# 2052. 统计按数位和排序后位置不变的整数

[Timus 2052](https://acm.timus.ru/problem.aspx?space=1&num=2052) · difficulty 1486 · dp, binary_search

原题作者 Alexander Ipatov（由 Bulat Zaynullin 整理），出自 2015 年乌拉尔体育编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把 1, …, n 按十进制数字和排序，数字和相同时按数值排序。统计位置不变的数的个数。时间限制 1 秒，内存限制 64 MB。

## 输入

一个整数 n，2 ≤ n ≤ 10⁹。

## 输出

位置不变的数的个数。

## 评测方式

按记号逐个比较输出。

## 样例

```
19
```

```
3
```

十九个数的新顺序为 `1,10,2,11,3,12,4,13,5,14,6,15,7,16,8,17,9,18,19`。恰有 `1,18,19` 保持位置，答案为三，数位和分别为一、九、十。

## 解法

### 排序位置的公式

令 `C(b,s)` 表示不超过 `b`、数位和为 `s` 的正整数个数，`L_s=sum_{t<s} C(n,t)`。数位和为 `s` 的组占据位置 `[L_s+1,L_s+C(n,s)]`。若 `x` 的数位和为 `s`，其排序后位置是
`rank(x)=L_s+C(x,s)`。
更小的数位和全部在前，同组则按数值排序，因此计入直到 `x` 自身的成员。位置不变当且仅当 `x-C(x,s)=L_s`。

### 每种数位和至多一个不动点

把一组的成员按值写为 `x_1<x_2<…`，其位置是 `L_s+j`。相邻整数的数位和永不相同：加一使数位和变化 `1-9k`，其中 `k` 是末尾九的个数，该值不可能为零。因此 `x_{j+1}≥x_j+2`，使 `x_j-j` 严格递增，只能至多一次等于 `L_s`。所以每种数位和只需寻找一个候选。

令 `F_s(b)=b-C(b,s)`。`b` 加一时计数增加零或一，所以 `F_s` 单调不减。在该组的排序位置区间中二分寻找满足 `F_s(b)≤L_s` 的**最后一个**整数，空组直接跳过。最后核验候选在区间中、数位和为 `s` 且精确等式成立，然后答案加一。

该搜索不会遗漏。任何不动点都在自身组的位置区间并满足条件；紧接着的整数数位和不同，因此只要搜索区间尚未结束，`F_s` 立即增为 `L_s+1`。此后单调性排除其他候选，所以二分必找到已有不动点。最终检查保证计数的每个候选确实位置不变。

### 按位精确计数

令 `D` 为 `n` 的位数，`S=9D`。预计算允许前导零的 `l` 位十进制串中，数位和为 `q` 的数量 `W_l(q)`。初值 `W_0(0)=1`，递推 `W_l(q)=sum_{a=0..9} W_{l-1}(q-a)`，每行可用滑动窗口求出。保存前缀 `P_l(q)=sum_{r≤q} W_l(r)`；负下标取零，超过可能数位和时取 `10^l`，只需长度到 `D-1`。

计数上界 `b` 时从左向右扫描，维护剩余数位和 `q`。当前数字为 `d`、右边剩 `l` 位，较小选择 `a=0,…,d-1` 让后缀和为 `q-a`，总数为
`P_l(q)-P_l(q-d)`。
加入这部分，令 `q-=d` 并沿相等前缀继续。若剩余和负则停止；扫描结束后仅当 `q=0` 时加入 `b` 自身。短整数用前导零表示且唯一。仅查询正数位和 `s≥1`，所以整数零自动排除。这样 `C(b,s)` 只需 `O(D)`，无需枚举所有整数。

遍历 `s=1,…,S`，求组大小、二分候选并累加 `L_s`。计数与排名全为整数；这里最多九个自由后缀位，六十四位计数器足够。

位置从一开始，`C(x,s)` 必须包含 `x`。后缀串允许零，但正整数组不包含整数零。处理空数位和组以及跨九进位。只有固定数位和后搜索条件才单调，整个排列并非按数值单调。应找最后一个满足不等式的数并检查其数位和，邻近非组成员也可能满足不等式。每组只加至多一依赖上述唯一性证明。

## 各语言说明

预计算时间与空间为 `O(D·S)`。至多 `S` 次搜索，每次 `O(log n)` 步、每步 `O(D)` 计数，总时间 `O(D·S·(1+log n))`，额外空间 `O(D·S)`。这里 `D≤10,S≤90`，始终不构造完整排列。

五种实现均使用相同的后缀前缀计数与组区间搜索。C++/Go/Java/Rust 用六十四位计数器，Python 用精确整数。十进制串只用于查询的至多十位，不对整个数域逐个处理。
