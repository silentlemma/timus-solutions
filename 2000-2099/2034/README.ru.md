# 2034. Максимальный минимум расстояния на кратчайшем пути

[Timus 2034](https://acm.timus.ru/problem.aspx?space=1&num=2034) · сложность 283 · bfs, dp

Автор оригинальной задачи — Олег Меркурьев; Уральская региональная командная олимпиада по программированию 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дан связный простой неориентированный граф с единичными рёбрами и три различные
вершины `s,f,r`. Выбирается один из кратчайших путей из `s` в `f`.
Его оценка — минимум расстояния от `r` до вершины этого пути, включая оба конца.
Нужно максимизировать такую оценку по всем кратчайшим путям.
Расстояния от `r` считаются по всему графу. Более длинный путь не подходит,
даже если его оценка выше.

Ограничения: `3 ≤ n ≤ 100000`, `2 ≤ m ≤ 100000`, петель и кратных рёбер нет,
граф связен. Лимиты: 1 секунда, 64 МБ.

## Входные данные

Сначала `n m`, затем `m` пар концов рёбер от 1 до `n`.
Последняя строка — попарно различные `s f r`.

## Выходные данные

Одно целое — максимальная оценка кратчайшего пути. Ноль допустим, если любой
кратчайший путь содержит `r`. Ближайшими могут быть и концы `s`, `f`.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
7 7
1 2
2 4
2 5
3 4
4 6
5 6
6 7
1 7 3
```

```
2
```

## Решение

BFS из `s` даёт расстояния `ds` и порядок обхода; BFS из `r` — расстояния `dr`.
Используем ориентированный переход `u→v` только при `ds[v]=ds[u]+1`.
Получается ациклический граф, упорядоченный слоями BFS.

Пусть `best[v]` — наибольший минимум `dr` на кратчайшем пути из `s` в `v`.
Изначально `best[s]=dr[s]`, остальные значения `-1`. Перебираем вершины
в порядке первого BFS и для каждого допустимого перехода обновляем
`best[v]=max(best[v],min(best[u],dr[v]))`. Ответ — `best[f]`.

### Доказательство

Любой префикс кратчайшего пути тоже кратчайший: иначе его замена
сократила бы весь путь. Поэтому каждое ребро увеличивает `ds` на
единицу. Обратно, путь из `s` в `f` с такими переходами имеет ровно
`ds[f]` рёбер и является кратчайшим.

Начальное значение учитывает `s`. Любой кратчайший путь в `v` заканчивается
предшественником `u` предыдущего слоя; его оценка равна минимуму оценки
префикса и `dr[v]`. Минимум монотонен по первой величине, поэтому достаточно
хранить лучший префикс для каждого `u`. Максимум по всем предшественникам
даёт точное `best[v]`. Порядок BFS обрабатывает предшественников раньше,
и индукция доказывает результат для `f`.

Можно обрабатывать и вершины вне всех кратчайших путей `s-f`. Если их
значение достигает `f` по возрастающим слоям, полученный полный путь
тоже кратчайший; в противном случае повлиять на `f` они не могут.

В примере путь `1-2-4-6-7` имеет минимум расстояния от вершины 3, равный
единице в вершине 4. У пути `1-2-5-6-7` минимум равен двум в вершинах 2 и 6.
Максимум этих оценок — два.

Два BFS и один просмотр рёбер требуют `O(n+m)` времени. Смежность,
расстояния, порядок и динамика занимают `O(n+m)` памяти.

Подводные камни:

- Сначала минимум по вершинам пути, затем максимум по путям.
- Переход разрешён только на следующий слой BFS.
- Расстояния от `r` считаются по всему графу, концы `s` и `f` учитываются.
- Ноль корректен, если на кратчайших путях нельзя избежать `r`.
- Более длинный безопасный обход не участвует в выборе.

## Особенности языков

Все обходы итеративны, рекурсия на цепочке из 100000 вершин не требуется.
Java использует примитивные массивы смежности и очередей, Go — байтовый ввод.
Python построчно читает рёбра в компактный массив концов до последней тройки,
затем строит смежность через итератор. Rust хранит текст входа и разбирает
его итератором. Память всех реализаций `O(n+m)`, расстояния и ответ
помещаются в знаковое 32-битное целое.
