# 2034. 最短路中的最大距离瓶颈

[Timus 2034](https://acm.timus.ru/problem.aspx?space=1&num=2034) · 难度 283 · bfs, dp

原题作者 Oleg Merkurev，出自 2014 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定连通简单无向单位边图及三个不同顶点 `s,f,r`。只能选择一条 `s` 到 `f` 的最短路。
路径得分是 `r` 到该路径任一顶点的图距离最小值，包括起终点。求所有最短路中的最大得分。
`r` 的距离使用整个图；即使更长绕路得分更高，也不能选择。

限制：`3 ≤ n ≤ 100000`、`2 ≤ m ≤ 100000`，无自环、无重边且连通。
时间 1 秒，内存 64 MB。

## 输入

先给 `n m`，随后 `m` 对位于 `1..n` 的边端点，最后一行是两两不同的 `s f r`。

## 输出

一个整数，最短路径的最大得分。若每条最短路都经过 `r`，答案为零。
`s` 和 `f` 也可能是最近路径顶点，不能排除。

## 评测方式

按记号逐个比较输出。

## 样例

```
7 7
1 2
2 4
2 5
3 4
4 6
5 6
6 7
1 7 3
```

```
2
```

## 解法

从 `s` 做 BFS 得到 `ds` 和访问顺序，从 `r` 做 BFS 得到 `dr`。
只使用满足 `ds[v]=ds[u]+1` 的有向边 `u→v`，它们按 BFS 层组成有向无环图。
令 `best[v]` 为所有 `s` 到 `v` 最短路上最小 `dr` 的最大值。
初始化 `best[s]=dr[s]`，其余 `-1`。按第一个 BFS 顺序扫描，
每个允许转移更新 `best[v]=max(best[v],min(best[u],dr[v]))`，输出 `best[f]`。

### 正确性

最短路的每个前缀也最短，否则替换前缀会缩短全程。因此每条边使 `ds` 恰增一。
反过来，所有边均如此的 `s-f` 路径长度恰为 `ds[f]`，必然最短。
初值包含起点。到 `v` 的每条最短路来自前层某 `u`，得分为前缀得分与 `dr[v]`
的较小者。此最小函数对前缀得分单调，所以保留每个 `u` 的最佳前缀即可。
对全部前驱取最大正好得到 `best[v]`。BFS 顺序先处理全部前驱，逐层归纳证明答案。

可以同时处理不在任何最短 `s-f` 路上的顶点：若其贡献能沿递增层到达 `f`，
整条路线仍有长度 `ds[f]`，就是合法最短路；否则不会影响终点。

样例 `1-2-4-6-7` 到顶点 3 的最小距离在 4 处为一；`1-2-5-6-7` 在 2 或 6
处为二。两个得分的最大值为二。

两次 BFS 加一次边扫描，时间 `O(n+m)`；邻接、距离、顺序和动态规划数组占 `O(n+m)` 空间。

注意事项：

- 先对一条路径的顶点取最小，再对路径取最大。
- 转移必须恰好前进一个 BFS 层。
- `r` 的距离用完整图，并包括 `s`、`f`。
- 无法避免经过 `r` 时零是合法答案。
- 更长的安全绕路不允许。

## 优化解法

先计算第一个起点的距离，再把第二次 BFS 与最短路层上的瓶颈 DP 合并。FIFO 保证弹出顶点时所有前驱层已完成，因此其最佳值已经确定。必须在目标弹出时停止，不能在首次发现时停止。扁平邻接和可复用队列替代嵌套容器，紧凑距离及评分数组仍实现同一线性图算法。
