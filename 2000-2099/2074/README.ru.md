# 2074. Группировка задач по путям их тем

[Timus 2074](https://acm.timus.ru/problem.aspx?space=1&num=2074) · сложность 975 · implementation, sorting

Автор оригинальной задачи — Михаил Рубинчик.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Классификатор тем — дерево, записанное списком: каждый заголовок — это
идентификатор вида `2.2.1.` и название темы, а за ним идут одна или
несколько строк с номерами задач этой темы. Для каждой упомянутой
задачи выведите темы, к которым она относится; тема описывается именами
на пути от корня, соединёнными точками. Задачи с одинаковым набором тем
выводятся одной строкой. Ограничения: 2 секунды и 256 МБ.

## Входные данные

Классификатор, как в примере. Тем не больше 20, различных номеров задач
не больше 20, номера от 1000 до 9999. Название темы — от 1 до 20
строчных латинских букв и одиночных пробелов. Идентификаторы идут в
порядке обхода в глубину, так что заголовок из k чисел — потомок
последнего заголовка из k − 1 чисел.

## Выходные данные

Строки «номера : темы»: задачи группы по возрастанию через ", ", затем
" : ", затем описания их тем в лексикографическом порядке через ", ".
Сами строки идут в лексикографическом порядке.

## Примеры

### Пример 1

Ввод:

```
1. graphs
1022
1065
2. geometry
1020
2.1. idea
1130
2.2. technique
1111 1065
1265
2.2.1. convex hull
1271
3. dynamic programming
1244
```

Вывод:

```
1020 : geometry
1022 : graphs
1065 : geometry.technique, graphs
1111, 1265 : geometry.technique
1130 : geometry.idea
1244 : dynamic programming
1271 : geometry.technique.convex hull
```

## Решение

Вход читается построчно. Строка, первое слово которой кончается точкой,
— заголовок; число точек — его глубина, поэтому стек имён обрезается до
depth − 1 элементов и в него кладётся новое имя. Описание текущей темы —
стек, соединённый точками. Любая другая строка содержит номера задач, и
каждой из них в множество добавляется текущее описание. Задача
относится только к темам, где она перечислена, а не к их предкам: в
примере 1065 есть только в graphs и geometry.technique.

Затем отсортированное множество каждой задачи склеивается в ключ, задачи
с равными ключами объединяются, и каждая группа даёт строку из её
отсортированных номеров и ключа. Строки сортируются как обычные строки,
где пробел идёт раньше точки, а точка раньше букв. При не более чем 20
темах и задачах работа ничтожна.
