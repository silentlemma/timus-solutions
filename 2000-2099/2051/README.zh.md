# 2051. 从上下包络恢复面积相等的两条折线

[Timus 2051](https://acm.timus.ru/problem.aspx?space=1&num=2051) · difficulty 3748 · meet_in_middle

原题作者 Viktor Kamashev（由 Bulat Zaynullin 整理），出自 2015 年乌拉尔体育编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两个隐藏的、定义在 [0, T] 上的连续分段线性函数积分相等。只知道它们的逐点最大值 h 和逐点最小值 g。还原任意一对这样的函数。时间限制 1 秒，内存限制 64 MB。

## 输入

首先是 T，2 ≤ T ≤ 10⁶。然后依次给出 h 和 g，各自先给出结点数（2 ≤ n, m ≤ 100 000），再给出整数对 t y。时间从 0 严格递增到 T，高度在 0 到 10⁶ 之间，任意三个相邻结点不共线。处处 g ≤ h，相等的点不超过三十个（含端点），且不会在整条线段上相等。保证有解。

## 输出

按同样格式输出两个函数：结点数，然后是整数对 t y，时间从 0 严格递增到 T，任意三个相邻结点不共线。

## 评测方式

检查器精确验证两个函数的逐点最大值和最小值分别是 h 和 g，并且积分相等；任何合法的一对都被接受。

## 解法

### 可以在哪里交换上下角色

在连通的 `h>g` 开区间中，连续的恢复函数必须始终沿同一条包络。在不相等的值之间切换会不连续。只有在 `h=g` 接触处可以换角色。反过来，独立选择各接触间区域的上下归属总能得到连续且包络正确的函数。

每个接触必是至少一条输入函数的节点时刻。否则间隙局部线性，内部孤立零点会变号，或者零间隙延续成公共线段，两者均被禁止。因此接触时间为整数。至少一条函数在这里有整数高度节点，相等使公共高度也为整数。

合并两条节点时间序列，精确比较插值。在边 `(a,x),(b,y)` 上，时刻 `t` 的值表示为有理数对 `(x(b-t)+y(t-a),b-a)`，交叉相乘即可判断相等。保存内部接触，并把零和 `T` 作为外边界，不论端点是否接触。这样得到 `R≤31` 个正间隙区域。

### 精确划分面积

把缺失的内部接触插入两条图中，所有新增坐标均为整数。每个区域的一条函数的双倍积分由 `(y_i+y_next)(t_next-t_i)` 求和得到。上下之差 `d_i` 是正整数，设 `D=sum d_i`。若第一条输出在子集 `S` 的区域走上包络，其双倍面积等于完整下包络的双倍面积加 `sum_S d_i`；第二条等于完整上包络减去相同的和。两者相等恰好要求 `sum_S d_i=D/2`。存在性保证 `D` 为偶数且有相应子集。

把权重分为 `L=floor(R/2)≤15` 个左权重和至多十六个右权重。枚举所有左子集，每个只存一个整数
`key=sum·2^L+mask`。
逐个加入权重时将列表翻倍，然后排序。低 `L` 位保存掩码，因此首先按和排序，相同和也安全保留掩码。

用格雷码顺序枚举右掩码，相邻掩码仅改变一位，故右和只需加减一个权重。对 `need=D/2-right_sum`，二分寻找第一个不小于 `need·2^L` 的键。若它除以 `2^L` 的商为 `need`，就找到匹配左子集；取低位并合并左右掩码。两半的所有子集均被枚举，故必能找到保证存在的方案。

全程整数精确计算。插值分子至多 `10^12`，交叉乘积至多 `10^18`；`D≤2·10^12`，所有打包键小于 `6.6·10^16`。有符号六十四位足够，但应在乘法前提升类型。完整掩码最多三十一位。

### 恢复规范折线

按时间从左到右访问区域，将选中包络的自身节点与插入的边界接触加入第一条输出，另一包络加入第二条。重复边界点忽略。若最后三点共线，用精确叉乘判断并删除中间点，重复到不共线。删除不会改变函数，栈最终得到规范节点。接触高度相等保证连续性，子集和保证积分相等，互补选择保证上下包络。所有输出坐标仍为原范围内的整数。

不要在另一条图的每个无关节点处插值并加入输出，该值可能不是整数。只需当前选中图的节点和接触。两条输出在简化前合计至多 `n+m+30` 个原始节点。

接触不一定同时是两条图的节点，另一条可能直穿该点。端点接触不计入内部划分表。使用双倍面积与六十四位乘法；左半相同和也须保留掩码。格雷码按变化的位更新权重，不能使用迭代编号。按时间恢复，并在换角色后也删除共线点。只在节点检查包络会遗漏区间内部的非法交叉，检查器还核验所有联合线性区间的中点。

## 各语言说明

图扫描和栈恢复共 `O(n+m)` 时间。计入排序和二分，时间为 `O(n+m+R·2^ceil(R/2))`，额外空间 `O(n+m+2^floor(R/2))`。`R≤31` 时最多保存 32768 个键并枚举 65536 个右子集。

五种版本均使用精确整数和打包标量键。Python 将坐标存入紧凑无符号数组，以 bisect 搜索并分块输出。Java 使用基本类型数组和字节输入输出缓冲。无需浮点几何或积分。

Python 解答在 PyPy 下运行：在 CPython 3.12 下它在评测的第 19 个测试上超时，而在 PyPy 3.10 下以 0.562 秒通过。
