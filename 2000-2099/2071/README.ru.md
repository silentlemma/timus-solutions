# 2071. Порядок коктейлей с наименьшим числом наливаний

[Timus 2071](https://acm.timus.ru/problem.aspx?space=1&num=2071) · сложность 640 · bitmask, dp

## Задача

Каждый из n гостей заказывает коктейль — непустой набор соков A, B и P.
Стаканы ставят в ряд в некотором порядке, а за одно наливание отрезок
подряд идущих стаканов заполняется одним соком (сначала яблочный, затем
банановый, затем ананасовый, так что порядок наливаний не мешает). Каждый
стакан должен получить ровно соки своего коктейля. Расставьте стаканы
так, чтобы наливаний было как можно меньше. Ограничения: 1 секунда и
64 МБ.

## Входные данные

n, 1 ≤ n ≤ 10⁵, затем n строк, каждая — одно из A, B, P, AB, AP, BP,
ABP.

## Выходные данные

Наименьшее число наливаний, затем номера стаканов в порядке ряда.
Подходит любая оптимальная расстановка.

## Проверка

Проверяющая программа сравнивает число наливаний и пересчитывает,
сколько наливаний нужно для выведенной расстановки.

## Примеры

### Пример 1

Ввод:

```
3
A
B
ABP
```

Вывод:

```
3
1 3 2
```

## Решение

При фиксированном ряде каждому соку нужно по наливанию на каждый
максимальный отрезок стаканов, где он есть, так что стоимость — число
мест, где сок есть в стакане, но нет в предыдущем (первый стакан
считается со всеми соками). Перестановка стакана к такому же никогда не
добавляет отрезков, поэтому стаканы одного коктейля можно поставить
вместе, и важен только порядок не более чем семи разных коктейлей.

Их упорядочивает DP по подмножествам: best[S][last] — наименьшее число
наливаний для ряда из коктейлей множества S, который заканчивается
коктейлем last. Добавление коктейля k стоит столько, сколько соков k нет
в last, то есть popcount(k & ~last). Ответ — минимум по last для полного
множества, а сохранённые предшественники дают порядок. При семи
коктейлях это 2⁷ · 7 · 7 шагов, так что работа — O(n) на чтение и вывод.

В примере порядок B, ABP, A требует трёх наливаний: по одному отрезку на
каждый сок.
