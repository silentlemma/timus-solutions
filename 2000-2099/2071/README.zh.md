# 2071. 使倒入次数最少的鸡尾酒顺序

[Timus 2071](https://acm.timus.ru/problem.aspx?space=1&num=2071) · 难度 641 · bitmask, dp

原题作者 Mikhail Rubinchik（由 Nickolai Permyakov 和 Alexey Danilyuk 整理），出自 2015 年乌拉尔地区团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 位客人各点一杯鸡尾酒：果汁 A、B、P 的一个非空集合。杯子按某种顺序排成一排，一次倒入把一种果汁倒进一段连续的杯子（先苹果，再香蕉，最后菠萝，所以倒入顺序不成问题）。每个杯子必须恰好得到其鸡尾酒中的果汁。安排杯子顺序，使倒入次数最少。时间限制 1 秒，内存限制 64 MB。

## 输入

n（1 ≤ n ≤ 10⁵），然后 n 行，每行是 A、B、P、AB、AP、BP、ABP 之一。

## 输出

最少倒入次数，然后按排列顺序输出杯子编号。任何最优排列都可接受。

## 评测方式

检查器比较倒入次数，并重新计算输出的排列所需的倒入次数。

## 样例

### 样例 1

输入：

```
3
A
B
ABP
```

输出：

```
3
1 3 2
```

## 解法

排列固定时，每种果汁对其所在杯子的每个极长连续段需要一次倒入，所以代价就是“某果汁在当前杯中有而在前一杯中没有”的位置数（第一杯的所有果汁都计入）。移除一个杯子不会增加连续段的数量。把它放到盛有同种鸡尾酒的杯子旁边，只会延长已有的连续段。因此可以把同种鸡尾酒的杯子放在一起，只需确定至多七组的顺序。

用子集 DP 确定顺序：best[S][last] 表示由集合 S 中的鸡尾酒组成、以 last 结尾的一排所需的最少倒入次数。在后面接上鸡尾酒 k 的代价是 k 中 last 没有的果汁数，即 popcount(k & ~last)。答案是全集下对 last 取最小，记录的前驱给出顺序。七种鸡尾酒时只有 2⁷ · 7 · 7 步，所以总工作量是读入和输出的 O(n)。

样例中顺序 B、ABP、A 需要三次倒入：每种果汁一段。

## 优化解法

C++ 版本枚举至多七种混合饮料的排列。每种饮料的杯子编号用同一个数组中的链表保存。输入输出耗时 O(n)，枚举 k 种饮料耗时 O(k! · k)，空间复杂度为 O(n)。提交 11317118 耗时 0.046 秒、使用 560 KB；基础版为 0.078 秒和 420 KB。

Java 逐字节解析输入，用字节数组保存动态规划的代价和前驱，并通过一个整型数组连接杯子编号。提交 11317279 耗时 0.125 秒，使用 832 KB；基础版耗时 0.14 秒，使用 8836 KB。

Go 每次读取一个词元，用一个 32 位数组连接杯子编号。子集动态规划使用字节数组存储代价和前驱。提交 11317277 耗时 0.031 秒，使用 1288 KB；基础版耗时 0.031 秒，使用 8040 KB。

Python 用字节数组存储代价和前驱，逐行读取订单，并分批输出紧凑存储的杯子编号。提交 11317276 耗时 0.109 秒，使用 1408 KB；基础版耗时 0.171 秒，使用 16872 KB。

Rust 用一个字节分别存储每个动态规划状态的代价和前驱。同类杯子的编号通过一个共用的 32 位数组连接。提交 11317274 耗时 0.046 秒，使用 584 KB；基础版耗时 0.046 秒，使用 7676 KB。
