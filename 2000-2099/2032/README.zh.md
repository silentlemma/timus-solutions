# 2032. 在整数格点上实现三条边长

[Timus 2032](https://acm.timus.ru/problem.aspx?space=1&num=2032) · 难度 787 · geometry

原题作者 Alexey Danilyuk，出自 2014 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定三条正整数边长，找三个整数坐标点，使三个两两距离恰好等于输入长度，顺序任意。
长度不超过 `10000000`，保证三角形不等式。每个坐标绝对值不超过 `100000000`。
时间 1 秒，内存 64 MB。

## 输入

一行三个边长。

## 输出

任意三个整数坐标对，以空白分隔；不存在则输出 `-1`。顶点顺序任意。

## 评测方式

检查器精确比较三个距离的平方并检查坐标范围；只有不存在整点三角形时才接受 `-1`。任何合法的摆放都被接受。

## 样例

```
4 3 5
```

```
0 0
3 4
3 0
```

```
10 17 21
```

```
0 0
0 21
-8 15
```

```
100 100 100
```

```
-1
```

## 解法

排序边长 `r ≤ b ≤ a`，取 `A=(0,0)`、`B=(x,y)`、`C=(u,v)`，
满足 `|B|=r`、`|C|=b`、`|C-B|=a`。点积为 `D=(r²+b²-a²)/2`；
分子为奇数则不可能为格点。叉积为整数 `K`，且 `K²=r²b²-D²`。
负数或非完全平方立即排除，用精确整数平方根计算，不进行浮点取整。`D` 可以为负。

固定半径 `r` 圆上的格点 `B`，解方程：
`u=(Dx-Ky)/r²`、`v=(Dy+Kx)/r²`。两个分子都整除时得到答案。

枚举第一象限全部 `B`，先检查坐标轴。非零两直角边除以最大公约数 `t`，
得到斜边 `d=r/t` 的本原勾股三元组，`d` 是 `r` 的约数。欧几里得参数化给出
`m²-k²,2mk`，其中 `m²+k²=d`、`m>k≥1`、互质且奇偶不同。
试除分解 `r` 构造全部约数。对奇数 `d≥5`，枚举 `m` 从
`floor(sqrt(d/2))+1` 到 `floor(sqrt(d-1))`，取 `k=isqrt(d-m²)`，
精确检查平方、互质及奇偶。两边乘 `r/d`，尝试两个坐标顺序，立即检查而不保存整个圆。

为何完整？任意格点实现可平移一顶点到原点，必要时反射整个图形使叉积非负，
再旋转 90 度的整数倍使 `B` 位于闭第一象限。这些操作保持整数坐标。
轴点或完整本原参数枚举必定访问该 `B`，线性方程随后唯一恢复 `C`，
故用尽候选可证明无解。叉积平方为完全平方仅是必要预检，不替代方向搜索。

返回点满足点积、叉积，故 `|C|²=(D²+K²)/r²=b²`，
`|C-B|²=b²+r²-2D=a²`。整除保证整数，坐标绝对值不超过到原点距离
`r,b≤10000000`，因此满足输出界限。

首例距离平方 `25,9,16` 对应边长 `5,3,4`；第二例 `441,289,100` 对应
`21,17,10`，负坐标合法。边长 100 的等边情形有 `D=5000`、
`K²=75000000`，不是完全平方，所以第三例无解。

令 `d(r)` 为约数数目，`M` 为最大输入边，最多 `O(d(r) sqrt(r))` 次尝试。
精确二分根（包括较大的叉积平方根）给出共同时间上界 `O(d(r) sqrt(r) log(M+1))`，
工作空间 `O(d(r))`。所有中间值，包括平方根搜索边界，均可放入有符号 128 位。

注意事项：

- 不能假定一边总能沿坐标轴。
- 检查全部约数、两种直角边顺序、互质和奇偶。
- 根和坐标除法必须精确，不能取近似。
- 点积与坐标可能为负。
- 中间乘积可达 `10^28`，先扩大类型再乘。

## 各语言说明

C++ 用有符号 `__int128`，Rust 用 `i128`，均用精确二分根。
Go 用 `math/big.Int.Sqrt`，Java 8 用 `BigInteger` 与整数 Newton 迭代，
因为该版本无内置平方根。两者的小整数二分根参数最多 `10000000`。
Python 用无限精度整数和 `math.isqrt`，无需浮点几何。
