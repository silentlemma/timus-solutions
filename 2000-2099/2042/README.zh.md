# 2042. 区间赋值下的有界长度回文计数

[Timus 2042](https://acm.timus.ru/problem.aspx?space=1&num=2042) · difficulty 3245 · strings, segment_tree

原题作者 Nikita Sivukhin，出自 2014 年夏季彼得罗扎沃茨克集训营乌拉尔联邦大学 Dandelion 专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

维护一个小写拉丁字母字符串。修改把给定闭区间内的全部字符设为同一个字母；查询统计完全位于指定区间内、长度不超过固定 `k` 的回文子串出现次数。不同位置的相同字符串分别计数。

## 输入

第一行是初始字符串和 `k`，其中 `1≤n≤100000`、`1≤k≤50`。下一行给出 `1≤m≤100000` 次操作。`1 l r c` 将位置 `l..r` 设为小写字母 `c`；`2 l r` 查询该区间的计数。输入使用从一开始的下标，`1≤l≤r≤n`。字符串长度及 `k` 不变。时间限制 3 秒，内存限制 64 MB。

## 输出

按操作顺序为每个查询输出一行整数；没有查询时输出为空。按整数标记比较答案。统计端点对而非不同回文值，每个答案最多为 `nk≤5000000`。

## 评测方式

按记号逐个比较输出。

## 样例

```
abacaba 4
3
2 1 3
1 1 3 c
2 1 4
```

```
4
10
```

最初前三个字符为 `aba`，三个单字符及一个长度三回文共 `4` 次出现。将位置 `1..3` 赋为 `c` 后，前四个字符为 `cccc`，全部 `4+3+2+1=10` 个子串都是长度不超过 `4` 的回文。

## 解法

### 每个中心保存一个计数

以下下标从零开始。令 `O=(k+1)//2`、`E=k//2`。`odd[i]` 是以字符 `i` 为中心、包含中心且上限为 `O` 的奇回文半径；`even[i]` 是中心在 `i` 之前的间隙、上限为 `E` 的偶回文半径。半径 `d` 对应这一奇偶性的 `d` 个正长度，因此 `p[i]=odd[i]+even[i]` 统计分配给该中心下标的全部允许出现。

用 Manacher 计算半径。加入上限后镜像初始化仍然正确：低于上限的镜像半径在已知右界内是精确的，达到上限则已获得最大允许值。新的成功比较推进右界，两个扫描各为线性时间。

维护两棵带懒标记的线段树：一棵对字符区间赋值并提取短连续窗口；另一棵维护 `p` 的赋值与区间和，还能在一次遍历中用显式数组替换短连续区间。逐中心做单点修改会多出一个不必要的对数因子。

### 赋值只需修复边界

先给 `[l,r]` 的字符赋值。只有最大允许窗口与该区间相交的中心可能改变，故受影响中心都位于裁剪到整串范围后的 `A=[l-O+1,r+E]`。对内部中心 `I=[l+E,r-O+1]`，两种最大窗口均完全落在赋值区间内，所有相应子串都相同字符，可以懒赋值 `p=k`。

`A` 剩余部分最多是两段，各至多 `k-1` 个中心。若 `I` 为空，则一次修复整个裁剪后的 `A`，因为两段名义边界可能重叠。修复中心 `[u,v]` 时，提取全局裁剪后的字符 `[u-E,v+O-1]`，计算有界半径，再只替换目标中心。此窗口包含这些中心的每一个允许回文，所以窗口边缘不会截掉合法答案。即使赋值区间很长，窗口也只有 `O(k)` 长度。

### 查询区间内的出现次数

若 `r-l+1<k`，提取整个查询区间，直接求本地有界半径之和。否则 `[l+E,r-O+1]` 的中心具有完全落在查询内的最大窗口，使用存储的 `p` 区间和。剩下的中心是 `l..l+E-1` 和 `r-O+2..r`。

左侧提取查询的前 `k-1` 个字符，只累加窗口的前 `E` 个中心；右侧提取后 `k-1` 个字符，只累加后 `O-1` 个中心。这些窗口覆盖全部相关回文，并自然施加查询边界。内部与两侧分割所有中心下标，而每次出现有唯一中心及奇偶性，所以恰好统计每个所需出现一次，且不会包含越界子串。`k=1` 时两侧为空，只剩单字符。

### 正确性与复杂度

初始计数正确后，每次赋值恢复全部改变的中心，并保持其他中心不变。对操作归纳得到存储值正确，中心划分则证明查询正确。短窗口及批量替换耗时 `O(k+log n)`，长常数内部使用懒赋值。总时间 `O(n+m(k+log n))`，空间 `O(n)`。

Python 采用另一种不变量：`s[i]` 和 `e[i]` 分别统计以位置 `i` 为起点和终点的合法回文。以下描述 Python 时使用左闭右开区间。扫描时维护一个可容纳于机器字的位掩码，第 `d` 位表示以当前位置结尾、长度为 `d+1` 的回文。将前一个掩码左移两位，补入长度一和二的候选，再与当前字母的历史位置掩码按位与。历史掩码的第 `d` 位为一，当且仅当向前 `d` 个位置的字符与当前字符相同。因此，较长的候选恰好在内部子串是回文且两端字母相等时保留。去掉长度超过 `k` 的位，再通过小型置位计数表得到 `e[i]`。每个字母的历史掩码按距上次出现的距离移位；对反转后的窗口扫描即可得到 `s[i]`。

对于全为同一字母的窗口，端点计数为 `min(k,t)`，其中 `t` 是朝相应边界可用的字符数。若短窗口只由两段或三段连续相同字符组成，且相邻段的字母不同，也可以从各段内部的计数出发直接计算。只有两段时，不存在同时包含两种字母的回文；若有三段，包含不同字母的回文必须覆盖整个中间段，并从字母相同的两侧各取等量字符。只需加入两侧长度足够且总长度不超过上限的扩展。其他情况使用掩码扫描。有界的精确缓存保存短字节串及其不可变端点计数或查询总数，复用结果不会改变答案。

查询长度小于 `k-1` 时，每个子串都已满足长度限制。先用三角数统计各连续相同字符段内部的子串，再以每一整段为中心向两侧对称扩展。任何包含不同字母的回文都有唯一的这种中心段，因此每次出现恰好计数一次。若扩展工作超过线性预算，就丢弃部分结果，改用掩码扫描，从而保证短查询的计算仍为线性时间。

字符和端点计数用 bytearray 保存，并划分为固定大小的块；块的和由带懒标记的线段树维护。起点计数之和与终点计数之和打包在同一整数的两个独立字段中，每个字段都能容纳最大可能总和，因此相加时不会相互进位。赋值先给完整块标记新字母，并暂将两种端点计数都设为 `k`；读取字符或局部修改带标记的块前，先将其实际内容恢复。若所有合法长度都能容纳在新赋值的同字符段内，计数 `k` 就是准确的。其余受影响计数在两端长度为 `O(k)` 的窗口中重算，窗口相交时合并。发生变化的回文必与赋值区间相交，且长度不超过 `k`，所以这些窗口包含所需的全部字符，其他计数仍然正确。仅更新重算过的块的和。

对于长度至少为 `k-1` 的查询 `[l,r)`，答案为 `sum(e[0:r])-sum(s[0:l])`，两项都是树上的前缀和。由于回文长度不超过 `k`，任何起点在 `l` 之前的合法回文也必在 `r` 之前结束。因此，相减恰好消去越过查询左界的出现，留下完全位于查询区间内的出现。查询整串时直接使用已存总和。

赋值可以推迟到需要端点结构的查询再处理。第一次使用该结构前，先把待处理赋值应用到字符上，再一次性建立计数。后续批次中，若某次赋值的整个区间被更晚的赋值覆盖，就可以省略，因为下一个尚未回答的查询只关心最终字符。逆序扫描时只记录较长赋值的覆盖范围；忽略短赋值至多会漏删冗余写入，不会误删仍然需要的赋值。较大的短赋值批次先按原顺序修改字符，并去掉已经等于目标字母的前后缀。对 `[l,r)` 的实际修改只会影响 `[l,r+k-1)` 内的终点计数和 `[l-k+1,r)` 内的起点计数，区间均裁剪到整串范围。将这些区间排序、合并邻近区间，再补上所需的 `k-1` 个上下文字符，每个合并区域只根据最终字符串重算一次。即使赋值互相重叠，所有重算都使用最终字符，结果仍然准确。其他批次则逐次修复赋值边界。最后一次查询之后的赋值无需处理。

有些查询完全不需要修复。除最近一次赋值的区间外，Python 还维护一个已知字符全部相同的区间：与同字母且相交或相邻的赋值合并，或选择新赋值区间、未被破坏的同字符片段。这些操作始终保证所记区间内的字符相同。查询若包含在这两个已知同字符区间中的任一个内，答案就是 `dL-d(d-1)/2`，其中 `L` 为查询长度，`d=min(k,L)`；这是将长度 `j` 从一到 `d` 的 `L-j+1` 次出现相加得到的。`k=1` 时，无论字符如何，每个查询都可使用该公式。此类查询不会触发待处理赋值的执行。

Python 的复杂度还要计入树外的工作。令 `B` 为固定块长，且 `B≥k`。一次赋值可能写入 `O(n/B)` 个块标记，修复 `O(B+k)` 个字符，树上路径耗时 `O(log n)`。按实现中固定的阈值，过滤批次时维护已覆盖区间的并集也可能访问 `O(n/B+1)` 个片段。所有批次对受影响区间的排序总耗时至多为 `O(m log m)`。因此，一个保守的总时间上界是 `O(n+m(n/B+B+k+log n+log m))`。字符、计数和树占用 `O(n)` 空间，加上缓冲输入、待处理赋值和答案后，总空间为 `O(n+m)`。这些开销与上文按中心计数的复杂度不同。

偶中心在 `i` 之前。必须裁剪全局窗口、合并重叠修复区间，并区分半径与长度。统计出现次数且包含每个单字符。处理 `k>n` 及空输出；部分修改块前应恢复其懒标记值。短数组替换应一次遍历，避免 `k` 次独立单点修改。

## 各语言说明

C++、Go、Rust 使用平面数组及对数深度递归。Rust 用饱和算术处理左界裁剪和空内部。Go 1.14 使用自定义整数解析及缓冲输出。Java 8 重用字符、半径和替换数组，减少分配。Python 使用端点掩码、带懒标记的分块树和延后的边界修复。计数不超出有符号 32 位；Rust 使用无符号 32 位和。所有版本只转换一次输入下标。
