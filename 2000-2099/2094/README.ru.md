# 2094. Когда идти на своё место в заполняющемся ряду

[Timus 2094](https://acm.timus.ru/problem.aspx?space=1&num=2094) · сложность 5142 · dp, probability

Автор оригинальной задачи — Денис Дублённых; Открытое личное первенство УрФУ по программированию 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В ряду кинотеатра n мест; часть занята, одно — место Алекса, и каждое
свободное место остаётся свободным до начала фильма с вероятностью p %,
независимо. Остальные зрители входят по одному в случайном порядке, и
все идут к месту от левого края ряда. Алекс может ждать в проходе и
выбирать, когда идти; если он ещё ждёт к началу, идёт тогда.
Минимизируйте ожидаемое число зрителей, через которых Алекс пройдёт, плюс
число тех, кто пройдёт через него. Ограничения: 1 секунда и 64 МБ.

## Входные данные

Целые n и p (1 ≤ n ≤ 1000, 0 ≤ p ≤ 100), затем строка из n символов:
0 — свободно, 1 — занято, 2 — место Алекса. Строка содержит ровно одну 2.

## Выходные данные

Ожидание с абсолютной или относительной погрешностью не больше 10⁻⁶.

## Примеры

### Пример 1

Ввод:

```
5 0
01120
```

Вывод:

```
2.500
```

### Пример 2

Ввод:

```
3 50
020
```

Вывод:

```
0.375
```

## Решение

Через занятые места слева Алекс пройдёт при любой стратегии, так что
они дают постоянное слагаемое. Важны свободные места: l слева и r
справа, всего v = l + r. Каждое заполнится с вероятностью 1 − p/100, так
что число пришедших биномиально; после того как часть прихода уже
видна, шанс, что придёт ещё кто-то, и ожидаемое число ещё не пришедших
зависят только от числа оставшихся свободных мест, и оба получаются
короткой рекуррентной формулой по этому числу. Каждый следующий
пришедший занимает любое ещё свободное место с одинаковой вероятностью.

Тогда DP по (l, r) сравнивает два выбора. Пойти сейчас стоит ожидаемого
числа будущих пришедших справа — r, умноженное на ожидаемое число ещё не
пришедших и делённое на l + r. Ожидание следующего прихода ничего не
стоит, если больше никто не придёт; иначе новый зритель садится слева с
вероятностью l / (l + r) (через него придётся пройти: 1 плюс значение в
(l − 1, r)) или справа (значение в (l, r − 1)). Без свободных мест слева
Алекс может просто ждать, а без мест справа — идти: оба случая стоят 0.
Ответ — занятые места слева плюс значение в начальном состоянии, всего
O(n²).

В первом примере приходят все (p = 0); ожидание зрителя справа стоит 2
или 3 в зависимости от того, кто придёт первым, поэтому ответ 2.5.

Ловушка (тест 03): для единственного места ответ равен 0. И `0`, и
`0.000` допустимы; проверка должна сравнивать числовые значения с указанной
погрешностью, а не требовать совпадения текста.
