# 2094. 在逐渐坐满的一排中何时入座

[Timus 2094](https://acm.timus.ru/problem.aspx?space=1&num=2094) · 难度 5138 · dp, probability

原题作者 Denis Dublennykh，出自 2014 年乌拉尔联邦大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

电影院一排有 n 个座位；有些已被占用，有一个是 Alex 的，每个空座以 p% 的概率在电影开始前保持空着，相互独立。其他观众按随机顺序一个个进来，所有人都从这一排的左端走向座位。Alex 可以在过道等待并选择何时入座；如果到开场时还在等，就在那时入座。最小化 Alex 经过的观众数加上经过 Alex 的观众数的期望。时间限制 1 秒，内存限制 64 MB。

## 输入

n ≤ 1000 和 p，然后是这一排：0 为空，1 为已占，2 为 Alex 的座位。

## 输出

期望值，绝对或相对误差不超过 10⁻⁶。

## 样例

### 样例 1

输入：

```
5 0
01120
```

输出：

```
2.500
```

### 样例 2

输入：

```
3 50
020
```

输出：

```
0.375
```

## 解法

左边已占的座位无论如何都要经过，所以只贡献一个常数。重要的是空座：左边 l 个，右边 r 个，共 v = l + r 个。每个以 1 − p/100 的概率被坐上，所以来的人数服从二项分布；在已看到一部分到来之后，还会再来一人的概率和还会来的人数期望只取决于剩下的空座数，两者都可以由关于这个数的简短递推得到。下一个到来的人等概率坐到每个仍空着的座位上。

然后在 (l, r) 上做 DP 比较两种选择。现在入座的代价是右边将来到来人数的期望，即 r 乘以还会来的人数期望再除以 l + r。等待下一个人：若再无人来则代价为 0；否则新来的人以 l / (l + r) 的概率坐在左边（Alex 要经过这个人：1 加上 (l − 1, r) 的值），否则坐在右边（(l, r − 1) 的值）。左边没有空座时 Alex 可以一直等，右边没有空座时可以直接入座，代价都是 0。答案为左边已占座位数加上初始状态的值，总计 O(n²)。

第一个样例中所有人都会来（p = 0）；等待右边的观众，根据谁先来代价为 2 或 3，所以答案为 2.5。
