# 2005. Кратчайший допустимый маршрут по пяти точкам

[Timus 2005](https://acm.timus.ru/problem.aspx?space=1&num=2005) · сложность 94 · bruteforce

Автор оригинальной задачи — Михаил Рубинчик; подготовка — Олег Меркурьев. Уральская региональная командная олимпиада по программированию 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно посетить пять точек ровно по одному разу, начав в 1 и закончив в
5. Точка 3 не может быть предпоследней. По расстояниям между всеми
парами найдите маршрут минимальной суммарной длины и эту длину. Подходит
любой оптимальный допустимый маршрут.

## Входные данные

Целочисленная матрица расстояний 5 на 5. Значения от 0 до 10000, на
диагонали нули, матрица симметрична и выполняется неравенство
треугольника: `d[i][j]≤d[i][k]+d[k][j]`. Время 0,5 секунды, память 64
МБ.

## Выходные данные

Первая строка — минимальная суммарная длина. Вторая — пять номеров точек
в порядке посещения через пробел. При равенстве длин можно выбрать любой
оптимум.

## Проверка

Проверяющая программа убеждается, что маршрут допустим, напечатанная
длина — его длина и он оптимален; принимается любой оптимальный маршрут.

## Примеры

```
0 2600 3800 2600 2500
2600 0 5300 3900 4400
3800 5300 0 1900 4500
2600 3900 1900 0 3700
2500 4400 4500 3700 0
```

```
13500
1 2 3 4 5
```

Длина показанного маршрута равна `2600+5300+1900+3700=13500`.
Предпоследняя точка 4 удовлетворяет ограничению.

## Решение

Точка 1 первая, точка 5 последняя, поэтому меняется только порядок
точек 2, 3 и 4: шесть порядков, из которых два, где 3 стоит прямо перед
5, запрещены. Перебираем остальные четыре, складываем четыре расстояния
каждого маршрута и берём кратчайший. `O(1)`.

Подводные камни:

- правило касается остановки прямо перед последней;
- маршрут стоит от 0 до 40 000, поэтому минимум начинается с «пока
  ничего», а не с 0 или 10 000.

## Особенности языков

- Python берёт порядки из `itertools.permutations`, остальные языки
  перебирают точки тремя вложенными циклами.
