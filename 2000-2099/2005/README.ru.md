# 2005. Кратчайший допустимый маршрут по пяти точкам

[Timus 2005](https://acm.timus.ru/problem.aspx?space=1&num=2005) · сложность 94 · bruteforce

Автор оригинальной задачи — Михаил Рубинчик; подготовка — Олег Меркурьев. Уральская региональная командная олимпиада по программированию 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно посетить пять точек ровно по одному разу, начав в 1 и закончив в
5. Точка 3 не может быть предпоследней. По расстояниям между всеми
парами найдите маршрут минимальной суммарной длины и эту длину. Подходит
любой оптимальный допустимый маршрут.

## Входные данные

Целочисленная матрица расстояний 5 на 5. Значения от 0 до 10000, на
диагонали нули, матрица симметрична и выполняется неравенство
треугольника: `d[i][j]≤d[i][k]+d[k][j]`. Время 0,5 секунды, память 64
МБ.

## Выходные данные

Первая строка — минимальная суммарная длина. Вторая — пять номеров точек
в порядке посещения через пробел. При равенстве длин можно выбрать любой
оптимум.

## Проверка

Проверяющая программа убеждается, что маршрут допустим, напечатанная
длина — его длина и он оптимален; принимается любой оптимальный маршрут.

## Примеры

```
0 2600 3800 2600 2500
2600 0 5300 3900 4400
3800 5300 0 1900 4500
2600 3900 1900 0 3700
2500 4400 4500 3700 0
```

```
13500
1 2 3 4 5
```

Длина показанного маршрута равна `2600+5300+1900+3700=13500`.
Предпоследняя точка 4 удовлетворяет ограничению.

## Решение

Меняется только порядок точек 2, 3, 4. Из шести перестановок две
заканчиваются точкой 3 и запрещены. Остаются маршруты `1,2,3,4,5`,
`1,3,2,4,5`, `1,3,4,2,5`, `1,4,3,2,5`. Для каждого суммируем четыре
соседних расстояния и сохраняем самый короткий вместе с его длиной.

Программы перебирают первую и последнюю промежуточные точки: они
различны, а последняя не равна 3. Средняя — оставшаяся точка. Во
внутренней нумерации промежуточные индексы равны 1, 2, 3 с суммой 6;
вычитание выбранных крайних даёт средний индекс. Поэтому каждая
допустимая перестановка рассмотрена ровно один раз и запрещённых нет.
Любой требуемый ответ входит в эти четыре кандидата, значит минимум
среди них оптимален. Одновременное сохранение длины и маршрута
обеспечивает согласованность вывода.

Время `O(1)` и память `O(1)`: всегда пять точек, четыре кандидата и
четыре ребра у каждого. Сумма не больше 40000, достаточно знаковых
32-битных целых. Для данных метрических расстояний предподсчёт
кратчайших путей не нужен.

Запрет относится к предпоследней точке, а не ко второй или третьей. 1
всегда первая, 5 всегда последняя. Нулевые расстояния и несколько
оптимумов допустимы. Начальное лучшее значение должно позволять выбрать
нулевую длину; 10000 не ограничивает длину всего маршрута. Перед выводом
внутренние индексы переводятся в номера 1..5.

## Особенности языков

Пять языков проверяют одинаковые четыре кандидата и читают все 25
элементов матрицы. Где удобно, используются массивы фиксированного
размера; Python применяет короткие списки. Сохранённый маршрут не
меняется при рассмотрении следующих кандидатов.
