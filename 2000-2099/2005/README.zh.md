# 2005. 五站路线的最短合法顺序

[Timus 2005](https://acm.timus.ru/problem.aspx?space=1&num=2005) · 难度 94 · bruteforce

原题作者 Mikhail Rubinchik. (Prepared by Oleg Merkurev)，出自 2013 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

恰好访问五个地点各一次，从 1 出发，在 5 结束。地点 3 不能是倒数第二站。已知每对地点的距离，求总距离最小的合法路线及其长度。允许任意最优路线。

## 输入

一个 5 行 5 列的整数距离矩阵。每项为 0 到 10000，对角线为零，距离对称并满足三角不等式 `d[i][j]≤d[i][k]+d[k][j]`。时间限制 0.5 秒，内存 64 MB。

## 输出

第一行输出最小总距离。第二行按访问顺序输出五个地点编号，以空格分隔。相同最优长度可任选一个路线。

## 评测方式

检查器确认路线合法、输出的长度确实是其长度并且最优；任何最优路线都被接受。

## 样例

```
0 2600 3800 2600 2500
2600 0 5300 3900 4400
3800 5300 0 1900 4500
2600 3900 1900 0 3700
2500 4400 4500 3700 0
```

```
13500
1 2 3 4 5
```

所示路线长度为 `2600+5300+1900+3700=13500`，倒数第二站为 4，满足约束。

## 解法

只有 2、3、4 的顺序可变。六种排列中有两种以 3 结束，须去掉。剩余四条路线为 `1,2,3,4,5`、`1,3,2,4,5`、`1,3,4,2,5`、`1,4,3,2,5`。各求四条相邻边之和，保存最小值及对应路线。

程序枚举首个和最后一个中间地点，要求二者不同且最后一个不是 3。中间地点就是剩下的那个。内部采用从零开始的编号，中间地点索引为 1、2、3，总和为 6；减去已选两端即可得到中间索引。因此每个合法排列恰好枚举一次，且不会考虑非法排列。所有可能答案均在这四个候选中，选择最小值必然最优。同时保存长度和路线，保证输出相互对应。

时间 `O(1)`，空间 `O(1)`：地点恒为五个，候选恒为四个，各有四条边。总长度不超过 40000，有符号 32 位整数足够。给定距离已满足度量条件，无需预处理最短路。

限制针对倒数第二站，不是第二或第三站。1 必须开头，5 必须结尾。允许零距离及多个最优解。最优值初始化应允许零长度胜出；10000 不是整条路线的长度上界。输出时将内部索引转换为 1..5。

## 各语言说明

五种语言枚举相同四个候选并读取全部 25 个矩阵元素。适用时采用定长数组，Python 使用短列表。保存的路线不会被后续候选修改。
