# 2083. Взвешенная сумма степеней перестановки по циклам

[Timus 2083](https://acm.timus.ru/problem.aspx?space=1&num=2083) · сложность 2654 · math

Автор оригинальной задачи — Денис Дублённых.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дана перестановка p чисел 1 … n. Строка t матрицы A размера m × n — это
p, применённая t раз: A[t][j] = pᵗ(j) (первая строка — сама p).
Вычислите вектор q × A для данного q длины m, то есть
v[j] = q₁ p(j) + q₂ p²(j) + … + q_m pᵐ(j). Ограничения: 4 секунды и
256 МБ.

## Входные данные

m и n, 2 ≤ m, n ≤ 5·10⁴, затем p(1) … p(n), затем q₁ … q_m,
0 ≤ qᵢ ≤ 10⁹.

## Выходные данные

n компонент q × A.

## Примеры

### Пример 1

Ввод:

```
3 4
3 2 4 1
3 5 8
```

Вывод:

```
37 32 41 50
```

## Решение

Разобьём p на циклы. На цикле c₀, c₁, …, c_{L−1} с p(c_s) = c_{s+1}
(индексы по модулю L) pᵗ(c_s) = c_{(s+t) mod L}. Свернём q по остатку t
по модулю L: Q[r] — сумма q_t по t ≡ r (mod L). Тогда
v[c_s] = Σ_r Q[r] · c_{(s+r) mod L} — циклическая корреляция длины L.
Свёртка q зависит только от L, а различных длин циклов не больше
примерно √(2n), так что свёртки стоят O(m √n).

Корреляция — это произведение многочленов: перевёрнутый Q, умноженный
на цикл, записанный дважды, даёт v[c_s] коэффициентом s + L − 1.
Значения доходят до 5·10⁴ · 5·10⁴ · 10⁹ = 2.5·10¹⁸, поэтому произведение
должно быть точным. C++, Go, Java и Rust используют
теоретико-числовое преобразование по трём простым модулям (998244353,
167772161, 469762049) и собирают коэффициенты методом Гарнера; результат
меньше 2⁶³, поэтому 64-битная арифметика с переполнением даёт его
точно. Python упаковывает каждую последовательность в одно длинное
целое, по десять байт на число, перемножает два числа и читает
коэффициенты обратно: ни один коэффициент не вылезает за свои десять
байт. Короткие циклы (до 32) суммируются напрямую. Произведения дают
O(n log n) с NTT, O(n^(log₂ 3)) с умножением Карацубы в Python.

В примере p — цикл 1 → 3 → 4 → 1 и неподвижная точка 2, и
v[2] = (3 + 5 + 8) · 2 = 32.
