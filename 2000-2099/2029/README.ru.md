# 2029. Расстояние до произвольного расположения дисков

[Timus 2029](https://acm.timus.ru/problem.aspx?space=1&num=2029) · сложность 601 · math

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть три стержня `A`, `B`, `C` и `n` дисков различных размеров от 1 до
`n`. Изначально все находятся на `A`, меньшие выше больших. За ход
верхний диск переносится на другой стержень, пустой либо с большим
верхним диском. Найдите минимальное число ходов до заданного
расположения. Символ на позиции `i` с единицы задаёт стержень диска
размера `i`: первым записан самый маленький. На каждом стержне порядок
однозначно задан размерами, поэтому любая строка из `A,B,C` допустима.

Ограничения: `1 ≤ n ≤ 50`, 1 секунда, 64 МБ. Для существующего ответа
обещано не более `10^18`; на самом деле все допустимые состояния
достижимы за не более `2^n-1` ходов.

## Входные данные

Первая строка содержит `n`, вторая — ровно `n` заглавных букв `A`, `B`, `C`.

## Выходные данные

Минимальное число ходов. Формат разрешает `-1` для недостижимого состояния,
но доказательство ниже показывает достижимость всех корректных входов.

## Проверка

Ответы сравниваются по токенам.

## Решение

Рассмотрим подзадачу: все `m` оставшихся дисков начинают на стержне `s`.
Если целевой стержень наибольшего диска `m` тоже `s`, оставим его и решим
меньшую подзадачу с тем же началом. Иначе обозначим цель через `d`, третий
стержень через `u`. Перенесём всю башню из `m-1` дисков с `s` на `u`,
переместим диск `m` на `d`, затем решим меньшую цель с началом на `u`.
Первые две части требуют `(2^(m-1)-1)+1 = 2^(m-1)` ходов.

Обоснуем оптимальность. Полный перенос башни имеет стоимость `T(m)=2^m-1`.
До первого движения диска `m` все меньшие должны собраться на третьем стержне,
что требует не менее `T(m-1)` ходов. После его последнего движения на цель
меньшей башне нужно ещё `T(m-1)` ходов. Обычная рекурсивная конструкция
с одним движением наибольшего достигает `T(m)=2T(m-1)+1`.

Предложенная конструкция произвольной цели по индукции занимает не более
`2^m-1` ходов: либо двигаются только меньшие, либо первые части стоят `2^(m-1)`,
а остаток — не более `2^(m-1)-1`. Это одновременно доказывает достижимость.

Допустимость движения меньших дисков не зависит от положения наибольшего:
каждый из них помещается и на него, и на пустой стержень. Если наибольший
повторно посещает один стержень, удалим его движения между посещениями,
сохранив все движения меньших. Получится корректный более короткий путь
с тем же концом. Значит, его маршрут в оптимуме простой. Если начало и цель
совпадают, движений нет. Иначе остаются один прямой ход или два через `u`.
Два хода `s→u→d` требуют сначала перенести меньшую башню с `s` на `d`,
затем с `d` на `s`, плюс два движения наибольшего: не менее
`2T(m-1)+2 = 2^m`. Это хуже прямой конструкции. Поэтому при разных стержнях
наибольший двигается ровно один раз, и указанная рекурсия оптимальна.

Вычислим её проходом: `source = A`, ответ ноль, индексы от `n-1` до 0.
Если целевой стержень позиции `i` отличается от `source`, добавляем `2^i`
и заменяем `source` третьим стержнем. Иначе ничего не меняем. Для кодов 0, 1, 2
третий стержень равен `3-source-target`. Переменная `source` обозначает
начальный угол подзадачи меньших дисков.

В первом примере состояние уже начальное: ноль. Во втором переносится
полная башня из четырёх дисков: `2^4-1=15`. Для `BCCBABC` проход от
наибольшего добавляет `64+16+8+4+2+1=95`; диск 6 уже находится на нужном
стержне своей подзадачи.

Время — `O(n)`, состояние прохода — `O(1)`, хранение входа — `O(n)`.
Решения не строят последовательность ходов или экспоненциальный граф состояний.

Подводные камни:

- В строке диски идут от меньшего к большему, а обрабатываются наоборот.
- Начальный стержень меньшей подзадачи меняется только при добавлении
  слагаемого.
- Цель не обязана лежать на одном фиксированном оптимальном пути из
  полной `A` в полную `B`.
- Для сдвига нужна 64-битная единица: `2^50-1 = 1125899906842623` не
  помещается в 32 бита.
- Случай недостижимости для корректных назначений здесь не возникает.

## Особенности языков

До сдвига используются C++ `1LL`, Go `int64(1)`, Java `1L`, Rust
`1_u64`. В Python целые точные. Коды стержней — обычные целые;
беззнаковое вычисление третьего стержня в Rust безопасно внутри ветки
разных стержней. Вещественные степени не нужны.
