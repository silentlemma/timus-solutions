# 2029. 到任意圆盘状态的距离

[Timus 2029](https://acm.timus.ru/problem.aspx?space=1&num=2029) · 难度 601 · math

原题作者 Nikita Sivukhin 和 Édouard Lucas，出自 2014 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `A`、`B`、`C` 三根柱和大小为 1 至 `n` 的不同圆盘，初始全在 `A`，小盘位于大盘上方。
每次将一根柱最上面的盘移到另一根空柱或更大的顶盘上。求到给定目标状态的最少移动数。
字符串从一开始的第 `i` 个位置表示大小为 `i` 的盘所在柱，因此最小盘在前。
同柱顺序由大小唯一决定，所以任意 `A,B,C` 字符串都表示合法状态。

限制：`1 ≤ n ≤ 50`、1 秒、64 MB。存在的答案保证不超过 `10^18`；实际上全部合法目标都可达，且至多 `2^n-1` 步。

## 输入

第一行是 `n`，第二行恰有 `n` 个大写字母 `A`、`B`、`C`。

## 输出

输出最少移动数。格式允许不可达时输出 `-1`，但下面证明所有合法输入都可达。

## 评测方式

按记号逐个比较输出。

## 样例

```
1
A
```

```
0
```

```
4
BBBB
```

```
15
```

```
7
BCCBABC
```

```
95
```

## 解法

考虑剩余 `m` 个盘全从柱 `s` 出发的子问题。如果最大盘 `m` 的目标还是 `s`，保留它，继续较小子问题。
否则设目标为 `d`、第三柱为 `u`：把全部 `m-1` 小盘移到 `u`，把最大盘移到 `d`，
再从小盘全在 `u` 的角状态完成剩余目标。前两部分耗费 `(2^(m-1)-1)+1 = 2^(m-1)`。

先回顾完整塔移动费用 `T(m)=2^m-1`。最大盘首次移动前，小盘必须组成第三柱上的完整塔，至少需 `T(m-1)`；
最大盘最后一次移到目标后，小塔还需 `T(m-1)` 步。只移动最大盘一次的标准递归构造达到
`T(m)=2T(m-1)+1`。

上面的任意目标构造归纳地至多使用 `2^m-1` 步：要么仅移动小盘，要么前两部分花 `2^(m-1)`，
剩余至多 `2^(m-1)-1`。这也证明全部目标可达。

小盘移动是否合法与最大盘的位置无关，因为所有小盘均可放在它或空柱上。若最大盘重复访问某柱，
删除两次访问之间最大盘的移动，保留所有小盘移动，仍合法且终态不变，却严格更短。
所以最优解中最大盘的柱路径简单。起点等于终点时无需移动；不等时只有直接一步或经 `u` 两步。
两步路径 `s→u→d` 要求先将小塔从 `s` 移到 `d`，再从 `d` 移到 `s`，加上两次最大盘移动，
至少 `2T(m-1)+2 = 2^m`，已劣于直接构造。因此目标不同时最大盘恰移动一次，上述递推最优。

迭代计算：初始化 `source = A`、答案为零，按 `n-1` 至 0 的下标扫描。
若位置 `i` 的目标不同于 `source`，累加 `2^i` 并把 `source` 改为第三柱；否则不变。
柱编码为 0、1、2 时，第三柱为 `3-source-target`。`source` 是剩余小盘子问题的起始角。

第一个样例本来就在起点，答案零；第二个是四盘完整塔，答案 `2^4-1=15`。
`BCCBABC` 按最大盘起算累加 `64+16+8+4+2+1=95`，大小 6 的盘已经匹配其子问题起点。

时间 `O(n)`，扫描状态 `O(1)`，缓存输入占 `O(n)`。提交程序不构造完整移动序列或指数状态图。

注意事项：

- 输入最小盘在前，算法最大盘先处理。
- 只在加入贡献时更新较小子问题的起始柱。
- 目标不必位于完整 `A` 塔到完整 `B` 塔的某一固定最优路径上。
- 移位必须先使用 64 位一：`2^50-1 = 1125899906842623` 超过 32 位。
- 合法盘分配在本题没有不可达情况。

## 各语言说明

C++ 用 `1LL`、Go 用 `int64(1)`、Java 用 `1L`、Rust 用 `1_u64` 再移位，Python 整数精确。
柱号用普通整数。Rust 的无符号第三柱计算在两柱不同的分支内安全，不需要浮点幂。
