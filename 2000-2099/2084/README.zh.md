# 2084. 偿还技术债的任务顺序

[Timus 2084](https://acm.timus.ru/problem.aspx?space=1&num=2084) · 难度 3114 · dp, sorting

原题作者 Nikita Burlakov。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

债务初始为 X。N 个任务中每一个先把债务减少 aᵢ（不低于零），然后获得 max(0, bᵢ − D)，其中 D 是此时的债务。求总收益最大的任务顺序并输出。时间限制 2 秒，内存限制 256 MB。

## 输入

X 和 N（0 ≤ X ≤ 100，1 ≤ N ≤ 200），然后是 a₁ … a_N（0 到 100）和 b₁ … b_N（0 到 10⁶）。

## 输出

最大总收益，然后是获得它的任务顺序。任何这样的顺序都可接受。

## 评测方式

检查器比较总收益并重放输出的顺序。

## 样例

### 样例 1

输入：

```
5 3
0 1 5
5 1 0
```

输出：

```
6
3 2 1
```

### 样例 2

输入：

```
4 4
3 0 1 2
7 8 2 3
```

输出：

```
19
1 4 3 2
```

## 解法

债务从不超过 X，所以 b > X 的任务总比同一任务取 b = X 时多得 b − X；这部分在最后加上，之后所有 b 都不超过 X。记 rᵢ 为截至并包括任务 i 的总修复量。则债务为 X − min(X, rᵢ)，任务获得 max(0, min(X, rᵢ) − (X − bᵢ))。

取一个最优顺序，把收益为零的任务称为放弃的。把它们移到最前面只会增加其他任务看到的修复量，所以放弃的任务可以先做。其余每个任务获得 min(X, rᵢ) − (X − bᵢ)，第二部分之和与顺序无关。第一部分是截断到 X 的修复量前缀和，当任务按 a 降序排列时在每个位置都最大。反过来，对任意放弃集合，这个顺序获得的不少于公式值，因为真实收益不会小于零。所以答案是公式在所有放弃集合上的最大值。

把任务按 a 升序排序。若保留的任务在放弃的任务之后按降序进行，则任务 k 看到的是排序表中它之前的放弃任务加上从 k 起的所有任务。因此在排序表上做 DP，保存 s——目前为止放弃任务的修复量（截断到 X，更大没有区别）：保留的任务获得 min(X, s + suffix_k) − (X − b_k)，放弃的任务把它的 a 加到 s 上。记录的选择给出顺序：先放弃的任务，再按 a 降序的保留任务。DP 复杂度 O(N · (X + 1))，另加排序。

第一个样例中第三个任务先修复全部 5 个单位，然后第二、第一个任务分别获得 1 和 5，共 6。
