# 2011. 是否至少有六种不同排列

[Timus 2011](https://acm.timus.ru/problem.aspx?space=1&num=2011) · 难度 103 · combinatorics

原题作者 Alexey Kungurtsev，出自 2013 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给出 `n` 个符号，每个属于三种类型之一。用全部符号恰好组成一个长为 `n` 的词，相同符号不可区分。判断能否得到至少六个不同的词。每个给定符号必须恰好使用一次。

## 输入

第一行为 `n`，`1 ≤ n ≤ 100`。第二行为 `n` 个 1 到 3 的整数，表示类型。时间限制 0.5 秒，内存 64 MB。

## 输出

若至少有六个不同词，输出 `Yes`，否则输出 `No`。大小写必须一致，唯一答案按标记比较。

## 评测方式

按记号逐个比较输出。

## 样例

```
6
1 2 2 3 3 3
```

```
Yes
```

三类数量为 1、2、3，共有 `6!/(1!·2!·3!)=60` 个不同词，所以输出 `Yes`。

## 解法

长度为 `i` 的前缀若各类数量为 `c1,c2,c3`，不同词数为 `i!/(c1!·c2!·c3!)`，因为交换相同符号不改变词。完整阶乘会使定长整数溢出，但这里只需达到六。

开始时三个数量为零，空前缀有 `ways=1`。按输入顺序添加符号。类型 `v` 的数量增加到 `c`，前缀长度增加到 `i` 后，更新 `ways = ways·i/c`。先乘后除。除法必定整除：分子的阶乘增加因子 `i`，分母只有新增类型的阶乘增加因子 `c`。

一旦 `ways≥6` 就返回 `Yes`。即使仍有剩余符号，答案也不会改变：把同一份固定的剩余序列接到每个不同前缀词后，完整词依旧不同且恰好用完全部符号。若从未达到六，则最后的精确词数小于六，返回 `No`。

由归纳可知，返回前每个计数都精确，因为更新正是相邻多项式系数的比值。固定后缀的单射保证提前肯定答案有效；没有提前返回时，最终精确计数直接决定答案。因此算法正确。

每次更新前 `ways≤5`、`i≤100`，乘积至多 500，普通整数足够，无需取模、舍入、近似截断或大阶乘。用下标 `v−1` 存三个数量。五个同类加一个异类恰有六种，而四个同类加一个异类只有五种。所有符号相同时始终只有一种。

时间为 `O(n)`，计数状态只需 `O(1)` 额外空间；完整程序存储输入符号，总空间为 `O(n)`。另一种办法是按三类数量相乘组合数，并在达到同一阈值时停止。

## 各语言说明

不同副本不能当作带编号的符号计数；恰好六种也满足要求。不可先除 `ways/c`，中间结果未必整除。不可截断到六后还继续使用精确递推，应立即返回。五种语言均先乘后做整数除法。Python 求解器不计算大数，使用 CPython。Go 1.14、Java 8、Rust 1.75 只需普通整数与固定计数数组。
