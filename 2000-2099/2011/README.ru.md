# 2011. Не меньше шести различных перестановок

[Timus 2011](https://acm.timus.ru/problem.aspx?space=1&num=2011) · сложность 103 · combinatorics

Автор оригинальной задачи — Алексей Кунгурцев; Уральская региональная командная олимпиада по программированию 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны `n` символов трёх возможных типов. Все символы нужно расположить в
слово длины `n`; одинаковые символы неразличимы. Определите, существует
ли хотя бы шесть разных слов. Каждый имеющийся символ используется ровно
один раз.

## Входные данные

В первой строке дано `n`, `1 ≤ n ≤ 100`. Во второй — `n` целых чисел от
1 до 3, обозначающих типы символов. Лимит времени 0,5 секунды, памяти 64
МБ.

## Выходные данные

Выведите `Yes`, если разных слов не меньше шести, иначе `No`. Регистр
важен. Единственный ответ сравнивается по токенам.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
6
1 2 2 3 3 3
```

```
Yes
```

Кратности типов равны 1, 2 и 3. Число разных слов `6!/(1!·2!·3!)=60`,
поэтому ответ `Yes`.

## Решение

Кусочки одного вида одинаковы, поэтому из k кусочков, среди которых
c₁, c₂, c₃ каждого вида, получается k!/(c₁!·c₂!·c₃!) разных слов. Читаем
кусочки по одному и храним это число для прочитанных: когда приходит
k-й кусочек и его вид теперь встречается c раз, число умножается на k и
делится на c нацело. Как только число достигает 6, ответ `Yes`:
оставшиеся кусочки, дописанные в одном и том же порядке, оставят слова
разными. Если 6 так и не набирается, ответ `No`. `O(n)`.

Перед каждым шагом число не больше 5, поэтому 5 · 100 помещается в
любой целый тип; умножать надо до деления.

Подводные камни:

- ровно шесть слов — это уже `Yes`;
- полные факториалы считать нельзя: они переполняются.

## Оптимизированные решения

Оптимизированное решение на C++ считает значения сразу при чтении через
`scanf` вместо `iostream` и вектора и выводит ответ, как только он
известен: 116 КБ вместо 380 КБ при том же времени.
