# 2011. Не меньше шести различных перестановок

[Timus 2011](https://acm.timus.ru/problem.aspx?space=1&num=2011) · сложность 103 · combinatorics

Автор оригинальной задачи — Алексей Кунгурцев; Уральская региональная командная олимпиада по программированию 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны `n` символов трёх возможных типов. Все символы нужно расположить в
слово длины `n`; одинаковые символы неразличимы. Определите, существует
ли хотя бы шесть разных слов. Каждый имеющийся символ используется ровно
один раз.

## Входные данные

В первой строке дано `n`, `1 ≤ n ≤ 100`. Во второй — `n` целых чисел от
1 до 3, обозначающих типы символов. Лимит времени 0,5 секунды, памяти 64
МБ.

## Выходные данные

Выведите `Yes`, если разных слов не меньше шести, иначе `No`. Регистр
важен. Единственный ответ сравнивается по токенам.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
6
1 2 2 3 3 3
```

```
Yes
```

Кратности типов равны 1, 2 и 3. Число разных слов `6!/(1!·2!·3!)=60`,
поэтому ответ `Yes`.

## Решение

Для префикса длины `i` с кратностями `c1,c2,c3` число разных слов равно
`i!/(c1!·c2!·c3!)`: перестановка одинаковых символов слова не меняет.
Полные факториалы переполняют обычные целые. Нам достаточно достичь
шести.

Начинаем с нулевых кратностей и `ways=1` для пустого префикса.
Рассматриваем символы в исходном порядке. При добавлении типа `v`
увеличиваем его кратность до `c`, длину префикса до `i` и вычисляем
`ways = ways·i/c`. Сначала умножаем, затем делим. Деление точное: в
числителе формулы появляется множитель `i`, а в знаменателе — только
множитель `c` факториала добавленного типа.

Как только `ways≥6`, отвечаем `Yes`. Оставшиеся символы уменьшить число
вариантов не могут: допишем одну и ту же фиксированную оставшуюся
последовательность к каждому различному слову префикса. Полные слова
сохранят различия и используют все символы. Если ни один префикс не
достиг шести, конечное точное число меньше шести и ответ `No`.

По индукции хранимое число точно на каждом шаге до возврата: обновление
равно отношению соседних мультиномиальных коэффициентов. Дописывание
доказывает корректность раннего положительного ответа. Без раннего
возврата проверяется точное конечное число. Вместе это доказывает
алгоритм.

Перед обновлением `ways≤5`, а `i≤100`, поэтому произведение не больше
500. Достаточно обычного целого типа; округлений, остатков, неточного
насыщения и переполнения факториалов нет. Три кратности хранятся по
индексу `v−1`. Пять одинаковых символов и один другой дают ровно шесть
слов; четыре одинаковых и один другой — лишь пять. При одном типе всегда
получается одно слово.

Время `O(n)`, дополнительное состояние счётчика `O(1)`. Полные программы
сохраняют входные символы, поэтому суммарная память `O(n)`. Альтернатива
— перемножать биномиальные коэффициенты по трём кратностям, прекращая
вычисления при достижении того же порога.

## Особенности языков

Нужны разные слова, а не перестановки пронумерованных экземпляров. Ровно
шесть тоже подходит. Нельзя сначала делить `ways` на `c`: промежуточное
частное может быть нецелым. Нельзя ограничить число шестью, а затем
продолжить формулу для точного значения; вместо этого сразу возвращаем
ответ. Во всех пяти реализациях целочисленное деление следует за
умножением. Решатель Python не вычисляет больших чисел и работает в
CPython. Go 1.14, Java 8 и Rust 1.75 используют обычные целые и массив
трёх счётчиков.
