# 2048. 按十三日星期五的次数分类年份

[Timus 2048](https://acm.timus.ru/problem.aspx?space=1&num=2048) · difficulty 901 · implementation

原题作者 Alexander Ipatov（由 Oleg Dolgorukov 整理），出自 2015 年乌拉尔体育编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对公历中从 A 到 B 的每一年，统计 13 日是星期五的月份数；对 0 到 12 的每个 k，输出恰好有 k 个这样月份的年数。能被 400 整除，或能被 4 整除但不能被 100 整除的年份是闰年，此时二月有 29 天。时间限制 1 秒，内存限制 64 MB。

## 输入

两个整数 A 和 B，1919 ≤ A ≤ B ≤ 10⁹。

## 输出

按 k = 0, …, 12 递增输出十三行 `k: count`，包括计数为零的行。

## 评测方式

按记号逐个比较输出。

## 样例

```
2015 2016
```

```
0: 0
1: 1
2: 0
3: 1
4: 0
5: 0
6: 0
7: 0
8: 0
9: 0
10: 0
11: 0
12: 0
```

2015 年二月、三月和十一月十三日符合，所以桶三有一年。2016 年只有五月十三日符合，桶一有一年。其他桶均为零，仍需输出全部十三个标签。

## 解法

### 建立一个日历周期

以星期一为零、星期日为六。在延伸格里高利历中，第一年一月一日为星期一。维护当前月第一天的星期 `w`，十三日为 `(w+12) mod 7`，等于星期五的编号四时计数。每月结束后将 `w` 增加实际月长并模七。

模拟 `1..400` 年，令 `type[y-1]` 存第 `y` 年的符合月份数，再将四百个类型汇成十三桶直方图 `cycle`。闰日只在完整闰年规则成立时加入二月。

闰年模式每四百年重复。一个周期有 `400/4-400/100+400/400=97` 个闰年，总天数 `400*365+97=146097=7*20871`，因此下个周期起始星期也不变。相同月长和相同起始星期证明每年类型以 400 年为周期。

### 年份前缀直方图

令 `F(t)` 为 `1..t` 年的十三桶计数，写成 `t=400q+r`、`0≤r<400`。先取 `q*cycle`，再将保存类型的前 `r` 年各自所在桶加一。逐桶计算 `F(B)-F(A-1)` 即可。

### 正确性

逐月计算从已知星期开始，每步恰好前进实际月长，因此归纳得到每个十三日和第一周期每年类型的正确值。四百年的总天数及闰年规则重复性证明其后类型相同。

`1..t` 年分为 `q` 个不相交完整周期及一个 `r` 年前缀，每个完整周期贡献 `cycle`，余下部分恰是前 `r` 个保存类型。因此计算得到准确 `F(t)`。从截至 `B` 的各桶计数中减去截至 `A-1` 的计数，恰好留下含两端的 `A..B`。

周期 `C=400` 时，时间 `O(C*12+C+13)`、额外空间 `O(C+13)`，与输入年份区间宽度无关，均为常量。算法不逐年遍历 `A..B`。

## 各语言说明

- 十三日距一日为十二天，不是十三天。
- 类型数组从第一年开始，索引是 `(year-1) mod 400`。
- 应减 `F(A-1)`，端点相同也不例外。
- 只检查被四整除不够：2100 非闰年，2000 与 2400 为闰年。
- 必须输出零桶，统计年份而非月份。

五个版本均只建立一次日历，用于两次前缀查询。编译语言使用 64 位计数，Python 使用整数。求解程序不依赖日期库，也不硬编码整个分布。
