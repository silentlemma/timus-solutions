# 2048. Распределение лет по числу пятниц тринадцатого

[Timus 2048](https://acm.timus.ru/problem.aspx?space=1&num=2048) · difficulty 900 · implementation

Автор оригинальной задачи — Александр Ипатов; подготовка — Олег Долгоруков. XIX Открытый чемпионат Урала по спортивному программированию (апрель, 2015).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для каждого года от A до B по григорианскому календарю посчитайте
месяцы, у которых 13-е число приходится на пятницу, и для каждого k от 0
до 12 выведите, сколько лет имеют ровно k таких месяцев. Год високосный,
если делится на 400 или делится на 4, но не на 100; тогда в феврале 29
дней. Ограничения: 1 секунда и 64 МБ.

## Входные данные

Два целых числа A и B, 1919 ≤ A ≤ B ≤ 10⁹.

## Выходные данные

Тринадцать строк `k: count` для k = 0, …, 12 по возрастанию, включая
нулевые.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
2015 2016
```

```
0: 0
1: 1
2: 0
3: 1
4: 0
5: 0
6: 0
7: 0
8: 0
9: 0
10: 0
11: 0
12: 0
```

В 2015 году подходят 13 февраля, 13 марта и 13 ноября, поэтому один год
попадает в группу три. В 2016 подходит только 13 мая, давая один год в
группе один. Остальные группы нулевые; все тринадцать меток всё равно
выводятся.

## Решение

### Один календарный период

Нумеруем дни недели от понедельника ноль до воскресенья шесть. В
продолженном григорианском календаре 1 января первого года —
понедельник. Поддерживаем день недели `w` первого числа текущего месяца.
Тринадцатое имеет день `(w+12) mod 7`; он должен равняться пятнице,
четырём. После месяца увеличиваем `w` на фактическую длину месяца по
модулю семь.

Моделируем годы `1..400`, сохраняя в `type[y-1]` количество подходящих
месяцев года `y`. По четырёмстам значениям строим гистограмму `cycle` из
тринадцати групп. Дополнительный февральский день учитывается по полному
правилу високосности.

Високосность повторяется через 400 лет. За период есть
`400/4-400/100+400/400=97` високосных лет и `400*365+97=146097=7*20871`
дней. Поэтому начальный день недели следующего периода совпадает с
прежним. Длины месяцев и начальные дни недели полностью повторяются,
значит, повторяется и тип каждого года.

### Гистограмма префикса лет

Пусть `F(t)` — тринадцать количеств для лет `1..t`. Представим
`t=400q+r`, где `0≤r<400`. Берём `q*cycle` и добавляем по единице в
группы первых `r` сохранённых типов. Ответ равен покомпонентной разности
`F(B)-F(A-1)`.

### Доказательство

Месячная рекуррентность начинается с известного дня недели и каждый раз
продвигается ровно на длину месяца. По индукции она правильно определяет
все тринадцатые числа и типы лет первого периода. Число дней в 400 годах
и периодическое правило високосности доказывают повторение этих типов
дальше.

Годы `1..t` распадаются на `q` непересекающихся полных периодов и
префикс из `r` лет. Полный период даёт `cycle`, остаток — ровно типы
первых `r` лет. Следовательно, формула вычисляет `F(t)`. Вычитание лет
до `A-1` из лет до `B` оставляет в каждой группе в точности
включительный отрезок `A..B`.

При длине периода `C=400` время — `O(C*12+C+13)`, дополнительная память
— `O(C+13)`. Обе оценки постоянны относительно длины исходного
диапазона. Перебора всех лет от `A` до `B` нет.

## Особенности языков

- От первого до тринадцатого проходит двенадцать дней, не тринадцать.
- Массив начинается с первого года, поэтому индекс равен `(year-1) mod 400`.
- Вычитается `F(A-1)`, в том числе при одинаковых концах отрезка.
- Делимости на четыре недостаточно: 2100 обычный, 2000 и 2400 високосные.
- Нулевые группы тоже печатаются; считаются годы, а не месяцы.

Все пять реализаций один раз строят календарь и используют его для двух
префиксных гистограмм. Компилируемые языки хранят количества в 64 битах,
Python — в целых числах. В решениях не нужны библиотека дат и заранее
вшитое распределение.
