# 2001. Mathematicians and Berries

[Timus 2001](https://acm.timus.ru/problem.aspx?space=1&num=2001) · 难度 22 · math

原题作者 Oleg Merkurev. (Prepared by Kirill Devyatkin)，出自 2013 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两篮子称重三次。最初各自装有浆果；随后把第二篮所有浆果倒入第一篮并分别称重；最后把第一篮全部浆果倒入第二篮，再称两篮。篮子自重不变，求原本各篮浆果重量。

## 输入

按时间顺序给三对 `a1 b1`、`a2 b2`、`a3 b3`，每个整数读数在 0–10000，数据符合所述转移。时间 0.5 秒、内存 64 MB。

## 输出

依次输出第一、第二篮原有浆果重量。

## 评测方式

按记号逐个比较输出。

## 样例

```
1 2
2 1
0 3
```

```
1 1
```

最后第一篮为空，自重为 0；中间第二篮为空，自重为 1。从初始读数 1、2 分别减去对应自重，得到 1、1。

## 解法

设两个空篮子重 c 和 d，浆果重 x 和 y。第一次称重得到 a1 = c + x 和 b1 = d + y。
把第二个篮子倒进第一个之后，b2 = d；把第一个倒进第二个之后，a3 = c。因此
x = a1 − a3，y = b1 − b2；读数 a2 和 b3 用不上。`O(1)`。

## 优化解法

优化解法（C++、Java）计算同样的两个差。C++ 用 `scanf` 中的 `%*d` 跳过读数 a2 和
b3，而不是用 `iostream`：124 KB，而不是 396 KB，时间不变。Java 从 `System.in` 手
工解析数字，而不是使用 `Scanner`：0.125 s，而不是 0.156 s；344 KB，而不是
1608 KB。
