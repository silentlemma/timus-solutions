# 2001. Mathematicians and Berries

## 任务

两篮子称重三次。最初各自装有浆果；随后把第二篮所有浆果倒入第一篮并分别称重；最后把第一篮全部浆果倒入第二篮，再称两篮。篮子自重不变，求原本各篮浆果重量。

## 输入

按时间顺序给三对 `a1 b1`、`a2 b2`、`a3 b3`，每个整数读数在 0–10000，数据符合所述转移。时间 0.5 秒、内存 64 MB。

## 输出

依次输出第一、第二篮原有浆果重量。

## 评测方式

按记号逐个比较输出。

## 样例

```
1 2
2 1
0 3
```

```
1 1
```

最后第一篮为空，自重为 0；中间第二篮为空，自重为 1。从初始读数 1、2 分别减去对应自重，得到 1、1。

## 解法

设空篮重 `c,d`，初始浆果重 `x,y`，则 `a1=c+x`、`b1=d+y`。第二篮倒空后 `b2=d`，第一篮倒空后 `a3=c`，因此唯一答案 `x=a1−a3`、`y=b1−b2`。

代回等式即可证明两差就是原有内容物。其余读数 `a2=c+x+y`、`b3=d+x+y` 仍须读入，但不必用于恢复。没有除法、搜索或舍入。

固定六个读数，时间 `O(1)`、空间 `O(1)`。合法差值在 0–10000，有符号 32 位足够。

减去同一只空篮的自重：第一篮用 `a3`，第二篮用 `b2`。合并读数 `a2,b3` 仍含篮重。保持输出顺序，零浆果、零篮重均正常处理。
