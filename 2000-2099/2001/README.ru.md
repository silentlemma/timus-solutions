# 2001. Математики и ягоды

## Задача

Две корзины взвешивают трижды. Сначала каждая содержит собственные
ягоды. Затем всё содержимое второй пересыпают в первую и снова
взвешивают обе. Наконец все ягоды из первой пересыпают во вторую и
повторяют измерения. Найти первоначальные массы ягод, учитывая
неизменную массу самих корзин.

## Входные данные

Три пары `a1 b1`, `a2 b2`, `a3 b3` в порядке измерений. Каждое показание
целое от 0 до 10000. Данные соответствуют описанным пересыпаниям.
Лимиты: 0,5 секунды и 64 МБ.

## Выходные данные

Первоначальная масса ягод в первой и второй корзине именно в таком порядке.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
1 2
2 1
0 3
```

```
1 1
```

Первая корзина пуста на последнем измерении, поэтому её масса 0. Вторая
пуста на среднем измерении и весит 1. Вычитая их из первоначальных
показаний 1 и 2, получаем 1 и 1.

## Решение

Пусть пустые корзины весят `c,d`, а исходные ягоды — `x,y`. Тогда
`a1=c+x`, `b1=d+y`. После опустошения второй корзины `b2=d`, после
опустошения первой `a3=c`. Единственный ответ: `x=a1−a3`, `y=b1−b2`.

Подстановка доказывает, что обе разности точно равны исходному
содержимому. Остальные измерения имеют вид `a2=c+x+y`, `b3=d+x+y`; они
считываются, но для восстановления не нужны. Деления, поиска и
округления нет.

Время `O(1)`, память `O(1)` для фиксированных шести показаний. При
корректных данных разности лежат от 0 до 10000, достаточно знакового
32-битного типа.

Вычитать массу той же пустой корзины: для первой `a3`, для второй `b2`.
Общие показания `a2,b3` тоже включают корзину. Сохранять порядок ответа;
нулевые массы ягод или пустых корзин не требуют особых случаев.
