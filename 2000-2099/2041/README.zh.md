# 2041. 相邻边界严格兼容的排列

[Timus 2041](https://acm.timus.ru/problem.aspx?space=1&num=2041) · difficulty 2106 · greedy, dsu

原题作者 Oleg Merkurev，出自 2014 年夏季彼得罗扎沃茨克集训营乌拉尔联邦大学 Dandelion 专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `n` 个带编号的对象，第 `i` 个对象的内部体积为 `a_i`，外部体积为 `b_i`。排列全部对象，使每一对相邻对象 `u,v` 都满足严格不等式 `b_u>a_v`。只约束相邻对象。判断是否存在这样的排列，存在时构造一个。

## 输入

第一行是 `2≤n≤100000`。随后 `n` 行各有 `a_i,b_i`，满足 `1≤a_i≤b_i≤1000000`。允许内部和外部体积相等。编号是输入顺序中的 `1..n`。时间限制 1 秒，内存限制 64 MB。

## 输出

不存在时输出 `No`。否则输出 `Yes` 和全部 `n` 个编号的一个排列。任意合法排列都可接受。

## 评测方式

检查器验证编号范围、唯一性、标记数量和每一对相邻对象的严格不等式。对 `No`，独立计算下文的点对象数量和严格跨越某体积的区间数量。无需与某个固定的参考排列相同。

## 样例

```
3
1 5
2 2
6 7
```

```
Yes
3 1 2
```

```
3
2 2
2 2
3 4
```

```
No
```

第一个示例的 `3,1,2` 满足 `7>1` 和 `5>2`。程序也可能输出同样合法的 `3,2,1`。第二个示例中，两个 `(2,2)` 之间必须把外部体积提升到大于 `2`；`(3,4)` 不能紧随 `(2,2)`，因此无法完成这个过渡。

## 解法

### 选择最大的可用内部体积

设 `B` 为上一个已选对象的外部体积，初始取 `B=max(b_i)+1`。从未使用的对象中选择最大的 `a_i<B`，内部体积相同时选择最大的 `b_i`。加入原编号，把 `B` 改为该对象的 `b_i` 并删除它。两种体积都相同时编号顺序任意；实现选择最大编号。如果还未用完对象就没有可选对象，输出 `No`。

外部体积的第二优先级不可省略：对于 `(2,2),(2,3)`，必须先选第二个。先选点对象会错误地陷入死路。

### 失败为什么能证明无解

把 `a<b` 的对象称为区间，把 `(x,x)` 称为位于 `x` 的点。每个未使用区间始终可选。若可选区间 `v` 未被选择，本次选中的 `u` 满足 `a_u≥a_v`。若严格大于，则 `b_u≥a_u>a_v`；若相等，第二优先级保证 `b_u≥b_v>a_v`。所以 `v` 下一步仍然可选。初始所有对象可选，归纳可知算法失败时只可能剩下点。

固定一个体积 `x`，令 `K(x)` 是位于 `x` 的点数，`T(x)` 是满足 `a<x<b` 的区间数。任意合法排列都必须满足 `K(x)≤T(x)+1`。相邻两次出现点 `x` 之间，外部体积必须第一次从不大于 `x` 提升为大于 `x`。第一次完成提升的对象满足 `b>x`，而前一条合法边又要求 `a<x`。因此 `K(x)-1` 个互不重叠的间隔各需要一个不同的严格跨越区间。

假设贪心失败，取一个仍未使用的点 `x`。只要 `B>x`，该点就可选，因此选中对象的内部体积至少为 `x`。这种阶段不可能把 `B` 降到 `x` 以下，只能通过选择一个位于 `x` 的点结束，使 `B=x`。跨越 `x` 的区间内部体积小于 `x`，所以不会在该阶段被选择。每个这样的区间只能在 `B≤x` 时被选中，并开启新阶段 `B>x`。失败时 `B≤x`，且由不变量可知所有区间均已使用。于是一个初始阶段和 `T(x)` 个后续阶段各消耗一个点 `x`，共消耗 `T(x)+1` 个；还至少剩一个，得到 `K(x)>T(x)+1`，违反任何合法排列的必要条件。

成功时所有边按构造合法，失败时则给出了无解证据。这也证明了对每个 `x` 分别成立的计数条件是充分条件。不要把它改成跨所有点类的全局匹配：同一个区间可能在一个排列中帮助多个不同的体积。

### 删除后的前驱查询

把三元组 `(a,b,编号)` 升序排序，位置为 `1..n`，另设哨兵 `0`。对 `B` 做 lower bound，得到满足 `a<B` 的位置数量 `c`。所需对象就是不超过 `c` 的最大未删除位置，排序自然实现两层优先级。

采用路径折半、按秩合并的并查集，并在根保存组件的最小位置 `best`。初始每个位置独立。删除可用位置 `p` 时，把它的组件与 `p-1` 的组件合并。组件始终是连续区间 `[l,r]`，其中 `(l,r]` 全部已删除，左端 `l` 仍可用或等于哨兵。因此 `best[find(c)]` 正好是所需前驱。根编号本身可能已经删除，必须使用保存的最小位置而非根编号。返回 `0` 表示无可选对象。所有查找均为迭代实现。

排序和 `n` 次二分查找耗时 `O(n log n)`，平衡并查集再用 `O(n α(n))`。总时间 `O(n log n)`，包括输出的空间为 `O(n)`。也可以用维护可用位置计数的树状数组实现 `O(n log n)` 前驱查询。

输入允许 `a=b`，但相邻条件必须严格。内部体积相同时先按外部体积决定优先级，最后才考虑编号。并查集根编号不等于可用前驱，必须读取保存的最小位置。跨越区间条件对每个点体积分开检查，因为同一个区间可以帮助多个点类。合法输出顺序可以不同于示例。

## 各语言说明

C++、Go 和 Rust 直接保存三元组及并查集数组。Go 使用兼容 1.14 的排序和缓冲输入输出；Rust 使用迭代二分查找和缓冲输出。Java 8 使用字节输入缓冲、三元组数组、字节秩和 StringBuilder。Python 逐行读取对象，使用排序三元组、`bisect_left` 和保存秩的 bytearray，迭代路径折半避免递归栈限制。所有版本保留从一开始的原编号，并用严格下界排除 `a=B`。
