# 2010. 空棋盘上的攻击格数

[Timus 2010](https://acm.timus.ru/problem.aspx?space=1&num=2010) · 难度 133 · math

民间题目，出自 2013 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在空的 `n×n` 棋盘上，把一枚棋子放在 `(x,y)`。分别求王、马、象、车、后一步攻击的格数。坐标均从 1 到 `n`，不计起点。没有其他棋子阻挡射线；马按通常的日字形跳跃。

## 输入

第一行是 `n`，`1 ≤ n ≤ 100,000,000`。下一行是 `x y`，`1 ≤ x,y ≤ n`。时间限制 0.5 秒，内存 64 MB。

## 输出

依次输出五行：`King: 数量`、`Knight: 数量`、`Bishop: 数量`、`Rook: 数量`、`Queen: 数量`。英文标签区分大小写。唯一的标签与整数按空白分隔的标记比较。

## 评测方式

按记号逐个比较输出。

## 样例

```
8
5 2
```

```
King: 8
Knight: 6
Bishop: 9
Rook: 14
Queen: 23
```

八个相邻格都在棋盘内，马有六个合法终点。象的四条射线长为 1、4、1、3，共 9 格。车在行、列上各攻击其余 7 格，共 14 格。后的答案是 `9+14=23`。

## 解法

只需到边界的距离，不建立或扫描棋盘。

王的第一坐标可以是 `x` 及存在的 `x−1,x+1`，数量为 `a=1+[x>1]+[x<n]`，方括号表示条件为真时取 1，否则为 0。第二坐标同理有 `b=1+[y>1]+[y<n]` 种。任意组合都至多走一步，因此答案是 `a·b−1`，减去起点；`n=1` 时自然得到零。

马只需检查八个不同偏移 `(±1,±2)` 和 `(±2,±1)`，当两个终点坐标均在 `1..n` 时计数。这些偏移没有重复，也不会到达起点。

象的每条射线在两个相应边界中较近的一处终止，四条长度为 `min(x−1,y−1)`、`min(x−1,n−y)`、`min(n−x,y−1)`、`min(n−x,n−y)`。相加即可：每个合法对角线终点属于且只属于一条射线，射线仅在已排除的起点相交。

车可以攻击同行及同列的所有其他格，各有 `n−1` 格。两部分唯一交点是已排除的起点，故答案为 `2(n−1)`。后把车与象的攻击合并；离开起点后，直线方向和对角线方向没有交点，因此两者相加，不再减一。这些计数完整覆盖合法目标并排除非法目标，证明五个结果正确。

固定次数的计算和八次马的检查使时间为 `O(1)`，额外空间为 `O(1)`。答案不超过 `4(n−1) ≤ 399,999,996`；实现使用 64 位整数或 Python 整数。使用有符号坐标以正确排除马的负坐标终点。另一种象的计数方法是把两条完整对角线与棋盘相交，再从每条去掉起点。

## 各语言说明

不能计入起点、第二步或越界的跳跃。车的答案与位置无关，象的答案则有关。后合并两个已去掉起点的集合，无需再减。单格棋盘用相同公式处理。Go 1.14 需要自定义最小值函数；Java 8 和 Rust 使用有符号宽整数。Python 只存常数个值，使用 CPython。
