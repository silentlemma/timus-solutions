# 2010. Число атакованных клеток пустой доски

[Timus 2010](https://acm.timus.ru/problem.aspx?space=1&num=2010) · сложность 133 · math

Задача из фольклора; Уральская региональная командная олимпиада по программированию 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На пустую доску `n×n` ставят одну фигуру в клетку `(x,y)`. Для короля,
коня, слона, ладьи и ферзя независимо найдите число клеток, атакуемых за
один ход. Координаты меняются от 1 до `n`. Исходную клетку не считают.
Других фигур и препятствий нет; конь выполняет обычный прыжок.

## Входные данные

В первой строке дано `n`, `1 ≤ n ≤ 100 000 000`, во второй — `x y`, `1 ≤
x,y ≤ n`. Лимит времени 0,5 секунды, памяти 64 МБ.

## Выходные данные

Выведите ровно пять строк в порядке `King: число`, `Knight: число`,
`Bishop: число`, `Rook: число`, `Queen: число`. Регистр названий важен.
Единственные правильные названия и целые числа сравниваются по токенам.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
8
5 2
```

```
King: 8
Knight: 6
Bishop: 9
Rook: 14
Queen: 23
```

Все восемь соседних клеток существуют. У коня остаётся шесть допустимых
назначений. Четыре диагональных луча имеют длины 1, 4, 1 и 3: всего 9.
Ладья атакует по 7 других клеток строки и столбца, всего 14. Для ферзя
получаем `9+14=23`.

## Решение

Достаточно расстояний до границ; строить или обходить доску нельзя.

У короля допустимы первая координата `x` и существующие соседи
`x−1,x+1`. Их число `a=1+[x>1]+[x<n]`, где скобки дают 1 при истинном
условии и 0 иначе. Для второй координаты аналогично `b=1+[y>1]+[y<n]`.
Любая пара находится не дальше одного шага; ответ `a·b−1` исключает
исходную клетку. При `n=1` формула даёт ноль.

Для коня проверяем восемь разных смещений `(±1,±2)` и `(±2,±1)`.
Прибавляем единицу, только если обе координаты назначения лежат в
`1..n`. Ни одно смещение не ведёт в исходную клетку.

Луч слона заканчивается при достижении ближайшей из двух границ. Четыре
длины равны `min(x−1,y−1)`, `min(x−1,n−y)`, `min(n−x,y−1)` и
`min(n−x,n−y)`. Их сумма считает все диагональные назначения ровно по
разу: каждое лежит на одном из лучей, а пересекаться лучи могут только в
исключённом начале.

Ладья атакует все остальные клетки строки и столбца: по `n−1` в каждом.
Общая клетка этих линий — только исходная, уже исключённая, поэтому
ответ `2(n−1)`. Диагональные и прямые атаки ферзя вне начала не
пересекаются. Следовательно, ответ ферзя — сумма ответов слона и ладьи
без дополнительного вычитания. Так учтены все и только допустимые клетки
для каждой фигуры, что доказывает правильность.

Число действий и восемь проверок коня не зависят от размера: время
`O(1)`, дополнительная память `O(1)`. Любой ответ не больше `4(n−1) ≤
399 999 996`; реализации используют 64-битные целые либо целые Python.
Знаковые координаты позволяют отвергать отрицательные назначения коня.
Альтернатива для слона — пересечь каждую из двух полных диагональных
прямых с доской и исключить исходную клетку из обеих.

## Особенности языков

Не включайте исходную клетку, второй ход или выходящие за границы
прыжки. Ответ ладьи не зависит от позиции, ответ слона зависит. После
сложения диагональных и прямых атак ферзя вычитать ничего не надо. Доска
`1×1` обрабатывается теми же формулами. В Go 1.14 нужен собственный
минимум, в Java 8 и Rust — знаковые широкие координаты. Python хранит
лишь постоянное число значений и запускается в CPython.
