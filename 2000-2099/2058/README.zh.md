# 2058. 奇数与偶数个回文的最少划分

[Timus 2058](https://acm.timus.ru/problem.aspx?space=1&num=2058) · difficulty 1673 · strings, dp

原题作者 Mikhail Rubinchik，出自 2015 年 7 月 11 日回文专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对字符串的每个前缀，把它划分为若干连续的回文，求片段数的最小奇数值和最小偶数值。时间限制 1 秒，内存限制 64 MB。

## 输入

一个由 1 到 300 000 个小写英文字母组成的字符串。

## 输出

共 n 行，每个前缀一行：最小的奇数片段数（不存在时为 `-1`）和最小的偶数片段数（不存在时为 `-2`）。

## 评测方式

按记号逐个比较输出。

## 样例

```
abaa
```

```
1 -2
-1 2
1 -2
3 2
```

前缀 `a` 只能有一段，`ab` 只能划分成 `a|b`。`aba` 本身为回文，也能分成三个字母。`abaa` 可分为 `aba|a` 与 `a|b|aa`，故偶数最少两段，奇数最少三段。

## 解法

### 前缀递推与回文树

令 `O[i],E[i]` 分别表示前缀最少的奇数、偶数段数，取无穷大 `n+1`，初始化 `O[0]=∞`、`E[0]=0`。若最后一段是长度 `L` 的回文后缀，则 `O[i]=min(E[i−L]+1)`、`E[i]=min(O[i−L]+1)`，最小值遍历所有回文后缀。这恰好枚举全部最后切点，并且增加一段一定改变奇偶性。

回文树的每个节点代表一个不同的回文串。两个根的长度为 `−1` 与 `0`；`link[v]` 指向最长的真回文后缀。加入字母时，从旧的最长后缀沿后缀链接寻找前一个字母与新字母相等的节点，再经对应转移扩展。新节点的后缀链接同样从其父节点的链接开始查找。至多新增当前最长后缀一个节点：更短的新后缀已经作为该回文的前缀出现。因此节点不超过 `n+2`。输入只含小写字母，前置零字节可以安全充当哨兵。

### 用等差系列压缩后缀链

定义 `d[v]=len[v]−len[link[v]]`。`sl[v]` 指向第一个差值不同的后缀：若当前与 `link[v]` 差值相同，则取 `sl[link[v]]`，否则取 `link[v]`。从 `v` 开始、不含 `sl[v]` 的链接链为一个系列，其长度以 `d[v]` 为公差。每一步只访问系列首节点 `last,sl[last],…`。

每个节点保存两个前驱最小值 `C_O[v],C_E[v]`。处理前缀末端 `i` 时，令 `b=i−len[sl[v]]−d[v]`，以 `O[b],E[b]` 初始化；这是最短系列成员前的切点。如果 `d[v]=d[link[v]]`，逐分量与 `link[v]` 的旧缓存取最小值。然后用 `C_E[v]+1` 更新 `O[i]`，用 `C_O[v]+1` 更新 `E[i]`。继承的缓存来自过去的前缀，不能每步清空，也不能当作当前末端的值重算。

### 旧缓存为何正好对应当前切点

考虑系列首节点 `v`，设 `u=link[v]` 与它差值相同，`d=d[v]`、`m=len[u]`。回文的最小周期等于其长度减去最长真回文边界长度，所以 `u` 的最小周期为 `d`，且 `m≥d`。在 `v` 内，`u` 的前缀和后缀出现位置相差 `d`。两者之间不能再出现 `u`：否则中间出现与最后出现是覆盖并集的相同回文两端，使该并集成为长于 `u` 的真回文后缀，矛盾。所用覆盖事实很简单：一个串的相同回文前后缀若长度至少为整个串的一半，每对镜像位置都因反射而相等。

在末端 `i−d`，`u` 必为系列首节点。否则后缀链中它前面有一个同差值节点 `z`，长度为 `m+d`。重叠的前后缀 `u` 唯一确定 `z=v`。此前与当前的两个 `v` 覆盖一个回文 `w`。若 `w` 有长于 `v` 的真回文后缀，该后缀开头的 `u` 会严格落在 `z` 内的两个端点出现之间，与上段结论矛盾。因此 `link[w]=v`，且 `d[w]=d`，这又违背 `v` 当前是系列首节点。`i−d` 和 `i` 之间没有另一次 `u` 出现；当前的 `u` 也不是系列首节点。所以读取的缓存恰好最后更新于 `i−d`。

当时 `u` 的系列包含当前系列除最长者以外的各长度。从 `i−d` 减去这些长度，得到当前系列除最短成员以外的全部前驱切点。初始化 `b` 补上缺失切点。因此两个缓存确为当前整个系列的分量最小值。结合完整递推，按前缀长度归纳即可证明所有答案及不可达标记正确。

### 系列数为何是对数级

回文的任何边界都是回文，所以 `d[v]` 确为最小周期。设某系列最后的节点为 `x`，`L=len[x]`、`B=len[link[x]]`、`p=L−B`。假设 `B≥2L/3`，则 `B≥2p`。该边界具有周期 `p`，其最小周期 `q≤p`。若 `q<p`，长度至少 `p+q`，所以 `gcd(p,q)` 也是周期。这个规则可用欧几里得减法证明：在长度至少两周期之和时，经相差 `p` 或 `q` 的位置比较，得到差周期 `q−p`，再重复。公周期整除 `p`，故将边界按周期补上剩余 `p` 个字符后仍保留它，违背 `x` 的最小周期 `p`。因此 `q=p`，但这又违背差值已经改变。于是 `B<2L/3`；每次系列跳转都按固定比例缩短。

## 各语言说明

动态规划时间为 `O(n log n)`，空间为 `O(n)`。建树时后缀查找的长度下降总和是线性的，因为加入一个字母最多令相应后缀增长二。编译型语言以稀疏孩子链表表示转移，每次最多检查 26 个字母，故对本字母表为确定性常数。Python 使用整数键字典，访问时间为期望常数，所以其时间界也是期望的；另使用压缩的 32 位数组、共享无穷大对象和字节输出。Java 直接把数字写入一个字节缓冲区，避免复制大字符字符串。其余版本也缓冲输出。节点编号、长度与计数都在有符号 32 位范围内。

必须保留两个奇偶分量，只初始化 `E[0]=0`，添加一段时交换奇偶。动态规划沿系列链接走，扩展树时沿后缀链接走。清空缓存会破坏时间偏移不变量。相同字母的串有很多回文后缀却只有一个系列；ruler 串覆盖很多系列。输出每个前缀，区分 `-1/-2`，不能把无穷大视为可达段数。

同一奇偶性中比最小值更大的段数也都可达，只要不超过前缀长度：当 `k+2≤i`，若某段长度至少三，将其拆成首字母、回文中间、尾字母；否则有至少两个长度二的段，各拆成两个字母。每次恰好增加两段。

Python 解答在 PyPy 下运行：在 CPython 3.12 下它在评测的第 48 个测试上超时，而在 PyPy 3.10 下以 0.515 秒通过。
