# 2058. Нечётные и чётные разбиения на палиндромы

[Timus 2058](https://acm.timus.ru/problem.aspx?space=1&num=2058) · difficulty 1673 · strings, dp

Автор оригинальной задачи — Михаил Рубинчик; Палиндромный контест, 11 июля 2015.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для каждого префикса строки разбейте его на непрерывные палиндромы и
найдите наименьшее нечётное и наименьшее чётное число частей.
Ограничения: 1 секунда и 64 МБ.

## Входные данные

Одна строка из 1–300 000 строчных английских букв.

## Выходные данные

n строк, по одной на префикс: наименьшее нечётное число частей или `-1`,
если его нет, и наименьшее чётное или `-2`, если его нет.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
abaa
```

```
1 -2
-1 2
1 -2
3 2
```

Префикс `a` имеет одну часть; `ab` — только `a|b`. Строка `aba` сама
палиндром и делится на три буквы. Для `abaa` разбиения `aba|a` и
`a|b|aa` дают чётный минимум два и нечётный три.

## Решение

### Динамика префиксов и дерево палиндромов

Обозначим минимумы `O[i],E[i]` по нечётному и чётному числу частей.
Бесконечность равна `n+1`; `O[0]=∞`, `E[0]=0`. Если последний
палиндромный суффикс имеет длину `L`, то `O[i]=min(E[i−L]+1)`,
`E[i]=min(O[i−L]+1)`. Минимум берётся по всем палиндромным суффиксам,
поэтому учитывает каждый последний разрез и правильно меняет чётность.

В дереве палиндромов каждая различная палиндромная строка представлена
одной вершиной. Два корня имеют длины `−1` и `0`, `link[v]` указывает на
самый длинный собственный палиндромный суффикс. При добавлении буквы
идём по суффиксным ссылкам от прежнего максимального суффикса, пока
предшествующая буква не совпадёт с новой. Переход расширяет найденный
палиндром. Ссылку новой вершины ищем аналогично, начиная со ссылки её
родителя. Новым может быть только максимальный суффикс: любой более
короткий уже встречается как его префикс. Поэтому вершин не больше
`n+2`. Нулевой байт перед строкой безопасен для строчного алфавита.

### Серии вместо всей цепочки

Пусть `d[v]=len[v]−len[link[v]]`. Ссылка `sl[v]` ведёт к первому
суффиксу с другой разностью: это `sl[link[v]]` при равных разностях и
`link[v]` иначе. Серия — цепочка от `v` включительно до `sl[v]`
исключительно; её длины образуют арифметическую прогрессию шага `d[v]`.
Динамика посещает только ведущие вершины `last,sl[last],…`.

Для каждой вершины храним два минимума предшественников `C_O[v],C_E[v]`.
На конце `i` начинаем с `O[b],E[b]`, где `b=i−len[sl[v]]−d[v]` — разрез
перед кратчайшим элементом серии. При `d[v]=d[link[v]]` уменьшаем каждую
компоненту сохранённой компонентой `link[v]`. Затем `C_E[v]+1` улучшает
`O[i]`, а `C_O[v]+1` — `E[i]`. Унаследованный кэш относится к прошлому
префиксу: очищать все кэши или пересчитывать его как значение текущего
суффикса нельзя.

### Почему старый кэш соответствует нужным разрезам

Для ведущей `v` с `u=link[v]` той же разности положим `d=d[v]`,
`m=len[u]`. Наименьший период палиндрома — его длина минус длина
максимального собственного палиндромного бордера. Поэтому период `u`
равен `d` и `m≥d`. Префиксное и суффиксное вхождения `u` внутри `v`
начинаются на расстоянии `d`. Промежуточного вхождения нет: вместе с
последним оно образовало бы покрывающие палиндромные края, а значит
собственный палиндромный суффикс `v` длиннее `u`. Здесь используется
простое отражение: если одинаковые палиндромные края имеют длину не
меньше половины слова, они вынуждают равенство каждой пары зеркальных
букв во всём слове.

На конце `i−d` вершина `u` ведущая. Иначе непосредственно перед ней в
суффиксной цепочке была бы `z` той же разности длины `m+d`.
Перекрывающиеся края `u` однозначно определяют `z=v`. Предыдущее и
текущее вхождения `v` покрывают палиндром `w`. Если у `w` есть
собственный палиндромный суффикс длиннее `v`, его префикс `u` начинается
строго между двумя крайними вхождениями внутри `z` — противоречие.
Поэтому `link[w]=v` и `d[w]=d`, что противоречит текущей ведущей роли
`v`. Между концами `i−d` и `i` новых вхождений `u` нет; на конце `i` она
не ведущая. Значит, её кэш последний раз записан ровно на `i−d`.

Длины прежней серии `u` — все нынешние длины, кроме наибольшей.
Вычитание их из `i−d` даёт текущие разрезы для всех элементов, кроме
кратчайшего; недостающий разрез добавляет инициализация `b`. Таким
образом, обе компоненты кэша являются минимумами по всей текущей серии.
Индукция по префиксам и полная рекуррентность доказывают правильность
ответа, включая невозможные чётности.

### Логарифмическое число серий

Любой бордер палиндрома сам палиндром, поэтому `d[v]` действительно
является наименьшим периодом. Для последнего элемента `x` серии положим
`L=len[x]`, `B=len[link[x]]`, `p=L−B`. Если `B≥2L/3`, то `B≥2p`. У
бордера есть период `p` и наименьший период `q≤p`. При `q<p` его длина
не меньше `p+q`, значит, периодом является и `gcd(p,q)`. Это правило
выводится вычитанием периодов: для `p<q` сравнения через сдвиги на `p` и
`q` дают период `q−p` при длине не меньше их суммы, затем применяем
Евклида. Общий период делит `p`, поэтому достраивание бордера на
оставшиеся `p` символов сохраняет его, противореча минимальности `p` для
`x`. Следовательно, `q=p` — тоже противоречие смене разности. Итак,
`B<2L/3`: каждая ссылка серии сокращает длину в постоянное число раз.

## Особенности языков

Динамика требует `O(n log n)` времени и `O(n)` памяти. Суммарные
уменьшения длин при поиске суффиксных ссылок линейны: добавление буквы
увеличивает соответствующие длины не больше чем на два. В компилируемых
версиях переходы представлены списками детей: просмотр не более 26 букв
даёт детерминированное константное время. Python использует словарь
целочисленных ключей с ожидаемым константным доступом, упакованные
32-битные массивы, общий объект бесконечности и байтовый вывод;
временная оценка для него ожидаемая. Java записывает цифры в один
байтовый буфер без копий больших символьных строк. Остальные версии
также буферизуют вывод. Индексы и количества помещаются в знаковые 32
бита.

Не смешивать чётности: только `E[0]=0`, при добавлении части компоненты
меняются местами. Динамика идёт по ссылкам серий, расширение дерева — по
суффиксным. Очистка кэшей уничтожает временной сдвиг. В одинаковых
буквах суффиксов много, но серия одна; слово ruler проверяет большое
число серий. Печатать все префиксы, различать `-1/-2`; бесконечность
нельзя считать достижимым числом.

Минимумы описывают также все большие достижимые количества той же
чётности. При `k+2≤i` часть длины хотя бы три можно разделить на первую
букву, палиндромную середину и последнюю. Если все части имеют длины не
больше двух, можно разделить две части длины два. Число частей
увеличивается на два.

Решение на Python запускается под PyPy: под CPython 3.12 оно превышает
ограничение времени на 48-м тесте судьи, а под PyPy 3.10 принимается за
0.515 с.
