# 2045. 构造恰含指定数量不同回文的字符串

[Timus 2045](https://acm.timus.ru/problem.aspx?space=1&num=2045) · 难度 478 · constructive

原题作者 Mikhail Rubinchik，出自 2014 年夏季彼得罗扎沃茨克集训营乌拉尔联邦大学 Dandelion 专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对于每个整数 `1≤i≤n`，构造一个由小写拉丁字母组成、长度为 `n`、恰含 `i` 种不同非空回文子串的字符串，或说明不存在。子串必须连续。同一个字符串值即使出现在多个位置也只计一次。回文正读与反读相同。

## 输入

一个整数 `1≤n≤2000`。时间限制 0.5 秒，内存限制 64 MB。

## 输出

按顺序输出 `n` 行。第 `i` 行格式为 `i : word` 或 `i : NO`。每个单词必须恰有 `n` 个小写拉丁字母、`i` 种不同非空回文。

允许任意正确构造。检查器核验行数、编号顺序、冒号、长度、字母表，并用回文树计算实际不同回文数；仅当 `i<min(n,3)` 时接受 `NO`，不与某个固定构造的字符串逐字比较。

## 评测方式

检查器核对格式以及每个词的长度和字母，并用回文树统计其中不同回文的个数；只有不存在这样的词时才接受 `NO`。任何合法的词都被接受。

## 样例

```
4
```

```
1 : NO
2 : NO
3 : abca
4 : bbca
```

长度为四的字符串不可能只有一种或两种不同回文。`abca` 仅含 `a,b,c`；`bbca` 含 `b,c,a,bb`。程序可以输出其他合法字符串。

## 解法

先处理最短两种长度。`n=1` 输出 `a`。`n=2` 时一种回文不可能，而 `aa` 有 `a`、`aa` 两种回文。

当 `n≥3`，目标一和二输出 `NO`。对每个 `3≤i≤n`，令 `k=i-3`，先输出 `k` 个 `a`，再接无限周期串 `bcdbcdbcd…` 的前 `n-k` 个字符。

### 正确性

任何长度至少为三的单词都有至少三种不同回文。若用了至少三个字母，三个单字母已足够。若只用一个字母，长度一、二、三的前缀就是三个不同回文。若恰用两个字母，已有两个单字母回文；有相等相邻字符时得到第三个二字符回文，否则相邻字符交替，前三个字符形成第三个三字符回文。长度为二时，两个字母不同则有两个单字母，相同则有单字母和二字符回文。因此不可能的目标恰为 `i<min(n,3)`。

构造中尾部长度 `n-k=n-i+3≥3`，所以 `b,c,d` 都出现。尾部没有长度二或三的回文，因为相邻字符及相隔一位的字符都不同。任何更长回文不断去掉两端后，中心必为长度二或三的回文。因此尾部只有三个单字母回文。

开头的连续相同字符贡献恰好 `a,a²,…,a^k`；`k=0` 时不贡献。跨越边界的子串以 `a` 开头，以 `b,c` 或 `d` 结尾，不可能回文。这两组互不相交，共 `k+3=i` 种；总长度为 `k+(n-k)=n`。结合小长度处理及下界，所有字符串和 `NO` 均正确。

### 复杂度

每个字符串的构造及输出耗时 `O(n)`，共 `n` 行，因此总时间 `O(n^2)`，逐行输出时额外空间 `O(n)`。当 `n` 较大，必须输出 `n-2` 个长度为 `n` 的字符串，故仅输出就需要 `Ω(n^2)` 时间。

注意事项：

- 统计不同字符串值，而非回文出现次数或回文划分。
- 尾部至少保留三个字符，目标 `i=n` 时也一样。
- 连续前缀的字母不能出现在尾部；二元交替尾部会产生更长回文。
- 长度一、二须单独处理。
- 检查器应接受与示例和实现构造不同的合法答案。

## 各语言说明

五个实现都只建立一次周期尾串，随后逐行输出。C++、Go、Python、Rust 拼接重复前缀和尾串前缀；Java 为当前行填充字符数组。缓冲输出避免逐字符系统写入，内存不保存整个平方大小的答案。选择 CPython 3.12。
