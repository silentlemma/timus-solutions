# 2045. Заданное количество различных палиндромов

[Timus 2045](https://acm.timus.ru/problem.aspx?space=1&num=2045) · сложность 478 · constructive

Автор оригинальной задачи — Михаил Рубинчик; Ural FU Dandelion contest. Petrozavodsk training camp. Summer 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для каждого целого `i` от `1` до `n` построить слово длины `n` из
строчных латинских букв, содержащее ровно `i` различных непустых
подстрок-палиндромов, либо сообщить, что такого слова нет. Подстрока
состоит из подряд идущих символов. Одинаковые подстроки считаются одним
значением независимо от количества вхождений. Палиндром одинаково
читается в обоих направлениях.

## Входные данные

Одно целое число `1≤n≤2000`. Лимиты: 0,5 секунды и 64 МБ.

## Выходные данные

Вывести `n` строк по порядку. Строка `i` имеет вид `i : word` либо `i :
NO`. Каждое слово должно содержать ровно `n` строчных латинских букв и
ровно `i` различных непустых палиндромов.

Допускается любой правильный ответ. Валидатор проверяет число и порядок
строк, двоеточие, длину, алфавит и фактическое количество различных
палиндромов деревом палиндромов. `NO` принимается только при
`i<min(n,3)`. Сравнения слова с фиксированной конструкцией нет.

## Проверка

Проверяющая программа сверяет формат, длину и буквы каждого слова и
считает его различные палиндромы деревом палиндромов; `NO` принимается,
только если слова нет. Принимаются любые подходящие слова.

## Примеры

```
4
```

```
1 : NO
2 : NO
3 : abca
4 : bbca
```

У слова длины четыре не бывает всего одного или двух различных
палиндромов. В `abca` есть только `a,b,c`; в `bbca` — `b,c,a,bb`. Это
допустимые примеры, программы могут выводить другие слова.

## Решение

Первые две длины рассматриваем отдельно. При `n=1` подходит `a`. При
`n=2` одно значение невозможно, а `aa` даёт два: `a` и `aa`.

При `n≥3` для целей один и два печатаем `NO`. Для каждого `3≤i≤n`
положим `k=i-3`. Выведем `k` букв `a`, затем первые `n-k` символов
бесконечного периодического слова `bcdbcdbcd…`.

### Доказательство

Любое слово длины хотя бы три содержит не менее трёх различных
палиндромов. Если различных букв хотя бы три, достаточно односимвольных
подстрок. Если буква одна, подходят первые один, два и три символа. Если
букв ровно две, имеются оба односимвольных палиндрома; равные соседние
буквы дадут третий длины два, а при отсутствии равных соседей первые три
символа образуют палиндром. Для длины два минимум равен двум: либо две
разные буквы, либо одна буква и равная пара. Поэтому невозможны в
точности цели `i<min(n,3)`.

В конструкции длина хвоста `n-k=n-i+3≥3`, то есть в нём присутствуют все
буквы `b,c,d`. В хвосте нет палиндромов длины два и три: соседние буквы
и буквы через одну различны. Любой более длинный палиндром содержит
центральный палиндром длины два или три, получаемый последовательным
удалением крайних букв. Следовательно, в хвосте ровно три односимвольных
палиндрома.

Начальный блок даёт ровно разные строки `a,a²,…,a^k`, при `k=0` — ни
одной. Подстрока, пересекающая границу, начинается с `a`, а
заканчивается на `b,c` или `d`, поэтому палиндромом не является. Два
множества не пересекаются; всего `k+3=i` значений, а длина слова
`k+(n-k)=n`. Вместе с малыми случаями и нижней границей это доказывает
все слова и все ответы `NO`.

### Сложность

Одно слово строится и выводится за `O(n)`. Для `n` строк получаем
`O(n^2)` времени и `O(n)` дополнительной памяти при немедленном выводе
очередной строки. Для больших `n` требуется напечатать `n-2` слов длины
`n`, поэтому сам вывод уже требует `Ω(n^2)` времени.

Подводные камни:

- Считаются разные строки, а не вхождения палиндромов и не разбиения.
- В хвосте должны оставаться хотя бы три символа, в том числе при `i=n`.
- Буква начального блока не входит в алфавит хвоста; двоичный
  чередующийся хвост создаёт длинные палиндромы.
- Длины один и два обрабатываются отдельно.
- Проверка обязана принимать правильные слова, отличные от примера и
  рабочей конструкции.

## Особенности языков

Все пять реализаций один раз строят периодический хвост и выводят по
одной строке. C++, Go, Python и Rust соединяют повторяющийся префикс с
началом хвоста. Java заполняет массив символов для очередной строки.
Буферизованный вывод исключает отдельные записи каждого символа;
квадратичный полный ответ в памяти не хранится. Выбран CPython 3.12.
