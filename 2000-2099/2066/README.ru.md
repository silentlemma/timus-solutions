# 2066. Наименьшее значение из трёх чисел

[Timus 2066](https://acm.timus.ru/problem.aspx?space=1&num=2066) · сложность 28 · bruteforce

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Три неотрицательных целых числа можно записать в любом порядке, поставив
между соседними один из знаков +, − или ×; умножение выполняется
первым, скобок и унарного минуса нет. Найдите наименьшее возможное
значение такого выражения. Ограничения: 1 секунда и 64 МБ.

## Входные данные

Числа a ≤ b ≤ c, 0 ≤ a, каждое в отдельной строке, c ≤ 100.

## Выходные данные

Наименьшее значение.

## Проверка

Ответы сравниваются по токенам.

## Примеры

### Пример 1

Ввод:

```
1
2
3
```

Вывод:

```
-5
```

## Решение

Порядков не больше 6, пар знаков 9, поэтому программы перебирают до 54
выражений. Значение x op₁ y op₂ z считается с обычным приоритетом: если
× стоит только вторым, сначала вычисляется y × z, иначе — слева
направо.

Перебор всегда заканчивается одним и тем же видом: наименьшее число
минус большее из b + c и b × c, то есть a − max(b + c, b × c).
Вычесть из наименьшего числа как можно больше, очевидно, выгоднее всего,
а b + c больше b × c, только когда одно из них 0 или 1. Проверка всех
176 851 входа подтверждает формулу, но простому перебору доказательство
не нужно.

В примере 1 − 2 × 3 = −5.

## Оптимизированные решения

Оптимизированное решение на Java разбирает числа побайтно из `System.in`
вместо `Scanner`: 0.093 с вместо 0.140 с и 400 КБ вместо 1584 КБ.
