# 2066. Наименьшее значение из трёх чисел

[Timus 2066](https://acm.timus.ru/problem.aspx?space=1&num=2066) · сложность 28 · bruteforce

Автор оригинальной задачи — Кирилл Бороздин; Уральская региональная командная олимпиада по программированию 2015.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Три неотрицательных целых числа можно записать в любом порядке, поставив
между соседними один из знаков +, − или ×; умножение выполняется
первым, скобок и унарного минуса нет. Найдите наименьшее возможное
значение такого выражения. Ограничения: 1 секунда и 64 МБ.

## Входные данные

Числа a ≤ b ≤ c, 0 ≤ a, каждое в отдельной строке, c ≤ 100.

## Выходные данные

Наименьшее значение.

## Проверка

Ответы сравниваются по токенам.

## Примеры

### Пример 1

Ввод:

```
1
2
3
```

Вывод:

```
-5
```

## Решение

Порядков не больше 6, пар знаков 9, поэтому программы перебирают до 54
выражений. Значение x op₁ y op₂ z считается с обычным приоритетом: если
× стоит только вторым, сначала вычисляется y × z, иначе — слева
направо.

Перебор всегда заканчивается одним и тем же видом: наименьшее число
минус большее из b + c и b × c, то есть a − max(b + c, b × c).
Вычесть из наименьшего числа как можно больше, очевидно, выгоднее всего,
а b + c больше b × c, только когда одно из них 0 или 1. Проверка всех
176 851 входа подтверждает формулу, но простому перебору доказательство
не нужно.

В примере 1 − 2 × 3 = −5.

## Оптимизированные решения

Оптимизированное решение на Java разбирает числа побайтно из `System.in`
вместо `Scanner`: 0.093 с вместо 0.140 с и 400 КБ вместо 1584 КБ.

`2066_math.py`. Перебор перестановок и пар операций заменяется двумя выражениями. Для неотрицательных a<=b<=c минимум чисто аддитивных выражений равен a-b-c. Если произведение вычитается, выгодно включить в него два больших числа: a-b*c; положительные произведения и другие смешанные размещения не улучшают одновременно оба кандидата. Берём минимум. Имя math отличает это рассуждение от сохранённого учебного перебора. Время и память O(1). Самостоятельная программа для судьи явно сбрасывает stdout перед os._exit(0), пропуская обычное завершение интерпретатора. Выигрыш памяти подтверждён её собственным Accepted. Сама смена способа завершения не улучшает асимптотику, а её эффект в среде выполнения не гарантируется на других платформах. Простая версия сохранена без изменений.

По сравнению с `2066_bruteforce.py`: время 0.078 s → 0.14 s; память 532 KB → 208 KB.

## Особенности языков

Новые исходники сравниваются по срезу от 18 ноября 2026 года с другими авторами на текущих компиляторах судьи. Порогов по ID посылки или дате нет. Ничьи делят место, времена меньше 0.015 с при сравнении считаются 0.015 с. Приведённые ниже места относятся к новым версиям; прежние исходники сохраняют собственные исторические метрики Accepted.

`2066_math.py`: место по времени 330/341, по памяти 3/341 в этой сопоставимой выборке.

Звёздочка означает недостигнутую рейтинговую цель: для C++ нужны первые десять мест либо топ 15% одновременно по обеим метрикам; для остальных семейств — первое место по обеим. Отдельный критерий допуска может выполняться по рейтингу или улучшению, в том числе при снижении времени либо памяти минимум на 30%.
