## Задача

Дни нумеруются 1, 2, 3, … Каждый второй день — отчёт; из оставшихся
дней каждый третий — отчёт; из оставшихся — каждый четвёртый, и так
бесконечно. Дни, которые никогда не убираются, спокойные. Посчитайте
спокойные дни на [l; r]. Ограничения: 1 секунда и 64 МБ.

## Входные данные

l и r, 1 ≤ l ≤ r ≤ 10⁹.

## Выходные данные

Число спокойных дней от l до r.

## Проверка

Точные токены ответа. Каждый новый исходник прошёл полные проверки целевой среды, независимые математические сравнения и имеет собственный Accepted с хешем; простые версии сохраняют свои метрики.

## Примеры

### Пример 1

Ввод:

```
1 10
```

Вывод:

```
3
```

## Решение

Пусть f(n) — число спокойных дней среди первых n. Удаления всегда
берут позиции в списке оставшихся дней, поэтому среди первых c
оставшихся дней шаг k убирает ровно ⌊c / k⌋, а оставшиеся дни среди
первых n остаются префиксом списка. Значит, f(n) находится как
c ← c − ⌊c / k⌋ при k = 2, 3, …, пока c ≥ k; когда c < k, дальнейшие шаги
префикс не трогают. Число c убывает примерно как n / k, так что цикл
кончается примерно через 2√(n/π) шагов, около 3.6·10⁴ для 10⁹. Ответ —
f(r) − f(l − 1).

В примере f(10): 10 → 5 → 4 → 3, и спокойные дни — 1, 3 и 7.

## Оптимизированные решения

Одношаговое решето сохраняем как учебную базу. Перед шагом k размер оставшегося префикса c=qk+r. После j удалений по q частное остаётся q ровно при 2 qj<=r; верхнее неравенство лишь ослабляется. Сразу выполняем r//(2 q)+1 шагов: c-=q*j,k+=j. Следующее положительное частное строго меньше. Перед k индукция из c<-c-floor(c/k) даёт (k-1)c<=N+(k-2)(k-1)/2. При K=ceil(N^(1/3))+1 ранних шагов меньше K, а затем q<=K, значит остаётся не больше K блоков: O(N^(1/3)) времени, O(1) состояния. Ответ quiet(R)-quiet(L-1). Go использует ограниченный переносимый нативный ввод-вывод, Java использует те же точные блоки. Python вычисляет каждый префикс отдельно и получает частное и остаток одним вызовом divmod. Все вычисления целочисленные.

## Особенности языков

Срезы рейтинга сохранены 1 и 4 ноября 2026 года. Цель C++ — топ 15% либо первые 10 мест одновременно по времени и памяти; других семейств — первое место по обеим метрикам. Ничьи делят место. Пустые выборки дают только формальное покрытие.

Используется сохранённый профиль текущих компиляторов; исключены собственный автор и старые строки со временем меньше 0,015 с. Для семейств кроме C++ дополнительно требуется ID посылки ≥10770000; память C++ сравнивается по первым 1000 подходящим строкам. Собственные времена меньше 0,015 с считаются 0,015 с.
