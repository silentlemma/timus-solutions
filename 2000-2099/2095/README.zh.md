# 2095. 统计反复筛选后留下的日子

[Timus 2095](https://acm.timus.ru/problem.aspx?space=1&num=2095) · 难度 277 · math

原题作者 Dmitry Ivankov，出自 2014 年乌拉尔联邦大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

日子编号为 1, 2, 3, … 每隔一天（第二天）要汇报；剩下的日子中每第三天要汇报；再剩下的中每第四天，如此无限进行。从不被去掉的日子是清静日。统计 [l; r] 中的清静日。时间限制 1 秒，内存限制 64 MB。

## 输入

l 和 r（1 ≤ l ≤ r ≤ 10⁹）。

## 输出

从 l 到 r 的清静日数目。

## 样例

### 样例 1

输入：

```
1 10
```

输出：

```
3
```

## 解法

设 f(n) 为前 n 天中的清静日数。删除总是按剩余日子列表中的位置进行，所以在前 c 个剩余日子中，第 k 步恰好删去 ⌊c / k⌋ 个，而前 n 天中剩下的日子始终是列表的前缀。因此 f(n) 由 c ← c − ⌊c / k⌋（k = 2, 3, …，当 c ≥ k 时）求出；一旦 c < k，后面的步骤不再影响这个前缀。c 大约按 n / k 减少，所以循环约 2√(n/π) 步结束，10⁹ 时约 3.6·10⁴ 步。答案为 f(r) − f(l − 1)。

样例中 f(10)：10 → 5 → 4 → 3，清静日为 1、3 和 7。
