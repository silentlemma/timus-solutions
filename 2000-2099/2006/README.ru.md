# 2006. Перекрытие наиболее важной клетки

[Timus 2006](https://acm.timus.ru/problem.aspx?space=1&num=2006) · сложность 3676 · graphs, shortest_paths

Автор оригинальной задачи — Илья Кучумов; подготовка — Олег Меркурьев. Уральская региональная командная олимпиада по программированию 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Прямоугольное поле состоит из свободных `.` и закрытых `#` клеток. Между
свободными клетками с общей стороной можно перейти за один шаг.
Различные свободные начало и конец изначально соединены. Нужно закрыть
ровно одну другую свободную клетку, максимально увеличив кратчайшее
расстояние. Разрыв связности предпочтительнее любой конечной длины.
Подходит любая оптимальная клетка. Хотя бы одна допустимая клетка
существует; она может находиться и в другой компоненте.

## Входные данные

Числа `n m`, `2 ≤ n,m ≤ 1000`, `n·m ≤ 100000`. Следующие две строки
содержат координаты начала и конца в порядке `строка столбец`, с
нумерацией от 1 из левого верхнего угла. Затем идут `n` строк по `m`
символов `.` или `#`. Концы различны, свободны и соединены; свободных
клеток хотя бы три. Время 2 секунды, память 128 МБ.

## Выходные данные

Строка и столбец свободной клетки, отличной от концов, после удаления
которой расстояние максимально. Разрыв пути считается лучшим
результатом. Равные оптимумы допустимы.

## Проверка

Проверяющая программа закрывает напечатанную клетку, запускает поиск в
ширину и сравнивает новое расстояние или разрыв связи с оптимумом;
принимается любая лучшая клетка.

## Примеры

```
4 4
1 1
4 4
..##
#.##
#...
###.
```

```
2 2
```

Удаление `(2,2)` разрывает единственный проход между концами и потому
оптимально.

## Решение

Выберем кратчайший путь `P[0..k]`. Удаление вне него сохраняет этот путь
и не увеличивает расстояние. Достаточно проверить внутренние клетки `P`.
При `k=1` концы соседние, можно выбрать любую другую свободную клетку.

BFS из начала даёт расстояния `ds` и дерево, содержащее `P`; BFS из
конца даёт `dt`. Уровень `λ(v)` — индекс последней вершины `P` на пути
дерева к `v`; уровни присваиваются в порядке BFS. Для удаления `P[i]`
разделим оставшуюся исходную компоненту на `R` с уровнем ниже `i`, `V` с
уровнем `i` без самой `P[i]` и `S` с уровнем выше `i`.

Кратчайший префикс к вершине `R` остаётся в `R`. Для `y` из `S` пусть
`j=λ(y)>i`. Ветка дерева до `P[j]` и остаток `P` до конца имеют длину
`ds[y]+k−2j`. Любой маршрут через `P[i]` имеет длину хотя бы
`ds[y]+k−2i`, строго большую. Поэтому кратчайший суффикс длины `dt[y]`
избегает удаляемой клетки.

Пересечь границу из `R∪V` в `S` можно двумя способами. Ребро `x–y` с
`λ(x)<i<λ(y)` даёт кандидат `ds[x]+1+dt[y]`. Одно ребро предлагает эту
длину всем индексам строго между уровнями концов — это предложение на
интервале.

Во втором случае `x` лежит в `V`, и обычный кратчайший префикс мог
проходить через удаляемую клетку. Вычислим исправленный `detour[x]`: для
каждой вершины `v` вне `P` начальная оценка равна минимуму `ds[u]+1` по
соседям меньшего уровня. Многоточечная Дейкстра распространяет оценки
только между вершинами вне `P` одного уровня. Области уровней
непересекаются. Затем ребро из такой `x` в `y` большего уровня даёт
`detour[x]+1+dt[y]` только для удаления с индексом `λ(x)`.

Почему исправленный префикс точен? У пути, ограниченного `R∪V`,
рассмотрим последний вход из `R` в `V`. Префикс не короче
соответствующей начальной оценки, а остаток идёт внутри `V`. Обратно,
любой путь Дейкстры имеет допустимый префикс в `R` и не использует
удаляемую клетку. Любой обходной путь пересекает границу с `S`, и два
описанных случая исчерпывают это пересечение. Значит, минимум
предложений равен искомому расстоянию; отсутствие предложений означает
разрыв.

Сортируем интервалы по левому концу и идём по индексам пути. Куча хранит
пары `(длина,правый конец)`: добавляем начавшиеся интервалы и удаляем
просроченные минимумы. Сравниваем минимум активных интервалов с
точечными предложениями. Выбираем клетку с наибольшим результатом.

Использовано сведение для удаления вершины из [работы Lee и Lu, раздел
2.2](https://arxiv.org/html/1310.8062#S2.SS2), с обычной Дейкстрой и
кучей интервалов. Линейная процедура минимумов матрицы не нужна. При
`N=n·m` и не более `2N` рёбер время `O(N log N)`, память `O(N)`. Плоское
поле с рамкой упрощает соседей; недостижимые компоненты не участвуют в
вычислениях.

Формулы для удаления одного ребра недостаточно: обходы внутри одного
уровня обязательны. Интервалы исключают оба уровня концов, а точечное
предложение не допускает саму вершину пути. Нельзя закрывать начало и
конец. Разрыв лучше любой конечной длины. При соседних концах третья
клетка может быть изначально недостижимой. Считайте переходы, а не
вершины, и не меняйте местами строку и столбец.

## Особенности языков

Все порты используют итеративный BFS, плоское поле с рамкой, записи
межуровневых рёбер и кучи; длинный коридор не создаёт рекурсии.
Расстояния и именованная бесконечность укладываются в знаковые 32-битные
целые. Rust проверяет беззнаковые маркеры отсутствующего уровня перед
сравнением. Python выводит только координаты. Ресурсы полных программ
измеряются до публикации готовности.
