# 2006. 封闭最关键的网格单元

[Timus 2006](https://acm.timus.ru/problem.aspx?space=1&num=2006) · 难度 3676 · graphs, shortest_paths

原题作者 Ilya Kuchumov. (Prepared by Oleg Merkurev)，出自 2013 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

矩形网格中 `.` 可通行，`#` 被阻挡。每次可向共享边的可通行单元移动一步。不同的起点和终点都可通行且初始连通。必须封闭恰好一个其他可通行单元，使新的最短距离最大；使两端不连通优于任何有限距离。可输出任意最优单元。保证至少有一个合法候选，它也可能位于另一连通分量。

## 输入

首行为 `n m`，`2 ≤ n,m ≤ 1000`，`n·m ≤ 100000`。随后两行分别给起点和终点的 `行 列`，从左上角以 1 编号。再给 `n` 行，每行 `m` 个 `.` 或 `#`。两端不同、可通行且初始有路径，至少有三个可通行单元。时间 2 秒，内存 128 MB。

## 输出

输出一个非端点可通行单元的行、列，使删除后的最短距离最大，不连通视为最优先。多个最优答案可任选。

## 评测方式

检查器封住输出的格子后运行 BFS，把新的距离或是否断开与最优结果比较；任何最佳格子都被接受。

## 样例

```
4 4
1 1
4 4
..##
#.##
#...
###.
```

```
2 2
```

删除 `(2,2)` 切断两端之间唯一通道，因此最优。

## 解法

选择一条最短路径 `P[0..k]`。删除路径外的单元不会破坏这条路径，也就不能增加距离；只需考察内部路径顶点。当 `k=1` 时两端相邻，任意其他可通行单元都可以。

从起点 BFS 得到距离 `ds` 及包含 `P` 的树，从终点 BFS 得到 `dt`。令层级 `λ(v)` 为树上起点到 `v` 的路径中最后一个 `P` 顶点的下标，按 BFS 顺序赋值。若删除 `P[i]`，把原可达分量的其他顶点划为层级小于 `i` 的 `R`、层级等于 `i` 但不含 `P[i]` 的 `V`，以及层级大于 `i` 的 `S`。

到 `R` 顶点的最短前缀留在 `R`。对 `S` 中的 `y`，设 `j=λ(y)>i`，沿树枝到 `P[j]` 再到终点的长度为 `ds[y]+k−2j`。任何经过 `P[i]` 的路线至少为 `ds[y]+k−2i`，严格更长。因此长度为 `dt[y]` 的最短后缀避开被删顶点。

从 `R∪V` 跨到 `S` 有两类情况。边 `x–y` 满足 `λ(x)<i<λ(y)` 时，候选长度为 `ds[x]+1+dt[y]`。它对严格介于两个端点层级之间的所有失败下标都提供同一值，即区间候选。

另一类中 `x` 属于 `V`，普通最短前缀可能经过被删顶点。为路径外顶点计算修正前缀 `detour`：顶点 `v` 的初值为所有较低层邻居 `u` 的 `ds[u]+1` 的最小值。多源 Dijkstra 只在同层、且不在 `P` 上的顶点间传播。各层区域互不相交。随后从路径外 `x` 到更高层 `y` 的边，为失败下标 `λ(x)` 单独提供 `detour[x]+1+dt[y]`。

修正前缀为何准确？任取限制在 `R∪V` 内的路径，考察其最后一次从 `R` 进入 `V`：前缀不短于对应初值，余段始终在 `V`。反之每条带初值的 Dijkstra 路径都有合法的 `R` 内前缀，并避开被删顶点。任何替代路径都必须跨入 `S`，以上两类穷尽跨界情况，所以最小候选就是正确距离；无候选表示不连通。

按区间左端点排序，依次扫描路径下标。堆保存 `(代价,右端点)`，加入已开始的区间，弹出过期的最小项。将当前堆最小值与单点候选取最小，再选择替代距离最大的路径单元。

采用 [Lee 与 Lu 论文第 2.2 节](https://arxiv.org/html/1310.8062#S2.SS2)的避开顶点归约，在此用普通 Dijkstra 与区间堆实现，不使用线性矩阵行最小值过程。令 `N=n·m`，网格无向边不超过 `2N`，时间 `O(N log N)`，空间 `O(N)`。带边框的一维网格便于邻接访问，不可达分量不参与计算。

仅有删除边的公式不足以删除顶点，同层内部绕路必不可少。区间排除两个端点层级，低层单点候选必须排除路径顶点自身。不能封闭起终点，不连通优于任意有限距离。两端相邻时第三单元甚至可以初始不可达。距离数的是移动次数，注意输出行列顺序。
