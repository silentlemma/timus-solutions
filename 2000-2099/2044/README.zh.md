# 2044. 每个前缀的回文分段数位掩码

[Timus 2044](https://acm.timus.ru/problem.aspx?space=1&num=2044) · 难度 2428 · strings

原题作者 Mikhail Rubinchik，出自 2014 年夏季彼得罗扎沃茨克集训营乌拉尔联邦大学 Dandelion 专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定由小写拉丁字母组成、长度为 `1≤n≤300000` 的字符串。对于每个非空前缀，以及每个 `1≤j≤31`，判断能否将此前缀恰好分成 `j` 个非空回文串。各段连续、有序，覆盖全部位置；不同段可以相同。回文串正读与反读一致。

用一个非负整数编码一个前缀的所有答案：当且仅当能分成 `j` 段时，第 `j-1` 位为一。结果在 `0..2^31-1` 内。时间限制 0.5 秒，内存限制 64 MB。

## 输入

一行字符串，其长度即 `n`，不另行给出长度整数。

## 输出

按前缀长度递增的顺序输出 `n` 个十进制整数，每行一个。整数记号精确比较。

## 评测方式

按记号逐个比较输出。

## 样例

```
abaa
```

```
1
2
5
14
```

`a` 只能分成一段；`ab` 只能采用 `a|b`。`aba` 可以整体作为回文，也可以分成 `a|b|a`，所以掩码为 `1+4=5`。`abaa` 的可行划分为 `aba|a`、`a|b|aa`、`a|b|a|a`，分别有二、三、四段，因此得到 `2+4+8=14`。

## 解法

### 前缀动态规划与回文树

内部掩码 `D[i]` 的第 `j` 位表示前 `i` 个字符能恰好分成 `j` 段。它与输出不同：第零位留给零段，因此设 `D[0]=1`。若最后一段是长度为 `L` 的回文后缀，之前的部分就是前缀 `i-L`。于是 `D[i]=OR(D[i-L]<<1)`，对当前所有回文后缀取按位或。只保留第 `0..31` 位，输出 `D[i]>>1`。添加一段不会减少段数，故超出 31 的状态可以永久丢弃。

回文树 eertree 为每个不同的非空回文建立一个结点，并含长度为 `-1` 与 `0` 的两个根。字符 `c` 的边表示在原回文两侧添加 `c`。`link[v]` 指向最长的真回文后缀。每添加一个字符，沿后缀链接寻找可扩展后缀，至多新建一个结点，再求出其后缀链接。字符串前加一个不属于输入字母表的哨兵。

若每个前缀都遍历全部后缀链接，全相同字符会造成平方时间。定义 `diff[v]=len[v]-len[link[v]]`。后缀链上连续相同的差值组成一组。若 `diff[v]=diff[link[v]]`，令 `series[v]=series[link[v]]`；否则令 `series[v]=link[v]`。它直接跳过当前整组。

### 每组只计算一次并集

每个结点保留持久掩码 `cache[v]`。在前缀末端 `i`，从最长回文后缀出发沿 `series` 访问组首 `v`。设 `d=diff[v]`、`B=len[series[v]]+d`，其中 `B` 是本组最短回文长度。先赋值 `cache[v]=D[i-B]`；若 `v` 与 `link[v]` 的差值相同，再按位或入 `cache[link[v]]`。将 `cache[v]<<1` 并入当前答案，再跳到下一组。

这里后缀结点的缓存一般来自更早的前缀，这是有意的。每次清空缓存会破坏算法。

### 为什么旧缓存恰好对应当前切点

回文串的每个 border 也是回文：其后缀是等长前缀的逆序。周期长度与 border 的互补长度对应，因此 `diff[v]` 就是该回文的最短周期。

考虑非单元素组，令 `u=link[v]` 且 `diff[u]=diff[v]=d`。有 `|v|=|u|+d`、`|u|≥d`。`v` 的前缀和后缀两个 `u` 副本覆盖整个 `v`，起点相差 `d`。它们中间不能再出现一个 `u`：与第一个副本重叠会得到小于 `d` 的正周期。因此，在末端严格位于 `i-d` 与 `i` 之间时，`u` 不可能作为后缀出现。

在末端 `i-d`，`u` 必然是组首。否则该后缀链有一个直接前驱 `z`，满足 `link[z]=u` 且差值仍为 `d`。于是 `|z|=|v|`，覆盖它的两个 `u` 副本强制 `z=v`。末端位于 `i-d` 与 `i` 的两个 `v` 副本于是组成更长的回文 `W`：关于整体中心的反射交换两个相同的回文副本。`W` 有周期 `d`，且包含最短周期为 `d` 的 `v`，故其最短周期也是 `d`。这样 `link[W]=v` 且差值相同，与当前 `v` 是组首矛盾。

所以 `cache[u]` 最后一次更新在 `i-d`。归纳假设表明它包含旧组长度 `L=B,B+d,…,|v|-d` 对应的所有 `D[i-d-L]`。这些切点恰好对应当前更长的后缀 `B+d,…,|v|`；再加入 `D[i-B]` 就补上了最短者。单元素组只需这一项。

因此，每个缓存恰好合并其当前组的全部切点，各组划分所有回文后缀，左移添加最后一段。对前缀长度归纳即可证明所有输出精确。论证针对实际切点集合，因此适用于按位或，并非直接套用最少分段数的递推。

### 复杂度

每两次 `series` 跳转使正长度至少减半。设连续三个长度为 `L,A,B`，并假设 `B>L/2`。前两个回文的最短周期分别为 `d,e`。长度 `A` 的回文继承周期 `d`，但差值不同，因此 `e<d`；另有 `e≤A-B`。它在长度 `L` 回文两端的副本覆盖整体，重叠长度为 `2A-L>2e`。两个 `e` 周期字符串若至少重叠 `e` 个位置，其并集仍有周期 `e`：每对相距 `e` 的位置都被某个副本覆盖。这与 `d` 最小矛盾，所以 `B≤L/2`。

一次跳转未必减半，例如 `aabaaabaa` 给出 `9→5`。两次跳转的性质已经保证每个前缀只有 `O(log n)` 组。结合标准后缀搜索的摊还界和固定字母表，总时间 `O(n log n)`，空间 `O(n)`。Python 的转换字典使用期望查找时间，其他实现使用有界字母表数组。

系列链接的基本方法见 [Rubinchik 与 Shur，EERTREE，第 4.1 节](https://arxiv.org/abs/1506.04862)。上面的切点并集证明解释了它如何用于精确分段数掩码。

注意事项：

- 各段非空，内部零位只属于空前缀。
- 必须按位或，不能相加；不同切点可能产生相同段数。
- 内部截断到 32 位，输出再右移一次。Java 必须无符号右移。
- 保留旧缓存，其时间偏移是证明的一部分。
- 某前缀掩码为零，不代表以后仍为零；更长回文可能直接接到很早的切点。
- 稠密的 64 位转换表可能超出内存，结点编号应紧凑存储。

## 各语言说明

C++ 和 Go 使用每结点 26 个 32 位转换。Rust 的转换也为 32 位，在下标处转换类型。Java 用基本类型数组组织稀疏出边，结点编号同时作为其入边编号，每次最多扫描 26 条边。输出均缓冲。

Python 用紧凑 `array` 存储结点字段和掩码，转换放在一个以 `parent*26+letter` 为键的字典中，分批输出。

Python 解答在 PyPy 下运行：在 CPython 3.12 下它在评测的第 32 个测试上超时，而在 PyPy 3.10 下以 0.375 秒通过。
