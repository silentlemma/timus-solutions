# 2020. Две встречные очереди на перекрёстке

[Timus 2020](https://acm.timus.ru/problem.aspx?space=1&num=2020) · сложность 162 · simulation

Автор оригинальной задачи — Денис Дублённых; подготовка — Никита Бурлаков. NEERC 2014, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

К перекрёстку с юга и с севера подошли две встречные очереди автомобилей.
Каждая машина едет прямо (`F`), налево (`L`) или направо (`R`). Очереди
заданы от ближайшей к перекрёстку машины к самой дальней, обгонять нельзя.
Проезд занимает одну секунду. Поворачивающая налево машина уступает
первой встречной, если та едет прямо или направо. Два левых поворота
выполняются вместе; два манёвра без левого поворота тоже не мешают друг другу.
В каждую секунду проезжают все первые машины, которым это разрешено;
следующие за ними могут поехать лишь со следующей секунды. Новых машин нет.
Нужно найти время полного освобождения очередей.

В каждой исходной очереди от 1 до 1000 автомобилей.
Лимиты: 1 секунда, 64 МБ.

## Входные данные

Первая строка задаёт южную очередь, вторая — северную.
Строки содержат только `F`, `L`, `R`, начиная с ближайшей машины.

## Выходные данные

Выведите общее время проезда всех автомобилей в секундах.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
RLF
FF
```

```
4
```

```
L
L
```

```
1
```

## Решение

Храним индексы `i`, `j` первых необработанных машин и прошедшее время.
Пока обе очереди непусты, читаем **обе старые головы** `a`, `b`.
Южная машина едет, если `a != L` или `b == L`; северная — если
`b != L` или `a == L`. Оба признака вычисляем до изменения индексов.
Продвигаем разрешённые очереди и добавляем одну секунду.

| Южная машина | Северная машина | Кто проезжает |
| --- | --- | --- |
| `L` | `F` или `R` | только северная |
| `F` или `R` | `L` | только южная |
| `L` | `L` | обе |
| `F` или `R` | `F` или `R` | обе |

Как только одна очередь кончается, встречных препятствий больше нет.
Каждая оставшаяся машина требует ровно секунду: добавляем суммарное число
необработанных машин к времени.

Докажем корректность инвариантом: после `t` смоделированных секунд индексы
равны точному числу проехавших машин каждой очереди. Изначально это нули.
Таблица полностью повторяет правила приоритета для двух текущих машин.
Одновременное обновление по старому состоянию точно воспроизводит следующую
секунду и сохраняет инвариант. После опустошения одной стороны оставшиеся
машины проезжают по одной каждую секунду, поэтому прибавление хвоста точно.
Итоговое время совпадает с требуемым.

В каждую секунду уезжает хотя бы одна машина: либо левый поворот ждёт
встречную машину без левого поворота, либо едут обе. Для исходных длин
`s`, `t` время работы `O(s+t)`, дополнительная память `O(1)`; вместе со
строками ввода память `O(s+t)`. Ответ между `max(s,t)` и `s+t`, то есть не
больше 2000 секунд.

В первом примере в первую секунду едут южная `R` и северная `F`.
Во вторую южная `L` ждёт следующую северную `F`. Затем южные `L` и `F`
занимают третью и четвёртую секунды. Во втором примере оба левых поворота
выполняются за одну секунду.

Подводные камни:

- Сначала определите оба решения о проезде, затем меняйте индексы: новая
  голова действует позже.
- Левый поворот уступает и прямому движению, и правому повороту.
- Два встречных левых поворота выполняются одновременно.
- После окончания одной очереди не забудьте время оставшегося хвоста.

## Оптимизированные решения

Оптимизированное решение на C++ читает две очереди через `scanf` в
глобальные массивы `char` по 1001 байту, ведь в очереди не больше 1000
машин, вместо `std::string`, читаемых через `iostream`; оно проходит их
до завершающих нулей и печатает через `printf`:
{2020_simulation_optimized.cpp}.

### Измеренный выигрыш

Каждая оптимизированная версия имеет Accepted и сокращает время или
память минимум на 30% относительно базовой версии на том же языке.
Базовые исходники сохранены. Отрицательное сокращение означает рост
расхода. Звёздочка относится только к рейтинговой цели.

- `2020_simulation_optimized.cpp`: сокращение времени +0.00%; сокращение
  памяти +72.63%; база: `2020_simulation.cpp`.
