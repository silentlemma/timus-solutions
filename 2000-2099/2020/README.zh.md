# 2020. 两条相向车队的清空时间

[Timus 2020](https://acm.timus.ru/problem.aspx?space=1&num=2020) · 难度 162 · simulation

原题作者 Denis Dublennykh（由 Nick Burlakov 整理），出自 NEERC 2014 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两条车队分别从南、北相向到达路口。每辆车的意图为直行 `F`、左转 `L`
或右转 `R`。队列从最近到最远给出，不能超车，每车过路口耗时一秒。
左转车必须让对向队首的直行车或右转车先行；两辆左转车可以同时通过，
两辆均不左转的车也可以同时通过。每秒所有有通行权的队首车立即通过，
新露出的队首只能从下一秒起行动。没有新车加入。求两队全部通过所需时间。

每条初始队列长度为 1 至 1,000。时间限制 1 秒，内存限制 64 MB。

## 输入

第一行是南侧队列，第二行是北侧队列，均只含 `F`、`L`、`R`，从最近的车开始。

## 输出

输出所有车通过路口所需的总秒数。

## 评测方式

按记号逐个比较输出。

## 样例

```
RLF
FF
```

```
4
```

```
L
L
```

```
1
```

## 解法

维护两队尚未通过的首车下标 `i`、`j` 和经过的秒数。两队均非空时，先取
**两个旧队首** `a`、`b`。南侧可行条件为 `a != L` 或 `b == L`；北侧可行
条件为 `b != L` 或 `a == L`。先计算两个条件，再分别推进下标，时间加一。

一队清空后，对向已无车阻挡，剩余每车各用一秒。把未通过车数之和加到
时间上即可。

正确性不变式为：模拟 `t` 秒后，两个下标恰好等于各侧实际已通过的车数。
初始均为零。表格完整对应当前两车的优先权规则；从同一旧状态同时更新，
就准确重现下一秒并保持不变式。一侧清空后，其余车辆每秒通过一辆，
追加尾部数量也准确，因此结果就是实际清空时间。

每轮至少通过一辆车：要么一辆左转车让非左转车先行，要么两辆都走。
设初始长度为 `s`、`t`，时间 `O(s+t)`，额外状态 `O(1)`，包括输入字符串
则空间 `O(s+t)`。答案在 `max(s,t)` 与 `s+t` 之间，最多 2,000 秒。

第一例第一秒南侧 `R` 与北侧 `F` 同时通过；第二秒南侧 `L` 等待另一辆
北侧 `F`；第三、四秒分别通过南侧 `L` 和 `F`。第二例两个左转同时通过，
只需一秒。

注意事项：

- 两个出发决定都必须在推进下标前计算，新队首不能参与当前秒。
- 左转既要让直行，也要让对向右转。
- 两辆相向左转车可以同时通过。
- 一队清空后仍要计入另一队剩余车辆。

## 各语言说明

五种实现都只需两个字符串下标。Python 将布尔值加到下标上，其余版本
转换布尔值或用条件递增。普通整数足以容纳结果。
