# 2088. Шанс победы при лучшем цвете после слепой раздачи

[Timus 2088](https://acm.timus.ru/problem.aspx?space=1&num=2088) · сложность 5167 · dp, combinatorics

Автор оригинальной задачи — Евгений Курпилянский.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В колоде карты цветов 0 … k; цвет 0 — джокер. Саша берёт несколько
известных карт, затем получает t случайных карт из оставшихся. Зная
руку, Саша называет цвет c ≥ 1, при котором шанс победы наибольший;
затем из оставшейся колоды открывают y случайных карт, и Саша
выигрывает, если в руке хотя бы на x карт цветов 0 и c больше, чем среди
открытых. Найдите вероятность победы Саши по модулю 10⁹ + 7.
Ограничения: 2 секунды и 256 МБ.

## Входные данные

k ≤ 100 и t ≤ 100, количества c₀ … c_k карт каждого цвета в колоде (не
больше 100 карт), количества s₀ … s_k, которые берёт Саша, затем x и y.

## Выходные данные

Вероятность p/q в виде p·q⁻¹ по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
3 1
1 2 0 1
0 1 0 0
1 2
```

Вывод:

```
666666672
```

### Пример 2

Ввод:

```
2 3
6 5 3
2 2 0
5 3
```

Вывод:

```
176428573
```

## Решение

После известных карт остаётся rᵢ карт цвета i, всего R, и D = R − t
остаются в колоде после слепой раздачи. Пусть в руке h карт цветов 0 и
c. Тогда в колоде u = c₀ + c_c − h таких карт, открытые карты
подчиняются гипергеометрическому закону, и Саша выигрывает, когда среди
y открытых не больше h − x карт цветов 0 и c. Значит, число выигрышных
открытий из C(D, y) равно
W(u, h − x) = Σ_{j ≤ h−x} C(u, j) C(D − u, y − j), и эта таблица
считается один раз.

Слепая раздача даёт z джокеров и dᵢ карт цвета i, Σ dᵢ = t − z; у неё
C(r₀, z) Π C(rᵢ, dᵢ) равновероятных вариантов. При фиксированном z оценка
цвета i зависит только от dᵢ, а ответу нужна сумма по всем раздачам
максимальной оценки. Эта сумма собирается по порогам: все пары
(цвет, dᵢ > 0) сортируются по оценке, и хранится многочлен
P(X) = Π Fᵢ(X), где Fᵢ — сумма C(rᵢ, d) X^d по уже разрешённым d
(d = 0 разрешено всегда, оно же даёт базовую оценку — максимум по цветам
оценки при dᵢ = 0). Разрешение ещё одной пары (i, d) превращает Fᵢ в
Fᵢ + C(rᵢ, d) X^d, поэтому P растёт на C(rᵢ, d) X^d · P / Fᵢ; деление
точное, ведь Fᵢ начинается с 1. Прирост коэффициента при X^{t−z}
считает раздачи, у которых лучшая оценка только что стала этой, и
каждая добавляется с этой оценкой. Количества приводятся по модулю
10⁹ + 7, и результат делится на C(R, t) C(D, y). Предвычисление требует
O(N²) операций, где N = 100 — ограничение на число карт. Есть O(t + 1)
вариантов числа джокеров и O(k t) событий для каждого; при каждом
формальном делении вычисляются O(t) коэффициентов с использованием до
O(t) предыдущих членов для каждого коэффициента. Оценка времени в
худшем случае — O(N² + k (t + 1)^4).

Ловушка (генерируемый тест gen8, аргументы `5 8`): деление многочленов
квадратично, поэтому линейная оценка теряет множитель t. Для чётного
t ≤ 50 допустимое семейство k = 1, c = (t, t), s = (0, 0), x = y = 0
выполняет t²(t² − 4)/48 итераций внутреннего цикла деления, хотя ответ
всегда равен 1. Поэтому пороговая динамика может требовать Θ(t^4)
времени даже при одном цвете.

В первом примере при любой руке лучший выбор — цвет 1, и две из трёх
равновероятных рук выигрывают, поэтому ответ 2/3.

## Особенности языков

Оценки сравниваются точно; они доходят до C(100, 50) ≈ 10²⁹. C++ и Rust
хранят их в беззнаковых 128-битных целых, Go и Java — в длинных целых, а
Python — в своих целых.
