# 2059. 比较回文串的出现频率

[Timus 2059](https://acm.timus.ru/problem.aspx?space=1&num=2059) · difficulty 1487 · strings

原题作者 Mikhail Rubinchik，出自 2015 年 7 月 11 日回文专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对两个词 A 和 B，考察在其中至少一个里出现的所有不同回文。分别统计在 A 中出现更多次的回文、在两者中出现次数相同的回文，以及在 B 中出现更多次的回文。出现位置可以重叠，区分大小写。时间限制 1 秒，内存限制 64 MB。

## 输入

测试数 T，然后每个测试两行，分别为 A 和 B。每个词非空，长度不超过 200 000；全部输入不超过 8 MB。

## 输出

第 i 个测试输出一行 `Case #i: x y z`，给出三个计数。

## 评测方式

检查器比较每个测试的三个数，数之间的空白无关紧要。

## 样例

```
3
abacab
abccab
faultydogeuniversity
hasnopalindromeatall
abbacabbaccab
youmayexpectedstrongsamplesbutnow
```

```
Case #1: 4 1 2
Case #2: 8 3 9
Case #3: 13 0 15
```

第一组中，`a,aba,aca,bacab` 在 `abacab` 中出现更多，`b` 在两串中都出现两次，而 `c,cc` 在 `abccab` 中出现更多，所以输出 `4 1 2`。第二组的回文并集有 20 种，分为 `8+3+9`；第三组有 28 种，分为 `13+0+15`。必须计算重叠出现，例如 `aaaa` 中 `aa` 出现三次，比较 `aaaa` 与 `aaa` 得到 `4 0 0`。

## 解法

### 共用一棵回文树

真实节点分别表示不同的回文串，另设长度 `−1` 与 `0` 的两个辅助根。标号为 `c` 的边将内部回文 `P` 扩展成 `cPc`；从奇根出发则得到单字符 `c`。每个节点记录长度、指向最长真回文后缀的 `link`，以及稀疏孩子链表。

从左到右扫描 `A`。从此前最长回文后缀沿后缀链接向上，直到能用新字符包住该回文。沿对应边转移，没有边则新建。新节点的后缀链接从其父节点的链接开始同样查找。读取回文前面的字符之前，必须检查当前字符串的左边界。

然后保留节点与边来扫描 `B`，但把活动后缀重置为空根，并改用 `B` 的边界。相同回文因此共享节点，又不会产生跨越两个字符串边界的回文。编译型语言版本的每个节点有两个初始为零的计数器。每处理一个位置，只给当前最长后缀在对应字符串中的计数器加一。

### 得到全部出现次数

按创建编号从大到小处理真实节点，把 `v` 的两个计数器分别加到 `link[v]` 的计数器上。再比较 `v` 的两项计数，增加 `x,y,z` 中的一项。两个辅助根不参与分类。

Python 用等价的有符号差值代替两个计数器：扫描 `A` 时加 `+1`，扫描 `B` 时加 `−1`，然后按相同的倒序沿后缀链接传播差值。正、零、负分别计入 `x,y,z`。减法与传播可交换，因此结果与比较两个完整出现次数完全相同。

内部回文和两端相同字符唯一确定整个回文，所以共用节点表示一个不同字符串，而不是一次出现。在一个位置至多新增最长回文后缀：任何更短的回文后缀同时也是最长者的前缀，已经在更早的位置出现。因此总节点数至多 `|A|+|B|+2`，新节点的真回文后缀必有更早的编号。

固定一个结束位置，所有在此结束的回文各自在最长后缀的链接链上出现一次。起初只在这条链顶部放一个标记；计数传播将它恰好一次地送到每个祖先。因此每个节点获得的标记数正是其回文的结束位置数，即出现次数。即使出现相互重叠，不同结束位置仍然分别计算。链接总指向更早编号，倒序保证所有后代先于祖先处理，由此证明两个字符串的计数都正确。每个真实节点至少在一串中出现，所以相等的两项计数自动为正；最终分类正好统计所需的不同回文。

### 多组测试与实现

测试之间复用数组。清空两个根的孩子链头和计数，每次分配新的活动编号时初始化该槽的全部相关字段，包括孩子链头与两项计数。旧的不可达槽不会影响新树。Python 每个节点只重置一个差值计数器，在 `span` 中存储长度加一，在每个词前加零字节哨兵，并为两个根使用按字节直接索引的转移表。两个单字符字符串是基本情形：相同则为 `0 1 0`，不同则为 `1 0 1`。

Python 还直接处理两个词都由单一字符组成，或两个词都是周期为二的交替词的情况。在交替词中，每个首字符对应一族奇数长度回文，长度每增加二，出现次数就减少一。两个词使用相同的双字符集合时共享这些回文族；集合不同时只能共享单字符回文。如果两个词都没有长度为二或三的回文，就只需统计单字符，因为任何更长回文的中心都包含这样的回文。两个词相同时，Python 只为其中一个建树，所有真实节点都计入相等项。它还复用上一对词的答案；词序交换时交换 `x,z`。这些捷径保持频率不变，也不改变最坏复杂度。

若字符表大小为 `σ`，一次转移最多扫描 `σ` 个孩子，每组时间为 `O(σ(|A|+|B|))`。后缀链接查找的长度下降总量是线性的，因为一次扩展最多使相关后缀增长二；计数传播也为线性。对固定字节字符表，时间为 `O(|A|+|B|)`，活动节点空间为 `O(|A|+|B|)`。编译型语言一次性分配最多 `400002` 个槽，Python 按遇到的最大输入对扩容，避免为每个极小测试重新初始化大数组。所有次数均适合有符号 32 位整数。

C++ 从输入流逐行读取字符串；Python 把输入保存在 `BytesIO` 中再按行读取。Go、Java 保留至多 8 MiB 的输入缓冲，Rust 也保存输入。输出使用有界分块缓冲，不会因接近两百万组小测试而保存全部答案。Python 使用复用的紧凑数组。

不能建立互不相关的两棵树后直接比较节点编号，因为不同树中编号不代表相同字符串。开始 `B` 时重置活动后缀。只标记最长后缀；若先增加整条链又传播，会重复计数。保持逆拓扑顺序，忽略空根，计入重叠，比较完整频率而不只是是否存在。复用槽时重置两个计数器。除了单串长度，还要测试总输入 8 MB 的情形。
Python 的有符号计数为零表示频率相等，而非未出现：只对已经创建的真实节点分类。例如测试 `002` 中将 `abba` 与自身比较，答案必须为 `0 4 0`。生成器在 Windows 上也必须输出 LF：转换为 CRLF 会使 `max_many_single_letters` 和 `max_many_varied_single_letters` 超过总输入大小限制。
