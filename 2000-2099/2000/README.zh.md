# 2000. Grand Theft Array V

[Timus 2000](https://acm.timus.ru/problem.aspx?space=1&num=2000) · 难度 160 · games

原题作者 Ilya Kuchumov. (Prepared by Kirill Devyatkin)，出自 2013 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两人从非负数数组的指定位置开始，第一人先手，随后交替。每回合先取得当前位置的数并清零，再向左或右移动一格，不得越界；两人可以同格。全部数变零时结束。每人优先最大化自己的最终分数，平分时最小化对方分数。求双方最优得分。

`10≤n≤100000`，数值 0–10000，起点 `p,q` 从 1 编号。时间 0.5 秒、内存 64 MB。

## 输入

先给长度 `n`，再给 `n` 个数，最后依次给第一、第二人的起点。

## 输出

第一人、第二人的得分两个整数。

## 评测方式

按记号逐个比较输出。

## 样例

```
10
1 2 3 4 5 6 7 8 9 0
4 8
```

```
21 24
```

起点 4、8 的中点是 6，等距时第一人先收取。第一人得到 1–6 的总和 21，第二人得到 7–10 的总和 24。

## 解法

游戏结束后两人总分固定为原数组总和，因此最大化自己已等价于最小化对方。数值非负，保证整个区域的重量不会因避开某格而更好。

### 起点不同

最早收取格 `i` 的全局回合分别为 `T1(i)=2·|i−p|+1`、`T2(i)=2·|i−q|+2`，等距离归第一人。这把线分为连续区域。`p<q` 时，令 `c=floor((p+q)/2)`，第一人取得 1..c；`p>q` 时，令 `c=ceil((p+q)/2)`，第一人取得 c..n。第二人取得其余部分。

仅比较距离还不够，因为无法同时往两端走。区域保证策略是先朝对手走到自己最远边界，在对手能够收取之前收下该格，然后立即反向走到外侧端点。对手若要进入该外侧区域，必须经过这条边界。虽然可以同格，但反向之后的收取优先权已经在区域主人手中；对手速度相同，只能跟随，无法超越向外的路线。因此整段区域均能保证。

双方都能保证各自区域，且两者之和为全部重量，故任何人都无法对抗另一人的保护策略而获得更多。这证明分数最优；这里利用收取时序，不把站人位置当障碍。

### 起点相同

第一人取得起点值。令 `L,R` 为严格左、右两侧总和，第一人选较重侧直接走到端点，可保证 `a[p]+max(L,R)`，跟随者一直落后。第二人看见第一步后选择相反侧并守住移动前沿；第一人即使折返也无法抢在此前沿前收取。因此第一人最多得到起点加原先选择的一侧，不超过上述保证。起点位于端点时另一侧为空，第二人只能跟随、得零。

答案为第一人 `a[p]+max(L,R)`，第二人 `min(L,R)`。全零数组立即结束，均为零。

### 复杂度与验证步数

时间 `O(n)`，存数组空间 `O(n)`，额外变量 `O(1)`。总和至多 `10^9`，原生版本用 64 位分数。

区域保护路线在 `2n` 个个人回合内取得保证总和，所以 `4n` 个交替回合足够。截断最小最大搜索中，第一人的保护给出相同下界，第二人的保护给出互补上界，因为未收取权重非负。因此这个有限步数已经给出完整游戏的值，在 `4n` 步内做最小最大搜索就能精确检验小规模情形。

先收后走；不同起点的中点等距总归第一人，不论左右顺序。同起点必须选较重侧。经过零格仍花回合，同格不会阻挡。第一人在右边时不能交换玩家身份。
