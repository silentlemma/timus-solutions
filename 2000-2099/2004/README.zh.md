# 2004. 包含所有二进制单词的最短串

[Timus 2004](https://acm.timus.ru/problem.aspx?space=1&num=2004) · 难度 761 · graphs, greedy

原题作者 Ilya Kuchumov，出自 2013 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

将 0 到 `2^n−1` 的每个整数写成恰好 `n` 位的二进制形式，保留前导零。分成长度 `ceil(n/2)` 的高位块与长度 `floor(n/2)` 的低位块，再把低位块移到高位块前面，各块内部顺序不变。求一个最短二进制串，使所有结果都作为连续子串出现。任意最优答案均可。

## 输入

一个整数 `n`，`1 ≤ n ≤ 20`。时间限制 0.5 秒，内存 64 MB。

## 输出

一个长度最小的二进制串，前导零不能省略。

## 评测方式

检查器确认答案是长度为 2ⁿ + n − 1 的二进制串，并且包含所有长度为 n 的词；任何这样的串都被接受。

## 样例

```
1
```

```
10
```

当 `n=1` 时必须出现 0 和 1。样例的 `10` 与程序输出的 `01` 都是最短答案。

## 解法

交换固定长度的两个位块是可逆的：在结果的前 `floor(n/2)` 位之后切开，再交换回来。因此无论 `n` 奇偶，变换后的集合仍是全部 `2^n` 个二进制单词，不必实际计算函数。

长度为 `L` 的串只有 `L−n+1` 个长度为 `n` 的窗口。覆盖 `2^n` 个不同单词，必有 `L≥2^n+n−1`。下面构造达到此下界的串。

以所有 `n−1` 位单词为有向图顶点。每个 `n` 位单词是一条从其前缀到其后缀的边，边标签为最后一位。每个顶点入度和出度均为 2。当 `n=1` 时，只有空单词一个顶点和两条自环。欧拉回路使相邻边重叠，恰好拼出所有单词各一次。

先输出 `n` 个零，使用零顶点上的全零自环。之后若添加 1 得到的 `n` 位单词尚未使用，就添加 1，否则添加 0。用字节数组标记单词，以移位和掩码维护当前窗口。再添加 `2^n−1` 位即可。

为何此贪心无需回溯就能走完全部边？在非起点处，已用入边比已用出边多一条，而总入度等于总出度，所以不可能无边可走。提前停止只能在零顶点形成闭合回路，此时剩余边在每个顶点仍然平衡。若某个非零顶点还有出边，因优先选 1，其零边必尚未使用。由平衡，这条零边的终点也有未用出边。连续添加零至多 `n−1` 步到达零顶点，与在该点无边可走矛盾。最初的零自环是选择顺序的唯一例外，且就在起点。因此所有边均被使用，所有窗口不同，长度达到下界。

时间 `O(2^n+n)`，含输出与标记的空间为 `O(2^n+n)`。最大答案为 1,048,595 位，无需保存所有变换单词或递归栈。

输出是线性串，因此 `2^n` 条边的循环之外还需 `n−1` 位重叠前缀。循环前标记零单词。窗口只保留最后 `n` 位，掩码为 `2^n−1`。`n=1` 直接使用同一代码。不能把任意有效答案与某个固定字符串直接比较。
