# 2017. 两组自洽的陈述

[Timus 2017](https://acm.timus.ru/problem.aspx?space=1&num=2017) · 难度 1331 · graphs, bitmask, bfs

原题作者 Oleg Dolgorukov，出自 NEERC 2014 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`n` 个人各自给出一个地点，以及在该地点见到的人。每份陈述都将同一地点赋给
陈述者本人和列出的所有人。寻找人数最少的**非空**组，使组内全部陈述相互
一致，组外全部陈述也相互一致。两组可以对同一个人的位置有不同说法。
没有列出某人不表示某人不在那里：可能只是没有注意到。保证存在合法划分。

`2 ≤ n ≤ 400`；地点是长度 1 至 20 的小写拉丁字母串。
每份名单含 `0 ≤ m ≤ n−1` 个不同编号，编号为 1 至 `n`，严格递增，
且不包含陈述者。时间限制 1 秒，内存限制 64 MB。

## 输入

第一行是 `n`。之后按编号给出 `n` 行，每行依次为地点、名单长度 `m`，
以及在该地点见到的 `m` 个人的编号。

## 输出

第一行输出最小的正组大小，第二行输出所选的从一开始的编号。
可以输出任意最优组，编号顺序不限。

## 评测方式

检查器确认该组非空，组内和其余的人各自都一致，并且规模最小；任何最优的组都被接受。

## 样例

```
3
bar 0
bar 1 1
pool 2 1 2
```

```
1
3
```

```
3
pool 2 2 3
pool 2 1 3
pool 2 1 2
```

```
1
1
```

## 解法

为陈述者 `i` 构造位集 `C_i`，包含本人和名单中的所有人。两份陈述冲突，
当且仅当地点不同且 `C_i ∩ C_j` 非空。将这样的两个陈述者用无向边连接。
两个人把同一个**第三者**放在不同地点也产生冲突；只检查彼此是否看见
对方会漏边。地点相同时，名单不同不会产生冲突。

一组陈述自洽当且仅当其内部没有边。若存在边，共同提到的人就被赋予两个
不同地点；若没有边，所有关于同一人的陈述都一致，可以补全为一个位置
分配。因此两组均自洽等价于每条边的端点属于不同组，需要正确二染色，
仅求顶点覆盖不够。由存在性保证可知图是二分图。

用迭代广度优先搜索给每个连通分量染色。在一个连通二分分量中，确定一个
顶点的颜色就确定了全部颜色，只有交换两种颜色这两个选择。每个分量选
较小的一侧，平局任选。不同分量之间没有约束，所以局部最小相加就是全局最小。

孤立点的两侧大小为一和零，通常不选。如果最终为空，则整个图没有边，
任选一个人即可满足非空条件，且大小一显然最优。否则每个含边分量至少
贡献一人，独立取得的最小解已经非空。

第一例中两个 `bar` 陈述一致，而 `pool` 陈述与两者都冲突，应选编号 3。
第二例地点完全相同，没有边，任意单人组都最优。

设所有名单总长度为 `M`，位集机器字宽为 `w`。建位集及比较所有陈述对的
时间为 `O(M + n² ceil(n / w))`，染色另需 `O(n²)`。包含输入缓冲的空间
为 `O(n² + M)`。400 位只需七个 64 位机器字。

注意事项：

- 位集必须包含陈述者本人。
- 不能漏掉共同描述第三者造成的冲突。
- 所选组本身也必须自洽，最小顶点覆盖不足以解决问题。
- 每个分量独立交换两侧；只有整个答案为空时才需要补一个孤立点。
- 不要求互相看见，名单中没有出现某人也不构成否定断言。

## 各语言说明

C++ 使用 `std::bitset`，Go 与 Rust 使用 64 位数组，Java 使用 `BitSet`，
Python 使用任意精度整数。五种实现都用迭代遍历和相同的分量选择规则。
