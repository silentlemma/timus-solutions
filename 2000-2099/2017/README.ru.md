# 2017. Две согласованные группы

[Timus 2017](https://acm.timus.ru/problem.aspx?space=1&num=2017) · сложность 1331 · graphs, bitmask, bfs

Автор оригинальной задачи — Олег Долгоруков; NEERC 2014, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждый из `n` участников называет место и перечисляет людей, замеченных
там. Показание приписывает это место самому участнику и всем
перечисленным людям. Нужно выбрать наименьшую **непустую** группу так,
чтобы показания внутри неё не противоречили друг другу, а показания всех
оставшихся участников также были согласованы. Две группы могут
по-разному описывать местонахождение одного человека. Отсутствие
человека в списке ничего не запрещает: его могли не заметить.
Существование подходящего разбиения гарантировано.

Число участников `2 ≤ n ≤ 400`. Место — непустая строка длиной до 20 строчных
латинских букв. Список содержит `0 ≤ m ≤ n−1` различных номеров от 1 до `n`
в возрастающем порядке и не включает автора показания.
Лимиты: 1 секунда, 64 МБ.

## Входные данные

Первая строка содержит `n`. Следующие `n` строк относятся к участникам по
порядку: место, длина списка `m`, затем `m` номеров замеченных там людей.

## Выходные данные

В первой строке выведите положительный минимальный размер группы, во второй —
номера выбранных участников с единицы. Допустимы любой оптимум и любой порядок.

## Проверка

Проверяющая программа убеждается, что группа непуста, что и она, и
остальные согласованы, и что размер наименьший возможный; принимается
любая оптимальная группа.

## Примеры

```
3
bar 0
bar 1 1
pool 2 1 2
```

```
1
3
```

```
3
pool 2 2 3
pool 2 1 3
pool 2 1 2
```

```
1
1
```

## Решение

Создадим битовую маску `C_i`: сам участник `i` и все люди из его списка.
Показания двух участников противоречат друг другу тогда и только тогда,
когда места различаются, а `C_i ∩ C_j` непусто. Проведём между такими
участниками неориентированное ребро. Противоречие возникает и тогда, когда
два участника помещают **третьего** человека в разные места. Проверка только
непосредственных наблюдений друг за другом такие случаи пропускает.
При одинаковом месте различные списки не создают противоречия.

Множество показаний согласовано ровно тогда, когда внутри него нет ребра.
Если ребро есть, общему человеку назначены два места. Если рёбер нет, все
утверждения о каждом человеке совпадают; их можно дополнить до полного
назначения мест. Поэтому согласованность обеих групп равносильна тому, что
каждое ребро соединяет разные группы. Требуется правильная двухцветная
раскраска, а не только вершинное покрытие. По гарантии граф двудольный.

Обходом в ширину без рекурсии раскрасим каждую компоненту связности. В
связной двудольной компоненте выбор цвета одной вершины определяет цвета
всех остальных. Два варианта разбиения лишь меняют доли местами. Выберем
меньшую долю каждой компоненты; при равенстве подойдёт любая. Между
компонентами нет ограничений, поэтому независимые минимумы дают общий минимум.

Изолированная вершина образует доли размеров один и ноль, поэтому обычно
ничего не добавляет. Если итоговая группа пуста, во всём графе нет рёбер:
тогда берём любого одного участника, соблюдая положительность размера.
Иначе каждая компонента с ребром уже добавляет хотя бы одну вершину, и
найденный минимум непуст.

В первом примере показания двух участников из `bar` согласованы, а
показание из `pool` противоречит обоим: выбираем номер 3. Во втором примере
все места совпадают, рёбер нет и подходит любой один участник.

Пусть `M` — суммарная длина списков, а `w` — размер машинного слова маски.
Построение масок и проверка пар требуют `O(M + n² ceil(n / w))` времени,
обход — ещё `O(n²)`. Память `O(n² + M)` с учётом буферизованного ввода.
Для 400 участников хватает семи 64-битных слов на маску.

Подводные камни:

- Включайте участника в собственную маску.
- Учитывайте противоречия через третьего человека без прямого наблюдения.
- Выбранная группа тоже должна быть согласована: минимального вершинного
  покрытия мало.
- Выбирайте долю отдельно в каждой компоненте; изолированные вершины
  нужны лишь при пустом ответе.
- Не требуйте взаимного наблюдения и не считайте отсутствие в списке
  отрицательным утверждением.

## Особенности языков

C++ использует `std::bitset`, Go и Rust — массивы 64-битных слов, Java —
`BitSet`, Python — целые числа произвольной точности. Во всех пяти
реализациях одинаковое правило выбора компонент и нерекурсивный обход.
