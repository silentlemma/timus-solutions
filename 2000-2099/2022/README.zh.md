# 2022. 穿过厚墙水平孔洞的抛物线

[Timus 2022](https://acm.timus.ru/problem.aspx?space=1&num=2022) · 难度 3530 · geometry

原题作者 Nick Burlakov，出自 NEERC 2014 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

移动发射点从地面 `(0,0)` 以速度 `(vx,vy)` 起跳，只受向下重力 `g=10`。
墙的水平范围为 `L≤X≤L+l`，孔洞底面高 `h`、顶面高 `h+d`。当发射点
尚在空中且位于墙前时，可释放初始**绝对**速度为 `(ux,uy)` 的质点弹丸。
弹丸也只受重力。寻找任意释放时刻，使其穿过整个孔洞而不碰底面或顶面。

八个整数 `L,h,l,d,vx,vy,ux,uy` 均为 1 至 1,000，距离单位为米、速度
单位为米每秒，x 轴指向墙。时间从起跳开始计算。给出的时刻前后偏移
`ε=10⁻⁶` 秒也必须保持墙内净空。保证只要有可行答案，就有满足这种
稳健要求的答案。时间限制 1 秒，内存限制 64 MB。

## 输入

第一行 `L h l d`，第二行 `vx vy ux uy`。

## 输出

输出任意满足要求的释放时间，绝对或相对误差至多 `10⁻⁶`。
无解则输出 `-1`。

## 评测方式

检查器确认在与答案相差不超过 10⁻⁶ 的任何发射时刻，抛射物都能穿过整个开口，并且只有在没有可行时刻时才输出 `-1`；任何这样的时刻都被接受。

```
4 2 2 4
1 1 5 10
```

```
0.1
```

## 解法

时刻 `t` 发射点为 `(vx t,vy t−5t²)`。弹丸到墙坐标 `X` 的飞行时间为
`τ=(X−vx t)/ux`，故 `Y(t,X)=vy t−5t²+uy τ−5τ²`。
释放区间为 `0<t<T=min(2vy/10,L/vx)`。速度是绝对速度，不能再叠加发射点速度。

固定 `t` 时，高度关于 `X` 为凹二次函数，墙内最低处位于某个端面。
因此要求 `Y(t,L)>h` 且 `Y(t,L+l)>h`。乘以正数 `ux²` 得到
`ux²(Y(t,X)−H)=−At²+Bt+C`，其中
`A=5(ux²+vx²)`、`B=vy ux²−uy vx ux+10X vx`、
`C=uy X ux−5X²−H ux²`。每个底面条件在两个实根之间的开区间成立；
重根只是碰到底面，不合法。与释放范围相交后得到一个开区间 `I`。

顶面要检查最高处，可能在**墙内部**。轨迹顶点为 `X*=vx t+ux uy/10`。
墙内最大高度分三段：

- `X*≤L` 时为 `Y(t,L)`；
- `L≤X*≤L+l` 时为 `vy t−5t²+uy²/20`；
- `X*≥L+l` 时为 `Y(t,L+l)`。

分段时刻为 `(10L−ux uy)/(10vx)` 与 `(10(L+l)−ux uy)/(10vx)`。
对每一段求最大高度**不小于** `h+d` 的闭根区间，并与该段及 `I` 相交。
与顶面相切时，禁区可能只含一个点。

为何能把全部禁区合成一个区间？`Y(t,X)` 由线性项减去 `5t²` 和
`5((X−vx t)/ux)²`，因此联合凹。两个时刻各自的最优墙坐标的凸组合
仍在固定墙区间内；联合凹性说明混合时刻的最大值不小于两最大值的
相同加权和。因此 `F(t)=max_X Y(t,X)` 凹，超水平集 `F(t)≥h+d` 是
一个区间或单点。取禁区最左、最右边界，从 `I` 中减去这个**闭集**，
剩余至多两个开可行分量。

选择最宽分量的中点。宽度大于 `2ε` 就保证距两个时间边界都超过 `ε`，
也避开孤立的相切禁点。存在性承诺保证有解时存在这样的分量。
不能跨越中间禁区合并两个可行分量。只解常数个二次方程，时间和额外空间均为 `O(1)`。

为稳定求解 `−At²+Bt+C=0`，先用整数精确计算 `D=B²+4AC`。
`D>0` 时取 `q=(B+copysign(sqrt(D),B))/2`，两根为 `q/A`、`−C/q`，
避免相近数相减。`D=0` 单独处理。输入界给出 `A≤10⁷`、
`|B|≤1.02·10⁹`、`|C|≤2.02·10⁹`、`|D|≤1.1212·10¹⁸`，
所有中间乘法用有符号 64 位整数即可。输出应保留选定浮点值的往返精度。

第一例 `t=0.1` 时，两端高度为 4.808、4.888，内部顶点为 5.05，
都严格处于 2 与 6 之间。第二例中发射点的最大高度加弹丸额外上升
也只有 10，低于高 15 的底面，故无解。

注意事项：

- `h` 是底面高度，顶面为 `h+d`。
- 顶面检查必须包含内部轨迹顶点。
- 精确相切时不能丢弃零宽度禁点。
- 先用 64 位整数完成乘法，再转换成浮点数。
- 取单个可行分量的中点，并保留完整 ±ε 余量（测试 072–073）。
  生成器必须丢弃有可行时刻却没有宽度大于 `2ε` 的分量的输入：
  仅满足整数范围并不能保证稳健性承诺。例如，`random_full` 的种子 452071
  原本只生成宽约 1.256 微秒的可行分量。
