# 2072. Полив по сухости с концом каждой группы на её краю

[Timus 2072](https://acm.timus.ru/problem.aspx?space=1&num=2072) · сложность 207 · sorting, dp

Автор оригинальной задачи — Илья Кучумов; Уральская региональная командная олимпиада по программированию 2015.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n цветов стоят в ряд на расстоянии шага друг от друга, у каждого своя
сухость. Садовник начинает у самого левого цветка и должен полить все
цветы в порядке неубывания сухости; цветы одинаковой сухости можно
поливать в любом порядке. Полив цветка и шаг к соседу занимают по
минуте. Найдите наименьшее общее время. Ограничения: 2 секунды и 64 МБ.

## Входные данные

n, 1 ≤ n ≤ 10⁵, затем n значений сухости слева направо, каждое от 1 до
10⁹.

## Выходные данные

Наименьшее общее время в минутах.

## Примеры

### Пример 1

Ввод:

```
6
3 2 5 6 2 5
```

Вывод:

```
21
```

## Решение

Полив всегда занимает n минут, так что важна только ходьба. Отсортируем
цветы по сухости и разобьём на группы одинаковой сухости; группы
проходятся одна за другой. Внутри группы садовник должен побывать у
каждого цветка между её самой левой позицией l и самой правой r, так что
путь покрывает весь отрезок [l; r], и лучше всего дойти до одного конца
и пройти к другому. Он заканчивается в l или в r, и больше ничего из
прошлого для следующей группы не важно.

Поэтому для каждой группы хранятся два значения: наименьшее время
закончить её в l и в r. Из позиции p закончить в l стоит
|p − r| + (r − l) (сначала идём к r), а закончить в r —
|p − l| + (r − l). Каждое минимизируется по двум возможным концам
предыдущей группы; перед первой группой садовник стоит в позиции 1.
Ответ — меньшее из итоговых значений плюс n. Основное время уходит на
сортировку: O(n log n).

В примере группы — {2, 5}, {1}, {3, 6} и {4} (сухость 2, 3, 5 и 6), и
лучший путь занимает 15 шагов, плюс 6 поливов: 21.

## Особенности языков

Сумма может превышать 2³¹ (примерно до 10¹⁰), поэтому используются
64-битные целые. В Java сухость и позиция упакованы в один long для
сортировки.
