# 2072. 按干燥度浇水，每组在一端结束

[Timus 2072](https://acm.timus.ru/problem.aspx?space=1&num=2072) · 难度 207 · sorting, dp

原题作者 Ilya Kuchumov，出自 2015 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 朵花排成一行，相邻两朵相距一步，每朵花有各自的干燥度。园丁从最左边的花出发，必须按干燥度不减的顺序给所有花浇水；干燥度相同的花顺序任意。浇一朵花和走到相邻的花各需一分钟。求最短总时间。时间限制 2 秒，内存限制 64 MB。

## 输入

n（1 ≤ n ≤ 10⁵），然后从左到右给出 n 个干燥度，每个在 1 到 10⁹ 之间。

## 输出

最短总时间（分钟）。

## 样例

### 样例 1

输入：

```
6
3 2 5 6 2 5
```

输出：

```
21
```

## 解法

浇水总是 n 分钟，所以只需考虑行走。按干燥度排序并分成干燥度相同的组；各组必须依次完成。在一组内，园丁必须到达其最左位置 l 和最右位置 r 之间的每朵花，因此路线覆盖整个区间 [l; r]，最好的走法是先到一端再扫到另一端。结束点是 l 或 r，过去的其他信息对下一组都不重要。

因此每组只保存两个值：在 l 结束和在 r 结束的最短时间。从位置 p 出发，在 l 结束花费 |p − r| + (r − l)（先走到 r），在 r 结束花费 |p − l| + (r − l)。两者都对上一组的两个可能端点取最小；第一组之前园丁在位置 1。答案是最后两个值中较小者加 n。排序占主要时间：O(n log n)。

样例中各组为 {2, 5}、{1}、{3, 6} 和 {4}（干燥度 2、3、5、6），最佳路线走 15 步，加 6 次浇水，共 21。

## 各语言说明

总和可能超过 2³¹（约到 10¹⁰），所以使用 64 位整数。Java 把干燥度和位置打包进一个 long 来排序。
