# 2028. 生成三角和网格程序

[Timus 2028](https://acm.timus.ru/problem.aspx?space=1&num=2028) · 难度 879 · constructive

原题作者 Kirill Borozdin，出自 2014 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

输出一份下述网格语言程序。它收到一个整数 `n` 时，对每个 `1 ≤ n ≤ 100` 都必须恰好输出一个
`1+2+…+n` 并正常结束，任意正确程序均可。生成器本身不接收 `n`；唯一输入为可忽略的
`Good luck!`。生成器时间限制 1 秒，内存限制 64 MB。

生成程序的网格为 `H×W`，`1 ≤ H,W ≤ 100`。机器有当前寄存器及 `A`…`Z` 共 26 个内存寄存器，
初值全零。指针从左上角朝右出发；每个时钟先执行指令，再沿更新方向移动一格，不环绕。

| 指令 | 含义 |
| --- | --- |
| `^`、`>`、`v`、`<` | 分别设为上、右、下、左。 |
| `.` | 无操作。 |
| `A`…`Z` | 交换当前寄存器与指定内存寄存器。 |
| `?` | 读取到当前寄存器；唯一输入耗尽后重复读取 `n`。 |
| `!` | 输出当前值并清零。 |
| `+`、`-` | 当前值加一或减一。 |
| `@` | 当前值为零则逆时针转，否则顺时针转。 |
| `#` | 立即结束，不移动。 |

当前值绝对值超过 100000 时在移动前报 `OVERFLOW ERROR`，移出网格报 `RUNTIME ERROR`。
完成 1000000 个时钟仍未正常结束或先报错，则报 `TIME LIMIT EXCEEDED`。
要求生成的程序避免全部错误；先输出正确数字再报错也不合格。

## 输入

仅一行 `Good luck!`，属于生成器。生成程序的独立输入才是整数 `n`。

## 输出

输出 `H W`，再输出恰好 `H` 行、每行 `W` 个合法指令。该程序必须处理每个合法 `n`。

## 评测方式

检查器对 1 到 100 的每个 n 运行输出的程序，只有每次运行都恰好输出一次正确的和并正常停止才接受。官方样例中的程序只是展示格式，并不是正确答案，所以保存的样例输出标记为 `format_only`，不参与检查。

## 样例

```
Good luck!
```

```
4 6
?A?v>v
>..>@A
-...A!
^A.+<#
```
此官方样例仅说明输出格式，其中的程序不解决题目：目标输入 1 时输出 2 而不是 1。
生成器输出下面的正确程序，无需与这个格式示例相同。

## 解法

```text
6 11
>?v........
.>>.......v
..@A+AB+B-<
..B........
..-........
.^@A!#.....
```
用 `A` 存累积和、`B` 存临时计数，当前寄存器存外层计数 `q`，初值 `n`。
对 `q=n,n-1,…,1`，给 `A` 加 `q` 个单位，从 `B` 恢复 `q` 后减一。
计数归零后把 `A` 换到当前寄存器，输出并结束。

内层宏 `-B+BA+A` 先让当前值减一，再通过交换、加一、换回使 `B` 加一，同样使 `A` 加一。
执行 `j` 次后，当前值 `q-j`、`B=j`、`A=old_sum+j`。执行 `q` 次时当前值为零、
`B=q`，`A` 已增加 `q`。出口 `B-` 恢复 `q`、清空 `B`，并留下 `q-1`。

零基坐标的内层 `@` 在 `(2,2)`，从右向左进入；非零转上进入内层矩形，零则转下到 `B-`。
宏从右往左执行，因此在网格中反向书写。外层 `@` 在 `(5,2)`，朝下进入：非零转左到 `^`，
沿走廊经 `(1,1)`、`(1,2)` 返回；零转右到 `A!#`。输入格 `(0,1)` 只经过一次。

外层不变量为当前值 `q`、`B=0`，`A` 等于已处理的 `n` 至 `q+1` 之和。
内层不变量保证每轮恰好加入 `q` 并为 `q-1` 恢复外层状态。最终 `q=0` 时 `A=1+…+n`，
唯一输出位于最终出口，随后正常结束。所有寄存器值在 0 至 5050 之间，路径始终位于 6×11 网格内。

设 `S=n(n+1)/2`，入口三步、每个累加单位 18 步、外层轮次之间八步、最终出口六步，
精确步数为 `3+18S+8(n-1)+6 = 18S+8n+1`。`n=100` 时最大 91701，小于百万步。

生成器打印固定 66 格程序，时间及空间均为 `O(1)`；生成的程序执行时间为 `O(n²)`，寄存器空间为 `O(1)`。
两者是不同执行阶段，仅在生成器中算出公式不能代替可运行的目标网格程序。

注意事项：

- 官方样例只是格式示意，必须保留，但不能当正确程序。
- 生成器不读取 `n`；打印出的程序处理所有目标值。
- 字母指令交换而非复制，内层宏必须恢复当前计数。
- 注意两个 `@` 的进入方向及内层体的反向书写。
- 必须恰好一次正确输出并正常结束，输出后报错仍不合法。

## 各语言说明

五种生成器用命名高度、宽度常量打印相同字面指令行，可忽略输入。
固定输出就是要求的构造，内部循环处理全部目标值。点是真正的空操作，必须精确保留行宽和方向。
