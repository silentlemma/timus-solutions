# 2089. Победители, при которых ни одна команда не выигрывает дважды

[Timus 2089](https://acm.timus.ru/problem.aspx?space=1&num=2089) · сложность 949 · graphs, greedy

Автор оригинальной задачи — Александр Ипатов; подготовка — Егор Щелконогов.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

k команд играют n пар; каждая команда играет от одной до трёх пар.
Выберите победителя каждой пары — одну из двух её команд — так, чтобы ни
одна команда не выиграла две пары, или сообщите, что это невозможно.
Подходит любой правильный выбор. Ограничения: 2 секунды и 256 МБ.

## Входные данные

n и k, 1 ≤ n ≤ 10⁵, 2 ≤ k ≤ 10⁵, затем n пар.

## Выходные данные

`Yes` и победители пар по порядку, или `No`.

## Проверка

Проверяющая программа принимает `No`, только если так в ожидаемом
выводе, а иначе проверяет, что каждый победитель играет в своей паре и
выигрывает один раз.

## Примеры

### Пример 1

Ввод:

```
3 4
1 2
2 3
1 4
```

Вывод:

```
Yes
1
2
4
```

### Пример 2

Ввод:

```
6 4
1 2
1 3
1 4
2 3
2 4
3 4
```

Вывод:

```
No
```

## Решение

Команды — вершины, пары — рёбра; выбор победителей — это направление
каждого ребра в один из его концов так, чтобы в каждую вершину входило
не больше одного ребра. Связную часть, где рёбер больше, чем вершин, так
не направить, а часть, где их не больше, можно: это дерево или дерево с
одним лишним ребром, то есть ровно с одним циклом.

Построение обрывает листья. Команда с единственной нерешённой парой
выигрывает её; это никогда не мешает, ведь другой пользы от этой команды
нет, а у второй команды пары становится на одну нерешённую пару меньше,
и она сама может стать листом. Когда листьев не осталось, у каждой
оставшейся команды ноль или хотя бы две нерешённые пары. Если у какой-то
команды их всё ещё три, в её части слишком много рёбер, и ответ No.
Иначе оставшиеся пары образуют непересекающиеся циклы, и обход каждого
цикла отдаёт каждую пару команде, к которой она ведёт, так что каждая
команда на цикле выигрывает ровно одну. При степенях не больше трёх всё
работает за O(n + k).

Во втором примере четыре команды играют шесть пар — больше, чем могут
выиграть, поэтому ответ No.
