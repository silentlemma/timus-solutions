# 2099. Один поворот под прямым углом через четыре точки

[Timus 2099](https://acm.timus.ru/problem.aspx?space=1&num=2099) · сложность 574 · geometry

Автор оригинальной задачи — Денис Дублённых; Открытое личное первенство УрФУ по программированию 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Может ли точка, летящая по прямой, пройти A, затем B, повернуть на 90°
и затем по прямой пролететь через C, а потом D? Точкой поворота может
быть B или C. Ограничения: 1 секунда и 64 МБ.

## Входные данные

Целые координаты A, B, C, D в пространстве, по модулю до 10⁶; точки
попарно различны.

## Выходные данные

`Valid` или `Invalid`.

## Примеры

### Пример 1

Ввод:

```
-2 0 0
-1 0 0
0 1 0
0 2 0
```

Вывод:

```
Valid
```

## Решение

Первая прямая — A + t·AB, вторая проходит через C с направлением CD,
обе проходятся вперёд. Полёт возможен ровно тогда, когда:

- AB · CD = 0 — поворот под прямым углом;
- AC · (AB × CD) = 0 — прямые лежат в одной плоскости и, будучи
  перпендикулярными, пересекаются в точке P;
- P = A + t·AB при t = (AC · AB) / |AB|² (основание второй прямой на
  первой, ведь CD ⊥ AB) не раньше B: AC · AB ≥ |AB|²;
- C не раньше P на второй прямой: (C − P) · CD = AC · CD ≥ 0, потому что
  составляющая C − P вдоль AB ортогональна CD.

Все проверки точные, в целых числах. Смешанное произведение доходит
по модулю до 1,6·10¹⁹, за пределами 64-битных целых со знаком, поэтому
C++ и Rust считают его в 128-битных целых, а Go и Java — в длинных.

В примере первая прямая — ось x, вторая — ось y, поворот происходит в
начале координат после B = (−1, 0, 0), а C = (0, 1, 0) идёт после него:
Valid.
