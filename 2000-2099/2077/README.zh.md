# 2077. 用点或连字符的最短唯一缩写

[Timus 2077](https://acm.timus.ru/problem.aspx?space=1&num=2077) · 难度 6156 · strings, sorting

原题作者 Mikhail Rubinchik（由 Egor Shchelkonogov 整理）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

集合中的每个单词写成以下之一：整个单词、前缀加一个点、或者用连字符连接的前缀和后缀。若把点或连字符换成某个（可能为空的）字符串能得到某个单词，则该单词符合这个缩写。每个缩写只能被它自己的单词符合。先使总长度最小；再使整词书写的单词尽量多；再使连字符尽量少；最后使连字符前的前缀总长度最大。保证答案唯一。时间限制 0.5 秒，内存限制 32 MB。

## 输入

n（1 ≤ n ≤ 10⁶），然后是按字典序排列的 n 个不同的小写字母单词，总长度不超过 10⁶。

## 输出

按输入顺序每行输出一个缩写。

## 样例

### 样例 1

输入：

```
4
aba
abaca
add
dd
```

输出：

```
aba
a-ca
add
dd
```

### 样例 2

输入：

```
2
aa
aaaaa
```

输出：

```
aa
aaa.
```

### 样例 3

输入：

```
2
abc
abcdabc
```

输出：

```
abc
abcd.
```

## 解法

另一个单词是否符合某个缩写与其他缩写无关，所以每条准则都拆成对每个单词单独的选择：最短的缩写，长度相同时选整词，再选点而不是连字符，再选最长的前缀。前缀和后缀都非空（评测系统就是这样理解题意的）。长度为 m 的单词 w，整词代价为 m，长度为 a 的前缀加点代价为 a + 1，长度为 a 的前缀和长度为 b 的后缀加连字符代价为 a + b + 1，a + b ≤ m。

点。单词已排序，所以与 w 有共同前缀的单词构成 w 周围的一个连续区间，其他单词都没有的最短前缀（若存在）比 w 与两个相邻单词的较长公共前缀多一个字母。

连字符。另一个单词 v 符合 w[..a]-w[m−b..]，当且仅当 v 以 w 的前 a 个字母开头、以其后 b 个字母结尾，并且长度至少为 a + b。具有该前缀的单词是输入顺序中的区间 [lo, hi]。对后缀，把单词反转后排序并用栈遍历，这样为反转单词字典树的节点编号，并得到每个（单词, b）对应的节点；每个节点按编号递增保存其单词列表，总长度为 M 时共 M 项。于是 (a, b) 唯一，当且仅当在 (w, b) 节点的列表中，编号在 [lo, hi] 内且不是 w 的单词都短于 a + b。二分查找找到列表中的这一段，再用长度的区间最大值（32 个一块，块上建稀疏表）检查。

若 (a, b) 不唯一，则 (a − 1, b) 也不唯一：前缀区间只会变大，长度界只会变小。所以 a 从 m − 1 递减到 1，而 b 只增不减，每个单词至多检查 2m 次，每次 O(log n)。所有前缀的区间 [lo, hi] 由对排序单词的两遍栈扫描得到：一遍记录每个前缀区间的最后一个单词，另一遍在构造答案时维护第一个单词。a 自上而下扫描还意味着给定代价的第一个连字符缩写前缀最长，所以只有严格更便宜的才替换它。总时间 O(M log M)，数组约占 25 MB。

第一个样例中 “aba” 也符合 “a-a”，所以 “abaca” 写成 “a-ca”，比整词或 “abac.” 都短。第二个样例中 “a-aa” 对 “aaaaa” 是唯一的，因为 “aa” 太短，放不下两部分，但 “aaa.” 长度相同，而点优先于连字符。
