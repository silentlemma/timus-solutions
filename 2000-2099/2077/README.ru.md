# 2077. Кратчайшие однозначные сокращения с точкой или дефисом

[Timus 2077](https://acm.timus.ru/problem.aspx?space=1&num=2077) · сложность 6151 · strings, sorting

Автор оригинальной задачи — Михаил Рубинчик (Подготовка — Егор Щелконогов).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждое слово набора записывается целиком, префиксом с точкой или
префиксом и суффиксом, соединёнными дефисом. Слово подходит под
сокращение, если заменой точки или дефиса на некоторую (возможно,
пустую) строку получается это слово. Под каждое сокращение должно
подходить только своё слово. Нужно минимизировать суммарную длину; затем
записать целиком как можно больше слов; затем использовать как можно
меньше дефисов; затем максимизировать суммарную длину префиксов перед
дефисами. Ответ гарантированно единственный. Ограничения: 0.5 секунды и
32 МБ.

## Входные данные

n, 1 ≤ n ≤ 10⁶, затем n различных слов из строчных букв в
лексикографическом порядке суммарной длиной не больше 10⁶.

## Выходные данные

Сокращения по одному в строке в порядке ввода.

## Примеры

### Пример 1

Ввод:

```
4
aba
abaca
add
dd
```

Вывод:

```
aba
a-ca
add
dd
```

### Пример 2

Ввод:

```
2
aa
aaaaa
```

Вывод:

```
aa
aaa.
```

### Пример 3

Ввод:

```
2
abc
abcdabc
```

Вывод:

```
abc
abcd.
```

## Решение

Подходит ли под сокращение другое слово, не зависит от остальных
сокращений, поэтому каждый критерий распадается на выбор для каждого
слова отдельно: кратчайшее сокращение, при равенстве — слово целиком,
затем точка, а не дефис, затем самый длинный префикс. Префиксы и
суффиксы непустые (так условие понимает проверяющая система). Слово w
длины m стоит m целиком, a + 1 с префиксом длины a и точкой и a + b + 1
с дефисом между префиксом длины a и суффиксом длины b, a + b ≤ m.

Точка. Слова отсортированы, поэтому слова с общим префиксом с w образуют
отрезок вокруг w, и кратчайший префикс, которого нет ни у какого другого
слова, на единицу длиннее большего из общих префиксов w с двумя
соседями.

Дефис. Другое слово v подходит под w[..a]-w[m−b..], если начинается с
первых a букв w, кончается его последними b буквами и имеет длину не
меньше a + b. Слова с этим префиксом — отрезок [lo, hi] порядка ввода.
Для суффиксов перевёрнутые слова сортируются и обходятся со стеком,
который нумерует узлы дерева суффиксов и даёт узел каждой пары
(слово, b); у каждого узла есть список его слов по возрастанию номера,
всего M записей при суммарной длине M. Пара (a, b) однозначна, если в
списке узла (w, b) слова с номерами из [lo, hi], кроме w, все короче
a + b. Двоичный поиск находит эту часть списка, а максимум длин на
отрезке (блоки по 32 и разреженная таблица по блокам) проверяет её.

Если (a, b) неоднозначна, то и (a − 1, b) тоже: отрезок префикса только
растёт, а ограничение на длину только уменьшается. Поэтому a идёт от
m − 1 вниз до 1, а b только растёт — не больше 2m проверок на слово,
каждая за O(log n). Отрезки [lo, hi] для всех префиксов дают два прохода
со стеками по отсортированным словам: один запоминает последнее слово
каждого отрезка, другой хранит первое, пока строятся ответы. Перебор a
сверху вниз означает ещё, что первый дефис данной стоимости имеет самый
длинный префикс, так что заменяет его только строго более дешёвый. Всё
работает за O(M log n), а массивы занимают около 25 МБ.

В первом примере под «a-a» подошло бы и «aba», поэтому «abaca»
становится «a-ca» — это короче, чем слово целиком или «abac.». Во втором
примере «a-aa» однозначно для «aaaaa», так как «aa» слишком коротко,
чтобы вместить обе части, но «aaa.» той же длины, а точка лучше
дефиса.
