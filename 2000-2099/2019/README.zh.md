# 2019. 不交叉的同类型端点配对

[Timus 2019](https://acm.timus.ru/problem.aspx?space=1&num=2019) · 难度 297 · greedy

原题作者 Denis Dublennykh（由 Oleg Merkurev 整理），出自 NEERC 2014 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

半圆上按顺序排列 `2n` 个不同端点，用拉丁字母表示，其中恰有 `n` 个大写
和 `n` 个小写。把每个大写端点与忽略大小写后相同的小写端点配对，每个
端点使用一次，连接的直线段不得相交。输出任意合法配对，或报告无解。

`1 ≤ n ≤ 5,000`，26 种字母均可重复。大写端点和小写端点按出现顺序
**分别**从 1 至 `n` 编号。时间限制 1 秒，内存限制 64 MB。

## 输入

第一行是 `n`，第二行是恰有 `2n` 个大小写拉丁字母的字符串。

## 输出

有解时，按大写端点顺序输出其对应的 `n` 个互异小写编号。
任意合法答案均可。无解时输出准确的 `Impossible`。

## 评测方式

检查器确认每对连接的是同一种字母、每个端点恰用一次且线段互不相交；只有不存在匹配时才接受 `Impossible`。任何合法的匹配都被接受。

## 样例

```
2
AbBa
```

```
2 1
```

```
2
AbaB
```

```
Impossible
```

```
1
Ab
```

```
Impossible
```

## 解法

半圆上两条弦相交，当且仅当它们的端点交替出现。嵌套或分离的配对不会
相交。任意完整的不交叉配对都有一个最内层对，其两端在剩余位置中相邻。
反复删除这些对可将字符串变空。反过来，消去相邻的同字母异大小写端点，
可以构造不交叉配对，因为每个记录对内部的端点都已完成配对。

从左到右扫描，用栈保存尚未配对的端点，同时分别记录大小写编号。
当前字母若与栈顶类型相同、大小写相反，就弹栈并记录这一对，否则入栈。
大写在前、小写在前均允许。无论谁先出现，答案总以大写编号为下标，
保存小写编号。最终栈不空则输出 `Impossible`。

为什么贪心消去不会破坏有解性？任意两个可选的相邻消去，要么互不重叠，
先后次序可以交换；要么在 `xXx` 或 `XxX` 上重叠，任意选择都留下同一个
字母。每次消去都严格缩短字符串，因此对长度归纳可知最终不可约字符串
唯一：不同的第一步之后，结果已经相同，或再删除另一对就会相同，后续
对更短的字符串应用归纳假设。

栈始终保存已处理前缀的不可约形式。添加一个字母只可能消去栈顶，或保持
不可约，所以栈算出的就是上述唯一结果。若完整不交叉配对存在，按最内层
顺序消去能得到空串，栈也必定为空；非空残留则证明无解。栈为空时，记录
的各对嵌套或分离，类型吻合且覆盖所有端点，故得到正确答案。

`AbBa` 先消去 `bB`，再消去 `Aa`，大写顺序的答案为 `2 1`。
`AbaB` 中唯一类型匹配的线段端点交替，必然交叉。`Ab` 的类型不同。
即使每种字母数量平衡也不够，例如 `ABab` 仍无解。

每个端点至多入栈一次、出栈一次，时间 `O(n)`，空间 `O(n)`。
栈最多有 `2n ≤ 10,000` 个端点。

注意事项：

- 大小写编号独立，不是字符串中的位置。
- 只有同字母、相反大小写才能消去。
- 小写端点可以先于对应的大写端点出现。
- 每种字母数量相等不能保证不交叉。
- 按大写顺序输出小写编号，注意 `Impossible` 的准确拼写。

## 各语言说明

使用 ASCII 字符或字节；同一拉丁字母相反大小写的编码异或为 32。
C++、Go 使用端点结构，Rust、Python 使用二元组，Java 使用平行数组和
栈大小。所有扫描均为迭代，普通整数足以存储编号。
