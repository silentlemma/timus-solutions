# 2019. Сопоставление типов без пересечений

[Timus 2019](https://acm.timus.ru/problem.aspx?space=1&num=2019) · сложность 297 · greedy

Автор оригинальной задачи — Денис Дублённых; подготовка — Олег Меркурьев. NEERC 2014, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На полуокружности последовательно расположены `2n` различных точек,
обозначенных латинскими буквами: ровно `n` заглавных и `n` строчных.
Нужно сопоставить каждой заглавной точке строчную с той же буквой без учёта
регистра. Каждая точка используется один раз, а соединяющие отрезки не
должны пересекаться. Найдите любое сопоставление или установите невозможность.

Число пар `1 ≤ n ≤ 5000`; все 26 типов могут повторяться.
Заглавные и строчные точки нумеруются **независимо**, каждые от 1 до `n`
в порядке появления. Лимиты: 1 секунда, 64 МБ.

## Входные данные

Первая строка содержит `n`, вторая — слово из ровно `2n` заглавных и строчных
латинских букв.

## Выходные данные

Если решение существует, выведите `n` различных номеров строчных точек в
порядке соответствующих заглавных: сначала партнёр первой, затем второй
и так далее. Допустимо любое правильное сопоставление. Иначе выведите
`Impossible`.

## Проверка

Проверяющая программа убеждается, что пары соединяют буквы одного вида,
используют каждый конец по разу и не пересекаются; `Impossible`
принимается, только если сопоставления нет. Принимается любое подходящее
сопоставление.

```
AbBa
```

```

```

```
2
```


## Решение

Две хорды полуокружности пересекаются ровно тогда, когда их концы
чередуются. Вложенные и непересекающиеся по порядку пары безопасны. В
любом полном непересекающемся сопоставлении есть самая внутренняя пара:
её концы соседние среди оставшихся точек. Удаляя такие пары, можно
опустошить слово. Обратно, удаление соседних одинаковых букв
противоположного регистра даёт непересекающееся сопоставление: точки
внутри очередной пары уже были сопоставлены.

Просматриваем слово слева направо, храня стек ещё не сопоставленных точек.
Каждой точке выдаём очередной номер её регистра. Если текущая буква и
вершина стека одного типа и разных регистров, снимаем вершину и записываем
пару; иначе кладём текущую точку в стек. Подходят оба порядка регистров.
Номер строчной точки сохраняем в ячейку ответа по номеру заглавной,
независимо от порядка их появления. Непустой стек в конце означает `Impossible`.

Обоснуем, почему жадное удаление не уничтожает решение. Два возможных
удаления соседних пар либо не затрагивают общие позиции и потому
переставляются местами, либо перекрываются в тройке `xXx` или `XxX`.
Во втором случае оба выбора оставляют одну и ту же букву. Каждое удаление
укорачивает слово. Индукция по длине показывает единственность окончательного
несократимого слова: после разных первых выборов результаты уже совпадают
либо совпадут после удаления второй пары; дальше применима гипотеза для
более коротких слов.

Стек хранит несократимую форму просмотренного префикса. Новая буква либо
сокращается с вершиной, либо оставляет префикс несократимым. Значит, стек
вычисляет общий результат всех порядков сокращения. Полное непересекающееся
сопоставление даёт сокращение до пустоты внутренними парами, поэтому стек
тоже опустеет. Непустой остаток доказывает отсутствие любого решения.
Если остаток пуст, записанные пары вложены или разделены, совпадают по
типу и используют все точки ровно один раз, то есть решение корректно.

В `AbBa` сначала сокращается `bB`, затем `Aa`: ответ `2 1`.
В `AbaB` единственные подходящие по типу пары имеют чередующиеся концы и
обязательно пересекаются. В `Ab` типы различаются уже у единственной пары.
Равенства количеств каждого типа недостаточно: пример — `ABab`.

Каждая точка попадает в стек не более одного раза и снимается не более
одного раза. Время `O(n)`, память `O(n)`, размер стека не больше `2n ≤ 10000`.

Подводные камни:

- Номера заглавных и строчных точек считаются отдельно и не равны
  позициям в слове.
- Сокращаются лишь одинаковые буквы разных регистров.
- Строчная точка может предшествовать своей заглавной паре.
- Одинаковых количеств букв недостаточно для отсутствия пересечений.
- Выводите партнёров в порядке заглавных точек и точно пишите `Impossible`.

## Особенности языков

Работаем с ASCII: коды противоположных регистров одной латинской буквы
отличаются битом 32. C++ и Go хранят структуры точек, Rust и Python — пары,
Java — два параллельных массива и размер стека. Рекурсии нет, обычного
целого типа достаточно для индексов.
