# 2026. Максимальная знакопеременная сумма букв

[Timus 2026](https://acm.timus.ru/problem.aspx?space=1&num=2026) · сложность 594 · greedy

Автор оригинальной задачи — Алексей Данилюк; Уральская региональная командная олимпиада по программированию 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Замените каждый `?` строчной латинской буквой, сохранив все заданные буквы.
В результате должно быть хотя бы `k` различных букв. Значение буквы — её номер
в алфавите от `a = 1` до `z = 26`. Качество равно сумме значений на нечётных
местах минус сумма на чётных, при нумерации с единицы. Выведите любое заполнение
максимального качества либо сообщите, что требование о числе букв невыполнимо.

Ограничения: длина `1 ≤ n ≤ 100000`, `1 ≤ k ≤ 26`, 1 секунда, 64 МБ.
Качество может быть отрицательным.

## Входные данные

Первая строка — шаблон из строчных латинских букв и вопросительных
знаков. Вторая — `k`.

## Выходные данные

Оптимальная заполненная строка либо `-1`, если заполнение невозможно.
Выводится сама строка, а не её качество. Допустимую строку с качеством
−1 тоже нужно вывести.

## Проверка

Проверяющая программа сверяет буквы, фиксированные позиции и число
различных букв и сравнивает качество с оптимумом; принимается любое
оптимальное заполнение.

## Решение

Пусть `F` — множество уже заданных букв, `P` и `M` — количества
свободных мест с плюсом и минусом. При нумерации с нуля чётные индексы
имеют плюс. Нужно добавить `r = max(0, k-|F|)` новых различных букв. Так
как `k ≤ 26`, отсутствующих букв не меньше `r`. Условие существования —
ровно `P+M ≥ r`: каждой новой букве нужно отдельное свободное место, а
достаточное число мест позволяет их разместить.

Без ограничения разнообразия заполним все плюсы буквой `z`, все минусы — `a`.
Это базовый максимум качества. Замена на значение `c` теряет `26-c` на плюсе
или `c-1` на минусе. Все потери неотрицательны.

Перечислим отсутствующие значения по возрастанию. Для `x` новых букв на плюсах
минимальная потеря получается у `x` наибольших значений, для `y` на минусах —
у `y` наименьших. Построим префиксные стоимости `high[x]` и `low[y]`.
Переберём `max(0,r-M) ≤ x ≤ min(r,P)`, положим `y = r-x` и выберем минимум
`high[x]+low[y]`.

После базового заполнения разместим выбранные большие буквы по одной на любых
`x` свободных плюсах, малые — на любых `y` минусах. Выбранные множества не
пересекаются: вместе в них `r` букв, а отсутствующих не меньше `r`. Остальные
места сохраняют базовые буквы. При равных стоимостях подходит любой вариант `x`.

Докажем оптимальность. В любом допустимом заполнении выберем любые `r`
новых различных букв и по одному месту-представителю каждой. Пусть `x`
представителей стоят на плюсах, `y` — на минусах. Их суммарная потеря не
больше полной потери, поскольку остальные потери неотрицательны. Для
плюсов нижняя граница — `high[x]`, для минусов — `low[y]`. Значит,
полная потеря не меньше перебранного минимума. Обе отдельные границы
достижимы одновременно: наибольшие `x` и наименьшие `y` отсутствующие
буквы не пересекаются. Наше заполнение достигает этой границы, добавляя
`r` типов, поэтому глобально оптимально. Базовые буквы могут дать ещё
типы: требуется хотя бы `k`, а не ровно `k`.

В первом примере `za` даёт `26-1 = 25`, базовый максимум; при `k = 1` разрешены
две буквы. Во втором на двух местах нельзя разместить три типа. В третьем
единственная строка уже задана и имеет качество `1-26+1 = -24`. В четвёртом
та же строка содержит только два типа, поэтому ответ невозможен.

При алфавите `σ = 26` время и память — `O(n + σ)`, то есть `O(n)`.
Хранятся индексы свободных мест и ответ, а префиксы стоимостей имеют
длину `σ+1`. Альтернатива — динамика чекера: каждую отсутствующую букву
пропустить либо назначить представителю одного из знаков, учитывая два
количества представителей.

Подводные камни:

- В `F` входят только заданные буквы: базовые `a` и `z` могут быть перезаписаны.
- Сохраняйте заданные места и правильно переводите чётность индексов.
- Не требуйте ровно `k` типов и не сравнивайте с одной конкретной
  оптимальной строкой.
- При `r = 0` подходит базовый максимум; отрицательное качество
  фиксированной строки допустимо.
- Вход `ab` с `k = 2` допускает строку качества −1: выводится `ab`, а не `-1`.

## Особенности языков

Все значения помещаются в обычные целые. C++, Go и Rust хранят индексы в
векторах или срезах; Java — в целочисленных массивах. Go и Rust работают
с ASCII-байтами, Python — с символами. Буферизация поддерживает строку
длины 100000; в Go используется `fmt.Fscan`, без стандартного лимита
длины токена Scanner. Другой интерпретатор для CPython не нужен.
