# 2026. 最大化字母交错和

[Timus 2026](https://acm.timus.ru/problem.aspx?space=1&num=2026) · 难度 594 · greedy

原题作者 Alexey Danilyuk，出自 2014 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

将每个 `?` 替换成小写英文字母，保持所有原有字母不变。结果至少包含 `k` 种不同字母。
字母权值是其字母表序号，即 `a = 1` 至 `z = 26`。从一开始编号，质量为奇数位置权值之和
减去偶数位置权值之和。输出质量最大的任意合法填法，或说明无法满足不同字母数要求。

限制：长度 `1 ≤ n ≤ 100000`、`1 ≤ k ≤ 26`、1 秒、64 MB。质量可以是负数。

## 输入

第一行是由小写英文字母和问号组成的模板，第二行是 `k`。

## 输出

输出一个最优完整字符串；若无解则输出 `-1`。要求输出字符串本身而非质量。
合法字符串的质量即使等于 −1，也必须输出该字符串。

## 评测方式

检查器核对字母、固定位置和不同字母的个数，并把质量与最优值比较；任何最优的补全都被接受。

## 解法

设 `F` 为固定字母集合，`P`、`M` 分别为正号与负号的空位数。零基下标的偶数位置是正号。
还需 `r = max(0, k-|F|)` 种新字母。因为 `k ≤ 26`，缺失字母至少有 `r` 种。
有解当且仅当 `P+M ≥ r`：每种新字母需要独立空位，空位足够就能放下。

暂不考虑种数，把正号空位填 `z`、负号空位填 `a`，得到无约束最大质量作为基准。
把正号改成权值 `c` 的损失为 `26-c`，负号为 `c-1`，均非负。

将缺失权值按升序列出。若在正号上引入 `x` 种新字母，损失最小的是最大的 `x` 个缺失值；
在负号上引入 `y` 种时取最小的 `y` 个。预处理相应前缀代价 `high[x]`、`low[y]`。
枚举 `max(0,r-M) ≤ x ≤ min(r,P)`，令 `y = r-x`，最小化 `high[x]+low[y]`。

先填基准，再把最大的 `x` 个缺失字母各放入一个正号空位，最小的 `y` 个各放入一个负号空位。
这两组互不相交，因为共需 `r` 个，而缺失字母总数至少为 `r`。其余空位保持基准字母。
多个 `x` 同样最优时任选其一。

证明：任意合法填法都有至少 `r` 种原来缺失的字母，任选 `r` 种，并为每种选一个代表空位。
设其中 `x` 个正号、`y` 个负号。其他位置损失非负，因此总代价不小于代表代价。
正号代表至少花费 `high[x]`，负号至少 `low[y]`，故总损失至少为枚举得到的最小值。
而最大的 `x` 个与最小的 `y` 个缺失字母不相交，所以两个独立下界可以同时达到。
构造达到该下界且引入 `r` 种字母，因而全局最优。基准字母额外增加种类也合法：要求至少 `k` 种而非恰好。

第一个样例 `za` 的质量为 `26-1 = 25`，已经是基准最大值；`k = 1` 允许出现两种字母。
第二个样例两个位置放不下三种字母。第三个样例只有固定字符串，质量为 `1-26+1 = -24`。
第四个样例该固定串仅两种字母，因此无解。

设字母表大小 `σ = 26`，时间和空间均为 `O(n + σ)`，即 `O(n)`。
程序保存空位下标与答案，代价前缀长度为 `σ+1`。另一种方法是检查器的 DP：
每个缺失字母可跳过、放正号代表或负号代表，状态记录两种代表数量。

注意事项：

- `F` 只统计固定字母；基准的 `a`、`z` 可能全部被替换。
- 固定位置不能修改，注意一基符号与零基下标的对应。
- 不要强制恰好 `k` 种，也不要固定某个最优字符串。
- `r = 0` 时直接使用基准；固定字符串的负质量仍可能合法。
- `ab`、`k = 2` 有解且质量为 −1，必须输出 `ab` 而不是 `-1`。

## 各语言说明

普通整数足够。C++、Go、Rust 用向量或切片保存空位下标，Java 使用整数数组。
Go 和 Rust 按 ASCII 字节处理，Python 使用字符。缓冲输入支持长度 100000 的 token；
Go 使用 `fmt.Fscan`，不受 Scanner 默认 token 长度上限限制。CPython 无需替代运行时。
