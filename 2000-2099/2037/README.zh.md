# 2037. 构造指定回文数量的二元词

[Timus 2037](https://acm.timus.ru/problem.aspx?space=1&num=2037) · 难度 1224 · constructive

原题作者 Mikhail Rubinchik，出自 2014 年夏季彼得罗扎沃茨克集训营乌拉尔联邦大学 Dandelion 专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对每个 `i=1,…,n`，构造一个长度为 `n`、仅含 `a,b` 的词，
使其恰有 `i` 个不同的非空回文子串。不同指字符串内容不同，不是位置或出现次数。
若不存在则报告无解。时间限制 0.5 秒，内存 64 MB。

## 输入

一个整数 `1 ≤ n ≤ 2000`，仅一个实例，无测试数前缀。

## 输出

恰好 `n` 行，按下标递增，格式为 `i : word` 或无解时 `i : NO`。
接受任意合法词。词使用小写 `a,b`，无解标记为大写 `NO`。

## 评测方式

检查器核对每个词的长度和字母，并用回文树统计其中不同回文的个数；任何合法的词都被接受，只有不存在这样的词时才接受拒绝的答复。

## 样例

```
4
```

```
1 : NO
2 : NO
3 : NO
4 : aaaa
```

## 解法

最少数量在 `n≤7` 时为 `n`，`n=8` 时为 `7`，`n≥9` 时为 `8`。
从最小值到 `n` 的每个整数都可构造。

### 无解数量的证明

追加一个字符最多新增一种不同回文。新回文必为后缀。
若两个不同长度的后缀都新出现，较短者也是较长回文的真前缀，
于是已经在最后位置以前出现，矛盾。因此长度 `n` 的词最多有 `n` 种不同回文。

小范围下界由 [tests/gen.py --proof](tests/gen.py) 中的完整有限枚举复现。
它枚举长度一到九的全部二元词，直接将每个子串与其反转比较，集合保存不同内容：

| 长度 | 回文数量 : 词数 |
| --- | --- |
| 1–7 | `n : 2^n` |
| 8 | `7 : 4; 8 : 252` |
| 9 | `8 : 24; 9 : 488` |

这是全部 `1022` 个词而非抽样。任何长度至少九的词包含一个九字符前缀，
前缀的至少八种不同回文仍在整词中，所以任意更大 `n` 的下界为八。
以下构造达到其余全部数量。

### 回文集合有界的周期

无限周期 `(aababb)…` 的回文恰为
`{a,b,aa,bb,aba,bab,abba,baab}`。
检查六种起始余数及一至六的长度即可列出它们；长度五、六都没有回文。
更长回文必含一个长度五或六的中心回文，因此也不存在。
脚本同时复现这个有限检查。

对目标 `8≤i<n`，令 `k=i−6≥2`，先写 `k` 个 `a`，
再接无限周期 `(babbaa)…` 的前缀，使总长恰为 `n`。
全由 `a` 组成的回文恰有 `k` 个，即 `a,a²,…,a^k`。
若含 `b` 的回文跨越初始长段的边界，其开头有 `t` 个连续 `a`，
对称结尾必须在某个 `b` 后面有 `t` 个 `a`。
周期中的连续 `a` 最长为二，所以 `t≤2`。
这个回文位于最后两个初始 `a` 开始的后缀中，而该后缀是 `(aababb)…` 的前缀。
完全位于周期尾部的回文也受相同限制。
因此额外回文只有 `b,bb,aba,bab,abba,baab`。
尾部至少七个字符时这六种均出现。
这里尾长 `n−k=n−i+6≥7`，故总数恰为 `k+6=i`。

`i=n` 时使用 `a^n`。剩余可行特例 `n=8,i=7` 使用 `aababbaa`：
有 `a,aa` 和五种额外回文 `b,bb,aba,bab,abba`，此时尚无 `baab`。
其他低于最小值的下标输出 `NO`。

样例 `n=4` 时，完整小范围枚举排除一、二、三；
`aaaa` 的回文内容为 `a,aa,aaa,aaaa`，满足第四行。
逐行构造并输出耗时 `O(n²)`，与大规模输出量相同，额外空间 `O(n)`。

注意事项：

- 计不同子串内容，不计出现次数，也不计空回文。
- 长度八可达到七种，必须单独处理。
- 某个模式失败不能作为输出 `NO` 的依据。
- 周期构造的 `k=i−6`，尾部首字母为 `b`。
- 无解行也必须输出下标和冒号。

## 各语言说明

C++、Go、Rust 和 Java 使用缓冲输出，Java 每次仅构造一行字符数组。
Python 直接逐行打印。求解程序不建立回文树，也不保存全部平方级输出。
只使用较小整数下标，不存在算术溢出。
