# 2037. Двоичные слова с заданным числом палиндромов

[Timus 2037](https://acm.timus.ru/problem.aspx?space=1&num=2037) · сложность 1224 · constructive

Автор оригинальной задачи — Михаил Рубинчик; Ural FU Dandelion contest. Petrozavodsk training camp. Summer 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для каждого `i` от `1` до `n` постройте слово длины `n` над `a,b`
с ровно `i` различными непустыми подстроками-палиндромами.
Различаются значения подстрок, а не их позиции или число вхождений.
Если слово невозможно, укажите это. Лимиты: 0,5 секунды и 64 МБ.

## Входные данные

Одно целое `1 ≤ n ≤ 2000`. Набор единственный, без количества тестов.

## Выходные данные

Ровно `n` строк по возрастанию индекса: `i : слово` либо `i : NO`.
Подходит любое корректное слово из строчных `a,b`; маркер отсутствия `NO`
пишется прописными буквами.

## Проверка

Проверяющая программа сверяет длину и буквы каждого слова и считает его
различные палиндромы деревом палиндромов; принимаются любые подходящие
слова, а отказ — только если слова нет.

## Примеры

```
4
```

```
1 : NO
2 : NO
3 : NO
4 : aaaa
```

## Решение

Минимум равен `n` при `n≤7`, `7` при `n=8` и `8` при `n≥9`.
Все числа от этого минимума до `n` достижимы.

### Доказательство невозможности меньших чисел

Новая буква добавляет не более одного нового различного палиндрома.
Любой новый палиндром обязан быть суффиксом. Если бы новых суффиксов
было два, меньший был бы также собственным префиксом большего палиндрома
и уже встречался бы до последней позиции. Поэтому число различных
палиндромов слова длины `n` не превосходит `n`.

Малые нижние границы проверяются полным конечным перебором,
воспроизводимым в [tests/gen.py --proof](tests/gen.py).
Перечисляются все двоичные слова длины от одного до девяти,
а значения подстрок сравниваются со своим обращением и собираются в множество:

| Длина | Число палиндромов : количество слов |
| --- | --- |
| 1–7 | `n : 2^n` |
| 8 | `7 : 4; 8 : 252` |
| 9 | `8 : 24; 9 : 488` |

Это все `1022` слова, а не выборка. Любое более длинное слово содержит
префикс длины девять с хотя бы восемью различными палиндромами.
Они сохраняются и в полном слове, что доказывает нижнюю границу
для произвольного `n≥9`. Конструкции ниже достигают всех остальных чисел.

### Период с ограниченным набором палиндромов

В бесконечном периоде `(aababb)…` встречаются ровно
`{a,b,aa,bb,aba,bab,abba,baab}`.
Для проверки перебираются шесть возможных начал периода и длины от
одного до шести. Палиндромов длины пять и шесть нет.
У любого более длинного палиндрома центральная подстрока длины пять
или шесть тоже палиндром, поэтому более длинных нет.
Скрипт воспроизводит и эту конечную проверку.

Пусть требуется `8≤i<n`. Возьмём `k=i−6≥2` букв `a` и допишем
префикс периода `(babbaa)…` так, чтобы общая длина стала `n`.
Существуют ровно `k` палиндромов только из `a`: `a,a²,…,a^k`.
Палиндром, который пересекает границу и содержит `b`, начинается с
`t` букв `a`. Симметричный конец содержит `t` таких букв после `b`.
В периоде блоки `a` имеют длину не более двух, значит, `t≤2`.
Такой палиндром целиком находится в суффиксе, начинающемся с последних
двух начальных `a`, а этот суффикс — префикс `(aababb)…`.
Палиндромы целиком внутри хвоста также ограничены набором периода.
Поэтому дополнительные значения — только `b,bb,aba,bab,abba,baab`.
Все шесть уже встречаются при длине хвоста хотя бы семь.
У нас `n−k=n−i+6≥7`, поэтому всего получается `k+6=i`.

Для `i=n` выводим `a^n`. Остаётся особый случай `n=8,i=7`:
слово `aababbaa` содержит `a,aa` и пять дополнительных палиндромов
`b,bb,aba,bab,abba`; `baab` ещё не появляется.
Меньшим невозможным индексам соответствует `NO`.

В примере `n=4` числа один, два и три исключены полным малым перебором.
Слово `aaaa` содержит ровно `a,aa,aaa,aaaa`, поэтому подходит для
четвёртой строки.

Строим и выводим по одной строке: `O(n²)` времени, что соответствует
размеру вывода для больших `n`, и `O(n)` дополнительной памяти.

Подводные камни:

- Нужны различные значения подстрок, а не вхождения; пустой палиндром исключён.
- При длине восемь достижимо семь палиндромов — это отдельный случай.
- Неудача одного шаблона не доказывает, что допустимо печатать `NO`.
- В периодической конструкции `k=i−6`, а хвост начинается с `b`.
- Индекс и двоеточие нужны в каждой строке, включая `NO`.

## Особенности языков

C++, Go, Rust и Java используют буферизованный вывод, Java создаёт один
массив символов на строку. Python сразу печатает очередную строку.
В решениях нет палиндромного дерева и хранения всего квадратичного вывода.
Используются лишь малые индексы, переполнение арифметики невозможно.
