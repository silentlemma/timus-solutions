# 2060. 统计相邻回文出现对

[Timus 2060](https://acm.timus.ru/problem.aspx?space=1&num=2060) · difficulty 650 · strings

原题作者 Mikhail Rubinchik，出自 2015 年 7 月 11 日回文专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

统计字符串中相邻的非空回文对：满足 s[i..j] 和 s[j+1..k] 都是回文的三元组 0 ≤ i ≤ j < k < n。位置不同的相同文本分别计数。时间限制 1 秒，内存限制 64 MB。

## 输入

一个由 1 到 300 000 个小写拉丁字母组成的字符串。

## 输出

精确的个数。

## 评测方式

按记号逐个比较输出。

## 样例

```
abaa
```

```
5
```

对于 `abaa`，各位置结尾的回文数为 `E=[1,1,2,2]`，各位置开头的回文数为 `S=[2,1,2,1]`。三个内部边界分别贡献 `1·1`、`1·2`、`2·1`，合计五。第一个边界计入 `a|b`，虽然它们不覆盖整个单词；最后一个计入 `a|a` 与 `aba|a`。

## 解法

### 对每个边界独立选择

设 `E[j]` 为恰好在 `j` 结尾的非空回文出现数，`S[j]` 为在 `j` 开头的数量。在边界 `j|j+1`，左边可选 `E[j]` 种，右边可选 `S[j+1]` 种，两段位置唯一确定一个合法三元组。反之，每个三元组也唯一确定边界与这两个选择。因此答案为 `sum(E[j]·S[j+1])`，其中 `0≤j<n−1`。统计的是出现位置，不是不同的回文字符串。

### Manacher 半径对应端点区间

奇中心 `c` 的半径 `r≥1` 包含中心字符，描述长度 `1,3,…,2r−1` 的回文。它们的结束位置恰好各一次遍历 `[c,c+r−1]`，开始位置遍历 `[c−r+1,c]`。间隙在 `c` 前的偶中心，半径 `r≥0` 对应结束区间 `[c,c+r−1]` 和开始区间 `[c−r,c−1]`；半径零不贡献回文。

用 Manacher 分别求两类半径。保存右端最远的回文窗口；若中心在其中，复制已知的镜像半径并截断到窗口右端，再向外比较尚未确定的字符。在窗口外，奇半径从一开始，偶半径从零开始。对称性保证复制部分，扩展比较得到最大半径。每个中心至多有一次失败比较，成功的新比较推动最右边界，所以每个过程为 `O(n)`。

对每个端点区间进行一次差分更新：闭区间 `[l,r]` 在 `l` 加一、`r+1` 减一，花费 `O(1)`。全部中心处理后，两个差分数组的前缀和就是 `E` 与 `S`。每次回文出现拥有唯一的中心、奇偶与半径，因此恰好给自己的开始和结束各贡献一次，无遗漏或重复。再由边界乘法公式得到正确答案。

### 内存与整数范围

奇偶两个过程复用一个半径数组，并在开始偶过程前重置窗口。处理偶中心 `c` 时，窗口来自更早的中心 `q<c`，镜像下标为 `2q−c<c`。因此只会读取已经覆盖的偶半径前缀，不会读到旧的奇半径。两个差分数组长度为 `n+1`，允许在 `n` 处做减法；只有 `0..n−1` 是实际位置。

每个端点计数不超过 `n`，有符号 32 位数组足够。但乘积可能超过 32 位，最终答案最多为 `n(n−1)(n+1)/6`：共有 `C(n+1,3)` 个可能三元组，全相同字符时全部有效。`n=300000` 时为 `4499999999950000`。C++、Go、Java、Rust 必须在相乘前转换为有符号 64 位；Python 整数精确。

## 各语言说明

两个 Manacher 过程、差分更新、前缀和与答案求和共用 `O(n)` 时间、`O(n)` 空间。所有实现均为迭代，精确比较字母。Python 选用 CPython 3.12 和三个紧凑的有符号 32 位数组；其他语言使用整数数组或向量。读入一个字符串，输出一个整数。

不能只计算每个位置最长的回文；须包含单字符与两类中心，不能把空的偶回文计入。偶中心的开始区间右端是 `c−1`，不是 `c`。应把 `E[j]` 与 `S[j+1]` 相乘，而非 `S[j]`，只考虑内部边界。不合并内容相同的出现，也不要求两段覆盖整串。长度一的答案为零。转换到 64 位必须发生在相乘之前，而非溢出之后。

Python 解答在 PyPy 下运行：在 CPython 3.12 下它在评测的第 49 个测试上超时，而在 PyPy 3.10 下以 0.234 秒通过。
