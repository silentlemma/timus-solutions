# 2031. 旋转后得到连续整数的一行数

[Timus 2031](https://acm.timus.ru/problem.aspx?space=1&num=2031) · 难度 88 · bruteforce

原题作者 Nikita Sivukhin，出自 2014 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

构造一行 `n` 个十进制数，使整行旋转 180 度后成为递增的连续正整数段。
每个输出数恰有两位，一位数必须补前导零。旋转既反转整行数的顺序，也反转每个数的数字顺序。
`0`、`1`、`8` 旋转后不变，`6` 与 `9` 互换，其他数字不可读，不能使用。

限制：`1 ≤ n ≤ 99`，1 秒，64 MB。

## 输入

一个整数 `n`，表示所需行中的数目。

## 输出

输出任意合法的 `n` 个两位数，以空格分隔。无解则精确输出 `Glupenky Pierre`。
旋转后的数必须为正，因此 `00` 不合法；其他两位表示中的前导零必须保留。

## 评测方式

检查器把输出的一行旋转过来，确认得到的是连续的正整数，每个数都由两位可读数字组成；只有不存在这样的连续段时才接受“无解”的回答。任何合法的一行都被接受。

## 样例

```
2
```

```
11 01
```

```
99
```

```
Glupenky Pierre
```

## 解法

只有数字 0、1、6、8、9 倒过来还能读，所以旋转后只能出现由它们组成的 1 到 99 的数。
依次检查 1 … 99，统计当前连续可读数的长度，当它在某个数 r 处达到 n 时停止。然后把
r, r − 1, …, r − n + 1 倒过来输出：每个数先写旋转后的个位，再写旋转后的十位，这样
旋转后的整行按递增顺序读出这一段。如果没有足够长的连续段，答案是
`Glupenky Pierre`。`O(100 + n)`。

可读的数是 1、6、8、9、10、11、16、18、19、60、61、66、68、69、80、81、86、88、89、
90、91、96、98、99；最长的连续段 8–11 和 88–91 各有四个数，所以只有 n ≤ 4 有解。

注意事项：

- 旋转时 6 和 9 互换；
- 保留前导零：01 倒过来是 10；
- 00 会变成 0，而 0 不是正数。

## 优化解法

优化的 C++ 解法用 `getchar` 读入 `n`，用 `putchar` 逐个输出数字，不用
`iostream`，也不拼接字符串：88 KB，而不是 368 KB，时间不变。

## 各语言说明

- 旋转后的数由字符拼成，因此前导零得以保留。
