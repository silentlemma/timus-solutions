# 2031. Ряд, превращающийся в последовательные числа

[Timus 2031](https://acm.timus.ru/problem.aspx?space=1&num=2031) · сложность 88 · bruteforce

Автор оригинальной задачи — Никита Сивухин; Уральская региональная командная олимпиада по программированию 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Построить ряд из `n` десятичных чисел, который после поворота всего ряда на 180
градусов становится возрастающим отрезком последовательных положительных целых.
Каждое напечатанное число состоит ровно из двух цифр: однозначные дополняются
ведущим нулём. Поворот меняет порядок чисел и порядок цифр внутри каждого числа.
Цифры `0`, `1`, `8` переходят в себя, `6` и `9` — друг в друга. Остальные
цифры становятся нечитаемыми и не подходят.

Ограничение: `1 ≤ n ≤ 99`. Лимиты: 1 секунда, 64 МБ.

## Входные данные

Одно целое `n` — количество чисел в требуемом ряду.

## Выходные данные

Любой подходящий ряд из `n` двухзначных записей через пробел. При
отсутствии решения вывести в точности `Glupenky Pierre`. После
переворота все числа должны быть положительными: `00` недопустимо. В
остальных записях ведущие нули сохраняются.

## Проверка

Проверяющая программа переворачивает напечатанный ряд и убеждается, что
получается отрезок подряд идущих положительных чисел из двух читаемых
цифр каждое; ответ о невозможности принимается, только если такого
отрезка нет. Принимается любой подходящий ряд.

## Примеры

```
2
```

```
11 01
```

```
99
```

```
Glupenky Pierre
```

## Решение

Будем искать числа после поворота. Каждое лежит от 1 до 99 и содержит только
цифры `0,1,6,8,9`, включая возможный ведущий ноль. Перебираем эти целые по
возрастанию, поддерживая длину текущей непрерывной серии читаемых чисел.
Нечитаемое число сбрасывает длину в ноль. Если на числе `r` длина достигла `n`,
найден нужный интервал `[r-n+1,r]`.

Для восстановления исходного ряда перебираем цели от `r` до `r-n+1` в
обратном порядке. У каждого числа сначала записываем перевёрнутую цифру
единиц, затем перевёрнутую цифру десятков. Добавление символов сохраняет
ширину два. Если полный перебор завершился без нужной серии, выводим
сообщение об отсутствии решения.

### Доказательство

Таблица поворота — инволюция: двукратное применение возвращает каждую читаемую
цифру. Построенный ряд является обратным поворотом выбранного интервала.
Разворот всего ряда возвращает возрастающий порядок целей, а разворот и замена
цифр внутри каждой записи возвращают её две цифры. Поэтому получаются в точности
выбранные последовательные положительные целые.

Обратно, любой правильный ряд после поворота обязан дать положительный
непрерывный интервал внутри `[1,99]` с читаемыми цифрами. Полный перебор
последовательно посетит каждое число этого интервала, и длина серии
достигнет `n`. Следовательно, неудача перебора доказывает невозможность
ответа.

Все читаемые положительные цели:
`1,6,8,9,10,11,16,18,19,60,61,66,68,69,80,81,86,88,89,90,91,96,98,99`.
Самые длинные серии — `[8,11]` и `[88,91]`, обе длины четыре. Поэтому
возможны ровно длины от одного до четырёх; программа находит серии без
отдельной проверки этого порога.

Первый образец `11 01` после поворота даёт `10 11`. Программа может вывести
`60 80`, превращающееся в `08 09`: это тоже правильный ответ. Во втором образце
99 больше максимальной длины серии, поэтому выводится требуемая фраза.

Проверяется не более 99 целых, а при успехе печатается `n` записей:
`O(100+n)` времени, `O(1)` состояния перебора и `O(n)` буфера ответа.
Работа перечисления постоянна из-за фиксированного двухзначного диапазона.

Подводные камни:

- Разворачиваются и порядок чисел, и цифры внутри каждого числа.
- Цифры `6` и `9` нужно заменять, одного разворота символов мало.
- Ведущий ноль является частью двухзначной записи.
- Ноль не входит в положительный целевой интервал.
- Другой допустимый интервал не обязан совпадать с образцом.

## Особенности языков

Все реализации добавляют символы цифр, не преобразуя результат поворота
в целое, чтобы сохранить нули. Для нечитаемых цифр в таблице есть
маркер. Rust вычисляет убывающие цели как `r-offset`: найденная серия
гарантирует `r ≥ n`, поэтому вычитание беззнаковых чисел безопасно.
Большие числа и вещественная арифметика не нужны.
