# 2069. 至多两次转弯的最佳路线

[Timus 2069](https://acm.timus.ru/problem.aspx?space=1&num=2069) · 难度 226 · greedy

原题作者 Oleg Merkurev（由 Alexander Borzunov 整理），出自 2015 年乌拉尔地区团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

城市是由 n 条竖直街道和 m 条水平街道组成的网格，每条街道有各自的人气值。路线沿街道从左上角走到右下角，其酷炫度是路线上走过非零距离的街道中最小的人气值。求最大可能的酷炫度。时间限制 1 秒，内存限制 64 MB。

## 输入

n 和 m（2 ≤ n, m ≤ 10⁵），然后从左到右给出 n 条竖直街道的人气值，从上到下给出 m 条水平街道的人气值，每行一个，范围 1 到 10⁹。

## 输出

最大的酷炫度。

## 评测方式

精确比较完整输出，包括空格和换行。

## 样例

### 样例 1

输入：

```
2 3
4
8
2
7
3
```

输出：

```
4
```

### 样例 2

输入：

```
4 3
12
4
12
3
21
5

```

输出：

```
12
```

## 解法

记竖直街道为 v₁ … vₙ，水平街道为 h₁ … hₘ；路线从 v₁ 与 h₁ 的交点出发，到 vₙ 与 hₘ 的交点结束。第一步沿 v₁ 或 h₁，最后一步沿 vₙ 或 hₘ，共四种情况。

- 从 v₁ 开始、在 hₘ 结束。酷炫度至多 min(v₁, hₘ)，先沿 v₁ 向下再沿 hₘ 向右即可达到。
- 从 h₁ 开始、在 vₙ 结束：至多 min(h₁, vₙ)，先向右再向下即可达到。
- 从 h₁ 开始、在 hₘ 结束。要换行，路线必须沿某条竖直街道走，所以酷炫度至多 min(h₁, max v, hₘ)。沿 h₁ 向右走到最好的竖直街道，顺着它向下，再沿 hₘ 向右，酷炫度至少为这个值。
- 从 v₁ 开始、在 vₙ 结束：对称地为 min(v₁, max h, vₙ)。

每条路线都属于其中一种情况，且每个上界都能达到，所以答案是四个值中的最大者，时间 O(n + m)。

第一个样例中，前两种情况给出 min(4, 3) = 3 和 min(2, 8) = 2，而最后一种沿 v₁ = 4 向下、沿 h₂ = 7 向右、再沿 v₂ = 8 向下，酷炫度为 4。

## 优化解法

流式计算两方向街道最大值及端点值，不保存所有街道。阈值可行当且仅当每个方向至少一条街达到阈值，且两个端点各有合格相邻街。这些街的交叉网格连通，因此条件充分且必要。取两方向最大值与两端点最大值的最小者即可，保持基础分类证明且工作空间为常数。
