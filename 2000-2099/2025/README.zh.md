# 2025. 最大化组间对象对数

[Timus 2025](https://acm.timus.ru/problem.aspx?space=1&num=2025) · 难度 60 · math

原题作者 Alexey Danilyuk，出自 2014 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

将 `n` 个不同对象划分成至少两组、至多 `k` 组非空组，每个对象恰好属于一组。
一个无序对象对当两个对象在不同组时贡献一，否则贡献零。求贡献总数的最大值，不必输出分组。

有 `1 ≤ T ≤ 10` 个独立测试，每个满足 `2 ≤ k ≤ n ≤ 10000`。时间限制 1 秒，内存限制 64 MB。

## 输入

第一行是 `T`，接下来 `T` 行各含 `n` 和 `k`。

## 输出

按输入顺序，每个测试输出一行，一个整数答案。

## 评测方式

按记号逐个比较输出。

## 样例

```
3
6 3
5 5
4 2
```

```
12
10
4
```

## 解法

用满 k 组最好：如果组数更少，某一组至少有两个物品，把它拆开会增加对数。组的大小
为 s₁, …, s_k 时，位于不同组的对数是 (n² − Σ sᵢ²) / 2，所以平方和要尽量小。各组大小
相差不超过一时就是这样，因为把一个物品从大小为 a 的组移到大小为 b ≤ a − 2 的组会
减小平方和。因此 r = n mod k 个组有 q + 1 个物品，其余 k − r 个组各有
q = n div k 个，答案是 (n² − (k − r)·q² − r·(q + 1)²) / 2。每个测试 `O(1)`。

当 n = 6、k = 3 时，各组大小为 2、2、2，答案是 12。

注意事项：

- 每对只算一次，因此要除以二；
- 只用整数运算，不要用浮点平均数。
