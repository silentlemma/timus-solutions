# 2025. 最大化组间对象对数

[Timus 2025](https://acm.timus.ru/problem.aspx?space=1&num=2025) · 难度 60 · math

原题作者 Alexey Danilyuk，出自 2014 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

将 `n` 个不同对象划分成至少两组、至多 `k` 组非空组，每个对象恰好属于一组。
一个无序对象对当两个对象在不同组时贡献一，否则贡献零。求贡献总数的最大值，不必输出分组。

有 `1 ≤ T ≤ 10` 个独立测试，每个满足 `2 ≤ k ≤ n ≤ 10000`。时间限制 1 秒，内存限制 64 MB。

## 输入

第一行是 `T`，接下来 `T` 行各含 `n` 和 `k`。

## 输出

按输入顺序，每个测试输出一行，一个整数答案。

## 评测方式

按记号逐个比较输出。

## 样例

```
3
6 3
5 5
4 2
```

```
12
10
4
```

## 解法

先证明使用全部 `k` 组最优。若只有 `m < k` 组，由于 `n ≥ k > m`，必有一组至少含两个对象。
把它拆为大小 `a`、`b` 的两个非空组，原来的组间对象对都保留，并新增 `ab > 0` 对。
因此更少的组不可能最优。

固定为 `k` 组，大小是 `s₁, …, sₖ` 时，组间对象对数为 `(n² - Σ sᵢ²) / 2`。
`n²` 统计全部有序对象对，组大小的平方去掉组内对象对，包括自身与自身。
剩下的每个无序跨组对出现两次，因此除以二。

于是要最小化大小的平方和。若两组大小满足 `a ≥ b+2`，从大组移一个对象到小组，平方和变化为
`(a-1)² + (b+1)² - a² - b² = -2(a-b-1) < 0`，跨组对数增加 `a-b-1`。
所以最优大小之差不能达到二。不断进行这种改进最终得到均衡划分；所有均衡划分的平方和相同，
因而都达到最大值。

令 `q = n // k`、`r = n % k`，有 `r` 组大小为 `q+1`，其余 `k-r` 组大小为 `q`。
由于 `k ≤ n`，所有组非空。答案为 `(n² - (k-r)q² - r(q+1)²) / 2`。
只用整数计算即可；每个整数平方与其本身奇偶相同，所以分子必为偶数。

样例的大小 `2,2,2` 得到 12 对；五个单元素组得到 10 对；大小 `2,2` 得到 4 对。
还可核对 `k = n` 时为 `n(n-1)/2`，`k = 2` 时为 `floor(n²/4)`。

每个测试使用 `O(1)` 算术时间和 `O(1)` 工作空间，全部测试时间为 `O(T)`。
这些程序的输入或输出缓存最多占 `O(T)` 空间；C++ 和 Go 逐个处理，使用固定大小缓冲区。

注意事项：

- 允许至多 `k` 组，必须先证明恰好 `k` 组最优。
- 各组非空，每个对象只分配一次。
- 用余数确定 `q` 与 `q+1` 的组数，不用浮点平均值。
- 对象对无序，平方公式最后必须除以二。
- 读取全部测试并逐行输出。最大答案为 49995000，使用宽整数保证乘积精确。

## 各语言说明

C++ 使用 `long long`，Go 使用 `int64`，Java 使用 `long`，Rust 使用 `u64`。
Python 使用精确整数和 `divmod`。Rust 的无符号减法安全，因为组内平方和不超过 `n²`。
各版本只计算整数商与余数，不构造具体划分；CPython 无需更换运行时。
