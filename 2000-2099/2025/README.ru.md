# 2025. Максимум пар между группами

[Timus 2025](https://acm.timus.ru/problem.aspx?space=1&num=2025) · сложность 60 · math

Автор оригинальной задачи — Алексей Данилюк; Уральская региональная командная олимпиада по программированию 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Разделите `n` различных объектов на количество непустых групп от двух до
`k`. Каждый объект должен попасть ровно в одну группу. Неупорядоченная
пара даёт единицу, если объекты относятся к разным группам, и ноль
иначе. Найдите максимально возможное число таких пар. Само разбиение
выводить не нужно.

Дано `1 ≤ T ≤ 10` независимых тестов, в каждом `2 ≤ k ≤ n ≤ 10000`.
Ограничения: 1 секунда и 64 МБ.

## Входные данные

Первая строка содержит `T`. В каждой из следующих `T` строк записаны `n` и `k`.

## Выходные данные

Для каждого теста выведите одно целое число в отдельной строке, сохраняя
порядок.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
3
6 3
5 5
4 2
```

```
12
10
4
```

## Решение

Лучше использовать все k групп: если групп меньше, в какой-то из них не
меньше двух предметов, и её разбиение добавляет пары. При размерах групп
s₁, …, s_k пар из разных групп (n² − Σ sᵢ²) / 2, поэтому сумма квадратов
должна быть как можно меньше. Так бывает, когда размеры отличаются не
больше чем на единицу: перенос предмета из группы размера a в группу
размера b ≤ a − 2 уменьшает сумму квадратов. Значит, r = n mod k групп
получают q + 1 предмет, остальные k − r — по q = n div k, и ответ равен
(n² − (k − r)·q² − r·(q + 1)²) / 2. `O(1)` на тест.

Для n = 6, k = 3 группы 2, 2, 2 и ответ 12.

Подводные камни:

- каждая пара считается один раз, отсюда деление на два;
- только целочисленная арифметика, без вещественного среднего.
