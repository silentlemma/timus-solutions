# 2025. Максимум пар между группами

[Timus 2025](https://acm.timus.ru/problem.aspx?space=1&num=2025) · сложность 60 · math

Автор оригинальной задачи — Алексей Данилюк; Уральская региональная командная олимпиада по программированию 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Разделите `n` различных объектов на количество непустых групп от двух до
`k`. Каждый объект должен попасть ровно в одну группу. Неупорядоченная
пара даёт единицу, если объекты относятся к разным группам, и ноль
иначе. Найдите максимально возможное число таких пар. Само разбиение
выводить не нужно.

Дано `1 ≤ T ≤ 10` независимых тестов, в каждом `2 ≤ k ≤ n ≤ 10000`.
Ограничения: 1 секунда и 64 МБ.

## Входные данные

Первая строка содержит `T`. В каждой из следующих `T` строк записаны `n` и `k`.

## Выходные данные

Для каждого теста выведите одно целое число в отдельной строке, сохраняя
порядок.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
3
6 3
5 5
4 2
```

```
12
10
4
```

## Решение

Сначала докажем, что выгодно использовать все `k` групп. Если их `m <
k`, то из `n ≥ k > m` следует, что некоторая группа содержит хотя бы два
объекта. Разделим её на две непустые части размеров `a` и `b`. Все
прежние пары между группами останутся, а `ab > 0` пар между новыми
частями добавятся. Меньшее число групп хуже.

При ровно `k` группах размеров `s₁, …, sₖ` число пар между группами
равно `(n² - Σ sᵢ²) / 2`. Величина `n²` считает все упорядоченные пары;
квадраты размеров удаляют пары внутри групп, включая пары объекта с
самим собой. Каждая оставшаяся неупорядоченная пара посчитана дважды,
поэтому делим на два.

Нужно минимизировать сумму квадратов размеров. Пусть два размера
удовлетворяют `a ≥ b+2`. Перенос одного объекта из большей группы в
меньшую меняет сумму на `(a-1)² + (b+1)² - a² - b² = -2(a-b-1) < 0`, то
есть добавляет `a-b-1` пар. Значит, в оптимуме размеры не могут
отличаться на два или больше. Повторяя такие улучшения, получим
сбалансированное разбиение. Во всех сбалансированных разбиениях сумма
квадратов одинакова, поэтому каждое достигает максимума.

Положим `q = n // k`, `r = n % k`. Тогда `r` групп имеют размер `q+1`, остальные
`k-r` — размер `q`. Они непустые, поскольку `k ≤ n`. Ответ равен
`(n² - (k-r)q² - r(q+1)²) / 2`. Все вычисления целочисленные. Числитель чётный:
квадрат целого числа имеет ту же чётность, что и само число.

В примере размеры `2,2,2` дают 12 пар; пять групп по одному объекту дают 10 пар;
размеры `2,2` дают 4 пары. Дополнительные проверки: при `k = n` ответ равен
`n(n-1)/2`, при `k = 2` — `floor(n²/4)`.

На один тест требуется `O(1)` времени и `O(1)` рабочей памяти; на все тесты —
`O(T)` времени. Буферизация ввода или вывода использует до `O(T)` памяти;
C++ и Go обрабатывают тесты с буферами фиксированного размера.

Подводные камни:

- Разрешено не более `k` групп: отдельно обоснуйте оптимальность ровно `k`.
- Группы непустые, каждый объект назначается ровно один раз.
- Остаток определяет количество групп размеров `q` и `q+1`; вещественное
  среднее не нужно.
- Пары неупорядоченные: в формуле с квадратами необходимо деление на два.
- Прочитайте все тесты и выведите по одному ответу на строку. Максимальный ответ
  равен 49995000; широкие целые типы сохраняют точность всех произведений.

## Особенности языков

C++ использует `long long`, Go — `int64`, Java — `long`, Rust — `u64`.
Python применяет точные целые и `divmod`. В Rust беззнаковое вычитание
безопасно: сумма квадратов размеров не превосходит `n²`. Все программы
вычисляют целые частное и остаток, не строя само разбиение. Другой
интерпретатор для CPython не нужен.
