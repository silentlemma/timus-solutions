# 2025. Максимум пар между группами

[Timus 2025](https://acm.timus.ru/problem.aspx?space=1&num=2025) · сложность 60 · math

Автор оригинальной задачи — Алексей Данилюк; Уральская региональная командная олимпиада по программированию 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Разделите `n` различных объектов на количество непустых групп от двух до
`k`. Каждый объект должен попасть ровно в одну группу. Неупорядоченная
пара даёт единицу, если объекты относятся к разным группам, и ноль
иначе. Найдите максимально возможное число таких пар. Само разбиение
выводить не нужно.

Дано `1 ≤ T ≤ 10` независимых тестов, в каждом `2 ≤ k ≤ n ≤ 10000`.
Ограничения: 1 секунда и 64 МБ.

## Входные данные

Первая строка содержит `T`. В каждой из следующих `T` строк записаны `n` и `k`.

## Выходные данные

Для каждого теста выведите одно целое число в отдельной строке, сохраняя
порядок.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
3
6 3
5 5
4 2
```

```
12
10
4
```

## Решение

Лучше использовать все k групп: если групп меньше, в какой-то из них не
меньше двух предметов, и её разбиение добавляет пары. При размерах групп
s₁, …, s_k пар из разных групп (n² − Σ sᵢ²) / 2, поэтому сумма квадратов
должна быть как можно меньше. Так бывает, когда размеры отличаются не
больше чем на единицу: перенос предмета из группы размера a в группу
размера b ≤ a − 2 уменьшает сумму квадратов. Значит, r = n mod k групп
получают q + 1 предмет, остальные k − r — по q = n div k, и ответ равен
(n² − (k − r)·q² − r·(q + 1)²) / 2. `O(1)` на тест.

Для n = 6, k = 3 группы 2, 2, 2 и ответ 12.

Подводные камни:

- каждая пара считается один раз, отсюда деление на два;
- только целочисленная арифметика, без вещественного среднего.

## Оптимизированные решения

`2025_math_optimized.java`. Java сохраняет формулу сбалансированных групп. Пусть q=N/K и r=N%K: r групп содержат q+1 человек, K-r — q. Ответ (N*N-((K-r)*q*q+r*(q+1)*(q+1)))/2 вычисляется в long. При N<=10000 он не больше 49995000, поэтому итоговое преобразование в int точно. Байтовые буферы ввода и вывода по 128 байт обходятся без BufferedInputStream, StringBuilder и строк на каждый ответ. До десяти ответов занимают не более 90 байт; функция вывода также безопасно сбрасывает полный буфер. Время O(T), дополнительная память O(1), арифметика каждого теста O(1).

Accepted точного исходника Java 1.8 №11327424: 0.093 с / 344 КБ. Сохранённое сравнение компиляторов от 2026-11-20: время 4/650, память 4/650. При памяти меньше 1024 КБ строгий допуск учитывает только время: первые десять мест или топ 15%, равенства делят место, процентный порог округляется вверх. Звёздочка остаётся для отдельной цели языка: первого места по обеим метрикам. Прежний документированный оптимизированный запуск №11302162: 0.14 с / 372 КБ; это отдельная историческая пара, не текущий замер данного исходника. Учебные версии сохранены без изменений.

- `2025_math_optimized.java`: 0.093 s / 344 KB; сохранённая учебная база `2025_math.java`: 0.125 s / 1628 KB.

`2025_math_optimized.cpp`. Сохраняется формула суммы квадратов размеров сбалансированных групп с точной арифметикой long long. Вместо scanf используется пополняемый буфер ввода 256 байтов с дополнительным байтом-ограничителем; число, пересекающее границу чтения, дочитывается целиком. Ответы собираются в фиксированный буфер 128 байтов и выводятся одним вызовом вместо printf для каждого теста. Не более десяти ответов до 49995000 занимают максимум 90 байтов. Арифметика O(1) на тест, всего O(T), дополнительная память фиксирована. Простая математическая версия сохранена.

Accepted точного исходника G++ 13.2 x64 №11327412: 0.015 с / 76 КБ. Полная публичная таблица, загруженная 2026-11-21, содержит 3066 строк. После исключения нашего автора и отбора актуальных компиляторов C/C++ место по времени 1/463, по памяти 2/463; равные показатели делят место, время ниже 0.015 с учитывается как 0.015 с. Обе цели первой десятки пройдены, звёздочка не нужна. При памяти меньше 1024 КБ строгий допуск также учитывает только время. Прежний оптимизированный запуск №11303661: 0.031 с / 128 КБ; сохранённая простая C++-версия №11292869: 0.031 с / 444 КБ. Это отдельные парные замеры, не смешанные минимумы. Повторная отправка не потребовалась.

## Особенности языков

Ничего особенного не требуется.

Вычитаем пары внутри групп из общего числа пар. Вклад более крупных групп считаем отдельно. Принятая посылка 11324249 заняла 0,140 с и использовала 224 КБ. Простая версия заняла 0,078 с и использовала 448 КБ. Зафиксированное время выше, чем у простой версии.
