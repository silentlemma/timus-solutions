# 2057. 非回文分段的最少与最多数量

[Timus 2057](https://acm.timus.ru/problem.aspx?space=1&num=2057) · difficulty 3259 · strings

原题作者 Nikita Sivukhin，出自 2015 年 7 月 11 日回文专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把一个由英文字母组成的字符串划分为若干连续的非空片段，每段都不是回文；区分大小写，允许只有一段。求片段数可能的最小值和最大值。时间限制 1 秒，内存限制 64 MB。

## 输入

一个由 1 到 200 000 个英文字母组成的字符串。

## 输出

若无法划分输出 `-1`，否则输出片段数的最小值和最大值。

## 评测方式

按记号逐个比较输出。

## 样例

```
a
```

```
-1
```

```
abba
```

```
2 2
```

```
babcbcb
```

```
1 2
```

`a` 无法形成合法段。`abba` 本身回文，但 `ab|ba` 是两段，长度四也不可能更多。`babcbcb` 可整段保留，或分成 `babcb|cb` 两段；若分三段，长度只能是 2、2、3 的排列，三个位置选择都含回文，因此最多两段。

## 解法

### 精确回文查询

计算 Manacher 奇偶半径：`odd[c]` 包含中心字母，`even[c]` 以 `c` 前的间隙为中心。半开区间 `[l,r)` 长 `L`，中心 `c=floor((l+r)/2)`；奇长时当且仅当 `odd[c]≥floor(L/2)+1` 为回文，偶长时要求 `even[c]≥L/2`。在当前最右回文内部复用镜像半径、截到边界，再向外扩展；每个新增右边界只付费一次，故预处理 `O(n)`，精确查询 `O(1)`。

### 最多段数：两个层级与两个极端切点

令 `d[i]` 为前缀 `s[0:i]` 最多段数，无解为 `-1`，`d[0]=0`。原始递推在所有 `j≤i−2` 且 `s[j:i]` 非回文的切点中取 `1+max d[j]`。处理 `i` 时加入新切点 `i−2`，按分数保存最早、最晚位置和最高层 `M`。只按顺序检查 `M,M−1`，每层只查两端位置；成功得层级加一，否则无解。以下证明其充分性。

同一精确分数 `v` 的任意两个切点之间必为回文，否则添加这段可将后一个分数提升到 `v+1`。所以相邻切点间的词及相邻两词的串接均为回文，意味着相邻词可交换，全部为同一原始回文根 `U` 的幂。交换词事实可对 `XY=YX` 反复消去较短前缀，像 Euclid 一样得到公共根。若最晚切点后缀 `T` 和最早后缀 `U^k T` 都回文，则逆序得到 `U^k T=T U^k`，因此 `T` 也是 `U` 的幂，中间所有后缀也回文。故每层只查两端即可。

再证明可行时 `d[i]∈{M,M+1}`。上界来自原递推，`M≤1` 时显然。假设 `M≥2` 且可行但 `d[i]<M`，则所有分数至少 `M−1` 的切点后缀都回文。取一个最优 `M` 段前缀，剩下长度至少二的尾串 `Y`；末两段记为 `Q,P`。于是 `Y,PY` 都回文。

设 `PY` 的末尾同字母块为 `a^r`；若 `Y` 为恒定串，也计入 `P` 中相连的字母。回文 `PY` 必以恰好 `a^r b` 开头，`b≠a`，这段位于非回文 `P` 内。若 `Qa^r` 非回文，将切点移到 `b` 前即可得到 `M` 段，所以它必须回文。若 `r≥2`，`Qa^(r−1)` 非回文，否则两个相邻长度回文前缀强迫周期一，与 `Q` 非回文矛盾；剩余后缀首尾同字母块长度为 1、`r`，也非回文，再次得到 `M` 段。故 `r=1`。

此时 `Qa` 回文且首字母为 `a`，所以 `Qab` 非回文。该切点分数至少 `M−1`，迫使 `(PY)[2:]` 回文；加上 `PY` 回文可得周期二。首两字母不同，因此 `PY` 是奇长交替串，`Y` 是至少长三的奇长交替后缀，`P` 是 `ab` 的正整数次幂。

向前归纳。若 `A_h` 后的各段与 `Y` 构成长至少 `2(M−h)+3` 的奇长交替尾串，且 `A_h a` 或 `A_h aba` 非回文，就把剩下偶长交替串分成 `M−h` 个正偶长段，总共得到 `M` 段，矛盾。因此这两个扩展都回文，长度差二强迫相同周期，`A_h` 也为偶长 `ab` 幂。最后原各段全是这种幂，整个输入成为奇长交替串；它的非回文子串都为偶长，不可能拼出奇长总串。矛盾证明上界降幅限制，继而归纳证明整个 DP 正确。

### 最少段数只可能一或二

若 `AB,BC,ABC` 全回文，则 `B` 回文。因为 `ABC` 的回文前后缀给出周期 `|A|,|C|`，总长大于二者之和，所以其最大公约数也是周期。该周期规则可直接证明：在长至少 `p+q` 且 `p<q` 时，对 `i≥p` 比较 `i→i−p→i−p+q`，否则比较 `i→i+q→i+q−p`，得到周期 `q−p`，反复 Euclid。回文反射将 `B` 映到从 `|C|` 开始的同长子串，而原始起点为 `|A|`；二者模公共周期相同，故 `B` 等于逆序。

对任何三个相邻非回文段，若相邻两段拼接非回文就合并这对；否则两对都回文，根据引理三段整体必非回文，可合并三段。重复即可把任何可行方案缩到一或二段。因此 DP 判定可行后，整串非回文时最少一段，否则最少两段。

## 各语言说明

Manacher、DP 与最后查询总计 `O(n)` 时间、`O(n)` 空间。最多 `floor(n/2)` 段，层级数组只需这些层及零层。五个版本均迭代执行并用整数下标；Python 为 CPython 3.12，全部保留完整输入。

加入 `i−2` 而非 `i−1`，零分只对应空前缀，跳过不可行前缀。保留两端切点，不能只保留最近位置。回文也可能可分，如 `abba`；非恒定串也可能无解，如 `ababa`。贪心最短前缀及只用长二、三段均错误。注意大小写和中心奇偶。正式程序不使用概率哈希，也不扫描所有 DP 层。

不要把偶数长度误解为 `ab` 的偶数次幂：测试 `edge_05`（`ababa`）中，`P=(ab)^1`，而 `Y=aba` 和 `PY=ababa` 都是回文。
