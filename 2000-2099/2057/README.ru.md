# 2057. Минимум и максимум непалиндромных частей

[Timus 2057](https://acm.timus.ru/problem.aspx?space=1&num=2057) · difficulty 3259 · strings

Автор оригинальной задачи — Никита Сивухин; Палиндромный контест, 11 июля 2015.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Разбейте строку из английских букв на непрерывные непустые части, ни
одна из которых не палиндром; регистр важен, одна часть допускается.
Найдите наименьшее и наибольшее возможное число частей. Ограничения: 1
секунда и 64 МБ.

## Входные данные

Одна строка из 1–200 000 английских букв.

## Выходные данные

`-1`, если разбиения нет, иначе наименьшее и наибольшее число частей.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
a
```

```
-1
```

```
abba
```

```
2 2
```

```
babcbcb
```

```
1 2
```

Буква `a` не даёт допустимой части. Для `abba` вся строка — палиндром,
но `ab|ba` даёт две части, и больше при длине четыре невозможно. Для
`babcbcb` допустима одна часть и разбиение `babcb|cb` на две. Три части
имели бы длины 2, 2, 3 в некотором порядке; каждый из трёх вариантов
содержит палиндром, поэтому максимум равен двум.

## Решение

### Точные проверки палиндромов

Вычислим нечётные и чётные радиусы Манакера: `odd[c]` включает
центральную букву, `even[c]` относится к промежутку перед `c`. Для
полуинтервала `[l,r)` длины `L` и центра `c=floor((l+r)/2)` условие
палиндрома — `odd[c]≥floor(L/2)+1` при нечётном `L` и `even[c]≥L/2` при
чётном. Манакер переносит зеркальный радиус внутри самого правого
палиндрома с ограничением его границей, затем расширяет; каждое новое
положение правой границы оплачивается один раз за проход. Предвычисление
занимает `O(n)`, точный запрос — `O(1)`.

### Максимум: два уровня и крайние разрезы

Пусть `d[i]` — максимум допустимых частей префикса `s[0:i]`, либо `-1`;
`d[0]=0`. Полная рекуррентность: `d[i]=1+max d[j]` по `j≤i−2` с
непалиндромом `s[j:i]`. На шаге `i` добавим новый допустимый разрез
`j=i−2`. Для каждого достигнутого значения храним первый и последний
разрез, а также наибольшее добавленное значение `M`. Проверяем уровни
`M`, `M−1` по убыванию, в каждом — оба крайних разреза. При успехе
получаем `d[i]=уровень+1`, иначе `-1`. Докажем достаточность этих
проверок.

Между любыми двумя разрезами одного точного уровня `v` лежит палиндром:
непалиндром повысил бы значение более позднего префикса. Поэтому слова
между соседними разрезами и объединения соседних слов палиндромны.
Соседние слова коммутируют и являются степенями одного примитивного
палиндрома `U`. Факт о коммутирующих словах следует сокращением меньшего
префикса в `XY=YX` по алгоритму Евклида. Если суффиксы обоих крайних
разрезов — палиндромы, обозначим последний `T`, первый `U^k T`. Разворот
даёт `U^k T=T U^k`, значит `T` тоже степень `U`. Все промежуточные
суффиксы палиндромны. Итак, уровень успешен ровно тогда, когда успешен
один из крайних разрезов.

Теперь докажем, что при существующем разбиении `d[i]` равно `M` или
`M+1`. Верхняя граница следует из рекуррентности; для `M≤1` утверждение
очевидно. Пусть `M≥2`, но префикс допустим и `d[i]<M`. Тогда любой
разрез с уровнем не ниже `M−1` имеет палиндромный суффикс. Возьмём
оптимальный префикс из `M` частей и хвост `Y` длины хотя бы два.
Последние части назовём `Q,P`. Слова `Y` и `PY` палиндромны.

Пусть последний блок одинаковых букв в `PY` — `a^r` (включая часть `P`,
если `Y` постоянен). Палиндром `PY` начинается ровно с `a^r b`, `b≠a`,
внутри непалиндрома `P`. Если `Qa^r` непалиндромно, перенос разреза
перед `b` даёт `M` частей. Поэтому `Qa^r` — палиндром. При `r≥2` слово
`Qa^(r−1)` непалиндромно: два последовательных палиндромных префикса
означали бы период один и постоянное `Q`. Оставшийся суффикс имеет
разные длины крайних блоков 1 и `r`, значит тоже непалиндромен; снова
получаем `M` частей. Следовательно `r=1`.

Теперь `Qa` — палиндром с первой буквой `a`, поэтому `Qab`
непалиндромно. Его разрез имеет уровень не ниже `M−1`, значит `(PY)[2:]`
обязан быть палиндромом. Вместе с палиндромом `PY` это даёт период два.
Первые буквы различны: `PY` — нечётное чередующееся слово, `Y` — его
нечётный суффикс длины хотя бы три, `P` — степень `ab` чётной длины.

Продвигаемся назад. Пусть части после `A_h` вместе с `Y` образуют
нечётный чередующийся хвост длины не меньше `2(M−h)+3`. Если `A_h a` или
`A_h aba` непалиндромно, оставшийся чётный чередующийся хвост делится на
`M−h` положительных чётных частей, давая всего `M`. Поэтому оба
расширения палиндромны. Разница длин два задаёт тот же период и чётную
длину `A_h`. Все исходные части оказываются степенями `ab` чётной длины;
вся строка нечётно чередуется. Каждый её непалиндром имеет чётную длину,
а нечётную сумму из них получить нельзя. Противоречие доказывает границу
и по индукции весь DP.

### Минимум равен одному или двум

Если `AB`, `BC` и `ABC` палиндромны, то `B` — палиндром. У `ABC` есть
периоды `|A|` и `|C|` благодаря палиндромным суффиксу и префиксу. Длина
больше суммы периодов, поэтому периодом служит их НОД. Элементарное
обоснование: при `p<q` и длине хотя бы `p+q` сравнения `i→i−p→i−p+q` для
`i≥p` и `i→i+q→i+q−p` иначе дают период `q−p`; повторяем Евклид.
Отражение переводит `B` в равную по длине подстроку с началом `|C|`
вместо `|A|`; начала сравнимы по общему периоду, значит `B` равно
развороту.

У трёх соседних непалиндромных частей объединяем соседнюю пару, если
объединение непалиндромно. Если обе пары палиндромны, вся тройка
непалиндромна по лемме; объединяем её. Так любое допустимое разбиение
сокращается до одной или двух частей. После проверки существования через
DP минимум равен одному для непалиндромной всей строки, иначе двум.

## Особенности языков

Манакер, DP и заключительная проверка занимают `O(n)` времени и `O(n)`
памяти. Частей не больше `floor(n/2)`, поэтому достаточно стольких
уровней и нулевого. Все версии итеративны и используют целые индексы;
Python работает под CPython 3.12. Ввод хранится целиком.

Добавлять разрез `i−2`, а не `i−1`; нулевой уровень принадлежит пустому
префиксу. Пропускать невозможные префиксы, хранить оба крайних разреза.
Палиндром иногда разбивается, как `abba`; непостоянная строка иногда не
разбивается, как `ababa`. Жадный выбор короткого префикса и ограничение
длинами два или три неверны. Учитывать регистр и обе чётности центра. В
решениях нет вероятностного хеширования и перебора всех уровней DP.

Не путать чётную длину с чётным показателем степени `ab`: в тесте
`edge_05` (`ababa`) слова `Y=aba` и `PY=ababa` палиндромны при `P=(ab)^1`.
