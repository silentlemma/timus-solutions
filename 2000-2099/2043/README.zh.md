# 2043. 带南边界补给的蛇形遍历

[Timus 2043](https://acm.timus.ru/problem.aspx?space=1&num=2043) · difficulty 4147 · math

原题作者 Ilya Kuchumov (Prepared by Kirill Borozdin)，出自 2014 年夏季彼得罗扎沃茨克集训营乌拉尔联邦大学 Dandelion 专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

网格从西向东有 `n` 列，从南向北有 `m` 行。按竖向蛇形顺序处理格子：从西南角向北走完第一列，向东一步，再向南走完第二列，继续交替。起始格子不计移动步数，相邻格子间一步移动花费一。

容器最初有 `k` 单位资源，每处理一格消耗一单位。每处理完 `k` 格后，若尚未处理最后一格，就直向南走到当前列底格，向外一步补满，再返回同一底格，随后按最短曼哈顿路径走到处理顺序的下一格。出去并返回共两步。补给移动不推进处理顺序，也不消耗资源。处理最后一格后立即停止。求总移动步数模 `1000000007`。

## 输入

第一行 `1≤t≤10`。随后每行给出 `n,m,k`，满足 `1≤n,m≤10^12`、`1≤k≤10^18`、`min(n,m)≤10^6`。因此面积 `N=nm≤10^18`。宽和高作用不同，不能交换。时间限制 4 秒，内存 64 MB。

## 输出

按输入顺序，每组输出一行模 `1000000007` 的整数，按整数标记比较答案。

## 评测方式

按记号逐个比较输出。

## 样例

```
1
5 3 5
```

```
20
```

共有 `15` 格，普通遍历需 `14` 步，在第 `5`、`10` 格后补给。第一次当前格和下一格距南边的高度为 `1`、`0`，用 `1+2+0=3` 步替代一步，多 `2` 步。第二次高度为 `2`、`1`，多 `2+2+1-1=4` 步。总数 `14+2+4=20`，第 `15` 格后不补给。

## 解法

### 一次补给的额外代价

坐标从零开始，南端高度为零。第 `j` 格后当前位置为 `(x,y)`，下一格为 `(u,v)`。补给路线花费 `y+2+v+|u-x|`，替代普通的一步。额外代价始终为偶数，记其一半为 `f(j)`。补给数恰为 `F=(N-1)//k`，答案是 `N-1+2Σ f(ik)`，`1≤i≤F`。上界 `N-1` 排除最后一格的补给，即使 `k` 整除 `N` 也如此。

设 `j=qm+r`、`0≤r<m`。`r>0` 时，上行列有 `f(j)=r`，下行列有 `f(j)=m-r`，由 `q` 的奇偶性决定。`r=0` 时，奇数 `q` 对应顶部转列，`f=m`；偶数对应底部转列，`f=1`。因此令 `P=2m`、`z=j mod P`，则 `f(j)=min(z,P-z)`，但 `z=0` 的值是 `1` 而非零。

### 按列求和

零基列 `c` 包含补给序号区间 `(cm,min((c+1)m,N-1)]`。其中 `k` 的倍数下标从 `a=cm//k+1` 到 `b=min((c+1)m,N-1)//k`。若 `a>b` 则无补给，否则有 `C=b-a+1` 个。

上行列的半代价构成从 `ak-cm` 到 `bk-cm` 的等差数列；下行列则从 `(c+1)m-ak` 到 `(c+1)m-bk`。每列使用 `C(first+last)/2` 求和。下行数列末项为零时，额外加一修正底部转列。各序号区间恰好划分全部补给，故得到正确的 `O(n)` 方法。

### 余数周期的短前缀

令 `g=gcd(k,2m)`、`L=2m/g`。`ki` 的余数周期为 `L`，完整周期恰好访问 `0,g,2g,...,(L-1)g` 各一次。设 `h=L//2`，三角函数两边之和为 `g h(L-h)`，无论 `L` 奇偶。零余数还贡献一，所以周期和为 `C=g h(L-h)+1`。

写成 `F=qL+r`，完整周期贡献 `qC`。对非零周期下标有 `f(ki)=f(k(L-i))`，所以 `prefix(r)+prefix(L-r-1)=C-1`。只计算前 `W=min(r,L-r-1)` 项；若互补前缀更短，从 `C-1` 中减去它。每次余数加 `k mod 2m`，必要时减去一次 `2m`。真前缀不会出现零余数，其特殊的一已在周期及互补公式中处理。

因为 `W≤floor((L-1)/2)≤m/g≤m`，当 `n<W` 时按列，否则枚举余数。循环数最多 `min(n,m)≤10^6`。列区间划分证明第一种求和，余数排列和对称性证明第二种，因此任选一种均正确。

### Python 的完整列短周期

Python 还可按 `T=2k/gcd(m,k)` 对完整列分组。列号加 `T` 保持奇偶性及 `cm mod k`，故完整列代价重复。`T` 为偶数且 `k` 整除 `Tm`。已有 `columns(T,m,k)` 省略末尾的底部补给，加一即可恢复完整周期。`R` 列的不完整组同理：只有 `k` 整除 `Rm` 时补回末项，奇数 `R` 的半代价为 `m`，偶数为一。组合周期及余组后，若 `k` 整除 `N`，减去真实最后一格的补给。

仅在 `2T<min(n,W)` 时使用此加速。一个周期及其不完整前缀访问少于 `2T` 列，不会恶化原循环上界。所有运算模答案模数仍然精确。

每组时间 `O(min(n,m)+log(max(k,m)))`，额外算术空间 `O(1)`；对数项来自 gcd。整个输入最多十组。

面积、实际使用的序号乘积及所选短余数和均适合 64 位，后者不超过 `m·10^6≤10^18`。完整等差数列及周期总和可能达到约 `10^30`。C++、Rust 使用 128 位中间值。Go、Java、Python 先把等差求和的一个偶因子除以二，再对因子取模，乘积小于 `MOD²<2^63`；Go、Java 还先对完整周期因子取模。这些操作保持余数并避免溢出。

不要旋转网格、最后一格后补给或增加起始移动。三角函数零余数代价是一。互补前缀长度为 `L-r-1`，必须扣除周期末端的特殊一。保留顶部与底部转列修正；先除偶因子再做模乘。不能构造全部网格或枚举所有补给。

## 各语言说明

各版本使用整数 gcd 和标量循环。C++、Rust 用 128 位保存精确大和；Go 1.14、Java 8 维护模意义下的 64 位和，Java 使用缓冲数字输入。Python 使用额外完整列周期及有界模累加，选择 PyPy 3.10。输入输出缓冲只容纳最多十组数据及答案。
