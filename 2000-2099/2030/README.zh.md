# 2030. 向树上邻点广播数值

[Timus 2030](https://acm.timus.ru/problem.aspx?space=1&num=2030) · 难度 517 · dfs

原题作者 Nikita Sivukhin，出自 2014 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定有 `n` 个顶点的连通无向树，编号为 1 至 `n`，顶点 `v` 初值为整数 `a[v]`。
依次处理两类请求：

- `1 v`：取操作前 `v` 的当前值，将该快照加到每个邻点，`v` 自身不变。
- `2 v`：输出 `v` 当前值对 `P = 1000000007` 的余数。

邻点收到的是增量，不是覆盖。以后的广播和查询都包含此前全部增量。
限制：`1 ≤ n,m ≤ 100000`，`0 ≤ a[v] ≤ 1000000000`，2 秒，64 MB。

## 输入

先给出 `n`，再一行 `n` 个初值。接下来 `n-1` 行为边的端点 `x y`，满足
`1 ≤ x,y ≤ n`、`x ≠ y`，保证连通。之后给出请求数 `m` 和 `m` 对 `t v`，
其中 `t` 为 1 或 2，`1 ≤ v ≤ n`。

## 输出

每个第二类请求输出一行 `[0,P-1]` 中的余数。没有第二类请求时输出为空。
只有一个顶点时，任何广播都不改变其数值。

## 评测方式

按记号逐个比较输出。

## 解法

用迭代遍历把树根设为顶点 1。每个非根顶点恰有一个父亲，其余邻点都是孩子。
把广播拆为向父亲的一次直接增量，以及对所有孩子的一次共同延迟增量。

维护初始为 `a[v]` 的 `direct[v]` 和初始为零的 `broadcast[v]`。
`broadcast[v]` 是 `v` 曾广播过的所有快照之和，`direct[v]` 包含初值与所有孩子广播的增量。
不变量为非根顶点的
`value(v) = direct[v] + broadcast[parent[v]] (mod P)`，根则只有 `direct[root]`。

每次先求 `delta = value(v)`。查询直接输出；广播将 `delta` 加到 `broadcast[v]`，
若存在父亲，再加到 `direct[parent[v]]`。所有字段立即模 `P`，请求中不遍历邻点。

### 正确性

初始无广播，不变量显然成立。若广播前成立，每个孩子的值都读取 `broadcast[v]`，
因此这个共同字段增加 `delta`，所有孩子便恰好各增 `delta`。父亲通过自己的 `direct`
收到同一增量。源点读取自己的 `direct` 和父亲的 `broadcast`，两者都没改变，因而自身不变。
其他顶点的公式没有读取任何改变的字段，所以也不变。这完全实现了所需操作并保持不变量。
查询只读取不变量，归纳得出每个答案正确。操作只有整数加法，因此中途模 `P` 保持所需余数。

首个样例先读到四个 1。顶点 1 广播后仅顶点 2、3 变为 2，顶点 1、4 仍为 1。
第二个样例在唯一一条边上交替广播，查询依次得到 `1,1,2,3,5,8,13,21`。

遍历 `O(n)`，每次请求 `O(1)`，总时间 `O(n+m)`。树、父亲和值数组占工作空间 `O(n)`。
Python 最多缓冲 `O(m)` 个输出字符串；Rust 还保留输入，计入缓冲总空间为 `O(n+m)`。
C++、Go、Java 流式处理请求与输出。

注意事项：

- 源点不接收自身广播，树没有自环。
- 修改字段前先取当前源值快照。
- 使用父亲的累计广播，不是父亲的当前值。
- 根要单独处理，不能通过父亲哨兵把自身广播加回来。
- 十万顶点的链应迭代遍历，避免递归栈溢出。
- 无查询时不额外输出零。

## 各语言说明

每次加法后都规范化，两个余数之和至多 `2000000012`，Java 的有符号 `int` 也安全。
C++、Go、Rust 的值字段使用更宽类型；一次条件减模足够。Java 使用原始类型邻接数组与字节解析器。
Python 按行读取，迭代建好父亲后释放临时邻接。无需递归、度数阈值或对数数据结构。
