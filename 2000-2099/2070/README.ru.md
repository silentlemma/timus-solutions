## Задача

Один считает целое число интересным, если оно простое, другая — если
простое число его положительных делителей. Число удовлетворяет обоих,
если их мнения совпадают в ту или другую сторону. Посчитайте такие числа
на отрезке [L; R]. Ограничения: 2 секунды и 64 МБ.

## Входные данные

L и R, 2 ≤ L ≤ R ≤ 10¹².

## Выходные данные

Количество чисел из [L; R], которые устраивают обоих.

## Проверка

Вывод сравнивается полностью, включая пробелы и переводы строк.

## Примеры

### Пример 1

Ввод:

```
3 7
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
2 2
```

Вывод:

```
1
```

### Пример 3

Ввод:

```
77 1010
```

Вывод:

```
924
```

## Решение

У простого числа 2 делителя, а 2 — простое, так что любое простое
интересно обоим. Составное число устраивает обоих, если только его число
делителей не простое. Для x = p₁^a₁ · … · pₛ^aₛ это число равно
(a₁ + 1) · … · (aₛ + 1), а произведение простое, только если в нём один
множитель. Значит, неподходящие числа — это ровно степени p^k простого
числа с k ≥ 2 и простым k + 1, и ответ — R − L + 1 минус их количество
на [L; R].

Раз p^k ≤ 10¹² при k ≥ 2, каждое такое p не больше 10⁶. Решето до 10⁶
даёт простые, и для каждого простого p с p² ≤ R перебираются степени
p², p³, … до R; считаются те, что не меньше L и у которых показатель
плюс один — простое. У простых больше 10⁴ есть только квадрат, так что
перебор короткий; основное время уходит на решето, O(N log log N) при
N = 10⁶.

В первом примере у 4 = 2² три делителя, поэтому среди 3 … 7 это
единственное неподходящее число, и ответ 4.

## Оптимизированные решения

Квадраты простых отделяются от остальных подходящих чётных степеней. Число простых до нужного квадратного корня вычисляется DP подсчёта простых по различным целым частным. Явное решето требуется лишь для больших степеней, чьи простые основания не превосходят корня четвёртой степени. Подходящие показатели учитываются по тому же теоретико-числовому доказательству; ответ на отрезке — разность префиксных количеств. Корни корректируются целочисленно, исключая ошибки границы из-за вещественной арифметики.

Здесь R — правая граница отрезка, M=floor(sqrt(R)), P — число малых простых для больших степеней. Подсчитанные степени — неподходящие числа, поэтому их количество на отрезке вычитается из длины отрезка.
