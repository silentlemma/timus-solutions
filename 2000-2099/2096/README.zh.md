# 2096. 关于由早先计划派生的计划的询问

[Timus 2096](https://acm.timus.ru/problem.aspx?space=1&num=2096) · 难度 2627 · dfs, trees

原题作者 Egor Shchelkonogov，出自 2014 年乌拉尔联邦大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

计划 0 给出 n 天中每天的活动。计划 i（i = 1 … m）先对更早的计划 f 提问“计划 f 中第 x 天是什么”，然后复制更早的计划 pᵢ 并做修改，每次修改把第 d、d + p、…、d + (k − 1)p 天设为新活动（后面的修改优先）。回答所有询问。时间限制 2 秒，内存限制 64 MB。

## 输入

n 和 m（至多 10⁵），计划 0 的 n 个活动，然后对每个计划给出其询问以及基础计划和修改；询问和修改总数各不超过 10⁵，修改涉及的天数总计不超过 5·10⁶。

## 输出

每个计划一行，给出其询问的答案。

## 样例

### 样例 1

输入：

```
3 2
1 2 3
1
0 3
0 2
1 2 2 4
2 2 1 5
3
1 1
1 2
1 3
0 0
```

输出：

```
3
4 5 5
```

## 解法

每个计划都是其基础计划加上自己的修改，所以计划构成以计划 0 为根的树，每个询问都针对某个固定的计划。用一个活动数组对树做一次遍历，离线回答所有询问：进入计划时应用它的修改并保存被覆盖日子的旧值，回答关于该计划的询问，遍历子节点，离开时按相反顺序恢复保存的值。每个被修改的日子只写入和恢复一次，所以工作量为 O(n + m + Σ k + q)。遍历用显式栈，因为树可能是长为 10⁵ 的链。
