# 2096. Вопросы о планах, выведенных из прежних

[Timus 2096](https://acm.timus.ru/problem.aspx?space=1&num=2096) · сложность 2627 · dfs, trees

Автор оригинальной задачи — Егор Щелконогов; Открытое личное первенство УрФУ по программированию 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

План 0 задаёт занятие на каждый из n дней. План i (i = 1 … m) сначала
задаёт вопросы «что в день x в плане f» о прежних планах f, затем
копирует прежний план pᵢ и применяет изменения, каждое из которых ставит
на дни d, d + p, …, d + (k − 1)p новое занятие (более позднее изменение
побеждает). Ответьте на все вопросы. Ограничения: 2 секунды и 64 МБ.

## Входные данные

n и m (до 10⁵), n занятий плана 0, затем для каждого плана его вопросы
и его базовый план с изменениями; всего не больше 10⁵ вопросов и 10⁵
изменений, а изменения в сумме затрагивают не больше 5·10⁶ дней.

## Выходные данные

Для каждого плана — строка с ответами на его вопросы.

## Примеры

### Пример 1

Ввод:

```
3 2
1 2 3
1
0 3
0 2
1 2 2 4
2 2 1 5
3
1 1
1 2
1 3
0 0
```

Вывод:

```
3
4 5 5
```

## Решение

Каждый план — это его базовый план плюс собственные изменения, поэтому
планы образуют дерево с корнем в плане 0, и каждый вопрос относится к
фиксированному плану. На все вопросы отвечаем офлайн одним обходом
дерева с единственным массивом занятий: при входе в план применяем его
изменения, сохраняя старые значения перезаписанных дней, отвечаем на
вопросы об этом плане, обходим детей, а при выходе восстанавливаем
сохранённые значения в обратном порядке. Каждый изменённый день
записывается и восстанавливается один раз, так что работа —
O(n + m + Σ k + q). Обход идёт с явным стеком, потому что дерево может
быть путём из 10⁵ планов.
