# 2013. 任意路线下顶点前后的确定值

[Timus 2013](https://acm.timus.ru/problem.aspx?space=1&num=2013) · 难度 940 · graphs

原题作者 Alex Samsonov（由 Egor Shchelkonogov 整理），出自 NEERC 2014 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在有向图顶点 1 以值 0 开始行走。进入顶点时记录当前值；若该顶点参数 `k>0`，把值替换为 `k`，否则保持不变。再记录离开值并任选出边继续。允许重复访问。对每个顶点，分别判断所有可能到达该次访问的路线是否具有相同进入值和相同离开值。所有顶点均可从 1 到达。

## 输入

先给 `n`，`1 ≤ n ≤ 100,000`。按顶点顺序每行给出 `k m` 和递增的 `m` 个不同出边目标。`0 ≤ k ≤ 100,000`，`0 ≤ m ≤ n`，目标编号为 `1..n`，允许自环。总边数至多 100,000。时间限制 1 秒，内存 64 MB。

## 输出

按编号每顶点一行两个答案：替换前与替换后。始终为零写 `sober`；始终为同一个正值写整数；多种可能写 `unknown`。英文均为小写，唯一答案按标记比较。

## 评测方式

按记号逐个比较输出。

## 样例

```
5
0 2 2 3
6 1 4
5 2 4 5
5 1 5
0 0
```

```
sober sober
sober 6
sober 5
unknown 5
5 5
```

```
2
0 2 1 2
0 2 1 2
```

```
sober sober
sober sober
```

第一个样例的顶点 4 可以带着 6 或 5 进入，所以入口未知；自身替换后出口为 5。到顶点 5 的两种路线随后都携带 5。第二例没有替换，环不会改变初始零值。

## 解法

入口只需三类状态：尚未到达、一个确定值（含零）、未知。用两个不同负数表示尚未到达和未知。把顶点 1 的入口设为零，放入变化队列。以后回到顶点 1 时，初始零仍是一种合法可能。

弹出顶点后，若 `k>0`，出口状态就是 `k`；否则继承当前入口。把该状态传给全部后继。尚未到达的后继接受新状态；相同确定值保持不变，不同状态合并成未知。未知吸收所有后续信息。只在入口变化时入队。队列清空后，用同样替换规则计算出口。

这种摘要足够：正值替换抛弃全部历史，零值顶点保留历史。两个可行的不同值，或本来就包含多个值的状态，正确说明歧义；来自不同顶点的同一数值仍相同。每项传播都对应真实路线，所以不会凭空产生歧义。终止时每条边都已传递其前驱最终出口，按有限路线长度归纳可知所有可能都已包含。因此确定状态就是全部路线的共同值，未知则表示至少两种可能。环无需拓扑顺序。

每个入口至多变化两次：未到达变为确定，再变为未知，或直接变为未知。每次变化至多入队一次，每份邻接表至多扫描两次。时间 `O(n+m)`，空间 `O(n+m)`。用带偏移的平面数组存边，并使用迭代队列，不递归也不枚举所有路线。

## 各语言说明

首次访问不能定案，后来的冲突要沿零值顶点继续传播。正值顶点能重置未知输入；再次进入顶点 1 也可能让入口未知。纯零环始终保持零，相同正标签不冲突。全部顶点可达，所以不输出未到达状态。Java 队列容量 `2n` 足够；Go、C++、Rust 用可增长数组。Python 用紧凑有符号数组存图和状态、deque 存队列，并在构造输出前释放输入标记，使用 CPython。
