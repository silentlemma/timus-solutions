# 2079. Остатки Фибоначчи, которые могут следовать за данным

[Timus 2079](https://acm.timus.ru/problem.aspx?space=1&num=2079) · сложность 4667 · number_theory

Автор оригинальной задачи — Владислав Исенбаев.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Числа Фибоначчи берутся по модулю простого p: x₀ = 0, x₁ = 1,
xₙ = (xₙ₋₁ + xₙ₋₂) mod p. По значению x найдите все значения, которые
могут идти за ним, то есть все различные x_{k+1} по индексам k с
x_k = x (индексы уходят далеко за период). Ограничения: 0.5 секунды и
256 МБ.

## Входные данные

Простое p, 2 ≤ p < 10⁹, и x, 0 ≤ x < p.

## Выходные данные

Количество различных следующих значений, затем сами значения по
возрастанию, или только 0, если x не встречается.

## Примеры

### Пример 1

Ввод:

```
7 0
```

Вывод:

```
2
1 6
```

### Пример 2

Ввод:

```
7 3
```

Вывод:

```
1
5
```

### Пример 3

Ввод:

```
11 4
```

Вывод:

```
0
```

## Решение

Работу делают два факта. Тождество Кассини
F(k+1)² − F(k+1) F(k) − F(k)² = (−1)ᵏ верно и по модулю p, поэтому
значение y, идущее за x, решает y² − x y − (x² + s) = 0 при s = 1 или
−1. Это даёт не больше четырёх кандидатов y = (x ± √(5x² + 4s)) / 2;
квадратные корни берутся алгоритмом Тонелли — Шенкса.

Но кандидат может и не встречаться: в третьем примере 4 не появляется
по модулю 11, хотя у уравнения есть корни. Чтобы проверить кандидата,
работаем в кольце F_p[t] / (t² − t − 1), где tᵏ = F(k) t + F(k − 1).
Пара (x, y) встречается ровно тогда, когда x t + (y − x) — степень t,
то есть это задача дискретного логарифма. Период последовательности
делит p − 1, если p mod 5 равно 1 или 4, и 2(p + 1) иначе, поэтому
шаги младенца и великана — m ≈ √(2p) шагов tⁱ в таблице и великанские
шаги умножением на t⁻ᵐ = (t − 1)ᵐ — отвечают за O(√p). Простые до 50
(включая 2 и 5, которые формулы не покрывают) обрабатываются обходом
всего периода длиной не больше 4p + 4.

В первом примере x = 0 даёт y² = ±1 по модулю 7; −1 не квадрат, а 1
(k = 0) и 6 (k = 8, F(9) = 34) встречаются.
