# 2047. 以前缀约数个数约束序列

[Timus 2047](https://acm.timus.ru/problem.aspx?space=1&num=2047) · difficulty 483 · number_theory

民间题目，由 Alexander Ipatov 整理，出自 2015 年乌拉尔体育编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

构造 n 个整数 a₁, …, aₙ，满足 1 ≤ aᵢ ≤ 300，并且对 2 到 n 的每个 k，前缀和 a₁ + … + aₖ 恰好有 aₖ 个不同的正约数。第一项本身没有条件。时间限制 1 秒，内存限制 64 MB。

## 输入

一个整数 n，2 ≤ n ≤ 100 000。

## 输出

输出一个合法序列，数之间用空格分隔；若不存在则输出 `Impossible`。

## 评测方式

检查器核对长度和取值范围，并统计从第二个起每个前缀和的约数个数；任何合法序列都被接受，只有不存在序列时才接受 `Impossible`。

## 样例

```
3
```

```
1 3 4
```

`1+3=4` 的约数是 `1,2,4`，所以第二项为三。下一个前缀和 `8` 的约数是 `1,2,4,8`，所以第三项为四。`2 4 6` 也是正确答案：对应约束前缀和 `6`、`12` 分别有四、六个约数。

## 解法

记正约数个数为 `τ(s)`。任何至少两项、总和为 `s` 的序列，其最后一项必为 `d=τ(s)`，前一个和唯一为 `s-d`。按和递增搜索这些前驱边。

令 `depth[s]` 表示总和为 `s` 的合法序列最大长度。恰在 `1≤s≤300` 时，一项序列合法，基本值为一；否则为零，表示不可达。若 `d≤300`、`s>d` 且 `depth[s-d]>0`，还可取 `depth[s-d]+1`，选较大者。

完整搜索上界 `M=300n` 来自每项不超过 300。首次深度达到 `n` 时停止，反向沿 `n-1` 条强制前驱边记录末项，将剩余总和作为第一项，再反转答案。若扫描到 `M` 仍未达到，输出 `Impossible`。

### 分块计算约数数目

先筛出不超过 `floor(sqrt(M))` 的素数，每次处理 `K=65536` 个整数。每个数的剩余因子初始为自身、计数初始为一。对于 `p²≤right` 的素数 `p`，访问块内其倍数，除尽 `p` 的 `e` 次幂，将计数乘 `e+1`。剩余值大于一时再乘二。依据公式 `τ(s)=product(e+1)`。

将计数追加到紧凑历史中以便重建。合法边最多回跳 300，故深度只需 301 个循环槽位；必须先读前驱再覆盖当前槽位。约数个数大于 300 的边不参与转移。

### 正确性

分解移除了不超过块右端平方根的全部素因子。若剩余值仍是合数，就有其中一个素因子，与已除尽矛盾。因此它为一或一个素数，指数因子之积得到准确约数数目，包括 `τ(1)=1`。

对总和归纳：合法序列或是一项且值在范围内，或最后一项必为 `τ(s)`，前缀位于唯一更小前驱。反过来，向可达前驱追加该项会满足新条件且保留旧条件。因此递推恰好求最大合法长度。合法回跳在一至 300 之间，循环数组保留正确前驱值。

首次成功前所有深度都小于 `n`，新增深度只能加一，所以首次成功恰为 `n`。反向重建每步沿同一递推边，深度减一，最后落在不超过 300 的基本值，故每项范围及全部前缀条件正确。若 `300n` 内均失败，任意所求序列的终点都会与精确递推矛盾；因此无解输出同样正确，不依赖猜测的截断。

### 复杂度与实际搜索范围

保守最坏界为时间 `O(M log M+n)`、空间 `O(M+K+sqrt(M)+n)`，并可提前停止。若扫描了 `B` 个和，历史空间为 `O(B)`，至多额外分解一个块。块间素数循环开销受 `sqrt(M)≤5477<K` 限制。约数数目满足 `τ(s)≤2sqrt(s)≤2sqrt(30000000)<11000`，所以 16 位存储乃至 Java 有符号 short 都安全。

独立普通筛构造出长度 100000、终点总和 `1568617` 的合法链，并逐个前缀以约数枚举核验。其前缀证明所有合法长度均存在答案，因此首次成功终点均不超过该和。程序仍使用完整上界 `300n`，没有把该链或终点作为硬编码截止条件。

## 各语言说明

条件从 `k=2` 开始；统计正约数而非素因子。前驱深度零不可转移。301 格循环数组使当前槽位与全部 300 种前驱槽位不同；写入当前深度前先读取前驱。重建需要约数历史，不只有深度环。不要对零进行除因子循环。

五个版本均为相同完整分块搜索。Java 扩展基本 short 数组，C++、Go、Rust 也存储 16 位历史。Python 使用 `array("H")` 和小块、小环列表。

Python 解答在 PyPy 下运行：在 CPython 3.12 下它在评测的第 13 个测试上超时，而在 PyPy 3.10 下以 0.437 秒通过。
