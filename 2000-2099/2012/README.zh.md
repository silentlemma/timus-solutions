# 2012. 在截止时间前完成十二项任务

[Timus 2012](https://acm.timus.ru/problem.aspx?space=1&num=2012) · 难度 17 · math

原题作者 Alexander Ipatov（由 Olga Soboleva 整理），出自 NEERC 2014 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

五小时内共有十二项任务。第一小时完成恰好 `f` 项，即使提前做完，也必须等到完整一小时结束才能开始下一项。其余每项恰需 45 分钟，依次进行。判断能否在五小时结束前全部完成。

## 输入

一个整数 `f`，`1 ≤ f ≤ 11`。时间限制 1 秒，内存 64 MB。

## 输出

能按时完成输出大写 `YES`，否则输出 `NO`。唯一答案按标记比较。

## 评测方式

按记号逐个比较输出。

## 样例

```
7
```

```
YES
```

```
5
```

```
NO
```

`f=7` 时剩五项，总时间 `60+5·45=285` 分钟，不超过 300。`f=5` 时剩七项，需要 `60+7·45=375` 分钟，超过截止时间。

## 解法

统一使用分钟。第一阶段占 60 分钟，余下 `12−f` 项各占 45 分钟，故完成时间为 `T=60+45·(12−f)`。当且仅当 `T≤300` 时输出 `YES`。

这个条件必要且充分。固定的第一小时加上后续顺序执行的任务，恰需上述时长；若超过上限就无法完成。如果不超过 300，从第 60 分钟立即开始剩余任务即可按时结束。第一小时内的空闲不能让第二阶段提前。

也可这样理解：第一小时后还剩 240 分钟，只能完成 `floor(240/45)=5` 项。因此要求 `12−f≤5`，即 `f≥7`。程序保留使用具名常量的时间表达式，避免没有解释的阈值。刚好在截止时刻完成也合法。

时间为 `O(1)`，额外空间为 `O(1)`。合法输入的最大总时间为 `60+11·45=555`，普通有符号整数足够，不需要浮点数或舍入。

## 各语言说明

完整保留第一小时，计算未完成的任务，并统一时间单位。答案只能是大写 `YES`/`NO`。Java 8 的 Scanner 足以读取一个整数；其他语言用标准输入接口。CPython 足以完成常数规模计算。五个程序均使用精确整数不等式。
