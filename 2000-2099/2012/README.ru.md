# 2012. Двенадцать задач до окончания сеанса

[Timus 2012](https://acm.timus.ru/problem.aspx?space=1&num=2012) · сложность 17 · math

Автор оригинальной задачи — Александр Ипатов; подготовка — Ольга Соболева. NEERC 2014, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

За пятичасовой сеанс нужно выполнить двенадцать задач. В первый час
выполнено ровно `f` задач. Даже если они закончены раньше, к следующей
приступают только после полного первого часа. Каждая оставшаяся задача
занимает ровно 45 минут, задачи выполняются последовательно. Определите,
можно ли закончить все двенадцать к концу сеанса.

## Входные данные

Одно целое число `f`, `1 ≤ f ≤ 11`. Лимит времени 1 секунда, памяти 64 МБ.

## Выходные данные

Выведите `YES`, если план укладывается в срок, иначе `NO`. Регистр
верхний. Единственный ответ сравнивается по токенам.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
7
```

```
YES
```

```
5
```

```
NO
```

При `f=7` остаётся пять задач: всего `60+5·45=285` минут, что не
превышает 300. При `f=5` остаётся семь задач: `60+7·45=375` минут,
больше отведённого времени.

## Решение

Переведём длительности в минуты. Первый этап занимает 60 минут; после
него остаётся `12−f` задач. Полное время `T=60+45·(12−f)`. Ответ `YES`
получается ровно при `T≤300`.

Условие необходимо и достаточно. Полный первый час и последовательные
оставшиеся задачи требуют именно столько времени: если оно больше
лимита, закончить нельзя. Если оно не больше 300, начинаем остальные
задачи сразу после минуты 60 и успеваем. Свободное время внутри первого
часа не позволяет сдвинуть этот момент раньше.

То же условие можно записать иначе. После первого часа есть 240 минут,
за которые помещается только `floor(240/45)=5` новых задач. Значит,
`12−f≤5`, то есть `f≥7`. Реализации используют исходное выражение
длительности с именованными константами. Равенство сроку допустимо в
обеих формах.

Время `O(1)`, дополнительная память `O(1)`. При допустимом входе полная
длительность не превосходит `60+11·45=555`, поэтому достаточно обычных
знаковых целых. Вещественные числа и округления не нужны.

## Особенности языков

Учтите полный первый час, считайте именно оставшиеся задачи и не
смешивайте часы с минутами. Ответы пишутся `YES`/`NO`, только верхним
регистром. Для одного числа подходит даже Scanner Java 8; остальные
реализации используют стандартное чтение. CPython достаточно для
вычисления постоянного размера. Все пять решений проверяют одно точное
целочисленное неравенство.
