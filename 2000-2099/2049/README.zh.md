# 2049. 逆向等分构造转移操作

[Timus 2049](https://acm.timus.ru/problem.aspx?space=1&num=2049) · difficulty 3271 · constructive

原题作者 Daniil Ayzenshteyn（由 Egor Shchelkonogov 整理），出自 2015 年乌拉尔体育编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 n 个容器，每个装有一个单位。操作 a → b 把与 b 当前容量相等的量从 a 倒入 b，即 (x, y) 变为 (x − y, 2y)，只有 x ≥ y 时才允许。用不超过 3n 次操作使容器 1 恰好装有 k 个单位，其余容器最后装多少都可以。时间限制 1 秒，内存限制 64 MB。

## 输入

两个整数 n 和 k，1 ≤ k ≤ n ≤ 100 000。

## 输出

若无法做到输出 `-1`。否则先输出操作次数 M（0 ≤ M ≤ 3n），再输出 M 行，每行一对不同的容器编号 a b。

## 评测方式

检查器执行这些操作，确认每次操作合法且容器 1 最后恰有 k 个单位；任何合法的操作序列都被接受，只有无法做到时才接受 `-1`。

## 样例

```
5 3
```

```
4
2 1
4 3
3 1
1 5
```

```
5 5
```

```
-1
```

第一个示例依次得到 `[1,1,1,1,1]→[2,0,1,1,1]→[2,0,2,0,1]→[4,0,0,0,1]→[3,0,0,0,2]`，首个容器为三。第二个示例必须将全部五个单位集中，下述不变量禁止这种情况。

## 解法

### 可行条件

`k` 为二的幂（包括一）时可行；否则恰在 `n≥k+1+(k mod 2)` 时可行。

全部数量最大公约数的奇数部分不变。对任意奇素数幂 `q`，由于二在模 `q` 下可逆，变换前所有坐标被 `q` 整除，当且仅当变换后也如此。初始最大公约数为一，因此 `n=k` 时集中全部数量要求 `k` 为二的幂。

对于奇数 `k>1`，考察第一个容器首次变成 `k`。它不能是接收者，因为接收会翻倍为偶数；作为供给者，之前为 `k+y`，另一个接收者为 `y≥1`，总量至少 `k+2`。这证明了所有不可行情形，充分性由构造给出。

### 逆向构造

二的幂使用 `N=k` 个容器，否则使用 `N=k+1+(k mod 2)`，未使用的容器一直为一。先设定目标**终态**：`[k,0,…]` 或 `[k,N-k,0,…]`。后者的额外量是一或二，最大公约数奇数部分为一。

逆操作选 `b` 中正偶数 `2h`，取一半放入另一容器 `a`，即 `(x,2h)→(x+h,h)`。记录原正向编号对 `(a,b)`。它可合法撤回，因为 `x+h≥h`。最后反转的是记录的**顺序**，每对的方向不变。

维护空容器、正偶数容器及按数量分组的正奇数容器。

1. 至少两个偶数时，任选一个等分到空容器。
2. 唯一偶数能被四整除时，同样等分。
3. 否则它为 `2h`，`h` 为奇数。选择奇数数量 `a≠h`，固定**同一对容器**，不断逆操作并交换奇偶角色，直到偶数能被四整除，下一步再等分。
4. 若没有不同于 `h` 的奇数数量，最大公约数奇数部分就是 `h`，故 `h=1`。此时只有一个二，其余正量均为一，等分最后的二。

需要空容器时必然有空位：总量 `N` 且某个正量大于一，正容器数量就小于 `N`。普通等分除最后一步外保留偶数；固定对逆操作也保留偶数。

固定对的半量及奇量按 `(h,a)→((h+a)/2,h)` 演化，直到新半量为偶数。非零差 `D=a-h` 每步变为 `-D/2`，所以恰经过 `t=ν2(|D|)` 步，半量变偶数，整体可被四整除。每段循环终止，随后等分增加正容器数。最终有 `N` 个正量、总量 `N`，即全部为一。反向执行记录即可得到目标首容器数量。

### 操作数量证明

证明包含解析界和一个小规模**完整有限验证**，如下代码及 [tests/gen.py](tests/gen.py)。

正量定义 `L(v)=floor(log2(v))`，令 `F=sum L(v)`、`P` 为正容器数。对一步或一段操作证明成本至多 `2ΔF+3ΔP`。

普通等分 `2h→h,h` 成本一，`ΔP=1`、`ΔF=L(h)-1≥-1`，符合该界。

将 `t` 次固定对逆操作与紧接着的等分合为阶段，成本 `t+1`、`ΔP=1`。写 `a-h=2^t d`，`d` 为带符号奇数，`ε=(-1)^t`、`T=2h+a`。阶段后数量为 `b,b,c`，其中 `b=(T-εd)/3` 为正偶数，`c=T-2b` 为正奇数。由半量递推 `h_next=(T-h)/2` 及不动点 `T/3` 解得此式。

只须证明 `ΔF≥floor((t-1)/2)`，便有 `t+1≤2ΔF+3`。

`t=1` 时 `b=(h+a)/2,c=h`。设 `q=L(max(h,a))`，由 `b≥max(h,a)/2` 得 `ΔF=2L(b)-L(a)-1≥q-3`。`q≥3` 即满足，否则两输入均小于八。

`t≥2` 时设 `u=min(h,a),v=max(h,a),p=L(u),q=L(v)`。平均操作保证 `b,c≥u`，且 `b,c≥v/4`：若 `a≥h`，偶数 `t` 时 `b≥(a+3h)/4,c≥a/3`，奇数 `t≥3` 时 `c≥(a+3h)/4,b≥a/3`；若 `h>a`，两者都至少 `h/2`。因此
`ΔF≥3max(p,q-2)-p-q-1≥q-5`。
又由 `|a-h|≥2^t` 得 `q≥t`。`t≥8` 时已足够；`2≤t≤7` 且 `q≥5+floor((t-1)/2)` 时也足够。剩余情况 `q≤7`，故两个奇数输入均小于 256。

所以所有余下情况，包括小 `t=1` 情况，都由下列 16256 个有序、不同、正奇数对的完整验证覆盖：

```python
L = lambda x: x.bit_length() - 1
for h in range(1, 256, 2):
    for a in range(1, 256, 2):
        if a == h:
            continue
        D = a - h
        t = (abs(D) & -abs(D)).bit_length() - 1
        d = D // (1 << t)
        T = 2 * h + a
        b = (T - (-1) ** t * d) // 3
        c = T - 2 * b
        delta = 2 * L(b) + L(c) - L(2 * h) - L(a)
        assert t + 1 <= 2 * delta + 3
```

全部断言成立，阶段界得证。对普通等分和完整阶段求和，终态 `F=0,P=N`，因此
`M≤2(0-F_initial)+3(N-P_initial)≤3N≤3n`。
算法没有对 `n` 或操作数使用经验截断。

### 实现与复杂度

用数组保存双向链表：正偶数共用一个表，奇数按当前数量分组；另一链表保存非空奇量组。选择不同于 `h` 的奇量只需首组或下一组。改变数量前先删除两个容器的旧成员关系，再插入新关系。容器链接可在奇偶列表之间复用。

链表操作均为常数，不扫描稀疏集合。时间、空间为 `O(N+M)=O(n)`。

## 各语言说明

接收者数量必须翻倍，转移量并不任意。保留首容器编号。反转操作顺序而非对的方向。阶段内固定同一对，否则阶段证明不适用。仅等分需要空容器。`k=1` 时零次操作正确。

五个版本均用紧凑数组及独立操作缓冲。Python 使用无符号 `array` 并分块输出，Java 使用基本类型数组和可复用字节输出缓冲。C++、Go、Rust 缓冲输出。
