# 2049. Построение переливаний обратным делением

[Timus 2049](https://acm.timus.ru/problem.aspx?space=1&num=2049) · difficulty 3271 · constructive

Автор оригинальной задачи — Даниил Айзенштейн; подготовка — Егор Щелконогов. XIX Открытый чемпионат Урала по спортивному программированию (апрель, 2015).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть n сосудов, в каждом одна единица. Действие a → b переливает из a в
b ровно столько, сколько сейчас в b, то есть (x, y) превращается в (x −
y, 2y); оно допустимо, только если x ≥ y. Не более чем за 3n действий
получите в сосуде 1 ровно k единиц; в остальных может остаться что
угодно. Ограничения: 1 секунда и 64 МБ.

## Входные данные

Два целых числа n и k, 1 ≤ k ≤ n ≤ 100 000.

## Выходные данные

Выведите `-1`, если это невозможно. Иначе выведите число действий M, 0 ≤
M ≤ 3n, и затем M строк с парами a b различных сосудов.

## Проверка

Проверяющая программа выполняет действия, убеждается, что каждое
допустимо и что в сосуде 1 в конце k единиц; принимается любая
подходящая последовательность, а `-1` — только если задача невыполнима.

## Примеры

```
5 3
```

```
4
2 1
4 3
3 1
1 5
```

```
5 5
```

```
-1
```

Первый пример меняет объёмы так:
`[1,1,1,1,1]→[2,0,1,1,1]→[2,0,2,0,1]→[4,0,0,0,1]→[3,0,0,0,2]`. Первый
сосуд содержит три. Во втором примере пришлось бы собрать вместе все
пять единиц, что запрещено инвариантом ниже.

## Решение

### Критерий существования

Для степени двойки `k`, включая единицу, ответ существует. Для остальных
— ровно при `n≥k+1+(k mod 2)`.

Нечётная часть НОД всех объёмов сохраняется. Для любой нечётной степени
простого `q` все координаты после `(x,y)→(x-y,2y)` делятся на `q` тогда
и только тогда, когда делились до шага: двойка обратима по модулю `q`.
Первоначальный НОД равен единице. Поэтому при `n=k` весь объём можно
собрать только в степень двойки.

Для нечётного `k>1` рассмотрим первое появление `k` в первом сосуде.
Получатель удваивается, значит, первый сосуд был донором: до шага в нём
`k+y`, а в получателе `y≥1`. Общий объём не меньше `k+2`. Это доказывает
все запреты; достаточность даёт конструкция.

### Обратная конструкция

Используем `N=k` сосудов для степени двойки, иначе `N=k+1+(k mod 2)`.
Неиспользуемые остаются единицами. Начинаем с желаемого **конечного**
состояния: `[k,0,…]` либо `[k,N-k,0,…]`. Во втором случае добавочный
объём один или два, нечётная часть НОД равна единице.

Обратный шаг берёт положительный чётный объём `2h` в сосуде `b` и
переносит половину в другой сосуд `a`: `(x,2h)→(x+h,h)`. Запоминаем
исходную прямую пару `(a,b)`. Обратить этот шаг можно легально,
поскольку `x+h≥h`. В конце разворачивается **порядок** пар, а не
направление каждой пары.

Храним пустые сосуды, положительные чётные сосуды и группы нечётных
сосудов по объёму.

1. При наличии хотя бы двух чётных делим любой из них пополам в пустой
   сосуд.
2. Единственный чётный объём, делящийся на четыре, тоже делим в пустой.
3. Иначе он равен `2h` с нечётным `h`. Выбираем нечётный объём `a≠h` и
   сохраняем **ту же пару сосудов**. Выполняем обратные шаги, меняя их
   чётную и нечётную роли, пока чётный объём не станет кратен четырём.
   Затем следующим шагом делим его.
4. Если отличного от `h` нечётного объёма нет, нечётная часть НОД равна
   `h`, значит, `h=1`. Есть единственная двойка, остальные положительные
   — единицы; делим последнюю двойку.

Пустой сосуд всегда найдётся: при массе `N` и объёме больше единицы
положительных сосудов меньше `N`. Обычное деление оставляет чётный
сосуд, кроме последнего шага. Обратные шаги пары тоже его сохраняют.

Для пары `(2h,a)` половина и нечётный объём переходят как
`(h,a)→((h+a)/2,h)`, пока новая половина нечётна. Ненулевая разность
`D=a-h` превращается в `-D/2`. Ровно через `t=ν2(|D|)` шагов половина
станет чётной, весь чётный объём — кратным четырём. Каждая серия
завершается, после неё деление увеличивает число положительных сосудов.
В итоге их `N` при сумме `N`, то есть все единичные. Обращение
записанных шагов даёт нужное прямое решение с сохранением номера первого
сосуда.

### Доказательство предела числа действий

Доказательство включает аналитическую оценку и небольшой **полный
конечный перебор**, приведённый ниже и в [tests/gen.py](tests/gen.py).

Пусть `L(v)=floor(log2(v))` для положительного `v`, `F=sum L(v)`, а `P`
— число положительных сосудов. Ограничим цену каждого шага или группы
величиной `2ΔF+3ΔP`.

Обычное деление `2h→h,h` стоит один шаг, `ΔP=1`, `ΔF=L(h)-1≥-1`, поэтому
оценка верна.

Объединим серию из `t` обратных шагов с немедленно следующим делением.
Цена фазы `t+1`, `ΔP=1`. Запишем `a-h=2^t d`, где `d` нечётное со
знаком, `ε=(-1)^t`, `T=2h+a`. В конце фазы три объёма `b,b,c`, где
`b=(T-εd)/3` положителен и чётен, `c=T-2b` положителен и нечётен.
Формула следует из рекуррентности половины `h_next=(T-h)/2` с
неподвижной точкой `T/3`.

Достаточно `ΔF≥floor((t-1)/2)`, тогда `t+1≤2ΔF+3`.

При `t=1` имеем `b=(h+a)/2,c=h`. Если `q=L(max(h,a))`, то `b≥max(h,a)/2`
и `ΔF=2L(b)-L(a)-1≥q-3`. При `q≥3` этого достаточно; иначе оба входа
меньше восьми.

При `t≥2` обозначим `u=min(h,a),v=max(h,a),p=L(u),q=L(v)`. Усреднение
даёт `b,c≥u`. Также `b,c≥v/4`: при `a≥h` и чётном `t` имеем
`b≥(a+3h)/4,c≥a/3`, при нечётном `t≥3` — `c≥(a+3h)/4,b≥a/3`; при `h>a`
оба объёма не меньше `h/2`. Следовательно, `ΔF≥3max(p,q-2)-p-q-1≥q-5`.
Из `|a-h|≥2^t` следует `q≥t`. Для `t≥8` нужная оценка получена. Для
`2≤t≤7` она тоже верна при `q≥5+floor((t-1)/2)`. В оставшихся случаях
`q≤7`, то есть оба нечётных входа меньше 256.

Значит, все остаточные случаи, включая малые при `t=1`, покрываются
полным перебором 16256 упорядоченных разных положительных нечётных пар
меньше 256:

```python
L = lambda x: x.bit_length() - 1
for h in range(1, 256, 2):
    for a in range(1, 256, 2):
        if a == h:
            continue
        D = a - h
        t = (abs(D) & -abs(D)).bit_length() - 1
        d = D // (1 << t)
        T = 2 * h + a
        b = (T - (-1) ** t * d) // 3
        c = T - 2 * b
        delta = 2 * L(b) + L(c) - L(2 * h) - L(a)
        assert t + 1 <= 2 * delta + 3
```

Все утверждения выполняются, лемма фазы доказана. Суммируем обычные
деления и полные фазы. В конце `F=0,P=N`, поэтому
`M≤2(0-F_initial)+3(N-P_initial)≤3N≤3n`. Эмпирическая граница по `n` или
числу действий не используется.

### Реализация и сложность

Двусвязные списки хранятся в массивах. Для чётных сосудов один список,
нечётные распределены по спискам текущих объёмов. Ещё один список
содержит непустые группы нечётных объёмов. Для поиска объёма, отличного
от `h`, достаточно первой группы или следующей. Перед изменением двух
объёмов удаляем старые членства, после — вставляем новые. Ссылки сосуда
переиспользуются между чётным и нечётным списками.

Все операции списков постоянны; разреженные множества не сканируются.
Время и память — `O(N+M)=O(n)`.

## Особенности языков

Получатель удваивается, переносимый объём не произволен. Важен именно
первый сосуд. Обращается порядок действий, а не направление пар. Пара не
меняется внутри серии, иначе доказательство фазы неприменимо. Пустые
сосуды нужны только для делений. При `k=1` правильны ноль действий.

Все реализации используют компактные массивы и отдельные буферы пар.
Python хранит беззнаковые `array` и выводит порциями; Java — примитивные
массивы и повторно используемый байтовый буфер. C++/Go/Rust выводят с
буферизацией.
