# 2098. Заплатить наличными или переплатить за страховку

[Timus 2098](https://acm.timus.ru/problem.aspx?space=1&num=2098) · сложность 325 · math

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

После мелкой аварии водитель может заплатить b рублей наличными или
оформить её и дать заплатить страховой. Страховка стоит c сейчас и
дорожает на d каждый год, так что следующие k лет стоят c + d, c + 2d,
…, c + kd; после оформленной аварии эти k платежей на p процентов выше.
Скажите, какой вариант дешевле (при равенстве — Insurance), и на
сколько. Ограничения: 1 секунда и 64 МБ.

## Входные данные

b (до 10⁵), затем c и d (до 10⁴), затем k и p (до 100).

## Выходные данные

`Cash` или `Insurance`, затем выгода с абсолютной или относительной
погрешностью не больше 10⁻⁶.

## Примеры

### Пример 1

Ввод:

```
10000
5000 1000
3 50
```

Вывод:

```
Cash
500.00
```

### Пример 2

Ввод:

```
15000
2500 1000
4 25
```

Вывод:

```
Insurance
10000.00
```

## Решение

Оба варианта платят обычную страховку S = k·c + d·k(k + 1)/2 за
следующие k лет. Наличные добавляют b, оформление — S·p/100. Сравнение
100·b с S·p оставляет всё в целых (не больше примерно 5·10⁹), а их
разность, делённая на 100, — выгода, она печатается точно с двумя
знаками.

В первом примере S = 21000, так что оформление стоит на 10500 больше, а
наличные — на 10000: Cash, выгода 500.
