# 2098. 付现金还是多付保险费

[Timus 2098](https://acm.timus.ru/problem.aspx?space=1&num=2098) · 难度 325 · math

原题作者 Denis Dublennykh，出自 2014 年乌拉尔联邦大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

发生小事故后，司机可以付 b 卢布现金私了，或者报案让保险公司赔付。保险现在价格为 c，每年上涨 d，所以接下来 k 年分别为 c + d、c + 2d、…、c + kd；报案后这 k 次付款都高 p%。判断哪种选择更便宜（相等时选 Insurance）以及便宜多少。时间限制 1 秒，内存限制 64 MB。

## 输入

b（至多 10⁵），然后是 c 和 d（至多 10⁴），然后是 k 和 p（至多 100）。

## 输出

`Cash` 或 `Insurance`，然后是节省的金额，绝对或相对误差不超过 10⁻⁶。

## 样例

### 样例 1

输入：

```
10000
5000 1000
3 50
```

输出：

```
Cash
500.00
```

### 样例 2

输入：

```
15000
2500 1000
4 25
```

输出：

```
Insurance
10000.00
```

## 解法

两种选择都要付接下来 k 年的普通保险费 S = k·c + d·k(k + 1)/2。现金多付 b，报案多付 S·p/100。比较 100·b 与 S·p 可以全用整数（至多约 5·10⁹），二者之差除以 100 就是节省的金额，精确输出两位小数。

第一个样例中 S = 21000，报案多付 10500，而现金多付 10000：Cash，节省 500。
