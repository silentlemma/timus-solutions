# 2027. 执行有界寄存器网格

[Timus 2027](https://acm.timus.ru/problem.aspx?space=1&num=2027) · 难度 541 · simulation

原题作者 Kirill Borozdin，出自 2014 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

解释执行矩形指令网格。机器有一个当前整数寄存器及 `A` 至 `Z` 共 26 个内存寄存器，初值全为零。
指针从左上格出发，初始朝右。每个时钟先执行当前格指令，再沿更新后的方向移动一格。网格不环绕。

| 指令 | 移动前的效果 |
| --- | --- |
| `^`、`>`、`v`、`<` | 分别设为向上、右、下、左。 |
| `.` | 无操作。 |
| `A`…`Z` | 交换当前值与指定内存寄存器。 |
| `?` | 用下一个输入整数覆盖当前值；输入用完后每次都重复最后一个整数。 |
| `!` | 输出当前值，然后将当前寄存器清零。 |
| `+`、`-` | 当前值加一或减一。 |
| `@` | 当前值为零则逆时针转，否则顺时针转，负数也属于非零。 |
| `#` | 立即结束，不移动。 |

指令执行后当前值超出 `[-100000,100000]` 则报 `OVERFLOW ERROR`；随后移动出界则报
`RUNTIME ERROR`。若完成 1000000 个时钟仍未结束或报这两种错，则报 `TIME LIMIT EXCEEDED`。
保留此前所有输出。执行及溢出判断先于移动，两种错误均先于时钟上限判断；第 1000000 步执行 `#` 可以成功。

`1 ≤ H,W ≤ 100`，输入整数数量 `1 ≤ N ≤ 100000`，每个绝对值至多 100000。未读完输入并不报错。
时间限制 2 秒，内存限制 64 MB。

## 输入

先给 `H W`，再给 `H` 行各 `W` 个合法指令字符，随后给 `N` 及逐行的 `N` 个整数。

## 输出

每执行一个 `!`，输出一行整数。发生错误则另起一行追加其精确消息。
正常结束不追加内容，整个输出可以为空。

## 评测方式

按记号逐个比较输出。

## 解法

将每个整数按十进制记号读取：先跳过可选的 `+` 或 `-`，逐位累积数字，再应用符号。
模拟前，对网格尺寸、输入数量和输入值都采用相同步骤。

直接模拟，保存坐标、方向、当前值、内存、输入游标及输出缓冲。方向按顺时针编码为右、下、左、上。
`@` 遇非零加一模四，遇零减一模四。读到最后一个数后游标保持在其下标。

最多执行 1000000 次：先执行指令，`#` 立即返回；否则检查溢出，再按方向偏移移动并检查边界。
第一处错误立即终止。循环耗尽则追加时间上限消息。输出缓冲保留错误之前的值。
不需要检测循环：重复位置仍可能继续输出很多数字，不能据此提前停止。

正确性用时钟数归纳。初始寄存器、位置、方向、未读输入及空输出符合定义。
每条指令执行规定更新：交换保留两个值，读取选择下一个数或最后的重复数，输出发生在清零之前，方向变化先于移动。
所以每步的状态与输出前缀一致。按规定阶段检查得到相同的第一处错误，`#` 在移动前结束。
百万个完整时钟后只能再触发时间上限，故完整输出及最终消息正确。

第一个样例通过 `A` 循环转移单位并输出 5。第二个输出零并清空当前寄存器，随后进入无法结束的循环，
故追加时间上限。第三个把唯一的输入读两次；第二次仍得 1，输出后结束。

设执行时钟数 `S ≤ 1000000`、输出字符数 `B`，时间为 `O(HW + N + S + B)`。
包含输入输出缓冲的空间为 `O(HW + N + B)`，寄存器和指针只用常量空间。
流式输出可去掉输出存储项，但必须保留错误之前的每次输出。

注意事项：

- 整数可以带显式 `+`，输入数量也一样。测试 `028` 使用 `+1`；将符号当成数字会把数量读成负数。
- 字母指令是交换，不是复制；`!` 输出后清零。
- 输入耗尽时重复最后一项，未用完输入合法。
- `@` 的负数分支也顺时针。
- 不环绕，`#` 后不移动，溢出优先于移动出界。
- 先完成百万步的指令与移动，再判断时间上限。
- 大量输出不能省略；立即结束甚至不应添加多余换行。

## 各语言说明

普通有符号整数足够覆盖合法值及一步越界。C++ 用字符串缓冲，Go 用 `strings.Builder`，Java 用
`StringBuilder`，Rust 用 `String`，Python 用 `StringIO`，避免保存近百万个独立数字字符串。
所有版本缓冲输入并完整执行规定时钟上限，不跳过循环。
