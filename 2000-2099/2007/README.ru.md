# 2007. Минимальная строка после всех буквенных операций

[Timus 2007](https://acm.timus.ru/problem.aspx?space=1&num=2007) · сложность 1922 · strings, greedy

Автор оригинальной задачи — Илья Кучумов; Уральская региональная командная олимпиада по программированию 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны строка и мультимножество буквенных модификаторов. Каждый нужно
использовать ровно один раз, в любом порядке. Модификатор `c` либо
вставляет `c` в произвольное место, включая края, либо удаляет одну
существующую `c`. Вставленную букву позже тоже можно удалить. Найдите
лексикографически минимальный результат. Более короткий собственный
префикс меньше продолжения. Гарантируется, что применением всех
модификаторов пустую строку получить нельзя.

## Входные данные

Две непустые строки: исходная `S` и модификаторы `T`. Обе состоят только
из строчных латинских букв и имеют длину не более 100000 каждая. Порядок
модификаторов во входе не ограничивает порядок применения. Время 0,5
секунды, память 64 МБ.

## Выходные данные

Минимальная достижимая строка, непустая по гарантии. Длина не больше `|S|+|T|`.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
abc
bbc
```

```
ab
```

Удалим `c` её модификатором, а два модификатора `b` потратим на вставку
и удаление дополнительной `b`. Останется `ab`.

## Решение

### Жадное правило

Пусть `R[c]` — количество оставшихся исходных букв, `K[c]` —
модификаторов. Пустое продолжение возможно тогда и только тогда, когда
для всех букв `K[c]≥R[c]` и разность `K[c]−R[c]` чётна: удаляем исходные
буквы, затем расходуем лишние одинаковые пары вставкой и удалением. Если
условие выполнено, сразу завершаем ответ: любое продолжение больше
текущего префикса.

Иначе выбираем минимальную возможную следующую букву. Это либо вставка
буквы с положительным запасом модификаторов, либо исходная буква, весь
исходный префикс перед которой можно удалить имеющимися запасами. При
равенстве выбираем самое раннее доступное исходное вхождение, удаляем
префикс перед ним и сохраняем букву. Если вставка меньше, расходуем
соответствующий модификатор и выводим его букву.

### Почему правило равенства верно

Оставшиеся исходные буквы сохраняют порядок, прочие буквы результата
вставлены. Вставленная и затем удалённая буква расходует нейтральную
пару одинаковых модификаторов. Операции можно переставить в такую форму
без изменения результата.

Выбранная исходная `c` делит остаток на `X+c+Z`. Все буквы `X` строго
больше `c`: каждая позиция `X` сама доступна, а более ранняя `c` была бы
выбрана первой. Модификатора меньше `c` тоже нет. Если ответ сохраняет
более позднюю исходную `c`, можно поменять сохраняемое и удаляемое
вхождения местами, не изменив расходы и строку. Поэтому достаточно
самого раннего.

Сравним сохранение этой `c` со вставкой `c` первой. Возьмём любое
продолжение после вставки. Если все исходные буквы `X` удаляются, а
исходная `c` сохраняется, используем её для первого символа и вставим
`c` в её прежнее место результата. Ответ и расходы совпадут. Если
исходная `c` удаляется, сохраним её первой, а два освободившихся
модификатора `c` израсходуем нейтральной парой. После раннего удаления
`X` снова получается тот же ответ.

Если некоторая исходная буква `X` сохраняется, перед первой такой буквой
стоят только вставленные символы, не меньшие `c`. Продолжение имеет
начальную серию `c^r`, за которой идёт большая буква. Эти `r` символов
вставлены, поэтому `r≤K[c]−1`: один модификатор уже ушёл на первую
вставку. Сохранение исходной буквы оставляет все `K[c]` модификаторов
`c`, поскольку в `X` таких букв нет. Можно дописать ещё `r+1` копий `c`,
а затем закончить допустимым образом, сохранив суффикс и вставив
остальные модификаторы. Результат строго меньше продолжения после
вставки.

Таким образом, сохранение исходной буквы не хуже. Минимальная доступная
следующая буква, это правило равенства и проверка пустого продолжения
доказывают оптимальность по индукции по оставшимся операциям и исходным
буквам.

### Быстрая реализация

Для каждой буквы храним позиции в исходной строке, число уже
использованных позиций `head[c]` и ограничитель `n=|S|`. Пусть
`cut[c]=head[c]+K[c]`. Первое неудаляемое вхождение находится в
`positions[c][cut[c]]`, либо в `n`, если индекс вышел за список. Минимум
таких позиций обозначим `r`. Ближайшее исходное вхождение доступно тогда
и только тогда, когда его позиция не больше `r`, включая саму `r`.

Удаление префиксной буквы уменьшает `K` и увеличивает `head`, поэтому
`cut` не меняется. Сохранение увеличивает её `cut`, вставка уменьшает.
Также `delta[c]=cut[c]−исходная_частота[c]=K[c]−R[c]`. Битовая маска
отмечает отрицательные или нечётные разности; для остановки обновляется
только бит выбранной буквы. Две другие маски отмечают оставшиеся
исходные буквы и доступные модификаторы.

Минимальную доступную исходную букву запоминаем до следующего сохранения
исходной позиции. Вставка выбирается только для строго меньшей `c`,
которой нет в достижимом префиксе. Уменьшение её запаса не переносит
первую неудаляемую позицию раньше ближайшего вхождения этой буквы,
расположенного за `r`. Значит, запомненный выбор верен на всей серии
вставок. Если для текущей исходной буквы нет модификатора, только она
доступна без поиска.

Запросов исходной буквы не больше `n+1`, каждый просматривает до `A=26`
букв. Каждая исходная позиция используется один раз, вставок не больше
`m=|T|`. Время `O(A n+m+A)`, то есть `O(n+m)` для фиксированного
алфавита. Память `O(n+m+A)` вместе с выводом. Дерево всех
последовательностей операций не строится.

## Особенности языков

Все модификаторы обязательны, но нейтральные пары не должны оставаться в
ответе. Проверяйте пустое продолжение до выбора очередной буквы:
исходная гарантия не запрещает пустой остаток позже. При равенстве
предпочитайте исходную букву, включайте первую неудаляемую позицию в
доступный диапазон и сбрасывайте сохранённый выбор после использования
исходной позиции. Проверяйте границы `cut` перед индексированием. Пять
портов используют массивы позиций, 26-битные маски и итеративные циклы;
поиск младшего бита вызывается только для ненулевой маски.
