# 2007. 使用全部字母操作后的最小字符串

[Timus 2007](https://acm.timus.ru/problem.aspx?space=1&num=2007) · 难度 1921 · strings, greedy

原题作者 Ilya Kuchumov，出自 2013 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定字符串与字母修改器多重集。必须以任意顺序将每个修改器使用恰好一次。修改器 `c` 可以在任意位置（含两端）插入 `c`，或删除当前已有的一个 `c`。后来也可删除插入的字母。求字典序最小的最终字符串，真前缀比其任何延长更小。保证使用全部修改器不能得到空串。

## 输入

两行非空串：原串 `S` 与修改器 `T`。仅含小写拉丁字母，各自长度不超过 100000。输入中修改器的顺序不限制操作顺序。时间 0.5 秒，内存 64 MB。

## 输出

最小的可达字符串，由保证知其非空，长度不超过 `|S|+|T|`。

## 评测方式

按记号逐个比较输出。

## 样例

```
abc
bbc
```

```
ab
```

用 `c` 修改器删除 `c`，两个 `b` 修改器分别插入、删除一个额外 `b`，留下 `ab`。

## 解法

### 贪心规则

设 `R[c]` 为剩余原始字母数，`K[c]` 为修改器数。剩余部分可变为空串，当且仅当每种字母均满足 `K[c]≥R[c]` 且 `K[c]−R[c]` 为偶数：删除原始字母，再把剩余同字母修改器两两用于插入和删除。此时立即停止输出，因为延长当前前缀更大。

否则选择最小可行的下一字母：可以插入一个还有修改器的字母，或保留某个原始位置，只要它之前的原始前缀都能用现有修改器删除。同字母平局时，优先保留最早的可达原始位置，删除其前缀。只有插入字母严格更小时才插入。

### 平局规则的证明

最终保留的原始字母顺序不变，其余存活字母均为插入。一个插入后又被删除的字母消耗同字母修改器的一对，净效果为零。操作可按这种形式重排而不改变结果。

所选原始 `c` 将剩余原串分成 `X+c+Z`。`X` 中字母均严格大于 `c`：其中每个位置本身可达，更早的 `c` 也会被优先选中。也不存在小于 `c` 的可用修改器。若某答案保留更后的原始 `c`，交换哪一个同字母位置被保留、哪一个被删除，不改变用量或最终串。因此只需最早位置。

比较保留此 `c` 与先插入 `c`。任取插入分支的后续方案。若 `X` 的全部原始字母被删除而原始 `c` 存活，可用此原始位置充当首个输出，在它原来的输出位置改为插入 `c`，结果和修改器用量相同。若原始 `c` 被删除，则保留它作为首字母，省下的两个 `c` 修改器作一次中性插入、删除对。提前删除 `X` 后仍可获得同一结果。

若 `X` 中某个原始字母存活，在第一个此类字母之前只有插入字母，均不小于 `c`。后续结果以 `c^r` 开始，随后有更大字母。这 `r` 个 `c` 都是插入的，且最初的插入已消耗一个，故 `r≤K[c]−1`。保留原始 `c` 后，因 `X` 不含 `c`，仍有全部 `K[c]` 个修改器，可再输出 `r+1` 个 `c`，然后保留后缀并插入其他修改器完成合法操作。所得串严格更小。

所以保留原始位置不劣于插入。同最小可行首字母原则及可空时停止结合，对剩余操作和原始字母归纳，得全局最优。

### 高效实现

每种字母保存原始位置列表、已消耗数量 `head[c]` 及哨兵 `n=|S|`。令 `cut[c]=head[c]+K[c]`，第一个无法删除的该字母位置是 `positions[c][cut[c]]`，超出列表则为 `n`。所有这些位置的最小值为 `r`。某字母最早的剩余原始位置不大于 `r` 时恰好可达，注意包含 `r`。

删除前缀字母使 `K` 减一、`head` 加一，`cut` 不变。保留原始字母使其 `cut` 加一，插入则减一。又有 `delta[c]=cut[c]−初始频数[c]=K[c]−R[c]`。位掩码标记负数或奇数差值，每次只更新所选字母的位便可判断停止。另两个掩码记录剩余原始字母及可用修改器。

最小可达原始字母可缓存，直到保留下一个原始位置。插入只会选择严格更小的 `c`，它在当前可达前缀中没有原始出现。减少其配额后，第一个不可删位置仍不会早于其第一个剩余位置，而该位置在 `r` 之后，所以缓存对整段插入都有效。当前原始字母没有修改器时，只有它可达，可直接选择。

最多 `n+1` 次原始字母查询，每次查看至多 `A=26` 种字母；每个原始位置消耗一次，插入至多 `m=|T|` 次。时间 `O(A n+m+A)`，固定字母表下即 `O(n+m)`；含输出的空间 `O(n+m+A)`。不构造操作序列树。

## 各语言说明

全部修改器必须消耗，但中性对不必留在答案里。每次选字母前先判断可空；初始保证不排除以后后缀可空。同字母优先原始位置，可达区间包含首个不可删位置，保留原始字母后须刷新缓存。访问列表前检查 `cut` 上界。五个版本都使用位置数组、26 位掩码及迭代循环，仅在掩码非零时寻找最低有效位。
