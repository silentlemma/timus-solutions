# 2087. Переводить стрелки только там, где последний поезд ушёл не туда

[Timus 2087](https://acm.timus.ru/problem.aspx?space=1&num=2087) · сложность 3539 · trees, segment_tree

Автор оригинальной задачи — Денис Мухаметьянов.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Железная дорога на клетчатой карте — дерево: депо и станции — листья,
стрелки — внутренние вершины, каждое ребро длины 1, и у каждой стрелки
задано начальное положение (прямо, налево или направо). Поезда один за
другим выходят из депо в заданные моменты, проходят единицу пути за
единицу времени и должны попасть на заданные станции; стрелку можно
переводить только в момент, когда к ней подходит поезд. Выведите
наименьшее число переводов, каждый с моментом, стрелкой и новым
положением. Подходит любой порядок переводов. Ограничения: 4 секунды и
256 МБ.

## Входные данные

N и M, 2 ≤ N, M ≤ 500, карта (2N − 1) × (2M − 1), затем Q ≤ 2·10⁵
поездов с моментами отправления и станциями назначения в порядке
отправления.

## Выходные данные

Число переводов, затем сами переводы `T X Y C`.

## Проверка

Локальная проверяющая программа сравнивает число переводов и мультимножество
событий с эталонным ответом, допуская любой порядок вывода. Движение поездов
она не воспроизводит.

## Примеры

### Пример 1

Ввод:

```
3 3
S-F-X
..|..
L-R-R
|...|
X.X-R
4
1 1 3
2 3 1
4 1 3
6 3 2
```

Вывод:

```
4
3 1 2 R
5 1 2 F
7 1 2 R
8 2 2 L
```

### Пример 2

Ввод:

```
2 3
S-F-X
..|..
..X..
3
1 2 2
2 1 3
4 1 3
```

Вывод:

```
2
2 1 2 R
3 1 2 F
```

## Решение

Поезда идут с одинаковой скоростью и выходят по порядку, поэтому каждую
стрелку они проходят в порядке отправления, поезд с отправлением T
подходит к стрелке на глубине h в момент T + h, а каждая стрелка смотрит
туда, куда ушёл последний прошедший через неё поезд (или стоит в
начальном положении). Поезду нужен перевод ровно на тех стрелках его
пути, которые смотрят не к его станции, и эти переводы вынуждены, так
что минимум — сумма таких несовпадений по всем поездам.

Карта превращается в подвешенное дерево с глубинами, эйлеровыми
отрезками и тяжёлыми путями для наименьших общих предков. Для каждой
вершины заранее известен лист, к которому ведут начальные положения.
Для нового поезда с назначением d начинаем с листа e, куда его повели бы
текущие положения из корня (это предыдущее назначение, ведь предыдущий
поезд выставил все стрелки своего пути). Пока e ≠ d, наименьший общий
предок j вершин d и e — неправильная стрелка: перевод в момент
T + depth(j) в сторону потомка c на пути к d. Ниже c стрелки смотрят
туда, куда ушёл последний поезд с назначением внутри поддерева c; его
находит дерево отрезков по эйлерову порядку (для каждой станции хранится
последний поезд) как максимум на отрезке, а если в это поддерево ещё не
заходил ни один поезд, берётся начальный лист c. Этот лист становится
новым e. Каждый шаг даёт один перевод ответа. После обработки нового
назначения обновляем в дереве отрезков номер последнего посещения станции.
В конце сортируем R событий для вывода. С учётом подготовки за O(NM)
общее время — O(NM + (Q + R) log(NM) + R log R), память —
O(NM + Q + R), где R ≤ 2·10⁵ — число переводов.

Ловушка (тест 12): поезд меняет только стрелки на своём пути;
неиспользуемая ветка сохраняет состояние после последнего посетившего
её поезда, который мог пройти раньше предыдущего поезда.

Во втором примере первому поезду нужно перевести стрелку направо в
момент 2, второму — обратно прямо в момент 3, а третий идёт так же, как
второй.
