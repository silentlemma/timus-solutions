# 2087. 只在上一列车去向不同处扳道岔

[Timus 2087](https://acm.timus.ru/problem.aspx?space=1&num=2087) · 难度 3539 · trees, segment_tree

原题作者 Denis Mukhametianov。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

画在网格上的铁路是一棵树：车库和车站是叶子，道岔是内部节点，每条边长 1，每个道岔有给定的初始位置（直行、左转或右转）。列车在给定时刻依次离开车库，每单位时间走一单位距离，必须到达指定车站；道岔只能在列车到达它的那一刻扳动。输出最少的扳动次数，每次给出时刻、道岔和新位置。扳动的任意顺序都可接受。时间限制 4 秒，内存限制 256 MB。

## 输入

N 和 M（2 ≤ N, M ≤ 500），(2N − 1) × (2M − 1) 的地图，然后是 Q ≤ 2·10⁵ 列按出发顺序给出的列车，包括出发时刻和目的车站。

## 输出

扳动次数，然后是各次扳动 `T X Y C`。

## 评测方式

本地检查器将扳动次数和事件多重集合与参考答案比较，允许任意输出顺序。它不模拟列车运行。

## 样例

### 样例 1

输入：

```
3 3
S-F-X
..|..
L-R-R
|...|
X.X-R
4
1 1 3
2 3 1
4 1 3
6 3 2
```

输出：

```
4
3 1 2 R
5 1 2 F
7 1 2 R
8 2 2 L
```

### 样例 2

输入：

```
2 3
S-F-X
..|..
..X..
3
1 2 2
2 1 3
4 1 3
```

输出：

```
2
2 1 2 R
3 1 2 F
```

## 解法

列车速度相同且按顺序出发，所以它们按出发顺序经过每个道岔，出发时刻为 T 的列车在 T + h 时刻到达深度为 h 的道岔，而每个道岔指向最后一列经过它的列车所去的方向（或保持初始位置）。列车恰好需要在其路径上指向别处的道岔处扳动，这些扳动是必需的，所以最小值就是所有列车上这种不一致之和。

地图读成一棵有根树，带深度、欧拉区间和用于最近公共祖先的重链剖分。对每个节点预先求出按初始位置走到的叶子。对目的地为 d 的新列车，从当前道岔位置从根引向的叶子 e 开始（就是上一列车的目的地，因为上一列车设置了它路径上的所有道岔）。当 e ≠ d 时，d 与 e 的最近公共祖先 j 是不一致的道岔：在 T + depth(j) 时刻把它扳向通往 d 的子节点 c。在 c 之下，道岔指向目的地位于 c 子树内的最后一列车的方向，这由按欧拉序建立的线段树（为每个车站保存最后一列车）作为区间最大值求出；若还没有列车进入过该子树，则用 c 的初始叶子。这个叶子成为新的 e。每一步产生答案中的一次扳动。处理一个不同于上次的目的地后，在线段树中更新该车站的最后访问编号。最后对 R 个事件排序并输出。计入 O(NM) 的预处理，总时间为 O(NM + (Q + R) log(NM) + R log R)，空间为 O(NM + Q + R)，其中 R ≤ 2·10⁵ 是扳动次数。

易错点（测试 12）：列车只改变自身路径上的道岔；未经过的分支保留最后访问它的列车留下的状态，该列车可能早于上一列车。

第二个样例中第一列车需要在时刻 2 把道岔扳向右，第二列车需要在时刻 3 把它扳回直行，第三列车与第二列车同路。
