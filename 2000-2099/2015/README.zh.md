# 2015. 选择负担得起的住房与居住方式

[Timus 2015](https://acm.timus.ru/problem.aspx?space=1&num=2015) · 难度 300 · bruteforce

原题作者 Eugene Kurpilyansky，出自 NEERC 2014 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

选择一套住房，独住或与列表中的一位朋友合住。独住可选一室或两室；合住只能选两室。独住支付全部租金，合住时双方各付恰好一半，并各自满足预算。总分为住房收益加对应房间数的独住收益，或加所选朋友的收益。求任意可负担的最高分方案；只有完全无可行方案时才报告无法租房。

## 输入

首先是自身预算及一室、两室独住收益。然后 `n`，`0 ≤ n ≤ 256`，及 `n` 对朋友预算与收益。再给 `m`，`1 ≤ m ≤ 256`，及 `m` 组三元组：房间数（1 或 2）、完整租金、住房收益。预算与租金都是 1 到 100,000 的整数，收益为 0 到 100,000。朋友与住房按输入顺序从 1 编号。时间限制 1 秒，内存 64 MB。

## 输出

独住住房 `i` 输出 `You should rent the apartment #i alone.`；与朋友 `j` 合住输出 `You should rent the apartment #i with the friend #j.`。无可行方案输出 `Forget about apartments. Live in the dormitory.`。将 `i,j` 替换为编号，保留英文、空格、`#` 和句号。

## 评测方式

检查器核对句子、编号、房间数和两人的预算，并把得分与最优值比较；任何最优选择都被接受，只有在什么都租不起时才接受拒绝的答复。

第一例只能负担住房 1，得分 `50+200=250`；住房 2 即使分半仍太贵。第二例独住最高 2001，而住房 3 与朋友 1 合住得 `1001+1001=2002`。第三例唯一住房超出预算。

## 解法

顺序枚举住房。若全租金不超过自身预算，考虑 `住房收益+独住收益[房间数−1]`。若是两室，再枚举每位朋友。合住当且仅当 `租金≤2·自身预算` 且 `租金≤2·朋友预算`，得分为 `住房收益+朋友收益`。加倍比较对奇数租金也精确，无需除法或浮点数。

保存最高分及两个编号。最高分初始化为 −1，小于所有合法得分；只有严格更好才替换，这给出确定的平分选择，但评测不要求该顺序。内部用朋友编号零表示独住。若从未更新，就输出无法租房。

任意合法方案必为独住一套住房，或与一位朋友合住两室。循环覆盖全部可能，且恰好排除付款超过任一预算的选项。候选得分也恰为相关两项收益之和。归纳可知已保存方案始终是已检查可行选项中的最高分，所以结束时全局最优，或确实无解。负的初始值确保零分可行方案不会被当成无解。

至多检查 `m(n+1) ≤ 65,792` 个候选，时间 `O(m(n+1))`，也包含 `n=0`。输入占空间 `O(n+m)`，选择状态额外 `O(1)`。得分与加倍预算至多 200,000，普通有符号整数足够。另一做法是按预算排序朋友并查询可负担的最大收益，但本题范围下枚举已足够。

## 各语言说明

一室不能合住，双方预算都要检查，朋友不能代付另一半。奇数租金不可向下取整，共享得分不可再加独住收益。独住收益取决于房间数。允许零朋友和零收益。五份程序均用精确整数比较与相同枚举顺序；无方案状态和独住状态分开。Python 使用 CPython，这个有限搜索无需优化。
