# 2016. 三段空间圆弧上的高速部分

[Timus 2016](https://acm.timus.ru/problem.aspx?space=1&num=2016) · 难度 6173 · geometry

原题作者 Denis Dublennykh（由 Eugene Kurpilyansky 整理），出自 NEERC 2014 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一点从原点静止出发，受到恒定向上加速度 `(0,0,a)`，以及始终垂直于运动、不做功的约束力。它先沿以 `C1` 为心的圆向上运动。第一次到达该圆上距离 `C2` 最近的点时，圆心改为 `C2`，保持当时的切向速度。再用同样规则切换到 `C3`，最后绕 `C3` 完整一周。求运动速度至少为 `v` 的路径总长度。

每个新圆经过切换点，并以进入时的速度方向为切线。两次最近点均唯一，不等于相应圆弧的起点，且在转满一圈前首次到达。切换点不等于新圆心。除初始时刻外速度始终非零。这些条件保证有合法的定向轨迹，也允许水平圆。

## 输入

先给 `t`，`1 ≤ t ≤ 1000`。每个实验先给整数 `v a`，`1 ≤ v ≤ 50,000`，`1 ≤ a ≤ 1000`，再给三个圆心坐标。坐标是 `[-10^6,10^6]` 内整数，且 `C1.x²+C1.y²>0`。不存在以恰好速度 `v` 走过的水平圆弧。时间限制 1 秒，内存 64 MB。

## 输出

按实验顺序每行输出总长度，允许绝对或相对误差至多 `10^-6`，测试使用 `float:1e-6`。孤立的速度等于阈值的点不贡献长度。

## 评测方式

数值按 10⁻⁶ 的绝对或相对误差比较。

第一段半径为 5、角度为 `asin(0.8)`，到达 `(4,0,2)`；第二段是半径 16 的水平四分之一圆，到达 `(20,16,2)`；最后是半径 1 的水平整圆。速度阈值对应高度 `0.5`，第一段符合部分加上后两段全长即为答案。

## 解法

### 把速度化为高度

约束力与速度垂直，所以不做功。单位质量的向上加速度在高度变化中做功 `a·Δz`。初始高度、速度都为零，因此 `速度²=2az`。所求区域正是 `z≥h`，其中 `h=v²/(2a)`。无需对时间积分或逐步模拟圆弧上的加速度。始终非零的速度保证方向不会反转。

### 定向圆的表示

保存圆心 `C`、半径 `R`、起点单位径向量 `A` 和向前单位切向量 `B`，满足 `A·B=0`。走过正角度 `θ` 后的位置为 `C+R(A cosθ+B sinθ)`。单位法向量为 `N=A×B`。初始 `R=|C1|`、`A=−C1/R`，`B` 是向上单位向量在垂直于 `A` 的平面上的投影再归一化。等价地取定向原始法向量 `(-C1.y,C1.x,0)`，令 `B=unit(N×A)`。非零水平分量确保该切线存在且朝上。

对下一个圆心，令 `q=Cnext−C`、`d=q·N`、`ρ=|q−dN|`。最近点径向方向为 `U=(q−dN)/ρ`。因为到新圆心的距离平方是 `R²+|q|²−2R·q·U`，在圆平面内单位方向中，沿投影方向恰好使它最小。唯一性保证 `ρ>0`。终点角为 `atan2(U·B,U·A)`；非正时加 `2π`。首次到达且终点不同于起点，保证角度严格在零与 `2π` 之间。该点向前切线是 `T=N×U`。

### 避免切换时的数值消去

新径向量为 `R·U−q=δ·U−d·N`，其中 `δ=R−ρ`。故新半径为 `hypot(δ,d)`，单位径向量为 `(δU−dN)/Rnew`。新定向法向量与 `δN+dU` 成比例，因为 `(δU−dN)×T=δN+dU`。把新法向量与新径向量叉乘并归一化，就得到向前切线。第三个圆直接使用 `2π`，不再找下一切换点。

若先计算世界坐标中的终点再减新圆心，可能丢掉极短径向量，并使下一圆的平面错误。改用有理化差值

`δ = (R²−|q|²+d²)/(R+ρ)`。

它来自 `ρ²=|q|²−d²`。求和使用误差补偿。计算 `T=unit(Nraw×q)`、`U=unit(T×N)`，避免近乎平行投影的相减。`d=0` 时保留原始未归一化法向量，仅在 `δ<0` 时反号；反复归一化可能破坏精确共面性。初始整数乘积处于浮点精确整数范围内。保存 `Rnew²=δ²+d²` 供下一次切换使用，不用任意误差阈值把微小正半径判为零。

### 求高于阈值的弧长

高度为 `Cz+R(Az cosθ+Bz sinθ)`。令 `F=R·hypot(Az,Bz)`、`φ=atan2(Bz,Az)`。`F=0` 时整段高度不变，按常量高度全部计入或全部排除。否则设 `u=(h−Cz)/F`：`u≤−1` 时整段符合，`u≥1` 时长度为零。若 `−1<u<1`，令 `α=acos(u)`，合法角度为区间 `[φ−α+2πk,φ+α+2πk]`。分别与实际走过的 `[0,L]` 相交，累加宽度后乘 `R`。因 `L≤2π`、`φ∈[-π,π]`、`α<π`，检查 `k=-2..2` 已足够，区间除端点外不重叠。

能量等式证明高度条件；投影及切线构造恢复题目规定的每段定向圆弧。区间相交恰好计数满足高度条件的角度，乘半径换为长度，因此三段相加正确。

## 各语言说明

每个实验仅三段圆弧与固定次数的区间相交，总时间 `O(t)`，每实验额外几何空间 `O(1)`。完整输入或输出缓冲最多用 `O(t)` 空间。32 位整数语言须先把速度转为浮点再平方。坐标可能为负；需要向前首次到达的角度，不能选择无向的较短弧。水平圆单独处理，最后一圆必须走满一周。C++ 使用 `long double`；Go、Java、Rust、Python 使用双精度和三项补偿求和。即使最终弧长很大，新半径和圆平面的稳定计算仍不可省略。
