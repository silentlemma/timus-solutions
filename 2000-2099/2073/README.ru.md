# 2073. Сводная таблица журналов соревнований

[Timus 2073](https://acm.timus.ru/problem.aspx?space=1&num=2073) · сложность 242 · implementation

## Задача

Даны n ≤ 100 журналов соревнований: название из 1–30 латинских букв,
цифр и пробелов, дата DD.MM.YY, число задач p ≤ 13 и посылок s ≤ 100,
затем s посылок — буква задачи и вердикт. Выведите таблицу, нарисованную
символами `+`, `-` и `|`: строка заголовков и по строке на соревнование
с названием, дополненным до 30 символов, датой (8 символов) и 13
отметками, по одной на букву A … M. Отметка — `o`, если задача хоть раз
принята, `x`, если её сдавали, но ни разу не приняли, `.`, если задача
была, но её не сдавали, и пробел, если такой задачи в соревновании не
было. Ограничения: 1 секунда и 64 МБ.

## Входные данные

n, затем для каждого соревнования строка названия, строка даты, строка
«p s» и s строк «буква вердикт». Вердикт — один из `Accepted`,
`Wrong Answer`, `Runtime Error`, `Time Limit Exceeded`,
`Memory Limit Exceeded`, `Compilation Error`.

## Выходные данные

Таблица, оформленная как в примере, с линией границы перед заголовком,
после него и после каждого соревнования.

## Примеры

### Пример 1

Ввод:

```
2
Codeforces Gamma Round 512
29.02.16
5 4
A Accepted
B Accepted
C Accepted
E Accepted
URKOP
17.10.15
12 11
A Accepted
B Wrong Answer
B Time Limit Exceeded
J Accepted
B Accepted
J Time Limit Exceeded
J Accepted
F Accepted
E Runtime Error
H Accepted
E Runtime Error
```

Вывод:

```
+------------------------------+--------+-------------+
|Contest name                  |Date    |ABCDEFGHIJKLM|
+------------------------------+--------+-------------+
|Codeforces Gamma Round 512    |29.02.16|ooo.o        |
+------------------------------+--------+-------------+
|URKOP                         |17.10.15|oo..xo.o.o.. |
+------------------------------+--------+-------------+
```

## Решение

Каждое соревнование начинается с p точек и 13 − p пробелов. Посылка
ставит своей задаче `o`, если вердикт `Accepted`; любой другой вердикт
ставит `x`, если отметка ещё не `o`. Затем строки выводятся с названием,
дополненным пробелами до 30 символов. Всё линейно по размеру входа.

В названиях бывают пробелы, поэтому вход читается построчно, а пробелы
и возвраты каретки в конце строк отбрасываются (название не кончается
пробелом). Отметки сохраняют свои пробелы в конце: в примере вторая
строка заканчивается на `.. ` перед границей.
