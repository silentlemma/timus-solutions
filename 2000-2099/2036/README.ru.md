# 2036. Конечное замыкание пересечениями прямых

[Timus 2036](https://acm.timus.ru/problem.aspx?space=1&num=2036) · сложность 1706 · geometry

Автор оригинальной задачи — Михаил Рубинчик; Ural FU Dandelion contest. Petrozavodsk training camp. Summer 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны `n` различных точек. На каждой итерации проводятся прямые через все
пары текущих точек, затем пересекаются все пары различных непараллельных
прямых. Полученные точки добавляются к множеству. Процесс повторяется,
пока множество растёт. Найдите окончательное число точек либо установите,
что рост бесконечен. Лимиты: 0,5 секунды и 64 МБ.

## Входные данные

Число `1 ≤ n ≤ 100000` и `n` строк с целыми координатами `x y`,
где `|x|,|y| ≤ 100000000`. Все точки различны. Набор один, без числа тестов.
Ограничения относятся к исходным точкам; новые пересечения могут иметь
дробные координаты и находиться за указанными границами.

## Выходные данные

Конечное количество точек либо `oo` — две строчные латинские буквы,
если процесс бесконечен.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
4
0 0
0 1
1 0
1 1
```

```
5
```

## Решение

Назовём множество замкнутым, если итерация ничего не добавляет.
Коллинеарное множество замкнуто. Замкнута и конфигурация, где все точки,
кроме одной, лежат на прямой: остальные определяемые прямые соединяют
эту единственную внешнюю точку с точками основания, и все их конечные
пересечения уже существуют. Ещё один вариант — четыре вершины
параллелограмма вместе с пересечением диагоналей.

### Доказательство полноты классификации

В конечном неколлинеарном замкнутом множестве выберем треугольник `ABC`
минимальной положительной площади. Внутри открытого отрезка любой его
стороны нет точки множества: вместе с противоположной вершиной она дала
бы меньшую положительную площадь. Все точки лежат на трёх прямых сторон,
включая продолжения. Иначе у точки все три барицентрические координаты
ненулевые, а две имеют одинаковый знак. Прямая через эту точку и оставшуюся
вершину пересекает открытый отрезок противоположной стороны. Замкнутость
даёт запрещённую точку. Два отрицательных коэффициента работают так же.

Невырожденным аффинным преобразованием положим
`A=(0,0), B=(1,0), C=(0,1)`. Если дополнительные точки есть на двух
сторонах, переименуем вершины и запишем `D=(t,0), E=(0,u)`,
где `t,u` вне `[0,1]`. При `tu≠1` прямые `DC` и `EB` пересекаются в
`(t(u−1)/(tu−1), u(t−1)/(tu−1))`. Обе координаты ненулевые, а сумма не
равна единице, поскольку `(t−1)(u−1)≠0`. Это точка вне всех трёх прямых
сторон, что невозможно. Значит, `tu=1`, а ограничения на параметры
заставляют оба быть отрицательными.

Если `DE` пересекает `BC`, получаем дополнительную точку `F` вне открытого
отрезка `BC`. Применим тот же аргумент у вершины `B` к `D` на `BA` и
`F` на `BC`. Параметр первой точки равен `1−t>1`, хотя оба должны быть
отрицательными. Поэтому `DE` параллельна `BC`, то есть `t=u`, откуда
`t=u=−1`. Получены четыре вершины параллелограмма `B,C,D,E` и центр `A`.
Другой точки на `AB` или `AC` быть не может из-за равенства `tu=1`
с уже существующей точкой другой стороны. Точка на `BC` снова нарушит
аргумент у `B`. За пределами трёх прямых точек уже нет.

Если дополнительные точки есть только на одной стороне, все точки,
кроме противоположной вершины, коллинеарны. Классификация доказана.
Обратно, параллелограмм с центром замкнут: определяются только четыре
прямые сторон и две диагонали, чьи конечные пересечения — вершины и центр.

### Проверка исходного множества

При `n≤3` ответ равен `n`. Иначе проверим три прямые через пары первых
трёх точек. Если вне одной из них не более одной точки, ответ также `n`.
Так находится любое множество этого вида: хотя бы две из первых трёх
точек принадлежат прямой основания.

После неудачи этих проверок конечное замыкание может быть лишь
исключительной конфигурацией из пяти точек. При `n>5` ответ `oo`.
При `n=4` нужны четыре вершины параллелограмма; центр добавит пятую точку.
Четырёхточечный набор из центра и трёх вершин содержит три коллинеарные
точки и уже был бы обработан. При `n=5` исходное множество должно состоять
из четырёх вершин и настоящего центра.

Для четырёх точек перебираем три разбиения на пары концов диагоналей:
координатные суммы в парах должны совпадать. Для пяти перебираем центр,
проверяем параллелограмм на остальных четырёх и равенство их суммы
четырём центрам по каждой координате. В остальных случаях конечное
замкнутое надмножество невозможно, поэтому рост бесконечен.

В примере вершины квадрата дают центр `(1/2,1/2)`. После его добавления
множество из пяти точек замкнуто, ответ `5`. Целочисленность исходных
координат не означает целочисленность пересечений.

Три прохода занимают `O(n)` времени; проверки четырёх и пяти точек
постоянны. Хранение входа требует `O(n)` памяти, дополнительная
геометрическая память — `O(1)`.

Подводные камни:

- Множество с одной внешней точкой может быть сколь угодно большим в
  пределах входа.
- Трапеция лишь с одной парой параллельных сторон не подходит.
- В пятиточечном случае нужна именно точка пересечения диагоналей.
- Пересекаются целые прямые, а не только исходные отрезки.
- Выводите буквы `oo`, не цифры `00`; предел числа итераций не
  доказывает бесконечность.

## Особенности языков

В C++, Go, Java и Rust используем знаковые 64-битные координаты уже до
умножения; Python считает точно. Разность координат не больше `2·10^8`,
определитель по модулю не больше `8·10^16`. Суммы концов диагоналей
избавляют от деления и учитывают полуцелые центры. В Java используются
массивы примитивных координат; Python сразу строит кортежи точек,
не сохраняя второй список всех преобразованных целых.
