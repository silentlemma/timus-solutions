# 2036. 直线交点的有限闭包

[Timus 2036](https://acm.timus.ru/problem.aspx?space=1&num=2036) · 难度 1705 · geometry

原题作者 Mikhail Rubinchik，出自 2014 年夏季彼得罗扎沃茨克集训营乌拉尔联邦大学 Dandelion 专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

从 `n` 个互不相同的点开始。每轮连接当前每对不同点确定直线，
求每对不同且不平行的直线交点，把所有交点加入集合；只要集合增加就继续。
求最终点数，或判断过程无限。时间限制 0.5 秒，内存 64 MB。

## 输入

一个整数 `1 ≤ n ≤ 100000`，随后 `n` 行整数坐标 `x y`，
满足 `|x|,|y| ≤ 100000000`。所有点不同，只有一个实例，无测试数前缀。
坐标界限只限制初始点；新交点可能是分数，也可能超出原范围。

## 输出

最终点数；若无限增长，输出两个小写拉丁字母 `oo`。

## 评测方式

按记号逐个比较输出。

## 样例

```
4
0 0
0 1
1 0
1 1
```

```
5
```

## 解法

称一轮不增加点的集合为闭集。共线集合已经封闭。
除至多一个点外其余共线的集合也封闭：其余确定的直线都是外部点到基线上点的连线，
有限交点均已存在。另一种有限封闭形状是平行四边形的四个顶点加两对角线的中心。

### 分类为什么完整

在有限非共线闭集中选择正面积最小的三角形 `ABC`。
任何边的开线段内都没有集合中的点，否则该点与对面顶点形成更小的正面积三角形。
所有点都位于三条边的延长直线上。若某点不在这三条线上，其三个重心坐标均非零，
其中至少两个同号。它与余下顶点的连线和对边开线段相交；闭包产生禁止存在的点。
两个坐标都为负数时同样成立。

通过可逆仿射变换设 `A=(0,0), B=(1,0), C=(0,1)`。
若两条边线上都有额外点，可重命名顶点，写为 `D=(t,0), E=(0,u)`，
其中 `t,u` 都不在 `[0,1]` 内。若 `tu≠1`，`DC` 与 `EB` 的交点为
`(t(u−1)/(tu−1), u(t−1)/(tu−1))`。
两坐标非零，且因 `(t−1)(u−1)≠0`，坐标和不等于一。
该交点不在三条边线上，矛盾。因此 `tu=1`；结合参数范围，两者都必须为负。

若 `DE` 和 `BC` 相交，交点 `F` 是 `BC` 开线段以外的额外点。
在顶点 `B` 对 `BA` 上的 `D` 和 `BC` 上的 `F` 应用相同两边论证。
第一个参数为 `1−t>1`，但两个参数应都为负，矛盾。
故 `DE` 平行 `BC`，得到 `t=u`，再由乘积及符号得 `t=u=−1`。
这五个点正是四边形 `B,C,D,E` 的四个顶点及中心 `A`。
`AB` 或 `AC` 上的另一点会与另一边已有点违反 `tu=1`；
`BC` 上的另一点再次违反顶点 `B` 的论证。因此没有更多点。

若额外点仅在一条边线上，除对面顶点外其余全部共线。
至此分类完成。反过来，四个平行四边形顶点加中心确实封闭：
确定的直线只有四条边线和两条对角线，有限交点仅为顶点或中心。

### 对初始集合的判断

`n≤3` 时已经封闭，输出 `n`。否则测试前三个点的三对连线，
若某条线上之外至多一个点，仍输出 `n`。
这不会漏掉此类形状，因为前三点中至少两个位于其基线上。

前述测试失败后，有限闭包只能是特殊五点集，故 `n>5` 时输出 `oo`。
`n=4` 时必须是平行四边形四顶点，加入中心得到五点。
若四点是中心和三个顶点，其中必有一对相对顶点与中心共线，
会被前面的测试处理。`n=5` 时必须已是四顶点加真实中心。

四点可分成三种对角线端点配对，两对端点的坐标和相等即为平行四边形。
五点则枚举中心，其他四点满足上述条件，且四点坐标和等于中心坐标的四倍。
其余输入不可能包含在任何有限闭集中，因此无限增长。

样例四个正方形顶点的对角线新增 `(1/2,1/2)`，随后五点集封闭，
故输出 `5`。初始坐标为整数并不要求中心为整数。
三次线性扫描耗时 `O(n)`，四点、五点判断耗时常数。
保存输入占 `O(n)` 空间，额外几何工作空间为 `O(1)`。

注意事项：

- 除一个点以外共线的输入可以有很多点，不能仅因点数大而判无限。
- 只有一对平行边的梯形不是特殊情形。
- 第五点必须是真实对角线中心。
- 相交的是完整直线而非线段，交点可以在外部。
- 输出字母 `oo`，不是数字 `00`；迭代次数截断不能证明无限。

## 各语言说明

C++、Go、Java、Rust 在乘法前就使用有符号 64 位坐标，Python 用精确整数。
坐标差不超过 `2·10^8`，行列式绝对值不超过 `8·10^16`。
端点和比较不需要除法，也能处理半整数中心。
Java 保存基本类型坐标数组；Python 直接构造点元组，不另外保存全部已转换整数列表。
