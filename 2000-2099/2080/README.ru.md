# 2080. Карты в порядке следующего использования

[Timus 2080](https://acm.timus.ru/problem.aspx?space=1&num=2080) · сложность 746 · fenwick

Автор оригинальной задачи — Евгений Курпилянский; подготовка — Михаил Вяцков.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n карт лежат стопкой, и их используют k раз в известном порядке: каждый
раз нужная карта должна быть сверху, а после использования её можно
вернуть на любую глубину. Выведите начальный порядок стопки и для каждого
использования число карт, которые окажутся над картой, когда её вернут.
Подходит любой правильный ответ. Ограничения: 2 секунды и 256 МБ.

## Входные данные

n и k, 1 ≤ n, k ≤ 10⁵, затем k номеров карт в порядке использования.

## Выходные данные

Начальная стопка сверху вниз, затем k строк с числом карт над каждой
использованной картой после её возвращения.

## Проверка

Проверяющая программа воспроизводит использования: каждая карта должна
быть сверху, когда она нужна, а глубина возврата не должна превышать n − 1.

## Примеры

### Пример 1

Ввод:

```
3 5
3 1 2 2 1
```

Вывод:

```
3 1 2
2
1
0
1
0
```

## Решение

Будем держать стопку отсортированной по времени следующего
использования, а карты, которые больше не понадобятся, — внизу. Тогда
сверху всегда лежит следующая нужная карта. В начале это порядок первого
использования, за которым идут неиспользуемые карты. После использования
в момент i следующее использование карты — в момент j (или никогда), и
она должна лечь ровно под карты, чьё следующее использование раньше j.
Каждая такая карта используется где-то между i и j, и у каждой карты,
используемой там, следующее использование раньше j, так что их число —
количество различных карт среди использований i + 1 … j − 1 (или до k,
если карта больше не понадобится).

Различные значения на отрезках считаются офлайн деревом Фенвика по
моментам. Момент t > i — первое после i использование своей карты ровно
тогда, когда предыдущее использование этой карты не позже i. Поэтому
запросы идут по возрастанию i, а момент t добавляется в дерево, как
только i доходит до предыдущего использования его карты (моменты,
которые вообще первые для своей карты, добавляются сразу). Ответ для i —
число добавленных моментов в (i, j). Проход Фенвика — O((n + k) log k);
оценки ниже учитывают и построение начального порядка.

В примере карта 1 используется в моменты 2 и 5, а между ними — только
карта 2, поэтому после момента 2 она возвращается под одну карту.
