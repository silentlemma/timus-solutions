# 2080. 按下次使用时间排列卡片

[Timus 2080](https://acm.timus.ru/problem.aspx?space=1&num=2080) · 难度 746 · fenwick

原题作者 Eugene Kurpilyansky（由 Mikhail Vyatskov 整理）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 张卡片叠成一摞，将按已知顺序使用 k 次：每次要用的卡片必须在最上面，用完后可以放回任意深度。给出这摞卡片的初始顺序，以及每次使用后放回时其上方的卡片数。任何正确答案都可接受。时间限制 2 秒，内存限制 256 MB。

## 输入

n 和 k（1 ≤ n, k ≤ 10⁵），然后按使用顺序给出 k 个卡片编号。

## 输出

自上而下的初始顺序，然后 k 行，每行是每张用过的卡片放回后其上方的卡片数。

## 评测方式

检查器重放使用过程：每张卡片在需要时必须在最上面，且每次放回的深度都不超过 n − 1。

## 样例

### 样例 1

输入：

```
3 5
3 1 2 2 1
```

输出：

```
3 1 2
2
1
0
1
0
```

## 解法

让这摞卡片始终按下次使用时间排序，不再使用的卡片放在底部。这样最上面总是下一张要用的卡片。开始时就是首次使用的顺序，后面跟着从未使用的卡片。在时刻 i 使用后，这张卡片下次使用在时刻 j（或不再使用），它必须恰好放在下次使用早于 j 的那些卡片下面。每张这样的卡片都会在 i 与 j 之间使用，而在其间使用的每张卡片下次使用都早于 j，所以它们的数量就是第 i + 1 … j − 1 次使用中不同卡片的个数（若该卡片不再使用，则到 k 为止）。

区间内不同值的个数用按时刻建立的树状数组离线统计。时刻 t > i 是其卡片在 i 之后的首次使用，当且仅当该卡片的上一次使用不晚于 i。所以按 i 递增处理询问，当 i 到达时刻 t 的卡片的上一次使用时，就把 t 加入树中（本身就是首次使用的时刻在开始时加入）。i 的答案就是 (i, j) 中已加入的时刻数。树状数组扫描为 O((n + k) log k)，下表还计入了初始顺序的构造。

样例中卡片 1 在时刻 2 和 5 使用，其间只用了卡片 2，所以在时刻 2 之后它放回到一张卡片下面。
