# 2035. Разложение суммы с двумя верхними границами

[Timus 2035](https://acm.timus.ru/problem.aspx?space=1&num=2035) · сложность 78 · math

Автор оригинальной задачи — Кирилл Бороздин; Уральская региональная командная олимпиада по программированию 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

По целым `X,Y,C`, где `0 ≤ X,Y,C ≤ 1000000000`, найти любые целые
`A,B` с условиями `0 ≤ A ≤ X`, `0 ≤ B ≤ Y` и `A+B=C`.
Лимиты: 0,5 секунды, 64 МБ.

## Входные данные

Одна строка `X Y C`. Перед единственным набором нет количества тестов.

## Выходные данные

Любая подходящая пара `A B` либо слово `Impossible`, если пары нет.
При `C=0` пара `0 0` допустима.

## Проверка

Проверяющая программа сверяет обе границы и сумму; `Impossible`
принимается, только если пары нет. Принимается любая подходящая пара.

## Примеры

```
2 7 5
```

```
2 3
```

```
9 15 100
```

```
Impossible
```

## Решение

Возьмём `A=min(X,C)`, затем `B=C-A`. Если `B≤Y`, выведем пару,
иначе — `Impossible`.

Число `A` неотрицательно и не превосходит ни `X`, ни `C`. Поэтому `B≥0`,
а сумма равна `C` по построению. Проверка `B≤Y` даёт оставшееся ограничение.

Для полноты заметим: любое допустимое первое слагаемое не больше `X`
и не больше `C`, значит, не больше выбранного нами. Его второе слагаемое
будет не меньше нашего `B`. Построение минимизирует необходимое второе
слагаемое: если даже оно превышает `Y`, подходящей пары не существует.
Таким образом, корректен и отказ.

Все решения также описываются интервалом
`max(0,C-Y) ≤ A ≤ min(X,C)` с `B=C-A`. При данных неотрицательных
границах он непуст тогда и только тогда, когда `C≤X+Y`.

В первом примере `A=2` даёт `B=3` в пределах семи. Пары `0 5` и `1 4`
тоже подходят. Во втором максимальная сумма `9+15=24` меньше `100`,
поэтому ответ невозможен.

Время и рабочая память — `O(1)`: достаточно сравнения, вычитания и
проверки границы.

Подводные камни:

- Все границы неотрицательны и включены.
- Если брать `A=X` без ограничения величиной `C`, второе слагаемое может
  стать отрицательным.
- Нулевые слагаемые и нулевая пара допустимы.
- Подходит любая допустимая пара, не только образец.
- В слове `Impossible` важны написание и регистр.

## Особенности языков

C++ и Java используют знаковые 64-битные числа, Go — `int64`, Rust —
`u64`, Python — точные целые. Вычитание Rust безопасно из-за `A≤C`. Даже
`X+Y≤2000000000` помещается в знаковые 32 бита; более широкий тип просто
упрощает арифметику. Нулевая пара отделена от признака отсутствия
решения.
