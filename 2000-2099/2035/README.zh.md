# 2035. 在两个上界内拆分总和

[Timus 2035](https://acm.timus.ru/problem.aspx?space=1&num=2035) · 难度 78 · math

原题作者 Kirill Borozdin，出自 2014 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定整数 `X,Y,C`，满足 `0 ≤ X,Y,C ≤ 1000000000`，找任意整数 `A,B`，
使 `0 ≤ A ≤ X`、`0 ≤ B ≤ Y`、`A+B=C`。时间 0.5 秒，内存 64 MB。

## 输入

一行 `X Y C`，仅一个实例，无测试数前缀。

## 输出

任意合法 `A B`，无解则精确输出 `Impossible`。`C=0` 时 `0 0` 合法。

## 评测方式

检查器核对两个范围和总和；只有不存在这样的一对时才接受 `Impossible`。任何合法的一对都被接受。

## 样例

```
2 7 5
```

```
2 3
```

```
9 15 100
```

```
Impossible
```

## 解法

取 `A=min(X,C)`，令 `B=C-A`。`B≤Y` 时输出，否则无解。
`A` 非负且不超过 `X` 和 `C`，所以 `B≥0`，构造直接保证和为 `C`；
检查第二个上界即可满足全部条件。

为证明完整性，任意合法第一个加数都同时不超过 `X`、`C`，因此不超过我们的选择；
其第二个加数便不小于我们的 `B`。构造最小化必要的第二加数，如果这个最小值仍大于 `Y`，
任何方案都失败，故无解判断正确。

等价地，全部解由 `max(0,C-Y) ≤ A ≤ min(X,C)`、`B=C-A` 给出。
在非负输入下，区间非空恰好等价于 `C≤X+Y`。

首例取 `A=2`，得到界内的 `B=3`，而 `0 5`、`1 4` 也合法。
第二例最大总和 `9+15=24` 小于 `100`，所以无解。
只需比较、减法和界检查，时间和工作空间均为 `O(1)`。

注意事项：

- 输入界限非负且包含端点。
- 直接取 `A=X` 而不以 `C` 截断可能得到负的 `B`。
- 零加数和全零对都合法。
- 任意合法对均可，不只样例。
- `Impossible` 的拼写与大小写必须正确。

## 各语言说明

C++、Java 用有符号 64 位，Go 用 `int64`，Rust 用 `u64`，Python 用精确整数。
`A≤C` 保证 Rust 无符号减法安全。`X+Y≤2000000000` 本身也可放入有符号 32 位；
宽类型只是让运算直接。每个实现都区分合法零对与无解。
