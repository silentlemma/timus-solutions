# 2035. 在两个上界内拆分总和

[Timus 2035](https://acm.timus.ru/problem.aspx?space=1&num=2035) · 难度 78 · math

原题作者 Kirill Borozdin，出自 2014 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定整数 `X,Y,C`，满足 `0 ≤ X,Y,C ≤ 1000000000`，找任意整数 `A,B`，
使 `0 ≤ A ≤ X`、`0 ≤ B ≤ Y`、`A+B=C`。时间 0.5 秒，内存 64 MB。

## 输入

一行 `X Y C`，仅一个实例，无测试数前缀。

## 输出

任意合法 `A B`，无解则精确输出 `Impossible`。`C=0` 时 `0 0` 合法。

## 评测方式

检查器核对两个范围和总和；只有不存在这样的一对时才接受 `Impossible`。任何合法的一对都被接受。

## 样例

```
2 7 5
```

```
2 3
```

```
9 15 100
```

```
Impossible
```

## 解法

让 A 尽量大，A = min(X, C)，B = C − A。若 B ≤ Y，这一对可行；否则任何一对都不行，
因为其他的 A 都更小，只会让 B 更大。`O(1)`。

注意事项：

- 只取 A = X 可能超过 C，使 B 变成负数；
- 允许加数为零，任何合法的一对都会被接受。

## 优化解法

优化的 C++ 解法用 `getchar` 手工解析这三个数，而不是用 `iostream`：100 KB，而不
是 400 KB，时间不变。

没有特别需要注意的地方。
