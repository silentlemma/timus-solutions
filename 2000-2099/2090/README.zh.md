# 2090. 人行横道还是红绿灯：各自何时更快

[Timus 2090](https://acm.timus.ru/problem.aspx?space=1&num=2090) · 难度 4817 · math, probability

原题作者 Egor Shchelkonogov，出自 2014 年乌拉尔联邦大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

行人以速度 v 沿马克思街走向它与恩格斯街的路口，要到达对角。一种走法是在路口前 d 处的人行横道（无信号灯）穿过马克思街，再在红绿灯处穿过恩格斯街；另一种是在红绿灯处按任意顺序穿过两条街。信号灯对穿恩格斯街的行人亮绿灯 t₁、黄灯 t₂，然后对穿马克思街的行人亮绿灯 t₃、黄灯 t₄，循环往复；只在绿灯时才踏上街道。开始时的相位均匀随机。求人行横道严格更快的概率和红绿灯严格更快的概率。时间限制 1 秒，内存限制 64 MB。

## 输入

v，然后是 d、w₁（恩格斯街宽）和 w₂（马克思街宽），然后是 t₁ … t₄；均在 1 到 10⁶ 之间，且 w₁ ≤ v t₂、w₂ ≤ v t₄。

## 输出

两个概率，绝对误差不超过 10⁻⁹。

## 样例

### 样例 1

输入：

```
1
10 1 1
4 1 4 1
```

输出：

```
0.4 0.1
```

## 解法

两种走法沿马克思街走的距离 d 相同；横道走法还要先穿过马克思街，所以它到达远角比另一种走法到达近角晚 w₂/v，然后等恩格斯街的绿灯。设 θ 为红绿灯走法到达路口时的相位。

- θ 在恩格斯绿灯 [0, t₁) 内：红绿灯走法立即穿过恩格斯街，然后等到 t₁ + t₂ 的马克思绿灯。横道走法在 θ + w₂/v 到达远角；若此时仍在绿灯内就先到（穿过恩格斯街至多需要 t₂），否则要等整整一个周期而落后。所以横道在 [0, t₁ − w₂/v) 上更快，红绿灯在绿灯最后的 w₂/v 上更快。
- θ 在马克思黄灯（长 t₄）内：红绿灯走法两条街都不能走，要等恩格斯绿灯，再等很久的马克思绿灯，而横道走法不晚于下一个恩格斯绿灯到达；横道更快。
- θ 在恩格斯黄灯或马克思绿灯内：两种走法在同一个绿灯中穿过恩格斯街，打平。

所以两个概率为 (v (t₁ + t₄) − w₂) / (v T) 和 w₂ / (v T)，其中 T = t₁ + t₂ + t₃ + t₄。它们是有理数，因此用精确的整数长除法输出，四舍五入到 12 位小数并去掉末尾的零。

样例中 v = 1，w₂ = 1，T = 10：横道更快的概率为 (4 + 1 − 1) / 10 = 0.4，红绿灯为 1/10 = 0.1。
