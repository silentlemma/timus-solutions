# 2062. 按约数累积辐射

[Timus 2062](https://acm.timus.ru/problem.aspx?space=1&num=2062) · 难度 295 · fenwick

原题作者 Alexey Danilyuk（由 Nikita Sivukhin 整理），出自 2015 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一条链上有 n 个粒子，初始电荷为 a[i]。向粒子 k 施加功率 d 会使编号是 k 的倍数的每个粒子增加 d。操作 `2 l r d` 对 l 到 r 的每个粒子分别施加功率 d，因此被其中多个粒子覆盖到的粒子会得到多次增加；操作 `1 i` 询问粒子 i 当前的电荷。时间限制 3 秒，内存限制 128 MB。

## 输入

先是 n，然后是 n 个电荷 a[i]，再是 q 和 q 个操作。1 ≤ n, q ≤ 300 000，0 ≤ a[i], d ≤ 10⁶，1 ≤ i ≤ n，1 ≤ l ≤ r ≤ n。

## 输出

按顺序输出各询问的答案，每行一个。

## 评测方式

按记号逐个比较输出。

## 样例

每个输入块之后紧接对应输出。

```
3
1 2 3
2
2 1 3 5
1 2
```

```
12
```

```
6
1 2 1 4 5 6
5
2 2 4 2
1 3
1 4
2 3 5 1
1 5
```

```
3
8
6
```

第一组中，对 `[1,3]` 施加强度五，粒子二会同时收到源一和源二的贡献，因此答案为 `2+5+5=12`。初始电荷本身并不是辐射源。

第二组第一次更新使 `[2,4]` 中各源的累计强度为二。粒子三只收到源三，得到 `1+2=3`；粒子四收到源二和源四，得到 `4+2+2=8`。随后更新 `[3,5]` 给源五增加一，因此粒子五变为 `5+1=6`。

## 解法

### 区分源强度与实际电荷

令 `v[k]` 为向源 `k` 施加的累计强度，初值为零。更新只需对 `v[l..r]` 加 `d`。源 `k` 到达粒子 `i` 的充要条件是 `k` 整除 `i`，故电荷恒等于 `a[i]+sum(v[k] : k divides i)`。单次辐射直接满足该式，线性相加保证每次操作后仍成立。不同约数代表不同源，波相遇并不会抵消或合并贡献。

### 用树状数组维护区间加

将 `v` 的差分序列放入树状数组。闭区间加 `d` 转化为位置 `l` 加 `d`，以及存在时位置 `r+1` 减 `d`。直到 `k` 的差分前缀和就是 `v[k]`：两个边界增量恰好只在区间内留下 `d`。树状数组的更新、查询路径正确覆盖对应区间，各需 `O(log n)`。测量时对所有约数求这些前缀和，再加上粒子自身不变的初始电荷。由前述电荷不变量可知输出正确。

### 以紧凑 CSR 存储约数对

每个约数属于一对 `(d,i/d)`，较小者满足 `d²≤i`。仅预处理这些较小者：对所有 `d²≤n` 的 `d`，枚举 `d²,d²+d,…≤n`。这些恰好是以 `d` 为较小约数的倍数。第一次筛统计每个编号的条目数，前缀和得到平坦数组的偏移，第二次筛填入各切片。查询 `i` 时遍历其切片，对每一对查询两项，相等时只查一次。较小项唯一确定约数对，因此所有正约数，包括一和 `i`，均恰好计入一次。完全平方数必须去掉重复的平方根。

每个小约数最多 `floor(sqrt(300000))=547`，可存于 16 位整数，Java 有符号 short 也足够。条目数至多 `n·547=164100000<2³¹`，故 32 位有符号偏移足够；分配时使用实际计数。精确条目数为 `S=sum(floor(n/d)−d+1,1≤d≤floor(sqrt(n)))`，调和级数给出 `O(n log n)` 的预处理和存储上界，避免给每个粒子建立装箱整数列表。

不能对初始电荷求约数和；更新的是源强度。右端点包含在内，因此负增量位于 `r+1`，若 `r=n` 则省略树外操作。索引从一开始，零位置更新不会前进。不要重复计算平方根、用 32 位截断答案、漏掉源一，或为更新输出答案。重复查询、零强度都合法。

## 各语言说明

电荷与树状数组单元均为有符号 64 位。安全的宽松上界是 `1000000+q·n·1000000≤90000000001000000<2⁶³`，因为一次操作最多有 `n` 个源。差分值可能为负，即使实际累计强度非负。索引及 `d²` 仍能用 32 位表示。

预处理时间、空间为 `O(n log n)`。若有 `u` 次更新，测量编号为 `i₁,…,iₘ`，总时间为 `O(n log n+u log n+sum(τ(iⱼ) log n))`，其中 `τ(i)` 是约数个数。单次更新为 `O(log n)`，单次测量为 `O(τ(i) log n)`，并非常数。五种实现使用相同约数对切片。C++、Go、Java、Rust 使用原始数组或向量及缓冲输入输出。Python 用 16 位约数、32 位偏移、64 位初始电荷与树状数组，逐行读入，每 1024 个答案输出一次。Python 解答在 PyPy 上运行，因为 CPython 在最大的测试上太慢。
