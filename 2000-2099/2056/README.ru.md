# 2056. Определить вид стипендии

[Timus 2056](https://acm.timus.ru/problem.aspx?space=1&num=2056) · difficulty 41 · implementation

Задача из фольклора; XIX Открытый чемпионат Урала по спортивному программированию (апрель, 2015).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Студент сдал n экзаменов с оценками от 3 до 5. Определите стипендию:
`None`, если есть хотя бы одна 3, иначе `Named`, если все оценки 5,
иначе `High`, если средний балл не меньше 4.5, и `Common` во всех
остальных случаях. Ограничения: 1 секунда и 64 МБ.

## Входные данные

Число экзаменов n, 1 ≤ n ≤ 10, и затем n строк по одной оценке.

## Выходные данные

Одно слово с учётом регистра.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
3
5
5
4
```

```
High
```

```
3
3
3
3
```

```
None
```

В первом примере сумма равна четырнадцати, и `2·14≥9·3`, поэтому среднее
выше 4,5. Троек нет, но есть четвёрка, следовательно ответ `High`. Во
втором примере присутствуют тройки; первое правило сразу определяет
`None`.

## Решение

Просматриваем оценки, поддерживая сумму `S` и минимум `q`, первоначально
ноль и пять. После любого префикса это ровно его сумма и минимум: новую
оценку прибавляем к сумме и сравниваем с минимумом. После всех `n`
оценок равенство `q=3` означает наличие тройки и только его. Тогда
выводим `None`, не рассматривая среднее.

Иначе `q=5` равносильно тому, что все оценки — пятёрки, поскольку
больших допустимых значений нет; выводим `Named`. Если обе проверки не
сработали, имеются только четвёрки и пятёрки, причём хотя бы одна
четвёрка. Условие `S/n≥4.5` при `n>0` равносильно целочисленному
`2S≥9n`. При его выполнении выводим `High`, иначе `Common`. Эти проверки
в точности реализуют четыре правила в нужном порядке, взаимно исключают
друг друга и покрывают все случаи, что доказывает корректность.

Тройка отменяет стипендию даже при большом среднем. Только пятёрки дают
`Named`, а не `High`. Граница среднего включается: четвёрка и пятёрка
дают `High`. Нельзя усекать среднее целочисленным делением. Для
единственного экзамена тройка, четвёрка и пятёрка дают соответственно
`None`, `Common`, `Named`. Важен регистр ответа.

## Особенности языков

Один проход занимает `O(n)` времени и `O(1)` рабочих данных. Python и
Rust дополнительно сохраняют `O(n)` текста или токенов ввода; остальные
версии читают буферизованным потоком. Арифметика целая и точная: `S≤50`,
`2S≤100`, `9n≤90`. Все версии используют те же три статистики; Python
запускается под CPython 3.12. Деление с плавающей точкой не нужно.
