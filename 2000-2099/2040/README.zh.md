# 2040. 每次追加字母后新增的回文值

[Timus 2040](https://acm.timus.ru/problem.aspx?space=1&num=2040) · 难度 861 · strings

原题作者 Mikhail Rubinchik（由 Kirill Borozdin 整理），出自 2014 年夏季彼得罗扎沃茨克集训营乌拉尔联邦大学 Dandelion 专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对单词的每个非空前缀，输出追加最后一个字母时新增了多少种不同的非空回文子串。不同位置的相同字符串只算一个值，不统计出现次数。

## 输入

一个仅含小写 `a`、`b` 的单词，`1≤n≤5000000`。时间限制 0.5 秒，内存限制 100 MB。官方说明保证存在足够快的 C++ 解法，但明确不保证其他语言，包括 Java。

## 输出

按顺序输出恰好 `n` 个数字，不含空格。第 `i` 位为长 `i` 前缀的不同非空回文数量减去长 `i-1` 前缀的数量。首位为 `1`。下面证明每位只能是 `0` 或 `1`。

## 评测方式

按记号逐个比较输出。

## 样例

```
abbbba
```

```
111111
```

依次新增 `a`、`b`、`bb`、`bbb`、`bbbb`、`abbbba`，故六位都是一。并非每个二进制单词都如此：`aababbaa` 输出 `11111110`，最后一个字母没有新增回文值。

## 解法

### 最多新增一个回文

新子串一定以新位置结尾。假设有两个不同的新回文后缀 `U,V` 且 `|U|>|V|`。由于两者均回文，`U` 的回文后缀 `V` 同时也是 `U` 的前缀，此次出现更早结束，与 `V` 新增矛盾。因此最多新增一个值，且只能是最长回文后缀，总共至多 `n` 个非空回文结点。

### 二元回文树

每个结点代表一个回文，存长度、指向最长真回文后缀的后缀链接，以及两个带字母标签的转移：`c` 将 `P` 扩展为 `cPc`。另设长度零与虚拟长度负一的根；虚根产生单字母回文，其自链接终止所有扩展失败的搜索。结点零为虚根，一为空根；转移零表示不存在，真正回文编号从二开始。

保存当前前缀最长回文后缀 `last`。位置 `p` 追加字母 `c` 时，沿链接从 `last` 查找首个结点 `P`，满足 `p-1-length(P)≥0` 且该位置字符为 `c`。虚根必定成功。候选按长度递减，故首个匹配给出新最长后缀 `cPc`。

若转移存在，该值以前出现过，输出零并复用结点。否则新建唯一结点，长度为 `length(P)+2`，登记转移并输出一。新长度一结点链接到空根；更长结点从 `link(P)` 开始作同样搜索，找到的候选的 `c` 转移即新后缀链接。任何真回文后缀的内部都是 `P` 的真回文后缀，因此此过程找到最长者。链接目标已存在，否则本步将新增两个回文，与前证矛盾。

每个回文的内部在追加其最后字母前已经出现。结合 `cPc` 表示唯一性，边恰好识别此前的回文值。由归纳，两个搜索维护正确的最长后缀及后缀链接；新建结点等价于新增不同值，因此输出正确。

### 两类搜索的线性总复杂度

令 `F_i` 为处理 `i` 字母后的最长回文后缀长度，`F_0=0`。第一搜索从 `F_(i-1)` 到 `F_i-2`，每个链接至少减少一，步数不超过 `F_(i-1)+2-F_i`。求和消去中间项，至多 `2n`。

令 `G_i` 为当前最长后缀的最长真回文后缀长度，`G_0=-1`。新最长回文的真后缀 `W` 若长度至少二，其内部是旧前缀的回文后缀。由 `|W|<F_i≤F_(i-1)+2`，该内部比旧最长更短，故 `G_i≤G_(i-1)+2`；长度零或一也满足此式。第二搜索开始长度至多 `G_(i-1)`，结束于 `G_i-2`，代价至多 `G_(i-1)+2-G_i`。不需要搜索的步骤，零代价也小于该非负上界。求和仍为 `O(n)`。二元转移为常数时间，连同结点创建，树总工作为 `O(n)`。

### 表示与资源

C++ 每结点使用四个 32 位字段，而非四个机器字索引。`n=5000000` 时结点缓冲最多 `16(n+2)=80000032` 字节，还须计入输入、输出与运行时。Python 使用四个定宽整数数组，不建立数百万 Python 对象，并直接写出 bytearray，不再完整复制。

Java 每结点四个无符号三字节字段，合计 `12(n+2)` 字节。结点编号与 `length+1` 都小于 `2^23`；长度加一把虚根编码为零。输出复用输入字节：ASCII `a`、`b` 都没有数值四对应的位，新建回文时设置该位，以后比较字符时屏蔽它，整个单词处理完后才原地转成 `0`/`1`。此时不再需要原字符。仅输出原单词范围，不含空白或未使用的缓冲容量。

树、输入和答案占用 O(n) 空间；Java 预留固定的 5 000 002 字节输入缓冲。整个数字串按字节读写，不分别格式化数百万个数。

Python 解答在 PyPy 下运行：在 CPython 3.12 下它在评测的第 9 个测试上超时，而在 PyPy 3.10 下以 0.375 秒、92 MB（限制 100 MB）通过。Go 和 Rust 把单词读入一个固定大小的缓冲区，像其他版本一样在其中标记答案，并把树放在四个 32 位整数数组中，总共约 85 MB；它们的早期版本在评测时无法编译。

统计不同值而非出现次数，排除空回文。仅新边创建贡献一位一，重复出现不贡献。第二搜索从父结点后缀链接开始。虚根的逻辑长度为负一，压缩存储使用显式偏移。避免每字段 64 位索引、整个输入 UTF-16 副本、Python 输出完整复制。全一的小示例不能代替含零和长后缀失败链的测试。
