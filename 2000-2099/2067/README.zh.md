# 2067. 第三点无法加入的点对

[Timus 2067](https://acm.timus.ru/problem.aspx?space=1&num=2067) · 难度 326 · geometry

原题作者 Alexey Danilyuk（由 Alexey Danilyuk 和 Alexander Borzunov 整理），出自 2015 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 n 个不同的点 (sᵢ, rᵢ)。对两点 v、u，记 p(v, u) 为它们之间的距离；对三点，记 p(v, u, w) 为三条两两距离之和的一半。若两个不同的点 v、u 对任意点 w 都满足 p(v, u) ≥ p(v, u, w)，就称它们是最佳点对。求所有最佳点对。时间限制 2 秒，内存限制 64 MB。

## 输入

点数 n（2 ≤ n ≤ 2·10⁵），然后 n 行，每行整数 sᵢ 和 rᵢ（−10⁸ ≤ sᵢ, rᵢ ≤ 10⁸）。没有重合的点。

## 输出

最佳点对的个数，然后每行一对，给出两点按输入顺序的编号。点对之间、对内两个编号的顺序都任意。

## 评测方式

检查器比较点对个数和点对集合，对内两个编号的顺序任意。

## 样例

### 样例 1

输入：

```
2
2 3
7 6
```

输出：

```
1
1 2
```

### 样例 2

输入：

```
3
5 5
2 -4
-4 2
```

输出：

```
0
```

## 解法

把条件乘以 2：p(v, u) ≥ p(v, u, w) 即 p(v, u) ≥ p(v, w) + p(w, u)。三角不等式给出相反的方向，所以只能取等号，而这恰好在 w 位于线段 vu 上时成立（w = v 或 w = u 时自然成立）。因此 v、u 是最佳点对当且仅当所有点都在它们之间的线段上。

若所有点不共线，就没有最佳点对。若共线，候选只有直线上的两个端点，而它们确实满足条件：其余点都在两者之间。两点总是共线，所以 n = 2 时答案是唯一的一对 1 2。

共线性用叉积 (p₂ − p₁) × (pᵢ − p₁) = 0 精确判断，其中各项可达 4·10¹⁶，在 64 位整数范围内。端点是按 s、再按 r 排序时最小和最大的点。整体时间 O(n)。

第二个样例中三点构成三角形，所以答案是 0。

## 各语言说明

乘积需要 64 位整数。
