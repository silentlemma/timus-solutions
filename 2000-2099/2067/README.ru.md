# 2067. Пары, к которым не присоединиться третьему

[Timus 2067](https://acm.timus.ru/problem.aspx?space=1&num=2067) · сложность 326 · geometry

## Задача

Даны n различных точек (sᵢ, rᵢ). Для двух точек v, u обозначим p(v, u)
расстояние между ними, а для трёх точек p(v, u, w) — половину суммы трёх
попарных расстояний. Две различные точки v, u образуют лучшую пару, если
p(v, u) ≥ p(v, u, w) для любой точки w. Найдите все лучшие пары.
Ограничения: 2 секунды и 64 МБ.

## Входные данные

Число точек n, 2 ≤ n ≤ 2·10⁵, затем n строк с целыми sᵢ и rᵢ,
−10⁸ ≤ sᵢ, rᵢ ≤ 10⁸. Совпадающих точек нет.

## Выходные данные

Число лучших пар, затем сами пары по одной в строке — номера точек в
порядке ввода. Пары и номера внутри пары можно выводить в любом порядке.

## Проверка

Проверяющая программа сравнивает число пар и множество пар, номера
внутри пары — в любом порядке.

## Примеры

### Пример 1

Ввод:

```
2
2 3
7 6
```

Вывод:

```
1
1 2
```

### Пример 2

Ввод:

```
3
5 5
2 -4
-4 2
```

Вывод:

```
0
```

## Решение

Умножим условие на 2: p(v, u) ≥ p(v, u, w) означает
p(v, u) ≥ p(v, w) + p(w, u). Неравенство треугольника утверждает
обратное, значит, должно быть равенство, а оно бывает ровно тогда, когда
w лежит на отрезке vu (для w = v и w = u условие выполнено само собой).
Итак, v и u — лучшая пара ровно тогда, когда все точки лежат на отрезке
между ними.

Если точки не лежат на одной прямой, лучших пар нет. Если лежат,
кандидаты — только две крайние точки прямой, и они подходят: все
остальные точки между ними. Две точки всегда на одной прямой, поэтому
при n = 2 ответ — единственная пара 1 2.

Коллинеарность проверяется точно векторным произведением
(p₂ − p₁) × (pᵢ − p₁) = 0, слагаемые которого доходят до 4·10¹⁶ и
помещаются в 64-битные целые. Крайние точки — наименьшая и наибольшая в
порядке по s, затем по r. Всё работает за O(n), кроме сортировки в Python: O(n log n).

Во втором примере три точки образуют треугольник, поэтому ответ 0.
