# 2067. Пары, к которым не присоединиться третьему

[Timus 2067](https://acm.timus.ru/problem.aspx?space=1&num=2067) · сложность 326 · geometry

Автор оригинальной задачи — Алексей Данилюк; подготовка — Алексей Данилюк и Александр Борзунов. Уральская региональная командная олимпиада по программированию 2015.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны n различных точек (sᵢ, rᵢ). Для двух точек v, u обозначим p(v, u)
расстояние между ними, а для трёх точек p(v, u, w) — половину суммы трёх
попарных расстояний. Две различные точки v, u образуют лучшую пару, если
p(v, u) ≥ p(v, u, w) для любой точки w. Найдите все лучшие пары.
Ограничения: 2 секунды и 64 МБ.

## Входные данные

Число точек n, 2 ≤ n ≤ 2·10⁵, затем n строк с целыми sᵢ и rᵢ,
−10⁸ ≤ sᵢ, rᵢ ≤ 10⁸. Совпадающих точек нет.

## Выходные данные

Число лучших пар, затем сами пары по одной в строке — номера точек в
порядке ввода. Пары и номера внутри пары можно выводить в любом порядке.

## Проверка

Проверяющая программа сравнивает число пар и множество пар, номера
внутри пары — в любом порядке.

## Примеры

### Пример 1

Ввод:

```
2
2 3
7 6
```

Вывод:

```
1
1 2
```

### Пример 2

Ввод:

```
3
5 5
2 -4
-4 2
```

Вывод:

```
0
```

## Решение

Умножим условие на 2: p(v, u) ≥ p(v, u, w) означает
p(v, u) ≥ p(v, w) + p(w, u). Неравенство треугольника утверждает
обратное, значит, должно быть равенство, а оно бывает ровно тогда, когда
w лежит на отрезке vu (для w = v и w = u условие выполнено само собой).
Итак, v и u — лучшая пара ровно тогда, когда все точки лежат на отрезке
между ними.

Если точки не лежат на одной прямой, лучших пар нет. Если лежат,
кандидаты — только две крайние точки прямой, и они подходят: все
остальные точки между ними. Две точки всегда на одной прямой, поэтому
при n = 2 ответ — единственная пара 1 2.

Коллинеарность проверяется точно векторным произведением
(p₂ − p₁) × (pᵢ − p₁) = 0, слагаемые которого доходят до 4·10¹⁶ и
помещаются в 64-битные целые. Крайние точки — наименьшая и наибольшая в
порядке по s, затем по r. Всё работает за O(n), кроме сортировки в Python: O(n log n).

Во втором примере три точки образуют треугольник, поэтому ответ 0.

## Оптимизированные решения

`2067_geometry_optimized.py`. Сохраняется условие: лучшая пара существует только когда все различные точки коллинеарны. Первые две гарантированно различные точки задают направление, остальные читаются потоком и проверяются точными целочисленными произведениями. Одновременно сохраняются ID лексикографических минимума и максимума без массивов координат и сортировки. На прямой эти концы образуют единственную лучшую пару. Первая неколлинеарная точка завершает проверку. Время O(n), память O(B) для блоков 4096 байт и ограниченных координат; свобода порядка точек пары сохранена.

По сравнению с `2067_geometry.py`: время 0.421 s → 0.203 s; память 62 116 KB → 6 124 KB.

C++ и Go задают прямую по первым двум точкам и обрабатывают остальные по мере чтения. Ненулевое векторное произведение сразу исключает подходящую пару. Иначе храним индексы точек с минимальным и максимальным x, а для вертикальной прямой — с минимальным и максимальным y. Время O(n), дополнительная память O(1).

Принятые базовые реализации [2067_geometry.java](2067_geometry.java), [2067_geometry.py](2067_geometry.py), [2067_geometry.rs](2067_geometry.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.

## Особенности языков

Новые исходники сравниваются по срезу от 18 ноября 2026 года с другими авторами на текущих компиляторах судьи. Порогов по ID посылки или дате нет. Ничьи делят место, времена меньше 0.015 с при сравнении считаются 0.015 с. Учебные алгоритмы сохранены. Перепроверенные базовые версии используют собственные новые метрики и ID Accepted точного исходника; эти проверки не считаются оптимизациями.

`2067_geometry_optimized.py`: место по времени 1/13, по памяти 3/13 в этой сопоставимой выборке.

Звёздочка означает недостигнутую рейтинговую цель: для C++ нужны первые десять мест либо топ 15% одновременно по обеим метрикам; для остальных семейств — первое место по обеим. Отдельный критерий допуска может выполняться по рейтингу или улучшению, в том числе при снижении времени либо памяти минимум на 30%.
