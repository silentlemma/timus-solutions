# 2003. 两两最大公约数的迭代

[Timus 2003](https://acm.timus.ru/problem.aspx?space=1&num=2003) · 难度 366 · number_theory

原题作者 Kirill Borozdin，出自 2013 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定正整数数组。一步操作将每对不同位置的最大公约数各放入新数组，无序位置对只取一次。即使原值或结果相同，各对仍分别贡献元素。因此长度 `k` 变成 `k(k−1)/2`。求所有元素均为 1 所需的最少步数。

## 输入

首行整数 `n`，`3 ≤ n ≤ 10000`。随后 `n` 行各给一个 1 到 `10^7` 的整数。数之间以空白分隔。时间限制 1 秒，内存 64 MB。

## 输出

输出最少步数；若永远无法完成或最少步数超过 `10^18`，输出小写 `infinity`。初始数组全为 1 时答案为 0。

## 评测方式

按记号逐个比较输出。

## 样例

```
3
1
2
3
```

```
1
```

```
4
2
2
2
2
```

```
infinity
```

第一个样例中每对的最大公约数都为 1，所以一步即可。第二个样例每次生成的元素始终都是 2。

## 解法

固定质数 `p`，设当前有 `c` 个元素能被它整除。新生成的最大公约数含 `p` 当且仅当所选两个位置均含 `p`，故新出现次数为 `c(c−1)/2`。这里数的是位置，不是质因数的指数。

出现次数的变化为 `0→0`、`1→0`、`2→1→0`。3 保持为 3；当 `c≥4` 时有 `c(c−1)/2≥c`，所以出现至少三次的质数永不消失。初始长度至少 3，也保证每次的新数组长度至少 3。

因此某质数整除三个原始元素便证明答案为 `infinity`。否则所有质数最多两步便消失。若有质数出现两次，恰需两步；否则只要原来含大于 1 的数，恰需一步；完全没有质因数则答案为 0。这同时证明可达性与最小性。有限答案不会超过 2，故无需对 `10^18` 作大整数计算。

设最大输入值为 `A`，用小筛求出不超过 `B=floor(sqrt(A))` 的质数。逐个分解输入值，当试除质数的平方大于剩余值时停止。找到一个质因数时只计一次，然后除尽其全部幂；最后大于 1 的剩余值必为质数，也只计一次。用哈希表记录出现次数，第三次出现立即返回 `infinity`。否则返回最大次数，初值为 0。

设 `P` 为不超过 `B` 的质数个数，`F` 为各输入元素不同质因数个数之和。期望时间 `O(B log log(B+2) + nP + n log(A+1))`，包括除法与哈希更新；含输入的空间为 `O(n+B+F)`。哈希界是期望界。这里 `B≤3162`、`P≤446`、`F≤8n`，因为前九个质数的乘积已超过 `10^7`。不保存大小为 `10^7` 的筛或不断增长的最大公约数数组。

每个位置的同一质数只计一次：`[4,8,1]` 仍需两步。整个数组的最大公约数为 1 不保证终止，例如 `[2,2,2,3]` 为无限。反之 `[6,10,15]` 每对都有公因数，却只需两步。相同输入值仍代表不同位置。1 不贡献因数，输出 `infinity` 的大小写必须准确。

## 各语言说明

五种实现均使用小质数试除与稀疏计数。C++、Go、Java 和 Rust 用整数运算确定平方根界，Python 使用 `isqrt`。限制内乘积均适合有符号 32 位整数。Java 使用缓冲输入，Python 一次读取并解析整数。在最大输入上测量完整程序后选择 CPython。
