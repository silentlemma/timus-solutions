# 2038. 顶点在所有最小二分图点覆盖中的归属

[Timus 2038](https://acm.timus.ru/problem.aspx?space=1&num=2038) · 难度 2284 · matching, bitmask

原题作者 Alexey Danilyuk，出自 2014 年夏季彼得罗扎沃茨克集训营乌拉尔联邦大学 Dandelion 专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

考虑二分图的所有最小基数顶点覆盖。覆盖选取一些顶点，使每条边至少有一个端点被选。
某顶点不在任何最小覆盖中则标为 `N`，在所有最小覆盖中则为 `A`，
仅在部分最小覆盖中则为 `E`。时间限制 1 秒，内存 64 MB。

## 输入

一个实例 `n m k`，满足 `1≤n,m≤1000`、`0≤k≤1000000`，随后 `k` 行跨部边 `u v`，
其中 `1≤u≤n`、`1≤v≤m`。两部分独立从一编号，无重复边，因此 `k≤nm`。
无测试数前缀。

## 输出

两行无空格字符串，第一行 `n` 个左部分类，第二行 `m` 个右部分类，均按编号排序。
使用大写 `N,E,A`。这里是最小基数覆盖，不是仅按包含关系极小。

## 评测方式

按记号逐个比较输出。

## 解法

先求任意一个最大匹配，再从未匹配顶点传播强制选择。
两个方向的邻接均用位掩码，避免为百万条边分别分配对象。

### 交替搜索求最大匹配

依次加入左部顶点，保持已处理前缀的最大匹配。
若新顶点有空闲右邻点，直接匹配；否则 BFS：
左点访问尚未看到的右邻点，已匹配右点再访问其匹配左点。
为每个新右点记录来自哪个左点。到达空闲右点即找到增广路，
沿前驱及原匹配反转路径上的匹配关系。

一次搜索每个右点只访问一次。已匹配左点只能通过其唯一匹配右点入队，
因此也至多一次；取出时自身匹配边已经访问。
掩码仅枚举新右点。若右部全部匹配，可停止处理后续左点。

加入一个左点最多使最优值增加一。任何新增广路必须从该新空闲点开始，
它不能成为交替路内部顶点。一次成功达到新最优值，失败则原值仍最优。
增广路判据可由与更大匹配的对称差分解为交替连通分量得到。

### 最小覆盖的固定匹配预算

设匹配大小为 `ν`。不相交的匹配边要求任意覆盖至少取 `ν` 个顶点。
从全部未匹配左点出发，沿左到右邻边及右到左匹配边得到 `D_L,D_R`。
其中没有空闲右点，否则存在增广路。

`(L 中不在 D_L 的点) 与 D_R 的并集` 覆盖全部边：
可达左点的每个右邻点都可达。每对匹配端点同时可达或同时不可达，
所以此覆盖恰好取每对中的一个。未匹配左点被排除，`D_R` 中无未匹配右点。
覆盖大小恰为 `ν`，证明下界可达。
因此任意最小覆盖恰好选每条固定匹配边的一个端点，且不选未匹配顶点。

### 强制顶点与其余选择

未匹配顶点强制不选，为 `N`。强制不选点的全部邻点必须选，为 `A`；
强制选取点的匹配端点必须不选。用两次交替可达搜索传播：

- 从未匹配左点出发：可达左点为 `N`，可达右点为 `A`。
- 从未匹配右点出发：可达右点为 `N`，可达左点为 `A`。

最小覆盖存在，所以这些结论不会冲突。
剩余未标记点都已匹配，且其匹配端点也未标记。
一个覆盖取全部强制 `A` 加全部未标记左点，另一个取全部 `A` 加未标记右点。
接触 `N` 的边已有 `A` 另一端；其余边要么接触 `A`，
要么连接两个未标记端点，由所选一部覆盖。
两覆盖都恰取每条匹配边一个端点，大小均为 `ν`。
每个未标记顶点在一个覆盖中、不在另一个中，故为 `E`。
不需要枚举覆盖或计算强连通分量。

样例中 `L1`、`R7` 必选，`L8…L11`、`R8,R9` 从不选择。
`L2…L7` 和 `R1…R6` 可变化：
`L1…L7` 加 `R7`，以及 `L1` 加 `R1…R7`，
是两个大小为八的最小覆盖，证明这些顶点可选也可不选。

### 复杂度与存储

令 `B=ceil(max(n,m)/w)`，`w` 为机器字位数。
编译语言使用 `w=64`，每行至多十六个字，
时间为 `O(k+n²B+nm+(n+m)B)` 字操作。
Python 的任意精度整数位操作和取最低位也有字数开销；
包含输入更新的保守界为 `O((k+n(n+m))B)`。所有遍历都非递归。

位掩码、匹配与队列空间为 `O((n+m)B+n+m)`。
C++、Java 用缓冲流，Python 每次读一条边。
Go、Rust 保留输入缓冲，在给定数字范围内额外使用 `O(k)` 字节。

注意事项：

- 孤立点为 `N`，无边图只有空的最小覆盖。
- 一个最大匹配足够，但其未匹配点不属于任何最小覆盖。
- 若两部全部被完美匹配覆盖，所有点均为 `E`。
- 两部都要以全部未匹配点为根传播。
- 两部编号分开处理，屏蔽最后一个字中无效位。
- 只对非零字计算末尾零数。

## 各语言说明

C++、Go、Rust 使用无符号 64 位字。Java 使用基本类型 `long` 行数组，
有符号表示不影响位掩码运算。
Python 预先计算单点位，只转换当前行两个整数，不保存百万边的全部 token 列表。
