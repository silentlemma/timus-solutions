# 2038. Принадлежность всем минимальным покрытиям двудольного графа

[Timus 2038](https://acm.timus.ru/problem.aspx?space=1&num=2038) · сложность 2284 · matching, bitmask

Автор оригинальной задачи — Алексей Данилюк; Ural FU Dandelion contest. Petrozavodsk training camp. Summer 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Рассмотрите все вершинные покрытия двудольного графа минимальной мощности.
Покрытие выбирает вершины так, чтобы у каждого ребра был выбран хотя бы
один конец. Для каждой вершины укажите `N`, если она не входит ни в одно
минимальное покрытие, `A`, если входит во все, или `E`, если входит
в некоторые, но не во все. Лимиты: 1 секунда и 64 МБ.

## Входные данные

Один набор `n m k`: `1≤n,m≤1000`, `0≤k≤1000000`, далее `k` рёбер `u v`,
где `1≤u≤n`, `1≤v≤m`. В каждой доле своя нумерация с единицы.
Повторяющихся рёбер нет, поэтому `k≤nm`. Числа тестов перед набором нет.

## Выходные данные

Две строки без пробелов: `n` букв для левой доли и `m` для правой,
по порядку номеров. Буквы `N,E,A` прописные.
Требуется минимум мощности, а не просто минимальность по включению.

## Проверка

Ответы сравниваются по токенам.

## Решение

Найдём одно максимальное паросочетание и распространим вынужденные
решения от непокрытых им вершин. Обе стороны смежности храним битовыми
масками, без отдельного объекта на каждое ребро.

### Поиск максимального паросочетания

Последовательно добавляем вершины левой доли, поддерживая максимум для
обработанного префикса. Если у новой вершины есть свободный правый сосед,
сразу добавляем ребро. Иначе запускаем BFS: из левой вершины идём
в ещё не просмотренных правых соседей, из занятой правой — в её пару слева.
Для каждой правой вершины запоминаем левую, из которой её обнаружили.
Свободная правая завершает увеличивающий путь; по предкам и прежним
парам обращаем принадлежность рёбер паросочетанию.

Каждая правая посещается один раз за поиск. Занятая левая может попасть
в очередь только через единственную занятую ею правую, поэтому тоже один раз.
Её парное ребро уже просмотрено к моменту извлечения.
Маски перечисляют только новых правых соседей.
Если правая доля целиком занята, построение можно завершить.

Добавление одной левой вершины увеличивает оптимум не более чем на один.
Любой новый увеличивающий путь начинается в ней: новая свободная вершина
не может быть внутренней вершиной чередующегося пути.
Успех достигает нового оптимума, неуспех сохраняет прежний.
Критерий увеличивающего пути следует из разложения симметрической разности
с любым большим паросочетанием на чередующиеся компоненты.

### Размер минимума и бюджет пар

Пусть в паросочетании `ν` рёбер. Любое покрытие содержит не менее `ν`
вершин из-за непересекающихся парных рёбер.
Из всех свободных левых вершин идём по рёбрам слева направо и по парным
рёбрам обратно. Обозначим достижимые множества `D_L,D_R`.
Свободная правая недостижима, иначе был бы увеличивающий путь.

Множество `(L вне D_L) вместе с D_R` покрывает каждое ребро:
у достижимой левой вершины достижим каждый правый сосед.
У каждой пары либо достижимы оба конца, либо оба недостижимы,
поэтому покрытие выбирает ровно один конец.
Свободные левые исключены, свободных правых в `D_R` нет.
Получено покрытие размера `ν`, то есть нижняя граница достигается.

Следовательно, любое минимальное покрытие выбирает ровно один конец
каждого ребра данного паросочетания и не выбирает ни одной свободной вершины.

### Вынужденные вершины и свободный выбор

Свободные вершины обязательно отсутствуют: это `N`.
Все соседи обязательно отсутствующей вершины должны присутствовать: `A`.
Парная вершина обязательно выбранной должна отсутствовать.
Два прохода реализуют эти правила:

- От свободных левых: достигнутые слева получают `N`, справа — `A`.
- От свободных правых: достигнутые справа получают `N`, слева — `A`.

Противоречия невозможны, поскольку минимальное покрытие существует.
Все непомеченные вершины заняты паросочетанием, и их пары тоже непомечены.
Первое покрытие выберет все вынужденные `A` и все непомеченные слева,
второе — все `A` и все непомеченные справа.
Рёбра с концом `N` уже имеют другой конец `A`; остальные либо касаются `A`,
либо соединяют две непомеченные вершины и покрываются выбранной долей.
В каждом парном ребре выбран ровно один конец, размер обоих покрытий `ν`.
Любая непомеченная вершина входит в одно и не входит в другое: это `E`.
Перебирать покрытия или строить компоненты сильной связности не требуется.

В примере `L1` и `R7` обязательны. `L8…L11` и `R8,R9` никогда не выбираются.
Шесть вершин `L2…L7` и шесть `R1…R6` допускают выбор:
`L1…L7` вместе с `R7` и `L1` вместе с `R1…R7` — два минимальных
покрытия размера восемь, свидетельствующие о вариантах.

### Сложность и хранение

Пусть `B=ceil(max(n,m)/w)` для разрядности слова `w`.
В компилируемых версиях `w=64` и не более шестнадцати слов в строке маски;
время `O(k+n²B+nm+(n+m)B)` машинных операций.
У Python маски — большие целые; консервативная оценка с их обработкой
при чтении и выделении младшего бита — `O((k+n(n+m))B)`.
Поиск и распространение полностью итеративны.

Маски, пары и очереди занимают `O((n+m)B+n+m)`. C++ и Java читают поток
через буфер, Python — по одному ребру. Go и Rust сохраняют входной
буфер, что добавляет `O(k)` байт при данных границах чисел.

Подводные камни:

- Изолированная вершина — `N`; у пустого графа единственный минимум —
  пустое покрытие.
- Одного максимального паросочетания достаточно, а его свободные вершины
  не входят ни в один минимум.
- При совершенном паросочетании обеих долей все вершины имеют тип `E`.
- Нужны оба прохода и все свободные начальные вершины.
- Нумерации долей различны, лишние биты последнего слова нужно исключить.
- Количество младших нулей вычисляется только для ненулевого слова.

## Особенности языков

C++, Go и Rust используют беззнаковые 64-битные слова. Java хранит
примитивные строки `long`, знаковое представление не мешает битовым
операциям. Python заранее вычисляет отдельные биты вершин и преобразует
только два числа одной строки, не создавая список всех токенов
миллионного входа.
