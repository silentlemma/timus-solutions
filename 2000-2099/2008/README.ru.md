# 2008. Три баллистических прыжка

[Timus 2008](https://acm.timus.ru/problem.aspx?space=1&num=2008) · сложность 1039 · math

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Материальная точка начинает на одной из двух рук, причём неизвестно на
какой. Нужно прыгнуть на другую руку, обратно на исходную и затем на
точку головы. Каждый прыжок независимо выбирает начальную скорость с
модулем не больше `v`. Во время полёта действует только направленная
вниз тяжесть `g=9.8`, горизонтальная скорость постоянна. Определите,
существует ли подходящая начальная рука для всех трёх прыжков. Три
неподвижные различные точки лежат в одной вертикальной плоскости, ось y
направлена вверх.

## Входные данные

Целое `v`, затем три пары координат: голова, левая рука, правая рука.
Скорость и все координаты — неотрицательные целые не больше 10000.
Единицы: метры и метры в секунду. Время 0,5 секунды, память 64 МБ.

## Выходные данные

Выведите точно `Yes`, если прыжки возможны, иначе `No`. Единственный
токен сравнивается точно.

## Проверка

Ответы сравниваются по токенам.

При скорости 10 перелёты между руками на расстоянии 10 возможны. Первый
пример заканчивается прыжком с левой руки, второй — с правой. В третьем
скорость 5 недостаточна даже для перелёта между руками.

## Решение

При любой начальной руке нужны оба направления между руками. Последний
прыжок может начинаться с любой. Поэтому проверяем `левая→правая` и
`правая→левая`, а также хотя бы одно из `левая→голова`, `правая→голова`.
Вертикальная разность делает достижимость направленной.

Для отдельного прыжка пусть смещение равно `dx,dy`, время полёта `t>0`,
расстояние `r=sqrt(dx²+dy²)>0`. Начальные компоненты должны быть
`ux=dx/t`, `uy=dy/t+g t/2`. Квадрат модуля скорости:

`u²(t)=r²/t²+g dy+g²t²/4`.

Сумма первого и последнего слагаемых минимальна и равна `g r` при
`t²=2r/g`. Значит, минимальный квадрат начальной скорости равен
`g(r+dy)`. Он неотрицателен, а для различных точек минимизирующее время
положительно. Для вертикального движения вниз может хватать нулевой
начальной скорости: свободное падение допустимо.

Прыжок возможен ровно при `v²≥(49/5)(r+dy)`. Обозначим `T=5v²−49dy`.
Получаем `T≥49r`, что эквивалентно `T≥0` и `T²≥49²(dx²+dy²)`. Все
сравнения целочисленные. Проверка знака обязательна до возведения в
квадрат; равенство допустимо, погрешность вычислений не нужна.

Два направления между руками необходимы для любого маршрута. Если они и
прыжок к голове с некоторой руки возможны, выбираем эту руку начальной:
после двух перелётов вернёмся на неё и выполним последний. Любая
допустимая последовательность требует именно этих направлений, что
доказывает итоговое условие.

Время `O(1)`, память `O(1)` для фиксированных трёх точек. Достаточно
знаковых 64-битных целых: `|T|≤500490000`, поэтому
`T²≤250490240100000000<2^63`; правая часть `49²(dx²+dy²)≤480200000000`.
Умножение с самого начала должно быть 64-битным.

## Особенности языков

Голова читается раньше рук. Между руками проверяются оба направления, к
голове достаточно любого. Смещения знаковые, несмотря на неотрицательный
ввод. Используйте точно `g=49/5`, не округляйте до 10 и не вычисляйте
корни в программе. Учтите `v=0`, отрицательное `dy`, вертикальные
траектории и равенство. C++, Go, Java и Rust всюду используют знаковые
64-битные числа; целые Python точны.
