# 2076. Круг на оси симметрии квадратичной кривой

[Timus 2076](https://acm.timus.ru/problem.aspx?space=1&num=2076) · сложность 6151 · geometry, math

Автор оригинальной задачи — Михаил Рубинчик.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Кривая — множество точек (a t² + b t + c, d t² + e t + f) для всех
вещественных t. Точку P проецируют на одну из осей симметрии кривой и
получают точку Q. Пересекается ли замкнутый круг с центром Q и радиусом
R с кривой? Ответ `YES`, если да для любой оси, `NO`, если ни для какой,
и `MAYBE`, если зависит от оси. Гарантируется, что хотя бы одна ось
есть. Ограничения: 2 секунды и 256 МБ.

## Входные данные

T ≤ 7000 тестов, каждый — три строки `a b c`, `d e f`, `Px Py R` из
целых чисел, по модулю не больше 10²⁰, R ≥ 1.

## Выходные данные

`YES`, `NO` или `MAYBE` для каждого теста.

## Примеры

### Пример 1

Ввод:

```
1
0 1 0
1 0 0
2 1 1
```

Вывод:

```
YES
```

## Решение

Запишем кривую как C + B t + A t² с A = (a, d), B = (b, e), C = (c, f),
и пусть W = P − C. Кривая — точка, прямая, луч или парабола.

- A = B = 0: одна точка C. Любая прямая через C — ось, а основание Q
  пробегает окружность с диаметром CP, от самой C (расстояние 0) до P
  (расстояние |CP|). Поэтому ответ `YES`, если |CP| ≤ R, и `MAYBE`
  иначе.
- A = 0, B ≠ 0: прямая. Сама прямая — ось, и Q лежит на ней, что даёт
  `YES`. Любая перпендикулярная прямая тоже ось, и тогда Q находится на
  расстоянии P от прямой, (W × B)² / |B|². Снова `YES` или `MAYBE`.
- A ≠ 0: единственная ось — прямая через вершину с направлением A (для
  параболы, а также для луча, когда A × B = 0). При t₀ = −(A·B) / (2|A|²)
  в вершине координата Q вдоль оси от вершины получается N / (4|A|³),
  где N = 4|A|² (W·A) + (A·B)². Поперёк оси кривая раскрывается как
  s = κw² с κ = |A|³ / K, K = (A × B)².

Для точки Q = (s, 0) на оси квадрат расстояния до кривой — минимум по
u = w² ≥ 0 величины (κu − s)² + u. Производная обращается в ноль при
u = s/κ − 1/(2κ²). Если это не положительно (s ≤ 1/(2κ), то есть
N ≤ 2K), ближайшая точка — вершина на расстоянии |s|, и проверка —
N² ≤ 16 R² |A|⁶. Иначе квадрат расстояния равен
s/κ − 1/(4κ²) = K (N − K) / (4|A|⁶), и проверка —
K (N − K) ≤ 4 R² |A|⁶. Для луча K = 0, и формулы по-прежнему верны:
внутри луча расстояние 0, позади его начала — |s|. Ответ `YES` или
`NO`, ведь ось одна.

Всё сравнивается точно. Входные числа доходят до 10²⁰, так что
произведения — примерно до 10¹⁶⁴: Python, Go и Java пользуются своими
длинными целыми, а решения на C++ и Rust несут собственное маленькое
знаковое длинное целое со сложением, вычитанием, умножением и
сравнением на 32-битных разрядах. На тест — O(1) операций с длинными
числами.

В примере кривая — парабола y = x², ось — x = 0, и Q = (0, 1) лежит с
внутренней стороны параболы на расстоянии √3/2 < 1 от неё, поэтому ответ
`YES`.
