# 2097. 找出相差一个线性函数的路段

[Timus 2097](https://acm.timus.ru/problem.aspx?space=1&num=2097) · 难度 2202 · strings

原题作者 Dmitry Ivankov，出自 2014 年乌拉尔联邦大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

新雪道的高度为 x₀ … x_m，另外以同样方式给出 n 条旧雪道。若存在 a 和 b 使所有 i 都有 xᵢ − yᵢ = a·i + b，则旧雪道上的路段 y₀ … y_m 与之相似。求一条雪道和一个相似路段的起点，使 |a| 最小，否则输出 −1。任何这样的答案都可接受。时间限制 1 秒，内存限制 64 MB。

## 输入

n ≤ 10⁵，然后是 m ≤ 10⁵ 和 x₀ … x_m，然后是每条旧雪道的长度和高度；长度之和不超过 10⁵，高度绝对值不超过 10⁹。

## 输出

雪道编号和路段起点（距起点的米数），或 −1。

## 评测方式

检查器只在期望输出为 −1 时接受 −1，否则检查路段相似且其 |a| 最小。

## 样例

### 样例 1

输入：

```
2
2 3 2 1
5 21 15 10 6 3 2
4 10 7 5 3 2
```

输出：

```
2 1
```

### 样例 2

输入：

```
3
2 0 0 0
1 0 0
2 1 2 4
1 5 17
```

输出：

```
-1
```

## 解法

差 xᵢ − yᵢ 是线性的，当且仅当它的二阶差分为零，即 x 与该路段的二阶差分相同。所以用 KMP 算法在每条旧雪道的二阶差分中查找 x 的 m − 1 个二阶差分；位置 j 的每次出现就是起点为 j 的相似路段，其 a 为 (x₁ − x₀) − (y_{j+1} − y_j)。保留所有出现中最小的 |a|。m = 1 时模式为空，每条足够长雪道的每个起点都匹配。数值可达 4·10⁹，所以用 64 位整数，工作量与输入规模成线性。

第一个样例中新雪道 3、2、1 的二阶差分为 0，它在第二条雪道 10、7、5、3、2 中只出现在位置 1。
