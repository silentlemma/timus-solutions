# 2097. Отрезок, отличающийся на линейную функцию

[Timus 2097](https://acm.timus.ru/problem.aspx?space=1&num=2097) · сложность 2204 · strings

Автор оригинальной задачи — Дмитрий Иванков; Открытое личное первенство УрФУ по программированию 2014.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У нового склона высоты x₀ … x_m, и так же даны n старых склонов. Отрезок
y₀ … y_m старого склона похож, если xᵢ − yᵢ = a·i + b при всех i для
некоторых a и b. Найдите склон и начало похожего отрезка с наименьшим
|a| или выведите −1. Подходит любой такой ответ. Ограничения: 1 секунда
и 64 МБ.

## Входные данные

n ≤ 10⁵, затем m ≤ 10⁵ и x₀ … x_m, затем каждый старый склон своей
длиной и высотами; сумма длин не больше 10⁵, высоты по модулю до 10⁹.

## Выходные данные

Номер склона и начало отрезка (число метров от его начала) или −1.

## Проверка

Проверяющая программа принимает −1, только если так в ожидаемом
выводе, а иначе проверяет, что отрезок похож и его |a| наименьший.

## Примеры

### Пример 1

Ввод:

```
2
2 3 2 1
5 21 15 10 6 3 2
4 10 7 5 3 2
```

Вывод:

```
2 1
```

### Пример 2

Ввод:

```
3
2 0 0 0
1 0 0
2 1 2 4
1 5 17
```

Вывод:

```
-1
```

## Решение

Разность xᵢ − yᵢ линейна ровно тогда, когда её вторые разности нулевые,
то есть когда вторые разности x и отрезка совпадают. Поэтому m − 1
вторых разностей x ищутся во вторых разностях каждого старого склона
алгоритмом Кнута — Морриса — Пратта; каждое вхождение на позиции j — это
похожий отрезок с началом j, и его a равно (x₁ − x₀) − (y_{j+1} − y_j).
Хранится наименьшее |a| по всем вхождениям. При m = 1 образец пуст, и
подходит любое начало любого достаточно длинного склона. Значения
доходят до 4·10⁹, поэтому в языках с фиксированной разрядностью нужны
64-битные целые, а время работы — O(input).

В первом примере у нового склона 3, 2, 1 вторая разность 0, и во втором
склоне 10, 7, 5, 3, 2 она встречается только на позиции 1.
