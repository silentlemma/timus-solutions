# 2009. 两条每人一秒的服务队列

[Timus 2009](https://acm.timus.ru/problem.aspx?space=1&num=2009) · 难度 833 · simulation

原题作者 Alexey Kungurtsev，出自 2013 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

学生进入左右两条队列，每人服务一秒，条件允许就立即开始。新到者可以排任意队尾，或直接插在其名单中某个当前仍排队的熟人后面。选择前方人数最少的位置，平局选右队，之后不能换队。同组同时到达，但依输入顺序逐人选择。若完成服务与到达同刻，两队的完成事件先于所有新到者。求每人的离队时间及队列。

## 输入

`n m`，`5 ≤ n ≤ 1000`，`1 ≤ m ≤ n`，学生编号 1..n。随后 `n` 行各列至多 100 个可跟随的其他学生编号，以 0 结束。许可有方向，不保证互相认识，名单不含自身。每组由一行 `t k` 和一行按到达顺序排列的 `k` 个编号描述。时间为递增整数 `1 ≤ t ≤ 10^9`，每人恰好出现一次。时间限制 1 秒，内存 64 MB。

## 输出

按学生编号输出 `n` 行，每行离队时间与 `left` 或 `right`。唯一正确的数字和词按词元比较。

## 评测方式

按记号逐个比较输出。

## 样例

```
5 1
0
0
0
0
1 0
1 5
1 2 3 4 5
```

```
2 right
2 left
4 right
3 left
3 right
```

前四人到达后右队为 `[1,3]`，左队为 `[2,4]`。5 可直接排在 1 后，使右队变成 `[1,5,3]`。全组在时刻 1 到达，两个队首先于 2 离队；5 于 3 离队，3 于 4 离队。输出仍按编号顺序。

## 解法

用有序数组保存两队。每人记录当前队列，若不在队则为 −1，以及从零开始的位置。每条非空队保存队首下一次完成时间。已离队者的位置可保留旧值，但必须用在队标志忽略。

处理时刻 `t` 的组之前先推进两队。若下一完成时间 `u≤t`，恰有 `min(队长,t−u+1)` 个队首学生离开。记录时间 `u,u+1,…`，标记离队，删除此前缀并更新剩余位置。若还有人则下一完成时间加已服务人数，否则标记空闲。这样直接跨越最长 `10^9` 的空档。

新到者先取两队队尾位置。每个当前仍在队的名单熟人，为其队列提供“该位置加一”的候选。各取最小值；只有左位置严格更小时选左，否则选右。插入并更新移位后缀。空队加入首人后，其完成时间为 `t+1`。所有组处理完后，从各队下一完成时间起每秒记录剩余离队者。

对到达事件归纳。初始数组、成员标志和时钟均对应空队。没有到达的间隔内，队首先在保存时刻完成，其余按数组顺序每秒完成一个。前缀公式因此恰好处理所有不晚于 `t` 的完成事件，包含等号，并在任何新到者前恢复位置。

合法插入点正是队尾和当前在队的名单熟人之后。最小候选及右队平局规则精确实现要求。非空队的合法位置至少为一，不能挤到正在服务的队首前，故其完成时钟不变。空队立即开始，一秒后结束。更新后缀保持同组下一人的所有位置和成员事实。最终排空同样是无新到达的服务过程，所以全部输出正确。

设名单条目总数 `F≤100n`。至多 `n` 次插入与 `2m` 次服务批次，每次移动或重排至多 `n` 个位置，熟人查询总计 `F`。时间 `O(n²+F)`，含输入输出的空间 `O(n+F)`。不逐秒遍历真实时间。任意离队时间不超过 `max_到达+n≤1000001000`，有符号 32 位整数足够。

## 各语言说明

同刻先处理所有完成服务，再处理到达。未到达和已离队的熟人均无效，许可不应对称化。新到者直接插在熟人后、早到跟随者之前，不构成永久群组。平局选右，空闲时钟从新到达重启，答案按编号存储。五个版本使用迭代数组或列表；Java 用缓冲输入与原生整数熟人数组。
