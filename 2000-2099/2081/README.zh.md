# 2081. 故障表盘上的递减时间

[Timus 2081](https://acm.timus.ru/problem.aspx?space=1&num=2081) · 难度 720 · greedy

原题作者 Pavel Egorov（由 Ivan Burmistrov 整理）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

计时器在由 `_`、`|`、`.` 画出的七段表盘上显示 MM:SS，但部分亮着的段可能不显示（显示出的段总是正确的）。给出 n 次读数，恢复 00:00 到 59:59 之间严格递减、且与各读数相符的时间。任何正确答案都可接受。时间限制 2 秒，内存限制 256 MB。

## 输入

n ≤ 100，然后每次读数三行、每行 17 个字符：四个数字分别占第 1–3、5–7、11–13、15–17 列。

## 输出

n 行 MM:SS。

## 评测方式

检查器检查格式、严格递减，以及每个显示的段都属于所选数字。

## 样例

### 样例 1

输入：

```
2
._..._........._.
|...._|.*...|.._|
|_|.._..*...|.|..
....._....._..._.
|.|...|.*.|.|.._.
|.|.|_..*.|_|.._.
```

输出：

```
03:12
00:05
```

## 解法

若格子中每个显示的字符都与数字在该位置的字符相同，则该数字与格子相符。每次读数的四个格子给出相符数字表。按顺序处理读数，从上一个答案减一开始向下扫描，取第一个相符的时间，即最大的相符时间。

只要存在答案，这样做就不会失败：归纳可知每次读数的贪心值不小于该答案中的值，因为答案的值相符，且小于答案的上一个值，而后者不超过贪心的上一个值。每次读数最多扫描 3600 步。

样例中第一次读数既符合 03:12 也符合 09:48，所以输出可能与样例不同。
