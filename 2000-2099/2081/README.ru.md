# 2081. Убывающие времена на неисправном табло

[Timus 2081](https://acm.timus.ru/problem.aspx?space=1&num=2081) · сложность 721 · greedy

Автор оригинальной задачи — Павел Егоров; подготовка — Иван Бурмистров.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Таймер показывает MM:SS на семисегментном табло из символов `_`, `|` и
`.`, но часть горящих сегментов может не отображаться (показанный
сегмент всегда верен). По n показаниям восстановите времена от 00:00 до
59:59, строго убывающие и согласованные с показаниями. Подходит любой
правильный ответ. Ограничения: 2 секунды и 256 МБ.

## Входные данные

n ≤ 100, затем по три строки из 17 символов на показание: четыре цифры
занимают столбцы 1–3, 5–7, 11–13 и 15–17.

## Выходные данные

n строк MM:SS.

## Проверка

Проверяющая программа проверяет формат, строгое убывание и то, что
каждый показанный сегмент принадлежит выбранной цифре.

## Примеры

### Пример 1

Ввод:

```
2
._..._........._.
|...._|.*...|.._|
|_|.._..*...|.|..
....._....._..._.
|.|...|.*.|.|.._.
|.|.|_..*.|_|.._.
```

Вывод:

```
03:12
00:05
```

## Решение

Цифра подходит к ячейке, если каждый показанный символ совпадает с
символом цифры на этом месте. Для каждого показания четыре ячейки дают
таблицу подходящих цифр. Идём по показаниям по порядку и берём
наибольшее подходящее время меньше предыдущего ответа, перебирая вниз.

Это никогда не ломается, если ответ существует: по индукции жадное
значение каждого показания не меньше значения в этом ответе, ведь
значение ответа подходит и меньше предыдущего значения ответа, которое
не больше предыдущего жадного. Перебор — не больше 3600 шагов на
показание.

В примере первое показание подходит и к 09:48, и к 03:12, так что вывод
может отличаться от образца.
