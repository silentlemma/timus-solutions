# 2075. Слоистый коктейль через трубочку

[Timus 2075](https://acm.timus.ru/problem.aspx?space=1&num=2075) · сложность 2610 · fenwick

Автор оригинальной задачи — Михаил Рубинчик (Подготовка — Егор Щелконогов).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Ликёры наливают в стакан, и они образуют слои по плотности: ликёр с
лексикографически меньшим названием плотнее и лежит ниже, а налитый
повторно ликёр сливается со своим слоем. Пьющий держит трубочку на
фиксированной высоте H и пьёт 1 мм в секунду с этой высоты, так что
слои сверху опускаются к трубочке. Он перестаёт пить, как только
коктейль не достаёт до H, если только ровно в этот момент не наливают
новый ликёр. По событиям со временем (наливание, установка трубочки,
ожог, после которого трубочку вынимают) выведите отрезки времени, когда
он пил, и какой ликёр. Ограничения: 1 секунда и 256 МБ.

## Входные данные

n ≤ 10⁵ событий в возрастающие различные моменты T ≤ 10⁹: `T name h`
наливает h ≤ 10⁹ мм ликёра (1–10 строчных букв), `T Oleg H` ставит
трубочку на высоту H ≤ 10¹⁴ ниже текущего верха и начинает питьё,
`T fire` прекращает питьё (бывает только во время питья).

## Выходные данные

Строки `from-to name` по возрастанию времени; две соседние строки одного
ликёра не должны соприкасаться, поэтому соприкасающиеся куски
объединяются.

## Примеры

### Пример 1

Ввод:

```
7
1 kahlua 1
2 baileys 1
3 cointreau 1
4 Oleg 0
5 kahlua 3
6 fire
20 Oleg 0
```

Вывод:

```
4-5 baileys
5-6 cointreau
20-24 kahlua
```

## Решение

Стакан — список слоёв, отсортированный по названию. Питьё d секунд на
уровне H убирает вещество из [H; H + d) и, поскольку всё сверху
опускается, забирает его снизу вверх. Значит, нужно найти слой, где
находится уровень H, выпить его часть выше H (или меньше, если d
кончится) и повторять со следующим слоем, пока есть время и коктейль.
Уровень трубочки при этом не меняется.

Сначала читаются все названия и сортируются, так что у каждого ликёра
своё место, а дерево Фенвика хранит высоты мест. Слой с уровнем H —
первое место, префиксная сумма которого больше H; его находит обычный
спуск по дереву за O(log m) вместе с тем, сколько этого слоя выше H.
Каждый шаг либо заканчивает питьё, либо выпивает остаток слоя выше
трубочки; слой, целиком лежащий выше трубочки, исчезает, поэтому, кроме
O(1) шагов на событие, шаги оплачиваются наливаниями, и всего
O(n log n).

Между двумя событиями пьющий пьёт столько, сколько прошло времени. Если
коктейль кончился раньше, питьё прекращается; если ровно к
следующему событию — питьё продолжается, что важно, только если это
событие — наливание (новая трубочка или ожог и так задают состояние).
После последнего события он, если ещё пьёт, выпивает всё выше
трубочки. Соприкасающиеся по времени куски одного ликёра объединяются
перед выводом.

В примере трубочка на высоте 0 сначала берёт baileys (4-5), затем
опустившийся cointreau (5-6); в момент 20 остаётся только kahlua, 4 мм,
выпитые за 20-24.

## Особенности языков

Высоты доходят до 10¹⁴, а время — примерно до 10⁹ + 10¹⁴, поэтому нужны
64-битные целые. Решение на Python отправляется на PyPy: на CPython оно
близко к пределу.
