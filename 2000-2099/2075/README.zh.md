# 2075. 用吸管喝分层鸡尾酒

[Timus 2075](https://acm.timus.ru/problem.aspx?space=1&num=2075) · 难度 2608 · fenwick

原题作者 Mikhail Rubinchik（由 Egor Shchelkonogov 整理）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

利口酒倒入杯中按密度分层：名称字典序越小密度越大、位置越低，再次倒入的同种利口酒并入已有的层。饮者把吸管固定在高度 H，以每秒 1 毫米的速度从该高度喝，上面的层会向下滑到吸管处。一旦鸡尾酒够不到 H 就停止喝，除非恰好在那一刻有新的倒入。给出带时间的事件（倒酒、放置吸管、被烫到拿出吸管），输出喝的时间区间以及每段喝的是哪种利口酒。时间限制 1 秒，内存限制 256 MB。

## 输入

n ≤ 10⁵ 个事件，时间 T ≤ 10⁹ 互不相同且递增：`T name h` 倒入 h ≤ 10⁹ 毫米的利口酒（1 到 10 个小写字母），`T Oleg H` 把吸管放到当前顶部以下的高度 H ≤ 10¹⁴ 并开始喝，`T fire` 停止喝（只会在喝的过程中出现）。

## 输出

按时间递增输出 `from-to name`；同一种利口酒的相邻两行不能首尾相接，所以相接的片段要合并。

## 样例

### 样例 1

输入：

```
7
1 kahlua 1
2 baileys 1
3 cointreau 1
4 Oleg 0
5 kahlua 3
6 fire
20 Oleg 0
```

输出：

```
4-5 baileys
5-6 cointreau
20-24 kahlua
```

## 解法

杯子是按名称排序的层列表。在高度 H 喝 d 秒会拿走 [H; H + d) 中的酒，并且因为上面的部分下滑，是自下而上依次拿走的。所以要做的是：找到包含高度 H 的层，喝掉它在 H 以上的部分（若 d 不够则少喝），然后在还有时间和酒时对下一层重复。这期间吸管高度不变。

先读入所有名称并排序，每种利口酒有固定的位置，用树状数组保存各位置的高度。包含高度 H 的层是前缀和首次超过 H 的位置，通过在树上的常规下降在 O(log m) 内找到，同时得到该层在 H 以上的部分有多少。每一步要么结束喝酒，要么喝完某层在吸管以上的剩余部分；完全位于吸管以上的层会消失，因此除了每个事件 O(1) 步以外，其余步数由倒酒次数承担，总计 O(n log n)。

两次事件之间饮者喝的时间等于时间差。若酒提前喝完，就永久停止；若恰好在下一事件时喝完，则继续喝，这只有在该事件是倒酒时才有影响（新吸管或被烫本来就会设定状态）。最后一个事件之后，若仍在喝，就把吸管以上的酒全部喝完。同一种利口酒在时间上相接的片段在记录时合并。

样例中吸管在 0 处，先喝 baileys（4-5），再喝滑下来的 cointreau（5-6）；在 20 时只剩 kahlua，4 毫米，在 20-24 喝完。

## 各语言说明

高度可达 10¹⁴，时间可达约 10⁹ + 10¹⁴，所以使用 64 位整数。Python 解法用 PyPy 提交：在 CPython 上接近时间限制。
