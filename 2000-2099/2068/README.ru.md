# 2068. Чётность числа разбиений

## Задача

Есть n кучек орехов, в каждой нечётное число орехов. Двое ходят по
очереди; ход — разделить одну кучку на три непустые, в каждой из которых
снова нечётное число орехов. Кто не может сделать ход, проигрывает.
Первой ходит Дейенерис, затем Станнис. Определите победителя при
оптимальной игре. Ограничения: 1 секунда и 64 МБ.

## Входные данные

Нечётное n, 1 ≤ n ≤ 777, затем n нечётных размеров кучек от 1 до 54321.

## Выходные данные

`Daenerys`, если она выигрывает, иначе `Stannis`.

## Примеры

### Пример 1

Ввод:

```
1
3
```

Вывод:

```
Daenerys
```

### Пример 2

Ввод:

```
3
1 1 1
```

Вывод:

```
Stannis
```

### Пример 3

Ввод:

```
5
777 313 465 99 1
```

Вывод:

```
Daenerys
```

## Решение

Стратегия здесь ничего не решает. Ход заменяет одну кучку тремя, поэтому
число кучек растёт ровно на два, а общее число орехов не меняется. Игра
заканчивается ровно тогда, когда в каждой кучке по одному ореху: кучку
из 3 и более (нечётного числа) орехов всегда можно разбить как
1 + 1 + (a − 2). В этот момент кучек столько же, сколько орехов, так что
число сделанных ходов всегда равно (S − n) / 2, то есть сумме
(aᵢ − 1) / 2 по кучкам.

Дейенерис делает ходы с нечётными номерами, поэтому она выигрывает ровно
тогда, когда это число нечётно. В третьем примере кучки дают
388 + 156 + 232 + 49 + 0 = 825 ходов — нечётное число. Работа за O(n).

## Особенности языков

Сумма не больше 777 · 27160 и помещается в 32-битное целое; в C++ и Java
она всё равно хранится в 64 битах.
