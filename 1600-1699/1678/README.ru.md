# 1678. Космический покер 3

[Timus 1678](https://acm.timus.ru/problem.aspx?space=1&num=1678) · сложность 5108 · combinatorics

Автор оригинальной задачи — Алексей Самсонов; Ural SU Contest, Петрозаводские летние сборы, август 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N игроков получают по M личных карт, а на стол выкладываются K общих
карт; рука игрока — личные карты вместе с общими. У карт есть только
достоинство (13 достоинств, от 2 до A), и каждая карта бесконечной
колоды принимает любое достоинство с вероятностью 1/13. Комбинация
(v1, …, vL) требует v1 карт одного достоинства, v2 другого и так далее —
всего L разных достоинств; рука её содержит, если таких карт не меньше.
C комбинаций перечислены от самой дешёвой к самой дорогой, и раунд
выигрывает игрок с самой дорогой комбинацией за столом; если таких
несколько, объявляется ничья.

Зная личные карты первого игрока и уже открытые общие карты, найти
вероятность того, что этот игрок победит единолично.

## Входные данные

N, M и K (2 ≤ N, M ≤ 10; 1 ≤ K ≤ 5); M личных карт первого игрока;
открытые общие карты, не больше K (строка может быть пустой); C
(1 ≤ C ≤ 100) и комбинации от дешёвой к дорогой, каждая в виде
L v1 … vL, все vi положительны, а их сумма не больше M + K.

## Выходные данные

Вероятность с погрешностью не больше 10⁻⁵.

## Решение

Важно лишь, сколько карт каждого достоинства. Рука содержит
(v1, …, vL) ровно тогда, когда после сортировки обоих списков по
убыванию i-е по величине количество не меньше i-го по величине vi:
самому большому требованию всегда можно отдать самое частое
достоинство. Значит, лучшая комбинация руки зависит только от
отсортированных количеств, и её запоминает кэш.

Переберём скрытые общие карты как количества по 13 достоинствам: h
скрытых карт дают не больше C(h + 12, 12) ≤ 6188 вариантов, у каждого
полиномиальная вероятность h! / (Π xᵢ! · 13ʰ). Для варианта берём
лучшую комбинацию первого игрока c; без единой комбинации выиграть
нельзя. При известных общих картах личные карты соперников
независимы, поэтому вариант добавляет свою вероятность, умноженную на
q^(N − 1), где q — вероятность того, что лучшая комбинация одного
соперника дешевле c (отсутствие комбинации считается самым дешёвым).

Эта вероятность зависит только от отсортированных общих количеств,
поэтому разных таблиц не больше p(K) ≤ 7. Чтобы построить таблицу,
разобьём достоинства на группы по общему количеству: g достоинств
группы с общим количеством v взаимозаменяемы, поэтому группа получает
разбиение своей доли s из M карт соперника не больше чем на g частей,
которое можно разместить g! / ((g − частей)! · Π mult!) способами (mult —
число равных частей), с весом 1 / Π x!. Состояние после группы — это
отсортированный список количеств у соперника и число использованных
карт; в конце каждое полное состояние, умноженное на M! / 13ᴹ, идёт в
свою лучшую комбинацию, а префиксные суммы дают вероятность «дешевле c»
для каждого c.

`O(C(K + 12, 12) · 13 + p(K) · S)`, где S — работа одной таблицы,
несколько тысяч форм из не более чем M + K карт; всё работает намного
быстрее секунды.

Подводные камни:

- третья строка может быть пустой, поэтому вход читается по строкам;
- ничья — не победа: соперник должен быть строго дешевле;
- комбинация требует не меньше vi карт, поэтому «KQKQKQ» содержит (2, 3).

Ответы совпадают с прямым перебором всех раздач на крошечных размерах и
с независимой принятой реализацией.
