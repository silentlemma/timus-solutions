# 1678. 太空扑克 3

[Timus 1678](https://acm.timus.ru/problem.aspx?space=1&num=1678) · 难度 5108 · combinatorics

原题作者 Alex Samsonov，出自 2008 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 名玩家各拿 M 张私有牌，桌上再发 K 张公共牌；玩家的一手牌就是私有牌加上公共牌。
牌只有点数（13 种，从 2 到 A），无限牌堆中的每张牌取每种点数的概率都是 1/13。
组合 (v1, …, vL) 要求某个点数有 v1 张、另一个点数有 v2 张……共 L 种不同点数；
一手牌只要数量不少于要求就算含有该组合。C 个组合按价值从低到高给出，
全桌价值最高的组合的持有者获胜；若有多名玩家并列，则为平局。

已知第一名玩家的私有牌和已经翻开的公共牌，求该玩家单独获胜的概率。

## 输入

N、M、K（2 ≤ N, M ≤ 10；1 ≤ K ≤ 5）；第一名玩家的 M 张私有牌；
已翻开的公共牌，至多 K 张（该行可能为空）；C（1 ≤ C ≤ 100），
以及按价值从低到高的组合，每个写成 L v1 … vL，所有 vi 为正且总和不超过 M + K。

## 输出

概率，误差不超过 10⁻⁵。

## 样例

### 样例 1

输入：

```
2 5 2
23456

1
1 2
```

输出：

```
0.0883526857
```

### 样例 2

输入：

```
2 5 2
23456
78
2
7 1 1 1 1 1 1 1
1 4
```

输出：

```
0.8407915043
```

## 解法

只有每种点数的张数有意义。把两个列表都按降序排好后，一手牌含有 (v1, …, vL)
当且仅当第 i 大的张数不小于第 i 大的 vi：最大的需求总可以交给出现最多的点数。
因此一手牌的最佳组合只取决于排好序的张数，用缓存记住即可。

把未翻开的公共牌枚举成 13 种点数上的张数：h 张隐藏牌至多有
C(h + 12, 12) ≤ 6188 种情况，每种的多项式概率为 h! / (Π xᵢ! · 13ʰ)。
对每种情况求出第一名玩家的最佳组合 c；一个组合都没有就不可能获胜。
公共牌确定后各对手的私有牌相互独立，所以这种情况贡献其概率乘以 q^(N − 1)，
其中 q 是某一个对手的最佳组合比 c 便宜的概率（没有任何组合算作最便宜）。

这个概率只取决于排好序的公共张数，所以不同的表至多 p(K) ≤ 7 张。
建表时按公共张数把点数分组：公共张数为 v 的一组中 g 个点数可以互换，
于是该组分到对手 M 张牌中的 s 张，并把 s 拆成至多 g 个部分，
放置方式有 g! / ((g − 部分数)! · Π mult!) 种（mult 为相等部分的个数），
权重为 1 / Π x!。每组之后的状态是对手目前排好序的张数列表和已用牌数；
最后每个完整状态乘以 M! / 13ᴹ 计入它的最佳组合，前缀和给出每个 c 的“比 c 便宜”的概率。

`O(C(K + 12, 12) · 13 + p(K) · S)`，其中 S 是一张表的工作量，
即几千种至多 M + K 张牌的张数形状；整体远不到一秒。

注意事项：

- 第三行可能为空，所以要按行读入；
- 平局不算获胜：对手必须严格更便宜；
- 组合要求的是至少 vi 张，所以 “KQKQKQ” 含有 (2, 3)。

答案与小规模下对所有发牌的直接枚举以及一个独立的已通过实现一致。
