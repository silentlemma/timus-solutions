# 1640. Кольцо холода

[Timus 1640](https://acm.timus.ru/problem.aspx?space=1&num=1640) · сложность 178 · geometry

Автор оригинальной задачи — Дмитрий Иванков (подготовка — Александр Ипатов); осеннее первенство школьников, октябрь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Демоны стоят в n точках решётки. Сандро может телепортироваться в любую
точку, где нет демона, и создать вокруг неё ледяное кольцо радиусом не
больше 10000. Кольцо должно убить хотя бы одного демона (лежащего на
окружности), а все оставшиеся в живых демоны должны оказаться внутри.
Нужно вывести центр и радиус.

## Входные данные

n (1 ≤ n ≤ 100), затем координаты демонов — целые числа не больше 1000
по модулю, отсчитанные от текущего положения Сандро. Все демоны в разных
точках, ни один не стоит там, где Сандро.

## Выходные данные

Центр и радиус с точностью 10⁻⁹. Подходит любой правильный ответ.

## Примеры

### Пример 1

Ввод:

```
7
1 1
1 5
3 6
5 3
8 0
9 5
5 9
```

Вывод:

```
5 4 5
```

### Пример 2

Ввод:

```
2
0 2
2 0
```

Вывод:

```
1 1 1.41421356237309
```

## Решение

Телепортироваться не нужно. В точке, где стоит Сандро, демона нет, а
окружность вокруг неё через самого дальнего демона убивает его и
охватывает всех остальных. Её радиус не больше 1000 · √2, что далеко от
10000. `O(n)`.

Подводные камни:

- центр не должен совпадать с демоном, так что центр наименьшей
  охватывающей окружности годится не всегда; начальная точка — всегда;
- правильных ответов много, поэтому чекер принимает любую окружность,
  удовлетворяющую правилам.
