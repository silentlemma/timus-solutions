# 1683. Холодильник

[Timus 1683](https://acm.timus.ru/problem.aspx?space=1&num=1683) · сложность 137 · greedy

Автор оригинальной задачи — Станислав Васильев; X открытое личное первенство УрГУ, 28 февраля 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Бумажную полоску шириной 1 см и длиной n см складывают в квадрат
1 × 1 см из n слоёв. При каждом сгибе от левого края отмеряется целое
число сантиметров, и эта часть загибается направо, так что левый край
сдвигается на отмеренную длину. Найти наименьшее число сгибов и
отмеренные длины.

## Входные данные

n (1 ≤ n ≤ 10⁹).

## Выходные данные

Число сгибов, затем отмеренные длины по порядку. Подходит любая
кратчайшая последовательность.

## Примеры

### Пример 1

Ввод:

```
12
```

Вывод:

```
4
5 3 2 1
```

## Решение

Загнуть x см полоски длины L можно, только если загнутая часть
помещается на остальной, x ≤ L − x, и тогда остаётся полоска длины
L − x ≥ ⌈L / 2⌉. Значит, никакой сгиб не уменьшает полоску больше чем
вдвое с округлением вверх, а загибание ⌊L / 2⌋ каждый раз ровно этого
и достигает: число сгибов — наименьшее m с 2ᵐ ≥ n. `O(log n)`.

Подводные камни:

- при n = 1 сгибы не нужны: выводятся 0 и пустой список;
- 5 3 2 1 из примера — один из многих ответов, поэтому чекер сравнивает
  количество и воспроизводит сгибы.

Чекер воспроизводит каждый сгиб и сравнивает количество с жадным.
