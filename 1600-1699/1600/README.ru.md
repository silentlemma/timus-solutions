# 1600. Аэропорт

[Timus 1600](https://acm.timus.ru/problem.aspx?space=1&num=1600) · сложность 552 · geometry

Автор оригинальной задачи — Владимир Яковлев; IX открытое личное первенство УрГУ, 1 марта 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

До 500 объектов летят в пространстве прямолинейно с постоянной
скоростью; все начинают дальше друг от друга, чем критическое расстояние
d. Нужно найти первый момент, когда какая-то пара сблизится до
расстояния d, и вывести `ALARM!`, а затем время с тремя знаками и пару,
или `OK`, если этого не случится. Если в этот момент сблизились
несколько пар, можно вывести любую.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n и d, затем положение и скорость каждого объекта, шесть чисел.

## Выходные данные

`OK` или `ALARM!`, а затем время и номера двух объектов.

## Примеры

### Пример 1

Ввод:

```
2 1.0
1.0 1.0 -1.0 0.0 0.0 10.0
0.0 0.0 4.0 2.0 0.0 0.0
```

Вывод:

```
ALARM!
0.500 1 2
```

## Решение

С точки зрения одного объекта пары другой движется по прямой p + v·t, где
p и v — разности положений и скоростей. Расстояние равно d, когда
|p + v·t|² = d², то есть квадратное уравнение
(v·v)t² + 2(p·v)t + (p·p − d²) = 0. При равных скоростях или
отрицательном дискриминанте пара не сближается. Иначе меньший корень —
момент, когда расстояние впервые становится d; так как все пары
начинают поодаль, отрицательный корень значит, что они разлетаются.
Самый ранний момент по всем парам и есть ответ: `O(n²)`, около 125000
пар.

Тесты проверяет чекер, который принимает любую пару, сблизившуюся в
нужный момент, с учётом округления до трёх знаков. Времена сверены с
бисекцией по расстоянию до момента наибольшего сближения.

Подводные камни:

- пара, которая лишь касается расстояния d в момент наибольшего
  сближения, всё равно вызывает тревогу: дискриминант тогда ровно 0
  (тест 04);
- при крошечной относительной скорости время бывает большим, почти
  10⁶ секунд в тесте 07, так что заранее его ограничивать нельзя;
- с половинным дискриминантом, b = p·v и b² − a·c, не нужно таскать
  множитель 4.
