# 1600. 机场

[Timus 1600](https://acm.timus.ru/problem.aspx?space=1&num=1600) · 难度 552 · geometry

原题作者 Vladimir Yakovlev，出自 2008 年 3 月 1 日第九届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

最多 500 个物体在空间中做匀速直线运动；开始时彼此的距离都大于临界距离 d。求某一对物体首次接近到距离 d 的时刻，
输出 `ALARM!`，再输出保留三位小数的时间和这对物体；若永远不会发生，输出 `OK`。若该时刻有多对同时接近，输出任意一对即可。

时间限制：1 秒。内存限制：64 MB。

## 输入

n 和 d，然后是每个物体的位置和速度，共六个数。

## 输出

`OK`，或 `ALARM!` 后跟时间和两个物体的编号。

## 样例

### 样例 1

输入:

```
2 1.0
1.0 1.0 -1.0 0.0 0.0 10.0
0.0 0.0 4.0 2.0 0.0 0.0
```

输出:

```
ALARM!
0.500 1 2
```

## 解法

从一对物体中的一个看，另一个沿直线 p + v·t 运动，其中 p、v 是位置差和速度差。距离为 d 时 |p + v·t|² = d²，
即二次方程 (v·v)t² + 2(p·v)t + (p·p − d²) = 0。速度相同或判别式为负时，这对物体不会接近。否则较小的根就是
距离首次变为 d 的时刻；由于每对物体开始时都相距较远，负根说明它们在互相远离。所有对中最早的时刻就是答案：
`O(n²)`，约 125000 对。

测试使用检查器，它接受在正确时刻接近的任意一对，允许三位小数的舍入误差。时间已与对最近点之前的距离做二分的结果对照。

注意事项：

- 只在最近点恰好达到距离 d 的一对也要报警，此时判别式恰为 0（测试 04）；
- 相对速度很小时时间可能很大，测试 07 中接近 10⁶ 秒，所以不能预先给时间设上限；
- 用半判别式 b = p·v 和 b² − a·c，就不必处理因子 4。
