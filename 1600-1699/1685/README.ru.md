# 1685. Орфография

[Timus 1685](https://acm.timus.ru/problem.aspx?space=1&num=1685) · сложность 184 · strings

Автор оригинальной задачи — Евгений Крохалев; X открытое личное первенство УрГУ, 28 февраля 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Текст шифруется так: пишется его средний символ (номер (1 + n) div 2
из n), затем шифруется часть слева от него, затем часть справа. По
зашифрованной строке восстановить текст.

## Входные данные

Одна строка не длиннее 20000 символов: латинские буквы, пробелы и
знаки препинания.

## Выходные данные

Исходный текст.

## Примеры

### Пример 1

Ввод:

```
kyaVs alisse uop.
```

Вывод:

```
Vasya likes soup.
```

### Пример 2

Ввод:

```
gtorhoprahy
```

Вывод:

```
orthography
```

## Решение

Шифрование обходит позиции текста в фиксированном порядке: середина
отрезка, затем левый отрезок, затем правый. Этот порядок зависит
только от n, поэтому повторим его и поставим i-й символ шифра в i-ю
посещённую позицию. Для отрезков lo..hi с нумерацией от 0 середина —
(lo + hi) div 2. Рекурсию заменяет явный стек, хотя её глубина всего
около log n. `O(n)`.

Подводные камни:

- строка может начинаться или заканчиваться пробелами, а это символы
  текста: отрезать можно только перевод строки;
- в тексте может стоять несколько пробелов подряд (тест 05).

Ответы совпадают с независимой принятой реализацией и возвращают
выход шифровщика к случайным текстам.
