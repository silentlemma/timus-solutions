# 1653. Конвейер Смерти

[Timus 1653](https://acm.timus.ru/problem.aspx?space=1&num=1653) · сложность 5743 · geometry

Автор оригинальной задачи — Павел Атнашев; четвертьфинал Восточного подрегиона NEERC 2008.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Космическая станция — правильный многогранник (одно из пяти платоновых
тел) с центром в начале координат, в каждой вершине пушка, направленная
от центра. Сначала одна пушка смотрит вдоль Oz, а ребро из неё лежит в
полуплоскости x ≥ 0 плоскости Oxz. При каждой атаке станция
поворачивается так, чтобы ближайшая к нападающему кораблю пушка
смотрела прямо на корабль, и остаётся так до следующей атаки. Нужно найти суммарный угол
поворота.

## Входные данные

Название тела (tetrahedron, hexahedron, octahedron, dodecahedron или
icosahedron), затем n (1 ≤ n ≤ 100) и n векторов атаки — направлений, в
которых корабли летят к центру. Ближайшая пушка всегда определена
однозначно.

## Выходные данные

Суммарный угол в радианах с 5 знаками после десятичной точки.

## Решение

Корабль, летящий к центру вдоль v, приходит с направления −v. Вершины
каждого тела берутся из классических координат (вершины куба,
прямоугольники золотого сечения для икосаэдра и додекаэдра) и
нормируются. Чтобы получить начальное положение, одна вершина становится
новой осью z, а соседняя вершина без своей z-составляющей — новой осью x;
любой выбор вершины и соседа даёт ту же станцию, ведь вращения тела
переводят их друг в друга.

Ориентация станции хранится матрицей поворота. При каждой атаке
ближайшая пушка — та, у которой наибольшее скалярное произведение с
целью. Наименьший поворот, наводящий её на цель, — поворот на угол между
ними вокруг оси пушка × цель; этот угол прибавляется к сумме, а поворот,
построенный по формуле Родрига, накапливается в ориентации. Если пушка
уже смотрит на цель, поворот не нужен. `O(V² + n · V)` для V вершин.

Подводные камни:

- вектор атаки направлен к центру, так что цель — противоположное
  направление;
- поворот меняет ориентацию для всех следующих атак, так что повороты
  нужно компоновать, а не просто складывать их углы;
- векторы не обязаны быть единичными (тест 02).

Ответы совпадают с независимой принятой реализацией на 120 случайных
тестах, все с однозначно ближайшей пушкой.
