# 1653. 死亡传送带

[Timus 1653](https://acm.timus.ru/problem.aspx?space=1&num=1653) · 难度 5743 · geometry

原题作者 Pavel Atnashev，出自 NEERC 2008 东部分区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

空间站是以原点为中心的正多面体（五种柏拉图立体之一），每个顶点上有一门背离中心的炮。起初有一门炮指向
Oz，从它出发的一条棱位于 Oxz 平面的 x ≥ 0 半平面内。每次遭到攻击时，空间站旋转，使离来袭者最近的炮正对
它，并保持这个姿态直到下次攻击。求旋转角度的总和。

## 输入

立体的名称（tetrahedron、hexahedron、octahedron、dodecahedron 或 icosahedron），然后是 n
（1 ≤ n ≤ 100）和 n 个攻击向量，即舰船飞向中心的方向。最近的炮总是唯一确定的。

## 输出

总角度（弧度），保留小数点后 5 位。

## 样例

### 样例 1

输入：

```
tetrahedron
5
0.00000 0.00000 -1.00000
-1.00000 0.00000 1.00000
0.00000 0.00000 -1.00000
-1.00000 0.00000 1.00000
0.00000 0.00000 -1.00000
```

输出：

```
1.78225
```

## 解法

沿 v 飞向中心的舰船来自方向 −v。各立体的顶点取自经典坐标（立方体顶点，二十面体和十二面体用黄金比例
矩形）并单位化。为得到初始姿态，取一个顶点作为新的 z 轴，取一个相邻顶点去掉 z 分量后作为新的 x 轴；任何
顶点与邻点的选择都得到同一个空间站，因为立体的旋转把它们互相映射。

空间站的姿态用旋转矩阵保存。每次攻击时，与目标点积最大的炮就是最近的。把它对准目标的最小旋转是绕轴
“炮 × 目标”转过两者间的夹角；把这个角加入总和，并用罗德里格斯公式构造该旋转，与当前姿态复合。若炮已对准
目标则无需旋转。V 个顶点时为 `O(V² + n · V)`。

易错点：

- 攻击向量指向中心，所以目标是其反方向；
- 旋转会改变之后所有攻击时的姿态，所以必须复合旋转，而不能只累加角度；
- 向量不一定是单位长度（测试 02）。

在 120 个随机测试上（每个都有明确的最近炮），答案与一个独立的已通过实现一致。
