# 1662. Пусти козла в огород 6

[Timus 1662](https://acm.timus.ru/problem.aspx?space=1&num=1662) · сложность 4354 · geometry

Автор оригинальной задачи — Алексей Самсонов; Ural SU Contest, Петрозаводские зимние сборы, январь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Грядка с капустой — выпуклый многоугольник. Вне её нужно вбить колышек
и привязать к нему козу на верёвке длины R и козлёнка на верёвке длины
r так, чтобы коза доставала до любой точки грядки, а козлёнок — ни до
одной внутренней. Нужно вывести место для колышка, округлённое до 10⁻⁶,
или `No solution`.

## Входные данные

N (3 ≤ N ≤ 50), затем N вершин многоугольника по порядку — целые числа,
по модулю не больше 1000, затем целые r и R (1 ≤ r < R ≤ 1000).

## Выходные данные

Координаты колышка или `No solution`.

## Примеры

### Пример 1

Ввод:

```
4
0 0
0 1
1 1
1 0
1 3
```

Вывод:

```
0.500000 -1.000000
```

### Пример 2

Ввод:

```
3
0 0
0 14
2 7
8 10
```

Вывод:

```
No solution
```

Принимается любое подходящее место; для первого примера это решение
выводит другое.

## Решение

Коза достаёт до всей грядки ровно тогда, когда достаёт до каждой
вершины, так что колышек должен лежать в A — пересечении кругов радиуса
R вокруг вершин. Козлёнок не достаёт до внутренних точек ровно тогда,
когда колышек не ближе r к грядке, то есть вне внутренности B — грядки,
расширенной на r (её граница — рёбра, сдвинутые наружу на r, соединённые
дугами радиуса r вокруг вершин). И A, и B выпуклые.

Если какая-то точка A лежит вне внутренности B, то и какая-то точка
границы A тоже: достаточно двигаться от B перпендикулярно разделяющей
прямой, пока A не закончится. Каждый кусок границы A вне внутренности B
либо вся граница, содержащая угол, либо кончается на границе B, в том
числе при касании. Поэтому достаточно перебрать:

- все точки пересечения двух окружностей радиуса R;
- точки, где окружность радиуса R пересекает прямую, содержащую ребро,
  сдвинутое на r;
- точки, где окружность радиуса R пересекает окружность радиуса r
  вокруг вершины.

Каждый кандидат проверяется напрямую с допуском 10⁻⁷: не дальше R от
каждой вершины, вне грядки и не ближе r к каждому ребру. Выводится
первый подошедший. `O(N³)`.

Подводные камни:

- ответом может быть единственная точка, где всё впритык, например где
  встречаются три окружности радиуса R (тест 03) или ровно r от ребра и
  ровно R от вершины (тест 04); перебор только углов A и середин её дуг
  пропускает точки второго рода;
- вершины могут идти в любую сторону, от этого зависит, какая сторона
  ребра внешняя;
- чекер принимает любое место, выполняющее условия с точностью 10⁻⁵.

На случайных входах и на наименьшем целом R, при котором место
находится, для многих многоугольников ответы совпадают с независимой
принятой реализацией в том, есть ли место, кроме точного случая теста
04, где найденное здесь место проверено и подходит.
