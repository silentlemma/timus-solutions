# 1662. 放山羊进菜园 6

[Timus 1662](https://acm.timus.ru/problem.aspx?space=1&num=1662) · 难度 4622 · geometry

原题作者 Alex Samsonov，出自 2008 年 1 月彼得罗扎沃茨克冬季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一块卷心菜地是凸多边形。要在菜地外钉一根木桩，用长 R 的绳子拴一只山羊、长 r 的绳子拴一只小山羊，使山羊能
够到菜地的每一点，而小山羊够不到菜地的任何内部点。输出木桩的位置（精确到 10⁻⁶），或 `No solution`。

## 输入

N（3 ≤ N ≤ 50），然后按顺序给出多边形的 N 个顶点，都是绝对值不超过 1000 的整数，然后是 r 和 R
（1 ≤ r < R ≤ 1000）。

## 输出

木桩的坐标，或 `No solution`。

## 样例

### 样例 1

输入：

```
4
0 0
0 1
1 1
1 0
1 3
```

输出：

```
0.500000 -1.000000
```

### 样例 2

输入：

```
3
0 0
0 14
2 7
8 10
```

输出：

```
No solution
```

任何满足条件的位置都会被接受；对第一个样例，本解法输出的是另一个位置。

## 解法

山羊能够到整块菜地当且仅当它能够到每个顶点，所以木桩必须位于 A——以各顶点为圆心、半径为 R 的圆盘的交。
小山羊够不到内部当且仅当木桩到菜地的距离至少为 r，即位于 B 的内部之外，B 是菜地向外扩张 r 后的图形（边界由
向外平移 r 的各边和以顶点为圆心、半径为 r 的圆弧连接而成）。A 和 B 都是凸的。

如果 A 中某点位于 B 的内部之外，那么 A 的边界上也有这样的点：沿着把该点与 B 分开的直线，朝远离 B 的方向移动，
直到离开 A。A 的边界在 B 之外的部分由若干段组成，每段要么是整个边界，要么在 A 的边界与 B 的边界相交处结束。
所以只需尝试：

- A 的角点，即两个半径为 R 的圆的交点；
- 半径为 R 的圆与向外平移 r 的边的交点；
- 半径为 R 的圆与以顶点为圆心、半径为 r 的圆的交点。

每个候选点都直接检验，容差 10⁻⁷：到每个顶点不超过 R，在菜地之外，到每条边至少为 r。输出第一个通过的点。
`O(N³)`。

易错点：

- 答案可能是所有条件都恰好取等的唯一一点，例如三个半径为 R 的圆的公共点（测试 03），或者到某条边恰为 r、到某个
  顶点恰为 R 的点（测试 04）；只尝试 A 的角点和弧的中点的搜索会漏掉第二种；
- 顶点可能按任一方向给出，这决定了边的哪一侧是外侧；
- 检查器接受任何在 10⁻⁵ 内满足条件的位置。

在随机输入上，以及在许多多边形能找到位置的最小整数 R 上，关于是否存在位置，答案都与一个独立的已通过实现一致，
唯一的例外是测试 04 这种恰好取等的情形，这里找到的位置经过检验是有效的。
