# 1667. Квадратная страна 3

[Timus 1667](https://acm.timus.ru/problem.aspx?space=1&num=1667) · сложность 1878 · constructive

Автор оригинальной задачи — Иван Бурмистров (подготовка — Александр Ипатов); Ural SU Contest, Петрозаводские зимние сборы, январь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для каждого из T тестов заполнить таблицу N × M квадратами различных
целых положительных чисел, каждый не больше 10¹⁷, так чтобы сумма в
каждой строке и каждом столбце была квадратом; если это невозможно,
вывести `-1`. Таблицы разных тестов разделяются пустой строкой.

## Входные данные

T (1 ≤ T ≤ 20), затем T пар N M (1 ≤ N, M ≤ 20).

## Выходные данные

Таблицы или `-1`.

## Примеры

### Пример 1

Ввод:

```
3
1 2
3 1
2 2
```

Вывод:

```
9 16

1024
25
274576

4761 8464
627264 1115136
```

Принимается любая подходящая таблица; это решение выводит другие.

## Решение

Возьмём два списка различных целых положительных чисел a₁ … a_N и
b₁ … b_M, сумма квадратов каждого из которых — квадрат, и положим в
клетку (i, j) число (aᵢ·bⱼ)². Тогда сумма строки i равна aᵢ² · Σbⱼ² —
квадрат, умноженный на квадрат, и для столбцов так же. Таблица существует
всегда, и вся работа — найти списки с достаточно маленькими числами и
различными произведениями.

- Одно число: 1. Два числа: катеты пифагоровой тройки, m² − n² и 2mn.
- k + 1 чисел: для любых u₁ … u_k с S = Σuᵢ² подходят числа 2u₁, …,
  2u_k и S − 1, потому что 4S + (S − 1)² = (S + 1)². В роли u берутся
  арифметические прогрессии и отрезки подряд идущих простых чисел, а
  списки с повторяющимся числом отбрасываются.

Два произведения aᵢbⱼ и a_kb_l равны ровно тогда, когда
aᵢ / a_k = b_l / bⱼ, поэтому у списков не должно быть общих отношений.
Каждый список хранит множество своих несократимых отношений; для теста
решение перебирает пары списков по их наибольшим числам и берёт первую
пару с непересекающимися множествами отношений и
max(a) · max(b) ≤ √10¹⁷. Одни арифметические прогрессии на некоторых
больших размерах не справляются (у двух сторон находится общее
отношение), одни простые дают слишком большие числа, а вместе подходят
для всех 400 размеров, причём наибольшее произведение около 1,9 · 10⁸.
Примерно 200 списков-кандидатов до 20 чисел на размер — это несколько
сотен тысяч шагов на размер, `O(K · N²)` для K списков.

Подводные камни:

- при равных размерах нельзя дважды взять один и тот же список: его
  отношения совпадут;
- числа в таблице доходят примерно до 3,5 · 10¹⁶, нужны 64-битные целые.

Все 400 размеров проверены чекером, который проверяет различность,
ограничение и каждую строку и столбец.
