# 1667. 方形国 3

[Timus 1667](https://acm.timus.ru/problem.aspx?space=1&num=1667) · 难度 1878 · constructive

原题作者 Ivan Burmistrov（由 Alexander Ipatov 准备），出自 2008 年 1 月彼得罗扎沃茨克冬季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对 T 个测试中的每一个，用互不相同的正整数的平方填满一张 N × M 的表，每个数不超过 10¹⁷，使每行、每列的和都
是平方数；若不可能，输出 `-1`。不同测试的表之间用空行隔开。

## 输入

T（1 ≤ T ≤ 20），然后是 T 对 N M（1 ≤ N, M ≤ 20）。

## 输出

各张表，或 `-1`。

## 样例

### 样例 1

输入：

```
3
1 2
3 1
2 2
```

输出：

```
9 16

1024
25
274576

4761 8464
627264 1115136
```

任何满足条件的表都会被接受；本解法输出的是另外的表。

## 解法

取两个互不相同的正整数列表 a₁ … a_N 和 b₁ … b_M，各自的平方和都是平方数，在格子 (i, j) 中放 (aᵢ·bⱼ)²。
于是第 i 行的和为 aᵢ² · Σbⱼ²，是平方数乘平方数，各列同理。这样的表总是存在，工作在于找到数足够小、乘积互不
相同的列表。

- 一个数：1。两个数：勾股三元组的两条直角边 m² − n² 和 2mn。
- k + 1 个数：对任意 u₁ … u_k，令 S = Σuᵢ²，则 2u₁、…、2u_k 和 S − 1 满足条件，因为
  4S + (S − 1)² = (S + 1)²。u 取等差数列和连续素数段，有重复数的列表丢弃。

两个乘积 aᵢbⱼ 与 a_kb_l 相等当且仅当 aᵢ / a_k = b_l / bⱼ，所以两个列表不能有相同的比值。每个列表保存其既约
比值的集合；对每个测试，解法按最大数从小到大枚举列表对，取第一对比值集合不相交且 max(a) · max(b) ≤ √10¹⁷
的。只用等差数列时某些较大的尺寸会失败（两边总有某个相同的比值），只用素数时数又太大，两者合起来则全部 400 种
尺寸都能成功，最大乘积约为 1.9 · 10⁸。每个尺寸约有 200 个最多 20 个数的候选列表，每个尺寸几十万步，K 个列表
时为 `O(K · N²)`。

易错点：

- 尺寸相同时不能两次使用同一个列表：它的比值会重合；
- 表中的数可达约 3.5 · 10¹⁶，需要 64 位整数。

全部 400 种尺寸都用检查器验证过，检查器检查互不相同、上限以及每一行和每一列。
