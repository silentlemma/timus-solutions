# 1677. Обезьяна за клавиатурой

[Timus 1677](https://acm.timus.ru/problem.aspx?space=1&num=1677) · сложность 1586 · strings

Автор оригинальной задачи — Игорь Чевдарь; Ural SU Contest, Петрозаводские летние сборы, август 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждую секунду обезьяна набирает одну из первых N букв, все
равновероятны. Нужно найти математическое ожидание числа секунд до
появления заданного слова в набранном тексте, округлённое вниз.

## Входные данные

N (1 ≤ N ≤ 26), затем слово — строчные буквы из первых N, не больше
30000.

## Выходные данные

Ожидаемое время, округлённое вниз (оно и так целое).

## Примеры

### Пример 1

Ввод:

```
2
aa
```

Вывод:

```
6
```

### Пример 2

Ввод:

```
2
ba
```

Вывод:

```
4
```

## Решение

Ответ — сумма N^k по всем k, при которых первые k букв слова совпадают
с последними k (это грани слова), включая всё слово. Для aa при N = 2 это
2 + 4 = 6, для ba — просто 4.

Почему так, объясняет рассуждение со ставками. Перед каждой секундой
приходит новый игрок с одной монетой и ставит всё по честной ставке N к
1 на то, что следующей будет первая буква слова; выиграв, ставит всё на
вторую букву и так далее. Игра честная, поэтому в момент первого
появления слова суммарный выигрыш игроков минус принесённые монеты
имеет нулевое ожидание. В этот момент в игре остаются ровно те, кто
начал с грани слова, у каждого N^k для грани длины k, а каждая секунда
принесла одну монету. Значит, ожидаемое время равно сумме N^k.

Грани даёт префикс-функция: самая длинная грань слова, самая длинная
грань её и так далее. Сумма в системе по основанию N состоит только из
цифр 0 и 1, поэтому строится по схеме Горнера от старшей цифры; в ней до
примерно 42 500 десятичных цифр. `O(L²)` операций над разрядами числа,
`O(L)` на грани.

Подводные камни:

- ответ — огромное точное целое (тест 05), нужна длинная арифметика;
  числа с плавающей точкой здесь бесполезны;
- при N = 1 время равно просто длине слова (тест 03).

Ответы совпадают с точным решением уравнений ожидания для всех слов до
длины 5 над не более чем тремя буквами и с независимой принятой
реализацией.

## Особенности языков

- C++ и Rust считают сами в разрядах по основанию 10⁹: каждый шаг
  умножает на N и прибавляет одну цифру.
- Python снимает ограничение на перевод огромных целых в текст через
  sys.set_int_max_str_digits(0).
