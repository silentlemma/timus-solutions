# 1622. Эндшпиль

[Timus 1622](https://acm.timus.ru/problem.aspx?space=1&num=1622) · сложность 3122 · backtracking

Оригинальная задача — SPbSU ITMO Contest, Петрозаводские сборы, зима 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Солитер на крестообразной доске из 33 клеток (квадрат 7 × 7 без угловых
квадратов 2 × 2, столбцы A–G, строки 1–7): 32 фишки занимают все клетки,
кроме центральной D4. Ход — фишка перепрыгивает по горизонтали или
вертикали через соседнюю фишку на пустую клетку, перепрыгнутая фишка
снимается. По клетке выведите 31 ход, после которых единственная фишка
стоит ровно там, или `Impossible`.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Клетка последней фишки.

## Выходные данные

31 ход `from-to`, по одному в строке, или `Impossible`.

## Решение

Какие клетки возможны, следует из инварианта. Разобьём клетки на три
класса по (r + c) mod 3. Прыжок затрагивает три подряд идущие клетки
линии, по одной каждого класса, и меняет число фишек каждого класса на
единицу, так что все три чётности меняются. То же верно для классов
(r − c) mod 3. После 31 прыжка чётности определены, а значит, определены
оба остатка последней фишки и тем самым r и c по модулю 3: они должны
совпадать с центром, который достижим. На доске остаются только D4, D1,
D7, A4 и G4; любая другая клетка — `Impossible`.

Ходы находит поиск в глубину по доске как 33-битной маске, запоминающий
уже найденные тупиковые позиции. Поиск для D4 или D7 занимает доли
секунды, а для D1 напрямую — намного дольше; но начальная позиция
симметрична, так что A4, D1 и G4 — это D7, повёрнутая на четверти
оборота: ищем D7 и поворачиваем каждый ход ответа.

Подводные камни:

- ходы из примера — лишь один из ответов; чекер проигрывает ходы;
- клетка рядом с центром (D3) уже невозможна.
