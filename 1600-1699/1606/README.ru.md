# 1606. Слалом

[Timus 1606](https://acm.timus.ru/problem.aspx?space=1&num=1606) · сложность 714 · greedy

## Задача

На склоне стоят до 50000 флажков, у всех разные x и разные y. Петя
спускается от линии старта y = 100000 до линии финиша y = 0 по
ломаной с вершинами во флажках, всё время вниз, и должен менять
направление налево/направо на каждом флажке, которого касается; мимо
флажка можно и проехать по прямой, не касаясь. Нужно коснуться как
можно большего числа флажков и вывести их по порядку. Подходит любой
лучший список.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n, затем координаты флажков.

## Выходные данные

Количество флажков, затем их номера в порядке касания.

## Примеры

### Пример 1

Ввод:

```
5
5 2
6 5
1 1
4 3
2 4
```

Вывод:

```
4
2 5 4 3
```

### Пример 2

Ввод:

```
4
1 6
3 4
5 2
4 1
```

Вывод:

```
3
1 3 4
```

## Решение

Лыжник всегда едет вниз, так что флажки, которых он касается, идут по
убыванию y. В таком порядке их координаты x должны идти зигзагом: каждый
шаг уходит вбок в другую сторону, чем предыдущий. На линию старта и
финиша можно выйти в любой точке, так что первый и последний шаги ничего
не ограничивают. Задача — самая длинная зигзагообразная
подпоследовательность координат x.

Разобьём отсортированную последовательность на максимальные отрезки, на
которых x только растёт или только убывает. Первый флажок, флажок, где
поворачивает каждый отрезок, и последний флажок дают зигзаг на один
флажок длиннее числа отрезков, и длиннее зигзага не бывает: каждому его
шагу нужен свой отрезок. После сортировки это один проход:
`O(n log n)`.

Тесты проверяет чекер, который принимает любой список нужной длины, идущий
вниз и поворачивающий на каждом флажке. Длина сверена с полным перебором
всех подмножеств до 8 флажков.

Подводные камни:

- ответ не единственный: в первом примере третьим может быть флажок с
  x = 4 или x = 5, и вывод может отличаться от примера;
- один флажок — тоже допустимый спуск с одним касанием (тест 03);
- если x вниз по склону только растёт, коснуться можно лишь первого и
  последнего флажка (тест 05).
