# 1606. 回转滑雪

[Timus 1606](https://acm.timus.ru/problem.aspx?space=1&num=1606) · 难度 714 · greedy

原题作者 Alexander Toropov，由 Alexander Ipatov 准备，出自 2008 年 3 月 1 日第九届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

山坡上插着最多 50000 面旗，所有旗的 x 互不相同，y 也互不相同。Petya 从起点线 y = 100000 滑到终点线 y = 0，
路线是以旗为顶点的折线，始终向下，并且在碰到的每面旗处都必须改变左右方向；也可以直线经过旗而不碰它。
要碰到尽可能多的旗，并按顺序输出它们。任何最优列表都可接受。

时间限制：1 秒。内存限制：64 MB。

## 输入

n，然后是各面旗的坐标。

## 输出

旗的数量，然后按碰到的顺序给出编号。

## 样例

### 样例 1

输入:

```
5
5 2
6 5
1 1
4 3
2 4
```

输出:

```
4
2 5 4 3
```

### 样例 2

输入:

```
4
1 6
3 4
5 2
4 1
```

输出:

```
3
1 3 4
```

## 解法

滑雪者始终向下，所以碰到的旗按 y 递减排列。按这个顺序，它们的 x 坐标必须呈锯齿状：每一步横向方向都与前一步相反。
起点线和终点线上的任何一点都可以到达，所以第一步和最后一步没有限制。问题就是 x 坐标的最长锯齿子序列。

把排序后的序列划分成 x 只增或只减的极长段。取第一面旗、每段转折处的旗以及最后一面旗，得到比段数多一面旗的锯齿序列；
而锯齿序列不可能更长，因为它的每一步都需要一个单独的段。排序后只需扫一遍：`O(n log n)`。

测试使用检查器，接受任何长度正确、向下且在每面旗处转向的列表。长度已在所有不超过 8 面旗的子集上与穷举搜索对照。

注意事项：

- 答案不唯一：第一个样例中第三面旗可以是 x = 4 或 x = 5 的那面，输出可能与样例不同；
- 只有一面旗时，碰一次也是合法的下滑（测试 03）；
- 若沿坡向下 x 一直增大，只能碰到第一面和最后一面旗（测试 05）。
