# 1689. Рыболов и штанга

[Timus 1689](https://acm.timus.ru/problem.aspx?space=1&num=1689) · сложность 915 · prefix_sums

Автор оригинальной задачи — Станислав Васильев; X открытое личное первенство УрГУ, 28 февраля 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В жёлобе длины g лежат n червяков длины w, не наползающих друг на
друга. У штанги общей длины b на каждом конце блин ширины p. Червяк
повреждён, если хоть какая-то его часть оказывается под блином.
Положить штангу в жёлоб так, чтобы повредить как можно меньше
червяков, а среди таких мест выбрать самое левое.

## Входные данные

g и w (1 ≤ w ≤ g ≤ 100000), b и p (1 ≤ p ≤ b/2 ≤ g/2), n
(1 ≤ n ≤ 100000), затем левые концы червяков, от 0 до g − w. Все
величины целые.

## Выходные данные

Расстояние от левого края жёлоба до левого края штанги.

## Примеры

### Пример 1

Ввод:

```
1000 4
500 60
10
47 68 22 237 585 417 666 996 888 555
```

Вывод:

```
149
```

### Пример 2

Ввод:

```
20 1
2 1
11
1 2 3 4 6 8 10 12 14 16 19
```

Вывод:

```
17
```

## Решение

Блин [a, a + p] повреждает червяка [x, x + w], если они перекрываются
на положительную длину: a < x + w и a + p > x. Простое касание не
вредит, как показывает второй пример. Для целых это значит
x − p + 1 ≤ a ≤ x + w − 1. Левый блин начинается в позиции штанги s,
а правый — в s + b − p, поэтому каждый червяк повреждается при двух
отрезках значений s. Все концы целые, так что среди лучших мест всегда
есть целое s.

Прибавим +1 на обоих отрезках в разностном массиве по
s = 0, …, g − b и −1 на их пересечении, чтобы червяк под обоими
блинами считался один раз. Префиксные суммы дают число повреждённых
червяков для каждого s. Берём первый минимум. `O(n + g)`.

Подводные камни:

- касание не вредит червяку, поэтому отрезки открыты с обоих концов
  (пример 2);
- длинный червяк может лежать сразу под обоими блинами; двойной счёт
  меняет ответ в тесте 04;
- отрезки обрезаются до 0, …, g − b; при b = g есть только s = 0
  (тест 03).

Ответы совпадают с прямым подсчётом для каждой позиции на 150
маленьких тестах и с независимой принятой реализацией.
