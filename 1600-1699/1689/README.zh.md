# 1689. 渔夫与杠铃

[Timus 1689](https://acm.timus.ru/problem.aspx?space=1&num=1689) · 难度 915 · prefix_sums

原题作者 Stanislav Vasilyev，出自 2009 年 2 月 28 日第十届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

长为 g 的槽里有 n 条长为 w、互不重叠的虫子。总长为 b 的杠铃两端各有一片宽 p 的杠铃片。
虫子只要有一部分在杠铃片下面就算受伤。把杠铃放进槽里，使受伤的虫子尽量少，并在这些位置中取最靠左的。

## 输入

g 和 w（1 ≤ w ≤ g ≤ 100000），b 和 p（1 ≤ p ≤ b/2 ≤ g/2），n（1 ≤ n ≤ 100000），
然后是各虫子的左端，范围 0 到 g − w。所有数都是整数。

## 输出

槽左端到杠铃左端的距离。

## 样例

### 样例 1

输入：

```
1000 4
500 60
10
47 68 22 237 585 417 666 996 888 555
```

输出：

```
149
```

### 样例 2

输入：

```
20 1
2 1
11
1 2 3 4 6 8 10 12 14 16 19
```

输出：

```
17
```

## 解法

杠铃片 [a, a + p] 与虫子 [x, x + w] 重叠长度为正时才会伤到它：a < x + w 且 a + p > x。
仅仅接触不算，第二个样例说明了这一点。对整数而言即 x − p + 1 ≤ a ≤ x + w − 1。
左片从杠铃位置 s 开始，右片从 s + b − p 开始，所以每条虫子对应 s 的两个区间。
所有端点都是整数，所以最优位置中总有整数 s。

在 s = 0, …, g − b 上的差分数组里对两个区间各加 +1，并在它们的交集上加 −1，
使同时位于两片之下的虫子只计一次。前缀和给出每个 s 的受伤虫子数，取第一个最小值。`O(n + g)`。

注意事项：

- 接触不伤虫子，所以区间两端都是开的（样例 2）；
- 一条长虫子可能同时在两片之下；重复计数会改变测试 04 的答案；
- 区间要截到 0, …, g − b；当 b = g 时只有 s = 0（测试 03）。

答案与 150 个小测试上对每个位置的直接计数一致，也与一个独立的已通过实现一致。
