# 1693. Задача Лойда

[Timus 1693](https://acm.timus.ru/problem.aspx?space=1&num=1693) · сложность 9125 · constructive

Авторы оригинальной задачи — Сэм Лойд и Игорь Чевдарь; Ural SU Contest, Петрозаводские зимние сборы, февраль 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Распилить шахматную доску n × n по линиям сетки на как можно большее
число связных частей так, чтобы никакие две части не совпадали. Части,
отличающиеся только поворотом, одинаковы, но цвета клеток важны:
чёрная и белая клетки — две разные части.

## Входные данные

n (1 ≤ n ≤ 30).

## Выходные данные

Число частей, затем n строк по n строчных латинских букв. Каждая часть
записана одной буквой, соседние части — разными. Подходит любое
оптимальное разрезание.

## Примеры

### Пример 1

Ввод:

```
8
```

Вывод:

```
18
aaaacaaa
bbbcccba
baddabbb
aacdacba
accdacaa
babdccbb
baaadbba
babbaaaa
```

## Решение

**Граница.** Посчитаем цветные фигуры каждой площади с точностью до
поворота: площади 1 — 2, площади 2 — 1, площади 3 — 4, площади 4 — 10,
площади 5 — 36, площади 6 — 110, площади 7 — 392. Суммарная площадь
различных частей не меньше суммы k наименьших из этих площадей,
поэтому k не больше наибольшего числа, для которого сумма наименьших
площадей помещается в n². Для n = 8 это 2 + 1 + 4 + 10 = 17 фигур
площади до 4, всего 56 клеток, и ещё одна часть из оставшихся 8 клеток —
итого 18.

**Построение.** Граница достигается для каждого допустимого n подходящей
упаковкой различных цветных фигур. Однако точно упаковать до 163 фигур
в квадрат — тяжёлый перебор. Поэтому разрезания для всех 30 размеров
были найдены один раз заранее случайным поиском в глубину с
перезапусками, а программа
печатает сохранённую доску для данного n. `O(n²)`.

Каждая сохранённая доска проверена независимо. Её однобуквенные области —
связные части, все различные с точностью до поворота с учётом цветов,
и их число равно границе выше. Количества фигур по площадям
пересчитаны перебором полимино.

Подводные камни:

- цвета важны, поэтому одиночных клеток две, а не одна;
- отражения не считаются одинаковыми, только повороты;
- одну букву можно повторять у частей без общей стороны.

Чекер восстанавливает части по буквам и проверяет их число и попарные
различия.
