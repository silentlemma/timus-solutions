# 1698. Квадратная страна 5

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Посчитать положительные числа не более чем из n цифр без ведущих
нулей, квадрат которых оканчивается самим числом, как 76² = 5776.

## Входные данные

n (1 ≤ n ≤ 2000).

## Выходные данные

Количество.

## Примеры

### Пример 1

Ввод:

```
1
```

Вывод:

```
3
```

## Решение

d-значное число x подходит, когда x² ≡ x (mod 10ᵈ), то есть когда
x(x − 1) делится и на 2ᵈ, и на 5ᵈ. Числа x и x − 1 взаимно просты,
поэтому каждая степень простого делит одно из них, и получаются четыре
остатка по модулю 10ᵈ: 0, 1 и два смешанных. Смешанные остатки — это
последние d цифр двух бесконечных 10-адических чисел, …890625 и
…109376. Их цифры, кроме последней, в каждом разряде дают в сумме 9,
потому что сами числа в сумме дают 1 (mod 10ᵈ).

Значит, для каждой длины d кандидаты — 1 (только при d = 1) и два
окончания длины d, которые подходят, если их старшая цифра, d-я цифра
бесконечного числа, не 0. Запишем число с окончанием 5 как
x = Σ xᵢ 10ⁱ: цифра d в x² — это сумма xᵢ·xⱼ по i + j = d плюс перенос
снизу. Новая цифра c входит в эту сумму как 2·5·c, кратное 10, поэтому
c обязана равняться (остальные произведения + перенос) mod 10, а
следующий перенос получается сразу. У числа с окончанием 6 в этом
разряде цифра 9 − c, и она подходит при c ≠ 9. `O(n²)` произведений
цифр, без длинной арифметики.

Подводные камни:

- 1 подходит (1² = 1), а 0 не положительно;
- окончания с ведущим нулём, как 0625 при d = 4, не считаются
  (тест 04);
- два бесконечных числа связаны: одно равно 1 минус другое, так что
  одна и та же цифра решает за оба.

Ответы совпадают с независимой принятой реализацией для всех
проверенных n до 2000.
