# 1649. 抽象主义走向大众

[Timus 1649](https://acm.timus.ru/problem.aspx?space=1&num=1649) · 难度 6963 · backtracking

原题作者 Eugene Krokhalev，出自 NEERC 2008 东部分区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n × m 的画布起初是空的。细菌一次放一个，每个放进一个空格；新放入的细菌使每个已有细菌的相邻格（上、下、
左、右）的数量加一，达到 5 的格子回到 1。给定最终数量（每格 1 到 4），求一个能得到它们的放置所有格子
的顺序，或指出不存在。

## 输入

n 和 m（1 ≤ n, m ≤ 20），然后是 n 行，每行 m 个 1 到 4 的数。

## 输出

`No`，或 `Yes` 以及按放置顺序列出的格子，每行一个“行 列”。任何合法顺序都被接受。

## 样例

### 样例 1

输入：

```
3 3
2 2 1
3 1 3
1 2 2
```

输出：

```
Yes
2 2
2 1
1 1
1 2
2 3
1 3
3 3
3 2
3 1
```

## 解法

格子从 1 开始，每有一个邻居在它之后放置就加一，模 4。所以一个顺序合法，当且仅当每个格子 v 之后放置的
邻居数等于 need(v) − 1，而该数介于 0 和 deg(v) 之间。它总是确定的，只有一种例外：显示 1 的内部格子
（四个邻居）之后的邻居可以是 0 个或 4 个。

从顺序的两端剥离。若一个格子的所有未放邻居都必须在它之后，就可以把它移到任何合法顺序的最前面而不破坏
顺序，所以它最先放置并移除。同理，不能有更晚未放邻居的格子最后放置；它的邻居随之少期待一个更晚的邻居，
模 4。每次移除都可能让更多格子变成被迫的，所以用队列继续剥离；而要求的更晚邻居多于剩余邻居的格子说明
图画不可能。画布上互不相连的部分分别求解。

当没有被迫的格子时，任何合法顺序的第一个格子仍然所有邻居都在它之后，所以它必然是某个显示 1 的不确定内部
格子。这样的格子在任何合法顺序中要么在所有邻居之前，要么在所有邻居之后，因此只对其中一个分支（最先或
最后）进行搜索不会遗漏。两个计数检查用于剪枝：更晚邻居数之和必须等于边数，这确定了有多少不确定格子排在
前面；相邻的不确定格子必须交替（两个“最先”或两个“最后”不能相邻），所以每组提供它两种棋盘颜色之一，对
各组做子集和就能判断所需数目是否可达。实际中无论哪个分支都会引发一连串被迫移动，所以搜索极小。最坏指数
级，每个分支线性剥离。

易错点：

- 只有内部的 1 是不确定的；边上的 1 总是在其未放邻居中最后；
- 在一个邻居最后放置后，数 1 会绕回 4（还要四个更晚邻居，或一个也不要）；
- 即使所有数都在范围内，答案也可能是 `No`，例如 2 × 2 的全 1 方块（测试 07）。

检查器重放顺序；在 400 个随机和特意构造的画布上（包括所有内部格子都显示 1 的棋盘顺序），答案的 Yes 或
No 与一个独立的已通过实现一致，并且能通过检查器。
