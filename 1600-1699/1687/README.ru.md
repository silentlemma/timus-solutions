# 1687. Занимательная нумизматика

[Timus 1687](https://acm.timus.ru/problem.aspx?space=1&num=1687) · сложность 1279 · greedy

Оригинальную задачу подготовил Владимир Яковлев, особая благодарность Владиславу Исенбаеву; X открытое личное первенство УрГУ, 28 февраля 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Коробочки с монетами после скидки стоят по 100 йен, а набор коробочек
стоит для покупателя по 100 йен за каждую различную нужную монету в
нём. Найти самый большой набор коробочек, в каждой из которых есть
нужная монета, цена которого не превосходит его ценности.

## Входные данные

n (1 ≤ n ≤ 100) видов монет и k (1 ≤ k ≤ 50) коробочек, затем каждая
коробочка — размер и различные монеты, затем m нужных монет.

## Выходные данные

Число коробочек и их номера. Подходит любой самый большой набор.

## Примеры

### Пример 1

Ввод:

```
10 4
5 2 7 6 1 3
6 6 7 10 2 9 4
5 1 8 3 9 2
5 4 3 7 6 1
4 8 5 4 9
```

Вывод:

```
3
2 3 4
```

## Решение

Назовём коробочку полезной, если в ней есть нужная монета, а нужную
монету — доступной, если она есть в какой-то коробочке. Набор S
полезных коробочек должен удовлетворять |S| ≤ (нужных монет в S),
поэтому |S| не больше числа доступных монет и, конечно, не больше
числа полезных коробочек.

Меньшее из двух достижимо. Для каждой доступной монеты, ещё не
покрытой, берём любую коробочку с ней: так уходит не больше одной
коробочки на монету, и покрываются все доступные монеты. Затем
добавляем другие полезные коробочки, пока их число не превышает числа
доступных монет. Набор стоит все доступные монеты и содержит
min(полезных, доступных) коробочек. `O(k · n)` с множествами монет.

Подводные камни:

- ответ может быть больше максимального паросочетания между
  коробочками и монетами: коробочки {1, 2, 3}, {1}, {1}, {1} при нужных
  монетах 1, 2, 3 позволяют взять три коробочки, хотя сопоставить
  можно только две (тест 03);
- коробочки без нужных монет не учитываются (тест 04);
- если ни в одной коробочке нет нужной монеты, ответ — 0 и пустой
  список.

Чекер принимает любой набор ожидаемого размера, который окупается.
Ответы совпадают с полным перебором наборов коробочек на маленьких
тестах и с независимой принятой реализацией.
