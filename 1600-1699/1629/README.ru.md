# 1629. Перелёт

[Timus 1629](https://acm.timus.ru/problem.aspx?space=1&num=1629) · сложность 792 · simulation

Автор оригинальной задачи — Алексей Самсонов; XIII открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Путешественнику нужно пролететь через аэропорты 1, 2, …, N, всегда из
аэропорта i в аэропорт i + 1; ровно в полночь он в аэропорту 1. Каждый
день из аэропорта i вылетают Q_i рейсов по неизменному расписанию, но
отныне каждый вылетает на D_i минут позже; полёт до аэропорта i + 1
длится T_i минут, пересадка мгновенная. Через сколько минут
путешественник окажется в аэропорту N?

## Входные данные

В первой строке N (2 ≤ N ≤ 100). Далее аэропорты 1…N − 1 описаны двумя
строками каждый: Q_i, D_i и T_i (1 ≤ Q_i ≤ 10; 0 ≤ D_i, T_i < 1440),
затем Q_i времён вылета по расписанию в формате HH:MM.

## Выходные данные

Число минут после полуночи, когда путешественник приземлится в
аэропорту N.

## Примеры

### Пример 1

Ввод:

```
3
2 60 1200
00:00 01:00
2 0 300
20:30 21:30
```

Вывод:

```
1590
```

### Пример 2

Ввод:

```
3
1 0 600
10:00
1 60 60
19:00
```

Вывод:

```
1260
```

## Решение

Ждать дольше никогда не выгодно, поэтому в каждом аэропорту берётся
первый рейс, вылетающий не раньше прибытия. Рейс по расписанию HH:MM
сегодня вылетает в 60 · HH + MM + D_i минут, а в следующие дни — на целое
число раз по 1440 позже; если он уже улетел, разность, округлённая
вверх до целых суток, даёт его следующий вылет. Самый ранний из Q_i
вариантов плюс T_i — прибытие в следующий аэропорт. `O(ΣQ_i)`.

Подводные камни:

- на рейс, вылетающий ровно в минуту прибытия, успеть можно (второй
  пример);
- задержки действуют с полуночи, так что вчерашний вечерний рейс не
  переносится на сегодня: при задержке 120 минут рейс в 23:00 вылетает
  в 25:00, а не в 01:00 (тест 06);
- с задержкой сегодняшний рейс может вылететь уже после следующей
  полуночи; это всё равно самый ранний его вылет (тест 04).

Ответы совпадают с независимой принятой реализацией на 150 случайных
маршрутах.
