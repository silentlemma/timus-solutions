# 1629. 旅程

[Timus 1629](https://acm.timus.ru/problem.aspx?space=1&num=1629) · 难度 792 · simulation

原题作者 Alex Samsonov，出自第十三届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

旅行者要依次飞过机场 1, 2, …, N，每次从机场 i 飞到机场 i + 1，午夜零点整时身在机场 1。
每天从机场 i 起飞 Q_i 个航班，时刻表固定不变，但从现在起每个航班都晚 D_i 分钟起飞；飞到
机场 i + 1 需要 T_i 分钟，转机不花时间。问旅行者多少分钟后到达机场 N？

## 输入

第一行为 N（2 ≤ N ≤ 100）。接着机场 1 到 N − 1 各用两行描述：Q_i、D_i、T_i
（1 ≤ Q_i ≤ 10；0 ≤ D_i, T_i < 1440），然后是 Q_i 个按时刻表的起飞时间，格式为 HH:MM。

## 输出

旅行者在机场 N 降落时距午夜的分钟数。

## 样例

### 样例 1

输入：

```
3
2 60 1200
00:00 01:00
2 0 300
20:30 21:30
```

输出：

```
1590
```

### 样例 2

输入：

```
3
1 0 600
10:00
1 60 60
19:00
```

输出：

```
1260
```

## 解法

多等永远没有好处，所以在每个机场都搭乘不早于到达时刻起飞的第一个航班。时刻表上 HH:MM 的
航班今天在 60 · HH + MM + D_i 分钟起飞，之后每天推迟 1440 的整数倍；如果它已经飞走，把差值
向上取整到整天就得到它下一次起飞的时间。Q_i 个候选中最早的那个加上 T_i，就是到达下一个机场
的时间。`O(ΣQ_i)`。

易错点：

- 恰好在到达那一分钟起飞的航班仍然赶得上（第二个样例）；
- 延误从午夜才开始生效，所以昨晚的航班不会挪到今天：延误 120 分钟时，23:00 的航班在 25:00
  起飞，而不是 01:00（测试 06）；
- 加上延误后，今天的航班可能在第二天午夜之后才起飞，那仍是它最早的一班（测试 04）。

在 150 条随机航线上，答案与一个独立的已通过实现一致。
