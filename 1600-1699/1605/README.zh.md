# 1605. 魔鬼数列

[Timus 1605](https://acm.timus.ru/problem.aspx?space=1&num=1605) · 难度 611 · math

原题作者 Alexander Ipatov，出自 2008 年 3 月 1 日第九届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

x₀ = 0，x₁ = 1，xₙ = (xₙ₋₁ + xₙ₋₂)/2。对 2 ≤ n ≤ 100000，求 xₙ 的十进制表示小数点后以多少个 6 开头。
例如 x₁₀ = 0.666015625 以三个 6 开头。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

n。

## 输出

开头 6 的个数。

## 样例

### 样例 1

输入:

```
10
```

输出:

```
3
```

## 解法

递推的特征根为 1 和 −1/2，代入初值得 xₙ = 2/3 − (−1)ⁿ·(2/3)·2⁻ⁿ。由于 2/3 = 0.666…，一切取决于 xₙ 与 2/3
的距离以及在哪一侧。

一个数恰以 k 个 6 开头，当且仅当它落在 [0.6…6, 0.6…6 + 10⁻ᵏ)（k 个 6）中，即介于 2/3 − (2/3)·10⁻ᵏ 和
2/3 + (1/3)·10⁻ᵏ 之间。n 为偶数时 xₙ 比 2/3 小 (2/3)·2⁻ⁿ，所以只要 10ᵏ ≤ 2ⁿ 就保有 k 个 6。n 为奇数时 xₙ
比 2/3 大同样的量，所以只要 2·10ᵏ < 2ⁿ，即 10ᵏ ≤ 2ⁿ⁻¹（n ≥ 2 时不可能取等）。两种情况下答案都是
⌊m·log₁₀ 2⌋，其中 m = n 或 n − 1，也就是 2ᵐ 的十进制位数减一：`O(1)`。

公式已在 n < 200 时与精确分数的十进制展开对照，并与 2ᵐ 的位数对照。

注意事项：

- 在哪一侧很重要：x₃ = 0.75 没有 6，而 x₄ = 0.625 有一个，所以奇数 n 要用 2ⁿ⁻¹ 而不是 2ⁿ；
- m·log₁₀ 2 可能接近整数，但 n 不超过 10⁵ 时距离不小于 1.5·10⁻⁵（n = 28738），远大于 double 的舍入误差（测试 08 至 10）；
- 用浮点数模拟 xₙ，大约 50 步后就丢失了与 2/3 的差，远远到不了 n = 100000。
