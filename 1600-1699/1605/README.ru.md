# 1605. Дьявольская последовательность

## Задача

x₀ = 0, x₁ = 1 и xₙ = (xₙ₋₁ + xₙ₋₂)/2. Для 2 ≤ n ≤ 100000 нужно
определить, со скольких шестёрок после запятой начинается десятичная
запись xₙ. Например, x₁₀ = 0.666015625 начинается с трёх.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

n.

## Выходные данные

Количество начальных шестёрок.

## Примеры

### Пример 1

Ввод:

```
10
```

Вывод:

```
3
```

## Решение

У рекурренты характеристические корни 1 и −1/2, а начальные значения
дают xₙ = 2/3 − (−1)ⁿ·(2/3)·2⁻ⁿ. Поскольку 2/3 = 0.666…, всё решают
расстояние от xₙ до 2/3 и сторона.

Число начинается ровно с k шестёрок, когда лежит в [0.6…6, 0.6…6 + 10⁻ᵏ)
с k шестёрками, то есть между 2/3 − (2/3)·10⁻ᵏ и 2/3 + (1/3)·10⁻ᵏ. При
чётном n xₙ меньше 2/3 на (2/3)·2⁻ⁿ, так что k шестёрок сохраняются,
пока 10ᵏ ≤ 2ⁿ. При нечётном n xₙ больше на ту же величину, так что они
сохраняются, пока 2·10ᵏ < 2ⁿ, то есть 10ᵏ ≤ 2ⁿ⁻¹ (равенство при n ≥ 2
невозможно). В обоих случаях ответ — ⌊m·log₁₀ 2⌋ при m = n или n − 1, на
единицу меньше числа десятичных цифр 2ᵐ: `O(1)`.

Формула сверена с десятичной записью точных дробей при n < 200 и с
числом цифр 2ᵐ.

Подводные камни:

- сторона важна: у x₃ = 0.75 нет шестёрки, а у x₄ = 0.625 одна, так что
  нечётным n нужно 2ⁿ⁻¹ вместо 2ⁿ;
- m·log₁₀ 2 может подходить близко к целому, но при n до 10⁵ не ближе
  1,5·10⁻⁵ (n = 28738), что гораздо больше ошибки округления double
  (тесты 08–10);
- моделирование xₙ в вещественных числах теряет отличие от 2/3 уже
  примерно через 50 шагов, задолго до n = 100000.
