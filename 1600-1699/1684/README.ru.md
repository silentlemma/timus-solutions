# 1684. Последнее слово Джека

[Timus 1684](https://acm.timus.ru/problem.aspx?space=1&num=1684) · сложность 266 · strings

Автор оригинальной задачи — Дмитрий Иванков; X открытое личное первенство УрГУ, 28 февраля 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны слово и второе слово. Разбить второе слово на части, каждая из
которых — непустой префикс первого, или сообщить, что это невозможно.

## Входные данные

Два слова по одному в строке, непустые, из строчных латинских букв,
длиной не больше 75000.

## Выходные данные

No и на следующей строке части через пробел, если разбиение есть;
иначе Yes. Подходит любое верное разбиение.

## Примеры

### Пример 1

Ввод:

```
abracadabra
abrabracada
```

Вывод:

```
No
abr abracad a
```

### Пример 2

Ввод:

```
abracadabra
arbadacarba
```

Вывод:

```
Yes
```

## Решение

Пусть z[p] — длина самого длинного префикса первого слова,
начинающегося в позиции p второго: Z-функция строки
word + "#" + last даёт их все за линейное время. От разреза в p
следующая часть может закончиться в любой из позиций p + 1, …, p + z[p],
ведь любой более короткий префикс тоже подходит. Поэтому достижимые
разрезы всегда образуют целый отрезок 0, …, reach: идём по p от 0, пока
p ≤ reach, и расширяем reach до p + z[p]. Каждый новый разрез q
запоминает p, который его покрыл, и проход по этим ссылкам от конца
даёт части.

Если проход остановился раньше конца второго слова, ответ Yes.
`O(m + n)` для слов длины m и n.

Подводные камни:

- брать каждый раз самый длинный префикс нельзя: для aab и aaab жадное
  aa оставляет ab, а a + aab подходит (тест 06);
- слова ответа перевёрнуты: No означает, что разбиение есть;
- строка ответа содержит до 75000 частей, её лучше собрать целиком.

Чекер сверяет вердикт с независимой принятой реализацией и проверяет,
что части — префиксы, складывающиеся в слово.
