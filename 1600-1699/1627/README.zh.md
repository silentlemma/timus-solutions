# 1627. 连通

[Timus 1627](https://acm.timus.ru/problem.aspx?space=1&num=1627) · 难度 1093 · math

原题出自 2008 年冬季彼得罗扎沃茨克集训的 SPbSU ITMO Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

房子是 n × m 的房间网格（1 ≤ n, m ≤ 9），每个房间是卧室 `.` 或储藏室 `*`，至少有一间
卧室。门只能装在有公共墙的卧室之间。求装门的方案数，使任意两间卧室之间恰有一条路径，
结果模 10⁹。

时间限制：4 秒。内存限制：64 MB。

## 输入

n 和 m，然后是地图的 n 行。

## 输出

方案数模 10⁹。

## 样例

### 样例 1

输入：

```
2 2
..
..
```

输出：

```
4
```

### 样例 2

输入：

```
2 2
*.
.*
```

输出：

```
0
```

## 解法

任意两间卧室之间恰有一条路径，意味着门构成卧室图的一棵生成树。根据基尔霍夫矩阵树定理，
生成树的个数等于拉普拉斯矩阵（对角线为度数，每对相邻卧室为 −1）去掉一行一列后的行列式；
图不连通时它为 0。最多 81 间卧室时，这是一个 80 × 80 的行列式。

答案要模 10⁹，而它不是素数，所以普通的模 10⁹ 消元无法除以主元。按行做欧几里得算法却
可以：要消去主元下方的元素，就从主元行减去该行的适当倍数，再交换两行，像求最大公约数
那样，直到该元素变为 0。只用到减法、乘法和交换，所以一切在模 10⁹ 下都成立；每次交换使
符号取反。v 间卧室时为 `O(v³ log M)`。Python 改用 Bareiss 消元，进行 `O(v³)` 次大整数运算，除法均为整除，
最后再取余。

易错点：

- 只在角上相接的卧室不连通：答案 0（第二个样例）；
- 只有一间卧室时有一种方案，即不装任何门（测试 03）。

在 160 个随机房子上，答案与一个独立的已通过实现一致。
