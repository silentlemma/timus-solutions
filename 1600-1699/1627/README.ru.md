# 1627. Объединение

[Timus 1627](https://acm.timus.ru/problem.aspx?space=1&num=1627) · сложность 1091 · math

Оригинальная задача — SPbSU ITMO Contest, Петрозаводские сборы, зима 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дом — сетка n × m комнат (1 ≤ n, m ≤ 9), каждая — спальня `.` или
кладовая `*`, хотя бы одна спальня есть. Дверями можно соединять
спальни с общей стеной. Посчитайте способы расставить двери так, чтобы
между любыми двумя спальнями был ровно один путь, по модулю 10⁹.

Ограничение времени: 4 секунды. Ограничение памяти: 64 МБ.

## Входные данные

n и m, затем n строк карты.

## Выходные данные

Число способов по модулю 10⁹.

## Примеры

### Пример 1

Ввод:

```
2 2
..
..
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
2 2
*.
.*
```

Вывод:

```
0
```

## Решение

Ровно один путь между любыми двумя спальнями означает, что двери
образуют остовное дерево графа спален. По матричной теореме Кирхгофа
число остовных деревьев равно определителю лапласиана (степени на
диагонали, −1 для каждой пары соседей) без одной строки и столбца; для
несвязного графа он равен 0. При 81 спальне это определитель 80 × 80.

Ответ нужен по модулю 10⁹, а это не простое число, поэтому обычное
исключение по модулю 10⁹ не может делить на ведущий элемент. Зато может
алгоритм Евклида на строках: чтобы обнулить элемент под ведущим, из
ведущей строки вычитается нужное кратное этой строки, и строки
меняются местами, как при вычислении НОД, пока элемент не станет 0.
Используются только вычитание, умножение и перестановки, так что всё
верно по модулю 10⁹; каждая перестановка меняет знак.
`O(v³ log M)` для v спален. Python вместо этого использует исключение
Барейса, которое держит точные длинные целые и делит нацело, а затем
берёт остаток.

Подводные камни:

- спальни, касающиеся только углом, не связаны: 0 (второй пример);
- одна спальня даёт один способ — пустое множество дверей (тест 03).

Ответы совпадают с независимой принятой реализацией на 160 случайных
домах.
