# 1636. Штрафное время

[Timus 1636](https://acm.timus.ru/problem.aspx?space=1&num=1636) · сложность 60 · implementation

Автор оригинальной задачи — Алексей Самсонов; XIII открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Команды QXX и ZZZ решили все десять задач; QXX победила со штрафным
временем T1 против T2 у ZZZ. Каждая штрафная попытка добавляет
20 минут. По числу штрафных попыток ZZZ на каждой задаче нужно решить,
победила бы ZZZ без них. При равном времени команды упорядочиваются по
названию, так что ZZZ всё равно была бы второй.

## Входные данные

В первой строке T1 и T2 (250 ≤ T1 ≤ T2 ≤ 2400), затем десять чисел
штрафных попыток ZZZ.

## Выходные данные

`Dirty debug :(`, если попытки стоили ZZZ первого места, иначе
`No chance.`.

## Примеры

### Пример 1

Ввод:

```
290 420
0 0 0 2 1 0 2 0 1 0
```

Вывод:

```
No chance.
```

### Пример 2

Ввод:

```
300 719
0 0 0 0 0 0 21 0 0 0
```

Вывод:

```
Dirty debug :(
```

## Решение

Вычесть из T2 по 20 минут за каждую штрафную попытку. ZZZ победила бы
только со строго меньшим временем, чем T1, ведь при равенстве первой
по алфавиту идёт QXX. `O(1)`.

Подводные камни:

- равное чистое время — всё равно поражение (тест 03), на минуту
  меньше — победа (тест 04);
- ответы кончаются точкой и грустным смайликом, и то и другое входит в
  ожидаемый текст.

Ответы совпадают с независимой принятой реализацией на 100 случайных
тестах.
