# 1623. Фрактальный лабиринт

[Timus 1623](https://acm.timus.ru/problem.aspx?space=1&num=1623) · сложность 3124 · shortest_paths

Оригинальная задача — SPbSU ITMO Contest, Петрозаводские сборы, зима 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В доме N дверей (2 ≤ N ≤ 20), а внутри него K домов (K ≤ 5), каждый —
точная копия всего дома, так что вложенность бесконечна. M дорог длины 1
соединяют двери внешнего дома и внутренних (дом 0 — внешний, двери
записываются как `дом.дверь`). Найдите кратчайший путь между двумя
заданными дверями внешнего дома или выведите `no solution`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и K, затем M и дороги `a.b - c.d`, затем две двери.

## Выходные данные

Длина кратчайшего пути или `no solution`.


### Пример 2

Ввод:

```

8
0.0 - 0.2

0.2 - 0.4
0.3 - 0.5
0.4 - 0.6
0.5 - 0.7
0.6 - 0.0

```

Вывод:

## Решение

Пусть D(i, j) — расстояние между дверями i и j внешнего дома. Пройти
внутренний дом от его двери i до двери j стоит ровно D(i, j), ведь
внутренний дом — копия. Значит, D — неподвижная точка: это расстояния в
графе из всех (K + 1) · N дверей с дорогами и с ребром длины D(i, j)
между дверями i и j каждого внутреннего дома.

Начнём с D = ∞ (внутренние дома закрыты) и будем пересчитывать D по
графу снова и снова. После раунда t D учитывает все пути глубиной не
больше t домов, поэтому значения только уменьшаются к настоящим
расстояниям; каждый раунд зависит лишь от предыдущего, так что как
только раунд ничего не меняет, D окончательно. Раунд запускает Дейкстру
на плотном графе от каждой из N внешних дверей.
`O(R · N · ((K + 1) N)²)` для R раундов.

Подводные камни:

- двери могут совпадать: ответ 0 (тест 03);
- лучший путь может требовать нескольких уровней вложенности и
  находиться лишь в поздних раундах (тест 04: 6 после первого раунда,
  5 после второго);
- у двери может вовсе не быть дорог (тест 06).

Ответы совпадают с независимой принятой реализацией на 360 случайных
лабиринтах.
