# 1623. 分形迷宫

[Timus 1623](https://acm.timus.ru/problem.aspx?space=1&num=1623) · 难度 3015 · shortest_paths

原题出自 2008 年冬季彼得罗扎沃茨克集训的 SPbSU ITMO Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一座房子有 N 扇门（2 ≤ N ≤ 20），里面有 K 座房子（0 ≤ K ≤ 5），每座都是整座房子的
完全复制，因此 K > 0 时嵌套无穷无尽。M 条长度为 1 的道路连接外层房子与内层房子的门（0 号
是外层房子，门记作 `房子.门`）。求外层房子两扇给定门之间的最短路，或输出
`no solution`。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 K，然后是 M 和道路 `a.b - c.d`，最后是两扇门。

## 输出

最短路长度，或 `no solution`。

## 样例

### 样例 1

输入：

```
12 1
11
0.0 - 1.1
0.1 - 0.2
1.2 - 1.3
0.3 - 0.4
1.4 - 1.5
0.5 - 0.6
1.6 - 1.7
0.7 - 0.8
1.8 - 1.9
0.9 - 0.10
1.10 - 0.11
0 11
```

输出：

```
11
```

### 样例 2

输入：

```
8 0
8
0.0 - 0.2
0.1 - 0.3
0.2 - 0.4
0.3 - 0.5
0.4 - 0.6
0.5 - 0.7
0.6 - 0.0
0.7 - 0.1
2 5
```

输出：

```
no solution
```

## 解法

设 D(i, j) 为外层房子门 i 与门 j 之间的距离。穿过一座内层房子从它的门 i 到门 j
恰好花费 D(i, j)，因为内层房子是复制品。所以 D 是一个不动点：它是由全部
(K + 1) · N 扇门组成的图中的最短距离，图中有道路，以及每座内层房子的门 i 与门 j
之间长度为 D(i, j) 的边。

先只用给定道路计算 D，再用上一轮的 D 作为内层房子边的权重反复重算。
每轮增加一层递归替换，所以数值只会减小并逼近真实距离；一旦某轮没有变化，
D 就是最终结果。每次计算都在稠密图上从 N 扇外层门各运行一次 Dijkstra。
R 轮共 `O(R · N · ((K + 1) N)²)`。

易错点：

- 两扇门可能相同：答案为 0（测试 03）；
- 最优路径可能需要多层嵌套，只在后面的轮次中才能找到（测试 04：第一轮后为 6，
  第二轮后为 5）；
- 某扇门可能完全没有道路（测试 06）。

在 360 个随机迷宫上，答案与一个独立的已通过实现一致。
