# 1637. 三角形游戏 2

[Timus 1637](https://acm.timus.ru/problem.aspx?space=1&num=1637) · 难度 3157 · geometry

原题作者 Alexander Ipatov，出自第十三届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

地图上画着一个三角形，还有一块与它全等的纸板棋子。每一步可以把棋子关于任意一条直线作镜面反射。
求让棋子与所画三角形完全重合所需的最少步数，或指出无法做到。

## 输入

两行，每行六个整数：所画三角形的顶点和棋子当前的顶点，绝对值都不超过 2000。所画三角形不退化。

## 输出

最少步数，或 `IMPOSSIBLE`。

## 样例

### 样例 1

输入：

```
4 0 6 3 7 0
0 0 2 3 3 0
```

输出：

```
2
```

## 解法

棋子必须经由一个保距变换到达三角形，它把棋子的顶点按六种顺序之一对应到所画的顶点；只有三条边
长都相等时这种顺序才可能。平面上任何保距变换都是若干反射的乘积，最少的反射次数只取决于它的类型：

- 恒等变换：0；
- 非恒等的旋转或平移（保持定向）：2，因为一次反射总会改变定向；
- 反射：1；
- 滑移反射（改变定向，且没有不动点构成的直线）：3，因为两次反射永远不改变定向。

定向通过比较两个三角形叉积的符号得到。定向改变时，当且仅当存在一条合适的直线，变换才是单次
反射：每个移动的顶点与其像有同一条垂直平分线，而每个不动的顶点都在这条线上。直线
a x + b y = c（a = 2(x' − x)，b = 2(y' − y)，c = x'² + y'² − x² − y²）用交叉相乘比较，使用
64 位整数（Python 用任意精度整数）。答案是有效顺序中的最小值。`O(1)`。

易错点：

- 顶点可能以任意顺序给出，所以六种对应都要考虑（测试 03）；
- 对等腰三角形，一种对应下的滑移反射在另一种对应下可能是半周旋转，答案可能是 2 而不是 3（测试 07）；
- 对于固定的对应，定向改变需要反射（1 步）或滑移反射（3 步）。

在 240 个随机格点保距变换上，答案与一个独立的已通过实现一致。
