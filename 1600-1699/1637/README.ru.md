# 1637. Игра в треугольник 2

[Timus 1637](https://acm.timus.ru/problem.aspx?space=1&num=1637) · сложность 3157 · geometry

Автор оригинальной задачи — Александр Ипатов; XIII открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На карте — нарисованный треугольник и равная ему картонная фишка.
Ход отражает фишку относительно любой прямой. Нужно найти наименьшее
число ходов, после которых фишка в точности совпадёт с нарисованным
треугольником, или сообщить, что это невозможно.

## Входные данные

Две строки по шесть целых чисел: вершины нарисованного треугольника и
текущие вершины фишки, все не больше 2000 по модулю. Нарисованный
треугольник невырожден.

## Выходные данные

Наименьшее число ходов или `IMPOSSIBLE`.

## Примеры

### Пример 1

Ввод:

```
4 0 6 3 7 0
0 0 2 3 3 0
```

Вывод:

```
2
```

## Решение

Фишка должна попасть на треугольник движением, которое переводит её
вершины в нарисованные в одном из шести порядков; порядок возможен,
только если совпадают все три длины сторон. Любое движение плоскости —
произведение отражений, и наименьшее их число зависит только от вида
движения:

- тождественное: 0;
- нетривиальный поворот или перенос (ориентация сохраняется): 2, ведь
  одно отражение всегда меняет ориентацию;
- отражение: 1;
- скользящее отражение (ориентация меняется, прямой неподвижных точек
  нет): 3, так как два отражения никогда не меняют ориентацию.

Ориентации сравниваются по знакам векторных произведений двух
треугольников. Если ориентация меняется, движение — одно отражение ровно
тогда, когда подходит одна прямая: у каждой сдвигаемой вершины с её
образом один и тот же серединный перпендикуляр, а каждая оставшаяся на
месте вершина лежит на нём. Прямые a x + b y = c, где a = 2(x' − x),
b = 2(y' − y), c = x'² + y'² − x² − y², сравниваются перекрёстным
умножением в 64-битных целых (в Python — произвольной точности).
Ответ — минимум по допустимым порядкам.
`O(1)`.

Подводные камни:

- вершины могут быть перечислены в любом порядке, так что важны все
  шесть сопоставлений (тест 03);
- у равнобедренного треугольника скользящее отражение при одном
  сопоставлении может оказаться поворотом на 180° при другом, и ответ
  может быть 2, а не 3 (тест 07);
- при фиксированном сопоставлении смена ориентации требует отражения
  (1 ход) или скользящего отражения (3 хода).

Ответы совпадают с независимой принятой реализацией на 240 случайных
движениях решётки.
