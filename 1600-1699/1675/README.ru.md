[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Посчитать матрицы M × N из нулей и единиц, у которых ровно K строк и
ровно L столбцов состоят только из нулей, по модулю 10⁹ + 7.

## Входные данные

M, N, K, L (1 ≤ M, N ≤ 100000; 0 ≤ K ≤ M; 0 ≤ L ≤ N).

## Выходные данные

Количество по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
2 2 0 0
```

Вывод:

```
7
```

### Пример 2

Ввод:

```
2 3 1 1
```

Вывод:

```
6
```

## Решение

Выберем, какие K строк и какие L столбцов нулевые, — C(M, K) · C(N, L)
способов. Тогда все единицы лежат в оставшемся блоке a × b, где
a = M − K и b = N − L, и в каждой строке и каждом столбце этого блока
должна быть единица.

Матрицы a × b без нулевых строк и столбцов считаются
включением-исключением по столбцам, которые обязаны быть нулевыми: если
нулевыми заданы j столбцов, каждая из a строк — любой из 2^(b − j) − 1
ненулевых наборов на остальных, так что

f(a, b) = Σⱼ (−1)ʲ C(b, j) (2^(b − j) − 1)^a.

Формула симметрична по a и b, поэтому сумма идёт по меньшей стороне.
Факториалы и обратные к ним до max(M, N) дают биномиальные
коэффициенты. `O(max(M, N) + min(a, b) log max(a, b))`.

Подводные камни:

- если все строки нулевые, то и все столбцы тоже: K = M требует L = N
  (тесты 06 и 07); формула это учитывает, ведь при a = 0 сумма равна
  Σ (−1)ʲ C(b, j), то есть 1 при b = 0 и 0 иначе;
- 0⁰ в этой сумме считается равным 1.

Ответы совпадают с перебором всех матриц до 4 × 4 при всех K и L и с
независимой принятой реализацией.
