# 1659. 正三角形

[Timus 1659](https://acm.timus.ru/problem.aspx?space=1&num=1659) · 难度 650 · geometry

原题作者 Vladimir Yakovlev，出自 NEERC 2008 东部分区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定一个正三角形。再标出六个点，三个严格在其内部，三个严格在其外部，使这九个点构成至少九个正三角形（包括给定
的那个）的顶点。九个点中任意两点的距离至少为 1，每个新点到三角形各边的距离至少为 0.1，边长之差不超过 10⁻⁶
即视为相等。

## 输入

三行，给出三角形的顶点。坐标的绝对值不超过 100，边长至少为 10。

## 输出

先输出三个内部点，再输出三个外部点，每行一个。

## 样例

### 样例 1

输入：

```
0 30
-25.9807621135 -15
25.9807621135 -15
```

输出：

```
0.0000000000 15.0000000000
-12.9903810567 -7.5000000000
12.9903810567 -7.5000000000
0.0000000000 -45.0000000000
38.9711431703 22.5000000000
-38.9711431703 22.5000000000
```

任何正确的答案都会被接受。题面中给出的这个样例的答案是故意写错的（那些点只构成三个正三角形），所以上面给出的
是本解法的输出。

## 解法

把三角形的中心 g 放在原点，设 a、b、c 为指向顶点 A、B、C 的向量；它们长度相同，两两夹角 120°，且
a + b + c = 0。取内部点 t·a、t·b、t·c，外部点 −s·a、−s·b、−s·c。每组三点本身是正三角形，加上给定的
那个共三个。

另外六个来自形如 A、内部点 t·b、外部点 −s·c 的三元组。把平面朝合适的方向旋转 60°，a 变成 −c，b 变成
−a，因此从 t·b 到 A 的边，即向量 a − t·b，变成 −c + t·a。当且仅当 s = 1 + t 时它等于 −s·c − t·b
（利用 a + b = −c），这样选取时该三元组就是正三角形。每个顶点都能这样与两个相邻顶点配对，得到六个三角形，
总共九个。

本解法取 t = 1/2、s = 3/2。边长至少为 10 时，所有距离都远高于限制：内部三角形边长至少为 5，内部点到最近
一边的距离为外接圆半径的四分之一（至少 1.44），外部点则在最近一边之外整整一个半径处。`O(1)`。

易错点：

- 顶点可以按任意顺序给出，顺时针或逆时针，构造不受影响；
- 大三角形的外部点远远超出输入坐标所在的方框，题目允许这样；
- 答案不是比对，而是检查：检查器会数出正三角形并检验所有距离。
