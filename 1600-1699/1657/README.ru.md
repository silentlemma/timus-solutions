# 1657. Змейка-куб

[Timus 1657](https://acm.timus.ru/problem.aspx?space=1&num=1657) · сложность 1522 · backtracking

Автор оригинальной задачи — Станислав Васильев (подготовка — Сергей Пупырев); четвертьфинал Восточного подрегиона NEERC 2008.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Головоломка-змейка — нить из 27 кубиков. В прямом кубике (`F`) нить
проходит через противоположные грани, в поворачивающем (`T`) — через
смежные; крайние кубики считаются прямыми. Нужно свернуть змейку в куб
3 × 3 × 3 и вывести положение каждого кубика относительно предыдущего
или сообщить, что это невозможно.

## Входные данные

27 букв `F` и `T`.

## Выходные данные

26 букв из `RLFBUD` (справа, слева, впереди, сзади, сверху, снизу) или
`IMPOSSIBLE`. Подходит любой правильный способ сворачивания.

## Примеры

### Пример 1

Ввод:

```
FFTTTFTTFTTTFTFTTTTFTFTFTFF
```

Вывод:

```
UURDFFRBBUFLLDDRBRFFLLUURR
```

### Пример 2

Ввод:

```
FFTFTFTFTTTTFFFTTTFTTFTTTFF
```

Вывод:

```
IMPOSSIBLE
```

## Решение

Сворачивание — путь через все 27 клеток куба: после прямого кубика
следующий шаг сохраняет направление, после поворачивающего идёт в одно
из четырёх поперечных направлений. Поиск в глубину перебирает их по
очереди, не заходя в занятые клетки, и бросает ветвь, как только
свободные клетки распадаются больше чем на один кусок: остаток змейки
не смог бы обойти их все.

Два наблюдения делают перебор достаточно малым для Python. Клетки
раскрашиваются в два цвета, как шахматная доска, — 14 одного и 13
другого, а змейка чередует цвета, так что начинается на большем цвете:
в углу или в центре грани. А симметрии куба делают все углы и все первые
шаги из угла одинаковыми, тогда как из центра грани есть лишь два вида
шага — внутрь, к центру куба, или вдоль грани. Так что поиск начинается
всего с трёх первых ходов.

Подводные камни:

- первая и последняя буквы гарантированно равны `F`; код их не
  проверяет;
- полностью прямая змейка — стержень из 27 и никогда не сворачивается
  (тест 03);
- способов сворачивания много, так что чекер воспроизводит ходы.

Ответы совпадают с независимой принятой реализацией по Yes или No и
проходят чекер на 120 змейках, включая случайные и змейки случайных
сворачиваний с одним изменённым кубиком.

Сложность: `O(C * 4^C)` для C = 27 клеток, не больше четырёх направлений
после каждого поворотного кубика.
