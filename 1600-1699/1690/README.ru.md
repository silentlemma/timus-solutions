# 1690. Армия магов

[Timus 1690](https://acm.timus.ru/problem.aspx?space=1&num=1690) · сложность 638 · constructive

Автор оригинальной задачи — Евгений Курпилянский; Ural SU Contest, Петрозаводские зимние сборы, февраль 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть 5n кандидатов, живущих в различных целых точках. Два мага уважают
друг друга, если отрезок между их домами проходит через ещё одну целую
точку. Выбрать n кандидатов, попарно уважающих друг друга, или
сообщить, что это невозможно.

## Входные данные

n (1 ≤ n ≤ 5000), затем 5n домов — целые числа, по модулю не больше
10000.

## Выходные данные

OK и номера выбранных кандидатов или IMPOSSIBLE. Подходит любая
верная армия.

## Примеры

### Пример 1

Ввод:

```
2
1 1
5 5
0 0
2 2
0 10
6 6
7 7
8 8
9 9
10 10
```

Вывод:

```
OK
2 1
```

## Решение

На отрезке от (x1, y1) до (x2, y2) есть целая точка внутри ровно
тогда, когда gcd(|x1 − x2|, |y1 − y2|) ≥ 2. В частности, у двух домов
с одинаковой чётностью x и y разности чётные, так что середина их
отрезка — целая точка.

Классов чётности всего четыре, и 5n домов в четырёх классах дают хотя
бы ⌈5n / 4⌉ ≥ n домов в одном из них. Поэтому ответ всегда OK: берём
любые n домов из самого большого класса. `O(n)`.

Подводные камни:

- IMPOSSIBLE не бывает никогда;
- чётность отрицательной координаты должна получаться 0 или 1: −3
  нечётно, и `x & 1` в дополнительном коде это учитывает, а `x % 2` в
  C-подобных языках даёт −1 (тест 03).

Чекер принимает любых n различных кандидатов, попарно уважающих друг
друга, проверяя все пары, если они не из одного класса чётности.
Ответы независимой принятой реализации тоже его проходят.
