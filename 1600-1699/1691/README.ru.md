# 1691. Сложность алгоритма

[Timus 1691](https://acm.timus.ru/problem.aspx?space=1&num=1691) · сложность 2798 · graphs

Автор оригинальной задачи — Иван Бурмистров; Ural SU Contest, Петрозаводские зимние сборы, февраль 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В ориентированном графе без кратных дуг (петли разрешены) F(N) — число
путей длины N из s в t. Найти наименьшее k ≥ 0, при котором
F(N) ≤ C · Nᵏ для некоторой константы C и всех N ≥ 1, или −1, если F
растёт быстрее любого многочлена.

## Входные данные

n, m, s, t (1 ≤ n, m ≤ 100000), затем m дуг.

## Выходные данные

k или −1.

## Примеры

### Пример 1

Ввод:

```
2 3 1 2
1 1
1 2
2 2
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
3 6 1 2
1 2
2 1
1 3
3 1
2 3
3 2
```

Вывод:

```
-1
```

## Решение

Важны только вершины, лежащие на каком-нибудь пути из s в t:
достижимые из s, из которых достижима t. Если t недостижима, F равна
нулю и k = 0. Такие вершины образуют целые компоненты сильной
связности: всё, что лежит на цикле с такой вершиной, тоже находится
между s и t.

Компонента, в которой дуг больше, чем вершин, содержит два разных
цикла через общую вершину. Тогда путь может обходить их в
экспоненциально многих порядках, и ответ −1. Иначе каждая компонента —
одна вершина, возможно с петлёй, или один простой цикл, где дуг
столько же, сколько вершин. Путь через c ≥ 1 простых циклов распределяет
лишнюю длину по ним примерно N^(c − 1) способами. Значит,
F(N) ≤ C · N^(c − 1), и на подходящей арифметической прогрессии N
этот порядок достигается. Поэтому k = max(0, c − 1), где c —
наибольшее число циклических компонент на одном пути из s в t.

Алгоритм Косарайю нумерует компоненты так, что дуги между ними идут от
меньших номеров к большим. Один проход в этом порядке находит c как
самый длинный путь, где циклическая компонента весит 1. Все шаги
используют явный стек. `O(n + m)`.

Подводные камни:

- компонента с двумя циклами, из которой t недостижима (или которая
  недостижима из s), не важна (тест 07);
- один цикл на пути оставляет F ограниченной, так что k = 0, а не 1
  (тест 08);
- петля — цикл длины 1, и s = t допускается (тест 04);
- глубина рекурсии дошла бы до 10⁵, поэтому обходы используют
  собственные стеки.

Ответы совпадают с независимой принятой реализацией. На 121
крошечном графе они также совпадают с ростом F(N), посчитанной точно
до N = 3000.
