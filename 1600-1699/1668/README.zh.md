# 1668. 死星 2

[Timus 1668](https://acm.timus.ru/problem.aspx?space=1&num=1668) · 难度 5684 · math

原题作者 Alex Samsonov，出自 2008 年 1 月彼得罗扎沃茨克冬季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 维空间中的空间站装有 M 台固定的发动机。给发动机 i 输入 X 单位能量，会给推力的第 j 个坐标加上 X · A_ij，
X 可以为负。选择 X₁ … X_M，使总推力尽量接近目标向量 b，并在这样的选择中取 X 的平方和最小的一个。

## 输入

N 和 M（1 ≤ N, M ≤ 100），然后 M 行、每行 N 个整数 A_ij，然后 b 的 N 个整数；绝对值都不超过 100。

## 输出

X₁ … X_M，保留小数点后五位。

## 样例

### 样例 1

输入：

```
4 3
2 3 -2 1
-1 2 1 3
4 2 3 -2
3 13 -9 13
```

输出：

```
4.00000 2.00000 -1.00000
```

## 解法

推力为 Σ Xᵢ aᵢ，其中 aᵢ 是 A 的第 i 行。这是以 aᵢ 为列的矩阵的最小二乘问题，其解中最短的那个（伪逆给出的解）
是唯一的：它就是落在向量 cⱼ = (A₁ⱼ, …, A_Mⱼ)（即 A 的各列）张成空间里的那个解，因为与它们正交的部分不改变
推力，只会增加长度。

1. 在 cⱼ 中选出极大线性无关组。用浮点数做需要一个“几乎相关”的阈值；这里改为在模素数 10⁹ + 7 下做消元，是
   精确的。模素数下无关的组在有理数上也无关；模素数下的秩只有在该素数整除所有 r 阶子式时才会偏小，而这需要
   专门针对该素数构造矩阵。
2. 用 Gram–Schmidt 把选出的向量变成标准正交基 q₁ … q_r，每次投影都减两遍：第二遍恢复因舍入而损失的正交性。
3. 令 X = Σ w_k q_k，推力为 K w，其中 K_jk = cⱼ · q_k，K 列满秩。对 K 再做一次 QR（同样用 Gram–Schmidt），
   回代得到最小二乘的 w，进而得到 X。

两步都不构造 AᵀA，所以条件数不会被平方。`O(N · M · min(N, M))`。

易错点：

- 发动机相关时，最佳推力可由许多 X 达到，只有最短的那个正确（测试 03 和 05）；
- 坏掉的发动机得到 0，全零矩阵得到全零（测试 02）；
- 极小的负数会打印成 `-0.00000`，所以小于 5 · 10⁻⁶ 的值置为零。

在约 300 个小输入上，答案与用分数精确计算的结果一致；在大输入上与一个独立的已通过实现一致。

- Python 在 PyPy 下运行：在 100 × 100 的输入上 CPython 需要 0.2–0.4 秒，而限制是 0.5 秒，对评测机来说太接近，
  PyPy 约 0.1 秒。CPython 版本仍把 Q 转置保存，使每次投影都是按行一遍内置求和。
