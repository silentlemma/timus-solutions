# 1668. Звезда смерти 2

[Timus 1668](https://acm.timus.ru/problem.aspx?space=1&num=1668) · сложность 5401 · math

Автор оригинальной задачи — Алексей Самсонов; Ural SU Contest, Петрозаводские зимние сборы, январь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У станции в N-мерном пространстве M закреплённых двигателей. Если подать
на двигатель i X единиц энергии, он добавит X · A_ij к j-й координате
тяги, причём X может быть отрицательным. Нужно выбрать X₁ … X_M так,
чтобы итоговая тяга была как можно ближе к нужному вектору b, а среди
таких вариантов — с наименьшей суммой квадратов X.

## Входные данные

N и M (1 ≤ N, M ≤ 100), затем M строк по N целых A_ij, затем N целых
координат b; все по модулю не больше 100.

## Выходные данные

X₁ … X_M с пятью знаками после десятичной точки.

## Примеры

### Пример 1

Ввод:

```
4 3
2 3 -2 1
-1 2 1 3
4 2 3 -2
3 13 -9 13
```

Вывод:

```
4.00000 2.00000 -1.00000
```

## Решение

Тяга равна Σ Xᵢ aᵢ, где aᵢ — строка i матрицы A. Это задача наименьших
квадратов для матрицы со столбцами aᵢ, и кратчайшее из её решений (ответ
через псевдообратную матрицу) единственно: это то решение, которое лежит
в линейной оболочке векторов cⱼ = (A₁ⱼ, …, A_Mⱼ), столбцов A, потому что
любая ортогональная им часть ничего не меняет в тяге и только добавляет
длину.

1. Среди cⱼ выбирается максимальный независимый набор по модулю
   10⁹ + 7. В вещественных числах нужен порог «почти зависимы»;
   исключение по модулю этого простого точно. Независимость по модулю
   простого означает независимость над рациональными, но ранг может
   упасть, если простое делит все миноры порядка, равного рангу над
   рациональными. Ограничения входа это допускают; код предполагает
   совпадение рангов.
2. Выбранные векторы превращаются в ортонормированный базис q₁ … q_r
   методом Грама–Шмидта, причём каждая проекция вычитается дважды:
   второй проход восстанавливает ортогональность, потерянную при
   округлении.
3. При X = Σ w_k q_k тяга равна K w, где K_jk = cⱼ · q_k, и у K полный
   ранг по столбцам. Второе QR-разложение K, тоже по Граму–Шмидту, даёт
   w по методу наименьших квадратов обратной подстановкой, а затем и X.

Ни один шаг не строит AᵀA, так что число обусловленности не
возводится в квадрат. `O(N · M · min(N, M))`.

Подводные камни:

- при зависимых двигателях лучшая тяга достигается многими X, и верен
  только кратчайший (тесты 03 и 05);
- неработающий двигатель получает 0, а нулевая матрица — все нули
  (тест 02);
- чтобы не печатать `-0.00000`, значения с |Xᵢ| < 5 · 10⁻⁶ обнуляются;
  Python заменяет уже отформатированный отрицательный ноль.

Ответы совпадают с точным вычислением в дробях примерно на 300 малых
входах и с независимой принятой реализацией на больших.

## Особенности языков

- Python запускается под PyPy: CPython тратит здесь 0,2–0,4 с на входах
  100 × 100 при ограничении 0,5 с, это слишком близко для проверяющей
  системы, а PyPy — около 0,1 с. Python хранит Q и её транспонированную
  копию и вычитает сумму проекций; остальные версии вычитают их по одной.
