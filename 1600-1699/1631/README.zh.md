# 1631. 醉酒的国王 2

## 任务

国王在边长均为奇数的 m × n 棋盘上巡游：从角上出发并回到该角，除起点外每个格子恰好经过一次，
路径不能自交，而且由于喝醉了，永远不能连续两步朝同一方向走。求这样的巡游的最短长度，按格子
中心之间的距离计算（直走一步为 1，斜走一步为 √2）。

## 输入

一行，m 和 n（6 < m, n < 500，均为奇数）。

## 输出

最短巡游的长度，精度 10⁻⁹。

## 样例

### 样例 1

输入：

```
7 7
```

输出：

```
55.213203435596425732025330863145
```

## 解法

巡游是经过全部 m · n 个格子的闭合路径，所以恰好有 m · n 步。若其中 D 步是斜走，长度就是
m · n + D · (√2 − 1)，问题变成让 D 尽量小。

斜步无法避免。连续两步直走必须转弯，所以每个格子最多有一条横向的步和一条纵向的步。于是在
每一行中，横向的步把相邻格子两两配对，格子数为奇数时至少剩下一个；每一列同样如此。每个剩下
的格子都需要一步斜走，所以 D ≥ (m + n) / 2。这个简单的下界并不紧：其余条件把最少斜步
数推到 D = m + n + 1（这里不作证明）。题面插图中 7 × 7 的巡游用了 15 步斜走，而
49 + 15 · (√2 − 1) = 55.2132… 正是期望的答案。程序以 12 位小数输出这个公式；最大的值约为
2.5 · 10⁵，用 double 计算时绝对误差仍在 10⁻¹¹ 左右。`O(1)`。

易错点：

- 巡游是闭合的，所以步数是 m · n 而不是 m · n − 1；
- Java 按默认区域设置格式化，可能输出小数逗号；用 `Locale.US` 保持小数点。

答案与一个独立的已通过实现一致。
