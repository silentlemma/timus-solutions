## Задача

Король обходит шахматную доску m × n с нечётными сторонами: начинает и
заканчивает в углу, каждую клетку, кроме первой, посещает ровно один
раз, не пересекает свой путь и, будучи пьяным, никогда не делает два
хода подряд в одном направлении. Нужно найти длину кратчайшего такого
обхода, считая между центрами клеток (прямой ход — 1, диагональный — √2).

## Входные данные

Одна строка с m и n (6 < m, n < 500, оба нечётные).

## Выходные данные

Длина кратчайшего обхода с точностью 10⁻⁹.

## Примеры

### Пример 1

Ввод:

```
7 7
```

Вывод:

```
55.213203435596425732025330863145
```

## Решение

Обход — замкнутый путь через все m · n клеток, поэтому в нём ровно m · n
ходов. Если D из них диагональные, длина равна m · n + D · (√2 − 1), и
нужно сделать D как можно меньше.

Без диагоналей не обойтись. Два прямых хода подряд обязаны повернуть,
поэтому в каждой клетке не больше одного горизонтального хода и не
больше одного вертикального. Значит, в строке горизонтальные ходы
разбивают соседние клетки на пары, и при нечётном числе клеток хотя бы
одна остаётся без пары; то же верно для каждого столбца. Каждой такой
клетке нужен диагональный ход, так что уже D ≥ (m + n) / 2. Эта простая
оценка не точна: остальные условия поднимают наименьшее возможное число
до D = m + n + 1 (здесь это не доказывается). На рисунке из условия обход
доски 7 × 7 использует 15 диагоналей, и 49 + 15 · (√2 − 1) = 55,2132… —
ожидаемый ответ. Программа печатает эту формулу с 12 знаками; самое
большое значение, около 2,5 · 10⁵, сохраняет в double абсолютную
погрешность порядка 10⁻¹¹. `O(1)`.

Подводные камни:

- обход замкнут, поэтому ходов m · n, а не m · n − 1;
- Java форматирует по локали по умолчанию и может напечатать десятичную
  запятую; `Locale.US` сохраняет точку.

Ответы совпадают с независимой принятой реализацией.
