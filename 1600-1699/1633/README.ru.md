# 1633. О гиппогрифах

[Timus 1633](https://acm.timus.ru/problem.aspx?space=1&num=1633) · сложность 754 · math

Автор оригинальной задачи — Игорь Чевдарь; XIII открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Опасность гиппогрифа с клювом длины A и когтями длины B равна
√(A² + B²). Эликсир превращает их в a₁A + b₁B и a₂A + b₂B. Его качество —
наибольший множитель, в который он может увеличить опасность любого
гиппогрифа ненулевой опасности. Нужно найти качество.

## Входные данные

Две строки: a₁ b₁, затем a₂ b₂ — неотрицательные целые числа не больше
10⁶.

## Выходные данные

Качество с точностью до 9 знаков после десятичной точки.

## Примеры

### Пример 1

Ввод:

```
1 2
3 4
```

Вывод:

```
5.4649857042190426504511884932842
```

### Пример 2

Ввод:

```
1 2
2 4
```

Вывод:

```
5
```

## Решение

Эликсир — это матрица M = [[a₁, b₁], [a₂, b₂]], действующая на вектор
(A, B), а опасность — евклидова длина, так что качество — наибольшее
растяжение M: её наибольшее сингулярное число, корень из наибольшего
собственного числа MᵀM.

Школьная формула √((T + √(T² − 4D²)) / 2), где T = a₁² + b₁² + a₂² + b₂²
и D = a₁b₂ − b₁a₂, теряет знаки в double: когда M почти кратна повороту,
T² и 4D² порядка 10²⁵ и почти равны, и в их разности теряются значащие
цифры. Разложение на множители этого избегает:
T − 2D = (a₁ − b₂)² + (b₁ + a₂)² = Q и T + 2D = (a₁ + b₂)² + (b₁ − a₂)² = P,
а сингулярные числа равны (√P + √Q) / 2 и |√P − √Q| / 2. P и Q — целые меньше
2⁵³, точные в double, поэтому ответ (√P + √Q) / 2 — полусумма двух правильно
округлённых корней с погрешностью около 2 · 10⁻¹⁰ даже около 2 · 10⁶.
`O(1)`.

Подводные камни:

- формула через собственные числа в double не даёт нужной точности на
  почти ортогональных матрицах (тесты 06, 07);
- квадраты доходят до 4 · 10¹², за пределы 32-битных целых;
- у матрицы ранга один норма всё равно положительна (второй пример), а у
  нулевой матрицы она 0 (тест 03).

Ответы совпадают с независимой принятой реализацией с точностью
2,4 · 10⁻¹⁰ на 200 случайных эликсирах.
