# 1633. 鹰头马身有翼兽

[Timus 1633](https://acm.timus.ru/problem.aspx?space=1&num=1633) · 难度 754 · math

原题作者 Igor Chevdar，出自第十三届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

喙长 A、爪长 B 的鹰头马身有翼兽的危险度为 √(A² + B²)。一种药剂把它们变为 a₁A + b₁B 和
a₂A + b₂B。药剂的品质是它对任意一只危险度非零的兽能使危险度放大的最大倍数。求品质。

## 输入

两行：a₁ b₁，然后 a₂ b₂，都是不超过 10⁶ 的非负整数。

## 输出

品质，精确到小数点后 9 位。

## 样例

### 样例 1

输入：

```
1 2
3 4
```

输出：

```
5.4649857042190426504511884932842
```

### 样例 2

输入：

```
1 2
2 4
```

输出：

```
5
```

## 解法

药剂就是作用在向量 (A, B) 上的矩阵 M = [[a₁, b₁], [a₂, b₂]]，危险度是欧氏长度，所以品质是 M
的最大伸缩倍数：它的最大奇异值，即 MᵀM 最大特征值的平方根。

教科书公式 √((T + √(T² − 4D²)) / 2)（其中 T = a₁² + b₁² + a₂² + b₂²，D = a₁b₂ − b₁a₂）在
double 中会丢失精度：当 M 接近旋转矩阵的倍数时，T² 与 4D² 约为 10²⁵ 且几乎相等，它们的差中
会丢失有效数字。因式分解可以避免这一点：T − 2D = (a₁ − b₂)² + (b₁ + a₂)² = Q，
T + 2D = (a₁ + b₂)² + (b₁ − a₂)² = P，奇异值为 (√P + √Q) / 2 和 |√P − √Q| / 2。P 和 Q 都是小于 2⁵³ 的整数，在
double 中是精确的，所以答案 (√P + √Q) / 2 是两个正确舍入的平方根之和的一半，即使接近 2 · 10⁶，误差也
只有约 2 · 10⁻¹⁰。`O(1)`。

易错点：

- 在 double 中用特征值公式，对几乎正交的矩阵达不到精度要求（测试 06、07）；
- 平方可达 4 · 10¹²，超出 32 位整数；
- 秩为一的矩阵范数仍为正（第二个样例），零矩阵为 0（测试 03）。

在 200 个随机药剂上，答案与一个独立的已通过实现相差不超过 2.4 · 10⁻¹⁰。
