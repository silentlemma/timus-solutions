# 1614. Нацпроект «Трамваи»

## Задача

В городе 2n трамвайных остановок (1 ≤ n ≤ 100). Нужно проложить ровно n
маршрутов, каждый — последовательность ровно из 2n остановок (остановки
могут повторяться), так, чтобы любые две остановки были соседними на
каком-нибудь маршруте: от одной до другой можно доехать без
промежуточных остановок. Выведите маршруты или `-1`, если это
невозможно. Принимается любой правильный набор.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

n.

## Выходные данные

n строк, в каждой 2n остановок одного маршрута.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
1 6 2 1 3 4
2 3 6 5 4 6
5 1 4 2 5 3
```

## Решение

Пар остановок n(2n − 1), а у n маршрутов по 2n остановок ровно
n(2n − 1) соседних мест, поэтому каждая пара должна встретиться ровно
один раз. Разобьём полный граф на 2n вершинах на n путей через
все вершины. Это всегда возможно.

Пронумеруем остановки 0 … 2n − 1 по кругу. Маршрут k идёт k, k + 1,
k − 1, k + 2, k − 2, …, k + n (по модулю 2n): он проходит каждую
остановку один раз, а его соседние пары чередуют суммы 2k + 1 и 2k по
модулю 2n — это все пары {k − j, k + 1 + j} и все пары {k + j, k − j}.
У любой пары разных остановок есть сумма s по модулю 2n, и пара
попадает в маршрут ⌊s / 2⌋, так что n маршрутов покрывают все пары.
`O(n²)`.

Подводные камни:

- при n = 1 это один маршрут из обеих остановок (тест 02);
- маршруты из примера другие, но тоже правильные, поэтому чекер
  проверяет, что покрыта каждая пара.
