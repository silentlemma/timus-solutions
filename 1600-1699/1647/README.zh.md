# 1647. 分岛！

[Timus 1647](https://acm.timus.ru/problem.aspx?space=1&num=1647) · 难度 836 · geometry

原题作者 Vladislav Isenbaev（由 Alexander Ipatov 准备），出自 2008 年 10 月的乌拉尔国立大学中学生竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

岛屿是一个非退化三角形。在海岸上找两点 S 和 T，使线段 ST 把岛分成面积相等、海岸线长度也相等的两部分，
或指出不存在。

## 输入

六个整数 x₁ y₁ x₂ y₂ x₃ y₃，绝对值不超过 2000。

## 输出

`YES` 以及 S 和 T 的坐标（精度 10⁻⁹），或 `NO`。任何合法线段都被接受。

## 样例

### 样例 1

输入：

```
0 0 10 0 0 10
```

输出：

```
YES
0 0
5 5
```

### 样例 2

输入：

```
0 3 4 0 3 4
```

输出：

```
YES
1.741248277008306 3.580416092336102
3.445803840397070 0.415647119702198
```

## 解法

沿海岸按弧长行走。把 S 放在弧长位置 s，T 放在再往前半个周长处，这样海岸线总是被平分；令 f(s) 为从 S
到 T 那一侧的面积减去三角形面积的一半。把 S 移动半个周长会交换两部分，所以 f(s + P/2) = −f(s)，而 f
连续：它在 [0, P/2] 上有零点。因此答案总是 `YES`（这样的直线恰好是过内心的直线），用二分即可找到零点。

一部分的面积用鞋带公式对 S、走向 T 途中经过的顶点以及 T 计算；顶点按弧长位置绕两圈记录，于是越过第一个
顶点的情形无需特殊处理。二百次折半使区间远小于 double 精度。`O(1)`，常数为几千次运算。

易错点：

- 答案从不会是 `NO`，尽管题面允许；
- 弦可能从顶点开始或在顶点结束，如第一个样例；按弧长参数化无需特殊处理；
- 这样的弦可能多达三条，所以检查器接受任何合法的弦。

程序给出的弦在所有测试上都能通过检查器，一个独立的已通过实现在 180 个随机三角形上给出的弦也能通过。
