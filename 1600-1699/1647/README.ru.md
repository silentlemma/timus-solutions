# 1647. Раздел острова

[Timus 1647](https://acm.timus.ru/problem.aspx?space=1&num=1647) · сложность 836 · geometry

Автор оригинальной задачи — Владислав Исенбаев (подготовка — Александр Ипатов); осеннее первенство школьников, октябрь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Остров — невырожденный треугольник. Нужно найти на его побережье две
точки S и T так, чтобы отрезок ST делил остров на две части с равными
площадью и длиной побережья, или сообщить, что таких нет.

## Входные данные

Шесть целых чисел x₁ y₁ x₂ y₂ x₃ y₃, не больше 2000 по модулю.

## Выходные данные

`YES` и координаты S и T с точностью 10⁻⁹ или `NO`. Подходит любой
правильный отрезок.

## Примеры

### Пример 1

Ввод:

```
0 0 10 0 0 10
```

Вывод:

```
YES
0 0
5 5
```

### Пример 2

Ввод:

```
0 3 4 0 3 4
```

Вывод:

```
YES
1.741248277008306 3.580416092336102
3.445803840397070 0.415647119702198
```

## Решение

Пойдём вдоль побережья по длине дуги. Поставим S в позицию s, а T на
полпериметра дальше, так что побережье всегда делится поровну; пусть
f(s) — площадь части от S до T минус половина треугольника. Сдвиг S на
полпериметра меняет части местами, так что f(s + P/2) = −f(s), а f
непрерывна: у неё есть корень на [0, P/2]. Значит, ответ всегда `YES`
(такие прямые — ровно те, что проходят через центр вписанной
окружности), и корень находит бисекция.

Площадь части считается формулой шнурования по S, вершинам, пройденным
по пути к T, и T; вершины записаны по их позициям на дуге дважды по
кругу, так что переход через первую вершину не требует особого случая.
Двести делений пополам сужают отрезок далеко за пределы точности double.
`O(1)` с константой в несколько тысяч операций.

Подводные камни:

- `NO` никогда не бывает ответом, хотя условие его допускает;
- хорда может начинаться или кончаться в вершине, как в первом примере;
  параметризация по дуге обходится без особых случаев;
- чекер принимает любую правильную хорду, ведь их может быть до трёх.

Хорды программы проходят чекер на всех тестах, как и хорды независимой
принятой реализации на 180 случайных треугольниках.
