# 1699. 转弯的乌龟

[Timus 1699](https://acm.timus.ru/problem.aspx?space=1&num=1699) · 难度 1074 · trees

原题作者 Alex Samsonov，出自 2009 年 2 月彼得罗扎沃茨克冬季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在方格场地上，可通行的格子之间的连接方式唯一：任意两格之间恰有一条路径。
乌龟在边相邻的格子之间移动，路线的难度是沿途 90° 转弯的次数。回答 q 个询问：从一个可通行格到另一个的转弯数。

## 输入

h 和 w（1 ≤ w · h ≤ 100000），由 `#`（可通行）和 `.` 组成的地图，然后是 q（1 ≤ q ≤ 50000）和询问 r1 c1 r2 c2。

## 输出

每个询问的转弯数，每行一个。

## 样例

### 样例 1

输入：

```
5 4
.#..
###.
..##
.##.
....
4
1 2 2 1
2 3 4 3
4 2 3 4
1 2 4 2
```

输出：

```
1
0
2
3
```

## 解法

可通行的格子构成一棵树。用广度优先搜索以任意可通行格为根。对每个格子记录父亲、深度、从父亲出发那一步的方向，
以及 T——从根到它的路径上的转弯数。孩子的 T 等于父亲的 T，若在父亲处换了方向则再加一。

a 与 b 之间的路线从 a 向上到它们的汇合格 m，再向下到 b。设 a′ 和 b′ 是 m 在两侧的孩子。
从 m 向下到 b 这一段的转弯数是 T(b) − T(b′)，a 一侧同理。在 m 处，除非路线直穿过去（即进入 a′ 与进入 b′ 的步方向相反），否则会转弯。
若 m 就是 b，只计 a 一侧。倍增法可以同时找出 m 以及 a′、b′：先把较深的格子提到比另一格深一层，
再在二者祖先不同时一起上提。`O((n + q) log n)`。

注意事项：

- 汇合格处的转弯容易漏掉，没有转弯的直穿情形也是（测试 04）；
- 深度相同、以及一端是另一端祖先的路线需要分别处理；
- 蜿蜒的走廊会让树深达 50000，所以遍历不用递归。

答案与小场地上逐条走路线的结果一致，也与一个独立的已通过实现在大的随机、蛇形和多分支场地上一致。
