# 1638. Книжный червь

[Timus 1638](https://acm.timus.ru/problem.aspx?space=1&num=1638) · сложность 66 · math

Автор оригинальной задачи — Алексей Самсонов; XIII открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Сто томов стоят на полке вплотную в порядке возрастания слева направо. У
каждого тома листы заданной общей толщины и две обложки заданной
толщины. Червь начинает с первого листа одного тома и прогрызает путь
насквозь, пока не достигнет последнего листа другого тома. Какова длина
пути?

## Входные данные

Четыре положительных целых числа не больше 100: толщина листов тома,
толщина обложки, том, где червь начинает, и том, где он останавливается.

## Выходные данные

Длина пути.

## Примеры

### Пример 1

Ввод:

```
10 1 1 2
```

Вывод:

```
2
```

## Решение

Вся хитрость в том, где лежат листы. У книги, стоящей на полке корешком
наружу, первый лист справа, а последний слева, так что первый лист тома
a примыкает к обложке, обращённой к тому a + 1, а последний лист тома b —
к обложке, обращённой к тому b − 1. Пусть w = листы + 2 · обложка — целый
том:

- a < b: только правая обложка a, тома между ними и левая обложка b:
  2 · cover + (b − a − 1) · w; пример даёт 2;
- a > b: червь проходит ещё и все листы обоих томов:
  2 · pages + 2 · cover + (a − b − 1) · w;
- a = b: только листы этого тома.

`O(1)`.

Подводные камни:

- интуитивный ответ для томов 1 и 2 — целая книга или две, но червь
  проходит только две обложки (пример);
- в обратную сторону путь гораздо длиннее (тест 02).

Ответы совпадают с независимой принятой реализацией на 200 случайных
тестах.
