# 1638. 书虫

[Timus 1638](https://acm.timus.ru/problem.aspx?space=1&num=1638) · 难度 65 · math

原题作者 Alex Samsonov，出自第十三届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一百卷书从左到右按编号递增紧挨着立在书架上。每卷书的书页有给定的总厚度，另有两张给定厚度的封面。
一条虫从某一卷的第一页开始一直往前啃，直到另一卷的最后一页为止。它啃出的路径有多长？

## 输入

四个不超过 100 的正整数：一卷书页的厚度、封面的厚度、虫子起点所在的卷号和终点所在的卷号。

## 输出

路径的长度。

## 样例

### 样例 1

输入：

```
10 1 1 2
```

输出：

```
2
```

## 解法

关键在于书页的位置。书脊朝外立在书架上的书，第一页在右边，最后一页在左边，所以第 a 卷的第一页
挨着朝向第 a + 1 卷的封面，第 b 卷的最后一页挨着朝向第 b − 1 卷的封面。记一整卷的厚度为
w = 书页 + 2 · 封面：

- a < b：只有 a 的右封面、中间各卷和 b 的左封面：2 · cover + (b − a − 1) · w；样例得 2；
- a > b：虫子还要穿过两卷的全部书页：2 · pages + 2 · cover + (a − b − 1) · w；
- a = b：只有这一卷的书页。

`O(1)`。

易错点：

- 对第 1 卷和第 2 卷，直觉答案是一两整本书，但虫子只穿过两张封面（样例）；
- 反方向的路径长得多（测试 02）。

在 200 个随机测试上，答案与一个独立的已通过实现一致。
