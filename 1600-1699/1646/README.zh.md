# 1646. 哥斯拉卷土重来！

[Timus 1646](https://acm.timus.ru/problem.aspx?space=1&num=1646) · 难度 891 · strings

原题作者 Ivan Burmistrov，出自 2008 年 10 月的乌拉尔国立大学中学生竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定两个 DNA 样本。m 天中每天把之前的两个样本拼接成一个新样本（第二个接在第一个后面）。求给定模式串
在最后一个样本中的出现次数，对 10⁹ + 7 取模。

## 输入

模式串（不超过 100 个 `ACGT` 字母），两个初始样本（每个不超过 10 个字母），m（1 ≤ m ≤ 100），然后
m 对数：第 k 天拼接的两个样本编号，均在 1 到 k + 1 之间。

## 输出

出现次数对 10⁹ + 7 取模。

## 样例

### 样例 1

输入：

```
AGA
A
G
4
1 2
2 1
3 1
5 4
```

输出：

```
2
```

### 样例 2

输入：

```
A
CT
AG
2
1 1
3 3
```

输出：

```
0
```

## 解法

长度每天至多翻倍，所以最后的样本可能有约 2¹⁰⁰ 个字母，绝不能真的构造出来。对每个样本只保存出现次数
（模 10⁹ + 7）以及它的前 L − 1 个和后 L − 1 个字母，L 为模式串长度（样本更短时保存整个样本）。

拼接 A 和 B 时，A 内部和 B 内部的出现都保留，再加上跨越接缝的出现。这样的出现从 A 的最后 L − 1 个
字母中开始、在 B 的前 L − 1 个字母中结束，所以它们正好是短串 tail(A) + head(B) 中的出现：任何一部分
单独都放不下模式串。新的开头取 head(A) + head(B) 的前 L − 1 个字母，新的结尾取 tail(A) + tail(B) 的
后 L − 1 个字母，样本短于 L − 1 时也同样正确。`O(m · L²)`。

易错点：

- 计数会让任何整数类型溢出：2¹⁰⁰ 个 `A` 中有 2¹⁰⁰ 次 `A` 的出现（测试 04）；
- 短于 L − 1 的样本必须整体保存；用负下标取最后 L − 1 个字母会把它截断（测试 06）；
- 模式串只有一个字母时，保存的两端为空，也没有跨越接缝的出现。

在 400 个随机测试上答案与一个独立的已通过实现一致，在小测试上与直接计数一致。
