# 1646. Годзилла возвращается!

[Timus 1646](https://acm.timus.ru/problem.aspx?space=1&num=1646) · сложность 891 · strings

Автор оригинальной задачи — Иван Бурмистров; осеннее первенство школьников, октябрь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны два образца ДНК. В каждый из m дней новый образец получается
склейкой двух прежних (второй дописывается в конец первого). Нужно
посчитать вхождения данного образца-шаблона в последний образец по
модулю 10⁹ + 7.

## Входные данные

Шаблон (не больше 100 букв `ACGT`), два первых образца (не больше 10 букв
каждый), m (1 ≤ m ≤ 100), затем m пар: в день k — номера двух
склеиваемых образцов, каждый от 1 до k + 1.

## Выходные данные

Число вхождений по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
AGA
A
G
4
1 2
2 1
3 1
5 4
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
A
CT
AG
2
1 1
3 3
```

Вывод:

```
0
```

## Решение

Каждый день длина может удвоиться, так что последний образец может иметь
около 2¹⁰⁰ букв; строить его нельзя. Для каждого образца храним только
число вхождений по модулю 10⁹ + 7 и его первые и последние L − 1 букв,
где L — длина шаблона (или весь образец, если он короче).

Склейка A и B сохраняет все вхождения внутри A и внутри B и добавляет
пересекающие шов. Такое вхождение начинается в последних L − 1 буквах A
и кончается в первых L − 1 буквах B, так что это ровно вхождения в
короткую строку tail(A) + head(B): ни одна из частей сама по себе не
вмещает шаблон. Новое начало — первые L − 1 букв head(A) + head(B), новый
конец — последние L − 1 букв tail(A) + tail(B); это верно и тогда, когда
образец короче L − 1. `O(m · L²)`.

Подводные камни:

- количество переполняет любой целый тип: 2¹⁰⁰ копий `A` содержат 2¹⁰⁰
  вхождений `A` (тест 04);
- образец короче L − 1 нужно хранить целиком; взятие последних L − 1
  букв отрицательным индексом его обрезает (тест 06);
- при шаблоне из одной буквы хранимые концы пусты и через шов ничего не
  проходит.

Ответы совпадают с независимой принятой реализацией на 400 случайных
тестах и с прямым подсчётом на маленьких.
