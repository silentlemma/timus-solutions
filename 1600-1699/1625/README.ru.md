# 1625. Ганкелева матрица

[Timus 1625](https://acm.timus.ru/problem.aspx?space=1&num=1625) · сложность 1046 · math

Оригинальная задача — SPbSU ITMO Contest, Петрозаводские сборы, зима 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У ганкелевой матрицы размера n в строке i и столбце j стоит α(i + j − 1),
так что она строится по α1, …, α(2n−1). Для 1 ≤ n ≤ 100 найдите
неотрицательные целые не длиннее 300 цифр, при которых каждая
квадратная подматрица, содержащая левую верхнюю клетку, имеет
определитель 1. Принимаются любые такие числа.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n.

## Выходные данные

α1, …, α(2n−1), по одному в строке.

## Примеры

### Пример 1

Ввод:

```
1
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
2
```

Вывод:

```
1
6
37
```

### Пример 3

Ввод:

```
3
```

Вывод:

```
1
3
10
7
630
```

## Решение

Подходят числа Каталана 1, 1, 2, 5, 14, …: у ганкелевой матрицы
[C(i + j)] каждый ведущий квадрат имеет определитель 1. По лемме
Линдстрёма — Гесселя — Вьенно такой определитель считает семейства
непересекающихся путей на решётке, а C(i + j) — число путей типа Дика от
одной начальной точки до одной конечной; для этих точек непересекающееся
семейство только одно, поэтому каждый определитель равен 1.

У C(198) 116 цифр, это с запасом в пределах ограничения. Каждое число
получается из предыдущего: C(k + 1) = C(k) · 2(2k + 1) / (k + 2), и
деление нацело. Python, Go и Java пользуются своими длинными целыми;
C++ и Rust хранят число цифрами по основанию 10⁹ с умножением и делением
на малое число. `O(n²)`.

Подводные камни:

- ответы примеров другие, поэтому чекер проверяет определители (по
  модулю трёх больших простых, исключением, ведущие элементы которого и
  есть ведущие миноры);
- при n = 1 нужно только число 1.
