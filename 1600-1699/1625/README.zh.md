# 1625. 汉克尔矩阵

[Timus 1625](https://acm.timus.ru/problem.aspx?space=1&num=1625) · 难度 1046 · math

原题出自 2008 年冬季彼得罗扎沃茨克集训的 SPbSU ITMO Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 阶汉克尔矩阵第 i 行第 j 列的元素是 α(i + j − 1)，所以它由 α1、…、α(2n−1) 构成。
对 1 ≤ n ≤ 100，求出每个都不超过 300 位的非负整数，使所有包含左上角格子的方阵
子矩阵的行列式都等于 1。任何这样的数都被接受。

时间限制：1 秒。内存限制：64 MB。

## 输入

n。

## 输出

α1、…、α(2n−1)，每行一个。

## 样例

### 样例 1

输入：

```
1
```

输出：

```
1
```

### 样例 2

输入：

```
2
```

输出：

```
1
6
37
```

### 样例 3

输入：

```
3
```

输出：

```
1
3
10
7
630
```

## 解法

卡特兰数 1、1、2、5、14、… 满足要求：汉克尔矩阵 [C(i + j)] 的每个左上方阵的行列式
都是 1。根据 Lindström–Gessel–Viennot 引理，这样的行列式计数的是互不相交的格路族，
而 C(i + j) 计数从一个起点到一个终点的 Dyck 型路径；对这些点只有一个互不相交的路径族，
所以每个行列式都等于 1。

C(198) 有 116 位，远在限制之内。每个数由前一个得到：C(k + 1) = C(k) · 2(2k + 1) / (k + 2)，
除法是整除。Python、Go 和 Java 使用自带的大整数；C++ 和 Rust 把数按 10⁹ 进制存储，
只需与小整数相乘和相除。`O(n²)`。

易错点：

- 样例的答案与此不同，所以由检查器验证行列式（模三个大素数，用消元法，其主元正是
  各阶左上主子式）；
- n = 1 时只需要数 1。
