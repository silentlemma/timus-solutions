# 1663. Хоббит, или Туда и обратно 2

[Timus 1663](https://acm.timus.ru/problem.aspx?space=1&num=1663) · сложность 3048 · dp

Автор оригинальной задачи — Александр Ипатов; Ural SU Contest, Петрозаводские зимние сборы, январь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Путешествие начинается в городе 1, проходит через каждый из N городов
ровно по одному разу и возвращается в город 1. Вход в город A из города
B стоит P_A · ⌊1000 / P_B⌋, где P — население. Нужно вывести самый
дешёвый маршрут, начиная с города 1; подходит любой самый дешёвый.

## Входные данные

N (2 ≤ N ≤ 1000), затем население городов P₁ … P_N (1 ≤ Pᵢ ≤ 1000).

## Выходные данные

N городов в порядке обхода.

## Примеры

### Пример 1

Ввод:

```
4
10 3 5 4
```

Вывод:

```
1 4 2 3
```

## Решение

Обозначим q_B = ⌊1000 / P_B⌋, тогда шаг из B в A стоит q_B · P_A.
Отсортируем города по населению: вдоль этого порядка P не убывает, а
q не возрастает. Для стоимостей такого вида произведения некоторый
самый дешёвый маршрут пирамидальный: он поднимается от самого маленького
города к самому большому по возрастающей последовательности городов и
спускается обратно через остальные.

Поэтому каждый город в отсортированном порядке попадает либо на путь
вверх, либо на путь вниз. После городов от 0 до m один из путей
кончается в городе m, и важен только конец j другого пути. С учётом
сдвигов up[j] — наименьшая стоимость, когда в m кончается путь вверх,
down[j] — когда путь вниз. Добавление города m + 1 к пути, который уже
кончается в m, сохраняет j и прибавляет одно и то же ко всем элементам,
поэтому это хранится как общий сдвиг для каждого массива; добавление к другому пути
даёт единственный новый элемент для j = m — минимум по всем j. Последний
город замыкает оба пути. На каждом шаге запоминается, какое j дало
новые элементы, и проход назад от лучшего конечного состояния
распределяет города по путям. `O(N²)`.

Подводные камни:

- маршрут должен начинаться с города 1, который не обязательно самый
  маленький, поэтому найденный цикл поворачивается;
- плата считается целочисленным делением, поэтому у многих городов
  одинаковое q (тест 06 и большие города в gen4);
- при двух городах маршрут всего один.

Пирамидальность подтверждена полным перебором всех маршрутов на 400
случайных входах до 9 городов, а стоимости маршрутов совпадают с
независимой принятой реализацией на 60 случайных входах до 1000 городов.
Чекер сравнивает стоимости маршрутов.
