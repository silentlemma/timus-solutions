# 1634. Паутинный клещ

## Задача

После каждого опрыскивания N кадок с деревьями переставляются по
фиксированной перестановке P, и яйца клеща гибнут, как только все кадки
впервые вернутся на свои исходные места. Для P, выбранной равновероятно
среди всех перестановок N элементов, нужно найти математическое ожидание
числа опрыскиваний и вывести его целую часть.

## Входные данные

Одно целое число N (1 ≤ N ≤ 50).

## Выходные данные

Целая часть ожидаемого числа опрыскиваний.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
1
```

## Решение

Число опрыскиваний — порядок P: наименьшее общее кратное длин её циклов.
Перестановка, у которой для каждого k ровно m_k циклов длины k, при
равновероятном выборе имеет вероятность 1 / Π k^(m_k) m_k! (классический
подсчёт перестановок данного циклового типа), так что ожидание — сумма
по цикловым типам.

При N = 50 цикловых типов 204226, но у многих один и тот же НОК. Рюкзак
по длинам циклов их объединяет: dp[s][l] — вероятность того, что
случайная перестановка s элементов использует только уже рассмотренные
длины 1…k и их НОК равен l. Добавление m циклов длины k переносит вес из
dp[s][l] в dp[s + mk][НОК(l, k)], умножая его на 1 / (k^m m!), который
набирается по одному множителю k · m. При N = 50 различных значений НОК
для каждого размера всего около тысячи (функция Ландау ограничивает их
числом 180180). Ответ — Σ l · dp[N][l]. `O(N² log N · L)` при L
состояниях на размер.

Хватает double: на всех 50 входах точные ожидания (посчитанные отдельно
в дробях) никогда не подходят ближе чем на 0,005 к целому числу сверху,
кроме N = 1, где ожидание ровно 1, и добавка 10⁻⁹ сохраняет его целым.
Ожидание растёт медленно: 1069,51 при N = 50.

Подводные камни:

- порядок — НОК длин циклов, а не их произведение или сумма;
- перебор всех разбиений с точными длинными числами верен, но в
  некоторых языках медленный; объединение по НОК сильно сокращает работу;
- точное целое должно пережить отбрасывание дробной части: сумма,
  получившаяся как 0,9999999…, дала бы 0 при N = 1 (тест 02).

Ответы совпадают с точными рациональными значениями на всех 50 входах,
а также с независимой принятой реализацией.
