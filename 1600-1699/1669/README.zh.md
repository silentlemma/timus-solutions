# 1669. 万能单词

[Timus 1669](https://acm.timus.ru/problem.aspx?space=1&num=1669) · 难度 1390 · bitmask

原题作者 Ivan Burmistrov（由 Alex Samsonov 准备），出自 2008 年 1 月彼得罗扎沃茨克冬季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

由前 N 个字母组成的单词称为万能的，如果这 N 个字母（每个用一次）的任意排列都是它的子序列。判断给定单词是否
万能。

## 输入

N（1 ≤ N ≤ 26），然后是长度 L ≤ 300、由前 N 个小写字母组成的单词。

## 输出

`YES` 或 `NO`。

## 样例

### 样例 1

输入：

```
3
abacaba
```

输出：

```
YES
```

### 样例 2

输入：

```
3
abcba
```

输出：

```
NO
```

## 解法

一个固定的字母顺序是子序列，当且仅当每个下一个字母都取它在前一个字母之后的第一次出现时能走完。所以对字母集合
S，设 reach(S) 为按 S 的最坏顺序做这种贪心嵌入能走到的位置。最坏顺序以某个字母 c 结尾，前面是其余字母的最坏
顺序：

reach(S) = 对 S 中的 c 取 after(c, reach(S \ {c})) 的最大值，

其中 after(c, p) 是位置 p 及之后第一个 c 的下一个位置。单词万能当且仅当全部 N 个字母的 reach 不超出单词。若某个
集合失败，任何包含它的超集也失败，因为对手可以先排这个集合。

- 按从小到大枚举掩码，每个子集都排在其超集之前，所以表格自底向上填写，且只增长到需要的地方：第一个失败的掩码
  立刻给出 `NO`。
- 先做一个快速估计：无论已经放了什么，剩下的 k 个字母有 k 个不同的下一次出现位置，最远的至少隔 k 个位置。所以
  万能单词至少需要 N + (N − 1) + … + 1 个字母，N ≥ 25 时总是 `NO`。

易错点：

- 2²⁴ 个 16 位元素的完整表格占 32 MiB；表格随着掩码的枚举而增长；
- 17 个字母上的之字形 a…q、p…a、b…q、… 长 273 且是万能的，会用到全部 2¹⁷ 个子集（测试 06）；
- 在前 17 个字母上万能的单词，仍可能缺少子序列 rb（测试 08）。

在 500 个随机小输入上，答案与穷举所有顺序的结果一致，也与一个独立的已通过实现一致。
