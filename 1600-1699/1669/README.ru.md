# 1669. Универсальное слово

[Timus 1669](https://acm.timus.ru/problem.aspx?space=1&num=1669) · сложность 1390 · bitmask

Автор оригинальной задачи — Иван Бурмистров (подготовка — Алексей Самсонов); Ural SU Contest, Петрозаводские зимние сборы, январь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Слово из первых N букв универсально, если любая расстановка этих N букв,
каждой по разу, является его подпоследовательностью. Нужно определить,
универсально ли данное слово.

## Входные данные

N (1 ≤ N ≤ 26), затем слово длины L ≤ 300 из первых N строчных букв.

## Выходные данные

`YES` или `NO`.

## Примеры

### Пример 1

Ввод:

```
3
abacaba
```

Вывод:

```
YES
```

### Пример 2

Ввод:

```
3
abcba
```

Вывод:

```
NO
```

## Решение

Данный порядок букв — подпоследовательность ровно тогда, когда, беря
каждую следующую букву в первом её вхождении после предыдущей, удаётся
пройти по слову. Поэтому для множества букв S пусть reach(S) — докуда
доходит такое жадное вложение при худшем порядке S. Худший порядок
кончается какой-то буквой c после худшего порядка остальных:

reach(S) = max по c из S от after(c, reach(S \ {c})),

где after(c, p) — место сразу за первым c на месте p или дальше. Слово
универсально ровно тогда, когда reach всех N букв не выходит за слово.
Если какое-то множество не проходит, не проходит и любое его надмножество:
противник может начать с него.

- Маски в порядке возрастания перечисляют каждое подмножество раньше
  надмножеств, поэтому таблица заполняется снизу вверх и растёт лишь
  насколько нужно: первая неудачная маска сразу даёт `NO`.
- Сначала быстрая оценка: что бы ни было уже поставлено, у оставшихся k
  букв k разных следующих вхождений, так что самое дальнее отстоит хотя
  бы на k мест. Значит, универсальному слову нужно N + (N − 1) + … + 1
  букв, и при N ≥ 25 ответ всегда `NO`.

Подводные камни:

- полная таблица из 2²⁴ 16-битных элементов занимает 32 МиБ;
  таблица растёт по мере перебора масок;
- зигзаг a…q, p…a, b…q, … на 17 буквах универсален при длине 273, и в
  дело идут все 2¹⁷ подмножеств (тест 06);
- слово, универсальное на первых 17 буквах, всё же может не содержать
  подпоследовательность rb (тест 08).

Ответы совпадают с полным перебором всех порядков на 500 случайных малых
входах и с независимой принятой реализацией.
