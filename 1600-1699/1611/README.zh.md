# 1611. 十抽一

[Timus 1611](https://acm.timus.ru/problem.aspx?space=1&num=1611) · 难度 698 · dp

原题作者 Alexander Ipatov（创意来自 Stanislav Vasiliev），出自 2008 年 3 月 29 日第十二届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n ≤ 10000 名售票员排成一列，每人是好的（`1`）或坏的（`0`）；序号是 10 的倍数的人都要被罚款。在罚款前，
最多可以把 k ≤ 50 位朋友插进队列的任意位置。要使被罚的朋友与被罚的好售票员之和最少，输出这个数以及朋友在新队列中的位置。
任何最优队列都可接受。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

n 和 k，然后是由 `0` 和 `1` 组成的队列字符串。

## 输出

最少的罚款数，然后是 m 以及 m 个朋友的位置。

## 样例

### 样例 1

输入:

```
10 2
0000000001
```

输出:

```
0
2 5 12
```

### 样例 2

输入:

```
10 2
1111111111
```

输出:

```
1
0
```

## 解法

从前往后构造新队列。已排 i 名售票员和 j 位朋友后，下一个人不论是谁都站在第 i + j + 1 位。所以到目前为止的最少罚款数
cost[i][j] 有两种转移：插入一位朋友，若该位置是 10 的倍数就被罚；或者第 i + 1 名售票员入列，只有当他是好的且站在这样的位置上才加一次罚款。
排在最后一名售票员之后的朋友只可能被罚，所以永远不需要。答案是 j ≤ k 时 cost[n][j] 的最小值，沿表格回溯即可得到朋友的位置：`O(n·(k + 1))`。

测试使用检查器，按输出的位置重建队列并统计罚款。数值已在短队列上与枚举朋友位置的所有组合对照。

注意事项：

- 一位朋友会让后面所有售票员后移一位，所以排在最前面的一位朋友就能一次救下所有好售票员（测试 05），第二位朋友反而可能只增加罚款；
- 朋友站在第十位上也会被罚，而且队列变长后可能出现新的第十位（测试 08）；
- 答案不唯一：第一个样例插入了两位朋友，但只在最前面插一位也一样好。
