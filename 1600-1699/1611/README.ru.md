# 1611. Децимация

[Timus 1611](https://acm.timus.ru/problem.aspx?space=1&num=1611) · сложность 695 · dp

Автор оригинальной задачи — Александр Ипатов (идея — Станислав Васильев); XII чемпионат Урала по спортивному программированию, 29 марта 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n ≤ 10000 кондукторов стоят в колонне, каждый хороший (`1`) или плохой
(`0`); штрафуют каждого, чей номер в колонне делится на 10. До k ≤ 50
друзей кондукторов можно поставить в колонну куда угодно до начала
штрафов. Нужно минимизировать число оштрафованных друзей плюс
оштрафованных хороших кондукторов и вывести его вместе с номерами друзей
в новой колонне. Подходит любая лучшая колонна.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

n и k, затем колонна строкой из `0` и `1`.

## Выходные данные

Наименьшее число таких штрафов, затем m и m номеров друзей.

## Примеры

### Пример 1

Ввод:

```
10 2
0000000001
```

Вывод:

```
0
2 5 12
```

### Пример 2

Ввод:

```
10 2
1111111111
```

Вывод:

```
1
0
```

## Решение

Строим новую колонну с начала. После i кондукторов и j друзей следующий
человек стоит на месте i + j + 1, кто бы он ни был. Поэтому у cost[i][j],
наименьшего числа штрафов на данный момент, два хода: встаёт друг, и его
штрафуют, если это место кратно 10, или встаёт кондуктор i + 1 и
добавляет штраф, только если он хороший и стоит на таком месте. Друзья
после последнего кондуктора могли бы только получить штраф, так что они
не нужны. Ответ — наименьшее cost[n][j] при j ≤ k, а обратный проход по
таблице даёт места друзей: `O(n·k)`.

Тесты проверяет чекер, который восстанавливает колонну по выведенным
местам и считает её штрафы. Числа сверены с перебором всех наборов мест
для друзей на коротких колоннах.

Подводные камни:

- друг сдвигает на одно место всех кондукторов за ним, так что один
  друг в начале может спасти сразу всех хороших кондукторов (тест 05),
  а второй друг может лишь добавить штраф;
- сами друзья на десятых местах тоже получают штраф, а удлинённая
  колонна может дотянуться до нового десятого места (тест 08);
- ответ не единственный: в первом примере ставятся два друга, но один в
  начале ничуть не хуже.
