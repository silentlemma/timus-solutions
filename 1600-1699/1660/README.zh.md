# 1660. 倒霉岛

[Timus 1660](https://acm.timus.ru/problem.aspx?space=1&num=1660) · 难度 5926 · geometry

原题作者 Alexander Kokovin（由 Alexander Ipatov 准备），出自 2008 年 1 月彼得罗扎沃茨克冬季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

画有一个半径为 R 的圆，其内部有一个半径为 r 的圆，两圆心相距 d。第一位玩家画一个圆，从内部与大圆相切、从外部
与小圆相切。之后依次画的每个圆都必须与两个给定圆以及上一个刚画的圆相切，且不与其他圆相交（允许与第一个圆相切）。
某一步有两种画法时，由第一位玩家决定。当再也画不下时，测量第一个圆与最后一个圆之间的距离。求第一位玩家能达到的
最小距离。

## 输入

整数 R、r、d，满足 0 < r < R − d，d ≥ 0，均不超过 100。

## 输出

该距离，小数点后至少 5 位。

## 样例

### 样例 1

输入：

```
3 1 0
```

输出：

```
0.00000
```

## 解法

这些圆构成施泰纳链。以两给定圆的一个极限点（同时关于两个圆互为反演点的两点之一）为中心做反演，两圆变为同心圆。
小圆内部的极限点为

p = 2·d·R² / (b + √(b² − 4·d²·R²))，其中 b = R² + d² − r²，

从大圆圆心朝小圆圆心方向量取；d = 0 时它就是公共圆心，无需特殊处理。反演保持相切与相交关系，而在同心的图形中，
链上每个圆半径都是 w，到中心的距离都是 m，所以每个新圆都是前一个绕中心转过同一角度 α = 2·asin(w / m)。因此
无论从哪里开始，链上总有 n = ⌊2π / α⌋ 个圆，最后一个与第一个相差 (n − 1)·α。

剩下唯一的自由是第一个圆的起点（另一个方向只是镜像）。把第一个和最后一个圆反演回去，就得到它们的距离
|c₁ − c₂| − r₁ − r₂，它是起始角的函数。最佳起点总是对称的：首尾圆关于圆心连线（d = 0 时任一直径）互为镜像，
缺口中心位于其一条射线上。这一点已在全部 166 650 个合法输入上验证，对照的是扫描 20 000 个起始角再用三分搜索细化的结果，
两者相差不超过 10⁻¹⁰。实际上总是缺口在环较窄一侧的那种更优；解法直接取两者中较小的。`O(1)`。

易错点：

- 链恰好闭合时答案为 0，所以计数时要给舍入留一点余量（测试 01 和 05）；
- 只能放下两个圆时，最后一个与第一个相切（测试 06）；
- 按上面的写法求极限点不需要两个几乎相等的数相减，对很薄的环也能保持精度（测试 02–04）。

在全部 166 650 个输入上，答案与一个独立的已通过实现一致。
