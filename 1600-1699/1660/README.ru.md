# 1660. Остров Невезения

[Timus 1660](https://acm.timus.ru/problem.aspx?space=1&num=1660) · сложность 6373 · geometry

## Задача

Нарисована окружность радиуса R, а внутри неё окружность радиуса r,
центр которой на расстоянии d. Первый игрок рисует окружность, касающуюся
большой изнутри и малой снаружи. Затем по очереди каждая следующая
окружность должна касаться обеих данных и только что нарисованной, не
пересекая других (касаться самой первой можно). Если шаг можно сделать
двумя способами, решает первый игрок. Когда окружностей больше не
помещается, измеряется расстояние между первой и последней. Нужно найти
наименьшее расстояние, которого может добиться первый игрок.

## Входные данные

Целые R, r и d, 0 < r < R − d, d ≥ 0, все не больше 100.

## Выходные данные

Расстояние, не менее чем с 5 знаками после десятичной точки.

## Примеры

### Пример 1

Ввод:

```
3 1 0
```

Вывод:

```
0.00000
```

## Решение

Окружности образуют цепочку Штейнера. Инверсия плоскости относительно
предельной точки двух данных окружностей (одной из двух точек,
симметричных друг другу относительно обеих окружностей сразу) делает
окружности концентрическими. Предельная точка внутри малой окружности —

p = 2·d·R² / (b + √(b² − 4·d²·R²)), где b = R² + d² − r²,

отсчитанная от большого центра в сторону малого; при d = 0 это общий
центр, так что особый случай не нужен. Инверсия сохраняет касания и
пересечения, а в концентрической картине у всех окружностей цепочки
одинаковый радиус w и одинаковое расстояние m до центра, так что каждая
новая — это предыдущая, повёрнутая на один и тот же угол
α = 2·asin(w / m). Поэтому в цепочке всегда n = ⌊2π / α⌋ окружностей, а
последняя отстоит от первой на (n − 1)·α, где бы цепочка ни началась.

Остаётся выбрать только место первой окружности (другое направление —
просто зеркальное отражение). Отобразив первую и последнюю окружности
обратно, получаем расстояние |c₁ − c₂| − r₁ − r₂ как функцию угла старта.
Лучший старт всегда симметричный: первая и последняя окружности
зеркальны относительно прямой через два центра, а зазор лежит с одной из
двух её сторон. Это проверено на всех 166 650 допустимых входах против
перебора 20 000 углов старта с уточнением тернарным поиском; результаты
совпадают с точностью 10⁻¹⁰. На деле выигрывает зазор с узкой стороны
кольца; решение просто берёт меньший из двух. `O(1)`.

Подводные камни:

- когда цепочка замыкается точно, ответ 0, поэтому при подсчёте нужен
  небольшой запас на округление (тесты 01 и 05);
- если помещаются только две окружности, последняя касается первой
  (тест 06);
- в таком виде предельная точка не требует вычитания почти равных чисел,
  что сохраняет точность для тонких колец (тесты 02–04).

Ответы совпадают с независимой принятой реализацией на всех 166 650
входах.
