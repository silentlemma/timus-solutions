## Задача

Билеты нумеруются 1, 2, 3, … без ведущих нулей. Билет d₁d₂…dₙ
счастливый, если никакие две противоположные цифры не совпадают:
dᵢ ≠ dₙ₊₁₋ᵢ при i ≠ n + 1 − i. Нужно посчитать счастливые билеты от a до
b (1 ≤ a ≤ b ≤ 10¹⁸).

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

a и b.

## Выходные данные

Количество счастливых билетов.

## Примеры

### Пример 1

Ввод:

```
1 10
```

Вывод:

```
10
```

### Пример 2

Ввод:

```
100 2000
```

Вывод:

```
1620
```

## Решение

Посчитаем счастливые билеты до n, f(n), и выведем f(b) − f(a − 1).

Цифры разбиваются на противоположные пары и при нечётной длине на
среднюю цифру. Когда несколько начальных цифр зафиксированы, остальные
считаются по парам: у пары с обеими фиксированными цифрами они должны
различаться (иначе ответ 0), пара с фиксированной только левой цифрой
оставляет 9 вариантов для правой, пара со свободными цифрами — 10·9 = 90,
свободная средняя цифра — 10. Префикс всегда фиксируется слева, так что у
пары не бывает фиксированной только правой цифры.

f(n) складывает все более короткие числа по первой цифре от 1 до 9 и
числа длины n, меньшие n, — по первой позиции, где они становятся меньше
n, и меньшей цифре на ней; само n добавляется, если оно счастливое. При
не более чем 19 цифрах это несколько тысяч шагов.

Количества сверены с проверкой всех чисел до 300000.

Подводные камни:

- первая цифра не может быть 0, в том числе при подсчёте более коротких
  чисел;
- у средней цифры нечётной длины нет пары, и она всегда свободна;
- количество до 10¹⁸ около 3,9·10¹⁷ и помещается в 64 бита, но a − 1
  может быть 0, и тогда количество равно 0.
