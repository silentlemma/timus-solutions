# 1666. 瓦夏·费拉里

[Timus 1666](https://acm.timus.ru/problem.aspx?space=1&num=1666) · 难度 1285 · math

原题作者 Igor Chevdar，出自 2008 年 1 月彼得罗扎沃茨克冬季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把 x⁴ + ax³ + bx² + cx + d 分解成尽可能多的整系数因式。若不能分解，输出 `Irreducible`，否则输出括号括起的各
因式，不加空格，不写零项、系数 1 和指数 1（常数项 1 要写）。

## 输入

整数 a、b、c、d，绝对值不超过 20000。

## 输出

分解式或 `Irreducible`。

## 样例

### 样例 1

输入：

```
0 0 0 0
```

输出：

```
(x)(x)(x)(x)
```

### 样例 2

输入：

```
-4 -3 24 45
```

输出：

```
(x2+3x+3)(x2-7x+15)
```

### 样例 3

输入：

```
1 1 1 1
```

输出：

```
Irreducible
```

## 解法

多项式是首一的，由高斯引理，整数上的任何分解都可以用首一因式表示，因式最多的分解就是分解成不可约因式。

1. 逐个提取整数根。首一整系数多项式的根整除常数项（常数项为 0 意味着根 0），所以枚举常数项的因数就能找到。每个
   根 r 分出因式 x − r，综合除法得到商。
2. 若再没有根，剩下的三次或二次多项式不可约。
3. 没有根的四次多项式要么不可约，要么是两个二次式之积 (x² + px + q)(x² + rx + s)。比较系数：qs = d，
   p + r = a，q + s + pr = b，ps + qr = c。对 d 的每个因数 q 取 s = d / q；若 q ≠ s，后两式给出
   p(s − q) = c − aq，p 唯一确定；若 q = s，p 与 r 是 t² − at + (b − 2q) 的根，只有判别式为完全平方数时才是
   整数。每个候选都用全部四个等式检验。

不超过 20000 的数的因数用 √20000 步求出，所有数值都小于 10¹⁸。`O(√|d|)`。

易错点：

- 因式顺序任意；检查器把它们乘回去、计数并检查每个因式的写法；
- x⁴ + 4 没有根，但可以分解为 (x² + 2x + 2)(x² − 2x + 2)（测试 11）；
- 两个二次式常数项相等时需要走判别式的分支（测试 06）。

在随机和构造的输入上，答案与一个独立的已通过实现一致。
