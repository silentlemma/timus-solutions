# 1666. Про Васю Феррари

Автор оригинальной задачи — Игорь Чевдарь; Ural SU Contest, Петрозаводские зимние сборы, январь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Разложить x⁴ + ax³ + bx² + cx + d на как можно большее число множителей
с целыми коэффициентами. Вывести `Irreducible`, если разложения нет,
иначе множители в скобках, без пробелов, нулевых слагаемых, единичных
коэффициентов и показателей 1 (свободный член 1 пишется).

## Входные данные

Целые a, b, c, d, по модулю не больше 20000.

## Выходные данные

Разложение или `Irreducible`.

## Примеры

### Пример 1

Ввод:

```
0 0 0 0
```

Вывод:

```
(x)(x)(x)(x)
```

### Пример 2

Ввод:

```
-4 -3 24 45
```

Вывод:

```
(x2+3x+3)(x2-7x+15)
```

### Пример 3

Ввод:

```
1 1 1 1
```

Вывод:

```
Irreducible
```

## Решение

Многочлен приведённый, поэтому по лемме Гаусса любое разложение над
целыми можно составить из приведённых множителей, а больше всего
множителей даёт разложение на неприводимые.

1. Целые корни выделяются по одному. Целый корень приведённого многочлена с
   целыми коэффициентами делит свободный член (нулевой свободный член
   означает корень 0), поэтому перебор делителей свободного члена его
   находит. Каждый корень r даёт множитель x − r, а деление по схеме
   Горнера оставляет частное.
2. Если корней больше нет, оставшиеся кубический или квадратный
   многочлен неприводимы.
3. Многочлен четвёртой степени без корней либо неприводим, либо
   произведение двух квадратных (x² + px + q)(x² + rx + s). Сравнение
   коэффициентов: qs = d, p + r = a, q + s + pr = b, ps + qr = c. Для
   каждого делителя q числа d берём s = d / q; если q ≠ s, исключение r
   даёт p(s − q) = c − aq, и p определено однозначно; если q = s, p и r —
   корни t² − at + (b − 2q), целые только при дискриминанте — точном
   квадрате. Каждый кандидат проверяется по последним двум равенствам.

Здесь B = max(1, |a|, |b|, |c|, |d|) ≤ 20000, и все значения
остаются меньше 10¹⁸.

Подводные камни:

- множители могут идти в любом порядке; чекер перемножает их, считает и
  проверяет запись каждого;
- у x⁴ + 4 нет корней, но он раскладывается в
  (x² + 2x + 2)(x² − 2x + 2) (тест 11);
- одинаковые свободные члены двух квадратных требуют пути через
  дискриминант (тест 06).

Ответы совпадают с независимой принятой реализацией на случайных и
построенных входах.
