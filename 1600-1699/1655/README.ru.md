# 1655. Сомалийские пираты

[Timus 1655](https://acm.timus.ru/problem.aspx?space=1&num=1655) · сложность 1818 · dp

Автор оригинальной задачи — Денис Мусин; четвертьфинал Восточного подрегиона NEERC 2008.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Лазерная пушка на корабле поворачивается со скоростью до w оборотов в
минуту и стреляет мгновенно, топя всё на линии огня. n пиратских кораблей
идут прямо к ней, корабль i — с азимута bᵢ на расстоянии dᵢ морских миль
со скоростью vᵢ узлов. Ни один пират не должен подойти ближе чем на морскую
милю. Пушка сначала смотрит по азимуту a; нужно найти наименьшее время,
за которое можно потопить всех, и порядок стрельбы или сообщить, что это невозможно.

## Входные данные

a, w и n (0 ≤ a < 360, 0.01 ≤ w ≤ 1, 1 ≤ n ≤ 500), затем n строк
bᵢ dᵢ vᵢ (0 ≤ bᵢ < 360, 1 ≤ dᵢ ≤ 1000, 0.01 ≤ vᵢ ≤ 100), все азимуты
пиратских кораблей различны.

## Выходные данные

Наименьшее время в минутах с точностью 10⁻³ и порядок кораблей по
одному номеру в строке или `Impossible`.

## Примеры

### Пример 1

Ввод:

```
0.0 0.05 2
144.0 22.0 100.0
216.0 22.0 100.0
```

Вывод:

```
12.000
2
1
```

### Пример 2

Ввод:

```
0.0 0.05 2
144.0 20.0 100.0
216.0 20.0 100.0
```

Вывод:

```
Impossible
```

## Решение

Корабль i нужно потопить за (dᵢ − 1) / vᵢ · 60 минут. Будем отсчитывать
азимуты по часовой стрелке от начального направления пушки; корабли
прямо по курсу топятся в момент 0. Пушка стреляет на ходу, так что любой
корабль, через который она проходит, можно сразу и потопить, а значит, в
каждый момент потопленные корабли образуют дугу вокруг начала: часть
взята поворотом влево (против часовой), часть — вправо.

Поэтому состояние — (i, j, конец): потоплены i ближайших к началу
кораблей слева и j ближайших справа, а пушка смотрит на левый или правый
конец этой дуги. Наименьшее время состояния получается из двух меньших
состояний — продолжая в ту же сторону или возвращаясь через начало с
другого конца, — и шаг допустим, только если новый корабль достигнут не
позже его срока. Ответ — лучшее состояние с i + j, равным числу оставшихся
кораблей; запомненные выборы дают порядок. `O(n²)` состояний, не более
125 751 пары (i, j).

Подводные камни:

- переход от одного конца к другому проходит через начало, так что
  стоит сумму двух расстояний, а не их разность;
- корабль, уже находящийся в миле, допустим, только если он прямо по
  курсу (тест 03);
- когда оба направления одинаково быстры (первый пример), программа
  предпочитает закончить слева, как и независимая принятая реализация;
  чекер принимает любой порядок с наименьшим временем.

Ответы совпадают с независимой принятой реализацией на 60 случайных
тестах, включая порядок.
