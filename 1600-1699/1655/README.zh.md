# 1655. 索马里海盗

[Timus 1655](https://acm.timus.ru/problem.aspx?space=1&num=1655) · 难度 1818 · dp

原题作者 Denis Musin，出自 NEERC 2008 东部分区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

船上的激光炮每分钟最多转 w 圈，射击瞬间完成，击沉射线上的一切。n 艘海盗船径直驶来，第 i 艘从方位角 bᵢ、
距离 dᵢ 海里处以 vᵢ 节的速度接近。任何海盗船都不能靠近到一海里以内。炮起初指向方位角 a，求击沉全部海盗船
的最短时间和射击顺序，或指出不可能。

## 输入

a、w 和 n（0 ≤ a < 360，0.01 ≤ w ≤ 1，1 ≤ n ≤ 500），然后 n 行 bᵢ dᵢ vᵢ（0 ≤ bᵢ < 360，
1 ≤ dᵢ ≤ 1000，0.01 ≤ vᵢ ≤ 100），所有海盗船的方位角互不相同。

## 输出

最短时间（分钟，精度 10⁻³）以及船的顺序，每行一个编号；或者输出 `Impossible`。

## 样例

### 样例 1

输入：

```
0.0 0.05 2
144.0 22.0 100.0
216.0 22.0 100.0
```

输出：

```
12.000
2
1
```

### 样例 2

输入：

```
0.0 0.05 2
144.0 20.0 100.0
216.0 20.0 100.0
```

输出：

```
Impossible
```

## 解法

第 i 艘船必须在 (dᵢ − 1) / vᵢ · 60 分钟内击沉。把方位角按顺时针从炮的初始方向起算；正前方的船在时刻 0
击沉。炮转动时也能射击，所以经过的船都可以顺手击沉，于是任何时刻已击沉的船构成包含起点的一段弧：一部分
是向左（逆时针）转得到的，一部分是向右。

因此状态为 (i, j, 端点)：左侧离起点最近的 i 艘和右侧最近的 j 艘已被击沉，炮指向这段弧的左端或右端。每个
状态的最早时间来自两个更小的状态——沿同一方向继续，或从另一端穿过起点折回——并且只有不晚于新船的期限到达
才允许这一步。答案是 i + j 等于剩余船数的最佳状态；记录的选择给出顺序。共 `O(n²)` 个状态，最多 125 751 对 (i, j)。

易错点：

- 从一端到另一端要经过起点，代价是两段距离之和，而不是差；
- 已在一海里处的船只有正对炮口时才来得及（测试 03）；
- 两个方向一样快时（第一个样例），程序和一个独立的已通过实现一样优先在左端结束；检查器接受任何时间最短的顺序。

在 60 个随机测试上，答案（包括顺序）与一个独立的已通过实现一致。
