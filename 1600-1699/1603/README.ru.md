# 1603. Эрудит

[Timus 1603](https://acm.timus.ru/problem.aspx?space=1&num=1603) · сложность 255 · implementation

Автор оригинальной задачи — Владимир Яковлев; IX открытое личное первенство УрГУ, 1 марта 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Таблица 4 × 4 заполнена строчными буквами. Слово можно записать в ней по
пути из соседних по горизонтали или вертикали клеток, который может
поворачивать под прямым углом где угодно, но не проходит по клетке
дважды. Для каждого из не более 100 слов длиной от 1 до 16 букв нужно
сказать, можно ли его найти.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Четыре строки таблицы, затем n и слова.

## Выходные данные

`word: YES` или `word: NO` для каждого слова.

## Проверка

Вывод сравнивается полностью, включая пробелы и переводы строк.

## Примеры

### Пример 1

Ввод:

```
abra
adac
babr
arca
3
abracadabra
ababaab
ababaaba
```

Вывод:

```
abracadabra: YES
ababaab: YES
ababaaba: NO
```

## Решение

Поиск в глубину идёт от каждой клетки с первой буквой и шагает в
неиспользованную соседнюю клетку со следующей буквой. Использованные
клетки образуют 16-битную маску. Из-за повторяющихся букв поиск может
много раз попадать в одну и ту же ситуацию: то же множество
использованных клеток, та же последняя клетка и тот же остаток слова.
Поэтому неудачная пара (маска, клетка) запоминается и больше не
перебирается; таких пар не больше 16·2¹⁶, а достижимых на деле гораздо
меньше. Быстрая проверка заранее отбрасывает слово, которому нужно
больше какой-то буквы, чем есть в таблице.

Результаты сверены с независимой реализацией на сгенерированных
таблицах, включая таблицы из одной повторённой буквы с длинными словами.

Подводные камни:

- подсчёт букв может отвергнуть слово ещё до поиска: пятнадцати клеток
  `a` не хватит для шестнадцати букв `a`, а единственную клетку `b` нельзя
  использовать для обоих концов слова (тест 04);
- повторяющиеся буквы могут приводить к повторному перебору состояний,
  поэтому неудачные пары (маска, клетка) нужно запоминать; в тесте 07
  четырнадцать клеток `a` и отдельные клетки `b` и `c`, а самое длинное
  слово проходит проверку количества букв;
- такой ответ NO может следовать из одной лишь чётности: если раскрасить
  таблицу как шахматную доску, путь из 16 клеток всегда заканчивается на
  другом цвете, так что слово, начинающееся и заканчивающееся в клетках
  одного цвета, не может занять все 16 клеток (тест 07);
- клетку нельзя использовать дважды, а шаги только по горизонтали или
  вертикали (тест 03).

## Оптимизированные решения

Поиск по-прежнему идёт по соседним клеткам без повторного посещения. Неудачные состояния запоминаются по текущему концу и маске посещённых клеток; позиция в слове следует из размера маски и не увеличивает ключ. Маски допустимых букв и соседства отсекают невозможные продолжения до ветвления. Для одинаковых слов переиспользуется результат. Поле фиксировано и мало: явно учитывается перебор подмножеств, а не заявляется полиномиальное время поиска.
