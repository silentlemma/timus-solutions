# 1664. Нефтепроводы

[Timus 1664](https://acm.timus.ru/problem.aspx?space=1&num=1664) · сложность 1965 · graphs

Автор оригинальной задачи — Артём Мелентьев; Ural SU Contest, Петрозаводские зимние сборы, январь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На плоскости N станций, и M прямых нефтепроводов соединяют их пары; два
нефтепровода встречаются только в общей станции. Каждый пропускает не
больше своей пропускной способности, в любую сторону. У станции 1
наименьшая координата x, у станции N — наибольшая. Нужно найти
наибольший поток от станции 1 к станции N и план: для каждого
нефтепровода направление и количество.

## Входные данные

N (2 ≤ N ≤ 10000) и координаты станций (целые, по модулю не больше
10⁸), затем M и нефтепроводы: две станции и пропускная способность от 1
до 10⁸. Наибольший поток положителен и не больше 2·10⁹.

## Выходные данные

Наибольший поток, затем M строк «A B C»: C единиц течёт из A в B,
C ≥ 0, каждый нефтепровод ровно один раз.

## Примеры

### Пример 1

Ввод:

```
3
0 0
1 1
2 0
2
1 2 2
2 3 1
```

Вывод:

```
1
1 2 1
2 3 1
```

## Решение

Нефтепроводы образуют плоский граф, у которого исток и сток лежат на
внешней грани, поэтому наибольший поток получается из кратчайших путей в
двойственном графе. Добавим одно лишнее ребро, которое уходит из истока
влево, обходит всё снаружи и входит в сток справа; оно делит внешнюю
грань на две — верхнюю и нижнюю. Каждый разрез между истоком и стоком —
это путь в двойственном графе от одной из этих граней к другой, так что
наибольший поток равен кратчайшему такому пути с пропускными
способностями в роли длин.

Грани получаются сортировкой нефтепроводов вокруг каждой станции по
углу: придя на станцию по нефтепроводу, грань продолжается по следующему
нефтепроводу по часовой стрелке. Дейкстра от одной из двух граней даёт
расстояние d до каждой грани, а поток по нефтепроводу от его левой грани
к правой равен d(правая) − d(левая). Эти разности не превосходят
пропускной способности, взаимно сокращаются вокруг каждой транзитной
станции и в сумме у истока дают кратчайшее расстояние. `O(M log M)`.

Подводные камни:

- при координатах до 10⁸ два направления могут отличаться меньше, чем
  различает double (тест 02), поэтому углы сравниваются точно
  целочисленным векторным произведением; Python сначала сортирует по
  вещественным углам, а потом точно исправляет почти равных соседей;
- у частей карты, недостижимых из истока, грани недостижимы для
  Дейкстры; по их нефтепроводам ничего не течёт (тест 04);
- направление лишнего ребра задаёт знак всех разностей, поэтому решение
  разворачивает план, если нефть потекла бы в исток.

Потоки проверяет чекер — пропускные способности, сохранение и итог, — а
итоговые значения совпадают с независимой принятой реализацией.
