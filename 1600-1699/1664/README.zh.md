# 1664. 输油管道

[Timus 1664](https://acm.timus.ru/problem.aspx?space=1&num=1664) · 难度 1863 · graphs

原题作者 Artem Melentyev，出自 2008 年 1 月彼得罗扎沃茨克冬季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

平面上有 N 个站点，M 条直线管道连接其中一些站点对；两条管道只在公共站点处相遇。每条管道双向都可输送，但不超过
其容量。站点 1 的 x 坐标最小，站点 N 的 x 坐标最大。求从站点 1 到站点 N 的最大流，以及一个方案：每条管道的方向
和流量。

## 输入

N（2 ≤ N ≤ 10000）和各站点坐标（绝对值不超过 10⁸ 的整数），然后是 M 和各管道：两个站点和 1 到 10⁸ 之间的
容量。最大流为正且不超过 2·10⁹。

## 输出

最大流，然后 M 行 "A B C"：C 个单位从 A 流向 B，C ≥ 0，每条管道恰好列出一次。

## 样例

### 样例 1

输入：

```
3
0 0
1 1
2 0
2
1 2 2
2 3 1
```

输出：

```
1
1 2 1
2 3 1
```

## 解法

管道构成平面图，源点和汇点都在外部面上，所以最大流可以由对偶图中的最短路得到。加一条额外的边，从源点向左离开，
绕到外面，再从右边进入汇点；它把外部面分成上下两个面。最小割对应于这两个面之间的对偶最短路，以容量为长度，
不含额外边；路径长度就是最大流。

面通过在每个站点周围按角度排序管道得到：沿某条管道到达一个站点后，面沿顺时针方向的下一条管道继续。从这两个面之一
做 Dijkstra，得到每个可达面的距离 d，沿管道选定方向的带符号流量为 d(右) − d(左)。这些差值的绝对值不超过容量，
在中转站点周围相互抵消，在源点处总和的绝对值等于最短距离。

易错点：

- 坐标可达 10⁸，两个方向的差别可能小于 double 能分辨的程度（测试 10），所以用整数叉积精确比较角度；Python 先按
  浮点角度排序，再精确修正几乎相等的相邻项（共 K 次相邻交换）；
- 面边界遍历按连通分量编号；其他分量的编号在 Dijkstra 中不可达，这些管道上没有流（测试 04）；
- 额外边的方向决定所有差值的符号，所以若油会流入源点，解法就把方案整体反向。

检查器会验证流量的容量、守恒和总量，总量也与一个独立的已通过实现一致。
