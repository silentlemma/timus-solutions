# 1628. Белые полосы

[Timus 1628](https://acm.timus.ru/problem.aspx?space=1&num=1628) · сложность 164 · implementation

Автор оригинальной задачи — Александр Ипатов; XIII открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Календарь — таблица m × n: строка i — неделя, столбец j — день недели.
Некоторые k клеток закрашены чёрным (неудачные дни), остальные белые.
Отрезок — прямоугольник клеток 1 × l или l × 1. Нужно посчитать белые
полосы: максимальные по включению белые отрезки.

## Входные данные

В первой строке m, n и k (1 ≤ m, n ≤ 30000, 0 ≤ k ≤ 60000). В каждой из
следующих k строк — чёрная клетка x y (1 ≤ x ≤ m, 1 ≤ y ≤ n); клетки
различны.

## Выходные данные

Количество белых полос.

## Примеры

### Пример 1

Ввод:

```
3 5 4
1 1
1 5
2 2
3 3
```

Вывод:

```
8
```

### Пример 2

Ввод:

```
5 1 2
2 1
3 1
```

Вывод:

```
2
```

## Решение

В каждой строке чёрные клетки делят её на белые участки, и в каждом
столбце так же. Участок длины 2 и больше — полоса. Одиночная белая
клетка устроена иначе: это отрезок 1 × 1 сразу в обоих направлениях,
поэтому она считается один раз и только если не растёт ни в одну
сторону, то есть её соседи по строке и по столбцу все чёрные или за
краем таблицы. Иначе клетка уже лежит в более длинной полосе.

Итак, строки считают свои участки длины не меньше 2 плюс одиночные
клетки, закрытые сверху и снизу, а столбцы — только участки длины не
меньше 2. Каждая строка и каждый столбец сортируют свои чёрные клетки,
а множество проверяет соседей: в C++ упорядоченное, в остальных — хеш-множество.
C++: `O(m + n + (m + k) log(k + 1))`; остальные: `O(m + n + k log k)`.

Подводные камни:

- одиночную белую клетку нельзя считать дважды, по разу на направление
  (тест 05);
- при одной строке или одном столбце каждая белая клетка закрыта краем
  в другом направлении (второй пример);
- в полностью белой таблице при m, n > 1 есть m + n полос, так что
  строки и столбцы без чёрных клеток тоже считаются (тест 06).

Ответы совпадают с независимой принятой реализацией на 120 случайных
календарях и на самом большом.
