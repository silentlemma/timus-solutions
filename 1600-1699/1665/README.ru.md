# 1665. Финансовая пирамида декана

## Задача

К вечеру первого дня на столе лежит одно заявление. Каждый следующий
день число заявлений умножается на целый множитель — 2 или нечётное
число больше 1, — возможно, каждый день разный. Деньги выплачивают
только в чётный день и только если вечером на столе ровно N заявлений.
Для каждого N нужно решить, возможно ли это.

## Входные данные

T (1 ≤ T ≤ 100), затем T чисел N (1 ≤ N ≤ 2²⁵ − 1).

## Выходные данные

`YES` или `NO` для каждого N.

## Примеры

### Пример 1

Ввод:

```
4
4
7
6
30
```

Вывод:

```
NO
YES
NO
YES
```

## Решение

В день d число заявлений — произведение d − 1 множителей, а d должен
быть чётным, так что вопрос в том, раскладывается ли N в произведение
нечётного числа множителей, каждый из которых 2 или нечётное число
больше 1. Запишем N = 2ᵃ · r, r нечётное. Множитель двойку в N вносит
только множитель 2, поэтому таких множителей ровно a, а нечётные дают в
произведении r.

- Если r = 1, множителей ровно a: `YES`, когда a нечётно (N = 1 — это
  первый день, выплаты не будет).
- Если a чётно и r > 1, a двоек и само r дают a + 1 множителей —
  нечётное число: `YES`.
- Если a нечётно, r нужно разбить на чётное число нечётных множителей
  больше 1, а это возможно ровно тогда, когда r не простое (два
  множителя или больше при необходимости): `YES` для составного r,
  `NO` для простого.

Простота проверяется делением на нечётные числа до √r, это не больше
примерно 2900 делителей. `O(T · √N)`.

Подводные камни:

- N = 1 и N = 2ᵃ с чётным a — `NO`; 2ᵃ с нечётным a — `YES` (тест 02);
- степень двойки с нечётным показателем, умноженная на простое, — `NO`
  (6 в примере, 2²³ · 3 в тесте 03).

Ответы совпадают с полным перебором последовательностей множителей для
всех N до 3000 и с независимой принятой реализацией.
