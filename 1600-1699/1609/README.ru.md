# 1609. Трамвайная плитка

[Timus 1609](https://acm.timus.ru/problem.aspx?space=1&num=1609) · сложность 2995 · constructive

Автор оригинальной задачи — Сергей Пупырев; XII чемпионат Урала по спортивному программированию, 29 марта 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Прямоугольник n × m (n, m ≤ 10, nm чётно) нужно замостить плитками
1 × 2. Начальник сначала кладёт несколько плиток так, чтобы остальное
можно было доделать ровно одним способом. Нужно найти наименьшее число
таких плиток и показать одну расстановку: занятые ими клетки как `1`,
остальные как `0`. Подходит любая оптимальная расстановка.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

n и m.

## Выходные данные

Число плиток, затем n строк по m символов.

## Примеры

### Пример 1

Ввод:

```
4 4
```

Вывод:

```
2
1100
0110
0000
0000
```

### Пример 2

Ввод:

```
2 5
```

Вывод:

```
2
11110
00000
```

## Решение

Это наименьшее число вынуждения для замощений клетчатого прямоугольника
доминошками. Досок всего 75, поэтому ответы найдены один раз заранее
перебором и хранятся в программе: 40 шаблонов, по одному для каждого
n ≤ m, а при n > m шаблон поворачивается набок.

Перебор опирается на быструю проверку. В двудольном графе с единственным
совершенным паросочетанием всегда есть вершина степени 1 (теорема
Коцига), так что у свободных клеток единственное замощение ровно тогда,
когда повторное покрытие клетки с единственным свободным соседом
исчерпывает их все. При k = 0, 1, 2, … перебираются все наборы из k
непересекающихся плиток с этой проверкой, и первое подходящее k — ответ:
полный перебор при k − 1 доказывает, что меньшего числа плиток не
хватает. Самой большой доске 10 × 10 нужно 5 плиток, это около минуты
счёта; любая другая доска — около секунды.

Хранимые шаблоны устроены так, что и сами занятые клетки замощаются
единственным образом, поэтому картинка из `1` и `0` однозначно задаёт
всё замощение при любом прочтении. Ответы для квадратов согласуются с
теоремой Пахтера и Кима: доске 2k × 2k нужно k плиток.

Тесты проверяет чекер: число плиток, то, что отмеченные клетки
покрываются таким числом плиток, и то, что у свободных клеток ровно одно
замощение.

Подводные камни:

- у полоски 1 × m уже только одно замощение, так что ответ 0, а таблица
  из одних нулей (тесты 03, 05 и 06);
- узкие доски труднее: 2 × 8 нужно 3 плитки, а 3 × 8 — только 2 (тесты
  07 и 09);
- вывод показывает не то, как лежат плитки, а только занятые ими клетки;
  шаблоны, чьи занятые клетки замощаются единственным образом, снимают
  любые сомнения.
