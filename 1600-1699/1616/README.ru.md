# 1616. Квадратная страна 4

[Timus 1616](https://acm.timus.ru/problem.aspx?space=1&num=1616) · сложность 3993 · geometry

## Задача

Карта квадрата [−n, n] × [−n, n] (1 ≤ n ≤ 30) показывает владельца
каждой единичной клетки: строчная буква у каждого владельца, `.` у
государства. Ось x направлена вправо, ось y — вверх. Затем оси
координат поворачивают по часовой стрелке вокруг (0, 0) на α градусов
(0 ≤ α ≤ 90, вещественное), и каждая единичная клетка новой сетки
достаётся владельцу, которому до поворота принадлежало больше половины
её площади, или государству, если такого нет. Выведите новую карту
квадрата [−2n, 2n] × [−2n, 2n] в том же виде.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n и α, затем 2n строк по 2n символов.

## Выходные данные

4n строк по 4n символов.

## Примеры

### Пример 1

Ввод:

```
2 45.0
aaaa
aaaa
bb.x
bbx.
```

Вывод:

```
........
........
...aa...
..aa.x..
..a..x..
...bb...
........
........
```

## Решение

Поворот осей по часовой стрелке поворачивает землю против часовой
стрелки в новых координатах. Каждая клетка владельца становится
квадратом, повёрнутым на α; он задевает лишь несколько новых клеток в
пределах своего ограничивающего прямоугольника. Отсечение повёрнутого
квадрата каждой из этих клеток (четыре полуплоскости, как в методе
Сазерленда — Ходжмана) даёт многоугольник пересечения, а формула
шнурования — его площадь, которая добавляется к доле владельца в этой
клетке. Клетка достаётся владельцу, чья доля больше 1/2 больше чем на
10⁻⁹. Клеток владельцев не больше 3 600, так что это мгновенно.
`O(n²)`.

Подводные камни:

- доля ровно в половину — не больше половины: такие клетки уходят
  государству (разрезанные клетки примера при 45 градусах);
- при α = 0 и α = 90 клетки переходят точно в клетки, и рёбра, которые
  только касаются, не должны добавлять площадь (тесты 02, 03);
- радианы во всех языках считаются как α · π / 180, чтобы пограничные
  доли округлялись одинаково.

Ответы совпадают с независимой принятой реализацией на 150 случайных
картах.
