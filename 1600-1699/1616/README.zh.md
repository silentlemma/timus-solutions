# 1616. 方形国 4

[Timus 1616](https://acm.timus.ru/problem.aspx?space=1&num=1616) · 难度 3993 · geometry

原题作者 Vladimir Yakovlev（创意来自 Stanislav Vasilyev），出自 2008 年 3 月 29 日第十二届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

正方形 [−n, n] × [−n, n]（1 ≤ n ≤ 30）的地图标出每个单位格的主人：每个主人
一个小写字母，`.` 表示属于国家。x 轴向右，y 轴向上。然后坐标轴绕 (0, 0) 顺时针
旋转 α 度（0 ≤ α ≤ 90，实数），新网格的每个单位格归在旋转前拥有其一半以上面积的
主人；若没有这样的主人则归国家。以同样格式输出 [−2n, 2n] × [−2n, 2n] 的新地图。

时间限制：1 秒。内存限制：64 MB。

## 输入

n 和 α，然后是 2n 行，每行 2n 个字符。

## 输出

4n 行，每行 4n 个字符。

## 样例

### 样例 1

输入：

```
2 45.0
aaaa
aaaa
bb.x
bbx.
```

输出：

```
........
........
...aa...
..aa.x..
..a..x..
...bb...
........
........
```

## 解法

坐标轴顺时针旋转，相当于土地在新坐标中逆时针旋转。每个被拥有的格子变成一个旋转了 α
的正方形，它只与其外接矩形内的少数几个新格子相交。用这些格子依次裁剪旋转后的正方形
（四个半平面，如 Sutherland–Hodgman 方法）得到相交多边形，再用鞋带公式求其面积，
累加到该主人在这个格子中的份额。若某主人的份额比 1/2 大出 10⁻⁹ 以上，格子就归他。
被拥有的格子最多 3 600 个，计算瞬间完成。`O(n²)`。

易错点：

- 恰好一半不算超过一半：这样的格子归国家（样例中 45 度时被切开的格子）；
- α = 0 和 α = 90 时格子恰好对上格子，只是相接的边不能增加面积（测试 02、03）；
- 各语言都按 α · π / 180 计算弧度，让临界份额的舍入一致。

在 150 张随机地图上，输出与一个独立的已通过实现一致。
