# 1624. Уходи отсюда!

[Timus 1624](https://acm.timus.ru/problem.aspx?space=1&num=1624) · сложность 4804 · implementation

Оригинальная задача — SPbSU ITMO Contest, Петрозаводские сборы, зима 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Тюрьма — сетка W × H клеток (2 ≤ W · H ≤ 150) со стенами или дверями
между соседними клетками и стенами по всему краю. Два ослепших
разведчика начинают в неизвестных клетках (возможно, в одной) и по
очереди пытаются шагнуть на север, юг, восток или запад, сообщая
направление и удалась ли попытка; нечётные донесения — первого
разведчика. По K донесениям (1 ≤ K ≤ 10⁵) выведите первое донесение, после
которого обе позиции известны точно, или что данных недостаточно, или
первое донесение, противоречащее предыдущим (это важнее).

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

W, H и K, затем K донесений вида `E+` или `N-`.

## Выходные данные

Одно из трёх сообщений; при нехватке данных — без номера донесения.

## Примеры

### Пример 1

Ввод:

```
2 1 4
E+
W-
N-
S-
```

Вывод:

```
The scouts are safe at step number 2
```

### Пример 2

Ввод:

```
2 1 4
N-
W-
N-
S-
```

Вывод:

```
There is not enough data
```

### Пример 3

Ввод:

```
2 1 4
N-
W-
N-
S+
```

Вывод:

```
A mistake has been made at step number 4
```

## Решение

Каждый разведчик хранит свою позицию относительно своего неизвестного
старта, диапазон посещённых позиций и то, что он видел на каждом ребре
относительно старта: дверь или стену. Неизвестные — два старта. Старт
первого разведчика должен держать его посещённый диапазон внутри
тюрьмы, что даёт отрезок по каждой координате; так же для второго.

Разведчики встречают одни и те же стены только через сдвиг между их
стартами. Если первый видел дверь на относительном ребре e, а второй —
стену на относительном ребре f того же вида (или наоборот), то сдвиг
e − f невозможен. Такие сдвиги отмечаются в таблице из
(2H − 1) · (2W − 1) элементов.
Число оставшихся пар стартов — сумма по неотмеченным сдвигам, каждый
даёт прямоугольник стартов первого; счёт останавливается на 2. Значение
1 означает, что разведчики найдены, 0 — ошибку, как и донесения одного
разведчика о двери и стене на одном ребре.

Пересчёт нужен лишь при новом противоречии между разведчиками или расширении
диапазона. E — число донесений, открывающих новое ребро или расширяющих
диапазон; `E = O(W · H)`.

Подводные камни:

- об ошибке нужно сообщить, даже если разведчики уже найдены;
- размахи посещённых столбцов и строк разведчика должны быть меньше W и H (тест 05);
- разведчики могут стоять в одной клетке, не замечая друг друга.

Ответы совпадают с независимой принятой реализацией на 132 случайных
тюрьмах с правдивыми и искажёнными донесениями.
