# 1639. Шоколад 2

[Timus 1639](https://acm.timus.ru/problem.aspx?space=1&num=1639) · сложность 32 · games

Автор оригинальной задачи — Александр Пронченков (подготовка — Иван Бурмистров); осеннее первенство школьников, октябрь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Двое по очереди ломают шоколадку m × n: ход — взять любой кусок и
разломить его на два вдоль линий между дольками. Проигрывает тот, кто не
может сделать ход, потому что остались только куски 1 × 1. Должен ли
Карлсон ходить первым или вторым, чтобы наверняка выиграть?

## Входные данные

Два целых числа m и n (1 ≤ m, n ≤ 50).

## Выходные данные

`[:=[first]`, если выигрывает первый ход, иначе `[second]=:]`.

## Примеры

### Пример 1

Ввод:

```
2 4
```

Вывод:

```
[:=[first]
```

### Пример 2

Ввод:

```
1 3
```

Вывод:

```
[second]=:]
```

## Решение

Каждый ход превращает один кусок в два, то есть увеличивает число кусков
ровно на один. Игра начинается с одного куска и заканчивается с m · n,
поэтому длится всегда m · n − 1 ходов, что бы ни делали игроки. Первый
игрок делает последний ход и выигрывает ровно тогда, когда m · n − 1
нечётно, то есть когда m · n чётно. `O(1)`.

Подводные камни:

- стратегия ни на что не влияет, так что перебирать нечего;
- шоколадка 1 × 1 не допускает ни одного хода, и первый игрок сразу
  проигрывает (тест 03).
