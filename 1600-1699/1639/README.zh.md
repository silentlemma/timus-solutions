# 1639. 巧克力 2

[Timus 1639](https://acm.timus.ru/problem.aspx?space=1&num=1639) · 难度 32 · games

原题作者 Alexander Pronchenkov（由 Ivan Burmistrov 准备），出自 2008 年 10 月的乌拉尔国立大学中学生竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两人轮流掰一块 m × n 的巧克力：每一步拿起任意一块，沿格线把它掰成两块。只剩 1 × 1 的小块、无法
再走的一方输。Karlsson 应该先走还是后走才能稳赢？

## 输入

两个整数 m 和 n（1 ≤ m, n ≤ 50）。

## 输出

先走必胜时输出 `[:=[first]`，否则输出 `[second]=:]`。

## 样例

### 样例 1

输入：

```
2 4
```

输出：

```
[:=[first]
```

### 样例 2

输入：

```
1 3
```

输出：

```
[second]=:]
```

## 解法

每一步都把一块变成两块，也就是块数恰好加一。游戏从一块开始、以 m · n 块结束，所以无论双方怎么走，
总是恰好 m · n − 1 步。当且仅当 m · n − 1 为奇数，即 m · n 为偶数时，先手走最后一步并获胜。`O(1)`。

易错点：

- 策略毫无影响，所以没有什么需要搜索的；
- 1 × 1 的巧克力一步也走不了，先手立即输掉（测试 03）。

## 优化解法

优化的 Java 解法用 `System.in.read` 手工解析这两个数，而不是使用 `Scanner`：
372 KB，而不是 1608 KB，时间不变。它直接检查 `m · n` 的奇偶性，这与步数
`m · n − 1` 的奇偶性正好相反。
