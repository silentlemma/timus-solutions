# 1618. Arrays Printing

[Timus 1618](https://acm.timus.ru/problem.aspx?space=1&num=1618) · сложность 4085 · combinatorics

Оригинальная задача — SPbSU ITMO Contest, Петрозаводские сборы, зима 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Java-массив вида `new Object[a1][a2]…[an][0]` (n ≤ 100,
a1, …, an — положительные целые числа, a1 · … · an ≤ 512) печатается
через `Arrays.deepToString`, и получается строка S (не длиннее 10⁵ символов).
Элементы массива — ссылки, поэтому
один и тот же объект-массив может стоять в нескольких местах. Две
конфигурации одинаковы, если любые два пути по индексам ведут к одному
объекту в одной из них ровно тогда, когда и в другой. Посчитайте
конфигурации, которые печатаются как S, по модулю 10007.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Строка S.

## Выходные данные

Число конфигураций по модулю 10007.

## Примеры

### Пример 1

Ввод:

```
[[], []]
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
[[[[]]]]
```

Вывод:

```
1
```

### Пример 3

Ввод:

```
[[[]], [[]]]
```

Вывод:

```
3
```

## Решение

Разбор скобок даёт размеры a1, …, an. Считаем снизу. m ссылок на
пустые массивы можно как угодно сгруппировать в объекты: это разбиение
множества, B(m) способов (числа Белла). Уровнем выше m ссылок на массивы
ширины w сначала делятся на k различных объектов, S(m, k) способами
(числа Стирлинга второго рода); эти k объектов содержат k · w ссылок на
следующий уровень, конфигурации которых считаются совместно:

f(m) = Σₖ S(m, k) · g(k · w),

где g считает уровень ниже. Различные объекты могут хранить одни и те же
ссылки, поэтому нижний уровень свободен. Корень — один массив с a1
ссылками, так что ответ — f(a1) на верхнем уровне. На каждом непустом
уровне m не превосходит ни 512 / w, ни числа позиций на этой глубине.
`O(|S| + n · 512²)`.

Подводные камни:

- одиночный `[]` не содержит ссылок и даёт ровно одну конфигурацию
  (тест 04);
- два массива первого примера могут быть одним объектом, а могут и не
  быть: 2;
- числа быстро растут и берутся по модулю 10007 начиная с таблицы
  Стирлинга.

Ответы совпадают с независимой принятой реализацией на 100 случайных
формах.
