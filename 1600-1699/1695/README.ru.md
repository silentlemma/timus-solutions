# 1695. Работа для роботов

## Задача

Каждый день на работу выходит непустая группа роботов, попарно
дружащих между собой, и группы не могут повторяться. По графу дружбы n
роботов найти первый день, когда новой группы не остаётся.

## Входные данные

n (1 ≤ n ≤ 50), затем матрица дружбы n × n из нулей и единиц,
симметричная, с нулями на диагонали.

## Выходные данные

Номер этого дня.

## Примеры

### Пример 1

Ввод:

```
6
011100
101100
110100
111000
000001
000010
```

Вывод:

```
19
```

## Решение

Рабочая группа — клика графа дружбы, то есть независимое множество
графа «не дружат». Каждая непустая группа занимает один день, так что
ответ — число непустых клик плюс один, а это число независимых
множеств графа «не дружат» с учётом пустого.

Независимые множества набора вершин M считаем рекурсивно:

- если M распадается на несколько связных частей, их количества
  перемножаются;
- если любые две вершины M — враги, множества — пустое и |M|
  одиночных вершин: |M| + 1;
- если ни у одной вершины нет больше двух врагов, M — путь или цикл с
  фибоначчиевыми количествами: P(s) = P(s − 1) + P(s − 2) для пути и
  P(s − 1) + P(s − 3) для цикла;
- иначе берём вершину v с наибольшим числом врагов, хотя бы тремя:
  count(M) = count(M − v) + count(M − v − враги v).

Ветвление только по вершинам степени не меньше трёх держит рекурсию
маленькой, а запоминание по маске вершин убирает повторы. Ответ
доходит до 2⁵⁰, когда все роботы дружат, и помещается в 64 бита.

Подводные камни:

- пустая группа — не рабочий день, но день ржавления на единицу больше
  числа групп, поэтому учёт пустого множества сразу даёт ответ;
- все дружат — 2⁵⁰ (тест 03), никто не дружит — n + 1 (тест 04);
- цикл врагов требует своей формулы (тест 07).

Ответы совпадают с перебором всех подмножеств на маленьких графах и с
независимой принятой реализацией на случайных, разреженных и
регулярных графах из 50 роботов.
