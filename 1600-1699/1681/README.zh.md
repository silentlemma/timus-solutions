# 1681. 熊大哥的果园

[Timus 1681](https://acm.timus.ru/problem.aspx?space=1&num=1681) · 难度 3703 · geometry

原题作者 Pavel Egorov，出自 2009 年 2 月 28 日第十届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

果园是由 n 根柱子构成的严格凸多边形，按逆时针给出。每根柱子都向逆时针方向第 k 根柱子拉一根绳子。
兔子翻过围栏进来，且从不跨越绳子。求兔子到不了的面积占果园面积的比例。

## 输入

n 和 k（3 ≤ n ≤ 300；1 ≤ k < n），然后是 n 根柱子的整数坐标，绝对值不超过 10000。

## 输出

保住的面积与总面积之比，误差不超过 10⁻⁴。

## 样例

### 样例 1

输入：

```
5 3
0 0
20 0
20 20
10 30
0 20
```

输出：

```
0.466666667
```

### 样例 2

输入：

```
6 2
0 2
-2 1
-2 -1
0 -2
2 -1
2 1
```

输出：

```
0.666666667
```

## 解法

k 和 n − k 给出的是同一组弦，所以令 k = min(k, n − k)。当 k = 1 时所有绳子都沿着围栏，
兔子根本进不来：答案为 1。

否则每根绳子都是把果园一分为二的弦，所以两点在同一块中当且仅当没有绳子把它们分开，
每一块都是果园与每根绳子的一个半平面之交。兔子能到达的恰好是含有一段围栏的那些块。
边 i（从柱子 i 到柱子 i + 1）旁边的块，就是对每根绳子都裁到含有该边中点的半平面后的果园。
两条边不会共用一块：从柱子 i + 1 − k 和 i 出发的绳子都紧挨边 i，它们一起把边 i 与其他所有边隔开。
因此答案是 1 − Σ 面积(边 i 的块) / 总面积。

只需应用从边 i 上方经过的 k 根绳子，即从柱子 i + 1 − k, …, i 出发的绳子。
对任何其他绳子，果园位于边 i 一侧的部分是边 i 周围连续 n − k + 1 根柱子的凸包，
而由于 2k ≤ n，这些柱子包含某根经过边 i 的绳子的全部 k + 1 根柱子，这根绳子已经切得至少一样深。

用半平面裁剪凸多边形的代价与其大小成线性。先用从边两端出发的两根绳子裁剪，只剩一个小三角形，
再应用其余的绳子。`O(n² + n · k · s)`，其中 s 是一块的大小，只有几个顶点。

注意事项：

- k = 1 和 k = n − 1 的答案是 1 而不是 0：绳子就是围栏本身；
- 只在柱子处碰到围栏的块（比如五角星的尖角，测试 05）是保住的；
- 当 2k = n 时每根绳子出现两次，没有影响。

答案与在 500 个随机多边形上用全部 n 根绳子裁剪的结果一致，
也与一个独立的已通过实现在接近圆形和不规则的随机多边形上的结果一致。
