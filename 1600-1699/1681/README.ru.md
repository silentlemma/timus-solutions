# 1681. Сад-огород

[Timus 1681](https://acm.timus.ru/problem.aspx?space=1&num=1681) · сложность 3537 · geometry

Автор оригинальной задачи — Павел Егоров; X открытое личное первенство УрГУ, 28 февраля 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Сад — строго выпуклый многоугольник из n столбов, заданных против
часовой стрелки. От каждого столба натянута верёвка к столбу,
отстоящему на k шагов дальше против часовой стрелки. Кролик залезает
через забор и никогда не пересекает верёвки. Найти долю площади сада,
до которой он не может добраться.

## Входные данные

n и k (3 ≤ n ≤ 300; 1 ≤ k < n), затем n столбов — целые координаты,
по модулю не больше 10000.

## Выходные данные

Отношение спасённой площади ко всей площади с погрешностью не больше
10⁻⁴.

## Примеры

### Пример 1

Ввод:

```
5 3
0 0
20 0
20 20
10 30
0 20
```

Вывод:

```
0.466666667
```

### Пример 2

Ввод:

```
6 2
0 2
-2 1
-2 -1
0 -2
2 -1
2 1
```

Вывод:

```
0.666666667
```

## Решение

Верёвки для k и для n − k — одни и те же хорды, поэтому положим
k = min(k, n − k). При k = 1 все верёвки идут вдоль забора, и кролик
вообще не может попасть внутрь: ответ 1.

Иначе каждая верёвка — хорда, разрезающая сад на две части, поэтому две
точки лежат в одном куске ровно тогда, когда их не разделяет ни одна
верёвка, и каждый кусок — это сад, пересечённый с одной полуплоскостью
на каждую верёвку. Кролик попадает ровно в те куски, которые содержат
отрезок забора. Кусок у стороны i (от столба i до столба i + 1) — это
сад, обрезанный для каждой верёвки по полуплоскости, где лежит
середина стороны. Двум сторонам один кусок не достаётся: верёвки от
столбов i + 1 − k и i обе ограничивают сторону i и вместе отделяют её
от любой другой стороны. Значит, ответ — 1 − Σ площадь(кусок стороны i) / площадь.

Достаточно применить только k верёвок, проходящих над стороной i, — от
столбов i + 1 − k, …, i. Часть сада со стороны стороны i от любой
другой верёвки — выпуклая оболочка n − k + 1 подряд идущих столбов
вокруг стороны i, а поскольку 2k ≤ n, среди них есть все k + 1
столбов какой-то верёвки над стороной i. Эта верёвка уже режет не
меньше.

Обрезка выпуклого многоугольника полуплоскостью линейна по его
размеру. Сначала применяются две верёвки от концов стороны, после них
остаётся маленький треугольник, затем остальные.
`O(n² + n · k · s)`, где s — максимальный размер куска после первых двух обрезок.

Подводные камни:

- k = 1 и k = n − 1 дают 1, а не 0: верёвки совпадают с забором;
- кусок, который касается забора только в столбе, как луч пентаграммы
  (тест 05), спасён;
- при 2k = n каждая верёвка встречается дважды, это не мешает.

Ответы совпадают с обрезкой всеми n верёвками на 500 случайных
многоугольниках и с независимой принятой реализацией на случайных
многоугольниках, близких к окружности и неправильных.
