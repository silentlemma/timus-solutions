# 1686. Фотоэлектрический звездолёт

[Timus 1686](https://acm.timus.ru/problem.aspx?space=1&num=1686) · сложность 1491 · geometry

Автор оригинальной задачи — Павел Атнашев; X открытое личное первенство УрГУ, 28 февраля 2009 года.

## Задача

Звездолёт-тетраэдр обшит солнечными батареями. Каждая звезда светит с
заданного направления с интенсивностью, равной длине вектора
направления; квадратный метр, освещённый с интенсивностью I под углом
падения α, даёт I · cos α ватт. Найти суммарную мощность, удвоенную,
как того требует сюжет.

## Входные данные

Четыре вершины (целые, по модулю не больше 100, не в одной плоскости),
затем n (1 ≤ n ≤ 10) и n векторов на звёзды — целые, длиной от 0 до
2500, с различными направлениями.

## Выходные данные

Удвоенная мощность с погрешностью не больше 10⁻⁵.

## Примеры

### Пример 1

Ввод:

```
0 -1 0
0 1 0
0 0 2
1 0 0
2
0 0 -1358
21 0 0
```

Вывод:

```
2800.00000
```

## Решение

Тетраэдр выпуклый, поэтому грани не затеняют друг друга, и грань
освещена звездой ровно тогда, когда её внешняя нормаль смотрит на
звезду. Грань с единичной внешней нормалью n̂ и площадью A получает от
вектора звезды d мощность A · max(0, n̂ · d). Вместо этого возьмём
векторное произведение N двух рёбер грани, направленное от четвёртой
вершины: это внешняя нормаль длины 2A, и грань даёт max(0, N · d) / 2.
Удвоение сокращает половину, и ответ — целое число Σ max(0, N · d) по
четырём граням и всем звёздам, выведенное с пятью нулями после точки.
`O(n)`.

Подводные камни:

- нормаль каждой грани ориентируется по противоположной вершине:
  порядок вершин во входе ничего не говорит об ориентации;
- звезда в плоскости грани ничего этой грани не даёт (тест 03).

Ответы совпадают с независимой принятой реализацией, которая
проецирует тетраэдр на плоскость, перпендикулярную каждой звезде, и
берёт площадь силуэта.
