# 1686. 光伏星舰

[Timus 1686](https://acm.timus.ru/problem.aspx?space=1&num=1686) · 难度 1491 · geometry

原题作者 Pavel Atnashev，出自 2009 年 2 月 28 日第十届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一艘四面体星舰表面覆盖着太阳能电池板。每颗恒星从给定方向照射，强度等于方向向量的长度；
以强度 I、入射角 α 照射的一平方米产生 I · cos α 瓦。按故事要求，求总功率的两倍。

## 输入

四个顶点（绝对值不超过 100 的整数，不共面），然后是 n（1 ≤ n ≤ 10）和 n 个指向恒星的整数向量，
长度在 0 到 2500 之间且方向各不相同。

## 输出

两倍的功率，误差不超过 10⁻⁵。

## 样例

### 样例 1

输入：

```
0 -1 0
0 1 0
0 0 2
1 0 0
2
0 0 -1358
21 0 0
```

输出：

```
2800.00000
```

## 解法

四面体是凸的，所以各面互不遮挡，一个面被某颗恒星照亮当且仅当它的外法向朝向该恒星。
单位外法向为 n̂、面积为 A 的面从恒星向量 d 得到 A · max(0, n̂ · d)。
改用该面两条边的叉积 N，并让它背离第四个顶点：它是长度为 2A 的外法向，所以该面贡献 max(0, N · d) / 2。
翻倍正好抵消一半，答案就是对四个面和所有恒星求和的整数 Σ max(0, N · d)，输出时带五位零小数。`O(n)`。

注意事项：

- 每个法向都要按对面的顶点定向：输入中顶点的顺序与定向无关；
- 位于某个面所在平面内的恒星对该面没有贡献（测试 03）。

答案与一个独立的已通过实现一致，后者把四面体投影到垂直于每颗恒星方向的平面上并计算轮廓面积。
