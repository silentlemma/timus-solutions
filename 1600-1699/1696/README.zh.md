# 1696. 机器人的工资

[Timus 1696](https://acm.timus.ru/problem.aspx?space=1&num=1696) · 难度 860 · dp

原题作者 Igor Chevdar，出自 2009 年 2 月彼得罗扎沃茨克冬季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

等级为 1..n 的 n 个机器人每月各领 1 到 k 的工资。若存在机器人 a、b、c，从 a 到 c 等级递减而工资递增，
这种发放就被禁止；发放方式不能重复。一年中的月份编号为 1..p。会计在哪个月用尽所有发放方式？

## 输入

n, k, p（1 ≤ n ≤ 1000；1 ≤ k ≤ 200；2 ≤ p ≤ 10⁹）。

## 输出

那个月在当年中的编号。

## 样例

### 样例 1

输入：

```
3 3 20
```

输出：

```
7
```

## 解法

按等级顺序写出工资，被禁止的模式就是长度为三的严格递减子序列。若允许的发放方式有 C 种，
会计在从头数起的第 C + 1 个月生锈，所以答案是 (C mod p) + 1。

逐个等级计数。状态为 a（目前最大的工资）和 b（前面有更大工资的最大工资，没有则为 0）。
新工资 z 当且仅当 z ≥ b 时允许，因为 z < b 会构成递减三元组。若 z < a，状态变为 (a, z)，否则变为 (z, b)。
两种转移都是前缀和：新的 (a, c) 沿行收集所有 b ≤ c 的旧 (a, b)，新的 (z, b) 沿列收集所有 a ≤ z 的旧 (a, b)。
总计 `O(n · k²)`，对 p 取模。

注意事项：

- 月份是 (C mod p) + 1，所以 C 是 p 的倍数时为第 1 个月（测试 10）；
- 相等的工资不会构成被禁止的三元组，只有严格递减的才会；
- 计数从一开始就对 p 取模，因为 C 本身大得惊人。

Python 解答以 PyPy 提交：本地 CPython 在 n = 1000、k = 200 时约需 3 秒，超过 2 秒的时限。

答案与 n ≤ 6、k ≤ 5 时对所有工资序列的计数一致，也与一个独立的已通过实现一致。
