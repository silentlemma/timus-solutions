# 1619. Старший брат

[Timus 1619](https://acm.timus.ru/problem.aspx?space=1&num=1619) · сложность 717 · math

Оригинальная задача — SPbSU ITMO Contest, Петрозаводские сборы, зима 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

За год старший брат получает K монет по одному евро, а младший — M, по
одной монете в равновероятном случайном порядке. Старший злится, если в
какой-то момент у младшего денег больше. Для каждого из N случаев
(N ≤ 2004, 0 ≤ K, M ≤ 10⁴) выведите вероятность того, что этого не
случится, с погрешностью не больше 10⁻⁶.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк `K M`.

## Выходные данные

Вероятности, по одной в строке.

## Примеры

### Пример 1

Ввод:

```
3
1 0
0 1
1 1
```

Вывод:

```
1
0
0.5
```

## Решение

Порядки — это пути по решётке из K шагов одного вида и M другого, их
C(K + M, M). Если M > K, младший в конце впереди, и ответ 0. Иначе
плохие пути — те, на которых в какой-то момент младший на монету
впереди; отражение пути до первого плохого момента включительно
переводит его в путь с K + 1 и M − 1 монетами, взаимно однозначно,
поэтому плохих путей C(K + M, M − 1). Вероятность равна

1 − C(K + M, M − 1) / C(K + M, M) = 1 − M / (K + 1) = (K − M + 1) / (K + 1).

`O(1)` на случай.

Подводные камни:

- равные суммы допустимы: злит только строгое превосходство, поэтому
  K = M = 1 даёт 1/2, а не 0 (пример);
- K = M = 0 даёт 1, а M > K — ровно 0 (тест 03).

Формула совпадает с перебором всех порядков для всех K, M ≤ 8.
