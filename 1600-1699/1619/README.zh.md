# 1619. 哥哥

[Timus 1619](https://acm.timus.ru/problem.aspx?space=1&num=1619) · 难度 717 · math

原题出自 2008 年冬季彼得罗扎沃茨克集训的 SPbSU ITMO Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一年里哥哥共得到 K 枚一欧元硬币，弟弟得到 M 枚，每次一枚，顺序均匀随机。若某一时刻
弟弟的钱比哥哥多，哥哥就会生气。对 N 个情形（N ≤ 2004，0 ≤ K, M ≤ 10⁴）分别输出
这种情况始终不发生的概率，误差不超过 10⁻⁶。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N 行 `K M`。

## 输出

各个概率，每行一个。

## 样例

### 样例 1

输入：

```
3
1 0
0 1
1 1
```

输出：

```
1
0
0.5
```

## 解法

所有顺序对应由 K 步一种、M 步另一种组成的格路，共 C(K + M, M) 条。若 M > K，弟弟
最后领先，答案为 0。否则坏路径是某一时刻弟弟领先一枚的路径；把这样的路径从起点到第一次变坏
为止的部分反射，就一一对应到有 K + 1 和 M − 1 枚硬币的路径，所以坏路径有
C(K + M, M − 1) 条。概率为

1 − C(K + M, M − 1) / C(K + M, M) = 1 − M / (K + 1) = (K − M + 1) / (K + 1)。

每个情形 `O(1)`。

易错点：

- 金额相等没关系：只有严格领先才会让哥哥生气，所以 K = M = 1 得 1/2 而不是 0（样例）；
- K = M = 0 得 1，M > K 恰好得 0（测试 03）。

对所有 K, M ≤ 8，公式与枚举全部顺序的结果一致。
