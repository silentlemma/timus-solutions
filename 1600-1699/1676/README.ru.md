# 1676. Смертельная битва

[Timus 1676](https://acm.timus.ru/problem.aspx?space=1&num=1676) · сложность 1730 · matching

Автор оригинальной задачи — Магаз Асанов (подготовка — Александр Ипатов); Ural SU Contest, Петрозаводские летние сборы, август 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждый из N монстров должен драться с разным из M бойцов Земли, и бойцы
должны выиграть все бои; матрица из нулей и единиц говорит, какой боец
побеждает какого монстра. Для каждой пары (монстр i, боец j) нужно
вывести 1, если выбор этой пары на первый бой делает полное выигрышное
распределение невозможным, и 0 иначе.

## Входные данные

N и M (1 ≤ N ≤ 300, N ≤ M ≤ 1500), затем N строк по M цифр.

## Выходные данные

Матрица ответов N × M.

## Примеры

### Пример 1

Ввод:

```
4 4
1111
1000
1111
1111
```

Вывод:

```
1000
0111
1000
1000
```

### Пример 2

Ввод:

```
4 5
10000
10000
10000
10000
```

Вывод:

```
11111
11111
11111
11111
```

## Решение

Пара подходит ровно тогда, когда входит в какое-нибудь паросочетание
всех монстров с побеждающими их бойцами. Алгоритм Куна находит одно
такое паросочетание; если для какого-то монстра это не удаётся, все пары
невозможны.

Иначе монстр i оставляет своего бойца m(i) и может взять побеждающего
его бойца j ещё двумя способами:

- j свободен, и i просто переходит к нему;
- j принадлежит монстру k, который берёт другого побеждающего его
  бойца: того, кого отдаёт i (цикл замыкается), свободного или бойца
  третьего монстра, который тогда должен перейти дальше так же.

Со стрелкой k → k₂, когда k может взять бойца k₂, это значит: k
достигает i или k достигает монстра, которого побеждает какой-нибудь
свободный боец (сам k тоже считается). Достижимость среди N монстров
даёт поиск из каждого из них, так что всё вместе — `O(N² · M)`.

Подводные камни:

- боец, никого не побеждающий, или монстр, которого никто не побеждает,
  дают строки и столбцы из единиц (тесты 04 и 05);
- если полного распределения нет, ответ — одни единицы, даже для пар,
  где боец побеждает (пример 2);
- строки — цифры без пробелов.

Ответы совпадают с перебором всех полных распределений на 600 случайных
малых входах и с независимой принятой реализацией на больших.

## Особенности языков

- Python хранит каждую строку одним длинным целым и ведёт поиск Куна с
  непосещёнными бойцами в виде битового множества, так что следующий
  кандидат берётся сразу из adj[u] & unseen.
