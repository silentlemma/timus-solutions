# 1676. 真人快打

[Timus 1676](https://acm.timus.ru/problem.aspx?space=1&num=1676) · 难度 1730 · matching

原题作者 Magaz Asanov（由 Alexander Ipatov 准备），出自 2008 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 个怪物要分别与 M 名地球战士中互不相同的一人交战，战士必须赢下每一场；0/1 矩阵给出哪名战士能打败哪个怪物。
对每一对（怪物 i，战士 j），若把这一对选作第一场会使完整的获胜分配不可能，输出 1，否则输出 0。

## 输入

N 和 M（1 ≤ N ≤ 300，N ≤ M ≤ 1500），然后是 N 行、每行 M 个数字。

## 输出

N × M 的答案矩阵。

## 样例

### 样例 1

输入：

```
4 4
1111
1000
1111
1111
```

输出：

```
1000
0111
1000
1000
```

### 样例 2

输入：

```
4 5
10000
10000
10000
10000
```

输出：

```
11111
11111
11111
11111
```

## 解法

一对可行当且仅当它属于某个把所有怪物匹配给能打败它们的战士的匹配。Kuhn 算法找出一个这样的匹配；如果某个怪物
匹配失败，所有的对都不可行。

否则怪物 i 保留自己的战士 m(i)，还可以通过另外两种方式得到能打败它的战士 j：

- j 是空闲的，i 直接换过去；
- j 属于怪物 k，k 改用另一个能打败它的战士：i 让出的那个（形成环）、一个空闲的，或第三个怪物的战士，而那个怪物
  又必须同样换走。

当 k 能拿走 k₂ 的战士时连一条 k → k₂ 的边，条件就是：k 能到达 i，或者 k 能到达某个被空闲战士打败的怪物（包括
k 自己）。N 个怪物之间的可达性由从每个怪物出发的搜索得到，总计 `O(N² · M)`。

易错点：

- 谁都打不过的战士或者谁都打不过的怪物会产生全为 1 的行和列（测试 04 和 05）；
- 没有完整分配时答案全为 1，即使是战士能赢的对（样例 2）；
- 每行是不带空格的数字。

在 600 个随机小输入上，答案与穷举所有完整分配的结果一致；在大输入上与一个独立的已通过实现一致。

## 各语言说明

- Python 把每一行存成一个大整数，并把未访问的战士作为位集进行 Kuhn 搜索，所以下一个候选直接从 adj[u] & unseen
  中取得。
