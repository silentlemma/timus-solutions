# 1635. 记忆术与回文

[Timus 1635](https://acm.timus.ru/problem.aspx?space=1&num=1635) · 难度 202 · dp

原题作者 Igor Chevdar，出自第十三届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把一个由小写字母组成的字符串切成尽量少的回文串，输出个数以及按顺序排列的各段。任何最优切分
都可以。

## 输入

一个非空字符串，只含小写拉丁字母，长度不超过 4000。

## 输出

最少的回文个数，然后是一个最优切分的各段，以空格分隔。

## 样例

### 样例 1

输入：

```
pasoib
```

输出：

```
6
p a s o i b
```

### 样例 2

输入：

```
zzzqxx
```

输出：

```
3
zzz q xx
```

### 样例 3

输入：

```
wasitacatisaw
```

输出：

```
1
wasitacatisaw
```

## 解法

令 `d[j]` 为前 `j` 个字母的最少回文块数，`d[0]=0`。每个回文
`s[l..r]` 给出转移 `d[r+1]=min(d[r+1],d[l]+1)`，记住起点 `l`，
从末尾恢复并反转各块。任何划分都有最后一个回文块，因此转移完整。

C++、Go、Java、Rust 基础版按从左到右的 `2n−1` 个奇偶中心扩展回文。
在 `l` 之前结束的每个块，其中心都严格小于 `l`；当前回文的中心不小于
`l`，故使用的 `d[l]` 已最终确定。最坏 `O(n²)` 时间、`O(n)` 空间，
包括恢复；不需要平方大小的回文矩阵。

现有 Python 基础版把回文起点存为整数位集。右端点为 `i` 时，将上一步起点
右移一位，与字母 `s[i]` 的所有位置相交，再加单字母起点 `i`；末两字母
相同则另加 `i−1`。这正是内部回文递推，并补齐长度一、二的基本情况。

添加一个字母使最少块数最多变化一。上界来自添加单字母；下界来自删去最优
划分最后回文的末字母：剩余部分是首字母加回文内部，最多把一块变成两块。
因此 `d[i+1]` 是 `d[i]−1,d[i],d[i]+1` 之一。`level[v]` 存已处理且
最少块数为 `v` 的前缀长度；依次把当前起点与 `d[i]−2,d[i]−1` 层相交。
若都为空，加单字母即最优；非空交集的最低位给出合法前驱。

设大整数每个存储分块有 `w` 位，Python 需要 `O(n²/w+n)` 分块操作。
各层掩码总共可能占 `O(n²)` 位，另有 `O(n)` 个索引和对象：即使只有一个
置位，仍要存到最高位的位置。不能套用原生 DP 的线性空间，也不假定 `w=64`。

## 优化解法

新 C++ 保留同一中心扩展 DP，故使用 `_optimized`。先检查整个字符串
是否回文；若是，一块就是已证明的最优解，`O(n)` 返回。其他输入仍为最坏
`O(n²)`。`n≤4000` 时，块数、初始哨兵 `n+1`、前缀索引及恢复端点都能
放入无符号 16 位单元。静态数组保存输入、最优值、前驱和端点；用 `fwrite`
直接输出片段，不建立子串对象和字符串向量，stdio 替代 iostream。
整个 Accepted 程序内存为 140 KB 对原版 676 KB，节省 79.3%；两版时间均为
0.015 s，不宣称测得加速。两版都保留。

## 评测方式

答案检查需验证块数、每块回文、拼接等于原串，以及块数最少；不同最优
划分均合法。实际新 C++ 通过了 693 个独立额外输入：长度一至八的全部 510 个
非空二元串、180 个随机串、三个长度 4000 且已证明最优值为 1、2、4000 的串。
小串答案由逐个反转后缀的独立 DP 生成，不用中心扩展。大串为同一字母、交替
`ab`、重复 `abcd`；最后一种没有长度二或三的回文，故也没有更长回文。
另外通过 Docker 中全部 15 个仓库输入，并有对应精确源码的 Accepted。
693 次是实际 C++ 执行，不是新 Python 候选执行。
