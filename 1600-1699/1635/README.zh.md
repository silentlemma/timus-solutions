# 1635. 记忆术与回文

[Timus 1635](https://acm.timus.ru/problem.aspx?space=1&num=1635) · 难度 202 · dp

原题作者 Igor Chevdar，出自第十三届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把一个由小写字母组成的字符串切成尽量少的回文串，输出个数以及按顺序排列的各段。任何最优切分
都可以。

## 输入

一个非空字符串，只含小写拉丁字母，长度不超过 4000。

## 输出

最少的回文个数，然后是一个最优切分的各段，以空格分隔。

## 样例

### 样例 1

输入：

```
pasoib
```

输出：

```
6
p a s o i b
```

### 样例 2

输入：

```
zzzqxx
```

输出：

```
3
zzz q xx
```

### 样例 3

输入：

```
wasitacatisaw
```

输出：

```
1
wasitacatisaw
```

## 解法

设 dp[j] 为长度为 j 的前缀最少需要的回文段数；则对所有回文 s[l..r] 有
dp[r + 1] = min dp[l] + 1，记下取到最小值的 l 就能还原各段。

C++、Go、Java 和 Rust 从左到右围绕 2n − 1 个中心逐一扩展来枚举回文。这个顺序是安全的：回文
s[l..r] 的中心不在 l 左边，而每个在 l − 1 结束的回文的中心都在 l 左边，所以 dp[l] 已经确定。
最坏情况（同一个字母重复）`O(n²)` 时间，`O(n)` 内存。

Python 无法逐个处理八百万个回文，所以改用位集。以 i 结尾的回文 s[j..i] 的起点 j 由 i − 1 的
起点得到：整体下移一位，只保留字母为 s[i] 的位置，再加上 i 本身，以及在 s[i − 1] = s[i] 时
加上 i − 1。此外 dp 每步最多变化 1（去掉最后一个字母后，最后一段可拆成它的首字母和一个回文），
所以 dp[i + 1] 只能是 dp[i] − 1、dp[i] 或 dp[i] + 1。对每个 dp 值维护一个位置位集，两次“与”
运算就能判定，最低的公共位给出这一段。`O(n² / 64)` 次字运算。

易错点：

- 先取最长回文并非最优：abaab 需要两段 a 和 baab，而不是 aba、a、b（测试 06）；
- 存全部 n² 个回文标志的矩阵按字节要 16 MB；中心扩展完全不需要它。

检查器接受任何最优切分；在 100 个随机字符串上，答案的段数与一个独立的已通过实现一致。
