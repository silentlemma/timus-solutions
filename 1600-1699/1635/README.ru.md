# 1635. Мнемоника и палиндромы

## Задача

Разбить строку из строчных букв на наименьшее число палиндромов и
вывести их количество и сами куски по порядку. Подходит любое
оптимальное разбиение.

## Входные данные

Одна непустая строка из строчных латинских букв длиной не больше 4000.

## Выходные данные

Наименьшее число палиндромов, затем куски оптимального разбиения через
пробел.

## Примеры

### Пример 1

Ввод:

```
pasoib
```

Вывод:

```
6
p a s o i b
```

### Пример 2

Ввод:

```
zzzqxx
```

Вывод:

```
3
zzz q xx
```

### Пример 3

Ввод:

```
wasitacatisaw
```

Вывод:

```
1
wasitacatisaw
```

## Решение

Пусть dp[j] — наименьшее число палиндромов для префикса длины j; тогда
dp[r + 1] = min dp[l] + 1 по палиндромам s[l..r], а запомненное l
минимума восстанавливает куски.

C++, Go, Java и Rust перебирают палиндромы, расширяясь вокруг каждого из
2n − 1 центров слева направо. Такой порядок безопасен: центр палиндрома
s[l..r] не левее l, а у каждого палиндрома, кончающегося в l − 1, центр
левее l, так что dp[l] уже окончательно. `O(n²)` времени в худшем случае
(одна повторяющаяся буква), `O(n)` памяти.

Python не может позволить себе восемь миллионов палиндромов по одному,
поэтому работает с битовыми множествами. Начала j палиндромов s[j..i]
получаются из начал для i − 1: сдвинуть их на одну позицию вниз и
оставить позиции, где стоит s[i], затем добавить само i и i − 1, если
s[i − 1] = s[i]. Кроме того, dp меняется за шаг не больше чем на
единицу (без последней буквы последний кусок распадается на свою первую
букву и палиндром), так что dp[i + 1] равно dp[i] − 1, dp[i] или
dp[i] + 1. С битовым множеством позиций для каждого значения dp это
решают две операции «и», а младший общий бит указывает кусок.
`O(n² / 64)` операций над словами.

Подводные камни:

- брать сначала самый длинный палиндром неоптимально: abaab требует
  двух кусков, a и baab, а не aba, a, b (тест 06);
- матрица всех n² флагов палиндромности занимает 16 МБ в байтах;
  расширению от центров она не нужна.

Чекер принимает любое оптимальное разбиение; ответы совпадают по
количеству с независимой принятой реализацией на 100 случайных строках.
