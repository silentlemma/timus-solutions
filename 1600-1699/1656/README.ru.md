# 1656. Войско Тридевятого царства

[Timus 1656](https://acm.timus.ru/problem.aspx?space=1&num=1656) · сложность 206 · constructive

Автор оригинальной задачи — Владимир Яковлев (идея — Магаз Асанов); четвертьфинал Восточного подрегиона NEERC 2008.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно расставить n² солдат заданного роста в квадрат n × n так, чтобы в
каждой строке и каждом столбце самый высокий стоял в середине, а рост от
середины к обоим краям не возрастал.

## Входные данные

Нечётное n от 3 до 9, затем n² ростов от 170 до 200.

## Выходные данные

Квадрат — n строк по n ростов. Подходит любая правильная расстановка.

## Проверка

Проверяются размеры, исходное мультимножество роста и все требуемые неравенства монотонности от центра; принимается любая допустимая сетка.

## Примеры

### Пример 1

Ввод:

```
3
170
170
180
175
170
175
175
170
175
```

Вывод:

```
170 175 170
175 180 175
170 175 170
```

## Решение

Упорядочим клетки по паре (меньшее, большее) их расстояний от
центральной строки и центрального столбца и отдадим самых высоких солдат
клеткам с наименьшим рангом. В строке на расстоянии a от центра клетка на
расстоянии b имеет ранг (b, a), пока b < a, и (a, b) дальше: так или
иначе ранг растёт с ростом b, так что по каждую сторону от середины рост
к краю не увеличивается. Столбцы — то же по симметрии. Клетки с равным
рангом — зеркальные отражения и никогда не стоят по одну сторону одной
линии. `O(n² log n)`; стабильная сортировка в Go: `O(n² log² n)`.

Подводные камни:

- «не возрастал к краям» разрешает равный рост (тест 02);
- правильных расстановок много, поэтому чекер проверяет правила и набор
  ростов.

Квадраты программы проходят чекер на 90 случайных войсках.

## Оптимизированные решения

Ограниченные значения роста подсчитываются вместо сортировки координатных кортежей. Клетки меньшего манхэттенова расстояния от центра получают не меньший рост: каждый шаг наружу по строке или столбцу увеличивает расстояние, что доказывает ограничения. Каждая клетка заполняется один раз, одинаковые значения разрешены. Python разворачивает счётчики роста в байтовый массив и по префиксным смещениям слоёв выводит строки без полной сетки. Простое построение с сортировкой координат сохраняется.
