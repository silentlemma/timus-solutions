# 1661. Додекаэдр

[Timus 1661](https://acm.timus.ru/problem.aspx?space=1&num=1661) · сложность 3657 · combinatorics

Автор оригинальной задачи — Игорь Чевдарь; Ural SU Contest, Петрозаводские зимние сборы, январь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Тридцать стержней одинаковой длины, каждый своего цвета, становятся
рёбрами додекаэдра. Нужно посчитать, сколько разных додекаэдров можно
собрать, если отличающиеся лишь поворотом считаются одинаковыми.

## Входные данные

Тридцать целых чисел от 1 до 30 — цвета стержней.

## Выходные данные

Количество различных додекаэдров.

## Примеры

### Пример 1

Ввод:

```
1 1 2 2 2 2 2 2 2 2
2 2 2 2 2 2 2 2 2 2
2 2 2 2 2 2 2 2 2 2
```

Вывод:

```
11
```

## Решение

По лемме Бернсайда число раскрасок с точностью до поворота равно
среднему по 60 поворотам додекаэдра числу раскрасок, которые поворот
оставляет на месте. Поворот разбивает 30 рёбер на циклы, и раскраска
не меняется ровно тогда, когда каждый цикл одноцветный. Повороты бывают
четырёх видов:

- тождественный: 30 циклов длины 1;
- 24 поворота вокруг осей через центры противоположных граней: 6 циклов
  длины 5;
- 20 поворотов вокруг осей через противоположные вершины: 10 циклов
  длины 3;
- 15 поворотов на 180° вокруг осей через середины противоположных
  рёбер: эти 2 ребра остаются на месте, остальные 28 дают 14 циклов
  длины 2.

Если все циклы длины L, цвет c должен занять ровно count(c) / L циклов;
это невозможно, если L делит не все количества, а иначе даёт
мультиномиальный коэффициент (30 / L)! / ∏ (count(c) / L)!. Для поворота
на 180° сначала по порядку выбираются цвета двух неподвижных рёбер, а
остальное считается так же при L = 2. Сумма делится на 60. `O(C³)` для
C = 30 цветов.

Подводные камни:

- ответ доходит до 30! / 60, около 4,4 · 10³⁰ (тест 03), больше 64 бит;
  все промежуточные значения меньше 30! < 2¹²⁸, поэтому C++ и Rust
  используют 128-битные целые, а остальные — длинную арифметику;
- мультиномиальный коэффициент как произведение биномиальных, по одному
  точному множителю за раз, не требует чисел больше примерно 30 · 30!.

Типы циклов выше взяты из настоящей группы вращений, построенной по
координатам додекаэдра, и формула совпадает с полным перебором орбит на
малых раскрасках. Ответы также совпадают с независимой принятой
реализацией на случайных входах.
