# 1661. 正十二面体

[Timus 1661](https://acm.timus.ru/problem.aspx?space=1&num=1661) · 难度 3657 · combinatorics

原题作者 Igor Chevdar，出自 2008 年 1 月彼得罗扎沃茨克冬季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

三十根等长的棒，各有一种颜色，用作正十二面体的棱。求能做出多少种不同的正十二面体，仅相差一个旋转的视为相同。

## 输入

三十个 1 到 30 之间的整数，即各棒的颜色。

## 输出

不同正十二面体的个数。

## 样例

### 样例 1

输入：

```
1 1 2 2 2 2 2 2 2 2
2 2 2 2 2 2 2 2 2 2
2 2 2 2 2 2 2 2 2 2
```

输出：

```
11
```

## 解法

由 Burnside 引理，旋转意义下的着色数等于正十二面体 60 个旋转各自保持不变的着色数的平均值。一个旋转把 30 条棱分成
若干循环，着色不变当且仅当每个循环同色。旋转分为四类：

- 恒等：30 个长度为 1 的循环；
- 绕相对两面中心连线的 24 个旋转：6 个长度为 5 的循环；
- 绕相对两顶点连线的 20 个旋转：10 个长度为 3 的循环；
- 绕相对两棱中点连线的 15 个半周旋转：这 2 条棱不动，其余 28 条组成 14 个长度为 2 的循环。

若所有循环长度都是 L，颜色 c 必须恰好占 count(c) / L 个循环；只要 L 不整除某个数量就不可能，否则方案数为多项式
系数 (30 / L)! / ∏ (count(c) / L)!。对半周旋转，先按顺序给两条不动的棱选颜色，其余按 L = 2 同样计算。总和除以
60。颜色数 C = 30 时为 `O(C³)`。

易错点：

- 答案可达 30! / 60，约 4.4 · 10³⁰（测试 03），超过 64 位；所有中间值都小于 30! < 2¹²⁸，所以 C++ 和 Rust
  用 128 位整数，其余语言用大整数；
- 把多项式系数写成二项式系数之积、每次乘一个精确的因子，所需的数不超过约 30 · 30!。

上述循环类型来自由正十二面体坐标构造出的真实旋转群，公式在小规模着色上与暴力数轨道的结果一致。在随机输入上，答案
也与一个独立的已通过实现一致。
