# 1673. Допуск к экзамену

[Timus 1673](https://acm.timus.ru/problem.aspx?space=1&num=1673) · сложность 1171 · number_theory

Автор оригинальной задачи — Игорь Чевдарь; Ural SU Contest, Петрозаводские летние сборы, август 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N преподавателей проводят N² лабораторных: преподаватель t — работы с
номерами t, N + t, 2N + t, …. Студент j из N ходит ровно на работы с
номерами, кратными j, и допускается к экзамену, если побывал хотя бы на
одной работе каждого преподавателя. Допущено ровно K студентов; нужно
вывести наименьшее возможное N или 0, если такого нет.

## Входные данные

K (1 ≤ K ≤ 2·10⁹).

## Выходные данные

Наименьшее N или 0.

## Примеры

### Пример 1

Ввод:

```
8
```

Вывод:

```
15
```

### Пример 2

Ввод:

```
3
```

Вывод:

```
0
```

## Решение

Преподаватель t проводит работы с номерами, сравнимыми с t по модулю N. Студент j
посещает j, 2j, …, Nj, а они пробегают все кратные gcd(j, N) по модулю
N; это все остатки ровно тогда, когда gcd(j, N) = 1. Значит, K = φ(N) —
функция Эйлера, и нужно найти наименьшее N с φ(N) = K.

Для N = p₁^e₁ ⋯ p_r^e_r значение φ(N) = ∏ (pᵢ − 1) pᵢ^(eᵢ − 1). Каждое
pᵢ − 1 делит K, поэтому пробовать стоит только простые вида d + 1 для
делителей d числа K. У K ≤ 2·10⁹ не больше 1536 делителей; каждое d + 1
проверяется тестом Миллера–Рабина по основаниям 2, 3, 5, 7, который
точен ниже 3,2·10⁹.

Перебор с запоминанием берёт простые-кандидаты по возрастанию:
least(rest, i) — наименьшее произведение степеней простых начиная с i-го
с функцией Эйлера rest. Для каждого простого p начиная с i, у которого
(p − 1) | rest, пробуются p^e при e ≥ 1, пока (p − 1)p^(e − 1) делит rest, затем
рекурсия на остаток с более поздними простыми, и сохраняется наименьшее
произведение. Каждое состояние — делитель K и номер простого, ответ —
least(K, 0). Для D делителей и P простых-кандидатов время в среднем —
`O(√K + D · P² · log K)`; упорядоченная map в C++ добавляет множитель
`log(DP)` к стоимости поиска.

Подводные камни:

- K = 1 даёт N = 1: при одном преподавателе и одной работе единственный
  студент допущен (тест 03);
- нечётное K больше 1 никогда не бывает значением φ (тест 02), как и
  некоторые чётные, наименьшее из них 14 (тест 08);
- ответ может превышать 2³¹: φ(2 500 015 625) = 2·10⁹ (тест 06).

Ответы совпадают с наименьшим N из решета для функции Эйлера для всех K
до 300 и каждого седьмого K до 3000, а на больших K — с независимой
принятой реализацией.
