# 1648. 游艇

[Timus 1648](https://acm.timus.ru/problem.aspx?space=1&num=1648) · 难度 387 · greedy

原题作者 Alexey Samsonov，出自 2008 年 10 月的乌拉尔国立大学中学生竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

造船厂每月最多造 d 艘游艇。第 i 个月月底会来 aᵢ 位新晋亿万富翁，每人都要立刻买到游艇；买不到的人
就永远不来了。游艇可以提前造好，但每艘存放一个月要花一块金锭。求 n 个月内最多能卖出多少艘游艇，
以及卖出这么多时最少的存放费用。

## 输入

n 和 d（1 ≤ n ≤ 20000，1 ≤ d ≤ 100000），然后是 a₁ … aₙ（0 ≤ aᵢ ≤ 100000）。

## 输出

最多卖出的游艇数和最少的存放金锭数。

## 样例

### 样例 1

输入：

```
3 5
6 1 7
```

输出：

```
13 2
```

## 解法

销售：到第 i 个月底最多造出 i · d 艘，而第 i 个月的买家只在那时购买。能卖给的买家都卖是最优的，所以
累计销量为 Sᵢ = min(Sᵢ₋₁ + aᵢ, i · d)，答案是 Sₙ。尽早卖出同时也让每月底剩下的库存最少。

存放：在每月销量确定后，每艘游艇都尽可能晚地造。从最后一个月往前走：一个月要造它卖出的数量，加上
后面月份自己造不完的部分，但不超过 d；剩余的部分移到前一个月，每跨过一个月界就花一块金锭。这些转移
量之和就是最少的存放费用。`O(n)`。

销量最多为 20000 · 100000 = 2,000,000,000，可用 32 位有符号整数表示。
存放费用需要 64 位，可达约 n² · d / 2。

易错点：

- 某个月的买家不能留到以后再卖，所以该月销量受限于该月买家数和到那时已造出的数量（测试 03）；
- 买家集中在末尾会迫使长期存放（测试 04、05），超出 32 位整数（gen3）。

在 120 个随机测试上答案与一个独立的已通过实现一致，在小测试上与穷举搜索一致。
