# 1617. Ползуны

[Timus 1617](https://acm.timus.ru/problem.aspx?space=1&num=1617) · сложность 65 · implementation

Автор оригинальной задачи — Владимир Яковлев; XII чемпионат Урала по спортивному программированию, 29 марта 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В депо n колёсных пар (1 ≤ n ≤ 150), у каждой целый диаметр от 600 до
700 мм. Вагону нужны четыре колёсные пары одного диаметра. Сколько
вагонов можно оснастить?

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

n, затем n диаметров.

## Выходные данные

Число вагонов.

## Примеры

### Пример 1

Ввод:

```
9
689
690
690
689
689
690
689
688
688
```

Вывод:

```
1
```

## Решение

Посчитаем пары каждого диаметра. Диаметр, у которого c пар, оснащает
⌊c / 4⌋ вагонов, а разные диаметры друг на друга не влияют, поэтому
ответ — сумма по всем диаметрам. `O(n)`.

Подводные камни:

- оставшиеся пары разных диаметров нельзя объединять (тест 01);
- восемь пар одного размера оснащают два вагона, а не один (тест 03).

## Оптимизированные решения

Оптимизированное решение на Java читает ввод блоками по 1 КБ и разбирает
его вручную вместо `Scanner`, а диаметры, от 600 до 700, считает в
обычном массиве из 101 счётчика со сдвигом на 600: 0.109 с вместо
0.140 с и 336 КБ вместо 1680 КБ.
