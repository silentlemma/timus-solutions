# 1607. Такси

[Timus 1607](https://acm.timus.ru/problem.aspx?space=1&num=1607) · сложность 46 · implementation

Автор оригинальной задачи — Денис Мусин; IX открытое личное первенство УрГУ, 1 марта 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Петя торгуется с таксистом. Петя начинает с a и каждый раз повышает
цену на b; таксист начинает с c и каждый раз снижает на d; говорят по
очереди, первым Петя. Никто не называет цену за чужой ценой: таксист
соглашается с Петиной ценой вместо того, чтобы просить меньше, и Петя
соглашается с ценой таксиста вместо того, чтобы предложить больше.
Сколько заплатит Петя? Все числа от 1 до 10000.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

a, b, c и d.

## Выходные данные

Цена поездки.

## Примеры

### Пример 1

Ввод:

```
150 50 1000 100
```

Вывод:

```
450
```

## Решение

Разыграем торг. Если a уже не меньше c, таксист соглашается. Иначе Петя
повышает на b; если это дошло до цены таксиста, Петя с ней соглашается.
Потом таксист снижает на d; если это дошло до Петиного предложения,
таксист соглашается с ним. Разрыв за раунд сокращается хотя бы на 2,
так что раундов не больше примерно 5000: `O(max(1, c - a))`. Результаты
сверены с независимой реализацией на 800 случайных входах.

Подводные камни:

- та сторона, что перешла бы чужую цену, уступает по чужой цене, так что
  ответ — всегда реально названная цена (тесты 04 и 05);
- Петя может начать выше цены таксиста; тогда торга нет, и Петя платит
  a (тест 02).
