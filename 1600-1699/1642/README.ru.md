# 1642. Одномерный лабиринт

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Человек стоит в точке 0 на прямой с препятствиями и выходом в точке x,
идёт в выбранном направлении, сразу выходит, достигнув выхода, и
разворачивается у каждого препятствия. Для обоих начальных направлений,
вперёд (в сторону роста) и назад, нужно найти пройденное до выхода
расстояние или сообщить, что выход недостижим.

## Входные данные

n и x (0 ≤ n ≤ 100), затем n различных координат препятствий. Все
координаты ненулевые, не больше 1000 по модулю, и ни одно препятствие
не стоит в точке выхода. В любом направлении путь встречает выход или
препятствие.

## Выходные данные

Два расстояния, сначала для движения вперёд, или `Impossible`.

## Примеры

### Пример 1

Ввод:

```
3 -2
-10 -4 2
```

Вывод:

```
6 2
```

### Пример 2

Ввод:

```
3 -2
10 -1 2
```

Вывод:

```
Impossible
```

## Решение

Важны только ближайшие препятствия: left — наибольшее меньше 0 (или −∞,
если его нет) и right — наименьшее больше 0 (или +∞, если его нет).
Выход достижим ровно тогда, когда left < x < right; иначе `Impossible`.
Тогда в обоих направлениях путь прямой или с одним крюком:

- x > 0: вперёд x; назад до left и обратно, 2 · |left| + x;
- x < 0: вперёд до right и обратно, 2 · right + |x|; назад |x|.

Нужное для крюка препятствие существует по обещанию условия. `O(n)`.

Подводные камни:

- препятствие между началом и выходом закрывает оба направления, так
  что один ответ на оба (второй пример, тест 06);
- со стороны выхода препятствий может не быть вовсе.

Ответы совпадают с независимой принятой реализацией на 300 случайных
прямых.
