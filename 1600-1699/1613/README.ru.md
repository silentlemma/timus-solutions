# 1613. Для любителей статистики

[Timus 1613](https://acm.timus.ru/problem.aspx?space=1&num=1613) · сложность 142 · binary_search

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Трамваи каждого из n городов (n ≤ 69 999) перевезли за год некоторое
число людей, меньше 10⁹. Для каждого из q запросов (q ≤ 69 999)
`l r x` скажите, есть ли среди городов с номерами от l до r такой,
что перевёз ровно x человек. Выведите строку из q символов: `1` — да,
`0` — нет.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n, n чисел, q, затем q строк `l r x`.

## Выходные данные

Строка ответов.

## Примеры

### Пример 1

Ввод:

```
5
1234567 666666 3141593 666666 4343434
5
1 5 3141593
1 5 578202
2 4 666666
4 4 7135610
1 1 1234567
```

Вывод:

```
10101
```

## Решение

Отсортируем пары (число, номер города). Города с числом x тогда идут
одним блоком, по возрастанию номеров. Для запроса двоичный поиск
находит первую пару, не меньшую (x, l): ответ «да», если её число равно
x, а город не больше r. `O((n + q) log n)`.

Подводные камни:

- ответ — одна строка без разделителей;
- город нужно найти не раньше l, а не просто где-нибудь с числом x
  (тест 04).
