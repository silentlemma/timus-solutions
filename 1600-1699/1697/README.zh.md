# 1697. 狙击

[Timus 1697](https://acm.timus.ru/problem.aspx?space=1&num=1697) · 难度 5442 · geometry

原题作者 Alex Samsonov，出自 2009 年 2 月彼得罗扎沃茨克冬季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

位于 S = (sx, sy, sz) 的狙击手盯着一个沿地面从 A 骑行到 B 的目标。子弹沿直线飞行；
可以擦过摩天楼（立在地面上、各边平行于坐标轴的长方体），但不能穿过。
求狙击手能击中的路径上的第一个点，或报告不存在。

## 输入

S，然后是地面上的 A 和 B，然后是 n（0 ≤ n ≤ 100）座楼 lx ly rx ry h。
所有值都是绝对值不超过 100 的整数，sz ≥ 0。楼与楼没有公共点，S 在所有楼之外，线段 AB 不碰任何楼。

## 输出

该点的坐标，误差不超过 10⁻⁷，或 Impossible。

## 样例

### 样例 1

输入：

```
0 0 2
-4 4 4 4
2
-3 2 -1 3 10
1 -1 4 2 20
```

输出：

```
-1.3333333333 4.0000000000
```

### 样例 2

输入：

```
0 0 2
4 1 4 -1
1
1 -1 3 1 10
```

输出：

```
Impossible
```

## 解法

设 P(t) = A + t(B − A)。射向 P(t) 的子弹上的点是 S + u(P(t) − S) = S + u(A − S) + v(B − A)，其中 v = u·t，
它关于 (u, v) 是线性的。所以楼的内部在 (u, v) 平面上的原像是一个开凸多边形，
由两条带（x 和 y 方向）以及 u 的高度范围（sz·(1 − u) 要低于 h）截出。它挡住的时刻 t 就是该多边形上 v / u 的取值，
是一个开区间 (lᵢ, rᵢ)。再加两条直线 −1 ≤ t ≤ 2，使多边形有界，又不影响需要的时刻。

所有边界直线的系数都是很小的整数。所以多边形的顶点可以精确求出：取满足全部约束的两两直线交点，
lᵢ 和 rᵢ 就是这些点上 v / u 的极值。多边形有内部（楼确实挡住了什么）当且仅当它有三个不同的顶点：
仅仅相切的多边形只是线段或点。唯一的例外是射击平面包含一面墙，例如 S、A、B 的 x 都等于 lx：
此时多边形有内部，但每发子弹只是贴着墙滑过。这时某条带边界直线的两个系数都为零，这栋楼什么也挡不住。
狙击手在地面上（sz = 0）时只是没有高度约束。

空闲时刻构成闭集，所以它的第一个点是 0 或某个区间的右端点 rᵢ。按顺序用所有开区间检验这些候选，输出第一个空闲的。
所有比较都是小于 10¹⁰ 的整数交叉相乘。`O(n²)`。

注意事项：

- 允许擦过墙、棱或屋顶，所以区间是开的，空闲时刻可能恰好夹在两个区间之间；
- 贴着屋顶或墙飞行的子弹不算被挡住，浮点判断很容易在这里出错；
- 所有子弹可能都在某面墙所在的平面内（测试 10 和 11），此时多边形有内部并不意味着被挡住；
- A = B 时只有一个时刻 0。

答案与一个独立的已通过实现在 330 个随机测试上一致，其中大多数坐标很小，子弹会擦过棱和角；
在 400 个所有子弹都位于墙面所在平面的测试上也一致。
