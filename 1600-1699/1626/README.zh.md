# 1626. 干扰线段

[Timus 1626](https://acm.timus.ru/problem.aspx?space=1&num=1626) · 难度 6623 · geometry

原题出自 2008 年冬季彼得罗扎沃茨克集训的 SPbSU ITMO Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个简单多边形有 N 个顶点（3 ≤ N ≤ 800，整数坐标绝对值不超过 10⁴，没有三个相邻顶点
共线），线段 S 严格位于其内部。这里的三角剖分只用多边形的顶点，并且除三角形自己的
顶点外，任何顶点都不能落在三角形的边上。求某个三角剖分中严格包含 S 的三角形，输出它的
三个顶点编号；否则输出 `Impossible`。任何这样的三角形都被接受。

时间限制：5 秒。内存限制：64 MB。

## 输入

N，按顺序给出的顶点，然后是 S 的两个端点。

## 输出

三个顶点编号，或 `Impossible`。

## 样例

### 样例 1

输入：

```
3
0 0
0 3
4 3
1 2 2 2
```

输出：

```
1 2 3
```

### 样例 2

输入：

```
4
0 0
2 0
2 3
0 3
1 1 1 2
```

输出：

```
Impossible
```

## 解法

一个三角形属于某个三角剖分，当且仅当它的边都是多边形的边或对角线（在多边形内部、不碰
到其他顶点），并且内部没有顶点：这时多边形其余部分分成若干更小的多边形，都可以三角剖分。
所以任务就是在 S 周围找这样一个三角形。

一切都用 N 个顶点的位集完成。把多边形定为逆时针方向后，对每对 a < b 存下严格位于直线
a → b 左侧的顶点集合。若 j 位于 i 处的内角之内、i 位于 j 处的内角之内，没有边与该线段
真正相交，且开线段上没有顶点，则 i、j 是对角线。可能相交的边的两端相对直线 i → j 的
“严格在左侧”标志不同（左侧集合与自身循环右移一位的异或），且 i 和 j 相对该边所在直线的
同类标志也不同；只需精确检查这些候选边。

然后对每条使 S 两端都严格在其左侧的对角线或边 a → b，第三个顶点 k 是 a 和 b 的公共邻居，
并且要使 S 两端都在三角形内，这同样是位集的与运算。若三个“左侧”集合除三角形的顶点外没有
公共顶点，三角形 a、b、k 就是空的。找到的第一个这样的三角形就是答案。时间为 `O(N³)`。

Python 用另一种方式构建“左侧”集合：在每个顶点周围按角度对其余顶点排序，于是每个“左侧”
集合都是该顺序中的一段循环区间，可由前缀位集以 `O(1)` 次大数运算得到；每个方向上最近的
顶点则标出哪些线段上没有其他顶点。它只保存当前顶点的集合，因此三角形是否为空改用三个角来判断：
多边形在角上的边都不能指向三角形内部。边界无法穿过三角形的边，于是整条边界都在外面，所有顶点也是。
表中 w 是大数每个数位的比特数。

易错点：

- 某个顶点可能恰好落在一条候选对角线上（测试 03、04）；
- 在矩形中两条对角线可能都与 S 相交（第二个样例）；
- 样例中的三角形顶点顺序可以任意，所以由检查器逐条验证所有条件。

所有测试的答案都通过了检查器，并且在每个生成的多边形上，一个独立的已通过实现给出相同的结论。

## 各语言说明

- Python 在 PyPy 下运行：在这里最大的测试上 CPython 约用 2.4 秒，限制为 5 秒，对评测而言
  太接近，而 PyPy 约 0.9 秒。PyPy 只在回收时才释放短命的位掩码，所以解法每 64 行调用一次
  回收器；否则仅垃圾就超过 64 MB 的限制。
- Java 用 int 运算构建“左侧”集合（坐标不超过 10⁴ 允许这样做），用时减半。
