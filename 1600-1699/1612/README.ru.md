# 1612. Трамвайный форум

[Timus 1612](https://acm.timus.ru/problem.aspx?space=1&num=1612) · сложность 152 · strings

Автор оригинальной задачи — Александр Ипатов, подготовка — Денис Мусин; XII чемпионат Урала по спортивному программированию, 29 марта 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Сообщение на форуме длиной до 10000 символов, из строчных латинских
букв, пробелов, переводов строк и знаков `. , - : ! ?`, написал водитель
трамвая, если слово `tram` встречается в нём чаще, чем `trolleybus`,
водитель троллейбуса, если наоборот, и водитель автобуса иначе. Слова —
это отрезки из букв. Кто его написал?

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Сообщение.

## Выходные данные

`Tram driver`, `Trolleybus driver` или `Bus driver`.

## Примеры

### Пример 1

Ввод:

```
of course, tram is the best transport
in the world!
```

Вывод:

```
Tram driver
```

### Пример 2

Ввод:

```
yes, yekaterinburg trams are the
best trams in the world, but
i like my trolleybus too.
```

Вывод:

```
Trolleybus driver
```

### Пример 3

Ввод:

```
read forum.tr.ru every day!
you can learn much about tram 
drivers and trolleybus drivers.
```

Вывод:

```
Bus driver
```

## Решение

Разбиваем сообщение на слова по каждому символу, который не буква,
считаем слова, равные `tram` и `trolleybus`, и сравниваем два числа:
`O(n)`. Ответы сравнивались с независимой реализацией на
сгенерированных сообщениях.

Подводные камни:

- считаются только целые слова: `trams`, `tramway` или `tr` в
  `forum.tr.ru` — это не слово `tram` (примеры 2 и 3);
- знаки тоже разделяют слова, так что в `tram-tram` два трамвая, а в
  `tram,trolleybus` — по одному каждого (тесты 06 и 07);
- при равных количествах, в том числе нулевых, это водитель автобуса.

## Оптимизированные решения

Оптимизированное решение на C++ собирает слово в массиве `char`
фиксированного размера на 11 байт вместо `std::string`: совпасть могут
только слова не длиннее 10 букв, длины `trolleybus`, поэтому буквы после
десятой только считаются, но не хранятся. Буквы оно проверяет сравнением
с границами диапазона вместо `islower`: {1612_strings_optimized.cpp}.

Оптимизированное решение на Java читает байты из буфера на 4 КБ, а не
собирает всё сообщение в `StringBuilder` и не разбивает его регулярным
выражением. О текущем слове оно хранит только длину и то, остаётся ли
оно ещё префиксом `tram` и `trolleybus`, так что слова вообще не
сохраняются: {1612_strings_optimized.java}.
