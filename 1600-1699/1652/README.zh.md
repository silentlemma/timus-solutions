# 1652. 银行危机

[Timus 1652](https://acm.timus.ru/problem.aspx?space=1&num=1652) · 难度 2611 · matching

原题作者 Pavel Atnashev，出自 NEERC 2008 东部分区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 家银行各有所属国家和可用资金，它们之间有 m 笔同业债务。一家银行如果向本国银行放贷，就算“负责任”。
在检查之前，银行可以向债权人整笔买下债务，只能用最初的可用资金支付；卖方总会同意。求负责任银行的最大
可能数量。

## 输入

n（2 ≤ n ≤ 1000），然后 n 行“国家 资金”（1 ≤ 国家 ≤ 100，0 ≤ 资金 ≤ 10⁹），然后 m（0 ≤ m ≤ 10000）
和 m 行“债权人 债务人 金额”（0 ≤ 金额 ≤ 10⁹）。

## 输出

负责任银行的最大数量。

## 样例

### 样例 1

输入：

```
5
1 100000
1 200000
1 300000
2 400000
2 500000
4
1 2 200000
1 3 200000
2 4 500000
3 5 500000
```。

输出：

```
3
```

## 解法

银行只需要一笔本国银行欠下的债务，所以只有每笔债务最终的持有者重要。若债务 d 的债务人与银行 b 同国、b
本身不是债务人，并且 b 已经持有 d 或者 d 的金额不超过 b 的资金，b 就可以成为 d 的持有者。每笔债务只有一个
持有者，所以负责任的银行对应互不相同的债务：答案是各国二分图最大匹配之和。没匹配上的债务就留在
原处，而买多于一笔债务毫无帮助。

银行与债务的配对可能有一千万种，但一家银行买得起的债务是按金额排序后的一个前缀，所以从不需要列出这些配对。
Kuhn 的增广路通过带路径压缩的“下一个未访问债务”指针遍历前缀，跳过已标记的债务。先处理已持有本国银行债务的
银行，两组内均按买得起的前缀长度递增排序。搜索失败后标记保留：匹配没有改变，所以已到达的债务仍然走不通。

其中 N = n + m，k 为成功搜索的次数。

易错点：

- 银行不能借钱给自己，所以即使买得起也绝不能持有自己欠下的债务（测试 04）；
- 别国银行欠下的债务没有帮助；
- 卖掉债务得来的钱不能再花，所以每次购买只按最初资金检查。

在 150 个小市场上答案与对所有持有者的穷举一致，在大市场上与一个独立的已通过实现一致。
