# 1652. Банковский кризис

[Timus 1652](https://acm.timus.ru/problem.aspx?space=1&num=1652) · сложность 2688 · matching

Автор оригинальной задачи — Павел Атнашев; четвертьфинал Восточного подрегиона NEERC 2008.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У n банков, каждый со своей страной и свободными средствами, есть m
межбанковских долгов. Банк считается «ответственным», если кредитует
банк своей страны. Перед проверкой банки могут выкупать долги целиком у
кредиторов, платя только из изначальных свободных средств; продавцы
всегда согласны. Нужно найти наибольшее возможное число ответственных
банков.

## Входные данные

n (2 ≤ n ≤ 1000), затем n строк «страна средства» (1 ≤ страна ≤ 100,
0 ≤ средства ≤ 10⁹), затем m (0 ≤ m ≤ 10000) и m строк
«кредитор должник сумма» (0 ≤ сумма ≤ 10⁹).

## Выходные данные

Наибольшее число ответственных банков.

## Примеры

### Пример 1

Ввод:

```
5
1 100000
1 200000
1 300000
2 400000
2 500000
4
1 2 200000
1 3 200000
2 4 500000
3 5 500000
```

Вывод:

```
3
```

## Решение

Банку нужен всего один долг банка своей страны, так что важен только
итоговый держатель каждого долга. Банк b может стать держателем долга d,
если должник по d из страны b, сам b не должник и b либо уже держит d,
либо сумма d укладывается в средства b. У каждого долга один держатель,
так что ответственные банки сопоставлены разным долгам: ответ —
наибольшее паросочетание в двудольном графе, отдельно для каждой страны.
Несопоставленные долги просто остаются на месте, а покупка больше одного
долга никогда не помогает.

Рёбер в графе может быть десять миллионов, но доступные банку долги
образуют префикс долгов, отсортированных по сумме, так что их никогда не
перечисляют. Увеличивающие пути Куна проходят префикс через указатель
«следующий непросмотренный долг» со сжатием путей, так что каждый долг
просматривается один раз за поиск. Сначала идут банки, уже держащие
долг, затем более бедные, и чинить приходится мало путей. После
неудачного поиска пометки сохраняются: паросочетание не изменилось, так
что достигнутые долги по-прежнему никуда не ведут. `O(k · (n + m))` для
k успешных поисков, на практике гораздо меньше.

Подводные камни:

- банк не может кредитовать сам себя, так что никогда не держит
  собственный долг, даже если может его оплатить (тест 04);
- долг банка другой страны не помогает;
- деньги от продажи долга тратить нельзя, так что каждая покупка
  проверяется только по изначальным средствам.

Ответы совпадают с полным перебором держателей на 150 маленьких рынках и
с независимой принятой реализацией на больших.
