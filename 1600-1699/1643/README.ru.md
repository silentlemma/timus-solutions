# 1643. Атака Тёмной крепости

[Timus 1643](https://acm.timus.ru/problem.aspx?space=1&num=1643) · сложность 425 · bfs

Автор оригинальной задачи — Денис Дублённых; осеннее первенство школьников, октябрь 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Две армии стоят на карте n × m из проходимых и непроходимых районов. За
день армия переходит в любой из 8 соседних проходимых районов; район с
буквой-телепортом может мгновенно перенести её в любой район с той же буквой.
Оказавшись в одном районе, армии объединяются и дальше идут вместе. До
этого ни одной из них нельзя входить в крепость. Нужно найти наименьшее
число дней, за которое объединённая армия дойдёт до крепости.

## Входные данные

n и m (1 ≤ n, m ≤ 100), затем карта: `#` — непроходимый район, `.` —
проходимый, `A`–`Z` — телепорты, `$` и `!` — армии, `*` — крепость;
каждый из трёх последних символов встречается ровно один раз.

## Выходные данные

Наименьшее число дней или `Impossible`.

## Примеры

### Пример 1

Ввод:

```
5 8
....AA.#
.######!
.....*##
.#######
..B$...B
```

Вывод:

```
11
```

### Пример 2

Ввод:

```
3 5
##*..
!#...
##..$
```

Вывод:

```
Impossible
```

## Решение

Армия, пришедшая раньше, может подождать, так что встреча в районе c
занимает max(d₁(c), d₂(c)) дней, где d₁ и d₂ — расстояния двух армий
при закрытой крепости. Затем объединённой армии нужно ещё d(c) дней до
крепости, а поскольку любой ход обратим (шаг работает в обе стороны,
телепорт связывает свою букву в обоих направлениях), d — это расстояние
от самой крепости. Ответ — минимум max(d₁, d₂) + d по всем районам,
кроме крепости.

Каждое расстояние — один поиск в ширину, где телепорты стоят 0: 0-1 BFS,
в котором бесплатные ходы идут первыми: в Go через стек, в остальных
через начало дека. У первого обработанного района с буквой наименьшее
расстояние среди районов этой буквы, так что каждая буква распространяется
один раз. `O(n · m)` на поиск, всего три поиска.

Подводные камни:

- армия не может проходить через крепость до встречи (тест 06),
  но объединённая армия может начать путь прямо рядом с ней;
- группу буквы нужно распространять только один раз, иначе карта,
  полная одной буквы, стоит квадратичного времени;
- объединённая армия тоже может пользоваться телепортами (тест 07).

Ответы совпадают с независимой принятой реализацией на 180 случайных
картах.

## Оптимизированные решения

Новые C++ и Go хранят сетку и три массива расстояний плоско; номера клеток и расстояния — 16-битные. Клеток не больше 10000, кратчайшее расстояние меньше 10000, а 65535 означает недостижимость. При первом обнаружении буквы телепорта на дне d сразу назначаем d всем клеткам этой буквы и помещаем их в очередь. Так нулевая компонента неявно стягивается до продолжения обычного BFS; оставшиеся рёбра стоят один день. Каждая клетка обнаруживается один раз, очереди хватает n·m элементов. Связанный массив хранит группы букв без отдельных объектов для клеток. Два обхода запрещают крепость, третий стартует в ней без запрета. Минимизируем max(d₁,d₂)+d₃ по достижимым местам встречи вне крепости: ранняя армия ждёт, а обратимость ходов делает третье расстояние продолжением пути. Время и память O(n·m). Все обычные исходники сохранены; Java, Python и Rust закрывают быстрый набор уже подходящими базами.

Принятые базовые реализации [1643_bfs.java](1643_bfs.java), [1643_bfs.py](1643_bfs.py), [1643_bfs.rs](1643_bfs.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
