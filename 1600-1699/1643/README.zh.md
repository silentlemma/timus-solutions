# 1643. 进攻黑暗要塞

[Timus 1643](https://acm.timus.ru/problem.aspx?space=1&num=1643) · 难度 426 · bfs

原题作者 Denis Dublennykh，出自 2008 年 10 月的乌拉尔国立大学中学生竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两支军队位于 n × m 的地图上，地区分为可通行和不可通行两种。军队每天可移动到 8 个相邻的可通行地区
之一；带有传送字母的地区能把军队瞬间送到任何有相同字母的地区。两支军队一旦处在同一地区就会合，此后
一起行动。会合之前，任何一支都不能进入要塞。求会合后的军队到达要塞所需的最少天数。

## 输入

n 和 m（1 ≤ n, m ≤ 100），然后是地图：`#` 不可通行，`.` 可通行，`A`–`Z` 传送门，`$` 和 `!` 为
两支军队，`*` 为要塞；后三种符号各恰好出现一次。

## 输出

最少天数，或 `Impossible`。

## 样例

### 样例 1

输入：

```
5 8
....AA.#
.######!
.....*##
.#######
..B$...B
```

输出：

```
11
```

### 样例 2

输入：

```
3 5
##*..
!#...
##..$
```

输出：

```
Impossible
```

## 解法

先到的军队可以等待，所以在地区 c 会合需要 max(d₁(c), d₂(c)) 天，其中 d₁、d₂ 是要塞封闭时两支
军队的距离。会合后的军队还需要 d(c) 天到达要塞；由于每种移动都可逆（一步两向都能走，传送门在同一
字母的地区之间双向相连），d 就是从要塞本身出发的距离。答案是除要塞外所有地区上 max(d₁, d₂) + d 的
最小值。

每个距离都是一次传送代价为 0 的广度优先搜索：0-1 BFS，免费的移动放到双端队列的前端。从队列中取出
某字母的第一个地区时，它已经是该字母所有地区中距离最小的，所以每个字母只需扩展一次。每次搜索
`O(n · m)`，共三次。

易错点：

- 会合前军队不能穿过要塞（第二个样例、测试 06），但会合后的军队可以就在要塞旁出发；
- 每个字母的组只应扩展一次，否则满是同一字母的地图会花费平方时间；
- 会合后的军队同样可以使用传送门（测试 07）。

在 180 张随机地图上，答案与一个独立的已通过实现一致。
