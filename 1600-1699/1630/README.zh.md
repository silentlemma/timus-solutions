# 1630. 护身符

[Timus 1630](https://acm.timus.ru/problem.aspx?space=1&num=1630) · 难度 1004 · graphs

原题作者 Sergey Pupyrev（由 Daniil Ayzenshteyn 准备），出自第十三届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

护身符是空间中一组半径 1 毫米的小球，其中一些球对用 8 毫米长的杆相连，因此相邻球心恰好相距
1 厘米。只要能沿着杆从一个球到达另一个球，这样的路径上最少的杆数就必须等于两球心之间以厘米
计的距离。给定连接方案（哪些球相连），判断能否做出这样的护身符。

## 输入

第一行为 N 和 M（1 ≤ N ≤ 100，0 ≤ M ≤ 10000），即球数和杆数。接下来 M 行每行给出由一根杆
相连的两个球；任何一对球不会连两次，也没有杆把球连到自身。

## 输出

能做出时输出 `Luck is possible`，否则输出 `Unlucky Petr`。

## 样例

### 样例 1

输入：

```
3 3
1 2
1 3
2 3
```

输出：

```
Luck is possible
```

### 样例 2

输入：

```
4 4
1 2
1 3
1 4
2 3
```

输出：

```
Unlucky Petr
```

## 解法

不同的连通分量可以放得很远，所以逐个检查：分量中的图距离必须能由空间中的点实现。这样只剩
两种形状。

取一个有两个邻居 u、w 的球 v。它们到 v 的距离都是 1，所以彼此相距 1 或 2；相距 2 时它们是
过 v 的一条直径的两端。此时第三个邻居 x 到 u、w 的距离平方之和为 4，而 1 和 4 的任何组合
都得不到 4，所以这样的 v 恰好有两个邻居。

- 若分量中有三角形 a、b、c，那么 c 的任何其他邻居 d 到 a 的距离必须是 1（否则 c 位于 a 和
  d 之间，却有三个邻居），到 b 也是 1；如此反复，每个球都与其余所有球相连。空间中两两等距的
  点最多四个，所以它是至多 4 个球的完全图。
- 没有三角形时，每个球的邻居都彼此相对，于是所有度数不超过 2，每个中间的球都是其两个邻居的
  中点：所有球在一条直线上，环无法闭合。所以它是一条路径。

两种形状确实都可行：沿直线排列的路径，以及边长为 1 的点、线段、正三角形或正四面体。用并查集
为每个分量统计球数 k、杆数 e 和最大度数；当 e = k − 1 且度数都不超过 2，或 e = k(k − 1)/2
且 k ≤ 4 时，该分量可行。`O(N + M log N)`。

易错点：

- 三角形再挂一个球就不行（第二个样例）；
- 正方形或六边形是环而不是路径（测试 04、09）；
- 五个两两相连的球需要四维空间（测试 05）。

在全部 1024 个 5 球图和 360 个随机方案上，答案与一个独立的已通过实现一致。
