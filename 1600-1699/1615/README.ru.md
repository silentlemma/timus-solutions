# 1615. Трамвайный пасьянс

[Timus 1615](https://acm.timus.ru/problem.aspx?space=1&num=1615) · сложность 2070 · math

Автор оригинальной задачи — Владимир Яковлев; XII чемпионат Урала по спортивному программированию, 29 марта 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В перетасованной колоде 2n карт: две масти, в каждой n достоинств
(2 ≤ n ≤ 10 000). Карты выкладываются по одной в ряд слева направо.
После каждой карты ряд просеивается: пока какие-то две карты, между
которыми ровно одна карта, совпадают мастью или достоинством, левая
карта самой левой такой пары убирается, а карты правее сдвигаются.
Пасьянс сошёлся, если в конце осталось ровно две карты. Выведите
вероятность этого несократимой дробью.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

n.

## Выходные данные

Вероятность в виде `p/q`.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
2/3
```

## Решение

Ответ — (n² + 3n − 2) / (2n(2n − 1)), сокращённая на наибольший общий
делитель числителя и знаменателя. `O(log n)`.

Немного о том, что за этим стоит. Карта убирается только как левая в
паре, поэтому две последние карты колоды всегда остаются: правее них
через одну никогда нет карт. Пасьянс сходится ровно тогда, когда всё,
что перед ними, сметено. Сама формула найдена разыгрыванием всех
раскладов для маленьких колод: n = 2, 3, 4, 5 дают 2/3, 8/15, 13/28 и
19/45 — в точности её значения, а случайные расклады для n = 10, 30 и
100 с ней согласуются. Вероятность неудачи раскладывается как
(n − 1)(3n − 2) / (2n(2n − 1)).

Подводные камни:

- дробь нужно сократить: при n = 6 это 52/132 = 13/33 (тест 05);
- 2n(2n − 1) доходит примерно до 4·10⁸, так что произведение
  помещается в 32 бита, но решения на C++, Go, Java и Rust используют
  64-битные целые, а Python — целые произвольной точности.
