# 1615. 电车接龙

[Timus 1615](https://acm.timus.ru/problem.aspx?space=1&num=1615) · 难度 2070 · math

原题作者 Vladimir Yakovlev，出自 2008 年 3 月 29 日第十二届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一副洗好的牌有 2n 张：两种花色，每种 n 个点数（2 ≤ n ≤ 10 000）。牌一张一张
从左到右排成一行。每放一张牌后进行筛选：只要有两张中间恰好隔一张牌的牌花色或
点数相同，就移除最左边这样一对中的左边那张，右边的牌依次左移。若最后恰好剩下
两张牌，接龙就成功了。以最简分数输出成功的概率。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

n。

## 输出

概率，格式为 `p/q`。

## 样例

### 样例 1

输入：

```
2
```

输出：

```
2/3
```

## 解法

答案是 (n² + 3n − 2) / (2n(2n − 1))，再用分子分母的最大公约数约分。`O(log n)`。

背后的一些事实。牌只会作为一对中的左边那张被移除，所以整副牌的最后两张总会留下：
它们右边隔一个位置的地方从来没有牌。接龙成功当且仅当它们前面的牌全被清掉。公式本身
是通过对小牌组枚举所有发牌得到的：n = 2、3、4、5 分别给出 2/3、8/15、13/28 和
19/45，正是公式的值；对 n = 10、30 和 100 的随机发牌也与之吻合。失败的概率可以分解为
(n − 1)(3n − 2) / (2n(2n − 1))。

易错点：

- 分数必须约分：n = 6 时为 52/132 = 13/33（测试 05）；
- 2n(2n − 1) 最多约为 4·10⁸，乘积放得进 32 位，但 C++、Go、Java 和 Rust 解法使用
  64 位整数，Python 则使用任意精度整数。
