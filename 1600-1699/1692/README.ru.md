# 1692. Флаги провинций

[Timus 1692](https://acm.timus.ru/problem.aspx?space=1&num=1692) · сложность 380 · constructive

Автор оригинальной задачи — Игорь Чевдарь; Ural SU Contest, Петрозаводские зимние сборы, февраль 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нарисовать как можно больше флагов из n цветов так, чтобы у любых двух
флагов был общий цвет, но ни один цвет не встречался на трёх и более
флагах.

## Входные данные

n (3 ≤ n ≤ 1000).

## Выходные данные

Число флагов k, затем каждый флаг — число его цветов и сами цвета.
Подходит любой верный набор.

## Примеры

### Пример 1

Ввод:

```
4
```

Вывод:

```
3
2 1 2
2 1 3
2 2 3
```

## Решение

Каждой из k(k − 1)/2 пар флагов нужен общий цвет. Цвет, который есть
не больше чем на двух флагах, общий не больше чем для одной пары,
поэтому разные пары используют разные цвета и k(k − 1)/2 ≤ n.

Эта граница достигается: занумеруем пары флагов и дадим каждой паре
свой цвет, нанесённый только на эти два флага. Тогда на каждом флаге
k − 1 цветов, любые два флага делят цвет своей пары, и ни один цвет не
встречается больше чем на двух флагах. Берём наибольшее k с
k(k − 1)/2 ≤ n; лишние цвета не используются. `O(n)` на вывод.

Подводные камни:

- оставшиеся цвета использовать не обязательно (тест 04);
- набор из примера — один из многих, поэтому чекер проверяет флаги, а
  не сравнивает текст.

Чекер проверяет количество, диапазоны, общие цвета у каждой пары и
правило «не больше двух»; ответы независимой принятой реализации
проходят его для всех n до 300.
