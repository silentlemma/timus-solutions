## Задача

Числа 1, 2, 3, … выписываются по очереди. Новое число a соединяется со
всеми ранее выписанными b, для которых b + a² ≡ 0 или a + b² ≡ 0
(mod k). Вывести число, после которого в графе впервые появляется
цикл, или −1, если этого не случится.

## Входные данные

k (1 ≤ k ≤ 100000).

## Выходные данные

Это число.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
5
```

## Решение

Соединены ли два числа, зависит только от их остатков. У каждого
остатка r есть пара s = −r² mod k, и все числа с остатком r соединены
со всеми числами с остатком s. Если s ≠ r, по два числа каждого
остатка уже дают 4-цикл; если s = r, три числа с остатком r дают
треугольник. И то и другое случается не позже числа 3k, так что цикл
появляется всегда и −1 не выводится никогда.

Значит, можно моделировать. Храним выписанные числа, сгруппированные
по остаткам, и систему непересекающихся множеств над числами. Для
нового числа a с остатком r ранние соседи — числа с остатком −r² mod k
и числа, остаток s которых удовлетворяет s² ≡ −r; остатки s с данным
−s² mod k перечислены заранее. Рёбра добавляются по одному: ребро
между числами одного дерева замыкает первый цикл, и a — ответ. Любое
другое ребро сливает два дерева, а это происходит меньше 3k раз за всё
время, так что работа — `O(k α(k))`.

Подводные камни:

- оба условия могут указывать на один и тот же остаток; его надо взять
  один раз, иначе одно ребро посчитается дважды и даст ложный цикл;
- при k = 1 соединена любая пара, и ответ 3;
- r · r доходит до 10¹⁰, больше 32 бит, поэтому остатки возводятся в
  квадрат в 64-битной арифметике.

Ответы совпадают с независимой принятой реализацией для всех k ≤ 299 и
для 34 больших k.
