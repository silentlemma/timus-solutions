# 1682. 疯狂的教授

[Timus 1682](https://acm.timus.ru/problem.aspx?space=1&num=1682) · 难度 537 · dsu

原题作者 Pavel Egorov，出自 2009 年 2 月 28 日第十届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

依次写下 1, 2, 3, …。新写的数 a 与之前所有满足 b + a² ≡ 0 或 a + b² ≡ 0（mod k）的数 b 连边。
输出写下哪个数之后图中第一次出现环；若永远不会出现，输出 −1。

## 输入

k（1 ≤ k ≤ 100000）。

## 输出

该数。

## 样例

### 样例 1

输入：

```
2
```

输出：

```
5
```

## 解法

两个数是否相连只取决于它们的余数。每个余数 r 都有伙伴 s = −r² mod k，
余数为 r 的所有数都与余数为 s 的所有数相连。若 s ≠ r，两个余数各有两个数就构成 4 元环；
若 s = r，三个余数为 r 的数构成三角形。这两种情况最迟在写到 3k 时发生，
所以环一定会出现，永远不会输出 −1。

因此直接模拟。按余数分组保存已写下的数，并对这些数维护并查集。
对余数为 r 的新数 a，之前的邻居是余数为 −r² mod k 的数，以及余数 s 满足 s² ≡ −r 的数；
对每个值，事先列出 −s² mod k 等于它的所有余数 s。逐条加边：连接同一棵树中两个数的边闭合了第一个环，
a 就是答案。其余每条边都合并两棵树，总共少于 3k 次，所以工作量为 `O(k log k)`。

注意事项：

- 两个条件可能指向同一个余数，只能取一次，否则同一条边算两次会造成虚假的环；
- k = 1 时任意两数都相连，答案为 3；
- r · r 接近 10¹⁰，超出 32 位，所以要用 64 位运算求余数的平方。

答案与一个独立的已通过实现在所有 k ≤ 299 以及 34 个更大的 k 上一致。
