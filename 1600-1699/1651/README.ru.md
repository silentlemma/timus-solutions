# 1651. Кратчайшая подцепь

[Timus 1651](https://acm.timus.ru/problem.aspx?space=1&num=1651) · сложность 346 · dp

Автор оригинальной задачи — Владимир Яковлев (идея — Магаз Асанов); четвертьфинал Восточного подрегиона NEERC 2008.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Цепь p в ориентированном графе задана списком из n вершин. Нужно найти
цепь q с теми же первой и последней вершинами, рёбра которой — рёбра p,
взятые в том же порядке, и с наименьшим числом рёбер.

## Входные данные

n (2 ≤ n ≤ 100000), затем n номеров вершин от 1 до 10000; соседние
номера не совпадают.

## Выходные данные

Вершины q через пробел; q может состоять из одной вершины.

## Примеры

### Пример 1

Ввод:

```
9
1 2 7 3 2
8 4 8 5
```

Вывод:

```
1 2 8 5
```

## Решение

Позиция i списка означает «стоим в вершине pᵢ и можем брать рёбра p,
начиная с i-го». Отсюда q может взять любое более позднее ребро,
выходящее из pᵢ, то есть ребро (pⱼ, pⱼ₊₁) с j ≥ i и pⱼ = pᵢ, и
продолжить с позиции j + 1. Попадание в последнюю вершину где угодно
заканчивает q, ведь дальше рёбра могут только добавиться.

Значит, dp[i] = 0, если pᵢ — последняя вершина, иначе
dp[i] = 1 + min dp[j + 1] по j ≥ i с pⱼ = pᵢ. При проходе справа налево
таблица по номерам вершин хранит этот минимум для суффикса, так что
каждая позиция стоит O(1); запомненное j восстанавливает q от позиции 0.
Если первая и последняя вершины совпадают, q — эта одна вершина. `O(n)`.

Среди одинаково коротких цепей программа оставляет самый поздний переход
из вершины. Так все пять решений выдают одинаковый ответ, но допустима
любая оптимальная цепь. Проверяющая программа проверяет концы, порядок
рёбер и минимальную длину, независимо вычисленную проходом слева направо.

Подводные камни:

- замкнутая цепь сжимается до одной вершины (тест 03);
- разные оптимальные списки вершин должны приниматься (тест gen3);
- q может проходить последнюю вершину только в конце, так что
  остановиться при первом попадании правильно;
- цель перехода — позиция после выбранного ребра, j + 1, а не j.

Решение на Python и проверяющая программа сверены с полным перебором
подмножеств рёбер на 2000 случайных малых цепях и 1155 исчерпывающих случаях.
