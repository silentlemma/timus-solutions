# 1651. 最短子链

[Timus 1651](https://acm.timus.ru/problem.aspx?space=1&num=1651) · 难度 346 · dp

原题作者 Vladimir Yakovlev（创意来自 Magaz Asanov），出自 NEERC 2008 东部分区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有向图中的一条链 p 由 n 个顶点的列表给出。求一条链 q，起点和终点与 p 相同，其边是按 p 中相同顺序选取
的 p 的边，并且边数尽可能少。

## 输入

n（2 ≤ n ≤ 100000），然后是 n 个 1 到 10000 的顶点编号；相邻编号不相同。

## 输出

q 的各顶点，以空格分隔；q 可以只有一个顶点。

## 样例

### 样例 1

输入：

```
9
1 2 7 3 2
8 4 8 5
```

输出：

```
1 2 8 5
```

## 解法

列表的位置 i 表示“位于顶点 pᵢ，可以使用 p 中从第 i 条起的边”。从这里 q 可以取任何从 pᵢ 出发的更靠后的
边，即 j ≥ i 且 pⱼ = pᵢ 的边 (pⱼ, pⱼ₊₁)，然后从位置 j + 1 继续。在任何地方到达最后一个顶点就结束 q，
因为继续走只会增加边。

所以若 pᵢ 是最后一个顶点则 dp[i] = 0，否则 dp[i] = 1 + min dp[j + 1]（对所有 j ≥ i 且 pⱼ = pᵢ）。从右往
左扫描时，用按顶点编号索引的表保存后缀上的这个最小值，于是每个位置 O(1)；记下所选的 j 就能从位置 0
还原 q。首尾顶点相同时，q 就是这一个顶点。`O(n)`。

在同样短的链中，程序对每个顶点保留最靠后的跳转，使五种实现输出一致；但任何最优链都合法。
检查器验证起终点、边的顺序以及最小长度；最小长度通过从左到右扫描边独立计算。

易错点：

- 闭合的链缩成一个顶点（测试 03）；
- 不同的最优顶点列表都必须接受（测试 gen3）；
- q 只能在结尾经过最后一个顶点，所以第一次到达就停止是对的；
- 跳转的目标是所选边之后的位置 j + 1，而不是 j。

Python 解法与检查器已在 2000 条随机小链和 1155 个穷举用例上通过边子集穷举验证。

## 优化解法

C++ 和 Go 版本使用相同的后缀动态规划，只用一个变量保存下一位置的距离，每个位置仅记录所选的跳转。顶点编号和距离都只需 16 位：若最短路线两次经过同一顶点，可以省去两次访问之间的路段，剩余边仍按输入顺序出现。起点和终点相同时不需要跳转表。时间仍为 O(n)。

已通过评测的基础实现 [1651_dp.java](1651_dp.java), [1651_dp.py](1651_dp.py), [1651_dp.rs](1651_dp.rs) 也满足快速版本的要求：在保存的比较快照中，时间和内存均符合前 15% 或前十名的排名收录规则。直接复用这些源文件，不创建相同副本。星号标记尚未达到该语言目标排名的版本。
