# 1621. 定积分

[Timus 1621](https://acm.timus.ru/problem.aspx?space=1&num=1621) · 难度 4203 · math

原题出自 2008 年冬季彼得罗扎沃茨克集训的 SPbSU ITMO Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

P(x) = a4·x⁴ + a3·x³ + a2·x² + a1·x + a0 的系数是绝对值不超过 10⁶ 的整数，a4 ≠ 0，
没有实根也没有重根。计算 1 / P(x) 在整条实数轴上的积分，绝对误差或（积分为正时）相对误差不超过 10⁻⁹。

时间限制：1 秒。内存限制：64 MB。

## 输入

a0、a1、a2、a3 和 a4。

## 输出

积分的值。

## 样例

### 样例 1

输入：

```
16 0 0 0 1
```

输出：

```
0.2776801836
```

## 解法

代换 x = sinh t，dx = cosh t dt 把无穷直线变为 t ∈ (−∞, ∞)，被积函数按 exp(−3|t|) 衰减；
在 |t| = 20（x ≈ 2.4·10⁸）处截断，损失小于 10⁻²⁰。其余是自适应三点高斯—勒让德求积：
当两半之和与整体之差超过 10⁻¹³ · (1 + |值|) 时就把区间对分，最多 50 层，这样实轴附近的
根造成的尖峰得到细小的区间，平坦部分保持粗大。S 个区间时为 `O(S)`。

复分析提供了交叉验证：积分等于 2πi 乘以上半平面各根 z 处 1 / P′(z) 之和。用数值方法求出的
根在这里的所有测试上给出相同的值。

易错点：

- 首项系数为负时 P 处处为负，积分也为负（测试 03）；
- 像 999 ± i 这样的根会在远离原点处产生窄峰（测试 04）；
- 10⁶ x⁴ + 1 与 x⁴ + 10⁶ 的质量分布在完全不同的尺度上（测试 05、06）。
