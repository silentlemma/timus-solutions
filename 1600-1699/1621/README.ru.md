# 1621. Определённый интеграл

[Timus 1621](https://acm.timus.ru/problem.aspx?space=1&num=1621) · сложность 4203 · math

Оригинальная задача — SPbSU ITMO Contest, Петрозаводские сборы, зима 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У P(x) = a4·x⁴ + a3·x³ + a2·x² + a1·x + a0 целые коэффициенты по модулю
не больше 10⁶, a4 ≠ 0, нет вещественных корней и нет кратных корней.
Вычислите интеграл от 1 / P(x) по всей вещественной прямой с абсолютной
или, для положительного интеграла, относительной погрешностью не больше 10⁻⁹.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

a0, a1, a2, a3 и a4.

## Выходные данные

Значение интеграла.

## Примеры

### Пример 1

Ввод:

```
16 0 0 0 1
```

Вывод:

```
0.2776801836
```

## Решение

Замена x = sinh t, dx = cosh t dt переводит бесконечную прямую в
t ∈ (−∞, ∞) с подынтегральной функцией, убывающей как exp(−3|t|); обрезка на
|t| = 20 (x ≈ 2,4·10⁸) теряет меньше 10⁻²⁰. Остальное — адаптивная
трёхточечная квадратура Гаусса — Лежандра: отрезок делится пополам,
пока две половины вместе отличаются от целого больше чем на
10⁻¹³ · (1 + |значение|), до 50 уровней вглубь, так что острые пики от
корней у вещественной оси получают мелкие отрезки, а плоские участки
остаются крупными. `O(S)` для S отрезков.

Проверка даёт комплексный анализ: интеграл равен 2πi, умноженному на
сумму 1 / P′(z) по корням z в верхней полуплоскости. Найденные численно
корни дают те же значения на всех наших тестах.

Подводные камни:

- отрицательный старший коэффициент делает P отрицательным везде, а
  интеграл — отрицательным (тест 03);
- корни вроде 999 ± i дают узкий пик далеко от начала координат
  (тест 04);
- 10⁶ x⁴ + 1 и x⁴ + 10⁶ сосредотачивают массу в совсем разных масштабах
  (тесты 05, 06).
