# 1679. 史高治的塔

[Timus 1679](https://acm.timus.ru/problem.aspx?space=1&num=1679) · 难度 998 · geometry

原题为民间流传的题目，出自 2008 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个半径为 R、圆心在原点的圆形岛屿。判断是否存在内接于该圆的正方形，使两个给定点都在它的边界上。

## 输入

T（1 ≤ T ≤ 1000），接着 T 行整数 R、x1、y1、x2、y2（1 ≤ R ≤ 10000）；两点都在圆内。

## 输出

每行输出 YES 或 NO。

## 样例

### 样例 1

输入：

```
3
2 1 1 1 -1
2 1 1 0 0
1 1 0 -1 0
```

输出：

```
YES
NO
YES
```

## 解法

内接正方形的每条边都是到圆心距离为 s = R / √2 的弦，圆从这条直线上截下的恰好就是这条边。
所以圆内一点在某条边上，当且仅当它在这条边所在的直线上。

设 u 为经过第一个点 P 的那条边的单位法向量，即 u · P = s。其余各边的法向量是 −u 和 u 旋转 ±90°，
这些边的方程可化为 u · Q′ = s，其中 Q′ 是第二个点 Q 旋转 0°、180° 或 ±90° 的结果。
因此答案为 YES，当且仅当四种旋转中有一个 Q′ 使 P 与 Q′ 位于同一条到圆心距离为 s 的直线上：

- 若 Q′ = P，经过 P 且到圆心距离为 s 的任意直线都可以，它存在当且仅当 |P| ≥ s，即 2|P|² ≥ R²；
- 否则就是经过 P 和 Q′ 的直线，距离为 |P × Q′| / |P − Q′|，检验 2 (P × Q′)² = R² |P − Q′|²。

全部都是精确的整数判断，数值小于 10¹⁷。`O(T)`。

注意事项：这里用浮点角度很脆弱。恰好距离为 s 的点（边的中点，例如 R = 12 时的 (6, 6)）
会得到对 1 求反余弦，舍入可能使参数越界；测试 02 中有这样的点。

答案与按方向做浮点搜索的结果一致：覆盖 R ≤ 3 时的所有点对，以及 R ≤ 30 的 21000 个随机情形。
