# 1679. Башня дядюшки Скруджа

[Timus 1679](https://acm.timus.ru/problem.aspx?space=1&num=1679) · сложность 998 · geometry

Оригинальная задача — фольклор; Ural SU Contest, Петрозаводские летние сборы, август 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Круглый остров радиуса R с центром в начале координат. Определить,
есть ли квадрат, вписанный в его окружность, на границе которого лежат
обе данные точки.

## Входные данные

T (1 ≤ T ≤ 1000), затем T строк с целыми R, x1, y1, x2, y2
(1 ≤ R ≤ 10000); обе точки лежат в круге.

## Выходные данные

YES или NO для каждой строки.

## Примеры

### Пример 1

Ввод:

```
3
2 1 1 1 -1
2 1 1 0 0
1 1 0 -1 0
```

Вывод:

```
YES
NO
YES
```

## Решение

Каждая сторона вписанного квадрата — хорда на расстоянии s = R / √2 от
центра, и круг вырезает из её прямой ровно эту сторону. Значит, точка
круга лежит на стороне тогда и только тогда, когда лежит на её прямой.

Пусть u — единичная нормаль стороны через первую точку P, то есть
u · P = s. У остальных сторон нормали −u и u, повёрнутая на ±90°, а
их уравнения сводятся к u · Q′ = s, где Q′ — вторая точка
Q, повёрнутая на 0°, 180° или ±90°. Поэтому ответ YES, если для одного
из четырёх поворотов Q′ точки P и Q′ лежат на общей прямой на
расстоянии s от центра:

- если Q′ = P, подходит любая прямая через P на расстоянии s, а она
  существует при |P| ≥ s, то есть 2|P|² ≥ R²;
- иначе это прямая через P и Q′ на расстоянии |P × Q′| / |P − Q′|, и
  проверка — 2 (P × Q′)² = R² |P − Q′|².

Все проверки точные и целочисленные, числа меньше 10¹⁷. `O(T)`.

Подводный камень: углы в плавающей точке здесь ненадёжны. Точка ровно
на расстоянии s, середина стороны (например, R = 12, (6, 6)), даёт
арккосинус от 1, который округление может вывести за допустимый
диапазон; такие точки есть в тесте 02.

Ответы совпадают с перебором ориентаций в плавающей точке для всех пар
точек при R ≤ 3 и на 21000 случайных случаев с R ≤ 30.
