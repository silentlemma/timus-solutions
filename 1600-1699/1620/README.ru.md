# 1620. Умный дом

[Timus 1620](https://acm.timus.ru/problem.aspx?space=1&num=1620) · сложность 1551 · probability, math

Оригинальная задача — SPbSU ITMO Contest, Петрозаводские сборы, зима 2008 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N лампочек (1 ≤ N ≤ 10⁹), из них M включены. K раз (K ≤ 1000) вирус
выбирает равновероятно случайную лампочку и переключает её. Выведите
математическое ожидание числа включённых лампочек в конце в виде
несократимой дроби p/q.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, M и K.

## Выходные данные

Ожидание в виде `p/q`.

## Примеры

### Пример 1

Ввод:

```
1 1 9
```

Вывод:

```
0/1
```

### Пример 2

Ввод:

```
5 4 3
```

Вывод:

```
353/125
```

## Решение

Если в среднем включено E лампочек, переключение гасит одну с
вероятностью E / N и зажигает одну с вероятностью (N − E) / N, поэтому
следующее ожидание равно E · (1 − 2/N) + 1. Его неподвижная точка — N/2,
и расстояние до неё каждый раз умножается на (N − 2)/N:

E_K = N/2 + (M − N/2) · ((N − 2)/N)^K = (N^(K+1) + (2M − N)(N − 2)^K) / (2 N^K).

Числа доходят примерно до 9 000 цифр. Python, Go и Java пользуются своими
длинными целыми. НОД двух таких чисел в Java медленный, а в C++ и Rust
длинных целых нет, поэтому эти решения хранят числитель цифрами по
основанию 10⁹ и сокращают только простые делители 2N — других простых в
знаменателе 2N^K нет, — деля на каждый, пока делится. `O(K²)` операций с
цифрами.

Подводные камни:

- результат может быть 0, он выводится как `0/1` (первый пример);
- при N = 1 число N − 2 отрицательно, а при N = 2 равно нулю
  (тесты 03, 05);
- при K = 0 ответ — M/1 (тест 04);
- Python 3.12 ограничивает печать целых 4 300 цифрами, если не снять
  ограничение.

Ответы совпадают с независимой принятой реализацией на 300 случайных
входах, многие из которых с N — степенью двойки или с множеством малых
простых делителей.
