# 1620. 智能房屋

[Timus 1620](https://acm.timus.ru/problem.aspx?space=1&num=1620) · 难度 1539 · probability, math

原题出自 2008 年冬季彼得罗扎沃茨克集训的 SPbSU ITMO Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 个灯泡（1 ≤ N ≤ 10⁹），其中 M 个亮着。病毒 K 次（K ≤ 1000）均匀随机地选一个灯泡
并切换它的状态。以最简分数 p/q 输出最后亮着的灯泡数的数学期望。

时间限制：2 秒。内存限制：64 MB。

## 输入

N、M 和 K。

## 输出

期望，格式为 `p/q`。

## 样例

### 样例 1

输入：

```
1 1 9
```

输出：

```
0/1
```

### 样例 2

输入：

```
5 4 3
```

输出：

```
353/125
```

## 解法

若期望有 E 个灯亮着，一次切换以 E / N 的概率关掉一个、以 (N − E) / N 的概率打开一个，
所以下一个期望是 E · (1 − 2/N) + 1。它的不动点是 N/2，带符号的差 E − N/2 每次乘以
(N − 2)/N：

E_K = N/2 + (M − N/2) · ((N − 2)/N)^K = (N^(K+1) + (2M − N)(N − 2)^K) / (2 N^K)。

数字最多约 9 000 位。Python、Go 和 Java 使用自带的大整数，C++ 和 Rust 使用 10⁹ 进制数位。
Java 中两个这样的数求最大公约数很慢，所以 Java、C++ 和 Rust 只约去 2N 的素因子
（分母 2N^K 没有其他素因子），约去次数不超过各自在分母中的指数。

易错点：

- 结果可能为 0，输出为 `0/1`（第一个样例）；
- N = 1 时 N − 2 为负（测试 05），N = 2 时为零（测试 03）；
- K = 0 时答案为 M/1（测试 04）；
- Python 3.12 默认只能打印 4 300 位以内的整数，需要解除限制。

在 300 个随机输入（很多 N 是 2 的幂或含很多小素因子）上，答案与一个独立的已通过实现一致。
