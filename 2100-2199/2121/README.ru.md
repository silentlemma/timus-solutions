# 2121. Площадь между двумя зеркальными параболами

[Timus 2121](https://acm.timus.ru/problem.aspx?space=1&num=2121) · сложность 724 · geometry, math

Автор оригинальной задачи — Алексей Данилюк; Петрозаводск лето 2018. t.me/umnik_team Contest.

## Задача

Найдите площадь области, ограниченной параболами y = (x − a)² и
x = (y − a)², и выведите её ровно с 10 знаками после запятой.
Ограничения: 1 секунда и 64 МБ.

## Входные данные

Целое a, 1 ≤ a ≤ 10¹⁸.

## Выходные данные

Площадь.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
7.6666666667
```

## Решение

Перенесём начало координат в (a, a): при x = a + p и y = a + q область
задаётся неравенствами q ≥ p² − a и p ≥ q² − a. Параболы пересекаются в
четырёх точках. Две лежат на q = p, где p² = p + a, то есть
p = (1 ± s)/2 при s = √(4a + 1). Вычитание уравнений даёт
(p − q)(p + q + 1) = 0, так что две другие лежат на p + q = −1 в точках
p = (−1 ± t)/2 при t = √(4a − 3).

Интегрируем по p: верх области — q = √(p + a), а низ — q = p² − a у
обоих краёв и q = −√(p + a) в середине. В каждом углу √(p + a) равно
|q|, поэтому каждая первообразная превращается в многочлен от координат
углов. Затем суммы и произведения двух корней каждой пары уничтожают s и
t: площадь равна ровно 4a − 1/3.

Значит, ответ — 4a − 1, за которым идёт «.6666666667». При a = 10¹⁸
целая часть чуть меньше 4 · 10¹⁸ и помещается в 64-битное целое, а
вещественные числа потеряли бы последние цифры.

В примере 4 · 2 − 1/3 = 7.6666666667.
