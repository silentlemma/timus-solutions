# 2159. Кратчайшее и наименьшее сочинение по правилам порядка слов

[Timus 2159](https://acm.timus.ru/problem.aspx?space=1&num=2159) · сложность 1407 · graphs, greedy

Автор оригинальной задачи — Валентин Зуев; Уральская командная олимпиада по программированию 2021.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Сочинение — последовательность слов через одиночные пробелы. В нём
должны быть n ключевых слов, а каждое из k правил (a, b) требует, чтобы
везде, где встречается a, где-то позже встретилось b. Выведите
кратчайшее сочинение, удовлетворяющее всему, а среди кратчайших —
лексикографически наименьшее, где пробел меньше любой буквы; выведите
−1, если такого нет. Ограничения: 2 секунды и 256 МБ.

## Входные данные

n и k, 1 ≤ n, k ≤ 10⁵, n различных ключевых слов, затем k различных
правил; общая длина всех слов не больше 2 · 10⁶.

## Выходные данные

Сочинение или −1.

## Примеры

### Пример 1

Ввод:

```
2 3
atan
tan
atan ate
atan tabular
zzz atan
```

Вывод:

```
atan ate tabular tan
```

### Пример 2

Ввод:

```
1 3
a
a b
b c
c a
```

Вывод:

```
-1
```

## Решение

Обязательные слова — ключевые и всё, что достижимо от них по правилам;
их находит один обход. Если сочинение возможно, достаточно написать
каждое из них один раз, так что у кратчайшего сочинения фиксированный
набор слов и фиксированная длина. Слово должно стоять раньше всех слов,
на которые указывают его правила среди обязательных; повтор слова не
помогает, ведь правила его последней копии всё равно нужно выполнить
позже. Поэтому сочинение существует ровно тогда, когда эти слова не
образуют цикла, и тогда это их топологический порядок.

Все такие порядки одной длины, так что наименьший строится жадно:
алгоритм Кана с очередью с приоритетом всегда пишет наименьшее
свободное слово. Сравнивать слова напрямую правильно, потому что слово
с пробелом после него меньше любого более длинного слова, начинающегося
с него, — пробел самый маленький символ. Работа — O(L log n) для общей
длины L.

В первом примере «zzz» писать не обязательно, а обязательные слова atan,
ate, tabular и tan после записи atan идут в алфавитном порядке.
