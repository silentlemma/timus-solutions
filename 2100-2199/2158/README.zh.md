# 2158. 把多重集拆成一个等差数列和一个等比数列

[Timus 2158](https://acm.timus.ru/problem.aspx?space=1&num=2158) · 难度 1856 · math, greedy

原题作者 Valentin Zuev，出自 2021 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把 N 个非负整数拆成一个非空等差数列和一个公比非零的非空等比数列，每个数恰好用一次，输出这两个数列，或者输出 −1。任何合法的拆分都可接受。时间限制 2 秒，内存限制 256 MB。

## 输入

N（2 ≤ N ≤ 50 000），然后是这些数（0 ≤ aᵢ ≤ 10⁹）。

## 输出

−1，或者等差数列的长度、按顺序的各项，以及按顺序的等比数列各项。

## 评测方式

检查器核对多重集和两个数列，并把 −1 与存储的答案比较。

## 样例

### 样例 1

输入：

```
6
0 2 3 4 6 8
```

输出：

```
3
0 3 6
2 4 8
```

### 样例 2

输入：

```
6
4 4 6 6 8 9
```

输出：

```
3
4 6 8
4 6 9
```

### 样例 3

输入：

```
4
0 0 0 0
```

输出：

```
1
0
0 0 0
```

### 样例 4

输入：

```
5
0 0 1 1 2
```

输出：

```
-1
```

## 解法

先排序。关键的界：公比 q ≠ 1 的等比数列至多约 30 项，因为各项都是不超过 10⁹ 的整数，而既约形式的公比 p / r 要求首项是 r^(t−1) 的倍数，所以各项至少按 2^(t−1) 增长。0 只能放进全零的数列。公比为 1 或公差为 0 的数列由相等的数组成，这些情况先处理：

- 只有一种或两种不同的值：各值分开；
- 恰好一个值重复：它的副本组成常数数列，可能把一个副本留给另一个数列，然后检查其余部分；
- 至多 31 个数：依次尝试每个单独的数作为其中一个数列。

否则在关键之处所有数都互不相同，等比部分至多 30 项，其余都在等差部分。N 较大时，等差数列的公差就是相邻差的中位数，首项在前 31 个数中；N 较小时，在前 32 个数中枚举等差数列的前两项。对给定的首项和公差，一次贪心扫描把每个等于下一个等差项的数取走，其余的给等比部分，一旦等比部分超过 30 个数就放弃。等差部分的最后一两项也可能属于等比部分，所以这几种变体也要检查。所有检查都是精确的整数比较。

第二个样例中 4, 6, 8 的公差为 2，4, 6, 9 的公比为 3 / 2。
