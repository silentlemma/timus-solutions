# 2158. Разбиение мультимножества на арифметическую и геометрическую прогрессии

[Timus 2158](https://acm.timus.ru/problem.aspx?space=1&num=2158) · сложность 1856 · math, greedy

Автор оригинальной задачи — Валентин Зуев; Уральская командная олимпиада по программированию 2021.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Разбейте N неотрицательных целых чисел на непустую арифметическую
прогрессию и непустую геометрическую прогрессию с ненулевым
знаменателем, используя каждое число один раз, и выведите обе, или −1.
Подходит любое правильное разбиение. Ограничения: 2 секунды и 256 МБ.

## Входные данные

N, 2 ≤ N ≤ 50 000, затем числа, 0 ≤ aᵢ ≤ 10⁹.

## Выходные данные

−1 или длина арифметической прогрессии, её члены по порядку и члены
геометрической прогрессии по порядку.

## Проверка

Проверяющая программа сверяет мультимножество и обе прогрессии, а −1
сравнивает с сохранённым ответом.

## Примеры

### Пример 1

Ввод:

```
6
0 2 3 4 6 8
```

Вывод:

```
3
0 3 6
2 4 8
```

### Пример 2

Ввод:

```
6
4 4 6 6 8 9
```

Вывод:

```
3
4 6 8
4 6 9
```

### Пример 3

Ввод:

```
4
0 0 0 0
```

Вывод:

```
1
0
0 0 0
```

### Пример 4

Ввод:

```
5
0 0 1 1 2
```

Вывод:

```
-1
```

## Решение

Отсортируем числа. Главная оценка: геометрическая прогрессия со
знаменателем q ≠ 1 имеет не больше примерно 30 членов, потому что её
члены — целые до 10⁹, а знаменатель p / r в несократимом виде требует,
чтобы первый член делился на r^(t−1), так что члены растут не медленнее
2^(t−1). Нули подходят только в прогрессию из нулей. Прогрессии со
знаменателем 1 или шагом 0 состоят из равных чисел, и эти случаи
разбираются сначала:

- одно различное значение или два: каждое значение отдельно;
- ровно одно значение повторяется: его копии образуют постоянную
  прогрессию, возможно отдав одну копию другой, а остаток проверяется;
- не больше 31 числа: каждое число по отдельности пробуется как одна
  из прогрессий.

Иначе там, где это важно, все числа различны, в геометрической части не
больше 30 членов, а арифметическая содержит остальные. При большом N шаг
арифметической прогрессии — медиана разностей соседей, а её первый член
среди первых 31 чисел; при меньшем N первые два члена перебираются среди
первых 32 чисел. Для начала и шага один жадный проход берёт каждое
число, равное следующему члену арифметической прогрессии, а остальные
отдаёт геометрической части, прекращая, как только в ней больше 30
чисел. Последние один или два члена арифметической части могут
принадлежать геометрической, так что эти несколько вариантов тоже
проверяются. Все проверки — точные сравнения целых.

Во втором примере у 4, 6, 8 шаг 2, а у 4, 6, 9 знаменатель 3 / 2.
