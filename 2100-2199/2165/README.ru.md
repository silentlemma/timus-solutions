# 2165. Триангуляция выпуклого многоугольника с наибольшим наименьшим треугольником

## Задача

Разрежьте выпуклый многоугольник с N вершинами на треугольники
непересекающимися диагоналями так, чтобы наименьший треугольник был как
можно больше, и выведите его площадь с абсолютной или относительной
погрешностью не более 10⁻⁹.
Ограничения: 1 секунда и 256 МБ.

## Входные данные

N, 3 ≤ N ≤ 200, затем вершины против часовой стрелки, координаты по
модулю до 10⁸.

## Выходные данные

Наибольшая возможная площадь наименьшего треугольника.

## Примеры

### Пример 1

Ввод:

```
4
0 0
5 -1
8 3
0 4
```

Вывод:

```
11.5
```

## Решение

Это классическая динамика по отрезкам для триангуляций. Пусть f(i, j) —
лучший наименьший треугольник в триангуляции подмногоугольника с
вершинами i … j. Его сторона (i, j) входит ровно в один треугольник
(i, k, j) при i < k < j, который делит его на части i … k и k … j, так что

f(i, j) = max по k от min(f(i, k), f(k, j), площадь(i, k, j)),

а f(i, i + 1) = +∞ для одной стороны: ребро не должно ограничивать
минимум. C++ и Python используют удвоенную площадь многоугольника,
а Go, Java и Rust — безопасную верхнюю границу 8 · 10¹⁶. Нулевое значение
обнулит все оценки даже в тесте 02. Ответ — f(0, N − 1).
Площади хранятся удвоенными как точные целые из векторных
произведений до примерно 4 · 10¹⁶, так что итоговое полуцелое печатается
точно. Кандидаты, которые не могут превзойти текущий лучший, отсекаются
сразу. Работа — O(N³).

В примере две триангуляции четырёхугольника дают наименьшие куски 11.5
и 10, так что ответ — 11.5.
