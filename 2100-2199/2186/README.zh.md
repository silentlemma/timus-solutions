# 2186. 让足够多射线指向圆的最小旋转角

[Timus 2186](https://acm.timus.ru/problem.aspx?space=1&num=2186) · 难度 1765 · geometry, sorting

原题作者 Artyom Kutuzov，出自 2024 年乌拉尔团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

从原点沿互不相同的方向 (xᵢ, yᵢ) 射出 n 条射线，一个半径为 r、圆心为 (a, b) 的圆位于原点之外。所有射线一起逆时针旋转角 α，然后开 k 枪，每枪独立且等概率地选一条射线；若射线与圆相交（含边界）则命中。对 q 个概率 pᵢ 中的每一个，求使命中概率至少为 pᵢ 的 [0, 360) 中最小的 α，否则输出 −1。误差不超过 10⁻³ 即可。时间限制 2 秒，内存限制 256 MB。

## 输入

n、k 和 q（1 ≤ n ≤ 10⁵，1 ≤ k ≤ 10，1 ≤ q ≤ 10⁵），然后是 n 个坐标不超过 10⁹ 的方向，然后是 a、b 和 r，最后是至多五位小数的 pᵢ。

## 输出

每个查询的角度（度），或 −1。

## 样例

### 样例 1

输入：

```
6 2 5
5 -5
3 0
-3 -2
-3 -1
-3 0
-4 -1
4 2 2
0.3 0.5 0.75 0.8 0.9
```

输出：

```
0.0000000000
45.0000000000
165.9637565321
180.0000000000
-1
```

## 解法

若有 c 条射线与圆相交，命中概率为 1 − ((n − c) / n)ᵏ，随 c 递增，所以每个查询问的是使命中射线数至少为某个 c 的最小旋转。

从原点看，圆是从下切线到上切线的一段方向弧，宽度为 2 · asin(r / √(a² + b²))。随着 α 增大，射线从下切线进入这段弧。因此命中数只在 α = 0 或某条射线到达下切线时增加，此时命中的射线就是方向位于它之后弧宽范围内的射线。把射线按角度排序，在加倍的列表上用双指针窗口求出每条射线对应的数目，再对每个数目取最小的 α，并用后缀最小值使其单调，就回答了所有数目。

恰好在切线上的方向决定射线是否命中，所以只要浮点数接近相等，就用整数重新检验：窗口边界通过点积和叉积比较两条射线的夹角与弧宽；接近 α = 0 的入弧角设为零，除非射线严格在弧内，此时入弧角设为略小于一整圈。

概率有五位小数，所以每个数目 c 对应一个等级 ⌊10⁵ · (1 − ((n − c) / n)ᵏ)⌋，用浮点数计算，在接近网格点时用整数确认；C++、Go 和 Python 对查询 p 二分查找第一个不小于 10⁵ p 的等级；Java 和 Rust 预先计算所有网格值的答案。

样例中 k = 2，n = 6。射线 (3, 0) 在 α = 0 时与圆相切，已经给出 1 − (5/6)² ≥ 0.3；而 0.9 需要六条射线中的五条，弧永远无法同时容纳它们。

排序和窗口需要 O(n log n)，查询需要 O(q log n)；Java 和 Rust 用 O(n + 10⁵) 预处理表后，查询需要 O(q)。
