# 2102. Ровно двадцать простых множителей

[Timus 2102](https://acm.timus.ru/problem.aspx?space=1&num=2102) · сложность 147 · number_theory

Автор оригинальной задачи — Владимир Лесков; Чемпионат УрФУ среди юниоров 2016.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Определите, равна ли сумма показателей в разложении n на простые
ровно 20, то есть является ли n произведением ровно 20 простых с учётом
кратности. Ограничения: 2 секунды и 64 МБ.

## Входные данные

n, 1 ≤ n ≤ 10¹⁸.

## Выходные данные

`Yes` или `No`.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
No
```

### Пример 2

Ввод:

```
1048576
```

Вывод:

```
Yes
```

### Пример 3

Ввод:

```
10000000000
```

Вывод:

```
Yes
```

## Решение

Делим n на каждое d от 2 до B = 2·10⁶, пока d² ≤ n, и считаем
отделённые простые множители. Если цикл остановился, потому что d²
превзошло остаток, то остаток — 1 или простое и добавляет 0 или 1. Иначе
остаток не меньше B² = 4·10¹², так что отделённая часть не больше
10¹⁸ / B², меньше 2¹⁸, то есть множителей пока меньше 18; у остатка нет
делителей меньше B и он не больше 10¹⁸ < B³, поэтому добавляет не больше
двух. Сумма не может достичь 20, и ответ No. Работа — не больше 2·10⁶
делений.

В третьем примере 10¹⁰ = 2¹⁰ · 5¹⁰ имеет 20 простых множителей.
