# 2148. Рикошет от круглой цистерны между двумя равноудалёнными игроками

[Timus 2148](https://acm.timus.ru/problem.aspx?space=1&num=2148) · сложность 500 · geometry

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Круглая цистерна имеет центр C и радиус r. Два игрока A и B стоят вне
её на одинаковом расстоянии от C. Найдите точку на границе цистерны, от
которой выстрел из A отражается в B, с углом падения, равным углу
отражения, и без участков пути внутри цистерны; выстрел по касательной
не считается. Выведите «No way», если такой точки нет. Ограничения:
0.5 секунды и 256 МБ.

## Входные данные

Центр и радиус, затем A, затем B, все целые, по модулю не больше 3000.

## Выходные данные

Точка или «No way».

## Проверка

Проверяющая программа сверяет расстояние до центра и два угла с
точностью 10⁻⁶ и убеждается, что оба участка пути проходят вне цистерны.

## Примеры

### Пример 1

Ввод:

```
4 7 3
0 0
8 0
```

Вывод:

```
4.000000 4.000000
```

### Пример 2

Ввод:

```
0 0 2
-5 0
-3 4
```

Вывод:

```
-1.788854 0.894427
```

## Решение

Поскольку |A − C| = |B − C|, картина симметрична относительно
биссектрисы угла ACB, и точка на этой биссектрисе, P = C + r · w / |w|,
где w = A + B − 2C, отражает A в B: нормаль в P и есть биссектриса. Путь
A → P проходит вне цистерны ровно тогда, когда A строго дальше
касательной в P, то есть (A − C) · w > r · |w|; по симметрии то же
верно и для B. При равенстве выстрел идёт по касательной, а w = 0
означает, что A и B стоят друг напротив друга, и тогда левая часть
равна 0.

Если условие не выполнено, другой точки тоже нет: точки границы, видимые
из A, образуют дугу вокруг направления на A, видимые из B — дугу вокруг
направления на B, и когда точка на биссектрисе не лежит строго внутри
обеих дуг, они вообще не пересекаются.

Проверка идёт только в целых числах, обе части возводятся в квадрат,
когда левая положительна; значения намного меньше 64 бит. Координаты P
выводятся с девятью знаками после запятой.

В первом примере w = (0, −14) направлен прямо вниз от C = (4, 7), так
что P = (4, 4).
