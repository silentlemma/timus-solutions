# 2148. 在两名等距玩家之间借圆形罐体反弹射击

[Timus 2148](https://acm.timus.ru/problem.aspx?space=1&num=2148) · 难度 491 · geometry

原题作者 Kirill Meshcheryakov，出自 2019 年乌拉尔团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

圆形罐体的中心为 C，半径为 r。两名玩家 A 和 B 站在罐体外，到 C 的距离相同。求罐体边界上的一点，使从 A 射出的子弹在该点反弹后到达 B，入射角等于反射角，且路径的任何部分都不在罐体内部；沿切线擦过的射击不算。若不存在则输出 "No way"。时间限制 0.5 秒，内存限制 256 MB。

## 输入

中心和半径，然后是 A，再然后是 B，都是绝对值不超过 3000 的整数。

## 输出

该点，或者 "No way"。

## 评测方式

检查器以 10⁻⁶ 的精度核对到中心的距离和两个角，并验证两段路径都在罐体之外。

## 样例

### 样例 1

输入：

```
4 7 3
0 0
8 0
```

输出：

```
4.000000 4.000000
```

### 样例 2

输入：

```
0 0 2
-5 0
-3 4
```

输出：

```
-1.788854 0.894427
```

## 解法

由于 |A − C| = |B − C|，图形关于角 ACB 的平分线对称，平分线上的点 P = C + r · w / |w|（其中 w = A + B − 2C）能把 A 反射到 B：P 处的法线就是这条平分线。路径 A → P 在罐体之外且不沿切线擦过，当且仅当 A 严格位于 P 处切线的外侧，即 (A − C) · w > r · |w|；由对称性，此时 B 也满足。取等号时子弹沿切线擦过，而 w = 0 表示 A 和 B 正好相对，此时左边为 0。

若条件不成立，也不存在其他点：从 A 可见的边界点构成以 A 的方向为中心的一段弧，从 B 可见的构成以 B 的方向为中心的一段弧，当平分线上的点不严格位于两段弧内时，两段弧的内部不相交。

判断只用整数，在左边为正时把两边平方；数值远小于 64 位。P 的坐标保留九位小数输出。

第一个样例中 w = (0, −14) 从 C = (4, 7) 笔直向下，所以 P = (4, 4)。
