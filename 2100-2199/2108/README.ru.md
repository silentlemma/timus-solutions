# 2108. Замыкание набора фигурок по правилам желаний

## Задача

Есть n коллекционных фигурок. Каждое из m желаний гласит: как только
есть все фигурки набора A, хочется и все фигурки набора B. Начиная с уже
имеющихся фигурок, найдите наименьший набор, удовлетворяющий всем
желаниям, то есть набор, получаемый исполнением желаний, пока не
захочется ничего нового. Ограничения: 0.9 секунды и 64 МБ.

## Входные данные

n и m, 1 ≤ n ≤ 1000, 0 ≤ m ≤ 4000, затем m строк с наборами A и B в
виде строк из n нулей и единиц, и имеющийся набор в том же формате.

## Выходные данные

Итоговый набор в том же формате.

## Примеры

### Пример 1

Ввод:

```
6 4
111000 101000
110000 111000
010000 100000
000010 000001
010100
```

Вывод:

```
111100
```

## Решение

Набор, удовлетворяющий всем желаниям и содержащий имеющиеся фигурки,
обязан содержать каждую фигурку, к которой ведёт какая-то цепочка
желаний, а набор ровно из этих фигурок удовлетворяет всем желаниям.
Поэтому повторяются проходы по желаниям: желание, у которого A лежит
внутри имеющегося набора, добавляет B. Проход, который ничего не
добавил, завершает процесс, а любой другой добавляет хотя бы одну
фигурку, так что проходов не больше n + 1.

Наборы — битсеты из 64-битных слов: «A внутри имеющегося набора» — это
A AND NOT owned = 0, а добавление B — OR, обе операции по n / 64 слов.
Вся работа — O(n · m · n / 64), около 6 · 10⁷ операций над словами.

В примере имеющиеся фигурки 2 и 4 включают третье желание, которое
добавляет 1; затем второе желание добавляет 3, и результат — 111100.

## Особенности языков

Решение на Python транспонирует задачу, потому что проходы там слишком
медленны, когда цепочка желаний перечислена в обратном порядке. Для
каждой фигурки строится множество желаний, которым она нужна, в виде
одного большого целого (столбец матрицы строк A). Дерево отрезков по
фигуркам хранит объединение этих множеств по ещё отсутствующим
фигуркам — ровно множество ещё не включённых желаний. Каждый раунд
исполняет все новые включённые желания и обнуляет листья только что
полученных фигурок. Каждое желание исполняется не более одного раза,
а лист каждой фигурки обнуляется не более одного раза.

Пусть w — число бит в разряде большого целого Python, N = ceil(n / w),
M = ceil(m / w), L = 1 + ceil(log2 n). При m > 0 время составляет
O(nm + (nL + m)M + nN): чтение и транспонирование требуют O(nm),
обновления дерева и проверки готовности — O(nLM), перебор включённых
желаний — O(mM), перебор новых фигурок — O(nN). Объединение результатов
требует O(mN), что уже покрывается O(nm). При m = 0 время — O(n).

Ловушка (тест 15, пустые результаты): желание, которое ничего не
добавляет, всё равно надо обработать. Перебор установленных битов в Python
не занимает константное время на бит: `mask & -mask` и `mask ^= low`
просматривают разряды целого. При n = 1 и m = 4000 желаниях A = B = 0
ответ остаётся 0, но перебор включённых желаний требует Θ(m² / w)
операций над разрядами. Поэтому оценка O(n^2 m / 64) для повторных
проходов не описывает решение на Python.
