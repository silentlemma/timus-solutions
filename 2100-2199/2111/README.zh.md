# 2111. 与顺序无关的运费

[Timus 2111](https://acm.timus.ru/problem.aspx?space=1&num=2111) · 难度 74 · math

原题作者 Anna Khanova，出自 2019 年大学学术信息学奥林匹克。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 个城市由长为 dᵢ 的道路与首都相连，城市 i 需要 dᵢ 吨货物。卡车在首都只装一次货，
按任意顺序沿道路访问各城市；把 m 吨货运 l 公里的费用为 m · l。求最小总费用。时间
限制 1 秒，内存限制 256 MB。

## 输入

1 ≤ n ≤ 10⁵，然后是 d₁ … dₙ，其中 1 ≤ dᵢ ≤ 10⁴。

## 输出

最小费用。

## 样例

### 样例 1

输入：

```
3
1 2 3
```

输出：

```
36
```

## 解法

每次访问都是从首都到某城市再返回。去程载重为 L 时，这次访问去程花费 L·d，返程花
费 (L − d)·d，共 (2L − d)·d。这里 L 等于 d 加上尚未访问城市的需求。对所有访问求
和，每个城市贡献两次 d² 减去一次，每对城市无论谁先都贡献 2·dᵢ·dⱼ。所以任何顺序的
花费都是 (Σ dᵢ)²，可达 10¹⁸，需要 64 位整数。

样例中 (1 + 2 + 3)² = 36。

## 优化解法

优化的 C++ 解法用 `fread` 按 8 KB 分块读入并手工解析数字，而不是每个数调用一次
`scanf`：0.015 s，而不是 0.078 s；104 KB，而不是 140 KB。公式不变。

优化的 Python 解法按 16 KB 分块读入并按需解析，因此不会构造所有距离的列表：
916 KB，而不是 7368 KB，时间不变。优化的 Rust 解法从加锁的标准输入手工解析数字，
而不是把整个输入读成字符串：216 KB，而不是 2140 KB，时间不变。
