# 2111. Стоимость доставки, не зависящая от порядка

[Timus 2111](https://acm.timus.ru/problem.aspx?space=1&num=2111) · сложность 74 · math

Автор оригинальной задачи — Анна Ханова; Вузовско-академическая олимпиада по информатике 2019.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n городов соединены со столицей дорогами длины dᵢ, и городу i нужно dᵢ
тонн груза. Грузовик, загруженный один раз в столице, объезжает города
в любом порядке, всегда по дорогам; перевозка m тонн на l километров
стоит m · l. Найдите наименьшую общую стоимость. Ограничения: 1 секунда
и 256 МБ.

## Входные данные

1 ≤ n ≤ 10⁵, затем d₁ … dₙ, где 1 ≤ dᵢ ≤ 10⁴.

## Выходные данные

Наименьшая стоимость.

## Примеры

### Пример 1

Ввод:

```
3
1 2 3
```

Вывод:

```
36
```

## Решение

Каждая поездка идёт из столицы в город и обратно. С грузом L по пути
туда поездка стоит L·d и затем (L − d)·d по пути обратно, то есть
(2L − d)·d. Здесь L — это d плюс потребности ещё не объеханных городов.
В сумме по поездкам каждый город даёт d² дважды минус один раз, а каждая
пара городов — 2·dᵢ·dⱼ, какой бы из них ни был раньше. Значит, любой
порядок стоит (Σ dᵢ)², а это до 10¹⁸ и требует 64-битных целых.

В примере (1 + 2 + 3)² = 36.

## Оптимизированные решения

Оптимизированное решение на C++ разбирает числа вручную из блоков по
8 КБ, прочитанных `fread`, вместо вызова `scanf` для каждого: 0.015 с
вместо 0.078 с и 104 КБ вместо 140 КБ. Формула та же.

Оптимизированное решение на Python читает ввод блоками по 16 КБ и
разбирает его по мере надобности, поэтому список всех расстояний не
строится: 916 КБ вместо 7368 КБ при том же времени. Оптимизированное
решение на Rust разбирает числа вручную прямо из `stdin().lock()` вместо
чтения всего ввода в строку: 216 КБ вместо 2140 КБ при том же времени.
