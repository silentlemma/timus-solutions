# 2166. Самое дальнее в метрике L1 пересечение прямых от начала координат

## Задача

N попарно непараллельных прямых заданы двумя целыми точками каждая, и
каждое пересечение двух прямых — станция. Добраться до станции (x, y) от
начала координат вдоль осей стоит |x| + |y|. Выведите наибольшую такую
стоимость по всем станциям с относительной погрешностью 10⁻⁴.
Ограничения: 3 секунды и 256 МБ.

## Входные данные

N, 2 ≤ N ≤ 10⁵, затем прямые как x₁ y₁ x₂ y₂ с координатами по модулю до
1000.

## Выходные данные

Наибольшее |x| + |y| по всем пересечениям.

## Примеры

### Пример 1

Ввод:

```
3
0 0 1 1
1 0 1 1
1 3 2 1
```

Вывод:

```
4
```

## Решение

Стоимость |x| + |y| — наибольшая из четырёх линейных функций ±x ± y,
так что ответ — наибольшее значение линейной функции по всем
пересечениям расположения прямых, взятое по четырём направлениям.
Классический факт о расположениях прямых: пересечение, крайнее в любом
направлении, образуют две прямые, соседние в циклическом порядке
наклонов. Поэтому прямые сортируются по направлению точным сравнением
через векторное произведение, и проверяются N пересечений циклических
соседей.

Если прямая записана как dy · x − dx · y = c, пересечение двух прямых —
дробь со знаменателем |dx₁ dy₂ − dy₁ dx₂|, и её норма L1 равна
(|dx₁ c₂ − c₁ dx₂| + |dy₁ c₂ − c₁ dy₂|), делённому на этот знаменатель.
Лучшая дробь хранится точно с перекрёстным умножением целых и
печатается точным округлением. Работа — O(N log N).

В примере прямые y = x и x = 1 пересекаются в (1, 1), прямая через (1, 3)
и (2, 1) пересекает y = x в (5/3, 5/3), а x = 1 — в (1, 3), самой дальней,
со стоимостью 4.
