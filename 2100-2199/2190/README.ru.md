# 2190. Наименьшее число перекладываний валунов до нужной пропорции

## Задача

Есть N куч по sᵢ валунов. За минуту можно добавить или убрать один
валун. Найдите наименьшее время, после которого кучи соотносятся как
p₁ : … : p_N и не все пусты. Ограничения: 2 секунды и 256 МБ.

## Входные данные

N, 2 ≤ N ≤ 10⁵, затем s₁ … s_N и p₁ … p_N, все от 1 до 10⁹.

## Выходные данные

Наименьшее число минут.

## Примеры

### Пример 1

Ввод:

```
2
21 34
2 3
```

Вывод:

```
2
```

## Решение

Поделим все pᵢ на их наибольший общий делитель и получим qᵢ. Непустой
набор куч в этой пропорции — это ровно k · qᵢ для целого k ≥ 1, так что
ответ — минимум по k от

cost(k) = Σ |sᵢ − k qᵢ| = Σ qᵢ · |sᵢ / qᵢ − k|.

Это взвешенная сумма расстояний от k до точек sᵢ / qᵢ с весами qᵢ,
выпуклая функция, минимум которой на вещественных числах достигается во
взвешенной медиане: сортируем отношения, сравнивая a / b и c / d как
a · d и c · b в 64 битах, и берём первое отношение, на котором
накопленный вес достигает половины суммы. Лучшее целое — пол этого
отношения или на единицу больше, причём пол пропускается, если он равен
нулю. Оба кандидата
отстоят от вещественного минимума не больше чем на 1, поэтому каждая
стоимость не превосходит cost(1) + Σqᵢ ≤ 2 · 10¹⁴ и помещается в 64 бита.

В примере отношения равны 10.5 и 11.33, у второго вес 3 из 5, оно и есть
медиана, и k = 11 даёт 22 и 33 за 1 + 1.

Сортировка даёт O(N log N).
