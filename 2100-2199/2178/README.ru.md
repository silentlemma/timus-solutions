## Задача

Посчитайте отрезки массива из N чисел, значения которых различны и
образуют набор последовательных целых в каком-то порядке. Ограничения:
1 секунда и 512 МБ.

## Входные данные

N, 1 ≤ N ≤ 10⁵, затем a₁ … aₙ, 1 ≤ aᵢ ≤ 10⁵.

## Выходные данные

Число таких отрезков.

## Примеры

### Пример 1

Ввод:

```
5
4 2 3 1 2
```

Вывод:

```
11
```

## Решение

Отрезок [l, r] подходит ровно тогда, когда его значения различны и
max − min = r − l. Различность — условие окна: для каждой позиции
самый дальний конец отрезка без повторов получается из последних
вхождений значений за два линейных прохода, так что у каждого начала l
есть граница R(l) для конца, а у каждого конца — граница для начала.

Остальное — обычный «разделяй и властвуй» по массиву. Отрезки внутри
одной половины считаются рекурсивно; для пересекающих середину берутся
префиксные минимумы и максимумы от середины наружу в обе стороны.
Четыре случая определяются тем, где лежат минимум и максимум:

- оба слева: конец определяется как l + max − min, его проверяем;
- оба справа: симметрично, определяется начало;
- максимум слева, минимум справа: условие имеет вид
  min(правой части) + r = max(левой части) + l, так что правые концы,
  у которых префиксный максимум остаётся меньше левого максимума, а
  префиксный минимум меньше левого минимума, образуют окно, монотонно
  сдвигающееся при движении l влево; счётчики ключа min + r по окну
  отвечают для каждого l;
- минимум слева, максимум справа: то же с ключом max − r.

Окна также обрезаются по R(l). Каждый уровень делает линейную работу,
так что всего O(N log N), а очень короткие диапазоны просматриваются
напрямую.

В примере подходят 11 отрезков, среди них [4, 2, 3, 1] и [3, 1, 2].
