# 2198. Суммарная высота всех упорядоченных корневых деревьев из N вершин

## Задача

Найдите сумму высот всех упорядоченных корневых деревьев из N вершин по
модулю 10⁹ + 7. Ограничения: 1 секунда и 256 МБ.

## Входные данные

N, 1 ≤ N ≤ 400.

## Выходные данные

Сумма по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
3
```

## Решение

Обход упорядоченного дерева с e = N − 1 рёбрами, проходящий каждое ребро
вниз и вверх по разу, даёт путь Дика из 2e шагов, и это биекция, при
которой высота дерева — наибольший уровень пути. Суммарная высота равна
сумме по h ≥ 1 числа путей, достигающих уровня h.

Пути, остающиеся в полосе от уровня 0 до h − 1, считаются отражениями
относительно двух прямых −1 и h, что даёт знакопеременную сумму
биномиальных коэффициентов с периодом w = h + 1. Если вычесть её из
числа всех путей и перегруппировать, число путей Дика, достигающих
уровня h, равно

Σ по k ≥ 1 от C(2e, e + kw − 1) − 2 C(2e, e + kw) + C(2e, e + kw + 1),

и ненулевые только слагаемые с kw ≤ e + 1. Значит, ответ — двойная
сумма по ширинам w = 2 … e + 1 и их кратным, около e ln e слагаемых, с
биномиальными коэффициентами C(2e, j), посчитанными один раз через
обратные по модулю.

В примере два дерева из 3 вершин — путь высоты 2 и корень с двумя
листьями высоты 1, так что ответ 3.

Это O(N log N).
