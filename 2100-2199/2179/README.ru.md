# 2179. Наибольшее число непересекающихся прямых трасс между городами

## Задача

N различных городов — точки на плоскости. Трасса — прямой отрезок между
двумя городами, на котором нет других городов, и трассы могут
встречаться только в общих концах. Найдите наибольшее число трасс.
Ограничения: 1 секунда и 256 МБ.

## Входные данные

N, 2 ≤ N ≤ 10⁵, затем N точек с координатами не больше 10⁹ по модулю.

## Выходные данные

Наибольшее число трасс.

## Примеры

### Пример 1

Ввод:

```
4
3 1
-2 -3
1 0
0 6
```

Вывод:

```
6
```

## Решение

Набор трасс, к которому нельзя добавить ещё одну, — это триангуляция
точек: каждая ограниченная грань — треугольник, а внешняя граница —
выпуклая оболочка. Если на границе оболочки лежат h городов, включая
коллинеарные, формула Эйлера даёт любой триангуляции одинаковые
3N − 3 − h рёбер, так что ответу нужно только h.

Монотонная цепочка строит нижнюю и верхнюю оболочки отсортированных
точек и выкидывает точку только при строгом правом повороте, поэтому
города на рёбрах оболочки остаются в цепочке. У двух цепочек общие два
конца, так что h = нижняя + верхняя − 2. Когда все города на одной
прямой, обе цепочки содержат все N городов, h получается 2N − 2, и
формула даёт N − 1 трассу между соседями, что и верно.

В примере (1, 0) лежит внутри треугольника из трёх других, так что
h = 3 и ответ 12 − 3 − 3 = 6: три стороны и три трассы к внутреннему
городу.

Сортировка даёт O(N log N).
