# 2179. 城市之间互不相交的直线公路最多有几条

[Timus 2179](https://acm.timus.ru/problem.aspx?space=1&num=2179) · 难度 2099 · geometry

原题作者 Vadim Barinov，出自 2023 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 座不同的城市是平面上的点。公路是连接两座城市、上面没有其他城市的直线段，公路之间只能在公共端点相交。求公路的最大条数。时间限制 1 秒，内存限制 256 MB。

## 输入

N（2 ≤ N ≤ 10⁵），然后是 N 个点，坐标绝对值不超过 10⁹。

## 输出

公路的最大条数。

## 样例

### 样例 1

输入：

```
4
3 1
-2 -3
1 0
0 6
```

输出：

```
6
```

## 解法

无法再添加一条公路的公路集合就是这些点的一个三角剖分：每个有界面都是三角形，外边界是凸包。若凸包边界上有 h 座城市（包括共线的），由欧拉公式，每个三角剖分都恰有 3N − 3 − h 条边，所以答案只需要 h。

单调链对排好序的点构造下凸壳和上凸壳，只有严格右转时才弹出点，因此位于凸包边上的城市会留在链中。两条链共享两个端点，所以 h = 下链 + 上链 − 2。当所有城市共线时，两条链都包含全部 N 座城市，h 为 2N − 2，公式给出相邻城市之间的 N − 1 条公路，这是正确的。

样例中 (1, 0) 位于另外三点构成的三角形内部，所以 h = 3，答案为 12 − 3 − 3 = 6：三条边和三条通向内部城市的公路。

排序使复杂度为 O(N log N)。
