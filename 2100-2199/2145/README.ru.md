# 2145. Число раздач задач, которые решит каждый школьник

[Timus 2145](https://acm.timus.ru/problem.aspx?space=1&num=2145) · сложность 375 · combinatorics, sorting

Автор оригинальной задачи — Валентин Зуев; Уральская командная олимпиада по программированию 2019.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У n школьников знания aᵢ, у n задач сложности bⱼ; школьник решает
задачу, если aᵢ ≥ bⱼ. Посчитайте по модулю p число способов дать
каждому школьнику ровно одну задачу, все разные, так чтобы каждый решил
свою. Ограничения: 3 секунды и 256 МБ.

## Входные данные

n, 1 ≤ n ≤ 10⁵, значения aᵢ, значения bⱼ, все от 0 до 10⁹, и p,
1 ≤ p ≤ 10⁹.

## Выходные данные

Число способов по модулю p.

## Примеры

### Пример 1

Ввод:

```
3
1 2 3
1 2 3
100
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
3
3 3 3
1 1 1
100
```

Вывод:

```
6
```

## Решение

Отсортируем школьников по знаниям и будем раздавать задачи начиная со
слабейшего. Пусть cᵢ — число задач, которые решает i-й школьник (счёт с
0). Любую задачу, которую решает более слабый школьник, решает и i-й, а
i более слабых уже забрали i разных задач из cᵢ задач i-го. Что бы они
ни забрали, у i-го ровно cᵢ − i вариантов, так что ответ —
произведение cᵢ − i. Как только множитель равен 0, произведение
остаётся 0.

После сортировки обоих массивов cᵢ растёт с i, и один указатель по
задачам даёт их все. Произведение берётся по модулю p на каждом шаге, а
1 % p учитывает p = 1. Работа — O(n log n).

Во втором примере каждый школьник решает каждую задачу, и произведение
равно 3 · 2 · 1 = 6.

## Оптимизированные решения

C++ и Go хранят задачи и студентов в одном массиве 32-битных событий. Младший бит задаёт тип и при равных значениях ставит задачу перед студентом. После сортировки событие задачи увеличивает число свободных вариантов. Событие студента умножает ответ на это число и расходует один вариант. Получается то же произведение, что и в проходе по двум массивам.

Принятые базовые реализации [2145_combinatorics_sorting.java](2145_combinatorics_sorting.java), [2145_combinatorics_sorting.py](2145_combinatorics_sorting.py), [2145_combinatorics_sorting.rs](2145_combinatorics_sorting.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
