## Задача

Для целого C посчитайте пары неотрицательных целых A ≤ B с
√A + √B = √C. Ограничения: 1 секунда и 256 МБ.

## Входные данные

C, 0 ≤ C ≤ 10¹⁸.

## Выходные данные

Число пар.

## Примеры

### Пример 1

Ввод:

```
9
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
3
```

Вывод:

```
1
```

## Решение

Запишем C = s² q, где q свободно от квадратов. Возведение в квадрат
√A = √C − √B показывает, что √(BC) — целое, а отсюда — что A и B равны
a² q и b² q при a + b = s; обратно, любое такое разбиение подходит.
Значит, ответ — число пар a ≤ b с a + b = s, то есть ⌊s/2⌋ + 1 (у C = 0
единственная пара 0, 0).

Осталось найти s — корень наибольшего квадрата, делящего C. Пробное
деление на d до 10⁶ (кубический корень из 10¹⁸) убирает d², пока оно
делит, и затем ещё одно d, если есть, умножая s на d за каждое убранное
d². Остаток имеет только простые множители больше 10⁶, и их не больше
двух, потому что 10¹⁸ < (10⁶)³, так что квадратный множитель у него
есть, только если он сам — квадрат простого; тогда s получает это
простое. Работа — не больше 10⁶ делений.

В первом примере 9 = 3² · 1, так что s = 3, и пары — 0 + 9 и 1 + 4.
