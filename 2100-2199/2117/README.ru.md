# 2117. Суммы двух квадратных корней, равные заданному корню

[Timus 2117](https://acm.timus.ru/problem.aspx?space=1&num=2117) · сложность 544 · number_theory

Автор оригинальной задачи — Павел Климов; Вузовско-академическая олимпиада по информатике 2019.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для целого C посчитайте пары неотрицательных целых A ≤ B с
√A + √B = √C. Ограничения: 1 секунда и 256 МБ.

## Входные данные

C, 0 ≤ C ≤ 10¹⁸.

## Выходные данные

Число пар.

## Проверка

Тесты репозитория сравнивают полный текст вывода, игнорируя только конечные пробельные символы. Значимые пробелы, переводы строк, регистр и пунктуация сохраняются.

## Примеры

### Пример 1

Ввод:

```
9
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
3
```

Вывод:

```
1
```

## Решение

Запишем C = s² q, где q свободно от квадратов. Возведение в квадрат
√A = √C − √B показывает, что √(BC) — целое, а отсюда — что A и B равны
a² q и b² q при a + b = s; обратно, любое такое разбиение подходит.
Значит, ответ — число пар a ≤ b с a + b = s, то есть ⌊s/2⌋ + 1 (у C = 0
единственная пара 0, 0).

Осталось найти s — корень наибольшего квадрата, делящего C. Пробное
деление на d до 10⁶ (кубический корень из 10¹⁸) убирает d², пока оно
делит, и затем ещё одно d, если есть, умножая s на d за каждое убранное
d². Остаток — 1, простое или произведение двух простых больше 10⁶, ведь
три таких множителя превысили бы 10¹⁸. Квадратный множитель у него
есть, только если он сам — квадрат простого; тогда s получает это
простое. Время работы — O(min(10⁶, √C)).

В первом примере 9 = 3² · 1, так что s = 3, и пары — 0 + 9 и 1 + 4.

## Оптимизированные решения

`2117_number_theory_optimized.py`. Извлечение квадратной части C сохраняется, но пробное деление заканчивается, когда d³ превышает уменьшающийся остаток. Степень простого снимается целиком, множитель корня умножается на d^(exponent//2). После 2 и 3 проверяются только кандидаты 6k±1. В остатке тогда не больше двух простых множителей с кратностью; точная проверка квадрата через isqrt извлекает единственный возможный квадратный множитель. Ответ при C=0 и формула root//2+1 прежние. Не больше O(C^(1/3)) пробных делений и постоянное число ограниченных целых; простой перебор сохранён.

По сравнению с `2117_number_theory.py`: время 0.531 s → 0.218 s; память 464 KB → 752 KB.

Новые C++/Go сохраняют разложение C=s²q с бесквадратным q и ответ floor(s/2)+1. При C>0 из √A = √C − √B получаем 2√(BC) = B + C − A. Правая часть чётна, поскольку её квадрат делится на четыре. Значит BC — квадрат. При B>0 показатели простых в B и C имеют одинаковую чётность, откуда B=b²q и A=(s−b)²q. Получаем целые разбиения s, включая A=0.

Полный квадрат, включая ноль, сразу даёт s=sqrt(C). Иначе удаляем пары множителей и нечётный остаток для2 и3, затем проверяем только делители6k±1. Останавливаемся, когда d³ превышает уменьшающийся остаток R: все его простые множители не меньше d, поэтому их не более двух с учётом кратности. Дополнительный квадрат есть ровно тогда, когда R — квадрат. Оценки корней с плавающей точкой исправляются точными целочисленными произведениями; при C≤10^18 они и первый не прошедший куб помещаются в uint64. Вместо перебора всех чисел до фиксированного10^6 колесо пропускает большинство делений, а граница остатка часто завершает цикл раньше. Худшее время O(C^(1/3)), память O(1). Go читает через стандартные дескрипторы в буфер на 64 байта. Ответ не превышает 500 000 001, поэтому для девяти цифр и перевода строки достаточно десяти байтов. Все простые варианты сохранены; Java/Python/Rust используют подходящие исходные версии.

Принятые базовые реализации [2117_number_theory.java](2117_number_theory.java), [2117_number_theory.py](2117_number_theory.py), [2117_number_theory.rs](2117_number_theory.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
