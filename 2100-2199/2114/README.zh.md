# 2114. 网格中给定大小的最重直角三角形

[Timus 2114](https://acm.timus.ru/problem.aspx?space=1&num=2114) · 难度 985 · prefix_sums

原题作者 Valentin Zuev，出自 2019 年大学学术中学生信息学奥林匹克。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n × m 网格中写着非负整数。倒在格子 (x₀, y₀) 上的水覆盖满足 x ≥ x₀、y ≥ y₀ 且 x + y ≤ x₀ + y₀ + k 的格子 (x, y)，即一个直角边各为 k + 1 格的直角三角形。对 q 个 k 值中的每一个，找出覆盖和最大的格子，输出和与格子。时间限制 3 秒，内存限制 256 MB。

## 输入

n 和 m（1 ≤ n, m ≤ 500），网格（0 ≤ aᵢⱼ ≤ 10⁹），然后是 q（1 ≤ q ≤ 50）以及各个值 1 ≤ kᵢ ≤ 10⁵。

## 输出

每个 k 的最大和以及给出它的一个格子。

## 评测方式

检查器接受任何和最大的格子。

## 解法

设 T(x, y) 为 (x, y) 处三角形的和。(x + 1, y − 1) 处的三角形斜边同为 x + y + k。与之相比，(x, y) 处的三角形多出第 x 行从第 y 列到第 y + k 列的格子，少了第 y − 1 列从第 x + 1 行到第 x + k + 1 行的格子。借助按行和按列的前缀和，两部分都是 O(1)，于是

T(x, y) = T(x + 1, y − 1) + 行的部分 − 列的部分。

第一列没有左边的邻居：T(x, 1) 等于 T(x + 1, 1) 加上行的部分，再减去第 x 行以下、对角线 x + y = x + k + 2 上的格子，它们在三角形上移时离开了三角形。沿每条反对角线的前缀和同样能在 O(1) 内给出这一部分。

从最下面一行向上计算，每一行的值由下面一行得到，所以每个询问 O(n m)，全部询问 O(q n m) 再加上前缀和。能够到远角的 k 从 (1, 1) 覆盖整个网格。和可达 2.5 · 10¹⁴，需要 64 位整数。

Python 使用上述向右上方转移的递推。C++、Go、Java 和 Rust 则在每一列中直接向上移动，加入一段行并减去最远反对角线上的一段，每个格子同样只需 O(1)。

C++ 和 Go 构建前缀和的时间和空间均为 O(n m)，总时间为 O(q n m)。Python、Java 和 Rust 存储 O(n + m) 条对角线，每条含 O(n) 个元素，因此预处理的时间和空间均为 O(n(n + m))，总时间为 O(n(n + m) + q n m)。易错点是忽略窄网格的预处理成本（测试 09 和生成测试 thin2）：当 n = 500、m = 1 时，Python 在处理任何询问前就要累加 250000 个对角线元素。

第一个样例中 k = 3 时从 (1, 2) 出发的三角形覆盖 4 + 7 + 4 + 1 + 7 + 9 + 7 + 4 + 7 = 50。
