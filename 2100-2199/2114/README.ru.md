# 2114. Самый тяжёлый прямоугольный треугольник заданного размера в таблице

[Timus 2114](https://acm.timus.ru/problem.aspx?space=1&num=2114) · сложность 1001 · prefix_sums

Автор оригинальной задачи — Валентин Зуев; Вузовско-академическая олимпиада по информатике 2019.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В таблице n × m записаны неотрицательные числа. Вода, вылитая в клетку
(x₀, y₀), покрывает клетки (x, y) с x ≥ x₀, y ≥ y₀ и
x + y ≤ x₀ + y₀ + k — прямоугольный треугольник с катетами по k + 1
клеток. Для каждого из q значений k найдите клетку с наибольшей
покрытой суммой и выведите сумму и клетку. Ограничения: 3 секунды и
256 МБ.

## Входные данные

n и m, 1 ≤ n, m ≤ 500, таблица, 0 ≤ aᵢⱼ ≤ 10⁹, затем q, 1 ≤ q ≤ 50, и
значения 1 ≤ kᵢ ≤ 10⁵.

## Выходные данные

Для каждого k — наибольшая сумма и клетка, которая её даёт.

## Проверка

Проверяющая программа принимает любую клетку с наибольшей суммой.

## Решение

Пусть T(x, y) — сумма треугольника в (x, y). У треугольника в
(x + 1, y − 1) та же гипотенуза x + y + k. По сравнению с ним
треугольник в (x, y) добавляет клетки строки x со столбца y по y + k и
теряет клетки столбца y − 1 со строки x + 1 по строку x + k + 1. С
префиксными суммами по строкам и по столбцам обе части считаются за
O(1), так что

T(x, y) = T(x + 1, y − 1) + часть строки − часть столбца.

Для первого столбца левого соседа нет: T(x, 1) — это T(x + 1, 1) плюс
часть строки минус клетки диагонали x + y = x + k + 2 ниже строки x,
которые выходят из треугольника при сдвиге вверх. Префиксные суммы
вдоль каждой побочной диагонали тоже дают эту часть за O(1).

При движении от нижней строки вверх каждая строка значений получается
из строки под ней, так что запрос занимает O(n m), а все запросы —
O(q n m) плюс префиксные суммы. k, достающее до дальнего угла, покрывает
из (1, 1) всю таблицу. Суммы доходят до 2.5 · 10¹⁴, нужны 64-битные
целые.

В первом примере треугольник из (1, 2) при k = 3 покрывает
4 + 7 + 4 + 1 + 7 + 9 + 7 + 4 + 7 = 50.
