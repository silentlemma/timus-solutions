# 2182. Бутылки, множащиеся по числу единиц в номере коробки

## Задача

Бутылки с номерами 1 … 2ⁿ − 1 кладутся в коробки с теми же номерами.
Бутылка, положенная в коробку k, создаёт новую бутылку с номером
popcount(k) — числом единиц в двоичной записи k, если только это не само
k; новая бутылка идёт в свою коробку и делает то же самое. Для q коробок
выведите, сколько бутылок в них окажется. Ограничения: 1 секунда и
256 МБ.

## Входные данные

n, 1 ≤ n ≤ 60, q, 1 ≤ q ≤ 10⁵, затем номера коробок, 1 ≤ aᵢ ≤ 2ⁿ − 1.

## Выходные данные

Число бутылок в каждой запрошенной коробке.

## Примеры

### Пример 1

Ввод:

```
5
2
8 4
```

Вывод:

```
1 6
```

## Решение

Каждая бутылка, попавшая в коробку j, отправляет одну бутылку дальше в
коробку popcount(j), если она отлична от j. Поэтому для итогового числа
c(k) в коробке k

c(k) = 1 + Σ c(j) по коробкам j ≠ k с popcount(j) = k.

Ни одна коробка с номером больше 60 ничего не получает, ведь у числа
меньше 2⁶⁰ не больше 60 единиц, так что в них по одной бутылке. Для
k ≤ 60 коробок j с popcount(j) = k ровно C(n, k); все, кроме немногих
не больших 60, содержат по одной бутылке, так что c(k) — это C(n, k)
плюс 1 плюс лишние бутылки малых коробок k < j ≤ 60 с popcount(j) = k, минус
один за j = k при k = 1. Поскольку popcount(j) < j при j > 1, заполнение c
от 60 вниз до 1 использует только готовые значения. Наибольшее число,
около 2⁶⁰, помещается в 64 бита, а каждый запрос — просмотр таблицы.

В примере коробка 4 получает свою бутылку и по одной из каждой из
C(5, 4) = 5 коробок 15, 23, 27, 29 и 30.
