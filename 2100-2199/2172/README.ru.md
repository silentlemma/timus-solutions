# 2172. Наименьшее число задач для упоминаний всех спонсоров

[Timus 2172](https://acm.timus.ru/problem.aspx?space=1&num=2172) · сложность 761 · greedy, constructive

## Задача

Спонсор i хочет появиться ровно в sᵢ различных задачах, а ни одна
задача не может упоминать больше K различных спонсоров. Найдите
наименьшее число задач M и план, перечисляющий спонсоров каждой задачи.
Подходит любой правильный план. Ограничения: 1 секунда и 256 МБ.

## Входные данные

N и K, 1 ≤ N, K ≤ 1000, затем s₁ … s_N, 1 ≤ sᵢ ≤ 1000, в сумме не больше
10⁵.

## Выходные данные

M, затем для каждой задачи число её спонсоров и их номера.

## Проверка

Проверяющая программа сверяет M и проверяет, что план выполняет все
пожелания и ограничения.

## Примеры

### Пример 1

Ввод:

```
5 2
1 1 1 1 1
```

Вывод:

```
3
1 5
2 2 3
2 4 1
```

## Решение

Две нижние оценки очевидны: спонсору с наибольшим пожеланием нужно
столько различных задач, а S = Σ sᵢ упоминаниям нужно не меньше
⌈S / K⌉ задач. Значит, M ≥ max(max sᵢ, ⌈S / K⌉), и столько хватает.

Выпишем все упоминания в ряд, спонсор за спонсором, и раздадим их
задачам по кругу: упоминание t идёт в задачу t mod M. Упоминания одного
спонсора идут подряд, и их не больше M, так что они попадают в разные
задачи. Каждая задача получает не больше ⌈S / M⌉ ≤ K упоминаний. Работа
— O(S).

В примере пяти спонсорам с одним пожеланием каждый нужно ⌈5 / 2⌉ = 3
задачи.
