## Задача

Простой граф записывается как N, M и затем M пар вершин от 1 до N, где
N ≥ 1, без петель и повторных рёбер. Посчитайте непрерывные отрезки
массива из K чисел, являющиеся такой записью. Ограничения: 2 секунды и
256 МБ.

## Входные данные

K, 1 ≤ K ≤ 10⁵, затем числа, каждое от 0 до 10⁹.

## Выходные данные

Число отрезков.

## Примеры

### Пример 1

Ввод:

```
12
2 2 2 2 1 1 2 1 2 1 0 0
```

Вывод:

```
3
```

## Решение

Начало s определяет весь отрезок: N = a[s], M = a[s + 1], а рёбра — M
пар после них, так что кандидатов не больше K. Кандидат подходит, когда
N ≥ 1, отрезок помещается, а его пары

- не содержат 0 и пар одинаковых чисел,
- не повторяют неупорядоченную пару,
- используют только числа не больше N.

Пары кандидата начинаются в позициях одной чётности, поэтому первые два
условия готовятся для обеих чётностей справа налево: для каждой позиции
пары p good(p) — где должна остановиться серия допустимых пар от p, то
есть самая ранняя плохая пара или следующее вхождение уже встреченной
пары; её даёт хеш-таблица от неупорядоченной пары к ближайшей более
поздней позиции. Кандидат проходит их, если его конец не дальше
good(s + 2). Третье условие — максимум на отрезке из дерева отрезков.
При M = 0 запись — просто «N 0». Работа — O(K log K).

В примере три правильные записи — «2 1 1 2», «2 1 2 1» и «1 0».
