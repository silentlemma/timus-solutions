# 2125. 用最低次多项式延续数列

[Timus 2125](https://acm.timus.ru/problem.aspx?space=1&num=2125) · 难度 3087 · math

原题作者 Alexey Danilyuk 和 Oleg Merkurev，出自 2018 年夏季彼得罗扎沃茨克集训营 t.me/umnik_team 专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

数列 a₁ … aₙ 的复杂度是满足对 x = 1 … n 都有 p(x) ≡ aₓ (mod 998 244 353) 的多项式 p 的最小次数。把给定数列再延续 m 项，使整个数列的复杂度尽可能小，并输出新的各项。时间限制 4 秒，内存限制 128 MB。

## 输入

n 和 m（1 ≤ n ≤ 10⁵，1 ≤ m ≤ 8 · 10⁵），然后是 a₁ … aₙ。

## 输出

b_{n+1} … b_{n+m}。

## 样例

### 样例 1

输入：

```
5 10
1 4 9 16 25
```

输出：

```
36 49 64 81 100 121 144 169 196 225
```

### 样例 2

输入：

```
3 3
0 0 0
```

输出：

```
0 0 0
```

### 样例 3

输入：

```
5 10
1 2 4 8 16
```

输出：

```
31 57 99 163 256 386 562 794 1093 1471
```

### 样例 4

输入：

```
3 1
2 1 0
```

输出：

```
998244352
```

## 解法

在模素数的域上，经过给定 n 个点的次数小于 n 的多项式恰好有一个，而经过这些点的任何多项式的次数都不小于它。用这个多项式延续可以保持复杂度，所以答案就是它在 n + 1 … n + m 处的值。

把节点取为 0 … n − 1（平移一位），对整数 t ≥ n，拉格朗日公式为

p(t) = t! / (t − n)! · Σᵢ wᵢ / (t − i)，其中 wᵢ = aᵢ · (−1)^{n−1−i} / (i! (n − 1 − i)!)。

这个和是序列 w 与序列 1/k 的卷积，所以一次长度约为 2n + m 的数论变换就能一次得到全部 m 个值；阶乘及其逆元一次扫描求出。模数 998 244 353 = 119 · 2²³ + 1 具有变换所需的单位根。工作量 O((n + m) log(n + m))。

第一个样例中平方数由多项式 x² 延续：36, 49, … 225。
