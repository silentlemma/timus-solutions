# 2125. Продолжение последовательности многочленом наименьшей степени

[Timus 2125](https://acm.timus.ru/problem.aspx?space=1&num=2125) · сложность 3087 · math

## Задача

Сложность последовательности a₁ … aₙ — наименьшая степень многочлена p
с p(x) ≡ aₓ по модулю 998 244 353 при x = 1 … n. Продолжите данную
последовательность ещё на m членов так, чтобы сложность всей
последовательности была как можно меньше, и выведите новые члены.
Ограничения: 4 секунды и 128 МБ.

## Входные данные

n и m, 1 ≤ n ≤ 10⁵, 1 ≤ m ≤ 8 · 10⁵, затем a₁ … aₙ.

## Выходные данные

b_{n+1} … b_{n+m}.

## Примеры

### Пример 1

Ввод:

```
5 10
1 4 9 16 25
```

Вывод:

```
36 49 64 81 100 121 144 169 196 225
```

### Пример 2

Ввод:

```
3 3
0 0 0
```

Вывод:

```
0 0 0
```

### Пример 3

Ввод:

```
5 10
1 2 4 8 16
```

Вывод:

```
31 57 99 163 256 386 562 794 1093 1471
```

### Пример 4

Ввод:

```
3 1
2 1 0
```

Вывод:

```
998244352
```

## Решение

В поле по простому модулю через n данных точек проходит ровно один
многочлен степени меньше n, и любой многочлен через них имеет степень
не меньше его. Продолжение этим многочленом сохраняет сложность, так что
ответ — его значения в n + 1 … n + m.

С узлами 0 … n − 1 (со сдвигом на единицу) формула Лагранжа для целого
t ≥ n имеет вид

p(t) = t! / (t − n)! · Σᵢ wᵢ / (t − i), где
wᵢ = aᵢ · (−1)^{n−1−i} / (i! (n − 1 − i)!).

Сумма — свёртка последовательности w с последовательностью 1/k, так что
одно теоретико-числовое преобразование длины около 2n + m даёт сразу все
m значений; факториалы и обратные к ним получаются за один проход.
Модуль 998 244 353 = 119 · 2²³ + 1 имеет нужные преобразованию корни из
единицы. Работа — O((n + m) log(n + m)).

В первом примере квадраты продолжаются многочленом x²: 36, 49, … 225.

## Особенности языков

Решение на Python запускается под PyPy и делает то же преобразование на
плоских массивах 32-битных чисел. Прежняя версия перемножала
последовательности, упакованные в огромные десятичные числа; под CPython
она превышала лимит времени на тесте 14, а под PyPy модуль decimal
написан на чистом Python и намного медленнее.
