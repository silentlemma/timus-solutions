# 2161. 无论他人如何购买都能赢下每场对决的骑士

[Timus 2161](https://acm.timus.ru/problem.aspx?space=1&num=2161) · 难度 772 · greedy

原题作者 Aleksey Bykov，出自 2021 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 名骑士中每人有攻击 aᵢ、盾 dᵢ 和 gᵢ 枚金币；一枚金币可使攻击或盾加一点，而且谁也不知道别人会怎样花钱。每对骑士交战一次；当对手的攻击不小于自己的盾时骑士被击溃，当对手被击溃而自己没有被击溃时骑士获胜。找出一名能够购买装备、无论他人怎么做都赢下所有战斗的骑士，或者输出 −1。时间限制 1.5 秒，内存限制 256 MB。

## 输入

n（1 ≤ n ≤ 10⁵），然后是各三元组 aᵢ、dᵢ、gᵢ，每个在 0 到 10⁹ 之间。

## 输出

该骑士的编号，或者 −1。

## 样例

### 样例 1

输入：

```
2
100 4 5
1 2 8
```

输出：

```
-1
```

### 样例 2

输入：

```
3
5 2 2
4 1 10
10 4 0
```

输出：

```
2
```

## 解法

对手 j 可以把攻击提到 aⱼ + gⱼ，或者把盾提到 dⱼ + gⱼ，骑士 i 必须对两种极端都安全。所以 i 需要盾大于 A = max_{j ≠ i}(aⱼ + gⱼ)，攻击至少为 D = max_{j ≠ i}(dⱼ + gⱼ)。骑士 i 能做到当且仅当

max(0, A + 1 − dᵢ) + max(0, D − aᵢ) ≤ gᵢ。

除 i 之外所有人的最大值由每种值的最大两个及最大值的位置得到。至多只有一名骑士能满足条件，因为这样的骑士会打败所有其他人。没有对手时最大值不存在，唯一的骑士获胜。工作量 O(n)，需要 64 位求和。

第一个样例中骑士 1 最多只能把盾提到 9，而骑士 2 也能把攻击提到 9，所以骑士 1 不安全；骑士 2 无法得到大于 105 的盾。
