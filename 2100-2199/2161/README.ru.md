# 2161. Рыцарь, побеждающий в каждом бою при любых покупках остальных

[Timus 2161](https://acm.timus.ru/problem.aspx?space=1&num=2161) · сложность 754 · greedy

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У каждого из n рыцарей есть атака aᵢ, щит dᵢ и gᵢ монет; монета
прибавляет одно очко к атаке или к щиту, и никто не знает, как
потратят свои монеты остальные. Каждая пара рыцарей сражается один раз;
рыцарь сокрушён, когда атака соперника не меньше собственного щита, и побеждает,
когда соперник сокрушён, а сам рыцарь нет. Найдите рыцаря, который может
купить снаряжение, побеждающее во всех боях при любых действиях
остальных, или выведите −1. Ограничения: 1.5 секунды и 256 МБ.

## Входные данные

n, 1 ≤ n ≤ 10⁵, затем тройки aᵢ, dᵢ, gᵢ, каждое от 0 до 10⁹.

## Выходные данные

Номер такого рыцаря или −1.

## Примеры

### Пример 1

Ввод:

```
2
100 4 5
1 2 8
```

Вывод:

```
-1
```

### Пример 2

Ввод:

```
3
5 2 2
4 1 10
10 4 0
```

Вывод:

```
2
```

## Решение

Соперник j может достичь атаки aⱼ + gⱼ или щита dⱼ + gⱼ, и рыцарь i
должен быть защищён от обеих крайностей. Значит, i нужен щит больше
A = max по j ≠ i от (aⱼ + gⱼ) и атака не меньше
D = max по j ≠ i от (dⱼ + gⱼ). Рыцарь i справляется ровно тогда, когда

max(0, A + 1 − dᵢ) + max(0, D − aᵢ) ≤ gᵢ.

Максимумы по всем, кроме i, получаются из двух наибольших значений
каждого вида и позиции наибольшего. Пройти может не больше одного
рыцаря, ведь такой рыцарь побеждает всех остальных. Без соперников
максимумов нет, и одинокий рыцарь побеждает. Работа — O(n), с
64-битными суммами.

В первом примере рыцарь 1 может поднять щит только до 9, а рыцарь 2
может поднять атаку тоже до 9, так что рыцарь 1 не защищён; рыцарь 2 не
может получить щит больше 105.
