# 2176. Суммы различных чисел, чья троичная запись прячется в двоичной

[Timus 2176](https://acm.timus.ru/problem.aspx?space=1&num=2176) · сложность 1169 · dp, meet_in_middle

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Число красивое, если его троичная запись — подстрока его двоичной
записи, как у 12 = 110₃ = 1100₂. Для каждого из N чисел xᵢ определите,
является ли оно суммой различных красивых чисел. Ограничения: 1 секунда
и 256 МБ.

## Входные данные

N, 1 ≤ N ≤ 1000, затем x₁ … x_N с 1 ≤ xᵢ ≤ 10⁹.

## Выходные данные

YES или NO для каждого числа.

## Примеры

### Пример 1

Ввод:

```
6
1 2 3 8 9 10
```

Вывод:

```
YES
NO
NO
NO
YES
YES
```

### Пример 2

Ввод:

```
4
854789369 694089367 789789379 795089367
```

Вывод:

```
NO
YES
NO
YES
```

## Решение

В двоичной строке только цифры 0 и 1, так что у красивого числа нет
цифры 2 в троичной записи. У таких чисел до 10⁹ не больше 19 троичных
цифр, так что их меньше 2¹⁹, и они порождаются приписыванием 0 или 1 к
троичному префиксу, а те же цифры, прочитанные как двоичный шаблон,
ищутся в двоичной записи. Красивых среди них всего 40, наибольшее —
133991292.

Тогда вопрос — сумма подмножества из 40 фиксированных чисел, которые
делятся на две части.

- 31 наименьшее число в сумме даёт 48106098, так что битсет такого
  размера отмечает все суммы различных маленьких чисел; каждое число
  сдвигает битсет и объединяется с ним через OR.
- Оставшиеся 9 чисел дают всего 2⁹ сумм подмножеств, которые
  выписываются и сортируются.

Для запроса x перебираются суммы h большой части с
x − 48106098 ≤ h ≤ x, и ответ YES, если какое-то x − h отмечено в
битсете.

В первом примере 9 = 100₃ = 1001₂ и 10 = 101₃ = 1010₂ красивые, а 2 и 3
нет, и из 1 их не собрать.

Построение битсета — 31 проход по 48 миллионам битов, а каждый запрос
пробует не больше 512 сумм.
