# 2176. Sums of distinct numbers whose base-3 form hides in their binary form

[Timus 2176](https://acm.timus.ru/problem.aspx?space=1&num=2176) · difficulty 1043 · dp, meet_in_middle

Original problem by Konstantin Rychkov, from the Ural School Programming Contest 2023.

**English** · [Русский](README.ru.md) · [中文](README.zh.md) · [Español](README.es.md)

## Task

A number is beautiful when its base-3 notation is a substring of its
binary notation, like 12 = 110₃ = 1100₂. For each of N numbers xᵢ, tell
whether it is a sum of distinct beautiful numbers. The limits are
1 second and 256 MB.

## Input

N, 1 ≤ N ≤ 1000, then x₁ … x_N with 1 ≤ xᵢ ≤ 10⁹.

## Output

YES or NO for each number.

## Examples

### Example 1

Input:

```
6
1 2 3 8 9 10
```

Output:

```
YES
NO
NO
NO
YES
YES
```

### Example 2

Input:

```
4
854789369 694089367 789789379 795089367
```

Output:

```
NO
YES
NO
YES
```

## Solution

A binary string has only the digits 0 and 1, so a beautiful number has
no digit 2 in base 3. Such numbers up to 10⁹ have at most 19 ternary
digits, so there are fewer than 2¹⁹ of them, and they are generated by
appending 0 or 1 to a ternary prefix while the same digits, read as a
binary pattern, are tested against the binary form. Only 40 of them
are beautiful, the largest being 133991292.

The question is then a subset sum over 40 fixed numbers, split in two
parts.

- The smallest 31 numbers add up to 48106098, so a bitset of that size
  marks every sum of distinct small numbers; each number shifts the
  bitset and ORs it in.
- The remaining 9 numbers give only 2⁹ subset sums, listed and sorted.

For a query x, the sums h of the large part with x − 48106098 ≤ h ≤ x
are tried, and x is YES when some x − h is marked in the bitset.

In the first example 9 = 100₃ = 1001₂ and 10 = 101₃ = 1010₂ are
beautiful, while 2 and 3 are not and cannot be built from 1.

Building the bitset takes 31 passes over 48 million bits, and each query
tries at most 512 sums.
