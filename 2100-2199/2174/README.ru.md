# 2174. Разбиение купюр на пары с простыми суммами

## Задача

Разбейте N купюр, N чётно, на пары так, чтобы два номинала каждой пары
давали в сумме простое число, или сообщите, что это невозможно.
Подходит любое правильное разбиение. Ограничения: 1 секунда и 256 МБ.

## Входные данные

N, 2 ≤ N ≤ 500, затем номиналы, 1 ≤ cᵢ ≤ 10⁶.

## Выходные данные

NO или YES и N / 2 пар.

## Проверка

Проверяющая программа сверяет вердикт и проверяет, что пары используют
ровно данные купюры и имеют простые суммы.

## Примеры

### Пример 1

Ввод:

```
8
6 2 4 5 2 3 1 5
```

Вывод:

```
YES
5 2
3 2
5 6
1 4
```

### Пример 2

Ввод:

```
2
1 3
```

Вывод:

```
NO
```

## Решение

Единственное чётное простое — 2 = 1 + 1, так что любая другая пара
соединяет нечётную купюру с чётной. Пусть O — число нечётных купюр,
включая единицы, а E — число чётных. Пары из двух единиц убирают
нечётные купюры по две, поэтому их нужно ровно (O − E) / 2; если это
число отрицательно или требует больше единиц, чем есть, ответ NO.
Единицы одинаковы, так что неважно, какие из них объединять.

Оставшиеся нечётные и чётные купюры, которых поровну, образуют
двудольный граф с ребром, когда сумма проста; простоту даёт решето до
2 · 10⁶. Совершенное паросочетание в нём, найденное увеличивающими
путями Куна за O(N³), и есть ответ; если его нет, ответ NO.

Во втором примере 1 + 3 = 4 не простое, а две нечётные купюры иначе не
объединить.
