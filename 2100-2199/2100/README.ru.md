# 2100. Подсчёт гостей без тринадцати

[Timus 2100](https://acm.timus.ru/problem.aspx?space=1&num=2100) · сложность 29 · implementation

Автор оригинальной задачи — Алексей Данилюк; Чемпионат УрФУ среди юниоров 2016.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Пара приглашает n друзей; ответ `name+one` значит, что друг придёт с
парой. Все сидят за одним столом вместе с парой, и если за ним оказалось
бы ровно 13 человек, добавляют манекен. Каждое место стоит $100.
Выведите стоимость ужина. Ограничения: 1 секунда и 64 МБ.

## Входные данные

1 ≤ n ≤ 20, затем n ответов, каждый — имя не длиннее 20 латинских букв,
возможно с `+one`.

## Выходные данные

Стоимость в долларах.

## Примеры

### Пример 1

Ввод:

```
3
Ted+one
Robin
Barney
```

Вывод:

```
600
```

### Пример 2

Ввод:

```
6
Alice+one
Bob+one
carl
Debora+one
Enrique+one
FRED+one
```

Вывод:

```
1400
```

## Решение

Начинаем с двух хозяев, прибавляем 2 за ответ, оканчивающийся на
`+one`, и 1 иначе, превращаем 13 в 14 и умножаем на 100.

Во втором примере за столом оказалось бы 2 + 5 · 2 + 1 = 13 человек,
поэтому к ним добавляется манекен: 1400.

## Оптимизированные решения

Оптимизированное решение на C++ читает ответы через `scanf` в буфер на
25 байт вместо `iostream` и считает те, в которых есть `+`, ведь он
бывает только в ответе, оканчивающемся на `+one`: 128 КБ вместо 396 КБ
при том же времени.

Оптимизированное решение на Java читает ввод блоками по 1 КБ и, как
решение на C++, побайтно считает знаки `+` в ответах вместо `Scanner` и
строк: 0.093 с вместо 0.140 с и 364 КБ вместо 1572 КБ.
