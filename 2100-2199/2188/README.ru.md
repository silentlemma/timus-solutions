# 2188. Самый ранний обгон, который уже не будет потерян

## Задача

Лодка пиратов стартует на D футов впереди и проходит bᵢ футов в секунду
i; лодка Джима в эту секунду может пройти любое целое число футов от 0
до aᵢ. Джим хочет, чтобы первая секунда t, в конце которой лодка Джима строго
впереди, была как можно меньше, при условии, что затем лодка остаётся
строго впереди до конца секунды n. Для каждого из q предположений о D
найдите это t или −1. Ограничения: 1 секунда и 256 МБ.

## Входные данные

n и q, 1 ≤ n, q ≤ 10⁵, затем a₁ … a_n и b₁ … b_n со значениями от 0 до
10⁹, затем d₁ … d_q с 1 ≤ dⱼ ≤ 10⁹.

## Выходные данные

Ответ на каждое предположение.

Ввод:

```
7 4 7 0 5 6 4 4 5 4

```

Вывод:

```
1
2
3
5
5
5
6
10
10
-1
```

### Пример 2

Ввод:

```
1 4
4
1

```

Вывод:

```
1
1
-1
-1
```

## Решение

Пусть x(i) — путь Джима минус путь пиратов, так что Джим впереди в конце
секунды i, когда x(i) > D, и пусть G(i) — префиксная сумма aᵢ − bᵢ, то
есть x на полной скорости. Обе лодки движутся внутри секунды равномерно,
так что быть впереди на обоих концах секунды — значит быть впереди и в
течение неё.

До t Джим не должен быть впереди, так что лучший план — идти на полной
скорости, но не выше D. Такой срезанный путь заканчивается в
x = G(i) − max(0, Mᵢ − D), где Mᵢ — наибольшее из 0, G(1), …, G(i). С
секунды t Джим идёт на полной скорости, так что при M — максимуме до t и
S — наименьшем G(i) для i ≥ t Джим остаётся впереди ровно тогда, когда

S − max(0, M − D) > D, то есть S > max(D, M).

Значит, секунда t может подойти, только если S > M, и тогда она подходит
для всех D < S. Суффиксные минимумы S растут с t, так что у полезных
секунд пороги S возрастают, и каждый запрос — двоичный поиск первого
порога больше D.

Во втором примере G(1) = 3, так что при D = 1 и D = 2 обгон в первую
секунду, а при D = 3 и D = 4 Джим так и не выходит вперёд.

Префиксные суммы и суффиксные минимумы занимают O(n), а запросы
O(q log n).
