# 2171. Числа до N, покрытые хотя бы одной из K арифметических прогрессий

## Задача

Посчитайте целые от 1 до N, входящие хотя бы в одну из K бесконечных
возрастающих арифметических прогрессий bᵢ, bᵢ + dᵢ, … Ограничения:
2 секунды и 256 МБ.

## Входные данные

N и K, 1 ≤ N ≤ 10⁹, 1 ≤ K ≤ 18, затем пары bᵢ, dᵢ, 1 ≤ bᵢ, dᵢ ≤ 10⁹.

## Выходные данные

Это количество.

## Примеры

### Пример 1

Ввод:

```
15 2
3 5
6 2
```

Вывод:

```
7
```

## Решение

По формуле включений-исключений ответ — сумма по непустым подмножествам
прогрессий от (−1)^(размер + 1), умноженного на число общих для них всех
значений до N. Общие значения прогрессий снова образуют прогрессию или
пусты: две из них пересекаются, когда разность их начал делится на НОД
шагов, и тогда расширенный алгоритм Евклида даёт первое общее значение
не раньше обоих начал с шагом НОК (китайская теорема об остатках).

Подмножества обходятся в глубину, по одной прогрессии добавляясь к
текущему пересечению. Ветка обрывается, как только пересечение пусто
или начинается после N, ведь добавление новых прогрессий его не вернёт.
Когда шаг превышает оставшееся до N, пересечение — одно значение и
хранится с шагом 0, что заодно держит числа маленькими. Посещается не
больше 2¹⁸ подмножеств, каждое за O(log).

В примере 3, 8, 13 и 6, 8, 10, 12, 14 имеют общее 8, так что ответ —
3 + 5 − 1 = 7.
