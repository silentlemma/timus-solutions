# 2149. Как развернуть ASCII-голубей в красивый узор

[Timus 2149](https://acm.timus.ru/problem.aspx?space=1&num=2149) · сложность 148 · implementation

Автор оригинальной задачи — Кирилл Бороздин; Уральская командная олимпиада по программированию 2019.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n голубей сидят в ряд, n чётно, каждый смотрит влево или вправо, и они
нарисованы ASCII-графикой. Ряд красивый, когда левая половина смотрит в
одну сторону, а правая в другую, или когда голуби на чётных позициях
смотрят в одну сторону, а на нечётных в другую. Найдите наименьшее число
голубей, которых нужно развернуть. Ограничения: 0.5 секунды и 256 МБ.

## Входные данные

n, 2 ≤ n ≤ 100, затем три строки по 5n − 1 символов с голубями:
`<@..`, `.OO=`, `./\.` для голубя, смотрящего влево, и `..@>`, `=OO.`,
`./\.` для смотрящего вправо, разделённые столбцами точек.

## Выходные данные

Наименьшее число разворотов.

## Примеры

### Пример 1

Ввод:

```
8
..@>.<@...<@.....@>...@>...@>.<@...<@..
=OO...OO=..OO=.=OO..=OO..=OO...OO=..OO=
./\.../\.../\.../\.../\.../\.../\.../\.
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
4
..@>...@>.<@.....@>
=OO..=OO...OO=.=OO.
./\.../\.../\.../\.
```

Вывод:

```
1
```

## Решение

Нужна только первая строка: голубь i смотрит влево ровно тогда, когда
символ на позиции 5i — `<`. Красивых узоров четыре, две пары
противоположных. Считаем голубей, отличающихся от узора «левая половина
смотрит влево, правая вправо»; противоположный узор отличается ровно в
остальных голубях, так что ему нужно n минус это число. То же верно для
узора «чётные позиции смотрят влево, нечётные вправо». Ответ —
наименьшее из четырёх чисел, найденное за O(n).

Во втором примере чередование нарушает только первый голубь, так что
хватает одного разворота.
