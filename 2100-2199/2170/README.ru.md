# 2170. Время смешивания сока парами по выровненным блокам из степени двойки

## Задача

В 2ᴺ сосудах по литру сока с температурами tᵢ. Запрос берёт 2ᵖ сосудов
начиная с l и смешивает их раундами, переливая каждый второй сосуд в
левого соседа; пара переливается, как только обе её части устоялись.
Смешивание объёмов V₁, V₂ при t₁, t₂ даёт t = (V₁t₁ + V₂t₂) / (V₁ + V₂) и
занимает (|t − t₁| V₁ + |t − t₂| V₂) секунд. Ответьте на Q таких
запросов. Ограничения: 3 секунды и 512 МБ.

## Входные данные

N и Q, 1 ≤ N ≤ 18, 1 ≤ Q ≤ 10⁵, температуры, 0 ≤ tᵢ ≤ 10⁵, затем запросы
l, p с 1 ≤ l ≤ 2ᴺ, 0 ≤ p ≤ N и l + 2ᵖ − 1 ≤ 2ᴺ.

## Выходные данные

Время для каждого запроса.

## Примеры

### Пример 1

Ввод:

```
2 2
1 2 3 4
2 1
1 2
```

Вывод:

```
1.0
5.0
```

## Решение

Смешиваются всегда две половины одинакового объёма V. Тогда t — их
среднее, а время — V |t₁ − t₂|, модуль разности количеств тепла V t₁ и
V t₂, то есть сумм исходных температур в двух половинах. Обе половины
доводятся до конца независимо, так что блок размера 2ᵖ с началом l
занимает

T(l, p) = max(T(l, p − 1), T(l + 2ᵖ⁻¹, p − 1)) + |S(левая) − S(правая)|,

где T(l, 0) = 0, а S берётся из префиксных сумм. Запросы могут
начинаться где угодно, поэтому таблица заполняется для каждого начала и
каждого p. Строка p содержит 2ᴺ − 2ᵖ + 1 значений. Вместе с базовой
строкой таблица содержит (N − 1) · 2ᴺ + N + 2 элементов: 4 456 468 при
N = 18, из них 4 194 324 небазовых вычисляются за O(1) каждый. Времена
целые, а каждый запрос — просмотр таблицы. Общее время — O(N 2^N + Q),
память для таблицы — O(N 2^N).

Ловушки: начало не обязано быть выровнено по размеру блока (тест 05), а
независимые ветви не должны ждать окончания общего раунда (тест 14).

В примере блок 1 … 4 сначала смешивает (1, 2) и (3, 4) по 1 секунде, а
затем половины с суммами 3 и 7 ещё за 4, всего 5.
