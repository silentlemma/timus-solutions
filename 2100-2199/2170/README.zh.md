# 2170. 在 2 的幂长度的块上两两混合果汁所需时间

[Timus 2170](https://acm.timus.ru/problem.aspx?space=1&num=2170) · 难度 1409 · dp, prefix_sums

原题作者 Vadim Barinov，出自 2022 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

2ᴺ 个容器各装一升温度为 tᵢ 的果汁。一个询问取从 l 开始的 2ᵖ 个容器，分轮混合：每轮把每隔一个的容器倒进左边的邻居；一对容器在两部分都稳定后立即倒在一起。把温度为 t₁、t₂ 的体积 V₁、V₂ 混合，得到 t = (V₁t₁ + V₂t₂) / (V₁ + V₂)，耗时 (|t − t₁| V₁ + |t − t₂| V₂) 秒。回答 Q 个这样的询问。时间限制 3 秒，内存限制 512 MB。

## 输入

N 和 Q（1 ≤ N ≤ 18，1 ≤ Q ≤ 10⁵），各温度（0 ≤ tᵢ ≤ 10⁵），然后是询问 l、p，满足 1 ≤ l ≤ 2ᴺ、0 ≤ p ≤ N 且 l + 2ᵖ − 1 ≤ 2ᴺ。

## 输出

每个询问的时间。

## 样例

### 样例 1

输入：

```
2 2
1 2 3 4
2 1
1 2
```

输出：

```
1.0
5.0
```

## 解法

每次混合的都是体积相同（均为 V）的两半。此时 t 是它们的平均值，耗时为 V |t₁ − t₂|，即两份热量 V t₁ 与 V t₂ 之差的绝对值，也就是两半中原始温度之和的差。两半各自独立地完成，所以从 l 开始、大小为 2ᵖ 的块耗时

T(l, p) = max(T(l, p − 1), T(l + 2ᵖ⁻¹, p − 1)) + |S(左半) − S(右半)|，

其中 T(l, 0) = 0，S 由前缀和得到。询问可以从任意位置开始，所以对每个起点和每个 p 都填表。第 p 行存储 2ᴺ − 2ᵖ + 1 个值。包含初始行在内，共有 (N − 1) · 2ᴺ + N + 2 项：N = 18 时为 4,456,468 项，其中 4,194,324 个非初始项各用 O(1) 计算。时间都是整数，每个询问只需查表。总时间为 O(N 2^N + Q)，表的空间为 O(N 2^N)。

易错点：起点不必按块长对齐（测试 05）；独立分支不应等待整轮结束（测试 14）。

样例中块 1 … 4 先用各 1 秒混合 (1, 2) 和 (3, 4)，再用 4 秒混合和为 3 和 7 的两半，共 5 秒。
