# 2164. Подсчёт подстрок, являющихся законченными партиями «Четыре в ряд»

## Задача

«Четыре в ряд» играют на поле из 7 строк и 9 столбцов; ход называет
столбец, а ход в заполненный столбец — пропуск, который всё равно тратит
одну из 63 фишек. Партия кончается, когда у последнего ходившего четыре
подряд в строке, столбце или по диагонали (победа), или когда
потрачены все 63 фишки: ничья, если поле заполнено, иначе открытый
конец. В строке ходов посчитайте подстроки, являющиеся законченными
партиями с победой, и законченными партиями с ничьей. Ограничения:
1 секунда и 256 МБ.

## Входные данные

Строка из цифр 1 … 9 длины N, 1 ≤ N ≤ 10⁴.

## Выходные данные

Число партий с победой и число партий с ничьей.

## Примеры

### Пример 1

Ввод:

```
34353637
```

Вывод:

```
2 0
```

## Решение

Начальная позиция определяет всю партию: ходы играются с неё, пока
партия не кончится. Если ход побеждает, подстрока до этого хода —
партия с победой, а никакая более длинная подстрока с этого начала
партией вообще не является. Если 63 хода прошли без победы, подстрока
длины 63 — ничья ровно тогда, когда ни один ход не был пропуском. Так что
каждое начало моделируется не больше 63 ходов, всего N · 63 ходов.

Фишки каждого игрока — 63-битная доска, по биту на клетку, столбец за
столбцом. Ход ставит один бит, а четыре подряд вдоль направления со
сдвигом битов s есть, когда у b & (b ≫ s) & (b ≫ 2s) & (b ≫ 3s) есть
единичный бит; это считается двумя AND сдвинутых пар. Маска клеток, где
может начинаться линия из четырёх, не даёт сдвигам переходить через
край столбца. Победа проверяется только с седьмого хода, когда у
одного цвета уже есть четыре фишки.

В примере «3435363» побеждает в столбце 3, а «4353637» — в нижней
строке; других законченных партий среди подстрок нет.
