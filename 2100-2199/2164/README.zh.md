# 2164. 统计是完整四子棋对局的子串

[Timus 2164](https://acm.timus.ru/problem.aspx?space=1&num=2164) · 难度 1593 · simulation

原题作者 Vadim Barinov，出自 2021 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

四子棋在 7 行 9 列的棋盘上进行；一步棋指定一列，向已满的列落子算作跳过，但仍消耗 63 枚棋子中的一枚。当最后落子的一方在行、列或对角线上连成四子（获胜），或 63 枚棋子全部用完时对局结束：棋盘已满为平局，否则为未完结局。在一串走法中，统计有多少子串是完整的获胜对局、多少是完整的平局。时间限制 1 秒，内存限制 256 MB。

## 输入

由数字 1 … 9 组成、长度为 N 的字符串（1 ≤ N ≤ 10⁴）。

## 输出

获胜对局数和平局对局数。

## 样例

### 样例 1

输入：

```
34353637
```

输出：

```
2 0
```

## 解法

起始位置决定了整局棋：从那里开始走棋直到对局结束。若某一步获胜，到这一步为止的子串就是获胜对局，而从这个起点开始的更长子串都不是对局。若走完 63 步仍无人获胜，则长度为 63 的子串是平局当且仅当没有一步是跳过。所以每个起点至多模拟 63 步，总共 N · 63 步。

每个玩家的棋子是一个 63 位的棋盘，每格一位，按列排列。一步棋设置一位；沿位移为 s 的方向存在四连，当且仅当 b & (b ≫ s) & (b ≫ 2s) & (b ≫ 3s) 有某一位为 1，这用两次对移位后的数对取 AND 求得。用一个标记四连可能起点的掩码防止移位跨过列的边界。只从第七步开始检查胜负，因为此时某一方才可能有四枚棋子。

样例中 "3435363" 在第 3 列获胜，"4353637" 在最下面一行获胜；其他子串都不是完整的对局。
