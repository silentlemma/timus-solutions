# 2180. 向子树加值到指定深度并查询单个顶点

[Timus 2180](https://acm.timus.ru/problem.aspx?space=1&num=2180) · 难度 1607 · fenwick

原题作者 Vladimir Cherepanov，出自 2023 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一棵以 1 为根的树有 N 个顶点。更新「+ v k x」给 v 以及 v 下方至多 k 层的每个后代加上 x，查询「? v」询问到目前为止 v 总共被加了多少。时间限制 2 秒，内存限制 256 MB。

## 输入

N（2 ≤ N ≤ 10⁵），然后是父亲 p₂ … p_N（pᵢ < i），然后是 Q（1 ≤ Q ≤ 10⁵）和 Q 行「+ v k x」（0 ≤ k ≤ N，1 ≤ x ≤ 10⁹）或「? v」。

## 输出

每个查询的答案。

## 样例

### 样例 1

输入：

```
4
1 1 2
6
? 3
+ 1 1 5
? 2
+ 2 1 9
? 4
? 2
```

输出：

```
0
5
9
14
```

## 解法

用欧拉序后，v 的子树是一段进入时间区间，更新恰好作用于该区间中满足 depth(u) ≤ depth(v) + k 的顶点 u。因此在 u 处的查询要累加那些区间包含 entry(u) 且深度上限不小于 depth(u) 的更新，这是一个在线回答的二维问题。

外层树状数组按进入时间建立，把更新存为区间起点处的 +x 和区间末尾之后的 −x，这样到 entry(u) 的前缀和恰好保留包含 u 的区间。每个外层节点持有一棵按深度建立的内层树状数组：更新加在它的深度上限处，查询累加所有不小于 depth(u) 的上限。内层树预先压缩为该节点上查询会用到的深度，使内存保持在 O(Q log N)。

有三种情况绕过内层树：k = 0 只影响 v，存入普通数组；上限达到子树最深顶点时无需检查深度，存入普通的外层树状数组；从未被查询的顶点则从进入时间中去掉。

样例中第一次更新给 1、2、3 加 5，第二次给 2 和 4 加 9，所以顶点 2 得到 14。

每次操作的代价为 O(log² N)。
