# 2157. 穿过会让人停住的云层的最长下落

[Timus 2157](https://acm.timus.ru/problem.aspx?space=1&num=2157) · 难度 1301 · dp

原题作者 Valentin Zuev，出自 2020 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

跳伞者从 (x, y) 以 10 m/s² 的加速度从竖直速度为零开始下落，任何时刻都可以把水平速度设为 −1 到 1 m/s 之间的任意值。落到云 i 所在的点会停住 cᵢ 秒，之后再从静止开始下落。求到达地面 y = 0 之前的最长可能时间，绝对或相对误差不超过 10⁻⁴。时间限制 3 秒，内存限制 256 MB。

## 输入

n（0 ≤ n ≤ 50 000），起点，然后是各朵云 xᵢ, yᵢ, cᵢ，满足 |xᵢ| ≤ 10 000、0 < yᵢ < y ≤ 10 000、1 ≤ cᵢ ≤ 10 000。

## 输出

最长下落时间。

## 样例

### 样例 1

输入：

```
5
0 80
-1 30 2
-1 60 1
0 40 10
1 20 1
1 50 1
```

输出：

```
20.863703305
```

### 样例 2

输入：

```
0
100 100
```

输出：

```
4.472135955
```

## 解法

从静止下落高度 h 需要 √(h / 5) 秒，期间水平位置至多改变同样的量。所以从高度 Y 出发，位于 (x′, y′) 的云可达当且仅当 5 (x′ − x)² ≤ Y − y′，即每侧至多 ⌊√(Y / 5)⌋ ≤ 44 列。

设 best(p) 为从云 p 停留结束后（或从起点）起的最长剩余时间：要么直接落到地面，用时 √(h / 5)（h 为该点高度），要么落到某朵可达的云 q，加上它的密度和 best(q)。同一列中只有最高的可达云有意义。在下落到同列更低的云的途中经过它是可以的，而且更久，因为 √a + √b ≥ √(a + b)，停留还会增加时间。

所以按高度递增处理各朵云和起点。每一列按高度递增保存已处理的云及其值；对一个点，在至多 89 列的每一列中二分查找足够低的最高的云，该点的 best 就是这些值的最大值。起点最后处理，它的值就是答案。工作量 O(n · 89 · log n)。

第二个样例中没有云，从 100 米下落需要 √20 ≈ 4.472 秒。
