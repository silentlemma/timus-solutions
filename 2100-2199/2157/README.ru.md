# 2157. Самое долгое падение сквозь останавливающие облака

## Задача

Парашютист падает из точки (x, y) с ускорением 10 м/с², начиная с
нулевой вертикальной скорости, и может в любой момент задать любую
горизонтальную скорость от −1 до 1 м/с. Попадание в точку облака i
останавливает падение на cᵢ секунд, после чего падение начинается снова
с нулевой скоростью. Найдите наибольшее возможное время до достижения
земли y = 0 с абсолютной или относительной погрешностью не больше
10⁻⁴. Ограничения: 3 секунды и 256 МБ.

## Входные данные

n, 0 ≤ n ≤ 50 000, начальная точка, затем облака xᵢ, yᵢ, cᵢ с
|xᵢ| ≤ 10 000, 0 < yᵢ < y ≤ 10 000 и 1 ≤ cᵢ ≤ 10 000.

## Выходные данные

Наибольшее время падения.

## Примеры

### Пример 1

Ввод:

```
5
0 80
-1 30 2
-1 60 1
0 40 10
1 20 1
1 50 1
```

Вывод:

```
20.863703305
```

### Пример 2

Ввод:

```
0
100 100
```

Вывод:

```
4.472135955
```

## Решение

Падение с высоты h из состояния покоя длится √(h / 5) секунд, и за это
время горизонтальная координата может измениться не больше чем на
столько же. Поэтому с высоты Y облако в (x′, y′) достижимо ровно тогда,
когда 5 (x′ − x)² ≤ Y − y′, то есть не больше ⌊√(Y / 5)⌋ ≤ 44 столбцов в
каждую сторону.

Пусть best(p) — наибольшее оставшееся время от облака p после его
остановки или от начальной точки: либо падение прямо на землю,
√(h / 5) для её высоты h, либо падение на достижимое облако q с добавлением его
плотности и best(q). Внутри одного столбца важно только самое высокое
достижимое облако. Пролететь через него по пути к более низкому облаку
того же столбца можно, и это дольше, ведь √a + √b ≥ √(a + b), а остановка
добавляет время.

Поэтому облака и начальная точка обрабатываются по возрастанию высоты.
Каждый столбец хранит высоты своих обработанных облаков по возрастанию
вместе с их значениями; для точки двоичный поиск в каждом из не более
89 столбцов находит самое высокое достаточно низкое облако, и best точки
— максимум по ним. Начальная точка идёт последней, и её значение —
ответ. Работа — O(n · 89 · log n).

Во втором примере облаков нет, и падение со 100 м длится
√20 ≈ 4.472 секунды.
