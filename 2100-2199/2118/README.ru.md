# 2118. Разрезание битовой строки префиксного кода на нерасшифровываемые куски

[Timus 2118](https://acm.timus.ru/problem.aspx?space=1&num=2118) · сложность 1366 · greedy, strings

Автор оригинальной задачи — Алексей Данилюк; Петрозаводск лето 2018. t.me/umnik_team Contest.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Сообщение в алфавите из k букв закодировано двоичным префиксным кодом,
получилась битовая строка T. Разрежьте T на наибольшее число кусков так,
чтобы ни один кусок нельзя было расшифровать тем же кодом, или
сообщите, что это невозможно. Ограничения: 1 секунда и 64 МБ.

## Входные данные

k, 1 ≤ k ≤ 52, сообщение длиной до 10⁶ из первых k букв A–Z a–z, затем
k кодовых слов, каждое длины не больше k.

## Выходные данные

Наибольшее число кусков или −1.

## Примеры

### Пример 1

Ввод:

```
3
CACB
011
1
001
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
3
ACBABCAACABCAACC
0
10
110
```

Вывод:

```
-1
```

## Решение

Расшифровка префиксным кодом однозначна: в каждой позиции подходит не
больше одного кодового слова. Ответ зависит от однобитовых кодовых
слов.

- Их нет: один бит никогда не расшифровывается, поэтому каждый бит —
  отдельный кусок, и ответ — длина T.
- Есть и 0, и 1: расшифровывается любая строка, ответ −1.
- Ровно одно, назовём его g, а другой бит — b. Тогда все остальные
  кодовые слова начинаются с b. Кусок только из g расшифровывается,
  поэтому в каждом куске есть b, и кусков не больше, чем битов b.

В последнем случае кусок g…g b никогда не расшифровывается: биты g
расшифровываются по одному, а последний b сам по себе не кодовое слово.
Пусть p — последняя позиция T, для которой ни одно кодовое слово не
является префиксом суффикса, начинающегося в p. Каждый более поздний
суффикс начинается с кодового слова и по индукции расшифровывается,
поэтому последний кусок не может начинаться после p, а сам суффикс от p
не расшифровывается. Разрез сразу после каждого b до p и остаток как
последний кусок дают (число b до p) + 1 кусков, и больше нельзя. Если
такого p нет или в T вообще нет b, ответ −1.

В T может быть 5 · 10⁷ битов, поэтому она не строится. Суффиксы
просматриваются с конца автоматом Ахо — Корасик по развёрнутым кодовым
словам: состояние допускающее, когда какое-то кодовое слово — префикс
уже прочитанного суффикса. Переход по целой букве из данного состояния
считается побитово один раз и кешируется, так что просмотр стоит O(|s|)
плюс O(k²) на состояние, а состояний не больше k².

В первом примере T = 0010110011 и g = 1. Суффикс 0011 начинается с
кодового слова 001, но суффикс 010110011 не начинается ни с одного, так
что p — второй бит, перед ним один 0, и ответ — 2.
