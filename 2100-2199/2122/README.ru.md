# 2122. Суммарное расстояние Хэмминга между подпоследовательностями каждой длины

## Задача

Для двоичной строки s длины n и каждого k от 1 до n возьмите все
подпоследовательности длины k (выбранные по позициям) и сложите
расстояния Хэмминга по всем их неупорядоченным парам. Выведите n сумм по
модулю 40 961. Ограничения: 4 секунды и 256 МБ.

## Входные данные

Строка s, 1 ≤ n ≤ 4000.

## Выходные данные

n чисел — суммы для k = 1 … n по модулю 40 961.

## Примеры

### Пример 1

Ввод:

```
11000110111001
```

Вывод:

```
48 4056 15326 31033 20654 29362 32472 13700 21357 12217 20411 12456 212 0
```

### Пример 2

Ввод:

```
000
```

Вывод:

```
0 0 0
```

## Решение

Зафиксируем k и позицию j подпоследовательностей. Если у c_j из C(n, k)
подпоследовательностей на позиции j стоит 1, эта позиция даёт
c_j · (C(n, k) − c_j) различающихся пар. Суммируя по j,

answer(k) = C(n, k) · Σ c_j − Σ c_j².

Σ c_j считает единицы во всех подпоследовательностях, а каждая 1 строки
s входит в C(n − 1, k − 1) из них, так что
Σ c_j = (число единиц) · C(n − 1, k − 1). Работы
требует только Σ c_j².

Вместо выбора позиций будем удалять n − k из них по одной. Тогда каждая
подпоследовательность встречается (n − k)! раз, по разу на порядок
удаления, и пусть r_k(j) = c_j · (n − k)! считает порядки удаления. При
переходе от длины k + 1 к k (позиции с 0) элемент на позиции j остаётся
на месте, когда удаляется один из k − j более поздних элементов, а
элемент на позиции j + 1 сдвигается на j, когда удаляется один из первых
j + 1:

r_k(j) = (k − j) · r_{k+1}(j) + (j + 1) · r_{k+1}(j + 1).

Начиная с r_n = s, каждая длина занимает O(k), всего O(n²). Остальные
слагаемые масштабируются так же, и в конце всё выражение делится на
((n − k)!)². Модуль 40 961 — простое число больше 4000, поэтому эти
факториалы обратимы.

Во втором примере все подпоследовательности одинаковы, и каждая сумма
равна 0.
