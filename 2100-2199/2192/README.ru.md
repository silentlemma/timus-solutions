# 2192. Маршрут по лесу, где на каждой тропинке грибы дороже ягод

[Timus 2192](https://acm.timus.ru/problem.aspx?space=1&num=2192) · сложность 1041 · graphs

Автор оригинальной задачи — Вадим Баринов; Квалификационный тур Уральского регионального чемпионата ICPC 2022.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В лесу N полянок и M односторонних тропинок без циклов; на тропинке i
растут sᵢ грибов и wᵢ ягод. В день j гриб продаётся за aⱼ, а ягода за
bⱼ. Для каждого из Q дней определите, есть ли маршрут от полянки 1 до
полянки N, на каждой тропинке которого aⱼ sᵢ > bⱼ wᵢ. Ограничения:
2 секунды и 256 МБ.

## Входные данные

N, M и Q, 2 ≤ N ≤ 10⁵, 1 ≤ M, Q ≤ 10⁵. Затем M строк uᵢ vᵢ sᵢ wᵢ с
номерами полянок до 10⁵ и 1 ≤ sᵢ, wᵢ ≤ 10⁹ и Q строк aⱼ bⱼ,
1 ≤ aⱼ, bⱼ ≤ 10⁹. Никакие две тропинки не соединяют одну и ту же пару
полянок.

## Выходные данные

YES или NO для каждого дня.

## Примеры

### Пример 1

Ввод:

```
3 3 3
1 2 2 4
2 3 3 9
1 3 10 50
58 9
60 23
61 9
```

Вывод:

```
YES
NO
YES
```

## Решение

Условие на одной тропинке — sᵢ / wᵢ > bⱼ / aⱼ, так что маршрут подходит
в какой-то день ровно тогда, когда его наименьшее отношение sᵢ / wᵢ
больше bⱼ / aⱼ. Дням нужно от леса одно число: наибольшее возможное
наименьшее отношение по всем маршрутам из 1 в N.

Раз тропинки не образуют циклов, это значение узкого места считается
динамикой в топологическом порядке, найденном алгоритмом Кана: best(1)
бесконечно, а тропинка u → v предлагает v значение min(best(u), s / w),
из которых v берёт наибольшее. Отношения хранятся числителем и
знаменателем и сравниваются перекрёстным умножением, которое не
превосходит 10¹⁸; бесконечность — это 1 / 0. Номера полянок могут быть
больше N, поэтому массивы берутся по наибольшему встреченному номеру.

День даёт YES, когда N достижима и aⱼ · s > bⱼ · w для лучшего отношения
s / w, а строгое неравенство делает равенство ответом NO.

В примере у прямой тропинки отношение 1 / 5, у маршрута через 2 —
min(1 / 2, 1 / 3) = 1 / 3, так что узкое место равно 1 / 3. Дни
сравнивают с ним 9 / 58, 23 / 60 и 9 / 61, и слишком велико только
23 / 60.

Порядок и запросы занимают O(N + M + Q).
