# 2192. 每条小路上蘑菇都比浆果赚钱的森林路线

[Timus 2192](https://acm.timus.ru/problem.aspx?space=1&num=2192) · 难度 927 · graphs

原题作者 Vadim Barinov，出自 2022 年 ICPC 乌拉尔赛区资格赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

森林里有 N 块空地和 M 条没有环的单向小路；第 i 条小路上有 sᵢ 个蘑菇和 wᵢ 个浆果。第 j 天蘑菇卖 aⱼ，浆果卖 bⱼ。对 Q 天中的每一天，判断是否存在一条从空地 1 到空地 N 的路线，使经过的每条小路都满足 aⱼ sᵢ > bⱼ wᵢ。时间限制 2 秒，内存限制 256 MB。

## 输入

N、M 和 Q（2 ≤ N ≤ 10⁵，1 ≤ M, Q ≤ 10⁵）。接着 M 行 uᵢ vᵢ sᵢ wᵢ，空地编号不超过 10⁵，1 ≤ sᵢ, wᵢ ≤ 10⁹；然后 Q 行 aⱼ bⱼ，1 ≤ aⱼ, bⱼ ≤ 10⁹。任意两条小路不连接同一对空地。

## 输出

每天输出 YES 或 NO。

## 样例

### 样例 1

输入：

```
3 3 3
1 2 2 4
2 3 3 9
1 3 10 50
58 9
60 23
61 9
```

输出：

```
YES
NO
YES
```

## 解法

单条小路的条件是 sᵢ / wᵢ > bⱼ / aⱼ，所以一条路线在某天可行，当且仅当它最小的比值 sᵢ / wᵢ 大于 bⱼ / aⱼ。各天只需要森林给出一个数：从 1 到 N 的所有路线中，最小比值的最大可能值。

由于小路没有环，这个瓶颈值可以按 Kahn 算法得到的拓扑序做动态规划：best(1) 为无穷大，小路 u → v 给 v 提供 min(best(u), s / w)，v 取其中最大者。比值以分子和分母保存，用交叉相乘比较，乘积不超过 10¹⁸；无穷大记作 1 / 0。空地编号可能超过 N，所以数组按 L 开，其中 L 是 N 与所有编号的最大值。

当 N 可达且对最优比值 s / w 有 aⱼ · s > bⱼ · w 时，这一天输出 YES；由于是严格不等式，相等时输出 NO。

样例中直达小路的比值是 1 / 5，经过 2 的路线是 min(1 / 2, 1 / 3) = 1 / 3，所以瓶颈值为 1 / 3。三天分别用 9 / 58、23 / 60 和 9 / 61 与之比较，只有 23 / 60 太大。

拓扑序和查询共需 O(L + M + Q)。
