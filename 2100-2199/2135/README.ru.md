# 2135. Наименьшее число отрезков с произведениями в диапазоне

[Timus 2135](https://acm.timus.ru/problem.aspx?space=1&num=2135) · сложность 994 · dp, two_pointers

Автор оригинальной задачи — Анна Ханова; Контест "Лучше поздно, чем никогда".

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Разбейте последовательность из n натуральных чисел на наименьшее число
подряд идущих отрезков так, чтобы произведение каждого отрезка лежало в
[l, r], или сообщите, что это невозможно. Ограничения: 2 секунды и
256 МБ.

## Входные данные

n, l и r, 1 ≤ n ≤ 50 000, 1 ≤ l ≤ r ≤ 10¹⁸, затем числа, каждое от 1 до
10⁹.

## Выходные данные

Наименьшее число отрезков или −1.

## Примеры

### Пример 1

Ввод:

```
7 8 20
2 4 8 16 1 3 5
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
7 10 20
2 4 8 16 1 3 5
```

Вывод:

```
-1
```

## Решение

Пусть best(i) — наименьшее число отрезков, покрывающих первые i чисел.
Последний отрезок разбиения первых i чисел начинается в некотором j, и
его произведение растёт при сдвиге j влево, ведь все числа не меньше 1.
Поэтому начала с произведением не больше r образуют суффикс позиций от
U, а начала с произведением не меньше l — префикс позиций до L;
допустимые начала — отрезок [U, L).

Оба конца с ростом i только сдвигаются вправо, так что их ведут два
указателя, каждый с произведением своего окна: когда следующее число
вывело бы произведение за свою границу, из окна сначала делением
убираются числа слева, и каждое произведение остаётся в 64 битах. Число больше r сбрасывает
верхнее окно, а число не меньше l — нижнее. Значения best(j) для j из
[U, L) входят в монотонную деку и выходят из неё, что даёт их минимум за
O(1), и best(i) = 1 + этот минимум. Весь проход — O(n).

В первом примере 2 · 4 | 8 | 16 · 1 | 3 · 5 даёт четыре отрезка с
произведениями 8, 8, 16 и 15.
