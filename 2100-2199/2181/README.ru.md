# 2181. Подсчёт маршрутов туда и обратно по сетке без повторных перекрёстков

## Задача

Город — сетка N × M перекрёстков, где между соседями нет K дорог.
Маршрут дня идёт из (1, 1) в (N, M) только в сторону больших координат,
потом обратно только в сторону меньших, и ни один перекрёсток, кроме
двух концов, не посещается дважды. Посчитайте различные маршруты по
модулю 10⁹ + 7. Ограничения: 3 секунды и 256 МБ.

## Входные данные

N и M, 2 ≤ N, M ≤ 300, затем K, 0 ≤ K ≤ 10⁵, и K отсутствующих дорог,
каждая — двумя соседними перекрёстками, которые она соединяла.

## Выходные данные

Число маршрутов по модулю 10⁹ + 7 или 0.

## Примеры

### Пример 1

Ввод:

```
3 3
2
1 2 1 3
1 3 2 3
```

Вывод:

```
2
```

## Решение

Обратный путь, прочитанный задом наперёд, — ещё один монотонный путь из
(1, 1) в (N, M), так что маршрут — упорядоченная пара монотонных путей,
у которых общие только концы. Они должны выйти из (1, 1) в разные
стороны и войти в (N, M) с разных сторон. Путь через (1, 2) остаётся
выше другого, поэтому заканчивается через (N − 1, M), а путь через
(2, 1) — через (N, M − 1); четыре ребра в углах должны существовать.

Подсчёт пар вершинно непересекающихся путей из A₁ = (1, 2), A₂ = (2, 1)
в B₁ = (N − 1, M), B₂ = (N, M − 1) — это лемма
Линдстрёма–Гесселя–Вьенно:

det = P(A₁, B₁) · P(A₂, B₂) − P(A₁, B₂) · P(A₂, B₁),

где P считает монотонные пути. Любая пересекающаяся пара сокращается
обменом хвостов после первого общего перекрёстка, что сопоставляет ей
пересекающуюся пару другого соответствия, а перекрёстное соответствие на
плоской сетке не может быть непересекающимся. Две динамики по сетке,
по одной от каждого начала, дают все четыре числа. Любой из путей может
быть дорогой туда, так что ответ — 2 · det.

В примере у (1, 3) нет дорог, так что верхний путь —
(1, 2) → (2, 2) → (2, 3), нижний должен обойти (2, 2) через (3, 1), и
единственная пара даёт 2 маршрута.

Это O(NM + K).
