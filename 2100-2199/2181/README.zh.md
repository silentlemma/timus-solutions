# 2181. 网格上不重复经过路口的往返路线计数

[Timus 2181](https://acm.timus.ru/problem.aspx?space=1&num=2181) · 难度 1410 · dp, math

原题作者 Semyon Trifochkin，出自 2023 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

城市是 N × M 的路口网格，相邻路口之间缺少 K 条道路。一天的路线从 (1, 1) 出发，只朝坐标增大的方向走到 (N, M)，再只朝坐标减小的方向走回来，除两端外任何路口都不能经过两次。求不同路线的数目，对 10⁹ + 7 取模。时间限制 3 秒，内存限制 256 MB。

## 输入

N 和 M（2 ≤ N, M ≤ 300），然后是 K（0 ≤ K ≤ 10⁵）和 K 条缺失的道路，每条用它原本连接的两个相邻路口表示。

## 输出

路线数对 10⁹ + 7 取模，或 0。

## 样例

### 样例 1

输入：

```
3 3
2
1 2 1 3
1 3 2 3
```

输出：

```
2
```

## 解法

把回程倒过来读，就是另一条从 (1, 1) 到 (N, M) 的单调路径，所以一条路线是一对只共享两端的有序单调路径。它们必须从 (1, 1) 朝不同方向出发，并从不同方向进入 (N, M)。经过 (1, 2) 的路径始终在另一条上方，所以经 (N − 1, M) 结束，而经过 (2, 1) 的路径经 (N, M − 1) 结束；四个角上的边必须存在。

从 A₁ = (1, 2)、A₂ = (2, 1) 到 B₁ = (N − 1, M)、B₂ = (N, M − 1) 的顶点不相交路径对计数就是 Lindström–Gessel–Viennot 引理：

det = P(A₁, B₁) · P(A₂, B₂) − P(A₁, B₂) · P(A₂, B₁)，

其中 P 计数单调路径。任何相交的路径对在第一个公共路口之后交换尾部，就与另一种配对中的相交路径对一一对应而抵消，而交叉的配对在平面网格中不可能不相交。从两个起点各做一次网格 DP 就得到全部四个数。两条路径都可以作为去程，所以答案是 2 · det。

样例中 (1, 3) 没有道路，所以上方路径是 (1, 2) → (2, 2) → (2, 3)，下方路径必须经 (3, 1) 绕开 (2, 2)，唯一的一对给出 2 条路线。

复杂度 O(NM + K)。
