# 2160. Перестановки с тем же декартовым деревом

[Timus 2160](https://acm.timus.ru/problem.aspx?space=1&num=2160) · сложность 1117 · combinatorics, trees

## Задача

Две перестановки эквивалентны, если обе пусты или их наименьшие
элементы стоят на одной позиции, а части слева и справа от них, в свою
очередь, эквивалентны. Посчитайте перестановки 1 … N, эквивалентные
данной, по модулю 10⁹ + 7. Ограничения: 2 секунды и 256 МБ.

## Входные данные

N, 1 ≤ N ≤ 10⁵, затем перестановка.

## Выходные данные

Число эквивалентных перестановок по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
3
2 1 3
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
12
12 5 3 11 2 8 4 9 1 6 10 7
```

Вывод:

```
34650
```

## Решение

Рекурсивное определение — это в точности форма декартова дерева
перестановки: корень — наименьший элемент, а левое и правое поддеревья
строятся из двух сторон. Значит, нужно посчитать разметки
фиксированного двоичного дерева числами 1 … N, в которых каждая вершина
меньше всех вершин своего поддерева.

В такой разметке корень каждого поддерева размера s должен нести
наименьшую из его s меток, что происходит с вероятностью 1 / s, и эти
события независимы. Поэтому ответ — N!, делённое на произведение
размеров всех поддеревьев. Декартово дерево, а с ним и размеры
поддеревьев, даёт обычный проход со стеком: когда приходит меньший
элемент, снятые со стека элементы завершают свои поддеревья, и их
размеры накапливаются в левом сыне нового элемента. Деление — умножение
на обратный по простому модулю. Работа — O(N).

В первом примере у дерева корень 1 и два листа, так что ответ —
3! / (3 · 1 · 1) = 2.
