# 2143. 安排一组人使任何两人都不相邻

[Timus 2143](https://acm.timus.ru/problem.aspx?space=1&num=2143) · 难度 672 · dp, bitmask

原题作者 Alexey Kungurtsev，出自 2019 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

飞机有 n 排座位 A B C | D E F，中间是过道，部分座位已被占用。两个座位相邻，当它们在过道同一侧，且排号和字母都相差不超过一。把一组 k 人安排到空座上，使任何两人都不相邻，或者报告无法做到。任何合法的安排都可接受。时间限制 0.5 秒，内存限制 256 MB。

## 输入

n 和 k（1 ≤ n ≤ 100，1 ≤ k ≤ 6n），然后是 n 行形如 ".**|_|**." 的描述，"." 表示空座，"*" 表示已占。空座至少有 k 个。

## 输出

"PORAZHENIE"，或者 "POBEDA" 以及 k 个形如 1A 的座位。

## 评测方式

检查器核对结论，并验证这些座位为空、互不相同且两两不相邻。

## 样例

### 样例 1

输入：

```
2 2
.**|_|**.
**.|_|***
```

输出：

```
POBEDA
1A
2C
```

### 样例 2

输入：

```
2 3
...|_|***
***|_|***
```

输出：

```
PORAZHENIE
```

## 解法

过道两侧互不接触，所以每一侧是一个独立的 n × 3 网格，相邻关系就是国王的走法。合法安排的任何子集仍然合法，所以只需在每一侧求出最大的合法安排，检查两侧合计是否至少有 k 个座位。

在一侧，一排的座位构成一个 3 位掩码。若掩码只用空座且没有两个相邻的位，则它在该排中允许；两排相邻时，若一个掩码的任何位都不与另一个掩码的位处于同一列或相邻列，即 (m | m << 1 | m >> 1) & m′ = 0，则二者相容。对排和最后一排的掩码做动态规划，记录最多人数和前一排的掩码，从最后一排回溯即可重建最优安排。掩码只有 8 个，所以工作量为 O(64 n)。

第二个样例中三个空座 1A、1B、1C 至多坐两人，即 1A 和 1C，所以三人无法安排。
