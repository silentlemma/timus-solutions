# 2134. 在文档上盖章直到 k 个格子被涂两次

[Timus 2134](https://acm.timus.ru/problem.aspx?space=1&num=2134) · 难度 1666 · simulation

原题作者 Kirill Borozdin，出自 “迟到总比不到好”专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一枚印章带有 a × b 的黑色格子图案，在 n × m 的文档上按给定位置盖 q 次。被涂色超过一次的格子算作重涂。求第一次使重涂格子数至少为 k 的盖章，若始终不会发生则输出最终的文档。时间限制 1 秒，内存限制 256 MB。

## 输入

n、m 和 k（1 ≤ n, m ≤ 1000，1 ≤ k ≤ 100），然后是 a 和 b（1 ≤ a ≤ n，1 ≤ b ≤ m），以及 a 行图案，每行包含 b 个 "." 或 "#" 字符。接着是 q（1 ≤ q ≤ 10⁵）以及 q 个位置 (x, y)，表示印章左上角格子所在的行和列，均从 1 开始编号。整个印章必须位于文档内：1 ≤ x ≤ n − a + 1，1 ≤ y ≤ m − b + 1。

## 输出

"Wasted after stamp #s"，或者由 "." 和 "#" 组成的 n 行文档。

## 样例

### 样例 1

输入：

```
4 3 2
3 2
#.
.#
..
2
1 1
2 2
```

输出：

```
#..
.#.
..#
...
```

### 样例 2

输入：

```
4 3 1
3 2
#.
.#
..
2
1 1
2 2
```

输出：

```
Wasted after stamp #2
```

## 解法

直接涂每次盖章的每个黑格，对文档的每个格子记录它被涂了 0 次、1 次还是至少 2 次，并记录重涂格子数；一旦达到 k 就停止。由于下面的计数论证，这样已经足够快。

在文档仍然清晰时，处于"至少 2 次"状态的格子少于 k 个。所以每次盖章至多碰到 k − 1 个这样的格子，它的其他格子要么从 0 变为 1（总共至多 nm 次），要么从 1 变为 2（少于 k 次）。因此所有盖章合计至多碰到 q(k − 1) + nm + k 个格子。第三次使用的位置可以直接跳过：它的所有格子都已被重涂。工作量 O(ab + nm + qk)，约 10⁷ 步。

易错点：(x, y) 指定的是矩阵左上角的格子，即使该格子透明也是如此（测试 16）。整个矩阵都必须位于文档内。

样例中两次盖章都涂到了格子 (2, 2)。k = 2 时允许一个重涂格子，输出文档；k = 1 时在第二次盖章后文档作废。
