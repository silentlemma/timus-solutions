# 2134. Печати на документе, пока k клеток не окрашены дважды

[Timus 2134](https://acm.timus.ru/problem.aspx?space=1&num=2134) · сложность 1714 · simulation

Автор оригинальной задачи — Кирилл Бороздин; Контест "Лучше поздно, чем никогда".

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Печать с узором a × b из чёрных клеток ставится q раз на документ
n × m в заданных позициях. Клетка, окрашенная больше одного раза,
перекрашена. Найдите первую печать, после которой перекрашено не меньше
k клеток, или выведите итоговый документ, если этого не случится.
Ограничения: 1 секунда и 256 МБ.

## Входные данные

n, m и k, 1 ≤ n, m ≤ 1000, 1 ≤ k ≤ 100, затем a и b, узор, затем q,
1 ≤ q ≤ 10⁵, и q позиций.

## Выходные данные

«Wasted after stamp #s» или документ — n строк из «.» и «#».

## Примеры

### Пример 1

Ввод:

```
4 3 2
3 2
#.
.#
..
2
1 1
2 2
```

Вывод:

```
#..
.#.
..#
...
```

### Пример 2

Ввод:

```
4 3 1
3 2
#.
.#
..
2
1 1
2 2
```

Вывод:

```
Wasted after stamp #2
```

## Решение

Просто окрашиваем каждую чёрную клетку каждой печати, храня для каждой
клетки документа, окрашена ли она 0, 1 или не меньше 2 раз, и число
перекрашенных клеток; останавливаемся, как только оно достигает k.
Этого достаточно благодаря подсчёту.

Пока документ разборчив, в состоянии «не меньше 2» меньше k клеток.
Поэтому каждая печать задевает не больше k − 1 таких клеток, а каждая
другая её клетка либо переходит из 0 в 1, что всего бывает не больше nm
раз, либо из 1 в 2, что бывает меньше k раз. Значит, все печати вместе
задевают не больше q(k − 1) + nm + k клеток. Позицию, использованную в
третий раз, можно пропустить целиком: все её клетки уже перекрашены.
Работа — O(ab + nm + qk), около 10⁷ шагов.

В примерах обе печати окрашивают клетку (2, 2). При k = 2 одна
перекрашенная клетка допустима и выводится документ; при k = 1 он
испорчен после второй печати.
