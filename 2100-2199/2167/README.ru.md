# 2167. Наименьший ключ XOR, превращающий число в простое

## Задача

Для каждого из T чисел a меньше 2²⁰ найдите наименьший неотрицательный
ключ k, при котором a XOR k — простое число. Ограничения: 2 секунды и
256 МБ.

## Входные данные

T, 1 ≤ T ≤ 10⁵, затем числа, 0 ≤ a ≤ 1 048 575.

## Выходные данные

Наименьший ключ для каждого числа.

## Примеры

### Пример 1

Ввод:

```
3
5
6
1
```

Вывод:

```
0
1
2
```

## Решение

При фиксированном a ключ k = a XOR p взаимно однозначно соответствует
простому p, так что нужно найти простое p, при котором a XOR p
наименьшее. Ключи меньше 2²⁰ уже дают все простые меньше 2²⁰, в том
числе 2, а большему простому нужен ключ не меньше 2²⁰, так что важны
только простые меньше 2²⁰.

XOR тем меньше, чем больше старших битов p совпадает с a. Решетом
находятся простые меньше 2²⁰ и для каждого j строится таблица: есть ли
простое с данным префиксом из j битов; каждая таблица — OR пар
элементов следующей. Запрос выбирает биты p сверху: оставляет бит a,
если у какого-то простого есть такой более длинный префикс, и берёт
другой бит иначе. Это 20 шагов на число после подготовки за O(2²⁰ log log 2²⁰).

В примере 5 простое, 6 XOR 1 = 7 и 1 XOR 2 = 3.
