# 2139. Сок в поворачиваемом многоугольнике с дыркой в стороне

## Задача

В выпуклом многоугольнике, полном сока, делают дырку в точке H одной из
сторон, и всё, что выше горизонтали через H, выливается. Затем его
медленно поворачивают вокруг начала координат на q заданных углов по
очереди. Выведите количество оставшегося сока после дырки и после
каждого поворота с абсолютной или относительной погрешностью не больше
10⁻⁴. Ограничения: 4 секунды и 256 МБ.

## Входные данные

n, 3 ≤ n ≤ 10⁵, вершины против часовой стрелки, дырка, затем q,
0 ≤ q ≤ 10⁵, и углы в градусах, −360 ≤ αᵢ ≤ 360; все числа даны ровно с
тремя знаками после запятой, координаты по модулю не больше 10⁵.

## Выходные данные

q + 1 площадей.

## Примеры

### Пример 1

Ввод:

```
3
-2.000 1.000
1.000 -2.000
4.000 1.000
1.000 1.000
4
45.000
45.000
45.000
45.000
```

Вывод:

```
9.000000000
6.750000000
4.500000000
2.250000000
0.000000000
```

## Решение

Поворот вокруг начала координат перемещает дырку вместе с
многоугольником, так что важен только суммарный угол поворота θ.
Вместимость c(θ) — площадь части многоугольника ниже горизонтали через H
при этом угле, а оставшийся сок — наименьшая вместимость, встреченная
за медленный поворот.

При изменении θ эта прямая вращается вокруг H — точки границы. Один из
двух её лучей из H сразу выходит из многоугольника, поэтому область
ниже прямой только прибавляет площадь с одной стороны или только теряет
её, и c(θ) монотонна между двумя особыми углами: когда сторона с H
горизонтальна и многоугольник над ней (c = 0, дырка внизу) и когда она
горизонтальна и многоугольник под ней (c — вся площадь). Значит, по
кругу c растёт от 0 до полной площади и падает обратно. Если суммарный
угол хоть раз проходит угол, при котором дырка внизу, сок вытекает
навсегда. Иначе угол остаётся внутри одной дуги между двумя такими
углами, где c сначала растёт, а потом падает, так что минимум за любой
поворот достигается на его концах, и ответ — min(прежний ответ, c(θ)).

Для вычисления c(θ) вершины хранятся начиная с соседней с дыркой, в
точных целых координатах в тысячных относительно H, вместе с
префиксными суммами слагаемых формулы шнурования. Вершины по одну
сторону от прямой через H образуют одну дугу этого списка, поэтому
двоичный поиск по знаковым высотам находит ребро, через которое прямая
выходит, а площадь ниже — префикс веера из H плюс часть одного
треугольника. Каждый поворот стоит O(log n).

В примере треугольник вначале имеет площадь 9; каждый поворот на 45°
опускает уровень относительно многоугольника, а после четвёртого дырка
оказывается внизу и не остаётся ничего.
