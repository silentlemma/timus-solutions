# 2139. 侧面有孔的旋转多边形中剩余的果汁

[Timus 2139](https://acm.timus.ru/problem.aspx?space=1&num=2139) · 难度 3641 · geometry, binary_search

原题作者 Vadim Barinov，出自 2019 年乌拉尔团队程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个装满果汁的凸多边形在某条边上的点 H 处被打了一个孔，于是过 H 的水平线以上的果汁全部流出。然后把它绕原点依次缓慢旋转 q 个给定的角度。输出打孔后以及每次旋转后剩余的果汁量，绝对或相对误差不超过 10⁻⁴。时间限制 4 秒，内存限制 256 MB。

## 输入

n（3 ≤ n ≤ 10⁵），逆时针给出的顶点，孔的位置，然后是 q（0 ≤ q ≤ 10⁵）以及以度为单位的角度（−360 ≤ αᵢ ≤ 360）；坐标和角度恰有三位小数，坐标绝对值不超过 10⁵。

## 输出

q + 1 个面积。

## 样例

### 样例 1

输入：

```
3
-2.000 1.000
1.000 -2.000
4.000 1.000
1.000 1.000
4
45.000
45.000
45.000
45.000
```

输出：

```
9.000000000
6.750000000
4.500000000
2.250000000
0.000000000
```

## 解法

绕原点旋转时孔随多边形一起移动，所以只有至今转过的总角度 θ 有关。容量 c(θ) 是该角度下多边形位于过 H 的水平线以下部分的面积，剩余果汁就是缓慢旋转过程中见到的最小容量。

θ 变化时，这条直线绕边界上的点 H 转动。它从 H 出发的两条射线中有一条立即离开多边形，所以直线下方的区域只在一侧增加面积或只在一侧减少面积，c(θ) 在两个特殊角度之间单调：一个是 H 所在的边水平且多边形在其上方（c = 0，孔在最低处），另一个是该边水平且多边形在其下方（c 等于全部面积）。因此在整个圆周上 c 从 0 增加到全部面积再减回去。只要总角度经过孔在最低处的角度，果汁就永远流光。否则转过的角度始终在两个这样的角度之间的一段弧内，c 在其中先增后减，所以任何一次旋转的最小值都在端点处取得，答案为 min(之前的答案, c(θ))。

为了计算 c(θ)，从孔旁边的顶点开始存储顶点，用以千分之一为单位、相对于 H 的精确整数坐标，并保存鞋带公式各项的前缀和。位于过 H 的直线一侧的顶点构成这个列表中的一段弧，所以对有符号高度二分查找就能找到直线穿出的边，下方面积就是以 H 为顶点的三角形扇的前缀或后缀加上一个三角形的一部分。每次旋转 O(log n)。

样例中三角形一开始面积为 9；每次转 45° 都使液面相对多边形降低，第四次旋转后孔位于最低处，什么也不剩。
