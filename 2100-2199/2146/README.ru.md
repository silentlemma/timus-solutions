# 2146. Наименьший круговой период после не более k замен букв

[Timus 2146](https://acm.timus.ru/problem.aspx?space=1&num=2146) · сложность 641 · strings

## Задача

На барабане n секторов по кругу, в каждом строчная буква. Барабан имеет
период p, когда каждый сектор совпадает с сектором на p позиций дальше
по кругу. Замените не более k букв так, чтобы наименьший период был как
можно меньше, и выведите этот период и новый барабан. Подходит любой
оптимальный барабан. Ограничения: 5 секунд и 256 МБ.

## Входные данные

n и k, 1 ≤ n ≤ 10⁵, 0 ≤ k ≤ n, затем n букв.

## Выходные данные

Наименьший период и барабан после замен.

## Проверка

Проверяющая программа сверяет период, число замен и то, что у
выведенного барабана наименьший период ровно такой.

## Примеры

### Пример 1

Ввод:

```
6 3
abcdef
```

Вывод:

```
3
abcabc
```

### Пример 2

Ввод:

```
4 1
aaab
```

Вывод:

```
1
aaaa
```

### Пример 3

Ввод:

```
4 0
aaab
```

Вывод:

```
4
aaab
```

## Решение

На окружности периоды p и n дают период gcd(p, n), так что наименьший
период всегда делит n, и проверять нужно только делители n. Для
делителя d секторы распадаются на d классов позиций с одинаковым
остатком по модулю d, и период d означает, что в каждом классе одна
буква. Дешевле всего оставить в каждом классе самую частую букву, так
что число замен — n минус сумма этих частот.

Делители перебираются от меньшего, и первый, требующий не больше k
замен, — ответ; каждый класс заполняется своей самой частой буквой. У
такого барабана не может быть меньшего периода d′: тогда это был бы
барабан с периодом d′ не дальше k замен, и d′ был бы принят раньше.
Подсчёт букв занимает O(n) на делитель, а у n ≤ 10⁵ не больше 128
делителей.

В первом примере период 3 оставляет в классах «ad», «be» и «cf» по одной
букве за три замены, а периодам 1 и 2 нужно больше.
