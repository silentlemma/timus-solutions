# 2146. 至多改 k 个字母后的最小循环周期

[Timus 2146](https://acm.timus.ru/problem.aspx?space=1&num=2146) · 难度 641 · strings

原题作者 Valentin Zuev，出自 2019 年乌拉尔团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

转盘上有 n 个扇区围成一圈，每个扇区写着一个小写字母。若每个扇区都与沿圆周前进 p 个位置后的扇区相同，则转盘具有周期 p。至多修改 k 个字母，使最小周期尽可能小，输出这个周期和修改后的转盘。任何最优的转盘都可接受。时间限制 5 秒，内存限制 256 MB。

## 输入

n 和 k（1 ≤ n ≤ 10⁵，0 ≤ k ≤ n），然后是 n 个字母。

## 输出

最小周期和修改后的转盘。

## 评测方式

检查器核对周期、修改次数，以及输出的转盘的最小周期恰好是这个数。

## 样例

### 样例 1

输入：

```
6 3
abcdef
```

输出：

```
3
abcabc
```

### 样例 2

输入：

```
4 1
aaab
```

输出：

```
1
aaaa
```

### 样例 3

输入：

```
4 0
aaab
```

输出：

```
4
aaab
```

## 解法

在圆周上，周期 p 和 n 合起来给出周期 gcd(p, n)，所以最小周期总是 n 的约数，只需尝试 n 的约数。对约数 d，扇区按模 d 的余数分成 d 个类，周期为 d 意味着每个类只有一种字母。最省的做法是每个类保留出现最多的字母，所以修改次数为 n 减去这些频数之和。

从小到大尝试约数，第一个修改次数不超过 k 的就是答案，每个类都填上它最常见的字母。这样得到的转盘不可能有更小的周期 d′：否则它就是一个距离不超过 k 次修改、周期为 d′ 的转盘，d′ 会先被接受。每个约数统计字母需要 O(n)，而 n ≤ 10⁵ 至多有 128 个约数。

第一个样例中周期 3 用三次修改使 "ad"、"be"、"cf" 三个类各只剩一种字母，而周期 1 和 2 需要更多次修改。
