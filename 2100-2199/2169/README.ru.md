# 2169. Ориентация графа, где у вершины не больше одного выходящего и трёх входящих рёбер

## Задача

Дан простой неориентированный граф из N вершин и M рёбер. Посчитайте по
модулю 10⁹ + 7 число способов направить все рёбра так, чтобы у каждой
вершины было не больше одного выходящего и не больше трёх входящих
рёбер. Ограничения: 2 секунды и 256 МБ.

## Входные данные

N и M, 1 ≤ N ≤ 10⁵, 0 ≤ M ≤ 10⁵, затем M рёбер без петель и повторов.

## Выходные данные

Число ориентаций по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
5 4
1 2
1 3
1 4
1 5
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
6 4
1 2
1 3
2 3
4 5
```

Вывод:

```
4
```

## Решение

Раз у вершины не больше одного выходящего ребра, у компоненты связности
из V вершин не больше V рёбер, так что компоненты считаются по
отдельности, а результаты перемножаются.

- **Рёбер больше, чем вершин:** ориентаций нет, ответ 0.
- **Дерево (V − 1 ребро):** ровно у одной вершины, стока, нет
  выходящего ребра, и тогда все рёбра направлены к нему. У стока все
  рёбра входящие, у остальных вершин — все, кроме одного, так что
  выбирать можно вершины степени не больше 3, если нет вершин степени
  больше 4.
- **Один цикл (V рёбер):** у каждой вершины есть выходящее ребро, так
  что цикл направлен одним из двух способов, а свисающие с него деревья
  направлены к нему. Каждая вершина получает все рёбра, кроме одного, и
  достаточно степени не больше 4, получается 2 способа.

Система непересекающихся множеств собирает число вершин и рёбер каждой
компоненты, а проверка степеней проходит по всем вершинам.

В первом примере у центра степень 4 и он не может быть стоком, так что
сток — один из четырёх листьев.

Это O((N + M) α(N)).
