# 2169. 每个顶点至多一条出边、三条入边的图定向

[Timus 2169](https://acm.timus.ru/problem.aspx?space=1&num=2169) · 难度 1858 · dsu, graphs

原题作者 Valentin Zuev，出自 2022 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定一个有 N 个顶点、M 条边的简单无向图。求把每条边定向，使每个顶点至多一条出边、至多三条入边的方案数，对 10⁹ + 7 取模。时间限制 2 秒，内存限制 256 MB。

## 输入

N 和 M（1 ≤ N ≤ 10⁵，0 ≤ M ≤ 10⁵），然后是 M 条没有自环和重边的边。

## 输出

定向方案数对 10⁹ + 7 取模。

## 样例

### 样例 1

输入：

```
5 4
1 2
1 3
1 4
1 5
```

输出：

```
4
```

### 样例 2

输入：

```
6 4
1 2
1 3
2 3
4 5
```

输出：

```
4
```

## 解法

每个顶点至多一条出边，所以有 V 个顶点的连通分量至多有 V 条边，各分量分别计数后相乘。

- **边数多于顶点数：** 没有定向方案，答案为 0。
- **树（V − 1 条边）：** 恰有一个顶点（汇点）没有出边，所有边都指向它。汇点的所有边都是入边，其他顶点除一条外都是入边，所以可选的汇点是度数不超过 3 的顶点，前提是没有度数超过 4 的顶点。
- **单环（V 条边）：** 每个顶点都有出边，所以环有两种方向，挂在环上的树都指向环。每个顶点除一条外的边都是入边，只要度数不超过 4 即可，共 2 种方案。

并查集统计每个分量的顶点数和边数，度数检查对所有顶点进行。

第一个样例中中心的度数为 4，不能当汇点，所以汇点是四片叶子之一。

复杂度 O((N + M) α(N))。
