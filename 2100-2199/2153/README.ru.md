# 2153. Наибольший отряд из разных ролей и какой новичок поможет

[Timus 2153](https://acm.timus.ru/problem.aspx?space=1&num=2153) · сложность 934 · dp, bitmask

Автор оригинальной задачи — Валентин Зуев; Уральская командная олимпиада по программированию 2020.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У каждого из n членов гильдии непустой набор из четырёх квалификаций:
воин, маг, клирик и разбойник. Отряд даёт разным членам разные роли из
их квалификаций. Найдите наибольший отряд, а если в нём меньше четырёх
человек, перечислите квалификации, при найме человека только с которой
наибольший отряд станет больше. Ограничения: 0.5 секунды и 256 МБ.

## Входные данные

n, 1 ≤ n ≤ 15, затем квалификации каждого члена как подпоследовательность
«WMCR».

## Выходные данные

Наибольший размер и, если он меньше 4, строка «Looking for» с
квалификациями в порядке warrior, mage, cleric, rogue.

## Примеры

### Пример 1

Ввод:

```
1
W
```

Вывод:

```
1
Looking for mage cleric rogue
```

### Пример 2

Ввод:

```
2
M
CR
```

Вывод:

```
2
Looking for warrior cleric rogue
```

### Пример 3

Ввод:

```
4
WMCR
WMCR
WMCR
WMCR
```

Вывод:

```
4
```

### Пример 4

Ввод:

```
1
WMCR
```

Вывод:

```
1
Looking for warrior mage cleric rogue
```

## Решение

Наборов ролей всего 16. Динамика по членам гильдии хранит, какие наборы
ролей можно заполнить разными людьми: член либо остаётся в стороне,
либо берёт одну свободную роль набора. Обход наборов в убывающем порядке
внутри шага одного члена не даёт одному члену взять две роли. Наибольший отряд —
наибольший достижимый набор.

Новичок только с квалификацией r увеличивает отряд ровно тогда, когда
какой-то наибольший набор не использует r: этот набор вместе с новичком
больше, а если бы каждый наибольший набор использовал r, больший отряд
содержал бы достижимый набор прежнего наибольшего размера без r. Поэтому
в объявлении — роли вне пересечения всех наибольших достижимых наборов.
Работа — O(16 · 4 · n).

Во втором примере наибольшие отряды — {маг, клирик} и {маг, разбойник};
их пересечение — {маг}, так что нужны воины, клирики и разбойники.
