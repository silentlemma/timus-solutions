# 2101. 过三角形内一点的内接矩形

[Timus 2101](https://acm.timus.ru/problem.aspx?space=1&num=2101) · 难度 1664 · geometry

原题作者 Alexey Danilyuk，出自 2016 年乌拉尔联邦大学青少年锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定三角形及其严格内部的一点。若矩形的所有顶点都在三角形的边上，则称它内接于三角形。在边界经过该点的内接矩形中，求最大面积，并统计共有多少个不同的这样的矩形。时间限制 1 秒，内存限制 64 MB。

## 输入

三个顶点和该点，整数坐标绝对值不超过 10⁴；三个顶点不共线。

## 输出

最大面积，绝对或相对误差不超过 10⁻⁶，然后是矩形个数。

## 样例

### 样例 1

输入：

```
0 0
10 0
0 20
4 6
```

输出：

```
48.0000000000
4
```

### 样例 2

输入：

```
-3 0
2 -1
5 7
0 1
```

输出：

```
9.0697674419
2
```

## 解法

内接矩形有一条边落在三角形的一条边（底边）上，两个上顶点在另两条边上。只有当底边上的高的垂足落在底边内部时才可能，所以相邻角为钝角的边没有这样的矩形。底边长 b、高 H 时，高为 h 的矩形宽为 b (1 − h/H)。在直角三角形中，两条直角边描述的是同一组矩形（以直角为一个角的矩形），所以这一族只计一次。

对每条可用的底边，点可以在矩形的上边上，这把 h 定为点到底边的距离；也可以在左边或右边上，这确定了该边沿底边的位置，从而确定 h。上边的情形总给出一个矩形；侧边的情形再给出一个，除非点恰在高线上，此时侧边会把矩形压成退化。点严格在内部，所以这些矩形互不相同。数据为整数时面积是有理数：三角形面积的两倍、距离和投影都是整数，因此每个面积都是精确计算的分数，再四舍五入到 10 位小数。整体 O(1)。

第一个样例中两条直角边在坐标轴上，点为 (4, 6)：以原点为角、右边经过该点的矩形宽 4 高 12，面积 48，是四个中最大的。
