# 2183. Смена знаков на одном отрезке ради наибольшего минимума

## Задача

Поменяйте знаки всех чисел ровно на одном непустом отрезке массива так,
чтобы его минимум стал как можно больше, и выведите этот минимум. В
массиве есть отрицательное число. Ограничения: 1 секунда и 256 МБ.

## Входные данные

n, 1 ≤ n ≤ 10⁵, затем a₁ … aₙ, −10⁹ ≤ aᵢ ≤ 10⁹.

## Выходные данные

Наибольший возможный минимум.

## Примеры

### Пример 1

Ввод:

```
5
-1 3 -2 -4 5
```

Вывод:

```
-1
```

### Пример 2

Ввод:

```
4
2 -4 -3 -10
```

Вывод:

```
2
```

## Решение

Спросим, возможен ли минимум не меньше x. Каждое число меньше x нужно
развернуть, так что отрезок должен накрыть их все, а каждое число
внутри отрезка должно стать не меньше x, то есть быть не больше −x.
Более длинный отрезок только добавляет условия, поэтому достаточно
проверить кратчайший — от первого до последнего числа меньше x. Если
чисел меньше x нет, одно число не больше −x всё равно нужно развернуть,
и это выполнено, когда наименьшее число не больше −x.

Большее x делает проверку только труднее, так что двоичный поиск по x от
−10⁹ до 10⁹ находит наибольшее проходящее значение; проверка занимает
O(n), всего O(n log C).

Во втором примере разворот −4 −3 −10 даёт 2 4 3 10 с минимумом 2.

## Особенности языков

- Решение на Python обходится без двоичного поиска: один проход слева
  направо хранит лучший минимум префикса, когда смена знаков ещё не
  началась, идёт или закончилась, — это O(n).
