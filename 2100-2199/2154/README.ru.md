# 2154. Ближайшая к началу координат прямая через две точки

[Timus 2154](https://acm.timus.ru/problem.aspx?space=1&num=2154) · сложность 2665 · geometry, sorting

## Задача

n пушечных батарей стоят в различных целых точках. Из батареи можно
полететь на ядре в сторону любой другой батареи, спрыгнуть над любой
батареей по пути, а ядро летит дальше бесконечно. Найдите наименьшее
расстояние до начала координат, которого можно так достичь, с
абсолютной или относительной погрешностью не больше 10⁻⁶. Ограничения:
2 секунды и 256 МБ.

## Входные данные

n, 2 ≤ n ≤ 10⁵, затем точки, |xᵢ|, |yᵢ| ≤ 10⁵.

## Выходные данные

Наименьшее расстояние.

## Примеры

### Пример 1

Ввод:

```
4
1 0
0 1
-1 0
0 -1
```

Вывод:

```
0.0000000000
```

### Пример 2

Ввод:

```
5
0 3
1 2
1 3
1 4
2 3
```

Вывод:

```
0.7071067812
```

## Решение

До каждой батареи можно добраться от любой другой, а полёт из A над B
вместе с полётом из B над A покрывает всю прямую AB. Поэтому ответ —
наименьшее расстояние от начала координат до прямой через две батареи,
|A × B| / |A − B|, и 0, если батарея стоит в начале координат.

Перебор всех пар слишком медленный, но нужны только пары соседей в
порядке направлений по модулю π: точки сортируются по углу прямой из
начала координат через них с ключом x / y, и берутся все пары
циклических соседей: две точки ближайшей прямой всегда соседи в этом
циклическом порядке, с одной или с другой стороны. Точки на одной прямой через начало
координат имеют равные ключи, оказываются соседями и дают 0. Полное
сравнение со всеми парами на множестве маленьких случайных наборов это
подтверждает. Работа — O(n log n).

В первом примере прямая через (1, 0) и (−1, 0) проходит через начало
координат.
