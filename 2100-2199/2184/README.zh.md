# 2184. 一堆被分进两个箱子时堆大小的最大值

[Timus 2184](https://acm.timus.ru/problem.aspx?space=1&num=2184) · 难度 1216 · number_theory

原题作者 Artyom Stepanov，出自 2024 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

金币按每堆 d 枚放进 n 个箱子，每一堆整个放进一个箱子，只有最后一堆被任意分进两个箱子。已知各箱子里的金币数 aᵢ，求 d 的最大可能值。时间限制 1 秒，内存限制 256 MB。

## 输入

n（2 ≤ n ≤ 10⁵），然后是 a₁ … a_n（0 ≤ aᵢ ≤ 10¹²），不全为零。

## 输出

最大的 d。

## 样例

### 样例 1

输入：

```
4
5 8 7 100
```

输出：

```
5
```

### 样例 2

输入：

```
5
9 4 6 5 12
```

输出：

```
3
```

### 样例 3

输入：

```
6
4 8 16 24 12 40
```

输出：

```
8
```

## 解法

箱子里总共是整数个堆，所以 d 整除总和 S，并且除了分最后一堆的两个箱子外，每个箱子里的数都是 d 的倍数。反过来，若 d 整除 S 和除两个以外的所有 aᵢ，则两个余数之和为 0 或 d，正好是一堆被分开。所以答案是 S 与去掉至多两个值后其余所有值的最大公约数的最大值。

去掉一个值只有在它改变当前公约数时才有用。设去掉 i < j。若 S 与 i 之前的值的公约数已经整除 aᵢ，保留 aᵢ 不会改变什么；对 j 和它之后的值同理。所以 i 可以只在前缀公约数（从 S 开始）发生变化的位置中找，j 只在后缀公约数变化的位置中找。每次变化至少使一个不超过 10¹⁷ 的数减半，所以两类位置都少于 60 个。

解法标记这些位置，把其他值与 S 一起合并为一个公约数，再借助标记列表上的后缀公约数尝试所有标记值的对。不去掉任何值的情况由全体的公约数覆盖。

第一个样例中 S = 120，d = 5 时 5 和 100 保留，而 8 和 7 的余数 3 和 2 合成一堆 5。

扫描需要 O(n log S)，枚举对约需 120² 次求公约数。
