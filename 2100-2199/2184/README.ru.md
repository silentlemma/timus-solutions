# 2184. Наибольший размер кучки, когда одна кучка разделена между двумя сундуками

## Задача

Монеты раскладывали кучками по d в n сундуков, каждую кучку целиком в
один сундук, кроме последней, которую как угодно разделили между двумя
сундуками. По содержимому сундуков aᵢ найдите наибольшее возможное d.
Ограничения: 1 секунда и 256 МБ.

## Входные данные

n, 2 ≤ n ≤ 10⁵, затем a₁ … a_n с 0 ≤ aᵢ ≤ 10¹², не все нули.

## Выходные данные

Наибольшее d.

## Примеры

### Пример 1

Ввод:

```
4
5 8 7 100
```

Вывод:

```
5
```

### Пример 2

Ввод:

```
5
9 4 6 5 12
```

Вывод:

```
3
```

### Пример 3

Ввод:

```
6
4 8 16 24 12 40
```

Вывод:

```
8
```

## Решение

Всего в сундуках целое число кучек, так что d делит сумму S, и в каждом
сундуке, кроме двух, деливших последнюю кучку, лежит кратное d.
Обратно, если d делит S и все aᵢ, кроме двух, то два остатка в сумме
дают 0 или d, то есть разделённую кучку. Значит, ответ — наибольший НОД
числа S со всеми значениями, кроме не более чем двух.

Убирать значение имеет смысл, только если оно меняет текущий НОД. Пусть
убраны i < j. Если НОД S и значений до i уже делит aᵢ, то aᵢ можно
оставить, ничего не изменится, и так же для j со значениями после него.
Поэтому i можно искать среди позиций, где меняется префиксный НОД
(начатый с S), а j — среди позиций, где меняется суффиксный. Каждое
изменение хотя бы вдвое уменьшает число не больше 10¹⁷, так что тех и
других меньше 60.

Решение отмечает эти позиции, сворачивает все остальные значения в один
НОД вместе с S и перебирает все пары отмеченных значений с суффиксными
НОД по списку отмеченных. Случай без удаления покрывает НОД всех чисел.

В первом примере S = 120, и d = 5 оставляет 5 и 100, а 8 и 7 дают
остатки 3 и 2, которые складываются в одну кучку из 5.

Проход занимает O(n log S), а пары — около 120² шагов НОД.
