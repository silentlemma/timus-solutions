# 2163. 已知行和与列和时某个格子的可能取值

[Timus 2163](https://acm.timus.ru/problem.aspx?space=1&num=2163) · 难度 1130 · math

原题作者 Semyon Trifochkin，出自 2021 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个非负整数矩阵已知各行之和 r₁ … rₙ 和各列之和 c₁ … cₘ。在所有这样的矩阵中，统计第 a 行第 b 列的格子能取多少个值；若不存在这样的矩阵，答案为 0。时间限制 1 秒，内存限制 256 MB。

## 输入

n 和 m（1 ≤ n, m ≤ 1000），a 和 b，各行之和，然后是各列之和，每个在 0 到 10⁹ 之间。

## 输出

可能取值的个数。

## 样例

### 样例 1

输入：

```
1 2
1 1
15
5 10
```

输出：

```
1
```

### 样例 2

输入：

```
2 2
2 2
10 15
12 13
```

输出：

```
11
```

## 解法

矩阵存在当且仅当行和的总和与列和的总和相同，记为 T：此时沿行和列的经典贪心填法就能构造出一个。现在把该格固定为 x。需要 x ≤ rₐ 且 x ≤ c_b。第 a 行剩下的 rₐ − x 必须放到其他列中，而它们的和为 T − c_b；同样 c_b − x 必须放进其他行，其和为 T − rₐ；两者都给出 x ≥ rₐ + c_b − T。满足这些条件时，剩余部分又是一个总和相同、有一个格子保持为零的矩阵，同样的贪心填法可以构造出来。所以取值构成从 max(0, rₐ + c_b − T) 到 min(rₐ, c_b) 的区间，答案就是它的长度，至少为 1。求和需要 64 位。工作量 O(n + m)。

第二个样例中 T = 25，r₂ = 15，c₂ = 13，所以该格可取 3 … 13，共十一个值。
