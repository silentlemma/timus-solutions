# 2163. Возможные значения одной клетки при заданных суммах строк и столбцов

## Задача

У матрицы из неотрицательных целых известны суммы строк r₁ … rₙ и суммы
столбцов c₁ … cₘ. Посчитайте, сколько значений может принимать клетка в
строке a и столбце b по всем таким матрицам; если ни одной матрицы нет,
ответ 0. Ограничения: 1 секунда и 256 МБ.

## Входные данные

n и m, 1 ≤ n, m ≤ 1000, a и b, суммы строк, затем суммы столбцов, каждая
от 0 до 10⁹.

## Выходные данные

Число возможных значений.

## Примеры

### Пример 1

Ввод:

```
1 2
1 1
15
5 10
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
2 2
2 2
10 15
12 13
```

Вывод:

```
11
```

## Решение

Матрица существует ровно тогда, когда у сумм строк и сумм столбцов одна
и та же общая сумма T: тогда её строит классическое жадное заполнение по
строкам и столбцам. Теперь зафиксируем клетку равной x. Нужно x ≤ rₐ и
x ≤ c_b. Остаток строки a, rₐ − x, должен уйти в остальные столбцы с
суммой T − c_b, и так же c_b − x должно поместиться в остальные строки,
T − rₐ; оба условия дают x ≥ rₐ + c_b − T. При этих условиях оставшаяся
часть — снова матрица с совпадающими суммами и одной клеткой, равной
нулю, и то же жадное заполнение её строит. Значит, значения образуют
отрезок от max(0, rₐ + c_b − T) до min(rₐ, c_b), и ответ — его длина, не
меньше 1. Суммам нужны 64 бита. Работа — O(n + m).

Во втором примере T = 25, r₂ = 15 и c₂ = 13, так что клетка принимает
значения 3 … 13, одиннадцать штук.
