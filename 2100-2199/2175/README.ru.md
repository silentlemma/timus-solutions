# 2175. Число префиксных максимумов при только растущих элементах

## Задача

Лестница массива начинается с его первого элемента и раз за разом
берёт первый следующий элемент, строго больший последнего взятого, то
есть состоит из строгих префиксных максимумов. Каждое из Q изменений
прибавляет к одному элементу неотрицательное число; выведите длину
лестницы после каждого изменения. Ограничения: 2 секунды и 256 МБ.

## Входные данные

N, 1 ≤ N ≤ 10⁵, массив, 0 ≤ aᵢ ≤ 10⁹, затем Q, 1 ≤ Q ≤ 10⁵, и изменения
p, x с 0 ≤ x ≤ 10⁹.

## Выходные данные

Длина лестницы после каждого изменения.

## Примеры

### Пример 1

Ввод:

```
5
1 2 5 1 7
3
1 3
2 3
4 6
```

Вывод:

```
3
3
3
```

## Решение

Лестница хранится связным списком позиций. Когда aₚ растёт:

- Если p не на лестнице, она попадает туда ровно тогда, когда её новое
  значение больше всех более ранних элементов. Наибольший более ранний
  элемент, самый ранний среди равных, стоит на лестнице, и p
  вставляется сразу после него.
- Если p теперь на лестнице, следующие элементы лестницы, не большие
  нового значения, выпадают один за другим до большего или до конца.

Значения только растут, так что каждое удаление оплачено более ранней
вставкой, а вставок не больше N + Q. Максимум префикса даёт дерево
Фенвика максимумов по позициям; рост значения обновляет его узлы, и
подъём останавливается на первом узле, где уже лежит большее значение,
ведь все дальнейшие узлы тоже его содержат. Работа —
O((N + Q) log N).

В примере после первого изменения массив — 4 2 5 1 7, и в лестнице
4, 5, 7 три элемента.
