# 2175. 元素只增不减时前缀最大值的个数

[Timus 2175](https://acm.timus.ru/problem.aspx?space=1&num=2175) · 难度 1140 · fenwick

原题作者 Ignat Nigmatullin，出自 2023 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

数组的阶梯从第一个元素开始，每次取之后第一个严格大于上一个已取元素的元素，所以它由严格的前缀最大值组成。Q 次修改中每次给某个元素加上一个非负数；每次修改后输出阶梯的长度。时间限制 2 秒，内存限制 256 MB。

## 输入

N（1 ≤ N ≤ 10⁵），数组（0 ≤ aᵢ ≤ 10⁹），然后是 Q（1 ≤ Q ≤ 10⁵）以及修改 p, x（0 ≤ x ≤ 10⁹）。

## 输出

每次修改后阶梯的长度。

## 样例

### 样例 1

输入：

```
5
1 2 5 1 7
3
1 3
2 3
4 6
```

输出：

```
3
3
3
```

## 解法

把阶梯保存为位置的链表。当 aₚ 增大时：

- 若 p 不在阶梯上，它加入阶梯当且仅当新值大于之前所有元素。之前最大的元素（相等时取最早的）在阶梯上，把 p 链接在它后面。
- 若 p 现在在阶梯上，后面不大于新值的阶梯元素依次被删去，直到遇到更大的或到达末尾。

值只增不减，所以每次删除都由之前的一次插入"买单"，而插入至多 N + Q 次。前缀最大值由按位置建立的最大值树状数组给出；值增大时更新它的节点，向上走到第一个已存有更大值的节点就停止，因为之后的所有节点都包含那个值。工作量 O((N + Q) log N)。

样例中第一次修改后数组为 4 2 5 1 7，阶梯 4, 5, 7 有三个元素。
