# 2185. 让许多初值经过“负则加、否则减”的变换

[Timus 2185](https://acm.timus.ru/problem.aspx?space=1&num=2185) · 难度 2681 · math

原题作者 Artyom Stepanov 和 Artyom Abaturov，出自 2024 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

数组 a₁ … a_n 逐个元素作用于数 x：若 x < 0 就加上该元素，否则减去它。对 q 个初值分别输出最终值。时间限制 1.5 秒，内存限制 512 MB。

## 输入

n 和 q（1 ≤ n, q ≤ 10⁶），然后是满足 |aᵢ| ≤ 10⁶ 的数组和 q 个满足 |xᵢ| ≤ 10⁶ 的初值。

## 输出

每个初值对应的最终值。

## 样例

### 样例 1

输入：

```
3 2
3 1 2
4
-3
```

输出：

```
-2
1
```

### 样例 2

输入：

```
3 4
2 1 4
10
-5
2
6
```

输出：

```
3
2
3
-1
```

## 解法

记 ~x = −x − 1。一步变换与它可交换：若 x ≥ 0，则 ~x < 0，且 ~x + a = −(x − a) − 1 = ~(x − a)。因此整个过程满足 f(~x) = ~f(x)，负的初值可以由非负初值 ~x 回答。剩下的就是同时处理所有初值 0 … V（V ≤ 10⁶）。

维护一个初值区间 [L, R]，其中所有当前值都在零的同一侧，于是它们都等于初值 + offset，一步只移动 offset。当某一步使区间在初值 c = −offset 处跨过零时，小于 c 的初值当前值为负，从 c 开始的为非负。小于 c 的初值 s 当前值为 s + offset = ~((2c − 1 − s) + offset)，即另一侧镜像 2c − 1 − s 的补。所以把较小的一侧切掉，并记下“取镜像的补”，镜像落在保留下来的较大一侧；由于可交换性在之后每一步都成立，这个关系一直保持到最后。

最后保留的区间取初值 + offset，被切掉的段按切下的逆序填写，每段都由已经知道的镜像得到。每个初值至多被切掉一次。

第一个样例中 4 依次变为 1、0、−2；而 −3 = ~2，2 依次变为 −1、0、−2，所以 −3 最终为 ~(−2) = 1。

遍历数组需要 O(n)，填写需要 O(V)，查询需要 O(q)。
