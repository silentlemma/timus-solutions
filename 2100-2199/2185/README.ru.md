# 2185. Прогон многих стартовых значений через «прибавь, если отрицательно, иначе вычти»

## Задача

Массив a₁ … a_n применяется к числу x поэлементно: если x < 0, элемент
прибавляется, иначе вычитается. Выведите итоговое значение для каждого
из q стартовых значений. Ограничения: 1.5 секунды и 512 МБ.

## Входные данные

n и q, 1 ≤ n, q ≤ 10⁶, затем массив с |aᵢ| ≤ 10⁶ и q стартовых значений
с |xᵢ| ≤ 10⁶.

## Выходные данные

Итоговое значение для каждого старта.

## Примеры

### Пример 1

Ввод:

```
3 2
3 1 2
4
-3
```

Вывод:

```
-2
1
```

### Пример 2

Ввод:

```
3 4
2 1 4
10
-5
2
6
```

Вывод:

```
3
2
3
-1
```

## Решение

Обозначим ~x = −x − 1. Один шаг перестановочен с этим отображением:
если x ≥ 0, то ~x < 0 и ~x + a = −(x − a) − 1 = ~(x − a). Значит, весь
путь удовлетворяет f(~x) = ~f(x), и отрицательный старт отвечается
через неотрицательный старт ~x. Остаётся прогнать все старты 0 … V
сразу, V ≤ 10⁶.

Храним отрезок [L, R] стартов, текущие значения которых все по одну
сторону от нуля, так что все они равны старт + offset и шаг двигает
только offset. Когда шаг делает отрезок пересекающим ноль в старте
c = −offset, у стартов меньше c значения отрицательны, а начиная с c —
неотрицательны. Старт s меньше c сейчас хранит
s + offset = ~((2c − 1 − s) + offset), дополнение своего зеркала
2c − 1 − s с другой стороны. Поэтому меньшая сторона отрезается с
пометкой взять дополнение зеркала, которое лежит в остающейся большей
стороне, а раз правило перестановочности выполняется на каждом
следующем шаге, связь сохраняется до конца.

В конце оставшийся отрезок получает старт + offset, а отрезанные куски
заполняются в обратном порядке отрезания, каждый по уже известным
зеркалам. Каждый старт отрезается не больше одного раза.

В первом примере 4 проходит через 1, 0 и −2, а −3 = ~2, где 2 проходит
через −1, 0 и −2, так что −3 заканчивает в ~(−2) = 1.

Проход занимает O(n), заполнение O(V), а запросы O(q).
