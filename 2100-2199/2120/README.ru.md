# 2120. Матожидание веса случайного помеченного дерева с частью фиксированных степеней

[Timus 2120](https://acm.timus.ru/problem.aspx?space=1&num=2120) · сложность 1821 · math, probability

Автор оригинальной задачи — Алексей Данилюк; Петрозаводск лето 2018. t.me/umnik_team Contest.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Вес дерева на вершинах 1 … n — сумма по рёбрам (u, v) величин
u · s(u) + v · s(v), где s(u) — размер части, содержащей u, после
удаления ребра. У части вершин степень фиксирована, у остальных любая.
Выберите дерево с такими степенями равновероятно и выведите целую часть
матожидания его веса. Ограничения: 2 секунды и 64 МБ.

## Входные данные

n, 2 ≤ n ≤ 10⁶, затем a₁ … aₙ: фиксированная степень от 1 до n − 1 или
−1 для любой степени. Сумма |aᵢ| не больше 2n − 2.

Для определения матожидания должно существовать хотя бы одно подходящее
дерево; в оригинальном условии это явно не гарантируется. Если все степени
фиксированы, их сумма должна равняться 2n − 2: например, n = 3 и степени
1, 1, 1 удовлетворяют указанным ограничениям, но дерева нет и матожидание
не определено. При наличии свободной вершины существование уже следует
из ограничения на сумму модулей.

## Выходные данные

Целая часть матожидания веса.

## Примеры

Ввод:

67
```

```

```

```

### Пример 3

Ввод:

```
4
1 1 1 3
```

Вывод:

```
42
```

### Пример 4

Ввод:

```
4
1 1 2 2
```

Вывод:

```
38
```

## Решение

Сгруппируем слагаемые по вершинам. Удаление d рёбер вершины v делит
остальные n − 1 вершин на d ветвей, и на каждом ребре у v остаются все
вершины, кроме этой ветви, так что размеры s(v) по её рёбрам дают в
сумме d · n − (n − 1). Значит, вес зависит только от степеней:

W = Σ v · (n (d_v − 1) + 1) = n(n + 1)/2 + n · Σ v (d_v − 1).

По кодам Прюфера число деревьев со степенями d₁ … dₙ равно
(n − 2)! / ∏ (d_v − 1)!, и оно не меняется, когда свободные вершины
меняются степенями. Поэтому у всех свободных вершин одно и то же
матожидание d_v − 1, а в сумме эти величины дают
R = n − 2 − Σ (фиксированные d_v − 1). Если свободных вершин c и сумма их
номеров S, линейность матожидания даёт

E = n(n + 1)/2 + n · Σ_фикс v (d_v − 1) + n · R · S / c.

Эта формула применяется при c > 0. Если c = 0, последнее слагаемое
пропускается, как в тесте 05; существование дерева тогда требует R = 0.

Дробным может быть только последнее слагаемое; его целая часть считается
точно целочисленным делением. C++, Go и Python сначала делят R · S на c
с остатком, а затем умножают на n. Java и Rust сначала делят S на c
с остатком, а затем умножают на n · R. Оба способа избегают переполнения
знаковых 64-битных чисел. Нельзя отбрасывать остаток до умножения:
тесты 12 и 13 проверяют дробные матожидания. Работа — O(n).

В третьем примере все степени фиксированы, Σ v (d_v − 1) = 4 · 2 = 8, и
W = 10 + 4 · 8 = 42.
