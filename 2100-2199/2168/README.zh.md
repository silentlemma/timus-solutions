# 2168. 用互不相交且带边界的片段覆盖字符串

[Timus 2168](https://acm.timus.ru/problem.aspx?space=1&num=2168) · 难度 3630 · dp, strings

原题作者 Vadim Barinov，出自 2022 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 块符文排成一行，是一个小写字母串。一次可以拿起一段仍在原位的连续符文，条件是这一段的某个真前缀等于同样长度的后缀（这一段有边界，比如 abcdab 或 aa，而 abc 和 a 没有）。求最多能拿起多少块符文。时间限制 2 秒，内存限制 256 MB。

## 输入

N（1 ≤ N ≤ 10⁵），然后是字符串。

## 输出

能拿起的最多符文数。

## 样例

### 样例 1

输入：

```
6
abcdab
```

输出：

```
6
```

### 样例 2

输入：

```
7
abcdabd
```

输出：

```
6
```

### 样例 3

输入：

```
6
abacdc
```

输出：

```
6
```

## 解法

拿起的段是原串中互不相交的区间，所以设 f(i) 为前 i 块中最少留下的符文数，答案为 N − f(N)。区间 [l, e] 有长度为 L 的边界，当且仅当从 l 开始的文本在某个 p > l 处再次出现，且 LCP(l, p) ≥ L、e = p + L − 1。因此起点 l 和之后的匹配位置 p 使 p … p + LCP(l, p) − 1 中的每个终点都可以继承 f(l)，否则 f(i + 1) = f(i) + 1。

有两个事实让规模变小。

- **最多留下 26 块符文。** 从左往右走：若某块符文的字母之后还会出现，就从它开始拿到这个字母最后一次出现处；若之后不再出现，就跳过它。每个字母最多被跳过一次，所以 f 只取 0 … 26。
- **同一个字母只需保留代价递减的起点。** 取字母都为 c 的起点 l₁ < l₂，且 f(l₁) ≤ f(l₂)，以及区间 [l₂, e]，其长度为 L 的边界出现在 p。若 L = 1，则 s[p] = c，[l₁, p] 是边界为 c 的区间，已经以代价 f(l₁) 到达 e。若 L ≥ 2，区间 [l₁, l₂] 给出 f(l₂ + 1) ≤ f(l₁)，而 [l₂ + 1, e] 有在 p + 1 处出现的长度为 L − 1 的边界。对更短的边界重复这一论证，最后到达 L = 1，所以永远不需要 l₂。

于是每个字母保存一个代价严格递减的起点栈，最多 27 个。在位置 p，解法从最新的起点开始扫描字母 s[p] 的栈，用后缀数组在 LCP 数组上求区间最小值得到 LCP(l, p)（Python 用稀疏表，其他语言用线段树），并对每个代价 k 记录代价为 k 的区间能到达的最远终点。更早的起点代价更高，只有 LCP 更长时才有用。然后 f(p + 1) 是记录的终点覆盖 p 的最小代价，否则为 f(p) + 1。

第三个样例中，区间 aba 和 cdc 拿起了全部六块符文。

后缀数组和区间最小值结构用对秩对计数排序需要 O(N log N)（Python 版本直接排序，O(N log² N)），扫描再加 O(27 N)。
