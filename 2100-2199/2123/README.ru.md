# 2123. Число способов набрать массу двумя гирями каждого быстро растущего типа

[Timus 2123](https://acm.timus.ru/problem.aspx?space=1&num=2123) · сложность 1040 · dp

Автор оригинальной задачи — Алексей Данилюк; Петрозаводск лето 2018. t.me/umnik_team Contest.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть n типов гирь с массами a₁ … aₙ, каждый тип хотя бы вдвое тяжелее
предыдущего, и по две гири каждого типа. Посчитайте способы набрать
массу ровно W; способы различаются, если различается число гирь
какого-то типа. Ограничения: 4 секунды и 256 МБ.

## Входные данные

n и W, 1 ≤ n ≤ 60, 0 ≤ W ≤ 4 · 10¹⁸, затем a₁ … aₙ, где 1 ≤ a₁,
2aᵢ ≤ aᵢ₊₁ и aₙ ≤ 10¹⁸.

## Выходные данные

Число способов.

## Примеры

### Пример 1

Ввод:

```
5 100
2 5 10 21 49
```

Вывод:

```
3
```

## Решение

Запишем число гирь типа i как 1 + xᵢ, где xᵢ ∈ {−1, 0, 1}. Если S —
сумма всех масс, способ — это выбор xᵢ с Σ xᵢ aᵢ = W − S. Смена всех
знаков переводит решения для значения в решения для противоположного,
так что достаточно посчитать представления r = |W − S| (а при W > 2S их
нет).

Пойдём от самого тяжёлого типа вниз, храня достижимые остатки с числом
способов. Перед использованием типа i остаток r должен покрываться
типами 1 … i, так что r ≤ Sᵢ — сумме a₁ … aᵢ. Выбор xᵢ превращает r в r
или r − aᵢ, и по той же симметрии знаков r − aᵢ можно заменить на
|r − aᵢ|; r + aᵢ никогда не бывает достаточно мал, ведь более лёгкие
типы в сумме меньше aᵢ. При таких условиях роста 0 дают только все
xᵢ = 0, так что остаток 0 — это один способ, и он сразу идёт в ответ.

Остатки хранятся отсортированными. Оставление сохраняет порядок,
r − aᵢ при r > aᵢ тоже, а aᵢ − r при r ≤ aᵢ его обращает, так что
следующий список — слияние трёх отсортированных потоков со сложением
равных остатков. Каждый тип по меньшей мере вдвое уменьшает границу
остатков и не больше чем вдвое увеличивает число способов, так что
остаток и его счётчик помещаются вместе в одно 64-битное слово. Число
остатков может расти как числа Фибоначчи, но оно ограничено Sᵢ + 1 и
укладывается в ограничения.

В примере три способа: 2 · 5 + 2 · 10 + 21 + 49, 2 + 2 · 49 и
2 · 2 + 5 + 2 · 21 + 49.

## Особенности языков

Решение на Python хранит остатки битсетами по блокам масс, а числа
способов — двоичными битовыми плоскостями, так что шаг — это несколько
сдвигов и масок и побитовое сложение. Когда самые лёгкие типы образуют
точную цепочку удвоения u, 2u, 4u, …, число способов закончить ими —
гипербинарное число, член диатомической последовательности Штерна,
которое считается напрямую вместо развёртывания цепочки.
