# 2113. Наименьшая высота прыжка, чтобы уйти от потопа

[Timus 2113](https://acm.timus.ru/problem.aspx?space=1&num=2113) · сложность 432 · bfs, binary_search

## Задача

Заяц и вода начинают в разных клетках поля n × m с высотами. Они ходят
по очереди, первым заяц. Заяц стоит на месте или прыгает в соседнюю по
стороне клетку, которая выше текущей не более чем на J. Вода заполняет
каждую клетку, у которой есть заполненный сосед не меньшей высоты.
Найдите наименьшую высоту прыжка J, при которой заяц может никогда не
оказаться в воде, или −1, если не подходит никакая. Ограничения:
2 секунды и 256 МБ.

## Входные данные

n и m, 1 ≤ n, m ≤ 100, n · m ≠ 1, высоты 0 ≤ hᵢⱼ ≤ 10⁵, клетка зайца и
клетка воды.

## Выходные данные

Наименьшее J или −1.

## Примеры

### Пример 1

Ввод:

```
2 3
6 5 4
1 2 3
2 1
1 3
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
1 3
0 0 0
1 1
1 3
```

Вывод:

```
-1
```

## Решение

Вода не зависит от зайца, поэтому обход в ширину из её клетки даёт ход
F(c), после которого затоплена каждая клетка c (клетки, куда вода не
доходит, получают бесконечность). Заяц делает свой k-й шаг до k-го хода
воды и во время него ещё стоит там, поэтому стоять на c после k шагов
можно, только если F(c) > k. Ждать не выгодно: прийти раньше никогда не
хуже.

При фиксированном J второй обход из клетки зайца идёт по допустимым
шагам с этими сроками. Заяц выживает ровно тогда, когда обход доходит
до клетки, которая никогда не затопится: любая другая клетка в конце
концов затопится. Большее J разрешает больше шагов, так что выживание
монотонно по J. Если не подходит даже J = 10⁵, ответ −1, иначе
двоичный поиск по J находит наименьшее. Общее время — O(n m log H).

В первом примере вода из правого верхнего угла затапливает весь нижний
ряд, но никогда — клетки высоты 5 и 6. Заяц шагает с высоты 1 на высоту
2 и затем поднимается на три единицы, на высоту 5, как раз перед
приходом воды.
