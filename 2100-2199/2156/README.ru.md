# 2156. Разбиение разностей по кругу на равные половины

[Timus 2156](https://acm.timus.ru/problem.aspx?space=1&num=2156) · сложность 656 · math, constructive

Автор оригинальной задачи — Семён Трифочкин; Уральская командная олимпиада по программированию 2020.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n друзей с интересностями a₁ … aₙ сидят за круглым столом, и разговор
соседей i и i + 1 (n и 1 для последнего) имеет интересность
|aᵢ − aᵢ₊₁|. Разбейте n разговоров на два непустых множества с равной
суммарной интересностью или выведите NO. Подходит любое правильное
разбиение. Ограничения: 1 секунда и 256 МБ.

## Входные данные

n, 3 ≤ n ≤ 10⁵, затем a₁ … aₙ, 1 ≤ aᵢ ≤ 10⁹.

## Выходные данные

YES, затем размер и номера первого множества и второго, или NO.

## Проверка

Проверяющая программа убеждается, что множества непусты, разбивают все
разговоры и имеют равные суммы.

## Примеры

### Пример 1

Ввод:

```
3
1 2 3
```

Вывод:

```
YES
2
1 2
1
3
```

## Решение

Ответ всегда YES. При обходе стола по кругу разности со знаком
aᵢ − aᵢ₊₁ в сумме дают 0. Поэтому разговоры, где значение падает
(aᵢ > aᵢ₊₁), имеют ту же суммарную интересность, что и те, где оно
растёт, а разговоры равных соседей имеют интересность 0 и могут
присоединиться к любой стороне.

Если значения не все равны, есть хотя бы одно падение и один рост, так
что оба множества непусты. Если все равны, каждый разговор имеет
интересность 0, и подходит один разговор против остальных n − 1. Работа
— O(n).

В примере значение падает только с 3 обратно до 1, так что разговор 3
(интересность 2) уравновешивает разговоры 1 и 2 (по 1).

## Оптимизированные решения

`2156_math_constructive_optimized.cpp`. Сохраняется точное разбиение по спускам на круге. Высоты читаются через буфер fread 4 КБ; хранятся только первая и предыдущая высоты, убывающие рёбра отмечаются в bitset. Если все высоты равны, первое ребро выбирается для одной группы. Два прохода по bitset выводят обе группы через буфер fwrite 4 КБ без массива высот и векторов индексов. Время O(n), n бит плюс фиксированные буферы; корректность разбиения и нумерация рёбер не меняются.

Accepted точного исходника №11326979: 0.015 s / 136 KB. Сохранённая выборка G++ 13.2 от 2026-11-20: место по времени 1/33, по памяти 1/33. Учебные исходники сохранены.

Читаем значения по порядку и храним только первое и предыдущее. В битовом наборе отмечаем переходы с убыванием. Два прохода по набору выводят обе группы без массива входных значений и списков индексов.

Go хранит по одному логическому флагу на переход и выводит индексы через буфер фиксированного размера.

Python читает и выводит данные блоками и хранит один байт на переход.

Rust хранит по одному логическому флагу на переход и выводит индексы через буфер фиксированного размера.

Java буферизует ввод и вывод и хранит один логический флаг на переход. Память снизилась с 9008 до 656 КБ, время выросло с 0.140 до 0.156 с.
