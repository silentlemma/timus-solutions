# 2137. 延长二进制串以最大化其各边界的周期数

[Timus 2137](https://acm.timus.ru/problem.aspx?space=1&num=2137) · 难度 4582 · dp, strings

原题作者 Alexey Kotelnikov 和 idea by Mikhail Rubinchik 和 special thanks to Vladislav Isenbaev，出自 “迟到总比不到好”专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

字符串的边界是既是真前缀又是后缀的非空串。字符串的复杂度是其所有边界的不同周期的个数，动态复杂度是其所有前缀的复杂度之和。对二进制串 S 和从 1 到 25 的每个 i，求 |T| = i 时 S + T 的最大动态复杂度。时间限制 2 秒，内存限制 64 MB。

## 输入

S（0 ≤ |S| ≤ 10⁵），由字符 "X" 和 "." 组成。

## 输出

25 个数，即 i = 1 … 25 时的答案。

## 解法

前缀的边界是它的最长边界 π、π 的最长边界，依此类推，也就是前缀函数链。边界 b 的周期为 b − π(b)，沿着这条链，相等的周期成段出现。所以令 rank(0) = 0、rank(b) = rank(π(b)) + [b 的周期与 π(b) 的周期不同]，则最长边界为 π 的前缀的复杂度就是 rank(π)。追加一个字符可以在均摊 O(1) 内更新 π、周期和 rank，再删去字符只是简单截断。

S 的各前缀贡献是固定的，所以问题是选择 T，使新前缀的 rank(π) 之和最大。T 的前一半（大约十几个字符）用这种追加与回退的过程穷举。对 T 的其余部分，下一个最长边界只取决于当前边界和下一个字符，剩下两种情况。

- 最长边界比已构造的文本短：它位于已知文本中，所以下一个边界沿着该文本的 KMP 自动机（两种字符都有转移）前进。对自动机状态做动态规划，记录每个可达状态在每个额外长度上的最优总和。
- 最长边界不短于已构造的文本：这时串有一个不超过剩余字符数的短周期 p。保持这个边界意味着重复这个周期，对边界链上每个这样的 p 直接模拟。在某一步打破周期会使边界落入已知文本，这个状态作为新的起点送入动态规划。

每个长度上见到的最优值就是答案。前一半的穷举以及有限的可达状态数使工作量在限制之内；五种解答在随机串和周期串上都与一个独立的已通过实现一致。

测试 01（样例）中，"X.X" 可以延长一个 "." 得到动态复杂度 2。"X.X." 唯一的边界是周期为 2 的 "X."，所以其复杂度为 1。前缀 "X.X" 由于边界 "X"，复杂度也为 1；其余前缀的贡献为 0。易错点是将最终字符串的复杂度与所有前缀复杂度之和混淆。
