# 2137. Продолжение двоичной строки ради периодов её граней

[Timus 2137](https://acm.timus.ru/problem.aspx?space=1&num=2137) · сложность 6004 · dp, strings

## Задача

Грань строки — собственный непустой префикс, равный суффиксу. Сложность
строки — число различных периодов её граней, а динамическая сложность —
сумма сложностей всех её префиксов. Для двоичной строки S и каждого i
от 1 до 25 найдите наибольшую динамическую сложность строки S + T с
|T| = i. Ограничения: 2 секунды и 64 МБ.

## Входные данные

S, 0 ≤ |S| ≤ 10⁵, из символов «X» и «.».

## Выходные данные

25 чисел — ответы для i = 1 … 25.

## Решение

Грани префикса — его наибольшая грань π, наибольшая грань той и так
далее, то есть цепочка префикс-функции. Период грани b равен b − π(b), и
вдоль цепочки равные периоды идут сериями. Поэтому при rank(0) = 0 и
rank(b) = rank(π(b)) + [период b отличается от периода π(b)] сложность
префикса с наибольшей гранью π равна rank(π). Добавление символа
обновляет π, период и rank за амортизированное O(1), а удаление
символов обратно — простое усечение.

Префиксы S дают постоянный вклад, так что нужно выбрать T, максимизируя
сумму rank(π) по новым префиксам. Первая половина T, около дюжины
символов, перебирается полностью этой процедурой добавления и отката.
Для остальной части T следующая наибольшая грань зависит только от
текущей и следующего символа, и остаются два случая.

- Наибольшая грань короче уже построенного текста: она лежит в
  известном тексте, так что следующая грань идёт по автомату КМП этого
  текста с переходами по обоим символам. Динамика по состояниям автомата
  хранит лучший итог для каждого достижимого состояния и каждой
  дополнительной длины.
- Наибольшая грань не короче построенного текста: тогда у строки есть
  короткий период p, не больше числа оставшихся символов. Сохранение
  этой грани означает повторение периода, что моделируется напрямую для
  каждого такого p вдоль цепочки граней. Нарушение периода на
  каком-то шаге опускает грань в известный текст, и это состояние
  передаётся в динамику как новое начало.

Лучшее значение, встреченное для каждой длины, и есть ответ. Полный
перебор первой половины и ограниченное число достижимых состояний
укладывают работу в ограничения; все пять решений совпадают с
независимой принятой реализацией на случайных и периодических строках.

В примере «X.X» продолжается символом «.» со сложностью 2: префикс
«X.X.» имеет грань «X.» с периодом 2, а сам «X.X» даёт грань «X».
