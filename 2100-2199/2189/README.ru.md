# 2189. Значение, которого нет в наименьшем числе подотрезков, при точечных изменениях

[Timus 2189](https://acm.timus.ru/problem.aspx?space=1&num=2189) · сложность 1061 · fenwick, bitmask

Авторы оригинальной задачи — Артём Абатуров и Артём Степанов; Уральская командная олимпиада по программированию 2024.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В массиве из n ролей выполняются q точечных присваиваний. После каждого
выведите наименьшее по всем x число подотрезков, не содержащих x.
Ограничения: 2 секунды и 256 МБ.

## Входные данные

n и q, 1 ≤ n, q ≤ 10⁵, затем a₁ … a_n с 1 ≤ aᵢ ≤ 10⁹, затем q изменений
s r, задающих a_s = r с 1 ≤ r ≤ 10⁹.

## Выходные данные

Минимум после каждого изменения.

## Примеры

### Пример 1

Ввод:

```
6 5
1 2 3 1 1 2
3 4
5 4
2 1
3 1
6 1
```

Вывод:

```
4
5
4
3
1
```

### Пример 2

Ввод:

```
7 4
2 3 2 3 4 2 3
1 4
4 2
6 5
2 1
```

Вывод:

```
5
5
9
9
```

## Решение

Подотрезки без x — ровно те, что лежат внутри промежутков между
соседними вхождениями x и двумя концами, так что промежуток длины g даёт
g(g + 1) / 2. Отсутствующее значение даёт n(n + 1) / 2, больше
невозможно, так что важны только присутствующие значения.

Удаление вхождения в p сливает два соседних промежутка, и при ближайших
вхождениях ℓ < p < r (или концах 0 и n + 1) число растёт ровно на
(p − ℓ)(r − p); добавление вхождения уменьшает его на то же
произведение. Значит, изменение меняет оценки двух значений на одно
такое произведение каждое, если известны соседи p среди их вхождений.

Все позиции, которые значение когда-либо займёт, известны после чтения
входа, так что каждое значение хранит отсортированные позиции-кандидаты
со структурой, отмечающей текущие: дерево Фенвика с поиском k-й единицы
в компилируемых языках и битсет из 64-битных слов со сводкой непустых
слов в Python. Минимум по значениям — куча пар (оценка, значение), где
устаревшие записи пропускаются, когда оказываются наверху.

В первом примере после первого изменения массив равен
[1, 2, 4, 1, 1, 2], и значение 1 оставляет промежутки длины 2 и 1, что
даёт 3 + 1 = 4.

Каждое присваивание добавляет не более двух записей в кучу. В куче может
быть O(n + q) записей, и каждая удаляется не более одного раза, поэтому
все операции с кучей вместе требуют O((n + q) log(n + q)). С учётом
сортировки и поиска в деревьях Фенвика компилируемые решения работают за
O((n + q) log(n + q)) суммарного времени и используют O(n + q) памяти.
Оценка для кучи амортизированная по изменениям.

В Python сводка — целое произвольной точности длиной не более
B = ceil(n / 64) бит. Операции с ним не являются асимптотически
константными: если учитывать O(B) работы с разрядами фиксированного
размера на операцию, в том числе при построении сводки, безопасная
суммарная оценка — O((n + q)(log(n + q) + B)) при O(n + q) памяти.

Ловушка (тест 06): роли могут исчезать и возвращаться, оставляя в куче
устаревшие оценки. Записи нужно сверять с текущими оценками; нельзя
утверждать O(log n) для каждого изменения, поскольку одна очистка
может удалить много накопленных устаревших записей.
