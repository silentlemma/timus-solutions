# 2189. 单点修改下不出现在最少子段中的值

[Timus 2189](https://acm.timus.ru/problem.aspx?space=1&num=2189) · 难度 1198 · fenwick, bitmask

原题作者 Artyom Abaturov 和 Artyom Stepanov，出自 2024 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对一个长度为 n 的角色数组进行 q 次单点赋值。每次之后，输出在所有 x 中，不包含 x 的子段个数的最小值。时间限制 2 秒，内存限制 256 MB。

## 输入

n 和 q（1 ≤ n, q ≤ 10⁵），然后是 a₁ … a_n（1 ≤ aᵢ ≤ 10⁹），然后是 q 次修改 s r，表示 a_s = r（1 ≤ r ≤ 10⁹）。

## 输出

每次修改后的最小值。

## 样例

### 样例 1

输入：

```
6 5
1 2 3 1 1 2
3 4
5 4
2 1
3 1
6 1
```

输出：

```
4
5
4
3
1
```

### 样例 2

输入：

```
7 4
2 3 2 3 4 2 3
1 4
4 2
6 5
2 1
```

输出：

```
5
5
9
9
```

## 解法

不含 x 的子段恰好是位于 x 相邻两次出现之间或与两端之间的空隙内的子段，所以长为 g 的空隙贡献 g(g + 1) / 2。不出现的值给出 n(n + 1) / 2，这是最大可能值，所以只需考虑出现的值。

删除位置 p 的一次出现会合并它两侧的空隙，设最近的出现为 ℓ < p < r（或两端 0 和 n + 1），个数恰好增加 (p − ℓ)(r − p)；添加一次出现则减少同样的乘积。所以一次修改只让两个值的得分各变化一个这样的乘积，前提是知道 p 在它们出现位置中的邻居。

读完输入后，每个值将来可能占据的所有位置都已知，所以每个值保存排好序的候选位置，并用一个结构标记当前位置：编译型语言中用支持查找第 k 个 1 的树状数组，Python 中用 64 位字组成的位集并附带非空字的摘要。所有值的最小值用 (得分, 值) 的堆维护，过时的条目到达堆顶时跳过。

第一个样例中第一次修改后数组为 [1, 2, 4, 1, 1, 2]，值 1 留下长度为 2 和 1 的空隙，得到 3 + 1 = 4。

每次修改的代价为 O(log n)，Python 的字扫描很短。
