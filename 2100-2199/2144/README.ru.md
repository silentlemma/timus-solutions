# 2144. Порядок запечатанных коробок для одного отсортированного ряда

[Timus 2144](https://acm.timus.ru/problem.aspx?space=1&num=2144) · сложность 221 · sorting

Автор оригинальной задачи — Иван Смирнов; Уральская командная олимпиада по программированию 2019.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть n коробок, в каждой — фиксированный ряд размеров фигурок, который
нельзя ни переставить, ни развернуть. Определите, можно ли расставить
коробки в таком порядке, чтобы все размеры вместе шли по неубыванию.
Ограничения: 0.5 секунды и 256 МБ.

## Входные данные

n, 1 ≤ n ≤ 100, затем для каждой коробки kᵢ, 1 ≤ kᵢ ≤ 100, и её
размеры, 1 ≤ aᵢⱼ ≤ 10⁴.

## Выходные данные

YES или NO.

## Примеры

### Пример 1

Ввод:

```
3
2 1 2
3 7 7 7
1 5
```

Вывод:

```
YES
```

### Пример 2

Ввод:

```
2
2 1 3
1 2
```

Вывод:

```
NO
```

## Решение

Каждая коробка должна быть неубывающей внутри. После этого важны только
её первый размер f и последний размер l, и в правильном порядке l
каждой коробки не больше f следующей.

В любом правильном порядке первые размеры не убывают, ведь f ≤ l ≤ f
следующей коробки. Среди коробок с одинаковым первым размером f у всех,
кроме последней, l ≤ f, то есть l = f. Поэтому сортировка коробок по
(f, l) даёт правильный порядок, если он вообще есть, и достаточно
проверить соседей в этом порядке. Работа — O(Σ kᵢ + n log n).

В первом примере коробки (1, 2), (5, 5) и (7, 7) подходят в этом
порядке; во втором (1, 3) и (2, 2) пересекаются.
