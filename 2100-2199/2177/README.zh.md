# 2177. 相邻两数之和为 X 或 V 的最长不同数序列

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

求一个由互不相同的正整数组成的最长序列，其中每两个相邻数之和为 X 或 V。时间限制 1 秒，内存限制 256 MB。

## 输入

X 和 V（3 ≤ X, V ≤ 10⁹）。

## 输出

最大长度。

## 样例

### 样例 1

输入：

```
10
5
```

输出：

```
4
```

## 解法

长度至少为二的序列只会包含 [1, max(X, V) − 1] 中的数。当 a + b 等于 X 或 V 时连接此范围内不同的 a 和 b。每个数至多有两个搭档 X − a 和 V − a，所以这些数构成互不相交的路径和环，最长序列就是其中最大的连通分量。

设 X ≤ V，d = V − X。若 d = 0，分量是一对数或孤立点；总有一对数存在，因此答案为 2。否则交替使用两种搭档会使数移动 d：a, X − a, a + d, X − a − d, …… 所以一个分量至多位于模 d 的两个剩余类 r 和 X − r 中，范围在 [1, V − 1] 内。当下一个搭档非正，或等于当前数（X / 2 或 V / 2 为整数时），路径就会结束。

- d = 1：只有一个类，即整个范围，共 V − 1 个数。
- d = 2：若 V 为奇数，两个类就是两种奇偶性，答案仍为 V − 1；若 V 为偶数，两种搭档都保持奇偶性，最好的类有 V / 2 个数。
- d ≥ 3：最好的分量取两个不同的类，各有 ⌊(V − 3) / d⌋ + 1 个数，所以答案为 2 (⌊(V − 3) / d⌋ + 1)。

这些公式与对所有小于 60 的 X、V 直接统计分量的结果一致。工作量 O(1)。

样例中 d = 5，序列 8, 2, 3, 7 用到了模 5 余 2 和余 3 的两个类：2 (⌊7 / 5⌋ + 1) = 4。

易错点（测试 03 和 21）：缺少搭档不一定是因为搭档等于自身。测试 03 中 X = 3、V = 4，最长序列 2, 1, 3 在 3 处结束，因为另一个搭档是零。X 和 V 相等且为偶数时，如测试 21，中点也是孤立点，并非每个分量都是一对数。
