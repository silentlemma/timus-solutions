# 2177. Самый длинный ряд различных чисел с суммами соседей X или V

## Задача

Найдите самый длинный ряд различных натуральных чисел, в котором каждые
два соседа дают в сумме X или V. Ограничения: 1 секунда и 256 МБ.

## Входные данные

X и V, 3 ≤ X, V ≤ 10⁹.

## Выходные данные

Наибольшая длина.

## Примеры

### Пример 1

Ввод:

```
10
5
```

Вывод:

```
4
```

## Решение

Соединим a и b, если a + b равно X или V. У каждого числа не больше двух
партнёров, X − a и V − a, так что числа образуют непересекающиеся пути и
циклы, и самый длинный ряд — наибольшая из этих компонент.

Пусть X ≤ V и d = V − X. Если d = 0, каждая компонента — одна пара, и
ответ 2. Иначе чередование двух видов партнёров сдвигает число на d:
a, X − a, a + d, X − a − d, … Значит, компонента лежит в двух классах
вычетов по модулю d, r и X − r, внутри [1, V − 1] и обрывается только на
числах, которые сами себе партнёры, X / 2 и V / 2.

- d = 1: один класс, весь диапазон, V − 1 число.
- d = 2: при нечётном V два класса — две чётности, и ответ снова V − 1;
  при чётном V оба партнёра сохраняют чётность, и в лучшем классе V / 2
  чисел.
- d ≥ 3: лучшая компонента берёт два разных класса по
  ⌊(V − 3) / d⌋ + 1 чисел, так что ответ — 2 (⌊(V − 3) / d⌋ + 1).

Эти формулы совпадают с прямым подсчётом компонент для всех X, V меньше
60. Работа — O(1).

В примере d = 5, и ряд 8, 2, 3, 7 использует классы 2 и 3 по модулю 5:
2 (⌊7 / 5⌋ + 1) = 4.
