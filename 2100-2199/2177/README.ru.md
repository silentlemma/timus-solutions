# 2177. Самый длинный ряд различных чисел с суммами соседей X или V

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Найдите самый длинный ряд различных натуральных чисел, в котором каждые
два соседа дают в сумме X или V. Ограничения: 1 секунда и 256 МБ.

## Входные данные

X и V, 3 ≤ X, V ≤ 10⁹.

## Выходные данные

Наибольшая длина.

## Примеры

### Пример 1

Ввод:

```
10
5
```

Вывод:

```
4
```

## Решение

В ряду длины хотя бы два могут встречаться только числа из
[1, max(X, V) − 1]. Соединим различные a и b из этого диапазона, если
a + b равно X или V. У каждого числа не больше двух партнёров, X − a и
V − a, так что числа образуют непересекающиеся пути и циклы, и самый
длинный ряд — наибольшая из этих компонент.

Пусть X ≤ V и d = V − X. Если d = 0, компоненты — пары или изолированные
вершины; пара всегда существует, поэтому ответ 2. Иначе чередование двух
видов партнёров сдвигает число на d: a, X − a, a + d, X − a − d, …
Значит, компонента лежит не более чем в двух классах
вычетов по модулю d, r и X − r, внутри [1, V − 1]. Путь заканчивается,
когда следующий партнёр неположителен или совпадает с текущим числом
(в точках X / 2 или V / 2, если они целые).

- d = 1: один класс, весь диапазон, V − 1 число.
- d = 2: при нечётном V два класса — две чётности, и ответ снова V − 1;
  при чётном V оба партнёра сохраняют чётность, и в лучшем классе V / 2
  чисел.
- d ≥ 3: лучшая компонента берёт два разных класса по
  ⌊(V − 3) / d⌋ + 1 чисел, так что ответ — 2 (⌊(V − 3) / d⌋ + 1).

Эти формулы совпадают с прямым подсчётом компонент для всех X, V меньше
60. Работа — O(1).

В примере d = 5, и ряд 8, 2, 3, 7 использует классы 2 и 3 по модулю 5:
2 (⌊7 / 5⌋ + 1) = 4.

Ловушка (тесты 03 и 21): отсутствие партнёра не обязательно связано с
совпадением числа с самим собой. В тесте 03, X = 3, V = 4, самый длинный
ряд 2, 1, 3 заканчивается на 3, потому что другой партнёр равен нулю.
При равных чётных суммах, как в тесте 21, середина изолирована;
не каждая компонента является парой.
