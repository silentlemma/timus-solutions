# 2196. День, когда растущая окрестность выпуклого многоугольника достигает точки

Автор оригинальной задачи — Вадим Баринов; Квалификационный тур Уральского регионального чемпионата ICPC 2023.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В день 0 заражён выпуклый многоугольник из N вершин. Каждый следующий
день заражены все точки на некотором расстоянии от многоугольника, а
площадь каждый день удваивается. Для каждой из Q точек найдите первый
день, когда она внутри заражения или на его границе. Точки отстоят от
каждой последующей границы хотя бы на 10⁻⁶. Ограничения: 3 секунды и
256 МБ.

## Входные данные

N, 3 ≤ N ≤ 10⁵, затем вершины против часовой стрелки, затем Q,
1 ≤ Q ≤ 10⁵, и точки, все координаты не больше 10⁹ по модулю.

## Выходные данные

День для каждой точки.

## Примеры

### Пример 1

Ввод:

```
4
1 3
1 1
3 1
3 3
4
2 2
1 2
4 1
6 2
```

Вывод:

```
0
0
2
4
```

## Решение

Множество точек на расстоянии не больше d от выпуклого многоугольника с
площадью A и периметром P имеет площадь A + P d + π d²: сам
многоугольник, полоса вдоль каждой стороны и круговые секторы в углах,
которые в сумме дают полный круг. Значит, у дня i радиус dᵢ — решение
A + P d + π d² = 2ⁱ A, записанное как
dᵢ = (2ⁱ − 1) A / (P/2 + √(P²/4 + π (2ⁱ − 1) A)), чтобы избежать
сокращения. Радиусы превышают наибольшее возможное расстояние примерно
через 70 дней, а точке на расстоянии D от многоугольника отвечает первый
dᵢ ≥ D.

Расстояние до выпуклого многоугольника ищется за O(log N) на точку.
Двоичный поиск по вееру треугольников из вершины 0 определяет, внутри ли
точка (день 0), и если нет — две вершины, отделяющие стороны, обращённые
к точке, от остальных. Вдоль обращённой цепочки расстояние до сторон
сначала убывает, а потом растёт, так что второй двоичный поиск по знаку
проекции находит ближайшую сторону или вершину.

Когда расстояние ближе 10⁻⁵ к радиусу, сравнение повторяется без
корней в арифметике double-double: при расстоянии √(u / v) и
E = (2ⁱ − 1) A точка заражена, когда E v − π u ≥ 0 и
(E v − π u)² ≥ P² u v.

В примере у квадрата A = 4 и P = 8; точка (6, 2) на расстоянии 3, и
день 4 — первый, где 8d + πd² = 60 при d ≈ 3.28.

Всё вместе занимает O(N + Q log N).
