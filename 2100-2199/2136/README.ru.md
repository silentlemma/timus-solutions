# 2136. Наименьшее число кирпичей, чтобы прямоугольник не прошёл по дымоходу

[Timus 2136](https://acm.timus.ru/problem.aspx?space=1&num=2136) · сложность 2330 · two_pointers

Автор оригинальной задачи — Никита Сивухин; Контест "Лучше поздно, чем никогда".

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дымоход — клетчатое поле из h строк ширины w. В строке i слева lᵢ
кирпичей, справа rᵢ, и свободные клетки между ними образуют непустой
отрезок. Прямоугольник a × b начинает над дымоходом и двигается на одну
клетку за раз, не пересекая кирпичей, стараясь выйти снизу. Добавьте
наименьшее число кирпичей, сохранив в каждой строке непустой свободный
отрезок, чтобы он не мог пройти. Ограничения: 1 секунда и 256 МБ.

## Входные данные

h и w, 1 ≤ h ≤ 10⁵, 3 ≤ w ≤ 10⁹, затем a и b, 1 ≤ a ≤ 10⁹,
2 ≤ b ≤ 10⁹, затем пары lᵢ, rᵢ с lᵢ, rᵢ ≥ 1 и lᵢ + rᵢ < w.

## Выходные данные

Наименьшее число кирпичей.

## Примеры

### Пример 1

Ввод:

```
7 5
1 2
2 1
1 1
1 1
1 1
2 1
1 1
1 1
```

Вывод:

```
1
```

## Решение

Пока прямоугольник занимает фиксированный набор из a строк, он свободно
сдвигается вбок в пределах их общей свободной части. Шаг вниз со строк
i … i + a − 1 на строки i + 1 … i + a сохраняет столбцы, так что эти
столбцы должны быть свободны во всех a + 1 строках i … i + a. Если L и
R — наибольшие числа кирпичей слева и справа в таком окне из a + 1
строк, шаг возможен ровно при L + R + b ≤ w. Строки над и под дымоходом
пусты, поэтому окна у верха короче, и прямоугольник проходит ровно
тогда, когда каждое окно разрешает свой шаг.

Чтобы его остановить, в одном окне должно стать L + R ≥ w − b + 1.
Добавление кирпичей в одну строку увеличивает L или R по одному, и
свободная клетка в каждой строке остаётся, потому что b ≥ 2, так что
ответ — max(0, w − b + 1 − максимум по окнам (L + R)). Окна из a + 1
строк просматриваются с двумя монотонными деками для максимумов за O(h).

В примере у окна из первых двух строк L + R = 3, а w − b + 1 = 4, так
что ещё один кирпич в одной из этих строк перекрывает путь.
