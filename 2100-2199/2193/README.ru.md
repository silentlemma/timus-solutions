# 2193. Лучшая рифма: длина суффикса, делённая пополам за каждое различие

[Timus 2193](https://acm.timus.ru/problem.aspx?space=1&num=2193) · сложность 1660 · strings

Автор оригинальной задачи — Вадим Баринов; Квалификационный тур Уральского регионального чемпионата ICPC 2022.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Два слова рифмуются на длине суффикса L с оценкой L / 2ᵏ, где k — число
позиций, где различаются их последние L букв, а рифма — лучшая оценка по
всем L. Даны N слов и Q запросов «u v c»: найдите рифму слов u и v после
отрезания c букв с конца у обоих. Принимаются ответы с точностью 10⁻⁶.
Ограничения: 3 секунды и 256 МБ.

## Входные данные

N и Q, 2 ≤ N ≤ 10⁵, 1 ≤ Q ≤ 10⁵, затем N слов из строчных букв общей
длиной до 10⁶, затем Q запросов с 0 ≤ c < min(|s_u|, |s_v|).

## Выходные данные

Оценка для каждого запроса.

## Примеры

### Пример 1

Ввод:

```
5 7
fate
cmake
stake
cfake
cmate
1 2 0
2 3 0
1 4 0
2 5 0
1 5 0
1 4 1
2 5 2
```

Вывод:

```
1.5
3
2
2.5
3
1.5
3
```

## Решение

Выровняем слова по концам. При фиксированном числе различий k лучше всего
самый длинный суффикс, так что кандидаты — длины прямо перед (k + 1)-м
различием, считая от среза, с оценкой L / 2ᵏ. Первое различие может
стоять прямо у среза, но тогда k = 1 уже даёт не меньше 1/2, а k ≥ 18
даёт меньше 10⁵ / 2¹⁸ < 1/2. Значит, каждый запрос смотрит не больше
18 различий.

Запросы группируются по паре слов, и каждая пара один раз строит позиции
различий своих выровненных концов: компилируемые языки сравнивают буквы
напрямую, а Python делает XOR двух слов, прочитанных как большие числа,
и ищет ненулевые байты. Затем запрос прыгает от различия к различию,
начиная со своего среза, и останавливается, когда даже вся оставшаяся
длина, делённая на следующую степень двойки, не может побить лучшую
оценку. Одинаковые номера слов или совпадающие концы сразу дают всю
оставшуюся длину.

Оценки хранятся точно как кратные 2⁻¹⁸ и печатаются точными десятичными
дробями.

В примере «fate» и «cmake» оканчиваются на «fate» и «make»; с одним
различием суффикс «ate» против «ake» даёт 3/2 = 1.5, лучшее значение.

Пара стоит длину своего более короткого слова, всего не больше примерно
2 · 10⁸ букв по всем различным парам, а запрос — O(18).
