# 2193. 最佳押韵：每有一处不同，后缀长度减半

[Timus 2193](https://acm.timus.ru/problem.aspx?space=1&num=2193) · 难度 1660 · strings

原题作者 Vadim Barinov，出自 2022 年 ICPC 乌拉尔赛区资格赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两个单词在后缀长度 L 上押韵的得分为 L / 2ᵏ，其中 k 是它们最后 L 个字母中不同位置的个数，而它们的押韵程度是所有 L 中的最佳得分。给定 N 个单词和 Q 个查询「u v c」，求把单词 u 和 v 都从末尾切掉 c 个字母后的押韵程度。误差不超过 10⁻⁶ 即可。时间限制 3 秒，内存限制 256 MB。

## 输入

N 和 Q（2 ≤ N ≤ 10⁵，1 ≤ Q ≤ 10⁵），然后是 N 个由小写字母组成、总长不超过 10⁶ 的单词，然后是 Q 个查询，0 ≤ c < min(|s_u|, |s_v|)。

## 输出

每个查询的得分。

## 样例

### 样例 1

输入：

```
5 7
fate
cmake
stake
cfake
cmate
1 2 0
2 3 0
1 4 0
2 5 0
1 5 0
1 4 1
2 5 2
```

输出：

```
1.5
3
2
2.5
3
1.5
3
```

## 解法

把两个单词按末尾对齐。对固定的不同个数 k，后缀越长越好，所以候选长度就是从切口算起第 (k + 1) 个不同位置之前的长度，得分 L / 2ᵏ。第一个不同可能正好在切口处，但那时 k = 1 已经至少得 1/2，而 k ≥ 18 的得分小于 10⁵ / 2¹⁸ < 1/2。所以每个查询至多查看 18 个不同位置。

查询按单词对分组，每对单词只构造一次其对齐末尾的不同位置：编译型语言直接比较字母，Python 把两个单词当作大整数做异或并查找非零字节。然后查询从切口开始在不同位置之间跳跃，当剩余全长除以下一个 2 的幂也无法超过当前最佳得分时停止。相同的单词编号或完全相同的末尾直接给出剩余全长。

得分精确地以 2⁻¹⁸ 的倍数保存，并以精确的十进制小数输出。

样例中 "fate" 和 "cmake" 的末尾为 "fate" 和 "make"；一处不同时后缀 "ate" 对 "ake" 得 3/2 = 1.5，为最佳。

每对单词的代价是较短单词的长度，所有不同的对合计至多约 2 · 10⁸ 个字母，每个查询 O(18)。
