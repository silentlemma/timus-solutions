# 2140. 在体素地图中用最少的行走、跳跃、下落和攀爬到达终点

[Timus 2140](https://acm.timus.ru/problem.aspx?space=1&num=2140) · 难度 1128 · bfs

原题作者 Vadim Barinov，出自 2019 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一张由 A × B × H 个单位立方体组成的地图，格子有空有满。角色站在地面上方的空格里（在最底层，或者下面是实心格），沿四个水平方向用四种动作移动：走到相邻格、跳过中间一个下面空着的空格到两格之外、下落到低一层的相邻格、攀爬到高一层的相邻格，每种动作对哪些格子必须为空各有规定。求从起点到终点的最短动作序列，或者报告 NO。任何最短序列都可接受。时间限制 3 秒，内存限制 256 MB。

## 输入

A、B 和 H（每个不超过 50），地图按从底层往上分成 H 块，每块 A 行、每行 B 个字符，最后是起点和终点。

## 输出

NO，或者 YES、动作数以及形如"类型 方向"的各个动作。

## 评测方式

检查器独立计算最少动作数，并重放提交的路线，检查其合法性和最优性。它不使用存储的答案文件。

## 样例

### 样例 1

输入：

```
1 2 1
..
1 1 1
1 2 1
```

输出：

```
YES
1
walk east
```

### 样例 2

输入：

```
3 4 2
.#..
....
.#..
....
....
....
1 1 1
3 4 1
```

输出：

```
YES
4
climb east
jump south
drop east
walk east
```

## 解法

所有动作耗时相同，所以这是在至多 125 000 个可站立格子上的广度优先搜索，每个格子至多有 16 种动作：四种类型乘以四个方向。每种动作严格按题意检查相关格子：

- 行走：相邻格是可站立的格子；
- 跳跃：相邻格及其下方的格子都为空，且两步之外的格子可站立；
- 下落：相邻格为空，且它下方的格子可站立；
- 攀爬：角色头顶的格子为空，且与该格相邻的格子可站立。

在地图周围加一圈实心格就不必检查边界；一个格子在地面上方，当它为空且下方为实心，最底层下面的那圈也算实心。搜索记录第一次到达每个格子的动作，再从终点倒推出路线。工作量 O(A B H)。

第二个样例中角色爬上墙，跳过空的中间格，再下落回去并走到终点，共四步。
