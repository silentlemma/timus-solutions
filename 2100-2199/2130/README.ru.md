# 2130. Число, согласованное с ответами о делимости

[Timus 2130](https://acm.timus.ru/problem.aspx?space=1&num=2130) · сложность 961 · math, number_theory

Авторы оригинальной задачи — Кирилл Бороздин и Никита Сивухин; подготовка — Владимир Лесков. Контест "Лучше поздно, чем никогда".

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Загаданное целое x лежит от 1 до 10¹². Каждый из n ходов сообщает,
делится ли x на некоторое dᵢ. После каждого хода выведите любое число из
того же диапазона, согласованное со всеми ответами, или −1, если такого
нет. Подходит любое такое число. Ограничения: 2.5 секунды и 256 МБ.

## Входные данные

n, 1 ≤ n ≤ 10⁵, затем n пар dᵢ, tᵢ с 1 ≤ dᵢ ≤ 10⁶; tᵢ = 1 означает «да».

## Выходные данные

Подходящее число или −1 после каждого хода.

## Проверка

Проверяющая программа сама определяет для каждого хода, существует ли
подходящее число, и сверяет каждое выведенное число с ответами на тот
момент.

## Примеры

### Пример 1

Ввод:

```
3
10 1
5 0
100500 0
```

Вывод:

```
100500
-1
-1
```

### Пример 2

Ввод:

```
6
2 1
5 0
3 1
1 1
5 1
100500 0
```

Вывод:

```
12
12
12
12
-1
-1
```

### Пример 3

Ввод:

```
6
1000000 1
999999 1
2 0
999998 1
999997 1
999996 1
```

Вывод:

```
999999000000
999999000000
-1
-1
-1
-1
```

## Решение

Любое подходящее число кратно L — наименьшему общему кратному делителей
с ответом «да». Само L — лучший кандидат: если подходящее x существует,
то L делит x, а делитель d с ответом «нет» не делит x, значит, не делит и
L. Поэтому ответ — L, когда L ≤ 10¹² и ни один делитель с ответом «нет»
не делит L, и −1 иначе; став −1, ответ так и остаётся, ведь ответы
только добавляют условия.

Новый делитель с ответом «нет» проверяется с текущим L один раз. Ответ
«да», не меняющий L, ничего не меняет, а изменение L по меньшей мере
удваивает его, так что L меняется не больше примерно 40 раз, прежде чем
превысит 10¹². Только тогда все сохранённые делители «нет» проверяются
заново, и общая работа остаётся O(40 n).

Во втором примере 2 и 3 дают L = 6, но 5 — делитель с ответом «нет», а
следующий ответ «да» для 5 делает L = 30, которое делится на 5, так что
ответ становится −1; в образце выведено 12 — другое кратное 6.
