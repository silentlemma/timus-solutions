# 2129. Уплатить сумму ровно l монетами — степенями k

[Timus 2129](https://acm.timus.ru/problem.aspx?space=1&num=2129) · сложность 943 · dp

Автор оригинальной задачи — Даниил Айзенштейн; подготовка — Олег Меркурьев. Контест "Лучше поздно, чем никогда".

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Монеты стоят 1, k, k², k³, … Посчитайте по модулю 10⁹ + 7 мультимножества
ровно из l монет с суммой n. Тестов до 100. Ограничения: 3 секунды и
128 МБ.

## Входные данные

t, 1 ≤ t ≤ 100, затем t строк n, k, l с 1 ≤ n ≤ 10¹⁸, 2 ≤ k ≤ 10¹⁸ и
1 ≤ l ≤ 100.

## Выходные данные

Ответ для каждого теста.

## Примеры

### Пример 1

Ввод:

```
3
12 3 4
7 2 5
7 2 2
```

Вывод:

```
2
1
0
```

## Решение

Меньше всего монет дают цифры dᵢ числа n в системе по основанию k —
s = Σ dᵢ монет. Любой другой способ получается из этого разменом монет:
монета kⁱ превращается в k монет kⁱ⁻¹, добавляя k − 1 монету. Пусть xᵢ —
сколько монет kⁱ разменяно. Итоговые количества равны
dᵢ + k · xᵢ₊₁ − xᵢ, так что разные векторы x дают разные
мультимножества, а x допустим, когда ни одно количество не уходит в
минус: xᵢ ≤ dᵢ + k · xᵢ₊₁. При l монетах размены в сумме дают
B = (l − s) / (k − 1), что должно быть целым неотрицательным, так что
B ≤ 100.

Динамика от старшей цифры вниз хранит (использовано разменов, разменов
на уровне выше) с числом способов. На каждом уровне xᵢ пробегает
0 … min(dᵢ + k · xᵢ₊₁, оставшийся бюджет), так что при фиксированном
числе использованных новое значение зависит лишь от того, насколько
велико xᵢ₊₁; префиксные суммы по предыдущему уровню заполняют каждую
строку за O(B), O(B²) на уровень. Монеты номиналом 1 разменять нельзя, и
ответ — число способов, использующих ровно B разменов. При не более чем
60 цифрах это O(B² log_k n) на тест.

В первом примере 12 = 110 по основанию 3, так что s = 2, и для l = 4
нужен один размен: либо 9 превращается в три тройки, либо одна из троек
— в три единицы; это 3 + 3 + 3 + 3 и 9 + 1 + 1 + 1 из условия.
