# 2129. 用恰好 l 枚 k 的幂面值硬币付款

[Timus 2129](https://acm.timus.ru/problem.aspx?space=1&num=2129) · 难度 943 · dp

原题作者 Daniil Ayzenshteyn（由 Oleg Merkurev 整理），出自 “迟到总比不到好”专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

硬币面值为 1, k, k², k³, …。求恰好由 l 枚硬币组成、总额为 n 的多重集个数，对 10⁹ + 7 取模。至多 100 组测试。时间限制 3 秒，内存限制 128 MB。

## 输入

t（1 ≤ t ≤ 100），然后 t 行 n, k, l，满足 1 ≤ n ≤ 10¹⁸、2 ≤ k ≤ 10¹⁸、1 ≤ l ≤ 100。

## 输出

每组测试的答案。

## 样例

### 样例 1

输入：

```
3
12 3 4
7 2 5
7 2 2
```

输出：

```
2
1
0
```

## 解法

硬币最少的方法来自 n 的 k 进制数位 dᵢ，共 s = Σ dᵢ 枚。其他任何方法都由它通过拆分硬币得到：一枚 kⁱ 变成 k 枚 kⁱ⁻¹，硬币数增加 k − 1。设 xᵢ 为被拆开的 kⁱ 硬币个数。最终数量为 dᵢ + k · xᵢ₊₁ − xᵢ，所以不同的向量 x 给出不同的多重集，而 x 合法当且仅当没有数量变为负数：xᵢ ≤ dᵢ + k · xᵢ₊₁。若共 l 枚硬币，拆分次数之和为 B = (l − s) / (k − 1)，必须是非负整数，因此 B ≤ 100。

从最高位往下做动态规划，状态为（已用拆分次数，上一层的拆分次数），值为方法数。每一层 xᵢ 取遍 0 … min(dᵢ + k · xᵢ₊₁, 剩余预算)，所以在已用次数固定时，新值只取决于 xᵢ₊₁ 的大小；对上一层做前缀和，每行 O(B) 填完，每层 O(B²)。面值为 1 的硬币不能再拆，答案是恰好用了 B 次拆分的方法数。数位至多 60 个，每组测试 O(B² log_k n)。

第一个样例中 12 在 3 进制下为 110，所以 s = 2，l = 4 需要一次拆分：要么把 9 拆成三个 3，要么把一个 3 拆成三个 1，即题面中的 3 + 3 + 3 + 3 和 9 + 1 + 1 + 1。
