# 2109. 一段连续编号顶点的公共祖先

[Timus 2109](https://acm.timus.ru/problem.aspx?space=1&num=2109) · 难度 532 · trees, dp

原题作者 Vladimir Leskov，出自 2016 年乌拉尔联邦大学青少年锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一棵有 n 个顶点的树以顶点 1 为根。路线 [L, R] 从 L 走到 L + 1，再到 L + 2，依此类推直到 R，始终沿树上路径行走。对 q 条路线中的每一条，输出经过的顶点中离根最近的那个。时间限制 4 秒，内存限制 300 MB。

## 输入

n（1 ≤ n ≤ 2 · 10⁵），n − 1 条边，然后是 q（0 ≤ q ≤ 10⁶）以及路线 L ≤ R。

## 输出

每条路线的答案，每行一个。

## 样例

### 样例 1

输入：

```
7
1 2
1 3
2 4
2 5
2 6
3 7
3
4 6
3 4
5 7
```

输出：

```
2
1
1
```

### 样例 2

输入：

```
7
1 3
3 5
5 6
7 5
1 4
2 4
3
4 5
5 6
6 7
```

输出：

```
1
5
5
```

## 解法

路线恰好覆盖连接 L, L + 1, …, R 的最小子树，而该子树中离根最近的顶点就是整段的最近公共祖先。这个祖先是 L ≤ i < R 时各个 LCA(i, i + 1) 中最浅的一个：它们都位于它的子树内，而位于不同子分支的两个顶点之间的路径必须经过它。

所以先离线地用 Tarjan 方法一次求出所有 c(i) = LCA(i, i + 1)：深度优先搜索时，完成的顶点并入其父亲，进入顶点 v 时，已访问的邻居 i ± 1 的代表就是它们的公共祖先。同一顶点的祖先中最浅的那个前序编号最小，所以存下 c(i) 的前序编号，每条路线用稀疏表做区间最小值查询，每次 O(1)。L = R 时答案就是 L 本身。

搜索是迭代的，因为树可能是一条 2 · 10⁵ 个顶点的链。总时间 O(n log n + q)。

第一个样例中路线 4 → 5 → 6 停留在顶点 2 之下，而路线 3 → 4 和 5 → 6 → 7 经过根。
