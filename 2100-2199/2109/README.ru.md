# 2109. Общий предок отрезка подряд идущих вершин

[Timus 2109](https://acm.timus.ru/problem.aspx?space=1&num=2109) · сложность 532 · trees, dp

Автор оригинальной задачи — Владимир Лесков; Чемпионат УрФУ среди юниоров 2016.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано дерево из n вершин с корнем 1. Маршрут [L, R] идёт из L в L + 1,
затем в L + 2 и так далее до R, всегда по путям дерева. Для каждого из q
маршрутов выведите посещённую вершину, ближайшую к корню. Ограничения:
4 секунды и 300 МБ.

## Входные данные

n, 1 ≤ n ≤ 2 · 10⁵, n − 1 ребро, затем q, 0 ≤ q ≤ 10⁶, и маршруты
L ≤ R.

## Выходные данные

Ответ для каждого маршрута, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
7
1 2
1 3
2 4
2 5
2 6
3 7
3
4 6
3 4
5 7
```

Вывод:

```
2
1
1
```

### Пример 2

Ввод:

```
7
1 3
3 5
5 6
7 5
1 4
2 4
3
4 5
5 6
6 7
```

Вывод:

```
1
5
5
```

## Решение

Маршрут проходит ровно минимальное поддерево, соединяющее L, L + 1, …, R,
а ближайшая к корню вершина этого поддерева — наименьший общий предок
всего отрезка. Этот предок — самый высокий из попарных предков
LCA(i, i + 1) при L ≤ i < R: каждый из них лежит в его поддереве, а путь
между двумя вершинами в разных дочерних ветвях обязан пройти через него.

Поэтому c(i) = LCA(i, i + 1) для всех i считается один раз, офлайн,
методом Тарьяна: при обходе в глубину законченная вершина сливается с
родителем, а при входе в вершину v представитель уже посещённого соседа
i ± 1 и есть их общий предок. Среди предков одной вершины самый высокий
имеет наименьший номер в прямом порядке обхода, так что хранится этот
номер для c(i), и каждый маршрут отвечается запросом минимума на отрезке
по разреженной таблице за O(1). Для L = R ответ — сама L.

Обход итеративный, ведь дерево может быть путём из 2 · 10⁵ вершин. Общее
время — O(n log n + q).

В первом примере маршрут 4 → 5 → 6 остаётся ниже вершины 2, а маршруты
3 → 4 и 5 → 6 → 7 проходят через корень.
