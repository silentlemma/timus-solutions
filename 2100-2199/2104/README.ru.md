# 2104. Складывание двусторонней полоски до одного цвета

[Timus 2104](https://acm.timus.ru/problem.aspx?space=1&num=2104) · сложность 375 · games

Автор оригинальной задачи — Никита Сивухин; Чемпионат УрФУ среди юниоров 2016.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У полоски 1 × n клетки окрашены в цвета A и B с обеих сторон. Алиса и
Боб ходят по очереди, первой Алиса; ход складывает полоску пополам
(только при чётной длине) внутрь или наружу. Если после хода полоска с
обеих сторон одного цвета, то A означает победу Алисы, а B — Боба,
независимо от того, кто сложил. Если ходящий не может сложить и никто не
выиграл, это ничья. Кто победит при лучшей игре? Ограничения: 2 секунды
и 64 МБ.

## Входные данные

n ≤ 5·10⁵, затем две стороны строками из A и B.

## Выходные данные

`Alice`, `Bob` или `Draw`.

## Примеры

### Пример 1

Ввод:

```
4
BBAA
BABB
```

Вывод:

```
Bob
```

### Пример 2

Ввод:

```
3
AAA
BBB
```

Вывод:

```
Draw
```

### Пример 3

Ввод:

```
2
AA
BB
```

Вывод:

```
Alice
```

## Решение

Сгиб кладёт правую половину поверх левой или под неё. В одном случае
снаружи оказываются левая половина верхней стороны и перевёрнутая правая
половина верхней стороны, в другом — перевёрнутая правая половина нижней
стороны и левая половина нижней стороны. Грани, оказавшиеся внутри,
больше не видны. Значит, у каждой позиции не больше двух ходов, каждый
делит длину пополам, и в игре не больше log₂ n ≈ 19 уровней.

Хватает обычного минимакса по этому дереву: после каждого сгиба
проверяем, одного ли цвета новая полоска; иначе рекурсивно ходит другой
игрок, а нечётная длина — ничья. Алиса берёт лучший для себя результат,
Боб — лучший для себя, и перебор останавливается, как только ход
выигрывает. На уровне k не больше 2ᵏ полосок длины n / 2ᵏ, так что работа
O(n log n).

В первом примере оба сгиба Алисы оставляют полоски, которые Боб
складывает в B/B, поэтому выигрывает Боб.
