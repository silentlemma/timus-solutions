# 2191. Запись ломаной суммой ровно N модулей со знаками

[Timus 2191](https://acm.timus.ru/problem.aspx?space=1&num=2191) · сложность 2298 · math, constructive

Авторы оригинальной задачи — Валентин Зуев и Вадим Баринов; Квалификационный тур Уральского регионального чемпионата ICPC 2022.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Кусочно-линейная функция задана N вершинами (xᵢ, yᵢ) с возрастающими
xᵢ. Запишите её на [x₁, x_N] в виде ±|a₁x + b₁| ± … ± |a_N x + b_N| ровно
из N слагаемых в формате примеров. Ограничения: 3 секунды и 256 МБ.

## Входные данные

N, 2 ≤ N ≤ 10⁵, затем N вершин с целыми координатами не больше 10⁵ по
модулю.

## Выходные данные

Выражение в одной строке.

## Примеры

### Пример 1

Ввод:

```
2
1 0
2 1
```

Вывод:

```
|1x-1|+|0x+0|
```

### Пример 2

Ввод:

```
2
0 1
1 2
```

Вывод:

```
|1x-0|+|0x+1|
```

### Пример 3

Ввод:

```
3
-1 1
0 -1
1 0
```

Вывод:

```
|1.5x-0|-|0.5x+0.5|-|0x+0.5|
```

## Решение

Пусть sᵢ — наклон i-го отрезка. Во внутренней вершине xᵢ наклон
меняется с sᵢ₋₁ на sᵢ, и слагаемое cᵢ |x − xᵢ| с cᵢ = (sᵢ − sᵢ₋₁) / 2
делает ровно этот излом, ведь его наклон прыгает там на 2cᵢ. N − 2
внутренние вершины занимают N − 2 слагаемых, а на [x₁, x_N] остаётся
линейная функция, которая записывается оставшимися двумя:

- α |x − x₁| на отрезке равно α(x − x₁). Левее всех изломов слагаемые
  изломов дают наклон −Σcᵢ = −(s_last − s₁) / 2, так что
  α = (s₁ + s_last) / 2 возвращает первый наклон.
- Константа β, записанная как |0x + β| со знаком β перед модулем,
  выставляет значение в x₁: β = y₁ − Σ cᵢ (xᵢ − x₁).

Эта сумма выглядит как смесь многих дробей, но преобразование Абеля
превращает Σ (sᵢ − sᵢ₋₁)(xᵢ − x₁) в s_last (x_{N−1} − x₁) − (y_{N−1} − y₁),
потому что каждое sⱼ, умноженное на ширину своего отрезка, — это просто
его подъём. Значит, каждый коэффициент — одна дробь, у которой числитель
и знаменатель — произведения не более двух разностей координат, и при
|xᵢ| до 10⁵ даже bᵢ = −cᵢ xᵢ помещается в 64 бита.

Каждая дробь печатается точно делением в столбик с 18 знаками после
запятой без хвостовых нулей, так что выражение отличается не больше чем
примерно на 10⁻¹⁸ на коэффициент. Если же сначала округлить наклоны,
ошибки накапливались бы вдоль ломаной.

В третьем примере наклоны равны −2 и 1, так что излом в 0 — это 1.5|x|,
α = −0.5 и β = 1 − 1.5 = −0.5.

Это O(N) с 18 цифрами на число.
