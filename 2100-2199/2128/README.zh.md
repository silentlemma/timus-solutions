# 2128. 把牌排从牌行移到花色牌堆：拓扑排序

[Timus 2128](https://acm.timus.ru/problem.aspx?space=1&num=2128) · 难度 994 · graphs

原题作者 Alexander Ipatov（由 Oleg Dolgorukov 整理），出自 “迟到总比不到好”专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一副牌有 m 种花色、点数 1 … n，摆成 k 行。一次操作取某一行最右边的牌放到该花色的牌堆上，条件是牌堆顶的牌点数比它小一，或者牌堆为空且这张牌点数为 1。判断能否把所有牌移到牌堆中，并输出一种操作顺序。任何合法顺序都可接受。时间限制 1 秒，内存限制 128 MB。

## 输入

m、n 和 k（1 ≤ n · m ≤ 10⁵，1 ≤ k ≤ 10⁵），然后是各行：aᵢ ≥ 1 以及从左到右的 aᵢ 对（花色，点数），其中 1 ≤ 花色 ≤ m，1 ≤ 点数 ≤ n。所有牌互不相同，合起来构成完整的 n · m 张牌。

## 输出

"NO"，或者 "YES" 以及按移动顺序排列的牌。

## 评测方式

检查器重放这些移动。

## 样例

### 样例 1

输入：

```
2 3 2
3 1 3 2 3 1 1
3 1 2 2 2 2 1
```

输出：

```
YES
1 1
2 1
2 2
2 3
1 2
1 3
```

### 样例 2

输入：

```
2 3 2
3 1 3 2 2 1 2
3 1 1 2 3 2 1
```

输出：

```
NO
```

## 解法

一张牌只能在另外两张牌之后移动（若它们存在）：同花色点数小一的牌必须已在牌堆上，它所在行中右边的牌必须已经移走。条件仅此而已，所以一个移动序列合法，当且仅当每张牌都排在它的两个前驱之后。

这就是一个每张牌至多两条入边的图的拓扑序。Kahn 算法从没有前驱的牌（位于各行最右端的 1 点牌）开始，随着牌变为可用，释放同花色的下一张牌和行中的左邻居。若能到达所有牌，得到的顺序就是答案，否则存在环，答案为 NO。工作量 O(nm + k)。

第二个样例中，花色 1 的 1 点被花色 2 的 3 点挡住，而这张 3 点需要花色 2 的 2 点；那张牌又被花色 1 的 2 点挡住，而这张 2 点需要花色 1 的 1 点：形成环。
