# 2138. Перестановка байтов 32-битного числа

## Задача

Число до 2³² − 1 передаётся четырьмя цифрами по основанию 256.
«Хорошие» компьютеры читают цифры со старшей, «плохие» — с младшей.
Компьютер одного типа получил число от компьютера другого типа и прочёл
его как v. Выведите число, которое было отправлено на самом деле.
Ограничения: 0.5 секунды и 256 МБ.

## Входные данные

Тип отправителя, GOOD или BAD, затем v, 0 ≤ v ≤ 4 294 967 295.

## Выходные данные

Отправленное число.

## Примеры

### Пример 1

Ввод:

```
GOOD
16777216
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
BAD
1000
```

Вывод:

```
3892510720
```

## Решение

Кто бы ни был отправителем, получатель читает те же четыре цифры в
обратном порядке. Поэтому ответ — v с переставленными в обратном порядке
четырьмя цифрами по основанию 256, а тип отправителя неважен. Цифры v
берутся с младшей через % 256 и / 256, а результат собирается со
старшей, или используется перестановка байтов.

В первом примере у 16 777 216 цифры 1;0;0;0, и в обратном порядке они
дают 1.
