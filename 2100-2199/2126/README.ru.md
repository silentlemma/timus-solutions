# 2126. Победа красных: центральные трёхчленные коэффициенты по простому модулю

## Задача

Каждый из n человек независимо идёт в красную команду, в синюю или
становится зрителем, каждое с вероятностью 1/3. Побеждает команда, где
больше игроков. Если t — вероятность победы красных, выведите t · 3ⁿ по
простому модулю p, то есть число из 3ⁿ выборов, в которых красных
больше. Ограничения: 1 секунда и 64 МБ.

## Входные данные

n и p, 1 ≤ n ≤ 10¹⁸, 5 ≤ p < 10⁶, p простое.

## Выходные данные

Это число по модулю p.

## Примеры

### Пример 1

Ввод:

```
5 5
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
5 7
```

Вывод:

```
5
```

## Решение

Перестановка цветов показывает, что красные и синие побеждают одинаково
часто, так что ответ — (3ⁿ − D) / 2, где D — число ничьих. Дадим каждому
человеку вес x за красных, 1 за зрителя и x⁻¹ за синих: D — свободный
член (x + 1 + x⁻¹)ⁿ, центральный трёхчленный коэффициент Tₙ. Деление на
2 — это умножение на (p + 1) / 2.

Поскольку (1 + x + x²)ᵖ ≡ 1 + xᵖ + x²ᵖ по модулю p, эти коэффициенты
обладают свойством Люка: Tₙ — произведение T_d по цифрам d числа n в
системе счисления по основанию p. Цифры меньше p < 10⁶, а Tₖ следует
рекуррентности

(k + 1) T_{k+1} = (2k + 1) Tₖ + 3k T_{k−1}.

Чтобы не делить на каждом шаге, программы ведут Fₖ = k! · Tₖ, для
которых F_{k+1} = (2k + 1) Fₖ + 3k² F_{k−1}, и один раз делят на
факториалы в конце; цифры отсортированы, так что один проход доходит до
всех. Цифра больше (p − 1) / 2 сначала отражается по формуле
T_{p−1−d} ≡ (−3)^{(p−1)/2 − d} T_d (mod p), так что проход не заходит
дальше (p − 1) / 2. 3ⁿ даёт быстрое возведение в степень, а работа —
O(p).

В первом примере T₅ = 51, 3⁵ = 243 и (243 − 51) / 2 = 96 ≡ 1 по модулю 5.
