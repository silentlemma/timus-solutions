# 2116. Компоненты графа обобщённого коня на огромной доске

[Timus 2116](https://acm.timus.ru/problem.aspx?space=1&num=2116) · сложность 870 · dfs

Автор оригинальной задачи — Кирилл Девяткин; Вузовско-академическая олимпиада по информатике 2019.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Обобщённый конь ходит на B клеток вдоль одной оси и на A клеток вдоль
другой. Поставьте на доску N × N как можно больше коней так, чтобы ни
один не мог дойти до клетки другого за любое число ходов. Ограничения:
1 секунда и 256 МБ.

## Входные данные

N, 1 ≤ N ≤ 10⁹, затем A и B, 0 ≤ A ≤ B ≤ 3.

## Выходные данные

Наибольшее число коней.

## Примеры

### Пример 1

Ввод:

```
2
1
1
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
3
0
1
```

Вывод:

```
1
```

## Решение

Два коня должны стоять в разных компонентах связности графа ходов, а по
одному коню на компоненту годится, так что ответ — число компонент. При
A = B = 0 ход никуда не ведёт, каждая клетка — своя компонента, и ответ
— N², которому нужны 64 бита.

Иначе доска огромна, но ходы короткие. Каждая компонента — класс
некоторого инварианта ходов, например чётности x + y при A = B = 1 или
остатков x и y по модулю B при A = 0, и на достаточно большой доске
каждый класс связен. Для каждой из девяти пар (A, B) с B > 0 число компонент
перестаёт меняться с N = 2B: полный перебор всех досок до 40 × 40 это
подтверждает. Поэтому поиск в глубину на доске со стороной min(N, 2B),
не больше 6 × 6, даёт ответ.

Подводный камень: случай A = B = 0 нужно обработать до ограничения размера
доски. Число компонент равно N² и не стабилизируется; в тесте
[25](tests/25.in) N = 2, а ответ равен 4.

В первом примере A = B = 1 — ходы по диагонали: две диагонали доски
2 × 2 разделены, и помещаются два коня. Во втором ходы длины 1 связывают
все клетки доски 3 × 3.
