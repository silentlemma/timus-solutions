# 2116. 巨大棋盘上广义马图的连通分量

[Timus 2116](https://acm.timus.ru/problem.aspx?space=1&num=2116) · 难度 871 · dfs

原题作者 Kirill Deviatkin，出自 2019 年大学学术中学生信息学奥林匹克。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

广义马沿一个坐标轴走 B 格，沿另一个坐标轴走 A 格。在 N × N 棋盘上放尽可能多的马，使得任何一匹马都无法经过若干步到达另一匹马的格子。时间限制 1 秒，内存限制 256 MB。

## 输入

N（1 ≤ N ≤ 10⁹），然后是 A 和 B（0 ≤ A ≤ B ≤ 3）。

## 输出

最多的马数。

## 样例

### 样例 1

输入：

```
2
1
1
```

输出：

```
2
```

### 样例 2

输入：

```
3
0
1
```

输出：

```
1
```

## 解法

两匹马必须位于走法图的不同连通分量中，而每个分量放一匹马是可行的，所以答案就是连通分量的个数。当 A = B = 0 时走一步哪儿也去不了，每个格子自成一个分量，答案为 N²，需要 64 位整数。

否则棋盘很大，但走法很短。每个分量都是走法的某个不变量的一个类，例如 A = B = 1 时 x + y 的奇偶性，或 A = 0 时 x 和 y 模 B 的余数，而棋盘足够大时每个类都是连通的。对十种 (A, B) 中的每一种，分量数从 N = 2B 起不再变化：对不超过 40 × 40 的所有棋盘做穷举搜索证实了这一点。因此在边长为 min(N, 2B)（至多 6 × 6）的棋盘上做一次深度优先搜索即可得到答案。

第一个样例中 A = B = 1 是斜着走：2 × 2 棋盘的两条对角线互不相连，所以能放两匹马。第二个样例中长度为 1 的走法把 3 × 3 棋盘的所有格子连在一起。
