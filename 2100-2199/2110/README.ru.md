# 2110. Наибольшее ИЛИ после удаления ровно k чисел

[Timus 2110](https://acm.timus.ru/problem.aspx?space=1&num=2110) · сложность 1032 · bitmask, dp, backtracking

Автор оригинальной задачи — Алексей Данилюк; Чемпионат УрФУ среди юниоров 2016.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Удалите ровно k из n неотрицательных целых так, чтобы побитовое ИЛИ
оставшихся было как можно больше. В каждом тесте k ≤ 7 или все числа не
больше 10⁵. Ограничения: 2 секунды и 64 МБ.

## Входные данные

n и k, 0 ≤ k ≤ 100, k + 1 ≤ n ≤ 10⁵, затем n чисел, каждое не больше
10⁹.

## Выходные данные

Наибольшее ИЛИ.

## Примеры

### Пример 1

Ввод:

```
4 1
32 16 8 7
```

Вывод:

```
56
```

### Пример 2

Ввод:

```
4 1
98765432 98765432 98765432 1
```

Вывод:

```
98765433
```

## Решение

Пусть F — ИЛИ всех чисел, а r = n − k — сколько чисел остаётся. У
каждого единичного бита F есть свидетель — число, в котором он стоит,
поэтому не больше popcount(F) чисел уже дают F, а остальные места можно
заполнить чем угодно. Значит, при r ≥ popcount(F) ответ — F.

Иначе r < popcount(F) ≤ 30, и остаются два маленьких случая.

- k ≤ 7: тогда n = r + k ≤ 36. Поиск в глубину по числам, отсортированным
  по убыванию, выбирает, какие оставить. Ветка обрывается, когда текущее
  ИЛИ вместе со всеми последующими числами не может превзойти лучший
  результат, и эта верхняя оценка берётся сразу, когда оставшихся мест
  хватает, чтобы выбрать по свидетелю для каждого ещё не набранного бита.
- Числа не больше 10⁵: тогда F < 2¹⁷, r ≤ 16 и n ≤ 116. Рюкзак по маскам
  ИЛИ хранит для каждой маски наименьшее число различных чисел, дающих
  её; маска, достижимая не более чем r числами, допустима, ведь дубликаты
  и другие числа заполняют остальные места, не уменьшая ИЛИ. Маски
  обходятся по убыванию, чтобы каждое число использовалось один раз, и
  цикл останавливается, как только достигнута F.

Во втором примере все копии 98765432 дают одни и те же биты, поэтому
удаление одной копии оставляет 1, и ответ — 98765433.
