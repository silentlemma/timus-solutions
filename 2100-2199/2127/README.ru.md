# 2127. Определитель матрицы смежности почти дерева

[Timus 2127](https://acm.timus.ru/problem.aspx?space=1&num=2127) · сложность 3079 · graphs, matrix

Автор оригинальной задачи — Алексей Данилюк; Петрозаводск лето 2018. t.me/umnik_team Contest.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Связный простой граф имеет n вершин и не больше n + 50 рёбер. Выведите
определитель его матрицы смежности по модулю 998 244 353. Ограничения:
2 секунды и 128 МБ.

## Входные данные

n и m, 1 ≤ n ≤ 2 · 10⁵, n − 1 ≤ m ≤ n + 50, затем m рёбер.

## Выходные данные

Определитель по модулю 998 244 353.

## Примеры

### Пример 1

Ввод:

```
4 3
1 2
2 3
3 4
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
5 10
1 2
1 3
1 4
1 5
2 3
2 4
2 5
3 4
3 5
4 5
```

Вывод:

```
4
```

### Пример 3

Ввод:

```
1 0
```

Вывод:

```
0
```

### Пример 4

Ввод:

```
2 1
2 1
```

Вывод:

```
998244352
```

## Решение

Матрица огромна, поэтому сначала граф уменьшается шагами, которые
меняют определитель известным образом.

- Лист u с соседом v: в строке u единственный ненулевой элемент стоит
  в столбце v, а в столбце u — только в строке v, так что разложение по
  обоим даёт det A = −det A′ без u и v. Это повторяется, пока есть
  листья (граф при этом может распасться на части), а вершина без
  соседей делает определитель равным 0.
- Путь через две вершины степени 2, a и b, x – a – b – y, убирается
  дополнением Шура по {a, b}: блок [[0, 1], [1, 0]] имеет определитель
  −1, а его исключение добавляет ребро веса −1 между x и y. Так что
  каждая пара вершин пути даёт множитель −1 и меняет знак заменяющего её
  ребра. Путь с чётным числом внутренних вершин становится ребром с
  весом, а при нечётном остаётся одна внутренняя вершина.
- Часть, которая является просто циклом длины L, имеет определитель 2
  при нечётном L, 0 при L, кратном 4, и −4 иначе.

После удаления листьев у каждой вершины степень не меньше 2, и раз
m − n ≤ 50, вершин степени больше 2 примерно не больше сотни. Сжатая
матрица содержит эти вершины и по одной оставшейся вершине на нечётный
путь. Строки оставшихся вершин путей ненулевые только в столбцах
вершин ветвления, так что если их больше, чем вершин ветвления, они
линейно зависимы и определитель равен 0. Остальное — метод Гаусса по
простому модулю не больше чем на 200 строках. Общее время —
O(n + m + k³), где k — размер малой матрицы.

В первом примере путь 1 – 2 – 3 – 4 теряет пары (1, 2) и (3, 4) как
листья, что даёт (−1)² = 1. В четвёртом одно ребро даёт −1.
