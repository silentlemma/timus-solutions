# 2127. 近似树的邻接矩阵行列式

[Timus 2127](https://acm.timus.ru/problem.aspx?space=1&num=2127) · 难度 3079 · graphs, matrix

原题作者 Alexey Danilyuk，出自 2018 年夏季彼得罗扎沃茨克集训营 t.me/umnik_team 专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个连通简单图有 n 个顶点，边数至多 n + 50。输出其邻接矩阵的行列式对 998 244 353 取模的结果。时间限制 2 秒，内存限制 128 MB。

## 输入

n 和 m（1 ≤ n ≤ 2 · 10⁵，n − 1 ≤ m ≤ n + 50），然后是 m 条边。

## 输出

行列式对 998 244 353 取模。

## 样例

### 样例 1

输入：

```
4 3
1 2
2 3
3 4
```

输出：

```
1
```

### 样例 2

输入：

```
5 10
1 2
1 3
1 4
1 5
2 3
2 4
2 5
3 4
3 5
4 5
```

输出：

```
4
```

### 样例 3

输入：

```
1 0
```

输出：

```
0
```

### 样例 4

输入：

```
2 1
2 1
```

输出：

```
998244352
```

## 解法

矩阵太大，所以先用一些以已知方式改变行列式的步骤缩小图。

- 叶子 u 及其邻居 v：u 行唯一的非零元素在 v 列，u 列唯一的非零元素在 v 行，沿两者展开得到 det A = −det A′，其中删去了 u 和 v。只要还有叶子就重复（图可能因此分成几块），而没有邻居的顶点使行列式为 0。
- 经过两个度为 2 的顶点 a、b 的路径 x – a – b – y，用关于 {a, b} 的 Schur 补消去：块 [[0, 1], [1, 0]] 的行列式为 −1，消去它会在 x 和 y 之间添加一条权为 −1 的边。所以路径上每消去一对顶点就乘上因子 −1，并翻转替代边的符号。内部顶点数为偶数的路径变成一条带权边，为奇数时保留一个内部顶点。
- 仅由长度为 L 的环构成的一块，其行列式在 L 为奇数时为 2，L 被 4 整除时为 0，否则为 −4。

叶子删完后每个顶点的度至少为 2，又因为 m − n ≤ 50，度大于 2 的顶点大约不超过一百个。压缩后的矩阵包含这些顶点，以及每条奇数路径保留的一个顶点。保留的路径顶点所在的行只在分支顶点的列上非零，所以如果它们比分支顶点多，这些行线性相关，行列式为 0。剩下的就是在至多约 200 行上做模素数的高斯消元。总时间 O(n + m + k³)，k 为小矩阵的大小。

第一个样例中路径 1 – 2 – 3 – 4 作为叶子先后删去 (1, 2) 和 (3, 4)，得到 (−1)² = 1。第四个样例中一条边得到 −1。
