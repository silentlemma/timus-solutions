# 2195. Превращение одного бинарного дерева в другое через путь

[Timus 2195](https://acm.timus.ru/problem.aspx?space=1&num=2195) · сложность 2102 · constructive

Автор оригинальной задачи — Вадим Баринов; Квалификационный тур Уральского регионального чемпионата ICPC 2023.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Два бинарных дерева на N вершинах с корнем 0. Ход берёт некорневую
вершину v с её поддеревом и подвешивает под вершину u вне этого
поддерева, причём дерево должно остаться бинарным. Приведите не больше
N ходов, после которых первое дерево изоморфно второму. Ограничения:
1 секунда и 256 МБ.

## Входные данные

N, 2 ≤ N ≤ 1000, затем родители вершин 1 … N − 1 в первом дереве и во
втором.

## Выходные данные

Число ходов M ≤ N, затем M строк v u.

## Примеры

### Пример 1

Ввод:

```
4
0 0 1
0 1 2
```

Вывод:

```
1
2 3
```

### Пример 2

Ввод:

```
4
2 0 0
0 3 0
```

Вывод:

```
2
3 1
1 0
```

## Решение

Любое бинарное дерево можно вытянуть в путь. Выпишем вершины в прямом
порядке обхода; когда следующая вершина не является ребёнком
предыдущей, подвесим её под предыдущую. При обходе в прямом порядке уже
пройденные вершины образуют путь, а предыдущая вершина — лист, ведь в
прямом порядке за вершиной с детьми идёт её первый ребёнок. Значит, она
получает единственного ребёнка, дерево остаётся бинарным, и предыдущая
вершина не лежит в переносимом поддереве. В конце дерево — путь прямого
обхода.

Ход делается только тогда, когда предыдущая вершина — лист, кроме
последнего, так что дерево с ℓ листьями требует ℓ − 1 ходов, а у
бинарного дерева на N вершинах не больше (N + 1) / 2 листьев.

Второе дерево вытягивается в свой путь так же, и каждый ход можно
отменить, подвесив поддерево обратно, — дерево останется бинарным, ведь
восстанавливается прежнее состояние. Поэтому ответ — ходы для первого
дерева, а затем ходы для второго в обратном порядке, где каждая вершина
второго дерева заменена вершиной первого на том же месте пути. Всего
не больше N − 1 ходов.

Во втором примере первое дерево одним ходом вытягивается в путь
0 → 2 → 1 → 3, и один отменённый ход второго дерева придаёт ему нужную
форму.

Это O(N).
