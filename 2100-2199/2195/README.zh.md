# 2195. 经由一条路径把一棵二叉树变成另一棵

[Timus 2195](https://acm.timus.ru/problem.aspx?space=1&num=2195) · 难度 1537 · constructive

原题作者 Vadim Barinov，出自 2023 年 ICPC 乌拉尔赛区资格赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两棵 N 个顶点的二叉树都以 0 为根。一次操作取一个非根顶点 v 及其子树，把它挂到该子树之外的顶点 u 下面，并且树必须保持二叉。给出至多 N 次操作，使第一棵树与第二棵树同构。时间限制 1 秒，内存限制 256 MB。

## 输入

N（2 ≤ N ≤ 1000），然后是第一棵树和第二棵树中顶点 1 … N − 1 的父亲。

## 输出

操作次数 M ≤ N，然后是 M 行 v u。

## 样例

### 样例 1

输入：

```
4
0 0 1
0 1 2
```

输出：

```
1
2 3
```

### 样例 2

输入：

```
4
2 0 0
0 3 0
```

输出：

```
2
3 1
1 0
```

## 解法

任何二叉树都能拉成一条路径。按先序列出顶点；每当下一个顶点不是前一个顶点的孩子时，就把它挂到前一个顶点下面。按先序进行时，已经经过的顶点构成一条路径，而前一个顶点是叶子，因为先序中有孩子的顶点后面紧跟着它的第一个孩子。所以它得到唯一的孩子，树保持二叉，且前一个顶点不在被移动的子树中。最后整棵树就是先序路径。

只有当前一个顶点是叶子（且不是最后一个叶子）时才操作，所以有 ℓ 片叶子的树需要 ℓ − 1 次操作，而 N 个顶点的二叉树至多有 (N + 1) / 2 片叶子。

第二棵树同样可以拉成它自己的先序路径，而每次操作都能通过把子树挂回原处来撤销，由于恢复的是之前的状态，树仍保持二叉。因此答案是第一棵树的操作，再接上第二棵树的操作的逆序，其中第二棵树的每个顶点都换成第一棵树中路径上同一位置的顶点。总数至多 N − 1。

第二个样例中第一棵树用一次操作拉成路径 0 → 2 → 1 → 3，再撤销第二棵树的一次操作，就得到目标形状。

复杂度 O(N)。
