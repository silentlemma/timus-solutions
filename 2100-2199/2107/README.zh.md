# 2107. 补全 k 秒后复原的跳跃规则

[Timus 2107](https://acm.timus.ru/problem.aspx?space=1&num=2107) · 难度 1523 · dp, graphs

原题作者 Alexey Danilyuk，出自 2016 年乌拉尔联邦大学青少年锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

舞者站在平台 1 … n 上，每一秒平台 i 上的舞者跳到平台 f(i)。f 的一部分值已固定，其余（以 0 给出）可以任意选择。请选择它们，使得 k 秒后每位舞者都回到起始平台，或者报告无法做到。任何合法的补全都可接受。时间限制 2 秒，内存限制 150 MB。

## 输入

n 和 k（1 ≤ n ≤ 35，1 ≤ k ≤ 10⁹），然后是 f(1) … f(n)（0 ≤ f(i) ≤ n）。

## 输出

"No"，或者 "Yes" 和补全后的 f。

## 评测方式

检查器验证输出的 f 保留了固定值，并且 k 秒后所有人都回到原位。

## 样例

### 样例 1

输入：

```
3 4
1 2 3
```

输出：

```
Yes
1 2 3
```

### 样例 2

输入：

```
3 4
0 0 0
```

输出：

```
Yes
1 2 3
```

### 样例 3

输入：

```
3 1
2 2 2
```

输出：

```
No
```

### 样例 4

输入：

```
2 666
2 0
```

输出：

```
Yes
2 1
```

### 样例 5

输入：

```
2 777
2 0
```

输出：

```
No
```

## 解法

k 秒后所有人回到原位，当且仅当 f 是一个排列，且所有环长都整除 k。因此两个指向同一目标的固定值直接得到 "No"，而已经由固定值闭合的环，其长度必须整除 k。

其余固定边构成互不相交的路径；值未定且没有入边的平台是只有一个顶点的路径。补全 f 就是把路径连成环：每条路径的终点指向同组下一条路径的起点。所以要把路径分成若干组，每组的顶点总数整除 k。

只有路径长度有意义，所以状态是每种长度还剩多少条未用路径，用混合进制编码。在总和不超过 35 的情况下，各长度 (数量 + 1) 的乘积不到一千个状态。一个组是总和整除 k 的任意非空子状态。为了不把同一种划分按不同顺序重复计算，一个状态选取的组必须包含该状态中最大长度的一条路径；若存在这样的组使剩余部分可解，则该状态可解。最后回放保存的选择，用实际路径构造出环。

第四个样例中 1 → 2 是两个顶点的路径，666 是偶数，所以环 1 → 2 → 1 可行；而 777 不行。
