# 2107. Достроить правило прыжков, повторяющееся через k секунд

[Timus 2107](https://acm.timus.ru/problem.aspx?space=1&num=2107) · сложность 1488 · dp, graphs

Автор оригинальной задачи — Алексей Данилюк; Чемпионат УрФУ среди юниоров 2016.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Танцоры стоят на платформах 1 … n, и каждую секунду танцор с платформы i
прыгает на платформу f(i). Часть значений f задана, остальные (даны как
0) можно выбрать свободно. Выберите их так, чтобы через k секунд каждый
танцор вернулся на исходную платформу, или сообщите, что это невозможно.
Подходит любое правильное дополнение. Ограничения: 2 секунды и 150 МБ.

## Входные данные

n и k, 1 ≤ n ≤ 35, 1 ≤ k ≤ 10⁹, затем f(1) … f(n), 0 ≤ f(i) ≤ n.

## Выходные данные

«No» или «Yes» и дополненная f.

## Проверка

Проверяющая программа убеждается, что выведенная f сохраняет заданные
значения и через k секунд возвращает всех на места.

## Примеры

### Пример 1

Ввод:

```
3 4
1 2 3
```

Вывод:

```
Yes
1 2 3
```

### Пример 2

Ввод:

```
3 4
0 0 0
```

Вывод:

```
Yes
1 2 3
```

### Пример 3

Ввод:

```
3 1
2 2 2
```

Вывод:

```
No
```

### Пример 4

Ввод:

```
2 666
2 0
```

Вывод:

```
Yes
2 1
```

### Пример 5

Ввод:

```
2 777
2 0
```

Вывод:

```
No
```

## Решение

Все возвращаются через k секунд ровно тогда, когда f — перестановка, у
которой длины всех циклов делят k. Поэтому два заданных значения с одной
целью дают «No», а цикл, уже замкнутый заданными значениями, должен иметь
длину, делящую k.

Остальные заданные рёбра образуют непересекающиеся пути; платформа с
открытым значением и без входящего ребра — путь из одной вершины.
Дополнить f — значит соединить пути в циклы: конец каждого пути указывает
на начало следующего в его группе. Итак, пути нужно разбить на группы,
у которых суммарное число вершин делит k.

Важны только длины путей, поэтому состояние — сколько путей каждой длины
ещё не использовано, закодированное в смешанной системе счисления.
Произведение (количество + 1) по длинам с суммой не больше 35 остаётся
меньше тысячи состояний. Группа — любое непустое подсостояние с суммой,
делящей k. Чтобы не считать одно разбиение в разных порядках, группа для
состояния обязана содержать путь наибольшей присутствующей в нём длины;
состояние разрешимо, если такая группа оставляет разрешимый остаток.
Затем сохранённые выборы проигрываются, и циклы строятся из настоящих
путей.

В четвёртом примере 1 → 2 — путь из двух вершин, а 666 чётно, так что
цикл 1 → 2 → 1 подходит; для 777 — нет.
