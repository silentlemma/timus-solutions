# 2141. 区间的最大交错和

[Timus 2141](https://acm.timus.ru/problem.aspx?space=1&num=2141) · 难度 251 · dp

原题作者 Alexander Lozhkin，出自 2019 年乌拉尔团队程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在序列中选一个连续区间（可以为空），按交替符号求和：选中的第一个元素取正号，第二个取负号，依此类推。求可能的最大值。时间限制 1 秒，内存限制 256 MB。

## 输入

n（1 ≤ n ≤ 10⁵），然后是 a₁ … aₙ（−10⁵ ≤ aᵢ ≤ 10⁵）。

## 输出

最大的交错和（空区间为 0）。

## 评测方式

精确比较完整输出，包括空格和换行。

## 样例

### 样例 1

输入：

```
5
1 2 3 4 5
```

输出：

```
5
```

### 样例 2

输入：

```
5
1 -2 3 -4 5
```

输出：

```
15
```

### 样例 3

输入：

```
5
-1 -2 -3 -4 -5
```

输出：

```
2
```

## 解法

扫描序列，对以当前元素结尾的区间维护两个值：P 为该元素取正号时的最优和，M 为取负号时的最优和。取正号的元素要么开始一个新区间，要么跟在取负号的元素之后，而取负号的元素总是跟在取正号的元素之后：

- P = a + max(0, 上一个 M)，
- M = 上一个 P − a。

第一个元素只能取正号，所以开始时 P = a₁，并令 M 为 0，在下一步中这只表示"重新开始"。答案是出现过的最大的 P 或 M，或者 0。和可达 10¹⁰，所以需要 64 位整数。扫描用时 O(n)。

第二个样例中 1 − (−2) + 3 − (−4) + 5 = 15。

## 优化解法

保留交替符号段的双状态 DP，并允许空答案。新的负状态需要旧的正状态，因此覆盖前先保存旧值。直接比较代替反复辅助调用。有界有符号词元解析不保存全部词元、整数列表及切片，并正确衔接跨缓冲词元。原生求和使用 64 位。
