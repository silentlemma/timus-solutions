# 2141. Наибольшая знакопеременная сумма отрезка

[Timus 2141](https://acm.timus.ru/problem.aspx?space=1&num=2141) · сложность 251 · dp

Автор оригинальной задачи — Александр Ложкин; Уральская командная олимпиада по программированию 2019.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Выберите непрерывный отрезок последовательности, возможно пустой, и
сложите его со знаками по очереди: первый выбранный элемент с плюсом,
второй с минусом и так далее. Найдите наибольшее возможное значение.
Ограничения: 1 секунда и 256 МБ.

## Входные данные

n, 1 ≤ n ≤ 10⁵, затем a₁ … aₙ, −10⁵ ≤ aᵢ ≤ 10⁵.

## Выходные данные

Наибольшая знакопеременная сумма (0 для пустого отрезка).

## Примеры

### Пример 1

Ввод:

```
5
1 2 3 4 5
```

Вывод:

```
5
```

### Пример 2

Ввод:

```
5
1 -2 3 -4 5
```

Вывод:

```
15
```

### Пример 3

Ввод:

```
5
-1 -2 -3 -4 -5
```

Вывод:

```
2
```

## Решение

Последовательность просматривается с двумя значениями для отрезков,
заканчивающихся на текущем элементе: P — лучшая сумма, когда этот
элемент со знаком плюс, и M — когда со знаком минус. Элемент с плюсом
либо начинает новый отрезок, либо идёт после элемента с минусом, а
элемент с минусом всегда идёт после элемента с плюсом:

- P = a + max(0, предыдущее M),
- M = предыдущее P − a.

Первый элемент может быть только с плюсом, поэтому вначале P = a₁, а M
полагается равным 0, что на следующем шаге означает лишь «начать
заново». Ответ — наибольшее встреченное P или M, либо 0. Суммы доходят
до 10¹⁰, так что нужны 64-битные целые. Проход занимает O(n).

Во втором примере 1 − (−2) + 3 − (−4) + 5 = 15.
