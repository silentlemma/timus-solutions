# 2106. 从十六进制字节流解码嵌套结构

[Timus 2106](https://acm.timus.ru/problem.aspx?space=1&num=2106) · 难度 1068 · parsing

原题作者 Mikhail Vyatskov，出自 2016 年乌拉尔联邦大学青少年锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个二进制协议有 n 种结构类型。字段可以是 int（4 字节，大端，无符号）、字符串（先是作为 int 的长度，然后每个小写字母一个字节），或者先前描述过的结构，其字段依次排列。数据流是一串记录：以 int 表示的结构类型编号（从 1 开始），然后是该结构。请把记录输出为带缩进的树。时间限制 2 秒，内存限制 64 MB。

## 输入

n 和 l（1 ≤ n ≤ 240，2n ≤ l ≤ 10³），然后是 l 行描述："struct 名字" 开始一个类型，之后每行在一个空格后给出一个字段的类型。最后一行是大写十六进制的数据流，至多 10⁴ 位。

结构名互不相同，由 1–10 个小写拉丁字母组成，且不能为 "int"、"string" 或 "struct"。每个结构至少有一个字段。

## 输出

每条记录先输出类型名，然后每行一个字段，缩进比所属结构多一个空格："int 值"、"string 文本"，或者嵌套结构的名字，后面跟着它自己的字段。
保证输出大小不超过 30 KB。

## 样例

### 样例 1

输入：

```
2 5
struct a
 string
struct b
 a
 int
000000020000000361626300000004000000010000000568656C6C6F
```

输出：

```
b
 a
  string abc
 int 4
a
 string hello
```

## 解法

把描述读成每个结构的字段类型表，并把十六进制行解码为字节。然后用显式的（结构，下一个字段）栈代替递归遍历数据流，因为结构可以嵌套大约 240 层。每一步取栈顶结构的下一个字段：int 输出一个数，字符串先读长度再读那么多字节，结构则输出名字并入栈。一行的缩进就是栈的深度。所有字段都处理完的结构出栈，栈空时开始下一条记录。

每个字节只读一次，每行输出的代价是其长度，所以工作量与输入和输出呈线性关系。

样例中数据流依次是 2（类型 b）、内部 a 的字符串 "abc"、4，然后是记录 1（类型 a），内容为 "hello"。
