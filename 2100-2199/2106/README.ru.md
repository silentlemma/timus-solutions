# 2106. Расшифровка вложенных структур из потока байт в hex

[Timus 2106](https://acm.timus.ru/problem.aspx?space=1&num=2106) · сложность 1068 · parsing

Автор оригинальной задачи — Михаил Вяцков; Чемпионат УрФУ среди юниоров 2016.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Бинарный протокол знает n типов структур. Поле — это int (4 байта,
старшие вперёд, без знака), строка (её длина как int, затем по байту на
строчную букву) или описанная ранее структура, поля которой идут по
порядку. Поток — последовательность записей: номер типа структуры с
единицы как int, затем сама структура. Выведите записи в виде дерева с
отступами. Ограничения: 2 секунды и 64 МБ.

## Входные данные

n и l, 1 ≤ n ≤ 240, 2n ≤ l ≤ 10³, затем l строк описания: «struct
имя» начинает тип, а каждая следующая строка содержит после пробела тип
одного поля. Последняя строка — поток в hex с заглавными цифрами, не
больше 10⁴ цифр.

Имена структур различны, состоят из 1–10 строчных латинских букв и не
совпадают с «int», «string» или «struct». В каждой структуре есть хотя бы одно поле.

## Выходные данные

Для каждой записи — имя её типа, затем поля по одному в строке с
отступом на пробел больше, чем у владельца: «int значение», «string
текст» или имя вложенной структуры, за которым идут её поля.
Гарантируется, что размер вывода не превышает 30 КБ.

## Примеры

### Пример 1

Ввод:

```
2 5
struct a
 string
struct b
 a
 int
000000020000000361626300000004000000010000000568656C6C6F
```

Вывод:

```
b
 a
  string abc
 int 4
a
 string hello
```

## Решение

Описания читаются в таблицу типов полей для каждой структуры, а
hex-строка превращается в байты. Затем поток обходится с явным стеком
пар (структура, следующее поле) вместо рекурсии, ведь вложенность может
достигать примерно 240 уровней. На каждом шаге берётся следующее поле
верхней структуры: int выводит одно число, строка читает длину и затем
столько байтов, а структура выводит своё имя и кладётся в стек. Отступ
строки — глубина стека. Структура, у которой все поля пройдены,
снимается, а пустой стек начинает следующую запись.

Каждый байт читается один раз, а каждая выведенная строка стоит своей
длины, так что работа линейна по входу и выходу.

В примере поток содержит 2 (тип b), затем строку «abc» внутреннего a,
затем 4, затем запись 1 (тип a) с «hello».
