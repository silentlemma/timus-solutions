# 2147. Самые дешёвые односторонние и двусторонние дороги для всех просьб

[Timus 2147](https://acm.timus.ru/problem.aspx?space=1&num=2147) · сложность 1890 · graphs

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть n домов и m просьб «из a нужен путь в b». Односторонняя дорога
стоит x, двусторонняя — y. Постройте дороги наименьшей общей стоимости
так, чтобы для каждой просьбы был ориентированный путь. Ограничения:
3 секунды и 256 МБ.

## Входные данные

n, m, x и y, 2 ≤ n ≤ 10⁵, 1 ≤ m ≤ 10⁵, 1 ≤ x, y ≤ 10⁹, затем m
различных просьб.

## Выходные данные

Наименьшая стоимость.

## Примеры

### Пример 1

Ввод:

```
4 3 2 3
1 2
1 3
2 3
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
4 3 2 3
1 2
1 3
2 1
```

Вывод:

```
5
```

### Пример 3

Ввод:

```
4 4 2 3
1 2
2 1
1 3
3 1
```

Вывод:

```
6
```

## Решение

Просьбы из разных компонент слабой связности графа просьб никак не
связаны, так что каждая компонента решается отдельно. Пусть в ней V
домов и C компонент сильной связности (КСС).

Если y ≤ x, остовное дерево из двусторонних дорог за (V − 1) · y
обслуживает все просьбы, а дешевле связать V домов вообще нельзя.

Если x < y, есть два кандидата. Один ориентированный цикл через все V
домов, V · x, обслуживает всё. Иначе каждой КСС размера s нужен сильно
связный набор дорог, и двустороннее дерево за (s − 1) · y это даёт; сами
КСС образуют ациклический граф, и односторонние дороги вдоль
топологического порядка КСС, (C − 1) · x, дают все просьбы между ними.
Это (V − C) · y + (C − 1) · x. Смесь двух вариантов, цикл для одних КСС
и деревья для других, никогда не лучше обоих: как только одна КСС
использует цикл, каждая КСС-дерево размера s вместе со своей
соединительной односторонней дорогой стоит (s − 1) · y + x > s · x —
столько стоили бы её дома внутри одного большого цикла. Поэтому ответ для компоненты — более дешёвый кандидат.

КСС находятся алгоритмом Косараю с итеративными обходами, а компоненты
слабой связности — ещё одним обходом в обе стороны, за O(n + m). Суммам
нужны 64-битные целые.

Во втором примере 1 и 2 образуют КСС: двусторонняя дорога (3) и
односторонняя к 3 (2) стоят 5, а цикл через 1, 2 и 3 стоил бы 6.
