# 2147. 满足所有拜访请求的最便宜单向与双向道路

[Timus 2147](https://acm.timus.ru/problem.aspx?space=1&num=2147) · 难度 1890 · graphs

原题作者 Valentin Zuev，出自 2019 年乌拉尔中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 n 座房子和 m 个请求"a 需要一条到 b 的路"。单向路花费 x，双向路花费 y。修建总花费最小的道路，使每个请求都有一条有向路径。时间限制 3 秒，内存限制 256 MB。

## 输入

n、m、x 和 y（2 ≤ n ≤ 10⁵，1 ≤ m ≤ 10⁵，1 ≤ x, y ≤ 10⁹），然后是 m 个互不相同的请求。

## 输出

最小花费。

## 样例

### 样例 1

输入：

```
4 3 2 3
1 2
1 3
2 3
```

输出：

```
4
```

### 样例 2

输入：

```
4 3 2 3
1 2
1 3
2 1
```

输出：

```
5
```

### 样例 3

输入：

```
4 4 2 3
1 2
2 1
1 3
3 1
```

输出：

```
6
```

## 解法

请求图中不同弱连通分量里的请求互不影响，所以每个分量单独求解。设其中有 V 座房子和 C 个强连通分量（SCC）。

若 y ≤ x，用双向路建一棵生成树，花费 (V − 1) · y，满足所有请求，而连通 V 座房子不可能更便宜。

若 x < y，有两个候选。一个经过全部 V 座房子的有向环，花费 V · x，满足一切请求。否则每个大小为 s 的 SCC 需要一组强连通的道路，用双向树花 (s − 1) · y 即可；各 SCC 本身构成一个 DAG，沿 SCC 的拓扑序修单向路，花费 (C − 1) · x，就满足它们之间的所有请求。总计 (V − C) · y + (C − 1) · x。把两者混合——一些 SCC 用环、另一些用树——永远不会比两者都好：只要有一个 SCC 用了环，每个大小为 s 的树形 SCC 连同它那条连接用的单向路花费 (s − 1) · y + x > s · x，而 s · x 正是这些房子放进一个大环里的花费。所以该分量的答案是较便宜的候选。

用迭代搜索实现的 Kosaraju 算法求 SCC，再沿两个方向做一次搜索求弱连通分量，O(n + m)。总和需要 64 位整数。

第二个样例中 1 和 2 构成一个 SCC：一条双向路（3）加一条通往 3 的单向路（2）共花 5，而经过 1、2、3 的环要花 6。
