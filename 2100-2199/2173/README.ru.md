# 2173. Число расстановок спонсоров, не больше двух на задачу

## Задача

Есть M задач и N спонсоров; спонсор i должен появиться ровно в sᵢ
различных задачах, а задача может упоминать не больше двух спонсоров.
Посчитайте расстановки по модулю 10⁹ + 7; расстановки различаются,
если у какой-то задачи другой набор спонсоров. Ограничения: 2 секунды и
256 МБ.

## Входные данные

N и M, 1 ≤ N ≤ 1000, 1 ≤ M ≤ 2000, затем s₁ … s_N, 1 ≤ sᵢ ≤ M, в сумме
не больше 2M.

## Выходные данные

Число расстановок по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
2 2
1 1
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
5 13
1 1 1 1 1
```

Вывод:

```
351780
```

## Решение

Добавляем спонсоров по одному. После того как размещено t упоминаний,
задачи делятся на три группы: в j из них один спонсор, в (t − j) / 2 —
два, остальные пусты. Для следующих спонсоров важно лишь, какая задача
в какой группе, так что состояние — одно j.

Следующий спонсор с пожеланием s занимает a задач, где уже есть один
спонсор, и s − a пустых, что выбирается C(j, a) · C(e, s − a) способами,
где e — число пустых задач. Новое состояние — j − a + (s − a). Ответ —
сумма по всем конечным состояниям.

Состояние имеет чётность t, так что живых состояний не больше M / 2 + 1,
а спонсор с пожеланием s стоит O(M · s) переходов. Всего это
O(M · Σ sᵢ) = O(M²) при один раз подготовленных факториалах и обратных
к ним.

В первом примере два спонсора либо делят одну задачу (два способа), либо
берут по задаче (ещё два), всего четыре.
