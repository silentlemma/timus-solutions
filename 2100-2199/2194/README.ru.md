# 2194. Наименьшее число ходов на доске со змеями, где шестёрка даёт перебросить

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Фишка стоит в клетке 1 доски из N клеток. Бросок k переводит её в
min(i + k, N); попадание в N — победа, а попадание на змею длины pᵢ
отправляет в i − pᵢ, возможно, на другую змею. Шестёрка позволяет
бросить снова в том же ходу. Найдите наименьшее число ходов до победы,
если кубик подыгрывает, или −1. Ограничения: 1 секунда и 256 МБ.

## Входные данные

N, 2 ≤ N ≤ 2 · 10⁵, затем p₂ … p_{N−1} с 0 ≤ pᵢ < i.

## Выходные данные

Наименьшее число ходов или −1.

## Примеры

### Пример 1

Ввод:

```
10
0 1 1 1 1 1 1 0
```

Вывод:

```
-1
```

### Пример 2

Ввод:

```
10
1 2 1 2 0 1 1 1
```

Вывод:

```
1
```

### Пример 3

Ввод:

```
10
1 1 2 2 0 6 7 8
```

Вывод:

```
2
```

## Решение

Змеи отправляют фишку только влево, так что клетка, где она в итоге
остановится после прихода в i, считается один раз слева направо:
land(i) = land(i − pᵢ) или i, если змеи нет.

Теперь состояние — клетка, где предстоит бросить кубик, с числом
начатых ходов. Бросок от одного до пяти заканчивает ход, это ребро веса
1, а шестёрка продолжает ход — ребро веса 0. В начале начат один ход, и
первый бросок, достигающий N, даёт ответ с текущим числом ходов. Поиск
в ширину 0-1 с декой обрабатывает два веса за O(6N).

Во втором примере шестёрка из клетки 1 приводит в 7, змея спускает в 6,
и четвёрка оттуда достигает 10 в том же ходу.
