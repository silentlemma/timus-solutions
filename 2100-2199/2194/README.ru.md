# 2194. Наименьшее число ходов на доске со змеями, где шестёрка даёт перебросить

[Timus 2194](https://acm.timus.ru/problem.aspx?space=1&num=2194) · сложность 495 · bfs

Автор оригинальной задачи — Вадим Баринов; Квалификационный тур Уральского регионального чемпионата ICPC 2023.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Фишка стоит в клетке 1 доски из N клеток. Бросок k переводит её в
min(i + k, N); попадание в N — победа, а попадание на змею длины pᵢ
отправляет в i − pᵢ, возможно, на другую змею. Шестёрка позволяет
бросить снова в том же ходу. Найдите наименьшее число ходов до победы,
если кубик подыгрывает, или −1. Ограничения: 1 секунда и 256 МБ.

## Входные данные

N, 2 ≤ N ≤ 2 · 10⁵, затем p₂ … p_{N−1} с 0 ≤ pᵢ < i.

## Выходные данные

Наименьшее число ходов или −1.

## Примеры

### Пример 1

Ввод:

```
10
0 1 1 1 1 1 1 0
```

Вывод:

```
-1
```

### Пример 2

Ввод:

```
10
1 2 1 2 0 1 1 1
```

Вывод:

```
1
```

### Пример 3

Ввод:

```
10
1 1 2 2 0 6 7 8
```

Вывод:

```
2
```

## Решение

Змеи отправляют фишку только влево, так что клетка, где она в итоге
остановится после прихода в i, считается один раз слева направо:
land(i) = land(i − pᵢ) или i, если змеи нет.

Теперь состояние — клетка, где предстоит бросить кубик, с числом
начатых ходов. Бросок от одного до пяти заканчивает ход, это ребро веса
1, а шестёрка продолжает ход — ребро веса 0. В начале начат один ход, и
первый бросок, достигающий N, даёт ответ с текущим числом ходов. Поиск
в ширину 0-1 с декой обрабатывает два веса за O(6N).

Во втором примере шестёрка из клетки 1 приводит в 7, змея спускает в 6,
и четвёрка оттуда достигает 10 в том же ходу.

## Оптимизированные решения

C++ вычисляет land[i] сразу при чтении левого телепорта, убирая массив прыжков. Поиск идёт слоями ходов: сначала замыкаем все пути бросков шестёрки, расширяя текущую границу, и лишь затем добавляем исходы 1…5 для следующего хода. По индукции первое достижение клетки имеет минимальное число ходов, поэтому вместо расстояний хватает битовой посещённости. Если хотя бы один бросок из клетки достаёт до N, то шестёрка тоже достигает или перелетает N. Поэтому проверка шестёрки в текущем ходу покрывает все победные броски. Старые клетки не раскрываются повторно: их бесплатные и платные переходы рассмотрены раньше. Клетка один раз входит в растущую очередь uint32; два массива занимают O(N), биты O(N/64) слов, время O(6N)=O(N). Простые 0–1 BFS с деком сохранены; остальные четыре семейства используют подходящие базы.

Принятые базовые реализации [2194_bfs.go](2194_bfs.go), [2194_bfs.java](2194_bfs.java), [2194_bfs.py](2194_bfs.py), [2194_bfs.rs](2194_bfs.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
