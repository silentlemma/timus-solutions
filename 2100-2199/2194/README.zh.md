# 2194. 掷出六点可再掷一次的蛇棋最少回合数

[Timus 2194](https://acm.timus.ru/problem.aspx?space=1&num=2194) · 难度 495 · bfs

原题作者 Vadim Barinov，出自 2023 年 ICPC 乌拉尔赛区资格赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

棋子从 N 格棋盘的第 1 格出发。掷出 k 点把它移到 min(i + k, N)；到达 N 即获胜，落在长度为 pᵢ 的蛇上则被送到 i − pᵢ，可能又落在另一条蛇上。掷出六点可以在同一回合内再掷一次。若骰子配合，求获胜所需的最少回合数，否则输出 −1。时间限制 1 秒，内存限制 256 MB。

## 输入

N（2 ≤ N ≤ 2 · 10⁵），然后是 p₂ … p_{N−1}（0 ≤ pᵢ < i）。

## 输出

最少回合数，或者 −1。

## 样例

### 样例 1

输入：

```
10
0 1 1 1 1 1 1 0
```

输出：

```
-1
```

### 样例 2

输入：

```
10
1 2 1 2 0 1 1 1
```

输出：

```
1
```

### 样例 3

输入：

```
10
1 1 2 2 0 6 7 8
```

输出：

```
2
```

## 解法

蛇只会把棋子往左送，所以到达 i 后最终停下的格子可以从左到右一次算出：land(i) = land(i − pᵢ)，没有蛇时为 i。

状态是棋子即将掷骰时所在的格子，以及已经开始的回合数。掷出一到五点结束本回合，是权为 1 的边；掷出六点继续本回合，是权为 0 的边。开始时已开始一个回合，第一次到达 N 的那一掷以当前回合数给出答案。用双端队列做 0-1 广度优先搜索处理这两种权，O(6N)。

第二个样例中从第 1 格掷出六点到达第 7 格，滑到第 6 格，再掷出四点在同一回合内到达第 10 格。
