# 2105. 反向骑行者的相遇次数

[Timus 2105](https://acm.timus.ru/problem.aspx?space=1&num=2105) · 难度 206 · math

原题作者 Nikita Sivukhin，出自 2016 年乌拉尔联邦大学青少年锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两个孩子从同一点出发，沿长为 L 的环形路以速度 v_A 和 v_B 反向骑行 T 秒；有时其中一人会停一会儿。相遇是指他们处在同一点而之前一刻不在一起的时刻。统计相遇次数。时间限制 1 秒，内存限制 64 MB。

## 输入

L ≤ 10⁹，T ≤ 10⁶，v_A, v_B ≤ 10³，然后是 n ≤ 10⁵ 次停留：谁、开始时刻、持续时间；同一孩子的停留互不重叠。

## 输出

相遇次数。

## 样例

### 样例 1

输入：

```
10 10 2 1
3
1 1 1
1 2 2
2 2 1
```

输出：

```
2
```

## 解法

反向骑行时，两人在同一点当且仅当两人共骑过的距离是 L 的倍数。这个距离从 0 开始且不减，所以直到最终距离的每个倍数 kL（k ≥ 1）都恰好到达一次，计为一次相遇，即使两人在那里停留一段时间；起点不算。同一孩子的停留互不重叠，所以每人骑行 T 减去自己停留时长之和，答案为 ⌊(v_A · ride_A + v_B · ride_B) / L⌋，用 64 位整数计算。

样例中 Alice 骑 7 秒，Bob 骑 9 秒，共 2 · 7 + 9 = 23 米，路长 10：相遇两次。
