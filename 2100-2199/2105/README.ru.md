# 2105. Встречи двух велосипедистов, едущих навстречу

[Timus 2105](https://acm.timus.ru/problem.aspx?space=1&num=2105) · сложность 206 · math

Автор оригинальной задачи — Никита Сивухин; Чемпионат УрФУ среди юниоров 2016.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Двое детей едут по кольцевой дорожке длины L в противоположных
направлениях со скоростями v_A и v_B, начав в одной точке, в течение T
секунд; иногда кто-то из них на время останавливается. Встреча — момент,
когда они в одной точке, а перед этим там не были. Посчитайте встречи.
Ограничения: 1 секунда и 64 МБ.

## Входные данные

L ≤ 10⁹, T ≤ 10⁶, v_A, v_B ≤ 10³, затем n ≤ 10⁵ остановок: кто, начало,
длительность; любые две остановки одного ребёнка пересекаются не более чем в одной точке.

## Выходные данные

Число встреч.

## Проверка

Сравнивается один точный целочисленный токен; пробельное оформление несущественно. Новый точный исходник Python прошёл 13 тестов репозитория на PyPy 3.10. Остальные сохранённые варианты имеют собственные проверки целевой среды и точные Accepted. Вывод сравнивается по правилам проверяющего модуля задачи.

## Решение

При езде навстречу двое оказываются в одной точке ровно тогда, когда
проеханное ими вместе расстояние кратно L. Это расстояние не убывает и
начинается с 0, поэтому каждое кратное kL при k ≥ 1 до итогового
расстояния достигается один раз и даёт одну встречу, даже если оба там
постоят; начало не считается. Любые две остановки одного ребёнка пересекаются не более чем в одной точке,
поэтому каждый едет T минус сумма длительностей своих остановок, и ответ
равен ⌊(v_A · ride_A + v_B · ride_B) / L⌋ в 64-битных целых (в Python — произвольной точности).

В примере Алиса едет 7 секунд, а Боб 9, вместе 2 · 7 + 9 = 23 метра по
дорожке длины 10: две встречи.

## Оптимизированные решения

Относительный путь не убывает: берём (speedA+speedB)*T и вычитаем speed*duration для каждой остановки соответствующего велосипедиста. Благодаря непересечению его остановок вычитания точны независимо от времени начала. Каждый новый кратный длине круга уровень даёт одну встречу; стояние на уже достигнутом уровне не создаёт новых. Ответ — частное относительного пути и длины круга. Компактные реализации сохраняют лишь текущую сумму и сразу освобождают записи остановок. Python читает существующие текстовые потоки и считает целыми числами. Все пять понятных версий сохранены.

- `2105_math_optimized.py`: 0.125 s / 264 KB; база `2105_math.py`: 0.062 s / 440 KB; изменение относительно базы: время +101.6%, память -40.0%.
