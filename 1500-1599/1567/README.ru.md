## Задача

Петя набирает речёвку не длиннее 1000 символов на телефоне без
предиктивного ввода и берёт рубль за каждое нажатие. Символ стоит
столько нажатий, каково его место на клавише:

| клавиша | символы |
|-----|------------|
| 1 | a b c |
| 2 | d e f |
| 3 | g h i |
| 4 | j k l |
| 5 | m n o |
| 6 | p q r |
| 7 | s t u |
| 8 | v w x |
| 9 | y z |
| 0 | . , ! |
| # | пробел |

Речёвка состоит из слов из строчных букв, пробелов, запятых, точек и
восклицательных знаков. Нужно вывести её стоимость.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Речёвка в одной строке.

## Выходные данные

Число нажатий.

## Примеры

### Пример 1

Ввод:

```
pokupaite gvozdi tolko v kompanii gvozdederov i tovarischi!
```

Вывод:

```
114
```

## Решение

Таблица сопоставляет каждому символу его место на клавише, считая с 1, и
ответ — сумма по строке. Строка читается целиком, ведь пробелы тоже
стоят нажатия. `O(n)`.

Подводные камни:

- на клавише 9 только y и z, так что z стоит 2 (тест 03);
- пробел — отдельный символ на клавише #, по одному нажатию на каждый,
  даже когда два пробела стоят рядом (тест 05);
- чтение по словам теряет пробелы.

## Оптимизированные решения

Оптимизированное решение на C++ превращает клавиши в таблицу на 256
элементов с числом нажатий для каждого байта, поэтому каждый символ
находится одним обращением, а не поиском по всем клавишам, и читает
строку через `getchar` вместо `getline`: 100 КБ вместо 376 КБ при том же
времени.
