# 1518. Джедайский ребус 3

[Timus 1518](https://acm.timus.ru/problem.aspx?space=1&num=1518) · сложность 1045 · math

Авторы оригинальной задачи — Илья Гребнов, Никита Рыбак и Дмитрий Ковалёв; Timus Top Coders: Third Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны ключи K1 … KN (1 ≤ N ≤ 100, каждый от 0 до 100), а каждый
следующий ключ равен
Ki = (Ki−1·CN + Ki−2·CN−1 + … + Ki−N·C1) mod Y, где сдвиги Ci равны 0
или 1 и 2 ≤ Y < 2²⁸. Нужно найти KX при N < X < 2²⁸.

Ограничение времени: 1.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, X и Y, затем N ключей, затем N сдвигов.

## Выходные данные

KX.

## Примеры

### Пример 1

Ввод:

```
3 6 73
12 91 65
1 1 0
```

Вывод:

```
22
```

## Решение

Если считать от K1, ключ KX — это член номер X − 1 линейной
рекурренты. Её характеристический многочлен — P(x) = x^N − Σ x^(N−j) по
тем j, для которых C(N+1−j) = 1. Вычисляем x^(X−1) по модулю P(x) и Y
быстрым возведением в степень: перемножаем два многочлена степени меньше
N, затем сворачиваем каждый член x^d с d ≥ N, заменяя x^N на сумму
выше. Если x^(X−1) ≡ r0 + r1·x + … + r(N−1)·x^(N−1), то
KX = r0·K1 + r1·K2 + … + r(N−1)·KN mod Y. Каждое произведение стоит
`O(N²)`, а около 2·28 произведений дают `O(N² log X)`, порядка 10⁶
операций; возведение в степень матрицы 100 × 100 потребовало бы около
6·10⁷ умножений.

Подводные камни:

- X доходит до 2²⁸ − 1, поэтому идти по ключам по одному слишком долго
  (gen5);
- произведения меньше 2⁵⁶; 64-битные версии приводят их сразу,
  Python — позже (тест 05, gen5);
- данные ключи могут достигать Y, их тоже нужно привести (тест 07);
- при N = 1 многочлен линейный: x заменяется на C1 (тесты 02, 03);
- если все сдвиги нулевые, все следующие ключи равны 0 (тест 04).
