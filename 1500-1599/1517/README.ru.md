# 1517. Свобода выбора

[Timus 1517](https://acm.timus.ru/problem.aspx?space=1&num=1517) · сложность 240 · suffix_structures

Авторы оригинальной задачи — Илья Гребнов, Никита Рыбак и Дмитрий Ковалёв; Timus Top Coders: Third Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны две речи по N заглавных латинских букв (1 ≤ N ≤ 100000). Нужно
вывести их самый длинный общий фрагмент — самую длинную строку, которая
входит в обе речи как непрерывная часть. Подходит любая самая длинная.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем две речи по одной в строке.

## Выходные данные

Самый длинный общий фрагмент; пустая строка, если общих букв нет.

## Примеры

### Пример 1

Ввод:

```
28
VOTEFORTHEGREATALBANIAFORYOU
CHOOSETHEGREATALBANIANFUTURE
```

Вывод:

```
THEGREATALBANIA
```

## Решение

Строим суффиксный автомат первой речи: его состояния — классы подстрок,
кончающихся в одном и том же множестве позиций; у каждого класса есть
длина самой длинной строки и суффиксная ссылка на класс её более
коротких суффиксов. Состояний не больше 2N, автомат строится по одной
букве за `O(N)`. Затем читаем через него вторую речь, храня состояние и
длину run самого длинного суффикса прочитанной части, который входит в
первую речь. Если у следующей буквы нет перехода, идём по суффиксным
ссылкам, ставя run равным длине каждого достигнутого состояния, пока не
найдётся переход или не дойдём до начала; затем делаем переход и
прибавляем единицу. Наибольшее run и место, где оно закончилось во
второй речи, дают ответ. `O(N)` при алфавите из 26 букв.

Подводные камни:

- у речей может не быть общих букв, тогда ответ — пустая строка
  (тест 03, gen5);
- ответом может быть вся речь (gen4);
- сравнение всех пар позиций — это 10¹⁰ шагов;
- самых длинных фрагментов может быть много, поэтому тесты проверяются
  чекером (все тесты).
