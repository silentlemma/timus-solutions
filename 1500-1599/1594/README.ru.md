# 1594. Сокровища ацтеков

## Задача

Нужно посчитать способы замостить прямоугольник l × w
(1 ≤ l, w ≤ 100) доминошками 1 × 2, по модулю 10⁹ + 7.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

l и w.

## Выходные данные

Число замощений по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
3 4
```

Вывод:

```
11
```

## Решение

Профиль по стороне из 100 клеток имеет 2¹⁰⁰ состояний, так что обычная
динамика не подходит. Формула Кастелейна точно считает замощения доски
m × n:

T = ∏ ∏ (4cos²(jπ/(m + 1)) + 4cos²(kπ/(n + 1))), где j от 1 до ⌈m/2⌉,
а k от 1 до ⌈n/2⌉.

Косинусы — не числа по модулю простого, но всё произведение — да.
Значения 2cos(jπ/(m + 1)), j = 1..m, — корни Sₘ(x) = Uₘ(x/2), многочлена
Чебышёва с S₀ = 1, S₁ = x и Sₖ₊₁ = x·Sₖ − Sₖ₋₁, у которого целые
коэффициенты. Корни идут парами ±x, плюс 0 при нечётном m, поэтому после
лишнего множителя x при нечётном m все степени чётные, и замена x² на y
даёт приведённый целочисленный многочлен Pₘ, корни aⱼ которого — ровно
значения 4cos²(jπ/(m + 1)) из произведения. Если Q — приведённый
многочлен с корнями −bₖ для корней bₖ многочлена Pₙ, то

T = ∏ ∏ (aⱼ + bₖ) = Res(Pₘ, Q),

результант, то есть определитель матрицы Сильвестра двух многочленов.
Её размер не больше 50 + 50, так что метод Гаусса по модулю 10⁹ + 7
работает за `O((l + w)³)`.

Результаты сверены с динамикой по профилю на всех досках до 9 × 14, а на
доске 8 × 8 дают известное 12988816.

Подводные камни:

- при нечётном l·w ответ 0, и формула даёт его сама: у обоих многочленов
  есть корень 0;
- Q(y) = (−1)ᵉ·Pₙ(−y) приведённый; без знака при нечётной степени e
  ответ меняет знак;
- коэффициенты Sₘ быстро растут, поэтому берутся по модулю 10⁹ + 7 на
  каждом шаге.
