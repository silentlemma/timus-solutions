# 1594. 阿兹特克宝藏

[Timus 1594](https://acm.timus.ru/problem.aspx?space=1&num=1594) · 难度 4014 · math

原题作者 Igor Chevdar，出自 2009 年 2 月彼得罗扎沃茨克冬季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

求用 1 × 2 的多米诺骨牌铺满 l × w 矩形（1 ≤ l, w ≤ 100）的方法数，对 10⁹ + 7 取模。

时间限制：1 秒。内存限制：64 MB。

## 输入

l 和 w。

## 输出

铺法数对 10⁹ + 7 取模。

## 样例

### 样例 1

输入:

```
3 4
```

输出:

```
11
```

## 解法

边长为 100 的轮廓有 2¹⁰⁰ 个状态，常规的轮廓动态规划行不通。Kasteleyn 公式精确给出 m × n 棋盘的铺法数：

T = ∏ ∏ (4cos²(jπ/(m + 1)) + 4cos²(kπ/(n + 1)))，其中 j 从 1 到 ⌈m/2⌉，k 从 1 到 ⌈n/2⌉。

因子未必属于素域，但乘积是整数。2cos(jπ/(m + 1))（j = 1..m）是 Sₘ(x) = Uₘ(x/2) 的根，
这是满足 S₀ = 1、S₁ = x、Sₖ₊₁ = x·Sₖ − Sₖ₋₁ 的切比雪夫多项式，系数都是整数。根成对出现 ±x，m 为奇数时还有 0，
所以 m 为奇数时多乘一个 x 后所有次数都是偶数，把 x² 换成 y 就得到首一整系数多项式 Pₘ，它的根 aⱼ 恰好是乘积中的
4cos²(jπ/(m + 1))。设 Q 是以 −bₖ 为根的首一多项式（bₖ 为 Pₙ 的根），则

T = ∏ ∏ (aⱼ + bₖ) = Res(Pₘ, Q)，

即两个多项式的结式，也就是它们 Sylvester 矩阵的行列式。矩阵大小不超过 50 + 50，用模 10⁹ + 7 的高斯消元需要
`O((l + w)³)`。

结果已在所有不超过 9 × 14 的棋盘上与轮廓动态规划对照，8 × 8 棋盘上得到已知的 12988816。

注意事项：

- l·w 为奇数时答案为 0，公式自然给出：两个多项式都有根 0；
- Q(y) = (−1)ᵉ·Pₙ(−y)（e = deg Pₙ）才是首一的；漏掉符号仅在两个次数均为奇数时使答案变号；
- Sₘ 的系数增长很快，每一步都要对 10⁹ + 7 取模。
