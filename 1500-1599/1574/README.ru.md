# 1574. Математики и скобки

[Timus 1574](https://acm.timus.ru/problem.aspx?space=1&num=1574) · сложность 353 · strings

Автор оригинальной задачи — Александр Торопов; XIV открытое командное первенство школьников Свердловской области по программированию, октябрь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дана непустая строка из не более чем 100000 скобок. Нужно посчитать циклические
сдвиги на 0 … n − 1 символов, превращающие её в правильную скобочную
последовательность. Сдвиги на разное число символов считаются отдельно,
даже если дают одну и ту же строку.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Строка скобок.

## Выходные данные

Число таких сдвигов.

## Проверка

Тесты репозитория сравнивают полный текст вывода, игнорируя только конечные пробельные символы. Значимые пробелы, переводы строк, регистр и пунктуация сохраняются.

## Примеры

### Пример 1

Ввод:

```
)(()
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
)()(
```

Вывод:

```
2
```

### Пример 3

Ввод:

```
()
```

Вывод:

```
1
```

## Решение

Если открывающих и закрывающих скобок разное число, ни один сдвиг не
подходит. Иначе возьмём баланс после каждого префикса: открывающие минус
закрывающие. Сдвиг, начинающийся сразу после позиции i, меняет каждый
баланс на −p(i), где p(i) — баланс в этом месте, поэтому он не уходит
ниже нуля ровно тогда, когда p(i) — наименьший из всех балансов. Ответ —
число префиксов с балансом, равным этому минимуму. `O(n)`.

Подводные камни:

- строка вроде `)()(` даёт одну и ту же правильную строку двумя разными
  сдвигами, и оба считаются (второй пример);
- сдвиг на ноль тоже считается (третий пример);
- у несбалансированной строки ответ 0, даже если какой-то сдвиг держит
  все балансы неотрицательными (тесты 04, 05).

## Оптимизированные решения

`1574_strings_optimized.java`. Java сохраняет текущий баланс, минимальный баланс префикса и число попаданий в минимум. Ввод читается блоками по 16384 байта, разделители вне скобочного алфавита пропускаются. Новый минимум обнуляет счёт до единицы, равный минимум увеличивает его. При ненулевом итоговом балансе ответ ноль. Иначе префиксы длины 1..N точно считают допустимые циклические разрезы: полный префикс заменяет пустой, соответствующий тому же разрезу. Строка скобок и массив префиксов не хранятся. Время O(N), дополнительная память O(1) с фиксированным буфером; при N<=100000 счётчики помещаются в int. Учебная версия с массивом и отдельно описанная Python-реализация сохранены.

Accepted точного исходника Java 1.8 №11327330: 0.109 с / 560 КБ. Сохранённое сравнение компиляторов от 2026-11-20: время 5/22, память 2/22. При памяти меньше 1024 КБ строгий допуск учитывает только время: первые десять мест или топ 15%, равенства делят место, процентный порог округляется вверх. Звёздочка остаётся для отдельной цели языка: первого места по обеим метрикам. Прежний документированный оптимизированный запуск №11325019: 0.125 с / 480 КБ; это отдельная историческая пара, не текущий замер данного исходника. Учебные версии сохранены без изменений.

- `1574_strings_optimized.java`: 0.109 s / 560 KB; сохранённая учебная база `1574_strings.java`: 0.125 s / 1196 KB.

`1574_strings_optimized.py`. Сохраняются текущий баланс, минимальный префикс и число попаданий в минимум; ненулевой итог даёт ноль. Для сбалансированной строки исключение пустого префикса по-прежнему даёт точное число допустимых циклических сдвигов. Python теперь читает блоками B=4096 байт вместо целой скобочной строки, без массива или строки длины ввода. Время O(N), буферная память O(B) и ограниченные счётчики; перед прямым выходом вывод сбрасывается. Java уже читает потоково, учебная версия с массивом префиксов сохранена.

Accepted точного исходника CPython 3.12 №11326664: 0.093 с / 676 КБ. Сравнение, сохранённое 2026-11-20 для актуальных компиляторов семейства: место по времени 1/45, по памяти 9/45. При памяти меньше 1024 КБ строгий критерий учитывает только время.

- `1574_strings_optimized.py`: 0.093 s / 676 KB; сохранённая учебная база `1574_strings.py` (Python 3.12 x64): 0.093 s / 5252 KB; изменение времени +0.0%; изменение памяти -87.1%.

`1574_strings_optimized.cpp`. Сохраняется точный подсчёт минимумов префиксного баланса за один проход. Скобки читаются через fread блоками по 16 КБ вместо отдельного блокирующего вызова getchar для каждого символа. Новый меньший баланс сбрасывает счётчик в один, равный минимум увеличивает его. Прочие разделители по-прежнему пропускаются; при ненулевом итоговом балансе выводится ноль. Непустой префикс полной длины представляет циклический разрез в начале строки. Время O(n), фиксированная вспомогательная память.

Accepted точного исходника №11326997: 0.015 s / 92 KB. Сохранённая выборка G++ 13.2 от 2026-11-20: место по времени 1/58, по памяти 1/56. Учебные исходники сохранены.

Прежний документированный замер Python: По сравнению с `1574_strings.py`: время 0.093 s → 0.14 s; память 5252 KB → 1 412 KB.

Версии C++, Go и Rust считают вхождения минимального баланса префикса прямо при чтении. При появлении нового минимума счётчик сбрасывается до единицы. Учитываются префиксы длин от 1 до n. При нулевом итоговом балансе полный префикс заменяет пустой: оба соответствуют одному и тому же циклическому разрезу. C++ использует буферизованный стандартный ввод, Go читает блоками фиксированного размера, Rust читает из буфера стандартного ввода. Время O(n), дополнительная память O(1).

Сохранённые принятые базовые реализации [1574_strings.rs](1574_strings.rs) также проходят строгий критерий быстрого набора в сохранённой выборке: первые десять мест или топ 15% по требуемым метрикам. Они используются без одинаковых копий; остальные учебные исходники сохранены. Звёздочка обозначает отдельную рейтинговую цель языка.

## Особенности языков

Новые исходники сравниваются по срезу от 18 ноября 2026 года с другими авторами на текущих компиляторах судьи. Порогов по ID посылки или дате нет. Ничьи делят место, времена меньше 0.015 с при сравнении считаются 0.015 с. Приведённые ниже места относятся к новым версиям; прежние исходники сохраняют собственные исторические метрики Accepted.

Звёздочка означает недостигнутую рейтинговую цель: для C++ нужны первые десять мест либо топ 15% одновременно по обеим метрикам; для остальных семейств — первое место по обеим. Отдельный критерий допуска может выполняться по рейтингу или улучшению, в том числе при снижении времени либо памяти минимум на 30%.
