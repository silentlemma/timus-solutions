# 1574. Математики и скобки

## Задача

Дана непустая строка из не более чем 100000 скобок. Нужно посчитать циклические
сдвиги на 0 … n − 1 символов, превращающие её в правильную скобочную
последовательность. Сдвиги на разное число символов считаются отдельно,
даже если дают одну и ту же строку.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Строка скобок.

## Выходные данные

Число таких сдвигов.

## Примеры

### Пример 1

Ввод:

```
)(()
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
)()(
```

Вывод:

```
2
```

### Пример 3

Ввод:

```
()
```

Вывод:

```
1
```

## Решение

Если открывающих и закрывающих скобок разное число, ни один сдвиг не
подходит. Иначе возьмём баланс после каждого префикса: открывающие минус
закрывающие. Сдвиг, начинающийся сразу после позиции i, меняет каждый
баланс на −p(i), где p(i) — баланс в этом месте, поэтому он не уходит
ниже нуля ровно тогда, когда p(i) — наименьший из всех балансов. Ответ —
число префиксов с балансом, равным этому минимуму. `O(n)`.

Подводные камни:

- строка вроде `)()(` даёт одну и ту же правильную строку двумя разными
  сдвигами, и оба считаются (второй пример);
- сдвиг на ноль тоже считается (третий пример);
- у несбалансированной строки ответ 0, даже если какой-то сдвиг держит
  все балансы неотрицательными (тесты 04, 05).
