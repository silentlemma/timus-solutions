# 1574. 数学家与括号

[Timus 1574](https://acm.timus.ru/problem.aspx?space=1&num=1574) · 难度 353 · strings

原题作者 Alexander Toropov，出自 2007 年 10 月第十四届斯维尔德洛夫斯克州中学生团体程序设计公开赛（USU Junior Contest）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定一个非空的括号串，长度至多为 100000，统计把它变成正确括号序列的循环移位（移动 0 … n − 1 个字符）的个数。移动字符数不同的
移位分别计数，即使得到的是同一行。

时间限制：1 秒。内存限制：64 MB。

## 输入

一行括号。

## 输出

这样的移位个数。

## 评测方式

仓库测试比较完整输出文本，仅忽略末尾空白。应保留有意义的空格、换行、大小写及标点。

## 样例

### 样例 1

输入:

```
)(()
```

输出:

```
1
```

### 样例 2

输入:

```
)()(
```

输出:

```
2
```

### 样例 3

输入:

```
()
```

输出:

```
1
```

## 解法

如果左括号和右括号个数不同，没有移位可行。否则取每个前缀之后的平衡值：左括号数减右括号数。从位置 i 之后开始的
移位会使每个平衡值都变化 −p(i)（p(i) 为该处的平衡值），所以它不会降到零以下，当且仅当 p(i) 是所有平衡值中的最
小值。答案就是平衡值等于这个最小值的前缀个数。`O(n)`。

注意事项：

- 像 `)()(` 这样的行通过两个不同的移位得到同一个正确的行，两个都算（第二个样例）；
- 移动零个字符也算（第三个样例）；
- 不平衡的行答案只能是 0，即使某个移位让所有平衡值都非负（测试 04、05）。

## 优化解法

`1574_strings_optimized.java`. 在线统计最小前缀余额的出现次数，最终余额非零则输出零。平衡串的最小值不大于零，因此 lowest=0 且不计空前缀仍得到相同循环移位数。Java 直接读括号字节，不保留整行，只需固定输入空间。Python 去掉全部前缀和列表，但仍读入完整字节串，故总空间仍 O(n)，Java 辅助空间 O(1)。两版时间 O(n)。Python 在 os._exit(0) 前刷新答案；运行时退出方式不改变算法复杂度。

C++、Go 和 Rust 版本在读入时统计最小前缀平衡值的出现次数。遇到更小的平衡值时将计数重置为 1。统计长度从 1 到 n 的前缀。总平衡值为零时，完整前缀代替空前缀，两者对应同一个循环切分点。C++ 使用带缓冲的标准输入，Go 读取定长块，Rust 直接使用标准输入缓冲区。时间 O(n)，额外空间 O(1)。
