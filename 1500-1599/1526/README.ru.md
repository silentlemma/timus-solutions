# 1526. Марсианские тарелки

[Timus 1526](https://acm.timus.ru/problem.aspx?space=1&num=1526) · сложность 1326 · dp

Автор оригинальной задачи — Дмитрий Гозман; Dmitry Gozman Contest 1 на Петрозаводских зимних сборах, январь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Праздничный ужин состоит из t/2 блюд (2 ≤ t ≤ 200, t чётно) из n видов
(1 ≤ n ≤ 10), повторы разрешены. Официант приносит блюда и уносит
пустые тарелки; тарелки ставятся стопкой, и унести можно только верхнюю. m пар
(0 ≤ m ≤ 100) «i j» запрещают приносить блюдо j, пока тарелка блюда i
стоит где-либо на столе. Нужно посчитать расписания из t действий
(принести блюдо какого-то вида или унести верхнюю тарелку) по модулю p
(2 ≤ p ≤ 10⁴).

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

p, t, n и m, затем m пар.

## Выходные данные

Число расписаний по модулю p.

## Примеры

### Пример 1

Ввод:

```
10000 4 2 1
1 2
```

Вывод:

```
7
```

### Пример 2

Ввод:

```
9999 6 10 2
2 3
6 7
```

Вывод:

```
4866
```

## Решение

Расписание — это лес тарелок: над каждой тарелкой вложены тарелки,
принесённые, пока она стояла на столе. Можно ли принести блюдо, зависит
только от множества ещё разрешённых видов, которое вначале содержит все
виды, а над тарелкой вида x сужается до своей части, не запрещённой x.
Пусть F[S][q] — число расписаний из q блюд при разрешённом множестве S.
Первая тарелка — это некоторый x из S с a блюдами над ней, их число
F[S ∩ after(x)][a], а остальные q − 1 − a блюд идут за ней при том же
S: F[S][q] = Σ по a от G[S][a] · F[S][q − 1 − a], где
G[S][a] = Σ по x из S от F[S ∩ after(x)][a]. Нужны только множества,
достижимые из полного; меньшее множество считается раньше, а множество
может ссылаться на себя при меньшем q. Не больше 2¹⁰ множеств дают
`O(2^n·t·(n+t))`.

Подводные камни:

- пара запрещает блюдо, пока другая тарелка стоит где угодно на столе,
  а не только сверху (тест 04, gen2);
- пара «i j» запрещает приносить j над i, а не наоборот (тест 08);
- блюдо может быть запрещено над самим собой, тогда его тарелки не
  ставятся друг на друга (тест 05);
- могут встретиться все 1024 множества видов (тест 04, gen2);
- одна и та же пара может быть дана дважды (тест 07).
