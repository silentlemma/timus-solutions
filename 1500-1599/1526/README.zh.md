# 1526. 火星盘子

[Timus 1526](https://acm.timus.ru/problem.aspx?space=1&num=1526) · 难度 1325 · dp

原题作者 Dmitry Gozman，出自 2007 年 1 月彼得罗扎沃茨克冬季集训的 Dmitry Gozman Contest 1。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一顿节日晚餐有 t/2 道菜（2 ≤ t ≤ 200，t 为偶数），从 n 种菜（1 ≤ n ≤ 10）中选，可
以重复。服务员上菜、撤盘；盘子叠放，只能撤最上面的一个。m 对（0 ≤ m ≤ 100）"i j"
表示只要桌上任何位置有菜 i 的盘子，就不能上菜 j。求 t 个动作（上某种菜，或撤掉最上面
的盘子）的安排数，模 p（2 ≤ p ≤ 10⁴）。

时间限制：2 秒。内存限制：64 MB。

## 输入

p、t、n、m，然后是 m 对。

## 输出

安排数模 p。

## 样例

### 样例 1

输入:

```
10000 4 2 1
1 2
```

输出:

```
7
```

### 样例 2

输入:

```
9999 6 10 2
2 3
6 7
```

输出:

```
4866
```

## 解法

一个安排是一片盘子森林：每个盘子上面嵌套着它在桌上时上的盘子。能否上一道菜只取决于
仍被允许的菜的集合，它开始时包含所有种类，在种类 x 的盘子上方缩小为其中不被 x 禁止
的部分。设 F[S][q] 为允许集合为 S 时 q 道菜的安排数。第一个盘子是 S 中某个 x，上面有
a 道菜，数目为 F[S ∩ after(x)][a]，其余 q − 1 − a 道菜在其后，允许集合仍为 S：
F[S][q] = Σ_a G[S][a] · F[S][q − 1 − a]，其中 G[S][a] = Σ_{x∈S} F[S ∩ after(x)][a]。
只需要从全集出发可达的集合；较小的集合先算，一个集合可以在较小的 q 上引用自身。至多
2¹⁰ 个集合，共 `O(2^n·(t/2)²)`。

注意事项：

- 一对限制在另一个盘子位于桌上任何位置时都生效，而不只是在最上面时（测试 04、
  gen2）；
- "i j" 禁止的是在 i 上方上 j，而不是反过来（测试 08）；
- 一道菜可以禁止叠在自己上面，这时它的盘子永不相叠（测试 05）；
- 可能用到全部 1024 个种类集合（测试 04、gen2）；
- 同一对可能出现两次（测试 07）。
