# 1516. 怀旧

[Timus 1516](https://acm.timus.ru/problem.aspx?space=1&num=1516) · 难度 1766 · backtracking

原题作者 Nikita Rybak、Ilya Grebnov 与 Dmitry Kovalioff，出自 Timus Top Coders: Third Challenge。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

8 × 8 的跳棋棋盘上有 1 到 12 枚白子和 1 到 12 枚黑子，都在同一种颜色的格子上。一枚
棋子可以沿任意斜方向吃掉相邻的敌子，前提是该敌子不在棋盘边上，且它后面紧挨的格子为
空：棋子跳到那里，被吃的棋子立即离开棋盘。一步中可以连续吃任意多个。求最少要从棋盘
上拿掉几枚（任意颜色的）棋子，才能让某枚白子一步吃掉剩下的全部黑子。

时间限制：1 秒。内存限制：64 MB。

## 输入

从上到下的 8 行棋盘：'W' 白子，'B' 黑子，'.' 空格。

## 输出

最少要拿掉的棋子数。

## 样例

### 样例 1

输入:

```
W.......
.W......
..B...B.
.....W..
..B.B...
........
........
........
```

输出:

```
1
```

## 解法

拿掉全部黑子总是可行的，所以答案不超过黑子数。否则就是某枚白子连续吃子；从每枚白子
出发用深度优先搜索尝试所有吃法。吃子的棋子离开后它原来的格子就空了。在吃子链上，落
点格子上的白子必须拿掉，代价为一；落点格子上的黑子也必须拿掉，于是它没有被吃。吃子
链没吃到的每枚黑子都必须拿掉，所以搜索中的每个点给出代价
（拿掉的白子）+（黑子数）−（吃掉的黑子）。每次跳跃吃掉不同的黑子，所以一条链最多
12 跳，实际搜索量极小。棋盘用 64 位掩码表示。

注意事项：

- 边上的黑子吃不到，必须拿掉；如果全在边上，答案就是黑子数（测试 02、gen4）；
- 落点格子上的任何颜色的棋子都必须拿掉（测试 04、05）；
- 被吃的棋子立即离开，起始格子也空着，所以吃子链可以绕一圈回到起点（测试 06）；
- 棋子可以都在浅色格子上（测试 07）；
- 必须尝试每一枚白子（测试 08）。
