# 1511. Налоговые операции

[Timus 1511](https://acm.timus.ru/problem.aspx?space=1&num=1511) · сложность 1212 · dp

Авторы оригинальной задачи — Никита Рыбак, Илья Гребнов и Дмитрий Ковалёв; Timus Top Coders: Third Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В декларации указаны три положительных числа A, B и C (каждое меньше
10¹⁰⁰⁰), но A + B ≠ C. Цифру можно заменить на другую со штрафом, равным
модулю разности цифр; длину числа менять нельзя, и первая цифра не может
стать нулём. Нужно найти наименьший общий штраф, при котором A + B = C,
или вывести -1.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

A, B и C, каждое в своей строке.

## Выходные данные

Наименьший общий штраф или -1.

## Примеры

### Пример 1

Ввод:

```
123
554
345
```

Вывод:

```
8
```

## Решение

A и B не могут быть длиннее C, иначе и их сумма была бы длиннее.
Иначе складываем столбиком, как на бумаге, от младшей цифры, с
переносом в качестве состояния: cost[carry] — самое дешёвое исправление
уже пройденных столбцов, которое передаёт этот перенос. В каждом
столбце перебираем цифру x для A и y для B (за пределами длины числа —
только 0, в первой цифре — не 0); цифра C тогда равна
(x + y + carry) mod 10 и не должна быть 0 в первой цифре C, а штраф —
сумма трёх разностей. Ответ — cost[0] после последнего столбца C. Не
больше 2 · 100 переходов на столбец, `O(len(C))` с множителем 200.

Подводные камни:

- первая цифра не может стать нулём, поэтому в 1 + 1 = 1 приходится
  исправлять C на 2 (тест 02);
- C короче A или на две цифры длиннее любой суммы — ответ -1
  (тесты 03, 04, gen3);
- когда C на цифру длиннее, старшие столбцы A и B должны дать перенос
  (тест 06, gen2);
- в числах до 1000 цифр, поэтому они обрабатываются как строки цифр
  (gen1, gen5).
