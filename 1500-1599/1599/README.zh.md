# 1599. 环绕数

[Timus 1599](https://acm.timus.ru/problem.aspx?space=1&num=1599) · 难度 1732 · geometry

原题作者 Vladimir Yakovlev。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一条闭合铁路经过 n 个节点（3 ≤ n ≤ 5000），沿直线轨道行进，轨道可以相交、重叠。对 m 个观察点（1 ≤ m ≤ 5000）中的每一个：
若点在某段轨道上，输出 `EDGE`；否则输出目送火车跑完一圈时人按逆时针方向转了多少整圈，即环绕数。
坐标为绝对值不超过 10⁹ 的整数。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行是 n，接下来 n 行按行进顺序给出节点坐标 x y。轨道连接相邻节点，最后一个节点与第一个节点相连。然后是 m，接下来 m 行给出观察点坐标 x y。

## 输出

每个点单独一行输出 `EDGE` 或有符号的圈数：逆时针为正，顺时针为负。

## 样例

### 样例 1

输入:

```
8
-2 -2
-5 1
-2 4
1 3
-2 0
-3 1
-2 2
1 1
3
-2 1
0 0
1 2
```

输出:

```
-2
EDGE
0
```

## 解法

看从该点向右的射线。火车每次向上穿过它，就从该点旁按逆时针方向经过；向下穿过则是顺时针。所以环绕数等于向上穿过射线的轨道数减去向下穿过的轨道数。
从 a 到 b 的轨道在 a.y ≤ p.y < b.y 且点在其左侧（即 cross(b − a, p − a) > 0）时向上穿过，在 b.y ≤ p.y < a.y 且点在其右侧时向下穿过。
只算每段轨道的下端点而不算上端点，经过节点的穿越恰好计数一次；相切时，两个贡献相互抵消或都不计入。水平轨道不计入环绕数之和。

叉积为 0 且点在轨道的包围盒内时，点在轨道上。对每个点遍历轨道，在统计穿越前先检查此条件；若成立，立即停止并输出 `EDGE`。否则遍历结束后输出总和。最坏时间复杂度为 `O(n·m)`，至多检查 2.5·10⁷ 次轨道，全部是整数运算。

结果已在小路线上与用 atan2 累加转角的做法对照，包括经过各点所在行的路线和来回往返的路线。

注意事项：

- 叉积的绝对值至多为 (2·10⁹)² = 4·10¹⁸，小于有符号 64 位整数的最大值 2⁶³ − 1；32 位整数不够用；
- 射线上的节点处，穿越计数一次，相切的总贡献为零；按 y 的半开区间判断可处理这些情况，水平轨道只影响 `EDGE`；
- 同一轨道上方向相反的两次行进在环绕数之和中抵消，零长度轨道的贡献为零；两者仍须检查 `EDGE`。
