# 1599. 环绕数

[Timus 1599](https://acm.timus.ru/problem.aspx?space=1&num=1599) · 难度 1843 · geometry

原题作者 Vladimir Yakovlev。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一条闭合铁路经过 n 个节点（3 ≤ n ≤ 5000），沿直线轨道行进，轨道可以相交、重叠。对 m 个观察点（m ≤ 5000）中的每一个：
若点在某段轨道上，输出 `EDGE`；否则输出目送火车跑完一圈时人按逆时针方向转了多少整圈，即环绕数。
坐标为绝对值不超过 10⁹ 的整数。

时间限制：1 秒。内存限制：64 MB。

## 输入

n 和各节点，然后是 m 和各观察点。

## 输出

每个点输出 `EDGE` 或转的圈数。

## 样例

### 样例 1

输入:

```
8
-2 -2
-5 1
-2 4
1 3
-2 0
-3 1
-2 2
1 1
3
-2 1
0 0
1 2
```

输出:

```
-2
EDGE
0
```

## 解法

看从该点向右的射线。火车每次向上穿过它，就逆时针绕过该点一次；向下穿过则是顺时针。所以环绕数等于向上穿过射线的轨道数减去向下穿过的轨道数。
从 a 到 b 的轨道在 a.y ≤ p.y < b.y 且点在其左侧（即 cross(b − a, p − a) > 0）时向上穿过，在 b.y ≤ p.y < a.y 且点在其右侧时向下穿过。
只算每段轨道的下端点而不算上端点，射线经过节点时该节点恰好算一次，水平轨道则永远不算。

叉积为 0 且点在轨道的包围盒内时，点在轨道上。对每个点检查每段轨道：`O(n·m)`，共 2.5·10⁷ 步，全部是整数运算。

结果已在小路线上与用 atan2 累加转角的做法对照，包括经过各点所在行的路线和来回往返的路线。

注意事项：

- 叉积可达 2·(2·10⁹)² = 8·10¹⁸，仍小于 2⁶³，64 位整数够用，但没有余量；
- 射线经过节点或沿水平轨道时，不能算两次也不能漏掉，半开区间判断 a.y ≤ p.y < b.y 正好处理这些情况；
- 路线可能沿原路返回，也可能有长度为零的轨道：它们只影响 `EDGE`。
