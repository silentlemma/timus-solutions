# 1599. Число оборотов

[Timus 1599](https://acm.timus.ru/problem.aspx?space=1&num=1599) · сложность 1843 · geometry

Автор оригинальной задачи — Владимир Яковлев.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Замкнутая железная дорога идёт через n узлов (3 ≤ n ≤ 5000) по прямым
путям, которые могут пересекаться и накладываться. Для каждой из m точек
наблюдения (m ≤ 5000) нужно вывести `EDGE`, если точка лежит на пути, а
иначе — сколько полных оборотов против часовой стрелки сделает тот, кто
следит за поездом за один его круг: число оборотов кривой вокруг точки.
Координаты — целые числа до 10⁹ по модулю.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n и узлы, затем m и точки наблюдения.

## Выходные данные

`EDGE` или число оборотов для каждой точки.

## Примеры

### Пример 1

Ввод:

```
8
-2 -2
-5 1
-2 4
1 3
-2 0
-3 1
-2 2
1 1
3
-2 1
0 0
1 2
```

Вывод:

```
-2
EDGE
0
```

## Решение

Посмотрим вдоль луча из точки вправо. Каждый раз, когда поезд пересекает
его вверх, он проходит мимо точки против часовой стрелки, а вниз — по
часовой. Значит, число оборотов — это число путей, пересекающих луч
вверх, минус пересекающих его вниз. Путь из a в b пересекает луч вверх,
если a.y ≤ p.y < b.y и точка лежит слева от него, то есть
cross(b − a, p − a) > 0, и вниз, если b.y ≤ p.y < a.y и точка справа.
Учитывая нижний конец каждого пути, но не верхний, луч через узел
считает узел ровно один раз, а горизонтальные пути не считаются никогда.

Точка лежит на пути, если векторное произведение равно 0 и точка внутри
ограничивающего прямоугольника пути. Каждый путь проверяется для каждой
точки: `O(n·m)`, 2,5·10⁷ шагов только в целых числах.

Результаты сверены с суммированием углов поворота через atan2 на
небольших маршрутах, включая маршруты через строки точек и маршруты туда
и обратно.

Подводные камни:

- векторное произведение доходит до 2·(2·10⁹)² = 8·10¹⁸, это ещё меньше
  2⁶³, так что 64-битных целых хватает, но запаса нет;
- луч через узел или вдоль горизонтального пути не должен считаться
  дважды или вовсе пропадать, и полуоткрытая проверка a.y ≤ p.y < b.y
  это обеспечивает;
- маршрут может идти обратно по себе, а пути нулевой длины возможны:
  они важны только для `EDGE`.
