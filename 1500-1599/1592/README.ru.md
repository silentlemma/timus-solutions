# 1592. Китайские часы

## Задача

Есть n ≤ 50000 часов с 12-часовым циферблатом, каждые показывают время
h:mm:ss. Стрелки можно крутить только вперёд, и усилие — это суммарное
время, на которое сдвигаются стрелки. Нужно выбрать одно время для всех
часов с наименьшим суммарным усилием.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n, затем время на каждых часах в виде h:mm:ss, где 1 ≤ h ≤ 12.

## Выходные данные

Выбранное время в том же формате.

## Примеры

### Пример 1

Ввод:

```
3
11:30:00
12:10:01
6:10:18
```

Вывод:

```
12:10:01
```

## Решение

Будем считать секунды от 12 часов, так что время — это число t от 0 до
43199. Перевод часов со времени a на время t стоит (t − a) mod 43200
секунд движения стрелок. Для цели t часы, показывающие не больше t,
стоят t − a, а часы с более поздним временем — на полный оборот больше,
так что сумма равна n·t − Σa + 43200·(число часов после t). Сдвиг t назад
до ближайшего времени на часах уменьшает n·t и не меняет количество,
поэтому лучшая цель — одно из времён на часах. После сортировки
указатель поддерживает количество, пока t проходит по временам часов:
`O(n log n)`.

Условие не говорит, какое время выводить, если одинаково хороших
несколько; решения выводят самое раннее, считая от 12 часов. Результаты
сверены с перебором всех 43200 времён на маленьких входах.

Подводные камни:

- 12 часов — начало циферблата: это 0 секунд, и ответ 0 секунд
  выводится как 12:00:00;
- суммарное усилие доходит примерно до 50000·43200 ≈ 2·10⁹, больше
  32-битных чисел;
- минуты и секунды выводятся двумя цифрами, а час — без ведущего нуля.
