# 1500. 通行许可

[Timus 1500](https://acm.timus.ru/problem.aspx?space=1&num=1500) · 难度 642 · bitmask

原题作者 Magaz Asanov、Alexander Mironenko、Anton Botov 与 Evgeny Krokhalev，出自 2006 年第 31 届 ACM ICPC 叶卡捷琳堡四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

城市有 N 个路口（2 ≤ N ≤ 30），由 M 段道路相连，每段属于 K 个类别之一
（1 ≤ K ≤ 20）；两个路口之间可以有多个类别的道路。某个类别的许可允许在该类别的所
有道路上行驶。求能从路口 0 开到路口 1 所需的最少许可数，并列出这些类别。

时间限制：2.5 秒。内存限制：64 MB。

## 输入

K、N 和 M，然后是 M 行，每行两个路口和一个类别。

## 输出

许可数，然后是类别。任何一个最小集合都可以。

## 样例

### 样例 1

输入:

```
3 3 3
0 2 0
0 2 1
1 2 2
```

输出:

```
2
0 2
```

## 解法

选最少的类别是一个没有捷径的覆盖问题，但类别集合至多 2²⁰ 个，所以按大小枚举，遇
到第一个连通 0 和 1 的集合就停止。

检查单个集合必须很快。对每个路口 u 和类别 c，记录经类别 c 的道路与 u 相连的路口
的位掩码。u 在整个集合下的邻居就是这些掩码的并；对低十个类别和高十个类别的每个子
集都预先算好，于是两次查表即可得到。然后从路口 0 出发扩展已到达路口的掩码，一旦
包含路口 1 就停止。`O(2^K · N)`。

注意事项：

- 最短的路线不一定最便宜：只用一个类别的长路线胜过用两个类别的短路线（测试 04）；
- 一对路口之间可能有多个类别的道路，任选其一即可（测试 01、03）；
- 当答案需要全部 20 个类别时几乎要试遍所有集合，所以每次检查只能是几次查表（gen2）。
