# 1500. Разрешения на проезд

[Timus 1500](https://acm.timus.ru/problem.aspx?space=1&num=1500) · сложность 642 · bitmask

Авторы оригинальной задачи — Магаз Асанов, Александр Мироненко, Антон Ботов и Евгений Крохалев; четвертьфинал XXXI ACM ICPC, Екатеринбург, 2006 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В городе N перекрёстков (2 ≤ N ≤ 30), соединённых M отрезками улиц,
каждый из одной из K категорий (1 ≤ K ≤ 20); два перекрёстка могут
соединять улицы нескольких категорий. Разрешение на категорию позволяет
ездить по всем её улицам. Нужно найти наименьшее число разрешений, при
котором можно проехать от перекрёстка 0 до перекрёстка 1, и перечислить
их категории.

Ограничение времени: 2.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

K, N и M, затем M строк с двумя перекрёстками и категорией.

## Выходные данные

Число разрешений, затем категории. Подходит любой наименьший набор.

## Примеры

### Пример 1

Ввод:

```
3 3 3
0 2 0
0 2 1
1 2 2
```

Вывод:

```
2
0 2
```

## Решение

Выбор наименьшего числа категорий — задача о покрытии без коротких
путей, но наборов категорий не больше 2²⁰, так что перебираем их по
размеру и останавливаемся на первом наборе, соединяющем 0 и 1.

Проверка одного набора должна быть быстрой. Для каждого перекрёстка u и
категории c храним битовую маску перекрёстков, соединённых с u улицей
категории c. Соседи u при целом наборе — объединение этих масок; оно
заранее посчитано для каждого подмножества младших десяти категорий и
старших десяти, так что хватает двух обращений к таблицам. Поиск от
перекрёстка 0 наращивает маску достигнутых перекрёстков и
останавливается, как только в ней оказывается перекрёсток 1.
`O(2^K · N)`.

Подводные камни:

- самый короткий путь не всегда самый дешёвый: длинный путь по одной
  категории лучше короткого по двум (тест 04);
- пару перекрёстков могут соединять улицы нескольких категорий, и любой
  из них достаточно (тесты 01, 03);
- когда ответу нужны все 20 категорий, перебираются почти все наборы,
  поэтому проверка одного набора должна сводиться к нескольким
  обращениям к таблицам (gen2).

## Особенности языков

- Python запускается в PyPy: цепочка, которой нужны все 20 категорий,
  занимает около 1,25 с в CPython и около 0,14 с в PyPy.
