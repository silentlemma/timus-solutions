# 1539. По данным разведки…

## Задача

В рапорте даны N средних (1 ≤ N ≤ 100) по одной и той же группе
гоблинов, каждое — положительное число не больше 1000, округлённое ровно
до d знаков после точки (1 ≤ d ≤ 5). Нужно найти наименьший возможный
размер группы.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

d и N, затем N средних, по одному в строке.

## Выходные данные

Наименьший размер группы.

## Примеры

### Пример 1

Ввод:

```
2 3
52.29
0.71
170.86
```

Вывод:

```
7
```

## Решение

Будем считать в единицах 10^−d: среднее, записанное как v единиц,
получается из p предметов на q гоблинов, когда p / q округляется до v,
то есть v − 1/2 ≤ 10^d·p / q < v + 1/2, или
(2v − 1)·q ≤ 2·10^d·p < (2v + 1)·q (округление половины вверх). При
данном q вопрос в том, есть ли целое число в полуинтервале: берём
наименьшее p, допустимое левым концом, и проверяем правый конец, всё в
целых числах.

Важна только дробная часть каждого среднего, потому что к каждому итогу
можно добавить целое число предметов на гоблина, а целое среднее
подходит любой группе; повторы тоже можно убрать. При q = 10^d длина
полуинтервала не меньше 1, так что ответ не больше 10^d = 10⁵:
перебираем q = 1, 2, … и останавливаемся на первом, подходящем всем
средним. Среднее, отбросившее одно q, обычно отбрасывает и следующие,
поэтому оно переносится в начало списка. В худшем случае `O(10^d·N)`.

Подводные камни:

- округление половины вверх: 1/4 = 0,25 записывается как 0.3, поэтому
  четыре гоблина объясняют и 0.3, и 0.8 (тест 05);
- одно лишь 0.00001 требует уже 66667 гоблинов (тест 04);
- целые части ничего не меняют: в тесте 08 999.99999 считается как
  0.99999, которому, как и 0.00001, нужно не меньше 66667 гоблинов, а
  половина делает группу чётной, 66668;
- вещественные числа недостаточно точны у концов интервалов, поэтому
  средние читаются как целые.
