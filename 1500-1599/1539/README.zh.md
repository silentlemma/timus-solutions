# 1539. 情报

[Timus 1539](https://acm.timus.ru/problem.aspx?space=1&num=1539) · 难度 1050 · number_theory

原题作者 Stanislav Vasiliev，出自 2007 年 3 月 3 日第八届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一份报告给出同一群哥布林的 N 个平均数（1 ≤ N ≤ 100），每个都是不超过 1000 的正数，恰好四
舍五入到小数点后 d 位（1 ≤ d ≤ 5）。求这群哥布林最少可能有多少个。

时间限制：1 秒。内存限制：64 MB。

## 输入

d 和 N，然后是 N 个平均数，每行一个。

## 输出

最小的群体规模。

## 样例

### 样例 1

输入:

```
2 3
52.29
0.71
170.86
```

输出:

```
7
```

## 解法

以 10^−d 为单位：写作 v 个单位的平均数来自 q 个哥布林共 p 件物品，当且仅当 10^d·p / q 舍入后为
v，即 v − 1/2 ≤ 10^d·p / q < v + 1/2，也就是 (2v − 1)·q ≤ 2·10^d·p < (2v + 1)·q（四舍五
入，恰好一半时进位）。对给定的 q，问题是半开区间里有没有整数：取左端允许的最小 p，再检查右
端，全部用整数运算。

只有每个平均数的小数部分才重要，因为每个总数都可以加上每个哥布林整数件物品，而整数平均数
适合任何群体；重复的也可以去掉。q = 10^d 时区间长度不小于 1，所以答案不超过 10^d ≤ 10⁵：
依次尝试 q = 1, 2, …，在第一个满足所有平均数的 q 处停下。排除了某个 q 的平均数往往也会排
除接下来的 q，所以把它移到列表最前面。最坏 `O(10^d·N)`。

注意事项：

- 恰好一半时进位：1/4 = 0.25 写作 0.3，所以四个哥布林可以同时给出 0.3 和 0.8（测试 05）；
- 仅 0.00001 一个就需要 66667 个哥布林（测试 04）；
- 整数部分不起作用：测试 08 中 999.99999 等同于 0.99999，它和 0.00001 一样至少需要 66667
  个哥布林，而 0.5 使群体为偶数，即 66668；
- 浮点数在区间端点附近不够精确，所以平均数按整数读入。
