# 1569. “伊塞季”大楼的网络

[Timus 1569](https://acm.timus.ru/problem.aspx?space=1&num=1569) · 难度 886 · bfs

原题作者 Sergey Pupyrev，出自 2007 年 10 月 6 日第十二届乌拉尔国立大学程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一份连通的规划用 M 条信道连接 N ≤ 100 个结点，每对结点至多一条。要从规划的信道中选出 N − 1 条，仍能连通
所有结点，并使两结点间的最大距离尽可能小，输出这些信道。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 M，然后是每条规划信道的两个结点。

## 输出

选出的信道，每行一对结点。任何最优的网络都被接受。

## 样例

### 样例 1

输入:

```
4 4
1 2
2 3
2 4
3 4
```

输出:

```
1 2
2 3
2 4
```

## 解法

这就是直径最小的生成树。任何树的中心要么是一个结点（直径为偶数时），要么是某条信道的中点（直径为奇数时）。
若最优树直径为 2r、中心是结点 c，则在这棵树中、从而在规划中，每个结点到 c 的距离都不超过 r，于是从 c 出发
的最短路径树直径不超过 2r。同理，直径为 2r + 1、中心在信道 (a, b) 上时，每个结点到 a 或 b 的距离不超过 r，
从两端同时生长的最短路径树加上这条信道本身，直径不超过 2r + 1。

所以先从每个结点做广度优先搜索得到所有距离；结点 c 的得分为 2·max dist(c, ·)，信道 (a, b) 的得分为
2·max min(dist(a, ·), dist(b, ·)) + 1，以最优中心出发的最短路径树就是答案。耗时 O(N·(N + M))。结果已在 300
个随机的小规划上与枚举所有生成树的做法对照。

注意事项：

- 最优树的中心可能是一条信道，给出任何结点中心都达不到的奇数直径（测试 05）；
- 以信道为中心时，这条信道必须留在树中；
- 最优网络不止一个，所以检查器比较最大距离，并检查每条信道都在规划中。
