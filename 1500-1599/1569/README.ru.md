# 1569. Сети в Исети

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Связный план соединяет N ≤ 100 узлов M каналами, не больше одного на
пару. Нужно выбрать N − 1 запланированных каналов, которые по-прежнему
связывают все узлы, так, чтобы наибольшее расстояние между двумя узлами
было как можно меньше, и вывести их.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем два узла каждого запланированного канала.

## Выходные данные

Выбранные каналы, по паре узлов в строке. Принимается любая лучшая сеть.

## Примеры

### Пример 1

Ввод:

```
4 4
1 2
2 3
2 4
3 4
```

Вывод:

```
1 2
2 3
2 4
```

## Решение

Это остовное дерево наименьшего диаметра. Середина любого дерева — либо
узел, когда диаметр чётный, либо середина канала, когда он нечётный.
Если у лучшего дерева диаметр 2r и середина — узел c, то каждый узел
находится в пределах r от c в этом дереве, а значит, и в плане, и
дерево кратчайших путей из c имеет диаметр не больше 2r. Так же для
диаметра 2r + 1 с серединой на канале (a, b) каждый узел находится в
пределах r от a или b, и дерево кратчайших путей, растущее сразу из
обоих концов, вместе с самим каналом имеет диаметр не больше 2r + 1.

Значит, поиск в ширину из каждого узла даёт все расстояния; узел c
получает оценку 2·max dist(c, ·), канал (a, b) —
2·max min(dist(a, ·), dist(b, ·)) + 1, а ответ — дерево кратчайших путей
от лучшего центра. Это занимает O(N·(N + M)) времени. Результаты
сверены с перебором всех остовных деревьев на 300 случайных маленьких
планах.

Подводные камни:

- серединой лучшего дерева может быть канал, что даёт нечётный диаметр,
  недостижимый ни для какого узла-центра (тест 05);
- при центре на канале этот канал должен остаться в дереве;
- лучших сетей несколько, так что чекер сравнивает наибольшее
  расстояние и проверяет, что каждый канал есть в плане.
