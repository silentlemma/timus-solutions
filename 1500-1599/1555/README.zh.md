# 1555. 寻找宝藏！

[Timus 1555](https://acm.timus.ru/problem.aspx?space=1&num=1555) · 难度 8847 · games

原题出自 2007 年 9 月彼得罗扎沃茨克集训的 Novosibirsk SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两名玩家在 N × N 的迷宫里轮流行动（N ≤ 6，至多 30 面墙；每个格子任何一边都可以有墙，所以相邻格子之间可能有两面墙）。
一步可以是走到相邻的空格且不穿墙、原地不动，或者用每人仅有的一枚火箭射击：向北、东、南、西或向下。
火箭一直飞，直到飞出棋盘、撞墙（墙被摧毁）或击中另一名玩家（其死亡）；向下发射的火箭会杀死射击者。死亡的玩家输；
踩到宝箱的玩家还可以通过离开棋盘获胜。双方都采取最优策略。输出 `Draw`，或第一名玩家的 `Win`/`Lose` 及步数
（第一名玩家使其最小，第二名使其最大）和第一名玩家的第一步：`M` 或 `S` 加上按数字键盘表示的方向
（8 北、6 东、2 南、4 西、5 不动或向下）。

时间限制：5 秒。内存限制：64 MB。

## 输入

N，然后是 3N 行、每行 3N 个字符：每个格子是一个 3 × 3 的方块，墙 `-` 和 `|` 在各边中点，中心是 `1`、`2`、`*` 或空格。

## 输出

`Draw`，或结果和步数，再给出第一步。

## 样例

### 样例 1

输入:

```
3
.-..-..-.
|1....|2|
.........
.........
|*|.....|
.........
.........
|.......|
.-..-..-.
```

输出:

```
Win 5
M2
```

### 样例 2

输入:

```
2
.-..-.
|2..*|
.-....
.-....
|1||.|
.-..-.
```

输出:

```
Lose 1
S5
```

## 解法

逆向分析。局面由两个格子、谁拿着宝箱以及轮到谁组成；此外每枚火箭要么仍装填着，要么已飞出棋盘，要么已用在墙 w 上。
射击只会转到装填火箭更少的状态，所以火箭状态从“都未装填”到“两枚都装填”依次求解，
每个状态是约 7 500 个局面的博弈图，其中射击都通向已解出的局面。

在一个火箭状态内，用逆向归纳得到结果：只要有一步能让行动方获胜，局面即为胜；所有步都输则为负；剩下在环中的为平局。
步数随后用带堆的类 Dijkstra 过程求出：第一名玩家的局面在保持结果的步中取最少步数，第二名玩家的局面在这些步都已知后取最多。
第一步按结果、再按步数、再按 M8、M6、M2、M4、M5、S8、S6、S2、S4、S5 的顺序选最好的。
对 S ≤ 32 个火箭状态和 P 个局面为 `O(S² · P log P)`。

注意事项：

- 第一名玩家即使输也让步数尽量少：第二个样例中第一名玩家立刻向下射击（`Lose 1`）；
- 相邻格子之间有两面墙时，火箭只摧毁遇到的第一面，被摧毁的墙不会再出现（测试 06）；
- 飞出棋盘的火箭只是被用掉；
- 拿着宝箱的玩家只能从没有墙的一边离开棋盘；
- 处于环中的局面为平局（测试 03）。

答案已在这里的测试以及 40 个随机迷宫（其中包括有 30 面墙的 6 × 6 棋盘）上与一份独立的已通过实现对比过。

## 各语言说明

- 没有 Python 解答：最大的测试用 CPython 约需 85 秒，用 PyPy 约需 20 秒，而限制是 5 秒。
- 四份解答都把局面的走法和前驱存进对所有火箭状态重复使用的扁平数组：为约一千个状态中的每一个重新分配会让解答最多慢一倍。
