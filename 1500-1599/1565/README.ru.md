# 1565. Необычная дуэль

[Timus 1565](https://acm.timus.ru/problem.aspx?space=1&num=1565) · сложность 1785 · games

Автор оригинальной задачи — Сергей Пупырев; XII чемпионат УрГУ по программированию, 6 октября 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Три дуэлянта A, B и C попадают с вероятностями 1, b и c (b ≠ c), и
попадание убивает. Честный жребий задаёт порядок, и они стреляют по
очереди в этом порядке, пропуская убитых, пока не останется один; каждый
выстрел может быть в любого соперника или в воздух. A всегда стреляет в
самого меткого из живых соперников. B и C выбирают выстрел, дающий им
наибольший шанс выжить, а при равенстве стреляют в сильнейшего соперника.
Нужно вывести шансы выжить для A, B и C не менее чем с пятью знаками
после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Три меткости.

## Выходные данные

Три шанса в одной строке.

## Примеры

### Пример 1

Ввод:

```
1.0 0.8 0.5
```

Вывод:

```
0.30000 0.17778 0.52222
```

## Решение

Каждый из 6 порядков решается отдельно, и результаты усредняются. Когда
кто-то погибает, остаются двое и стреляют по очереди; если первый
стреляющий попадает с вероятностью p, а второй — с q, первый побеждает с
вероятностью

p + (1 − p)(1 − q)·p + … = p / (p + q − p·q).

Пока живы все трое, ход A сразу заканчивает эту фазу: A не промахивается
и убивает более сильного из B и C. Значит, с любого хода фаза длится не
больше двух следующих выстрелов, и шансы получаются рекурсией по ходам:
стреляющий сравнивает выстрел в каждого соперника (попадание с его
меткостью, затем оставшаяся дуэль, которую начинает следующий живой;
промах — следующий ход) с выстрелом в воздух (следующий ход) и берёт
лучший для себя шанс. Равенства разбираются, как сказано в условии,
затем в порядке A, B, C и воздух, с допуском 10⁻¹². Всё занимает
постоянное время. Результаты совпадают с независимой программой примерно
на 420 входах.

Подводные камни:

- выстрел в воздух может быть лучшим: в примере, пока живы все трое, C
  всегда стреляет в воздух и даёт выстрелить сначала A и B;
- B или C могут никогда не попадать или никогда не промахиваться, и
  безупречного B или C A расстреливает первым (тесты 02–05);
- следующий стреляющий после попадания пропускает убитого, и от этого
  зависит, кто начинает оставшуюся дуэль.
