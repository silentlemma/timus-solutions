# 1565. 三人决斗

[Timus 1565](https://acm.timus.ru/problem.aspx?space=1&num=1565) · 难度 1785 · games

原题作者 Sergey Pupyrev，出自 2007 年 10 月 6 日第十二届乌拉尔国立大学程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

三名决斗者 A、B、C 的命中率分别为 1、b、c（b ≠ c），命中即死。公平抽签决定顺序，他们按此顺序轮流射击，
跳过已死的人，直到只剩一人；每一枪可以射向任一对手或朝天开。A 总是射击活着的对手中最准的那个。B 和 C
选择使自己生存机会最大的射击，若相等则射向最强的对手。输出 A、B、C 的生存概率，小数点后至少五位。

时间限制：1 秒。内存限制：64 MB。

## 输入

三个命中率。

## 输出

一行中的三个概率。

## 样例

### 样例 1

输入:

```
1.0 0.8 0.5
```

输出:

```
0.30000 0.17778 0.52222
```

## 解法

6 种顺序分别求解，再取平均。一旦有人死去，剩下两人轮流射击；若先开枪者命中率为 p，另一人为 q，先开枪者
获胜的概率为

p + (1 − p)(1 − q)·p + … = p / (p + q − p·q)。

三人都活着时，轮到 A 就立刻结束这一阶段：A 从不失手，会打死 B、C 中较强的一个。所以从任何一轮起，这一
阶段至多再持续两枪，概率可按轮次递归求出：射手比较射向每个对手（按其命中率命中，之后是剩下的决斗，由下
一个活着的人先开枪；未命中则进入下一轮）与朝天开枪（进入下一轮），取对自己最好的结果。相等时按题意处理，
再依 A、B、C、朝天的顺序，容差 10⁻¹²。总耗时为常数。结果在约 420 组输入上与一个独立程序一致。

注意事项：

- 朝天开枪可能是最好的：样例中三人都活着时，C 总是朝天开枪，让 A 和 B 先开枪；
- B 或 C 可能从不命中或从不失手，完美的 B 或 C 会先被 A 打死（测试 02–05）；
- 命中后下一个射手要跳过死者，这决定了谁先开始剩下的决斗。
