# 1565. 三人决斗

[Timus 1565](https://acm.timus.ru/problem.aspx?space=1&num=1565) · 难度 1780 · games

原题作者 Sergey Pupyrev，出自 2007 年 10 月 6 日第十二届乌拉尔国立大学程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

三名决斗者 A、B、C 的命中率分别为 1、b、c（b ≠ c），命中即死。公平抽签决定顺序，他们按此顺序轮流射击，
跳过已死的人，直到只剩一人；每一枪可以射向任一对手或朝天开。A 总是射击活着的对手中最准的那个。B 和 C
选择使自己生存机会最大的射击，若相等则射向最强的对手。输出 A、B、C 的生存概率，小数点后至少五位。

时间限制：1 秒。内存限制：64 MB。

## 输入

三个命中率。

## 输出

一行中的三个概率。

## 样例

### 样例 1

输入:

```
1.0 0.8 0.5
```

输出:

```
0.30000 0.17778 0.52222
```

## 解法

6 种顺序分别求解，再取平均。一旦有人死去，剩下两人轮流射击；若先开枪者命中率为 p，另一人为 q，先开枪者
获胜的概率为

p + (1 − p)(1 − q)·p + … = p / (p + q − p·q)。

三人都活着时，轮到 A 就立刻结束这一阶段：A 从不失手，会打死 B、C 中较强的一个。
设较强者命中率为 h，较弱者为 l，且 h > l。较强者总是射击 A。射杀另一名对手会让 A 接着开枪，
因此不能提高生存概率。较弱者比较射击 A 与等待：若下一个是 A，概率差的符号与
(1 − h)(1 − l) − h 相同；若下一个是较强者，则与 (1 − h)²(1 − l) − h 相同。
相应表达式非负时射击 A，否则朝天开枪。l = 0 时所有动作结果相同，按平局规则选择 A。

用共同尺度 S 精确读取十进制输入，令 h = H/S、l = L/S，以整数乘积比较：
(S − H)(S − L) ≥ H·S 和 (S − H)²(S − L) ≥ H·S²。
这样既保留真正的平局，也不会把微小的严格优势当成平局。确定策略后，沿用原来的递归混合命中与未命中的结果，
到 A 开枪为止，最多再经过两枪。计算两人决斗公式时使用较小命中率与较大命中率之比，避免两者在浮点数中
下溢为零导致除零；只有概率计算使用浮点数。

这里 d 表示输入的十进制数字个数。

注意事项：

- 固定容差可能把严格优势误判为平局，显著改变其他人的生存概率；
- 朝天开枪可能是最好的：样例中三人都活着时，C 总是朝天开枪，让 A 和 B 先开枪；
- B 或 C 可能从不命中或从不失手，完美的 B 或 C 会先被 A 打死（测试 02–05）；
- 命中后下一个射手要跳过死者，这决定了谁先开始剩下的决斗。
