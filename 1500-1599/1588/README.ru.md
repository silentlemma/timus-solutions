# 1588. Ямайка

## Задача

Есть n различных городов (1 ≤ n ≤ 300) в целых точках с координатами от
0 до 10000. Любые два города соединяет прямая дорога, и одна дорога
обслуживает все города на своей прямой. Нужно найти суммарную длину
дорог, округлённую до целого числа миль.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n, затем координаты каждого города.

## Выходные данные

Суммарная длина, округлённая.

## Примеры

### Пример 1

Ввод:

```
4
0 0
0 100
100 0
50 50
```

Вывод:

```
412
```

## Решение

Каждая прямая, на которой лежат хотя бы два города, несёт одну дорогу
от первого города до последнего. Из города i каждый другой город виден
в некотором сокращённом направлении (dx/g, dy/g), где g = НОД(dx, dy),
на расстоянии g шагов. Город i — конец дороги в этом направлении ровно
тогда, когда в противоположном направлении городов нет, и тогда длина
дороги равна g·|(dx/g, dy/g)| для самого дальнего города в этом
направлении. Сумма по всем городам находит каждую дорогу дважды, с
обоих концов, поэтому делится пополам. С направлениями в хеш-таблице
ожидаемое время — `O(n²)`; C++ использует упорядоченную таблицу,
а Java — сортировку, что даёт `O(n² log n)`.

Результаты сверены с явной группировкой городов на прямой каждой пары.

Подводные камни:

- прямая с тремя и более городами — одна дорога, а не по одной на пару:
  в примере диагональ через (50, 50) считается один раз;
- направления нужно сокращать на НОД, иначе города одной прямой на
  разном числе шагов выглядят как разные дороги;
- сумма делится пополам до округления.
- города на нескольких прямых через одну точку создают также дороги
  между этими прямыми; их тоже нужно учитывать (генераторный тест `gen3`).
