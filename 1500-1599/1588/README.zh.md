# 1588. 牙买加

[Timus 1588](https://acm.timus.ru/problem.aspx?space=1&num=1588) · 难度 326 · geometry

原题作者 Andrey Demidov，出自 2007 年 10 月 27 日在叶卡捷琳堡举行的 ACM ICPC 2007–2008 NEERC 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 n 个互不相同的城市（1 ≤ n ≤ 300），位于坐标在 0 到 10000 之间的整点上。任意两个城市之间修一条直路，一条路服务于其所在直线上的所有城市。
求所有道路的总长度，四舍五入到整数英里。

时间限制：1 秒。内存限制：64 MB。

## 输入

n，然后是每个城市的坐标。

## 输出

四舍五入后的总长度。

## 样例

### 样例 1

输入:

```
4
0 0
0 100
100 0
50 50
```

输出:

```
412
```

## 解法

每条至少经过两个城市的直线上有一条路，从第一个城市修到最后一个城市。从城市 i 看，其他每个城市都位于某个约简方向
(dx/g, dy/g) 上，其中 g = gcd(dx, dy)，距离为 g 步。城市 i 是该方向道路的端点，当且仅当相反方向上没有城市；
此时道路长度为该方向最远城市的 g·|(dx/g, dy/g)|。对所有城市求和时每条路会从两端各算一次，所以总和要除以 2。
方向存在哈希表里（Java 中改为排序），复杂度为 `O(n²)` 或 `O(n² log n)`。

结果已与对每一对城市显式找出其直线上所有城市的做法对照。

注意事项：

- 经过三个及以上城市的直线只算一条路，而不是每对一条：样例中经过 (50, 50) 的对角线只算一次；
- 方向必须按 gcd 约简，否则同一直线上步数不同的城市会被当成不同的路；
- 先除以 2 再四舍五入。
