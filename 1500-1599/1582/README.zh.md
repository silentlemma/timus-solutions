# 1582. 博彩公司

[Timus 1582](https://acm.timus.ru/problem.aspx?space=1&num=1582) · 难度 123 · math

原题作者 Sergey Pupyrev，由 Vladimir Yakovlev 整理，出自 2007 年 10 月 27 日在叶卡捷琳堡举行的 ACM ICPC 2007–2008 NEERC 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一场比赛有三种结果，最佳赔率分别为 k₁、k₂、k₃（0.01 … 100）：押中时投注 x 得到 k·x，押错一无所得。把总共 1000
英镑的投注分配到三种结果上，使最坏情况下拿回的钱最多，输出这个数，四舍五入到整数。

时间限制：1 秒。内存限制：64 MB。

## 输入

k₁、k₂ 和 k₃。

## 输出

保证能拿回的钱数（四舍五入）。

## 样例

### 样例 1

输入:

```
3.5 3.5 3.5
```

输出:

```
1167
```

### 样例 2

输入:

```
1.25 10.0 5.75
```

输出:

```
931
```

## 解法

在结果 i 上投注 xᵢ，x₁ + x₂ + x₃ = 1000；结果 i 的回报为 kᵢ·xᵢ。若三种回报不等，从回报最高的结果挪一点钱到回报
最低的结果就能提高最小值，所以最优分配中所有回报都等于某个 P。于是 xᵢ = P / kᵢ，由投注总额得

P = 1000 / (1/k₁ + 1/k₂ + 1/k₃)。

三项在双精度下依次相加，回报按“半数进一”取整为 ⌊P + 0.5⌋。`O(1)`。

注意事项：

- 三个赔率都大于 3 时，保证的回报大于投注，如第一个样例；
- 恰好一半时进位：赔率 2、10、25 给出 1562.5，答案为 1563，而 `printf("%.0f")` 会舍入到偶数，输出 1562（测试 08）；
- Python 的 `sum` 自 3.12 版起以更高精度累加浮点数，所以 Python 解法像其他语言一样逐项相加。
