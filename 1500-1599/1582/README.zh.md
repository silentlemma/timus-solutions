# 1582. 博彩公司

[Timus 1582](https://acm.timus.ru/problem.aspx?space=1&num=1582) · 难度 123 · math

原题作者 Sergey Pupyrev，由 Vladimir Yakovlev 整理，出自 2007 年 10 月 27 日在叶卡捷琳堡举行的 ACM ICPC 2007–2008 NEERC 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一场比赛有三种结果，最佳赔率分别为 k₁、k₂、k₃（0.01 … 100）：押中时投注 x 得到
k·x，押错一无所得。把总共 1000 英镑的投注分配到三种结果上，使最坏情况下拿回的钱
最多，输出这个数，四舍五入到整数。

时间限制：1 秒。内存限制：64 MB。

## 输入

k₁、k₂ 和 k₃。

## 输出

保证能拿回的钱数（四舍五入）。

## 评测方式

仓库测试比较完整输出文本，仅忽略末尾空白。应保留有意义的空格、换行、大小写及标点。

## 样例

### 样例 1

输入:

```
3.5 3.5 3.5
```

输出:

```
1167
```

### 样例 2

输入:

```
1.25 10.0 5.75
```

输出:

```
931
```

## 解法

在结果 i 上投注 xᵢ，x₁ + x₂ + x₃ = 1000；结果 i 的回报为 kᵢ·xᵢ。要保证回报 P，
每种结果的回报都必须至少为 P，即 xᵢ ≥ P / kᵢ，三个不等式相加得
1000 ≥ P·(1/k₁ + 1/k₂ + 1/k₃)。投注 xᵢ = P / kᵢ 恰好达到这个界，所以最大的保证
回报为

P = 1000 / (1/k₁ + 1/k₂ + 1/k₃)。

将每个十进制数精确读成 a / 10ˢ。从 N = 1、D = 0 开始，对每个赔率先更新
D = D·a + N·10ˢ，再更新 N = N·a。此时 P = 1000·N / D。使用任意精度整数，
二分查找满足 2·1000·N ≥ (2m − 1)·D 的最大整数 m，即可精确地将半数向上取整。
答案不超过 ⌊1000·100 / 3⌋，因此二分次数为常数。设 L 为输入的十进制数字总数
（若含指数则先展开），时间复杂度为 `O(L^2)`，空间复杂度为 `O(L)`。

注意事项：

- 三个赔率都大于 3 时，保证的回报大于投注，如第一个样例；
- 恰好一半时进位：赔率 2、10、25 给出 1562.5，答案为 1563，而 `printf("%.0f")` 会舍入到偶数，输出 1562（测试 08）；
- 二进制浮点误差可能让精确的半数略微变小：赔率 0.02、0.02、0.03 的回报恰为 7.5，答案应为 8（测试 10）。题目未限制小数位数，因此应使用精确运算，而非添加 epsilon。
