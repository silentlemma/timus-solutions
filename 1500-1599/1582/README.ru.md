# 1582. Букмекеры

## Задача

У матча три исхода с лучшими коэффициентами k₁, k₂ и k₃ (0.01 … 100):
ставка x на верный исход приносит k·x, неверная — ничего. Нужно
распределить ставки на общую сумму 1000 фунтов по трём исходам так,
чтобы в худшем случае получить как можно больше, и вывести эту сумму,
округлённую до целого.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

k₁, k₂ и k₃.

## Выходные данные

Гарантированная выплата, округлённая.

## Примеры

### Пример 1

Ввод:

```
3.5 3.5 3.5
```

Вывод:

```
1167
```

### Пример 2

Ввод:

```
1.25 10.0 5.75
```

Вывод:

```
931
```

## Решение

Поставим xᵢ на исход i, x₁ + x₂ + x₃ = 1000; исход i приносит kᵢ·xᵢ.
Если три выплаты различны, перенос небольшой суммы с самого выгодного
исхода на самый невыгодный поднимает минимум, так что при лучшем
распределении все выплаты равны некоторому P. Тогда xᵢ = P / kᵢ, и сумма
ставок даёт

P = 1000 / (1/k₁ + 1/k₂ + 1/k₃).

Три слагаемых складываются одно за другим в двойной точности, и
выплата округляется половиной вверх как ⌊P + 0.5⌋. `O(1)`.

Подводные камни:

- при всех коэффициентах больше 3 гарантированная выплата больше ставки,
  как в первом примере;
- точная половина округляется вверх: коэффициенты 2, 10 и 25 дают
  1562.5 и ответ 1563, а `printf("%.0f")` округлил бы к чётному и вывел
  1562 (тест 08);
- `sum` в Python начиная с версии 3.12 складывает вещественные числа с
  повышенной точностью, поэтому решение на Python складывает три
  слагаемых по одному, как и остальные.
