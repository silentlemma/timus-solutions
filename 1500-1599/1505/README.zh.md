# 1505. 输油

[Timus 1505](https://acm.timus.ru/problem.aspx?space=1&num=1505) · 难度 2815 · graphs

原题作者 Magaz Asanov 与 Evgeny Krokhalev，出自 2006 年第 31 届 ACM ICPC 叶卡捷琳堡四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 个泵站（1 ≤ N ≤ 10000）由至多 100000 条单向管道相连。从 i 到 a 的管道有容量 b、
当前流量 c（0 ≤ c ≤ b ≤ 10000）以及每增加一单位容量的价格 d（0 ≤ d ≤ 10⁶）。石
油只从泵站 N 离开网络，泵站 N 没有出发的管道。其他每个泵站收到的油不多于送出的油；
收到较少的泵站附近有油井，可以多产一单位。要以最小代价使流入泵站 N 的流量增加一单
位，输出代价和新的流量，或者 "Impossible"。

时间限制：2 秒。内存限制：64 MB。

## 输入

N，然后每个泵站一行：它的管道，即用逗号分隔的四元组 a b c d，以句点结尾；没有管道
的泵站只有一个句点。

## 输出

最小代价，然后每个泵站一行，列出它的管道，即用逗号分隔的 "a 流量" 对，以句点结尾；
或者 "Impossible"。任何最便宜的改动都可以。

## 样例

### 样例 1

输入:

```
4
2 1 1 1, 3 1 1 3.
3 1 0 2, 4 1 1 2.
4 1 1 1.
.
```

输出:

```
2
2 2, 3 1.
3 1, 4 1.
4 2.
.
```

## 解法

多出的一单位沿着残量网络中从有油井的泵站到泵站 N 的一条路径流动。沿管道 i → a，
如果管道还有余量，它可以免费正向通过；管道满了则花 d 正向通过，此时容量加一。只要
管道上有流量，它还可以免费反向从 a 走到 i：从 i 少送一单位，这一单位就在 i 空出来
了。所有价格都非负，所以从所有有油井的泵站同时出发运行 Dijkstra 算法即可找到最便宜
的路径；再从 N 往回走，把路径上每条管道的流量改变一。M 条管道时为
`O((N + M) log N)`。

只要有油井，它的盈余就必须沿有流量的管道到达 N，这就是一条路径，所以答案为
"Impossible" 当且仅当没有任何泵站有油井。

注意事项：

- 只在环上流动的流量不会产生油井，所以无解（测试 03）；
- 最便宜的路线可能要把某条管道的流量往回推（测试 04）；
- d = 0 的满管道扩容不花钱（测试 05）；
- 代价可达 10⁴ · 10⁶ = 10¹⁰，超出 32 位（gen5）；
- 每个泵站的管道以句点结尾，所以按标点而不是按行读取输入最方便（所有测试）；
- 最便宜的改动可能有很多，所以测试使用检查程序（所有测试）。
