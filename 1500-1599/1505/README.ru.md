# 1505. Перекачка нефти

[Timus 1505](https://acm.timus.ru/problem.aspx?space=1&num=1505) · сложность 2815 · graphs

Авторы оригинальной задачи — Магаз Асанов и Евгений Крохалев; четвертьфинал XXXI ACM ICPC, Екатеринбург, 2006 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N перекачивающих станций (1 ≤ N ≤ 10000) соединены не более чем 100000
односторонних нефтепроводов. У нефтепровода из i в a есть пропускная
способность b, текущий поток c (0 ≤ c ≤ b ≤ 10000) и цена d
(0 ≤ d ≤ 10⁶) за каждую добавленную единицу пропускной способности.
Нефть уходит из сети только со станции N, у которой нет исходящих
нефтепроводов. Каждая другая станция получает не больше нефти, чем
отправляет; где получает меньше, рядом есть скважина, способная дать
ещё одну единицу. Нужно как можно дешевле увеличить поток в станцию N
на единицу и вывести стоимость и новые потоки или «Impossible».

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем по строке на станцию: её нефтепроводы — четвёрки a b c d через
запятую, в конце точка; у станции без нефтепроводов — одна точка.

## Выходные данные

Минимальная стоимость, затем по строке на станцию с её нефтепроводами —
пары «a поток» через запятую, в конце точка; или «Impossible». Подходит
любое самое дешёвое изменение.

## Примеры

### Пример 1

Ввод:

```
4
2 1 1 1, 3 1 1 3.
3 1 0 2, 4 1 1 2.
4 1 1 1.
.
```

Вывод:

```
2
2 2, 3 1.
3 1, 4 1.
4 2.
.
```

## Решение

Дополнительная единица идёт по пути от станции со скважиной до станции
N в остаточной сети. По нефтепроводу i → a она может пройти вперёд
бесплатно, если в нём есть запас, и за d, если он заполнен, — тогда его
пропускная способность растёт на единицу. Ещё она может пройти назад,
из a в i, бесплатно, если по нефтепроводу идёт поток: если отправить
из i на единицу меньше, она освобождается в i. Все цены
неотрицательны, поэтому алгоритм Дейкстры сразу от всех станций со
скважинами находит самый дешёвый путь; затем идём назад от N и меняем
поток каждого нефтепровода на пути на единицу. `O((N + M) log N)` для M
нефтепроводов.

Если хоть одна скважина есть, её излишек должен дойти до N по
нефтепроводам с потоком, а это путь, поэтому ответ «Impossible» ровно
тогда, когда скважин нет ни у одной станции.

Подводные камни:

- поток, который только ходит по циклу, скважин не создаёт, и ответа
  нет (тест 03);
- самый дешёвый путь может отодвигать назад поток нефтепровода
  (тест 04);
- заполненный нефтепровод с d = 0 расширяется бесплатно (тест 05);
- стоимость может достигать 10⁴ · 10⁶ = 10¹⁰, больше 32 бит (gen5);
- нефтепроводы станции заканчиваются точкой, поэтому вход проще читать
  по знакам препинания, а не по строкам (все тесты);
- самых дешёвых изменений может быть много, поэтому тесты проверяются
  чекером (все тесты).
