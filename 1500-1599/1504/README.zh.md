# 1504. 礼貌

[Timus 1504](https://acm.timus.ru/problem.aspx?space=1&num=1504) · 难度 2173 · geometry

原题作者 Stanislav Vasiliev，出自 2006 年第 31 届 ACM ICPC 叶卡捷琳堡四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

半径为 R（1 ≤ R ≤ 100）、圆心在原点的圆桌上，K 块蛋糕（2 ≤ K ≤ 1000）放在互不相同
的点上，每块重 1 到 10000 克。坐在桌边某点的客人会礼貌地拿最近的一块，若有几块同样
近则拿最重的。求桌边上的一个座位，使拿到的蛋糕尽可能重。

时间限制：1.5 秒。内存限制：64 MB。

## 输入

R 和 K，然后 K 行，每行是一块蛋糕的坐标（实数）和重量。

## 输出

座位的两个坐标，精确到 7 位。任何最优座位都可以。

## 样例

### 样例 1

输入:

```
10 3
1 -1 100
2 2 200
-2.5 -2.56 1
```

输出:

```
6 8
```

## 解法

比其他所有蛋糕都更靠近蛋糕 i 的点构成它的 Voronoi 单元：由各条垂直平分线界定的半平
面之交，是一个包含该蛋糕的凸多边形。座位落在这个单元里就拿到蛋糕 i，所以答案是单元
能伸到桌边的最重的蛋糕。蛋糕本身在桌上，单元又是凸的，因此单元伸到桌边当且仅当它离
圆心最远的顶点距离至少为 R。

从最重的蛋糕开始逐个尝试。对每块蛋糕，从包住桌子的正方形出发，用它与其他蛋糕的垂直
平分线去切，从最近的开始。一旦所有顶点都在桌内就判定失败；当下一块蛋糕的距离超过单
元半径的两倍时停止切割，因为它的平分线已碰不到单元。座位就在从蛋糕到最远顶点的线段
与桌边的交点。每次切割与单元大小成线性，失败的蛋糕的单元在切过几个最近邻居后就缩进
桌内，所以最坏情况下工作量约为 `O(K² log K)`。

注意事项：

- 单元可能只在一点碰到桌边，该点与几块蛋糕等距，要拿最重的那块，所以判断时需要一点
  容差（测试 02）；
- 差几百分之一够不到桌边的单元必须判定失败（测试 07）；
- 最重的蛋糕可能被较轻的蛋糕围住（测试 05、gen2）；
- 蛋糕可以正好放在桌边上（测试 04）；
- 重量都相同时，任何座位都正确（测试 06）；
- 正确的座位很多，所以测试使用检查程序（所有测试）；
- 用所有蛋糕去切每个重蛋糕的单元，在 Python 中约需 3 秒；提前停止把它降到零点几
  秒（gen2、gen6）。
