# 1534. 刚铎足球

[Timus 1534](https://acm.timus.ru/problem.aspx?space=1&num=1534) · 难度 585 · math

原题作者 Sergey Pupyrev，出自 2007 年 3 月 3 日第八届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一支球队踢了 N 场比赛，总共进 K 球、失 L 球（0 ≤ K, L ≤ 10⁹，1 ≤ N ≤ 10⁹）。胜一场得
3 分，平一场得 1 分，负一场得 0 分。求球队可能获得的最多和最少积分。

时间限制：1 秒。内存限制：64 MB。

## 输入

一行中的 K、L 和 N。

## 输出

最多和最少的积分。

## 样例

### 样例 1

输入:

```
3 2 2
```

输出:

```
4 3
```

### 样例 2

输入:

```
3 1 2
```

输出:

```
6 3
```

### 样例 3

输入:

```
3 0 4
```

输出:

```
10 6
```

### 样例 4

输入:

```
3 0 1
```

输出:

```
3 3
```

## 解法

若有 W 场胜、R 场负，球队得 3W + (N − W − R) = N + 2W − R 分。把每场的进球拆成双方相
等的部分和净胜球：相等部分在双方都合计为某个 X ≥ 0，胜场的净胜球合计 K − X，负场的净
负球合计 L − X，且每场胜负至少差一球。相等部分可以放进任意一场。所以
W 胜 R 负可行当且仅当

- W = R = 0 且 K = L；
- R = 0，W ≥ 1 且 K − L ≥ W（L 全部放进相等部分）；
- W = 0，R ≥ 1 且 L − K ≥ R；
- W ≥ 1，R ≥ 1，W ≤ K 且 R ≤ L；所有情况下都有 W + R ≤ N。

接下来在每种情况中求 N + 2W − R 的最大和最小值：设 d = K − L，没有负场时最多
N + 2·min(d, N)，最少 N + 2（d = 0 时为 N）；d < 0 且没有胜场时最多 N − 1，最少 N − min(−d, N)；
胜负都有时最多 N − 1 + 2·min(K, N − 1)，最少 N + 2 − min(L, N − 1)，这需要 K, L ≥ 1 且
N ≥ 2。答案取适用情况中的最优值。数值可达 3·10⁹，需要 64 位整数。`O(1)`。

注意事项：

- 最小值可能同时包含胜和负：样例 1 中一胜一负得 3 分，少于一胜一平；
- 有进球且一球未失的球队至少赢过一场，所以最小值是 N + 2 而不是 N（测试 03、10）；
- 单场 1:1 只能是平局（测试 09）；
- 3·10⁹ − 3 超出 32 位整数（测试 06）。
