# 1523. K-инверсии

[Timus 1523](https://acm.timus.ru/problem.aspx?space=1&num=1523) · сложность 296 · fenwick

Автор оригинальной задачи — Дмитрий Гозман; Dmitry Gozman Contest 1 на Петрозаводских зимних сборах, январь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дана перестановка a1, …, an чисел 1 … n (1 ≤ n ≤ 20000). Нужно
посчитать её k-инверсии (2 ≤ k ≤ 10) — последовательности индексов
i1 < i2 < … < ik с ai1 > ai2 > … > aik — и вывести их число по модулю
10⁹.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n и k, затем перестановка.

## Выходные данные

Число k-инверсий по модулю 10⁹.

## Примеры

### Пример 1

Ввод:

```
3 2
3 1 2
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
5 3
5 4 3 2 1
```

Вывод:

```
10
```

## Решение

Пусть ends[i] — число убывающих цепочек длины L, кончающихся в позиции
i; при L = 1 это везде 1. Цепочка длины L + 1, кончающаяся в i, — это
цепочка длины L, кончающаяся в более ранней позиции p с ap > ai, и
затем i. Поэтому каждый уровень — один проход слева направо с деревом
Фенвика по значениям: запрашиваем сумму по значениям больше ai, затем
добавляем ends[i] в ai. Если считать значения сверху, «больше»
превращается в префикс. k − 1 проход даёт `O(n·k·log n)`.

Подводные камни:

- k может превышать длину самой длинной убывающей цепочки и даже n, и
  тогда ответ 0 (тесты 04, 05, gen3);
- числа растут как C(20000, 10), поэтому их надо брать по модулю 10⁹
  при сложении (gen2, gen5).
