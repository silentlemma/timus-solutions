## Задача

N солдат (1 ≤ N ≤ 100000) с номерами от 1 до N маршируют по кругу. В
каждом раунде один солдат выбывает: сначала солдат K (1 ≤ K ≤ N), затем
каждый раз солдат на K позиций впереди выбывшего последним, считая
только тех, кто ещё марширует. Нужно вывести солдат в порядке выбывания.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и K.

## Выходные данные

Номера солдат в порядке выбывания.

## Примеры

### Пример 1

Ввод:

```
5 3
```

Вывод:

```
3 1 5 2 4
```

## Решение

Пронумеруем ещё марширующих солдат 0, 1, … по кругу. Если выбывший
последним имел среди них ранг r, то у следующего ранг
(r + K − 1) mod (оставшиеся солдаты), потому что место выбывшего
занимает следующий солдат. Дерево Фенвика хранит 1 для каждого
марширующего солдата; спуск по степеням двойки находит солдата с
заданным рангом за `O(log N)`, а удаление — это точечное изменение.
Всего `O(N log N)`.

Подводные камни:

- удаление из обычного списка стоит `O(N)` за раунд, всего `O(N²)`,
  слишком медленно для 100000 солдат (gen1);
- при K = 1 солдаты выбывают по порядку (тест 03, gen5);
- при K = N первым выбывает последний солдат (тест 04, gen4).

## Оптимизированные решения

Оптимизированное решение на C++ заполняет дерево сразу, записывая в
каждый узел длину его отрезка, ведь в начале марширует каждый солдат, и
удаляет солдата во время самого поиска: узлы, где спуск не шагает
вперёд, — это ровно те узлы, чей отрезок содержит найденного солдата,
поэтому они уменьшаются по пути вниз, без второго прохода. Дерево лежит
в статическом массиве, а каждое число сразу печатается через `printf`,
вместо того чтобы собирать вывод в строку: {1521_fenwick_optimized.cpp}.
