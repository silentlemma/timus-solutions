# 1566. Треугольные открытки

[Timus 1566](https://acm.timus.ru/problem.aspx?space=1&num=1566) · сложность 3016 · geometry

Автор оригинальной задачи — Владимир Яковлев; XII чемпионат УрГУ по программированию, 6 октября 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны целые длины сторон треугольного конверта и треугольной открытки, все
не больше 1000 миллиметров. Нужно определить, помещается ли открытка в
конверт. Открытку можно сдвигать, поворачивать и переворачивать, и она
может касаться краёв конверта.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Стороны конверта в первой строке, стороны открытки во второй.

## Выходные данные

`YES` или `NO`.

## Примеры

### Пример 1

Ввод:

```
30 40 50
50 36 27
```

Вывод:

```
YES
```

### Пример 2

Ввод:

```
200 200 200
210 110 110
```

Вывод:

```
NO
```

## Решение

Треугольник помещается в другой ровно тогда, когда он помещается так,
что одна из его сторон лежит на стороне другого. Для доказательства
возьмём внешние нормали n к сторонам конверта, длины которых равны
длинам сторон: их сумма равна нулю. При фиксированном повороте открытки
пусть F — сумма max(n · v) по её вершинам v, по одному максимуму для
каждой нормали. Сдвиг существует ровно тогда, когда F не больше
удвоенной площади конверта: три полуплоскости допустимых сдвигов тогда
имеют непустое пересечение.

Между поворотами, в которых меняется опорная вершина открытки, F имеет
вид A cos θ + B sin θ. Она положительна, поэтому F″ = −F < 0, и минимум
на каждом таком промежутке достигается на его границе. Там опорная
сторона открытки параллельна стороне конверта. Допустимым сдвигом можно
совместить эти стороны, что и доказывает достаточность перебора.

Значит, нужно перебрать 3 · 3 · 2 положения: сторона открытки на
стороне конверта, открытка перевёрнута или нет. Пусть сторона конверта
идёт от (0, 0) до (m, 0), его вершина — (w, H), а вершина открытки —
(u, h) над началом её стороны длины ℓ, и открытка сдвигается вдоль
стороны на t. Она помещается, когда ℓ ≤ m, h ≤ H и некоторое t из
[0, m − ℓ] ставит её вершину между двумя другими сторонами конверта:

h·w / H ≤ t + u ≤ m − h·(m − w) / H.

Это пересечение отрезков. Касание допускается, поэтому вещественные
сравнения при проверке размещения делаются с допуском 10⁻⁹. Плоский
конверт, если он встретится, вмещает только плоскую открытку не длиннее
себя. Всё это занимает постоянное время.

Подводные камни:

- открытка может совпадать с конвертом и касаться его всюду (тест 03);
- длинной стороны мало: игла длины 999 с концом в 2 мм слишком широка у
  этого конца, чтобы войти в угол 60° равностороннего конверта со
  стороной 1000 мм (тест 05);
- вершина открытки может лежать за концом её основания, если угол при
  этом конце тупой; то же верно для конверта (тест 07);
- кратчайшая сторона открытки может быть длиннее кратчайшей стороны
  конверта: нужно проверять положения, а не сравнивать отсортированные
  длины сторон (тест 14).
