# 1566. 三角形明信片

[Timus 1566](https://acm.timus.ru/problem.aspx?space=1&num=1566) · 难度 3034 · geometry

原题作者 Vladimir Yakovlev，出自 2007 年 10 月 6 日第十二届乌拉尔国立大学程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定三角形信封和三角形明信片的整数边长，都不超过 1000 毫米，判断明信片能否放进信封。明信片可以平移、
旋转和翻面，也可以碰到信封的边。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行是信封的边，第二行是明信片的边。

## 输出

`YES` 或 `NO`。

## 样例

### 样例 1

输入:

```
30 40 50
50 36 27
```

输出:

```
YES
```

### 样例 2

输入:

```
200 200 200
210 110 110
```

输出:

```
NO
```

## 解法

一个三角形能放进另一个三角形，当且仅当它能以自己的某条边贴在另一个三角形的某条边上放进去。这是关于两个
三角形的已知事实，这里也做了验证：对明信片的转角做细密搜索，并对每个转角精确判断（存在平移，当且仅当
对信封各边求“边长 × 明信片越过该边方向的最远距离”之和不超过面积的两倍），在约 600 对随机三角形上与这条
规则一致，独立程序也是如此。

所以要试 3 · 3 · 2 种放法：明信片的哪条边贴在信封的哪条边上，以及是否翻面。设信封的边从 (0, 0) 到
(m, 0)，其顶点为 (w, H)；明信片长为 ℓ 的边从起点出发，其顶点在 (u, h)，明信片沿边滑动 t。当 ℓ ≤ m、
h ≤ H，且 [0, m − ℓ] 中有某个 t 使其顶点位于信封另两条边之间时，它就放得下：

h·w / H ≤ t + u ≤ m − h·(m − w) / H。

两端都是 t 的线性函数，所以只是区间求交。碰到也算放得下，所以所有比较都允许 10⁻⁹ 的误差。若给出的信封
是扁平的，它只能装下不比它长的扁平明信片。全部只需常数时间。

注意事项：

- 明信片可能与信封完全相同，处处相接（测试 03）；
- 只看最长边不够：长 999、一端宽 2 毫米的针，在那一端太宽，伸不进边长 1000 毫米的等边信封的 60° 角
  （测试 05）；
- 明信片在某边处有钝角时，其顶点可能落在这条边的两端之外，信封也是如此（测试 07）。
