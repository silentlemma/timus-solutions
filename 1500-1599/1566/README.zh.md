# 1566. 三角形明信片

[Timus 1566](https://acm.timus.ru/problem.aspx?space=1&num=1566) · 难度 3016 · geometry

原题作者 Vladimir Yakovlev，出自 2007 年 10 月 6 日第十二届乌拉尔国立大学程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定三角形信封和三角形明信片的整数边长，都不超过 1000 毫米，判断明信片能否放进信封。明信片可以平移、
旋转和翻面，也可以碰到信封的边。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行是信封的边，第二行是明信片的边。

## 输出

`YES` 或 `NO`。

## 样例

### 样例 1

输入:

```
30 40 50
50 36 27
```

输出:

```
YES
```

### 样例 2

输入:

```
200 200 200
210 110 110
```

输出:

```
NO
```

## 解法

一个三角形能放进另一个三角形，当且仅当它能以自己的某条边贴在另一个三角形的某条边上放进去。
证明如下：取信封各边的外法向量 n，向量长度等于对应边长，因此它们的和为零。固定明信片的转角，
对每个法向量求明信片顶点 v 的 max(n · v)，再将三个最大值相加，记为 F。当且仅当 F 不超过信封面积的
两倍时存在可行平移，因为此时描述平移的三个半平面有非空交集。

在支撑顶点不变的转角区间内，F 的形式为 A cos θ + B sin θ。F 为正，因此 F″ = −F < 0，
每个区间的最小值都在端点取得。此时明信片的一条支撑边与信封的一条边平行；若存在可行平移，
就能使这两条边相接。因此只需枚举边贴边的放法。

所以要试 3 · 3 · 2 种放法：明信片的哪条边贴在信封的哪条边上，以及是否翻面。设信封的边从 (0, 0) 到
(m, 0)，其顶点为 (w, H)；明信片长为 ℓ 的边从起点出发，其顶点在 (u, h)，明信片沿边滑动 t。当 ℓ ≤ m、
h ≤ H，且 [0, m − ℓ] 中有某个 t 使其顶点位于信封另两条边之间时，它就放得下：

h·w / H ≤ t + u ≤ m − h·(m − w) / H。

这里只需区间求交。碰到也算放得下，所以放置检查中的浮点比较允许 10⁻⁹ 的误差。若给出的信封
是扁平的，它只能装下不比它长的扁平明信片。全部只需常数时间。

注意事项：

- 明信片可能与信封完全相同，处处相接（测试 03）；
- 只看最长边不够：长 999、一端宽 2 毫米的针，在那一端太宽，伸不进边长 1000 毫米的等边信封的 60° 角
  （测试 05）；
- 底边某个端点处的角为钝角时，明信片的顶点可能落在该端点之外，信封也是如此（测试 07）；
- 明信片的最短边可以长于信封的最短边；应检查实际放法，而不能逐项比较排序后的边长（测试 14）。
