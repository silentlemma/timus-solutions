# 1528. Последовательность

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

При f(1) = g(1) = 1
f(n) = 1 + f(1)g(1) + … + f(n − 1)g(n − 1) и
g(n) = 1 + 2g(1) + … + 2g(n − 1) − g(n − 1)². Для не более чем 5000
случаев (1 ≤ n ≤ 10000, 2 ≤ p ≤ 2·10⁹) нужно вывести f(n) mod p.

Ограничение времени: 3 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Пары n и p по одной в строке, в конце 0 0.

## Выходные данные

f(n) mod p для каждого случая.

## Примеры

### Пример 1

Ввод:

```
1 2
2 11
0 0
```

Вывод:

```
1
2
```

## Решение

У обеих последовательностей есть явные формулы. Если g(i) = i при
i < n, то g(n) = 1 + (n − 1)n − (n − 1)² = n. Тогда
f(n) − f(n − 1) = f(n − 1)·(n − 1), так что f(n) = n·f(n − 1) = n!.
Значит, в каждом случае нужно n! mod p. При n ≥ p само p — один из
множителей, и ответ 0. Иначе перемножаем до n, беря остаток по пути;
произведения остаются меньше 2·10¹³, в пределах 64 бит. Это до 5·10⁷
умножений на все случаи — быстро в компилируемых языках. На Python
простой цикл занимает около 6 секунд, поэтому решение на Python хранит
точные факториалы всех кратных 100 как длинные числа, берёт остаток от
одного из них и домножает не больше 99 множителей.

Подводные камни:

- формулы выглядят тяжело, но g(n) = n и f(n) = n! (все тесты);
- при n ≥ p ответ сразу 0 (тест 02, gen3);
- p доходит до 2·10⁹, поэтому произведениям нужны 64 бита (тест 03,
  gen1);
- простое p чуть больше n — хорошая проверка: по теореме Вильсона
  (p − 1)! ≡ −1 (тест 05).
