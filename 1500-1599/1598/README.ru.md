# 1598. Атака на DSA

[Timus 1598](https://acm.timus.ru/problem.aspx?space=1&num=1598) · сложность 3599 · math

Оригинальную задачу подготовил Владимир Яковлев.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Открытый ключ DSA (q, p, g, y) состоит из N-битного простого q
(3 ≤ N ≤ 36), L-битного простого p (L ≤ 60), где q делит p − 1, g порядка
q по модулю p и y = gˣ mod p для секретного 0 < x < q. По ключу и хешу H
нужно вывести любую действительную подпись (r, s): 0 < r, s < q и при
w = s⁻¹, u₁ = H·w и u₂ = r·w по модулю q выполнено
((g^u₁·y^u₂) mod p) mod q = r.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, L, q, p, g, y и H.

## Выходные данные

r и s.

## Примеры

### Пример 1

Ввод:

```
3 6 5 41 10 16 2
```

Вывод:

```
3 3
```

## Решение

Хеш задан, поэтому обычные приёмы, подделывающие подпись для какого-то
сообщения, не помогают: решение находит секретный ключ. Порядок g равен
q, так что x — дискретный логарифм y в группе не больше чем из 2³⁶
элементов, и метод «шаг младенца, шаг великана» требует примерно √q шагов
(√q < 2¹⁸): gʲ mod p при j < m = ⌈√q⌉ кладутся в хеш-таблицу, а затем y
умножается на g⁻ᵐ = g^(q − m) по модулю p до совпадения со значением
в таблице; если это gʲ после i шагов, то x = i·m + j.

Зная x, подпись строим, как сказано в условии, перебирая k = 1, 2, …,
пока r = (gᵏ mod p) mod q и s = k⁻¹(H + x·r) mod q оба не станут
ненулевыми. q простое, так что k⁻¹ = k^(q − 2) mod q. Проверка тогда
проходит: u₁ + x·u₂ ≡ (H + x·r)·w ≡ k (mod q), поэтому
g^u₁·y^u₂ ≡ gᵏ (mod p). В таблице указано ожидаемое время для t попыток
выбора k.

Тесты проверяет чекер, который проверяет подпись так же, как условие. Он
принял вывод на ключах, построенных ровно как описано, с размерами от
крошечных до N = 36, L = 60.

Подводные камни:

- у p до 60 бит, так что произведениям может понадобиться до 120 бит:
  C++ и Rust берут 128-битные целые, Go — bits.Mul64 с bits.Rem64,
  а Java 8, где нет ни того ни другого, умножает по два бита, чтобы каждая
  сумма оставалась меньше 2⁶³;
- при k = 1 может получиться r = g mod q = 0 (так и есть в примере),
  поэтому k нужно перебирать дальше;
- H помещается в N бит и может быть больше q; оно берётся по модулю q.
