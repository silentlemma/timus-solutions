# 1585. Пингвины

[Timus 1585](https://acm.timus.ru/problem.aspx?space=1&num=1585) · сложность 38 · implementation

Автор оригинальной задачи — Владимир Яковлев; ACM ICPC 2007–2008, NEERC, Восточный подрегион, Екатеринбург, 27 октября 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В блокноте записаны N ≤ 1000 пингвинов, каждый как «Emperor Penguin»,
«Little Penguin» или «Macaroni Penguin». Нужно вывести вид, который
встречается чаще всех; он единственный.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем по одному виду в строке.

## Выходные данные

Самый частый вид.

## Примеры

### Пример 1

Ввод:

```
7
Emperor Penguin
Macaroni Penguin
Little Penguin
Emperor Penguin
Macaroni Penguin
Macaroni Penguin
Little Penguin
```

Вывод:

```
Macaroni Penguin
```

## Решение

Посчитаем записи по первому слову и выведем вид с наибольшим числом, а
после него «Penguin». `O(N)`.

Подводные камни:

- в каждой записи есть пробел, так что её читают либо целой строкой,
  либо двумя словами;
- какого-то вида может не быть вовсе (тест 03).

## Оптимизированные решения

Три вида начинаются с разных заглавных букв, E, L и M, а слово «Penguin»
и число `N` ни одной из них не содержат, поэтому достаточно посчитать
эти буквы во всём вводе и выбрать наибольший счётчик. Оптимизированное
решение на C++ вообще не читает слова и считает буквы через `getchar`, а
ответ выводит через `puts` вместо `iostream`: 88 КБ вместо 388 КБ при
том же времени. Оптимизированное решение на Java считает их, читая блоки
по 256 байт: 0.109 с вместо 0.171 с и 328 КБ вместо 4576 КБ.

Оптимизированное решение на Python считает полные названия в исходных
байтах через `bytes.count`: 348 КБ вместо 512 КБ при том же времени.
