# 1560. Элементарные симметрические функции

[Timus 1560](https://acm.timus.ru/problem.aspx?space=1&num=1560) · сложность 931 · fenwick

Оригинальная задача — Novosibirsk SU Contest, Петрозаводские сборы, сентябрь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

К массиву из N ≤ 80000 целых чисел поступает M ≤ 100000 запросов двух
видов: `I i d` прибавляет d к A[i], а `C l r K` (1 ≤ K ≤ 4) спрашивает
элементарные симметрические многочлены S(0), …, S(K) от A[l..r], где
S(j) — сумма произведений всех j-элементных подмножеств. Ответы берутся
по модулю простого 1000 ≤ P ≤ 10⁹. Начальные значения и изменения по модулю не
больше 10⁵.

Ограничение времени: 4 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, M и P, затем массив, затем запросы.

## Выходные данные

Для каждого запроса `C` — S(0) … S(K) в виде вычетов по модулю P в одной
строке.

## Примеры

### Пример 1

Ввод:

```
7 6 1237
0 0 1 1 1 1 1
C 3 3 1
C 1 6 4
I 1 -1235
C 1 7 3
I 4 1
C 2 5 4
```

Вывод:

```
1 1
1 4 6 4 1
1 7 20 30
1 4 5 2 0
```

## Решение

Степенные суммы p(j) = Σ a^j на отрезке поддерживать легко: четыре дерева
Фенвика хранят их для j = 1…4, обновление меняет каждую на
new^j − old^j, а запрос берёт разность двух префиксных сумм.
Элементарные многочлены получаются из тождеств Ньютона,
k·S(k) = S(k−1)·p(1) − S(k−2)·p(2) + S(k−3)·p(3) − …, где S(0) = 1.
P — простое больше 4, поэтому деление на k ≤ 4 — это умножение на
обратный элемент по модулю P.

Узлы деревьев хранят суммы без приведения: каждая начинается как сумма
не более N вычетов, а каждое обновление добавляет разность двух вычетов,
так что они остаются меньше примерно 2·10¹⁴ и помещаются в 64 бита; по
модулю они приводятся только при чтении запросом. Каждый запрос
занимает O(K log N) времени, всего O((N + M) log N). Результаты сверены
с прямым произведением по отрезку на случайных маленьких тестах.

Подводные камни:

- значения и изменения бывают отрицательными, а ответы должны быть
  вычетами от 0 до P − 1 (тесты 03, 04);
- четвёртая степень значения около 10⁹ переполняет 64 бита, если не
  приводить каждое умножение (тест 05);
- P может быть меньше значений, поэтому значения сначала приводятся
  (тест 06).
