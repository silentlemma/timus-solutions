# 1560. 初等对称函数

[Timus 1560](https://acm.timus.ru/problem.aspx?space=1&num=1560) · 难度 933 · fenwick

原题出自 2007 年 9 月彼得罗扎沃茨克集训的 Novosibirsk SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对一个由 N ≤ 80000 个整数组成的数组进行 M ≤ 100000 次两类查询：`I i d` 把 d 加到 A[i] 上；
`C l r K`（1 ≤ K ≤ 4）询问 A[l..r] 的初等对称多项式 S(0), …, S(K)，其中 S(j) 是所有 j 元子集
之积的和。答案对素数 1000 ≤ P ≤ 10⁹ 取模。数值和改变量的绝对值都不超过 10⁵。

时间限制：4 秒。内存限制：64 MB。

## 输入

N、M 和 P，然后是数组，再是各个查询。

## 输出

对每个 `C` 查询，在一行中输出模 P 的余数 S(0) … S(K)。

## 样例

### 样例 1

输入:

```
7 6 1237
0 0 1 1 1 1 1
C 3 3 1
C 1 6 4
I 1 -1235
C 1 7 3
I 4 1
C 2 5 4
```

输出:

```
1 1
1 4 6 4 1
1 7 20 30
1 4 5 2 0
```

## 解法

区间上的幂和 p(j) = Σ a^j 很容易维护：四棵树状数组分别保存 j = 1…4 的幂和，更新时每个幂和改变
new^j − old^j，查询取两个前缀和之差。初等多项式由牛顿恒等式得到：
k·S(k) = S(k−1)·p(1) − S(k−2)·p(2) + S(k−3)·p(3) − …，其中 S(0) = 1。P 是大于 4 的素数，所以除以
k ≤ 4 就是乘以它模 P 的逆元。

树的结点保存不取模的和：每个和起初是至多 N 个余数之和，每次更新加上两个余数之差，所以它们保持在约
2·10¹⁴ 以下，放得进 64 位；只在查询读取时才取模。每次查询耗时 O(K log N)，总计
O((N + M) log N)。结果已在随机小测试上与对区间直接求积的结果对照。

注意事项：

- 数值和改变量可能为负，而答案必须是 0 到 P − 1 之间的余数（测试 03、04）；
- 接近 10⁹ 的数的四次方会溢出 64 位，除非每次乘法都取模（测试 05）；
- P 可能比数值小，所以先对数值取模（测试 06）。
