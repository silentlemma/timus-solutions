# 1587. 飞猪

[Timus 1587](https://acm.timus.ru/problem.aspx?space=1&num=1587) · 难度 819 · greedy

原题作者 Sergey Pupyrev，出自 2007 年 10 月 27 日在叶卡捷琳堡举行的 ACM ICPC 2007–2008 NEERC 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

观众给一头猪打了 n 个分（1 ≤ n ≤ 50000），每个分是 −3 到 3 之间的整数。求一段非空连续分数乘积的最大值。

时间限制：0.75 秒。内存限制：64 MB。

## 输入

n，然后是 n 个分数。

## 输出

最大乘积的完整数值。

## 样例

### 样例 1

输入:

```
3
1 2 -1
```

输出:

```
2
```

## 解法

零把分数切成若干段。段内每个分数的绝对值至少为 1，所以更长的一段绝对值乘积不会更小，乘积等于 ±2ᵃ·3ᵇ，其中 a 和 b
分别是 ±2 和 ±3 的个数。段内负数个数为偶数时整段为正；为奇数时，最好的正区间要么去掉第一个负数及其之前的部分，要么去掉最后一个负数及其之后的部分。
用前缀计数得到每个候选的 a 和 b，按 a·ln 2 + b·ln 3 比较；不同的 (a, b) 不会接近到让双精度数分不清。只有最终答案才转成大整数。

如果不存在正区间，每段都只是一个负数：有零时答案为 0，否则就是这个负数本身（此时 n = 1）。复杂度为 `O(n + B(n))`，其中 B(n) 是构造并输出大整数的时间（C++/Rust 中为 `O(n²)`）。
结果已在小数据上与枚举所有区间并精确计算乘积的做法对照。

注意事项：

- 答案可达 3⁵⁰⁰⁰⁰，将近 24000 位；C++ 和 Rust 以 10⁹ 为基手工相乘，Python 3.12 需要解除长整数转文本的位数限制；
- 每段都做大整数乘法太慢；比较指数，只构造答案；
- 单独一个负数就是答案，而 −1 0 −1 的答案是 0。
