# 1587. Летающая свинья

[Timus 1587](https://acm.timus.ru/problem.aspx?space=1&num=1587) · сложность 821 · greedy

Автор оригинальной задачи — Сергей Пупырев; ACM ICPC 2007–2008, NEERC, Восточный подрегион, Екатеринбург, 27 октября 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Зрители ставят свинье n оценок (1 ≤ n ≤ 50000), каждая — целое число от
−3 до 3. Нужно найти наибольшее произведение непустого отрезка подряд
идущих оценок.

Ограничение времени: 0.75 секунды. Ограничение памяти: 64 МБ.

## Входные данные

n, затем n оценок.

## Выходные данные

Наибольшее произведение, полностью.

## Примеры

### Пример 1

Ввод:

```
3
1 2 -1
```

Вывод:

```
2
```

## Решение

Нули режут оценки на куски. Внутри куска каждая оценка по модулю не
меньше 1, так что более длинный отрезок никогда не даёт меньшего модуля
произведения, а само произведение равно ±2ᵃ·3ᵇ, где a и b — количества
оценок ±2 и ±3. При чётном числе отрицательных оценок весь кусок
положителен. При нечётном лучший положительный отрезок отбрасывает либо
всё до первой отрицательной оценки включительно, либо всё начиная с
последней. Префиксные количества дают a и b каждого кандидата, а
кандидаты сравниваются по a·ln 2 + b·ln 3; разные пары (a, b) никогда не
сходятся настолько близко, чтобы вещественные числа их перепутали.
Длинным числом становится только победитель.

Если положительного отрезка нет, каждый кусок — одна отрицательная
оценка: ответ 0, если есть ноль, а иначе сама оценка (тогда n = 1).
`O(n)` плюс итоговое умножение. Результаты сверены с перебором всех
отрезков с точными произведениями на маленьких входах.

Подводные камни:

- ответ доходит до 3⁵⁰⁰⁰⁰, почти 24000 цифр; C++ и Rust умножают
  вручную в системе по основанию 10⁹, а в Python 3.12 нужно снять
  ограничение на перевод длинных чисел в текст;
- перемножать длинные числа для каждого куска слишком медленно;
  сравниваются показатели, а строится только ответ;
- одна отрицательная оценка сама себе ответ, а −1 0 −1 даёт 0.
