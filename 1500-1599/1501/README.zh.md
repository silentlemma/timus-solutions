# 1501. 美感

[Timus 1501](https://acm.timus.ru/problem.aspx?space=1&num=1501) · 难度 268 · dp

原题作者 Leonid Volkov 与 Stanislav Vasiliev，出自 2006 年第 31 届 ACM ICPC 叶卡捷琳堡四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两叠牌各 N 张（4 ≤ N ≤ 1000），共有 N 张红牌和 N 张黑牌。荷官反复从某一叠取出最上
面的牌，放到红牌叠或黑牌叠上，直到所有牌都移完。任何时刻红牌叠与黑牌叠的张数之差
不能超过一。输出每张牌取自哪一叠——2N 个数字 1 和 2，或 "Impossible"。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

N，然后是两叠牌从上到下的颜色，1 为红，0 为黑。

## 输出

2N 个数字，或 "Impossible"。任何符合要求的顺序都可以。

## 样例

### 样例 1

输入:

```
4
0011
0110
```

输出:

```
22121112
```

### 样例 2

输入:

```
4
1100
1100
```

输出:

```
Impossible
```

## 解法

一个时刻由从两叠各取了 i 张和 j 张来描述。对每叠已取出的部分令
d = 2 · (红牌数) − (张数)，则红牌叠与黑牌叠相差 d1[i] + d2[j]，当它为 −1、0 或 1
时状态合法。若状态合法且其上方或左边的状态可达，则它可达；(0, 0) 为起点。若
(N, N) 可达，就从它往回走，任选一个可达的前驱，再把步骤倒过来读出。`O(N²)`。

注意事项：

- 条件在每一步之后都要成立，而不仅仅是最后（测试 02、gen4）；
- 正确的顺序可能有很多，所以测试使用检查程序（所有测试）；
- 时间限制只有 0.5 秒，N² 个状态的表必须很省；Python 解法把每一行存成一个整数掩
  码，并用一次加法让可达性沿着连续的合法状态传播。
