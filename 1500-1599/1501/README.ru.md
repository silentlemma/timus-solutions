# 1501. Чувство прекрасного

[Timus 1501](https://acm.timus.ru/problem.aspx?space=1&num=1501) · сложность 268 · dp

Авторы оригинальной задачи — Леонид Волков и Станислав Васильев; четвертьфинал XXXI ACM ICPC, Екатеринбург, 2006 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В двух стопках по N карт (4 ≤ N ≤ 1000) всего N красных и N чёрных карт.
Крупье раз за разом берёт верхнюю карту одной из стопок и кладёт её в
красную или чёрную стопку, пока не переложит все карты. В каждый момент
красная и чёрная стопки могут отличаться не больше чем на одну карту.
Нужно вывести, из какой стопки берётся каждая карта, — 2N цифр 1 и 2,
или «Impossible».

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем две стопки сверху вниз, 1 — красная карта, 0 — чёрная.

## Выходные данные

2N цифр или «Impossible». Подходит любой верный порядок.

## Примеры

### Пример 1

Ввод:

```
4
0011
0110
```

Вывод:

```
22121112
```

### Пример 2

Ввод:

```
4
1100
1100
```

Вывод:

```
Impossible
```

## Решение

Момент описывается числами i и j карт, взятых из двух стопок. Если
положить d = 2 · (красные карты) − (карты) по взятой части каждой
стопки, то красная и чёрная стопки отличаются на d1[i] + d2[j], и
состояние допустимо, когда это −1, 0 или 1. Состояние достижимо, если
оно допустимо и достижимо состояние над ним или слева от него; (0, 0) —
начало. Если (N, N) достижимо, идём от него назад, беря любого
достижимого предшественника, и читаем ходы в обратном порядке.
`O(N²)`.

Подводные камни:

- условие действует после каждого хода, а не только в конце (тест 02,
  gen4);
- верных порядков может быть много, поэтому тесты проверяются чекером
  (все тесты);
- при ограничении в 0,5 секунды таблица из N² состояний должна быть
  дешёвой; решение на Python хранит каждую строку одной целочисленной
  маской и распространяет достижимость по отрезкам допустимых состояний
  одним сложением.
