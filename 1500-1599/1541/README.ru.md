# 1541. Погоня

[Timus 1541](https://acm.timus.ru/problem.aspx?space=1&num=1541) · сложность 2122 · backtracking

Автор оригинальной задачи — Александр Ипатов; Восьмое открытое личное первенство УрГУ, 3 марта 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Друзья пробежали K лиг (K < 20), i-ю лигу с целой скоростью Vi лиг в
час, каждую медленнее предыдущей (Vi < Vj при i > j) и ни одну быстрее
100000. Погоня заняла M/N часов, где M и N взаимно просты,
1 ≤ M, N ≤ 50 и M/N ≤ 3. Нужно найти K и скорости или вывести -1, если
их нет. Подходит любой ответ.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

M и N.

## Выходные данные

K, затем V1 … VK.

## Примеры

### Пример 1

Ввод:

```
2 3
```

Вывод:

```
2
6 2
```

## Решение

Время равно 1/V1 + … + 1/VK, так что M/N нужно записать суммой меньше
чем 20 различных аликвотных дробей со знаменателями до 10⁵, перечисленных
от большего знаменателя к меньшему.

Ищем перебором с итеративным углублением по числу дробей, выбирая
знаменатели по возрастанию. Если осталось покрыть p/q не более чем
`left` дробями после знаменателя `last`, то следующий знаменатель d
удовлетворяет условиям

- d > last и 1/d ≤ p/q, то есть d ≥ ⌈q/p⌉;
- `left` дробей не больше 1/d должны дотянуться до p/q, то есть
  d ≤ left·q/p;
- наибольшая возможная сумма `left` дробей начиная с d — отрезок
  гармонического ряда по префиксным суммам — должна достигать p/q, как
  до выбора d, так и для остатка после него.

Остаток хранится несократимой дробью. Её числитель и знаменатель держатся
ниже 2⁶¹, чтобы в языках с 64-битными числами не было переполнения;
ветви, которые вышли бы за эту границу, пропускаются, причём во всех
языках одни и те же, поэтому все пять обходят одно и то же дерево.

Прогнаны все 1291 допустимых входа: у каждого есть ответ, не больше чем
из 13 дробей (при M/N около 3 нужны почти все маленькие знаменатели),
наибольший знаменатель меньше 10⁵, а самый медленный вход занимает около
0,3 с в Python. Ответы проверены точно, дробями.

Подводные камни:

- скорости выводятся по убыванию, в обратном порядке поиска (все тесты);
- для 3/1 нужны 1, 1/2, …, 1/10 и ещё три дроби (тест 02);
- ответ может состоять из одной дроби, даже 1/1 (тесты 03, 04);
- без указанной границы произведения знаменателей переполняют 64 бита;
- ответов бывает несколько, поэтому тесты проверяет чекер (все тесты).

Сложность: `O(D^K)` в худшем случае для K дробей со знаменателями до D =
10⁵.
