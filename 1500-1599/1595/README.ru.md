# 1595. Совершенная последовательность

[Timus 1595](https://acm.timus.ru/problem.aspx?space=1&num=1595) · сложность 1154 · constructive

Автор оригинальной задачи — Александр Бачериков.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно вывести последовательность различных целых положительных чисел, не
больше 10¹³ каждое, которая содержит все числа 1, 2, …, N
(1 ≤ N ≤ 250000), имеет не больше 2N членов и в которой сумма первых k
членов делится на k при каждом k. Подходит любая такая
последовательность.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

Последовательность через пробел.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
1 3 2 6 8
```

## Решение

Расставим числа 1, 2, …, N по порядку, каждое после одного лишнего члена
x: если S — сумма до сих пор, а k — место для x, то x должен сделать
S + x кратным k, а затем S + x + m кратным k + 1 для следующего числа m.
Значит, x ≡ a = −S (mod k) и x ≡ b = −S − m (mod k + 1). Так как k и
k + 1 взаимно просты, китайская теорема об остатках даёт один класс по
модулю k(k + 1), и его легко выписать: x = a + k·t, а k ≡ −1 (mod k + 1),
так что t ≡ a − b (mod k + 1), и обратный элемент не нужен. Первое x
класса больше N не совпадает с числами 1..N, а шаги на k(k + 1) мимо
редких прежних лишних членов сохраняют все члены различными. В
последовательности ровно 2N членов, и `O(N)` шагов с хеш-множеством
строят её.

Каждое x не превышает N + k(k + 1), если не приходится обходить
занятое значение, а k < 2N, так что члены намного меньше 10¹³; при
N = 250000 наибольший около 5·10⁸. Тесты проверяет чекер, который
прогнан на всех N до 300 и на наибольшем N.

Подводные камни:

- ответ из примера лишь один из многих; чекер принимает любую верную
  последовательность;
- суммы префиксов доходят примерно до 6·10¹³, больше 32-битных чисел;
- 500000 чисел — это несколько мегабайт вывода, поэтому вывод
  буферизуется, а не пишется по одному числу.
