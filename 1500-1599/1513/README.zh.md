# 1513. 柠檬寓言

[Timus 1513](https://acm.timus.ru/problem.aspx?space=1&num=1513) · 难度 381 · dp

原题作者 Nikita Rybak、Ilya Grebnov 与 Dmitry Kovalioff，出自 Timus Top Coders: Third Challenge。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一篇文章里 "柠檬" 一词出现了 N 次（1 ≤ N ≤ 10000）。可以把其中一些换成 "香蕉"，使连
续的柠檬不超过 K 个（0 ≤ K ≤ N）。求准确的方案数。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 K。

## 输出

方案数。

## 样例

### 样例 1

输入:

```
5 2
```

输出:

```
24
```

## 解法

设 a[i] 为 i 个词中没有超过 K 个连续柠檬的序列数。i 个词的合法序列是 i − 1 个词的合
法序列再加一个词（柠檬或香蕉），得 2·a[i − 1]，但要去掉新柠檬恰好形成 K + 1 个连续
柠檬的序列：它们是 i − K − 2 个词的合法序列、一个香蕉和 K + 1 个柠檬，所以 i > K
时 a[i] = 2·a[i − 1] − a[i − K − 2]，其中 a[−1] = 1 对应全是柠檬的序列；i ≤ K 时
a[i] = 2^i。没有取模，所以要用大整数；Python、Go 和 Java 自带，C++ 和 Rust 用 10⁹
进制的数组。最坏 `O(N²)` 次数位运算。

注意事项：

- 答案要精确，最大到 2^10000，约 3000 位（测试 04、07）；
- K = 0 时只剩全是香蕉的一种（测试 05）；
- K = 1 时得到斐波那契数（测试 06）；
- 减法要用到 i − K − 2 个词的序列，即使它是 −1 个词，也就是 K + 1 个连续柠檬的情
  况（测试 01、gen3）。

## 优化解法

Go 和 Rust 版本沿用同一个递推式，并用环形缓冲区保存历史值。某个值被减去后，对应位置即可复用。只保存到第 N 个位置之前还会用到的值，因此最多需要 min(K + 2, N − K) 个位置。Go 原地更新大整数。Rust 用 32 位整数保存各数位块，并在相邻两项之间交替复用两个缓冲区。通过评测的 Go 版本用时 0.031 秒、占用 5652 KB，基础版用时 0.062 秒、占用 9884 KB。Rust 版本占用 2564 KB，基础版占用 15176 KB，两者均用时 0.031 秒。
