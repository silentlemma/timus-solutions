## Задача

В тексте слово «лимон» встречается N раз (1 ≤ N ≤ 10000). Некоторые из
них можно заменить на «банан» так, чтобы подряд стояло не больше K
лимонов (0 ≤ K ≤ N). Нужно точно посчитать число способов.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и K.

## Выходные данные

Число способов.

## Примеры

### Пример 1

Ввод:

```
5 2
```

Вывод:

```
24
```

## Решение

Пусть a[i] — число строк из i слов без серии длиннее K лимонов. Верная
строка из i слов — это верная строка из i − 1 слова плюс ещё одно
слово, лимон или банан, что даёт 2·a[i − 1], кроме строк, где новый
лимон даёт серию ровно из K + 1: это верная строка из i − K − 2 слов,
банан и K + 1 лимон, поэтому a[i] = 2·a[i − 1] − a[i − K − 2] при
i > K, причём a[−1] = 1 для строки из одних лимонов, а a[i] = 2^i при
i ≤ K. Модуля нет, поэтому числа длинные; в Python, Go и Java они
есть, а C++ и Rust хранят разряды по основанию 10⁹. В худшем случае
`O(N²)` операций с цифрами.

Подводные камни:

- ответ точный и доходит до 2^10000, около 3000 цифр (тесты 04, 07);
- при K = 0 остаётся одна строка из бананов (тест 05);
- при K = 1 получаются числа Фибоначчи (тест 06);
- вычитанию нужна строка из i − K − 2 слов, даже когда это −1 слово, —
  случай K + 1 лимона подряд (тест 01, gen3).
