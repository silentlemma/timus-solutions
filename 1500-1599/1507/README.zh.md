# 1507. 艰难的决定

[Timus 1507](https://acm.timus.ru/problem.aspx?space=1&num=1507) · 难度 447 · math

原题作者 Evgeny Krokhalev，出自 2006 年第 31 届 ACM ICPC 叶卡捷琳堡四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定元素为 0 到 100 之间整数的 n × n 矩阵 A（2 ≤ n ≤ 50），判断矩阵
B = A^(n(n−1)) + A^(n(n−1)+1) + … + A^(n(n+1)) 是否有零元素。

时间限制：1 秒。内存限制：64 MB。

## 输入

n，然后是 A 的 n 行。

## 输出

B 有零元素时输出 "No"，否则输出 "Yes"。

## 样例

### 样例 1

输入:

```
2
0 7
15 30
```

输出:

```
Yes
```

### 样例 2

输入:

```
3
100 35 40
0 22 0
10 11 0
```

输出:

```
No
```

## 解法

元素非常大，但只关心它们是否为零；元素都非负时，和为零仅当所有项为零，积为零仅当有因子为零。所
以把 A 看成有向图，非零元素处有边 i → j：(A^k)[i][j] 非零当且仅当存在从 i 到 j 长
度为 k 的路径，而 B 没有零当且仅当每个 j 都能从每个 i 经长度在 n(n−1) 到 n(n+1)
之间的路径到达。

把布尔矩阵的每一行存成位掩码，乘法就是按第一个因子的位把第二个因子的行或起来。用快
速幂算出 A^(n(n−1))，再一次一乘得到 2n + 1 个连续的幂并把它们或起来。大约 125 次
乘法，每次 `O(n²)` 个字运算。

实际上答案为 "Yes" 当且仅当图是强连通的：检查了所有 n ≤ 4 的图以及 n 不超过 12
的随机图，没有发现例外。2n + 1 个连续长度的窗口覆盖了循环结构的所有余数，所以即使只
有一个环（它的幂从来不是正的）也满足。

注意事项：

- 题面里公式只以图片给出：幂从 n(n−1) 到 n(n+1)；
- 真实数值会让 64 位整数溢出，所以只计算是否为零（测试 06）；
- 单个环没有正的幂，但 B 没有零（测试 03、07）；
- 两部分之间只有单向联系，或者某个顶点没有出边或没有入边，就会出现零（测试 04、
  08、gen3）。
