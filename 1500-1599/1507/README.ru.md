# 1507. Трудное решение

Автор оригинальной задачи — Евгений Крохалев; четвертьфинал XXXI ACM ICPC, Екатеринбург, 2006 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дана матрица A размера n × n (2 ≤ n ≤ 50) из целых чисел от 0 до 100.
Нужно определить, есть ли нулевой элемент в матрице
B = A^(n(n−1)) + A^(n(n−1)+1) + … + A^(n(n+1)).

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n, затем n строк матрицы A.

## Выходные данные

«No», если в B есть нулевой элемент, иначе «Yes».

## Примеры

### Пример 1

Ввод:

```
2
0 7
15 30
```

Вывод:

```
Yes
```

### Пример 2

Ввод:

```
3
100 35 40
0 22 0
10 11 0
```

Вывод:

```
No
```

## Решение

Элементы огромны, но важно только, равны ли они нулю, а при
неотрицательных элементах сумма равна нулю, только если равны нулю все
слагаемые, а произведение — только если равен нулю множитель. Поэтому будем считать A
ориентированным графом с ребром i → j там, где элемент ненулевой:
(A^k)[i][j] не равен нулю ровно тогда, когда из i в j ведёт путь длины
k, и в B нет нулей ровно тогда, когда каждая вершина j достижима из
каждой i путём длины от n(n−1) до n(n+1).

Каждую строку булевой матрицы храним битовой маской, тогда при
умножении объединяются строки второго множителя, выбранные битами
первого. Вычисляем A^(n(n−1)) быстрым возведением в степень, затем по
одному умножению получаем 2n + 1 последовательных степеней и
объединяем их. Около 125 произведений по `O(n²)` операций над словами.

На самом деле ответ «Yes» ровно тогда, когда граф сильно связен:
проверка всех графов с n ≤ 4 и случайных до n = 12 не нашла
исключений. Окно из 2n + 1 последовательных длин покрывает все остатки
циклической структуры, так что проходит даже один цикл, степени
которого никогда не бывают положительными.

Подводные камни:

- формула в условии дана только картинкой: степени идут от n(n−1) до
  n(n+1);
- настоящие значения переполняют любой целый тип, поэтому считаем
  только «ноль или не ноль» (тест 06);
- у одного цикла нет положительной степени, но в B нулей нет
  (тесты 03, 07, gen5);
- односторонняя связь между двумя частями или вершина без выходящих
  или без входящих рёбер дают нули (тесты 04, 08, gen3).
