# 1537. 恩特

[Timus 1537](https://acm.timus.ru/problem.aspx?space=1&num=1537) · 难度 283 · dp

原题作者 Sergey Pupyrev，出自 2007 年 3 月 3 日第八届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

第一个恩特学会两个词。每个学会 w 个词的恩特把这些词教给一个年老和一个年轻的、还不会说话
的恩特；随后精灵再教年老的一个词，使其掌握 w + 1 个词，再教年轻的 w 个词，使其掌握 2w 个
词。这样无限进行下去。求恰好掌握 K 个词的恩特数，对 P 取模（K ≤ 10⁷，P ≤ 10⁹）。

时间限制：1 秒。内存限制：64 MB。

## 输入

K 和 P。

## 输出

恰好掌握 K 个词的恩特数对 P 取模。

## 样例

### 样例 1

输入:

```
4 10
```

输出:

```
2
```

## 解法

设 f(w) 为掌握 w 个词的恩特数。除第一个外，每个恩特都由一个前辈教过：作为年老的学生
（w − 1 个词）或年轻的学生（w / 2 个词，仅当 w 为偶数），所以 f(2) = 1，偶数 w 有
f(w) = f(w − 1) + f(w / 2)，奇数 w 有 f(w) = f(w − 1)。奇数 w 不带来新的计数，因此
g(m) = f(2m) = f(2m + 1) 满足 g(1) = 1 和 g(m) = g(m − 1) + g(⌊m / 2⌋)，答案为
g(⌊K / 2⌋)，K = 1 时为 0。若 B(n) 表示将 n 划分为若干个 2 的幂的方案数，则
m ≥ 1 时 g(m) = B(2m) / 2。这些计数大到无法精确保存，所以递推时对 P 取模。

对 m 扫描一遍到 K / 2 = 5·10⁶ 即可；只有不超过 K / 4 的值会被再次用到，所以只保存这些
（2.5·10⁶ 个数）。两个余数之和至多为 2(P − 1) ≤ 1,999,999,998，能用有符号 32 位整数
保存；编译型语言的解答使用 64 位整数求和。时间 `O(K)`，空间 `O(K)`。

注意事项：

- K = 1：没有恩特只掌握一个词（测试 02）；
- P = 1 时答案总为 0（测试 04）；
- 每次求和后都要对 P 取模：精确计数会超出定长整数范围，但两个余数之和能用 32 位整数
  保存（测试 06、07）；
- g(m) 是 B(2m) 的一半：K = 4 时答案为 2，而 B(4) = 4（测试 01）；
- Python 在 PyPy 下运行：K = 10⁷ 时 CPython 约需 0.8 秒，PyPy 约 0.17 秒。
