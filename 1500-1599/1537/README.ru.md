# 1537. Энты

[Timus 1537](https://acm.timus.ru/problem.aspx?space=1&num=1537) · сложность 283 · dp

## Задача

Первый энт выучивает два слова. Каждый энт, знающий w слов, учит им
одного старого и одного молодого неговорящего энта; затем эльфы учат
старого ещё одному слову (итого w + 1), а молодого — ещё w словам
(итого 2w). Это продолжается бесконечно. Нужно
посчитать энтов, знающих ровно K слов, по модулю P (K ≤ 10⁷, P ≤ 10⁹).

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

K и P.

## Выходные данные

Число энтов, знающих ровно K слов, по модулю P.

## Проверка

Вывод сравнивается полностью, включая пробелы и переводы строк.

## Примеры

### Пример 1

Ввод:

```
4 10
```

Вывод:

```
2
```

## Решение

Пусть f(w) — число энтов, знающих w слов. Каждого энта, кроме первого,
учил один родитель: как старого ученика (w − 1 слово) или как молодого
(w / 2 слов, только при чётном w), поэтому f(2) = 1 и
f(w) = f(w − 1) + f(w / 2) при чётном w, f(w) = f(w − 1) при нечётном.
Нечётное w ничего не добавляет, так что g(m) = f(2m) = f(2m + 1)
удовлетворяет g(1) = 1 и g(m) = g(m − 1) + g(⌊m / 2⌋), а ответ —
g(⌊K / 2⌋), или 0 при K = 1. Если B(n) — число разбиений n на степени
двойки, то g(m) = B(2m) / 2 при m ≥ 1. Эти числа слишком велики для
точного хранения, поэтому рекуррентная формула вычисляется по модулю P.

Хватает одного прохода по m до K / 2 = 5·10⁶; повторно нужны только
значения до K / 4, поэтому хранятся только они (массив из 2,5·10⁶
чисел). Сумма двух остатков не превосходит 2(P − 1) ≤ 1 999 999 998
и помещается в знаковое 32-битное число; компилируемые решения используют
64-битные суммы. Время `O(K)`, память `O(K)`.

Подводные камни:

- K = 1: никто не знает одно слово (тест 02);
- при P = 1 любой ответ равен 0 (тест 04);
- каждую сумму нужно брать по модулю P: точные количества выходят за
  пределы целых фиксированной разрядности, хотя сумма двух остатков
  помещается в 32 бита (тесты 06, 07);
- g(m) равно половине B(2m): при K = 4 ответ равен 2, а B(4) = 4
  (тест 01);
- Python запускается в PyPy: K = 10⁷ занимает около 0,8 с в CPython и
  около 0,17 с в PyPy.

## Оптимизированные решения

Используется та же рекуррентность, но последний диапазон суммируется алгебраически вместо вычисления всех оставшихся состояний DP. Нужно вычислить лишь более ранний префикс и сохранить только его меньшую начальную часть. Упакованные 32-битные остатки заменяют 64-битные ячейки; граница модуля гарантирует вместимость. Вывод для чётного и нечётного концов сохраняет все начальные случаи. Принятая реализация использует CPython; её результат сравнивается с фактическим интерпретатором сохранённой простой версии.

```text
T = floor(K/2), H = floor(T/2), D = floor(H/2)
g(0) = 0, g(1) = 1
S = sum(g(j), D < j <= H)
For H >= 1:
  g(2H) = 2S + [H is even] * g(D)
  g(2H+1) = g(2H) + g(H)
answer = g(T) mod P
```

- `1537_dp_optimized.py`: 0.656 s / 5276 KB; база `1537_dp.py`: 0.203 s / 20812 KB; изменение относительно базы: время +223.2%, память -74.6%.
