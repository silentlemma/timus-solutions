# 1571. Переводчики

[Timus 1571](https://acm.timus.ru/problem.aspx?space=1&num=1571) · сложность 451 · constructive

Автор оригинальной задачи — Сергей Пупырев; XII чемпионат УрГУ по программированию, 6 октября 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждая из N ≤ 100 строительных бригад говорит на одном языке.
Переводчик знает любые два языка. Любые две бригады должны иметь
возможность поговорить, и никакая другая бригада не должна понимать их
разговор. Нужно вывести наименьшее число переводчиков с их языками в
виде `язык1-язык2` или `Impossible`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем язык каждой бригады.

## Выходные данные

Число переводчиков и пары их языков или `Impossible`. Принимается любой
лучший набор.

## Примеры

### Пример 1

Ввод:

```
3
russian
french
german
```

Вывод:

```
3
russian-english
english-german
english-french
```

## Решение

Если у двух бригад общий язык, то третья бригада, если она есть, не
сможет поговорить с первой так, чтобы вторая не поняла; если бригад
всего две, никто не нужен. Иначе пусть все k языков различны. Одной
бригаде никто не нужен, двум нужен один переводчик для их двух языков.

При k ≥ 3 разговор, проходящий через язык другой бригады, этой бригадой
подслушивается, так что между любыми двумя бригадами переводчики должны
образовывать цепочку, внутренние языки которой не знает ни одна бригада.
Если бы переводчики использовали только языки бригад, они образовали бы
связный граф на этих k языках, а с k − 1 рёбрами это было бы дерево, в
котором какая-то цепочка проходит через третий язык. Значит, нужно k
переводчиков, и k хватает: язык каждой бригады в паре с языком, которого
никто не знает, например english. Если какая-то бригада говорит на
english, средний язык — первое свободное имя из одной или двух букв:
языки в ответе тоже должны быть не длиннее десяти букв, а 100 бригад
не могут занять все 702 таких имени. `O(N log N)` в C++; в остальных
языках в среднем `O(N)`.

Подводные камни:

- двум бригадам одного языка никто не нужен, а для трёх бригад с
  повторяющимся языком задача невыполнима (тесты 03, 05);
- какая-то бригада сама может говорить на english, поэтому средний язык
  не должна знать ни одна бригада (тесты 06, 08);
- принимаются и другие ответы, например треугольник прямых пар для трёх
  бригад, так что чекер проверяет конфиденциальность.
