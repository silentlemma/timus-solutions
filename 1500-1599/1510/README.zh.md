# 1510. 秩序

[Timus 1510](https://acm.timus.ru/problem.aspx?space=1&num=1510) · 难度 87 · greedy

原题作者 Den Raskovalov，出自 2006 年第 31 届 ACM ICPC 叶卡捷琳堡四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 N 张钞票（1 ≤ N ≤ 500000），面值在 0 到 10⁹ 之间，其中超过一半面值相同。输出这
个面值。

时间限制：1 秒。内存限制：16 MB。

## 输入

N，然后每行一个面值，共 N 个。

## 输出

占多数的面值。

## 样例

### 样例 1

输入:

```
5
3
3
2
2
3
```

输出:

```
3
```

## 解法

Boyer–Moore 投票：保存一个候选值和一个计数器。与候选值相同的钞票让计数器加一，其他
钞票让它减一；计数器为零时，下一张钞票成为候选值。每次减一相当于用一张别的钞票抵消
一张候选值的钞票；多数值的钞票比其他所有钞票加起来还多，不可能被完全抵消，所以最后
的候选值就是它。时间 `O(N)`，内存 `O(1)`。

注意事项：

- 16 MB 很紧：在 Python 中一次读入全部输入再切分，可能占用约 29 MB，
  所以所有解法都逐个读取钞票；
- 多数值可能排在所有其他钞票之后（测试 03、gen2），也可能与它们交替出现（测试
  04）；
- 多数值可以是 0（测试 05）。

## 优化解法

优化解法（C++、Java）按 16 KB 分块读入，并手工解析多达 500 000 个数，而不是用
`scanf` 和 `StreamTokenizer`，数值存为能容纳 `10⁹` 的 `int`。C++ 用时 0.031 s，
而不是 0.437 s，内存 104 KB，而不是 136 KB；Java 用时 0.140 s，而不是 0.265 s，
但内存从 488 KB 增加到 584 KB。投票方法不变。

优化的 Python 解法利用每行恰好一个值这一点，直接转换这 `n` 行中的每一行，不切分
成词：0.203 s，而不是 0.375 s，内存不变。
