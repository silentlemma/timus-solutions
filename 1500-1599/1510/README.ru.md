# 1510. Порядок

[Timus 1510](https://acm.timus.ru/problem.aspx?space=1&num=1510) · сложность 87 · greedy

Автор оригинальной задачи — Ден Расковалов; четвертьфинал XXXI ACM ICPC, Екатеринбург, 2006 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть N банкнот (1 ≤ N ≤ 500000) достоинством от 0 до 10⁹, и больше
половины из них одного достоинства. Нужно вывести это достоинство.

Ограничение времени: 1 секунда. Ограничение памяти: 16 МБ.

## Входные данные

N, затем N достоинств по одному в строке.

## Выходные данные

Достоинство большинства.

## Примеры

### Пример 1

Ввод:

```
5
3
3
2
2
3
```

Вывод:

```
3
```

## Решение

Голосование Бойера — Мура: храним кандидата и счётчик. Банкнота, равная
кандидату, увеличивает счётчик, любая другая уменьшает, а когда
счётчик равен нулю, следующая банкнота становится кандидатом. Каждое
уменьшение погашает одну банкноту кандидата одной другой банкнотой; у
большинства банкнот больше, чем у всех остальных вместе, поэтому его
нельзя погасить полностью и в конце оно и есть кандидат. `O(N)` времени
и `O(1)` памяти.

Подводные камни:

- 16 МБ — это мало: на Python чтение всего ввода сразу и его разбиение
  может занимать около 29 МБ, поэтому все решения читают банкноты
  по одной;
- большинство может идти после всех остальных банкнот (тест 03, gen2)
  или чередоваться с ними (тест 04);
- достоинство большинства может быть 0 (тест 05).
