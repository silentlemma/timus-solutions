# 1533. Толстые хоббиты

[Timus 1533](https://acm.timus.ru/problem.aspx?space=1&num=1533) · сложность 979 · matching

Автор оригинальной задачи — Александр Ипатов; Восьмое открытое личное первенство УрГУ, 3 марта 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У N хоббитов (2 ≤ N ≤ 100) разный вес. Некоторые пары взвешивались друг
с другом, и всем известны все результаты, включая следствия из цепочек.
Хоббит отказывается идти, если в отряде есть хоббит, заведомо более
лёгкий. Нужно найти наибольший отряд, в котором ни один хоббит не
известен как более тяжёлый, чем другой.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем матрица N × N из нулей и единиц: единица в строке i, столбце j
значит, что хоббиты i и j взвешивались и хоббит i оказался тяжелее.

## Выходные данные

Размер отряда, затем номера его хоббитов в одной строке. Подходит любой
наибольший отряд.

## Примеры

### Пример 1

Ввод:

```
2
0 1
0 0
```

Вывод:

```
1
2
```

### Пример 2

Ввод:

```
3
0 0 0
0 0 0
0 0 0
```

Вывод:

```
3
1 2 3
```

## Решение

Замкнём взвешивания транзитивно (алгоритм Флойда — Уоршелла на
булевых значениях); получится строгий частичный порядок, и нужна его
наибольшая антицепь. По теореме Дилуорса её размер равен наименьшему
числу цепей, покрывающих всех хоббитов, а это N минус наибольшее
паросочетание в двудольном графе, где у каждого хоббита есть «тяжёлая»
и «лёгкая» копия, а ребро i → j проведено, когда i тяжелее j.
Паросочетание находит алгоритм Куна.

Чтобы перечислить хоббитов, используем построение Кёнига: начнём с
непокрытых тяжёлых копий и пойдём по чередующимся путям (любое ребро в
лёгкую копию, затем её ребро паросочетания обратно). Недостигнутые
тяжёлые копии и достигнутые лёгкие образуют наименьшее вершинное
покрытие; хоббит, ни одна копия которого в него не входит, попадает в
антицепь, и таких ровно N минус паросочетание. Два таких хоббита не
могут быть сравнимы, иначе ребро между ними осталось бы непокрытым.
`O(N³)`.

Подводные камни:

- порядок нужно сначала замкнуть: в тесте 03 хоббит 1 тяжелее хоббита 3
  только через хоббита 2 (также тесты 05, 07);
- ответ — не просто самые лёгкие или самые тяжёлые хоббиты: в тесте 04
  средний слой из четырёх лучше обоих одиночек;
- наибольших отрядов бывает несколько, поэтому тесты проверяет чекер
  (все тесты).
