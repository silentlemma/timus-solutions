# 1533. 胖霍比特人

[Timus 1533](https://acm.timus.ru/problem.aspx?space=1&num=1533) · 难度 979 · matching

原题作者 Alexander Ipatov，出自 2007 年 3 月 3 日第八届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 个霍比特人（2 ≤ N ≤ 100）体重各不相同。有些对彼此称过重，所有人都知道全部结果，包括由
结果链推出的结论。若同行者中有已知比自己轻的人，霍比特人就拒绝出发。求一个最大的队伍，
其中没有人已知比另一人重。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是一个由 0 和 1 组成的 N × N 矩阵：第 i 行第 j 列为 1 表示霍比特人 i 和 j 称过重且
i 更重。

## 输出

队伍的大小，然后在一行中给出队员的编号。任何一个最大队伍都可以。

## 样例

### 样例 1

输入:

```
2
0 1
0 0
```

输出:

```
1
2
```

### 样例 2

输入:

```
3
0 0 0
0 0 0
0 0 0
```

输出:

```
3
1 2 3
```

## 解法

先对称重结果做传递闭包（布尔版 Floyd–Warshall），得到一个严格偏序，所求即其最大反链。
由 Dilworth 定理，其大小等于覆盖所有霍比特人所需的最少链数，也就是 N 减去一个二分图的最
大匹配：每个霍比特人有一个"重"副本和一个"轻"副本，当 i 比 j 重时连边 i → j。用 Kuhn 算法
求匹配。

为了列出成员，按 König 的构造：从未匹配的重副本出发，沿交错路行走（任意一条到轻副本的边，
再沿其匹配边返回）。未到达的重副本与已到达的轻副本组成最小点覆盖；两个副本都不在覆盖中的
霍比特人属于反链，恰好有 N 减匹配数个。两个这样的霍比特人不可能可比，否则它们之间的边未被
覆盖。`O(N³)`。

注意事项：

- 必须先做闭包：测试 03 中霍比特人 1 只是通过霍比特人 2 才比 3 重（另见测试 05、07）；
- 答案不只是最轻或最重的那些人：测试 04 中四人的中间层胜过两端各一人；
- 最大队伍可能不止一个，所以测试使用检查器（所有测试）。
