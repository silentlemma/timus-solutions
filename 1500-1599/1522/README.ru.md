# 1522. Фабрика

[Timus 1522](https://acm.timus.ru/problem.aspx?space=1&num=1522) · сложность 1765 · greedy

Автор оригинальной задачи — Дмитрий Гозман; Dmitry Gozman Contest 1 на Петрозаводских зимних сборах, январь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N игрушек (1 ≤ N ≤ 10⁵) проходят станки A, B и C в этом порядке и
занимают на них ai, bi и ci единиц времени (каждое от 1 до 10⁶); каждый
станок обрабатывает одну игрушку за раз, а порядок игрушек можно
выбрать любой, один и тот же на всех станках. Станок B быстрый:
max bi ≤ min ai или max bi ≤ min ci. Нужно найти наименьшее время
изготовления всех игрушек и порядок, на котором оно достигается.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем ai, bi и ci для каждой игрушки.

## Выходные данные

Наименьшее время, затем оптимальный порядок игрушек. Подходит любой
оптимальный порядок.

## Примеры

### Пример 1

Ввод:

```
5
3 1 6
1 1 2
5 2 5
7 1 4
10 2 8
```

Вывод:

```
33
2 1 3 5 4
```

### Пример 2

Ввод:

```
1
5 4 7
```

Вывод:

```
16
1
```

## Решение

Когда станок B так доминирован, правило Джонсона для двух фиктивных
станков со временами ai + bi и bi + ci даёт оптимальный порядок:
сначала игрушки с ai + bi < bi + ci по возрастанию ai + bi, затем
остальные по убыванию bi + ci. Время получаем моделированием на A, B и C:
станок берёт игрушку, когда он свободен и предыдущий этап игрушки
завершён. `O(N log N)`.

Подводные камни:

- правило опирается на условие на станок B; общая задача о трёх станках
  гораздо сложнее;
- B может быть доминирован станком C, а не A (тест 04, gen2);
- игрушки с равными суммарными временами могут идти в любую группу
  (тесты 03, 05);
- суммарное время может достигать 100002000000, больше 32 бит (gen3);
- оптимальных порядков может быть много, поэтому тесты проверяются
  чекером (все тесты).
