## Задача

Нужно расставить N ферзей (4 ≤ N ≤ 100000) на доске N × N так, чтобы
никакие два не стояли на одной горизонтали, вертикали или диагонали.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

Столбец и строка каждого ферзя, по ферзю в строке, в любом порядке.
Подходит любая верная расстановка.

## Примеры

### Пример 1

Ввод:

```
8
```

Вывод:

```
1 5
2 1
3 8
4 4
5 2
6 7
7 3
8 6
```

## Решение

Перебор при таком размере безнадёжен, но известны явные расстановки.
Для чётного N с N mod 6 ≠ 2 ставим ферзя столбца i ≤ N/2 в строку 2i, а
ферзя столбца N/2 + i — в строку 2i − 1: каждый ферзь левой половины
стоит на другой диагонали, чем любой ферзь правой, а внутри половины
строки растут на 2 на столбец, так что и там диагонали разные. Для
чётного N с N mod 6 = 2 это не работает; вместо этого при
s = (2(i − 1) + N/2 − 1) mod N ставим столбец i в строку 1 + s, а
столбец N + 1 − i — в строку N − s. Ни одна из расстановок не занимает
главную диагональ, поэтому нечётное N берёт расстановку для N − 1 и
добавляет ферзя в угол (N, N). Проверено для всех N от 4 до 3000 и для
самых больших. `O(N)`.

Подводные камни:

- простая схема «чётные, потом нечётные» ломается ровно при
  N mod 6 = 2, как при N = 8 в примере (тесты 01, 05, gen2, gen7);
- нечётному N нужен свободный угол доски для N − 1 (тесты 03, 06,
  gen3, gen6);
- верных расстановок много, поэтому тесты проверяются чекером (все
  тесты);
- вывод из 100000 строк лучше собрать в один буфер (gen5).
