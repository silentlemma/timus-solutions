# 1550. Пирамида декана 3

Автор оригинальной задачи — Евгений Крохалев; XI командный студенческий чемпионат Урала по программированию, Екатеринбург, 21 апреля 2007 года.

## Задача

Правильная четырёхугольная пирамида высоты H со стороной основания W
(обе меньше 10⁴) имеет вертикальное цилиндрическое отверстие радиуса R
с центром над точкой (X, Y) основания; начало координат в центре
основания, оси вдоль его сторон. Отверстие не пересекает рёбер
пирамиды. Нужно найти объём пирамиды с отверстием с точностью 10⁻³.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

H и W, затем X и Y, затем R.

## Выходные данные

Объём.

## Примеры

### Пример 1

Ввод:

```
3.0 3.0
-1.00 -0.70
0.1
```

Вывод:

```
8.96858
```

## Решение

Сплошная пирамида имеет объём H·W²/3. Над точкой (x, y) основания её
высота равна H·(1 − max(|x|, |y|)/(W/2)). Раз отверстие не задевает
рёбер, его круг лежит внутри одного треугольника основания под одной
гранью, где высота — линейная функция от (x, y). Интеграл линейной
функции по кругу равен её значению в центре, умноженному на площадь,
так что отверстие убирает πR²·H·(1 − max(|X|, |Y|)/(W/2)). `O(1)`.

Подводные камни:

- числа могут быть записаны без десятичной точки (тест 02);
- объём доходит примерно до 3·10¹¹, и двойная точность ещё держит его
  с запасом лучше 10⁻³ (тест 04);
- в C++ нет стандартной M_PI, и у компилятора судьи её нет, поэтому
  решение на C++ использует acos(−1).

## Оптимизированные решения

Оптимизированная версия C++ использует ту же формулу с константой π и вводом-выводом через функции C. Вычисления выполняются в long double, результат выводится с пятью знаками после запятой. Посылка 11317021 заняла 0,015 с и использовала 136 КБ. Простая версия заняла 0,015 с и использовала 444 КБ.

Java вычисляет объём по той же формуле, напрямую разбирая числа и выводя результат с фиксированной точностью. Посылка 11318321 заняла 0,093 с и использовала 464 КБ. Простая версия заняла 0,093 с и использовала 1964 КБ.

Go вычисляет объём по той же формуле и использует небольшие буферы для чтения чисел и вывода с фиксированной точностью. Go 1.14 x64, посылка 11322933. Время 0,031 → 0,015 с, память 1080 → 320 КБ.

Версия на Python читает пять значений из байтового потока и вычисляет долю высоты по расстоянию до ближайшей стороны основания. Python 3.12 x64, посылка 11322022. Время 0,093 → 0,109 с, память 444 → 452 КБ.
