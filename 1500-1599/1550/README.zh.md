# 1550. 系主任的金字塔 3

[Timus 1550](https://acm.timus.ru/problem.aspx?space=1&num=1550) · 难度 594 · geometry

原题作者 Evgeny Krokhalev，出自 2007 年 4 月 21 日在叶卡捷琳堡举行的第十一届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个高为 H、底面边长为 W（均小于 10⁴）的正四棱锥，有一个半径为 R 的竖直圆柱形孔贯穿，孔的中
心在底面点 (X, Y) 的正上方；坐标原点在底面中心，坐标轴沿底面各边。孔不与棱锥的任何棱相交。
求带孔棱锥的体积，精确到 10⁻³。

时间限制：1 秒。内存限制：64 MB。

## 输入

H 和 W，然后是 X 和 Y，然后是 R。

## 输出

体积。

## 样例

### 样例 1

输入:

```
3.0 3.0
-1.00 -0.70
0.1
```

输出:

```
8.96858
```

## 解法

实心棱锥的体积为 H·W²/3。在底面点 (x, y) 上方，其高度为 H·(1 − max(|x|, |y|)/(W/2))。由于孔
不碰任何棱，其圆盘位于底面的一个三角形内、某一个侧面之下，那里的高度是 (x, y) 的线性函数。线
性函数在圆盘上的积分等于它在圆心的值乘以面积，所以孔去掉的体积为
πR²·H·(1 − max(|X|, |Y|)/(W/2))。`O(1)`。

注意事项：

- 数字可能不带小数点（测试 02）；
- 体积可达约 3·10¹¹，双精度仍能远小于 10⁻³ 的误差表示它（测试 04）；
- C++ 没有标准的 M_PI，评测系统的编译器也没有，所以 C++ 解法使用 acos(−1)。

## 优化解法

优化后的 C++ 版本沿用同一公式，使用编译期常量 π 和 C 的输入输出函数。计算使用 long double，结果保留五位小数。提交 11317021 耗时 0.015 秒，使用 136 KB。简单版本耗时 0.015 秒，使用 444 KB。

Java 使用相同的体积公式，直接解析十进制数并以固定精度输出。提交 11318321 耗时 0.093 秒，使用 464 KB；简单版本耗时 0.093 秒，使用 1964 KB。

Go 沿用相同的体积公式，并使用小缓冲区解析十进制输入和写出定点精度结果。 Go 1.14 x64（提交 11322933）的运行时间从 0.031 秒变为 0.015 秒，内存从 1080 KB 变为 320 KB。

Python 版本从字节流读取五个数，并根据到最近底边的距离求出高度比例。 Python 3.12 x64（提交 11322022）的运行时间从 0.093 秒变为 0.109 秒，内存从 444 KB 变为 452 KB。
