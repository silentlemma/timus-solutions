# 1508. Японский кроссворд

[Timus 1508](https://acm.timus.ru/problem.aspx?space=1&num=1508) · сложность 1563 · dp

Автор оригинальной задачи — Станислав Васильев; четвертьфинал XXXI ACM ICPC, Екатеринбург, 2006 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В строке японского кроссворда L клеток (1 ≤ L ≤ 400) и ключ из K длин
групп (0 ≤ K ≤ L): закрашенные клетки образуют K отрезков таких длин, в
таком порядке, и между соседними есть хотя бы одна пустая клетка. О
некоторых клетках уже известно, что они пусты ('.') или закрашены
('X'), об остальных ничего не известно ('?'). Нужно вывести всё, что
из этого следует: пометить клетку '.' или 'X', если она такого цвета
в каждой подходящей строке, или вывести «Impossible», если подходящих
строк нет.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

L и K, строка с K длинами (пустая при K = 0) и L известных клеток.

## Выходные данные

L клеток после вывода или «Impossible».

## Примеры

### Пример 1

Ввод:

```
10 2
4 2
?????.?X??
```

Вывод:

```
?XXX?.?X?.
```

### Пример 2

Ввод:

```
9 0

??????.X?
```

Вывод:

```
Impossible
```

## Решение

Пусть pre[i][j] говорит, можно ли разместить первые j групп в первых i
клетках, а suf[i][j] — можно ли разместить группы начиная с j в клетках
начиная с i. pre[i][j] верно, если клетка i − 1 может быть пустой и
верно pre[i − 1][j], или если группа j может закончиться в клетке
i − 1: в её клетках нет '.', а клетка прямо перед ней может быть
пустой, и pre верно для j − 1 групп до неё (или группа начинает строку
и является первой). suf — зеркальное отражение. Префиксный счётчик
клеток '.' проверяет место группы за `O(1)`.

Строка вообще возможна, если верно pre[L][K]. Клетка c может быть
пустой, если она не 'X' и для некоторого j верны pre[c][j] и
suf[c + 1][j]. Клетка c может быть закрашена, если какая-то группа j
может стоять на отрезке, накрывающем её: в отрезке нет '.', клетки
вокруг могут быть пустыми, pre даёт j групп слева, а suf — остальные
справа. Каждый возможный отрезок прибавляет единицу к своим клеткам
через массив разностей. Клетка, которая может быть и той и другой, —
'?'. `O(L·K)`.

Подводные камни:

- при K = 0 строка длин пустая, поэтому вход читаем по токенам
  (тесты 02, 04, 07, gen6);
- одной известной закрашенной клетки достаточно, чтобы отсутствие групп
  стало невозможным (тесты 02, 04);
- между соседними группами нужна пустая клетка, даже когда они
  заполняют всю строку (тест 05);
- у длинной группы середина закрашена, где бы группа ни стояла
  (тест 06);
- слишком много групп для строки дают «Impossible» (тест 09, gen5).
