# 1508. 日本数织

[Timus 1508](https://acm.timus.ru/problem.aspx?space=1&num=1508) · 难度 1563 · dp

原题作者 Stanislav Vasiliev，出自 2006 年第 31 届 ACM ICPC 叶卡捷琳堡四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

数织的一行有 L 个格子（1 ≤ L ≤ 400），提示是 K 个组长度（0 ≤ K ≤ L）：黑格按顺序
组成 K 段这样长度的连续段，相邻两段之间至少有一个空格。有些格子已知为空（'.'）或
为黑（'X'），其余未知（'?'）。要推出所有能确定的信息：如果某格在每一种符合条件的
行里都是同一种颜色，就标为 '.' 或 'X'；没有符合条件的行时输出 "Impossible"。

时间限制：1 秒。内存限制：64 MB。

## 输入

L 和 K，一行 K 个长度（K = 0 时为空行），以及 L 个已知格子。

## 输出

推导后的 L 个格子，或者 "Impossible"。

## 样例

### 样例 1

输入:

```
10 2
4 2
?????.?X??
```

输出:

```
?XXX?.?X?.
```

### 样例 2

输入:

```
9 0

??????.X?
```

输出:

```
Impossible
```

## 解法

设 pre[i][j] 表示前 i 个格子能否放下前 j 组，suf[i][j] 表示从 i 开始的格子能否放下
从 j 开始的各组。pre[i][j] 成立，当且仅当格子 i − 1 可以为空且 pre[i − 1][j] 成立，
或者第 j 组可以在格子 i − 1 结束：它的格子里没有 '.'，它前面紧挨的格子可以为空，且
对它之前的 j − 1 组 pre 成立（或者这一组从行首开始且是第一组）。suf 与之对称。用
'.' 的前缀计数可以 `O(1)` 检查一组能否放在某处。

pre[L][K] 成立时这一行才有解。格子 c 可以为空，当它不是 'X' 且对某个 j 有
pre[c][j] 和 suf[c + 1][j] 成立。格子 c 可以为黑，当某个第 j 组可以放在覆盖它的区
间上：区间里没有 '.'，两侧格子可以为空，pre 给出左边的 j 组，suf 给出右边其余各
组。每个可能的区间通过差分数组给它的格子加一。两种都可能的格子为 '?'。`O(L·K)`。

注意事项：

- K = 0 时长度那一行是空的，所以要按记号读入（测试 02、04、07、gen6）；
- 只要有一个已知黑格，没有组的情况就无解（测试 02、04）；
- 相邻两组之间必须有空格，即使它们占满整行（测试 05）；
- 长组无论放在哪里，中间部分都是黑的（测试 06）；
- 组太多放不下时输出 "Impossible"（测试 09、gen5）。
