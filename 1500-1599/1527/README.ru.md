# 1527. Плохие дороги

[Timus 1527](https://acm.timus.ru/problem.aspx?space=1&num=1527) · сложность 1133 · shortest_paths

Автор оригинальной задачи — Дмитрий Гозман; Dmitry Gozman Contest 1 на Петрозаводских зимних сборах, январь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n городов (1 ≤ n ≤ 100) соединены m односторонними дорогами
(1 ≤ m ≤ 10⁴). Каждая дорога занимает какое-то время, может стоить один
тугрик и требует машину с просветом не меньше заданного. Нужно найти
наименьший просвет машины, на которой можно доехать из s в f не больше
чем за t минут и не больше чем за b тугриков, и маршрут для неё, или
вывести -1.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

n, m, s и f; затем b и t; затем каждая дорога: откуда, куда, плата
(0 или 1), время и просвет.

## Выходные данные

Наименьший просвет, число дорог в маршруте и номера дорог по порядку;
или -1. Подходит любой подходящий маршрут.

## Примеры

### Пример 1

Ввод:

```
2 2 1 2
1 100
1 2 1 100 77
1 2 1 100 66
```

Вывод:

```
66
1
2
```

### Пример 2

Ввод:

```
2 2 1 2
0 100
1 2 0 101 77
1 2 1 100 66
```

Вывод:

```
-1
```

## Решение

Ответ — просвет какой-то дороги, а больший просвет лишь добавляет
дороги, поэтому делаем двоичный поиск по отсортированным просветам.
Чтобы проверить просвет, запускаем алгоритм Дейкстры по состояниям
(город, уплачено тугриков), используя только дороги не выше него и
укладываясь в оба ограничения. Маршрут, повторяющий город, может
выбросить петлю, не заплатив больше, поэтому важны не больше n − 1
тугриков и бюджет можно ограничить этим числом. Состояние
пропускается, если меньшее число тугриков уже доводит до его города так
же быстро, — это держит поиск маленьким. Дорога-предшественник каждого
состояния даёт маршрут. Состояний не больше n², поэтому проверка стоит
`O(n·m·log(n·m))`, а всего `O(log m · n·m·log(n·m))`, на деле гораздо
меньше.

Подводные камни:

- бюджет может быть 10⁶, но больше n − 1 тугриков никогда не нужно
  (тест 08);
- дороги могут не занимать времени совсем (тест 03, gen3);
- более дешёвый по деньгам маршрут может быть слишком медленным, и
  наоборот (тесты 04, 05);
- финиш может быть недостижим в рамках ограничений или вообще
  (тесты 02, 06, gen5);
- просветы могут быть равны 0 (тест 07);
- подходящих маршрутов может быть много, поэтому тесты проверяются
  чекером (все тесты).
