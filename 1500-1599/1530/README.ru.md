# 1530. Единицы и нули

[Timus 1530](https://acm.timus.ru/problem.aspx?space=1&num=1530) · сложность 880 · greedy

Автор оригинальной задачи — Дмитрий Гозман; Dmitry Gozman Contest 1 на Петрозаводских зимних сборах, январь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Две двоичные последовательности A и B длины n (1 ≤ n ≤ 10⁵) совместимы,
если A XOR B = A + B. Дана пара (p, q); нужно найти первую совместимую
пару после неё, упорядочивая пары по первой последовательности, а затем
по второй; если такой нет, вывести первую совместимую пару вообще.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n, затем p и q, каждая в своей строке, возможно с пробелами в конце.

## Выходные данные

Две последовательности ответа, каждая в своей строке.

## Примеры

### Пример 1

Ввод:

```
1
0
0
```

Вывод:

```
0
1
```

### Пример 2

Ввод:

```
2
01
10
```

Вывод:

```
10
00
```

## Решение

Сумма двух двоичных чисел равна их XOR ровно тогда, когда нет
переносов, то есть ни в одной позиции нет единицы в обоих. Ответ либо
оставляет a = p с наименьшим совместимым b больше q, либо берёт
следующее a.

При a = p лучшее b совпадает с q до некоторой позиции j, имеет 1 в j,
где у q стоит 0, и нули после. Сохранённая часть q должна обходить
единицы p, поэтому j лежит до первой позиции, где у p и q обе единицы,
а поставить 1 в j можно, только если у p там 0. Наибольшее такое j даёт
наименьшее b. Если его нет, a должно вырасти: следующая двоичная
последовательность после p превращает её последний 0 в 1 и обнуляет
остальное, а b = 0…0 подходит к любому a. Если p из одних единиц,
начинаем заново с пары из одних нулей. `O(n)`.

Подводные камни:

- «+» складывает последовательности как двоичные числа, так что
  совместимость значит отсутствие общих единиц (все тесты);
- сами p и q могут конфликтовать, и тогда хвост q сохранить нельзя
  (тест 05);
- если p состоит из одних единиц, после него ничего нет, и ответ
  начинается заново (тесты 03, 04, gen3);
- строки могут заканчиваться пробелами, поэтому вход читаем по токенам
  (тест 06).
