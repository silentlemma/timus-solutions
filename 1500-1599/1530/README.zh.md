# 1530. 一和零

[Timus 1530](https://acm.timus.ru/problem.aspx?space=1&num=1530) · 难度 879 · greedy

原题作者 Dmitry Gozman，出自 2007 年 1 月彼得罗扎沃茨克冬季集训的 Dmitry Gozman Contest 1。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

长度为 n（1 ≤ n ≤ 10⁵）的两个二进制序列 A 和 B 满足 A XOR B = A + B 时称为相容。给
定一对 (p, q)，按先比较第一个序列、再比较第二个序列的顺序，求它之后的第一个相容对；
若不存在，输出所有相容对中的第一个。

时间限制：1 秒。内存限制：64 MB。

## 输入

n，然后是 p 和 q，各占一行，行末可能有空格。

## 输出

答案的两个序列，各占一行。

## 样例

### 样例 1

输入:

```
1
0
0
```

输出:

```
0
1
```

### 样例 2

输入:

```
2
01
10
```

输出:

```
10
00
```

## 解法

两个二进制数相加等于它们的异或，当且仅当没有进位，即没有哪个位置两者都是 1。答案要
么保持 a = p 并取大于 q 的最小相容 b，要么取下一个 a。

当 a = p 时，最好的 b 在某个位置 j 之前与 q 相同，在 j 处 q 为 0 而 b 为 1，之后全为
0。保留下来的 q 的前缀必须避开 p 的 1，所以 j 在 p 与 q 第一次同为 1 的位置之前，且只
有 p 在 j 处为 0 时 b 才能在 j 放 1。最大的这种 j 给出最小的 b。若不存在，a 必须变
大：p 之后的下一个二进制序列把它最后一个 0 变成 1 并把后面清零，而 b = 0…0 与任何 a
相容。若 p 全是 1，就从全零对重新开始。`O(n)`。

注意事项：

- "+" 把序列当作二进制数相加，所以相容就是没有公共的 1（所有测试）；
- p 和 q 本身可能冲突，这时 q 的尾部不能保留（测试 05）；
- p 全为 1 时其后没有序列，答案要回到开头（测试 03、04、gen3）；
- 行末可能有空格，所以按记号读入（测试 06）。
