# 1540. 魔戒之战

[Timus 1540](https://acm.timus.ru/problem.aspx?space=1&num=1540) · 难度 1073 · games

原题作者 Alexander Ipatov，出自 2007 年 3 月 3 日第八届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 K 条戒指链（1 ≤ K ≤ 50，每条至多 100 个戒指），每个戒指的含金量在 1 到 100 之间。每一步
选一条链和其中一个戒指，移除该链中含金量不超过所选戒指的所有戒指；链可能断成几段。移除最后
一个戒指的人获胜。甘道夫先手：若萨鲁曼获胜输出 `S`，否则输出 `G` 和甘道夫获胜的第一步——
链号和戒指号，先取链号最小，再取戒指号最小。

时间限制：1 秒。内存限制：64 MB。

## 输入

K，然后每条链给出其长度和各戒指的含金量。

## 输出

`S`，或 `G` 以及第一个获胜着法的链号和戒指号。

## 样例

### 样例 1

输入:

```
2
3 1 2 1
1 1
```

输出:

```
G
1 1
```

### 样例 2

输入:

```
2
3 2 1 2
1 1
```

输出:

```
S
```

## 解法

各条链是独立的游戏，由 Sprague–Grundy 定理，局面必败当且仅当各链 Grundy 值的异或为 0。

会出现哪些片段？移除含金量不超过 x 的戒指后，剩下的是含金量大于 x 的极大连续段。之后在这样
一段内的着法移除不超过某个 y > x 的戒指，剩下大于 y 的极大段，它们在整条链中也是极大的。所
以每个片段都是大于某个含金量的极大段；这些段相互嵌套，构成一棵树：根是整条链，一个段的孩子
是大于其最小含金量的那些段。

在一个段内用含金量 x 走一步，留下的是树的一条"前沿"：最小含金量大于 x、而父节点不满足的那
些后代。按 x 递增、用以最小含金量为键的堆处理，每个节点只被其孩子替换一次，所以一个段内所
有着法的异或值只需与其子树大小成线性的时间（乘以对数）。Grundy 值是这些值的 mex，自叶向根
计算；每条链至多 2·100 个段，所以很快。

若总异或 T 不为 0，链 i 中的获胜着法是使该链异或变为 T ⊕ g(i) 的着法；按顺序扫描链和戒指，
利用根节点的着法值表即可得到所要求的最小着法。可能有多个戒指具有获胜的含金量，取第一个。
链长为 L 时为 `O(K·L² log L)`。

注意事项：

- 相同的戒指一步全部移除，答案给出其中第一个（测试 05、08）；
- 第一个获胜着法可能在后面的链里（测试 07）；
- 一条链可能断成相同的几段，其值相互抵消（测试 06）。
