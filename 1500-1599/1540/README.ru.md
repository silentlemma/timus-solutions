# 1540. Битва за кольцо

[Timus 1540](https://acm.timus.ru/problem.aspx?space=1&num=1540) · сложность 1071 · games

Автор оригинальной задачи — Александр Ипатов; Восьмое открытое личное первенство УрГУ, 3 марта 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть K цепочек колец (1 ≤ K ≤ 50, до 100 колец в каждой), у каждого
кольца содержание золота от 1 до 100. Ход — выбрать цепочку и кольцо в
ней и убрать все кольца этой цепочки с содержанием не больше, чем у
выбранного; цепочка может распасться на несколько. Убравший последнее
кольцо выигрывает. Гэндальф ходит первым: нужно вывести `S`, если
выигрывает Саруман, или `G` и выигрышный первый ход Гэндальфа — цепочку
и кольцо, с наименьшей цепочкой, а затем наименьшим кольцом.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

K, затем каждая цепочка: её длина и содержание золота в кольцах.

## Выходные данные

`S` или `G` и номера цепочки и кольца первого выигрышного хода.

## Примеры

### Пример 1

Ввод:

```
2
3 1 2 1
1 1
```

Вывод:

```
G
1 1
```

### Пример 2

Ввод:

```
2
3 2 1 2
1 1
```

Вывод:

```
S
```

## Решение

Цепочки — независимые игры, поэтому по Шпрагу — Гранди позиция
проигрышна ровно тогда, когда xor их чисел Гранди равен 0.

Какие куски могут появиться? Удаление колец до x оставляет максимальные
отрезки колец больше x. Следующий ход внутри такого отрезка удаляет
кольца до некоторого y > x и оставляет максимальные отрезки больше y,
которые максимальны и во всей цепочке. Значит, любой кусок — это
максимальный отрезок колец больше некоторого содержания; такие отрезки
вложены и образуют дерево, корень которого — цепочка, а дети отрезка —
отрезки больше его наименьшего содержания.

Ход с содержанием x в отрезке оставляет фронт дерева: потомков, у
которых наименьшее содержание больше x, а у родителя нет. Перебирая x
по возрастанию с кучей по наименьшему содержанию, каждый узел
заменяется своими детьми один раз, так что значения xor всех ходов в
отрезке считаются за время, линейное по его поддереву (с логарифмом).
Число Гранди — mex этих значений, считается от листьев вверх; отрезков в
цепочке не больше 2·100, так что это быстро.

Если общий xor T не 0, выигрышные ходы в цепочке i — те, что оставляют
в ней xor T ⊕ g(i); перебор цепочек и колец по порядку с таблицей
значений ходов корня даёт нужный наименьший ход. Выигрышное содержание
может быть у нескольких колец; называется первое из них.
`O(K·L² log L)` для цепочек длины L.

Подводные камни:

- одинаковые кольца уходят за один ход, а в ответе называется первое из
  них (тесты 05, 08);
- первый выигрышный ход может быть в более поздней цепочке (тест 07);
- цепочка может распасться на одинаковые куски, значения которых
  взаимно уничтожаются (тест 06).
