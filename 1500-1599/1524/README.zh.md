# 1524. 黑衣人

[Timus 1524](https://acm.timus.ru/problem.aspx?space=1&num=1524) · 难度 9705 · simulation

原题作者 Dmitry Gozman，出自 2007 年 1 月彼得罗扎沃茨克冬季集训的 Dmitry Gozman 第 1 场比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

模拟一个至多 26 名特工的机构，每名特工有一个代号字母和五项 0 到 1 之间的属性：准确度、步行速度、智力、经验和驾驶技术。
机构还有汽车（每辆属于某种车型，车型有最低驾驶技术要求和损坏前能行驶的距离）以及一组怪物种类。事件按时间到来：
新特工加入（取离名字首字母最近的空闲字母，距离相同取较小者）、购买汽车，或收到任务：送货、杀怪、调查或谈判，地点离办公室有一定距离。

任务由一名特工或一对特工完成，步行或乘一辆车，往返一趟。一对特工步行速度取较慢者，驾驶技术取较好者，
准确度取平均，经验和智力按 1 − (1 − a)(1 − b) 合成。杀怪用时为闪避值 / 准确度，调查为最短时间 / 智力，谈判为最短时间 / 经验，
每种任务对属性都有要求。每一段时间分别四舍五入到分钟。行驶距离用尽的汽车会损坏，剩下的路步行。
任务一旦有人能做就开始，先收到的先开始；选最快的组合，单人优先于一对，再比字母；只有严格更快时才用车，再取最小的 id。
任务完成后各特工的属性按给定公式增长，经验达到退休水平的特工离开。

按时间输出每次购车、汽车损坏、杀死怪物、完成任务、特工疲倦、新特工加入和开始任务，同一分钟内按此顺序，同类内按消息文本的字典序。

时间限制：3 秒。内存限制：64 MB。

## 输入

特工、车型、汽车和怪物种类，然后是最大步行距离、最大闪避值、最大怪物经验和退休经验，接着是至多 2000 个事件。

## 输出

如上所述的若干行 `dddd:hh:mm    消息`。

## 解法

按事件模拟。任务开始时，它的全过程都已确定：汽车损坏、杀死怪物和任务结束的时刻，都从开始时算起。
这些时刻放进优先队列，先按时间再按种类（损坏、杀怪、结束）排序，这也正是同一分钟内消息的顺序。

每个时刻先清空队列中的到期事件，再处理这一时刻的外部事件，然后按收到的顺序反复尝试等待中的任务，只要还有任务能开始。
对一个任务，尝试每名空闲特工和每对空闲特工，不用车以及用每辆空闲的车；用车有五种情况：去程中损坏、到达时损坏、
返程中损坏、恰好回到时损坏，或不损坏。每分钟的消息输出前按种类和文本排序。

注意事项：

- 每一段分别四舍五入：驾驶和损坏后的步行是两次取整，使用 `floor(t + 0.5 + 10⁻⁹)`，以免 0.5 因二进制表示而丢失；
- 要求用 ≥ 比较，没有容差（测试 05）；
- 只与步行一样快的车不用；在驾驶技术允许且用时相同的车中取最小的 id（汽车用时相同：测试 06）；
- 一对只有严格快于每名符合要求的空闲单人时才更好；
- 汽车恰在行驶距离用尽时损坏，包括到达时或返回时（测试 04）；
- 疲倦的特工立即空出字母（测试 07）；
- 较晚的任务可以在较早的任务还在等能做它的人时先开始（测试 03）。

输出已在这里的测试和 100 个随机机构上与一份独立的已通过实现对比过。

## 各语言说明

- Python 在 PyPy 下运行：这里最大的测试用 CPython 约需 10 秒，用 PyPy 为 1.7 秒。此外，在不会于途中损坏的车里，它只尝试驾驶技术允许且 id 最小的那辆，因为它们用时都相同。
