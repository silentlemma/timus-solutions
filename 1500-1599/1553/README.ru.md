# 1553. Пещеры и туннели

[Timus 1553](https://acm.timus.ru/problem.aspx?space=1&num=1553) · сложность 282 · trees

Оригинальная задача — Novosibirsk SU Contest, Петрозаводские сборы, сентябрь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N ≤ 100000 пещер образуют дерево. У каждой пещеры есть уровень радиации,
сначала 0. Нужно ответить на Q ≤ 100000 запросов: «I U V» увеличивает
уровень пещеры U на V ≤ 10000, а «G U V» спрашивает наибольший уровень
на пути от U до V.

Ограничение времени: 3 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, N − 1 туннель, Q и запросы.

## Выходные данные

Ответ на каждый запрос G, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
4
1 2
2 3
2 4
6
I 1 1
G 1 1
G 3 4
I 2 3
G 1 1
G 3 4
```

Вывод:

```
1
0
1
3
```

## Решение

Тяжёлые пути: подвесим дерево за пещеру 1, и пусть каждая пещера
продолжает свою цепочку в ребёнка с самым большим поддеревом. Любой путь
от пещеры вверх к корню пересекает не больше log₂ N цепочек, потому что
каждое лёгкое ребро хотя бы вдвое уменьшает размер поддерева. Выложим
цепочки одну за другой, чтобы каждая занимала подряд идущие места, и
будем хранить дерево отрезков максимумов по местам.

Увеличение меняет один лист и максимумы над ним. Запрос пути
поднимается от того конца, у которого голова цепочки глубже, беря
максимум по куску этой цепочки, пока оба конца не окажутся в одной
цепочке, и завершается куском между ними. Дерево строится без рекурсии,
по порядку обхода в ширину, ведь путь из 100000 пещер переполнил бы
рекурсивный обход. `O((N + Q) log² N)`.

Подводные камни:

- запрос от пещеры к ней самой — это её уровень (тесты 01, 04);
- увеличения на 0 допустимы (тест 04);
- уровень может дойти до 10⁹ (10⁵ увеличений по 10⁴), близко к границе
  32 бит, поэтому решения хранят уровни в 64 битах;
- путь из 100000 пещер — одна длинная цепочка (gen2).
