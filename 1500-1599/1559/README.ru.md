# 1559. Лингвистика TruCoders

[Timus 1559](https://acm.timus.ru/problem.aspx?space=1&num=1559) · сложность 4082 · parsing

Оригинальная задача — Novosibirsk SU Contest, Петрозаводские сборы, сентябрь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Язык задан выражением не длиннее 10000 символов из строчных букв (одно
слово из одной буквы), 0 (пустое множество), скобок, конкатенации,
объединения `|` и звёздочки `*` (любое число повторений, включая ноль,
что даёт пустое слово). Трое могут выучить не больше 10¹⁰⁰⁰⁰⁰ слов
каждый. Нужно вывести F, если вместе они могут выучить весь язык, и N
иначе.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Одна строка с выражением.

## Выходные данные

F или N.

## Примеры

### Пример 1

Ввод:

```
((a|b)(c|d))
```

Вывод:

```
F
```

## Решение

Ответ N ровно тогда, когда язык бесконечен. Конечный язык, заданный
выражением длины L, содержит не больше 2^L слов: у буквы или 0 их не
больше 1, объединение складывает размеры, конкатенация перемножает, а
звёздочка над конечным языком без непустых слов даёт только пустое
слово, так что каждый символ увеличивает оценку не больше чем вдвое. А
2^10000 — это около 10³⁰¹¹, гораздо меньше 3·10¹⁰⁰⁰⁰⁰.

Для каждого подвыражения достаточно знать четыре вещи: непусто ли
множество, есть ли в нём пустое слово, есть ли непустое слово и
бесконечно ли оно. Объединение соединяет их через «или». Конкатенация
пуста, если пуста хотя бы одна часть, а иначе содержит пустое слово,
если его содержат обе части, непустое — если хотя бы одна, и бесконечна,
если бесконечна хотя бы одна. Звёздочка никогда не пуста, всегда
содержит пустое слово и бесконечна ровно тогда, когда в аргументе есть
непустое слово.

Скобки могут быть вложены примерно на 5000 уровней, поэтому выражение
разбирается с явным стеком, а не рекурсией. Каждый уровень скобок хранит
объединение до сих пор, конкатенацию до сих пор и её последний символ, к
которому ещё может относиться следующая звёздочка. Это занимает O(L)
времени. Результаты сверены с перебором, который выписывает слова до
фиксированной длины, на случайных выражениях.

Подводные камни:

- звёздочка не всегда даёт бесконечно много слов: 0* и (0|(0)*)* — это
  только пустое слово (тесты 03, 05);
- пустой множитель опустошает всю конкатенацию вместе со звёздочкой:
  в a*0 нет слов (тест 04);
- предел 10¹⁰⁰⁰⁰⁰ лишь выглядит как число для сравнения: даже 2000
  выборов из двух букв дают всего 2^2000 слов (тест gen7);
- рекурсия по 5000 вложенным скобкам может переполнить стек (тест gen1).
