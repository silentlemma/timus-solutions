# 1559. TruCoders 语言学

[Timus 1559](https://acm.timus.ru/problem.aspx?space=1&num=1559) · 难度 4082 · parsing

原题出自 2007 年 9 月彼得罗扎沃茨克集训的 Novosibirsk SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一种语言由不超过 10000 个字符的表达式给出，表达式由小写字母（只含一个字母的单词）、0（空集）、括号、
连接、并 `|` 和星号 `*`（任意次重复，包括零次，即空单词）构成。三个人每人最多能记住 10¹⁰⁰⁰⁰⁰ 个单
词。若他们合起来能学会整个语言，输出 F，否则输出 N。

时间限制：1 秒。内存限制：64 MB。

## 输入

一行，包含表达式。

## 输出

F 或 N。

## 样例

### 样例 1

输入:

```
((a|b)(c|d))
```

输出:

```
F
```

## 解法

答案为 N 当且仅当语言是无限的。长度为 L 的表达式给出的有限语言至多有 2^L 个单词：字母或 0 至多 1
个，并把大小相加，连接把大小相乘，而对不含非空单词的有限语言取星号只得到空单词，所以每个字符至多让上
界翻倍。而 2^10000 约为 10³⁰¹¹，远小于 3·10¹⁰⁰⁰⁰⁰。

对每个子表达式只需知道四件事：集合是否非空，是否含空单词，是否含非空单词，是否无限。并用“或”把它们合
起来。连接只要有一部分为空就为空，否则当两部分都含空单词时含空单词，任一部分含非空单词时含非空单词，
任一部分无限时无限。星号永不为空，总含空单词，并且当且仅当其参数含非空单词时无限。

括号可能嵌套约 5000 层，所以用显式栈而不是递归来读表达式。每层括号保存到目前为止的并、到目前为止的连
接以及最后一个符号，后面的星号仍可作用于它。耗时 O(L)。结果已在随机表达式上与列出固定长度以内所有单
词的暴力对照。

注意事项：

- 星号不一定给出无限多个单词：0* 和 (0|(0)*)* 只有空单词（测试 03、05）；
- 空的因子会让整个连接连同星号一起变空：a*0 没有单词（测试 04）；
- 上限 10¹⁰⁰⁰⁰⁰ 只是看起来像需要比较的数：即使 2000 个二选一的字母也只有 2^2000 个单词（测试 gen7）；
- 对 5000 层嵌套括号递归可能导致栈溢出（测试 gen1）。
