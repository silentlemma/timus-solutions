# 1561. Винни-Пух

[Timus 1561](https://acm.timus.ru/problem.aspx?space=1&num=1561) · сложность 2840 · math

Оригинальная задача — Novosibirsk SU Contest, Петрозаводские сборы, сентябрь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждую бочку мёда одного сорта Винни съедает за одно и то же целое
число дней, своё для каждого сорта и неизвестное. По порядку приходят
до 1000 запросов: `Add` добавляет новый сорт, `Learn A0 … Ak S E`
сообщает, что первый день недели после поедания A0 бочек сорта 0, …,
Ak бочек сорта k, начатого в день недели S, — E, а `Eat A0 … Ak S`
спрашивает этот первый день после еды (0 ≤ Ai ≤ 10⁶). На каждый `Eat`
нужно ответить днём недели, если известные факты его определяют,
`Don't know`, если допускают несколько, и `Already crazy`, если
известные факты противоречат друг другу.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Число запросов, затем по одному запросу в строке; дни недели записаны как
Monday … Sunday.

## Выходные данные

По строке на каждый запрос `Eat`.

## Примеры

### Пример 1

Ввод:

```
9
Add
Add
Learn 5 2 Saturday Monday
Eat 3 3 Tuesday
Add
Learn 0 9 4 Friday Thursday
Eat 3 0 6 Sunday
Learn 3 2 10 Saturday Friday
Eat 3 4 11 Monday
```

Вывод:

```
Don't know
Saturday
Already crazy
```

## Решение

Для дня недели важно только число дней по модулю 7, и возможен любой
вычет, ведь сорт может съедаться за 7 дней. Значит, неизвестные x₀, x₁, …
лежат в поле вычетов по модулю 7, факт — это линейное уравнение
A0·x₀ + … + Ak·xk = E − S, а первый день после трапезы, начатой в S, —
S + A0·x₀ + … + Ak·xk.

Факты хранятся в виде ступенчатого базиса: у каждой строки на первом
ненулевом месте, её опорном, стоит 1, и опорные места строк различны.
Новый вектор приводится вычитанием кратных строк в порядке возрастания
их опорных мест вместе с правыми частями. Факт, который приводится к
нулю, либо лишний, либо, при ненулевой правой части, — противоречие,
после которого на любую трапезу отвечается `Already crazy`; иначе он
становится новой строкой. Трапеза определена ровно тогда, когда её вектор
приводится к нулю, и тогда накопленная правая часть равна минус её
длительности по модулю 7. Каждое приведение занимает O(R·K) для R строк и
K сортов. Результаты сверены с перебором всех вычетов на случайных
маленьких тестах.

Подводные камни:

- факт о трапезе из нуля бочек — противоречие, если только не S = E
  (тест 03);
- число бочек, кратное 7, ничего не говорит о днях на бочку (тест 04);
- как только факты противоречат друг другу, на каждую следующую трапезу
  отвечается `Already crazy`, а ответы на прежние остаются (тест 05);
- сорта могут появиться после того, как факт стал известен, поэтому
  хранимые строки короче последующих векторов;
- Python запускается под PyPy: самые большие тесты идут около 1.1 с в
  CPython при ограничении 2 с и около 0.3 с в PyPy.
