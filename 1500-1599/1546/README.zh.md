# 1546. 日式排序

[Timus 1546](https://acm.timus.ru/problem.aspx?space=1&num=1546) · 难度 888 · sorting

原题作者 Vladimir Yakovlev，出自 2007 年 4 月 21 日在叶卡捷琳堡举行的第十一届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把由小写字母和数字组成的字符串（总共不超过 100 KB）按"日式"顺序排序，其中字符串里的数字按
数值比较：photox2 排在 photox10 之前。题面没有完整说明规则，只提供了一个能排序小输入的程
序。

时间限制：1 秒。内存限制：64 MB。

## 输入

各个字符串，每行一个。

## 输出

按日式顺序排好的同样的字符串。

## 样例

### 样例 1

输入:

```
photox10
photox1
photo2
photox2
```

输出:

```
photo2
photox1
photox2
photox10
```

## 解法

规则就是文件管理器中的自然排序，下列细节与评测网站讨论区引用的题面给出的程序输出一致：

- 把字符串拆成字母和极大的数字段；
- 逐段比较：数字在字母之前，数字按数值比较（先比去掉前导零后的长度，再逐位比较，因为可能很
  长），字母按编码比较；
- 先结束的字符串排在前面；
- 只有各段全部相同时，才逐段比较各数字的前导零个数，零多的排在前面：000 < 00 < 0，
  a001 < a01，01w01 < 01w1。

每个字符串得到一个键：各段的列表和取负的前导零个数列表；按键做稳定排序即可。总长为 L 时为
`O(L log n)`。

注意事项：

- 前导零只用于打破平局：z001pp00 排在 z0pp01 之后（测试 02）；
- 全由零组成的串是一个数，000 排在 0 之前（测试 03）；
- 数字可能超过 64 位（测试 04）；
- 数字在字母之前：1, 2, 10, a, a1, aa（测试 06）。
