# 1514. Национальный парк

[Timus 1514](https://acm.timus.ru/problem.aspx?space=1&num=1514) · сложность 1753 · geometry

Авторы оригинальной задачи — Никита Рыбак, Илья Гребнов и Дмитрий Ковалёв; Timus Top Coders: Third Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N деревьев (3 ≤ N ≤ 50000) стоят в целых точках с координатами не больше
10⁶ по модулю; несколько деревьев могут стоять в одной точке. Нужно
выбрать три разных дерева, треугольник которых имеет наименьший
периметр; треугольник нулевой площади тоже считается. Вывести периметр
не менее чем с четырьмя знаками после точки и номера трёх деревьев.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем координаты N деревьев.

## Выходные данные

Наименьший периметр, затем номера трёх деревьев в любом порядке.
Подходит любая оптимальная тройка.

## Примеры

### Пример 1

Ввод:

```
5
0 0
1 1
3 0
0 3
3 3
```

Вывод:

```
6.6503
1 2 3
```

## Решение

«Разделяй и властвуй», как для ближайшей пары точек. Сортируем деревья
по x, решаем левую и правую половины, и пусть d — лучший периметр на
данный момент. Каждая сторона треугольника не больше половины его
периметра, поэтому у лучшего треугольника все три дерева ближе d/2 друг
к другу. Значит, лучший треугольник с деревьями по обе стороны от линии
раздела лежит в полосе шириной d/2 с каждой стороны от неё: сортируем
полосу по y и для каждого дерева перебираем пары деревьев выше него
меньше чем на d/2, сужая границу при каждом улучшении d. Довод об
упаковке, как для ближайшей пары, ограничивает число таких деревьев,
поэтому каждый уровень стоит одной сортировки, а всего `O(N log² N)`.
Куски до 8 деревьев проверяются перебором троек.

Подводные камни:

- три дерева в одной точке дают периметр 0 (тест 03, gen7);
- вырожденные треугольники считаются, так что деревья на одной прямой
  дают удвоенное расстояние между крайними (тесты 02, 06, gen2, gen3);
- когда у всех деревьев один x, каждое дерево попадает в каждую полосу,
  и объём работы мал только благодаря границе по y (gen2);
- у 50000 деревьев около 2·10¹³ троек, перебрать все невозможно (gen1);
- оптимальных троек может быть много, поэтому тесты проверяются
  чекером (все тесты).
