# 1531. 平面上的区域

[Timus 1531](https://acm.timus.ru/problem.aspx?space=1&num=1531) · 难度 1427 · math

原题作者 Dmitry Gozman，出自 2007 年 1 月彼得罗扎沃茨克冬季集训的 Dmitry Gozman Contest 1。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

区域 1 是由两个等腰直角三角形组成的正方形。区域 n + 1 由区域 n 得到：以其每个三角形的
每条直角边为斜边作两个等腰直角三角形，再去掉属于更早区域的所有三角形。求区域 n 由多少个
简单多边形组成（1 ≤ n ≤ 2000）。

时间限制：1 秒。内存限制：64 MB。

## 输入

n。

## 输出

多边形的个数。

## 样例

### 样例 1

输入:

```
1
```

输出:

```
1
```

### 样例 2

输入:

```
2
```

输出:

```
4
```

### 样例 3

输入:

```
3
```

输出:

```
8
```

### 样例 4

输入:

```
4
```

输出:

```
12
```

## 解法

前 16 个区域可以在格点上精确构造：把正方形放大 2^16 倍，使所有顶点的坐标保持为整数；
保留中心没有被更早三角形覆盖的新三角形，并把同一区域内有公共边的三角形
连起来。前 16 个区域得到 1, 4, 8, 12, 20, 28, 44, 60, 92, 124, 188, 252, 380, 508,
764, 1020。从区域 3 开始，增量依次为 4, 4, 8, 8, 16, 16, …，每两个区域翻一倍，所以
当 n ≥ 2 时

- 偶数 n = 2k 得 2^(k+2) − 4；
- 奇数 n = 2k + 1 得 3·2^(k+1) − 4。

各解法输出这些数，最大约为 10³⁰¹，所以 C++ 和 Rust 逐位对十进制数翻倍，Go 和 Java 使
用自带的大整数。至多 `O(n²)` 次数位运算。

注意事项：

- 区域 1 是唯一的例外：奇数公式会给出 2，但正方形是一个多边形（测试 01）；
- n = 2000、1999 时答案超过 300 位（测试 06、07）；
- 公式基于前 16 个区域的计数，并经评测系统验证；上面的推导并不能证明它。
