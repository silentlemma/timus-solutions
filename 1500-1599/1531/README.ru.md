# 1531. Зоны на плоскости

[Timus 1531](https://acm.timus.ru/problem.aspx?space=1&num=1531) · сложность 1426 · math

Автор оригинальной задачи — Дмитрий Гозман; Dmitry Gozman Contest 1 на Петрозаводских зимних сборах, январь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Зона 1 — квадрат из двух равнобедренных прямоугольных треугольников.
Зона n + 1 получается из зоны n: на каждом катете каждого её
треугольника, как на гипотенузе, строятся равнобедренные прямоугольные
треугольники, затем убираются все треугольники, входящие в более
ранние зоны. Нужно посчитать, из скольких простых многоугольников
состоит зона n (1 ≤ n ≤ 2000).

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n.

## Выходные данные

Число многоугольников.

## Решение

Построение можно провести точно на решётке: увеличим квадрат в 2^16
раз, чтобы каждая середина и каждая половина катета оставались целыми,
оставим новые треугольники, центр которых не накрыт более ранним
треугольником, и соединим треугольники зоны с общей стороной. Для первых
16 зон получается 1, 4, 8, 12, 20, 28, 44, 60, 92, 124, 188, 252, 380,
508, 764, 1020. Начиная с зоны 3 числа растут на 4, 4, 8, 8, 16, 16, …,
удваиваясь каждые две зоны, так что при n ≥ 2

- чётное n = 2k даёт 2^(k+2) − 4;
- нечётное n = 2k + 1 даёт 3·2^(k+1) − 4.

Решения печатают эти числа, которые доходят примерно до 10³⁰¹, поэтому
C++ и Rust удваивают десятичное число по цифрам, а Go и Java пользуются
своими длинными числами. Не больше `O(n²)` операций с цифрами.

Подводные камни:

- зона 1 — единственное исключение: нечётная формула дала бы 2, но
  квадрат — это один многоугольник (тест 01);
- при n = 2000 в ответе больше 300 цифр (тесты 06, 07);
- формула опирается на числа первых 16 зон и проверена судьёй;
  рассуждение выше её не доказывает.
