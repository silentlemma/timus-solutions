# 1520. Империя наносит ответный удар

[Timus 1520](https://acm.timus.ru/problem.aspx?space=1&num=1520) · сложность 2420 · geometry

Авторы оригинальной задачи — Никита Рыбак, Илья Гребнов и Дмитрий Ковалёв; Timus Top Coders: Third Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Республика — круг радиуса R (1 ≤ R ≤ 1000) с центром в начале координат,
в нём N заводов (1 ≤ N ≤ 300) в целых точках. На каждый завод падает
бомба с общим для всех радиусом поражения. Нужно найти наименьший
радиус, при котором бомбы вместе накрывают весь круг, не менее чем с
пятью знаками после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и R, затем координаты N заводов.

## Выходные данные

Наименьший радиус.

## Примеры

### Пример 1

Ввод:

```
4 4
0 2
0 -2
2 0
-2 0
```

Вывод:

```
2.94725152
```

## Решение

Ответ — наибольшее расстояние от точки круга до ближайшего к ней
завода. Точки, ближайшие к заводу i, образуют его ячейку Вороного —
выпуклую область; режем квадрат вокруг круга серединными
перпендикулярами с другими заводами, начиная с ближайших, и
останавливаемся, когда следующий завод более чем вдвое дальше самой
дальней вершины ячейки: более дальние перпендикуляры её уже не режут. Расстояние до
завода — выпуклая функция, поэтому на части ячейки внутри круга оно
максимально в вершине ячейки внутри круга, в точке, где сторона ячейки
пересекает окружность, или где-то на дуге окружности внутри ячейки, а
внутренний максимум дуги — напротив завода (для завода в центре —
в любой точке). Берём наибольшего из этих кандидатов по всем ячейкам.

Подводные камни:

- самая дальняя точка часто лежит на границе, там, где перпендикуляр
  встречает окружность (тест 01, тест 04);
- дуга границы может содержать самую дальнюю точку в середине, в точке
  напротив завода (тест 03, gen3);
- заводы могут повторяться, а у двух равных точек нет серединного
  перпендикуляра, поэтому их пропускаем (тест 05, gen5);
- один завод даёт R плюс его расстояние от центра (тесты 02, 03, gen3).
