# 1520. 帝国反击战

[Timus 1520](https://acm.timus.ru/problem.aspx?space=1&num=1520) · 难度 2420 · geometry

原题作者 Nikita Rybak、Ilya Grebnov 与 Dmitry Kovalioff，出自 Timus Top Coders: Third Challenge。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

共和国是以原点为圆心、半径为 R（1 ≤ R ≤ 1000）的圆盘，其中有 N 座工厂
（1 ≤ N ≤ 300）位于整点上。每座工厂上投下一枚炸弹，所有炸弹的杀伤半径相同。求这些
炸弹合起来覆盖整个圆盘所需的最小半径，小数点后至少五位。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 R，然后是 N 座工厂的坐标。

## 输出

最小半径。

## 样例

### 样例 1

输入:

```
4 4
0 2
0 -2
2 0
-2 0
```

输出:

```
2.94725152
```

## 解法

答案是圆盘内一点到最近工厂的距离的最大值。离工厂 i 最近的点构成它的 Voronoi 单元，
是一个凸区域；用它与其他工厂的垂直平分线去切一个包住圆盘的正方形，从最近的开始，
一旦下一座工厂的距离超过最远单元顶点距离的两倍就停止，因为更远的平分线已切不到它。到工厂的
距离是凸函数，所以在单元位于圆盘内的部分，最大值出现在圆盘内的单元顶点、单元边与圆
的交点，或者单元内某段圆弧上，而圆弧内部的最大值在工厂对面的圆上一点（工厂在圆心时，
任意一点均可）。对所有单元取这些候选的最大值。

注意事项：

- 最远点常在边界上，即平分线与圆的交点（测试 01、测试 04）；
- 边界圆弧的中间也可能有最远点，即工厂对面的那一点（测试 03、gen3）；
- 工厂可能重复，两个相同的点没有垂直平分线，所以跳过（测试 05、gen5）；
- 只有一座工厂时答案是 R 加上它到圆心的距离（测试 02、03、gen3）。
