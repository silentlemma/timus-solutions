# 1577. 电子邮件

[Timus 1577](https://acm.timus.ru/problem.aspx?space=1&num=1577) · 难度 470 · dp

原题作者 Igor Chevdar，出自 2007 年 10 月第十四届斯维尔德洛夫斯克州中学生团体程序设计公开赛（USU Junior Contest）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

若真实密码是输入字符串的子序列，服务器就接受该字符串。Vasya 有两个由小写字母组成、各长至多 2000 的密码，想要
一个两台服务器都接受的字符串。求以两个密码为子序列的最短字符串有多少个不同的，对 10⁹ + 7 取模。

时间限制：1 秒。内存限制：64 MB。

## 输入

两个密码，每行一个。

## 输出

最短公共字符串的个数对 10⁹ + 7 取模。

## 样例

### 样例 1

输入:

```
b
ab
```

输出:

```
1
```

### 样例 2

输入:

```
abcab
cba
```

输出:

```
4
```

## 解法

这些就是两个密码 a 和 b 的最短公共超序列。对后缀 a[i:] 和 b[j:] 保存最短长度 L(i, j) 和该长度的不同字符串个数
C(i, j)。若 a[i] = b[j]，每个这样的字符串都以这个字母开头，其余部分是 a[i+1:] 与 b[j+1:] 的最短字符串。否则它
以 a[i] 或 b[j] 开头，其余部分是 a[i+1:]、b[j:] 或 a[i:]、b[j+1:] 的最短字符串。首字母不同的字符串互不相同，所以
达到最短长度的各分支的个数直接相加，不会重复计数。

当一个后缀为空时，唯一的答案就是另一个后缀。从密码末尾往前逐行填表，第 i 行只需要第 i + 1 行，所以两行就够了。
`O(|a|·|b|)`，约 4·10⁶ 步。结果已在 250 对随机短密码上与列举所有最短字符串的做法对照。

注意事项：

- 不同的交错方式可能得到同一个字符串，例如由 `a` 和 `a` 得到 `aa`，所以计数的是字符串而不是方式（测试 03、05）；
- 没有公共字母的密码给出所有交错，即 C(|a| + |b|, |a|)，需要取模（测试 gen4）；
- Python 在 PyPy 下运行：最大的测试在 CPython 下约需 1–2.5 秒（限制为 1 秒），在 PyPy 下约 0.15 秒。
