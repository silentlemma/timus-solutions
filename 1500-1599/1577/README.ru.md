# 1577. Электронная почта

[Timus 1577](https://acm.timus.ru/problem.aspx?space=1&num=1577) · сложность 470 · dp

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Сервер принимает введённую строку, если настоящий пароль — её
подпоследовательность. У Васи два пароля из строчных букв длиной до 2000
каждый, и нужна одна строка, которую примут оба сервера. Нужно посчитать
различные строки наименьшей возможной длины, содержащие оба пароля как
подпоследовательности, по модулю 10⁹ + 7.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Два пароля, по одному в строке.

## Выходные данные

Число кратчайших общих строк по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
b
ab
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
abcab
cba
```

Вывод:

```
4
```

## Решение

Это кратчайшие общие надпоследовательности паролей a и b. Для суффиксов
a[i:] и b[j:] храним их наименьшую длину L(i, j) и число C(i, j)
различных строк этой длины. Если a[i] = b[j], каждая такая строка
начинается с этой буквы, а остаток — кратчайшая строка для a[i+1:] и
b[j+1:]. Иначе она начинается с a[i] или с b[j], а остаток — кратчайшая
строка для a[i+1:], b[j:] или для a[i:], b[j+1:]. Строки с разными
первыми буквами различны, так что числа для ветвей, достигающих
наименьшей длины, просто складываются; ничего не считается дважды.

Когда один суффикс пуст, единственный ответ — другой суффикс. Строки
таблицы заполняются от концов паролей назад, и строке i нужна только
строка i + 1, так что хватает двух строк. `O(|a|·|b|)`, 4·10⁶ шагов.
Результаты сверены с перебором всех строк наименьшей длины на 250
случайных парах коротких паролей.

Подводные камни:

- разные способы чередования могут давать одну и ту же строку, как `aa`
  из `a` и `a`, так что считаются строки, а не способы (тесты 03, 05);
- пароли без общих букв дают все чередования, C(|a| + |b|, |a|), что
  требует модуля (тест gen4);
- Python запускается под PyPy: самые большие тесты идут около 1–2.5 с
  в CPython при ограничении 1 с и около 0.15 с в PyPy.
