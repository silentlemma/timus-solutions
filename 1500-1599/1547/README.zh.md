# 1547. 密码搜索

[Timus 1547](https://acm.timus.ru/problem.aspx?space=1&num=1547) · 难度 857 · math

原题作者 Vladimir Yakovlev，出自 2007 年 4 月 21 日在叶卡捷琳堡举行的第十一届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

所有长度为 1 到 N 的小写字母密码先按长度、再按字母顺序列出：a, …, z, aa, …, zz, …。把这个列
表尽量均匀地分成 M 个连续区间，必要时前面的区间多一个，并把每个区间输出为"首-尾"
（1 ≤ N, M ≤ 50；密码数不少于 M）。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 M。

## 输出

M 行"首-尾"。

## 样例

### 样例 1

输入:

```
5 4
```

输出:

```
a-fssst
fsssu-mmmmn
mmmmo-tgggg
tgggh-zzzzz
```

## 解法

共有 T = 26 + 26² + … + 26ᴺ 个密码，最多约 6·10⁷⁰。设 T = q·M + r，第 i 个处理器（从 0 起）
负责编号从 i·q + min(i, r) + 1 到 (i + 1)·q + min(i + 1, r) 的密码。

先按长度、再按字母顺序列出字符串，就是双射 26 进制：第 k 个密码（从 1 起）就是用数字
a = 1, …, z = 26 写出的 k。转换时反复取 (k − 1) mod 26 作为最后一个字母，再对
⌊(k − 1) / 26⌋ 继续。

Python、Go 和 Java 使用自带的大整数。C++ 和 Rust 把数存成 26 进制数字列表：T 在 26 进制下
是 11…10，除以 M 是竖式除法，区间端点是 q 乘一个小数再加一个小数，转换时减 1 并去掉最低位。
共 `O(M·N)` 次数位运算。

注意事项：

- 只含一个密码的区间也要写成"首-尾"，如 a-a（测试 03）；
- 数量可达 71 位（测试 04）；
- 多出的密码分给前 T mod M 个处理器（测试 07）。
