## Задача

Все пароли из строчных букв длины от 1 до N перечислены по длине, а
затем по алфавиту: a, …, z, aa, …, zz, …. Нужно разбить список на M
идущих подряд диапазонов как можно ровнее, при необходимости первые
диапазоны на один длиннее, и вывести каждый диапазон как
первый-последний (1 ≤ N, M ≤ 50; паролей не меньше M).

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M.

## Выходные данные

M строк «первый-последний».

## Примеры

### Пример 1

Ввод:

```
5 4
```

Вывод:

```
a-fssst
fsssu-mmmmn
mmmmo-tgggg
tgggh-zzzzz
```

## Решение

Всего паролей T = 26 + 26² + … + 26ᴺ, примерно до 6·10⁷⁰. При
T = q·M + r процессор i (с 0) перебирает пароли с номерами от
i·q + min(i, r) + 1 до (i + 1)·q + min(i + 1, r).

Перечисление строк по длине, а затем по алфавиту — это биективная
система по основанию 26: k-й пароль (с 1) — это k, записанное цифрами
a = 1, …, z = 26. Для перевода раз за разом берём (k − 1) mod 26 как
последнюю букву и продолжаем с ⌊(k − 1) / 26⌋.

Python, Go и Java пользуются своими длинными числами. C++ и Rust
хранят числа списками цифр по основанию 26: T — это 11…10 в этой
системе, деление на M — деление в столбик, концы диапазонов — q,
умноженное на маленькое число, плюс маленькое число, а перевод вычитает
1 и отбрасывает младшую цифру. `O(M·N²)` операций с цифрами; для Python
из-за отдельных степеней — `O(N³ + M·N²)` при умножении в столбик.

Подводные камни:

- диапазон из одного пароля всё равно выводится как первый-последний,
  например a-a (тест 03);
- количества доходят до 71 цифры (тест 04);
- лишние пароли достаются первым T mod M процессорам (тест 07).
