# 1563. Баяны

[Timus 1563](https://acm.timus.ru/problem.aspx?space=1&num=1563) · сложность 54 · hashing

Автор оригинальной задачи — Владимир Яковлев; XII чемпионат УрГУ по программированию, 6 октября 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Анжела по порядку обходит N магазинов (N ≤ 1000) и у каждого магазина,
название которого уже встречалось, говорит «Баян». Нужно посчитать,
сколько раз Анжела это скажет. Название — строка из 1–30 латинских букв
и пробелов, и никакие два названия не различаются только регистром.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем по одному названию магазина в строке.

## Выходные данные

Число повторных магазинов.

## Примеры

### Пример 1

Ввод:

```
12
ESPRIT
Nice Connection
Camelot
Adilisik
Lady and Gentleman City
MEXX
Camelot
Sultanna Frantsuzova
Camaieu
MEXX
Axara
Camelot
```

Вывод:

```
3
```

## Решение

Каждый магазин после первого с тем же названием — повтор, так что ответ
равен N минус число различных названий, посчитанных хеш-множеством.
Название — вся строка вместе с пробелами, поэтому строки читаются
целиком, а отрезается только конец строки. `O(N)` в среднем.

Подводные камни:

- в названиях есть пробелы, так что чтение по словам разбивает их
  (тесты 03, gen3);
- одним пробелом больше или меньше — уже другое название (тест 03);
- одно название может быть префиксом другого (тест 05).
