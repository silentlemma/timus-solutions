# 1552. Brainfuck

[Timus 1552](https://acm.timus.ru/problem.aspx?space=1&num=1552) · 难度 1158 · dp

原题出自 2007 年 9 月彼得罗扎沃茨克集训的 Novosibirsk SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一台只有 > < + − . 命令的 brainfuck 机器有 30000 个字节单元，初值都为 0，指针指向最左边的单元；
指针和字节都会循环回绕。写出一个最短的程序，输出给定的至多 50 个小写字母组成的字符串。最优
程序从来不需要超过四个单元。

时间限制：2 秒。内存限制：64 MB。

## 输入

那个字符串。

## 输出

一个最短的程序，写在一行。任何一个都可以。

## 样例

### 样例 1

输入:

```
a
```

输出:

```
+++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++.
```

## 解法

只有用到的单元重要，去掉它们之间未用的单元或把它们挪到起始单元旁边只会缩短移动，所以它们是
四个相邻单元组成的一块，起始单元在块内某处；靠回绕可以走到单元 0 的左边。只改不打印的单元完
全可以晚些再改，所以每个单元要么是 0，要么是最后一次从它打印的字母。

逐个打印字母。打印一个字母后，状态是指针所在的单元（存着这个字母）以及其余三个单元的值（0 或
某个字母）：4·27³ ≈ 79000 个状态。从单元 q 打印下一个字母的代价是移动 |p − q|、值的变化（从 0
到字母是其编码，字母之间是差值，绕过 256 从不更划算）再加一个点。DP 记录到达每个状态的最小代
价和前驱状态，倒着走一遍即可重建程序。共 `O(n·4·27³·4)` 步。

注意事项：

- 样例程序被分成了几行显示，但答案只占一行；
- 新单元从 0 开始，比 a 低 97，而用过的单元可能近得多（测试 03、04）；
- 相距很远的字母混在一起会占用三个单元，其中一个在起点左边，靠回绕到达（测试 08）；
- Python 在 PyPy 下运行：50 个字母的测试 CPython 约需 3.2 秒，PyPy 约 0.2 秒。
