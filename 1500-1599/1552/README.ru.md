# 1552. Brainfuck

[Timus 1552](https://acm.timus.ru/problem.aspx?space=1&num=1552) · сложность 1156 · dp

Оригинальная задача — Novosibirsk SU Contest, Петрозаводские сборы, сентябрь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У машины brainfuck, знающей только команды > < + − ., есть 30000
байтовых ячеек, все равны 0, и указатель на самую левую; указатель и
байты переходят через край по кругу. Нужно написать самую короткую
программу, печатающую заданную строку не длиннее 50 строчных букв.
Оптимальной программе никогда не нужно больше четырёх ячеек.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Строка.

## Выходные данные

Самая короткая программа одной строкой. Подходит любая.

## Примеры

### Пример 1

Ввод:

```
a
```

Вывод:

```
+++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++.
```

## Решение

Важны только используемые ячейки, а убрать неиспользуемые между ними или
придвинуть их к стартовой ячейке значит лишь сократить переходы, так что
они образуют блок из четырёх соседних ячеек, где-то внутри которого
стартовая; уйти левее ячейки 0 можно благодаря переходу через край.
Ячейку, которую меняют, не печатая, можно было бы поменять и позже,
поэтому в каждой ячейке либо 0, либо последняя напечатанная из неё
буква.

Будем печатать буквы по одной. После буквы состояние — ячейка под
указателем (в ней эта буква) и значения трёх остальных ячеек, 0 или
буква: 4·27³ ≈ 79000 состояний. Напечатать следующую букву из ячейки q
стоит переход |p − q|, изменение значения (от 0 до буквы — её код, между
буквами — их разность, переход через 256 никогда не выгоднее) и точку.
ДП хранит самый дешёвый путь в каждое состояние и предыдущее состояние,
так что программа восстанавливается обратным проходом.
`O(n·4·27³·4)` шагов.

Подводные камни:

- программа из примера показана в нескольких строках, но ответ — одна
  строка;
- новая ячейка начинается с 0, на 97 шагов ниже a, а использованная
  может быть гораздо ближе (тесты 03, 04);
- далёкие друг от друга буквы вперемешку занимают три ячейки, одна из
  них левее стартовой, куда попадают через край (тест 08);
- Python запускается в PyPy: тесты из 50 букв занимают около 3,2 с в
  CPython и около 0,2 с в PyPy.
