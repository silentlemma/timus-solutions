# 1538. 瞭望塔

[Timus 1538](https://acm.timus.ru/problem.aspx?space=1&num=1538) · 难度 1273 · geometry

原题作者 Alexander Ipatov，出自 2007 年 3 月 3 日第八届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 N 座山丘（5 ≤ N ≤ 5000），坐标为绝对值不超过 10⁸ 的整数，任意三座不共线。选出五座
作为一个凸五边形的顶点，或说明不存在。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是各山丘的坐标，每行一座。

## 输出

`No`，或 `Yes` 以及按逆时针绕五边形顺序排列的五座山丘编号。任何这样的五边形都可以。

## 样例

### 样例 1

输入:

```
6
1 0
0 1
1 2
2 0
2 2
3 1
```

输出:

```
Yes
2 1 4 5 3
```

## 解法

由 Erdős–Szekeres 定理，平面上任意九个无三点共线的点中必有五个处于凸位置（八个不够）。所
以只需看前 min(N, 9) 座山丘：枚举其至多 C(9, 5) = 126 个五元子集，用 Andrew 单调链求每个
子集的凸包，输出第一个凸包包含全部五点的子集。单调链按逆时针给出凸包。只有 N ≤ 8 时答案才
可能是 `No`。其余输入甚至不必读取。叉积可达约 8·10¹⁶，需要 64 位。读入九个点之外为
`O(1)`。

注意事项：

- 八座山丘可能没有凸五边形（测试 04），但第九座总会造出一个（测试 05）；
- 无论输入顺序如何，山丘都必须按逆时针列出（测试 06）；
- 坐标为 10⁸ 时叉积超出 32 位（测试 07）；
- 答案可能不止一个，所以测试使用检查器（所有测试）。
