# 1538. Сторожевые башни

[Timus 1538](https://acm.timus.ru/problem.aspx?space=1&num=1538) · сложность 1273 · geometry

## Задача

Даны N холмов (5 ≤ N ≤ 5000) с целыми координатами, по модулю не больше
10⁸, никакие три не лежат на одной прямой. Нужно выбрать пять, которые
являются вершинами выпуклого пятиугольника, или сообщить, что таких нет.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем координаты холмов, по холму в строке.

## Выходные данные

`No` или `Yes` и номера пяти холмов в порядке обхода пятиугольника
против часовой стрелки. Подходит любой такой пятиугольник.

## Примеры

### Пример 1

Ввод:

```
6
1 0
0 1
1 2
2 0
2 2
3 1
```

Вывод:

```
Yes
2 1 4 5 3
```

## Решение

По теореме Эрдёша — Секереша любые девять точек плоскости, никакие три
из которых не лежат на одной прямой, содержат пять точек в выпуклом
положении (восьми недостаточно). Значит, хватает первых min(N, 9)
холмов: переберём их пятиэлементные подмножества, которых не больше
C(9, 5) = 126, построим выпуклую оболочку каждого монотонной цепью
Эндрю и выведем первое подмножество, оболочка которого содержит все пять
точек. Цепь перечисляет оболочку против часовой стрелки. Ответ `No`
возможен только при N ≤ 8. Остаток входа можно даже не читать.
Векторные произведения доходят примерно до 8·10¹⁶, поэтому нужны 64
бита. `O(1)` сверх чтения девяти точек.

Подводные камни:

- у восьми холмов выпуклого пятиугольника может не быть (тест 04), но
  девятый холм всегда его создаёт (тест 05);
- холмы нужно перечислить против часовой стрелки, в каком бы порядке
  они ни шли во входе (тест 06);
- при координатах 10⁸ векторные произведения не помещаются в 32 бита
  (тест 07);
- ответов бывает несколько, поэтому тесты проверяет чекер (все тесты).
