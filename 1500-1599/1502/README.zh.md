# 1502. 多米诺点数

[Timus 1502](https://acm.timus.ru/problem.aspx?space=1&num=1502) · 难度 74 · math

原题为民间流传的题目，由 Stanislav Vasiliev 整理，出自 2006 年第 31 届 ACM ICPC 叶卡捷琳堡四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一套多米诺骨牌中，0 到 N（1 ≤ N ≤ 10000）之间每一对无序点数都恰有一张牌，包括两端
相同的牌。求整套牌的点数总和。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

N。

## 输出

点数总和。

## 样例

### 样例 1

输入:

```
2
```

输出:

```
12
```

## 解法

统计每个点数出现在多少个端上。点数 v 出现在每张 v–w（w ≠ v）的一端，共 N 张；又出
现在 v–v 的两端：总共 N + 2 个端。所以点数总和为
(N + 2)·(0 + 1 + … + N) = (N + 2)·N·(N + 1)/2。`O(1)`。

注意事项：

- 两端相同的牌要把点数算两次（测试 02）；
- N = 10⁴ 时答案约为 5·10¹¹，需要 64 位（测试 04）。
