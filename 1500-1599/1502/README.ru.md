# 1502. Точки домино

[Timus 1502](https://acm.timus.ru/problem.aspx?space=1&num=1502) · сложность 74 · math

Оригинальная задача — фольклор, подготовил Станислав Васильев; четвертьфинал XXXI ACM ICPC, Екатеринбург, 2006 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В наборе домино есть по одной костяшке для каждой неупорядоченной пары
чисел точек от 0 до N (1 ≤ N ≤ 10000), включая дубли. Нужно найти общее
число точек в наборе.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

Общее число точек.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
12
```

## Решение

Посчитаем, сколько раз встречается каждое значение конца. Значение v
стоит на одном конце каждой костяшки v–w с w ≠ v, то есть N костяшек, и
на обоих концах дубля v–v: всего N + 2 конца. Значит, точек
(N + 2)·(0 + 1 + … + N) = (N + 2)·N·(N + 1)/2. `O(1)`.

Подводные камни:

- дубль учитывает своё значение дважды (тест 02);
- при N = 10⁴ ответ около 5·10¹¹ и требует 64 бит (тест 04).
