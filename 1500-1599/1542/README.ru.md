# 1542. Автодополнение

[Timus 1542](https://acm.timus.ru/problem.aspx?space=1&num=1542) · сложность 624 · sorting

Автор оригинальной задачи — Ден Расковалов; XI командный студенческий чемпионат Урала по программированию, Екатеринбург, 21 апреля 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В словаре N различных слов (N ≤ 10⁵, не длиннее 15 строчных букв) с их
частотами (до 10⁶). Для каждой из M ≤ 15000 набранных приставок нужно
вывести не больше десяти слов, начинающихся с неё, сначала самые частые,
а при равных частотах по алфавиту.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк со словом и его частотой, затем M и M приставок, по
одной в строке.

## Выходные данные

Для каждой приставки — её варианты, по одному в строке; списки соседних
приставок разделяются пустой строкой.

## Примеры

### Пример 1

Ввод:

```
5
kare 10
kanojo 20
karetachi 1
korosu 7
sakura 3
3
k
ka
kar
```

Вывод:

```
kanojo
kare
korosu
karetachi

kanojo
kare
karetachi

kare
karetachi
```

## Решение

Один раз отсортируем слова по убыванию частоты, а затем по алфавиту.
Положим каждый различный запрос в хеш-таблицу с пустым списком. Затем
пройдём по отсортированным словам: для каждой из не больше 15 приставок
слова, которая является запросом, допишем слово в её список, если там
ещё нет десяти. Поскольку слова идут в нужном порядке, каждый список в
итоге совпадает с ответом. Общее время — `O(N log N + 15·N + M)`;
повторяющиеся запросы используют один список.

Подводные камни:

- приставка без слов всё равно занимает своё место в выводе — пустой
  блок, в том числе в самом начале или в конце (тест 02);
- равные частоты идут по алфавиту, так что a раньше ab (тест 03);
- запрос может совпадать с целым словом или быть длиннее всех слов
  (тест 05).
