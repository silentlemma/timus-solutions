# 1509. 识别骨牌

[Timus 1509](https://acm.timus.ru/problem.aspx?space=1&num=1509) · 难度 3218 · geometry

原题作者 Ekaterina Ovechkina 与 Stanislav Vasiliev，出自 2006 年第 31 届 ACM ICPC 叶卡捷琳堡四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一张骨牌是由两个正方形组成的 L × 2L 矩形（1 ≤ L ≤ 100），每个正方形里按通常方式排
着 0 到 6 个点。取以正方形中心为中心、边长减半的小正方形：一个点在中心，两个点在小
正方形的两个相对角上，三个点再加上中心，四个点占满它的四个角，五个点再加上中心，六
个点再加上它平行于骨牌长边的两条边的中点。照片按实际尺寸拍下了一张扣着的骨牌的全部
N 个点（1 ≤ N ≤ 12），骨牌被任意旋转和平移，坐标精确到 0.0001。L 没有给出。按字典
序输出所有可能的点数对 A ≤ B。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N 个点的坐标。

## 输出

所有可能的 "A B"，每行一对。

## 样例

### 样例 1

输入:

```
2
1.12 2.2
7 -3.0001
```

输出:

```
0 2
1 1
```

## 解法

枚举所有 A + B = N 且 A ≤ B 的组合。按 L = 1、骨牌沿 x 轴摆放生成它的点，寻找把它
们映到照片上的相似变换。取照片上的一点 g0 和离它最远的点 g1。把点看成复数，对模板
中每一对有序点 (a, b)，映射 z ↦ g0 + (z − a)·(g1 − g0)/(b − a) 把 a 送到 g0、b 送到
g1；系数的模就是 L，必须在 1 到 100 之间。如果模板的每个点都在小容差内落到照片上各
不相同的点上，这一组合就成立。再对镜像模板重复一遍。单个点只能是 0-1。最多 12 个
点，搜索量极小。

各解法也接受任何摆放的镜像。题面说骨牌扣着放，但没有说清照片是朝哪个方向镜像的；这
种理解被评测系统接受。

注意事项：

- 两个点既符合 0-2 也符合 1-1，只是尺寸不同（测试 01）；
- 这时由 L 的范围决定：相距 0.8 的两个点不可能是 1-1，相距 80 的两个点不可能是
  0-2（测试 03、04、gen4）；
- 单个点只能是 0-1（测试 02）；
- 骨牌可以转任意角度，也可以是镜像（测试 06、07、09、10）；
- 坐标有 1e-4 的误差，所以要带容差比较，而容差必须远小于 L = 1 时点间的 0.25（测
  试 08、gen2）。
