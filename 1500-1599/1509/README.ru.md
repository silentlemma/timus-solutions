# 1509. Распознавание домино

[Timus 1509](https://acm.timus.ru/problem.aspx?space=1&num=1509) · сложность 3220 · geometry

Авторы оригинальной задачи — Екатерина Овечкина и Станислав Васильев; четвертьфинал XXXI ACM ICPC, Екатеринбург, 2006 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Костяшка домино — прямоугольник L × 2L (1 ≤ L ≤ 100) из двух квадратов, в
каждом от 0 до 6 точек в обычном порядке. Возьмём квадрат вдвое меньшей
стороны вокруг центра квадрата, с параллельными сторонами: одна точка стоит
в центре, две — в левом нижнем и правом верхнем углах малого квадрата при
вертикальной костяшке, три добавляют центр, четыре занимают все его углы,
пять добавляют центр, а шесть добавляют середины двух его сторон,
параллельных длинным сторонам костяшки. На фото видны все N точек (1 ≤ N ≤
12) одной перевёрнутой костяшки в натуральную величину, произвольно
повёрнутой и сдвинутой, без перспективных или иных искажений; координаты
точны до 0.0001. L не дано. Нужно вывести все возможные пары A ≤ B чисел
точек в лексикографическом порядке.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем координаты N точек.

## Выходные данные

Возможные пары «A B» по одной в строке.

## Примеры

### Пример 1

Ввод:

```
2
1.12 2.2
7 -3.0001
```

Вывод:

```
0 2
1 1
```

## Решение

Перебираем все пары 0 ≤ A ≤ B ≤ 6 с A + B = N. Строим их точки для L = 1,
положив костяшку вдоль оси x, и ищем подобие, переводящее их в фото. Возьмём
точку фото g0 и самую дальнюю от неё точку g1. Если считать точки
комплексными числами, то для каждой упорядоченной пары (a, b) различных
точек шаблона отображение z ↦ g0 + (z − a)·(g1 − g0)/(b − a) переводит a в
g0 и b в g1; модуль его множителя равен L и должен лежать от 1 до 100 с
учётом допуска. Пара подходит, если каждая точка шаблона попадает с небольшим
допуском в свою отдельную точку фото. То же повторяем с зеркальным
шаблоном. Одна точка может быть только 0-1. При не более чем 12 точках
перебор крошечный.

Все пять решений проверяют и зеркальное отражение каждого расположения.

Подводные камни:

- две точки подходят и для 0-2, и для 1-1, при разных размерах
  (тест 01);
- тогда решают границы L: две точки на расстоянии 0.8 не могут быть
  1-1, а на расстоянии 80 — 0-2 (тесты 03, 04, gen4);
- одна точка — только 0-1 (тест 02);
- нужно учитывать произвольный поворот и вид перевёрнутой костяшки (тесты 06, 07,
  09, 10);
- в координатах погрешность 1e-4, поэтому сравниваем с допуском,
  который много меньше 0.25 между точками при L = 1 (тест 08, gen2).
