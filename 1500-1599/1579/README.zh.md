# 1579. 运送皮大衣

[Timus 1579](https://acm.timus.ru/problem.aspx?space=1&num=1579) · 难度 499 · greedy

原题作者 Alexander Kokovin，出自 2007 年 10 月第十四届斯维尔德洛夫斯克州中学生团体程序设计公开赛（USU Junior Contest）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N ≤ 10⁵ 件皮大衣，尺寸按不降顺序给出，要一件套一件地穿着带出商店。一件大衣只有尺寸比另一件大超过 R 时才能套
在它外面。把大衣分成最少的趟数，每趟输出大衣件数及按递增顺序的编号。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 R，然后是 N 个尺寸。

## 输出

趟数 K，然后 K 行，每行一趟的大衣。任何最优答案都被接受。

## 样例

### 样例 1

输入:

```
8 3
1 2 3 5 7 10 12 13
```

输出:

```
3
2 3 6
3 1 4 7
3 2 5 8
```

## 解法

尺寸两两相差都不超过 R 的大衣永远不能在同一趟，所以窗口 [x, x + R] 内尺寸个数的最大值是下界 K；在已排序的尺
寸上用双指针一遍就能求出。

K 趟也足够：把大衣轮流分配，第 i 件放进第 i mod K 趟。同一趟中第 i 件之后是第 i + K 件，而从 i 到 i + K 的
K + 1 件放不进同一个窗口，所以第 i + K 件的尺寸比第 i 件大超过 R。`O(N)`。结果已在 400 个随机小测试上与穷举所有
分趟方式的做法对照。

注意事项：

- 尺寸必须增大超过 R，所以恰好相差 R 的尺寸不能在同一趟（测试 04）；
- R = 0 时相同尺寸需要不同的趟（测试 03、gen2）；
- 合法答案不止一个，所以检查器检验各趟。

## 优化解法

C++、Go 和 Rust 仍用双指针滑动窗口与循环分组。尺寸及其非负差至多为 10⁹，因此尺寸数组占 4N 字节。出行编号 t 从零开始，衣服编号从 t+1 起，每次加 K，直到超过 N。衣服件数为 ⌊(N−1−t)/K⌋+1，可先输出件数再逐个输出编号。输入块为 4096 字节，输出缓冲为 8192 字节。寻找窗口并枚举编号共耗时 O(N)，尺寸数组占 O(N) 空间。Java 和 Python 复用达标的基础版。

已通过评测的基础实现 [1579_greedy.java](1579_greedy.java), [1579_greedy.py](1579_greedy.py) 也满足快速版本的要求：在保存的比较快照中，时间和内存均符合前 15% 或前十名的排名收录规则。直接复用这些源文件，不创建相同副本。星号标记尚未达到该语言目标排名的版本。
