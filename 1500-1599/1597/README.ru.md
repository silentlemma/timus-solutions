# 1597. Чернобыльский орёл на крыше. Версия 2

[Timus 1597](https://acm.timus.ru/problem.aspx?space=1&num=1597) · сложность 1776 · binary_search

Оригинальную задачу подготовил Сергей Ведерников.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Яйца остаются целыми при падении с этажей до неизвестного E,
0 ≤ E ≤ n, а выше E разбиваются. Имея k яиц, причём целые можно бросать снова,
нужно найти наименьшее число бросков, которое в худшем случае определяет
E. До 1000 тестов, k и n до 10¹⁸, в конце `0 0`. Это
[задача 1223](../../1200-1299/1223/README.ru.md) с гораздо большими
числами.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Строки с k и n, затем `0 0`.

## Выходные данные

Наименьшее число бросков для каждого теста.

## Примеры

### Пример 1

Ввод:

```
1 10
2 5
0 0
```

Вывод:

```
10
3
```

## Решение

Перевернём вопрос: сколько этажей можно разобрать за t бросков с k
яйцами? Первый бросок делит здание: если яйцо разбилось, на этажи ниже
остаются t − 1 бросков и k − 1 яиц, иначе на этажи выше — t − 1 бросков и
k яиц, так что f(t, k) = f(t − 1, k − 1) + f(t − 1, k) + 1. Решение этой
рекурренты — f(t, k) = C(t, 1) + C(t, 2) + … + C(t, k). Ответ — наименьшее
t с f(t, k) ≥ n, а f растёт с t, так что его находит двоичный поиск.

С одним яйцом можно бросать только поэтажно, и ответ — само n. С двумя и
более f(t, 2) = t(t + 1)/2 достигает 10¹⁸ уже при t меньше 1,5·10⁹, так
что поиск идёт по t до U = 2·10⁹. Сумма строится по членам,
C(t, i) = C(t, i − 1)·(t − i + 1)/i, и обрывается, как только превысит n;
это покрывает и огромные k: члены растут так быстро, что нужны лишь
несколько десятков. Не больше 31 шага примерно по 60 членов на тест.

Результаты сверены с классической динамикой по этажам и яйцам для всех
зданий до 120 этажей и до 8 яиц.

Подводные камни:

- произведение C(t, i − 1)·(t − i + 1) переполняет 64 бита; решения на
  C++, Go, Java и Rust раскладывают C(t, i − 1) = q·i + r и считают
  q·(t − i + 1) + r·(t − i + 1)/i, что точно, и сдаются, как только
  q·(t − i + 1) превысило бы n;
- при k ≥ 60 яйцах ответ — просто двоичный поиск по этажам, длина n в
  битах, и тот же цикл его даёт;
- одному яйцу нужно n бросков, что может превышать диапазон поиска и
  обрабатывается заранее.
