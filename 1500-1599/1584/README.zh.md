# 1584. 法老的秘密

[Timus 1584](https://acm.timus.ru/problem.aspx?space=1&num=1584) · 难度 1325 · matching

原题作者 Alex Gevak，出自 2007 年 10 月 27 日在叶卡捷琳堡举行的 ACM ICPC 2007–2008 NEERC 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

雕像排成 n × m 的方阵（n、m 为偶数，至多 20），每尊用一个字母表示种类，种类少于 30 种。要重新摆放，使每一行和每一列
从两端读起都一样，并尽量少搬动雕像，输出搬动次数。保证总能摆成。

时间限制：1 秒。内存限制：64 MB。

## 输入

n 和 m，然后是 n 行，每行 m 个字母。

## 输出

最少的搬动次数。

## 样例

### 样例 1

输入:

```
4 4
abxa
xyyb
xyyx
abba
```

输出:

```
2
```

## 解法

行和列都对称，意味着一个格子的四个镜像 (i, j)、(i, m−1−j)、(n−1−i, j)、(n−1−i, m−1−j) 是同一种类。所以方阵分成
nm/4 组，每组四格，每组要放同一种类；有 c 尊雕像的种类恰好占 c/4 组。

已经站在其种类将来所在位置的雕像不动；其余每尊至少搬一次，而沿置换的每个环搬运恰好用这么多次（交换要两次，
如样例）。所以答案就是种类发生变化的格子数。把种类 k 分给一组的代价是 4 减去该组中已有的 k 类雕像数，最优选择
是一个指派问题：每种类的每个位置一列（种类 k 有 c/4 列），每组一行，用匈牙利算法以 O(G³) 求解，G = nm/4 ≤ 100。
结果已在 200 个随机小方阵上与枚举所有指派的做法对照。

注意事项：

- 计数的是搬动雕像的次数，而不是交换次数：一次交换是两次搬动（样例）；
- 一组中可能两种各两尊，此时不论分给哪一种，都有两尊要换（测试 03）；
- 逐组贪心可能妨碍别处更好的匹配，所以需要真正的指派。
