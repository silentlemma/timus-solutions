# 1584. Тайны фараонов

[Timus 1584](https://acm.timus.ru/problem.aspx?space=1&num=1584) · сложность 1325 · matching

Автор оригинальной задачи — Алексей Жевак; ACM ICPC 2007–2008, NEERC, Восточный подрегион, Екатеринбург, 27 октября 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Статуи стоят в прямоугольнике n × m (n и m чётные, до 20), каждая
обозначена буквой своего вида, видов меньше 30. Нужно переставить их так,
чтобы каждый ряд и каждый столбец читался одинаково с обоих концов,
перетащив как можно меньше статуй, и вывести это число. Переставить
всегда можно.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n и m, затем n строк по m букв.

## Выходные данные

Наименьшее число перетаскиваний.

## Примеры

### Пример 1

Ввод:

```
4 4
abxa
xyyb
xyyx
abba
```

Вывод:

```
2
```

## Решение

Симметричные ряды и столбцы означают, что четыре зеркальных образа
клетки, (i, j), (i, m−1−j), (n−1−i, j) и (n−1−i, m−1−j), заняты одним
видом. Значит, прямоугольник распадается на nm/4 групп по четыре клетки,
каждую нужно заполнить одним видом, и вид из c статуй занимает ровно c/4
групп.

Статуя, уже стоящая там, где будет её вид, остаётся на месте; каждую
другую нужно перетащить хотя бы раз, а перенос по каждому циклу
перестановки обходится ровно таким числом перетаскиваний (обмен — два,
как в примере). Так что ответ — число клеток, вид которых меняется.
Отдать группу виду k стоит 4 минус число статуй вида k, уже стоящих в
ней, и лучший выбор — это задача о назначениях: по столбцу на каждое
место каждого вида (c/4 столбцов для вида k), по строке на группу,
решаемая венгерским алгоритмом за O(G³) при G = nm/4 ≤ 100 групп.
Результаты сверены с перебором всех назначений на 200 случайных
маленьких прямоугольниках.

Подводные камни:

- считаются перетаскивания статуй, а не обмены: один обмен — это два
  перетаскивания (пример);
- в группе могут стоять два вида по два, и тогда меняются две статуи,
  какой бы вид ей ни достался (тест 03);
- жадный выбор по группам может помешать лучшему выбору в другой группе,
  так что нужно настоящее назначение.
