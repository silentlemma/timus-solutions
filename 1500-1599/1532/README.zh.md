# 1532. 翻译之难

[Timus 1532](https://acm.timus.ru/problem.aspx?space=1&num=1532) · 难度 1976 · hashing

原题作者 Sergey Pupyrev，出自 2007 年 3 月 3 日第八届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

列表中有 K 个互不相同的单词（1 ≤ K ≤ 5000），每个由 1 到 15 个小写英文字母组成。其中一些是
另一些的错误拼写：错误拼写最多有两处错误，每处是漏掉一个字母、多出一个字母或写错一个
字母，并且每个单词的正确拼写都在列表中。按字典序输出所有连同其错误拼写出现不止一次的
单词。

时间限制：4 秒。内存限制：64 MB。

## 输入

K，然后是 K 个单词，每行一个。

## 输出

这类单词的个数，然后是这些单词，每行一个。

## 样例

### 样例 1

输入:

```
7
lomba
pella
palpa
papa
moina
morna
sin
```

输出:

```
5
moina
morna
palpa
papa
pella
```

## 解法

由于正确拼写都在列表中，一个单词属于答案当且仅当有另一个单词与它的编辑距离不超过 2。
取两个这样的单词的一个最优对齐：每次替换从两个单词中各删去一个字母，每个多余字母从其中
一个单词删去一个字母，剩下的是同一个串，称为剩余串。所以每个单词至多删去两个字母。反过
来，若从两个单词删去字母后剩下同一个串，对每个被删字母记下它所在的空隙：剩余串中位于它
之前的字母个数。在同一空隙内，两个单词被删的字母可以用替换配对，多出的插入，因此两词的
距离不超过各空隙中两个数量较大者之和。

对于剩余串相同、分别删去 c 和 d 个字母的两个单词，这个和在以下情况下不超过 2：

- c + d ≤ 2；
- c = 2 且 d = 1，单个空隙是那两个空隙之一；
- c = d = 2，两个空隙相同。

每个单词至多给出 1 + 15 + 105 = 121 个键：剩余串按每字母 5 位打包成整数（Python 直接用其字节），加上单词编号、
删去的字母数及其空隙。同一个单词不会两次给出相同的空隙。排序后，检查每组剩余串相同的键：
若剩余串本身是一个单词，组内所有单词都与它接近；两个各删去一个字母的单词
接近；删去两个字母的单词，与在相同空隙删去两个字母的单词、或在其某个空隙删去一个字母的
单词接近。按每字母 5 位打包时，剩余串最多占 75 位，所以 C++ 和 Rust 使用 128 位键，
Go 用两个 64 位字段，Java 用前 12 个字母在所有前段中的排名代替它们。
L ≤ 15 时为 `O(K·L²·(L + log(K·L)))`。

注意事项：

- 仅有相同的剩余串还不够：abcde 和 bcdxy 删去两个字母后都得到 bcd，但空隙不同，两者相距
  三次编辑（测试 05）；
- 交换两个相邻字母算两次编辑（测试 03）；
- 长度相差三或更多的单词永远不接近（测试 07）；
- 答案可以为空，此时输出 0（测试 02、04）。
