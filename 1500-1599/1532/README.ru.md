# 1532. Трудности перевода

[Timus 1532](https://acm.timus.ru/problem.aspx?space=1&num=1532) · сложность 1976 · hashing

Автор оригинальной задачи — Сергей Пупырев; Восьмое открытое личное первенство УрГУ, 3 марта 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В списке K различных слов (1 ≤ K ≤ 5000) длиной от 1 до 15 строчных
латинских букв. Некоторые из них — ошибочные написания других: в слове
не больше двух ошибок, каждая — пропущенная, лишняя или неверная буква,
а правильное написание каждого слова в списке есть. Нужно вывести в
лексикографическом порядке все слова, которые вместе со своими
ошибочными вариантами встречаются больше одного раза.

Ограничение времени: 4 секунды. Ограничение памяти: 64 МБ.

## Входные данные

K, затем K слов, по одному в строке.

## Выходные данные

Количество таких слов, затем сами слова, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
7
lomba
pella
palpa
papa
moina
morna
sin
```

Вывод:

```
5
moina
morna
palpa
papa
pella
```

## Решение

Раз все правильные написания есть в списке, слово попадает в ответ
ровно тогда, когда какое-то другое слово отстоит от него не больше чем
на две правки. Возьмём оптимальное выравнивание двух таких слов: каждая
замена удаляет по букве из обоих слов, каждая лишняя буква — из одного,
а оставшееся — одна и та же строка, остаток. Значит, каждое слово
теряет не больше двух букв. Обратно, если после удаления букв из двух
слов остаётся одно и то же, запишем для каждой удалённой буквы её
промежуток — число букв остатка перед ней. Внутри промежутка удалённые
буквы двух слов можно сопоставить заменами, а лишние вставить, так что
слова отстоят не больше чем на сумму по промежуткам большего из двух
количеств.

Для двух слов с общим остатком, потерявших c и d букв, эта сумма не
больше двух в таких случаях:

- c + d ≤ 2;
- c = 2 и d = 1, и единственный промежуток — один из двух;
- c = d = 2, и промежутки те же.

Каждое слово даёт не больше 1 + 15 + 105 = 121 ключа: остаток,
упакованный в число по 5 бит на букву (Python берёт его байты), номер слова, число удалённых букв
и их промежутки. Одинаковых промежутков одно слово дважды не даёт. После
сортировки каждая группа с одинаковым остатком проверяется: если
остаток сам является словом, к нему близки все в группе;
два слова, потерявшие по одной букве, близки; слово, потерявшее две
буквы, близко к слову, потерявшему две в тех же промежутках или одну в
одном из его промежутков. При упаковке по 5 бит на букву остаток занимает
до 75 бит, поэтому C++ и Rust используют 128-битные ключи, Go использует
два 64-битных поля, а Java заменяет первые 12 букв их рангом среди всех
начал. `O(K·L²·(L + log(K·L)))` при L ≤ 15.

Подводные камни:

- общего остатка мало: abcde и bcdxy после двух удалений дают bcd, но
  в разных промежутках, и между ними три правки (тест 05);
- перестановка двух соседних букв — это две правки (тест 03);
- слова, длины которых отличаются на три и больше, никогда не близки
  (тест 07);
- ответ может быть пустым, тогда выводится 0 (тесты 02, 04).
