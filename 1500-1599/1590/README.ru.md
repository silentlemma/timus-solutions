# 1590. Шифр Бэкона

[Timus 1590](https://acm.timus.ru/problem.aspx?space=1&num=1590) · сложность 186 · strings

## Задача

Нужно посчитать различные непустые подстроки строки длиной не больше
5000 из строчных латинских букв.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Строка.

## Выходные данные

Количество различных подстрок.

## Примеры

### Пример 1

Ввод:

```
aaba
```

Вывод:

```
8
```

## Решение

Строится суффиксный автомат строки. Каждое состояние отвечает за
подстроки, которые заканчиваются в одном и том же множестве позиций; их
длины идут от len(link) + 1 до len, так что в состоянии
len − len(link) различных подстрок, и никакая подстрока не попадает в
два состояния. Ответ — сумма len − len(link) по всем состояниям, кроме
начального. В автомате не больше 2n состояний, он строится за `O(n·26)`
времени и памяти. Результаты сверены с подсчётом всех подстрок через
множество на коротких строках.

Подводные камни:

- у случайной строки из 5000 букв около 12,5 миллиона различных
  подстрок, так что хранить их в 64 МБ нельзя;
- при расщеплении состояния копия получает все переходы старого
  состояния и его суффиксную ссылку;
- в тесте 02 одна буква и два состояния с учётом начального, поэтому
  число состояний может равняться 2n.
