# 1590. Количество различных подстрок

## Задача

Дана непустая строка из `N ≤ 5000` строчных латинских букв. Найдите число её различных непустых непрерывных подстрок. Лимит времени: 2 секунды. Память: 64 МБ.

## Входные данные

Строка.

## Выходные данные

Количество различных подстрок.

## Проверка

Сравнивается целочисленный токен ответа; пробельные разделители несущественны.

## Примеры

### Пример 1

Ввод:

```
aaba
```

Вывод:

```
8
```

## Решение

Основной учебный алгоритм сортирует все суффиксы лексикографически.
У суффикса с позиции `i` есть `N−i` непустых префиксов. Из них уже встречались
ровно префиксы до длины LCP с предыдущим суффиксом: все суффиксы с заданным
префиксом идут в сортировке подряд. Поэтому ответ равен `N(N+1)/2` минус
сумма длин LCP соседних суффиксов. Первый суффикс добавляет все свои
префиксы. Каждая различная подстрока учитывается ровно один раз.

Пять файлов `sorting_strings` реализуют этот прямой алгоритм. Сравнение
суффиксов может читать `O(N)` букв, поэтому время в худшем случае —
`O(N² log N)`. C++ string_view, срезы Go и заимствованные срезы Rust требуют
`O(N)` дополнительной памяти. Подстроки Java 8 и срезы bytes в Python
копируются, поэтому память — `O(N²)`. Python ищет LCP бинарным поиском
по равенству префиксов, используя сравнения байтов на уровне C; указанная
оценка времени сохраняется. Все пять вариантов приняты судьёй.

Сохранены и пять исходных суффиксных автоматов. Состояние объединяет
подстроки с одинаковыми позициями окончаний и добавляет
`len(v)−len(link(v))` различных длин. Сумма по некорневым состояниям даёт
ответ за `O(N)` времени и памяти при фиксированных 26 буквах.
Клон копирует переходы и наследует прежнюю суффиксную ссылку.

## Оптимизированные решения

Предпочтительный учебный алгоритм сортирует суффиксы и вычитает соседние наибольшие общие префиксы из числа вхождений подстрок. Компактный C++ сортирует начальные позиции без копирования каждого суффикса, сокращая память, но сохраняя худшую стоимость длинных сравнений. Отдельные варианты суффиксного автомата упаковывают переходы в плоские списки рёбер; клону перед перенаправлениями нужна своя копия списка. Это разные алгоритмы, их имена и измеренные сравнения разделены. Экономия памяти может сопровождаться замедлением, и наоборот.
