# 1558. 周期数

[Timus 1558](https://acm.timus.ru/problem.aspx?space=1&num=1558) · 难度 865 · math

原题出自 2007 年 9 月彼得罗扎沃茨克集训的 Novosibirsk SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

周期数 (a₁…aₖ)b₁…bₘ 向左有无穷多位：块 a₁…aₖ 无限重复，低位末尾是 b₁…bₘ。给定两个周期长度相同
（k ≤ 9）且没有非周期部分的这种数，从低位起逐位相加，照常进位。输出和时周期要最短，在此前提下非周期
部分也要最短。

时间限制：1 秒。内存限制：64 MB。

## 输入

两行，每行一个形如 (a₁…aₖ) 的数。

## 输出

用同样记法表示的和。

## 样例

### 样例 1

输入:

```
(234)
(342)
```

输出:

```
(576)
```

## 解法

把两个周期读成 k 位数 A 和 B，相加得 S = A + B。若 S < 10ᵏ，任何块都不进位，和就是 S 用 k 位写出后
无限重复。否则最低的块等于 S − 10ᵏ 并向上进位；它上面的每个块都收到这个进位，等于 S + 1 − 10ᵏ，并
同样向上进位。所以和就是块 P = S + 1 − 10ᵏ 在唯一的块 S − 10ᵏ 之上无限重复。

剩下的是求最短写法。无穷部分的最短周期，是使 P 由其前 d 位的 k/d 个副本组成的 k 的最小约数 d。然后
从上方截出非周期部分：从 P 的第一个块往下，只要某位等于它上方 d 位处的数字，它就仍属于周期部分。下
面剩下的数字构成最短的非周期部分，周期就从它们正上方读出，因此块可能会转动：999909 + 099000 得到
(100989)09（测试 gen4）。结果已在 1500 对随机数上与 200 位的直接加法对照。

注意事项：

- 非周期部分可能缩短：(111) + (999) 是 (1)0，(5) + (5) 也是 (1)0（测试 09、02）；
- 前导零属于周期，例如 (0100)（测试 10）；
- 全是 9 的和，例如 (454545) + (545454)，根本没有进位，就是 (9)（测试 08）。
