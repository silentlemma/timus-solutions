# 1558. Периодические числа

[Timus 1558](https://acm.timus.ru/problem.aspx?space=1&num=1558) · сложность 865 · math

Оригинальная задача — Novosibirsk SU Contest, Петрозаводские сборы, сентябрь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У периодического числа (a₁…aₖ)b₁…bₘ бесконечно много цифр слева: блок
a₁…aₖ повторяется бесконечно, а в младших разрядах стоит b₁…bₘ. Нужно
сложить два таких числа с периодами одной длины k ≤ 9 и без
непериодической части, поразрядно от младших разрядов с обычными
переносами. Сумму нужно вывести с самым коротким периодом, а среди
таких — с самой короткой непериодической частью.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Две строки, в каждой число вида (a₁…aₖ).

## Выходные данные

Сумма в той же записи.

## Примеры

### Пример 1

Ввод:

```
(234)
(342)
```

Вывод:

```
(576)
```

## Решение

Прочтём оба периода как k-значные числа A и B и сложим их: S = A + B.
Если S < 10ᵏ, ни один блок не даёт переноса, и сумма — это S,
повторённое бесконечно и записанное k цифрами. Иначе младший блок равен
S − 10ᵏ и передаёт перенос дальше; каждый блок выше получает этот
перенос, равен S + 1 − 10ᵏ и тоже передаёт перенос. Значит, сумма — это
блок P = S + 1 − 10ᵏ, бесконечно повторённый над единственным блоком
S − 10ᵏ.

Остаётся найти самую короткую запись. Самый короткий период бесконечной
части — наименьший делитель d числа k, при котором P состоит из k/d копий
своих первых d цифр. Затем непериодическая часть отрезается сверху:
спускаясь от первого блока P, цифра ещё принадлежит периодической части,
пока она равна цифре на d разрядов выше. Оставшиеся внизу цифры образуют
самую короткую непериодическую часть, а период читается сразу над ними,
поэтому блок может повернуться: 999909 + 099000 даёт (100989)09
(тест gen4). Результаты сверены с прямым сложением 200 разрядов на 1500
случайных парах.

Подводные камни:

- непериодическая часть может сократиться: (111) + (999) — это (1)0, и
  (5) + (5) — тоже (1)0 (тесты 09, 02);
- ведущие нули входят в период, как в (0100) (тест 10);
- сумма из одних девяток, например (454545) + (545454), вовсе не даёт
  переноса и равна просто (9) (тест 08).
