# 1548. Сакура и статистика

[Timus 1548](https://acm.timus.ru/problem.aspx?space=1&num=1548) · сложность 10900 · greedy

Автор оригинальной задачи — Сергей Пупырев; XI командный студенческий чемпионат Урала по программированию, Екатеринбург, 21 апреля 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дана чёрно-белая картинка N × M пикселей (1 ≤ N, M ≤ 50), причём чёрные
пиксели каждого столбца образуют не больше одного вертикального отрезка.
Найдите наименьший набор прямоугольников из чёрных пикселей, объединение
которых — ровно множество чёрных пикселей; прямоугольники могут
перекрываться. Подойдёт любой наименьший набор.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем N строк по M символов: `1` — чёрный, `0` — белый.

## Выходные данные

Число прямоугольников, затем каждый прямоугольник — строка и столбец
двух противоположных углов, строки считаются сверху.

## Примеры

### Пример 1

Ввод:

```
3 3
010
111
010
```

Вывод:

```
2
1 2 3 2
2 1 2 3
```

### Пример 2

Ввод:

```
4 5
00000
11100
11010
10000
```

Вывод:

```
4
2 1 2 3
3 1 3 2
2 1 4 1
3 4 3 4
```

## Решение

Раз в каждом столбце не больше одного чёрного отрезка строк, столбцы
промежутка [l, r) все чёрные ровно на тех строках, где пересекаются их
отрезки, а это снова один отрезок строк, возможно пустой. Значит,
прямоугольник можно растянуть на все эти строки, и он задаётся одним
промежутком столбцов.

Каждая строка распадается на максимальные отрезки чёрных пикселей. Набор
промежутков даёт покрытие картинки ровно тогда, когда каждый такой
отрезок строки — объединение выбранных промежутков, лежащих внутри него.
Так что задача — найти наименьшее семейство промежутков, которое так
порождает все отрезки строк, а ответ — его размер.

Такое семейство находится жадно, тем же способом, каким Франзблау и
Клейтман покрывают вертикально выпуклые многоугольники. Начинаем с
различных отрезков строк и идём по правым концам слева направо. Проход
назад с подсчётом выбранных промежутков находит промежуток для удаления.
Удаляем его и сдвигаем вправо левые концы некоторых промежутков,
заканчивающихся раньше, перебирая правые концы по убыванию, чтобы все
отрезки строк по-прежнему порождались. Повторяем проход для того же
правого конца, пока больше ничего нельзя удалить; `O(N·M + M⁴)`,
немного при M ≤ 50.

Подводные камни:

- прямоугольники могут перекрываться, и лучшим ответам это нужно: крест
  из первого примера и два квадрата теста 05 укладываются в два
  прямоугольника, а любое разбиение требует трёх;
- в строке может быть несколько отрезков, и каждый порождается
  отдельно: в строке 3 второго примера это столбцы 1–2 и столбец 4;
- белой картинке прямоугольники не нужны (тест 03).

Количества сравнивались с полным перебором наборов максимальных
прямоугольников на 400 случайных маленьких картинках и с независимой
принятой реализацией на 300 картинках до 50 × 50. Тесты проверяются
чекером, который принимает любое наименьшее покрытие.
