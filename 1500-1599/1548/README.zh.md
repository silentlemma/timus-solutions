# 1548. 樱花与统计

[Timus 1548](https://acm.timus.ru/problem.aspx?space=1&num=1548) · 难度 10900 · greedy

原题作者 Sergey Pupyrev，出自 2007 年 4 月 21 日在叶卡捷琳堡举行的第十一届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定一幅 N × M 像素的黑白图（1 ≤ N, M ≤ 50），每一列的黑色像素至多构成一段竖直连续段。求数量最少的一组由黑色像素组成的矩形，
使它们的并恰好是全部黑色像素；矩形可以重叠。任意一组最少的都可以。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 M，然后是 N 行，每行 M 个字符：`1` 表示黑色，`0` 表示白色。

## 输出

矩形的数量，然后每个矩形给出两个对角的行号和列号，行从上往下数。

## 样例

### 样例 1

输入:

```
3 3
010
111
010
```

输出:

```
2
1 2 3 2
2 1 2 3
```

### 样例 2

输入:

```
4 5
00000
11100
11010
10000
```

输出:

```
4
2 1 2 3
3 1 3 2
2 1 4 1
3 4 3 4
```

## 解法

由于每一列至多只在一段连续的行上是黑的，区间 [l, r) 中的各列同时为黑的行恰好是它们各自行段的交，仍是一段连续的行（可能为空）。
所以矩形总可以拉伸到这些行上，一个矩形只由它的列区间决定。

每一行分成若干极大的黑色段。一组区间能给出图的覆盖，当且仅当每个这样的行段都是落在它内部的所选区间之并。
于是问题变成：找出以这种方式生成所有行段的最小区间族，答案就是它的大小。

这样的区间族可以贪心求出，做法与 Franzblau 和 Kleitman 覆盖竖直凸多边形的方法相同。从不同的行段出发，按右端点从左到右处理。
从右端点往回扫描、统计所选区间，找到一个可删除的区间。将它删除，再按右端点递减的顺序，把一些右端点更早的区间的左端点向右移动，使所有行段仍被生成。
对同一个右端点重复扫描，直到没有区间可删；`O(N·M + M⁴)`，在 M ≤ 50 时很小。

注意事项：

- 矩形可以重叠，最优答案也需要重叠：第一个样例的十字和测试 05 的两个正方形各用两个矩形，而任何不重叠的划分都需要三个；
- 一行可能有好几段，每段各自被生成：第二个样例的第 3 行有第 1–2 列和第 4 列两段；
- 全白的图不需要矩形（测试 03）。

数量已在 400 张随机小图上与对极大矩形集合的穷举搜索对比，并在 300 张至多 50 × 50 的图上与一份独立的已通过实现对比。
测试由检查器评判，接受任意一组最少的覆盖。
