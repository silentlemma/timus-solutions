# 1591. 抽象思维

[Timus 1591](https://acm.timus.ru/problem.aspx?space=1&num=1591) · 难度 1050 · math

原题作者 Denis Musin，出自 2007 年 10 月 27 日在叶卡捷琳堡举行的 ACM ICPC 2007–2008 NEERC 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

圆上等距地放着 n 个点（3 ≤ n ≤ 2000），每两点之间连一条弦。有趣的三角形由三条两两相交的弦构成，且至少有一个交点在圆内而不在圆上。
求有趣三角形的个数。

时间限制：1 秒。内存限制：64 MB。

## 输入

n。

## 输出

有趣三角形的个数。

## 样例

### 样例 1

输入:

```
4
```

输出:

```
4
```

### 样例 2

输入:

```
5
```

输出:

```
25
```

## 解法

三角形由其弦所用的端点集合唯一确定，因此按这个集合计数。两条弦在圆内相交当且仅当它们的端点在圆上交替出现，这只取决于点的顺序。

- 三个顶点都在圆内：三条弦有六个不同端点，而六个点的所有配对中只有六边形的三条长对角线两两相交；每 6 个点一个三角形。
- 两个顶点在圆内：两条弦从同一点 P 出发，第三条弦与两者都相交，所以它的两个端点分别在这对弦的两侧；
  5 个点时三角形由 P 的选择决定，每 5 个点五个。
- 一个顶点在圆内：另外两个顶点在圆上，所以一条弦是四边形的边，另两条是它的对角线，两者相交；每条边一个三角形，每 4 个点四个。

答案为 C(n, 6) + 5·C(n, 5) + 4·C(n, 4)，复杂度 `O(1)`。对 n ≤ 12，已与仅凭端点顺序枚举所有弦的三元组的做法对照。

注意事项：

- 正多边形中可能有多条弦经过同一点，例如六边形的三条长对角线都过圆心；答案仍把这样的三元组算作三角形，公式也是如此；
- 答案可达约 9·10¹⁶，需要 64 位整数；C(n, k) 用逐步相乘并整除的方式计算，中间值不超过 C(n, k)·n。
