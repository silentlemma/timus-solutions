# 1591. Абстрактное мышление

[Timus 1591](https://acm.timus.ru/problem.aspx?space=1&num=1591) · сложность 1050 · math

Автор оригинальной задачи — Денис Мусин; ACM ICPC 2007–2008, NEERC, Восточный подрегион, Екатеринбург, 27 октября 2007 года.

## Задача

На окружности на равных расстояниях стоят n точек (3 ≤ n ≤ 2000), и
каждые две соединены хордой. Интересный треугольник образуют три хорды,
попарно пересекающиеся, причём хотя бы одна точка пересечения лежит
внутри окружности, а не на ней. Нужно посчитать интересные
треугольники.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n.

## Выходные данные

Количество интересных треугольников.

## Примеры

### Пример 1

Ввод:

```
4
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
5
```

Вывод:

```
25
```

## Решение

Треугольник определяется множеством концов своих хорд, поэтому считаем
по этому множеству. Две хорды пересекаются внутри окружности ровно
тогда, когда их концы чередуются по окружности, а это зависит только от
порядка точек.

- Три вершины внутри: у хорд шесть разных концов, и из разбиений шести
  точек на пары только три длинные диагонали шестиугольника попарно
  пересекаются; один треугольник на 6 точек.
- Две вершины внутри: две хорды выходят из одной точки P, а третья
  пересекает обе, так что её концы лежат по разные стороны от пары; на
  5 точках треугольник задаётся выбором P — пять на 5 точек.
- Одна вершина внутри: две вершины на окружности, значит, одна хорда —
  сторона четырёхугольника, а две другие — его диагонали, которые
  пересекаются; один треугольник на сторону, четыре на 4 точки.

Ответ — C(n, 6) + 5·C(n, 5) + 4·C(n, 4), за `O(1)`. Для n ≤ 12 он сверен
с перебором всех троек хорд по одному лишь порядку их концов.

Подводные камни:

- в правильном многоугольнике через одну точку может проходить
  несколько хорд, например три длинные диагонали шестиугольника через
  центр; ответ всё равно считает такую тройку треугольником, как и
  формула;
- ответ доходит примерно до 9·10¹⁶, так что нужны 64-битные числа, а
  C(n, k) строится как произведение, делимое на каждом шаге, которое
  остаётся меньше C(n, k)·n.
