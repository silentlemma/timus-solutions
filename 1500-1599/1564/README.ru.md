## Задача

Петя поднимается по лестнице небоскрёба с 1-го этажа и считает цифры 1 в
номерах этажей по пути. По числу k (1 ≤ k ≤ 10¹⁸) нужно вывести этаж,
на котором была сосчитана последняя из этих единиц, или `Petr lies`,
если ни один этаж не даёт ровно k единиц.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число k.

## Выходные данные

Номер этажа или `Petr lies`.

## Примеры

### Пример 1

Ввод:

```
4
```

Вывод:

```
11
```

### Пример 2

Ввод:

```
3
```

Вывод:

```
Petr lies
```

## Решение

Пусть f(x) — число единиц в 1, …, x. Оно считается по разрядам: в разряде
p (1, 10, 100, …) числа до x составляют ⌊x / 10p⌋ полных блоков по 10p
чисел, в каждом из которых в этом разряде p единиц, а последний,
неполный блок добавляет p единиц, если его цифра в этом разряде больше 1,
остаток x ниже разряда плюс 1, если цифра равна 1, и ничего, если она 0.

f только растёт, поэтому этаж, на котором сосчитана k-я единица, — это
первое x с f(x) ≥ k, которое находится двоичным поиском по 1 … 10¹⁸
(f(10¹⁸) — около 1.8·10¹⁸). Если f(x) больше k, этаж x принёс сразу
несколько единиц, и числа k при счёте не было, так что Петя лжёт. Поиск
занимает около 60 шагов по O(log x). Результаты сверены с проходом по
этажам по одному для всех k до 25000.

Подводные камни:

- этаж вроде 11 добавляет сразу две единицы, так что некоторые числа
  никогда не встречаются (второй пример);
- ответ для k = 10¹⁸ — около 5.2·10¹⁷, а разряды доходят до 10¹⁷, так
  что решения с целыми фиксированной ширины требуют 64 бит (тест 05);
- число на одну меньше суммы на этаже из одних единиц — ложь (тест 08).
