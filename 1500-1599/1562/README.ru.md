# 1562. Ананас

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Ананас — вытянутый эллипсоид вращения шириной a и высотой b
(1 ≤ a < b ≤ 100, в сантиметрах). Его кладут на бок и режут поперёк оси
на n кусков одинаковой толщины (1 ≤ n ≤ 100). Кубический сантиметр
весит один грамм. Нужно вывести вес каждого куска в порядке отрезания с
точностью до микрограмма.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

a, b и n в одной строке; a и b могут быть дробными.

## Выходные данные

n строк — веса в граммах с шестью знаками после точки.

## Примеры

### Пример 1

Ввод:

```
15 20.5 8
```

Вывод:

```
103.773800
273.585474
386.793256
443.397147
443.397147
386.793256
273.585474
103.773800
```

## Решение

Направим ось по z с серединой в 0. Сечение на высоте z — круг радиуса
(a/2)·√(1 − (2z/b)²), так что его площадь равна π·a²/4·(1 − 4z²/b²).
Её интеграл от 0 до z,

V(z) = π·a²/4·(z − 4z³/(3b²)),

даёт кусок между разрезами z₁ и z₂ как V(z₂) − V(z₁), где разрезы стоят
в −b/2 + b·i/n. Весь ананас весит π·a²·b/6 — сумму всех кусков. `O(n)`.

Подводные камни:

- a — полная ширина, а не радиус;
- размеры могут быть дробными (тест 05 и пример);
- при совпадении округлённых размеров генератор должен сохранять 1 ≤ a < b
  (gen1/gen4; регрессионный seed 1318341 в режиме 1);
- крайние куски длинного тонкого ананаса весят лишь сотые доли грамма,
  и для них тоже нужны шесть знаков (тест 04).

## Оптимизированные решения

Версия Go нормирует вертикальную координату к отрезку [−1, 1]. Для ломтика с серединой m и половиной ширины h средний квадрат координаты равен m² + h²/3. Вычитаем это среднее из единицы и умножаем на толщину ломтика и площадь центрального круга. Для всех ломтиков используется один буфер вывода. Вес округляется до целых микрограммов и печатается с шестью десятичными знаками. syscall.Read и syscall.Write используют стандартные дескрипторы, повторяют прерванные вызовы и дописывают частичные записи.

Принятые базовые реализации [1562_geometry.cpp](1562_geometry.cpp), [1562_geometry.java](1562_geometry.java), [1562_geometry.py](1562_geometry.py), [1562_geometry.rs](1562_geometry.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
