# 1562. 转基因菠萝

[Timus 1562](https://acm.timus.ru/problem.aspx?space=1&num=1562) · 难度 402 · geometry

原题作者 Denis Musin，出自 2007 年 10 月 6 日第十二届乌拉尔国立大学程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

菠萝是宽为 a、高为 b 的长形旋转椭球（1 ≤ a < b ≤ 100，单位厘米）。把它横放，沿垂直于轴的方向切成 n
块等厚的片（1 ≤ n ≤ 100）。每立方厘米重一克。按切下的顺序输出每块的重量，精确到微克。

时间限制：1 秒。内存限制：64 MB。

## 输入

一行中的 a、b 和 n；a 和 b 可以是小数。

## 输出

n 行，以克为单位的重量，小数点后六位。

## 样例

### 样例 1

输入:

```
15 20.5 8
```

输出:

```
103.773800
273.585474
386.793256
443.397147
443.397147
386.793256
273.585474
103.773800
```

## 解法

让轴沿 z 方向，中点在 0。高度 z 处的截面是半径为 (a/2)·√(1 − (2z/b)²) 的圆，面积为
π·a²/4·(1 − 4z²/b²)。它从 0 到 z 的积分

V(z) = π·a²/4·(z − 4z³/(3b²))

给出切口 z₁ 与 z₂ 之间的一块为 V(z₂) − V(z₁)，切口位于 −b/2 + b·i/n。整个菠萝重 π·a²·b/6，即所有块
之和。`O(n)`。

注意事项：

- a 是整个宽度，而不是半径；
- 尺寸可以是小数（测试 05 和样例）；
- 生成的尺寸在舍入后相等时，调整后仍须满足 1 ≤ a < b（gen1/gen4；模式 1 的回归种子 1318341）；
- 细长菠萝两端的块只有百分之几克重，同样需要六位小数（测试 04）。
