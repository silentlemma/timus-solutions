# 1562. 转基因菠萝

[Timus 1562](https://acm.timus.ru/problem.aspx?space=1&num=1562) · 难度 402 · geometry

原题作者 Denis Musin，出自 2007 年 10 月 6 日第十二届乌拉尔国立大学程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

菠萝是宽为 a、高为 b 的长形旋转椭球（1 ≤ a < b ≤ 100，单位厘米）。把它横放，沿垂直于轴的方向切成 n
块等厚的片（1 ≤ n ≤ 100）。每立方厘米重一克。按切下的顺序输出每块的重量，精确到微克。

时间限制：1 秒。内存限制：64 MB。

## 输入

一行中的 a、b 和 n；a 和 b 可以是小数。

## 输出

n 行，以克为单位的重量，小数点后六位。

## 评测方式

仓库测试按 |实际值-参考值| <= 0.000001·max(1,|参考值|) 比较数值记号，拒绝非有限值，并精确比较非数值记号。

## 样例

### 样例 1

输入:

```
15 20.5 8
```

输出:

```
103.773800
273.585474
386.793256
443.397147
443.397147
386.793256
273.585474
103.773800
```

## 解法

让轴沿 z 方向，中点在 0。高度 z 处的截面是半径为 (a/2)·√(1 − (2z/b)²) 的圆，面积为
π·a²/4·(1 − 4z²/b²)。它从 0 到 z 的积分

V(z) = π·a²/4·(z − 4z³/(3b²))

给出切口 z₁ 与 z₂ 之间的一块为 V(z₂) − V(z₁)，切口位于 −b/2 + b·i/n。整个菠萝重 π·a²·b/6，即所有块
之和。`O(n)`。

注意事项：

- a 是整个宽度，而不是半径；
- 尺寸可以是小数（测试 05 和样例）；
- 生成的尺寸在舍入后相等时，调整后仍须满足 1 ≤ a < b（gen1/gen4；模式 1 的回归种子 1318341）；
- 细长菠萝两端的块只有百分之几克重，同样需要六位小数（测试 04）。

## 优化解法

Go 版本将竖直坐标归一化到 [−1, 1]。若一片的中点为 m、半宽为 h，坐标平方的平均值为 m² + h²/3。用一减去该平均值，再乘以厚度和中央圆盘面积，即可直接得到重量。重量四舍五入到整数微克，再用固定缓冲区输出六位小数。syscall.Read 和 syscall.Write 使用标准句柄，重试中断调用并完成部分写入。

已通过评测的基础实现 [1562_geometry.cpp](1562_geometry.cpp), [1562_geometry.java](1562_geometry.java), [1562_geometry.py](1562_geometry.py), [1562_geometry.rs](1562_geometry.rs) 也满足快速版本的要求：在保存的比较快照中，时间和内存均符合前 15% 或前十名的排名收录规则。直接复用这些源文件，不创建相同副本。星号标记尚未达到该语言目标排名的版本。
