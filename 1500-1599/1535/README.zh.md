# 1535. 霍比特人，或去而复返

[Timus 1535](https://acm.timus.ru/problem.aspx?space=1&num=1535) · 难度 496 · constructive

原题作者 Alexander Ipatov，出自 2007 年 3 月 3 日第八届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

比尔博从城市 1 出发，2 … N 号城市各访问一次，再回到城市 1（2 ≤ N ≤ 50000）。从城市 Q
进入城市 P 要付 P·Q 枚金币。输出一个总花费最小的访问顺序和一个总花费最大的访问顺序。

时间限制：1 秒。内存限制：64 MB。

## 输入

N。

## 输出

两行，每行 N 个数并以 1 开头：最便宜的顺序和最贵的顺序。任何最优顺序都可以。

## 样例

### 样例 1

输入:

```
4
```

输出:

```
1 4 2 3
1 3 4 2
```

## 解法

花费是经过 1 … N 所有数的环上相邻两数乘积之和，所以两行都是环形排列。

最贵的排列让每个数都挨着大小最接近的两个数：1, 3, 5, … 一直到 N，再沿偶数递减回到 2。
这是使这种环形和最大的经典"管风琴"排列。

最便宜的排列让大数与小数相邻。从 N 开始读这个环，一侧是 2, N − 2, 4, N − 4, 6, …，另一
侧是 1, N − 1, 3, N − 3, 5, …；第 k 步两侧分别取 k + 1 和 k（k 为奇数）或 N − k 和
N − k + 1（k 为偶数），直到某一对会重复使用某个数。若剩下一个数，就放在两侧相遇之处。对
N ≤ 10 的穷举表明，在不计翻转的意义下这是唯一的最便宜环，评测系统对所有 N 都接受它；我们
没有证明。把环转到以 1 开头就是第一行。`O(N)`。

注意事项：

- 简单交替 1, N, 2, N − 1, … 并非最优：N = 5 时它花费 38，而 1, 5, 2, 3, 4 花费 37（测试 04）；
- 两侧相遇时可能剩一个城市（测试 05），也可能不剩（测试 06）；
- 两行都必须以城市 1 开头（所有测试）。
