# 1535. Хоббит, или Туда и обратно

[Timus 1535](https://acm.timus.ru/problem.aspx?space=1&num=1535) · сложность 497 · constructive

Автор оригинальной задачи — Александр Ипатов; Восьмое открытое личное первенство УрГУ, 3 марта 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Бильбо выходит из города 1, по разу посещает каждый из городов 2 … N и
возвращается в город 1 (2 ≤ N ≤ 50000). Вход в город P из города Q
стоит P·Q золотых. Нужно вывести порядок посещения с наименьшей
суммарной платой и порядок с наибольшей.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

Две строки по N чисел, начиная с 1: самый дешёвый порядок и самый
дорогой. Подходят любые оптимальные порядки.

## Примеры

### Пример 1

Ввод:

```
4
```

Вывод:

```
1 4 2 3
1 3 4 2
```

## Решение

Плата — это сумма произведений соседей по циклу через все числа 1 … N,
так что обе строки — расстановки по кругу.

Самая дорогая ставит рядом близкие по величине числа:
1, 3, 5, … по возрастанию, затем чётные по убыванию до 2. Это классическая
расстановка «органные трубы», которая максимизирует такую сумму по кругу.

Самая дешёвая соединяет большие числа с маленькими. Если читать цикл от
N, одна сторона идёт 2, N − 2, 4, N − 4, 6, …, а другая 1, N − 1, 3,
N − 3, 5, …; на шаге k стороны берут k + 1 и k при нечётном k и N − k и
N − k + 1 при чётном, пока пара не повторит число. Если одно число
осталось, оно стоит там, где стороны встречаются. Полный перебор при
N ≤ 10 показывает, что это единственный самый дешёвый цикл с точностью
до отражения, и судья принимает его при всех N; доказательства у нас
нет. Поворот цикла к началу в 1 даёт первую строку. `O(N)`.

Подводные камни:

- простое чередование 1, N, 2, N − 1, … не оптимально: при N = 5 оно
  стоит 38, а 1, 5, 2, 3, 4 стоит 37 (тест 04);
- стороны могут встретиться с одним оставшимся городом (тест 05) или
  без него (тест 06);
- обе строки должны начинаться с города 1 (все тесты).
