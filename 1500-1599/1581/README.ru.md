## Задача

Последовательность из N ≤ 1000 чисел от 1 до 10 диктуется сериями: для
каждой серии равных чисел сначала говорится, сколько их, а затем какое
это число. Нужно вывести продиктованные числа.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N чисел.

## Выходные данные

Длины и значения серий по порядку в одной строке.

## Примеры

### Пример 1

Ввод:

```
8
1 1 2 3 3 3 10 10
```

Вывод:

```
2 1 1 2 3 3 2 10
```

## Решение

Пройдём по числам и разрежем их на максимальные серии равных значений;
для каждой серии выведем её длину и затем значение. `O(N)`.

Подводные камни:

- серия может быть всей последовательностью длиной до 1000 (тест 05);
- равные числа, стоящие не рядом, образуют разные серии (тест 04);
- 10 — одно число, так что читать нужно числа, а не символы.
