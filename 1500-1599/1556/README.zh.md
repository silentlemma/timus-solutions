# 1556. 秘密奶牛关卡中的多重射击

[Timus 1556](https://acm.timus.ru/problem.aspx?space=1&num=1556) · 难度 8030 · geometry

原题出自 2007 年 9 月彼得罗扎沃茨克集训的 Novosibirsk SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

Vasya 站在平面上的一点，周围有 N 头奶牛（N ≤ 50000），每头是半径同为 R（0.4 ≤ R ≤ 2）
的圆盘，它们既不与 Vasya 相交或接触，也互不相交或接触。Vasya 选一个主方向，同时射出 K 支箭（2 ≤ K ≤ 16）；
第 i 支箭（从 0 开始）沿与主方向成 Aᵢ = arctan(i/(K − 1) − 1/2) 角的射线飞行。射线穿过或
碰到奶牛即为命中。每次命中后，箭以 P %（0 ≤ P ≤ 100）的概率继续飞行，否则停下；第五次命中后
必定停下。求使命中总数期望最大的主方向。

时间限制：5 秒。内存限制：64 MB。

## 输入

N、K、P 和 R，然后是 Vasya 的坐标，再是 N 个奶牛圆心的坐标；所有坐标都是绝对值不超过 25000
的实数。

## 输出

一行 `The best shot at (x;y) gives Vasya E average hits.`，其中 (x, y) 是主方向的单位向量，
至少 10 位小数，E 是保留 4 位小数的期望。

## 样例

### 样例 1

输入:

```
3 5 40 1.0
-2.0 1
0 2.0
3 2.0
4 -3
```

输出:

```
The best shot at (0.8944271910;0.4472135955) gives Vasya 5.8000 average hits.
```

## 解法

把 Vasya 移到原点。角度为 θ 的射线碰到圆心距离为 d、方向为 c 的奶牛，当且仅当 θ 与 c 相差不
超过 asin(R/d)（含端点）。主方向为 φ 时第 i 支箭沿 φ + Aᵢ 飞行，所以当 φ 落在把同一区间往回
转 Aᵢ 后的区间里时，它碰到这头奶牛。每次命中继续飞行的概率相同，所以只有射线上奶牛的个数 m
有关：m = 0 时这支箭得分为 0，否则为 1 + q + … + q^(min(m, 5) − 1)，其中 q = P/100。

各箭得分之和只在这些区间的 2NK 个端点处变化。端点只排序一次；每支箭看到的是同一个有序表的循环
移位，因此绕圆一周把 K 个表合并即可（Python 用堆，其他语言比较 K 个表头），起点处先统计已包含
φ = 0 的区间。每个事件角是一个候选，此时进入的区间已计入，离开的区间仍计入；事件之间的每个开区
间也是候选，取更新后的计数。相等时取开区间的中点，输出它比输出切线方向更稳妥。距首个端点不超过 10⁻¹² 的端点算作同一事件。

得分以 1/100⁴ 为单位用整数保存，比较是精确的。
检查器接受任何得分与最佳期望相差不超过 10⁻⁴ 的方向；结果已与一个独立程序对照。

注意事项：

- Aᵢ 的公式在原题中是一张图片，样例验证了 arctan(i/(K − 1) − 1/2)；这些偏移是对称的，所以朝
  哪一侧量都无所谓；
- 碰到也算命中，所以最佳射击可能只是一个切线方向：样例中 5.8 只在那里取到，两侧分别是 4.4 和
  4.8；
- x 轴方向附近的区间会越过 2π（测试 02、06）；
- 不管射线上有多少奶牛，一支箭最多命中五次（测试 03）；P = 0 时每支箭最多得 1（测试 04）；
- 正方形远角处的奶牛在角度上只有约 10⁻⁵ 宽（测试 05）。
