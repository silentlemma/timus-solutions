# 1556. Мультивыстрел на секретном коровьем уровне

[Timus 1556](https://acm.timus.ru/problem.aspx?space=1&num=1556) · сложность 8030 · geometry

Оригинальная задача — Novosibirsk SU Contest, Петрозаводские сборы, сентябрь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Вася стоит в точке плоскости среди N коров (N ≤ 50000) — кругов одного
радиуса R (0.4 ≤ R ≤ 2), которые не пересекаются и не касаются ни Васи,
ни друг друга.
Вася выбирает основное направление и выпускает сразу K стрел
(2 ≤ K ≤ 16); стрела i (с нуля) летит по лучу под углом
Aᵢ = arctg(i/(K − 1) − 1/2) к основному направлению. Луч, который
пересекает корову или касается её, попадает в неё. После каждого
попадания стрела летит дальше с вероятностью P % (0 ≤ P ≤ 100), иначе
останавливается, а после пятого попадания останавливается наверняка.
Нужно найти основное направление с наибольшим математическим ожиданием
общего числа попаданий.

Ограничение времени: 5 секунд. Ограничение памяти: 64 МБ.

## Входные данные

N, K, P и R, затем координаты Васи, затем координаты N центров коров;
все координаты — вещественные числа, по модулю не больше 25000.

## Выходные данные

Строка `The best shot at (x;y) gives Vasya E average hits.`, где (x, y) —
основное направление в виде единичного вектора (не менее 10 знаков после
запятой), а E — ожидание с 4 знаками после запятой.

## Примеры

### Пример 1

Ввод:

```
3 5 40 1.0
-2.0 1
0 2.0
3 2.0
4 -3
```

Вывод:

```
The best shot at (0.8944271910;0.4472135955) gives Vasya 5.8000 average hits.
```

## Решение

Перенесём Васю в начало координат. Луч под углом θ задевает корову с
центром на расстоянии d в направлении c ровно тогда, когда θ отстоит от c
не больше чем на asin(R/d), концы включительно. Стрела i летит под углом
φ + Aᵢ при основном направлении φ, поэтому задевает корову, когда φ лежит
в том же интервале, повёрнутом назад на Aᵢ. Шанс пролететь дальше у всех
попаданий одинаковый, поэтому важно только число m коров на луче: стрела
даёт 0 при m = 0, иначе 1 + q + … + q^(min(m, 5) − 1), где q = P/100.

Сумма по стрелам меняется только в 2NK концах этих интервалов. Концы
сортируются один раз; каждая стрела видит тот же отсортированный список,
только сдвинутый по кругу, поэтому K списков сливаются за один обход
окружности (в Python — кучей, в остальных языках — сравнением K голов),
начиная с интервалов, которые уже содержат φ = 0. Каждый угол события —
кандидат, где входящие интервалы уже учтены, а выходящие ещё учтены; и
каждый открытый промежуток между событиями — кандидат со счётчиками после
обновления. При равенстве выбирается середина промежутка: её печатать
надёжнее, чем касательное направление. Событие объединяет концы в пределах 10⁻¹² от первого.

Суммы хранятся целыми числами в единицах 1/100⁴, так что сравнения
точные.
Чекер принимает любое направление, дающее лучшее ожидание с точностью
10⁻⁴; результаты сверены с независимой программой.

Подводные камни:

- формула для Aᵢ в исходном условии дана картинкой, и пример
  подтверждает arctg(i/(K − 1) − 1/2); сдвиги симметричны, поэтому
  неважно, в какую сторону их отсчитывать;
- касание считается, поэтому лучший выстрел может быть единственным
  касательным направлением: в примере 5.8 достигается только там, а по
  обе стороны получается 4.4 и 4.8;
- интервалы около направления оси x переходят через 2π (тесты 02, 06);
- стрела набирает не больше пяти попаданий, сколько бы коров ни лежало на
  луче (тест 03), а при P = 0 каждая стрела даёт не больше 1 (тест 04);
- корова в дальнем углу квадрата занимает по углу всего около 10⁻⁵
  (тест 05).
