# 1545. Иероглифы

## Задача

В справочнике N ≤ 1000 иероглифов, каждый записан двумя строчными
буквами. По введённой букве нужно вывести иероглифы, которые с неё
начинаются.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, N двухбуквенных записей, затем буква.

## Выходные данные

Подходящие записи, по одной в строке, в любом порядке; ничего, если их
нет.

## Примеры

### Пример 1

Ввод:

```
6
na
no
ni
ki
ka
ku
k
```

Вывод:

```
ka
ki
ku
```

## Решение

Сравним первую букву каждой записи с введённой и выведем совпадения в
порядке справочника. `O(N)`.

Подводные камни:

- если совпадений нет, вывод пуст (тесты 02, 05);
- запись, встречающаяся дважды, выводится дважды (тест 03);
- буква должна стоять первой: совпадение на втором месте не считается
  (тест 05).
