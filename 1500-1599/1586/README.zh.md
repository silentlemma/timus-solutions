# 1586. 三素数

[Timus 1586](https://acm.timus.ru/problem.aspx?space=1&num=1586) · 难度 144 · dp

原题作者 Denis Musin，出自 2007 年 10 月 27 日在叶卡捷琳堡举行的 ACM ICPC 2007–2008 NEERC 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

若一个数中任意三个相邻数字都构成三位素数，就称它为三素数。求 n 位三素数（3 ≤ n ≤ 10000）的个数，对 10⁹ + 9 取模。

时间限制：2 秒。内存限制：64 MB。

## 输入

n。

## 输出

个数对 10⁹ + 9 取模。

## 样例

### 样例 1

输入:

```
4
```

输出:

```
204
```

## 解法

下一位数字能否接上只取决于最后两位，所以按最后两位计数。n = 3 时每个三位素数按其最后两位计一次。之后每一位数字 c
能接在以 ab 结尾的数后面，当且仅当 abc 是三位素数，新数以 bc 结尾。143 个三位素数给出每位 143 种转移：
`O(143·n)`。结果已与逐个检验所有不超过六位的数的做法对照。

注意事项：

- 三位素数不能以 0 开头，所以任何窗口都不能以 0 开头；直接按素数计数就自然处理了这一点；
- 个数增长很快，要对 10⁹ + 9 取模，而不是 10⁹ + 7。

## 优化解法

优化的 C++ 解法把每个素数转移的起止两位数一次性存入固定数组，而不是每一位都重新
计算 `p / 10` 和 `p % 100`，并反复使用两个固定的计数数组，而不是每一位都新建
`vector`。计数用 `int` 而不是 `long long`，每次加法后用一次条件减法代替 `%` 取
模：两个小于 10⁹ + 9 的余数之和小于 2³¹：{1586_dp_optimized.cpp}。

优化的 Go 解法把每个素数转移的起止两位数一次性存入固定数组，并反复使用两个固定的
计数数组，而不是每一位都新建切片；每次加法后用一次条件减法代替 `%` 取模：
{1586_dp_optimized.go}。

优化的 Java 解法用 `System.in.read` 逐字节读入 `n`，而不是用 `Scanner`；把每个素
数转移的起止两位数存入 `int` 数组，而不是遍历装箱 `Integer` 素数的列表；并交换两
个计数数组，而不是每一位都新建数组。计数用 `int` 而不是 `long`，每次加法后用一次
条件减法代替 `%` 取模：两个小于 10⁹ + 9 的余数之和小于 2³¹：
{1586_dp_optimized.java}。

优化的 Python 解法在 `n = 3` 时直接输出三位素数的个数 143；`n ≥ 4` 时，它把转
移矩阵求幂，而不是逐位走完全部 `n` 位。从第四位起，最后两位数字都是某个三位素数
的末位，所以只能是 1、3、7 或 9，只剩 16 种两位组合；一个 16 × 16 矩阵记录从一种
组合到另一种组合的素数个数。四位数的计数乘以该矩阵的 `n − 4` 次幂（用反复平方计
算，`n ≤ 10000` 时至多平方 14 次）即得答案，总共 `O(16³ log n)`：
{1586_dp_matrix.py}。
