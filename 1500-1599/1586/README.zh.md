# 1586. 三素数

[Timus 1586](https://acm.timus.ru/problem.aspx?space=1&num=1586) · 难度 144 · dp

原题作者 Denis Musin，出自 2007 年 10 月 27 日在叶卡捷琳堡举行的 ACM ICPC 2007–2008 NEERC 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

若一个数中任意三个相邻数字都构成三位素数，就称它为三素数。求 n 位三素数（3 ≤ n ≤ 10000）的个数，对 10⁹ + 9 取模。

时间限制：2 秒。内存限制：64 MB。

## 输入

n。

## 输出

个数对 10⁹ + 9 取模。

## 样例

### 样例 1

输入:

```
4
```

输出:

```
204
```

## 解法

下一位数字能否接上只取决于最后两位，所以按最后两位计数。n = 3 时每个三位素数按其最后两位计一次。之后每一位数字 c
能接在以 ab 结尾的数后面，当且仅当 abc 是三位素数，新数以 bc 结尾。143 个三位素数给出每位 143 种转移：
`O(143·n)`。结果已与逐个检验所有不超过六位的数的做法对照。

注意事项：

- 三位素数不能以 0 开头，所以任何窗口都不能以 0 开头；直接按素数计数就自然处理了这一点；
- 个数增长很快，要对 10⁹ + 9 取模，而不是 10⁹ + 7。
