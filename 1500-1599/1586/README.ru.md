# 1586. Трипростые числа

[Timus 1586](https://acm.timus.ru/problem.aspx?space=1&num=1586) · сложность 144 · dp

Автор оригинальной задачи — Денис Мусин; ACM ICPC 2007–2008, NEERC, Восточный подрегион, Екатеринбург, 27 октября 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Число трипростое, если любые три подряд идущие цифры образуют
трёхзначное простое число. Нужно посчитать n-значные трипростые числа
(3 ≤ n ≤ 10000) по модулю 10⁹ + 9.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

n.

## Выходные данные

Количество по модулю 10⁹ + 9.

## Примеры

### Пример 1

Ввод:

```
4
```

Вывод:

```
204
```

## Решение

Может ли идти следующая цифра, зависит только от двух последних цифр,
так что числа считаются по ним. При n = 3 каждое трёхзначное простое
считается один раз под своими двумя последними цифрами. Каждая следующая
цифра c приписывается к числу, оканчивающемуся на ab, ровно тогда, когда
abc — трёхзначное простое, и новое число оканчивается на bc. 143
трёхзначных простых дают 143 перехода на цифру: `O(143·n)`. Результаты
сверены с проверкой всех чисел не длиннее шести цифр.

Подводные камни:

- трёхзначное простое не может начинаться с 0, так что ни одно окно не
  может начинаться с нулевой цифры; подсчёт по самим простым это
  учитывает;
- количество быстро растёт и берётся по модулю 10⁹ + 9, а не 10⁹ + 7.
