# 1575. Екатеринбургское метро 2

[Timus 1575](https://acm.timus.ru/problem.aspx?space=1&num=1575) · сложность 861 · bfs

Автор оригинальной задачи — Александр Ипатов; XIV открытое командное первенство школьников Свердловской области по программированию, октябрь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В условии дана схема метро будущего: 70 станций на 8 линиях, одна из
которых кольцевая, с пересадками между 2–4 линиями на некоторых станциях.
Перегон между соседними станциями занимает минуту, пересадки и ожидание
времени не занимают. Нужно ответить на до 4900 вопросов: наименьшее число
минут от одной станции до другой.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число вопросов, затем по два названия станций в строке.

## Выходные данные

По числу минут на вопрос.

## Примеры

### Пример 1

Ввод:

```
6
Prospekt_Kosmonavtov Geologicheskaya
Shevchenko Vilonovskaya
Koltsovo Zelyony_ostrov
Teatralnaya Kamennye_palatki
China_town Italyanskaya
1905_year_square 1905_year_square
```

Вывод:

```
6
3
11
3
9
0
```

## Решение

Вся настоящая работа — переписать схему с картинки. Каждая линия
записывается как её станции по порядку, а кольцевая к тому же соединяет
последнюю станцию с первой. Пересадочная станция нарисована двумя или
больше кружками рядом, иногда с коротким куском линии между ними, но это
одна станция: восемь линий называют ровно 70 станций, так что каждый
кружок принадлежит одной из названных. Например, Teatralnaya соединяет
голубую, синюю и жёлтую линии, а 1905_year_square — четыре линии.

Раз пересадки бесплатны, ответ — число перегонов на кратчайшем пути в
графе станций, который находит поиск в ширину из каждой станции по одному
разу. `O(70 · рёбер + вопросов)`. Схема переписана с картинки независимо,
и ответы для всех 4900 упорядоченных пар совпадают с независимой
программой.

Подводные камни:

- две станции на картинке записаны иначе, чем во входе:
  `Prospekt Kosmonavtov` и `Kamennye palatki` нарисованы с пробелом и
  переносом строки, а приходят с подчёркиваниями;
- кольцевая линия — кольцо из 12 станций;
- вопрос может спрашивать путь от станции до неё самой (0).
