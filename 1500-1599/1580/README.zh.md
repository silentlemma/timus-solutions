# 1580. 系主任的债务

[Timus 1580](https://acm.timus.ru/problem.aspx?space=1&num=1580) · 难度 880 · graphs

原题作者 Alexey Efremov，出自 2007 年 10 月第十四届斯维尔德洛夫斯克州中学生团体程序设计公开赛（USU Junior Contest）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

系主任欠 N ≤ 1000 名学生每人一笔未知的钱。在 M ≤ 10⁵ 天里，每天有一对不同的学生告诉系主任他们两人一共还应
得多少。若这些说法能唯一确定，就输出每名学生应得的钱数（小数点后两位），否则输出 `IMPOSSIBLE`。

时间限制：2 秒。内存限制：64 MB。

## 输入

N 和 M，然后每条说法：两名学生和他们的总额 A（−10000 ≤ A ≤ 10000）。

## 输出

N 个钱数，每行一个，或 `IMPOSSIBLE`。

## 样例

### 样例 1

输入:

```
3 3
1 2 2
2 3 4
3 1 6
```

输出:

```
2.00
0.00
4.00
```

### 样例 2

输入:

```
4 3
1 2 2
1 3 4
1 4 6
```

输出:

```
IMPOSSIBLE
```

## 解法

每条说法是一个方程 x_u + x_v = A，即学生图上的一条边。在一个连通分量内选定某名学生的债务 t；用广度优先搜索沿
边走，其他每笔债务都是 ±t 加一个常数，每走一步符号翻转一次。若分量中没有奇环，可以让两部分的债务分别加 +d
和 −d，所有说法仍然成立，所以答案不唯一。闭合奇环的边连接符号相同的两名学生，给出 2t = A − 常数，从而确定 t。

债务以半卢布为单位计算，此时一切都是整数，输出为 `.00` 或 `.50`。最后再检查每条说法：互相矛盾的说法也意味
着没有答案。`O(N + M)`。结果已在 500 个随机小方程组上与有理数上的精确高斯消元对照。

注意事项：

- 钱数可能是半卢布，也可能是负的：−0.50 必须保留负号（测试 03、04）；
- 每个分量都必须有奇环，而不只是其中一个（测试 05）；
- 沿两个奇环的说法可能互相矛盾（测试 06、gen2）。
