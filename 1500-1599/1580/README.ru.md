# 1580. Долги декана

## Задача

Декан должен каждому из N ≤ 1000 студентов неизвестную сумму. В каждый
из M ≤ 10⁵ дней новая пара студентов сообщает декану, сколько эти двое
должны получить вместе. Нужно вывести, сколько должен получить каждый, с
двумя знаками после точки, если заявления определяют это однозначно, и
`IMPOSSIBLE` иначе.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем каждое заявление: два студента и их сумма A
(−10000 ≤ A ≤ 10000).

## Выходные данные

N сумм, по одной в строке, или `IMPOSSIBLE`.

## Примеры

### Пример 1

Ввод:

```
3 3
1 2 2
2 3 4
3 1 6
```

Вывод:

```
2.00
0.00
4.00
```

### Пример 2

Ввод:

```
4 3
1 2 2
1 3 4
1 4 6
```

Вывод:

```
IMPOSSIBLE
```

## Решение

Каждое заявление — уравнение x_u + x_v = A, ребро графа на студентах.
Внутри компоненты связности выберем долг t одного студента; обходя рёбра
поиском в ширину, каждый другой долг выражается как ±t плюс константа, а
знак меняется на каждом шаге. Если в компоненте нет нечётного цикла, все
её долги можно сдвинуть на +d и −d по двум долям, и все заявления
останутся верными, так что ответ не единственный. Ребро, замыкающее
нечётный цикл, соединяет двух студентов с одинаковым знаком и даёт
2t = A − константы, что фиксирует t.

Долги считаются в половинах рубля, где всё целое, и выводятся как `.00`
или `.50`. В конце все заявления проверяются ещё раз: противоречащие
друг другу заявления тоже не оставляют ответа. `O(N + M)`. Результаты
сверены с точным методом Гаусса над рациональными числами на 500
случайных маленьких системах.

Подводные камни:

- сумма может быть в половину рубля, в том числе отрицательной: у −0.50
  должен остаться минус (тесты 03, 04);
- нечётный цикл нужен в каждой компоненте, а не в одной из них (тест 05);
- заявления по двум нечётным циклам могут противоречить друг другу
  (тесты 06, gen2).
