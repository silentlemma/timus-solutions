# 1536. 烟草的妙处

[Timus 1536](https://acm.timus.ru/problem.aspx?space=1&num=1536) · 难度 7335 · dp

原题作者 Sergey Pupyrev，出自 2007 年 3 月 3 日第八届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

算式 a1+a2=b（0 ≤ a1, a2, b < 10⁸）用火柴摆成，每格一个符号。每格有十二个可放火柴的位置：
数码管的七个位置（上、中、下横和四条竖）、上半部和下半部各一条斜线"/"、加号的竖棍以及
等号的两根横棍。题面图中的符号如下（所有斜线方向相同）：

| 符号 | 火柴数 | 位置 |
|---|---|---|
| `0` | 6 | 上横、左右两条上竖、左右两条下竖、下横 |
| `1` | 3 | 上斜、右上竖、右下竖 |
| `2` | 4 | 上横、右上竖、下斜、下横 |
| `3` | 4 | 上横、上斜、中横、下斜 |
| `4` | 4 | 左上竖、右上竖、中横、右下竖 |
| `5` | 5 | 上横、左上竖、中横、右下竖、下横 |
| `6` | 5 | 上斜、中横、左下竖、右下竖、下横 |
| `7` | 3 | 上横、上斜、左下竖 |
| `8` | 7 | 数码管的全部七个常规位置 |
| `9` | 5 | 上横、左上竖、右上竖、中横、下斜 |
| `+` | 2 | 中横，以及穿过中心的一根竖棍 |
| `=` | 2 | 自己的两根短横 |

移动至多 K 根火柴（0 ≤ K ≤ 100），把算式变成字符数相同的正确等式 X+Y=Z，其中 X、Y、Z
各有 1 到 8 位且没有前导零。不能增加或拿走火柴。输出这样的等式或"Impossible"。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行是算式，第二行是 K。

## 输出

至多 K 次移动可得到的正确算式，或 `Impossible`。

## 样例

### 样例 1

输入:

```
33+88=127
2
```

输出:

```
33+88=121
```

### 样例 2

输入:

```
3+3=7
1
```

输出:

```
Impossible
```

## 解法

若新算式与旧算式火柴数相同，最少移动次数就是新算式中那些在同一格里旧算式没有占据其位置
的火柴：其余火柴留在原处，这些必须搬动。所以要在总数不变的条件下使留在原处的火柴最多。

枚举 X 和 Y 的长度（Z 取剩下的长度，且不能短于两者）；这就确定了加号和等号所在的格子。
然后像竖式加法那样从右往左填各列。状态是列号、进位和已用火柴数，值为留在原处的最大火柴
数；每一步选择该列中 X 和 Y 的数字，从而确定 Z 的数字和下一个进位。超出 X 或 Y 末端的数字
不存在，也不用火柴；多于一位的数首位不能为 0。若最后一列之后进位为 0、火柴全部用完且留在
原处的不少于 total − K，则该长度划分可行；保存的选择给出各位数字。约 64 种划分 × 8 列 × 2
种进位 × 180 种火柴数 × 100 对数字，少于 2·10⁷ 步。

注意事项：

- 加号的横棍恰好位于中横的位置，所以当带中横的数字占据加号的格子时它可以不动，如测试 05 中的 5：
  答案需要 17 次移动，否则需要 18 次；
- 符号可以移动：测试 05 中加号从第四格移到第二格；
- 火柴必须全部用上：测试 07 中扔掉火柴只需 3 次移动，全部保留则需要 5 次；测试 09 中的 8
  比任何同长度的正确等式都多出火柴；
- 不允许前导零，这使测试 06 中原本 9 次可行的答案变得不可能；
- 形状以图为准：1 的上半部是斜线，7 的左下有一根竖棍，3 由两根横棍和两条斜线组成。
