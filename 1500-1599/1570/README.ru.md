# 1570. Ужин на 45 этаже

[Timus 1570](https://acm.timus.ru/problem.aspx?space=1&num=1570) · сложность 895 · dp

Автор оригинальной задачи — Владимир Яковлев; XII чемпионат УрГУ по программированию, 6 октября 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В меню N ≤ 100 блюд, у каждого цена 1 … 10000 рублей и сытность от 0.1
до 10 (не более трёх знаков после точки) — число людей, которых оно
насыщает. Нужно заказать сколько угодно порций любых блюд так, чтобы
сумма сытностей была не меньше M ≤ 20 при наименьшей стоимости, а среди
таких заказов выбрать заказ с наибольшим числом разных блюд. Вывести
стоимость и блюда с числом порций.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем каждое блюдо: название, цена и сытность.

## Выходные данные

Стоимость, затем по блюду с числом порций в строке. Принимается любой
лучший заказ.

## Примеры

### Пример 1

Ввод:

```
4 6
pizza 320 2.4
turkey 1050 3.5
lasagna 150 0.9
pasta 75 0.45
```

Вывод:

```
865
pizza 2
lasagna 1
pasta 1
```

## Решение

Сытность читается точно, в тысячных, так что цель — T = 1000·M, а любая
сумма от T и выше считается за T. Неограниченный рюкзак по этим суммам
хранит для каждой суммы наименьшую стоимость и при равенстве наибольшее
число разных блюд, упакованные в одно число стоимость·128 − блюда, где
меньше — лучше.

Число разных блюд не складывается по порциям, поэтому блюда добавляются
по одному. Для каждого блюда заказы с ним начинаются с первой порции
поверх заказа без него, что даёт ещё одно блюдо, а затем растут
следующими порциями, которые блюд не добавляют; сохраняется лучшее из
этих заказов и заказов без блюда. Каждый шаг запоминает, откуда он
пришёл, так что заказ восстанавливается обратным ходом от суммы T блюдо
за блюдом. Это O(N·T) времени, около 2·10⁶ состояний. Результаты сверены с
перебором всех чисел порций на 300 случайных маленьких меню.

Подводные камни:

- более дешёвый заказ может перебрать M, так что суммы выше T должны
  оставаться возможными (тест 07: две порции по 0.501);
- равенство стоимости разрешается числом разных блюд, а не числом порций
  (пример и тесты 04, 05);
- сытность может быть записана без точки (тест 04);
- Python запускается под PyPy: самые большие тесты идут около 0.8 с в
  CPython при ограничении 1 с и около 0.1 с в PyPy.
