# 1557. Атака на сеть

[Timus 1557](https://acm.timus.ru/problem.aspx?space=1&num=1557) · сложность 1700 · graphs

Оригинальная задача — Novosibirsk SU Contest, Петрозаводские сборы, сентябрь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Связная сеть состоит из N серверов (1 ≤ N ≤ 2000) и M двусторонних каналов (0 ≤ M ≤ 100000);
канал может соединять сервер сам с собой, и несколько каналов могут
соединять одну пару. Два хакера уничтожают по одному каналу, всего два
разных канала. Нужно посчитать неупорядоченные пары каналов, после
удаления которых найдутся два сервера без связи между собой.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем два сервера каждого канала.

## Выходные данные

Число пар.

## Примеры

### Пример 1

Ввод:

```
3 3
1 2
2 3
3 1
```

Вывод:

```
3
```

## Решение

Возьмём остовное дерево. Каждый канал вне дерева замыкает один цикл —
путь по дереву между его концами плюс сам канал. Мост не лежит ни на одном
таком цикле. Два канала, не являющихся мостами, образуют разрез ровно
тогда, когда лежат на одном и том же наборе этих циклов.

Дадим каждому каналу вне дерева псевдослучайную 64-битную метку, а каждому
каналу дерева — XOR меток циклов, проходящих через него. Код проверяет
равенство наборов циклов сравнением этих XOR-меток; мост получает метку 0.
XOR для канала дерева над сервером равен XOR внешних меток, у которых
ровно один конец лежит в его поддереве, поэтому один проход от листьев
вверх заполняет все метки.

Мост разрезает сеть вместе с любым другим каналом, что даёт
C(M, 2) − C(M − B, 2) пар при B мостах. Остальные каналы добавляют
C(c, 2) за каждую группу из c равных ненулевых меток. Петля получает
собственную метку и образует разрез лишь в паре с мостом. Метки получаются
применением splitmix64 к номеру канала, так что запуск детерминирован;
совпадения XOR, включая 0, возможны. Результаты сверены с перебором всех
пар на 400 маленьких сетях.

Подводные камни:

- пары неупорядоченные: в примере три пары каналов треугольника дают 3,
  а не 6;
- при единственном канале пар нет вовсе (тест 08);
- C(M, 2) — около 5·10⁹ и требует 64 бит, хотя сам ответ не больше
  примерно 2·10⁸ (тест gen3);
- два канала между одними и теми же серверами не образуют разреза, пока
  их соединяет третий путь (тест 07).
