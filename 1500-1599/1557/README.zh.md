# 1557. 网络攻击

[Timus 1557](https://acm.timus.ru/problem.aspx?space=1&num=1557) · 难度 1700 · graphs

原题出自 2007 年 9 月彼得罗扎沃茨克集训的 Novosibirsk SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个连通的网络有 N 台服务器（1 ≤ N ≤ 2000）和 M 条双向信道（0 ≤ M ≤ 100000）；信道可以把服务器连到自身，
同一对服务器之间也可以有多条信道。两名黑客各毁掉一条信道，共两条不同的信道。求有多少个无序信道对，
删去之后会有两台服务器彼此不连通。

时间限制：2 秒。内存限制：64 MB。

## 输入

N 和 M，然后是每条信道的两台服务器。

## 输出

信道对的数目。

## 样例

### 样例 1

输入:

```
3 3
1 2
2 3
3 1
```

输出:

```
3
```

## 解法

取一棵生成树。树外的每条信道闭合一个环：它两端之间的树上路径加上它自己。桥不在任何这样的环上。
两条非桥信道构成割，当且仅当它们位于同一组这样的环上。

给树外的每条信道一个伪随机 64 位标签，给每条树边经过它的那些环的标签的异或。代码通过比较这些异或
标签来判断环的集合是否相同；桥的标签为 0。服务器上方那条树边的异或，等于恰有一个端点在其子树中的
所有树外标签的异或，所以从叶子往上一遍就能填好全部标签。

桥和任何其他信道一起都能割开网络，B 条桥给出 C(M, 2) − C(M − B, 2) 对。其余信道中，每组 c 个相
等的非零标签再加 C(c, 2)。自环有自己的标签，只有与桥配对才能使攻击成功。标签由对信道编号应用
splitmix64 得到，所以运行是确定的；异或仍可能碰撞，包括 0。结果已在 400 个小网络上与枚举所有信道对
的暴力对照。

注意事项：

- 信道对是无序的：样例中三角形的三对信道给出 3，而不是 6；
- 只有一条信道时根本没有信道对（测试 08）；
- C(M, 2) 约为 5·10⁹，需要 64 位，尽管答案本身至多约为 2·10⁸（测试 gen3）；
- 同一对服务器之间的两条信道，只要还有第三条路径连接它们，就不构成割（测试 07）。
