# 1549. Японский пазл

## Задача

Есть S прямых и T поворотных квадратных кусочков пути
(0 ≤ S, T ≤ 1000, S + T > 0). Нужно сложить самый длинный замкнутый путь: цикл из
кусочков на разных клетках сетки, каждый соединён со следующим через
середину стороны. Вывести его длину и кусочки по порядку как F
(прямой), L (поворот налево) и R (поворот направо) или «Atawazu», если цикл не сложить.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

S и T.

## Выходные данные

Число кусочков и строка из F, L и R или `Atawazu`.

## Примеры

### Пример 1

Ввод:

```
5 6
```

Вывод:

```
10
FLLFRLLFLF
```

### Пример 2

Ввод:

```
49 3
```

Вывод:

```
Atawazu
```

## Решение

Какие количества прямых f и поворотов t могут образовать цикл?

- клетки цикла чередуются по цветам шахматной доски, поэтому f + t
  чётно;
- каждый поворот меняет горизонтальный ход на вертикальный и обратно,
  поэтому t чётно, а значит, и f;
- цикл поворачивает на 360°, поэтому t ≥ 4;
- без прямых ходы чередуются горизонтальные и вертикальные, а для
  замыкания нужно чётное число тех и других, так что t кратно 4; и
  t = 8 не подходит (перебор всех циклов из 8 клеток).

Этих условий и достаточно, по трём построениям:

- граница коробки в 2 ряда шириной f/2 + b + 2 клеток с b выступами:
  выступ вставляет две новые соседние клетки снаружи верхнего или
  нижнего ряда, добавляя 4 поворота и забирая 2 прямых; это даёт t = 4 + 4b, и
  в двух рядах вместе хватает места для выступов, когда f ≥ 2 или b = 0;
- для t = 6 + 4b (тогда f ≥ 2) коробка в 3 ряда с теми же выступами и
  одним вдавленным углом: угловая клетка сдвигается по диагонали внутрь,
  превращая две прямые в повороты;
- без прямых и при t ≥ 12 — лесенка: L, затем LR, повторённое
  t/4 − 2 раз, L, LR, и то же самое ещё раз.

Если T < 4, выводим `Atawazu`. Иначе ответ берёт наибольшее чётное
f ≤ S и чётное t ≤ T; только при f = 0 t опускается до наибольшего
кратного 4, равного 4 или не меньше 12. Программа читает буквы по пути
коробки, а строки лесенок строит напрямую. Все
S, T ≤ 120, а также любые f или t до 1000 при малых значениях другого
проверены обходом пути; перебор всех циклов до 18 клеток нашёл ровно
такие пары (f, t).

Подводные камни:

- восемь поворотов без прямых нельзя использовать все, четыре — можно (тесты 04, 12);
- нечётный прямой кусочек или поворот остаётся лишним (тесты 01, 11, 17);
- путь из примера — лишь один из многих; чекер проходит вывод (все
  тесты с циклом).
