# 1549. 另一个日本拼图

[Timus 1549](https://acm.timus.ru/problem.aspx?space=1&num=1549) · 难度 2338 · constructive

原题作者 Stanislav Vasiliev，由 Vladimir Yakovlev 整理，出自 2007 年 4 月 21 日在叶卡捷琳堡举行的第十一届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 S 块直轨和 T 块弯轨方块（0 ≤ S, T ≤ 1000）。拼出最长的闭合轨道：由放在网格不同格子上的
方块组成的环，每块通过边的中点与下一块相接。输出其长度以及按顺序排列的方块：F（直）、L 和
R（转弯）；若无法拼成环则输出"Atawazu"。

时间限制：1 秒。内存限制：64 MB。

## 输入

S 和 T。

## 输出

方块数以及由 F、L、R 组成的字符串，或 `Atawazu`。

## 样例

### 样例 1

输入:

```
5 6
```

输出:

```
10
FLLFRLLFLF
```

### 样例 2

输入:

```
49 3
```

输出:

```
Atawazu
```

## 解法

直轨数 f 与弯轨数 t 满足什么条件才能成环？

- 环上的格子在棋盘的两种颜色间交替，所以 f + t 为偶数；
- 每次转弯都在水平和竖直移动之间切换，所以 t 为偶数，从而 f 也是；
- 环总共转过 360°，所以 t ≥ 4；
- 没有直轨时水平与竖直移动交替，而闭合需要两者各为偶数次，所以 t 是 4 的倍数；并且 t = 8
  不行（对全部 8 格环的搜索）。

这些条件也是充分的，用三种构造：

- 2 行、宽 f/2 + b + 2 格的盒子边界，带 b 个凸起：凸起把上行或下行相邻两格抬高一格，增加 4
  个弯、用掉 2 个直轨；这给出 t = 4 + 4b，当 f ≥ 2 或 b = 0 时两行合起来有足够位置放凸起；
- 对 t = 6 + 4b（此时 f ≥ 2）用 3 行的盒子，凸起相同，再把一个角向内凹：角上的格子沿对角线
  向内移动，把两个直轨变成弯；
- 没有直轨且 t ≥ 12 时用阶梯：L，然后 LR 重复 t/4 − 2 次，L，LR，再重复一遍。

所以答案取不超过 S 的最大偶数 f 和不超过 T 的最大偶数 t；只有 f 为 0 时，t 降为等于 4 或不小
于 12 的最大 4 的倍数。程序摆出格子，再按转弯读出字母。所有 S, T ≤ 120，以及另一个值较小时
直到 1000 的任意 f 或 t，都通过走一遍轨道验证过；对至多 18 格的全部环的搜索正好得到这些
(f, t) 组合。`O(S + T)`。

注意事项：

- 八个弯而没有直轨无法闭合，四个可以（测试 04、12）；
- 奇数的直轨或弯轨会剩下一块（测试 01、11）；
- 样例中的轨道只是众多答案之一；检查器会沿输出走一遍（所有测试）。
