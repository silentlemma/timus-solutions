# 1529. Игра в квадраты

[Timus 1529](https://acm.timus.ru/problem.aspx?space=1&num=1529) · сложность 3540 · games

Автор оригинальной задачи — Дмитрий Гозман; Dmitry Gozman Contest 1 на Петрозаводских зимних сборах, январь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Два игрока по очереди ходят в k-мерном параллелепипеде из
n1 × … × nk единичных кубиков (1 ≤ k ≤ 8,
(n1 + 1)·…·(nk + 1) ≤ 10000), а потом и в оставшихся параллелепипедах.
Ход: выбрать параллелепипед и единичный кубик в нём и разрезать через
этот кубик k плоскостями, параллельными граням; разрезанные кубики
исчезают, остаётся до 2^k меньших параллелепипедов. Разрез допустим,
если у одного из новых параллелепипедов каждое ребро взаимно просто с
соответствующим ребром разрезаемого, или если не остаётся ничего. Кто
не может сходить, проигрывает. Нужно сказать, кто выиграет, и если
выигрывает Алиса, которая ходит первой, — её лексикографически
наименьший выигрышный разрез.

Ограничение времени: 5 секунд. Ограничение памяти: 64 МБ.

## Входные данные

k, затем n1 … nk.

## Выходные данные

1 или 2 — победитель, а при 1 ещё координаты разреза с единицы.

## Примеры

### Пример 1

Ввод:

```
2
2 2
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
3
3 4 5
```

Вывод:

```
1
1 1 3
```

## Решение

Оставшиеся параллелепипеды — независимые игры, поэтому по теореме
Шпрага — Гранди у каждого есть значение, а ход стоит XOR значений
оставленных частей; пустая часть стоит 0. Разрез в позиции c ребра d
оставляет вдоль него куски c − 1 и d − c, а части — все сочетания
кусков k рёбер. У части все рёбра взаимно просты ровно тогда, когда
каждый её кусок взаимно прост, поэтому разрез допустим, если у каждого
ребра есть непустой взаимно простой с ним кусок; так как
gcd(d − c, d) = gcd(c, d), средний разрез недопустим, только когда и
c − 1, и c имеют общий делитель с d. Параллелепипед с ребром 1
исчезает при любом разрезе и стоит 1. В одномерном случае два куска
всегда дают в сумме d − 1, и значение равно d mod 2.

Значение параллелепипеда не зависит от порядка рёбер, поэтому значения
считаются для отсортированных наборов рёбер по возрастанию размера и
записываются для всех порядков. Для параллелепипеда берём таблицу
значений его частей по длинам кусков и по одной оси заменяем ось её
допустимыми разрезами: каждый разрез делает XOR срезов c − 1 и d − c.
После всех осей в таблице стоят значения всех ходов, а их mex — значение
параллелепипеда. Это около 2k операций на элемент таблицы, а не 2^k.
Алиса выигрывает, когда весь параллелепипед стоит больше 0, а её первый
ход — первый ноль в таблице ходов всего параллелепипеда в порядке рёбер
из ввода.

Подводные камни:

- «исходный параллелепипед» в правиле — это тот, что режется этим ходом;
  такое прочтение принимает судья;
- параллелепипед с ребром 1 всегда можно срезать целиком, поэтому
  Алиса выигрывает разрезом (1, …, 1) (тест 05);
- одномерный случай не требует перебора: нечётные длины выигрывают
  (тесты 03, 04, 10);
- у прямоугольника 6 × 5 часть разрезов недопустима (тест 06);
- много работы и у квадратных параллелепипедов вроде 99 × 99, и у
  длинных тонких вроде 1046 × 2 (тест 07, gen1).

## Особенности языков

Решение на Python упаковывает каждую строку значений вдоль последней оси
в одно длинное число с 16-битными дорожками. Разрез по последней оси
соединяет дорожку c − 1 с дорожкой d − c, то есть с дорожкой c − 1
перевёрнутой строки, поэтому строки обрабатываются XOR целиком, и по
остальным осям тоже XOR целых строк. Даже список допустимых разрезов
строится байтовыми масками.
