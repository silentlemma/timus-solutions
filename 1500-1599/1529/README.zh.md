# 1529. 方块游戏

[Timus 1529](https://acm.timus.ru/problem.aspx?space=1&num=1529) · 难度 3540 · games

原题作者 Dmitry Gozman，出自 2007 年 1 月彼得罗扎沃茨克冬季集训的 Dmitry Gozman Contest 1。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两名玩家轮流操作一个由 n1 × … × nk 个单位立方体组成的 k 维长方体（1 ≤ k ≤ 8，
(n1 + 1)·…·(nk + 1) ≤ 10000），之后也操作剩下的长方体。一步是选一个长方体和其中一
个单位立方体，用平行于各面的 k 个平面穿过这个立方体切开：被切到的立方体消失，剩下至
多 2^k 个更小的长方体。如果某个新长方体的每条棱都与被切长方体对应的棱互质，或者什么
都不剩，这一刀就是合法的。不能行动的一方输。判断谁赢；如果先手 Alice 赢，输出她字典
序最小的必胜切法。

时间限制：5 秒。内存限制：64 MB。

## 输入

k，然后是 n1 … nk。

## 输出

赢家 1 或 2；若为 1，再输出切点从 1 开始的坐标。

## 样例

### 样例 1

输入:

```
2
2 2
```

输出:

```
2
```

### 样例 2

输入:

```
3
3 4 5
```

输出:

```
1
1 1 3
```

## 解法

剩下的长方体是互相独立的游戏，所以由 Sprague–Grundy 定理每个长方体有一个值，一步的
值是留下各部分的值的异或；空的部分值为 0。在长为 d 的棱的位置 c 切，沿这条棱留下
c − 1 和 d − c 两段，各部分就是 k 条棱上各段的所有组合。一个部分的每条棱都互质，当
且仅当它的每一段都互质，所以合法当且仅当每条棱都有一段非空且与之互质；由于
gcd(d − c, d) = gcd(c, d)，中间的切法只有在 c − 1 和 c 都与 d 有公因子时才不合法。
有一条棱为 1 的长方体被任何一刀切掉，值为 1。一维时两段之和总是 d − 1，值为
d mod 2。

长方体的值与棱的顺序无关，所以按大小递增对排好序的棱列表计算，并按所有顺序存储。对
一个长方体，取其各部分按段长索引的值表，逐条轴把这条轴替换成它的合法切法，每种切法
对 c − 1 和 d − c 两个切片做异或：处理完所有轴后，表中就是每一步的值，它们的 mex 就
是长方体的值。每个表项约 2k 次运算，而不是 2^k。整个长方体的值大于 0 时 Alice 赢，
她的第一步是按输入棱的顺序在整个长方体的走法表中第一个为零的位置。

注意事项：

- 规则里的“原长方体”指这一步被切的长方体；评测系统接受这种理解；
- 有一条棱为 1 的长方体总能被整个切掉，所以 Alice 用 (1, …, 1) 获胜（测试 05）；
- 一维情况无需搜索：奇数长度获胜（测试 03、04、10）；
- 6 × 5 的长方形有些切法不合法（测试 06）；
- 像 99 × 99 这样的方形长方体和像 1046 × 2 这样细长的长方体工作量都很大（测试 07、
  gen1）。

## 语言说明

Python 解法把沿最后一条轴的每行值打包成一个大整数，每 16 位一个通道。沿最后一条轴的
一刀把通道 c − 1 与通道 d − c（即反转后的行的通道 c − 1）合并，所以整行一次异或，其
他轴也是整行异或。连合法切法的计算也用字节掩码完成。
