# 1519. Формула 1

[Timus 1519](https://acm.timus.ru/problem.aspx?space=1&num=1519) · сложность 466 · dp

Авторы оригинальной задачи — Никита Рыбак, Илья Гребнов и Дмитрий Ковалёв; Timus Top Coders: Third Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В поле N × M клеток (2 ≤ N, M ≤ 12) некоторые клетки заняты норами.
Трасса — один замкнутый цикл, проходящий ровно один раз через каждую
свободную клетку и переходящий между клетками с общей стороной. Нужно
посчитать трассы; их число помещается в 63 бита.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем N строк по M символов: '.' — свободно, '*' — нора.
Свободных клеток не меньше четырёх.

## Выходные данные

Число трасс.

## Примеры

### Пример 1

Ввод:

```
4 4
**..
....
....
....
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
4 4
....
....
....
....
```

Вывод:

```
6
```

## Решение

Динамика по изломанному профилю, клетка за клеткой по строкам, где
состояние — связность кусков, пересекающих профиль. В профиле M + 1
разъём: нижние стороны клеток предыдущей или текущей строки
и левая сторона текущей клетки. Каждый разъём пуст или является концом
куска пути, а два конца каждого куска вложены как скобки, поэтому
разъём — это «(», «)» или ничего: 2 бита, и состояние помещается в
26 бит. В свободной клетке с левым разъёмом L и верхним U:

- разъёмов нет: начинаем новый кусок вправо и вниз;
- один разъём: продолжаем его вправо или вниз;
- «(» и «(»: соединяем куски, и «)», парная U, становится «(»;
- «)» и «)»: соединяем их, и «(», парная L, становится «)»;
- «)» и «(»: соединяем два куска в один;
- «(» и «)»: это замыкает цикл, что допустимо только в последней
  свободной клетке, когда других разъёмов нет, и тогда засчитывается.

Нора пропускает только состояния с обоими пустыми разъёмами. В конце
строки профиль сдвигается на один разъём. На пустом поле 12 × 12
одновременно бывает не больше примерно 14000 состояний, а работа —
`O(N·M²·S)` при S состояниях.

Подводные камни:

- цикл можно замкнуть только в последней свободной клетке, когда больше
  ничего не открыто (тест 09);
- нечётное число свободных клеток или отрезанная от остальных
  свободная область дают 0 (тесты 05, 06, 08);
- у пустого поля 12 × 12 около 1.08·10¹⁸ трасс, поэтому числам нужны
  64 бита (тест 03);
- норы, разбросанные поодиночке, обычно не оставляют трасс, поэтому
  генерируемые тесты в основном вырезают целые блоки 2 × 2 (gen1, gen2,
  gen3).

## Оптимизированные решения

Все новые версии сохраняют скобочные переходы профиля и разрешают замкнуть цикл лишь на последней свободной клетке без оставшихся концов. После транспонирования при необходимости высота H = max(N, M), ширина профиля W = min(N, M). C++, Go и Rust переиспользуют два плотных массива 32-битных состояний и 64-битных счётчиков. При слиянии одна таблица из 65536 ячеек хранит 16-битные позиции; линейное пробирование сравнивает полные ключи, не смешивая коллизии. В профиле до 13 позиций. Для t пар выбираем 2t занятых позиций и заполняем их правильной скобочной последовательностью. Сумма binom(13, 2t), умноженных на t-е число Каталана, даёт 41 835 состояний. Начальная ёмкость слоя 16 384 растёт по мере необходимости. Сдвиг строки инъективен, ключи меняются на месте без ещё одного словаря. Python также отбрасывает несвязные, несбалансированные по цветам графы и вершины степени меньше двух, встраивает поиск пары и переиспользует два словаря. Это необходимые условия, без приближения ответа. При максимуме S состояний в слое ожидаемое время O(H·W²·S). Упакованные нативные слои уменьшают выделения и расходы ключей. Базы сохранены; Java использует подходящую базу. Для Python указан реально принятый интерпретатор.

Новая реализация Python использует CPython, исходная — PyPy. Убираем края, целиком занятые препятствиями, и выбираем направление обхода. Если высота оставшегося поля чётная и половины зеркальны, Python строит профили только для верхней половины. Отражение даёт те же числа спариваний для нижней. Соединяются только профили с одинаковыми столбцами пересечения разреза. Если концов больше двух, общая пара образует отдельный цикл из двух рёбер. Проверяем это маской до обхода. От одного конца чередуем верхние и нижние пары. Учитываем сочетание, если цикл обходит все концы. Перемножаем числа вариантов и учитываем оба порядка для разных профилей. Для четырёх или шести концов спаривания без общего ребра дают один цикл. При симметрии по обеим осям отражённые группы дают одинаковый вклад. В широком несимметричном поле выбираем разрез в средней трети с наименьшим числом доступных переходов. Обходим обе половины к разрезу. После обрезки свободные клетки есть с обеих сторон, так что для цикла нужны хотя бы два перехода. Узкие несимметричные поля обходим целиком. Соединение занимает O(W·P), где P — сумма квадратов совокупных размеров групп.

Принятая версия Python 3.12 x64 заняла 0.703 с при 0.609 с у базовой и использовала 4 880 KB при 10768 KB у базовой.

Принятые базовые реализации [1519_dp.java](1519_dp.java) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
