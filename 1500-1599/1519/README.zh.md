# 1519. 一级方程式

[Timus 1519](https://acm.timus.ru/problem.aspx?space=1&num=1519) · 难度 466 · dp

原题作者 Nikita Rybak、Ilya Grebnov 与 Dmitry Kovalioff，出自 Timus Top Coders: Third Challenge。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N × M 的场地（2 ≤ N, M ≤ 12）中有些格子被地洞占据。赛道是一条闭合回路，恰好经过每
个空格一次，只在有公共边的格子之间移动。求赛道的数目；它不超过 63 位。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 M，然后是 N 行，每行 M 个字符：'.' 空格，'*' 地洞。至少有四个空格。

## 输出

赛道数。

## 样例

### 样例 1

输入:

```
4 4
**..
....
....
....
```

输出:

```
2
```

### 样例 2

输入:

```
4 4
....
....
....
....
```

输出:

```
6
```

## 解法

按行逐格的轮廓线动态规划（插头 DP），状态是穿过轮廓线的各段路径的连通关系。轮廓线
上有 M + 1 个插头：上一行或当前行格子的下边，以及当前格的左边。每个插头要么为空，
要么是某段路径的一端，而每段路径的两端像括号一样嵌套，所以插头是 "("、")" 或空：
2 位，一个状态占 26 位。在左插头为 L、上插头为 U 的空格：

- 没有插头：新开一段，向右和向下；
- 一个插头：把它延伸到右边或下边；
- "(" 和 "("：连接两段，与 U 配对的 ")" 变为 "("；
- ")" 和 ")"：连接两段，与 L 配对的 "(" 变为 ")"；
- ")" 和 "("：把两段连成一段；
- "(" 和 ")"：这会闭合回路，只允许在最后一个空格且没有其他插头时发生，此时计数。

地洞格只放行两个插头都为空的状态。每行结束时轮廓线平移一个插头。在空的 12 × 12 场地上
同时最多约有 14000 个状态，总工作量为 `O(N·M²·S)`，S 为状态数。

注意事项：

- 回路只能在最后一个空格、且没有其他未闭合部分时闭合（测试 09）；
- 空格数为奇数，或有一块空格与其余部分隔开，答案为 0（测试 05、06、08）；
- 空的 12 × 12 场地约有 1.08·10¹⁸ 条赛道，所以需要 64 位（测试 03）；
- 零散的单个地洞通常使赛道不存在，所以生成的测试多半挖去整块 2 × 2（gen1、gen2、
  gen3）。

## 优化解法

新版保持平衡括号轮廓转移，只在最后自由格且无其他插头时闭环。必要时转置，使高度 H = max(N, M)，轮廓宽度 W = min(N, M)。C++、Go、Rust 复用两组 32 位状态与 64 位计数密集数组，合并时以 65536 项、16 位位置表索引。线性探测比较完整键。轮廓至多有 13 个位置。对 t 对括号，选出 2t 个位置，再填入合法括号串。对 binom(13, 2t) 与第 t 个 Catalan 数的乘积求和得到 41,835 种状态。初始容量为 16,384，可按需增长。行移位为单射，可原地改键而不重建哈希表。Python 另检查连通、黑白平衡及最小度二，内联括号匹配、复用两个字典；都是必要条件，没有近似计数。若 S 为单层最大状态数，期望时间 O(H·W²·S)。原生压缩层减少分配及键开销。保留五个原文件；Java 复用已符合标准的基础版。Python 表格保留真正 Accepted 的解释器。

Python 新版使用 CPython，原版使用 PyPy。先裁去完全由障碍组成的边框，再选择扫描方向。裁剪后的高度为偶数且上下半场镜像时，只计算上半场轮廓。反射给出下半场相同的配对计数。只有切线相交列完全相同的轮廓才可拼接。端点超过两个时，共用配对会形成独立的两边环，先用位掩码排除这种情况。任选一个端点，交替沿上下两边的配对前进，环经过全部端点才计数。将两个计数相乘，不同轮廓计入两个顺序。四个或六个端点且没有共用边时只会形成单环。两轴对称时，反射列所得的分组贡献相同。对于较宽的非对称场地，在中间三分之一选可跨越边最少的切线，两侧分别向切线扫描。裁剪后两边都有自由格，环必须至少跨越两次。较窄的非对称场地完整扫描。若 P 为按切线列掩码分组后两侧合计组大小的平方和，拼接用时 O(W·P)。
