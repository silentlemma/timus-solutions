# 1519. 一级方程式

[Timus 1519](https://acm.timus.ru/problem.aspx?space=1&num=1519) · 难度 466 · dp

原题作者 Nikita Rybak、Ilya Grebnov 与 Dmitry Kovalioff，出自 Timus Top Coders: Third Challenge。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N × M 的场地（2 ≤ N, M ≤ 12）中有些格子被地洞占据。赛道是一条闭合回路，恰好经过每
个空格一次，只在有公共边的格子之间移动。求赛道的数目；它不超过 63 位。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 M，然后是 N 行，每行 M 个字符：'.' 空格，'*' 地洞。至少有四个空格。

## 输出

赛道数。

## 样例

### 样例 1

输入:

```
4 4
**..
....
....
....
```

输出:

```
2
```

### 样例 2

输入:

```
4 4
....
....
....
....
```

输出:

```
6
```

## 解法

按行逐格的轮廓线动态规划（插头 DP），状态是穿过轮廓线的各段路径的连通关系。轮廓线
上有 M + 1 个插头：上一行或当前行格子的下边，以及当前格的左边。每个插头要么为空，
要么是某段路径的一端，而每段路径的两端像括号一样嵌套，所以插头是 "("、")" 或空：
2 位，一个状态占 26 位。在左插头为 L、上插头为 U 的空格：

- 没有插头：新开一段，向右和向下；
- 一个插头：把它延伸到右边或下边；
- "(" 和 "("：连接两段，与 U 配对的 ")" 变为 "("；
- ")" 和 ")"：连接两段，与 L 配对的 "(" 变为 ")"；
- ")" 和 "("：把两段连成一段；
- "(" 和 ")"：这会闭合回路，只允许在最后一个空格且没有其他插头时发生，此时计数。

地洞格只放行两个插头都为空的状态。每行结束时轮廓线平移一个插头。在空的 12 × 12 场地上
同时最多约有 14000 个状态，总工作量为 `O(N·M²·S)`，S 为状态数。

注意事项：

- 回路只能在最后一个空格、且没有其他未闭合部分时闭合（测试 09）；
- 空格数为奇数，或有一块空格与其余部分隔开，答案为 0（测试 05、06、08）；
- 空的 12 × 12 场地约有 1.08·10¹⁸ 条赛道，所以需要 64 位（测试 03）；
- 零散的单个地洞通常使赛道不存在，所以生成的测试多半挖去整块 2 × 2（gen1、gen2、
  gen3）。
