# 1503. Многочлен

[Timus 1503](https://acm.timus.ru/problem.aspx?space=1&num=1503) · сложность 1709 · math

Автор оригинальной задачи — Ден Расковалов; четвертьфинал XXXI ACM ICPC, Екатеринбург, 2006 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дан многочлен a0·x^N + a1·x^(N−1) + … + aN степени N (1 ≤ N ≤ 5) с
целыми коэффициентами (−100 ≤ ai ≤ 100, a0 ≠ 0). Нужно вывести все его
вещественные корни в порядке возрастания, повторяя каждый столько раз,
какова его кратность, с точностью 10⁻⁶.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем коэффициенты a0, a1, …, aN по одному в строке.

## Выходные данные

Вещественные корни по одному в строке; ничего, если их нет.

## Примеры

### Пример 1

Ввод:

```
2
1
-2
1
```

Вывод:

```
1
1
```

## Решение

С простыми корнями всё легко: в них многочлен меняет знак, а между
двумя соседними корнями производной он монотонен и меняет знак не
больше одного раза. Корни производной находим так же, рекурсивно,
режем ими интервал |x| < 1 + max |ai / a0| (все корни внутри) и делим
пополам каждый кусок, на концах которого знаки разные.

Корень чётной кратности знак не меняет, а кратный корень нечётной
кратности трудно точно найти численно, поэтому кратные корни сначала
убираются точно. У рационального корня p/q число p делит aN, а q
делит a0; каждого такого кандидата проверяем в целых числах
(q^N·f(p/q) = 0) и выделяем схемой Горнера делением на q·x − p, при
котором коэффициенты остаются целыми. После этого кратный корень
иррационален, и сопряжённый к нему тоже кратный, так что у остатка
есть множитель — квадрат иррационального квадратного трёхчлена. При
степени не больше 5 и без рациональных корней это возможно, только
если остаток равен a0·(x² + b·x + d)² и имеет степень 4. Сравнивая
коэффициенты (теперь a0, …, a4 — коэффициенты остатка) при u = 4·a0 и
e = u·a2 − a1², получаем, что так бывает
при 2·a1·e = a3·u² и e² = a4·u³, а двойные корни тогда равны
(−a1 ± √(a1² − 2e)) / u. У того, что осталось, корни только простые,
их находит деление пополам. Всего несколько сотен вычислений значения.

Подводные камни:

- двойной корень только касается оси, поэтому поиск смены знака его
  пропускает (тест 01, пример);
- у корня может быть кратность 5 (тест 02);
- кратные корни бывают иррациональными (тесты 03, 06, gen3);
- если вещественных корней нет, вывод пустой (тест 04);
- при a0 ≠ ±1 рациональные корни бывают дробными (тесты 05, 07);
- корень 0 не годится для перебора делителей (0 делится на любое p),
  поэтому сначала отбрасываем нулевые свободные члены (тест 08);
- пять простых корней разделяются только корнями производной между
  ними (тест 09);
- корни сравниваются с допуском, поэтому тесты проверяются чекером (все
  тесты).

## Особенности языков

Решение на C++ делит пополам в `long double`, но печатает `double`:
`printf` из MinGW, на котором работает G++ под Windows, может неверно печатать
`long double`. Решение на Python всё время считает точно через
`Fraction`.
