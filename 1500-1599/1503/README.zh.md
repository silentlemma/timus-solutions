# 1503. 多项式

[Timus 1503](https://acm.timus.ru/problem.aspx?space=1&num=1503) · 难度 1709 · math

原题作者 Den Raskovalov，出自 2006 年第 31 届 ACM ICPC 叶卡捷琳堡四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 N 次（1 ≤ N ≤ 5）整系数多项式 a0·x^N + a1·x^(N−1) + … + aN
（−100 ≤ ai ≤ 100，a0 ≠ 0），按升序输出它的所有实根，每个根按重数重复输出，精度
10⁻⁶。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后每行一个系数 a0, a1, …, aN。

## 输出

每行一个实根；没有实根时什么也不输出。

## 样例

### 样例 1

输入:

```
2
1
-2
1
```

输出:

```
1
1
```

## 解法

单根很好处理：多项式在单根处变号，而在导数的两个相邻根之间单调，最多变号一次。用同
样的方法递归求出导数的根，用它们切开区间 |x| < 1 + max |ai / a0|（所有根都在里
面），对两端符号不同的每一段二分。

偶数重根不改变符号，奇数重根也很难用数值方法精确定位，所以先精确地去掉重根。有理根
p/q 满足 p 整除 aN、q 整除 a0；用整数运算检验每个候选（q^N·f(p/q) = 0），并用综
合除法除以 q·x − p，系数仍保持为整数。此后剩下的重根都是无理数，它的共轭根也是重
根，所以剩余部分含有一个无理二次式的平方作为因子。次数不超过 5 且没有有理根时，只
有剩余部分恰好是 4 次的 a0·(x² + b·x + d)² 才可能。比较系数（此时 a0, …, a4 指剩余部分的系数），令 u = 4·a0、
e = u·a2 − a1²，条件是 2·a1·e = a3·u² 且 e² = a4·u³，此时两个二重根为
(−a1 ± √(a1² − 2e)) / u。剩下部分只有单根，交给二分。总共只需几百次求值。

注意事项：

- 二重根只与坐标轴相切，单纯找变号会漏掉它（测试 01，即样例）；
- 一个根的重数可以是 5（测试 02）；
- 重根可以是无理数（测试 03、06、gen3）；
- 没有实根时输出为空（测试 04）；
- a0 ≠ ±1 时有理根可以是分数（测试 05、07）；
- 根 0 不适合枚举因数（任何 p 都整除 0），所以先去掉为零的常数项（测试 08）；
- 五个单根只能靠它们之间的导数根来分开（测试 09）；
- 根按误差比较，所以测试使用检查程序（所有测试）。

## 语言说明

C++ 解法用 `long double` 二分，但输出 `double`：Windows 上 G++ 所用的 MinGW
`printf` 可能无法正确输出 `long double`。Python 解法全程用 `Fraction` 精确计算。
