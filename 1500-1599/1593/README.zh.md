## 任务

土地按边长为正整数的正方形地块出售，边长为 a 的地块售价 a²。要把恰好 N ≤ 10¹⁵ 花在尽量少的地块上，输出需要的地块数。
这是 [第 1073 题](../../1000-1099/1073/README.zh.md) 的大数据版本。

时间限制：1 秒。内存限制：64 MB。

## 输入

正整数 N，1 ≤ N ≤ 10¹⁵。

## 输出

和为 N 的最少平方数个数。

## 样例

### 样例 1

输入:

```
344
```

输出:

```
3
```

## 解法

由拉格朗日定理，任何 N 都是四个平方数之和，所以答案在 1 到 4 之间，具体是几由经典定理给出：

- N 是完全平方数时为 1；
- N 中每个形如 4k + 3 的素因子都出现偶数次时为 2（费马平方和定理）；
- 去掉所有因子 4 后 N = 4ᵃ(8b + 7) 时为 4（勒让德三平方定理）；
- 其余为 3。

只有判断两平方和时需要分解 N。在 C++、Go、Java 和 Rust 中，用奇数试除到 √N（最多约 1.6·10⁷ 个）就足够快，
最后剩下的是 1 或一个素数。Python 中这个循环太慢，所以先试除掉 1000 以内的小因子，剩下的部分用 Pollard ρ 方法分解，
并用以前十二个素数为底的 Miller–Rabin 测试判素，它在远超 10¹⁵ 的范围内都是精确的。

Python 的复杂度是随机 ρ 方法的期望估计；由于可能重试，没有确定性的最坏运行时间上界。

答案已与对所有不超过 20000 的 N 的动态规划对照。

注意事项：

- 平方根要小心：10¹⁵ 附近的数用浮点开方可能差 1，要用整数步调整；
- 两个接近 √N 且都形如 4k + 3 的素数之积没有小因子，模 4 余 1，所以只试除到立方根再猜测剩余部分会出错（测试 06）；
- 试除后剩下的因子也要检查：若 N 本身是形如 4k + 3 的素数，√N 以内没有任何因子（测试 08）；素数 2 从不影响结果，因为 2 = 1 + 1。
- 生成的数据也必须满足 N ≤ 10¹⁵：生成器模式 2 的素数搜索必须有上界，模式 4 在乘以 4ᵃ 之前必须为 +7 留出空间。这两个边界问题均未影响已保存的编号测试。
