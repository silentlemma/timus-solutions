# 1578. Охота на мамонта

[Timus 1578](https://acm.timus.ru/problem.aspx?space=1&num=1578) · сложность 877 · greedy

Автор оригинальной задачи — Александр Ипатов; XIV открытое командное первенство школьников Свердловской области по программированию, октябрь 2007 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны N + 2 различные точки с целыми координатами (N ≤ 2000). Нужно
выстроить их в ломаную, у которой каждый поворот острый: в каждой
внутренней вершине два звена образуют угол меньше 90°, причём угол 0°
(разворот назад) считается острым. Вывести `NO`, если это невозможно, и
иначе `YES` и порядок.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N + 2 точки.

## Выходные данные

`YES` и номера точек по порядку или `NO`. Принимается любой подходящий
порядок.

## Примеры

### Пример 1

Ввод:

```
2
0 0
1 1
1 2
2 0
```

Вывод:

```
YES
1 3 4 2
```

### Пример 2

Ввод:

```
2
0 0
0 1
0 2
0 3
```

Вывод:

```
YES
1 3 2 4
```

## Решение

Это всегда возможно: начнём где угодно и будем всегда идти в самую
дальнюю ещё не посещённую точку. Рассмотрим поворот в B, где A — перед
ней, а C — после. Когда путь стоял в A, обе точки B и C были свободны и
B была выбрана как самая дальняя, так что |AC| ≤ |AB|. Теорема
косинусов, |AC|² = |AB|² + |BC|² − 2·|AB|·|BC|·cos B, даёт тогда
cos B ≥ |BC| / (2·|AB|) > 0, так что угол в B меньше 90°. `NO` не
выводится никогда. Каждый шаг ищет самую дальнюю свободную точку за линейное время:
`O(N²)`, около 2·10⁶ кандидатов суммарно, с точными целыми квадратами
расстояний.

Подводные камни:

- ответ никогда не `NO`, даже для точек на одной прямой, где путь
  ходит зигзагом туда и обратно (второй пример, тест 12);
- угол — между двумя звеньями в вершине, так что движение прямо — это
  180° и не допускается, а разворот назад — 0° и допускается;
- подходят разные порядки, так что чекер проверяет каждый поворот.
