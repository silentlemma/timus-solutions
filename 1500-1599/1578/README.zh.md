# 1578. 猎捕猛犸

[Timus 1578](https://acm.timus.ru/problem.aspx?space=1&num=1578) · 难度 877 · greedy

原题作者 Alexander Ipatov，出自 2007 年 10 月第十四届斯维尔德洛夫斯克州中学生团体程序设计公开赛（USU Junior Contest）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 N + 2 个坐标为整数的不同点（N ≤ 2000），把它们排成一条折线，使每个转弯都是锐角：在每个内部顶点处两条线段
的夹角小于 90°，0°（原路折返）也算锐角。若不可能则输出 `NO`，否则输出 `YES` 和顺序。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N + 2 个点。

## 输出

`YES` 和按顺序的点编号，或 `NO`。任何合法顺序都被接受。

## 样例

### 样例 1

输入:

```
2
0 0
1 1
1 2
2 0
```

输出:

```
YES
1 3 4 2
```

### 样例 2

输入:

```
2
0 0
0 1
0 2
0 3
```

输出:

```
YES
1 3 2 4
```

## 解法

总是可以做到：从任意点出发，每次都走向尚未访问的最远点。考虑 B 处的转弯，A 在它之前，C 在它之后。路径停在 A
时，B 和 C 都还没访问，而 B 被选为最远的，所以 |AC| ≤ |AB|。由余弦定理
|AC|² = |AB|² + |BC|² − 2·|AB|·|BC|·cos B 得 cos B ≥ |BC| / (2·|AB|) > 0，所以 B 处的角小于 90°。永远不会输出
`NO`。每一步用线性时间寻找最远的未访问点：`O(N²)`，总共约 2·10⁶ 个候选点，用精确的整数距离平方。

注意事项：

- 答案永远不是 `NO`，即使点都在一条直线上，路径也可以来回折返（第二个样例、测试 12）；
- 角是顶点处两条线段之间的角，所以直行是 180°，不允许；折返是 0°，允许；
- 合法顺序不止一种，所以检查器检验每个转弯。
