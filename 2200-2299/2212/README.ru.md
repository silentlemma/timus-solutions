# 2212. Префиксные суммы Q раз подряд как одна свёртка

## Задача

Массив из N чисел Q раз подряд заменяется своими префиксными суммами.
Выведите результат по модулю 998 244 353. Ограничения: 2 секунды и
256 МБ.

## Входные данные

N и Q, 2 ≤ N ≤ 10⁵, 1 ≤ Q ≤ 10⁷, затем массив со значениями от 1 до
10⁸.

## Выходные данные

Итоговый массив по модулю 998 244 353.

## Примеры

### Пример 1

Ввод:

```
3 2
1 2 3
```

Вывод:

```
1 4 10
```

## Решение

Одна префиксная сумма умножает производящую функцию массива на
1 / (1 − x), так что Q сумм умножают её на 1 / (1 − x)^Q, коэффициенты
которой равны C(Q + k − 1, k). Ответ — свёртка

pᵢ = Σ по j ≤ i от C(Q + i − j − 1, i − j) · vⱼ.

Коэффициенты получаются друг из друга: k-й равен предыдущему, умноженному
на (Q + k − 1) / k, с обратными 1 … N по модулю, посчитанными обычной
линейной рекуррентой.

Свёртка делается по модулю 998 244 353 теоретико-числовым
преобразованием, для которого этот модуль и подобран. Python вместо
этого упаковывает обе последовательности в огромные десятичные числа, по
23 цифры на элемент. Каждый точный коэффициент произведения меньше
10⁵ · 10⁸ · 10⁹, так что ячейки не переполняются друг в друга, а
встроенное умножение десятичных чисел само делает быстрое
преобразование; затем каждая ячейка берётся по модулю 998 244 353.

В примере Q = 2 даёт коэффициенты 1, 2, 3, так что последнее значение
равно 3 · 1 + 2 · 2 + 1 · 3 = 10.

Это O(N log N).
