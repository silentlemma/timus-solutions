# 2208. Поиск двух чисел с общим делителем на отрезке при изменениях

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Массив из N чисел от 2 до 10⁶ получает Q операций: заменить один
элемент или назвать две позиции на отрезке [l, r], числа на которых не
взаимно просты, либо −1, если таких нет. Подходит любая верная пара.
Ограничения: 2 секунды и 256 МБ.

## Входные данные

N и Q, 2 ≤ N ≤ 10⁵, 1 ≤ Q ≤ 10⁵, затем массив, затем операции «1 l r» и
«2 p x».

## Выходные данные

Пара позиций или −1 для каждого запроса на отрезке.

## Примеры

### Пример 1

Ввод:

```
5 4
2 3 4 5 6
1 1 5
1 2 4
2 3 6
1 2 4
```

Вывод:

```
1 3
-1
2 3
```

## Решение

Два числа не взаимно просты ровно тогда, когда у них есть общее простое,
а у числа до 10⁶ не больше 7 различных простых делителей. Для каждой
позиции i пусть prev(i) — наибольшее j < i, число на котором имеет общее
простое с числом на i; это последнее более раннее вхождение одного из
его простых.

На отрезке [l, r] есть подходящая пара ровно тогда, когда у какого-то i
в нём prev(i) ≥ l, и тогда (prev(i), i) — такая пара. Дерево отрезков по
значениям prev отвечает на запрос спуском к первому i ≥ l на отрезке,
у которого prev достаёт до l.

Изменение в p меняет prev только в самом p и, для каждого простого,
которое p теряет или получает, в следующем после p вхождении этого
простого. Каждое простое хранит свои вхождения в упорядоченной
структуре (сбалансированное множество в C++, дерево Фенвика по
позициям, которые оно вообще может занять, собранным заранее, в других
языках), и не больше 15 затронутых позиций пересчитываются.

Версия на Python экономит время на маленьких простых: 25 простых до 100
становятся битовой маской, которая помещается в машинное слово, а узел
дерева хранит ещё и то, есть ли у двух его элементов общее маленькое
простое. Так как 101 · 103 · 107 > 10⁶, у числа не больше двух простых
больше 100, и только они используют дерево prev. Их вхождения, включая
те, что появятся при изменениях, нумеруются заранее одной сортировкой,
а текущие хранятся в битовом множестве с уровнями-сводками из 30-битных
слов, где предыдущее вхождение находится за несколько операций со
словами. Запрос проходит отрезки дерева слева с OR уже пройденных масок
и спускается в первый отрезок, где есть пара.

В примере 2 и 4 имеют общий делитель 2, на отрезке 3, 4, 5 пары нет, а
после изменения 3 и 6 имеют общий делитель 3.

После решета наименьших простых до 10⁶ каждая операция стоит около
7 log N шагов.
