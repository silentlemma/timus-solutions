# 2222. 3 × N 棋盘上攻击图为树的最多马数

[Timus 2222](https://acm.timus.ru/problem.aspx?space=1&num=2222) · 难度 1127 · dp

原题作者 Vadim Barinov，出自 2025 年 ICPC 乌拉尔赛区资格赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在 3 × N 棋盘上放尽可能多的马，使相互攻击的马构成的图是一棵树：连通且无环。输出任意一种最优摆法。时间限制 1 秒，内存限制 256 MB。

## 输入

N（1 ≤ N ≤ 10⁵）。

## 输出

三行，每行 N 个 0 或 1。

## 样例

### 样例 1

输入：

```
3
```

输出：

```
0 1 1
1 0 1
1 1 1
```

### 样例 2

输入：

```
2
```

输出：

```
1 0
0 0
0 1
```

## 解法

马最多攻击到两列之外，所以按列填棋盘，用最后两列的轮廓做 DP。状态记录这六个格子中哪些有马，以及其中哪些已经通过更早的马相互连通，并按规范顺序重新编号。加入一列马的掩码时，把每匹新马与它在前两列中攻击到的马相连；在同一分量内部相连会形成环，因此禁止；一个分量离开轮廓时若没有碰到新列，只有当它就是整棵完成的树时才允许，此时转入一个只接受空列的特殊完成状态。这样可达的所有状态一次性构造成一个小自动机。

DP 逐列保存每个状态的最多马数。几列之后，每一步所有可达状态的得分向量都恰好增加 2，此后每一步都是同样的 max-plus 更新，所以 DP 停止，剩余各列重复使用同样的选择。答案是轮廓为单个分量的最佳状态，摆法沿保存的选择倒推还原。

第一个样例在 3 × 3 棋盘上放 7 匹马：中心格攻击不到任何格子，保持为空；外圈八个格子构成一个马步环，所以去掉其中一个。

易错点（测试 05、08 和 09）：N=5 时已经能放 2N+3 匹马，但 N=8 时最优值只有 18；N=9 时才恢复为 21。只有整个状态得分向量都出现相同增量后，才能重复使用选择。

自动机大小固定，所以复杂度 O(N)。
