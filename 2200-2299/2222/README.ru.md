# 2222. Больше всего коней на доске 3 × N, чей граф атак — дерево

[Timus 2222](https://acm.timus.ru/problem.aspx?space=1&num=2222) · сложность 1127 · dp

## Задача

Расставьте как можно больше коней на доске 3 × N так, чтобы граф
бьющих друг друга коней был деревом: связным и без циклов. Выведите
любую оптимальную расстановку. Ограничения: 1 секунда и 256 МБ.

## Входные данные

N, 1 ≤ N ≤ 10⁵.

## Выходные данные

Три строки из N нулей и единиц.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
0 1 1
1 0 1
1 1 1
```

### Пример 2

Ввод:

```
2
```

Вывод:

```
1 0
0 0
0 1
```

## Решение

Конь бьёт не дальше чем на два столбца, так что доска заполняется по
столбцам динамикой по профилю из двух последних столбцов. Состояние
хранит, в каких из этих шести клеток стоят кони и какие из них уже
связаны друг с другом через более ранних коней, с перенумерацией в
каноническом порядке. Добавление столбца с маской коней соединяет
каждого нового коня с конями, которых он бьёт в двух предыдущих
столбцах; соединение внутри одной компоненты замкнуло бы цикл и
запрещено, а компонента, покидающая профиль, не задев новый столбец,
допустима, только если это всё законченное дерево, — тогда переходим в
особое законченное состояние, принимающее только пустые столбцы. Все
достижимые так состояния один раз строятся как небольшой автомат.

Динамика хранит наибольшее число коней для каждого состояния, столбец за
столбцом. Через несколько столбцов вектор оценок на каждом шаге
сдвигается ровно на 2 во всех достижимых состояниях, и дальше каждый
шаг — то же самое max-plus обновление, так что динамика
останавливается, а те же выборы повторяются для всех оставшихся
столбцов. Ответ — лучшее состояние, профиль которого — одна компонента,
а расстановка восстанавливается назад по сохранённым выборам.

В первом примере на доске 3 × 3 стоит 7 коней: центр никого не бьёт и
остаётся пустым, а восемь крайних клеток образуют один цикл ходов коня,
так что одна из них пропускается.

Ловушка (тесты 05, 08 и 09): уже при N=5 достигается 2N+3 коня, но
при N=8 оптимум равен лишь 18; при N=9 он снова равен 21. Повторять
выборы можно только после равномерного сдвига всего вектора оценок.

Автомат фиксированного размера, так что это O(N).
