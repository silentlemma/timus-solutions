# 2226. Где кончается прогулка по кратчайшему неиспользованному ребру из каждой вершины

[Timus 2226](https://acm.timus.ru/problem.aspx?space=1&num=2226) · сложность 738 · dp, trees

Автор оригинальной задачи — Вадим Баринов; Чемпионат Урала 2025.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дерево из N вершин, длины рёбер различны. Прогулка начинается в
некоторой вершине и всегда идёт по кратчайшему ребру в ещё не
посещённую вершину, пока такие рёбра есть. Для каждой начальной вершины
выведите, где кончится прогулка. Ограничения: 1 секунда и 256 МБ.

## Входные данные

N, 2 ≤ N ≤ 10⁵, затем N − 1 рёбер u v l с различными длинами до 10⁹.

## Выходные данные

Конечная вершина для каждого начала.

## Примеры

### Пример 1

Ввод:

```
5
1 2 109
2 3 547
2 4 652
5 3 318
```

Вывод:

```
5 1 5 1 1
```

## Решение

В дереве единственный посещённый сосед текущей вершины — тот, откуда
пришла прогулка, так что следующий шаг зависит только от текущей
вершины и предыдущей: это кратчайшее ребро или второе по длине, если
кратчайшее ведёт назад. У каждой вершины нужны только два кратчайших
ребра.

Подвесим дерево и посчитаем два значения на вершину:

- down(v) — конец прогулки, которая только что пришла в v из родителя:
  она продолжает по кратчайшему ребру в ребёнка c и кончается в
  down(c) или в v, если такого нет;
- up(v) — конец прогулки, которая только что шагнула из v в родителя p:
  в p она берёт кратчайшее ребро, кроме ребра в v, которое ведёт либо в
  родителя p (это up(p)), либо в другого ребёнка c (это down(c)), либо
  его нет (прогулка кончается в p).

down заполняется от листьев вверх, а up — от корня вниз, итеративными
обходами. Прогулка из v сначала идёт по кратчайшему ребру v, так что её
конец — up(v), если это ребро ведёт в родителя, и down(v) иначе.

В примере прогулка из 1 идёт в 2, затем по 547 в 3, затем по 318 в 5,
где и останавливается.

Это O(N).
