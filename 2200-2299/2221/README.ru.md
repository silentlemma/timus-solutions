# 2221. Размеры оболочек всех поддеревьев декартова дерева точек

## Задача

N точек с различными x и различными y делятся рекурсивно: самая высокая
точка множества — его делегат, а точки левее и правее неё образуют два
новых множества. Для каждой точки выведите число вершин выпуклой
оболочки множества, делегатом которого она является (1 для точки, 2 для
отрезка). Ограничения: 2 секунды и 512 МБ.

## Входные данные

N, 1 ≤ N ≤ 10⁵, затем точки с координатами не больше 10⁹ по модулю.

## Выходные данные

Размер оболочки для каждой точки в порядке ввода.

## Примеры

### Пример 1

Ввод:

```
5
0 0
6 4
4 7
8 9
12 1
```

Вывод:

```
1
1
3
4
1
```

## Решение

Это деление — ровно декартово дерево с ключом x и приоритетом y,
которое строится стеком после сортировки по x; множество делегата — его
поддерево, непрерывный диапазон по x.

Оболочка поддерева — это его нижняя и верхняя цепочки, построенные как в
монотонной цепочке Эндрю. Точка, не лежащая на оболочке множества
ребёнка, не может лежать на оболочке множества родителя, так что
родителю нужны лишь цепочки детей и своя точка. Поднимаясь по дереву,
родитель берёт цепочку большего ребёнка в виде связного списка и
вставляет делегата, а затем точки цепочки меньшего ребёнка с ближнего
конца списка: дописывая справа, если основа левая, или слева, если
правая. Каждая вставка выбрасывает точки, которые больше не дают
строгого поворота, так что коллинеарные точки уходят.

Меньшее в большее означает, что каждая точка вставляется O(log n) раз, а
выбрасываний не больше, чем вставок. Размер оболочки — длина нижней
цепочки плюс длина верхней минус два общих конца, но не меньше 1.

В примере самая высокая точка (8, 9) — делегат всех пяти точек, у
оболочки которых 4 вершины, а (4, 7) — делегат трёх точек слева от неё,
треугольника.

Это O(n log n).
