# 2204. Выбор дат экзаменов, блокирующих меньше всего поездок

## Задача

Каждый из n экзаменов можно сдавать в одном из двух промежутков дней, и
экзамены идут по порядку, не пересекаясь. Есть m непересекающихся
поездок, тоже по порядку. Поездка пропадает, если у неё есть общий день
с выбранным промежутком экзамена. Выберите промежутки так, чтобы
сохранить как можно больше поездок. Ограничения: 1 секунда и 256 МБ.

## Входные данные

n и m, 1 ≤ n, m ≤ 10⁵, затем два промежутка каждого экзамена и
промежутки поездок, дни до 10⁹.

## Выходные данные

Наибольшее число сохранённых поездок.

## Примеры

### Пример 1

Ввод:

```
3 5
3 5 7 9
43 50 51 58
100 103 111 114
6 6
47 47
101 101
103 103
112 112
```

Вывод:

```
4
```

## Решение

Будем минимизировать число потерянных поездок. Поездки, задевающие
промежуток дней, образуют непрерывный блок среди отсортированных
поездок, который находится двумя указателями, движущимися только
вперёд, ведь промежутки идут по возрастанию.

Динамика хранит для каждого варианта текущего экзамена наименьшее число
потерянных поездок и номер последней поездки, которую этот вариант
блокирует. Единственное пересечение соседних экзаменов — одна длинная
поездка, задевающая оба выбранных промежутка: это может быть только
последняя поездка, заблокированная предыдущим промежутком, и первая,
заблокированная следующим. Поэтому если вариант блокирует c поездок,
его стоимость — c плюс лучшая из двух предыдущих стоимостей, каждая
уменьшенная на единицу, если её последняя заблокированная поездка —
первая для этого варианта. Поездка, тянущаяся через три экзамена,
задевает и средний, так что она вычитается на каждом шаге и всё равно
учитывается один раз.

В примере первые два экзамена могут обойти все поездки, а последний
блокирует либо поездки в дни 101 и 103, либо поездку в день 112, так что
теряется одна поездка и сохраняются четыре.

Это O(n + m).
