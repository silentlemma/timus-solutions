# 2204. 选择考试日期以挡掉最少的旅行

[Timus 2204](https://acm.timus.ru/problem.aspx?space=1&num=2204) · 难度 640 · dp, two_pointers

原题作者 Ivan Kogut，出自 2022 年大学学术中学生信息学奥林匹克。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 场考试中的每一场都可以在两个日期区间之一参加，考试按顺序排列且互不重叠。有 m 次互不相交的旅行，也按顺序给出。若某次旅行与所选的考试区间有共同的一天，这次旅行就去不成。选择区间使能去的旅行尽可能多。时间限制 1 秒，内存限制 256 MB。

## 输入

n 和 m（1 ≤ n, m ≤ 10⁵），然后是每场考试的两个区间和各次旅行的区间，日期不超过 10⁹。

## 输出

能去的旅行的最大次数。

## 样例

### 样例 1

输入：

```
3 5
3 5 7 9
43 50 51 58
100 103 111 114
6 6
47 47
101 101
103 103
112 112
```

输出：

```
4
```

## 解法

改为最小化去不成的旅行数。与一个日期区间相交的旅行在排好序的旅行中构成连续的一段，由于区间按递增顺序给出，可以用只向前移动的双指针找到。

DP 对当前考试的每个选项保存到目前为止最少损失的旅行数，以及这个选项挡掉的最后一次旅行的编号。相邻两场考试之间唯一的重叠是同时碰到两个所选区间的一次长旅行：它只可能是前一个区间挡掉的最后一次旅行，同时是后一个区间挡掉的第一次旅行。所以若某个选项挡掉 c 次旅行，它的代价是 c 加上前两个代价中较好的那个，若前一个选项挡掉的最后一次旅行恰是本选项的第一次，则该代价减一。跨越三场考试的旅行也会碰到中间那场，因此每一步都会被减去，仍然只计一次。

样例中前两场考试可以避开所有旅行，最后一场要么挡掉第 101 天和第 103 天的旅行，要么挡掉第 112 天的旅行，所以损失一次，保留四次。

复杂度 O(n + m)。
