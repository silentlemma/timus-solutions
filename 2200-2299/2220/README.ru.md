# 2220. Среднее 1 / gcd по всем парам до N

## Задача

Найдите среднее 1 / gcd(i, j) по всем парам 1 ≤ i ≤ j ≤ N по модулю
10⁹ + 7. Ограничения: 1.5 секунды и 512 МБ.

## Входные данные

N, 1 ≤ N ≤ 10⁷.

## Выходные данные

Среднее как p · q⁻¹ по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
833333340
```

### Пример 2

Ввод:

```
3
```

Вывод:

```
805555562
```

### Пример 3

Ввод:

```
1
```

Вывод:

```
1
```

## Решение

Сгруппируем пары по их gcd d. Если i = da и j = db, то пары с gcd d —
это взаимно простые пары a ≤ b ≤ ⌊N / d⌋, и их Φ(⌊N / d⌋), где
Φ(m) = φ(1) + … + φ(m). Значит, сумма равна

Σ по d от Φ(⌊N / d⌋) / d,

и в конце она делится на число пар N(N + 1) / 2.

⌊N / d⌋ принимает O(√N) различных значений, и на каждом блоке d с одним
частным сумме нужно Φ этого частного, умноженное на разность
гармонических чисел H(right) − H(left − 1) по простому модулю.

- Φ во всех частных берётся из решета φ до некоторой границы, а выше —
  из тождества Φ(x) = x(x + 1) / 2 − Σ по d ≥ 2 от Φ(⌊x / d⌋), снова
  с группировкой по частным, начиная с меньших аргументов.
- Гармоническим числам понадобилось бы обратное для каждого d до 10⁷.
  Вместо этого решение хранит F = d! и W = d! · H(d), обновляя их как
  W ← W · d + F и F ← F · d, и берёт одно обратное к F на блок. Версия
  на Python объединяет восемь соседних шагов в один через произведение
  восьми множителей и его производную.

В первом примере пары (1, 1), (1, 2) и (2, 2) дают 1 + 1 + 1/2 = 5/2, а
среднее равно 5/6.

Это O(N) умножений для гармонических чисел и около O(N^(3/4)) для сумм
функции Эйлера.
