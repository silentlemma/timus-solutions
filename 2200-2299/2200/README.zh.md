# 2200. 马能到达多少块分开的棋盘

[Timus 2200](https://acm.timus.ru/problem.aspx?space=1&num=2200) · 难度 1651 · dsu, sorting

原题作者 Vadim Barinov，出自 2020 年大学学术中学生信息学奥林匹克。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 块至少 3 × 3 的矩形棋盘放在网格上，彼此不接触，连角都不接触。一匹马站在某个格子上，可以在一块棋盘内走，也可以一步跳到另一块棋盘。求它能到达的棋盘数，包括起始棋盘。时间限制 4 秒，内存限制 256 MB。

## 输入

N 和 M（1 ≤ N ≤ 5 · 10⁴，2 ≤ M ≤ 10⁹），然后是马所在的格子，然后是每块棋盘的左下角和右上角，所有坐标绝对值不超过 M。

## 输出

棋盘数。

## 样例

### 样例 1

输入：

```
4 12
0 0
0 0 3 3
5 0 8 3
0 4 8 7
9 8 12 11
```

输出：

```
3
```

### 样例 2

输入：

```
2 10
-1 -1
-2 -2 1 1
-2 2 1 5
```

输出：

```
1
```

## 解法

在至少 3 × 3 的棋盘内，马能到达每个格子，只有一个例外：3 × 3 棋盘的中心一步也走不了。若马从那里出发，答案为 1；否则整块棋盘都可达，而从外面跳进来也不可能落在这样的中心。

两块棋盘相距一跳，当且仅当它们之间恰好隔一列空格且闭区间形式的行范围相交，或者恰好隔一行空格且闭区间形式的列范围相交。马的一步使一个坐标变化 2，另一个变化 1。要跨过 g 列的间隙，x 要变化 g + 1 ≤ 2，而棋盘不接触，所以 g = 1，于是 x 变化 2、y 变化 1，这恰好在行范围作为闭区间有公共点时才可能。对角的情形也被覆盖：隔一行且列范围在一条线上相接，就是第二种情形。

所以棋盘构成一个图，答案是起始棋盘在并查集中所在分量的大小。为找出边，把每条位于 x = R 的右边与位于 x = R + 1 的左边匹配：事件按所在直线排序，再按区间起点排序；由于同一直线上同类的边互不重叠，每个区间只需与另一类中最近的那个区间比较。对水平边做同样的扫描。

第一个样例中两块小棋盘都隔着一行空格够到上方的长棋盘，而最后一块棋盘位于对角方向，两个方向都有间隙。

排序使复杂度为 O(N log N)。
