# 2200. Сколько отдельных досок может посетить конь

[Timus 2200](https://acm.timus.ru/problem.aspx?space=1&num=2200) · сложность 1651 · dsu, sorting

Автор оригинальной задачи — Вадим Баринов; Вузовско-академическая олимпиада по информатике 2020.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N прямоугольных досок размером не меньше 3 × 3 лежат на сетке, не
касаясь друг друга даже углами. Конь стоит в одной клетке и может
ходить внутри доски или перепрыгивать между досками за один ход.
Посчитайте, сколько досок он может посетить, включая свою. Ограничения:
4 секунды и 256 МБ.

## Входные данные

N и M, 1 ≤ N ≤ 5 · 10⁴, 2 ≤ M ≤ 10⁹, затем клетка коня, затем каждая
доска своими левым нижним и правым верхним углами, все координаты не
больше M по модулю.

## Выходные данные

Число досок.

## Примеры

### Пример 1

Ввод:

```
4 12
0 0
0 0 3 3
5 0 8 3
0 4 8 7
9 8 12 11
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
2 10
-1 -1
-2 -2 1 1
-2 2 1 5
```

Вывод:

```
1
```

## Решение

Внутри доски размером не меньше 3 × 3 конь достигает любой клетки, с
одним исключением: из центра доски 3 × 3 нет ни одного хода. Если конь
стоит там, ответ 1; иначе достижима вся его доска, а прыжок снаружи в
такой центр попасть не может.

Две доски отстоят на один прыжок только тогда, когда их разделяет ровно
один пустой столбец и их замкнутые диапазоны строк пересекаются, или
ровно одна пустая строка и пересекаются замкнутые диапазоны столбцов.
Ход коня меняет одну координату на 2, а другую на 1. Чтобы пересечь
промежуток из g столбцов, x должен измениться на g + 1 ≤ 2, а раз доски
не касаются, g = 1, так что x меняется на 2, а y на 1, что возможно
ровно тогда, когда диапазоны строк как замкнутые отрезки имеют общую
точку. Диагональные случаи тоже покрыты: промежуток в одну строку при
столбцах, встречающихся по одной линии, — это второй случай.

Значит, доски образуют граф, а ответ — размер компоненты стартовой
доски в системе непересекающихся множеств. Чтобы найти рёбра, каждая
правая сторона на x = R сопоставляется с левыми сторонами на x = R + 1:
события сортируются по линии, затем по началу отрезка, и поскольку
стороны одного вида на одной линии не пересекаются, каждый отрезок
достаточно сравнить с последним отрезком другого вида. Тот же проход
выполняется для горизонтальных сторон.

В первом примере обе маленькие доски достают до длинной доски над ними
через одну пустую строку, а последняя доска стоит по диагонали с
промежутками по обоим направлениям.

Сортировка даёт O(N log N).
