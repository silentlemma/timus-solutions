# 2216. Наименьшее число лифтов с камерами, через которые проходит любой путь наверх

## Задача

В здании этажи 1 … N и K лифтов, лифт i перемещает между любыми
этажами отрезка [lᵢ, rᵢ]. Поставьте камеры в как можно меньше лифтов,
чтобы каждый, кто идёт с этажа 1 на этаж N, проехал хотя бы в одном
лифте с камерой, или выведите −1. Ограничения: 1 секунда и 256 МБ.

## Входные данные

N и K, 1 ≤ N, K ≤ 10⁵, затем K отрезков.

## Выходные данные

Наименьшее число камер или −1.

## Примеры

### Пример 1

Ввод:

```
1984 1
1 1984
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
2 2
1 2
1 2
```

Вывод:

```
2
```

## Решение

При N = 1 лифт никому не нужен, так что никакая расстановка камер не
подходит, и ответ −1.

Иначе посмотрим на промежуток между этажами f и f + 1. Любой путь из 1
в N должен его пересечь, а пересекают его только лифты с l ≤ f < r, так
что камеры во всех них замечают всех. Обратно, если при какой-то
расстановке над каждым промежутком остаётся хотя бы один лифт без
камеры, то отрезки лифтов без камер перекрываются от 1 до N и образуют
незамеченный путь. Значит, ответ — наименьшее число лифтов над одним
промежутком.

Разностный массив (+1 в l, −1 в r) даёт число лифтов над каждым
промежутком как текущую сумму, и минимум по f = 1 … N − 1 — ответ.

Во втором примере оба лифта пересекают единственный промежуток, так что
камера нужна в обоих.

Это O(N + K).
