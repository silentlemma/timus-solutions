# 2213. 移动机器人程序中的一条指令使累计和最小

[Timus 2213](https://acm.timus.ru/problem.aspx?space=1&num=2213) · 难度 1278 · prefix_sums

原题作者 Ignat Nigmatullin，出自 2024 年大学学术中学生信息学奥林匹克。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

机器人从无限网格的格子 (1, 1) 出发，网格上只有 N × M 矩形内有非零值；机器人执行由 R、D、L、U 组成的程序，并累加经过的每个格子的值（包括起点）。把恰好一条指令移动到程序中的任意位置（也可以是原位置），使和尽可能小，输出新程序。时间限制 1.5 秒，内存限制 256 MB。

## 输入

N 和 M（N · M ≤ 10⁵），绝对值不超过 10⁹ 的网格，然后是长度为 2 … 10⁵ 的程序。

## 输出

一个最优程序。

## 样例

### 样例 1

输入：

```
2 3
1 2 3
1 -1 2
DRULL
```

输出：

```
DRLLU
```

### 样例 2

输入：

```
2 2
-1 1
1 -1
RDULD
```

输出：

```
DULRD
```

### 样例 3

输入：

```
2 3
1 1 1
1 1 1
RRD
```

输出：

```
RRD
```

## 解法

指令从零开始编号，p[k] 表示执行 k 条指令后的位置，f(p) 表示格子的值（矩形外为零）。删除下标 i 处方向为 d 的指令，再插入剩余程序的下标 j 处。包含区间边界的累计和变化为：

- 若 j ≤ i：对 k = j … i 求和，求和项为 f(p[k] + d) − f(p[k + 1])；
- 若 j ≥ i：对 k = i … j 求和，求和项为 f(p[k + 1] − d) − f(p[k])。

这些区间外的访问保持不变。由于 p[i + 1] = p[i] + d，k = i 的求和项为零。

对四个方向中的每一个，两种情况都化为沿路径前缀和上的最优区间问题：

- 把指令提前：对每个存放该指令的位置 i，需要以 i 结尾的区间的最佳起点，由 f(p[k] + d) − f(p[k + 1]) 的前缀和的当前最大值给出；
- 把指令推后：对区间的每个终点，需要它之前该方向指令的最佳位置，由 f(p[k + 1] − d) − f(p[k]) 的前缀和的当前最大值给出，且只考虑存放该指令的起点。

八次扫描中的最佳结果给出要移动的指令及其新位置。程序保持不变总是允许的，所以变化量不会为正。

第一个样例中把下标 2 处的 U 移到末尾，将对 (1, 2) 和 (1, 1) 的访问替换为 (2, 1) 和 (2, 0)，和从 4 降到 2。

易错点（[测试 05](tests/05.in)）：只对 f(p[k] ± d) − f(p[k]) 求和会漏掉边界项。在该测试中，唯一格子的值为 7，RL 和 LR 的得分都是 14；只平移原来的中间格子会错误地预测变化量为 +7，而实际为零。应使用上述公式中相邻的路径下标。

复杂度 O(NM + |S|)。
