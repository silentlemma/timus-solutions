# 2213. 移动机器人程序中的一条指令使累计和最小

[Timus 2213](https://acm.timus.ru/problem.aspx?space=1&num=2213) · 难度 2005 · prefix_sums

原题作者 Ignat Nigmatullin，出自 2024 年大学学术中学生信息学奥林匹克。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

机器人从无限网格的格子 (1, 1) 出发，网格上只有 N × M 矩形内有非零值；机器人执行由 R、D、L、U 组成的程序，并累加经过的每个格子的值（包括起点）。把恰好一条指令移动到程序中的任意位置（也可以是原位置），使和尽可能小，输出新程序。时间限制 1.5 秒，内存限制 256 MB。

## 输入

N 和 M（N · M ≤ 10⁵），绝对值不超过 10⁹ 的网格，然后是长度为 2 … 10⁵ 的程序。

## 输出

一个最优程序。

## 样例

### 样例 1

输入：

```
2 3
1 2 3
1 -1 2
DRULL
```

输出：

```
DRLLU
```

### 样例 2

输入：

```
2 2
-1 1
1 -1
RDULD
```

输出：

```
DULRD
```

### 样例 3

输入：

```
2 3
1 1 1
1 1 1
RRD
```

输出：

```
RRD
```

## 解法

取位置 i 上方向为 d 的指令 c，把它重新插入到位置 j。在两个位置之前和之后经过的格子都不变。若 j > i，两者之间经过的格子是原来的格子平移 −d，因为 d 这一步推迟了；若 j < i，中间的格子平移 +d。所以和的变化是路径上一段连续区间内 cell(p + 平移) − cell(p) 的和。

对四个方向中的每一个，两种情况都化为沿路径前缀和上的最优区间问题：

- 把指令提前：对每个存放该指令的位置 i，需要以 i 结尾的区间的最佳起点，由带平移 +d 的前缀和的当前最大值给出；
- 把指令推后：对区间的每个终点，需要它之前该方向指令的最佳位置，由带平移 −d 的前缀和的当前最大值给出。

八次扫描中的最佳结果给出要移动的指令及其新位置。程序保持不变总是允许的，所以变化量不会为正。

第一个样例中把位置 3 的 U 移到末尾，使路径最后两个格子下移一行，和从 4 降到 2。

复杂度 O(NM + |S|)。
