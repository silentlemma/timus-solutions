# 2213. Перенос одной команды программы робота для наименьшей суммы

[Timus 2213](https://acm.timus.ru/problem.aspx?space=1&num=2213) · сложность 1278 · prefix_sums

Автор оригинальной задачи — Игнат Нигматуллин; Вузовско-академическая олимпиада по информатике 2024.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Робот стартует в клетке (1, 1) бесконечного поля, где ненулевые
значения есть только в прямоугольнике N × M, выполняет программу из
ходов R, D, L и U и прибавляет значение каждой посещённой клетки, включая
стартовую. Перенесите ровно одну команду в любое место программы, можно
на её же место, чтобы сумма стала как можно меньше, и выведите новую
программу. Ограничения: 1.5 секунды и 256 МБ.

## Входные данные

N и M с N · M ≤ 10⁵, поле со значениями не больше 10⁹ по модулю, затем
программа длины 2 … 10⁵.

## Выходные данные

Оптимальная программа.

## Примеры

### Пример 1

Ввод:

```
2 3
1 2 3
1 -1 2
DRULL
```

Вывод:

```
DRLLU
```

### Пример 2

Ввод:

```
2 2
-1 1
1 -1
RDULD
```

Вывод:

```
DULRD
```

### Пример 3

Ввод:

```
2 3
1 1 1
1 1 1
RRD
```

Вывод:

```
RRD
```

## Решение

Нумеруем команды с нуля; p[k] — позиция после k команд, а f(p) —
значение клетки (ноль вне прямоугольника). Удалим команду с направлением
d на позиции i и вставим её на позицию j в оставшейся программе.
Изменение суммы с учётом границ отрезка равно:

- если j ≤ i: сумме по k = j … i величин f(p[k] + d) − f(p[k + 1]);
- если j ≥ i: сумме по k = i … j величин f(p[k + 1] − d) − f(p[k]).

Посещения вне этих отрезков не меняются. Слагаемое при k = i равно
нулю, поскольку p[i + 1] = p[i] + d.

Для каждого из четырёх направлений оба случая сводятся к поиску лучшего
отрезка по префиксной сумме вдоль пути:

- перенос команды раньше требует для каждой позиции i с этой командой
  лучшего начала отрезка, кончающегося в i, — его даёт текущий максимум
  префиксных сумм величин f(p[k] + d) − f(p[k + 1]);
- перенос команды позже требует для каждого конца отрезка лучшей
  позиции команды с этим направлением перед ним — её даёт текущий
  максимум префиксных сумм величин f(p[k + 1] − d) − f(p[k]),
  учитывающий только начала с нужной командой.

Лучший из восьми проходов даёт команду для переноса и её новую позицию.
Оставить программу без изменений всегда можно, так что изменение
никогда не положительно.

В первом примере перенос U с индекса 2 в конец заменяет посещения
(1, 2) и (1, 1) на (2, 1) и (2, 0), уменьшая сумму с 4 до 2.

Ловушка ([тест 05](tests/05.in)): сумма только f(p[k] ± d) − f(p[k])
теряет граничное слагаемое. На единственной клетке со значением 7
программы RL и LR обе дают 14; сдвиг только исходной промежуточной
клетки предсказывает изменение +7 вместо нуля. Нужны соседние индексы
пути из формул выше.

Это O(NM + |S|).
