# 2213. Перенос одной команды программы робота для наименьшей суммы

[Timus 2213](https://acm.timus.ru/problem.aspx?space=1&num=2213) · сложность 2005 · prefix_sums

Автор оригинальной задачи — Игнат Нигматуллин; Вузовско-академическая олимпиада по информатике 2024.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Робот стартует в клетке (1, 1) бесконечного поля, где ненулевые
значения есть только в прямоугольнике N × M, выполняет программу из
ходов R, D, L и U и прибавляет значение каждой посещённой клетки, включая
стартовую. Перенесите ровно одну команду в любое место программы, можно
на её же место, чтобы сумма стала как можно меньше, и выведите новую
программу. Ограничения: 1.5 секунды и 256 МБ.

## Входные данные

N и M с N · M ≤ 10⁵, поле со значениями не больше 10⁹ по модулю, затем
программа длины 2 … 10⁵.

## Выходные данные

Оптимальная программа.

## Примеры

### Пример 1

Ввод:

```
2 3
1 2 3
1 -1 2
DRULL
```

Вывод:

```
DRLLU
```

### Пример 2

Ввод:

```
2 2
-1 1
1 -1
RDULD
```

Вывод:

```
DULRD
```

### Пример 3

Ввод:

```
2 3
1 1 1
1 1 1
RRD
```

Вывод:

```
RRD
```

## Решение

Возьмём команду c с направлением d на позиции i и вставим её на позицию
j. Клетки, посещённые до обеих позиций и после обеих, не меняются. Если
j > i, клетки между ними — исходные, сдвинутые на −d, ведь шаг d
теперь делается позже; если j < i, клетки между ними сдвинуты на +d.
Значит, изменение суммы — сумма по непрерывному отрезку пути от
cell(p + сдвиг) − cell(p).

Для каждого из четырёх направлений оба случая сводятся к поиску лучшего
отрезка по префиксной сумме вдоль пути:

- перенос команды раньше требует для каждой позиции i с этой командой
  лучшего начала отрезка, кончающегося в i, — его даёт текущий максимум
  префиксных сумм со сдвигом +d;
- перенос команды позже требует для каждого конца отрезка лучшей
  позиции команды с этим направлением перед ним — её даёт текущий
  максимум префиксных сумм со сдвигом −d.

Лучший из восьми проходов даёт команду для переноса и её новую позицию.
Оставить программу без изменений всегда можно, так что изменение
никогда не положительно.

В первом примере перенос U с позиции 3 в конец сдвигает две последние
клетки пути на строку вниз и уменьшает сумму с 4 до 2.

Это O(NM + |S|).
