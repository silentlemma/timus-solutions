# 2209. Stern–Brocot 树第 N 层的第 M 个分数

[Timus 2209](https://acm.timus.ru/problem.aspx?space=1&num=2209) · 难度 1558 · math

原题作者 Vadim Barinov，出自 2023 年大学学术中学生信息学奥林匹克。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

Stern–Brocot 树的根是 1/1，两侧边界是 0/1 和 1/0，每个结点是它最近的左祖先与右祖先的中间分数。求深度 N 上从左数第 M 个分数。时间限制 0.5 秒，内存限制 256 MB。

## 输入

N 和 M（1 ≤ N ≤ 10⁹，1 ≤ M ≤ min(2^(N−1), 10⁹)）。

## 输出

分子和分母。

## 样例

### 样例 1

输入：

```
1 1
```

输出：

```
1 1
```

### 样例 2

输入：

```
3 3
```

输出：

```
3 2
```

### 样例 3

输入：

```
5 7
```

输出：

```
5 7
```

## 解法

深度 N 上有 2^(N−1) 个结点，从根到其中第 M 个结点的路径就是用 N − 1 位二进制写出的 M − 1，0 表示向左，1 表示向右。向下走时保存当前结点的两个边界 a/b 和 c/d，结点本身为 (a + c)/(b + d)：向左一步使该结点成为新的右边界，向右一步使它成为新的左边界。

N 可以达到 10⁹，但 M ≤ 10⁹ 意味着这些位中至多 30 个是 1，所以路径以 N − 1 − k 个 0 开头，其中 k 是 M − 1 的二进制位数。从根向左走 z 次只会把右边界变为 1/z，所以从边界 0/1 和 1/z（z = 0 时为 1/0）出发，只需处理最后 k 位。

数值的增长不超过 z 乘以 30 步的斐波那契数，远在 64 位范围内。

第二个样例中 M − 1 = 2，两位二进制为 10：先向右到 2/1，再向左到 3/2。

复杂度 O(log M)。
