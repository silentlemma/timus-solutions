# 2209. M-я дробь на уровне N дерева Штерна–Броко

## Задача

В корне дерева Штерна–Броко стоит 1/1, по краям — 0/1 и 1/0, и каждая
вершина — медианта ближайших левого и правого предков. Найдите M-ю слева
дробь на глубине N. Ограничения: 0.5 секунды и 256 МБ.

## Входные данные

N и M, 1 ≤ N ≤ 10⁹, 1 ≤ M ≤ min(2^(N−1), 10⁹).

## Выходные данные

Числитель и знаменатель.

## Примеры

### Пример 1

Ввод:

```
1 1
```

Вывод:

```
1 1
```

### Пример 2

Ввод:

```
3 3
```

Вывод:

```
3 2
```

### Пример 3

Ввод:

```
5 7
```

Вывод:

```
5 7
```

## Решение

На глубине N стоит 2^(N−1) вершин, и путь от корня к M-й из них — это
M − 1, записанное N − 1 двоичными цифрами: 0 — шаг влево, 1 — вправо.
При спуске храним две границы a/b и c/d текущей вершины, сама вершина —
(a + c)/(b + d): шаг влево делает вершину новой правой границей, шаг
вправо — новой левой.

N может быть 10⁹, но M ≤ 10⁹ означает, что единиц среди цифр не больше
30, так что путь начинается с N − 1 − k нулей, где k — длина M − 1 в
битах. Спуск от корня влево z раз меняет только правую границу на 1/z,
так что обход начинается с границ 0/1 и 1/z (1/0 при z = 0) и
обрабатывает лишь последние k цифр.

Числа растут не быстрее чем z, умноженное на число Фибоначчи за
30 шагов, — с запасом в 64 битах.

Во втором примере M − 1 = 2 = 10 в двоичной записи на двух цифрах:
вправо к 2/1, затем влево к 3/2.

Это O(log M).
