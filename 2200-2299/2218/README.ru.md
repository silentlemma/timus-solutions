# 2218. Подсчёт точек на точном манхэттенском расстоянии

## Задача

N различных компьютеров стоят в целых точках. Бегун в (x, y) должен
пробежать ровно d, двигаясь вдоль осей, и не может бежать к компьютеру,
который ближе d. Для каждого из Q бегунов посчитайте компьютеры на
манхэттенском расстоянии ровно d. Ограничения: 3 секунды и 256 МБ.

## Входные данные

N, 1 ≤ N ≤ 10⁵, затем компьютеры, затем Q, 1 ≤ Q ≤ 10⁵, и бегуны x, y, d
с координатами не больше 10⁹ по модулю и 0 ≤ d ≤ 4 · 10⁹.

## Выходные данные

Число для каждого бегуна.

## Примеры

### Пример 1

Ввод:

```
5
0 0
1 1
2 0
1 -1
1 0
4
1 0 1
2 2 2
5 1 5
0 1 4
```

Вывод:

```
4
2
1
0
```

## Решение

Повернём координаты: u = x + y и v = x − y. Манхэттенское расстояние
становится max(|Δu|, |Δv|), так что точки на расстоянии ровно d лежат
на границе квадрата со сторонами вдоль осей: две вертикальные стороны
u = U ± d с |v − V| ≤ d и две горизонтальные v = V ± d с |u − U| < d,
углы учитываются вместе с вертикальными сторонами.

Отсортируем точки по (u, v) и отдельно по (v, u). Тогда каждая сторона
— непрерывный отрезок в одном из списков, и два двоичных поиска считают
её. При d = 0 подходит только точка самого бегуна.

В примере бегун в (1, 0) с d = 1 добегает до четырёх соседей (0, 0),
(1, 1), (2, 0) и (1, −1).

Сортировка занимает O(N log N), а каждый бегун — восемь двоичных
поисков.
