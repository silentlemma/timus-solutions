# 2227. Замеры и разрезы выпуклого многоугольника по диагоналям

[Timus 2227](https://acm.timus.ru/problem.aspx?space=1&num=2227) · сложность 1200 · geometry, fenwick

Автор оригинальной задачи — Вадим Баринов.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Выпуклый многоугольник из N вершин получает Q действий по диагоналям
текущего многоугольника: замер сообщает большую из двух площадей, а
разрез выбрасывает меньшую часть (при равенстве — часть с вершиной,
номер которой вне выбранной пары) и сообщает её площадь. Выведите все
сообщённые площади с точностью 10⁻⁹. Ограничения: 0.5 секунды и 256 МБ.

## Входные данные

N и Q, 4 ≤ N ≤ 10⁵, 1 ≤ Q ≤ 10⁵, затем вершины против часовой стрелки с
координатами не больше 10⁹ по модулю, затем действия «m l r» или
«c l r».

## Выходные данные

Одна площадь на каждое действие.

## Примеры

### Пример 1

Ввод:

```
5 4
2 0
3 1
2 2
0 2
0 0
m 5 3
m 2 4
c 1 3
m 4 1
```

Вывод:

```
3.0
4.0
1.0
2.0
```

## Решение

Все площади хранятся удвоенными, точными целыми, так что каждый ответ
оканчивается на «.0» или «.5». При l < r удвоенная площадь
многоугольника l, l + 1, …, r из исходных вершин — отрезок префиксных
сумм формулы шнурования плюс замыкающее слагаемое x_r y_l − y_r x_l.

Разрезы только убирают куски, и каждый кусок, отрезанный диагональю
текущего многоугольника, лежит по одну сторону от любой следующей
диагонали. Кусок, отрезанный от дуги l … r, записывается на первое ребро
этой дуги l + 1 в дереве Фенвика; кусок снаружи дуги записывается на
ребро r + 1, вне любой следующей дуги. Для следующей диагонали (l, r)
часть текущего многоугольника на внутренней дуге — исходная площадь дуги
минус записи на рёбрах l + 1 … r, а другая часть — текущая общая площадь
минус она.

Замер выводит большую часть. Разрез выбрасывает меньшую часть или
внешнюю при равенстве, записывает её, как описано, и уменьшает общую
площадь.

В примере первый замер делит пятиугольник площади 5 по диагонали 5–3 на
части 3 и 2 и выводит 3.

Это O(N + Q log N).
