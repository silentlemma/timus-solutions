# 2206. Взаимно простые точки решётки внутри выпуклого многоугольника

## Задача

Дан выпуклый многоугольник из N вершин с координатами ровно с тремя
знаками после запятой. Посчитайте точки (x, y) с натуральными взаимно
простыми координатами внутри него или на границе. Ограничения:
4.5 секунды и 512 МБ.

## Входные данные

N, 3 ≤ N ≤ 2 · 10⁵, затем вершины против часовой стрелки, каждая
координата от 1 до 2 · 10⁶.

## Выходные данные

Число взаимно простых точек.

## Примеры

### Пример 1

Ввод:

```
3
1.000 1.000
3.000 1.000
1.000 3.000
```

Вывод:

```
5
```

## Решение

Умножим все координаты на 1000, чтобы они стали целыми. В каждом
целочисленном столбце x многоугольник покрывает один отрезок по y между
нижней и верхней цепочками. Проходя каждое ребро по целым столбцам,
которые оно покрывает, точное целочисленное деление даёт
upper(x) = ⌊верх⌋ и lower(x) = ⌈низ⌉ − 1, так что в столбце
upper(x) − lower(x) целых точек; вертикальное ребро ничего нового не
добавляет.

Среди них точки с gcd(x, y) = 1 считаются обращением Мёбиуса по общему
делителю d:

Σ по d от μ(d) · Σ по столбцам x, делящимся на d, от
(⌊upper(x) / d⌋ − ⌊lower(x) / d⌋).

Пусть R = ⌊max x⌋ — самый правый целочисленный столбец в исходных
координатах, R ≤ 2 · 10⁶. Для каждого d внутренняя сумма обходит не более
⌊R / d⌋ столбцов, что суммарно даёт O(R log R) операций. Массивы границ
содержат R + 1 элементов, а решето вычисляет μ до min(R, max upper(x)).
При d > R / 2 единственное возможное кратное — столбец x = d; в Python
он обрабатывается одним слагаемым.

Ловушка (тест gen5): даже маленькому многоугольнику у границы допустимых
координат нужны массивы и решето с абсолютной индексацией. Его ширина
не ограничивает их размер или общее время работы.

В примере треугольник содержит (1, 1), (1, 2), (1, 3), (2, 1), (2, 2) и
(3, 1), и не взаимно проста только (2, 2), так что ответ 5.

Время работы O(N + R log R), память O(N + R).
