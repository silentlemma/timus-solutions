# 2223. 用异或和进位实现的加法要调用几次

[Timus 2223](https://acm.timus.ru/problem.aspx?space=1&num=2223) · 难度 936 · bitmask

原题作者 Vadim Barinov，出自 2025 年乌拉尔锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

递归函数 f(x, y) 在 y = 0 时返回 x，否则调用 f(x xor y, (x and y) << 1)，整数没有位数限制。对以二进制给出、至多 10⁶ 位的正整数 X 和 Y，输出调用 f(X, Y) 时的调用次数，或输出 "infinity"。时间限制 1 秒，内存限制 256 MB。

## 输入

二进制的 X 和 Y（1 ≤ X, Y < 2^1000000）。

## 输出

调用次数。

## 样例

### 样例 1

输入：

```
1011
100
```

输出：

```
2
```

### 样例 2

输入：

```
101
1
```

输出：

```
3
```

## 解法

这是通过反复传播进位来做加法：x xor y 是不计进位的和，(x and y) << 1 是进位。和 x + y 始终不变，两个参数都保持非负，所以递归总会结束，对这样的输入不会出现 "infinity"。

进位产生于两个数都为 1 的位，之后每次调用把它上移一位，只要上面那一位恰好在一个数中为 1。它停在第一个两数相同的位：两个 0 吸收它，两个 1 则是另一个进位产生的地方。所以进位非零的轮数，就是由一个公共 1 及其上方连续若干个不同位组成的最长链的长度（包括那个公共位）。

从最高位开始扫描一次，记录当前连续不同位的长度；每遇到一个公共 1 就结束一条长度为该值加一的链，每遇到相同的位就把计数清零。答案是最长链加 2：第一次调用和 y = 0 的最后一次调用。

第二个样例中 101 + 1 在最低位有公共 1，其上一位在两个数中都是 0，所以链长为 1，共调用 3 次。

对 L 位二进制数，复杂度 O(L)。
