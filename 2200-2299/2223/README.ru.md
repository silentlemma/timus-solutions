# 2223. Сколько вызовов делает сложение через XOR и перенос

## Задача

Рекурсивная функция f(x, y) возвращает x при y = 0, а иначе вызывает
f(x xor y, (x and y) << 1) для неограниченных целых. Для натуральных X и
Y, заданных в двоичной записи до 10⁶ цифр, выведите число вызовов при
f(X, Y) или «infinity». Ограничения: 1 секунда и 256 МБ.

## Входные данные

X и Y в двоичной записи, 1 ≤ X, Y < 2^1000000.

## Выходные данные

Число вызовов.

## Примеры

### Пример 1

Ввод:

```
1011
100
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
101
1
```

Вывод:

```
3
```

## Решение

Это сложение повторным распространением переносов: x xor y — сумма без
переносов, а (x and y) << 1 — перенос. Сумма x + y не меняется, и оба
аргумента остаются неотрицательными, так что рекурсия всегда
заканчивается, и «infinity» для таких входных данных не бывает.

Перенос рождается в бите, где у обоих чисел 1, и каждый следующий вызов
сдвигает его на бит вверх, пока бит выше равен 1 ровно в одном из
чисел. Он останавливается на первом бите, одинаковом в обоих: два нуля
его поглощают, а две единицы — место, где рождается другой перенос.
Значит, число раундов с ненулевым переносом — длина самой длинной
цепочки из общей единицы и серии различающихся битов над ней, считая
общий бит.

Один проход от старшего бита хранит длину текущей серии различающихся
битов; на каждой общей единице он закрывает цепочку такой длины плюс
один, а каждый одинаковый бит обнуляет серию. Ответ — самая длинная
цепочка плюс 2: за первый вызов и за последний с y = 0.

Во втором примере у 101 + 1 общая единица в младшем бите, а бит над ней
равен 0 в обоих числах, так что цепочка длины 1 и вызовов 3.

Это O(L) для L двоичных цифр.
