# 2224. Двое игроков на полосе 2 × N без повторных клеток

[Timus 2224](https://acm.timus.ru/problem.aspx?space=1&num=2224) · сложность 1477 · games

Автор оригинальной задачи — Вадим Баринов; Чемпионат Урала 2025.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Двое игроков стоят в разных клетках доски 2 × N и ходят по очереди,
первым Blue, каждый раз в соседнюю по стороне клетку, в которой никто
не был и которая не занята. Кто не может сделать ход, проигрывает. Кто
выиграет при оптимальной игре? Ограничения: 0.5 секунды и 256 МБ.

## Входные данные

N, 3 ≤ N ≤ 10⁹, затем клетка Blue и клетка Red.

## Выходные данные

Blue или Red.

## Примеры

### Пример 1

Ввод:

```
3
1 2
2 3
```

Вывод:

```
Blue
```

### Пример 2

Ввод:

```
3
1 1
2 1
```

Вывод:

```
Red
```

## Решение

Отразим доску так, чтобы Blue был не правее Red. Пусть left — число
столбцов левее Blue, right — число столбцов правее Red, а gap —
расстояние между их столбцами. Хвост из k свободных столбцов позади
игрока даёт до 2k ходов змейкой, так что игра идёт за то, кто сохранит
более длинный хвост, а клетки между игроками решают, кому придётся
уступить первым.

- **Одна строка.** Каждый игрок может сразу уйти в свой хвост, а
  середина общая. Blue выигрывает с более длинным хвостом, а при равных
  хвостах — ровно при чётном gap, потому что тогда именно Blue первым
  доходит до середины и забирает лишние клетки.
- **Разные строки.** При gap 0 игроки стоят в одном столбце, и Red может
  отвечать на каждый ход симметрично, так что выигрывает Red; равные
  хвосты тоже позволяют Red зеркалить Blue, и выигрывает Red. При gap 1
  Blue шагает по диагонали перед Red и отрезает строку Red, и выигрывает
  Blue. Когда хвосты различаются ровно на один столбец, всё решает гонка
  через середину, и Blue выигрывает ровно при нечётном gap. Иначе
  выигрывает более длинный хвост.

Эти правила проверены полным перебором минимакса по всем начальным
позициям на всех досках от 2 × 3 до 2 × 8.

В первом примере Blue в соседнем столбце в другой строке и выигрывает,
а во втором игроки в одном столбце, и выигрывает Red.

Это O(1).
