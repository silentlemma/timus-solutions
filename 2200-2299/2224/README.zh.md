# 2224. 两名玩家在 2 × N 条带上不走回头路的比赛

[Timus 2224](https://acm.timus.ru/problem.aspx?space=1&num=2224) · 难度 1477 · games

原题作者 Vadim Barinov，出自 2025 年乌拉尔锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两名玩家站在 2 × N 棋盘的不同格子上，轮流移动，Blue 先手，每次移到一个边相邻、没人到过且未被占据的格子。不能移动的玩家输。双方都最优时谁获胜？时间限制 0.5 秒，内存限制 256 MB。

## 输入

N（3 ≤ N ≤ 10⁹），然后是 Blue 的格子和 Red 的格子。

## 输出

Blue 或 Red。

## 样例

### 样例 1

输入：

```
3
1 2
2 3
```

输出：

```
Blue
```

### 样例 2

输入：

```
3
1 1
2 1
```

输出：

```
Red
```

## 解法

翻转棋盘使 Blue 不在 Red 的右边。设 left 为 Blue 左边的列数，right 为 Red 右边的列数，gap 为两人所在列的距离。玩家身后 k 个空列的尾部可以蛇形走出至多 2k 步，所以比赛的关键是谁保住更长的尾部，而两人之间的格子决定谁先被迫让步。

- **同一行。** 每名玩家都能立刻走进自己的尾部，中间部分是共享的。Blue 在尾部更长时获胜；尾部相等时当且仅当 gap 为偶数时获胜，因为此时是 Blue 先到达中间并拿走多出的格子。
- **不同行。** gap 为 0 时两人在同一列，Red 可以对每一步作对称回应，所以 Red 获胜；尾部相等时 Red 也能镜像 Blue，Red 获胜。gap 为 1 时 Blue 斜着走到 Red 前面，切断 Red 所在的行，Blue 获胜。当尾部恰好相差一列时，由穿过中间的竞速决定，Blue 当且仅当 gap 为奇数时获胜。其余情况尾部更长的一方获胜。

这些规则已与 2 × 3 到 2 × 8 所有棋盘上所有初始局面的完全极小极大搜索核对过。

第一个样例中 Blue 在另一行的相邻列，Blue 获胜；第二个样例中两人在同一列，Red 获胜。

复杂度 O(1)。
