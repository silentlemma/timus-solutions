# 2214. 可移动 K 次的滑动窗口的最大收益

[Timus 2214](https://acm.timus.ru/problem.aspx?space=1&num=2214) · 难度 1278 · dp

原题作者 Vladimir Cherepanov，出自 2024 年大学学术中学生信息学奥林匹克。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

照射器覆盖 N 株植物中连续的 L 株，第 i 天给每株被覆盖的植物 j 增加 a_ij。它可以放在任何位置，并且每天至多一次、总共至多 K 次，可以在一天中途移动；那一天旧位置和新位置都算，每株植物只算一次。求 M 天的最大总收益。时间限制 3.5 秒，内存限制 256 MB。

## 输入

N、M、L 和 K（1 ≤ N ≤ 5000，1 ≤ M ≤ 100，1 ≤ L ≤ N，0 ≤ K ≤ M），然后是 M × N 个 0 到 10⁹ 的值。

## 输出

最大总收益。

## 样例

### 样例 1

输入：

```
3 4 2 1
3 2 0
4 1 1
0 3 7
2 1 1
```

输出：

```
23
```

## 解法

状态为（天，已用移动次数，当天结束时的位置）。移动到原位置不改变任何东西，所以任何方案都可以补足到恰好 K 次移动，因此只保留到最后一天仍能达到 K 的移动次数。

借助当天这一行的前缀和，不移动的一天增加窗口和 w(x)。从 x 移到 y 的一天增加两个窗口的并：

- 若 |x − y| < L，并是一个区间，值为 prefix(较大终点) − prefix(较小起点)，可拆成只与 x 有关的项和只与 y 有关的项；对每个 y 最好的 x 是最近 L 个位置上的滑动窗口最大值，用单调队列维护，x 在 y 左边和右边各做一次；
- 若两个窗口不相交，值为 w(x) + w(y)，而距离至少为 L 的 x 中最好的 dp(x) + w(x) 是一个前缀最大值。

每层代价 O(N)。第 i 天保留的移动次数从 max(0, K − (M − i)) 到 min(i, K)，总共处理 (K + 1)(M − K + 1) − 1 层。M · (K + 1) 是上界，并非准确层数：测试 03 中 M = K = 1，只有一层。

样例中照射器先覆盖植物 1 和 2，在第二天中途移到 2 和 3，三株植物最终为 7、7 和 9，共 23。

时间 O(N M (K + 1))，辅助内存 O(N (K + 1))。C++ 和 Java 流式读取输入；Python、Go 和 Rust 还保留 O(N M) 的输入，因此总内存为 O(N M + N (K + 1))。一个陷阱是 K = 0 时漏掉 +1（测试 06）：仍然必须读取所有行并更新固定窗口的得分。
