# 2214. Наибольшая выгода от скользящего окна, которое можно сдвинуть K раз

[Timus 2214](https://acm.timus.ru/problem.aspx?space=1&num=2214) · сложность 1278 · dp

Автор оригинальной задачи — Владимир Черепанов; Вузовско-академическая олимпиада по информатике 2024.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Излучатель накрывает L подряд идущих растений из N и в день i
добавляет a_ij каждому накрытому растению j. Его ставят куда угодно, и
не чаще раза в день, всего не больше K раз, его можно переставить в
середине дня; тогда в этот день считаются и старая, и новая позиции,
каждое растение один раз. Найдите наибольшую сумму за M дней.
Ограничения: 3.5 секунды и 256 МБ.

## Входные данные

N, M, L и K, 1 ≤ N ≤ 5000, 1 ≤ M ≤ 100, 1 ≤ L ≤ N, 0 ≤ K ≤ M, затем
M × N значений от 0 до 10⁹.

## Выходные данные

Наибольшая сумма.

## Примеры

### Пример 1

Ввод:

```
3 4 2 1
3 2 0
4 1 1
0 3 7
2 1 1
```

Вывод:

```
23
```

## Решение

Состояние — (день, использовано перестановок, позиция в конце дня).
Перестановка на ту же позицию ничего не меняет, так что любой план можно
дополнить до ровно K перестановок, и хранятся только числа перестановок,
из которых ещё можно дойти до K к последнему дню.

С префиксными суммами строки дня день без перестановки добавляет сумму
окна w(x). День с перестановкой из x в y добавляет объединение двух окон:

- если |x − y| < L, объединение — один отрезок со значением
  prefix(max конец) − prefix(min начало), которое распадается на
  слагаемое от x и слагаемое от y; лучший x для каждого y — максимум в
  скользящем окне по последним L позициям, который хранится монотонной
  декой, один раз для x левее y и один раз для x правее y;
- если окна не пересекаются, значение равно w(x) + w(y), а лучшее
  dp(x) + w(x) по x не ближе L — текущий префиксный максимум.

Каждый слой стоит O(N). В день i хранятся числа перестановок от
max(0, K − (M − i)) до min(i, K), всего (K + 1)(M − K + 1) − 1
обработанных слоёв. M · (K + 1) — верхняя граница, а не точное число:
в тесте 03 при M = K = 1 слой только один.

В примере излучатель накрывает растения 1 и 2, в середине второго дня
переставляется на 2 и 3, и растения стоят 7, 7 и 9, всего 23.

Это O(N M (K + 1)) времени и O(N (K + 1)) вспомогательной памяти.
C++ и Java читают вход потоком; Python, Go и Rust также хранят вход
размером O(N M), поэтому их полная память — O(N M + N (K + 1)). Ловушка —
забыть +1 при K = 0 (тест 06): всё равно нужно прочитать все строки и
обновить суммы для неподвижных окон.
