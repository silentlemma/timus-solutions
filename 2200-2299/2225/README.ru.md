# 2225. Наименьшее число ударов молотком на два гвоздя

[Timus 2225](https://acm.timus.ru/problem.aspx?space=1&num=2225) · сложность 1110 · dsu, sorting

Автор оригинальной задачи — Вадим Баринов; Чемпионат Урала 2025.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N гвоздей торчат на lᵢ сантиметров. Удар приходится на два соседних
гвоздя: более высокий опускается на 1, а если они одной высоты — оба.
Найдите наименьшее число ударов, чтобы забить все гвозди. Ограничения:
1 секунда и 256 МБ.

## Входные данные

N, 2 ≤ N ≤ 10⁵, затем l₁ … l_N с 1 ≤ lᵢ ≤ 10⁹.

## Выходные данные

Наименьшее число ударов.

## Примеры

### Пример 1

Ввод:

```
3
4 1 3
```

Вывод:

```
7
```

### Пример 2

Ввод:

```
4
2 2 6 6
```

Вывод:

```
8
```

## Решение

Будем смотреть на гвозди по уровням сверху вниз. На уровне h гвозди
высотой не меньше h образуют максимальные серии соседей. Удар опускает
не больше двух гвоздей, причём только два гвоздя одной высоты, стоящие
рядом, так что серии из k гвоздей на этом уровне нужно ⌈k / 2⌉ ударов, и
забивание серий уровень за уровнем сверху достигает ровно этого числа.
Ответ — сумма ⌈k / 2⌉ по всем сериям всех уровней, что подтверждает и
перебор на маленьких случаях.

Уровней до 10⁹, но серии меняются только на высотах гвоздей. Обработаем
гвозди от самого высокого вниз и будем объединять каждый с уже
обработанными соседями в системе непересекающихся множеств. Новый гвоздь
— серия длины 1, добавляющая 1 на каждом уровне до своей высоты, то есть
он добавляет свою высоту. Объединение двух серий превращает
⌈a / 2⌉ + ⌈b / 2⌉ в ⌈(a + b) / 2⌉, на единицу меньше ровно тогда, когда
обе длины нечётны, а объединённая серия живёт на всех уровнях до текущей
высоты, так что такое объединение вычитает текущую высоту.

В первом примере на уровнях стоят серии {1} на высоте 4, {1} и {3} на
высотах 3 и 2 и {1, 2, 3} на высоте 1, так что ответ
1 + 2 + 2 + 2 = 7.

Сортировка даёт O(N log N).
