# 2225. 一次敲两颗钉子的锤子最少要敲几下

[Timus 2225](https://acm.timus.ru/problem.aspx?space=1&num=2225) · 难度 1110 · dsu, sorting

原题作者 Vadim Barinov，出自 2025 年乌拉尔锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 颗钉子分别露出 lᵢ 厘米。一锤落在相邻的两颗钉子上：较高的那颗下降 1 厘米，若两颗一样高则都下降。求把所有钉子敲进去的最少锤数。时间限制 1 秒，内存限制 256 MB。

## 输入

N（2 ≤ N ≤ 10⁵），然后是 l₁ … l_N（1 ≤ lᵢ ≤ 10⁹）。

## 输出

最少锤数。

## 样例

### 样例 1

输入：

```
3
4 1 3
```

输出：

```
7
```

### 样例 2

输入：

```
4
2 2 6 6
```

输出：

```
8
```

## 解法

从上往下按层看钉子。在第 h 层，高度至少为 h 的钉子构成若干极大的相邻段。一锤至多压下两颗钉子，而且只有相邻且等高的两颗才会同时下降，所以该层长为 k 的段需要 ⌈k / 2⌉ 锤，而从上到下逐层敲各段恰好达到这个数目。答案是所有层所有段的 ⌈k / 2⌉ 之和，小规模情形的暴力验证也确认了这一点。

层数可达 10⁹，但段只在钉子的高度处变化。把钉子从最高到最低处理，用并查集把每颗钉子与已处理的邻居合并。新钉子是长度为 1 的段，在不超过其高度的每一层贡献 1，即贡献它的高度。合并两段把 ⌈a / 2⌉ + ⌈b / 2⌉ 变成 ⌈(a + b) / 2⌉，当且仅当两段长度都是奇数时少 1，而合并后的段在不超过当前高度的所有层都存在，所以这次合并减去当前高度。

第一个样例中，高度 4 层有段 {1}，高度 3 和 2 层有段 {1} 和 {3}，高度 1 层有段 {1, 2, 3}，所以答案为 1 + 2 + 2 + 2 = 7。

排序使复杂度为 O(N log N)。
