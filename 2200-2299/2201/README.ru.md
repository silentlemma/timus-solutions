# 2201. Чат-сервер, где каждое gl и hf меняет удачу читателей

[Timus 2201](https://acm.timus.ru/problem.aspx?space=1&num=2201) · сложность 1875 · parsing, prefix_sums

Автор оригинальной задачи — Вадим Баринов; Вузовско-академическая олимпиада по информатике 2020.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Игровой сервер обрабатывает N команд чата: вход, выход, число игроков
онлайн, общее сообщение, личное сообщение и две команды сравнения для
admin. Сообщения состоят из пар «gl» и «hf», и каждый читатель, который
в сети, умножает свою удачу на A за каждое «gl» и делит на B за каждое
«hf»; на авторов это не действует. Выведите ответ сервера на каждую
команду, включая сравнения удачи двух игроков. Ограничения:
2.5 секунды и 256 МБ.

## Входные данные

N, M, A и B, 1 ≤ N ≤ 86400, 2 ≤ M ≤ 10, 1 ≤ A, B ≤ 10⁹, затем N строк
лога «[hh:mm:ss] NICK: /command».

## Выходные данные

Ответ сервера на каждую команду.

## Решение

Удача игрока равна A^g / B^f, где g и f — число пар, прочитанных игроком, так
что достаточно хранить два счётчика. Общие сообщения доходят сразу до
всех в сети, поэтому они идут в два общих итога, а каждый игрок хранит
счётчики относительно них: при входе итоги вычитаются, при выходе
прибавляются обратно, а автор общего сообщения вычитает свои пары. Для
двух игроков в сети итоги тогда сокращаются, и разница удачи задаётся
двумя целыми Δg и Δf. Личные сообщения меняют только счётчики
получателя.

Сравнение A^Δg и B^Δf по логарифмам ломается рядом с равенством: при
A = 5, B = 34, Δg = 165363 и Δf = 75472 логарифмы различаются всего на
9 · 10⁻⁹, и допуск вроде 10⁻⁶ назвал бы две разные удачи равными.
Поэтому равенство проверяется точно. Запишем A = r^s и B = q^t с
наибольшими возможными показателями. Если A^Δg = B^Δf при A, B > 1, то
оба — степени одного целого, и тогда r = q, так что равенство выполнено
ровно при r = q и s·Δg = t·Δf либо при Δg = Δf = 0 для несвязанных
оснований; основание 1 просто выпадает. Только когда удачи различны,
используется знак Δg·ln A − Δf·ln B, и двойная точность различает
разницы гораздо меньше этих 9 · 10⁻⁹.

Остальное — аккуратный разбор: короткие и длинные имена команд, тексты
ответов и порядок проверок для сравнений.

Каждая команда, кроме чтения строки, занимает O(1), так что весь лог
обрабатывается за линейное время.
