# 2217. 通过排序子串把二进制串变成回文

[Timus 2217](https://acm.timus.ru/problem.aspx?space=1&num=2217) · 难度 549 · prefix_sums

原题作者 Timofey Imaev，出自 2025 年 ICPC 乌拉尔赛区资格赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

长度为 N 的二进制串 S 可以任意多次把它的任意子串按非降序排序。能否得到回文？时间限制 1 秒，内存限制 256 MB。

## 输入

N（1 ≤ N ≤ 10⁵），然后是 S。

## 输出

YES 或 NO。

## 样例

### 样例 1

输入：

```
12
010110110100
```

输出：

```
YES
```

### 样例 2

输入：

```
1
1
```

输出：

```
YES
```

### 样例 3

输入：

```
2
10
```

输出：

```
NO
```

## 解法

排序子串只会把 0 往左移，而且可以一次只做一个相邻交换 "10" → "01"。所以计数相同的串 T 可达，当且仅当 T 的每个前缀中 0 的个数都不少于 S 的同一前缀。

回文的前 k 个字符和后 k 个字符中 0 的个数相同。对可达的回文 P，P 前 k 个字符中的 0 不少于 S 的，后 k 个字符中的 0 不多于 S 的，因为 0 只会离开末尾。所以对所有不超过 N / 2 的 k：

S 后 k 个字符中 0 的个数 ≥ 前 k 个字符中 0 的个数。

另外，N 为偶数时 0 两两配对，个数必须是偶数；N 为奇数时由中间字符处理奇偶性。这两个条件也是充分的。设 Z 为 0 的总数，m = floor(N / 2)，h = floor(Z / 2)，A(k)、B(k) 分别为 S 前 k 个和后 k 个字符中 0 的个数。由上述条件可得，k ≤ m 时 A(k) ≤ h，且 B(m) ≥ h。选择 P 的前半部分，使其每个长度为 k 的前缀恰有 Q(k) = min(B(k), h) 个 0。该计数从 0 开始，每加入一个字符最多增加 1，最终等于 h。将这一半镜像；若 N 为奇数，则仅当 Z 为奇数时将中间字符设为 0。由于 A(k) ≤ Q(k) ≤ B(k)，前后两半都满足可达性约束，因此这个回文可达。

从两端同时扫描一次，维护两个 0 计数的差，一旦为负就输出 NO。

易错点（测试 12）：仅满足配对要求并不能保证目标可达。S = "1001" 本身就是回文，所以答案为 YES；但把 0 在配对允许的范围内尽量左移得到的 "0110" 不可达，因为它的前两个字符中 0 的个数少于 S。

第三个样例中 "10" 只有一个 0，偶数长度下个数为奇数，所以答案为 NO。

复杂度 O(N)。
