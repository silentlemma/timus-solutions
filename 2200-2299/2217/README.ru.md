# 2217. Получение палиндрома сортировкой подстрок двоичной строки

[Timus 2217](https://acm.timus.ru/problem.aspx?space=1&num=2217) · сложность 549 · prefix_sums

Автор оригинальной задачи — Тимофей Имаев; Квалификационный тур Уральского регионального чемпионата ICPC 2025.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В двоичной строке S длины N можно сколько угодно раз сортировать любую
подстроку по неубыванию. Можно ли получить палиндром? Ограничения:
1 секунда и 256 МБ.

## Входные данные

N, 1 ≤ N ≤ 10⁵, затем S.

## Выходные данные

YES или NO.

## Примеры

### Пример 1

Ввод:

```
12
010110110100
```

Вывод:

```
YES
```

### Пример 2

Ввод:

```
1
1
```

Вывод:

```
YES
```

### Пример 3

Ввод:

```
2
10
```

Вывод:

```
NO
```

## Решение

Сортировка подстроки только сдвигает нули влево, и её можно сделать по
одному соседнему обмену «10» → «01». Значит, строка T с теми же
количествами достижима ровно тогда, когда в каждом префиксе T нулей не
меньше, чем в том же префиксе S.

У палиндрома в первых k символах столько же нулей, сколько в последних
k. Для достижимого палиндрома P в первых k символах P нулей не меньше,
чем у S, а в последних k — не больше, чем у S, ведь нули только уходят
из конца. Значит, для всех k до N / 2:

нулей в последних k символах S ≥ нулей в первых k символах.

Кроме того, при чётном N нули разбиваются на пары, так что их число
должно быть чётным; при нечётном N чётность берёт на себя средний
символ. Эти два условия и достаточны. Пусть Z — общее число нулей,
m = floor(N / 2), h = floor(Z / 2), а A(k) и B(k) — числа нулей в
первых и последних k символах S. Из условий следует A(k) ≤ h при
k ≤ m и B(m) ≥ h. Выберем первую половину P так, чтобы в каждом её
префиксе длины k было Q(k) = min(B(k), h) нулей. Этот счётчик начинается
с нуля, растёт не более чем на единицу за символ и заканчивается на h.
Отразим половину и при нечётном N поставим в центр ноль ровно тогда,
когда Z нечётно. Так как A(k) ≤ Q(k) ≤ B(k), ограничения достижимости
выполнены для обеих половин, и этот палиндром достижим.

Один проход с двух концов хранит текущую разность двух количеств нулей и
отвечает NO, когда она становится отрицательной.

Ловушка (тест 12): одного разбиения на пары недостаточно для выбора
достижимой цели. Для S = «1001» ответ YES, поскольку S уже палиндром,
но «0110», где нули сдвинуты максимально влево с учётом пар, недостижим:
в его первых двух символах нулей меньше, чем у S.

В третьем примере в «10» один ноль — нечётное число при чётной длине,
так что ответ NO.

Это O(N).
