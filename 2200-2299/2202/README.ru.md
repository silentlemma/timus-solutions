# 2202. Соединение пар точек непересекающимися кривыми вокруг контура прямоугольника

[Timus 2202](https://acm.timus.ru/problem.aspx?space=1&num=2202) · сложность 2009 · graphs, segment_tree

Автор оригинальной задачи — Валентин Зуев; Вузовско-академическая олимпиада по информатике 2020.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N пар различных точек нужно по одной паре соединять кривыми, которые не
пересекают друг друга и не касаются контура прямоугольника
(0, 0)–(W, H), кроме того, что кривая может начинаться или кончаться в
точке на контуре. Определите, можно ли соединить все пары. Ограничения:
3 секунды и 256 МБ.

## Входные данные

N, W и H, 1 ≤ N ≤ 10⁵, 1 ≤ W, H ≤ 10⁸, затем N пар точек с
координатами не больше 10⁸ по модулю.

## Выходные данные

YES или NO.

## Примеры

### Пример 1

Ввод:

```
1 2 2
-1 1 3 1
```

Вывод:

```
YES
```

### Пример 2

Ввод:

```
3 4 4
0 0 3 3
4 0 1 3
2 4 2 0
```

Вывод:

```
YES
```

### Пример 3

Ввод:

```
3 4 4
0 0 4 4
4 0 0 4
2 4 2 0
```

Вывод:

```
NO
```

## Решение

Контур — замкнутая кривая, так что пару, у которой одна точка строго
внутри, а другая строго снаружи, соединить нельзя: ответ NO.

Пара, у которой хотя бы одна точка строго внутри или строго снаружи,
рисует кривую, касающуюся контура не больше чем в одной точке, а такая
кривая ничего не разделяет. Если рисовать такие пары первыми, а
остальные в обход них, их можно не учитывать.

Остаются пары, у которых обе точки на контуре. Каждая их кривая — хорда,
идущая целиком внутри или целиком снаружи прямоугольника, ведь пересечь
контур она не может. Пронумеруем точки по положению вдоль контура; две
хорды с одной стороны пересекаются ровно тогда, когда их концы
чередуются. Значит, ответ YES ровно тогда, когда граф чередования этих
хорд двудольный: одна доля внутри, другая снаружи.

В этом графе может быть Θ(N²) рёбер, поэтому раскраска строит только
остовный лес. Дерево отрезков по позициям на контуре хранит для каждого
непосещённого конца позицию его пары, с минимумом и максимумом в узле.
Хорда [l, r] пересекает другую хорду ровно тогда, когда у какого-то
конца строго между l и r пара лежит вне [l, r], так что один запрос
находит непокрашенную пересекающую хорду, которая получает
противоположный цвет и удаляется из дерева. Каждая хорда находится один
раз.

Наконец, каждый цветовой класс проверяется проходом со стеком вдоль
контура: хорды одного класса должны правильно вкладываться, иначе граф
не двудольный.

В третьем примере три хорды соединяют (0, 0)–(4, 4), (4, 0)–(0, 4) и
(2, 4)–(2, 0); любые две из них чередуются, так что они образуют
треугольник, и ответ NO.

Сортировка и запросы к дереву занимают O(N log N).
