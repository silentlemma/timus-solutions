# 2202. 绕着矩形轮廓用互不相交的曲线连接点对

[Timus 2202](https://acm.timus.ru/problem.aspx?space=1&num=2202) · 难度 2009 · graphs, segment_tree

原题作者 Valentin Zuev，出自 2020 年大学学术中学生信息学奥林匹克。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 对互不相同的点要一对一对地用曲线连接，这些曲线彼此不相交，也不碰到矩形 (0, 0)–(W, H) 的轮廓，只是曲线可以从轮廓上的点出发或到达轮廓上的点。判断能否连接所有点对。时间限制 3 秒，内存限制 256 MB。

## 输入

N、W 和 H（1 ≤ N ≤ 10⁵，1 ≤ W, H ≤ 10⁸），然后是 N 对坐标绝对值不超过 10⁸ 的点。

## 输出

YES 或 NO。

## 样例

### 样例 1

输入：

```
1 2 2
-1 1 3 1
```

输出：

```
YES
```

### 样例 2

输入：

```
3 4 4
0 0 3 3
4 0 1 3
2 4 2 0
```

输出：

```
YES
```

### 样例 3

输入：

```
3 4 4
0 0 4 4
4 0 0 4
2 4 2 0
```

输出：

```
NO
```

## 解法

轮廓是一条闭曲线，所以一点严格在内、另一点严格在外的点对永远无法连接：答案为 NO。

至少有一个点严格在内或严格在外的点对，画出的曲线至多在一个点碰到轮廓，这样的曲线不会分割任何区域。先画这些点对，其余曲线绕开它们，就可以不考虑它们。

剩下的是两个点都在轮廓上的点对。它们的曲线都是一条弦，完全在矩形内部或完全在外部，因为不能穿过轮廓。按沿轮廓的位置给点编号；同一侧的两条弦相交当且仅当它们的端点交错。所以答案为 YES 当且仅当这些弦的交错图是二分图，一部分在内，一部分在外。

这个图可能有 Θ(N²) 条边，所以染色时只建一片生成森林。在轮廓位置上建线段树，为每个未访问的端点存其配对端点的位置，并在节点上维护最小值和最大值。弦 [l, r] 与另一条弦相交，当且仅当 l 与 r 之间严格存在某个端点，其配对端点在 [l, r] 之外，所以一次查询就能找到一条未染色的相交弦，给它染上相反的颜色并从树中删除。每条弦只被找到一次。

最后沿轮廓用栈扫描检查每个颜色类：同一类的弦必须正确嵌套，否则图不是二分图。

第三个样例中三条弦分别连接 (0, 0)–(4, 4)、(4, 0)–(0, 4) 和 (2, 4)–(2, 0)；任意两条都交错，构成三角形，所以答案为 NO。

排序和树上查询共需 O(N log N)。
