# 2210. T 天内打工或购买企业能得到的最多金钱

[Timus 2210](https://acm.timus.ru/problem.aspx?space=1&num=2210) · 难度 1161 · dp

原题作者 Valentin Zuev，出自 2023 年大学学术中学生信息学奥林匹克。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

玩家每天要么打工赚 1 枚硬币，要么购买 N 种企业之一的一家，第 i 种企业花费 Aᵢ，从第二天起每天带来 Bᵢ 枚硬币；然后结算之前购买的企业的收入。从零开始，对 Q 个时长 T 中的每一个，求 T 天后最多有多少硬币。时间限制 2 秒，内存限制 256 MB。

## 输入

N（1 ≤ N ≤ 100），然后是 1 到 100 之间的 Aᵢ、Bᵢ，然后是 Q（1 ≤ Q ≤ 5 · 10⁴）和时长 1 ≤ T ≤ 10⁸。

## 输出

每个 T 对应的最大金额。

## 样例

### 样例 1

输入：

```
1
1 100
1
5
```

输出：

```
401
```

### 样例 2

输入：

```
2
1 1
4 10
1
8
```

输出：

```
42
```

## 解法

只有收入高于所有更便宜种类的企业才有用，它们构成一个价格和收入都递增的列表，最后一种最贵，价格为 C、收入为 I。

状态为（收入，金钱）。每天要么打工，要么买一种买得起的企业；若某状态的收入和金钱都不超过另一个状态，就把它舍去，所以每天只剩一段短小的阶梯形状态。DP 按天进行，有两个出口：

- **以后只打工。** 第 d 天的状态 (r, m) 若以后只打工，最终为 m + (r + 1)(T − d)，是关于 T 的一条直线。每个状态都加入这样一条直线。
- **富裕状态。** 一旦收入和金钱都不小于 C，金钱就不再构成限制，而且尽早购买不会更差。此时剩下的每一天独立地在打工（价值 1）和购买在剩余 k 天中收益最大的企业（价值 Bk − A）之间取较好者。剩余天数达到 C + 1 起总是最上面那种企业，价值 Ik − C，所以在一段固定的前缀之后，总额是关于 T 的二次函数，且所有富裕状态的 T² 部分相同。去掉它后，每个富裕状态只剩一条直线。

非富裕状态继续打工或购买，当所有状态都变为富裕时循环结束；最坏情况下这需要几百天。到那时为止的较小 T 直接查表，更大的 T 则取打工直线和富裕直线上的最大值，两组直线各自保存为上凸壳并用二分查询。

第一个样例（测试 01）的最优操作为打工、购买、打工、购买、打工。每天结束时的金钱依次为 1、0、101、200、401。易错点是过早购买：初始金钱为零，第一天无法购买，且新企业从购买后的第二天才开始产生收入。

DP 在几百天内每天至多保留 C + 2I + 1 ≤ 301 个状态，每个查询 O(log)。
