# 2203. Подсчёт походов в магазин, когда два продукта кончаются по своим графикам

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Бутерброду нужно A грамм хлеба и B грамм колбасы, которые продаются
буханками по X грамм и палками по Y грамм. Когда запаса не хватает на
следующий бутерброд, за один поход покупается наименьшее число буханок и
палок, при котором его можно сделать. Начав с пустыми руками и сделав N
бутербродов, сколько раз придётся сходить в магазин? Ограничения:
1 секунда и 256 МБ.

## Входные данные

A, B, X, Y и N, 1 ≤ A, B ≤ 100, 1 ≤ X, Y, N ≤ 10⁹.

## Выходные данные

Число походов.

## Примеры

### Пример 1

Ввод:

```
30 20 90 30 4
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
5 6 7 72 100
```

Вывод:

```
74
```

### Пример 3

Ввод:

```
99 100 37 47 1000000000
```

Вывод:

```
1000000000
```

## Решение

Если X ≤ A, любой остаток меньше одной буханки, а значит, меньше нужного
на бутерброд, и каждый бутерброд требует похода; то же при Y ≤ B. Тогда
ответ N.

Иначе за поход покупается не больше одной буханки. Пронумеруем
бутерброды с 0; буханка j (с 0) покупается перед бутербродом k ровно
тогда, когда впервые (k + 1)A > jX, то есть k = ⌊jX / A⌋. При
g = gcd(A, X), P = X / g и E = A / g походы за хлебом — это ⌊jP / E⌋,
шаблон из E походов, повторяющийся каждые P бутербродов, и ниже N их
⌈NA / X⌉. Походы за колбасой устроены так же со своими P' и E'.

Поход покупает и то и другое, когда номер бутерброда входит в оба
шаблона, и ответ — походы за хлебом плюс походы за колбасой минус такие
общие. Для каждой из E · E' ≤ 10⁴ пар остатков r = ⌊iP / E⌋ и
r' = ⌊jP' / E'⌋ номера r + sP = r' + tP' по китайской теореме об
остатках образуют либо пустое множество (когда gcd(P, P') не делит
r' − r), либо одну арифметическую прогрессию с шагом lcm(P, P'), члены
которой меньше N считаются сразу.

В первом примере походы за хлебом — 0 и 3, за колбасой — 0, 1 и 3, так
что общие — 0 и 3, и ответ 2 + 3 − 2 = 3.

Это O(AB + log XY).
