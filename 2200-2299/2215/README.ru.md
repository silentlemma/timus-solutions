# 2215. Подсчёт точек в прямоугольниках, пока вся плоскость поворачивается

## Задача

N различных точек получают Q событий по порядку: повернуть все точки на
90°, 180° или 270° против часовой стрелки вокруг заданной точки или
посчитать точки в прямоугольнике со сторонами вдоль осей. Ограничения:
3 секунды и 256 МБ.

## Входные данные

N, 1 ≤ N ≤ 4 · 10⁴, затем точки, затем Q, 1 ≤ Q ≤ 4 · 10⁴, и события
«r90 x y», «r180 x y», «r270 x y» или «ask x1 y1 x2 y2», все координаты
не больше 10⁹ по модулю.

## Выходные данные

Число для каждого «ask».

## Примеры

### Пример 1

Ввод:

```
4
1 1
2 2
3 3
4 4
4
r90 0 0
ask -2 -1 0 4
r180 1 1
ask 3 -3 6 0
```

Вывод:

```
2
3
```

## Решение

Любая последовательность поворотов на четверть вокруг точек — это один
поворот на четверти вокруг начала координат, за которым следует сдвиг:
текущее положение исходной точки p равно Rᵏ p + t. Новый поворот на j
четвертей вокруг c переводит это в Rʲ(Rᵏ p + t − c) + c, так что
достаточно обновлять k и t.

Прямоугольник запроса в текущих координатах переводится обратно в
исходные вычитанием t и поворотом на −k четвертей. Поворот на четверть
переводит прямоугольник со сторонами вдоль осей в такой же, так что
достаточно перевести два противоположных угла и упорядочить их
координаты. После этого все запросы спрашивают об одном и том же
неподвижном множестве точек.

На это отвечаем офлайн: каждый прямоугольник даёт два события — у
правой стороны и сразу левее левой, события и точки обходятся в порядке
x, а дерево Фенвика по сжатым y считает вставленные точки в диапазоне y.

В примере после первого поворота точки равны (−1, 1) … (−4, 4), и первый
прямоугольник содержит (−1, 1) и (−2, 2).

Это O((N + Q) log(N + Q)).
