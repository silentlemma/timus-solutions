# 2211. Подсчёт треугольников с целыми сторонами и заданной целой площадью

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Посчитайте треугольники с целыми длинами сторон и площадью ровно S;
треугольники с одинаковым набором сторон совпадают. Ограничения:
0.5 секунды и 256 МБ.

## Входные данные

S, 1 ≤ S ≤ 10⁹.

## Выходные данные

Число треугольников.

## Примеры

### Пример 1

Ввод:

```
6
```

Вывод:

```
1
```

## Решение

Формула Герона даёт S² = p(p − a)(p − b)(p − c) для полупериметра p. У
треугольника с целыми сторонами и целой площадью периметр всегда чётен,
а площадь делится на 6, так что при S, не делящемся на 6, ответ 0. Иначе
x = p − a, y = p − b и z = p − c — натуральные числа, стороны равны
y + z, x + z и x + y, и

xyz(x + y + z) = S².

Различным треугольникам соответствуют решения с x ≤ y ≤ z. И x, и y
делят S², поэтому решение выписывает делители S² по разложению S. Для
каждого x с 3x⁴ ≤ S² кандидаты y ≥ x идут до наибольшего с
y²(x + 2y) ≤ S² / x, что сохраняет z ≥ y и находится двоичным поиском.
Когда xy делит S², z — положительный корень
z² + (x + y)z − S² / (xy) = 0, который должен быть целым: дискриминант
(x + y)² + 4S² / (xy) должен быть полным квадратом нужной чётности.

В примере S² = 36 = 1 · 2 · 3 · 6, так что x, y, z = 1, 2, 3, а стороны
равны 5, 4 и 3.

Пусть D = d(S²) — число делителей, а P — число просмотренных пар
делителей. Разложение пробными делениями занимает O(√S), сортировка и
двоичные поиски — O(D log D), проверка пар — O(P), где P ≤ D².
Поэтому безопасная оценка времени — O(√S + D²), дополнительной памяти —
O(D). Учитывать только сортировку ошибочно: остаются разложение и перебор
пар; тест 18 проверяет площадь с большим числом делителей.

Ещё одна ловушка — считать только прямоугольные треугольники: в тесте 05
при S = 12 есть ровно треугольники (5, 5, 6) и (5, 5, 8), и ни один из
них не прямоугольный.
