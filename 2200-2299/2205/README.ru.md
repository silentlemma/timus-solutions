# 2205. Наименьший общий предок в дереве наибольших собственных делителей

## Задача

Два различных натуральных числа соединены, когда одно из них —
наибольший собственный делитель другого. Путь — последовательность
различных чисел, где соседние соединены, а его цена — наименьшее число в
нём. Для каждой из N пар (a, b) выведите наибольшую цену пути из a в b
или −1, если пути нет. Ограничения: 2 секунды и 256 МБ.

## Входные данные

N, 1 ≤ N ≤ 5 · 10⁵, затем N пар с 1 ≤ a, b ≤ 10⁷.

## Выходные данные

Ответ для каждой пары.

## Примеры

### Пример 1

Ввод:

```
3
4 4
4 5
4 6
```

Вывод:

```
4
1
1
```

## Решение

Наибольший собственный делитель n > 1 — это n / p для его наименьшего
простого делителя p, так что у каждого числа больше 1 ровно один
меньший сосед: связи образуют дерево с корнем 1, и у каждой пары ровно
один путь. К корню значения только уменьшаются, поэтому наименьшее число
на пути — наименьший общий предок, а −1 не бывает.

Выпишем простые множители a по убыванию. Предки a отбрасывают наименьшие
множители по одному, так что это ровно произведения нескольких первых
множителей этого списка. Значит, общий предок — произведение самого
длинного общего начала двух убывающих списков.

Это произведение получается из g = gcd(a, b). Пусть t — наибольший
простой делитель a / g или b / g. Каждое простое больше t входит в a и b
с одинаковым показателем, а само t входит в g с меньшим из двух
показателей — там списки и начинают различаться. Ниже t списки уже
разошлись. Значит, ответ — g, из которого убраны все простые множители
меньше t; при a = b это само a, а при g = 1 — это 1.

Решето наименьших нечётных простых делителей до 10⁷, хранимое только
для нечётных чисел, даёт любые разложения, а степени двойки убираются
битовым приёмом.

В примере 4 = 2 · 2 и 6 = 3 · 2 различаются уже в наибольшем множителе,
так что их общий предок — 1.

Решето занимает O(V log log V) для V = 10⁷, а каждый запрос O(log V).
