# 2219. 使步行长度之和能到达每个房间的最少杯数

[Timus 2219](https://acm.timus.ru/problem.aspx?space=1&num=2219) · 难度 1468 · bfs, greedy

原题作者 Ivan Moskovchenko，出自 2025 年 ICPC 乌拉尔赛区资格赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个连通的简单图有 N 个房间和 M 条走廊。第 i 杯咖啡让人恰好走过 aᵢ 条走廊，可以重复经过。对每个房间 v，求最少用几杯，使其长度之和等于某条从房间 1 到 v 的路线的长度，否则输出 −1。时间限制 2.5 秒，内存限制 256 MB。

## 输入

N、M 和 K（2 ≤ N ≤ 10⁵，N − 1 ≤ M ≤ 2 · 10⁵，1 ≤ K ≤ 10⁵），然后是各走廊，然后是 a₁ … a_K（1 ≤ aᵢ ≤ 10⁹）。

## 输出

房间 1 … N 的答案。

## 样例

### 样例 1

输入：

```
5 4 4
1 2
2 3
3 4
4 5
1 2 3 4
```

输出：

```
0 1 1 1 1
```

### 样例 2

输入：

```
5 4 2
1 2
2 3
3 4
4 5
1 2
```

输出：

```
0 1 1 2 -1
```

### 样例 3

输入：

```
2 1 1
1 2
999
```

输出：

```
0 1
```

## 解法

路线总能通过来回走一步延长 2，所以从 1 到 v 存在长度为 L 的路线，当且仅当 L 不小于到 v 的与 L 同奇偶的最短路线。每个房间的这两个最短路线长度由在（房间，奇偶）状态上的一次广度优先搜索得到。

所以对每个杯数 x 和每种奇偶 p，只需知道 x 杯奇偶为 p 的最大和。把杯子按降序排列，总体最大和是前 x 杯，另一种奇偶的最佳和则交换一杯：去掉某种奇偶中已选的最小一杯，加上另一种奇偶中未选的最大一杯，两种选择都试一下。这是带奇偶限制的最大和的标准交换论证。

依次处理 x = 1, 2, …，每种奇偶用双指针记录，对每个小于 2N 的长度 L，第一个使同奇偶最佳和达到 L 的杯数。每个房间取其两个不同奇偶距离对应杯数中的较小者，房间 1 不需要杯子。

第二个样例中房间 5 相距 4 条走廊，而杯子至多给出 1 + 2 = 3，所以答案为 −1。

搜索需要 O(N + M)，杯子的排序需要 O(K log K)。
