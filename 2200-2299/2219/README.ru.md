# 2219. Наименьшее число стаканов, длины прогулок которых дают путь до каждой аудитории

[Timus 2219](https://acm.timus.ru/problem.aspx?space=1&num=2219) · сложность 833 · bfs, greedy

Автор оригинальной задачи — Иван Московченко; Квалификационный тур Уральского регионального чемпионата ICPC 2025.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Связный простой граф из N аудиторий и M коридоров. Стакан i позволяет
пройти ровно aᵢ коридоров, повторы разрешены. Для каждой аудитории v
найдите наименьшее число стаканов, сумма длин которых равна длине
какого-нибудь маршрута из аудитории 1 в v, или −1. Ограничения:
2.5 секунды и 256 МБ.

## Входные данные

N, M и K, 2 ≤ N ≤ 10⁵, N − 1 ≤ M ≤ 2 · 10⁵, 1 ≤ K ≤ 10⁵, затем
коридоры, затем a₁ … a_K с 1 ≤ aᵢ ≤ 10⁹.

## Выходные данные

Ответы для аудиторий 1 … N.

## Примеры

### Пример 1

Ввод:

```
5 4 4
1 2
2 3
3 4
4 5
1 2 3 4
```

Вывод:

```
0 1 1 1 1
```

### Пример 2

Ввод:

```
5 4 2
1 2
2 3
3 4
4 5
1 2
```

Вывод:

```
0 1 1 2 -1
```

### Пример 3

Ввод:

```
2 1 1
1 2
999
```

Вывод:

```
0 1
```

## Решение

Маршрут всегда можно удлинить на 2, шагнув туда и обратно, так что
маршрут длины L из 1 в v существует ровно тогда, когда L не меньше
кратчайшего маршрута до v той же чётности, что и L. Эти два кратчайших
маршрута для каждой аудитории даёт один поиск в ширину по состояниям
(аудитория, чётность).

Значит, для каждого числа x и каждой чётности p достаточно знать
наибольшую сумму x стаканов с чётностью p. Если стаканы отсортированы
по убыванию, наибольшая сумма вообще — первые x, а лучшая сумма другой
чётности меняет один стакан: убирает наименьший выбранный стакан
некоторой чётности и добавляет наибольший невыбранный другой чётности,
перебирая оба варианта. Это стандартный обменный аргумент для
наибольшей суммы с условием на чётность.

Проходя x = 1, 2, …, два указателя, по одному на каждую чётность, запоминают для
каждой длины L меньше 2N первое число стаканов, чья лучшая сумма
чётности L достигает L. Аудитория берёт меньшее число по двум своим
расстояниям разной чётности, а аудитории 1 стаканы не нужны.

Во втором примере аудитория 5 в 4 коридорах, а стаканы дают не больше
1 + 2 = 3, так что ответ −1.

Поиск занимает O(N + M), а стаканы — O(K log K) на сортировку.
