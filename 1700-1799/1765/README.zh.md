# 1765. 错误 404

[Timus 1765](https://acm.timus.ru/problem.aspx?space=1&num=1765) · 难度 4244 · number_theory

原题作者 Igor Chevdar（创意来自 Dmitry Poletayev），出自 2010 年 4 月 10 日第十四届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

涡轮原有 n 片叶片，叶尖构成正 n 边形；其中 k 片断掉了。在剩下的叶片中去掉尽可能少的叶片，使保留叶片的质心位于轴上，且至少保留一片。n 至多有两个不同的素因子。

## 输入

n 和 k（3 ≤ n ≤ 20000，1 ≤ k ≤ n − 1），然后按升序给出断掉的叶片编号；叶片沿圆周编号为 1 到 n。

## 输出

要去掉的叶片数以及它们的编号（任意顺序）；如果无法保留平衡的叶片组，输出 −1。任何最优答案都可以。

## 样例

### 样例 1

输入：

```
12 3
3 4 12
```

输出：

```
2
8 9
```

### 样例 2

输入：

```
3 1
1
```

输出：

```
-1
```

## 解法

叶尖是 n 次单位根，保留的叶片平衡当且仅当叶尖之和为零。对至多有两个素因子 p、q 的 n，de Bruijn 关于单位根零和的定理指出，这样的叶尖集合是互不相交的正 p 边形和正 q 边形的并。
所以任务是在这样的多边形中保留尽可能多的完好叶片。

每个多边形都落在模 n/(pq) 余数相同的叶片之中。这 pq 片叶片构成 p × q 的网格，组内第 t 片位于第 t mod p 行、第 t mod q 列：q 边形是一行，p 边形是一列。
行与列总是相交，所以一组中保留的要么是所有不含断叶的行，要么是所有不含断叶的列，取多者；组内其他完好叶片都去掉。
只有一个素因子时只有 p 边形，一组当且仅当没有断叶时保留。如果什么都保留不了，答案为 −1。`O(n + √n)`。

样例 1 中 p = 2、q = 3。在奇数编号的叶片中，断掉的 3 破坏了一个三角形和一条直径；保留两条完整的直径（1、7 与 5、11）比保留一个三角形更好，所以去掉 9。
在偶数编号的叶片中，4 和 12 破坏了一个三角形和两条直径；另一个三角形 2、6、10 保留，所以去掉 8。

注意事项：

- 只有一个素因子时，单片叶片不构成平衡集合；
- 不能同时保留一行和一列，它们有一片公共叶片；
- 如果没有一个多边形是完整的，就得去掉全部叶片，这是不允许的：答案为 −1。

在 250 个最多 16 片叶片的随机情形上，答案与对所有完好叶片子集求叶尖之和的搜索一致；在 100 个最多 20000 片叶片的随机情形上，去掉的叶片数与一个独立的已通过实现相同。
