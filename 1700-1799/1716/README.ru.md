## Задача

Ответ на каждый тест задачи — YES (3 байта) или NO (2 байта).
Хитрая программа выводит YES на первом тесте, а на каждом следующем —
ответ предыдущего теста. По числу тестов n и суммарному размеру ответов
s найти математическое ожидание числа непройденных тестов, если все
порядки тестов равновероятны.

## Входные данные

n и s (1 ≤ n ≤ 5000, 2n ≤ s ≤ 3n).

## Выходные данные

Ожидаемое число непройденных тестов с погрешностью не более 10⁻⁵.

## Примеры

### Пример 1

Ввод:

```
3 7
```

Вывод:

```
2.0000000
```

## Решение

Размеры дают количества: y = s − 2n ответов YES и k = n − y ответов NO.
По линейности ожидания сложим вероятности того, что не пройден каждый
тест. Первый тест не пройден, если его ответ NO, с вероятностью k/n.
Каждый следующий тест не пройден, если его ответ отличается от
предыдущего. Два данных места занимают YES и NO в любом порядке с
вероятностью 2yk/(n(n − 1)). Остальные n − 1 тестов дают в сумме
2yk/n, поэтому ожидание равно

k/n + 2yk/n = k(2y + 1)/n.

В примере y = 1 и k = 2, что даёт 2 · 3/3 = 2. `O(1)`.

Подводные камни:

- первый тест сравнивается с воображаемым YES, а не ни с чем;
- k(2y + 1) доходит примерно до 1,25 · 10⁷, это легко помещается в
  64-битные целые, а делится только в конце;
- n = 1 не требует особого случая: в формуле не остаётся n − 1.

Формула совпадает с полным перебором всех порядков для каждого n до 7
и каждого числа ответов YES.
