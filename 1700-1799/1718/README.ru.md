## Задача

В задаче было семь тестов. После них добавили десять новых, затем
удалили тест 6, и все прежние решения перепроверяются. Каждый автор,
у которого список изменившихся вердиктов не пуст, получает письмо. По
старым вердиктам найти наименьшее и наибольшее возможное число писем.

## Входные данные

n (1 ≤ n ≤ 1000), затем n строк с именем автора и старым вердиктом:
AC, CE или ML X, TL X либо WA X, где 1 ≤ X ≤ 7. Вердикт с тестом X
означает, что тесты 1 … X − 1 пройдены, а тест X — нет. Вердикты,
отличающиеся только X, различны.

## Выходные данные

Наименьшее и наибольшее число авторов, получающих письма.

## Примеры

### Пример 1

Ввод:

```
5
[SPbSU_ITMO]_WiNGeR TL 6
Milanin_(TNU) WA 6
Vladimir_Yakovlev_(USU) AC
Sandro_(USU) WA 1
Sandro_(USU) ML 3
```

Вывод:

```
0 3
```

## Решение

После изменения тесты 1 … 5 остаются, старый тест 7 становится тестом
6, а новые тесты — 7 … 16. Каждый старый вердикт либо точно меняется,
либо может измениться, либо точно остаётся:

- CE и падения на тестах 1 … 5 остаются: впереди те же тесты;
- падение на тесте 7 обязательно меняется: этот тест теперь шестой, так
  что в лучшем случае вердикт содержит 6 вместо 7;
- AC может измениться, ведь новый тест может упасть, и падение на
  тесте 6 может измениться: этого теста больше нет, и проверка
  продолжается на старом тесте 7. Если решение падает на старом тесте 7
  так же, вердикт остаётся тем же, ведь этот тест теперь шестой.

Поэтому наименьшее число писем — число авторов с падением на тесте 7.
Наибольшее добавляет авторов с AC или падением на тесте 6. Имена
считаются множествами. `O(n)`.

Подводные камни:

- автор считается один раз, сколько бы его решений ни изменилось;
- падение на старом тесте 6 может сохранить в точности тот же вердикт,
  поэтому письма оно не требует;
- в именах бывают квадратные и круглые скобки, но нет пробелов, так что
  чтение по словам работает.

Ответы совпадают с независимой принятой реализацией на 600 случайных
тестах.
