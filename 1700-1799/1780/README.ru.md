# 1780. Код Грея

[Timus 1780](https://acm.timus.ru/problem.aspx?space=1&num=1780) · сложность 894 · dp

Автор оригинальной задачи — Дмитрий Полетаев; XV Открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Отражённый двоичный код Грея длины n перечисляет все n-значные двоичные
строки; на позиции k стоит код Грея числа k. На бумажке записаны k и его
код x в двоичном виде одинаковой длины, часть цифр стёрта и показана
как `?`. Восстановить оба числа, если это можно сделать ровно одним
способом.

## Входные данные

k и x — строки из 0, 1 и ? одинаковой длины, не больше 10⁵, возможно с
ведущими нулями.

## Выходные данные

Восстановленные k и x, или `Ambiguity`, если способов несколько, или
`Impossible`, если их нет.

## Примеры

### Пример 1

Ввод:

```
0?1
0?0
```

Вывод:

```
011
010
```

### Пример 2

Ввод:

```
?00
??0
```

Вывод:

```
Ambiguity
```

### Пример 3

Ввод:

```
100
100
```

Вывод:

```
Impossible
```

## Решение

Список, построенный отражением и приписыванием, ставит на позицию k
число k xor (k со сдвигом вправо на один), так что цифра i числа x,
считая слева, — это цифра i числа k xor цифра i − 1 числа k, с нулём
перед первой цифрой. Идя слева направо, прочтения первых цифр можно
считать по последней цифре k: прочтение, кончающееся на k(i) = b,
продолжает кончающееся на k(i − 1) = c, когда бумажка допускает
k(i) = b и x(i) = b xor c. Счётчики обрезаются на 2 — больше ответу не
нужно.

Если прочтение ровно одно, оно восстанавливается с конца: на каждом
шаге дальше ведёт лишь одна предыдущая цифра, у которой есть своё
прочтение, а цифры кода следуют из k. `O(n)`.

В первом примере средняя цифра k обязана быть 1: при 0 последняя цифра
кода была бы 1, а код кончается на 0. Значит, k = 011, x = 010.

Подводные камни:

- первая цифра кода равна первой цифре k;
- счётчики могут расти как 2ⁿ, поэтому их обрезают;
- ведущие нули — часть строк, их нужно сохранить.

Ответы совпадают с перебором всех k до 10 цифр на 600 случайных
бумажках и с независимой принятой реализацией на 60 бумажках до 10⁵
цифр.
