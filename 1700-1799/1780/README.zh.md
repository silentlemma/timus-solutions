# 1780. 格雷码

[Timus 1780](https://acm.timus.ru/problem.aspx?space=1&num=1780) · 难度 894 · dp

原题作者 Dmitry Poletaev，出自第十五届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

长度为 n 的反射二进制格雷码列出所有 n 位二进制串；第 k 个位置上是 k 的格雷码。纸上用等长的二进制写着 k 及其编码 x，部分数字被擦去，记为 `?`。
若恰好只有一种方式，复原这两个数。

## 输入

k 和 x，均为由 0、1、? 组成的等长串，长度至多 10⁵，可能有前导零。

## 输出

复原后的 k 和 x；若有多种方式输出 `Ambiguity`，若没有输出 `Impossible`。

## 样例

### 样例 1

输入：

```
0?1
0?0
```

输出：

```
011
010
```

### 样例 2

输入：

```
?00
??0
```

输出：

```
Ambiguity
```

### 样例 3

输入：

```
100
100
```

输出：

```
Impossible
```

## 解法

通过反射和加前缀构造的列表在第 k 位放的是 k xor（k 右移一位），所以从左数 x 的第 i 位等于 k 的第 i 位 xor k 的第 i − 1 位，第一位之前视为 0。
从左到右，可以按 k 的最后一位统计前若干位的读法数：以 k(i) = b 结尾的读法延续以 k(i − 1) = c 结尾的读法，当纸上允许 k(i) = b 且 x(i) = b xor c。
计数截断在 2，答案只需要这么多。

如果恰有一种读法，就从末尾复原：每一步只有一个自身有读法的前一位能接下去，编码各位由 k 得出。`O(n)`。

样例 1 中 k 的中间一位必须是 1：若为 0，编码最后一位将是 1，而编码以 0 结尾。所以 k = 011，x = 010。

注意事项：

- 编码第一位等于 k 的第一位；
- 计数可能像 2ⁿ 那样增长，所以要截断；
- 前导零是串的一部分，必须保留。

在 600 张随机纸条上，答案与枚举所有不超过 10 位的 k 的结果一致；在 60 张最多 10⁵ 位的纸条上与一个独立的已通过实现一致。
