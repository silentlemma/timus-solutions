# 1767. Дом доктора Ди

## Задача

Улицы образуют сетку. Один путь идёт из A в B, другой — из C
в D, каждый по какому-то кратчайшему пути по сетке. Выбрать пути так,
чтобы общая длина совпадающих улиц была наибольшей, и вывести эту
длину.

## Входные данные

Точки A, B, C и D по одной в строке — целые координаты, по модулю не
больше 10⁹.

## Выходные данные

Наибольшая общая длина.

## Примеры

### Пример 1

Ввод:

```
2 2
4 4
5 5
3 3
```

Вывод:

```
2
```

## Решение

Кратчайший путь не выходит из прямоугольника, натянутого на его концы,
поэтому общие улицы лежат в пересечении двух прямоугольников —
прямоугольнике w на h — или их нет вовсе, если прямоугольники не
пересекаются. Кратчайший путь движется по каждой оси только в одну
сторону: он поднимается вправо или влево либо идёт по прямой, что
подходит к обоим случаям.

Если оба пути поднимаются в одну сторону, оба могут дойти до одного
угла пересечения, пройти одной лесенкой до противоположного угла и
продолжить к своим концам, разделив w + h, а длиннее путь внутри
пересечения не бывает. Если один поднимается вправо, а другой влево,
общий кусок должен двигаться по каждой оси в одну сторону для обоих,
поэтому это один прямой отрезок, не длиннее max(w, h), и оба пути
могут пройти по одной стороне пересечения. `O(1)`.

В примере оба пути поднимаются вправо, пересечение — квадрат от (3, 3)
до (4, 4), и общая часть 1 + 1 = 2.

Подводные камни:

- для общей части направление пути не важно: из C в D вправо вверх —
  то же, что из D в C;
- прямоугольники, касающиеся лишь в точке или по линии, делят 0 или эту
  линию;
- длины доходят до 4·10⁹, больше знакового 32-битного диапазона.

Ответы совпадают с перебором всех пар кратчайших путей на 400
случайных случаях с координатами до 5 и с независимой принятой
реализацией на 90 случайных случаях.
