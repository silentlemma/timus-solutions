# 1767. 迪博士的房子

[Timus 1767](https://acm.timus.ru/problem.aspx?space=1&num=1767) · 难度 732 · geometry

原题作者 Alex Samsonov，出自 2010 年 4 月 10 日第十四届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

街道构成网格。一条路线从 A 到 B，另一条从 C 到 D，各自沿网格上的某条最短路径。选择这两条路径，使它们共用的街道总长尽可能大，并输出这个长度。

## 输入

点 A、B、C、D，每行一个，均为绝对值不超过 10⁹ 的整数坐标。

## 输出

最大共用长度。

## 样例

### 样例 1

输入：

```
2 2
4 4
5 5
3 3
```

输出：

```
2
```

## 解法

最短路径不会离开以其两端为对角的矩形，所以共用的街道位于两个矩形的交集——一个 w × h 的矩形——之中；若两矩形不相交则没有。
最短路径在每个坐标轴上只朝一个方向移动：要么向右上升，要么向左上升，要么是一条直线（两种情况都适用）。

如果两条路线朝同一方向上升，它们都能走到交集的同一个角，沿同一条阶梯走到对角，再各自走向终点，共用 w + h，而交集内的路径不可能更长。
如果一条向右上升、另一条向左上升，共用部分对两者在每个轴上都只能朝一个方向，所以只能是一条直线段，至多 max(w, h)，两条路线都可以沿交集的一条边走。`O(1)`。

样例中两条路线都向右上升，交集是从 (3, 3) 到 (4, 4) 的正方形，共用 1 + 1 = 2。

注意事项：

- 对共用部分来说路线没有方向：从 C 到 D 向右上升与从 D 到 C 相同；
- 只在一点或沿一条线相接的矩形共用 0 或这条线；
- 长度可达 4·10⁹，超过 32 位有符号整数范围。

在 400 个坐标不超过 5 的随机情形上，答案与所有最短路径对的枚举一致；在 90 个随机情形上与一个独立的已通过实现一致。
