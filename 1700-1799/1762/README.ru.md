# 1762. Поиски тайника

## Задача

В зале n на m плиток выходы в четырёх углах. Путник входит в одном углу
и идёт по диагонали, по плитке за шаг, поворачивая на 90° у каждой
стены, пока не придёт в угол. Каждая плитка, на которую он наступает,
переворачивается — с белой стороны на серую или обратно. Посчитать
серые плитки в конце.

## Входные данные

n и m (2 ≤ n, m ≤ 1 000 000).

## Выходные данные

Число серых плиток.

## Примеры

### Пример 1

Ввод:

```
7 5
```

Вывод:

```
11
```

### Пример 2

Ввод:

```
2 3
```

Вывод:

```
3
```

## Решение

Пронумеруем плитки от 0 до a = n − 1 поперёк и от 0 до b = m − 1 вдоль.
Если развернуть зал у стен, путь станет прямой диагональю, и впервые
он придёт в угол через L = lcm(a, b) шагов, так что наступит на L + 1
плиток с повторами. На плитку можно попасть не больше одного раза в
каждом из двух диагональных направлений, поэтому она остаётся серой,
если только путь не пересекает там сам себя, и ответ — L + 1 минус
удвоенное число пересечений.

При g = gcd(a, b) путь идёт только по прямым x − y ≡ 0 и x + y ≡ 0 по
модулю 2g, поскольку его время t совпадает с ±x по модулю 2a и с ±y по
модулю 2b. Плитка на прямых обоих видов имеет x и y, делящиеся на g,
причём x/g и y/g одной чётности. Внутри зала каждая такая точка —
пересечение, а на стене путь от неё лишь отражается. Значит, при
A = a/g и B = b/g пересечения — это пары 1 ≤ X < A, 1 ≤ Y < B одной
чётности: ⌊A/2⌋·⌊B/2⌋ нечётных пар плюс ⌊(A−1)/2⌋·⌊(B−1)/2⌋ чётных.
`O(log n)` на gcd.

В первом примере a = 6, b = 4, g = 2, L = 12, A = 3, B = 2, и
единственное пересечение — X = Y = 1, плитка (2, 2): 13 − 2 = 11.

Подводные камни:

- L доходит примерно до 10¹², нужны 64 бита;
- при отражении от стены на плитку наступают один раз, а не два;
- моделирование пути требует до 10¹² шагов.

Формула совпадает с моделированием пути для всех залов до 69 на 69
плиток и с независимой принятой реализацией на 100 случаях до
предельных значений.
