# 1762. 寻找藏宝处

[Timus 1762](https://acm.timus.ru/problem.aspx?space=1&num=1762) · 难度 1684 · math

原题作者 Alexander Larin，出自 2010 年 3 月 13 日第十一届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个 n × m 块地砖的大厅四角各有一个出口。行者从一个角进入，沿对角线每步走一块，碰到墙就转 90°，直到走到某个角。
每块踩到的地砖都会翻面，白变灰或灰变白。求最后灰色地砖的数量。

## 输入

n 和 m（2 ≤ n, m ≤ 1 000 000）。

## 输出

灰色地砖的数量。

## 样例

### 样例 1

输入：

```
7 5
```

输出：

```
11
```

### 样例 2

输入：

```
2 3
```

输出：

```
3
```

## 解法

横向把地砖编号为 0 到 a = n − 1，纵向为 0 到 b = m − 1。在墙处展开后，路径是一条直的对角线，它在 L = lcm(a, b) 步后第一次到达角，
所以算上重复共踩 L + 1 块。一块踩到的地砖在两个对角方向上各至多被踩一次，所以除非路径在那里自交，它最后是灰色的；答案是 L + 1 减去两倍的交叉点数。

设 g = gcd(a, b)，由于时间 t 模 2a 等于 ±x、模 2b 等于 ±y，路径只沿着模 2g 意义下 x − y ≡ 0 和 x + y ≡ 0 的直线走。
同时在两类直线上的地砖，x 和 y 都能被 g 整除，且 x/g 与 y/g 奇偶相同。在大厅内部，每个这样的点都是交叉点；在墙上路径只是从那里反弹。
所以令 A = a/g、B = b/g，交叉点就是奇偶相同的 1 ≤ X < A、1 ≤ Y < B：⌊A/2⌋·⌊B/2⌋ 个奇数对加上 ⌊(A−1)/2⌋·⌊(B−1)/2⌋ 个偶数对。求 gcd 需要 `O(log n)`。

样例 1 中 a = 6，b = 4，g = 2，L = 12，A = 3，B = 2，唯一的交叉点是 X = Y = 1，即地砖 (2, 2)：13 − 2 = 11。

注意事项：

- L 可达约 10¹²，需要 64 位；
- 在墙上反弹时那块地砖只被踩一次，而不是两次；
- 模拟路径需要多达 10¹² 步。

对所有不超过 69 × 69 的大厅，公式与路径模拟一致；在 100 个直到上限的情形上与一个独立的已通过实现一致。
