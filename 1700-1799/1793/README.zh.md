# 1793. 托盘 2

[Timus 1793](https://acm.timus.ru/problem.aspx?space=1&num=1793) · 难度 403 · geometry

原题作者 Sofia Tekhazheva，出自 2010 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

托盘的底面为 a × b，四周有高度为 d 的竖直边框。两个盘子是高度都为 h 的圆台，各有一个底面半径和一个更大的顶面半径。能否把两个盘子都放上去，使它们的底面完全贴在托盘上？

## 输入

a、b 和 d；然后是每个盘子的底面半径和顶面半径；最后是 h。所有数都是 1 到 1000 之间的整数。

## 输出

能放下输出 "YES"，否则输出 "NO"。

## 样例

### 样例 1

输入：

```
10 10 10
1 2
1 2
5
```

输出：

```
YES
```

### 样例 2

输入：

```
8 4 1
1 2
1 3
1
```

输出：

```
NO
```

## 解法

盘子向上变宽，所以在边框以内它在高度 min(d, h) 处最宽，此处半径 w = r + (R − r)·min(d, h)/h。边框以上它可以伸出边缘。
因此每个盘子的中心到每条边的距离至少为 w，这要求 2w ≤ a 且 2w ≤ b。两个等高的盘子在底部相距最远、在顶部相距最近，
所以它们的中心至少要相距 R₁ + R₂。两个中心在各自允许矩形的相对角上相距最远：一个方向相距 a − w₁ − w₂，另一个方向相距 b − w₁ − w₂。
把所有量乘以 h 后都是整数，比较距离的平方可以避免开方，所以判断是精确的。`O(1)`。

第一个样例中边框比盘子高，所以两个盘子的 w 都是 2；中心在每个方向上可以相距 6，总共约 8.49，而只需要 4。

注意事项：

- 边框较低时，盘子的顶部可以比托盘还宽；
- 盘子是在顶部相撞，而不是在边框的高度；
- 恰好相切的盘子也能放下，浮点判断在这里可能出错。

在 600 个随机情形上（其中包括沿 3-4-5 对角线恰好相切的盘子），答案与一个独立的已通过实现一致。
