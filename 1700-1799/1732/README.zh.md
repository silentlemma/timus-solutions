# 1732. 真理部

[Timus 1732](https://acm.timus.ru/problem.aspx?space=1&num=1732) · 难度 558 · strings

原题作者 Alex Samsonov（由 Dmitry Ivankov 准备），出自第十四届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

擦掉一句格言中的一些字母（每个被擦掉的字母变成空格），使得把连续空格压缩成一个并去掉首尾空格后，它读起来是另一句给定的格言。指出要擦掉哪些字母。

## 输入

原格言和目标格言，各不超过 100 000 个字符：由拉丁字母组成的单词，用单个空格分隔。两者不同。

## 输出

把被擦掉的字母替换为 `_` 后的原格言；若做不到则输出 `I HAVE FAILED!!!`。任何符合要求的答案都可以。

## 样例

### 样例 1

输入：

```
Preved to Medved
Preved Me
```

输出：

```
Preved __ Me____
```

### 样例 2

输入：

```
this is impossible
im possible
```

输出：

```
I HAVE FAILED!!!
```

## 解法

每个目标单词必须是某个原单词内部的一段连续字母，同一原单词中的两个目标单词之间至少要有一个被擦掉的字母。
原格言的空格无法去掉，所以目标单词永远不会跨越两个原单词。

按顺序遍历原单词，贪心地放置目标单词：每个放在当前单词中最早的出现处，且距离该单词中前一个目标单词的结尾至少两个位置。
如果单词剩余部分中没有出现，就转到下一个原单词。最早的放置给后面留下最多空间，所以若贪心用完了原单词，任何方法都不行。
所有未保留的字母都变成 `_`。

用库函数 `find` 搜索可能是平方级的，例如由 100 000 个 a 组成的单词对一个由 a 组成、以 b 结尾的目标单词。
因此搜索使用当前目标单词的前缀函数，只在目标单词更换时重建，并且每次搜索都从上一次结束的地方开始，
所以原格言的每个字母只被扫描一次。`O(L)`。

样例 1 中 `Preved` 原样保留，`to` 被擦掉，`Me` 是 `Medved` 的开头。

注意事项：

- `abab` 不能变成 `ab ab`：空格必须来自被擦掉的字母，同样的原因使样例 2 中 `impossible` 无法得到 `im possible`；
- 字母区分大小写；
- 目标单词不能连接两个原单词：`to Me` 永远得不到 `toMe`。

检查程序验证只有字母变成了下划线，且结果读起来是目标格言。在 300 个短格言上答案与穷举所有擦除方式一致，在长格言上与一个独立的已通过实现一致。
