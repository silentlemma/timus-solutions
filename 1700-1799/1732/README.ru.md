# 1732. Министерство правды

[Timus 1732](https://acm.timus.ru/problem.aspx?space=1&num=1732) · сложность 558 · strings

Автор оригинальной задачи — Алексей Самсонов (подготовка — Дмитрий Иванков); XIV Открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Стереть часть букв изречения — каждая стёртая буква становится
пробелом — так, чтобы после сжатия подряд идущих пробелов в один и
обрезки краёв получилось другое данное изречение. Показать, какие буквы
стереть.

## Входные данные

Исходное изречение и требуемое, каждое до 100 000 символов: слова из
латинских букв через одиночные пробелы. Изречения различны.

## Выходные данные

Исходное изречение, где стёртые буквы заменены на `_`, или
`I HAVE FAILED!!!`, если это невозможно. Подходит любой подходящий
ответ.

## Примеры

### Пример 1

Ввод:

```
Preved to Medved
Preved Me
```

Вывод:

```
Preved __ Me____
```

### Пример 2

Ввод:

```
this is impossible
im possible
```

Вывод:

```
I HAVE FAILED!!!
```

## Решение

Каждое требуемое слово должно быть отрезком букв внутри одного
исходного слова, а между двумя требуемыми словами внутри одного
исходного слова нужна хотя бы одна стёртая буква. Пробелы исходного
изречения убрать нельзя, поэтому требуемое слово никогда не захватывает
два исходных.

Идём по исходным словам по порядку и жадно расставляем требуемые:
каждое — в самое раннее вхождение в текущем слове, не меньше чем через
две позиции после конца предыдущего в этом слове. Если в остатке слова
вхождения нет, переходим к следующему слову. Самое раннее размещение
оставляет больше всего места для остальных, поэтому если жадности не
хватило исходных слов, не сработает ничто. Каждая неоставленная буква
становится `_`.

Поиск библиотечным `find` может быть квадратичным, например слово из
100 000 букв a против требуемого слова из a с b на конце. Поэтому поиск
идёт по префикс-функции текущего требуемого слова, которая
перестраивается только при смене слова, а каждый поиск начинается там,
где закончился предыдущий, так что каждая буква исходного изречения
просматривается один раз. `O(L)`.

В первом примере `Preved` остаётся целиком, `to` стирается, а `Me` —
начало `Medved`.

Подводные камни:

- `abab` нельзя превратить в `ab ab`: пробел должен получиться из
  стёртой буквы, и по той же причине `impossible` не даёт `im possible`
  во втором примере;
- регистр букв важен;
- требуемое слово не может соединить два исходных: `to Me` никогда не
  даст `toMe`.

Проверяющая программа проверяет, что подчёркиваниями стали только
буквы и что результат читается как требуемое изречение. Ответы
совпадают с полным перебором всех стираний на 300 коротких изречениях и
с независимой принятой реализацией на длинных.
