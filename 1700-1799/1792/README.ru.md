## Задача

Четыре пересекающихся круга содержат по биту, а три лепестка — общие
части трёх кругов — содержат чётность суммы по кругам, которые их
накрывают. В порядке рисунка из условия лепесток j лежит во всех
кругах, кроме круга j, а четвёртый круг накрывает все три лепестка.
Изменено не более одного из семи битов. Восстановить правильный код.

## Входные данные

Семь битов: четыре круга, затем три лепестка.

## Выходные данные

Семь битов правильного кода, отличающегося от входа не более чем в
одном месте.

## Примеры

### Пример 1

Ввод:

```
0 1 0 1 1 0 1
```

Вывод:

```
0 1 0 0 1 0 1
```

### Пример 2

Ввод:

```
1 1 1 1 1 1 1
```

Вывод:

```
1 1 1 1 1 1 1
```

## Решение

Проверяем слово как есть: лепесток j должен равняться сумме кругов,
кроме круга j, по модулю 2. Если проверка не прошла, по очереди меняем
каждый из семи битов и оставляем первую замену, после которой слово
правильное. Два правильных слова всегда отличаются хотя бы в трёх
местах, поэтому ответ единственный. `O(1)`.

В первом примере неверны все три лепестка, а под всеми ними лежит
только четвёртый круг; замена в нём 1 на 0 делает лепестки равными
1, 0, 1, как и записано.

Подводные камни:

- изменённым битом может быть сам лепесток, а не круг;
- слово может уже быть правильным, тогда оно выводится без изменений.

Все 128 возможных входов дают тот же ответ, что и независимая принятая
реализация.
