# 1733. 被遗忘的技术

[Timus 1733](https://acm.timus.ru/problem.aspx?space=1&num=1733) · 难度 4590 · geometry

原题作者 Pavel Atnashev（创意来自 Alex Samsonov），出自第十四届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

绒布上放着一本矩形的书，书上放着一张圆盘，圆心在书内或书的边上。老鼠只能在绒布上跑，所以不能穿过书；
它想到达圆盘悬在绒布上方、严格在书外的某一点。求最短路径的长度。

## 输入

书的四个顶点（按逆时针顺序），然后是圆盘的圆心和半径（半径至少为 1），然后是老鼠的位置。
所有数都是绝对值不超过 1000 的整数。老鼠既不接触书也不接触圆盘，并且路径存在。

## 输出

最短路径的长度，误差不超过 10⁻⁵。

## 样例

### 样例 1

输入：

```
-4 -3 8 6 5 10 -7 1
1 7 5
7 -1
```

输出：

```
12.07107
```

## 解法

目标是圆盘在书外的部分连同其边界。绕过凸障碍物的最短路由老鼠与书的顶点之间的直线段组成，
所以它是：先走到某个顶点的最短路，再从老鼠或该顶点沿直线到目标。在老鼠和四个顶点上做 Dijkstra 求出这些最短路：
老鼠连到它能看见的每个顶点，每个顶点连到两个相邻顶点。

从点 s 出发，s 能看见的最近目标点是下列之一：

- 从圆心指向 s 的射线与圆的交点，前提是它在书外且 s 能看见它；
- 某条边在圆盘内的弦上最近的点，前提是 s 在这条边的外侧或在其所在直线上；此时整条边都可见。

其他目标点都无关紧要。沿圆周的距离只有一个极小值，所以在一段弧上最近点是射线点或弧的端点，而弧的端点也是弦的端点；
沿弦的距离是凸的。如果最优点被 s 的可见区域边界截断，通往它的路径会经过某个顶点，而以该顶点为起点不会更差。
答案是到某点的最短路加上该点到最近目标点的距离的最小值。`O(1)`。

样例中老鼠跑 7.071 到顶点 (8, 6)，再沿边跑 5 到位于圆上的顶点 (5, 10)。

注意事项：

- 从内部与圆相切的边只给出一个点，它不严格在书外，所以长度为零的弦被跳过；
- 顶点可能在圆盘内部，这时它本身就是目标点；
- 老鼠可能在某条边所在的直线上，所以对边的检查带有小容差；
- 直接可见的那部分圆盘不一定最近：绕过一个顶点到书的另一侧可能更短，所以即使老鼠能看见目标，也要尝试每个顶点。

在 210 个随机数据上，答案与对目标点的密集采样搜索（逐点检查线段）在采样精度内一致。一个独立的已通过实现在其中 209 个上一致；
在剩下的一个（测试 07）上，它停在直接可见的那部分圆盘，得到 1068.837，而绕过顶点 (−2, 16) 的路径为 1060.690，采样也证实了这一点。
