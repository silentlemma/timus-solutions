# 1749. Периодическая сумма

Автор оригинальной задачи — Пётр Лежанкин; контест УГАТУ, Петрозаводские летние сборы, август 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

S(t) — сумма всех подстрок десятичной записи t как чисел, ведущие нули
допускаются, а F(t, k) — запись t k раз подряд. По p, k и m найти
S(F(p, k)) по модулю m.

## Входные данные

p (1 ≤ p < 10¹⁰⁰⁰⁰⁰), затем k и m (1 ≤ k, m ≤ 10⁹).

## Выходные данные

S(F(p, k)) по модулю m.

## Примеры

### Пример 1

Ввод:

```
1205
3 999999999
```

Вывод:

```
847123538
```

## Решение

Читаем цифры слева направо, и пусть E — сумма подстрок, кончающихся на
текущей цифре. Новая цифра d на позиции j удлиняет каждую из них на
цифру и начинает новую, так что E становится 10·E + d·j, а S копит E
после каждой цифры.

На одной копии p это линейно по состоянию (S, E, J, 1), где J — число
цифр перед копией: позиция её i-й цифры равна J + i. Один проход по p
даёт матрицу 4 × 4 одной копии: E становится 10ⁿ·E + v·J + w, где v —
значение p, а w — сумма его цифр с весами-позициями и степенями десяти;
S получает накопленные суммы этих трёх величин; J растёт на длину n
числа p. k-я степень этой матрицы, найденная повторным возведением в
квадрат по модулю m и применённая к начальному состоянию S = E = J = 0,
даёт ответ. `O(n + log k)`.

В примере S(1205) само по себе равно 1575, а три копии дают 847123538 по
модулю 999999999.

Подводные камни:

- в p до 100 000 цифр, поэтому оно читается строкой;
- подстроки с ведущими нулями считаются своим значением, так что
  нулевая цифра всё равно сдвигает позиции;
- при m = 1 любой ответ 0.

Ответы совпадают с прямой суммой по всем подстрокам в точных целых на
300 случайных наборах и с независимой принятой реализацией на больших
тестах.
