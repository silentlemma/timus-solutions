# 1749. 周期和

[Timus 1749](https://acm.timus.ru/problem.aspx?space=1&num=1749) · 难度 2013 · matrix

原题作者 Petr Lezhankin，出自 2009 年 8 月彼得罗扎沃茨克夏季集训的乌法国立航空技术大学专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

S(t) 是 t 的十进制表示的所有子串（允许前导零）作为数之和，F(t, k) 是把 t 连续写 k 次得到的数。给定 p、k 和 m，求 S(F(p, k)) 对 m 取模。

## 输入

p（1 ≤ p < 10¹⁰⁰⁰⁰⁰），然后是 k 和 m（1 ≤ k, m ≤ 10⁹）。

## 输出

S(F(p, k)) 对 m 取模。

## 样例

### 样例 1

输入：

```
1205
3 999999999
```

输出：

```
847123538
```

## 解法

从左到右读数字，设 E 为以当前数字结尾的所有子串之和。位置 j 处的新数字 d 把每个这样的子串延长一位，并新开一个子串，
所以 E 变为 10·E + d·j，而 S 在每个数字后累加 E。

在 p 的一个副本上，这对状态 (S, E, J, 1) 是线性的，其中 J 是该副本之前的数字个数：副本第 i 个数字的位置为 J + i。
对 p 扫描一遍就得到一个副本的 4 × 4 矩阵：E 变为 10ⁿ·E + v·J + w，其中 v 是 p 的值，w 是 p 的数字按位置和十的幂加权之和；
S 加上这三个量的累计和；J 增加 p 的长度 n。用反复平方对 m 取模求这个矩阵的 k 次幂，作用于初始状态 S = E = J = 0 即得答案。`O(n + log k)`。

样例中 S(1205) 单独为 1575，三个副本给出模 999999999 为 847123538。

注意事项：

- p 最多有 100 000 位，所以按字符串读入；
- 带前导零的子串按其值计入，所以零数字仍然推进位置；
- m = 1 时所有答案都是 0。

在 300 个随机数据上，答案与用精确整数直接对所有子串求和的结果一致；在大测试上与一个独立的已通过实现一致。
