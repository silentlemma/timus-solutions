# 1785. Трудности локализации

[Timus 1785](https://acm.timus.ru/problem.aspx?space=1&num=1785) · сложность 16 · implementation

Оригинальная задача — фольклор; Уральская региональная командная олимпиада по программированию 2010.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Игра называет размер армии словом вместо числа: 1–4 — "few", 5–9 —
"several", 10–19 — "pack", 20–49 — "lots", 50–99 — "horde", 100–249 —
"throng", 250–499 — "swarm", 500–999 — "zounds", 1000 и больше —
"legion". Вывести слово для заданного числа монстров.

## Входные данные

n (1 ≤ n ≤ 2000).

## Выходные данные

Слово для n.

## Проверка

Тесты репозитория точно сравнивают токены вывода; пробельные разделители между ними несущественны.

## Примеры

### Пример 1

Ввод:

```
7
```

Вывод:

```
several
```

### Пример 2

Ввод:

```
40
```

Вывод:

```
lots
```

## Решение

Храним нижние границы диапазонов от большей к меньшей — 1000, 500,
250, 100, 50, 20, 10, 5, 1 — рядом с их словами. Пропускаем границы,
которые больше n; первая не большая даёт слово. `O(1)`.

В примерах 7 проходит границы от 1000 до 10 и останавливается на 5 —
"several"; 40 останавливается на 20 — "lots".

Подводные камни:

- граница относится к большему слову: 5 — "several", 1000 — "legion";
- все n от 1000 до 2000 — "legion".

Ответы совпадают с независимой принятой реализацией на всех n от 1 до
2000.

## Оптимизированные решения

`1785_implementation_optimized.py` используется побайтово без изменений, без второго исходника и нового алгоритма. Accepted точного исходника на CPython 3.12 №11327034: 0.078 с / 704 КБ. Сохранённая выборка актуальных компиляторов семейства Python от 2026-11-20: место по времени 18/582, по памяти 494/582. Поскольку здесь меньше 1024 КБ, строгий критерий первых десяти мест или топ 15% учитывает только время; звёздочка сохраняет отдельную рейтинговую цель языка. У того же файла есть прежний Accepted на PyPy 3.10 №11325075: 0.14 с / 196 КБ. Это парные замеры разных запусков: CPython даёт выбранный результат по времени и рейтингу, PyPy расходует меньше памяти. Прежние замечания об экономии памяти в этом разделе относятся к этому замеру PyPy, а не к строке CPython. Все учебные исходники сохранены без изменений.

`1785_implementation_optimized.go`. Сохраняются девять фиксированных интервалов названий армии с теми же включёнными нижними границами. Вместо параллельных массивов порогов и слов и поиска индекса используются убывающие условия; выбирается первое совпадение, включая границы5,10,20,50,100,250,500,1000. Общей сортировки или нового поиска нет. При области1..2000 и девяти случаях время и состояние O(1), написание слов прежнее. Переносимые os.Stdin.Read/os.Stdout.Write и прямое преобразование целых используют фиксированные буферы ввода и вывода по 4096 байт. Частичная запись обрабатывается до повторного использования буфера. Исходный простой вариант с Accepted сохранён.

По сравнению с `1785_implementation.go`: время 0.031 s → 0.015 s; память 1080 KB → 796 KB.

Самостоятельная программа для судьи явно сбрасывает stdout перед os._exit(0), пропуская обычное завершение интерпретатора. Выигрыш памяти подтверждён её собственным Accepted. Сама смена способа завершения не улучшает асимптотику, а её эффект в среде выполнения не гарантируется на других платформах. Простая версия сохранена без изменений.

По сравнению с `1785_implementation.py`: время 0.093 s → 0.14 s; память 424 KB → 196 KB.

Оптимизированное решение на C++ ищет слово в той же таблице, но читает
через `scanf` и печатает через `puts` вместо `iostream`: 116 КБ вместо
376 КБ при том же времени.

Оптимизированное решение на Java разбирает числа побайтно из `System.in`
вместо `Scanner`: 0.093 с вместо 0.125 с и 340 КБ вместо 1600 КБ.

## Особенности языков

Новые исходники сравниваются по срезу от 18 ноября 2026 года с другими авторами на текущих компиляторах судьи. Порогов по ID посылки или дате нет. Ничьи делят место, времена меньше 0.015 с при сравнении считаются 0.015 с. Приведённые ниже места относятся к новым версиям; прежние исходники сохраняют собственные исторические метрики Accepted.

`1785_implementation_optimized.go`: место по времени 1/21, по памяти 1/21 в этой сопоставимой выборке.

Прежнее сравнение PyPy: `1785_implementation_optimized.py`: место по времени 566/582, по памяти 2/582 в этой сопоставимой выборке.

Звёздочка означает недостигнутую рейтинговую цель: для C++ нужны первые десять мест либо топ 15% одновременно по обеим метрикам; для остальных семейств — первое место по обеим. Отдельный критерий допуска может выполняться по рейтингу или улучшению, в том числе при снижении времени либо памяти минимум на 30%.
