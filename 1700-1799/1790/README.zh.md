# 1790. 寻找真理

[Timus 1790](https://acm.timus.ru/problem.aspx?space=1&num=1790) · 难度 1336 · simulation

原题作者 Mikhail Rubinchik，出自 2010 年乌拉尔地区程序设计团体赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一排 n 个底座中，有一个上面放着神器。每轮触摸一个底座：若神器在那里就找到了，否则它会按自己的选择移到相邻的底座。
给定 m 次触摸的序列，判断无论神器从哪里出发、如何移动，这个序列是否总能找到它。

## 输入

n 和 m（2 ≤ n, m ≤ 100000），然后是 m 个 1 到 n 之间的底座编号。

## 输出

若序列总能找到神器输出 "YES"，否则输出 "NO"。

## 样例

### 样例 1

输入：

```
3 2
2 2
```

输出：

```
YES
```

### 样例 2

输入：

```
3 3
1 2 3
```

输出：

```
NO
```

## 解法

跟踪神器仍可能所在的底座集合。每次移动都会改变它所在底座的奇偶性，所以集合分成偶数部分和奇数部分，
每一部分始终是一段同奇偶、没有空缺的 lo、lo + 2、…、hi。触摸一段的端点会使它缩短一个位置。
触摸一段的内部会留下一个洞，但移动之后洞的两个邻居都能从相隔两步的位置到达，所以没有变化。
一次移动把 lo…hi 变成另一种奇偶性的 lo − 1…hi + 1，只是碰到 1 或 n 处墙壁的一段会被推向内侧：1 变成 2，n 变成 n − 1。
最后两段都为空时答案为 YES。`O(m)`。

第二个样例中，从 2 出发的神器可以溜走：触摸 1 落空，它去 3；触摸 2 落空，它回到 2；触摸 3 再次落空。

注意事项：

- 在 100000 轮中逐个跟踪最多 100000 个底座太慢，所以用两段来表示；
- 严格在一段内部的触摸是浪费的，不会留下永久的洞；
- 在墙边，这一段不会越过墙，而是向内退一步。

在 400 个少量底座上的随机短序列上，答案与直接模拟整个集合的结果一致；在长扫描、被破坏的扫描和随机序列上，与一个独立的已通过实现一致。
