# 1743. 多米诺排序

[Timus 1743](https://acm.timus.ru/problem.aspx?space=1&num=1743) · 难度 991 · greedy

原题作者 Artyom Ripatti 和 Petr Lezhankin，出自 2009 年 8 月彼得罗扎沃茨克夏季集训的乌法国立航空技术大学专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把 n 张多米诺骨牌排成一列，每行一张，可以翻转任意几张，使左列数字不减、右列数字不增。输出这样的排法，或者报告不存在。

## 输入

n（1 ≤ n ≤ 10⁵），然后是每张骨牌上的两个数（0 到 10⁶）。

## 输出

`YES` 和按顺序排列的骨牌，或者 `NO`。任何符合要求的排法都可以。

## 样例

### 样例 1

输入：

```
3
5 2
6 1
3 4
```

输出：

```
YES
1 6
2 5
3 4
```

### 样例 2

输入：

```
4
1 5
7 1
3 8
5 6
```

输出：

```
YES
1 7
1 5
6 5
8 3
```

### 样例 3

输入：

```
2
1 2
3 4
```

输出：

```
NO
```

## 解法

把一张骨牌看作区间 [low, high]。它要么正放为 (low, high)，要么翻转为 (high, low)。任意两行都必须有序：
两张正放的骨牌在区间嵌套时相容，两张翻转的也一样，而一张正放和一张翻转的在区间相交时相容。
所以正放的骨牌构成一条嵌套区间链，翻转的构成另一条，并且一条链最内层的区间必须与另一条链最内层的区间相交；
这时每个正放区间都与每个翻转区间相交。

按左端点排序区间，相等时长的在前。嵌套链就是右端点不增的子序列，把列表分成两个这样的子序列可以贪心完成：
区间能放进第一条链就放进去，否则放进第二条，否则无解。第一条链末尾的右端点总小于第二条的，
所以这等同于把区间放进最紧的那条链，而只要存在划分，这样就不会失败。

如果两条链都用到，它们最后的（最内层的）区间必须相交。如果两者互不包含，任何划分的最内层两区间都相同；
否则所有区间都包含它们的交集。因此检查即可判定。
第一条链正放输出，第二条翻转并倒序输出。`O(n log n)`。

样例 2 中两条链为 [1, 7] ⊃ [1, 5] 和 [3, 8] ⊃ [5, 6]，最内层区间在 5 处相交。

注意事项：

- 只在一个数处相接的区间也算相交；
- 相同的骨牌在两个方向上都嵌套，所以除排序顺序外无需特别处理；
- 一个大区间套着两个分离的小区间时无解：两个小区间会是最内层区间，而它们不相交。

检查程序验证输出的骨牌相同且两列都有序。在 500 组最多 8 张骨牌的随机数据上，判断与穷举所有翻转方式一致；
在大测试上与一个独立的已通过实现一致。
