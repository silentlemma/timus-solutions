# 1787. Поворот на МЕГУ

[Timus 1787](https://acm.timus.ru/problem.aspx?space=1&num=1787) · сложность 25 · simulation

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Светофор пропускает на поворот k машин в минуту. За минуту i к
повороту, пустому в начале, подъезжает aᵢ новых машин. Сколько машин
ждёт через n минут?

## Входные данные

k и n (1 ≤ k, n ≤ 100), затем a₁, …, aₙ (0 ≤ aᵢ ≤ 100).

## Выходные данные

Число ждущих машин.

## Примеры

### Пример 1

Ввод:

```
5 3
6 7 2
```

Вывод:

```
0
```

### Пример 2

Ввод:

```
5 3
20 0 0
```

Вывод:

```
5
```

## Решение

Следим за пробкой поминутно: добавляем новые машины, убираем k, а если
получилось меньше нуля, пробка просто пуста. `O(n)`.

В первом примере пробка равна 1, затем 3, затем 0, потому что в
последнюю минуту у светофора стоят только 5 машин. Во втором — 15, 10,
5.

Подводные камни:

- пробка не уходит в минус: тихая минута не копит пропускную
  способность на потом, поэтому сумма всех aᵢ минус n·k — неверный
  ответ;
- по той же причине важен порядок: первый пример в обратном порядке,
  2 7 6, оставляет 3 машины, а не 0.

Ответы совпадают с независимой принятой реализацией на 150 случайных
случаях с любыми числами машин и с числами, близкими к k.

## Оптимизированные решения

Оптимизированные решения (C++, Java) ведут тот же счёт очереди. C++
читает и пишет через `scanf` и `printf` вместо `iostream`: 124 КБ вместо
392 КБ при том же времени. Java разбирает числа вручную из небольшого
буфера вместо `Scanner`: 364 КБ вместо 1680 КБ при том же времени.
