# 1787. Поворот на МЕГУ

[Timus 1787](https://acm.timus.ru/problem.aspx?space=1&num=1787) · сложность 25 · simulation

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Светофор пропускает на поворот k машин в минуту. За минуту i к
повороту, пустому в начале, подъезжает aᵢ новых машин. Сколько машин
ждёт через n минут?

## Входные данные

k и n (1 ≤ k, n ≤ 100), затем a₁, …, aₙ (0 ≤ aᵢ ≤ 100).

## Выходные данные

Число ждущих машин.

## Примеры

### Пример 1

Ввод:

```
5 3
6 7 2
```

Вывод:

```
0
```

### Пример 2

Ввод:

```
5 3
20 0 0
```

Вывод:

```
5
```

## Решение

Следим за пробкой поминутно: добавляем новые машины, убираем k, а если
получилось меньше нуля, пробка просто пуста. `O(n)`.

В первом примере пробка равна 1, затем 3, затем 0, потому что в
последнюю минуту у светофора стоят только 5 машин. Во втором — 15, 10,
5.

Подводные камни:

- пробка не уходит в минус: тихая минута не копит пропускную
  способность на потом, поэтому сумма всех aᵢ минус n·k — неверный
  ответ;
- по той же причине важен порядок: первый пример в обратном порядке,
  2 7 6, оставляет 3 машины, а не 0.

Ответы совпадают с независимой принятой реализацией на 150 случайных
случаях с любыми числами машин и с числами, близкими к k.

## Оптимизированные решения

`1787_simulation_optimized.java`. Java сохраняет потоковую рекуррентность очереди машин: прибавить прибывших, вычесть пропускную способность за минуту и ограничить остаток снизу нулём. Между шагами хранится только число ожидающих; прибывшие не записываются в массив, неиспользованная пропускная способность не переносится. Фиксированный буфер ввода на 256 байт и прямой десятичный вывод заменяют Scanner и общее форматирование. Время O(N), дополнительная память O(1). При заданных ограничениях очередь помещается в int.

Accepted точного исходника Java 1.8 №11327468: 0.109 с / 316 КБ. Сохранённое сравнение компиляторов от 2026-11-20: время 65/755, память 5/755. При памяти меньше 1024 КБ строгий допуск учитывает только время: первые десять мест или топ 15%, равенства делят место, процентный порог округляется вверх. Звёздочка остаётся для отдельной цели языка: первого места по обеим метрикам. Прежний документированный оптимизированный запуск №11303638: 0.125 с / 364 КБ; это отдельная историческая пара, не текущий замер данного исходника. Учебные версии сохранены без изменений.

- `1787_simulation_optimized.java`: 0.109 s / 316 KB; сохранённая учебная база `1787_simulation.java`: 0.125 s / 1680 KB.

Оптимизированные решения (C++, Java) ведут тот же счёт очереди. C++
читает и пишет через `scanf` и `printf` вместо `iostream`: 124 КБ вместо
392 КБ при том же времени.

Читаем количества машин из итератора и храним только текущую длину очереди. Принятая посылка 11324248 заняла 0,125 с и использовала 244 КБ. Простая версия заняла 0,078 с и использовала 420 КБ. Зафиксированное время выше, чем у простой версии.
