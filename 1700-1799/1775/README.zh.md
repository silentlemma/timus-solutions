# 1775. 太空保龄球

[Timus 1775](https://acm.timus.ru/problem.aspx?space=1&num=1775) · 难度 935 · geometry

原题作者 Alexander Mironenko，出自第十五届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

平面上立着 n 个直径为 1 的圆柱球瓶，中心为互不相同的整点。选定直径的球从任意点抛出，沿直线滚动，撞倒所有碰到的球瓶。求一次投掷撞倒至少 k 个球瓶所需的最小直径。

## 输入

n 和 k（1 ≤ k ≤ n ≤ 200），然后是各中心 xᵢ, yᵢ（|xᵢ|, |yᵢ| ≤ 10⁵）。

## 输出

最小直径，绝对或相对误差不超过 10⁻⁶；如果任意小的球都可以，输出 0。

## 样例

### 样例 1

输入：

```
5 4
0 4
0 6
6 4
6 6
3 0
```

输出：

```
1.0000000000
```

## 解法

直径为 D 的球碰到球瓶，当且仅当球瓶中心到球心轨迹直线的距离不超过 (D + 1)/2，即位于宽 D + 1 的带中。从足够远处抛出时，球可以走过任意一整条直线，
所以问题是求容纳 k 个中心的最窄带，答案为其宽度减 1，但不小于 0。

对固定方向，最窄的带由把中心按垂直于该方向的距离排序、取连续 k 个最接近的得到。方向旋转时，每组的宽度在两中心共线的时刻之间按 |sin| 变化，
而 |sin| 在其间没有内部最小值，所以最优方向是某两个中心沿带排成一线的方向。于是只剩 n(n − 1)/2 个方向，每个排序一次；
横向距离用与方向的整数叉积计算，只在最后除以方向长度。`O(n³ log n)`。

样例中四个中心 (0, 4)、(0, 6)、(6, 4)、(6, 6) 可放进宽为 2 的水平带，所以直径为 1 的球能把它们全部撞倒。

注意事项：

- k 个中心共线或 k = 1 时答案为 0；
- 带宽小于 1 时答案也是 0，而不是负的直径；
- 投球者可以从任何地方出发，所以路径是一整条直线，而不是从某个球瓶出发的射线。

在 60 个最多 200 个球瓶的随机情形上，答案与一个独立的已通过实现（对直径二分）一致。Python 解答在 PyPy 下运行。
