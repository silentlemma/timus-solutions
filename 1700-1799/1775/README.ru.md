# 1775. Космический боулинг

[Timus 1775](https://acm.timus.ru/problem.aspx?space=1&num=1775) · сложность 934 · geometry

Автор оригинальной задачи — Александр Мироненко; XV Открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На плоскости стоят n круглых кеглей диаметра 1 с различными целыми
центрами. Шар выбранного диаметра, брошенный из любой точки, катится по
прямой и сбивает все кегли, которых касается. Найти наименьший диаметр,
при котором одним броском можно сбить не меньше k кеглей.

## Входные данные

n и k (1 ≤ k ≤ n ≤ 200), затем центры xᵢ, yᵢ (|xᵢ|, |yᵢ| ≤ 10⁵).

## Выходные данные

Наименьший диаметр с абсолютной или относительной погрешностью не более
10⁻⁶ или 0, если подойдёт сколь угодно малый шар.

## Примеры

### Пример 1

Ввод:

```
5 4
0 4
0 6
6 4
6 6
3 0
```

Вывод:

```
1.0000000000
```

## Решение

Шар диаметра D касается кегли, когда её центр не дальше (D + 1)/2 от
прямой, по которой идёт центр шара, то есть лежит в полосе ширины
D + 1. Бросая издалека, шар может пройти по любой прямой целиком, так
что задача — найти самую узкую полосу с k центрами, а ответ — её ширина
минус 1, но не меньше 0.

При фиксированном направлении самая узкая такая полоса получается, если
отсортировать центры по расстоянию поперёк направления и взять k
ближайших подряд. При повороте направления ширина каждой такой группы
меняется как |sin| между моментами, когда два центра выстраиваются в
линию, а у |sin| там нет внутреннего минимума, поэтому лучшее
направление — то, в котором какие-то два центра лежат вдоль полосы.
Остаётся n(n − 1)/2 направлений, на каждое одна сортировка; расстояния
поперёк считаются целым векторным произведением с направлением и
делятся на его длину только в конце. `O(n³ log n)`.

В примере четыре центра (0, 4), (0, 6), (6, 4), (6, 6) помещаются в
горизонтальную полосу ширины 2, так что шар диаметра 1 сбивает их все.

Подводные камни:

- k центров на одной прямой или k = 1 дают 0;
- полоса уже 1 тоже даёт 0, а не отрицательный диаметр;
- бросать можно откуда угодно, поэтому путь — целая прямая, а не луч от
  кегли.

Ответы совпадают с независимой принятой реализацией, ищущей диаметр
двоичным поиском, на 60 случайных случаях до 200 кеглей. Решение на
Python работает под PyPy.
