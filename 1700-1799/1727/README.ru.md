# 1727. Магические числа Знайки

## Задача

Найти набор различных целых положительных чисел меньше 10⁵, цифры
которых в сумме дают n, или вывести −1, если такого нет.

## Входные данные

n (0 < n < 10⁵).

## Выходные данные

Размер набора и затем его числа или −1. Подходит любой подходящий
набор.

## Примеры

### Пример 1

Ввод:

```
17
```

Вывод:

```
3
7 12 43
```

## Решение

Набор существует всегда: цифры всех чисел от 1 до 99 999 дают в сумме
5 · 45 · 10⁴ = 2 250 000, намного больше n.

Идём вниз от 99 999 и берём каждое число, сумма цифр которого ещё
помещается в остаток n. У больших чисел сумма цифр около 45, и они
быстро расходуют почти весь n; когда остаток становится маленьким,
жадный алгоритм проскакивает к числам с маленькой суммой цифр вроде
20 000 или 10 000, а в самом конце однозначные 9, 8, …, 1 набирают
любой остаток до 45. Суммы цифр заранее строятся как
s(i) = s(i / 10) + i mod 10. `O(10⁵)`.

Для n = 17 жадный алгоритм выводит 98 000 — у одного этого числа сумма
цифр 17. Подходит любой набор с нужной суммой.

Подводные камни:

- ответ −1 не бывает никогда;
- числа должны быть различными и меньше 10⁵, так что 99 999 можно взять
  только один раз;
- при n = 99 999 в наборе 3261 число, поэтому вывод лучше собирать
  целиком.

Жадный алгоритм набирает ровно n для каждого n от 1 до 99 999 —
проверено по одному. Проверяющая программа проверяет диапазон,
различность и сумму цифр.
