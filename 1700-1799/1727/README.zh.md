# 1727. 万事通的魔法数

[Timus 1727](https://acm.timus.ru/problem.aspx?space=1&num=1727) · 难度 200 · greedy

原题作者 Ivan Burmistrov，出自 2009 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

找出一组互不相同、小于 10⁵ 的正整数，使它们所有数字之和为 n；若不存在则输出 −1。

## 输入

n（0 < n < 10⁵）。

## 输出

集合的大小，然后是其中的数；或者 −1。任何符合要求的集合都可以。

## 样例

### 样例 1

输入：

```
17
```

输出：

```
3
7 12 43
```

## 解法

集合总是存在：1 到 99 999 所有数的数字之和为 5 · 45 · 10⁴ = 2 250 000，远大于 n。

从 99 999 往下走，只要某数的数字和还不超过 n 的剩余部分就选它。大数的数字和接近 45，很快用掉 n 的大部分；
剩余变小后，贪心会跳到数字和小的数，比如 20 000 或 10 000，最后一位数 9, 8, …, 1 可以凑出不超过 45 的任何余数。
数字和预先按 s(i) = s(i / 10) + i mod 10 计算。`O(10⁵)`。

当 n = 17 时贪心输出 98 000，这一个数的数字和就是 17。任何总和正确的集合都可以。

注意事项：

- 答案永远不会是 −1；
- 数必须互不相同且小于 10⁵，所以 99 999 只能用一次；
- 当 n = 99 999 时集合有 3261 个数，所以输出最好一次性拼好。

对 1 到 99 999 的每个 n 逐一检查，贪心都恰好凑出 n。检查程序验证范围、互不相同以及数字总和。
