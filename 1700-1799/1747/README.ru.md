# 1747. Осмотр владений

## Задача

Любые два из n городов соединены дорогой. Царь выезжает из столицы,
должен побывать в каждом городе ровно два раза и вернуться в столицу.
Посчитать число возможных маршрутов по модулю p.

## Входные данные

n и p (3 ≤ n ≤ 10⁵, 1 ≤ p ≤ 10⁹ + 7).

## Выходные данные

Число маршрутов по модулю p.

## Примеры

### Пример 1

Ввод:

```
3 123
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
4 123
```

Вывод:

```
30
```

## Решение

Столица посещается в начале и в конце, так что между ними маршрут — это
слово, в котором каждый из остальных m = n − 1 городов встречается
дважды и никакой город не идёт сразу за собой, ведь дорога соединяет
два разных города. Включения-исключения по парам, стоящим рядом, дают
число таких слов

a(m) = Σ (−1)^k C(m, k) (2m − k)! / 2^(m − k),

но p не обязательно простое, и делить по модулю p не всегда можно. Те
же числа удовлетворяют

a(m) = m(2m − 1)·a(m − 1) + m(m − 1)·a(m − 2), a(0) = 1, a(1) = 0,

где нужны только умножения, так что ответ получается за `O(n)` шагов
по любому модулю p.

При n = 4 остальных городов три, и слов 30, например `ABCABC` и
`ABACBC`.

Подводные камни:

- p может быть 1, чётным или любым составным, что исключает обратные
  по модулю;
- m(2m − 1) доходит до 2·10¹⁰, поэтому перед следующим умножением его
  приводят по модулю p, чтобы остаться в 64 битах.

Рекуррентность даёт те же числа, что и сумма включений-исключений, обе
в точных целых, для всех m до 59 и для m = 100, 250, 500, 1000 и 1500.
Ответы также совпадают с независимой принятой реализацией, которая
раскладывает p на степени простых, на 68 тестах.
