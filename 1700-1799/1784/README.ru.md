# 1784. Шулеры

[Timus 1784](https://acm.timus.ru/problem.aspx?space=1&num=1784) · сложность 1243 · greedy

Автор оригинальной задачи — Александр Ипатов; XV Открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Колода из 52 карт лежит в четырёх стопках по 13 карт. В каждой стопке
сверху вниз идут достоинства 2, 3, …, A, но масти перемешаны. Один ход
берёт несколько карт одной масти с верха стопки, сохраняя их порядок,
и либо кладёт их в новую стопку, либо кладёт на карту, достоинство
которой на единицу больше нижней из взятых. Найти наименьшее число
ходов, после которых получатся четыре стопки, каждая одной масти.

## Входные данные

Четыре строки — стопки сверху вниз, по 13 карт. Карта — достоинство
(2–9, T, J, Q, K, A) и масть (S, C, D, H). Все карты различны.

## Выходные данные

Наименьшее число ходов.

## Примеры

### Пример 1

Ввод:

```
2C 3C 4C 5C 6C 7C 8C 9C TC JC QC KC AC
2S 3S 4S 5S 6S 7S 8D 9D TD JD QD KD AD
2D 3D 4D 5D 6D 7D 8S 9S TS JS QS KS AS
2H 3H 4H 5H 6H 7H 8H 9H TH JH QH KH AH
```

Вывод:

```
3
```

## Решение

Идём по достоинствам сверху вниз. Пусть каждая стопка уже начинается
с серии одной масти от 2 до достоинства r. Эта серия должна оказаться
на карте достоинства r + 1 той же масти, а она лежит в следующем ряду
какой-то стопки. Так ряд r задаёт отображение стопок в стопки: стопку
i нужно положить на стопку target(i). Стопке, переходящей в себя,
ничего не нужно. Остальные распадаются на циклы. В цикле длины L
каждое место назначения закрыто серией, которую тоже надо переносить,
поэтому одна серия сначала уходит в новую стопку, затем по очереди
переносятся остальные L − 1, а отложенная серия переносится последней:
L + 1 ход. После этого каждая стопка снова начинается с одномастной
серии, теперь до достоинства r + 1, и следующий ряд разбирается так же.
Ответ — сумма по 12 промежуткам между рядами. `O(1)`, размер колоды
фиксирован.

В примере масти меняются только между 7 и 8. Пики второй стопки должны
лечь на 8S третьей стопки, а бубны третьей — на 8D второй: цикл из
двух, 3 хода. Пики уходят в новую стопку, бубны ложатся на 8D, пики —
на 8S.

Подводные камни:

- цикл стоит на один ход больше своей длины, а не ровно длину;
- в одном ряду может быть несколько отдельных циклов, и каждый платит
  свой лишний ход;
- для отображения важна только масть карты, достоинство задано рядом.

Ответы совпадают с независимой принятой реализацией на 120 случайных
раскладах и с полным перебором ходов на 225 маленьких колодах с меньшим
числом достоинств.
