# 1784. 老千

[Timus 1784](https://acm.timus.ru/problem.aspx?space=1&num=1784) · 难度 1243 · greedy

原题作者 Alexander Ipatov，出自第十五届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一副 52 张的牌分成四叠，每叠 13 张。每叠从上到下依次是点数 2、3、…、A，但花色是混乱的。一次操作从某叠顶部取出若干张同花色的牌，
保持顺序不变，要么用它们新建一叠，要么把它们放到一张点数比取出的最底下那张大一的牌上。求最少的操作次数，使最后得到四叠，每叠只有一种花色。

## 输入

四行，表示从上到下的各叠牌，每行 13 张。每张牌由点数（2–9、T、J、Q、K、A）和花色（S、C、D、H）组成。所有牌互不相同。

## 输出

最少的操作次数。

## 样例

### 样例 1

输入：

```
2C 3C 4C 5C 6C 7C 8C 9C TC JC QC KC AC
2S 3S 4S 5S 6S 7S 8D 9D TD JD QD KD AD
2D 3D 4D 5D 6D 7D 8S 9S TS JS QS KS AS
2H 3H 4H 5H 6H 7H 8H 9H TH JH QH KH AH
```

输出：

```
3
```

## 解法

按点数从上往下处理。假设每一叠已经以从 2 到点数 r 的同花色连续段开头。这一段最终要放到同花色、点数为 r + 1 的牌上，而那张牌位于某一叠的下一行。
于是第 r 行给出叠到叠的映射：第 i 叠要放到第 target(i) 叠上。映射到自身的叠不需要操作，其余的叠分解成若干个环。
在长度为 L 的环中，每个目的地都被一个同样需要移动的连续段盖住，所以先把一段移到新叠，再依次移动其余 L − 1 段，最后移回暂存的那段：共 L + 1 次。
之后每一叠又以同花色连续段开头，只是延伸到点数 r + 1，下一行同样处理。答案是 12 个行间空隙的代价之和。`O(1)`，牌的数量固定。

样例中只有 7 和 8 之间花色发生变化。第二叠的黑桃要放到第三叠的 8S 上，第三叠的方块要放到第二叠的 8D 上：长度为二的环，3 次操作。
黑桃先移到新叠，方块放到 8D 上，黑桃再放到 8S 上。

注意事项：

- 一个环的代价是长度加一，而不是长度本身；
- 同一行中可能出现多个独立的环，每个环都要多付一次操作；
- 映射只与牌的花色有关，点数由行决定。

在 120 个随机发牌上答案与一个独立的已通过实现一致，在 225 个点数更少的小牌组上与对所有操作的完全搜索一致。
