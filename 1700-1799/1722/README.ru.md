# 1722. Смотровая площадка

[Timus 1722](https://acm.timus.ru/problem.aspx?space=1&num=1722) · сложность 1355 · geometry

Автор оригинальной задачи — Евгений Курпилянский; Уральская региональная командная олимпиада по программированию 2009.

## Задача

Город — круг радиуса R с центром в начале координат. Смотровая площадка
— крыша круглого здания радиуса r_old с центром в начале координат;
новое круглое здание радиуса r_new стоит в точке (x, y). Оба лежат
внутри города и не касаются друг друга. Точка города закрыта, если из
любой точки площадки отрезок до неё задевает новое здание. Найти
закрытую часть города в процентах.

## Входные данные

R, r_old и r_new (1 ≤ r_old < r_new < R ≤ 1000), затем целые x и y.

## Выходные данные

Закрытая часть города в процентах, не менее шести знаков после
десятичной точки.

## Примеры

### Пример 1

Ввод:

```
10 1 3
-1 4
```

Вывод:

```
20.9346176061
```

## Решение

Зафиксируем точку P. Точки Q, для которых отрезок PQ задевает новое
здание, образуют выпуклое множество: конус из P вокруг здания, срезанный
по ближней к P стороне здания. P закрыта, когда в нём лежит вся
площадка, то есть когда P лежит между двумя внешними общими
касательными зданий — за новым зданием или внутри него. Так как
r_new > r_old, за новым зданием касательные расходятся, и закрытая
часть доходит до границы города.

Пусть d — расстояние между центрами и k = (r_new − r_old)/d. Единичные
нормали касательных образуют с направлением на новое здание угол с
косинусом −k, поэтому касаются его в точках C + r_new·n со стороны,
обращённой к площадке, и уходят от него вдоль C + (r_new − r_old)·n.
Каждая выходит из города там, где |T + tD| = R, — это квадратное
уравнение относительно t.

Площадь получается обходом закрытой части против часовой стрелки со
сложением ориентированных площадей относительно нового центра C: сектор
здания между точками касания со стороны площадки шириной 2·acos k;
треугольники от C до каждого отрезка касательной; дуга границы — это
треугольник от C до её концов плюс кусок города, отсечённый её хордой.
С ориентированными площадями сумма верна при любой форме. `O(1)`.

Подводные камни:

- точки касания лежат на стороне нового здания, обращённой к площадке,
  поэтому добавлять нужно сектор 2·acos k, а не дальний;
- основание нового здания тоже закрыто;
- `M_PI` не входит в стандарт C++ и отсутствует у жюри, поэтому решение
  на C++ использует `acos(-1)`.

Ответы совпадают с оценкой по сетке, сделанной прямо по определению, на
маленьких городах и с независимой принятой реализацией во всех десяти
выводимых знаках на 500 случайных наборах, включая здания, касающиеся
границы или почти касающиеся друг друга.
