# 1722. 观景台

[Timus 1722](https://acm.timus.ru/problem.aspx?space=1&num=1722) · 难度 1355 · geometry

原题作者 Eugene Kurpilyansky，出自 2009 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

城市是以原点为圆心、半径为 R 的圆。观景台是以原点为圆心、半径为 r_old 的圆形建筑的楼顶；
半径为 r_new 的新圆形建筑位于 (x, y)。两者都在城市内部且互不接触。
如果从观景台上任意一点到城市某点的线段都碰到新建筑，则该点被遮挡。求被遮挡部分占城市的百分比。

## 输入

R、r_old 和 r_new（1 ≤ r_old < r_new < R ≤ 1000），然后是整数 x 和 y。

## 输出

被遮挡部分的百分比，小数点后至少六位。

## 样例

### 样例 1

输入：

```
10 1 3
-1 4
```

输出：

```
20.9346176061
```

## 解法

固定一点 P。使线段 PQ 碰到新建筑的点 Q 构成一个凸集：从 P 出发包住建筑的锥体，在建筑靠近 P 的一侧截断。
当整个观景台都在其中时 P 被遮挡，也就是 P 位于两座建筑的两条外公切线之间、在新建筑后方或其内部。
由于 r_new > r_old，切线在新建筑后方张开，被遮挡部分一直延伸到城市边界。

设 d 为圆心距，k = (r_new − r_old)/d。切线的单位法向量与指向新建筑的方向夹角的余弦为 −k，
所以切点为 C + r_new·n，位于新建筑朝向观景台的一侧，切线沿 C + (r_new − r_old)·n 远离观景台。
每条切线在 |T + tD| = R 处离开城市，这是关于 t 的二次方程。

面积通过逆时针绕被遮挡部分一周、相对新圆心 C 累加有向面积得到：建筑在观景台一侧两切点之间的扇形，宽 2·acos k；
从 C 到每段切线的三角形；以及边界弧，它等于从 C 到弧两端的三角形加上弦切下的城市部分。
使用有向面积，无论形状如何总和都正确。`O(1)`。

注意事项：

- 切点位于新建筑朝向观景台的一侧，所以要加的是 2·acos k 的扇形，而不是远侧的；
- 新建筑的底面本身也被遮挡；
- `M_PI` 不属于标准 C++，评测上没有，所以 C++ 解答使用 `acos(-1)`。

在小城市上，答案与直接按定义做的网格估计一致；在 500 个随机数据（包括建筑接触边界或几乎相互接触的情况）上，
与一个独立的已通过实现在全部十位输出数字上一致。
