# 1719. 杀死魔头

[Timus 1719](https://acm.timus.ru/problem.aspx?space=1&num=1719) · 难度 1462 · geometry

原题作者 Alexander Ipatov，出自 NEERC 2009 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

玩家站在原点，四个魔头站在给定的点上，任意三个不共线。一次射击沿整条直线向两个方向发射，
杀死直线上的所有魔头。只剩两次射击，求能杀死全部四个魔头的最短行走距离。

## 输入

四行，每行是一个魔头的整数坐标，绝对值不超过 10000。

## 输出

最短距离，误差不超过 10⁻⁵。

## 样例

### 样例 1

输入：

```
-2 0
2 0
-2 4
2 4
```

输出：

```
2.0000000000
```

## 解法

任意三个魔头不共线，所以每次射击恰好杀死两个。于是有三种把魔头分成两条直线 L₁、L₂ 的方式，以及两种射击顺序。
玩家走到 L₁ 上某点 P，沿它射击，然后直接走到 L₂ 上的最近点再次射击。

令 L₁ 上 P = A + t·u（u 为单位方向），则路程为 f(t) = √((t − t₀)² + h²) + |k·t + m|。
其中 t₀ 是原点在 L₁ 上的投影，h 是原点到 L₁ 的距离；第二项是 P 到 L₂ 的距离：
对 L₂ 的单位法向量 n 有 k = n·u，且 |k| ≤ 1。两项都是凸函数，所以最小值在折点或导数为零处：

- t₀，当 L₂ 与 L₁ 平行时（k = 0）；
- 两直线的交点 t = −m/k，第二项在此转折；
- t₀ ± k·h/√(1 − k²)，在此第一项的导数（取值从 −1 到 1）抵消 ±k。

在这几个点上计算 f 并取最小值，就得到精确的最小值，无需搜索。`O(1)`。

注意事项：

- 玩家可以站在魔头所在的点上，或者一开始就在某条直线上：答案可能是 0（测试 02）；
- 两直线垂直时 |k| = 1，导数无法抵消，答案就在折点；
- 射击沿直线向两个方向进行，所以玩家无需走到魔头外侧。

在 900 个随机测试（包括远离原点的近乎平行的直线）上，答案与一个使用三分搜索的独立已通过实现一致。
