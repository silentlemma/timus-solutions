# 1782. 杰克的新单词

[Timus 1782](https://acm.timus.ru/problem.aspx?space=1&num=1782) · 难度 2126 · strings

原题作者 Alex Samsonov，出自第十五届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个二进制单词中没有满足 |y| ≤ 2|x| 的非空子串 xyxyx。从空单词出发，允许三种语句：在开头添一个字母，在末尾添一个字母，
或把每个 0 换成 01、每个 1 换成 10（加倍）。用至多 100 句语句得到该单词，或报告需要更多。

## 输入

这个单词，非空，至多 10⁵ 个字母。

## 输出

语句数 k（1 ≤ k ≤ 100）以及按顺序的语句 `front c`、`back c` 或 `double`，或者 −1。任何符合要求的描述都可以。

## 样例

### 样例 1

输入：

```
011010011
```

输出：

```
5
back 1
front 0
double
double
back 1
```

## 解法

倒着读，描述就是从单词两端去掉几个字母、撤销一次加倍、再去掉字母，如此往复。当单词的字母能两两配成 01 和 10 时就能撤销加倍，此时每对的第一个字母组成更短的单词。
没有这种禁止重复的单词有已知的结构：除去两端各至多两个字母，它是同类更短单词的加倍。所以单词 s 的最少语句数这样求：
尝试从两端各去掉至多五个字母（两个就够，五个留有余量）并撤销剩余部分的加倍，与直接逐个添加 s 的所有字母比较，取最省的；结果按单词记忆。
每一层遇到的单词互为片段，所以只需尝试几十个，而折半使层数约为 log₂ n。`O(n log n)`。

然后正向写出描述：先是更短的单词，然后加倍，再按相反顺序添加开头的字母，最后添加末尾的字母。若最少语句数也超过 100，答案为 −1。

样例中 01101001 是 0110 的加倍，0110 又是 01 的加倍：两个字母、两次加倍、末尾一个 1，共五句。

注意事项：

- 添加到开头的字母要按相反顺序输出；
- 出现 00 或 11 这样的一对，说明中间部分不是加倍得到的单词；
- 答案不唯一，所以检查器重放这些语句。

在 310 个单词上（由随机语句生成的短单词以及长至 10⁵ 的 Thue–Morse 单词片段），语句数与一个独立的已通过实现（广度优先搜索所有描述）找到的最少数相同。
