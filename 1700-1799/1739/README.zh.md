# 1739. 法留克果

[Timus 1739](https://acm.timus.ru/problem.aspx?space=1&num=1739) · 难度 1794 · bitmask

原题作者 Alex Samsonov，出自第十四届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

你在种植园里，想把 n 个果子带出去。每次通过大门可以带任意一组果子，但只有当它们的香味总和是 256 的整数倍时警报才不会响。
果子可以随意带回园内。除臭剂使一个果子的香味减弱 25%，香水使一个果子的香味增强 10%；
每种只能用一次（可以都用在同一个果子上），效果在果子通过大门后消失。用最少的出门次数带出所有果子并输出方案，或者报告不可能。

## 输入

n（1 ≤ n ≤ 12），然后是 n 个香味值，为 1 到 1000 的整数。

## 输出

`IMPOSSIBLE`，或者动作数量后跟各个动作：`take k a1 … ak`、`return s b1 … bs`、`dearomatize p` 和 `aromatize q`，
不超过 20 000 个。任何出门次数最少的方案都可以。

## 样例

### 样例 1

输入：

```
3
36 56 200
```

输出：

```
4
take 2 2 3
return 1 3
aromatize 3
take 2 1 3
```

### 样例 2

输入：

```
1
100
```

输出：

```
IMPOSSIBLE
```

## 解法

把果子带回园内没有代价，所以一次出门可以带任意一组果子，无论已在外面与否；只有仍在园内的果子重要，带得多永远不会更差。
对每种喷洒方式（不喷、除臭剂喷在果子 i 上、香水喷在果子 j 上、或两者都用）列出总香味能通过的组合，只保留不被其他组合包含的那些。
香味乘以 1000，使其 3/4、11/10 和 33/40 都保持为整数。Python、Java 和 Rust 的解答还会去掉被所需喷剂更少的组合包含的组合，出门方式因此少得多。

然后对"仍在园内的果子"和"已用的喷剂"做动态规划，得到最少出门次数：从一个状态出发，用某个未用过的喷洒方式所列出的组合出门，
就把这个组合从园内果子中去掉。回溯选择得到方案：把需要的、已在外面的果子带回，喷洒，带出。
设列出的组合有 M 个，复杂度为 `O(4·2ⁿ·M)`，列出它们需 `O(n²·2ⁿ)`。

样例 1 中先带出 56 + 200 = 256；然后把 200 带回，喷香水后变成 220，与 36 一起带出：36 + 220 = 256。

注意事项：

- 喷洒后的香味可能不是整数：0.75·100 和 1.1·36 都是分数，而总和必须是 256 的整数倍；
- 两种喷剂可以用在同一个果子上，得到它香味的 33/40；
- 单个果子只有在香味本来就是 256、512 或 768 时才能通过：任何喷洒都不能把 1 到 1000 中的其他香味变成 256 的倍数。

在 200 个最多 7 个果子的随机数据上，最少出门次数与用精确分数遍历所有组合和喷洒方式的广度优先搜索一致；
在大测试上与一个独立的已通过实现一致；检查程序重放了每个方案。Python 解答在 PyPy 下运行。
