# 1739. Фарюки

[Timus 1739](https://acm.timus.ru/problem.aspx?space=1&num=1739) · сложность 1794 · bitmask

Автор оригинальной задачи — Алексей Самсонов; XIV Открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Вы на плантации и хотите вынести n фарюков. За каждый выход через
проходную можно вынести любой набор фарюков, но тревога не поднимается,
только если их суммарный аромат — целое кратное 256. Заносить фарюки
обратно можно свободно. Дезодорант ослабляет аромат одного фарюка на
25%, духи усиливают аромат одного фарюка на 10%; каждое средство можно
использовать один раз за всё время, можно оба на один фарюк, а действие
кончается, когда фарюк проходит проходную. Вынести все фарюки за
наименьшее число выходов и вывести план или сообщить, что это
невозможно.

## Входные данные

n (1 ≤ n ≤ 12), затем n ароматов — целые числа от 1 до 1000.

## Выходные данные

`IMPOSSIBLE` или число действий, а затем сами действия: `take k a1 … ak`,
`return s b1 … bs`, `dearomatize p` и `aromatize q`, не больше 20 000.
Подходит любой план с наименьшим числом выходов.

## Примеры

### Пример 1

Ввод:

```
3
36 56 200
```

Вывод:

```
4
take 2 2 3
return 1 3
aromatize 3
take 2 1 3
```

### Пример 2

Ввод:

```
1
100
```

Вывод:

```
IMPOSSIBLE
```

## Решение

Заносить фарюки обратно ничего не стоит, поэтому за выход можно вынести
любой набор, уже снаружи или нет; важны только фарюки, оставшиеся
внутри, и больший набор никогда не хуже. Для каждого способа
обработки (никакого, дезодорант на фарюк i, духи на фарюк j или оба)
выписываем наборы, суммарный аромат которых проходит, и оставляем лишь
не содержащиеся в другом. Ароматы умножаются на 1000, чтобы 3/4, 11/10
и 33/40 от них оставались целыми. Решения на Python, Java и Rust
отбрасывают ещё и набор, содержащийся в наборе с меньшим числом
средств, что сильно сокращает число ходов.

Затем динамика по фарюкам, оставшимся внутри, и использованным
средствам даёт наименьшее число выходов: из состояния выход с
выписанным набором неиспользованного вида обработки убирает набор из
оставшихся внутри. Восстановление выбора даёт план: занести нужные
фарюки, которые снаружи, обработать, вынести. `O(4·2ⁿ·M)` при M
выписанных наборах плюс `O(n²·2ⁿ)` на их выписывание.

В первом примере сначала выходят 56 + 200 = 256; затем 200 заносится
обратно, после духов становится 220 и выходит вместе с 36:
36 + 220 = 256.

Подводные камни:

- обработанный аромат может быть нецелым: 0,75·100 и 1,1·36 — дроби, а
  сумма должна быть целым кратным 256;
- оба средства можно применить к одному фарюку, это даёт 33/40 его
  аромата;
- один фарюк проходит, только если его аромат уже 256, 512 или 768:
  никакая обработка не превращает другой аромат от 1 до 1000 в кратное
  256.

Наименьшее число выходов совпадает с поиском в ширину по всем наборам и
обработкам с точными дробями на 200 случайных наборах до 7 фарюков и с
независимой принятой реализацией на больших тестах; проверяющая
программа проигрывает каждый план. Решение на Python работает под
PyPy.
