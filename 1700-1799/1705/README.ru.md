# 1705. Зайцы-бандиты

## Задача

Банда из k зайцев украла n кочанов и поделила их поровну, а остаток
меньше k достался лисе. К дележу незаметно присоединился ещё один заяц:
при k + 1 зайцах каждый получил ровно столько же, сколько при k. Для
каждого n найти наименьшее возможное k.

## Входные данные

Число тестов t (1 ≤ t ≤ 30000), затем t строк с n (1 ≤ n ≤ 10^18).

## Выходные данные

Для каждого теста наименьшее k в отдельной строке.

## Примеры

### Пример 1

Ввод:

```
3
9
11
18
```

Вывод:

```
5
4
5
```

## Решение

Нужно наименьшее k, при котором ⌊n/k⌋ = ⌊n/(k + 1)⌋. Пусть q = ⌊n/k⌋ и
r = n mod k; равенство верно ровно тогда, когда лишнего зайца можно
накормить из остатка, то есть r ≥ q. Так как r < k, нужно q < k, и k
больше s = ⌊√n⌋.

Запишем n = s² + e и k = s + x, x ≥ 1. Поскольку (s + x)(s − x) =
s² − x², получаем n = k(s − x) + x² + e, так что частное равно s − x
или s − x + 1:

- частное s − x, остаток x² + e: условие x² + x ≥ s − e;
- частное s − x + 1, остаток x² + e − s − x: условие x² ≥ 2s − e + 1.

Каждое неравенство даёт своё наименьшее x через один целый квадратный
корень. Вблизи границ между случаями оценка может ошибиться на единицу,
поэтому для обоих x прямо проверяются k = s + x − 1, s + x и
s + x + 1, и ответ — наименьшее подходящее k. Маленькие n (меньше 100)
перебираются. `O(1)` на тест.

Подводные камни:

- n доходит до 10^18, поэтому всё 64-битное; вещественный корень там
  неточен и поправляется целочисленными сравнениями;
- самые маленькие n ведут себя иначе: при n = 1 ответ 2, при n = 2 — 3
  (в тесте 02 все n до 100);
- до 30000 тестов, так что ввод и вывод должны быть быстрыми.

Ответы совпадают с полным перебором для всех n до 200000 и с
независимой принятой реализацией на 15000 значениях до 10^18, включая
числа рядом с квадратами и произведениями s(s + 1).
