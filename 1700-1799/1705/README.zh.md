# 1705. 强盗兔子

[Timus 1705](https://acm.timus.ru/problem.aspx?space=1&num=1705) · 难度 948 · math

原题作者 Alexander Ipatov，出自 2009 年 4 月 4 日第十三届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

k 只兔子组成的团伙偷了 n 棵白菜并平分，不足 k 棵的余数归狐狸。分配时又有一只兔子悄悄加入：
k + 1 只兔子时每只分到的数量与 k 只时完全相同。对每个 n，求最小可能的 k。

## 输入

测试数 t（1 ≤ t ≤ 30000），然后 t 行，每行一个 n（1 ≤ n ≤ 10^18）。

## 输出

对每个测试，在单独一行输出最小的 k。

## 样例

### 样例 1

输入：

```
3
9
11
18
```

输出：

```
5
4
5
```

## 解法

要求最小的 k 使 ⌊n/k⌋ = ⌊n/(k + 1)⌋。设 q = ⌊n/k⌋，r = n mod k；等式成立当且仅当多出的兔子能从余数里分到，
即 r ≥ q。由于 r < k，需要 q < k，所以 k 大于 s = ⌊√n⌋。

记 n = s² + e，k = s + x，x ≥ 1。因为 (s + x)(s − x) = s² − x²，有 n = k(s − x) + x² + e，
所以商为 s − x 或 s − x + 1：

- 商为 s − x，余数 x² + e：条件为 x² + x ≥ s − e；
- 商为 s − x + 1，余数 x² + e − s − x：条件为 x² ≥ 2s − e + 1。

每个不等式通过一次整数平方根得到各自最小的 x。在两种情况的分界附近估计可能差一，
所以对两个 x 都直接检验 k = s + x − 1、s + x 和 s + x + 1，取满足条件的最小 k。
较小的 n（小于 100）直接枚举。每个测试 `O(1)`。

注意事项：

- n 可达 10^18，全部使用 64 位整数；此时浮点平方根不精确，需要用整数比较修正；
- 最小的几个 n 情况不同：n = 1 时答案为 2，n = 2 时为 3（测试 02 包含 100 以内的所有 n）；
- 测试最多 30000 组，输入输出要快。

答案与 200000 以内所有 n 的暴力结果一致，并在 15000 个不超过 10^18 的值上与一个独立的已通过实现一致，
其中包括平方数和乘积 s(s + 1) 附近的数。
