# 1730. Челмедведосвин

[Timus 1730](https://acm.timus.ru/problem.aspx?space=1&num=1730) · сложность 1146 · constructive

## Задача

Скрещивание двух существ даёт существо, в котором доля каждого
животного — среднее двух долей. По животным и их долям в существе
выписать родословную, которая его даёт: список строк, каждая — животное
или скрещивание двух предыдущих строк, последняя — само существо, и
каждая строка, кроме последней, участвует в каком-то скрещивании.
Вывести `No solution`, если такой нет.

## Входные данные

Название существа: от одного до десяти различных названий животных
через дефис, не длиннее 200 символов. Затем доля каждого животного
дробью a/b (1 ≤ a ≤ b ≤ 1500); сумма долей равна 1.

## Выходные данные

Число строк n (1 ≤ n ≤ 10 000) и сами строки или `No solution`.
Подходит любая подходящая родословная.

## Примеры

### Пример 1

Ввод:

```
man-bear-pig
1/2 1/4 1/4
```

Вывод:

```
7
man
pig
1 2
bear
man
4 5
3 6
```

### Пример 2

Ввод:

```
man
1/1
```

Вывод:

```
1
man
```

### Пример 3

Ввод:

```
man-bear-pig
1/3 1/3 1/3
```

Вывод:

```
No solution
```

## Решение

Каждая доля при скрещивании — среднее двух долей, поэтому по индукции
у любой доли в любой родословной знаменатель — степень двойки. Если у
какой-то несократимой доли это не так, решения нет.

Иначе пусть L — наибольший несократимый знаменатель, не больше 1024.
Раздадим животным по их доле из L одинаковых листьев, по порядку, и
построим над листьями сбалансированное двоичное дерево: каждая
внутренняя вершина скрещивает свои две половины, так что каждый лист
даёт ровно 1/L существа. Поддерево, все листья которого — одно
животное, и есть это животное, поэтому становится одной строкой.
Получается не больше 2L − 1 ≤ 2047 строк. `O(L)`.

В первом примере L = 4 и листья — man, man, bear, pig. Левая половина —
чистый man, правая скрещивает bear с pig, так что родословная: man,
bear, pig, 2 3, 1 4.

Подводные камни:

- доли даны несокращёнными, например 750/1500, и их надо сократить,
  прежде чем смотреть на знаменатель;
- чистое животное — родословная из одной строки, совсем без
  скрещиваний;
- одно и то же животное может стоять в нескольких строках.

Проверяющая программа проигрывает родословную точными дробями и
проверяет доли, ссылки на строки и то, что каждый предок использован.
Родословные проходят её на 200 случайных наборах, а `No solution`
выводится ровно там же, где у независимой принятой реализации.
