# 1735. Похищение века

## Задача

Есть n мешков по k слитков; в каждом мешке только золотые слитки по x
кг или только платиновые по y кг, и внешне слитки неотличимы. Выбрать,
сколько слитков взять из каждого мешка, чтобы одно точное взвешивание
показало, в каких мешках платина, или сообщить, что это невозможно.

## Входные данные

n, k, x и y (3 ≤ n ≤ 20, 1 ≤ k ≤ 10⁶, 1 ≤ x < y ≤ 10).

## Выходные данные

`YES` и n количеств или `NO`. Подходят любые подходящие количества.

## Примеры

### Пример 1

Ввод:

```
4 8 9 10
```

Вывод:

```
YES
4 5 6 8
```

## Решение

При количествах c_i весы показывают x·Σc_i + (y − x)·P, где P — сумма
количеств из платиновых мешков. Первое слагаемое одинаково при любом
раскладе, поэтому взвешивание различает платиновые мешки ровно тогда,
когда все 2ⁿ сумм подмножеств количеств различны. В частности,
количества положительны и различны, а x и y не важны.

Значит, вопрос в наименьшем возможном наибольшем элементе множества из
n положительных чисел с различными суммами подмножеств. Последовательность
Конвея — Гая u₀ = 0, u₁ = 1, u_{m+1} = 2u_m − u_{m−r} при
r = round(√(2m)) даёт множества {u_n − u_i : 0 ≤ i < n} с различными
суммами подмножеств и наибольшим элементом u_n: 1, 2, 4, 7, 13, 24, 44,
84, 161, 309, … до 267 420 при n = 20. Код выводит это множество,
если u_n ≤ k, иначе `NO`. `O(n)`.

В примере u₄ = 7 ≤ 8, и множество — 3, 5, 6, 7.

Подводные камни:

- степени двойки 1, 2, 4, … тоже подходят, но требуют 2ⁿ⁻¹ слитков,
  при больших n намного больше u_n;
- количество 0 полностью скрывает свой мешок, поэтому из каждого мешка
  нужно взять хотя бы один слиток.

При n до 6 перебор показывает, что меньшего наибольшего элемента не
бывает; для больших n есть лучшие множества (максимум 1157 при n = 12),
хотя эти границы совпадают с независимой принятой реализацией при n от 3
до 20 по обе стороны от u_n. Каждое выведенное множество проверено на
различие сумм подмножеств.
