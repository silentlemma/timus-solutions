# 1754. 金字塔中的爆炸

[Timus 1754](https://acm.timus.ru/problem.aspx?space=1&num=1754) · 难度 646 · geometry

原题作者 Alexander Ipatov，出自 2010 年 3 月 13 日第十一届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个空心三棱锥的底面顶点为 (x₁, y₁, 0)、(x₂, y₂, 0)、(x₃, y₃, 0)，顶点为 (x₄, y₄, H)。巫妖从 (x₀, y₀, 0) 升到 (x₀, y₀, h)，花费 h 点法力，
然后以该点为中心造一个球形力场，花费等于半径的法力。力场只要碰到墙或地面，金字塔就会倒塌。有 m 点法力，巫妖能把它弄塌吗？

## 输入

m、h 和 H（1 ≤ m, h, H ≤ 1000），然后是五个点 xᵢ, yᵢ（−1000 ≤ xᵢ, yᵢ ≤ 1000）。点 (x₀, y₀, h) 严格位于金字塔内部。

## 输出

`YES` 或 `NO`。

## 样例

### 样例 1

输入：

```
13 6 30
6 6
0 0
0 30
30 0
0 0
```

输出：

```
YES
```

### 样例 2

输入：

```
11 6 30
6 6
0 0
0 30
30 0
0 0
```

输出：

```
NO
```

## 解法

上升后还剩 m − h 点法力，力场必须够到金字塔表面最近的点。从凸体内部的一点出发，这就是到各个面所在平面距离的最小值：到地面为 h，
到经过底角 A、B 和顶点的墙为 |n·(P − A)| / |n|，其中 n 是 B − A 与（顶点 − A）的叉积。当 m − h ≥ 0 且其中某个距离不超过 m − h 时答案为 `YES`。

距离可能恰好等于 m − h（例如竖直的墙），所以比较时不做舍入：|n·(P − A)| ≤ k·|n| 变为 (n·(P − A))² ≤ k²·|n|²，其中 k = m − h。
左边可达约 3·10²⁰，超过 64 位，所以乘积用 128 位计算，语言没有时用大整数。`O(1)`。

样例中地面和两面竖直墙 x = 0、y = 0 的距离都是 6，斜墙约 6.93，所以需要 6 + 6 = 12 点法力：13 够，11 不够。

注意事项：

- m < h 时巫妖连升起来都做不到；
- 带容差的浮点数可能把只差一点点够不到 m − h 的距离判错；
- 底面三个角的顺序可以是任意方向。

在 450 个随机金字塔上答案与一个独立的已通过实现一致，其中三分之一带有整数距离的竖直墙，法力恰好在临界值附近。
