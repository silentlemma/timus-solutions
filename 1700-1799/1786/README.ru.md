# 1786. Биография Сандро

[Timus 1786](https://acm.timus.ru/problem.aspx?space=1&num=1786) · сложность 110 · strings

Автор оригинальной задачи — Ольга Соболева; Уральская региональная командная олимпиада по программированию 2010.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Текст из латинских букв нужно изменить так, чтобы в нём встретилось
слово "Sandro". Замена буквы на другую букву того же регистра стоит
5 монет, смена регистра буквы — тоже 5. Найти наименьшую стоимость.

## Входные данные

Текст длиной от 6 до 200 букв.

## Выходные данные

Наименьшее число монет.

## Примеры

### Пример 1

Ввод:

```
MyNameIsAlexander
```

Вывод:

```
20
```

## Решение

Перебираем все места для шести букв имени. Буква стоит 5, если у неё
неверный регистр, и ещё 5, если это не та буква, так что буква,
неверная в обоих смыслах, стоит 10. Складываем шесть стоимостей в
каждом месте и берём наименьшую сумму. `O(n)`.

В примере лучшее место — "xander": x нужна другая буква и заглавный
регистр — 10, а замены e → r и r → o стоят по 5, всего 20.

Подводные камни:

- неверная буква неверного регистра оплачивается дважды;
- имя может начинаться с самой первой буквы или кончаться самой
  последней.

Ответы совпадают с независимой принятой реализацией на 150 случайных
текстах: случайные буквы, испорченные копии имени и тексты только из
букв имени.
