# 1786. Биография Сандро

[Timus 1786](https://acm.timus.ru/problem.aspx?space=1&num=1786) · сложность 110 · strings

Автор оригинальной задачи — Ольга Соболева; Уральская региональная командная олимпиада по программированию 2010.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Текст из латинских букв нужно изменить так, чтобы в нём встретилось
слово "Sandro". Замена буквы на другую букву того же регистра стоит
5 монет, смена регистра буквы — тоже 5. Найти наименьшую стоимость.

## Входные данные

Текст длиной от 6 до 200 букв.

## Выходные данные

Наименьшее число монет.

## Примеры

### Пример 1

Ввод:

```
MyNameIsAlexander
```

Вывод:

```
20
```

## Решение

Перебираем все места для шести букв имени. Буква стоит 5, если у неё
неверный регистр, и ещё 5, если это не та буква, так что буква,
неверная в обоих смыслах, стоит 10. Складываем шесть стоимостей в
каждом месте и берём наименьшую сумму. Сам перебор занимает `O(n)` времени,
но Python в каждой позиции копирует суффикс `text[start:]`, поэтому эта
реализация работает за `O(n^2)`. Все реализации используют `O(n)` памяти
с учётом входной строки; максимальная длина входа — всего 200.

В примере лучшее место — "xander": x нужна другая буква и заглавный
регистр — 10, а замены e → r и r → o стоят по 5, всего 20.

Подводные камни:

- неверная буква неверного регистра оплачивается дважды;
- в тесте 03, `sANDRO`, неверен регистр всех шести букв, поэтому стоимость — 30;
- имя может начинаться с самой первой буквы или кончаться самой
  последней.

Ответы Python совпадают с независимым оракулом на графе допустимых операций
на 2 000 случайных коротких текстах, 592 направленных проверках, всех 8
сохранённых тестах и 64 сгенерированных тестах.

## Оптимизированные решения

Оптимизированное решение на C++ читает текст через `scanf` в буфер на
201 байт, которого хватает на 200 букв и завершающий ноль, вместо
`std::cin` и `std::string`, а раз в тексте только латинские буквы,
регистр определяется сравнением с `'Z'`, а буква переводится в нижний
регистр прибавлением `'a' − 'A'` вместо вызовов `isupper` и `tolower`:
{1786_strings_optimized.cpp}.

Оптимизированное решение на Java читает текст посимвольно прямо из
`System.in` вместо создания `Scanner`, а раз в тексте только латинские
буквы, регистр определяется сравнением с `'Z'`, а буква переводится в
нижний регистр прибавлением `'a' − 'A'` вместо вызовов
`Character.isUpperCase` и `Character.toLowerCase`:
{1786_strings_optimized.java}.
