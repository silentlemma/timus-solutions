## Задача

Вася садится первым в ряд из n мест, на место k; остальные приходят по
одному, пока ряд не заполнится. Каждый заходит с того края, где между
краем и его местом уже сидит меньше людей, а при равенстве — с более
близкого края. Найти наибольшее число людей, которые споткнутся о ноги
Васи.

## Входные данные

n и k (1 ≤ k ≤ n ≤ 50, n чётно).

## Выходные данные

Наибольшее число людей, споткнувшихся о Васю.

## Примеры

### Пример 1

Ввод:

```
4 1
```

Вывод:

```
1
```

## Решение

Назовём дальней стороной более длинную часть ряда за Васей; в ней
max(k − 1, n − k) мест. Ответ — это число минус 2, но не меньше 0.
`O(1)`.

Два места у дальнего края никогда не спотыкаются. За последним местом
никого нет, а за предпоследним — не больше одного человека, тогда как с
другой стороны сидит Вася, и при равенстве ближе его собственный край.

Все остальные на дальней стороне споткнуться могут. Сначала посадим два
крайних места, затем заполним дальнюю сторону от её края к Васе. Тогда
у каждого нового человека со стороны Васи на пути только Вася, а с
другой — хотя бы двое, поэтому он идёт мимо Васи.

Люди с ближней стороны тоже могут споткнуться, но только когда ближняя
сторона уже намного полнее дальней, и тогда люди с дальней стороны
видят слишком много народу со стороны Васи и перестают спотыкаться.
Это никогда не окупается.

В примере на дальней стороне три места, поэтому спотыкается один
человек: с места 2, после того как заняты места 3 и 4.

Подводные камни:

- при n = 2 или Васе в середине ряда из четырёх мест ответ 0, а не
  отрицательное число;
- дальняя сторона может оказаться с любой стороны от Васи.

Формула совпадает с полным перебором всех порядков прихода для всех
чётных n до 16 и всех k.
