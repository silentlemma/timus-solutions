# 1712. Шифровальная решётка

[Timus 1712](https://acm.timus.ru/problem.aspx?space=1&num=1712) · сложность 86 · implementation

## Задача

В решётке 4 × 4 вырезаны четыре окошка. Положенная на листок 4 × 4,
она открывает четыре клетки, и в них по порядку чтения пишутся
очередные четыре буквы пароля из 16 букв. Затем решётку поворачивают на
90° по часовой стрелке, и так четыре раза, так что в каждую клетку
попадает ровно одна буква. По решётке в начальном положении и
заполненному листку восстановить пароль.

## Входные данные

Четыре строки решётки, X — окошко, . — бумага, затем четыре строки
листка: латинские буквы обоих регистров.

## Выходные данные

Пароль из 16 букв.

## Примеры

### Пример 1

Ввод:

```
....
X..X
.X..
...X
Pwoo
Khaa
smrs
odbk
```

Вывод:

```
KamkohobPassword
```

## Решение

Повторим запись. В каждом из четырёх положений соберём буквы под
окошками по строкам и слева направо, затем повернём решётку. Поворот по
часовой стрелке переводит клетку (r, c) в (c, 3 − r), так что в
повёрнутой решётке в (r, c) стоит то, что в старой было в (3 − c, r).
`O(1)`.

Подводные камни:

- в одном положении буквы идут в порядке чтения окошек, а не в том
  порядке, в каком они были найдены в предыдущем положении;
- поворот по часовой стрелке: поворот в другую сторону читает те же
  клетки в другом порядке (в тесте 04 все четыре окошка в одном углу);
- во входе нет пробелов, так что чтение словами работает в любом языке.

Ответы совпадают с независимой принятой реализацией на 300 случайных
правильных решётках.

## Оптимизированные решения

Оптимизированные решения (C++, Java) читают оба квадрата посимвольно в
массивы фиксированного размера 4 × 4, а не словами, и печатают буквы
пароля по мере нахождения (C++) или собирают их в массив из 17 байт
(Java). Java к тому же переиспользует один массив для повёрнутой
решётки, а не выделяет новый на каждый поворот. C++: 84 КБ вместо 348 КБ
при том же времени; Java: 0.109 с вместо 0.140 с и 348 КБ вместо
1568 КБ.
