# 1772. Лыжни для роботов

[Timus 1772](https://acm.timus.ru/problem.aspx?space=1&num=1772) · сложность 738 · segment_tree

## Задача

От старта до финиша идут n параллельных лыжней, лыжник стартует на
лыжне s. По пути он по порядку встречает k упавших роботов, каждый
перегораживает лыжни с l по r; между ними можно переходить вбок, по
одной лыжне в секунду. Ни один робот не перегораживает все лыжни. Найти
наименьшее число секунд на переходы, чтобы объехать всех.

## Входные данные

n, s и k (2 ≤ n ≤ 10⁵, 1 ≤ s ≤ n, 0 ≤ k ≤ 10⁵), затем k перегороженных
отрезков l и r (1 ≤ l ≤ r ≤ n) в порядке встречи.

## Выходные данные

Наименьшее число секунд.

## Примеры

### Пример 1

Ввод:

```
5 3 2
2 5
1 4
```

Вывод:

```
6
```

## Решение

Пусть f(x) — наименьшее время, чтобы оказаться на лыжне x после уже
встреченных роботов и свободно двигаться дальше. В начале
f(x) = |x − s|, и f никогда не отличается больше чем на 1 у соседних
лыжней: лишний шаг исправляет разницу. Робот на лыжнях с l по r не
меняет f вне их, а внутри задаёт f(x) = min(f(l − 1) + (x − l + 1),
f(r + 1) + (r + 1 − x)): лыжник проезжает по лыжне l − 1 или r + 1 и
потом возвращается внутрь. Объезд дальше не помогает: там f уже
наименьшая по правилу шага.

Значит, каждый робот присваивает отрезку лыжней функцию вида
min(a + x, b − x), а f(x) задаётся последним роботом, покрывающим x, или
стартом, если таких нет. Дерево отрезков хранит в каждой вершине
последнего робота, чей отрезок покрывает всю вершину; последний робот
над лыжней — наибольший из них на пути к корню. Каждому роботу нужны два
запроса и одно присваивание, а ответ — наименьшая f по всем лыжням в
конце. `O((n + k) log n)`.

В примере f сначала 2 1 0 1 2. Робот на лыжнях 2—5 оставляет лыжне 1
значение 2 и делает остальные 3 4 5 6; робот на лыжнях 1—4 оставляет
лыжне 5 значение 6 и делает остальные 10 9 8 7, так что ответ 6.

Подводные камни:

- робота у края можно объехать только с одной стороны;
- сумма может доходить примерно до 10¹⁰, когда роботы гоняют лыжника
  от края до края, — больше 32 бит;
- лыжни внутри перегороженного отрезка снова доступны сразу после него.

Ответы совпадают с динамикой по лыжням со всеми переходами на 400
случайных случаях до 9 лыжней и с независимой принятой реализацией на
48 случаях до 10⁵ лыжней и роботов. Решение на Python работает под PyPy.
