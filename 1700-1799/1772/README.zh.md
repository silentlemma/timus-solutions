# 1772. 机器人的滑雪道

[Timus 1772](https://acm.timus.ru/problem.aspx?space=1&num=1772) · 难度 738 · segment_tree

原题作者 Alex Samsonov，出自 2010 年 4 月 10 日第十四届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

从起点到终点有 n 条平行雪道，滑雪者从第 s 条出发。沿途依次遇到 k 个倒下的机器人，每个挡住第 l 到第 r 条雪道；
在它们之间可以横向移动，每秒一条雪道。没有机器人挡住全部雪道。求绕过所有机器人所需的最少横移秒数。

## 输入

n、s 和 k（2 ≤ n ≤ 10⁵，1 ≤ s ≤ n，0 ≤ k ≤ 10⁵），然后按遇到的顺序给出 k 个被挡住的区间 l 和 r（1 ≤ l ≤ r ≤ n）。

## 输出

最少秒数。

## 样例

### 样例 1

输入：

```
5 3 2
2 5
1 4
```

输出：

```
6
```

## 解法

设 f(x) 为通过已遇到的机器人后位于雪道 x 并可自由继续前进的最少时间。开始时 f(x) = |x − s|，且相邻雪道的 f 之差从不超过 1：多走一步就能弥补差距。
挡住 l 到 r 的机器人不改变区间外的 f，而在区间内令 f(x) = min(f(l − 1) + (x − l + 1), f(r + 1) + (r + 1 − x))：
滑雪者从 l − 1 或 r + 1 号雪道通过，之后再移回来。绕得更远没有好处，因为按横移规则那里的 f 已经最小。

所以每个机器人给一段雪道赋上形如 min(a + x, b − x) 的函数，而 f(x) 由覆盖 x 的最后一个机器人给出，若没有则由起点给出。
线段树在每个结点保存其区间被完整覆盖的最后一个机器人；覆盖某条雪道的最后一个机器人就是它到根路径上这些值的最大者。
每个机器人需要两次查询和一次赋值，答案是最后所有雪道上 f 的最小值。`O((n + k) log n)`。

样例中 f 起初为 2 1 0 1 2。挡住 2 到 5 的机器人让雪道 1 保持 2，其余变为 3 4 5 6；挡住 1 到 4 的机器人让雪道 5 保持 6，其余变为 10 9 8 7，所以答案为 6。

注意事项：

- 靠边的机器人只能从一侧绕过；
- 机器人迫使滑雪者在两边来回时，总数可达约 10¹⁰，超过 32 位；
- 被挡区间内的雪道在机器人之后立即又可以使用。

在 400 个最多 9 条雪道的随机情形上，答案与按雪道考虑所有移动的动态规划一致；在 48 个最多 10⁵ 条雪道和机器人的情形上与一个独立的已通过实现一致。Python 解答在 PyPy 下运行。
