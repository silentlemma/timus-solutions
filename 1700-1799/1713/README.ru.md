# 1713. Ключевые подстроки

[Timus 1713](https://acm.timus.ru/problem.aspx?space=1&num=1713) · сложность 636 · strings

Автор оригинальной задачи — Дмитрий Иванков (идея — Александр Мироненко); NEERC 2009, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Ключ команды — её подстрока, которая не является подстрокой никакой
другой команды. Для каждой из n команд найти кратчайший ключ.

## Входные данные

n (2 ≤ n ≤ 1000), затем n команд: строчные латинские буквы, от 1 до
100. Никакая команда не является подстрокой другой.

## Выходные данные

Кратчайший ключ каждой команды в порядке ввода. Подходит любой
кратчайший ключ.

## Примеры

### Пример 1

Ввод:

```
3
abcm
acm
bcd
```

Вывод:

```
ab
ac
d
```

## Решение

Подстрока, начинающаяся в позиции p команды, встречается в другой
команде ровно тогда, когда она — префикс какого-то суффикса этой другой
команды. Поэтому в позиции p кратчайший ключ на букву длиннее
наибольшего общего префикса с суффиксами других команд, если он
помещается до конца команды.

Отсортируем все суффиксы всех команд, их не больше 10⁵. В
отсортированном порядке общий префикс двух суффиксов равен минимуму
общих префиксов соседей между ними. Поэтому наибольший общий префикс с
суффиксом другой команды достигается на ближайшем таком суффиксе сверху
или снизу. Два прохода его находят. При проходе вниз текущее значение
начинается заново с общего префикса с соседом, если сосед из другой
команды, а иначе берёт минимум с ним. Проход вверх устроен так же.
Лучшее начало каждой команды и даёт её ключ. `O(L log L · ℓ)` при L
буквах всего и командах длины ℓ.

Подводные камни:

- вся команда всегда ключ, так как ни одна команда не содержится в
  другой, поэтому ответ есть у каждой команды;
- подстрока, повторяющаяся внутри своей же команды, всё равно ключ:
  считаются только другие команды;
- подходит любой кратчайший ключ, поэтому тесты используют
  проверяющую программу.

Проверяющая программа убеждается, что каждый ключ лежит в своей
команде, ни в какой другой, и имеет наименьшую длину. Длины совпадают с
независимой принятой реализацией на 200 маленьких случайных наборах и
на больших.
