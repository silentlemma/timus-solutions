# 1713. 关键子串

[Timus 1713](https://acm.timus.ru/problem.aspx?space=1&num=1713) · 难度 636 · strings

原题作者 Dmitry Ivankov（创意来自 Alexander Mironenko），出自 NEERC 2009 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

命令的关键子串是它的一个子串，且不是任何其他命令的子串。对 n 条命令中的每一条，求一个最短的关键子串。

## 输入

n（2 ≤ n ≤ 1000），然后是 n 条命令：由 1 到 100 个小写拉丁字母组成。没有命令是另一条命令的子串。

## 输出

按输入顺序输出每条命令的一个最短关键子串。任何最短关键子串都可以。

## 样例

### 样例 1

输入：

```
3
abcm
acm
bcd
```

输出：

```
ab
ac
d
```

## 解法

从命令位置 p 开始的子串出现在另一条命令中，当且仅当它是那条命令某个后缀的前缀。
所以位置 p 处的最短关键子串，比它与其他命令后缀的最长公共前缀多一个字母（前提是在命令结束前放得下）。

把所有命令的所有后缀排序，至多 10⁵ 个。在排好的顺序中，两个后缀的公共前缀等于它们之间相邻后缀公共前缀的最小值，
所以与其他命令后缀的最大公共前缀在上方或下方最近的这种后缀处取得。两次扫描即可求出：向下扫描时，
若相邻后缀属于另一条命令，当前值重新从与它的公共前缀开始，否则与它取最小值；向上扫描同理。
每条命令的最佳起点就给出它的关键子串。设所有命令共有 L 个字母、命令长度为 ℓ，复杂度为 `O(L log L · ℓ)`。

注意事项：

- 整条命令总是关键子串，因为没有命令被包含在另一条中，所以每条命令都有答案；
- 在自身命令中重复出现的子串仍然是关键子串：只考虑其他命令；
- 任何最短关键子串都可以，所以测试使用检查程序。

检查程序验证每个关键子串属于自己的命令、不属于其他命令，并且长度最小。
在 200 个小型随机数据和若干大型数据上，长度与一个独立的已通过实现一致。
