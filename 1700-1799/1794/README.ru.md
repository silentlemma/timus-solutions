## Задача

n учеников сидят по кругу, пронумерованные от 1 до n по часовой
стрелке, и выступают друг за другом по часовой стрелке. Ученик i хочет
выступить aᵢ-м. Выбрать, кто выступит первым, чтобы как можно больше
учеников выступили ровно в желаемую очередь. Принимается любой лучший
выбор.

## Входные данные

n (2 ≤ n ≤ 10⁵), затем a₁, …, aₙ (1 ≤ aᵢ ≤ n).

## Выходные данные

Номер ученика, который начинает.

## Проверка

Принимается любой начинающий ученик с максимальным числом выполненных желаний; единственный минимальный номер не требуется.

## Примеры

### Пример 1

Ввод:

```
4
4 1 2 3
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
3
1 1 1
```

Вывод:

```
3
```

## Решение

Если начинает ученик k, ученик i выступает в очередь
((i − k) mod n) + 1. Значит, ученика i устраивает ровно одно начало:
k = ((i − aᵢ) mod n) + 1. Считаем эти голоса по всем ученикам и
выводим начало с наибольшим числом голосов. `O(n)`.

В первом примере все четверо голосуют за начало 2: например, ученик 1
хочет быть четвёртым, а порядок 2, 3, 4, 1 ставит его четвёртым.

Подводные камни:

- i − aᵢ бывает отрицательным, и в C++, Go и Java остаток тогда тоже
  отрицателен;
- несколько начал могут набрать поровну, как во втором примере, где
  принимается любое из трёх.

Чекер сам считает голоса и принимает любое начало с наибольшим их
числом. Он согласуется с прямым подсчётом по всем началам на 300
маленьких классах, а ответы совпадают с независимой принятой
реализацией на больших.

## Оптимизированные решения

Для каждого возможного начинающего ученика сохраняется число голосов. Разность индексов строго лежит между минусом и плюсом размера класса, поэтому достаточно одного условного прибавления вместо общих операций остатка. Буферизованный ввод не хранит все предпочтения; беззнаковые 32-битные счётчики достаточны, поскольку каждый ограничен размером класса. Реализация выбирает первый максимум, хотя условие принимает любого оптимального начинающего ученика.

- `1794_implementation_optimized.cpp`: 0.015 s / 520 KB; база `1794_implementation.cpp`: 0.078 s / 568 KB; изменение относительно базы: время -80.8%, память -8.5%.
- `1794_implementation_optimized.py`: 0.187 s / 912 KB; база `1794_implementation.py`: 0.125 s / 8004 KB; изменение относительно базы: время +49.6%, память -88.6%.
