## Задача

n учеников сидят по кругу, пронумерованные от 1 до n по часовой
стрелке, и выступают друг за другом по часовой стрелке. Ученик i хочет
выступить aᵢ-м. Выбрать, кто выступит первым, чтобы как можно больше
учеников выступили ровно в желаемую очередь. Принимается любой лучший
выбор.

## Входные данные

n (2 ≤ n ≤ 10⁵), затем a₁, …, aₙ (1 ≤ aᵢ ≤ n).

## Выходные данные

Номер ученика, который начинает.

## Примеры

### Пример 1

Ввод:

```
4
4 1 2 3
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
3
1 1 1
```

Вывод:

```
3
```

## Решение

Если начинает ученик k, ученик i выступает в очередь
((i − k) mod n) + 1. Значит, ученика i устраивает ровно одно начало:
k = ((i − aᵢ) mod n) + 1. Считаем эти голоса по всем ученикам и
выводим начало с наибольшим числом голосов. `O(n)`.

В первом примере все четверо голосуют за начало 2: например, ученик 1
хочет быть четвёртым, а порядок 2, 3, 4, 1 ставит его четвёртым.

Подводные камни:

- i − aᵢ бывает отрицательным, и в C++, Go и Java остаток тогда тоже
  отрицателен;
- несколько начал могут набрать поровну, как во втором примере, где
  принимается любое из трёх.

Чекер сам считает голоса и принимает любое начало с наибольшим их
числом. Он согласуется с прямым подсчётом по всем началам на 300
маленьких классах, а ответы совпадают с независимой принятой
реализацией на больших.
