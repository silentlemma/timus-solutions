# 1715. Another Ball Killer

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Поле n × m заполнено шариками пяти цветов. Ход удаляет фигуру —
связную (по сторонам) группу из двух или более шариков одного цвета — и
приносит k(k − 1) очков за k шариков. Шарики сверху падают вниз, а
опустевшая колонка сдвигает колонки справа от неё влево. Ленивый игрок
выбирает основной цвет и повторяет: пока есть фигура другого цвета,
удаляет самую большую такую фигуру; затем удаляет самую большую фигуру
основного цвета, если она есть. При равенстве берётся фигура с самым
нижним шариком, а среди них — с самым левым из нижних. Для каждого
цвета на поле вывести, сколько очков получит игрок с этим основным
цветом.

## Входные данные

n и m (1 ≤ n, m ≤ 50), затем n строк сверху вниз из букв B, G, R, W и
Y.

## Выходные данные

Для каждого присутствующего цвета в порядке B, G, R, W, Y строка
«цвет: очки».

## Примеры

### Пример 1

Ввод:

```
3 6
WWWGBG
WBGGGB
GGGGBB
```

Вывод:

```
B: 74
G: 92
W: 74
```

## Решение

Играем в точности по описанию. Поиск находит все фигуры нужного вида
(основного цвета или нет) обходом в ширину. Для каждой фигуры он
запоминает размер и её нижний шарик — самый левый в самой нижней
строке — и выбирает лучшую по размеру, затем по строке этого шарика,
затем по его столбцу. Удаление фигуры очищает её клетки. Затем каждая
колонка уплотняется вниз, а непустые колонки — влево.

Каждый ход убирает хотя бы два шарика, поэтому в партии не больше nm / 2
ходов. Каждый ход стоит одного-двух поисков по полю, так что партия
занимает `O((nm)²)` времени, несколько миллионов посещений клеток для
50 × 50, а партий не больше пяти.

Подводные камни:

- правило при равенстве касается одного шарика: среди самых больших
  фигур берётся самый нижний шарик из всех, а если в строке их
  несколько — самый левый. Это не фигура, чей самый левый шарик ниже
  всех;
- после каждого удаления снова пробуются неосновные цвета, прежде чем
  делать следующий основной ход: падающие шарики могут образовать новые
  фигуры;
- поле без фигур всё равно выводит 0 для каждого присутствующего цвета
  (тесты 02 и 03);
- решение на Python отправляется под PyPy: CPython тратит около 2,5 с
  на случайном поле 50 × 50.

Очки совпадают с независимой принятой реализацией на 300 маленьких
случайных полях и на больших полях с двумя и пятью цветами.
