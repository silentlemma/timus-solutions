# 1702. Перекрёсток

[Timus 1702](https://acm.timus.ru/problem.aspx?space=1&num=1702) · сложность 2314 · backtracking

Автор оригинальной задачи — Сергей Пупырев; XIII чемпионат Урала по спортивному программированию, 4 апреля 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Машины подъезжают к перекрёстку с четырёх сторон, и с каждой стороны
делятся на три потока: направо, прямо и налево. Получается 12 потоков
со своими светофорами. В потоке i стоит nᵢ машин, а при зелёном
сигнале за минуту проезжает vᵢ машин. Светофоры переключаются раз в
минуту, и два потока могут ехать одновременно, только если они не
пересекаются и не сходятся в одном направлении. За 10 минут сделать
наибольшее число машин, оставшихся в одном потоке, как можно меньше.

## Входные данные

n₁ … n₁₂ (0 ≤ nᵢ ≤ 1000), затем v₁ … v₁₂ (1 ≤ vᵢ ≤ 1000).

## Выходные данные

Это наименьшее возможное наибольшее значение.

## Примеры

### Пример 1

Ввод:

```
2 0 0 14 13 0 20 0 0 0 60 7
1 1 1 1 3 1 2 1 1 1 5 1
```

Вывод:

```
10
```

## Решение

По рисунку из условия потоки 1–3 едут с юга, 4–6 — с востока, 7–9 — с
севера и 10–12 — с запада, в каждой группе по порядку направо, прямо,
налево, при правостороннем движении. Если нарисовать их пути через
перекрёсток, получится граф конфликтов: потоки с одной стороны не
конфликтуют никогда, потоки с одинаковым направлением — всегда, а
остальные — когда их пути пересекаются. Например, поток 1 конфликтует
только с 9 и 11. Сигналы на одну минуту — это набор попарно
совместимых потоков, а открывать больше потоков никогда не вредно,
поэтому важны только 17 максимальных наборов. Каждый из них открывает
ровно четыре потока.

Ищем ответ L двоичным поиском. Чтобы в потоке i осталось не больше L
машин, ему нужно ⌈(nᵢ − L) / vᵢ⌉ зелёных минут. Вопрос сводится к тому,
покрывают ли 10 максимальных наборов эти потребности, и это решает
перебор с запоминанием. Какая-то минута должна открыть поток с
наибольшей оставшейся потребностью, поэтому ветвимся только по
наборам, содержащим его. Отсекаем, когда потребность больше
оставшихся минут или сумма потребностей больше учетверённого числа
оставшихся минут. Перебор остаётся маленьким: заметно меньше 0.1 с на
тест.

Подводные камни:

- поток, которому нужно больше 10 минут, сразу делает такое L
  невозможным;
- граф конфликтов берётся с рисунка, поэтому вся трудность — правильно
  понять нумерацию (и правило слияния при одинаковом направлении);
- два пересекающихся потока по 100 машин при 10 в минуту делят 10
  минут и оставляют по 50 (тест 06).

Ответы совпадают с независимой принятой реализацией на 310 случайных
тестах, включая тяжёлые потоки, которым нужно по три-четыре минуты.
