# 1759. 长寿者

[Timus 1759](https://acm.timus.ru/problem.aspx?space=1&num=1759) · 难度 462 · implementation

原题作者 Alexander Ipatov，出自 2010 年 3 月 13 日第十一届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一份 n 人的名单给出每人的出生日期、成为在世最年长者的日期和死亡日期；每人的第二个日期等于前一人的死亡日期。
求谁活的天数最多（出生当天和死亡当天都算）。若有并列，输出死得最早的那个人。

## 输入

n（1 ≤ n ≤ 100），然后 n 行，每行三个格式为 `dd.mm.yyyy` 的日期，在公历 1800 年 1 月 1 日到 2009 年 12 月 31 日之间，每个日期都晚于前一个。所有出生日期互不相同，所有死亡日期也互不相同。

## 输出

这个人在名单中的编号。

## 样例

### 样例 1

输入：

```
4
10.10.1873 27.12.1987 11.01.1988
18.11.1874 11.01.1988 14.02.1991
21.02.1875 14.02.1991 04.08.1997
29.08.1880 04.08.1997 16.04.1998
```

输出：

```
3
```

## 解法

把每个日期变成天数编号，寿命为 死亡 − 出生 + 1 天。编号时一年从三月算起，使 2 月 29 日（如果有）成为一年的最后一天：
这样 y 年之前的年份共有 365·y 天加上 ⌊y/4⌋ − ⌊y/100⌋ + ⌊y/400⌋ 个闰日，而第 m 个月（三月为 0）之前的天数为 ⌊(153·m + 2) / 5⌋，
因为三月到七月与八月到十二月都是 153 天，且大小月交替方式相同。名单按死亡顺序排列，所以第一个达到最长寿命的人就是答案。`O(n)`。

样例中寿命分别为 41731、42457、44725 和 42964 天，所以第三位（生于 1875 年，卒于 1997 年）活得最久。

注意事项：

- 1800 年和 1900 年不是闰年，而 2000 年是；
- 出生当天和死亡当天都要算，这不改变胜者，但会改变长度；
- 并列时死得早的人胜出，也就是行号更小的人。

在 160 个随机名单上（包括并列以及 1800、1900、2000 年二月末附近的日期），答案与基于标准日期库的计数以及一个独立的已通过实现一致。
