# 1724. 人类起源之谜

[Timus 1724](https://acm.timus.ru/problem.aspx?space=1&num=1724) · 难度 666 · strings

原题作者 Alex Samsonov（由 Ivan Burmistrov 准备），出自 2009 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

DNA 串由核苷酸 `A`、`C`、`G`、`T` 及其反核苷酸 `a`、`c`、`g`、`t` 组成。
人类串是空串、两个人类串的连接，或者在一个人类串前面加一个核苷酸、末尾加上对应反核苷酸得到的串。
判断给定串的若干子串是否为人类串。

## 输入

一个由 `ACGTacgt` 组成、长度为 L（1 ≤ L ≤ 100 000）的串，然后是 q（1 ≤ q ≤ 50 000）
和 q 对 l、r（1 ≤ l ≤ r ≤ L），即子串的首尾位置。

## 输出

一行 q 个字符：子串是人类串则为 `1`，否则为 `0`。

## 样例

### 样例 1

输入：

```
caAgtGTtgAacCc
5
2 3
6 9
10 11
1 14
13 14
```

输出：

```
01101
```

## 解法

人类串就是有四种括号的括号序列：核苷酸是左括号，其反核苷酸是右括号。
子串是人类串，当且仅当把它的字母依次送入栈时，从不遇到与栈顶不匹配的右括号，并且最后栈为空。

把整个串送入同一个栈，并给每个前缀之后的栈起一个名字——树的一个结点。入栈创建当前结点的新子结点，
匹配的右括号回到父结点，不匹配或碰到栈底的右括号则开始一个新的孤立结点。
从 l 到 r 的子串是人类串，当且仅当 r 之后的结点与 l − 1 之后的结点相同：人类片段只压入它之后会弹出的元素，
而降到起点以下或遇到错误右括号的片段再也回不去，因为之后的结点都是新的。所以每个询问只需一次比较。`O(L + q)`。

样例中 `GTtg`（6–9）、`Aa`（10–11）和 `Cc`（13–14）是人类串，而 `aA`（2–3）先闭后开，整个串也是如此。

注意事项：

- `cC` 和 `GTgt` 不是人类串：顺序和嵌套都重要；
- 与全局栈匹配的右括号可能属于 l 之前的左括号，所以栈内容相同还不够，必须是同一个结点；
- 有 50 000 个询问且时限 0.5 秒，回答询问时不能遍历其子串。

在 300 个短随机串的所有子串上，答案与直接按文法的搜索一致；在长串上与一个独立的已通过实现一致。
