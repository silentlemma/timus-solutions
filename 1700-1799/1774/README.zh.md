# 1774. 法师军队的理发师

[Timus 1774](https://acm.timus.ru/problem.aspx?space=1&num=1774) · 难度 519 · matching

原题作者 Magaz Asanov，出自第十五届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 个人每人需要剃两次须，分别在其停留期间两个不同的整分钟：第 i 个人在第 tᵢ 分钟到达并停留 sᵢ 分钟，因此允许的分钟为 tᵢ 到 tᵢ + sᵢ − 1。
每分钟至多给 k 个人剃须。判断能否给所有人剃完，并给出每个人的两个分钟。

## 输入

n 和 k（1 ≤ n, k ≤ 100），然后是每个人的 tᵢ 和 sᵢ（0 ≤ tᵢ ≤ 1000，2 ≤ sᵢ ≤ 1000）。

## 输出

`No`，或者 `Yes` 以及每个人的两个分钟 pᵢ < qᵢ。任何符合要求的安排都可以。

## 样例

### 样例 1

输入：

```
3 2
1 3
1 3
1 3
```

输出：

```
Yes
1 2
1 3
2 3
```

### 样例 2

输入：

```
2 1
1 3
1 3
```

输出：

```
No
```

## 解法

这是一个流问题：每个人送出 2 次剃须，每分钟至多接收 k 次，一个人在其停留的每一分钟至多送出一次。
相邻两个到达或离开时刻之间的分钟看到的是同一批人，所以合并成块：长 L 分钟的块至多接收 k·L 次，且来自同一人的至多 min(L, 2) 次。
块数至多 2n + 1，网络很小，用 Dinic 算法求最大流；当且仅当流量为 2n 时所有人都能剃完。

在块内，剃须按分钟轮流分配，每个人的剃须连续排列。所以同一人在同一块中的两次剃须落在不同分钟（他送两次时 L ≥ 2），且每分钟不超过 k 次，因为块至多容纳 k·L 次。
网络有 O(n²) 条边，流量至多 2n，每次沿路径增广需 O(n²)，总共 `O(n³)`。

样例 1 中三个人共享第 1 到 3 分钟，k = 2：六次剃须正好填满六个位置，轮流分配得到 1 2、3 1、2 3，即每对分钟各一次。

注意事项：

- 同一个人的两次剃须必须在不同分钟，仅按块计数会忽略这一点；
- 最后允许的分钟是 tᵢ + sᵢ − 1，而不是 tᵢ + sᵢ；
- 安排不唯一，所以检查器检验时间窗口和每分钟的负载。

在 300 个最多 5 人的随机情形上，答案与枚举所有分钟对的搜索一致；在 100 个最多 100 人的情形上与一个独立的已通过实现一致，且双向检查。
