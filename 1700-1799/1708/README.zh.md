# 1708. 数字和 2

[Timus 1708](https://acm.timus.ru/problem.aspx?space=1&num=1708) · 难度 11130 · math

原题作者 Vladimir Yakovlev，出自 2009 年 4 月 4 日第十三届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在 b 进制下，若没有更小的数与某个正整数具有相同的数字和以及相同的数字平方和，则称它为最小数。
要求用最短的模式列表描述所有最小数。模式由数字和星号组成，星号表示前一个数字可以重复任意次（包括零次）。
匹配某个模式的数都必须是最小数，而每个最小数都必须匹配某个模式。

## 输入

基数 b，2 ≤ b ≤ 36。

## 输出

按字符串排序的模式，每行一个，使用数字 1 … 9、A、B、…，且不含多余部分：写 12*3 而不是 12*2*3。
模式也可以匹配空串。

## 样例

### 样例 1

输入：

```
4
```

输出：

```
1*2*
112*3*
12*3*
2*3*
```

## 解法

两个和都与数字的顺序无关，所以最小数不含 0，且数字不减：它是数字 1 … b − 1 的多重集，即一个计数向量。
两个和相同的向量中，数字较少的更小；长度相同时，看第一个计数不同的数字，该数字副本更多的向量更小。
比较只取决于两个向量之差，因此给两者加上相同的数字不会改变结果。

从最小数中删去一些数字仍是最小数，所以最小向量恰好是不位于任何"极小非最小向量"之上的向量，下文称后者为禁止向量。
为了找到它们，对每个最多用 15 个数字可达的 (数字和, 平方和) 对，求出它的最小向量：按递增顺序追加数字，
每个对只保留最好的词——由上面的性质，最好的词在任何延伸之后仍然最好。
禁止向量去掉其最大数字后是最小的，所以它来自在某个最小词末尾追加一个数字。
如果延长后的词不是其对的最小者，而少一个数字的每个词都是最小者，它就是禁止的。
基数 36 时约有 720000 个对和 25000 个禁止向量；没有一个超过 15 个数字，把上限提高到 17 也找不到新的。

模式通过对最后一个数字的递归得到。设 G 是数字 1 … n 上的禁止向量集合，t 是 G 中数字 n 的最大计数。
当数字 n 有 k < t 个副本时，前缀必须避开 G 中该数字副本数不超过 k 的向量（去掉数字 n，只保留极小者）；
副本数达到 t 或更多时，前缀必须避开全部这些向量，这种情况变成星号。
所以模式就是星号情况的模式后接 n*，以及对每个 k < t 该情况的模式后接 k 个副本；
其中已经避开一切的前缀模式被丢弃，因为星号覆盖了它们。这些集合随 k 增大；
由于 G 只含极小向量，新加入的向量永远不会位于旧向量之上，所以每一步只需删去位于某个新向量之上的旧向量。
相同的集合经常重复出现，因此结果被记忆化。模式保存在由 (父节点, 计数) 节点构成的字典树中，
一个集合的结果是若干段连续的节点。基数 36 最终约有 210 万个节点和 47062 个模式。

注意事项：

- 内存限制为 64 MB：最小词紧凑地存放在开放寻址哈希表中，在构造模式之前释放；
- 最频繁的检查是一个向量是否位于众多向量之一之上：其他向量按非零计数集合分组，
  只检查被测向量非零集合之内的组；
- 基数 2 只有一个模式 1*，基数 36 的输出约 325 KB；
- Python 解答在 PyPy 下处理基数 36 需要约 16 秒和几百 MB。它通过了这里的全部测试，
  保留并标记为 TLE，不声称能满足评测的限制；
- Java 解答在这里约需 1.5 秒，但在评测的第 30 个测试上超时，所以同样保留并标记为 TLE；
  为了满足那里的内存限制，它的哈希表填充到四分之三。

对 2 到 36 的每个基数，输出都与一个独立的已通过实现完全相同。
