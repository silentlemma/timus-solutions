# 1757. Золотые слитки

[Timus 1757](https://acm.timus.ru/problem.aspx?space=1&num=1757) · сложность 2312 · binary_search

Автор оригинальной задачи — Василий Бурнин; XI открытое личное первенство УрГУ, 13 марта 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть n слитков; слиток i весит mᵢ граммов и имеет пробу pᵢ — граммы
золота в килограмме сплава. Можно взять любую часть любого слитка.
Отлить слиток массой m граммов и пробы p или сообщить, что это
невозможно.

## Входные данные

n, m и p (1 ≤ n ≤ 1000, 1 ≤ m ≤ 10⁶, 0 ≤ p ≤ 1000), затем mᵢ и pᵢ для
каждого слитка (1 ≤ mᵢ ≤ 1000, 0 ≤ pᵢ ≤ 1000).

## Выходные данные

`NO` либо `YES` и граммы xᵢ, взятые из каждого слитка, так что
|Σxᵢ − m| < 10⁻⁶ и |Σxᵢpᵢ/1000 − mp/1000| < 10⁻⁶. Подходит любой
подходящий выбор.

## Примеры

### Пример 1

Ввод:

```
4 150 750
100 1000
150 585
100 750
100 0
```

Вывод:

```
YES
75.000000000
0.000000000
50.000000000
25.000000000
```

### Пример 2

Ввод:

```
1 100 1000
200 0
```

Вывод:

```
NO
```

## Решение

Выложим слитки в ряд от самого бедного к самому богатому, всего M
граммов, и рассмотрим окно в m граммов, начинающееся в s. Золото в нём
G(s), в миллиграммах, не убывает при сдвиге s вправо: окно теряет более
бедный металл и захватывает более богатый, — и меняется непрерывно. Любой набор из m
граммов содержит золота не меньше, чем окно при s = 0, и не больше, чем
окно при s = M − m. Поэтому слиток можно отлить ровно тогда, когда
M ≥ m и G(0) ≤ m·p ≤ G(M − m); обе границы вычисляются точно.

Если можно, двоичный поиск по s находит, где G(s) = m·p, а части — это
пересечения окна со слитками: целые слитки внутри и не более двух
разрезанных по краям. G(s) считается проходом по слиткам, а в Python —
поиском по префиксным суммам. При K = 100 делениях пополам всего `O(n log n + K·n)`,
в Python — `O(n log n + K log n)`, в Go со стабильной сортировкой —
`O(n log² n + K·n)`. Малое число разрезанных слитков к тому же держит
погрешность округления
выведенных частей намного ниже 10⁻⁶.

В первом примере слитки по порядку имеют пробу 0, 585, 750 и 1000. Окно
при s = 0 содержит 100 граммов пробы 0 и 50 пробы 585, 29,25 грамма
золота; в дальнем конце — 50 пробы 750 и 100 пробы 1000, 137,5. Заказу
нужно 112,5, поэтому окно останавливается внутри: около 30,12 грамма
слитка 585, весь слиток 750 и около 19,88 слитка 1000. Это другой
подходящий ответ, не тот, что в примере.

Подводные камни:

- заказ тяжелее всего склада невозможен при любой пробе;
- решение «да или нет» требует точных границ: G(0) и G(M − m) —
  целые суммы, точно представимые в double;
- смешивание многих слитков в долях может дать длинные дроби;
  1000 частей, округлённых до 10 знаков после запятой, дают погрешность
  не более 5·10⁻⁸.

Ответы совпадают с независимой принятой реализацией в том, какие
заказы выполнимы, на 500 случайных складах, многие из которых с пробой
ровно на границе или чуть за ней, и каждый ответ проходит чекер обоих
условий и весов слитков.
