# 1703. 机械臂

[Timus 1703](https://acm.timus.ru/problem.aspx?space=1&num=1703) · 难度 1229 · geometry

原题作者 Pavel Atnashev，出自 2009 年 4 月 4 日第十三届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

机器人的手臂由长为 a 的上臂（固定在肩关节即原点，可以任意转动）和长为 b 的前臂组成。
前臂在肘部绕垂直于两段的轴弯曲，弯曲角不能是锐角。前臂末端的爪子只有在扶手轴线与肘轴平行时才能合拢在直径为 1 的扶手上。
给出扶手的轴线，求一个肘部位置和弯曲角，使爪子能合拢在扶手上，或者报告不存在。

## 输入

a 和 b，然后是扶手轴线上的两个不同点。所有数都是绝对值不超过 100 的整数，a, b ≥ 4，轴线不经过肩关节。

## 输出

肘部坐标和 [π/2, π] 中的弯曲角，或 “No solution.”。任何合法位置都可以。

## 样例

### 样例 1

输入：

```
8 6
-10 10 0
10 10 0
```

输出：

```
0 6.4 4.8 1.5707963267948966
```

### 样例 2

输入：

```
5 10
-10 10 0
10 10 0
```

输出：

```
No solution.
```

## 解法

肘轴垂直于两段手臂且平行于扶手，所以肩、肘和爪都位于过肩关节且垂直于扶手的平面内。
爪子在轴线与该平面的交点处握住扶手，也就是轴线上离肩关节最近的点 h。设 r = |h|，
肩、肘和 h 构成边长为 a、b、r 的三角形，弯曲角就是 r 所对的角。它不是锐角当且仅当 a² + b² ≤ r²，
而三角形能闭合当且仅当 r ≤ a + b。

两个判断都可以用整数精确完成。取轴上一点 p 和方向 d，有 r² = |p × d|² / |d|²，
所以把 a² + b² 和 (a + b)² 乘以 |d|² 后与 |p × d|² 比较。满足时把肘放在该平面内：
沿 h 方向 x = (a² − b² + r²) / (2r)，垂直方向 √(a² − x²)，弯曲角为 arccos((a² + b² − r²) / (2ab))。`O(1)`。

注意事项：

- 直角（a² + b² = r²，第一个样例）和伸直的手臂（r = a + b，测试 04）都允许，所以比较必须精确；
- 扶手离肩太近会使弯曲角成为锐角（测试 02 和 08），尽管手臂够得着；
- 肘部可以关于通向 h 的直线镜像，两侧都可以。

检查器验证两段的长度、所在平面和输出的角度。在 150 个随机测试（许多处于边界）上，结论与一个独立的已通过实现一致。
