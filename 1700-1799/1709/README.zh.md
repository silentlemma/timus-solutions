# 1709. 企鹅航空

[Timus 1709](https://acm.timus.ru/problem.aspx?space=1&num=1709) · 难度 154 · dsu

原题作者 Alexander Ipatov，出自 2009 年 4 月 4 日第十三届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一家航空公司在 n 个机场中的某些机场对之间有航班，用对称的 0/1 矩阵给出。新的航线网必须使任意两个机场可以互达
（可以转机），并且航班数是所有连通网络中最少的。取消一个航班花费 d，开通一个航班花费 a。
求最便宜的修改方案，并以矩阵输出：取消的航班处为 d，新开的航班处为 a，其余为 0。

## 输入

n（2 ≤ n ≤ 100），然后是 d 和 a（1 ≤ d, a ≤ 10⁶），接着是矩阵的 n 行。

## 输出

最小花费，然后是对称的 n × n 方案。任何最优方案都可以。

## 样例

### 样例 1

输入：

```
6
2 3
011000
101000
110000
000011
000101
000110
```

输出：

```
7
0d0000
d00000
000a00
00a0d0
000d00
000000
```

## 解法

航班最少的连通网络是有 n − 1 个航班的生成树。若这棵树保留了 m 个旧航班中的 k 个，方案就取消 m − k 个、
开通 n − 1 − k 个，所以无论 d 和 a 是多少，保留越多越便宜。保留的航班在旧网络中构成一个森林，
因此 k 至多为 n − c（c 是旧网络的连通分量数），生成森林恰好达到这个值。

所以用并查集构造生成森林：连接两棵不同树的旧航班保留，其余都取消。再从机场 1 向其他每棵树中的某个机场
开通一个新航班，共 c − 1 个，把 c 棵树连起来。总花费为 d(m − n + c) + a(c − 1)。`O(n²)`。

注意事项：

- 所有航班都存在时花费可达 4851 · 10⁶，需要 64 位整数（测试 04）；
- 两棵树之间的新航班绝不会与旧航班重复，否则旧航班早已把它们连起来；
- 矩阵的各行没有空格。

检查程序接受任何最优方案：它检查花费、对称性、d 和 a 只出现在已有和不存在的航班上，以及结果是一棵生成树。
在 800 个随机图上，答案与一个独立的已通过实现一致。
