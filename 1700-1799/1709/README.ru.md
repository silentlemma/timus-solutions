# 1709. Пингвин-Авиа

[Timus 1709](https://acm.timus.ru/problem.aspx?space=1&num=1709) · сложность 153 · dsu

## Задача

Авиакомпания летает между некоторыми парами из n аэропортов, заданными
симметричной матрицей из 0 и 1. Новая схема должна связывать любые два
аэропорта, возможно с пересадками, и содержать столько рейсов, сколько
минимально нужно связной схеме. Отмена рейса стоит d, новый рейс стоит
a. Найти самое дешёвое изменение и вывести его матрицей: d у
отменённого рейса, a у нового и 0 в остальных клетках.

## Входные данные

n (2 ≤ n ≤ 100), затем d и a (1 ≤ d, a ≤ 10⁶), затем n строк матрицы.

## Выходные данные

Наименьшая сумма, затем план размером n × n, симметричный. Подходит
любой оптимальный план.

## Примеры

### Пример 1

Ввод:

```
6
2 3
011000
101000
110000
000011
000101
000110
```

Вывод:

```
7
0d0000
d00000
000a00
00a0d0
000d00
000000
```

## Решение

Связная схема с наименьшим числом рейсов — остовное дерево из n − 1
рейса. Если дерево сохраняет k из m старых рейсов, план отменяет m − k
и вводит n − 1 − k, так что чем больше сохранённых рейсов, тем дешевле,
каковы бы ни были d и a. Сохранённые рейсы образуют лес внутри старой
схемы, поэтому k не больше n − c, где c — число её компонент
связности, и остовный лес этого достигает.

Поэтому строим остовный лес системой непересекающихся множеств: старый
рейс между двумя разными деревьями сохраняем, любой другой отменяем.
Затем соединяем c деревьев c − 1 новыми рейсами из аэропорта 1 в
какой-нибудь аэропорт каждого другого дерева. Сумма равна
d(m − n + c) + a(c − 1). `O(n²)`.

Подводные камни:

- при всех рейсах сумма доходит до 4851 · 10⁶, нужны 64 бита (тест
  04);
- новый рейс между двумя деревьями никогда не повторяет старый: старый
  рейс уже соединил бы их;
- строки матрицы записаны без пробелов.

Проверяющая программа принимает любой оптимальный план. Она проверяет
сумму, симметричность, то, что d и a стоят только на старых и на
отсутствующих рейсах, и что результат — остовное дерево. Ответы
совпадают с независимой принятой реализацией на 800 случайных графах.
