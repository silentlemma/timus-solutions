# 1706. 密文 2

[Timus 1706](https://acm.timus.ru/problem.aspx?space=1&num=1706) · 难度 678 · strings

原题作者 Dmitry Ivankov，出自 2009 年 4 月 4 日第十三届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定长度为 n 的字符串 s 和密钥 k < n。对每个位置 i，取从 i 开始的 k 个字符（到结尾后接回 s 的开头），
统计这个窗口中不同非空子串的个数。输出这 n 个数。

## 输入

第一行为 k（1 ≤ k ≤ 1000），第二行为 s：由小写拉丁字母组成，长度 n 满足 k < n ≤ 4000。

## 输出

n 个数，以空格分隔。

## 样例

### 样例 1

输入：

```
3
abaccc
```

输出：

```
5 6 5 3 5 6
```

## 解法

把 s 重复几遍，使每个窗口都成为普通区间 [a, a + k)。窗口中每个不同子串在其最左起点 j 处计数。
从 j 开始，窗口内有长度 1 … a + k − j，某个长度已被占用，当且仅当窗口中某个更早的起点 j′（a ≤ j′ < j）
与 j 的公共前缀至少这么长。所以窗口的答案是对 j 求和 a + k − j 减去 best[j]（不小于零），
其中 best[j] 是 j 与窗口内更早起点的最长公共前缀。

从右向左遍历 a。当 a 成为某窗口的左端点时，每个 best[j] 只新增一个更早的起点，即 a 本身，
因此对 j = a + 1 … a + k − 1 把 best[j] 提高到 lcp(a, j)。这些前缀由上一步得到：
若位置 a 与 a + d 的字符相同，lcp(a, a + d) = lcp(a + 1, a + 1 + d) + 1，否则为 0，
所以只需一个按距离 d 索引的数组。每步 O(k)；遍历从最后一个窗口再往右 k 个位置开始，
保证用到的前缀都已准确。时间 `O((n + k) · k)`，内存 `O(n + k)`。

注意事项：

- 窗口会绕过 s 的结尾；用 s 的四份拷贝可使遍历中的所有比较都在文本之内；
- 对每个窗口建后缀自动机也可行，但约需 n · k 次自动机操作，且每个状态有 26 个转移；
- k = 1 时每个位置的答案都是 1（测试 02）。

在由两个、三个和全部字母组成的随机字符串、斐波那契串以及周期串上，答案与一个独立的已通过实现一致。
