# 1706. Шифровка 2

## Задача

Дана строка s длины n и ключ k < n. Для каждой позиции i берутся k
символов начиная с i, с переходом к началу s после её конца, и
считается число различных непустых подстрок этого окна. Вывести n
таких чисел.

## Входные данные

k (1 ≤ k ≤ 1000) в первой строке, s во второй: строчные латинские
буквы, её длина n, k < n ≤ 4000.

## Выходные данные

n чисел через пробел.

## Примеры

### Пример 1

Ввод:

```
3
abaccc
```

Вывод:

```
5 6 5 3 5 6
```

## Решение

Повторим s, чтобы каждое окно стало обычным отрезком [a, a + k).
Каждую различную подстроку окна считаем в её самом левом начале j.
Начиная с j, в окне есть длины 1 … a + k − j, и длина уже занята ровно
тогда, когда какое-то более раннее начало j′ окна, a ≤ j′ < j, имеет с
j общий префикс не короче её. Поэтому ответ для окна — сумма по j
величин a + k − j минус best[j], где best[j] — наибольший общий префикс
j с более ранним началом в окне, с отсечением снизу нулём.

Пройдём a справа налево. Когда a становится левым концом окна, во все
best[j] входит лишь одно новое раннее начало — сама позиция a, поэтому
best[j] поднимается до lcp(a, j) для j = a + 1 … a + k − 1. Эти
префиксы берутся с предыдущего шага: lcp(a, a + d) равен
lcp(a + 1, a + 1 + d) + 1, если символы в a и a + d совпадают, и 0
иначе, так что их хранит один массив по расстоянию d. Шаг стоит O(k),
а проход начинается с a = n + 2k, чтобы префиксы до длины k
уже были точными. Время `O((n + k) · k)`, память `O(n + k)`.

Подводные камни:

- окна переходят через конец s; четыре копии s оставляют все сравнения
  прохода внутри текста;
- суффиксный автомат на каждое окно тоже подходит, но это около n · k
  шагов автомата с переходами по 26 буквам;
- при k = 1 для каждой позиции ответ 1 (тест 02).

Ответы совпадают с независимой принятой реализацией на случайных
строках из двух, трёх и всех букв, слове Фибоначчи и периодических
строках.
