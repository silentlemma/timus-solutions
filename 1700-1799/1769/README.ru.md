## Задача

Дана непустая строка десятичных цифр. Найти наименьшее целое
положительное число, десятичная запись которого не встречается в
строке.

## Входные данные

Строка длиной не более 10⁵ цифр.

## Выходные данные

Это число.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
10123456789
```

Вывод:

```
11
```

## Решение

В строке из n цифр не больше n кусков каждой длины, а шестизначных
чисел 9·10⁵, так что какое-то шестизначное число всегда отсутствует и
ответ не длиннее шести цифр. Каждый кусок из одной—шести цифр, не
начинающийся с нуля, — запись числа; отметив их все и считая от 1 до
первого неотмеченного, получаем ответ. `O(6n)`.

В примере встречаются 1—9 и 10, а 11 — нет.

Подводные камни:

- куски, начинающиеся с 0, не являются записями чисел, хотя число после
  нуля всё равно встречается на цифру позже;
- в строке из нулей нет 1;
- поиск в строке каждого числа по очереди может быть медленным на
  длинных строках с большим ответом.

Ответы совпадают с поиском в строке чисел 1, 2, 3 и так далее на 90
случайных строках и с независимой принятой реализацией на 20 длинных.

## Оптимизированные решения

Десятичные подстроки отмечаются для одной длины за раз с помощью числового скользящего кода и компактного битового множества. Кандидаты перебираются по возрастанию до первого отсутствующего числа. Если все числа данной длины встречаются, переходим к следующей и переиспользуем память. Ведущие нули и требование минимального ответа обрабатываются по исходному числовому определению, без строкового объекта каждой подстроки и множеств всех длин одновременно.
