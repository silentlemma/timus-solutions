# 1723. Книга Сандро

[Timus 1723](https://acm.timus.ru/problem.aspx?space=1&num=1723) · сложность 62 · strings

Автор оригинальной задачи — Иван Бурмистров (подготовка — Ольга Соболева); Уральская региональная командная олимпиада по программированию 2009.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждая подстрока данного слова — заклинание, а его сила — число его
вхождений в слово, считая перекрывающиеся. Вывести самое сильное
заклинание.

## Входные данные

Непустое слово не длиннее 50 строчных латинских букв.

## Выходные данные

Любое самое сильное заклинание.

## Примеры

### Пример 1

Ввод:

```
tebidohtebidoh
```

Вывод:

```
tebidoh
```

## Решение

Каждое вхождение заклинания начинается с вхождения его первой буквы, и
разные вхождения начинаются в разных местах. Поэтому никакое заклинание
не сильнее своей первой буквы, и самая частая буква — самое сильное
заклинание. `O(n)`.

В примере каждая буква встречается дважды, так что `t` не слабее
`tebidoh`.

Подводные камни:

- вхождения могут перекрываться: `aba` встречается в `abababa` три
  раза, но `a` — четыре;
- подходит любое самое сильное заклинание, поэтому тесты используют
  проверяющую программу.

Проверяющая программа считает вхождения ответа с перекрытиями и
сравнивает их с ожидаемым ответом. Самая частая буква совпадает с
полным перебором всех подстрок на 300 случайных словах.

## Оптимизированные решения

Оптимизированное решение на C++ считает буквы по мере чтения через
`getchar`, не сохраняя строку: 84 КБ вместо 352 КБ.

Оптимизированное решение на Java читает буквы побайтно из `System.in`
вместо чтения слова через `Scanner` и выводит ответ одним байтом: 348 КБ
вместо 1556 КБ при том же времени.
