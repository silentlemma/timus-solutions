# 1753. 书架

[Timus 1753](https://acm.timus.ru/problem.aspx?space=1&num=1753) · 难度 335 · geometry

原题作者 Dmitry Ivankov，出自 2010 年 3 月 13 日第十一届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

长度为 L 的书架两端有高 h 的挡板。一本高 H 的书竖立在左挡板旁。把书的下边沿书架向右拖，书的侧面始终靠在左挡板顶端，直到书平躺下来。
所有物体厚度为零。求书的中点最多能到左挡板左侧多远。

## 输入

整数 h、H 和 L（1 ≤ h < H < L ≤ 1000）。

## 输出

书的中点在挡板左侧的最大偏移，误差不超过 10⁻⁵。

## 样例

### 样例 1

输入：

```
7 120 200
```

输出：

```
39.850361
```

## 解法

把左挡板顶端放在 (0, h)，书的下端放在 (x, 0)。书沿着从下端经过挡板顶端的直线放置，这一段长 r = √(x² + h²)，
所以距下端 H/2 的中点的横坐标为 x(1 − H / 2r)。向左的偏移为 f(x) = x(H / 2r − 1)。

它的导数是 H·h² / 2r³ − 1，所以 r³ < H·h²/2 时 f 增大，之后减小，最佳时刻是 r = ∛(H·h²/2)。这个 r 永远不超过 H，所以此时书仍靠在挡板上。
如果这个 r 不大于 h（恰好在 H ≤ 2h 时发生），中点永远不会越过挡板，答案为 0；否则 x = √(r² − h²)，答案为 f(x)。
L 不起作用，因为书总能放在书架上。`O(1)`。

样例中 r = ∛2940 ≈ 14.33，x ≈ 12.50，偏移约为 39.85。

注意事项：

- 书不超过挡板高度两倍时答案是 0，不是负的偏移；
- 挡板在左边，所以只有书较陡时，下端右移才会让中点左移。

在 100 个随机输入上公式与扫描 200001 个下端位置的结果一致，在另外 300 个输入上与一个独立的已通过实现一致。

## 优化解法

Go 和 Rust 用比值 q = cbrt(H/(2h)) 改写同一最优公式。H ≤ 2h 时位移为零。否则令 f = (q−1)(q+1)，计算 h·f·sqrt(f)。公共因子只算一次，也避免了两个较大长度平方相减。结果直接保留六位小数输出。两个版本都使用固定字节缓冲区，先舍入到百万分之一，再写出十进制数字。Go 直接访问标准句柄。Rust 通过 C main 启动，通过 C 运行库传输缓冲区。
