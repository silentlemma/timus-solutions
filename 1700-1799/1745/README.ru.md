# 1745. Ещё Один Ответ

[Timus 1745](https://acm.timus.ru/problem.aspx?space=1&num=1745) · сложность 817 · dp

Автор оригинальной задачи — Дамир Ахметзянов; контест УГАТУ, Петрозаводские летние сборы, август 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны n слов из скобок. Составить из некоторых из них, каждое не более
одного раза и в любом порядке, самую длинную правильную скобочную
последовательность.

## Входные данные

n (1 ≤ n ≤ 1000), затем слова; их суммарная длина не больше 10 000.

## Выходные данные

Длина l и число k использованных слов, затем k номеров слов по порядку.
Подходит любой самый длинный ответ.

## Примеры

### Пример 1

Ввод:

```
4
(
(((
(
))
```

Вывод:

```
4 3
1 3 4
```

### Пример 2

Ввод:

```
3
()
(()
)
```

Вывод:

```
6 3
2 3 1
```

## Решение

Опишем слово изменением глубины, которое оно даёт, и наименьшей
глубиной, которой оно достигает от своего начала. В лучшем ответе
слова, не понижающие глубину, можно поставить первыми, меньше всего
проваливающиеся — раньше: перенос такого слова раньше только поднимает
глубину для всех после него. Слова, понижающие глубину, идут последними;
прочитанные задом наперёд с заменой скобок на противоположные, они дают
тот же случай, что ставит первыми те, чей конец выше всего над их нижней
точкой. Значит, есть лучший ответ, берущий выбранные слова в этом одном
фиксированном порядке.

Дальше это рюкзак по фиксированному порядку: для каждой глубины d —
самая длинная уже построенная последовательность, кончающаяся на
глубине d. Слово может идти после глубины d, если d плюс его наименьшая
глубина не ниже нуля, и ведёт в глубину d плюс его изменение. Ответ —
значение на глубине 0, а таблица взятых слов восстанавливает порядок.
Глубина не превосходит общей длины L. `O(n·L)`, около 10⁷ шагов.

В первом примере `(`, `(` и `))` дают `(())` длины 4; для `(((`
понадобились бы ещё три закрывающие скобки.

Подводные камни:

- пустой ответ допустим: `0 0` и пустая строка;
- слову вроде `)(` перед собой нужна глубина 1, и оно сохраняет
  глубину;
- порядок внутри каждой половины важен: слово с глубоким провалом
  должно идти, пока глубина ещё высока.

Проверяющая программа проверяет последовательность, различные номера
слов и длину. Длины совпадают с перебором всех упорядоченных выборов
слов на 400 случайных наборах до 6 слов и с независимой принятой
реализацией на больших тестах. Решение на Python работает под PyPy,
так как его 10⁷ шагов занимают здесь на CPython около 0,5 с.
