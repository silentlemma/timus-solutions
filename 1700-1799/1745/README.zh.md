# 1745. 又一个答案

[Timus 1745](https://acm.timus.ru/problem.aspx?space=1&num=1745) · 难度 820 · dp

原题作者 Damir Akhmetzyanov，出自 2009 年 8 月彼得罗扎沃茨克夏季集训的乌法国立航空技术大学专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 n 个由括号组成的单词，选出其中一些（每个至多用一次，顺序任意）拼接成最长的合法括号序列。

## 输入

n（1 ≤ n ≤ 1000），然后是这些单词；总长度不超过 10 000。

## 输出

长度 l 和所用单词数 k，然后按顺序输出 k 个单词编号。任何最长的答案都可以。

## 样例

### 样例 1

输入：

```
4
(
(((
(
))
```

输出：

```
4 3
1 3 4
```

### 样例 2

输入：

```
3
()
(()
)
```

输出：

```
6 3
2 3 1
```

## 解法

用单词造成的深度变化量以及它从起点出发达到的最低深度来描述单词。在最优答案中，不降低深度的单词可以放在前面，
下探最浅的在最前：把这样的单词提前只会提高其后所有位置的深度。降低深度的单词放在最后，倒过来看它们是同样的情况，
于是结尾比自身最低点高得最多的排在前面。所以存在一个最优答案，按这一固定顺序取用所选单词。

接下来就是按固定顺序做背包：对每个深度 d，记录到目前为止构造的、结束于深度 d 的最长前缀。
若 d 加上单词的最低深度不小于零，单词就可以接在深度 d 之后，并通向深度 d 加上它的变化量。
答案是深度 0 处的值，记录取用了哪些单词的表可以还原顺序。深度不超过总长度 L。`O(n·L)`，至多 10⁷ 步。

样例 1 中 `(`、`(` 和 `))` 组成长度为 4 的 `(())`；用 `(((` 还需要三个右括号。

注意事项：

- 允许空答案：`0 0` 和一个空行；
- 像 `)(` 这样的单词前面需要深度 1，并且保持深度不变；
- 每一半内部的顺序很重要：下探很深的单词必须在深度还高的时候使用。

检查程序验证序列、单词编号互不相同以及长度。在 400 组最多 6 个单词的随机数据上，长度与穷举所有有序选择的结果一致；
在大测试上与一个独立的已通过实现一致。Python 解答在 PyPy 下运行，因为它的 10⁷ 步在这里用 CPython 约需 0.5 秒。
