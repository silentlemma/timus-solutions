# 1714. Мнемоника и палиндромы 2

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Сложность слова — наименьшее число палиндромов, на которое его можно
разбить. Вывести слово из n букв a и b наибольшей сложности.

## Входные данные

n (1 ≤ n ≤ 1000).

## Выходные данные

Такое слово. Подходит любое.

## Примеры

### Пример 1

Ввод:

```
6
```

Вывод:

```
aababb
```

## Решение

Над двумя буквами палиндромы находятся легко, поэтому сложное слово
должно избегать длинных. Здесь слово начинается с aabab, повторяет
блок bbaaba и заканчивается коротким хвостом, выбранным по n mod 6:
пусто, b, bb, bbaaababb, bbaa или bbaab. Каждый блок добавляет к
наименьшему разбиению два палиндрома. Нескольким коротким длинам нужны
свои слова: ab для 2, aababbaa для 8 и aababbaabab для 11. До 5 букв
подходит префикс aabab. `O(n)`.

Сложность этих слов равна ⌊n/3⌋ + 1 при n ≥ 12 и на один больше при
n ≡ 2 (mod 6). Меньшие длины дают 1, 2, 2, 2, 2, 3, 3, 4, 4, 4, 5.
Полный перебор всех слов подтверждает, что это наибольшая сложность
для всех n до 20. Совпадающая оценка для больших n здесь не доказана:
слова те же, что у независимой принятой реализации, и совпадают с ней
для всех n от 1 до 1000.

Подводные камни:

- простое правило с префиксом ломается при n = 2: aa — один палиндром,
  а ab требует двух;
- при n = 8 длинный хвост ещё не помещается, а при n = 11 шаблону не
  хватает одного палиндрома, поэтому у этих длин свои найденные
  перебором слова;
- подходит любое слово наибольшей сложности, поэтому тесты используют
  проверяющую программу, которая находит минимальное число палиндромов
  в разбиении динамическим программированием.
