# 1796. Парк аттракционов

## Задача

Учительница платит за билеты купюрами по 10, 50, 100, 500, 1000 и 5000
рублей. Денег хватает на билеты, но не хватило бы, если убрать любую
одну купюру. По числу купюр каждого достоинства и цене билета вывести
все возможные количества билетов.

## Входные данные

Шесть чисел купюр, от меньшего достоинства к большему, затем цена. Все
числа не больше 1000, цена положительна. Хотя бы один ответ существует.

## Выходные данные

Число возможных ответов, затем ответы по возрастанию.

## Примеры

### Пример 1

Ввод:

```
0 2 0 0 0 0
10
```

Вывод:

```
5
6 7 8 9 10
```

### Пример 2

Ввод:

```
1 2 0 0 0 0
10
```

Вывод:

```
1
11
```

## Решение

Пусть сумма равна T, а наименьшая из данных купюр — s. Для k билетов
денег должно хватать: k·price ≤ T. Без любой одной купюры их хватать не
должно, и наименьшая купюра — самый трудный случай: если T − s мало,
то без любой большей купюры тоже мало. Значит, T − s < k·price, и
ответы — все k от ⌊(T − s)/price⌋ + 1 до ⌊T/price⌋. `O(answers)`, их
не больше 5000.

В первом примере T = 100 и s = 50: без одной купюры 50 рублей не должно
хватать, значит, билетов больше 5, и не больше 10.

Подводные камни:

- убирать нужно наименьшую из имеющихся купюр, а не вообще купюру в
  10 рублей;
- при купюре в 5000 рублей и цене 1 ответов 5000, и все в одной
  строке.

Ответы совпадают с независимой принятой реализацией на 300 случайных
случаях с малым и большим числом купюр.
