# 1707. Секрет Гипножабы

[Timus 1707](https://acm.timus.ru/problem.aspx?space=1&num=1707) · сложность 1916 · fenwick

Автор оригинальной задачи — Дмитрий Иванков; XIII чемпионат Урала по спортивному программированию, 4 апреля 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Состояния — числа 0 … n − 1. Каждый из m законов даёт состояния глаз
(sᵢ, tᵢ) = ((s₀ + iΔs) mod n, (t₀ + iΔt) mod n) для i = 0 … k − 1.
Каждый из p экспериментов по такому же правилу даёт q состояний прибора
(aⱼ, bⱼ, cⱼ, dⱼ). Для состояния прибора xⱼ = 1, если есть состояние
глаз с s между aⱼ и bⱼ и t между cⱼ и dⱼ, границы включительно, иначе
xⱼ = 0.

## Входные данные

n и m (1 ≤ n ≤ 5000, 1 ≤ m ≤ 1000), затем m строк s₀ t₀ Δs Δt k
(0 ≤ s₀, t₀, |Δs|, |Δt| ≤ n − 1, 1 ≤ k ≤ 567). Затем p (1 ≤ p ≤ 345) и
p строк a₀ b₀ c₀ d₀ Δa Δb Δc Δd q с теми же ограничениями на начала и
шаги и 1 ≤ q ≤ 345.

## Выходные данные

По строке на эксперимент: при q ≤ 20 цифры x₀ … x_{q−1} без пробелов,
при q > 20 число (Σ 7ʲ xⱼ) mod 200904040963.

## Решение

Состояния глаз — не более 567000 точек сетки n × n, и каждое состояние
прибора спрашивает, есть ли точка в прямоугольнике со сторонами вдоль
осей. Это решается подсчётом: если C(x, y) — число точек с s ≤ x и
t ≤ y, то в прямоугольнике [a, b] × [c, d] лежит
C(b, d) − C(a − 1, d) − C(b, c − 1) + C(a − 1, c − 1) точек, а угол с
отрицательной координатой даёт 0.

Все углы известны заранее, поэтому отвечаем офлайн. Проходим t от 0 до
n − 1: добавляем точки строки t в дерево Фенвика по s, затем для
каждого угла этой строки читаем C(x, t) как префиксную сумму дерева.
Полная таблица C заняла бы 25 миллионов счётчиков — слишком много
памяти, а проход хранит лишь дерево и по счётчику на угол. При P точках
и Q = 4 · Σq углах время `O((P + Q) log n + n)`.

Подводные камни:

- шаги бывают отрицательными, поэтому остатки нужно приводить к
  0 … n − 1;
- границы отрезка идут в любом порядке, в том числе aⱼ > bⱼ;
- в хеше x₀ стоит при младшей степени, 7⁰;
- решение на Python хранит точки и углы в компактных массивах,
  отсортированных по строкам подсчётом: списки целых объектов здесь
  занимают около 77 МБ, больше лимита в 64 МБ.

Ответы совпадают с независимой принятой реализацией на случайных
законах и экспериментах на маленьких сетках, на максимальных размерах
и на нескольких медленных законах с узкими прямоугольниками, где нули
и единицы перемешаны.
