# 1707. 催眠蟾蜍的秘密

[Timus 1707](https://acm.timus.ru/problem.aspx?space=1&num=1707) · 难度 1916 · fenwick

原题作者 Dmitry Ivankov，出自 2009 年 4 月 4 日第十三届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

状态是数 0 … n − 1。m 条规律中的每一条给出眼睛状态
(sᵢ, tᵢ) = ((s₀ + iΔs) mod n, (t₀ + iΔt) mod n)，i = 0 … k − 1。
p 个实验中的每一个按同样的规则给出 q 个仪器状态 (aⱼ, bⱼ, cⱼ, dⱼ)。
对一个仪器状态，若存在某个眼睛状态，其 s 在 aⱼ 与 bⱼ 之间、t 在 cⱼ 与 dⱼ 之间（含边界），则 xⱼ = 1，否则 xⱼ = 0。

## 输入

n 和 m（1 ≤ n ≤ 5000，1 ≤ m ≤ 1000），接着 m 行 s₀ t₀ Δs Δt k
（0 ≤ s₀, t₀, |Δs|, |Δt| ≤ n − 1，1 ≤ k ≤ 567）。然后是 p（1 ≤ p ≤ 345）
和 p 行 a₀ b₀ c₀ d₀ Δa Δb Δc Δd q，起点和步长的范围相同，1 ≤ q ≤ 345。

## 输出

每个实验一行：q ≤ 20 时输出不带空格的 x₀ … x_{q−1}，q > 20 时输出 (Σ 7ʲ xⱼ) mod 200904040963。

## 样例

### 样例 1

输入：

```
3 3
0 1 0 0 1
1 2 0 0 1
2 0 0 0 1
5
0 0 1 1 0 0 0 0 5
1 1 0 0 0 0 0 0 3
0 1 0 0 0 0 0 0 345
1 2 1 1 0 0 0 1 4
1 2 1 1 0 0 0 1 3
```

输出：

```
11111
000
0
0110
011
```

## 解法

眼睛状态是 n × n 网格上至多 567000 个点，每个仪器状态询问一个与坐标轴平行的矩形内是否有点。
这可以用计数解决：设 C(x, y) 为满足 s ≤ x 且 t ≤ y 的点数，则矩形 [a, b] × [c, d] 内有
C(b, d) − C(a − 1, d) − C(b, c − 1) + C(a − 1, c − 1) 个点，坐标为负的角计为 0。

所有角都事先已知，因此可以离线回答。让 t 从 0 扫到 n − 1：把第 t 行的点加入按 s 建的树状数组，
再对该行的每个角以树状数组前缀和读出 C(x, t)。完整的 C 表需要 2500 万个计数，内存不够；
扫描只需树状数组和每个角一个计数。设有 P 个点、Q = 4 · Σq 个角，时间为 `O((P + Q) log n + n)`。

注意事项：

- 步长可以为负，余数需要调整到 0 … n − 1；
- 区间的两端可以任意顺序给出，包括 aⱼ > bⱼ；
- 哈希中 x₀ 对应最低次幂 7⁰；
- Python 解法用紧凑数组保存点和角，并用计数排序按行排列：用整数对象列表在这里约需 77 MB，超过 64 MB 限制。

在小网格上的随机规律与实验、最大规模数据，以及少量慢速规律配窄矩形（0 和 1 混杂）的数据上，
答案与一个独立的已通过实现一致。
