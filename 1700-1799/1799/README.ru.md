# 1799. Саша и мажорные строки

[Timus 1799](https://acm.timus.ru/problem.aspx?space=1&num=1799) · сложность 4373 · strings

Автор оригинальной задачи — Александр Кульков; Петрозаводские летние сборы 2015, Moscow IPT Contest.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Строим бор всех суффиксов строки и сливаем каждую цепочку рёбер через
вершины с единственным ребёнком, без какого-либо концевого символа. На
каждом ребре этого сжатого дерева считаем число различных непустых
подстрок его метки и складываем. Ответить для каждой из нескольких
строк.

## Входные данные

n (1 ≤ n ≤ 10⁵), затем n строк из строчных букв суммарной длины не
больше 10⁵.

## Выходные данные

Сумма для каждой строки, по одной в строке.

## Примеры

### Пример 1

Ввод:

```
3
umqra
umnik
merkurev
```

Вывод:

```
35
35
101
```

### Пример 2

Ввод:

```
1
abaaa
```

Вывод:

```
17
```

## Решение

Одинаковые поддеревья суффиксного дерева в суффиксном автомате
склеены, поэтому строим автомат и сжимаем его так же: оставляем
начальное состояние и все состояния, у которых число исходящих
переходов не равно 1, а каждый путь через остальные заменяем одним
ребром. Как и в дереве, при этом пропадают состояния, где суффикс
просто кончается. Ребро из u в w с некоторой меткой соответствует
стольким рёбрам дерева, сколько путей ведёт из начала в u; их считаем
в порядке возрастания длины. Каждая метка — это подстрока s[l..r],
кончающаяся в первом вхождении строк w, так что остаётся найти число
различных подстрок s[l..r] для каждого ребра.

Эти запросы на отрезках решаются офлайн, по возрастанию r. Пока префикс
растёт до r, count[p] — число различных подстрок s[0..r], последнее
вхождение которых начинается в p; тогда ответ для s[l..r] — сумма
count[p] по p ≥ l. Добавленная буква делает последним вхождением всех
суффиксов префикса новый конец: это состояния на пути по суффиксным
ссылкам от нового префикса до начала. Они переходят целыми цепочками
состояний с общим прежним последним концом. Как в link–cut деревьях,
таких цепочек в среднем O(log n) на букву. Для цепочки старые начала
образуют один отрезок, поэтому count ведут два дерева Фенвика с
прибавлением и суммой на отрезке. Дерево отрезков по эйлерову обходу
дерева суффиксных ссылок даёт последний конец состояния — самый
поздний префикс в его поддереве. `O(n log² n)` по всем строкам.

Во втором примере у сжатого дерева рёбра a, aa, baaa и baaa с 1, 2, 7
и 7 различными подстроками. Два ребра baaa происходят из одного ребра
автомата, в начало которого ведут два пути.

Подводные камни:

- конец суффикса не останавливает сжатие: для aa дерево — одно ребро
  aa;
- одинаковые метки на разных рёбрах считаются обе, за это отвечает
  число путей в автомате;
- сумма не помещается в 32 бита;
- при 10⁵ строках каждый массив нужно заводить по размеру своей
  строки, а не по максимуму.

Ответы совпадают с явным сжатым суффиксным бором на более чем тысяче
коротких строк и с независимой принятой реализацией на длинных
случайных, периодических строках и словах Фибоначчи. Решение на
Python работает под PyPy.
