# 1799. Sasha 与潮字符串

[Timus 1799](https://acm.timus.ru/problem.aspx?space=1&num=1799) · 难度 4368 · strings

原题作者 Oleksandr Kulkov，出自 2015 年彼得罗扎沃茨克夏季集训 Moscow IPT Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

建立字符串所有后缀的字典树，并合并每一条经过只有一个孩子的结点的边链，不加任何结束符。在这棵压缩树的每条边上，统计其标签中不同非空子串的个数，再求和。对若干个字符串分别作答。

## 输入

n（1 ≤ n ≤ 10⁵），然后是 n 个由小写字母组成的字符串，总长度不超过 10⁵。

## 输出

每个字符串的和，每行一个。

## 样例

### 样例 1

输入：

```
3
umqra
umnik
merkurev
```

输出：

```
35
35
101
```

### 样例 2

输入：

```
1
abaaa
```

输出：

```
17
```

## 解法

后缀树中相同的子树在后缀自动机里被合并，所以改为建立自动机并用同样的方式压缩：保留初始状态以及出边数不等于 1 的所有状态，把经过其余状态的每条路径替换为一条边。
与树一样，这会去掉那些仅仅是某个后缀结束的状态。从 u 到 w、读出某个标签的边，对应的树边条数等于从初始状态到 u 的路径数，按长度递增的顺序统计。
每个标签都是在 w 的字符串第一次出现处结束的子串 s[l..r]，于是剩下的就是对每条边求 s[l..r] 中不同子串的个数。

这些区间询问按 r 递增离线回答。前缀增长到 r 时，count[p] 表示 s[0..r] 中最后一次出现从 p 开始的不同子串个数；那么 s[l..r] 的答案就是 p ≥ l 的 count[p] 之和。
追加一个字母会让前缀的所有后缀的最后一次出现都变成新的结尾：这些就是从新前缀沿后缀链接到初始状态路径上的状态。它们以“先前最后结尾相同”的状态链为单位整体移动。
与 link–cut 树一样，每个字母平均只有 O(log n) 条这样的链。一条链的旧起点构成一个区间，所以用两棵支持区间加和区间求和的树状数组维护 count。
在后缀链接树的欧拉序上用线段树求一个状态的最后结尾，即它子树中最晚的前缀。所有字符串合计 `O(n log² n)`。

第二个样例中压缩树的边是 a、aa、baaa 和 baaa，分别有 1、2、7 和 7 个不同子串。两条 baaa 边来自自动机中的同一条边，从初始状态到它的起点有两条路径。

注意事项：

- 后缀的结束不会阻止压缩：对 aa 来说，树只有一条边 aa；
- 不同边上相同的标签都要计数，这由自动机中的路径数负责；
- 和会超出 32 位；
- 字符串多达 10⁵ 个，每个数组都要按各自字符串的大小分配，而不是按最大值。

在一千多个短字符串上，答案与显式构造的压缩后缀字典树一致；在长的随机串、周期串和斐波那契串上，与一个独立的已通过实现一致。Python 解答在 PyPy 下运行。
