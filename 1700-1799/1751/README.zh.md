# 1751. 不可能性理论

[Timus 1751](https://acm.timus.ru/problem.aspx?space=1&num=1751) · 难度 3496 · graphs

原题作者 Damir Akhmetzyanov，出自 2009 年 8 月彼得罗扎沃茨克夏季集训的乌法国立航空技术大学专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个理论有 n 个假设，有些依赖于其他假设，可能成环。假设 i 以概率 pᵢ 可接受（相互独立），检查它需要 tᵢ 秒，一次只能检查一个。
当一个假设以及它直接或间接依赖的所有假设都可接受时，它为真。求在最优检查顺序下，弄清哪些假设为真的期望时间。

## 输入

n（1 ≤ n ≤ 500），然后对每个假设给出 tᵢ（1 ≤ tᵢ ≤ 1000）、pᵢ（0.0001 ≤ pᵢ ≤ 0.9999）、kᵢ 以及它直接依赖的 kᵢ 个假设。

## 输出

期望时间，误差不超过 10⁻³。

## 样例

### 样例 1

输入：

```
4
5 0.3 1 2
6 0.99 0
2 0.2 1 4
2 0.2 0
```

输出：

```
13.350
```

### 样例 2

输入：

```
3
1 0.5 1 2
2 0.5 1 3
3 0.5 1 1
```

输出：

```
2.750
```

## 解法

在同一依赖环上的假设互相依赖，所以它们同真同假。Tarjan 算法把假设分成这样的组，并且每个组都在它所依赖的所有组之后给出。

只有当一个组所依赖的所有组都被证实完全可接受时，这个组才需要检查；下面任何一次失败都已使它为假。
组内检查到第一次失败为止，最便宜的顺序是按 tᵢ / (1 − pᵢ) 从小到大：交换两个顺序不对的相邻项只会降低期望时间。
所以按这个顺序，组 g 的代价为 E_g = t₁ + p₁t₂ + p₁p₂t₃ + …，完全可接受的概率为 q_g = Πpᵢ。
答案是对所有组求 E_g 乘以 g 所依赖的所有组 h 的 q_h 之积的和。这个集合用位集构造：按 Tarjan 给出的顺序，每个组合并它所指向的组的位集。
设依赖数为 m，复杂度 `O(n² + n·m / 64)`。

样例 1 中 2 和 4 总要检查，分别 6 秒和 2 秒；1 只在 2 成立时检查，0.99 · 5；3 只在 4 成立时检查，0.2 · 2：共 13.35。

注意事项：

- 先检查某组再检查它下面的组，可能浪费本可由下面的失败省下的时间；
- 为真的组必须全部检查；
- 许多组的乘积可能非常小，这里无害。

在 200 个最多 6 个假设的随机理论上，答案与对所有已知信息搜索得到的最优自适应策略一致；在大测试上与一个独立的已通过实现一致。
