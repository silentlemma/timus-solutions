# 1751. Теория Невероятности

[Timus 1751](https://acm.timus.ru/problem.aspx?space=1&num=1751) · сложность 3496 · graphs

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В теории n гипотез, некоторые основаны на других, возможно по циклу.
Гипотеза i допустима с вероятностью pᵢ, независимо от прочих, и её
проверка занимает tᵢ секунд, по одной проверке за раз. Гипотеза
истинна, если допустимы она и всё, на чём она основана, прямо или
косвенно. Найти ожидаемое время, чтобы узнать, какие гипотезы истинны,
при лучшем порядке проверок.

## Входные данные

n (1 ≤ n ≤ 500), затем для каждой гипотезы tᵢ (1 ≤ tᵢ ≤ 1000), pᵢ
(0.0001 ≤ pᵢ ≤ 0.9999), kᵢ и kᵢ гипотез, на которых она основана
напрямую.

## Выходные данные

Ожидаемое время с погрешностью не более 10⁻³.

## Примеры

### Пример 1

Ввод:

```
4
5 0.3 1 2
6 0.99 0
2 0.2 1 4
2 0.2 0
```

Вывод:

```
13.350
```

### Пример 2

Ввод:

```
3
1 0.5 1 2
2 0.5 1 3
3 0.5 1 1
```

Вывод:

```
2.750
```

## Решение

Гипотезы на одном цикле зависимостей основаны друг на друге, поэтому
все вместе истинны или все ложны. Алгоритм Тарьяна разбивает гипотезы
на такие группы и выдаёт каждую группу после всех групп, на которых она
основана.

Группу нужно проверять, только если все группы, на которых она
основана, оказались полностью допустимыми; любая неудача ниже уже
делает её ложной. Внутри группы проверки идут до первой неудачи, и
самый дешёвый порядок — по tᵢ / (1 − pᵢ) по возрастанию: обмен двух
соседей, стоящих не в том порядке, может только уменьшить ожидаемое
время. Значит, группа g стоит E_g = t₁ + p₁t₂ + p₁p₂t₃ + … в этом
порядке и полностью допустима с вероятностью q_g = Πpᵢ. Ответ — сумма
по группам E_g, умноженного на произведение q_h по всем группам h, на
которых основана g. Это множество строится битовой маской: каждая
группа берёт маски групп, на которые указывает, в порядке выдачи
Тарьяна. `O(n² + n·m / 64)` при m зависимостях.

В первом примере 2 и 4 проверяются всегда, за 6 и 2 секунды, 1 — только
если верна 2, 0,99 · 5, а 3 — только если верна 4, 0,2 · 2: всего 13,35.

Подводные камни:

- проверка группы раньше групп под ней может потратить время, которое
  сберегла бы неудача ниже;
- истинную группу нужно проверить полностью;
- произведения по многим группам бывают очень малы, здесь это не
  мешает.

Ответы совпадают с лучшей адаптивной стратегией, найденной перебором
по всему уже известному, на 200 случайных теориях до 6 гипотез и с
независимой принятой реализацией на больших тестах.
