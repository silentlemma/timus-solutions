# 1781. Чистое программирование

[Timus 1781](https://acm.timus.ru/problem.aspx?space=1&num=1781) · сложность 2067 · graphs

Автор оригинальной задачи — Алексей Самсонов; XV Открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Таблица n × n из нулей и единиц говорит, какие классы задействует
каждое из n соревнований, идущих по порядку. Класс i убирают сразу
после соревнования i, и после этого им пользоваться нельзя, так что
соревнование i не может занимать класс j при j < i. Одна операция
меняет местами строки i и j, а затем столбцы i и j. Не более чем за 200
операций добиться подходящей таблицы или сообщить, что это невозможно.

## Входные данные

n (2 ≤ n ≤ 100), затем таблица.

## Выходные данные

Число операций и пары i, j или −1. Подходит любой подходящий ответ.

## Примеры

### Пример 1

Ввод:

```
3
0 0 0
1 1 0
1 1 0
```

Вывод:

```
1
1 3
```

### Пример 2

Ввод:

```
3
1 1 1
1 1 0
1 0 0
```

Вывод:

```
-1
```

## Решение

Одновременный обмен строк и столбцов лишь одинаково перенумеровывает
соревнования и их классы, и достижима любая перенумерация. Таблица
подходит, когда все единицы вне диагонали лежат над ней, то есть
соревнование a, занимающее класс b ≠ a, идёт раньше соревнования b. Это
рёбра a → b графа, а подходящая нумерация — его топологический порядок;
если в графе есть цикл, ничего не выйдет и ответ −1.

Порядок достигается, если ставить его соревнования на места 1, 2, … по
одному, каждое не более чем одним обменом стоящего там соревнования с
нужным, так что операций не больше n − 1 ≤ 99. `O(n²)`.

В первом примере соревнования 2 и 3 занимают класс 1, поэтому
соревнование 1 должно идти после обоих; обмен 1 и 3 ставит его
последним.

Подводные камни:

- соревнование может занимать свой класс, и эти диагональные единицы
  порядка не задают;
- каждая операция меняет строки и столбцы одинаково, так что это
  перенумерация, а не свободное перемещение строк;
- ответ не единственный, поэтому чекер проигрывает обмены.

Существование ответа совпадает с перебором всех перенумераций на 300
случайных таблицах до 5 классов, а обмены проходят чекер на 100
случайных таблицах до 100 классов, как и обмены независимой принятой
реализации.
