# 1720. Summit Online Judge

[Timus 1720](https://acm.timus.ru/problem.aspx?space=1&num=1720) · 难度 978 · math

原题作者 Alex Samsonov，出自 NEERC 2009 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

每场比赛有 x 到 y 道题。若若干场比赛恰好能凑出某个题数，则该卷册大小是正确的。统计 l 到 r 之间正确的大小个数。

## 输入

x、y、l、r（1 ≤ x ≤ y ≤ 10¹⁸，1 ≤ l ≤ r ≤ 10¹⁸）。

## 输出

[l, r] 中正确大小的个数。

## 样例

### 样例 1

输入：

```
4 5 7 13
```

输出：

```
5
```

## 解法

k 场比赛能达到的总题数恰好是区间 [kx, ky]。区间 k + 1 从 (k + 1)x 开始，当 (k + 1)x ≤ ky + 1
（即 k(y − x) ≥ x − 1）时它与区间 k（末尾为 ky）相接。这从某个 K 起成立，从 K·x 起每个数都被覆盖；
在 K 之前各区间彼此分开。所以统计 t 以内被覆盖的数 C(t)，答案为 C(r) − C(l − 1)：

- 若 x = y，被覆盖的是 x 的倍数，C(t) = ⌊t/x⌋；
- 否则 K = max(1, ⌈(x − 1)/(y − x)⌉)。在 t 之前结束的区间 k < K（即 k ≤ ⌊t/y⌋）共 f 个，
  贡献 (y − x)·f(f + 1)/2 + f；
- 下一个区间可能越过 t，若它在 t 之前开始，贡献 t − kx + 1；
- 从 K·x 起到 t 的数全部计入。

样例中 K = 3：区间 [4, 5] 和 [8, 10] 分开，从 12 起全部被覆盖，所以 8、9、10、12、13 是正确的。`O(1)`。

注意事项：

- x = 1 时第一个区间就已与其余相接：⌈0/(y − x)⌉ = 0，所以 K 至少取 1；
- K·x 可达 10³⁶，所以比较 K ≤ ⌊t/x⌋ 而不是 K·x ≤ t；分开的区间之和小于 t，可用 64 位整数存放；
- x = y 时根本没有相接点。

在较小范围内对所有 x、y、t 与暴力结果一致，并在 700 个最大到 10¹⁸ 的随机测试上与一个独立的已通过实现一致。
