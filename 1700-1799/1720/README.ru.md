# 1720. Summit Online Judge

Автор оригинальной задачи — Алексей Самсонов; NEERC 2009, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В каждом контесте от x до y задач. Размер тома правильный, если
несколько контестов могут дать ровно столько задач. Посчитать
правильные размеры от l до r.

## Входные данные

x, y, l и r (1 ≤ x ≤ y ≤ 10¹⁸, 1 ≤ l ≤ r ≤ 10¹⁸).

## Выходные данные

Число правильных размеров в [l, r].

## Примеры

### Пример 1

Ввод:

```
4 5 7 13
```

Вывод:

```
5
```

## Решение

При k контестах достижимые суммы — ровно отрезок [kx, ky]. Отрезок
k + 1 начинается с (k + 1)x. Он касается отрезка k, последнее число
которого ky, когда (k + 1)x ≤ ky + 1, то есть k(y − x) ≥ x − 1. Это
выполнено начиная с некоторого K, и начиная с K·x покрыто каждое число.
До K отрезки разделены. Поэтому считаем покрытые числа до t и отвечаем
C(r) − C(l − 1):

- если x = y, покрыты кратные x, и C(t) = ⌊t/x⌋;
- иначе K = max(1, ⌈(x − 1)/(y − x)⌉). Отрезки k < K, которые
  заканчиваются не позже t, то есть с k ≤ ⌊t/y⌋, дают
  (y − x)·f(f + 1)/2 + f, где f — их число;
- следующий отрезок может кончаться за t и даёт t − kx + 1 при k < K, если
  начинается не позже t;
- начиная с K·x засчитывается всё до t.

В примере K = 3: отрезки [4, 5] и [8, 10] разделены, а начиная с 12
покрыто всё, так что правильны 8, 9, 10, 12 и 13. `O(1)`.

Подводные камни:

- при x = 1 < y уже первый отрезок сливается с остальными:
  ⌈0/(y − x)⌉ = 0, поэтому K должно быть не меньше 1;
- K·x приближается к 10³⁶, поэтому сравниваем K ≤ ⌊t/x⌋ вместо K·x ≤ t;
  сумма разделённых отрезков меньше t и помещается в 64 бита;
- при x = y > 1 точки слияния нет вовсе.

Количества совпадают с полным перебором для всех x, y и t до небольших
границ и с независимой принятой реализацией на 700 случайных тестах до
10¹⁸.
