## Задача

Перечислить в алфавитном порядке все слова длины n из букв a, b и c, в
которых нет подстрок-палиндромов из двух и более букв. Если суммарно
они займут больше 100 000 букв, вывести `TOO LONG`.

## Входные данные

n (1 ≤ n ≤ 20 000).

## Выходные данные

Слова по одному в строке или `TOO LONG`.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
ab
ac
ba
bc
ca
cb
```

## Решение

В середине палиндрома из двух и более букв стоит палиндром из двух или
трёх букв, поэтому достаточно, чтобы соседние буквы и буквы через одну
были различны. Тогда любые три буквы подряд — это a, b и c в каком-то
порядке, и каждая буква повторяет букву на три позиции раньше: слово —
одна из шести перестановок a, b и c, повторённая. Значит, при n = 1
слов три, при любом большем n — шесть, и ответ `TOO LONG`, когда
6n > 100 000, то есть начиная с n = 16 667. `O(n)`.

Подводные камни:

- при n = 1 шесть перестановок дают только три разных слова;
- ограничение — на суммарную длину, а не на число слов.

Списки совпадают с проверкой всех слов из a, b и c по одному при n до
9.
