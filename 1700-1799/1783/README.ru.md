# 1783. Ядерная гонка

Автор оригинальной задачи — Павел Атнашев; XV Открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Одна страна планирует иметь ровно aᵢ боеголовок к концу месяца i. Её
соперник начинает с нуля и в начале месяца i, зная планы
aᵢ, …, aᵢ₊ₘ₋₁, выбирает наименьшее целое изменение xᵢ, при котором
изменение запаса на xᵢ в каждый из следующих m месяцев держало бы его
не ниже плана в конце каждого из них. Выполняется только изменение
этого месяца; в следующем месяце выбор делается заново. Вывести
x₁, …, xₙ.

## Входные данные

n и m (1 ≤ n ≤ 10000, 1 ≤ m ≤ 50), затем a₁, …, aₙ₊ₘ₋₁
(0 ≤ aᵢ ≤ 10⁵).

## Выходные данные

x₁, …, xₙ.

## Примеры

### Пример 1

Ввод:

```
4 3
0 0 4 2 1 0
```

Вывод:

```
2 1 1 -1
```

## Решение

При запасе s в начале месяца i после t месяцев одинакового изменения x
запас равен s + t·x и должен быть не меньше aᵢ₊ₜ₋₁. Поэтому x — наибольшее
из ⌈(aᵢ₊ₜ₋₁ − s)/t⌉ по t = 1…m. Затем запас растёт на x, и следующий месяц
повторяет то же. Округлять нужно вверх и для отрицательных чисел, где
обычное целочисленное деление во многих языках округляет к нулю.
`O(n·m)`.

В примере первый приказ должен за три месяца дотянуть до 4: 2. С
запасом 2 следующие планы 0, 4, 2 требуют ⌈2/2⌉ = 1; затем с 3 планы 4,
2, 1 требуют 1; затем с 4 планы 2, 1, 0 позволяют −1.

Подводные камни:

- приказы бывают отрицательными, когда планы падают;
- ⌈−3/2⌉ равно −1, а не −2 и не 0, поэтому деление должно явно
  округлять вверх;
- каждый раз выполняется только первый из планируемых месяцев.

Ответы совпадают с независимой принятой реализацией на 60 случайных
случаях — от нескольких месяцев до 10000 месяцев случайных,
волнообразных и редких всплесков в планах.
