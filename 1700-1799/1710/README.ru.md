# 1710. Борис, ты не прав!

[Timus 1710](https://acm.timus.ru/problem.aspx?space=1&num=1710) · сложность 649 · geometry

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Борис утверждает, что треугольники равны, если у них равны AB, BC и
угол при A, то есть две стороны и угол напротив одной из них. Дан
треугольник ABC. Вывести YES, если каждый треугольник, совпадающий с
ним в этом смысле, ему равен. Иначе вывести NO и такой треугольник
A₂B₂C₂, который ему не равен.

## Входные данные

Точки A, B и C, по одной в строке: целые координаты, по модулю не
больше 100, не на одной прямой.

## Выходные данные

YES, или NO и три точки контрпримера с наибольшей точностью.
Координаты должны быть не больше 1000 по модулю, а треугольник —
невырожденным. Подходит любой контрпример.

## Примеры

### Пример 1

Ввод:

```
0 0
-1 4
4 0
```

Вывод:

```
YES
```

### Пример 2

Ввод:

```
0 0
4 3
6 0
```

Вывод:

```
NO
0.0000000000 0.0000000000
-3.0000000000 4.0000000000
0.0000000000 2.0000000000
```

## Решение

Оставим A, B и направление луча из A к C. Любой подходящий треугольник
можно переместить в это положение, и C₂ окажется на этом луче на
расстоянии |BC| от B. Точка на расстоянии t по лучу подходит, когда
t² − 2t·(AB·u) + |AB|² − |BC|² = 0, где u — единичный вектор вдоль AC.
Один корень — |AC|. Другой — t′ = 2(AB·AC)/|AC| − |AC|, ведь сумма
корней равна 2(AB·u).

Другой треугольник существует ровно тогда, когда t′ > 0 и t′ ≠ |AC|.
В целых числах: 2(AB·AC) > |AC|² и AB·AC ≠ |AC|². Тогда
C₂ = A + (C − A)·(2(AB·AC) − |AC|²)/|AC|². Эта точка лежит на луче
ближе 2|AB| к A, то есть заведомо в пределах 1000, а у треугольника
ABC₂ те же AB, BC и угол A, но другая сторона AC. `O(1)`.

Подводные камни:

- при AB·AC = |AC|² окружность вокруг B касается луча, второй корень —
  сама точка C, и ответ YES (тест 07). Проверка в плавающей точке
  легко выводит C ещё раз как «другую» точку;
- тупой или прямой угол при A даёт t′ ≤ 0: YES (пример 1, тест 04);
- в Java печатать нужно с фиксированной локалью: некоторые локали
  выводят десятичную запятую.

Проверяющая программа принимает любой контрпример. Она проверяет две
стороны и угол при A, другую третью сторону, ненулевую площадь и
границу 1000. Вердикты совпадают с независимой принятой реализацией на
900 случайных треугольниках, кроме касательных, где та выводит C ещё
раз.
