# 1710. 鲍里斯，你错了！

[Timus 1710](https://acm.timus.ru/problem.aspx?space=1&num=1710) · 难度 649 · geometry

原题作者 Alexander Ipatov（由 Vladimir Yakovlev 准备），出自 2009 年 4 月 4 日第十三届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

鲍里斯声称：若两个三角形的 AB、BC 以及 A 处的角分别相等（即两边及其中一边的对角相等），则它们全等。
给定三角形 ABC，若每个在这种意义下与它一致的三角形都与它全等，输出 YES；否则输出 NO 以及一个不全等的三角形 A₂B₂C₂。

## 输入

点 A、B、C，每行一个：整数坐标，绝对值不超过 100，三点不共线。

## 输出

YES，或者 NO 加上反例的三个点，尽可能精确。坐标绝对值不超过 1000，三角形不能退化。任何反例都可以。

## 样例

### 样例 1

输入：

```
0 0
-1 4
4 0
```

输出：

```
YES
```

### 样例 2

输入：

```
0 0
4 3
6 0
```

输出：

```
NO
0.0000000000 0.0000000000
-3.0000000000 4.0000000000
0.0000000000 2.0000000000
```

## 解法

保持 A、B 以及从 A 指向 C 的射线方向不变。任何一致的三角形都能移到这个位置，此时 C₂ 在这条射线上，且到 B 的距离为 |BC|。
射线上距 A 为 t 的点满足条件当且仅当 t² − 2t·(AB·u) + |AB|² − |BC|² = 0，其中 u 是沿 AC 的单位向量。
一个根是 |AC|，因为两根之和为 2(AB·u)，另一个根是 t′ = 2(AB·AC)/|AC| − |AC|。

不同的三角形存在当且仅当 t′ > 0 且 t′ ≠ |AC|，用整数表示即 2(AB·AC) > |AC|² 且 AB·AC ≠ |AC|²。
此时 C₂ = A + (C − A)·(2(AB·AC) − |AC|²)/|AC|²。它在射线上距 A 不到 2|AB|，远在 1000 之内，
三角形 ABC₂ 的 AB、BC 和角 A 相同，但 AC 边不同。`O(1)`。

注意事项：

- 当 AB·AC = |AC|² 时，以 B 为圆心的圆与射线相切，另一个根就是 C 本身，答案为 YES（测试 07）；
  浮点判断很容易再次把 C 当作"不同"的点输出；
- A 处为钝角或直角时 t′ ≤ 0，答案为 YES（样例 1、测试 04）；
- Java 必须用固定的区域设置输出，因为有些区域设置会输出小数逗号。

检查程序接受任何反例：它检查两条边和 A 处的角、不同的第三边、非零面积以及 1000 的界限。
在 900 个随机三角形上，结论与一个独立的已通过实现一致，只有相切的情形例外，那里它会再次输出 C。
