# 1755. Торт

[Timus 1755](https://acm.timus.ru/problem.aspx?space=1&num=1755) · сложность 829 · greedy

Автор оригинальной задачи — Владислав Исенбаев; XI открытое личное первенство УрГУ, 13 марта 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В торте n граммов бисквита и m граммов шоколада. Малыш режет его на две
части с любым количеством каждого, а Карлсон берёт ту, что ему больше
нравится, а при равенстве оставляет выбор Малышу. Кусок с x граммами
бисквита и y шоколада Малыш оценивает в a₁x + b₁y, а Карлсон — в
a₂x + b₂y. Найти разрез, при котором Малышу достанется больше всего.

## Входные данные

a₁, b₁, a₂, b₂ (0 ≤ aᵢ, bᵢ ≤ 100), затем n и m (0 ≤ n, m ≤ 1000).

## Выходные данные

Бисквит и шоколад в одном из двух кусков с погрешностью не более
10⁻⁸. Подходит любой лучший разрез.

## Примеры

### Пример 1

Ввод:

```
1 2 3 2
400 300
```

Вывод:

```
300.00000000 0.00000000
```

## Решение

Малышу всегда достаётся кусок, который Карлсон ценит не больше чем в
половину всего торта, T/2 при T = a₂n + b₂m: если один кусок Карлсону
нравится больше, он его и берёт, а при равенстве оба куска стоят для
него T/2. Любой кусок, который Карлсон ценит не больше T/2, можно
сделать куском Малыша, просто отрезав его. Значит, нужно найти кусок
наибольшей ценности a₁x + b₁y при a₂x + b₂y ≤ T/2, 0 ≤ x ≤ n и
0 ≤ y ≤ m.

Это дробный рюкзак с двумя товарами: каждый грамм бисквита приносит a₁
и занимает a₂ места из T/2, каждый грамм шоколада приносит b₁ и
занимает b₂. Лучше всего взять сначала товар с большей ценностью на
единицу места, сколько поместится, а затем другой. Товары, не
занимающие места, берутся целиком, а сравнение a₁·b₂ с b₁·a₂ сохраняет
порядок точным. `O(1)`.

В примере T/2 = 900. Шоколад приносит 2 за 2 места, а бисквит 1 за 3,
поэтому берутся все 300 граммов шоколада, занимая 600, а затем 100
граммов бисквита: кусок ценностью 700 для Малыша. Программа выводит
этот кусок, 100 и 300; в примере выведен другой, 300 и 0, — это тот же
разрез.

Подводные камни:

- в ответе можно назвать любой из кусков, важен разрез, а не кусок;
- если Карлсону ничего не нравится, Малыш может забрать весь торт;
- равенство Малышу не мешает, поэтому кусок может занять место ровно.

Разрезы дают Малышу ту же ценность, что и независимая принятая
реализация, перебирающая углы допустимой области, на 600 случайных
тортах, в том числе с нулевыми коэффициентами и совпадающими вкусами.
