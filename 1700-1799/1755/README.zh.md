# 1755. 蛋糕

[Timus 1755](https://acm.timus.ru/problem.aspx?space=1&num=1755) · 难度 833 · greedy

原题作者 Vladislav Isenbaev，出自 2010 年 3 月 13 日第十一届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个蛋糕含 n 克奶油和 m 克巧克力。小男孩把它切成两块（每种成分的量任意），卡尔松拿走他更喜欢的那块，若两块一样好则让小男孩选。
含 x 克奶油、y 克巧克力的一块，小男孩估值为 a₁x + b₁y，卡尔松估值为 a₂x + b₂y。求一种切法使小男孩得到的最多。

## 输入

a₁, b₁, a₂, b₂（0 ≤ aᵢ, bᵢ ≤ 100），然后是 n 和 m（0 ≤ n, m ≤ 1000）。

## 输出

两块之一的奶油和巧克力量，误差不超过 10⁻⁸。任何最优切法都可以。

## 样例

### 样例 1

输入：

```
1 2 3 2
400 300
```

输出：

```
300.00000000 0.00000000
```

## 解法

小男孩最终得到的那块，卡尔松的估值总不超过整个蛋糕的一半 T/2，其中 T = a₂n + b₂m：如果卡尔松更喜欢某一块，他就拿走它；
若一样，两块对他都值 T/2。任何卡尔松估值不超过 T/2 的块，只要把它切下来就能归小男孩。
所以问题是在 a₂x + b₂y ≤ T/2、0 ≤ x ≤ n、0 ≤ y ≤ m 下求 a₁x + b₁y 的最大值。

这是两种物品的分数背包：每克奶油带来 a₁、占用 T/2 中的 a₂，每克巧克力带来 b₁、占用 b₂。
先尽量多取单位占用价值更高的物品，再取另一种，就是最优的。不占空间的物品排在最前，比较 a₁·b₂ 与 b₁·a₂ 可使顺序判断精确。`O(1)`。

样例中 T/2 = 900。巧克力每 2 单位空间带来 2，奶油每 3 单位带来 1，所以先取全部 300 克巧克力，占用 600，再取 100 克奶油：
对小男孩价值 700 的一块。程序输出这块 100 和 300；样例输出的是另一块 300 和 0，是同一种切法。

注意事项：

- 答案可以给出任意一块，重要的是切法而不是哪一块；
- 卡尔松什么都不喜欢时，小男孩可以拿走整个蛋糕；
- 平局对小男孩无妨，所以这块可以恰好占满空间。

在 600 个随机蛋糕上（包括零系数和口味一致的情况），这些切法给小男孩的价值与一个独立的已通过实现（枚举可行区域的角点）相同。
