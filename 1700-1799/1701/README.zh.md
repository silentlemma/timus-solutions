# 1701. 奥斯塔普和伙伴们

[Timus 1701](https://acm.timus.ru/problem.aspx?space=1&num=1701) · 难度 639 · dsu

原题作者 Dmitry Ivankov，出自 2009 年 4 月 4 日第十三届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

笔记本里记着形如“员工 i 比员工 j 多挣 d”的陈述。0 号员工瓦西里挣 0，其他人都不超过 10⁹（也不少于 0）。
求满足所有陈述的工资，或者第一条无法与前面各条同时满足的陈述的编号。

## 输入

n 和 m（1 ≤ n, m ≤ 50000），然后是 m 条陈述 i j d（0 ≤ i, j < n；|d| ≤ 20000）。

## 输出

Possible 和 n 个工资，或 “Impossible after i statements”。任何满足条件的工资都可以。

## 样例

### 样例 1

输入：

```
5 6
3 4 1200
4 1 -5500
2 3 4300
3 0 8200
0 4 -7000
2 1 0
```

输出：

```
Possible
0
12500
12500
8200
7000
```

### 样例 2

输入：

```
3 5
1 2 5
0 2 0
1 0 -5
1 2 5
2 2 0
```

输出：

```
Impossible after 3 statements
```

### 样例 3

输入：

```
3 2
1 0 871
1 2 903
```

输出：

```
Impossible after 2 statements
```

## 解法

用带权并查集按顺序处理陈述。每个员工存储自己与父亲的工资差，于是路径压缩后 salary(x) = salary(root) + offset(x)。
每个集合还记录其根的工资可以取值的范围，使集合内所有工资都在 0 … 10⁹ 之内。瓦西里所在的集合一开始只有取值 0。

同一集合内的陈述 salary(i) − salary(j) = d 必须与偏移一致。两个集合之间的陈述确定 salary(rⱼ) = salary(rᵢ) + shift。
合并后根的范围是原范围与另一个根的范围平移 −shift 后的交集，范围为空就说明这条陈述破坏了条件。
最后每个根取其范围的最小值，所有工资由偏移得出。`O((n + m) α(n))`。

注意事项：

- 陈述可能只与上下界矛盾而不与其他陈述矛盾：在第三个样例中，第二条陈述让某人的工资变成负数；
- 陈述可能把员工和自己比较，此时 d 必须为 0（测试 05）；
- 这里上界永远不会起作用，因为 |d| ≤ 20000 且至多 49999 条联系，任何差都小于 10⁹，但下界会起作用；
- 查找根使用迭代路径压缩，按大小合并使树保持较浅的深度。

检查器验证瓦西里的 0、取值范围和每一条陈述，或者逐字比较 Impossible 行；一个独立的已通过实现在同样的测试上也能通过它。
