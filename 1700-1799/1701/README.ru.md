# 1701. Остап и партнёры

[Timus 1701](https://acm.timus.ru/problem.aspx?space=1&num=1701) · сложность 641 · dsu

Автор оригинальной задачи — Дмитрий Иванков; XIII чемпионат Урала по спортивному программированию, 4 апреля 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В блокноте записаны утверждения «сотрудник i получает на d больше
сотрудника j». Сотрудник 0, Василий, получает 0, и никто больше не
получает больше 10⁹ (или меньше 0). Найти зарплаты, подходящие под все
утверждения, или номер первого утверждения, которое не удаётся
выполнить вместе с предыдущими.

## Входные данные

n и m (1 ≤ n, m ≤ 50000), затем m утверждений i j d
(0 ≤ i, j < n; |d| ≤ 20000).

## Выходные данные

Possible и n зарплат или «Impossible after i statements». Подходят любые
верные зарплаты.

## Примеры

### Пример 1

Ввод:

```
5 6
3 4 1200
4 1 -5500
2 3 4300
3 0 8200
0 4 -7000
2 1 0
```

Вывод:

```
Possible
0
12500
12500
8200
7000
```

### Пример 2

Ввод:

```
3 5
1 2 5
0 2 0
1 0 -5
1 2 5
2 2 0
```

Вывод:

```
Impossible after 3 statements
```

### Пример 3

Ввод:

```
3 2
1 0 871
1 2 903
```

Вывод:

```
Impossible after 2 statements
```

## Решение

Обрабатываем утверждения по порядку системой непересекающихся множеств
с весами. Каждый сотрудник хранит разницу между своей зарплатой и
зарплатой родителя, так что после сжатия пути
salary(x) = salary(root) + offset(x). Каждое множество также хранит
диапазон значений, которые может принять зарплата его корня, чтобы все
его зарплаты оставались в 0 … 10⁹. Множество Василия начинается с
единственного значения 0.

Утверждение salary(i) − salary(j) = d внутри одного множества должно
согласоваться со смещениями. Между двумя множествами оно задаёт
salary(rⱼ) = salary(rᵢ) + shift. Диапазон объединённого корня — старый
диапазон, пересечённый с диапазоном другого корня, сдвинутым на
−shift, и пустой диапазон означает, что утверждение всё ломает. В
конце каждый корень берёт наименьшее значение своего диапазона, а все
зарплаты следуют из смещений. `O((n + m) α(n))`.

Подводные камни:

- утверждение может противоречить только границам, а не другим
  утверждениям: в третьем примере второе утверждение делает зарплату
  отрицательной;
- утверждение может сравнивать сотрудника с ним самим, и тогда d должно
  быть 0 (тест 05);
- верхняя граница здесь никогда не срабатывает: |d| ≤ 20000 и не больше
  49999 связей держат любую разницу ниже 10⁹, а нижняя срабатывает;
- поиск корня идёт без рекурсии, ведь до сжатия множества образуют
  длинные цепочки.

Чекер проверяет 0 у Василия, диапазоны и каждое утверждение или точную
строку Impossible; независимая принятая реализация проходит его на тех
же тестах.
