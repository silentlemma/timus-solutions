# 1763. Блоха-знаток

## Задача

Круглый стол разделён на n секторов, занумерованных по часовой стрелке.
Начиная с сектора 1, путник переходит на соседний сектор или
перепрыгивает через два сектора, то есть с сектора i на i ± 1 или
i ± 3 по кругу. Посчитать обходы, которые посещают каждый сектор ровно
один раз и возвращаются на сектор 1, по модулю 10⁹ + 9.

## Входные данные

n (6 ≤ n ≤ 10⁹).

## Выходные данные

Число обходов по модулю 10⁹ + 9.

## Примеры

### Пример 1

Ввод:

```
6
```

Вывод:

```
12
```

## Решение

Обходы — это гамильтоновы циклы круга с хордами длины 3, каждый в обоих
направлениях. Их можно считать по секторам: если решать, какие рёбра
идут из каждого сектора вперёд, к i + 1 и i + 3, открытыми остаются
лишь несколько последних секторов и три первых, которые получают рёбра
через «шов» в самом конце. Состояние хранит степень каждого открытого
сектора и то, какие открытые концы принадлежат одному пути, а цикл
может замкнуться только последним ребром. Получается конечное множество
состояний с фиксированными переходами, поэтому числа подчиняются
линейной рекурренте.

Рекуррента найдена методом Берлекэмпа—Мэсси по числам для 7—200
секторов, посчитанным этим перебором: её порядок 19, она не меняется,
берётся ли 40 или 195 членов, и воспроизводит все числа до 200. Сам
перебор совпадает с простым перебором всех обходов до 33 секторов. При
шести секторах прыжки на +3 и −3 приводят в один сектор, поэтому 6
обрабатывается отдельно.

Для больших n многочлен x^(n − 7) приводится по модулю характеристического
многочлена рекурренты быстрым возведением в степень, и полученные
коэффициенты смешивают первые 19 чисел. `O(k² log n)` при k = 19.

При шести секторах обходов 12: 6 неориентированных циклов, каждый в
обоих направлениях.

Подводные камни:

- при шести секторах ходы +3 и −3 совпадают, и это ломает закономерность
  остальных столов;
- часть коэффициентов отрицательна, их нужно возвращать в диапазон;
- число не монотонно: 9 секторов дают 110 обходов, меньше, чем 8.

Ответы совпадают с числами перебора для всех столов до 200 секторов и с
независимой принятой реализацией на 80 случайных столах до 10⁹
секторов.
