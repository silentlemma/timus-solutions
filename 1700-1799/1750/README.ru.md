# 1750. Пахом и овраг

## Задача

Овраг — ломаная ABC. Найти кратчайший путь из S в T, не пересекающий
его; идти вдоль края или обходить концы можно.

## Входные данные

Число тестов n (1 ≤ n ≤ 5000), затем для каждого теста координаты S, T,
A, B и C — целые числа, по модулю не больше 10. Все пять точек
различны, S и T не лежат на овраге.

## Выходные данные

Длина кратчайшего пути для каждого теста с погрешностью не более 10⁻⁶.

## Примеры

### Пример 1

Ввод:

```
3
1 2 5 6 4 4 5 2 1 6
2 2 4 3 1 3 3 3 3 1
2 1 4 4 3 2 4 3 1 4
```

Вывод:

```
8.000000
3.650282
3.828427
```

## Решение

Кратчайший путь — ломаная, изгибающаяся только в точках оврага, так что
это S, затем некоторые из A, B и C в каком-то порядке, затем T: не
больше 16 кандидатов. Берём кратчайший допустимый: сортировкой, а в
Java/Rust — поддерживая минимум. `O(1)` на тест.

Все проверки идут в целых числах. Кандидат недопустим, если какое-то
его звено собственно пересекает AB или BC. Излом B требует большей
осторожности: овраг продолжается от него в обе стороны, поэтому путь
может касаться B, но должен оставаться в одном из двух замкнутых
секторов между лучами BA и BC — и когда проходит через B напрямую, и
когда поворачивает там. Когда BA и BC направлены одинаково, овраг
складывается сам на себя, B становится свободным концом, а конец
оврага, лежащий внутри другого звена, вовсе не угол: путь не может
перейти там на другую сторону.

В первом примере прямой путь пересекает BC, а обход C занимает
4 + 4 = 8.

Подводные камни:

- овраг может быть прямым, с B посередине: пересечение в B — всё равно
  пересечение;
- овраг может сложиться так, что A лежит внутри BC или C внутри AB;
  тогда эта точка — середина оврага, а не конец, который можно обойти;
- путь вдоль стороны оврага лишь касается его.

Длины совпадают с независимой принятой реализацией на 4986 из 5000
случайных тестов. Остальные 14 — все со сложенным оврагом, где та
реализация проходит прямо через конец, лежащий внутри другого звена, то
есть пересекает овраг; здесь путь обходит свободный конец.
