# 1750. 帕霍姆与沟壑

[Timus 1750](https://acm.timus.ru/problem.aspx?space=1&num=1750) · 难度 1260 · geometry

原题作者 Petr Lezhankin，出自 2009 年 8 月彼得罗扎沃茨克夏季集训的乌法国立航空技术大学专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

沟壑是折线 ABC。求从 S 到 T 不穿过沟壑的最短路径；沿着沟沿走或绕过它的端点都可以。

## 输入

测试数 n（1 ≤ n ≤ 5000），然后每个测试给出 S、T、A、B、C 的坐标，均为绝对值不超过 10 的整数。五点互不相同，S 和 T 不在沟壑上。

## 输出

每个测试的最短路径长度，误差不超过 10⁻⁶。

## 样例

### 样例 1

输入：

```
3
1 2 5 6 4 4 5 2 1 6
2 2 4 3 1 3 3 3 3 1
2 1 4 4 3 2 4 3 1 4
```

输出：

```
8.000000
3.650282
3.828427
```

## 解法

最短路径是只在沟壑上的点处转折的折线，所以它是 S，然后按某种顺序经过 A、B、C 中的若干个，再到 T：至多 16 个候选。
按长度排序，取第一个合法的；Java/Rust 则维护合法候选的最小长度。每个测试 `O(1)`。

所有检查都用整数进行。若某段与 AB 或 BC 真正相交，候选就不合法。折点 B 需要更小心：沟壑从它向两边延伸，
所以路径可以接触 B，但必须留在射线 BA 与 BC 之间的两个闭扇形之一中——无论是径直穿过 B 还是在那里转弯。
当 BA 和 BC 方向相同时，沟壑折回自身，B 成为自由端点，而位于另一段内部的沟壑端点根本不是拐角：路径不能在那里换边。

样例 1 中直线路径穿过 BC，绕过 C 需要 4 + 4 = 8。

注意事项：

- 沟壑可能是直的，B 在中间：在 B 处穿过仍是穿过；
- 沟壑可能折回，使 A 位于 BC 内部或 C 位于 AB 内部；这时该点处于沟壑中间，而不是可以绕过的端点；
- 沿沟壑一边走只是接触它。

在 5000 个随机测试中的 4986 个上，长度与一个独立的已通过实现一致。其余 14 个都是折回的沟壑，
那个实现径直穿过位于另一段内部的端点，也就是穿过了沟壑；这里的路径改为绕过自由端点。
