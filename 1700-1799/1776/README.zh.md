# 1776. 周年烟火

[Timus 1776](https://acm.timus.ru/problem.aspx?space=1&num=1776) · 难度 465 · dp

原题作者 Alex Samsonov，出自第十五届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 枚火箭排成一行。第一轮齐射发射两端的火箭。之后每轮齐射前，在两枚已发射的相邻火箭之间的每个非空区段中等概率选出一枚火箭，所有选中的火箭在这一轮发射。
齐射间隔十秒，发射最后一枚火箭的那轮结束演出。求演出的期望时长（秒）。

## 输入

n（3 ≤ n ≤ 400）。

## 输出

期望时长，绝对或相对误差不超过 10⁻⁶。

## 样例

### 样例 1

输入：

```
5
```

输出：

```
26.66666666666
```

## 解法

第一轮后 m = n − 2 枚内部火箭构成一个区段；含 i 枚的区段在其随机选中的火箭处分为 l 枚和 i − 1 − l 枚两段（每个 l 的概率为 1/i），之后两段独立发展。
设 done(i, j) 为 i 枚的区段在 j 轮内发射完的概率：done(0, j) = 1，i ≤ j 时 done(i, j) = 1，否则

done(i, j) = (1/i) · Σ done(l, j − 1) · done(i − 1 − l, j − 1)。

之后轮数的期望为对 j ≥ 0 求和 Σ (1 − done(m, j))，答案是它的十倍。轮数的分布类似随机搜索树的高度，约为 4.3 ln m，尾部下降得非常快，
所以一旦 1 − done(m, j) 小于 10⁻¹⁵ 就停止求和：只需几十轮、每轮 `O(m²)`，而不是 `O(m³)`。

五枚火箭时，三枚内部火箭以 1/3 的概率在中间那枚处分开，之后还需两轮，否则需要三轮：10 × (2/3 · 3 + 1/3 · 2) = 26.67 秒。

注意事项：

- 第一轮齐射开始演出，不增加时间；
- 各区段独立分裂，所以一个区段的概率是其两部分概率的乘积；
- 对全部 m 轮求和也可以，但需要 `O(m³)`，对某些语言太慢。

对 400 以内的许多 n，答案与一个独立的已通过实现（对全部轮次求和）的结果在 10⁻⁹ 内一致。
