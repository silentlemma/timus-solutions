# 1776. Праздничный фейерверк

[Timus 1776](https://acm.timus.ru/problem.aspx?space=1&num=1776) · сложность 465 · dp

Автор оригинальной задачи — Алексей Самсонов; XV Открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n ракет стоят в ряд. Первый залп запускает две крайние ракеты. Перед
каждым следующим залпом в каждом непустом отрезке ракет между двумя
запущенными соседями равновероятно выбирается одна ракета, и все
выбранные взлетают в этом залпе. Залпы идут с интервалом десять секунд,
и фейерверк заканчивается залпом, запускающим последнюю ракету. Найти
ожидаемую длительность фейерверка в секундах.

## Входные данные

n (3 ≤ n ≤ 400).

## Выходные данные

Ожидаемая длительность с абсолютной или относительной погрешностью не
более 10⁻⁶.

## Примеры

### Пример 1

Ввод:

```
5
```

Вывод:

```
26.66666666666
```

## Решение

После первого залпа m = n − 2 внутренних ракет образуют один отрезок, а
отрезок из i ракет делится на своей случайной ракете на отрезки из l и
i − 1 − l ракет, для каждого l с вероятностью 1/i, и они дальше живут
независимо. Пусть done(i, j) — вероятность, что отрезок из i ракет
закончится не больше чем за j залпов: done(0, j) = 1, done(i, j) = 1 при
i ≤ j, а иначе

done(i, j) = (1/i) · Σ done(l, j − 1) · done(i − 1 − l, j − 1).

Ожидаемое число дальнейших залпов — Σ (1 − done(m, j)) по j ≥ 0, а
ответ в десять раз больше. Число залпов ведёт себя как высота
случайного дерева поиска, около 4,3 ln m, и его хвост убывает очень
быстро, поэтому сумма останавливается, как только 1 − done(m, j)
становится меньше 10⁻¹⁵: несколько десятков шагов по `O(m²)` вместо
`O(m³)`.

При пяти ракетах три внутренние делятся на средней с вероятностью 1/3,
и тогда нужно ещё два залпа, а иначе три: 10 × (2/3 · 3 + 1/3 · 2) =
26,67 секунды.

Подводные камни:

- первый залп начинает фейерверк и времени не добавляет;
- отрезки делятся независимо, поэтому вероятность для отрезка — это
  произведение вероятностей для двух его частей;
- суммирование всех m шагов тоже работает, но стоит `O(m³)` — для
  некоторых языков слишком медленно.

Ответы совпадают с независимой принятой реализацией, суммирующей все
шаги, для многих n до 400 с точностью 10⁻⁹.
