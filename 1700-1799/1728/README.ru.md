# 1728. Проклятие Team.GOV

[Timus 1728](https://acm.timus.ru/problem.aspx?space=1&num=1728) · сложность 524 · implementation

## Задача

Ефремов и Канторов выбирают третьего участника из списка претендентов.
Сила команды — сумма рейтингов её участников. Если выбранный состав уже
выступал на каком-то прошлом турнире, Ефремов не приходит; если и
состав без него уже выступал, команду дисквалифицируют. Выбрать
претендента, дающего самую сильную выступающую команду, или сообщить,
что при любом выборе команду дисквалифицируют.

## Входные данные

n (1 ≤ n ≤ 100) прошлых составов: размер от 1 до 3 и фамилии в
алфавитном порядке; в каждом составе есть Канторов, в каждом составе из
трёх — Ефремов. Затем рейтинги Ефремова и Канторова, m (1 ≤ m ≤ 100) и
m претендентов с рейтингами. Рейтинги от 1 до 666.

## Выходные данные

`Win` и претендент, дающий самую сильную команду, или `Fail`. Подходит
любой лучший претендент.

## Примеры

### Пример 1

Ввод:

```
6
3 Efremov Kantorov Rubinchik
2 Efremov Kantorov
3 Efremov Kantorov Kokovin
3 Burmistrov Efremov Kantorov
3 Efremov Kantorov Pervukhin
2 Kantorov Pervukhin
100 10
6
Fominykh 200
Komarov 34
Pervukhin 250
Golubev 23
Soboleva 50
Gein 50
```

Вывод:

```
Win
Fominykh
```

### Пример 2

Ввод:

```
2
3 Efremov Fominykh Kantorov
2 Fominykh Kantorov
99 666
1
Fominykh 100
```

Вывод:

```
Fail
```

## Решение

Храним каждый прошлый состав как множество фамилий. Для каждого
претендента c: если {Efremov, Kantorov, c} — новый состав, играют все
трое, и сила — сумма трёх рейтингов; иначе, если новый {Kantorov, c},
двое играют без Ефремова; иначе c не годится. Берём самого сильного из
оставшихся или `Fail`, если их нет. Ожидаемое время `O(n + m)`;
в C++ — `O((n + m) log n)`.

В первом примере Fominykh даёт 100 + 10 + 200 = 310. Pervukhin уже
играл с обоими и с одним Канторовым, так что такую команду
дисквалифицируют.

Подводные камни:

- состав сравнивается как множество фамилий, а не по одному
  претенденту: претендент, игравший только с Канторовым, всё равно
  приводит Ефремова;
- составы из Ефремова с Канторовым или из одного Канторова никогда не
  совпадают с составом с претендентом;
- более сильный претендент, из-за которого не придёт Ефремов, может
  проиграть более слабому, с которым Ефремов придёт.

Проверяющая программа пересчитывает силу каждого претендента и
принимает любого лучшего. Ответы совпадают с независимой принятой
реализацией на 200 случайных наборах.
