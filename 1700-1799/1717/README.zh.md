# 1717. 参赛规则

[Timus 1717](https://acm.timus.ru/problem.aspx?space=1&num=1717) · 难度 2166 · segment_tree

原题作者 Sergey Pupyrev，由 Alex Samsonov 整理，出自 NEERC 2009 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 支队伍各有平均年龄 a、参赛次数 f 和满意度 s。选择一个年龄范围和一个参赛次数范围，
使至少两支队伍同时落在两个范围内，且这些队伍的满意度之和最大。

## 输入

n（2 ≤ n ≤ 1500），然后 n 行 a f s，其中 4·10⁸ ≤ a ≤ 10⁹，0 ≤ f ≤ 10⁹，|s| ≤ 10⁹。

## 输出

第一行是年龄范围，第二行是参赛次数范围，都是 0 到 10⁹ 之间的整数。任何最优的范围对都可以。

## 样例

### 样例 1

输入：

```
4
500000000 1 1
510000000 3 -10
600000000 3 2
700000000 4 3
```

输出：

```
550000000 750000000
2 5
```

## 解法

这是平面上点的最大权矩形问题，且矩形内至少有两个点。只有 a 和 f 的不同取值有意义。
依次固定最小年龄，逐步提高最大年龄，把每个新年龄的队伍加入按 f 的不同取值建立的线段树。

节点保存总和、队伍数（上限为 2）、对每个确切数量 0、1、"2 或更多"的最佳前缀和最佳后缀，
以及含两支或更多队伍的最佳区间。这里的前缀和后缀从不为空。两个子节点按最大子段和的常规方法合并，
数量相加并截断；跨越中点的区间由左子节点的后缀和右子节点的前缀拼成，二者数量之和至少为 2。
每加入一个新年龄后，根节点给出这些年龄下最佳的参赛次数范围。总共 `O(n² log n)`。

线段树只求出最佳值及其年龄对；然后对这对年龄用前缀和一次扫描重新求出参赛次数范围：
对每个右端点，最佳左端点是在区间内至少留下两支队伍的那些左端点中前缀和最小的。

注意事项：

- 单独一支队伍永远不能作为答案，即使其他队伍都只会使总和变小（测试 02）；
- 同一年龄的队伍必须全部加入后才能读取根节点，f 相同的队伍共用一个叶子；
- 总和可达 1.5 · 10¹²，需要 64 位整数；
- Python 解答在 PyPy 下运行，线段树存放在四个扁平数组中：它不再按三种确切计数分别保存，而只保存至少含一支队伍的最优前缀和后缀，因此跨过结点中点的区间本身就含两支队伍，只有叶子需要区分一支和两支。CPython 处理 1500 支队伍约需 5 秒。在 PyPy 下评测用时 0.75 秒；使用九个计数数组的早期版本在评测的第 5 个测试上超时。

检查程序接受任何最优的范围对：它检查边界、至少有两支队伍入选以及总和。
在 300 个小型随机测试和若干大型测试上，答案与一个独立的已通过实现一致。
