# 1717. Правила допуска

[Timus 1717](https://acm.timus.ru/problem.aspx?space=1&num=1717) · сложность 2166 · segment_tree

Автор оригинальной задачи — Сергей Пупырев, подготовка — Алексей Самсонов; NEERC 2009, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У каждой из n команд есть средний возраст a, число соревнований f и
удовлетворение s. Выбрать диапазон возрастов и диапазон числа
соревнований так, чтобы в оба попадали хотя бы две команды, а суммарное
удовлетворение этих команд было наибольшим.

## Входные данные

n (2 ≤ n ≤ 1500), затем n строк a f s, где 4·10⁸ ≤ a ≤ 10⁹,
0 ≤ f ≤ 10⁹ и |s| ≤ 10⁹.

## Выходные данные

Диапазон возрастов в первой строке и диапазон соревнований во второй —
целые числа от 0 до 10⁹. Подходит любая оптимальная пара диапазонов.

## Примеры

### Пример 1

Ввод:

```
4
500000000 1 1
510000000 3 -10
600000000 3 2
700000000 4 3
```

Вывод:

```
550000000 750000000
2 5
```

## Решение

Это прямоугольник наибольшего веса над точками плоскости, внутри
которого не меньше двух точек. Важны только различные значения a и f.
По очереди фиксируем наименьший возраст и шаг за шагом поднимаем
наибольший, добавляя команды каждого нового возраста в дерево отрезков
над различными значениями f.

Узел хранит сумму, число команд (не больше 2), лучший префикс и лучший
суффикс для каждого точного количества 0, 1 и «2 или больше», а также
лучший отрезок с двумя и более командами. Префиксы и суффиксы здесь
никогда не пусты. Два потомка объединяются как обычно для наибольшего
подотрезка, с количествами, сложенными и ограниченными. Отрезок через
середину соединяет суффикс левого потомка и префикс правого, у которых
в сумме не меньше двух команд. После каждого нового возраста корень
даёт лучший диапазон соревнований для этих возрастов. Всего это
`O(n² log n)`.

Дерево находит только лучшее значение и его пару возрастов. Диапазон
соревнований для этой пары затем находится заново по префиксным суммам
за один проход. Для каждого правого конца лучший левый — с наименьшей
префиксной суммой среди тех, что оставляют внутри хотя бы две команды.

Подводные камни:

- одна команда никогда не может быть ответом, даже когда все остальные
  только ухудшают сумму (тест 02);
- команды с одинаковым возрастом нужно добавить все до чтения корня, а
  команды с одинаковым f делят один лист;
- суммы доходят до 1,5 · 10¹², поэтому нужны 64 бита;
- решение на Python работает под PyPy с деревом в четырёх плоских
  массивах: вместо трёх точных счётчиков оно хранит только лучшие
  префикс и суффикс, содержащие хотя бы одну команду, так что отрезок
  через середину вершины сам содержит две команды, и отличать одну
  команду от двух нужно только в листьях. CPython на 1500 командах нужно
  около 5 с. Под PyPy у жюри решение тратит 0,75 с; прежняя версия с
  девятью массивами счётчиков не укладывалась во время на тесте 5 жюри.

Проверяющая программа принимает любую оптимальную пару диапазонов. Она
проверяет границы, то, что допущены хотя бы две команды, и сумму.
Ответы совпадают с независимой принятой реализацией на 300 маленьких
случайных тестах и на больших.
