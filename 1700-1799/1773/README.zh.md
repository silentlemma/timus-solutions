# 1773. 地铁通到每个家

[Timus 1773](https://acm.timus.ru/problem.aspx?space=1&num=1773) · 难度 852 · constructive

原题作者 Alexander Ipatov（由 Marina Mukhacheva 准备），出自 2010 年 4 月 10 日第十四届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 条宽度相同、高为 h 的墙纸上各画有一条直线段，从高度 l 的左边缘到高度 r 的右边缘。墙纸可以上下颠倒。把所有墙纸并排贴上，使这些线段连成横贯墙面的一条直线。

## 输入

h 和 n（1 ≤ h ≤ 100000，1 ≤ n ≤ 50000），然后是每条墙纸的 l 和 r（0 ≤ l, r ≤ h）。

## 输出

从左到右的墙纸编号，颠倒的墙纸前加负号；若无法做到则输出 0。任何符合要求的顺序都可以。

## 样例

### 样例 1

输入：

```
5 3
3 2
2 1
2 1
```

输出：

```
-3 1 2
```

### 样例 2

输入：

```
5 3
3 2
2 1
3 2
```

输出：

```
0
```

## 解法

颠倒后墙纸左端变为 h − r、右端变为 h − l，所以其升高 d = r − l 不变。所有墙纸的 d 必须相同，这时按顺序各墙纸的左端为 start、start + d、…、start + (n − 1)·d。
左端为 x 的墙纸可以放在 x 对应的位置，或颠倒后放在 h − d − x 对应的位置。

如果一条墙纸能放在两个位置 i 和 j，那么 x 和 h − d − x 都在直线上，所以对所有这样的墙纸 i + j 相同：位置两两配成 i 与 K − i，只有同一对的墙纸会互相竞争。
因此先让只有一个可选位置的墙纸各就其位，再让有两个位置的墙纸占用其中仍空着的那个；若有墙纸无处可放，这个 start 不可行。
start 本身只有两个候选：端点最极端的墙纸（d > 0 时最低，d < 0 时最高）要么用它开始直线，要么颠倒后用相反的极端结束直线。水平直线则在第一条墙纸的两个高度上检查。`O(n)`。

样例 1 中 d = −1。最极端的端点是 4，来自颠倒后的墙纸 2 或 3，所以直线从 4 开始：颠倒的墙纸 3 从 4 到 3，墙纸 1 从 3 到 2，墙纸 2 从 2 到 1。

注意事项：

- 颠倒不改变斜率，所以斜率不同就毫无希望；
- 两个左端相同的墙纸不能算两次；
- 顺序不唯一，所以检查器自己把墙纸拼起来。

在约 500 个最多 5 条墙纸的随机情形上，答案与枚举所有顺序和颠倒方式的结果一致；在 100 个最多 50000 条墙纸的情形上与一个独立的已通过实现一致，且双向检查。
