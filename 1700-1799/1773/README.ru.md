# 1773. Метро в каждый дом

[Timus 1773](https://acm.timus.ru/problem.aspx?space=1&num=1773) · сложность 852 · constructive

Автор оригинальной задачи — Александр Ипатов (подготовка — Марина Мухачёва); XIV чемпионат Урала по спортивному программированию, 10 апреля 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На n полосах обоев одинаковой ширины и высоты h нарисовано по прямому
отрезку от левого края, на высоте l, до правого, на высоте r. Полосу
можно перевернуть вверх ногами. Наклеить все полосы рядом так, чтобы
отрезки образовали одну прямую через всю стену.

## Входные данные

h и n (1 ≤ h ≤ 100000, 1 ≤ n ≤ 50000), затем l и r для каждой полосы
(0 ≤ l, r ≤ h).

## Выходные данные

Номера полос слева направо, с минусом перед перевёрнутой полосой, или
0, если ни один порядок не подходит. Подходит любой подходящий порядок.

## Примеры

### Пример 1

Ввод:

```
5 3
3 2
2 1
2 1
```

Вывод:

```
-3 1 2
```

### Пример 2

Ввод:

```
5 3
3 2
2 1
3 2
```

Вывод:

```
0
```

## Решение

Переворот меняет концы полосы на h − r слева и h − l справа, так что её
подъём d = r − l не меняется. У всех полос d должен совпадать, и тогда
левые концы полос по порядку — start, start + d, …, start + (n − 1)·d.
Полоса с левым концом x может встать на место x или, перевёрнутая, на
место h − d − x.

Если полоса может встать на два места i и j, то и x, и h − d − x лежат
на прямой, поэтому i + j одинаково для всех таких полос: места
разбиваются на пары i и K − i, и соревнуются только полосы одной пары.
Поэтому сначала полосы с единственным возможным местом встают каждая на
своё, а затем каждая полоса с двумя местами занимает свободное из них;
если какой-то полосе места нет, этот start не годится. Для самого start
есть два кандидата: полоса с самым крайним концом — наименьшим при d > 0
и наибольшим при d < 0 — либо начинает им прямую, либо, перевёрнутая,
заканчивает её противоположным крайним концом. Горизонтальная прямая
проверяется на двух высотах первой полосы. `O(n)`.

В первом примере d = −1. Крайний конец — 4, у полосы 2 или 3 после
переворота, поэтому прямая начинается на 4: перевёрнутая полоса 3
ведёт от 4 к 3, полоса 1 — от 3 к 2, полоса 2 — от 2 к 1.

Подводные камни:

- переворот не меняет наклон, так что при разных наклонах шансов нет;
- полосу, у которой оба левых конца совпадают, нельзя считать дважды;
- порядок не единственный, поэтому чекер сам склеивает полосы.

Ответы совпадают с перебором всех порядков и переворотов примерно на
500 случайных случаях до 5 полос и с независимой принятой реализацией,
проверенные в обе стороны, на 100 случаях до 50000 полос.
