# 1744. Рота Капитана

## Задача

Каждый день трое из n солдат заступают на ночное дежурство, и никакие
двое не должны дежурить вместе больше трёх раз. Составить график на как
можно большее число дней.

## Входные данные

Нечётное n (3 ≤ n ≤ 99).

## Выходные данные

Наибольшее число дней k и трое солдат каждого дня. Подходит любой
график на k дней.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
3
1 2 3
2 3 1
3 1 2
```

### Пример 2

Ввод:

```
5
```

Вывод:

```
10
1 2 3
1 2 4
1 2 5
1 3 4
1 3 5
1 4 5
2 3 4
2 3 5
2 4 5
3 4 5
```

## Решение

Каждый день сводит вместе три пары солдат, а каждая из n(n − 1)/2 пар
может дежурить вместе три раза, поэтому дней не больше n(n − 1)/2. Столько
и получается: пронумеруем солдат 0 … n − 1 и возьмём тройки i, i + d,
i + 2d по модулю n для всех i и всех d от 1 до (n − 1)/2.

Пара солдат, номера которых отличаются на δ, встречается дважды как
соседи в тройке — в тройках для d с δ = ±d, начинающихся с любого из
них, — и один раз как концы тройки — для d с δ = ±2d. Так как n
нечётно, каждому δ подходит ровно одно d первого вида и, поскольку на 2
можно делить по модулю n, ровно одно второго, так что каждая пара
встречается ровно три раза. Солдаты в тройке различны, потому что d и 2d
не кратны n. `O(n²)`.

При n = 3 получается первый пример: d = 1 и три поворота 1, 2, 3.

Подводные камни:

- одни и те же трое могут дежурить в несколько дней;
- порядок солдат внутри дня не важен.

Проверяющая программа проверяет число дней, номера солдат и число
встреч пар; график проверен для всех нечётных n от 3 до 99.
