# 1736. 中国冰球

[Timus 1736](https://acm.timus.ru/problem.aspx?space=1&num=1736) · 难度 1177 · greedy

原题作者 Alexander Ipatov（由 Igor Chevdar 准备），出自第十四届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 支冰球队进行单循环赛，每场比赛产生 3 分：常规时间获胜为 3 : 0，加时获胜为 2 : 1。
给定每支队伍的最终积分，判断这样的赛季是否存在；若存在，给出所有比赛的结果。

## 输入

n（2 ≤ n ≤ 200），然后是按非递增顺序排列的积分；它们之和为 3n(n − 1)/2，且每个都不超过 3(n − 1)。

## 输出

`INCORRECT`，或者 `CORRECT` 以及每场比赛 `i ? j`，其中 `?` 为 `<`、`<=`、`>=` 或 `>`，
分别表示队 i 常规时间输、加时输、加时赢或常规时间赢。任何符合要求的赛季都可以。

## 样例

### 样例 1

输入：

```
4
8 7 2 1
```

输出：

```
CORRECT
2 <= 1
3 >= 4
1 > 3
4 < 2
1 > 4
2 > 3
```

### 样例 2

输入：

```
4
8 8 1 1
```

输出：

```
INCORRECT
```

## 解法

每场比赛的 3 分可以按四种方式中的任意一种分配，所以只有总分重要。取剩余积分最少的队伍（剩 s 分），一次性定下它所有剩余比赛：
它的 m − 1 场比赛共 3(m − 1) 分，自己留 s 分，其余分出去——每场 3 分先给最强的队，剩下的零头给下一支。然后移除它并重复。
如果某一时刻最弱的队的积分多于它的比赛能给的、有人需要负分，或者最后还有队伍剩有积分，则表格不可能。

先满足最强的队能给弱队留出最多余地，而正是弱队可能在剩余比赛中得不到分；类似 Havel–Hakimi 方法证明中的交换论证表明这样做不会丢失可行赛季，
下面的检查也证实了这一点。每轮排序，总复杂度 `O(n² log n)`。

样例 1 中第 4 队留 1 分，分出 8 分：3 分给第 1 队，3 分给第 2 队，2 分给第 3 队。
然后第 3 队把 6 分分给第 1、2 队，第 2 队对第 1 队拿 1 分。

注意事项：

- 总和正确的表格仍可能不可能：样例 2 中两支最弱的队互相比赛，仅这一场就产生 3 分，多于他们的 2 分；
- 结果符号是从第一支队的角度表示的，所以 `i < j` 表示队 i 在常规时间输了。

表格可能当且仅当对每个 k，最弱的 k 支队伍至少有 3·C(k, 2) 分，因为它们之间的比赛就产生这么多分；这是分配积分的最大流条件。
在 260 个最多 200 队的随机表格（其中 154 个不可能）上，判断都与该条件一致，且检查程序重放了每个输出的赛季。
当 n 不超过 5 时，每个总和正确的表格都与列举所有赛季的结果做了比较。
