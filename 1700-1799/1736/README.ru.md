# 1736. Китайский хоккей

[Timus 1736](https://acm.timus.ru/problem.aspx?space=1&num=1736) · сложность 1177 · greedy

Автор оригинальной задачи — Александр Ипатов (подготовка — Игорь Чевдарь); XIV Открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В круговом турнире n хоккейных команд каждый матч даёт 3 очка: 3 : 0 за
победу в основное время и 2 : 1 за победу в овертайме. По итоговым
очкам всех команд определить, возможен ли такой сезон, и если да,
показать результаты всех матчей.

## Входные данные

n (2 ≤ n ≤ 200), затем очки в порядке невозрастания; их сумма равна
3n(n − 1)/2, и ни одно не больше 3(n − 1).

## Выходные данные

`INCORRECT` или `CORRECT` и все матчи в виде `i ? j`, где `?` — `<`,
`<=`, `>=` или `>`: поражение в основное время, поражение в овертайме,
победа в овертайме или победа в основное время команды i. Подходит
любой подходящий сезон.

## Примеры

### Пример 1

Ввод:

```
4
8 7 2 1
```

Вывод:

```
CORRECT
2 <= 1
3 >= 4
1 > 3
4 < 2
1 > 4
2 > 3
```

### Пример 2

Ввод:

```
4
8 8 1 1
```

Вывод:

```
INCORRECT
```

## Решение

Каждый матч делит 3 очка любым из четырёх способов, так что важны
только итоги. Возьмём команду, у которой осталось меньше всего очков,
s, и разыграем сразу все её оставшиеся матчи: из 3(m − 1) очков её
m − 1 матчей она оставляет себе s, а остальное раздаёт — по 3 очка за
матч сильнейшим командам, остаток следующей. Затем убираем её и
повторяем. Если у слабейшей команды больше очков, чем могут дать её
матчи, кому-то понадобились бы отрицательные очки или в конце у
команды остались очки, таблица невозможна.

Раздача сильнейшим в первую очередь оставляет больше всего места
слабым — именно их оставшиеся матчи могут оставить без очков; обменный
аргумент, как в доказательстве метода Хавела — Хакими для графов,
показывает, что так сезон никогда не теряется, и проверки ниже это
подтверждают. Сортировка на каждом шаге даёт `O(n² log n)`.

В первом примере команда 4 оставляет себе 1 очко и раздаёт 8: 3
команде 1, 3 команде 2 и 2 команде 3. Затем команда 3 отдаёт свои 6
командам 1 и 2, а команда 2 берёт 1 против команды 1.

Подводные камни:

- таблица с правильной суммой всё равно может быть невозможной: во
  втором примере две слабейшие команды играют друг с другом, и один
  этот матч даёт 3 очка, больше их 2;
- знаки результата — со стороны первой команды, так что `i < j`
  означает поражение команды i в основное время.

Таблица возможна ровно тогда, когда у k слабейших команд не меньше
3·C(k, 2) очков при каждом k, потому что столько дают их матчи между
собой; это условие максимального потока для раздела очков. Вердикты
совпадают с ним на 260 случайных таблицах до 200 команд, из которых 154
невозможны, а каждый выведенный сезон проверяющая программа проиграла
заново. При n до 5 каждая таблица с правильной суммой сравнена с
перечислением всех сезонов.
