## Задача

Посчитать шашечные позиции на доске n × n ровно с k фигурами. Фигура —
белая или чёрная шашка или дамка и стоит на чёрной клетке; должны быть
оба цвета, и никакая шашка не стоит на своём поле превращения (белые
шашки не на последней горизонтали, чёрные — не на первой). Вывести
количество по модулю 10⁹ + 7.

## Входные данные

n и k (4 ≤ n ≤ 1000, n чётно, 2 ≤ k ≤ n²/4).

## Выходные данные

Количество позиций по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
4 2
```

Вывод:

```
172
```

## Решение

Чёрных клеток n²/2: n/2 на первой горизонтали, n/2 на последней и
m = n²/2 − n между ними. На чёрную клетку первой или последней
горизонтали можно поставить три вида фигур, на любую другую — четыре,
поэтому позиций с k фигурами без учёта цветов

Σ C(n, a)·3^a·C(m, k − a)·4^(k − a)

по a — числу фигур на двух крайних горизонталях.

Из этого вычитаем одноцветные позиции, по симметрии дважды. Для белых
на клетку последней горизонтали можно поставить только дамку, а на
любую другую — шашку или дамку, что даёт

Σ C(n/2, a)·C(m + n/2, k − a)·2^(k − a).

Так как k ≥ 2, доска никогда не пуста. Биномиальные коэффициенты дают
факториалы до n²/2 и обратные к ним. `O(n²)` на факториалы,
`O(n log k)` на суммы.

При n = 4 и k = 2 первая сумма 96 + 192 + 54 = 342, вторая
60 + 24 + 1 = 85, так что ответ 342 − 2·85 = 172.

Подводные камни:

- обе крайние горизонтали теряют по одному виду фигур, а не только
  поле превращения противника;
- для одного цвета крайние горизонтали различаются: на своей первой
  годятся оба вида, на своей последней — только дамка;
- разность нужно вернуть в диапазон 0 … 10⁹ + 6.

Количества совпадают с перечислением всех позиций при всех k на досках
4 × 4 и при k до 4 на досках 6 × 6, а также с независимой принятой
реализацией на больших тестах.
