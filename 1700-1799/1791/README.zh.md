# 1791. 斯焦帕叔叔与公交车

[Timus 1791](https://acm.timus.ru/problem.aspx?space=1&num=1791) · 难度 1471 · greedy

原题作者 Eugene Kurpilyansky，出自 2010 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一段单车道路面由两个方向的公交车共用，每次只能通过一辆，每辆车通过恰好需要一分钟。第 i 辆车在第 tᵢ 分钟到达，
在这段路上（包括等待）最多可以花 pᵢ 分钟。同一方向的车必须按到达顺序通过。判断能否让所有车都准时。

## 输入

n（1 ≤ n ≤ 100000），然后是一个方向的 n 对 tᵢ pᵢ；接着是 m（1 ≤ m ≤ 100000）和另一个方向的 m 对。所有数在 1 到 10⁸ 之间，每个方向按到达顺序给出。

## 输出

若所有车都能准时输出 "YES"，否则输出 "NO"。

## 样例

### 样例 1

输入：

```
2
1 1
1 2
1
2 2
```

输出：

```
YES
```

### 样例 2

输入：

```
2
1 1
1 2
1
2 1
```

输出：

```
NO
```

## 解法

第 i 辆车必须在 tᵢ … tᵢ + pᵢ − 1 中的某一分钟进入，每分钟只能进入一辆。同一方向上一辆车要在下一辆之前进入，
所以它的最晚分钟不超过下一辆的最晚分钟减一；从后往前扫一遍即可相应地降低最晚分钟。然后按分钟推进：
在两个方向已到达的队首车中，放行最晚分钟更早的那辆；若都没到达，就跳到下一次到达。若某辆车在其最晚分钟之后才放行，答案为 NO。
放行最紧迫的等待车辆不会更差，因为把它与更晚的一辆交换后两辆都仍然准时。所有车都通过则答案为 YES。`O(n + m)`。

第一个样例中第一辆车在第 1 分钟进入，第二辆在第 2 分钟，另一方向的车在第 3 分钟，正是它能用的最后一分钟。
第二个样例中那辆车必须在第 2 分钟之前进入，第二辆车也是如此，而第 1 分钟已被第一辆车占用。

注意事项：

- 同一方向上，耐心的车后面跟着一辆着急的车，会让耐心的车也变得着急，从后往前的扫描处理了这一点；
- 时间可达 10⁸，所以时钟要跳过空闲时段，而不是逐分钟计数；
- 等待也计入 pᵢ，所以在 tᵢ 到达的车必须不晚于 tᵢ + pᵢ − 1 进入。

在 400 个小随机情形上，答案与枚举两队所有合并方式的结果一致；在大情形上（有余量的计划、某辆车差一分钟的满计划以及随机时间），与一个独立的已通过实现一致。
