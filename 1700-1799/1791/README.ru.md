# 1791. Дядя Стёпа и автобусы

[Timus 1791](https://acm.timus.ru/problem.aspx?space=1&num=1791) · сложность 1472 · greedy

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Однополосный участок дороги делят автобусы обоих направлений, по
одному за раз, и каждому нужна ровно одна минута на проезд. Автобус i
подъезжает в минуту tᵢ и может провести на участке не более pᵢ минут,
включая ожидание. Автобусы одного направления проезжают в порядке
прибытия. Определить, могут ли все автобусы успеть.

## Входные данные

n (1 ≤ n ≤ 100000), затем n пар tᵢ pᵢ для одного направления; затем m
(1 ≤ m ≤ 100000) и m пар для другого. Все числа от 1 до 10⁸, каждое
направление дано в порядке прибытия.

## Выходные данные

"YES", если все автобусы могут успеть, иначе "NO".

## Примеры

### Пример 1

Ввод:

```
2
1 1
1 2
1
2 2
```

Вывод:

```
YES
```

### Пример 2

Ввод:

```
2
1 1
1 2
1
2 1
```

Вывод:

```
NO
```

## Решение

Автобус i должен въехать в одну из минут tᵢ … tᵢ + pᵢ − 1, и за минуту
въезжает только один автобус. С одной стороны автобус въезжает раньше
следующего, поэтому его последняя минута не больше последней минуты
следующего минус один; один проход с конца соответственно уменьшает
последние минуты. Затем идём по минутам: из двух передних автобусов,
которые уже подъехали, пропускаем тот, у кого последняя минута раньше;
если не подъехал никто, прыгаем к следующему прибытию. Если автобус
пропущен позже своей последней минуты, ответ NO. Пропустить самый
срочный из ждущих никогда не хуже: перенос перед менее срочными
сохраняет порядок и сроки. Ответ YES, если проехали все. `O(n + m)`.

В первом примере первый автобус въезжает в минуту 1, второй — в 2, а
автобус с другой стороны — в 3, последнюю допустимую для него. Во
втором примере тот автобус должен въехать не позже минуты 2, но так же
и второй автобус, а минута 1 занята первым.

Подводные камни:

- срочный автобус позади терпеливого на той же стороне заставляет
  спешить и терпеливого, это учитывает проход с конца;
- времена доходят до 10⁸, поэтому часы должны перепрыгивать простои, а
  не считать каждую минуту;
- ожидание входит в pᵢ, так что автобус, подъехавший в tᵢ, должен
  въехать не позже tᵢ + pᵢ − 1.

Ответы совпадают с перебором всех слияний двух очередей на 400
маленьких случайных случаях и с независимой принятой реализацией на
больших: планы с запасом, плотные планы, где одному автобусу не хватает
минуты, и случайные времена.
