# 1758. К вопросу о лысине 2

[Timus 1758](https://acm.timus.ru/problem.aspx?space=1&num=1758) · сложность 2764 · backtracking

Автор оригинальной задачи — Екатерина Васильева; XI открытое личное первенство УрГУ, 13 марта 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Трактиры занумерованы от 1 до n. Обход начинается в трактире 1 и может
переходить из одного трактира в другой, только если номер одного
делится на номер другого, не заходя ни в один трактир дважды. Найти
обход через как можно больше трактиров.

## Входные данные

n (2 ≤ n ≤ 50).

## Выходные данные

Число трактиров в самом длинном обходе, затем трактиры в порядке
обхода. Подходит любой самый длинный обход.

## Примеры

### Пример 1

Ввод:

```
9
```

Вывод:

```
7
1 9 3 6 2 4 8
```

## Решение

Это самый длинный простой путь в графе делимости — в общем случае
трудная задача, но входов всего 49. Решения хранят таблицу самых
длинных обходов, найденных заранее полным перебором, и выводят запись
для наибольшего n' ≤ n, где длина растёт: обход для n' остаётся обходом
и для n, а между такими точками лучшая длина не меняется. В таблице 26
записей, ответ — `O(1)`.

Перебор продолжает обход из последнего трактира всеми способами и
отсекает ветку, когда даже в лучшем случае рекорд не побить. Лучший
случай — число свободных трактиров, достижимых из последнего через
свободные, минус все, кроме одного, из тех, у кого не больше одного
свободного соседа: посетить можно только один из них, и только
последним. Если начать с рекордом, равным известной длине, полный
перебор доказывает, что длиннее не бывает; на одно n уходит до
полуминуты, поэтому он сделан заранее, а не в пределах секунды.

При n = 9 обход 1 9 3 6 2 4 8 пропускает 5 и 7: каждый связан только с
трактиром 1, а он занят началом.

Подводные камни:

- простое p больше n / 2 связано только с 1, поэтому может быть только
  вторым трактиром, и на нём обход закончится;
- обход обязан начинаться в трактире 1, а закончиться может где угодно;
- жадный обход теряет лучшую длину уже при малых n.

Длины совпадают с независимой принятой реализацией для всех n от 2 до
50, а чекер проверяет сами обходы.
