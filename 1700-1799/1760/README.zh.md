# 1760. 地狱般的工作

[Timus 1760](https://acm.timus.ru/problem.aspx?space=1&num=1760) · 难度 681 · math

原题作者 Alexander Ipatov，出自 2010 年 3 月 13 日第十一届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 条记录按相同顺序抄在两个本子上，第一个本子每页 a 条，第二个每页 b 条。求在第一个本子中同页、在第二个本子中不同页的记录对数。

## 输入

a、b 和 n（1 ≤ a, b ≤ n ≤ 25 000 000）。

## 输出

这样的对数。

## 样例

### 样例 1

输入：

```
3 4 10
```

输出：

```
4
```

### 样例 2

输入：

```
2 4 10
```

输出：

```
0
```

## 解法

答案等于在第一个本子中同页的对数——n div a 个整页各 C(a, 2) 对，加上 C(n mod a, 2)——减去在两个本子中都同页的对数。
两个本子的分页处把这一行切成若干段，两个本子中都同页的对数就是各段 C(len, 2) 之和。

这个和按页较大的本子逐页计算：每个大页被小页切成开头、若干完整小页和结尾，每个大页 O(1)。两个本子的分页每 L = lcm(a, b) 条重复一次，
所以当 L ≤ n 时，把一个周期的和乘以 n div L 再加上剩余部分。无论哪种情况，遍历的大页至多约 √n 个：
L ≤ n 时每个周期有 L / max(a, b) = min(a, b) / gcd(a, b) 个，不超过 √L；L > n 时 max(a, b) > √n。所以复杂度为 `O(√n)`。

样例 1 中每页 3 条各有 3 对，共 9 对；分页处 3、4、6、8、9 把这一行切成长度为 3、1、2、2、1、1 的段，共 5 对：9 − 5 = 4。

注意事项：

- 答案可达约 3·10¹⁴，超过 32 位；
- 在某些语言中逐条遍历 n 条记录太慢，小页很小时逐个遍历小页也太慢；
- lcm(a, b) 可达 6·10¹⁴，所以用 64 位按 a / gcd · b 计算。

在 300 个小情形上答案与逐对计数一致，在 60 个较大情形上与线性计数一致，在 100 个直到上限的情形上与一个独立的已通过实现一致。
