# 1746. Гиперладья

[Timus 1746](https://acm.timus.ru/problem.aspx?space=1&num=1746) · сложность 1644 · matrix

Автор оригинальной задачи — Пётр Лежанкин; контест УГАТУ, Петрозаводские летние сборы, август 2009 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Клетки n-мерной решётки имеют целые координаты от 0 до m − 1.
Гиперладья ходит из клетки в любую клетку, отличающуюся ровно в одной
координате. Для q данных клеток посчитать маршруты ровно из d ходов
между каждыми двумя из них по модулю p.

## Входные данные

n, m, d, p и q (1 ≤ n ≤ 50, 2 ≤ m ≤ 10⁵, 0 ≤ d ≤ 10⁹,
1 ≤ p ≤ 10⁹, 2 ≤ q ≤ 50), затем q клеток.

## Выходные данные

Таблица q × q: число маршрутов из клетки i в клетку j по модулю p.

## Примеры

### Пример 1

Ввод:

```
2 8 4 10000000 4
3 5
0 5
3 7
0 0
```

Вывод:

```
896 720 720 560
720 896 560 720
720 560 896 560
560 720 560 896
```

### Пример 2

Ввод:

```
3 3 4 10000000 3
0 2 2
1 1 1
1 2 2
```

Вывод:

```
90 36 45
36 90 54
45 54 90
```

## Решение

Зафиксируем целевую клетку. О текущей клетке важно лишь h — число
координат, в которых она отличается от цели. Ход из h либо исправляет
одну из этих h координат (h способов, в h − 1), либо меняет её на
другое неверное значение (h(m − 2) способов, h не меняется), либо
портит одну из n − h верных ((n − h)(m − 1) способов, в h + 1). Эти
числа образуют матрицу (n + 1) × (n + 1), и её d-я степень, найденная
повторным возведением в квадрат по модулю p, даёт в строке h, столбце 0
число маршрутов из клетки на расстоянии h до цели. Для каждого ответа
нужно лишь число координат, в которых две клетки различаются.
`O(n³ log d + q²n)`.

В первом примере клетки 1 и 2 различаются в одной координате и
получают 720 маршрутов, клетки 1 и 4 — в двух и получают 560.

Подводные камни:

- p не обязательно простое, поэтому степень матрицы надо считать
  напрямую, без деления;
- при p = 1 всё равно 0, включая маршруты длины 0;
- произведения доходят до 10¹⁸ до взятия остатка, нужна 64-битная
  арифметика.

Таблицы совпадают с пошаговым подсчётом по всей решётке на 150
маленьких случайных наборах и с независимой принятой реализацией на
больших тестах.
