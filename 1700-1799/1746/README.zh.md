# 1746. 超级车

[Timus 1746](https://acm.timus.ru/problem.aspx?space=1&num=1746) · 难度 1630 · matrix

原题作者 Petr Lezhankin，出自 2009 年 8 月彼得罗扎沃茨克夏季集训的乌法国立航空技术大学专场。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 维网格的格点坐标为 0 到 m − 1 的整数。超级车可以从一个格点走到恰好有一个坐标不同的任意格点。
对给定的 q 个格点，求每两点之间恰好走 d 步的路线数，对 p 取模。

## 输入

n、m、d、p 和 q（1 ≤ n ≤ 50，2 ≤ m ≤ 10⁵，0 ≤ d ≤ 10⁹，1 ≤ p ≤ 10⁹，2 ≤ q ≤ 50），然后是 q 个格点。

## 输出

一个 q × q 的表：从格点 i 到格点 j 的路线数对 p 取模。

## 样例

### 样例 1

输入：

```
2 8 4 10000000 4
3 5
0 5
3 7
0 0
```

输出：

```
896 720 720 560
720 896 560 720
720 560 896 560
560 720 560 896
```

### 样例 2

输入：

```
3 3 4 10000000 3
0 2 2
1 1 1
1 2 2
```

输出：

```
90 36 45
36 90 54
45 54 90
```

## 解法

固定目标格点。关于当前格点，只需知道它与目标不同的坐标个数 h。从 h 出发的一步要么把这 h 个坐标之一改对（h 种，到 h − 1），
要么把其中之一改成另一个错误值（h(m − 2) 种，h 不变），要么破坏 n − h 个正确坐标之一（(n − h)(m − 1) 种，到 h + 1）。
这些数构成一个 (n + 1) × (n + 1) 矩阵，用反复平方对 p 取模求它的 d 次幂，第 h 行第 0 列就是从距离为 h 的格点到目标的路线数。
每个答案只需知道两个格点不同的坐标个数。`O(n³ log d + q²n)`。

样例 1 中格点 1 和 2 有一个坐标不同，得 720 条路线；格点 1 和 4 有两个不同，得 560 条。

注意事项：

- p 不一定是质数，所以矩阵幂必须直接计算，不能做除法；
- p = 1 时一切都为 0，包括长度为 0 的路线；
- 取余前乘积可达 10¹⁸，需要 64 位运算。

在 150 个小型随机数据上，表格与对整个网格逐步计数的结果一致；在大测试上与一个独立的已通过实现一致。
