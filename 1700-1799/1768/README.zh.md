# 1768. 环形弦

[Timus 1768](https://acm.timus.ru/problem.aspx?space=1&num=1768) · 难度 1171 · geometry

原题作者 Dmitry Ivankov，出自 2010 年 4 月 10 日第十四届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 n 个点，判断它们是否是一个非退化正 n 边形按环绕顺序列出的顶点。

## 输入

n（3 ≤ n ≤ 100），然后是 n 个点，实数坐标在 0 到 1 之间，精度至少 10⁻¹⁰。点可以重合，但有两个点的距离不小于 0.3。
当答案为否时，任何小于 10⁻⁵ 的点的改动都不能使答案变为是。

## 输出

`YES` 或 `NO`。

## 样例

### 样例 1

输入：

```
4
0 0
1 0
1 1
0 1
```

输出：

```
YES
```

### 样例 2

输入：

```
3
0 0
1 0
0.5 1
```

输出：

```
NO
```

## 解法

正多边形的中心是其顶点的平均值，按顺序列出时，每个顶点都是前一个绕中心旋转 2π/n（朝某一方向）得到的。
所以把点看作相对于其平均值的复数 zᵢ，当对所有 i（循环地）都有 zᵢ₊₁ = ω·zᵢ，其中 ω = e^(±2πi/n)，且 z₀ 不是中心本身时，答案为是。`O(n)`。

这些等式用 10⁻⁸ 的容差检验。精度为 10⁻¹⁰ 的点至多偏差几个 10⁻¹⁰。如果每次旋转的偏差都不超过 ε，
这些点就在由 z₀ 构造的正多边形的 n·ε 范围内，所以需要改动 10⁻⁵ 的点集必然在某处偏差超过 10⁻⁵/n = 10⁻⁷。

样例 1 中平均值为 (0.5, 0.5)，旋转四分之一圈把正方形的每个角变到下一个。样例 2 中三个点到它们平均值的距离不相等。

注意事项：

- 顺序可以是任一方向；
- 正确的点按其他顺序（例如星形）不行；
- 较小的多边形绕两圈会重复点，不符合要求。

在 160 个随机情形上（按顺序的正多边形、一个顶点移动至少 0.001 的、星形顺序的以及绕了不止一圈的），答案与一个独立的已通过实现一致。
