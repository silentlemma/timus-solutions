# 1768. Кольцевые струны

[Timus 1768](https://acm.timus.ru/problem.aspx?space=1&num=1768) · сложность 1156 · geometry

Автор оригинальной задачи — Дмитрий Иванков; XIV чемпионат Урала по спортивному программированию, 10 апреля 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны n точек. Определить, являются ли они вершинами невырожденного
правильного n-угольника, перечисленными в порядке обхода.

## Входные данные

n (3 ≤ n ≤ 100), затем n точек с вещественными координатами от 0 до 1,
заданными с точностью не хуже 10⁻¹⁰. Точки могут совпадать, но
какие-то две точки находятся на расстоянии не меньше 0.3. Если ответ
отрицательный, никакое изменение точек меньше чем на 10⁻⁵ не делает его
положительным.

## Выходные данные

`YES` или `NO`.

## Примеры

### Пример 1

Ввод:

```
4
0 0
1 0
1 1
0 1
```

Вывод:

```
YES
```

### Пример 2

Ввод:

```
3
0 0
1 0
0.5 1
```

Вывод:

```
NO
```

## Решение

Центр правильного многоугольника — среднее его вершин, и при
перечислении по порядку каждая вершина — это предыдущая, повёрнутая
вокруг центра на 2π/n в ту или другую сторону. Поэтому, если считать
точки комплексными числами zᵢ относительно их среднего, ответ
положительный, когда zᵢ₊₁ = ω·zᵢ для всех i по кругу при
ω = e^(±2πi/n), а z₀ не совпадает с самим центром. `O(n)`.

Равенства проверяются с допуском 10⁻⁸. Точки, заданные с точностью
10⁻¹⁰, промахиваются не больше чем на несколько 10⁻¹⁰. Если бы каждый
поворот промахивался не больше чем на ε, точки лежали бы в пределах n·ε
от правильного многоугольника, построенного по z₀, так что набор,
требующий изменения на 10⁻⁵, где-то промахивается больше чем на
10⁻⁵/n ≥ 10⁻⁷.

В первом примере среднее — (0.5, 0.5), и поворот на четверть оборота
переводит каждый угол квадрата в следующий. Во втором три точки не
равноудалены от своего среднего.

Подводные камни:

- обход может идти в любую сторону;
- нужные точки в другом порядке, например звездой, не подходят;
- меньший многоугольник, обойдённый дважды, повторяет точки и не
  подходит.

Ответы совпадают с независимой принятой реализацией на 160 случайных
случаях: правильные многоугольники по порядку, с одной вершиной,
сдвинутой хотя бы на 0.001, в порядке звезды и обойдённые больше одного
раза.
