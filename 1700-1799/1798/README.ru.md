# 1798. Огненный круг. Версия 2

## Задача

Пол вымощен плитами 1 × 1, а огненный круг радиуса R имеет центр в
общем углу четырёх плит. Плита повреждена, если у неё не меньше двух
общих точек с огненным кругом. Посчитать повреждённые плиты.

## Входные данные

R — целое число от 1 до 10⁹.

## Выходные данные

Число повреждённых плит.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
16
```

### Пример 2

Ввод:

```
4
```

Вывод:

```
60
```

## Решение

Как видно из примеров, огонь занимает весь круг. В первой четверти
плита [x, x + 1] × [y, y + 1] имеет с кругом больше одной общей точки
ровно тогда, когда её ближний угол строго внутри: x² + y² ≤ R² − 1 = n.
Значит, ответ — это 4, умноженное на число точек решётки с x, y ≥ 0 в
круге x² + y² ≤ n.

По симметрии относительно диагонали достаточно сложить
g(x) = ⌊√(n − x²)⌋ по столбцам x = 0 … m, где m = ⌊√(n/2)⌋: там
окружность не круче 45°. Это около 0,7·10⁹ столбцов — слишком много,
чтобы обойти. Вместо этого идём от столбца m влево по верхней выпуклой
оболочке точек решётки в круге. Вдоль ребра оболочки (a, b) — a
столбцов влево и b строк вверх, gcd(a, b) = 1 — каждый столбец равен
полу прямой ребра, поэтому a столбцов сразу дают
a·y + (a − 1)(b − 1)/2 + b. Следующее ребро ищется поиском по дереву
Штерна — Броко между последним направлением, вышедшим из круга, и
направлением, оставшимся внутри. Поиск останавливается, когда от
внешней точки-медианты шаги вдоль внутреннего направления поднимаются
не медленнее окружности: тогда между двумя направлениями не может быть
точки внутри. У оболочки около R^(2/3) вершин, так что для R = 10⁹
обход занимает около миллиона шагов. Затем первая четверть содержит
2·(Σ g(x) − m(m + 1)/2) + m + 1 точек: часть над диагональю дважды и
диагональ один раз. `O(R^(2/3))`.

Во втором примере n = 15 и m = 2; столбцы 0, 1, 2 имеют высоты 3, 3,
3, поэтому в четверти 2·(9 − 3) + 3 = 15 точек, а ответ 60.

Подводные камни:

- плита, касающаяся окружности одним углом, не повреждена, отсюда
  строгое неравенство и n = R² − 1;
- ответ около π·10¹⁸, близко к пределу знаковых 64-битных чисел;
- проверка наклона умножает числа около 10¹⁸ на квадраты длин рёбер,
  для этого нужны 128 бит: __int128, i128, bits.Mul64, а в Java —
  double с точной проверкой через BigInteger, когда стороны близки.

Для каждого радиуса до 4000 сумма по столбцам совпадает с прямой
суммой, а версия на Go совпадает с независимой принятой реализацией на
всех радиусах до 600 и на больших до 10⁹, в том числе на кратных
гипотенуз пифагоровых троек. Решение на Python работает под PyPy.
