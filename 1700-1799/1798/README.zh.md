# 1798. 火环（第二版）

[Timus 1798](https://acm.timus.ru/problem.aspx?space=1&num=1798) · 难度 2107 · geometry

原题作者 Alexander Ipatov；第 1490 题半径更大的版本。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

地面铺着 1 × 1 的石板，半径为 R 的火环以四块石板的公共角为圆心。若一块石板与火环至少有两个公共点，它就被损坏。统计被损坏的石板数。

## 输入

R，1 到 10⁹ 之间的整数。

## 输出

被损坏的石板数。

## 样例

### 样例 1

输入：

```
2
```

输出：

```
16
```

### 样例 2

输入：

```
4
```

输出：

```
60
```

## 解法

由样例可见，火覆盖整个圆盘。在第一象限中，石板 [x, x + 1] × [y, y + 1] 与圆盘有不止一个公共点，当且仅当它最近的角严格在圆内：
x² + y² ≤ R² − 1 = n。所以答案是圆盘 x² + y² ≤ n 中满足 x, y ≥ 0 的格点数的 4 倍。

利用关于对角线的对称性，只需对列 x = 0 … m 求 g(x) = ⌊√(n − x²)⌋ 之和，其中 m = ⌊√(n/2)⌋，在这一段圆的倾斜不超过 45°。
这大约有 0.7·10⁹ 列，逐列访问太多。改为从第 m 列向左沿着圆内格点的上凸包行走。沿凸包的边 (a, b)（向左 a 列、向上 b 行，gcd(a, b) = 1），
每一列都等于边所在直线的下取整，所以这 a 列一次加上 a·y + (a − 1)(b − 1)/2 + b。下一条边通过在 Stern–Brocot 树上搜索得到，
搜索范围在最后一个走出圆的方向和一个仍在圆内的方向之间。当从圆外的中间点沿圆内方向前进时上升得不比圆慢，
两个方向之间就不可能有圆内的点，此时停止搜索。凸包约有 R^(2/3) 个顶点，所以 R = 10⁹ 时大约走一百万步。
最后第一象限的点数为 2·(Σ g(x) − m(m + 1)/2) + m + 1：对角线上方的部分算两次，对角线算一次。`O(R^(2/3))`。

第二个样例中 n = 15，m = 2；第 0、1、2 列的高度都是 3，所以四分之一中有 2·(9 − 3) + 3 = 15 个点，答案为 60。

注意事项：

- 只在一个角上与圆相切的石板不算损坏，因此用严格不等式和 n = R² − 1；
- 答案约为 π·10¹⁸，接近有符号 64 位整数的上限；
- 斜率判断要把约 10¹⁸ 的数乘以边长的平方，需要 128 位：__int128、i128、bits.Mul64，Java 中则用 double，两边接近时再用 BigInteger 精确判断。

对于不超过 4000 的每个半径，列和都与直接求和一致；Go 版本在不超过 600 的所有半径以及最大到 10⁹ 的大半径（包括勾股数斜边的倍数）上，与一个独立的已通过实现一致。Python 解答在 PyPy 下运行。
