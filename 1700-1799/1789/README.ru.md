# 1789. В поисках Додекаэдра

[Timus 1789](https://acm.timus.ru/problem.aspx?space=1&num=1789) · сложность 220 · constructive

Автор оригинальной задачи — Михаил Рубинчик; Уральская региональная командная олимпиада по программированию 2010.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Артефакт стоит на одном из n постаментов в ряд, на остальных —
копии. Каждый ход касаются одного постамента. Если артефакт там, он
найден; если нет, артефакт переходит на соседний постамент, левый или
правый, на свой выбор. Вывести не более 1000 касаний, которые найдут
артефакт, где бы он ни стоял сначала и как бы ни двигался.

## Входные данные

n (2 ≤ n ≤ 100).

## Выходные данные

Число касаний, затем номера постаментов по порядку.

## Проверка

Проверяется последовательность не более чем из 1000 касаний с номерами 1..N; после каждого неуспешного касания распространяются все возможные положения предмета, и в итоге ни одно не должно сохраниться. Допустима любая последовательность с этой гарантией. Новый точный исходник Python прошёл 13 тестов репозитория на PyPy 3.10. Также 99 сравнений потоковой конструкции со списками для всех N=2..100. Остальные сохранённые варианты имеют собственные проверки целевой среды и точные Accepted. Вывод сравнивается по правилам проверяющего модуля задачи.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
2
2 2
```

## Решение

После каждого неудачного касания артефакт сдвигается, поэтому чётность его
постамента меняется каждый ход. Касаемся 2, 3, …, n − 1. Если при
первом касании артефакт стоит на чётном постаменте, то на каждом ходу
он имеет ту же чётность, что и тронутый, и стоит не левее, поэтому
перепрыгнуть его не может и будет пойман не позже чем на n − 1. Иначе
после этих n − 2 касаний его чётность совпадает с чётностью n − 1, и
касания n − 1, n − 2, …, 2 так же выметают его справа. При n > 2
постаменты 1 и n не трогаем: артефакт оттуда обязан шагнуть внутрь.
Всего 2(n − 2) касаний. При n = 2 середины нет вовсе, и подходит
двойное касание постамента 1. `O(n)`.

В примере оба прохода — одно касание постамента 2: артефакт на 2
пойман сразу, а с 1 или 3 он обязан перейти на 2.

Подводные камни:

- один проход слева пропускает артефакт с другой чётностью — он просто
  проскальзывает мимо;
- при n > 2 касаться крайних постаментов бесполезно: артефакт не
  может на них остаться;
- n = 2 требует отдельного ответа, формула даёт ноль касаний.

Чекер следит за множеством постаментов, где артефакт ещё может быть, и
требует, чтобы оно опустело. Проходят все n от 2 до 100, а полный
перебор таких множеств при n до 12 подтверждает, что более короткой
последовательности нет.

## Оптимизированные решения

Сохраняются конструкция, ловящая обе чётности, и её доказательство. При N>2 выполняются проходы 2..N-1 и N-1..2, число касаний 2*(N-2). При N=2 выводятся два касания 1,1. Компактные реализации записывают последовательность потоком, не сохраняя объединённые списки и не раскрывая список аргументов вывода. Последовательность и гарантия поиска те же; время вывода O(N), рабочее состояние потока ограничено. Все простые файлы остаются.
