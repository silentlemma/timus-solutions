# 1789. 寻找十二面体

[Timus 1789](https://acm.timus.ru/problem.aspx?space=1&num=1789) · 难度 220 · constructive

原题作者 Mikhail Rubinchik，出自 2010 年乌拉尔地区程序设计团体赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一排 n 个底座中，有一个上面放着神器，其余放着复制品。每轮触摸一个底座。若神器在那里就找到了；否则神器会移到相邻的底座，向左或向右由它决定。
输出一个不超过 1000 次触摸的序列，无论神器从哪里出发、如何移动都能找到它。

## 输入

n（2 ≤ n ≤ 100）。

## 输出

触摸次数，然后按顺序输出所触摸的底座编号。

## 评测方式

验证至多1000次触碰，编号均在1..N；每次未成功触碰后传播所有可能位置，最终不得有存活位置。满足保证的任意序列均可。 新Python精确源码在PyPy 3.10通过13个仓库测试。 另有 99 N=2..100流式与列表构造比较. 其他保留原生版本各有保存的目标环境检查与精确Accepted。输出按本题检查器规则比较。

## 样例

### 样例 1

输入：

```
3
```

输出：

```
2
2 2
```

## 解法

每次未找到神器的触摸后，神器都会移动，所以它所在底座编号的奇偶性每轮都会改变。依次触摸 2、3、…、n − 1。若第一次触摸时神器在偶数号底座上，
那么每一轮它都与被触摸的底座奇偶性相同且不在其左侧，因此无法越过，最迟在 n − 1 处被抓到。否则，这 n − 2 次触摸之后它的奇偶性与 n − 1 相同，
于是触摸 n − 1、n − 2、…、2 会从右边以同样方式把它扫到。n > 2 时底座 1 和 n 从不触摸：神器在那里必须向内走。
共 2(n − 2) 次触摸。n = 2 时没有中间部分，触摸底座 1 两次即可。`O(n)`。

样例中两趟都只是触摸一次底座 2：在 2 上的神器立即被抓到，在 1 或 3 上的必须移到 2。

注意事项：

- 只从左边扫一遍会漏掉另一种奇偶性的神器，它会直接溜过去；
- n > 2 时触摸两端的底座是浪费，神器不能停留在那里；
- n = 2 需要单独处理，因为公式给出零次触摸。

检查器跟踪神器可能所在的底座集合，并要求它最终变空。2 到 100 的每个 n 都能通过，对 n 不超过 12 的这些集合做完全搜索，确认不存在更短的序列。

## 优化解法

保留捕获两种奇偶性的构造及证明。N>2时依次扫描2..N-1、N-1..2，共2*(N-2)次；N=2则输出1,1两次。紧凑版流式输出，不保留拼接列表或展开输出参数列表。序列和最坏情况保证不变，输出仍为O(N)时间，流式工作状态有界，所有教学源码保留。
