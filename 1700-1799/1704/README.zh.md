# 1704. 解调

[Timus 1704](https://acm.timus.ru/problem.aspx?space=1&num=1704) · 难度 3193 · math

原题作者 Pavel Atnashev，出自 2009 年 4 月 4 日第十三届乌拉尔竞技编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一段文本按位发送：每个字符 8 位，从最低位开始，每位 t 个采样。某一位的第 k 个采样等于未知的基准电平，
加上未知振幅乘以 sin(2πk/t)（位为 1）或 sin(4πk/t)（位为 0），再加上噪声。根据 n 个采样还原文本。

## 输入

n 和 t（0 < n ≤ 10000，5 ≤ t ≤ 1000，n 是 8t 的倍数），然后是 n 个 0 到 1 之间、至多五位小数的采样，分布在一行或多行。

## 输出

文本，由拉丁字母、数字、标点和空格组成，解码结果唯一。

## 样例

### 样例 1

输入：

```
40 5
0.3 0.8 0.6 0.4 0.2
0.5 0.6 0.3 0.9 0.4
0.4 0.8 0.3 0.8 0.2
0.3 0.6 0.1 0.7 0.2
0.7 0.7 0.1 0.7 0.1
0.5 0.8 0.7 0.3 0.2
0.4 0.8 0.2 0.8 0.2
0.5 0.8 0.3 0.8 0.2
```

输出：

```
!
```

## 解法

在整数个周期上，sin(2πk/t) 与 sin(4πk/t) 的和都为零且两者正交：t ≥ 5 时它们的乘积对 k = 0 … t − 1 求和为 0。
所以对一位的 t 个采样分别与两个波形求相关，即求采样 × 波形之和。常数电平对两个和都没有贡献；
发送的波形给自己的和贡献振幅乘以 t/2，对另一个和没有贡献，噪声只是让它变模糊。
取和较大的波形作为该位，再从最低位开始拼出字符。`O(n)`。

注意事项：

- 电平和振幅都未知，但无需估计：电平会被抵消，振幅只起缩放作用；
- 字符内的位从最低位开始：样例的采样拼出 10000100，即 33，是 ! 的编码；
- 采样可以任意分布在各行中（测试 05）。

在用随机电平、振幅和噪声运行题面编码器得到的数据上，答案与一个独立的已通过实现一致。
