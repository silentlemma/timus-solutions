# 1704. Демодуляция

## Задача

Текст передан побитно, по восемь бит на символ начиная с младшего и по
t отсчётов на бит. Отсчёт k бита — неизвестный уровень плюс неизвестная
амплитуда, умноженная на sin(2πk/t) для единицы или sin(4πk/t) для
нуля, плюс шум. По n отсчётам восстановить текст.

## Входные данные

n и t (0 < n ≤ 10000, 5 ≤ t ≤ 1000, n кратно 8t), затем n отсчётов от
0 до 1 не более чем с пятью знаками после точки, в одной или нескольких
строках.

## Выходные данные

Текст из латинских букв, цифр, знаков препинания и пробелов. Он
раскодируется однозначно.

## Примеры

### Пример 1

Ввод:

```
40 5
0.3 0.8 0.6 0.4 0.2
0.5 0.6 0.3 0.9 0.4
0.4 0.8 0.3 0.8 0.2
0.3 0.6 0.1 0.7 0.2
0.7 0.7 0.1 0.7 0.1
0.5 0.8 0.7 0.3 0.2
0.4 0.8 0.2 0.8 0.2
0.5 0.8 0.3 0.8 0.2
```

Вывод:

```
!
```

## Решение

На целом числе периодов sin(2πk/t) и sin(4πk/t) дают в сумме ноль и
ортогональны: сумма их произведений по k = 0 … t − 1 равна 0 при t ≥ 5.
Поэтому для t отсчётов одного бита считаем корреляцию с обеими волнами,
то есть суммы произведений отсчёт × волна. Постоянный уровень ничего
не добавляет ни к одной сумме. Переданная волна добавляет к своей сумме
амплитуду, умноженную на t/2, а к другой ничего, и шум лишь размывает
это. Бит — та волна, чья сумма больше, а символы собираются начиная с
младшего бита. `O(n)`.

Подводные камни:

- уровень и амплитуда неизвестны, но оценивать их не нужно: уровень
  сокращается, а амплитуда лишь масштабирует;
- биты в символе идут от младшего: отсчёты примера дают 10000100, то
  есть 33 — код !;
- отсчёты могут быть разбиты по строкам как угодно (тест 05).

Ответы совпадают с независимой принятой реализацией на выходе
кодировщика из условия со случайными уровнями, амплитудами и шумом.
