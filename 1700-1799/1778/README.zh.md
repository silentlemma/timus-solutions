# 1778. 中国冰球 2

[Timus 1778](https://acm.timus.ru/problem.aspx?space=1&num=1778) · 难度 4088 · greedy

原题作者 Alex Samsonov，出自第十五届乌拉尔国立大学公开团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

编号 1 到 n 的 n 名球迷乘坐编号 1 到 m 的 m 辆大巴，每辆载 a 到 b 人，编号大的大巴载编号大的球迷。有些球迷说出了自己的大巴编号。
求球迷 r 可能乘坐的所有大巴，或报告这些回答互相矛盾。

## 输入

n、m、a 和 b（2 ≤ m ≤ n ≤ 10⁵，1 ≤ a ≤ b ≤ n，m·a ≤ n ≤ m·b），然后是 r，然后是 s（1 ≤ s ≤ n − 1）和 s 对：球迷 rᵢ ≠ r 与大巴 fᵢ。

## 输出

`IMPOSSIBLE`，或者可能的大巴数以及按升序排列的大巴编号。

## 样例

### 样例 1

输入：

```
16 4 1 16
3
2
2 2
4 3
```

输出：

```
2
2 3
```

## 解法

第 i 辆大巴载边界 P(i − 1) 之后到边界 P(i) 的球迷，其中 P(0) = 0、P(m) = n 且 a ≤ P(i) − P(i − 1) ≤ b。球迷 x 在大巴 f 中意味着 P(f) ≥ x 且 P(f − 1) ≤ x − 1，
所以每个边界一开始有自己的区间。从左到右，每个边界还必须位于前一个边界区间之后 a 到 b 处；从右到左，位于后一个边界区间之前 a 到 b 处；
这样一串约束使每个可能值的集合始终是区间。两遍之后，每个区间恰好包含该边界在某种完整安排中能取的值，空区间则表示回答互相矛盾。

球迷 r 在大巴 k 中，当且仅当某种安排中 P(k − 1) ≤ r − 1 且 P(k) ≥ r。把两个区间按 r 截断，再检查其中是否有一对值相距 a 到 b
（两个区间的差也构成区间），就能立即回答每辆大巴。`O(n + m)`。

样例中球迷 2 在大巴 2、球迷 4 在大巴 3，给出 P(1) ≤ 1、P(2) = 2 或 3、P(3) ≥ 4。P(2) = 3 时球迷 3 在大巴 2，P(2) = 2 时在大巴 3。

注意事项：

- 两遍都必须做：只从左边走会漏掉来自另一端的限制；
- 球迷 1 总在大巴 1，球迷 n 总在大巴 m；
- 只含一个值的边界区间（如 a = b 时）会确定整个安排。

在 500 个最多 5 辆大巴的随机情形上，答案与枚举所有安排的结果一致；在 80 个最多 10⁵ 名球迷的情形上与一个独立的已通过实现一致。
