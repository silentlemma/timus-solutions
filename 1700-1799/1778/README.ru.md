# 1778. Китайский хоккей 2

[Timus 1778](https://acm.timus.ru/problem.aspx?space=1&num=1778) · сложность 3901 · greedy

Автор оригинальной задачи — Алексей Самсонов; XV Открытый командный чемпионат УрГУ по программированию.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n болельщиков с номерами от 1 до n едут в m автобусах с номерами от 1
до m, в каждом от a до b человек, и в автобусе с бо́льшим номером едут
болельщики с бо́льшими номерами. Некоторые болельщики сообщили номер
своего автобуса. Найти все автобусы, в которых может ехать болельщик r,
или сообщить, что ответы противоречат друг другу.

## Входные данные

n, m, a и b (2 ≤ m ≤ n ≤ 10⁵, 1 ≤ a ≤ b ≤ n, m·a ≤ n ≤ m·b), затем r,
затем s (1 ≤ s ≤ n − 1) и s пар: болельщик rᵢ ≠ r и автобус fᵢ.

## Выходные данные

`IMPOSSIBLE` либо число возможных автобусов и сами автобусы по
возрастанию.

## Примеры

### Пример 1

Ввод:

```
16 4 1 16
3
2
2 2
4 3
```

Вывод:

```
2
2 3
```

## Решение

Автобус i везёт болельщиков после границы P(i − 1) до границы P(i), где
P(0) = 0, P(m) = n и a ≤ P(i) − P(i − 1) ≤ b. Болельщик x в автобусе f
означает P(f) ≥ x и P(f − 1) ≤ x − 1, так что у каждой границы есть свой
начальный отрезок. Проходя слева направо, каждая граница должна ещё
лежать на a—b дальше отрезка предыдущей, а справа налево — на a—b
раньше отрезка следующей; цепочка таких ограничений оставляет каждое
множество возможных значений отрезком. После обоих проходов каждый
отрезок содержит ровно те значения, которые эта граница принимает в
какой-нибудь полной рассадке, а пустой отрезок значит, что ответы
противоречат друг другу.

Болельщик r едет в автобусе k, когда в какой-то рассадке P(k − 1) ≤ r − 1
и P(k) ≥ r. Обрезав два отрезка по r и проверив, что какая-то пара
значений в них отстоит на a—b — разности двух отрезков тоже образуют
отрезок, — сразу отвечаем для каждого автобуса. `O(n + m)`.

В примере болельщик 2 в автобусе 2 и болельщик 4 в автобусе 3 дают
P(1) ≤ 1, P(2) = 2 или 3, P(3) ≥ 4. Болельщик 3 едет в автобусе 2 при
P(2) = 3 и в автобусе 3 при P(2) = 2.

Подводные камни:

- нужны оба прохода: один проход слева пропускает ограничения с
  дальнего конца;
- болельщик 1 всегда в автобусе 1, а болельщик n — в автобусе m;
- один вариант каждой границы, как при a = b, фиксирует всю
  рассадку.

Ответы совпадают с перебором всех рассадок на 500 случайных случаях до
5 автобусов и с независимой принятой реализацией на 80 случаях до 10⁵
болельщиков.
