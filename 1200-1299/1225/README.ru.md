# 1225. Ряды из белых, синих и красных полосок

[Timus 1225](https://acm.timus.ru/problem.aspx?space=1&num=1225) · сложность 35 · dp

Оригинальная задача — четвертьфинал ACM ICPC 2002–2003, центральный регион России, Рыбинск, октябрь 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Ряд из `N ≤ 45` полосок составлен из белых, синих и красных. Соседние
полоски не бывают одного цвета, а синяя должна стоять между белой и
красной. Посчитать возможные ряды.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

Число рядов.

## Проверка

Тесты репозитория сравнивают полный текст вывода, игнорируя только конечные пробельные символы. Значимые пробелы, переводы строк, регистр и пунктуация сохраняются.

## Примеры

### Пример 1

Ввод:

```
1
```

Вывод:

```
2
```

## Решение

Синей полоске нужны соседи с обеих сторон, так что ряд никогда не
кончается синей — только белой или красной. Пусть `f(n)` — число
правильных рядов длины `n`. Перед последней белой стоит либо красная,
завершающая правильный ряд длины `n − 1` с красной на конце, либо синяя
после красной, завершающая правильный ряд длины `n − 2` с красной на
конце; для красной то же с переставленными цветами. По симметрии ровно
половина рядов каждой длины кончается красной, поэтому
`f(n) = f(n − 1) + f(n − 2)` при `f(1) = f(2) = 2`: удвоенные числа
Фибоначчи. `O(N)`.

Тонкие места:

- одна полоска может быть белой или красной, но не синей, так что
  `f(1) = 2`;
- при `N = 45` получается 2 269 806 340, больше 32-битных знаковых целых.

Формула проверена перебором всех раскрасок до 12 полосок, и каждое `N` от
1 до 45 сверено с отдельно написанным решением.

## Оптимизированные решения

`1225_math.py`. Другой точный алгоритм через производящую функцию: флагов 2·Fib(N). При B=2^64 коэффициент N−1 функции 1/(1−x−x²) равен floor(B^(N+1)/(B²−B−1)) mod B; ответ удваивается. Для 1≤N≤45 коэффициенты помещаются в разряд B, положительный хвост меньше единицы и не переносится. Без float и готовых ответов. Одно деление O(N)-битных целых, числитель до 2945 бит; для неограниченного N арифметика не константна. Понятная рекуррентная версия сохранена.

Точный исходник: Python 3.12 x64 Accepted #11327782: 0.062 s / 644 KB. Сохранённые места в группе компилятора от 2026-11-20, время затем память: 5/366; 329/366. Строгий допуск учитывает только время при памяти меньше 1024 КБ: первые десять или топ 15%, равенства делят место, процентный порог округляется вверх. Звёздочка остаётся для отдельной цели языка — первого места по обеим метрикам. Сохранённый прежний вариант имеет собственную парную посылку #11324831 (PyPy 3.10 x64): 0.14 s / 224 KB; замеры и рантаймы не смешиваются. Все учебные исходники сохранены без изменений.

- `1225_math.py`: 0.062 s / 644 KB; сохранённая учебная база `1225_dp.py` (Python 3.12 x64): 0.093 s / 372 KB.

Оптимизированное решение на Java разбирает число побайтно из `System.in`
вместо `Scanner`: 0.093 с вместо 0.125 с и 316 КБ вместо 1576 КБ.

`1225_dp_optimized.py`. Сохраняется рекуррентность с двумя накопителями от (2,2): очередная полоса заменяет пару на (current,previous+current). Таблица не вводится. Сырые байты ввода и немедленное завершение после сброса вывода снижают накладные расходы. Выполняется O(N) сложений с двумя целыми накопителями в пределах N<=45. Самостоятельная программа для судьи явно сбрасывает stdout перед os._exit(0), пропуская обычное завершение интерпретатора. Выигрыш памяти подтверждён её собственным Accepted. Сама смена способа завершения не улучшает асимптотику, а её эффект в среде выполнения не гарантируется на других платформах. Простая версия сохранена без изменений.

По сравнению с `1225_dp.py`: время 0.093 s → 0.14 s; память 372 KB → 224 KB.

Ввод целиком хранится в байтовом буфере: это обмен памяти под ввод на меньшие накладные расходы универсального ввода-вывода.

Новые исходники сравниваются по срезу от 18 ноября 2026 года с другими авторами на текущих компиляторах судьи. Порогов по ID посылки или дате нет. Ничьи делят место, времена меньше 0.015 с при сравнении считаются 0.015 с. Приведённые ниже места относятся к новым версиям; прежние исходники сохраняют собственные исторические метрики Accepted.

`1225_dp_optimized.py`: место по времени 363/366, по памяти 2/366 в этой сопоставимой выборке.

Звёздочка означает недостигнутую рейтинговую цель: для C++ нужны первые десять мест либо топ 15% одновременно по обеим метрикам; для остальных семейств — первое место по обеим. Отдельный критерий допуска может выполняться по рейтингу или улучшению, в том числе при снижении времени либо памяти минимум на 30%.
