# 1225. Ряды из белых, синих и красных полосок

[Timus 1225](https://acm.timus.ru/problem.aspx?space=1&num=1225) · сложность 35 · dp

Оригинальная задача — четвертьфинал ACM ICPC 2002–2003, центральный регион России, Рыбинск, октябрь 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Ряд из `N ≤ 45` полосок составлен из белых, синих и красных. Соседние
полоски не бывают одного цвета, а синяя должна стоять между белой и
красной. Посчитать возможные ряды.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

Число рядов.

## Примеры

### Пример 1

Ввод:

```
1
```

Вывод:

```
2
```

## Решение

Синей полоске нужны соседи с обеих сторон, так что ряд никогда не
кончается синей — только белой или красной. Пусть `f(n)` — число
правильных рядов длины `n`. Перед последней белой стоит либо красная,
завершающая правильный ряд длины `n − 1` с красной на конце, либо синяя
после красной, завершающая правильный ряд длины `n − 2` с красной на
конце; для красной то же с переставленными цветами. По симметрии ровно
половина рядов каждой длины кончается красной, поэтому
`f(n) = f(n − 1) + f(n − 2)` при `f(1) = f(2) = 2`: удвоенные числа
Фибоначчи. `O(N)`.

Тонкие места:

- одна полоска может быть белой или красной, но не синей, так что
  `f(1) = 2`;
- при `N = 45` получается 2 269 806 340, больше 32-битных знаковых целых.

Формула проверена перебором всех раскрасок до 12 полосок, и каждое `N` от
1 до 45 сверено с отдельно написанным решением.
