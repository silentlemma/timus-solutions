# 1225. 白、蓝、红条纹排成的行

[Timus 1225](https://acm.timus.ru/problem.aspx?space=1&num=1225) · 难度 35 · dp

原题出自 2002 年 10 月在雷宾斯克举行的 ACM ICPC 2002–2003 俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一行 `N ≤ 45` 条条纹由白、蓝、红三色组成。相邻条纹颜色不同，蓝色条纹必须夹在一条
白色和一条红色之间。统计可能的行数。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`。

## 输出

行的数目。

## 样例

### 样例 1

输入：

```
1
```

输出：

```
2
```

## 解法

蓝色条纹两侧都需要邻居，所以一行不会以蓝色结尾，只能以白色或红色结尾。设 `f(n)`
为长度 `n` 的合法行数。最后一条白色之前要么是红色，接在一个以红色结尾、长 `n − 1`
的合法行后面；要么是红色加蓝色，接在一个以红色结尾、长 `n − 2` 的合法行后面；
最后是红色时交换颜色同理。由对称性，每种长度的行恰有一半以红色结尾，所以
`f(n) = f(n − 1) + f(n − 2)`，`f(1) = f(2) = 2`：即斐波那契数的两倍。`O(N)`。

注意事项：

- 一条条纹可以是白色或红色，但不能是蓝色，所以 `f(1) = 2`；
- `N = 45` 时结果为 2,269,806,340，超出 32 位有符号整数。

公式已用枚举不超过 12 条条纹的所有着色验证，并且 1 到 45 的每个 `N` 都与另一份
独立解答比对过。
