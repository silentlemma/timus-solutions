# 1290. Саботаж

[Timus 1290](https://acm.timus.ru/problem.aspx?space=1&num=1290) · сложность 80 · sorting

Оригинальная задача — фольклор (подготовил Ден Расковалов); IX открытое командное соревнование школьников по программированию, 13 марта 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Медленная функция получает N ≤ 25 000 целых положительных чисел, каждое
не больше 25 000. Она печатает, сколько из них не меньше 1, затем
сколько больше 1, больше 2 и так далее, останавливаясь перед первым 0.
Напечатанные числа снова читаются как массив, и тот же шаг выполняется
ещё раз; второй список и есть результат. Нужно получить его быстро.

Для 4 1 6 первый список — 3 2 2 2 1 1, второй — 6 4 1.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N чисел, по одному в строке. N может быть равно 0.

## Выходные данные

Числа результата, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
3
4
1
6
```

Вывод:

```
6
4
1
```

## Решение

Представим числа рядами клеток: число p — ряд из p клеток, все ряды
выровнены по левому краю. j-е напечатанное число считает ряды,
доходящие до столбца j, то есть первый список — длины столбцов:
картинка, повёрнутая набок (сопряжённое разбиение). Второй поворот
возвращает ряды, от самого длинного к самому короткому.

Значит, функция просто сортирует массив по убыванию. Значения не больше
25 000, поэтому хватает сортировки подсчётом: посчитать каждое значение
и вывести значения от 25 000 до 1, каждое столько раз, сколько оно
встретилось. `O(N + 25 000)`.

Тонкие места:

- при N = 0 вывод пустой (тест 02);
- равные числа возвращаются все (тесты 04 и 06).

Равносильность проверялась прямой симуляцией двух шагов на 200
случайных массивах.

## Особенности языков

- Все языки хранят по счётчику на значение, всего 25 001, и печатают
  через буфер.
