# 1264. 工作日常

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个函数统计 0 到 M 的每个值在 N 个元素的数组中出现了几次，写法是对每个元素和每个值各写
一行 `if`（0 ≤ N, M ≤ 40 000）。写一行要一秒。写完整个函数需要多少秒？

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 M。

## 输出

秒数。

## 样例

### 样例 1

输入：

```
3 1
```

输出：

```
6
```

## 解法

有 N 个元素、M + 1 个值，所以答案是 N · (M + 1)。`O(1)`。

注意事项：

- 值从 0 到 M，共 M + 1 个，而不是 M 个；
- 答案可达 40 000 · 40 001 = 1 600 040 000，接近 32 位有符号整数的上限；C++、Go、Java 和 Rust 使用 64 位
  （测试 05）；
- N = 0 时无论 M 为多少答案都是 0（测试 02、03）。

## 各语言说明

- 所有语言都输出同一个乘积。
