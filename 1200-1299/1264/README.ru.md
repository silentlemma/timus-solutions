# 1264. Трудовые будни

[Timus 1264](https://acm.timus.ru/problem.aspx?space=1&num=1264) · сложность 21 · math

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Функция считает, сколько раз каждое значение от 0 до M встречается в
массиве из N элементов, и записана как одна строка `if` на каждый
элемент и каждое значение (0 ≤ N, M ≤ 40 000). Одна строка пишется за
одну секунду. Сколько секунд уйдёт на всю функцию?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M.

## Выходные данные

Число секунд.

## Проверка

Тесты репозитория точно сравнивают токены вывода; пробельные разделители между ними несущественны.

## Примеры

### Пример 1

Ввод:

```
3 1
```

Вывод:

```
6
```

## Решение

Элементов N, значений M + 1, поэтому ответ равен N · (M + 1). `O(1)`.

Тонкие места:

- значения идут от 0 до M, их M + 1, а не M;
- ответ доходит до 40 000 · 40 001 = 1 600 040 000, близко к пределу
  32-битного знакового типа; C++, Go, Java и Rust используют 64 бита (тест 05);
- при N = 0 ответ 0 при любом M (тесты 02, 03).

## Оптимизированные решения

`1264_math_optimized.java`. Сохраняется прямое произведение N*(M+1), включая нулевые границы. При N,M<=40000 результат не больше 1600040000: int достаточен. Фиксированные буферы ввода 256 байтов, вывода 128 байтов и переиспользуемые цифры уменьшают накладные расходы. Арифметика и дополнительная память O(1); симуляция массива и новый алгоритм подсчёта не вводятся, простая версия сохранена.

Accepted точного исходника Java 1.8 №11327465: 0.093 с / 340 КБ. Сохранённое сравнение компиляторов от 2026-11-20: время 42/1224, память 11/1224. При памяти меньше 1024 КБ строгий допуск учитывает только время: первые десять мест или топ 15%, равенства делят место, процентный порог округляется вверх. Звёздочка остаётся для отдельной цели языка: первого места по обеим метрикам. Прежний документированный оптимизированный запуск №11303732: 0.14 с / 296 КБ; это отдельная историческая пара, не текущий замер данного исходника. Учебные версии сохранены без изменений.

- `1264_math_optimized.java`: 0.093 s / 340 KB; сохранённая учебная база `1264_math.java`: 0.109 s / 1552 KB.

`1264_math_optimized.py` используется побайтово без изменений, без второго исходника и нового алгоритма. Accepted точного исходника на CPython 3.12 №11327022: 0.046 с / 596 КБ. Сохранённая выборка актуальных компиляторов семейства Python от 2026-11-20: место по времени 1/597, по памяти 524/597. Поскольку здесь меньше 1024 КБ, строгий критерий первых десяти мест или топ 15% учитывает только время; звёздочка сохраняет отдельную рейтинговую цель языка. У того же файла есть прежний Accepted на PyPy 3.10 №11324828: 0.109 с / 208 КБ. Это парные замеры разных запусков: CPython даёт выбранный результат по времени и рейтингу, PyPy расходует меньше памяти. Прежние замечания об экономии памяти в этом разделе относятся к этому замеру PyPy, а не к строке CPython. Все учебные исходники сохранены без изменений.

`1264_math_optimized.go`. Сохраняется прямой подсчёт N*(M+1), включая ноль элементов и значение ноль среди M+1 возможностей. Симуляция массива не вводится. При N,M<=40000 произведение не больше1600040000; Go сохраняет int64, Python использует точные целые. Байтовый числовой ввод и прямой вывод снижают накладные расходы при O(1) времени и дополнительного состояния. Переносимые os.Stdin.Read/os.Stdout.Write и прямое преобразование целых используют фиксированные буферы ввода и вывода по 4096 байт. Частичная запись обрабатывается до повторного использования буфера. Исходный простой вариант с Accepted сохранён.

По сравнению с `1264_math.go`: время 0.031 s → 0.031 s; память 1060 KB → 820 KB.

## Особенности языков

Новые исходники сравниваются по срезу от 18 ноября 2026 года с другими авторами на текущих компиляторах судьи. Порогов по ID посылки или дате нет. Ничьи делят место, времена меньше 0.015 с при сравнении считаются 0.015 с. Приведённые ниже места относятся к новым версиям; прежние исходники сохраняют собственные исторические метрики Accepted.

`1264_math_optimized.go`: место по времени 1/16, по памяти 1/16 в этой сопоставимой выборке.

Прежнее сравнение PyPy: `1264_math_optimized.py`: место по времени 539/597, по памяти 1/597 в этой сопоставимой выборке.

Звёздочка означает недостигнутую рейтинговую цель: для C++ нужны первые десять мест либо топ 15% одновременно по обеим метрикам; для остальных семейств — первое место по обеим. Отдельный критерий допуска может выполняться по рейтингу или улучшению, в том числе при снижении времени либо памяти минимум на 30%.
