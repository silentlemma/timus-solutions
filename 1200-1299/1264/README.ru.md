## Задача

Функция считает, сколько раз каждое значение от 0 до M встречается в
массиве из N элементов, и записана как одна строка `if` на каждый
элемент и каждое значение (0 ≤ N, M ≤ 40 000). Одна строка пишется за
одну секунду. Сколько секунд уйдёт на всю функцию?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M.

## Выходные данные

Число секунд.

## Примеры

### Пример 1

Ввод:

```
3 1
```

Вывод:

```
6
```

## Решение

Элементов N, значений M + 1, поэтому ответ равен N · (M + 1). `O(1)`.

Тонкие места:

- значения идут от 0 до M, их M + 1, а не M;
- ответ доходит до 40 000 · 40 001 = 1 600 040 000, близко к пределу
  32-битного знакового типа; C++, Go, Java и Rust используют 64 бита (тест 05);
- при N = 0 ответ 0 при любом M (тесты 02, 03).

## Оптимизированные решения

Оптимизированное решение на Java разбирает два числа побайтно из
`System.in` вместо `Scanner`: 296 КБ вместо 1552 КБ, хотя время растёт с
0.109 с до 0.140 с.
