# 1293. 埃尼娅号

[Timus 1293](https://acm.timus.ru/problem.aspx?space=1&num=1293) · 难度 14 · math

原题作者 Den Raskovalov，出自 2004 年 3 月 13 日第九届中学生公开团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 块 A × B 米的矩形面板需要两面都做处理，每平方米需要一纳克药剂（1 ≤ N, A, B ≤ 100）。一共需要
多少纳克？

时间限制：1 秒。内存限制：64 MB。

## 输入

一行中的 N、A、B。

## 输出

纳克数。

## 样例

### 样例 1

输入：

```
5 2 3
```

输出：

```
60
```

## 解法

每块面板有两面，每面 A · B 平方米，所以答案是 2 · N · A · B。`O(1)`。

注意事项：

- 两面都要算：漏掉因子 2，样例会得到 30 而不是 60（测试 01）；
- 最大答案是 2 000 000，32 位整数绰绰有余（测试 03）。

## 各语言说明

- 所有语言都输出同一个乘积。
