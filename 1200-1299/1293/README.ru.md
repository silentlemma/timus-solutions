# 1293. Эния

[Timus 1293](https://acm.timus.ru/problem.aspx?space=1&num=1293) · сложность 14 · math

Автор оригинальной задачи — Ден Расковалов; IX открытое командное соревнование школьников по программированию, 13 марта 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N прямоугольных панелей размером A на B метров нужно обработать с
обеих сторон, а на один квадратный метр уходит один нанограмм состава
(1 ≤ N, A, B ≤ 100). Сколько нанограммов нужно?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, A и B в одной строке.

## Выходные данные

Число нанограммов.

## Примеры

### Пример 1

Ввод:

```
5 2 3
```

Вывод:

```
60
```

## Решение

У каждой панели две стороны по A · B квадратных метров, поэтому ответ
равен 2 · N · A · B. `O(1)`.

Тонкие места:

- считаются обе стороны: без множителя 2 на примере получится 30
  вместо 60 (тест 01);
- наибольший ответ — 2 000 000, он с запасом помещается в 32 бита
  (тест 03).

## Оптимизированные решения

Оптимизированное решение на Java разбирает три числа побайтно из
`System.in` вместо `Scanner`: 312 КБ вместо 1596 КБ при том же времени.
