# 1235. 树木之间最大的正方形场地

[Timus 1235](https://acm.timus.ru/problem.aspx?space=1&num=1235) · 难度 769 · geometry

原题作者 Andrey Demidov，出自 2002–2003 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个 W × H 的公园（1 ≤ W, H ≤ 10 000），一个角在原点，园中有 N 棵树
（0 ≤ N ≤ 100），位于互不相同的整点上。求边与公园的边平行、位于公园内、且内部
（不含边界）没有树的最大正方形；树在它的边界上是允许的。

时间限制：1 秒。内存限制：64 MB。

## 输入

N、W 和 H，然后是 N 棵树的 `x y`。

## 输出

最大正方形的西南角 P、Q 以及边长 L。任何一个最大正方形都可以。

## 评测方式

最大正方形可能有多个，所以评测程序接受任意一个：L 必须等于最大边长，正方形
必须在公园内，并且没有树严格位于其内部。

## 样例

### 样例 1

输入：

```
7 10 7
3 2
4 2
7 0
7 3
4 5
2 4
1 7
```

输出：

```
4 3 4
```

## 解法

取一个最大正方形，把它向左平移：它可以一直移动，直到左边碰到公园边界，或碰到一棵
高度严格介于其底边和顶边之间的树。再用同样的方式向下平移。正方形仍然是空的、大小
不变，而此时它的角的 x 等于 0 或某棵树的 x，y 等于 0 或某棵树的 y。

所以只需尝试所有这样的角，最多 101 × 101 个。从角 (p, q) 出发，边长受公园限制，
即 `min(W − p, H − q)`，也受每棵位于右上方（x > p 且 y > q）的树限制：当边长
超过 `max(x − p, y − q)` 时，这棵树就严格在内部。左边或下边的树永远不会进入内部。
所有角中最大的边长就是答案。`O(N³)`，N ≤ 100。

注意事项：

- 角的两个坐标可能来自不同的树，所以要尝试所有组合，而不是逐棵树尝试；
- 树在边界上是允许的，因此比较都是严格的：样例中场地 4 3 4 有两条边上有树，顶边
  在公园边界上；
- 没有树时答案是公园较短的一边（测试 02）。

## 各语言说明

- Python 对每个 p 先去掉不在其右边的树，再尝试各个 q。
