# 1255. Укладка гробов 1 × K в квадрат

## Задача

Сколько прямоугольников 1 × K (гробов) помещается без наложений и
параллельно сторонам в квадрат N × N (1 < N, K < 10 000)?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и K.

## Выходные данные

Наибольшее число гробов.

## Проверка

Сравнивается один точный целочисленный токен; пробельное оформление несущественно. Новый точный исходник Python прошёл 16 тестов репозитория на PyPy 3.10. Остальные сохранённые варианты имеют собственные проверки целевой среды и точные Accepted. Вывод сравнивается по правилам проверяющего модуля задачи.

## Примеры

### Пример 1

Ввод:

```
5 3
```

Вывод:

```
8
```

## Решение

Если K > N, ничего не помещается. Иначе запишем N = qK + r, 0 ≤ r < K, и
пусть s = min(r, K − r). Ответ равен

```text
(N² − s²) / K
```

и всегда целый, потому что N ≡ r, а значит, N² ≡ r² ≡ (K − r)² по
модулю K.

Столько помещается:

- при r ≤ K/2 гробы, лежащие вдоль строк, заполняют первые qK столбцов
  каждой строки, а гробы, стоящие вдоль столбцов, заполняют последние r
  столбцов во всех строках, кроме r, оставляя пустым угол r × r;
- при r > K/2 четыре блока гробов, уложенные «вертушкой» вокруг центра,
  оставляют дыру (K − r) × (K − r).

Больше не помещается: раскрасим клетку в цвет `(строка + столбец) mod K`.
Гроб покрывает K подряд идущих клеток строки или столбца, то есть ровно
по одной клетке каждого цвета, так что гробов не больше, чем клеток в
самом малом цветовом классе, а подсчёт по диагоналям показывает, что в
нём ровно (N² − s²) / K клеток. `O(1)`.

Тонкие места:

- оставшийся квадрат имеет сторону min(r, K − r), а не r: при N = 7,
  K = 4 r = 3, но остаётся лишь дыра 1 × 1, и помещается 12 гробов
  (тест 08);
- N² не превышает 99 980 001 (N = 9999, тест 03), что ещё помещается в 32 бита.

Формула сравнивалась с полным перебором для всех N и K от 2 до 7.

## Оптимизированные решения

Используется ровно та же целочисленная формула углового квадрата, что в учебных версиях. При r=N mod K и s=min(r,K-r), если N>=K, ответ (N*N-s*s)//K, иначе ноль. Нет вычислений с округлением или таблицы готовых ответов. Компактный файл читает существующий текстовый поток и прямо записывает точное целое. Экономию подтверждает его собственная посылка на PyPy; интерпретатор и рост времени явно указаны ниже. Пять простых файлов сохранены.

- `1255_math_optimized.py`: 0.140 s / 248 KB; база `1255_math.py`: 0.078 s / 376 KB; изменение относительно базы: время +79.5%, память -34.0%.
