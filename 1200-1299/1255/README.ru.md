# 1255. Укладка гробов 1 × K в квадрат

## Задача

Сколько прямоугольников 1 × K (гробов) помещается без наложений и
параллельно сторонам в квадрат N × N (1 < N, K < 10 000)?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и K.

## Выходные данные

Наибольшее число гробов.

## Проверка

Сравнивается один точный целочисленный токен; пробельное оформление несущественно. Новый точный исходник Python прошёл 16 тестов репозитория на PyPy 3.10. Остальные сохранённые варианты имеют собственные проверки целевой среды и точные Accepted. Вывод сравнивается по правилам проверяющего модуля задачи.

## Примеры

### Пример 1

Ввод:

```
11 4
```

Вывод:

```
30
```

## Решение

Если K > N, ничего не помещается. Иначе запишем N = qK + r, 0 ≤ r < K, и
пусть s = min(r, K − r). Ответ равен

```text
(N² − s²) / K
```

и всегда целый, потому что N ≡ r, а значит, N² ≡ r² ≡ (K − r)² по
модулю K.

Столько помещается:

- при r ≤ K/2 гробы, лежащие вдоль строк, заполняют первые qK столбцов
  каждой строки, а гробы, стоящие вдоль столбцов, заполняют последние r
  столбцов во всех строках, кроме r, оставляя пустым угол r × r;
- при r > K/2 четыре блока гробов, уложенные «вертушкой» вокруг центра,
  оставляют дыру (K − r) × (K − r).

Больше не помещается: раскрасим клетку в цвет `(строка + столбец) mod K`.
Гроб покрывает K подряд идущих клеток строки или столбца, то есть ровно
по одной клетке каждого цвета, так что гробов не больше, чем клеток в
самом малом цветовом классе, а подсчёт по диагоналям показывает, что в
нём ровно (N² − s²) / K клеток. `O(1)`.

Тонкие места:

- оставшийся квадрат имеет сторону min(r, K − r), а не r: при N = 7,
  K = 4 r = 3, но остаётся лишь дыра 1 × 1, и помещается 12 гробов
  (тест 08);
- N² не превышает 99 980 001 (N = 9999, тест 03), что ещё помещается в 32 бита.

Формула сравнивалась с полным перебором для всех N и K от 2 до 7.

## Оптимизированные решения

`1255_math_optimized.java`. Сохраняется точная формула углового квадрата: при N<K ответ ноль, иначе r=N mod K, s=min(r,K-r), ответ (N*N-s*s)/K. Без вещественной арифметики и таблицы ответов. Все числовые поля, нужные вычислению, потребляются до вывода. Один массив 256 байт сначала служит вводу, затем выводу; перед знаковым int резервируются двенадцать байт, разворачиваются только новые цифры. Убраны отдельные массивы ввода, вывода и цифр, нужные алгоритму данные не перезаписываются. Разбор и вывод линейны по потреблённым байтам, буфер фиксирован.

Исторический Accepted точного исходника Java 1.8 №11327763: 0.078 с / 340 КБ. Срез от 2026-11-20 давал время 2/27, память 2/27. Общие текущие критерии при памяти меньше 1024 КБ учитывают только время; историческая числовая пара проходит, отдельного требования первого места и звёздочки нет. Прежняя №11309313: 0.109 с / 320 КБ, самостоятельная историческая пара. Весь исполняемый код и пять учебных файлов сохранены.

Оба Python-файла считают одну точную целочисленную формулу углового квадрата. Компактный читает строку и пишет число без конечного перевода строки, учебный использует input/print. Замеры ниже различаются и исходником, и интерпретатором: база на CPython 3.12, компактный файл на PyPy 3.10. Это наблюдаемые пары, а не изолированная экономия памяти от правки кода.
