# 1255. 把 1 × K 的棺材装进正方形

[Timus 1255](https://acm.timus.ru/problem.aspx?space=1&num=1255) · 难度 282 · math

原题作者 Stanislav Vasilyev 和 Alexey Lakhtin，出自 2003 年 3 月 15 日乌拉尔国立大学公开团体赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N × N 的正方形（1 < N, K < 10 000）里，最多能不重叠、平行于边地放入多少个 1 × K 的
长方形（棺材）？

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 K。

## 输出

最多的棺材数。

## 评测方式

比较一个精确整数词元，忽略排版空白。 新Python精确源码在PyPy 3.10通过16个仓库测试。 其他保留原生版本各有保存的目标环境检查与精确Accepted。输出按本题检查器规则比较。

## 样例

### 样例 1

输入：

```
5 3
```

输出：

```
8
```

## 解法

若 K > N，什么也放不下。否则写 N = qK + r，0 ≤ r < K，令 s = min(r, K − r)。答案是

```text
(N² − s²) / K
```

而且总是整数，因为 N ≡ r，所以 N² ≡ r² ≡ (K − r)²（模 K）。

能放这么多：

- 当 r ≤ K/2 时，沿行横放的棺材填满每一行的前 qK 列，沿列竖放的棺材填满最后 r 列中
  除 r 行之外的部分，留下一个 r × r 的空角；
- 当 r > K/2 时，四块棺材像风车一样围着中心摆放，留下一个 (K − r) × (K − r) 的洞。

不能再多：把每个格子染成 `(行 + 列) mod K` 的颜色。一口棺材覆盖一行或一列中连续的 K
个格子，所以每种颜色恰好一格，因此棺材数不超过最小颜色类的格子数，而沿对角线计数可知
它恰好是 (N² − s²) / K。`O(1)`。

注意事项：

- 剩下的正方形边长是 min(r, K − r) 而不是 r：N = 7、K = 4 时 r = 3，但只剩一个 1 × 1
  的洞，能放 12 口（测试 08）；
- N² 最大为 99,980,001（N = 9999，测试 03），仍在 32 位范围内。

该公式对 2 到 7 的所有 N 和 K 与穷举搜索比较过。
