# 1284. 太空扑克

[Timus 1284](https://acm.timus.ru/problem.aspx?space=1&num=1284) · 难度 2284 · bruteforce

原题作者 Leonid Volkov，出自 2004 年乌拉尔国立大学个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一排放着 N ≤ 20 张互不相同的牌；每张牌的点数为 1 到 100，花色为 1 到 10。奇数花色为蓝色，
偶数花色为黄色，手中蓝色花色与黄色花色的数目相差不超过一。一步操作是取出一张牌，放到这排
中的任意位置。求最少的步数，使得每种花色的牌连在一起，蓝黄花色交替出现，并且每种花色内部
按点数排序，所有花色方向相同（全部升序或全部降序）。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后从左到右给出 N 张牌的点数和花色。

## 输出

最少步数。

## 样例

### 样例 1

输入：

```
5
10 1
12 2
8 2
4 4
7 4
```

输出：

```
2
```

## 解法

从未移动过的牌保持相对顺序，而每张要移动的牌都可以一步放到最终位置。所以对固定的目标排列，
答案是 N 减去手牌中已经符合目标顺序的最长子序列长度：给每张牌标上它在目标中的名次，求名次
的最长上升子序列。

各个目标只在以下方面不同：蓝色花色的顺序、黄色花色的顺序、哪种颜色在前（若一种颜色的花色
更多则固定）、以及排序方向。每种颜色最多五种花色，所以最多 5! · 5! · 2 · 2 = 57 600 个目标，
每个用 `O(N log N)` 的最长上升子序列检验。

注意事项：

- 方向是共同的：不允许一种花色升序而另一种降序；
- 若一种颜色的花色更多，它必须位于这一排的开头和结尾（测试 08）；
- 已经排好的手牌不需要移动（测试 04、06）。

在 200 手最多六张牌的随机牌上，与对单步移动可达的所有排列做广度优先搜索的结果比较过。

## 各语言说明

- C++ 用 `next_permutation` 枚举花色顺序；其他语言递归交换元素。
