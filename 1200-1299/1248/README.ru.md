# 1248. Сложение чисел с 19 значащими цифрами

[Timus 1248](https://acm.timus.ru/problem.aspx?space=1&num=1248) · сложность 658 · math

Автор оригинальной задачи — Александр Клепинин; личное первенство УрГУ, 1 марта 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Сложить до 1000 чисел, записанных в экспоненциальной форме с 19
значащими цифрами каждое, все от 10⁻¹⁰⁰ до 10¹⁰⁰, и вывести сумму в
экспоненциальной форме с 19 верными значащими цифрами.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N чисел по одному в строке.

## Выходные данные

Сумма в виде `d.ddddddddddddddddddeE`.

## Примеры

### Пример 1

Ввод:

```
2
1.5e3
1.5e-3
```

Вывод:

```
1.500001500000000000e3
```

## Решение

Double хранит лишь 15–17 цифр, и даже 80-битный long double теряет
малые слагаемые рядом с большими, поэтому сумма считается точно. Каждое
входное число — целое кратное 10⁻³⁰⁰ (19 цифр около 10⁻¹⁰⁰ доходят
до 10⁻¹¹⁸), так что после умножения на 10³⁰⁰ оно становится
точным целым: цифры мантиссы, умноженные на степень десяти. Целые
складываются точно, сумма обрезается до 19 старших цифр с округлением
остатка вверх от половины и выводится с порядком
`(число цифр − 1) − 300`. Если округление превращает 19 цифр в 10¹⁹,
мантисса становится единицей с нулями, а порядок растёт на единицу.
`O(N · L)` при L ≈ 400 цифр.

Тонкие места:

- слагаемые после 19-й цифры всё же могут повлиять на округление:
  тест 04 стоит ровно на половине, тест 05 — чуть ниже;
- сумма двух чисел меньше 10¹⁰⁰ может округлиться до 2·10¹⁰⁰ (тест 03);
  округление может перенестись в новую степень десяти (тест 08);
- порядок выводится как есть, `e3` и `e-100`, без плюса и ведущих нулей.

## Особенности языков

- Python использует свои точные целые, Go — `math/big`; Java складывает
  `BigDecimal` и округляет через `MathContext(19, HALF_UP)`; C++ и Rust
  хранят по одной знаковой сумме цифр на каждую степень десяти и
  разносят переносы в конце.

## Оптимизированные решения


Java кеширует множители и накапливает масштабированные слагаемые в BigInteger. Java 1.8, посылка 11318438. Время 0,109 → 0,109 с, память 1696 → 1932 КБ.

Rust суммирует десятичные числа в блоках фиксированного размера, переносит разряды и округляет первые 19 значащих цифр. Rust 1.75 x64, посылка 11323295. Время 0,015 → 0,015 с, память 280 → 68 КБ.


**Посылки Timus для простых версий**

Go складывает цифры со знаком по десятичным разрядам и выполняет переносы один раз после чтения всех слагаемых. Go 1.14 x64, посылка 11322027. Время 0,015 → 0,015 с, память 2076 → 908 КБ.
