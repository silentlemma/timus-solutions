# 1248. 以 19 位有效数字相加

[Timus 1248](https://acm.timus.ru/problem.aspx?space=1&num=1248) · 难度 659 · math

原题作者 Alexander Klepinin，出自 2003 年 3 月 1 日乌拉尔国立大学个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把至多 1000 个用科学计数法给出、各有 19 位有效数字、都在 10⁻¹⁰⁰ 到 10¹⁰⁰ 之间的数
相加，并以科学计数法输出和，给出 19 位正确的有效数字。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N 个数，每行一个。

## 输出

和，形如 `d.ddddddddddddddddddeE`。

## 样例

### 样例 1

输入：

```
2
1.5e3
1.5e-3
```

输出：

```
1.500001500000000000e3
```

## 解法

double 只能保存 15–17 位，即使 80 位的 long double 也会在大数旁边丢掉小的项，所以
要精确求和。每个输入都是 10⁻³⁰⁰ 的整数倍（10⁻¹⁰⁰ 以下的 19 位数字大约到 10⁻¹¹⁹），
所以乘以 10³⁰⁰ 后就成为精确的整数：尾数的数字乘以 10 的幂。把这些整数精确相加，把和
截取到最高的 19 位，对其余部分四舍五入，并以指数 `(位数 − 1) − 300` 输出。如果舍入
使 19 位变成 10¹⁹，尾数就成为 1 后面跟零，指数加一。`O(N · L)`，L ≈ 400 位。

注意事项：

- 小数只影响第 19 位之后的数字，但仍可能通过舍入改变它：测试 04 恰好位于一半处，
  测试 05 略低于一半；
- 两个小于 10¹⁰⁰ 的数之和可达 2·10¹⁰⁰，舍入也可能进位到新的 10 的幂（测试 03）；
- 指数直接输出，如 `e3` 和 `e-100`，没有加号和前导零。

## 各语言说明

- Python 使用其精确整数，Go 用 `math/big`；Java 把 `BigDecimal` 相加并用
  `MathContext(19, HALF_UP)` 舍入；C++ 和 Rust 为每个 10 的幂保存一个带符号的数字和，
  最后再处理进位。
