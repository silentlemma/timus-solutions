# 1232. Посадка зонда внутри конуса

[Timus 1232](https://acm.timus.ru/problem.aspx?space=1&num=1232) · сложность 2375 · geometry

Оригинальная задача — четвертьфинал ACM ICPC 2002–2003, центральный регион России, Рыбинск, октябрь 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Станция висит на высоте h над плоским астероидом, на оси z. Зонд
вылетает со станции и движется прямыми отрезками длины ровно d; каждый
отрезок должен опускать его ниже, а весь путь должен оставаться внутри
конуса с углом α при вершине под станцией, где проходят её сигналы.
Последний отрезок тоже должен иметь длину d и заканчиваться на
поверхности. Нужно найти путь из наименьшего числа отрезков или сообщить,
что посадка невозможна.

Ограничения: 0.5 ≤ h ≤ 99.9999, 1 ≤ d ≤ 5, 0.1 ≤ α ≤ 2 (радианы), все не
более чем с четырьмя знаками после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

h, d и α.

## Выходные данные

Число отрезков n или -1, если посадка невозможна; затем n точек, где
заканчиваются отрезки, в виде `x y z`, последняя — на поверхности.
Координаты нужны с точностью 0.0001.

## Проверка

Путь не единственный, поэтому принимается любой правильный путь из
наименьшего числа отрезков. Наш чекер сравнивает n с ожидаемым ответом и
проверяет длину каждого отрезка, то, что он идёт вниз, что каждая точка
внутри конуса и что последняя на поверхности, всё с точностью 0.0001.

## Примеры

### Пример 1

Ввод:

```
11 5 2
```

Вывод:

```
3
0 3 7
3 3 3
3 -1 0
```

## Решение

**Сколько отрезков.** Отрезок опускает не больше чем на d, поэтому нужно
не меньше `n = ⌈h/d⌉` отрезков, и n хватает всегда, когда посадка вообще
возможна: если садится более длинный путь, его первые n отрезков
кончаются строго над поверхностью, а поскольку глубины, достижимые за n
отрезков, образуют отрезок до `n·d`, глубина h тоже достижима за n. Так
что ответ — n или -1.

**Построение пути.** Вся работа — в том, чтобы потерять лишнюю высоту:
когда осталось L отрезков, `extra = z − (L−1)·d` лежит в `(0, d]`, и как
только один отрезок опустит ровно на `extra`, остальные идут прямо вниз.
Один отрезок может это сделать, если `extra` не меньше наименьшего
спуска, доступного из текущей точки. Из точки на стенке конуса на глубине
t под станцией, где ширина конуса `w = 2t·tg(α/2)`, наименьший спуск
равен 0 при `w ≥ d` (отрезок может быть почти горизонтальным), а иначе
его даёт отрезок, пересекающий конус до противоположной стенки:

```text
спуск = (√(d²(1 + tg²) − w²) − w·tg) / (1 + tg²),  tg = tg(α/2)
```

Пока лишнюю высоту нельзя потерять одним отрезком, путь, лежащий в
плоскости y = 0, делает отрезок с наименьшим спуском, к противоположной
стенке, так что следующий отрезок снова начинается со стенки.

**Когда жадность ошибается.** Пересекать конус с полным наклоном не всегда
лучше всего. Из более глубокой точки стенки конус шире, и пока он там чуть
уже d, более глубокий старт может дать более высокий конец после
следующего пересечения. Поэтому программа пробует также пути, у которых
первые j отрезков скользят прямо вниз по стенке до начала зигзага, для
j = 0, 1, …, n, и выводит первый, который садится. j = 0 — обычный жадный
зигзаг; на тесте 05 (α = 0.496, d = 1, h = 2.01) он уходит под
поверхность, а два скольжения и одно пересечение садятся. `O(n²)` при
n ≤ 100.

Тонкие места:

- первый отрезок выходит из вершины конуса, поэтому даже самый наклонный
  опускает на `d·cos(α/2)`; если h меньше, сесть нельзя (тесты 02, 06,
  10);
- `⌈h/d⌉` требует небольшого допуска, иначе при h, кратном d (тест 04),
  получится лишний отрезок.

Наш чекер принимает эти пути; кроме того, ответы (n или -1) сравнивались
с полным перебором по глубине и расстоянию до оси на мелкой сетке, для
углов по всему диапазону, чуть выше и чуть ниже каждого порога, где
посадка становится возможной, и совпали везде. Это численная проверка, а
не доказательство того, что скольжения и затем зигзага всегда хватает.
