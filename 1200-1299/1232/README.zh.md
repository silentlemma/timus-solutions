# 1232. 在圆锥内让探测器着陆

[Timus 1232](https://acm.timus.ru/problem.aspx?space=1&num=1232) · 难度 2375 · geometry

原题出自 2002 年 10 月在雷宾斯克举行的 ACM ICPC 2002–2003 俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

空间站悬停在平坦小行星上方高度 h 处，位于 z 轴上。探测器从空间站出发，沿长度
恰为 d 的直线段移动；每一段都必须让它更低，整条路径必须留在空间站下方顶角为 α
的圆锥内（信号只能在其中传播）。最后一段长度也必须是 d，并且终点在地面上。求
段数最少的路径，或者报告无法着陆。

限制：0.5 ≤ h ≤ 99.9999，1 ≤ d ≤ 5，0.1 ≤ α ≤ 2（弧度），都最多有四位小数。

时间限制：1 秒。内存限制：64 MB。

## 输入

h、d 和 α。

## 输出

段数 n，若无法着陆则输出 -1；然后是 n 个各段终点，格式为 `x y z`，最后一个在
地面上。坐标精度要求 0.0001。

## 评测方式

路径不唯一，所以任何段数最少的合法路径都被接受。我们的评测程序把 n 与期望答案
比较，并检查每段的长度、每段是否向下、每个点是否在圆锥内以及最后一点是否在地面
上，误差都在 0.0001 以内。

## 样例

### 样例 1

输入：

```
11 5 2
```

输出：

```
3
0 3 7
3 3 3
3 -1 0
```

## 解法

**需要几段。** 每段最多下降 d，所以至少需要 `n = ⌈h/d⌉` 段；只要能着陆，n 段
就够：如果更长的路径能着陆，它的前 n 段终点严格在地面之上，而 n 段能到达的深度
构成一个直到 `n·d` 的区间，所以深度 h 用 n 段也能到达。因此答案是 n 或 -1。

**构造路径。** 关键在于消耗多余的高度：还剩 L 段时，
`extra = z − (L−1)·d` 落在 `(0, d]` 内，一旦某一段恰好下降 `extra`，其余各段
就竖直向下。只要 `extra` 不小于从当前点出发的最小下降量，一段就能做到。从空间站
下方深度 t 处圆锥壁上的一点出发，那里圆锥宽 `w = 2t·tan(α/2)`：若 `w ≥ d`，
最小下降量为 0（这一段可以几乎水平），否则由横穿到对面壁的那一段给出：

```text
drop = (√(d²(1 + tan²) − w²) − w·tan) / (1 + tan²),  tan = tan(α/2)
```

在多余高度还不能用一段消耗掉时，路径保持在平面 y = 0 内，走下降量最小、横穿到对
面壁的那一段，这样下一段又从壁上出发。

**贪心何时出错。** 以最大倾斜横穿并不总是最好的。壁上更深的点所在处圆锥更宽，当
那里的宽度略小于 d 时，从更深处出发，下一次横穿之后反而可能停在更高的位置。因此
程序还尝试这样的路径：前 j 段先沿壁直线下滑，再开始之字形，j = 0, 1, …, n，并
输出第一条能着陆的路径。j = 0 就是普通的贪心之字形；在测试 05（α = 0.496，
d = 1，h = 2.01）中它会降到地面以下，而下滑两段再横穿一次就能着陆。`O(n²)`，
n ≤ 100。

注意事项：

- 第一段从圆锥顶点出发，即使倾斜最大也要下降 `d·cos(α/2)`；若 h 更小，就无法
  着陆（测试 02、06、10）；
- `⌈h/d⌉` 需要一个小的容差，否则 h 是 d 的倍数时（测试 04）会多出一段。

我们的评测程序接受这些路径；另外，答案（n 或 -1）还与在细网格上按深度和到轴距离
进行的穷举搜索作了比较，覆盖整个角度范围，在每个能够着陆的阈值的略上方和略下方
取值，结果处处一致。这只是数值验证，并不能证明"先下滑再之字形"总是足够。

## 各语言说明

- 所有语言都用相同的容差执行同样的模拟，并输出六位小数。
