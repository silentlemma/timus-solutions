# 1245. Закрыть круглые пятна не более чем двумя картинами

[Timus 1245](https://acm.timus.ru/problem.aspx?space=1&num=1245) · сложность 948 · geometry

Автор оригинальной задачи — Александр Петров (текст — Леонид Волков); личное первенство УрГУ, 1 марта 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N круглых пятен (0 < N ≤ 1000) с целыми радиусом и центром, не больше
10 000, нужно закрыть одной или двумя прямоугольными картинами со
сторонами, параллельными осям. Каждая сторона картины не меньше 100, две
картины не должны налегать друг на друга, и каждое пятно должно целиком
лежать под одной картиной. Найти наименьшую общую площадь.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем каждое пятно в виде `R X Y`.

## Выходные данные

Наименьшая общая площадь.

## Примеры

### Пример 1

Ввод:

```
3
50 50 50
50 250 50
10 150 250
```

Вывод:

```
40000
```

## Решение

Картина — прямоугольник со сторонами вдоль осей, поэтому она закрывает
пятно ровно тогда, когда закрывает описанный около него квадрат
`[X − R, X + R] × [Y − R, Y + R]`. Картина для группы пятен — это
ограничивающий прямоугольник их квадратов, расширенный до 100 там, где он
уже: `max(w, 100) · max(h, 100)`.

Два непересекающихся прямоугольника разделяются вертикальной или
горизонтальной прямой, и каждый можно расширить до 100 на своей стороне
этой прямой, не задевая другой. Поэтому перебираем одну картину, а затем
все способы разделить пятна вертикальной прямой и горизонтальной.

Для вертикальной прямой отсортируем квадраты по левому краю. Любое
допустимое разбиение — префикс этого порядка: всё слева кончается не
позже, чем начинается всё справа, а квадрат начинается раньше, чем
кончается. Префикс из k квадратов может висеть отдельно от остальных
ровно тогда, когда его правый край не больше левого края квадрата k. С
ограничивающими прямоугольниками всех префиксов и суффиксов каждое
разбиение проверяется за O(1). `O(N log N)`.

Тонкие места:

- две картины могут касаться по краю: это нужно в тесте 04;
- минимум в 100 миллиметров действует для каждой картины: даже одному
  крошечному пятну нужна картина 100 × 100 (тест 02);
- край квадрата бывает отрицательным при R > X; важны только разности.

Ответы сравнивались с перебором всех разбиений пятен на две группы на
800 случайных маленьких случаях.
