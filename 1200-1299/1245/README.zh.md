# 1245. 用至多两幅画盖住圆形污渍

[Timus 1245](https://acm.timus.ru/problem.aspx?space=1&num=1245) · 难度 940 · geometry

原题作者 Alexander Petrov（题面 Leonid Volkov），出自 2003 年 3 月 1 日乌拉尔国立大学个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 N 个圆形污渍（0 < N ≤ 1000），半径和圆心都是不超过 10 000 的整数，要用一幅或两幅
边与坐标轴平行的矩形画盖住。每幅画的每条边至少 100，两幅画不能重叠，每个污渍必须
完整地位于某一幅画下面。求最小的总面积。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后每个污渍为 `R X Y`。

## 输出

最小的总面积。

## 样例

### 样例 1

输入：

```
3
50 50 50
50 250 50
10 150 250
```

输出：

```
40000
```

## 解法

画是边与坐标轴平行的矩形，所以它盖住一个污渍当且仅当它盖住该污渍的外接正方形
`[X − R, X + R] × [Y − R, Y + R]`。一组污渍所需的画就是它们正方形的包围盒，在不足
100 的方向上扩展到 100：`max(w, 100) · max(h, 100)`。

两个不重叠的矩形可以被一条竖直或水平的直线分开，并且每个都可以在这条直线自己的一侧
扩展到 100 而不与另一个重叠。所以先试一幅画，再试用竖直直线和水平直线分开污渍的所有
方式。

对于竖直直线，把正方形按左边界排序。任何合法的划分都是这个顺序的一个前缀：左边的
一切都不晚于右边的一切开始的位置结束，而一个正方形的开始早于结束。由 k 个正方形
组成的前缀能与其余部分分开悬挂，当且仅当它的最右边界不超过剩余第一个正方形的左边界。
预先求出所有前缀和后缀的包围盒，每种划分只需 O(1)。`O(N log N)`。

注意事项：

- 两幅画可以沿边相接：测试 04 需要这一点；
- 100 毫米的下限对每幅画都有效：即使只有一个很小的污渍，也需要一幅 100 × 100 的画
  （测试 02）；
- 当 R > X 时正方形的边界可能为负；只有差值才重要。

这些答案在 800 个随机的小规模情况上与把污渍分成两组的所有划分逐一尝试的结果比较过。
