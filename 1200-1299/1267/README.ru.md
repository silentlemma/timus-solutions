# 1267. Екатеринбургское метро

## Задача

На линии метро N станций (1 ≤ N ≤ 16), время в пути между соседними —
целые минуты (каждое до 10⁵, возможно 0). Поезда отправляются со
станции 1 в сторону N каждые P минут, начиная с минуты A, и со станции N
в сторону 1 каждые P минут, начиная с минуты B (1 ≤ P ≤ 10⁵,
0 ≤ A, B ≤ P).
Стоянки мгновенные. Турист начинает на станции S, садится в любой поезд
и должен выйти на каждой другой станции, чтобы осмотреть её; вместе с
посадкой это занимает 59 секунд, так что следующий поезд со станции
уходит не раньше чем через минуту после прибытия. В конце турист
возвращается на S. Найти наименьшее время от первой посадки до
последнего прибытия на S.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N − 1 времён в пути, затем S, затем P, A и B.

## Выходные данные

Наименьшая продолжительность в минутах.

## Примеры

### Пример 1

Ввод:

```
3
5 7
2
4 0 1
```

Вывод:

```
28
```

## Решение

Задачу упрощают три наблюдения.

- Время начала свободно, а когда первые поезда доехали до дальних
  концов, расписание повторяется с периодом P. Начав на целое число
  периодов позже, турист пользуется теми же поездами в те же
  относительные моменты, поэтому можно считать, что поезда ходят вечно:
  в сторону N поезд проходит станцию i в моменты с остатком
  (A + pos(i)) mod P, в сторону 1 — с остатком
  (B + pos(N) − pos(i)) mod P.
- Оказаться на станции раньше никогда не хуже: можно дождаться любого
  более позднего поезда. Поэтому для каждого множества осмотренных
  станций и текущей станции важен лишь самый ранний момент прибытия.
- Выходить на уже осмотренной станции никогда не выгодно. Ехать дальше
  в ту же сторону не лучше, чем остаться в поезде, а поезд обратно
  проходит предыдущую станцию позже момента отъезда с неё, так что его
  можно было дождаться там.

Для обоих направлений первого поезда динамика по (множество осмотренных,
станция) хранит самое раннее прибытие. Из каждого состояния берём первый
поезд в каждую сторону, уходящий не раньше чем через минуту после
прибытия, и едем до любой неосмотренной станции на его пути. Когда
осмотрено всё, добавляем ожидание и поездку прямо на S. При n = N это
`O(2ⁿ · n²)`.

Тонкие места:

- уехать на том же поезде, на котором турист приехал, нельзя: следующее
  отправление не раньше чем через минуту;
- время в пути может быть 0, и тогда несколько станций стоят в одном
  месте (тесты 05, 09);
- поездка может проходить неосмотренные станции без остановки;
- при N = 1 ответ 0 (тест 02).

Динамика сравнивалась на 400 маленьких случаях (N ≤ 6, короткие
перегоны и периоды) с поиском по настоящему расписанию, включая первые
поезда, любой начальный поезд и выходы на осмотренных станциях.

## Особенности языков

- Все языки выполняют одну и ту же динамику по плоскому массиву из
  2ⁿ · n моментов прибытия.
- CPython тратит около 1,3 с на самых больших тестах, больше лимита,
  поэтому решение на Python отправляется под PyPy 3.10.
