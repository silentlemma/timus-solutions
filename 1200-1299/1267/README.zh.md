# 1267. 叶卡捷琳堡地铁

[Timus 1267](https://acm.timus.ru/problem.aspx?space=1&num=1267) · 难度 1729 · dp

原题作者 Leonid Volkov（由 Leonid Volkov 和 Alexander Somov 准备），出自 2003 年 10 月 25 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一条地铁线有 N 个车站（1 ≤ N ≤ 16），相邻车站间的行车时间为整分钟（每段不超过 10⁵，
可以为 0）。从 1 号站开往 N 号站的列车从第 A 分钟起每 P 分钟一班，从 N 号站开往 1 号站的
列车从第 B 分钟起每 P 分钟一班（1 ≤ P ≤ 10⁵，0 ≤ A, B ≤ P）；每班车开到另一端后就离开
线路。停站是瞬时的。游客从 S 站出发，可以上任意一班车，必须在其他每个车站下车参观，连同
上车共需 59 秒，所以从一个车站乘坐的下一班车至少在到达一分钟后才出发。最后游客回到
S 站。求从第一次上车到最后到达 S 站的最短时间。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N − 1 个行车时间，然后是 S，然后是 P、A 和 B。

## 输出

最短用时（分钟）。

## 样例

### 样例 1

输入：

```
3
5 7
2
4 0 1
```

输出：

```
28
```

## 解法

三个观察使问题变简单。

- 出发时间可以自由选择，而当首班车都开到远端之后，时刻表以 P 为周期重复。晚整数个周期
  出发，用到的是相对时刻相同的同样的列车，所以可以认为列车永远在运行：开往 N 的列车在
  A + pos(i) mod P 的时刻经过 i 站，开往 1 的列车在 B + pos(N) − pos(i) mod P 的时刻经过。
- 早到车站永远不会更差：可以等任何更晚的列车。所以对每个“已参观集合 + 当前车站”，只需
  记录最早到达时间。
- 在已参观的车站下车永远没有好处。继续向同一方向乘坐不如留在车上；而反方向的列车经过上
  一个车站的时刻晚于游客离开它的时刻，游客在那里等就能赶上。

对首班车的两个方向，各做一次以（已参观集合，车站）为状态、记录最早到达时间的 DP。从每个
状态出发，向两个方向各取到达后至少一分钟才发车的第一班车，乘到途中任意一个未参观的车站。
全部参观完后，加上直接回到 S 的那段车程。记 n = N，复杂度为 `O(2ⁿ · n²)`。

注意事项：

- 不能乘坐送游客来的那班车离开：下一次出发至少要晚一分钟；
- 行车时间可以为 0，此时几个车站位于同一处（测试 05、09）；
- 一次乘车可以经过未参观的车站而不停留；
- N = 1 时答案为 0（测试 02）。

在 400 个小规模数据（N ≤ 6，区间和周期都较短）上与按真实时刻表的搜索比较过，后者考虑了
首班车、任意的起始列车以及在已参观车站下车。

## 各语言说明

- 所有语言都在含 2ⁿ · n 个到达时间的一维数组上做同样的 DP。
