# 1202. Кратчайший путь через цепочку прямоугольников

[Timus 1202](https://acm.timus.ru/problem.aspx?space=1&num=1202) · сложность 442 · greedy

Автор оригинальной задачи — Леонид Волков; командное соревнование УрГУ, март 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

До `10⁵` прямоугольников на клетчатой бумаге образуют цепочку слева
направо: у первого левый нижний угол в `(0, 0)`, каждый начинается там,
где по горизонтали кончается предыдущий, и каждая сторона длиной от 2 до
100 клеток. Там, где соседи соприкасаются, их общая граница исчезает.
Путник идёт по линиям сетки от `(1, 1)` до точки на клетку внутри
правого верхнего угла последнего прямоугольника, не может идти по
границам прямоугольников и переходит из прямоугольника в следующий
только через исчезнувшую часть границы. Найти длину кратчайшего пути или
`-1`, если пути нет.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`n`, затем каждый прямоугольник как `x1 y1 x2 y2` — левый нижний и
правый верхний углы.

## Выходные данные

Длина кратчайшего пути или `-1`.

## Примеры

### Пример 1

Ввод:

```
2
0 0 3 5
3 1 5 7
```

Вывод:

```
8
```

## Решение

Путь должен попасть из `x = 1` в `x = x2 − 1` последнего прямоугольника,
и это всегда можно сделать, ни разу не шагая влево, так что
горизонтальная часть фиксирована. Между прямоугольниками `i` и `i + 1`
путь пересекает прямую `x = x2ᵢ` на целой высоте строго внутри обоих
прямоугольников, то есть в `[max(y1) + 1, min(y2) − 1]`; если этот
диапазон пуст, пути нет. Внутри прямоугольника высоту можно менять как
угодно по внутренней вертикальной линии, поэтому вертикальная длина —
суммарное изменение высоты между стартом, выбранными высотами переходов
и целью.

Чтобы её минимизировать, двигаемся только по необходимости: держим
текущую высоту и на каждой границе загоняем её в допустимый диапазон. По
индукции самый дешёвый способ оказаться на высоте `h` после границы `i`
стоит жадную сумму плюс `|h − жадная высота|`, так что жадный выбор
никогда не хуже. `O(n)`.

Тонкие места:

- прямоугольники, соприкасающиеся меньше чем на две единицы или только
  углом, не оставляют перехода вовсе;
- прямоугольники могут заходить ниже нуля;
- при одном прямоугольнике ответ — просто расстояние от `(1, 1)` до цели,
  а для прямоугольника 2×2 это 0.

Ответы сверены с отдельно написанным решением на 400 случайных цепочках и
на всех тестах.
