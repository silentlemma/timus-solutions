# 1202. 穿过一串矩形的最短路

[Timus 1202](https://acm.timus.ru/problem.aspx?space=1&num=1202) · 难度 442 · greedy

原题作者 Leonid Volkov，出自 2002 年 3 月乌拉尔国立大学团体赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

方格纸上最多 `10⁵` 个矩形从左到右连成一串：第一个的左下角在 `(0, 0)`，每个矩形
在水平方向上从前一个结束的地方开始，每条边长 2 到 100 格。相邻矩形接触处的公共
边界消失。旅行者沿网格线从 `(1, 1)` 走到最后一个矩形右上角向内一格的点，不能
沿任何矩形边界走，只能通过消失的那部分边界从一个矩形进入下一个。求最短路长度，
没有路时输出 `-1`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`n`，然后每个矩形一行 `x1 y1 x2 y2`，分别是左下角和右上角。

## 输出

最短路的长度，或 `-1`。

## 样例

### 样例 1

输入：

```
2
0 0 3 5
3 1 5 7
```

输出：

```
8
```

## 解法

路径要从 `x = 1` 走到最后一个矩形的 `x = x2 − 1`，而且总能做到从不向左走，所以
水平部分是固定的。在矩形 `i` 和 `i + 1` 之间，路径在严格位于两个矩形内部的某个
整数高度上穿过直线 `x = x2ᵢ`，即高度在 `[max(y1) + 1, min(y2) − 1]` 中；如果
这个范围为空就无路可走。在矩形内部可以沿内部的竖线任意改变高度，所以竖直长度就是
起点、所选的各个穿越高度和终点之间高度变化的总和。

要使它最小，只在被迫时移动：保持当前高度，在每条边界处把它夹到允许范围内。由归纳
可知，在第 `i` 条边界之后站在高度 `h` 的最小代价等于目前的贪心总和加上
`|h − 贪心高度|`，所以贪心选择永远不会更差。`O(n)`。

注意事项：

- 只接触不到两个单位、或者只在角上接触的矩形之间根本没有通道；
- 矩形可能延伸到零以下；
- 只有一个矩形时，答案就是 `(1, 1)` 到终点的距离，2×2 的矩形答案为 0。

答案已在 400 条随机矩形链和所有测试上与另一份独立解答比对。
