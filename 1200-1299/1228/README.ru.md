# 1228. Границы массива по множителям индексов

[Timus 1228](https://acm.timus.ru/problem.aspx?space=1&num=1228) · сложность 108 · math

Оригинальная задача — четвертьфинал ACM ICPC 2002–2003, центральный регион России, Рыбинск, октябрь 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`n`-мерный массив `array[0..k1, 0..k2, …, 0..kn]`, `n ≤ 20`, хранится так,
что быстрее всех меняется последний индекс, поэтому элемент
`X[i1, …, in]` имеет номер `1 + D1·i1 + … + Dn·in` при некоторых
множителях `Di`. По множителям и общему числу элементов `s` найти верхние
границы `k1, …, kn`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`n` и `s`, затем `D1, …, Dn`.

## Выходные данные

`k1, …, kn` через пробелы или переводы строк.

## Примеры

### Пример 1

Ввод:

```
3 24
8
4
1
```

Вывод:

```
2 1 3
```

## Решение

Увеличение индекса `i` на единицу пропускает целый блок последующих
размерностей, так что `D(i−1) = Di · (ki + 1)`, а весь массив — один блок
первой размерности: `s = D1 · (k1 + 1)`. Если поставить `s` перед
множителями, каждая граница на единицу меньше частного двух соседей:
`k1 = s/D1 − 1` и `ki = D(i−1)/Di − 1`. `O(n)`.

Тонкие места:

- последний множитель всегда 1, а первая граница получается из `s`, а не
  из множителя;
- произведения доходят почти до `2³¹`, так что по ходу не стоит считать в
  32-битных знаковых целых.

Границы проверены обратным перемножением в `s` на 59 сгенерированных
массивах и сверены с отдельно написанным решением на всех тестах.

## Особенности языков

- Во всех языках `s` ставится перед множителями, и делятся соседи.
