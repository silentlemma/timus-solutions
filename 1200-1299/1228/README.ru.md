# 1228. Границы массива по множителям индексов

[Timus 1228](https://acm.timus.ru/problem.aspx?space=1&num=1228) · сложность 109 · math

Оригинальная задача — четвертьфинал ACM ICPC 2002–2003, центральный регион России, Рыбинск, октябрь 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`n`-мерный массив `array[0..k1, 0..k2, …, 0..kn]`, `n ≤ 20`, хранится так,
что быстрее всех меняется последний индекс, поэтому элемент
`X[i1, …, in]` имеет номер `1 + D1·i1 + … + Dn·in` при некоторых
множителях `Di`. По множителям и общему числу элементов `s` найти верхние
границы `k1, …, kn`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`n` (`1 ≤ n ≤ 20`) и `s` (`1 ≤ s < 2³¹ − 1`), затем `D1, …, Dn`.

## Выходные данные

`k1, …, kn` (`0 < ki ≤ 1000`) через пробелы или переводы строк.

## Примеры

### Пример 1

Ввод:

```
3 24
8
4
1
```

Вывод:

```
2 1 3
```

## Решение

Увеличение индекса `i` на единицу пропускает целый блок последующих
размерностей, так что `D(i−1) = Di · (ki + 1)`, а весь массив — один блок
первой размерности: `s = D1 · (k1 + 1)`. Если поставить `s` перед
множителями, каждая граница на единицу меньше частного двух соседей:
`k1 = s/D1 − 1` и `ki = D(i−1)/Di − 1`. `O(n)`.

Тонкие места:

- последний множитель всегда 1, а первая граница получается из `s`, а не
  из множителя;
- произведения меньше `2³¹ − 1`, поэтому для вычислений достаточно
  32-битных знаковых целых.

Границы проверены перемножением `ki + 1` в `s` на 59 сгенерированных
массивах и сверены с отдельно написанным решением на всех тестах.

## Оптимизированные решения

Оптимизированное решение на C++ читает множители по одному и хранит
только предыдущий, печатая каждую границу, как только приходит её
делитель, вместо того чтобы держать `s` и все множители в `std::vector`:
{1228_math_optimized.cpp}.

Оптимизированное решение на Java разбирает числа по цифрам прямо из
`System.in` вместо создания `Scanner` и хранит только предыдущий
множитель вместо массива всех множителей: {1228_math_optimized.java}.
