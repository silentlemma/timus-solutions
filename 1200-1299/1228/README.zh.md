# 1228. 由下标乘数求数组的上界

[Timus 1228](https://acm.timus.ru/problem.aspx?space=1&num=1228) · 难度 109 · math

原题出自 2002 年 10 月在雷宾斯克举行的 ACM ICPC 2002–2003 俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`n` 维数组 `array[0..k1, 0..k2, …, 0..kn]`（`n ≤ 20`）按最后一个下标变化最快的方式
排列，所以元素 `X[i1, …, in]` 的序号是 `1 + D1·i1 + … + Dn·in`，其中 `Di` 是某些
乘数。已知各乘数和元素总数 `s`，求上界 `k1, …, kn`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`n`（`1 ≤ n ≤ 20`）和 `s`（`1 ≤ s < 2³¹ − 1`），然后是 `D1, …, Dn`。

## 输出

`k1, …, kn`（`0 < ki ≤ 1000`），以空格或换行分隔。

## 评测方式

仓库测试精确比较输出记号，记号之间的空白分隔不影响结果。

## 样例

### 样例 1

输入：

```
3 24
8
4
1
```

输出：

```
2 1 3
```

## 解法

下标 `i` 增加 1 会跳过其后各维组成的一整块，所以 `D(i−1) = Di · (ki + 1)`，而整个
数组就是第一维的一块：`s = D1 · (k1 + 1)`。把 `s` 放在乘数前面，每个上界就是相邻
两数之商减一：`k1 = s/D1 − 1`，`ki = D(i−1)/Di − 1`。`O(n)`。

注意事项：

- 最后一个乘数总是 1，而第一个上界来自 `s`，不是来自乘数；
- 乘积小于 `2³¹ − 1`，所以 32 位有符号整数足以完成计算。

上界已在 59 个生成的数组上通过将 `ki + 1` 相乘还原 `s` 验证，并在所有测试上
与另一份独立解答比对。

## 优化解法

优化的 C++ 解法逐个读入乘数，只保留前一个，每读到一个除数就立即输出对应的上界，
而不是把 `s` 和全部乘数存进 `std::vector`：{1228_math_optimized.cpp}。

优化的 Java 解法直接从 `System.in` 逐位解析数字，而不是创建 `Scanner`，并且只保
留前一个乘数，而不是保存全部乘数的数组：{1228_math_optimized.java}。
