# 1222. Наибольшее произведение чисел с заданной суммой

## Задача

У стаи орлов всего `N ≤ 3000` голов, а её IQ равен произведению числа
голов её орлов. Найти наибольший возможный IQ, то есть наибольшее
произведение натуральных чисел с суммой `N`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

Наибольшее произведение.

## Примеры

### Пример 1

Ввод:

```
5
```

Вывод:

```
6
```

## Решение

Слагаемое 4 и больше можно разбить на 2 и остаток, не уменьшив
произведение, а слагаемое 5 и больше так его увеличивает
(`2(k − 2) > k` при `k > 4`), слагаемое же 1 только тратит голову. Значит,
в оптимальном разбиении только двойки, тройки и четвёрки, а 4 — то же,
что 2 + 2. Три двойки хуже двух троек (`8 < 9`), так что двоек не больше
двух. Остаётся: одни тройки, когда `N` делится на 3, ещё одна двойка при
остатке 2 и две двойки (или одна четвёрка) вместо тройки при остатке 1.
При `N` до 3 лучше всего один орёл. В произведении до 478 цифр. `O(N²)`
операций с цифрами для многократного умножения на 3.

Тонкие места:

- `N = 1` даёт 1, а `N = 4` даёт 4;
- остаток 1 нельзя оставлять множителем 1;
- ответ далеко за пределами 64 бит.

Ответы проверены перебором всех разбиений для каждого `N` до 59 и сверены
с отдельно написанным решением на всех тестах.
