# 1222. 给定和的数的最大乘积

[Timus 1222](https://acm.timus.ru/problem.aspx?space=1&num=1222) · 难度 144 · math

原题为民间流传的题目，由 Leonid Volkov 提供，出自第七届乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一群鹰总共有 `1 ≤ N ≤ 3000` 个头，这群鹰的智商等于各只鹰头数的乘积。求可能的
最大智商，也就是和为 `N` 的若干正整数的最大乘积。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`。

## 输出

最大的乘积。

## 评测方式

仓库测试比较完整输出文本，仅忽略末尾空白。应保留有意义的空格、换行、大小写及标点。

## 样例

### 样例 1

输入：

```
7
```

输出：

```
12
```

## 解法

大于等于 4 的部分可以拆成 2 和剩余部分而不降低乘积，大于等于 5 的部分这样拆还会
增大乘积（`k > 4` 时 `2(k − 2) > k`），而 1 只会浪费一个头。所以最优拆分只含 2、
3 和 4，而 4 和 2 + 2 一样。三个 2 不如两个 3（`8 < 9`），所以 2 最多两个。于是：
`N` 能被 3 整除时全用 3；余数为 2 时再加一个 2；余数为 1 时用两个 2（或一个 4）
代替一个 3。`N` 不超过 3 时一只鹰最好。乘积最多 478 位。反复乘以 3 共需 `O(N²)`
次数字运算。

答案有O(N)位。动态十进制向量、大整数及十进制输出占O(N)活跃值/输出空间，另计库算术工作区；优化C++实际保留固定1000项数字数组。重复小乘法可用保守O(N²)数字工作界。库求幂使用较大乘法，共同上界不意味着内置求幂重复N次乘法。

注意事项：

- `N = 1` 得 1，`N = 4` 得 4；
- 余数 1 不能作为因子 1 留下；
- 答案远远超出 64 位。

答案已对每个不超过 59 的 `N` 用枚举所有拆分的方法验证，并在所有测试上与另一份
独立解答比对。

## 优化解法

`1222_math_optimized.java`. 保留最优拆三、余一改为乘四的规则，N<4 单独处理。同一乘积以 10^9 进制块、至多 3^18 的运行时乘数计算，不用 BigInteger 或预存答案。每个 long 中间值小于 10^9*3^18<2^63，输出时低位块补足九位。保守上界 O(N²) 算术工作、O(N) 空间；保留简单数学版。

- `1222_math_optimized.java`: 0.093 s / 348 KB; 保留教学基础版 `1222_math.java`: 0.093 s / 1708 KB.

`1222_math_optimized.rs`. 保留最优三的分解，余一改用四。每个 u32 数位打包九位十进制而非一位，直接输出补足九位的组，不构造十进制 String。乘三适合 u32，因为 3*(10^9-1)+2<2^32。反复小数乘法仍需 O(n²) 数位运算、O(n) 输出位存储，收益是表示更紧凑而非新渐近算法。保留简单十进制数位版。

与 `1222_math.rs` 相比：时间 0.031 s → 0.015 s；内存 208 KB → 64 KB。

优化的 C++ 解法对一个固定的、有 1000 位十进制数字的全局数组做乘法，而不是用随乘
积增长的 `std::vector`，因此程序不需要动态内存；当 `N ≤ 3000` 时乘积至多
478 位：{1222_math_optimized.cpp}。
