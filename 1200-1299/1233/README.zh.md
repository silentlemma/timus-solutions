# 1233. 数在字典序中的位置

[Timus 1233](https://acm.timus.ru/problem.aspx?space=1&num=1233) · 难度 907 · math

原题作者 Andrew Stankevich，出自 2002–2003 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把 1 到 N 的数当作字符串按字典序排列：N = 11 时是 1, 10, 11, 2, 3, …, 9。给定
K 和 M（1 ≤ K, M ≤ 10⁹），求使 K 位于第 M 位的最小 N，若不存在则报告。

时间限制：1 秒。内存限制：64 MB。

## 输入

K 和 M。

## 输出

最小的这样的 N，若不存在则输出 0。

## 样例

### 样例 1

输入：

```
2 4
```

输出：

```
11
```

### 样例 2

输入：

```
2 1
```

输出：

```
0
```

## 解法

取 N ≥ K，统计排在 K 之前（含 K）的数。

- **不比 K 长的数。** 对每个长度 l，这些数是从 `10^(l−1)` 到 K 的前 l 位。它们
  都不超过 K，所以任何 N ≥ K 都包含它们；它们的个数 B 就是 N = K 时 K 的位置。
- **比 K 长的数。** 长度为 `len(K) + j` 的数排在 K 之前当且仅当它小于
  `K·10^j`，所以对每个 j ≥ 1 共有 `K·10^j − 10^(len(K)+j−1)` 个。

当 N 从 K 开始增大时，K 的位置恰好在 N 本身是排在 K 之前的较长数时加一。因此若
M < B 则无解，若 M = B 答案为 K，否则 N 是按大小排列的第 (M − B) 个排在 K 之前
的较长数：先整段减去各个长度，再在第一个没有用完的长度内计数。解析所有前缀共处理
`1 + 2 + ... + len(K)` 位数字；较长长度的循环需要 `O(log M)` 次迭代（在本题限制下
最多九次）。若整数运算按常数时间计，总时间为 `O((log K)^2 + log M)`。

注意事项：

- 10 的幂之前没有任何较长的数，所以它的位置永远不变（测试 04、08、11）；
- N 可能远超 32 位：K = 100000001 之前每个较长长度只有 `10^j` 个数，M = 10⁹ 时
  答案有 18 位（测试 10）；
- 较长长度的数量取决于 M，因此仅按解析 K 来估计时间会漏掉这部分工作（测试 09、10）。

## 各语言说明

- C++、Go、Java 和 Rust 使用有符号 64 位整数，Python 使用任意精度整数。当 K 不是
  10 的幂时循环在九个长度内结束，所以 `K·10^j` 始终小于 10¹⁸。
