# 1233. Место числа в словарном порядке

[Timus 1233](https://acm.timus.ru/problem.aspx?space=1&num=1233) · сложность 907 · math

Автор оригинальной задачи — Андрей Станкевич; полуфинал ACM ICPC Северо-Восточной Европы 2002–2003.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Запишем числа от 1 до N в лексикографическом порядке, как строки: при
N = 11 это 1, 10, 11, 2, 3, …, 9. По данным K и M (1 ≤ K, M ≤ 10⁹) найти
наименьшее N, при котором K стоит на месте M, или сообщить, что такого
нет.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

K и M.

## Выходные данные

Наименьшее такое N или 0, если его нет.

## Примеры

### Пример 1

Ввод:

```
2 4
```

Вывод:

```
11
```

### Пример 2

Ввод:

```
2 1
```

Вывод:

```
0
```

## Решение

Возьмём N ≥ K и посчитаем числа, стоящие не позже K.

- **Не длиннее K.** Для каждой длины l это числа от `10^(l−1)` до первых
  l цифр K. Все они не больше K, так что есть при любом N ≥ K; их
  количество B — место K при N = K.
- **Длиннее K.** Число длины `len(K) + j` стоит раньше K ровно тогда,
  когда оно меньше `K·10^j`, так что для каждого j ≥ 1 таких
  `K·10^j − 10^(len(K)+j−1)`.

Когда N растёт после K, место K увеличивается на единицу ровно тогда,
когда само N — одно из более длинных чисел, стоящих раньше K. Поэтому при
M < B ответа нет, при M = B ответ — K, а иначе N — (M − B)-е по
возрастанию более длинное число перед K: вычитаем целые длины, а затем
отсчитываем внутри первой неисчерпанной длины. При разборе всех префиксов
обрабатываются `1 + 2 + ... + len(K)` цифр; цикл по большим длинам делает
`O(log M)` итераций (не больше девяти при данных ограничениях). Если считать
целочисленную арифметику единичной операцией, время — `O((log K)^2 + log M)`.

Тонкие места:

- перед степенью десяти не стоит ни одно более длинное число, так что её
  место не меняется (тесты 04, 08, 11);
- N может далеко выходить за 32 бита: перед K = 100000001 стоят лишь
  `10^j` чисел каждой большей длины, и при M = 10⁹ ответ состоит из 18
  цифр (тест 10);
- число больших длин зависит от M, поэтому оценка времени только по
  разбору K не учитывает эту работу (тесты 09, 10).

## Особенности языков

- C++, Go, Java и Rust используют знаковые 64-битные целые, а Python —
  целые произвольной точности. `K·10^j` остаётся меньше 10¹⁸, потому что,
  если K не степень десяти, цикл заканчивается за девять длин.
