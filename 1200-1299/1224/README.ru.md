# 1224. Повороты робота, обходящего прямоугольник по спирали

[Timus 1224](https://acm.timus.ru/problem.aspx?space=1&num=1224) · сложность 66 · math

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Робот начинает в левой верхней клетке поля из `N` строк и `M` столбцов,
оба до `2³¹ − 1`, двигаясь вправо, и обходит все клетки по спирали по
часовой стрелке, закручивающейся к середине. Посчитать его повороты.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `M`.

## Выходные данные

Число поворотов.

## Примеры

### Пример 1

Ввод:

```
3 5
```

Вывод:

```
4
```

## Решение

Путь чередует горизонтальные и вертикальные отрезки, начиная с
горизонтального, и поворачивает один раз между двумя отрезками. Каждый
горизонтальный отрезок съедает строку, а каждый вертикальный — столбец,
ведь спираль снимает поле снаружи.

Если `N ≤ M`, первыми кончаются строки — после `N` горизонтальных и
`N − 1` вертикальных отрезков, то есть `2N − 1` отрезков и `2(N − 1)`
поворотов. Иначе первыми кончаются столбцы — после `M` отрезков каждого
вида: `2M` отрезков и `2M − 1` поворотов. `O(1)`.

Тонкие места:

- одна строка не требует ни одного поворота, а один столбец требует
  одного, ведь робот начинает движение вправо;
- ответ доходит примерно до `4.3·10⁹`, больше 32-битных целых.

Формула проверена моделированием робота на всех полях до 14 × 14 и
сверена с отдельно написанным решением на всех тестах.
