# 1224. Повороты робота, обходящего прямоугольник по спирали

[Timus 1224](https://acm.timus.ru/problem.aspx?space=1&num=1224) · сложность 65 · math

Оригинальная задача — четвертьфинал ACM ICPC 2002–2003, центральный регион России, Рыбинск, октябрь 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Робот начинает в левой верхней клетке поля из `N` строк и `M` столбцов,
оба до `2³¹ − 1`, двигаясь вправо, и обходит все клетки по спирали по
часовой стрелке, закручивающейся к середине. Посчитать его повороты.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `M`.

## Выходные данные

Число поворотов.

## Проверка

Тесты репозитория точно сравнивают токены вывода; пробельные разделители между ними несущественны.

## Примеры

### Пример 1

Ввод:

```
3 5
```

Вывод:

```
4
```

## Решение

Путь чередует горизонтальные и вертикальные отрезки, начиная с
горизонтального, и поворачивает один раз между двумя отрезками. Каждый
горизонтальный отрезок съедает строку, а каждый вертикальный — столбец,
ведь спираль снимает поле снаружи.

Если `N ≤ M`, первыми кончаются строки — после `N` горизонтальных и
`N − 1` вертикальных отрезков, то есть `2N − 1` отрезков и `2(N − 1)`
поворотов. Иначе первыми кончаются столбцы — после `M` отрезков каждого
вида: `2M` отрезков и `2M − 1` поворотов. `O(1)`.

Тонкие места:

- одна строка не требует ни одного поворота, а один столбец при `N > 1` требует
  одного, ведь робот начинает движение вправо;
- ответ доходит примерно до `4.3·10⁹`, больше знаковых 32-битных целых.

Формула проверена моделированием робота на всех полях до 14 × 14 и
сверена с отдельно написанным решением на всех тестах.

## Оптимизированные решения

Оптимизированное решение на Java читает ввод блоками по 1 КБ и разбирает
два числа вручную вместо `Scanner`: 348 КБ вместо 1564 КБ при том же
времени.

`1224_math_optimized.py`. Сохраняется формула поворотов спирали: 2*(N-1) при N<=M, иначе 2*M-1. Отдельная строка или столбец учитываются без симуляции. При заданных размерах ответ может выйти за знаковые 32 бита, поэтому Rust использует i64, Python — точные целые. O(1) ограниченной арифметики и памяти. Два размера читаются из сырых байтовых токенов; нового алгоритма обхода спирали нет. Самостоятельная программа для судьи явно сбрасывает stdout перед os._exit(0), пропуская обычное завершение интерпретатора. Выигрыш памяти подтверждён её собственным Accepted. Сама смена способа завершения не улучшает асимптотику, а её эффект в среде выполнения не гарантируется на других платформах. Простая версия сохранена без изменений.

По сравнению с `1224_math.py`: время 0.078 s → 0.125 s; память 372 KB → 196 KB.

`1224_math_optimized.rs`. Сохраняется формула поворотов спирали: 2*(N-1) при N<=M, иначе 2*M-1. Отдельная строка или столбец учитываются без симуляции. При заданных размерах ответ может выйти за знаковые 32 бита, поэтому Rust использует i64, Python — точные целые. O(1) ограниченной арифметики и памяти. Хранятся только два размера и ответ вместо входной String и вектора значений. Rust-версия читает и пишет через среду выполнения C, без сохранения декодированной входной String и построения форматированной строки ответа. Простой исходник с Accepted сохранён.

По сравнению с `1224_math.rs`: время 0.031 s → 0.015 s; память 208 KB → 56 KB.
