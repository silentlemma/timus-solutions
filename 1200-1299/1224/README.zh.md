# 1224. 沿螺旋扫过矩形的机器人转弯次数

[Timus 1224](https://acm.timus.ru/problem.aspx?space=1&num=1224) · 难度 66 · math

原题出自 2002 年 10 月在雷宾斯克举行的 ACM ICPC 2002–2003 俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

机器人从 `N` 行 `M` 列（都不超过 `2³¹ − 1`）区域的左上格出发，向右前进，沿着向
中心收拢的顺时针螺旋覆盖所有格子。统计它转弯的次数。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N` 和 `M`。

## 输出

转弯次数。

## 样例

### 样例 1

输入：

```
3 5
```

输出：

```
4
```

## 解法

路径交替地走横段和竖段，从横段开始，相邻两段之间转一次弯。螺旋从外向内剥开
区域，每个横段用掉一行，每个竖段用掉一列。

若 `N ≤ M`，行先用完：共 `N` 个横段和 `N − 1` 个竖段，即 `2N − 1` 段、
`2(N − 1)` 次转弯。否则列先用完：两种段各 `M` 个，共 `2M` 段、`2M − 1` 次转弯。
`O(1)`。

注意事项：

- 只有一行时一次也不用转，只有一列时却要转一次，因为机器人开始时向右走；
- 答案可达约 `4.3·10⁹`，超出 32 位整数。

公式已在不超过 14 × 14 的所有区域上用模拟机器人验证，并在所有测试上与另一份
独立解答比对。
