# 1256. Кладбищенский сторож

## Задача

Две собаки сидят на цепях длины R4 у двух столбов. Домик сторожа
находится в R1 от первого столба и в R2 от второго; между столбами R3
(0 ≤ R1, R2, R3 ≤ 20000, 1 ≤ R4 ≤ 20000). Сторож выходит из домика,
ставит миски так, чтобы каждая собака дотянулась до своей, и
возвращается. Найти длину кратчайшего такого обхода с тремя знаками
после точки. Обратный путь входит в ответ: в примере это 1750 туда и
1750 обратно.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

R1, R2, R3 в первой строке (возможно, дробные), целое R4 во второй.

## Выходные данные

Длина кратчайшего обхода.

## Примеры

### Пример 1

Ввод:

```
1000 2000 1000
250
```

Вывод:

```
3500.000
```

## Решение

Каждая собака достаёт до круга радиуса R = R4 вокруг своего столба.
Поставим столб A в начало координат, столб B в точку (R3, 0), а домик H
на расстояниях R1 и R2 от них. Обход — это H → P → Q → H, где P в круге
A, а Q в круге B; другой порядок — тот же обход в обратную сторону.

Если домик внутри одного из кругов, эту собаку кормят у порога, а идти
нужно только до другого круга и обратно:
2 · max(0, max(R1, R2) − R).

Иначе зафиксируем P. Если отрезок от P до H пересекает круг B, вторая
миска ставится по пути домой, и остаток обхода равен просто |PH|. Если
нет, Q лежит на окружности B; путь P → Q → H считается в 24 точках
окружности и затем уточняется поиском золотого сечения рядом с лучшей
из них.

Полная длина |HP| + (лучший путь от P через круг B к H) выпукла по P:
сумма |PQ| + |QH| выпукла по паре (P, Q), а минимум по Q из выпуклого
круга сохраняет выпуклость. Поэтому поиск золотого сечения по x от
поисков золотого сечения по y внутри круга A находит минимум. При S = 70
шагах на поиск и K = 24 точках это `O(S² · (K + S))`, около миллиона
расстояний в худшем случае.

Тонкие места:

- домик может быть внутри одного круга или обоих (тесты 02, 03);
- совпадающие столбы, R3 = 0 (тест 04), требуют отдельной обработки,
  чтобы избежать деления на ноль;
- если три точки лежат на одной прямой (тесты 01, 06, 07), округление
  может сделать квадрат высоты домика чуть отрицательным;
- расстояния во входе могут быть дробными (тест 11).

Ответы сравнивались с перебором по плотной сетке для обеих мисок на 150
случайных случаях и с независимым поиском по углам на двух окружностях
ещё на 200.

## Особенности языков

- Все языки выполняют одни и те же вложенные поиски.
- В C++ π берётся как `acos(-1)`, так как `M_PI` не входит в стандарт.
- Java читает числа через `StreamTokenizer`, который принимает и дробные,
  и печатает с `Locale.ROOT`, чтобы получить десятичную точку.
