# 1256. 墓地看守

[Timus 1256](https://acm.timus.ru/problem.aspx?space=1&num=1256) · 难度 2233 · geometry

原题作者 Alexander Petrov（由 Alexander Mironenko 准备），出自 2003 年 3 月 15 日乌拉尔国立大学公开团体赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两条狗分别用长度为 R4 的链子拴在两根柱子上。看守的小屋到第一根柱子 R1，到第二根柱子
R2；两根柱子相距 R3（0 ≤ R1, R2, R3 ≤ 20000，1 ≤ R4 ≤ 20000）。看守从小屋出发，把
食盆放在每条狗都够得到的地方，然后回家。求这样一次行走的最短长度，保留小数点后三位。
回程也要计入：样例中去程 1750，回程 1750。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行 R1、R2、R3（可能是小数），第二行整数 R4。

## 输出

最短行走长度。

## 样例

### 样例 1

输入：

```
1000 2000 1000
250
```

输出：

```
3500.000
```

## 解法

每条狗能够到以其柱子为圆心、半径 R = R4 的圆盘。把柱子 A 放在原点，柱子 B 放在
(R3, 0)，小屋 H 放在与它们距离为 R1 和 R2 的位置。行走路线是 H → P → Q → H，其中 P
在圆盘 A 内，Q 在圆盘 B 内；另一种顺序就是同一路线反着走。

如果小屋在某个圆盘内，那条狗在门口就能喂，只需走到另一个圆盘再回来：
2 · max(0, max(R1, R2) − R)。

否则固定 P。若 P 到 H 的线段穿过圆盘 B，第二个食盆顺路放下，剩下的路就是 |PH|。
否则 Q 在圆 B 上；先在圆上取 24 个点计算 P → Q → H 的长度，再在最好的那个点附近用
黄金分割搜索细化。

总长度 |HP| +（从 P 经过圆盘 B 回到 H 的最短路）关于 P 是凸的：|PQ| + |QH| 关于
(P, Q) 这一对是凸的，在凸的圆盘上对 Q 取最小值后仍是凸的。因此在圆盘 A 内，对 x
做黄金分割搜索、内层对 y 做黄金分割搜索，就能找到最小值。每次搜索 S = 70 步、取
K = 24 个点，复杂度 `O(S² · (K + S))`，最坏情况下约一百万次距离计算。

注意事项：

- 小屋可能在一个圆盘内，也可能同时在两个圆盘内（测试 02、03）；
- 两根柱子重合时，R3 = 0（测试 04），需特殊处理以避免除以零；
- 三点共线时，舍入可能使小屋高度的平方略小于零（测试 01、06、07）；
- 输入的距离可能是小数（测试 11）。

答案在 150 组随机数据上与对两个食盆的密集网格搜索比较过，另外 200 组与在两个圆上按
角度独立搜索的结果比较过。

## 各语言说明

- 所有语言执行相同的嵌套搜索。
- C++ 用 `acos(-1)` 得到 π，因为 `M_PI` 不属于标准。
- Java 用 `StreamTokenizer` 读数，它也接受小数；输出时用 `Locale.ROOT` 保证小数点。
