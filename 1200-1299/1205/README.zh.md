# 1205. 步行加地铁穿城的最快路线

[Timus 1205](https://acm.timus.ru/problem.aspx?space=1&num=1205) · 难度 235 · graphs

原题作者 Alexander Klepinin，出自 2002 年 3 月乌拉尔国立大学团体赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

可以按一种速度步行到任何地方，也可以按不低于它的速度乘地铁，地铁在
`2 ≤ N ≤ 200` 个车站之间，由最多 400 条直线双向线路连接；只能在车站上下车和
换乘，且不花时间。求从 A 点到 B 点的最快路线及其经过的车站。

时间限制：1 秒。内存限制：64 MB。

## 输入

步行速度和地铁速度；`N` 和各车站坐标；线路，每条为两个车站编号，以 `0 0` 结束；
然后是 A 和 B。

## 输出

最短时间（精确到 `10⁻⁶`），然后是路线上的车站数以及按访问顺序排列的车站。

## 评测方式

可能有多条路线用时相同，所以只要输出的时间与路线本身的用时一致（从 A 步行到第一个
车站，相连的相邻车站之间乘车，不相连的之间步行，最后从最后一个车站步行到 B），
并且该时间最短，就判为正确。

## 样例

### 样例 1

输入：

```
1 100
4
0 0
1 0
9 0
9 9
1 2
1 3
2 4
0 0
10 10
10 0
```

输出：

```
2.6346295
4 4 2 1 3
```

## 解法

在车站、A 和 B 上建完全图：任意两点之间的代价是步行时间，相连的车站之间则是乘车
时间；在同一条直线上乘车永远不比步行慢。在这个有 `N + 2` 个顶点的稠密图上运行
Dijkstra 算法，每次用线性扫描选下一个顶点，就得到最短时间，前驱给出路线；去掉
A 和 B 就是途经的车站。`O(N²)`。

注意事项：

- 路线可以为空：速度相同或者地铁帮不上忙时，答案是直接步行，输出 `0` 个车站；
- 允许在两个车站之间步行，这可能是最优路线的一部分，比如走到附近换乘另一条线；
- 线路列表可以为空，`0 0` 紧跟在车站之后。

路线已在 200 个随机城市和所有测试上与另一份独立解答比对，评测程序双向检查。

  `Locale.US` 格式化时间。
