# 1259. Как стать звездой

## Задача

Зафиксируем угол α, 0 < α < π. Ломаная начинается отрезком от (0, 0)
до (1, 0); каждый следующий отрезок — это предыдущий, повёрнутый на α
против часовой стрелки вокруг своего свободного конца. Построение
останавливается, как только ломаная замкнулась, и получается звезда,
число вершин которой равно числу отрезков. Сколько существует разных
звёзд ровно с N вершинами (3 ≤ N ≤ 100 000)?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

Число звёзд с N вершинами.

## Примеры

### Пример 1

Ввод:

```
5
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
9
```

Вывод:

```
3
```

## Решение

Поворот отрезка на α вокруг дальнего конца даёт следующий отрезок,
направленный как предыдущий, повёрнутый на β = α + π. Значит, отрезки —
единичные векторы под углами 0, β, 2β, …, и ломаная замыкается после k
отрезков ровно тогда, когда их сумма равна нулю:

```text
1 + e^{iβ} + … + e^{i(k−1)β} = 0  ⇔  e^{ikβ} = 1 и e^{iβ} ≠ 1
```

Впервые замкнуться после N отрезков значит β = 2πm / N при
НОД(m, N) = 1. Так как π < β < 2π, m пробегает N/2 < m < N. Числа,
взаимно простые с N, разбиваются на пары m и N − m по разные стороны от
N/2 (при N ≥ 3 ни одно не равно N/2), поэтому ответ — φ(N) / 2, где
функция Эйлера φ находится перебором делителей. `O(√N)`.

Тонкие места:

- допустимы только повороты между π и 2π, поэтому ответ — половина
  φ(N), а не вся функция (звезда и её зеркальное отражение — разные
  ломаные, но лишь одна из них поворачивает против часовой стрелки на
  α < π);
- звезда должна впервые замкнуться именно на N: углы с НОД(m, N) > 1
  замыкаются раньше и дают звёзды с меньшим числом вершин.

Формула сравнивалась для всех N от 3 до 299 с суммированием единичных
шагов для каждого возможного угла и проверкой, когда сумма впервые
возвращается в ноль.

## Оптимизированные решения

Обе версии находят половину функции Эйлера, удаляя простые множители из остатка и обновляя функцию один раз на каждый различный множитель. Go сначала удаляет двойку и проверяет только нечётные делители. Rust сначала удаляет двойку и тройку, затем проверяет делители с остатками один и пять по модулю шесть. Перебор заканчивается, когда квадрат делителя превышает остаток. Обе версии читают и выводят единственное целое через малые фиксированные байтовые буферы без `Scanner` и форматирования строк. Go обращается прямо к стандартным дескрипторам, повторяет прерванные вызовы и завершает частичные записи. Rust читает и пишет через библиотеку времени исполнения C.

Принятая версия Rust 1.75 x64 заняла 0.046 с при 0.015 с у базовой и использовала 48 KB при 224 KB у базовой.

Принятые базовые реализации [1259_math.cpp](1259_math.cpp), [1259_math.java](1259_math.java), [1259_math.py](1259_math.py) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
