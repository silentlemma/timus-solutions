# 1259. 如何成为明星

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

固定角 α，0 < α < π。折线从 (0, 0) 到 (1, 0) 的线段开始；之后每一段都是前一段绕其自由
端逆时针旋转 α 得到的。折线一旦闭合就停止，得到一颗星，它的顶点数等于线段数。恰好有
N 个顶点（3 ≤ N ≤ 100 000）的不同的星有多少颗？

时间限制：1 秒。内存限制：64 MB。

## 输入

N。

## 输出

N 个顶点的星的数量。

## 样例

### 样例 1

输入：

```
5
```

输出：

```
2
```

### 样例 2

输入：

```
9
```

输出：

```
3
```

## 解法

把一段绕远端旋转 α，得到的下一段方向等于前一段方向转过 β = α + π。所以各段是角度为
0, β, 2β, … 的单位向量，折线在 k 段后闭合当且仅当它们的和为零：

```text
1 + e^{iβ} + … + e^{i(k−1)β} = 0  ⇔  e^{ikβ} = 1 且 e^{iβ} ≠ 1
```

在第 N 段时首次闭合，意味着 β = 2πm / N 且 gcd(m, N) = 1。由于 π < β < 2π，m 取
N/2 < m < N。与 N 互素的数按 m 和 N − m 成对出现，分在 N/2 两侧（N ≥ 3 时没有一个等于
N/2），所以答案是 φ(N) / 2，欧拉函数 φ 用试除求出。`O(√N)`。

注意事项：

- 转角只能在 π 和 2π 之间，所以答案是 φ(N) 的一半而不是全部（一颗星和它的镜像是不同的
  折线，但只有其中一条是按 α < π 逆时针旋转得到的）；
- 星必须恰好在第 N 段首次闭合：gcd(m, N) > 1 的角度会更早闭合，得到顶点更少的星。

对 3 到 299 的每个 N，把公式与以下做法比较过：对每个候选角度累加单位步长，记录和第一次
回到零的时刻。
