# 1259. 如何成为明星

[Timus 1259](https://acm.timus.ru/problem.aspx?space=1&num=1259) · 难度 398 · math

原题作者 Pavel Egorov，出自 2003 年 10 月 11 日斯维尔德洛夫斯克州中学生公开团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

固定角 α，0 < α < π。折线从 (0, 0) 到 (1, 0) 的线段开始；之后每一段都是前一段绕其自由
端逆时针旋转 α 得到的。折线一旦闭合就停止，得到一颗星，它的顶点数等于线段数。恰好有
N 个顶点（3 ≤ N ≤ 100 000）的不同的星有多少颗？

时间限制：1 秒。内存限制：64 MB。

## 输入

N。

## 输出

N 个顶点的星的数量。

## 样例

### 样例 1

输入：

```
5
```

输出：

```
2
```

### 样例 2

输入：

```
9
```

输出：

```
3
```

## 解法

把一段绕远端旋转 α，得到的下一段方向等于前一段方向转过 β = α + π。所以各段是角度为
0, β, 2β, … 的单位向量，折线在 k 段后闭合当且仅当它们的和为零：

```text
1 + e^{iβ} + … + e^{i(k−1)β} = 0  ⇔  e^{ikβ} = 1 且 e^{iβ} ≠ 1
```

在第 N 段时首次闭合，意味着 β = 2πm / N 且 gcd(m, N) = 1。由于 π < β < 2π，m 取
N/2 < m < N。与 N 互素的数按 m 和 N − m 成对出现，分在 N/2 两侧（N ≥ 3 时没有一个等于
N/2），所以答案是 φ(N) / 2，欧拉函数 φ 用试除求出。`O(√N)`。

注意事项：

- 转角只能在 π 和 2π 之间，所以答案是 φ(N) 的一半而不是全部（一颗星和它的镜像是不同的
  折线，但只有其中一条是按 α < π 逆时针旋转得到的）；
- 星必须恰好在第 N 段首次闭合：gcd(m, N) > 1 的角度会更早闭合，得到顶点更少的星。

对 3 到 299 的每个 N，把公式与以下做法比较过：对每个候选角度累加单位步长，记录和第一次
回到零的时刻。

## 优化解法

两个版本都通过消去剩余数的质因子计算欧拉函数的一半，每种质因子只更新一次欧拉函数。Go 先消去二，再只检查奇数因子。Rust 先消去二和三，再只检查模六余一或五的因子。因子的平方大于剩余数时停止。两个版本都通过小型固定字节缓冲区读写单个整数，不使用 `Scanner` 或字符串格式化。Go 直接访问标准句柄，重试被中断的调用并完成部分写入。Rust 通过 C 运行库读写。

通过评测的 Rust 1.75 x64 版本耗时 0.046 秒，基础版为 0.015 秒，内存为 48 KB，基础版为 224 KB。

已通过评测的基础实现 [1259_math.cpp](1259_math.cpp), [1259_math.java](1259_math.java), [1259_math.py](1259_math.py) 也满足快速版本的要求：在保存的比较快照中，时间和内存均符合前 15% 或前十名的排名收录规则。直接复用这些源文件，不创建相同副本。星号标记尚未达到该语言目标排名的版本。
