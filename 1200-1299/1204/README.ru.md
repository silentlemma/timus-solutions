# 1204. Идемпотенты по модулю произведения двух простых

[Timus 1204](https://acm.timus.ru/problem.aspx?space=1&num=1204) · сложность 229 · number_theory

Автор оригинальной задачи — Павел Атнашев; командное соревнование УрГУ, март 2002 года.

## Задача

Число `x` — идемпотент по модулю `n`, если `x·x ≡ x (mod n)`. Для
до 1000 значений `n < 10⁹`, каждое из которых — произведение двух
различных простых `p` и `q`, вывести все идемпотенты от `0` до `n − 1` по
возрастанию.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число тестов `k`, затем `n` для каждого теста.

## Выходные данные

Для каждого теста — его идемпотенты в одной строке по возрастанию.

## Примеры

### Пример 1

Ввод:

```
3
6
15
910186311
```

Вывод:

```
0 1 3 4
0 1 6 10
0 1 303395437 606790875
```

## Решение

`x(x − 1) ≡ 0 (mod pq)` значит, что каждое из `p` и `q` делит `x` или
`x − 1`, то есть по модулю каждого простого `x` равно 0 или 1. По
китайской теореме об остатках это даёт ровно четыре идемпотента: 0, 1,
число, равное 1 по модулю `p` и 0 по модулю `q`, и число, равное 0 по
модулю `p` и 1 по модулю `q`. Третье — `x = q·(q⁻¹ mod p)`, обратный
находится расширенным алгоритмом Евклида, а четвёртое — `n + 1 − x`,
потому что их сумма равна 1 по модулю обоих простых.

Чтобы разложить `n`, перебираем простые до `√10⁹ < 31623`, найденные один
раз решетом; меньший множитель среди них. Не больше примерно 3400 делений
на тест. `O(k·π(√n))`.

Тонкие места:

- два нетривиальных идемпотента нужно вывести по возрастанию, а меньшим
  может оказаться любой;
- пробным делением нужно найти только меньший множитель; больший, до
  `5·10⁸`, — это просто `n / p`;
- `p` может быть равно 2.

Ответы сверены с отдельно написанным решением на 3000 сгенерированных
произведениях всех трёх видов.

## Особенности языков

- Python берёт обратный через `pow(q, -1, p)`; остальные языки —
  расширенным алгоритмом Евклида.
