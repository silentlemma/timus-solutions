# 1223. Наименьшее число бросков яиц, находящее критический этаж

[Timus 1223](https://acm.timus.ru/problem.aspx?space=1&num=1223) · сложность 291 · dp

Оригинальная задача — фольклор, предложена Александром Клепининым; VII студенческое соревнование по программированию УрГУ.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Все яйца одинаково прочны: яйцо выдерживает падение с этажа `E` и ниже и
разбивается с любого более высокого. По числу яиц и этажей, каждое не
больше 1000, найти наименьшее число бросков, которое наверняка
определяет `E` в худшем случае; уцелевшие яйца можно бросать снова. До
1000 запросов, в конце `0 0`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

По запросу в строке: число яиц и число этажей.

## Выходные данные

Для каждого запроса — наименьшее число бросков в худшем случае.

## Примеры

### Пример 1

Ввод:

```
1 10
2 5
0 0
```

Вывод:

```
10
3
```

## Решение

Перевернём вопрос: сколько этажей можно различить за `d` бросков с `k`
яйцами? Первый бросок делается с какого-то этажа; если яйцо разбилось,
остаются этажи ниже с `d − 1` бросками и `k − 1` яйцами, а если уцелело —
этажи выше с `d − 1` бросками и `k` яйцами. Поэтому

`reach(d, k) = reach(d − 1, k − 1) + reach(d − 1, k) + 1`,

при `reach(0, k) = reach(d, 0) = 0`. Ответ для `n` этажей — наименьшее
`d` с `reach(d, k) ≥ n`. Десяти яиц уже хватает на обычный двоичный поиск
по 1000 этажам, так что больше яиц не помогает и `k` ограничивается 10.
Заполнение для каждого `k` ответов для всех `n` по мере роста `d` стоит
`O(10 · 1000)` один раз, а каждый запрос — просто взгляд в таблицу.

Тонкие места:

- с одним яйцом надёжен только путь этаж за этажом, так что ответ —
  число этажей;
- любое число яиц больше 10 ведёт себя как 10, поэтому число яиц
  ограничивается перед поиском в таблице;
- числа этажей растут как биномиальные коэффициенты, поэтому их тоже
  ограничиваем тысячей, иначе они переполнятся задолго до конца таблицы.

Ответы проверены прямой минимаксной рекуррентой для до 5 яиц и 60 этажей
и сверены с отдельно написанным решением на всех тестах.
