# 1223. 找出临界楼层最少要扔几次蛋

[Timus 1223](https://acm.timus.ru/problem.aspx?space=1&num=1223) · 难度 292 · dp

原题为民间流传的题目，由 Alexander Klepinin 提供，出自第七届乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

建筑物有编号为 1 到 `f` 的楼层，并有 `e` 个相同的蛋，`1 ≤ e, f ≤ 1000`。
未知的 `E` 在 `0..f` 内：从不高于 `E` 的楼层扔下蛋不会碎，从更高楼层扔下就会碎。
若在第一层就摔碎，则 `E = 0`；若从第 `f` 层扔下仍不碎，则 `E = f`。

求在最坏情况下确定 `E` 所需的最少扔蛋次数。没碎的蛋可以重复使用。
最多有 1000 个询问；`0 0` 结束输入，不是询问。

时间限制：1 秒。内存限制：64 MB。

## 输入

每行一个询问：蛋的个数和楼层数。

## 输出

对每个询问输出最坏情况下的最少次数。

## 评测方式

按查询顺序比较整数词元，0 0 不输出。五份新教学代码各通过13个
仓库Docker输入并有精确SHA的自身Accepted。实际教学Python检查21000个查询，
每批不超1000：蛋数1..20的所有楼层1..1000，加1000个随机查询，蛋数至1000。
独立预言机用闭式二项式和 `Σ C(d,i)` 与二分，不用两种DP。不是每门原生语言
各执行21000次。覆盖单蛋、单层、十及千蛋、容量恰好边界、1000查询和终止对。

## 样例

### 样例 1

输入：

```
1 10
2 5
0 0
```

输出：

```
10
3
```

## 解法

新的教学代码使用直接极小极大递推。令 `D(e,f)` 为 e 个蛋、f 层的
最少最坏情况次数。零层为零，`D(1,f)=f`。首扔 x 层：碎了还需处理 x−1 层、
少一个蛋；未碎还需 f−x 层、蛋数不变。故
`D(e,f)=1+min₁≤ₓ≤f max(D(e−1,x−1),D(e,f−x))`。任何策略都有首层并必须
处理两个结果，给出下界；选择最佳层并在两分支使用最优策略便达到它。

按蛋数和楼层递增计算，两项分别位于前一蛋数行或当前行更小楼层。
有 F+1 个阈值、每次两个结果，故至少 `ceil(log₂(F+1))` 次。十个蛋用普通
二分即可在 F≤1000 时达到此界，最多十次，每次至多损失一个蛋；更多蛋无益。
因此限制为十行有证明。E=10、F=1000 时预处理 `O(EF²)`，空间 `O(EF)`
整数单元，查询 `O(1)`。五份教学源码各获自身 Accepted，Python 用 PyPy3.10。
全部五份旧源码逐字节保留，没有重复的 optimized 副本。

## 优化解法

保留的 `dp` 反问：d 次、e 蛋最多解决多少层 R(d,e)？首扔分为
碎蛋分支、自身一层和未碎分支，所以
`R(d,e)=R(d−1,e−1)+1+R(d−1,e)`，边界为零。此分解必要且可达；最小满足
R(d,e)≥f 的 d 正是 D(e,f)。逐次增加 d，首次覆盖楼层时填写答案。
容量可截至 F：更大值对合法查询相同且递推单调。因一个蛋 d 次可测 d 层，
至多 F 轮，各答案单元只写一次；预处理 `O(EF)`、空间 `O(EF)`、查询 `O(1)`。
截断后加数至多 F，和至多 `2F+1=2001`，固定宽度整数安全。

按30%规则仅旧 Python 被列为优化：CPython0.078秒/812KB，教学PyPy为
0.265秒/2916KB，时间减少70.6%、内存72.2%。算法不同，保留旧 `dp` 名称。
旧 Java 时间仅改善28.4%且内存更高；C++/Go/Rust也不达准入，都保留为其他
算法而非优化标签。新简单 Java 已达排名目标。
