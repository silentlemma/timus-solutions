# 1223. 找出临界楼层最少要扔几次蛋

[Timus 1223](https://acm.timus.ru/problem.aspx?space=1&num=1223) · 难度 291 · dp

原题为民间流传的题目，由 Alexander Klepinin 提供，出自第七届乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

所有的蛋一样结实：从第 `E` 层及以下扔下不会碎，从更高的任何一层扔下都会碎。给定
蛋的个数和楼层数（都不超过 1000），求在最坏情况下也能确定 `E` 的最少扔蛋次数；
没碎的蛋可以再次使用。最多 1000 个询问，以 `0 0` 结束。

时间限制：1 秒。内存限制：64 MB。

## 输入

每行一个询问：蛋的个数和楼层数。

## 输出

对每个询问输出最坏情况下的最少次数。

## 样例

### 样例 1

输入：

```
1 10
2 5
0 0
```

输出：

```
10
3
```

## 解法

把问题反过来问：用 `d` 次扔蛋和 `k` 个蛋能区分多少层？第一次从某一层扔；如果蛋
碎了，剩下下面的楼层，还有 `d − 1` 次和 `k − 1` 个蛋；如果没碎，剩下上面的楼层，
还有 `d − 1` 次和 `k` 个蛋。所以

`reach(d, k) = reach(d − 1, k − 1) + reach(d − 1, k) + 1`，

其中 `reach(0, k) = reach(d, 0) = 0`。`n` 层的答案是满足 `reach(d, k) ≥ n` 的最小
`d`。十个蛋已经足够在 1000 层上做普通的二分查找，所以更多的蛋没有帮助，`k` 截断
为 10。对每个 `k` 随着 `d` 增长填出所有 `n` 的答案只需一次 `O(10 · 1000)`，之后
每个询问只是查表。

注意事项：

- 只有一个蛋时唯一稳妥的做法是逐层试，所以答案就是楼层数；
- 超过 10 个蛋都与 10 个一样，所以查表前要先把蛋数截断；
- 楼层数像二项式系数一样增长，所以也要截断到 1000，否则远在表填完之前就会溢出。

答案已对最多 5 个蛋、60 层的情形用直接的极小极大递推验证，并在所有测试上与另一份
独立解答比对。
