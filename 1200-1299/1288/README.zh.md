# 1288. 天体定位

[Timus 1288](https://acm.timus.ru/problem.aspx?space=1&num=1288) · 难度 2191 · simulation

原题作者 Alexander Mironenko，出自 2004 年乌拉尔国立大学个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

定位器给出 N ≤ 10 000 个 0 到 100 的读数。需要找出：

- 前壁：第一个不小于 95、且在它之前存在不超过 35 的读数的读数；
- 前壁位于 f 之后，位置 m 的读数要乘以 1 + (m − f) · A（0 ≤ A ≤ 0.1，小数点后最多三位），
  此后只使用这些值；
- 后壁：距前壁至少 D 个位置、不小于 95 的第一个值，并且两壁之间存在不超过 35 的值；
- 在两个区域中（位置 f + S 到 f + E，但不包括后壁及其之后）找最大值（相等时取第一个）；若该值
  达到区域的阈值 L，则有物体。

输出前壁位置、后壁到前壁的距离，以及每个区域的物体距离、没有物体，或在区域内一个读数也没有
时的未搜索。

时间限制：1 秒。内存限制：64 MB。

## 输入

N、D、S1、E1、L1、S2、E2、L2 和 A，然后是 N 个读数。

## 输出

报告各行，措辞与样例完全一致。

## 样例

### 样例 1

输入：

```
10 4 1 1 50 2 2 56 0.09
9
26
96
56
21
73
73
93
96
97
```

输出：

```
Surface found at 3.
Bottom found at 4.
Channel 1: Object at 1.
Channel 2: No object.
```

## 解法

这道题就是对上述规则的仔细模拟：每面壁扫描一遍，每个区域查看一遍。`O(N)`。

用缩放整数避免舍入。A 最多三位小数，所以 1 + (m − f) · A 是精确的千分之几。
读数按百万分之一存储（最多六位小数），所以每个修正值都是 10⁻⁹ 的精确整数倍。这样阈值 95、35 和 L、值之间的
比较以及寻找第一个最大值都完全不需要容差：50 乘以 1 + 9 · 0.1 恰好是 95，是一面壁
（测试 06）。

注意事项：

- 在第一个不超过 35 的读数之前出现的 95 以上读数不是前壁（测试 03）；
- 距前壁不足 D 的高值不是后壁，但可能是物体（测试 04）；
- 后壁及其之后都不搜索，完全落在那里的区域输出“No search.”（测试 08）；
- 区域可能超出读数的末尾（测试 07）；
- 没有前壁时只输出“No surface.”（测试 02）。

在 300 个随机信号上与一个独立实现比较过。
