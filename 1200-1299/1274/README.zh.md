# 1274. 分数运算

[Timus 1274](https://acm.timus.ru/problem.aspx?space=1&num=1274) · 难度 678 · math

原题作者 Sergey Volchenkov、Vladimir Pinaev 和 Michael Kopachev，出自 2003 年 10 月 15–16 日在雷宾斯克举行的 ACM ICPC 2003–2004 俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对两个写成带分数形式的数做加、减、乘、除，例如 `-7 3/4`、`8 1/2`、`-7/11`、`0` 或 `11`。
只有负数才写符号，有分数部分时省略为零的整数部分，分数部分为零时省略分数。输入的分数
可能未约分；答案要按同样格式写出并完全约分。无论输入还是答案，整数部分和分子都不超过
30 000，分母在 1 到 30 000 之间。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一个分数、运算符、第二个分数，各占一行。

## 输出

结果。

## 样例

### 样例 1

输入：

```
-3 1/6
+
2/4
```

输出：

```
-2 2/3
```

## 解法

把每个操作数化为带符号的分子与分母：w n/d 变为 ±(w·d + n)/d。按通常的公式运算，把负分母
的符号移到分子上，再同除以最大公约数。然后输出符号、整数部分以及余数/分母，省略为零的
部分。中间乘积小于 10¹⁸，完全在 64 位范围内。`O(log 30000)`。

注意事项：

- 结果为零时写作 `0`，不带符号（测试 02、09）；
- 整数结果没有分数部分，绝对值小于一的结果没有整数部分（测试 04、06）；
- 除以负数会把符号带到分母上，必须移回来（测试 04）；
- 单独一行的运算符 `-` 不能误当作分数的符号。

在 300 个生成的数据上与 Python 的 `Fraction` 比较过。

## 各语言说明

- 所有语言都按单词解析分数并单独处理符号，输出时分同样的三种情况。

## 优化解法

Go 直接从输入缓冲区的字节中解析数字。 Go 1.14 x64（提交 11318448）的运行时间从 0.031 秒变为 0.015 秒，内存从 1068 KB 变为 968 KB。

Python 读取字节串，先取出整数部分，再约分余下的分数部分。 Python 3.12 x64（提交 11318456）的运行时间从 0.078 秒变为 0.093 秒，内存从 544 KB 变为 540 KB。

**简单版本的 Timus 提交记录**

G++ 13.2 x64 №11321879 · Go 1.14 x64 №11322040 · Java 1.8 №11322043 · Python 3.12 x64 №11322042 · Rust 1.75 x64 №11322044.

Java 复用固定大小的字节缓冲区逐行读取，并直接解析其中的数字。 Java 1.8（提交 11321991）的运行时间从 0.109 秒变为 0.078 秒，内存从 784 KB 变为 356 KB。

Rust 用欧几里得算法约分，并将整数格式化到定长缓冲区。 Rust 1.75 x64（提交 11323303）的运行时间从 0.046 秒变为 0.062 秒，内存从 232 KB 变为 44 KB。
