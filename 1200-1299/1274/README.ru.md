# 1274. Дробная арифметика

## Задача

Сложить, вычесть, умножить или разделить две дроби, записанные как
смешанные числа, например `-7 3/4`, `8 1/2`, `-7/11`, `0` или `11`.
Знак пишется только у отрицательных чисел, нулевая целая часть
опускается, если есть дробь, а нулевая дробь опускается. Входные дроби
могут быть сократимы; ответ нужно записать так же и полностью
сократить. Целые части и числители не больше 30 000, знаменатели от 1
до 30 000 — и для входа, и для ответа.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Первая дробь, знак операции, вторая дробь — каждое в своей строке.

## Выходные данные

Результат.

## Примеры

### Пример 1

Ввод:

```
-3 1/6
+
2/4
```

Вывод:

```
-2 2/3
```

## Решение

Превратим каждый операнд в числитель со знаком над знаменателем:
w n/d становится ±(w·d + n)/d. Выполним операцию по обычным формулам,
перенесём знак отрицательного знаменателя в числитель и разделим оба на
наибольший общий делитель. Затем выведем знак, целую часть и остаток над
знаменателем, опуская нулевые части. Промежуточные произведения меньше
10¹⁸ и спокойно помещаются в 64 бита. `O(log 30000)`.

Тонкие места:

- нулевой результат пишется `0`, без знака (тесты 02, 09);
- у целого результата нет дробной части, а у результата по модулю
  меньше единицы нет целой (тесты 04, 06);
- деление на отрицательное число переносит знак в знаменатель, и его
  нужно вернуть обратно (тест 04);
- операцию `-` в отдельной строке нельзя спутать со знаком дроби.

Ответы сравнивались с `Fraction` из Python на 300 сгенерированных
случаях.

## Особенности языков

- Все языки разбирают дробь по словам, отделяя знак, и выводят её по
  тем же трём случаям.
