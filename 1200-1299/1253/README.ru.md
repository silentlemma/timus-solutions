# 1253. Развёртывание заготовок некрологов

[Timus 1253](https://acm.timus.ru/problem.aspx?space=1&num=1253) · сложность 690 · strings

Автор оригинальной задачи — Леонид Волков; открытое командное первенство УрГУ, 15 марта 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть N заготовок (N ≤ 9) длиной до 1000 символов каждая, возможно в
несколько строк. В заготовке `*M` — ссылка на заготовку M (не больше 10
ссылок в каждой). Развернуть заготовку 1, заменяя каждую ссылку текстом
её заготовки снова и снова, пока ссылок не останется. Вывести результат,
если он конечен и не длиннее 10⁶ символов, и `#` в противном случае.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N в первой строке; затем заготовки, каждая начинается с новой строки и
заканчивается символом `#`.

## Выходные данные

Развёрнутый текст или `#`.

## Примеры

### Пример 1

Ввод:

```
7
She w*7s *7 *2 wom*7n.
*3#
wonderful#
Everyone loved her *5.
We will miss her *5.#
Some text *6#
very much#
Another text *4#
a#
```

Вывод:

```
She was a wonderful woman.
Everyone loved her very much.
We will miss her very much.
```

## Решение

Развёртывание заготовки 1 не кончается ровно тогда, когда из неё
достижим цикл ссылок, а иначе её длина определена:
`size(i) = обычные символы + Σ size(заготовки по ссылкам)`. Поиск в глубину
из заготовки 1 считает эти длины и отмечает заготовки, которые ещё
разворачиваются; встретить такую снова — значит найти цикл. Длины
ограничиваются чуть больше 10⁶, ведь восемь уровней по десять ссылок
могут дать 10⁸ · 1000 символов. Если цикла нет и `size(1)` ≤ 10⁶, текст
выписывается той же рекурсией. Время — `O(S + L + 10^N)`, в Python —
`O(N(S + L))`, где S — размер входа, L — длина вывода.

Тонкие места:

- цикл среди заготовок, до которых заготовка 1 не доходит, безвреден
  (тест 03);
- граница включительна: ровно 10⁶ символов выводятся, на один больше —
  уже `#` (gen1 и gen2);
- перевод строки сразу после каждого `#` разделяет заготовки, но
  переводы строк внутри заготовки — часть её текста, а заготовка может
  быть пустой;
- номера заготовок однозначные, так что `*21` — ссылка на заготовку 2,
  за которой идёт цифра 1 (тест 08).

## Особенности языков

- Python один раз делит каждую заготовку по `*` и запоминает
  развёрнутые тексты; остальные языки идут по символам и пишут текст
  сразу в один буфер.

## Оптимизированные решения

Версия C++ сначала вычисляет длину развёртки, затем передаёт участки обычного текста прямо в буфер вывода. Ссылки на пустые развёртки пропускаются, весь результат в памяти не хранится. При S символах ввода, L символах вывода и N шаблонах время O(S + NL), дополнительная память O(S + N). Метрики взяты из посылки 11317000.

Версия для Java 1.8 хранит шаблоны в байтовых массивах, измеряет длину развёртки и пишет фрагменты через буфер без сборки полного результата. Посылка 11317131 заняла 0,062 с и 432 КБ, базовая версия — 0,109 с и 6088 КБ.

Версия для Rust 1.75 x64 делит шаблоны на фрагменты и ссылки, измеряет длину развёртки и пишет фрагменты через буфер без сборки полного результата. Посылка 11317130 заняла 0,015 с и 212 КБ, базовая версия — 0,015 с и 2032 КБ.

Версия для Python 3.12 x64 сначала вычисляет длины, кэширует развёртки до 4096 байт и выводит более длинные развёртки частями. Посылка 11317128 заняла 0,062 с и 660 КБ, базовая версия — 0,078 с и 4356 КБ.

**Посылки Timus для простых версий**

G++ 13.2 x64 №11322206 · Go 1.14 x64 №11322207 · Java 1.8 №11322208 · Python 3.12 x64 №11322209 · Rust 1.75 x64 №11322210.

Go вычисляет длины развёрток перед выводом, затем пишет литералы и ссылки потоком. Для большого вывода он кэширует развёртки, которые помещаются в фиксированный буфер. Go 1.14 x64, посылка 11322833. Время 0,015 → 0,015 с, память 940 → 400 КБ.
