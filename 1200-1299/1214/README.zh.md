# 1214. 撤销一个奇怪的过程

[Timus 1214](https://acm.timus.ru/problem.aspx?space=1&num=1214) · 难度 102 · math

原题作者 Anatoly Uglov，出自 2002 年 10 月 USU Open Collegiate Programming Contest（Junior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个过程接收两个整数 `x` 和 `y`。若两者都为正，它把循环体执行 `x + y` 次：
`y ← x² + y`，然后 `x ← x² + y`，然后 `y ← ⌊√(x − y)⌋`，再从 `x` 中减去 `y`
共 `2y` 次；最后打印 `x` 和 `y`。已知打印结果（都在 `−32000` 到 `32000` 之间），
求原来的输入。保证不会溢出。

时间限制：1 秒。内存限制：64 MB。

## 输入

打印出的 `x` 和 `y`。

## 输出

输入的 `x` 和 `y`。

## 样例

### 样例 1

输入：

```
1 1
```

输出：

```
1 1
```

## 解法

从 `(x, y)` 出发跟踪一次循环。先 `y` 变成 `x² + y`，再 `x` 变成 `2x² + y`。两者
之差为 `x²`，所以新的 `y` 就是 `x`。把它减去 `2x` 次，就从 `2x² + y` 中减掉 `2x²`，
剩下 `y`。所以每次循环只是交换两个数，而决定循环次数的和 `x + y` 不变。`x + y`
次之后，两数恰在和为奇数时被交换。

因此，这个过程在两数都为正且和为奇数时交换它们，否则什么也不变。这个变换的逆就是
它本身：对打印出的数对用同一条规则即可。`O(1)`。

注意事项：

- 有一个数为零或负数时循环根本不执行，数对原样打印；
- 决定奇偶的是和，而不是两个数本身。

对 `−3` 到 `15` 之间的每一对数运行该过程再撤销，每次都得到原来的数对。

- 所有语言都使用同一条一行规则。
