# 1214. Как отменить странную процедуру

## Задача

Процедура принимает два целых `x` и `y`. Если оба положительны, она
`x + y` раз выполняет тело цикла: `y ← x² + y`, затем `x ← x² + y`, затем
`y ← ⌊√(x − y)⌋`, затем `2y` раз вычитает `y` из `x`; в конце она
печатает `x` и `y`. По напечатанному, оба от `−32000` до `32000`,
восстановить вход. Переполнений не бывает.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Напечатанные `x` и `y`.

## Выходные данные

Входные `x` и `y`.

## Примеры

### Пример 1

Ввод:

```
1 1
```

Вывод:

```
1 1
```

## Решение

Проследим один виток цикла от `(x, y)`. Сначала `y` становится
`x² + y`, затем `x` становится `2x² + y`. Их разность — `x²`, поэтому
новое `y` равно `x`. Вычитание его `2x` раз отнимает `2x²` от `2x² + y` и
оставляет `y`. Значит, каждый виток просто меняет числа местами, а сумма
`x + y`, задающая число витков, не меняется. После `x + y` витков числа
переставлены ровно тогда, когда сумма нечётна.

Итак, процедура меняет числа местами, если оба положительны и их сумма
нечётна, и ничего не меняет иначе. Это преобразование обратно самому
себе: применяем то же правило к напечатанной паре. `O(1)`.

Тонкие места:

- при нуле или отрицательном числе цикл не выполняется вовсе, и пара
  печатается без изменений;
- чётность определяет сумма, а не сами числа.

Запуск процедуры на всех парах от `−3` до `15` и отмена результата каждый
раз возвращали исходную пару.

## Оптимизированные решения

два числа вручную вместо `Scanner`: 384 КБ вместо 1584 КБ при том же
времени.
