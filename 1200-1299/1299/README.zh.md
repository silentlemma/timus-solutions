# 1299. 普西隆人

[Timus 1299](https://acm.timus.ru/problem.aspx?space=1&num=1299) · 难度 1525 · implementation

原题作者 Pavel Egorov，出自 2004 年 3 月 13 日第九届中学生公开团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

模拟战斗机器人的一次决策。机器人有能量 E 和弹药 W，处于四种行为模式之一，看到 M 个平均能量为 MP
的敌人，最危险的一个位于角度 a。输出一条命令：

- `LEFT X`、`RIGHT X`、`FRONT X`、`BACKWARD X`，其中 X = min(100, E)；
- `FIRE P`，其中 P = min(20, W)；
- `STOP`。

行为模式：

- 警戒（G）：没有敌人时 `STOP`；若 |a| < 5 则开火；否则转向目标，a ≥ 5 向左，a ≤ −5 向右；
- 防御（D）：若 20 · M ≥ W，则边射击边后退，否则按警戒行动；
- 进攻（A），己方有 N 个平均能量为 NP 的机器人：若 N · NP > 3 · M · MP，则边射击边前进，否则边射击边
  后退；
- 巡逻（P），与下一个航点的偏差为 d：有敌人时按防御行动；否则用车头或车尾朝向航点，取需要转动较小
  的一侧，该角度大于 20 时转向，否则前进或后退。

边射击边后退：没有敌人或目标偏离至少 5 度时向后移动，否则开火。边射击边前进同理，用 `FRONT` 和
10 度。

角度在 −179 到 180 之间，其余数在 0 到 1000 之间。

时间限制：1 秒。内存限制：64 MB。

## 输入

E 和 W；模式字母；M、MP 和 a；进攻时再给 N 和 NP，巡逻时再给 d。

## 输出

一条命令。

## 样例

### 样例 1

输入：

```
100 100
P
0 0 0
-100
```

输出：

```
LEFT 100
```

### 样例 2

输入：

```
10 1000
A
1 10 30
100 1000
```

输出：

```
FRONT 10
```

### 样例 3

输入：

```
10 1000
G
1 10 4
```

输出：

```
FIRE 20
```

## 解法

完全按上述规则执行，只用整数。题目中有三处需要解读：

- 正角度在左边。警戒模式 a ≥ 5 时向左转，第一个样例也与此一致：航点在右边 100 度，所以车尾在左边
  80 度，机器人 `LEFT`。
- 后退和前进时“偏离至少 5（或 10）度”理解为 |a| ≥ 5（或 10），与警戒模式使用相同的绝对角度。机器人
  只在瞄准时开火。
- 巡逻时车尾指向 d − 180（d ≤ 0 时为 d + 180）。车头和车尾需要同样的转角时（d = ±90），保留车头，
  所以 d = 90 输出 `LEFT`（测试 19）。

`O(1)`。

注意事项：

- 阈值是精确的：a = 5 时已经转向（测试 05），偏差为 20 时仍然移动（测试 13 和 16）；
- 进攻时实力恰为敌方三倍仍后退，因为条件是严格不等式（测试 10）；
- 数量受机器人现有资源限制：只剩 5 单位弹药时 `FIRE 5`（测试 10），没有能量时 `BACKWARD 0`
  （测试 16）；
- 巡逻中遇到敌人时按防御规则行动，而不是按航线（测试 18）。

在 400 个随机输入（角度靠近各个阈值）上与同一解读的独立实现比较过。
