# 1213. Как меньше всего поднимать перегородки, чтобы загнать тараканов в шлюз

[Timus 1213](https://acm.timus.ru/problem.aspx?space=1&num=1213) · сложность 171 · graphs

Автор оригинальной задачи — Евгений Крохалев; USU Open Collegiate Programming Contest, октябрь 2002 года, Junior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В грузовом модуле до 30 отсеков, соединённых перегородками, и в каждом
отсеке полно тараканов. Если пустить газ в отсек и открыть одну его
перегородку, все тараканы перебегут в соседний отсек. Каждый отсек
связан со шлюзом. Найти наименьшее число открываний перегородок, чтобы
собрать всех тараканов в шлюзе.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Название шлюза, затем по перегородке в строке — два названия отсеков
через `-`, затем строка `#`. Названия — до 20 латинских букв и цифр,
регистр важен.

## Выходные данные

Наименьшее число открываний.

## Примеры

### Пример 1

Ввод:

```
Gateway
Machinery-Gateway
Machinery-Control
Control-Central
Control-Engine
Central-Engine
Storage-Gateway
Storage-Waste
Central-Waste
#
```

Вывод:

```
6
```

## Решение

Каждый отсек, кроме шлюза, вначале полон тараканов и в конце должен быть
пуст, а отсек пустеет, только когда открывают одну из его собственных
перегородок, так что нужно хотя бы одно открывание на отсек. Этого и
достаточно: берём дерево перегородок, по которому из каждого отсека
можно дойти до шлюза, и опустошаем отсеки от самых дальних к шлюзу,
каждый через перегородку на пути к нему. Ответ — число различных
названий отсеков минус один. `O(P log P)` для `P` перегородок.

Тонкие места:

- `Engine` и `engine` — разные отсеки;
- у шлюза может не быть перечисленных перегородок вовсе, тогда ответ 0;
- расположение перегородок не важно, важно только число отсеков.

Ответы сверены с отдельно написанным решением на 100 случайных модулях.

## Особенности языков

- Во всех языках названия собираются во множество, и выводится его
