# 1282. 博弈树

[Timus 1282](https://acm.timus.ru/problem.aspx?space=1&num=1282) · 难度 338 · games

原题作者 Sergey Volchenkov、Vladimir Pinaev 和 Michael Kopachev，出自 2003 年 10 月 15–16 日在雷宾斯克举行的 ACM ICPC 2003–2004 俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个双人游戏由一棵以 1 号节点为根、共 1 < N ≤ 1000 个节点的树给出。双方轮流走，先手从根开始，
每步走到一个子节点。每个叶子记录结果：+1 表示先手胜，−1 表示后手胜，0 表示平局。双方都采取
最佳策略时结果如何？

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后对节点 2 到 N，内部节点为 `N 父节点`，叶子为 `L 父节点 结果`。

## 输出

`+1`、`-1` 或 `0`。

## 样例

### 样例 1

输入：

```
7
N 1
N 1
L 2 -1
L 2 +1
L 3 +1
L 3 +1
```

输出：

```
+1
```

### 样例 2

输入：

```
7
N 1
N 1
L 2 -1
L 2 +1
L 3 +1
L 3 0
```

输出：

```
0
```

### 样例 3

输入：

```
18
N 1
N 1
N 2
L 2 +1
N 3
L 3 +1
L 3 +1
L 4 -1
L 4 +1
N 4
N 6
L 6 -1
L 6 -1
L 11 -1
L 11 +1
L 12 +1
L 12 -1
```

输出：

```
+1
```

## 解法

这就是极小化极大。先手在偶数深度的节点行动，取子节点中的最大值；后手在奇数深度行动，取
最小值。节点可能在父节点之前给出，所以不能按输入顺序计算：从根做一次广度优先遍历得到所有
深度，倒序走这个顺序就能保证子节点先于父节点处理。`O(N)`。

注意事项：

- 父节点可能出现在子节点之后（测试 05）；
- 1000 个节点的链会让朴素递归很深（测试 06）；
- 结果写作带加号的 `+1`，输入输出都是如此。

在 149 棵生成的树上与普通的递归极小化极大比较过。

## 各语言说明

- 所有语言都倒序遍历同一个广度优先顺序。
- Java 在解析结果前去掉加号。
