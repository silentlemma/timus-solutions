# 1282. Дерево игры

[Timus 1282](https://acm.timus.ru/problem.aspx?space=1&num=1282) · сложность 338 · games

## Задача

Игра двух игроков задана деревом из 1 < N ≤ 1000 вершин с корнем в вершине
1. Игроки ходят по очереди, первый — в корне, спускаясь к одному из
детей. В каждом листе записан итог: +1, если выиграл первый игрок, −1,
если второй, 0 при ничьей. Какой итог получится при наилучшей игре обоих?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем для вершин 2…N либо `N предок` для внутренней вершины, либо
`L предок итог` для листа.

## Выходные данные

`+1`, `-1` или `0`.

## Примеры

### Пример 1

Ввод:

```
7
N 1
N 1
L 2 -1
L 2 +1
L 3 +1
L 3 +1
```

Вывод:

```
+1
```

### Пример 2

Ввод:

```
7
N 1
N 1
L 2 -1
L 2 +1
L 3 +1
L 3 0
```

Вывод:

```
0
```

### Пример 3

Ввод:

```
18
N 1
N 1
N 2
L 2 +1
N 3
L 3 +1
L 3 +1
L 4 -1
L 4 +1
N 4
N 6
L 6 -1
L 6 -1
L 11 -1
L 11 +1
L 12 +1
L 12 -1
```

Вывод:

```
+1
```

## Решение

Это минимакс. Первый игрок ходит в вершинах чётной глубины и выбирает
наибольшее значение среди детей, второй — на нечётной и выбирает
наименьшее. Вершина может быть описана раньше своего предка, поэтому
значения считаются не в порядке входа: обход в ширину от корня даёт
все глубины, а проход по этому порядку в обратную сторону посещает всех
детей раньше родителя. `O(N)`.

Тонкие места:

- предок может быть описан после потомка (тест 05);
- цепочка из 1000 вершин сделала бы наивную рекурсию глубокой (тест 06);
- итоги записываются как `+1`, со знаком плюс, и во входе, и в ответе.

Ответы сравнивались с обычным рекурсивным минимаксом на 149
сгенерированных деревьях.

## Особенности языков

- Все языки проходят один и тот же порядок обхода в ширину с конца.
- Java убирает знак плюс перед разбором итога.
