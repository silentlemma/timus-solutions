## Задача

Сколькими нулями оканчивается десятичная запись числа
1ⁿ + 2ⁿ + 3ⁿ + 4ⁿ при 1 ≤ n ≤ 300 000?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число n.

## Выходные данные

Количество нулей на конце.

## Примеры

### Пример 1

Ввод:

```
1
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
3
```

Вывод:

```
2
```

## Решение

При наибольшем n в сумме больше 180 000 цифр, но нули на конце
ограничены степенью двойки в ней. Пусть S = 1ⁿ + 2ⁿ + 3ⁿ + 4ⁿ.

- n = 1: S = 10, один ноль.
- Чётное n: 1ⁿ + 3ⁿ ≡ 1 + 1 = 2 (mod 4), а 2ⁿ и 4ⁿ кратны 4, так что S
  делится на 2, но не на 4.
- Нечётное n ≥ 3: 3ⁿ ≡ 3 (mod 8), поэтому 1ⁿ + 3ⁿ ≡ 4 (mod 8), а 2ⁿ и
  4ⁿ кратны 8; S делится на 4, но не на 8.

Значит, трёх нулей на конце не бывает, и всё решает S mod 100: два
нуля, если остаток равен 0, один ноль, если он оканчивается на 0, и ни
одного иначе. Четыре степени по модулю 100 считаются быстрым
возведением в степень. `O(log n)`.

На самом деле ответ зависит только от n mod 20: 0, если n делится на 4,
2, если n даёт остаток 3 по модулю 4 или 5 по модулю 20, и 1 в
остальных случаях. Решения вычисляют ответ напрямую, не опираясь на эту
таблицу.

Тонкие места:

- n с остатком 1 по модулю 4 обычно даёт один ноль, но n = 5, 25, …
  дают два (тесты 05 и 06);
- полную сумму можно построить длинной арифметикой, но это не нужно:
  важны только две последние цифры.

Результаты сравнивались с точной суммой в длинной арифметике для всех
n до 3000.

- Python использует встроенный `pow` с тремя аргументами; остальные
