# 1241. Подсчёт треугольников после прямых разрезов

[Timus 1241](https://acm.timus.ru/problem.aspx?space=1&num=1241) · сложность 1680 · geometry

Автор оригинальной задачи — Елена Крючкова; полуфинал ACM ICPC Северо-Восточной Европы 2002–2003.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Плиту M × N (M, N ≤ 50) разрезали K раз (K ≤ 296). Каждый разрез —
прямая от одной точки края до другой, обе с целыми координатами, идущая
вертикально, горизонтально или под 45° к сторонам; все разрезы различны.
Посчитать куски, которые являются прямоугольными равнобедренными
треугольниками любого размера.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

M, N и K, затем каждый разрез в виде `X1 Y1 X2 Y2`.

## Выходные данные

Число треугольных кусков.

## Примеры

### Пример 1

Ввод:

```
4 4 4
1 4 1 0
0 4 4 0
0 0 4 4
0 2 4 2
```

Вывод:

```
6
```

### Пример 2

Ввод:

```
7 4 6
6 0 7 1
1 4 1 0
0 4 4 0
0 0 4 4
0 2 7 2
7 0 3 4
```

Вывод:

```
8
```

## Решение

Разрез идёт от края до края, так что это целая прямая через плиту одного
из четырёх видов: `x = c`, `y = c`, `x − y = c` или `x + y = c` с целым c.
Важно лишь, какие прямые разрезаны, а их всего
(M − 1) + (N − 1) + 2(M + N − 1), 296 для наибольшей плиты.

Разобьём каждый единичный квадрат обеими диагоналями на четыре маленьких
треугольника. Любой возможный разрез идёт по рёбрам этих треугольников,
так что каждый кусок — их объединение: соседние маленькие треугольники
объединяются, если их общее ребро не лежит на разрезанной прямой, через
систему непересекающихся множеств на не более чем 10 000 элементах.

Чтобы распознать треугольник, заметим, что каждый кусок выпуклый — это
плита, разрезанная прямыми, — а его стороны направлены лишь в 8 возможных
направлениях, по одной стороне на направление. Значит, у куска столько
сторон, сколько различных внешних направлений у его рёбер. Каждый
маленький треугольник запоминает внешние направления своих рёбер,
лежащих на разрезе или на краю; кусок, у которого объединение направлений
содержит ровно 3, — треугольник с углами 45°, 45° и 90°, то есть прямоугольный
равнобедренный. `O(M·N)`.

Тонкие места:

- разрез задан двумя концами, которые могут идти в любом порядке; важны
  только вид прямой и её константа;
- кусок может быть большим треугольником из многих маленьких, так что
  форму надо судить по сторонам, а не по площади.

Ответы сравнивались с точным разрезанием многоугольника плиты каждой
прямой на 400 случайных маленьких плитах.

## Особенности языков

- Все языки хранят направления как 8-битную маску на маленький
  треугольник и считают её биты.
