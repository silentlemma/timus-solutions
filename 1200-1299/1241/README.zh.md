# 1241. 统计直线切割后留下的三角形

[Timus 1241](https://acm.timus.ru/problem.aspx?space=1&num=1241) · 难度 1680 · geometry

原题作者 Elena Kruchkova，出自 2002–2003 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一块 M × N 的板（M, N ≤ 50）被切了 K 刀（K ≤ 296）。每一刀都是从边上一点到另一点
的直线，两端都是整点，方向为竖直、水平或与边成 45°；所有切口互不相同。统计切出的
块中，有多少是任意大小的等腰直角三角形。

时间限制：1 秒。内存限制：64 MB。

## 输入

M、N 和 K，然后每一刀为 `X1 Y1 X2 Y2`。

## 输出

三角形块的个数。

## 样例

### 样例 1

输入：

```
4 4 4
1 4 1 0
0 4 4 0
0 0 4 4
0 2 4 2
```

输出：

```
6
```

### 样例 2

输入：

```
7 4 6
6 0 7 1
1 4 1 0
0 4 4 0
0 0 4 4
0 2 7 2
7 0 3 4
```

输出：

```
8
```

## 解法

每一刀从边到边，所以它是穿过整块板的一整条直线，属于四类之一：`x = c`、`y = c`、
`x − y = c` 或 `x + y = c`，c 为整数。重要的只是哪些直线被切了，而它们总共只有
(M − 1) + (N − 1) + 2(M + N − 1) 条，最大的板为 296 条。

用两条对角线把每个单位正方形分成四个小三角形。任何可能的切口都沿着这些小三角形的边，
所以每一块都是它们的并：两个相邻的小三角形，除非公共边落在被切的直线上，就用并查集
合并，元素最多 10 000 个。

为了识别三角形，注意每一块都是凸的（它是被直线切开的板），而且它的边只有 8 种可能
的方向，每个方向至多一条边。所以一块有几条边，就等于它的边有几种不同的外法方向。每个
小三角形记录它落在切口或板边上的那些边的外法方向；方向的并恰好有 3 个的块就是三角形，
其角只能为 45°、45° 和 90°，所以是等腰直角三角形。`O(M·N)`。

注意事项：

- 切口用两个端点给出，顺序任意；重要的只是直线的种类和常数；
- 一块可能是由许多小三角形组成的大三角形，所以要按边来判断形状，而不是按面积。

这些结果在 400 块随机的小板上与按每条切线精确切分板的多边形的结果比较过。

## 各语言说明

- 所有语言都为每个小三角形用一个 8 位掩码保存方向，并统计其中的位数。
