# 1230. 用玩具语言写一个打印自身的程序

[Timus 1230](https://acm.timus.ru/problem.aspx?space=1&num=1230) · 难度 793 · strings

原题出自 2002 年 10 月在雷宾斯克举行的 ACM ICPC 2002–2003 俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

输出一个用 PIBAS（题面中定义的一种小语言）写的程序，它恰好打印出自己的源文本。
PIBAS 程序是一行由 `;` 分隔的语句。语句要么把字符串表达式赋给一个用单个大写字母
命名的变量，`V=表达式`，要么打印它，`?表达式`。表达式用 `+` 连接变量、用单引号或
双引号括起的常量（不能包含自身的引号）以及子串 `$(V,起点,长度)`。

时间限制：1 秒。内存限制：64 MB。

## 输入

没有输入。

## 输出

PIBAS 程序。

## 评测方式

只要程序是合法的 PIBAS 并且恰好打印出自己的文本，就判为正确；参考评测程序用一个
按语法实现的小型解释器运行它。

## 样例

没有输入，而且任何正确的程序都是合法答案，所以题面没有给出样例输出。

## 解法

常见的自打印程序思路：把程序的大部分放进字符串 `A`，打印两次，一次放在引号里作为
赋值的内容，一次作为代码。难点在引号。`A` 位于单引号之间，所以不能含有单引号，而
其中的代码又必须打印两种引号。因此程序先把它们存进变量，`C="'"` 和 `B='"'`，打印
代码只引用 `C` 和 `B`：

```text
C="'";B='"';A=';?"C="+B+C+B+";B="+C+B+C+";A="+C+A+C+A';?"C="+B+C+B+";B="+C+B+C+";A="+C+A+C+A
```

最后一条语句先打印 `C="'";B='"';A=`（引号取自变量），然后是 `'`、`A` 的文本、
再一个 `'`，最后再打印一次 `A` 的文本，这就是整个程序。每个解答都由开头部分和 `A`
的文本拼出这一行并打印。`O(1)`。

注意事项：

- 常量不能包含自身的引号，所以两种引号都不能直接写在 `A` 里；
- `?` 打印时不换行，所以程序打印自身时各部分之间不能多出任何东西。

评测程序会运行打印出来的程序，并把它的输出与其文本进行比较。

## 各语言说明

- C++ 和 Rust 用原始字符串、Go 用反引号表示这两部分；Python 用三引号字符串表示
  开头，Java 对双引号进行转义。
