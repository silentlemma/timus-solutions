# 1230. Программа на игрушечном языке, печатающая саму себя

[Timus 1230](https://acm.timus.ru/problem.aspx?space=1&num=1230) · сложность 793 · strings

Оригинальная задача — четвертьфинал ACM ICPC 2002–2003, центральный регион России, Рыбинск, октябрь 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Вывести программу на PIBAS — маленьком языке, описанном в условии, —
которая печатает в точности свой собственный текст. Программа на PIBAS —
одна строка операторов, разделённых `;`. Оператор либо присваивает
строковое выражение переменной, обозначенной одной заглавной буквой,
`V=выражение`, либо печатает его, `?выражение`. Выражение соединяет через
`+` переменные, константы в одинарных или двойных кавычках (не содержащие
своей кавычки) и подстроки `$(V,начало,длина)`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Входных данных нет.

## Выходные данные

Программа на PIBAS.

## Проверка

Принимается любая программа, если она правильна с точки зрения PIBAS и
печатает в точности свой текст; эталонный чекер запускает её маленьким
интерпретатором грамматики.

## Примеры

Входных данных нет, а правильным ответом годится любая подходящая
программа, поэтому пример вывода в условии не дан.

## Решение

Обычная идея куайна: держим большую часть программы в строке `A` и
печатаем её дважды — один раз в кавычках как присваиваемое значение и
один раз как код. Трудность в кавычках. `A` стоит в одинарных кавычках,
поэтому не может содержать одинарную кавычку, а код в ней должен
печатать оба вида кавычек. Поэтому программа сначала кладёт их в
переменные, `C="'"` и `B='"'`, а печатающий код ссылается только на `C` и
`B`:

```text
C="'";B='"';A=';?"C="+B+C+B+";B="+C+B+C+";A="+C+A+C+A';?"C="+B+C+B+";B="+C+B+C+";A="+C+A+C+A
```

Последний оператор печатает `C="'";B='"';A=` с кавычками, взятыми из
переменных, затем `'`, текст `A`, снова `'` и ещё раз текст `A` — это и
есть вся программа. Каждое решение печатает эту строку, собранную из её
начала и текста `A`. `O(1)`.

Тонкие места:

- константа не может содержать свою кавычку, так что ни одну из кавычек
  нельзя написать прямо внутри `A`;
- `?` печатает без перевода строки, так что программа должна напечатать
  себя без каких-либо вставок между частями.

Чекер запускает напечатанную программу и сравнивает то, что она печатает,
с её текстом.

## Особенности языков

- C++ и Rust используют сырые строки, Go — обратные кавычки для двух
  частей; Python берёт для начала строку в тройных кавычках, а Java
  экранирует двойные кавычки.
