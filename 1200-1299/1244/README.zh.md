# 1244. 根据重量找出一副牌缺了哪些

[Timus 1244](https://acm.timus.ru/problem.aspx?space=1&num=1244) · 难度 254 · dp

原题作者 Alexander Petrov，出自 2003 年 3 月 1 日乌拉尔国立大学个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

完整牌组含 `N` 张按输入顺序编号的牌，`2 ≤ N ≤ 100`，每张重量为整数
`1 ≤ w_i ≤ 1000` 毫克，总重记作 `T`。剩余牌的重量为整数 `W`，`0 < W < T`。
确定缺少哪些编号：唯一时按升序输出；存在多个可能集合时输出 `-1`；不可能时输出 `0`。
重量相同的牌仍是不同的牌。时间限制：0.5 秒。内存限制：64 MB。

## 输入

W，然后是 N，然后是 N 张牌的重量。

## 输出

缺少的牌、-1 或 0。

## 评测方式

按空白分隔的整数比较答案。唯一解按升序列出缺少的编号；否则只输出 `0` 或 `-1`。

## 解法

留在牌堆里的牌组成一个总重为 W 的集合，缺少的就是其余的牌。所以统计重量为 W 的
牌的集合个数，但只数到 2，因为只有这一点重要：`ways[i][s]` 是前 i 张牌中重为 s
的集合个数，上限为 2，且 `ways[i][s] = min(2, ways[i−1][s] + ways[i−1][s − w_i])`。
于是 `ways[N][W]` 为 0、2（输出 -1）或恰好为 1。

对于唯一的集合，从最后一张牌开始、令 s = W 往回走：当且仅当前 i − 1 张牌自己就能凑
出 s，即 `ways[i−1][s] = 1` 时，第 i 张牌缺少；否则它在牌堆里，s 减去它的重量。唯一性
意味着这两种情况只有一种成立。`O(N·W)`，W < 100 000。

注意事项：

- 重量相同的牌是不同的牌：两张重 1 的牌、W = 1 时，任一张都可能缺少，所以答案是
  -1（测试 04）；
- 可能缺少多张牌，最多除一张以外全部缺少（测试 08）。

这些答案在 1500 副随机的小牌堆上与枚举所有子集的结果比较过。

## 优化解法

取补集把重量为 `W` 的剩余牌集合与重量为 `T−W` 的缺失牌集合一一对应。
只对 `S = min(W,T−W)` 计数，必要时对选出的编号再取补集。无解、唯一、多解三种情况不变，
而 `S ≤ 50000`。

四种原生语言只保留一行截断到 `0,1,2` 的计数，按重量递减更新。某重量首次可达时记录最后一张牌的编号，
之后不覆盖此前驱。前一个重量在处理这张牌之前已可达；递减更新与正重量保证沿前驱链的牌编号严格递减，
不会重复用牌。最终集合唯一时，这条链就是所需集合。前驱编号不超过 100。
时间 `O(N·S)`，空间 `O(S+N)`。

Python 保存每个前缀的可达重量位集，但“至少两种表示”的位集仅保留当前行。
旧的多解状态分别按不取、取新牌传播；旧可达集合与其平移的交集也说明存在两个不同集合。
唯一解由前缀可达位集回溯。一旦 `S` 有两种表示即可输出 `-1`，因为后续牌都可以不取，原有两种集合仍有效。

令 `C` 为最大牌重、`w` 为大整数分块位数，`B = ceil((S+C+1)/w)`、
`B_W = ceil((W+C+1)/w)`。优化 Python 的保守时间、空间界均为 `O(N·B)` 个机器字；
简单 Python 使用对应 `B_W` 的前缀位集。`C` 包含截断前平移的临时空间。五份简单源码全部原样保留。

相对未改动的 Accepted 简单源码，实测内存下降：C++ 98.1%、Go 90.3%、Java 95.6%、Python 80.2%、Rust 97.7%。五种均按内存改善准入。一个计时刻度的时间差不视为可靠加速。排名快照：2026 年 11 月 2 日；星号表示仍可继续优化。

## 各语言说明

简单 C++/Go/Java/Rust 保留完整前缀计数表；简单 Python 为各前缀保留可达与多解位集。优化原生版本只保留一行计数及首次可达前驱；优化 Python 保留可达前缀与一个多解位集。Python 共通过 40,770 组输入：小规模和随机牌组使用独立的按编号子集枚举，极限情况使用已知精确答案。五种实际程序还各自在 Docker 中通过 72 组筛选的参考输入。
