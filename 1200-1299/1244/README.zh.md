# 1244. 根据重量找出一副牌缺了哪些

[Timus 1244](https://acm.timus.ru/problem.aspx?space=1&num=1244) · 难度 254 · dp

原题作者 Alexander Petrov，出自 2003 年 3 月 1 日乌拉尔国立大学个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一副完整的牌有 N 张（2 ≤ N ≤ 100），每张的重量已知，为 1 到 1000 毫克。一副不完整
的牌重 W，比完整的轻。如果能唯一确定缺少的牌，按升序输出它们的编号；如果可能缺少的
牌组不止一种，输出 -1；如果一种都不可能，输出 0。

时间限制：1 秒。内存限制：64 MB。

## 输入

W，然后是 N，然后是 N 张牌的重量。

## 输出

缺少的牌、-1 或 0。

## 样例

### 样例 1

输入：

```
270
4
100
110
170
200
```

输出：

```
2 4
```

### 样例 2

输入：

```
270
4
100
110
160
170
```

输出：

```
-1
```

### 样例 3

输入：

```
270
4
100
120
160
180
```

输出：

```
0
```

## 解法

留在牌堆里的牌组成一个总重为 W 的集合，缺少的就是其余的牌。所以统计重量为 W 的
牌的集合个数，但只数到 2，因为只有这一点重要：`ways[i][s]` 是前 i 张牌中重为 s
的集合个数，上限为 2，且 `ways[i][s] = min(2, ways[i−1][s] + ways[i−1][s − w_i])`。
于是 `ways[N][W]` 为 0、2（输出 -1）或恰好为 1。

对于唯一的集合，从最后一张牌开始、令 s = W 往回走：当且仅当前 i − 1 张牌自己就能凑
出 s，即 `ways[i−1][s] = 1` 时，第 i 张牌缺少；否则它在牌堆里，s 减去它的重量。唯一性
意味着这两种情况只有一种成立。`O(N·W)`，W < 100 000。

注意事项：

- 重量相同的牌是不同的牌：两张重 1 的牌、W = 1 时，任一张都可能缺少，所以答案是
  -1（测试 04）；
- 可能缺少多张牌，最多除一张以外全部缺少（测试 08）。

这些答案在 1500 副随机的小牌堆上与枚举所有子集的结果比较过。
