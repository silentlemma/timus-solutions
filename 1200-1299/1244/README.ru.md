# 1244. Каких карт не хватает в колоде, по её весу

[Timus 1244](https://acm.timus.ru/problem.aspx?space=1&num=1244) · сложность 254 · dp

Автор оригинальной задачи — Александр Петров; личное первенство УрГУ, 1 марта 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В полной колоде N карт (2 ≤ N ≤ 100) известного веса от 1 до 1000
миллиграммов. Неполная колода весит W, меньше полной. Вывести номера
недостающих карт в порядке возрастания, если они определяются
однозначно, -1, если недоставать могут разные наборы карт, и 0, если
никакой.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

W, затем N, затем N весов карт.

## Выходные данные

Недостающие карты, -1 или 0.

## Примеры

### Пример 1

Ввод:

```
270
4
100
110
170
200
```

Вывод:

```
2 4
```

### Пример 2

Ввод:

```
270
4
100
110
160
170
```

Вывод:

```
-1
```

### Пример 3

Ввод:

```
270
4
100
120
160
180
```

Вывод:

```
0
```

## Решение

Оставшиеся в колоде карты образуют набор общего веса W, а недостающие —
всё остальное. Поэтому посчитаем наборы карт веса W, но только до 2,
потому что важно лишь это: `ways[i][s]` — число наборов из первых i
карт веса s, ограниченное двойкой, и
`ways[i][s] = min(2, ways[i−1][s] + ways[i−1][s − w_i])`. Тогда
`ways[N][W]` равно 0, 2 (вывести -1) или ровно 1.

Для единственного набора пойдём назад от последней карты с s = W: карта
i отсутствует ровно тогда, когда первые i − 1 карт уже сами дают s,
`ways[i−1][s] = 1`; иначе она в колоде, и s уменьшается на её вес.
Единственность означает, что выполняется только одно из двух.
`O(N·W)` при W < 100 000.

Тонкие места:

- одинаковые карты — разные карты: при двух картах веса 1 и W = 1
  недоставать может любая, так что ответ -1 (тест 04);
- недоставать может несколько карт, вплоть до всех, кроме одной
  (тест 08).

Ответы сравнивались с перебором всех подмножеств на 1500 случайных
маленьких колодах.
