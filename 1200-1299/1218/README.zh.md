# 1218. 哪些绝地武士能赢得锦标赛

[Timus 1218](https://acm.timus.ru/problem.aspx?space=1&num=1218) · 难度 323 · graphs

原题作者 Leonid Volkov，出自第七届乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N ≤ 200` 名绝地武士各有三个参数，每个参数上所有人的值都不同。两人对决时，至少
两个参数更强的一方获胜，输者退出比赛。按输入顺序列出所有存在某种赛程能让其成为
最后留下者的武士。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后每名武士给出不超过 30 个字母的名字和三个绝对值不超过 `10⁵` 的整数。

## 输出

可能的冠军，每行一个，按输入顺序。

## 样例

### 样例 1

输入：

```
5
Solo 0 0 0
Anakin 20 18 30
Luke 40 12 25
Kenobi 15 3 2
Yoda 35 9 125
```

输出：

```
Anakin
Luke
Yoda
```

## 解法

每一对恰有一个胜者，所以“击败”关系是一张竞赛图。一名武士能赢得比赛，当且仅当
沿着胜利链可以从该武士到达所有其他武士。

如果所有人都可达，取以候选人为根的这样一棵链树，从叶子向上安排比赛：每名武士都与
树中位于其上方的那位对决并落败，直到只剩候选人。如果有人不可达，那么可达的人谁也赢不了
他们中的任何一个，所以候选人一方永远淘汰不掉他们中的最后一人。

因此用 Warshall 算法求“击败”关系的传递闭包，输出能到达所有其他人的武士。
`O(N³)`。

注意事项：

- 只有一名武士时，该武士自动获胜；
- 三人成环时，每个人都能获胜，正如样例所示；
- 输出保持输入顺序，而不是实力顺序。

答案已在 200 个随机赛事和所有测试上与另一份独立解答比对。
