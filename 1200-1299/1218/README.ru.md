# 1218. Какой джедай может выиграть турнир

[Timus 1218](https://acm.timus.ru/problem.aspx?space=1&num=1218) · сложность 323 · graphs

Автор оригинальной задачи — Леонид Волков; VII студенческое соревнование по программированию УрГУ.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У каждого из `N ≤ 200` джедаев три параметра, и в каждом параметре все
значения различны. Из двух джедаев матч выигрывает тот, кто сильнее хотя
бы в двух параметрах, а проигравший покидает турнир. Вывести в порядке
ввода всех джедаев, для которых найдётся расписание матчей, где они
остаются последними.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем для каждого джедая имя до 30 букв и три целых числа, по модулю
не больше `10⁵`.

## Выходные данные

Возможные победители, по одному в строке, в порядке ввода.

## Примеры

### Пример 1

Ввод:

```
5
Solo 0 0 0
Anakin 20 18 30
Luke 40 12 25
Kenobi 15 3 2
Yoda 35 9 125
```

Вывод:

```
Anakin
Luke
Yoda
```

## Решение

В каждой паре ровно один победитель, так что отношение «побеждает» —
турнирный граф. Джедай может выиграть турнир ровно тогда, когда от этого джедая
по цепочкам побед достижимы все остальные.

Если достижимы все, берём дерево таких цепочек с корнем в кандидате и
играем матчи от листьев вверх: каждый джедай встречается с тем, кто стоит
выше в дереве и выигрывает этот матч, пока не останется один кандидат. Если же
кто-то недостижим, никто из достижимых не может победить никого из них,
и последнего из них сторона кандидата выбить не сможет.

Поэтому строим транзитивное замыкание отношения «побеждает» алгоритмом
Уоршелла и выводим всех, из кого достижимы все остальные. `O(N³)`.

Тонкие места:

- единственный джедай побеждает по умолчанию;
- в кольце из трёх выиграть может любой, как в примере;
- вывод сохраняет порядок ввода, а не порядок по силе.

Ответы сверены с отдельно написанным решением на 200 случайных турнирах и
на всех тестах.

  матрицы.
