# 1249. Все ли тёмные области — прямоугольники?

[Timus 1249](https://acm.timus.ru/problem.aspx?space=1&num=1249) · сложность 220 · implementation

Авторы оригинальной задачи — Никита Шамгунов и Леонид Волков; открытое командное первенство УрГУ, 15 марта 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано изображение N × M из нулей и единиц (N, M ≤ 3000). Определить,
является ли каждая связная область единиц (клетки соединены сторонами)
прямоугольником со сторонами вдоль осей.

Ограничение времени: 2.5 секунды. Ограничение памяти: 4 МБ.

## Входные данные

N и M, затем N строк по M цифр через пробел.

## Выходные данные

`Yes` или `No`.

## Примеры

### Пример 1

Ввод:

```
2 2
0 1
1 1
```

Вывод:

```
No
```

### Пример 2

Ввод:

```
3 3
0 0 1
1 1 0
1 1 0
```

Вывод:

```
Yes
```

## Решение

Область не является прямоугольником ровно тогда, когда у неё где-то есть
внутренний угол, а внутренний угол — это окно 2 × 2 ровно с тремя
тёмными клетками. И наоборот, если ни в одном окне нет трёх тёмных
клеток, каждая область — прямоугольник: идя вдоль её границы, нельзя
повернуть внутрь. Так что вся проверка такова: ни в одном окне 2 × 2 нет
ровно трёх единиц.

Настоящее ограничение — память: в изображении до 9 миллионов клеток, а
текст входа — около 18 МБ при лимите 4 МБ. Окну нужны лишь две строки,
поэтому программа хранит предыдущую строку и текущую, читает вход
потоком и останавливается на первом плохом окне. Время `O(N·M)`, память
`O(M)`.

Тонкие места:

- чтение всего входа сразу или хранение изображения нарушает лимит в
  4 МБ;
- две области, касающиеся только углом, допустимы: в таком окне две
  тёмные клетки (второй пример).

Правило сравнивалось с поиском каждой области и проверкой, что она
заполняет свой ограничивающий прямоугольник, на 400 случайных маленьких
изображениях.

## Особенности языков

- Python читает по одной строке, превращает её в целое число,
  используемое как битовое множество, и находит плохое окно битовыми
  операциями: нечётное число единиц среди четырёх битов и не меньше двух
  из них.
- Java и Rust читают вход побайтно через небольшой буфер.
