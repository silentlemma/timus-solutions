# 1266. Закон Кирхгоффа

[Timus 1266](https://acm.timus.ru/problem.aspx?space=1&num=1266) · сложность 1401 · math

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В цепи N узлов (2 ≤ N ≤ 20) и M резисторов (1 ≤ M < 1000), каждый
соединяет два узла и имеет целое сопротивление от 1 до 1000; между
парой узлов может быть много резисторов. Найти общее сопротивление между
узлами 1 и N, округлённое до двух знаков после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем M строк `A B R`.

## Выходные данные

Сопротивление.

## Примеры

### Пример 1

Ввод:

```
4 5
1 2 15
2 4 5
1 3 10
3 4 10
2 3 1
```

Вывод:

```
9.40
```

## Решение

Следуем рецепту из условия. Сложим проводимости 1/R всех резисторов
между каждой парой узлов. Зафиксируем потенциал узла 1 равным 1, узла N
равным 0; в каждом другом узле сумма токов равна нулю:

```text
sum over v of g(u, v) · (V(u) − V(v)) = 0
```

Это линейная система не более чем из 18 неизвестных, она решается
методом Гаусса с выбором ведущего элемента. Ток из узла 1 равен
I = Σ g(1, v) · (1 − V(v)), а сопротивление — 1 / I.

Компоненты, отрезанные от обоих концов, тока не несут, а их потенциалы
не определены. Перед составлением системы поиском от узла 1 отбрасывают
все недостижимые из него внутренние узлы. Каждый оставшийся внутренний узел связан
с узлом 1, потенциал которого зафиксирован, поэтому система имеет
единственное решение. `O(M + N³)`.

Тонкие места:

- изолированные узлы и куски, отрезанные от обоих концов, делают систему
  вырожденной, если их оставить (тесты 05, 06);
- параллельные резисторы между одними узлами складываются как
  проводимости (тест 03);
- при N = 2 неизвестных нет совсем (тесты 02, 03).

Ответы сравнивались на 120 случайных цепях с формулой Кирхгофа через
матричную теорему о деревьях — отношением двух миноров лапласиана,
вычисленных в точных дробях.
