# 1246. В какую сторону обходят многоугольник

[Timus 1246](https://acm.timus.ru/problem.aspx?space=1&num=1246) · сложность 334 · geometry

Автор оригинальной задачи — Евгений Кобзев; личное первенство УрГУ, 1 марта 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Собака привязана к столбу внутри участка, обнесённого забором, — простого
многоугольника из N вершин (3 ≤ N ≤ 200 000, целые координаты по модулю
до 50 000). Бегун бегает круг за кругом вдоль забора, проходя вершины в
данном порядке, а собака гоняется за бегуном внутри. В какую сторону
намотается трос на столб: по часовой стрелке (`cw`) или против (`ccw`)?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N вершин в порядке обхода бегуном.

## Выходные данные

`cw` или `ccw`.

## Примеры

### Пример 1

Ввод:

```
4
0 0
0 1
1 1
1 0
```

Вывод:

```
cw
```

## Решение

Собака следует за бегуном вдоль внутренней стороны участка, так что трос
наматывается в ту сторону, в которую бегун обходит многоугольник. Это
знак ориентированной площади многоугольника по формуле шнурования,
`Σ (x_i·y_{i+1} − x_{i+1}·y_i)`: положительный при обходе против часовой
стрелки и отрицательный по часовой. Многоугольник простой и не вырожден,
так что сумма никогда не равна нулю. `O(N)`.

Тонкие места:

- многоугольник не обязательно выпуклый, так что поворот в одной
  вершине ничего не говорит; решает только площадь целиком (тесты 04 и
  05);
- каждое слагаемое доходит до 5·10⁹, больше 32 бит, поэтому сумма
  хранится в 64 битах.

## Особенности языков

- Python перемножает списки координат со сдвинутой копией через `map`;
  остальные языки проходят одним циклом.
