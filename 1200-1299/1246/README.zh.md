# 1246. 多边形按哪个方向被绕行

[Timus 1246](https://acm.timus.ru/problem.aspx?space=1&num=1246) · 难度 334 · geometry

原题作者 Evgeny Kobzev，出自 2003 年 3 月 1 日乌拉尔国立大学个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一条狗拴在围栏内一块地中的柱子上，这块地是一个有 N 个顶点的简单多边形
（3 ≤ N ≤ 200 000，坐标为绝对值不超过 50 000 的整数）。一个跑步者按给定的顶点顺序
沿着围栏一圈又一圈地跑，狗在里面追着跑步者跑。绳子会绕着柱子朝哪个方向缠：顺时针（`cw`）
还是逆时针（`ccw`）？

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是按跑步顺序给出的 N 个顶点。

## 输出

`cw` 或 `ccw`。

## 样例

### 样例 1

输入：

```
4
0 0
0 1
1 1
1 0
```

输出：

```
cw
```

## 解法

狗沿着这块地的内侧跟着跑步者，所以绳子缠绕的方向就是跑步者绕多边形的方向。这就是
用鞋带公式算出的多边形有向面积 `Σ (x_i·y_{i+1} − x_{i+1}·y_i)` 的符号：逆时针为正，
顺时针为负。多边形是简单的且不退化，所以和永远不为零。`O(N)`。

注意事项：

- 多边形不一定是凸的，所以某一个顶点处的转向说明不了什么；只有整体面积起决定作用
  （测试 04 和 05）；
- 每一项可达 5·10⁹，超过 32 位，所以和要用 64 位保存。
