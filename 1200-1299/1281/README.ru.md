# 1281. Бассейн реки

[Timus 1281](https://acm.timus.ru/problem.aspx?space=1&num=1281) · сложность 1771 · geometry

## Задача

На карте N ≤ 10 рек, каждая — ломаная от истока до устья, всего не
больше 1000 точек. Река, устье которой лежит во внутренней вершине
другой реки, — её приток. Бассейн реки — наименьший выпуклый
многоугольник, содержащий реку, её притоки, их притоки и так далее.
Вывести наибольшую площадь бассейна с двумя знаками после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем для каждой реки число точек и сами точки, возможно дробные.

## Выходные данные

Наибольшая площадь бассейна.

## Решение

Притоки находятся поиском последней точки каждой реки среди внутренних
вершин всех рек. Бассейн реки содержит её собственные точки и
рекурсивно точки её притоков, а его площадь — площадь их выпуклой
оболочки: оболочку даёт монотонная цепь, площадь — формула шнурования.
Реки образуют лес, поэтому рекурсия заканчивается. P — общее число точек.

Тонкие места:

- у притоков бывают свои притоки, и все они входят в бассейн (тест 05);
- у прямой реки площадь ноль (тест 03);
- устья сопоставляются с внутренними вершинами по точным ключам из прочитанных координат;
- площадь может оканчиваться ровно половиной последнего выводимого
  знака и округлиться в любую сторону, поэтому эти тесты сравнивают с
  допуском 0,01.

Ответы сравнивались с независимой реализацией на 90 сгенерированных
картах; расхождения были только на таких половинах, на 0,01.
