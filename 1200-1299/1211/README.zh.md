# 1211. 没有循环指认且只有一人认错的证词

[Timus 1211](https://acm.timus.ru/problem.aspx?space=1&num=1211) · 难度 311 · graphs

原题作者 Leonid Volkov，出自 2002 年 10 月 USU Open Collegiate Programming Contest（Junior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N ≤ 25000` 个孩子中，每个孩子要么承认是自己打碎了杯子（记为 0），要么指认一个
孩子为肇事者。如果恰好有一个孩子认错，并且没有一群孩子绕成一圈互相指认，证词就
看起来是一致的。对最多 16 个测试分别回答 `YES` 或 `NO`。

时间限制：2 秒。内存限制：64 MB。

## 输入

首行是整数 `1 ≤ T ≤ 16`。每个测试占两行：整数 `1 ≤ N ≤ 25000`，然后 N 个整数 `0 ≤ a_i ≤ N`。第 i 项属于孩子 i：0 表示认罪，正值表示所指孩子的从 1 开始编号，也可能是 i 自己。

## 输出

每个测试一行，`YES` 或 `NO`。

## 样例

### 样例 1

输入：

```
5
1
0
1
1
5
3 3 0 2 4
6
2 3 2 0 4 5
4
0 0 2 3
```

输出：

```
YES
NO
YES
NO
NO
```

## 解法

除认错者外，每个孩子恰好指向一个孩子，所以证词构成一张每个顶点至多一条出边的
图。在恰好一人认错的前提下，没有环当且仅当从任何孩子出发沿着指认走下去，最终都会
到达认错者。

依次从每个孩子出发行走，并标记当前路径上的孩子。路径在到达认错者，或到达已知能
通向认错者的孩子时停止；此时路径上的每个孩子也都通向那里。如果路径撞上当前路径上
已标记的孩子，指认就构成了环。每个孩子只被走过一次。每个测试 `O(N)`。

注意事项：

- 指认自己的孩子就是长度为一的环；
- 没有人认错或有两人认错，答案已经是 `NO`；
- 链长可达 25000，所以要用循环而不是递归来走。

答案已在 200 个文件、每个 16 组各类随机测试上与另一份独立解答比对。

链遍历每个测试用 `O(N)` 工作空间存指控、状态和当前路径。全部 T 个测试时间 `O(Σ N_i)`。令 I 为全部输入字节数，H 为最长行。基础 Python 保留全部切分 token，Rust 保留整个 String，因此空间 `O(I + max N_i + T)`。C++、Go 用有界缓冲流式读取，图空间 `O(max N_i)`。Java 还保留当前行及 T 个答案词，空间 `O(max N_i + H + T)` 加库缓冲。优化 Rust 保留有界输入缓冲/token、指控、状态、路径及 T 个答案，空间 `O(max N_i + T + B)`，B 为固定缓冲。DSU 随读取处理指控，每个测试摊还时间 `O(N α(N))`；实际静态 25001 项有符号 16 位数组与缓冲占 `O(M + B)`，M=25000，小测试也分配该大小。最大索引 25000 和最小负分量大小 −25000 均能放入有符号 16 位。

## 优化解法

C++ 和 Go 版本用并查集边读边处理指认。如果两个孩子已经连通，新增的指认会闭合一个无向环。环中每个孩子至多发出一次指认，因此每个孩子恰好提供一条环上的边，整个环必然有向。自我指认和互相指认也同样处理。要求恰好一人认错且没有环。每个有符号 16 位条目保存父节点编号或负的分量大小。

精确源码缓存采用统一[排名标准](../../RATING_CRITERIA.md)。基础 Java、Python 已达标，直接复用不复制。两份 Go 均通过同语言回退比较，因无精确编译器对手。C++ 快速覆盖由 `1211_dsu.cpp` 提供，Rust 由 `1211_graphs_implementation_optimized.rs`（#11328956，0.031 s / 580 KB）提供。基础 Rust #11283644 的 0.031 s / 5212 KB 未过必需内存比较，基础 C++ 未过时间；两者作为不标星教学版保留。低于 1024 KB 只比时间；达标且高于此界的 Go/Java/Python 需两项。没有单独第一名目标。
