# 1211. 没有循环指认且只有一人认错的证词

[Timus 1211](https://acm.timus.ru/problem.aspx?space=1&num=1211) · 难度 311 · graphs

原题作者 Leonid Volkov，出自 2002 年 10 月 USU Open Collegiate Programming Contest（Junior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N ≤ 25000` 个孩子中，每个孩子要么承认是自己打碎了杯子（记为 0），要么指认一个
孩子为肇事者。如果恰好有一个孩子认错，并且没有一群孩子绕成一圈互相指认，证词就
看起来是一致的。对最多 16 个测试分别回答 `YES` 或 `NO`。

时间限制：2 秒。内存限制：64 MB。

## 输入

`T`，然后每个测试给出 `N` 和 `N` 条证词。

## 输出

每个测试一行，`YES` 或 `NO`。

## 样例

### 样例 1

输入：

```
4
4
2 0 2 2
4
2 0 2 1
5
2 3 4 1 3
3
0 3 2
```

输出：

```
YES
YES
NO
NO
```

## 解法

除认错者外，每个孩子恰好指向一个孩子，所以证词构成一张每个顶点至多一条出边的
图。在恰好一人认错的前提下，没有环当且仅当从任何孩子出发沿着指认走下去，最终都会
到达认错者。

依次从每个孩子出发行走，并标记当前路径上的孩子。路径在到达认错者，或到达已知能
通向认错者的孩子时停止；此时路径上的每个孩子也都通向那里。如果路径撞上当前路径上
已标记的孩子，指认就构成了环。每个孩子只被走过一次。每个测试 `O(N)`。

注意事项：

- 指认自己的孩子就是长度为一的环；
- 没有人认错或有两人认错，答案已经是 `NO`；
- 链长可达 25000，所以要用循环而不是递归来走。

答案已在 200 个文件、每个 16 组各类随机测试上与另一份独立解答比对。

## 优化解法

C++ 和 Go 版本用并查集边读边处理指认。如果两个孩子已经连通，新增的指认会闭合一个无向环。环中每个孩子至多发出一次指认，因此每个孩子恰好提供一条环上的边，整个环必然有向。自我指认和互相指认也同样处理。要求恰好一人认错且没有环。每个有符号 16 位条目保存父节点编号或负的分量大小。

已通过评测的基础实现 [1211_graphs.java](1211_graphs.java), [1211_graphs.py](1211_graphs.py), [1211_graphs.rs](1211_graphs.rs) 也满足快速版本的要求：在保存的比较快照中，时间和内存均符合前 15% 或前十名的排名收录规则。直接复用这些源文件，不创建相同副本。星号标记尚未达到该语言目标排名的版本。
