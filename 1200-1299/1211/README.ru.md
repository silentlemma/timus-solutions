# 1211. Показания без круга и с одним признанием

[Timus 1211](https://acm.timus.ru/problem.aspx?space=1&num=1211) · сложность 311 · graphs

Автор оригинальной задачи — Леонид Волков; USU Open Collegiate Programming Contest, октябрь 2002 года, Junior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждый из `N ≤ 25000` детей либо признаётся, что разбил кружку
(записано как 0), либо называет виновным ребёнка. Показания
выглядят непротиворечивыми, если признался ровно один ребёнок и нет группы
детей, указывающих друг на друга по кругу. Ответить `YES` или `NO` для
каждого из не более чем 16 тестов.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`T`, затем для каждого теста `N` и `N` показаний.

## Выходные данные

`YES` или `NO` для каждого теста, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
4
4
2 0 2 2
4
2 0 2 1
5
2 3 4 1 3
3
0 3 2
```

Вывод:

```
YES
YES
NO
NO
```

## Решение

Каждый ребёнок, кроме признавшегося, указывает ровно на одного ребёнка,
так что показания образуют граф, где из каждой вершины выходит не больше
одного ребра. При ровно одном признании круга нет тогда и только тогда,
когда, идя по обвинениям от любого ребёнка, всегда приходим к
признавшемуся.

Идём по очереди от каждого ребёнка, отмечая детей на текущем пути. Путь
останавливается на признавшемся или на ребёнке, про которого уже
известно, что он туда ведёт; тогда туда ведёт и каждый ребёнок на пути.
Если же путь наткнулся на ребёнка, отмеченного на текущем пути, обвинения
идут по кругу. Каждый ребёнок проходится один раз. `O(N)` на тест.

Тонкие места:

- ребёнок, назвавший самого себя, — круг из одного;
- ни одного признания или два — уже `NO`;
- цепочки бывают длиной 25000, поэтому обход — цикл, а не рекурсия.

Ответы сверены с отдельно написанным решением на 200 файлах по 16
случайных тестов всех видов.

## Оптимизированные решения

Версии C++ и Go обрабатывают обвинения по мере чтения с помощью системы непересекающихся множеств. Обвинение между уже связанными вершинами замыкает неориентированный цикл. Из каждой вершины выходит не более одного обвинения, поэтому каждая вершина цикла даёт ровно одно его ребро и цикл оказывается ориентированным. Сюда же относятся самообвинение и два встречных обвинения. Требуется одно признание и отсутствие циклов. Знаковая 16-битная ячейка хранит индекс родителя или отрицательный размер компоненты.

Принятые базовые реализации [1211_graphs.java](1211_graphs.java), [1211_graphs.py](1211_graphs.py), [1211_graphs.rs](1211_graphs.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
