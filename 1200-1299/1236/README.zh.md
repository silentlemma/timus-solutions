# 1236. 从错位的消息恢复异或密钥

[Timus 1236](https://acm.timus.ru/problem.aspx?space=1&num=1236) · 难度 498 · math

原题作者 Elena Kruchkova，出自 2002–2003 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

消息按字节加密：`E[i] = K[i] xor C[i]`，K 是秘密密钥。同一段 N 字节的明文
（1 ≤ N ≤ 10 000）被发送了两次：一次原样，一次在前面加了一个空格（字节 32）。
根据两条密文恢复密钥的前 N + 1 个字节。

时间限制：1 秒。内存限制：64 MB。

## 输入

两行十六进制数字：N 字节的密文，然后是 N + 1 字节的密文。

## 输出

用同样的十六进制形式输出密钥的 N + 1 个字节。

## 样例

### 样例 1

输入：

```
05262C5269143F314C2A69651A264B
610728413B63072C52222169720B425E
```

输出：

```
41434D2049435043204E454552432732
```

## 解法

把两条密文记为 S（短）和 L（长）。长明文以已知的空格开头，所以
`K[0] = L[0] xor 32`。此后，长密文的第 i + 1 个字节和短密文的第 i 个字节隐藏着
同一个明文字节 C[i]：

```text
C[i] = S[i] xor K[i],   K[i+1] = L[i+1] xor C[i] = L[i+1] xor S[i] xor K[i]
```

每个密钥字节都能推出下一个，所以一遍扫描就能恢复全部 N + 1 个。`O(N)`。

注意事项：

- 每个字节都输出为两位大写数字，小于 16 时要补前导零（测试 gen3）。
