# 1236. Восстановление ключа XOR по сдвинутому сообщению

[Timus 1236](https://acm.timus.ru/problem.aspx?space=1&num=1236) · сложность 499 · math

Автор оригинальной задачи — Елена Крючкова; полуфинал ACM ICPC Северо-Восточной Европы 2002–2003.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Сообщения шифруются побайтно как `E[i] = K[i] xor C[i]` с секретным
ключом K. Один и тот же открытый текст из N байт (1 ≤ N ≤ 10 000)
отправили дважды: как есть и с одним пробелом (байт 32) в начале. По
обоим зашифрованным сообщениям восстановить первые N + 1 байт ключа.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Две строки шестнадцатеричных цифр: зашифрованное сообщение из N байт,
затем из N + 1 байта.

## Выходные данные

N + 1 байт ключа в том же шестнадцатеричном виде.

## Примеры

### Пример 1

Ввод:

```
05262C5269143F314C2A69651A264B
610728413B63072C52222169720B425E
```

Вывод:

```
41434D2049435043204E454552432732
```

## Решение

Обозначим зашифрованные сообщения S (короткое) и L (длинное). Длинный
текст начинается с известного пробела, поэтому `K[0] = L[0] xor 32`.
Дальше байт i + 1 длинного сообщения и байт i короткого скрывают один и
тот же открытый байт C[i]:

```text
C[i] = S[i] xor K[i],   K[i+1] = L[i+1] xor C[i] = L[i+1] xor S[i] xor K[i]
```

Каждый байт ключа даёт следующий, так что один проход восстанавливает
все N + 1. `O(N)`.

Тонкие места:

- каждый байт выводится двумя заглавными цифрами, с ведущим нулём, если
  он меньше 16 (тест gen3).

## Особенности языков

  функциями; C++, Java и Rust разбирают пары цифр сами.
