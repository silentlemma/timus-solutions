# 1261. Чаевые

[Timus 1261](https://acm.timus.ru/problem.aspx?space=1&num=1261) · сложность 329 · number_theory

## Задача

Купюры бывают в 1, 3, 9, 27, … тритов, и у гостя ровно по одной купюре
каждого достоинства. Счёт равен N тритов (1 ≤ N ≤ 10⁷). Гость платит
какую-то сумму, а сдачу официант оставляет себе в качестве чаевых.
Официант обижается, если чаевые не положительны или их нельзя набрать
разными купюрами. Найти сумму оплаты и чаевые; оплата не может
превышать 4 294 967 291. Принимается любая подходящая пара; если её
нет, вывести 0.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

Сумма оплаты и чаевые.

## Проверка

Подходящих пар много, поэтому чекер принимает любую: оплата минус
чаевые должна равняться N, чаевые — быть положительными, оплата — не
выходить за предел, и обе суммы в троичной записи должны состоять
только из цифр 0 и 1.

## Примеры

### Пример 1

Ввод:

```
5
```

Вывод:

```
9 4
```

## Решение

И оплата P, и чаевые T — суммы различных степеней 3, и P − T = N.
Запишем N в уравновешенной троичной системе с цифрами −1, 0 и 1: цифры
1 образуют P, а цифры −1 образуют T. Идём с младшего разряда: остаток 1
даёт цифру 1, остаток 2 — цифру −1 с переносом в следующий разряд.

Если в троичной записи N нет цифры 2, получается T = 0. Тогда возьмём
наименьшую степень 3, которой нет в P, и добавим её к обеим суммам: в P
купюры остаются различными, а T состоит из одной этой купюры. Значит,
ответ существует всегда, и 0 не выводится никогда. P остаётся меньше
3¹⁶ ≈ 4,3 · 10⁷, далеко от предела. `O(log N)`.

Тонкие места:

- чаевые должны быть положительными: N = 1 нельзя оплатить как 1 с
  чаевыми 0, а 4 3 — один из ответов (тест 02);
- для оплаты может понадобиться купюра больше N: N = 10⁷ оплачивается
  суммой 14 960 143 с чаевыми 4 960 143 (тест 03);
- оплата и чаевые могут содержать одну и ту же купюру: чаевые — лишь
  сумма, которую можно было бы набрать, а не купюры гостя.

Все N от 1 до 3000 и два наибольших прогнаны через чекер.
