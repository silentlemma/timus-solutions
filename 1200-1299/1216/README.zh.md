# 1216. 两个兵和一个王：白方能升变吗

[Timus 1216](https://acm.timus.ru/problem.aspx?space=1&num=1216) · 难度 2043 · games

原题作者 Leonid Volkov，出自第七届乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在 `N × N`（`6 ≤ N ≤ 26`）的棋盘上有一个白兵、一个黑兵和黑王，没有白王。按通常
的国际象棋规则：白方先走，兵可以从初始横线走两格，黑兵可以吃过路兵吃掉白兵，黑王
不能站在白兵攻击的格子上，黑兵走到第一横线时按黑方意愿升变为后、车、象或马。白兵
走到最后一横线白方即胜；其他所有情况，包括白方无棋可走的局面，都算黑方胜。判断
谁获胜。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后是白兵、黑兵和黑王所在的格子，例如 `h5`。

## 输出

`WHITE WINS` 或 `BLACK WINS`。

## 样例

### 样例 1

输入：

```
10
h5 i5 b3
```

输出：

```
WHITE WINS
```

### 样例 2

输入：

```
8
d5 h6 b6
```

输出：

```
BLACK WINS
```

## 解法

带记忆地搜索博弈树。白方每走一步，白兵至少前进一横线，所以局面不会重复，搜索
必然结束；轮到白方的局面连同结果一起记下。

轮到白方时最多有四种选择：前进一格、从初始横线前进两格，或向某一侧吃子。走到最后
一横线的着法立即获胜。在同一横线上紧挨黑兵的双步会被吃过路兵，因此跳过。

轮到黑方时先找吃子：王紧挨白兵、黑兵在白兵的斜前方，或升变后的棋子沿空线能到达
白兵。任何一种都是黑方胜。否则黑方尝试王走到不被白兵攻击的每个格子、兵的每种走法
（在第一横线有四种升变，在初始横线可走两格）以及升变棋子的每种走法；只有对所有
这些着法白方都能获胜，白方才算获胜，而黑方无棋可走按规则算黑方胜。实际遇到的局面
在数万个量级。

注意事项：

- 两个兵都可以从初始横线走两格，但只有黑兵可以吃过路兵；
- 王不能走到白兵攻击的两个格子上，但走到兵旁边的其他格子是可以的，这时它威胁要吃
  掉兵；
- 规则允许黑方升变为四种棋子中的任意一种，所以每种都要尝试，而不是假定升后
  最好；
- 白兵走到最后一横线白方就赢，即使新后立刻会被吃掉。

答案已在 200 个各类随机局面和所有测试上与另一份独立解答比对。
