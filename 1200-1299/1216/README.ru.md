# 1216. Две пешки и король: проведут ли белые пешку?

## Задача

На доске `N × N`, `6 ≤ N ≤ 26`, стоят белая пешка, чёрная пешка и чёрный
король, белого короля нет. Действуют обычные шахматные правила: белые
ходят первыми, пешки могут с начальной горизонтали шагнуть на две
клетки, чёрная пешка может взять белую на проходе, чёрный король не может
стоять под боем белой пешки, а чёрная пешка, дойдя до первой горизонтали,
превращается в ферзя, ладью, слона или коня по выбору чёрных. Белые
выигрывают, если их пешка дошла до последней горизонтали; во всех
остальных случаях, включая позицию, где белым некуда ходить, выигрывают
чёрные. Определить победителя.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем поля белой пешки, чёрной пешки и чёрного короля, например
`h5`.

## Выходные данные

`WHITE WINS` или `BLACK WINS`.

## Примеры

### Пример 1

Ввод:

```
10
h5 i5 b3
```

Вывод:

```
WHITE WINS
```

### Пример 2

Ввод:

```
8
d5 h6 b6
```

Вывод:

```
BLACK WINS
```

## Решение

Перебираем дерево игры с запоминанием. Каждый ход белых продвигает белую
пешку хотя бы на одну горизонталь, поэтому позиции не повторяются и
перебор всегда заканчивается; позиция с ходом белых запоминается вместе с
результатом.

У белых при их ходе не больше четырёх вариантов: шаг вперёд, два шага с
начальной горизонтали или взятие в одну из сторон. Ход на последнюю
горизонталь сразу выигрывает. Двойной шаг рядом с чёрной пешкой на той же
горизонтали проигрывает из-за взятия на проходе и пропускается.

Чёрные при своём ходе сначала ищут взятие: король рядом с белой пешкой,
чёрная пешка по диагонали перед ней или превращённая фигура, достающая её
по свободной линии. Любое из них выигрывает для чёрных. Иначе чёрные
пробуют каждый шаг короля на поле не под боем пешки, каждый ход пешки (с
четырьмя превращениями на первой горизонтали и двойным шагом с
начальной) и каждый ход превращённой фигуры; белые выигрывают, только
если выигрывают после всех них, а чёрные без единого хода по правилам
выигрывают. На практике получаются десятки тысяч позиций.

Тонкие места:

- обе пешки могут шагнуть на две клетки с начальной горизонтали, но
  брать на проходе может только чёрная;
- король не может встать на два поля под боем белой пешки, но встать
  рядом с пешкой в другом месте можно, и тогда он грозит её взять;
- правила разрешают чёрным превратить пешку в любую из четырёх фигур,
  поэтому пробуется каждая, а не только ферзь;
- белые выигрывают, дойдя до последней горизонтали, даже если нового
  ферзя тут же можно взять.

Ответы сверены с отдельно написанным решением на 200 случайных позициях
всех видов и на всех тестах.

## Особенности языков

- Во всех языках один и тот же перебор с запоминанием; Python поднимает
  предел рекурсии, ведь на каждую горизонталь подъёма пешки перебор
  уходит на два уровня глубже.
