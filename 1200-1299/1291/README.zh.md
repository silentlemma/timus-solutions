# 1291. 齿轮

[Timus 1291](https://acm.timus.ru/problem.aspx?space=1&num=1291) · 难度 383 · bfs

原题作者 Pavel Egorov，出自 2004 年 3 月 13 日第九届中学生公开团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N ≤ 1000 个齿轮，每个有 1 到 1000 个齿，两两啮合，连接不构成环。其中一个齿轮以 1 到 1000 的
速度逆时针转动。用最简分数输出每个齿轮的速度：逆时针为正，顺时针为负，不转动的齿轮输出 0/1。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后对每个齿轮给出齿数和与它啮合的齿轮列表，以 0 结尾。最后一行是主动齿轮及其速度。

## 输出

N 行速度，格式为 `p/q`，负号写在 p 前面。

## 样例

### 样例 1

输入：

```
4
10 2 3 0
20 1 0
40 1 4 0
100 3 0
1 6
```

输出：

```
6/1
-3/1
-3/2
3/5
```

## 解法

两个啮合的齿轮在单位时间内转过的齿数相同，所以速度 × 齿数相等，且转向相反。沿着从主动齿轮 r
出发的任意一条链，速度 × 齿数都不变，因此驱动能到达的每个齿轮 j 的速度是

± 速度 · 齿数(r) / 齿数(j)，

每经过一条连接符号翻转一次：与 r 距离为偶数时为 +，为奇数时为 −。没有环，所以距离是确定的，
从 r 出发的广度优先搜索就能求出它的奇偶性。到达不了的齿轮静止。每个分数用 速度 · 齿数(r) ≤ 10⁶
与 齿数(j) 的最大公约数约分，32 位整数就够用。`O(N + L)`，L 为列出的连接数。

注意事项：

- 不在被驱动的树中的齿轮输出 0/1（测试 03）；
- 题目没有保证每条连接在两端都列出，所以每条连接都双向保存（测试 04）；
- 分数必须约分（测试 05）。

在 40 个随机森林上与直接传播精确分数的做法比较过。
