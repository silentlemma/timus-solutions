# 1273. Шпалы

[Timus 1273](https://acm.timus.ru/problem.aspx?space=1&num=1273) · сложность 464 · dp

Автор оригинальной задачи — Магаз Асанов (подготовил Леонид Волков); чемпионат Уральского государственного университета, 25 октября 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Два рельса — прямые x = 0 и x = 1. Каждая из K ≤ 100 шпал соединяет
(0, Y1) с (1, Y2) в целых точках, |Y1|, |Y2| ≤ 1000; никакие две шпалы
не имеют общего левого или общего правого конца. Убрать как можно
меньше шпал, чтобы никакие две из оставшихся не пересекались.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

K, затем K пар Y1 Y2.

## Выходные данные

Наименьшее число шпал, которые нужно убрать.

## Примеры

### Пример 1

Ввод:

```
3
0 1
3 0
1 2
```

Вывод:

```
1
```

## Решение

Раз концы не совпадают, две шпалы пересекаются ровно тогда, когда их
левые и правые концы идут в противоположном порядке. Отсортируем шпалы
по левому концу; тогда набор без пересечений — это набор с возрастающими
правыми концами, и больше всего шпал остаётся в наибольшей возрастающей
подпоследовательности правых концов. Ответ — K минус её длина; её
находит квадратичная динамика по последней оставленной шпале. `O(K²)`.

Тонкие места:

- вход не упорядочен ни по одному концу (тест 06);
- K может быть 0 (тест 02);
- координаты бывают отрицательными.

Ответы сравнивались с перебором всех подмножеств шпал на 119 случайных
случаях до 12 шпал.

## Особенности языков

- Все языки сортируют пары и выполняют одну и ту же динамику.
