# 1227. 单向道路上给定长度的拉力赛路线

[Timus 1227](https://acm.timus.ru/problem.aspx?space=1&num=1227) · 难度 301 · graphs

原题出自 2002 年 10 月在雷宾斯克举行的 ACM ICPC 2002–2003 俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `M ≤ 100` 个城市和 `N ≤ 10⁴` 条给定长度的双向道路。为了安全，拉力赛路线上的
每条道路只能按一个方向行驶，路线可以在道路上的任意位置开始和结束。判断是否存在
长度恰好为 `S ≤ 2·10⁶` 的路线。

时间限制：1 秒。内存限制：64 MB。

## 输入

`M`、`N` 和 `S`，然后每条道路给出两个城市和长度。

## 输出

`YES` 或 `NO`。

## 样例

### 样例 1

输入：

```
3 2 20
1 2 10
2 3 5
```

输出：

```
NO
```

### 样例 2

输入：

```
3 3 1000
1 2 1
2 3 1
1 3 1
```

输出：

```
YES
```

## 解法

如果道路中有环，路线可以沿同一方向反复绕行，所以任何长度都可以。从城市到自身的
环路，或同一对城市之间的第二条道路，也都是这样的环。并查集能找出第一条两端已连通
的道路。

否则道路构成一个森林。每条道路只能单向行驶，意味着路线不能折返，只能沿简单路径
前进；又因为可以在道路中间开始和停下，不超过最长路径长度的任何长度都能达到。树中
最长的路径就是它的直径：从任意城市走到最远的城市，再从那里走到最远的城市。当且仅
当某棵树的直径不小于 `S` 时答案为 `YES`。`O(N α(M) + M)`。

注意事项：

- 从城市连回自身的道路算作环；
- 同一对城市之间的两条道路也能让车一直兜圈子；
- 森林可能有多棵树，每棵树要分别求直径；
- 长度恰好等于直径的路线是允许的。

答案已在 200 张有环和无环、`S` 接近直径的随机地图上与另一份独立解答比对。
