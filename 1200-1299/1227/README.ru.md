# 1227. Маршрут ралли заданной длины по односторонним дорогам

[Timus 1227](https://acm.timus.ru/problem.aspx?space=1&num=1227) · сложность 302 · graphs

Оригинальная задача — четвертьфинал ACM ICPC 2002–2003, центральный регион России, Рыбинск, октябрь 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `M ≤ 100` городов и `N ≤ 10⁴` двусторонних дорог заданной длины.
Ради безопасности каждая дорога маршрута ралли проходится только в одном
направлении, а маршрут может начинаться и кончаться в любом месте дороги.
Определить, существует ли маршрут длины ровно `S ≤ 2·10⁶`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`M`, `N` и `S`, затем каждая дорога — два города и длина.

## Выходные данные

`YES` или `NO`.

## Примеры

### Пример 1

Ввод:

```
3 2 20
1 2 10
2 3 5
```

Вывод:

```
NO
```

### Пример 2

Ввод:

```
3 3 1000
1 2 1
2 3 1
1 3 1
```

Вывод:

```
YES
```

## Решение

Если в дорогах есть цикл, маршрут может проходить его снова и снова в
одном направлении, так что годится любая длина. Петля из города в себя
или вторая дорога между теми же двумя городами — тоже такой цикл.
Система непересекающихся множеств находит первую дорогу, концы которой
уже связаны.

Иначе дороги образуют лес. Раз дорогу можно проходить только в одну
сторону, маршрут не может развернуться и идёт по простому пути, а раз он
может начинаться и заканчиваться посреди дороги, достижима любая длина
до длины самого длинного пути. Самый длинный путь дерева — его диаметр:
из любого города идём в самый дальний, а оттуда снова в самый дальний.
Ответ `YES` ровно тогда, когда диаметр какого-то дерева не меньше `S`.
`O(N + M²)`, или `O(N + M log M)` для Python.

Тонкие места:

- дорога из города в него же считается циклом;
- две дороги между одной парой городов тоже позволяют ездить по кругу
  сколько угодно;
- в лесу может быть несколько деревьев, и у каждого свой диаметр;
- маршрут длиной ровно в диаметр разрешён.

Ответы сверены с отдельно написанным решением на 200 случайных картах с
циклами и без, с `S` около диаметра.

## Оптимизированные решения

Версии Go, Rust и Python по-прежнему находят циклы с помощью системы непересекающихся множеств. В лесу достаточно одного обхода для каждого дерева. Каждый ребёнок возвращает длину самого глубокого пути вниз. Прежде чем сохранить большую ветвь, складываем длины новой ветви и лучшей из уже просмотренных в этом городе. Путь через город использует две разные ветви или начинается в самом городе, поэтому этих сумм достаточно. Python записывает порядок обхода и идёт по нему в обратную сторону, чтобы обработать детей раньше родителей. Go хранит смежность в одном массиве с однобайтовыми индексами вершин и рёбер. Время обхода линейно по размеру леса.

Принятая версия Rust 1.75 x64 заняла 0.031 с при 0.015 с у базовой и использовала 212 KB при 464 KB у базовой.

Принятые базовые реализации [1227_graphs.cpp](1227_graphs.cpp), [1227_graphs.java](1227_graphs.java) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
