# 1280. Топологическая сортировка

## Задача

Есть N ≤ 1000 предметов и M ≤ 100 000 правил «s u»: предмет s нужно
изучить раньше предмета u. Согласуется ли заданный порядок всех N
предметов со всеми правилами?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, M правил, затем порядок N предметов.

## Выходные данные

`YES` или `NO`.

## Примеры

### Пример 1

Ввод:

```
5 6
1 3
1 4
3 5
5 2
4 2
1 2
1 3 4 5 2
```

Вывод:

```
YES
```

### Пример 2

Ввод:

```
5 6
1 3
1 4
3 5
5 2
4 2
1 2
1 2 4 5 3
```

Вывод:

```
NO
```

## Решение

Ничего сортировать не нужно: запомним место каждого предмета в
заданном порядке и проверим, что каждое правило идёт вперёд, то есть s
стоит раньше u. Если в правилах есть цикл, какое-то правило на нём при
любом порядке идёт назад, так что проверка и так скажет `NO`, как и
требует условие. `O(N + M)`.

Тонкие места:

- для `NO` достаточно одного нарушенного правила; порядок в тесте 02
  нарушает три правила: 3 → 5, 5 → 2 и 4 → 2;
- правило может вести от предмета к нему же, и его не выполнит никакой
  порядок (тест 04);
- правила могут повторяться (тест 07);
- без правил годится любой порядок (тест 06).

## Особенности языков

- Все языки хранят места в массиве и один раз проходят по правилам.
