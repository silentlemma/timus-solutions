# 1265. 镜子

[Timus 1265](https://acm.timus.ru/problem.aspx?space=1&num=1265) · 难度 1539 · geometry

原题作者 Alexander Klepinin（由 Ivan Dashkevich 准备），出自 2003 年 10 月 25 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给出眼睛 (x1, y1)、目标 (x2, y2) 和一面平面镜，即 (xm1, ym1) 与 (xm2, ym2) 之间的线段，
判断从眼睛能否在镜中看到目标。镜子两面都能反射，入射角等于反射角。八个数都在
[−1000, 1000] 内，小数点后最多六位；两个点都不在镜子所在直线上，镜子两端不重合。

时间限制：1 秒。内存限制：64 MB。

## 输入

八个数，以空格和换行分隔。

## 输出

`VISIBLE` 或 `INVISIBLE`。

## 样例

### 样例 1

输入：

```
1 0 0 -1 0 0 1 1
```

输出：

```
VISIBLE
```

### 样例 2

输入：

```
0.000001   0
0   0.000001
-0.000001   -0.000001
0.000001   0.000001
```

输出：

```
INVISIBLE
```

## 解法

当两点位于镜子所在直线的同一侧，并且从眼睛到目标镜像的视线与镜子线段相交（端点也算）
时，目标可见。

把原点放在镜子的一端 A，令 s 沿镜子方向，e 和 t 分别是眼睛和目标相对 A 的向量。叉积
he = s × e 和 ht = s × t 是两点到直线的高度乘以 |s|，它们必须同号。点积 pe = s · e 和
pt = s · t 是两点沿直线的位置乘以 |s|。视线与镜子直线的交点按高度之比分割两个垂足之间
的路程，所以交点位于从 A 起镜长的

```text
u = (pe · ht + pt · he) / ((he + ht) · |s|²)
```

倍处，当且仅当 0 ≤ u ≤ 1 时目标可见。

浮点数在这里不够用：交点可能只距长约两千的镜子端点百万分之几，而这就决定了答案。所以每个数都按
百万分之一读成精确整数，最大 10⁹。此时高度和位置可达 8 · 10¹⁸，判定中的乘积约达
1.3 · 10³⁸，仍在有符号 128 位整数范围内。`O(1)`。

注意事项：

- 目标在镜前也不一定可见：反射后的视线可能错过线段（测试 04）；
- 经过镜子端点的视线算作可见（测试 05），把眼睛移动 10⁻⁶ 就会改变答案（测试 06、07）；
- 位于两侧的点永远不可见，即使镜子是双面的（测试 02、03）；
- 仅 he + ht 这一和就可能超出 64 位。

在 1500 组随机数据（小整数和六位小数的点）上，与用分数精确反射目标再判断线段相交的方法
比较过。

## 各语言说明

- C++ 和 Rust 用 `__int128` 和 `i128` 计算；Go 和 Java 用 64 位计算高度和位置，最后的乘积
  用 `big.Int` 和 `BigInteger`；Python 使用自带的整数。
- 所有语言都手工解析数字，把小数部分补足到六位，任何值都不经过 double。
