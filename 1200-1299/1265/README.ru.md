# 1265. Зеркало

[Timus 1265](https://acm.timus.ru/problem.aspx?space=1&num=1265) · сложность 1514 · geometry

## Задача

Даны глаз (x1, y1), цель (x2, y2) и плоское зеркало — отрезок между
(xm1, ym1) и (xm2, ym2). Определить, видна ли цель из глаза в зеркале.
Зеркало отражает с обеих сторон, угол падения равен углу отражения. Все
восемь чисел лежат в [−1000, 1000] и имеют не больше шести знаков после
точки; ни одна из точек не лежит на прямой зеркала, концы зеркала
различны.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Восемь чисел, разделённых пробелами и переводами строк.

## Выходные данные

`VISIBLE` или `INVISIBLE`.

## Примеры

### Пример 1

Ввод:

```
1 0 0 -1 0 0 1 1
```

Вывод:

```
VISIBLE
```

### Пример 2

Ввод:

```
0.000001   0
0   0.000001
-0.000001   -0.000001
0.000001   0.000001
```

Вывод:

```
INVISIBLE
```

## Решение

Цель видна, когда обе точки лежат по одну сторону от прямой зеркала, а
луч зрения от глаза к зеркальному образу цели пересекает отрезок
зеркала, включая концы.

Поместим начало координат в конец A зеркала AB, пусть s = B − A,
а e и t — глаз и цель относительно A. Векторные произведения he = s × e
и ht = s × t — высоты точек над прямой, умноженные на |s|; у них должен
быть один знак. Скалярные произведения pe = s · e и pt = s · t — их
положения вдоль прямой, умноженные на |s|. Луч зрения пересекает прямую
зеркала там, где делит путь между двумя основаниями перпендикуляров в
отношении высот, то есть в точке

```text
u = (pe · ht + pt · he) / ((he + ht) · |s|²)
```

от A в долях длины зеркала, и цель видна ровно тогда, когда 0 ≤ u ≤ 1.

Плавающей точки здесь не хватает: пересечение может отстоять на
несколько миллионных от конца зеркала длиной в две тысячи и решать ответ. Поэтому
каждое число читается как точное целое в миллионных, до 10⁹ по модулю.
Векторные и скалярные произведения ограничены по модулю 4 · 10¹⁸
и 8 · 10¹⁸, итоговые — 6,4 · 10³⁷, что помещается в знаковое
128-битное целое. `O(1)`.

Тонкие места:

- цель перед зеркалом видна не всегда: отражённый луч может пройти мимо
  отрезка (тесты 03, 04);
- луч через конец зеркала считается видимым (тест 05), а сдвиг глаза на
  10⁻⁶ меняет ответ (тесты 06, 07);
- точки по разные стороны не видны никогда, даже при двустороннем
  зеркале (тест 02);
- итоговым произведениям нужно больше 64 бит.

Ответы сравнивались на 1500 случайных случаях (малые целые и точки с
шестью знаками) с точным отражением цели в дробях и проверкой
пересечения отрезков.

## Особенности языков

- C++ и Rust считают в `__int128` и `i128`; Go и Java берут высоты и
  положения в 64 битах, а итоговые произведения — в `big.Int` и
  `BigInteger`; Python использует свои целые.
- Все языки разбирают числа вручную, дополняя дробную часть до шести
  цифр, так что ни одно значение не проходит через double.
