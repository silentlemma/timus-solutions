# 1210. 逐层攀升行星的最低花费

[Timus 1210](https://acm.timus.ru/problem.aspx?space=1&num=1210) · 难度 170 · dp

原题作者 Leonid Volkov，出自 2002 年 10 月 USU Open Collegiate Programming Contest（Junior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

行星分布在第 0 层到第 `N < 30` 层，每层最多 30 颗，第 0 层只有一颗，即旅行者的
家。通道只从某一层的行星通往下一层的行星，每条通道的花费是 `−32768` 到 `32767`
之间的整数；负的花费表示守护通道的精灵会倒贴给旅行者。求从家到第 `N` 层任意一颗
行星的最便宜路线，结果可能为负。保证至少存在一条路线。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后是 `N` 个块，块之间用只含 `*` 的行分隔。第 `i` 块以第 `i` 层的行星数
开头；接着每颗行星一行，列出若干对“第 `i − 1` 层的行星、花费”，以 `0` 结尾。

## 输出

最小的总花费。

## 样例

### 样例 1

输入：

```
3
2
1 15 0
1 5 0
*
3
1 -5 2 10 0
1 3 0
2 40 0
*
2
1 1 2 5 3 -5 0
2 -19 3 -20 0
```

输出：

```
-1
```

## 解法

地图是分层的，每条通道都上升一层，所以没有环，负花费也无妨：到某颗行星的最便宜
路线，就是到某颗连向它的行星的最便宜路线再加上这条通道。为当前层的每颗行星记录
最小花费，家为 0，再根据下一层块中列出的入边算出下一层的花费。答案是第 `N` 层的
最小花费。`L` 为通道数时为 `O(L)`。

注意事项：

- 一颗行星可能根本没有入边，或者只有来自不可达行星的入边；这样的行星必须保持
  不可达，而不能把它后面的慷慨通道传递下去；
- `*` 行只是分隔符，读数时可以跳过；
- 总和的绝对值小于 `30 · 32768`，32 位整数就够了。

答案已在 300 张随机地图上与另一份独立解答比对，其中一半含有不可达的行星。

- Python 和 Rust 从输入流中滤掉 `*`；其他语言在读数函数中跳过它们。
