# 1210. Самый дешёвый подъём по уровням планет

[Timus 1210](https://acm.timus.ru/problem.aspx?space=1&num=1210) · сложность 170 · dp

Автор оригинальной задачи — Леонид Волков; USU Open Collegiate Programming Contest, октябрь 2002 года, Junior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Планеты расположены на уровнях от 0 до `N < 30`, не больше 30 на
уровне, и на уровне 0 одна планета — дом путешественника. Переходы ведут
только с планеты одного уровня на планеты следующего, и каждый стоит
целое число от `−32768` до `32767`; отрицательная стоимость значит, что
охраняющий переход дух доплачивает путешественнику. Найти самый дешёвый
маршрут от дома до любой планеты уровня `N`; он может быть
отрицательным. Маршрут заведомо существует.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` блоков, разделённых строками `*`. Блок `i` начинается с
числа планет на уровне `i`; затем для каждой из них строка пар «планета
уровня `i − 1`, стоимость», завершённая `0`.

## Выходные данные

Наименьшая суммарная стоимость.

## Примеры

### Пример 1

Ввод:

```
3
2
1 15 0
1 5 0
*
3
1 -5 2 10 0
1 3 0
2 40 0
*
2
1 1 2 5 3 -5 0
2 -19 3 -20 0
```

Вывод:

```
-1
```

## Решение

Карта слоистая, и каждый переход поднимается на уровень, так что циклов
нет и отрицательные стоимости не мешают: самый дешёвый путь до планеты —
самый дешёвый путь до одной из планет, ведущих к ней, плюс этот переход.
Храним наименьшую стоимость для каждой планеты текущего уровня, начиная с
0 для дома, и строим стоимости следующего уровня по входящим переходам из
его блока. Ответ — наименьшая стоимость на уровне `N`. `O(L)` для `L`
переходов.

Тонкие места:

- у планеты может не быть входящих переходов вовсе или быть только
  переходы с недостижимых планет; такая планета должна остаться
  недостижимой, а не передавать дальше щедрый переход с неё;
- строки `*` — только разделители, при чтении чисел их можно пропускать;
- сумма по модулю меньше `30 · 32768`, так что 32-битных целых хватает.

Ответы сверены с отдельно написанным решением на 300 случайных картах,
половина из них с недостижимыми планетами.

## Особенности языков

- Python и Rust отфильтровывают токены `*` из потока ввода; остальные
  языки пропускают их в функции чтения чисел.
