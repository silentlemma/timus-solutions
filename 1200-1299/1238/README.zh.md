# 1238. 用重复次数折叠字符串

[Timus 1238](https://acm.timus.ru/problem.aspx?space=1&num=1238) · 难度 416 · dp

原题作者 Roman Elizarov，出自 2002–2003 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

折叠序列是一个字母、两个前后相接的折叠序列，或者 `X(S)`，其中 S 是折叠序列、X 是
大于 1 的整数，表示 S 重复 X 次。给定由 1 到 100 个大写字母组成的字符串，输出一个
展开后等于它的最短折叠序列。

时间限制：1 秒。内存限制：64 MB。

## 输入

字符串。

## 输出

一个最短的折叠序列；任何一个都可以。

## 评测方式

可能有多个同样短的折叠，所以评测程序会展开答案，与输入比较，并把长度与最短长度比较。

## 样例

### 样例 1

输入：

```
AAAAAAAAAABABABCCD
```

输出：

```
9(A)3(AB)CCD
```

### 样例 2

输入：

```
NEERCYESYESYESNEERCYESYESYES
```

输出：

```
2(NEERC3(YES))
```

## 解法

设 `best[i][j]` 为 `s[i..j]` 最短折叠的长度。它的最外层要么是连接，此时在某个点 k
分成两个更短的折叠；要么是一个 `X(S)`，此时这一段就是 S 的展开重复 X 次。由此得到
按长度递增的区间 DP：

- `best[i][j] = min(best[i][k−1] + best[k][j])`，取遍所有分割点；
- 对每个使该段具有周期 p 的、长度的真因子 p，还有
  `位数(长度/p) + 2 + best[i][i+p−1]`。

该段具有周期 p 当且仅当它与自身平移 p 后相同，即 `s[i..j−p] = s[i+p..j]`。每个区间
记住自己的选择，最后从顶层重建折叠。对于长度为 L 的区间，每个真因子 p 在最坏情况下
需要比较 L−p 个字符。对所有区间和因子求和，时间复杂度为 `O(n³ log n)`；DP 的空间
复杂度为 `O(n²)`，n ≤ 100。

注意事项：

- 次数可能是两位或三位数，其位数也要计入长度：`100(A)` 和 `A99(A)` 一样短
  （测试 04）；
- 重复的内部本身也要折叠，例如 `2(NEERC3(YES))`；
- 子串比较不是常数时间：全部由相同字母组成的字符串（测试 04）对每个真因子都需要
  完整比较，因此最坏时间复杂度中有一个对数因子。

Python 教学版为每个子串缓存实际的最短折叠字符串。从原文开始，尝试所有切分及能重复得到原文的块，保留最短编码。计算重复编码长度时要计入数字和括号。整个输入的缓存结果可以直接输出。设输入长度为 N，复制、哈希和比较字符串使最坏时间为 O(N⁴)，存储字符串最坏需要 O(N³) 空间。

## 优化解法

新 C++、Go 版本保留区间 DP，预计算每对后缀的最长公共前缀。长度 L 的区间可用周期 p 当且仅当 p 整除 L 且 LCP[left][left+p]≥L−p，重复检查为 O(1)。枚举分割点及周期，重复代价包含次数的十进制位数与两个括号。时间 O(n³)，表空间 O(n²)。n≤100，长度及 LCP 可用字节；有符号字节决策用正数表示分割，负数表示周期，零表示原文。重建结果至多 100 字符。保留简单版本；Java、Python、Rust 的已有合格基础版也覆盖快速集合。

已通过评测的基础实现 [1238_dp.java](1238_dp.java), [1238_dp.py](1238_dp.py), [1238_dp.rs](1238_dp.rs) 也满足快速版本的要求：在保存的比较快照中，时间和内存均符合前 15% 或前十名的排名收录规则。直接复用这些源文件，不创建相同副本。星号标记尚未达到该语言目标排名的版本。
