# 1238. 用重复次数折叠字符串

[Timus 1238](https://acm.timus.ru/problem.aspx?space=1&num=1238) · 难度 415 · dp

原题作者 Roman Elizarov，出自 2002–2003 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

折叠序列是一个字母、两个前后相接的折叠序列，或者 `X(S)`，其中 S 是折叠序列、X 是
大于 1 的整数，表示 S 重复 X 次。给定由 1 到 100 个大写字母组成的字符串，输出一个
展开后等于它的最短折叠序列。

时间限制：1 秒。内存限制：64 MB。

## 输入

字符串。

## 输出

一个最短的折叠序列；任何一个都可以。

## 评测方式

可能有多个同样短的折叠，所以评测程序会展开答案，与输入比较，并把长度与参考答案比较。

## 样例

### 样例 1

输入：

```
AAAAAAAAAABABABCCD
```

输出：

```
9(A)3(AB)CCD
```

### 样例 2

输入：

```
NEERCYESYESYESNEERCYESYESYES
```

输出：

```
2(NEERC3(YES))
```

## 解法

设 `best[i][j]` 为 `s[i..j]` 最短折叠的长度。它的最外层要么是连接，此时在某个点 k
分成两个更短的折叠；要么是一个 `X(S)`，此时这一段就是 S 的展开重复 X 次。由此得到
按长度递增的区间 DP：

- `best[i][j] = min(best[i][k−1] + best[k][j])`，取遍所有分割点；
- 对每个使该段具有周期 p 的、长度的真因子 p，还有
  `位数(长度/p) + 2 + best[i][i+p−1]`。

该段具有周期 p 当且仅当它与自身平移 p 后相同，即 `s[i..j−p] = s[i+p..j]`。每个区间
记住自己的选择，最后从顶层重建折叠。`O(n³)`，n ≤ 100。

注意事项：

- 次数可能是两位或三位数，其位数也要计入长度：`100(A)` 和 `A99(A)` 一样短
  （测试 04）；
- 重复的内部本身也要折叠，例如 `2(NEERC3(YES))`。
