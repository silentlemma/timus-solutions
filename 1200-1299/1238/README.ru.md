# 1238. Свёртка строки с повторами

[Timus 1238](https://acm.timus.ru/problem.aspx?space=1&num=1238) · сложность 416 · dp

Автор оригинальной задачи — Роман Елизаров; полуфинал ACM ICPC Северо-Восточной Европы 2002–2003.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Свёрнутая последовательность — это буква, две свёрнутые
последовательности, записанные подряд, или `X(S)` для свёрнутой
последовательности S и целого X > 1, что означает S, повторённую X раз.
По строке из 1–100 заглавных букв вывести кратчайшую свёрнутую
последовательность, которая в неё разворачивается.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Строка.

## Выходные данные

Кратчайшая свёрнутая последовательность; подходит любая.

## Проверка

Равных по длине свёрток может быть несколько, поэтому чекер
разворачивает ответ, сравнивает его со входом и сравнивает длину с
минимальной длиной.

## Примеры

### Пример 1

Ввод:

```
AAAAAAAAAABABABCCD
```

Вывод:

```
9(A)3(AB)CCD
```

### Пример 2

Ввод:

```
NEERCYESYESYESNEERCYESYESYES
```

Вывод:

```
2(NEERC3(YES))
```

## Решение

Пусть `best[i][j]` — длина кратчайшей свёртки `s[i..j]`. Её верхний
уровень — либо конкатенация, и тогда она делится на две более короткие
свёртки в некоторой точке k, либо одно `X(S)`, и тогда отрезок — это
развёртка S, повторённая X раз. Отсюда ДП по отрезкам в порядке роста
длины:

- `best[i][j] = min(best[i][k−1] + best[k][j])` по точкам разреза;
- для каждого делителя p < длины отрезка, такого что у отрезка есть
  период p, ещё `цифры(длина/p) + 2 + best[i][i+p−1]`.

У отрезка период p ровно тогда, когда он совпадает с собой, сдвинутым на
p: `s[i..j−p] = s[i+p..j]`. Каждый отрезок запоминает свой выбор, и
свёртка восстанавливается сверху. Для отрезка длины L каждый собственный
делитель p требует сравнения L−p символов в худшем случае. Суммарно по
всем отрезкам и делителям это даёт `O(n³ log n)` времени; ДП использует
`O(n²)` памяти, n ≤ 100.

Тонкие места:

- счётчики бывают двух- и трёхзначными, и их длина учитывается: `100(A)`
  и `A99(A)` одинаково коротки (тест 04);
- внутренняя часть повтора тоже сворачивается, как в `2(NEERC3(YES))`;
- сравнение подстрок не выполняется за константное время: строки из
  одинаковых букв (тест 04) требуют полного сравнения для каждого
  собственного делителя, что даёт логарифмический множитель в худшем случае.

## Особенности языков

- Все языки сравнивают сдвинутые подстроки одним библиотечным вызовом.
