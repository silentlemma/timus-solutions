# 1292. 火星太空基地

[Timus 1292](https://acm.timus.ru/problem.aspx?space=1&num=1292) · 难度 380 · math

原题作者 Denis Musin，出自 2004 年 3 月 13 日第九届中学生公开团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

设 F(x) 为 x 的各位十进制数字的立方和，例如 F(12) = 9。太空基地沿一条航线分布：第一个基地距
航线端点 K，若基地 i 之前的间隔为 x，则它之后的间隔为 F(x)。密钥 K 是 3 的倍数。

飞船位于基地 N − 1 和 N 之间，距基地 N − 1 为 L。对 T ≤ 33 333 个询问（2 ≤ N ≤ 33 333，
3 ≤ K ≤ 33 333），输出飞船到基地 N 的距离。

时间限制：1 秒。内存限制：64 MB。

## 输入

T，然后 T 行，每行 N、K、L。

## 输出

T 行距离。

## 样例

### 样例 1

输入：

```
2
4 6 123
7 93 49
```

输出：

```
18
104
```

## 解法

把航线端点看作基地 0，基地 N 之前的间隔就是对 K 施加 N − 1 次 F，答案为这个间隔减去 L。样例
可以验证：6 → 216 → 225 → 141，141 − 123 = 18。

每个询问最多施加 33 332 次 F，对 33 333 个询问来说太慢，但这条链几乎立刻就稳定下来。因为
d³ ≡ d (mod 3)，F 保持数字和模 3 的余数，所以 3 的倍数仍是 3 的倍数。F(153) = 1 + 125 + 27
= 153，逐一检查 33 333 以内所有 3 的倍数可知，每个数最多 14 步就到达 153（最慢的是 12 558）。
因此不断施加 F，直到做完 N − 1 步或值变成 153。`O(T · 14 · 位数)`。

注意事项：

- 基地 N 之前的间隔需要 N − 1 步而不是 N − 2 步：第一个基地已经距端点 K（测试 01）；
- 链可能恰好在到达 153 之前截止（测试 03）；
- 间隔可能远大于 K，例如 F(99) = 1458（测试 05）。

与完整施加 N − 1 次 F 的结果比较过。

## 优化解法

两个版本逐个处理查询，直到指定步数或不动点 153，并使用有界输出缓冲区。Go 用十项表查每位数字的立方。C++ 合并两个三位块的预计算立方和，船的位置偏移及减法结果使用有符号 64 位整数。Go 也使用有符号 64 位偏移，并通过字节缓冲区直接读写数字，不为每个数字分配字符串。辅助空间为常数。
