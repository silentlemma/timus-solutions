# 1250. 圣海之中的岛屿

[Timus 1250](https://acm.timus.ru/problem.aspx?space=1&num=1250) · 难度 726 · graphs

原题作者 Stanislav Skorb（由 Ivan Dashkevich 整理），出自 2003 年 3 月 15 日乌拉尔国立大学公开团体赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一张 W × H 的地图（W, H ≤ 500）上有海 `.` 和陆地 `#`。海格以边或角相接就属于同一片
海；陆地格只以边相接才属于同一个岛。包含格子 (X, Y)（从左上角数起）的那片海是圣海，
它里面的所有陆地也都是神圣的——包括它的岛屿内部的海中的岛屿，依此类推。统计不接触
地图边缘的神圣岛屿个数。

时间限制：1 秒。内存限制：64 MB。

## 输入

W、H、X 和 Y，用一个或多个空格分隔，然后是 H 行，每行 W 个字符。

## 输出

这样的岛屿个数。

## 样例

### 样例 1

输入：

```
9 7 1 1
........#
.#######.
.#.....#.
.#.#.#.#.
.#.....#.
.#######.
#........
```

输出：

```
3
```

### 样例 2

输入：

```
9 7 3 3
........#
.#######.
.#.....#.
.#.#.#.#.
.#.....#.
.#######.
#........
```

输出：

```
2
```

## 解法

在地图外围加一圈外部格子。通过角相连的海无法被只经过边移动的路径穿过：在它看似
很薄的地方，它的两个格子以角相接，把缝隙封住了。所以圣海里面的陆地，恰好就是从
外圈出发、只经过边、避开圣海的漫水填充无法到达的陆地。

程序从 (X, Y) 出发沿八个方向填充找出圣海，再从外圈填充所有不属于圣海的格子，并在
未被到达的格子中统计岛屿，每个岛屿用一次沿边的填充。接触边缘的岛屿总会被外圈到达，
所以永远不会计入。每次填充都用显式栈，因为 250 层嵌套的环会让递归溢出。`O(W·H)`。

注意事项：

- 嵌套在神圣岛屿的湖中的岛屿也算：在第一个样例中是那个环和它里面的两个岛（测试 06
  有一个湖）；
- 只以角相接的陆地是不同的岛（测试 08）；
- 第一行的数之间可能有多个空格，所以地图按接下来的 W·H 个 `.` 和 `#` 字符读入，不管
  它们之间是什么。

这些结果在 1500 张随机的小地图上与另一个构建海和岛之树的解法比较过。

## 各语言说明

- Python 用表示“仍可通行”格子的字节数组做填充，填充过程中逐个清除。
