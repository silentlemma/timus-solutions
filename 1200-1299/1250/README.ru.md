# 1250. Острова внутри священного моря

[Timus 1250](https://acm.timus.ru/problem.aspx?space=1&num=1250) · сложность 726 · graphs

Автор оригинальной задачи — Станислав Скорб (подготовил Иван Дашкевич); открытое командное первенство УрГУ, 15 марта 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На карте W × H (W, H ≤ 500) море `.` и суша `#`. Клетки моря образуют
одно море, если соприкасаются стороной или углом; клетки суши образуют
один остров, если соприкасаются только стороной. Море, содержащее клетку
(X, Y) (счёт от левого верхнего угла), священно, и вся суша внутри него
тоже священна — включая острова в морях внутри его островов и так далее.
Посчитать священные острова, не касающиеся края карты.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

W, H, X и Y через один или несколько пробелов, затем H строк по W
символов.

## Выходные данные

Число таких островов.

## Примеры

### Пример 1

Ввод:

```
9 7 1 1
........#
.#######.
.#.....#.
.#.#.#.#.
.#.....#.
.#######.
#........
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
9 7 3 3
........#
.#######.
.#.....#.
.#.#.#.#.
.#.....#.
.#######.
#........
```

Вывод:

```
2
```

## Решение

Окружим карту кольцом внешних клеток. Море, связанное через углы, нельзя
пересечь путём, идущим только через стороны: где оно кажется тонким, две
его клетки встречаются углом и закрывают щель. Поэтому суша внутри
священного моря — это ровно та суша, до которой заливка через стороны от
внешнего кольца не может дойти, обходя священное море.

Программа находит священное море заливкой по всем восьми направлениям
из (X, Y), заливает от внешнего кольца все клетки, не входящие в него, и
считает острова среди недостигнутых клеток, по одной заливке через
стороны на остров. Остров, касающийся края, всегда достигается от
кольца, так что он не считается. Каждая заливка использует явный стек,
потому что вложенность в 250 колец переполнила бы рекурсию. `O(W·H)`.

Тонкие места:

- острова, вложенные в озёра священных островов, тоже считаются: в
  первом примере это кольцо и оба острова внутри него (в тесте 06 есть
  озеро);
- суша, соприкасающаяся только углом, образует разные острова
  (тест 08);
- в первой строке между числами может быть несколько пробелов, поэтому
  карта читается как следующие W·H символов `.` и `#`, что бы ни стояло
  между ними.

Ответы сравнивались со вторым решением, строящим дерево морей и
островов, на 1500 случайных маленьких картах.

## Особенности языков
