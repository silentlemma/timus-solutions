# 1260. 较真的摄影师

[Timus 1260](https://acm.timus.ru/problem.aspx?space=1&num=1260) · 难度 111 · dp

原题作者 Alexander Ipatov，出自 2003 年 10 月 11 日斯维尔德洛夫斯克州中学生公开团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

年龄分别为 1, 2, …, N 岁（1 ≤ N ≤ 55）的 N 名学生坐成一排。1 岁的坐在最左端，任意两个
相邻者的年龄差不超过 2。这样的排法有多少种？

时间限制：1 秒。内存限制：64 MB。

## 输入

N。

## 输出

排法的数量。

## 样例

### 样例 1

输入：

```
4
```

输出：

```
4
```

## 解法

设 a(k) 为年龄 1..k 的排法数。看第二个位置坐的是谁：

- 2 岁：其余部分是 2..k 且以 2 开头的一排，即平移一位的同一问题，a(k − 1) 种；
- 先 3 岁再 2 岁：接下来必须是 4，其余部分是 4..k 且以 4 开头的一排，a(k − 3) 种；
- 3 岁，但 2 在更后面：2 的邻居只能是 1、3、4，而 1 和 3 已经彼此相邻，所以 2 只能坐在
  最右端、挨着 4。这就迫使排成锯齿形：沿奇数年龄 1, 3, 5, … 向上，再沿偶数年龄向下到
  4, 2，恰好一种。

所以 a(k) = a(k − 1) + a(k − 3) + 1，其中 a(1) = a(2) = 1，a(3) = 2。把规则往回推得到
a(0) = 0 和 a(−1) = −1，于是循环可以从 k = 1 开始，不需要特判。a(55) = 1 388 937 263
仍在 32 位范围内，但解答使用 64 位。`O(N)`。

注意事项：

- 第三种情况容易漏掉：N = 5 时它就是 1, 3, 5, 4, 2 这一排（测试 05）；
- N = 1 和 N = 2 时都只有一种排法（测试 02、03）。

对不超过 10 的 N，递推式与枚举所有排列的结果比较过。
