## Задача

N студентов в возрасте 1, 2, …, N лет (1 ≤ N ≤ 55) садятся в ряд.
Однолетний сидит с левого края, а возрасты любых двух соседей
отличаются не больше чем на 2. Сколько существует таких рядов?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

Число рядов.

## Примеры

### Пример 1

Ввод:

```
4
```

Вывод:

```
4
```

## Решение

Пусть a(k) — число рядов для возрастов 1..k. Посмотрим, кто сидит
вторым:

- возраст 2: остальное — ряд из 2..k, начинающийся с 2, та же задача со
  сдвигом на единицу, a(k − 1) способов;
- возраст 3, затем 2: следующим обязан быть 4, а остальное — ряд из 4..k,
  начинающийся с 4, a(k − 3) способов;
- возраст 3, а 2 позже: соседями 2 могут быть только 1, 3 и 4, а 1 и 3
  уже сидят рядом друг с другом, поэтому 2 сидит с правого края рядом с
  4. Это вынуждает зигзаг 1, 3, 5, … вверх по нечётным возрастам и назад
  вниз по чётным до 4, 2: ровно один ряд.

Итак, a(k) = a(k − 1) + a(k − 3) + 1, где a(1) = a(2) = 1 и a(3) = 2.
Если продолжить правило назад, получится a(0) = 0 и a(−1) = −1, и цикл
можно начинать с k = 1 без особых случаев. a(55) = 1 388 937 263 ещё
помещается в 32 бита, но решения используют 64. `O(N)`.

Тонкие места:

- третий случай легко упустить: при N = 5 это ряд 1, 3, 5, 4, 2
  (тест 05);
- при N = 1 и N = 2 ряд ровно один (тесты 02, 03).

Рекуррента сравнивалась с перебором всех перестановок для N до 10.
