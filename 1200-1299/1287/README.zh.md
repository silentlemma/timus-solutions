# 1287. 火星运河

[Timus 1287](https://acm.timus.ru/problem.aspx?space=1&num=1287) · 难度 381 · dp

原题作者 Alexander Mironenko（由 Igor Goldberg 准备），出自 2004 年乌拉尔国立大学个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一块 N × N 的田（N ≤ 1400）种着两种谷物 `s` 和 `S`，每格一种。求沿行、列或任一条对角线的
最长同字母直线连续段。输出最长连续段更长的那个字母，相等则输出 `?`，再输出该长度。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后 N 行，每行 N 个字母。

## 输出

获胜的字母或 `?`，然后是最长连续段的长度。

## 样例

### 样例 1

输入：

```
3
SsS
sSs
SsS
```

输出：

```
S
3
```

### 样例 2

输入：

```
2
sS
Ss
```

输出：

```
?
2
```

## 解法

逐行扫描。对每个格子记录在四个方向上以它结尾的连续段长度：来自左边、上边、左上和右上。
若邻格字母相同，则等于邻格的长度加一，否则为 1。只需要上一行，并在扫描中记录每个字母的
最长连续段。时间 `O(N²)`，内存 `O(N)`。

注意事项：

- 来自右上的对角线容易被忘掉（测试 06）；
- 最长连续段相等时输出 `?`（测试 02）；
- 田里有近两百万个格子，所以读入要快。

在 300 块边长不超过九格的随机田上，与从每个格子出发逐一走完每条连续段的结果比较过。

## 各语言说明

- C++、Go、Java 和 Rust 为两行保存四个连续段数组。
- Python 逐格处理会太慢。它把行、列和两条方向的对角线都做成字节串：对角线就是逐行错开
  一格后的列，由 `zip` 完成转置。然后对 k 二分，用 `bytes.find` 判断文本中是否出现 k 个
  相同字母连续。
