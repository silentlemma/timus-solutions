# 1287. Каналы на Марсе

[Timus 1287](https://acm.timus.ru/problem.aspx?space=1&num=1287) · сложность 383 · dp

Автор оригинальной задачи — Александр Мироненко (подготовил Игорь Гольдберг); личное первенство УрГУ 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Поле N × N (N ≤ 1400) засеяно злаком двух сортов, `s` и `S`, по одному
в клетке. Найти самую длинную прямую серию одинаковых клеток по
строке, столбцу или любой из диагоналей. Вывести букву, у которой самая
длинная серия длиннее, или `?`, если они равны, а затем эту длину.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк по N букв.

## Выходные данные

Буква-победитель или `?`, затем длина самой длинной серии.

## Примеры

### Пример 1

Ввод:

```
3
SsS
sSs
SsS
```

Вывод:

```
S
3
```

### Пример 2

Ввод:

```
2
sS
Ss
```

Вывод:

```
?
2
```

## Решение

Проходим поле по строкам. Для каждой клетки храним длину серии,
кончающейся в ней, в каждом из четырёх направлений: слева, сверху,
сверху-слева и сверху-справа. Каждая равна серии соседа плюс один, если
у соседа та же буква, и 1 иначе. Нужна только предыдущая строка, а
самая длинная серия каждой буквы запоминается по ходу. Динамика требует
`O(N²)` времени и `O(N)` памяти для состояний; общая память зависит от
способа хранения входных данных (см. ниже).

Тонкие места:

- диагональ сверху-справа легко забыть (тест 06);
- при равных самых длинных сериях выводится `?` (тест 02);
- в поле почти два миллиона клеток, поэтому читать нужно быстро.

Ответы сравнивались с проходом каждой серии от каждой клетки на 1200
случайных полях со стороной до двенадцати клеток и на всех 530 полях
со стороной от одной до трёх клеток.

## Особенности языков

- C++, Go, Java и Rust хранят по три массива серий для каждой из двух
  строк и отдельный счётчик горизонтальной серии. C++, Go и Java
  используют `O(N)` общей памяти; Rust сохраняет весь ввод и использует `O(N²)`.
- Python поклеточно был бы слишком медленным. Он строит строки,
  столбцы и обе диагонали как строки байтов: диагонали — это столбцы
  строк, сдвинутых каждая на шаг, а транспонирует `zip`. Затем двоичный
  поиск по k спрашивает, встречаются ли k копий буквы подряд в тексте,
  через `bytes.find`. Разделители и заполнение точками не позволяют серии
  перейти между линиями или выйти за границы поля. Построение текста требует
  `O(N²)` времени и памяти; двоичные поиски занимают `O(N² log N)` времени
  в худшем случае, общая память — `O(N²)`.
