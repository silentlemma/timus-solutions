# 1229. 不与第一层重合的第二层砖

[Timus 1229](https://acm.timus.ru/problem.aspx?space=1&num=1229) · 难度 384 · constructive

原题出自 2002 年 10 月在雷宾斯克举行的 ACM ICPC 2002–2003 俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一块 `N × M` 的区域（两边都是偶数且不超过 100）铺着一层 1 × 2 的砖，每块砖的两个
格子都标着它的编号。在整个区域上再铺第二层这样的砖，使第二层没有任何一块砖恰好
压在第一层的某块砖上；若做不到则输出 `-1`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N` 和 `M`，然后是 `N` 行、每行 `M` 个数：第一层。

## 输出

描述第二层的 `N` 行、每行 `M` 个数，或 `-1`。

## 评测方式

满足条件的第二层有很多，所以只要每个数恰好标记两个相邻格子，并且没有砖与第一层
的砖占据相同的两个格子，就判为正确。

## 样例

### 样例 1

输入：

```
2 4
1 1 2 2
3 3 4 4
```

输出：

```
2 1 1 4
2 3 3 4
```

## 解法

把区域切成 2 × 2 的小块，每块用两块砖覆盖：要么都横放（一块在上行，一块在下行），
要么都竖放（每列一块）。横放的砖只有在第一层恰好有一块砖占满该块的这一行时才会
重合。但那样的话，这块砖在该块的每一列各占一个格子，于是第一层没有砖能占满该块的
某一列，竖放的砖就是安全的。所以：若第一层在该块的上行或下行没有砖，就横放；否则
竖放。因此第二层总是存在，永远不需要输出 `-1`。`O(NM)`。

注意事项：

- 第一层的砖可能跨越 2 × 2 块的边界；只有完全落在一块之内的砖才可能被重合，判断
  正是针对这种情况；
- 第二层的编号是自由的，按块依次编号即可。

每个输出都经过评测程序检查，另一份独立解答的输出也能通过，测试用的是 100 个通过
翻转成对砖块得到的随机第一层。

## 各语言说明

- 所有语言都按相同顺序扫描 2 × 2 块，并用相同方式给砖编号。
