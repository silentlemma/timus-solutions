# 1297. Палиндромы

[Timus 1297](https://acm.timus.ru/problem.aspx?space=1&num=1297) · сложность 82 · strings

Автор оригинальной задачи — Евгений Крохалев; IX открытое командное соревнование школьников по программированию, 13 марта 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дана строка не длиннее 1000 латинских букв. Нужно вывести её самую
длинную подстроку, которая читается одинаково в обоих направлениях;
если таких несколько — самую левую. Заглавные и строчные буквы
различаются.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Строка.

## Выходные данные

Самая длинная подстрока-палиндром.

## Примеры

### Пример 1

Ввод:

```
Kazak
```

Вывод:

```
aza
```

## Решение

У каждого палиндрома есть центр: буква для нечётной длины и промежуток
между двумя буквами для чётной. В строке из n букв 2n − 1 центров. От
каждого расширяемся наружу, пока буквы с обеих сторон совпадают.
Расширение доходит до самого длинного палиндрома вокруг центра, а более
короткие начинаются правее, поэтому никогда не выигрывают.

Лучший палиндром — самый длинный, а среди равных — с наименьшим
началом. `O(n²)` в худшем случае (строка из одной буквы), всего около
500 000 сравнений при n = 1000.

Алгоритм Манакера справился бы за `O(n)`, но при таком размере он не
нужен.

Тонкие места:

- буквы сравниваются точно, так что `K` и `k` различны (тесты 01, 04 и
  10);
- если никакие соседние буквы не равны, ответ — первая буква (тест 03);
- при равенстве длин выбирается самый левый палиндром (тесты 05 и 06);
- палиндромам чётной длины нужны свои центры (тесты 05 и 08).

Ответы сравнивались с перебором всех подстрок на 300 случайных
строках.

## Особенности языков

- Строка читается целиком, а лишние пробельные символы, например `\r`
  в конце, отбрасываются перед поиском.
