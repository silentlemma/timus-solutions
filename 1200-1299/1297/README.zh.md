# 1297. 回文

[Timus 1297](https://acm.timus.ru/problem.aspx?space=1&num=1297) · 难度 82 · strings

原题作者 Evgeny Krokhalev，出自 2004 年 3 月 13 日第九届中学生公开团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定一行不超过 1000 个拉丁字母。输出其中正读反读都相同的最长子串；若有多个，输出最左边的一个。
大小写字母视为不同。

时间限制：1 秒。内存限制：64 MB。

## 输入

这一行字符串。

## 输出

最长回文子串。

## 样例

### 样例 1

输入：

```
Kazak
```

输出：

```
aza
```

## 解法

每个回文都有一个中心：奇数长度时是一个字母，偶数长度时是两个字母之间的空隙。n 个字母的字符串共有
2n − 1 个中心。从每个中心向两边扩展，直到两侧字母不同。扩展到的就是以该中心为中心的最长回文，更短
的回文起点更靠右，永远不会更优。

最好的回文是最长的那个，长度相同时取起点最小的。最坏情况（全是同一个字母）为 `O(n²)`，n = 1000
时也只有约 500 000 次比较。

Manacher 算法可以做到 `O(n)`，但在这个规模下没有必要。

注意事项：

- 字母按原样比较，`K` 和 `k` 不同（测试 01、04 和 10）；
- 所有字母互不相同时，答案是第一个字母（测试 03）；没有相邻的相同字母只能排除偶数长度的回文，
  仍可能有 `aba` 这样的奇数长度回文（测试 06）；
- 长度相同时取最左边的回文（测试 05 和 06）；
- 偶数长度的回文需要单独的中心（测试 05 和 08）。

在 300 个随机字符串上与枚举所有子串的结果比较过。
