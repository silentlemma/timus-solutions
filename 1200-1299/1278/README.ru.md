## Задача

Звуковой процессор знает две команды, по одной в ячейке памяти.
`CALL X` кладёт адрес следующей ячейки в стек из 100 ячеек и переходит в
ячейку X. `BELL&RET` издаёт один звук, затем возвращается по адресу с
вершины стека или останавливается, если стек пуст. Выполнение начинается
с ячейки 0. Написать программу не длиннее 100 команд с единственной
`BELL&RET` последней, которая звучит ровно K раз (1 ≤ K ≤ 10⁹).

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

K.

## Выходные данные

Программа, по команде в строке, начиная с ячейки 0.

## Проверка

Подходящих программ много, поэтому чекер принимает любую: он проверяет
вид каждой строки и что каждый вызов указывает вперёд. Затем он считает
звуки из каждой ячейки, снизу вверх, и проверяет глубину стека и итог.

## Примеры

### Пример 1

Ввод:

```
4
```

Вывод:

```
CALL 1
CALL 2
BELL&RET
```

### Пример 2

Ввод:

```
1
```

Вывод:

```
BELL&RET
```

## Решение

Пусть bells(i) — число звуков, которое издаётся, когда процессор
выполняет программу с ячейки i до возврата из этого выполнения. Последняя
ячейка даёт bells = 1. Команда `CALL X` в ячейке i сначала выполняет
программу с X, а потом с i + 1, поэтому bells(i) = bells(X) + bells(i + 1).
Достаточно двух вариантов X:

- `CALL i+1` удваивает: bells(i) = 2 · bells(i + 1);
- вызов последней ячейки прибавляет один: bells(i) = bells(i + 1) + 1.

Поднимаясь от последней ячейки, начнём с 1 и пройдём двоичные цифры K
после старшей единицы: на каждой цифре удваиваем, а на каждой единице
ещё прибавляем один. Для K меньше 2³⁰ нужно не больше 29 удвоений и 29
прибавлений — 59 ячеек вместе со звонком. Все вызовы указывают вперёд,
так что в стеке не больше одного адреса на ячейку. `O(log K)`.

Тонкие места:

- при K = 1 программа — одна `BELL&RET` (тест 02);
- вызов той же или более ранней ячейки бесконечно вызывает сам себя и
  переполняет стек, поэтому ни один вызов не может указывать назад;
- программа читается с ячейки 0, поэтому ячейки, построенные снизу
  вверх, выводятся в обратном порядке.

Все K до 299 дополнительно прогнаны на буквальной модели процессора, а
ответы на все тесты проходят чекер.

## Особенности языков

- Все языки проходят двоичные цифры K одинаково.
