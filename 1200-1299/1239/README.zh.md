# 1239. 一条射线穿过尽可能多的球

[Timus 1239](https://acm.timus.ru/problem.aspx?space=1&num=1239) · 难度 3112 · geometry

原题作者 Roman Elizarov，出自 2002–2003 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

位于原点的枪向卦限 x, y, z ≥ 0 射出一条射线。有 N 个幽灵（0 ≤ N ≤ 100），每个是
球心为整点 (X, Y, Z)（1 ≤ X, Y, Z ≤ 10 000）、半径为整数 1 ≤ R ≤ min(X, Y, Z)
的球；射线碰到的每个幽灵都会被消灭，哪怕只碰到一点。求一条射线最多能消灭多少个
幽灵，以及是哪些。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后每个幽灵为 `X Y Z R`。

## 输出

幽灵的个数，然后是它们的编号，顺序任意。

## 评测方式

最优的组合可能不止一个，所以评测程序接受任意一个：个数必须等于参考答案，编号必须
互不相同，并且必须存在一条碰到所有列出幽灵的射线。评测程序用 50 位十进制数寻找这条
射线。

## 样例

### 样例 1

输入：

```
2
1200 1200 3900 300
160 160 820 60
```

输出：

```
2
1 2
```

### 样例 2

输入：

```

100 75 100 20

```

输出：

```
5
6 7 9 10 11
```

## 解法

从枪看去，球心为 C 的幽灵是一个圆锥：沿 d 的射线碰到它当且仅当 `d·C ≥ L·|d|`，其中
`L = √(|C|² − R²)` 是从原点出发的切线长。在方向球面上每个幽灵是一个球冠，题目要求
被最多球冠覆盖的点。

包含最优点的那些球冠相交成一个凸区域。要么这个区域就是一个球冠，此时它的中心在所有
球冠里；要么它有一个角点，是两个球冠边界相交或相切的地方。所以只需尝试指向各球心的
方向以及两条边界的交点，共 `O(N²)` 个候选，并统计包含每个候选的球冠数。`O(N³)`。

球冠 i 与 j 的边界交于单位向量 `d = (a·C_i + b·C_j ± c·C_i×C_j)`，满足
`d·C_i = L_i` 和 `d·C_j = L_j`。记 `g = C_i·C_j`，`det = |C_i|²|C_j|² − g²`，

```text
a·det = L_i|C_j|² − L_j·g,   b·det = L_j|C_i|² − L_i·g,   c² = Q / det²,
Q = det − L_i²|C_j|² − L_j²|C_i|² + 2g·L_i·L_j
```

难点全在精度：第一个样例之所以成立，只是因为两个圆锥恰好相切，而相切就足够了。因此
凡是能用整数判断的都用整数：

- 球冠 i 的中心在球冠 k 内当且仅当 `(C_i·C_k)² ≥ L_k²·|C_i|²`，全是整数；
- 两条边界相交当且仅当 Q ≥ 0，Q 是一个整数加上 `2g·√(L_i²L_j²)`；它的符号通过
  在 128 位整数中比较平方得到，所以相切恰好给出 Q = 0 和唯一一个点；
- 当 Q、`a·det` 和 `b·det` 是两个几乎相等的数之差时，用共轭来计算，
  `x − y = (x² − y²)/(x + y)`，分子是精确的。

只有最后一步——判断第三个球冠是否包含候选点——使用容差，而且所判断的量的各项都精确到
约 10⁻¹⁵，所以相对误差 10⁻⁹ 是安全的。

注意事项：

- 缩放得到的幽灵，如 `(1200, 1200, 3900, 300)` 和 `(2400, 2400, 7800, 600)`，
  圆锥相同，det = 0，这一对没有交点，但它们与其他球冠的交点仍会同时计入两者
  （测试 09）；
- 稍细一点的副本必须错过切点（测试 08）；
- 没有幽灵时答案是 0 和一个空列表。

这些答案在 600 个随机的小规模情况上与用 80 位十进制数做的同样搜索比较过，其中许多由
缩放和镜像的副本组成。

## 各语言说明

- C++ 和 Rust 用 128 位整数得到精确符号，Go 用 `math/big`，Java 用 `BigInteger`；
  Python 的整数本来就是精确的。
