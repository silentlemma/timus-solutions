# 1212. Места для ещё одного корабля в морском бое

[Timus 1212](https://acm.timus.ru/problem.aspx?space=1&num=1212) · сложность 493 · geometry

Авторы оригинальной задачи — Антон Ботов и Анатолий Углов; USU Open Collegiate Programming Contest, октябрь 2002 года, Junior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Поле морского боя — `N` строк и `M` столбцов, оба до 30000, и на нём уже
стоят до 30 кораблей от одной до четырёх клеток. Корабли не могут
касаться друг друга, даже углом. Посчитать способы поставить ещё один
корабль из `K` клеток, горизонтально или вертикально.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, `M` и число кораблей `L`; затем каждый корабль — столбец и строка
его левой верхней клетки, длина и `V` или `H`; затем `K`.

## Выходные данные

Число мест для нового корабля.

## Примеры

### Пример 1

Ввод:

```
4 4 2
1 2 2 V
3 1 2 H
2
```

Вывод:

```
4
```

## Решение

Каждый стоящий корабль запрещает прямоугольник вокруг себя, на клетку
шире с каждой стороны. Сначала считаем горизонтальные места. Строки
делятся на полосы по верхнему краю и сразу под нижним краем каждого
запрещённого прямоугольника; внутри полосы каждая строка пересекает одни
и те же прямоугольники, так что у всех её строк одинаковое число мест.
Для одной строки полосы берём запрещённые отрезки столбцов по порядку и
прибавляем `max(0, длина − K + 1)` за каждый свободный промежуток между
ними; умножаем на высоту полосы. Вертикальные места — то же самое на
повёрнутом поле. Однопалубный корабль одинаков в обоих направлениях,
поэтому для него берётся только один подсчёт. Полос не больше 61,
`O(L² log L)`.

Тонкие места:

- первое число корабля — столбец, второе — строка;
- однопалубный корабль нельзя считать дважды;
- запрещённые прямоугольники выступают за края поля; при разбиении на
  полосы разрезы за пределами поля пропускаются;
- ответ доходит примерно до `1.8·10⁹`, в пределах 32-битных знаковых целых.

Ответы сверены с перебором по всем клеткам на 450 случайных маленьких
полях и с отдельно написанным решением на всех тестах.

Учебный Python напрямую считает запрещённые начальные клетки. Для горизонтальной установки расширяем запретный прямоугольник каждого корабля на K − 1 столбцов влево и обрезаем по области допустимых начал. Добавляем каждое начало во множество, чтобы посчитать пересечения один раз. Размер множества вычитаем из числа всех начал. Для вертикального размещения транспонируем поле, кроме случая K = 1. Каждый корабль добавляет не более 36 клеток на направление. Ожидаемое время O(L), память O(L).

## Оптимизированные решения

C++, Go и Rust считают запрещённые начальные клетки. Для горизонтальной установки расширяем запретный прямоугольник на K − 1 столбцов влево и обрезаем по области допустимых начал. Каждый поставленный корабль даёт не более 36 клеток. Кодируем их как (row − 1)M + column − 1, сортируем коды и считаем различные. Для вертикальной установки транспонируем поле.

Версия на PyPy экономит память, считая запрещённые конечные клетки. Горизонтальный корабль, заканчивающийся в столбце x, пересекает запретный отрезок [a,b] тогда и только тогда, когда x ≥ a и x − K + 1 ≤ b. Один раз сортируем запретные прямоугольники по левой границе. Расширяем их на K − 1 вправо для горизонтальной установки или вниз для вертикальной и обрезаем по допустимым конечным клеткам. Для каждой затронутой строки храним самую правую покрытую границу и вычитаем только вновь покрытые клетки. Каждый прямоугольник затрагивает не более девяти строк. Оба подхода считают K = 1 один раз. Время O(L log L), память O(L).

Принятая версия PyPy 3.10 x64 заняла 0.14 с при 0.078 с у базовой и использовала 340 KB при 684 KB у базовой.

Принятые базовые реализации [1212_geometry.java](1212_geometry.java) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.

## Особенности языков

C++, Go и Rust сортируют коды начал в фиксированных массивах. Go хранит коды в uint32 и использует стандартные дескрипторы с фиксированными буферами. PyPy хранит одну правую границу на затронутую строку и использует один порядок прямоугольников для двух направлений. Java сохраняет исходный подсчёт по полосам строк.
