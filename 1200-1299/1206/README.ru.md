# 1206. Пары чисел, суммы цифр которых складываются

## Задача

Пусть `S(N)` — сумма цифр `N`. Для `2 ≤ K ≤ 50` посчитать упорядоченные
пары `K`-значных чисел `A` и `B` без ведущих нулей, для которых
`S(A + B) = S(A) + S(B)`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`K`.

## Выходные данные

Число пар.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
1980
```

## Решение

Каждый перенос при сложении превращает 10 в одном разряде в 1 в
следующем и уменьшает сумму цифр на 9. Значит, равенство выполняется
ровно тогда, когда переносов нет, то есть цифры в каждом разряде дают в
сумме не больше 9. Тогда разряды независимы. В старшем разряде обе цифры
от 1 до 9, это `8 + 7 + … + 1 = 36` пар; в каждом из остальных `K − 1`
разрядов цифры от 0 до 9, это `10 + 9 + … + 1 = 55` пар. Ответ —
`36 · 55^(K−1)`, число до 87 цифр. `O(K²)` при умножении столбиком.

Тонкие места:

- ответ выходит за 64 бита уже при `K = 12`;
- старшие цифры не могут быть нулём, поэтому для них пар другое число.

Формула проверена перебором всех пар для `K = 2` и `K = 3`, и каждое `K`
сверено с отдельно написанным решением.
