# 1262. Псевдоримское число

## Задача

Псевдоримские цифры обозначают 1, 5, 10, 50, 100, 500, 1000 и так далее
без конца. В условии перечислены правила записи числа ими, близкие к
обычным римским: не больше трёх одинаковых степеней десяти подряд и
не больше двух одинаковых «пятёрок» подряд; меньшая цифра может стоять
перед большей, только если она — степень десяти, а большая больше её не
более чем в десять раз; перед цифрой не больше одной меньшей и после неё
не больше одной большей; и правило для каждых трёх соседних цифр. Цифра
перед большей вычитается, иначе прибавляется. Найти, сколько цифр в
псевдоримской записи числа N (1 ≤ N ≤ 10²⁰⁰³).

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

Число цифр.

## Примеры

### Пример 1

Ввод:

```
1939
```

Вывод:

```
8
```

## Решение

Поскольку цифры продолжаются за M (5000, 10 000, …), каждый десятичный
разряд N записывается отдельно, точно как единицы, десятки или сотни в
обычных римских числах: десятичные цифры от 0 до 9 занимают 0, 1, 2, 3,
2, 1, 2, 3, 4, 2 знака (ничего, I, II, III, IV, V, VI, VII, VIII, IX).
Ответ — сумма этих чисел по десятичным цифрам N, прочитанного как
строка. `O(log N)`.

Тонкие места:

- в N до 2004 цифр, поэтому его нужно читать как строку;
- правила в напечатанном виде позволяют записать некоторые числа и
  длиннее: VIV — это 5 + 4 = 9, и запись проходит их все. Обычная
  форма — самая короткая из допустимых, и пример с ней согласуется (тест 05);
- нули ничего не стоят, поэтому 10²⁰⁰³ — это одна буква (тест 03).

Две одинаковые «пятёрки» дают то же значение, что и один знак следующей
степени десяти, поэтому разрешение такой пары не сокращает обычную форму.
