# 1262. 伪罗马数字

## 任务

伪罗马数字表示 1, 5, 10, 50, 100, 500, 1000，并无限延续下去。题目列出了用它们书写数的
规则，接近通常的罗马数字：同一个 10 的幂最多连续三个，同一个“5 类”数字最多连续两个；
较小的数字只有在它是 10 的幂、且较大的数字不超过它的十倍时，才能放在较大数字之前；
一个数字之前最多有一个比它小的，之后最多有一个比它大的；另外还有关于每三个相邻数字的
规则。位于较大数字之前的数字做减法，否则做加法。求 N（1 ≤ N ≤ 10²⁰⁰³）的伪罗马记法
有多少位。

时间限制：1 秒。内存限制：64 MB。

## 输入

N。

## 输出

位数。

## 样例

### 样例 1

输入：

```
1939
```

输出：

```
8
```

## 解法

由于数字在 M 之后还有（5000、10 000、…），N 的每个十进制位都单独书写，就像通常罗马数字
里的个位、十位、百位一样：十进制数字 0 到 9 分别占 0、1、2、3、2、1、2、3、4、2 个字母
（无、I、II、III、IV、V、VI、VII、VIII、IX）。答案是把 N 当作字符串读入后，对各位求这些
值之和。`O(log N)`。

注意事项：

- N 最多有 2004 位，必须当作字符串读入；
- 按题面印出的规则，有些数还能写得更长：VIV 即 5 + 4 = 9，并且满足全部规则。通常的
  写法是合法写法中最短的，样例也与之一致（测试 05）；
- 零不占字母，所以 10²⁰⁰³ 只有一个字母（测试 03）。

两个相同的“5 类”数字的值等于下一个 10 的幂对应的单个数字，因此允许这样的数字对并不会
使通常写法更短。

## 各语言说明

- 所有语言都对输入的每个字符查表求和。
