# 1234. 把砖塞进地上的洞

[Timus 1234](https://acm.timus.ru/problem.aspx?space=1&num=1234) · 难度 688 · geometry

原题作者 Elena Andreeva，出自 2002–2003 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

要把一块 A × B × C 的砖推进一个无限深、截面为 D × E 的矩形洞。它能通过吗？所有
长度都在 1 到 10 之间，最多一位小数。

时间限制：1 秒。内存限制：64 MB。

## 输入

一行中的 A、B、C、D 和 E。

## 输出

`YES` 或 `NO`。

## 样例

### 样例 1

输入：

```
1.0 2.0 1.5 1.4 1.0
```

输出：

```
NO
```

### 样例 2

输入：

```
1.0 2.0 1.5 1.5 1.0
```

输出：

```
YES
```

## 解法

砖是一端朝下推进去的，所以只要它的某个面能放进 D × E 的矩形就能通过，而由两条较短
边 q ≤ p 组成的面最容易。设洞的边为 b ≤ a，分三种情况：

- q > b：这个面在任何方向上的宽度都至少是 q，大于洞的宽度 b，`NO`；
- p ≤ a：直着就能放进去，`YES`；
- p > a：转一个角度可能还能放进去。Carver 判据指出，此时 p × q 的矩形能放进
  a × b 的矩形当且仅当 `((a+b)/(p+q))² + ((a−b)/(p−q))² ≥ 2`。

所有长度都是整数个十分之一，所以程序把它们读成以十分之一为单位的整数，并把判据
展开：`(a+b)²(p−q)² + (a−b)²(p+q)² ≥ 2(p+q)²(p−q)²`。这样即使恰好贴合的情况也
无需舍入就能判断。`O(1)`。

注意事项：

- 恰好贴合也算通过：第二个样例和测试 03、04、07 都贴着洞壁；
- 转角的情况可能非常接近边界：测试 05 中判据左边约为 2 − 5·10⁻⁶，测试 06 中约为
  2 + 3·10⁻⁷，所以容差较大的浮点运算会答错其中一个。

该判据在数千个随机情况上与按角度扫描的结果比较过，并在所有 197 个判据与 2 相差不到
2·10⁻⁴ 的一位小数情况上与精确分数计算比较过。

## 各语言说明

- 所有语言都先把每个长度四舍五入成十分之一单位（浮点数中 `x · 10` 不一定是整数），
  之后只用整数。
