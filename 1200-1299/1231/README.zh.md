# 1231. 玩数数出局游戏的图灵机

[Timus 1231](https://acm.timus.ru/problem.aspx?space=1&num=1231) · 难度 2192 · constructive

原题出自 2002 年 10 月在雷宾斯克举行的 ACM ICPC 2002–2003 俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

纸带上有 n 个减号（1 ≤ n ≤ 200，事先未知），其余格子都是 `#`。这些减号围成
一圈；从第一个开始，每数到第 k 个尚未划掉的减号就把它划掉，直到只剩一个。给定
k（1 ≤ k ≤ 200），输出一台图灵机的控制表，使它对任意 n 都把除这一个之外的所有
减号变成 `+`。

机器从状态 1 开始，位于最左边的减号上。表中的一行
`状态 符号 新状态 新符号 移动` 表示在某状态读到某符号时怎么做；移动为 `<`、`>`
或 `=`，当没有任何一行匹配时机器停机。可以写入 `+`、`#` 和 `A`–`Z`，减号所在
的格子只能是 `-` 或 `+`，留下的减号不能改变，并且读写头最后必须停在它上面。
限制：最多 1 000 000 步，行数少于 10 000，状态编号 1 到 30 000，起点两侧各最多
5000 格。

时间限制：1 秒。内存限制：64 MB。

## 输入

整数 k。

## 输出

行数 p（1 < p < 10 000），然后是 p 行，每行五项，用单个空格分隔。

## 评测方式

任何对所有 n 都正确的表都被接受。参考评测程序对 1 到 200 的每个 n 运行这张表，
检查步数、写入的符号、留下的减号以及读写头最终的位置。

## 样例

题面只展示格式：对 k = 2 给出一张划掉第二个减号的五行表，它只在 n = 2 时正确。

## 解法

机器不必模拟游戏：输出表时 k 已知，所以程序自己用约瑟夫递推
`pos(n) = (pos(n−1) + k) mod n` 对每个 n 解出游戏，并把答案写进表里。

- **计数。** 状态 i 表示"读写头在第 i 格"。读到 `-` 就右移并进入状态 i+1，
  所以走到减号之后的 `#` 时状态为 n+1，n 也就知道了。
- **寻找。** 这一行退回到最后一个减号上，进入"还要左移 d 格"的状态，其中
  d = n−1−pos(n)；这些状态一直左移到 d 为 0，读写头就停在留下的减号上。
- **划掉。** 五个固定状态先越过它，把它右边直到 `#` 的一切变成 `+`，再走回并
  经过它，划掉它左边的一切，最后沿着 `+` 向右回到它，此时没有匹配的行，机器
  停机。

共 609 行，最多 6n 步。`O(N)`，其中 `N = 200`。

注意事项：

- 留下的减号所在格子必须保持 `-`，所以扫描经过它时写回同一个 `-`；
- n = 1 也必须正确：这时机器什么也不划掉，停在唯一的减号上。

评测程序对每个 n 运行这张表，并把留下的减号与游戏留下的那个进行比较。
