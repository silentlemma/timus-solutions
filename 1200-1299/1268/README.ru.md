# 1268. Маленький Чу

[Timus 1268](https://acm.timus.ru/problem.aspx?space=1&num=1268) · сложность 728 · number_theory

Автор оригинальной задачи — Павел Атнашев; чемпионат Уральского государственного университета, 25 октября 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Маленький Чу просыпается через K, K², K³, … дней после рождения, и день
недели ни разу не должен повториться; в неделе N дней, N простое
(2 < N < 65 536), а K не больше недели. Для каждого из T ≤ 6553 значений
N вывести K, при котором пробуждений больше всего; по примеру видно, что
ожидается наибольшее такое K.

Ограничение времени: 0,25 секунды. Ограничение памяти: 64 МБ.

## Входные данные

T, затем T простых чисел N.

## Выходные данные

K для каждого N, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
4
3
5
7
11
```

Вывод:

```
2
3
5
8
```

## Решение

День недели i-го пробуждения — это K^i mod N. Эти значения повторяются
с периодом, равным порядку K по модулю N, поэтому больше всего
пробуждений, N − 1, даёт первообразный корень. Ответ — наибольший
первообразный корень по модулю N.

Число g — первообразный корень ровно тогда, когда g^((N−1)/q) ≠ 1 mod N
для каждого простого q, делящего N − 1. Разложим N − 1 на множители
решетом наименьших простых делителей до 65 536 и будем пробовать
g = N − 1, N − 2, …, пока одно не подойдёт. Первообразные корни
составляют заметную долю вычетов, так что кандидатов немного, и для
каждого нужно лишь несколько быстрых возведений в степень. Повторные N
отвечаются из таблицы. Примерно `O(L log log L + T · k log N)` при
пределе решета L и k кандидатах.

Тонкие места:

- дни различны при любом первообразном корне, но ожидается наибольший
  (в примере 8 для N = 11, а не 2);
- лимит времени — четверть секунды на до 6553 запросов, поэтому N − 1
  лучше раскладывать решетом, а не перебором заново каждый раз
  (тесты 04, 05);
- когда N − 1 — степень двойки, нужна лишь одна проверочная степень
  (тест 06).

Ответы сравнивались с перебором степеней каждого кандидата для всех
простых меньше 3000.
