# 1270. Уникуб

[Timus 1270](https://acm.timus.ru/problem.aspx?space=1&num=1270) · сложность 2285 · matching

Автор оригинальной задачи — Александр Мироненко; чемпионат Уральского государственного университета, 25 октября 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть N ≤ 30 кубиков, каждая грань покрашена в один из 30 цветов; цвета
даны в порядке «передняя, верхняя, правая, нижняя, левая, задняя».
Фигура состоит из M ≤ 30 клеток, у каждой есть требования к цветам её
шести граней (0 — любой цвет). Нужно поставить в каждую клетку свой
кубик, повернув как нужно, чтобы все требования выполнялись, и вывести
номер кубика для каждой клетки или 0, если это невозможно.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, N кубиков, M, затем M строк `X Y Z F U R D L B`.

## Выходные данные

M номеров кубиков или 0.

## Проверка

Подходящих расстановок может быть несколько, поэтому чекер принимает
любую: номера должны быть различны, и каждый кубик должен удовлетворять
требованиям своей клетки в одном из 24 поворотов. Ответ 0 принимается,
только если ожидаемый ответ равен 0.

## Примеры

### Пример 1

Ввод:

```
1
6 1 3 4 5 2
1
0 0 0 1 2 3 6 5 4
```

Вывод:

```
1
```

## Решение

Положение клетки не важно: требования относятся только к граням, а
соседние кубики друг на друга не влияют. Значит, это паросочетание в
двудольном графе клеток и кубиков. Кубик может стоять в клетке, если
один из его 24 поворотов выполняет все её требования. Повороты находятся
замыканием двух поворотов на четверть оборота — вокруг вертикальной оси
и вокруг оси «лево-право» — относительно композиции. Получаются ровно 24
собственных поворота и ни одного зеркального отражения. Затем алгоритм
Куна ищет увеличивающий путь из каждой клетки; если он не нашёлся, ответ
0. `O(M · N · 24 · 6 + M · N · M)`.

Тонкие места:

- разрешены только повороты: кубик, чьё зеркальное отражение подходит
  к клетке, может к ней не подходить (тест 02);
- жадный выбор может закрыть путь следующей клетке, поэтому
  паросочетание должно уметь переставлять уже поставленные кубики
  (тест 05);
- если клеток больше, чем кубиков, ответа нет (тест 03).

Существование расстановки сравнивалось с перебором всех инъективных
расстановок на 300 маленьких случайных случаях.

## Особенности языков

- Все языки строят повороты одинаково и запускают алгоритм Куна
  рекурсивно; глубина не больше 30.
