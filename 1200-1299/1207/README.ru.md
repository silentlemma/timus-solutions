# 1207. Прямая через две точки, делящая остальные пополам

[Timus 1207](https://acm.timus.ru/problem.aspx?space=1&num=1207) · сложность 120 · geometry

Автор оригинальной задачи — Павел Атнашев; командное соревнование УрГУ, март 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано чётное число `4 ≤ N ≤ 10000` точек с целыми координатами не больше
`10⁶` по модулю, никакие три не лежат на одной прямой. Выбрать две из
них так, чтобы прямая через них делила остальные точки на две равные
половины.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем координаты каждой точки.

## Выходные данные

Номера двух выбранных точек.

## Проверка

Подходит много пар, поэтому принимаются любые две разные точки, если их
прямая оставляет по `(N − 2)/2` точек с каждой стороны.

## Примеры

### Пример 1

Ввод:

```
4
0 0
1 0
0 1
1 1
```

Вывод:

```
1 4
```

## Решение

Берём самую нижнюю точку, а из двух на одной высоте — левую. Все
остальные точки лежат выше неё или правее на той же высоте, в пределах
полуоборота, поэтому их можно отсортировать по углу вокруг неё одним
знаком векторного произведения, без плавающей точки. В таком порядке все
точки до `k`-й лежат по одну сторону прямой от нижней точки к `k`-й, а
все после — по другую. Среди `N − 1` остальных точек у той, что стоит на
месте `(N − 2)/2` при счёте с нуля, по `(N − 2)/2` точек до и после.
`O(N log N)`.

Тонкие места:

- если выбирать нижнюю точку только по высоте, точка той же высоты
  левее неё окажется на полуобороте и сломает порядок;
- векторные произведения доходят до `8·10¹²`, больше 32 бит;
- компаратор должен возвращать «равно» при сравнении элемента с самим
  собой, иначе некоторые сортировки его отвергают.

Каждый ответ проверен подсчётом точек с каждой стороны, а отдельно
написанное решение проходит тот же чекер на всех тестах.
