# 1203. Сколько докладов может посетить один человек

[Timus 1203](https://acm.timus.ru/problem.aspx?space=1&num=1203) · сложность 79 · greedy

Автор оригинальной задачи — Магаз Асанов; командное соревнование УрГУ, март 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На конференции `N ≤ 10⁵` интересных докладов, каждый идёт с минуты `Ts`
по минуту `Te`, `1 ≤ Ts < Te ≤ 30000`. Посещённые доклады не могут
пересекаться, и между ними должна быть хотя бы минута: после доклада,
кончающегося в 15, следующий может начаться не раньше 16. Найти наибольшее
число докладов, которые может посетить один человек.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `Ts Te` для каждого доклада.

## Выходные данные

Наибольшее число докладов.

## Примеры

### Пример 1

Ввод:

```
5
3 4
1 5
6 7
4 5
1 3
```

Вывод:

```
3
```

## Решение

Классическая жадность для выбора интервалов: раз за разом берём доклад,
который кончается раньше всех среди начинающихся после конца последнего
выбранного. Любое оптимальное расписание может заменить свой первый
доклад на этот без потерь, и рассуждение повторяется.

Времена маленькие, поэтому сортировка не нужна: для каждой минуты `e`
храним самое позднее начало среди докладов, кончающихся в `e`. Идём по
минутам по порядку; если самое позднее начало в `e` позже конца
последнего выбранного, доклад, кончающийся в `e`, можно взять, и он
кончается раньше всех доступных. `O(N + T)` при `T = 30000`.

Тонкие места:

- доклад, начинающийся в ту же минуту, когда кончается предыдущий,
  нельзя, так что проверка строгая: «начало > последний конец»;
- повторяющиеся одинаковые доклады засчитываются не больше одного раза.

Ответы сверены с отдельно написанным решением на 300 случайных входах и
на всех тестах.
