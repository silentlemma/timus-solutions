# 1203. 一个人最多能听多少场报告

[Timus 1203](https://acm.timus.ru/problem.aspx?space=1&num=1203) · 难度 79 · greedy

原题作者 Magaz Asanov，出自 2002 年 3 月乌拉尔国立大学团体赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一次会议有 `N ≤ 10⁵` 场感兴趣的报告，每场从第 `Ts` 分钟进行到第 `Te` 分钟，
`1 ≤ Ts < Te ≤ 30000`。所听的报告不能重叠，而且之间至少要隔一分钟：在 15 分结束
的报告之后，下一场最早只能从 16 分开始。求一个人最多能听多少场报告。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后每场报告一行 `Ts Te`。

## 输出

最多能听的报告数。

## 样例

### 样例 1

输入：

```
5
3 4
1 5
6 7
4 5
1 3
```

输出：

```
3
```

## 解法

区间调度的经典贪心：每次在开始时间晚于上一场所选报告结束时间的报告中，选结束最早
的一场。任何最优安排都可以把它的第一场换成这一场而不吃亏，同样的论证可以反复
进行。

时间范围很小，所以不需要排序：对每一分钟 `e` 记录在 `e` 结束的报告中最晚的开始
时间。按顺序扫过每一分钟；如果 `e` 处最晚的开始时间晚于上一场所选报告的结束时间，
就可以选一场在 `e` 结束的报告，而它正是可选报告中结束最早的。`O(N + T)`，
`T = 30000`。

注意事项：

- 在前一场结束的同一分钟开始的报告不能选，所以判断是严格的“开始 > 上次结束”；
- 重复的相同报告最多只算一次。

答案已在 300 个随机输入和所有测试上与另一份独立解答比对。
