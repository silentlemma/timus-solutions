# 1237. Проверка оптимальности плана эвакуации

[Timus 1237](https://acm.timus.ru/problem.aspx?space=1&num=1237) · сложность 985 · graphs

Автор оригинальной задачи — Владимир Котов; полуфинал ACM ICPC Северо-Восточной Европы 2002–2003.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В N зданиях (N ≤ 100) работают по B_i человек, а M убежищ (M ≤ 100)
вмещают не больше C_j человек каждое. Путь от здания i до убежища j
занимает `|X_i − P_j| + |Y_i − Q_j| + 1`. План говорит, сколько людей E_ij
из каждого здания идёт в каждое убежище; он отправляет всех и не
превышает вместимости. Нужно определить, минимально ли суммарное время
пути, и если нет — показать любой допустимый план с меньшей суммой.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M; здания в виде `X Y B`; убежища в виде `P Q C`; затем N строк
плана.

## Выходные данные

`OPTIMAL` или `SUBOPTIMAL` и затем лучший план в том же формате.

## Проверка

Принимается любой лучший план. Чекер сравнивает первое слово с ожидаемым
ответом и проверяет, что план отправляет всех людей каждого здания, не
переполняет убежища и даёт меньшее суммарное время, чем исходный.

## Примеры

### Пример 1

Ввод:

```
3 4
-3 3 5
-2 -2 6
2 2 5
-1 1 3
1 1 4
-2 -2 7
0 -1 3
3 1 1 0
0 0 6 0
0 3 0 2
```

Вывод:

```
SUBOPTIMAL
3 0 1 1
0 0 6 0
0 4 0 1
```

### Пример 2

Ввод:

```
3 4
-3 3 5
-2 -2 6
2 2 5
-1 1 3
1 1 4
-2 -2 7
0 -1 3
3 0 1 1
0 0 6 0
0 4 0 1
```

Вывод:

```
OPTIMAL
```

## Решение

План — это поток, а поток имеет наименьшую стоимость ровно тогда, когда в
его остаточном графе нет цикла отрицательной стоимости. Здесь этот граф
можно построить только на убежищах плюс одна дополнительная вершина для
свободных мест:

- **j → k** переводит одного человека некоторого здания i из убежища j в
  убежище k, что требует `E_ij > 0` и стоит `D_ik − D_ij`; ребро берёт
  самое выгодное такое здание;
- **j → запас**, стоимость 0, есть, когда в убежище j есть свободное
  место;
- **запас → k**, стоимость 0, позволяет убежищу k остаться с одним
  человеком меньше.

Цикл только по убежищам сдвигает цепочку людей и сохраняет загрузку
каждого убежища; цикл через вершину запаса занимает свободное место на
одном конце и освобождает место на другом. Беллман — Форд сразу из всех
вершин либо успокаивается не больше чем за M + 1 раунд (`OPTIMAL`), либо
ещё меняет расстояние в последнем раунде; тогда M + 1 шаг по
предшественникам приводит на отрицательный цикл, и перевод одного
человека по каждому его ребру между убежищами даёт более дешёвый
допустимый план. `O(N·M² + M³)`.

Тонкие места:

- если не учесть свободные места исходного плана, пропадут улучшения
  вроде теста 05, где одному человеку надо просто перейти в пустое
  убежище поближе;
- простой цикл выходит из каждого убежища один раз, так что каждый
  перевод берёт человека, который там действительно есть.

Ответы сравнивались с точным потоком минимальной стоимости на 399
случайных маленьких городах, и каждый лучший план проверялся чекером.

## Особенности языков
