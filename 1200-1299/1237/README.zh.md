# 1237. 检验疏散计划是否最优

[Timus 1237](https://acm.timus.ru/problem.aspx?space=1&num=1237) · 难度 985 · graphs

原题作者 Vladimir Kotov，出自 2002–2003 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 栋楼（N ≤ 100）各有 B_i 名职员，M 个避难所（M ≤ 100）各最多容纳 C_j 人。从
楼 i 走到避难所 j 需要 `|X_i − P_j| + |Y_i − Q_j| + 1`。计划给出每栋楼去每个避难所
的人数 E_ij；它安置了所有人且不超过容量。判断计划的总步行时间是否最小，若不是，
给出任意一个总时间更小的合法计划。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 M；各楼的 `X Y B`；各避难所的 `P Q C`；然后是计划的 N 行。

## 输出

`OPTIMAL`，或者 `SUBOPTIMAL` 并在其后按相同格式给出更好的计划。

## 评测方式

任何更好的计划都被接受。评测程序把第一个词与期望答案比较，并检查计划是否安置了每栋
楼的所有人、没有超过任何避难所的容量、总时间比给定计划更小。

## 样例

### 样例 1

输入：

```
3 4
-3 3 5
-2 -2 6
2 2 5
-1 1 3
1 1 4
-2 -2 7
0 -1 3
3 1 1 0
0 0 6 0
0 3 0 2
```

输出：

```
SUBOPTIMAL
3 0 1 1
0 0 6 0
0 4 0 1
```

### 样例 2

输入：

```
3 4
-3 3 5
-2 -2 6
2 2 5
-1 1 3
1 1 4
-2 -2 7
0 -1 3
3 0 1 1
0 0 6 0
0 4 0 1
```

输出：

```
OPTIMAL
```

## 解法

计划就是一个流，而流的费用最小当且仅当它的残量图中没有负费用环。这里该图可以只建在
避难所上，再加一个表示空余位置的额外结点：

- **j → k**：把某栋楼 i 的一个人从避难所 j 移到避难所 k，要求 `E_ij > 0`，费用
  为 `D_ik − D_ij`；这条边取最便宜的那栋楼；
- **j → 空余**：费用 0，当避难所 j 有空位时存在；
- **空余 → k**：费用 0，允许避难所 k 最终少一个人。

只经过避难所的环把一串人依次挪动，每个避难所的人数不变；经过空余结点的环在一端占用
一个空位，在另一端腾出一个位置。从所有结点同时出发的 Bellman–Ford 要么在至多 M + 1
轮内稳定（`OPTIMAL`），要么在最后一轮仍有距离改变；此时沿前驱走 M + 1 步就会落在一个
负环上，沿该环每条避难所之间的边移动一个人，就得到更便宜的合法计划。
`O(N·M² + M³)`。

注意事项：

- 如果不考虑给定计划中的空余位置，就会漏掉像测试 05 那样的改进：一个人只需搬到更近
  的空避难所；
- 简单环从每个避难所只出发一次，所以每次移动的人都确实在那里。

这些结论在 399 个随机小城市上与精确的最小费用流结果比较过，每个更好的计划都经过了
评测程序的检查。
