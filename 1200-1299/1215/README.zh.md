# 1215. 仍能击中目标的最小炮弹

[Timus 1215](https://acm.timus.ru/problem.aspx?space=1&num=1215) · 难度 302 · geometry

原题作者 Anton Botov 和 Anatoly Uglov，出自 2002 年 10 月 USU Open Collegiate Programming Contest（Junior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

炮弹落在给定的点，留下一个与炮弹等宽的圆形弹坑。目标是一个凸多边形，有 3 到 100
个按逆时针给出的顶点，所有坐标都是 `[−2000, 2000]` 内的整数。求弹坑能碰到目标的
最小炮弹直径，保留三位小数。

时间限制：1 秒。内存限制：64 MB。

## 输入

落点和 `N`，然后是 `N` 个顶点。

## 输出

保留三位小数的最小直径。

## 样例

### 样例 1

输入：

```
2 -1 8
0 1
1 0
2 0
3 1
3 2
2 3
1 3
0 2
```

输出：

```
2.000
```

## 解法

弹坑碰到目标当且仅当其半径不小于落点到多边形的距离，所以答案是这个距离的两倍。
若点在多边形内部或边界上，距离为 0；由于顶点按逆时针排列，这等价于点在每条边的
左侧或边上，用整数叉积可以精确判断。否则多边形上的最近点在边界上，距离就是到各边
（作为线段）的最小距离：垂足落在线段内时取到垂足的距离，否则取到较近端点的距离。
`O(N)`。

注意事项：

- 点在边界上也算击中，直径为 `0.000`；
- 当最近点是顶点时，到边所在直线的距离会偏小；
- 答案是直径，即距离的两倍。

答案已在 300 个随机目标上与另一份独立解答比对，落点分别在外部、内部和顶点上。

## 优化解法

Go 和 Rust 随顶点输入处理多边形边，只保留首个和前一个顶点。整数叉积判断点位于边的哪侧，点积决定最近点是端点还是内部投影。距离平方保留为整数分数，通过 128 位交叉乘积比较。取得最小值后，先用整数检查修正平方根，再精确比较半单位阈值，将直径舍入到三位小数。两个版本均使用固定字节输入输出缓冲区，辅助空间为常数。Go 直接通过标准句柄传输缓冲区。

已通过评测的基础实现 [1215_geometry.cpp](1215_geometry.cpp), [1215_geometry.java](1215_geometry.java), [1215_geometry.py](1215_geometry.py) 也满足快速版本的要求：在保存的比较快照中，时间和内存均符合前 15% 或前十名的排名收录规则。直接复用这些源文件，不创建相同副本。星号标记尚未达到该语言目标排名的版本。
