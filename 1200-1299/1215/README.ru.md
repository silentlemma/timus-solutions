# 1215. Самый маленький снаряд, который ещё попадёт в цель

[Timus 1215](https://acm.timus.ru/problem.aspx?space=1&num=1215) · сложность 300 · geometry

Авторы оригинальной задачи — Антон Ботов и Анатолий Углов; USU Open Collegiate Programming Contest, октябрь 2002 года, Junior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Снаряд падает в заданную точку и оставляет круглую воронку диаметром со
снаряд. Цель — выпуклый многоугольник с 3–100 вершинами против часовой
стрелки, все координаты целые в `[−2000, 2000]`. Найти наименьший
диаметр снаряда, воронка которого задевает цель, с тремя знаками.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Точка попадания и `N`, затем `N` вершин.

## Выходные данные

Наименьший диаметр с тремя знаками после точки.

## Примеры

### Пример 1

Ввод:

```
2 -1 8
0 1
1 0
2 0
3 1
3 2
2 3
1 3
0 2
```

Вывод:

```
2.000
```

## Решение

Воронка задевает цель ровно тогда, когда её радиус не меньше расстояния
от точки попадания до многоугольника, так что ответ — удвоенное
расстояние. Если точка внутри или на границе, расстояние 0; раз вершины
идут против часовой стрелки, так бывает, когда точка лежит слева от
каждого ребра или на нём, что точно решают целочисленные векторные
произведения. Иначе ближайшая точка многоугольника лежит на границе, и
расстояние — наименьшее расстояние до ребра как отрезка: до основания
перпендикуляра, если оно внутри отрезка, иначе до ближнего конца.
`O(N)`.

Тонкие места:

- точка на границе — попадание с диаметром `0.000`;
- расстояния до прямых, содержащих рёбра, слишком малы, когда ближайшая
  точка — вершина;
- ответ — диаметр, удвоенное расстояние.

Ответы сверены с отдельно написанным решением на 300 случайных целях с
выстрелами снаружи, внутри и в вершины.

## Особенности языков

- Во всех языках попадание внутрь проверяется точными целочисленными
  векторными произведениями, вывод — три знака; Java форматирует с
  `Locale.US`.
