# 1254. Обезвреживание бомб по порядку в городе

[Timus 1254](https://acm.timus.ru/problem.aspx?space=1&num=1254) · сложность 645 · shortest_paths

Автор оригинальной задачи — Павел Атнашев; открытое командное первенство УрГУ, 15 марта 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Город — сетка N × M (N, M ≤ 75) из пустых кварталов `.` и зданий `#`.
Джон ходит между соседними кварталами по стороне или по диагонали со
скоростью V. Начиная с (x₀, y₀), он должен обезвредить K бомб
(K ≤ 1000) в данном порядке; недостижимую бомбу он пропускает. Найти
наименьшее общее время с точностью до двух знаков.

Ограничение времени: 5 секунд. Ограничение памяти: 64 МБ.

## Входные данные

N, M, K и V; карта — M строк по N символов; начало; K бомб в виде
`x y`.

## Выходные данные

Наименьшее время с двумя знаками после точки.

## Примеры

### Пример 1

Ввод:

```
4 3 3 1.23
....
##..
....
1 1
1 3
4 1
4 3
```

Вывод:

```
8.66
```

## Решение

Обезвреживание мгновенно и порядок задан, так что итог — сумма
кратчайших путей от каждой позиции до следующей достижимой бомбы,
делённая на V. Шаг по стороне имеет длину 1, по диагонали — √2; шаг по
диагонали может проходить мимо угла здания, и пример этого требует на
пути мимо `##`.

Нужно до 1000 поисков кратчайшего пути на 5625 клетках. Дёшевы они
благодаря трём вещам:

- город один раз делится на части, связанные ходами, так что бомба в
  другой части пропускается сразу, а не после полного поиска;
- каждый поиск — A* с октильным расстоянием
  `max(dx, dy) + (√2 − 1)·min(dx, dy)` в качестве оценки, которая никогда
  не превосходит истинной длины, поэтому когда бомба впервые выходит из
  очереди, её расстояние окончательно, а в открытом городе поиск почти не
  отходит от прямой;
- уже найденные пути запоминаются по паре концов в обе стороны.

Карта окружена каймой из зданий, так что ходам не нужна проверка
границ. `O(K · NM log NM)` в худшем случае.

Тонкие места:

- после недостижимой бомбы Джон остаётся, где был (тест 03);
- начало может совпасть с бомбой — путь длины 0 (тест 02);
- начальная клетка считается свободной, что бы ни было на карте.

Итоги сравнивались с обычным алгоритмом Дейкстры на 300 случайных
маленьких городах со зданиями и недостижимыми бомбами.
