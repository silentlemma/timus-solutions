# 1200. Сколько делать рогов и копыт

[Timus 1200](https://acm.timus.ru/problem.aspx?space=1&num=1200) · сложность 256 · math

Автор оригинальной задачи — Магаз Асанов; командное соревнование УрГУ, март 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждый рог приносит `A` рублей, каждое копыто — `B` рублей,
`-10000 ≤ A, B ≤ 10000` с двумя знаками после точки. Продать можно не
больше `K ≤ 10000` изделий всего, а рэкетиры берут квадрат количества
изделий каждого вида. Выбрать `x` рогов и `y` копыт с `x + y ≤ K`, чтобы
максимизировать `A·x + B·y − x² − y²`; среди лучших планов взять тот, где
меньше рогов, затем меньше копыт.

Ограничение времени: 0.25 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`A` и `B`, затем `K`.

## Выходные данные

Наибольшая прибыль с двумя знаками после точки, затем `x` и `y`.

## Примеры

### Пример 1

Ввод:

```
34.20 61.70
45
```

Вывод:

```
1239.50
16 29
```

## Решение

Считаем в копейках, чтобы каждая прибыль была точным целым:
`a·x − 100·x² + b·y − 100·y²`, где `a`, `b` — цены, умноженные на 100.
Перебираем все `x` от 0 до `K`. При фиксированном `x` часть копыт —
вогнутая парабола по `y`, поэтому её лучшее значение на `0..K−x` — в
целом числе сразу ниже или сразу выше вершины `b/200`, загнанном в
диапазон; пробуем оба и при равенстве оставляем меньший `y`. Если идти по
`x` вверх и заменять лучший план только при строго большей прибыли,
получится нужный выбор среди равных. `O(K)`.

Тонкие места:

- при прибыли в числах с плавающей точкой два равных плана могут
  сравниться как разные, и выбор среди равных пойдёт не так;
- прибыль доходит до `5·10⁷` рублей, `5·10⁹` копеек — больше 32-битных
  целых;
- когда обе цены отрицательны, ответ — ничего не делать, и прибыль нужно
  вывести как `0.00`, а не `-0.00`.

Ответы сверены с отдельно написанным перебором всех планов на 400
случайных входах с маленьким `K`.

## Особенности языков

- Все языки читают цены как числа с плавающей точкой и округляют до
  копеек; для двух знаков в этом диапазоне это точно.
