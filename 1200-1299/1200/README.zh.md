# 1200. 该生产多少角和蹄

[Timus 1200](https://acm.timus.ru/problem.aspx?space=1&num=1200) · 难度 257 · math

原题作者 Magaz Asanov，出自 2002 年 3 月乌拉尔国立大学团体赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

每只角赚 `A` 卢布，每只蹄赚 `B` 卢布，`-10000 ≤ A, B ≤ 10000`，精确到两位小数。
总共最多能卖出 `K ≤ 10000` 件，而敲诈者按每种商品数量的平方收钱。选择 `x` 只角
和 `y` 只蹄，满足 `x + y ≤ K`，使 `A·x + B·y − x² − y²` 最大；有多个最优方案时
取角最少的，再取蹄最少的。

时间限制：0.25 秒。内存限制：64 MB。

## 输入

`A` 和 `B`，然后是 `K`。

## 输出

最大利润（两位小数），然后是 `x` 和 `y`。

## 样例

### 样例 1

输入：

```
34.20 61.70
45
```

输出：

```
1239.50
16 29
```

## 解法

把价格转为整数戈比 `a,b`。利润是 `P(x,y)=a·x+b·y−100(x²+y²)`，
整数 `x,y≥0` 且 `x+y≤K`。允许不生产，所以最优利润非负。

简单算法枚举角数 `x=0..K`。固定 `x` 后，蹄数利润是顶点 `b/200` 的凹抛物线，
限制在 `0≤y≤K−x`。检查顶点旁的两个整数并截到可行区间；顶点为负则取零。
所有可行 `x` 的最佳 `y` 都已考虑，故得到全局最优。按 `x` 及两个 `y` 从小到大
遍历，仅严格更高利润才更新，平局保留更少角、再更少蹄。五份 Accepted 基础版
都遵守此规则。时间 `O(K)`，常量工作状态加有界输入输出。

利润用整数戈比比较。基础版先把两位小数价格乘 100 再舍入为整数；
`|A|,|B|≤10000` 时浮点表示误差远小于半戈比，初始转换安全，后续全是整数。
`K≤10000` 时中间表达式绝对值不超过 `2·10¹⁰`，最大利润不超过 `5·10⁹` 戈比。
原生语言需有符号 64 位评分，不能用 32 位。

## 优化解法

利润是整数三角形上的可分凹二次函数。内部最优点舍入两个独立顶点；若违反容量，则有边界最优点。代入容量等式得到一元凹二次函数，只需顶点旁的整数和端点。Java 显式检查常数个候选，Python 直接做等价且考虑平局的投影。利润用整数戈比精确计算，平局先少角、再少蹄。这是替代线性枚举的常数规模几何算法。

- `1200_math_geometry.java`: 0.109 s / 868 KB; 基础版 `1200_math.java`: 0.140 s / 2096 KB; 相对基础版的变化: 时间 -22.1%, 内存 -58.6%.
- `1200_math_geometry.py`: 0.125 s / 284 KB; 基础版 `1200_math.py`: 0.093 s / 488 KB; 相对基础版的变化: 时间 +34.4%, 内存 -41.8%.

## 评测方式

比较精确戈比利润及两个数量，必须满足平局规则。实际 Java 候选通过
Docker 中 13 个仓库输入并取得对应精确源码的 Accepted。常数候选法的 Python
实现还独立枚举全部整数点验证了 8400 个合法小三角形，以及 400 个超出题目
`K≥1` 范围的零容量扩展输入，共 8800 次 Python 执行，不是 8800 次 Java 执行。
重要情况包括负价格、零生产、闲置容量、紧的对角线及产生平局的半整数顶点。
