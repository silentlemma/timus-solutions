# 1200. 该生产多少角和蹄

[Timus 1200](https://acm.timus.ru/problem.aspx?space=1&num=1200) · 难度 256 · math

原题作者 Magaz Asanov，出自 2002 年 3 月乌拉尔国立大学团体赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

每只角赚 `A` 卢布，每只蹄赚 `B` 卢布，`-10000 ≤ A, B ≤ 10000`，精确到两位小数。
总共最多能卖出 `K ≤ 10000` 件，而敲诈者按每种商品数量的平方收钱。选择 `x` 只角
和 `y` 只蹄，满足 `x + y ≤ K`，使 `A·x + B·y − x² − y²` 最大；有多个最优方案时
取角最少的，再取蹄最少的。

时间限制：0.25 秒。内存限制：64 MB。

## 输入

`A` 和 `B`，然后是 `K`。

## 输出

最大利润（两位小数），然后是 `x` 和 `y`。

## 样例

### 样例 1

输入：

```
34.20 61.70
45
```

输出：

```
1239.50
16 29
```

## 解法

以戈比为单位计算，让每个利润都是精确的整数：`a·x − 100·x² + b·y − 100·y²`，
其中 `a`、`b` 是价格乘以 100。枚举 `x` 从 0 到 `K`。固定 `x` 时，蹄的部分是关于
`y` 的凹抛物线，所以它在 `0..K−x` 上的最大值位于顶点 `b/200` 正下方或正上方的
整数处（再限制到范围内）；两个都试，相等时保留较小的 `y`。让 `x` 递增，并且只在
利润严格更大时替换最优方案，就得到要求的平局处理。`O(K)`。

注意事项：

- 用浮点数计算利润时，两个相等的方案可能被比较成不相等，从而选错；
- 利润可达 `5·10⁷` 卢布，即 `5·10⁹` 戈比，超出 32 位整数；
- 两个价格都为负时答案是什么都不生产，利润要输出 `0.00` 而不是 `-0.00`。

答案已在 400 个 `K` 较小的随机输入上与另一份独立编写的、枚举所有方案的暴力解法
比对。

## 各语言说明

- 所有语言都把价格读成浮点数再四舍五入到戈比，在这个范围内对两位小数是精确的。
