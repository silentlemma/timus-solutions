# 1279. Склад

## Задача

Склад из N × M секций (N, M ≤ 100) хранит стопки контейнеров высотой
от 1 до 1000. Приходит K ≤ 10⁷ новых контейнеров, и их по одному ставят
на одну из самых низких секций. Найти наименьшую высоту после того, как
все они поставлены.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, M и K, затем N строк по M высот.

## Выходные данные

Наименьшая высота после размещения контейнеров.

## Примеры

### Пример 1

Ввод:

```
2 2 3
1 3
2 4
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
3 3 10
1 2 3
4 5 6
7 8 9
```

Вывод:

```
5
```

## Решение

Добавление всегда на самую низкую секцию похоже на заливку водой: в
конце все секции ниже некоторого уровня h подняты до h, а оставшиеся
контейнеры подняли часть из них до h + 1, но не все. Чтобы поднять всё
до уровня h, нужно need(h) = Σ max(0, h − высота) контейнеров, и это
число растёт с h. Значит, ответ — наибольшее h с need(h) ≤ K; его
находит двоичный поиск между наименьшей высотой и ею же плюс K.
`O(N · M · log K)`.

Тонкие места:

- ответ может превышать 10⁷, а need(h) до 10⁴ · 10⁷ требует 64 бит
  (тесты 03, 12);
- оставшиеся контейнеры не поднимают минимум, если не достаются каждой
  секции этого уровня (тест 05);
- моделировать контейнеры по одному при K = 10⁷ слишком медленно.

Ответы сравнивались с размещением контейнеров по одному с помощью кучи
на 199 маленьких складах.
