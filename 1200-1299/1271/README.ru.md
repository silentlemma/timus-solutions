# 1271. Лоцман

[Timus 1271](https://acm.timus.ru/problem.aspx?space=1&num=1271) · сложность 4259 · geometry

Автор оригинальной задачи — Алексей Лахтин; чемпионат Уральского государственного университета, 25 октября 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Треугольный танкер плывёт по прямоугольной гавани 0 ≤ x ≤ DX,
0 ≤ y ≤ DY (DX, DY < 10⁸) среди N ≤ 40 треугольных кораблей на якоре.
Он может только перемещаться, но не поворачиваться. Найти длину
кратчайшего маршрута, приводящего его первый угол в заданную точку, с
тремя знаками после запятой или −1, если это невозможно. Танкер может касаться
кораблей и краёв гавани, но не перекрываться с ними; корабли друг друга
не перекрывают.

Ограничение времени: 3 секунды. Ограничение памяти: 64 МБ.

## Входные данные

DX и DY, три угла танкера, цель для его первого угла, N, затем три угла
каждого корабля. Все координаты целые.

## Выходные данные

Длина маршрута или −1.

## Примеры

### Пример 1

Ввод:

```
2003 2003
20 50
10 30
30 30
140 60
1
80 1000

Вывод:

```

## Решение

Следим только за первым углом A танкера; все три угла смещены от него
на постоянные векторы d₁, d₂, d₃ (один из них нулевой).

- Танкер остаётся в гавани ровно тогда, когда A остаётся в меньшем
  прямоугольнике, сдвинутом внутрь на наименьшее и наибольшее смещения.
- Танкер перекрывается с кораблём ровно тогда, когда A лежит строго
  внутри выпуклой оболочки девяти точек (угол корабля − смещение
  танкера). Это суммы Минковского, открытые выпуклые многоугольники не
  более чем с шестью углами.

Значит, точка движется в прямоугольнике вокруг открытых выпуклых
препятствий. Кратчайший путь изгибается только в углах препятствий.
Поэтому вершины графа — начало, цель и все углы препятствий, лежащие в
прямоугольнике и не строго внутри другого препятствия. Две вершины
соединены, если отрезок между ними не заходит внутрь ни одного
препятствия. Маршрут находит алгоритм Дейкстры.

Геометрические проверки точны в 64-битных целых:
углы целые, по модулю меньше 3 · 10⁸.
Отрезок не задевает открытый выпуклый многоугольник ровно тогда, когда
их разделяет, в худшем случае касанием, какая-то ось. Проверять нужно
нормали рёбер многоугольника и нормаль самого отрезка. Каждая проверка
сравнивает скалярные произведения порядка 10¹⁷. При V ≤ 242 вершинах
графа и N многоугольниках это `O(V² · N)`.

Тонкие места:

- касание разрешено: танкер может скользить вдоль корабля, проходить в
  щель ровно своей ширины или закончить путь вплотную к кораблю
  (тесты 06, 07, 09);
- цель может быть недостижима, потому что танкер там не помещается — в
  гавани или среди кораблей (тест 03);
- проверки в плавающей точке могут ошибиться при 10⁸, где щепка толщиной в
  единицу всё равно должна перекрывать путь (тест 05);
- препятствие может выступать за уменьшенный прямоугольник; его углы
  снаружи не используются, но части внутри по-прежнему мешают;
- если цель совпадает с началом, ответ 0 (тест 04).

Ответы сравнивались с независимой реализацией на 240 случайных гаванях,
включая гавани с 40 кораблями, координаты до 10⁸ и стены с узкими
проходами.

## Особенности языков

- Все языки используют точные целочисленные проверки. Для Дейкстры
  Python использует `heapq`, остальные — перебор вершин.
