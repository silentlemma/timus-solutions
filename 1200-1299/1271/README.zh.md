# 1271. 领航员

[Timus 1271](https://acm.timus.ru/problem.aspx?space=1&num=1271) · 难度 4551 · geometry

原题作者 Alexey Lakhtin，出自 2003 年 10 月 25 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一艘三角形油轮在矩形港口 0 ≤ x ≤ DX、0 ≤ y ≤ DY（DX, DY < 10⁸）中航行，港内停着
N ≤ 40 艘三角形船只。油轮只能平移，不能旋转。求把它的第一个角送到给定点的最短路线长度，
保留三位小数；若做不到则输出 −1。油轮可以接触其他船和港口边界，但不能与它们重叠；船只
之间互不重叠。

时间限制：3 秒。内存限制：64 MB。

## 输入

DX 和 DY，油轮的三个角，第一个角的目标点，N，然后是每艘船的三个角。所有坐标都是整数。

## 输出

路线长度，或 −1。

## 样例

### 样例 1

输入：

```
2003 2003
20 50
10 30
30 30
140 60
1
80 1000
100 20
60 20
```

输出：

```
146.569
```

## 解法

只跟踪油轮的第一个角 A；其他角相对它有固定的偏移 d₁、d₂、d₃（其中一个为零）。

- 油轮留在港内，当且仅当 A 留在一个更小的矩形里，这个矩形按最小和最大偏移向内收缩。
- 油轮与一艘船重叠，当且仅当 A 严格位于九个点（船的角 − 油轮偏移）的凸包内部。这些就是
  闵可夫斯基和，是最多六个角的开凸多边形。

于是问题变成一个点在矩形内绕开开凸障碍物移动。最短路径只在障碍物的角上转折。因此图的
顶点是起点、终点，以及所有位于矩形内、且不严格位于其他障碍物内部的障碍物角。若两点间
的线段不进入任何障碍物内部，就连一条边。最后用 Dijkstra 算法求路线。

一切都用 64 位整数精确计算：角都是整点，绝对值小于 3 · 10⁸。线段与开凸多边形不相交，
当且仅当存在某条轴把它们分开（最坏情况为相切）。需要检验的轴是多边形各边的法向量以及
线段自身的法向量。每次检验比较约 10¹⁷ 量级的点积。图中顶点 V ≤ 242、多边形 N 个时为
`O(V² · N)`。

注意事项：

- 允许接触：油轮可以贴着船滑行、穿过恰好与自身同宽的缝隙，或停在紧贴船只的位置（测试
  06、07、09）；
- 目标可能不可达，因为油轮在那里放不下：超出港口或与船重叠（测试 03）；
- 在 10⁸ 量级上浮点判断可能出错，而一条厚度为一个单位的细长船仍必须挡住去路（测试 05）；
- 障碍物可能伸出收缩后的矩形；伸到外面的角不能用，但矩形内的部分仍然阻挡；
- 目标就是起点时答案为 0（测试 04）。

在 240 个随机港口上与一个独立实现比较过，其中包括有 40 艘船的港口、10⁸ 的坐标以及带窄缝
的船墙。

## 各语言说明

- 所有语言都使用同样的精确整数判断和简单的 O(V²) Dijkstra 算法。
