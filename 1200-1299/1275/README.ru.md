# 1275. Рыцари Круглого стола

[Timus 1275](https://acm.timus.ru/problem.aspx?space=1&num=1275) · сложность 2249 · math

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N рыцарей (2 ≤ N ≤ 1000) сидят за круглым столом, у каждого есть
несколько кубков. За один заход слуга либо приносит по кубку двум
рыцарям, сидящим через K мест друг от друга, либо уносит по кубку у
каждого из них. У каждого рыцаря в конце должно быть F кубков, и слуга
не может унести кубок, которого нет. Найти план с наименьшим числом
заходов или вывести −1, если его нет. Начальные количества и F — от 0
до 1000, а в оптимальном плане не больше 30 000 заходов.

Ограничение времени: 0,1 секунды. Ограничение памяти: 0,5 МБ. В условии
разрешены C, C++ и Pascal, форма отправки предлагает ещё Rust.

## Входные данные

N, K и F, затем N количеств кубков.

## Выходные данные

Число заходов M и сами заходы в виде `i j +` или `i j -`, либо −1.

## Проверка

Оптимальных планов может быть много, поэтому чекер принимает любой:
число заходов должно быть наименьшим возможным, каждый заход должен
обслуживать двух рыцарей через K мест, количества кубков должны
оставаться неотрицательными, и у каждого в конце должно быть F.

## Примеры

### Пример 1

Ввод:

```
3 1 4
1 2 3
```

Вывод:

```
3
1 2 +
1 2 +
3 1 +
```

## Решение

Пусть x_i — число заходов со знаком к паре (i, i + K): плюс — принести,
минус — унести. Смешивать то и другое на одной паре — лишние заходы.
Рыцарь i входит в пары (i, i + K) и (i − K, i), поэтому x_(i−K) + x_i
должно равняться F минус число кубков у этого рыцаря.

Рыцари распадаются на gcd(N, K) циклов i, i + K, i + 2K, … длины
L = N / gcd(N, K), и каждый цикл решается отдельно. Если положить первую
неизвестную равной t, каждое правило задаёт следующую, и получается
x_j = ±t + c_j с чередующимися знаками. Последнее правило замыкает цикл:

- при нечётном L оно даёт 2t = r: решение ровно одно, а при нечётном r
  его нет;
- при чётном L t сокращается: решения нет, если r ≠ 0, а иначе годится
  любое t. Число заходов Σ |t − p_j| по точкам p_j = ∓c_j наименьшее,
  когда t — их медиана.

Сначала выводятся все заходы, приносящие кубки, а затем уносящие. Тогда
у рыцаря кубков сначала только прибавляется, а потом только убавляется,
поэтому количества остаются неотрицательными и в конце равны F ≥ 0.

Тонкие места:

- на чётном цикле план без заходов к первой паре может быть неоптимален;
  лучшее число выбирает медиана (тест gen3);
- `-` перед тем `+`, на который он рассчитывает, может унести кубок,
  которого ещё нет;
- при N = 2K пары (i, i + K) и (i + K, i) совпадают, и обоим рыцарям
  должно быть нужно одно и то же изменение (тест 07);
- лимит памяти не позволяет ничего тяжёлого: одни потоки C++ занимают
  слишком много, поэтому программа использует `scanf` и `printf`.

Наименьшее число заходов сравнивалось с полным перебором всех планов на
400 случайных столах до пяти рыцарей.

## Особенности языков

- В условии разрешены только C, C++ и Pascal, но форма отправки Timus
  предлагает ещё Rust 1.75, поэтому даны решения на C++ и Rust; Go,
  Python и Java отправить нельзя.
- В C++ изменения числа кубков и числа заходов со знаком имеют тип `int`,
  а t и сумма — `long long`; в Rust эти изменения, числа заходов и t
  имеют тип `i64`, а сумма — `u64`. Вместо `scanf` и `printf` в Rust ввод
  и вывод реализованы с фиксированными буферами по 4096 байт.
