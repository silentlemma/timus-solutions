# 1209. Цифры записанных подряд 1, 10, 100, 1000

## Задача

Степени десятки записаны подряд: `110100100010000…`. Для до 65535
позиций `1 ≤ K < 2³¹` вывести цифру на каждой позиции.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` позиций.

## Выходные данные

`N` цифр через пробел.

## Примеры

### Пример 1

Ввод:

```
4
3
14
7
6
```

Вывод:

```
0 0 1 0
```

## Решение

`m`-я записанная степень — это `10^(m−1)`, она занимает `m` цифр, поэтому
начинается с позиции `1 + (1 + 2 + … + (m − 1)) = 1 + m(m − 1)/2`, и
именно там стоит её единственная 1. На позиции `K` стоит 1 ровно тогда,
когда `K − 1 = m(m − 1)/2` для некоторого `m`, то есть когда
`8(K − 1) + 1 = (2m − 1)²` — точный квадрат. `O(1)` на позицию.

Тонкие места:

- `8(K − 1) + 1` доходит примерно до `1.7·10¹⁰`, больше 32 бит;
- корень в плавающей точке может ошибиться на единицу около больших
  квадратов, поэтому его надо поправить точными целочисленными
  проверками.

Ответы сверены с отдельно написанным решением на всех позициях от 1 до
65535, на случайных позициях и на позициях рядом с единицами.

## Особенности языков

- Python использует точный `math.isqrt`; остальные языки поправляют
  корень в плавающей точке целочисленными сравнениями.
