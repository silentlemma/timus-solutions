# 1296. 超空间跳跃

[Timus 1296](https://acm.timus.ru/problem.aspx?space=1&num=1296) · 难度 63 · dp

原题作者 Den Raskovalov，出自 2004 年 3 月 13 日第九届中学生公开团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 N ≤ 60 000 个 −30 000 到 30 000 之间的整数，求连续一段的最大和。允许取空段，其和为 0。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N 个数，每行一个。N 可能为 0。

## 输出

最大和。

## 样例

### 样例 1

输入：

```
10
31
-41
59
26
-53
58
97
-93
-23
84
```

输出：

```
187
```

### 样例 2

输入：

```
3
-1
-5
-6
```

输出：

```
0
```

## 解法

这是最大子段和问题，用 Kadane 算法一遍扫描即可。维护 `ending`：以当前数结尾的段的最大和，空段也
算在内。每个新数 p 要么接在这段后面，要么在和会变成负数时干脆不取：

ending = max(ending + p, 0)。

答案是 `ending` 取到过的最大值，初始为空段的 0。时间 `O(N)`，内存 `O(1)`。

注意事项：

- 全是负数时答案为 0，而不是最大的那个数（测试 02）；
- 允许 N = 0（测试 03）；
- 和可达 60 000 · 30 000 = 1.8 · 10⁹，接近 32 位上限，所以解法使用 64 位（测试 gen2）。

在 300 个随机序列上与枚举所有段的结果比较过。

- 所有语言都只维护两个累计和：`best` 和 `ending`。
