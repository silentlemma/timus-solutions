# 1217. Билеты, счастливые и по-московски, и по-петербургски

[Timus 1217](https://acm.timus.ru/problem.aspx?space=1&num=1217) · сложность 409 · combinatorics

Автор оригинальной задачи — Леонид Волков; VII студенческое соревнование по программированию УрГУ.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Номер билета — `N` цифр, `N` чётно и не больше 20, ведущие нули
допустимы. По-московски билет счастливый, если суммы цифр двух половин
равны, а по-петербургски — если цифры на нечётных местах дают ту же
сумму, что и на чётных. Посчитать билеты, счастливые в обоих смыслах.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

Число таких билетов.

## Примеры

### Пример 1

Ввод:

```
4
```

Вывод:

```
100
```

## Решение

Разобьём позиции на четыре группы по половине и по чётности: `A` и `B` —
нечётные и чётные позиции первой половины, `C` и `D` — второй, и пусть
каждая буква обозначает ещё и сумму цифр своей группы. Условия
записываются как `A + B = C + D` и `A + C = B + D`. Сложив их, получаем
`A = D`, вычтя — `B = C`; и наоборот, из этих двух равенств следуют оба
условия. Группы независимы, так что ответ —

(пары заполнений `A` и `D` с равными суммами) × (пары заполнений `B` и
`C` с равными суммами).

Число способов набрать сумму `s` из `k` цифр даёт маленькая таблица,
строящаяся по одной цифре, а каждый множитель — сумма по `s` произведений
двух таких чисел. `O(N²)` с крошечными константами.

Тонкие места:

- размеры групп зависят от того, нечётно ли `N/2`; подсчёт по позициям
  избавляет от ошибки;
- ответ при `N = 20` — около `1.9·10¹⁷`, больше 32 бит, но в 64
  помещается.

Формула проверена перебором всех шестизначных билетов, и каждое чётное
`N` от 2 до 20 сверено с отдельно написанным решением.

## Оптимизированные решения

Go, Java и Rust считают пары групп из k цифр с равной суммой без таблицы. Дополняем каждую цифру второй группы до девяти. Сумма новых 2k цифр должна быть 9k. Число неотрицательных решений без верхней границы даёт формула шаров и перегородок, а включения и исключения убирают цифры не меньше десяти. Если выбраны j таких позиций, вычитаем из каждой десять и используем сумму 9k − 10j. Ответы для двух независимых групп перемножаются. Go переиспользует входной буфер для записи десятичных цифр ответа справа налево. syscall.Read и syscall.Write работают со стандартными дескрипторами, повторяют прерванные вызовы и дописывают частичные записи.

Принятые базовые реализации [1217_combinatorics.cpp](1217_combinatorics.cpp), [1217_combinatorics.py](1217_combinatorics.py) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.

## Особенности языков

Эти замечания относятся к базовым реализациям.

- Во всех языках таблицы сумм цифр строятся одинаково; в Python целые
  произвольной точности, в остальных — 64-битные.
