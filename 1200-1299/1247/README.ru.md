# 1247. Ни один отрезок не тяжелее своей длины плюс N

[Timus 1247](https://acm.timus.ru/problem.aspx?space=1&num=1247) · сложность 240 · dp

Автор оригинальной задачи — Александр Мироненко; личное первенство УрГУ, 1 марта 2003 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Последовательность A_1 … A_S целых чисел от 0 до 100 в сумме даёт S + N
(S, N ≤ 30 000). Определить, верно ли для каждого отрезка
`A_i + … + A_j ≤ (j − i + 1) + N`.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

S и N, затем S чисел.

## Выходные данные

`YES` или `NO`.

## Примеры

### Пример 1

Ввод:

```
4 3
2
3
0
2
```

Вывод:

```
YES
```

### Пример 2

Ввод:

```
4 5
1
0
5
3
```

Вывод:

```
NO
```

## Решение

Вычтем из каждого элемента 1: условие превращается в «ни один отрезок
`B_i = A_i − 1` не даёт в сумме больше N». Значит, важна только
наибольшая сумма отрезка, и алгоритм Кадане находит её за один проход:
лучшая сумма отрезка, кончающегося в i, равна `max(предыдущая, 0) + B_i`,
а ответ — наибольшая из них в сравнении с N. `O(S)`.

Вся последовательность в B даёт ровно N, так что ответ NO ровно тогда,
когда отрезание префикса или суффикса с отрицательной суммой оставляет
более тяжёлый отрезок.

Тонкие места:

- ноль в начале уже делает остаток слишком тяжёлым (тест 04);
- отрезок из одного элемента тоже считается.
