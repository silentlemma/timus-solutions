# 1247. 没有一段比它的长度加 N 更重

[Timus 1247](https://acm.timus.ru/problem.aspx?space=1&num=1247) · 难度 240 · dp

原题作者 Alexander Mironenko，出自 2003 年 3 月 1 日乌拉尔国立大学个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

由 0 到 100 的整数组成的序列 A_1 … A_S 之和为 S + N（S, N ≤ 30 000）。判断是否对
每一段都有 `A_i + … + A_j ≤ (j − i + 1) + N`。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

S 和 N，然后是 S 个数。

## 输出

`YES` 或 `NO`。

## 样例

### 样例 1

输入：

```
4 3
2
3
0
2
```

输出：

```
YES
```

### 样例 2

输入：

```
4 5
1
0
5
3
```

输出：

```
NO
```

## 解法

把每个元素减 1：条件变成“`B_i = A_i − 1` 的任何一段之和都不超过 N”。所以只有最大的
段和才重要，Kadane 算法一遍就能求出：以 i 结尾的段的最大和为
`max(前一个, 0) + B_i`，答案就是其中的最大值与 N 的比较。`O(S)`。

整个序列在 B 中的和恰为 N，所以答案为 NO 当且仅当去掉一个和为负的前缀或后缀后剩下
一段更重的部分。

注意事项：

- 开头的一个 0 就已经让其余部分过重（测试 04）；
- 只有一个元素的段也算。
