# 1243. Что остаётся после дележа на семерых гномов

[Timus 1243](https://acm.timus.ru/problem.aspx?space=1&num=1243) · сложность 49 · math

## Задача

Семь гномов поровну делят N одинаковых вещей (1 ≤ N ≤ 10⁵⁰), а то, что
нельзя разделить поровну, отдают Белоснежке. Сколько вещей получит
Белоснежка?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

N mod 7.

## Примеры

### Пример 1

Ввод:

```
123456123456
```

Вывод:

```
1
```

## Решение

Ответ — остаток от деления N на 7, но в N до 51 цифры, гораздо больше
64 бит. Если читать N как строку и хранить только остаток её префикса,
он получается цифра за цифрой: `rest = (rest · 10 + цифра) mod 7`.
`O(len N)`.

Тонкие места:

- уже 20 цифр переполняют 64-битное целое (тест gen4).

## Оптимизированные решения

Оптимизированное решение на C++ сворачивает цифры по мере чтения через
`getchar`, не сохраняя число строкой, и выводит однозначный ответ одним
байтом: 84 КБ вместо 380 КБ при том же времени.

Оптимизированное решение на Go читает цифры побайтно через буфер на
128 байт вместо чтения числа строкой через `fmt.Scan` и выводит
однозначный ответ двумя байтами: 0.015 с вместо 0.046 с и 912 КБ вместо
1060 КБ.

## Особенности языков

- Целые Python вмещают N точно, поэтому там просто `int(N) % 7`;
  остальные языки сворачивают цифры.
