# 1242. 亲戚村庄里的狼人嫌疑人

[Timus 1242](https://acm.timus.ru/problem.aspx?space=1&num=1242) · 难度 175 · graphs

原题作者 Leonid Volkov，出自 2003 年 3 月 1 日乌拉尔国立大学个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

村里有 N 个人（1 < N ≤ 1000），已知其中一些人的父母是谁（每人至多两个，没有环）。
他们之中住着一个狼人，它从不攻击自己的祖先或后代。给出受害者名单，按升序输出所有
可能是狼人的人；如果没有，输出 0。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是若干行 `孩子 父母`，然后是单词 `BLOOD` 和受害者，每行一个。

## 输出

按升序输出可能的狼人，或 0。

## 样例

### 样例 1

输入：

```
8
1 3
3 6
4 5
6 2
4 6
8 1
BLOOD
3
8
```

输出：

```
4 5 7
```

### 样例 2

输入：

```
6
1 2
3 2
1 4
3 4
2 6
5 2
5 4
BLOOD
2
5
```

输出：

```
0
```

## 解法

一个受害者就足以排除这些人：受害者本人、受害者的任何祖先（那样受害者就是狼人的
后代）和受害者的任何后代（那样受害者就是它的祖先）。其余所有人都与每次袭击相容。

所以从所有受害者同时出发沿父母关系向上走，标记所有到达的人，再用同样的方式沿子女
关系向下走；没有被标记的就是嫌疑人。每次遍历有独立的 `seen` 数组，每个人沿关系
至多入栈一次。栈中初始的受害者项可能使其关系被再次扫描，但总工作量仍为
`O(N + 关系数)`。

注意事项：

- 受害者也可能是另一名受害者的祖先或后代，因此其初始栈项可能被再次处理（测试 02）；
- 既不是祖先也不是后代的亲戚，比如堂表兄弟姐妹或兄弟姐妹，仍然是嫌疑人（测试 05）；
- 受害者名单可能为空，此时所有人都是嫌疑人；
- 一条 1000 代的长链需要显式栈，而不是深递归。
