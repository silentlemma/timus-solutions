# 1812. Остров Невезения 2

[Timus 1812](https://acm.timus.ru/problem.aspx?space=1&num=1812) · сложность 2729 · math

Оригинальная задача — Tavrida NU Akai Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Две окружности радиусов r₁ и r₂ касаются прямой и друг друга. В каждом
из n раундов между каждыми двумя соседними окружностями вписывается
окружность, касающаяся прямой и обеих. Окружности нумеруются вдоль
прямой, начиная с окружности r₁. Вывести радиус i-й окружности
несократимой дробью или "Irrational".

## Входные данные

r₁, r₂, n и i (1 ≤ r₁, r₂ ≤ 1000, 0 ≤ n ≤ 30, 1 ≤ i ≤ 2ⁿ + 1).

## Выходные данные

Радиус в виде p/q или "Irrational".

## Примеры

### Пример 1

Ввод:

```
1 1 1 2
```

Вывод:

```
1/4
```

### Пример 2

Ввод:

```
3 5 2 4
```

Вывод:

```
Irrational
```

## Решение

Две окружности радиусов r и s, касающиеся прямой и друг друга, отстоят
вдоль неё на 2√(rs), а вписанная между ними окружность имеет
1/√t = 1/√r + 1/√s. Поэтому у каждой окружности
1/√r = a/√r₁ + b/√r₂, где пары (a, b) ведут себя как
диатомическая последовательность Штерна: у концов (1, 0) и (0, 1), а
новая окружность получает сумму пар соседей. Пара в позиции x после n
раундов берётся с более грубого уровня: чётный x — старая окружность,
нечётный — сумма двух соседних. Записывая значение как α·f(x) +
β·f(x + 1) и деля x пополам n раз, получаем (a, b) за n шагов.

Крайние окружности сохраняют r₁ и r₂. У внутренней окружности a и b
положительны, и 1/r = a²/r₁ + b²/r₂ + 2ab/√(r₁r₂) рационально ровно
тогда, когда r₁r₂ — полный квадрат. При g = gcd(r₁, r₂) это значит
r₁ = g·p² и r₂ = g·q², и тогда r = g·p²·q² / (a·q + b·p)². `O(n)`.

В первом примере средняя окружность между двумя единичными имеет
1/√r = 2, так что r = 1/4. Во втором 3·5 = 15 — не квадрат.

Подводные камни:

- крайние окружности рациональны, даже если r₁r₂ не квадрат;
- a и b растут как числа Фибоначчи, поэтому (a·q + b·p)² требует 64
  бит;
- дробь нужно сократить.

Ответы совпадают с независимой принятой реализацией на 430 входах,
среди них все окружности после не более чем 3 раундов и позиции в
глубине 30 раундов.
