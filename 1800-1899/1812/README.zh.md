# 1812. 厄运之岛 2

[Timus 1812](https://acm.timus.ru/problem.aspx?space=1&num=1812) · 难度 2711 · math

原题出自 Tavrida NU Akai Contest，2010 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

半径为 r₁ 和 r₂ 的两个圆都与一条直线相切，并且彼此相切。在 n 轮中的每一轮，在每两个相邻的圆之间内切一个同时与直线和这两个圆相切的圆。
沿直线从 r₁ 圆开始给所有圆编号。输出第 i 个圆的半径（最简分数），或者 "Irrational"。

## 输入

r₁、r₂、n 和 i（1 ≤ r₁, r₂ ≤ 1000，0 ≤ n ≤ 30，1 ≤ i ≤ 2ⁿ + 1）。

## 输出

形如 p/q 的半径，或者 "Irrational"。

## 样例

### 样例 1

输入：

```
1 1 1 2
```

输出：

```
1/4
```

### 样例 2

输入：

```
3 5 2 4
```

输出：

```
Irrational
```

## 解法

与直线相切且彼此相切的半径为 r 和 s 的两个圆，沿直线相距 2√(rs)，它们之间内切的圆满足 1/√t = 1/√r + 1/√s。所以每个圆都有 1/√r = a/√r₁ + b/√r₂，
其中二元组 (a, b) 的行为与 Stern 双原子序列相同：两端为 (1, 0) 和 (0, 1)，新圆得到其两个邻居之和。n 轮后位置 x 的二元组来自上一层：
偶数 x 是原来的圆，奇数 x 是两边圆之和。把值写成 α·f(x) + β·f(x + 1)，并把 x 折半 n 次，就在 n 步内得到 (a, b)。

两端的圆保持 r₁ 和 r₂。内部圆的 a 和 b 都为正，1/r = a²/r₁ + b²/r₂ + 2ab/√(r₁r₂) 为有理数当且仅当 r₁r₂ 是完全平方数。
令 g = gcd(r₁, r₂)，这意味着 r₁ = g·p²、r₂ = g·q²，此时 r = g·p²·q² / (a·q + b·p)²。`O(n)`。

第一个样例中两个单位圆之间的中间圆满足 1/√r = 2，所以 r = 1/4。第二个样例中 3·5 = 15 不是平方数。

注意事项：

- 即使 r₁r₂ 不是平方数，两端的圆也是有理的；
- a 和 b 像斐波那契数一样增长，所以 (a·q + b·p)² 需要 64 位；
- 分数必须约分。

在 430 个输入上（其中包括至多 3 轮后的每一个圆以及 30 轮深处的位置），答案与一个独立的已通过实现一致。
