# 1883. День рождения энта

[Timus 1883](https://acm.timus.ru/problem.aspx?space=1&num=1883) · сложность 1216 · geometry

Автор оригинальной задачи — Денис Мухаметьянов; Уральская региональная командная олимпиада по программированию 2011.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Торт — квадрат от (−10⁹, −10⁹) до (10⁹, 10⁹), на нём n свечек в
различных целых точках строго внутри. Вырежьте выпуклый многоугольник
ненулевой площади, содержащий ровно k свечек, считая лежащие на
границе. Вершины — целые точки торта, перечисленные против часовой
стрелки, без развёрнутых углов и сторон нулевой длины.

## Входные данные

n и k (1 ≤ k < n ≤ 1000), затем n свечек; все координаты по модулю
меньше 10⁹.

## Выходные данные

Число вершин m (3 ≤ m ≤ 10 000) и сами вершины. Подходит любой верный
многоугольник.

## Примеры

### Пример 1

Ввод:

```
5 3
1 0
1 2
2 1
3 0
3 2
```

Вывод:

```
3
1 0
2 1
1 2
```

## Решение

Отсортируем свечки по x, а затем по y, и пусть (x, y) — k-я из них.
Первые k свечек — это все свечки с меньшим x вместе с теми, что стоят в
столбце x не выше y. Возьмём всё до столбца x − 1, столбец x до (x, y) и
полосу между столбцами x − 1 и x под прямой из (x, y) в (x − 1, 10⁹):

(−10⁹, −10⁹), (x, −10⁹), (x, y), (x − 1, 10⁹), (−10⁹, 10⁹).

Все повороты строго левые. Столбец x − 1 лежит внутри целиком, ведь
свечки ниже 10⁹, а свечки выше (x, y) в столбце x оказываются за
наклонной стороной. Если x − 1 = −10⁹, четвёртая вершина совпала бы с
пятой, поэтому её убираем и остаётся четырёхугольник. Сортировка — за
`O(n log n)`.

В примере третья свечка в этом порядке — (2, 1), и пятиугольник
(−10⁹, −10⁹), (2, −10⁹), (2, 1), (1, 10⁹), (−10⁹, 10⁹) содержит
(1, 0), (1, 2) и (2, 1) — другой, но верный ответ.

Подводные камни:

- простой вертикальный разрез не годится, когда несколько свечек стоят
  в одном столбце; наклонная верхняя сторона делит этот столбец на k-й
  свечке;
- свечки на границе считаются, так что k-я свечка может стоять в
  вершине;
- при x − 1 = −10⁹ вершина (x − 1, 10⁹) совпадает с углом, и её нужно
  выбросить, чтобы не было стороны нулевой длины.

Куски проходят чекер строгой выпуклости, ориентации, диапазона
координат и числа свечек на 40 малых полях и на 125 случайных
больших тортах, многие из которых с плотными столбцами.
