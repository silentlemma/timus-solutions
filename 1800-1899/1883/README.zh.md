# 1883. 树人的生日

[Timus 1883](https://acm.timus.ru/problem.aspx?space=1&num=1883) · 难度 1216 · geometry

原题作者 Denis Mukhametianov，出自 2011 年乌拉尔地区团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

蛋糕是从 (−10⁹, −10⁹) 到 (10⁹, 10⁹) 的正方形，n 支蜡烛位于严格在内部的互不相同的整点上。切下一个面积非零的凸多边形，恰好包含 k 支蜡烛（边界上的也算）。顶点必须是蛋糕上的整点，按逆时针顺序给出，不能有平角，也不能有长度为零的边。

## 输入

n 和 k（1 ≤ k < n ≤ 1000），然后是 n 支蜡烛；所有坐标的绝对值都小于 10⁹。

## 输出

顶点数 m（3 ≤ m ≤ 10 000）和各顶点。任何合法的多边形都可以。

## 样例

### 样例 1

输入：

```
5 3
1 0
1 2
2 1
3 0
3 2
```

输出：

```
3
1 0
2 1
1 2
```

## 解法

把蜡烛按 x、再按 y 排序，设 (x, y) 是第 k 支。前 k 支蜡烛就是 x 更小的全部蜡烛，加上第 x 列中不高于 y 的那些。取到第 x − 1 列为止的全部、第 x 列直到 (x, y) 的部分，以及第 x − 1 列与第 x 列之间、位于从 (x, y) 到 (x − 1, 10⁹) 的直线下方的带状区域：

(−10⁹, −10⁹), (x, −10⁹), (x, y), (x − 1, 10⁹), (−10⁹, 10⁹)。

每个转角都是严格左转。第 x − 1 列整列在内部，因为蜡烛都低于 10⁹；而第 x 列中高于 (x, y) 的蜡烛在斜边之外。若 x − 1 = −10⁹，第四个顶点会与第五个重合，所以去掉它，剩下一个四边形。排序需要 `O(n log n)`。

样例中按此顺序的第三支蜡烛是 (2, 1)，五边形 (−10⁹, −10⁹), (2, −10⁹), (2, 1), (1, 10⁹), (−10⁹, 10⁹) 包含 (1, 0)、(1, 2) 和 (2, 1)，这是另一个合法答案。

注意事项：

- 多支蜡烛在同一列时简单的竖直切割行不通；倾斜的上边在第 k 支蜡烛处把这一列分开；
- 边界上的蜡烛也算，所以第 k 支蜡烛可以正好在顶点上；
- 当 x − 1 = −10⁹ 时顶点 (x − 1, 10⁹) 与角点重合，必须去掉以免出现零长度的边。

在 40 个小规模情形和 125 个随机大蛋糕（其中许多列很拥挤）上，切块都通过了对严格凸性、方向、坐标范围和蜡烛数的检查器。
