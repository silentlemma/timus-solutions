# 1835. Болотный доктор

[Timus 1835](https://acm.timus.ru/problem.aspx?space=1&num=1835) · сложность 3124 · strings

## Задача

Адрес — это имя пользователя и домен, соединённые «@»; каждая часть —
непустая строка из строчных латинских букв и точек, не начинающаяся и
не заканчивающаяся точкой и без двух точек подряд. Посчитать различные
адреса, встречающиеся в тексте как подстроки.

## Входные данные

Текст — не больше 10⁶ байт из символов с кодами от 32 до 126 и
переводов строк.

## Выходные данные

Число различных адресов в тексте.

## Примеры

### Пример 1

Ввод:

```
a.b@c.d
b@c.de.
@qq
q@.q
```

Вывод:

```
5
```

## Решение

Является ли строка адресом, зависит только от самой строки, а не от
места, где она встречается. Поэтому работает классический подсчёт
различных подстрок с фильтром: строим суффиксный массив и LCP каждого
суффикса с предыдущим в отсортированном порядке. Префикс суффикса
встречается раньше в этом порядке ровно тогда, когда он не длиннее
этого LCP, так что каждый различный адрес считается один раз, у
первого начинающегося с него суффикса, если считать только префиксы-
адреса длиннее LCP.

Для суффикса, начинающегося с буквы, его префиксы-адреса определяются
первым «@» после него в том же отрезке из букв и точек. Имя
пользователя не может заходить левее последнего «..», у «@» с обеих
сторон должны быть буквы, а домен заканчивается буквой до следующего
«..», «@» или другого символа. Всё это заранее посчитано для каждого
«@», так что каждый суффикс добавляет число букв в отрезке — по
префиксным суммам.

Суффиксный массив строится циклическим удвоением с сортировкой
подсчётом по алфавиту из 30 символов, где все прочие символы имеют
один код; LCP — алгоритмом Касаи. `O(n log n)`.

В примере адреса — a.b@c, a.b@c.d, b@c, b@c.d и b@c.de; b@c и b@c.d
встречаются дважды, но считаются один раз.

Подводные камни:

- один адрес может встретиться много раз, так что подсчёт вхождений
  завышает ответ;
- «a..b@c» всё ещё содержит адрес b@c, но не a..b@c и не .b@c;
- один «@» между двумя отрезками из 5·10⁵ букв даёт около 2.5·10¹¹
  адресов, нужны 64-битные числа;
- CPython слишком медленный для суффиксного массива из 10⁶ символов;
  решение на Python работает на PyPy и хранит массивы компактно.

Ответы совпадают с проверкой всех подстрок для сотен коротких случайных
текстов и с независимой принятой реализацией на текстах в мегабайт.
