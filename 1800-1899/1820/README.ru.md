# 1820. Уральские бифштексы

[Timus 1820](https://acm.timus.ru/problem.aspx?space=1&num=1820) · сложность 25 · math

Автор оригинальной задачи — Магаз Асанов; XII открытое личное первенство УрГУ, 19 марта 2011 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Повар должен прожарить обе стороны n бифштексов, по минуте на сторону,
на сковороде, где помещается не больше k бифштексов одновременно. Найти
наименьшее число минут.

## Входные данные

n и k (1 ≤ n, k ≤ 1000).

## Выходные данные

Наименьшее число минут.

## Примеры

### Пример 1

Ввод:

```
3 2
```

Вывод:

```
3
```

## Решение

Сторон 2n, и за минуту жарится не больше k из них, так что нужно хотя
бы ⌈2n/k⌉ минут; а две стороны одного бифштекса нельзя жарить в одну
минуту, так что нужно хотя бы 2. Ответ — max(2, ⌈2n/k⌉), и он
достижим: выпишем стороны как лицо 1, …, лицо n, оборот 1, …, оборот n
и каждую минуту жарим следующие k из них. При n ≥ k две стороны
бифштекса стоят в списке на расстоянии n и никогда не попадают в одну
минуту; при n < k обе стороны и так укладываются в две минуты. `O(1)`.

В примере: лица 1 и 2, затем оборот 1 с лицом 3, затем обороты 2 и 3 —
три минуты.

Подводные камни:

- жарить целые партии по k бифштексов по две минуты — значит терять
  место на сковороде: 3 бифштекса на сковороде на 2 жарятся 3 минуты,
  а не 4;
- при k ≥ 2n оценка ⌈2n/k⌉ равна 1, но бифштексу всё равно нужны две
  минуты.
