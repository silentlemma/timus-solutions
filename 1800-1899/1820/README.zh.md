# 1820. 乌拉尔牛排

[Timus 1820](https://acm.timus.ru/problem.aspx?space=1&num=1820) · 难度 25 · math

原题作者 Magaz Asanov，出自 2011 年 3 月 19 日第十二届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

厨师要把 n 块牛排的两面都煎好，每面一分钟，平底锅一次最多放 k 块牛排。求最少需要多少分钟。

## 输入

n 和 k（1 ≤ n, k ≤ 1000）。

## 输出

最少的分钟数。

## 样例

### 样例 1

输入：

```
3 2
```

输出：

```
3
```

## 解法

共有 2n 面，每分钟最多煎 k 面，所以至少需要 ⌈2n/k⌉ 分钟；同一块牛排的两面不能在同一分钟煎，所以至少需要 2 分钟。
答案是 max(2, ⌈2n/k⌉)，并且可以达到：把各面列成正面 1, …, 正面 n, 反面 1, …, 反面 n，每分钟煎接下来的 k 面。
当 n ≥ k 时，同一块牛排的两面在列表中相距 n，永远不会落在同一分钟；当 n < k 时，两面本来就能在两分钟内煎完。`O(1)`。

在样例中：先煎正面 1 和 2，再煎反面 1 和正面 3，最后煎反面 2 和 3：共三分钟。

注意事项：

- 每次整批煎 k 块、每批两分钟会浪费锅的空间：容量为 2 的锅煎 3 块牛排需要 3 分钟，而不是 4 分钟；
- 当 k ≥ 2n 时 ⌈2n/k⌉ 等于 1，但一块牛排仍然需要两分钟。
