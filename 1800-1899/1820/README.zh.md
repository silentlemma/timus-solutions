# 1820. 乌拉尔牛排

[Timus 1820](https://acm.timus.ru/problem.aspx?space=1&num=1820) · 难度 25 · math

原题作者 Magaz Asanov，出自 2011 年 3 月 19 日第十二届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

厨师要把 n 块牛排的两面都煎好，每面一分钟，平底锅一次最多放 k 块牛排。求最少需要多少分钟。

## 输入

n 和 k（1 ≤ n, k ≤ 1000）。

## 输出

最少的分钟数。

## 评测方式

仓库测试精确比较输出记号，记号之间的空白分隔不影响结果。

## 样例

### 样例 1

输入：

```
3 2
```

输出：

```
3
```

## 解法

共有 2n 面，每分钟最多煎 k 面，所以至少需要 ⌈2n/k⌉ 分钟；同一块牛排的两面不能在同一分钟煎，所以至少需要 2 分钟。
答案是 max(2, ⌈2n/k⌉)，并且可以达到：把各面列成正面 1, …, 正面 n, 反面 1, …, 反面 n，每分钟煎接下来的 k 面。
当 n ≥ k 时，同一块牛排的两面在列表中相距 n，永远不会落在同一分钟；当 n < k 时，两面本来就能在两分钟内煎完。`O(1)`。

在样例中：先煎正面 1 和 2，再煎反面 1 和正面 3，最后煎反面 2 和 3：共三分钟。

注意事项：

- 每次整批煎 k 块、每批两分钟会浪费锅的空间：容量为 2 的锅煎 3 块牛排需要 3 分钟，而不是 4 分钟；
- 当 k ≥ 2n 时 ⌈2n/k⌉ 等于 1，但一块牛排仍然需要两分钟。

## 优化解法

优化的 Java 解法直接从 `System.in` 逐字节解析数字，而不是使用 `Scanner`：
348 KB，而不是 1608 KB，时间不变。

`1820_math_optimized.cpp`. 保留 max(2,ceil(2N/K))：一块牛排需要两个不同分钟，每分钟最多处理 2N 个面中的 K 个。显式 C 字节转换替代整数格式化读写，以有符号 64 位中间值精确向上取整。时间和额外状态保持 O(1)。

与 `1820_math.cpp` 相比：时间 0.031 s → 0.015 s；内存 124 KB → 72 KB。

`1820_math_optimized.go`. 保留相同的煎制下界及构造。可移植 os.File 字节流和有界输入输出缓冲区替代 fmt，以 int64 精确向上取整。只保留两个输入和答案，因此算法时间 O(1)，额外存储固定。

与 `1820_math.go` 相比：时间 0.046 s → 0.031 s；内存 1076 KB → 808 KB。

`1820_math_optimized.py`. 对原始字节记号使用相同的精确煎制公式，避免完整输入解码字符串和 main 函数封装。显式刷新打印结果后结束进程，跳过解释器正常清理。在题目整数范围内，时间及额外存储均为 O(1)。

与 `1820_math.py` 相比：时间 0.093 s → 0.125 s；内存 348 KB → 216 KB。
