## Задача

В справке есть страницы 1, …, n. F1 открывает или закрывает страницу 1.
На каждой странице, кроме последней, есть кнопки, открывающие или
закрывающие следующую страницу, но видна и доступна только наименее
подробная открытая страница — с наименьшим номером. Найти наименьшее
число нажатий, превращающее один набор открытых страниц в другой.

## Входные данные

n (1 ≤ n ≤ 50), затем начальный и требуемый наборы в виде строк из n
нулей и единиц; i-й символ говорит, открыта ли страница i.

## Выходные данные

Наименьшее число нажатий.

## Примеры

### Пример 1

Ввод:

```
3
111
000
```

Вывод:

```
5
```

## Решение

Это головоломка «китайские кольца». В любом состоянии есть не больше
двух ходов: переключить страницу 1 или переключить страницу сразу за
первой открытой. Будем читать страницу i как бит i − 1 двоичного
слова. Тогда это в точности два вида шагов отражённого кода Грея,
который через шаг переключает бит 0, а иначе — бит сразу над младшим
единичным. Значит, все 2ⁿ состояний лежат на одном пути в порядке кода
Грея, и место состояния на нём — его слово, декодированное из кода
Грея: xor слова со всеми его сдвигами вправо. Ответ — модуль разности двух
мест. `O(n)`.

В примере 111 — это слово 7, его место 7 xor 3 xor 1 = 5, а 000 стоит
на месте 0: пять нажатий.

Подводные камни:

- первый символ — страница 1, младший бит, так что строка читается с
  конца;
- ответ доходит до 2⁵⁰ − 1, нужны 64-битные числа;
- поиск в ширину по 2⁵⁰ состояниям безнадёжен.

Ответы совпадают с поиском в ширину при n до 9 и с независимой
принятой реализацией на случайных парах до 50 страниц.
