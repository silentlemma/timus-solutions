# 1890. 凭空而来的薪资

[Timus 1890](https://acm.timus.ru/problem.aspx?space=1&num=1890) · 难度 464 · fenwick

原题作者 Dmitry Ivankov，出自 NEERC 2011 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定一棵包含 n 名员工的有根树，顶点编号为 0 到 n − 1，根为 0。
每个顶点有一个非负整数工资。按输入顺序执行 q 次条件更新：

- `employee x y z`：若顶点 x 当前的工资严格小于 y，则将其增加 z；
- `department x y z`：若 x 的子树中当前的平均工资严格小于 y，则将
  这棵子树中每个顶点的工资增加 z，包括 x 本身。

求所有最终工资。树的结构保持不变。时间限制为 1 秒，内存限制为 64 MB。

## 输入

第一行包含 n、q 和根的初始工资 s₀，其中 1 ≤ n, q ≤ 50 000，
0 ≤ s₀ ≤ 10⁹。

接下来对 i = 1 到 n − 1，每行给出其父顶点 pᵢ 和初始工资 sᵢ，
满足 0 ≤ pᵢ < i，0 ≤ sᵢ ≤ 10⁹。

随后 q 行按上述格式给出更新，其中 0 ≤ x < n，1 ≤ y, z ≤ 10⁹。

## 输出

按顶点编号递增的顺序输出 n 个最终工资，每行一个。

## 评测方式

输出按整数记号逐一比较。

## 样例

### 样例 1

输入：

```
4 3 1
0 10
0 10
1 10
employee 2 15 1
employee 3 5 1
department 0 10 1
```

输出：

```
2
11
12
11
```

## 解法

按前序遍历排列树。设 tin[x] 为 x 的访问位置，size[x] 为其子树大小。
该子树恰好占据区间 [tin[x], tin[x] + size[x])。

父顶点的编号总比子顶点小，因此可以按编号递减的顺序将子树大小累加
到父顶点。随后按编号递增的顺序处理顶点。每个父顶点为子顶点 x 保留
一个长度为 size[x] 的连续区间，放在自身位置及此前子顶点的区间之后。
这样无需递归即可在 `O(n)` 时间内得到前序位置。

按此顺序维护工资，使用两棵树状数组实现区间加和区间求和。具体地，
设 dᵢ 为相邻工资的差分，下标从 1 开始，d₁ 等于第一项工资。
第一棵树维护 dᵢ，第二棵树
维护 (i − 1)dᵢ。如果它们到 k 的前缀和分别为 B₁(k) 和 B₂(k)，那么
前 k 项工资之和为 k·B₁(k) − B₂(k)。区间加 z 只改变两个边界差分，
因此每棵树只需进行两次单点修改。区间和由两个前缀和相减得到。

对 `employee` 查询 x 对应的单点区间；对 `department` 查询整棵子树，
设结果为 S。平均值条件可以精确写成 S < y·size[x]，无需除法或浮点数。
相应的严格不等式成立时，在同一区间加 z，否则不修改。

前序区间恰好选中操作指定的员工。树状数组公式给出此前所有更新后的
当前工资之和，因此条件判断和增加操作都符合要求。最后逆转第一棵
树状数组的构建过程：按下标递减的顺序，将每个元素从其树状数组父结点
中减去。此时各项就是当前差分 dᵢ，再求前缀和即可在线性时间内还原
所有工资。按原顶点编号输出结果。

每次查询或增加需要 `O(log n)` 时间。初始化时按下标递增的顺序将每项
累加到其树状数组父结点，线性构建两棵树。初始化和最终还原均为线性，
所以总时间为 `O(n + q log n)`，树状数组占用 `O(n)` 空间。

样例中，员工 2 的工资从 10 变成 11。员工 3 的工资保持 10，因为
10 不小于 5。此时整棵树的工资总和为 32，平均值为 8，小于 10，
所以最后一次操作给所有工资加 1，按编号得到 2、11、12、11。

注意事项：

- 等于阈值时不更新；
- 子树包含根顶点及所有后代；
- 一棵子树的原始顶点编号不一定连续；
- 工资、总和、加权差分及 y·size[x] 等乘积需要有符号 64 位整数；
  Python 整数可以直接处理；
- 按顶点编号输出，而不是按遍历顺序输出。

64 位整数，树的下标仍可使用普通整数。
