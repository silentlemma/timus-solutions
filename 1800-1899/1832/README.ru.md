# 1832. Шоу «Ариран»

[Timus 1832](https://acm.timus.ru/problem.aspx?space=1&num=1832) · сложность 955 · constructive

Автор оригинальной задачи — Виктор Камашев (подготовка — Даниил Айзенштейн); XV открытый чемпионат Урала по спортивному программированию, апрель 2011 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n артистов в шеренге разбиваются на d хороводов, где d — неизвестный
собственный делитель n: j-й хоровод образуют по кругу артисты j, j + d,
j + 2d, … Выбрать цвета рубах из 26 так, чтобы соседи в каждом
хороводе различались при любом d, или сообщить, что это невозможно.

## Входные данные

n (2 ≤ n ≤ 300000).

## Выходные данные

n строчных латинских букв — цвета артистов — или «Impossible».
Подходит любая правильная раскраска.

## Примеры

### Пример 1

Ввод:

```
7
```

Вывод:

```
acacbdb
```

## Решение

Нумеруем артистов с 0. Два артиста соседи при каком-то d ровно тогда,
когда между ними d или n − d, где d — собственный делитель n.

Пусть m — наименьшее число, не делящее n. Тогда m не делит и ни один
собственный делитель, так что раскраска по x mod m различает любых двух
артистов на расстоянии d. Поскольку НОК(1, …, 13) = 360360 больше
300000, m не больше 13.

Остаются пары через стык круга, на расстоянии n − d. Пусть p —
наименьший простой делитель n; каждый собственный делитель не больше
n/p, так что эти расстояния не меньше n − n/p. Разобьём шеренгу на
первые n − n/p артистов и последние n/p: внутри каждой части
расстояний такой длины нет, так как n/p ≤ n − n/p. Красим обе части по
x mod m, вторую — своими m буквами. Тогда пары внутри части в порядке,
а пары из разных частей никогда не совпадают по цвету. Используется не
больше 2m ≤ 26 букв, так что ответ никогда не «Impossible». `O(n)`.

При n = 7 m = 2 и p = 7: первые шесть артистов чередуют a и b, а
последний получает c, выходит abababc; ответ из примера — другая
правильная раскраска.

Подводные камни:

- хороводы замкнуты, поэтому артисты на расстоянии n − d тоже соседи;
- при d = n/2 в хороводе только два артиста, и это тоже соседняя пара;
- одной раскраски по x mod m мало из-за стыка: при n = 7 она даёт
  артистам 0 и 6 один цвет.

Все n от 2 до 3000 и многие большие, включая те, где нужны все 26
букв, проверены против каждого собственного делителя.
