# 1850. Космический туризм

[Timus 1850](https://acm.timus.ru/problem.aspx?space=1&num=1850) · сложность 2662 · fenwick

Автор оригинальной задачи — Дмитрий Иванков; Ural SU Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n планет лежат на одном луче из звезды, каждая на своём расстоянии и
каждая населена некоторой расой. Корабль туриста пролетает без
дозаправки не больше d, может заправиться на любой планете и работает
только на расстояниях от звезды в пределах диапазона туриста
[low, high]; туриста доставляют на любую планету этого диапазона. Для
каждого туриста найти наибольшее число различных рас, с которыми он
может встретиться.

## Входные данные

n, s и d (1 ≤ n, s, d ≤ 10⁵), затем n планет — расстояние (различные,
не больше 10⁶) и раса (от 1 до s); затем m (1 ≤ m ≤ 10⁵) и диапазоны
туристов с границами до 10⁶.

## Выходные данные

Ответ для каждого туриста, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
5 5 11
10 1
50 2
30 1
20 1
60 3
2
5 65
15 45
```

Вывод:

```
2
1
```

## Решение

Отсортируем планеты по расстоянию. Внутри диапазона турист может
перейти от планеты к следующей ровно тогда, когда между ними не больше
d, так что планеты диапазона распадаются на серии, и ответ — наибольшее
число рас в одной серии. Серии — это глобальные куски планет,
разрезанные в промежутках больше d и обрезанные диапазоном: диапазон,
задевающий куски P₁ … Pₖ, состоит из хвоста P₁, целых кусков
P₂ … Pₖ₋₁ и головы Pₖ.

Поэтому заранее посчитаем внутри каждого куска число рас от его начала
до каждой планеты (голова) и от каждой планеты до его конца (хвост), а
также число рас каждого целого куска, с разреженной таблицей для
наибольшего по диапазону кусков. Диапазон через несколько кусков
отвечается двумя обращениями и одним запросом к таблице.

Диапазону внутри одного куска нужно число различных рас среди подряд
идущих планет. Ответим на такие запросы офлайн, отсортировав их по
правому концу: идя вправо, держим дерево Фенвика, где каждая раса
учтена только в своей последней на данный момент планете; тогда расы в
[l, r] — это сумма по позициям l … r. `O((n + m) log n)`.

В примере планеты 10, 20 и 30 образуют один кусок расы 1, а планеты 50
и 60 — другой, рас 2 и 3, поскольку 50 − 30 > 11. Первый турист видит
оба куска и встречает в лучшем случае две расы; второй видит только 20
и 30.

Подводные камни:

- корабль не может покинуть диапазон даже ради другой планеты в нём;
- в диапазоне может не оказаться ни одной планеты;
- одна раса может жить на нескольких планетах одного куска.

Ответы совпадают с прямым подсчётом на трёхстах маленьких случаях и с
независимой принятой реализацией на больших тестах. Решение на Python
работает на PyPy.
