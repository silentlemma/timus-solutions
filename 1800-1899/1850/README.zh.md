# 1850. 太空旅游

[Timus 1850](https://acm.timus.ru/problem.aspx?space=1&num=1850) · 难度 2662 · fenwick

原题作者 Dmitry Ivankov，出自 2010 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 颗行星位于从恒星出发的同一条射线上，各自有不同的距离，每颗上住着某个种族。游客的飞船不加油最多飞 d，可以在任何行星加油，并且只能在距恒星的距离位于游客范围 [low, high] 内时工作；游客会被送到该范围内的任意一颗行星。
对每位游客，求他最多能接触到多少个不同的种族。

## 输入

n、s、d（1 ≤ n, s, d ≤ 10⁵），然后是 n 颗行星的距离（互不相同，不超过 10⁶）和种族（1 到 s）；然后是 m（1 ≤ m ≤ 10⁵）和各游客的范围，边界不超过 10⁶。

## 输出

每位游客的答案，每行一个。

## 样例

### 样例 1

输入：

```
5 5 11
10 1
50 2
30 1
20 1
60 3
2
5 65
15 45
```

输出：

```
2
1
```

## 解法

按距离对行星排序。在范围内，游客能从一颗行星到下一颗，当且仅当二者相距不超过 d，所以范围内的行星分成若干段，答案是一段中种族数的最大值。
这些段就是全局按大于 d 的间隔切开的行星块再被范围截取的结果：覆盖块 P₁ … Pₖ 的范围由 P₁ 的尾部、完整的块 P₂ … Pₖ₋₁ 和 Pₖ 的头部组成。

因此预先在每个块内计算从块起点到每颗行星的种族数（头部）、从每颗行星到块终点的种族数（尾部），以及每个完整块的种族数，并用稀疏表求一段块中的最大值。跨越多个块的范围只需两次查表和一次稀疏表查询。

位于单个块内的范围需要求一段连续行星中不同种族的数目。把这些询问按右端点排序离线处理：向右扫描时维护一棵树状数组，每个种族只在它目前最后出现的行星处计数；那么 [l, r] 中的种族数就是位置 l … r 上的计数之和。`O((n + m) log n)`。

在样例中，行星 10、20、30 组成一个种族 1 的块，行星 50 和 60 组成另一个块，种族为 2 和 3，因为 50 − 30 > 11。第一位游客看到两个块，最多接触两个种族；第二位只看到 20 和 30。

注意事项：

- 飞船不能离开范围，即使是为了到达范围内的另一颗行星；
- 范围内可能一颗行星也没有；
- 同一种族可能出现在同一块的多颗行星上。

在三百个小数据上答案与直接计数一致，在大测试上与一个独立的已通过实现一致。Python 版本在 PyPy 上运行。
