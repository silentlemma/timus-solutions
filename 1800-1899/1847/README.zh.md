# 1847. 环外之地

[Timus 1847](https://acm.timus.ru/problem.aspx?space=1&num=1847) · 难度 3793 · dp

原题作者 Alexander Ipatov，出自 2010 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

平面上的 n 座城市由总长最小的 n − 1 条直路连接。国王从城市 1 出发做深度优先的旅行：从当前城市沿任意一条路前往还没见过的城市，若没有这样的路，就沿最初来时的路返回；每座新城市都记入他的日记。
他的儿子在城市之间直线飞行，按日记的顺序访问它们，然后回到城市 1。国王选路的顺序未知：求最短可能的飞行距离。

## 输入

n（2 ≤ n ≤ 1000），n 座城市的坐标（绝对值不超过 10 000 的整数，所有点互不相同），一个空行，然后是 n − 1 条路，每条以两座城市给出。

## 输出

最短的飞行距离，相对误差不超过 10⁻⁹。

## 样例

### 样例 1

输入：

```
4
0 0
1 0
1 1
0 1

1 2
1 4
4 3
```

输出：

```
4.000
```

## 解法

日记是以城市 1 为根的树的先序遍历，每座城市的孩子可以按任意顺序访问。飞越一棵子树从其根开始；由于每个孩子的子树都在下一个孩子开始前结束，飞行会在它的某片叶子结束。
因此对每座城市 u 及其下方的每片叶子 e，令 cost(u, e) 为飞越 u 的子树并在 e 结束的最短距离。

在 u 内部，孩子按某种顺序飞越。孩子 a 结束后紧接着进入孩子 b 的花费为 link(a, b) = 对 a 的叶子 e 取 cost(a, e) + |e b| 的最小值，它与之前的顺序无关。
于是孩子的顺序是一个子集上的最短路问题：enter(m, b) 表示完成集合 m 中其余孩子后进入 b 的最小花费，初值 enter({b}, b) = |u b|，转移为 enter(m, a) + link(a, b)。
对孩子 b 的叶子 e，有 cost(u, e) = enter(全部, b) + cost(b, e)；答案是 cost(1, e) + |e 1| 的最小值。

道路构成平面点集的最小生成树，同一城市出发的两条边夹角至少 60°，所以每座城市最多有六个邻居，子集步骤每座城市最多花费 2⁶·6²。
计算 link 时，城市下方的每片叶子最多被看六次，而一片叶子最多位于 n 座城市之下，所以这部分是 `O(n²)`。按广度优先顺序的逆序处理城市，先孩子后父亲，以避免深递归。

在样例中，树为 1 – 2 和 1 – 4 – 3。先访问 2 得到 1、2、4、3，飞行 1 + √2 + 1 + √2；先访问 4 得到 1、4、3、2，四段单位长度，共 4。

注意事项：

- 飞越子树总是从它的根开始，这正是 link(a, b) 与其余顺序无关的原因；
- 度数上界来自树的最小性；对任意的树，子集步骤会是指数级的。

在六十组最多 1000 座城市的随机数据上，答案与一个独立的已通过实现一致，其中包括有许多等长道路的网格、长脊柱和嵌套的五臂星形。
