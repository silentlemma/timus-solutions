# 1847. Замкадье

[Timus 1847](https://acm.timus.ru/problem.aspx?space=1&num=1847) · сложность 3831 · dp

Автор оригинальной задачи — Александр Ипатов; Ural SU Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n городов на плоскости соединены n − 1 прямыми дорогами наименьшей
суммарной длины. Король выехал из города 1 и путешествовал в глубину:
из текущего города ехал по любой дороге в ещё не виденный город, а если
такой не было — возвращался туда, откуда впервые приехал; каждый новый
город попадал в его дневник. Его сын летает между городами напрямик и
посещает их в порядке дневника, после чего возвращается в город 1.
Порядок, в котором король выбирал дороги, неизвестен: найти кратчайший
возможный перелёт.

## Входные данные

n (2 ≤ n ≤ 1000), координаты n городов (целые, по модулю не больше
10 000, все точки различны), пустая строка и n − 1 дорога парами
городов.

## Выходные данные

Кратчайший перелёт с относительной погрешностью не более 10⁻⁹.

## Примеры

### Пример 1

Ввод:

```
4
0 0
1 0
1 1
0 1

1 2
1 4
4 3
```

Вывод:

```
4.000
```

## Решение

Дневник — прямой обход дерева с корнем в городе 1, где дети каждого
города берутся в любом порядке. Перелёт по поддереву начинается в его
корне и, поскольку поддерево каждого ребёнка заканчивается до начала
следующего, кончается в одном из его листьев. Поэтому для каждого
города u и каждого листа e под ним пусть cost(u, e) — кратчайший
перелёт по поддереву u, заканчивающийся в e.

Внутри u дети облетаются в некотором порядке. Войти в ребёнка b сразу
после окончания ребёнка a стоит link(a, b) = min по листьям e ребёнка a
от cost(a, e) + |e b|, и это не зависит от того, что было раньше.
Значит, порядок детей — задача о кратчайшем пути по подмножествам:
enter(m, b) — самый дешёвый способ закончить детей из множества m с b
последним, начиная с enter({b}, b) = |u b| и переходя через
enter(m, a) + link(a, b). Тогда cost(u, e) = enter(все, b) + cost(b, e)
для листа e ребёнка b, а ответ — наименьшее cost(1, e) + |e 1|.

Дороги образуют минимальное остовное дерево точек на плоскости, где два
ребра из одного города образуют угол не меньше 60°, так что у города не
больше шести соседей и шаг по подмножествам стоит не больше 2⁶·6² на
город. Подсчёт link просматривает каждый лист под городом не больше
шести раз, а лист лежит не более чем под n городами, так что эта часть
`O(n²)`. Города обрабатываются от детей к родителям, в обратном порядке
обхода в ширину, чтобы избежать глубокой рекурсии.

В примере дерево — 1 – 2 и 1 – 4 – 3. Если сначала посетить 2, порядок
будет 1, 2, 4, 3 и перелёт 1 + √2 + 1 + 1; если сначала 4 — порядок 1,
4, 3, 2 и четыре единичных шага, 4.

Подводные камни:

- перелёт по поддереву всегда начинается в его корне, поэтому
  link(a, b) не зависит от остального порядка;
- ограничение степени следует из минимальности дерева; для
  произвольного дерева шаг по подмножествам был бы экспоненциальным.

Ответы совпадают с независимой принятой реализацией на шестидесяти
случайных наборах до 1000 городов, включая решётки со многими равными
дорогами, длинные хребты и вложенные пятилучевые звёзды.
