# 1894. 不宜飞行的天气

[Timus 1894](https://acm.timus.ru/problem.aspx?space=1&num=1894) · 难度 1405 · geometry

原题作者 Daniil Ayzenshteyn，出自 NEERC 2011 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给出两个非退化严格凸多边形在 60 秒前的位置。多边形 A 静止，B 沿某个
未知但固定的方向以每秒恰好 1 米的速度平移，不发生旋转。在给定时刻，
B 至少覆盖 A 的一个内部点。

在所有可能的固定运动方向中，求从现在起到两个多边形分离的最短等待
时间。如果存在一个方向使它们现在已经分离，答案为 0。
时间限制为 2 秒，内存限制为 64 MB。

## 输入

第一行给出 A 和 B 的顶点数量 n、m，3 ≤ n, m ≤ 50 000。
随后 n 行是 A 的顶点，再后面 m 行是 B 的顶点，均按逆时针顺序给出。
坐标为以米计的整数，绝对值不超过 10⁸。

## 输出

输出最短剩余时间，单位为秒。

## 评测方式

绝对或相对误差不超过 10⁻⁶。

## 样例

### 样例 1

输入：

```
4 4
400 400
600 400
600 600
400 600
0 0
1000 0
1000 1000
0 1000
```

输出：

```
540.0
```

## 解法

令 K = A + (−B)，即所有 a − b 构成的闵可夫斯基差，其中 a 属于 A，
b 属于 B。将 B 平移向量 v 后，两多边形相交当且仅当 v 属于 K。
初始相交条件保证原点严格位于 K 内部。

对固定单位方向 u，经过 t 秒的位移为 t·u。分离对应沿该射线离开 K。
所有方向中最短的退出距离，就是原点到 K 边界的距离 r：每次退出都
必须经过边界，而最近的边界点给出达到该分离阈值的方向。速度为 1，
给定位置又是 60 秒前的，因此答案为 max(0, r − 60)。

线性构造 K。先将 B 的每个顶点取负，这仍保持逆时针顺序。将两个顶点
列表分别循环移位，使 y 最小、同 y 时 x 最小的顶点位于开头。此时两组
边向量已经按极角排列。按角度合并，选取方向较小的边；若两边平行且
同向，则同时加上两个向量。从两个起始顶点的和出发，就得到 K 的
逆时针边界。

对于 K 的相邻顶点 p、q，原点到其边所在直线的距离为
cross(p, q) / hypot(q − p)。由于原点在内部，分子为正。取所有边的
最小值即可。这也是到多边形边界的距离：以原点为圆心、最小直线距离
为半径的圆盘位于所有定义半平面内，因此它与最近直线的切点也属于
对应的边。

合并时可以立即处理每条新边，无需另存整个 K。读取、合并和扫描共需
`O(n + m)` 时间，输入数组使用 `O(n + m)` 空间。

样例中的 K 是正方形 [−600, 600] × [−600, 600]。其边界离原点最近
600 米，所以最短剩余时间为 600 − 60 = 540 秒。

注意事项：

- 减去已过去的 60 秒，并将答案下限设为零；
- 对 B 的坐标取负，但不反转顶点顺序；
- 同方向的边应同时合并；
- 先用有符号 64 位整数精确计算叉积，再进行浮点除法；Python 整数已
  具备足够精度；
- 不要在 64 位整数中对叉积求平方，否则可能溢出；
- 坐标允许为负，应使用有符号运算和 `hypot`。

测试中有一个容易损失精度的细长多边形，也有各含 50 000 个顶点的多边形；另外还在 128 个测试上单独验证了答案。

## 各语言说明

边方向叉积和距离分子的叉积都保持整数运算：C++ 使用 `long long`，
Go 使用 `int64`，Java 使用 `long`，Rust 使用 `i64`；Python 整数具有
任意精度。只在计算斜边长度和最后除法时转换为浮点数，避免近乎平行的
坐标使符号或两个大乘积间的小差值丢失。

各版本输出小数点后十位。Java 显式使用 `Locale.US`，确保小数分隔符为点。
