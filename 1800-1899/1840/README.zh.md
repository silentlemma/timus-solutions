# 1840. 广告的牺牲品

[Timus 1840](https://acm.timus.ru/problem.aspx?space=1&num=1840) · 难度 6905 · geometry

原题作者 Pavel Egorov，出自 2011 年 4 月第十五届乌拉尔竞技编程公开锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一名滑冰运动员要按顺序滑过 n 条有向线段，相邻线段之间用圆弧连接，使路径光滑；若两个相邻线段之间放不下圆弧，可以延长其中一条。
速度不超过 10，沿路径的加速度不超过 1，在半径为 R 的圆弧上速度不超过 √R（向心加速度 v²/R ≤ 1）。从静止出发并在终点停下，求滑完全程的最少时间。

## 输入

n（1 ≤ n ≤ 1000），然后是 n 条线段的起点和终点坐标，都是绝对值不超过 1000 的整数。没有两个相邻线段同向，并且光滑路径总是存在。

## 输出

最少时间，绝对或相对误差不超过 10⁻⁶。

## 样例

### 样例 1

输入：

```
1
0 0 4 0
```

输出：

```
4.0000000000
```

### 样例 2

输入：

```
2
-2 4 0 4
4 0 4 -2
```

输出：

```
7.1415926536
```

## 解法

路径。取两个相邻线段：前一条在 B 处结束，方向为 u；后一条在 A 处开始，方向为 v。若两条直线不平行，它们交于点 X，X 在 B 之后 t 处、在 A 之前 back 处。
与两条直线都相切的圆弧在距 X 相等的地方与它们相切，所以最大（也最快）的圆弧取距离 min(t, back)，余量较大的那条线段延长两者之差。
设转角为 φ、切线距离为 d，则半径为 d·(1 + cos φ)/sin φ，圆弧转过 φ。若 X 在后方，min(t, back) 为负，圆弧要绕远路，转过 2π − φ。
距离为 0 时是一个尖角，即半径为 0 的圆弧，运动员必须在那里停下。方向相反的相邻线段在把其中一条延长对齐之后，用横跨两条直线间距的半圆连接。

滑行。路径现在是一串片段：线段的限速为 10，圆弧的限速为 min(10, √R)。加速和减速都不超过 1 时，两段相接处的速度取两者中较小的：
从起点能达到的速度（向前扫描，v² 每段增加 2·长度，并受每段限速约束），以及到终点前还来得及刹住的速度（同样向后扫描）。
每段最快的滑法是加速、若有余地则以限速巡航、再减速。`O(n)`。

在第二个样例中，直线 y = 4 和 x = 4 的交点在第一条线段之后 4 处、第二条线段之前 4 处，得到半径为 4、限速为 2 的四分之一圆。
运动员在 2 米内加速到 2，以速度 2 滑过长 2π 的圆弧用时 π 秒，在最后 2 米内刹停：2 + π + 2。

注意事项：

- 在很急的圆弧上，限速 √R 可能使速度几乎降到零，因此时间可能非常大；答案仍是若干简短闭式的和；
- 一段的限速同时约束它两端的速度；
- 当下一条线段从转弯的后方开始时，需要绕远路。

在五百条随机路径和大测试上，答案与一个独立的已通过实现一致。
