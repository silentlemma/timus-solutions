# 1871. Сейсмические волны

[Timus 1871](https://acm.timus.ru/problem.aspx?space=1&num=1871) · сложность 623 · dijkstra

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У каждого пользователя Twitter есть список фолловеров, которые видят все
твиты этого пользователя. Фолловер может сделать ретвит: перед сообщением дописывается
строка «RT @nick: », где nick — пользователь, чей твит или ретвит
повторяется. Сообщение длиннее 140 символов не отправляется вовсе.
Первый пользователь пишет твит о землетрясении; кто о нём узнает?

## Входные данные

n (2 ≤ n ≤ 100), затем n строк «имя k фолловер₁ … фолловерₖ» с
различными именами из 1–30 латинских букв и, наконец, твит — непустая
строка не длиннее 140 символов с ASCII-кодами от 32 до 127.

## Выходные данные

Число пользователей, узнавших о землетрясении, затем их имена в любом
порядке, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
5
Miyako 1 Sae
Yuno 2 Miyako Sae
Nazuna 1 Nori
Sae 1 Yuno
Nori 1 Nazuna
Hidamari is going to collapse!!!
```

Вывод:

```
3
Miyako
Sae
Yuno
```

## Решение

Пользователь, отправляющий сообщение не длиннее 140 символов,
показывает его всем фолловерам. Ретвит сообщения пользователя u длиннее
на 6 + |u| символов — префикс «RT @: » и имя. Короче всегда лучше, так
что ищем самое короткое сообщение, которое каждый пользователь мог бы
отправить. Это кратчайший путь от первого пользователя,
начинающийся с длины твита, с весом 6 + |u| на каждом ребре из u.
Алгоритм Дейкстры по n ≤ 100 пользователям находит его, а у кого
кратчайшее сообщение длиннее 140, те не могут его отправить. Ответ — пользователи,
способные отправить сообщение, вместе со всеми их фолловерами: фолловер видит сообщение,
даже если собственный ретвит фолловера был бы слишком длинным. `O(n²)`,
или `O(n² log n)` в C++ из-за обращений к `map`.

В примере твит Miyako — 32 символа. Sae видит его и ретвитит 44
символа, Yuno видит это и ретвитит 53 символа, которые снова доходят до
Miyako и Sae. Nazuna и Nori ничего не узнают.

Подводные камни:

- меньше ретвитов не значит короче сообщение: длинное имя на коротком
  пути может проиграть нескольким коротким именам;
- твит может начинаться и кончаться пробелами, они считаются, так что
  строку надо читать целиком;
- сообщение ровно из 140 символов ещё отправляется;
- пользователи, которые не могут сделать ретвит, всё равно узнают
  новость, если её отправляет тот, на кого они подписаны.

Ответы совпадают с независимой принятой реализацией на 180 случайных
сетях, в том числе там, где путь с меньшим числом ретвитов даёт более
длинное сообщение.
