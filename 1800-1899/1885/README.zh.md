# 1885. 乘客的舒适

[Timus 1885](https://acm.timus.ru/problem.aspx?space=1&num=1885) · 难度 186 · math

原题作者 Denis Dublennykh，出自 NEERC 2011 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

飞机必须在最初 t 秒内爬升到 h 米，然后保持这个高度。它每秒至多爬升 v 米，在到达 h 之前不能下降。当且仅当飞机以超过每秒 x 米的速度爬升时，乘客的耳朵会堵塞。求耳朵堵塞的最短和最长可能时间。

## 输入

h, t, v, x（5000 ≤ h ≤ 12 000，50 ≤ t ≤ 1200，1 ≤ x < v ≤ 100，h ≤ t·v）。

## 输出

最短和最长时间，绝对或相对误差都不超过 10⁻⁶。

## 样例

### 样例 1

输入：

```
10000 500 50 10
```

输出：

```
125.0 500.0
```

## 解法

最短：以 x 或更慢速度飞行的每一秒都不计，并且每秒至多升高 x 米。若 t·x ≥ h，飞机以 x 爬升，耳朵从不堵塞。否则应当除 τ 秒外都以 x 爬升，这 τ 秒以 v 爬升，满足 τ·v + (t − τ)·x = h，所以 τ = (h − t·x)/(v − x)。快速的那几秒用低于 v 的速度只会更长。

最长：只有爬升时耳朵才堵塞，所以至多 t 秒，也至多 h/x 秒。以略高于 x 的速度爬升可以逼近后一个界限；若 h/x > t，飞机在全部 t 秒内以 h/t > x 的速度爬升。答案为 min(t, h/x)。`O(1)`。

样例中 t·x = 5000 < 10 000，所以需要以 50 m/s 飞 5000/40 = 125 秒；而以 h/t = 20 > 10 m/s 爬升全部 500 秒会让耳朵一直堵塞。

注意事项：

- 最长时间是一个极限：恰好以 x 爬升耳朵不堵，但任何更快的速度都会堵，所以答案是 min(t, h/x)；
- 当 t·x ≥ h 时最短时间为 0；
- 慢于 x 的爬升不计时，所以混合较慢的速度永远不比以 x 爬升更好。

答案在所有测试上与一个独立的已通过实现一致。
