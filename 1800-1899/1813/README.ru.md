# 1813. Случайный порядок песен

[Timus 1813](https://acm.timus.ru/problem.aspx?space=1&num=1813) · сложность 1570 · number_theory

Оригинальная задача — Tavrida NU Akai Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Последовательность x₀ = 0, xᵢ = (a·xᵢ₋₁ + b) mod m должна за первые m
членов пройти каждое число от 0 до m − 1 по разу и вернуться к 0. По
всем парам (a, b) с 0 ≤ a, b < m, для которых это так, найти среднее a,
округлённое вниз.

## Входные данные

До 100 строк, в каждой m (1 < m < 10⁹).

## Выходные данные

Для каждого m — среднее, округлённое вниз.

## Примеры

### Пример 1

Ввод:

```
2
36
100
123
```

Вывод:

```
1
13
41
1
```

## Решение

Последовательность должна быть одним циклом длины m — полным периодом
линейного конгруэнтного генератора. По теореме Халла — Добелла это
происходит ровно тогда, когда b взаимно просто с m, a − 1 делится на
каждый простой делитель m и a − 1 делится на 4, если m делится на 4.
Значит, если c — произведение различных простых делителей m, удвоенное
при 4 | m, то подходящие a — это 1, 1 + c, 1 + 2c, … меньше m, всего
m/c штук, поскольку c делит m. Число подходящих b от a не зависит,
поэтому среднее по парам равно среднему этой прогрессии,
(m − c + 2)/2. Разложение m перебором делителей до √m занимает `O(√m)`
на значение.

Для m = 36 = 2²·3² c = 2·3·2 = 12, и a равно 1, 13 или 25 со
средним 13. Для m = 123 = 3·41 c = 123, и подходит только a = 1.

Подводные камни:

- лишний множитель 2 для кратных 4: при m = 4 значение a = 3 не
  подходит;
- среднее по парам равно среднему по a только потому, что у каждого
  подходящего a одинаковое число подходящих b;
- a = 0 не подходит никогда: тогда последовательность повторяет b.

Ответы совпадают с полным моделированием всех пар (a, b) для всех m от
2 до 60 и с независимой принятой реализацией на случайных значениях,
произведениях малых простых, больших простых и их квадратах.
