## Задача

Пусть F₀ = F₁ = 1 и Fᵢ = i·Fᵢ₋₁·Fᵢ₋₂. Найти число делителей Fₙ по
модулю 10⁹ + 7.

## Входные данные

n (1 ≤ n ≤ 10⁶).

## Выходные данные

Число делителей Fₙ по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
4
```

## Решение

Каждый шаг один раз домножает на i и повторяет два предыдущих
произведения, так что множитель k входит в Fₙ ровно fib(n − k + 1) раз,
где fib(1) = fib(2) = 1: один раз в F_k, один раз в F_{k+1}, дважды в
F_{k+2} и далее по правилу Фибоначчи. Значит, Fₙ = Π k^fib(n−k+1) по
k = 1 … n.

Число делителей равно Π (e_p + 1) по простым p, где e_p — показатель p
в Fₙ. Число k вносит v_p(k), умноженное на свой вес fib(n − k + 1), а
v_p(k) считает, сколько из p, p², p³, … делят k, так что e_p — сумма
весов всех кратных p, p² и так далее. Важен только e_p по модулю
10⁹ + 7, поэтому веса тоже хранятся по модулю. Обход кратных каждой
степени простого занимает около n·ln ln n шагов; решение на Python
суммирует каждую прогрессию одним срезом. `O(n log log n)`.

В примере F₃ = 3·F₂·F₁ = 3·2·1 = 6, у которого делители 1, 2, 3 и 6.

Подводные камни:

- показатели огромны, но ответу они нужны только по модулю 10⁹ + 7;
- степень простого, перешедшая n, должна остановить цикл до
  переполнения;
- решение на Python работает на PyPy.

Ответы совпадают с прямым разложением Fₙ при n до 14 и с независимой
принятой реализацией до 10⁶.
