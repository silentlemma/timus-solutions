# 1852. 立方中的立方中的立方

[Timus 1852](https://acm.timus.ru/problem.aspx?space=1&num=1852) · 难度 2452 · simulation

原题作者 Grigoriy Nazarov，出自 2011 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Team.GOV Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

Vadik 在一个已复原的魔方上做了一串面转动。反复执行同一串转动，魔方终究会复原。还需要再执行这串转动多少次，才能回到原来的图案？

## 输入

一行不超过 10⁵ 个字母 U、D、L、R、F、B，分别表示上、下、左、右、前、后面：小写字母把该面顺时针转 90°，大写字母逆时针转 90°。

## 输出

还需要重复的次数。

## 样例

### 样例 1

输入：

```
Ud
```

输出：

```
3
```

### 样例 2

输入：

```
RRRR
```

输出：

```
0
```

## 解法

这串转动按一个固定的置换移动 54 个贴纸，重复 k 次能复原魔方，当且仅当 k 是该置换的阶的倍数，而阶就是各循环长度的最小公倍数。由于这串转动已经执行过一次，答案是阶减 1。

把贴纸表示为它所在小块的位置（坐标取自 {−1, 0, 1}）以及它所在面的外法向量。转动外法向量为 a 的面，会移动位置 p 满足 p·a = 1 的贴纸：p 和法向量都绕 a 转四分之一圈。
从面外看，逆时针是 v → a × v + a(a·v)，顺时针则把 a × v 换成 −a × v。于是十二个字母各自成为一张"每个贴纸去往何处"的表，整串转动折叠成一个置换，每个字母查表 54 次（Python 中每个字母一次 `bytes.translate`）。`O(54·|s|)`。

在第一个样例中，从上方看逆时针转 U、从下方看顺时针转 d，两个外层绕竖直轴朝同一方向旋转，所以四次后图案复原：还需三次。在第二个样例中，R 的四个四分之一转已经复原了魔方。

注意事项：

- 顺时针是从每个面的外侧看的，所以同样大小写的字母，下面与上面的转向相反；
- 这串转动已经执行过一次，因此要减一；
- 阶很小（魔方上最多 1260），但循环长度要用最小公倍数合并，而不是相乘。

在三百个随机序列和已知的阶上（例如相邻两面各顺时针转一次的阶为 105，转一下、再转一下、再把两者撤销的阶为 6），答案与一个独立的已通过实现一致。
