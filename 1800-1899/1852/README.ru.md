# 1852. Гигантский мезон с вишнями

[Timus 1852](https://acm.timus.ru/problem.aspx?space=1&num=1852) · сложность 2452 · simulation

Автор оригинальной задачи — Григорий Назаров; Ural SU Team.GOV Contest, Петрозаводские летние сборы, август 2011 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Вадик сделал последовательность поворотов граней собранного кубика
Рубика. Если повторять ту же последовательность снова и снова, кубик
рано или поздно соберётся. Сколько ещё раз нужно применить
последовательность, чтобы вернуть исходный узор?

## Входные данные

Одна строка не длиннее 10⁵ букв U, D, L, R, F и B — верхняя, нижняя,
левая, правая, передняя и задняя грани: строчная буква поворачивает
грань на 90° по часовой стрелке, заглавная — на 90° против.

## Выходные данные

Сколько ещё повторений нужно.

## Примеры

### Пример 1

Ввод:

```
Ud
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
RRRR
```

Вывод:

```
0
```

## Решение

Последовательность переставляет 54 наклейки фиксированной
перестановкой, и k повторений собирают кубик ровно тогда, когда k
кратно порядку этой перестановки — наименьшему общему кратному длин её
циклов. Ответ — порядок минус 1, ведь один раз последовательность уже
применена.

Опишем наклейку положением её кубика с координатами из {−1, 0, 1} и
внешней нормалью её грани. Поворот грани с внешней нормалью a двигает
наклейки, у которых положение p даёт p·a = 1: и p, и нормаль
поворачиваются на четверть оборота вокруг a. Если смотреть на грань
снаружи, против часовой стрелки — это v → a × v + a(a·v), а по часовой —
то же с −a × v. Так каждая из двенадцати букв становится таблицей,
куда переходит каждая наклейка, и последовательность сворачивается в
одну перестановку по 54 обращения на букву (в Python — один
`bytes.translate` на букву). `O(54·|s|)`.

В первом примере U против часовой стрелки сверху и d по часовой снизу
вращают оба крайних слоя в одну сторону вокруг вертикальной оси, так
что узор возвращается через четыре последовательности: ещё три. Во
втором примере четыре четверти оборота R уже собирают кубик.

Подводные камни:

- по часовой стрелке — если смотреть снаружи на каждую грань, так что
  нижняя грань при том же регистре буквы вращается противоположно
  верхней;
- последовательность уже применена один раз, отсюда минус один;
- порядок невелик (на кубике не больше 1260), но длины циклов
  объединяются через НОК, а не перемножаются.

Ответы совпадают с независимой принятой реализацией на трёхстах
случайных последовательностях и на известных порядках, например 105
для двух поворотов соседних граней по часовой стрелке и 6 для поворота,
ещё одного и отмены обоих.
