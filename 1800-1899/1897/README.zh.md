# 1897. Alice、Bob 与字符串

[Timus 1897](https://acm.timus.ru/problem.aspx?space=1&num=1897) · 难度 5381 · suffix_structures

原题作者 Oleksandr Kulkov，出自 Petrozavodsk Summer 2018 的 Moscow IPT Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

游戏状态是固定字符串 s 的一个子串 t，可以为空。每步在 t 的左、右
各添加一个小写字母，要求结果仍是 s 的子串。无合法操作的一方输，
双方均采用最优策略。

在所有让当前行动方获胜的不同起始字符串中，求字典序第 k 小的一个。
空串最小，真前缀排在其扩展之前。同一子串的不同出现位置只算一个
候选。时间限制为 1 秒，内存为 256 MB。

## 输入

第一行是仅含小写英文字母的 s，1 ≤ |s| ≤ 100 000。
第二行是 k，1 ≤ k ≤ 10¹⁰。

## 输出

输出所求字符串；如果获胜字符串少于 k 个，输出 `no solution`。
若答案为空串，输出 `-`。

## 评测方式

输出按记号逐一比较。

## 样例

### 样例 1

输入：

```
abac
3
```

输出：

```
b
```

### 样例 2

输入：

```
rndstr
1
```

输出：

```
-
```

### 样例 3

输入：

```
abc
10
```

输出：

```
no solution
```

## 解法

### 按中心压缩游戏

每步增加两个字母，因此保留出现位置的中心和长度奇偶性。偶数长度的
中心 c 是位置 c 之前的间隙；奇数长度的中心 c 是字符位置。记奇偶性
e 为 0 或 1、半径为 d，则子串起点是 c − d，长度是 2d + e。

对每个中心从内向外读取左右字母对，建立这些序列的字典树。偶数树的根
对应空串，奇数树按中心字母分根。相同前缀对应相同子串，一步游戏就是
走一条字典树边。中心到达文本边界时标记终点。

压缩路径，但保留根、分叉和所有终点，即使终点只有一个孩子。中心序列
总数为 `O(n)`，故保留的节点也是 `O(n)`。一个出现位置结束不表示游戏
必须停止：其他出现位置可能还能扩展。终点标记准确记录出现集合的变化。

快速构造使用 s 及其反串的后缀数组、LCP 和区间最小值查询。两个中心
序列的公共前缀长度，是左侧向外、右侧向外匹配长度的较小者，并截断到
可用半径。必要时比较下一对字母。每次比较为常数时间，排序中心后，
使用相邻 LCP 和深度栈构造压缩树。

### 计算压缩边的胜负

存在一步进入必败状态时，当前状态必胜。设一条压缩边从半径 L 到 R，
孩子的结果为 W(R)。内部状态只有一个后继，因此
W(d) = W(R) XOR ((R − d) mod 2)，其中 L < d ≤ R。
按自底向上顺序，利用每条出边的第一个状态计算显式节点。

### 将字符串归属到后缀

把每个不同子串归属给其出现位置中后缀数组排名最小的起点。按后缀数组
顺序，这些归属形成通常的新增前缀块：长度严格大于与前一后缀的 LCP。
块内按长度递增，恰好就是字典序。

一条压缩边内部的出现中心集合不变。每增大一次半径，所有出现位置前面
添加相同字母，因此其后缀顺序不变。于是一个代表中心 c 可以负责整条
边。自底向上求代表：在当前节点半径处，比较终点中心与各孩子的代表。

边 L < d ≤ R 产生起点 p = c − d，范围为 [c − R, c − L − 1]。
胜负随半径交替，因此获胜字符串在该区间每隔一个起点贡献 1。分别对
奇、偶起点使用差分数组。获胜的奇数根在其代表起点增加一个长度为 1
的字符串；空串根单独处理。

求差分前缀和，得到每个后缀负责的获胜数量。按后缀数组扫描，找到包含
排名 k 的块。设其起点为 p，再扫描全部压缩边，每条边至多给出一个
半径 d = c − p 和长度 2d + e。保留获胜候选，补上适用的单字母根，
排序长度并选择剩余排名。

每个不同子串对应唯一的字典树状态和后缀归属。边上的奇偶规则给出其
胜负，区间增加只计一次，而归属顺序与长度顺序合起来是字典序，所以
最终选择正确。

使用计数排序的后缀数组倍增、LCP 预处理以及中心路径排序共需
`O(n log n)` 时间。压缩游戏和归属计数为线性；所选归属的长度排序
至多需要 `O(n log n)`。总时间和稀疏表空间均为 `O(n log n)`。

第一个样例的获胜字符串依次为空串、`a`、`b`、`ba`，所以第三个是 `b`。
第二个样例中，空串可以走到终止字符串 `rn`，因此必胜。第三个样例
只有空串和 `b` 获胜，不足十个。

注意事项：

- 一步增加半径 1，但增加长度 2；
- 压缩时保留所有终点，即使只有一个孩子；
- 一个边界出现位置不会禁止其他出现位置的扩展；
- 按后缀排名归属，不能按原文本最早位置；
- 统计不同字符串而非出现次数，并使用 64 位计数；
- 获胜空串排在所有非空候选之前。

## 各语言说明

将短的中心前缀打包成整数键以减少比较。C++、Go、Java 和 Rust 用基本类型数组存储 LCP 表。

Python 解答在 PyPy 上运行，走另一条路线：使用 s 的反串的后缀自动机，其反向后缀链接构成原串 s 的后缀树，从而给出字典序。只出现一次的字符串只能扩展到其出现位置碰到 s 较近的一端为止，因此它的胜负由奇偶性决定；对于重复出现的字符串，每个自动机状态各个长度的胜负保存在总大小为线性的位集中，高度重复的字符串使用共享的连续段。然后沿后缀树向下统计必胜字符串，找到第 k 个。评测用时 0.69 秒（限制 1 秒）；使用中心字典树以及后来使用第一版自动机的早期版本分别在评测第 73 和第 107 个测试上超时。
