# 1853. 激光技术

[Timus 1853](https://acm.timus.ru/problem.aspx?space=1&num=1853) · 难度 6453 · geometry

原题作者 Denis Dublennykh，出自 2011 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Team.GOV Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

激光源和接收器位于凸多边形的边界上，沿边界相距 d，光束总是从一个笔直地射向另一个。两者以相同的恒定速度沿同一方向在边界上移动，直到回到出发位置。
玻璃会在两个相继脉冲交叉的地方变得浑浊，因此光束会画出一条曲线：求所画出的所有线条的总长度。

## 输入

n（3 ≤ n ≤ 10 000）和按逆时针顺序给出的顶点，均为绝对值不超过 10⁶ 的整数；然后是整数 d，它大于最长边且不超过周长的一半。

## 输出

总长度，绝对或相对误差不超过 10⁻⁶。

## 样例

### 样例 1

输入：

```
3
-1 0
1 0
0 10
11
```

输出：

```
22.3730148246
```

### 样例 2

输入：

```
4
0 0
10 0
10 10
0 10
11
```

输出：

```
56.1255583559
```

## 解法

相继的脉冲交于运动光束与其包络相切的点，所以所画的图形就是光束族的包络。在激光源或接收器经过顶点的时刻把运动切开；这样的时刻至多 2n 个，让两点一起沿边界行走即可找到。
在两个这样的时刻之间，激光源按 A + t·u_A 移动，接收器按 B + t·u_B 移动（u 为所在边的单位方向），于是光束向量为 D(t) = D₀ + tV，其中 V = u_B − u_A，且 M = D × V 保持不变。

切点为 E = A + λD，在该点处直线没有侧向移动：(u_A + λV) × D = 0 给出 λ = (u_A × D)/M，它关于 t 是线性的。E′ 沿光束方向，所以其速度为 |E′·D|/|D|，化简后为 |R(t)|/√Q(t)，其中 Q = |D|²，R 是二次式。
把 R 写成 αQ + βQ′ + γ，积分就化为含 √Q 的项以及 ∫dt/√Q = asinh((Q′/2)/|M|)/√a，其中 a = |V|²，Q 的判别式为 −4M²；用 asinh 的形式可以避免通常对数形式的精度损失。R 在其根处变号，曲线在那里有尖点，所以每一段运动也要在那里切开。

沿逆时针方向，激光源和接收器总是向光束的两侧相反方向移动，所以切点位于两者之间，在玻璃内部。`O(n)`。

当 d 恰好是正方形周长的一半时，每束光都经过中心，图形只是一个点，答案为 0。

注意事项：

- 光束两端经过顶点的时刻不同：让它们一起行走，而不要按浮点距离去查找位置；
- 对凸多边形 M 为正，只有当光束沿着某条边时才为零，此时什么也画不出；
- 当 2at + b 为很大的负数时，ln(2at + b + 2√(aQ)) 可能因相消而损失精度，而 asinh 避免了这种相消。

在两百个随机多边形（包括 9000 个顶点的圆、细针形以及 d 取两个极限值的情况）上，答案与一个独立的已通过实现的差别不超过 10⁻⁷。
