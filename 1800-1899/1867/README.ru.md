# 1867. Нанотехнологии

## Задача

Даны квадраты расстояний между каждыми двумя из n атомов. Нужно
поставить атомы в точки с целыми координатами, по модулю не больше
10⁶, так чтобы все квадраты расстояний были такими, как заданы, или
сообщить, что это невозможно. Несколько атомов могут стоять в одной
точке.

## Входные данные

n (2 ≤ n ≤ 100), затем симметричная матрица n × n целых чисел aᵢⱼ
(0 ≤ aᵢⱼ ≤ 10⁹, aᵢᵢ = 0).

## Выходные данные

n строк с координатами атомов или «Impossible». Подходит любая верная
расстановка.

## Примеры

### Пример 1

Ввод:

```
3
0 1 4
1 0 1
4 1 0
```

Вывод:

```
0 0
1 0
2 0
```

### Пример 2

Ввод:

```
3
0 1 5
1 0 1
5 1 0
```

Вывод:

```
Impossible
```

### Пример 3

Ввод:

```
3
0 1 0
1 0 1
0 1 0
```

Вывод:

```
5 -5
5 -4
5 -5
```

## Решение

Сдвиги сохраняют сетку, так что атом 1 можно поставить в начало
координат. Пусть p — первый атом с положительным квадратом расстояния D до него.
Повороты на четверть оборота и отражения относительно осей и диагоналей
тоже сохраняют сетку, поэтому можно считать, что p стоит в (a, b) с
0 ≤ a ≤ b и a² + b² = D. Такие пары находятся перебором всех a до
√(D/2), и пробуется каждая.

Когда атомы 1 и p закреплены, у другого атома (x, y) на квадратах
расстояний d₁ и dₚ от них скалярное произведение
ax + by = (d₁ − dₚ + D)/2. Его векторное произведение bx − ay равно
±√(D·d₁ − dot²), поскольку dot² + cross² = D·(x² + y²). Тогда
x = (a·dot + b·cross)/D и y = (b·dot − a·cross)/D, и всё это должно
быть целым. У атомов на прямой через 1 и p cross равен 0. Первый атом
вне этой прямой может встать по любую её сторону, и пробуются обе:
зеркальный образ целой точки относительно наклонной прямой обычно не
целый. Дальше с расстоянием до этого атома согласуется только один знак.
Каждый атом сверяется со всеми поставленными до него, так что
дошедшая до конца расстановка — ответ. Её координаты не дальше √10⁹ от
начала, с большим запасом до предела. `O(√D + r·n²)`, где r — число
способов записать D как a² + b², не больше нескольких десятков.

Для первого примера так получается (0, 0), (0, 1), (0, 2), а для
третьего (0, 0), (0, 1), (0, 0); оба ответа не хуже приведённых.

Подводные камни:

- разные записи D не равноценны: 25 = 0² + 5² = 3² + 4², и атомам в
  (0, 0), (3, 4) и (4, 3) подходит только вторая;
- по той же причине надо пробовать обе стороны первой наклонной прямой;
- атомы могут стоять в одной точке, в том числе с атомом 1, и все
  расстояния могут быть нулевыми;
- произведения доходят до 10¹⁸, нужны 64-битные числа.

Ответы проходят чекер на всех матрицах 3 атомов с элементами до 13 и 4
атомов с элементами до 5 в сравнении со всеми малыми расстановками, а
также на больших случайных. Ответы «Impossible» совпадают с
независимой принятой реализацией.
