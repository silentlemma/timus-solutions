# 1867. 纳米技术

[Timus 1867](https://acm.timus.ru/problem.aspx?space=1&num=1867) · 难度 2568 · geometry

原题作者 Sergey Pupyrev（由 Ivan Burmistrov 准备），出自 2011 年乌拉尔联邦大学开放团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给出 n 个原子两两之间距离的平方。要把原子放在坐标为整数、绝对值不超过 10⁶ 的点上，使所有距离的平方都与给定的一致，或者说明这不可能。多个原子可以位于同一点。

## 输入

n（2 ≤ n ≤ 100），然后是对称的 n × n 整数矩阵 aᵢⱼ（0 ≤ aᵢⱼ ≤ 10⁹，aᵢᵢ = 0）。

## 输出

n 行原子坐标，或者 "Impossible"。任何合法的放置都可以。

## 样例

### 样例 1

输入：

```
3
0 1 4
1 0 1
4 1 0
```

输出：

```
0 0
1 0
2 0
```

### 样例 2

输入：

```
3
0 1 5
1 0 1
5 1 0
```

输出：

```
Impossible
```

### 样例 3

输入：

```
3
0 1 0
1 0 1
0 1 0
```

输出：

```
5 -5
5 -4
5 -5
```

## 解法

平移保持网格不变，所以可以把原子 1 放在原点。设 p 是第一个与它距离 D 为正的原子。四分之一圈的旋转以及关于坐标轴和对角线的反射也保持网格，所以可以认为 p 位于 (a, b)，其中 0 ≤ a ≤ b 且 a² + b² = D。枚举不超过 √(D/2) 的每个 a 即可找出这些数对，并逐一尝试。

固定原子 1 和 p 后，另一个原子 (x, y) 到它们的距离平方为 d₁ 和 dₚ，其点积 ax + by = (d₁ − dₚ + D)/2。叉积 bx − ay 等于 ±√(D·d₁ − dot²)，因为 dot² + cross² = D·(x² + y²)。于是 x = (a·dot + b·cross)/D，y = (b·dot − a·cross)/D，这些都必须是整数。位于 1 与 p 连线上的原子叉积为 0。第一个不在这条线上的原子可以放在线的任一侧，两侧都要尝试：整点关于斜线的镜像通常不是整点。此后只有一个符号与到该原子的距离相符。每个原子都与之前放好的所有原子核对，所以能走到最后的放置就是答案。其坐标离原点不超过 √10⁹，远在限制之内。`O(√D + r·n²)`，其中 r 是把 D 写成 a² + b² 的方法数，至多几十。

对第一个样例这样得到 (0, 0)、(0, 1)、(0, 2)，对第三个得到 (0, 0)、(0, 1)、(0, 0)；两者都和样例答案一样合法。

注意事项：

- D 的不同写法并不等价：25 = 0² + 5² = 3² + 4²，位于 (0, 0)、(3, 4) 和 (4, 3) 的原子只适合第二种；
- 出于同样的原因，第一条斜线的两侧都必须尝试；
- 原子可以重合，包括与原子 1 重合，所有距离也可能都是 0；
- 乘积可达 10¹⁸，需要 64 位整数。

答案在所有元素不超过 13 的 3 原子矩阵和元素不超过 5 的 4 原子矩阵上（与全部小规模放置比较）以及随机大数据上都通过了检查器。"Impossible" 的判断与一个独立的已通过实现一致。
