# 1814. 连分数

[Timus 1814](https://acm.timus.ru/problem.aspx?space=1&num=1814) · 难度 2926 · math

原题出自 Tavrida NU Akai Contest，2010 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把 √x 写成无限连分数 [a₀; a₁, a₂, …]，输出它的 k 阶渐近分数 [a₀; a₁, …, aₖ]，写成最简分数，分子和分母都对 10⁹ + 7 取模。

## 输入

x 和 k（2 ≤ x ≤ 10⁶，0 ≤ k ≤ 10⁹）；x 不是完全平方数。

## 输出

渐近分数 p/q，两者都对 10⁹ + 7 取模。

## 样例

### 样例 1

输入：

```
2 3
```

输出：

```
17/12
```

## 解法

√x 的部分商在 a₀ 之后是周期的。常用的递推 m ← d·a − m、d ← (x − m²)/d、a ← ⌊(a₀ + m)/d⌋ 能依次给出它们，周期在第一个等于 2a₀ 的项处结束。
对 x ≤ 10⁶，周期长度最多几千项。渐近分数通过矩阵乘积增长：矩阵 [[pₖ, pₖ₋₁], [qₖ, qₖ₋₁]] 等于 M(a₀)·M(a₁)·…·M(aₖ)，其中 M(a) = [[a, 1], [1, 0]]。
所以先乘 M(a₀)，再用快速幂乘上一个完整周期之积的 ⌊k/L⌋ 次方，最后乘周期的前 k mod L 项，全部对 10⁹ + 7 取模。第一列就是 (p, q)。
渐近分数总是最简的，因为 pₖqₖ₋₁ − pₖ₋₁qₖ = ±1，所以取模前无需约分。`O(L + log k)`。

样例中 √2 = [1; 2, 2, 2, …]，渐近分数为 1、3/2、7/5 和 17/12。

注意事项：

- 取模之前分数必须是最简的，而渐近分数本来就是；
- 阶数 k 从 0 开始，0 阶就是 a₀/1；
- 当 x 不是平方数时 d 永远不会变为 0，而平方数会破坏周期递推。

在 300 个随机测试上，答案与一个独立的已通过实现一致；对八个平方根的前二十个渐近分数，与精确分数一致。
