# 1814. Цепная дробь

[Timus 1814](https://acm.timus.ru/problem.aspx?space=1&num=1814) · сложность 2928 · math

Оригинальная задача — Tavrida NU Akai Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Записать √x бесконечной цепной дробью [a₀; a₁, a₂, …] и вывести её
подходящую дробь порядка k, [a₀; a₁, …, aₖ], несократимой дробью с
числителем и знаменателем по модулю 10⁹ + 7.

## Входные данные

x и k (2 ≤ x ≤ 10⁶, 0 ≤ k ≤ 10⁹); x не является полным квадратом.

## Выходные данные

Подходящая дробь в виде p/q, оба по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
2 3
```

Вывод:

```
17/12
```

## Решение

Неполные частные √x после a₀ периодичны. Обычная рекуррента
m ← d·a − m, d ← (x − m²)/d, a ← ⌊(a₀ + m)/d⌋ даёт их, а период
кончается на первом члене, равном 2a₀. Для x ≤ 10⁶ он не длиннее
нескольких тысяч членов. Подходящие дроби растут произведениями
матриц: матрица [[pₖ, pₖ₋₁], [qₖ, qₖ₋₁]] равна M(a₀)·M(a₁)·…·M(aₖ) с
M(a) = [[a, 1], [1, 0]]. Значит, умножаем M(a₀), затем произведение
одного полного периода в степени ⌊k/L⌋ быстрым возведением, затем
первые k mod L членов периода, всё по модулю 10⁹ + 7. Первый столбец —
(p, q). Подходящие дроби всегда несократимы, поскольку
pₖqₖ₋₁ − pₖ₋₁qₖ = ±1, поэтому сокращать перед взятием остатков не нужно.
`O(L + log k)`.

В примере √2 = [1; 2, 2, 2, …], и подходящие дроби — 1, 3/2, 7/5 и
17/12.

Подводные камни:

- дробь должна быть несократимой до взятия остатков, и подходящие дроби
  уже такие;
- порядок k считается с 0, так что порядок 0 — это a₀/1;
- при x, не являющемся квадратом, d никогда не обращается в 0, а
  квадрат сломал бы рекурренту периода.

Ответы совпадают с независимой принятой реализацией на 300 случайных
тестах и с точными дробями для первых двадцати подходящих дробей
восьми квадратных корней.
