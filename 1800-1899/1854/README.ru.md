## Задача

Император Адриан приносит в жертву стадо из n баранов, n нечётно, деля
его поровну между некоторым числом богов. Теон Смирнский хочет, чтобы
это число было нечётным и имело нечётное число положительных делителей.
Найти наибольшее такое число богов.

## Входные данные

Нечётное целое n (1 ≤ n ≤ 10¹⁸ − 1).

## Выходные данные

Наибольшее подходящее число богов.

## Примеры

### Пример 1

Ввод:

```
45
```

Вывод:

```
9
```

## Решение

У числа нечётное число делителей ровно тогда, когда оно — полный
квадрат: делители разбиваются на пары k и m/k, и только у квадрата есть
делитель в паре с самим собой. Все делители нечётного n нечётны, так
что ответ — наибольший квадрат, делящий n, то есть произведение
p^(2⌊e/2⌋) по степеням простых p^e в разложении n.

Выделяем нечётные простые p, пока p³ ≤ n, причём n по ходу уменьшается.
Остаток не имеет простых делителей до своего кубического корня, так что
это 1, простое, произведение двух простых или квадрат простого, и
только последний добавляет квадрат: проверяем точным целым квадратным
корнем. Перебор делителей занимает не больше 10⁶ шагов, а решение на
Python пробует только простые из решета. `O(n^(1/3))`.

В примере 45 = 3²·5, так что ответ 9.

Подводные камни:

- большой простой делитель в квадрате, например (10⁹ − 63)², остаётся
  после перебора и всё равно должен быть распознан;
- вещественный квадратный корень числа около 10¹⁸ может ошибиться на
  единицу; поправляйте его целыми проверками.

Ответы совпадают с прямым перебором на сотне маленьких чисел и с
независимой принятой реализацией на больших простых, произведениях
двух больших простых, квадратах больших простых и произведениях многих
маленьких простых.
