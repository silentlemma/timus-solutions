## Задача

Ворота строятся из вертикальной берёзы, земли и двух палок длиной a и
b: берёза — одна стойка, а палки образуют вторую стойку и перекладину.
Ворота могут быть любым четырёхугольником. Найдите их наибольшую
площадь. Берёза выше, чем a + b.

## Входные данные

a и b (1 ≤ a, b ≤ 10 000).

## Выходные данные

Наибольшая площадь с не менее чем шестью знаками после десятичной
точки.

## Решение

У четырёхугольника прямой угол там, где берёза встречается с землёй.
Диагональ c от верхней точки на берёзе до дальнего конца на земле
делит его на две части. Одна — прямоугольный треугольник с гипотенузой
c, его площадь не больше c²/4 и достигается при равных катетах. Другая
— треугольник из двух палок с углом t между ними. Тогда
c² = a² + b² − 2ab·cos t, а сумма равна
(a² + b² − 2ab·cos t)/4 + ab·sin t/2. Её производная обращается в
ноль при sin t + cos t = 0, то есть t = 135°, и площадь равна
(a² + b² + 2√2·ab)/4. `O(1)`.

При a = b = 2 получаем (4 + 4 + 8√2)/4 = 2 + 2√2 ≈ 4.828427125.

Подводные камни:

- ворота не обязаны быть прямоугольником; закреплён только прямой
  угол у основания берёзы;
- угол между палками — 135°, а не 90°: прямой угол даёт лишь
  (a + b)²/4;
- берёза по условию достаточно высокая, так что её высота ответ не
  ограничивает.

Формула совпадает с прямым перебором угла между палками и с
независимой принятой реализацией на всех тестах.

## Оптимизированные решения

Сохраняются та же геометрическая формула максимума (a*a+b*b+2*sqrt(2)*a*b)/4 и понятные исходники. Java уменьшает накладные расходы сканирования и форматирования. Go и Python вычисляют формулу, затем один раз округляют до шести знаков через целое с масштабом 10^6; таблицы ответов нет. При a,b<=10000 масштабированный результат меньше 2^47, поэтому погрешность вычисления и не больше половины миллионной при десятичном округлении вместе меньше 10^-6 по модулю. Дробная часть выводится ровно шестью позициями с ведущими нулями. Меняются представление и ввод-вывод, время и память остаются O(1).
