# 1874. 足球球门

[Timus 1874](https://acm.timus.ru/problem.aspx?space=1&num=1874) · 难度 199 · geometry

原题作者 Fedor Fominykh，出自 2011 年乌拉尔地区团队程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

球门由一棵竖直的白桦树、地面和两根长为 a 和 b 的木棍搭成：白桦树是一根门柱，两根木棍组成另一根门柱和横梁。球门可以是任意四边形。求它的最大面积。白桦树比 a + b 高。

## 输入

a 和 b（1 ≤ a, b ≤ 10 000）。

## 输出

最大面积，小数点后至少六位。

## 样例

### 样例 1

输入：

```
2 2
```

输出：

```
4.828427125
```

## 解法

四边形在白桦树与地面相交处有一个直角。从树上的顶点到地面远端的对角线 c 把它分成两部分。一部分是斜边为 c 的直角三角形，面积至多为 c²/4，在两条直角边相等时取到。另一部分是两根木棍组成的三角形，木棍夹角为 t。于是 c² = a² + b² − 2ab·cos t，总面积为 (a² + b² − 2ab·cos t)/4 + ab·sin t/2。其导数在 sin t + cos t = 0 即 t = 135° 时为零，面积为 (a² + b² + 2√2·ab)/4。`O(1)`。

当 a = b = 2 时得到 (4 + 4 + 8√2)/4 = 2 + 2√2 ≈ 4.828427125。

注意事项：

- 球门不必是矩形；只有白桦树根部的直角是固定的；
- 木棍之间的角是 135° 而不是 90°：直角只能得到 (a + b)²/4；
- 题目保证白桦树足够高，所以它的高度不会限制答案。

公式与对木棍夹角的直接搜索一致，也与一个独立的已通过实现在所有测试上一致。
