# 1824. 伊夫利特轰炸

[Timus 1824](https://acm.timus.ru/problem.aspx?space=1&num=1824) · 难度 1063 · backtracking

原题作者 Igor Andrianov，出自 2011 年 3 月 19 日第十二届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 n 座城市，是平面上的点。投在某座城市上的瓶子会摧毁与它距离不超过 r 的所有城市。瓶子只能投在城市上。
求摧毁所有城市所需的最少瓶数，以及投放的城市。

## 输入

n 和 r（1 ≤ n ≤ 30，1 ≤ r ≤ 1000），然后 n 行，为城市的整数坐标，范围 0 到 1000。

## 输出

最少的瓶数，然后是投放城市的编号。任何最优方案都可以。

## 样例

### 样例 1

输入：

```
4 50
10 10
500 500
501 501
999 999
```

输出：

```
3
1 3 4
```

## 解法

这是把距离不超过 r 的城市相连所得的图上的最小支配集，图有 30 个顶点，所以每座城市的覆盖范围可以放进一个位掩码 cover[i]。

依次尝试预算 k = 1, 2, …，搜索至多 k 次投放来覆盖尚存城市的集合。
必须有某次投放命中可达城市最少的未覆盖城市 u，所以搜索只在 u 可达的城市上分支，新命中最多的先试。三种剪枝让搜索保持很小：

- 即使 k 次投放都取当前最大增益也覆盖不了剩余城市时，放弃；
- 若某候选的新命中是已试候选的新命中的子集，就跳过它，因为它的分支只会更差；
- 记住失败的状态（剩余城市，预算），不再用相同或更小的预算重复搜索。

第一个成功的预算就是最优的。最多有 2^n 个掩码和 n 种预算，每次展开状态需要 O(n^2) 工作。保守上界为 O(n^3 * 2^n) 时间和 O(2^n + n^2) 空间。

在样例中城市 2 和 3 相距 √2，一个瓶子就能同时摧毁它们，而 1 和 4 离其他城市都很远：需要三个瓶子。

注意事项：

- 距离恰好为 r 也算命中，所以用整数比较平方；
- 没有规定禁止两座城市位于同一点；
- 贪心地选择命中最多的城市并不是最优的。
- 簇状输入（测试 `gen3`，生成器模式 3）的坐标必须在 [0,1000] 内：种子 11 曾生成 y = 1006。生成器现在将每个坐标限制在此范围内。

在 1,200 张小规模随机地图上，瓶数都与独立的精确子集枚举程序一致。
