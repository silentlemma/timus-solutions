# 1843. 切割长方体

[Timus 1843](https://acm.timus.ru/problem.aspx?space=1&num=1843) · 难度 3920 · constructive

原题作者 Mikhail Rubinchik，出自 2010 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个六个面涂成六种不同颜色的长方体，被平行于各面的平面锯开，每一刀都穿过整个长方体。每块碎片以未知的朝向给出：三个尺寸和六个面的颜色，内部的面用点标记。
把每块放回原处：指出碎片的哪个面朝前、哪个面朝下，并给出它前下左顶点在长方体中的坐标。

## 输入

长方体：尺寸 w、d、h（从前到后、从下到上、从左到右，各在 1 到 1000 之间），以及来自 "ROYGBV" 的六种颜色，依次为前、后、下、上、左、右面。
然后是 n（1 ≤ n ≤ 1000）和 n 块碎片，格式相同，原在内部的面用 "." 表示。保证有解。

## 输出

按输入顺序，对每块碎片输出朝前的面的字母和朝下的面的字母（F、B、D、U、L、R 分别表示它自己的前、后、下、上、左、右面），再输出它的前下左顶点。任何正确的放法都可以。

## 样例

### 样例 1

输入：

```
2 2 2 ROYGBV
2
1 2 2 R.YGBV
2 2 1 YGVBO.
```

输出：

```
F D 0 0 0
R F 1 0 0
```

## 解法

每一刀都穿过整个长方体，所以碎片构成一个网格：切口把每条轴分成若干段，网格的每个格子就是一块碎片。碎片接触长方体的某个面，当且仅当它的格子在该面所在轴上是第一个或最后一个。

分段。取从左到右的轴。带有前面颜色和下面颜色的碎片组成沿这条轴的前下棱，每段一块。在每块中，前面和下面的颜色标出它的两条轴，它沿第三条轴的尺寸就是一段的长度。
同时带左面颜色的那块给出第一段，带右面颜色的给出最后一段（没有切口时可能是同一块）。中间各段可以任意排列，因为交换两个内部薄片得到的碎片集合相同。另外两条轴同理。

放置。现在每个格子要求一块具有给定尺寸和颜色的碎片：位于表面的面是长方体的颜色，其余是点。把碎片的 24 种转法都写出来，取最小的写法作为键；格子得到相同的键，当且仅当碎片的某种转法正好合适。
按键对碎片分组，给每个格子分配其组中的任意一块，再找出该碎片恰好合适的转法。转法由绕两条相交轴的四分之一转生成，并用转到前面和下面的面来命名。平均 `O(24·n)`；C++ 使用 `std::map`，为 `O(24·n + n log n)`。

在样例中，前下棱只有第一块，所以从左到右的轴是一段长度 2，竖直轴也一样。从前到后，带下面和左面颜色的碎片是两块全部，尺寸都是 1，所以长方体在中间被切了一刀。第二块把右面转到前面、前面转到下面后，放进后面的格子。

注意事项：

- 多块碎片可能有相同的键，比如内部的单位立方体；其中任何一块都适合任何这样的格子；
- 转法是旋转而不是镜像，所以 24 种转法都必须由旋转得到；
- 没有切口的轴只有一段，同时接触两个面。

在最多 1000 块碎片的随机长方体上，放置结果都通过检查器：它旋转每块碎片，确认碎片无重叠地填满长方体，并且表面上的面颜色正确。
