# 1896. 军事演习 2.1

[Timus 1896](https://acm.timus.ru/problem.aspx?space=1&num=1896) · 难度 864 · fenwick, bitmask

题目由 Maxim Pivko 准备。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

将编号 1 到 N 排成圆圈。从 1 开始数当前仍在圈中的 K 个编号，删除
最后数到的编号。随后从其下一个仍在圈中的编号重新计数，直到全部删除。
第一次删除 K。

设第 i 步删除的编号为 sᵢ，求所有 |i − sᵢ| 的按位异或，i 从 1 到 N。
时间限制为 0.5 秒，内存为 6 MB；题面只允许 C、C++ 和 Pascal，提交表单还提供 Rust。

## 输入

一行包含 N、K，满足 1 ≤ N ≤ 1 100 000，1 ≤ K ≤ N。

## 输出

输出最终的整数异或值。

## 评测方式

输出按整数记号逐一比较。

## 样例

### 样例 1

输入：

```
5 3
```

输出：

```
2
```

## 解法

把剩余编号按递增顺序看待，设 r 是下一次计数开始的零基位置，初值为 0。
当前有 c 个编号时，下次删除位置为 (r + K − 1) 模 c。找到该位置的编号，
将其与当前步数之差的绝对值计入异或，然后删除。保持 r 不变：它现在
指向后继编号，越过末尾的情况由下一次取模处理。

为在内存限制内按排名查找，将编号分成每组 64 个存在位。位为 1 表示
对应编号仍在圈中。在这些字之上建立树状数组，维护各字中的置位数量。
前缀查找找到累计数量超过所需零基排名 r 的第一个字。减去此前各字中的
数量，就得到字内的零基排名。

在一个字内选择对应置位只需常数时间：利用置位数不断选择字的某一半，
直到定位目标位。字长固定为 64 位。清除所选位，并将树状数组中该字的
计数减一。

树状数组的前缀计数始终等于相应范围内的剩余编号数量，所以先找字再找位
恰好得到所需的剩余排名。排名递推正是循环计数规则，因此所有删除编号
及异或项都正确。

令 W = ⌈N/64⌉，每次删除耗时 `O(1 + log W)`，总时间为
`O(N(1 + log W))`，也可上界为 `O(N log N)`。空间为 `O(W)` 个机器字，
不保存完整删除序列。

样例的删除顺序为 3、1、5、2、4。绝对差为 2、1、2、2、1，异或为 2。

注意事项：

- K 只计数仍在圈中的编号，并包含起始编号；
- 排名从 0 开始，编号和步骤数从 1 开始；
- 删除后不要增加 r，否则会跳过后继编号；
- 最后一个字中未使用的位必须清零；
- 使用无符号 64 位掩码，整字情况需避免移位 64 位；
- 不必保存逐编号的树或整个排列。
