# 1896. Военные учения 2.1

[Timus 1896](https://acm.timus.ru/problem.aspx?space=1&num=1896) · сложность 864 · fenwick, bitmask

Задачу подготовил Максим Пивко.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

По кругу расположены номера от 1 до N. Начиная с 1, отсчитайте K
оставшихся номеров и удалите последний отсчитанный. Затем начинайте
счёт со следующего оставшегося номера и повторяйте до опустошения круга.
Первым удаляется K.

Пусть sᵢ — номер, удалённый на шаге i. Найдите побитовое XOR чисел
|i − sᵢ| по всем шагам i от 1 до N. Ограничения: 0,5 секунды и 6 МБ;
в условии разрешены только C, C++ и Pascal, форма отправки предлагает ещё Rust.

## Входные данные

Одна строка содержит N и K: 1 ≤ N ≤ 1 100 000; 1 ≤ K ≤ N.

## Выходные данные

Выведите полученное целое значение XOR.

## Проверка

Ответы сравниваются по последовательностям целочисленных токенов.

## Примеры

### Пример 1

Ввод:

```
5 3
```

Вывод:

```
2
```

## Решение

Рассмотрим оставшиеся номера по возрастанию. Пусть r — позиция,
с которой возобновляется счёт, начиная с 0; изначально r = 0.
При c оставшихся номерах позиция следующего удаления равна
(r + K − 1) по модулю c. Находим номер на этой позиции, добавляем
к XOR модуль разности с номером шага и удаляем его. Значение r
не меняем: теперь это позиция следующего номера, а переход через
конец учтёт следующее взятие по модулю.

Для поиска по позиции в пределах памяти разобьём номера на слова
из 64 битов присутствия. Установленный бит означает, что номер ещё
в круге. Над словами построим дерево Фенвика с количествами единичных
битов. Поиск по префиксным суммам находит первое слово, где накопленное
количество превышает нужную позицию r с индексацией от 0. Вычтем
количество в предыдущих словах и получим позицию внутри слова, тоже от 0.

Поиск внутри одного слова занимает константное время: по числу
единичных битов последовательно выбираем нужную половину слова,
пока не найдём бит. Размер слова фиксирован — 64 бита. Сбрасываем
найденный бит и уменьшаем счётчик слова в дереве Фенвика.

Префиксные суммы дерева всегда равны количествам оставшихся номеров.
Поэтому поиск слова и затем бита возвращает в точности нужную позицию
среди оставшихся. Формула позиции совпадает с круговым счётом, значит
каждое удаление и каждый член XOR вычисляются верно.

При W = ⌈N/64⌉ удаление занимает `O(1 + log W)`, всё решение —
`O(N(1 + log W))`, что также ограничено `O(N log N)`. Память —
`O(W)` машинных слов. Полный порядок удаления не сохраняется.

В примере удаляются номера 3, 1, 5, 2, 4. Модули разностей равны
2, 1, 2, 2, 1, их XOR равен 2.

Подводные камни:

- K отсчитывается среди оставшихся, включая начальный номер;
- позиции отсчитываются от 0, а номера и шаги — от 1;
- не увеличивать r после удаления, иначе следующий номер будет пропущен;
- очистить неиспользуемые биты последнего слова;
- использовать беззнаковые 64-битные маски и не сдвигать на 64 для полного слова;
- не хранить без необходимости дерево на каждый номер или всю перестановку.

## Особенности языков

В условии разрешены только C, C++ и Pascal, но форма отправки Timus
предлагает ещё Rust 1.75, поэтому даны решения на C++ и Rust; Go, Python
и Java отправить нельзя. Оба хранят около 17 000 слов и счётчиков,
гораздо меньше 6 МБ.

Ответы совпадают с прямой симуляцией выбывания на 1625 тестах, включая
наибольшее N и размеры на границах машинных слов.
