# 1881. Длинное условие задачи

[Timus 1881](https://acm.timus.ru/problem.aspx?space=1&num=1881) · сложность 62 · simulation

Автор оригинальной задачи — Фёдор Фоминых; Уральская региональная командная олимпиада по программированию 2011.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На странице h строк по w символов. Слова в строке разделяются одним
пробелом, а слово, не помещающееся в текущую строку, начинает новую;
слова не переносятся. Сколько страниц займёт текст из n слов?

## Входные данные

h, w и n (1 ≤ h, w ≤ 100, 1 ≤ n ≤ 10 000), затем n слов, по одному в
строке, каждое не длиннее w; их суммарная длина не больше 10 000.
Слова непустые и состоят только из прописных и строчных английских
букв и знаков препинания `.,!?`.

## Выходные данные

Количество страниц.

## Примеры

### Пример 1

Ввод:

```
3 5 6
To
be
or
not
to
be
```

Вывод:

```
2
```

## Решение

Заполняем строки жадно. Храним число занятых символов в текущей
строке; слову нужна его длина плюс один пробел, если оно не первое в
строке. Если не помещается, начинаем с него новую строку. Начальное
значение −1 избавляет первое слово строки от пробела. Ответ — число
строк, делённое на h с округлением вверх. `O(n)`.

В примере строки такие: «To be», «or», «not» и «to be»: «or not» и
«not to» длиннее на один символ. Четыре строки при трёх строках на
странице занимают две страницы.

Подводные камни:

- слово, ровно заполняющее остаток строки вместе с пробелом, ещё
  помещается;
- пробел ставится только между словами, никогда в начале строки;
- число страниц округляется вверх.

Ответы совпадают с независимой принятой реализацией на 100 случайных
текстах.
