# 1845. 整数复行列式

[Timus 1845](https://acm.timus.ru/problem.aspx?space=1&num=1845) · 难度 4255 · number_theory

原题作者 Dmitry Poletaev 和 Ivan Burmistrov，出自 2010 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

高斯整数是实部和虚部都是整数的复数。若高斯整数满足 a = bq + r 且 |r| < |b|，则 r 是 a 除以 b 的余数。给定一个由高斯整数组成的 n × n 矩阵和一个非零高斯整数 p，求矩阵行列式除以 p 的余数。

## 输入

n（1 ≤ n ≤ 50），然后是矩阵的 n 行，每个元素给出实部和虚部，最后以同样方式给出 p。所有部分的绝对值不超过 10 000。

## 输出

余数的实部和虚部。任何余数都可以。

## 样例

### 样例 1

输入：

```
2
2 0 -7 0
1 0 0 -1
3 1
```

输出：

```
3 0
```

## 解法

行列式本身可能有几百位，所以编译型语言的解法从不构造它。把每个元素换成它模 p 的余数，行列式模 p 不变；把一行的倍数加到另一行，行列式完全不变。
高斯整数有带余除法：把 x / y 的两部分都舍入到最近的整数，得到的商 q 满足 |x − qy|² ≤ |y|² / 2。
因此可以对行做欧几里得算法来清空每列对角线以下的部分：从主元行减去 q 倍的下面一行，交换两行（符号取反），重复直到下面的元素为零。
该列的元素只会变小，而其他被改动的元素都重新模 p 约化，所以所有中间值都可以放进 64 位整数。行列式是对角线的乘积，每乘一个因子就模 p 约化一次。`O(n³ log |p|)`。

Python 版本走另一条路：用 Bareiss 消元计算精确的行列式，每个元素更新为 (a·c − b·d) / 上一个主元，且除法总是整除，最后再约化一次。Python 的大整数可以很快地处理几百位的数。`O(n³)` 次算术运算。

在样例中，行列式为 2·(−i) − (−7)·1 = 7 − 2i。因为 (3 + i)(1 − i) = 4 − 2i，余数可以是 3；因为 (3 + i)(2 − i) = 7 − i，余数也可以是 −i，这正是各解法的输出。

注意事项：

- 余数不唯一，所以由检查器评判答案；
- 当 p 是单位时，唯一的余数是 0；
- 对负的部分，舍入必须是 (2x + n) / 2n 的向下取整，而不是截断。

在最大 50 × 50、带零主元、相同行、单位模数和合数模数的随机矩阵上，余数都通过一个检查器：它计算精确的行列式并检验整除性。
