# 1845. Целочисленный комплексный определитель

[Timus 1845](https://acm.timus.ru/problem.aspx?space=1&num=1845) · сложность 4255 · number_theory

Авторы оригинальной задачи — Дмитрий Полетаев и Иван Бурмистров; Ural SU Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Целое гауссово число — комплексное число с целыми действительной и
мнимой частями. Если a = bq + r для целых гауссовых чисел и |r| < |b|,
то r — остаток от деления a на b. Дана матрица n × n из целых гауссовых
чисел и ненулевое целое гауссово число p; найти остаток от деления
определителя матрицы на p.

## Входные данные

n (1 ≤ n ≤ 50), затем n строк матрицы, каждый элемент — действительной
и мнимой частью, и в конце p так же. Все части по модулю не больше
10 000.

## Выходные данные

Действительная и мнимая часть остатка. Подходит любой остаток.

## Примеры

### Пример 1

Ввод:

```
2
2 0 -7 0
1 0 0 -1
3 1
```

Вывод:

```
3 0
```

## Решение

Сам определитель может содержать сотни цифр, поэтому решения на
компилируемых языках его не строят. Определитель не меняется по модулю
p, если заменить каждый элемент его остатком по модулю p, и не
меняется вовсе при прибавлении к строке кратного другой строки. У целых
гауссовых чисел есть деление с остатком: округление обеих частей x / y
до ближайших целых даёт частное q с |x − qy|² ≤ |y|² / 2. Поэтому
каждый столбец под диагональю можно обнулить алгоритмом Евклида над
строками: вычесть из строки с ведущим элементом нижнюю строку, умноженную
на q, поменять их местами (меняя знак) и повторять, пока нижний элемент
не станет нулём. Элементы столбца только уменьшаются, а все прочие
изменённые элементы снова приводятся по модулю p, так что все
промежуточные значения помещаются в 64 бита. Определитель —
произведение диагонали, приводимое по модулю p после каждого множителя.
`O(n³ log |p|)`.

Решение на Python идёт другим путём: считает точный определитель
методом Барейса, где каждый элемент обновляется как
(a·c − b·d) / предыдущий ведущий элемент и деление всегда нацело, и
один раз приводит его в конце. Длинные числа Python быстро справляются
с несколькими сотнями цифр. `O(n³)` арифметических операций.

В примере определитель равен 2·(−i) − (−7)·1 = 7 − 2i. Так как
(3 + i)(1 − i) = 4 − 2i, остатком может быть 3; так как
(3 + i)(2 − i) = 7 − i, им может быть и −i, что и выводят решения.

Подводные камни:

- остаток не единственный, поэтому ответы проверяет чекер;
- для обратимого p единственный остаток — 0;
- округление должно быть округлением вниз (2x + n) / 2n, а не
  отбрасыванием дробной части, для отрицательных частей.

Остатки проходят чекер, который считает точный определитель и
проверяет делимость, на случайных матрицах до 50 × 50 с нулевыми
ведущими элементами, равными строками, обратимыми и составными
модулями.
