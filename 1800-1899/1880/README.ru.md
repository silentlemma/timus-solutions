## Задача

У каждого из трёх игроков команды есть список «собственных» чисел.
Число собственное для команды, если оно есть во всех трёх списках.
Сколько таких чисел?

## Входные данные

Три блока: длина n списка (1 ≤ n ≤ 4000), затем его n различных
положительных чисел не больше 10⁹ в порядке возрастания.

## Выходные данные

Количество чисел, входящих во все три списка.

## Примеры

### Пример 1

Ввод:

```
5
13 20 22 43 146
4
13 22 43 146
5
13 43 67 89 146
```

Вывод:

```
3
```

## Решение

Списки отсортированы, так что идём по ним одновременно, с указателем на
каждый. Если три текущих числа равны, считаем одно. Затем сдвигаем все
указатели, стоящие на наименьшем из них; когда какой-то список
кончается, останавливаемся. Решение на Python вместо этого пересекает
три множества. `O(n)`.

В примере 13, 43 и 146 есть во всех трёх списках, а 20, 22, 67 и 89
отсутствуют хотя бы в одном.

Подводные камни:

- число только из двух списков не считается;
- после совпадения сдвигаются все три указателя, а в остальных случаях
  — только стоящие на минимуме; иначе можно проскочить общее число;
- проход останавливается, как только один список исчерпан.

Ответы совпадают с независимой принятой реализацией на 50 случайных
командах.
