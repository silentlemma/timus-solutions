# 1811. Dual-SIM телефон

[Timus 1811](https://acm.timus.ru/problem.aspx?space=1&num=1811) · сложность 1419 · binary_search

Оригинальная задача — Tavrida NU Akai Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть n мобильных операторов и k маршрутов «через оператора x на номер
оператора y за цену c». Телефон на две SIM-карты держит двух операторов
и отправляет каждое сообщение через более дешёвого из тех, кто может
достать до адресата. Выбрать двух операторов, достающих до номеров
всех операторов, так, чтобы самое дорогое сообщение было как можно
дешевле.

## Входные данные

n и k (2 ≤ n ≤ 10⁴, 0 ≤ k ≤ 10⁵), затем k строк x y c
(1 ≤ x, y ≤ n, 1 ≤ c ≤ 10⁹).

## Выходные данные

Наименьшая возможная цена самого дорогого сообщения или
"No solution".

## Примеры

### Пример 1

Ввод:

```
4 13
1 1 1
1 2 3
1 3 3
1 4 5
2 1 2
2 2 1
2 3 2
3 1 4
3 3 4
3 4 1
4 1 2
4 2 3
4 4 3
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
2 2
1 1 3
2 1 4
```

Вывод:

```
No solution
```

## Решение

Двоичный поиск по ответу. Для предела цены оставляем только маршруты
не дороже его и даём каждому оператору x множество адресатов, до
которых он достаёт, — битовый набор. Хорошая пара есть, когда два
множества покрывают всё. Их размеры в сумме не меньше n, так что одно
из них, a, покрывает хотя бы половину. Для каждого такого a все
адресаты, до которых a не достаёт, должны быть в множестве партнёра.
Берём пропущенного адресата с наименьшим общим числом входящих маршрутов:
партнёр должен быть одним из достающих до него операторов, и каждый
проверяется побитово — покрывает ли он всё, что пропускает a. Маршруты
отсортированы по цене, и предел — их префикс, поэтому переход от одного
предела к другому лишь добавляет или убирает маршруты между ними, что
держит все битовые наборы в актуальном виде примерно за k изменений
всего. `O(n²/64 + k log(k+1) · n/64)` в худшем случае, на деле гораздо меньше.

В первом примере при пределе 2 оператор 2 достаёт до 1, 2 и 3, а
оператор 3 — до 4 за 1, так что пара 2 и 3 подходит. При пределе 1 ни
одна пара не достаёт одновременно до операторов 1 и 3.

Подводные камни:

- повторные маршруты между одними и теми же операторами: оставлять
  самый дешёвый;
- оператор, до которого никто не достаёт, делает ответ "No solution";
- одного оператора, достающего до всех, достаточно с любым партнёром.

Ответы совпадают с прямым перебором всех пар на 90 маленьких тестах и
с независимой принятой реализацией на тестах до 10⁵ маршрутов между
несколькими сотнями операторов, на 10⁴ операторах, где несколько
покрывают по половине всех, и на полных таблицах цен.
