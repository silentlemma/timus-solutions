# 1811. 双卡手机

[Timus 1811](https://acm.timus.ru/problem.aspx?space=1&num=1811) · 难度 1419 · binary_search

原题出自 Tavrida NU Akai Contest，2010 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 n 个移动运营商和 k 条线路“通过运营商 x 发往运营商 y 的号码，价格 c”。双卡手机装两个运营商，每条短信通过能到达目标的较便宜的那个发送。
选择两个运营商，使它们能到达所有运营商的号码，并使最贵的短信尽可能便宜。

## 输入

n 和 k（2 ≤ n ≤ 10⁴，0 ≤ k ≤ 10⁵），然后是 k 行 x y c（1 ≤ x, y ≤ n，1 ≤ c ≤ 10⁹）。

## 输出

最贵短信的最低可能价格，或者 "No solution"。

## 样例

### 样例 1

输入：

```
4 13
1 1 1
1 2 3
1 3 3
1 4 5
2 1 2
2 2 1
2 3 2
3 1 4
3 3 4
3 4 1
4 1 2
4 2 3
4 4 3
```

输出：

```
2
```

### 样例 2

输入：

```
2 2
1 1 3
2 1 4
```

输出：

```
No solution
```

## 解法

对答案二分。对一个价格上限，只保留不超过它的线路，并给每个运营商 x 一个它能到达的目标集合（位集）。当两个集合能覆盖全部时就有好的组合。
它们的大小之和至少为 n，所以其中一个 a 至少覆盖一半。对每个这样的 a，a 漏掉的目标必须全在搭档的集合中。
取漏掉的目标中总入线路最少的那个：搭档必须是能到达它的运营商之一，再用位运算逐个检查它是否覆盖 a 漏掉的全部目标。
线路按价格排序，上限就是它们的一个前缀，所以从一个上限换到另一个只需加入或移除中间的线路，总共约 k 次改动就能让所有位集保持最新。
最坏 `O(n²/64 + k log(k+1) · n/64)`，实际远小于此。

第一个样例中，上限为 2 时运营商 2 能到达 1、2 和 3，运营商 3 以价格 1 到达 4，所以组合 2 和 3 可行。上限为 1 时没有组合能同时到达运营商 1 和 3。

注意事项：

- 同一对运营商之间的重复线路：保留最便宜的；
- 若某个运营商谁都到达不了，答案就是 "No solution"；
- 一个能到达所有人的运营商就足够了，搭档任意。

在 90 个小测试上，答案与对所有组合的直接搜索一致；在几百个运营商之间多达 10⁵ 条线路、10⁴ 个运营商中少数各覆盖一半以及完整价格表的测试上，与一个独立的已通过实现一致。
