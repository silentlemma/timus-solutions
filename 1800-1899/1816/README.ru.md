# 1816. Проблемы с Поллардом

[Timus 1816](https://acm.timus.ru/problem.aspx?space=1&num=1816) · сложность 2272 · number_theory

Оригинальная задача — Tavrida NU Akai Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Чтобы разложить n, программа останавливается, если n простое. Иначе
она берёт случайное r от 1 до 10¹⁸ и g = gcd(n, r), повторяет, пока g
равно 1 или n, и затем так же раскладывает g и n/g. Найти
математическое ожидание числа вычислений НОД с погрешностью не больше
10⁻⁶.

## Входные данные

n (2 ≤ n ≤ 10⁹).

## Выходные данные

Ожидаемое число вычислений НОД.

## Примеры

### Пример 1

Ввод:

```
12
```

Вывод:

```
4.8571428571
```

### Пример 2

Ввод:

```
8
```

Вывод:

```
6.6666666667
```

## Решение

Поскольку 10¹⁸ намного больше n, остаток r mod n равномерен с
пренебрежимой ошибкой, и НОД раскладывается по степеням простых n.
Если p входит в m с показателем e, то показатель p в gcd(m, r) равен
c < e с вероятностью (1 − 1/p)/pᶜ и e с вероятностью 1/pᵉ, независимо
для каждого простого. Для составного m шаг повторяется, пока НОД не
станет собственным, поэтому
E(m) = (1 + Σ P(g)·(E(g) + E(m/g))) / (1 − P(1) − P(m)) с суммой по
собственным делителям g, а на простых E равно 0.

Все встречающиеся числа — делители n, их не больше 1344 для чисел до
10⁹. Если записать делитель вектором показателей в смешанной системе
счисления, каждый собственный делитель делителя получает меньший
номер, так что E заполняется по возрастанию. Пара g и m/g — это номера
d и index − d. Сумма идёт по всем делителям всех делителей n, в худшем
случае около 1,4·10⁵ слагаемых. `O(Σ d(m))` по делителям m числа n.

Во втором примере 8 = 2³: НОД равен 1, 2, 4 или 8 с вероятностями 1/2,
1/4, 1/8 и 1/8. E(4) = 4, и
E(8) = (1 + 1/4·4 + 1/8·4) / (3/8) = 20/3.

Подводные камни:

- E(m) стоит в обеих частях, поскольку бесполезный НОД повторяет шаг;
- вероятности зависят от самих простых, а не только от вида
  показателей;
- простым числам НОД не нужен вовсе, так что E(p) = 0.

Ответы совпадают с независимой принятой реализацией на примерах,
простых, степенях простых, числе с наибольшим числом делителей и
случайных значениях.
