# 1889. Объявление в аэропорту

[Timus 1889](https://acm.timus.ru/problem.aspx?space=1&num=1889) · сложность 308 · bruteforce

Автор оригинальной задачи — Денис Дублённых; NEERC 2011, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Игорь услышал n фраз объявления и знает язык некоторых из них;
остальные — «unknown». Объявление прочитали на нескольких языках, на
каждом не больше одного раза и с одинаковым числом фраз. На скольких
языках его могли прочитать? Перечислите все варианты по возрастанию
или выведите «Igor is wrong.», если вариантов нет.

## Входные данные

n (2 ≤ n ≤ 1000), затем n строк с названием языка (от 4 до 20 строчных
букв) или «unknown»; хотя бы одна фраза известна.

## Выходные данные

Все возможные числа языков по возрастанию или «Igor is wrong.».

## Примеры

### Пример 1

Ввод:

```
6
english
unknown
unknown
unknown
german
unknown
```

Вывод:

```
2 3 6
```

### Пример 2

Ввод:

```
4
english
french
unknown
english
```

Вывод:

```
Igor is wrong.
```

### Пример 3

Ввод:

```
3
zulu
zulu
zulu
```

Вывод:

```
1
```

## Решение

Если объявление прочитано на k языках, то k делит n, и фразы
разбиваются на k подряд идущих блоков по n/k, по блоку на язык. Для
каждого делителя k проверяем две вещи. Известные фразы блока должны
быть на одном языке. Ни один язык не может встретиться в двух разных
блоках. Блоки без известных фраз могут быть на любом новом языке.
С хеш-множествами ожидаемое время — `O(n·d(n))`, с упорядоченным
множеством в C++ — `O(n·d(n)·log n)`.

В первом примере один блок содержал бы и английский, и немецкий, так
что 1 не подходит. Для 2 блоки — «english ? ?» и «? german ?», для 3 —
пары, где английский в первой, а немецкий в третьей, а 6 здесь всегда
возможно: ответ 2 3 6.

Подводные камни:

- один и тот же язык в двух блоках запрещает k, как в третьем примере
  для 3 языков;
- блок из одних неизвестных фраз допустим;
- строка вывода — «Igor is wrong.» с точкой.

Ответы совпадают с независимой принятой реализацией на 125 случайных
объявлениях.

## Оптимизированные решения

Go объединяет известные фразы в последовательные группы языков, сохраняя имя и номера первой и последней фразы. Таблица с открытой адресацией отклоняет язык, который повторяется после другого известного языка. Для каждого делителя n проверяется, что группа лежит в одном блоке, а разные группы занимают разные блоки. Здесь d(n) — число делителей n. Коллизии хеша могут дать квадратичное время построения групп в худшем случае. Для ввода-вывода служат фиксированные байтовые буферы; имена точно сравниваются в 20-байтовых массивах даже при коллизиях хеша.

Принятые базовые реализации [1889_bruteforce.cpp](1889_bruteforce.cpp), [1889_bruteforce.java](1889_bruteforce.java), [1889_bruteforce.py](1889_bruteforce.py), [1889_bruteforce.rs](1889_bruteforce.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
