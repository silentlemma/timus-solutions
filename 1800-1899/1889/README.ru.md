# 1889. Объявление в аэропорту

[Timus 1889](https://acm.timus.ru/problem.aspx?space=1&num=1889) · сложность 308 · bruteforce

Автор оригинальной задачи — Денис Дублённых; NEERC 2011, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Игорь услышал n фраз объявления и знает язык некоторых из них;
остальные — «unknown». Объявление прочитали на нескольких языках, на
каждом не больше одного раза и с одинаковым числом фраз. На скольких
языках его могли прочитать? Перечислите все варианты по возрастанию
или выведите «Igor is wrong.», если вариантов нет.

## Входные данные

n (2 ≤ n ≤ 1000), затем n строк с названием языка (от 4 до 20 строчных
букв) или «unknown»; хотя бы одна фраза известна.

## Выходные данные

Все возможные числа языков по возрастанию или «Igor is wrong.».

## Примеры

### Пример 1

Ввод:

```
6
english
unknown
unknown
unknown
german
unknown
```

Вывод:

```
2 3 6
```

### Пример 2

Ввод:

```
4
english
french
unknown
english
```

Вывод:

```
Igor is wrong.
```

### Пример 3

Ввод:

```
3
zulu
zulu
zulu
```

Вывод:

```
1
```

## Решение

Если объявление прочитано на k языках, то k делит n, и фразы
разбиваются на k подряд идущих блоков по n/k, по блоку на язык. Для
каждого делителя k проверяем две вещи. Известные фразы блока должны
быть на одном языке. Ни один язык не может встретиться в двух разных
блоках. Блоки без известных фраз могут быть на любом новом языке.
Делителей мало, и каждая проверка линейна, так что всё стоит
`O(n·d(n))`.

В первом примере один блок содержал бы и английский, и немецкий, так
что 1 не подходит. Для 2 блоки — «english ? ?» и «? german ?», для 3 —
пары, где английский в первой, а немецкий в третьей, а 6 здесь всегда
возможно: ответ 2 3 6.

Подводные камни:

- один и тот же язык в двух блоках запрещает k, как в третьем примере
  для 3 языков;
- блок из одних неизвестных фраз допустим;
- строка вывода — «Igor is wrong.» с точкой.

Ответы совпадают с независимой принятой реализацией на 125 случайных
объявлениях.
