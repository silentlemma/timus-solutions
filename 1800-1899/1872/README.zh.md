# 1872. 宽敞的办公室

[Timus 1872](https://acm.timus.ru/problem.aspx?space=1&num=1872) · 难度 798 · matching

原题作者 Alexander Klepinin，出自 2011 年乌拉尔联邦大学开放团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 n 个项目组和 n 个给定面积的房间。第 i 组接受面积在 lᵢ 到 rᵢ 之间的房间。要给每个组分配一个单独的房间。如果恰好只有一种分法，输出它；如果有多种或者一种也没有，说明情况。

## 输入

n（2 ≤ n ≤ 1000），然后是 n 个房间面积，然后是 n 行 lᵢ rᵢ（lᵢ ≤ rᵢ）。所有面积都在 1 到 10 000 之间。

## 输出

分法唯一时输出 "Perfect!" 和每个组的房间；有多种分法时输出 "Ask Shiftman for help."；没有分法时输出 "Let's search for another office."。

## 样例

### 样例 1

输入：

```
3
40 50 60
30 70
20 40
60 60
```

输出：

```
Perfect!
2 1 3
```

### 样例 2

输入：

```
3
40 50 70
30 70
20 50
60 60
```

输出：

```
Let's search for another office.
```

## 解法

把房间按面积排序。为了找到一种分法，从小到大分配房间：每个房间给正在等待的组（lᵢ 不超过其面积）中 rᵢ 最小的那个。如果没有组在等待，或者该组的 rᵢ 已经小于房间面积，就不存在分法。任何分法都能通过保持合法的交换变成这种分法，所以只要存在分法，贪心就不会失败。

按排序后的顺序，第 q 个房间里的组接受一段连续的房间 first(q) … last(q)，其中包含 q。另一种分法存在，当且仅当有若干组能沿一个环传递房间，每组搬进下一组的房间。最短的这种环长度总是 2。取环中最大的房间 M、搬进 M 的组所在的房间 P，以及 M 的组要搬进的房间 S；P 和 S 都小于 M。若 P ≥ S，M 的区段覆盖 P，于是 P 与 M 的组可以互换。若 P < S，P 的区段覆盖 S，于是 P 的组可以直接搬进 S，得到更短的环。因此分法唯一，当且仅当不存在 p < q 使得 last(p) ≥ q 且 first(q) ≤ p。面积相同的房间总会构成这样的一对。贪心需要 `O(n log n)`，检查需要 `O(n²)`。

第一个样例中房间 40、50、60 分别给第 2、1、3 组。第 1 组接受全部三个房间，但第 2 组和第 3 组只接受自己的房间，所以谁也换不了。

注意事项：

- 两个面积相同的房间总能互换，所以同时用到两者的分法永远不唯一；
- 交换不一定发生在相邻房间之间：最小和最大房间的组可以越过中间那个房间互换，而中间房间的组只要它；
- 仅用贪心判断可行性还不够，唯一性需要单独检查。

在 30 000 个至多 6 个房间的随机办公室上，结果与枚举所有分法一致；在 180 个至多 1000 个房间的随机办公室上，结果与一个独立的已通过实现一致。
