## Задача

Ключ шифра Алисы — последовательность x₁, …, xₙ чисел от 0 до a − 1,
где a — размер алфавита; ключ применяется к буквам сообщения снова и
снова. Ключи, отличающиеся лишь циклическим сдвигом, считаются одним, а
ключи, повторяющие более короткий блок (с периодом меньше n), не
используются. Посчитать различные ключи.

## Входные данные

a и n (1 ≤ a ≤ 26, 1 ≤ n ≤ 10 000).

## Выходные данные

Число ключей, точно.

## Примеры

### Пример 1

Ввод:

```
3 4
```

Вывод:

```
18
```

### Пример 2

Ввод:

```
10 2
```

Вывод:

```
45
```

## Решение

Ключи — это ожерелья длины n над a буквами с периодом ровно n, то есть
слова Линдона. Каждое слово длины n повторяет примитивный блок длины d,
делящей n, так что aⁿ = Σ по d | n от d·L(d), где L(d) — число слов
Линдона длины d (каждое даёт d различных поворотов). Обращение Мёбиуса
превращает это в n·L(n) = Σ по d | n от μ(d)·a^(n/d), где учитываются
только d без квадратов, со знаком (−1) в степени числа их простых
делителей.

У числа до 10 000 не больше пяти различных простых делителей, так что
слагаемых не больше 32, но в a^(n/d) до 14 150 цифр. Python, Go и Java
используют свою длинную арифметику; решения на C++ и Rust хранят числа
в системе по основанию 10⁹, и им нужны только умножение на a, сложение,
вычитание и деление на n: положительные и отрицательные слагаемые
суммируются отдельно и вычитаются один раз. В C++ и Rust каждое слагаемое
строится умножением на a шаг за шагом: всего менее 3n умножений чисел до
1600 разрядов, время O(n^2).

В первом примере из 81 ключа длины 4 у 9 период 2 или 1, а остальные 72
разбиваются на классы поворотов по 4: 18.

Подводные камни:

- при одной букве любой ключ длиннее 1 повторяет сам себя: ответ 0, а
  при n = 1 — 1;
- ответ точный и длинный; в Python 3.12 нужно снять стандартное
  ограничение на вывод длинных чисел.

Ответы совпадают с подсчётом по всем ключам для маленьких a и n и с
независимой принятой реализацией на длинах до 10 000.
