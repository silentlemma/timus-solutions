# 1856. 战争与和平

[Timus 1856](https://acm.timus.ru/problem.aspx?space=1&num=1856) · 难度 3517 · games

原题作者 Fedor Fominykh，出自 2011 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Team.GOV Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

巫妖大军分布在全部 n 个驻地中。两个信号咒语各自同时把每个驻地 i 的部队送往一个固定的驻地：第一个咒语送往 aᵢ，第二个送往 bᵢ。
每天中午 Vidomina 施放其中一个咒语，试图把全军集中到一个驻地；每天午夜 Korbu 施放一个，试图阻止；Vidomina 先手。若双方都采取最优策略，能否集中全军？

## 输入

n（2 ≤ n ≤ 1000），然后是每个驻地的 aᵢ、bᵢ。

## 输出

若 Vidomina 能集中全军，输出 "War"，否则输出 "Peace"。

## 样例

### 样例 1

输入：

```
2
2 1
1 2
```

输出：

```
Peace
```

### 样例 2

输入：

```
2
2 2
2 1
```

输出：

```
War
```

## 解法

有部队的驻地构成一个集合，咒语把它向前映射，而它永远不会变大。全军能集中，当且仅当任意两个驻地都能被强制汇合。若某一对 (u, v) 可以永远保持分开，那么从那里出发的部队永远不会相遇。
若任意一对都能汇合，Vidomina 就取两个有部队的驻地，按这对的策略行动直到它们合并，然后对更少的驻地重复。

因此游戏在对上进行，最多 499 500 对。若 Vidomina 的某个咒语要么直接合并这一对，要么让 Korbu 只剩下会合并它或通向已赢对的回应，则这一对对 Vidomina 来说是赢的。
倒推求解：对每一对及她的每个咒语，统计 Korbu 能使这对保持分开的回应数；对每一对列出通向它的 (对, 咒语) 走法；从存在计数为零的咒语的对开始。
当一对被赢下时，通向它的每个走法少一个开放回应，计数降为零的走法使其所在的对获胜。若所有对都被赢下，答案为 "War"。时间和内存都是 `O(n²)`。

在第一个样例中，两个咒语都是置换，所以两个驻地永远不会合并。在第二个样例中，第一个咒语立刻把两个驻地都送到驻地 2。

注意事项：

- Korbu 的回应本身也可能合并一对；这样的回应不算开放的；
- 逐对汇合之所以可行，是因为有部队的集合不会变大，尽管 Korbu 在其间移动其他部队；
- 以整个集合为状态的空间太大，只看对就足够了。

在三百个最多六个驻地的情形上，答案与对所有驻地集合的博弈搜索一致，在大测试上与一个独立的已通过实现一致。Python 版本在 PyPy 上运行。
