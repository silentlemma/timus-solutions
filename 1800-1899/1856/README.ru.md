# 1856. Война и мир

[Timus 1856](https://acm.timus.ru/problem.aspx?space=1&num=1856) · сложность 3517 · games

Автор оригинальной задачи — Фёдор Фоминых; Ural SU Team.GOV Contest, Петрозаводские летние сборы, август 2011 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Армия личей распределена по всем n гарнизонам. Каждое из двух
сигнальных заклинаний одновременно отправляет войска каждого
гарнизона i в фиксированный гарнизон: aᵢ для первого и bᵢ для второго.
Каждый день в полдень Видомина применяет одно из заклинаний, стараясь
собрать всю армию в одном гарнизоне, а каждую полночь Корбу применяет
одно, стараясь помешать; первой ходит Видомина. Если оба действуют
оптимально, можно ли собрать армию?

## Входные данные

n (2 ≤ n ≤ 1000), затем пары aᵢ, bᵢ для каждого гарнизона.

## Выходные данные

«War», если Видомина может собрать армию, иначе «Peace».

## Примеры

### Пример 1

Ввод:

```
2
2 1
1 2
```

Вывод:

```
Peace
```

### Пример 2

Ввод:

```
2
2 2
2 1
```

Вывод:

```
War
```

## Решение

Занятые гарнизоны образуют множество, которое заклинания отображают
вперёд, и оно никогда не растёт. Армию можно собрать ровно тогда,
когда любую пару гарнизонов можно принудительно свести вместе. Если
какую-то пару (u, v) можно навсегда удержать порознь, войска, начавшие
там, не встретятся никогда. Если любую пару можно свести, Видомина
берёт два занятых гарнизона, следует стратегии для этой пары, пока они
не сольются, и повторяет с меньшим числом занятых гарнизонов.

Значит, игра идёт на парах, которых не больше 499 500. Пара выиграна
для Видомины, если одно из её заклинаний либо сливает пару, либо
оставляет Корбу только ответы, которые сливают её или ведут в уже
выигранные пары. Решаем с конца: для каждой пары и каждого её
заклинания считаем ответы Корбу, держащие пару порознь, для каждой пары
выписываем ходы (пара, заклинание), ведущие в неё, и начинаем с пар,
у которых есть заклинание с нулевым счётчиком. Когда пара выиграна,
каждый ход, ведущий в неё, теряет один открытый ответ, и счётчик,
упавший до нуля, выигрывает свою пару. Ответ — «War», если выиграны все
пары. `O(n²)` по времени и памяти.

В первом примере оба заклинания — перестановки, так что два гарнизона
не сливаются никогда. Во втором первое заклинание сразу отправляет оба
гарнизона в гарнизон 2.

Подводные камни:

- ответ Корбу может сам слить пару; такой ответ не открытый;
- сбор по парам работает, потому что занятое множество не растёт, хотя
  Корбу в промежутках двигает остальные войска;
- пространство состояний из целых множеств слишком велико; пар
  достаточно.

Ответы совпадают с перебором игры по всем множествам гарнизонов на
трёхстах случаях до шести гарнизонов и с независимой принятой
реализацией на больших тестах. Решение на Python работает на PyPy.
