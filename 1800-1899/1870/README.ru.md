## Задача

Расставьте n ферзей на торической доске n × n (верхняя горизонталь
склеена с нижней, левая вертикаль с правой, так что диагонали
замыкаются) так, чтобы никакие два не били друг друга, или сообщите,
что это невозможно.

## Входные данные

n (4 ≤ n ≤ 10⁵).

## Выходные данные

«Yes» и для x = 1, …, n строку ферзя в столбце x; или «No». Подходит
любая верная расстановка.

## Примеры

### Пример 1

Ввод:

```
5
```

Вывод:

```
Yes
2 4 1 3 5
```

### Пример 2

Ввод:

```
8
```

Вывод:

```
No
```

## Решение

Нумеруем строки и столбцы с 0. На торе два ферзя бьют друг друга,
если у них совпадает x, y, x + y mod n или x − y mod n, поэтому каждая
из этих величин должна принять каждое значение по разу.

Если n взаимно просто с 6, ставим ферзя столбца i в строку 2i mod n.
Строки 2i, суммы 3i и разности −i все различны, потому что 2 и 3
обратимы по модулю n.

Иначе расстановки нет. Если n чётно, сложим x + y по всем ферзям.
Суммы принимают каждый остаток по разу, так что итог равен
n(n − 1)/2 ≡ n/2 (mod n). Но он же равен Σx + Σy = n(n − 1) ≡ 0 —
противоречие. Если n делится на 3 (и нечётно), сложим квадраты.
Поскольку (x + y)² + (x − y)² = 2x² + 2y², сумма квадратов S всех
остатков удовлетворяет S + S ≡ 2S + 2S, то есть 2S ≡ 0 (mod n). При
S = (n − 1)n(2n − 1)/6 для этого 3 должно делить (n − 1)(2n − 1), но
оба множителя дают остаток 2 по модулю 3. `O(n)`.

Для первого примера строки, считая с 1, — 1, 3, 5, 2, 4; это другой
верный ответ.

Подводные камни:

- ответ зависит от n по модулю 6, а не от простоты n: для 35
  расстановка есть, для 9 и 8 нет;
- шаг 2 — наименьший подходящий; шаг 1 ставит всех ферзей на одну
  диагональ;
- в выводе до 10⁵ чисел, так что его лучше собирать целиком.

Расстановки проходят чекер для каждого n от 4 до 400 и для самых
больших n, а ответы «No» совпадают с независимой принятой реализацией.
