# 1858. Магический куб

[Timus 1858](https://acm.timus.ru/problem.aspx?space=1&num=1858) · сложность 3590 · bfs

## Задача

Куб с ребром n·l был собран из n³ кубических кристаллов с ребром l. На
соприкасающихся гранях нарисована одна и та же руна, на внешних гранях
рун нет, и каждая руна встречается ровно на двух гранях. Кристаллы
даны по отдельности, каждый в неизвестном повороте, как руны на шести
гранях. Для нескольких пар кристаллов найти расстояние между их
центрами в собранном кубе.

## Входные данные

l и n (1 ≤ l ≤ 100, 2 ≤ n ≤ 30), затем n³ строк по шесть рун от 0 до
10⁹ (0 — нет руны), затем m (1 ≤ m ≤ 10 000) и m пар номеров
кристаллов.

## Выходные данные

Расстояние для каждой пары с абсолютной или относительной погрешностью
не более 10⁻⁶.

## Примеры

### Пример 1

Ввод:

```
1 2
0 8 73 0 0 16
0 9 0 73 0 1000
0 146 4 0 16 0
0 15 0 4 1000 0
146 0 1 0 6 0
15 0 0 1 2 0
8 0 17 0 0 6
9 0 0 17 0 2
2
1 5
2 8
```

Вывод:

```
1.4142135
1
```

## Решение

Повороты кристаллов вообще не важны. Если соединить каждые два
кристалла с общей руной, получится граф решётки куба n × n × n, а в
графе решётки число шагов между двумя клетками равно сумме разностей их
координат. Этого достаточно, чтобы восстановить координаты.

Кристалл с наименьшим числом соседей — угол c; назовём его началом
координат. Поиск в ширину из него даёт каждому кристаллу его x + y + z.
Остальные углы удалены на n − 1, 2(n − 1) или 3(n − 1) шагов, так что
углы ровно в n − 1 шагах от c — три его соседа по рёбрам куба, скажем в
(n − 1, 0, 0), (0, n − 1, 0) и (0, 0, n − 1). Поиск из первого даёт
(n − 1 − x) + y + z, откуда x = (d(c, v) − d(cₓ, v) + n − 1)/2, и так же
для y и z. Четыре поиска по n³ ≤ 27 000 кристаллам расставляют все, с
точностью до симметрии куба, сохраняющей расстояния. Каждый ответ —
l·√(Δx² + Δy² + Δz²). `O(n³ + m)`.

В примере ребро куба 2. Кристалл 1 делит руны с кристаллами 2, 3 и 7, а
кристалл 5 не делит с ним ни одной, но у них два общих соседа, так что
они стоят на диагонали грани: √2. Кристаллы 2 и 8 делят руну 9, так что
соприкасаются: 1.

Подводные камни:

- повороты кристаллов только отвлекают: важен лишь граф касаний;
- при n = 2 каждый кристалл — угол, и углы рядом с c — это его прямые
  соседи, которых находит то же правило;
- руны доходят до 10⁹, поэтому нужна хеш-таблица, а не массив.

Расстояния совпадают с независимой принятой реализацией на шестидесяти
маленьких кубах и на кубах с ребром 30 и десятью тысячами вопросов.
