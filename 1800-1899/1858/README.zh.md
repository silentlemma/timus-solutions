# 1858. 魔方块

[Timus 1858](https://acm.timus.ru/problem.aspx?space=1&num=1858) · 难度 3556 · bfs

原题作者 Mikhail Rubinchik（由 Denis Mukhametianov 准备），出自 2011 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Team.GOV Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个边长为 n·l 的立方体由 n³ 个边长为 l 的立方体晶体拼成。相接触的两个面上画着同一个符文，外表面上没有符文，每个符文恰好出现在两个面上。晶体被分开给出，每个处于未知的转向，用六个面上的符文描述。对若干对晶体，求它们在拼好的立方体中中心之间的距离。

## 输入

l 和 n（1 ≤ l ≤ 100，2 ≤ n ≤ 30），然后是 n³ 行，每行六个 0 到 10⁹ 的符文（0 表示没有符文），然后是 m（1 ≤ m ≤ 10 000）和 m 对晶体编号。

## 输出

每对的距离，绝对或相对误差不超过 10⁻⁶。

## 样例

### 样例 1

输入：

```
1 2
0 8 73 0 0 16
0 9 0 73 0 1000
0 146 4 0 16 0
0 15 0 4 1000 0
146 0 1 0 6 0
15 0 0 1 2 0
8 0 17 0 0 6
9 0 0 17 0 2
2
1 5
2 8
```

输出：

```
1.4142135
1
```

## 解法

晶体的转向完全无关紧要。把每两个共享符文的晶体连起来，就得到 n × n × n 立方体的网格图，而在网格图中两个格子之间的最短步数等于它们坐标差的绝对值之和。这足以恢复坐标。

邻居最少的晶体是一个角 c，把它作为原点。从它出发做一次广度优先搜索，就得到每个晶体的 x + y + z。其他角与它相距 n − 1、2(n − 1) 或 3(n − 1) 步，所以与 c 恰好相距 n − 1 步的角，就是它沿立方体棱的三个邻角，不妨设为 (n − 1, 0, 0)、(0, n − 1, 0) 和 (0, 0, n − 1)。
从第一个出发搜索得到 (n − 1 − x) + y + z，于是 x = (d(c, v) − d(cₓ, v) + n − 1)/2，y 和 z 同理。对最多 27 000 个晶体做四次搜索即可放好所有晶体，只差一个保持距离不变的立方体对称。每个答案为 l·√(Δx² + Δy² + Δz²)。`O(n³ + m)`。

在样例中立方体边长为 2。晶体 1 与晶体 2、3、7 共享符文，晶体 5 与它不共享符文，但它们有两个公共邻居，所以位于某个面的对角线上：√2。晶体 2 和 8 共享符文 9，所以相接触：1。

注意事项：

- 晶体的转向只是干扰：只有接触图才重要；
- n = 2 时每个晶体都是角，与 c 相邻的角就是它的直接邻居，同一规则可以找到；
- 符文最大到 10⁹，所以需要哈希表而不是数组。

在六十个小立方体和边长 30、一万个询问的立方体上，距离与一个独立的已通过实现一致。
