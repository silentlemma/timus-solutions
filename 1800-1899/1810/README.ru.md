# 1810. Антиуравнения

[Timus 1810](https://acm.timus.ru/problem.aspx?space=1&num=1810) · сложность 4022 · math

Оригинальная задача — Tavrida NU Akai Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Посчитать векторы x из {0, 1, 2}ⁿ, для которых каждая из k линейных
форм по модулю 3 отличается от заданного значения:
aᵢ₁x₁ + … + aᵢₙxₙ ≢ bᵢ (mod 3) для всех i.

## Входные данные

k и n (1 ≤ k, n ≤ 30), затем k строк aᵢ₁ … aᵢₙ bᵢ со значениями от 0
до 2.

## Выходные данные

Число решений.

## Примеры

### Пример 1

Ввод:

```
3 3
2 2 1 1
2 1 0 0
1 2 2 2
```

Вывод:

```
8
```

### Пример 2

Ввод:

```
4 3
2 2 1 1
2 1 0 0
1 2 2 2
1 0 1 2
```

Вывод:

```
6
```

## Решение

Смотрим на y = Ax вместо x. Если ранг A над GF(3) равен r, каждый y из
образа A получается ровно из 3^(n−r) векторов x, так что ответ — это
3^(n−r), умноженное на число векторов образа с yᵢ ≠ bᵢ для всех i.
Метод Гаусса на транспонированной матрице даёт базис её ядра — векторы
w, ортогональные каждому столбцу; y лежит в образе ровно тогда, когда
его синдром, список произведений w·y, нулевой.

У каждого yᵢ два допустимых значения, поэтому кандидатов y всего
2ᵏ ≤ 2³⁰ — слишком много для перебора, но они делятся на две половины
не более чем по 2¹⁵ вариантов. Синдром аддитивен: выписываем синдромы
всех вариантов первой половины, а для каждого варианта второй половины
считаем синдромы первой, равные минус его синдрому. Синдром над GF(3)
из не более чем 30 координат хранится двумя битовыми масками —
координаты, равные 1, и равные 2. Тогда сложение — несколько побитовых
операций, а смена знака меняет маски местами. `O(nk min(n,k) + 2^(k/2) · k)`.

В первом примере 8 из 27 наборов обходят все три значения; второй
пример добавляет ещё одно антиуравнение и оставляет 6.

Подводные камни:

- одинаковые или пропорциональные строки зависимы; у каждого вектора
  образа несколько прообразов ровно при r < n;
- нулевая строка с bᵢ = 0 исключает всё;
- ответ может доходить до 3³⁰, нужны 64 бита.

Ответы совпадают с прямым подсчётом по всем 3ⁿ наборам на 100
маленьких системах и с независимой принятой реализацией на квадратных,
малоранговых, повторяющихся и узких системах из 30 антиуравнений.
