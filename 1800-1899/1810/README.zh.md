# 1810. 反方程

[Timus 1810](https://acm.timus.ru/problem.aspx?space=1&num=1810) · 难度 4022 · math

原题出自 Tavrida NU Akai Contest，2010 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

统计 {0, 1, 2}ⁿ 中的向量 x 的个数，使 k 个模 3 线性形式都与给定值不同：对所有 i，aᵢ₁x₁ + … + aᵢₙxₙ ≢ bᵢ (mod 3)。

## 输入

k 和 n（1 ≤ k, n ≤ 30），然后是 k 行 aᵢ₁ … aᵢₙ bᵢ，取值为 0 到 2。

## 输出

解的个数。

## 样例

### 样例 1

输入：

```
3 3
2 2 1 1
2 1 0 0
1 2 2 2
```

输出：

```
8
```

### 样例 2

输入：

```
4 3
2 2 1 1
2 1 0 0
1 2 2 2
1 0 1 2
```

输出：

```
6
```

## 解法

改为考虑 y = Ax。若 A 在 GF(3) 上的秩为 r，则 A 的像中的每个 y 恰好来自 3^(n−r) 个向量 x，所以答案是 3^(n−r) 乘以满足对所有 i 有 yᵢ ≠ bᵢ 的像向量个数。
对转置矩阵做高斯消元得到其零空间的一组基，即与每一列都正交的向量 w；y 位于像中当且仅当它的校验子（各个乘积 w·y 组成的列表）为零。

每个 yᵢ 有两个允许的值，所以候选 y 共有 2ᵏ ≤ 2³⁰ 个，无法逐一尝试，但可以分成两半，每半至多 2¹⁵ 种选择。校验子是可加的：列出前一半所有选择的校验子，
对后一半的每种选择，统计前一半中等于其校验子相反数的个数。GF(3) 上至多 30 个坐标的校验子用两个位掩码保存：等于 1 的坐标和等于 2 的坐标。
这样加法只需几次位运算，取负就是交换两个掩码。`O(nk min(n,k) + 2^(k/2) · k)`。

第一个样例中 27 种取值里有 8 种避开了所有三个值；第二个样例再加一个反方程，剩下 6 种。

注意事项：

- 相同或成比例的行线性相关；每个像向量有多个原像当且仅当 r < n；
- 全零行且 bᵢ = 0 时任何取值都不行；
- 答案可达 3³⁰，需要 64 位整数。

在 100 个小系统上，答案与对全部 3ⁿ 种取值的直接计数一致；在 30 个反方程的方阵、低秩、重复和窄系统上，与一个独立的已通过实现一致。
