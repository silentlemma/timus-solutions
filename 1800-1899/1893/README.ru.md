# 1893. A380

[Timus 1893](https://acm.timus.ru/problem.aspx?space=1&num=1893) · сложность 60 · implementation

Автор оригинальной задачи — Денис Дублённых; NEERC 2011, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Определите расположение одного допустимого места по номеру ряда
и букве. Схема зависит от ряда:

| Ряды | Буквы мест по порядку | Проходы между |
| --- | --- | --- |
| 1–2 | A B C D | A/B и C/D |
| 3–20 | A B C D E F | B/C и D/E |
| 21–65 | A B C D E F G H J K | C/D и G/H |

Первое и последнее места каждого ряда находятся у окна. Места
с обеих сторон прохода находятся у прохода. Выведите `window` для
места у окна; иначе `aisle` для места у прохода либо `neither` для
остальных мест. Проверка окна имеет приоритет.

Ограничения: 1 секунда и 64 МБ.

## Входные данные

Одно обозначение места: номер ряда и сразу за ним прописная буква,
например `3C`. Номер ряда от 1 до 65, буква допустима для данного
ряда. В рядах эконом-класса буква I пропущена.

## Выходные данные

Выведите одно слово: `window`, `aisle` или `neither`.

## Проверка

Ответы сравниваются по последовательностям токенов.

## Примеры

### Пример 1

Ввод:

```
3C
```

Вывод:

```
aisle
```

### Пример 2

Ввод:

```
64A
```

Вывод:

```
window
```

### Пример 3

Ввод:

```
21F
```

Вывод:

```
neither
```

## Решение

Последний символ задаёт букву, предшествующие цифры — номер ряда.
Выберем один из трёх диапазонов и воспользуемся таблицей:

| Ряды | `window` | `aisle` | `neither` |
| --- | --- | --- | --- |
| 1–2 | A D | B C | нет |
| 3–20 | A F | B C D E | нет |
| 21–65 | A K | C D G H | B E F J |

Эти множества следуют из расположения краёв ряда и соседей каждого
прохода. В рядах 1–2 места A и D находятся и у окна, и у прохода;
приоритет окна даёт именно указанную классификацию. Каждая допустимая
буква получает требуемый результат.

Число проверок и длина входа ограничены константами, поэтому время
и дополнительная память — `O(1)`.

В примерах в ряду 3 проход находится между B и C, поэтому ответ
для `3C` — `aisle`. Место `64A` расположено у левого окна. Место `21F`
находится внутри среднего блока между проходами и не примыкает
ни к одному из них, поэтому ответ — `neither`.

Подводные камни:

- на границах 2/3 и 20/21 схема меняется;
- буква правого места у окна меняется с D на F, затем на K;
- в рядах 21–65 нет места I;
- сначала проверять окна, особенно для A и D в рядах 1–2.

Ответы совпадают с отдельной моделью схемы салона на всех 566 допустимых
местах.

## Особенности языков

Все пять версий разбирают цифры перед последней ASCII-буквой как
номер ряда и используют одну классификацию постоянного размера. В Go
и Rust допустима индексация по байтам: вход содержит только десятичные
цифры и одну прописную английскую букву.

Java читает этот единственный короткий токен через `Scanner`. Специальный
быстрый ввод и большие целые не нужны; проверка принадлежности затрагивает
только фиксированные наборы букв мест.
