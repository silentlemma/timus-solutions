# 1893. A380

[Timus 1893](https://acm.timus.ru/problem.aspx?space=1&num=1893) · сложность 60 · implementation

Автор оригинальной задачи — Денис Дублённых; NEERC 2011, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Определите расположение одного допустимого места по номеру ряда
и букве. Схема зависит от ряда:

| Ряды | Буквы мест по порядку | Проходы между |
| --- | --- | --- |
| 1–2 | A B C D | A/B и C/D |
| 3–20 | A B C D E F | B/C и D/E |
| 21–65 | A B C D E F G H J K | C/D и G/H |

Первое и последнее места каждого ряда находятся у окна. Места
с обеих сторон прохода находятся у прохода. Выведите `window` для
места у окна; иначе `aisle` для места у прохода либо `neither` для
остальных мест. Проверка окна имеет приоритет.

Ограничения: 1 секунда и 64 МБ.

## Входные данные

Одно обозначение места: номер ряда и сразу за ним прописная буква,
например `3C`. Номер ряда от 1 до 65, буква допустима для данного
ряда. В рядах эконом-класса буква I пропущена.

## Выходные данные

Выведите одно слово: `window`, `aisle` или `neither`.

## Проверка

Ответы сравниваются по последовательностям токенов.

## Примеры

Ввод:

```
3C
```

Вывод:

```

```

### Пример 2

Ввод:

```

```

Вывод:

```

### Пример 3

```

```

```

## Решение

Ряд — это число перед последним символом, место — последняя буква. В
самолёте три схемы рядов, и каждая задаёт, какие места у окна, а какие у
прохода:

| Ряды | `window` | `aisle` | `neither` |
| --- | --- | --- | --- |
| 1–2 | A D | B C | нет |
| 3–20 | A F | B C D E | нет |
| 21–65 | A K | C D G H | B E F J |

В рядах 1–2 места A и D примыкают и к окну, и к проходу; окно важнее,
поэтому это `window`. `O(1)`.

Подводные камни:

- схема меняется после 2-го и после 20-го ряда;
- в рядах 21–65 нет места I.

## Оптимизированные решения

`1893_implementation_optimized.py`. Сохраняются три схемы и приоритет окна. Ряд разбирается из байтов, конечный однобайтовый срез сравнивается без декодирования места. В экономклассе нет I, у окон A/K. Классификация O(1), чтение L байтов требует O(L) времени/памяти. Читаемая текстовая версия сохранена.

Повторно используется точный исторический исходник CPython 3.12 с Accepted №11302157: 0.078 с / 436 КБ. В сохранённой сопоставимой выборке компиляторов от 2026-11-20 место по времени 1/91, по памяти 30/91. При памяти меньше 1024 КБ строгий критерий учитывает только время и пройден. Звёздочка относится к отдельной рейтинговой цели языка. Это парные измерения данного исходника, не новая посылка и не гарантия ускорения на другой платформе. Версия использует обычное завершение интерпретатора.

- `1893_implementation_optimized.py`: 0.078 s / 436 KB; сохранённая учебная база `1893_implementation.py` (Python 3.12 x64): 0.109 s / 468 KB. Указаны оба измерения базы, в том числе при росте одной метрики.

Оптимизированное решение на C++ читает место через `scanf("%d%c")` и
печатает через `puts` вместо `iostream` и `std::string`: 120 КБ вместо
348 КБ. Схемы рядов те же.

Оптимизированное решение на Java читает место побайтно: цифры дают ряд,
следующий байт — букву, вместо чтения строки: 0.109 с вместо 0.156 с и
380 КБ вместо 1580 КБ.

## Особенности языков

Новые исходники сравниваются по срезу от 18 ноября 2026 года с другими авторами на текущих компиляторах судьи. Порогов по ID посылки или дате нет. Ничьи делят место, времена меньше 0.015 с при сравнении считаются 0.015 с. Приведённые ниже места относятся к новым версиям; прежние исходники сохраняют собственные исторические метрики Accepted.

Звёздочка означает недостигнутую рейтинговую цель: для C++ нужны первые десять мест либо топ 15% одновременно по обеим метрикам; для остальных семейств — первое место по обеим. Отдельный критерий допуска может выполняться по рейтингу или улучшению, в том числе при снижении времени либо памяти минимум на 30%.
