# 1893. A380

[Timus 1893](https://acm.timus.ru/problem.aspx?space=1&num=1893) · сложность 60 · implementation

Автор оригинальной задачи — Денис Дублённых; NEERC 2011, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Определите расположение одного допустимого места по номеру ряда
и букве. Схема зависит от ряда:

| Ряды | Буквы мест по порядку | Проходы между |
| --- | --- | --- |
| 1–2 | A B C D | A/B и C/D |
| 3–20 | A B C D E F | B/C и D/E |
| 21–65 | A B C D E F G H J K | C/D и G/H |

Первое и последнее места каждого ряда находятся у окна. Места
с обеих сторон прохода находятся у прохода. Выведите `window` для
места у окна; иначе `aisle` для места у прохода либо `neither` для
остальных мест. Проверка окна имеет приоритет.

Ограничения: 1 секунда и 64 МБ.

## Входные данные

Одно обозначение места: номер ряда и сразу за ним прописная буква,
например `3C`. Номер ряда от 1 до 65, буква допустима для данного
ряда. В рядах эконом-класса буква I пропущена.

## Выходные данные

Выведите одно слово: `window`, `aisle` или `neither`.

## Проверка

Ответы сравниваются по последовательностям токенов.

## Примеры

### Пример 1

Ввод:

```
3C
```

Вывод:

```
aisle
```

### Пример 2

Ввод:

```
64A
```

Вывод:

```
window
```

### Пример 3

Ввод:

```
21F
```

Вывод:

```
neither
```

## Решение

Ряд — это число перед последним символом, место — последняя буква. В
самолёте три схемы рядов, и каждая задаёт, какие места у окна, а какие у
прохода:

| Ряды | `window` | `aisle` | `neither` |
| --- | --- | --- | --- |
| 1–2 | A D | B C | нет |
| 3–20 | A F | B C D E | нет |
| 21–65 | A K | C D G H | B E F J |

В рядах 1–2 места A и D примыкают и к окну, и к проходу; окно важнее,
поэтому это `window`. `O(1)`.

Подводные камни:

- схема меняется после 2-го и после 20-го ряда;
- в рядах 21–65 нет места I.

## Оптимизированные решения

Оптимизированное решение на C++ читает место через `scanf("%d%c")` и
печатает через `puts` вместо `iostream` и `std::string`: 120 КБ вместо
348 КБ. Схемы рядов те же.

Оптимизированное решение на Java читает место побайтно: цифры дают ряд,
следующий байт — букву, вместо чтения строки: 0.109 с вместо 0.156 с и
380 КБ вместо 1580 КБ.
