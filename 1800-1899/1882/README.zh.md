# 1882. 老诺基亚

[Timus 1882](https://acm.timus.ru/problem.aspx?space=1&num=1882) · 难度 2585 · shortest_paths

原题作者 Mikhail Rubinchik，出自 2011 年乌拉尔地区团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

电话簿中有 n 个按字母序排列的不同名字；一开始全部显示，当前名字是第一个。"上"和"下"在显示的名字中循环移动。输入一个字母后只显示以已输入字母开头的名字，并把其中第一个设为当前；没有任何名字能接上的字母不会被接受。删除最后一个字母时当前名字不变，并显示所有以较短开头开头的名字。每按一次键用一秒；一个字母需要按的次数等于它在标准手机键盘（abc、def、ghi、jkl、mno、pqrs、tuv、wxyz）按键上的位置。对每个名字，求把它变为当前名字的最短时间。

## 输入

n（1 ≤ n ≤ 10⁵），然后是按字母序排列的小写名字，总长度不超过 10⁵。

## 输出

每个名字的最短时间。

## 样例

### 样例 1

输入：

```
5
a
aaa
aab
b
d
```

输出：

```
0 1 2 2 1
```

## 解法

一个局面是一对：已输入的字母（当前名字必须以它开头）和当前名字 x。于是已输入的字母就是 x 的前 d 个字母，这一对可写成 (x, d)，总数为 Σ (|x| + 1) ≤ 2·10⁵。按排序后的顺序，具有给定开头的名字构成一个区间，即字典树某结点的子树。"下"和"上"在这个区间里循环移到下一个或上一个名字，耗时一秒。删除转到 (x, d − 1)，耗时一秒。输入字母 c 转到子结点的第一个名字，与 x 无关。因此每个结点设一个枢纽顶点：每一对免费到达其结点的枢纽，枢纽以字母的代价通往每个子结点的第一个名字。边权在 0 到 4 之间，所以 Dijkstra 用环形的五个桶即可。x 的答案是它所有局面中的最小距离。总长度为 L 时 `O(n + L)`。

样例中 "d" 从 "a" 按一次"上"，"b" 按两次；"aab" 从 "a" 按两次"下"，先输入 "a" 并没有帮助。

注意事项：

- 删除时当前名字不变，所以一条路线可以先输入字母、在短列表中移动、删除后再移动；
- 从第一个显示的名字按"上"会到最后一个，所以靠后的名字代价很小；
- 字母的代价是它在按键上的位置，s 和 z 高达 4，所以移动可能比输入更划算；
- 输入字母的边与当前名字无关，枢纽正是利用这一点使图保持线性规模。

在 1500 个小规模随机电话簿上，时间与对（已输入字母，当前名字）状态的搜索一致；在大数据上与一个独立的已通过实现一致。
