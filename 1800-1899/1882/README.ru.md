## Задача

В телефонном справочнике n различных имён по алфавиту; сначала видны
все, а текущее — первое. «Вверх» и «вниз» переходят по видимым именам
по кругу. Набор буквы оставляет видимыми только имена, начинающиеся с
набранных букв, и делает текущим первое из них; буква, которой не
продолжается ни одно имя, не принимается. Стирание последней буквы
сохраняет текущее имя и показывает все имена с более коротким началом.
Нажатие кнопки — секунда; буква стоит столько нажатий, каково её место
на клавише обычной телефонной клавиатуры (abc, def, ghi, jkl, mno,
pqrs, tuv, wxyz). Для каждого имени найдите наименьшее время, за
которое его можно сделать текущим.

## Входные данные

n (1 ≤ n ≤ 10⁵), затем имена по алфавиту из строчных букв суммарной
длины не больше 10⁵.

## Выходные данные

Наименьшее время для каждого имени.

## Примеры

### Пример 1

Ввод:

```
5
a
aaa
aab
b
d
```

Вывод:

```
0 1 2 2 1
```

## Решение

Положение — пара: набранные буквы, с которых должно начинаться текущее
имя, и само текущее имя x. Тогда набранные буквы — первые d букв x, и
пара записывается как (x, d); всего их Σ (|x| + 1) ≤ 2·10⁵. В
отсортированном порядке имена с заданным началом образуют отрезок —
поддерево узла бора. «Вниз» и «вверх» переходят к следующему или
предыдущему имени этого отрезка по кругу за секунду. Стирание ведёт в
(x, d − 1) за секунду. Набор буквы c ведёт к первому имени дочернего
узла, каким бы ни было x. Поэтому у каждого узла есть вершина-хаб:
каждая пара попадает в хаб своего узла бесплатно, а хаб ведёт к
первому имени каждого ребёнка за стоимость буквы. Веса рёбер от 0 до
4, так что Дейкстра работает с пятью корзинами по кругу. Ответ для x —
наименьшее расстояние среди его пар. `O(n + L)` для суммарной длины L.

В примере «d» — одно нажатие «вверх» от «a», а «b» — два; «aab» — два
нажатия «вниз» от «a», и набор «a» сначала не помогает.

Подводные камни:

- стирание сохраняет текущее имя, так что путь может набрать буквы,
  пройти по короткому списку, стереть и идти дальше;
- «вверх» от первого видимого имени переходит к последнему, так что
  последние имена дешёвые;
- буква стоит своё место на клавише, до 4 у s и z, поэтому шаги могут
  оказаться выгоднее набора;
- рёбра набора буквы не зависят от текущего имени, и хабы пользуются
  этим, чтобы граф оставался линейным.

Время совпадает с перебором состояний (набранные буквы, текущее имя) на
1500 малых случайных справочниках и с независимой принятой реализацией
на больших.
