# 1809. 恰巴耶夫与土豆

[Timus 1809](https://acm.timus.ru/problem.aspx?space=1&num=1809) · 难度 598 · implementation

原题作者 Dmitry Ivankov，出自 NEERC 2010 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

四个土豆放在 20 × 20 棋盘的不同格子上。若两个土豆在同一行或同一列且中间没有别的土豆，一个就能射击另一个。移动尽可能少的土豆到空格上，使每个土豆恰好能射击另外一个。

## 输入

四行，每行是一个土豆的坐标 x 和 y，范围 1 到 20。

## 输出

按相同顺序输出新坐标。任何最优答案都可以。

## 样例

### 样例 1

输入：

```
1 1
2 2
4 4
4 3
```

输出：

```
1 2
2 2
4 4
4 3
```

## 解法

目标是让“能射击”关系把四个土豆分成两对。先检查原样的布局。否则尝试把一个土豆移到 400 个格子中的每一个。再不行的话，两次移动总是足够的。
若保留的两个土豆互相能看到，另外两个可以在保留土豆不占用的一行和列中自成一对。若看不到，每个被移动的土豆可以放在某个保留土豆旁边。
所以对每种“移动哪两个”的选择，只需尝试保留土豆旁边的格子和那一对单独的位置。对 20000 个随机布局的压力测试中，这一步从未落空。`O(1)`。

样例中第二对 (4, 4) 和 (4, 3) 已经符合要求，把第一个土豆移到 (1, 2) 就与 (2, 2) 成对。

注意事项：

- 两个土豆之间的土豆会挡住射击，所以一条线上的四个土豆不能成对；
- 一个土豆不能看到超过一个，所以一对不能与另一对共线；
- 被移动的土豆必须放在棋盘内的空格上。

检查器检验布局，并把移动土豆的个数与期望答案比较。所有解答在随机布局、拥挤的角落、一条直线以及接近正确的布局上都能通过检查，并与一个枚举所有格子对的独立已通过实现对照。
