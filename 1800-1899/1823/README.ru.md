# 1823. Идеальный газ

[Timus 1823](https://acm.timus.ru/problem.aspx?space=1&num=1823) · сложность 348 · math

Авторы оригинальной задачи — Бенуа Поль Эмиль Клапейрон и Дмитрий Менделеев; XII открытое личное первенство УрГУ, 19 марта 2011 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Уравнение состояния идеального газа pV = nRT связывает давление p,
количество вещества n, объём V и температуру T, где R = 8.314. Даны три
величины из четырёх; найти четвёртую. Объём и температура должны быть
положительны. Вывести «error», если данные противоречивы, и
«undefined», если значение определяется неоднозначно.

## Входные данные

Три строки «X = value» для трёх разных величин X из p, n, V и T, каждое
значение — неотрицательное целое не больше 1000. Данные V и T
положительны.

## Выходные данные

«X = value» с абсолютной или относительной погрешностью не больше
10⁻⁶, либо «error», либо «undefined».

## Примеры

### Пример 1

Ввод:

```
p = 1
n = 1
V = 1
```

Вывод:

```
T = 0.120279
```

## Решение

Выражаем недостающую величину из pV = nRT; данные значения целые,
поэтому все проверки на ноль точны.

- p = nRT/V и n = pV/(RT): V и T даны и положительны, так что результат
  всегда определён, возможно, равен 0.
- V = nRT/p: при p = 0 уравнение превращается в 0 = nRT, что верно для
  любого V при n = 0 («undefined») и ни для какого при n > 0
  («error»). При p > 0 и n = 0 объём вышел бы 0, что недопустимо
  («error»).
- T = pV/(nR) разбирается так же, с n вместо p.

Используем R = 8314/1000 и представляем результат точной целой дробью
a/b. Целочисленной арифметикой округляем её до шести знаков после
запятой, при равенстве округляя вверх, затем выводим целую и шестизначную
дробную части с явной десятичной точкой. В Java для цифр используется
`Locale.ROOT`. Абсолютная погрешность округления не превышает 0.0000005;
при данных ограничениях все промежуточные значения помещаются в знаковый
64-битный тип.

`O(1)`.

В примере T = 1·1/(1·8.314) ≈ 0.120279.

Подводные камни:

- нулевое давление или нулевое количество вещества допустимы и служат
  ответом, когда неизвестны p или n;
- вычисленные нулевые объём или температура — ошибка, а не ответ;
- строки могут идти в любом порядке;
- числовой вывод не должен зависеть от системной локали: тест 15
  выявляет стандартное форматирование Java, которое может вывести
  `0,000000` вместо `0.000000`.
