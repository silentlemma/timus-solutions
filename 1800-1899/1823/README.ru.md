# 1823. Идеальный газ

[Timus 1823](https://acm.timus.ru/problem.aspx?space=1&num=1823) · сложность 348 · math

Авторы оригинальной задачи — Бенуа Поль Эмиль Клапейрон и Дмитрий Менделеев; XII открытое личное первенство УрГУ, 19 марта 2011 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Уравнение состояния идеального газа pV = nRT связывает давление p,
количество вещества n, объём V и температуру T, где R = 8.314. Даны три
величины из четырёх; найти четвёртую. Объём и температура должны быть
положительны. Вывести «error», если данные противоречивы, и
«undefined», если значение определяется неоднозначно.

## Входные данные

Три строки «X = value» для трёх разных величин X из p, n, V и T, каждое
значение — неотрицательное целое не больше 1000. Данные V и T
положительны.

## Выходные данные

«X = value» с абсолютной или относительной погрешностью не больше
10⁻⁶, либо «error», либо «undefined».

## Проверка

Тесты репозитория сравнивают числовые токены по условию |ответ-эталон| <= 1e-6·max(1,|эталон|), отклоняют бесконечности и NaN, а нечисловые токены сравнивают точно.

## Примеры

### Пример 1

Ввод:

```
p = 1
n = 1
V = 1
```

Вывод:

```
T = 0.120279
```

## Решение

Выражаем недостающую величину из pV = nRT; данные значения целые,
поэтому все проверки на ноль точны.

- p = nRT/V и n = pV/(RT): V и T даны и положительны, так что результат
  всегда определён, возможно, равен 0.
- V = nRT/p: при p = 0 уравнение превращается в 0 = nRT, что верно для
  любого V при n = 0 («undefined») и ни для какого при n > 0
  («error»). При p > 0 и n = 0 объём вышел бы 0, что недопустимо
  («error»).
- T = pV/(nR) разбирается так же, с n вместо p.

Используем R = 8314/1000 и представляем результат точной целой дробью
a/b. Целочисленной арифметикой округляем её до шести знаков после
запятой, при равенстве округляя вверх, затем выводим целую и шестизначную
дробную части с явной десятичной точкой. В Java для цифр используется
`Locale.ROOT`. Абсолютная погрешность округления не превышает 0.0000005;
при данных ограничениях все промежуточные значения помещаются в знаковый
64-битный тип.

`O(1)`.

В примере T = 1·1/(1·8.314) ≈ 0.120279.

Подводные камни:

- нулевое давление или нулевое количество вещества допустимы и служат
  ответом, когда неизвестны p или n;
- вычисленные нулевые объём или температура — ошибка, а не ответ;
- строки могут идти в любом порядке;
- числовой вывод не должен зависеть от системной локали: тест 15
  выявляет стандартное форматирование Java, которое может вывести
  `0,000000` вместо `0.000000`.

## Оптимизированные решения

`1823_math_optimized.java`. Сохраняется точная целочисленная формула идеального газа с R=8314/1000 и шестью дробными знаками. HashMap заменён четырьмя long, значение -1 обозначает отсутствующую неотрицательную величину. При неизвестных V или T до деления различаются 0=0 (undefined) и единственный нулевой множитель (error); заданные V,T положительны. Рациональное значение округляется половиной вверх в масштабе10^6 и выводится цифрами с шестью дробными позициями и ведущими нулями, без printf/locale. Наибольший масштабированный числитель не больше 8.314·10^15 и помещается в long. Время и состояние арифметики O(1) плюс фиксированные байтовые буферы.

По сравнению с `1823_math.java`: время 0.093 s → 0.078 s; память 1736 KB → 504 KB.

`1823_math_optimized.py`. Уравнение идеального газа и все ветви ноль/undefined/error полностью сохранены. R=8314/1000 и целочисленное округление половины вверх до шести знаков прежние, плавающих приближений нет. Меняются лишь сырой ввод, декодирование ASCII и завершение интерпретатора. Ввод требует O(I) работы и памяти, арифметических операций ограниченного размера фиксированное число. Перед os._exit(0) ответ сбрасывается. Допуск даёт измеренная память собственной среды, а не новый алгоритм уравнения газа.

По сравнению с `1823_math.py`: время 0.078 s → 0.125 s; память 572 KB → 284 KB.

Go и Rust хранят p, V, n и T в четырёх фиксированных ячейках и выделяют неизвестное из 1000pV = 8314nT целочисленной арифметикой. Нулевые числитель и знаменатель дают undefined. Нулевой знаменатель или вынужденный нулевой объём либо температура дают error. Иначе дробь округляется до шести знаков 64-битными целыми.

Принятые базовые реализации [1823_math.cpp](1823_math.cpp), [1823_math.java](1823_math.java), [1823_math.py](1823_math.py) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.

## Особенности языков

Новые исходники сравниваются по срезу от 18 ноября 2026 года с другими авторами на текущих компиляторах судьи. Порогов по ID посылки или дате нет. Ничьи делят место, времена меньше 0.015 с при сравнении считаются 0.015 с. Учебные алгоритмы сохранены. Перепроверенные базовые версии используют собственные новые метрики и ID Accepted точного исходника; эти проверки не считаются оптимизациями.

`1823_math_optimized.java`: место по времени 1/18, по памяти 1/18 в этой сопоставимой выборке.

`1823_math_optimized.py`: место по времени 11/17, по памяти 1/17 в этой сопоставимой выборке.

Звёздочка означает недостигнутую рейтинговую цель: для C++ нужны первые десять мест либо топ 15% одновременно по обеим метрикам; для остальных семейств — первое место по обеим. Отдельный критерий допуска может выполняться по рейтингу или улучшению, в том числе при снижении времени либо памяти минимум на 30%.
