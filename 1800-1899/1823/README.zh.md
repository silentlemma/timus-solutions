# 1823. 理想气体

[Timus 1823](https://acm.timus.ru/problem.aspx?space=1&num=1823) · 难度 348 · math

原题作者署名为 Benoît Paul Émile Clapeyron 和 Dmitri Mendeleev，出自 2011 年 3 月 19 日第十二届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

理想气体状态方程 pV = nRT 联系压强 p、物质的量 n、体积 V 和温度 T，其中 R = 8.314。给出四个量中的三个，求第四个。
体积和温度必须为正。若数据矛盾输出 "error"，若该值不能唯一确定则输出 "undefined"。

## 输入

三行 "X = value"，X 是 p、n、V、T 中三个不同的量，每个值都是不超过 1000 的非负整数。给出的 V 和 T 为正。

## 输出

"X = value"，绝对或相对误差不超过 10⁻⁶；或者 "error"；或者 "undefined"。

## 样例

### 样例 1

输入：

```
p = 1
n = 1
V = 1
```

输出：

```
T = 0.120279
```

## 解法

从 pV = nRT 中解出缺少的量；给出的值都是整数，所以所有判零都是精确的。

- p = nRT/V 和 n = pV/(RT)：V 和 T 已给出且为正，结果总是确定的，可能为 0。
- V = nRT/p：若 p = 0，方程变成 0 = nRT，当 n = 0 时对任意 V 成立（"undefined"），当 n > 0 时对任何 V 都不成立（"error"）。若 p > 0 且 n = 0，V 将为 0，这不允许（"error"）。
- T = pV/(nR) 同理，把 p 换成 n。

使用 R = 8314/1000，将结果保留为精确的整数分数 a/b。用整数运算将其舍入到小数点后六位，恰好一半时向上舍入，再用固定的小数点输出整数部分和六位小数部分。Java 使用 `Locale.ROOT` 格式化数字。绝对舍入误差不超过 0.0000005；在输入范围内，所有中间值都可用有符号 64 位整数表示。

`O(1)`。

在样例中 T = 1·1/(1·8.314) ≈ 0.120279。

注意事项：

- 压强为零或气体量为零是允许的，当未知量是 p 或 n 时是合法的答案；
- 算出的体积或温度为零是错误，而不是答案；
- 各行的顺序任意；
- 数值输出不能依赖系统区域设置：测试 15 揭示 Java 默认格式化可能输出 `0,000000` 而非 `0.000000`。

## 优化解法

Go 和 Rust 用四个固定槽保存 p、V、n、T，并从 1000pV = 8314nT 中用整数运算解出未知量。分子分母同为零时输出 undefined，分母为零或体积、温度被迫为零时输出 error。其余情况用 64 位整数把分数舍入至六位小数。
