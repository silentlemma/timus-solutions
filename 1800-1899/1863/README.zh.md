# 1863. 和平的原子

[Timus 1863](https://acm.timus.ru/problem.aspx?space=1&num=1863) · 难度 1084 · meet_in_middle

原题作者 Alexander Klepinin（由 Daniil Ayzenshteyn 准备），出自 2011 年乌拉尔联邦大学开放团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

反应堆的控制棒可以停在 0 到 n 毫米之间的任意深度，起始深度为 s。日志记录了控制棒的 k 次移动，但只有长度，没有记录每次是向上还是向下；控制棒从未离开 [0, n] 范围。求控制棒现在可能处于的最小和最大深度。

## 输入

n、s、k（0 ≤ s ≤ n ≤ 10⁹，n > 0，1 ≤ k ≤ 40），然后是 k 次移动的长度。存在某种方向选择使控制棒始终在范围内。

## 输出

可能的最小和最大最终深度。

## 样例

### 样例 1

输入：

```
10 3 3
4 5 1
```

输出：

```
1 3
```

## 解法

枚举全部 2⁴⁰ 种方向太慢，所以把日志从中间分开。对前一半，保存不离开 [0, n] 所能到达的深度集合，逐次移动扩展它并合并相同深度；它最多有 2²⁰ 个元素。

对后一半，用深度优先搜索遍历所有方向选择，并记录三个数：总位移 t，以及前缀和的最小值 low 和最大值 high。从深度 x 出发，后一半始终在范围内当且仅当 x + low ≥ 0 且 x + high ≤ n，所以 x 必须位于 [−low, n − high] 中，并且终点为 x + t。
一旦 high − low 超过 n 就剪枝，因为已经没有合适的 x。每得到一个完整的选择，就在排好序的前一半深度中二分查找该区间内最小和最大的 x，由此得到该选择的最浅和最深终点。`O(2^(k/2)·k)`。

在样例中，第一次移动从 3 到 7（−4 会低于 0），然后 7 ± 5 得到 2 或 12，只有 2 在范围内；最后一次长度为 1 的移动结束于 1 或 3。

注意事项：

- 范围必须在每次移动之后都成立，而不仅仅在最后，所以后一半需要记录前缀的极值，而不只是总和；
- 把后一半全部 2²⁰ 种选择各存三个 64 位数，需要 24 MiB；深度优先搜索可避免存储全部选择；
- Python 版本在 PyPy 上运行，用有序的 32 位数组代替哈希集合保存前一半能达到的值，并用可行深度区间、算术界和对称性搜索后一半：在评测上占用 11 MB，而使用集合的早期版本在第 10 个测试上占用 70 MB。

在三百个短日志上，答案与沿整个日志追踪可达深度集合的结果一致；在 40 次移动的日志上，与一个独立的已通过实现一致。
