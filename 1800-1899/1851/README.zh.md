# 1851. GOV 实习

[Timus 1851](https://acm.timus.ru/problem.aspx?space=1&num=1851) · 难度 1715 · flow

原题作者 Mikhail Rubinchik，出自 2011 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Team.GOV Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

模式 p 到字符串 s 的距离，是 p 到 s 中所有长度为 |p| 的子串的汉明距离之和。s 和 p 的一些字符被擦除了；请恢复它们，使这个距离尽可能小。

## 输入

字符串 s 和模式 p，都非空，长度不超过 1000，由 "0"、"1" 和 "?" 组成，且 |p| ≤ |s|；"?" 表示被擦除的字符。

## 输出

最小距离，然后是把每个 "?" 换成 "0" 或 "1" 后的 s 和 p。任何最优的恢复方式都可以。

## 样例

### 样例 1

输入：

```
00?
1?
```

输出：

```
2
000
10
```

## 解法

字符 p[i] 在每个把它与 s[j] 对齐的窗口中与 s[j] 比较一次，这恰好发生在 0 ≤ j − i ≤ |s| − |p| 时；每个这样的对，若字符不同则代价为 1。
由于每个字符都是 0 或 1，这是一个割问题：把每个被擦除的字符放进图中，1 在源点一侧，0 在汇点一侧。

- 两个已知字符组成的对直接加上其代价。
- 被擦除字符与已知 1 组成的对，若被擦除的变成 0 则代价为 1：从源点到它连一条容量为 1 的弧；已知 0 则连一条到汇点的容量为 1 的弧。同一字符的这类弧合并为一条；若一个字符两种都有，较小的那部分无论如何都要付，从两边同时减去。
- 两个被擦除字符组成的对，若被分开则代价为 1：一条容量为 1 的无向边。

一种恢复方式的代价等于固定部分加上它所确定的割的容量，所以答案是固定部分加上最大流（这里用 Dinic 算法求），最后一次搜索后残量网络中源点一侧给出恢复方式。被擦除的字符最多 2000 个，对的数目为 |p|·(|s| − |p| + 1) ≤ 250 500。

在样例中，p[0] = 1 遇到 s[0] = 0 和 s[1] = 0，无论如何代价都是 2。p[1] 遇到 s[1] = 0 和 s[2]：把两个被擦除字符都恢复为 0 不再产生代价，所以答案是 2。

注意事项：

- p[i] 只会遇到 s[i] … s[i + |s| − |p|]，而不是 s 的全部字符；
- 同一节点上来自源点和通往汇点的弧可以在求流之前相互抵消，使流保持较小；
- 任何最小割都是正确答案，所以通过重新计算距离来检查输出。

恢复结果都通过一个检查器：它重新计算距离，并与最优值比较；最优值在三百个短数据上通过枚举所有恢复方式得到，在长数据上由一个独立的已通过实现给出。
