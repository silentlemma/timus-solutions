# 1801. Кубок Революции

[Timus 1801](https://acm.timus.ru/problem.aspx?space=1&num=1801) · сложность 4973 · graphs

Автор оригинальной задачи — Магаз Асанов; NEERC 2010, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

g·t команд лежат в t корзинах по g команд, и каждая команда
принадлежит политической партии. Разбить их на g групп по t команд
так, чтобы в каждой группе была ровно одна команда из каждой корзины и
не было двух команд одной партии. Вывести любое такое разбиение или
сообщить, что его нет.

## Входные данные

g и t (1 ≤ g, t ≤ 100), затем корзины одна за другой через пустые
строки; в каждой строке название команды и название её партии.
Названия — до 10 строчных букв, все названия команд различны.

## Выходные данные

"No" или "Yes", а за ним g групп, каждая после пустой строки, по t
названий команд, каждое на отдельной строке.

## Примеры

### Пример 1

Ввод:

```
2 3
cavalry red
guard white

infantry red
guerilla green

czechs white
gunners latvia
```

Вывод:

```
Yes

cavalry
guerilla
czechs

guard
infantry
gunners
```

### Пример 2

Ввод:

```
2 2
cavalry red
guard white

czechs white
cossacks white
```

Вывод:

```
No
```

## Решение

Строим двудольный мультиграф: корзины с одной стороны, партии с
другой, каждая команда — ребро между своей корзиной и партией. Группа
— это цвет: красим рёбра в g цветов так, чтобы ни у одной вершины цвет
не повторялся. У каждой корзины ровно g рёбер, значит, она видит
каждый цвет по разу, а партия — каждый цвет не больше раза. По теореме
Кёнига двудольный граф красится в столько цветов, какова его
наибольшая степень, поэтому ответ "No" ровно тогда, когда у какой-то
партии больше g команд.

Раскраска строится по одному ребру. Для ребра из корзины u в партию v
берём цвет a, свободный у u, и цвет b, свободный у v. Если они
различны, идём от u по пути, чередующему цвета b и a. В двудольном
графе он не может кончиться в v, у которой нет ребра цвета b. Обмен a
и b вдоль него освобождает b у u, и новое ребро получает цвет b. Путь
проходит каждую корзину не больше раза, так что в нём не больше 2t + 1
рёбер. `O(g·t·(g + t))`.

В первом примере две красные команды, cavalry и infantry, попадают в
разные группы, как и белые, guard и czechs.

Подводные камни:

- для ответа "No" достаточно проверить размеры партий;
- простой жадный выбор цветов застревает, нужна перекраска вдоль
  чередующихся путей;
- пустые строки между корзинами во входе проще всего пропускать,
  читая по словам.

Чекер требует, чтобы каждая команда была ровно один раз, в каждой
группе была одна команда из каждой корзины и партии в группе были
различны. Все решения проходят его на сотнях маленьких жеребьёвок и на
полных жеребьёвках из 100 корзин с плотными, свободными и
переполненными партиями, а ответы "No" совпадают с независимой
принятой реализацией.
