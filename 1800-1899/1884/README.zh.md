# 1884. 去大学的路

[Timus 1884](https://acm.timus.ru/problem.aspx?space=1&num=1884) · 难度 675 · sorting

原题作者 Egor Shchelkonogov，出自 2011 年乌拉尔地区团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

Egor 要横穿一条有两条 2 米宽车道的马路，以 5 km/h 的速度垂直穿过，中途不停。交通靠右行驶，所以从左边来的 n 辆车走近侧车道，从右边来的 m 辆车走远侧车道。每辆车宽 2 米、长 5 米，速度 20 km/h；给出到各车的距离。Egor 最少要等多久才能出发？

## 输入

n（1 ≤ n ≤ 300）和到左边各车的距离，然后是 m（1 ≤ m ≤ 300）和到右边各车的距离。距离在 1 到 10 000 米之间，每一行中依次至少增加 5。

## 输出

最少等待时间（秒），小数点后至少六位。

## 样例

### 样例 1

输入：

```
1
1
1
100
```

输出：

```
1.080000
```

## 解法

以 1/50 秒为时间单位，使一切都是整数：20 km/h 的车每米用 9 个单位，Egor 穿过一条车道用 72 个单位。距离为 d 的车在 9d 到 9(d + 5) 时段位于 Egor 的路线上。若在时刻 s 出发，Egor 在 s 到 s + 72 位于近侧车道，在 s + 72 到 s + 144 位于远侧车道。若这些时段的重叠多于一个点，这辆车就使 s 不可行。这是一个开区间的不可行出发时刻：左边的车为 (9d − 72, 9(d + 5))，右边的车为 (9d − 144, 9(d + 5) − 72)。把区间按左端点排序，从 s = 0 开始扫描：只要下一个区间在 s 之前开始，若其右端点更晚就把 s 移过去。第一个在 s 或之后开始的区间结束扫描。输出 s/50。`O((n + m) log(n + m))`。

样例中左边的车禁止 54 个单位之前的出发，右边的车只禁止 (756, 873)，所以 Egor 等待 54/50 = 1.08 秒。

注意事项：

- 只在一个瞬间碰到车是允许的，所以区间是开的：左边 8 米处的车让 Egor 可以立即出发；
- 右边的车只在 Egor 位于远侧车道时才有影响，即晚 72 个单位；
- 当车与车之间的空隙恰好够用时，整数单位避免了舍入问题。

在 26 条随机道路上，等待时间与以 1/50 秒为步长枚举所有出发时刻的结果一致；在 100 条道路上与一个独立的已通过实现一致。
