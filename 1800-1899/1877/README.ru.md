## Задача

У Дена два четырёхзначных велосипедных замка, и он чередует их по
вечерам, причём в ночь первого визита вора велосипед на первом замке.
Вор пробует код 0000 в эту ночь, 0001 в следующую и так далее.
Откроет ли вор когда-нибудь замок?

## Входные данные

Коды первого и второго замка, по четыре цифры.

## Выходные данные

«yes», если вор когда-нибудь откроет замок, иначе «no».

## Примеры

### Пример 1

Ввод:

```
0001
0000
```

Вывод:

```
no
```

### Пример 2

Ввод:

```
0002
0001
```

Вывод:

```
yes
```

## Решение

В ночь k (считая с 0) вор пробует код k, а велосипед стоит на первом
замке при чётном k и на втором при нечётном. Значит, первый замок
падёт, если его код чётный, второй — если его код нечётный, а иначе
велосипед в безопасности. `O(1)`.

В первом примере первый код нечётный, а второй чётный, так что ни один
замок не встретит свой код.

Подводные камни:

- коды с ведущими нулями надо читать как десятичные числа; `fmt.Scan`
  в Go может прочитать «0009» как 0 и 9, поэтому решение на Go
  читает строки;
- важна только чётность каждого кода, а не то, какой из них меньше.

Ответы совпадают с независимой принятой реализацией на всех тестах.
