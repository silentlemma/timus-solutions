# 1879. GOV 实习 2

[Timus 1879](https://acm.timus.ru/problem.aspx?space=1&num=1879) · 难度 1456 · greedy

原题作者 Mikhail Rubinchik，出自 2011 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

循环串 s 到较短串 t 的距离，是 t 到 s 的所有与 t 等长的子串（包括跨过 s 末尾的子串）的汉明距离之和。两个串中都可能有问号。把每个问号换成一个字母，使距离尽可能小，并输出这个距离。字母是 1 到 100 000 的数，0 表示问号。

## 输入

s 的长度 n（1 ≤ n ≤ 100 000）及其 n 个数，然后是 t 的长度 m 及其 m 个数。

## 输出

最小距离。

## 样例

### 样例 1

输入：

```
5
2 1 1 0 2
4
3 0 3 0
```

输出：

```
14
```

## 解法

长度为 n 的循环串有 n 个长度为 m 的子串，每个位置开始一个。对 t 的固定位置 j，起点取遍 s 的全部 n 个位置，所以每一对（s 的位置，t 的位置）恰好比较一次。因此距离等于 n·m 减去字母相同的对数 Σ a(c)·b(c)，其中 a(c)、b(c) 是字母 c 在 s 和 t 中的个数。字母的顺序完全无关。

现在设 s 的 x(c) 个问号和 t 的 y(c) 个问号变成字母 c。相同的对数增加 Σ (x(c)·b(c) + y(c)·a(c) + x(c)·y(c))。固定 y 时它关于 x 是线性的，所以最好把 s 的全部 p 个问号都变成同一个字母。同理 t 的全部 q 个问号也变成同一个字母。两串用同一个字母时增益为 p·b(c) + q·a(c) + p·q；用两个不同字母时至多为 p·max b + q·max a。当两个最大值在不同字母上时这个上界可以达到，否则第一种情况至少同样好。答案是 n·m − Σ a(c)b(c) 再减去较大的增益。`O(n + m + letters)`。

样例中计数为 a：2 → 2，1 → 2，一个问号；b：3 → 2，两个问号。没有相同字母，最佳增益为 6，例如把所有问号都变成 2。答案为 20 − 6 = 14。

注意事项：

- 循环子串使每一对恰好相遇一次，所以位置和字母顺序都无关紧要；
- 把同一个串的问号分给不同字母永远不会更好；
- 距离可达 10¹⁰，需要 64 位整数。

在 3000 个小规模随机数据上，答案与枚举所有替换和所有循环子串的结果一致；在 90 个大数据上与一个独立的已通过实现一致。
