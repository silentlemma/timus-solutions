# 1879. GOV-стажировка 2

[Timus 1879](https://acm.timus.ru/problem.aspx?space=1&num=1879) · сложность 1461 · greedy

Автор оригинальной задачи — Михаил Рубинчик; Уральская региональная командная олимпиада по программированию 2011.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Расстояние от циклической строки s до более короткой строки t — сумма
расстояний Хэмминга от t до всех подстрок s длины t, включая
переходящие через конец s. В обеих строках могут быть знаки вопроса.
Замените каждый знак вопроса буквой так, чтобы расстояние было
наименьшим, и выведите его. Буквы — числа от 1 до 100 000, а 0
обозначает знак вопроса.

## Входные данные

Длина n строки s (1 ≤ n ≤ 100 000) и её n чисел, затем длина m строки
t и её m чисел.

## Выходные данные

Наименьшее расстояние.

## Примеры

### Пример 1

Ввод:

```
5
2 1 1 0 2
4
3 0 3 0
```

Вывод:

```
14
```

## Решение

У циклической строки длины n есть n подстрок длины m — по одной с
каждой позиции. Для фиксированной позиции j строки t начала пробегают
все n позиций s, так что каждая пара (позиция s, позиция t)
сравнивается ровно один раз. Значит, расстояние равно n·m минус число
пар с равными буквами, Σ a(c)·b(c) по буквам c, где a(c) и b(c) —
число букв c в s и t. Порядок букв вообще не важен.

Пусть теперь x(c) знаков вопроса s и y(c) знаков вопроса t стали
буквой c. Число равных пар растёт на Σ (x(c)·b(c) + y(c)·a(c) +
x(c)·y(c)). При фиксированном y это линейно по x, так что лучше всего
отдать все p знаков вопроса s одной букве. Так же все q знаков вопроса
t идут в одну букву. С одной буквой на обе строки выигрыш равен
p·b(c) + q·a(c) + p·q, а с двумя разными он не больше
p·max b + q·max a. Эта оценка достигается, когда максимумы стоят у
разных букв, а иначе её перекрывает первый случай. Ответ —
n·m − Σ a(c)b(c) минус больший выигрыш. `O(n + m + letters)`.

В примере счётчики такие: a: 2 → 2, 1 → 2 и один знак вопроса;
b: 3 → 2 и два знака вопроса. Совпадений нет, а лучший выигрыш равен 6,
например если все знаки вопроса сделать буквой 2. Ответ 20 − 6 = 14.

Подводные камни:

- циклические подстроки сводят каждую пару ровно один раз, так что ни
  позиции, ни порядок букв не важны;
- делить знаки вопроса одной строки между буквами никогда не выгодно;
- расстояние доходит до 10¹⁰, нужны 64-битные числа.

Ответы совпадают с перебором всех замен и всех циклических подстрок на
3000 малых случайных тестах и с независимой принятой реализацией на 90
больших.
