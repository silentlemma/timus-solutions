# 1800. 墨菲定律

[Timus 1800](https://acm.timus.ru/problem.aspx?space=1&num=1800) · 难度 169 · math

原题作者 Alex Samsonov，出自 NEERC 2010 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一片吐司（长度为 l 的细线段）从高度 h 处黄油面朝下、水平地掉落。它自由下落（g = 9.81 m/s²），同时在竖直平面内以每分钟 ω 转绕中心旋转。
哪一面先接触地面？保证接触时吐司不是竖直的。

## 输入

l 和 h（厘米）以及 ω（每分钟转数），均为 1 到 1000 的整数。

## 输出

"butter" 或 "bread"。

## 样例

### 样例 1

输入：

```
10 400 15
```

输出：

```
butter
```

### 样例 2

输入：

```
10 500 15
```

输出：

```
bread
```

## 解法

先将长度换算为米，将 ω 换算为每秒弧度。
t 秒后中心的高度为 h − g·t²/2，吐司转过了 ω·t，所以较低一端的高度为 gap(t) = h − g·t²/2 − (l/2)·|sin ωt|。
答案只取决于 gap 第一次到达零时所在的四分之一圈：在一圈的第 0 和第 3 个四分之一圈中黄油朝下，在第 1 和第 2 个中面包朝下。所以按顺序检查各个四分之一圈。

在偶数号的四分之一圈中 |sin ωt| 增大，低端下降得比中心快，gap 只减不增：当且仅当在其末尾 gap ≤ 0 时在此处接触。
在奇数号的四分之一圈中低端相对中心回升，gap 可能先降、再升、再降。此时它的导数是凹的，因为三阶导数等于 (l/2)·ω³·cos ≤ 0。
用二阶导数上的二分找到导数的峰值。若峰值处导数为正，再用一次二分找出导数变为正的位置，即 gap 的局部最小值。
若这个最小值或该四分之一圈末尾的值不大于零，第一次接触就在这里。中心大约 1.5 秒内落地，所以最多约一百个四分之一圈。`O(ω)`。

第一个样例中吐司每秒转四分之一圈，约 0.9 秒后在约 81° 时落地：黄油。从 5 米落下时刚过 90° 落地：面包。

注意事项：

- 吐司的一端可能在中心还没落多少时就碰到地面：拿得很低的长吐司在第一个四分之一圈内就会接触（测试 05 和 06 均为 butter）；
- 在奇数号的四分之一圈中 gap 不单调，只看末尾的值可能漏掉接触；
- 单位：厘米换成米，每分钟转数换成每秒弧度；
- gen1、gen3 和 gen4 使用的生成器也必须遵守首次接触时不竖直的保证。
  以整数厘米为长度单位、r 为每分钟转数时，首次接触竖直的充要条件是
  (2h − l)·r² = 981·15²·n²，其中 n 为正奇数。
  用精确整数运算拒绝这样的随机结果；题目没有规定它们应输出哪一面。

在 3000 个随机输入（1500 个小输入）、64 个边界输入、全部九个保存的测试和五个配置的生成用例上，答案均与独立的时间区间细分判定程序一致。
