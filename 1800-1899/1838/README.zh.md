# 1838. 武士的一击

[Timus 1838](https://acm.timus.ru/problem.aspx?space=1&num=1838) · 难度 721 · math

原题作者 Denis Dublennykh，出自 2011 年 4 月第十五届乌拉尔竞技编程公开锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一根长 l 的竹竿放在 n 个支点上。在某一点把它砍成两段；若某段的质心不位于它下方的两个支点之间，这段就会掉下。求砍下去会使至少一段掉下的那些点的总长度，向上取整。

## 输入

l 和 n（3 ≤ l ≤ 10⁹，2 ≤ n ≤ 10⁵），然后是 n 个按递增顺序给出的互不相同的支点位置，都严格位于 0 和 l 之间。整根竹竿是稳定的。

## 输出

会使某段掉下的点的总长度，向上取整。

## 样例

### 样例 1

输入：

```
5 4
1 2 3 4
```

输出：

```
4
```

## 解法

设在支点 sᵢ 和 sᵢ₊₁ 之间的 x 处砍断。左段 [0, x] 放在 s₁, …, sᵢ 上，当它的质心 x/2 位于 [s₁, sᵢ] 时稳定；右段 [x, l] 放在 sᵢ₊₁, …, sₙ 上，当 (x + l)/2 位于 [sᵢ₊₁, sₙ] 时稳定。所以在这个间隔中两段都稳定当且仅当 x 位于

[max(sᵢ, 2s₁, 2sᵢ₊₁ − l), min(sᵢ₊₁, 2sₙ − l, 2sᵢ)]，

而在 s₁ 左边或 sₙ 右边砍总会有一段掉下。把 n − 1 个间隔中的安全长度相加，再从 l 中减去，就得到答案。所有边界都是整数，所以取整不会改变它。`O(n)`。

在样例中只有间隔 (2, 3) 是安全的：那里左段质心 x/2 在 1 和 2 之间，右段质心 (x + 5)/2 在 3 和 4 之间。所以 5 个单位中有 4 个要涂色。

注意事项：

- 一段需要两个支点，所以在第二个支点之前砍总会让左段掉下；
- 单个点（比如正好砍在支点上）没有长度，无关紧要；
- 2sₙ 可达 2·10⁹，超出 32 位整数。

在数百根小竹竿上，答案与按细网格统计掉落砍点的结果一致，并在大测试上与一个独立的已通过实现一致。
