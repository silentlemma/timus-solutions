# 1838. Удар самурая

## Задача

Стебель бамбука длины l лежит на n опорах. Его разрубают в одной точке
на две части, и часть падает, если её центр масс не лежит между двумя
опорами под ней. Найти суммарную длину точек, удар по которым роняет
хотя бы одну часть, округлённую вверх.

## Входные данные

l и n (3 ≤ l ≤ 10⁹, 2 ≤ n ≤ 10⁵), затем n различных положений опор по
возрастанию, все строго между 0 и l. Весь стебель лежит устойчиво.

## Выходные данные

Суммарная длина точек, где часть падает, округлённая вверх.

## Примеры

### Пример 1

Ввод:

```
5 4
1 2 3 4
```

Вывод:

```
4
```

## Решение

Пусть удар в точке x между опорами sᵢ и sᵢ₊₁. Левая часть [0, x] лежит
на s₁, …, sᵢ и стоит, когда её центр x/2 лежит в [s₁, sᵢ]; правая
часть [x, l] лежит на sᵢ₊₁, …, sₙ и стоит, когда (x + l)/2 лежит в
[sᵢ₊₁, sₙ]. Значит, на этом промежутке обе стоят при x из

[max(sᵢ, 2s₁, 2sᵢ₊₁ − l), min(sᵢ₊₁, 2sₙ − l, 2sᵢ)],

а удар левее s₁ или правее sₙ всегда роняет часть. Сумма безопасных
длин по n − 1 промежуткам, вычтенная из l, даёт ответ. Все границы
целые, так что округление его не меняет. `O(n)`.

В примере безопасен только промежуток (2, 3): там левый центр x/2
между 1 и 2, а правый (x + 5)/2 между 3 и 4. Значит, красятся 4 из 5
единиц.

Подводные камни:

- части нужны две опоры, так что удар до второй опоры всегда роняет
  левую часть;
- отдельные точки, например удар прямо по опоре, не имеют длины и не
  важны;
- 2sₙ доходит до 2·10⁹ и не помещается в 32-битные числа.

Ответы совпадают с подсчётом падающих ударов по мелкой сетке на
нескольких сотнях маленьких стеблей и с независимой принятой
реализацией на больших тестах.
