# 1833. Надежды гребного слалома

[Timus 1833](https://acm.timus.ru/problem.aspx?space=1&num=1833) · сложность 2007 · matching

Автор оригинальной задачи — Александр Ипатов (подготовка — Евгений Курпилянский); XV открытый чемпионат Урала по спортивному программированию, апрель 2011 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n каноистов составили m экипажей-двоек, бравших призы. Выплатить
каждому каноисту неотрицательную премию так, чтобы двое из каждого
экипажа-призёра вместе получили не меньше k, потратив в сумме как
можно меньше.

## Входные данные

n, k, m (2 ≤ n ≤ 500, 1 ≤ k ≤ 10000, 0 ≤ m ≤ 100000), затем m
экипажей — пары различных каноистов, каждый экипаж один раз.

## Выходные данные

Премия каждого каноиста с абсолютной погрешностью не больше 10⁻⁶.
Подходит любая оптимальная выплата.

## Примеры

### Пример 1

Ввод:

```
4 1000 4
1 2
1 3
2 4
3 4
```

Вывод:

```
146.5
853.5
853.5
146.5
```

## Решение

Это линейная релаксация вершинного покрытия: минимизировать Σxᵥ при
xᵤ + xᵥ ≥ k для каждого экипажа. У неё всегда есть полуцелый оптимум,
и он находится через удвоенный граф: сделаем левую и правую копии
каждого каноиста и для каждого экипажа соединим u слева с v справа и v
слева с u справа. Минимальное вершинное покрытие C этого двудольного
графа даёт xᵥ = k/2 за каждую копию v в C. Каждый экипаж в удвоенном
графе покрыт дважды, так что получает не меньше k, а сумма k·|C|/2
оптимальна: любое дробное решение, делённое на k и скопированное в обе
доли, — дробное покрытие двудольного графа, чей оптимум равен целому |C|.

По теореме Кёнига C получается из максимального паросочетания: ищем
чередующиеся пути от свободных левых копий; недостигнутые левые копии
и достигнутые правые образуют C. Паросочетание строится за `O(n·m)`
алгоритмом Куна, а в Python — алгоритмом Хопкрофта — Карпа.

В примере экипажи образуют цикл 1–2–4–3–1, чётный цикл, и покрытие
даёт каждому каноисту 500: всего 2000, столько же, сколько в ответе
примера 146.5 + 853.5 + 853.5 + 146.5.

Подводные камни:

- выплаты только 0 или k обходятся дороже: на треугольнике три
  половины, всего 1.5k, лучше двух целых k;
- каноисты вне экипажей получают 0;
- оптимальных выплат много, поэтому ответ проверяется по сумме и
  экипажам.

У всех ответов наименьшая сумма, найденная перебором выплат со
значениями 0, k/2 и k для до 9 каноистов, а на больших тестах сумма
совпадает с независимой принятой реализацией.
