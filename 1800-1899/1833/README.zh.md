# 1833. 激流回旋的希望

[Timus 1833](https://acm.timus.ru/problem.aspx?space=1&num=1833) · 难度 2017 · matching

原题作者 Alexander Ipatov（由 Evgeny Kurpilyansky 准备），出自 2011 年 4 月第十五届乌拉尔竞技编程公开锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 名划艇运动员组成了 m 个获过奖的双人艇组。给每名运动员发放非负奖金，使每个获奖艇组的两名成员合计至少得到 k，并使总花费尽可能少。

## 输入

n, k, m（2 ≤ n ≤ 500，1 ≤ k ≤ 10000，0 ≤ m ≤ 100000），然后是 m 个艇组，每个为两名不同的运动员，每个艇组只出现一次。

## 输出

每名运动员的奖金，绝对误差不超过 10⁻⁶。任何最优方案都可以。

## 样例

### 样例 1

输入：

```
4 1000 4
1 2
1 3
2 4
3 4
```

输出：

```
146.5
853.5
853.5
146.5
```

## 解法

这是顶点覆盖的线性松弛：在每个艇组满足 xᵤ + xᵥ ≥ k 的条件下最小化 Σxᵥ。它总有一个半整数最优解，可以通过加倍图求出：
为每名运动员建立左副本和右副本，对每个艇组把左边的 u 连到右边的 v，把左边的 v 连到右边的 u。
这个二分图的最小顶点覆盖 C 给出：v 的每个副本在 C 中就给 xᵥ 加 k/2。每个艇组在加倍图中被覆盖两次，所以至少得到 k；
而总额 k·|C|/2 是最优的，因为任何分数解复制到两侧后都是二分图的分数覆盖，而二分图的最优值就是整数 |C|。

由 König 定理，C 可从最大匹配得到：从未匹配的左副本出发搜索交错路径；未到达的左副本和到达的右副本构成 C。
匹配用 Kuhn 增广路算法需要 `O(n·m)`，Python 版本使用 Hopcroft–Karp 算法。

在样例中艇组构成环 1–2–4–3–1，这是偶环，覆盖给每名运动员 500：总计 2000，与样例答案 146.5 + 853.5 + 853.5 + 146.5 相同。

注意事项：

- 只发 0 或 k 会更贵：在三角形上，三个一半（共 1.5k）优于两个整的 k；
- 不在任何艇组中的运动员得 0；
- 最优方案有很多，所以答案按总额和各艇组来检查。

所有答案的总额都等于对至多 9 名运动员、取值 0、k/2、k 的全部方案穷举得到的最小值，并在大测试上与一个独立的已通过实现的总额一致。
