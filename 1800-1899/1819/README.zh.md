# 1819. 职业化的态度

[Timus 1819](https://acm.timus.ru/problem.aspx?space=1&num=1819) · 难度 6421 · graphs

原题出自 Tavrida NU Akai Contest，2010 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

城市有 n 个路口和 k 条双向道路，任意两个路口之间至多一条道路。
对 q 个询问（旅馆，赛场）中的每一个，判断是否存在从旅馆到赛场的三条路径，使得任意两条都不经过同一条道路。

## 输入

n 和 k（2 ≤ n ≤ 50000，1 ≤ k ≤ 50000），然后是 k 条道路，每条为两个不同的路口，然后是 q（1 ≤ q ≤ 50000）和 q 对不同的路口。

## 输出

对每个询问，单独一行输出 "Yes" 或 "No"。

## 解法

由 Menger 定理，答案为 "Yes" 当且仅当删除任意至多两条道路后这两个路口仍然连通，所以任务是回答关于三边连通性的询问。

取一个深度优先搜索森林。其余每条道路都连接一个路口和它的某个祖先，覆盖两者之间的树边。
给每条这样的道路一个随机的 64 位数，树边的覆盖定义为覆盖它的道路之数的异或：在每条道路的两端做标记，再沿树向上累积异或，就能在 `O(n + k)` 内得到所有覆盖。
覆盖道路的条数也同样累积。于是至多两条道路的割恰好是：

- 没有被覆盖的树边，即桥；
- 恰好被一条道路覆盖的树边，连同这条道路；
- 覆盖相等的两条树边。

在至少被两条道路覆盖的树边中，覆盖相同的树边位于同一条到根的路径上，把树切成若干块，覆盖它们的道路把这些块连成一个环；两个路口被这样的一对边分开，除非它们之间的树路径经过该类的全部边或一条也不经过。
因此每条树边得到一个值：桥和只被覆盖一次的边取新的随机值；覆盖相等的一类边取异或为零的随机值，而类中只有一条边时取 0。
由于一类边的任何非空真子段的异或以压倒性的概率非零，同一棵树中的两个路口三边连通当且仅当它们的标签（从根开始的值的异或）相同。
每个询问只需一次比较。借助哈希表处理类，期望复杂度 `O(n + k + q)`。

在样例中，路口 6 只有道路 1–6 和 4–6，路口 2 只有 1–2 和 2–3，所以它们各自被两条道路切开。
视搜索树而定，这样的一对要么是覆盖相等的两条树边，要么是一条只被另一条道路覆盖的树边。其余四个路口得到相同的标签。

注意事项：

- 不同连通分量中的路口在根处的标签都是 0，所以还要比较连通分量；
- 被完整穿过的类不会分开路口：一串割对的两端位于环的同一块中；
- 一条 50000 个顶点的路径需要非递归的深度优先搜索。

所有答案在数百个随机小图上与最大流暴力一致，并在最大规模的随机图、轮图、K4 块组成的环、路径和森林上与一个独立的已通过实现一致。
