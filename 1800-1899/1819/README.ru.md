# 1819. Профессиональный подход

[Timus 1819](https://acm.timus.ru/problem.aspx?space=1&num=1819) · сложность 6417 · graphs

Оригинальная задача — Tavrida NU Akai Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В городе n перекрёстков и k двусторонних участков дорог, никакие два
участка не соединяют одну и ту же пару. Для каждого из q запросов
(гостиница, место соревнования) ответить, есть ли три пути из гостиницы
к месту соревнования, никакие два из которых не проходят по одному
участку.

## Входные данные

n и k (2 ≤ n ≤ 50000, 1 ≤ k ≤ 50000), затем k участков парами
различных перекрёстков, затем q (1 ≤ q ≤ 50000) и q пар различных
перекрёстков.

## Выходные данные

Для каждого запроса «Yes» или «No» в отдельной строке.

## Решение

По теореме Менгера ответ «Yes» ровно тогда, когда никакие один или два
участка не разделяют два перекрёстка, так что задача — отвечать на
запросы о трёхрёберной связности.

Возьмём лес обхода в глубину. Каждый остальной участок соединяет
перекрёсток с одним из его предков и покрывает рёбра дерева между ними.
Дадим каждому такому участку случайное 64-битное число, а покрытием
ребра дерева назовём xor чисел покрывающих его участков: отметки на
обоих концах каждого участка и накопление xor вверх по дереву дают все
покрытия за `O(n + k)`. Так же накапливается число покрывающих
участков. Разрезы не больше чем из двух участков тогда такие:

- ребро дерева, которое ничем не покрыто, — мост;
- ребро дерева, покрытое ровно одним участком, вместе с этим участком;
- два ребра дерева с равными покрытиями.

Рёбра дерева с одинаковым покрытием лежат на одном пути к корню и режут
дерево на куски, которые покрывающие участки замыкают в кольцо; два
перекрёстка разделены такой парой, если только путь между ними по
дереву не проходит через все рёбра класса или ни через одно. Поэтому
каждое ребро дерева получает значение: новое случайное для мостов и
однократно покрытых рёбер, а для класса равных покрытий — случайные
значения с нулевым xor, причём ребро, одно в своём классе, получает 0.
Поскольку любая собственная часть класса почти наверняка даёт ненулевой
xor, два перекрёстка одного дерева трёхрёберно связны ровно тогда,
когда совпадают их метки — xor значений от корня. Каждый запрос — одно
сравнение. `O(n + k + q)` в среднем с хеш-таблицей для классов.

В примере у перекрёстка 6 есть только участки 1–6 и 4–6, а у
перекрёстка 2 — только 1–2 и 2–3, так что каждый отрезается двумя
участками. В зависимости от дерева обхода такая пара — либо два ребра
дерева с равными покрытиями, либо ребро дерева, покрытое только другим
участком. Остальные четыре перекрёстка получают равные метки.

Подводные камни:

- у перекрёстков из разных компонент в корнях одинаковая метка 0,
  поэтому компоненты тоже сравниваются;
- класс, путь через который пройден целиком, не разделяет: концы
  цепочки разрезающих пар лежат в одном куске кольца;
- для пути из 50000 вершин нужен обход в глубину без рекурсии.

Все ответы совпадают с перебором через максимальный поток на сотнях
случайных маленьких графов и с независимой принятой реализацией на
случайных графах, колёсах, кольцах из блоков K4, путях и лесах
максимального размера.
