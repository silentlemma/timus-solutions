# 1803. Винтовки белочехов

[Timus 1803](https://acm.timus.ru/problem.aspx?space=1&num=1803) · сложность 717 · math

Автор оригинальной задачи — Виктор Камашев; NEERC 2010, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Винтовка i стоит i-е число Фибоначчи рублей (1, 1, 2, 3, …). Купюры
достоинством в степени k, и каждая винтовка оплачивается наименьшим
числом купюр. Упорядочить винтовки по числу уплаченных купюр, при
равенстве — по номеру винтовки.

## Входные данные

k и n (2 ≤ k ≤ 10, 3 ≤ n ≤ 50000).

## Выходные данные

Номера винтовок в нужном порядке.

## Примеры

### Пример 1

Ввод:

```
10 8
```

Вывод:

```
1 2 3 4 8 7 5 6
```

## Решение

Наименьшее число купюр для суммы — это сумма её цифр в системе по
основанию k, так что винтовка стоит сумму цифр числа Фибоначчи.
В F(50000) около 10⁴ десятичных цифр, поэтому числа складываются
одно из другого прямо в системе по основанию k. Компилируемые решения
хранят разряды по основанию k^m — наибольшей степени k, не
превосходящей миллиона. Таблица даёт сумму цифр каждого разряда, так
что одно сложение сразу даёт следующее число и его сумму цифр. Затем
устойчивая сортировка по сумме цифр даёт порядок. `O(n² / log B)` для
разрядов по основанию B.

Решение на Python хранит каждую цифру по основанию k в 4-битном поле
одного большого целого. Поле содержит цифру + 16 − k, поэтому оно
переполняется ровно тогда, когда цифра по основанию k даёт перенос, и
обычное сложение целых передаёт переносы дальше. Поля, давшие
перенос, находятся по исключающему или слагаемых и суммы и снова
получают смещение. Число единиц в четырёх битовых плоскостях полей
даёт сумму цифр. При k = 2 сумма цифр — просто число единиц.

В примере цены 1, 1, 2, 3, 5, 8, 13, 21 с суммами цифр 1, 1, 2, 3, 5,
8, 4, 3, что даёт 1 2 3 4 8 7 5 6.

Подводные камни:

- в числах тысячи цифр, далеко за пределами 64 бит;
- при равном числе купюр винтовки идут по возрастанию номеров;
- перевод больших чисел в текст в Python слишком медленный для 50000
  чисел.

Ответы совпадают с независимой принятой реализацией для каждого
основания на наибольшем числе винтовок и на многих меньших.
