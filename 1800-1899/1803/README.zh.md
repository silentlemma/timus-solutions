# 1803. 捷克军团的步枪

[Timus 1803](https://acm.timus.ru/problem.aspx?space=1&num=1803) · 难度 716 · math

原题作者 Viktor Kamashev，出自 NEERC 2010 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

第 i 支步枪的价格是第 i 个斐波那契数卢布（1、1、2、3、…）。纸币面值为 k 的各次幂，每支步枪都用最少的纸币支付。按支付的纸币张数给步枪排序，张数相同时按步枪编号。

## 输入

k 和 n（2 ≤ k ≤ 10，3 ≤ n ≤ 50000）。

## 输出

按要求顺序排列的步枪编号。

## 样例

### 样例 1

输入：

```
10 8
```

输出：

```
1 2 3 4 8 7 5 6
```

## 解法

支付某金额所需的最少纸币数就是它在 k 进制下的数字和，所以每支步枪的纸币张数是一个斐波那契数的数字和。F(50000) 约有 10⁴ 位十进制数字，
因此这些数直接在 k 进制下由前两个相加得到。编译型语言的解答按 k^m 进制存储各段，k^m 是不超过一百万的 k 的最大幂。
一张表给出每一段的数字和，所以一次加法就同时得到下一个数及其数字和。再按数字和做稳定排序即得到顺序。段的进制为 B 时为 `O(n² / log B)`。

Python 解答把每个 k 进制数字放在一个大整数的 4 位字段中。其中一个加数的每个字段存放“数字 + 16 − k”，因此恰好在 k 进制数字需要进位时溢出，
普通的整数加法就会把进位传下去。发生进位的字段可以由两个加数与和的异或找出，并重新加上偏移。字段四个位平面的 1 的个数给出数字和。
k = 2 时数字和就是二进制中 1 的个数。

样例中价格为 1、1、2、3、5、8、13、21，数字和为 1、1、2、3、5、8、4、3，得到 1 2 3 4 8 7 5 6。

注意事项：

- 这些数有几千位，远超 64 位；
- 纸币张数相同时步枪按编号递增排列；
- 在 Python 中把五万个大数转成文本太慢。

对每种进制，在最大的步枪数以及许多较小的情形上，答案都与一个独立的已通过实现一致。

## 优化解法

基数为 2、4 或 8 时，通过统计置位的位数求数位和。其他基数使用单字节的数位和查找表。

G++ 13.2 x64（提交 11320151）的运行时间从 0.375 秒变为 0.14 秒，内存从 4728 KB 变为 1380 KB。

Rust 1.75 x64（提交 11320179）的运行时间从 0.359 秒变为 0.187 秒，内存从 6884 KB 变为 1420 KB。

对于其他基数，每次进位使数位和减少 k − 1，因此程序通过进位次数更新数位和。 Python 3.12 x64（提交 11320239）的运行时间从 1.687 秒变为 1.062 秒，内存从 26824 KB 变为 29780 KB。
