# 1831. 齐菲尔金的课

[Timus 1831](https://acm.timus.ru/problem.aspx?space=1&num=1831) · 难度 2244 · probability

原题作者 Evgeny Kurpilyansky（创意来自 Alexander Ipatov），出自 2011 年 4 月第十五届乌拉尔竞技编程公开锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一名学生从右到左列竖式相加两个数。写一位数字或一个进位标记需要一秒。两个数相加时，若其中之一为 0 或 1 需要一秒，否则需要两秒；但本节课已经算过的和（任意顺序）只需一秒就能回忆起来。
在每一位上，学生先把两个数字相加，若有进位再加上进位，写下最后一位数字，必要时标记进位；最高位的进位作为一位数字写出。对两个随机的、没有前导零的 k 位数，求期望用时。

## 输入

k（1 ≤ k ≤ 5000）。

## 输出

期望用时，绝对或相对误差不超过 10⁻⁶。

## 样例

### 样例 1

输入：

```
2
```

输出：

```
7.51530864
```

## 解法

利用期望的线性性拆分时间。

- 每一位写一位数字并计算一次数字之和：共 2k 秒，另外每个两数都大于 1 且首次遇到的数字和再加一秒。
- 每个进位都要标记，然后要么在下一位加上（一秒，因为加数之一是 1），要么在最高位之后写出：每个进位两秒。

进位构成一个马尔可夫链。对随机数字 0 … 9，无进位输入时产生进位的概率为 45/100，有进位输入时为 55/100；最高位的数字是 1 … 9，概率分别为 45/81 和 53/81。逐位迭代进位概率即可得到进位次数的期望。

由 2 … 9 中数字组成的一对 {a, b} 在低位出现的概率为 2/100（a = b 时为 1/100），在最高位出现的概率为 2/81（1/81），各位之间相互独立。
所以它至少出现一次的概率为 1 − (1 − q)^(k−1)(1 − r)，把 36 个这样的对的概率加起来即可。`O(k)`。

对 k = 2：写数字和求和共 4 秒，进位概率 0.45 和 0.6 带来 2·1.05 = 2.1，首次遇到的数字对带来 1.41531，合计 7.51531。

注意事项：

- 最高位数字不为 0，所以最高位有自己的进位概率和数字对概率；
- 含 0 或 1 的和从不需要两秒，所以只有 2 … 9 中数字组成的对的记忆才有意义；
- 加上进位是一次单独的一秒加法。

在 k 不超过 3 时，结果与对所有数对的穷举一致，并在所有测试的 k 上与一个独立的已通过实现一致。
