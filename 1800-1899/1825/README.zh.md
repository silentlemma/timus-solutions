# 1825. 伊夫利特轰炸 2

[Timus 1825](https://acm.timus.ru/problem.aspx?space=1&num=1825) · 难度 929 · geometry

原题作者 Alexander Belits，出自 2011 年 3 月 19 日第十二届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两个瓶子各摧毁一个圆环：与落点距离在 r 到 R 之间的一切。两个落点相距 d。求两个瓶子摧毁的总面积。

## 输入

d, r₁, R₁, r₂, R₂（0 ≤ d ≤ 15000，1 ≤ rᵢ < Rᵢ ≤ 15000）。

## 输出

两个圆环并集的面积，绝对或相对误差不超过 10⁻⁶。

## 样例

### 样例 1

输入：

```
200 100 300 200 300
```

输出：

```
353992.933435
```

## 解法

并集等于两环面积 π(R² − r²) 之和减去它们的交集。圆环是一个圆盘去掉其中较小的圆盘，记 L(a, b) 为以两点为圆心、半径为 a 和 b 的圆盘的公共面积，由容斥原理

交集 = L(R₁, R₂) − L(r₁, R₂) − L(R₁, r₂) + L(r₁, r₂)。

L 本身是通常的透镜面积：d ≥ a + b 时为 0，d ≤ |a − b| 时为 π·min(a, b)²，否则为 a²α + b²β 减去经过两圆心和两个交点的筝形面积，其中 α 和 β 是从两圆心看透镜的半角，由余弦定理得到，筝形面积等于 √((−d+a+b)(d+a−b)(d−a+b)(d+a+b)) 的一半。
情形判断用精确的整数完成，严格处于透镜情形时余弦值远离 ±1。`O(1)`。

在样例中 L(r₁, R₂) 就是整个第一个内圆盘：距离 200 处半径 100 的圆盘位于半径 300 的圆盘之内；其余三对都是真正的透镜。

注意事项：

- d = 0 时两个透镜公式都会除以零；包含情形会先把它拦下；
- 一个圆环可能完全位于另一个的孔中，此时交集为 0，尽管外圆盘相交；
- 面积可达约 10⁹，所以关键是相对误差。

样例与细网格计数一致，所有答案在约 400 个随机和相切的情形上与一个独立的已通过实现一致。
