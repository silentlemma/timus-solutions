# 1866. Стихотворный размер

[Timus 1866](https://acm.timus.ru/problem.aspx?space=1&num=1866) · сложность 751 · parsing

## Задача

Стопа — группа слогов, один из которых ударный. У хорея и ямба стопы из
двух слогов с ударением на первом и втором; у дактиля, амфибрахия и
анапеста — из трёх слогов с ударением на первом, втором и третьем.
Каждая строка стихотворения — ряд стоп одного вида, причём последняя
стопа может быть усечена. Слоги слова соединены дефисами, ударные слоги
стоят в квадратных скобках. Назовите размер стихотворения или выведите
«not a poem».

## Входные данные

n (2 ≤ n ≤ 100), затем n строк не длиннее 50 символов, в каждой не
меньше четырёх слогов; в них только латинские буквы, пробелы, дефисы
и квадратные скобки.

## Выходные данные

«trochee», «iamb», «dactyl», «amphibrach», «anapaest» или «not a poem».

## Примеры

### Пример 1

Ввод:

```
4
My [un]-cle [high] i-[deals] ins-[pire] him
But [when] past [jo]-king [he] fell [sick]
he [real]-ly [forced] one [to] ad-[mire] him
and [ne]-ver [played] a [shrew]-der [trick]
```

Вывод:

```
iamb
```

## Решение

Разобьём каждую строку по пробелам и дефисам на слоги и отметим те, в
которых есть скобка. Размер со стопами из k слогов и ударением на месте
p подходит строке, если слог i (с нуля) ударный ровно тогда, когда
i mod k = p − 1. Усечённая последняя стопа ничего не меняет: важно лишь
место внутри стопы. Ответ — первый размер, подходящий всем строкам; при
хотя бы четырёх слогах в строке никакие два размера не дают одинаковых
отметок, так что порядок проверок не важен. `O(L)` для L символов
всего.

В примере каждая строка ударяет слоги 2, 4, 6, 8 — это ямб.

Подводные камни:

- совпадать должен каждый слог, и безударные тоже: безударный слог на
  ударном месте нарушает размер;
- между словами может быть несколько пробелов, так что пустые куски
  надо пропускать;
- «not a poem» — три слова, и вывести их нужно в точности.

Ответы совпадают с независимой принятой реализацией на 300 случайных
стихотворениях, 120 из которых испорчены в одном слоге или в одной
строке.
