## Задача

К Дену пришли n друзей; i-й купил aᵢ литров сока, и все, включая Дена,
выпили поровну. Затем Ден платит 100 рублей за сок, выпитый не теми,
кто его покупал, справедливо разделив их между друзьями, купившими
больше, чем выпили. Сколько рублей получит каждый друг с округлением
вниз?

## Входные данные

n (2 ≤ n ≤ 100), затем a₁, …, aₙ (0 ≤ aᵢ ≤ 100) с положительной суммой.

## Выходные данные

Рубли каждого друга с округлением вниз.

## Примеры

### Пример 1

Ввод:

```
3
10 10 10
```

Вывод:

```
33 33 33
```

### Пример 2

Ввод:

```
2
10 0
```

Вывод:

```
100 0
```

## Решение

Если всего S литров, каждый из n + 1 человек выпивает S/(n + 1), так что
друг i купил для других aᵢ − S/(n + 1) литров, если это положительно, и
ничего иначе. Деньги делятся пропорционально этим количествам. Умножив
все на n + 1, остаёмся в целых числах: eᵢ = max(0, aᵢ(n + 1) − S), и
друг i получает ⌊100·eᵢ / Σ e⌋. Сумма никогда не равна 0: друзья вместе
купили S, а выпили только nS/(n + 1). `O(n)`; в Python — `O(n²)`.

В первом примере каждый выпил 7,5 литра, а каждый друг оплатил Дену 2,5
литра, так что деньги делятся на троих: по 33 после округления.

Подводные камни:

- Ден тоже пьёт, поэтому доля — S/(n + 1), а не S/n;
- друзья, купившие меньше, чем выпили, не получают ничего;
- точные целые числа снимают сомнения насчёт округления вниз.

Доли совпадают с независимой принятой реализацией на двухстах
случайных посиделках.
