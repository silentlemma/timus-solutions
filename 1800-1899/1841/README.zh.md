# 1841. 缆车

[Timus 1841](https://acm.timus.ru/problem.aspx?space=1&num=1841) · 难度 2141 · segment_tree

原题作者 Denis Dublennykh，出自 2010 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一条小路沿 n 段折线上山，折线顶点严格沿山坡向上排列；y 轴沿山坡向上。沿第 i 段行走时，x 每改变一个单位花费 vᵢ。
小路上有些点是缆车的下端：缆车从起点严格沿山坡向上，在下一次与小路相交的点结束，乘坐它需要给定的时间。没有人往下走。求从山脚到山顶的最少时间。

## 输入

n（1 ≤ n ≤ 10⁵），然后是从山脚到山顶的 n + 1 个顶点的 x 坐标；相邻的互不相同。接着 n 行：vᵢ、从第 i 段出发的缆车数 mᵢ，以及按山坡向上顺序给出的 mᵢ 对（起点的 x，乘坐时间）。
没有两条缆车从同一点出发，从两段公共顶点出发的缆车只列出一次，每条缆车都在小路上结束。坐标绝对值不超过 10⁶，时间为正且不超过 10⁶，缆车不超过 10⁵ 条。

## 输出

到达山顶的最少时间。

## 样例

### 样例 1

输入：

```
4
0 5 15 10 0
1 1 1 100
1 1 7 1
1 0
1 0
```

输出：

```
15
```

### 样例 2

输入：

```
3
0 10 0 10
10 0
10 1 10 1
10 0
```

输出：

```
101
```

## 解法

只有点沿小路的顺序有意义，而沿小路走到某点的花费是已知的：走到它所在段的第一个顶点的花费，加上 vᵢ 乘以 x 方向的距离。称之为该点的步行花费；它沿小路严格递增。

缆车落在哪里。若每段拥有其 x 范围但不含第一个顶点，那么除山脚外小路上的每个点恰好属于一段（因此公共顶点处的起点属于下面那段）。
从第 s 段上 x 处出发的缆车，落在 s 之后第一个 x 范围包含 x 的段上。在起点坐标上（除 Python 外均压缩）从上往下处理各段：在线段树中把第 s 段涂到它的 x 范围之前，先查询 s 拥有的所有缆车。
树节点只保存最后一次涂在它上面的颜色，而涂色沿小路往下进行，所以从叶子到根的路径上最小的段号就是落点所在的段。

最优时间。设 best(p) 为到达点 p 的最少时间，gain = min(best(p) − 步行花费(p))，取遍已到达的点；在山脚 gain = 0，且步行保持这一差值，因此在当前点有 best(p) = 步行花费(p) + gain。
按步行花费顺序处理起点和落点，花费相等时落点在前。起点记录 best = 花费 + gain；落点把 gain 设为 min(gain, best(起点) + 时间 − 花费(落点))。答案是山顶的步行花费加上 gain。`O((n + m) log(n + m))`；Python：`O(U + (n + m) log U + m log(m + 1))`，其中 U = max(x) − min(x) + 1。

在第一个样例中，从 x = 1 出发的缆车从第一段升到最后一段，落点步行花费 29，乘坐 100，不如步行。
从 x = 7 出发的缆车起点步行花费为 7，也落在最后一段，落点花费 23，用时 1，于是 gain 变为 7 + 1 − 23 = −15，答案为 30 − 15 = 15。

注意事项：

- 从公共顶点出发的缆车属于它下面的那段，无论它列在哪一行；
- 缆车可能落在很多段之后，或者恰好落在另一条缆车的起点上，"落点在前"的顺序会处理这种情况；
- 时间可达约 2·10¹⁷，超出 32 位整数，但在 64 位范围内；
- Python 版本在 PyPy 上运行，把数据放在机器整数的扁平数组中，约 20 MB；早先使用 Python 整数列表的版本在评测的第 17 个测试上占用 69 MB。

在四百座随机山以及大测试上，答案与一个独立的已通过实现和最短路搜索一致。
