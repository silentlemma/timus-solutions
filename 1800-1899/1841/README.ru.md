# 1841. Канатные дороги

[Timus 1841](https://acm.timus.ru/problem.aspx?space=1&num=1841) · сложность 2141 · segment_tree

Автор оригинальной задачи — Денис Дублённых; Ural SU Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Тропинка поднимается на гору ломаной из n звеньев, вершины которой идут
строго вверх по склону; ось y направлена вверх по склону. Проход по
звену i стоит vᵢ за единицу изменения x. Некоторые точки тропинки —
нижние концы канатных дорог: дорога идёт строго вверх по склону от
своего начала и заканчивается в следующей точке пересечения с
тропинкой, а поездка по ней занимает заданное время. Вниз никто не
ходит. Найти наименьшее время от подножия до вершины.

## Входные данные

n (1 ≤ n ≤ 10⁵), затем n + 1 координата x вершин от подножия к вершине
горы; соседние различны. Затем n строк: vᵢ, число mᵢ канатных дорог,
начинающихся на звене i, и mᵢ пар (x начала, время поездки) в порядке
вверх по склону. Никакие две дороги не начинаются в одной точке, дорога
из общей вершины звеньев указана один раз, и каждая дорога
заканчивается на тропинке. Координаты по модулю не больше 10⁶, времена
положительны и не больше 10⁶, дорог не больше 10⁵.

## Выходные данные

Наименьшее время подъёма на вершину.

## Примеры

### Пример 1

Ввод:

```
4
0 5 15 10 0
1 1 1 100
1 1 7 1
1 0
1 0
```

Вывод:

```
15
```

### Пример 2

Ввод:

```
3
0 10 0 10
10 0
10 1 10 1
10 0
```

Вывод:

```
101
```

## Решение

Важен только порядок точек вдоль тропинки, а пешком дойти до точки
стоит известную величину: путь до первой вершины её звена плюс vᵢ,
умноженное на расстояние по x. Назовём это пешей стоимостью точки; она
строго растёт вдоль тропинки.

Куда приезжает дорога. Каждая точка тропинки, кроме подножия,
принадлежит ровно одному звену, если звено владеет своим диапазоном x
без первой вершины (начало в общей вершине поэтому принадлежит нижнему
звену). Дорога из точки x на звене s приезжает на первое звено после s,
диапазон которого содержит x. Обходим звенья сверху вниз над
координатами начал (сжатыми, кроме Python): прежде чем покрасить звено s
по его диапазону x в дереве отрезков, находим все дороги, которыми владеет s. Узел дерева
хранит только последнюю краску, положенную на него, а краски идут вниз
по тропинке, поэтому наименьший номер звена на пути от листа к корню —
звено приезда.

Лучшие времена. Пусть best(p) — наименьшее время до точки p, а
gain = min(best(p) − пешая стоимость(p)) по уже достигнутым точкам; у
подножия gain = 0, а ходьба сохраняет эту разность, поэтому
best(p) = пешая стоимость(p) + gain в текущей точке. Обрабатываем начала
и приезды по пешей стоимости, при равенстве сначала приезды. Начало
запоминает best = стоимость + gain; приезд присваивает gain значение
min(gain, best(начала) + время − стоимость(приезда)). Ответ — пешая
стоимость вершины плюс gain. `O((n + m) log(n + m))`; Python: `O(U + (n + m) log U + m log(m + 1))`,
где U = max(x) − min(x) + 1.

В первом примере дорога из x = 1 поднимается с первого звена на
последнее, где пешая стоимость 29, и едет 100 — хуже ходьбы. Дорога из
x = 7 начинается при пешей стоимости 7 и тоже приезжает на последнее
звено, при стоимости 23, за 1 единицу времени, так что gain становится
7 + 1 − 23 = −15, а ответ 30 − 15 = 15.

Подводные камни:

- дорога из общей вершины принадлежит звену под ней, в какой бы строке
  она ни была указана;
- дорога может приехать на много звеньев позже или ровно в начало
  другой дороги, что учитывает порядок «сначала приезды»;
- времена доходят примерно до 2·10¹⁷: больше 32 бит, но в пределах 64;
- решение на Python работает на PyPy и держит данные в плоских массивах
  машинных целых, около 20 МБ; прежняя версия со списками целых чисел
  Python занимала 69 МБ на 17-м тесте судьи.

Ответы совпадают с независимой принятой реализацией и с поиском
кратчайшего пути на четырёхстах случайных горах, а также на больших
тестах.
