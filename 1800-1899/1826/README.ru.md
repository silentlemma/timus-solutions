# 1826. Минное поле

[Timus 1826](https://acm.timus.ru/problem.aspx?space=1&num=1826) · сложность 310 · greedy

Автор оригинальной задачи — Дмитрий Теряев; XII открытое личное первенство УрГУ, 19 марта 2011 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Разведгруппа из n человек переходит минное поле с одним миноискателем:
двое переходят вместе, затем один возвращается с миноискателем, и так
далее. У каждого своё время перехода, а пара движется со скоростью
более медленного. Найти наименьшее общее время перехода всей группы.

## Входные данные

n (2 ≤ n ≤ 100), затем n времён перехода — положительные целые не
больше 600.

## Выходные данные

Наименьшее общее время.

## Примеры

### Пример 1

Ввод:

```
4
1
10
5
2
```

Вывод:

```
17
```

## Решение

Это задача о мосте и фонарике. Отсортируем времена a ≤ b ≤ … ≤ y ≤ z.
Пока ждут больше трёх человек, переводим двух самых медленных одним из
двух способов и берём более дешёвый:

- самый быстрый сопровождает каждого: z + a + y + a = 2a + y + z;
- переходят двое самых быстрых, a возвращается, двое самых медленных
  переходят вместе, b возвращается: b + a + z + b = a + 2b + z.

В обоих случаях двое самых быстрых снова на исходном берегу, а
оставшихся на два меньше. Трое переходят за a + b + c (a сопровождает
обоих), двое — за время более медленного. Обменный аргумент показывает,
что некоторый оптимальный план всегда переводит двух самых медленных
именно так. `O(n log n)`.

В примере (1, 2, 5, 10) пара стоит 1 + 2·2 + 10 = 15 против
2 + 5 + 10 = 17 при сопровождении, а последние двое — 2: итого 17.

Подводные камни:

- всегда сопровождать самым быстрым не оптимально: 1, 2, 5, 10 заняли
  бы 19;
- всегда объединять медленных тоже не оптимально, если второй по
  скорости медленный;
- выбор делается заново в каждом раунде.

Ответы совпадают с поиском Дейкстры по всем состояниям для групп до 7
человек и с независимой принятой реализацией на случайных группах.
