# 1861. 戴雅的墓地

[Timus 1861](https://acm.timus.ru/problem.aspx?space=1&num=1861) · 难度 1001 · dp

原题作者 Mikhail Rubinchik，出自 2011 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Team.GOV Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一段 n 个字符的铭文部分磨损了："?" 表示无法辨认的字母。以最佳方式恢复磨损的字母后，给定的 m 个字母的名字最多能在铭文中出现多少次？出现可以重叠，大小写不同的字母视为不同。

## 输入

铭文（字母和 "?"）和名字（字母），1 ≤ m ≤ n ≤ 1000。

## 输出

最多可能的出现次数。

## 样例

### 样例 1

输入：

```
R?la?dDefe?tedHi?Br?t?erArc?i??ld
Archibald
```

输出：

```
1
```

### 样例 2

输入：

```
Arch?????rchibaldIronfist
Archibald
```

输出：

```
1
```

## 解法

选择名字副本的起始位置。若名字的每个字母都落在相同的字母或 "?" 上，副本就能放在 j 处。相距 d < m 的两个副本会重叠，它们一致当且仅当 d 是名字的周期，即名字平移 d 后与自身吻合；相距 m 或更远的副本不会相遇。

只要每个副本都与下一个一致，整组副本就是一致的。对三个副本 j₁ < j₂ < j₃，第一个与第三个的每个公共位置也都在第二个内部，所以一致性沿链传递。
因此对最后一个副本做动态规划：best[j] 等于 k ≤ j − m 的 best[k] 以及名字的各周期 d 对应的 best[j − d] 中的最大值再加一。周期由前缀函数给出：它们是 m − b，b 取名字的各个 border。
周期最多 m 个，位置有 n − m + 1 个，所以动态规划最多 m(n − m + 1) ≤ (n + 1)²/4 步。Python 版本用一次对平移后的位掩码（每个字母一个掩码）求 AND 来找出可放置的位置。`O(n·m)`。

在第二个样例中，副本可以放在位置 0 和 8，但 8 不是 "Archibald" 的周期，所以只能写出其中一个。

注意事项：

- 相邻副本一致就足够了，不需要记录恢复出的具体字母；
- "?" 可以变成任何字母，包括名字中没有的字母；
- "A" 和 "a" 是不同的字母。

在四百段短铭文上答案与枚举所有恢复方式一致，在大测试上与一个独立的已通过实现一致。
