# 1861. Кладбище в Дейе

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Надпись из n символов частично стёрлась: «?» обозначает букву, которую
не прочесть. Восстановив стёртые буквы наилучшим образом, сколько раз
наибольшее может встретиться в надписи данное имя из m букв? Вхождения
могут пересекаться, а буквы разного регистра различны.

## Входные данные

Надпись (буквы и «?») и имя (буквы), 1 ≤ m ≤ n ≤ 1000.

## Выходные данные

Наибольшее возможное число вхождений.

## Примеры

### Пример 1

Ввод:

```
R?la?dDefe?tedHi?Br?t?erArc?i??ld
Archibald
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
Arch?????rchibaldIronfist
Archibald
```

Вывод:

```
1
```

## Решение

Выберем позиции, где начинаются копии имени. Копия помещается в j,
если каждая буква имени попадает на ту же букву или на «?». Две копии
на расстоянии d < m пересекаются и согласованы ровно тогда, когда d —
период имени, то есть имя, сдвинутое на d, совпадает с собой; копии на
расстоянии m и больше не встречаются.

Набор копий согласован, как только каждая копия согласована со
следующей. Для трёх копий j₁ < j₂ < j₃ каждая общая позиция первой и
третьей лежит и внутри второй, так что согласованность передаётся по
цепочке. Отсюда динамика по последней копии: best[j] на единицу больше
наибольшего из best[k] при k ≤ j − m и best[j − d] для периодов d
имени. Периоды даёт префикс-функция: это m − b для граней b имени. При
не более чем m периодах и n − m + 1 позициях динамика занимает не
больше m(n − m + 1) ≤ (n + 1)²/4 шагов. Решение на Python находит подходящие
позиции одним AND сдвинутых битовых масок, по маске на букву.
`O(n·m)`.

Во втором примере копии помещаются в позиции 0 и 8, но 8 — не период
«Archibald», так что написать можно только одну из них.

Подводные камни:

- достаточно согласованности соседних копий; сами восстановленные
  буквы отслеживать не нужно;
- «?» может стать любой буквой, в том числе отсутствующей в имени;
- «A» и «a» — разные буквы.

Ответы совпадают с перебором всех восстановлений на четырёхстах
коротких надписях и с независимой принятой реализацией на больших
тестах.
