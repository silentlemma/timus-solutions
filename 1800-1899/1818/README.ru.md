# 1818. Честные рыбаки

[Timus 1818](https://acm.timus.ru/problem.aspx?space=1&num=1818) · сложность 1916 · number_theory

Оригинальная задача — Tavrida NU Akai Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n рыбаков по очереди делят улов. Проснувшийся i-м выбрасывает aᵢ рыб,
чтобы остаток делился на n равных частей, забирает одну часть и
оставляет остальные n − 1, не зная, что другие уже взяли своё. По всем
aᵢ найти наименьший возможный улов, не меньше одной рыбы.

## Входные данные

n (2 ≤ n ≤ 2000), затем a₁, …, aₙ (0 ≤ aᵢ ≤ n − 1).

## Выходные данные

Наименьший улов.

## Примеры

### Пример 1

Ввод:

```
2
1 1
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
3
1 0 2
```

Вывод:

```
19
```

## Решение

Если k-й рыбак находит Fₖ рыб, условие — Fₖ ≡ aₖ (mod n), а следующий
находит Fₖ₊₁ = (Fₖ − aₖ)/n · (n − 1). При Fₖ ≡ aₖ неравенство Fₖ ≥ aₖ
выполняется само, так как aₖ < n.

Прибавка t к улову добавляет t·((n − 1)/n)^(k−1) к Fₖ. При t = s·nʲ это
кратно n для первых j рыбаков, и их условия сохраняются, а рыбак j + 1
получает на s·(n − 1)ʲ ≡ s·(−1)ʲ больше. Поэтому улов строится по
цифрам в системе счисления по основанию n: на шаге j берётся
единственное s из [0, n), которое чинит рыбака j + 1, к улову
прибавляется s·nʲ, к найденному им — s·(n − 1)ʲ, и дальше следующий
рыбак. Подходящие уловы — ровно один вычет по модулю nⁿ, так что ответ
равен этому вычету или nⁿ, если вычет равен 0.

Числа дорастают примерно до n·log₁₀ n ≈ 6600 цифр, поэтому все решения
работают с длинной арифметикой: библиотечной в Go, Java и Python и
небольшим типом по основанию 10⁹ в C++ и Rust, где есть только нужные
операции: умножение со сложением, вычитание, деление и остаток от
деления на малое число. `O(n² log n)` операций над машинными словами.

Для второго примера: рыбаку 1 нужно X ≡ 1 (mod 3), так что X = 1, рыбак 1
находит 1 и оставляет 0 рыбаку 2, которому нужно 0: годится, s = 0.
Рыбаку 3 тоже остаётся 0, а нужно 2; прибавка s·9 к X даёт рыбаку 3
на s·4 ≡ s больше, так что s = 2 и X = 19.

Подводные камни:

- вычет 0 означает nⁿ рыб, а не 0: хотя бы одну рыбу поймали;
- (n − 1)ʲ по модулю n чередуется между 1 и −1, так что на нечётных
  шагах цифра меняет знак;
- найденное каждым рыбаком нужно хранить точно, а не по модулю n:
  деление на n подмешивает старшие цифры.

Ответы совпадают с перебором при n до 5 и с независимой принятой
реализацией на случайных тестах до n = 2000.
