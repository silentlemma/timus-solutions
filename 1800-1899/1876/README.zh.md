# 1876. 蜈蚣的早晨

[Timus 1876](https://acm.timus.ru/problem.aspx?space=1&num=1876) · 难度 55 · math

原题作者 Mikhail Rubinchik，出自 2011 年乌拉尔地区团队程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

蜈蚣有 40 只左脚和 40 只右脚，床下有 a 只左拖鞋和 b 只右拖鞋。它先给左脚穿鞋：摸出一只拖鞋需要一秒。左拖鞋穿到下一只左脚上。右拖鞋要多花一秒：穿到一只光着的右脚上，或者在右脚都已穿好时扔掉。然后用同样的方式给右脚穿鞋。最坏情况下需要多少秒？

## 输入

a 和 b（40 ≤ a, b ≤ 100）。

## 输出

最坏情况下的秒数。

## 样例

### 样例 1

输入：

```
40 40
```

输出：

```
120
```

## 解法

设给左脚穿鞋时摸出了 k 只右拖鞋；左脚阶段耗时 40 + 2k 秒。若 k ≥ 40，右脚已全部穿好，右脚阶段为空。这种情况最坏是先摸出全部 b 只右拖鞋：2b + 40 秒。若 k < 40，右脚阶段可能先摸出全部 a − 40 只多余的左拖鞋，每只两秒，再摸出缺少的 40 − k 只右拖鞋。总计 2a + k，在 k = 39 时最大：2a + 39。答案为 max(2b + 40, 2a + 39)。`O(1)`。

两种拖鞋各 40 只时，两种情形都至多 120 秒。

注意事项：

- 多余的左拖鞋只能在右脚阶段摸出，所以左脚阶段不能把右脚全部穿好：最坏是 39 只；
- 一旦右脚全部穿好，左脚阶段之后就什么也不会发生；
- 当 a = 41、b = 40 时第二种情形已经更大：121 对 120。

对所有输入，公式都与枚举所有摸拖鞋顺序的结果一致，也与一个独立的已通过实现一致。
