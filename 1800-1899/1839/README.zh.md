# 1839. 门塔库卢斯

[Timus 1839](https://acm.timus.ru/problem.aspx?space=1&num=1839) · 难度 2476 · geometry

原题作者 Alexey Samsonov（由 Victor Kamashev 准备），出自 2011 年 4 月第十五届乌拉尔竞技编程公开锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

弧 PQR 和两个点 A、B 构成一张笑脸，当 A 和 B 位于直线 PR 上与 Q 相对的一侧，角 APR、ARP、BPR、BRP 都是锐角，A 和 B 到直线 PR 的距离小于 PR 长度的两倍，并且直线 AB 与线段 PR 没有公共点。
给出 n 条弧和 m 个点，统计笑脸的个数。

## 输入

n 和 m（1 ≤ n ≤ 100，1 ≤ m ≤ 10⁴），然后是 n 条弧，每条按沿弧的顺序给出三个点，每条弧不超过半圆，然后是 m 个点。所有坐标都是绝对值不超过 10⁴ 的整数。

## 输出

笑脸的个数。

## 样例

### 样例 1

输入：

```
2 7
-2 2 0 0 2 2
-2 -2 0 0 2 -2
-1 3
1 3
0 5
0 3
-1 -3
1 -3
2 -3
```

输出：

```
4
```

## 解法

对每条弧分别处理。前三个条件只涉及单个点，可以用精确的整数检验：用叉积判断在 PR 的哪一侧，用两个点积判断底角是否为锐角，用 |cross| < 2·|PR|² 判断距离。
称通过检验的点为眼睛；它们都位于 PR 上方、线段正上方的带状区域内。

对两只眼睛 A 和 B，直线 AB 不碰到线段 PR，当且仅当 P 和 R 严格位于它的同一侧。P、A、B 的定向说明从 P 看 B 的角是否大于 A 的角，R、A、B 的定向说明从 R 看 B 的角是否更小。
所以直线不碰到 PR，当且仅当两只眼睛按 P 处的角和按 R 处的角排列的顺序相反；角相等时 P 或 R 落在直线上，永远不计数。
把眼睛按 P 处的角排序，相等的再按 R 处的角排序，用树状数组统计 R 处角的严格逆序对。

角通过正切 height/near 比较，使用小于 2³¹ 的数的乘积，因此全部精确。`O(n·m log m)`。

在样例中，上方的弧得到眼睛 (−1, 3)、(1, 3)、(0, 3) 和 (0, 5)：y = 3 上的三个两两连成平行线，而经过 (0, 5) 和另一只眼睛的直线都与 PR 相交。
下方的弧得到 (−1, −3) 和 (1, −3)；从 (2, −3) 看 R 是直角。共 3 + 1 张笑脸。

注意事项：

- 经过 P 或 R 的直线与线段接触，所以与 P 或 R 共线的眼睛不能配对；
- P 或 R 处为直角的点以及直线 PR 上的点都要排除；
- 答案可能超过 2³¹；
- Python 版本先按浮点正切排序，再用精确乘积修正顺序，并在 PyPy 上运行。

在数百个小的随机页面上，答案与逐对检查所有点的结果一致，并在大测试上与一个独立的已通过实现一致。
