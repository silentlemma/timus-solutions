# 1839. Ментакулус

[Timus 1839](https://acm.timus.ru/problem.aspx?space=1&num=1839) · сложность 2461 · geometry

## Задача

Дуга PQR и две точки A, B образуют рожицу, если A и B лежат по другую
сторону от прямой PR, нежели Q, углы APR, ARP, BPR, BRP острые, A и B
ближе к прямой PR, чем удвоенная длина PR, и прямая AB не имеет общих
точек с отрезком PR. По n дугам и m точкам посчитать рожицы.

## Входные данные

n и m (1 ≤ n ≤ 100, 1 ≤ m ≤ 10⁴), затем n дуг — по три точки в порядке
вдоль дуги, каждая дуга не больше полуокружности, затем m точек. Все
координаты целые, по модулю не больше 10⁴.

## Выходные данные

Число рожиц.

## Примеры

### Пример 1

Ввод:

```
2 7
-2 2 0 0 2 2
-2 -2 0 0 2 -2
-1 3
1 3
0 5
0 3
-1 -3
1 -3
2 -3
```

Вывод:

```
4
```

## Решение

Каждую дугу рассматриваем отдельно. Первые три условия касаются одной
точки и проверяются точно в целых: сторона от PR — векторным
произведением, острые углы при основании — двумя скалярными, а
расстояние — условием |cross| < 2·|PR|². Прошедшие точки назовём
глазами; их проекции лежат строго внутри отрезка PR.

Для двух глаз A и B прямая AB не задевает отрезок PR ровно тогда,
когда P и R строго по одну сторону от неё. Ориентация P, A, B говорит,
виден ли B из P под большим углом, чем A, а ориентация R, A, B —
виден ли B из R под меньшим углом. Значит, прямая не задевает PR ровно
тогда, когда глаза идут в противоположных порядках по углу при P и по
углу при R, а равные углы, при которых P или R лежит на прямой, не
считаются никогда. Сортируем глаза по углу при P, равные — по углу при
R, и считаем строгие инверсии углов при R деревом Фенвика.

Углы сравниваются через тангенсы height/near, произведениями чисел
меньше 2³¹, так что всё остаётся точным. `O(n·m log m)`.

В примере у верхней дуги глаза (−1, 3), (1, 3), (0, 3) и (0, 5): три
на y = 3 попарно дают параллельные прямые, а любая прямая через (0, 5)
и другой глаз пересекает PR. У нижней дуги глаза (−1, −3) и (1, −3);
из (2, −3) R видна под прямым углом. Получается 3 + 1 рожицы.

Подводные камни:

- прямая через P или R касается отрезка, поэтому глаза на одной прямой
  с P или с R пару не образуют;
- прямые углы при P или R и точки на прямой PR исключаются;
- ответ может превышать 2³¹;
- решение на Python сначала сортирует по тангенсам во float, а затем
  исправляет порядок точными произведениями, и работает на PyPy.

Ответы совпадают с проверкой всех пар точек на сотнях маленьких
случайных страниц и с независимой принятой реализацией на больших.
