## Задача

Мультимножество целых положительных чисел вначале пусто. Каждая
операция добавляет число или удаляет одну копию лежащего там числа.
После каждой операции вывести наибольший общий делитель всего
мультимножества; НОД пустого мультимножества объявлен равным 1.

## Входные данные

q (1 ≤ q ≤ 10⁵), затем q строк вида «+ x» или «- x», где
1 ≤ x ≤ 10⁹. Удаляются только имеющиеся числа.

## Выходные данные

НОД после каждой операции, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
5
+ 8
+ 6
+ 8
- 8
- 8
```

Вывод:

```
8
2
2
2
6
```

## Решение

НОД нельзя «отменить», поэтому для удаления нужна структура. Дадим
каждому добавлению свой лист дерева отрезков над операциями и будем
хранить для каждого значения стек листьев, где оно лежит. Добавление x
записывает x в лист этой операции; удаление x опустошает верхний лист
его стека, записывая 0, что не меняет никакой НОД, ведь
НОД(a, 0) = a. Каждый внутренний узел хранит НОД детей, так что корень —
НОД мультимножества, а корень 0 означает пустое мультимножество:
выводим 1. Обновление листа пересчитывает его предков, и подъём можно
остановить на первом узле, значение которого не изменилось: выше тогда
ничего не меняется. `O(q log q log x)`.

В примере листья хранят 8, 6 и 8, так что НОД равен 2. Удаление двух
восьмёрок опустошает два листа и оставляет 6.

Подводные камни:

- пустое мультимножество даёт 1, а не 0;
- равные числа могут добавляться несколько раз и удаляться по одному;
- при половине секунды важны и ранняя остановка подъёма, и быстрое
  чтение; решение на Python работает на PyPy.

Ответы совпадают с независимой принятой реализацией на тридцати
случайных файлах до 10⁵ операций.
