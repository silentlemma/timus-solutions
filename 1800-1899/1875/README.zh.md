# 1875. Angry Birds

原题作者 Fedor Fominykh，出自 2011 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

原点处的弹弓能以任意速度、任意角度发射小鸟；小鸟只受重力作用，所以每只都沿开口向下的抛物线飞行。小鸟会穿过它击中的猴子继续飞。五只猴子挂在坐标为正的点上，任意两只都不与弹弓共线。最少需要几发才能击中所有猴子？

## 输入

五行猴子坐标，都是不超过 10 000 的正整数。

## 输出

最少的发射次数。

## 样例

### 样例 1

输入：

```
1 5
2 8
3 9
4 8
5 5
```

输出：

```
1
```

## 解法

一发的轨迹是 y = bx − cx²（c > 0），而任何这样的曲线都能飞出。除以 x 后，斜率 y/x = b − cx 关于 x 线性递减。所以一发能击中若干只猴子，当且仅当它们的斜率 y/x 作为 x 的函数落在同一条递减直线上。两只猴子只有在 x 不同且右边那只斜率更小时才能共用一发。这样的一对确定了这一发，其余在它上面的猴子用共线检验找出，去分母后全部用整数计算。把每只单独的猴子和每一对确定的一发作为候选集合，在 2⁵ 个子集上做动态规划，求覆盖全部五只的最少集合数。`O(1)`。

样例中 x = 1 … 5 时斜率为 5, 4, 3, 2, 1，是一条递减直线，所以抛物线 y = x(6 − x) 一发击中所有猴子。

注意事项：

- 上下排列（x 相同）的猴子永远不能共用一发；
- 斜率随 x 增大的一对需要开口向上的抛物线，重力不允许；
- 乘积可达约 10¹⁶，需要 64 位整数。

在 300 个随机关卡上（其中许多有三到五只猴子在同一条抛物线上），答案与一个独立的已通过实现一致。
