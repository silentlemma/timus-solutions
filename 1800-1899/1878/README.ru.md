## Задача

Головоломка состоит из четырёх прозрачных слоёв 4 × 4 на общей оси. На
каждом слое четыре цветных квадратика, по одному каждого из четырёх
цветов, расположенные так, что поворот слоя на четверть оборота
переводит каждый в следующую четверть. Четыре квадратика каждого слоя
образуют орбиту этого поворота. У всех слоёв одинаковый циклический
порядок цветов по часовой стрелке с точностью до поворота, как на
[исходной схеме слоёв](https://acm.timus.ru/image/get.aspx/a394d0eb-f9d5-4bc2-846a-74ef972e9e4b).
Сверху слои заполняют сетку
4 × 4. Головоломка собрана, когда каждая четверть 2 × 2 одного цвета.
Ход — поворот одного слоя на 90° в любую сторону. По виду сверху
найдите наименьшее число ходов до сборки.

## Входные данные

Четыре строки по четыре цвета от 1 до 4 — вид сверху.

## Выходные данные

Наименьшее число ходов.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
2 1 2 3
1 1 2 2
4 4 3 3
1 4 3 4
```

Вывод:

```
1
```

## Решение

У всех слоёв одинаковый циклический порядок цветов, поэтому совмещение
квадратиков цвета 1 совмещает и остальные цвета.
На каждом слое ровно один квадратик цвета 1, и он задаёт ориентацию
слоя — свою четверть. Занумеруем четверти в том порядке, в каком их
обходит квадратик при повороте (левая верхняя, правая верхняя, правая
нижняя, левая нижняя). Головоломка собрана, когда все четыре квадратика
цвета 1 в одной четверти t. Слою, чей квадратик в четверти p, нужно
min(d, 4 − d) ходов, где d = (p − t) mod 4. Перебираем все четыре t и
берём самое дешёвое. `O(1)`.

В примере три квадратика цвета 1 в левой верхней четверти и один в
левой нижней, на четверть оборота дальше: один ход.

Подводные камни:

- совмещать только цвет 1 можно благодаря общему циклическому порядку
  цветов (как в тесте 01); одного квадратика каждого цвета на слое
  для этого недостаточно;
- в собранном состоянии цвет 1 может быть в любой четверти: кубик
  может оказаться повёрнут целиком;
- слой, развёрнутый на пол-оборота, стоит два хода в любую сторону;
- четверти надо нумеровать по кругу, а не по строкам, иначе расстояния
  будут неверны.

Решение на Python совпадает с независимым поиском в ширину по поворотам
физических слоёв на всех 1536 разрешимых полях, включая все соответствия
между числами и цветами.

## Оптимизированные решения

Формула дисбаланса фиксированного поля заменяет перебор целевых цветов и циклы модульных расстояний. Подсчитываем один цвет в каждом квадранте в порядке строк, сравниваем дисбалансы противоположных квадрантов и берём соответствующее дополнение. Существенен циклический порядок цветов на физической схеме; произвольная перестановка квадрантов неэквивалентна. Размер поля фиксирован, поэтому память и число операций постоянны относительно параметров входа.
