## Задача

Головоломка состоит из четырёх прозрачных слоёв 4 × 4 на общей оси. На
каждом слое четыре цветных квадратика, по одному каждого из четырёх
цветов, расположенные так, что поворот слоя на четверть оборота
переводит каждый в следующую четверть. Сверху слои заполняют сетку
4 × 4. Головоломка собрана, когда каждая четверть 2 × 2 одного цвета.
Ход — поворот одного слоя на 90° в любую сторону. По виду сверху
найдите наименьшее число ходов до сборки.

## Входные данные

Четыре строки по четыре цвета от 1 до 4 — вид сверху.

## Выходные данные

Наименьшее число ходов.

## Примеры

### Пример 1

Ввод:

```
2 1 2 3
1 1 2 2
4 4 3 3
1 4 3 4
```

Вывод:

```
1
```

## Решение

На каждом слое ровно один квадратик цвета 1, и он задаёт ориентацию
слоя — свою четверть. Занумеруем четверти в том порядке, в каком их
обходит квадратик при повороте (левая верхняя, правая верхняя, правая
нижняя, левая нижняя). Головоломка собрана, когда все четыре квадратика
цвета 1 в одной четверти t. Слою, чей квадратик в четверти p, нужно
min(d, 4 − d) ходов, где d = (p − t) mod 4. Перебираем все четыре t и
берём самое дешёвое. `O(1)`.

В примере три квадратика цвета 1 в левой верхней четверти и один в
левой нижней, на четверть оборота дальше: один ход.

Подводные камни:

- в собранном состоянии цвет 1 может быть в любой четверти: кубик
  может оказаться повёрнут целиком;
- слой, развёрнутый на пол-оборота, стоит два хода в любую сторону;
- четверти надо нумеровать по кругу, а не по строкам, иначе расстояния
  будут неверны.

Ответы совпадают с независимой принятой реализацией на 240 случайных
состояниях, полученных поворотами слоёв собранного кубика.
