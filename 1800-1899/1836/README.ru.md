# 1836. Вавилонская рыбка

[Timus 1836](https://acm.timus.ru/problem.aspx?space=1&num=1836) · сложность 1173 · geometry

Автор оригинальной задачи — Денис Дублённых; XV открытый чемпионат Урала по спортивному программированию, апрель 2011 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Открытый аквариум имеет квадратное основание со стороной a. Датчик на
каждом вертикальном ребре показывает уровень воды на этом ребре;
машина наклоняется, так что поверхность может быть не горизонтальной.
Для каждого теста найти объём воды или ответить «error», если такие
показания невозможны, или «ambiguous», если они не определяют объём.

## Входные данные

t (1 ≤ t ≤ 10⁴), затем t строк: a и четыре уровня, рёбра по порядку
вокруг основания, все целые от 0 до 10⁶, a > 0.

## Выходные данные

Для каждого теста объём с абсолютной или относительной погрешностью не
больше 10⁻⁶, либо «error», либо «ambiguous».

## Примеры

### Пример 1

Ввод:

```
2
10 2 3 4 3
10 2 3 3 3
```

Вывод:

```
300.000
error
```

## Решение

Поверхность — плоскость, поэтому её высоты f₁, …, f₄ над углами
удовлетворяют f₁ + f₃ = f₂ + f₄, а датчик показывает max(0, fᵢ):
показание 0 говорит лишь, что fᵢ ≤ 0.

- Нулевых показаний нет: плоскость известна. Она согласована ровно
  тогда, когда суммы по диагоналям равны, и объём равен
  a²·(h₁ + h₂ + h₃ + h₄)/4.
- Все показания нулевые: плоскость нигде не выше дна, объём 0.
- Один ноль, в углу i: плоскость даёт fᵢ = (left + right) − far, и это
  должно быть не больше 0. Тогда воде не достаётся угловой тетраэдр:
  плоскость опускается до fᵢ в углу и пересекает ноль на двух рёбрах
  на долях −fᵢ/(left − fᵢ) и −fᵢ/(right − fᵢ). Его объём — шестая часть
  произведения рёбер — прибавляется к средней высоте.
- Два нуля и больше: скрытые высоты должны лишь быть не больше 0 и
  уравнивать диагонали. Если на обеих диагоналях есть скрытый угол, это
  всегда возможно, причём многими способами; если только на одной, это
  невозможно ровно тогда, когда известная сумма этой диагонали меньше
  другой. В остальных случаях объём не определён.

`O(1)` на тест, в точных целых до последнего деления.

В первом примере 2 + 4 = 3 + 3 и объём 100·12/4 = 300; во втором
2 + 3 ≠ 3 + 3.

Подводные камни:

- нулевое показание — не нулевая высота, а только ограничение;
- при одном сухом угле формула без тетраэдра занижает ответ: для
  стороны 4 и уровней 0 1 5 1 скрытая высота −3 и объём
  16·(1 + 27/96) = 20.5, а не 16;
- объёмы доходят до 10¹⁸.

Ответы совпадают с независимой принятой реализацией на десяти тысячах
случайных тестов, половина из которых — настоящие плоскости, обрезанные
по дну.
