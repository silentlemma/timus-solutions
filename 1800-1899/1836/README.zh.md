# 1836. 巴别鱼

[Timus 1836](https://acm.timus.ru/problem.aspx?space=1&num=1836) · 难度 1173 · geometry

原题作者 Denis Dublennykh，出自 2011 年 4 月第十五届乌拉尔竞技编程公开锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个敞口鱼缸的底面是边长为 a 的正方形。每条竖直棱上的传感器显示该棱上的水位；汽车倾斜，所以水面不一定水平。
对每个测试，求水的体积；若读数不可能出现则输出 "error"，若读数不能确定体积则输出 "ambiguous"。

## 输入

t（1 ≤ t ≤ 10⁴），然后 t 行：a 和四个水位，棱按绕底面的顺序给出，都是 0 到 10⁶ 的整数，a > 0。

## 输出

对每个测试输出体积（绝对或相对误差不超过 10⁻⁶），或 "error"，或 "ambiguous"。

## 样例

### 样例 1

输入：

```
2
10 2 3 4 3
10 2 3 3 3
```

输出：

```
300.000
error
```

## 解法

水面是一个平面，所以它在四个角上的高度 f₁, …, f₄ 满足 f₁ + f₃ = f₂ + f₄，而传感器显示 max(0, fᵢ)：读数为 0 只说明 fᵢ ≤ 0。

- 没有零读数：平面已知。当且仅当两条对角线的和相等时才一致，体积为 a²·(h₁ + h₂ + h₃ + h₄)/4。
- 读数全为零：平面处处不高于底面，体积为 0。
- 角 i 处有一个零：平面给出 fᵢ = (left + right) − far，它必须不大于 0。这时水缺少一个角上的四面体：平面在角上降到 fᵢ，并在两条棱上分别于 −fᵢ/(left − fᵢ) 和 −fᵢ/(right − fᵢ) 的比例处穿过零。它的体积（三条棱乘积的六分之一）加回到平均高度上。
- 两个或更多零：隐藏的高度只需不大于 0 并使两条对角线平衡。若两条对角线上都有隐藏的角，总能做到，而且方式很多；若只有一条有，则当且仅当这条对角线已知的和小于另一条时不可能。其余情况体积不确定。

每个测试 `O(1)`，直到最后一次除法都用精确的整数。

在第一个样例中 2 + 4 = 3 + 3，体积为 100·12/4 = 300；在第二个中 2 + 3 ≠ 3 + 3。

注意事项：

- 零读数并不是零高度，只是一个界；
- 只有一个干角时，不加四面体的公式会算少：边长 4、水位 0 1 5 1 时隐藏高度为 −3，体积是 16·(1 + 27/96) = 20.5，而不是 16；
- 体积可达 10¹⁸。

在一万个随机测试（其中一半是被底面截断的真实平面）上，答案与一个独立的已通过实现一致。
