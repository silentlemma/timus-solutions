# 1828. Приближение прогрессией

## Задача

Даны целые a₁, …, aₙ; найти арифметическую прогрессию b₁, …, bₙ, не
обязательно целую, минимизирующую Σ(aᵢ − bᵢ)².

## Входные данные

n (2 ≤ n ≤ 10⁴), затем a₁, …, aₙ, по модулю не больше 10⁴.

## Выходные данные

Первый член и разность с абсолютной или относительной погрешностью не
больше 10⁻⁶.

## Примеры

### Пример 1

Ввод:

```
4
0 6 10 15
```

Вывод:

```
0.400 4.900
```

### Пример 2

Ввод:

```
4
-2 -2 -2 -2
```

Вывод:

```
-2 0
```

## Решение

Прогрессия — это bᵢ = b + d·xᵢ с xᵢ = i − 1, так что это прямая
наименьших квадратов для точек (xᵢ, aᵢ). Приравнивая нулю производные
по b и d, получаем нормальные уравнения с решением

d = (n·Σxa − Σx·Σa) / (n·Σx² − (Σx)²),  b = (Σa − d·Σx) / n.

Все четыре суммы — целые, помещающиеся в 64 бита (n·Σxa меньше 10¹⁶).
Далее C++, Go, Java и Rust используют плавающую точку, а Python — точные
дроби до вывода. Знаменатель равен n²(n² − 1)/12 и при n ≥ 2
не обращается в 0. `O(n)`.

Для первого примера x̄ = 1.5 и ā = 7.75; Σ(x − x̄)(a − ā) = 24.5 и
Σ(x − x̄)² = 5, так что d = 4.9 и b = 7.75 − 4.9·1.5 = 0.4.

Подводные камни:

- прогрессия подгоняется к позициям 0 … n − 1, а не к одним значениям:
  среднего недостаточно;
- Σx² около 3·10¹¹, а n·Σx² около 3·10¹⁵ — больше 32 бит;
- первый член — это b₁, значение в первой позиции, а не свободный член
  при другом начале отсчёта.
