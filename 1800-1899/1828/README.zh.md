# 1828. 用等差数列逼近

[Timus 1828](https://acm.timus.ru/problem.aspx?space=1&num=1828) · 难度 478 · math

原题作者 Alexey Samsonov，出自 2011 年 3 月 19 日第十二届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定整数 a₁, …, aₙ，求使 Σ(aᵢ − bᵢ)² 最小的等差数列 b₁, …, bₙ（不必是整数）。

## 输入

n（2 ≤ n ≤ 10⁴），然后是 a₁, …, aₙ，绝对值都不超过 10⁴。

## 输出

首项和公差，绝对或相对误差不超过 10⁻⁶。

## 样例

### 样例 1

输入：

```
4
0 6 10 15
```

输出：

```
0.400 4.900
```

### 样例 2

输入：

```
4
-2 -2 -2 -2
```

输出：

```
-2 0
```

## 解法

等差数列就是 bᵢ = b + d·xᵢ，其中 xᵢ = i − 1，所以这是拟合点 (xᵢ, aᵢ) 的最小二乘直线。令对 b 和 d 的偏导为零得到正规方程，其解为

d = (n·Σxa − Σx·Σa) / (n·Σx² − (Σx)²)，b = (Σa − d·Σx) / n。

四个和都是能放进 64 位的整数（n·Σxa 小于 10¹⁶）。之后 C++、Go、Java 和 Rust 使用浮点数，Python 则保留精确分数直到输出。分母等于 n²(n² − 1)/12，n ≥ 2 时不为 0。`O(n)`。

对第一个样例，x̄ = 1.5，ā = 7.75；Σ(x − x̄)(a − ā) = 24.5，Σ(x − x̄)² = 5，所以 d = 4.9，b = 7.75 − 4.9·1.5 = 0.4。

注意事项：

- 数列是对位置 0 … n − 1 拟合的，而不只是对数值：只看平均值是不够的；
- Σx² 约为 3·10¹¹，n·Σx² 约为 3·10¹⁵，超出 32 位；
- 首项是 b₁，即第一个位置上的值，而不是以别处为原点的截距。
