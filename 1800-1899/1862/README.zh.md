# 1862. 非常富有的鼹鼠

[Timus 1862](https://acm.timus.ru/problem.aspx?space=1&num=1862) · 难度 1270 · math

原题作者 Denis Dublennykh，出自 2011 年乌拉尔联邦大学开放团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

鼹鼠可以把数 x 变成 2x、2x + 1 或 ⌊x/2⌋，每次一步。对每一对 1 ≤ x < y ≤ 2ˡ − 1，鼹鼠用最少的步数把 x 变成 y。总共要走多少步？结果模 10⁹ + 7。

## 输入

l（2 ≤ l ≤ 10¹⁸）。

## 输出

总步数模 10⁹ + 7。

## 样例

### 样例 1

输入：

```
2
```

输出：

```
4
```

## 解法

数 1 … 2ˡ − 1 构成以 1 为根的满二叉树，x 是 2x 和 2x + 1 的父亲，三种操作沿着它的边移动。从 x 到 y 的最少步数就是树上距离，所以答案是所有点对的距离之和。

改为统计经过每条边的点对数。深度为 k（1 ≤ k ≤ l − 1）的节点上方的边，把其子树的 2^(l−k) − 1 个节点与其余 2ˡ − 2^(l−k) 个节点分开，这样的边有 2ᵏ 条。它们的贡献为 2ˡ·(2^(l−k) − 1)(2ᵏ − 1)，对 k 求和得
2ˡ·((l − 1)(2ˡ + 1) − 2(2ˡ − 2)) = 2ˡ·((l − 3)·2ˡ + l + 3)。用快速幂求 2ˡ，并把 l 对 10⁹ + 7 取模，复杂度为 `O(log l)`。

当 l = 2 时，树是 1 及其孩子 2 和 3：点对 (1, 2) 和 (1, 3) 相距一步，(2, 3) 相距两步，共 4。

注意事项：

- l 本身可达 10¹⁸，必须在相乘之前先取模；
- 模 10⁹ + 7 的差可能为负，要把模数加回来。

对 l 不超过 9，公式与直接求所有距离之和一致；对高度直到 10¹⁸（包括等于或接近模数倍数的高度），与一个独立的已通过实现一致。
