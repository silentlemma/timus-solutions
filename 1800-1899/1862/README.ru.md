# 1862. Очень состоятельный крот

## Задача

Крот умеет превращать число x в 2x, в 2x + 1 или в ⌊x/2⌋, по одному
действию за раз. Для каждой пары 1 ≤ x < y ≤ 2ˡ − 1 крот получает из x
число y за наименьшее число действий. Сколько всего действий будет
сделано, по модулю 10⁹ + 7?

## Входные данные

l (2 ≤ l ≤ 10¹⁸).

## Выходные данные

Общее число действий по модулю 10⁹ + 7.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
4
```

## Решение

Числа 1 … 2ˡ − 1 образуют полное двоичное дерево с корнем 1, где x —
родитель 2x и 2x + 1, а три действия ходят по его рёбрам. Наименьшее
число действий от x до y — расстояние в дереве, так что ответ — сумма
расстояний по всем парам.

Посчитаем вместо этого пары через каждое ребро. Ребро над вершиной на
глубине k (1 ≤ k ≤ l − 1) отделяет 2^(l−k) − 1 вершин её поддерева от
остальных 2ˡ − 2^(l−k), а таких рёбер 2ᵏ. Их вклад равен
2ˡ·(2^(l−k) − 1)(2ᵏ − 1), и сумма по k даёт
2ˡ·((l − 1)(2ˡ + 1) − 2(2ˡ − 2)) = 2ˡ·((l − 3)·2ˡ + l + 3). С 2ˡ
быстрым возведением в степень и l по модулю 10⁹ + 7 это `O(log l)`.

При l = 2 дерево — 1 с детьми 2 и 3: пары (1, 2) и (1, 3) отстоят на
одно действие, а (2, 3) — на два, всего 4.

Подводные камни:

- само l до 10¹⁸, поэтому его надо привести по модулю до умножения;
- разности по модулю 10⁹ + 7 могут стать отрицательными; прибавляйте
  модуль обратно.

Формула совпадает с прямым суммированием всех расстояний при l до 9 и
с независимой принятой реализацией для высот до 10¹⁸, включая высоты на
кратных модуля и рядом с ними.
