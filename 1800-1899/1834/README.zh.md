# 1834. 网球拍

[Timus 1834](https://acm.timus.ru/problem.aspx?space=1&num=1834) · 难度 4432 · constructive

原题作者 Daniil Aizenshtein，出自 2011 年 4 月第十五届乌拉尔竞技编程公开锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一列 n 节车厢在一条网球拍形状的尽头线上排序。每一轮中车厢从尾部逐节摘下，第一节驶入尽头线，之后每一节都挂到那里正在组成的列车的头部或尾部；然后新列车车头在前驶出。
求把车厢排成 1, …, n 所需的最少轮数，以及每一轮之后的顺序。

## 输入

n（2 ≤ n ≤ 10000），然后是从车头到车尾的车厢，为 1, …, n 的一个排列。

## 输出

最少轮数 k，然后是 k 行，每行为一轮之后的顺序。任何最优方案都可以。

## 样例

### 样例 1

输入：

```
6
2 5 3 1 6 4
```

输出：

```
3
5 1 6 4 3 2
1 2 3 4 6 5
1 2 3 4 5 6
```

## 解法

挂到头部的车厢按原顺序排在第一节驶入的车厢之前，挂到尾部的车厢在它之后且顺序相反。所以一轮就是任选一组车厢保持原顺序，再把其余车厢倒序接在后面。

k 轮之后每节车厢得到一个 k 位的选择码。先按最后一轮排序再逐层展开，车厢最终按其码在反射格雷码中的顺序排列，同码的车厢保持相互顺序，码中每有一个 1 就反转一次。
这些 1 的个数的奇偶性等于该码格雷秩的奇偶性。所以排好的列车按秩的顺序被切成至多 2ᵏ 段连续的值，秩为偶数的段在原位置上必须已经递增，秩为奇数的段必须递减。

把值贪心地切成最长的交替段，一次从递增段开始，一次从递减段开始。第一种切法用秩 0, 1, …，需要 2ᵏ ≥ R；第二种用秩 1, 2, …，秩 0 留空，需要 2ᵏ ≥ F + 1。
中间的空秩没有帮助，因为单节车厢既算递增也算递减。答案取较小的 k，第 j 轮恰好移动格雷码第 j 位为 1 的那些段。连同输出共 `O(n log n)`。

在样例中，从递增开始的切法是 1 | 2 | 3–4 | 5 | 6，共五段；从递减开始的是 1–2 | 3–4 | 5 | 6，共四段，加上空的秩 0 也占五个秩：需要三轮。

注意事项：

- 第一节驶入的车厢并不特殊：它只是落在保留的车厢和反转的车厢之间；
- 以递减开头的列车用空秩 0 可能比递增切法少一轮，例如完全倒序的列车；
- 已排好序的列车不需要任何一轮，只输出 0。

轮数在至多 7 节车厢的所有排列上与广度优先搜索一致，每个输出方案都在 4 到 6 节车厢的所有排列和大测试上逐轮检查过。
