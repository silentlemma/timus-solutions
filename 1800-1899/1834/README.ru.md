# 1834. Теннисная ракетка

[Timus 1834](https://acm.timus.ru/problem.aspx?space=1&num=1834) · сложность 4436 · constructive

Автор оригинальной задачи — Даниил Айзенштейн; XV открытый чемпионат Урала по спортивному программированию, апрель 2011 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Состав из n вагонов сортируют в тупике в форме ракетки. За один заход
вагоны по одному отцепляют с хвоста, первый заводят в тупик, а каждый
следующий присоединяют к голове или к хвосту формируемого там
состава; затем новый состав выводят головой вперёд. Найти наименьшее
число заходов, расставляющее вагоны в порядке 1, …, n, и порядок после
каждого захода.

## Входные данные

n (2 ≤ n ≤ 10000), затем вагоны от головы к хвосту — перестановка
1, …, n.

## Выходные данные

Наименьшее число заходов k, затем k строк с порядком после каждого
захода. Подходит любая оптимальная последовательность.

## Примеры

### Пример 1

Ввод:

```
6
2 5 3 1 6 4
```

Вывод:

```
3
5 1 6 4 3 2
1 2 3 4 6 5
1 2 3 4 5 6
```

## Решение

Вагоны, присоединённые к голове, выходят в прежнем порядке перед первым
заведённым вагоном, а присоединённые к хвосту — после него в обратном
порядке. Значит, заход выбирает любое множество вагонов, оставляет их в
порядке и дописывает остальные задом наперёд.

За k заходов каждый вагон собирает k-битный код своих выборов. Если
упорядочить по последнему заходу и раскрутить назад, вагоны окажутся
упорядочены по кодам в порядке отражённого кода Грея, а вагоны с общим
кодом сохранят взаимный порядок, обращённый по разу на каждую единицу
кода. Чётность этих единиц совпадает с чётностью ранга кода. Значит,
отсортированный состав режется не больше чем на 2ᵏ отрезков
последовательных значений в порядке рангов, и отрезок чётного ранга
должен уже возрастать по исходным позициям, а нечётного — убывать.

Режем значения жадно на самые длинные чередующиеся отрезки — один раз
начиная с возрастающего, другой раз с убывающего. Ранги 0, 1, … для
первой нарезки требуют 2ᵏ ≥ R; ранги 1, 2, … для второй, с пустым
рангом 0, требуют 2ᵏ ≥ F + 1. Пустые ранги в середине не помогают:
один вагон одновременно и возрастающий, и убывающий отрезок. Ответ —
меньшее k, а заход j переносит ровно отрезки, у кода Грея которых
установлен бит j. `O(n log n)` вместе с выводом.

В примере нарезка с возрастающего начала — 1 | 2 | 3–4 | 5 | 6, пять
отрезков, а с убывающего — 1–2 | 3–4 | 5 | 6, четыре отрезка, которые с
пустым рангом 0 тоже занимают пять рангов: три захода.

Подводные камни:

- первый заведённый вагон ничем не особенный: он просто оказывается
  между оставленными вагонами и обращёнными;
- составу, начинающемуся убыванием, с пустым рангом 0 нужно не меньше
  заходов, чем с возрастающей нарезкой, даже обратному составу;
- отсортированному составу заходы не нужны, и выводится только 0.

Число заходов совпадает с поиском в ширину по всем перестановкам до 7
вагонов, а каждая выведенная последовательность проверена заход за
заходом для всех перестановок от 4 до 6 вагонов и для больших тестов.
