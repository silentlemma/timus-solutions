# 1822. 雨果二世的战争

[Timus 1822](https://acm.timus.ru/problem.aspx?space=1&num=1822) · 难度 687 · binary_search

原题作者 Kirill Butin，出自 2011 年 3 月 19 日第十二届乌拉尔国立大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

王国的贵族在国王（贵族 1）之下构成一棵树。带有数 x 的命令从国王向下传达。没有附庸的贵族立即用 tᵢ 天召集军队。
有附庸的贵族等到至少 x% 的直接附庸准备就绪，再用 tᵢ 天召集军队。国王在至少 x% 的直接附庸就绪后出征。
求使国王在 t 天之内出征的最大 x。

## 输入

n 和 t（1 ≤ n ≤ 10⁴，0 ≤ t ≤ 10⁶），然后对贵族 2, …, n 给出宗主 pᵢ 和天数 tᵢ（0 ≤ tᵢ ≤ 100）。

## 输出

最大的 x，绝对误差不超过 10⁻⁴。

## 样例

### 样例 1

输入：

```
6 3
1 2
2 2
2 1
1 2
1 4
```

输出：

```
50.00000000
```

## 解法

对固定的 x，有 c 个附庸的贵族等待其中 ⌈x·c/100⌉ 个，即附庸就绪日中第 ⌈x·c/100⌉ 小的那一天，再过 tᵢ 天就绪；从叶子向上扫一遍就得到国王的日子。
更大的 x 不会让任何人更快，所以可行的 x 构成区间 [0, X]。

在区间内只有 ⌈x·c/100⌉ 的值有意义，而它们只在分数 m/c 处变化，其中 c 是某个贵族的直接附庸数。所以 X 本身等于某个这样的分数乘以 100。
对每个不同的 c 收集分数，用交叉相乘排序，再二分查找国王来得及的最后一个分数，每次检查都用精确的整数运算。
这样没有任何精度问题，输出的值也是精确的。分数至多 2n 个，总复杂度 `O(n log² n)`。

在样例中 x = 50 时，贵族 2 等待附庸 3 和 4 中的一个，它在第 1 天就绪，于是贵族 2 在第 3 天就绪。
国王的附庸分别在第 3、2、4 天就绪，第二个在第 3 天到来，来得及。任何大于 50 的 x 都让贵族 2 等两个附庸，让国王在 4、2、4 中等两个。

注意事项：

- x 是直接附庸的比例并向上取整：有 3 个附庸时 34% 就已经需要两个；
- 宗主的编号可能大于附庸的编号，所以处理顺序要从国王出发遍历得到；
- 国王本人不花时间召集；
- 国王没有附庸时立即出征，答案为 100。
