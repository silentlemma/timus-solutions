# 1888. Стаж пилотов

[Timus 1888](https://acm.timus.ru/problem.aspx?space=1&num=1888) · сложность 463 · bfs

Автор оригинальной задачи — Магаз Асанов; NEERC 2011, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В каждом из n рейсов летели два из p пилотов, и стаж одного был ровно
на год больше стажа другого; кто есть кто, неизвестно. Каждый стаж —
целое число лет от 1 до 50. Найдите наибольшую возможную разницу между
самым опытным и самым неопытным пилотом и стажи, дающие её, или
выведите −1, если данные противоречивы.

## Входные данные

n и p (2 ≤ n ≤ 1000, 2 ≤ p ≤ 50), затем n рейсов — по два различных
номера пилотов.

## Выходные данные

Наибольшая разница и затем p стажей или −1. Подходят любые верные
стажи.

## Примеры

### Пример 1

Ввод:

```
4 4
1 2
3 1
2 4
3 4
```

Вывод:

```
2
1 2 2 3
```

### Пример 2

Ввод:

```
3 3
1 2
2 3
1 3
```

Вывод:

```
-1
```

## Решение

Пилоты одного рейса отличаются на единицу, поэтому чётность их стажей
разная. Значит, связная группа пилотов должна быть двудольной; нечётный
цикл означает −1.

Внутри одной группы два пилота на расстоянии k отличаются не больше чем
на k, так что разброс не больше диаметра. И он достигается: стаж
1 + (расстояние от конца диаметра) меняется ровно на единицу вдоль
каждого рейса, потому что в двудольном графе расстояния соседей
отличаются на единицу. При p ≤ 50 диаметр не больше 49, так что эти
значения не выходят за 1 … 50.

Разные группы сдвигаются независимо, поэтому при двух и более группах
ответ — полные 49: одна группа чередует 1 и 2 по чётности, а остальные
чередуют 49 и 50. BFS из каждого пилота стоит `O(p·(p + n))`.

В первом примере пилоты образуют цикл 1–2–4–3 длины четыре с диаметром
2: от пилота 1 расстояния равны 0, 1, 1, 2.

Подводные камни:

- несколько групп сразу дают 49, какими бы маленькими они ни были;
- одна группа не может превысить свой диаметр, даже если она длинная и
  тонкая;
- одна и та же пара может летать несколько раз, это ничего не меняет.

Ответы совпадают с независимой принятой реализацией, а стажи проходят
чекер на 200 случайных наборах рейсов.
