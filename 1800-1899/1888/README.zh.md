# 1888. 飞行员的工龄

[Timus 1888](https://acm.timus.ru/problem.aspx?space=1&num=1888) · 难度 463 · bfs

原题作者 Magaz Asanov，出自 NEERC 2011 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 个航班中每个都由 p 名飞行员中的两名驾驶，其中一人的工龄恰好比另一人多一年；不知道谁是谁。每个工龄都是 1 到 50 之间的整数年。求最资深与最资浅飞行员之间可能的最大差值以及达到它的工龄；若数据矛盾则输出 −1。

## 输入

n 和 p（2 ≤ n ≤ 1000，2 ≤ p ≤ 50），然后是 n 个航班，每个为两个不同的飞行员编号。

## 输出

最大差值，然后是 p 个工龄；或者 −1。任何合法的工龄都可以。

## 样例

### 样例 1

输入：

```
4 4
1 2
3 1
2 4
3 4
```

输出：

```
2
1 2 2 3
```

### 样例 2

输入：

```
3 3
1 2
2 3
1 3
```

输出：

```
-1
```

## 解法

同一航班的飞行员相差一年，所以工龄的奇偶性不同。因此每个连通的飞行员组必须是二分图；出现奇环则输出 −1。

在同一组内，距离为 k 的两名飞行员至多相差 k，所以差值不超过直径。而且可以达到：取工龄为 1 +（到直径一端的距离），由于二分图中相邻点的距离恰好相差一，它沿每个航班恰好变化一。p ≤ 50 时直径至多为 49，所以这些值都在 1 … 50 之内。

不同的组可以独立平移，所以有两个或更多组时答案是完整的 49：一组按奇偶在 1 和 2 之间交替，其余组在 49 和 50 之间交替。从每名飞行员做 BFS 的代价为 `O(p·(p + n))`。

第一个样例中飞行员构成长度为四的环 1–2–4–3，直径为 2：从飞行员 1 出发距离为 0, 1, 1, 2。

注意事项：

- 只要有多个组就直接得到 49，无论它们多小；
- 一个组不能超过它的直径，即使它又长又细；
- 同一对飞行员可能飞多次，这不影响结果。

在 200 组随机航班上，答案与一个独立的已通过实现一致，工龄也通过了检查器。
