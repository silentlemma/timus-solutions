# 1802. 立方体拼图

[Timus 1802](https://acm.timus.ru/problem.aspx?space=1&num=1802) · 难度 2070 · backtracking

原题作者 Stanislav Vasilyev，出自 NEERC 2010 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

六块 n × n 的扁平方板一面涂了漆；另一面每个格子上立着一根由单位小方块组成、高度为 0 到 n 的柱子。高度之和为 n³。
可以任意转动这些部件，拼出一个四面八方都是漆面的 n × n × n 立方体，或者报告无法做到。

## 输入

n（2 ≤ n ≤ 20），然后是六个部件，每个部件为 n 行、每行 n 个高度。

## 输出

"No"，或者 "Yes"，然后从下到上输出 n 层，每层从后到前 n 行，每行从左到右 n 个 1 到 6 的部件编号。

## 解法

漆面朝外时，一个部件贴在立方体的某个面上，柱子朝里，并以四种方式之一旋转。镜像放置是不可能的，所以六个面都定义为底面经过立方体的旋转得到。
部件放在某个面上并取某种旋转，占据一组确定的格子，用位掩码保存；对称部件产生的相同掩码只算一次。由于整个立方体可以转动，最大的部件不旋转地放在底面。
然后回溯搜索填充其余各面，每次选择不与已占格子重叠的“部件和旋转”最少的那个面，某个面一个都没有时立即回退。
由于体积之和为 n³，六个互不重叠的部件恰好填满立方体。分配方式至多 5! · 4⁵ 种，剪枝使搜索非常小。每步 `O(n³)`。

第一个样例中 3 × 3 × 3 立方体的每个格子都得到所属部件的编号；第二个样例中部件无论如何都拼不起来。

注意事项：

- 部件不能翻面：翻过来漆面就朝里了；
- 对称的部件会产生相同的放置，只会拖慢搜索；
- 高度为零的部件也需要占用一个面。

检查器要求每个部件的格子恰好是该部件放在某个面上、取四种旋转之一的结果，且不同部件占不同的面；第一个样例给出的答案能通过检查。
在随机切成六块的立方体上（有或没有把一个格子移到另一部件），答案与一个独立的已通过实现一致。
