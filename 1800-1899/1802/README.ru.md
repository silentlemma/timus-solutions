# 1802. Кубик-головоломка

[Timus 1802](https://acm.timus.ru/problem.aspx?space=1&num=1802) · сложность 2070 · backtracking

Автор оригинальной задачи — Станислав Васильев; NEERC 2010, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Шесть плоских квадратов n × n покрыты лаком с одной стороны; с другой
стороны на каждой клетке стоит столбик из единичных кубиков высотой от
0 до n. Сумма высот равна n³. Свободно поворачивая детали, собрать куб
n × n × n, покрытый лаком со всех сторон, или сообщить, что это
невозможно.

## Входные данные

n (2 ≤ n ≤ 20), затем шесть деталей, каждая — n строк по n высот.

## Выходные данные

"No" или "Yes", а затем n слоёв снизу вверх, каждый — n строк от задней
к передней по n номеров деталей от 1 до 6 слева направо.

## Решение

Лаком наружу деталь лежит на одной грани куба столбиками внутрь,
повёрнутая одним из четырёх способов. Зеркальные положения
невозможны, поэтому шесть граней задаются как нижняя грань,
перенесённая поворотами куба. Деталь на грани с поворотом занимает
известное множество клеток, хранимое битовой маской; одинаковые маски
симметричной детали учитываются один раз. Поскольку весь куб можно
повернуть, самая большая деталь кладётся вниз без поворота. Дальше
перебор с возвратом заполняет остальные грани, каждый раз беря грань с
наименьшим числом деталей и поворотов, не задевающих занятые клетки, и
сразу отступая, если для грани их нет. Так как объёмы в сумме дают n³,
шесть непересекающихся деталей заполняют куб. Расстановок не больше
5! · 4⁵, а отсечения делают перебор крошечным. `O(n³)` на шаг.

В первом примере каждая клетка куба 3 × 3 × 3 получает номер своей
детали; во втором детали никак не складываются.

Подводные камни:

- деталь нельзя переворачивать: лак оказался бы внутри;
- симметричные детали дают одинаковые положения, которые лишь
  замедляют перебор;
- детали нулевой высоты тоже требуют своей грани.

Чекер требует, чтобы клетки каждой детали были этой деталью на
какой-то грани в одном из четырёх поворотов, с разными гранями для
разных деталей; данный ответ первого примера его проходит. Ответы
совпадают с независимой принятой реализацией на кубах, случайно
разрезанных на шесть деталей, с переносом одной клетки между деталями
и без него.
