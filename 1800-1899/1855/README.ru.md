# 1855. Между светом и тьмой

[Timus 1855](https://acm.timus.ru/problem.aspx?space=1&num=1855) · сложность 1263 · fenwick

## Задача

n городов лежат вдоль торгового тракта, и за каждый отрезок между
соседними городами берётся пошлина, вначале нулевая. События идут по
порядку: изменение прибавляет d к пошлине каждого отрезка между
городами a и b, а новая гильдия работает в городах a … b, и её караваны
одинаково часто ходят между каждой парой этих городов. Для каждой новой
гильдии вывести среднюю пошлину, которую в этот момент платит один её
караван.

## Входные данные

n и m (2 ≤ n ≤ 10⁵, 1 ≤ m ≤ 10⁵), затем m событий «change a b d» или
«establish a b», где 1 ≤ a < b ≤ n и |d| ≤ 10 000. Каждая пошлина
остаётся между 0 и 10 000.

## Выходные данные

Среднее для каждой новой гильдии с абсолютной или относительной
погрешностью не более 10⁻⁶.

## Примеры

### Пример 1

Ввод:

```
4 5
change 1 4 2
change 1 2 -1
establish 1 2
establish 2 4
establish 1 4
```

Вывод:

```
1.00000000
2.66666667
2.83333333
```

## Решение

Пусть tᵢ — пошлина отрезка от города i до города i + 1. У гильдии на
городах a … b есть (b − a + 1)(b − a)/2 маршрутов, и отрезок i лежит на
(i − a + 1)(b − i) из них — тех, что начинаются не позже i и кончаются
после него. Раскрыв произведение, получаем сумму пошлин
−S₂ + (a + b − 1)·S₁ + b(1 − a)·S₀, где S_k = Σ iᵏ·tᵢ по
i = a … b − 1, так что хватает сумм на отрезке для tᵢ, i·tᵢ и i²·tᵢ при
прибавлениях на отрезке.

Будем хранить пошлины как префиксные суммы разностей dif_j: изменение
прибавляет d в a и −d в b. Тогда сумма iᵏ·tᵢ по i ≤ x равна
P_k(x)·Σ dif_j − Σ dif_j·P_k(j − 1) по j ≤ x, где P_k(x) — сумма iᵏ
для i = 1 … x, посчитанная заранее. Четыре дерева Фенвика над
разностями, простое и взвешенные P₀, P₁ и P₂, отвечают на каждое событие
за `O(log n)`.

В примере пошлины в итоге равны 1, 2 и 2. У гильдии на городах 1 … 4
шесть маршрутов с пошлинами 1, 3, 5, 2, 4 и 2, то есть 17/6 ≈ 2,8333.

Подводные камни:

- в Python целые числа точные, а остальные решения считают по модулю
  2⁶⁴, что точно для итоговой суммы, поскольку она меньше 2,5·10¹⁸;
- сумме гильдии не нужно деление до самого конца;
- решение на Python работает на PyPy.

Средние совпадают с прямым подсчётом на двухстах маленьких случаях и с
независимой принятой реализацией на больших тестах.
