# 1805. Чапаев и шифровальная решётка

[Timus 1805](https://acm.timus.ru/problem.aspx?space=1&num=1805) · сложность 1008 · combinatorics

Автор оригинальной задачи — Александр Ипатов; NEERC 2010, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Шифровальная решётка — квадрат n × n с n²/4 окнами, такими что в
четырёх положениях, повёрнутых на четверть оборота, окна покрывают
каждую клетку ровно один раз. Записанные матрицей из 0 и 1 по
строкам, решётки упорядочены лексикографически. Вывести k-ю.

## Входные данные

n и k (4 ≤ n ≤ 10, n чётно, 1 ≤ k ≤ 10¹⁸); k не больше числа решёток.

## Выходные данные

Решётка — n строк по n цифр.

## Примеры

### Пример 1

Ввод:

```
4 15
```

Вывод:

```
0000
0000
1101
0001
```

## Решение

Поворот на четверть переводит каждую клетку по орбите из четырёх
клеток, а решётка открывает ровно одну клетку каждой орбиты, так что
решёток 4^(n²/4), не больше 4²⁵. Идём по клеткам по порядку и сначала
пробуем 0. Если клетка закрыта, каждая орбита без окна ещё может
открыть любую из своих не пройденных клеток, поэтому число таких
решёток — произведение этих количеств. Если k не больше этого числа,
клетка остаётся 0; иначе k уменьшается на него, и клетка становится
окном своей орбиты. Клетка орбиты, у которой окно уже есть, равна 0, а
последняя клетка орбиты без окна вынужденно равна 1, ведь произведение
с нулевым множителем равно 0. `O(n⁴)`.

В примере решёток с закрытыми двумя верхними строками
2⁴ = 16 ≥ 15, ведь у каждой орбиты остаются две нижние клетки, поэтому
эти строки остаются закрытыми, а выбор происходит в нижней половине.

Подводные камни:

- количества доходят до 4²⁵, около 10¹⁵, нужны 64-битные числа;
- орбита, уже получившая окно, больше не входит в произведение;
- 0 идёт раньше 1, поэтому сначала считается закрытый вариант.

Ответы совпадают с независимой принятой реализацией на первых,
последних и случайных решётках всех размеров и с полным списком 256
решёток стороны 4.
