# 1805. 恰巴耶夫与密码格栅

[Timus 1805](https://acm.timus.ru/problem.aspx?space=1&num=1805) · 难度 1010 · combinatorics

原题作者 Alexander Ipatov，出自 NEERC 2010 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

密码格栅是一个 n × n 的方块，开有 n²/4 个窗口，使它在依次旋转四分之一圈的四个位置中，窗口恰好把每个格子覆盖一次。把格栅写成按行读取的 0/1 矩阵，按字典序排列。输出第 k 个。

## 输入

n 和 k（4 ≤ n ≤ 10，n 为偶数，1 ≤ k ≤ 10¹⁸）；k 不超过格栅的总数。

## 输出

格栅，n 行，每行 n 个数字。

## 样例

### 样例 1

输入：

```
4 15
```

输出：

```
0000
0000
1101
0001
```

## 解法

旋转四分之一圈使每个格子沿着一个四格的轨道移动，而格栅恰好在每条轨道上开一个格子，所以共有 4^(n²/4) 个格栅，至多 4²⁵ 个。按顺序遍历格子，先尝试 0。
该格关闭时，每条还没有窗口的轨道仍可以打开其尚未经过的任意格子，所以这样的格栅个数是这些数量的乘积。若 k 不超过这个数，该格保持 0；
否则 k 减去这个数，该格成为其轨道的窗口。已有窗口的轨道上的格子为 0，没有窗口的轨道的最后一个格子必须为 1，因为含零因子的乘积为 0。`O(n⁴)`。

样例中前两行关闭的格栅有 2⁴ = 16 ≥ 15 个（每条轨道保留下面两个格子），所以这两行保持关闭，选择发生在下半部分。

注意事项：

- 数量可达 4²⁵，约 10¹⁵，需要 64 位整数；
- 已经有窗口的轨道不再计入乘积；
- 0 在 1 之前，所以先计算关闭的情况。

在各种尺寸的第一个、最后一个和随机格栅上，答案与一个独立的已通过实现一致，并与边长 4 的全部 256 个格栅的完整列表一致。
