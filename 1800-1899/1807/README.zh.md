# 1807. 马克沁机枪的子弹

[Timus 1807](https://acm.timus.ru/problem.aspx?space=1&num=1807) · 难度 1474 · number_theory

原题作者 Daniil Ayzenshteyn（创意来自 Alex Samsonov），出自 NEERC 2010 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 发子弹装在至少两个相同的箱子里，每箱至少 100 发。把它们分到两个或更多口袋中，使各口袋数量的最大公约数尽可能大，在此前提下最小公倍数也尽可能大。输出任意一种最优分法。

## 输入

n（200 ≤ n ≤ 10⁹）。

## 输出

各口袋中的子弹数。

## 样例

### 样例 1

输入：

```
200
```

输出：

```
100 100
```

### 样例 2

输入：

```
625
```

输出：

```
375 250
```

## 解法

设 p 为 n 的最小素因子；n 是合数，所以 p ≤ 31622。至少两个口袋的最大公约数 g 整除 n，且 n/g ≥ 2，所以最大的公约数是 n/p。
每种最优分法都是 n/p 乘以和为 p 的若干部分，其最小公倍数是 n/p 乘以这些部分的最小公倍数。各部分小于 p 且和为 p 时，最大的最小公倍数来自不同素数的幂再补上若干个 1，这是 Landau 函数的变体。
用背包求解：对每个素数 q 至多选一个小于 p 的 q 的幂，重量为该幂，价值为其对数，在重量不超过 p 的条件下最大化价值。每个素数的选择表用于还原各部分。
对所有素数做过一次完整搜索，表明对任意素数 p < 31623 的最优选择都不需要大于 700 的素数，所以只用小于 1000 的素数。各部分都小于 p，所以口袋总有至少两个。`O(p · π(1000) · log p)`。

第二个样例中 p = 5，n/p = 125；5 = 2 + 3 的最小公倍数 6 是可能的最大值，所以口袋装 250 和 375。

注意事项：

- n 为偶数时 p = 2，唯一的分法是两半；
- p 本身不能单独作为一部分，因为至少需要两个口袋；
- 最小公倍数可能超出 64 位整数，所以比较的是它的对数。

检查器把精确的最小公倍数与期望答案的比较，并检查和、最大公约数与口袋数。在 11 到 400 之间所有素数的平方、小于 31623 的最大素数的平方以及随机总数上，答案与一个独立的已通过实现一致。
