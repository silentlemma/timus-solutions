# 1808. 恰巴耶夫在海洋星球

[Timus 1808](https://acm.timus.ru/problem.aspx?space=1&num=1808) · 难度 1863 · geometry

原题作者 Alexander Mironenko，出自 NEERC 2010 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

星球是一个以原点为圆心、半径为 r 的水圆盘，折射率为 η。两名观察者在星球外沿给定向量看去，各自在水中看到一个人。他们可能看到的是同一个人吗？

## 输入

r（1 ≤ r ≤ 1000）和 η（1 ≤ η ≤ 100，至多两位小数），然后给出每名观察者的位置和视线方向，均为绝对值不超过 1000 的整数。两名观察者都在星球外，且看到的点严格在内部。
若答案为 "Yes"，公共点到岸边的距离至少为 10⁻⁴。

## 输出

"Yes" 或 "No"。

## 样例

### 样例 1

输入：

```
10 2.0
5 10 0 -1
-5 10 0 -1
```

输出：

```
Yes
```

### 样例 2

输入：

```
10 1.5
5 10 0 -1
-5 10 0 -1
```

输出：

```
No
```

## 解法

观察者能看到水中折射光线上的任意一点，这是圆的一条弦。视线第一次碰到圆周的位置是 |P + tD|² = r² 的较小根。在该点把单位方向分解为沿内法线的部分和长度为 sin α 的切向部分。
斯涅尔定律把切向部分除以 η，法向部分变为 √(1 − sin²β)，由此得到水中的方向 v。从入射点 E 出发，弦长为 −2·(E·v)。
两条弦有公共点，当且仅当它们在参数严格介于 0 和 1 之间的位置相交，或者位于同一直线上（两条视线沿同一直线穿过星球时会出现）。`O(1)`。

样例中两人都在 x = ±5 处竖直向下看。η = 2 时光线向中心偏折得足够多，在星球内部的轴上相交；η = 1.5 时它们只会在星球远侧之外相遇。

注意事项：

- 折射光线偏向法线，所以缩小的是切向部分而不是法向部分；
- 沿同一直线的两条视线给出同一条弦，这算作同一个人；
- 视线要取到第一个交点，即带负号的那个根。

在 300 个随机情形上（大小不同的星球和折射率，包括专门构造为 No 的情形，且都远离相切或平行的弦），答案与一个独立的已通过实现一致。
