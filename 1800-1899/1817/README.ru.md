# 1817. Карусель

[Timus 1817](https://acm.timus.ru/problem.aspx?space=1&num=1817) · сложность 1008 · probability

Оригинальная задача — Tavrida NU Akai Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У карусели n лошадок, и за секунду она поворачивается на одну лошадку.
Ребёнок подходит к случайной лошадке; если она занята, он ждёт
следующую, и так далее, пока не подъедет свободная. Никто не слезает.
Для каждого числа катающихся от 0 до n − 1 найти ожидаемое время
ожидания следующего ребёнка с погрешностью не больше 10⁻⁶.

## Входные данные

n (2 ≤ n ≤ 20).

## Выходные данные

n строк: ожидаемое ожидание в секундах, когда катаются 0, 1, …, n − 1
детей.

## Примеры

### Пример 1

Ввод:

```
4
```

Вывод:

```
0.000000
0.250000
0.687500
1.500000
```

## Решение

Ребёнок занимает первую свободную лошадку начиная со случайной позиции,
а это в точности вставка в кольцевую хеш-таблицу с линейным
зондированием, и ожидание — число пропущенных занятых лошадок. Анализ
линейного зондирования у Кнута для таблицы из n ячеек с k ключами даёт
среднее число проб неуспешного поиска (1 + Q)/2 с
Q = Σⱼ (j + 1)·k(k − 1)…(k − j + 1)/nʲ, сумма по j = 0 … k. Ожидание на
одну пробу меньше: (Q − 1)/2. Каждая строка — короткая сумма. `O(n²)`.

Для n = 4 и двух катающихся Q = 1 + 2·(2/4) + 3·(2·1/16) = 2,375, так
что ожидание равно 0,6875.

Подводные камни:

- ожидание берётся по тому, как садились предыдущие дети, а не по
  равномерно случайным занятым лошадкам: занятые отрезки растут
  быстрее;
- при k катающихся сумма обрывается на j = k;
- прямое моделирование по всем 2²⁰ рассадкам годится для
  компилируемого языка, но в остальных требует аккуратности; формула
  его обходит.

Ответы совпадают при всех n от 2 до 20 с независимой принятой
реализацией, следящей за вероятностью каждого множества занятых
лошадок, вплоть до последней цифры, где точное значение 0,3419875
округлено по-разному.
