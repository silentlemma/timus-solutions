# 1817. 旋转木马

[Timus 1817](https://acm.timus.ru/problem.aspx?space=1&num=1817) · 难度 1010 · probability

原题出自 Tavrida NU Akai Contest，2010 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

旋转木马上有 n 匹马，每秒转过一匹马。一个孩子走到一匹随机的马前；若它被占，就等下一匹马过来，依此类推，直到来了一匹空马。没有人下来。
对正在骑的人数从 0 到 n − 1 的每种情况，求下一个孩子的期望等待时间，误差不超过 10⁻⁶。

## 输入

n（2 ≤ n ≤ 20）。

## 输出

n 行：当有 0、1、…、n − 1 个孩子在骑时的期望等待秒数。

## 样例

### 样例 1

输入：

```
4
```

输出：

```
0.000000
0.250000
0.687500
1.500000
```

## 解法

孩子从随机位置开始取第一匹空马，这恰好是向带线性探测的环形哈希表中插入，等待时间就是经过的被占马匹数。
Knuth 对线性探测的分析给出：n 个槽、k 个键时，不成功查找的平均探测次数为 (1 + Q)/2，其中 Q = Σⱼ (j + 1)·k(k − 1)…(k − j + 1)/nʲ，对 j = 0 … k 求和。
等待时间比探测次数少一：(Q − 1)/2。每行只是一个简短的求和。`O(n²)`。

当 n = 4 且有两个孩子在骑时，Q = 1 + 2·(2/4) + 3·(2·1/16) = 2.375，所以等待时间为 0.6875。

注意事项：

- 期望是对之前的孩子如何就座取的，而不是对均匀随机的被占马匹：被占的连续段增长得更快；
- 有 k 个孩子在骑时，求和止于 j = k；
- 对全部 2²⁰ 种就座情况的直接模拟在编译型语言中可行，在其他语言中需要小心；公式避开了它。

对 2 到 20 的每个 n，答案都与一个跟踪每个被占马匹集合概率的独立已通过实现一致，只有一处最后一位不同：精确值 0.3419875 的舍入方式不同。
