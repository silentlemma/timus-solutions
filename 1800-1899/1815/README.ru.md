# 1815. Ферма в Сан-Андреасе

[Timus 1815](https://acm.timus.ru/problem.aspx?space=1&num=1815) · сложность 4112 · geometry

Оригинальная задача — Tavrida NU Akai Contest, Петрозаводские летние сборы, август 2010 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны три города и цена километра дороги от каждого из них. Поставить
ферму в любую точку плоскости так, чтобы общая цена трёх прямых дорог к
ней — взвешенная сумма расстояний — была наименьшей, и вывести эту цену
с абсолютной или относительной погрешностью не больше 10⁻⁹. Тестов до
10⁴.

## Входные данные

t (1 ≤ t ≤ 10⁴), затем для каждого теста три строки с координатами
городов (целые, по модулю до 1000) и строка с тремя ценами (от 1 до
1000).

## Выходные данные

Наименьшая общая цена для каждого теста.

## Примеры

### Пример 1

Ввод:

```
2
0 0
1 0
0 1
1 1 1
-3 0
3 5
0 -1
7 9 8
```

Вывод:

```
1.9318516526
81.1600672826
```

## Решение

Это взвешенная задача Ферма — Торричелли. При требуемой точности
итерационный поиск может ползти возле городов. У неё есть точный
ответ.

Стоимость выпукла. Город v — лучшее место, если тяга остальных, сумма
их весов на единичные векторы от v к ним, не длиннее общего веса,
стоящего в v; города в одной точке складывают там свои веса.

Если ни один город не подходит, лучшая точка M внутри, где три
взвешенных единичных вектора уравновешиваются, и у её стоимости есть
явная формула. Строим точку Q по другую сторону BC от A так, что
|BQ| : |CQ| : |BC| = w₃ : w₂ : w₁. Неравенство Птолемея для M, B, Q, C
даёт w₂|MB| + w₃|MC| ≥ w₁|MQ| для любой M, так что стоимость не меньше
w₁(|MA| + |MQ|) ≥ w₁|AQ|. Поскольку оптимум внутри, достигается
равенство, и ответ равен w₁|AQ|. Крошечный допуск в проверке городов
учитывает ошибки округления ровно на границе, где обе формулы
совпадают. `O(1)` на тест.

В первом тесте примера все цены равны 1 и все углы меньше 120°, так что ответ
— классическая точка Ферма с суммой расстояний
(1 + √3)/√2 ≈ 1,93185.

Подводные камни:

- итерация Вейсфельда может остановиться в городе, если шагнёт ровно в
  него, например когда города на одной прямой и их центр — один из них;
- два или три города могут совпадать;
- веса не обязаны образовывать треугольник; тогда город с наибольшим
  весом сразу оказывается лучшим.

Ответы совпадают с подробным локальным поиском от центра на 3000
случайных тестах с совпадающими, лежащими на одной прямой и
произвольными городами. С независимой принятой реализацией они тоже
совпадают везде, кроме случаев на одной прямой, где её итерация
начинается в городе и там и остаётся.
