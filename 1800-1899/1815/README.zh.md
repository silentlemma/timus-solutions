# 1815. 圣安地列斯的农场

[Timus 1815](https://acm.timus.ru/problem.aspx?space=1&num=1815) · 难度 4204 · geometry

原题出自 Tavrida NU Akai Contest，2010 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定三个城市以及从每个城市修路的每公里价格。在平面上任选一点建农场，使通往它的三条直路的总价（距离的加权和）最小，并以不超过 10⁻⁹ 的绝对或相对误差输出这个价格。最多 10⁴ 组数据。

## 输入

t（1 ≤ t ≤ 10⁴），然后每组数据是三行城市坐标（绝对值不超过 1000 的整数）和一行三个价格（1 到 1000）。

## 输出

每组数据的最小总价。

## 样例

### 样例 1

输入：

```
2
0 0
1 0
0 1
1 1 1
-3 0
3 5
0 -1
7 9 8
```

输出：

```
1.9318516526
81.1600672826
```

## 解法

这是加权的费马–托里拆利问题，所要求的精度排除了在城市附近收敛缓慢的迭代搜索。它有精确解。

代价函数是凸的。若其他城市的拉力（它们的权重乘以从 v 指向它们的单位向量之和）不超过位于 v 的总权重，城市 v 就是最佳位置；位于同一点的城市在那里合并权重。

若没有城市满足条件，最佳点 M 在内部，三个加权单位向量在那里抵消，其代价有闭式公式。在 BC 相对 A 的另一侧作点 Q，使 |BQ| : |CQ| : |BC| = w₃ : w₂ : w₁。
对 M、B、Q、C 用托勒密不等式，对任意 M 都有 w₂|MB| + w₃|MC| ≥ w₁|MQ|，所以代价至少为 w₁(|MA| + |MQ|) ≥ w₁|AQ|。
由于最优点在内部，等号成立，答案就是 w₁|AQ|。城市判断中的一个极小容差避免了恰在边界处除以零，在那里两个公式给出相同的值。每组 `O(1)`。

第一个样例中所有价格都是 1，所有角都小于 120°，所以答案就是经典的费马点，距离之和为 (1 + √3)/√2 ≈ 1.93185。

注意事项：

- 当 Weiszfeld 迭代恰好落到某个城市上时就可能停在那里，例如城市共线且它们的重心正是其中之一；
- 两个或三个城市可能重合；
- 权重未必能构成三角形；这时权重最大的城市直接胜出。

在 3000 个随机测试（城市重合、共线和一般位置）上，答案与从重心出发的精细局部搜索一致。除了那些迭代从某个城市开始并停留在那里的共线情形外，答案也与一个独立的已通过实现处处一致。
