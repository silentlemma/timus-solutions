# 1827. Войны туземцев

[Timus 1827](https://acm.timus.ru/problem.aspx?space=1&num=1827) · сложность 1188 · hashing

Автор оригинальной задачи — Дмитрий Иванков; XII открытое личное первенство УрГУ, 19 марта 2011 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Туземцы различают сутки по числу звёзд на ночном небе. В их книге
каждая война записана как x — звёзды в её первые сутки, y — звёзды в
последние сутки и d — длительность в сутках. По числу звёзд, видимых i
суток назад, для каждых из последних n суток отметить все сутки, в
которые могла идти какая-нибудь записанная война.

## Входные данные

n (2 ≤ n ≤ 10⁵), затем a₁, …, aₙ, где aᵢ — число звёзд i суток назад
(0 ≤ aᵢ ≤ 2·10⁸), затем m (1 ≤ m ≤ 10⁵) и m строк x, y, d
(0 ≤ x, y ≤ 2·10⁸, 2 ≤ d ≤ 50).

## Выходные данные

Строка из n цифр: i-я равна 1, если i суток назад могла идти война, и 0
иначе.

## Примеры

### Пример 1

Ввод:

```
6
6 5 4 3 2 1
3
2 4 3
4 5 2
1 6 5
```

Вывод:

```
011110
```

## Решение

Война длиной d, закончившаяся k суток назад, началась k + d − 1 суток
назад, поэтому она подходит ровно тогда, когда a в позиции k + d − 1
равно x, а a в позиции k равно y. Длины не больше 50, так что для
каждой длины d, встречающейся в книге, кладём пары (x, y) её войн в
хеш-множество и проходим по всем k, проверяя пару (a в k + d − 1, a в
k). Каждое попадание покрывает сутки k … k + d − 1: храним для каждого
k самые давние сутки, покрытые войной, которая там заканчивается, и
один проход отмечает все сутки не выше текущего максимума. Это не больше
49·n проверок, `O(50·n + m)`.

Python делает проверки для одной длины разом через `map` по двум
сдвинутым спискам, упаковывает попадания в битовую маску из длинного
целого и размазывает её на d суток за O(log d) сдвигов и «или».

В примере война (2, 4, 3) подходит на 5–3 суток назад, а (4, 5, 2) — на
3–2 суток назад, тогда как (1, 6, 5) требовала бы 6 звёзд 2 суток назад.

Подводные камни:

- первые сутки войны дальше в прошлом, так что x сравнивается с
  большим числом суток назад;
- если все числа равны, каждая война подходит везде, поэтому поиск войн
  по позициям их первого дня квадратичен;
- война может быть длиннее всей записи.

Ответы совпадают с независимой принятой реализацией на нескольких
сотнях случайных записей и на полноразмерных тестах.
