# 1842. 局部根

[Timus 1842](https://acm.timus.ru/problem.aspx?space=1&num=1842) · 难度 5624 · strings

原题作者 Ivan Burmistrov，出自 2010 年 8 月彼得罗扎沃茨克夏季集训的 Ural SU Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把 n 个字母组成的单词 w 在点 i（1 ≤ i ≤ n − 1）处切成前缀 p 和后缀 s。点 i 处的局部根是最短的非空单词 r，使得 p 与 r 结尾一致（一个是另一个的后缀），s 与 r 开头一致（一个是另一个的前缀）。
求局部根最长的一个点，以及该长度。

## 输入

一个由小写拉丁字母组成的单词，长度在 2 到 300 000 之间。

## 输出

该点以及该点处局部根的长度。任何局部根最长的点都可以。

## 样例

### 样例 1

输入：

```
aababaaa
```

输出：

```
5 6
```

## 解法

长度 L 在点 i 处可行，当且仅当对所有满足 i − L ≤ k < i 且不越出单词的 k 都有 w[k] = w[k + L]：把 r 写两遍，第一份在切点结束、第二份在切点开始，凡是落在单词内部的位置都与 w 相同。
w 的周期 P 总是可行的，所以局部根不会长于 P。临界分解定理说明某个点处的局部根恰好为 P，而 Crochemore–Perrin 的构造可以在线性时间内找到这样的点。

求 w 的字典序最大后缀两次：一次用字母的通常顺序，一次用反向顺序，两种情况下都把作为较长单词前缀的较短单词视为较小。两个起点中较靠后的那个就是临界点。
只有由同一个字母重复组成的单词，两个后缀才都是整个单词；此时任何点都可以，取 1。
最大后缀用 Two-Way 字符串搜索中的比较循环求得：维护候选起点、当前偏移和已匹配部分的周期，每次失配都把候选起点或扫描位置向前推进。周期本身等于 n 减去最长边界，由前缀函数求出。`O(n)`。

在样例中，最长边界是 "aa"，所以周期为 6。在 a < b 下最大后缀是 "babaaa"，起点 3；在 b < a 下是 "aaa"，起点 5。答案是点 5，那里的局部根是 "aaabab"。

注意事项：

- 根可以越出单词的两端，所以较短的一侧并不限制它；
- 时间限制为半秒，只有线性算法可行；Python 版本在 PyPy 上运行。

答案都通过一个检查器：它重新计算周期，并确认在输出的点处没有更短的根可行。对三个字母上长度不超过 8 的所有单词以及两个字母上长度不超过 12 的所有单词，直接搜索确认这些点都是临界点。
