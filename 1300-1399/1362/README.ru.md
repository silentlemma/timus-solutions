# 1362. Одноклассники 2

[Timus 1362](https://acm.timus.ru/problem.aspx?space=1&num=1362) · сложность 442 · dp

Автор оригинальной задачи — Евгений Крохалев; IX командный студенческий чемпионат Урала по программированию, Екатеринбург, 19–24 апреля 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Агентство из N ≤ 100 000 сотрудников устроено как дерево: у каждого,
кроме генерального директора, ровно один начальник. У Тани есть
новость, и каждый, кто её знает, может позвонить своему начальнику или
одному из непосредственных подчинённых; разговор длится минуту, и
одновременно человек ведёт только один разговор. Нужно вывести
наименьшее число минут, за которое новость узнает всё агентство. Это
версия задачи [1323](../1323/README.ru.md) для дерева.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк: строка K — список подчинённых сотрудника K,
заканчивающийся нулём. В последней строке номер Тани.

## Выходные данные

Наименьшее число минут.

## Примеры

### Пример 1

Ввод:

```
10
2 3 0
4 5 7 0
6 9 0
0
0
8 10 0
0
0
0
0
2
```

Вывод:

```
5
```

## Решение

Звонить можно и вверх, и вниз, так что начальник — просто ещё один
сосед. Подвесим дерево за Таню; тогда новость попадает в каждое
поддерево один раз, через его корень.

Пусть time(v) — сколько минут нужно v, чтобы оповестить всё своё
поддерево после того, как новость дошла до v. Если v звонит детям в
каком-то порядке, i-й ребёнок узнаёт новость на минуте i и заканчивает
на i + time(ребёнка). Лучший порядок — начинать с самого медленного
поддерева: сортируем времена детей по убыванию t₁ ≥ t₂ ≥ …, и
time(v) = max(tᵢ + i). Обмен двух соседей, стоящих не в этом порядке,
никогда не ухудшает результат, что и доказывает правило.

Дерево обходится в ширину, а времена считаются от листьев вверх, так
что даже цепочке из 100 000 рекурсия не нужна. `O(N log N)`.

Тонкие места:

- корень — не обязательно директор: если Таня подчинённая, новость идёт вверх и
  потом вниз по другим ветвям (тесты 03 и 04);
- цепочка из 100 000 слишком глубока для рекурсии в большинстве языков
  (сгенерированный тест 2);
- звезде из 100 000 нужно 99 999 минут, по одному звонку за раз
  (сгенерированный тест 3).

Ответы сравнивались с перебором всех способов звонить, минута за
минутой, на 400 случайных деревьях до 8 сотрудников.
