# 1362. 同学 2

[Timus 1362](https://acm.timus.ru/problem.aspx?space=1&num=1362) · 难度 442 · dp

原题作者 Evgeny Krokhalev，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一家有 N ≤ 100 000 名员工的公司是一棵树：除总经理外，每人恰有一位上司。Tanya 有一个消息，知道消息的人可以给
自己的上司或某个直接下属打电话；每次通话一分钟，一个人同一时间只能打一个电话。输出全公司都知道消息所需的最少
分钟数。这是 [1323](../1323/README.zh.md) 的树上版本。

时间限制：2 秒。内存限制：64 MB。

## 输入

1 ≤ N ≤ 100000 名员工有唯一 ID 1 至 N。接着 N 行，第 K 行列出员工 K 的直属下属，以 0 结束。最后一行是同范围内 Tanya 的 ID；层级构成树。

## 输出

最少的分钟数。

## 评测方式

词元比较（`judging: tokens`）：一个整数，表示最少经过的分钟数；忽略空白分隔。

## 样例

### 样例 1

输入：

```
6
2 3 0
4 5 0
6 0
0
0
0
4
```

输出：

```
4
```

## 解法

电话既可以往上打也可以往下打，所以上司只是又一个邻居。以 Tanya 为根；这样消息进入每棵子树恰好一次，经由子树的根。

设 time(v) 为 v 得知消息后通知整棵子树所需的分钟数。若 v 按某种顺序给孩子打电话，第 i 个孩子在第 i 分钟得知，在
i + time(孩子) 时完成。最优顺序是先打给最慢的子树：把孩子的时间按降序排为 t₁ ≥ t₂ ≥ …，则 time(v) = max(tᵢ + i)。
交换两个不符合这一顺序的相邻孩子永远不会更差，由此可证。

按广度优先顺序遍历树，再从叶子向上计算时间，所以即使是 100 000 长的链也不需要递归。`O(N log N)`。

所有简单实现保留 O(N) 的树、遍历、DP 与孩子时间数据。流式 C++/Go/Java 另有有界解析缓冲；Python/Rust 保存完整输入，共 O(N+I)，I 为输入字节。孩子列表及最大临时排序行合计仍 O(N)，没有递归调用栈。

注意事项：

- 根不一定是总经理：若 Tanya 是下属，消息先往上再沿其他分支往下（测试 03 和 04）；
- 100 000 长的链对大多数语言的递归来说太深（生成测试 2）；
- 100 000 个点的星形需要 99 999 分钟，每次只能打一个电话（生成测试 3）。

在 400 棵最多 8 名员工的随机树上，与逐分钟枚举所有打电话方式的搜索结果比较过。

## 优化解法

新 C++、Go、Rust 保留子树时间降序的拨号顺序。每员工存原上司、首个下属、下一兄弟三个索引，枚举全部无向邻居，无逐顶点容器或重复边对象。从消息源建立平坦 BFS 顺序及父数组，原上司只是普通邻居，原主管可不同。倒序处理，把孩子完成时间放入复用工作数组前缀，降序排序，取 max(time[i]+i+1)，叶子为零。编号与时间用 32 位足够：串行拨号至多 N−1 分钟。时间 O(N log N)，树空间 O(N)，无递归遍历。C++、Go 流式读入；Rust 保留输入字符串，完整空间 O(N+输入字节数)。保留简单版，Java 复用合格基础版，Python 使用独立优化源代码。

通过评测的 Rust 1.75 x64 版本耗时 0.046 秒，基础版为 0.031 秒，内存为 3 948 KB，基础版为 15320 KB。

Java 复用基础版，两项必需名次均 1/22。Python 使用 [1362_dp_optimized.py](1362_dp_optimized.py)，此前精确源 Accepted #11328667，0.312 s / 29520 KB。七个相同 CPython 对手选择第三参考，限额 0.34040 s / 39495.60 KB，两项须比较且均通过。教学基础版 0.468 s / 33988 KB 时间不通过。统一[标准](../../RATING_CRITERIA.md) 仅严格小于 1024 KB 不比较内存，恰好 1024 KB 须两项；排除快于 0.015 s 的对手，仅自己的时间取下限。优化 C++ 两项 1/58 通过；Go/Rust 通过同语言旧编译器回退。保留简单版，不复制相同优化文件。

七个文件仅修正解释性注释：五个简单文件及优化 Python 澄清从一计数的第 i 次电话在经过 i 分钟时完成；优化 Go 的工作数组注释移到逆序收集与排序循环旁。算法及有意义注释保留。
