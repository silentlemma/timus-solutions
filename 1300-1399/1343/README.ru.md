# 1343. 12 месяцев

[Timus 1343](https://acm.timus.ru/problem.aspx?space=1&num=1343) · сложность 417 · number_theory

Автор оригинальной задачи — Павел Атнашев; USU Championship 2004.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны первые k из 12 цифр, 0 ≤ k ≤ 12. Нужно вывести любое 12-значное
число, начинающееся с них и не имеющее делителей, кроме 1 и самого
себя. Ответ гарантированно существует.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

k в первой строке, k цифр во второй.

## Выходные данные

12-значное число.

## Проверка

Чекер принимает любые 12 цифр, начинающиеся с данных и образующие число
без других делителей.

## Примеры

### Пример 1

Ввод:

```
5
64631
```

Вывод:

```
646310554187
```

## Решение

Заполним свободные цифры нулями и будем увеличивать число, пока оно не
станет простым. Простые числа около 10¹² в среднем отстоят друг от
друга примерно на 28, и ни один промежуток ниже 10¹² не длиннее
нескольких сотен, так что проверяется не больше нескольких сотен чисел.
Каждое проверяется тестом Миллера — Рабина с основаниями 2, 3, 5, 7, 11
и 13, которые не ошибаются ниже 3 · 10¹². Если даны все 12 цифр, ответ
— само число. Число выводится с ведущими нулями, если этого требует
префикс из нулей.

Тонкие места:

- данные цифры могут начинаться с нулей, и ответ должен их сохранить,
  например `000000000002` (тесты 04 и 05);
- квадраты внутри теста доходят до 10²⁴, больше 64 бит, поэтому
  умножение по модулю n требует осторожности;
- при k = 0 вторая строка пустая (тест 02).

## Особенности языков

- C++ и Rust умножают в 128 битах, а Go использует `bits.Mul64` и
  `bits.Rem64`. Java делит один множитель на половины по 20 бит, что
  держит каждое произведение ниже 2⁶⁰ при n меньше 2⁴⁰.
