# 1343. 12 месяцев

[Timus 1343](https://acm.timus.ru/problem.aspx?space=1&num=1343) · сложность 417 · number_theory

Автор оригинальной задачи — Павел Атнашев; USU Championship 2004.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны первые k из 12 цифр, 0 ≤ k ≤ 12. Нужно вывести любое 12-значное
число, начинающееся с них и не имеющее делителей, кроме 1 и самого
себя. Ответ гарантированно существует.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

k в первой строке, k цифр во второй.

## Выходные данные

12-значное число.

## Проверка

Чекер принимает любые 12 цифр, начинающиеся с данных и образующие число
без других делителей.

## Примеры

### Пример 1

Ввод:

```
5
64631
```

Вывод:

```
646310554187
```

## Решение

Предпочтительная учебная версия — пробные деления на C++. Дополняем префикс нулями, отдельно обрабатываем 2, затем перебираем нечётные кандидаты. Число простое тогда и только тогда, когда у него нет делителя до целого квадратного корня. Сначала проверяем 2 и 3; остальные простые имеют вид 6q−1 или 6q+1, эти пары и перебирает цикл. При N<10¹² произведения помещаются в 64 бита. Для G кандидатов время O(G·sqrt(N)), дополнительная память O(1), без модульных степеней и таблицы простых. Гарантия существования ответа даёт простое до выхода за префикс. Печатаем ровно двенадцать цифр с ведущими нулями. При двенадцати заданных цифрах сразу выводим гарантированно допустимое значение, включая 000000000001. Элементарная версия сохранена на C++; более сложные принятые реализации доступны отдельно.

## Оптимизированные решения

`1343_number_theory_optimized.java`. Сохраняются прежний Миллер—Рабин с шестью основаниями и модульное умножение по20-битным частям: это компактный ввод-вывод уже оптимизированного Java-алгоритма. Ровно k цифр префикса читаются через разделители, число дополняется до12 позиций, последовательные кандидаты проверяются лишь при k<12. По обещанию существования полный12-значный префикс уже является допустимым ответом. Ведущие нули и число выводятся напрямую без Scanner, StringBuilder и String.format. Проверяемые значения ниже10^12<2^40, промежуточные части помещаются в long. При G кандидатах ниже P время O(G log P) ограниченных модульных шагов, память O(1). Простая Java-версия не выдумывается: прежний оптимизированный файл сохранён, новый точный Accepted допущен по собственному рейтингу топ-10/топ15%.

По сравнению с `1343_number_theory.java`: время 0.125 s → 0.093 s; память 1752 KB → 500 KB.

Миллер–Рабин использует основания 2,3,5,7,11,13. После проверок малых простых представим N−1=2ˢd, d нечётно. Для каждого основания считаем x=aᵈ mod N и принимаем его при x=1, x=N−1 либо если одно из следующих s−1 возведений в квадрат даёт N−1; иначе кандидат составной. [Граница Яшке для шести оснований](https://doi.org/10.1090/S0025-5718-1993-1192971-8) равна 3474749660383 и выше всех здешних чисел: тест детерминирован. Для G кандидатов нужно O(G log N) машинных операций. Новые Go и Rust используют ограниченный ввод-вывод, Go умножает через bits.Mul64/bits.Rem64, Rust — через u128. Java и Python переиспользуют подходящие исходные файлы. Быстрый набор C++ закрывает тот же [простой перебор](1343_bruteforce.cpp) из таблицы простых: его точный Accepted удовлетворяет критерию включения, копия optimized не нужна. Измеренный допуск не означает лучшую асимптотику по сравнению с Миллером–Рабином. Исходные версии Миллера–Рабина C++/Go/Rust сохранены среди других Accepted-подходов.

Принятые базовые реализации [1343_number_theory.java](1343_number_theory.java), [1343_number_theory.py](1343_number_theory.py) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.

## Особенности языков

Новые исходники сравниваются по срезу от 18 ноября 2026 года с другими авторами на текущих компиляторах судьи. Порогов по ID посылки или дате нет. Ничьи делят место, времена меньше 0.015 с при сравнении считаются 0.015 с. Приведённые ниже места относятся к новым версиям; прежние исходники сохраняют собственные исторические метрики Accepted.

`1343_number_theory_optimized.java`: место по времени 1/37, по памяти 2/37 в этой сопоставимой выборке.

Звёздочка означает недостигнутую рейтинговую цель: для C++ нужны первые десять мест либо топ 15% одновременно по обеим метрикам; для остальных семейств — первое место по обеим. Отдельный критерий допуска может выполняться по рейтингу или улучшению, в том числе при снижении времени либо памяти минимум на 30%.
