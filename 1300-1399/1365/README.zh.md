# 1365. 测试计算器

[Timus 1365](https://acm.timus.ru/problem.aspx?space=1&num=1365) · 难度 4701 · parsing

原题作者 Alexander Klepinin，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

输入的每一行是一个由字符 `0123456789+*/();` 组成、不超过 50 个字符的表达式，要求输出它的值，
且必须与评委一个旧的计算模块完全一致。已知的只有：运算 `+`、`*` 和 `/`（整数除法）以前缀形式书写，
参数个数任意，`+3;6;10` 得 19；没有运算的项会被拼接，`3;6;9` 得 369；可以使用括号，
`(+3;6)(*2;3)` 得 96；表达式的一部分无论出现在哪里，算法都相同。其余规则要靠运行该模块自己摸索。
计算过程中所有值都在 0 到 10⁹ 之间。

时间限制：2 秒。内存限制：64 MB。

## 输入

若干表达式，每行一个。

## 输出

对第 i 行输出 `Expression i evaluates to: v`，v 为其值。

## 样例

### 样例 1

输入:

```
(+3;6)(*2;3)
(+3;6)(/3;2)
```

输出:

```
Expression 1 evaluates to: 96
Expression 2 evaluates to: 91
```

## 解法

这个模块是一个 Java 小程序，如今的浏览器已无法运行，所以下面给出的是一份被接受的解答所遵循的规则：

- 项是一个数、一个带参数的运算符号，或括号中的整个表达式（缺少 `)` 也可以）；
- 相邻的项被拼接：把它们的十进制写法连起来，再作为数读出，因此前导零会消失；
- 运算的参数是由 `;` 分隔的拼接项串；`/` 从左到右做除法，除以零得 0；
- 在运算之外，即行首或括号内，`;` 把它后面全部内容的值拼接到前面：`1;+2;3` 是 1 拼上 5，即 15；
- 若一个拼接项串中一个项也没有，它的值为 1；
- 不能作为任何项开头的字符结束当前项串，该行其余部分被忽略。

由三个函数组成的递归下降实现这些规则：项、把参数合并起来的运算，以及拼接项串，后者会被告知自己是否位于运算之内。
每行只读一遍：对输入长度为 `O(n)`。规则已在 10 000 个随机表达式上与一份独立的已通过实现对比过。

注意事项：

- 第二个样例：`/3;2` 是 1，拼在 9 后面得 91；
- 运算之外的 `;` 拼接的是整个剩余部分，而不只是下一个项（测试 05）；
- 空行或不含任何项的行得 1，单独一个 `;` 得 11：它两侧各缺一个项（测试 03）；
- `(0)(5)` 是 5，`0;0` 是 0：拼接后的字符串按数读出（测试 06）；
- `/7;0` 得 0（测试 04）。
