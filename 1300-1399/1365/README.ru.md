# 1365. Тестирование вычислителя

[Timus 1365](https://acm.timus.ru/problem.aspx?space=1&num=1365) · сложность 4356 · parsing

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждая строка входа — выражение из символов `0123456789+*/();`, не длиннее
50 символов; нужно вывести его значение точно так же, как это делает старый
модуль-вычислитель жюри. Известно только вот что: операции `+`, `*` и `/`
(целочисленное деление) записываются в префиксной форме с любым числом
аргументов, `+3;6;10` даёт 19; термы без операции склеиваются, `3;6;9`
даёт 369; можно ставить скобки, `(+3;6)(*2;3)` даёт 96; и часть выражения
вычисляется одинаково, где бы она ни стояла. Остальное предлагалось
выяснить, запуская сам модуль. Все значения по ходу вычисления лежат от
0 до 10⁹.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Выражения, по одному в строке.

## Выходные данные

Для i-й строки — `Expression i evaluates to: v`, где v — её значение.

## Примеры

### Пример 1

Ввод:

```
(+3;6)(*2;3)
(+3;6)(/3;2)
```

Вывод:

```
Expression 1 evaluates to: 96
Expression 2 evaluates to: 91
```

## Решение

Модуль был Java-апплетом, который современные браузеры уже не запускают,
поэтому ниже описаны правила, которым следует принятое решение:

- терм — это число, знак операции с аргументами или целое выражение в
  скобках (без закрывающей `)` тоже можно);
- термы, стоящие подряд, склеиваются: их десятичные записи соединяются и
  снова читаются как число, так что ведущие нули пропадают;
- аргументы операции — склеенные цепочки термов, разделённые `;`; `/`
  делит слева направо, а деление на ноль даёт 0;
- вне операции, то есть в начале строки или внутри скобок, `;` приклеивает
  значение всего, что идёт после неё, к тому, что было раньше: `1;+2;3` —
  это 1, склеенная с 5, то есть 15;
- недостающий первый терм даёт вклад 1 в склеенную цепочку;
- `)` заканчивает цепочку; только лишняя `)` отбрасывает остаток строки.

Эти правила реализует рекурсивный спуск из трёх функций: терм, операция,
сворачивающая свои аргументы, и склеенная цепочка, которой сообщают,
стоит ли она внутри операции. Каждая строка читается один раз: `O(n)` от
длины входа. Правила проверены сравнением с независимым вычислителем
на 10 000 случайных выражений.

Подводные камни:

- вторая строка примера: `/3;2` — это 1, а после 9 получается 91;
- `;` вне операции приклеивает весь остаток, а не только следующий терм
  (тест 05);
- пустая строка или `()` даёт 1, а одна `;` даёт 11: по недостающему
  терму с каждой стороны (тест 03);
- `(0)(5)` — это 5, а `0;0` — это 0: склеенная строка читается как
  число (тест 06);
- `/7;0` даёт 0 (тест 04).
