# 1366. Подарки

[Timus 1366](https://acm.timus.ru/problem.aspx?space=1&num=1366) · сложность 523 · math

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждый из n ≤ 1000 детей приносит подарок, и подарками меняются так,
чтобы каждый ребёнок получил ровно один подарок и никто не остался со
своим. Нужно посчитать число способов.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число n.

## Выходные данные

Число схем обмена.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
2
```

## Решение

Схема обмена — перестановка без неподвижных точек, беспорядок. По
формуле включений-исключений их число d(k) = Σ (−1)ⁱ · k! / i! по
i = 0 … k, и умножение d(k − 1) на k даёт все слагаемые d(k), кроме
последнего, (−1)ᵏ. Значит, d(1) = 0 и d(k) = k · d(k − 1) + (−1)ᵏ:
начинаем с 0 и применяем это для k = 2 … n.

Ответ при n = 1000 содержит 2 568 цифр, так что нужна длинная
арифметика: каждый шаг умножает на небольшое число и прибавляет или
вычитает 1. `O(n² log n)` действий с цифрами.

Тонкие места:

- один ребёнок поменяться не может: ответ 0 (тест 02);
- d(21) — первое значение, которое не помещается в 64 бита (тест 06);
- после умножения число при k ≥ 3 не меньше 3, так что вычитание 1
  никогда не уводит ниже нуля.

Рекуррентность сравнивалась с подсчётом всех перестановок при n ≤ 8 и
с суммой включений-исключений при n = 50.

## Особенности языков

- Python использует встроенные длинные числа, Go и Java — стандартные библиотеки.
- C++ и Rust хранят число частями по девять десятичных цифр, начиная с
  младшей, и печатают все части, кроме старшей, дополняя их до девяти
  цифр.
