# 1366. 礼物

[Timus 1366](https://acm.timus.ru/problem.aspx?space=1&num=1366) · 难度 523 · math

原题创意来自 Stanislav Vasiliev，由 Pavel Egorov 准备，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n ≤ 1000 个孩子每人带来一件礼物，大家交换礼物，使每个孩子恰好得到一件礼物，且没有人拿回自己的礼物。求交换方案数。

时间限制：1 秒。内存限制：64 MB。

## 输入

一个数 n。

## 输出

交换方案的数目。

## 样例

### 样例 1

输入：

```
3
```

输出：

```
2
```

## 解法

一种交换就是没有不动点的排列，即错排。由容斥原理，错排数为 d(k) = Σ (−1)ⁱ · k! / i!（i = 0 … k），而
d(k − 1) 乘以 k 恰好给出 d(k) 中除最后一项 (−1)ᵏ 之外的所有项。所以 d(1) = 0，d(k) = k · d(k − 1) + (−1)ᵏ：
从 0 开始，对 k = 2 … n 依次应用即可。

n = 1000 时答案有 2 568 位，需要高精度运算：每一步乘以一个小整数，再加 1 或减 1。`O(n² log n)` 次数位运算。

注意事项：

- 一个孩子无法交换：答案为 0（测试 02）；
- d(21) 是第一个超出 64 位的值（测试 06）；
- k ≥ 3 时乘法之后的数至少为 3，所以减 1 不会小于零。

在 n ≤ 8 时与枚举所有排列的结果比较过，在 n = 50 时与容斥求和的结果比较过。

C++ 教学版按低位到高位保存单个十进制数字。第 k 步，偶数 k 的初始进位是 +1，奇数 k 为 −1。每位乘以 k 并加上进位，保留个位，把商传给下一位。一次扫描就得到 k·D(k−1)+(−1)^k。k 为奇数时前一个下标是偶数，D(k−1) 为奇数，最低位为正，首次减一不会使结果为负。输出时逆序打印。时间 O(n² log n)，空间 O(n log n)。

## 优化解法

Go/Java/Rust 仍计算错排数，但合并两步：由 D(k)=kD(k−1)+(−1)^k，偶数 k 有 D(k)=k(k−1)D(k−2)−(k−1)。从 D(2)=1 开始，单独处理 n=1；奇数 n 最后计算 nD(n−1)−1（n>1）。每对只扫描一次 10⁹ 进制数组。由递推式，偶数下标的错排数为奇数，最低块为正。初始减量小于乘数 f，而第一个乘积至少为 f。后续进位在 [0,f−1]，中间值小于 f·10⁹。f≤999000，因此有符号 64 位整数足够，末进位至多一块。由 D(n)<n!≤10³⁰⁰⁰，334 块足够，Go 和 Java 的完整输出最多占用 3001 字节。固定数组替代 Go 和 Java 的大数临时对象。Go 通过标准句柄读写并从末尾填充十进制缓冲区，Java 去除 Scanner。Rust 使用 C 入口和 C 运行库逐字符读写，每块仅需九字节的格式化缓冲区。时间 O(n² log n) 字操作，O(n log n) 数字。保留简单版，C++/Python 复用已达标基础版。
