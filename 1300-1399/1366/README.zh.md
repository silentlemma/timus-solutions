# 1366. 礼物

[Timus 1366](https://acm.timus.ru/problem.aspx?space=1&num=1366) · 难度 524 · math

原题创意来自 Stanislav Vasiliev，由 Pavel Egorov 准备，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n ≤ 1000 个孩子每人带来一件礼物，大家交换礼物，使每个孩子恰好得到一件礼物，且没有人拿回自己的礼物。求交换方案数。

时间限制：1 秒。内存限制：64 MB。

## 输入

一个数 n。

## 输出

交换方案的数目。

## 样例

### 样例 1

输入：

```
3
```

输出：

```
2
```

## 解法

一种交换就是没有不动点的排列，即错排。由容斥原理，错排数为 d(k) = Σ (−1)ⁱ · k! / i!（i = 0 … k），而
d(k − 1) 乘以 k 恰好给出 d(k) 中除最后一项 (−1)ᵏ 之外的所有项。所以 d(1) = 0，d(k) = k · d(k − 1) + (−1)ᵏ：
从 0 开始，对 k = 2 … n 依次应用即可。

n = 1000 时答案有 2 568 位，需要高精度运算：每一步乘以一个小数，再加 1 或减 1。`O(n²)` 次数位运算。

注意事项：

- 一个孩子无法交换：答案为 0（测试 02）；
- d(21) 是第一个超出 64 位的值（测试 06）；
- k ≥ 3 时乘法之后的数至少为 3，所以减 1 不会小于零。

在 n ≤ 8 时与枚举所有排列的结果比较过，在 n = 50 时与容斥求和的结果比较过。
