# 1372. 死星

[Timus 1372](https://acm.timus.ru/problem.aspx?space=1&num=1372) · 难度 5382 · geometry

原题创意来自 Alexander Mironenko，由 Pavel Egorov 准备，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

半径为 R 的球形空间站上有 N ≤ 9 台发动机卡在开启状态，每台装在高 h 的桅杆上，位于给定的经度和纬度，都以相同的推力
F 沿给定方向推动，方向也用经度和纬度表示。另一台装在同样桅杆上的发动机可以放在任何地方、朝任何方向、给任意推力。
要选择它，使空间站不再被加速旋转，且推力最小；输出它的位置、方向和推力，保留 8 位小数。

时间限制：1 秒。内存限制：64 MB。

## 输入

R、空间站质量和 h，然后是 F 和 N，再是 N 行：发动机的经度、纬度以及其方向的经度、纬度。

## 输出

新发动机的经度和纬度、其方向的经度和纬度，以及它的推力。任何推力最小的答案都可以。

## 样例

### 样例 1

输入：

```
100.3 1000000.45 15.5
156.5 1
0.0 0.0 90.0 0.0
```

输出：

```
0.00 0.00 270.00 0.00 156.50
```

## 解法

各发动机通过总力矩 T = Σ pᵢ × F dᵢ 使空间站加速旋转，其中 pᵢ 是长度为 R + h 的发动机位置向量，dᵢ 是推力的单位方向。
质量无关紧要。新发动机必须提供 −T。

点 p 处的力 f 产生力矩 p × f，且 |p × f| ≤ |p| · |f|。所以推力至少为 |T| / (R + h)，当 p 垂直于 T 且
f = p × T / |p|² 时恰好取到；此时 p × f = −T。与 T 垂直的大圆上任何一点都可以。解答取与 T 最不平行的坐标轴，
去掉它沿 T 的分量，作为放置方向。经度和纬度用 atan2 和 asin 求回。`O(N)`。

注意事项：

- 若总力矩为零，什么都不用做：推力为 0（测试 02 和 04）；
- 略小于 360 的经度会打印成 `360.00000000`，所以要折回 0（测试 09）；
- 输入中的质量只是干扰项；
- 极点处的经度是任意的（测试 03）。

测试由检查程序评判，它重新计算剩余力矩和最小推力；400 个随机空间站都通过了，其中许多的发动机在极点上或沿坐标轴。
