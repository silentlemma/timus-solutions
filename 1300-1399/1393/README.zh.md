# 1393. 平均公共前缀

[Timus 1393](https://acm.timus.ru/problem.aspx?space=1&num=1393) · 难度 1147 · strings

原题作者：Ilya Grebnov。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

T 是由 n 个大写字母组成的字符串，1 < n ≤ 250 000。把它的 n 个循环移位（包括
相同的）排序，输出这个顺序中相邻移位的最长公共前缀的平均长度，小数点后至少
三位。两个相同的移位公共前缀为全部 n 个字母。

时间限制：1.5 秒。内存限制：16 MB。

## 输入

n，然后是 T。

## 输出

平均公共前缀长度。

## 样例

### 样例 1

输入:

```
11
MISSISSIPPI
```

输出:

```
1.300
```

## 解法

相同的移位让顺序不唯一，也会破坏求公共前缀的常规方法，所以先把它们去掉。设
p 是 T 作为循环串的最短周期，用前缀函数求出：T 是一个 p 个字母的词 u 重复
n / p 次（若没有这样的周期则 p = n）。于是 T 的每个移位连续出现 n / p 次，
给出 p·(n / p − 1) 对公共前缀为 n 的相邻移位。u 的两个不同移位在前 p 个字母
内就不同，所以它们在 T 中的公共前缀与在 u 中相同。

u 的 p 个旋转互不相同。用前缀倍增加计数排序给它们排序：先按前 2ᵏ 个字母排
序，再按类别对排序。然后用 Kasai 的扫描求出每个旋转与前一个旋转的公共前缀：
从旋转 i 到 i + 1 最多损失一个字母，所以总工作量是线性的。答案是两部分之和
除以 n − 1，和用 64 位保存。`O(n log n)`。

注意事项：

- 相同移位的公共前缀是 n，而不是更多：AAAAA 的答案是 5.000（测试 02 和生成
  测试 2）；
- 和可达约 6.25·10¹⁰，需要 64 位（生成测试 2）；
- 只有最后一个字母不同的串需要约 log n 步倍增（生成测试 3）；
- 内存限制是 16 MB，所以数组使用 32 位整数。

在 1 500 个随机短串上做了比较（其中三分之一是周期串），对照程序对所有移位排
序并逐字母比较。

## 各语言说明

- Python 通过 `(T + T).find(T, 1)` 求 p，再用诱导排序（SA-IS）在线性时间内构建后缀数组，而不是倍增法，数据放在扁平的 `array` 缓冲区和 `bytearray` 中，并在 PyPy 下运行：在评测上用时 0.42 秒、内存 14 MB（限制 16 MB）。使用倍增排序和整数列表的早期版本在评测的第 30 个测试上超出内存限制。复杂度为 `O(n)`。
