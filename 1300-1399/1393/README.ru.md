# 1393. Average Common Prefix

[Timus 1393](https://acm.timus.ru/problem.aspx?space=1&num=1393) · сложность 1147 · strings

Автор оригинальной задачи: Ilya Grebnov.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

T — строка из n заглавных латинских букв, 1 < n ≤ 250 000. Нужно
отсортировать её n циклических сдвигов, включая одинаковые, и вывести
среднюю длину наибольшего общего префикса соседних сдвигов в этом
порядке, не меньше чем с тремя знаками после точки. Два одинаковых
сдвига имеют общими все n букв.

Ограничение времени: 1,5 секунды. Ограничение памяти: 16 МБ.

## Входные данные

n, затем T.

## Выходные данные

Средний общий префикс.

## Примеры

### Пример 1

Ввод:

```
11
MISSISSIPPI
```

Вывод:

```
1.300
```

## Решение

Одинаковые сдвиги делают порядок неоднозначным и ломают обычный поиск
общих префиксов, поэтому сначала уберём их. Пусть p — наименьший
период T как циклической строки, найденный префикс-функцией: T — слово
u из p букв, повторённое n / p раз (p = n, если такого периода нет).
Тогда каждый сдвиг T встречается n / p раз подряд, что даёт
p·(n / p − 1) пар соседей с общим префиксом n. Два разных сдвига u
различаются в пределах p букв, так что их общий префикс в T такой же,
как в u.

Все p поворотов u различны. Сортируем их удвоением префиксов с
сортировкой подсчётом: повороты, упорядоченные по первым 2ᵏ буквам,
затем по парам классов. Потом проход Касаи даёт общий префикс каждого
поворота с предыдущим: при переходе от поворота i к i + 1 теряется не
больше одной буквы, поэтому вся работа линейна. Ответ — сумма обеих
частей, делённая на n − 1; сумма хранится в 64 битах. `O(n log n)`.

Подводные камни:

- у одинаковых сдвигов общий префикс равен n, не больше: для AAAAA
  ответ 5.000 (тест 02 и сгенерированный тест 2);
- сумма доходит примерно до 6,25·10¹⁰ и требует 64 бит (сгенерированный тест 2);
- строке из одной буквы, кроме последней, нужно около log n шагов
  удвоения (сгенерированный тест 3);
- ограничение памяти 16 МБ, поэтому массивы из 32-битных чисел.

Ответы сравнивались на 1 500 случайных коротких строках, треть из
которых периодические, с сортировкой всех сдвигов и побуквенным
сравнением.

## Особенности языков

- Python находит p через `(T + T).find(T, 1)`, затем строит суффиксный
  массив индуцированной сортировкой (SA-IS) за
  линейное время вместо удвоения, в плоских буферах `array` и
  `bytearray`, и запускается под PyPy: у судьи он тратит 0,42 с и 14 МБ
  из 16 МБ. Прежняя версия с сортировками удвоением и списками целых
  превышала лимит памяти на тесте 30 жюри. `O(n)`.
