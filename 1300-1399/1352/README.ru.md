## Задача

Простое число Мерсенна — простое число вида 2^p − 1. Дано T запросов,
в каждом число N ≤ 38; нужно вывести показатель p N-го по возрастанию
простого числа Мерсенна.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

T, затем T строк с N.

## Выходные данные

T строк с показателями.

## Решение

Никакая программа не найдёт эти числа за секунду: 38-й показатель равен
6 972 593, и проверка даже одного числа такого размера требует огромных
вычислений. Порядок первых 38 простых чисел Мерсенна давно установлен,
поэтому решения хранят список их показателей как константную таблицу и
отвечают на запрос обращением по индексу. `O(T)`.

Тонкие места:

- N считается с 1: первое простое число Мерсенна — 2² − 1 = 3,
  показатель 2 (тест 03);
- все показатели помещаются в 32-битные целые.

Первые 22 значения проверены тестом Люка — Лемера для всех простых
показателей до 10 000; остальные взяты из опубликованного списка и
совпадают с примером и значениями, названными в условии.

## Особенности языков

- Python хранит таблицу одной строкой, разбитой на слова, поэтому ответы
  выводятся без обратного перевода в числа.
