# 1318. 对数

[Timus 1318](https://acm.timus.ru/problem.aspx?space=1&num=1318) · 难度 1393 · bitmask

原题创意来自 Nikita Shamgunov，由 Nikita Shamgunov 和 Anton Botov 准备，出自 2004 年 3 月 11–16 日在叶卡捷琳堡举行的第八届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 N ≤ 5000 个 128 位的数 A₀, …, A_{N−1}，求对所有有序对 k, j（从 0 到 N − 1）的
⌊log₁₀(A_k xor A_j)⌋ 之和，规定 0 的对数为 0。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行是 N。接下来 N 行每行四个 0 到 2³² − 1 的数，是 A_k 从高到低的 32 位字：
A_k = 2⁹⁶ · a₁ + 2⁶⁴ · a₂ + 2³² · a₃ + a₄。

## 输出

这个和。

## 样例

### 样例 1

输入：

```
2
0 0 0 2324
0 2332 0 0
```

输出：

```
44
```

## 解法

⌊log₁₀ x⌋ 等于不超过 x 的幂 10¹, 10², … 的个数。位数比 x 少的十的幂总是小于 x，而由于 10 > 2，与 x
位数相同的幂最多只有一个。因此用一张按位长 L 索引的表给出更短的幂的个数，长度为 L 的那个幂（如果存在）
只需比较一次。每对 k < j 只需一次异或、一次求位长和至多一次比较；对角线贡献 0，所以有序对之和是 k < j
之和的两倍。`O(N²)`，约 1250 万对。

注意事项：

- 有序对意味着样例中的 22 要算两次（测试 01）；
- 恰好为 10³⁸ 的异或值对数是 38，10³⁸ − 1 是 37（测试 06），最大的异或值 2¹²⁸ − 1 仍是 38（测试 05）；
- 各个字要按无符号数读取：4 294 967 295 放不进有符号 32 位整数；
- 和不超过 5000 · 4999 · 38 ≈ 9.5 · 10⁸，仍在 32 位以内，但用 64 位计数器毫无代价。

## 各语言说明

- C++ 和 Rust 使用原生 128 位整数；Go 和 Java 把每个数存成两个 64 位的半部分，并按无符号比较。
- 在 Python 中逐对计算 1250 万对需要好几秒，所以它改为处理排好序的数。在一段高于某一位 t 的位都相同的
  区间里，跨过第 t 位分界的每一对，其异或的最高位都是 t，因此更短的幂对它们都相同。若某个十的幂的最高位
  是 t，就像在二进制字典树中那样沿两半逐位向下，统计达到它的对数，很小的组则逐对检查。这样约需 0.2 秒，
  并在 800 个小型随机集合上与对所有对直接求和的结果比较过。
