# 1375. Нонконформизм

Автор оригинальной задачи — Ден Расковалов; IX командный студенческий чемпионат Урала по программированию, Екатеринбург, 19–24 апреля 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано простое p ≤ 10⁶ и 0 ≤ k ≤ p − 1. Нужно вывести любые x и y от 0
до p − 1 с x² + y² ≡ k (mod p) или `NO SOLUTION`, если таких нет.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

k и p.

## Выходные данные

x и y или `NO SOLUTION`.

## Примеры

### Пример 1

Ввод:

```
1 3
```

Вывод:

```
0 2
```

## Решение

Для нечётного простого p квадраты принимают (p + 1) / 2 различных
значений по модулю p, и столько же значений у k − x². Два множества по
(p + 1) / 2 значений среди p обязаны пересечься, так что какие-то x² и
y² дают в сумме k: ответ есть всегда, и `NO SOLUTION` не бывает. При
p = 2 любое k равно 0² + 0² или 1² + 0².

Чтобы его найти, запишем по одному корню для каждого квадрата: для y от
0 до p − 1 запоминаем y как корень из y² mod p. Затем пробуем
x = 0, 1, 2, …, пока у k − x² mod p не найдётся корень. Квадратами
является примерно половина всех значений, так что это заканчивается
почти сразу. `O(p)`.

Тонкие места:

- при k = 0 ответ 0 0 (тест 07);
- k − x² нужно брать по модулю p неотрицательным;
- x² доходит до 10¹², больше 32-битных чисел.

Ответ проверялся для всех k и всех простых меньше 300, а тесты
проверяются чекером, принимающим любую пару.
