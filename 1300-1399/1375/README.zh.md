# 1375. 不随大流

[Timus 1375](https://acm.timus.ru/problem.aspx?space=1&num=1375) · 难度 541 · number_theory

原题作者 Den Raskovalov，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定素数 p ≤ 10⁶ 和 0 ≤ k ≤ p − 1，输出任意一对 0 到 p − 1 之间的 x、y，使 x² + y² ≡ k (mod p)；若不存在则输出
`NO SOLUTION`。

时间限制：1 秒。内存限制：64 MB。

## 输入

k 和 p。

## 输出

x 和 y，或 `NO SOLUTION`。

## 评测方式

仓库使用语义检查器，接受满足以下条件的任意输出。 仓库检查器要求恰好两个非负整数记号 x,y，均小于 p，并验证 (x*x+y*y) mod p=k；任意有效对均可。输入保证素数，解总存在，因此拒绝 NO SOLUTION。

## 样例

### 样例 1

输入：

```
1 3
```

输出：

```
0 2
```

## 解法

对奇素数 p，平方数模 p 取 (p + 1) / 2 个不同的值，k − x² 也取同样多个值。p 个数中的两个各含 (p + 1) / 2 个值的集合
必然相交，所以总有 x² 与 y² 之和为 k：答案总是存在，永远不会输出 `NO SOLUTION`。p = 2 时，任何 k 都等于 0² + 0² 或
1² + 0²。

求解时，先为每个平方数记下一个平方根：对 0 到 p − 1 的 y，把 y 记为 y² mod p 的根。然后依次尝试 x = 0, 1, 2, …，
直到 k − x² mod p 有根为止。大约一半的值是平方数，所以几乎立刻就能结束。`O(p)`。

注意事项：

- k = 0 时答案是 0 0（测试 07）；
- k − x² 要取模 p 的非负值；
- y² 可接近 10¹²，超出 32 位整数。

对 300 以内的所有素数和所有 k 检查过答案，测试由接受任意一对答案的检查程序评判。

## 优化解法

`1375_math.py`. 用标量模运算替代 O(p) 平方根表。枚举 x，直到 r=(k-x*x) mod p 为零或通过 Euler 二次剩余判据。p=2 输出(0,k)；其余素数在 p mod4=3 时直接求根，否则用 Tonelli–Shanks。平方集合交集保证某个 x 成功；非剩余和 x 的搜索均有限，并非随机重试。最坏 O(p log p)，不承诺渐近优于表；Tonelli–Shanks 部分至多 O(log²p) 次模乘。p<=10^6 下存储 O(1) 个模数大小的整数。自己的 Accepted 和双指标第一名证明收录。保留教学表法，不同算法名为 math。

与 `1375_number_theory.py` 相比：时间 0.359 s → 0.078 s；内存 23992 KB → 828 KB。

新 C++/Go/Rust 以常数空间素域运算代替 O(p) 根表。p=2 或 k=0 时(k,0)。p≡1 mod4 先用 Euler 判据找非二次剩余 z，令 i=z^((p−1)/4)，则 i²=−1。取与 k 同余的奇数 t=k 或 k+p，a=(t+1)/2、b=(t−1)/2 满足 a²−b²=t，故(a mod p, ib mod p) 即答案。p≡3 mod4 时枚举 x=0…(p−1)/2，对 r=k−x² 计算 y=r^((p+1)/4) 并验 y²=r；若 r 为非零平方，Euler 判据给出 y²=r·r^((p−1)/2)=r。r=0 的平方根为零。枚举 x 恰好覆盖所有平方。平方集 S 与 k−S 各有 (p+1)/2 个元素，必有交集，因此扫描能找到一对。64 位乘积小于 10^12。T 次幂试验时间 O(1+T log p)，最坏 O(p log p)，额外空间 O(1)，不声称渐进时间始终优于表法。收录由实际评测/内存收益决定。Rust 用 C 字符 I/O。保留简单表，保留简单表法，Python 现有单独的模平方根版本。
