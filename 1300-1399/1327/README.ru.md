# 1327. Предохранители

## Задача

ЭВМ теряет предохранитель в каждый нечётный рабочий день: в день 1,
затем в день 3, в день 5 и так далее. Нужно посчитать, сколько
предохранителей сгорит с дня A по день B включительно,
1 ≤ A ≤ B ≤ 10 000.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

A в первой строке и B во второй.

## Выходные данные

Число предохранителей.

## Примеры

### Пример 1

Ввод:

```
1
5
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
100
200
```

Вывод:

```
50
```

## Решение

Среди дней с 1 по x ровно ⌊(x + 1) / 2⌋ нечётных. Нечётные дни с A по B
— это нечётные дни до B без нечётных дней до A − 1, что даёт
⌊(B + 1) / 2⌋ − ⌊A / 2⌋. `O(1)`.

Тонкие места:

- промежуток из одного дня даёт 1 для нечётного дня и 0 для чётного
  (тесты 03 и 04);
- оба конца учитываются, если они нечётные (тесты 01 и 07).
