# 1327. 保险丝

[Timus 1327](https://acm.timus.ru/problem.aspx?space=1&num=1327) · 难度 47 · math

原题作者 Den Raskovalov，出自 2004 年 10 月 16 日第十届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一台计算机在每个奇数工作日烧掉一根保险丝：第 1 天，然后第 3 天、第 5 天，依此类推。求从第 A 天到第 B 天
（含两端）烧掉的保险丝数，1 ≤ A ≤ B ≤ 10 000。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行是 A，第二行是 B。

## 输出

保险丝的数量。

## 样例

### 样例 1

输入：

```
1
5
```

输出：

```
3
```

### 样例 2

输入：

```
100
200
```

输出：

```
50
```

## 解法

第 1 天到第 x 天中有 ⌊(x + 1) / 2⌋ 个奇数日。从 A 到 B 的奇数日等于到 B 为止的奇数日减去到 A − 1 为止的
奇数日，即 ⌊(B + 1) / 2⌋ − ⌊A / 2⌋。`O(1)`。

注意事项：

- 只有一天的区间，奇数日得 1，偶数日得 0（测试 03 和 04）；
- 两端为奇数时都要计入（测试 01 和 07）。

## 优化解法

优化的 Java 解法直接从 `System.in` 逐字节解析两个数，而不是使用 `Scanner`：
0.078 s，而不是 0.109 s；304 KB，而不是 1624 KB。
