# 1322. Шпион

[Timus 1322](https://acm.timus.ru/problem.aspx?space=1&num=1322) · сложность 179 · strings

Идея оригинальной задачи — Александр Клепинин, подготовили Александр Клепинин и Станислав Васильев; VIII командный студенческий чемпионат Урала по программированию, Екатеринбург, 11–16 марта 2004 года.

## Задача

Шифратор берёт текст длиной до 100 000 символов, выписывает все его
циклические сдвиги, сортирует их и выдаёт последний столбец
отсортированной таблицы вместе с номером K строки, где стоит исходный
текст. По K и последнему столбцу нужно восстановить текст. Символы —
буквы и подчёркивание, упорядоченные так: A–Z, затем `_`, затем a–z.

Ограничение времени: 0.25 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Число K в первой строке и последний столбец во второй.

## Выходные данные

Исходный текст.

## Примеры

### Пример 1

Ввод:

```
3
rdarcaaaabb
```

Вывод:

```
abracadabra
```

## Решение

Это обратное преобразование Барроуза — Уилера. Строки, оканчивающиеся
символом c, превращаются в строки, начинающиеся с c, если перенести c из
конца в начало, и порядок между ними сохраняется. Строки, начинающиеся
с c, отсортированы по тому, что идёт после c, и ровно так же
отсортированы строки, оканчивающиеся на c. Значит, j-я строка,
оканчивающаяся на c, — это j-я строка, начинающаяся с c, сдвинутая на
один.

Отсортируем позиции последнего столбца устойчиво по символам и назовём
результат order. Строка order[j] оканчивается j-м символом
отсортированного столбца — тем, с которого начинается строка j, — и
строка order[j] — это строка j, сдвинутая влево на один, то есть сдвиг,
начинающийся на символ позже. Если начать со строки K и n раз перейти
по order, мы пройдём сдвиги, начинающиеся со второго, третьего, …
символа текста, а последний символ каждого из них стоит прямо перед его
началом, так что текст получается по порядку. Заданный порядок символов
совпадает с порядком ASCII, поэтому устойчивую сортировку делает
сортировка подсчётом по 128 кодам за `O(n)` времени. В Python вместо неё
используется встроенная устойчивая сортировка сравнениями, поэтому время
в худшем случае — `O(n log n)`. Все реализации используют `O(n)`
дополнительной памяти.

Тонкие места:

- у периодического текста несколько строк совпадают, и K может
  указывать на любую из них; все дают один и тот же текст (тест 04);
- заглавные буквы идут раньше подчёркивания, а строчные — после него
  (тест 05);
- сортировка должна быть устойчивой, иначе одинаковые символы
  перепутаются;
- ограничение времени — 0.25 секунды, поэтому нужны буферизованные ввод
  и вывод.

Дешифратор проверялся на 400 случайных и периодических текстах длиной
до 12 символов, зашифрованных прямой сортировкой сдвигов.

## Особенности языков

- Python сортирует позиции встроенной устойчивой сортировкой; остальные
  языки используют сортировку подсчётом.
- Python и Rust читают весь ввод перед разбором; Java собирает строки
  перед выделением токенов, а C++ и Go читают токены из буферизованного ввода.
