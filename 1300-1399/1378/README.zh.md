# 1378. 人工智能

[Timus 1378](https://acm.timus.ru/problem.aspx?space=1&num=1378) · 难度 1448 · geometry

原题创意来自 Alexander Klepinin，由 Stanislav Vasiliev 准备，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一张 W × H 像素（32 ≤ W, H ≤ 1000）的黑白照片上有一个用图形编辑器画出的实心图形：圆、正方形或三角形。
最长边或直径至少为 30 像素，三角形的角都不小于 10°。图形可以任意旋转。
输出 `circle`、`square` 或 `triangle`。

时间限制：1 秒。内存限制：64 MB。

## 输入

W 和 H，然后是 H 行，每行 W 个 0 或 1。

## 输出

`circle`、`square` 或 `triangle`。

## 解法

两个面积比对理想图形与大小和旋转无关，光栅化后近似成立。取质心、到最远像素中心的距离 r₁，以及垂直于该方向的最大伸展 r₂。
设 A 为面积：

- 对于理想的圆或椭圆，A / (π r₁ r₂) 等于 1，因为 r₁ 和 r₂ 是半轴；对于正方形则等于 2/π ≈ 0.64，因为它们是两条半对角线；
- 对于理想的正方形，A / (π r₁²) 等于 2/π；对于任何三角形，至多约为 0.4135，正三角形达到此值。

代码中 A 为像素个数，两距离都加上半个像素以近似补偿像素的大小。第一个比值大于 0.8 则为 `circle`；
否则，第二个比值大于 0.5 则为 `square`，其余为 `triangle`。

凸图形在每一行中只占一段连续的像素，所以计算 r₁ 和 r₂ 时只需各段的两端。`O(W · H)`。

注意事项：

- 第一个数是宽，第二个数是高；
- 正方形可以旋转任意角度（测试 03）；
- 本地测试包含答案为 `circle` 的椭圆形光栅图，只看圆度而不考虑 r₂ 的判断可能把它们当成正方形（测试 06）；
- 细长三角形的角可以小到 10°。
