# 1325. Грязь

[Timus 1325](https://acm.timus.ru/problem.aspx?space=1&num=1325) · сложность 533 · bfs

Идея оригинальной задачи — Станислав Васильев, подготовили Станислав Васильев и Павел Егоров; VIII командный студенческий чемпионат Урала по программированию, Екатеринбург, 11–16 марта 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Квартира — сетка N × M (N, M ≤ 500) из чистых клеток (1), грязных (2) и
стен (0). Из клетки можно шагнуть в любую из восьми клеток, имеющих с
ней общую вершину, и каждый шаг между чистой и грязной клеткой требует
переобуться. Нужно найти путь от компьютера до холодильника с
наименьшим числом переобуваний, а среди таких — с наименьшим числом
клеток. Вывести его длину в клетках, считая оба конца, и число
переобуваний, или 0 0, если до холодильника не добраться.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N и M, строка и столбец компьютера, строка и столбец холодильника,
затем N строк по M цифр. Левая верхняя клетка — (1, 1).

## Выходные данные

Длина пути в клетках и число переобуваний.

## Примеры

### Пример 1

Ввод:

```
3 7
1 1
3 7
1200121
1212020
1112021
```

Вывод:

```
8 4
```

### Пример 2

Ввод:

```
5 5
1 5
5 1
00001
00000
00000
00000
20000
```

Вывод:

```
0 0
```

## Решение

Стоимость пути — пара (переобувания, шаги), которая сравнивается сначала
по переобуваниям. Каждое переобувание меняет чистое на грязное или
наоборот, поэтому все клетки, впервые достигнутые ровно после c
переобуваний, одного вида: того же, что старт, при чётном c, и другого
при нечётном. Это разбивает поиск на слои c = 0, 1, 2, ….

Внутри слоя c обычный поиск в ширину по клеткам этого вида даёт
наименьшее число шагов. Его начальные клетки, затравки, — клетки этого
вида рядом со слоем c − 1, каждая с числом шагов, при котором её впервые
задели. Слой c − 1 обрабатывался в порядке шагов, так что затравки уже
отсортированы по шагам. Поиск идёт по уровням: на каждом числе шагов он
сначала принимает ещё не достигнутые затравки с этим числом, а затем
расширяет клетки уровня. Клетка другого вида становится затравкой слоя
c + 1 только в первый раз за слой — это и есть её наименьшее число
шагов. Первый слой, дошедший до холодильника, даёт ответ. Каждая клетка
фиксируется один раз и смотрит на восемь соседей, `O(N · M)`.

Тонкие места:

- ходить можно и по диагонали (тест 05);
- меньше переобуваний важнее короткого пути: чистый обход из 9 клеток
  лучше прямого пути из 7 с двумя переобуваниями (тест 06);
- компьютер и холодильник могут стоять в одной клетке: 1 0 (тест 03);
- без правила «один раз за слой» клетка может попасть в затравки до
  восьми раз, что на квартире 500 × 500 стоит слишком много памяти.

Ответы сравнивались с алгоритмом Дейкстры по паре (переобувания, шаги)
на 500 случайных квартирах размером до 8 × 8.

## Особенности языков

- CPython тратит около 0.3 секунды на полную квартиру 500 × 500, что
  слишком близко к пределу в 0.5 секунды, поэтому решение на Python
  отправляется под PyPy 3.10.
