# 1325. 泥泞

[Timus 1325](https://acm.timus.ru/problem.aspx?space=1&num=1325) · 难度 537 · bfs

原题创意来自 Stanislav Vasiliev，由 Stanislav Vasiliev 和 Pavel Egorov 准备，出自 2004 年 3 月 11–16 日在叶卡捷琳堡举行的第八届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

公寓是 N × M 的网格（N, M ≤ 500），由干净格（1）、泥泞格（2）和墙（0）组成。从一个格子可以走到与它有公共
顶点的八个格子中的任意一个，每次在干净格和泥泞格之间移动都要换鞋。求从电脑到冰箱换鞋次数最少、其次格子数
最少的路线。输出它的格子数（两端都算）和换鞋次数；若到不了冰箱，输出 0 0。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

N 和 M，电脑所在的行和列，冰箱所在的行和列，然后是 N 行、每行 M 个数字。左上角的格子是 (1, 1)。

## 输出

路线的格子数和换鞋次数。

## 样例

### 样例 1

输入：

```
3 7
1 1
3 7
1200121
1212020
1112021
```

输出：

```
8 4
```

### 样例 2

输入：

```
5 5
1 5
5 1
00001
00000
00000
00000
20000
```

输出：

```
0 0
```

## 解法

路线的代价是二元组（换鞋次数，步数），先比较换鞋次数。每次换鞋都在干净和泥泞之间切换，所以恰好经过 c 次换鞋
后首次到达的格子都是同一种：c 为偶数时与起点相同，为奇数时是另一种。这把搜索分成了层 c = 0, 1, 2, …。

在第 c 层内，对这种格子做普通的广度优先搜索即可得到最少步数。它的起始格子（种子）是与第 c − 1 层相邻的这种
格子，各自带着首次被碰到时的步数。第 c − 1 层是按步数顺序处理的，所以种子已经按步数排好。搜索逐级进行：在
每个步数上，先接收该步数中尚未到达的种子，再扩展这一级的格子。碰到的另一种格子只在本层第一次碰到时成为第
c + 1 层的种子，而这也正是它的最小步数。第一个到达冰箱的层给出答案。每个格子只确定一次、查看八个邻居，
`O(N · M)`。

注意事项：

- 也可以沿对角线走（测试 05）；
- 换鞋少比路线短更重要：9 格的干净绕行胜过需要换两次鞋的 7 格直路（测试 06）；
- 电脑和冰箱可能在同一个格子：1 0（测试 03）；
- 没有“每层只记一次”的规则，一个格子最多会作为种子入队八次，在 500 × 500 的公寓上占用过多内存。

在 500 个最大 8 × 8 的随机公寓上，与按（换鞋次数，步数）运行的 Dijkstra 算法比较过结果。
