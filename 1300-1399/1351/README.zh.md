# 1351. 好的 Gnusmas 是死的 Gnusmas

[Timus 1351](https://acm.timus.ru/problem.aspx?space=1&num=1351) · 难度 524 · geometry

原题作者 Denis Musin，出自 2005 年 3 月中学生锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

原点处的机枪覆盖两条射线之间的扇形：右边界经过 (X1, Y1)，左边界经过 (X2, Y2)；扇形小于半圈。射程为
D ≤ 30 000。对 N ≤ 30 000 个点中的每一个，若该点在扇形内且距离不超过 D，输出 `YES`，否则输出 `NO`。

时间限制：1 秒。内存限制：64 MB。

## 输入

D、X1、Y1、X2、Y2，然后是 N，再是 N 行点的坐标。所有数都是整数，绝对值不超过 30 000，且没有点位于原点。

## 输出

N 行，每行 `YES` 或 `NO`。

## 样例

### 样例 1

输入：

```
5 1 0 0 1
6
1 1
5 6
3 0
-1 2
0 5
-3 0
```

输出：

```
YES
NO
YES
NO
YES
NO
```

## 解法

扇形从右边界 R 逆时针转到左边界 L。点 P 在扇形内，当且仅当它不在 R 的顺时针一侧，也不在 L 的逆时针一侧：

- cross(R, P) = X1·y − Y1·x ≥ 0；
- cross(P, L) = x·Y2 − y·X2 ≥ 0。

每个条件给出一个半平面，由于扇形小于半圈，两个半平面的交恰好就是扇形，只有一个例外：两条边界在同一条射线上时（宽度为零的扇形），这条射线向后的延长线也能通过两个条件。所以位于边界所在直线上、但在机枪后方的点（叉积为零、点积为负）要单独排除。射程检查为 x² + y² ≤ D²，全部用整数，
无需开方。`O(N)`。

注意事项：

- 边界上和圆周上的点都算在内：样例中的 `3 0` 和 `0 5`；
- 位于某条边界反向射线上的点与该边界的叉积为零；另一个条件会把它排除，但宽度为零的扇形除外，那时只能靠单独的检查（测试 02 和 06）；
- 乘积可达 1.8·10⁹，超出 32 位整数；
- D = 30 000 时，点 (30 000, 1) 恰好超出射程（测试 04）。

在 18 个生成的测试上与用 `atan2` 比较角度的检查结果对比过，并在 300 个随机扇形（包括宽度为零的扇形）上与独立实现对比过。
