# 1351. Хороший гнусмас - мёртвый гнусмас

[Timus 1351](https://acm.timus.ru/problem.aspx?space=1&num=1351) · сложность 518 · geometry

Автор оригинальной задачи — Денис Мусин; чемпионат школьников, март 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Пулемёт в начале координат простреливает сектор между двумя лучами:
правая граница проходит через (X1, Y1), левая — через (X2, Y2); сектор
меньше половины оборота. Дальность стрельбы D ≤ 30 000. Для каждой из
N ≤ 30 000 точек нужно вывести `YES`, если точка лежит в секторе и не
дальше D, и `NO` иначе.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

D, X1, Y1, X2, Y2, затем N, затем N строк с точками. Все числа целые,
по модулю не больше 30 000, и ни одна точка не совпадает с началом
координат.

## Выходные данные

N строк с `YES` или `NO`.

## Примеры

### Пример 1

Ввод:

```
5 1 0 0 1
6
1 1
5 6
3 0
-1 2
0 5
-3 0
```

Вывод:

```
YES
NO
YES
NO
YES
NO
```

## Решение

Сектор идёт против часовой стрелки от правой границы R к левой границе
L. Точка P лежит в нём, если она не по часовой стрелке от R и не против
часовой стрелки от L:

- cross(R, P) = X1·y − Y1·x ≥ 0;
- cross(P, L) = x·Y2 − y·X2 ≥ 0.

Каждое условие задаёт полуплоскость, и раз сектор меньше половины
оборота, две полуплоскости пересекаются ровно по сектору, с одним
исключением: если обе границы лежат на одном луче (сектор нулевой
ширины), обратное продолжение этого луча тоже проходит оба условия.
Поэтому точка на прямой границы, но позади пулемёта, с нулевым
векторным и отрицательным скалярным произведением, отбрасывается
отдельно. Дальность
проверяется как x² + y² ≤ D², всё в целых числах, без корней. `O(N)`.

Тонкие места:

- точки на границах и на окружности считаются: `3 0` и `0 5` в
  примере;
- у точки на луче, противоположном границе, векторное произведение с
  этой границей равно нулю; её отсекает второе условие, кроме сектора
  нулевой ширины, где это делает только отдельная проверка (тесты 02 и
  06);
- произведения доходят до 1,8·10⁹ и помещаются в знаковые 32-битные целые;
- при D = 30 000 точка (30 000, 1) чуть дальше дальности (тест 04).

Ответы сравнивались с проверкой углов через `atan2` на 18
сгенерированных тестах и с независимым решением на 300 случайных
секторах, включая секторы нулевой ширины.

## Особенности языков

- Векторные произведения и квадраты считаются в 64-битных целых в C++,
  Go, Java и Rust, а в Python — в целых произвольной точности.
- Java читает через `StreamTokenizer`; его значения double хранят эти
  целые точно.
