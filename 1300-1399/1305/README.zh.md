# 1305. 凸包

[Timus 1305](https://acm.timus.ru/problem.aspx?space=1&num=1305) · 难度 704 · geometry

原题出自 1998 年 4 月 3–4 日在叶卡捷琳堡举行的第二届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定至多 100 000 个坐标为 0 到 1000 之间整数的点（点可以重复），构造它们的“正则凸包”：包含这些点
的最小凸集，其边界是一条闭折线，每条边或平行于坐标轴，或与坐标轴成 45°。按逆时针输出它的顶点，每个
一次，可从任意顶点开始，且（循环意义下）任意连续三个顶点不共线。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后 N 行，每行一个点。

## 输出

凸包的顶点，每行一个。

## 评测方式

凸包是唯一的，但遍历可以从任意顶点开始。检查程序接受预期顶点序列旋转到任意起点后的结果。

## 样例

### 样例 1

输入：

```
4
3 3
3 1
2 2
4 2
```

输出：

```
3 1
4 2
3 3
2 2
```

## 解法

凸包的边只能朝八个方向之一，所以它的外法向量是 (1, 0)、(1, 1)、(0, 1)、(−1, 1) 及它们的反方向之一。
具有这种边的最小凸集就是每个法向量方向上最紧的半平面的交：

minX ≤ x ≤ maxX，minY ≤ y ≤ maxY，minS ≤ x + y ≤ maxS，minD ≤ x − y ≤ maxD。

扫描一遍点就能求出这八个极值。从底边开始逆时针走，每个顶点都是一条轴向直线与一条斜线的交点，例如
底边两端的 (minS − minY, minY) 和 (maxD + minY, minY)。八个顶点的坐标都是整数。八条直线都碰到真实
的点，所以顶点总按这个顺序出现，但某条边的长度可能为 0，这时它的两个顶点重合。合并相等的相邻顶点
（包括首尾）就够了：剩下的边指向八个方向中互不相同的方向，每条都相对前一条向左转，所以不会有顶点留在
一条直边的中间。当除零条或两条以外的边都消失时，剩下的就是一个点或一条线段。

`O(N)`。

注意事项：

- 单个点即使重复出现也只输出一次（测试 02 和 03）；
- 落在八个方向之一的直线上的点给出只有两个顶点的线段（测试 04 和 05），其他斜率则会扩成真正的多边形
  （测试 06）；
- 可能有几个顶点连续重合，比如样例菱形的每个尖角处，那里平行于坐标轴的边长度为 0（测试 01）。

在 300 组随机点上检查过输出：严格凸且逆时针，边只在八个方向上，每条边都在其最紧的直线上，所有点都在
内部。

## 各语言说明

- C++、Go 和 Java 读入时只保留八个极值；Python 和 Rust 先读入所有点，内存也绰绰有余。
