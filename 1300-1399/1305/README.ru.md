# 1305. Выпуклая оболочка

[Timus 1305](https://acm.timus.ru/problem.aspx?space=1&num=1305) · сложность 708 · geometry

Оригинальная задача — II командный студенческий чемпионат Урала по программированию, Екатеринбург, 3–4 апреля 1998 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны до 100 000 точек с целыми координатами от 0 до 1000 (точки могут
повторяться). Нужно построить их «правильную выпуклую оболочку» —
наименьшее выпуклое множество, содержащее их, граница которого —
замкнутая ломаная, каждое звено которой параллельно оси или наклонено
к осям под 45°. Вывести её вершины против часовой стрелки, каждую по
разу, начиная с любой, так чтобы никакие три подряд идущие (по кругу)
вершины не лежали на одной прямой.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк по точке.

## Выходные данные

Вершины оболочки по одной в строке.

## Проверка

Оболочка единственна, но её обход может начинаться с любой вершины.
Проверяющая программа принимает ожидаемый список вершин, повёрнутый к
любому началу.

## Примеры

### Пример 1

Ввод:

```
4
3 3
3 1
2 2
4 2
```

Вывод:

```
3 1
4 2
3 3
2 2
```

## Решение

Сторона оболочки может идти только в одном из восьми направлений,
поэтому её внешняя нормаль — одна из (1, 0), (1, 1), (0, 1), (−1, 1) и
противоположных им. Наименьшее выпуклое множество с такими сторонами —
пересечение самых тесных полуплоскостей для каждой нормали:

minX ≤ x ≤ maxX, minY ≤ y ≤ maxY, minS ≤ x + y ≤ maxS, minD ≤ x − y ≤ maxD.

Один проход по точкам находит эти восемь экстремумов. Если идти против
часовой стрелки от нижней стороны, каждая вершина — пересечение линии,
параллельной оси, с диагональной, например (minS − minY, minY) и
(maxD + minY, minY) на концах нижней стороны. Все восемь вершин
целочисленные. Каждая из восьми прямых касается настоящей точки,
поэтому вершины всегда идут в этом порядке, но сторона может иметь
нулевую длину, и тогда две её вершины совпадают. Равные соседи (в том
числе через конец) сливаются, и больше чистить ничего не нужно:
оставшиеся стороны идут в разных из восьми направлений, каждая
поворачивает влево относительно предыдущей, так что ни одна вершина не
оказывается посреди прямой стороны. Точка или отрезок остаются, когда
исчезают все стороны, кроме нуля или двух.

`O(N)`.

Тонкие места:

- одна точка, даже повторённая, печатается один раз (тесты 02 и 03);
- точки на одной прямой в одном из восьми направлений дают отрезок с
  двумя вершинами (тесты 04 и 05), а любой другой наклон раздувается в
  настоящий многоугольник (тест 06);
- несколько вершин подряд могут совпадать, как на каждом остром углу
  ромба из примера, где стороны, параллельные осям, имеют длину 0
  (тест 01).

Вывод проверялся на 300 случайных наборах точек: строгая выпуклость и
обход против часовой стрелки, стороны только в восьми направлениях,
каждая сторона на своей самой тесной прямой и все точки внутри.

## Особенности языков

- C++, Go и Java хранят при чтении только восемь экстремумов; Python и
  Rust сначала читают все точки, что тоже легко помещается.
