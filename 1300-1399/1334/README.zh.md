# 1334. 跳棋

[Timus 1334](https://acm.timus.ru/problem.aspx?space=1&num=1334) · 难度 541 · simulation

原题作者 Den Raskovalov，出自 2004 年 10 月 16 日第十届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两名玩家轮流把自己颜色的棋子放在棋盘的深色格上，白方先走，共 32 步。某一步之后若有棋子可以被吃掉，走这一步
的玩家就输了：棋子 A 可以被斜向紧邻、颜色不同的棋子 B 吃掉，前提是这条斜线上紧接在 A 后面的格子空着。输出
输掉的那一步的编号，或 `Draw`。

时间限制：1 秒。内存限制：64 MB。

## 输入

32 行，用国际象棋记法给出格子，如 `a1`：奇数行是白方的着法，偶数行是黑方的。

## 输出

输掉的那一步的编号，或 `Draw`。

输入：

```

a3
a5
a7

b8

```


## 解法

把棋子逐个放到棋盘上。每走一步后，检查每个棋子的四条斜线：若那里的邻子颜色不同，且其后面的格子在棋盘内并且
空着，就可以吃子，刚走的这一步就输了。任何一方的吃子都算，包括刚走棋的一方自己，也包括往回吃。O(1)：最多
32 · 32 · 4 次检查。

注意事项：

- 落点在棋盘外的跳跃不算吃子，例如角上的棋子（测试 03）；
- 走棋的一方可能因为给自己创造了吃子机会而输（测试 05）；
- 第 32 步不可能输：那时所有深色格都已被占，无处落子，所以最后一个可能输的是第 31 步（测试 07）。
