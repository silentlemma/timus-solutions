# 1355. К вопросу о лысине

[Timus 1355](https://acm.timus.ru/problem.aspx?space=1&num=1355) · сложность 212 · number_theory

Автор оригинальной задачи — Александр Бикбаев; чемпионат школьников, март 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Трактиры пронумерованы натуральными числами, и из трактира n можно
перейти только в трактир, номер которого кратен n. Путь начинается в
трактире a и должен закончиться в трактире b, и в каждом трактире на
пути, включая a и b, выпивается кружка эля. Для каждой из T ≤ 20 пар с
1 ≤ a, b ≤ 10⁹ нужно вывести наибольшее число кружек или 0, если до b
не добраться.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

T, затем T строк с a и b.

## Выходные данные

T строк с ответами.

## Проверка

Точные токены ответа. Каждый новый исходник прошёл полные проверки целевой среды, независимые математические сравнения и имеет собственный Accepted с хешем; простые версии сохраняют свои метрики.

## Примеры

### Пример 1

Ввод:

```
5
30 89
2 16
3 243
1 1
2 2
```

Вывод:

```
0
4
5
1
1
```

## Решение

Каждое число на пути делит следующее, поэтому до b можно дойти, только
если a делит b. Тогда каждый шаг умножает номер на множитель больше 1, а
произведение всех множителей равно q = b / a. Чтобы посетить как можно
больше трактиров, каждый множитель должен быть простым числом, так что
число шагов — Ω(q), количество простых множителей q с учётом
кратности. Ответ — 1 + Ω(q), считая сам трактир a.

Ω(q) находится перебором делителей до √q ≤ 31 623.
`O(T · √(b / a))`.

Тонкие места:

- при a = b выпивается одна кружка, а не ноль (пример);
- если b меньше a или не кратно ему, ответ 0 (тест 04);
- T может быть равно 0, и тогда ответы не выводятся (тест 02);
- q = 2²⁹ даёт больше всего шагов, 30 кружек (тест 03).

## Оптимизированные решения

В базовой версии остаётся пробное деление. Быстрая версия на Python берёт НОД частного с фиксированным произведением всех простых до 1000. Этот НОД выявляет малые простые делители без кратностей. Каждый из них удаляем из частного с полной кратностью. Остальные множители больше 1000, поэтому при частном до 10^9 их не более двух. Второе фиксированное произведение включает простые от 1001 до 31623. Составной остаток имеет делитель в этом диапазоне, а простой остаток больше 10^6 взаимно прост с произведением. Поэтому остаток добавляет один или два множителя. Произведения заранее получены решетом и записаны шестнадцатеричными константами.

- `1355_number_theory_math.py`: 0.062 s / 584 KB; база `1355_number_theory.py`: 0.109 s / 392 KB; изменение относительно базы: время -43.1%, память +49.0%.
