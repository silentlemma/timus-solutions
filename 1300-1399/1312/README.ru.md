# 1312. Тарелки

[Timus 1312](https://acm.timus.ru/problem.aspx?space=1&num=1312) · сложность 2925 · geometry

Идея оригинальной задачи — Александр Петров, подготовили Александр Петров и Александр Мироненко; VIII командный студенческий чемпионат Урала по программированию, Екатеринбург, 11–16 марта 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно разместить три круглые тарелки радиусов R1, R2, R3 на
прямоугольном подносе H × W так, чтобы ни одна не выходила за край и
никакие две не перекрывались (касаться можно). Все числа — целые
положительные до 10⁶. Вывести три центра с четырьмя знаками после
точки в порядке радиусов или `0`, если разместить нельзя.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

H, W, R1, R2 и R3.

## Выходные данные

Шесть координат или `0`.

## Проверка

Принимается любое правильное размещение. Проверяющая программа
убеждается, что каждая тарелка лежит на подносе и никакие две не
перекрываются, с допуском 10⁻³ + 10⁻⁹ × (H + W) на округление и
погрешности вычислений с плавающей точкой. Если ожидаемый ответ `0`,
вывод тоже должен быть `0`.

## Примеры

### Пример 1

Ввод:

```
800 400 200 200 50
```

Вывод:

```
200.0000 200.0000 600.0000 200.0000 400.0000 50.0000
```

### Пример 2

Ввод:

```
800 400 200 200 51
```

Вывод:

```
0
```

## Решение

Переберём все шесть порядков трёх тарелок поиском с возвратом.

Для каждой тарелки центры-кандидаты строятся по следующим парам
касаний четырёх стенок и уже поставленных тарелок:

- касание двух стенок: четыре угла (r, r), (H − r, r), …;
- касание стенки и поставленной тарелки радиуса s: на прямой x = r или
  x = H − r (или y = …), на расстоянии r + s от центра той тарелки;
- касание двух поставленных тарелок: пересечение двух окружностей
  вокруг их центров радиусов r + s₁ и r + s₂.

Кандидат остаётся, только если тарелка лежит на подносе и не
перекрывает уже поставленные. Шесть порядков, не больше нескольких
десятков кандидатов на тарелку: весь перебор крошечный. Сравнения
допускают 10⁻⁹ × (H + W) на погрешности вычислений с плавающей точкой
при точных касаниях.

Тонкие места:

- ответ часто существует лишь при точном касании тарелок, как в
  примере; на единицу больше — и его нет (тесты 01 и 02);
- зазоры в углах рядом с тарелкой, заполняющей поднос, вмещают радиус
  около (√2 − 1)/(√2 + 1) от её радиуса: 8 рядом с 50 помещается, 9 —
  нет (тесты 10 и 11);
- тарелка шире подноса сразу делает размещение невозможным (тест 08).

Каждое размещение, выведенное на 250 небольших случайных подносах,
проверялось на правильность, а для каждого подноса с ответом `0`
поиск со штрафной функцией из 60 случайных начал тоже не нашёл
размещения.
