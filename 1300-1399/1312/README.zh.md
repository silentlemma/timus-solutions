# 1312. 盘子

[Timus 1312](https://acm.timus.ru/problem.aspx?space=1&num=1312) · 难度 2925 · geometry

原题创意来自 Alexander Petrov，由 Alexander Petrov 和 Alexander Mironenko 准备，出自 2004 年 3 月 11–16 日在叶卡捷琳堡举行的第八届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把半径为 R1、R2、R3 的三个圆盘放在 H × W 的矩形托盘上，任何一个都不能超出托盘，任意两个都不能重叠
（可以相切）。所有数都是不超过 10⁶ 的正整数。按半径的顺序输出三个圆心，保留四位小数；若无法放下，
输出 `0`。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

H、W、R1、R2 和 R3。

## 输出

六个坐标，或 `0`。

## 评测方式

任何合法的摆放都会被接受。检查程序确认每个盘子都在托盘上、任意两个都不重叠，允许
10⁻³ + 10⁻⁹ × (H + W) 的误差以容纳舍入和浮点计算误差。若预期答案为 `0`，输出也必须是 `0`。

## 样例

### 样例 1

输入：

```
800 400 200 200 50
```

输出：

```
200.0000 200.0000 600.0000 200.0000 400.0000 50.0000
```

### 样例 2

输入：

```
800 400 200 200 51
```

输出：

```
0
```

## 解法

用回溯搜索尝试三个盘子的全部六种顺序。

对每个盘子，根据以下与四面墙及已放好盘子的成对接触生成候选圆心：

- 与两面墙相切：四个角 (r, r)、(H − r, r)……；
- 与一面墙和一个半径为 s 的已放盘子相切：在直线 x = r 或 x = H − r（或 y = …）上，与该盘子圆心
  的距离为 r + s；
- 与两个已放盘子相切：以它们的圆心为心、半径分别为 r + s₁ 和 r + s₂ 的两个圆的交点。

只有当盘子在托盘上且不与已放的盘子重叠时，候选才保留。六种顺序，每个盘子至多几十个候选：整个搜索
非常小。
比较时允许 10⁻⁹ × (H + W) 的误差，以容纳恰好相切时的浮点计算误差。

注意事项：

- 答案往往只有在盘子恰好相切时才存在，比如样例；再大一个单位就没有了（测试 01 和 02）；
- 在填满托盘的盘子旁边，角落空隙能容纳的半径约为它的 (√2 − 1)/(√2 + 1)：50 旁边放得下 8，放不下 9
  （测试 10 和 11）；
- 比托盘还宽的盘子立刻使摆放不可能（测试 08）。

在 250 个小型随机托盘上，输出的每个摆放都检验过合法；对每个答案为 `0` 的托盘，从 60 个随机起点出发
的罚函数下降搜索也没有找到摆放。

## 各语言说明

- C++、Python 和 Rust 按递增顺序尝试各种顺序，Go 和 Java 使用 Heap 算法，因此不同语言可能输出不同的
  合法摆放。
