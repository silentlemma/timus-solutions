# 1398. 象与兵

[Timus 1398](https://acm.timus.ru/problem.aspx?space=1&num=1398) · 难度 856 · games

原题作者 Magaz Asanov，出自 2005 年乌拉尔锦标赛的练习赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

棋盘上有一个白象和一个位于第 2 到 7 横线的黑兵，按通常规则行棋，白方先走。
若黑兵升变成后，而白象下一步不能吃掉它，黑方获胜。若轮到黑方走而兵无路可
走，则为和棋。其余情况白方获胜。求双方最优下的结果。

时间限制：1 秒。内存限制：64 MB。

## 输入

象所在格，然后是兵所在格，均用国际象棋记法。

## 输出

WHITE、DRAW 或 BLACK。

## 样例

### 样例 1

输入:

```
a1
c2
```

输出:

```
WHITE
```

## 解法

黑方每走一步兵就前进，所以一局最多十几步，对 (象, 兵, 轮到谁) 做带记忆的
极小极大搜索可覆盖全部 64·64·2 个状态。白方尝试象沿四条斜线直到棋盘边缘或
兵的每一步，吃掉兵立即获胜。黑方在以下选择中取对白方最不利的结果：

- 向前一步，或从第 7 横线向前两步，走到空格；
- 到达第 1 横线：只有象能看到新后时白方才赢；
- 斜吃白象，此后兵再也挡不住。

若完全无路可走，兵被堵住，为和棋。`O(1)`，至多 8 192 个状态。

注意事项：

- 兵沿棋盘向下走，朝第 1 横线；
- 全部 3 024 个初始局面中只有四个和棋：a2 b2、b1 a3、g1 h3 和 h2 g2（测试
  02 到 05）；
- 黑方只在兵位于第 2 横线时获胜，此时新后落在另一种颜色的格上或象够不着
  （测试 06 和 07）；
- 两步走以及吃掉白象是否算白方输，都从不改变结果，因为白方从不需要送掉象。

其中两个解答在全部 3 024 个初始局面上做了比较，四个和棋也与论坛给出的数目
相符。
