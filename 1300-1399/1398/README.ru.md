# 1398. Слон и пешка

[Timus 1398](https://acm.timus.ru/problem.aspx?space=1&num=1398) · сложность 856 · games

Автор оригинальной задачи — Магаз Асанов; пробный тур чемпионата Урала 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На шахматной доске стоят белый слон и чёрная пешка на горизонтали от 2
до 7, ходы по обычным правилам, белые начинают. Чёрные выигрывают,
если пешка превращается в ферзя, которого слон не может взять следующим
же ходом. Ничья, если ход чёрных, а пешке некуда ходить. Во всех
остальных случаях выигрывают белые. Нужно найти исход при лучшей игре.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Поле слона, затем поле пешки в шахматной нотации.

## Выходные данные

WHITE, DRAW или BLACK.

## Примеры

### Пример 1

Ввод:

```
a1
c2
```

Вывод:

```
WHITE
```

## Решение

Пешка продвигается каждым ходом чёрных, так что партия длится не больше
дюжины ходов, и минимакс по (слон, пешка, чей ход) с запоминанием
охватывает все 64·64·2 состояния. Белые пробуют каждый ход слона по
четырём диагоналям до края доски или пешки, а взятие пешки сразу
выигрывает. Чёрные выбирают худший для белых исход из:

- шага вперёд или двух шагов с седьмой горизонтали на пустые поля;
- выхода на первую горизонталь: белые выигрывают, только если слон
  видит ферзя;
- взятия слона по диагонали, после которого пешку уже не остановить.

Если ходов нет вовсе, пешка заблокирована и это ничья. `O(1)`, не
больше 8 192 состояний.

Подводные камни:

- пешка идёт вниз по доске, к первой горизонтали;
- из всех 3 024 начальных позиций ничейных только четыре: a2 b2, b1 a3,
  g1 h3 и h2 g2 (тесты 02–05);
- чёрные выигрывают только со второй горизонтали, когда ферзь
  появляется на поле другого цвета или вне досягаемости (тесты 06 и 07);
- двойной ход и вопрос, считать ли взятие слона проигрышем белых,
  ни разу не меняют исхода: белым никогда не приходится отдавать слона.

Два решения сравнивались на всех 3 024 начальных позициях, а четыре
ничьи сходятся с числом, названным на форуме.
