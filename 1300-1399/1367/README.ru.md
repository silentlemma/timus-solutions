# 1367. Конфиденциально!

[Timus 1367](https://acm.timus.ru/problem.aspx?space=1&num=1367) · сложность 2783 · dsu

Автор оригинальной задачи — Павел Егоров; IX командный студенческий чемпионат Урала по программированию, Екатеринбург, 19–24 апреля 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Снимок размером не больше 1000 × 1000 клеток показывает перегородки:
`-` — горизонтальная перегородка по середине клетки, `|` —
вертикальная, `+` — крестовина из обеих, а `.` — свободное место.
Секрет `#` — крестовина с объектом в центре, доступным с любой из
четырёх сторон. Агенты ходят где угодно, кроме как сквозь перегородки,
и не выходят за пределы снимка. Два из не более чем 100 секретов
соединены, если агент может пройти от одного к другому. Нужно вывести
матрицу смежности; секреты нумеруются сверху вниз, а в строке — справа
налево.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

H строк по W символов.

## Выходные данные

Матрица из 0 и 1, по строке на каждый ряд.

## Примеры

### Пример 1

Ввод:

```
+------+
|#+-+--|
-++#|..|
##..|#.|
-+--+--+
```

Вывод:

```
10100
01010
10100
01011
00011
```

## Решение

Каждая перегородка идёт по средней линии своей клетки, поэтому четыре
четверти клеток вокруг узла сетки всегда соприкасаются: места, где может
быть агент, — это узлы сетки, их (H + 1) × (W + 1). Каждая клетка
соединяет некоторые из своих четырёх углов:

- `.` соединяет все четыре;
- `-` соединяет два верхних угла и два нижних;
- `|` соединяет два левых угла и два правых;
- `+` и `#` не соединяют ничего.

Система непересекающихся множеств по узлам даёт свободные области.
Секрет касается областей своих четырёх углов. Пример показывает, что
отношение не транзитивно: секрет 4 соединён с 2 и с 5, а 2 и 5 — нет.
Значит, агент не может пройти сквозь секрет с одной его стороны на
другую, и два секрета соединены ровно тогда, когда какой-то угол одного
лежит в той же области, что и какой-то угол другого.
`O(H · W · log(H · W) + K²)` для K секретов.

Тонкие места:

- порядок в строке — справа налево, как указано в условии;
- перегородка, кончающаяся у края клетки, не встречается с
  перегородкой, идущей по середине следующей клетки: в зазор агенты
  проходят (тест 02), а крестовина его закрывает (тест 03);
- секрет — тоже крестовина, поэтому он перекрывает путь между своими
  соседями (тест 07);
- каждый секрет соединён сам с собой;
- без секретов нет строк матрицы (тест 09).

Шесть маленьких схем из условия — тесты 02–07, а модель на узлах
сравнивалась на 1 500 случайных снимках до 7 × 7 с поиском по четырём
четвертям каждой клетки.
