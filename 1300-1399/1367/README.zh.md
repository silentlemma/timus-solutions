# 1367. 绝密

[Timus 1367](https://acm.timus.ru/problem.aspx?space=1&num=1367) · 难度 2783 · dsu

原题作者 Pavel Egorov，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一张至多 1000 × 1000 格的照片显示了隔墙：`-` 是穿过格子中线的水平隔墙，`|` 是竖直隔墙，`+` 是两者交叉，`.` 是
空地。秘密 `#` 是中心有目标物的交叉，目标物从四个方向都能接触到。特工可以去任何地方，但不能穿墙，也不能离开照片
范围。至多 100 个秘密中的两个，若特工能从一个走到另一个，就称它们相连。输出邻接矩阵，秘密从上到下编号，同一行中
从右到左编号。

时间限制：2 秒。内存限制：64 MB。

## 输入

H 行，每行 W 个字符。

## 输出

由 0 和 1 组成的矩阵，每行一行。

## 样例

### 样例 1

输入：

```
+------+
|#+-+--|
-++#|..|
##..|#.|
-+--+--+
```

输出：

```
10100
01010
10100
01011
00011
```

## 解法

每道隔墙都沿所在格子的中线，所以网格每个格点周围的四个四分之一格总是彼此相通：特工可以待的地方就是网格的格点，
共 (H + 1) × (W + 1) 个。每个格子连接它的四个角中的一部分：

- `.` 连接全部四个角；
- `-` 连接上面两个角，以及下面两个角；
- `|` 连接左边两个角，以及右边两个角；
- `+` 和 `#` 不连接任何角。

对格点做并查集就得到各个连通的空地区域。秘密接触它四个角所在的区域。样例说明这个关系不具传递性：秘密 4 与 2、5
都相连，但 2 与 5 不相连。所以特工不能穿过秘密从它的一侧走到另一侧，两个秘密相连当且仅当一个秘密的某个角与另一个
秘密的某个角位于同一区域。K 个秘密时为 `O(H · W · log(H · W) + K²)`。

注意事项：

- 同一行内的顺序是从右到左，输出说明中已明确规定；
- 止于格子边缘的隔墙与穿过下一个格子中线的隔墙并不相接：特工可以从缝隙通过（测试 02），交叉则把缝隙封住
  （测试 03）；
- 秘密本身也是交叉，所以它会挡住相邻格子之间的路（测试 07）；
- 每个秘密都与自身相连；
- 没有秘密时没有矩阵行（测试 09）。

题面中的六个小图就是测试 02 到 07；在 1 500 张最大 7 × 7 的随机照片上，把格点模型与按每格四个四分之一格搜索的
结果比较过。
