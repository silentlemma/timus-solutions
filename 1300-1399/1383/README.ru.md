# 1383. Проекты цветника

[Timus 1383](https://acm.timus.ru/problem.aspx?space=1&num=1383) · сложность 9102 · geometry

Автор оригинальной задачи — Андрей Румянцев; Петрозаводские летние сборы, август 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N ≤ 10 000 проектов, каждый — список точек с целыми координатами, по
модулю не больше 1000, всего 200 000 точек. Два проекта одинаковы, если
один получается из другого перестановкой точек и аффинным
преобразованием, сохраняющим ориентацию: матрицей с положительным
определителем и сдвигом. Нужно вывести классы одинаковых проектов.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем каждый проект: его длина M и M строк с координатами.

## Выходные данные

Число классов, затем каждый класс — список номеров проектов,
заканчивающийся нулём.

## Решение

Дадим каждому проекту канонический ключ, совпадающий у двух проектов
ровно тогда, когда они одинаковы, и сгруппируем проекты по ключу.
Повторяющиеся точки учитываются, так что ключ описывает список с
повторами.

- Все точки совпадают: ключ — просто их число.
- Все точки на одной прямой: аффинное преобразование может растянуть
  прямую и развернуть её, поэтому ставим концы в 0 и 1 и выписываем
  положения всех точек по порядку. Читаем и с другого конца и берём
  меньший список.
- Иначе берём строгую выпуклую оболочку против часовой стрелки;
  аффинное преобразование с положительным определителем переводит её в
  оболочку образа с тем же порядком вершин. Каждая вершина оболочки
  вместе со следующей и предыдущей задаёт систему координат:
  преобразование, переводящее её в (0, 0), следующую в (1, 0) и
  предыдущую в (0, 1), имеет положительный определитель. В этой системе
  все координаты — дроби с одним знаменателем, векторным произведением
  двух рёбер. После деления на общий НОД они становятся однозначными,
  так что у равных множеств точек получаются равные списки целых.
  Сначала сравниваем в каждой системе только оболочку. Затем для
  систем, в которых оболочка выглядит наименьшей, выписываем все точки
  по порядку и берём наименьший список. Так учитываются симметрии
  оболочки.

Классы выводятся по размеру проектов, затем по первому проекту, что
совпадает с примером. `O(S log S + Σ h²)` для S точек и оболочек из h
вершин.

Тонкие места:

- зеркальное отражение — другой проект, ведь у него отрицательный
  определитель (тест 04);
- прямую можно читать в любую сторону (тест 03);
- повторяющиеся точки важны (тесты 02, 03 и 06);
- множество, переходящее в себя при повороте на четверть оборота, даёт
  четыре одинаково наименьшие системы, и все четыре нужно сравнить
  целиком (тест 05 и сгенерированный тест 2).

Классы сравнивались на 350 случайных наборах маленьких проектов и их
образов при случайных целочисленных преобразованиях обоих знаков с
прямым поиском, который пробует перевести один треугольник проекта в
каждый треугольник другого. Тесты проверяются чекером, принимающим
классы в любом порядке.

## Особенности языков

- Java хранит точки, пары в системе координат и ключи в массивах простых
  чисел, упаковывая пару в один long, чтобы сортировке не нужен был
  компаратор: с объектом на каждую точку и ключами из обёрток она
  превышала лимит времени на тесте 8 жюри, а теперь тратит 1,67 с из 2 с.
- Python находит системы координат, не перебирая их все. Он записывает
  оболочку как циклическую последовательность того, что аффинное
  отображение сохраняет у каждых трёх соседних рёбер, — трёх их
  векторных произведений, делённых на их НОД, — и за линейное время
  берёт наименьший циклический сдвиг этой последовательности. Если все
  точки — вершины оболочки, ключом служит сама эта последовательность с
  числом повторов; иначе пробуются только системы координат в наименьших
  сдвигах, у симметричной оболочки отобранные ещё и по центру масс, и
  точки перечисляются в них. Решение работает на CPython; прежняя
  версия, перебиравшая все системы координат, превышала лимит времени на
  тесте 8 жюри даже под PyPy. `O(r · S log S)` для r систем координат,
  оставшихся после этих проверок.
