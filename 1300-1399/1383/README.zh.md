# 1383. 花坛设计方案

[Timus 1383](https://acm.timus.ru/problem.aspx?space=1&num=1383) · 难度 8198 · geometry

原题作者 Andrew Rumyantsev，出自 2005 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N ≤ 10 000 个方案，每个都是一列整点，坐标绝对值不超过 1000，总共不超过 200 000 个点。若一个方案经过重排点的顺序并施加保持
定向的仿射变换（行列式为正的矩阵加上平移）能变成另一个，则两方案相同。输出相同方案构成的各个类。

时间限制：2 秒。内存限制：64 MB。

## 输入

N，然后是每个方案：长度 M 和 M 行坐标。

## 输出

类的个数，然后每个类给出方案编号列表，以 0 结尾。

## 解法

给每个方案一个规范键，两个方案的键相同当且仅当它们相同，再按键分组。重复的点也计入，所以键描述的是带重复的点列。C++、Go、Java 和 Rust 的做法：

- 所有点都相同：键就是点的个数。
- 所有点共线：仿射变换可以拉伸并翻转这条直线，所以把两个端点放到 0 和 1，按顺序列出所有点的位置。也从另一端读一遍，
  取较小的列表。
- 否则取逆时针的严格凸包；行列式为正的仿射变换把它变成像的凸包，且顶点顺序不变。每个凸包顶点和它的下一个、上一个
  顶点确定一个坐标系：把它送到 (0, 0)、下一个送到 (1, 0)、上一个送到 (0, 1) 的变换行列式为正。在这个坐标系中所有
  坐标都是同分母的分数，分母为两条边的叉积。除以公共的最大公约数后表示就唯一了，所以相等的点集得到相等的整数列表。
  先只比较每个坐标系中的凸包；再对凸包看起来最小的那些坐标系，按顺序列出所有点，取最小的列表。这样就处理了凸包的
  对称性。

各类按方案大小、再按第一个方案编号输出，与样例一致。S 个点、凸包 h 个顶点时为 `O(S log S + Σ h²)`。

注意事项：

- 与镜像等价需要反转定向的仿射对称性（测试 04 和 13）；
- 直线可以从任一方向读（测试 03）；
- 重复的点有影响（测试 02、03 和 06）；
- 正方形凸包给出四个同样最小的凸包坐标系；内部点和重复次数仍然重要（测试 05 和生成测试 2）。

在 350 批随机小方案及其在正负两种随机整数变换下的像上，与直接搜索（尝试把一个方案的某个三角形映到另一个方案的每个
三角形）的结果比较过。测试由接受任意类顺序的检查程序评判。

## 各语言说明

- Java 把点、坐标系中的数对和键都存成普通数的数组，并把一个数对打包成一个 long，排序时无需比较器：每个点一个对象、键用包装类型时，它在评测的第 8 个测试上超时，现在用 2 秒中的 1.67 秒。
- Python 不逐一尝试所有坐标系。它把凸包写成一个循环序列，记录每三条相邻边在仿射变换下保持不变的量，即它们的三个叉积除以最大公约数，并在线性时间内取该序列的最小循环移位。若所有点都是凸包顶点，这个带重复次数的序列本身就是键；否则只使用最小移位处的坐标系，对称的凸包再按重心进一步筛选，并在这些坐标系中列出所有点。它在 CPython 上运行；尝试所有坐标系的早期版本即使在 PyPy 下也在评测的第 8 个测试上超时。复杂度为 `O((r + 1) S log S)`，r 为每个方案剩余坐标系数的上界。
