## Задача

Усложнённый вариант задачи 1452. Из N ≤ 10 000 чисел от 1 до 10⁹ нужно
выбрать как можно больше различных значений, которые в каком-то порядке
образуют последовательные члены возрастающей арифметической прогрессии,
и вывести их количество и номера.

Ограничение времени: 1 секунда. Ограничение памяти: 4 МБ.

## Входные данные

N, затем N чисел.

## Выходные данные

Наибольшее количество элементов, затем их номера в любом порядке.

## Примеры

### Пример 1

Ввод:

```
6
7 3 2 3 5 9
```

Вывод:

```
4
4 5 1 6
```

## Решение

В 4 МБ нет места для обычной таблицы по всем парам, поэтому решения
проходят прогрессии напрямую. Каждое различное значение хранится один
раз вместе с первым номером в хеш-таблице с открытой адресацией на 2¹⁵
ячеек, а значения сортируются. Для каждой пары i < j с d = a[j] − a[i]:

- ряд пар обрывается, как только a[i] + best·d выходит за наибольшее
  значение: более длинная прогрессия от a[i] не поместится, а d только
  растёт;
- пара пропускается, если нет a[j] + d — два члена не побьют лучший
  ответ, — или если есть a[i] − d — прогрессия проходится от своего
  наименьшего члена;
- иначе идём по a[j] + d, a[j] + 2d, …, пока значения есть.

Каждая пара соседей в прогрессии даёт не больше одного шага прохода,
так что работа — `O(N²)` обращений к таблице, причём для большинства
пар одно. Суммы выходят за 2³¹, поэтому хранятся в 64 битах.

Подводные камни:

- повторяющиеся значения считаются один раз (пример 1 и тест 04);
- одно повторённое значение даёт один элемент (тест 02);
- в множестве без прогрессий из трёх членов лучший ответ остаётся 2, и
  отсечение там слабее всего (сгенерированный тест 8 — числа, у которых
  в троичной записи только цифры 0 и 1);
- a[j] + d может превысить 2³¹ у верхней границы (тест 05 и
  сгенерированный тест 5).

Ответы сравнивались на 3 000 случайных коротких последовательностях с
перебором всех пар. Тесты проверяются программой, которая требует
ожидаемое количество и проверяет, что номера дают различные значения
одной прогрессии.

## Особенности языков

- В условии разрешены только C, C++ и Pascal, но форма отправки Timus

  Python и Java отправить нельзя.
