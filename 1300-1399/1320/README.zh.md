# 1320. 图的划分

[Timus 1320](https://acm.timus.ru/problem.aspx?space=1&num=1320) · 难度 287 · dsu

原题创意来自 Alexander Petrov，由 Alexander Petrov 和 Leonid Volkov 准备，出自 2004 年 3 月 11–16 日在叶卡捷琳堡举行的第八届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个简单图有偶数条边（2 到 1050 条），顶点编号为 1 到 1000。判断能否把它的边分成若干对相邻的边，即有公共
顶点的两条边。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

若干条边，每条边是一对顶点编号，直到输入结束。没有自环和重边。

## 输出

若这样的划分存在输出 1，否则输出 0。

## 样例

### 样例 1

输入：

```
1 2
2 3
3 1
1 10
```

输出：

```
1
```

### 样例 2

输入：

```
1 2
2 3
3 1
4 10
```

输出：

```
0
```

## 解法

相邻的两条边总在同一个连通分量中，所以每个分量的边数都必须是偶数。这也是充分的：边数为偶数的连通图总能
划分。取一棵深度优先搜索树，从最深的顶点往上处理。在顶点 v 处，把 v 上除通向父亲的边以外仍空闲的边两两
配对；若剩下一条，就与通向父亲的边配对，否则通向父亲的边留给父亲处理。除根以外的每个顶点都不会在自己
下方留下空闲的边，而在根处空闲的边彼此配对，因为边的总数是偶数，这总能做到。

因此答案只需要每个分量的边数。在顶点上建并查集，把边数存在根上：合并两个分量时边数相加，每条边再加一。
`O(M α(V))`。

注意事项：

- 整个图的边数总是偶数，但单个分量可能是奇数：一个三角形加一条单独的边答案为 0（测试 02；测试 06 中
  两个分开的三角形也是如此）；
- 没有给出边数，输入直接结束；
- 共用一个顶点的两个三角形是一个有六条边的分量，可以划分（测试 07）。

在 487 个最多 14 条边的随机图上，与枚举所有配对方式的结果比较过。
