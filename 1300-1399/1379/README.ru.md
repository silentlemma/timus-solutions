# 1379. Транспортировка кружек

[Timus 1379](https://acm.timus.ru/problem.aspx?space=1&num=1379) · сложность 581 · graphs

Автор оригинальной задачи — Павел Егоров; IX командный студенческий чемпионат Урала по программированию, Екатеринбург, 19–24 апреля 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Грузовик массой 3000 кг должен довезти как можно больше кружек, по
100 г каждая и не больше заказанных 10 000 000, от пункта 1 до пункта
N, N ≤ 500, за 24 часа. У каждой двусторонней дороги есть время
проезда в минутах и наибольшая допустимая масса грузовика в граммах.
Нужно вывести наибольшее число кружек.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем M строк: концы дороги, её время и ограничение массы.

## Выходные данные

Число кружек.

## Примеры

### Пример 1

Ввод:

```
3 3
1 2 10 3000220
2 3 20 3000201
1 3 1 3000099
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
1 0
```

Вывод:

```
10000000
```

## Решение

Более тяжёлому грузовику открыто меньше дорог, так что успеть с ростом
груза можно только хуже. Допустимая масса на пути равна ограничению
одной из его дорог, поэтому ищем двоичным поиском среди
ограничений дорог не меньше 3 000 000 г. Для каждого
алгоритм Дейкстры использует лишь дороги, выдерживающие эту массу, и
не хранит времена больше 1440 минут. По наибольшей успевающей массе W
ответ — min(10 000 000, ⌊(W − 3 000 000) / 100⌋).
`O((N + M log M) · log M)`.

Тонкие места:

- при N = 1 кружки уже на месте: все 10 000 000 (пример 2);
- ровно 24 часа, 1440 минут, — ещё успели (тест 03);
- самый быстрый путь может выдерживать меньше, чем более медленный
  (тест 05);
- дорога, выдерживающая ровно пустой грузовик, не позволяет взять ни
  одной кружки (тест 06);
- дороги могут не занимать времени (тест 07).

Ответы сравнивались с перебором всех простых путей на 400 случайных
графах до 6 пунктов.

## Особенности языков

- Python нуждается в PyPy: цепочка коротких дорог внутри полного графа
  дорог длиной в сутки заставляет поиски просматривать много дорог —
  около 0,5 с в CPython и 0,25 с в PyPy.
- Java хранит кучу в массиве простых long, упаковывая время и вершину в
  одно число: очередь с приоритетами из маленьких массивов превышала
  лимит времени на тесте 46 жюри.
