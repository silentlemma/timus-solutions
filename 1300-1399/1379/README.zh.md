# 1379. 运送杯子

[Timus 1379](https://acm.timus.ru/problem.aspx?space=1&num=1379) · 难度 607 · graphs

原题作者 Pavel Egorov，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一辆 3000 kg 的卡车要在 24 小时内把尽可能多的杯子从路口 1 运到路口 N（N ≤ 500），每个杯子重 100 g，最多为订购的
10 000 000 个。每条双向道路有以分钟计的行驶时间和以克计的卡车最大允许质量。输出最多能运的杯子数。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 M，然后是 M 行：道路的两端、时间和质量限制。

## 输出

杯子的数目。

## 样例

### 样例 1

输入：

```
3 3
1 2 10 3000220
2 3 20 3000201
1 3 1 3000099
```

输出：

```
2
```

### 样例 2

输入：

```
1 0
```

输出：

```
10000000
```

## 解法

卡车越重，能走的路就越少，所以随着载重增加，按时到达只会更难。最优的卡车质量恰好等于某条道路的限制，于是在不小于
3 000 000 g 的不同道路限制中二分查找。对每个候选值，Dijkstra 算法只使用能承受该质量的道路，且不保留超过 1440
分钟的时间。设能按时到达的最大质量为 W，答案为 min(10 000 000, ⌊(W − 3 000 000) / 100⌋)。`O(M log M · log M)`。

注意事项：

- N = 1 时杯子已经在会场：全部 10 000 000 个（样例 2）；
- 恰好 24 小时即 1440 分钟仍然来得及（测试 03）；
- 最快的路可能比慢的路承重小（测试 05）；
- 恰好只能承受空卡车的道路一个杯子也运不了（测试 06）；
- 道路可能不花时间（测试 07）。

在 400 个最多 6 个路口的随机图上，与枚举所有简单路径的结果比较过。

## 各语言说明

- Python 需要 PyPy：在由一天长的道路组成的完全图中藏一条短路链，会让每次搜索都扫遍所有道路，CPython 约需 0.5 秒，
  PyPy 约 0.25 秒。
- Java 把堆存成普通 long 的数组，时间和顶点打包在一个数里：用小数组组成的优先队列在评测的第 46 个测试上超时。
