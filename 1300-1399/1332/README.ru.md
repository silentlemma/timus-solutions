# 1332. Джинн-бомбардировки

[Timus 1332](https://acm.timus.ru/problem.aspx?space=1&num=1332) · сложность 612 · geometry

Автор оригинальной задачи — Александр Бикбаев; X командный чемпионат школьников Свердловской области по программированию, 16 октября 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N ≤ 100 городов — круги одного радиуса r с различными целыми центрами,
|x|, |y| ≤ 10 000. Одна бомба разрушает всё на расстоянии R от места
падения, и город считается разрушенным, только если он целиком попадает
в этот круг. Нужно найти наибольшее число городов, которые может
разрушить одна бомба; 1 ≤ R, r ≤ 10 000.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк с центрами, затем R и r.

## Выходные данные

Наибольшее число разрушенных городов.

## Примеры

### Пример 1

Ввод:

```
3
0 0
0 4
4 0
3 1
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
5
0 0
0 1
0 2
0 3
0 4
1 1
```

Вывод:

```
1
```

## Решение

Город целиком попадает в зону, ровно когда его центр отстоит от бомбы
не больше чем на D = R − r. При D < 0 нельзя разрушить ни одного
города, иначе нужно накрыть кругом радиуса D как можно больше центров.

Возьмём лучший круг и будем двигать его, сохраняя все его центры. Его
можно сдвинуть, пока какой-то центр не окажется на границе, а затем
поворачивать вокруг этого центра, пока на границу не выйдет второй, —
если только в круге не один центр. Поэтому достаточно перебрать круги с
центром в центре города и круги радиуса D через два центра на
расстоянии не больше 2D. Таких кругов для пары не больше двух, их центры лежат на
расстоянии √(D² − (d/2)²) по обе стороны от середины пары. Каждое из
не более чем N + N(N − 1) мест проверяется по всем центрам с небольшим допуском для
центров ровно на границе. `O(N³)`.

Тонкие места:

- город должен поместиться целиком, поэтому радиус действия R − r, и при
  R < r ответ 0 (тест 03);
- при R = r радиус действия 0, и разрушается один город (тесты 02 и 04);
- центры ровно на границе засчитываются; для целых точек вроде (3, 4)
  на окружности радиуса 5 в коде используется допуск (тесты 06 и gen3).

Ответы сравнивались с угловым заметанием вокруг каждого центра на 400
случайных небольших примерах.
