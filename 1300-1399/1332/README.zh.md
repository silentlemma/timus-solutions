# 1332. 精灵轰炸

[Timus 1332](https://acm.timus.ru/problem.aspx?space=1&num=1332) · 难度 612 · geometry

原题作者 Alexander Bikbaev，出自 2004 年 10 月 16 日第十届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N ≤ 100 座城市都是半径为 r 的圆，圆心是互不相同的整点，|x|, |y| ≤ 10 000。一枚炸弹摧毁落点距离 R 以内的
一切，城市只有整个落在这个圆内才算被摧毁。求一枚炸弹最多能摧毁多少城市；1 ≤ R, r ≤ 10 000。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后 N 行圆心，然后是 R 和 r。

## 输出

被摧毁城市的最大数量。

## 样例

### 样例 1

输入：

```
3
0 0
0 4
4 0
3 1
```

输出：

```
2
```

### 样例 2

输入：

```
5
0 0
0 1
0 2
0 3
0 4
1 1
```

输出：

```
1
```

## 解法

城市整个落在爆炸范围内，当且仅当其圆心与炸弹的距离不超过 D = R − r。若 D < 0，则一座城市也摧毁不了；否则
任务就是用半径为 D 的圆盖住尽可能多的圆心。

取一个最优的圆，在保持其中所有圆心的前提下移动它。可以把它移到某个圆心落在边界上，再绕这个圆心转动，直到
第二个圆心也到达边界——除非圆里只有一个圆心。因此只需尝试以城市圆心为中心的圆，以及经过距离不超过 2D 的两个
圆心、半径为 D 的圆。每对圆心至多有两个这样的圆，圆心位于这对点中点两侧、距离为 √(D² − (d/2)²) 处。至多 N + N(N − 1) 个
位置中的每一个都对所有圆心检查一遍，并为恰好在边界上的圆心留一点容差。`O(N³)`。

注意事项：

- 城市必须整个放得下，所以作用半径是 R − r，R < r 时答案为 0（测试 03）；
- R = r 时作用半径为 0，每次只摧毁一座城市（测试 02 和 04）；
- 恰好在边界上的圆心也算；对于像半径 5 的圆上 (3, 4) 这样的整点，代码也使用容差（测试 06 和 gen3）。

在 400 个随机小例子上，与绕每个圆心做角度扫描的结果比较过。
