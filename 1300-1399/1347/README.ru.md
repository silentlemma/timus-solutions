# 1347. Блог

[Timus 1347](https://acm.timus.ru/problem.aspx?space=1&num=1347) · сложность 1362 · parsing

Автор оригинальной задачи — Ден Расковалов; чемпионат школьников, март 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N ≤ 100 блоггеров ведут блоги и отмечают тех, кого читают, тегом
`<friend>имя</friend>`. Для каждого блоггера в порядке ввода нужно
вывести три списка, упорядоченных по алфавиту: тех, кого блоггер
упомянул, блоггеров, которые упомянули этого блоггера, и тех, кто в
обоих списках. Блоггер не бывает другом самому себе. Имена
регистрозависимы и состоят из латинских букв и `_`.

Ограничение времени: 0.4 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем для каждого блога имя автора в отдельной строке и сам блог,
который начинается с `<blog>` и заканчивается `</blog>`. В блоге до
1000 строк длиной до 255 символов, а последняя строка ввода может не
заканчиваться переводом строки.

## Выходные данные

Для каждого блоггера — имя и три строки, начинающиеся с `1: `, `2: ` и
`3: `, с именами через запятую и пробел, и пустая строка между
блоггерами.

## Примеры

### Пример 1

Ввод:

```
3
xoposhiy
<blog>
Tomorrow I found <friend>_denplusplus_</friend> to
 be <b>smartest</b> blogger in the net.
Also I received interesting link from
 <friend>strange_human</friend>
</blog>
_denplusplus_
<blog>
Some shit about my work.
</blog>
strange_human
<blog>
<friend>xoposhiy</friend>
<friend>_denplusplus_</friend>
</blog>
```

Вывод:

```
xoposhiy
1: _denplusplus_, strange_human
2: strange_human
3: strange_human

_denplusplus_
1: 
2: strange_human, xoposhiy
3: 

strange_human
1: _denplusplus_, xoposhiy
2: xoposhiy
3: xoposhiy
```

## Решение

Читаем каждый блог от строки с именем до первой строки с `</blog>`,
которая может совпадать со строкой `<blog>`. Каждый `<friend>` до
ближайшего `</friend>` даёт имя: то, что между ними, без других тегов и
с обрезанными пробелами. Множество этих имён без самого блоггера —
список 1. Список 2 для блоггера — множество других блоггеров, в чьём
списке 1 есть это имя, а список 3 — пересечение. Все списки
сортируются по кодам символов, так что `_` идёт после заглавных букв и
перед строчными. Здесь L — длина ввода, S — максимальная длина имени,
K — число разных имён (не менее 2); для хеш-множеств оценки ожидаемые.

Тонкие места:

- упоминания самого себя не считаются (тест 02);
- в теге друга вокруг имени могут быть пробелы или другие теги
  (тест 03);
- весь блог может стоять в одной строке (тест 04);
- люди без блога могут быть друзьями, но никого не упоминают (тест 05);
- `Bob` и `bob` — разные люди, а друг, упомянутый много раз, выводится
  один раз (тест 06);
- пустой список выводится как `1: ` с пробелом.

## Особенности языков

- Все пять решений читают весь ввод сразу и ищут теги как обычный
  текст.
