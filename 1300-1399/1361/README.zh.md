# 1361. 宇宙学对年代学

[Timus 1361](https://acm.timus.ru/problem.aspx?space=1&num=1361) · 难度 1858 · graphs

原题创意来自 Alexander Klepinin，由 Evgeny Krokhalev 准备，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

城市有 N ≤ 100 000 个路口，每个路口的出路按从左到右的顺序列出。两位教授同时从路口 A 和 B 出发。在每个路口，第一
位总是走最左边的路，第二位总是走最右边的路；每条路用时一分钟。两人只能在同一时刻、在路口相遇。输出第一次相遇的
分钟数，若永远不会相遇则输出 −1。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N 行，每行是以 0 结尾的路口列表，从最左边的路到最右边的路。每个列表至少包含一个非零路口编号，允许自环。
所有出路都从路口的同一侧出发。最后一行为 A 和 B。

## 输出

相遇的分钟数，或 −1。

## 样例

### 样例 1

输入：

```
7
2 4 0
3 1 0
4 2 0
5 1 6 3 0
6 4 0
2 5 4 0
6 0
1 7
```

输出：

```
7
```

## 解法

每位司机在每个路口恰有一个去向，所以每条路线都是一段尾巴加一个环。沿路线走到某个路口重复为止。这样，路线上的
每个路口 v 要么只在时刻 r 被经过一次，要么在长度为 L 的环上，于时刻 r, r + L, r + 2L, … 被经过。

对两条路线都经过的每个路口，求两个时刻集合的交：

- 两个单独时刻只有相等时才相交；
- 单独时刻 t 属于 r + kL，当且仅当 t ≥ r 且 L 整除 t − r；
- 两个环要求 t ≡ r₁ (mod L₁) 且 t ≡ r₂ (mod L₂)。由中国剩余定理，只有 gcd(L₁, L₂) 整除 r₂ − r₁ 时才有解。
  先除以最大公约数，再用模逆求出使 t = r₁ + L₁k 满足第二个同余式的最小 k ≥ 0
  （若 L₂ / gcd(L₁, L₂) = 1，则 k = 0）。若 t < r₂，就加上足够多个完整周期 lcm(L₁, L₂)。

答案是所有路口中最小的时刻。`O(M + N log N)`，其中 M 是列表中道路的总数，必须全部读入。

注意事项：

- 逐步模拟太慢：长度为 49 999 和 50 001、共享一个路口的两个环首次相遇可能要等到 2 499 999 998 分钟（生成测试 2），
  超出有符号 32 位整数；
- 两个长度均为 50 000、仅共享一个路口的环，若到达该路口的时间相差一分钟，就永远不会相遇（生成测试 3）；
- 两人可能从同一个路口出发，此时答案为 0（测试 02）；
- 每个列表只有第一条和最后一条路有用，但必须全部读入。

在 3 000 个最多 9 个路口的随机城市上（其中 985 个不会相遇），与足够长、覆盖尾巴和两个环的逐步模拟比较过。
