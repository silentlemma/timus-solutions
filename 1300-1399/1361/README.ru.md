# 1361. Космология против Хронологии

[Timus 1361](https://acm.timus.ru/problem.aspx?space=1&num=1361) · сложность 1858 · graphs

Идея оригинальной задачи — Александр Клепинин, подготовка — Евгений Крохалев; IX командный студенческий чемпионат Урала по программированию, Екатеринбург, 19–24 апреля 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В городе N ≤ 100 000 перекрёстков, и у каждого перекрёстка дороги
перечислены слева направо. Два профессора одновременно выезжают с
перекрёстков A и B. На каждом перекрёстке первый всегда сворачивает на
самую левую дорогу, а второй — на самую правую; каждая дорога занимает
одну минуту. Встретиться можно только на перекрёстке, в один и тот же
момент. Нужно вывести минуту первой встречи или −1, если встречи не
будет.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк — списки перекрёстков, заканчивающиеся нулём, от самой
левой дороги к самой правой. В последней строке A и B.

## Выходные данные

Минута встречи или −1.

## Примеры

### Пример 1

Ввод:

```
7
2 4 0
3 1 0
4 2 0
5 1 6 3 0
6 4 0
2 5 4 0
6 0
1 7
```

Вывод:

```
7
```

## Решение

У каждого водителя ровно один выезд с каждого перекрёстка, поэтому
каждый путь — это хвост, за которым идёт цикл. Проходим каждый путь,
пока перекрёсток не повторится. Тогда каждый перекрёсток v на пути
посещается либо один раз, в момент r, либо в моменты r, r + L, r + 2L,
…, если он лежит на цикле длины L.

Для каждого перекрёстка, который посещают оба пути, пересекаем два
множества моментов:

- два одиночных момента совпадают, только если равны;
- одиночный момент t входит в r + kL, если t ≥ r и L делит t − r;
- для двух циклов нужно t ≡ r₁ (mod L₁) и t ≡ r₂ (mod L₂). По китайской
  теореме об остатках решение есть, только если gcd(L₁, L₂) делит
  r₂ − r₁. Находим наименьшее решение t ≥ r₁; если t < r₂,
  добавляем целое число периодов lcm(L₁, L₂).

Ответ — наименьший момент по всем перекрёсткам. `O(M + N log N)`,
где M — число дорог в списках.

Тонкие места:

- пошаговая симуляция слишком медленна: циклы из 49 999 и 50 001
  перекрёстков с одним общим перекрёстком могут дать первую встречу лишь
  через 2 499 999 998 минут (сгенерированный тест 2), больше, чем вмещают
  знаковые 32-битные числа;
- циклы равной длины с единственным общим перекрёстком не дают встречи,
  если прибытия на него не совпадают по фазе
  (сгенерированный тест 3);
- оба могут стартовать с одного перекрёстка, тогда ответ 0 (тест 02);
- важны только первая и последняя дорога каждого списка, но прочитать
  нужно все.

Ответы сравнивались с пошаговой симуляцией, достаточно долгой, чтобы
покрыть хвосты и оба цикла, на 3 000 случайных городах до 9
перекрёстков, в 985 из которых встречи нет.
