# 1329. 银河历史

[Timus 1329](https://acm.timus.ru/problem.aspx?space=1&num=1329) · 难度 453 · dfs

原题作者 Evgeny Krokhalev，出自 2004 年 10 月 16 日第十届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

最多 40 000 个历史里程碑构成一棵有根树；每个里程碑有一个 0 到 40 000 的编号和其父节点的编号，根的父节点为
−1。回答最多 40 000 个关于两个不同里程碑 A 和 B 的问题：A 是 B 的祖先输出 1，B 是 A 的祖先输出 2，否则输出 0。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后 N 行，每行一个里程碑及其父节点；然后 L 和 L 行 A 与 B。

## 输出

每行一个答案。

## 样例

### 样例 1

输入：

```
10
234 -1
12 234
13 234
14 234
15 234
16 234
17 234
18 234
19 234
233 19
5
234 233
233 12
233 13
233 15
233 19
```

输出：

```
1
0
0
0
2
```

## 解法

对树做深度优先遍历，给每个里程碑记下进入它的时间和离开其整棵子树的时间。A 是 B 的祖先，当且仅当进入 B 时
A 仍然打开：enter[A] ≤ enter[B] < leave[A]。每个问题最多做两次区间检查。`O(N + L)`。

遍历使用显式栈。弹出一个里程碑后，先压入它的补码 ~v，再压入其子节点；补码标记子树遍历完成的时刻。这很
重要，因为树可能是一条 40 000 个里程碑的链，对某些语言的递归来说太深了。

注意事项：

- 里程碑以任意顺序给出，子节点可能在父节点之前（测试 03）；
- 存在里程碑 0，所以离开标记不能用 −v；~v = −v − 1 对 0 也适用（测试 03）；
- 40 000 个节点的链（测试 gen2）；
- 父节点相同的里程碑以及相邻分支上的里程碑之间不是祖先关系（测试 05）。

在 300 棵最多 12 个里程碑的随机树上，与沿父节点向上走的结果比较过。

## 优化解法

新的 C++、Go、Rust 源码保留 DFS 进入/离开区间，每个可能编号只存五个 16 位字段：父亲、首个孩子、下一兄弟、进入和离开时间。编号与时钟均不超过 40000，因此 65535 可作独立哨兵，不与节点零冲突。U=40001 项表共 400010 字节字段。进入节点后走首个孩子；子树结束后走兄弟，否则沿父亲上升直至找到兄弟。每条边最多经过两次，无递归或事件栈。读完全部边再遍历，允许孩子先于父亲出现。初始化 O(U)，遍历及查询 O(N+L)。C++ 用有界 C stdio 输入，Go 用标准句柄缓冲区；Rust 另保留输入文本。保留五个简单文件；Java/Python 复用符合标准的基础版。

通过评测的 Rust 1.75 x64 版本耗时 0.062 秒，基础版为 0.046 秒，内存为 2 116 KB，基础版为 5376 KB。

已通过评测的基础实现 [1329_dfs.java](1329_dfs.java), [1329_dfs.py](1329_dfs.py) 也满足快速版本的要求：在保存的比较快照中，时间和内存均符合前 15% 或前十名的排名收录规则。直接复用这些源文件，不创建相同副本。星号标记尚未达到该语言目标排名的版本。
