# 1329. 银河历史

[Timus 1329](https://acm.timus.ru/problem.aspx?space=1&num=1329) · 难度 453 · dfs

原题作者 Evgeny Krokhalev，出自 2004 年 10 月 16 日第十届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

最多 40 000 个历史里程碑构成一棵有根树；每个里程碑有一个 0 到 40 000 的编号和其父节点的编号，根的父节点为
−1。回答最多 40 000 个关于两个不同里程碑 A 和 B 的问题：A 是 B 的祖先输出 1，B 是 A 的祖先输出 2，否则输出 0。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后 N 行，每行一个里程碑及其父节点；然后 L 和 L 行 A 与 B。

## 输出

每行一个答案。

## 样例

### 样例 1

输入：

```
10
234 -1
12 234
13 234
14 234
15 234
16 234
17 234
18 234
19 234
233 19
5
234 233
233 12
233 13
233 15
233 19
```

输出：

```
1
0
0
0
2
```

## 解法

对树做深度优先遍历，给每个里程碑记下进入它的时间和离开其整棵子树的时间。A 是 B 的祖先，当且仅当进入 B 时
A 仍然打开：enter[A] ≤ enter[B] < leave[A]。每个问题最多做两次区间检查。`O(N + L)`。

遍历使用显式栈。弹出一个里程碑后，先压入它的补码 ~v，再压入其子节点；补码标记子树遍历完成的时刻。这很
重要，因为树可能是一条 40 000 个里程碑的链，对某些语言的递归来说太深了。

注意事项：

- 里程碑以任意顺序给出，子节点可能在父节点之前（测试 03）；
- 存在里程碑 0，所以离开标记不能用 −v；~v = −v − 1 对 0 也适用（测试 03）；
- 40 000 个节点的链（测试 gen2）；
- 父节点相同的里程碑以及相邻分支上的里程碑之间不是祖先关系（测试 05）。

在 300 棵最多 12 个里程碑的随机树上，与沿父节点向上走的结果比较过。
