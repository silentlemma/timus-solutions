# 1314. Погоня в метро

[Timus 1314](https://acm.timus.ru/problem.aspx?space=1&num=1314) · сложность 561 · bfs

Идея оригинальной задачи — Леонид Волков, подготовили Александр Сомов, Леонид Волков и Игорь Гольдберг; VIII командный студенческий чемпионат Урала по программированию, Екатеринбург, 11–16 марта 2004 года.

## Задача

В метро до 50 линий по 2–50 станций; станция — число до 32 767, и
станция, встречающаяся на нескольких линиях (или несколько раз на
одной), — это одно место, где они пересекаются. Беглец входит на первой
из M станций, записанных маяком, и едет к выбранной цели по кратчайшему
маршруту, считая только перегоны. Маяк записывает по порядку все
станции на пути. Нужно вывести по возрастанию все станции, которые
могут быть целью.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N; N строк, в каждой K и затем K станций; затем M и M записанных
станций.

## Выходные данные

Возможные цели по одной в строке.

## Примеры

### Пример 1

Ввод:

```
3
2 61 62
5 75 20 85 50 61
3 10 20 30
3 30 20 85
```

Вывод:

```
50
61
62
85
```

## Решение

Соединим соседние станции каждой линии ребром. Пусть s — первая
записанная станция, e — последняя, а d — расстояние в перегонах.
Беглец едет по кратчайшему маршруту из s в цель t, и запись — его
начало, поэтому:

- запись должна быть путём по рёбрам и сама кратчайшим маршрутом,
  d(s, e) = M − 1;
- t может быть целью ровно тогда, когда кратчайший маршрут из s в t
  проходит через e, то есть d(s, t) = d(s, e) + d(e, t).

Два поиска в ширину, из s и из e, дают все расстояния. `O(V + E)` для
станций и рёбер, каждых не больше 2500; Python тратит `O(V log V + E)`
из-за сортировки целей.

Условие обещает согласованную запись. Если это не так (неизвестная
станция, две несоседние станции или крюк), ни одна цель не подходит, и
ничего не выводится.

Тонкие места:

- сама e тоже цель, ведь поездка может закончиться прямо здесь
  (тест 01);
- при одной записанной станции подходит каждая достижимая из неё
  станция (тесты 02 и 07);
- запись из двух несоседних станций не подходит ни к чему (тест 04);
- станция дальше по линии не подходит, если до неё быстрее добраться
  по короткому пути (тест 05).

Ответы сравнивались с перечислением всех кратчайших маршрутов из s на
400 небольших случайных сетях.

## Особенности языков

- Номера станций прямо служат индексами массивов, поскольку они меньше
  32 768; Python вместо этого хранит словарь.
