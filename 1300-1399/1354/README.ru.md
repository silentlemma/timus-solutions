# 1354. Палиндром. Он же палиндром

[Timus 1354](https://acm.timus.ru/problem.aspx?space=1&num=1354) · сложность 138 · strings

Автор оригинальной задачи — Денис Назаров; чемпионат школьников, март 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано слово S1 длиной до 10 000 латинских букв. Нужно найти самое
короткое непустое слово S2, такое что S1S2 — палиндром, и вывести S1S2.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Слово S1 в одной строке.

## Выходные данные

Слово S1S2.

## Примеры

### Пример 1

Ввод:

```
No
```

Вывод:

```
NoN
```

### Пример 2

Ввод:

```
OnLine
```

Вывод:

```
OnLineniLnO
```

### Пример 3

Ввод:

```
AbabaAab
```

Вывод:

```
AbabaAababA
```

## Решение

Если S1S2 — палиндром и S2 не длиннее S1, то S2 — перевёрнутый
префикс S1, а остаток S1 после этого префикса сам должен быть
палиндромом. Поэтому самое короткое S2 даёт самый длинный
палиндромный суффикс S1, начинающийся с позиции 1 или дальше: S2 должно
быть непустым, так что само S1 не подходит, даже если оно палиндром.

Суффикс X хвоста T = S1 без первой буквы — палиндром ровно тогда, когда
X ещё и префикс reverse(T). Префикс-функция по строке reverse(T) + `#` +
T даёт в последней позиции длину L самого длинного такого суффикса, и
ответ — S1, за которым идут первые |S1| − L букв S1 в обратном порядке.
`O(|S1|)`.

Тонкие места:

- палиндрому всё равно нужна буква: `abcba` даёт `abcbabcba`
  (тест 05);
- одна буква удваивается, ведь пустой хвост — палиндром (тест 04);
- заглавные и строчные буквы различаются (тесты 03 и 07);
- прямая проверка каждого суффикса может занять 10⁸ шагов на длинных
  сериях одной буквы (сгенерированный тест 4).

Ответы сравнивались с прямым перебором длины префикса на 300 случайных
словах до 12 букв, а сгенерированные тесты проверялись на то, что
ответ — палиндром и более короткого дополнения нет.

## Оптимизированные решения

Оптимизированное решение на C++ не строит строку reverse(T) + `#` + T
длиной около 2·|S1| букв. Оно считает префикс-функцию одной лишь
reverse(S1), обращаясь к буквам S1 по обратным индексам, а затем
запускает фазу поиска Кнута — Морриса — Пратта с T в роли текста: длина
совпадения после последней буквы и есть L. Таблица хранится в
`unsigned short`, по два байта на элемент, ведь длина совпадения не
больше 9999 для слова не длиннее 10 000 букв. Вместо `iostream` слово
читается через `scanf` в массив фиксированного размера и печатается
через `fputs`, а добавленные буквы выводятся по одной через `putchar`:
{1354_strings_optimized.cpp}.

Оптимизированное решение на Go не строит строку reverse(T) + `#` + T
длиной около 2·|S1| букв. Оно считает префикс-функцию одной лишь
reverse(S1), обращаясь к буквам S1 по обратным индексам, а затем
запускает фазу поиска Кнута — Морриса — Пратта с T в роли текста: длина
совпадения после последней буквы и есть L. Таблица хранится в `uint16`,
по два байта на элемент, ведь длина совпадения не больше 9999 для слова
не длиннее 10 000 букв, а ответ пишется через `bufio.Writer` без сборки
в строку: {1354_strings_optimized.go}.

Оптимизированное решение на Java не строит строку reverse(T) + `#` + T
длиной около 2·|S1| букв. Оно считает префикс-функцию одной лишь
reverse(S1), обращаясь к буквам S1 по обратным индексам, а затем
запускает фазу поиска Кнута — Морриса — Пратта с T в роли текста: длина
совпадения после последней буквы и есть L. Таблица — это `char[]`, по
два байта на элемент, ведь длина совпадения не больше 9999 для слова не
длиннее 10 000 букв, а ответ пишется через `BufferedWriter` без сборки в
строку: {1354_strings_optimized.java}.

Оптимизированное решение на Python не строит строку reverse(T) + `#` + T
длиной около 2·|S1| букв. Оно считает префикс-функцию одной лишь
reverse(S1), а затем запускает фазу поиска Кнута — Морриса — Пратта с T
в роли текста: длина совпадения после последней буквы и есть L. Решение
работает с `bytes`, а таблица — это `array("H")` с двухбайтовыми
элементами вместо списка целых объектов, ведь длина совпадения не больше
9999 для слова не длиннее 10 000 букв: {1354_strings_optimized.py}.
