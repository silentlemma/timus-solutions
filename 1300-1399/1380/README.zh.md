# 1380. 奥斯塔普的象棋

[Timus 1380](https://acm.timus.ru/problem.aspx?space=1&num=1380) · 难度 3976 · implementation

原题作者 Ivan Popelyshev，出自 2005 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定一个不一定合理的棋局、轮到哪一方走以及至多 60 步棋，逐步检查。棋子按国际象棋规则行走，但没有王车易位、吃过路兵
和兵的升变。若移动的是轮到一方的一枚棋子、走法符合该棋子的走法，且走完后这一方没有任何一个王被攻击，这步棋就合法。
每步之后，若不合法输出 `Incorrect`，否则针对接下来要走的一方输出 `Mate`、`Draw`（逼和）、`Check` 或 `Correct`。
遇到不合法的一步、将死或逼和就停止，然后输出一个空行和棋盘。第一步之前不检查初始局面。

时间限制：1 秒。内存限制：64 MB。

## 输入

64 个数，以空格或换行分隔，从第 8 横排开始：0 表示空格，1 到 6 表示白方的兵、马、象、车、后、王，负数表示黑方。
然后是步数 P（1 ≤ P ≤ 60）、表示轮到哪一方走的 `White` 或 `Black`，以及 P 步形如 `e2-e4` 的着法。
纵线从左到右为 `a` 到 `h`，横排从下到上为 `1` 到 `8`。

## 输出

每个处理的着法输出一个词，然后是一个空行和与输入格式相同的棋盘。不执行不合法的着法；忽略 `Incorrect`、`Mate` 或
`Draw` 之后的着法。

## 解法

在 8 × 8 数组上模拟对局：

- 一枚棋子能到达某格，条件是该格上不是己方棋子且走法符合：马走日字，王走一步，远程棋子沿直线且中间各格为空，兵向前一步
  到空格、从自己的第二横排越过空格走两步到空格，或斜向前一步吃对方棋子；
- 若对方某枚棋子能到达某一方的某个王，这一方就被将军；
- 若棋子属于轮到的一方、能到达目标格，并且走完后这一方没有王被将军，这步就合法；否则撤销这步；
- 合法着法之后检查另一方：只要它有一枚棋子能合法地走到任意一格，就有着可走。无着可走时，被将军为将死，否则为逼和。
  有合法着法时，被将军输出 `Check`，否则输出 `Correct`。

每个局面最多尝试 64 · 64 步，每步对最多 64 个王分别检查最多 64 个攻击者。远程棋子的线路上最多有六个中间格。
宽松的上界为 `O(P · 64⁴)`；对于固定的 8 × 8 棋盘，时间复杂度为 `O(P)`。

题面没有说明一些情况；据该题讨论区的反馈，评测数据遵循以下规则：

- 即使每步都正确，最后一步之后也要输出棋盘（样例 3）；
- 兵在自己的第二横排上无论从何而来都可以走两格，但在第一横排上不行（测试 04 和 05）；
- 王可以被吃掉；没有王的一方永远不会被将军，若再没有其他棋子则无着可走：逼和（测试 06）；
- 一方可以有多个王，一步棋必须让所有的王都安全（测试 10 到 12）。
