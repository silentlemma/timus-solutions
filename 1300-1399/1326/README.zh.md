# 1326. 瓶盖

[Timus 1326](https://acm.timus.ru/problem.aspx?space=1&num=1326) · 难度 391 · bitmask

原题创意来自 Evgeny Kobzev，由 Pavel Atnashev 和 Alexander Mironenko 准备，出自 2004 年 3 月 11–16 日在叶卡捷琳堡举行的第八届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一位收藏者缺少 N ≤ 20 个瓶盖。每个瓶盖都能按自己的价格单独购买，另外还有 M ≤ 100 个成套出售的报价，每套
有一个整套价格。所有价格都是不超过 1000 的正数。求买下给定列表中所有瓶盖的最少花费。

时间限制：3 秒。内存限制：64 MB。

## 输入

N 和 N 个单个价格，然后是 M 和 M 行，每行是套装价格、其中瓶盖的数量和它们的编号。最后一行是需要的瓶盖数量
和它们的编号。

## 输出

最少的总价。

## 样例

### 样例 1

输入：

```
4
10
11
12
13
3
17 2 1 3
25 3 2 3 4
15 2 3 4
3 1 3 4
```

输出：

```
25
```

## 解法

只有需要的瓶盖才重要，所以给它们分配一个最多 20 位的掩码中的各位，每个报价（单个瓶盖或套装）都变成一个价格
和它所含需要瓶盖的掩码。设 cheapest[s] 为至少买下 s 中所有瓶盖的最少花费。必须有某个买下的报价包含 s 中
最低位的瓶盖，买下它之后只剩下 s 中不在该报价里的瓶盖：

cheapest[s] = 对所有包含 s 最低位瓶盖的报价 o，取 price(o) + cheapest[s 去掉 o 的瓶盖] 的最小值。

剩下的集合是更小的数，所以按 s 递增的顺序计算即可，cheapest[全集] 就是答案。同一个报价不会用到两次：剩余
部分已经不含它的任何瓶盖。对 K 个需要的瓶盖，复杂度为 `O(2^K · (N + M))`。

注意事项：

- 套装可能比其中任何一个瓶盖单买还便宜，也可能含有不需要的瓶盖（测试 03 和 04）；
- 需要的瓶盖列表可能为空，此时答案为 0（测试 02）；
- 可能根本没有套装（测试 05）。

在 400 个最多 6 个瓶盖、7 个套装的随机例子上，与尝试所有购买组合的结果比较过。

## 优化解法

Go 和 Rust 先把每个报价限制在所需瓶盖内。如果另一报价以相同或更低的价格覆盖其全部瓶盖，就丢弃该报价。完全相同的报价只保留一个。报价较少的瓶盖分配到低位，因为最低缺失位决定转移列表。逐个购买所需瓶盖的费用不超过 20 000，因此动态规划表可以用 16 位整数存储费用。

已通过评测的基础实现 [1326_bitmask.cpp](1326_bitmask.cpp), [1326_bitmask.java](1326_bitmask.java), [1326_bitmask.py](1326_bitmask.py) 也满足快速版本的要求：在保存的比较快照中，时间和内存均符合前 15% 或前十名的排名收录规则。直接复用这些源文件，不创建相同副本。星号标记尚未达到该语言目标排名的版本。

## 各语言说明

以下说明针对基础实现。

- Python 把出现在最少报价中的瓶盖放在最低位，因为 s 的最低位瓶盖决定要尝试哪些报价；它还会去掉被其他报价
  压制的报价，即另一个报价以不高的价格包含同样多的瓶盖。即便如此，在各套装价值相近时 CPython 仍需约 4 秒，
  所以 Python 解法以 PyPy 3.10 提交，约需 0.2 秒。
