# 1326. Крышки

[Timus 1326](https://acm.timus.ru/problem.aspx?space=1&num=1326) · сложность 391 · bitmask

Идея оригинальной задачи — Евгений Кобзев, подготовили Павел Атнашев и Александр Мироненко; VIII командный студенческий чемпионат Урала по программированию, Екатеринбург, 11–16 марта 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В коллекции не хватает N ≤ 20 крышек. Каждую можно купить отдельно по
своей цене, а ещё есть M ≤ 100 предложений наборов крышек, каждый с
одной ценой за весь набор. Все цены положительные и не больше 1000.
Нужно найти наименьшую сумму, за которую можно купить все крышки из
заданного списка.

Ограничение времени: 3 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N и N цен отдельных крышек, затем M и M строк, в каждой цена набора,
число крышек в нём и их номера. В последней строке число нужных крышек
и их номера.

## Выходные данные

Наименьшая общая сумма.

## Примеры

### Пример 1

Ввод:

```
4
10
11
12
13
3
17 2 1 3
25 3 2 3 4
15 2 3 4
3 1 3 4
```

Вывод:

```
25
```

## Решение

Важны только нужные крышки, поэтому они получают биты маски не длиннее
20 бит, и каждое предложение — отдельная крышка или набор — становится
ценой и маской нужных крышек в нём. Пусть cheapest[s] — наименьшая
сумма, за которую можно купить хотя бы крышки из s. Какое-то купленное
предложение должно содержать младшую крышку из s, и после него остаются
только крышки s, которых в этом предложении нет:

cheapest[s] = min по предложениям o с младшей крышкой s от
price(o) + cheapest[s без крышек o].

Оставшееся множество — меньшее число, так что можно перебирать s по
возрастанию, и cheapest[всё множество] — ответ. Одно предложение не
нужно дважды: в остатке уже нет ни одной из его крышек.
`O(2^K · (N + M))` для K нужных крышек.

Тонкие места:

- набор может быть дешевле даже одной своей крышки и может содержать
  ненужные крышки (тесты 03 и 04);
- список нужных крышек может быть пуст, и тогда ответ 0 (тест 02);
- наборов может не быть вовсе (тест 05).

Ответы сравнивались с перебором всех вариантов покупки на 400 случайных
примерах до 6 крышек и 7 наборов.

## Особенности языков

- Python ставит на младшие биты крышки, которые входят в меньше всего
  предложений, потому что младшая крышка s определяет, какие
  предложения перебирать. Ещё он отбрасывает каждое предложение, которое
  проигрывает другому, где столько же крышек не дороже. Даже так CPython
  тратит около 4 секунд, когда наборы примерно равноценны, поэтому
  решение на Python отправляется под PyPy 3.10, где оно занимает около
  0.2 секунды.
