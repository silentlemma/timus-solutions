# 1323. Одноклассники

[Timus 1323](https://acm.timus.ru/problem.aspx?space=1&num=1323) · сложность 831 · bitmask

Идея оригинальной задачи — Евгений Кобзев, подготовили Павел Атнашев и Александр Мироненко; VIII командный студенческий чемпионат Урала по программированию, Екатеринбург, 11–16 марта 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В классе N ≤ 10 учеников и M пар, которые могут звонить друг другу в
любую сторону, и так новость может дойти до каждого. Сначала новость
знает только староста. Звонок длится ровно минуту, и за минуту каждый,
кто уже знает новость, может сделать один звонок. Нужно составить план
звонков, чтобы все узнали новость ровно по одному разу как можно
раньше.

Ограничение времени: 1.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем M, затем M строк по два имени, затем имя старосты. Имена
различны и состоят не более чем из 20 латинских букв.

## Выходные данные

Число минут, затем для каждой минуты число звонков в ней и сами звонки,
по одному в строке: имя звонящего и имя того, кому звонят. Принимается
любой оптимальный план.

## Проверка

Чекер сравнивает число минут с минимальным, а затем проигрывает план:
каждый звонок должен идти по паре из входа, звонящий должен знать
новость до этой минуты, никто не может звонить дважды за минуту или
получить звонок дважды вообще, и в конце новость должны знать все.

## Примеры

### Пример 1

Ввод:

```
6
7
Tanya Lena
Tanya Katya
Tanya Masha
Lena Natasha
Lena Vitya
Natasha Vitya
Masha Vitya
Tanya
```

Вывод:

```
3
1
Tanya Lena
2
Tanya Masha
Lena Vitya
2
Vitya Natasha
Tanya Katya
```

## Решение

Дальнейшее зависит только от того, кто уже знает новость, поэтому
состояние — множество учеников, их не больше 2¹⁰. Из множества S за
минуту можно добавить любое множество T учеников вне S, если для
каждого ученика из T найдётся свой звонящий в S среди соседей этого
ученика. Это
паросочетание в двудольном графе из T в S, оно ищется дополняющими
путями. Поиск в ширину по множествам, перебирающий все подмножества T
непосвящённых соседей S, доходит до всего класса за наименьшее число
минут. Если запоминать множество и паросочетание, которые привели в
каждое состояние, получается план.

Достигаются только множества со старостой, и подмножества T остальных
дают не больше 3⁹ пар (S, T), каждая с паросочетанием не более чем на
десяти людях.

Тонкие места:

- если ученик один, ответ 0 и групп нет (тест 02);
- план начинается со старосты, имя которого может стоять в паре вторым
  (тест 03);
- пары могут быть записаны в обе стороны (тест 07);
- звонить сначала ближайшим не всегда лучше: ветке, за которой больше
  людей, нужно позвонить раньше (тест 08).

Минимальное время сравнивалось с перебором, в котором каждый знающий
каждую минуту звонит любому соседу или никому, на 300 случайных
классах до 7 учеников, и каждый план проигрывался чекером.
