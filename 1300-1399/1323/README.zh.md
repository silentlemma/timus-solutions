# 1323. 同学

[Timus 1323](https://acm.timus.ru/problem.aspx?space=1&num=1323) · 难度 831 · bitmask

原题创意来自 Evgeny Kobzev，由 Pavel Atnashev 和 Alexander Mironenko 准备，出自 2004 年 3 月 11–16 日在叶卡捷琳堡举行的第八届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个班有 N ≤ 10 名学生，其中有 M 对可以互相打电话（双向均可），消息通过这些电话能传到每个人。起初只有班长
知道消息。一通电话恰好用一分钟，每分钟内每个已经知道消息的人可以打一通电话。请安排通话，使每个人恰好听到
一次消息，并且尽可能早地全部知道。

时间限制：1.5 秒。内存限制：64 MB。

## 输入

N，然后 M，然后 M 行每行两个名字，最后是班长的名字。名字互不相同，由最多 20 个拉丁字母组成。

## 输出

所需的分钟数，然后对每一分钟给出该分钟的通话数和这些通话，每行一通：打电话的人和接电话的人的名字。任何
最优方案都被接受。

## 检查

检查器先把分钟数与最小值比较，然后重放方案：每通电话都必须沿输入中的某一对进行，打电话的人在这一分钟之前
就得知道消息，任何人一分钟内不能打两通电话，也不能被打两次，最后所有人都必须知道消息。

## 样例

### 样例 1

输入：

```
6
7
Tanya Lena
Tanya Katya
Tanya Masha
Lena Natasha
Lena Vitya
Natasha Vitya
Masha Vitya
Tanya
```

输出：

```
3
1
Tanya Lena
2
Tanya Masha
Lena Vitya
2
Vitya Natasha
Tanya Katya
```

## 解法

之后的进展只取决于谁已经知道消息，所以状态是学生的集合，最多 2¹⁰ 个。从集合 S 出发，一分钟内可以加入 S
之外的任意集合 T，只要能给 T 中每个学生在 S 里分配一个不同的、能打给这名学生的呼叫者。这是从 T 到 S 的二分图
匹配，用增广路求得。对集合做广度优先搜索，尝试 S 的未知邻居的每个子集 T，就能以最少的分钟数到达全班。
记下到达每个状态时的前一个集合和匹配，就得到方案。

只会到达包含班长的集合，其余人的子集 T 合计最多 3⁹ 对 (S, T)，每对做一次最多十人的匹配。

注意事项：

- 只有一名学生时答案为 0，没有任何分组（测试 02）；
- 方案从班长开始，而班长的名字可能出现在某一对的第二个位置（测试 03）；
- 同一对可能双向各列一次（测试 07）；
- 先打给最近的人不一定最好：后面人更多的那个分支要先打（测试 08）。

在 300 个最多 7 名学生的随机班级上，把最短时间与另一种搜索比较过：该搜索让每个已知情的人每分钟给任意邻居
打电话或不打；每个方案也都由检查器重放过。
