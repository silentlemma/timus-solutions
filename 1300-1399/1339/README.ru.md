# 1339. Рыцари и леди

[Timus 1339](https://acm.timus.ru/problem.aspx?space=1&num=1339) · сложность 852 · graphs

Автор оригинальной задачи — Магаз Асанов; USU Championship 2004.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В детском саду k мальчиков и k девочек, k ≤ 250 000. Каждому мальчику
нравится не больше одной девочки, и никакая девочка не нравится двум
мальчикам; точно так же каждой девочке нравится не больше одного
мальчика, и никакой мальчик не нравится двум девочкам. Нужно разбить
детей на k пар мальчик–девочка так, чтобы в каждой паре, где есть
влюблённый ребёнок, мальчику нравилась девочка из пары или девочке
нравился мальчик. Принимается любое такое разбиение.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

k, затем для каждого мальчика номер девочки, которая нравится, или 0,
затем для каждой девочки номер мальчика, который нравится, или 0.

## Выходные данные

Для каждого мальчика — номер девочки в паре.

## Проверка

Чекер принимает любое разбиение на пары, соблюдающее правило.

## Примеры

### Пример 1

Ввод:

```
3
3 0 0
0 2 0
```

Вывод:

```
3 2 1
```

## Решение

Проведём стрелку от каждого ребёнка к тому, кто нравится этому ребёнку. Из
каждого ребёнка выходит не больше одной стрелки и, раз никто не
нравится двоим, входит не больше одной, а стрелки всегда соединяют
мальчика и девочку. Значит, стрелки образуют отдельные пути и циклы, в
которых мальчики и девочки чередуются.

Пройдём каждый путь от начала — ребёнка, который никому не нравится, —
и разобьём детей на пары по двое подряд. Каждому на пути, кроме
последнего, нравится следующий, и лишним остаётся только последний
ребёнок пути нечётной длины, которому никто не нравится. Цикл чередует
мальчиков и девочек, поэтому он чётной длины и разбивается целиком. Все
составленные пары соединены стрелкой, так что правило выполнено.
Оставшимся детям никто не нравится, и мальчиков среди них столько же,
сколько девочек, так что их можно разбить как угодно: в такой паре нет
влюблённых. `O(k)`.

Тонкие места:

- путь нечётной длины должен оставлять лишним свой конец, а не начало:
  первому ребёнку пути кто-то нравится, и эти двое должны оказаться в
  одной паре (тест 04);
- один цикл через всех 500 000 детей нельзя обходить рекурсией (тест
  gen2);
- свободных детей нужно ставить в пары мальчик–девочка, и их всегда
  поровну.

Разбиения проверялись на 500 случайных примерах до 10 пар.

## Особенности языков

- CPython тратит около 0.7 секунды на 250 000 пар, что слишком близко к
  пределу в 1 секунду, поэтому решение на Python отправляется под
  PyPy 3.10, где оно занимает около 0.3 секунды.
