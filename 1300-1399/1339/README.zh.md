# 1339. 小朋友

[Timus 1339](https://acm.timus.ru/problem.aspx?space=1&num=1339) · 难度 856 · graphs

原题作者 Magaz Asanov，出自 USU Championship 2004。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

幼儿园里有 k 个男孩和 k 个女孩，k ≤ 250 000。每个男孩最多喜欢一个女孩，且没有女孩被两个男孩喜欢；同样，每个
女孩最多喜欢一个男孩，且没有男孩被两个女孩喜欢。要把孩子们分成 k 对男孩–女孩，使得每一对中只要有孩子喜欢
别人，就要么男孩喜欢这对中的女孩，要么女孩喜欢这对中的男孩。任何这样的分法都被接受。

时间限制：1 秒。内存限制：64 MB。

## 输入

k，然后对每个男孩给出所喜欢女孩的编号或 0，然后对每个女孩给出所喜欢男孩的编号或 0。

## 输出

对每个男孩，给出同组女孩的编号。

## 检查

检查器接受任何满足规则的分组。

## 样例

### 样例 1

输入：

```
3
3 0 0
0 2 0
```

输出：

```
3 2 1
```

## 解法

从每个孩子向其喜欢的孩子画一条箭头。每个孩子最多发出一条箭头，又因为没有人被两人喜欢，最多收到一条箭头，而且
箭头总是连接一个男孩和一个女孩。所以箭头构成若干互不相交的路径和环，男孩女孩交替出现。

从每条路径的起点（没有人喜欢的那个孩子）出发，沿路径两两配对。路径上除最后一个孩子外，每个人都喜欢下一个人，
只有奇数长度路径的最后一个孩子会剩下，而这个孩子不喜欢任何人。环上男孩女孩交替，所以长度为偶数，能完全配对。
到目前为止的每一对都由一条箭头相连，所以满足规则。剩下的孩子都不喜欢任何人，且男孩和女孩一样多，可以任意
配对：这样的一对里没有喜欢别人的孩子。`O(k)`。

注意事项：

- 奇数长度的路径必须剩下终点而不是起点：起点的孩子喜欢某人，必须和那个孩子配对（测试 04）；
- 穿过全部 500 000 个孩子的单个环不能用递归遍历（测试 gen2）；
- 空闲的孩子必须男孩配女孩，而且男孩和女孩的人数总是相等。

在 500 个最多 10 对的随机例子上检查过分组。
