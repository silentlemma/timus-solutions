# 1388. 照片

[Timus 1388](https://acm.timus.ru/problem.aspx?space=1&num=1388) · 难度 13892 · geometry, strings

原题作者 Andrew Rumyantsev，出自 2005 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

河流沿 y = 0 流动，原点处有一座水坝，两岸长着至多 100 000 棵树，坐标为绝
对值不超过 20 000 的整数。从水坝用视角接近 180 度的相机拍照：胶片是一条
直线，胶片前方的树经过原点投影到胶片上，同一射线上被挡住的树看不见。然后
从胶片上剪下只含一岸树木的一段并缩放。求两岸两张相同照片上树的最大数目，
相同指树沿照片的排列一致。

时间限制：1 秒。内存限制：64 MB。

## 输入

若干行树的坐标，以一行 0 0 结束。

## 输出

两张相同照片上树的最大数目。

## 样例

### 样例 1

输入:

```
-1 1
0 1
2 1
3 1
7 2
3 -2
1 -1
0 -1
0 -5
-4 -2
-3 -1
0 0
```

输出:

```
4
```

### 样例 2

输入:

```
0 1
1 1
2 1
-3 -1
-2 -2
-1 -3
0 0
```

输出:

```
3
```

## 解法

树是沿着过原点的直线被看到的，所以只有 c = x / y 有意义，c 相同的树互相
遮挡。胶片正对远离河流的方向时，两岸树在照片上的位置都是 c，照片右侧在
右。转动胶片相当于对 c 做一个保持循环顺序的射影变换，缩放则是系数为正的
仿射变换。沿河方向 c = ∞ 永远不会落在胶片片段内部。

因此一张照片就是某岸不同 c 值排序后的一段连续值，两段匹配当且仅当存在保
持定向的射影变换，把一段的第一个值映到另一段的第一个值，第二个映到第二个，
依此类推。任意三点都能按同样顺序映到任意三点，所以不超过三棵树的段总能匹
配。此后每个点都由前三个点确定，因此每相邻四点的交比必须相同：

(c₃ − c₁)(c₄ − c₂) / ((c₃ − c₂)(c₄ − c₁))。

取 c = p / q 时分母相互抵消，每个因子都是不超过 8·10⁸ 的 2 × 2 行列式，所
以交比是由 64 位整数组成的精确既约分数。给两岸的分数统一编号，答案就是 3
加上两个序列的最长公共子串长度，用其中一个序列的后缀自动机求得；若某岸不
同方向少于四个，答案为两岸数目中较小者，且不超过 3。`O(n log n)`。

注意事项：

- 镜像不算：样例 1 中反向匹配可得 5 棵树，而答案是 4（测试 08 是镜像情
  形）；
- 同一射线上被挡住的树不出现在照片上（测试 07）；
- 射影变换可能把段内某个方向映到沿河方向，使像分成两部分（生成测试 3）；
- 不超过三棵树的段总能匹配，没有树的一岸给出 0（测试 02 到 06）。

在 500 组随机小数据上做了比较，其中一半让一岸包含另一岸的射影像；对照程
序对每对段由前三点构造变换，并在匹配成立时继续延伸。
