# 1388. Фотография

[Timus 1388](https://acm.timus.ru/problem.aspx?space=1&num=1388) · сложность 13892 · geometry, strings

Автор оригинальной задачи — Андрей Румянцев; Петрозаводские летние сборы, август 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Река течёт вдоль y = 0, в начале координат стоит плотина, а по обоим
берегам растут до 100 000 деревьев с целыми координатами не больше
20 000 по модулю. С плотины снимают фотоаппаратом с углом почти
180 градусов: плёнка — прямая, деревья перед ней проецируются на неё
через начало координат, а дерево за другим на том же луче не видно.
Затем из плёнки вырезают кусок с деревьями только одного берега и
масштабируют. Нужно найти наибольшее число деревьев на двух
одинаковых фотографиях разных берегов, где одинаковые — значит с
одинаковым расположением деревьев вдоль фотографии.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Строки с координатами деревьев, в конце строка 0 0.

## Выходные данные

Наибольшее число деревьев на двух одинаковых фотографиях.

## Примеры

### Пример 1

Ввод:

```
-1 1
0 1
2 1
3 1
7 2
3 -2
1 -1
0 -1
0 -5
-4 -2
-3 -1
0 0
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
0 1
1 1
2 1
-3 -1
-2 -2
-1 -3
0 0
```

Вывод:

```
3
```

## Решение

Дерево видно вдоль прямой через начало координат, поэтому важно только
число c = x / y, а деревья с одинаковым c загораживают друг друга. Для
плёнки, повёрнутой прямо от реки, положение дерева на снимке на обоих
берегах равно c, правая сторона снимка справа. Поворот плёнки меняет
положения проективным преобразованием c, сохраняющим циклический
порядок, а масштабирование — аффинное с положительным множителем.
Направление вдоль реки, c = ∞, никогда не попадает внутрь куска плёнки.

Значит, снимок — это отрезок подряд идущих значений в отсортированном
списке различных c одного берега, и два отрезка совпадают ровно тогда,
когда проективное преобразование, сохраняющее ориентацию, переводит
первое значение одного в первое значение другого, второе во второе и
так далее. Любые три точки переводятся в любые три в том же порядке,
так что отрезки до трёх деревьев совпадают всегда. Дальше каждая точка
определяется тремя предыдущими, поэтому должно совпадать двойное
отношение каждых четырёх подряд идущих точек:

(c₃ − c₁)(c₄ − c₂) / ((c₃ − c₂)(c₄ − c₁)).

При c = p / q знаменатели сокращаются, а каждый множитель — определитель
2 × 2 не больше 8·10⁸, так что двойное отношение — точная несократимая
дробь из 64-битных чисел. Пронумеруем дроби обоих берегов; ответ — 3
плюс длина наибольшей общей подстроки двух последовательностей, которая
ищется суффиксным автоматом одной из них. Если на берегу меньше четырёх
направлений, ответ — меньшее из количеств, но не больше 3.
`O(n log n)`.

Подводные камни:

- зеркальное отражение не считается: в примере 1 обратное совпадение
  дало бы 5 деревьев, а ответ 4 (тест 08 — зеркальный случай);
- дерево за другим на том же луче на снимок не попадает (тест 07);
- проективное преобразование может отправить одно из направлений
  отрезка вдоль реки, и тогда образ распадается на две части
  (сгенерированный тест 3);
- отрезки до трёх деревьев совпадают всегда, а берег без деревьев даёт
  0 (тесты 02–06).

Ответы сравнивались на 500 случайных маленьких наборах, в половине из
которых один берег содержит проективный образ другого, с перебором,
который строит преобразование по первым трём точкам каждой пары
отрезков и продолжает совпадение, пока оно выполняется.
