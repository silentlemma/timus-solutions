# 1341. 仪器

[Timus 1341](https://acm.timus.ru/problem.aspx?space=1&num=1341) · 难度 1130 · geometry

原题作者 Stanislav Vasiliev，出自 USU Championship 2004。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一台仪器在距地心 6400 km 的固定距离上飞行。它从纬度 W、经度 L 出发，飞一个“正方形”：向北飞给定的距离，
再向东飞同样的距离，然后向南、向西。它不会到达极点。输出终点的纬度和经度，保留小数点后三位。

时间限制：1 秒。内存限制：64 MB。

## 输入

W、L 和正方形边长（千米），每行一个数。

## 输出

终点的纬度和经度，每行一个。

## 样例

### 样例 1

输入：

```
56.846841
53.36673
1124.427
```

输出：

```
56.847
60.631
```

## 解法

向北和向南沿经线飞行，各使纬度改变同一个角度 a = 边长 / 6400（弧度），所以仪器回到纬度 W。向东和向西沿纬线
飞行：纬度 φ 处的纬线半径为 6400 · cos φ，所以飞行一个边长会使经度转过 a / cos φ。向东的一段沿纬度 W + a 的
纬线飞，向西的一段沿纬度 W 的纬线飞。因此经度改变 a / cos(W + a) − a / cos(W)，换算成度后再调整到
(−180, 180] 内。`O(1)`。

在北半球，向东的一段离极点更近、转过的经度更多，所以仪器停在起点以东；在南半球，向东的一段离赤道更近，仪器
停在起点以西。

注意事项：

- 终点经度可能朝任一方向越过 180° 经线（测试 04 和 05）；
- 从南半球出发会使仪器向西偏移（测试 02）；
- 很小的值不能打印成 `-0.000`。
