# 1389. 道路施工

[Timus 1389](https://acm.timus.ru/problem.aspx?space=1&num=1389) · 难度 556 · dp

原题作者 Dmitry Ivankov 与 Alexander Ipatov，出自 2005 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N ≤ 100 000 座城市由 N − 1 条双向道路连接，任意两城可互达：道路构成一棵
树。要关闭尽量多的道路进行维修，但每座城市至多有一条道路被关闭。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 M = N − 1，然后是 M 条道路，每条为一对城市。

## 输出

关闭道路数 K，然后按输入中的写法给出这 K 条道路。

## 样例

### 样例 1

输入:

```
4 3
1 2
2 3
3 4
```

输出:

```
2
1 2
3 4
```

## 解法

被关闭的道路构成一个匹配，而树的最大匹配可以从叶子开始贪心求得。取一片叶
子和它唯一的邻居：存在某个最大匹配使用它们之间的道路，因为若匹配在该邻居
处使用了别的道路，可以换成这一条。因此从城市 1 做广度优先搜索，按逆序处理
各城市，只要通往父亲的道路两端都还空闲就关闭它。广度优先顺序代替了递归，
否则在 100 000 座城市的路径上会栈溢出。`O(N)`。

注意事项：

- 道路必须按输入中的写法、按输入顺序输出；评测似乎不接受正确答案的其他顺
  序，所以解答先标记选中的道路，再一次性按顺序输出；
- 100 000 座城市的路径对递归来说太深（生成测试 1）；
- 星形只能关闭一条道路（测试 03 和生成测试 3）。

在 300 棵至多 11 座城市的随机树上，与枚举所有道路集合的结果做了比较。测试
由检查程序判定：道路数须等于期望值，每条都按输入写法、按输入顺序给出，且没
有城市连着两条被关闭的道路。
