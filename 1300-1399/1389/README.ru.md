# 1389. Дорожные работы

[Timus 1389](https://acm.timus.ru/problem.aspx?space=1&num=1389) · сложность 556 · dp

Авторы оригинальной задачи — Дмитрий Иванков и Александр Ипатов; Петрозаводские летние сборы, август 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N ≤ 100 000 городов соединены N − 1 двусторонними дорогами так, что из
любого города можно доехать до любого другого: дороги образуют дерево.
Нужно закрыть на ремонт как можно больше дорог, но у каждого города не
больше одной закрытой.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M = N − 1, затем M дорог парами городов.

## Выходные данные

Число K закрытых дорог, затем K дорог в том виде, в каком они были во
входных данных.

## Примеры

### Пример 1

Ввод:

```
4 3
1 2
2 3
3 4
```

Вывод:

```
2
1 2
3 4
```

## Решение

Закрытые дороги образуют паросочетание, а наибольшее паросочетание в
дереве находится жадно от листьев. Возьмём лист и его единственного
соседа: какое-то наибольшее паросочетание содержит дорогу между ними,
потому что паросочетание с другой дорогой у этого соседа можно обменять
на эту. Поэтому обходим города в обратном порядке поиска в ширину от
города 1 и закрываем дорогу к родителю, если оба её конца ещё свободны.
Порядок поиска в ширину заменяет рекурсию, которая переполнила бы стек
на пути из 100 000 городов. `O(N)`.

Подводные камни:

- дороги выводятся так, как записаны во входных данных, и в порядке
  ввода; другой порядок верного ответа, судя по всему, не принимается,
  поэтому решения отмечают выбранные дороги и выводят их за один проход;
- путь из 100 000 городов слишком глубок для рекурсии (сгенерированный
  тест 1);
- в звезде можно закрыть только одну дорогу (тест 03 и сгенерированный
  тест 3).

Ответы сравнивались на 300 случайных деревьях до 11 городов с перебором
всех наборов дорог. Тесты проверяются программой, которая требует
ожидаемое число дорог, каждая записана как во входных данных, в порядке
ввода, и ни у одного города нет двух таких дорог.
