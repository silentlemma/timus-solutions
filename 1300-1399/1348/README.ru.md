# 1348. Пусти козла в огород 2

[Timus 1348](https://acm.timus.ru/problem.aspx?space=1&num=1348) · сложность 179 · geometry

Автор оригинальной задачи — Павел Егоров; чемпионат школьников, март 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Козёл привязан к точке C верёвкой длины L, так что достаёт всё, что не
дальше L от C. Грядка ананасов — отрезок AB. Нужно найти, на сколько
нужно удлинить верёвку, чтобы достать хотя бы один ананас, и на сколько
— чтобы достать все, с двумя знаками после точки. Все числа целые,
L ≥ 0, а координаты по модулю не больше 10 000.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Координаты A, B и C и длина L.

## Выходные данные

Два удлинения, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
8 -6 8 6
0 0 7
```

Вывод:

```
1.00
3.00
```

## Решение

Ближайшая точка грядки — проекция C на прямую AB, перенесённая в A или
B, если она выпала за отрезок. Самая дальняя точка отрезка от любой
точки — один из его концов. Значит, ответы — max(0, d_ближ − L) и
max(0, max(|CA|, |CB|) − L). Проекция использует
t = (C − A) · (B − A) / |B − A|², ограниченное отрезком от 0 до 1, а для
грядки из одной точки, A = B, берётся t = 0. `O(1)`.

Тонкие места:

- грядка может быть одной точкой (тесты 02 и 08);
- если C лежит на прямой грядки за концом, ближайшая точка — этот конец,
  а не проекция (тест 04);
- если верёвки уже хватает, нужно 0, а не отрицательное число
  (тест 05).
