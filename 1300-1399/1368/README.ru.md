# 1368. Пусти козла в огород 3

[Timus 1368](https://acm.timus.ru/problem.aspx?space=1&num=1368) · сложность 2507 · geometry

Автор оригинальной задачи — Алексей Лахтин; IX командный студенческий чемпионат Урала по программированию, Екатеринбург, 19–24 апреля 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Козёл стоит в клетке (0, 0) бесконечного поля и ходит только вверх,
вниз, влево и вправо. Секции забора ставятся в отдельные клетки. Нужно
запереть козла на участке ровно из K клеток, 1 ≤ K ≤ 10⁶, поставив как
можно меньше секций, и вывести их число и сами секции в порядке обхода
участка.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число K.

## Выходные данные

N, затем N строк с клетками секций в порядке обхода участка.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
7
-1 0
0 1
1 2
2 1
2 0
1 -1
0 -1
```

## Решение

Забор участка R обязан занимать каждую клетку, соседнюю с R по
стороне, и этих клеток уже достаточно, чтобы R запереть, поэтому нужно
выбрать K связных клеток с наименьшим числом соседей по стороне. Лучшие
фигуры — ромбы, и ни у каких K клеток нет меньше ⌈√(8K − 4)⌉ + 2
соседей: 4 для одной клетки, 4r + 4 для ромба радиуса r из
2r² + 2r + 1 клеток.

Строим участок из рядов. Если концы соседних рядов сдвигаются не больше
чем на клетку, забор — это по клетке слева и справа от каждого ряда и
клетки под первым и над последним рядом: для H рядов в нём 2H + w₁ + w_H
клеток. Ромб растёт на клетку с каждого края за ряд до середины, а
потом сужается. Фиксируем размер забора равным нижней оценке и
перебираем ширины первого и последнего рядов 1 или 2. Это задаёт H.
Самые широкие ряды — min(w₁ + 2i, w_H + 2(H − 1 − i)). Ограничиваем их
сверху наименьшим уровнем, при котором помещается K клеток (двоичный
поиск), а затем убираем по клетке из некоторых внутренних рядов этого
уровня, пока не останется ровно K. Если ни один вариант не подошёл,
размер забора растёт на единицу; для всех проверенных K достигалась
сама нижняя оценка.

Затем расставляем ряды, при сужении сдвигая сначала левый конец, и
выписываем забор вокруг участка: вдоль низа, вверх по правой стороне,
обратно по верху и вниз по левой стороне. Соседние секции касаются
стороной или углом. `O(√K · log K)`.

Тонкие места:

- забор может касаться только углами, ведь по диагонали козёл не
  ходит; забор, касающийся сторонами, требует гораздо больше секций;
- квадрат — не лучшая фигура: 1 000 000 клеток требуют 2 831 секцию
  против 4 000 вокруг квадрата;
- порядок вывода важен: клетки идут вокруг участка.

Построение проверялось для всех K до 3 000 и для больших K заливкой
участка из (0, 0); оценка сравнивалась со всеми полимино до 14 клеток.
Тесты проверяются чекером, который делает ту же заливку и проверяет
размер и порядок.
