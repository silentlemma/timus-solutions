# 1368. 放山羊进菜园 3

[Timus 1368](https://acm.timus.ru/problem.aspx?space=1&num=1368) · 难度 2449 · geometry

原题作者 Alexey Lakhtin，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一只山羊站在无限网格的格子 (0, 0) 中，只能上下左右移动。栅栏段可以放在单独的格子里。要用尽可能少的栅栏段把山羊
圈在恰好 K 个格子（1 ≤ K ≤ 10⁶）的区域里，输出栅栏段的数目以及按绕区域一周的顺序排列的各段。

时间限制：1 秒。内存限制：64 MB。

## 输入

一个数 K。

## 输出

N，然后 N 行按绕区域一周的顺序给出栅栏格子坐标。

## 样例

### 样例 1

输入：

```
3
```

输出：

```
7
-1 0
0 1
1 2
2 1
2 0
1 -1
0 -1
```

## 解法

区域 R 的栅栏必须占据与 R 有公共边的每个格子，而这些格子已经足以把 R 圈住，所以问题就是选出 K 个连通的格子，
使与它们有公共边的格子最少。最优形状是菱形或其变形，任何 K 个格子都至少有 ⌈√(8K − 4)⌉ + 2 个这样的邻格：一个格子时
为 4，半径为 r、含 2r² + 2r + 1 个格子的菱形时为 4r + 4。

按行构造区域。若相邻两行的端点最多移动一格，栅栏就是每行左右各一格，再加上第一行下方和最后一行上方的格子：H 行时
共 2H + w₁ + w_H 格。菱形在中间之前每行两端各扩一格，之后收缩。把栅栏大小定为下界，第一行和最后一行的宽度取 1 或
2，这就确定了 H。最宽的各行为 min(w₁ + 2i, w_H + 2(H − 1 − i))。用二分查找求出仍能容纳 K 格的最低封顶高度，把各行
截到这个高度，再从封顶高度上的若干内部行各去掉一格，直到恰好剩下 K 格。若没有可行的选择，栅栏大小加一；对所有试过
的 K，都恰好达到了下界。

然后摆放各行，行变窄时先移动左端，再绕区域一周列出栅栏：沿底部、沿右侧向上、沿顶部返回、沿左侧向下。相邻的栅栏段
以边或角相接。`O(√K · log K)`。

注意事项：

- 栅栏只需以角相接，因为山羊不能斜着走；以边相接的栅栏需要多得多的段；
- 正方形不是最好的形状：1 000 000 个格子需要 2 831 段，而围正方形需要 4 000 段；
- 输出顺序很重要：各格要绕区域一周排列。

构造对所有不超过 3 000 的 K 以及一些大的 K，用从 (0, 0) 出发的填充检查过；下界与 14 格以内的所有多联骨牌比较过。
测试由检查程序评判，它做同样的填充并检查数目和顺序。
