# 1330. Интервалы

[Timus 1330](https://acm.timus.ru/problem.aspx?space=1&num=1330) · сложность 95 · prefix_sums

Автор оригинальной задачи — Ден Расковалов; X командный чемпионат школьников Свердловской области по программированию, 16 октября 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N ≤ 10 000 датчиков дают целые показания от −10 000 до 10 000. Нужно
ответить не более чем на 100 000 вопросов: сумма показаний датчиков с i-го по j-й,
i ≤ j.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N показаний, затем Q и Q пар i, j.

## Выходные данные

По одной сумме в строке.

## Примеры

### Пример 1

Ввод:

```
5
1
2
3
-1
4
3
1 5
4 4
1 4
```

Вывод:

```
9
-1
5
```

## Решение

Храним before[i] — сумму первых i показаний, before[0] = 0. Сумма с i
по j — это before[j] − before[i − 1], одно вычитание на вопрос.
`O(N + Q)`.

Тонкие места:

- суммы лежат между −10⁸ и 10⁸, что помещается в 32-битное целое;
- вопросов может не быть вовсе (тест 03);
- при 100 000 вопросах ввод и вывод нужно читать и писать большими
  кусками, чтобы уложиться в 0.5 секунды.

## Оптимизированные решения

`1330_prefix_sums_optimized.py`. Сохраняются префиксные суммы и ответ before[j]-before[i-1] для [i,j]. Блоки по 65536 байтов разбираются split/map с переносом частичного числа вместо отдельного генератора для каждой строки. Префиксы хранятся в списке Python, выводятся пачки не более 4096 ответов. Для N значений и Q запросов время O(N+Q), состояние O(N) плюс ограниченные буферы; список запросов и весь вывод не сохраняются.

Accepted точного исходника CPython 3.12 №11326660: 0.156 с / 2648 КБ. Сохранённая выборка актуальных компиляторов от 2026-11-20: место по времени 5/34, по памяти 5/34. Обе обязательные метрики проходят строгий критерий первых десяти мест или топ 15%, процентная граница округляется вверх. Звёздочка относится к отдельной цели Python — первому месту по обеим метрикам.

Прежняя документированная оптимизированная посылка №11303743 (Python 3.12 x64) имела 0.203 с / 1440 КБ. У текущего запуска CPython 3.12 зафиксированы меньшее время и большая память. Это разные парные измерения судьи; сравнение включает выбор интерпретатора и разброс запусков. Сохранённая простая версия быстрее: 0.125 с; эта версия выбирает меньшую память.

- `1330_prefix_sums_optimized.py`: 0.156 s / 2648 KB; сохранённая учебная база `1330_prefix_sums.py` (Python 3.12 x64): 0.125 s / 27608 KB.

Оптимизированные решения на C++ и Java хранят префиксные суммы
32-битными целыми, чего хватает для сумм от −10⁸ до 10⁸. C++ разбирает
числа и записывает ответы вручную через буферы по 4 КБ и хранит суммы в
статическом массиве: 0.015 с вместо 0.125 с и 132 КБ вместо 2784 КБ.

Оптимизированное решение на Java читает ввод блоками по 4 КБ и разбирает его вручную вместо `StreamTokenizer`, а ответы пишет в байтовый буфер на 4 КБ вместо строк: 0.125 с вместо 0.156 с и 452 КБ вместо 7324 КБ.

## Особенности языков

- Простое решение на Java читает через `StreamTokenizer`, который
  понимает отрицательные показания, и собирает ответы в одну строку.
