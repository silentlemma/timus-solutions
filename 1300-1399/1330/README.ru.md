# 1330. Интервалы

[Timus 1330](https://acm.timus.ru/problem.aspx?space=1&num=1330) · сложность 96 · prefix_sums

Автор оригинальной задачи — Ден Расковалов; X командный чемпионат школьников Свердловской области по программированию, 16 октября 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N ≤ 10 000 датчиков дают целые показания от −10 000 до 10 000. Нужно
ответить на 100 000 вопросов: сумма показаний датчиков с i-го по j-й,
i ≤ j.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N показаний, затем Q и Q пар i, j.

## Выходные данные

По одной сумме в строке.

## Примеры

### Пример 1

Ввод:

```
5
1
2
3
-1
4
3
1 5
4 4
1 4
```

Вывод:

```
9
-1
5
```

## Решение

Храним before[i] — сумму первых i показаний, before[0] = 0. Сумма с i
по j — это before[j] − before[i − 1], одно вычитание на вопрос.
`O(N + Q)`.

Тонкие места:

- суммы лежат между −10⁸ и 10⁸, что помещается в 32-битное целое;
- вопросов может не быть вовсе (тест 03);
- при 100 000 вопросах ввод и вывод нужно читать и писать большими
  кусками, чтобы уложиться в 0.5 секунды.

## Особенности языков

- Java читает ввод через собственный байтовый буфер и собирает ответы в
  одну строку.
