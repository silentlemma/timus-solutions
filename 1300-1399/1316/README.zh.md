# 1316. 电子拍卖

[Timus 1316](https://acm.timus.ru/problem.aspx?space=1&num=1316) · 难度 427 · fenwick

原题创意来自 Pavel Atnashev，由 Pavel Atnashev 和 Pavel Egorov 准备，出自 2004 年 3 月 11–16 日在叶卡捷琳堡举行的第八届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

交易所的日志至多有 100 000 条操作：

- `BID X`：一位买家愿以价格 X 买一件；
- `DEL X`：撤回一份价格为 X 的出价；
- `SALE X K`：以价格 X 出售 K 件，前 K 份出价不低于 X 的出价各得一件；其余的回炉。

出价在买到之后依然有效，直到被撤回。价格在 0.01 到 10 000.00 之间，最多两位小数，K ≤ 100 000，
日志以 `QUIT` 结束。交易所每卖出一件赚 0.01。输出总收入。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

日志，每行一条操作，以 `QUIT` 结束。

## 输出

交易所的收入，保留两位小数。

## 样例

### 样例 1

输入：

```
BID 0.01
BID 10000
BID 5000
BID 5000
SALE 7945.14 3
DEL 5000
SALE 3487.45 3
SALE 0.01 3
QUIT
```

输出：

```
0.06
```

## 解法

一次出售卖出 min(K, 价格不低于 X 的有效出价数) 件，所以只需要按价格统计有效出价，并支持查询“价格不低于
X 的有多少”。

价格精确地读成整数分，从 1 到 1 000 000。把分从最高价往下编号，“不低于 X”就成了一个前缀，用树状数组
保存计数。出价在其价格处加 1，撤回减 1，出售读取一个前缀和。N 次操作、P 个价格索引的复杂度为 `O(P + N log P)`。

卖出的件数用整数计数，而每件赚一分钱，所以把这个数除以 100 并保留两位小数就是答案。

注意事项：

- 恰好为 X 的出价可以买到（测试 04），而且出价在被撤回之前，对之后的出售依然有效（测试 07）；
- 50 000 份出价和 49 999 次各 100 000 件的出售会卖出 2.49995 · 10⁹ 件，超过 2³¹，有符号 32 位计数器会溢出
  （测试 gen5）；
- 价格可能只有一位小数或没有小数，如 `5.5` 或 `10000`（测试 04 和 05）；
- 用浮点计算 0.01 · count 这样的收入可能少打印一分钱，整数分可以避免。

在 300 份随机日志上与直接统计所有有效出价的结果比较过。

## 各语言说明

- Python 只给日志中出现的价格编号，树因此很小；其他语言直接按全部一百万个价格建索引。
