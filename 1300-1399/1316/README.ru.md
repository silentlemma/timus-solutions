# 1316. Биржа

## Задача

Журнал биржи содержит до 100 000 операций:

- `BID X`: покупатель готов купить одну болванку по цене X;
- `DEL X`: заявка по цене X снимается;
- `SALE X K`: выставлено K болванок по цене X, и первые K заявок с ценой
  X или больше получают по одной; остальные идут на переплавку.

Заявка остаётся в силе и после покупки, пока её не снимут. Цены от
0.01 до 10 000.00, не больше двух знаков после точки, K ≤ 100 000,
журнал заканчивается словом `QUIT`. Биржа получает 0.01 с каждой
проданной болванки. Нужно вывести её итоговую прибыль.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Журнал по операции в строке, заканчивающийся `QUIT`.

## Выходные данные

Прибыль биржи с двумя знаками после точки.

## Примеры

### Пример 1

Ввод:

```
BID 0.01
BID 10000
BID 5000
BID 5000
SALE 7945.14 3
DEL 5000
SALE 3487.45 3
SALE 0.01 3
QUIT
```

Вывод:

```
0.06
```

## Решение

Продажа продаёт min(K, число действующих заявок по X или дороже)
болванок, так что нужен лишь счётчик действующих заявок по ценам с
запросом «сколько по X или дороже».

Цены читаются точно, как целые копейки, от 1 до 1 000 000. Если
нумеровать копейки от самой высокой цены вниз, «X или дороже»
становится префиксом, и счётчики хранит дерево Фенвика. Заявка
прибавляет 1 к своей цене, снятие вычитает 1, а продажа читает
префиксную сумму. `O(N log P)`.

Проданные болванки считаются в 64-битном целом, и, поскольку каждая
приносит одну копейку, это число, записанное с двумя знаками после
точки, и есть ответ.

Тонкие места:

- заявка ровно по X покупает (тест 04), и заявка покупает на каждой
  следующей продаже, пока её не снимут (тест 07);
- 50 000 заявок и 50 000 продаж по 100 000 болванок дают 2.5 · 10⁹
  проданных болванок, больше 2³¹, так что 32-битные счётчики
  переполняются (тест gen5);
- цены могут иметь один знак после точки или ни одного, например `5.5`
  или `10000` (тесты 04 и 05);
- вещественная прибыль вроде 0.01 · count может выйти на копейку
  меньше, чего целые копейки избегают.

Итоги сравнивались с прямым подсчётом по всем действующим заявкам на
300 случайных журналах.

## Особенности языков

- Python нумерует только встречающиеся в журнале цены, что делает
  дерево маленьким; остальные языки индексируют все миллион цен
  напрямую.
