## Задача

Покоящуюся бочку нужно спустить на n метров влево и m метров вниз,
1 ≤ n, m ≤ 50, по цепочке досок. У каждой доски целые концы, нижний
конец строго ниже верхнего и не правее его. Трения нет, g = 10, а на
каждом стыке бочка сохраняет величину скорости и лишь меняет
направление. Нужно вывести наименьшее время спуска с ошибкой не больше
10⁻³.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Числа n и m.

## Выходные данные

Наименьшее время в секундах.

## Примеры

### Пример 1

Ввод:

```
2 2
```

Вывод:

```
0.8614
```

## Решение

Без трения энергия сохраняется: на глубине d бочка движется со
скоростью v(d) = √(2·g·d), каким бы путём она туда ни попала. Вдоль
одной доски ускорение постоянно, поэтому бочка проходит длину L со
средней из скоростей на концах, и доска занимает 2L / (v₁ + v₂).

Значит, важны только точки решётки. Доска идёт из (x, e) в (y, d) с
y ≥ x и d > e, где x отсчитывается влево, а глубина вниз, и
best[d][y] = min(best[e][x] + 2L / (v(e) + v(d))). Ответ — best[m][n].
Переходов около n² · m² / 4, 1,6 миллиона при n = m = 50.
`O(n² · m²)`.

Тонкие места:

- первая доска начинается со скорости 0, и формула 2L / (0 + v) это
  учитывает;
- доска не может идти вправо или горизонтально, но может быть
  вертикальной;
- на пологом склоне бочка медленная, и ответ бывает большим: 22,3652
  при n = 50, m = 1 (тест 04).

При n = m = 1 единственная доска даёт 2√2 / √20 = 0,6325 (тест 02), что
совпадает с подсчётом по формуле вручную.

## Особенности языков

- Python один раз строит времена всех досок между двумя строками и
  обновляет строку целиком через `map(min, …)`, так что самый большой
  случай занимает около четверти секунды.
