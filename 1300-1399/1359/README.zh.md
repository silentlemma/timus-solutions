# 1359. 工地

[Timus 1359](https://acm.timus.ru/problem.aspx?space=1&num=1359) · 难度 1162 · dp

原题作者 Den Raskovalov（题面 Aleksandr Bikbaev），出自 2005 年 3 月中学生锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一只静止的桶要沿一串木板向左移动 n 米、向下移动 m 米，1 ≤ n, m ≤ 50。每块木板的两端都是整点，下端严格低于上端，
且不在上端的右边。没有摩擦，g = 10，在每个接头处桶保持速度大小，只改变方向。输出下滑的最短时间，误差不超过 10⁻³。

时间限制：1 秒。内存限制：64 MB。

## 输入

两个数 n 和 m。

## 输出

最短时间，单位为秒。

## 样例

### 样例 1

输入：

```
2 2
```

输出：

```
0.8614
```

## 解法

没有摩擦时能量守恒：在深度 d 处桶的速度为 v(d) = √(2·g·d)，与它走过的路径无关。沿一块木板的加速度不变，所以桶以
两端速度的平均值走完长度 L，这块木板用时 2L / (v₁ + v₂)。

因此只需考虑格点。木板从 (x, e) 到 (y, d)，其中 y ≥ x 且 d > e，x 向左计，深度向下计，
best[d][y] = min(best[e][x] + 2L / (v(e) + v(d)))。答案为 best[m][n]。转移约有 n² · m² / 4 个，n = m = 50 时为
160 万个。`O(n² · m²)`。

注意事项：

- 第一块木板从速度 0 开始，公式 2L / (0 + v) 已经包含这种情况；
- 木板不能向右或水平，但可以竖直；
- 坡度平缓时桶很慢，答案可能很大：n = 50、m = 1 时为 22.3652（测试 04）。

n = m = 1 时只有一块木板，用时 2√2 / √20 = 0.6325（测试 02），与手算结果一致。

## 各语言说明

- Python 一次性算出两行之间所有木板的用时，再用 `map(min, …)` 整行更新，使最大的情况只需约四分之一秒。
