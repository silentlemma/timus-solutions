# 1358. Провода

[Timus 1358](https://acm.timus.ru/problem.aspx?space=1&num=1358) · сложность 540 · graphs

Автор оригинальной задачи — Ден Расковалов (условие — Александр Бикбаев); чемпионат школьников, март 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N ≤ 1000 компьютеров соединены N − 1 проводами в связную сеть, то есть в
дерево. Нужно расставить компьютеры точками на плоскости с координатами
не больше 1000 по модулю так, чтобы провода, нарисованные прямыми
отрезками, не пересекались, а любые два компьютера были дальше 1 друг от
друга.

Ограничение времени: 0,25 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N − 1 строк с концами a, b каждого провода.

## Выходные данные

N строк с координатами компьютеров от 1 до N. Подходит любая правильная
расстановка.

## Примеры

### Пример 1

Ввод:

```
3
1 2
2 3
```

Вывод:

```
0 0
10 0
0 10
```

## Решение

Подвесим дерево за компьютер 1 и обойдём его в глубину. Каждый
компьютер ставим в столбец по его номеру в этом обходе,
x = 2 · номер − 999, и в строку по глубине, y = глубина. У каждого
компьютера свой столбец в двух единицах от соседнего, поэтому все
расстояния не меньше 2, а все координаты лежат в [−999, 999].

Провода не пересекаются. Каждый провод соединяет компьютер в некоторой
строке с его ребёнком в следующей строке, так что два провода могут
встретиться, только если лежат в одной полосе между двумя строками.
Обход в глубину проходит каждое поддерево подряд идущим блоком
столбцов, а у компьютеров одной строки поддеревья не пересекаются;
поэтому провода, выходящие из двух разных компьютеров строки, остаются в
двух непересекающихся диапазонах столбцов, а провода из одного
компьютера имеют общим только этот конец. `O(N)`.

Тонкие места:

- путь из 1000 компьютеров имеет глубину 999 строк и всё равно
  помещается в границы (сгенерированный тест 2);
- при N = 1 проводов нет вовсе (тест 02);
- обход должен быть итеративным или иметь достаточно стека для
  глубины 999.

Тесты проверяются чекером, который проверяет границы, каждую пару точек
и каждую пару проводов, включая провода с общим концом, лежащие друг на
друге.

- Ответы разных языков отличаются порядком детей, поэтому нужен чекер;

  короткое ограничение времени.
