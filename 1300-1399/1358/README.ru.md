# 1358. Провода

[Timus 1358](https://acm.timus.ru/problem.aspx?space=1&num=1358) · сложность 540 · graphs

Автор оригинальной задачи — Ден Расковалов (условие — Александр Бикбаев); чемпионат школьников, март 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N ≤ 1000 компьютеров соединены N − 1 проводами в связную сеть, то есть в
дерево. Нужно расставить компьютеры точками на плоскости с координатами
не больше 1000 по модулю так, чтобы провода, нарисованные прямыми
отрезками, не пересекались, а любые два компьютера были дальше 1 друг от
друга.

Ограничение времени: 0,25 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N − 1 строк с концами a, b каждого провода.

## Выходные данные

N строк с координатами компьютеров от 1 до N. Подходит любая правильная
расстановка.

## Примеры

### Пример 1

Ввод:

```
3
1 2
2 3
```

Вывод:

```
0 0
10 0
0 10
```

## Решение

Подвесим дерево за компьютер 1 и обойдём его в глубину. Каждый
компьютер ставим в столбец по его номеру в этом обходе,
x = 2 · номер − 999, и в строку по глубине, y = глубина. У каждого
компьютера свой столбец в двух единицах от соседнего, поэтому все
расстояния не меньше 2, а все координаты лежат в [−999, 999].

Провода не пересекаются. Каждый провод соединяет компьютер в некоторой
строке с его ребёнком в следующей строке, так что два провода могут
пересечься внутри отрезков, только если лежат в одной полосе между двумя строками.
Обход в глубину проходит каждое поддерево подряд идущим блоком
столбцов, а у компьютеров одной строки поддеревья не пересекаются;
поэтому провода, выходящие из двух разных компьютеров строки, остаются в
двух непересекающихся диапазонах столбцов, а провода из одного
компьютера имеют общим только этот конец. `O(N)`.

Тонкие места:

- путь из 1000 компьютеров с корнем на конце имеет глубину 999 и всё
  равно помещается в границы (сгенерированный тест 8);
- при N = 1 проводов нет вовсе (тест 02);
- обход должен быть итеративным или иметь достаточно стека для
  глубины 999.

Тесты проверяются чекером, который проверяет границы, каждую пару точек
и каждую пару проводов, включая провода с общим концом, лежащие друг на
друге.

Учебная версия C++ назначает точку при входе рекурсивного DFS в вершину. Столбец начинается с −999 и при каждом входе увеличивается на два. Номер строки равен глубине, переданной в вызов. Рекурсия идёт во всех соседей, кроме родителя. В дереве этого достаточно, чтобы посетить каждую вершину один раз и занять столбцы её поддерева подряд. Время и память O(N), глубина стека не превышает N.

## Оптимизированные решения

Go и Rust сохраняют x=2·preorder−999 и y=depth. Разные столбцы отстоят на 2, значит расстояния строго больше 1. При N ≤ 1000 получаем x в [−999,999], y в [0,999]. Ребро лежит между соседними уровнями внутри интервала столбцов поддерева своего родителя. У разных родителей одного уровня эти интервалы не пересекаются. Рёбра одного родителя идут в разные точки следующей строки и встречаются только в родителе. Новые версии хранят начала списков смежности, концы и ссылки на следующие рёбра, порядок обхода, глубину и стек в плоских 16-битных массивах. Индекс ребра не превышает 1998, номер вершины и глубина плюс один не превышают 1000. Нулевая глубина означает непосещённость, отдельный seen или массив родителей не нужен. Обратное добавление рёбер и LIFO сохраняют исходный порядок детей. Обе версии используют фиксированные массивы на 1000 вершин. Go читает и пишет через стандартные дескрипторы с буферами по 256 байтов. Rust использует посимвольный ввод и вывод и точку входа C. Время и память O(N). Простые файлы сохранены; C++/Java/Python используют подходящие базы.

Принятые базовые реализации [1358_graphs.cpp](1358_graphs.cpp), [1358_graphs.java](1358_graphs.java), [1358_graphs.py](1358_graphs.py) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.

## Особенности языков

Эти замечания относятся к базовым реализациям.

- Все языки обходят детей в порядке ввода и дают одинаковую расстановку;
  чекер принимает и другие правильные ответы.
- Java хранит списки смежности в плоских массивах, чтобы уложиться в
  короткое ограничение времени.
