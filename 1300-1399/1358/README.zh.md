# 1358. 电缆

[Timus 1358](https://acm.timus.ru/problem.aspx?space=1&num=1358) · 难度 540 · graphs

原题作者 Den Raskovalov（题面 Aleksandr Bikbaev），出自 2005 年 3 月中学生锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N ≤ 1000 台计算机由 N − 1 根电缆连成一个连通的网络，也就是一棵树。要把计算机放在平面上，坐标绝对值不超过 1000，
使得画成直线段的电缆互不相交，且任意两台计算机之间的距离大于 1。

时间限制：0.25 秒。内存限制：64 MB。

## 输入

N，然后是 N − 1 行，每行一根电缆的两端 a、b。

## 输出

N 行，依次为计算机 1 到 N 的坐标。任何合法的摆放都可以。

## 样例

### 样例 1

输入：

```
3
1 2
2 3
```

输出：

```
0 0
10 0
0 10
```

## 解法

以计算机 1 为根，对树做深度优先遍历。每台计算机放在由它在遍历中的序号决定的列上，x = 2 · 序号 − 999，行由深度
决定，y = 深度。每台计算机各占一列，相邻两列相距 2，所以所有距离至少为 2，坐标都落在 [−999, 999] 内。

电缆不会相交。每根电缆连接某一行的计算机与它在下一行的孩子，所以两根电缆只有位于同一条行间带中时才可能在内部相交。深度
优先遍历把每棵子树访问成一段连续的列，而同一行计算机的子树互不相交；因此同一行两台不同计算机引出的电缆分别处在两段
不相交的列区间内，同一台计算机引出的电缆只在这一端相交。`O(N)`。

注意事项：

- 1000 台计算机组成的路径以端点为根时深度为 999，仍在范围之内（生成测试 8）；
- N = 1 时根本没有电缆（测试 02）；
- 遍历必须是迭代的，或者有足够的栈空间应对 999 的深度。

测试由检查程序评判，它检查边界、每一对点和每一对电缆，包括有公共端点且相互重叠的电缆。

C++ 教学版在递归 DFS 进入节点时确定坐标。列从 −999 开始，每进入一个节点加二。行坐标为递归参数中的深度。递归访问父节点之外的所有邻居。输入是一棵树，因此每个节点只访问一次，同一子树的列连续。时间和空间为 O(N)，递归栈最多 N 层。

## 优化解法

Go/Rust 保持 x=2·preorder−999、y=depth。列各异且间隔2，任意点距>1；N≤1000 给 x∈[−999,999]、y∈[0,999]。边位于相邻深度行之间，也位于父节点的子树列区间内。同一行的不同父节点具有互不相交的列区间。同父节点的边通往下一行的不同点，只在父节点相交。新版用 16 位定长数组存储邻接表头、边的终点及后继，以及先序编号、深度和栈。边索引至多 1998，顶点编号及深度加一至多 1000。深度为 0 表示尚未访问。头插输入边再压入 LIFO 保留原子顺序。两种实现都按 1000 个顶点使用定长数组。Go 通过标准句柄用 256 字节定长缓冲读写，Rust 使用 C 字符 I/O 与 C 入口。时间空间 O(N)。保留简单版，C++/Java/Python 复用已达标基础版。
