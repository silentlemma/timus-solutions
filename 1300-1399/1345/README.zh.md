# 1345. HTML

原题作者 Pavel Egorov，出自 USU Championship 2004。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定一个最多 100 000 个字符的正确 Pascal 程序，把每个注释、关键字、字符串和数字分别用
`<span class=comment>`、`<span class=keyword>`、`<span class=string>` 或 `<span class=number>` 与 `</span>`
包起来，其余内容保持不变。注释里的一切都属于注释，字符串里的一切都属于字符串。

- 字符串要么是两个撇号之间、内部不含撇号的文本，要么是 `#` 后接非空且尽可能长的一串数字。
- 数字以数字字符开头和结尾，只含数字和至多一个小数点；总是取尽可能长的一段。
- 标识符以字母或 `_` 开头，后接字母、数字和 `_`，同样取尽可能长的一段。
- 注释是从 `{` 到下一个 `}`（两个括号都包含在内），或从 `//` 到行尾（不含换行符）。注释中的注释属于外层注释。
- 关键字是 35 个标识符，如 `begin`、`end` 和 `implementation`，大小写任意。

文本中可能有大于 127 的字节，最后一行可能没有换行符。

时间限制：1 秒。内存限制：64 MB。

## 输入

这个程序。

## 输出

加了标签的程序。

## 样例

### 样例 1

输入：

```
Begin
  writeln('Hello world!');
end.
```

输出：

```
<span class=keyword>Begin</span>
  writeln(<span class=string>'Hello world!'</span>);
<span class=keyword>end</span>.
```

## 解法

从左到右读文本，根据第一个字符判断这里开始的是什么：`{` 或 `//` 开始注释，`'` 或后跟数字的 `#` 开始字符串，
数字开始数，字母或 `_` 开始标识符。每一部分读到它的结尾后按需加标签；其他字符原样复制。因为先开始的部分会一直
占到自己的结尾，所以字符串里的 `{` 或注释里的 `'` 都不需要特别处理。标识符的小写形式在列表中时加上关键字
标签；整段读取标识符，可以避免把 `a1` 中的数字当成数。L 个字符时为 `O(L)`。

注意事项：

- `1..10` 是两个数加一个范围，`1.5.3` 是数 `1.5`、一个点和数 `3`：只有后面跟着数字时点才算数（测试 04）；
- `'it''s'` 是两个字符串 `'it'` 和 `'s'`，`#13#10` 也是两个字符串（测试 05）；
- `{` 注释在第一个 `}` 处结束，即使里面还有一个 `{`（测试 03）；
- 文本按字节处理，所以编码大于 127 的字母原样通过（测试 06），缺少的最后换行符也保持缺少（测试 01 和 08）；
- Windows 换行按普通换行读取，所以 `//` 注释不会带上回车符。

## 各语言说明

- 每种解答都处理原始字节；Python 用 latin-1 读取，每个字节对应一个字符并能原样还原。
