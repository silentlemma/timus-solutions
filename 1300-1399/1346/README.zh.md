# 1346. 单调区间

[Timus 1346](https://acm.timus.ru/problem.aspx?space=1&num=1346) · 难度 297 · greedy

原题作者 Alexander Klepinin，出自 USU Championship 2004。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

函数 F 定义在整数网格 A, A + 1, …, B 上，0 ≤ A < B ≤ 100 000，函数值在 −100 000 到 100 000 之间。把网格分成
尽可能少的区间，使 F 在每个区间上不减或不增，输出区间个数。

时间限制：1 秒。内存限制：64 MB。

## 输入

A 和 B，然后是 F(A), …, F(B)，以空格或换行分隔。

## 输出

最少的区间数。

## 样例

### 样例 1

输入：

```
1 10
1 2 3 4 2 1 -1 3 6 7
```

输出：

```
3
```

## 解法

区间划分的是网格上的点，所以一个区间的最后一点与下一个区间的第一点之间的那一步不受约束。单调区间的任何一部分
仍然单调。因此把第一个区间尽量延长永远没有坏处，之后的每个区间也一样：贪心计数就是最小值。

区间在保持单调时不断延长。它的方向由第一个非平的步决定，平的步适合任何方向。第一个与该方向相反的步结束这个
区间，下一个区间从下一个点开始。`O(B − A)`。

注意事项：

- 两个区间之间的那一步不受约束：1 3 2 4 只需 2 个区间，1 3 和 2 4（测试 02）；
- 平的步无论区间朝哪个方向都属于它，常函数就是一个区间（测试 03、05 和 06）；
- 函数值可能分在好几行。

在 500 个最多 12 个点的随机函数上，与对所有划分做动态规划的结果比较过。
