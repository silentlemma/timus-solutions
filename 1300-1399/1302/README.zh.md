# 1302. 三角波

[Timus 1302](https://acm.timus.ru/problem.aspx?space=1&num=1302) · 难度 347 · math

原题出自 1998 年 4 月 3–4 日在叶卡捷琳堡举行的第二届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个无限大的三角形被分成单位三角形并逐行编号：第 1 行是格子 1，第 2 行是格子 2 到 4，第 k 行是
从 (k − 1)² + 1 到 k² 的 2k − 1 个格子，尖朝上和尖朝下的三角形交替出现。每一步穿过一条边进入相邻
格子（穿过顶点不算）。求从格子 m 到格子 n 的最少步数，1 ≤ m, n ≤ 10⁹。

时间限制：1 秒。内存限制：64 MB。

## 输入

m 和 n。

## 输出

最短路线的长度。

## 样例

### 样例 1

输入：

```
6 12
```

输出：

```
3
```

## 解法

网格的边落在三族平行线上：水平线和两族斜线。给每族直线之间的条带编号，于是每个格子有三个数：
行号 r、从左边数的条带号和从右边数的条带号。对格子 n，取 r = ⌈√n⌉，它在行内的位置
p = n − (r − 1)²（1 到 2r − 1）：

- 左条带 ⌊(p + 1) / 2⌋，右条带 ⌊(2r − p + 1) / 2⌋。

穿过一条边恰好穿过一条直线，因此恰好使三个数之一变化 1。所以任何路线都不短于三个差值之和，而在
这个网格上这个和总能达到，因此

答案 = |Δ行| + |Δ左| + |Δ右|。

样例中格子 6 是 (3, 1, 2)，格子 12 是 (4, 2, 3)，答案为 1 + 1 + 1 = 3。行号用精确的整数平方根
求出。`O(1)`。

注意事项：

- 相邻的编号可能相距很远：k² 结束一行，k² + 1 在另一侧开始下一行（测试 06 和 07）；
- 格子 1 和 2 只在顶点相接，所以相距 2 步（测试 03）；
- 行号必须由精确的整数平方根得到：一行恰好在 k² 结束，平方根差 1 就会把格子放错行。

在 30 行的棋盘上，对所有起点小于 120、终点小于 625 的格子对，与广度优先搜索的结果比较过。

## 各语言说明

- Python 使用 `math.isqrt`；其他语言把浮点平方根上下调整直到精确。
