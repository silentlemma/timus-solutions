# 1360. Философский спор

[Timus 1360](https://acm.timus.ru/problem.aspx?space=1&num=1360) · сложность 1272 · math

Идея оригинальной задачи — Ден Расковалов, подготовка — Станислав Васильев; IX командный студенческий чемпионат Урала по программированию, Екатеринбург, 19–24 апреля 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

С ростом t точка x = sin(√t), y = cos(t) бегает по квадрату [−1, 1]².
Дана жирная точка — круг радиуса ε ≥ 10⁻⁴ с центром (x₀, y₀) внутри
квадрата. Нужно вывести любое t из [0, 10¹²], при котором кривая
попадает в этот круг, или `FAIL`, если такого нет.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

x₀ и y₀ в первой строке, ε во второй.

## Выходные данные

Момент t или `FAIL`.

## Примеры

### Пример 1

Ввод:

```
0.744 0.554
0.01
```

Вывод:

```
5.3
```

## Решение

Координаты меняются с очень разной скоростью. Обозначим s = √t, тогда
x = sin(s) и y = cos(s²). При большом s изменение s на δ сдвигает x
не больше чем на δ, а t = s² — примерно на 2sδ, что при достаточно
большом s больше целого периода косинуса.

Сначала используем r = min(ε, 1): точка внутри меньшего круга лежит
и внутри исходного. При переполнении положительный радиус читаем как
положительную бесконечность, а затем ограничиваем его.

Поэтому берём s₀ = asin(x₀) + 2πk с k = ⌈1/r⌉ + 1, так что
sin(s₀) = x₀ и s₀ ≥ 2π/r + 3π/2. В пределах π от t₀ = s₀² есть t с
cos(t) = y₀ ровно: t = acos(y₀) + 2πj для ближайшего целого j. Его
корень отличается от s₀ не больше чем на π / (√(s₀² − π) + s₀) < r/4,
так что x ошибается меньше чем на r/4, а y не ошибается вовсе. Ответ
`FAIL` не бывает никогда. Используем j = floor((t₀ − acos(y₀)) / (2π) + 0.5),
затем округляем t до целого числа миллионных через floor(t·10⁶ + 0.5)
и печатаем шесть знаков после точки: шаги округления во всех языках
одинаковы. Время и память — `O(1)`.

Тонкие места:

- при ε = 10⁻⁴ ответ около 4·10⁹, что далеко внутри [0, 10¹²], поэтому
  t нужно выводить с достаточным числом знаков: шесть знаков после
  точки сдвигают cos(t) не больше чем на 10⁻⁶;
- круг может быть больше квадрата (тест 05);
- у ε нет верхней границы, и оно может переполнить double (тест 13);
  сохраняем положительную бесконечность от разбора и ограничиваем
  рабочий радиус единицей;
- x₀ и y₀ стоит прижать к [−1, 1] перед asin и acos.

Выведенные ответы проверены на 1317 точках, включая все четыре угла
и центр при ε = 10⁻⁴ и радиусы за пределами double; расстояние ни разу
не превысило 0,251·ε. Тесты проверяются чекером, который заново
вычисляет точку кривой при выведенном t.
