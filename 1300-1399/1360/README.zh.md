# 1360. 哲学之争

[Timus 1360](https://acm.timus.ru/problem.aspx?space=1&num=1360) · 难度 1272 · math

原题创意来自 Den Raskovalov，由 Stanislav Vasiliev 准备，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

随着 t 增大，点 x = sin(√t)、y = cos(t) 在正方形 [−1, 1]² 中移动。给定一个圆心为 (x₀, y₀)、半径 ε ≥ 10⁻⁴ 的
圆点，输出 [0, 10¹²] 内任意一个使曲线落在圆点内的 t，若不存在则输出 `FAIL`。

时间限制：2 秒。内存限制：64 MB。

## 输入

第一行为 x₀ 和 y₀，第二行为 ε。

## 输出

一个时刻 t，或 `FAIL`。

## 样例

### 样例 1

输入：

```
0.744 0.554
0.01
```

输出：

```
5.3
```

## 解法

两个坐标变化的速度相差很大。记 s = √t，则 x = sin(s)，y = cos(s²)。在 s 较大时，s 改变 δ 只使 x 至多改变 δ，
却使 t = s² 改变约 2sδ，当 s 足够大时这超过了余弦的一整个周期。

先令 r = min(ε, 1)：落在较小圆内的点也一定在原圆内。若正半径在解析时溢出，先保留正无穷，再限制为 1。

所以取 s₀ = asin(x₀) + 2πk，其中 k = ⌈1/r⌉ + 1，这样 sin(s₀) = x₀ 且 s₀ ≥ 2π/r + 3π/2。在 t₀ = s₀² 的 π 范围内
存在恰好满足 cos(t) = y₀ 的 t：对最近的整数 j 取 t = acos(y₀) + 2πj。它的平方根与 s₀ 的差至多为
π / (√(s₀² − π) + s₀) < r/4，所以 x 的误差小于 r/4，y 完全没有误差。答案永远不会是 `FAIL`。
使用 j = floor((t₀ − acos(y₀)) / (2π) + 0.5)，再用 floor(t·10⁶ + 0.5) 将结果舍入为整数个百万分之一，
输出六位小数，使各语言的舍入步骤一致。时间和空间均为 `O(1)`。

注意事项：

- ε = 10⁻⁴ 时答案约为 4·10⁹，远在 [0, 10¹²] 之内，所以输出 t 时要有足够的位数：保留六位小数使 cos(t) 的变化
  不超过 10⁻⁶；
- 圆点可能比正方形还大（测试 05）；
- ε 没有上限，可能超出 double 的范围（测试 13）；保留解析所得的正无穷，再将工作半径限制为 1；
- 在调用 asin 和 acos 之前，把 x₀ 和 y₀ 限制在 [−1, 1] 内。

在 1317 个圆点上检查了输出的答案，包括 ε = 10⁻⁴ 时的四个角和中心，以及超出 double 范围的半径；距离从未超过
0.251·ε。测试由检查程序评判，它会在输出的 t 处重新计算曲线上的点。
