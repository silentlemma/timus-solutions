# 1335. 白色论题

[Timus 1335](https://acm.timus.ru/problem.aspx?space=1&num=1335) · 难度 182 · math

原题作者 Den Raskovalov，出自 2004 年 10 月 16 日第十届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 N（2 ≤ N ≤ 30 000），求三个不同的整数 A、B、C，都在 N² 到 (N + 1)²（含两端）之间，使 A² + B² 能被 C
整除；若不存在则输出 `No solution`。任何这样的三元组都被接受。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

整数 N。

## 输出

A、B 和 C，或 `No solution`。

## 检查

检查器接受区间内任意三个不同的数，只要 A² + B² 能被 C 整除。三元组总是存在，所以 `No solution` 永远不会被接受。

## 样例

### 样例 1

输入：

```
2
```

输出：

```
8 6 4
```

### 样例 2

输入：

```
1000
```

输出：

```
1000000 1000756 1000976
```

## 解法

取 C = N² + 1，A = N²，B = N² + N + 1。模 C 时第一个数是 −1，第二个数是 N，所以 A² + B² ≡ 1 + N²，这正是
C 本身，于是和能被 C 整除。由于 N² + N + 1 < N² + 2N + 1，三个数都在 N² 和 (N + 1)² 之间，并且对任意
N ≥ 1 都互不相同。所以答案总是存在，`No solution` 不会出现。`O(1)`。

这个三元组是这样找到的：对较小的 N 列出所有 A = N² 的解，发现每次都包含 (N² + N + 1, N² + 1)。

注意事项：

- 这些数可达约 9 · 10⁸，而只有检查器才需要的平方可达 8 · 10¹⁷，超出 32 位的范围；
- 样例给出的是别的三元组；任何正确的都被接受。
