# 1335. Белый тезис

[Timus 1335](https://acm.timus.ru/problem.aspx?space=1&num=1335) · сложность 182 · math

Автор оригинальной задачи — Ден Расковалов; X командный чемпионат школьников Свердловской области по программированию, 16 октября 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано N, 2 ≤ N ≤ 30 000. Нужно найти три различных целых числа A, B и C
от N² до (N + 1)² включительно, для которых A² + B² делится на C, или
вывести `No solution`, если таких нет. Принимается любая такая тройка.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Число N.

## Выходные данные

A, B и C или `No solution`.

## Проверка

Чекер принимает любые три различных числа из отрезка, у которых A² + B²
делится на C. Тройка существует всегда, поэтому `No solution` не
принимается никогда.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
8 6 4
```

### Пример 2

Ввод:

```
1000
```

Вывод:

```
1000000 1000756 1000976
```

## Решение

Возьмём C = N² + 1, A = N² и B = N² + N + 1. По модулю C первое число
равно −1, а второе — N, так что A² + B² ≡ 1 + N², а это и есть C, и
сумма делится на C. Все три лежат между N² и (N + 1)², поскольку
N² + N + 1 < N² + 2N + 1, и различны при любом N ≥ 1. Значит, ответ
существует всегда и `No solution` не бывает. `O(1)`.

Тройка найдена так: для небольших N были выписаны все решения с
A = N², и среди них каждый раз встречалась пара (N² + N + 1, N² + 1).

Тонкие места:

- числа доходят примерно до 9 · 10⁸, а их квадраты, нужные только
  чекеру, — до 8 · 10¹⁷, больше, чем вмещают 32 бита;
- в примерах показаны другие тройки; принимается любая верная.
