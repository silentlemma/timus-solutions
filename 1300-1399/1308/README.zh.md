# 1308. 院长的金字塔

[Timus 1308](https://acm.timus.ru/problem.aspx?space=1&num=1308) · 难度 2786 · bfs

原题创意来自 Stanislav Vasiliev，由 Pavel Egorov 和 Alexander Mironenko 准备，出自 2004 年 3 月 11–16 日在叶卡捷琳堡举行的第八届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个底面为单位正方形、四个侧面为正三角形的金字塔立在底面上，底面中心在原点，底边平行于坐标轴。每一步
绕所在面的一条棱翻滚，这条棱在桌面上不动。另有一条规则：若金字塔经过某条棱翻到底面上，下一次翻滚必须
经过底面的对边。至多翻滚 70 次，使金字塔重新立在底面上，并让底面中心尽量接近一个离原点不超过 25 的
给定点。输出这个距离，保留四位小数。

时间限制：1 秒。内存限制：64 MB。

## 输入

目标点的坐标。

## 输出

最小距离。

## 样例

### 样例 1

输入：

```
2.3660254037 1.3660254038
```

输出：

```
0.0000
```

## 解法

物体绕棱翻滚时，下一个面会落在这条棱的另一侧，所以跟踪桌面上的面最方便。

- 从一个侧面翻到相邻的侧面时，翻滚所绕的棱经过顶点。顶点不动，新三角形就是旧三角形绕顶点转 60°。
- 从侧面翻到底面时，正方形位于三角形底边之外，而按规则下一次翻滚直接翻到对面的侧面。这两次翻滚把
  顶点移动两倍三角形高加上正方形的边长，即沿从顶点指向底边的方向移动 1 + √3，并且这个方向反转。

因此躺着的三角形可由顶点和六个方向之一描述。走法有转 ±60°（一次翻滚）和跳 1 + √3（两次翻滚），停下
则再翻一次到底面上，此时底面中心离顶点 (1 + √3) / 2。

第一次翻滚经由底面四条边之一离开底面。由于每次转 60°，0° 和 180° 的边给出同样的六个方向，90° 和 270°
的边给出另外六个。因此以半次跳跃为单位度量的顶点总在一个六边形格点上，所有位置都能用整数对精确表示。
按翻滚次数做最短路搜索（走法代价为 1 或 2，按代价分桶即可）可遍历 69 次之内可达的全部三角形面状态，每类几千个。
每个状态都尝试作为翻到底面前的最后状态，取最近的中心；也可以完全不翻滚。

S 为可达状态数时复杂度为 `O(S)`。

注意事项：

- 很多点可以精确到达，比如样例和一次完整跳跃的距离（测试 01 和 08），但并非每个格点都可达：沿坐标轴
  半次跳跃的位置永远到不了（测试 07）；
- 起始位置本身也算，不翻滚（测试 02）。

模型与真实的三维金字塔翻滚模拟比较过：在遵守院长规则的前提下绕每条棱旋转实体，直到下一个面平放在桌上。
在 10 次翻滚以内，两者给出的底面位置集合完全相同。

## 各语言说明

- (1 + √3) / 2 按 1/2 + sin 60° 计算，用的是与方向相同的 60°。
