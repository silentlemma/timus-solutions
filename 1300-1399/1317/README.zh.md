# 1317. 冰雹

[Timus 1317](https://acm.timus.ru/problem.aspx?space=1&num=1317) · 难度 1064 · geometry

原题创意来自 Pavel Atnashev，由 Pavel Atnashev 和 Alexey Lakhtin 准备，出自 2004 年 3 月 11–16 日在叶卡捷琳堡举行的第八届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

停车场是一个有 3 到 10 个顶点的凸多边形，四周围着高为 h（1 ≤ h ≤ 100）的围栏。激光器放在地面上、严格位于停车场内部，
能摧毁距离不超过 d（h < d < 1000）的冰雹。冰雹垂直落下。

射程总是足以击落落在停车场上的冰雹；对于落在场外的冰雹，只要激光器能越过围栏看到并够得着，也会击落。
给定最多 100 个冰雹落点，求有多少冰雹在空中被击落。所有坐标的绝对值不超过 1000。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行是 n 和 h，接着 n 行按环绕顺序给出顶点，然后一行是 d 和激光器坐标，再是 k 和 k 行落点。

## 输出

被击落的冰雹数。

## 样例

### 样例 1

输入：

```
4 10.00
1.00 0.00
0.00 1.00
-1.00 0.00
0.00 -1.00
50.00 0.00 0.00
5
0.00 0.00
1.00 1.00
2.00 2.00
3.00 3.00
4.00 4.00
```

输出：

```
3
```

## 解法

设一颗冰雹落在停车场外，与激光器的水平距离为 r。从激光器指向落点的射线在水平距离 a 处穿过围栏离开停车场。
在高度 z 处击中冰雹的光束经过围栏时的高度为 z · a / r，所以只有 z ≥ h · r / a 时才能越过围栏。激光应尽量
往低处打，若这个最低点在射程之内，冰雹就被击落：

r² + (h · r / a)² ≤ d²，即 r² · (a² + h²) ≤ d² · a²。

为求 a，先按面积的符号把多边形转成逆时针，并把每条边写成外法向量 n 和偏移 c，使停车场满足所有边上的
n · p ≤ c。射线 L + t · u 在 t = (c − n · L) / (n · u) 处穿过它朝向的边（n · u > 0），由于停车场是凸的，
射线在其中最小的 t 处离开。对所有边都满足 n · p ≤ c 的冰雹落在停车场内或围栏上，总是计入。`O(n · k)`。

注意事项：

- 落在围栏上的冰雹算作落在停车场上（测试 02）；
- 顶点可能按顺时针给出（测试 05），所以要先确定方向；
- 比较需要一个小的相对容差：h = 100、半边长为 1 的正方形、距离为 2 的冰雹需要 d² ≥ 40004，因此
  d = 200 恰好够不着，d = 201 够得着（测试 06 和 07）。

在 400 个随机停车场上，与一种直接检查的结果比较过：它用二分查找最低可见高度，并让光束与围栏的每条边逐一检验。

## 各语言说明

- 五种解答的步骤相同；射线离开所经过的边的距离从无穷大开始取最小值。
