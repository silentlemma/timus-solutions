# 1317. Град

[Timus 1317](https://acm.timus.ru/problem.aspx?space=1&num=1317) · сложность 1064 · geometry

Идея оригинальной задачи — Павел Атнашев, подготовили Павел Атнашев и Алексей Лахтин; VIII командный студенческий чемпионат Урала по программированию, Екатеринбург, 11–16 марта 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Автостоянка — выпуклый многоугольник с 3–10 вершинами, обнесённый
забором высоты h (1 ≤ h ≤ 100). Лазер стоит на земле строго внутри
стоянки и уничтожает градину, если до неё не больше d (h < d < 1000).
Градины падают отвесно.

Дальности всегда хватает на градины, падающие на саму стоянку, а
градины снаружи лазер тоже сбивает, если видит их поверх забора и
достаёт. По не более чем 100 точкам падения градин нужно посчитать,
сколько из них сбито в воздухе. Все координаты по модулю не больше 1000.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

В первой строке n и h, затем n строк с вершинами в порядке обхода,
затем строка с d и координатами лазера, затем k и k строк с точками
падения.

## Выходные данные

Количество сбитых градин.

Ввод:


## Решение

Пусть градина падает вне стоянки на горизонтальном расстоянии r от
лазера. Луч выходит из стоянки на горизонтальном расстоянии a — там,
где луч от лазера к точке падения пересекает забор. Луч, попадающий в
градину на высоте z, проходит над забором на высоте z · a / r и
перелетает его только при z ≥ h · r / a. Стрелять выгодно как можно
ниже, и градина сбита, если эта самая низкая точка в пределах дальности:

r² + (h · r / a)² ≤ d², то есть r² · (a² + h²) ≤ d² · a².

Чтобы найти a, многоугольник разворачивается против часовой стрелки
(по знаку площади), и каждая сторона записывается внешней нормалью n со
сдвигом c, так что стоянка — это n · p ≤ c для всех сторон. Луч
L + t · u пересекает стороны, к которым движется (n · u > 0), при
t = (c − n · L) / (n · u), и раз стоянка выпуклая, выходит из неё при
наименьшем из этих t. Градина с n · p ≤ c для всех сторон падает на
стоянку или на забор и засчитывается всегда. `O(n · k)`.

Тонкие места:

- градины на заборе считаются падающими на стоянку (тест 02);
- вершины могут идти по часовой стрелке (тест 05), так что сначала
  нужно определить ориентацию;
- сравнениям нужен небольшой относительный допуск: при h = 100,
  квадрате с полустороной 1 и градине на расстоянии 2 нужно d² ≥ 40004,
  так что d = 200 чуть не достаёт, а d = 201 достаёт (тесты 06 и 07).

Ответы сравнивались с прямой проверкой, которая ищет самую низкую
видимую высоту бинарным поиском и проверяет луч против каждой стороны
забора, на 400 случайных стоянках.
