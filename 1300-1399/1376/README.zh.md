# 1376. 系主任的金字塔 2

[Timus 1376](https://acm.timus.ru/problem.aspx?space=1&num=1376) · 难度 11100 · backtracking

原题作者 Alexander Mironenko，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个底面是边长 A1 的正方形、四个侧面是腰长 A2 的全等等腰三角形的金字塔
（两者都在 0.1 到 10 之间，A2/A1 在 0.9 到 1.9 之间），底面着地，中心在
原点，底边与坐标轴平行。它可以绕一条棱从一个面滚到相邻的面，滚动时这条
棱保持不动。最多滚 N 次（2 ≤ N ≤ 32），让它重新以底面着地，并使底面中心
尽量靠近点 (X, Y)，该点至少相距 20.05·A1；距离相同时滚动次数最少。输出
保留 3 位小数的距离、滚动次数 M，以及它依次所站的 M + 1 个面：0 为底面，
1 到 4 为从朝向 +y 的那个侧面开始顺时针编号的侧面。

时间限制：2.5 秒。内存限制：64 MB。

## 输入

A1、A2、X、Y 和 N。

## 输出

距离、M，以及从起始的 0 开始的各个面。

## 样例

### 样例 1

输入:

```
10.0 10.0 1000.0 0.0 5
```

输出:

```
972.679
5
0 2 3 4 1 0
```

## 解法

状态是当前面、前一个面及当前面的顶点；滚动把顶点沿公共棱反射或展开。
四条规则覆盖所有滚动：从底面经从零编号的顶点 k - 1 与 k mod 4 的边滚到
侧面 k；从侧面滚到底面，展开出一个正方形；从侧面经侧棱顺时针或逆时针
滚到相邻侧面，反射第三个顶点。

搜索是精确的。每次滚动使着地面的中心移动固定的距离：底面与侧面之间为
A1/2 + h/3（h 为侧面的高），两侧面之间为 2·A1·h/(3·A2)，因此一张表给出
每个状态在剩余若干次滚动内以底面结束时中心位移的上界。对滚动做深度
优先搜索（从不立即滚回），用三角不等式剪掉距离下界大于当前最优距离的
分支，并先试最近的位置。每层最多保留 4 000 个状态（Python 为 200 个）的
束搜索先给出一个不错的答案，使剪枝立刻生效。最坏 `O(3^N)`，实际远小于此。

易错点：

- 答案不唯一：样例中的滚动可以换一种顺序（测试 01），所以检查器会重放
  滚动；
- N = 2 时无法更近，答案是 0 次滚动（测试 02）；
- 距离相同时看滚动次数。

答案在这里的所有测试和 150 个生成测试上与一份独立的已通过实现一致，
并在 240 个 N 不超过 8 的情形上与穷举所有滚动序列的结果一致。

## 各语言说明

- Python 对剩余不超过 8 次滚动的界精确计算：从 17 种状态各取一个，枚举所有不超过 8 次滚动的序列，取以底面结束的最远位置；更远处与其他语言一样累加固定步长。底面—侧面—底面的滚动总会回到原处，因此原来的界过于宽松：现在搜索访问的节点少 11 到 25 倍，200 个状态的束就足够。最大的测试在 CPython 下约 0.25 秒；没有精确界的最初版本即使在 PyPy 下也在评测第 5 个测试上超过 2.5 秒。
