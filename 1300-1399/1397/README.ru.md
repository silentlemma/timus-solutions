## Задача

На плоскости 2n точек, n ≤ 500. Двое по очереди красят их — первый
белым, второй чёрным, — пока каждый не покрасит n точек. Очки игрока —
сумма расстояний между всеми парами точек его цвета. При лучшей игре
обеих сторон нужно вывести разность очков победителя и проигравшего с
тремя знаками после точки. Во входных данных несколько игр.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Игры подряд: n, затем 2n строк с точками.

## Выходные данные

Разность для каждой игры.

## Примеры

### Пример 1

Ввод:

```
2
0 0
0 1
1 0
1 1
2
0 0
1 0
0 3
1 5
```

Вывод:

```
0.000
1.937
```

## Решение

Пусть Dᵢ — сумма расстояний от точки i до всех остальных. В сумме по
белым точкам каждая белая пара учтена дважды, а каждая разноцветная
пара — один раз: ΣW Dᵢ = 2·WW + WB, и так же ΣB Dᵢ = 2·BB + WB. Значит,
разность очков равна

WW − BB = (ΣW Dᵢ − ΣB Dᵢ) / 2,

и игра лишь складывает постоянные значения точек. Тогда каждому игроку
выгодно брать точку с наибольшим оставшимся Dᵢ: сортируем Dᵢ по
убыванию, первому достаются индексы 0, 2, 4, …, а ответ —
половина знакочередующейся суммы. `O(n²)` на игру для расстояний.

Подводные камни:

- игр несколько, и они идут до конца файла;
- ответ неотрицателен; код выводит его модуль;
- в Java Math.hypot намного медленнее Math.sqrt: до 499 500 пар за игру.

Ответы сравнивались с полным минимаксом по всем раскраскам на 200
случайных играх до 8 точек.
