# 1394. 舰船（第二版）

[Timus 1394](https://acm.timus.ru/problem.aspx?space=1&num=1394) · 难度 27928 · backtracking

原题由 Vladimir Yakovlev 准备。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

与[题目 1115](../../1100-1199/1115/README.zh.md) 相同，但测试难得多：N < 100
艘长度为 1 到 100 的舰船要恰好填满 1 < M < 10 个给定长度的行，每行至少一艘。
保证存在排法，输出任意一种。评测最多保留 20 个测试，每个都针对某类启发式，
但没有一个测试是为了击败所有启发式。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 M，然后 N 行舰船长度，再 M 行各行长度。

## 输出

按输入顺序对每一行输出两行：该行舰船数和它们的长度。

## 样例

### 样例 1

输入:

```
5 2
4
10
2
5
3
11
13
```

输出:

```
3
5 4 2
2
10 3
```

## 解法

一般情况下的精确多路划分很难，而评测的测试专门挑来击败单一启发式。
解法轮流运行四种精确搜索，每种都有一个时间片，每轮增长 1.6 倍，后面几轮
还会稍微打乱顺序；只要其中一个放好了所有船就停止。

- B，逐行填充。船按长度从大到小；在一行内每艘船或取或跳过，被跳过长度
  的所有副本一起跳过。每个未完成的行必须仍是未用船的子集和（后缀和的
  位集，在开新行时重算）。失败的状态——未用的船加上未完成的行——放进一个
  在重启之间保留的哈希表，因为它与顺序无关。B 每隔一轮还会对小模数做下面
  的余数检查。
- C，只对稀有长度（一到三个副本）做 B：这时一行只需要一个常见船能凑出的
  余量，常见船最后由嵌套的 B 放置。这样就不必枚举用常见船填行的大量等价
  方式。
- D，即 C，但“稀有”指不能被模数 K 整除，K 能整除很多船；再加上精确的
  余数检查：每个余数类剩下的非倍数船必须分给剩下的行，使每行得到自己长度
  模 K 的余数。由对行和计数向量（混合进制）的 DP 回答，每次查询有预算，
  缓存在重启之间保留。
- A，逐艘船放进行里，最稀有的长度先放。每行的剩余长度必须是未放船的和；
  不放当前船就无法完成的行必须得到它；剩余长度相同的行只试一次；相同的船
  按顺序进行；各行的船数也必须能凑起来（恰好 c 艘船之和的位集）。

最坏情况 `O(M^N)`，任何精确搜索都是如此。

易错点：

- 论坛测试 70 中的舰队有一行长 820，简单的重启 20 秒内什么也找不到
  （测试 03）；论坛测试 80 对其他顺序很难（测试 04）；
- 余数谜题：几乎所有船都是某个 k 的倍数，每行一艘特殊船，其余数决定它所在
  的行（生成测试 7 和 8）；
- 各行必须按输入顺序输出。

放置方案在这里的所有测试、八类共 200 个生成的舰队以及几个已知的困难舰队
上都通过了检查器，用时远低于限制；一份独立的已通过实现也能解出同一组。

## 各语言说明

- 没有 Python 解法：在测试 03 上 PyPy 约需 5 秒，CPython 超过 10 秒，而限制是 1 秒。
- Java 需要更贴近的移植才能在 1 秒内通过评测第 8 个测试：行内跳过的分支用循环而不是尾调用；A 的位集只到最长的行；下标用移位和掩码。没有这些改动的最初版本在该测试上超过 1 秒。
