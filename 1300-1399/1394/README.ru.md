# 1394. Корабли. Версия 2

[Timus 1394](https://acm.timus.ru/problem.aspx?space=1&num=1394) · сложность 27928 · backtracking

Подготовка оригинальной задачи — Владимир Яковлев.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Та же задача, что [1115](../../1100-1199/1115/README.ru.md), но с куда
более трудными тестами: N < 100 кораблей длиной от 1 до 100 должны
точно заполнить 1 < M < 10 рядов заданной длины, в каждом ряду хотя бы
один корабль. Расстановка существует; нужно вывести любую. Тестов не
больше 20, каждый подобран против какой-то эвристики, и ни один не
рассчитан на то, чтобы сломать их все.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем N строк с длинами кораблей, затем M строк с длинами рядов.

## Выходные данные

Для каждого ряда в порядке ввода две строки: число кораблей в нём и их
длины.

## Примеры

### Пример 1

Ввод:

```
5 2
4
10
2
5
3
11
13
```

Вывод:

```
3
5 4 2
2
10 3
```

## Решение

Точное разбиение на несколько частей в общем случае трудно, а тесты
жюри подобраны так, чтобы побеждать отдельные эвристики. Решения по
очереди запускают четыре точных поиска, каждый в кванте времени,
который растёт в 1,6 раза с каждым кругом, а на поздних кругах порядки
слегка перемешиваются; работа останавливается, как только один из
поисков расставит все корабли.

- B — ряды по одному. Корабли идут от длинных; внутри ряда каждый
  корабль берётся или пропускается, и копии пропущенной длины
  пропускаются вместе. Каждый открытый ряд должен оставаться суммой
  подмножества неиспользованных кораблей (битовые множества сумм
  суффиксов, пересчитываемые при открытии ряда). Неудачное состояние —
  неиспользованные корабли и открытые ряды — попадает в хеш-таблицу,
  которая переживает перезапуски, ведь от порядка оно не зависит. Через
  круг B ещё и делает проверку остатков (ниже) по малым модулям.
- C — это B только по редким длинам (от одной до трёх копий): ряду тогда
  нужен остаток, который соберут частые корабли, а их в конце расставляет
  вложенный B. Так не перебираются многочисленные взаимозаменяемые
  способы заполнить ряды частыми кораблями.
- D — это C, где «редкие» — не кратные модулю K, который делит много
  кораблей, плюс точная проверка остатков: оставшиеся некратные корабли
  каждого остатка должны разделиться между оставшимися рядами так, чтобы
  каждый ряд получил свою длину по модулю K. Ответ даёт ДП по рядам и
  векторам количеств (в смешанной системе счисления) с бюджетом на запрос
  и кешем, переживающим перезапуски.
- A — корабли по одному в ряды, начиная с самых редких длин. Остаток
  каждого ряда должен быть суммой нерасставленных кораблей; ряд, который
  нельзя закончить без текущего корабля, получает его; ряды с равными
  остатками пробуются один раз; равные корабли идут в ряды по порядку; и
  количества кораблей по рядам должны складываться (битовые множества
  сумм ровно c кораблей).

`O(M^N)` в худшем случае, как у любого точного поиска.

Подводные камни:

- на флоте из теста 70 с форума, с рядом длины 820, простые перезапуски
  ничего не находят за 20 секунд (тест 03); тест 80 с форума труден для
  других порядков (тест 04);
- головоломки с остатками: почти все корабли кратны некоторому k, и в
  каждом ряду один особый корабль, остаток которого определяет его ряд
  (сгенерированные тесты 7 и 8);
- ряды выводятся в порядке ввода.

Расстановки проходят программу проверки на всех здешних тестах, на 200
сгенерированных флотах восьми видов и на нескольких известных трудных
флотах, каждый с большим запасом; независимая принятая реализация решает
тот же набор.

## Особенности языков

- Решения на Python нет: на тесте 03 PyPy нужно около 5 с, а CPython —
  больше 10 с при ограничении 1 с.
- Чтобы пройти тест 8 жюри за 1 с, Java понадобился более точный порт:
  ветка пропуска в ряду — цикл, а не хвостовой вызов; битовые множества
  A кончаются на самом длинном ряду; индексы считаются сдвигами и
  масками. Первая версия без этого превышала 1 с на этом тесте.
