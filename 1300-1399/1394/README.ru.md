# 1394. Корабли. Версия 2

[Timus 1394](https://acm.timus.ru/problem.aspx?space=1&num=1394) · сложность 14802 · backtracking

Подготовка оригинальной задачи — Владимир Яковлев.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Та же задача, что [1115](../../1100-1199/1115/README.ru.md), но с куда
более трудными тестами: N < 100 кораблей с целыми длинами от 1 до 100
должны точно заполнить 1 < M < 10 рядов заданной длины, в каждом ряду
хотя бы один корабль. Расстановка существует; нужно вывести любую.
Тестов не больше 20, каждый подобран против какой-то эвристики, и ни
один не рассчитан на то, чтобы сломать их все.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем N строк с длинами кораблей, затем M строк с длинами рядов.

## Выходные данные

Для каждого ряда в порядке ввода две строки: число кораблей в нём и их
длины.

## Примеры

### Пример 1

Ввод:

```
5 2
4
10
2
5
3
11
13
```

Вывод:

```
3
5 4 2
2
10 3
```

## Решение

Точное разбиение на несколько частей в общем случае трудно, а тесты жюри
подобраны так, чтобы побеждать отдельные эвристики.

Перебор чередует три точных поиска в пяти слотах: B, B с рядами по
возрастанию длины, C, D и снова B. Кванты времени растут в 1,6 раза до
верхнего предела, а поздние круги слегка перемешивают порядки, пока один
из поисков не расставит все корабли или не кончится внутренний бюджет.

- B — ряды по одному. Корабли идут от длинных; внутри ряда каждый
  корабль берётся или пропускается, и копии пропущенной длины
  пропускаются вместе. Каждый открытый ряд должен оставаться суммой
  подмножества неиспользованных кораблей (битовые множества сумм
  суффиксов, пересчитываемые при открытии ряда). Неудачное состояние —
  неиспользованные корабли и открытые ряды — попадает в хеш-таблицу,
  которая переживает перезапуски, ведь от порядка оно не зависит. Каждый
  второй слот B ещё проверяет остатки по модулям D и малым модулям.
- C — это B только по редким длинам (от одной до трёх копий): ряду тогда
  нужен остаток, который соберут частые корабли, а их в конце
  расставляет вложенный B. Так не перебираются многочисленные
  взаимозаменяемые способы заполнить ряды частыми кораблями.
- D — это C, где «редкие» — не кратные модулю K, который делит много
  кораблей, плюс точная проверка остатков: оставшиеся некратные корабли
  каждого остатка должны разделиться между оставшимися рядами так, чтобы
  каждый ряд получил свою длину по модулю K. Ответ даёт ДП по рядам и
  векторам количеств (в смешанной системе счисления) с бюджетом на
  запрос и кешем, переживающим перезапуски.

Нужны все три: без C не хватает времени на тесте 8 жюри, без D — на
тесте 10, а если B занимает два слота из четырёх, а не три из пяти, — на
тесте 7. Четвёртый поиск, корабли по одному в ряды, не понадобился.

S — суммарная длина кораблей.

Подводные камни:

- на флоте из теста 70 с форума, с рядом длины 820, простые перезапуски
  ничего не находят за 20 секунд (тест 03); тест 80 с форума труден для
  других порядков (тест 04);
- головоломки с остатками: почти все корабли кратны некоторому k, и в
  каждом ряду один особый корабль, остаток которого ограничивает выбор
  ряда (сгенерированные тесты 7 и 8);
- флоты, которые решает только поиск по рядам B, и то лишь при удачном
  порядке, а C и D не решают (тесты 14 и 15);
- ряды выводятся в порядке ввода.

Расстановки проходят программу проверки на всех здешних тестах, на 130
трудных флотах и на 11 000 сгенерированных (из них 6 000 с равными
рядами): перебор — не дольше 0,55 с и 0,08 с, на трудных и на
сгенерированных флотах соответственно.

## Особенности языков

- Перебор на Python превышал лимит на тесте 7 жюри в четырёх версиях,
  каждая со своим основным поиском, поэтому решения на Python здесь нет.
- Чтобы пройти тест 8 жюри за 1 с, Java с перебором понадобился более
  точный порт: ветка пропуска в ряду — цикл, а не хвостовой вызов, а
  индексы считаются сдвигами и масками.
