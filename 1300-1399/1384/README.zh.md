# 1384. 放山羊进菜园 4

[Timus 1384](https://acm.timus.ru/problem.aspx?space=1&num=1384) · 难度 4590 · geometry

原题作者 Alexander Ipatov，出自 2005 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

菜园是一个简单多边形，不一定是凸的，有 3 ≤ N ≤ 25 个顶点，坐标为 0 到
1000 之间的整数。山羊会被拴在园内某处的木桩上，绳子必须足够短，使山羊碰
不到篱笆。对所有木桩位置，求最长的这种绳长，保留小数点后 2 位。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后按逆时针顺序给出 N 个顶点。

## 输出

绳子的长度。

## 样例

### 样例 1

输入:

```
3
0 0
200 0
0 200
```

输出:

```
58.58
```

## 解法

答案是多边形内最大圆的半径，即内部点到篱笆的最大距离。把篱笆看成若干对
象：每条边按其所在直线计入，因为最优圆心到一条边的最近点只有在该端点也
是相邻边的最近点，或者它是凹顶点时才会落在端点上，而凹顶点本身单独算作
一个对象。到两个对象等距的点构成一条曲线，沿着它距离是线性的（两条直线）
或凸的（直线和顶点、两个顶点），所以最大值出现在三个对象交汇处。

因此枚举所有三元组对象，求到三者距离相等的点：

- 三条直线：解线性方程组 n_i · p + c_i = r，单位法向量指向内部；
- 两条直线和一个顶点：沿两直线的角平分线走，到直线的距离在其上是线性
  的，再解一个二次方程，使到顶点的距离与之相等；
- 一条直线和两个顶点：同样地，沿两顶点的垂直平分线求解；
- 三个顶点：它们的外接圆圆心。

每个候选点都用到所有线段的真实距离和点是否在多边形内来检验。多余的候选点
仍是一个具有真实距离的内部点，不会给出过大的答案，而最优圆心一定在候选
点之中。约 28 000 个候选点，每个 O(N) 检验：`O(N⁴)`。

注意事项：

- 圆可能只抵住内角：宽度为 2 的加号形中答案为 √2，经过四个凹顶点（测试
  03）；
- 在宽度为 w 的走廊拐角处，圆的半径约为 0.586·w，大于走廊宽度的一半
  （测试 10）；
- 首项系数接近零的二次方程，或顶点落在直线上时只与零相切的情形，需要稳定
  的求根公式；
- 边中间的顶点会给出同一条直线两次，此时方程组退化（测试 12）。

在 150 个随机多边形上与网格搜索加局部爬山的结果做了比较，这些多边形由随
机点消除交叉得到，或为星形。测试按数值比较，误差不超过 0.011。
