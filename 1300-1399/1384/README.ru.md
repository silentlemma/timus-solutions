# 1384. Пусти козла в огород 4

[Timus 1384](https://acm.timus.ru/problem.aspx?space=1&num=1384) · сложность 4590 · geometry

Автор оригинальной задачи — Александр Ипатов; Петрозаводские летние сборы, август 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Огород — простой многоугольник, не обязательно выпуклый, с 3 ≤ N ≤ 25
вершинами в целых точках от 0 до 1000. Козла привяжут к колышку где-то
внутри, и верёвка должна быть настолько короткой, чтобы до изгороди
было не дотянуться. Нужно найти самую длинную такую верёвку по всем
местам для колышка, с округлением до 2 знаков после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N вершин против часовой стрелки.

## Выходные данные

Длина верёвки.

## Примеры

### Пример 1

Ввод:

```
3
0 0
200 0
0 200
```

Вывод:

```
58.58
```

## Решение

Ответ — радиус наибольшего круга внутри многоугольника, то есть
наибольшее расстояние от внутренней точки до изгороди. Изгородь
состоит из объектов. Каждое ребро учитывается своей прямой: ближайшая к
лучшему центру точка ребра бывает его концом, только если этот конец —
ещё и ближайшая точка соседнего ребра или невыпуклая вершина, которая
сама считается отдельным объектом. Точки, равноудалённые от двух
объектов, образуют кривую, вдоль которой расстояние линейно (две
прямые) или выпукло (прямая и вершина, две вершины), поэтому максимум
достигается там, где сходятся три объекта.

Значит, достаточно перебрать все тройки объектов и найти точки на
одинаковом расстоянии от всех трёх:

- три прямые: линейная система n_i · p + c_i = r, где единичные нормали
  смотрят внутрь;
- две прямые и вершина: идём по биссектрисе прямых, где расстояние до
  них линейно, и решаем квадратное уравнение для точек на таком же
  расстоянии от вершины;
- прямая и две вершины: то же на серединном перпендикуляре вершин;
- три вершины: центр их окружности.

Каждый кандидат проверяется настоящим расстоянием до всех отрезков и
проверкой принадлежности многоугольнику. Лишний кандидат — всё равно
внутренняя точка с настоящим расстоянием, так что слишком большой ответ
он не даст, а лучший центр среди кандидатов есть. Около 28 000
кандидатов проверяются за O(N) каждый: `O(N⁴)`.

Подводные камни:

- круг может упираться только во внутренние углы: в плюсе ширины 2
  ответ √2, через четыре невыпуклые вершины (тест 03);
- на повороте коридора ширины w круг имеет радиус около 0,586·w, больше
  половины ширины коридора (тест 10);
- квадратное уравнение со старшим коэффициентом около нуля или с
  касанием нуля, когда вершина лежит на прямой, требует устойчивой
  формулы корней;
- вершины посреди стороны дают одну и ту же прямую дважды, и система
  для них вырождена (тест 12).

Ответы сравнивались на 150 случайных многоугольниках — из случайных
точек с устранением пересечений и звёздных — с перебором по сетке и
последующим локальным подъёмом. Тесты проверяются как числа с
точностью 0,011.
