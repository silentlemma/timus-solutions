# 1331. Владислава

[Timus 1331](https://acm.timus.ru/problem.aspx?space=1&num=1331) · сложность 980 · geometry

Автор оригинальной задачи — Александр Бикбаев; X командный чемпионат школьников Свердловской области по программированию, 16 октября 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На сферической планете радиуса R ≤ 1000 есть M ≤ 5000 посадочных
площадок и N ≤ 5000 артефактов, каждый задан широтой и долготой в
градусах. Для каждого артефакта нужно вывести расстояние по поверхности
до ближайшей площадки с двумя знаками после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем R, затем M строк с площадками и N строк с артефактами,
каждый — широтой и долготой.

## Выходные данные

N строк с расстояниями.

## Примеры

### Пример 1

Ввод:

```
1 2
1
0 0
1 1
0 0
```

Вывод:

```
0.00
```

### Пример 2

Ввод:

```
2 1
1
0 0
0 90
0 45
```

Вывод:

```
1.57
0.79
```

## Решение

Каждое место ставится на единичную сферу как точка пространства:
(cos φ cos λ, cos φ sin λ, sin φ). Расстояние по поверхности растёт
вместе с прямой хордой между точками, так что ближайшая площадка — та,
у которой хорда короче всего; её находит перебор всех площадок.
Сравнение квадратов хорд не требует ни корней, ни тригонометрии внутри
цикла. Расстояние затем равно R · 2 · asin(хорда / 2). Эта формула
сохраняет точность для близких точек, в отличие от R · acos скалярного
произведения, которое там теряет знаки. `O(N · M)`, 25 миллионов пар.

Тонкие места:

- на полюсах долгота не важна (тест 04);
- долготы −179.5 и 179.5 отстоят на один градус через линию перемены
  дат, а не на 359 (тест 05);
- противоположные точки отстоят на π · R, и из-за округления
  хорда / 2 может чуть превысить 1, поэтому она ограничивается (тест 03).

Расстояния сравнивались с формулой гаверсинусов на 300 случайных
небольших примерах.
