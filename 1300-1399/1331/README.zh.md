# 1331. 弗拉季斯拉娃

[Timus 1331](https://acm.timus.ru/problem.aspx?space=1&num=1331) · 难度 988 · geometry

原题作者 Alexander Bikbaev，出自 2004 年 10 月 16 日第十届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一颗半径 R ≤ 1000 的球形行星上有 M ≤ 5000 个着陆点和 N ≤ 5000 件文物，每个都用以度为单位的纬度和经度给出。
对每件文物，输出它沿地表到最近着陆点的距离，保留小数点后两位。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 M，然后是 R，然后 M 行着陆点和 N 行文物，每行是纬度和经度。

## 输出

N 行距离。

## 样例

### 样例 1

输入：

```
1 2
1
0 0
1 1
0 0
```

输出：

```
0.00
```

### 样例 2

输入：

```
2 1
1
0 0
0 90
0 45
```

输出：

```
1.57
0.79
```

## 解法

把每个地点放到单位球面上，作为空间中的点：(cos φ cos λ, cos φ sin λ, sin φ)。地表距离随两点间的直线弦长
增大，所以最近的着陆点就是弦最短的那个，逐一尝试所有着陆点即可。比较弦长的平方，循环内不需要开方或三角函数。
距离为 R · 2 · asin(弦长 / 2)。这个公式对相近的点也保持精度，不像对点积取 R · acos 那样在那里丢失有效数字。
`O(N · M)`，共 2500 万对。

注意事项：

- 在两极经度无关紧要（测试 04）；
- 经度 −179.5 和 179.5 隔着日期变更线相差 1 度，而不是 359 度（测试 05）；
- 对跖点相距 π · R，舍入可能让 弦长 / 2 略微超过 1，所以要截断（测试 03）。

在 300 个随机小例子上，与半正矢公式（haversine）的结果比较过。
