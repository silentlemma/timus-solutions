# 1357. 傻瓜用水壶 1.0

[Timus 1357](https://acm.timus.ru/problem.aspx?space=1&num=1357) · 难度 1187 · simulation

原题作者 Vladimir Yakovlev，出自 2005 年 3 月中学生锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N ≤ 500 名学生在同一天的不同时刻醒来，共用一个放在 400 W 炉子上的水壶。发现炉子空闲的人倒入 200 ml、20 °C 的
水开始加热。发现水壶正在加热的人再加入 200 ml、20 °C 的水，温度按质量比例混合。水壶容量 1 升，即五份；壶满时，
后来的人要等到水壶空出来。水一到 100 °C，壶里所有份数的主人都得到咖啡，水壶立刻可以再用。质量为 m 的水在 Δt
秒内升温 P·Δt / (C·m) 度，C = 4190 J/(kg·K)。对每名学生输出拿到咖啡的时刻。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是按递增顺序给出的 N 个醒来时刻 `HH:MM:SS`。

## 输出

N 行，同样格式的拿到咖啡的时刻。

## 样例

### 样例 1

输入：

```
4
07:00:00
07:02:00
07:05:30
12:00:00
```

输出：

```
07:08:23
07:08:23
07:08:23
12:02:48
```

## 解法

考虑距离沸腾还缺的热量：Q = C · Σ mᵢ · (100 − Tᵢ)。混合不改变 Q，因为它对质量是线性的；炉子每秒使它减少 P。每
加一份水增加 C · 0.2 kg · 80 K = 67 040 J，炉子恰好用 167.6 秒补足。所以在时刻 s 开始、装有 k 份水的水壶在
s + 167.6 · k 时沸腾，与后来几份是何时加入的无关。

模拟时维护壶里的学生、等待队列和沸腾时刻。在沸腾之前到来的人加入水壶，把沸腾时刻推迟 167.6 秒；若壶已满则排队。
到沸腾时刻，壶里的学生拿到咖啡，最多五名等待者组成下一壶并立刻开始加热。所有时间都以整数毫秒保存，167.6 秒恰好
是 167 600 毫秒，因此完全没有舍入误差。`O(N)`。

题面有三点没有说明；据该题讨论区的反馈，评测数据遵循以下约定：

- 答案向上取整到整秒：10:00:00 和 10:00:01 共用一壶，在 10:05:35.2 沸腾，输出 `10:05:36`（测试 05）；
- 恰好在沸腾时刻醒来的学生不加入这一壶，而是开始新的一壶（测试 03）；
- 午夜之后的时间从 `00:00:00` 继续（测试 04）。

在 400 组随机数据上，与按题面用精确分数跟踪温度和质量的模拟结果比较过。
