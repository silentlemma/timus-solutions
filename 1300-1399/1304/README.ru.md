# 1304. Параллелепипед

[Timus 1304](https://acm.timus.ru/problem.aspx?space=1&num=1304) · сложность 1909 · bruteforce

Оригинальная задача — II командный студенческий чемпионат Урала по программированию, Екатеринбург, 3–4 апреля 1998 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Параллелепипед A имеет вершины (0, 0, 0) и (u, v, w), все стороны
меньше 1000. В нём лежат до 50 точек, и никакие две не лежат на прямой,
параллельной грани A, так что все их x, все y и все z различны. Нужно
найти параллелепипед G наибольшего объёма с рёбрами, параллельными
рёбрам A, который лежит в A и не содержит точек строго внутри (на его
поверхности точки допускаются). Вывести объём, округлённый до двух
знаков, половины — вверх.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

u, v и w; затем n; затем n строк с координатами точек. У всех чисел не
больше двух знаков после точки.

## Выходные данные

Объём G с двумя знаками после точки.

## Примеры

### Пример 1

Ввод:

```
1.0 1.0 1.0
1
0.5 0.5 0.5
```

Вывод:

```
0.50
```

## Решение

Каждая координата читается как целое число сотых, поэтому объёмы —
точные целые в миллионных, и итоговое округление тоже точное.

Наибольший параллелепипед нельзя раздвинуть, поэтому каждая из шести
его граней лежит на грани A или касается точки. Перебор устроен так:

- две грани по x выбираются из 0, u и x точек, примерно 52 · 51 / 2
  пар;
- остановить параллелепипед могут только точки строго между ними по
  x; назовём их P;
- нижняя грань по y лежит на 0 или на точке из P;
- верхняя грань по y опускается от v. В каждом положении точки из P
  строго между двумя гранями по y режут [0, w] на промежутки, и самый
  широкий промежуток даёт лучшую высоту.

Когда верхняя грань опускается ниже точки, та покидает слой, и два
промежутка вокруг её z сливаются в один. Двусвязный список по
отсортированным z делает каждое слияние за константу, а самый широкий
промежуток только растёт. Точки с z, равным 0 или w, никогда не делят
промежуток и в список не попадают.

Для пары граней по x с k точками между ними работа — порядка k², а по
всем парам это около n⁴ / 12, полмиллиона шагов при n = 50. Две
дешёвые оценки сокращают перебор: для каждого x1 значения x2 идут от
самого широкого, а пара или нижняя грань по y отбрасывается, как только
даже полная высота и глубина не могут превзойти лучший найденный объём.

Тонкие места:

- точки на поверхности A, даже в вершине, ничего не отрезают (тесты 02
  и 03);
- точка может лежать вне A; внутри G она быть не может, поэтому её
  отбрасываем до перебора, иначе её x дал бы G грань за пределами A
  (тесты 09, 10, gen6);
- округление половины вверх: объём ровно 0.005 печатается как 0.01
  (тест 07), а вещественное произведение может оказаться чуть ниже
  такой половины;
- объём доходит почти до 10⁹, то есть 10¹⁵ миллионных, так что нужны
  64-битные целые (тест 06).

Результаты сравнивались с прямой проверкой всех пар граней по x и по y
на 200 небольших случайных входах, во многих из которых есть точки на
гранях A.
