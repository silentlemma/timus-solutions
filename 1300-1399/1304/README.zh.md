# 1304. 长方体

[Timus 1304](https://acm.timus.ru/problem.aspx?space=1&num=1304) · 难度 1873 · bruteforce

原题出自 1998 年 4 月 3–4 日在叶卡捷琳堡举行的第二届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

长方体 A 的棱平行于坐标轴，对角顶点为 (0, 0, 0) 和 (u, v, w)，其中 0 < u, v, w < 1000。
给定 1 到 50 个点，它们也可以位于 A 外，任意两点都
不在平行于 A 某个面的直线上，所以它们的 x、y、z 坐标各不相同。求棱与 A 平行、位于 A 内且内部（严格
内部）不含任何点的最大长方体 G（点可以在其表面上）。输出其体积，保留两位小数，恰为一半时进位。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

u、v 和 w；然后是 n；然后 n 行点的坐标。所有数最多两位小数。

## 输出

G 的体积，保留两位小数。

## 样例

### 样例 1

输入：

```
1.0 1.0 1.0
1
0.5 0.5 0.5
```

输出：

```
0.50
```

## 解法

每个坐标都读成整数个百分之一，所以体积是以百万分之一为单位的精确整数，最后的舍入也是精确的。

最大的长方体无法再向外扩，所以它的六个面各自要么位于 A 的面上，要么碰到某个点。搜索如下：

- 两个 x 面从 0、u 和各点的 x 中选，至多 52 · 51 / 2 对；
- 只有 x 严格在两者之间的点才可能挡住长方体，记为 P；
- 下面的 y 面位于 0 或 P 中某个点上；
- 上面的 y 面从 v 向下扫。在每个位置，P 中 y 严格位于两个 y 面之间的点把 [0, w] 切成若干段，
  最宽的一段给出最佳高度。

上面的 y 面到达一个点的 y 时，该点离开这一层，它的 z 两侧的两段合并为一段。在排好序的 z 值上用双向链表，
定位节点后每次合并都是常数时间，而最宽的一段只会变大。z 等于 0 或 w 的点永远不会切开某一段，不放入链表。

对于中间有 k 个点的一对 x 面，有 O(k²) 次间隙合并。所有对的 k² 之和约为 n⁴ / 12，n = 50 时约五十万。
两个简单的界限还能进一步剪枝：对每个 x1，x2 从最宽的开始尝试；只要即使取满高度和深度也无法超过目前
最好的体积，就放弃这一对 x 面或这个下 y 面。

注意事项：

- A 表面上的点，即使在顶点上，也不会切掉任何东西（测试 02 和 03）；
- 点可能位于 A 之外；它不可能在 G 内部，所以在搜索前就把它去掉，否则它的 x 会让 G
  的一个面落在 A 之外（测试 09、10、gen6）；
- 舍入时一半向上：体积恰为 0.005 时输出 0.01（测试 07），而浮点乘积可能落在这种一半的稍下方；
- 体积接近 10⁹，即 10¹⁵ 个百万分之一，所以需要 64 位整数（测试 06）。

在 200 个小型随机输入上（其中很多在 A 的面上有点）与直接检查所有 x 面对和 y 面对的结果比较过。
