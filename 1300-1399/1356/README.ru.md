# 1356. Чего бы попроще

[Timus 1356](https://acm.timus.ru/problem.aspx?space=1&num=1356) · сложность 298 · number_theory

Автор оригинальной задачи — Александр Бикбаев; чемпионат школьников, март 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для каждого из T ≤ 20 чисел N, 2 ≤ N ≤ 10⁹, нужно представить N в виде
суммы как можно меньшего числа простых и вывести эти простые.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

T, затем T строк с N.

## Выходные данные

Для каждого N — строка с простыми числами. Подходит любая сумма с
наименьшим числом слагаемых.

## Примеры

### Пример 1

Ввод:

```
7
2
27
85
192
14983
3
7
```

Вывод:

```
2
23 2 2
2 83
11 181
14983
3
7
```

## Решение

- Если N простое, хватает одного простого.
- Если N чётное, хватает двух: гипотеза Гольдбаха не доказана, но
  проверена далеко за 10⁹. Перебираем p = 2, 3, 4, …, пока p и N − p
  не окажутся простыми.
- Если N нечётное, в сумме двух простых обязательно есть 2, ведь два
  нечётных простых дают чётную сумму. Значит, двух простых хватает ровно
  тогда, когда N − 2 простое.
- Иначе нужно и хватает трёх: берём наибольшее простое p ≤ N − 4.
  Остаток N − p чётный и не меньше 4, и он раскладывается на два
  простых, как выше.

Простота проверяется тестом Миллера — Рабина по основаниям 2, 3, 5, 7,
который точен для всех чисел меньше 3,2·10⁹. Промежутки между простыми
до 10⁹ меньше 300, а на 200 000 чётных чисел чуть меньше 10⁹
наименьшее простое в разложении Гольдбаха ни разу не превысило 919,
так что на ответ уходит лишь несколько сотен проверок. `O(T · g · log N)`, где g — число
проверенных кандидатов.

Тонкие места:

- нечётное N никогда не раскладывается на два нечётных простых, так
  что случай с 2 нужно проверить отдельно (`85 = 2 + 83` в примере);
- 4 = 2 + 2 — единственное чётное разложение с двойкой (тест 03);
- остаток после наибольшего простого должен быть не меньше 4, ведь 2 не
  сумма двух простых;
- T может быть равно 0 (тест 04).

Для всех N до 20 000 и для 2 000 случайных N до 10⁹ проверено, что
ответ состоит из простых с нужной суммой и наименьшим числом
слагаемых, а тест Миллера — Рабина сравнивался с перебором делителей на
203 000 чисел. Тесты проверяются чекером, принимающим любую кратчайшую
сумму.

## Особенности языков

- Произведения в тесте Миллера — Рабина меньше 10¹⁸, поэтому во всех
  языках хватает 64-битных целых.
