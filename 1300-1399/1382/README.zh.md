# 1382. 卡片游戏

[Timus 1382](https://acm.timus.ru/problem.aspx?space=1&num=1382) · 难度 1697 · graphs

原题作者 Alexander Ipatov（特别感谢 Dmitry Ivankov），出自 2005 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N ≤ 1000 个朋友各自秘密地拿一张编号 1 到 N 的卡片。然后朋友 i 说两句话：“我拿着卡片 aᵢ”和“朋友 bᵢ 拿着卡片 cᵢ”，
其中 bᵢ ≠ i。两句中恰有一句为真。没有两个朋友对同一个人说同样的话，也没有人把某位朋友自称拿着的卡片说成是那位朋友的。
对每个朋友输出哪一句（1 或 2）为真；保证有解。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

N，然后是 N 行 aᵢ、bᵢ、cᵢ。

## 输出

N 个 1 或 2。任何一致的答案都可以。

## 样例

### 样例 1

输入:

```
5
3 4 3
1 3 2
3 2 5
2 5 4
3 4 1
```

输出:

```
1 2 2 2 2
```

## 解法

给朋友 i 一个变量 xᵢ：第一句为真时取真。每句话都是一个断言“某人 p 拿着卡片 q”，其文字为真时断言为真。两个为真的断言
若让一个人拿两张卡，或让一张卡归两个人，就互相冲突。

输入的规则保证：关于同一个人的断言说的都是不同的卡片，关于同一张卡片的断言说的都是不同的人。所以条件很简单：关于每个人
至多一个断言为真，关于每张卡片也至多一个为真。这是 2-SAT。k 个文字中“至多一个”用 k 个辅助变量 s₁ … s_k 编码：
对每个 j 加入 lⱼ → sⱼ，对 j ≥ 2 加入 sⱼ₋₁ → sⱼ 和 sⱼ₋₁ → ¬lⱼ。这样即使一张卡片被提到一千次，公式仍是线性的。Tarjan 算法求出
蕴含图的强连通分量；按 Tarjan 完成分量的顺序，若某文字的分量排在其否定的分量之前，就把它设为真。

注意事项：

- 对同一张卡片的 1000 个断言，直接对每对冲突断言编码需要 499 500 个子句（测试 14）；
- 每个朋友的假话必须保持为假；只要真断言之间不冲突，输入的规则就保证这一点。

测试由检查程序评判：它先检查真断言之间是否冲突，再用二分图匹配检查能否发卡使所有假断言都为假。2 到 28 个朋友的随机发牌
全部通过了检查。
