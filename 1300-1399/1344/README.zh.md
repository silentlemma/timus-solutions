# 1344. 巨型萝卜

[Timus 1344](https://acm.timus.ru/problem.aspx?space=1&num=1344) · 难度 4147 · dsu

原题作者 Pavel Egorov，出自 USU Championship 2004。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N ≤ 32 个无质量的滑轮由无质量的绳子连接。每个滑轮上搭着一根绳子，轴上还系着另一根绳子。第一类滑轮的轴绳
向上，搭在上面的绳子两端向下；第二类则相反。每个绳端都通向另一个滑轮、天花板、一个 1 kg 的萝卜，或者（恰好
一个端头）空着：要在上面挂一个重物。所有绳子都是竖直的，用绳子相连的滑轮高度不同。求使系统平衡的重物质量，
保留小数点后四位；若不存在输出 `No solution`，若任意质量都可以则输出 `Any`。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后对每个滑轮给出类型 T、搭在其上的绳子两端通向何处（X1 和 X2）以及轴绳通向何处（Y）。0 表示天花板，
−1 表示萝卜，−2 表示空着的绳端。

## 输出

质量、`No solution` 或 `Any`。

## 样例

### 样例 1

输入：

```
2
1 -1 2 0
2 1 0 -2
```

输出：

```
2.0000
```

### 样例 2

输入：

```
4
1 3 2 0
2 1 0 4
1 -1 4 1
2 3 2 -2
```

输出：

```
No solution
```

### 样例 3

输入：

```
4
1 2 2 0
2 1 1 -2
1 4 4 0
2 3 3 -1
```

输出：

```
Any
```

## 解法

以千克为单位计量力。无质量滑轮上的绳子两端张力相同，均为 t；滑轮平衡时轴绳拉住两端：轴上的张力 a = 2t。
连接两个滑轮的绳子只有一个张力。连着萝卜的绳端张力为 1，空着的绳端张力为未知质量 m，天花板则提供所需的任何力。

绳子到达另一个滑轮的哪一部分，由方向决定：从滑轮 i 向下离开的绳子从上方到达滑轮 j。在 j 处，它连到朝上的
那一部分——要么是轴，要么是搭在上面的绳子两端。所以每根绳子给出“这个张力等于那个张力”，每个滑轮给出
“a = 2t”。

这些关系都只乘以 2 的幂。对张力建一个带权并查集，为每个张力记录它与所在组根之间相差的 2 的幂的指数。若某个关系
闭合了一个环而幂次不一致（例如 t = 2t），该组所有张力都必须为 0。然后：

- 若萝卜所在的组必须为 0，萝卜无法挂住：`No solution`；
- 若萝卜和空绳端在同一组，m 就是二者之间的 2 的幂；
- 若空绳端所在的组必须为 0，则 m = 0；
- 否则空绳端与萝卜无关：`Any`。

`O(N log N)`。

注意事项：

- 到达滑轮的绳子要么连到它的轴，要么连到搭在它上面的绳子，只有方向能区分；
- 张力比矛盾时，只有该组连着萝卜才无法平衡（测试 02）；
- 空绳端可能挂在与萝卜毫无关系的系统上（测试 03 和 06）；
- 31 个动滑轮的链给出 2³¹，超出有符号 32 位整数的范围。

在约 3000 个最多 5 个滑轮的随机系统上，把并查集的结果与对同一组方程做精确高斯消元的结果比较过。

## 各语言说明

- 五种解答都把 2 的幂的指数存为整数，最后才求出质量。
- **Java**：质量用 `BigDecimal` 和 `HALF_EVEN` 按“四舍六入五成双”舍入。
