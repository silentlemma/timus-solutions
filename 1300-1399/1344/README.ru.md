# 1344. Репка

[Timus 1344](https://acm.timus.ru/problem.aspx?space=1&num=1344) · сложность 4147 · dsu

Автор оригинальной задачи — Павел Егоров; USU Championship 2004.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N ≤ 32 невесомых блоков соединены невесомыми верёвками. Через каждый
блок перекинута верёвка, и ещё одна привязана к его оси. У блока
первого типа верёвка от оси уходит вверх, а оба конца перекинутой —
вниз; у второго типа наоборот. Каждый конец верёвки ведёт к другому
блоку, к потолку, к репке массой 1 кг или — ровно один конец — никуда:
на него нужно подвесить груз. Все верёвки вертикальны, а блоки,
соединённые верёвкой, находятся на разной высоте. Нужно найти массу
груза, при которой система в равновесии, с четырьмя знаками после точки,
или вывести `No solution`, если её нет, и `Any`, если подходит любая.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем для каждого блока его тип T, куда ведут оба конца перекинутой
через него верёвки (X1 и X2) и куда ведёт верёвка от оси (Y). 0 — это
потолок, −1 — репка, −2 — свободный конец.

## Выходные данные

Масса, `No solution` или `Any`.

## Примеры

### Пример 1

Ввод:

```
2
1 -1 2 0
2 1 0 -2
```

Вывод:

```
2.0000
```

### Пример 2

Ввод:

```
4
1 3 2 0
2 1 0 4
1 -1 4 1
2 3 2 -2
```

Вывод:

```
No solution
```

### Пример 3

Ввод:

```
4
1 2 2 0
2 1 1 -2
1 4 4 0
2 3 3 -1
```

Вывод:

```
Any
```

## Решение

Будем мерить силы в килограммах. Верёвка через невесомый блок имеет
одно натяжение t на обоих концах, и блок в равновесии, когда верёвка от
оси держит оба конца: натяжение у оси a = 2t. Верёвка между двумя
блоками имеет одно натяжение. Конец у репки имеет натяжение 1,
свободный конец — неизвестную массу m, а потолок даёт сколько нужно.

К какой части другого блока приходит верёвка, следует из направлений:
верёвка, уходящая от блока i вниз, приходит к блоку j сверху. У j это
либо ось, либо концы перекинутой верёвки — то, что смотрит вверх. Так
что каждая верёвка говорит «это натяжение равно тому», а каждый блок —
«a = 2t».

Все эти соотношения умножают на степени двойки. Система
непересекающихся множеств по натяжениям хранит для каждого натяжения
показатель степени двойки, связывающей его с корнем группы. Если соотношение
замыкает цикл и степени не сходятся, например t = 2t, все натяжения
этой группы должны быть равны 0. Дальше:

- если группа репки должна быть нулевой, репка не может висеть:
  `No solution`;
- если репка и свободный конец в одной группе, m — степень двойки между
  ними;
- если группа свободного конца должна быть нулевой, m = 0;
- иначе свободный конец не зависит от репки: `Any`.

`O(N log N)`.

Тонкие места:

- верёвка, приходящая к блоку, встречает либо его ось, либо
  перекинутую через него верёвку, и только направления говорят, что
  именно;
- противоречивые отношения натяжений мешают равновесию, только если
  в их группе репка (тест 02);
- свободный конец может висеть на системе, никак не связанной с репкой
  (тесты 03 и 06);
- цепочка из 31 подвижного блока даёт 2³¹, больше, чем помещается в
  знаковое 32-битное целое.

Система непересекающихся множеств сравнивалась с точным методом Гаусса
на тех же уравнениях примерно для 3000 случайных систем до 5 блоков.

## Особенности языков

- Все пять решений хранят показатели степеней двойки как целые числа
  и строят массу только в конце.
- **Java**: масса округляется через `BigDecimal` с `HALF_EVEN`
  (к чётному при равенстве).
