# 1371. 货运公司

[Timus 1371](https://acm.timus.ru/problem.aspx?space=1&num=1371) · 难度 516 · dp

原题创意来自 Den Raskovalov，由 Alexander Klepinin 准备，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N ≤ 50 000 个分部由 N − 1 条道路连成一棵树，每条路的运送时间在 0 到 1000 之间。输出所有不同分部有序对的平均运送
时间，即所有距离之和除以 N(N − 1)，保留 4 位小数。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N − 1 行，每行为一条路的两端和它的时间。

## 输出

平均时间。

## 样例

### 样例 1

输入：

```
4
1 2 1
2 3 1
2 4 1
```

输出：

```
1.5
```

## 解法

按经过每条路的分部对来计数。删去一条路会把树分成 s 和 N − s 个分部两部分，恰好有 s · (N − s) 对分部的两端分在两边、
要经过这条路。所以有序对的总和为 2 · Σ c · s · (N − s)。

以分部 1 为根，用广度优先遍历按父先子后的顺序列出分部。倒着读这个列表就能得到子树大小：每个分部把自己的大小加到
父分部上。`O(N)`。

注意事项：

- 在全是最贵道路的路径上，总和可达 4·10¹⁶，需要 64 位整数（生成测试 2）；
- 50 000 个分部的路径对递归来说太深，所以用广度优先顺序；
- 允许时间为 0 的免费道路（测试 03）。

在 300 棵最多 30 个分部的随机树上，与从每个分部出发搜索并累加所有距离的结果比较过。
