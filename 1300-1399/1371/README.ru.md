# 1371. Грузоперевозки

[Timus 1371](https://acm.timus.ru/problem.aspx?space=1&num=1371) · сложность 520 · dp

## Задача

N ≤ 50 000 филиалов соединены N − 1 дорогами в дерево, у каждой дороги
время доставки от 0 до 1000. Нужно вывести среднее время доставки по
всем упорядоченным парам различных филиалов — сумму всех расстояний,
делённую на N(N − 1), — с 4 знаками после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N − 1 строк с концами дороги и её временем.

## Выходные данные

Среднее время.

## Примеры

### Пример 1

Ввод:

```
4
1 2 1
2 3 1
2 4 1
```

Вывод:

```
1.5
```

## Решение

Посчитаем каждую дорогу по разу на каждую пару, которая по ней идёт.
Удаление дороги делит дерево на части из s и N − s филиалов, и ровно
s · (N − s) пар с концами в разных частях идут по ней. Значит, сумма по
упорядоченным парам равна 2 · Σ c · s · (N − s).

Подвесим дерево за филиал 1 и выпишем филиалы так, чтобы родители шли
раньше детей, обходом в ширину. Прочитанный с конца, этот список даёт
размеры поддеревьев: каждый филиал прибавляет свой размер к родителю.
`O(N)`.

Тонкие места:

- на пути из самых дорогих дорог сумма доходит до 4·10¹⁶, так что нужны
  64-битные целые (сгенерированный тест 2);
- путь из 50 000 филиалов слишком глубок для рекурсии, отсюда обход в
  ширину;
- бесплатные дороги со временем 0 допустимы (тест 03).

Ответы сравнивались с суммой всех расстояний, найденных поиском из
каждого филиала, на 300 случайных деревьях до 30 филиалов.
