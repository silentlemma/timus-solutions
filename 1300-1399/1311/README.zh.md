# 1311. 稳定的结构

[Timus 1311](https://acm.timus.ru/problem.aspx?space=1&num=1311) · 难度 1415 · implementation

原题作者 Alexey Lakhtin，出自 2004 年 3 月 11–16 日在叶卡捷琳堡举行的第八届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一堵墙由高度、厚度和密度相同但长度不同的砖砌成，共 H ≤ 10 000 层，每层至多 1000 块，总数不超过
100 000。砖占据 [L, R]，端点为 0 到 10 000 的整数，且没有砖压在下一层的两块或更多砖上。不用灰浆的话，
墙能立住吗？若某块砖连同压在它上面的所有砖，其质心落在支撑区的边缘或之外，就会有东西倒下。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

H；然后从顶层开始的每一层：砖数 K，接着 K 行按递增顺序的 `L R`。

## 输出

墙能立住输出 `Yes`，否则输出 `No`。

## 样例

### 样例 1

输入：

```
3
1
10 20
3
1 7
13 17
100 200
2
0 20
60 160
```

输出：

```
Yes
```

## 解法

稳定的墙中，底层以上的每块砖都恰好压在它下面的一块砖上，也就是与它重叠（长度为正）的那块，所以砖块构成
立在底层上的若干棵树。一块砖的支撑区是它与那块砖的重叠部分，而负载是这块砖加上直接或间接压在它上面的一切。

砖的质量与长度成正比，它关于 0 的力矩是 (R² − L²) / 2。因此一块砖的负载为其子树上的 W = Σ (R − L)
和 M = Σ (R² − L²) / 2，质心为 M / W。保存 2M 而不是 M，条件 lo < M / W < hi 就变为

2 · lo · W < 2M < 2 · hi · W，

全部是精确整数（2M 小于 2 · 10¹³）。

各层从顶部开始给出，这恰好是负载变得完整的顺序。对每个新的层，用双指针同时遍历上一层和新层：上面的
每块砖找到下面与之重叠的砖，按这个重叠检查，然后把自己的 W 和 2M 加到那块砖上。下面没有砖的，或只在
角上碰到砖的，会倒下。底层立在地面上。`O(H + 砖的总数)`。

注意事项：

- 质心恰好在边缘算作倒下（测试 03 对比测试 04）；
- 只在端点相碰的砖什么也撑不住（测试 05），空层会让上面的砖悬空（测试 06）；
- 上面加重物可以挽救伸出去的砖：这里九块小砖足够，八块不够（测试 09 和 10）。

在 600 堵随机墙上与一个独立的检查比较过，那个检查用精确分数并显式建立支撑树。
