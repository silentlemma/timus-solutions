# 1306. Медиана последовательности

[Timus 1306](https://acm.timus.ru/problem.aspx?space=1&num=1306) · сложность 145 · sorting

Оригинальная задача — II командный студенческий чемпионат Урала по программированию, Екатеринбург, 3–4 апреля 1998 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно найти медиану N ≤ 250 000 целых чисел от 0 до 2³¹ − 1: средний
элемент отсортированной последовательности при нечётном N и среднее
двух средних элементов при чётном. Вывести её с одним знаком после
точки.

Ограничение времени: 1 секунда. Ограничение памяти: 1 МБ. В условии
разрешены C, C++ и Pascal, форма отправки предлагает ещё Rust.

## Входные данные

N, затем N чисел по одному в строке.

## Выходные данные

Медиана с одним знаком после точки.

## Примеры

### Пример 1

Ввод:

```
4
3
6
4
5
```

Вывод:

```
4.5
```

## Решение

Вся последовательность занимает 250 000 · 4 байта, около 1 МБ, то есть
весь лимит памяти. Но важна только меньшая половина: медиана — это
наибольшее или среднее двух наибольших из ⌊N/2⌋ + 1 наименьших чисел.

Поэтому куча с максимумом наверху хранит ⌊N/2⌋ + 1 наименьших из уже
прочитанных чисел, около 500 КБ. Каждое новое число либо добавляется,
пока куча не заполнена, либо заменяет вершину, если оно меньше
вершины. В конце:

- при нечётном N вершина и есть медиана;
- при чётном N вершина и, после одного извлечения, новая вершина — два
  средних элемента.

`O(N log N)` по времени, `O(N / 2)` по памяти.

Тонкие места:

- сумма двух чисел около 2³¹ − 1 может переполнить 32-битный знаковый
  тип (тест 04), но помещается в беззнаковый; код использует 64 бита;
- среднее либо целое, либо оканчивается на .5, поэтому печатается
  точно, без вещественных чисел (тесты 01 и 08);
- потоки C++ здесь слишком дороги по памяти, поэтому программа читает
  через `scanf`.
