# 1306. 序列的中位数

[Timus 1306](https://acm.timus.ru/problem.aspx?space=1&num=1306) · 难度 145 · sorting

原题出自 1998 年 4 月 3–4 日在叶卡捷琳堡举行的第二届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

求 N ≤ 250 000 个 0 到 2³¹ − 1 之间整数的中位数：N 为奇数时是排序后正中间的元素，N 为偶数时是中间
两个元素的平均值。保留一位小数输出。

时间限制：1 秒。内存限制：1 MB。题面只允许 C、C++ 和 Pascal，提交表单还提供 Rust。

## 输入

N，然后是 N 个数，每行一个。

## 输出

中位数，保留一位小数。

## 样例

### 样例 1

输入：

```
4
3
6
4
5
```

输出：

```
4.5
```

## 解法

整个序列要占 250 000 · 4 字节，约 1 MB，正是全部内存限制。但只有较小的一半有用：中位数就是最小的
⌊N/2⌋ + 1 个数中最大的那个，或最大两个的平均值。

所以用一个大根堆保存目前读到的最小的 ⌊N/2⌋ + 1 个数，约 500 KB。每个新数在堆未满时加入；堆满后
若比堆顶小，就替换堆顶。最后：

- N 为奇数时，堆顶就是中位数；
- N 为偶数时，堆顶以及弹出一次后的新堆顶就是中间的两个元素。

时间 `O(N log N)`，内存 `O(N / 2)`。

注意事项：

- 两个接近 2³¹ − 1 的数相加，连 32 位无符号数都会溢出，所以和用 64 位计算（测试 03 和 04）；
- 平均值要么是整数，要么以 .5 结尾，因此不用浮点数就能精确输出（测试 01 和 08）；
- 这里 C++ 流太占内存，所以程序用 `scanf` 读入。
