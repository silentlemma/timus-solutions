# 1373. Pictura ex Machina

[Timus 1373](https://acm.timus.ru/problem.aspx?space=1&num=1373) · сложность 830 · geometry

Автор оригинальной задачи — Павел Егоров; IX командный студенческий чемпионат Урала по программированию, Екатеринбург, 19–24 апреля 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Плоттер рисует N ≤ 100 000 мазков. Каждый мазок идёт X миллиметров в
одном направлении, поворачивает на 90° по часовой стрелке и идёт ещё X
миллиметров; он задан началом и концом — целыми числами, по модулю не
больше 10 000. Нужно вывести ширину и высоту наименьшей рамки со
сторонами вдоль осей, в которую помещаются все мазки, с 4 знаками после
точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

До конца ввода — строки из четырёх целых чисел: начало и конец мазка.

## Выходные данные

Ширина и высота рамки.

## Примеры

### Пример 1

Ввод:

```
0 0 1 1
1 1 2 0
2 0 0 0
2 0 3 0
```

Вывод:

```
3.0000 2.0000
```

## Решение

Мазок — это два отрезка, так что рамка должна вместить только его
начало, конец и угол. Если первый отрезок — (p, q), то поворот по
часовой стрелке делает второй (q, −p), и вместе они дают сдвиг от
начала к концу: p + q = dx и q − p = dy. Значит, угол — это начало плюс
((dx − dy) / 2, (dx + dy) / 2). Ответ — ограничивающий прямоугольник
всех этих точек. Удвоение всех координат сохраняет половинки целыми, а
в конце прямоугольник снова делится пополам. `O(N)`.

Тонкие места:

- ось y направлена вверх: так пример даёт 3 × 2, а при обратном
  повороте — 3 × 1,5;
- углы могут лежать вне диапазона ввода, до 20 000 от начала координат
  (тест 06);
- мазков может не быть вовсе, тогда ответ 0 × 0 (тест 02);
- число мазков не дано: читать нужно до конца ввода.
