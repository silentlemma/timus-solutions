# 1373. Pictura ex Machina

[Timus 1373](https://acm.timus.ru/problem.aspx?space=1&num=1373) · 难度 830 · geometry

原题作者 Pavel Egorov，出自 2005 年 4 月 19–24 日在叶卡捷琳堡举行的第九届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

绘图仪画 N ≤ 100 000 笔。每一笔先沿一个方向画 X 毫米，再顺时针转 90° 继续画 X 毫米；每笔由起点和终点给出，都是
绝对值不超过 10 000 的整数。输出能容纳所有笔画、边平行于坐标轴的最小画框的宽和高，保留 4 位小数。

时间限制：1 秒。内存限制：64 MB。

## 输入

直到输入结束，每行四个整数：一笔的起点和终点。

## 输出

画框的宽和高。

## 样例

### 样例 1

输入：

```
0 0 1 1
1 1 2 0
2 0 0 0
2 0 3 0
```

输出：

```
3.0000 2.0000
```

## 解法

一笔就是两条线段，所以画框只需容纳它的起点、终点和拐角。若第一段为 (p, q)，顺时针转弯后第二段为 (q, −p)，两段合起来
就是从起点到终点的位移：p + q = dx，q − p = dy。所以拐角为起点加上 ((dx − dy) / 2, (dx + dy) / 2)。答案就是所有
这些点的外接矩形。把所有坐标加倍可以让一半的值保持为整数，最后再把矩形尺寸减半。`O(N)`。

注意事项：

- y 轴向上：这样样例得到 3 × 2，反方向转弯则得到 3 × 1.5；
- 拐角可能超出输入的范围，离原点可达 20 000（测试 06）；
- 可能根本没有笔画，此时答案为 0 × 0（测试 02）；
- 没有给出笔画数：要读到输入结束。
