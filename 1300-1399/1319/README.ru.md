# 1319. Отель

## Задача

Стеллаж для почты в гостинице — блок N × N ячеек (1 ≤ N ≤ 100),
пронумерованных по диагоналям: номер 1 в правом верхнем углу, каждая
диагональ идёт сверху вниз, а диагонали следуют одна за другой к левому
нижнему углу, где стоит N². Нужно вывести пронумерованную таблицу.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число N.

## Выходные данные

N строк по N чисел через пробел.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
4 2 1
7 5 3
9 8 6
```

## Решение

У клеток одной диагонали одинакова разность столбец − строка. Если
перебирать эту разность от N − 1 до −(N − 1), а строки каждой диагонали
сверху вниз, клетки идут в порядке нумерации. `O(N²)`.

Тонкие места:

- первая диагональ — одна правая верхняя клетка, а не главная диагональ
  (тест 01);
- N = 1 — одна клетка с числом 1 (тест 02).

## Особенности языков

- Все пять решений заполняют таблицу одинаково и выводят её в конце
  целиком.
