# 1338. 汽车

[Timus 1338](https://acm.timus.ru/problem.aspx?space=1&num=1338) · 难度 1718 · bfs

原题作者 Alexander Klepinin，出自 USU Championship 2004。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一张 W × H 格（1 ≤ W, H ≤ 500）的城市地图上有建筑（`.`）、道路（`#`）和检查点（`o`，也是道路）；道路格通过公共边
相连。检查点从最下面一行往上编号，同一行内从左到右。最多 20 次实验中，每次选定目标点 T，其余每个检查点各派
一辆车沿最短路线开往 T。若有多条最短路线可继续，车依次优先选择南、北、西、东。对每次实验输出从北、南、东、西
到达 T 的车辆数。

时间限制：3 秒。内存限制：64 MB。

## 输入

W 和 H，然后 H 行地图，然后 M 和 M 个目标点编号。

## 输出

每次实验一行 `Experiment #N: North: Rn, South: Rs, East: Re, West: Rw`。

## 样例

### 样例 1

输入：

```
10 5
..####....
..o..o....
..####.#o.
......##..
.o#####...
1
4
```

输出：

```
Experiment #1: North: 0, South: 1, East: 0, West: 0
```

## 解法

从 T 出发的广度优先搜索给出每个可达道路格到 T 的距离。位于距离 d > 0 的格子上的车，按南、北、西、东的顺序
走向第一个距离为 d − 1 的邻格。所以这样的格子都有唯一确定的下一个格子，它的车到达 T 的方向与下一个格子的车相同。按搜索
发现格子的顺序处理，每个格子的下一个格子都已确定，直接复制其方向即可。与 T 相邻的格子从它所在的那一侧到达：
向北一步进入 T 就是从南面到达。统计 T 能到达的、除 T 以外所有检查点的方向，就是答案。`O((M + 1) · W · H)`。

注意事项：

- 编号从最下面一行开始，而不是最上面（测试 04）；
- 与 T 不连通的检查点派出的车不会到达（测试 04）；
- 优先方向在每一步都会在等长路线之间做选择，而不只是在出发时（测试 15）；
- 逐辆模拟车辆要对多达 250 000 个点分别花费其路线长度的时间，太慢了。

在 500 张随机的小地图上，与逐步驾驶每辆车的结果比较过。

  0.4 秒。
