# 1353. Миллиардная Функция Васи

[Timus 1353](https://acm.timus.ru/problem.aspx?space=1&num=1353) · сложность 103 · dp

Автор оригинальной задачи — Денис Мусин; чемпионат школьников, март 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано S, 1 ≤ S ≤ 81. Нужно посчитать целые числа от 1 до 10⁹ с суммой
цифр S.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число S.

## Выходные данные

Количество.

## Примеры

### Пример 1

Ввод:

```
1
```

Вывод:

```
10
```

## Решение

Любое число меньше 10⁹, дополненное ведущими нулями, — строка из девяти
цифр, а ведущие нули сумму цифр не меняют. Поэтому считаем строки
цифр: ways[s] после k цифр — число k-значных строк с суммой s, и каждая
новая цифра d от 0 до 9 переносит ways[s] в s + d. После девяти цифр
ways[S] — количество чисел от 0 до 999 999 999 с суммой S. У нуля сумма
0, он никогда не учитывается, а само 10⁹ с суммой цифр 1 добавляет
единицу при S = 1. `O(9 · 81 · 10)`.

Тонкие места:

- 10⁹ входит в диапазон: при S = 1 ответ 10, а не 9 (тест 01);
- начиная с S = 10 одна цифра уже не может взять всю сумму, и простой
  подсчёт «шаров и перегородок» даёт лишнее (тест 07);
- значения симметричны, ways[s] = ways[81 − s], а наибольшее —
  45 433 800 при S = 40 и 41, оно помещается в 32 бита.

Та же таблица для 10⁶ вместо 10⁹ сравнивалась с подсчётом сумм цифр
всех чисел до 10⁶.
