# 1353. Vasya 的十亿函数

[Timus 1353](https://acm.timus.ru/problem.aspx?space=1&num=1353) · 难度 103 · dp

原题作者 Denis Musin，出自 2005 年 3 月中学生锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 S，1 ≤ S ≤ 81，统计 1 到 10⁹ 之间数字和为 S 的整数个数。

时间限制：1 秒。内存限制：64 MB。

## 输入

一个数 S。

## 输出

个数。

## 样例

### 样例 1

输入：

```
1
```

输出：

```
10
```

## 解法

每个小于 10⁹ 的数补上前导零后都是一个九位数字串，而前导零不改变数字和。所以改为统计数字串：k 位之后的
ways[s] 是数字和为 s 的 k 位串个数，每加一位数字 d（0 到 9）就把 ways[s] 加到 s + d 上。九位之后，ways[S]
就是 0 到 999 999 999 中数字和为 S 的数的个数。0 的数字和为 0，永远不会被计入；而 10⁹ 本身的数字和为 1，
在 S = 1 时再加一。`O(9 · 81 · 10)`。

注意事项：

- 10⁹ 在范围之内：S = 1 时答案是 10 而不是 9（测试 01）；
- 从 S = 10 开始，单个数字已无法承担全部的和，直接用隔板法会多算（测试 07）；
- 结果是对称的，ways[s] = ways[81 − s]，最大值为 S = 40 和 41 时的 45 433 800，可以放进 32 位整数。

把 10⁹ 换成 10⁶ 得到的同样的表，与逐个统计 10⁶ 以内所有数的数字和的结果比较过。
