# 1310. Диагностика ACM

[Timus 1310](https://acm.timus.ru/problem.aspx?space=1&num=1310) · сложность 1036 · dp

Идея оригинальной задачи — Александр Клепинин, подготовили Александр Клепинин и Павел Егоров; VIII командный студенческий чемпионат Урала по программированию, Екатеринбург, 11–16 марта 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Состояние — это вектор из L ≤ 100 целых чисел от 1 до M ≤ 50, сумма
которых делится на K ≤ 50. Все состояния выписаны в лексикографическом
порядке по возрастанию и пронумерованы с 0. По номеру N нужно вывести
состояние.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

L, M и K, затем N.

## Выходные данные

L значений состояния.

## Примеры

### Пример 1

Ввод:

```
3 10 4
213
```

Вывод:

```
9 6 1
```

## Решение

Сначала посчитаем, затем выберем значения по одному.

Пусть ways[i][r] — число способов заполнить i регистров значениями
1..M так, чтобы их сумма давала остаток r по модулю K. Тогда
ways[0][0] = 1 и

ways[i][(r + v) mod K] += ways[i − 1][r] для каждого v из 1..M.

Чтобы прочитать состояние, идём по позициям, храня сумму s уже
выбранных значений. В позиции, после которой остаётся `left` регистров,
значение v начинает блок из ways[left][(−(s + v)) mod K] состояний.
Пробуем v = 1, 2, …: пока N не меньше блока, пропускаем блок
(N −= block), иначе берём v и идём дальше.

Количества доходят примерно до 50¹⁰⁰, 170-значного числа, поэтому для
N и таблицы нужна длинная арифметика. В таблице (L + 1) · K чисел, и она
заполняется L · M · K длинными сложениями. `O(L · M · K)` длинных
операций.

Тонкие места:

- остаток отрицательного числа нужно брать в пределах 0..K − 1
  ((−(s + v)) mod K);
- при K = 1 состояниями являются все M^L векторов, и последний из них —
  все M (тест 06);
- один регистр: возможны только значения, кратные K (тесты 02 и 03).

Ответы сравнивались с прямым перечислением всех состояний на 150
небольших случайных случаях.
