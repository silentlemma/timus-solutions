# 1310. ACM 诊断

[Timus 1310](https://acm.timus.ru/problem.aspx?space=1&num=1310) · 难度 1036 · dp

原题创意来自 Alexander Klepinin，由 Alexander Klepinin 和 Pavel Egorov 准备，出自 2004 年 3 月 11–16 日在叶卡捷琳堡举行的第八届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个状态是由 L ≤ 100 个 1 到 M ≤ 50 之间整数组成的向量，其和能被 K ≤ 50 整除。把所有状态按字典序
从小到大列出，从 0 开始编号。给定编号 N，输出对应的状态。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

L、M 和 K，然后是 N。

## 输出

该状态的 L 个值。

## 样例

### 样例 1

输入：

```
3 10 4
213
```

输出：

```
9 6 1
```

## 解法

先计数，再逐个选出各个值。

设 ways[i][r] 为用 1..M 的值填满 i 个寄存器、使其和模 K 余 r 的方法数。则 ways[0][0] = 1，并且

对 1..M 中每个 v，ways[i][(r + v) mod K] += ways[i − 1][r]。

读出状态时，按位置依次处理，同时记录已选值的和 s。在后面还剩 `left` 个寄存器的位置上，值 v 对应一个
含 ways[left][(−(s + v)) mod K] 个状态的块。依次尝试 v = 1, 2, …：只要 N 不小于块的大小，就跳过
这个块（N −= block），否则选定 v 并继续。

这些数可达约 50¹⁰⁰，即 170 位的数，所以 N 和表格都需要高精度。表中有 (L + 1) · K 个数，需要 L · M · K 次
高精度加法来填写。共 `O(L · M · K)` 次高精度运算。

注意事项：

- 负数的余数必须取在 0..K − 1 之间（(−(s + v)) mod K）；
- K = 1 时所有 M^L 个向量都是状态，最后一个全是 M（测试 06）；
- 只有一个寄存器时，只有能被 K 整除的值才可能出现（测试 02 和 03）。

在 150 个小型随机用例上与直接列出全部状态的结果比较过。

## 各语言说明

  需要的操作：读入、加法、比较和减法。
