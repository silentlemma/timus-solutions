# 1321. 楼层显示屏

[Timus 1321](https://acm.timus.ru/problem.aspx?space=1&num=1321) · 难度 1361 · math

原题创意来自 Leonid Volkov，由 Pavel Egorov 和 Igor Goldberg 准备，出自 2004 年 3 月 11–16 日在叶卡捷琳堡举行的第八届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一栋楼有 1 到 N 层，4 < N < 10⁹⁹⁹。电梯显示屏为 N 的每一位数字各设一个数位，每个数位最多有七段，楼层号
不显示前导零。在这栋楼的任何楼层都不会亮的段没有安装。坏掉的段要么常亮，要么常灭。

维修人员可以在任意楼层进入电梯，边乘坐边看显示屏，直到找出所有坏段或确认没有坏段。输出这趟乘坐最少需要
经过的楼层间隔数。

各数字的样子：0 除中间段外全亮，1 亮右边两段，6 带有顶段，9 带有底段，7 是顶段和右边两段。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

整数 N。

## 输出

最少的楼层间隔数。

## 样例

### 样例 1

输入：

```
10
```

输出：

```
8
```

## 解法

一段在乘坐中既亮过又灭过，就算检查过了；从 L 乘到 R 会显示其间的每一层。所以要找最短的楼层区间 [L, R]，
使每个已安装的段在其中某处亮、某处灭。尚未用到的数位（例如 1 到 9 层的十位）是空白的：所有段都灭。

设 N 有 D 位。乘坐过程中最高位必须变化，所以区间要跨过 10^(D−1) 的某个倍数。若只跨过一次，较低各位都从 9
变到 0。紧挨最高位的那一位变化最少，它显示一段连续的数字：从 9 往下、从 0 往上。只有数字 2 的右下段是灭的，
只有 5 和 6 的右上段是灭的，所以最短的合格序列是 6, 7, 8, 9, 0, 1, 2 和 9, 0, 1, 2, 3, 4, 5，各需五个
10^(D−2) 层的块再加一。若跨过之后到不了 2，就需要 2, …, 9, 0，代价是七个块加一。只跨一次时，最高位只有在
数字为 1 时才满足：空白与 1 恰好在那里安装的两段上不同。跨过之后要到达数字 2，需要 N 以 12 或更大开头。

最高位数字不小于 2 时，最高位至少需要三个状态。N 以 2 或 3 开头时，空白、1、2 就够了。从 4 开始，左上段也
被安装，最短的序列是从空白到 4 或从 1 到 5。k 个状态的序列需要 (k − 2) · 10^(D−1) + 1 层，其中间的块显示
所有较低位的数字。一位数的楼需要 1 到 5 层。汇总如下：

- N < 10：4；
- N 以 1 开头且第二位不小于 2：5 · 10^(D−2) + 1；
- N 以 10 或 11 开头：7 · 10^(D−2) + 1；
- N 以 2 或 3 开头：10^(D−1) + 1；
- N 以 4 或更大开头：3 · 10^(D−1) + 1。

答案是一个数字，接着若干个零，最后是 1。`O(D)`。

注意事项：

- N 最多有 999 位，所以按字符串读入（测试 14 到 16）；
- 只有 10 或 11 层时到不了 12 层，只能从 2 层开始（测试 01 和 05）；
- 两位数的 N 答案中没有零：10 层是 8，12 层是 6（测试 01 和 04）。

对所有不超过 399 的 N 以及 60 个不超过 30 000 的随机 N，与逐层滑动窗口的结果比较过。
