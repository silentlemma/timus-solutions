# 1391. Змейка

[Timus 1391](https://acm.timus.ru/problem.aspx?space=1&num=1391) · сложность 5173 · graphs

Автор оригинальной задачи — Дмитрий Иванков; Петрозаводские летние сборы, август 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Лабиринт из H × W клеток, H ≤ 300 и W ≤ 30, состоит из стен 'X' и
свободных клеток '.' и имеет единственный вход на границе. Змейка
длины L — цепочка из L различных соседних клеток. За единицу времени
она ползёт на одну клетку вперёд, влево или вправо, и тело следует за
головой; если ползти некуда, не врезавшись в стену или в себя, змейка
погибает. В момент 0 голова у входа, а остальное тело снаружи. Для
каждого L от 2 до 17 нужно найти наименьшее время, когда голова снова
окажется у входа, или -1. Ни одна змейка длины 18 живой не выберется.

Ограничение времени: 3 секунды. Ограничение памяти: 64 МБ.

## Входные данные

H и W, клетка входа, затем H строк по W символов.

## Выходные данные

16 строк: лучшее время для длин от 2 до 17 или -1.

## Решение

Змейка не может развернуться назад, поэтому, чтобы выбраться, ей нужно
обойти цикл лабиринта. Лучший выход — петля: кратчайший путь от входа
до ближайшей клетки J достижимого простого цикла из c клеток, один
обход цикла и тот же путь назад, всего 2·dist(J) + c единиц. Голова
возвращается в J через c ходов; входить в клетку уходящего хвоста
можно, так что обход возможен ровно при c ≥ L, а путь назад за телом
свободен. Достижимый цикл из c ≥ 18 клеток выпустил бы змейку длины
18, поэтому учитываются только циклы от 4 до 16 клеток; на клетчатом
поле в любом цикле чётное число клеток.

Для каждого чётного c нужно наименьшее расстояние клетки цикла по всем
достижимым циклам из c клеток. Упорядочим достижимые клетки по
расстоянию поиска в ширину от входа и будем искать циклы из каждой
клетки по очереди только по более поздним клеткам, так что каждый цикл
находится из своей ближайшей клетки. Поиск — обход в глубину не
длиннее 16 шагов, который обрывается, когда манхэттенское расстояние
до начала слишком велико. Длина считается найденной в первой клетке,
которая её замыкает, а поиск заканчивается, когда найдены все семь
длин. Ответ для L — минимум 2·best(c) + c по c ≥ L.

Подводные камни:

- циклу нужно не меньше L клеток, а не L + 1: голова может войти в
  клетку, которую как раз покидает хвост (тест 03);
- в циклах на клетчатом поле чётное число клеток, так что змейка длины
  17 никогда не выбирается (тест 05);
- по сообщениям форума, в одном тесте жюри есть цикл больше чем из 17
  клеток, вопреки обещанию, и ответы его не учитывают; решения считают
  циклы не длиннее 16 клеток, что заодно ограничивает поиск (тест 06 —
  такой лабиринт).

Ответы сравнивались с поиском в ширину по положениям всей змейки для
всех длин на 300 случайных лабиринтах не больше 16 клеток и на всех
остальных тестах, кроме теста 06.
