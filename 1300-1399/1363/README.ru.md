# 1363. Полутона

[Timus 1363](https://acm.timus.ru/problem.aspx?space=1&num=1363) · сложность 4703 · greedy

Идея оригинальной задачи — Павел Атнашев, подготовка — Евгений Крохалев; IX командный студенческий чемпионат Урала по программированию, Екатеринбург, 19–24 апреля 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Серую картинку A размером N × M пикселей, 75 ≤ N, M ≤ 300, с яркостью
от 0 до 255 нужно напечатать чёрно-белой: каждый пиксель B равен 0 или
255. Для каждого пикселя (i, j) возьмём окно из пикселей (k, l) с
|k − i| ≤ 10 и |l − j| ≤ 10, лежащих внутри картинки. Среднее B − A по
этому окну должно быть по модулю не больше 20. Нужно вывести любое
такое B.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем N строк по M яркостей.

## Выходные данные

N строк по M чисел, каждое 0 или 255.

## Примеры

### Пример 1

Ввод:

```
3 3
255 255 0
0 0 255
254 0 253
```

Вывод:

```
255 255 0
0 0 255
255 0 255
```

## Решение

Округляем каждую строку отдельно, перенося ошибку вдоль неё. Храним e
— сумму B − A по уже пройденным пикселям строки. На очередном пикселе
вычитаем его яркость из e; если e стало меньше −127, печатаем белый и
прибавляем 255. Тогда e на каждом шаге остаётся в [−127, 127]. Ошибка
любого отрезка строки — разность двух таких сумм: не больше 254 и не
больше 127, если отрезок начинается там, откуда шёл обход строки.

У окна r ≥ 11 строк и c ≥ 11 столбцов, и его ошибка — сумма ошибок его
отрезков строк:

- окно вдали от левой и правой границ имеет ширину 21, и ошибка
  отрезка 254 намного меньше допустимых 20 · 21 = 420 на строку;
- окно у боковой границы может иметь ширину всего 11, что допускает
  220 на строку, меньше 254. Поэтому строки обходятся в чередующихся
  направлениях; тогда в каждой второй строке отрезок касается начала
  обхода и ошибается не больше чем на 127. При r ≥ 11 строках
  ⌈r/2⌉ · 254 + ⌊r/2⌋ · 127 ≤ 220 · r.

`O(N · M)`.

Тонкие места:

- обхода всех строк слева недостаточно: картинка из одного серого 46
  шириной 97 даёт у правой границы окно со средней ошибкой 22,8
  (сгенерированный тест 2);
- пример нарочно нарушает ограничения на размер и лишь показывает
  формат.

Тесты проверяются чекером, который проверяет каждое окно через
двумерные префиксные суммы; тот же чекер отвергает округление в одном
направлении на сгенерированном тесте 2.

## Особенности языков

- Все пять решений используют одно и то же целочисленное округление.
