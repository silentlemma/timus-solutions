# 1340. 蟑螂

[Timus 1340](https://acm.timus.ru/problem.aspx?space=1&num=1340) · 难度 4615 · geometry

原题作者 Pavel Egorov，出自 USU Championship 2004。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一只蟑螂位于 (X, Y)，朝向为 A（从 x 轴逆时针计量的度数），转弯不能比半径为 R 的圆更急。求它到 (KX, KY) 处
面包屑的最短路径长度，到达时的朝向不限，保留小数点后四位。所有坐标和 R 的绝对值都不超过 10 000。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行是 X、Y、A 和 R，第二行是 KX 和 KY。

## 输出

最短路径的长度。

## 样例

### 样例 1

输入：

```
1 2 90 10
21 2
```

输出：

```
31.4159
```

## 解法

这是转弯半径受限、只能向前开的车（Dubins 车）到一个点、终止朝向任意时的最短路径。已知这样的路径要么是一段弧
加一条直线段，要么是两段转向相反的弧。两种路径都从与起点相切的两个半径为 R 的圆之一（左圆或右圆）开始。

将起点平移到原点，把初始朝向旋转到 x 轴正方向，并按象限约化角度。设面包屑的新坐标为 (u, v)，
D² 为原始位移的平方，s = ±1 表示转向，d 为 (0, sR) 到面包屑的距离。直接计算
q = D² − 2sRv = d² − R²；仅将距零不超过 10⁻¹⁵D² 的负舍入误差修正为零。

- 弧加线段：若面包屑不在圆内，蟑螂转弯直到沿切线正对面包屑。必须满足 q ≥ 0，线段长为 √q，
  转角为 atan2(u, R − sv) − atan2(√q, R)。
- 两段弧：第二个圆与第一个圆相切，所以其圆心距第一个圆心 2R；它又经过面包屑，所以其圆心距面包屑 R。同时满足
  两个条件的点至多两个，每个给出一条路径；两段弧的角度由绕两个圆心的角度求得。交点要求 0 ≤ q ≤ 8R²；
  高度用 √(q(8R² − q)) / (2d) 计算，避免相近平方数相减。

所有弧角都按转弯方向计量并对 2π 取模；第二段弧用半径向量的叉积与点积求 atan2。不能用固定 epsilon 扩大距离
可行区间，也不能把接近整圈的转角归零：圆内的目标可能需要很长的绕行。答案是至多六个候选中最短的。`O(1)`。

注意事项：

- 面包屑在转弯圆内时，这一侧不存在“弧加线段”的路径，最短的可能是两段弧（测试 06）；
- 正前方的面包屑必须给出直线距离，而不是绕一整圈（测试 03）；
- 起终点重合时，在圆的计算前返回 0（测试 05、10）；
- 目标即使只略微位于前方转弯圆内，也不存在切线捷径，不能用 epsilon 允许这种路径（测试 18）；
- R = 0 时蟑螂可以原地转向（测试 02）。

在 10 000 个小规模随机输入上，与独立的切换角穷举程序比较；该程序通过积分运动验证每条候选路径。
