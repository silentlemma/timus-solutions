# 1340. 蟑螂

[Timus 1340](https://acm.timus.ru/problem.aspx?space=1&num=1340) · 难度 4914 · geometry

原题作者 Pavel Egorov，出自 USU Championship 2004。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一只蟑螂位于 (X, Y)，朝向为 A（从 x 轴逆时针计量的度数），转弯不能比半径为 R 的圆更急。求它到 (KX, KY) 处
面包屑的最短路径长度，到达时的朝向不限，保留小数点后四位。所有坐标和 R 的绝对值都不超过 10 000。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行是 X、Y、A 和 R，第二行是 KX 和 KY。

## 输出

最短路径的长度。

## 样例

### 样例 1

输入：

```
1 2 90 10
21 2
```

输出：

```
31.4159
```

## 解法

这是转弯半径受限、只能向前开的车（Dubins 车）到一个点、终止朝向任意时的最短路径。已知这样的路径要么是一段弧
加一条直线段，要么是两段转向相反的弧。两种路径都从与起点相切的两个半径为 R 的圆之一（左圆或右圆）开始。

- 弧加线段：若面包屑不在圆内，蟑螂转弯直到沿切线正对面包屑。设面包屑到圆心的距离为 d，线段长为
  √(d² − R²)，切点位于从圆心看面包屑方向之前 acos(R / d) 处。
- 两段弧：第二个圆与第一个圆相切，所以其圆心距第一个圆心 2R；它又经过面包屑，所以其圆心距面包屑 R。同时满足
  两个条件的点至多两个，每个给出一条路径；两段弧的角度由绕两个圆心的角度求得。

所有弧角都按转弯方向计量并对 2π 取模。比整圈只小一个舍入误差的角度视为没有转弯，否则正前方的面包屑会多算
一整圈。答案是至多六个候选中最短的。`O(1)`。

注意事项：

- 面包屑在转弯圆内时，这一侧不存在“弧加线段”的路径，最短的可能是两段弧（测试 06）；
- 正前方的面包屑必须给出直线距离，而不是绕一整圈（测试 03）；
- 面包屑就在蟑螂脚下时距离为 0（测试 05）；
- R = 0 时蟑螂可以原地转向（测试 02）。

在 300 个随机例子上，与对终止朝向的搜索比较过：对每个朝向尝试全部六种标准 Dubins 路径，这些路径还经过逐步
跟踪验证。最大差距为 5 · 10⁻⁵，即搜索的步长。
