# 1349. 农场

[Timus 1349](https://acm.timus.ru/problem.aspx?space=1&num=1349) · 难度 51 · math

原题署名作者为 Pierre Fermat，出自 2005 年 3 月中学生锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 n（0 ≤ n ≤ 100），求三个 1 到 100 之间、互不相同的整数 a、b、c，使 aⁿ + bⁿ = cⁿ；取 a 最小的，其次 b
最小，再次 c 最小；若不存在则输出 −1。

时间限制：1 秒。内存限制：64 MB。

## 输入

整数 n。

## 输出

a、b 和 c，或 −1。

## 样例

### 样例 1

输入：

```
0
```

输出：

```
-1
```

### 样例 2

输入：

```
1
```

输出：

```
1 2 3
```

## 解法

- n = 0：任何数的 0 次幂都是 1，而 1 + 1 永远不等于 1，所以无解。
- n = 1：a + b = c，三个数互不相同时最小的选择是 1 2 3。
- n = 2：最小的勾股数 3 4 5 在要求的顺序中排第一。
- n ≥ 3：根据费马大定理，aⁿ + bⁿ = cⁿ 没有正整数解。

`O(1)`。

注意事项：

- n = 0 时虽然所有幂都相等，但仍然无解（测试 01）；
- 三个数必须不同，这排除了 n = 1 时 1 1 2 这样的答案。

对 n 从 0 到 5 枚举所有不超过 100 的三元组，得到相同的答案。

## 优化解法

优化解法输出同样的三种答案。Java 用 `System.in.read` 手工解析指数，而不是
`Scanner`：0.062 s，而不是 0.125 s；316 KB，而不是 1612 KB。Rust 用 `write_all`
输出字节串形式的答案，而不是 `println!`：0.031 s，而不是 0.062 s；212 KB，而不是
232 KB。
