# 1349. Ферма

[Timus 1349](https://acm.timus.ru/problem.aspx?space=1&num=1349) · сложность 51 · math

Автором оригинальной задачи назван Пьер Ферма; чемпионат школьников, март 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано n, 0 ≤ n ≤ 100. Нужно найти три различных целых числа a, b, c от 1
до 100, для которых aⁿ + bⁿ = cⁿ, — то, где a наименьшее, затем
наименьшее b, затем наименьшее c, — или вывести −1, если их нет.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число n.

## Выходные данные

a, b и c или −1.

## Проверка

Тесты репозитория точно сравнивают токены вывода; пробельные разделители между ними несущественны.

## Примеры

### Пример 1

Ввод:

```
0
```

Вывод:

```
-1
```

### Пример 2

Ввод:

```
1
```

Вывод:

```
1 2 3
```

## Решение

- n = 0: любая степень равна 1, а 1 + 1 никогда не 1, так что ответа нет.
- n = 1: a + b = c, и наименьший вариант с тремя различными числами —
  1 2 3.
- n = 2: наименьшая пифагорова тройка, 3 4 5, первая в нужном порядке.
- n ≥ 3: по великой теореме Ферма у aⁿ + bⁿ = cⁿ нет решений в
  натуральных числах.

`O(1)`.

Тонкие места:

- при n = 0 ответа нет, хотя все степени равны (тест 01);
- числа должны быть различны, что исключает ответы вроде 1 1 2 при
  n = 1.

Перебор всех троек до 100 для n от 0 до 5 дал те же ответы.

## Оптимизированные решения

`1349_math_optimized.py`. Сохраняется полный разбор математических случаев: положительные решения есть только для степеней один и два, минимальные тройки — 1,2,3 и 3,4,5; степень ноль и степени больше двух решений не имеют. Единственный десятичный токен нормализуется удалением внешних пробелов, необязательного плюса и ведущих нулей; байты сравниваются с 1 и 2 без создания int и словаря ответов. Полный фиксированный ответ записывается до os._exit(0). Разбор требует O(I) для I байт ввода, математическая работа константна; таблицы произвольных готовых ответов нет. Новый CPython — 0.062 с/644 КБ против прежнего PyPy 0.109 с/172 КБ; рост памяти указан явно, учебная версия сохранена.

Точный исходник: Python 3.12 x64 Accepted #11327873: 0.062 s / 644 KB. Сохранённые места в группе компилятора от 2026-11-20, время затем память: 5/130; 98/130. Строгий допуск учитывает только время при памяти меньше 1024 КБ: первые десять или топ 15%, равенства делят место, процентный порог округляется вверх. Звёздочка остаётся для отдельной цели языка — первого места по обеим метрикам. Сохранённый прежний вариант имеет собственную парную посылку #11325067 (PyPy 3.10 x64): 0.109 s / 172 KB; замеры и рантаймы не смешиваются. Все учебные исходники сохранены без изменений.

- `1349_math_optimized.py`: 0.062 s / 644 KB; сохранённая учебная база `1349_math.py`: 0.093 s / 336 KB.

Оптимизированные решения печатают те же три ответа. Java разбирает
показатель степени вручную через `System.in.read` вместо `Scanner`:

байтовой строкой через `write_all` вместо `println!`: 0.031 с вместо
0.062 с и 212 КБ вместо 232 КБ.

## Особенности языков

Новые исходники сравниваются по срезу от 18 ноября 2026 года с другими авторами на текущих компиляторах судьи. Порогов по ID посылки или дате нет. Ничьи делят место, времена меньше 0.015 с при сравнении считаются 0.015 с. Приведённые ниже места относятся к новым версиям; прежние исходники сохраняют собственные исторические метрики Accepted.

Звёздочка означает недостигнутую рейтинговую цель: для C++ нужны первые десять мест либо топ 15% одновременно по обеим метрикам; для остальных семейств — первое место по обеим. Отдельный критерий допуска может выполняться по рейтингу или улучшению, в том числе при снижении времени либо памяти минимум на 30%.
