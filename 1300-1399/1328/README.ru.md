# 1328. Файрболл

[Timus 1328](https://acm.timus.ru/problem.aspx?space=1&num=1328) · сложность 1400 · geometry

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Прямоугольная комната занимает область от (0, 0) до (W, H),
2 ≤ W, H ≤ 1000. Брошенная из A точка летит по прямой и отскакивает от
стен по закону «угол падения равен углу отражения». Попадание точно в
угол отбрасывает её строго назад и считается за два отскока. Нужно
найти направление броска из A, при котором точка попадёт в B ровно
после N отскоков, 0 ≤ N ≤ 10, по кратчайшему такому пути. Среди
одинаково коротких путей выводится наименьший угол. A и B лежат внутри
комнаты, все числа целые. До последнего отскока точка пролетает
сквозь всё, кроме стен, в том числе сквозь мишень.

Угол — в градусах, против часовой стрелки от направления оси x, от 0 до
360, с двумя знаками после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

W и H, затем N, затем координаты A и B.

## Выходные данные

Угол.

## Примеры

### Пример 1

Ввод:

```
1000 10
3
101 5 128 8
```

Вывод:

```
45.00
```

## Решение

Отражать будем комнату, а не путь. Если раз за разом зеркально
отражать комнату через её стены, она замостит плоскость, а путь с
отскоками станет прямой через копии. В копии (i, j), на i комнат вбок и
j комнат вверх, лежит образ B в точке

x = i · W + (Bx при чётном i, иначе W − Bx),
y = j · H + (By при чётном j, иначе H − By),

и прямая из A к нему пересекает |i| вертикальных и |j| горизонтальных
стен, то есть отскакивает |i| + |j| раз. Угол — это вертикальная и
горизонтальная стена сразу, что согласуется с правилом считать его
дважды, а отражение в обеих стенах — это и есть отражение строго назад.

Значит, кандидаты — 4N образов с |i| + |j| = N (один при N = 0); они
сравниваются по квадрату длины, точно в целых числах, а затем по углу.
Прямая может по пути пройти через образ с меньшим числом отскоков, но
это значит лишь, что точка пролетает сквозь мишень до последнего
отскока, что ей ничем не грозит. `O(N)`.

Тонкие места:

- кратчайший путь может пересекать мишень до последнего отскока: в
  комнате 2 на 2 с мишенью в центре диагональ проходит сквозь неё между
  каждыми двумя углами и всё равно побеждает (тест 08);
- мишень может стоять там же, где бросающий, и тогда пути одинаковой
  длины уходят в нескольких направлениях (тест 05);
- бросок в угол — это два отскока (тест 06);
- угол берётся от 0 до 360, поэтому к отрицательному результату atan2
  прибавляется 360 (тест 03).

Ответы сравнивались с моделированием, которое прослеживает каждый
отскок точными дробями для всех направлений на образы в пределах N + 1
комнат, на 600 случайных небольших комнатах, и с независимой программой
на 300 случайных комнатах.
