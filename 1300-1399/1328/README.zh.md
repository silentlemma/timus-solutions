# 1328. 火球

[Timus 1328](https://acm.timus.ru/problem.aspx?space=1&num=1328) · 难度 1400 · geometry

原题作者 Pavel Egorov，出自 2004 年 10 月 16 日第十届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

矩形房间从 (0, 0) 延伸到 (W, H)，2 ≤ W, H ≤ 1000。从 A 抛出的点沿直线运动，按“入射角等于反射角”在墙上
反弹。恰好击中墙角时它会原路弹回，并算作两次反弹。求从 A 抛出的方向，使它在恰好 N 次反弹后（0 ≤ N ≤ 10）
沿最短的这种路径到达 B。若有多条同样短的路径，输出最小的角度。A 和 B 在房间内部，所有数都是整数。在最后一次反弹之前，这个点
会穿过除墙以外的一切，包括目标。

角度以度为单位，从 x 轴方向逆时针计量，范围是 0 到 360，保留小数点后两位。

时间限制：1 秒。内存限制：64 MB。

## 输入

W 和 H，然后是 N，然后是 A 和 B 的坐标。

## 输出

角度。

## 样例

### 样例 1

输入：

```
1000 10
3
101 5 128 8
```

输出：

```
45.00
```

## 解法

反射房间而不是路径。把房间沿墙一次次镜像，就铺满了平面，带反弹的路径变成穿过各个副本的直线。副本 (i, j)
（横向第 i 间、纵向第 j 间）中 B 的像位于

x = i · W + (i 为偶数时取 Bx，否则取 W − Bx)，
y = j · H + (j 为偶数时取 By，否则取 H − By)，

从 A 到它的直线穿过 |i| 面竖墙和 |j| 面横墙，即反弹 |i| + |j| 次。墙角同时是一面竖墙和一面横墙，这与“算作
两次”的规则一致，而在两面墙中各镜像一次，正好就是原路弹回。

所以候选是满足 |i| + |j| = N 的 4N 个像（N = 0 时只有一个），先按长度的平方（用整数精确比较）、再按角度
比较。直线可能在途中经过反弹次数更少的像，但这只意味着这个点在最后一次反弹前穿过了目标，这对它毫无影响。
`O(N)`。

注意事项：

- 最短路径可能在最后一次反弹前穿过目标：在 2 乘 2、目标居中的房间里，对角线在每两个墙角之间都穿过目标，
  仍然是最优的（测试 08）；
- 目标可能就在抛出者的位置，这时同样长的路径会朝几个方向出发（测试 05）；
- 射向墙角算两次反弹（测试 06）；
- 角度在 0 到 360 之间，所以 atan2 的负结果要加 360（测试 03）。

在 600 个随机的小房间上，与一种模拟比较过：对 N + 1 间房以内每个像的方向，用精确分数逐次跟踪反弹；还在
300 个随机房间上与一个独立程序比较过。

- C++、Go、Python 和 Rust 使用 atan2 · 180 / π；Java 使用 Math.toDegrees。
