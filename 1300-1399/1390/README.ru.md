# 1390. Выстрелы по стенам

[Timus 1390](https://acm.timus.ru/problem.aspx?space=1&num=1390) · сложность 8198 · geometry

Автор оригинальной задачи — Андрей Румянцев; Петрозаводские летние сборы, август 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

События происходят по порядку. Стена — отрезок, прямая
которого не проходит через начало координат; стены могут
пересекаться. Выстрел делается из начала координат с ненулевой
скоростью (vx, vy), и пуля летит прямо с постоянной скоростью. Для
каждого выстрела нужно вывести время до первого попадания в стену,
построенную раньше него, или Infinite. Координаты стен и компоненты
скорости — целые числа не больше 10 000 по модулю.

Ограничение времени: 3 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Строки «shot vx vy» и «wall x1 y1 x2 y2», в конце «end».
Всего не более 50 000 строк, включая «end».

## Выходные данные

Для каждого выстрела время полёта с погрешностью до 10⁻⁶ или
Infinite.

## Решение

Запишем прямую стены как n · p = c с c > 0. Пуля со скоростью v
достигает прямой в момент c / (n · v), так что ближайшая стена в
данном направлении — та, у которой (n · v) / c наибольшее среди стен,
покрывающих это направление. Стена покрывает направления от одного
конца до другого — дугу меньше π. Для двух стен разность (n · v) / c
по единичным векторам v — синусоида, которая на такой дуге меняет знак
не больше одного раза.

Это условие для дерева Ли Чао. Сначала читаем все события, листьями
берём различные направления выстрелов по углу и обрабатываем события
по порядку. Стена добавляется на отрезок листьев, который она
покрывает, разбитый на два при пересечении положительной полуоси x
(в Python — отрицательной): в каждой полностью покрытой вершине
остаётся стена, лучшая в середине, а другая спускается в ту половину,
где ещё может победить. Выстрел идёт от корня к своему листу и берёт
лучшую встреченную стену. Стены сравниваются точно: (n₁ · v)·c₂ против
(n₂ · v)·c₁ в 64-битных целых (в Python — произвольной точности), а
время c / (n · v) выводится точным целочисленным делением с девятью
знаками. `O(n log² n)`.

Подводные камни:

- пуля, задевшая конец стены, в неё попадает (тест 04);
- стена через границу углового порядка покрывает оба края
  отсортированных направлений (тесты 05, 10);
- одно направление встречается с разными скоростями, поэтому листья —
  направления, а время считается по скорости выстрела (тест 07);
- более поздняя дальняя стена не закрывает более раннюю ближнюю
  (тест 06), а стены могут пересекаться;
- стены без единого выстрела всё равно нужно прочитать (тест 02).

Ответы сравнивались с проверкой каждой стены для каждого выстрела в
точных дробях на 400 маленьких случайных наборах и в целых числах на
всех сгенерированных тестах.
