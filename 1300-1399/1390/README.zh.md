# 1390. 向墙射击

[Timus 1390](https://acm.timus.ru/problem.aspx?space=1&num=1390) · 难度 8947 · geometry

原题作者 Andrew Rumyantsev，出自 2005 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

按顺序发生至多 50 000 个事件。墙是一条线段，其所在直线不经过原点；墙可以
相交。射击从原点以非零速度 (vx, vy) 进行，子弹以恒定速度直线飞行。对每次
射击，输出子弹击中在它之前建好的最近一堵墙所需的时间，或 Infinite。所有坐
标都是绝对值不超过 10 000 的整数。

时间限制：3 秒。内存限制：64 MB。

## 输入

若干行 "shot vx vy" 和 "wall x1 y1 x2 y2"，以 "end" 结束。

## 输出

每次射击的飞行时间，误差不超过 10⁻⁶，或 Infinite。

## 解法

把墙所在直线写成 n · p = c，且 c > 0。速度为 v 的子弹在时刻 c / (n · v)
到达该直线，所以某方向上最近的墙，就是覆盖该方向的墙中 (n · v) / c 最大的
那一堵。一堵墙覆盖从一个端点到另一个端点的方向，是一段小于 π 的弧。对两堵
墙，(n · v) / c 之差在单位向量 v 上是一条正弦曲线，在这样的弧上至多变号一
次。

这正是李超树的条件。先读入所有事件，把不同的射击方向按角度排序作为叶子，
再按顺序处理事件。墙插入到它覆盖的叶子区间上，若跨过 x 轴正方向就拆成两
段：在区间的每个节点中，留下在中点更优的墙，另一堵下沉到它仍可能胜出的那
一半。射击从叶子走到根，取途中遇到的最优墙。墙之间用 64 位整数精确比较
(n₁ · v)·c₂ 与 (n₂ · v)·c₁，时间 c / (n · v) 用精确整数除法输出九位小数。
`O(n log² n)`。

注意事项：

- 擦到墙端点的子弹也算击中（测试 04）；
- 跨过 x 轴正方向的墙覆盖排序后方向的两端（测试 05）；
- 同一方向会以不同速度出现，所以叶子是方向，时间按该次射击的速度计算（测
  试 07）；
- 后建的较远墙不会挡住先建的较近墙（测试 06），墙也可能相交；
- 即使没有射击，也要读完所有墙（测试 02）。

在 400 组小型随机数据上与逐墙逐次射击的精确分数检查做了比较，所有生成测试
也用整数做了同样的比较。
