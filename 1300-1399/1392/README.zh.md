# 1392. 向往星空

[Timus 1392](https://acm.timus.ru/problem.aspx?space=1&num=1392) · 难度 763 · graphs

原题作者 Fedor Fominykh，出自 2005 年 4 月新乌拉尔斯克市第一届中学生团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

K ≤ 1000 颗行星都是球，球心和半径都是绝对值不超过 1000 的整数。两颗行星若
至少有两个公共点就粘在一起；群岛是由粘连对连成链的一组行星，且没有其他行
星粘到这组上。输出所有群岛。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

K，然后 K 行，每行 x、y、z 和 R。

## 输出

每个群岛一行，按升序列出其行星编号（从 0 开始），用逗号加空格分隔；群岛按其
最小行星编号排序。

## 样例

### 样例 1

输入:

```
2
1 1 1 1
1 3 1 1
```

输出:

```
0
1
```

### 样例 2

输入:

```
3
1 1 1 1
1 3 1 1
1 4 1 1
```

输出:

```
0
1, 2
```

### 样例 3

输入:

```
3
1000 1000 1000 1
 999 1000 1000 1
   1    1    1 1
```

输出:

```
0, 1
2
```

## 解法

两个实心球有不止一个公共点，当且仅当它们相交，即球心距离小于 r₁ + r₂；相等
时只是相切。用整数表示就是 dx² + dy² + dz² < (r₁ + r₂)²，完全没有舍入。群岛
就是这个关系的连通分量：检查所有球对，用并查集合并相交的球。然后按升序把行
星按根归组，再按每组第一颗行星排序。`O(K²)`。

注意事项：

- 只在一点相切的球不算粘连（样例 1 和 2，测试 06）；
- 在另一个球内部的球，即使从内部相切，也与之粘连（测试 05）；
- 乱序给出的一条链仍是一个群岛（测试 04）；
- 分隔符是逗号加空格，最后一颗行星后面没有。

测试按精确比较判定。
