# 1392. Тяга к звёздам

[Timus 1392](https://acm.timus.ru/problem.aspx?space=1&num=1392) · сложность 763 · graphs

Автор оригинальной задачи — Фёдор Фоминых; первая командная олимпиада школьников города Новоуральска по программированию, апрель 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

K ≤ 1000 планет — шары с целыми центрами и радиусами не больше 1000 по
модулю. Две планеты слиплись, если у них есть хотя бы две общие точки,
а архипелаг — группа планет, связанных цепочками слипшихся пар, к
которой не прилипла ни одна другая планета. Нужно вывести архипелаги.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

K, затем K строк с x, y, z и R.

## Выходные данные

По строке на архипелаг с номерами его планет с нуля по возрастанию
через запятую и пробел; архипелаги упорядочены по наименьшей планете.

## Примеры

### Пример 1

Ввод:

```
2
1 1 1 1
1 3 1 1
```

Вывод:

```
0
1
```

### Пример 2

Ввод:

```
3
1 1 1 1
1 3 1 1
1 4 1 1
```

Вывод:

```
0
1, 2
```

### Пример 3

Ввод:

```
3
1000 1000 1000 1
 999 1000 1000 1
   1    1    1 1
```

Вывод:

```
0, 1
2
```

## Решение

Два сплошных шара имеют больше одной общей точки ровно тогда, когда они
пересекаются, то есть расстояние между центрами меньше r₁ + r₂; при
равенстве они лишь касаются. В целых числах это
dx² + dy² + dz² < (r₁ + r₂)², без всякого округления. Архипелаги —
компоненты связности этого отношения: проверяем все пары и объединяем
пересекающиеся в системе непересекающихся множеств. Затем собираем
планеты по корню в порядке возрастания и сортируем группы по первой
планете. `O(K²)`.

Подводные камни:

- шары, касающиеся в одной точке, не слиплись (примеры 1 и 2, тест 06);
- шар внутри другого, даже касающийся его изнутри, к нему прилип
  (тест 05);
- цепочка, заданная вразнобой, всё равно один архипелаг (тест 04);
- разделитель — запятая и пробел, после последней планеты его нет.

Тесты проверяются точным сравнением.
