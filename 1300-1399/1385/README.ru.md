# 1385. Интересное число

## Задача

Число из 2N цифр без ведущего нуля называется интересным, если оно
делится и на число из своих первых N цифр, и на число из последних N
цифр. Нужно посчитать интересные числа из 2N цифр, 1 ≤ N ≤ 10 000.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число N.

## Выходные данные

Количество.

## Примеры

### Пример 1

Ввод:

```
1
```

Вывод:

```
14
```

Эти четырнадцать чисел: 11, 12, 15, 22, 24, 33, 36, 44, 48, 55, 66, 77,
88 и 99.

## Решение

Запишем число как A·10ᴺ + B, где в A ровно N цифр, а B < 10ᴺ. A делит
число тогда и только тогда, когда делит B, поэтому B = kA, а из
B < 10ᴺ ≤ 10A остаётся k от 1 до 9 (B = 0 ни на что делить нельзя).
Дальше B делит число, когда kA делит A·10ᴺ, то есть когда k делит 10ᴺ:
k равно 1, 2 или 5, а ещё 4 начиная с N = 2 и 8 начиная с N = 3. Для
каждого k число A идёт от 10ᴺ⁻¹, пока kA < 10ᴺ, и даёт ⌈10ᴺ/k⌉ − 10ᴺ⁻¹
чисел.

Итак, ответ — 14 при N = 1 и 155 при N = 2. Начиная с N = 3 это
900 + 400 + 150 + 100 + 25 = 1575, умноженное на 10ᴺ⁻³: цифры 1575 и
N − 3 нуля. `O(N)` на вывод.

Подводные камни:

- в ответе до 10 001 цифры, поэтому он выводится строкой (тест 05);
- 4 и 8 не делят 10 и 100, так что N = 1 и N = 2 — особые случаи
  (тесты 01 и 02).

Ответы для N до 3 проверены перебором всех чисел.
