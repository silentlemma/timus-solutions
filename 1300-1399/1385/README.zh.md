# 1385. 有趣的数

[Timus 1385](https://acm.timus.ru/problem.aspx?space=1&num=1385) · 难度 246 · math

原题作者 Alexander Ipatov，出自 2005 年 8 月彼得罗扎沃茨克夏季集训。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个没有前导零的 2N 位数，如果它既能被前 N 位组成的数整除，又能被后 N 位
组成的数整除，就称为有趣的数。求 2N 位有趣数的个数，1 ≤ N ≤ 10 000。

时间限制：1 秒。内存限制：64 MB。

## 输入

数 N。

## 输出

个数。

## 样例

### 样例 1

输入:

```
1
```

输出:

```
14
```

这十四个数是 11、12、15、22、24、33、36、44、48、55、66、77、88 和 99。

## 解法

把数写成 A·10ᴺ + B，其中 A 恰有 N 位，B < 10ᴺ。A 整除该数当且仅当 A 整除
B，所以 B = kA；由 B < 10ᴺ ≤ 10A，k 只能取 1 到 9（B = 0 不能作除数）。
B 整除该数当且仅当 kA 整除 A·10ᴺ，即 k 整除 10ᴺ：k 为 1、2 或 5，N ≥ 2 时
还有 4，N ≥ 3 时还有 8。对每个 k，A 从 10ᴺ⁻¹ 开始，只要 kA < 10ᴺ，共
⌈10ᴺ/k⌉ − 10ᴺ⁻¹ 个。

所以 N = 1 时答案为 14，N = 2 时为 155。从 N = 3 起答案是
900 + 400 + 150 + 100 + 25 = 1575 乘以 10ᴺ⁻³：即数字 1575 后接 N − 3 个零。
输出需要 `O(N)`。

注意事项：

- 答案最多有 10 001 位，所以按字符串输出（测试 05）；
- 4 和 8 不整除 10 和 100，所以 N = 1 和 N = 2 是特殊情形（测试 01 和
  02）。

N 不超过 3 的答案已通过枚举所有数验证。
