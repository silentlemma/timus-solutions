## Задача

Ориентированный граф называется красивым, если в нём N вершин и N − 1
дуга, ровно одна вершина без входящих дуг и нет ориентированных
циклов. Нужно посчитать красивые графы с N вершинами, 1 ≤ N ≤ 50, с
точностью до перенумерации вершин.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число N.

## Выходные данные

Количество различных красивых графов.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
5
```

Вывод:

```
9
```

## Решение

У каждой вершины, кроме источника, есть хотя бы одна входящая дуга, а
дуг всего N − 1, значит, у каждой ровно одна. Без циклов путь назад по
этим дугам всегда приходит в источник: красивый граф — это корневое
дерево с дугами от корня. Поэтому ответ — число a(N) непомеченных
корневых деревьев.

Если убрать корень, остаётся мультимножество меньших корневых деревьев,
и подсчёт таких мультимножеств даёт классическую формулу

a(1) = 1, a(m + 1) = (s(1)·a(m) + s(2)·a(m − 1) + … + s(m)·a(1)) / m,

где s(k) — сумма d·a(d) по делителям d числа k. Деление всегда
нацело. `O(N²)` операций с числами.

Подводные камни:

- a(50) = 425 976 989 835 141 038 353 не помещается в 64 бита; сумма перед
  делением переполняет знаковые 64 бита с N = 43, беззнаковые — с N = 44
  (тесты 18 и 19), поэтому решения используют 128-битные или длинные числа;
- порядок дочерних поддеревьев не важен; a(8) равно 115 (тест 06).

Первые девять ответов проверены построением всех деревьев из меньших с
отбором различных канонических строк.
