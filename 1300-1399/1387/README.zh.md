# 1387. 瓦夏的爸爸

## 任务

如果一个有向图有 N 个顶点和 N − 1 条弧，恰有一个顶点没有入弧，且没有有向
环，就称它为漂亮的图。在顶点重新编号意义下，求 N 个顶点的漂亮图的个数，
1 ≤ N ≤ 50。

时间限制：1 秒。内存限制：64 MB。

## 输入

数 N。

## 输出

不同漂亮图的个数。

## 样例

### 样例 1

输入:

```
3
```

输出:

```
2
```

### 样例 2

输入:

```
5
```

输出:

```
9
```

## 解法

除源点外每个顶点至少有一条入弧，而弧只有 N − 1 条，所以每个顶点恰有一条。
没有环时，沿这些弧倒着走总会回到源点：漂亮图就是弧从根指向外的有根树。
所以答案是无标号有根树的个数 a(N)。

去掉根后剩下一个由较小有根树组成的多重集，计数这样的多重集得到经典递推式

a(1) = 1，a(m + 1) = (s(1)·a(m) + s(2)·a(m − 1) + … + s(m)·a(1)) / m，

其中 s(k) 是 k 的所有因数 d 上 d·a(d) 之和。除法总是整除。共 `O(N²)` 次数
值运算。

注意事项：

- a(50) = 425 976 989 835 141 038 353 超出 64 位；除法前的和从 N = 43 起
  超出有符号 64 位，从 N = 44 起超出无符号 64 位（测试 18 和 19），所以解答
  使用 128 位整数或大整数；
- 子树的顺序不影响计数；a(8) 是 115（测试 06）。

前九个答案已通过由较小的树构造所有树并保留不同的规范字符串来验证。
