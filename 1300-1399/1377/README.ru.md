# 1377. Расстояние между клетками по прямоугольной спирали

[Timus 1377](https://acm.timus.ru/problem.aspx?space=1&num=1377) · сложность 295 · simulation

Автор оригинальной задачи — Станислав Васильев; IX командный студенческий чемпионат Урала по программированию, Екатеринбург, 19–24 апреля 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Обойдите сетку `N × M`, `2 ≤ N,M ≤ 100`, начиная с `(1,1)` вправо.
Двигайтесь прямо, пока следующая клетка находится в сетке и ещё не посещена;
иначе поворачивайте по часовой стрелке. Даны две различные клетки — номера
строки и столбца в пределах сетки. Найдите модуль разности их номеров в
порядке обхода. Время: 1 секунда. Память: 64 МБ.

## Входные данные

`N M`, затем `r₁ c₁` и `r₂ c₂`; индексация с единицы.

## Выходные данные

Модуль разности номеров посещения.

## Проверка

Целочисленные ответы сравниваются по токенам, разделённым пробелами.

## Примеры

### Пример 1

Ввод:

```
5 4
2 2
5 3
```

Вывод:

```
6
```

## Решение

Смоделируем спираль по часовой стрелке. Пометим внешнюю рамку как уже
посещённую, будем нумеровать клетки при входе и поворачивать вправо,
когда следующая клетка уже посещена. Каждый шаг посещает новую клетку,
а рамка не даёт выйти из сетки. Ответ — модуль разности двух номеров.
Время и память — `O(N·M)`. Порядок заданных клеток произволен; узкие сетки
и последняя строка или колонка обрабатываются теми же правилами.

## Оптимизированные решения

Для клетки `(r,c)` с нулевой индексацией номер слоя равен
`d = min(r,c,N−1−r,M−1−c)`. После удаления внешних `d` слоёв остаётся
прямоугольник высоты `h=N−2d` и ширины `w=M−2d`; перед ним посещено
ровно `N·M−h·w` клеток. Вычтем `d` из координат. Смещение по периметру
равно `c` на верхней стороне, `w−1+r` на правой,
`w−1+h−1+w−1−c` на нижней и `2(h+w−2)−r` на левой; стороны проверяем
именно в этом порядке. Если осталась одна строка или колонка, смещение
равно `c` или `r`. Так каждая клетка получает единственный номер в порядке
спирали. Ответ — модуль разности двух номеров. Время и память — `O(1)`.

Неизменённые симуляции остаются простыми версиями. Формула уменьшила
память на 57,8% в C++, 73,4% в Java и 50,2% в Python; время Go снизилось
с 0,046 до 0,015 с (на 67,4%). C++ и Java достигли рейтинговой цели в срезе
от 1 ноября 2026 года. Python занимает третье место по времени и первое
по памяти, не достигая более строгой цели первого места для этого языка:
его строка отмечена звёздочкой. В выборке Go нет конкурентов. Формула Rust
сэкономила только 25% памяти и один тик времени, поэтому отдельный
оптимизированный исходник не добавляется. Формулы слоёв сверены с отдельно
построенной спиралью, включая последние полосы и все клетки малых сеток.
