# 1377. Лара Крофт

[Timus 1377](https://acm.timus.ru/problem.aspx?space=1&num=1377) · сложность 295 · simulation

Автор оригинальной задачи — Станислав Васильев; IX командный студенческий чемпионат Урала по программированию, Екатеринбург, 19–24 апреля 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На кладбище N рядов по M могил, 2 ≤ N, M ≤ 100. Каждую ночь Лара
прокапывается под одну могилу, начиная с (1, 1) на восток: ход идёт
прямо, пока следующая могила цела, и поворачивает направо перед стеной
или уже разорённой могилой. В двух заданных могилах лежат сокровища, и
одно из них Лара только что нашла. Нужно вывести, через сколько ночей
будет найдено второе.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем две могилы с сокровищами (r₁, c₁) и (r₂, c₂).

## Выходные данные

Число ночей между двумя находками.

## Примеры

### Пример 1

Ввод:

```
5 4
2 2
5 3
```

Вывод:

```
6
```

## Решение

Ход — та же спираль по часовой стрелке, что и в
[1364](../1364/README.ru.md). Прокапываем её целиком, нумеруя каждую
могилу ночью, когда её разорили, а вместо стены окружаем кладбище
рамкой «разорённых» клеток. Ответ — разность двух номеров без знака,
ведь первым может оказаться любое из сокровищ. `O(N · M)`.

Тонкие места:

- сокровища могут быть перечислены в любом порядке (тест 03);
- первую и последнюю могилу кладбища 100 × 100 разделяют 9 999 ночей
  (тест 04);
- на кладбище из двух столбцов спираль идёт вниз по одному столбцу и
  обратно вверх по другому (тест 07).
