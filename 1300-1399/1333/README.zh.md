# 1333. 精灵轰炸 2

[Timus 1333](https://acm.timus.ru/problem.aspx?space=1&num=1333) · 难度 219 · geometry

原题作者 Den Raskovalov，出自 2004 年 10 月 16 日第十届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

最多 10 枚炸弹落在单位正方形 0 ≤ x, y ≤ 1 上。每枚炸弹击中一个圆心为 (x, y)、半径为 r 的圆，这些数都在 0 到
1 之间。输出正方形中至少被一枚炸弹击中的部分所占的百分比，误差不超过一个百分点。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后 N 行 x、y 和 r。

## 输出

正方形被击中部分的百分比。

## 检查

输出百分数。题目精度为1个百分点；仓库本地检查使用
`|actual−expected|≤0.01·max(1,|expected|)`，这与通用积分误差界是两件事。
每个候选通过12个仓库输入和206个额外完整Docker输入，并有精确SHA的自身
Accepted。独立预言机用自适应上下矩形包络，界定单元内所有截面，并使用
整圆/半圆/四分之一圆解析面积，不复用候选中点网格。此数据集相对包络端点
最大误差小于0.004001个百分点，并非通用实测保证。覆盖空集、零半径、边界
截取、包含重复、近相切、极小圆及两样例。

## 样例

### 样例 1

输入：


输出：

```

```

### 样例 2

```

```

## 解法

固定 x 时，圆 `(cx,cy,r)` 在 `|x−cx|<r` 时产生竖直区间
`cy±sqrt(r²−(x−cx)²)`，截到 `[0,1]`。按下端排序，扫描时只增加超过当前
最远上端的部分，得到并集长度 f(x)，重叠、重复、包含仅计一次；零半径无面积。
答案为 `100∫₀¹ f(x)dx`。五份简单源码用 S=20000 等宽条带的中点，
`area≈Σ f((k+1/2)/S)/S`，时间 `O(SN log N)`、额外空间 O(N) 加输入输出。
五份 Accepted 源码逐字节保留。

可证明误差而非依靠样本猜测。单圆区间在中心前按包含关系扩大、之后缩小，
对称差长度的总变化至多4r；截取不会增大变化。并集的变化包含于各区间变化
的并集，故 f 总变差至多 `4Σr`。宽 h 的条带上，相对中点值的积分误差至多
h/2 乘该条带变差，因为左/右每次变化影响不超过半条带。相加得
`|area−midpoint|≤2Σr/S`。N≤10,r≤1、S=20000 时，精确算术下至多0.1个百分点，
满足题目1个百分点要求。

## 优化解法

同一中点/区间并集算法改用 S=4096，误差界为
`100·20/4096=0.48828125` 个百分点，小于1，涵盖截取、重叠、窄圆及相切。
随机测试良好不能替代减少条带数的证明。六位小数输出另加至多0.0000005
个百分点舍入误差。使用 double，先比较平方，不对非正被开方数求根。

半径平方只算一次。C++/Go/Java复用有限区间数组、插入排序，避免每条带
对象或反射分配，`O(SN²)` 时间、O(N)空间。Python仍排序，`O(SN log N)`
时间、O(N)空间。这是同算法的实现改进，因此用 `_optimized`。
C++以内存减少39.3%准入，0.031→0.015秒只是一个计时刻度，不作可靠加速证据。
Go时间/内存改善67.4%/81.2%，Java50.3%/90.9%。Python时间改善30.1%
（0.156→0.109秒），内存反增11.9%（504→564KB），只按时间准入并带排名星号。
Rust时间不变，内存仅少1.5%（268→264KB），不添加该候选；旧Rust已在空竞争
样本中形式达标。
