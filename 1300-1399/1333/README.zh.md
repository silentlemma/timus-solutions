# 1333. 精灵轰炸 2

[Timus 1333](https://acm.timus.ru/problem.aspx?space=1&num=1333) · 难度 219 · geometry

原题作者 Den Raskovalov，出自 2004 年 10 月 16 日第十届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

最多 10 枚炸弹落在单位正方形 0 ≤ x, y ≤ 1 上。每枚炸弹击中一个圆心为 (x, y)、半径为 r 的圆，这些数都在 0 到
1 之间。输出正方形中至少被一枚炸弹击中的部分所占的百分比，误差不超过一个百分点。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后 N 行 x、y 和 r。

## 输出

正方形被击中部分的百分比。

## 检查

我们的测试接受与期望答案相差不超过 0.01 的结果。题面中的样例本身也有少许舍入：第二个约为 80.746，而不是
80.743。

## 样例

### 样例 1

输入：

```
1
0.5 0.5 0.5
```

输出：

```
78.539816
```

### 样例 2

输入：

```
2
0.2 0.2 0.5
0.8 0.8 0.5
```

输出：

```
80.74292
```

## 解法

把正方形切成 20 000 条细竖条，取每条中线。在这条直线上，每个圆覆盖 y 的一个区间，并截到 [0, 1] 内。把区间
排序后依次走一遍，就得到它们并集的长度。这些长度之和乘以竖条宽度就是被击中的面积。S 条竖条时为
`O(S · N log N)`。

误差只来自圆的边缘，那里弦长变化很快。即便如此，这里的误差也只有 10⁻⁵ 个百分点左右：用一百万条竖条时，第二个
样例的变化小于 10⁻⁵。这远在允许的一个百分点之内，所以不需要圆并集面积的精确公式。

注意事项：

- 圆可能伸出正方形，只计算正方形内的部分（测试 02 和 05）；
- 圆可能重复或互相包含，并集中这样的面积只能算一次（测试 07）；
- 可能根本没有炸弹，或者炸弹半径为 0（测试 03 和 06）。

在 60 个随机例子上，与对 700 × 700 网格点计数的结果比较过，最大差距为 0.005 个百分点。
