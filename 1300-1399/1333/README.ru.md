# 1333. Джинн-бомбардировки 2

[Timus 1333](https://acm.timus.ru/problem.aspx?space=1&num=1333) · сложность 218 · geometry

Автор оригинальной задачи — Ден Расковалов; X командный чемпионат школьников Свердловской области по программированию, 16 октября 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

До 10 бомб падают на единичный квадрат 0 ≤ x, y ≤ 1. Каждая поражает
круг с центром (x, y) и радиусом r, все числа от 0 до 1. Нужно вывести
долю квадрата, поражённую хотя бы одной бомбой, в процентах, с ошибкой
не больше одного процента.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк с x, y и r.

## Выходные данные

Процент поражённой площади квадрата.

## Проверка

Наши тесты принимают ответы в пределах 0.01 от ожидаемого. Примеры из
условия сами немного округлены: второй примерно равен 80.746, а не
80.743.

## Примеры

### Пример 1

Ввод:

```
1
0.5 0.5 0.5
```

Вывод:

```
78.539816
```

### Пример 2

Ввод:

```
2
0.2 0.2 0.5
0.8 0.8 0.5
```

Вывод:

```
80.74292
```

## Решение

Разрежем квадрат на 20 000 тонких вертикальных полос и возьмём прямую
через середину каждой. На этой прямой каждый круг покрывает один
отрезок по y, обрезанный до [0, 1]. Если отсортировать отрезки и пройти
по ним, получится длина их объединения. Сумма этих длин, умноженная на
ширину полосы, — это поражённая площадь. `O(S · N log N)` для S полос.

Ошибка возникает только у краёв кругов, где длина хорды быстро
меняется. Даже так она здесь порядка 10⁻⁵ процента: при миллионе полос
второй пример меняется меньше чем на 10⁻⁵. Это далеко в пределах
допустимого процента, так что точная формула для объединения кругов не
нужна.

Тонкие места:

- круги могут выходить за квадрат, и считается только часть внутри
  (тесты 02 и 05);
- круги могут повторяться или лежать друг в друге, и объединение должно
  считать такую площадь один раз (тест 07);
- бомб может не быть вовсе или у них может быть радиус 0 (тесты 03
  и 06).

Ответы сравнивались с подсчётом по сетке 700 × 700 точек на 60
случайных примерах; наибольшее расхождение — 0.005 процента.
