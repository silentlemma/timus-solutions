# 1386. И снова лабиринт

[Timus 1386](https://acm.timus.ru/problem.aspx?space=1&num=1386) · сложность 1157 · simulation

Автор оригинальной задачи — Андрей Халявин; Петрозаводские летние сборы, август 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Лабиринт — поле N × M, 1 ≤ N, M ≤ 100, с четырьмя командами. Для
каждой клетки и команды карта задаёт клетку, куда переходит игрок. С
какой клетки игрок начал, неизвестно, но все S ≤ 4000 команд игры
известны. Нужно вывести все клетки, где игрок может стоять сейчас.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем четыре блока, по одному на команду, из N строк по M пар:
пара в столбце i строки j блока k — клетка, куда ведёт команда k из
клетки (j, i). Затем S и S команд.

## Выходные данные

Число клеток, затем сами клетки по возрастанию строки, а затем
столбца.

## Примеры

### Пример 1

Ввод:

```
2 3
1 2  1 3  1 3
2 2  2 3  2 3
2 1  2 2  2 3
2 1  2 2  2 3
1 1  1 1  1 2
2 1  2 1  2 2
1 1  1 2  1 3
1 1  1 2  1 3
4
1 2 3 4
```

Вывод:

```
2
1 1
1 2
```

## Решение

Храним множество клеток, где может быть игрок, — сначала всё поле — и
пропускаем его через каждую команду. Несколько клеток могут вести в
одну, поэтому новое множество хранит каждую клетку один раз: клетка
добавляется, только если её отметка ещё не равна текущему шагу.
Множество никогда не растёт, так что шаг стоит не больше N·M
обращений. `O(S·N·M)`, в худшем случае 4·10⁷ простых шагов.

Подводные камни:

- карты могут быть перестановками, как на торе, и тогда ничего не
  сливается: каждый шаг проходит все 10 000 клеток (сгенерированные
  тесты 1 и 3);
- ограничение по времени — полсекунды, поэтому клетки нумеруются одним
  индексом, а каждый шаг — один плотный цикл;
- вывод упорядочен сначала по строке, потом по столбцу.

Ответы сравнивались на 400 маленьких случайных полях с моделированием
из каждой начальной клетки.

## Особенности языков

- Python запускается под PyPy и применяет команды по четыре сразу: 16
  таблиц для пар команд и таблица для блока из четырёх, собранная из
  двух пар при первой встрече блока, так что клетки проходят четверть
  шагов. По одной команде он превышал лимит 0,5 с на тесте 46 жюри,
  теперь тратит 0,33 с.
