# 1370. Волшебник

[Timus 1370](https://acm.timus.ru/problem.aspx?space=1&num=1370) · сложность 89 · implementation

## Задача

На ободе колеса написаны N цифр, 11 ≤ N ≤ 1000, а в окошке видны 10
подряд идущих, сначала цифры с 1-й по 10-ю. Каждый щелчок поворачивает
колесо на одну цифру, так что после одного щелчка в окошке цифры со 2-й
по 11-ю. По числу щелчков M (1 ≤ M ≤ 32 767) нужно вывести 10 цифр в окошке.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем N цифр по одной в строке.

## Выходные данные

10 цифр в окошке, включая ведущие нули.

## Примеры

### Пример 1

Ввод:

```
12 7
1
2
3
4
5
6
7
8
9
0
7
7
```

Вывод:

```
8907712345
```

## Решение

После M щелчков окошко начинается с цифры M (считая с 0), а колесо
замкнуто, поэтому ответ — цифры (M + i) mod N для i = 0 … 9. `O(1)`
после чтения ввода.

Тонкие места:

- M может быть во много раз больше N (тест 05);
- окошко может переходить через последнюю цифру (пример);
- ответ выводится цифрами, с ведущими нулями (тест 03).

## Оптимизированные решения

Оптимизированное решение на Java разбирает числа вручную вместо
`Scanner`, хранит цифры байтами и выводит десять цифр окошка одним
массивом байтов: 0.093 с вместо 0.125 с и 340 КБ вместо 1892 КБ.

Оптимизированное решение на C++ читает цифры как символы в массив
фиксированного размера и печатает десять из них через `putchar`, без
перевода в числа и без `std::string`: 120 КБ вместо 196 КБ при том же
времени.

## Особенности языков

- Простое решение на C++ хранит цифры как числа, остальные простые
  решения — как текст; все склеивают десять из окошка.
