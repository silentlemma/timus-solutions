# 1370. Волшебник

## Задача

На ободе колеса написаны N цифр, 11 ≤ N ≤ 1000, а в окошке видны 10
подряд идущих, сначала цифры с 1-й по 10-ю. Каждый щелчок поворачивает
колесо на одну цифру, так что после одного щелчка в окошке цифры со 2-й
по 11-ю. По числу щелчков M (1 ≤ M ≤ 32 767) нужно вывести 10 цифр в окошке.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем N цифр по одной в строке.

## Выходные данные

10 цифр в окошке, включая ведущие нули.

## Примеры

### Пример 1

Ввод:

```
12 7
1
2
3
4
5
6
7
8
9
0
7
7
```

Вывод:

```
8907712345
```

## Решение

После M щелчков окошко начинается с цифры M (считая с 0), а колесо
замкнуто, поэтому ответ — цифры (M + i) mod N для i = 0 … 9. `O(1)`
после чтения ввода.

Тонкие места:

- M может быть во много раз больше N (тест 05);
- окошко может переходить через последнюю цифру (пример);
- ответ выводится цифрами, с ведущими нулями (тест 03).

## Особенности языков

- C++ хранит цифры как числа, остальные четыре — как текст; все склеивают
  десять из окошка.
