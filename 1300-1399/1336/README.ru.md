# 1336. Проблема Бен Бецалеля

[Timus 1336](https://acm.timus.ru/problem.aspx?space=1&num=1336) · сложность 123 · math

Автор оригинальной задачи — Ден Расковалов; X командный чемпионат школьников Свердловской области по программированию, 16 октября 2004 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно представить целое число n, 1 ≤ n ≤ 10⁹, как отношение квадрата к
кубу: найти целые m и k от 1 до 10¹⁰⁰, для которых m² = k³ · n.
Принимается любая такая пара.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число n.

## Выходные данные

m в первой строке и k во второй.

## Проверка

Чекер принимает любые m и k от 1 до 10¹⁰⁰, для которых m² = k³ · n.

## Примеры

### Пример 1

Ввод:

```
18
```

Вывод:

```
12
2
```

### Пример 2

Ввод:

```
1
```

Вывод:

```
1
1
```

## Решение

Возьмём k = n и m = n². Тогда m² = n⁴ = n³ · n. Значит, пара существует
всегда, поэтому у задачи всегда есть решение. `O(1)`.

Тонкие места:

- m доходит до 10¹⁸, для этого нужно 64-битное целое (тест 03);
- в первом примере показана меньшая пара; принимается любая верная.

## Оптимизированные решения

Оптимизированное решение на Java читает n побайтно из `System.in` вместо
того, чтобы создавать `Scanner`, чьи регулярные выражения и данные
локали — главная статья расходов программы с одним умножением; n²
по-прежнему помещается в `long`, ведь оно не больше 10¹⁸:
{1336_math_optimized.java}.
