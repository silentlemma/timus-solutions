# 1996. 字节子串的最少最低位修改

[Timus 1996](https://acm.timus.ru/problem.aspx?space=1&num=1996) · 难度 1240 · strings

原题作者 Denis Dublennykh（由 Oleg Dolgorukov 整理）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

图像有 `n` 个字节，消息有 `m` 个字节。图像每个字节只能翻转最低位。让消息成为连续字节子串，求最少翻转次数；次数相同时选择最靠前的起点。其余七位保持不变。范围 `1≤n,m≤250000`，时间 2 秒，内存 64 MB。

## 输入

第一行 `n m`，接着两行分别是图像和消息。每个字节用从最高位到最低位的八个二进制字符表示，字节之间有空格。

## 输出

无可行位置时输出 `No`。否则输出 `Yes`，下一行输出最少翻转数及从 1 开始的起始字节编号。

## 评测方式

按记号逐个比较输出。

## 样例

```
3 2
11110001 11110001 11110000
11110000 11110000
```

```
Yes
1 2
```

```
3 1
11110000 11110001 11110000
11110000
```

```
Yes
0 1
```

第一例两个位置的高七位都匹配；起点 1 需要两次翻转，起点 2 只需一次。第二例起点 1、3 都不需修改，所以选较早的 1。

## 解法

以 `A[i]`、`B[j]` 表示字节数值。在序列 `A[i]>>1` 中用 KMP 搜索 `B[j]>>1`。出现位置恰好就是可行起点：高七位不同时无法修复，相同时总能通过最低位实现消息。完成一次匹配后回退到前缀函数状态，以保留重叠出现。若 `m>n` 或没有出现位置，输出 `No`。

令 `a[i]=A[i]&1`、`b[j]=B[j]&1`，`P` 是 `a` 的前缀和，`q=sum(b)`。反转 `b` 后与 `a` 卷积得到 `C`。从零开始的位置 `s` 对应 `C[s+m−1]=sum(a[s+j]·b[j])`。二进制恒等式 `x xor y=x+y−2xy` 给出费用

`P[s+m]−P[s]+q−2·C[s+m−1]`。

只按从小到大的顺序检查可行起点，费用严格变小时才替换答案。于是保留最早的最优位置。所选子串以外的翻转不会有帮助。

### 四种编译语言的精确 NTT

C++、Go、Java、Rust 使用模数 `998244353=119·2^23+1` 和原根 3。补零到不小于 `n+m−1` 的最小二次幂 `L`；`L≤524288`，所需单位根存在。两次正变换、逐点乘法、一次逆变换得到卷积。每个整数系数在 0 到 `m≤250000` 之间，小于模数，因此模意义结果就是精确整数，不含舍入或随机误判。乘法使用 64 位，两个余数之和适合有符号 32 位。可行起点不超过 32 时直接逐位比较。

### Python 的精确整数乘法

设 `R=2^18`，打包 `X=sum(a[i]R^i)`、`Y=sum(b[m−1−j]R^j)`。乘积的 `R` 进制各位即卷积系数。系数最多 250000，严格小于 262144，所以不会相互进位。16 项表把四个原始位放入九个字节；末组补零不改变数值。乘积转为小端字节后提取 18 位数字，其位偏移模八只会是 0、2、4、6，读取三个字节足够。

可行起点不超过 2048 时，将最低位按二进制位打包，利用移位、XOR、消息长度掩码和 popcount 求费用。反转使第一个字节处于最低位，掩码丢弃消息之外的尾部。阈值固定，该分支关于输入长度线性。所有高位符号相同还有直接生成起点的捷径；这些分支的费用和并列规则相同。

### 复杂度

NTT 版本时间 `O(n+m+L log L)`、空间 `O(n+m+L)`，即 `O((n+m) log(n+m))`、`O(n+m)`。令 `M(u,v)` 为两个至多 `u`、`v` 位整数的乘法成本，Python 时间为 `O(n+m+M(18n,18m))`，存储数据线性，另需乘法工作空间。Python 的此界针对整数乘法，不把它当作 FFT 实现。

高七位全部必须匹配；卷积前反转消息，读取 `s+m−1`。只考虑可行起点，费用相等不更新。每个字节包含前导零。零乘积、大系数、重叠出现、消息更长及单窗口都有专门测试。
