# 1989. 字母替换后的回文查询

[Timus 1989](https://acm.timus.ru/problem.aspx?space=1&num=1989) · 难度 338 · strings, fenwick, hashing

原题作者 Mikhail Rubinchik，出自 2013 年乌拉尔联邦大学公开团体锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

维护由 `n` 个小写英文字母组成的字符串。每次操作修改一个位置，或询问一个闭区间子串从左到右与从右到左是否相同。共有 `m` 次操作，`5≤n,m≤100000`，位置从 1 开始。时间限制 0.5 秒，内存限制 64 MB。

## 输入

首先是字符串，然后是 `m`，接着是 `m` 条操作。`change i a` 将位置 `i` 改为字母 `a`，`1≤i≤n`。`palindrome? l r` 查询闭区间 `l..r`，`1≤l≤r≤n`。允许将某个字母改成原来的值。

## 输出

按查询顺序输出：回文为 `Yes`，否则为 `No`。修改操作不输出内容。

## 评测方式

按记号逐个比较输出。

## 样例

输入：

```
abcda
5
palindrome? 1 5
palindrome? 1 1
change 4 b
palindrome? 1 5
palindrome? 2 4
```

输出：

```
No
Yes
Yes
Yes
```

初始整个字符串不是回文，单个字母始终是回文。把第 4 个字母改为 `b` 后得到 `abcba`，整个字符串和内部的 `bcb` 都是回文。

## 解法

### 精确的镜像缓冲区：C++、Go、Python、Rust

保存字符串 `s` 和反串 `t`，维持 `t[n−1−i]=s[i]`。修改时同时写入对应的两个位置。把查询转换为从零开始的半开区间 `[l,r)`，则它的反串就是 `t[n−r:n−l]`，直接与 `s[l:r]` 比较。

初始构造满足不变量，每次双写也保持不变量，即使字母没有改变。对区间内任意偏移 `j`，有 `t[n−r+j]=s[r−1−j]`。所以两个区间相等，当且仅当原子串的每一对镜像字符相等。这证明答案是精确的，没有哈希碰撞。单字符及左右端点都符合相同公式。

设所有查询长度之和为 `L`。初始化 `O(n)`，单次修改 `O(1)`，单次查询至多与子串长度成正比，总时间 `O(n+m+L)`，最坏 `O(nm)`，并非对数时间。C++ 使用 `memcmp`，Go 使用 `bytes.Equal`，Rust 使用切片相等，CPython 使用 `bytearray.startswith` 比较反串的 `memoryview`。这些连续比较在本机实现中执行。Python 视图能看到点修改，查询不复制字符数据，也不改变缓冲区长度。

程序实际上只需比较 `h=floor((r−l)/2)` 个字符，即 `s[l:l+h]` 与 `t[n−r:n−r+h]`。每对镜像字符恰好比较一次，奇数长度的中间字符与自身相等。单字符时两段均为空，结果为真。

### 四个有限域与树状数组：Java

对素数 `p=1000000007,1000000009,998244353,1000000033`，分别独立地从 `2..p−2` 均匀选择底数 `B`。预计算幂，使用两个树状数组维护 `s[i]Bⁱ` 和 `s[i]Bⁿ⁻¹⁻ⁱ` 模 `p` 的值。线性建树把每个节点加到其父节点。修改只影响两个权值，各树更新 `O(log n)`。

对 `[l,r)`，用前缀和差求出 `F,G`，在每个域中判断 `F·Bⁿ⁻ʳ ≡ G·Bˡ (mod p)`。缩放后镜像字符的指数一致，因此真正的回文一定通过。若不是回文，相减并移除公共幂后得到次数至多 `n−1` 的非零多项式：至少一个系数是 −25..25 中的非零字母差，在每个素数域中也非零。

域上的非零多项式，其根数不超过次数。对于与随机底数独立的固定输入，至多 `m` 个查询中出现错误 `Yes` 的概率不超过 `m·∏((n−1)/(p−3)) < 1.1·10⁻¹¹`。程序通过 `java.util.Random` 选择底数。这是蒙特卡洛算法，不是确定性的相等证明；概率估计假设独立均匀选择，不覆盖根据秘密底数自适应构造的查询。四个域总时间 `O(n+m log n)`，包括输出缓存的空间为 `O(n+m)`。某一个域不相等时即可立即回答 `No`。

### 实现与限制

使用字母的 ASCII 值。Java 乘积小于 `p²<1.01·10¹⁸`，用 `long` 安全计算；负差先规范化。树节点始终小于 `p`，两个节点相加不会超出 `int`，最多 17 个节点的前缀累加用 `long`。不需要模逆元。Java 使用字节缓冲输入，Go 兼容 1.14。

精确版本保存 `O(n)` 字符及至多 `O(m)` 输出。Go、Rust 还保留 `I` 个输入字节，实际空间 `O(n+m+I)`。Python 选择 CPython 3.12；实测 PyPy 3.10 在长回文查询上超出时间和内存。精确比较的最坏复杂度是二次的，所以 0.5 秒的限制对它来说很紧。静态 Manacher 半径不能直接应对点修改，每次重建同样可能需要二次时间。
