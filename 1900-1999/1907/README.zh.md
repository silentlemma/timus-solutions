# 1907. 两个方格的等量分配

[Timus 1907](https://acm.timus.ru/problem.aspx?space=1&num=1907) · difficulty 1326 · number_theory

原题作者 Ivan Burmistrov，比赛 Ural Championship 2012。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两个正方形网格的整数边长分别为 a、b，总共有 a²+b² 个单位格子，
以及 4(a+b) 条单位外边界线段。需要把这两类对象分配给同样的 c≥2 个组，
使每组得到相同数量的格子和相同数量的线段，不要求各组连通。
给定 a 和上界 n，求有多少整数 b 满足 1≤b≤n 且允许这样的分配。
时间限制 1 秒，内存限制 64 MB。

## 输入

两个整数 a、n，满足 1≤a≤10¹²、1≤n≤10¹⁸。

## 输出

输出合法 b 的数量。

## 评测方式

答案是一个精确整数，按标记比较。

## 样例

```
3 6
```

```
4
```

## 解法

存在组数 c 当且仅当 gcd(a²+b²,4(a+b))>1，即两个总数有公共质因子。
若 a、b 同奇偶，则两个总数均为偶数，取 c=2 即可。

若奇偶性不同，格子总数为奇数，公共质因子 p 必为奇质数，且整除 a+b。
代入 b≡−a (mod p)，得到 a²+b²≡2a²。由于 p 为奇数，只有 p|a 才能为零，
随后也有 p|b。反之，a、b 的公共奇质因子显然整除两个总数。
因此合法 b 恰好是与 a 同奇偶，或者与 a 有公共奇质因子的整数。

仅对 a 试除分解，保留不同的奇质因子。转而计算非法 b：与 a 奇偶相反，
并且不被这些质数整除。若 a 为奇数，令 b=2t，统计 t≤floor(n/2)
中与这些质数互质的整数；若 a 为偶数，统计 b≤n 中这样的奇数。

令 F(x,i) 表示不超过 x、避开下标 i,…,r−1 的质数且属于所选类型的数量。
没有剩余质数时，普通整数的基例为 x，奇数的基例为 floor((x+1)/2)。
否则 F(x,i)=F(x,i+1)−F(floor(x/pᵢ),i+1)。第二项删除 pᵢ 的倍数。
除以奇质数既保持奇偶性，也保持对其他质数的整除关系，因此递推正确。
x=0 时直接返回零。用 n 减去非法数量便得到答案。

不同奇质因子至多十个，因为最小的十一个奇质数乘积为
3 710 369 067 405，超过 10¹²。时间复杂度 O(√a+2ʳ)，空间 O(r)。
示例中，1、3、5 与 a 同为奇数，而 6 与 a 共享质因子 3，所以答案为四。

## 各语言说明

C++、Go 1.14、Java 8、Rust 1.75 使用有符号 64 位整数。不能直接计算
a²+b²，它可能达到约 10³⁶。每个递归结果都是实际子集的数量，不超过当前
上界，因此中间减法也安全；最终答案至多 10¹⁸。试除中的平方只在约 10¹²
范围内，与 n² 无关。Python 3.12 使用普通整数。递归深度至多十一层。
必须完整除去每个质数的所有幂，避免重复计数。

在 90 208 个测试上，答案与直接计算总量最大公约数的结果一致；大数据则与用任意精度直接计算的容斥和一致。
