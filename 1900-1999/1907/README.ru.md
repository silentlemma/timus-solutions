# 1907. Равные доли двух квадратных сеток

[Timus 1907](https://acm.timus.ru/problem.aspx?space=1&num=1907) · difficulty 1326 · number_theory

Автор исходной задачи: Ivan Burmistrov, Ural Championship 2012.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Две квадратные сетки имеют целые стороны a и b. Всего в них a²+b²
единичных клеток и 4(a+b) единичных отрезков внешних границ. Обе коллекции
нужно разделить между одинаковыми c≥2 группами так, чтобы каждой досталось
поровну клеток и поровну отрезков. Связность частей не требуется.
Даны a и n; посчитайте подходящие целые b от 1 до n включительно.
Ограничения: 1 секунда и 64 МБ.

## Входные данные

Два целых числа a,n: 1≤a≤10¹², 1≤n≤10¹⁸.

## Выходные данные

Количество допустимых значений b.

## Проверка

Ответ — одно точное целое число; сравнение по токенам.

## Примеры

```
3 6
```

```
4
```

## Решение

Число групп c существует тогда и только тогда, когда
gcd(a²+b²,4(a+b))>1, то есть итоги имеют общий простой делитель.
При одинаковой чётности a и b оба итога чётны, поэтому подходит c=2.

При разной чётности число клеток нечётно. Общий простой делитель p
тоже должен быть нечётным и делить a+b. Подставляя b≡−a (mod p),
получаем a²+b²≡2a². Поскольку p нечётно, это нуль ровно при p|a,
а тогда и p|b. Обратно, общий нечётный простой делитель a и b делит
оба итога. Значит, подходят b той же чётности, что и a, либо имеющие
с a общий нечётный простой множитель.

Разложим только a пробными делениями и сохраним различные нечётные простые
множители. Считаем неподходящие b: другой чётности и без этих множителей.
При нечётном a запишем b=2t и посчитаем t≤floor(n/2), взаимно простые
с выбранными множителями. При чётном a считаем такие нечётные b≤n.

Пусть F(x,i) — число рассматриваемых целых до x, не делящихся на простые
с индексами i,…,r−1. Если простых больше нет, ответ равен x для всех целых
или floor((x+1)/2) для нечётных. Иначе
F(x,i)=F(x,i+1)−F(floor(x/pᵢ),i+1). Второе слагаемое удаляет кратные pᵢ.
Деление на нечётное pᵢ сохраняет чётность и делимость на остальные простые,
что доказывает рекуррентность. При x=0 сразу возвращаем нуль.
Итоговый ответ равен n минус полученное число неподходящих размеров.

Различных нечётных простых не больше десяти: произведение первых одиннадцати
равно 3 710 369 067 405>10¹². Время O(√a+2ʳ), память O(r).
В примере подходят нечётные 1,3,5 и чётное 6 с общим множителем 3.

## Особенности языков

В C++, Go 1.14, Java 8 и Rust 1.75 используются знаковые 64-битные числа.
Вычислять a²+b² напрямую нельзя: оно достигает порядка 10³⁶. Каждый результат
рекурсии — количество элементов подмножества от нуля до текущей границы,
поэтому промежуточные вычитания также безопасны. Ответ не превышает 10¹⁸.
Квадрат пробного делителя имеет порядок не более 10¹², а не n².
Python 3.12 использует обычные целые. Глубина рекурсии не превышает одиннадцати.
Каждый простой множитель нужно удалить полностью, независимо от его степени.

Ответы совпадают с прямым вычислением НОД сумм на 90 208 тестах, а
большие — с простой суммой по включениям-исключениям в длинной
арифметике.
