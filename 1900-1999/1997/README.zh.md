# 1997. 避开禁用停留时长的进出配对

[Timus 1997](https://acm.timus.ru/problem.aspx?space=1&num=1997) · 难度 549 · matching

原题作者 Denis Dublennykh（由 Oleg Dolgorukov 整理）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

门口日志记录全部进出事件，日志开始和结束时室内为空。每名访客的停留时长必须不超过 `b` 或者不小于 `a`，两者之间的开区间禁止。判断能否把所有事件解释为这些访问；可以时输出任意完整配对。

事件数 `2≤n≤1000`，`1≤b,a≤10^9`，`b+1<a`。时间互异且递增，范围 1 到 `10^9`。方向 0 表示进入、1 表示离开。时间 1 秒、内存 64 MB。

## 输入

第一行 `a b`，第二行 `n`，随后 `n` 行各含事件时间及方向。

## 输出

无解输出 `Liar`。有解输出 `No reason`，再为每名访客输出进入、离开时间。任何正确配对及配对顺序均可。

## 评测方式

检查器确认这些配对恰好用到每次进入和离开各一次，并且所有时长都合法；只有在不存在分配时才接受 `Liar`。任何合法的分配、以任意顺序输出都被接受。

## 样例

```
6 3
4
1 0
2 0
5 1
10 1
```

```
No reason
1 10
2 5
```

```
6 3
4
1 0
2 0
6 1
10 1
```

```
Liar
```

第一例 `(1,10)` 与 `(2,5)` 的时长为 9、3，分别满足长、短限制。第二例时间 6 的离开若配进入 1 或 2，会得到禁用时长 5 或 4，因此后续离开也无法修复该事件。

## 解法

构造二分图：每个进入事件是左点，每个离开事件是右点。进入时间 `e` 与离开时间 `x` 之间连边，当且仅当 `x>e` 且 `x−e≤b` 或 `x−e≥a`。等于边界允许。每条边恰好表示一次可能的访问。

合法解释等价于完美匹配：解释使用每个进出事件恰好一次，因而形成匹配；反过来，完美匹配的各边给出正时长、符合限制且覆盖全部事件的访问。进入和离开数量不同可直接判无解。

### 分层增广

使用 Hopcroft–Karp，为两侧顶点保存伙伴，初始均未匹配。BFS 从全部空闲左点出发，经过可选的右点及其现有左伙伴，记录左点层数和到达空闲右点的最短距离。

DFS 只沿相邻 BFS 层前进，并且只在该最短距离的空闲右点结束。成功返回时沿交替路径修改双方伙伴，使匹配数增加一。每个左点保存本阶段已经检查的边游标；失败的左点退出当前分层。之后重新 BFS，直到没有增广路径。

沿交替路径翻转保持匹配性质并增加匹配数。如果终止后存在更大的匹配，两者的对称差中必有两端空闲的交替路径，与最后一次 BFS 失败矛盾。因此结果最大；其大小等于进入数时恰有合法解释。直接输出伙伴对应的事件时间即可。

一阶段时间 `O(E+V)`：BFS 扫边，DFS 游标让每条边至多被检查一次。每阶段耗尽最短增广路径，其长度严格增加。经过 `O(sqrt V)` 阶段后路径变长，顶点互不相交性又把剩余增广次数限制为 `O(sqrt V)`，得到 `O(E sqrt V)`。

### 局部贪心不充分

`a=10,b=2`，进入 1、10，离开 11、14，有解 `(10,11),(1,14)`。若先把离开 11 配给最老的可用进入 1，剩余时长 4 被禁止。增广路径能修改先前配对。

### 复杂度

每侧最多 500 点、最多 250000 条边。建图 `O(n²)`，匹配 `O(E sqrt V)`，总时间 `O(n² sqrt n)`、空间 `O(n²)`，五种语言相同。递归每次前进一个左层，深度最多 500。时间差适合有符号 32 位；Rust 也使用 64 位时间。
