# 1976. Квадраты расстояний до ближайшей базы

[Timus 1976](https://acm.timus.ru/problem.aspx?space=1&num=1976) · сложность 1295 · geometry

Автор оригинальной задачи — Идея — Илья Бушков; XVII Открытый чемпионат Урала по спортивному программированию (май, 2013).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В центрах некоторых клеток прямоугольной сетки стоят базы. Между центрами
соседних клеток одна единица. Для каждой клетки нужно найти квадрат
евклидова расстояния до ближайшей базы. Пустые клетки не являются
препятствиями и не ограничивают перемещение. Лимиты: 2 секунды и 64 МБ.

## Входные данные

Первая строка содержит n и m, 1≤n,m≤1000. Затем задана двоичная матрица
из n строк по m клеток: 1 означает базу, 0 — пустую клетку.
Гарантированы хотя бы одна база и хотя бы одна пустая клетка.

## Выходные данные

n строк по m целых чисел. В позиции (r,c) вывести минимум
(r−a)²+(c−b)² по всем базам (a,b). Между числами одной строки ставить
один пробел. Для базы ответ ноль; извлекать квадратный корень не нужно.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
3 4
1000
0000
0010
```

```
0 1 4 5
1 2 1 2
4 1 0 1
```

## Решение

### Разделение координат

Зафиксируем строку ответа r и столбец возможной базы q. Обозначим v[q]
минимальное вертикальное расстояние |r−a| до базы (a,q). Проход сверху
вниз находит ближайшую базу сверху, проход снизу вверх улучшает значение
базой снизу. Если в столбце нет баз, он остаётся недостижимым.

Для клетки с горизонтальной координатой x требуется минимум

v[q]²+(x−q)² по достижимым q.

При фиксированном q горизонтальное слагаемое постоянно. Поэтому среди
баз этого столбца полное расстояние минимизирует ближайшая по вертикали
база. Минимум по всем q рассматривает все базы исходной карты.

Маркер far=n+m отличает недостижимые столбцы. Любое настоящее
вертикальное расстояние не больше n−1. В столбце без базы оба прохода
оставляют значение не меньше far; такую параболу пропускаем. Хотя строка
может быть пустой, хотя бы один достижимый столбец существует всегда.

### Целочисленная нижняя огибающая парабол

Для достижимого q положим f[q]=v[q]² и Pq(x)=(x−q)²+f[q].
У всех парабол одинаковый коэффициент при квадрате. При p<q новая
парабола не выше старой тогда и только тогда, когда

2(q−p)x ≥ f[q]+q²−f[p]−p².

Первая целая координата переключения равна

ceil((f[q]+q²−f[p]−p²)/(2(q−p))).

Пересечения вычисляются точно. Округлять нужно вверх, в том числе при
отрицательном числителе: обычное деление с усечением не заменяет эту
формулу во всех случаях.

Храним стек столбцов и первых неотрицательных целых координат, с которых
они становятся предпочтительными. Столбцы q обрабатываем слева направо.
Находим пересечение нового кандидата с последним. Если переключение
случается не позже начала интервала последнего, у последнего не остаётся
оптимального участка: удаляем его и повторяем сравнение. Затем добавляем
q с найденным началом; если стек пуст, началом будет ноль. При равенстве
выбираем новую параболу, не меняя само значение расстояния.

Вычтем общий член x²: останутся прямые с строго убывающими наклонами
−2q. Нижняя огибающая посещает их в порядке возрастания q. Кандидат,
которого перекрыли до начала собственного участка, больше не может стать
оптимальным. Удаление и повторное сравнение новых соседей сохраняют
точную нижнюю огибающую на x≥0.

Просматриваем x=0…m−1, сдвигая указатель на следующего кандидата, когда
достигнуто его начало. Начала строго возрастают, поэтому указатель
движется только вперёд и каждый раз выбирает минимум.

### Корректность и сложность

Вертикальные проходы точно вычисляют все конечные v[q]. Стек и указатель
дают минимум Pq(x), а разделение координат отождествляет его с минимумом
квадрата расстояния до всех баз. Следовательно, каждая выведенная клетка
верна, включая базы, равные расстояния, пустые строки и столбцы.

Каждая парабола добавляется и удаляется не более одного раза; указатель
делает не более m переходов за строку. Время — `O(nm)`, общая память —
`O(nm)` с учётом вертикальной таблицы и ввода. Дополнительная память
огибающей — `O(m)`. Сам ответ содержит nm чисел.

В примере базы имеют координаты (0,0) и (2,2) при нумерации с нуля.
Для (0,3) квадраты расстояний равны 9 и 5, поэтому ответ 5.
Для (1,1) оба значения равны 2. Для (2,1) ближайшая вторая база
находится в одной единице, ответ 1. Так получаются все три строки примера.

BFS по четырём соседям вычисляет манхэттенское расстояние: для смещения
(1,1) его квадрат равен 4, а нужен ответ 2. Восемь направлений тоже
не дают точного евклидова квадрата. Пропускайте недостижимые столбцы,
правильно округляйте знаковое деление вверх, удаляйте кандидатов с
совпавшими началами. Сохраняйте исходные номера столбцов.

## Особенности языков

Пять программ используют одну точную огибающую. Python хранит таблицу
вертикальных расстояний списками строк для быстрого индексирования.
Перед проходами Python находит столбцы
с базами, оставляя остальные недостижимыми. Если все вертикальные расстояния
строки не больше единицы, они уже достигают целочисленной нижней границы:
ноль у базы и единица в пустой клетке. Python сразу возвращает эту строку;
для остальных строится полная огибающая. Компилируемые версии используют
целочисленные массивы. C++ и Go реализуют знаковое округление вверх,
Java применяет Math.floorDiv, Rust — div_euclid с отрицанием.
Вывод буферизуется по строкам, без накопления всей матрицы строк ответа.
Java переиспользует построитель строки и символьный буфер, не создавая
новый String для каждой строки вывода.
