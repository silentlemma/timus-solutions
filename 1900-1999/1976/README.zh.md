# 1976. 到最近基地的距离平方

[Timus 1976](https://acm.timus.ru/problem.aspx?space=1&num=1976) · 难度 1296 · geometry

原题作者 Idea by Ilya Bushkov，出自 2013 年乌拉尔体育编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

矩形网格的一些格子中心设有基地，相邻中心间距为一个单位。
对每个格子，求它到最近基地的欧氏距离平方。空格子不是障碍，
也不限制移动路径。时间限制为 2 秒，内存限制为 64 MB。

## 输入

第一行给出 n、m，1≤n,m≤1000。随后是 n 行、每行 m 个格子的二进制矩阵。
1 表示基地，0 表示空格。保证至少有一个基地和一个空格。

## 输出

输出 n 行，每行 m 个整数。位置 (r,c) 的值为所有基地 (a,b) 中
(r−a)²+(c−b)² 的最小值。同一行数字用一个空格分隔。
基地自身的答案为零，不需要开平方。

## 评测方式

按记号逐个比较输出。

## 样例

```
3 4
1000
0000
0010
```

```
0 1 4 5
1 2 1 2
4 1 0 1
```

## 解法

### 分离两个坐标

固定目标行 r 和基地所在列 q，令 v[q] 为该列基地到 r 的最小垂直距离。
从上往下扫描得到上方最近基地，再从下往上扫描，用下方最近基地更新。
没有基地的列保持不可达。

目标列 x 的答案就成为所有可达 q 中 v[q]²+(x−q)² 的最小值。
原因是 q 固定时横向项不变，该列中垂直距离最小的基地也使总距离平方最小。
再遍历所有 q，就覆盖了全部基地。

程序取 far=n+m。真实垂直距离至多为 n−1；无基地列在两次扫描后
仍至少为 far，因此不参与构造抛物线。即使某行没有基地，全图至少存在
一个基地，故该行总能找到可达列。

### 整数抛物线下包络

对可达 q，定义 f[q]=v[q]²、Pq(x)=(x−q)²+f[q]。
所有抛物线的二次项系数相同。对 p<q，新抛物线不高于旧抛物线当且仅当

2(q−p)x ≥ f[q]+q²−f[p]−p²。

因此第一个整数切换位置是

ceil((f[q]+q²−f[p]−p²)/(2(q−p)))。

不需要浮点交点或 epsilon。分子为负数时也必须向正无穷方向取整；
普通向零截断的除法不能直接代替这个有符号上取整公式。

用栈保存候选列和各自开始占优的第一个非负整数位置，按 q 从左到右处理。
计算新候选与栈顶的切换位置；若它不晚于栈顶自己的开始位置，则栈顶已没有
最优区间，将其弹出并继续比较。随后压入 q；若栈已空，起点设为零。
相等时选择新的抛物线，但答案值不会改变。

减去公共项 x² 后，得到斜率为 −2q 且严格递减的直线。
下包络按 q 递增的顺序访问候选。某候选若在自己开始前就被覆盖，
之后便不可能成为最优；删除它并重新比较相邻候选，仍保留 x≥0 上的精确下包络。

扫描 x=0…m−1，当到达下一个候选的开始位置时前移指针。
起点严格递增，指针从不后退，所选抛物线始终达到最小值。

### 正确性与复杂度

两次垂直扫描精确求出所有有限的 v[q]。下包络及指针精确求出 minq Pq(x)，
坐标分离又证明它等于到任意基地的最小距离平方，因此所有输出均正确，
包括基地、并列最近基地以及空行空列。

每个候选最多入栈、出栈各一次，每行的指针最多前进 m 次。
总时间为 `O(nm)`，含垂直表和输入的总空间为 `O(nm)`，每行下包络
额外占用 `O(m)`。输出本身就有 nm 个数。

样例按零下标的基地为 (0,0) 与 (2,2)。格子 (0,3) 到它们的距离平方是
9 和 5，所以答案为 5；(1,1) 的两个值都是 2；(2,1) 距第二个基地
一个单位，答案为 1。对所有格子计算后即得样例的三行结果。

四邻接 BFS 得到曼哈顿距离：偏移 (1,1) 的曼哈顿距离平方为 4，
这里却应为 2。八邻接近似也不精确。不要让不可达哨兵参与最小值竞争。
注意有符号上取整，在起点相同时弹出旧候选，并保留候选的原始列编号。

## 各语言说明

五个程序使用相同的精确下包络。Python 用行列表保存垂直距离，以便直接索引，
并预先找出含基地的列，
其余列直接保持不可达。若某行全部垂直距离至多为一，它们已达到整数下界：
基地处为零，空格处为一。Python 直接返回这些值；其余行仍构造完整下包络。
编译语言版本使用整数数组。
C++、Go 直接实现有符号上取整；Java 用 Math.floorDiv，Rust 用取负配合
div_euclid。输出按行缓冲，不累积整张答案矩阵的字符串。
Java 复用行构造器与字符缓冲区，不为每行创建新的输出 String。
