# 1910. Тройка соседних значений с наибольшей суммой

[Timus 1910](https://acm.timus.ru/problem.aspx?space=1&num=1910) · difficulty 34 · implementation

Автор исходной задачи: Denis Dublennykh, NEERC 2012, Eastern subregional contest.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В последовательности положительных значений найдите три подряд идущих
элемента с наибольшей суммой. Выведите эту сумму и номер среднего элемента
при нумерации с единицы. Максимизирующая тройка гарантированно единственна.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

Сначала n, 3≤n≤1000, затем n целых aᵢ, 1≤aᵢ≤10⁶.
Пробелы и переводы строк равноправны как разделители.

## Выходные данные

Максимальная сумма и номер среднего элемента с единицы.

## Проверка

Два точных целых числа; сравнение по токенам.

## Примеры

```
6
1 4 4 4 1 1
```

```
12 3
```

## Решение

Перебираем секции со второй по предпоследнюю как среднюю из трёх:
складываем её с двумя соседями и запоминаем наибольшую сумму вместе с
номером. Условие обещает, что лучшая тройка единственна, поэтому хватает
строгого сравнения. `O(n)`; сумма не больше 3·10⁶ и помещается в
32-битное целое.

Подводные камни:

- ответ — номер средней секции, считая с 1;
- при n = 3 тройка только одна.

## Оптимизированные решения

Оптимизированное решение на C++ не хранит секции: оно читает их по одной
через `scanf` и помнит только две предыдущие, а больше для тройки ничего
не нужно: 128 КБ вместо 192 КБ при том же времени.

Оптимизированное решение на Java хранит только два участка перед
текущим, как и решение на C++, и разбирает ввод вручную вместо
`Scanner`: 0.125 с вместо 0.156 с и 380 КБ вместо 2372 КБ.
