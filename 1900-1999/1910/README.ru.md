# 1910. Тройка соседних значений с наибольшей суммой

[Timus 1910](https://acm.timus.ru/problem.aspx?space=1&num=1910) · difficulty 34 · two_pointers

Автор исходной задачи: Denis Dublennykh, NEERC 2012, Eastern subregional contest.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В последовательности положительных значений найдите три подряд идущих
элемента с наибольшей суммой. Выведите эту сумму и номер среднего элемента
при нумерации с единицы. Максимизирующая тройка гарантированно единственна.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

Сначала n, 3≤n≤1000, затем n целых aᵢ, 1≤aᵢ≤10⁶.
Пробелы и переводы строк равноправны как разделители.

## Выходные данные

Максимальная сумма и номер среднего элемента с единицы.

## Проверка

Два точных целых числа; сравнение по токенам.

## Примеры

```
6
1 4 4 4 1 1
```

```
12 3
```

## Решение

Поддерживаем окно длины три. Начальная сумма состоит из первых трёх
значений, номер середины равен 2. При сдвиге начала с s−1 на s, где
индексы массива начинаются с нуля, вычитаем a[s−1] и добавляем a[s+2].
Если сумма стала больше лучшей, запоминаем её и новую середину s+2.

После каждого обновления текущая сумма точно равна сумме текущей тройки.
Изначально лучший ответ соответствует первому окну; после очередного
сравнения он максимален среди всех просмотренных окон. Каждое допустимое
начало 0,…,n−3 рассматривается ровно один раз, поэтому итог оптимален,
а сохранённая середина принадлежит единственной лучшей тройке.

При n=3 окно единственное, цикл обновления не выполняется. Выводится
именно середина, а не начало или конец окна. В примере элементы с номерами
2,3,4 дают 12, средний имеет номер 3.

Время O(n), память O(n) для входных значений и O(1) для дополнительного
состояния. Сумма не превышает 3·10⁶ и помещается в знаковое 32-битное число.

## Особенности языков

C++, Go 1.14, Java 8 и Rust 1.75 используют целочисленные массивы или
векторы. Python 3.12 читает числовые токены и выполняет тот же сдвиг суммы.
Вещественные числа и длинная арифметика не нужны. Меняем ответ только
при строго большей сумме; равные максимумы исключены условием.

Ответы совпадают с прямым суммированием всех троек на всех 14 157
последовательностях длины от 3 до 7 из значений от 1 до 4 с единственной
лучшей тройкой.
