# 1974. 音符序列平移后的最大匹配数

[Timus 1974](https://acm.timus.ru/problem.aspx?space=1&num=1974) · difficulty 1156 · bitmask, bruteforce

原题作者 Denis Dublennykh，出自 2013 年乌拉尔体育编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定源旋律和 m 个目标旋律。对长度相同的连续子串，统计相同绝对
音高的位置数。所有子串对中的最大值为绝对相似度；不同位置允许
存在且没有扣分。相对相似度是该最大值除以目标旋律长度。
限制：1 秒，64 MB。

## 输入

首行源长度 n 及 n 个音符。然后 m，1≤m≤100，再有 m 行各含长度
和对应音符。所有旋律长度均为 1…1000。

音符为 dN、dN+ 或 dN-，八度 d=1…8，N=A…G。自然音半音偏移为
C=0、D=2、E=4、F=5、G=7、A=9、B=11；+、- 各加减一。因此
C+=D-、D+=E-、E=F-、F=E+、F+=G-、G+=A-、A+=B-。B+ 是下一
八度 C，C- 是上一八度 B；不存在的 1C-、8B+ 不会输入。

## 输出

按目标顺序输出 m 个实数相似度，绝对或相对误差至多 10⁻⁶。值在 [0,1]。

## 评测方式

检查器按不超过 10⁻⁶ · max(1, |答案|) 的误差比较每个数。

## 样例

```
4 5C+ 5D 5C 5G
3
2 5D- 5D
2 5D 4B+
4 5D 5C+ 5D 5F-
```

```
1.000000
1.000000
0.500000
```

## 解法

### 标准音高与完整重叠

将音符转为 12(d−1)+自然偏移+升降，得到 0…95 的绝对音高，也自动
处理跨八度等价记法。八度有意义，不允许将整个旋律移调。

固定索引差 i−j，任何对应子串对均可扩展到两序列的完整重叠。扩展
不会减少已有相同位置，因为不同位置不扣分。因此只需统计 n+L−1
个非空平移重叠，L 为目标长度；最大值恰等于原定义。

### 编译语言的位置对计数

按音高存源序列位置列表。每对相同音高 (i,j) 恰属于平移 i−j，
令计数器 i−j+L−1 加一，最后取最大。每个重叠相等位置恰统计一次，
不等位置不统计，故正确。源位置表复用，每个目标重新清空计数。

有 K 个匹配位置对时，时间 `O(n+L+K)`，最坏 `O(nL)`，工作空间
`O(n+L+96)`，不含输入输出缓冲。C++、Go、Java、Rust 采用此法。

### Python 的大整数独立字段

取基数 2¹⁰=1024，音高 p 的掩码 M[p]=Σᵢ:音高(i)=p 2^(10i)。计算

T = Σⱼ M[目标[j]] · 2^(10(L−1−j))。

第 i−j+L−1 个 1024 进制数字正是该平移的匹配对数。每字段至多
min(n,L)≤1000，小于 1024，无进位串扰。取出各十位字段的最大值；
达到 min(n,L) 即可停止。最后除以 L 而非 n。

打包整数 B=10(n+L−1) 位，进行 L 次加法移位及至多 n+L−1 次取字段。
w 位机器字模型下，保守比较界 `O((n+L)·ceil(B/w))`，音高掩码占
`O(96·ceil(10n/w))` 字。任意精度整数内部完成密集运算，避免 Python
逐个遍历 nL 个位置对。

样例中 5C+=5D-，第一目标匹配源开头，两位相等，2/2=1。第二目标
匹配源第 2、3 位，因为 4B+=5C，仍为 2/2=1。最后目标的第 2、3
音符可对齐源前两位，最多两次匹配，故 2/4=0.5。

这不是最长公共子串或子序列：可以保留不匹配，但所有位置使用同一
平移。先归一等音记法，尤其 B+、C- 的跨八度。分母为目标长度。
允许零。1000 次匹配需要十位字段，九位会进位。保留全部平移，每个
目标重置编译语言计数器。

## 各语言说明

Python 使用精确大整数打包字段，其余四版枚举匹配位置对。Java 直接
从字节缓冲解析音高，避免 100,000 个临时音符字符串。比较不修改
源位置结构。
