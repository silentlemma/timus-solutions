# 1939. 通过与刹停之间的临界时刻

[Timus 1939](https://acm.timus.ru/problem.aspx?space=1&num=1939) · difficulty 841 · math

Original problem from Open Ural FU Championship 2012 | by Denis Dublennykh (prepared by Egor Shchelkonogov).

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

长l、高h的车辆以恒速v驶向门。门栅初始净高H，可在任意时刻
开始以速度x下降。看到关门后，车辆可切断牵引，以减速度a
刹至静止，或继续前进。初始距离足够远，立即刹车能停在门前。
问是否存在一个开始关门时刻，使任何决策都无法避免碰撞。
任何接触都算事故。限制：1秒、64MB。

## 输入

先给l,h,H且h<H，再给v,x,a。六个数都是不超过1000的正整数。
长度用厘米，v、x用厘米/秒，a用厘米/秒²。不提供当前门距。

## 输出

若存在不可避免事故的关门起始时刻，输出Crash，否则输出Safe。
大小写必须一致。

## 评测方式

按记号逐个比较输出。

## 样例

```
1 1 1000
1 1 1000
```

```
Safe
```

```
1000 1 2
1000 1 1
```

```
Crash
```

## 解法

设开始关门时车头离门d。门栅到达高度h需T=(H−h)/x，立即
刹车的停止距离为S=v²/(2a)。

安全刹停需要严格d>S。相等时车头停在门平面，门栅最终会
接触它。安全通过需要严格d+l<vT，因为车尾必须早于T离开；
等号也会接触。

延迟切断牵引不能改善两种界。延迟δ≥0后总停止距离为S+vδ，
任何允许轨迹的速度都不超过v。因此立即刹车最早停下，恒速
前进最早通过。两者都失败时，任意中间决策也无法成功。

若S+l<vT，所有门距都有安全选择：d>S立即刹，d≤S继续驶过。
否则选d=S，既不能严格停在门前，也不能使车尾严格早于T通过。
初始距离大于S，所以该关门时刻可达。故有不可避免事故当且仅当
S+l≥vT。即使只有孤立的一个危险时刻，也应输出Crash。

乘以正数2ax，得到精确整数比较

x·(v²+2al) ≥ 2av·(H−h)。

满足时包括等号输出Crash。无需除法、开方或误差常数。车长与
净高损失H−h都必须保留。

时间、空间均O(1)，算术次数固定。

Crash使用≥，因为两个边界都会接触。不能忽略车尾，把H−h
换成H，混淆停止时间与停止距离，或只判断未知的当前车距。
误差常数可能抹掉大整数乘积之间有意义的一单位差异。

## 各语言说明

左侧可达3,000,000,000，超出有符号32位；右侧至多1,998,000,000。
乘法前所有量就使用64位：C++的long long、Go的int64、Java的
long、Rust的i64；Python使用任意精度整数。均输出单词和末尾LF。
