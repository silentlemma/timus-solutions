# 1939. Граница между проездом и торможением

[Timus 1939](https://acm.timus.ru/problem.aspx?space=1&num=1939) · difficulty 841 · math

Original problem from Open Ural FU Championship 2012 | by Denis Dublennykh (prepared by Egor Shchelkonogov).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Машина длины l и высоты h едет к воротам с постоянной скоростью v.
Решётка с начальным просветом H может в любой момент начать опускаться
со скоростью x. После этого можно отключить тягу и тормозить с
замедлением a до остановки либо продолжить движение. Изначально
расстояния достаточно для остановки до ворот при немедленном торможении.
Есть ли момент начала закрывания, когда столкновения не избежать
никаким выбором? Любое касание считается аварией.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

Сначала l,h,H, где h<H, затем v,x,a. Все шесть чисел — положительные
целые не больше 1000. Длины заданы в сантиметрах, скорости в см/с,
замедление в см/с². Текущее расстояние до ворот не задано.

## Выходные данные

Crash, если существует начало закрывания с неизбежной аварией;
иначе Safe. Регистр этих слов обязателен.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
1 1 1000
1 1 1000
```

```
Safe
```


## Решение

Пусть d — расстояние от переднего края машины до ворот при начале
закрывания. До высоты h решётка доходит через T=(H−h)/x. Немедленное
торможение даёт тормозной путь S=v²/(2a).

Остановиться безопасно можно только при d>S. При равенстве передний
край останется в плоскости ворот и позже коснётся решётки. Проехать
безопасно можно только при d+l<vT: задний край должен выйти раньше T.
Равенство здесь тоже означает касание.

Задержка отключения тяги не улучшает границ: при задержке δ≥0 путь
до полной остановки равен S+vδ, а любая допустимая скорость не больше v.
Значит, никто не остановится раньше немедленного торможения и не
проедет раньше постоянной скорости. Если оба крайних варианта не
спасают, промежуточное решение тоже не спасёт.

При S+l<vT любой d безопасен: тормозим для d>S и едем дальше для d≤S.
Иначе выбираем d=S: остановка строго до ворот невозможна, а задний
край не успевает выйти строго раньше T. Такой момент достижим,
поскольку исходное расстояние больше S. Итак, авария возможна ровно
при S+l≥vT. Даже единственный опасный момент удовлетворяет условию.

Умножим на положительное 2ax и получим точное целое сравнение

x·(v²+2al) ≥ 2av·(H−h).

Если оно выполнено, включая равенство, выводим Crash. Делений и
произвольных эпсилонов нет. Длина машины и потеря просвета H−h
учитываются обязательно.

Время и память O(1): число арифметических операций фиксировано.

При равенстве нужен Crash: обе границы дают касание. Нельзя забыть
задний край, заменить H−h на H, перепутать время и путь торможения
или проверять только неизвестное текущее положение. Эпсилон способен
стереть значимую разницу в единицу между большими произведениями.

## Особенности языков

правая не больше 1 998 000 000. Все множители заранее 64-битные:
long long в C++, int64 в Go, long в Java, i64 в Rust. Python использует
целые произвольной длины. Везде одно слово и конечный LF.
