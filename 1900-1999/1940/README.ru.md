# 1940. Подсчёт лет без малого собственного делителя

[Timus 1940](https://acm.timus.ru/problem.aspx?space=1&num=1940) · difficulty 835 · number_theory

Original problem from Open Ural FU Championship 2012 | by Ksenia Karpova (prepared by Egor Shchelkonogov).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Проверяются B лет от A+1 до A+B включительно. Для номера n пробуют
делители 2,3,…,n−1 по порядку, по минуте на деление. Проверка завершается
при нахождении делителя или после k минут. Если делитель не найден,
год считается простым, даже когда число составное. Если собственные
кандидаты закончились раньше, год тоже проходит. Найти число таких лет.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

Три целых A,B,k: 2≤A,B≤10^9, 1≤k≤300. Максимальный номер равен
2·10^9. Разделители — пробельные символы, в том числе переводы строки.

## Выходные данные

Одно целое от 0 до B: число прошедших проверку лет в (A,A+B].

## Проверка

Сравнивается один целочисленный токен; пробелы несущественны.

## Примеры

```
23 7 3
```

```
2
```

## Решение

Последний доступный за k минут делитель — y=k+1, а не k. Составной
делитель ничего не добавляет: его меньший простой делитель проверен
раньше. Пусть p₁,…,p_s — все простые не больше y.

Сначала считаем числа, не кратные ни одному p_i. Обозначим через
φ(x,t) количество таких чисел в [1,x] для первых t простых, включая 1.
Имеем φ(x,t)=φ(x,t−1)−φ(⌊x/p_t⌋,t−1): удаляемые кратные взаимно
однозначно соответствуют оставшимся частным после деления на p_t.
Мемоизируем пары (x,t), используя один кэш для двух границ.

Простое n≤y тоже было бы удалено, хотя делить число на себя нельзя.
Возвращаем эти простые отдельно:

answer = φ(A+B,s)−φ(A,s) + π(min(A+B,y))−π(min(A,y)).

У удалённого составного есть собственный простой делитель ≤y, поэтому
других исключений нет. Единица сокращается при вычитании префиксов.
Так левая граница исключена, правая включена.

База рекурсии — b=min(s,6) простых с произведением W≤30030.
Предвычисляем количество допустимых остатков на каждом префиксе
периода. Тогда φ(x,b) получается за O(1) из целых периодов и остатка.

Выше базы φ(0,t)=0. При 1≤x<p_t остаётся только 1. При p_t≤x<p_t²
выжившее составное невозможно: оба его наименьших простых множителя
должны превышать p_t. Поэтому φ(x,t)=1+π(x)−t. Решето и префиксы
числа простых до L=301² покрывают все такие обращения. Остальные
состояния считают по рекуррентной формуле. В каждом переходе t
уменьшается, что вместе с базой доказывает корректность по индукции.

Пусть N=A+B, s=π(k+1)≤62, b≤6, W≤30030, L=301². Для каждой границы
X есть O(√N) различных частных ⌊X/d⌋; вложенное целочисленное деление
сохраняет этот вид. Состояний кэша O(s√N). Ожидаемое время —
O(L log log L + bW + s√N), память O(L+W+s√N), глубина стека ≤s.
Решето и период малы; массива или цикла длины B нет.

Начинать с A+1, включать A+B, проверять до k+1. Составные без малого
делителя проходят: 25 при k=3. Простое нельзя вычеркнуть делением
на себя. Добавление составного делителя может не менять ответ.
Не нужны ни перебор миллиарда лет, ни включения-исключения по всем
подмножествам без отсечений.

## Особенности языков

Границы и количества помещаются в знаковые 32 бита: N≤2·10^9,
ответ≤10^9. Ключ кэша требует 64 бита: x сдвигается на шесть бит,
затем дописывается t. В C++, Go, Rust стандартные хеш-таблицы;
в Java растущая таблица открытой адресации на примитивных массивах
экономит объекты. В Python целые неограниченные, префиксы периода —
массивы unsigned short. Только стандартные библиотеки, в конце LF.
