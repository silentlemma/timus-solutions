# 1951. Подсчёт общих комплексных корней

[Timus 1951](https://acm.timus.ru/problem.aspx?space=1&num=1951) · difficulty 1789 · number_theory

Original problem from Ural FU contest. Kontur Cup. Petrozavodsk training camp. Winter 2013 | by Mikhail Rubinchik (prepared by Olga Soboleva).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Посчитать комплексные x, одновременно удовлетворяющие xⁿ=A=a+bi и
xᵐ=C=c+di, где i²=−1. Коэффициенты целые, обе правые части ненулевые,
показатели положительны. Ограничения: 1 секунда, 64 МБ.

## Входные данные

Первая строка a,b,n, вторая c,d,m.
−10¹⁸≤a,b,c,d≤10¹⁸ включительно, 1≤n,m≤100.
Хотя бы одна из a,b и хотя бы одна из c,d ненулевая.

## Выходные данные

Одно целое число — количество общих комплексных корней.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
0 1 2
1 0 2
```

```
0
```

```
1 0 2
1 0 4
```

```
2
```

## Решение

Пусть g=gcd(n,m), p=n/g, q=m/g, тогда gcd(p,q)=1. Ответ g при
A^q=C^p, иначе ноль. Необходимость следует из возведения уравнений
в степени q и p. Для достаточности выберем целые u,v с up+vq=1 и
положим Y=A^u C^v. Отрицательные степени определены, ведь A,C ненулевые.
Условие совместности даёт Y^p=A, Y^q=C. Все решения x^g=Y подходят
исходной системе, а каждый общий корень имеет x^g=A^u C^v. У ненулевого
комплексного Y ровно g различных корней степени g — это и есть ответ.

Степени гауссовых целых сравним точно по модулям. Решетом найдём простые
до L=10000 и возьмём первые K=510 не меньше 5000. В этом интервале
560 простых, выбранные начинаются с 5003 и заканчиваются 9521. Приводим
обе координаты, используем двоичное возведение в степень и сравниваем
две координаты для каждого модуля. Любое отличие даёт ноль; все совпали — g.

Проверка детерминированная. Каждая координата Z^e по модулю не больше
(|Re Z|+|Im Z|)^e. Сумма входных модулей ≤2·10¹⁸<2⁶¹, p,q≤100.
Поэтому каждая координатная разность D между A^q и C^p удовлетворяет
|D|<2·(2·10¹⁸)^100<2⁶¹⁰¹. Каждый выбранный простой больше
4096=2¹², значит их произведение P>2^(510·12)=2⁶¹²⁰>|D|.
Совпадение остатков означает делимость D на каждый различный простой,
следовательно на P. Единственное такое целое с |D|<P — ноль. Это верно
для обеих координат. Здесь точная граница целых чисел, а не оценка
вероятности коллизии.

Умножение комплексных пар по модулю:
(r₁r₂−i₁i₂, r₁i₂+i₁r₂), с приведением обеих координат. Это гомоморфизм
колец; кольцо гауссовых остатков не обязано быть полем, поскольку нет
деления и вычисления обратных элементов.

O(L log log L + K log E) времени и O(L) памяти, E=max(n,m), L=10000,
K=510. Решето строим один раз. При фиксированных L,K из ограничений
само сравнение занимает O(log E) времени и фиксированную память.

Показатели нужно делить на g: Aᵐ=Cⁿ может выполняться без общих корней.
Важны обе координаты, фаза и отрицательные значения. Вещественные модули
и углы не доказывают равенство. Нескольких простых мало — нужна полная
граница произведения. Не предполагать поле гауссовых остатков и не забывать,
что по условию обе правые части ненулевые.

## Особенности языков

В нативных языках коэффициенты читаются как знаковые 64-битные числа.
Отрицательные остатки приводятся в 0..prime−1 до любого умножения.
Промежуточные значения после приведения меньше 2·9999²<2³¹−1 по модулю,
но версии всё равно используют 64 бита. Сырые коэффициенты 10¹⁸ умножать
нельзя. Только стандартная библиотека. Python/C++/Go/Java сохраняют модули
один раз, Rust строит список и передаёт его в функцию сравнения.
