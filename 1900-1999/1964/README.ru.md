# 1964. Минимальное общее пересечение

[Timus 1964](https://acm.timus.ru/problem.aspx?space=1&num=1964) · difficulty 172 · math

Original problem from Open Ural FU Personal Contest 2013 | by Alexander Ipatov.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть множество из n различных элементов и k его подмножеств. Известно
лишь, что в подмножестве i находится не менее a_i элементов. Найти
минимальное возможное число элементов, принадлежащих одновременно всем
k подмножествам. Перекрытия произвольны. Лимиты: 1 секунда, 64 МБ.

## Входные данные

Первая строка содержит n,k: 1≤n≤10⁹, 2≤k≤20. Во второй строке k целых
чисел a_i, для каждого 1≤a_i≤n.

## Выходные данные

Одно целое число — минимальный размер пересечения всех k множеств.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
1000000000 2
800000000 800000000
```

```
600000000
```

```
1000000000 2
500000000 500000000
```

```
0
```

## Решение

В первом примере в каждом множестве может отсутствовать не более
200 000 000 элементов. Даже непересекающиеся пропуски покроют лишь
400 000 000 из миллиарда. Остальные 600 000 000 обязательно общие;
непересекающиеся пропуски достигают этой границы. Во втором два
множества можно выбрать как разные половины общей совокупности,
поэтому пересечение пусто.

Рассмотрим дополнения. Пусть b_i=n−a_i — максимальное число элементов,
отсутствующих в множестве i. Чтобы элемент не попал в общее пересечение,
он должен отсутствовать хотя бы в одном множестве. Объединение дополнений
содержит не больше min(n,Σb_i) элементов. Поэтому пересечение не меньше

max(0,n−Σb_i) = max(0,Σa_i−(k−1)n).

Докажем достижимость. Пронумеруем элементы циклически от 0 до n−1.
Первому дополнению отдадим первые b_1 последовательных номеров,
следующему — следующие b_2 и так далее, переходя через n−1 к нулю.
Каждое b_i<n, поэтому внутри одного дополнения номера не повторяются,
и его размер ровно b_i. Исходное множество имеет ровно a_i элементов,
что удовлетворяет и условию «не менее».

При Σb_i<n все дополнения непересекающиеся, их объединение имеет размер
Σb_i. При Σb_i≥n последовательный обход посетит все n номеров, то есть
объединение покроет всю совокупность. В обоих случаях размер объединения
равен min(n,Σb_i), и нижняя граница пересечения достигается.

Строить множества в программе не нужно. Начинаем с n, вычитаем все
n−a_i, затем заменяем отрицательный итог нулём.

Время `O(k)`, память `O(k)`: реализации сохраняют k входных значений.
Сам аккумулятор требует `O(1)` дополнительной памяти.

Заданы нижние границы размеров, а не вероятности или независимые
события. Попарные пересечения и размер наименьшего множества не дают
искомый минимум. Отрицательный результат заменяем нулём. Итог не больше
n, но промежуточные суммы близки к 20·10⁹, а аккумулятор может опуститься
ниже −2³¹: нужны знаковые 64-битные числа. Если все a_i=n, ответ равен n.

## Особенности языков

C++ использует int64_t, Go 1.14 — int64, Java 8 — long, Rust 1.75 — i64.
Беззнаковый аккумулятор Rust не подходит из-за отрицательных промежуточных
значений. Python 3.12 считает точно целыми числами. Все версии один раз
считывают k границ.
