# 1964. 中国方言

[Timus 1964](https://acm.timus.ru/problem.aspx?space=1&num=1964) · difficulty 172 · math

Original problem from Open Ural FU Personal Contest 2013 | by Alexander Ipatov.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

全集含 n 个不同元素，有 k 个子集。只知道第 i 个子集至少包含 a_i
个元素，子集之间可以任意重叠。求同时属于全部 k 个子集的元素数量
的最小可能值。时间限制 1 秒，内存限制 64 MB。

## 输入

第一行 n,k，满足 1≤n≤10⁹、2≤k≤20。第二行 k 个整数 a_i，均满足
1≤a_i≤n。

## 输出

一个整数：所有 k 个子集的公共交集的最小大小。

## 评测方式

按记号逐个比较输出。

## 样例

```
1000000000 2
800000000 800000000
```

```
600000000
```

```
1000000000 2
500000000 500000000
```

```
0
```

## 解法

第一个样例中，每个集合最多缺少 200,000,000 个元素。即使两个缺失
集合互不相交，也只覆盖十亿中的 400,000,000 个，至少剩下
600,000,000 个公共元素；互不相交的缺失集合能达到此值。第二个样例
可让两个集合分别占据不同的一半，公共交集为空。

考虑补集，令 b_i=n−a_i。第 i 个集合最多缺少 b_i 个元素。一个元素
不在公共交集中，当且仅当它至少在一个补集中。所有补集的并集大小
至多为 min(n,Σb_i)，故公共交集至少有

max(0,n−Σb_i) = max(0,Σa_i−(k−1)n)

个元素。

还需证明可达到该下界。将元素按 0,…,n−1 循环编号，依次给各补集
分配接下来的 b_i 个连续编号，到末尾后从零继续。每个 b_i<n，所以
同一个补集内不会重复，大小恰好是 b_i。对应原集合大小恰好为 a_i，
因此也满足“至少”的要求。

若 Σb_i<n，补集互不相交，并集大小为 Σb_i。若 Σb_i≥n，连续行走
至少绕过全部 n 个编号，并集就是全集。因此并集大小始终可达到
min(n,Σb_i)，公共交集正好达到所述下界。

程序不需要真正构造集合。从 n 开始依次减去 n−a_i，最后与零取较大值。

时间 `O(k)`，空间 `O(k)`：这些实现保存 k 个输入值。累加器本身只需
`O(1)` 额外空间。

输入是集合大小的下界，不是概率或独立事件。不能只看最小集合或相加
两两交集。结果为负时取零。虽然最终答案不超过 n，中间总和可以接近
20·10⁹，减法结果可能小于 −2³¹，必须使用有符号 64 位整数。所有
a_i=n 时答案是 n。

## 优化解法

优化的 C++ 解法用 `scanf` 代替 `iostream` 读入，每读到一个值就立即从累加器中减去
`n − a_i`，而不是把 k 个值存进向量，所以只需 `O(1)` 空间；累加器仍是有符号 64 位
整数（`long long`），因为要减去多达 20 个、每个多达 10⁹ 的差额：
{1964_math_optimized.cpp}。

优化的 Java 解法计算同样的数，但用 `BufferedReader` 和 `StringTokenizer` 读取输
入，而不用 `Scanner`，因为 `Scanner` 准备正则表达式要花时间和内存：
{1964_math_optimized.java}。
