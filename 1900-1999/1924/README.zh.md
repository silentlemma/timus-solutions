# 1924. 奇偶性不变的符号游戏

[Timus 1924](https://acm.timus.ru/problem.aspx?space=1&num=1924) · difficulty 39 · math

原题为经典题，出自 2012 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

整数 1 到 n 按顺序排列。两队交替在尚未填写的相邻整数间隙放置
符号 + 或 −。先手队 `black` 希望最终表达式为偶数，`grimy` 希望为奇数。
双方最优行动，求胜队。n=1 时没有间隙，表达式就是 1。
限制：1 秒，64 MB。

## 输入

一个整数 n，1≤n≤50。

## 输出

若偶数目标队获胜，输出 `black`，否则输出 `grimy`。

## 评测方式

精确比较单个小写单词词元。

## 样例

```
1
```

```
grimy
```

```
4
```

```
black
```

## 解法

把数 x 前面的 + 改成 −，结果改变 2x，是一个偶数。所以双方能得到的任何表达式都与
1 + 2 + … + n = n(n + 1)/2 奇偶性相同，任何走法都改变不了胜者：和为偶数时 black
获胜，为奇数时 grimy 获胜。`O(1)`。

注意：n = 1 时根本没有走法，但仍由 1 的奇偶性决定胜负。

## 优化解法

优化的 C++ 解法用 `scanf` 读入、用 `puts` 输出，而不是 `iostream`：116 KB，而不是
380 KB。公式不变。

优化的 Java 解法直接从 `System.in` 逐字节解析这个数，而不是使用 `Scanner`：
336 KB，而不是 1616 KB，时间不变。
