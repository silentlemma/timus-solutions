# 1924. 奇偶性不变的符号游戏

[Timus 1924](https://acm.timus.ru/problem.aspx?space=1&num=1924) · difficulty 39 · math

原题为经典题，出自 2012 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

整数 1 到 n 按顺序排列。两队交替在尚未填写的相邻整数间隙放置
符号 + 或 −。先手队 `black` 希望最终表达式为偶数，`grimy` 希望为奇数。
双方最优行动，求胜队。n=1 时没有间隙，表达式就是 1。
限制：1 秒，64 MB。

## 输入

一个整数 n，1≤n≤50。

## 输出

若偶数目标队获胜，输出 `black`，否则输出 `grimy`。

## 评测方式

精确比较单个小写单词词元。

## 样例

```
1
```

```
grimy
```

```
4
```

```
black
```

## 解法

把整数 x 前的 + 改为 −，结果改变 −2x，是偶数。
所以任何完整表达式与全加号之和 S=n(n+1)/2 奇偶性相同。
间隙、符号及行动顺序都不能改变胜负。S 为偶数输出 black，
否则输出 grimy。没有行动的 n=1 也由公式正确处理。

论证覆盖所有完成的表达式，因此最优策略无法改变结论，无需博弈搜索。

时间 O(1)，额外空间 O(1)。

减去奇数仍有奇数的模 2 贡献。不要模拟回合或依据最后行动方判断。
n=1 没有间隙并不意味着平局。先除以 2，再检查总和奇偶性。

C++、Go、Java 使用标准输入工具读取单个整数。
