# 1924. Игра со знаками и неизменной чётностью

[Timus 1924](https://acm.timus.ru/problem.aspx?space=1&num=1924) · difficulty 39 · math

Оригинальная задача — фольклор; Уральская региональная олимпиада по программированию 2012.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В ряд записаны числа от 1 до n. Две команды по очереди ставят + или −
в свободный промежуток между соседними числами. Первая команда `black`
хочет получить чётный результат, `grimy` — нечётный. Обе играют оптимально,
black ходит первой. Определить победителя. При n=1 промежутков нет,
выражение равно 1. Лимиты: 1 секунда, 64 МБ.

## Входные данные

Одно целое число n, 1≤n≤50.

## Выходные данные

Ровно `black`, если побеждает команда чётного результата, иначе `grimy`.

## Проверка

Точное сравнение единственного слова с учётом строчного регистра.

## Примеры

```
1
```

```
grimy
```

```
4
```

```
black
```

## Решение

Замена + перед числом x на − изменяет результат на −2x, то есть
на чётное число. Поэтому любое завершённое выражение имеет ту же
чётность, что сумма всех положительных чисел S=n(n+1)/2.
Выбор промежутков, знаков и порядка ходов не влияет на победителя.
При чётном S выводим black, при нечётном — grimy. Случай n=1 без ходов
также обработан этой формулой.

Доказательство охватывает все варианты завершённого выражения,
поэтому оптимальная стратегия не может изменить результат.

O(1) времени и O(1) дополнительной памяти.

Вычитаемое нечётное число сохраняет нечётный вклад по модулю 2.
Не нужно моделировать ходы или смотреть на последнюю ходящую команду.
Отсутствие промежутков при n=1 не означает ничью. Чётность проверяется
после деления произведения на 2.

## Особенности языков

Все пять версий используют целые и точное деление на 2. Произведение
n(n+1) не больше 2550, сумма не больше 1275, обычных целых достаточно.
Python и Rust читают текст, C++, Go и Java считывают одно число
стандартными средствами ввода.
