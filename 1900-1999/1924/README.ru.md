# 1924. Игра со знаками и неизменной чётностью

[Timus 1924](https://acm.timus.ru/problem.aspx?space=1&num=1924) · difficulty 39 · math

Оригинальная задача — фольклор; Уральская региональная олимпиада по программированию 2012.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В ряд записаны числа от 1 до n. Две команды по очереди ставят + или −
в свободный промежуток между соседними числами. Первая команда `black`
хочет получить чётный результат, `grimy` — нечётный. Обе играют оптимально,
black ходит первой. Определить победителя. При n=1 промежутков нет,
выражение равно 1. Лимиты: 1 секунда, 64 МБ.

## Входные данные

Одно целое число n, 1≤n≤50.

## Выходные данные

Ровно `black`, если побеждает команда чётного результата, иначе `grimy`.

## Проверка

Точное сравнение единственного слова с учётом строчного регистра.

## Примеры

```
1
```

```
grimy
```

```
4
```

```
black
```

## Решение

Если перед числом x заменить + на −, результат изменится на 2x, то есть
на чётное число. Значит, любое выражение, которое могут составить игроки,
имеет ту же чётность, что и 1 + 2 + … + n = n(n + 1)/2, и никакие ходы не
меняют победителя: при чётной сумме побеждает black, при нечётной —
grimy. `O(1)`.

Тонкое место: при n = 1 ходов нет вовсе, и всё равно решает чётность 1.

## Оптимизированные решения

Оптимизированное решение на C++ читает через `scanf` и печатает через
`puts` вместо `iostream`: 116 КБ вместо 380 КБ. Формула та же.

Оптимизированное решение на Java разбирает число побайтно из `System.in`
вместо `Scanner`: 336 КБ вместо 1616 КБ при том же времени.
