# 1914. 整数输出与非整数输入

[Timus 1914](https://acm.timus.ru/problem.aspx?space=1&num=1914) · difficulty 3684 · matrix

原题作者 Alexander Ipatov（由 Dmitry Ivankov 准备），出自 NEERC 2012 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个 n×n 整数矩阵把 n 个可操作控制器的实数转角映射为
n 个受保护控制器的转角。初始转角都是整数。判断是否存在
至少一个坐标不是整数的实向量 x，使 Ax 的每个坐标均为整数。
只需判断存在性。限制：2 秒，64 MB。

## 输入

n，1≤n≤100，然后 n 行，每行 n 个 [−100,100] 内的整数。
第 j 行第 i 个数表示输入 i 逆时针转一圈时输出 j 的转动圈数。
负数表示顺时针，输入可取任意实数。

## 输出

存在时输出 `Power of magic saves lives`，否则输出 `Death`。

## 评测方式

精确比较输出词元，无需输出转角或近似行列式。

## 样例

```
3
1 2 0
4 3 0
0 0 0
```

```
Power of magic saves lives
```

## 解法

答案为 `Death` 当且仅当 det(A)=±1。

若矩阵奇异，取非零核向量并缩放，使某个坐标绝对值严格位于
0 与 1 之间，其像为零，因此可行。若 det(A)=±1，伴随矩阵
公式表明 A⁻¹ 是整数矩阵，故 Ax 为整数必然迫使 x 为整数。
若 |det(A)|>1，则 A⁻¹ 至少有一列非整数；否则整数矩阵 A⁻¹
的行列式却是非整数 1/det(A)，矛盾。该列的像是整数单位向量。

### 有界模数的精确证明

C++、Go、Java、Rust 在若干互不相同的固定素数下进行高斯消元。
每个 p 严格位于 2²⁹ 与 2³⁰ 之间，主元用 a^(p−2) mod p 求逆，
换行改变符号，无主元表示模 p 行列式为零。负数需归一化。

整数行列式若为 ±1，所有素数下的符号必须相同。若某个余数既非
1 也非 p−1，或不同素数给出相反符号，就确定不是单位行列式。
这不是随机检验：每行范数 ≤100√n≤1000<2¹⁰，由 Hadamard
不等式得 |det(A)|<2^(10n)。取 K=ceil((10n+1)/29)≤35 个素数，
乘积 M>2^(10n+1)。若余数全对应同一符号 s，则 M 整除 det(A)−s，
而此差绝对值小于 M，只能为零。无需重建行列式，也无需大整数。
模乘积小于 2⁶⁰，64 位足够。

### Python 的无分数消元

Python 使用任意精度整数与 Bareiss 算法。当前主元为 p、上次
主元为 q（初始 1）时，把剩余元素更新为
(aᵢⱼp−aᵢₖaₖⱼ)/q，再清零主元下方。子式恒等式保证整除。
需要时交换非零行，无主元则奇异。最后对角元等于行列式乘以
换行符号，只需比较绝对值；n=1 直接检查唯一元素。

两种算术后端实现同一精确判定。模数版本使用
`O(n³K + nK log p)` 次模运算及 `O(n²)` 个机器字。
Bareiss 使用 `O(n³)` 次大整数运算和 `O(n²)` 个整数，算术成本
取决于整数位数。

样例最后一行全零，因此可行。单个零系数可行，±1 不可行，
系数 2 则允许用半圈得到整数输出。

可逆不等于答案为否，只有行列式 ±1 才不允许所需输入。
注意各素数下符号一致、换行、零主元，不能只试几个随机模数。
浮点行列式可能在严重抵消后丢失小整数结果。转置不改变行列式，
任意交换行列则会影响符号。

## 各语言说明

四种模数实现使用 64 位乘法与最多 35 个已验证素数。Rust 使用
无符号余数，其他语言归一化至非负有符号整数。Java 使用字节输入。
Python 全程精确整除，不做浮点消元。每个程序独立且只用标准库。
