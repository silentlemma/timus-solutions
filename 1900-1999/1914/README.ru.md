# 1914. Дробные входы и целые выходы

[Timus 1914](https://acm.timus.ru/problem.aspx?space=1&num=1914) · difficulty 3724 · matrix

Автор оригинальной задачи — Александр Ипатов (подготовка — Дмитрий Иванков); NEERC 2012, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Целочисленная матрица n×n переводит вещественные повороты n доступных
регуляторов в повороты n защищённых. Изначально все повороты целые.
Нужно понять, существует ли вещественный вектор x с хотя бы одной
нецелой координатой, для которого Ax целиком целочисленен.
Требуется только ответ о существовании. Ограничения: 2 секунды, 64 МБ.

## Входные данные

n, 1≤n≤100, затем n строк по n целых чисел в [−100,100].
Элемент строки j и столбца i задаёт реакцию защищённого регулятора j
на один оборот доступного i против часовой стрелки. Отрицательный поворот
означает движение по часовой стрелке; входные повороты могут быть вещественными.

## Выходные данные

Если подходящий x существует, выведите `Power of magic saves lives`,
иначе — `Death`.

## Проверка

Точное сравнение токенов. Повороты или приближённый определитель выводить не нужно.

## Примеры

```
3
1 2 0
4 3 0
0 0 0
```

```
Power of magic saves lives
```

## Решение

Ответ `Death` получается ровно при det(A)=±1.

Если матрица вырождена, берём ненулевой вектор ядра и масштабируем так,
чтобы модуль одной координаты лежал строго между 0 и 1. Образ равен нулю,
значит, условие выполнено. При det(A)=±1 формула через присоединённую
матрицу показывает, что A⁻¹ целочисленна. Тогда целочисленность Ax
влечёт целочисленность x. Наконец, при |det(A)|>1 хотя бы один столбец
A⁻¹ нецелый: иначе целочисленная матрица A⁻¹ имела бы нецелый определитель
1/det(A). Этот столбец переводится в целый единичный вектор и подходит.

### Точный сертификат по модулям

C++, Go, Java и Rust считают определитель по разным фиксированным
простым p между 2²⁹ и 2³⁰. Исключение Гаусса в простом поле использует
перестановки строк и обратный элемент pᵢᵥₒₜ^(p−2) mod p. Если ненулевого
ведущего элемента нет, остаток определителя равен нулю. Отрицательные
числа нормализуются; перестановка строки меняет знак определителя.

Целый определитель ±1 обязан иметь один и тот же знак по всем модулям.
Если остаток не равен 1 или p−1, либо знаки по разным простым не совпали,
определитель не единица по модулю. Проверка конечная и детерминированная:
норма строки ≤100√n≤1000<2¹⁰, поэтому по неравенству Адамара
|det(A)|<2^(10n). Достаточно K=ceil((10n+1)/29)≤35 простых.
Их произведение M>2^(10n+1). Если все остатки соответствуют знаку s,
M делит det(A)−s, а модуль этой разности меньше M. Значит, det(A)=s.
Восстанавливать число китайской теоремой об остатках не требуется.
Произведения остатков меньше 2⁶⁰ и помещаются в 64 бита.

### Python: исключение без дробей

Python использует длинные целые и алгоритм Барейса. Для текущего ведущего
элемента p и предыдущего q (вначале 1) каждый элемент оставшейся подматрицы
заменяется на (aᵢⱼp−aᵢₖaₖⱼ)/q. После этого ведущий столбец снизу обнуляется.
Тождество для миноров гарантирует деление без остатка. Ненулевую строку
переставляем на ведущую позицию; если её нет, матрица вырождена.
Последний диагональный элемент — определитель с точностью до знака
перестановок, который не влияет на абсолютную величину. При n=1 сразу
проверяется единственный элемент.

Оба варианта проверяют один точный критерий. Модульные версии требуют
`O(n³K + nK log p)` операций и `O(n²)` машинных слов. Барейс выполняет
`O(n³)` операций с длинными целыми и хранит `O(n²)` целых; стоимость
арифметики зависит от длины чисел.

В примере последняя строка нулевая, поэтому ответ положительный.
Скалярный ноль также подходит, ±1 не подходят, а коэффициент 2 допускает
половину оборота с целым выходом.

Одной невырожденности недостаточно: запрещают нужный вход только ±1.
Нельзя смешивать знаки по простым, забывать перестановки строк и нулевые
ведущие элементы или ограничиваться несколькими случайными модулями.
Вещественный определитель теряет маленький целый результат при сокращениях.
Транспонирование не меняет определитель, произвольные перестановки меняют знак.

## Особенности языков

Четыре модульные версии используют 64-битные произведения, точное
возведение в степень и не более 35 проверенных простых. Rust хранит
остатки без знака, остальные нормализуют их в знаковом типе. В Java
быстрый байтовый ввод. Python делит целые точно, без вещественного Гаусса.
Каждый файл самодостаточен и использует стандартную библиотеку.
