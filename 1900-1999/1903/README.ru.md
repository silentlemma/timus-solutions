# 1903. Counting Sorted Selections

[Timus 1903](https://acm.timus.ru/problem.aspx?space=1&num=1903) · difficulty 941 · combinatorics

Original problem by Alex Samsonov, prepared by Alexander Fetisov, from Ural Championship 2012.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны n различных объектов с номерами и классами. Выберите ровно t объектов,
включая заданный k. Их можно упорядочивать по неубыванию класса, произвольно
переставляя равные классы. Объект k должен иметь возможность занять позицию x.
Посчитайте наборы, а не порядки, по модулю P = 10⁹+7.
Ограничения: 1 секунда и 64 МБ.

## Входные данные

Сначала n и t, где 1 ≤ t < n ≤ 5000. Далее n классов cᵢ от 1 до 5000.
В конце k и x, 1 ≤ k ≤ n, 1 ≤ x ≤ t. Номер k относится к исходному
списку, а не к позиции после сортировки.

## Выходные данные

Количество подходящих наборов по модулю 10⁹+7.

## Проверка

Точное сравнение единственного целого токена; режим `tokens`.

## Примеры

### Пример 1

```
5 3
2 1 1 3 1
2 3
```

```
1
```

### Пример 2

```
4 2
1 1 1 1
1 2
```

```
3
```

## Решение

Пусть v = cₖ. Обозначим через L число строго меньших классов, через G —
строго больших. Сам k не входит ни в одну группу. Среди t−1 остальных
выбранных объектов пусть a имеют меньший класс, b — больший.

Блок равных классов занимает позиции от a+1 до t−b. Значит k может
занять x тогда и только тогда, когда `a ≤ x−1` и `b ≤ t−x`.
Множитель за перестановки равных объектов не нужен: достаточно существования
одного подходящего порядка.

Начнём со всех `C(n−1,t−1)` наборов, содержащих k. Исключим слишком
большое количество меньших классов:

`A = Σ(a=x…min(L,t−1)) C(L,a) C(n−1−L,t−1−a)`.

Затем исключим слишком большое количество больших классов:

`B = Σ(b=t−x+1…min(G,t−1)) C(G,b) C(n−1−G,t−1−b)`.

В каждом слагаемом выбирается точное число из одной строгой группы,
остальные — из её дополнения, в том числе равные k. Плохие семейства
не пересекаются: одновременно потребовалось бы `a+b ≥ t+1`, хотя других
выбранных объектов всего t−1. Ответ: `C(n−1,t−1) − A − B` по модулю P.

Изначально каждый содержащий k набор учтён ровно один раз. Он исключается
ровно тогда, когда блок равных классов не содержит x. Двойного исключения
нет; в оставшемся наборе k можно поместить на x. Это доказывает формулу.

Предвычислим факториалы и обратные факториалы до n−1. Модуль P простой,
n < P, поэтому все факториалы обратимы. Один раз возведём
`factorial[n−1]` в степень `P−2`, затем заполним обратные факториалы назад.
Сочетание `C(N,r) = N! / (r!(N−r)!)` вычисляется за постоянное время;
при r вне [0,N] оно равно нулю.

В каждой сумме не более n слагаемых. Время `O(n + log P)`, память `O(n)`;
при фиксированном модуле время линейно по n. Сортировка не нужна.

В первом примере третий выбранный класс равен 1 лишь при выборе всех трёх
объектов класса 1: номеров 2, 3, 5. Во втором к объекту 1 можно выбрать
любой из трёх остальных; наборов три, а не шесть перестановок.

## Особенности языков

Во всех пяти версиях две суммы непересекающихся плохих семейств.
C++, Go, Java и Rust используют 64-битные произведения с приведением
по модулю между умножениями; произведение сразу трёх остатков переполнится.
Вычитания нормализуются сразу. Python использует CPython 3.12 и модульный `pow`.

Важно сравнивать классы строго, всегда включать k, различать номера
равных объектов и допускать любой порядок внутри их блока. Пустые суммы
равны нулю; уникальный минимум не может занять вторую позицию.

Ответы совпадают с перебором всех 47 013 помеченных подмножеств на 9117
малых запросах.
