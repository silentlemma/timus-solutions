# 1957. 所有可能的最终排名

[Timus 1957](https://acm.timus.ru/problem.aspx?space=1&num=1957) · difficulty 4747 · math

Original problem from Ural FU contest. Kontur Cup. Petrozavodsk training camp. Winter 2013 | by Mikhail Rubinchik (prepared by Denis Dublennykh).

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

四队两两各赛一场，共六场。部分比分已知，剩余比赛可进任意多个球。
胜得 3 分，平各得 1 分，负得 0 分。先按积分，再按进球数减失球数排名。
两项都相同则抽签可任选先后。列出全部可能最终排名。限制：1 秒、64 MB。

## 输入

先给已赛场数 n，0≤n≤6，再给 n 行 a,b,c,d：1≤a<b≤4，0≤c,d≤10，
分别是 a、b 的进球数。每对队伍至多出现一次。10 的限制仅用于已赛比分。

## 输出

先输出不同排名数 m，1≤m≤24，再输出 m 个 1,2,3,4 的排列，依次表示
第一至第四名。每个排列一次，按字典序。只按名次区分结果，不按未来比分。

## 评测方式

按记号逐个比较输出。

## 样例

```
5
1 2 1 0
1 3 2 1
1 4 3 2
2 3 1 0
2 4 5 4
```

```
2
1 2 3 4
1 2 4 3
```

## 解法

枚举每场未赛比赛的平、前队胜、后队胜三种结果，最终积分随之确定。
平局净胜球变化为零。每场决胜比赛的获胜优势写为 1+x，x 为非负整数，
可由 (1+x):0 实现。把 1 计入基础净胜球 g，保留未知变量 x。

枚举 24 个排名。若相邻后队积分更多，立即排除。同分的相邻 a 在 b 之前
要求 final_g[a]≥final_g[b]。至多三个此类条件，加上 x≥0，得到至多六个
整数变量的 A·x≤b。等号允许抽签任意排序；同分块内相邻比较由传递性足够。

### 精确整数可行性

每行除以系数的正 gcd h，右端 b 替为 floor(b/h)。对整数变量完全等价，
负 b 也必须向下取整。全零左端而右端为负即矛盾，否则删除该行。
相同系数向量仅保留最小右端。

选择正系数全为 1 或负系数全为 −1 的变量 x。将一个下界及上界写成
−p·x+L≤bL 和 q·x+U≤bU，p,q>0。对每对上下界生成
q·L+p·U≤q·bL+p·bU，保留不含 x 的行，消去 x。

必要性由加权相加得到。若所有下界系数为 −1，则其余变量为整数时，
每个下界都是整数。取最大下界，组合条件保证它满足所有上界。上界系数
全为 1 时，取最小整数上界同理。缺一侧表示该侧无界。因此投影保持整数
可行性，而非仅仅实数可行性。再规范化并重复，最终常数不矛盾即成功。

为什么总能选出这种变量？这是四队系数族的有限性质。按待检查排名重编号，
六对队伍各可无变量或取两个优势方向之一，共 3⁶ 种；三个相邻同分约束
由 2³ 个掩码选择。[tests/gen.py](tests/gen.py) 穷举全部 5832 族和
每条可用单位侧消元路径，验证 13,286 个不同中间系统、44,054 步，无死路。
这也涵盖任意变量顺序和同成本选择。常数不影响系数轨迹：gcd、合并平行行、
投影仅由系数确定；矛盾只会使程序提前结束。这是该特殊性质的可执行有限证明。

故保留排列当且仅当存在整数未来比分实现它，最后按生成时的字典序输出。

r=6−n 场未赛，至多 3ʳ 个结果模式、24 个排列。消元至多六步，规范化系统
最多 14 行，系数绝对值至多 31。对固定四队，消元工作 E 是常数，时间
O(3ʳ·24·E)，空间 O(1)。除 gcd 前系数至多 2·31²；初始 |b|≤66，六步
后不超过 66·62⁶<2⁴²，64 位有符号整数足够。负右端必须向下取整。
不能限制未来进球 ≤10、忽略净胜球、禁止抽签或接受非整数优势。

## 各语言说明

五种版本均为精确整数投影。Python 用大整数，其余用 64 位整数。
Go 1.14、Java 8 自行生成字典序排列。Java 用 Math.floorDiv，Rust 用
正除数 div_euclid，C++、Go 在负余数时修正截断除法。Rust 仅用标准库。
CPython 选择由资源测试核验。
