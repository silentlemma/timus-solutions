# 1967. 二进制分块的最小十进制拼接

[Timus 1967](https://acm.timus.ru/problem.aspx?space=1&num=1967) · difficulty 5145 · greedy

原题作者 Ilya Zvigintsev，出自 2013 年乌拉尔联邦大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把整数 1,2,…,n 的二进制表示依次拼成 S，将 S 划分为非空块，只允许
在位 1 前切分，因此每块无前导零。把每块转成正十进制整数，再按原顺序
拼接十进制表示。使最终整数最小，输出任意最优划分的位长度。最初数字
1 的表示属于 S。时间限制 1 秒，内存限制 64 MB。

## 输入

一个整数 n，2≤n≤100,000。

## 输出

两行：块数，以及从左到右的各块正位长度，恰好覆盖 S。任意达到最小
十进制整数的划分都接受。

## 评测方式

检查器核对块数、总长度以及各块起点是否合法，并用下面证明的交换准则检查最优性；任何最优划分都被接受。

## 样例

```
5
```

```
2
1 10
```

## 解法

n=5 时 S=11011100101。四位后缀 0101 以零开头，不合法；七位后缀
1100101 等于 101，不小于 100；十位后缀 1011100101 等于 741<1000。
下面的规则取最后十位，留下首位 1，十进制结果为 1||741=1741，整个
字符串合并则为 1765。

### 严格交换规则

相邻二进制块 A,B 的值为正整数 a,b，B 有 q 位，b 有 d 个十进制数字。
分开后的十进制值为 a·10^d+b，合并后的二进制值为 a·2^q+b。因此切分
严格更优当且仅当 10^d<2^q，称 B 为节省块；否则合并严格更优。正整数
d 时不可能相等，因为十的幂含因子五。

将局部正十进制数替换为更小值，也会使外部固定块的整个拼接更小：
更短表示减少总位数，等长更小表示在相同前缀后按字典序取胜。因此规则
适用于任意划分内部。

### 末块被唯一确定

多块最优划分的末块必须节省，否则合并最后两块可严格改进。末块也不能
包含更短的节省后缀，否则在该后缀前切分可改进。因此末块必为整个剩余
串的最短真节省后缀。若存在这样的后缀，单块答案同样能被切分改进。

选择该后缀后递归处理前缀。前缀也必须最优，因为追加固定末块的十进制
表示保持数值顺序。若没有真节省后缀，任何多块划分的末块都会不节省，
故整个前缀保持一块最优。该贪心证明适用于所有以 1 开头的二进制串。

### 不使用浮点的后缀搜索

q 位数 b 满足 2^(q−1)≤b<2^q。若节省，阈值 T=10^d 位于 b 与 2^q
之间，故 T 的二进制长度恰好为 q。反过来，若 10^d 有 q 位且 q 位
后缀小于它，则 b≥2^(q−1)>10^(d−1)，b 确实有 d 个十进制数字，且节省。

按二进制长度递增枚举 10、100、1000、……，检查相应后缀首位为 1，且
按字典序严格小于等长阈值二进制串。首个成功者就是最短节省后缀。
若阈值长度达到剩余串长度，则没有真后缀可取，输出整个前缀。自右向左
剥离块后，将位长度列表反转。

阈值按需增长并缓存。原生版本以从右向左的进位把任意长二进制串乘十，
Python 用整数乘法及 bin。没有块长上限、机器字长限制、浮点对数或整个
结果的十进制转换。

令 L=|S|，K 为搜索到的最大阈值位长。保守时间上界为
`O(n log n + L K²)`，空间 `O(L+K²)`，包含缓存及输出。每次后缀搜索
检查 `O(K)` 个阈值，最多比较 `O(K²)` 位，构造 S 用 `O(n log n)` 时间。

`python tests/gen.py 100000 certify` 对有限输入域穷举 n=100,000 时全部 1,568,946 个
前缀终点，并累积每个合法 n 的路径工作量。得到 K≤226、至多 461,145
次阈值检查、比较字符上界 2,780,158，以及 131,447 个输出块。代码不把
这些值作为限制或截断搜索；正确性来自交换证明，可复现证书说明完整
输入域的工作量。

先比较十进制位数再比较字典序。必须包含初始 1，只能在 1 前切分，与
10^d 的比较必须严格。按后缀长度递增搜索并反转最终列表。64 位甚至
128 位都不够存全部阈值，小 n 也会出现长块。不要猜测块长上限或使用
浮点对数。

## 各语言说明

C++、Go 1.14、Java 8、Rust 1.75 用二进制字符串或字节向量保存幂，
以小进位实现乘十。Python 3.12 使用精确整数及 bin，不转成巨大十进制
结果。Java 原位比较字符，避免子串分配。各版本仅用标准库且无递归。
