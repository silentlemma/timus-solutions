# 1968. 恢复错层金字塔的颜色

[Timus 1968](https://acm.timus.ru/problem.aspx?space=1&num=1968) · difficulty 1640 · constructive

原题出自 2013 年乌拉尔联邦大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

金字塔由高一单位、水平底面为 2×2 正方形的块组成，底层覆盖 m×n。
每个上层向内偏移一单位，块网格的行列数各减一，直到某个维度只剩一块。
块可以为红色或无色，俯视图给出每个单位格被多少个红块覆盖。

恢复块颜色。红块不能恰好位于相同水平底面的无色块上方；部分重叠
无色块是允许的。保证至少一个有效布局。时间限制 1 秒，内存限制 64 MB。

## 输入

偶数 m,n，2≤m,n≤40；随后 m 行，每行 n 个非负整数，表示各单位格
的红块覆盖数。数据保证符合几何及颜色限制。

## 输出

从底层到顶层输出，R 为红色、W 为无色。自零编号的第 z 层有 m/2−z
行，每行 n/2−z 个字符。相邻层间空一行，任意有效恢复均接受。

## 评测方式

检查器核对各层尺寸、符号、俯视图是否完全一致，并确认没有红块正好位于底面相同的无色块之上；任何合法的着色都被接受。

## 样例

```
4 6
0 0 1 1 0 0
0 0 1 2 1 0
0 0 0 1 2 1
0 0 0 0 1 1
```

```
WRW
WWR

WR
```

## 解法

样例中两个底层红块的左上角单位坐标为 (0,2)、(2,4)，上层红块为
(1,3)。三个 2×2 投影相加得到照片，两处重叠产生数字 2，对应底层
WRW/WWR、上层 WR。上层红块部分覆盖无色块，但底面不同，仍然合法。

### 恢复每个底面的红块数量

设 F[x,y] 为所有层中左上角底面坐标为 (x,y) 的红块数。每块覆盖四个
单位格，照片 A 满足

A[i,j]=F[i,j]+F[i−1,j]+F[i,j−1]+F[i−1,j−1]，

矩形外取零。自上到下、自左到右依次计算

F[i,j]=A[i,j]−F[i−1,j]−F[i,j−1]−F[i−1,j−1]。

三个被减项都已经得到，这个三角系统唯一确定每个底面的红块数量。
输入有效性保证结果非负、不可能位置为零，且对应物理块足够，无需截断。

### 在竖直链底部放置红块

第 z 层的块 (r,c) 左上角为 (z+2r,z+2c)。相同底面对应下两层的
(r+1,c+1)，并不对应相邻层。具有同一底面的块形成同奇偶层的竖直链，
从第零层或第一层开始。

颜色限制迫使每条链自下而上先是所有红块，再是无色块。因此数量
F[x,y] 决定最下面 F[x,y] 个块为红色。第 z 层块下方恰有 floor(z/2)
个对齐块，所以它为红色当且仅当 F[z+2r,z+2c]>floor(z/2)。

构造直接满足竖直限制，且保留每个底面的红块总数。按投影方程累加
这些底面即重现照片 A，因此正确。

令 B=Σ_z(m/2−z)(n/2−z) 为块总数。时间和含返回结果的空间均为
`O(mn+B)`，不计输出的额外空间为 `O(mn)`。最大 40×40 底面有 B=2870。

“恰好在上方”指相同的 2×2 底面，不是任意部分重叠；错误要求下方所有
重叠块都红会拒绝样例。相同底面隔一层才重复。反演式三个项全为减法，
包含对角项。层偏移是一单位，块间步长为二。保留空行分隔，并在任一块
网格维度达到一时停止。

## 各语言说明

普通有符号整数足够，照片值至多二十，相同底面的红块数至多十。各版本
保存数量矩阵并构造每层字符串。Python 3.12、G++ 13.2 的 C++、Go 1.14、
Java 8、Rust 1.75 均仅用标准库，无递归。
