# 1968. Восстановление цветов ступенчатой пирамиды

[Timus 1968](https://acm.timus.ru/problem.aspx?space=1&num=1968) · difficulty 1641 · constructive

Оригинальная задача: Открытое личное первенство УрФУ по программированию 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Пирамида сложена из блоков высоты один с квадратным основанием 2×2.
Нижний слой занимает прямоугольник m×n. Каждый следующий слой смещён
внутрь на единицу с каждой стороны и содержит на один ряд и столбец
блоков меньше. Построение заканчивается, когда одна из размерностей
сетки блоков становится единицей. Блоки красные или бесцветные; вид
сверху задаёт для каждой единичной клетки число покрывающих её красных
блоков.

Восстановить цвета. Красный блок не может находиться точно над бесцветным
с тем же основанием. Частичное перекрытие бесцветных блоков разрешено.
Гарантировано хотя бы одно допустимое расположение. Лимиты: 1 секунда,
64 МБ.

## Входные данные

Чётные m,n, 2≤m,n≤40, затем m строк по n неотрицательных чисел —
количество красных блоков над каждой единичной клеткой. Данные согласованы
с геометрией и ограничением цветов.

## Выходные данные

Слои снизу вверх: R означает красный блок, W — бесцветный. Слой z,
считая с нуля, содержит m/2−z строк по n/2−z символов. Между соседними
слоями одна пустая строка. Принимается любое допустимое восстановление.

## Проверка

Проверяющая программа сверяет размеры слоёв, символы, точный вид сверху
и то, что ни один красный блок не стоит прямо над бесцветным с тем же
основанием; принимается любая подходящая раскраска.

## Примеры

```
4 6
0 0 1 1 0 0
0 0 1 2 1 0
0 0 0 1 2 1
0 0 0 0 1 1
```

```
WRW
WWR

WR
```

## Решение

В примере красные нижние блоки начинаются в (0,2) и (2,4) при нумерации
единичных клеток с нуля. Красный верхний блок начинается в (1,3).
Сумма их трёх проекций 2×2 даёт фотографию; в двух местах перекрытия
получаются двойки. Нижний слой — WRW/WWR, верхний — WR. Красный
верхний блок частично перекрывает бесцветные, но их основания различны.

### Восстановление количества для каждого основания

Пусть F[x,y] — число красных блоков на всех уровнях, у которых левый
верхний угол горизонтального основания равен (x,y). Каждый покрывает
четыре единичные клетки. Для фотографии A:

A[i,j]=F[i,j]+F[i−1,j]+F[i,j−1]+F[i−1,j−1],

вне прямоугольника значения нулевые. Обходим строки сверху вниз,
внутри строки слева направо и вычисляем

F[i,j]=A[i,j]−F[i−1,j]−F[i,j−1]−F[i−1,j−1].

Все три вычитаемых уже известны, поэтому треугольная система однозначно
задаёт число красных блоков с каждым основанием. Корректность входа
гарантирует неотрицательность, нули для невозможных позиций и достаточное
число физических блоков. Обрезать значения не нужно.

### Красные блоки внизу вертикальной цепочки

Блок (r,c) слоя z имеет угол основания (x,y)=(z+2r,z+2c).
Такое же основание есть на два слоя ниже у блока (r+1,c+1), но не
в соседнем слое. Все совпадающие основания образуют вертикальную цепочку
уровней одной чётности, начиная с нулевого либо первого.

Из ограничения цветов следует, что снизу вверх сначала идут все красные
блоки цепочки, затем бесцветные. При числе F[x,y] красными должны быть
ровно F[x,y] нижних блоков. Ниже блока уровня z находится floor(z/2)
совпадающих оснований, поэтому цвет красный ровно при
F[z+2r,z+2c]>floor(z/2).

Построение соблюдает вертикальное ограничение и сохраняет число красных
блоков для каждого основания. Сумма их проекций по исходному уравнению
даёт A. Следовательно, восстановление корректно.

Пусть B=Σ_z(m/2−z)(n/2−z) — число блоков. Время и память с сохраняемым
ответом `O(mn+B)`, дополнительная память без вывода `O(mn)`. Для
максимального основания 40×40 имеем B=2870.

«Точно над» означает одно и то же основание 2×2. Если потребовать красный
цвет от всех частично перекрываемых нижних блоков, не пройдёт даже пример.
Совпадающие основания идут через слой. В формуле обращения все три
члена вычитаются, включая диагональный. Смещение слоя равно единице,
а шаг соседних блоков — двум. Сохраняем пустые разделители и заканчиваем,
когда одна из размерностей сетки блоков становится единицей.

## Особенности языков

Достаточно обычных знаковых целых: значения фотографии не больше двадцати,
число красных с одинаковым основанием — десяти. Все версии хранят матрицу
количеств и строят строки слоёв. Python 3.12, C++ в G++ 13.2, Go 1.14,
Java 8 и Rust 1.75 обходятся без рекурсии и внешних библиотек.
