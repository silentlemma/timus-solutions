# 1981. Подсчёт диагоналей по направлениям

[Timus 1981](https://acm.timus.ru/problem.aspx?space=1&num=1981) · сложность 444 · math, combinatorics

Автор оригинальной задачи — Григорий Назаров; Открытый командный чемпионат УрФУ по программированию — 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для правильного `n`-угольника посчитайте диагонали, имеющие хотя бы одну
другую параллельную диагональ, и отдельно диагонали, имеющие хотя бы
одну перпендикулярную диагональ. Диагональ соединяет две несмежные
вершины. Считаются сами подходящие диагонали; одна диагональ может
входить в оба ответа.

Дано целое `4≤n≤100000`. Ограничения: 0,5 секунды, 64 МБ.

## Входные данные

Одно целое число `n`.

## Выходные данные

Два целых числа: сначала количество для параллельности, затем для
перпендикулярности.

## Проверка

Ответы сравниваются по токенам.

## Примеры

Ввод:

```
4
```

Вывод:

```
0 2
```

## Решение

Пронумеруем вершины `0,…,n−1` по окружности. Направление хорды между
`i,j` имеет угол `π(i+j)/n+π/2` по модулю `π`. Поэтому класс
неориентированного направления задаётся остатком `r=(i+j) mod n`.

Посчитаем диагонали каждого класса. При нечётном `n` уравнение `i+j≡r`
даёт `(n−1)/2` неупорядоченных пар различных вершин: из `n`
упорядоченных решений одно имеет совпадающие концы. Ровно одна пара
является стороной. В каждом классе получается `d=(n−3)/2` диагоналей.
Если `d≥2`, все `n d` имеют параллельную; иначе не имеет ни одна.

При чётном `n` положим `h=n/2`. Классов каждой чётности по `h`. У
чётного класса два упорядоченных решения с совпадающими концами и нет
сторон, поэтому диагоналей `h−1`. У нечётного класса совпадающих концов
нет, но есть две стороны, поэтому диагоналей `h−2`. Размер `d` добавляем
к ответу только при `d≥2`; складываем вклады двух чётностей и умножаем
на `h`. Малые многоугольники учитываются этими же размерами классов.

Перпендикулярные классы отличаются на `n/2`, что невозможно при нечётном
`n`: второй ответ нулевой. При чётном `n` и чётном `h` класс-партнёр
имеет ту же чётность и тот же положительный размер. Если `h` нечётно, то
`h≥3`, и оба размера классов положительны. Значит, при чётном `n` каждая
диагональ имеет перпендикулярную, а ответ равен общему числу `n(n−3)/2`.

Формула направления относит каждую диагональ ровно к одному классу.
Условие на размер класса равносильно существованию другой параллельной
диагонали, а сдвиг на `n/2` описывает перпендикулярность. Это доказывает
оба подсчёта.

У квадрата из примера два направления, в каждом по одной диагонали,
поэтому параллельной нет ни у одной. Эти направления перпендикулярны, и
ответ равен `0 2`.

Время — `O(1)`, дополнительная память — `O(1)`. Нужны 64-битные
вычисления: максимальный ответ `4 999 850 000` превышает даже
беззнаковый 32-битный тип.

Подводные камни:

- Класс размера один не даёт подходящих параллельных диагоналей.
- При подсчёте хорд исключайте стороны и совпадающие концы.
- Направления рассматриваются по модулю `π`: противоположные ориентации
  совпадают.
- Считаются диагонали, а не неупорядоченные пары диагоналей.
- Умножение выполняйте уже в 64-битном типе: промежуточные произведения
  также велики.

## Особенности языков

Python использует точные целые. C++, Go и Java выполняют формулы в
знаковых 64-битных типах, Rust использует `u64`. В отправляемых
программах нет тригонометрии.
