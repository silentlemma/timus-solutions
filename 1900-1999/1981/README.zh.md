# 1981. 按方向分类统计对角线

[Timus 1981](https://acm.timus.ru/problem.aspx?space=1&num=1981) · 难度 444 · math, combinatorics

原题作者 Grigory Nazarov，出自 2013 年乌拉尔联邦大学公开团体锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对一个正 `n` 边形，分别统计至少有另一条平行对角线的对角线数量，以及至少有一条垂直对角线的对角线数量。对角线连接不相邻的两个顶点。统计的是满足条件的对角线本身，一条对角线可以同时计入两个答案。

输入整数 `4≤n≤100000`。时间限制 0.5 秒，内存限制 64 MB。

## 输入

一个整数 `n`。

## 输出

两个整数，先输出平行条件的数量，再输出垂直条件的数量。

## 评测方式

按记号逐个比较输出。

## 样例

输入:

```
4
```

输出:

```
0 2
```

## 解法

沿圆周将顶点编号为 `0,…,n−1`。连接 `i,j` 的弦方向角为 `π(i+j)/n+π/2`，模 `π` 意义下相同方向等价。因此无向方向类别为 `r=(i+j) mod n`。

先求每类的对角线数。若 `n` 为奇数，方程 `i+j≡r` 的 `n` 个有序解中恰有一个端点重复，故不同顶点的无序对有 `(n−1)/2` 个。其中恰有一条边，剩下 `d=(n−3)/2` 条对角线。若 `d≥2`，全部 `n d` 条都有平行伙伴；否则答案为零。

若 `n` 为偶数，令 `h=n/2`，两种奇偶性各有 `h` 个方向类。偶数类有两个重复端点的有序解，没有边，对角线数为 `h−1`。奇数类没有重复端点解，却有两条边，对角线数为 `h−2`。类大小 `d≥2` 时贡献 `d`，否则贡献零；将两种类大小的贡献之和乘以 `h`。小多边形也由这些类大小自然处理。

垂直方向类相差 `n/2`，所以奇数 `n` 不可能，第二个答案为零。若 `n` 为偶数且 `h` 为偶数，伙伴类奇偶性相同，大小也相同且为正。若 `h` 为奇数，则 `h≥3`，两种类大小都为正。因此偶数 `n` 的每条对角线都有垂直伙伴，答案就是总数 `n(n−3)/2`。

方向公式把每条对角线恰分到一类。类大小条件等价于存在不同的平行伙伴，类编号相差 `n/2` 则刻画垂直性，由此得到正确性。

样例正方形的两个对角线方向各只有一条，因此均无平行伙伴；这两个方向互相垂直，答案为 `0 2`。

时间为 `O(1)`，额外空间为 `O(1)`。必须使用 64 位整数，最大答案 `4,999,850,000` 甚至超过无符号 32 位整数上限。

注意事项：

- 大小为一的方向类对平行答案没有贡献。
- 统计弦时要排除边与重复端点。
- 方向模 `π`，反向仍属于同一类。
- 统计对角线数量，不是对角线的无序对数。
- 乘法前就使用 64 位类型，中间乘积也会超过 32 位。
