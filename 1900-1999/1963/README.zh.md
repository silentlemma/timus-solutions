# 1963. 反射对称轴上的边界点

[Timus 1963](https://acm.timus.ru/problem.aspx?space=1&num=1963) · difficulty 496 · geometry

Original problem from Open Ural FU Personal Contest 2013 | by Alexander Ipatov.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给出按边界顺序排列的简单四边形，求其边界上落在至少一条整图形反射
对称轴上的不同点数。四边形可以是凹的。任意连续三个顶点不共线，
对边不相交。时间限制 1 秒，内存限制 64 MB。

## 输入

四行，每行两个整数 x,y，按环绕边界的顺序给出顶点。每个坐标的
绝对值不超过 1000。

## 输出

一个整数：位于对称轴上的不同边界点数。对称轴必须使整个图形在
关于该直线反射后保持不变。

## 评测方式

按记号逐个比较输出。

## 样例

```
0 0
1 2
2 2
2 1
```

```
2
```

```
0 0
2 1
2 2
0 2
```

```
0
```

## 解法

第一个样例关于 y=x 反射时，(0,0)、(2,2) 固定，(1,2) 与 (2,1)
互换。唯一对称轴上的两个固定顶点给出答案 2。第二个样例的四种可能
顶点反射均不能保持多边形，答案为 0。

顶点 p_i 按 0,…,3 编号。反射将边界的角映射到角，并反转环绕顺序，
因此顶点置换必为 i→(s−i) mod 4，s=0,…,3，只需考虑四个候选。

s 为偶数时，两个对顶点固定，候选轴经过这两个顶点。s 为奇数时，
两对相邻顶点互换，候选轴经过对应两条对边的中点。用双倍坐标保存
轴上的两点 A,B：顶点写作 2p，边中点写作 p+q。半整数位置仍然精确，
无需浮点。令 D=B−A，若方向为零则跳过。

对置换给出的每对原坐标点 p,q，检验

(p+q−A)×D=0 且 (p−q)·D=0。

叉积条件表示中点在轴上，点积条件表示连接线段垂直于轴。两者合起来
恰好说明 p 反射为 q，也包含 p=q 的固定点情况。四对都满足时才接受
这条候选轴；所有运算均为整数。

任何真正反射都满足这些条件。反过来，通过检验的候选按反转环绕顺序
的置换把每条边映射到对应边，因此保持边界及其围成的图形。凹四边形
也适用，不依赖凸性。

通过检验的轴与边界的交点恰好是其两个定义点：偶数 s 对应两个固定
顶点，奇数 s 对应两个交换边的中点。更多交点会迫使某条边与其另一条
反射边在公共顶点以外相交，违反简单性。轴也不可能包含整条边，因为
上述反序置换不能同时固定两个相邻顶点。

把每条有效轴的两个双倍坐标点加入集合，输出并集大小。这样直接统计
不同点，不需要假定不同轴的边界交点彼此不同。

时间 `O(1)`，空间 `O(1)`：四个候选各检查四对顶点，最多保存八个点。

不能假设凸性，也不能只比较边长或只检查对角线；穿过对边中点的轴同样
重要，中点可能为半整数。保留输入的边界顺序，需要保持边而不仅是顶点
集合。无需浮点或 epsilon；四个反转循环顺序的置换保证候选完整。

## 各语言说明

C++、Go 1.14、Java 8、Rust 1.75 使用 64 位整数做叉积和点积，
Python 3.12 使用精确整数。C++/Go/Python/Rust 以集合去重双倍坐标；
Java 扫描至多八点的列表去重。不需要递归或几何库。
