# 1963. Точки границы на осях симметрии

[Timus 1963](https://acm.timus.ru/problem.aspx?space=1&num=1963) · difficulty 496 · geometry

Original problem from Open Ural FU Personal Contest 2013 | by Alexander Ipatov.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для простого четырёхугольника найти число различных точек границы, лежащих
хотя бы на одной оси отражательной симметрии всей фигуры. Четырёхугольник
может быть вогнутым. Никакие три последовательные вершины не коллинеарны,
противоположные стороны не пересекаются. Лимиты: 1 секунда, 64 МБ.

## Входные данные

Четыре строки с целыми координатами x,y очередной вершины в порядке
обхода границы. Модуль каждой координаты не превосходит 1000.

## Выходные данные

Одно целое число — количество различных точек границы на осях симметрии.
Отражение относительно такой прямой должно сохранять всю фигуру.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
0 0
1 2
2 2
2 1
```

```
2
```

```
0 0
2 1
2 2
0 2
```

```
0
```

## Решение

В первом примере отражение относительно y=x оставляет (0,0) и (2,2)
на месте, а (1,2) и (2,1) меняет местами. Две фиксированные вершины
лежат на единственной оси, поэтому ответ 2. Во втором ни одно из четырёх
возможных отражений вершин не сохраняет многоугольник: ответ 0.

Нумеруем вершины p_i от 0 до 3. Отражение переводит настоящие углы
границы в углы и меняет направление обхода. Поэтому перестановка вершин
имеет вид i→(s−i) mod 4, где s принимает четыре значения от 0 до 3.

При чётном s фиксируются две противоположные вершины — через них
проходит кандидат на ось. При нечётном s меняются местами две пары
соседних вершин: ось проходит через середины соответствующих
противоположных сторон. Храним точки A,B оси в удвоенных координатах:
для вершины это 2p, для середины ребра p+q. Так полуцелые координаты
не требуют дробей. Нулевое направление D=B−A пропускаем.

Для каждой пары p,q из предполагаемой перестановки проверяем

(p+q−A)×D=0 и (p−q)·D=0.

Первое равенство означает, что середина пары лежит на оси; второе —
что соединяющий отрезок перпендикулярен оси. Вместе это в точности
условие отражения p в q, в том числе при p=q. Кандидат принимается,
если подходят все четыре пары. Все вычисления целочисленные.

Условия необходимы для любого отражения. Они также достаточны:
перестановка с обращённым обходом переводит каждое ребро в нужное ребро,
значит, сохраняет границу и ограниченную ею фигуру. Выпуклость не нужна.

У прошедшей проверки оси ровно две точки на границе, задающие эту ось:
при чётном s противоположные вершины, при нечётном — середины рёбер.
Дополнительная точка заставила бы ребро пересечь своё отличное от него
отражение вне общей вершины, что невозможно для простого многоугольника.
Целое ребро на оси тоже невозможно: перестановка не фиксирует две
соседние вершины.

Добавляем обе удвоенные точки каждой правильной оси в множество и
выводим число элементов объединения. Так считаем именно различные
точки, не полагаясь на отсутствие совпадений у разных осей.

Время `O(1)`, память `O(1)`: четыре кандидата по четыре пары и не более
восьми сохраняемых точек.

Вогнутые фигуры разрешены. Одного сравнения длин сторон недостаточно;
нельзя рассматривать только диагонали, забывая оси через середины сторон.
Середины бывают полуцелыми. Сохраняем порядок обхода входных вершин,
проверяем рёбра, а не только множество вершин. Float и epsilon не нужны:
четыре перестановки с обращением циклического порядка дают полный список.

## Особенности языков

C++, Go 1.14, Java 8 и Rust 1.75 используют 64-битные произведения.
Python 3.12 считает точно целыми числами. C++/Go/Python/Rust хранят
удвоенные точки в множествах; Java удаляет повторы просмотром списка
длиной до восьми точек. Рекурсия и геометрические библиотеки не нужны.
