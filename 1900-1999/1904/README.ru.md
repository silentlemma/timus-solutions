# 1904. Reversing Absolute Folds

[Timus 1904](https://acm.timus.ru/problem.aspx?space=1&num=1904) · difficulty 478 · math, sorting

Original problem by Alexander Ipatov, from Ural Championship 2012.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для вещественного входа x последовательно выполните k операций:
текущее значение y заменяется на |y−aᵢ|. Найдите все x, при которых
итог не превышает 1. Выведите множество непересекающимися замкнутыми
отрезками с целыми концами. Исходный x может быть отрицательным.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

Сначала k, 1 ≤ k ≤ 10. Затем k целых a₁,…,aₖ в порядке обработки,
где −1000 ≤ aᵢ ≤ 1000.

## Выходные данные

Количество отрезков, затем пары l ≤ r по одному отрезку на строку,
в порядке возрастания координат. Отдельная точка допустима; для пустого
множества выведите 0. Граница с итоговым значением 1 включается.

## Проверка

Режим `tokens`: сравниваются отсортированные связные компоненты.
Пересекающиеся и касающиеся отрезки объединяются.

## Примеры

```
3
0 4 2
```

```
4
-7 -5
-3 -1
1 3
5 7
```

## Решение

Пойдём назад от допустимого итогового диапазона [0,1]. Если выход одной
операции должен лежать в [l,r], отрицательные значения невозможны:
при r < 0 отрезок отбрасывается, иначе заменяем l на max(l,0).
Полный прообраз при `z = |y−a|` равен

`[a−r, a−l] ∪ [a+l, a+r]`.

Получим такие ветви для всех текущих отрезков, отсортируем и объединим
пересечения, включая общий конец. Повторим для aₖ,aₖ₋₁,…,a₁.
При обращении каждой операции её выход неотрицателен, поэтому отсечение
важно. После последнего обращения отрицательные исходные x сохраняются:
сам итоговый ответ отсекать по нулю нельзя.

Инвариант: текущее объединение содержит ровно значения, успешно проходящие
уже обращённый суффикс цепочки. Две отражённые ветви дают все решения
одного ограничения на модуль. Пересечение выхода с [0,∞) убирает
невозможные значения, сортировка и слияние сохраняют множество.
После обращения всей цепочки получаем в точности нужные исходные x.

Все границы изначально целые. Сдвиги, отражения, отсечение по нулю
и объединения сохраняют целые концы. Для допустимого x выполняется
`|x| ≤ 1 + Σ|aᵢ| ≤ 10001`, достаточно 32-битного знакового типа.

За шаг число отрезков не более чем удваивается. Кандидатов не больше
`2^k`; с сортировкой на каждом уровне время `O(k·2^k)`, память `O(2^k)`.
При k ≤ 10 это мало. Пустое объединение далее остаётся пустым.

В примере обращение a₃=2 даёт [1,3], затем a₂=4 — [1,3] и [5,7].
Обращение a₁=0 добавляет отрицательные отражения — четыре отрезка ответа.

## Особенности языков

Все пять исходников сортируют пары по левому, затем по правому концу.
Python использует CPython 3.12; во всех языках вводятся знаковые aᵢ.
Java изменяет только правый конец заново созданного объединённого отрезка.

Сливаем при следующем левом конце не больше предыдущего правого:
множество вещественное. Точки не отбрасываются. Отрицательная константа
может сделать результат пустым: [0,−2] не принимает ничего, а [2,−1]
принимает только x=2.

Ответы совпадают с прямым вычислением цепочки на 4025 тестах, из них
1725 с пустым ответом и 915 с отдельными точками; в самых больших тестах
512 отдельных отрезков.
