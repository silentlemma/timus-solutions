# 1904. Reversing Absolute Folds

[Timus 1904](https://acm.timus.ru/problem.aspx?space=1&num=1904) · difficulty 478 · math, sorting

Original problem by Alexander Ipatov, from Ural Championship 2012.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对实数输入 x，按顺序进行 k 次操作，把当前值 y 替换为 |y−aᵢ|。
找出所有最终值不超过 1 的 x，用按坐标排序、互不相交的整数端点闭区间表示。
原始输入 x 可以为负。时限 1 秒，内存限制 64 MB。

## 输入

首先给出 k，1 ≤ k ≤ 10。然后是按处理顺序给出的 k 个整数 a₁,…,aₖ，
每个数满足 −1000 ≤ aᵢ ≤ 1000。

## 输出

先输出区间数，再每行输出一对 l ≤ r，按坐标递增。允许单点区间，
空集合输出 0。最终值等于 1 的边界也应包含。

## 评测方式

使用 `tokens` 模式精确比较排序后的连通分量。
相交或端点相接的闭区间必须合并。

## 样例

```
3
0 4 2
```

```
4
-7 -5
-3 -1
1 3
5 7
```

## 解法

从最终允许范围 [0,1] 反向处理。如果某一步的输出要求在 [l,r]，
绝对值不可能为负，所以 r < 0 时丢弃，否则令 l=max(l,0)。
在 `z = |y−a|` 下完整原像为

`[a−r, a−l] ∪ [a+l, a+r]`。

对所有当前区间生成两支，排序并合并所有交集，包括公共端点。
按 aₖ,aₖ₋₁,…,a₁ 重复。每次反演的输出都是绝对值，必须先限制为非负。
最后得到的是原始输入，可以保留负数，不要再把答案裁剪到非负区域。

不变式是：当前并集恰好包含能通过已反演后缀的所有值。两个反射区间
正是单次绝对值限制的全部解。与 [0,∞) 相交只去掉不可能输出，
排序与合并保持并集。因此反演完整链后恰好得到全部合法原始输入。

初始端点和常数都是整数，平移、反射、零点裁剪与合并都保持整数端点。
合法输入满足 `|x| ≤ 1 + Σ|aᵢ| ≤ 10001`，有符号 32 位整数足够。

每层区间数最多翻倍，候选数不超过 `2^k`。每层排序，总时间
`O(k·2^k)`，空间 `O(2^k)`。k ≤ 10，规模很小；空并集始终为空。

示例中反演 a₃=2 得到 [1,3]，反演 a₂=4 得到 [1,3] 与 [5,7]，
再反演 a₁=0，加入负方向反射，得到所示四个区间。

## 各语言说明

五种实现均先按左端点、再按右端点排序。Python 使用 CPython 3.12。
所有语言都必须读取有符号常数。Java 只修改新建合并区间的右端点。

下一左端点不大于上一右端点时合并，因为输入是实数。不要丢弃单点。
负常数可能使所有中间输出不可能：[0,−2] 的答案为空，[2,−1] 只接受 x=2。

在 4025 个测试上，答案与正向计算整条链的结果一致，其中 1725 个答案为空，915 个含孤立点；最大的测试有 512 个互不相交的区间。
