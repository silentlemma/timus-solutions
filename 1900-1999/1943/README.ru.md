# 1943. Выигрышный префикс из пяти карт

[Timus 1943](https://acm.timus.ru/problem.aspx?space=1&num=1943) · difficulty 907 · bruteforce, constructive

Original problem from Open Ural FU Personal Contest 2012 | by Andrey Demidov.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У двух игроков по перестановке достоинств 1..n. Одновременно снимаются
первые карты очередей. Равные обе удаляются; иначе старшая выигрывает
обе и кладёт в конец сначала младшую, затем старшую. Пустая очередь
означает поражение, одновременное опустошение — ничью. По известному
порядку соперника выбрать свою перестановку с победой либо установить
невозможность. Ничья и бесконечное повторение не подходят.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

n, 2≤n≤500, затем перестановка 1..n в колоде соперника сверху вниз.
В каждой исходной колоде каждое достоинство встречается один раз.

## Выходные данные

Только NO, если победы не достичь. Иначе YES в первой строке и любая
выигрышная перестановка во второй, сверху вниз.

## Проверка

Проверяющая программа разыгрывает всю игру с напечатанной колодой и
принимает любую колоду, которая действительно выигрывает. При пяти и
более картах ответ `NO` неверен по лемме ниже.

## Примеры

```
4
2 3 4 1
```

```
YES
2 4 1 3
```

## Решение

Берём m=min(n,5) первых карт соперника, перебираем их перестановки
и моделируем каждую m-карточную игру. Повтор пары очередей означает
цикл; выбираем первую настоящую победу. При n≤5 это все возможные
колоды, поэтому отсутствие победы доказывает NO.

Ключевая лемма: у любого порядка пяти разных достоинств есть выигрышный
ответ. Важен только порядок достоинств, поэтому достаточно достоинств от
1 до 5, и лемма проверяется розыгрышем всех 120² = 14 400 пар порядков.
Это делает короткий скрипт, заодно и для меньших колод:

```python
from collections import deque
from itertools import permutations

def game(a, b):
    a, b = deque(a), deque(b)
    seen, steps = set(), 0
    while a and b:
        state = tuple(a), tuple(b)
        if state in seen:
            return False, steps
        seen.add(state)
        x, y = a.popleft(), b.popleft()
        steps += 1
        if x > y:
            a.extend((y, x))
        elif y > x:
            b.extend((x, y))
    return bool(a), steps

for size in range(2, 6):
    orders = list(permutations(range(1, size + 1)))
    possible, longest = 0, 0
    for opponent in orders:
        results = [game(own, opponent) for own in orders]
        possible += any(won for won, _ in results)
        longest = max(longest, max(steps for _, steps in results))
    print(size, len(orders), possible, longest)
```

| Cards | Opponent orders | Orders with a winning reply | Longest game |
|---:|---:|---:|---:|
| 2 | 2 | 0 | 4 |
| 3 | 6 | 3 | 7 |
| 4 | 24 | 22 | 16 |
| 5 | 120 | 120 | 49 |

Состояний конечное число, поскольку остаётся не больше десяти карт;
повторное состояние не ведёт к победе. Перебор заканчивается, и для
каждого из 120 порядков пяти карт есть свидетель. В тестах присутствуют
все 120 входов с явными выигрышными ответами и все 32 меньших порядка.
Это воспроизводимый конечный сертификат. Пять — минимальный универсальный
размер: у четырёх карт есть два невозможных порядка.

При n>5 заменяем только первые пять карт локально выигрышным порядком,
остальные копируем у соперника. В первых n раундах исходные несыгранные
карты находятся перед всеми взятками, поэтому раньше очередь не
опустеет. Последние n−5 исходных пар равны и удаляются. После раунда n
очереди совпадут с состоянием пятёрочной игры после раунда пять.
Дальше все раунды одинаковы, значит локальная победа даёт полную.
Если она заняла t раундов, полная займёт n+t−5≤n+44. Лемма доказывает
успех при n≥5, полный перебор меньших колод — полноту решения.

Время и память O(n), плюс постоянный поиск не больше 5! кандидатов.
Полный локальный перебор устанавливает ≤49 раундов в игре и ≤10 активных
карт. Это проверенные границы, а не отсечения в программах. Первая
победа найдена не позже попытки 68; код всё равно перебирает обычным
образом до победы или окончания кандидатов.

Порядок взятки: младшая, старшая. Равные карты удаляются обе, пустые
одновременно дают ничью. Нужна победа, а не выживание или догадка после
ограниченного числа раундов. Пять карт не означает пять ходов. Нетронутые
карты должны стоять на одинаковых исходных местах, чтобы удалиться до
выхода взяток на голову. Наблюдения о сортированности колод не заменяют
полную конечную лемму.

## Особенности языков

В C++ next_permutation, в Python itertools.permutations. Go, Java, Rust
используют стандартные шаги поиска опорной позиции, преемника и разворота
суффикса на пяти элементах. Точные состояния очередей сохраняются
для обнаружения циклов; в Go индексы голов, в Java и Rust deque.
Хвост копируется. Только стандартные библиотеки, готовой таблицы ответов нет.
