# 1978. 每种数量的最大向量和

[Timus 1978](https://acm.timus.ru/problem.aspx?space=1&num=1978) · 难度 3231 · geometry, sorting

原题作者 Alexander Ipatov，出自 2013 年乌拉尔体育编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 `n` 个二维向量。对每个 `k=1,…,n`，从输入中恰好选取 `k` 个不同位置，使向量和的欧几里得长度最大。相同向量属于不同输入位置；坐标可以为零或负数。

`1≤n≤1000`，坐标为整数且 `−10⁶≤x,y≤10⁶`。时间限制 2 秒，内存限制 64 MB。

## 输入

第一行是 `n`，随后 `n` 行各含一对坐标 `x y`。

## 输出

输出 `n` 行，第 `k` 行为恰选 `k` 个向量时的最大长度。

## 评测方式

数值按 10⁻⁶ 的绝对或相对误差比较。

## 样例

输入：

```
3
3 -2
-3 -2
0 4
```

输出：

```
4.000000
4.000000
0.000000
```

## 解法

固定方向 `u`，选取投影最大的 `k` 个向量。旋转方向时，这些集合包含每种数量的最优解。设最优向量和为非零的 `s`，若另一个集合在 `s/|s|` 上的投影更大，其长度也必然更大，产生矛盾。出现投影相等时可做微小旋转，极限投影仍然最优；最优值为零的情况也不会遗漏。

让方向为 `(1,t)`，`t` 从负无穷增加到正无穷，维护投影升序排列。初始按 `y` 降序、再按 `x` 升序。前缀表示投影最小的集合，补集表示最大的集合；同时记录二者即可覆盖另一半圆的方向。

对于不同 `y` 的两个向量，设 `high` 的 `y` 更大，则交换时刻为 `t=(x_low−x_high)/(y_high−y_low)`。用整数交叉乘法精确排序这些事件。相同 `y` 在开半圆内不会交叉，相同向量无须事件。

单独发生的事件交换两个相邻元素，只改变二者之间的一个前缀。维护前缀的坐标和，更新相应大小的长度平方，同时用总和减去前缀，更新补集大小的答案。

同时发生的事件必须成批处理。每个相等投影组占据连续区间，经过事件后整个区间反转。对批内每对元素取其当前位置之间的区间，仅合并有重叠的区间，不能合并只是相邻的区间。反转各块，重算块内前缀；块外前缀和不变。重复向量也适用。

相邻事件之间的顺序固定。初始排列与全部批次反转因而遍历所需的最优投影集合。记录的每个前缀和补集都是真实子集，不可能超过真正最优值。结合最优和方向的投影论证，得到算法正确性。

共有 `O(n²)` 个事件，排序耗时 `O(n² log n)`。所有反转块的总长度为 `O(n²)`：非平凡块由本批事件连接，长度不超过相关事件数的两倍。批内起点排序同样满足该复杂度。空间为 `O(n²)`。

样例中 `(0,4)` 的长度为 4。前两个向量之和为 `(0,−4)`，长度也是 4。三个向量之和为零。

注意事项：

- 必须恰选 `k` 个，最优值不一定随 `k` 单调增加。
- 同一事件方向可能有多个不同投影组；相邻组不可合并。
- 同批中的一对元素在处理之前不一定相邻。
- 很接近的整数方向可能只有一的行列式差，必须精确比较事件斜率。
- 和的平方可达 `2·10¹⁸`，乘法和平方应使用 64 位整数。

## 各语言说明

C++、Go、Java 和 Rust 对打包后的元素对索引进行排序，比较使用精确的 64 位交叉乘法。Java 使用基本类型数组和归并排序。

Python 不保存 O(n²) 个事件。最优集合可以用一条直线与其余每个不同向量分开，而这条直线可以转动到经过某个向量为止。因此它把每个不同向量依次作为支点，将其余向量按其与支点连线的斜率排序，让直线绕支点旋转，每一步都记录一侧的集合及其补集，并逐个加入支点自身的副本。坐标范围使不同斜率之间的差距远大于 double 的舍入误差；斜率相同的向量可以按任意顺序经过，因为每个中间集合都是真实的子集。长度平方保持为精确整数，只在最终开平方时使用浮点数。时间 `O(n² log n)`，内存 `O(n)`。它在 PyPy 下运行，评测用时 0.80 秒（限制 2 秒）；保存全部元素对事件的早期版本在 CPython 下于评测第 7 个测试、在 PyPy 下于第 33 个测试超时。

在 14 139 个小测试上，答案与枚举全部子集的结果一致。
