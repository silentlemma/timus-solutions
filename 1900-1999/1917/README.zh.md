# 1917. 按阈值分组的安全消除

[Timus 1917](https://acm.timus.ru/problem.aspx?space=1&num=1917) · difficulty 242 · greedy

原题作者 Denis Dublennykh，出自 NEERC 2012 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

每枚硬币有正抗性阈值。强度 s 的法术会消除所有剩余且阈值≤s
的硬币，产生能量 s 乘以本次消除数量，不能超过 p。
先最大化消除总数，再在此基础上最小化法术次数。
限制：1 秒，64 MB。

## 输入

n,p，其中 1≤n≤1000、1≤p≤1 000 000 000。
随后 n 个任意顺序的阈值，1≤aᵢ≤1 000 000。

## 输出

最多可消除的数量及其最少法术次数。一个都不能消除时输出 `0 0`。

## 评测方式

精确比较两个整数词元，顺序固定。

## 样例

```
5 4
4 1 4 1 2
```

```
3 2
```

## 解法

排序后合并相同阈值。阈值 t 的 c 枚硬币不可拆开：弱法术一枚
也不消除，第一次强度≥t 的法术会同时消除全部 c 枚。

若 ct>p，这一组即使单独处理也不安全。提高强度或增加硬币只会
更差，而且消除更高阈值的法术也会包含这组。因此最大可消除集合
止于第一组不安全组之前。之前各组可分别消除，所以此上界可达。

对可行前缀贪心分批。active 是当前批硬币数，若
(active+c)t≤p 就加入整个新组；否则结算之前的非空批，再从当前组
开始新批。最后结算非空余批。每批法术强度取最大阈值，能量最小。
先检查 ct>p，且不统计空法术。

### 最长批的最优性

随着加入组，数量与最大阈值均不减，故贪心第一批是最长可行前缀。
把任意最优划分的第一批换成它，从后面的批中删去额外被消除的
硬币，丢弃空批。剩余各批数量及阈值不会增大，仍然安全，
总次数不增加。对余下组重复此交换即可证明最少次数。

排序时间 `O(n log n)`，分组扫描线性，空间 `O(n)`，含输入和排序副本。

样例用强度 1 消除两枚阈值 1，再用强度 2 消除一枚阈值 2。
两枚阈值 4 需要能量 8>4，因此结果为三枚、两次。

不能拆相同阈值，也不能跳过不安全的低阈值组。能量边界含等号，
必须计入本次同时消除的全部硬币。结算非空批后才清空累积。
下一组不安全不影响已累积的安全批。优先级是先数量、后次数。
