# 1955. Самый длинный видимый отрезок в многоугольнике

[Timus 1955](https://acm.timus.ru/problem.aspx?space=1&num=1955) · difficulty 3071 · geometry

Original problem from Ural FU contest. Kontur Cup. Petrozavodsk training camp. Winter 2013 | by Mikhail Rubinchik (prepared by Egor Shchelkonogov).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Найдите максимальное расстояние между двумя точками простого многоугольника,
если весь соединяющий отрезок лежит внутри или на границе. Многоугольник
может быть невыпуклым, без самопересечений и самокасаний. Концы разрешены
в любых точках, включая середины рёбер. Ограничения: 1 секунда, 64 МБ.

## Входные данные

Сначала n, 3≤n≤200, затем n целочисленных пар x,y в порядке обхода границы
по или против часовой стрелки, −1000≤x,y≤1000. Соседние коллинеарные
рёбра допустимы; несоседние рёбра не пересекаются и не касаются.

## Выходные данные

Одно вещественное число: максимальная длина с абсолютной или относительной
погрешностью не больше 10⁻⁶. Печатаем 12 знаков после точки.

## Проверка

Ответ сравнивается с абсолютной или относительной погрешностью 10⁻⁶.

## Примеры

```
4
0 0
0 1
1 1
1 0
```

```
1.414214
```

## Решение

### Почему достаточно прямых через пары вершин

Возьмём максимальный допустимый замкнутый отрезок и продолжим до границы.
Если на нём нет вершин, концы находятся внутри рёбер. Один конец можно
немного сдвинуть по ребру в обе стороны, сохраняя допустимость. Квадрат
длины строго выпуклый по этому сдвигу, локального максимума нет. Если
единственная вершина — конец, так же сдвигаем второй конец. Коллинеарная
границе прямая не исключение: максимальность включает целое ребро и ещё
одну вершину.

Пусть единственная вершина v строго внутри отрезка. Слегка повернём прямую
в обе стороны вокруг v: концы остаются внутри фиксированных рёбер,
допустимость сохраняется. Длина каждой половины равна h/|sin(θ−α)|,
где h>0 — расстояние от v до прямой соответствующего ребра. На открытом
интервале направлений это положительный косеканс со строго положительной
второй производной; сумма строго выпукла и не имеет локального максимума.
Если направление совпадает с граничным лучом, уже есть вторая вершина.
Значит, существует максимум, содержащий хотя бы две вершины многоугольника.

Перебираем всю прямую каждой пары и её пересечение с замкнутым
многоугольником. Самая длинная связная компонента — допустимый отрезок,
а доказательство гарантирует попадание максимума. Расстояния только между
выбранными вершинами недостаточно: отрезок может продолжаться до внутренних
точек двух других рёбер.

### Пересечение с прямой

Параметризация P+tD, D=Q−P. Высоты h(V)=cross(D,V−P) целые и точные.
Для ребра A→B при разных значениях (h(A)>0),(h(B)>0) добавляем
t=cross(A−P,B−A)/cross(D,B−A). Сортируем события и попарно соединяем
соседние. В −∞ ограниченный многоугольник отсутствует; полуоткрытое
правило согласованно обрабатывает вершину. Двойное касательное событие
даёт нулевой интервал или два соприкасающихся. Каждое ребро с двумя
нулевыми высотами добавляем отдельным замкнутым интервалом, используя
t=dot(V−P,D)/dot(D,D). Сортируем все интервалы, объединяем пересекающиеся
И соприкасающиеся. Максимальная длина по t, умноженная на |D|, даёт ответ
для прямой. Явные граничные интервалы сохраняют коллинеарные рёбра.

### Точные ускорения

Максимальное квадратное расстояние U между вершинами ограничивает любые
две точки многоугольника: это диаметр их выпуклой оболочки. Если самая
дальняя пара видима, сразу возвращаем sqrt(U). Каждое ребро и любая
проверенная видимая пара дают целую допустимую нижнюю границу L квадрата.

Пусть w,h — размеры ограничивающего прямоугольника, d²=dot(D,D).
Квадрат длины любого параллельного D отрезка не больше w²d²/dx² при dx≠0
и h²d²/dy² при dy≠0. Отбрасываем пару, если граница строго меньше L,
целочисленным перемножением крест-накрест. При нулевой компоненте такой
тест просто не отбрасывает. Делим D на НОД и выбираем знак; ключ прямой
(nx,ny,cross((nx,ny),P)) позволяет убрать повторения.

Python дополнительно сразу отбрасывает пару, если ребро поперечно пересекает
внутренность соединяющего её отрезка. Проверки знаков и диапазона числителя
со знаменателем целые. Две контактные вершины максимума видимы друг другу,
так что такая пара не нужна. Отмечаем прямую обработанной ТОЛЬКО после
видимой пары: невидимая пара не должна закрывать другую компоненту той же
прямой. Высоты пересчитываются точными приращениями по рёбрам, позволяя
ранний выход. Нативные версии могут рассматривать все компоненты и для
невидимых пар.

### Численные границы

Знаки, коллинеарность, НОД и отсечения целые. Модули числителей и
знаменателей параметров не больше 8·10⁶, перевод в binary64 точный.
Различные рациональные параметры отличаются относительно хотя бы на
1/(8·10⁶)²>10⁻¹⁴, намного больше округления; одинаковые дроби округляются
одинаково. Эпсилон для сортировки и касаний не нужен. |t|<2829, ошибка
частного ≤2⁻⁴², разности ≤2⁻⁴⁰. С учётом |D|<2829, произведений и корня
абсолютная ошибка длины меньше 10⁻⁸. Максимизация сохраняет эту границу.
Целые произведения отсечений до 3,2·10¹³ помещаются в знаковые 64 бита.

O(n³ log n) времени: O(n²) прямых, O(n) событий и сортировка для каждой.
O(n²) памяти для ключей и O(n) рабочих данных прямой. Проверка диаметра
занимает O(n²). Отсечения могут лишь улучшить эти границы.

Диаметр невыпуклого многоугольника может выходить наружу. Концы оптимального
отрезка не обязаны быть вершинами. Сохраняйте граничные рёбра, объединяйте
касания, последовательно используйте полуоткрытое правило и не считайте
произведения отсечений в 32 битах. Оба направления обхода работают одинаково.
Не отбрасывайте всю прямую из-за одной невидимой пары до проверки другой.

## Особенности языков

Только стандартные библиотеки, самодостаточные программы. В нативных
версиях знаковые 64-битные целые, binary64 лишь для частных и длин.
В Python целые неограниченные. Java использует строгую плавающую арифметику
и переиспользует массивы событий/интервалов. Ключ Java упаковывает nx,
ny+2000,c+4000000 в непересекающиеся поля: диапазоны [0,2000],[0,4000],
[0,8000000] помещаются в выбранные 12/23 бита, весь ключ в signed long.
Остальные версии хранят тройку целых.
