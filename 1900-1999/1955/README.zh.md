# 1955. 简单多边形内最长可见线段

[Timus 1955](https://acm.timus.ru/problem.aspx?space=1&num=1955) · difficulty 3071 · geometry

Original problem from Ural FU contest. Kontur Cup. Petrozavodsk training camp. Winter 2013 | by Mikhail Rubinchik (prepared by Egor Shchelkonogov).

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在简单多边形中选两点，要求连接它们的整段都在内部或边界上，求最大
距离。多边形可非凸，无自交及自接触；端点可在边的内部。1 秒，64 MB。

## 输入

先 n，3≤n≤200，再 n 对整数顶点 x,y，按顺时针或逆时针边界顺序，
−1000≤x,y≤1000。相邻边可以共线，非相邻边不交也不相触。

## 输出

一个实数，最大长度，绝对或相对误差不超过 10⁻⁶。打印 12 位小数。

## 评测方式

答案按 10⁻⁶ 的绝对或相对误差比较。

## 样例

```
4
0 0
0 1
1 1
1 0
```

```
1.414214
```

## 解法

### 为什么顶点对所在直线足够

取最长合法闭线段并延伸至边界。若段上没有顶点，两端都在边内；
沿边向两侧微移一端仍合法，距离平方严格凸，不可能局部最大。若唯一
顶点在一端，同样移动另一端。与边界共线也不例外：最长段包含整个
相邻边，已包含第二顶点。

若唯一顶点 v 严格位于段内，绕 v 向两侧微转直线，端点仍在固定边内
且局部合法。每半段长为 h/|sin(θ−α)|，h>0 为 v 到对应边所在直线
的垂距。在可行的开角区间内，这是二阶导严格正的正余割；两项之和
严格凸，仍不能局部最大。如果方向恰在相邻边界射线上，已经有另一
顶点。因此某个最优段至少包含两个顶点。

枚举每对顶点的整条直线，与闭多边形相交并取最长连通分量。所有结果
合法，上述论证保证包含最优。不能只比较所选顶点间距：最优段可越过
这两个顶点延伸到另外两条边的内部。

### 直线交集

参数化 P+tD，D=Q−P。精确整数高度 h(V)=cross(D,V−P)。边 A→B
若 (h(A)>0) 与 (h(B)>0) 不同，加入
t=cross(A−P,B−A)/cross(D,B−A)。排序并将相邻事件配对。有界多边形
在 −∞ 外，半开符号规则一致处理顶点。重复相切事件给零区间或两个
接触区间。两端高度均零的边另加闭区间，其端点参数
t=dot(V−P,D)/dot(D,D)。排序全部区间，合并重叠及接触。最长参数跨度
乘 |D| 即该直线答案。显式边界区间保留共线边。

### 精确加速

顶点间最大距离平方 U 是任意两点距离的上界，也是其凸包直径平方。
若最远顶点对可见，直接返回 sqrt(U)。边及已证可见的顶点对给出
精确整数可行下界 L。设包围盒宽高 w,h，d²=dot(D,D)，平行 D 的段
距离平方至多 w²d²/dx²（dx≠0）、h²d²/dy²（dy≠0）。用整数交叉乘
严格判断上界小于 L 即剪枝；零分量对应测试不会剪枝。D 以 gcd 和
统一符号规范化，用 (nx,ny,cross((nx,ny),P)) 去重直线。

Python 还在某边横穿所选两点连接段内部时立即排除该对，交点分子、
分母的符号与范围全用整数。最优段的两个接触顶点必互相可见，所以
这样安全。仅在找到可见对后标记该直线已处理；不可见对不能阻止
检查同一直线的其他分量。高度以精确整数边增量推进以便早退。原生
版也可对不可见的所选对检查所有分量。

### 数值边界

符号、共线、gcd 键及剪枝为整数运算。参数分子分母模至多 8·10⁶，
转 binary64 精确。不同有理参数相对间隔至少 1/(8·10⁶)²>10⁻¹⁴，
远大于舍入，同值分数舍入相同，故排序及接触判断无需 epsilon。
|t|<2829，商误差≤2⁻⁴²，差误差≤2⁻⁴⁰。乘 |D|<2829 并计入最后
乘法及平方根，长度绝对误差<10⁻⁸，取最大值仍保此界。剪枝整数
乘积至多 3.2·10¹³，在有符号 64 位内。

最坏 O(n³ log n) 时间：O(n²) 条线，每条 O(n) 事件和排序。去重键
用 O(n²) 空间，单线工作空间 O(n)。直径测试 O(n²)，剪枝只改善界。

非凸多边形的直径可能在外部，最优端点不一定为顶点。保留闭边界边、
合并接触分量、统一半开规则，剪枝乘法不能用 32 位。顺逆时针均适用。
一对不可见顶点不能提前删除整条直线而漏掉另一对。

## 各语言说明

独立程序，仅标准库。原生整数用有符号 64 位，仅商与长度用 binary64；
Python 整数任意精度。Java 严格浮点求值并复用事件/区间数组，直线键
将 nx、ny+2000、c+4000000 打包成不交位域，范围 [0,2000]、[0,4000]、
[0,8000000] 适配所选 12/23 位，整体在 signed long 内。其他版本
保存整数三元组。
