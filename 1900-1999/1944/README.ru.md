# 1944. Карта из символов с приоритетом точек

[Timus 1944](https://acm.timus.ru/problem.aspx?space=1&num=1944) · difficulty 238 · implementation

Original problem from Open Ural FU Personal Contest 2012 | by Andrey Demidov.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Изобразить различные целочисленные точки на декартовой сетке: x растёт
вправо, y вверх, одна ячейка соответствует одной паре координат.
Точка обозначается *, начало +, ось x знаком -, ось y знаком |,
остальные ячейки точкой. Звёздочка имеет приоритет над осями и началом;
оси могут полностью скрыться под точками. Нужен минимальный прямоугольник,
содержащий все точки и начало. Ограничения: 1 секунда, 64 МБ.

## Входные данные

n, 1≤n≤250, затем n различных целых пар (x,y), −100≤x,y≤100.
Совпадающих точек нет.

## Выходные данные

Строки идут от U=max(0,max y) до D=min(0,min y) включительно, вниз.
Столбцы — от L=min(0,min x) до R=max(0,max x). В каждой строке
W=R−L+1 символов, всего H=U−D+1 строк. Вывести только рисунок.

## Проверка

Сравнивается полный рисунок с точным расположением символов; пробел
не заменяет точку. Каждая формируемая строка заканчивается LF.

## Примеры

```
8
-10 5
-7 3
-4 2
-9 4
0 1
6 -1
3 0
8 -3
```

```
*.........|........
.*........|........
...*......|........
......*...|........
..........*........
----------+--*-----
..........|.....*..
..........|........
..........|.......*
```

## Решение

Изначально все четыре границы равны нулю, затем расширяются по точкам.
Координата (x,y) отображается в row=U−y, column=x−L. Это биекция
прямоугольника на индексы 0..H−1 и 0..W−1 с нужной ориентацией.

Заполняем сетку H×W точками. В столбце −L каждой строки ставим |.
Строку U заполняем -, затем её столбец −L заменяем на +. В конце
каждую заданную точку отмечаем * по вычисленным индексам. Выводим
строки по порядку индексов.

Начальные точки обозначают фон. Вертикальный и горизонтальный проходы
попадают ровно на x=0 и y=0. В пересечении ставится +, а последний
проход обеспечивает приоритет всех заданных точек. Различные точки
не накладываются. Нулевые исходные границы включают начало даже при
точках в одной четверти, и меньшая рамка не содержит все необходимые
координаты. Поэтому верны размеры, символы и направление, в том числе
при одной строке или одном столбце.

Время и память O(n+WH), с хранением входа и результата. W,H≤201,
максимальный вывод H(W+1)≤40602 ASCII-байта с LF — меньше 64 КиБ.
Границам и индексам достаточно обычного знакового целого.

Ноль входит в оба диапазона. При увеличении номера строки y уменьшается.
Не перепутать смещения строк и столбцов. В начале стоит +, только если
там нет точки; на оси точка тоже остаётся *. Не добавлять подписи,
пробелы, рамки или поля.

## Особенности языков

Python использует bytearray, Go байтовые срезы, C++ строки, Java
массивы char, Rust векторы байтов. В Java добавляется содержимое строк,
а не представление объекта-массива. Все символы ASCII. Уже завершённый
переводом строки рисунок выводится напрямую, без лишней пустой строки.
