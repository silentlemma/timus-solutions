# 1962. 带指定相邻关系的圆桌排列

[Timus 1962](https://acm.timus.ru/problem.aspx?space=1&num=1962) · difficulty 797 · graphs

Original problem from Open Ural FU Personal Contest 2013 | author not listed on Timus.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

将编号 1 到 n 的不同人围坐一圈，1 号的座位固定。对每个 i=1,…,m，
k_i 必须坐在 i 的任意一侧相邻座位。计算满足要求的排列数，模
1,000,000,007。旋转视为相同，镜像视为不同。只有两个人时，左右两侧
的邻居其实是同一个人。时间限制 1 秒，内存限制 64 MB。

## 输入

先给出 n,m，满足 2≤n≤100、0≤m≤n；随后 m 行各给出 k_i，满足
1≤k_i≤n 且 k_i≠i。提出要求的人恰好是编号前缀 1,…,m，输入不是
任意两个人组成的边对。

## 输出

一个整数：固定 1 号座位后的合法排列数，模 1,000,000,007。

## 评测方式

按记号逐个比较输出。

## 样例

```
6 6
2
1
1
5
6
5
```

```
4
```

```
4 3
2
3
1

```


## 解法

第一个样例形成两条路径 2–1–3 和 4–5–6。两个块的循环次序只有一种，
每条路径各有两个方向，因此得到 1!·2²=4。第二个样例强制 1、2、3
构成三角形，无法在保留所有必需相邻关系的同时插入 4 号，答案为零。

将要求视为无向边，互相要求只保留一条边。若任意顶点出现超过两个
不同邻居，立即返回零。否则每个连通分量都是路径、孤立顶点或环。
使用显式栈遍历分量，统计顶点数和度数之和；度数和等于顶点数的两倍
时，这个分量是环。

若环未覆盖全部 n 人，则其每个顶点的两侧都必须留给环内邻居，无法
接入其余人，答案为零。若环覆盖全部人，仅有两个遍历方向，固定
1 号座位后得到两个不同排列。

没有环时，把每条路径及每个孤立顶点缩成一个块。设块数为 C，至少
两个顶点的路径数为 P。不同块有 (C−1)! 种循环次序，每条非平凡路径
有两个方向，孤立顶点只有一个方向。因此答案为 (C−1)!·2^P 取模。

对 n≥3，这是双射：路径上的必需边迫使整条路径连续就座，每个合法
排列给出带方向块的循环次序；展开任意这种次序又会满足全部要求。
无论 1 号位于路径端点、内部还是孤立块，展开后的圆排列恰好只有一个
旋转能把 1 号放入固定座位，不需要额外乘以所在块的长度。

n=2 单独返回 1，因为唯一固定座位排列总是合法；整条二顶点路径的
两个方向实际上相同。计算阶乘和二的幂时，每次相乘都立即取模。

时间 `O(n+m)`，空间 `O(n+m)`。每次成功插边前，邻接表长度至多为二，
查重只需常数时间。插入后若产生度数三，立即退出。

互相要求不是两条平行边，孤立顶点也计入块数。覆盖全部人的环贡献二，
较小的环使答案为零。不要为镜像除以二，也不要乘以固定客人所在块的
长度。无要求时得到 (n−1)!；n≥3 时整条路径得到二。入栈即标记访问，
避免重复压栈。阶乘步骤的中间乘积需要 64 位，不能只使用 32 位整数。

## 各语言说明

C++ 使用 int64_t，Go 1.14 使用 int64，Java 8 使用 long，Rust 1.75
使用 u64 进行模乘。各版本使用邻接表和显式栈。Python 3.12 使用
整数及模幂 pow，无需递归。
