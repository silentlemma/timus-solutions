# 1962. Круговая рассадка с обязательными соседями

[Timus 1962](https://acm.timus.ru/problem.aspx?space=1&num=1962) · difficulty 796 · graphs

Original problem from Open Ural FU Personal Contest 2013 | author not listed on Timus.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Рассадить n различных людей с номерами от 1 до n по кругу. Место человека 1
фиксировано. Каждый человек i от 1 до m требует, чтобы человек k_i сидел
рядом с любой стороны. Найти число допустимых рассадок по модулю
1 000 000 007. Повороты не различаются, зеркальные рассадки различаются.
При n=2 один и тот же человек является соседом с обеих сторон.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

Числа n,m: 2≤n≤100, 0≤m≤n, затем m чисел k_i, по одному в строке.
Выполнено 1≤k_i≤n и k_i≠i. Требования задают именно люди 1,…,m,
а не произвольные пары исходных номеров.

## Выходные данные

Одно число — количество подходящих рассадок с фиксированным местом
первого человека по модулю 1 000 000 007.

## Проверка

Ответы сравниваются по токенам.

## Решение

Первый пример задаёт пути 2–1–3 и 4–5–6. Циклический порядок двух блоков
единственный; каждый путь можно развернуть. Получаем 1!·2²=4. Во втором
примере люди 1,2,3 образуют обязательный треугольник: вставить человека 4,
не разорвав нужное соседство, нельзя, поэтому ответ нулевой.

Каждое требование превращаем в неориентированное ребро. Встречные
требования дают одно ребро. Если степень вершины стала больше двух,
решения нет. Иначе каждая компонента — путь, отдельная вершина либо цикл.
Обходим компоненты явным стеком, подсчитывая вершины и сумму степеней.
Компонента является циклом, когда сумма степеней равна удвоенному числу
её вершин.

Цикл, охватывающий не всех людей, делает рассадку невозможной: оба места
рядом с каждой его вершиной уже требуются внутри цикла, и присоединить
остальных некуда. Если цикл охватывает всех n людей, остаются ровно два
направления обхода; положение человека 1 устраняет повороты.

Когда циклов нет, сожмём каждый путь, включая одиночную вершину, в блок.
Пусть C — число блоков, P — число путей хотя бы из двух вершин.
Циклических порядков различных блоков (C−1)!, а направлений у каждого
нетривиального пути два. Искомое число равно (C−1)!·2^P по модулю.

Для n≥3 это взаимно однозначное соответствие. Рёбра пути вынуждают его
вершины занимать последовательные места, поэтому всякая рассадка даёт
циклический порядок направленных блоков. Их раскрытие удовлетворяет
всем требованиям. Где бы внутри своего блока ни находился человек 1,
ровно один поворот раскрытого порядка ставит этого человека на нужное
место. Умножать дополнительно на длину блока не надо.

При n=2 сразу выводим 1: единственная рассадка подходит при любом
допустимом вводе. Два направления единственного пути здесь совпадают.
Факториал и степень считаем с приведением по модулю после каждого шага.

Время `O(n+m)`, память `O(n+m)`. До каждой успешной вставки списки
соседей содержат не больше двух элементов, поэтому поиск дубликата
занимает константное время. При появлении степени три сразу завершаемся.

Встречные требования нельзя считать двумя рёбрами. Одиночные вершины
тоже являются блоками. Полный цикл даёт два ответа, неполный — ноль.
Не делим результат на два за отражение и не умножаем на длину блока
первого человека. Без требований ответ (n−1)!, полный путь даёт два
при n≥3. Помечаем вершину при добавлении в стек. Промежуточное
модульное произведение требует 64 бит, хотя остаток помещается в 32.

## Особенности языков

C++ использует int64_t, Go 1.14 — int64, Java 8 — long, Rust 1.75 — u64
для произведений. Во всех версиях списки соседей и явный стек.
Python 3.12 использует целые числа и модульный pow; рекурсии нет.
