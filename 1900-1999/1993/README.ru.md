# 1993. Перестановка отмеченных фраз и исправление регистра

[Timus 1993](https://acm.timus.ru/problem.aspx?space=1&num=1993) · сложность 204 · parsing, strings

Автор оригинальной задачи — Денис Дублённых; подготовка — Евгений Курпилянский.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Переставьте части размеченного предложения. В каждой простой части ровно
один объект в `{фигурных скобках}`, один субъект в `(круглых)` и
глагольная группа в `[квадратных]`, в произвольном порядке. Каждая
группа содержит одно или несколько слов. Предложение состоит из одной
части либо двух, разделённых единственной запятой. Сразу после запятой
возможен союз из одного слова без скобок; это единственное возможное
слово вне групп.

В каждой части выведите объект, затем субъект, затем глагольную группу,
удалив скобки и сохранив порядок слов внутри групп. Союз оставьте перед
второй переставленной частью. Заглавной должна быть только первая буква
первого слова всего результата; остальные буквы строчные, включая слова
после запятой.

Длина ввода не больше 100 символов. Слова состоят только из латинских
букв. Изначально заглавная только первая буква первого входного слова.
Вложенных скобок нет, они стоят на границах слов. Между словами ровно
один пробел; перед запятой и закрывающими скобками и после открывающих
пробела нет. Лимит времени — 1 секунда, памяти — 64 МБ.

## Входные данные

Одна полная строка с размеченным предложением.

## Выходные данные

Одна строка результата. Между словами один пробел, перед запятой пробела
нет, после неё один. Новые знаки препинания не добавляются.

## Проверка

Вывод сравнивается посимвольно; отличается только необязательный последний перевод строки.

## Примеры

Ввод:

```
(We) [are] {blind}, if (we) [could not see] {creation of this clone army}
```

Вывод:

```
Blind we are, if creation of this clone army we could not see
```

Ввод:

```
{Truly wonderful} (the mind of a child) [is]
```

Вывод:

```
Truly wonderful the mind of a child is
```

## Решение

Сначала переведём весь ввод в нижний регистр. Прежнее первое слово может
переместиться в середину и должно потерять заглавную букву. Разделим
строку по запятой: внутри группы её быть не может, поскольку там только
слова.

Просматриваем каждую часть слева направо. Встретив `{`, `(` или `[`,
находим соответствующую закрывающую скобку, сохраняем содержимое в
ячейке объекта, субъекта или глагола и переходим за группу. Буквы вне
скобок образуют союз. Пробелы пропускаем. Соединяем необязательный союз
и три ячейки в порядке объект–субъект–глагол. Части соединяем через `, `
и делаем заглавным только первый символ полного результата.

Группы не вложены, поэтому соответствующая закрывающая скобка
заканчивает ровно текущую фразу. Тип скобки однозначно задаёт роль;
каждая роль в части встречается ровно один раз. Сохранение внутреннего
текста не меняет слова и их взаимный порядок. Просмотр перескакивает
через группы целиком, поэтому вне них читает ровно возможный союз.

Сборка выводит каждую фразу один раз в нужном порядке, а союз оставляет
перед второй частью. Запятая разделяет те же части. Начальное приведение
к нижнему регистру и единственная заглавная буква после сборки
исправляют регистр как прежнего, так и нового первого слова. Поэтому
совпадают слова, порядок, пунктуация и регистр.

В первом примере начальным становится объект, а союз остаётся после
запятой. Во втором объект уже первый, его внутренний порядок слов не
меняется.

## Оптимизированные решения

Сохраняется доказательство разбора по ролям. Компактные C++/Go держат границы фраз в одном ограниченном ASCII-буфере вместо копий и потоковых строковых объектов. Просмотр перескакивает через целую группу, запоминая объект, субъект и глагольную часть; слово вне групп — необязательный союз второй части. Выводятся союз и три роли в нужном порядке, исходный разделитель с запятой, все буквы становятся строчными кроме первой буквы результата. Группы не вложены, роли уникальны, поэтому каждая фраза выводится ровно один раз с прежним порядком слов. Python использует срезы и существующие текстовые потоки. При длине L<=100 время и память O(L).

- `1993_parsing_optimized.cpp`: 0.015 s / 76 KB; база `1993_parsing.cpp`: 0.015 s / 388 KB; изменение относительно базы: время -0.0%, память -80.4%.
- `1993_parsing_optimized.go`: 0.015 s / 272 KB; база `1993_parsing.go`: 0.031 s / 1184 KB; изменение относительно базы: время -51.6%, память -77.0%.
- `1993_parsing_strings.py`: 0.156 s / 300 KB; база `1993_parsing.py`: 0.062 s / 504 KB; изменение относительно базы: время +151.6%, память -40.5%.

## Особенности языков

Сохранённые срезы: 1–2 ноября 2026 года. Цель C++ — топ 15% либо первые 10 мест одновременно по времени и памяти; других семейств — первое место по обеим метрикам. Ничьи делят место. Пустые выборки дают только формальное покрытие.

Используется сохранённый профиль текущих компиляторов; исключены собственный автор и старые строки со временем меньше 0,015 с. Для семейств кроме C++ дополнительно требуется ID посылки ≥10770000; память C++ сравнивается по первым 1000 подходящим строкам. Собственные времена меньше 0,015 с считаются 0,015 с.
