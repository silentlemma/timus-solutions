# 1993. 重排标记短语并修正大小写

[Timus 1993](https://acm.timus.ru/problem.aspx?space=1&num=1993) · 难度 204 · parsing, strings

原题作者 Denis Dublennykh（由 Eugene Kurpilyansky 整理）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

重排一个已标记句子。每个简单分句恰有一个 `{花括号}` 宾语、一个 `(圆括号)` 主语和一个 `[方括号]` 动词短语，原顺序任意。每组含一个或多个词。输入是一分句，或两个以唯一逗号分隔的分句。逗号后可紧跟一个没有括号的单词连词；这是唯一可能不在括号内的词。

每个分句按宾语、主语、动词顺序输出，删除括号，保留组内词序。连词保留在第二个重排分句前。整个输出只有第一个词的第一个字母大写，其他字母均小写，包括逗号后。

输入长度至多 100 字符，单词只含拉丁字母。原输入仅第一个词首字母大写。括号不嵌套，位于词边界；词间恰有一个空格，逗号或右括号前、左括号后无空格。时间限制 1 秒，内存限制 64 MB。

## 输入

包含完整标记句子的一行。

## 输出

重排后的一行。词间一个空格，逗号前无空格、后有一个。不要增加标点。

## 评测方式

输出逐字符比较，仅允许末尾换行不同。

## 样例

输入：

```
(We) [are] {blind}, if (we) [could not see] {creation of this clone army}
```

输出：

```
Blind we are, if creation of this clone army we could not see
```

输入：

```
{Truly wonderful} (the mind of a child) [is]
```

输出：

```
Truly wonderful the mind of a child is
```

## 解法

先将整个输入转为小写，因为原首词可能移到中间，需要去掉其大写。按逗号分开分句；组内只有词，不会含逗号。

逐分句从左到右扫描。遇 `{`、`(`、`[` 时，找到相应右括号，将内部文本存入宾语、主语、动词槽，再跳到组后。括号外的字母组成可选连词，空格跳过。按可选连词、宾语、主语、动词拼接，各分句用 `, ` 连接，最后只将整个结果第一个字符转为大写。

无嵌套保证匹配右括号恰好结束当前短语，括号种类唯一确定角色，每种角色出现一次。原样保存内部文本保留全部词及组内顺序。扫描跳过完整组，所以括号外读到的字母恰为可选连词。

拼接将各短语按规定顺序输出一次，连词仍在第二分句前，逗号仍分隔相同分句。先全部小写、最后仅首字母大写，确保移动的原首词失去不合适的大写，新首词获得大写。因此词、顺序、标点及大小写均正确。

第一个例子中宾语移到开头，连词留在逗号后。第二个例子中宾语已经在前，组内词序不变。

## 优化解法

保留按角色解析的证明。紧凑C++/Go在一个有界ASCII输入缓冲中保存短语区间，避免复制短语及流/字符串对象。扫描时跳过整组，记录宾语、主语、动词位置；组外单词是第二分句的可选连词。依次输出连词及三种角色，保留逗号分隔，全部转小写，仅结果首字母大写。组不嵌套且角色唯一，因此每个短语恰输出一次，内部词序不变。Python用切片及现有文本流。L<=100，时间和存储均O(L)。
