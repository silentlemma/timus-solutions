# 1915. Руины титанов: воссоздание былого

[Timus 1915](https://acm.timus.ru/problem.aspx?space=1&num=1915) · difficulty 228 · simulation

Автор оригинальной задачи — Денис Дублённых; NEERC 2012, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Изначально стек пуст. Положительное число кладётся на вершину; −1
снимает и выводит вершину; 0 ставит сверху полную копию стека, сохраняя
порядок снизу вверх. Выведите снятые значения в порядке операций.
Перед каждым снятием стек гарантированно непуст. Его настоящая высота
может экспоненциально превышать количество операций.
Ограничения: 2 секунды, 128 МБ.

## Входные данные

n, 1≤n≤1 000 000, затем n строк, в каждой одно целое x:
−1, 0 либо значение монеты от 1 до 1 000 000 000.

## Выходные данные

По одному снятому значению в строке, в хронологическом порядке.
Если снятий нет, вывод пуст.

## Проверка

Точное сравнение целых токенов с сохранением порядка.

## Примеры

```
8
3
4
0
-1
-1
-1
-1
1
```

```
4
3
4
3
```

## Решение

Прочитаем операции и посчитаем число снятий P. В каждый момент r —
количество ещё не выполненных снятий. Храним только верхние min(h,r)
значений, где h — настоящая, возможно огромная высота. Более глубокие
элементы невозможно увидеть, не потратив больше r снятий. При P=0
вывода нет; после r=0 оставшиеся операции несущественны.

Используем кольцевой массив физической ёмкости P, логическое начало b
и размер s. Индексы берутся по модулю P. Логическая ёмкость r уменьшается
и может стать меньше физической.

При добавлении кладём значение в логический конец. Если s=r, сначала
удаляем нижний сохранённый элемент. При снятии выводим последний элемент,
уменьшаем s и r на единицу.

При удвоении сохраняем текущую вершину на месте. Если s=r, все будущие
наблюдаемые значения уже известны, ничего не меняется. Иначе настоящий
стек полностью сохранён, его размер s. Под него нужно дописать только
q=min(s,r−s) значений — последние q элементов старого стека.
Переносим этот суффикс перед логическим началом: новое начало
(b−q) mod P, начало источника (b+s−q) mod P. Приёмник занимает свободные
ячейки и не пересекается с источником. Пустой стек и заполненная
логическая ёмкость дают q=0.

### Корректность

Инвариант: сохранена ровно верхняя часть длины min(h,r). Для добавления
нужны лишь старые верхние r−1 элементов и новое значение, поэтому
отбрасывание нижнего допустимо. После снятия нужна глубина min(h−1,r−1),
на единицу меньше прежней; выводится настоящая вершина. При копировании,
если h≥r, верхние r элементов не меняются. Если h<r, стек известен
полностью; удвоенная последовательность заканчивается старым стеком,
а перед ним стоит указанный суффикс. Все операции сохраняют инвариант,
поэтому все ответы верны.

### Суммарная оценка

Каждое снятие уменьшает s на один, незаполненное добавление увеличивает
на один, заполненное добавление не меняет размер. Копирование увеличивает
s на q. Вначале s=0, после последнего снятия r=s=0. Поэтому сумма всех
q равна P минус число увеличивающих размер добавлений и не превосходит P.
Даже множество удвоений не вызывает повторной большой работы.
Время `O(n)`, память `O(n)`: список операций и кольцо имеют длину не больше n.

В примере [3,4] превращается в [3,4,3,4]; снятия дают 4,3,4,3.
Последнее добавление уже не влияет на вывод.

Копия сохраняет порядок, а не переворачивает стек. Суффикс добавляется
снизу под сохранённую часть. Логическая ёмкость уменьшается только при
снятии. При r<P заполненное добавление удаляет низ и дописывает в конец,
простая перезапись старого нижнего слота неверна. Учтите пустое копирование,
отсутствие вывода и запрет на экспоненциальное разворачивание или сдвиги массива.
