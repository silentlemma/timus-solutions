# 1945. Раскраска семейств через показатели простых

[Timus 1945](https://acm.timus.ru/problem.aspx?space=1&num=1945) · difficulty 3183 · number_theory

Original problem from Open Ural FU Personal Contest 2012 | by Andrey Demidov.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны различные положительные числа и g залов. Числа a,b могут быть
братьями, если a=p·i, b=p·j для некоторого целого p>0 и разных номеров
рождения 1≤i,j≤g. Их нужно отправить в разные залы для любого
возможного p, даже если родителя и других членов семьи нет во входе.
Найти любую допустимую рассадку. Ограничения: 1 секунда, 64 МБ.

## Входные данные

n и g, 1≤n≤50000, 2≤g≤5, затем n попарно различных целых a₁,…,a_n
из 1..10^9. Ответ должен соответствовать исходному порядку чисел.

## Выходные данные

Yes и n целых номеров залов из 1..g, по одному на входное число;
либо No при невозможности. Регистр обязателен, допустима любая
корректная раскраска. Ниже доказано, что все допустимые входы разрешимы.

## Проверка

Проверяющая программа перебирает все пары значений, которые могут
оказаться братьями при каком-нибудь родителе, и принимает любое
допустимое распределение. По построению ниже ответ `No` в пределах
ограничений неверен.

## Примеры

```
5 2
1
2
3
4
6
```

```
Yes
1
2
1
1
2
```

## Решение

Пусть v_p(a) — показатель простого p в a. Берём w₃=min(g−1,3) и
F(a)=v₂(a)+w₃·v₃(a)+4·v₅(a) по модулю g. Номер зала F(a)+1.
Три показателя находим повторными делениями, прочие множители не нужны.
Полная таблица малых множителей:

| g | w₃=min(g−1,3) | F(1),…,F(g) modulo g |
|---:|---:|---|
| 2 | 1 | 0, 1 |
| 3 | 2 | 0, 1, 2 |
| 4 | 3 | 0, 1, 3, 2 |
| 5 | 3 | 0, 1, 3, 2, 4 |

Выбор весов: F(2)=1 влечёт F(4)=2. При g=3 задаём F(3)=2, при
g=4 или 5 — F(3)=3. Для g=5 оставшийся остаток занимает F(5)=4.
При меньших g неиспользованные множители ничем не ограничены,
поэтому коэффициент v₅ можно оставить тем же. В строке таблицы
каждый остаток встречается ровно один раз.

Показатели аддитивны: v_q(p·i)=v_q(p)+v_q(i), откуда
F(p·i)=F(p)+F(i) по модулю g. Общая прибавка F(p) сохраняет
различие всех остатков строки. Поэтому полная возможная семья
p,2p,…,gp попадает в g разных залов, и любая её часть тоже допустима.
Это доказывает разрешимость любого корректного входа, программы
всегда печатают Yes. Используется циклическое сложение, в том числе
при составном g=4; простота g не предполагается.

Время O(n log A), A=max a_i≤10^9: не больше 29 успешных делений на
число и трёх неуспешных проверок. Одна метка требует O(1) памяти.
Полные программы с буферами используют не больше O(n), C++ и Go
обрабатывают числа и вывод потоком с ограниченными буферами.
Аккумулятор не больше 4·29, хватает знаковых 32 бит.

У возможных братьев отношение может быть нецелым: 4 и 6 имеют
родителя 2 при g≥3. Пара 3,4 может сидеть вместе при g=3, но не g=4.
Родителя может не быть в очереди. Вес w₃ зависит от g; к остатку
нужно прибавить один. Сохранить порядок входа и регистр Yes/No.
Ответ может отличаться от примера и оставаться правильным.

## Особенности языков

Только целочисленная арифметика, по одному залу в строке. Java и Rust
собирают вывод; Python хранит вход и ответы. Достаточно делений на
2,3,5 — полная факторизация до sqrt(A), общая раскраска графа и поиск
невозможного случая не нужны.
