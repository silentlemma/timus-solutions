# 1973. 固定多边形顶点的随机三角形期望面积

[Timus 1973](https://acm.timus.ru/problem.aspx?space=1&num=1973) · difficulty 4773 · geometry

原题作者 Denis Dublennykh，出自 2013 年乌拉尔体育编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

固定凸多边形的第一个顶点 A，独立且按面积均匀地在严格内部选择
B、C，求三角形 ABC 无向面积的期望。顶点数 3≤n≤1000，逆时针顺序，
整数坐标范围 −10⁶…10⁶，任意三顶点不共线。限制：1 秒，64 MB。

## 输入

n 后接边界顺序的 n 对 x,y。第一对为固定 A，不能随意更换起始顶点。

## 输出

一个实数期望面积。绝对误差或相对误差至多 10⁻⁶，满足任一即可。

## 评测方式

检查器按不超过 10⁻⁶ · max(1, |答案|) 的误差比较该数。

## 样例

```
4
0 0
1 0
1 1
0 1
```

```
0.120370370
```

## 解法

平移 A 到原点，其余顶点为 v₁,…,vₙ₋₁。扇形三角形
Tᵢ=(0,vᵢ,vᵢ₊₁)，i=1,…,n−2，面积 sᵢ>0，除零概率边界外划分整个
多边形。设总面积 S，dᵢ=2sᵢ=cross(vᵢ,vᵢ₊₁)，tᵢ=vᵢ+vᵢ₊₁，D=Σdᵢ。
cross(x,y)=xₓyᵧ−xᵧyₓ，三角形重心 cᵢ=tᵢ/3。

### 点在不同扇形三角形

i<j 时 Tᵢ 的射线在 Tⱼ 之前，凸多边形此顶点的整个角度小于 π，
所以 B∈Tᵢ、C∈Tⱼ 时 cross(B,C)≥0。条件独立使叉积期望为
cross(cᵢ,cⱼ)，面积是其一半。两种顺序 (i,j)、(j,i) 总概率为
2sᵢsⱼ/S²，合计贡献

sᵢsⱼ·cross(cᵢ,cⱼ)/S²。

### 点在同一个三角形

T=(0,u,v) 中的均匀点写为 r((1−t)u+tv)。t 在 [0,1] 均匀且独立于
密度 2r 的 r，故 E[r]=2/3。两点参数 (r,t)、(q,z) 的锚定面积为
area(T)·r·q·|t−z|。E|t−z|=1/3，所以条件期望为 (4/27)·area(T)。

乘以 (sᵢ/S)² 后加上不同三角形情形：

E = [(4/27)Σsᵢ³ + Σᵢ<ⱼ sᵢsⱼ·cross(tᵢ,tⱼ)/9] / S²。

代入 dᵢ=2sᵢ、D=2S：

E = [2Σdᵢ³ + 3Σᵢ<ⱼ dᵢdⱼ·cross(tᵢ,tⱼ)] / (27D²)。

### 前缀消除二重求和

处理 j 前保存精确向量 P=Σᵢ<ⱼ dᵢtᵢ，此 j 的成对贡献就是
dⱼ·cross(P,tⱼ)。分子加 2dⱼ³+3dⱼ·cross(P,tⱼ)，再将 P 加 dⱼtⱼ、
D 加 dⱼ。一遍扫描计算公式，最终各项非负。条件分类覆盖所有随机
点对，因此公式与前缀实现均正确。

时间为 `O(n)` 次算术运算，输入点占 `O(n)` 空间，另有 `O(1)` 个
累加器。整数位数由本题坐标和顶点上界限制。

### 先精确相减，再舍入

平移后坐标绝对值至多 2·10⁶，dᵢ≤8·10¹²，tᵢ 坐标至多 4·10⁶。
粗界已给出 P 坐标至多 3.2·10²²、|cross(P,tᵢ)| 至多 2.56·10²⁹，
有符号 128 位足够。近乎平行射线会使两个大乘积抵消，必须先精确
计算差。最终分子可能超过 128 位，故 C++、Rust 在立方和乘 dᵢ 前
把正项转浮点，最终正项和没有抵消。其他版本整段分数保持任意精度
整数，最后一次除法才舍入。

样例 d₁=d₂=1、t₁=(2,1)、t₂=(1,2)、cross(t₁,t₂)=3、D=2。分子
2(1+1)+3·3=13，分母 27·4=108，得到 13/108≈0.12037037037，
与打印值一致。

均匀按面积选择，扇形三角形必须按面积加权。固定首顶点。两个同分布
点的有向叉积期望为零，不能代替无向面积；须按角度顺序分类。不要
漏掉同三角形贡献或误用其他随机三角形常数代替 4/27。前缀相减用
精确宽整数，立方或 D² 前转换类型以免溢出。
