# 1973. Средняя площадь треугольника с закреплённой вершиной

[Timus 1973](https://acm.timus.ru/problem.aspx?space=1&num=1973) · difficulty 4773 · geometry

Автор оригинальной задачи — Денис Дублённых; XVII Открытый чемпионат Урала по спортивному программированию (май, 2013).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Зафиксирована первая вершина A выпуклого многоугольника. Точки B и C
независимо и равномерно по площади выбираются строго внутри него.
Найдите математическое ожидание обычной неориентированной площади ABC.
Вершин 3≤n≤1000, обход против часовой стрелки, целые координаты от −10⁶
до 10⁶ включительно, никакие три вершины не коллинеарны. Ограничения:
1 секунда, 64 МБ.

## Входные данные

n, затем n пар x,y в порядке границы. Первая пара — закреплённая A;
смена начальной вершины меняет задачу.

## Выходные данные

Одно вещественное число — ожидаемая площадь. Принимается абсолютная
или относительная ошибка не больше 10⁻⁶: достаточно одного условия.

## Проверка

Проверяющая программа сравнивает число с погрешностью не больше 10⁻⁶ ·
max(1, |ответ|).

## Примеры

```
4
0 0
1 0
1 1
0 1
```

```
0.120370370
```

## Решение

Перенесём A в начало координат. Остальные вершины — v₁,…,vₙ₋₁. Веер
Tᵢ=(0,vᵢ,vᵢ₊₁), i=1,…,n−2, с положительными площадями sᵢ разбивает
многоугольник, кроме границ нулевой вероятности. Обозначим площадь S,
dᵢ=2sᵢ=cross(vᵢ,vᵢ₊₁), tᵢ=vᵢ+vᵢ₊₁, D=Σdᵢ. Здесь
cross(x,y)=xₓyᵧ−xᵧyₓ; центр масс Tᵢ равен cᵢ=tᵢ/3.

### Точки в разных треугольниках веера

При i<j лучи Tᵢ идут раньше лучей Tⱼ. Угловой диапазон при вершине
выпуклого многоугольника меньше π, поэтому cross(B,C)≥0 для B из Tᵢ,
C из Tⱼ. Условная независимость даёт ожидание векторного произведения
cross(cᵢ,cⱼ), а площадь равна его половине. Два порядка (i,j),(j,i)
имеют суммарную вероятность 2sᵢsⱼ/S², поэтому вклад пары равен

sᵢsⱼ·cross(cᵢ,cⱼ)/S².

### Точки в одном треугольнике

Равномерную точку T=(0,u,v) запишем r((1−t)u+tv). Параметр t равномерен
на [0,1] и независим от r с плотностью 2r, поэтому E[r]=2/3. Для двух
точек с параметрами (r,t),(q,z) площадь равна area(T)·r·q·|t−z|.
Поскольку E|t−z|=1/3, условное ожидание равно (4/27)·area(T).

Умножаем на (sᵢ/S)² и добавляем разные треугольники:

E = [(4/27)Σsᵢ³ + Σᵢ<ⱼ sᵢsⱼ·cross(tᵢ,tⱼ)/9] / S².

Подстановка dᵢ=2sᵢ и D=2S даёт

E = [2Σdᵢ³ + 3Σᵢ<ⱼ dᵢdⱼ·cross(tᵢ,tⱼ)] / (27D²).

### Префикс вместо суммы пар

Перед j храним точный вектор P=Σᵢ<ⱼ dᵢtᵢ. Тогда парная сумма для j
равна dⱼ·cross(P,tⱼ). Прибавляем к числителю 2dⱼ³+3dⱼ·cross(P,tⱼ),
затем P увеличиваем на dⱼtⱼ и D на dⱼ. Один проход вычисляет выведенную
формулу, все слагаемые неотрицательны. Условные случаи покрывают все
пары выбранных точек, что доказывает корректность формулы и префикса.

Время — `O(n)` арифметических операций, хранимые точки — `O(n)` памяти,
дополнительно `O(1)` накопителей. Размер целых ограничен условиями.

### Точная разность перед округлением

После переноса модуль координат до 2·10⁶, dᵢ≤8·10¹², координат tᵢ до
4·10⁶. Даже грубая оценка даёт координаты P до 3,2·10²², а
|cross(P,tᵢ)| до 2,56·10²⁹: хватает знаковых 128 бит. Эту разность
надо вычислять точно, поскольку почти параллельные лучи дают близкие
большие произведения. Полный числитель может превышать 128 бит, поэтому
C++ и Rust переводят неотрицательные слагаемые в вещественный тип до
куба и умножения на dᵢ. В итоговой сумме нет вычитания близких чисел.
Другие версии сохраняют весь числитель целым произвольной длины до деления.

В примере d₁=d₂=1, t₁=(2,1), t₂=(1,2), cross(t₁,t₂)=3, D=2.
Числитель 2(1+1)+3·3=13, знаменатель 27·4=108. Получаем
13/108≈0,12037037037, то есть показанное округлённое значение.

Равномерность по площади требует весов площадей треугольников веера.
Первая вершина фиксирована. Ожидание ориентированного векторного
произведения двух одинаково распределённых точек равно нулю; обычная
площадь требует разобрать угловой порядок. Не теряйте случай одного
треугольника и коэффициент 4/27. Префиксная разность должна быть точной,
а перед кубами и D² нужен переход в тип, который не переполнится.

## Особенности языков

Python, Go 1.14 math/big и Java 8 BigInteger сохраняют всю дробь точно.
C++ использует __int128 для префикса и long double для суммы, Rust —
i128 и f64. Выводятся двенадцать знаков после точки. Внешние библиотеки
не нужны, используются стандартные и целые типы выбранных компиляторов.
