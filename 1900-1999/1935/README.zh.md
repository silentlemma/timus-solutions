# 1935. 允许重排时的最少纸张数

[Timus 1935](https://acm.timus.ru/problem.aspx?space=1&num=1935) · difficulty 80 · greedy

Original problem from Open Ural FU Championship 2012 | by Tatiana Sharypova (prepared by Oleg Dolgorukov).

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

将n个薄物体以任意顺序放入书页之间。物体i与每个相邻物体或
封面之间都至少需要a_i张纸。同一个间隔必须同时满足两侧物体。
求书中最少需要多少张纸。限制：1秒、64MB。

## 输入

第一行n，1≤n≤100。第二行有n个整数a_i，1≤a_i≤100。
输入顺序不限制放置顺序。

## 输出

输出一个整数，即满足所有要求的最少纸张数。

## 评测方式

按记号逐个比较输出。

## 样例

```
3
5 10 3
```

```
28
```

## 解法

答案是所有要求之和加上其中最大的一个，即 S + M。

不能更少：取要求最大的物品，其要求为 M。它左边的每个物品都需要自己左侧的空隙，
右边的每个物品都需要自己右侧的空隙，而最大的物品需要两侧的空隙。这是 n + 1 个
不同的空隙，合起来至少有 S + M 页。

这样也足够：把要求排序为 a₁ ≤ … ≤ aₙ，按此顺序放置物品，第一个之前留 a₁ 页，
第 i 个和第 i + 1 个之间留 a_(i+1) 页，最后一个之后留 aₙ 页。每个空隙都满足两侧
较大的要求，总数是 S + M。`O(n)`；程序中不需要排序。

注意事项：

- 相邻物品共用一个空隙：需要较大的要求，而不是两者之和；
- 输入顺序无关：100、1、100 需要 301 页，而不是 400 页；
- 只有一个物品时需要 2a₁ 页。

## 优化解法

优化的 C++ 解法用 `scanf` 代替 `iostream`，边读边求和与最大值，不保存这些要求：
124 KB，而不是 428 KB。
