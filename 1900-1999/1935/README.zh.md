# 1935. 允许重排时的最少纸张数

[Timus 1935](https://acm.timus.ru/problem.aspx?space=1&num=1935) · difficulty 80 · greedy

Original problem from Open Ural FU Championship 2012 | by Tatiana Sharypova (prepared by Oleg Dolgorukov).

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

将n个薄物体以任意顺序放入书页之间。物体i与每个相邻物体或
封面之间都至少需要a_i张纸。同一个间隔必须同时满足两侧物体。
求书中最少需要多少张纸。限制：1秒、64MB。

## 输入

第一行n，1≤n≤100。第二行有n个整数a_i，1≤a_i≤100。
输入顺序不限制放置顺序。

## 输出

输出一个整数，即满足所有要求的最少纸张数。

## 评测方式

按记号逐个比较输出。

## 样例

```
3
5 10 3
```

```
28
```

## 解法

令S为全部要求之和，M为最大要求，答案就是S+M。直接计算这
两个量即可，程序不需要排序。

先证明任意放法的下界。选择一个要求为M的物体。它左侧的每个
物体对应自己左边的间隔，右侧的每个物体对应自己右边的间隔；
选中的最大物体对应紧邻它的两个间隔。这样恰好对应全部n+1个
不同间隔，每个间隔的纸张数至少是对应要求。每个要求算一次，
选中的最大要求算两次，所以纸张总数至少为S+M。n=1或最大值
出现多次时此论证仍然成立。

再给出达到下界的放法。将要求按非递减顺序排为b_1≤...≤b_n。
第一个物体前放b_1张纸，物体i和i+1之间放b_{i+1}张，最后放
b_n张。每个内部间隔等于两侧要求的较大值，全部约束都满足。
总数为b_1+(b_2+...+b_n)+b_n=S+M，达到下界，因此公式最优。
排序仅用于证明存在这样的放法，不是计算答案所必需的操作。

时间O(n)。实现保存输入值，因此总空间O(n)，额外算术状态O(1)。

相邻物体共享间隔，只取较大要求而非两者相加。不能保留输入
顺序：100,1,100重排后只需301张纸，固定该顺序则需400张。
最大值需要额外计一次。单个物体也要2a_1张，因为有两个封面；
最大值重复出现并不改变公式。

## 各语言说明

答案至多100·100+100=10100，普通32位整数足够。C++使用整数
累加与最大元素，Go和Java在同一循环内维护和与最大值。Python
使用sum和max，Rust使用i32累加及非空切片的最大值。所有程序
按空白符读取整数，输出以换行结束。
