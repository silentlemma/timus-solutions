# 1983. Площадь части треугольника внутри шара

[Timus 1983](https://acm.timus.ru/problem.aspx?space=1&num=1983) · сложность 1547 · geometry

Автор оригинальной задачи — Михаил Рубинчик; Открытый командный чемпионат УрФУ по программированию — 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Три неколлинеарные точки с целыми координатами, по модулю не
превосходящими 200, задают заполненный треугольник в трёхмерном
пространстве. Найдите площадь его пересечения с замкнутым шаром радиуса
100 с центром в начале координат. Нужна площадь в плоскости
треугольника, а не площадь проекции или объём. Ограничения: 0,5 секунды
и 64 МБ.

## Входные данные

Три строки; в каждой три целые координаты одной вершины.

## Выходные данные

Одно неотрицательное вещественное число — искомая площадь.

## Проверка

Числа сравниваются с абсолютной или относительной погрешностью 10⁻².

## Примеры

Ввод:

```
0 0 0
0 2 0
2 0 0
```

Вывод:

```
2.00000
```

## Решение

Пусть вершины — `p,q,r`, нормаль `n=(q−p)×(r−p)`, `N=n·n>0`, `D=n·p`.
Уравнение плоскости треугольника: `n·x=D`. Если `F=10000N−D²≤0`,
плоскость не пересекает внутренность шара, поэтому площадь нулевая.
Иначе сечение — круг с квадратом радиуса `ρ²=F/N`; его центр является
проекцией начала координат на плоскость.

Выберем единичный вектор `u=(q−p)/|q−p|`, единичную нормаль `w=n/√N` и
`v=w×u`. Точка `x` получает плоские координаты `(x·u,x·v)`. Центр круга
переходит в ноль, поскольку параллелен `w`. Базис ортонормирован и
сохраняет площадь: остаётся пересечь плоский треугольник с кругом в
начале координат.

Для ориентированного ребра `p+t e`, `0≤t≤1`, используем исходные целые
3D-координаты. Обозначим `A=e·e`, `B=p·e`, `C=p·p−10000`, `Δ=B²−AC`.
Внутренняя часть прямой удовлетворяет `At²+2Bt+C<0`. При `Δ>0` границы
задают два корня. Устойчивая формула: `s=−B−copysign(√Δ,B)`, корни `s/A`
и `C/s`; упорядочим их. Разрежем ребро по корням строго внутри `(0,1)`.
Часть ребра внутренняя тогда и только тогда, когда параметр её середины
строго между корнями. При `Δ≤0` все части положительной длины внешние:
касание в середине не делает всё ребро внутренним.

Пусть `a,b` — плоские концы части ребра. Для внутренней части добавим
`cross(a,b)`, для внешней — `ρ²·atan2(cross(a,b),a·b)`. Суммируем со
знаком по границе, берём модуль и делим на два. Внутренние части дают
ориентированные треугольные веера, внешние — ориентированные сектора
круга. При сложении лишние веера сокращаются, а пересечение считается
один раз. Это также граничный интеграл непрерывного поля с ротором один
внутри круга и ноль снаружи. Разрезы в точках пересечения обосновывают
выбор треугольника или сектора на каждой части.

В примере весь прямоугольный треугольник внутри шара. Катеты равны 2,
площадь — `2·2/2=2`.

Рёбер всегда три, на каждом не более двух корней: время и память —
`O(1)`. Нормаль, остаток `F` и дискриминанты вычисляются целочисленно до
перехода к вещественным числам; при заданных границах достаточно
знаковых 64-битных типов. Для корней, проекций и углов используется
двойная точность.

Подводные камни:

- Все вершины снаружи шара не означают нулевую площадь: треугольник
  может содержать весь круг сечения.
- Сохраняйте знаки до последнего модуля и обработайте замыкающее ребро.
- Касание плоскости или ребра не создаёт внутреннего участка
  положительной длины.
- Вычисляйте `F` и `Δ` целочисленно, чтобы вычитание близких величин не
  изменило число пересечений.
- Нужен `atan2`, а не беззнаковый угол или деление на скалярное произведение.
- Нужна площадь в плоскости треугольника, а не её тень на координатной
  плоскости.

## Особенности языков

Все пять версий используют алгоритм постоянного размера. C++, Go, Java и
Rust хранят геометрические предикаты в знаковых 64-битных целых, площадь
— в двойной точности. Python использует точные целые и стандартную
вещественную арифметику. В Java явно выбран формат с десятичной точкой.
