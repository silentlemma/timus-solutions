# 1983. 球内三角形部分的面积

[Timus 1983](https://acm.timus.ru/problem.aspx?space=1&num=1983) · 难度 1546 · geometry

原题作者 Mikhail Rubinchik，出自 2013 年乌拉尔联邦大学公开团体锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

三个不共线的整点确定三维空间中的实心三角形，每个坐标的绝对值不超过 200。求三角形与以原点为球心、半径为 100 的闭球的交集面积。要求三角形平面中的实际面积，而非投影面积或体积。时间限制 0.5 秒，内存限制 64 MB。

## 输入

三行，每行给出一个顶点的三个整数坐标。

## 输出

输出一个非负实数，表示所求面积。

## 评测方式

数值按 10⁻² 的绝对或相对误差比较。

## 样例

输入:

```
0 0 0
0 2 0
2 0 0
```

输出:

```
2.00000
```

## 解法

设顶点为 `p,q,r`，法向量 `n=(q−p)×(r−p)`，`N=n·n>0`，`D=n·p`。三角形平面满足 `n·x=D`。若 `F=10000N−D²≤0`，平面与球内部无交集，面积为零。否则截面是圆盘，其半径平方为 `ρ²=F/N`，圆心是原点在该平面上的投影。

取单位向量 `u=(q−p)/|q−p|`、单位法向量 `w=n/√N` 以及 `v=w×u`。将顶点 `x` 映射为 `(x·u,x·v)`。圆心平行于 `w`，所以映射到原点；正交单位基保持面积。现在只需求平面三角形与原点圆盘的交集。

对每条有向边 `p+t e`，`0≤t≤1`，使用原来的整数三维坐标计算 `A=e·e`、`B=p·e`、`C=p·p−10000`、`Δ=B²−AC`。直线位于球内部的部分满足 `At²+2Bt+C<0`。若 `Δ>0`，边界是两个二次方程根。为避免相消，先算 `s=−B−copysign(√Δ,B)`，再算 `s/A` 和 `C/s` 并排序。用严格位于 `(0,1)` 的根切分边；子段中点参数严格位于两根之间时，该子段才在内部。若 `Δ≤0`，所有正长度子段都在外部：中点相切不能使整条边变成内部边。

对子段的平面端点 `a,b`，内部子段累加 `cross(a,b)`，外部子段累加 `ρ²·atan2(cross(a,b),a·b)`。沿三角形边界有符号求和，最后取绝对值并除以二。内部部分贡献有向三角形面积，外部部分贡献有向扇形面积；相加时多余部分抵消，圆盘与三角形交集恰好计数一次。这也可视为一个连续向量场的边界积分：圆内旋度为一，圆外为零。按全部交点切分，保证每个子段使用正确公式。

样例中的直角三角形完全在球内，两条直角边长均为 2，面积为 `2·2/2=2`。

固定三条边，每边最多两个根，时间和空间都是 `O(1)`。法向量、`F` 和判别式先用整数精确计算，再转换为浮点数；坐标范围保证有符号 64 位整数足够。平方根、投影和角度使用双精度。

注意事项：

- 三个顶点都在球外，交集仍可能是整个截面圆盘。
- 最后一步才取绝对值，并处理最后一个顶点到第一个顶点的边。
- 平面或边相切不会产生正长度的内部部分。
- 用整数计算 `F` 和 `Δ`，避免相消改变交点拓扑。
- 使用 `atan2`，保留角度的方向。
- 计算实际平面面积，而非坐标平面上的投影面积。

## 各语言说明

五个版本采用同一常数规模算法。C++、Go、Java 和 Rust 的几何判定使用有符号 64 位整数，面积使用双精度；Python 使用精确整数和标准浮点运算。Java 固定输出区域设置，使用小数点。
