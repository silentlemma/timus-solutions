# 1960. 每个前缀中不同的回文

[Timus 1960](https://acm.timus.ru/problem.aspx?space=1&num=1960) · difficulty 435 · strings

Original problem from Ural FU contest. Kontur Cup. Petrozavodsk training camp. Winter 2013 | by Mikhail Rubinchik (prepared by Grigory Nazarov).

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对单词每个非空前缀，统计不同的非空连续回文子串数。同一字符串多次出现
也只计一次；回文等于自身反转。限制：1 秒、64 MB。

## 输入

一个由 n 个小写英文字母组成的单词，1≤n≤100000。没有单独的长度整数。

## 输出

n 个空格分隔整数，依次对应长度 1…n 的前缀。不计空回文；统计字符串种类，
不是出现次数或最长回文长度。

## 评测方式

按记号逐个比较输出。

## 样例

```
aba
```

```
1 2 3
```

## 解法

样例中，`a` 只有 `a`，`ab` 有 `a,b`，`aba` 再加入 `aba`，因此答案依次为 1,2,3。

### 每次至多新增一个

加入 c 后，任何首次出现子串都以 c 结束。设新前缀的最长回文后缀为 P。
更短的回文后缀 Q 也是 P 的真前缀，因此早在 c 之前已出现。故只有 P
可能新增，每次新增零或一个不同回文，总数不超过 n。

### 回文树

使用标准的 eertree，见 [Rubinchik–Shur, 2015](https://arxiv.org/abs/1506.04862)。
此处实现说明自成一体。每个真实节点代表一个回文，保存长度、到最长真回文
后缀的链接，以及包裹转移 Q→cQc。两个虚根长度 −1、0，下标 0、1，
两者链接均指向 0；单字母节点链接到空根。内部回文和外层字母唯一确定
非空回文，因此每个节点恰有一个入转移。

last 保存加入前的最长回文后缀。沿后缀链接下降，直到候选前一字符等于 c。
长度 −1 的根比较的是新字符本身，故必停。最长可扩展 Q 给出新最长后缀
P=cQc。已有 c 转移则复用节点，否则创建长度 |Q|+2 的节点。

新长度为 1 时链接到空根；否则从 link[Q] 再找下一个可扩展后缀，跟随其
已有 c 转移，得到 P 的最长真回文后缀。该节点已存在，因为它也是 P 的真
前缀，出现更早。更新 last 为 P，每次输出真实节点数 total_nodes−2。

### 正确性与复杂度

链接按长度递减枚举回文后缀，首个可扩展候选必给出最长新后缀。内部节点和
字母唯一标识字符串，缺转移当且仅当该回文首次出现。其余回文已存在，由
归纳可知树恰好保存当前前缀的不同回文。

两次链接搜索总工作均线性。令 ℓ_old、ℓ_new 为前后 last 长度；失败链接
减少长度，包裹增加二，失败步数 ≤ℓ_old−ℓ_new+2，求和望远镜消去。
第二次令 q_old、q_new 为 last 的最长真后缀长度：起点 ≤q_old，终点
q_new−2，界 q_old−q_new+2 同样消去。不新增节点时不做第二次搜索，
但 q_new≤q_old+2 仍成立。

原生版本保存固定 26 字母的稠密转移，初始化及内存 `O(26n)`，即固定字母表
下 `O(n)`。Python 用稀疏字典精确整数键 parent*26+letter_code，期望时间
`O(n)`、空间 `O(n)`。键是单射表示，并非概率子串指纹。节点最多 n+2。

不要计入虚根、累加出现次数、漏掉偶回文，或假定每次必新增：`abca` 最终为 3。
取字符前必须检查左界，Python 负下标会静默读取错误位置。逐个枚举全部
回文出现可达平方规模，不适合长串。

## 各语言说明

C++ 用节点内数组；Go 1.14、Rust 1.75 用机器整数下标；Java 8 用单个
扁平 int 转移数组，避免逐节点对象。Python 用 bytes 和稀疏整数键。
Rust 仅用标准库，资源测量选择 CPython。
