# 1991. Неиспользованные запасы и оставшиеся цели

[Timus 1991](https://acm.timus.ru/problem.aspx?space=1&num=1991) · сложность 48 · implementation

Автор оригинальной задачи — Денис Дублённых; подготовка — Егор Щелконогов.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `n` независимых групп, в каждой ровно `k` целей. Группа `i`
получает `a_i` единиц запаса; каждая единица однократно устраняет одну
цель только своей группы. Действие всегда успешно. Передавать запасы
между группами нельзя. После максимального использования посчитайте
суммарный неиспользованный запас и число оставшихся целей.

Ограничения: `1≤n,k≤10000`, `0≤a_i≤100000`. Лимит времени — 1 секунда,
памяти — 64 МБ.

## Входные данные

В первой строке `n k`, во второй — `n` количеств запаса.

## Выходные данные

Два целых числа: сначала общий неиспользованный запас, затем общее число
оставшихся целей.

## Проверка

Ответы сравниваются по токенам.

## Примеры

Ввод:

```
4 5
2 7 5 0
```

Вывод:

```
2 8
```

По группам остаются пары `(запас,цели)`: `(0,3)`, `(2,0)`, `(0,0)`,
`(0,5)`. Их сумма — `(2,8)`.

## Решение

Каждая группа тратит min(aᵢ, k) припасов на min(aᵢ, k) целей. Значит,
при aᵢ > k остаётся aᵢ − k неиспользованных припасов, а иначе k − aᵢ
оставшихся целей. Эти числа суммируются по группам. `O(n)`.

Подводные камни:

- припасы не переходят между группами, поэтому в одной группе могут
  остаться лишние припасы, а в другой — цели: сравнивать только общие
  суммы неверно;
- сумма неиспользованных доходит до 10 000 · 99 999 ≈ 10⁹, это ещё
  помещается в 32-битное целое со знаком.
