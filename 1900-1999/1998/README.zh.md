# 1998. 在干扰下完成按序举起

[Timus 1998](https://acm.timus.ru/problem.aspx?space=1&num=1998) · 难度 378 · two_pointers

原题作者 Denis Dublennykh（由 Egor Shchelkonogov 整理）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

物体按照固定顺序举起。每个正常秒举起第一个尚未保持的物体。给定干扰秒不会举起物体，而是按相反顺序放下，直到放下的总重量严格超过 `k`，或已经全部放下。求第一次同时保持全部 `n` 个物体的秒数；完成后的干扰无效。

范围 `1≤n,m≤100000`、`1≤k≤10^9`、`1≤w[i]≤10000`；干扰时间严格递增，介于 1 与 `10^9`。时间 0.5 秒，内存 64 MB。

## 输入

先给 `n m k`，随后 `n` 个按举起顺序排列的重量，再给 `m` 个干扰时间。每个重量和时间单独一行。

## 输出

一个整数，表示完成秒数。

## 评测方式

按记号逐个比较输出。

## 样例

```
5 1 4
1
2
3
4
5
4
```

```
8
```

第 1–3 秒保持重量 1、2、3。第 4 秒不举起；只放下 3 尚未超过 4，还须放下 2，总重量 5。保留重量 1，第 5–8 秒重新举起剩余四个物体，因此答案 8。

## 解法

当前保持的物体始终是原顺序的前缀：正常步骤加一项，干扰删除后缀。因此前缀长度 `h` 足以描述状态。

### 预计算干扰后的长度

设 `P[h]` 是前 `h` 个重量和，`P[0]=0`，`retreat[h]` 是从长度 `h` 遭受一次干扰后保留的长度。

若 `P[h]≤k`，只能全部放下，答案为零。否则选最大的 `q<h` 使 `P[h]−P[q]>k`，这对应刚刚超过门槛时的最少放下数量。若 `q>0`，保留下一个更长前缀时放下总重不超过 `k`。等价于找到第一个不小于 `P[h]−k` 的前缀和，再取前一个位置并截断到零。

正重量让 `P` 严格递增，因此随 `h` 增加，所求位置不会向左。维护初始为零的指针 `q`。对每个 `h=1..n`，只要 `q+1<h` 且 `P[h]−P[q+1]>k` 就递增，最后写入 `retreat[h]=q`。旧位置在门槛增加时仍可用，停止条件说明更大的位置都不可用。总重尚未超过 `k` 时指针保持零。另设 `retreat[0]=0`。

指针总共最多移动 `n` 次，故预处理线性。比较必须为严格大于：放下总重恰为 `k` 时若仍有物体就要继续。

### 跳过事件间隔

维护最后处理的干扰时刻 `time` 和长度 `h`，初始均为零。下次干扰 `t` 之前恰有 `t−time−1` 个正常秒。若足够举起剩余 `n−h` 项，则返回 `time+n−h`，其严格早于 `t`。

否则将 `h` 增加该正常秒数，再替换为 `retreat[h]`，令 `time=t`。时刻 `t` 本身不举起。最后一次干扰之后答案为 `time+n−h`。

归纳可知，每次跳跃执行了字面过程中的全部正常举起，预计算表准确执行放下。完成检查返回最早可能完成时刻。若预计完成恰好落在干扰秒，必须处理干扰而不能提前结束。空前缀、连续干扰都符合相同公式。

### 复杂度与范围

五种语言时间 `O(n+m)`，包括输入存储的空间 `O(n+m)`；辅助表 `O(n)`。总重量至多 `10^9`，答案至多 `max(t)+n≤1000100000`。原生版本的重量和、时间使用 64 位。只有确认时间间隔小于缺失物体数后才转换为索引。

门槛必须严格超过；干扰秒不举起。全部保持后立即结束，忽略后续干扰。不要逐秒或逐个模拟全部掉落，稀疏时刻与深度重置能代表接近十亿次动作。干扰转移仅依赖前缀长度。
