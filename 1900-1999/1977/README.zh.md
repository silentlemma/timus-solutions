# 1977. 能量增长与三角形分配

[Timus 1977](https://acm.timus.ru/problem.aspx?space=1&num=1977) · 难度 2368 · segment_tree, simulation

原题作者 Denis Dublennykh，出自 2013 年乌拉尔体育编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `n` 个编号区段和一个仓库，初始能量均为零。每个区段每单位时间增加 `p` 单位能量。事件发生在互不相同、严格递增的整数时刻。`save l r` 将闭区间 `[l,r]` 的全部能量转移到仓库，并报告仓库新的总量。`enforce i d` 花掉仓库的全部能量：若 `|j−i|<d`，区段 `j` 增加 `x(d−|j−i|)`，其中 `x=仓库能量/d²`。这些能量叠加到区段原有能量上，随后仓库清零。

限制为 `1≤n≤10⁹`、`1≤p≤100`、`1≤q≤10⁵`、`0≤t≤10⁹`。保存操作满足 `1≤l≤r≤n`；分配操作满足 `1≤d≤min(i,n+1−i)`。时间限制 2 秒，内存限制 64 MB。

## 输入

第一行为 `n p`，第二行为 `q`。接下来按时间顺序给出 `q` 行 `t save l r` 或 `t enforce i d`。

## 输出

每次保存后输出仓库总能量。分配操作不输出。

## 评测方式

数值按 10⁻⁶ 的绝对或相对误差比较。

## 样例

输入：

```
5 1
4
2 save 4 5
3 enforce 2 2
4 save 3 5
5 enforce 3 3
```

输出：

```
4.000000
9.000000
```

## 解法

先读入所有事件，压缩更新公式发生变化的位置。加入 `1,n+1`；保存操作加入 `l,r+1`；分配操作加入 `i−d+1,i+1,i+d`。每个叶子表示相邻边界之间的所有整数区段，并保留这一段的真实长度。

线段树维护能量总和。每个节点有清零标记，以及一个待加的仿射函数；函数用首、末区段上的值表示。若两端值为 `a,b`，物理长度为 `L`，则总和增加 `(a+b)L/2`。相邻事件时刻为 `s,t` 时，在根节点加上常数 `p(t−s)`。

若左右孩子长度为 `A,B`，则下传后左孩子的末值为 `(aB+b(A−1))/(A+B−1)`，右孩子的首值为 `(a(B−1)+bA)/(A+B−1)`。公式只组合非负项；常数函数单独处理。清零标记必须先于加法下传。保存端点值能避免大坐标下斜率项与截距项相消。

保存操作收集完全覆盖节点的总和并将其清零。部分访问后，通过相加孩子总和重建父节点。分配操作拆为 `[i−d+1,i]` 上的递增等差数列，以及 `[i+1,i+d−1]` 上的递减等差数列。先用整数计算权重，再乘以 `仓库能量/d²`，最后清空仓库。

权重之和是 `1+…+d+(d−1)+…+1=d²`，因此恰好分配全部仓库能量。线段树的不变式是：节点总和已包含自己的懒标记，孩子在访问时收到该标记。统一增长、等差数列加法以及求和后清零均保持该不变式，因此每个输出都正确。

样例第一次保存收集两个能量为 2 的区段，得到 4。再增长一个单位时间并进行半径为二的分配后，能量为 `(4,5,4,1,1)`。再过一个单位时间，保存区段 3–5 得到 `5+2+2=9`。最后一次事件没有输出。

设压缩后有 `m=O(q)` 个区间，四种编译型语言的时间复杂度为 `O(q log q)`，空间复杂度为 `O(q)`。按先序存储恰需 `2m−1` 个节点：左孩子紧随父节点，右孩子跳过整个左子树。

### Python：将能量送往未来的保存操作

Python 文件 `1977_segment_tree_simulation.py` 将自然增长与分配得到的能量分开处理。坐标压缩只需加入 `1,n+1` 和保存边界 `l,r+1`。任意保存操作要么取走整个压缩单元，要么完全不碰它。分配范围可以只覆盖单元的一部分，此时对相交部分的等差数列求和即可，因为此后的保存操作无法区分单元内部的区段。

对于分配能量，倒序扫描事件，为每个区段标记下一次保存它的操作；若以后再也不保存，则标记为无接收目标。遇到保存操作，就用当前事件的标记覆盖其区间。这一步正确，因为对所有更早的事件而言，当前保存都早于该区间已经记录的接收目标。用可持久化线段树在版本之间共享未改变的路径；若整个节点区间的接收目标相同，就合并为一个标记。每次分配都记下所需的版本。

随后按时间顺序处理事件，维护实际的仓库余额。将分配拆为两个仿射部分，沿记录的版本传送能量。若接收目标唯一，直接把等差数列的和计入该保存；否则在完全覆盖的节点中累加两端值。某次保存使这条路径失效时，先用前述非负插值将暂存函数传给记录的孩子，再处理孩子。每份能量恰好到达首次保存它的操作；没有接收目标的能量可以丢弃。同一空间节点的连续版本可以共用数值缓冲区，因为旧版本会在新版本接收能量之前排空。

自然增长只需用区间映射维护相同的上次保存时间，初始为零。长为 `L`、上次在 `s` 时刻保存的部分，在 `t` 时刻贡献 `pL(t−s)`，随后将其时间改为 `t`。在保存的两个边界处分裂区间，并删除被覆盖的内部边界，便恰好计入上次保存以来的增长量。分层位集用于查找仍有效的边界；每次保存至多新增两个边界，每个被删除的边界都可将代价计入其插入操作。若没有实际转移非零仓库能量的分配，仅用这张映射即可完成计算。

建立可持久化路径之前，程序先尝试显式构造离线转移列表。倒序扫描区间映射，为分配范围中的每一部分找到首次接收它的保存操作，建立一条边，边权为这部分三角形整数权重之和。同一遍扫描还将相邻两次保存之间的自然增长，或从时刻零到首次保存的增长，计入对应保存。正序处理时，将每条边的权重乘以当前仓库余额除以 `d²` 的结果。因此，它与路径树把相同的能量送到相同的保存操作。这次尝试有工作量和存储上限；若区间过于零碎，就丢弃结果，改用通用路径方法。

较小的空间部分适合直接模拟。将整墙保存排除在分组之外，把其余相互重叠的操作区间合并为连通分量。若每个分量都只含少量压缩单元，就为每个单元维护分配能量总和与上次保存时间，并按顺序处理全部事件，共用一个仓库。分配时只需求出与单元相交部分的权重之和。保存不会切开单元，因此记录总和已经足够；两次整墙保存之间，各分量也没有空间上的相互影响。

另一条快速路径用于仅跨越少量压缩单元的保存。端点线段树只暂存加法，不维护子树总和。保存时下传标记，遍历并清空较短的区间，再根据访问到的单元的上次保存时间计算增长量，结果与求和后清零相同。整墙保存利用能量守恒，直接将仓库设为截至当前生成的全部能量 `npt`，并重置墙上的状态；在分量模拟中，这种重置可以推迟到再次访问该分量时执行。只有整墙重置的总开销也受限时，才采用窄范围保存路径。

设压缩后有 `m=O(q)` 个单元，通用方法的时间和空间复杂度均为 `O(q log q)`。每次保存至多产生 `O(log m)` 个路径节点，每次分配用 `O(log m)` 时间加入两个仿射区间，每个路径节点只传递一次暂存能量。数值缓冲区占用 `O(q)` 空间。显式转移的尝试上限，以及直接模拟对规模和工作量的检查，使各条路径在题目限制下都满足上述最坏情况界限。能量总和通过非负加法合并，仿射函数则用端点插值拆分，从而避免将两个接近的大能量值相减。

注意事项：

- 保存操作累加仓库能量，只有分配操作才将仓库清零。
- 先增长到事件时刻，再执行事件；时刻零合法。
- 半径一只影响中心，递减半边可能为空。
- 压缩后仍须使用物理长度，不能把每个叶子当成一个区段。
- 清空孩子后用相加重建父节点，避免相减大数时丢失小残量。
- 大坐标下直接使用全局浮点斜率和截距可能发生严重相消。
