# 1953. 由三边求最大面积椭圆

[Timus 1953](https://acm.timus.ru/problem.aspx?space=1&num=1953) · difficulty 2513 · geometry

Original problem from Ural FU contest. Kontur Cup. Petrozavodsk training camp. Winter 2013 | by Mikhail Rubinchik (idea by Pavel Ageev).

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定非退化三角形三边，求包含于其中且面积最大的椭圆。椭圆定义为
到两个焦点距离之和不超过 2R 的点集。输出两焦点间距离和大半轴 R。
要求的数值对唯一；圆的两个焦点重合。限制 1 秒，64 MB。

## 输入

三个由空白字符分隔的整数 a,b,c：1≤a≤b≤c≤1000，c<a+b。

## 输出

两个实数，先焦点距离再 R。每个数绝对或相对误差不超过 10⁻⁶。
程序输出小数点后 12 位。

## 评测方式

两个数都按 10⁻⁶ 的绝对或相对误差比较。

## 样例

```
1 1 1
```

```
0.000000 0.288675
```

## 解法

最优者是 Steiner 内接椭圆：中心为重心，在三边中点相切。面积证明
如下。将任意候选椭圆仿射变换为单位圆盘。包含单位圆盘的三角形面积
至少为 3√3：将各边平行内移至相切不会增大面积。外切三角形内切圆
半径为 1，面积等于半周长 cot(A/2)+cot(B/2)+cot(C/2)。cot 在
(0,π/2) 严格凸，三个半角之和 π/2，故其和至少为 3cot(π/6)=3√3，
仅正三角形取等号。所以椭圆面积与三角形面积之比至多 π/(3√3)。
正三角形内切圆的仿射像达到此界；重心与边中点在仿射变换下保持，
从而证明最优椭圆的描述和等号情形。

设顶点 p₁,p₂,p₃，重心 g。形状矩阵
Q=(1/6)Σ(pᵢ−g)(pᵢ−g)ᵀ，椭圆为 g+Q^(1/2)u，|u|≤1。正三角形
时 Q 正好是内切圆半径平方乘单位矩阵；仿射变换使两边都变为 TQTᵀ，
故任意三角形成立。特征值 λ₊≥λ₋>0 是半轴平方。记 S=a²+b²+c²，
三角形面积 Δ，则 trace Q=S/18，det Q=Δ²/27。因此
λ₊=(S+√D)/36，λ₊−λ₋=√D/18，其中 D=S²−48Δ²。

不实际计算面积，也不作接近浮点数相减。由海伦恒等式得到精确非负
整数 D=2[(a²−b²)²+(b²−c²)²+(c²−a²)²]。令 q=√D，答案为
sqrt(2q)/3 和 sqrt(S+q)/6。等边情形 D=0，自然给出零焦点距离，
无需误差阈值或特殊分支。

O(1) 时间和空间，只有整数运算及三个平方根。

按空白字符分隔读取三个整数，不要假设它们在同一行：测试 `case_02`
包含制表符和换行符。

R 是半轴；第一个数是两个焦点间的完整距离 2sqrt(λ₊−λ₋)。一般
三角形的内切圆并非最优。转成 double 前不能整数溢出，近圆时不能
用浮点计算 S²−48Δ²。很薄但合法的三角形仍有正面积和真正的椭圆。

## 各语言说明

C++、Go、Java、Rust 使用有符号 64 位整数求边平方和差的平方；
Python 整数任意精度。保守界 D<6·10¹²<2⁴³，整数不溢出且转为
binary64 完全精确，之后才用 double/f64 开平方。S+q 无抵消，
D=0 精确保留。12 位小数的打印误差至多 5·10⁻¹³。五版仅用标准库，
Java 明确指定 Locale.US。
