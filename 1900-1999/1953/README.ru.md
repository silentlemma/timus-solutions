# 1953. Эллипс максимальной площади по трём сторонам

[Timus 1953](https://acm.timus.ru/problem.aspx?space=1&num=1953) · difficulty 2513 · geometry

Original problem from Ural FU contest. Kontur Cup. Petrozavodsk training camp. Winter 2013 | by Mikhail Rubinchik (idea by Pavel Ageev).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

По длинам сторон невырожденного треугольника найдите содержащийся в нём
эллипс максимальной площади. Эллипс — множество точек с суммой расстояний
до двух фокусов не больше 2R. Нужны расстояние между фокусами и R, большая
полуось. Пара единственна; у окружности фокусы совпадают. 1 секунда, 64 МБ.

## Входные данные

Три целых a,b,c, разделённых пробельными символами: 1≤a≤b≤c≤1000, c<a+b.

## Выходные данные

Два вещественных числа: расстояние между фокусами, затем R. Допустимая
абсолютная или относительная погрешность каждого — 10⁻⁶. Печатаем 12
знаков после точки.

## Проверка

Оба числа сравниваются с абсолютной или относительной погрешностью 10⁻⁶.

## Примеры

```
1 1 1
```

```
0.000000 0.288675
```

## Решение

Оптимален вписанный эллипс Штейнера: центр в центроиде, касания в
серединах сторон. Докажем по площади. Аффинно превратим любой допустимый
эллипс в единичный круг. Содержащий круг треугольник имеет площадь не
меньше 3√3: сдвиг сторон внутрь параллельно до касания не увеличивает
площадь. У описанного треугольника радиус вписанной окружности 1,
площадь равна полупериметру cot(A/2)+cot(B/2)+cot(C/2). Котангенс строго
выпуклый на (0,π/2); полууглы суммируются в π/2, поэтому сумма не меньше
3cot(π/6)=3√3, равенство только в равностороннем случае. Отношение площади
эллипса к площади треугольника не больше π/(3√3). Аффинный образ круга,
вписанного в равносторонний треугольник, достигает границы. Центроид и
середины сторон сохраняются, что доказывает описание и случай равенства.

Для вершин p₁,p₂,p₃ и центроида g матрица формы эллипса равна
Q=(1/6)Σ(pᵢ−g)(pᵢ−g)ᵀ: эллипс имеет вид g+Q^(1/2)u, |u|≤1. Для
равностороннего треугольника Q равна квадрату радиуса вписанного круга,
умноженному на единичную матрицу. Аффинное преобразование меняет обе
части как Q→TQTᵀ, поэтому формула общая. Собственные значения λ₊≥λ₋>0 —
квадраты полуосей. Обозначим S=a²+b²+c², площадь треугольника Δ. Тогда
trace Q=S/18, det Q=Δ²/27, откуда λ₊=(S+√D)/36 и
λ₊−λ₋=√D/18, где D=S²−48Δ².

Не вычисляем площадь и не вычитаем близкие вещественные числа. Из
тождества Герона следует точное целое выражение
D=2[(a²−b²)²+(b²−c²)²+(c²−a²)²]. Для q=√D ответы:
sqrt(2q)/3 и sqrt(S+q)/6. В равностороннем случае D=0 и расстояние между
фокусами точно нулевое, без специального допуска.

O(1) времени и памяти: целые операции и три квадратных корня.

Читайте три целых числа как токены, разделённые пробельными символами,
не предполагая одну строку: тест `case_02` содержит табуляции и переводы строк.

R — полуось, первый ответ — ПОЛНОЕ расстояние между фокусами,
2sqrt(λ₊−λ₋). Обычная вписанная окружность оптимальна лишь при равных
сторонах. Нельзя переполнять целые до перевода в double или считать
S²−48Δ² вещественно возле окружности. Почти вырожденный допустимый
треугольник всё ещё имеет положительную площадь и настоящий эллипс.

## Особенности языков

В C++, Go, Java и Rust квадраты сторон и разностей считаются в знаковых
64 битах, Python использует неограниченные целые. Грубая граница
D<6·10¹²<2⁴³ обеспечивает отсутствие переполнения и точный перевод целого
в binary64. После этого берём корни в double/f64. В S+q нет вычитания,
D=0 сохраняется точно. Округление при печати 12 знаков даёт не больше
5·10⁻¹³. Только стандартные библиотеки; в Java указан Locale.US.
