# 1938. 三条直线上的等边三角形

[Timus 1938](https://acm.timus.ru/problem.aspx?space=1&num=1938) · difficulty 4554 · geometry

Original problem from Open Ural FU Championship 2012 | by Olga Soboleva.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在三条不同的无限直线上各选一点，使三个点组成等边三角形。
保证存在合适答案。限制：1秒、64MB。

## 输入

三行各给出四个整数x₁,y₁,x₂,y₂，表示一条直线上的两个不同点。
坐标在[−1000,1000]内，三条直线两两不同，可以平行或共点。
所选点不受输入线段范围限制。

## 输出

三行坐标对，第i点对应第i条输入直线。坐标绝对值不超过10⁸，
点到对应直线的距离不超过10⁻⁶，任意两点距离至少10⁻⁶，
三条边的最大与最小长度之差不超过10⁻⁶。所有容差都是绝对量，
任意满足条件的点均可。

## 评测方式

检查器按上述误差检验这三个条件；任何满足条件的三角形都被接受。

## 解法

把第二、三条直线写为Q+t·u、Z+s·v，在第一条上选A。令R为
正或负60°旋转，目标关系为P₃−A=R(P₂−A)。将第二条线绕A
旋转后，锚点T=A+R(Q−A)，方向D=Ru。与第三条相交，记
Δ=Z−T、det=cross(D,v)，有

t=cross(Δ,v)/det，s=cross(Δ,D)/det。

返回A、Q+t·u、Z+s·v。每点都显式位于对应直线上，关系
P₃−A=R(P₂−A)保证等边：60°旋转保持向量长度，向量与旋转
结果之间的弦也具有相同长度。

两个选择保证稳定性。首先选第一条线两个给定端点中
|cross(u,端点−Q)|较大的一个，用整数精确比较。二者不可能都
为零，否则第一、二条线重合。因此A不在第二条线上。非零整数
面积至少为1，故|P₂−A|≥1/|u|≥1/(2000√2)>10⁻⁶，不会退化。

其次计算两个旋转方向，取|cross(Ru,v)|较大的。设θ为u到v的
角度，归一化行列式为sin(θ−60°)、sin(θ+60°)，平均平方为
¼sin²θ+¾cos²θ=¼+½cos²θ≥¼。因此选中行列式绝对值至少
|u||v|/2，避免任何配置中的近乎平行相交。

坐标也有统一界。令M=1000，输入锚点范数至多√2M，所以
|T|≤3√2M、|Δ|≤4√2M。行列式界给出|t||u|≤2|Δ|及
|s||v|≤2|Δ|，两个新点范数至多9√2M<13000，远小于10⁸。
这些尺度及条件数也使双精度误差远低于绝对容差。输出十五位小数。

时间、空间均O(1)：输入固定三条直线，算术操作次数固定。

输入首端点可能是共同交点，直接使用会退化。只尝试一个旋转
方向可能得到极小分母和过大的坐标。输出顺序必须保持直线关联，
反转端点次序也必须有效。输入定义的是无限直线，而非线段。

## 各语言说明

选端点的面积在浮点转换前精确计算：C++的long long、Go的
int64、Java的long、Rust的i64及Python整数。旋转和相交参数
使用double/float64/f64。Java指定Locale.US。均输出三行，
每行两个坐标，末尾换行，无需数值搜索。
