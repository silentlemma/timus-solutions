# 1936. 三手势淘汰游戏的期望轮数

[Timus 1936](https://acm.timus.ru/problem.aspx?space=1&num=1936) · difficulty 1122 · probability, dp

Original problem from Open Ural FU Championship 2012 | by Denis Dublennykh (prepared by Oleg Dolgorukov).

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n名玩家每轮独立、等概率地选择三种手势之一。手势构成一个有向
环，每种恰好击败另一种。若恰好出现两种手势，仅获胜手势的
玩家留下；若只出现一种或三种都出现，则无人淘汰。剩一人时
结束，胜者奖励等于玩过的总轮数，包括无人淘汰的轮次。求指定
玩家获胜条件下的期望奖励。限制：1秒、64MB。

## 输入

一个整数n，2≤n≤100，表示初始玩家数。

## 输出

一个实数，表示胜者的期望奖励。绝对或相对误差至多10⁻⁶。

## 评测方式

答案按 10⁻⁶ 的绝对或相对误差比较。

## 样例

```
2
```

```
1.5
```

## 解法

获胜条件并不要求将答案除以n。对于任意总轮数r，重新标记
玩家保持概率不变，且能将任一胜者换成另一人。因此
P(T=r,胜者=i)=P(T=r)/n，而P(胜者=i)=1/n。给定某人获胜后，
轮数的分布与无条件分布相同，只需求总轮数的普通期望。

设m人时的期望为E_m，E_1=0。共有3^m个等概率手势分配。
若留下k人，1≤k<m，可以用C(m,k)种方式选出留下的集合，
再选三种可能的获胜手势之一，失败手势随即唯一确定，因此有
3C(m,k)种分配。淘汰至少一人的分配总数为3(2^m−2)，其余
都回到原状态。淘汰概率严格为正，所以等待人数减少的期望有限。

每轮都增加一。将原状态自环移到方程左边并约去公因子3，得到

E_m = (3^(m−1) + Σ_{k=1}^{m−1} C(m,k)·E_k) / (2^m−2)。

按顺序求E_2,...,E_n。更小状态均已知，第一步期望方程唯一
确定当前值，归纳即可证明DP正确。每行组合数从B_0=1开始，
用B_k=B_{k−1}(m−k+1)/k逐项产生；2和3的幂用乘法维护。

不能用浮点数计算1−P(无人淘汰)：n=96..100时，自环概率会
舍入成1。上述式子直接除以2^m−2，分子只加正数，避免相消。
所有组合数、幂和答案都在双精度范围内，尽管某些组合数超过
64位整数。最大期望约1.355203941481465·10¹⁷；输出十二位小数
足以满足允许绝对或相对误差的规则。

时间O(n²)，空间O(n)。一行组合数按需生成，不保存完整矩阵，
也不模拟每一轮。

无人淘汰的轮次也计入奖励。不能相减两个近乎相等的已舍入概率，
不能把所有组合数存入普通整数，也不能按某人的获胜概率缩放
期望。手势环的方向不改变三种获胜与失败手势对的数量。

## 各语言说明

五个版本的期望、幂和组合数均使用double/float64/f64，只有
索引是整数。C++设置定点精度，Go格式化输出，Java指定Locale.US，
Python使用f-string，Rust指定格式精度。均输出一个实数、十二位
小数和末尾换行。
