# 1936. Ожидаемая длительность игры с тремя жестами

[Timus 1936](https://acm.timus.ru/problem.aspx?space=1&num=1936) · difficulty 1122 · probability, dp

Original problem from Open Ural FU Championship 2012 | by Denis Dublennykh (prepared by Oleg Dolgorukov).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

n игроков в каждом раунде независимо и равновероятно выбирают один
из трёх жестов. Жесты образуют направленный цикл: каждый побеждает
один другой. Если встречаются ровно два разных жеста, остаются только
выбравшие победный. Если жест один или присутствуют все три, никто
не выбывает. Игра заканчивается при одном игроке. Награда победителя
равна числу всех сыгранных раундов, включая раунды без выбывания.
Найдите ожидаемую награду при условии победы заданного игрока.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

Одно целое n, 2≤n≤100 — начальное количество игроков.

## Выходные данные

Одно вещественное число — ожидаемая награда победителя.
Допускается абсолютная или относительная ошибка не больше 10⁻⁶.

## Проверка

Ответ сравнивается с абсолютной или относительной погрешностью 10⁻⁶.

## Примеры

```
2
```

```
1.5
```

## Решение

Условие победы не требует делить ответ на n. Для любой длительности r
перестановка имён сохраняет вероятности и переводит одного победителя
в любого другого. Поэтому P(T=r,победитель=i)=P(T=r)/n, а вероятность
победы i равна 1/n. Условное распределение длительности совпадает
с безусловным. Можно искать обычное ожидаемое число раундов.

Пусть E_m — это ожидание для m игроков, E_1=0. Все 3^m наборов жестов
равновероятны. Для k оставшихся, 1≤k<m, выберем их множество C(m,k)
способами и победный жест тремя способами. Проигрывающий жест после
этого определяется однозначно. Получаем 3C(m,k) наборов; суммарно
выбывание происходит в 3(2^m−2) наборах. Остальные возвращают в то же
состояние. Вероятность выбывания положительна, так что время
ожидания меньшего состояния конечно.

Любой раунд добавляет единицу. Перенесём повтор состояния в левую
часть уравнения первого шага и сократим общий множитель 3:

E_m = (3^(m−1) + Σ_{k=1}^{m−1} C(m,k)·E_k) / (2^m−2).

Вычисляем E_2,...,E_n по возрастанию. Все меньшие ожидания уже
известны, поэтому уравнение однозначно определяет очередное значение
и доказывает корректность DP. Биномиальную строку получаем из B_0=1
и B_k=B_{k−1}(m−k+1)/k, степени 2 и 3 поддерживаем умножением.

Нельзя считать знаменатель как 1−P(никто не выбыл) в double:
при n=96..100 вероятность повтора округляется до 1. Устойчивая
формула делит непосредственно на 2^m−2 и складывает положительные
величины. Коэффициенты, степени и ответ помещаются в double,
хотя некоторые коэффициенты превышают 64-битные целые. Наибольшее
ожидание примерно 1.355203941481465·10¹⁷. Двенадцати знаков после
точки достаточно при разрешённой абсолютной ИЛИ относительной ошибке.

Время O(n²), память O(n). Биномиальная строка строится на лету;
полной матрицы коэффициентов и симуляции отдельных раундов нет.

Раунды без выбывания тоже входят в награду. Нельзя вычитать почти
равные округлённые вероятности, хранить все биномиальные коэффициенты
в обычных целых или делить ожидание на вероятность победы игрока.
Направление цикла жестов не меняет число трёх пар победитель/проигравший.

## Особенности языков

Во всех пяти версиях ожидания, степени и коэффициенты вещественные:
double/float64/f64. Целыми остаются только индексы. C++ задаёт fixed
и точность, Go использует форматирование, Java указывает Locale.US,
Python — f-строку, Rust — точность форматирования. Везде одно число
с 12 знаками после точки и конечным переводом строки.
