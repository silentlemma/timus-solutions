# 1965. 划分为两条单调子序列

[Timus 1965](https://acm.timus.ru/problem.aspx?space=1&num=1965) · difficulty 1004 · dp

Original problem from Open Ural FU Personal Contest 2013 | by Sergey Pupyrev.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

将 1,…,n 的排列划分为两条非空严格单调子序列。每条子序列可独立选择
递增或递减，允许方向相同。组内保留输入相对顺序，每个值恰好使用一次。
输出任意合法划分，或报告无解。时间限制 1 秒，内存限制 64 MB。

## 输入

n，满足 3≤n≤100,000，随后 n 个互不相同的整数，范围为 1 到 n。

## 输出

有解时第一行给出两个组的大小，均在 1 到 n−1 之间，第二、三行分别
给出组内值，保持输入顺序。任意合法答案均接受。无解时输出 `Fail`。
单元素组在任意方向上都视为单调。

## 评测方式

检查器确认两组都非空、每个值恰好出现一次、保持输入顺序且各自严格单调；任何合法的划分都被接受。`Fail` 必须与保存的答案一致。

## 样例

```
8
8 7 1 6 4 3 5 2
```

```
3 5
1 4 5
8 7 6 3 2
```

```
6
3 5 1 2 6 4
```

```
3 3
3 5 6
1 2 4
```

```
6
3 5 2 1 6 4
```

```
Fail
```

## 解法

第一个样例的 1,4,5 递增，8,7,6,3,2 递减，两组均保持输入顺序并覆盖
全部值。第二个样例可使用两条递增序列 3,5,6 和 1,2,4。第三个样例
在全部方向组合下都无解，下面的动态规划会全部拒绝。

枚举四种方向对 (+,+)、(−,−)、(+,−)、(−,+)。固定一对后从左到右
处理。最近处理的值 v 属于某一组，称该组为当前拥有者，其末值必为 v。
因此状态只需记录拥有者，以及另一组的末值。

对每个拥有者，仅保留另一组的最佳末值：另一组递增时越小越好，递减
时越大越好。较好的末值允许所有较差末值所允许的未来追加，而拥有者
末值相同，所以较差状态不会提供独有机会。同时保存前一拥有者以恢复。

处理下一个值 x 有两种转移。若 x 能按指定方向接在 v 后，则加入原
拥有者组，另一末值不变。若 x 能接在另一组所存末值后，则加入另一组，
拥有者改变，新“另一组”末值变为 v。对同一新拥有者只留下最佳末值。
两种拥有者都不可达时，该方向组合无解。

第一个值可以属于任一组。空递增组以 0 作末值，空递减组以 n+1 作
末值，任何合法输入值都能接上。最终选择可达状态，沿前驱拥有者回溯，
然后按正向输入顺序恢复两组。

若恢复后有一组为空，则整个排列在另一组中单调。把另一组最后一个
元素移到空组即可：原组仍有 n−1≥2 个元素，单元素组适合任意方向。
所以允许中间空组不破坏支配关系，并能得到非空最终划分。

归纳可知，对每个固定方向对，状态保留了所有未来可行性：转移覆盖
新元素的两种归属，支配只删除更弱末值。若四种方向都失败，则确实无解。

时间 `O(n)`，空间 `O(n)`。四种方向，每个位置两个状态、常数次转移。
每次尝试用两个字节数组保存前驱；输入和输出分组也占线性空间。

两组可以同向。只给当前值贪心选一个组会丢失可能性，需要保留两个
拥有者。支配方向由“另一组”决定。必须保存获胜转移的前驱，不只保存
末值。输出值而非索引并保持输入顺序，在恢复后修复空组。不能把候选
划分逐 token 与某个样例划分比较。

## 各语言说明

Python 3.12 用 None 表示不可达，bytearray 保存前驱。C++/Go/Java/Rust
用 −1 表示不可达末值，因为合法末值和空组哨兵都非负。C++ 和 Go 使用
字节数组，Java 用 byte[][]，Rust 用 Vec<u8>。Java 使用缓冲整数输入
和 StringBuilder 输出。Rust 索引用 usize，有符号末值用 i32，无递归。
