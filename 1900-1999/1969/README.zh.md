# 1969. 重建往返电车时刻表

[Timus 1969](https://acm.timus.ru/problem.aspx?space=1&num=1969) · difficulty 2809 · constructive

原题出自 2013 年乌拉尔联邦大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

若干相同电车以恒速在端点 A、B 间行驶，到端点立即折返。每辆从 A
出发，完成同样的正整数 k 次完整往返后停在 A。观察点严格位于中间。
从 A 到观察点的时间 a、从观察点到 B 的时间 b 均为正整数秒，所有车相同。

首车在 D 出发。各车出发时刻不同、递增，且全部严格早于首车第一次
回到 A。所有行程在当天 23:59:59 或之前结束。给出 D 及按升序排列的
全部不同观察时刻，构造任意合法时刻表。限制：1 秒，64 MB。

## 输入

首行为 HH:MM:SS 格式的 D，之后每行一个相同格式的观察时刻，直到
文件结束，没有数量行。观察数 n 为偶数，2≤n≤5000；所有观察互异、
递增、不晚于 23:59:58，首个严格晚于 D。保证存在解。

## 输出

按出发顺序，每车输出一行全部端点访问时刻：从 A 出发，交替访问
B、A，最终回到 A。每行有 2k+1 个 HH:MM:SS 值。所有车的 k 及单程
时间 a+b 一致。任意合法时刻表均可接受。

## 评测方式

检查器模拟输出的时刻表，检验题目条件以及经过时刻的多重集是否完全一致；任何合法的时刻表都被接受。

## 解法

转为秒数。令 T 为递增观察序列，P=2(a+b) 为往返周期，τ=P/2 为单程。

### 枚举首车第一次返回时经过观察点的时刻

最早观察来自首车首次向 B 行驶，故 a=T[0]−D 已知。首车第一次返回
时经过观察点为 D+P−a。若其为 T[j]，则 P=T[j]−D+a。在此之前只能
出现各车第一次向外的经过：后发车不可能更早返回。因此 j≤R≤n/2，
R 为车数。枚举 j=1,…,n/2，必须包含最后一个下标。拒绝奇数 P 及
P≤2a，后者会使 b≤0。

### 直接确定往返次数

设最后出发时刻为 d，最后观察为 d+kP−a，且 D≤d<D+P。因此

k=floor((T[n−1]−D+a)/P)。

拒绝 k=0 或 n 不能被 2k 整除的候选，否则 R=n/(2k)。严格出发窗口
是这个取整公式成立的关键。

### 贪心还原各车

固定 P，从左到右扫描 T，跳过使用过的时刻。最早未使用的 t 必须是
某辆剩余车的第一次向外经过，因为该车其他经过更晚。其出发被唯一
确定为 t−a，且必须小于 D+P。它需要所有

t+rP 与 t+(P−2a)+rP，r=0,…,k−1。

检查每个时刻存在且未使用，再全部标记。缺失、冲突、不合法出发或
错误车数都使候选失败。全部观察恰分给 R 辆车时成功。用集合或数组
查询存在性，用代数标记区分候选，避免每次清空整天大小的数组。

### 正确性与复杂度

真实 P 一定在枚举范围，取整公式给出真实 k。删除若干完整车辆后，
最早剩余观察唯一决定下一辆真实车的出发，归纳得真实候选不会失败。
任何成功候选又把每个观察恰好分给一个模拟单程，并满足端点条件及
a,b>0。最后到达为 T[n−1]+a，依输入保证在当天。因此返回的解合法。

至多 n/2 个候选，各扫描或标记 O(n) 个观察。设 S=86400，时间
`O(n²+S)`，空间 `O(n+S)`；32 位有符号整数足够。

样例中 a=450 秒，P=2760，τ=1380，k=2，R=3。出发为 08:00:00、
08:37:19、08:44:02。每次加 τ 得每行五个端点时刻。交替采用观察
偏移 450 和 930 秒，精确重现十二次观察。

输入直到 EOF，没有数量行。同一输入可能对应不同周期及 k，不可
逐词比较答案。包含候选下标 n/2。最后出发必须严格小于 D+P。每次
候选逻辑重置标记，索引前先判断目标时间范围。不同车的端点时刻
可以相同，但观察时刻不能相同。

## 各语言说明

五版使用同一算法。Python 用集合保存存在性、列表保存代数标记；
C++、Go、Java 8、Rust 使用数组。Java 直接追加两位数，避免频繁
调用通用格式化。所有版本均保留每车一行。
