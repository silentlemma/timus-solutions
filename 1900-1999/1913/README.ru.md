# 1913. Два ретранслятора для трёх терминалов

[Timus 1913](https://acm.timus.ru/problem.aspx?space=1&num=1913) · difficulty 1863 · geometry

Автор оригинальной задачи — Алексей Самсонов (подготовка — Денис Мухаметьянов); NEERC 2012, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На плоскости находятся два источника энергии G₁,G₂ и приёмник C. Нужно
поставить два ретранслятора. Источник может передать энергию ретранслятору
на расстоянии не больше R; ретранслятор — другому ретранслятору или C
на таком же расстоянии. От каждого источника должен существовать путь
к C по разрешённым направленным передачам. Прямые связи источник–C
и источник–источник отсутствуют. Найдите любое размещение или установите
невозможность. Ретрансляторы могут совпадать с терминалами и друг с другом.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

Целое R, 1≤R≤10 000, затем три пары целых координат: C, G₁, G₂.
Все координаты в [−10 000,10 000]; три терминала попарно различны.

## Выходные данные

При невозможности выведите `Death`. Иначе выведите
`Now we have enough power` и две строки с координатами ретрансляторов.
Подходит любое правильное размещение; допустимая абсолютная или
относительная погрешность координат — 10⁻⁵.

## Проверка

Проверяющая программа проверяет фразу, четыре конечных числа
и достижимость C от каждого источника по разрешённым направленным связям.
Для округления длины ребра допускается абсолютная погрешность 10⁻⁷.
Ответ `Death` должен совпадать с ожидаемой разрешимостью.

## Решение

Сначала проверим независимые пути. Если |C−G₁|≤2R и |C−G₂|≤2R,
поставим ретрансляторы в середины отрезков C–G₁ и C–G₂. Связь между
ними не нужна: источники могут находиться по разные стороны от C.

Иначе в допустимой сети один ретранслятор находится рядом с C, второй
связан с первым. Либо оба источника достигают дальнего ретранслятора,
либо каждый достигает своего. Все три случая описываются одинаково:
выбрать терминал T из C,G₁,G₂ и найти узел H на расстоянии не больше R
от двух остальных терминалов и не больше 2R от T. Второй ретранслятор
ставится в середину H–T. При T=C узел H собирает оба источника;
при T=Gᵢ узел H касается C и второго источника.

Проверяем три пересечения замкнутых кругов радиусов R,R,2R, меняя
центр увеличенного круга. Достаточно проверить центры и точки пересечения
каждой пары окружностей. Если граница общего пересечения составлена
из разных окружностей, в месте смены дуг есть подходящая общая точка.
Если смены нет, пересечение — один вложенный круг, и подходит его центр.
Касания тоже включены.

### Точное решение о существовании

Пусть центры двух окружностей P,Q, радиусы a,b. Обозначим u=Q−P,
d=u·u>0, A=d+a²−b², F=4a²d−A². При F<0 пересечений нет.
Иначе точки имеют вид P+(Au±√F·rot90(u))/(2d),
где rot90(x,y)=(−y,x). Для третьего круга с центром S и радиусом c
введём w=P−S и T=d(c²−a²−w·w)−A(w·u).
Условие принадлежности — T≥B√F, где B=±w·rot90(u) с тем же знаком.

При B=0 или F=0 проверяем T≥0. При B>0 нужны T≥0 и T²≥B²F.
При B<0 достаточно T≥0 либо T²≤B²F. Знаки учитываются до возведения
в квадрат; все сравнения целочисленные, без допуска. В дробные координаты
переводится только уже подходящая точка. Печатаем 12 знаков после запятой,
второй ретранслятор получаем как середину отрезка до T.

### Корректность

Если оба ретранслятора достигают C, неравенства треугольника дают
два независимых ограничения 2R. Если C достигает только один, второй
обязан быть с ним связан. Когда оба источника используют дальний узел,
он попадает в пересечение при T=C. Когда источники используют разные
узлы, ближний к C узел попадает в пересечение при T, равном дальнему
источнику. Если оба используют ближний узел, уже выполнен первый случай.
Значит, любое допустимое размещение учтено. Обратно, середина делит
отрезок длины ≤2R на два разрешённых ребра, а H касается остальных
терминалов, поэтому построенный ответ верен. Полный набор кандидатов
и точные сравнения обосновывают также ответ `Death`.

Время и дополнительная память — `O(1)`: число терминалов, назначений
радиусов и точек-кандидатов постоянно.

В первом примере H=(2,0) собирает источники, а (1,0) передаёт энергию C.
Во втором разрешены совпадения с терминалами. В третьем источник дальше
3R от C, что превышает длину любого пути через два ретранслятора.

Не требуйте связи между независимыми узлами и не разрешайте прямую
связь источника с C. Совпадения допустимы. Нужны все три увеличенных
круга, внутренние и внешние касания, отрицательные B и T, а также
защита от переполнения при возведении в квадрат.

## Особенности языков

Квадрат расстояния не больше 8·10⁸. Оценка |T|≤1,76·10¹⁸ помещается
в знаковый 64-битный тип; T²≤3,0976·10³⁶ — консервативная верхняя граница.
C++ и Rust сравнивают квадраты в 128 битах; Go и Java используют большие
целые для этого сравнения; Python использует целые произвольной длины.
Double достаточно для вывода координат, но не для решения о существовании.
