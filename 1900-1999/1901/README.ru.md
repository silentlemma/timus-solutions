# 1901. Космический лифт

[Timus 1901](https://acm.timus.ru/problem.aspx?space=1&num=1901) · сложность 524 · greedy

Автор оригинальной задачи — Алексей Самсонов; чемпионат Урала 2012.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Выберите порядок n положительных весов. Двухместный лифт обрабатывает
очередь так: если сумма двух первых весов не больше s, они едут
вместе. Иначе первый едет один, а второй остаётся первым в очереди.
Последний вес едет один.

Максимизируйте число рейсов и постройте соответствующую очередь.
Каждый вес по отдельности допустим. Ограничения: 1 секунда и 64 МБ.

## Входные данные

Первая строка содержит n и s: 1 ≤ n ≤ 100 000; 1 ≤ s ≤ 10⁹.
Следующая строка содержит n весов vᵢ: 1 ≤ vᵢ ≤ s.

## Выходные данные

Выведите максимум рейсов, затем все n весов в порядке, дающем этот
максимум. Сохраните исходное мультимножество, включая повторения.
Подходит любая оптимальная очередь.

## Проверка

Чекер проверяет мультимножество, моделирует посадку и сравнивает
заявленное число рейсов с результатом моделирования и оптимумом.
Порядок может отличаться от примера.

## Примеры

### Пример 1

Ввод:

```
6 6
1 2 3 3 4 5
```

Вывод:

```
5
2 5 1 3 4 3
```

## Решение

Отсортируем веса и будем снимать их с двух концов. Если минимум плюс
максимум больше s, добавляем их в очередь в таком порядке и считаем
два рейса. Максимум несовместим и со следующим оставшимся минимумом,
поэтому оба действительно уедут по одному. Иначе добавляем два
наименьших как один рейс. Нечётный остаток даёт один рейс.

Докажем выбор двух наименьших обменом и верхнюю границу для первого
случая. Несовместимой назовём пару с суммой больше s. При q парных
рейсах общее число равно n − q.

Оптимальную очередь можно привести к каноническому виду: сначала
парно едут 2q наименьших весов, затем остальные образуют путь из
несовместимых соседей. Более того, все эти 2q весов попарно совместимы.
Отметим второго участника каждого парного рейса. Соседние неотмеченные
позиции несовместимы. Перенесём q наименьших весов в отмеченные места:
неотмеченные веса только увеличатся, сохраняя несовместимые цепочки.
Значит, наибольшие n − q весов покрываются не более чем q + 1 путями.

Любой сосед минимума в таком графе несовместим со всеми вершинами.
Удаление минимума сокращает покрытие из нескольких путей на один:
его универсальный сосед присоединяет другой путь, либо два таких
соседа вставляют другой путь вместо минимума. Если путь один, минимум
просто обходится. Удалив q наименьших неотмеченных весов, получаем
один путь на наибольших n − 2q весах, возможно пустой.

Любые 2r наименьших, r ≤ q, можно разбить на r совместимых пар:
возьмём r исходных пар и уменьшим их упорядоченные веса до глобально
наименьших. Если два наибольших среди первых 2q несовместимы, добавим
их перед хвостовым путём, а первые 2q − 2 разобьём на пары. Получим
лишь q − 1 парный рейс — противоречие. Поэтому малый префикс попарно
совместим, и канонический вид доказан.

Если минимум плюс максимум не больше s, минимум совместим со всеми.
При хотя бы двух весах очередь из одних одиночных рейсов невозможна,
поэтому q ≥ 1. Канонический оптимум начинается с двух наименьших
в одном рейсе. Удаление этого полного рейса оставляет оптимальную
подзадачу.

Если сумма крайних больше s, их префикс даёт два одиночных рейса.
Для обратной границы возьмём канонический оптимум. При q > 0 удалим
минимум из парного префикса и максимум из хвоста. Сохраним q − 1
малых пар, а освободившийся малый вес поставим между не более чем
двумя частями хвостового пути. На этих границах образуется не больше
одной пары: использованный с одной стороны вес не спаруется повторно.
В остатке не больше q пар, то есть потеряно не больше двух рейсов.

При q = 0 удаление крайних из несовместимого пути оставляет до трёх
частей. Сохранившиеся соседи минимума — универсальные концы, которыми
можно соединить части в один путь. Если удаляемые вершины соседние,
хватает одного универсального конца. Случаи края и пустого остатка
не требуют соединений. Остаток всё ещё едет по одному. Значит, оба
жадных выбора сохраняют оптимум.

Сортировка занимает `O(n log n)`, проход — `O(n)`. Вход и построенная
очередь требуют `O(n)` памяти.

В примере группы равны [2], [5, 1], [3], [4], [3]: всего пять рейсов.
Хотя бы один парный рейс неизбежен, поскольку вес 1 совместим со всеми.

Подводные камни:

- равенство s означает совместный рейс;
- после вывода несовместимых крайних оба должны уехать по одному;
- максимизируется, а не минимизируется число рейсов;
- повторяющиеся веса сохраняют свои количества.

Жадный алгоритм совпадает с перебором всех 2 601 556 очередей для 4998
малых мультимножеств и с отдельной ДП на 5003 случайных тестах.

## Особенности языков

Во всех версиях одна сортировка и буфер для построенной очереди.
Python рассчитан на CPython 3.12. Сумма двух максимальных весов
помещается в 32-битный знаковый тип, число рейсов не превышает n.
