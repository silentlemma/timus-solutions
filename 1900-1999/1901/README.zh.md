# 1901. 太空电梯

[Timus 1901](https://acm.timus.ru/problem.aspx?space=1&num=1901) · 难度 519 · greedy

原题作者 Alex Samsonov，出自 Ural Championship 2012。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

为 n 个正权值安排队列。双座电梯按以下规则处理：若队首两个权值之和
不超过 s，则一起出发；否则第一个单独出发，第二个仍在队首。最后剩余
一个时单独出发。

最大化出发次数并构造对应队列。每个权值单独都合法。
时间限制为 1 秒，内存限制为 64 MB。

## 输入

第一行给出 n、s，1 ≤ n ≤ 100 000，1 ≤ s ≤ 10⁹。
第二行给出 n 个权值 vᵢ，1 ≤ vᵢ ≤ s。

## 输出

输出最大次数，再输出产生该次数的 n 个权值队列。必须保留输入的
多重集合，包括重复值。任意最优队列均可。

## 评测方式

检查器验证多重集合、模拟上梯规则，并要求声明的次数同时等于模拟结果
和最优值。队列不必与样例相同。

## 样例

### 样例 1

输入：

```
6 6
1 2 3 3 4 5
```

输出：

```
5
2 5 1 3 4 3
```

## 解法

排序后使用双指针。若最小值加最大值大于 s，则依次输出二者，删除它们，
计两次。最大值与下一个剩余最小值也不兼容，所以二者确实各自出发。
否则输出两个最小值，计一次。最后剩余一个时再计一次。

下面证明两个最小值的交换选择及另一分支的最优上界。称和大于 s 的
两个权值不兼容。有 q 次双人出发时，总次数为 n − q。

最优队列可以写成规范形式：先将最小的 2q 个权值两两搭乘，其余权值
沿相邻均不兼容的路径排列。而且这 2q 个小值彼此都兼容。证明方法是
标记每次双人出发的第二个位置，相邻的未标记位置必不兼容。将最小的
q 个权值换到标记位置；未标记值只增大，所以已有不兼容链保持。
因此最大的 n − q 个权值可由至多 q + 1 条不兼容路径覆盖。

这类图中，最小值的任一邻点都与所有其他顶点不兼容。删除最小值时，
若有多条路径，其通用邻点可以接入另一整条路径，或者用两个通用邻点
把另一条路径替换到它的位置，使路径数减一。只有一条路径时直接绕过
最小值。这样删除 q 个最小未标记值，最大的 n − 2q 个值形成一条
路径，允许为空。

任意最小的 2r 个值，r ≤ q，都可组成 r 个兼容对：从原来的 r 对出发，
按大小用全局更小的值替换。如果最小 2q 个值中最大的两个不兼容，
把它们接在尾部路径前面，再将最小的 2q − 2 个值配对，就只需 q − 1
次双人出发，矛盾。因此小前缀彼此兼容，规范形式得证。

若最小值加最大值不超过 s，最小值与所有值兼容。至少有两个值时，不可能
全部单独出发，所以 q ≥ 1。规范最优队列以最小两个值同乘开始，删去
这次完整出发即留下最优子问题。

若两端之和大于 s，把它们放在前面可产生两次单人出发。反向上界来自
规范最优队列：q > 0 时，从配对前缀删除最小值，从尾部删除最大值。
保留 q − 1 个小值对，将空出的小值放在至多两条尾部路径之间。
两条边界至多形成一个新对，因为一旦该值与一侧配对就被消耗。
剩余队列至多有 q 个对，即次数最多损失两次。

q = 0 时，从不兼容路径删除两端极值，至多剩三段。最小值的存活邻点
是通用端点，可用来把这些段接成一条路径。若两个删除顶点相邻，
一个通用端点就够；原路径端点及空余情况直接处理。余下仍全部单独
出发。所以两个贪心分支都保留最优解。

排序耗时 `O(n log n)`，扫描为 `O(n)`。输入和结果队列使用 `O(n)` 空间。

样例的分组为 [2]、[5, 1]、[3]、[4]、[3]，共五次。因为权值 1 与
所有其他值兼容，所以至少一次双人出发不可避免。

注意事项：

- 和等于 s 时应共同出发；
- 输出两个不兼容极值后，两者都应单独离开；
- 目标是最大次数，而不是通常的最小次数；
- 重复权值必须保留原有数量。

贪心结果与对 4998 个小多重集的全部 2 601 556 种队列的搜索一致，也与单独编写的动态规划在 5003 个随机测试上一致。
