# 1911. 让移动屏障先通过的最小能量

[Timus 1911](https://acm.timus.ru/problem.aspx?space=1&num=1911) · difficulty 4162 · math

原题作者 Denis Dublennykh，比赛 NEERC 2012, Eastern subregional contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一辆长度为 l 的车以速度 v 沿主通道前进。厚度 L 的屏障以 V>v 从后追来，
初始屏障前沿距车尾 D。必须从给定绕行区间中选一个。车完全进入绕行段前
保持速度 v，完全进入后以恒定减速度 b≥a 运动；在该段把自然减速度 a
增加到 b 一次性花费 s(b−a)。屏障追到车尾时，可用每秒 k 能量的护盾
把它保持在车尾处；车完全进入绕行段后无需护盾。屏障必须整体通过出口后，
车头才能返回主通道。允许停车等待，随后步行。求最小总能量。
时间限制 1 秒，内存限制 64 MB。

## 输入

先给八个整数 v,l,V,L,D,a,k,s。前六个严格介于 0 与 100 000 之间，
v<V，0≤k,s≤10 000。再给 n，1≤n≤1000，以及 n 对 xᵢ,yᵢ，表示从
初始车头到各绕行段入口、出口的距离。满足 0<xᵢ、xᵢ+l<yᵢ、相邻段
yᵢ<xᵢ₊₁，且 yᵢ<100 000。长度单位米，速度米/秒，减速度米/秒²；
k 为每秒能量，s 为每增加一单位减速度所需的能量。

## 输出

最小能量，绝对误差或相对误差不超过 10⁻⁵。

## 评测方式

一个有限数值，使用 10⁻⁵ 的绝对/相对误差容限。

1 1 2 1 1 100 1 1234
1
100 102

## 解法

分别考虑每个绕行段 (x,y)。车完全进入的时间为 τ=(x+l)/v；没有护盾时，
屏障在 t_c=D/(V−v) 追到车尾。因此护盾费用必为 k·max(0,τ−t_c)。
完全进入后立即放开屏障最优：继续保持只会增加费用并延迟屏障通过。

进入时剩余间隔 g=max(D−(V−v)τ,0)，屏障前沿位于 x−g，后沿位于
x−g−L，所以完全通过出口还需 T=(y−x+L+g)/V。车头在完全进入阶段
剩余的行驶距离为 d=y−x−l>0。

减速度 b 下，停车前位移为 vt−bt²/2。在仍能运动到出口的情况下，增加 b
会把到达时间从 d/v 增至 2d/v。停车阈值 b_stop=v²/(2d)，停车后可以
额外等待。因此 T≤d/v 时不要求额外减速度；T≥2d/v 时取 b_stop；
中间区域所需减速度为 2(vT−d)/T²，由 d=vT−bT²/2 解出，且上述区间
保证到达时速度非负。自然减速度可能已经足够，故额外费用为
s·max(0,b_required−a)。

完全进入前的护盾时间不可避免；价格非负时，最小可行减速度费用最小。
对每个绕行段求两项费用之和再取最小即为全局最优，因为未选择的绕行段
不会改变主通道中的车速。

不要先用浮点数相减再乘价格。将 T 写成 N/(vV)，按整数计算两个费用：

```text
W = V-v
H = (x+l)W-Dv
N = v(y-x+L)+max(0,-H)
shield cost = k*max(0,H)/(vW)

if N >= 2dV:  Bnum = v²,                 Bden = 2d
elif N <= dV: Bnum = 0,                  Bden = 1
else:         Bnum = 2v²V(N-dV),          Bden = N²

extra = max(0, Bnum-a*Bden)
branch cost = shield cost + s*extra/Bden
```

所有阈值比较和 `extra` 中的减法均为精确整数；仅最后两个非负商转成浮点数。
因此精确零答案仍为零。N≤3·10¹⁰，减速度相关乘积小于 10²⁶，能量分子
小于 10³⁰，均适合有符号 128 位整数。分母始终为正。

时间复杂度 O(n)，输入区间占 O(n) 空间，额外状态 O(1)。示例中自然
减速已足以停车，只需支付 100 秒护盾费用。

## 各语言说明

C++、Rust 使用有符号 128 位。Go 1.14、Java 8 对有界项使用 64 位，
大乘积使用 math/big、BigInteger。Go 从精确 big.Rat 转换，Java 分别
转换正分子和正分母；Python 3.12 使用精确整数。最后的商在 C++ 中用
long double，其余用双精度，均输出十二位小数。需覆盖免费能力、精确到达/
停车阈值，以及非常接近的 v、V。

在 628 个测试上，答案与用 90 位精度逐步模拟运动、并用二分查找而非公式确定减速度的结果一致；其中 28 个专门围绕精确阈值和零价格构造。
