# 1911. Минимальная энергия для пропуска движущегося барьера

[Timus 1911](https://acm.timus.ru/problem.aspx?space=1&num=1911) · difficulty 4162 · math

Автор исходной задачи: Denis Dublennykh, NEERC 2012, Eastern subregional contest.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Тележка длины l едет по коридору со скоростью v. Сзади её догоняет барьер
толщины L со скоростью V>v; сначала между его передним краем и задним
краем тележки расстояние D. Нужно выбрать ровно один обходной участок.
До полного входа в него скорость тележки равна v, затем действует постоянное
замедление b≥a. Увеличение естественного a стоит s(b−a) за весь участок.
Когда барьер догнал тележку, щит может удерживать его вплотную к её заднему
краю за k единиц энергии в секунду. После полного ухода в обход щит не нужен.
Весь барьер должен пройти выход до возвращения переднего края тележки
в коридор. Разрешается остановиться, подождать и продолжить пешком.
Найдите минимальные затраты. Ограничения: 1 секунда, 64 МБ.

## Входные данные

Сначала восемь целых v,l,V,L,D,a,k,s. Первые шесть строго между 0 и 100 000,
v<V; 0≤k,s≤10 000. Затем n, 1≤n≤1000, и n пар xᵢ,yᵢ — расстояний до
начала и конца обхода от исходного переднего края тележки. Выполнено
0<xᵢ, xᵢ+l<yᵢ, yᵢ<xᵢ₊₁ для соседних обходов и yᵢ<100 000.
Длины измеряются в метрах, скорости в м/с, замедление в м/с²;
k — энергия в секунду, s — энергия на единицу дополнительного замедления.

## Выходные данные

Минимальная энергия с абсолютной или относительной погрешностью не более 10⁻⁵.

## Проверка

Одно конечное числовое значение, абсолютный/относительный допуск 10⁻⁵.

## Решение

Рассмотрим обход (x,y). Полный вход происходит в момент τ=(x+l)/v,
а без щита барьер догонит задний край в t_c=D/(V−v). Поэтому неизбежная
стоимость щита равна k·max(0,τ−t_c). После полного входа щит сразу убираем:
дальнейшее удержание лишь расходует энергию и мешает барьеру быстрее пройти.

Оставшийся зазор при входе g=max(D−(V−v)τ,0). Передний край барьера
находится в x−g, задний — в x−g−L. До полного прохода выхода ему нужно
T=(y−x+L+g)/V секунд. Переднему краю тележки внутри обхода осталось
проехать d=y−x−l>0.

При замедлении b путь до остановки описывается vt−bt²/2. Если тележка
достигает выхода на ходу, рост b увеличивает время от d/v до 2d/v.
Порог остановки b_stop=v²/(2d); остановка позволяет ждать сколько нужно.
Минимально требуемое замедление равно нулю при T≤d/v, b_stop при T≥2d/v,
и 2(vT−d)/T² между этими границами. Средняя формула следует из
d=vT−bT²/2; границы гарантируют неотрицательную скорость при прибытии.
Естественного замедления может хватать, поэтому доплата равна
s·max(0,b_required−a).

Время удержания до полного входа неизбежно, а минимальное достаточное
торможение оптимально при неотрицательной цене. Значит, берём минимум
суммарной стоимости по всем обходам. Пропущенные обходы не меняют скорость
по основному коридору.

Чтобы не вычитать близкие вещественные числа перед умножением на цены,
представим T=N/(vV) и обе стоимости точными рациональными выражениями:

```text
W = V-v
H = (x+l)W-Dv
N = v(y-x+L)+max(0,-H)
shield cost = k*max(0,H)/(vW)

if N >= 2dV:  Bnum = v²,                 Bden = 2d
elif N <= dV: Bnum = 0,                  Bden = 1
else:         Bnum = 2v²V(N-dV),          Bden = N²

extra = max(0, Bnum-a*Bden)
branch cost = shield cost + s*extra/Bden
```

Сравнения и разность в `extra` вычисляются целочисленно. В вещественный
вид переводятся только два последних неотрицательных отношения, поэтому
точный нулевой ответ не портится округлением. N≤3·10¹⁰, произведения
торможения меньше 10²⁶, числители энергии меньше 10³⁰; достаточно знаковых
128 бит. Все знаменатели положительны.

Время O(n), память O(n) для обходов и O(1) для дополнительного состояния.
В примере естественное торможение уже останавливает тележку; остаётся
оплатить только 100 секунд удержания.

## Особенности языков

C++ и Rust используют знаковые 128 бит. Go 1.14 и Java 8 используют
64-битные числа для ограниченных промежуточных значений и math/big либо
BigInteger для больших произведений. Go переводит точное отношение big.Rat,
Java — положительные числитель и знаменатель отдельно. Python 3.12 хранит
точные целые. Последние отношения вычисляются в long double у C++,
в double у остальных; выводится двенадцать цифр после точки.
Нужно учитывать нулевые цены, точные пороги и близкие скорости v,V.

Ответы совпадают с пошаговой симуляцией движения в 90-значной
арифметике, где торможение подбирается двоичным поиском, а не по
формуле, на 628 тестах; 28 из них построены вокруг точных порогов и
нулевых цен.
