# 1912. Совместный выход с сохранением соседства

[Timus 1912](https://acm.timus.ru/problem.aspx?space=1&num=1912) · difficulty 1267 · bfs

Автор исходной задачи: Stanislav Vasilyev, подготовка Denis Mukhametianov, NEERC 2012, Eastern subregional contest.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Два участника находятся в разных комнатах прямоугольной сетки. Их комнаты
соседствуют по стене или углу; это соседство нужно сохранять. За один ход
один участник проходит через тонкую ортогональную стену, увеличивая счётчик
переходов на единицу. Толстые стены непроходимы, одна комната не вмещает
обоих. Снаружи стен нет, перемещения бесплатны. Найдите минимальное число
проходов через тонкие стены, чтобы оба вышли, либо определите невозможность.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

Сначала n,m, 2≤n,m≤250. Далее ровно 2n+1 строк по 2m+1 символов.
При нумерации с нуля центры комнат находятся на нечётных строках и столбцах.
`1`,`2` — начальные комнаты, пробел — пустая комната, `+` — угол,
`.` — тонкая стена, `-`,`|` — толстые. Начальные комнаты различны и имеют
хотя бы общий угол. Пробелы схемы нужно сохранять. Соседство допускается
по диагонали, но переход между комнатами идёт только через общую стену.

## Выходные данные

Минимальное число переходов или `Death`, если оба выбраться не смогут.

## Проверка

Одно точное целое число либо точный токен `Death`; сравнение по токенам.

## Решение

Ищем путь в совместных положениях, а не два независимых пути. Даже если
каждый может выйти отдельно, первый шаг может нарушить соседство — это
происходит во втором примере.

Окружим сетку одним слоем внешних клеток. Проход тонкой стены, включая
границу, стоит один; движение между внешними соседними клетками бесплатно.
Пока один внутри, второй может занимать лишь внешние позиции рядом с его
граничной комнатой, поэтому одного слоя достаточно. Эти позиции образуют
связную по ортогональным шагам полоску или угловую букву L. Бесплатные
диагональные шаги снаружи заменяются такими же бесплатными ортогональными.
Совпадение внешних позиций также можно убрать бесплатным перестроением
перед последним выходом. Значит, конечная модель с разными позициями
сохраняет минимум. Нельзя стянуть всё внешнее пространство в одну вершину:
тогда второй пример ошибочно стал бы разрешимым.

Участники равноправны. Отсортируем линейные номера позиций a<b, забыв метки.
Относительный сдвиг один из (0,1),(1,−1),(1,0),(1,1). При ширине дополненной
сетки W состояние кодируется как `4·a+orientation`, а вторая позиция равна
a плюс 1,W−1,W или W+1. Перестановка имён — симметрия графа, поэтому
отождествление не теряет путей и не меняет их стоимости.

Для каждой ориентации заранее переберём восемь вариантов: какой участник
двигается и одно из четырёх направлений. Исключим совпадение и потерю
соседства, отсортируем новую пару и сохраним участника, бит стены,
изменение кода состояния и сдвиг его клетки. Останутся четыре относительных
хода. Во время поиска реальную проходимость и границы проверяет битовая
маска стен клетки.

Используем поиск 0-1 BFS: проход стены имеет вес один, шаг снаружи — нуль.
Нулевые рёбра добавляем в начало двусторонней очереди, единичные — в конец.
Вершину окончательно фиксируем при извлечении; ответ получаем при первом
извлечении положения, где оба снаружи. Недостаточно выхода одного и нельзя
останавливаться при простом обнаружении цели: нулевые рёбра меняют приоритет.

Каждый допустимый ход представлен, каждый переход графа физически допустим,
его вес совпадает с числом проходов стен. Внешний слой и отождествление
участников сохраняют оптимум, а 0-1 BFS находит его. Пустая очередь означает
невозможность выхода.

Состояний не больше 4(n+2)(m+2)≤254 016, из каждого проверяются четыре ребра.
Время и память O(nm). Достаточно знаковых 32-битных расстояний: оптимальный
путь не требует циклов с повтором состояния, вес ребра не больше единицы.

## Особенности языков

Во всех версиях расстояния и маски хранятся в компактных массивах, переходы
вычислены заранее, без сортировки и хеширования в основном цикле.
Python 3.12 использует `array` и байтовые массивы. Go 1.14 и Java 8 —
расширяемые кольцевые очереди целых без упакованных объектов узлов;
C++ и Rust 1.75 — стандартные двусторонние очереди. Схему читаем целыми
строками, удаляя только символы конца строки. Глубокой рекурсии нет.

Ответы совпадают с обычным алгоритмом Дейкстры по парам различимых
участников на всех 24 576 вариантах поля 2 × 2 и на 200 случайных малых
лабиринтах; поля 250 × 250 проверены по точным формулам.
