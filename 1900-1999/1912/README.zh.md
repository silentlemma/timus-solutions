# 1912. 保持相邻的共同逃离

[Timus 1912](https://acm.timus.ru/problem.aspx?space=1&num=1912) · difficulty 1267 · bfs

原题作者 Stanislav Vasilyev，准备 Denis Mukhametianov，比赛 NEERC 2012, Eastern subregional contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两名参与者位于矩形房间网格中的不同房间。两房间共边或共角，移动中必须
保持这种相邻关系。每次只能移动一人，穿过一面正交方向的薄墙，计数加一。
厚墙不可穿越，两人不能同时占据同一房间。矩形外没有墙，步行免费。
求两人都到外面的最少穿墙次数，或判断不可能。时间限制 1 秒，内存 64 MB。

## 输入

先给 n,m，2≤n,m≤250，再给恰好 2n+1 行，每行 2m+1 个字符。
下标从零开始时，房间中心位于奇数行、奇数列。`1`,`2` 是起始房间，
空格为空房间，`+` 是角点，`.` 是薄墙，`-`,`|` 是厚墙。起始房间不同，
至少共一个角。必须保留图中的空格。允许对角相邻，但房间之间的移动只能
穿过正交方向的共墙。

## 输出

最少穿墙次数；若两人不能都离开，输出 `Death`。

## 评测方式

精确整数或精确标记 `Death`，按标记比较。

## 解法

搜索两人的联合位置，不能分别求最短路。即使各自能独立出去，移动一人也
可能破坏相邻关系，第二个示例正是如此。

在网格外围补一圈外部格子。穿过包括边界在内的薄墙费用为一；外部相邻
格子间移动费用为零。只要一人仍在内部，外面的人就必须邻接该边界房间，
所以一圈足够。这些外部邻居形成正交连通的一条带或角落 L 形，免费对角
步行可替换成免费正交步行。最后一人出去前，也可免费调整外面人的位置，
避免外部位置重合。因此这个有限、位置不同的模型保持最优值。不能把整个
外部缩成一个大顶点，否则第二个示例会被错误判为可逃。

两人能力及目标相同，可将线性位置排序为 a<b，忽略名字。相对方向只有
(0,1),(1,−1),(1,0),(1,1)。补边后宽度为 W，将状态编码为
`4·a+orientation`，另一个位置是 a 加上 1,W−1,W,W+1 之一。交换名字是
图的对称变换，因此合并这类状态不会改变路径可行性或费用。

对每个方向预枚举两人、四种正交移动共八个候选，去除重合或不再相邻的
结果，对新位置排序，保存移动者、墙方向位、编码增量及移动位置增量。
恰有四种相对移动保留；运行时用墙位掩码检查实际通行和有限网格边界。

使用 0-1 BFS：穿墙边权一，外部步行边权零。零边放入双端队列头部，
单位边放入尾部。状态首次出队时确定距离，首次出队且两位置均在外部时
返回答案。不能只让一人出去，也不能在刚发现目标时返回，因为零边会影响
处理优先级。

每个合法行动都在图中，每条图边也都对应合法行动且费用正确。有限外圈及
身份合并保持最优值，0-1 BFS 给出最小费用；队列耗尽则不可能逃离。

状态最多 4(n+2)(m+2)≤254 016，每状态至多四个候选边，时间、空间均为
O(nm)。最短路径无需重复状态的环，每边费用至多一，故 32 位有符号距离足够。

## 各语言说明

所有版本使用紧凑距离和墙数组，并预计算转换，主循环不排序也不查哈希表。
Python 3.12 使用 `array` 及字节数组；Go 1.14、Java 8 使用可扩展整数
环形双端队列，避免装箱节点；C++、Rust 1.75 使用标准双端队列。
ASCII 图按整行读取，只删除行结束符，不使用随迷宫大小增长的递归。

在 2 × 2 房间的全部 24 576 种配置和 200 个随机小迷宫上，答案与对带标号参与者对运行普通 Dijkstra 的结果一致；250 × 250 的场地用精确公式检验。
