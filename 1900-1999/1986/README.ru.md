# 1986. Точное раскрытие рекурсивных смесей

[Timus 1986](https://acm.timus.ru/problem.aspx?space=1&num=1986) · сложность 1177 · matrix

Автор оригинальной задачи — Павел Климов; Открытый командный чемпионат УрФУ по программированию — 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждая именованная смесь задаётся целыми процентами других компонентов.
Компонент с собственным рецептом — смесь, остальные — базовые
ингредиенты. Выразите все рецепты через проценты всех базовых
ингредиентов, включая нулевые, в лексикографическом порядке. Разрешены
ссылки на себя и циклы. Гарантируется единственное раскрытие.

Рецептов не больше `n=10`, базовых ингредиентов — не больше `m=10`. Имя
состоит из 1–10 строчных латинских букв. Входные проценты целые от 1 до
100, сумма в каждом рецепте равна 100. Ограничения: 0,5 секунды и 64 МБ.

## Входные данные

Строки рецептов до конца файла, без начального количества. Формат
строки: `name : component percentage component percentage ...`. Рецепты
и компоненты каждого рецепта уже упорядочены лексикографически.

## Выходные данные

Для каждого рецепта строка `name : base percentage ...`. Имена рецептов
и всех глобальных базовых ингредиентов — в лексикографическом порядке.
Отсутствующие ингредиенты выводятся с нулём. Сумма процентов каждого
раскрытого рецепта равна 100.

## Проверка

Проверяющая программа точно решает уравнения и сравнивает каждый процент
с абсолютной или относительной погрешностью 10⁻³; также проверяются
имена, их порядок и суммы.

## Примеры

Ввод 1:

```
razduv : cucumber 30 razgon 50 tomato 20
razgon : bread 40 cucumber 20 razduv 40
```

Вывод 1:

```
razduv : bread 25.0 cucumber 50.0 tomato 25.0
razgon : bread 50.0 cucumber 40.0 tomato 10.0
```

Ввод 2:

```
razduv : cucumber 100
razgon : tomato 100
```

Вывод 2:

```
razduv : cucumber 100.0 tomato 0
razgon : cucumber 0 tomato 100.0
```

## Решение

Соберём и отсортируем все имена рецептов. Компоненты вне этого множества
являются базовыми; их объединение тоже отсортируем. Обозначим через
`P[i,j]` входной процент рецепта `j` в рецепте `i`, через `b[i]` —
непосредственный процент выбранного базового ингредиента. Его итоговая
доля `x[i]` лежит от нуля до единицы. Получаем `A x=b`, где `A=100I−P`.
Правая часть — входной процент, без дополнительного умножения на 100.

Единственность допустимого раскрытия обеспечивает невырожденность
системы. Вычислим `d=det(A)` и для каждого рецепта `i` и ингредиента
`dᵢ=det(A с заменой столбца i на b)`. По правилу Крамера `x[i]=dᵢ/d`. До
форматирования используем только целые числа. Так не теряется точность
даже при многократных возвратах к началу рецептов и крайне редком выходе
к базовым ингредиентам.

### Определители без дробей

Применим исключение Барейса к копии целочисленной матрицы. Предыдущий
опорный элемент изначально равен 1. На шаге `k` ищем ненулевой элемент в
столбце `k` не выше диагонали, переставляем соответствующую строку на
место и учитываем знак перестановки. Если опоры нет, определитель
нулевой: это допустимо для отсутствующего ингредиента. Для `i,j>k`
заменяем элемент на `(a[i,j]·pivot−a[i,k]·a[k,j])/previous`, затем
обнуляем исключённый столбец. Деление точное. Текущая опора становится
предыдущей. Последний диагональный элемент с учётом знака равен
определителю.

Почему достаточно знаковых 128 бит? Строка `[A | −b]` — взвешенная сумма
векторов `eᵢ−eⱼ` либо `eᵢ` с неотрицательными целыми весами, сумма
которых 100. После выбора строк и столбцов матрица таких векторов имеет
определитель 0 или ±1: раскладываем по столбцу с не более чем одним
ненулевым элементом; если такого столбца нет, в каждой строке и столбце
по два ненулевых элемента, а суммы строк нулевые. Мультлинейность даёт
границу `100ᵏ` для любого минора порядка `k`. Для замены столбца граница
сохраняется с точностью до знака столбца. Элементы Барейса — миноры. При
десяти строках максимальная разность до деления состоит из двух
произведений миноров девятого порядка: не больше `2·100¹⁸=2·10³⁶<2¹²⁷`.
Итоговые определители не больше `10²⁰`, переполнения используемых типов
нет.

### Вывод с точной суммой

Пусть `S=10⁶` единиц на процентный пункт. Для рецепта найдём
`u[b]=floor(100S·d_b/d)`. Доли неотрицательны и в сумме дают единицу,
поэтому сумма округлений вниз не больше `100S`. Недостающие единицы
добавим компоненту с максимальным числителем. Их меньше `m≤10`. Выводим
целые единицы с шестью знаками дробной части. Каждая строка в точности
даёт 100, а абсолютная ошибка каждого компонента меньше `10⁻⁵`
процентного пункта при допустимых `10⁻³`. Произведение при
форматировании не больше `10²⁸` и также помещается в 128 бит.

В первом примере подстановка второго уравнения в первое даёт для
`razduv` 25% bread, 50% cucumber и 25% tomato; обратная подстановка даёт
для `razgon` 50%, 40%, 10%. Во втором примере рецепты уже состоят из
базовых ингредиентов, но каждый вывод включает и другой глобальный
ингредиент с нулём.

Вычисляется не больше `nm+1` определителей по `O(n³)` целочисленных
операций. Время — `O((nm+1)n³)`, память под матрицы и числители —
`O(n²+nm)`. Величины целых чисел ограничены доказанными границами.

Подводные камни:

- Читайте до EOF; различать смеси и базовые ингредиенты можно лишь после
  сбора всех имён рецептов.
- Ссылки вперёд, на себя и циклы требуют системы уравнений, а не
  рекурсивной подстановки.
- Система `A=100I−P` вычисляет доли; в проценты переходим один раз при выводе.
- Нулевой определитель с заменённым столбцом означает нулевой компонент,
  а не ошибку входной системы.
- Учитывайте знаки перестановок строк и предыдущую опору Барейса;
  деление целочисленное и точное.
- Каждый вывод должен содержать все базовые ингредиенты, включая нулевые.

## Особенности языков

Python использует целые произвольной точности, Go — `math/big.Int`, Java
— `BigInteger`. В C++ используется знаковый `__int128_t`, в Rust —
`i128`; промежуточные значения покрыты доказанной границей. Все версии
форматируют целые микропроцентные единицы напрямую, без зависимости от
локали. При равенстве максимальных долей остаток округления может
достаться разным компонентам с той же границей ошибки.
