# 1986. 精确展开递归混合配方

[Timus 1986](https://acm.timus.ru/problem.aspx?space=1&num=1986) · 难度 1176 · matrix

原题作者 Pavel Klimov，出自 2013 年乌拉尔联邦大学公开团体锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

每种有名混合物由其他成分的整数百分比定义。有自己配方的成分是混合物，其余是基本原料。将每个配方展开为全部基本原料的百分比，包含零项，并按字典序输出。允许自引用和循环，保证展开结果唯一。

配方数 `n≤10`，基本原料数 `m≤10`。名称由 1–10 个小写拉丁字母组成。输入百分比均为 1 到 100 的整数，每个配方总和为 100。时间限制 0.5 秒，内存限制 64 MB。

## 输入

读取到 EOF，没有初始计数。每行格式为 `name : component percentage component percentage ...`。配方名称及各配方内部成分已按字典序排列。

## 输出

每个配方输出一行 `name : base percentage ...`。配方名和全部全局基本原料名均按字典序排列，缺少的原料显式输出零。每个展开配方总计 100%。

## 评测方式

检查器精确求解方程组，并按 10⁻³ 的绝对或相对误差比较每个百分比；同时检查名称、顺序以及总和。

## 样例

输入 1:

```
razduv : cucumber 30 razgon 50 tomato 20
razgon : bread 40 cucumber 20 razduv 40
```

输出 1:

```
razduv : bread 25.0 cucumber 50.0 tomato 25.0
razgon : bread 50.0 cucumber 40.0 tomato 10.0
```

输入 2:

```
razduv : cucumber 100
razgon : tomato 100
```

输出 2:

```
razduv : cucumber 100.0 tomato 0
razgon : cucumber 0 tomato 100.0
```

## 解法

先收集并排序全部配方名。不属于该集合的成分就是基本原料，再将它们排序。令 `P[i,j]` 为配方 `i` 中混合物 `j` 的输入百分比，`b[i]` 为某个基本原料的直接百分比，`x[i]` 为它最终所占的 0 到 1 之间的份额。方程为 `A x=b`，其中 `A=100I−P`。右侧就是输入百分比，不再乘以 100。

唯一合法展开保证系统非奇异。求 `d=det(A)`；对每个配方位置 `i` 和基本原料，将第 `i` 列替换为 `b` 得到 `dᵢ`。Cramer 法则给出 `x[i]=dᵢ/d`。直到输出都使用整数，因此即使配方反复返回起点、只有极小概率流向基本原料，也不会因浮点消元而丢失精度。

### 无分数行列式

对整数矩阵副本做 Bareiss 消元。前一主元初值为 1。在第 `k` 列从对角线向下找非零主元，换行并记录符号。若找不到，此行列式为零；对缺少的原料这是正常结果。对 `i,j>k` 更新为 `(a[i,j]·pivot−a[i,k]·a[k,j])/previous`，再将消去列置零。这些除法都是整除。当前主元成为前一主元，最后一个对角元素乘换行符号就是行列式。

128 位有符号整数为何足够？`[A | −b]` 的每行是 `eᵢ−eⱼ` 或 `eᵢ` 的非负整数加权和，权重和为 100。选取任意行列后，这些关联向量矩阵的行列式只可能是 0 或 ±1：若某列至多一个非零元素，递归展开；否则每行每列都恰有两个非零元素，行和为零。利用行列式的多重线性，任意 `k` 阶子式绝对值不超过 `100ᵏ`。替换列只涉及一列变号，界仍成立。Bareiss 保存的是子式，十行情况下最大除法前差值由两个九阶子式乘积组成，至多 `2·100¹⁸=2·10³⁶<2¹²⁷`；最终行列式至多 `10²⁰`，不会溢出。

### 总和严格为一百的输出

取每个百分点 `S=10⁶` 个整数单位，计算 `u[b]=floor(100S·d_b/d)`。精确份额非负且总和为一，因此向下取整的总和不超过 `100S`。将缺少的单位补到分子最大的成分上；缺少量小于 `m≤10`。按六位小数打印整数单位，每行严格合计 100。每项绝对误差小于 `10⁻⁵` 个百分点，优于要求的 `10⁻³`。格式化乘积至多 `10²⁸`，同样在 128 位内。

第一个样例将第二个方程代入第一个，得到 `razduv` 的 bread 25%、cucumber 50%、tomato 25%；代回得到 `razgon` 的 50%、40%、10%。第二个样例已全部是基本原料，但仍须输出另一种全局原料的零项。

至多计算 `nm+1` 个行列式，每个需 `O(n³)` 次整数运算，总时间 `O((nm+1)n³)`，矩阵及分子空间 `O(n²+nm)`。整数大小由上述界限制。

注意事项：

- 读取到 EOF，收集全部配方名之后才能区分混合物和基本原料。
- 前向引用、自引用和循环应使用方程，而非递归替换。
- `A=100I−P` 求的是份额，仅在输出时转成百分比。
- 替换列行列式为零表示该成分为零，不表示输入系统无效。
- 保存换行符号与前一 Bareiss 主元，并使用精确整数除法。
- 每个配方都必须输出全部基本原料，包括零项。

## 各语言说明

Python 使用任意精度整数，Go 使用 `math/big.Int`，Java 使用 `BigInteger`。C++ 使用有符号 `__int128_t`，Rust 使用 `i128`，中间值均由上述证明覆盖。所有版本直接格式化整数微百分比单位，不受区域设置影响。最大份额相同时，不同版本可以将舍入余量补给不同成分，误差界保持不变。
