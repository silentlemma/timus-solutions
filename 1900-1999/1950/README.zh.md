# 1950. 有限水渠贯穿的面积

[Timus 1950](https://acm.timus.ru/problem.aspx?space=1&num=1950) · difficulty 2087 · geometry

Original problem from Open Ural FU Personal Contest 2012 | by Andrey Demidov.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

初始三角形 A=(0,0)、B=(10,0)、C=(10,10)，有限水渠为线段 AF，
F=(x,y) 严格在内部。向斜边作高，把当前等腰直角三角形分成两个全等
三角形。不含 F 的一半成为最终地块，继续分含 F 的一半。若 F 在新高
上则停止，两个新三角形都成为最终地块；否则可以无限缩小。

一个最终地块可用，当且仅当其边界与 AF 恰有两个不同公共点。求所有
可用地块面积之和，必要时可忽略足够小的剩余部分。限制：1 秒、64 MB。

## 输入

十进制实数 x,y，小数部分至多三位，严格满足 0<y<x<10。

## 输出

一个总面积，绝对或相对误差不超过 10⁻³。

## 评测方式

答案按 10⁻³ 的绝对或相对误差比较。

## 样例

```
8.125 4.375
```

```
29.6875
```

## 解法

用直角顶点 R 及斜边端点 P,Q 表示当前三角形。初始 R=B、P=A、Q=C，
面积 50，高的落点 H=(P+Q)/2。所有边和高方向都是水平、竖直或斜率
±1，而 AF 斜率严格在 0 与 1 之间，故水渠不与边重合。舍弃子块的
内部没有 AF 端点，所以穿过其内部恰产生两个边界交点，单触顶点不够。

取法向量 n=(sign(H_y−R_y),−sign(H_x−R_x))，定义
v(T)=n·(T−R)、w(T)=x·T_y−y·T_x。舍弃的一半可用，当且仅当
w(R),w(H) 严格异号，且 v(A),v(F) 异号或 v(F)=0。前者令交点严格
位于高线段 RH 内，排除端点接触；后者令交点位于有限 AF 上并允许
端点 F。无限射线会错误地计入 F 后方地块。

满足时加当前面积的一半。若 v(F)=0 则停止：F 原在父块内部，故在
高的内部，一半含水渠进入部分，另一半只接触 F，恰有一半计入。
否则比较 v(F)、v(P) 符号，同号保留 (H,P,R)，异号保留 (H,R,Q)，
其中首顶点是新直角。面积减半后继续。

归纳证明：凸当前三角形与水渠的交集是以 F 结束的一段。它穿过舍弃
子块内部，当且仅当在高的内部相交，即上述两个符号条件。该步只将
舍弃的一半定为最终块，保留部分的贡献留给后续。精确停止规则处理
两个最终子块，所以每个可用地块恰计一次。

先去掉坐标开头可选的 `+`，再按小数点拆分，将小数部分补足三位，
得到准确的千分整数 fx,fy。测试 [50](tests/50.in) 的 `.002 +.001` 是一个陷阱：
若先拆分，整数部分会变成无法解析为整数的 `+`。
将几何坐标乘 S=2³⁰。初始
R=(10000S,0)、P=(0,0)、Q=(10000S,10000S)、F=(fxS,fyS)，最多切
30 次。取中点 d 次后顶点仍为 10000·2^(30−d) 的倍数，所以中点
及侧别全部用整数准确计算。w 使用原始 fx,fy，不用放大的 F。

坐标不超过 10737418240000，法向分量为 −1,0,1，射线侧别值绝对值
小于 2.15·10¹⁷，都可存入有符号 64 位整数。直接比较符号；相乘两个
侧别值或对放大坐标做普通叉积可能溢出。

部分面积是准确二进制分数。30 次后剩余面积至多
50/2³⁰≈4.657·10⁻⁸，覆盖所有遗漏贡献。输出十位小数至多再引入
5·10⁻¹¹ 误差。固定 30 步时间、空间均 O(1)；以精度 ε 为参数则
时间 O(log(1/ε))、空间 O(1)。

水渠是有限线段。触碰高的端点不贡献舍弃面积，但 F 在高上算边界端点。
新直角在 H。不要用浮点 epsilon 判断侧别、相乘侧别值，或声称截断
无限过程得到的是准确总和。

## 各语言说明

C++、Go、Java、Rust 的点坐标及乘积用有符号 64 位整数，Python 用整数。
仅面积累计和输出用浮点数。小数部分补足三位，避免输入二进制舍入。
尺度位移的左操作数必须为 64 位。
