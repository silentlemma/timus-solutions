# 1950. Площадь участков со сквозным каналом

[Timus 1950](https://acm.timus.ru/problem.aspx?space=1&num=1950) · difficulty 2085 · geometry

Original problem from Open Ural FU Personal Contest 2012 | by Andrey Demidov.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дан треугольник A=(0,0), B=(10,0), C=(10,10) и конечный отрезок канала AF,
где F=(x,y) строго внутри. Высотой к гипотенузе делим треугольник на два
равных прямоугольных равнобедренных. Половину без F оставляем итоговым
участком, половину с F делим дальше. Если F попала на новую высоту,
останавливаемся, обе новые половины становятся итоговыми. Иначе размеры
могут неограниченно уменьшаться.

Участок пригоден, если его граница имеет ровно две различные общие точки
с AF. Найти сумму площадей пригодных итоговых участков, при необходимости
пренебрегая достаточно малым остатком. Ограничения: 1 секунда, 64 МБ.

## Входные данные

Десятичные вещественные x,y, не более трёх знаков после точки, 0<y<x<10.
Неравенства строгие.

## Выходные данные

Суммарная площадь с абсолютной или относительной ошибкой не больше 10⁻³.

## Проверка

Ответ сравнивается с абсолютной или относительной погрешностью 10⁻³.

## Примеры

```
8.125 4.375
```

```
29.6875
```

## Решение

Пусть R — прямой угол текущего треугольника, P,Q — концы гипотенузы.
Изначально R=B, P=A, Q=C, площадь 50. Основание высоты H=(P+Q)/2.
Все стороны и разрезы горизонтальны, вертикальны либо имеют наклон ±1,
тогда как наклон AF строго между 0 и 1. Поэтому канал не лежит вдоль
стороны. Внутри отбрасываемой половины нет концов AF, и прохождение через
её внутренность даёт ровно две граничные точки. Одного касания вершины мало.

Возьмём нормаль n=(sign(H_y−R_y),−sign(H_x−R_x)) и обозначим
v(T)=n·(T−R), w(T)=x·T_y−y·T_x. Отбрасываемая половина пригодна тогда
и только тогда, когда w(R),w(H) строго разных знаков, а v(A),v(F) разных
знаков либо v(F)=0. Первая проверка помещает пересечение внутрь отрезка
разреза RH, исключая концы. Вторая ограничивает канал конечным AF, включая
F; бесконечный луч ошибочно учитывал бы участки за F.

Если проверки успешны, добавим половину площади. При v(F)=0 завершаем:
F была внутри родителя, значит внутри разреза; одна половина содержит
входящую часть канала, другая только касается F, поэтому учитывается
ровно одна. Иначе сравним знаки v(F) и v(P): при равенстве сохраняем
треугольник (H,P,R), при различии (H,R,Q), первая вершина — новый прямой
угол. Площадь уменьшаем вдвое и повторяем.

Корректность по индукции: пересечение выпуклого текущего треугольника
с каналом — конечная часть AF до F. Канал проходит внутри отбрасываемой
половины ровно при внутреннем пересечении разреза, что выражено двумя
знаковыми проверками. На шаге итоговой становится лишь эта половина,
вклад сохранённой разбирается позже. Правило точной остановки учитывает
обе итоговые половины, так что каждый пригодный участок посчитан один раз.

Читаем целые тысячные fx,fy и умножаем геометрические координаты на S=2³⁰.
Начальные R=(10000S,0), P=(0,0), Q=(10000S,10000S), F=(fxS,fyS).
Не более 30 разрезов. После d взятий середины вершины кратны
10000·2^(30−d), поэтому середины и стороны вычисляются точно целыми.
Для w используем сырые fx,fy, а не масштабированную F.

Координаты не больше 10737418240000, компоненты нормали −1,0,1, значения
стороны луча по модулю меньше 2.15·10¹⁷: всё помещается в знаковые 64 бита.
Сравниваем знаки без произведения. Умножение двух значений стороны или
обычное векторное произведение масштабированных точек может переполниться.

Частичные площади — точные двоичные дроби. После 30 разрезов остаток
не больше 50/2³⁰≈4.657·10⁻⁸, что ограничивает весь пропущенный вклад.
Десять знаков вывода добавляют не больше 5·10⁻¹¹ ошибки. Для 30 шагов
время и память O(1); при заданной точности ε время O(log(1/ε)), память O(1).

Канал конечен. Касание конца разреза не даёт пригодной отбрасываемой площади,
но F на разрезе является граничным концом канала. Новый прямой угол в H.
Не нужны эпсилон для сторон, произведение знаковых величин и утверждение,
будто частичная сумма бесконечного процесса абсолютно точна.

## Особенности языков

C++, Go, Java и Rust хранят точки и произведения в знаковых 64-битных
числах; Python использует целые. Вещественные только площади и вывод.
Десятичную дробную часть дополняем до трёх цифр без двоичного округления.
Левый операнд сдвига масштаба должен быть 64-битным.
