# 1906. Восстановление модульной рекуррентности

[Timus 1906](https://acm.timus.ru/problem.aspx?space=1&num=1906) · difficulty 6534 · number_theory

Автор исходной задачи: Denis Dublennykh, Ural Championship 2012.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны n наблюдений a₀,…,aₙ₋₁. Найдите самый длинный начальный отрезок,
получаемый умножением на одно целое k по одному положительному модулю P:
aᵢ₊₁=k·aᵢ mod P. Каждое оставленное значение должно быть остатком, то есть
aᵢ<P. Ограничения: 1 секунда, 64 МБ.

## Входные данные

Сначала n, 1≤n≤10 000, затем n целых чисел 0≤aᵢ≤10⁹.
Расположение пробелов и переводов строк несущественно.

## Выходные данные

Выведите L, P, k: максимальную длину префикса и любые подходящие параметры.
Требуется 1≤P≤2·10¹⁸ и 0≤k≤2·10¹⁸. Условие k<P не обязательно.

## Проверка

Конструктивный проверяющий сравнивает L с сохранённым оптимумом, проверяет
границы параметров, aᵢ<P и все переходы точной целочисленной арифметикой.
Любая корректная пара P,k допустима, даже если k не является остатком.

## Примеры

```
5
1 2 4 8 0
```

```
5 16 2
```

```
3
4 2 1
```

```
3 5 3
```

## Решение

Каждая соседняя пара задаёт сравнение aᵢ·k≡aᵢ₊₁ (mod P). Поддерживаем
равносильную систему P|G и d·k≡e (mod P), где d>0. Значение G=0
не ограничивает модуль. Начальное состояние: d=a₀,e=a₁,G=0.

Добавляя строку (a,b), найдём g=gcd(d,a) и коэффициенты xd+ya=g.
Заменим две строки на (g,xe+yb) и (0,(d/g)b−(a/g)e).
Матрица преобразования целочисленная с определителем один, поэтому
обратима по любому модулю. Обновим G через НОД с последним выражением,
d заменим на g, e — на xe+yb; при G>0 приведём e по модулю G.
Если d делит a, достаточно x=1,y=0. Строка (0,0) ничего не меняет,
а (0,b), b>0, невозможна из-за обязательного P>b.

При G>0 подходят делители P числа G, для которых gcd(d,P)|e.
Нужен наибольший такой делитель. Если gcd(d,G)|e, это само G.
Иначе положим U=gcd(G,e), Q=G/U, D=d/gcd(d,e). Пока gcd(Q,D)>1,
делим Q на этот НОД. Искомый модуль равен UQ; факторизация не нужна.

Доказательство рассмотрим для каждого простого p. Если его степень
в e не меньше степени в d, разрешена вся степень из G; в D такого p нет.
Иначе в P разрешено не больше множителей p, чем в e. U уже сохраняет
ровно разрешённую часть, а цикл удаляет из Q все лишние множители.
Поэтому UQ допустим и делится на любой другой допустимый модуль.

Префикс возможен тогда и только тогда, когда наибольший допустимый
модуль больше максимума наблюдений. При G=0 подойдёт P=d·10⁹+1:
он больше всех aᵢ и взаимно прост с d. Принимаем строки последовательно;
при первом нарушении возвращаем предыдущее состояние. Более длинный
префикс включал бы уже невозможный, поэтому найденная длина оптимальна.

Для восстановления k возьмём h=gcd(d,P), q=P/h. При q=1 положим k=0,
иначе k=(e/h)·inverse(d/h mod q) mod q. Полученное сравнение решает
всю исходную систему. Если a₀=0, ответом служит начальная серия нулей,
P=1,k=0. Для единственного положительного числа: P=a₀+1,k=0.

Пока G=0, строки пропорциональны и 0≤e≤10⁹. Первый ненулевой G≤10¹⁸,
а затем он только уменьшается. Поэтому P≤10¹⁸+1 и k<P удовлетворяют
ограничениям. Например, для 12,2,9 получаем G=52,d=2,e=9;
удаление лишних степеней даёт P=13,k=11.

Достаточно одного прохода. Консервативная оценка числа арифметических
операций Евклида — O(n log² B), B=2·10¹⁸. Память O(n) для входа
и O(1) для состояния. Факторизация и двоичный поиск по длине не нужны.

## Особенности языков

Сохранённые значения помещаются в знаковые 64 бита, но промежуточные
определители достигают порядка 10²⁷, а произведение при восстановлении
k — 10³⁶. C++ и Rust используют знаковые 128 бит; Go — math/big,
Java 8 — BigInteger, Python 3.12 — точные целые. Отрицательный остаток
нужно нормализовать. Нельзя предполагать простой модуль или рост значений.

Ответы совпадают с полным перебором малых модулей и с перебором
делителей первых миноров 2 × 2 на 6441 тесте; ещё 10 000 тестов
проверяют отдельно шаг с делителями. Проверяющая программа принимает
четыре верных ответа и отклоняет 15 неверных.
