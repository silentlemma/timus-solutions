# 1906. 恢复模乘递推

[Timus 1906](https://acm.timus.ru/problem.aspx?space=1&num=1906) · difficulty 6534 · number_theory

原题作者 Denis Dublennykh，比赛 Ural Championship 2012。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 n 个观测值 a₀,…,aₙ₋₁，求最长前缀，使它能由同一个整数乘数 k
和同一个正整数模数 P 生成：aᵢ₊₁=k·aᵢ mod P。所有保留的值都必须是
合法余数，即 aᵢ<P。时间限制 1 秒，内存限制 64 MB。

## 输入

先给出 n，1≤n≤10 000，再给出 n 个整数，0≤aᵢ≤10⁹。
空格和换行均作为分隔符。

## 输出

输出 L、P、k：最大前缀长度，以及任意一组满足要求的参数。
要求 1≤P≤2·10¹⁸、0≤k≤2·10¹⁸；不要求 k<P。

## 评测方式

构造题校验器比较 L 与保存的最优值，并用精确整数检查参数范围、aᵢ<P
以及每一步递推。不同的正确参数均被接受，k 也可以不是标准余数。

## 样例

```
5
1 2 4 8 0
```

```
5 16 2
```

```
3
4 2 1
```

```
3 5 3
```

## 解法

相邻观测值产生同余式 aᵢ·k≡aᵢ₊₁ (mod P)。维护与所有已接收同余式
等价的系统：P|G，以及 d·k≡e (mod P)，其中 d>0。G=0 表示没有模数
整除约束。初始 d=a₀,e=a₁,G=0。

加入行 (a,b) 时，求 g=gcd(d,a)，并用扩展欧几里得求 xd+ya=g。
将两行替换为 (g,xe+yb) 和 (0,(d/g)b−(a/g)e)。变换矩阵为整数矩阵，
行列式为一，因此在任意模数下可逆。用第二行的值更新 G 的最大公约数，
令 d=g、e=xe+yb；若 G>0，则将 e 对 G 取模。若 d|a，可直接用 x=1,y=0。
行 (0,0) 无影响；若遇到 (0,b) 且 b>0，由于 P>b，它不可能成立。

当 G>0 时，合法 P 必须是 G 的因子，且 gcd(d,P)|e。若 gcd(d,G)|e，
最大模数就是 G。否则令 U=gcd(G,e)、Q=G/U、D=d/gcd(d,e)，反复执行
Q←Q/gcd(Q,D)，直到最大公约数为一。最大合法模数为 UQ，无需质因数分解。

按质数 p 的指数证明：若 e 中的指数至少等于 d 中的指数，G 中的所有
p 因子都可保留，并且 D 不含 p；否则 P 中的指数不能超过 e 中的指数。
U 已保留全部允许部分，而循环从 Q 删除所有多余部分。因此 UQ 合法，
其他任何合法模数都是它的因子。

前缀可行当且仅当最大合法模数大于所有已观察值。G=0 时，取
P=d·10⁹+1；它足够大且与 d 互质。逐行加入，一旦不可行便返回上一状态。
任何更长前缀都包含失败的前缀，所以得到的 L 最大。

确定 P 后，令 h=gcd(d,P)、q=P/h。若 q=1，取 k=0；否则取
k=(e/h)·inverse(d/h mod q) mod q。这满足主元同余式，也满足全部原始行。
若 a₀=0，最长前缀就是开头连续的零，取 P=1,k=0。单个正数可取 P=a₀+1,k=0。

G=0 时各行成比例，故 0≤e≤10⁹。第一个非零 G 不超过 10¹⁸，以后只会
通过最大公约数缩小。因此 P≤10¹⁸+1、k<P，符合输出限制。例如序列
12,2,9 得到 G=52,d=2,e=9，移除多余质因子后可取 P=13,k=11。

只需一次扫描。保守的欧几里得算术操作复杂度为 O(n log² B)，B=2·10¹⁸。
存储输入需要 O(n) 空间，额外状态 O(1)。不需要分解整数，也不需要二分前缀长度。

## 各语言说明

保存的数值适合有符号 64 位，但中间行列式可达约 10²⁷，构造 k 时的
乘积可达约 10³⁶。C++ 与 Rust 使用有符号 128 位，Go 使用 math/big，
Java 8 使用 BigInteger，Python 3.12 使用精确整数。必须规范化负余数。
模数可以是合数，观测序列也可能递减。

在 6441 个测试上，答案与对小模数的穷举以及对前几个 2 × 2 子式的因子枚举一致；另有 10 000 个测试单独检验求因子的步骤。检查器接受四个正确输出并拒绝 15 个错误输出。
