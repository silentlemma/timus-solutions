# 1948. Первое невозможное возвращение

[Timus 1948](https://acm.timus.ru/problem.aspx?space=1&num=1948) · difficulty 1216 · math

Original problem from Open Ural FU Personal Contest 2012 | by Andrey Demidov.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Выбирается вещественное x. За секунду i+1, i=0,1,…, перемещение по прямой
равно a(x+i)²+b(x+i)+c с учётом знака. Найти наименьшее положительное
целое k, для которого никакое x не даёт нулевую сумму первых k перемещений.
Для каждого k можно выбирать своё x; более раннее возвращение не запрещено.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

t, 1≤t≤1000, затем t целочисленных троек a,b,c.
0<a<10⁹, |b|,|c|<10⁹; ограничения по модулю строгие.

## Выходные данные

Для каждой тройки вывести k. Условие требует `Infinity`, если такого k
нет или оно больше 10¹⁸. При данных ограничениях этот случай невозможен,
что доказано ниже; все ответы целые.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
2
1 -2 1
1 1 -6
```

```
2
9
```

## Решение

Сумма перемещений — квадратный трёхчлен по x со старшим коэффициентом ak>0.
Выделим квадрат, используя среднее индексов 0,…,k−1:

Σ_{i=0}^{k−1} f(x+i)
= ak·(x+(k−1)/2+b/(2a))²
+ k·(a(k²−1)/12+c−b²/(4a)).

Вещественный корень существует тогда и только тогда, когда минимум
неположителен. Поэтому возвращение возможно ровно при

k² ≤ 1 + 3b²/a² − 12c/a.

Правая часть постоянна. Вместо вещественного корня и огромных произведений
используем вложенные целые округления вниз:

s = floor(3b²/a) − 12c.

Если s<0, ответ 1: вещественное 3b²/a−12c лежит в [s,s+1), значит
отрицательно, и даже k=1 не подходит. Иначе s≥0, положим

T = 1 + floor(s/a).

При целом m и положительном целом a верно
floor((z−m)/a)=floor((floor(z)−m)/a). Применяя это к z=3b²/a и m=12c,
получаем T=floor(1+3b²/a²−12c/a). Для целого квадрата исходное
неравенство равносильно k²≤T. Ответ floor(sqrt(T))+1, в том числе
при точном квадрате T.

Python берёт точный целый корень. Остальные версии двоичным поиском
на [1,2000000000] находят первое k с k²>T. Предикат монотонен,
правый конец всегда подходит, поэтому поиск даёт первое невозможное
время. Вывод из точного минимума и равносильные округления доказывают алгоритм.

O(t log U) времени, U=2000000000: не более 31 итерации на тройку.
Арифметическому ядру нужно O(1) памяти, хранению входа или буфера ответов
O(t). Точный целый корень Python также укладывается в эту верхнюю оценку.

x вещественное, не целое. Неудача требует строгого k²>T: при равенстве
есть кратный корень. Знак b исчезает после возведения в квадрат.
При s<0 ответ 1. Нельзя умножать 32-битные числа или требовать одно x
сразу для всех времён вместо отдельного выбора для каждого k.

## Особенности языков

В нативных языках все коэффициенты, произведения и границы — знаковые
64-битные. 3b²≤2999999994000000003, s≤3000000005999999991,
T≤3000000005999999992. Квадрат границы не больше 4000000000000000000,
что меньше 2⁶³−1. До второго деления проверяем s<0, поэтому усечение
совпадает с floor; первое делимое неотрицательно. Не вычислять a²k²
и не использовать вещественный квадратный корень. В Python целые и isqrt точны.

Из a≥1 правая граница для k² не больше
1+3·999999999²+12·999999999=3000000005999999992<2000000000².
Значит, k≤2000000000<10¹⁸ существует всегда и ветка `Infinity` не нужна.
