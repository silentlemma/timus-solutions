# 1948. 首次无法返回的时刻

[Timus 1948](https://acm.timus.ru/problem.aspx?space=1&num=1948) · difficulty 1217 · math

Original problem from Open Ural FU Personal Contest 2012 | by Andrey Demidov.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

选择实数 x。第 i+1 秒（i=0,1,…）沿直线的有符号位移为
a(x+i)²+b(x+i)+c。求最小正整数 k，使任何实数 x 都不能令前 k 秒
位移总和为零。不同 k 可以选择不同 x，也不要求此前没有返回。
限制：1 秒、64 MB。

## 输入

首先 t，1≤t≤1000；随后 t 组整数 a,b,c。
0<a<10⁹，|b|,|c|<10⁹，绝对值上界为严格不等式。

## 输出

每组输出一个 k。若不存在或答案超过 10¹⁸，题目规定输出 `Infinity`。
下文证明在给定范围内这种情况不可能发生，所以实际均输出整数。

## 评测方式

按记号逐个比较输出。

## 样例

```
2
1 -2 1
1 1 -6
```

```
2
9
```

## 解法

总位移是关于 x 的二次多项式，最高项系数 ak>0。利用 0,…,k−1 的
平均值配方：

Σ_{i=0}^{k−1} f(x+i)
= ak·(x+(k−1)/2+b/(2a))²
+ k·(a(k²−1)/12+c−b²/(4a)).

有实根当且仅当最小值非正。因此能返回的充要条件为

k² ≤ 1 + 3b²/a² − 12c/a.

右侧固定。为避免浮点数在完全平方边界的误差及过大的乘积，计算

s = floor(3b²/a) − 12c.

若 s<0，则实数 3b²/a−12c 位于 [s,s+1)，必为负数，k=1 已无法
返回，答案为 1。否则 s≥0，令

T = 1 + floor(s/a).

对于整数 m 和正整数 a，有
floor((z−m)/a)=floor((floor(z)−m)/a)。取 z=3b²/a、m=12c，得到
T=floor(1+3b²/a²−12c/a)。整数平方满足原不等式当且仅当 k²≤T，
故答案是 floor(sqrt(T))+1；T 恰为完全平方时也必须加一。

Python 使用准确整数平方根。其余语言在 [1,2000000000] 二分第一个
满足 k²>T 的 k。该谓词单调，右端一定满足，因此得到首次不可能返回
的时刻。精确最小值与等价的取整步骤证明了整个算法。

O(t log U) 时间，U=2000000000，每组最多 31 次二分。算术核心只需
O(1) 空间，存储输入或输出缓冲使用 O(t) 空间。Python 的准确整数
平方根也满足此上界。

x 是实数，不是整数。失败条件为严格 k²>T；等号仍有重实根。
b 的符号在平方后消失。s<0 时答案为 1。避免 32 位乘法溢出，也不要
误认为必须用同一个 x 同时满足所有 k。

## 各语言说明

原生语言使用有符号 64 位整数存储系数、乘积和搜索边界。
3b²≤2999999994000000003，s≤3000000005999999991，
T≤3000000005999999992。搜索平方不超过 4000000000000000000，
小于 2⁶³−1。第二次除法前判断 s<0，确保非负整数除法等于向下取整；
第一次分子始终非负。不要计算 a²k² 或使用浮点平方根。Python 整数和
isqrt 均准确。

因为 a≥1，k² 的实数上界至多为
1+3·999999999²+12·999999999=3000000005999999992<2000000000²。
所以始终存在 k≤2000000000<10¹⁸，无需 `Infinity` 分支。
