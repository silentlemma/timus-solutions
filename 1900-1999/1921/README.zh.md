# 1921. 最长同字符直线段恰好为指定长度的表格

[Timus 1921](https://acm.timus.ru/problem.aspx?space=1&num=1921) · difficulty 1264 · constructive

原题作者 Grigoriy Nazarov，出自 2012 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

用前 k 个大写拉丁字母填满 n×m 表格。某行、某列或某条对角线上
必须存在连续 l−1 个相同字母，但任何方向都不能有连续 l 个。
对角线包括两个斜率，每步两个坐标各改变一。
等价地，最长同字符直线段必须恰好为 l−1。
不要求使用所有 k 个字母。限制：2 秒，64 MB。

## 输入

四个整数 n,m,k,l，满足 1≤n,m≤100，1≤k≤26，2≤l≤100。

## 输出

无解则输出 `NO`。否则输出 `YES`，然后输出 n 行，每行 m 个字母。
任何同时满足两个长度要求的表格都可接受。

## 评测方式

专用检查器验证标题、尺寸、允许字母和四个无向方向的最长同字符段。
最大值必须恰好为 l−1，而不只是小于 l。
依据下面证明的完整可行条件拒绝错误的 `NO`。
不与某个固定表格逐项比较。

## 样例

```
3 4 4 2
```

```
YES
ABCB
CDAD
ABCB
```

```
2 2 1 2
```

```
NO
```

## 解法

令 q=l−1，d=max(n,m)。若 d<q，则任何行、列、对角线都没有足够
长度，无法出现所需线段。

k=1 时只能全部填 A，最长段为 d，因此当且仅当 d=q 有解。

q=1 时，横向、纵向及对角相邻的格子都必须不同。
一个 2×2 方块的四格两两相邻，所以需要四个字母；非平凡单行或
单列需要两个，单格只需一个。精确需求为 min(n,2)·min(m,2)。
用从零开始的行 r、列 c，赋予字母编号

```text
(r mod 2) · min(m,2) + (c mod 2)。
```

这在单列中使用 A、B，而非 A、C。相邻格的奇偶对不同，
所以字母数足够时得到正确填法。

剩余情况 q≥2、k≥2。只要 d≥q，两个字母总足够。
若 m≥q，使用字母编号

```text
(r + floor(c/q)) mod 2。
```

每行是长度 q 的交替同色块，最后一块可能较短。至少有一个完整块，
因此所需长度出现。纵向相邻格总不同。

沿任一斜率的对角线，每步行奇偶性改变；块编号奇偶性仅在跨块边界
时改变。因此对角相邻格只可能在跨边界时相同。
两次跨边界相距 q 步，且 q≥2，不可能连续两步都相同。
故对角同色段至多为 2≤q，全局最大长度恰好为 q。

若 m<q，则 n≥q，转置公式为 (c+floor(r/q)) mod 2。
交换行列保留两个对角方向。至此构造覆盖所有其他可行情况，
每次拒绝也都来自必要条件。

包括生成表格和输出，时间与空间均为 O(nm)。无解判定为 O(1)。

普通棋盘染色会产生很长的同色对角线，不能作为通用解。
必须检查两种斜率。不出现长度 l 还不够，必须出现 l−1。
单字母和 l=2 要单独处理。仅行数达到 q 时必须转置块公式。
不要求所有 k 个字母出现；单列 k=2 时不能输出 C。

## 各语言说明

只需小整数除法、奇偶性和字符运算。公式坐标均从零开始，
字母编号从 A 开始。Go 1.14 显式计算小值的最小值、最大值，
其他原生版本使用标准操作。所有实现缓存行或输出，不使用搜索与递归。
