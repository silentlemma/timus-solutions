# 1921. Таблица с точной длиной наибольшей одноцветной цепочки

[Timus 1921](https://acm.timus.ru/problem.aspx?space=1&num=1921) · difficulty 1260 · constructive

Автор оригинальной задачи — Григорий Назаров; Уральская региональная командная олимпиада по программированию 2012.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Заполнить таблицу n×m первыми k заглавными латинскими буквами.
Должны встретиться l−1 одинаковых букв подряд в строке, столбце
или диагонали, но нигде не должно быть l одинаковых подряд.
Учитываются оба направления диагоналей с единичным изменением
обеих координат. Иными словами, максимальная длина прямой цепочки
одинаковых букв должна быть ровно l−1. Использовать все k букв
не обязательно. Лимиты: 2 секунды, 64 МБ.

## Входные данные

Четыре целых числа n,m,k,l: 1≤n,m≤100, 1≤k≤26, 2≤l≤100.

## Выходные данные

Если заполнения нет, вывести `NO`. Иначе вывести `YES`, затем n строк
по m букв. Подходит любое заполнение, удовлетворяющее обоим условиям.

## Проверка

Специальная проверка контролирует заголовок, размеры, допустимые буквы
и максимальную цепочку в четырёх неориентированных направлениях.
Максимум должен быть ровно l−1, а не просто меньше l. Ложный `NO`
отклоняется по полному критерию существования, доказанному ниже.
Сравнения с единственной ожидаемой таблицей нет.

## Примеры

```
3 4 4 2
```

```
YES
ABCB
CDAD
ABCB
```

```
2 2 1 2
```

```
NO
```

## Решение

Пусть q=l−1, d=max(n,m). Если d<q, ни одна строка, столбец или
диагональ не содержит достаточно клеток для нужной цепочки.

При k=1 вся таблица состоит из A, максимальная цепочка имеет длину d.
Поэтому этот случай разрешим тогда и только тогда, когда d=q.

При q=1 любые соседние по стороне или диагонали клетки должны
различаться. В квадрате 2×2 все четыре клетки попарно соседние,
поэтому нужны четыре буквы. Нетривиальной строке или столбцу нужны
две, одной клетке — одна. Точное требование: min(n,2)·min(m,2) букв.
Для строки r и столбца c с нумерацией с нуля используем индекс буквы

```text
(r mod 2) · min(m,2) + (c mod 2).
```

Так в одном столбце используются A и B, а не A и C. Соседние пары
чётностей различны, значит при достаточном алфавите заполнение корректно.

При q≥2 и k≥2 двух букв достаточно всегда, когда d≥q.
Если m≥q, зададим индекс буквы формулой

```text
(r + floor(c/q)) mod 2.
```

В каждой строке чередуются одноцветные блоки длины q, последний
может быть короче. Полный блок обязательно есть, нужная длина
достигается. Соседи по вертикали всегда различны.

При диагональном шаге чётность строки меняется всегда, а чётность
номера блока — только на его границе. Две диагональные клетки могут
совпасть лишь при пересечении границы. Границы отстоят на q шагов,
причём q≥2: два шага с равенством не могут идти подряд.
Следовательно, диагональная цепочка не длиннее 2≤q. Общий максимум
равен ровно q.

Если m<q, то n≥q. Транспонируем формулу: (c+floor(r/q)) mod 2.
Меняются местами строки и столбцы, обе диагонали сохраняются.
Все оставшиеся случаи покрыты конструкциями, а каждый отказ
следует из необходимого ограничения.

O(nm) времени и памяти с учётом построенной таблицы и вывода.
Невозможность определяется за O(1).

Шахматная раскраска создаёт длинные одноцветные диагонали и в общем
случае не подходит. Проверяйте оба наклона. Недостаточно запретить
длину l: нужно получить l−1. Отдельно обработайте одну букву и l=2.
Транспонируйте блоки, если до q доходит лишь число строк.
Не требуйте использования всех k букв и не выводите C при k=2
в одном столбце.

## Особенности языков

Нужны только целочисленное деление, чётность и работа с буквами.
Во всех формулах индексы начинаются с нуля, буквы — с A.
В Go 1.14 минимум и максимум вычисляются явно, в остальных нативных
версиях используются стандартные операции. Все программы буферизуют
строки или вывод; поиск и рекурсия не нужны.
