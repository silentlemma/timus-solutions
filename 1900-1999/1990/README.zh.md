# 1990. 能穿过走廊的最宽水平线段

[Timus 1990](https://acm.timus.ru/problem.aspx?space=1&num=1990) · 难度 1060 · geometry, sorting

原题作者 Denis Dublennykh（由 Egor Shchelkonogov 整理）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两条不相交、不接触的折线分别构成走廊左右边界。每条折线的顶点高度严格递增，两条折线的起始高度相同，终止高度也相同。水平线段从底部任意合法位置出发，沿连续路径到达顶部。它可以向任意方向平移，但必须保持水平并留在走廊内；允许接触墙壁。

还有若干点障碍，可能位于走廊外。障碍可以接触线段端点，但不能位于线段的严格内部。求允许通过的最大线段长度。

每面墙有 2 到 100000 个顶点，障碍数 `0≤q≤100000`。坐标均为绝对值不超过 `10⁹` 的整数。障碍按高度非递减排列，同一高度的 `x` 无序。时间限制 1 秒，内存限制 64 MB。

## 输入

左墙顶点数 `n` 及各顶点的 `x y`，然后是右墙顶点数 `m` 及其坐标，最后是 `q` 和障碍坐标。每条墙的顶点按 `y` 严格递增排列。在整个公共高度范围内，左墙始终严格位于右墙左侧。

## 输出

一个实数，表示最大可行长度。

## 评测方式

数值按 10⁻⁶ 的绝对或相对误差比较。

## 样例

输入：

```
2
0 0
5 10
3
5 0
10 5
10 10
1
6 5
```

输出：

```
4.0
```

在障碍高度 5，左右墙坐标为 2.5 和 10。坐标 6 的障碍留下 3.5 与 4 两个空隙。其他位置的墙间距至少为 5，因此答案为 4。

## 解法

记墙的位置为 `L(y)<R(y)`。忽略障碍时，宽度上界为 `C=min_y(R(y)−L(y))`。在两面墙所有顶点高度的相邻事件之间，两条墙均为仿射函数，差值也是仿射函数，最小值在端点取得。因此检查每个左墙顶点到右墙的间距，再检查每个右墙顶点到左墙的间距。对面边的指针只向前移动，总计 `O(n+m)`。

对范围内每种障碍高度，将其 `x` 排序，去掉 `[L(y),R(y)]` 外的点，并把两面墙作为首尾坐标。设相邻坐标的最大间隔为 `G(y)`，则长度 `w` 的线段能通过该高度，当且仅当 `w≤G(y)`。重复点只增加零间隔；墙上的点不产生额外限制。如果没有范围内障碍，该层只有已经计入 `C` 的墙间距约束。

答案是 `min(C, min_y G(y))`。不同高度的点没有竖直延伸，不能自行形成连续屏障，各层的限制可以分别处理。按输入顺序消费每个同高组，并前移两个墙指针。

### 为什么局部限制足够

任何从底部到顶部的连续路径都会经过每个中间高度，即使中途向下移动。因此墙宽和障碍间隔的限制都是必要的。

反过来，取所有墙顶点与障碍高度为事件。在每个事件处选一个长度为 `w` 的合法放置，左端点 `a` 满足 `L(y)≤a≤R(y)−w`。相邻事件之间没有障碍，墙均为仿射函数。将选定的左端点位置线性连接，两个不等式由凸组合在整个区间内保持成立。这样得到高度单调递增的连续路径，事件本身也因选择合法而安全。墙和障碍端点接触都允许，所以等号和最优长度本身也可行。

### 稳定的整数插值

不要先求两个很大的浮点坐标再相减。对顶点 `(x,y)` 与对面边 `(aₓ,aᵧ),(bₓ,bᵧ)`，先用整数计算间距分子 `(aₓ−x)(bᵧ−y)+(bₓ−x)(y−aᵧ)`，最后除以 `bᵧ−aᵧ`。检查右墙顶点时改变符号。

在障碍高度，墙写成分数 `N/D`，其中 `N=aₓ(bᵧ−y)+bₓ(y−aᵧ)`，`D=bᵧ−aᵧ>0`。用整数乘积判断障碍是否在墙内。边缘间距是 `(x·D−N)/D` 或 `(N−x·D)/D`，两障碍间距为整数。末顶点采用分母 1。会发生抵消的减法在转浮点前完成。

插值权重非负，总和不超过 `2·10⁹`。间距分子的绝对值不超过 `4·10¹⁸`，坐标分子不超过 `2·10¹⁸`；所用乘积和差均适合有符号 64 位整数。无需交叉乘两面墙的分母，否则会需要更大的界。只将完整间距转换为 double，输出小数点后 12 位。

## 各语言说明

若同高点数为 `k_y`，时间 `O(n+m+q+Σ k_y log(k_y+1))`，至多 `O(n+m+q log(q+1))`。墙与最大组大小 `K` 需要 `O(n+m+K)` 空间，无需全局障碍排序。Go、Rust 还保留 `I` 个输入字节，实际空间 `O(n+m+K+I)`；其他版本流式读取。

Java 对原始数组使用堆排序，保证组排序 `O(k log k)`，并使用字节缓冲和 `long`。C++、Go、Rust 在乘法前已采用 64 位类型，Python 使用精确整数。没有障碍、起点或终点上的障碍、范围外的高度以及同高乱序 `x` 均按同一规则处理。也可以二分长度并检查可行区间，但需重复扫描。
