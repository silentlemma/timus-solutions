# 1990. Максимальная ширина горизонтального отрезка в коридоре

[Timus 1990](https://acm.timus.ru/problem.aspx?space=1&num=1990) · сложность 1061 · geometry, sorting

Автор оригинальной задачи — Денис Дублённых; подготовка — Егор Щелконогов.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Две непересекающиеся и некасающиеся ломаные ограничивают коридор слева и
справа. Высоты вершин каждой ломаной строго возрастают; начальные высоты
совпадают, конечные тоже. Горизонтальный отрезок начинает движение в
любом месте нижнего уровня и должен непрерывно добраться до верхнего.
Его можно переносить в любом направлении, сохраняя горизонтальность и
находясь внутри коридора. Касаться стен разрешено.

Заданы точечные препятствия, в том числе вне коридора. Препятствие может
касаться конца отрезка, но не может находиться строго между его концами.
Найдите наибольшую ширину отрезка, для которой существует путь.

У каждой стены от 2 до 100000 вершин, препятствий `0≤q≤100000`. Все
координаты целые, по модулю не больше `10⁹`. Препятствия упорядочены по
неубыванию высоты; их координаты `x` на одной высоте произвольны. Лимит
времени — 1 секунда, памяти — 64 МБ.

## Входные данные

Число вершин `n` левой стены и их пары `x y`, затем число `m` и вершины
правой стены, затем `q` и координаты препятствий. Вершины каждой стены
даны по строгому возрастанию `y`. На всём общем диапазоне высот левая
стена строго левее правой.

## Выходные данные

Одно вещественное число — максимальная допустимая ширина.

## Проверка

Числа сравниваются с абсолютной или относительной погрешностью 10⁻⁶.

## Примеры

Ввод:

```
2
0 0
5 10
3
5 0
10 5
10 10
1
6 5
```

Вывод:

```
4.0
```

На высоте препятствия 5 стены имеют координаты 2,5 и 10. Точка с
координатой 6 оставляет промежутки 3,5 и 4. В остальных местах
расстояние между стенами не меньше 5, поэтому оптимальная ширина равна
4.

## Решение

Обозначим стены на высоте `y` через `L(y)<R(y)`. Без препятствий
допустимая ширина ограничена `C=min_y(R(y)−L(y))`. Между соседними
высотами объединённого набора вершин обе стены линейны, значит линейна и
разность: минимум достигается на границе участка. Проверяем каждую левую
вершину относительно правой стены и каждую правую относительно левой.
Указатель противоположного ребра движется только вперёд, поэтому два
прохода занимают `O(n+m)`.

Для каждой высоты препятствий внутри общего диапазона сортируем
координаты `x` и отбрасываем точки вне `[L(y),R(y)]`. Добавляем стены
как крайние координаты. Пусть `G(y)` — наибольший промежуток между
соседними оставшимися координатами. Отрезок проходит данный уровень
тогда и только тогда, когда его ширина не больше `G(y)`. Повторы
добавляют нулевые промежутки, точки на стенах не создают нового
ограничения. Если внутренних точек нет, достаточно уже учтённого
ограничения стен.

Ответ — `min(C, min_y G(y))`. Точки на разных высотах дают независимые
ограничения: у точки нет вертикальной протяжённости, поэтому такие
препятствия сами по себе не образуют сплошную перегородку. Обрабатываем
по одной группе одинаковой высоты, продвигая два указателя по стенам.

### Доказательство достаточности

Любой непрерывный путь снизу вверх пересекает каждый промежуточный
уровень. Поэтому все ограничения стен и промежутков необходимы, даже
если путь возвращается на меньшую высоту.

Для обратного утверждения соберём высоты всех вершин и препятствий. На
каждом таком уровне выберем допустимое положение отрезка ширины `w`. Его
левый конец `a` удовлетворяет `L(y)≤a≤R(y)−w`. Между соседними уровнями
препятствий нет, а стены линейны. Линейно соединим выбранные положения
левого конца: обе границы неравенства сохраняются выпуклой комбинацией.
Получается непрерывный путь с возрастающей высотой. На самих уровнях
положение допустимо по выбору. Равенства разрешены, поскольку касания
стен и концов допускаются. Значит локальные ограничения достаточны и
максимальная ширина достижима.

### Точная интерполяция перед делением

Нельзя сначала интерполировать две большие вещественные координаты, а
затем вычитать. Для вершины `(x,y)` напротив ребра `(aₓ,aᵧ),(bₓ,bᵧ)`
считаем целочисленный числитель зазора `(aₓ−x)(bᵧ−y)+(bₓ−x)(y−aᵧ)` и
только затем делим на `bᵧ−aᵧ`. При проверке правой вершины относительно
левой стены меняем знак.

На уровне препятствий храним стену как дробь `N/D`, где
`N=aₓ(bᵧ−y)+bₓ(y−aᵧ)`, `D=bᵧ−aᵧ>0`. Принадлежность точки коридору
проверяем целочисленными произведениями. Крайние зазоры равны
`(x·D−N)/D` и `(N−x·D)/D`; внутренние зазоры целые. Последняя вершина
представляется со знаменателем 1. Сокращающее вычитание происходит до
перехода к вещественным числам.

Неотрицательные веса интерполяции в сумме не больше `2·10⁹`. Модуль
числителя зазора не больше `4·10¹⁸`, координатного числителя — `2·10¹⁸`.
Все используемые произведения и разности помещаются в знаковые 64 бита.
Перемножать знаменатели двух стен не нужно: для этого потребовалась бы
большая оценка. Готовый зазор переводим в double и выводим 12 знаков
после точки.

## Особенности языков

При `k_y` точках на высоте время равно `O(n+m+q+Σ k_y log(k_y+1))`, не
больше `O(n+m+q log(q+1))`. Память стен и наибольшей группы размера `K`
— `O(n+m+K)`. Общая сортировка точек не нужна. Go и Rust также
удерживают `I` байтов входа: фактическая память `O(n+m+K+I)`. Остальные
версии читают потоково.

Java сортирует примитивный массив пирамидальной сортировкой с гарантией
`O(k log k)`, использует байтовый ввод и `long`. C++, Go и Rust
выполняют умножения уже в 64-битном типе, Python использует точные
целые. Отсутствие препятствий, точки на старте и финише, точки вне
диапазона высот и неотсортированные `x` обрабатываются общими правилами.
Альтернатива — двоичный поиск ширины с проверкой допустимых интервалов,
но он требует повторных проходов.
