# 1942. 最大格点同余类的最近平移

[Timus 1942](https://acm.timus.ru/problem.aspx?space=1&num=1942) · difficulty 647 · geometry

Original problem from Open Ural FU Personal Contest 2012 | by Vitaliy Belokobilskiy, Sergey Madzhuga.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定平面上n个点，只能平移一次坐标原点，不能旋转坐标轴。新坐标
两分量均为整数的点被计数。先最大化计数，再在实现最大计数的
平移中最小化欧氏长度。重合点也作为不同记录分别计数。
时限1秒，内存64 MB。

## 输入

n满足1≤n≤50000，随后n对实数坐标。每个绝对值≤100，小数点后
至多三位。允许符号及较短小数部分。

## 输出

最大计数的整数，以及最小平移距离。距离绝对误差≤10⁻⁵。

## 评测方式

检查器精确核对点数，并按 10⁻⁵ 的绝对误差检查平移距离。

## 解法

令S=1000，将十进制字符串补齐小数部分后解析成整数千分值X,Y，
不经二进制浮点乘法截断。两点能同时成为整数坐标，当且仅当
两个坐标差都是整数，因此归一化余数rx=X mod S、ry=Y mod S
必须相同，均在0..999。

用S²项数组统计每个余数对，键为rx·S+ry。每个有用平移属于一个
类，并恰好使该类全部点整数化，最大频率就是最大计数。

该类可选原点为(rx/S+i,ry/S+j)，i,j为整数。距离平方分量独立，
各取最近整数平移。千分值分量大小dx=min(rx,S−rx)，dy同理，
定义q=dx²+dy²。在最大频率类中选最小q，最后才求sqrt(q)/S。

频率只增不减。每次更新类后，按计数更大、同计数时q更小维护
当前最优。每个新达到并列频率的类都会比较，归纳保持已处理点的
最优解。类划分证明计数最优，逐轴最近整数选择证明距离最小。
半整数可能对应两个最近平移，但平方距离相同。

时间O(S²+n)，S=1000；频率辅助空间O(S²)。完整程序还保留O(n)
点或输入数据，总空间O(S²+n)。计数≤50000，千分坐标在±100000，
q≤500000，有符号32位足够。频率表约4 MB。

不能旋转、合并重合记录、把负小数部分直接取绝对值，也不能先
选最近类再考虑计数。整数部分不影响分类。接近1的余数对应很小
的负平移。分组和比较q不需epsilon。

## 各语言说明

C++、Go、Java显式归一化负余数；Python正模及Rust rem_euclid
已给正确范围。解析负小于1的数时也保留精确符号。Python、Go用
紧凑32位频率数组；Java固定输出区域设置。输出九位小数，舍入
误差≤5·10⁻¹⁰。只有最终平方根使用浮点，分组和并列决策都精确。
