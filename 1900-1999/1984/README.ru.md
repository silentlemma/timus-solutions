# 1984. Окружность, которой касаются все единичные круги

[Timus 1984](https://acm.timus.ru/problem.aspx?space=1&num=1984) · сложность 214 · geometry

Задача из фольклора; Открытый командный чемпионат УрФУ по программированию — 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Разместите `n` кругов радиуса 1 внутри общей окружности так, чтобы
внутренности кругов не пересекались, а каждый круг касался общей границы
изнутри. Найдите минимальный радиус внешней окружности. Дано целое
`1≤n≤10`. Ограничения: 0,5 секунды и 64 МБ.

## Входные данные

Одно целое число `n`.

## Выходные данные

Минимальный радиус, одно вещественное число.

## Проверка

Числа сравниваются с абсолютной или относительной погрешностью 10⁻⁶.

## Примеры

Ввод:

```
2
```

Вывод:

```
2
```

## Решение

Для одного круга ответ равен 1. Пусть теперь `n≥2`, внешний радиус —
`R`, а `r=R−1>0`. Из внутреннего касания следует, что центры всех
единичных кругов лежат на окружности радиуса `r` с тем же центром.
Расстояние между любыми двумя центрами должно быть хотя бы 2.

Упорядочим центры по полярному углу. Сумма `n` циклических угловых
промежутков равна `2π`, поэтому один промежуток `α` не больше `2π/n≤π`.
Расстояние для этой пары равно `2r sin(α/2)≤2r sin(π/n)`. Оно не меньше
2, значит `R≥1+1/sin(π/n)`.

Граница достижима: расположим центры в вершинах правильного
`n`-угольника на окружности радиуса `1/sin(π/n)`. Соседние центры
находятся ровно на расстоянии 2, остальные пары — не ближе. Каждый
единичный круг достигает внешнего радиуса `R=r+1` и касается внешней
границы. Поэтому при `n≥2` минимум равен `1+1/sin(π/n)`.

В примере `n=2`: центры противоположны на окружности радиуса 1. Два
единичных круга касаются друг друга и помещаются в окружность радиуса 2,
поэтому ответ 2.

Формула требует постоянного числа операций: время и память — `O(1)`. Для
данного диапазона достаточно двойной точности и десяти знаков после
десятичной точки.

Подводные камни:

- Касание внешней границы обязательно для каждого круга; произвольная
  упаковка кругов решает другую задачу.
- Центры лежат на радиусе `R−1`, а не `R`.
- Один круг рассмотрите до формулы, иначе получите деление на `sin(π)`.
- Угол `π/n` задаётся в радианах.
- Круги не могут перекрываться внутренностями, но могут касаться друг друга.

## Особенности языков

Все пять версий вычисляют одну формулу в двойной точности. C++ получает
π через `acos(-1)`, Python, Go, Java и Rust используют стандартные
константы π. В Java явно выбран формат с десятичной точкой.
