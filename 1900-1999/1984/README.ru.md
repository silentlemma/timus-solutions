# 1984. Окружность, которой касаются все единичные круги

[Timus 1984](https://acm.timus.ru/problem.aspx?space=1&num=1984) · сложность 214 · geometry

Задача из фольклора; Открытый командный чемпионат УрФУ по программированию — 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Разместите `n` кругов радиуса 1 внутри общей окружности так, чтобы
внутренности кругов не пересекались, а каждый круг касался общей границы
изнутри. Найдите минимальный радиус внешней окружности. Дано целое
`1≤n≤10`. Ограничения: 0,5 секунды и 64 МБ.

## Входные данные

Одно целое число `n`.

## Выходные данные

Минимальный радиус, одно вещественное число.

## Проверка

Численный ответ сравнивается с допуском из условия; ниже доказана граница округления.

- `1984_geometry_optimized.cpp` (G++ 13.2 x64): 16 тестов репозитория.

- `1984_geometry_optimized.py` (PyPy 3.10 x64): 16 тестов репозитория; 10 дополнительных сравнений точного исходника.

## Примеры

Ввод:

```
2
```

Вывод:

```
2
```

## Решение

Для одного круга ответ равен 1. Пусть теперь `n≥2`, внешний радиус —
`R`, а `r=R−1>0`. Из внутреннего касания следует, что центры всех
единичных кругов лежат на окружности радиуса `r` с тем же центром.
Расстояние между любыми двумя центрами должно быть хотя бы 2.

Упорядочим центры по полярному углу. Сумма `n` циклических угловых
промежутков равна `2π`, поэтому один промежуток `α` не больше `2π/n≤π`.
Расстояние для этой пары равно `2r sin(α/2)≤2r sin(π/n)`. Оно не меньше
2, значит `R≥1+1/sin(π/n)`.

Граница достижима: расположим центры в вершинах правильного
`n`-угольника на окружности радиуса `1/sin(π/n)`. Соседние центры
находятся ровно на расстоянии 2, остальные пары — не ближе. Каждый
единичный круг достигает внешнего радиуса `R=r+1` и касается внешней
границы. Поэтому при `n≥2` минимум равен `1+1/sin(π/n)`.

В примере `n=2`: центры противоположны на окружности радиуса 1. Два
единичных круга касаются друг друга и помещаются в окружность радиуса 2,
поэтому ответ 2.

Формула требует постоянного числа операций: время и память — `O(1)`. Для
данного диапазона достаточно двойной точности и десяти знаков после
десятичной точки.

Подводные камни:

- Касание внешней границы обязательно для каждого круга; произвольная
  упаковка кругов решает другую задачу.
- Центры лежат на радиусе `R−1`, а не `R`.
- Один круг рассмотрите до формулы, иначе получите деление на `sin(π)`.
- Угол `π/n` задаётся в радианах.
- Круги не могут перекрываться внутренностями, но могут касаться друг друга.

## Оптимизированные решения

`1984_geometry_optimized.java`. Сохраняются радиус 1 при N=1 и 1+1/sin(π/N) иначе, с прежним Math.sin. Ограниченное целое разбирается напрямую, double выводится с представлением для обратного восстановления вместо инициализации Formatter/Locale. Убрана общая десятичная форматирующая подсистема; геометрия и библиотечный синус не меняются. O(1) числовой работы и состояния; простая формульная версия сохранена.

Accepted точного исходника Java 1.8 №11326960: 0.078 с / 460 КБ. Сохранённое сравнение актуального Java от 2026-11-20: место по времени 1/53, по памяти 2/53. При памяти меньше 1024 КБ строгий критерий учитывает только время.

- `1984_geometry_optimized.java`: 0.078 s / 460 KB; сохранённая учебная база `1984_geometry.java`: 0.125 s / 1796 KB; изменение времени -37.6%; изменение памяти -74.4%.

Прежний радиус равен 1 при N=1, иначе 1 + 1/sin(pi/N). C++/Java уменьшают расходы стандартного ввода-вывода, сохраняя библиотечную формулу. Python вычисляет полином синуса до x^13 по схеме Горнера с шестью постоянными отношениями факториалов, а не таблицу ответов. При 2 <= N <= 10 имеем 0 < x<=pi/2, следующий знакочередующийся член x^15/15! меньше 7e-10; sin(pi/N)>=sin(pi/10)>0,3, поэтому ошибка радиуса меньше 10^-8. Целочисленный вывод шести знаков добавляет не больше половины миллионной, оставаясь в допуске 10^-6 по модулю. Все десять легальных N сверены с независимым библиотечным синусом. Фиксированные границы дают O(1) времени и памяти, исключение N=1 сохранено.

- `1984_geometry_optimized.cpp`: 0.015 s / 120 KB; база `1984_geometry.cpp`: 0.015 s / 444 KB; изменение относительно базы: время -0.0%, память -73.0%.

- `1984_geometry_optimized.py`: 0.109 s / 276 KB; база `1984_geometry.py`: 0.078 s / 396 KB; изменение относительно базы: время +39.7%, память -30.3%.

`1984_geometry_optimized.rs`. Сохраняется формула радиуса для упаковки кругов: для одного круга радиус равен 1, иначе 1+1/sin(PI/N). Вычисления идут в f64, десять знаков после точки выводятся напрямую, хранится лишь постоянное числовое состояние. Время и дополнительная память O(1). Rust использует среду выполнения C для ввода-вывода, без целых декодированных строк String и форматирования Rust. Простой принятый исходник сохранён без изменений.

По сравнению с `1984_geometry.rs`: время 0.015 s → 0.031 s; память 256 KB → 88 KB.
