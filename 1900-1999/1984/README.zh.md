# 1984. 每个单位圆盘都接触的外接圆

[Timus 1984](https://acm.timus.ru/problem.aspx?space=1&num=1984) · 难度 214 · geometry

民间题目，出自 2013 年乌拉尔联邦大学公开团体锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

将 `n` 个半径为 1 的圆盘放在一个大圆内，要求小圆盘内部互不相交，并且每个小圆盘都与大圆边界内切。求大圆的最小半径。输入整数满足 `1≤n≤10`。时间限制 0.5 秒，内存限制 64 MB。

## 输入

一个整数 `n`。

## 输出

一个实数，表示最小半径。

## 样例

输入:

```
2
```

输出:

```
2
```

## 解法

只有一个圆盘时答案为 1。对 `n≥2`，设大圆半径为 `R`，令 `r=R−1>0`。内切条件使所有小圆圆心位于同心的半径为 `r` 的圆周上。任意两个小圆圆心距离必须至少为 2。

按极角排列圆心。`n` 个循环角间隔之和为 `2π`，所以至少一个间隔 `α≤2π/n≤π`。对应圆心距离为 `2r sin(α/2)≤2r sin(π/n)`。该距离至少为 2，因此 `R≥1+1/sin(π/n)`。

将圆心放在半径为 `1/sin(π/n)` 的圆上的正 `n` 边形顶点，就能达到下界。相邻圆心距离恰为 2，其他圆心对距离不会更小。每个单位圆盘最远到达半径 `R=r+1`，因而都与外圆内切。因此 `n≥2` 时最小半径为 `1+1/sin(π/n)`。

样例 `n=2` 时，圆心位于半径为 1 的圆的一对对径点。两个单位圆盘互相相切，并装入半径为 2 的大圆，答案是 2。

公式只需固定次数运算，时间和空间均为 `O(1)`。在给定输入范围内，双精度及小数点后十位足以满足误差要求。

注意事项：

- 每个小圆盘都必须接触外圆边界，不能改成任意圆盘装填问题。
- 小圆圆心所在圆的半径是 `R−1`，不是 `R`。
- 单个圆盘应先单独处理，避免除以 `sin(π)`。
- `π/n` 使用弧度。
- 小圆盘内部不能重叠，但允许相切。

## 优化解法

半径公式仍为N=1时1，否则1+1/sin(pi/N)。C++/Java减少标准I/O开销，保留库公式。Python用Horner形式算到x^13的正弦多项式，只含六个固定阶乘比，并非答案表。2<=N<=10时0<x<=pi/2，下个交错项x^15/15!<7e-10；sin(pi/N)>=sin(pi/10)>0.3，因此半径误差<10^-8。六位十进制整数输出再增加至多半个百万分之一，仍满足10^-6绝对容差。全部十个合法N与独立库正弦对照。固定边界下时间、空间O(1)，明确保留N=1特例。
