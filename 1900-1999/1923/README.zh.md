# 1923. 交替按颜色扩展的两个区域

[Timus 1923](https://acm.timus.ru/problem.aspx?space=1&num=1923) · difficulty 545 · bfs

原题为经典题，Dmitry Karpenko 准备，出自 2012 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n×m 网格的每格颜色为数字 0..9。通过公共边连通的同色格构成国家。
第一方最初拥有左下角所在的整个国家，第二方拥有右上角所在的国家，
初始颜色不同。双方轮流行动，第一方先手。行动时改为给定联盟颜色，
保留全部旧领土，并吞并相邻的该颜色国家。不能选自己当前颜色或
对方当前颜色。给出合法行动序列，求最终两方面积。
每格面积为 1。限制：1 秒，64 MB。

## 输入

先给 n,m，2≤n,m≤50，再给 n 行，每行 m 个数字。
然后是 l，2≤l≤100，接着按时间顺序给出恰好 l 个颜色 0..9。
颜色数字之间可以使用任意空白分隔。

## 输出

第一行输出第一方面积，第二行输出第二方面积。
顺序对应初始左下角与右上角的国家。

## 评测方式

按顺序精确比较两个整数词元。

## 解法

为每格保存所有者：中立、第一方、第二方。双方分别维护领土格列表，
并预处理每格合法的四个边邻居。中立格的原始颜色不会变化；
一旦归某方所有，其原始颜色不再决定归属。

先标记两个起点，各按其初始颜色扩展经过中立格。
这样得到完整初始国家，而不是只占有一个角格。

行动选择颜色 c 时，将当前领土的所有格作为队列扫描。
发现原始颜色为 c 的中立邻居，立即标记所有者并追加到同一队列。
本次行动继续处理新增格，从而吞并整个邻国而不只是边界。
无论之后如何更换颜色，旧领土格都保留在列表中。

无需修改保存的颜色或记录当前联盟来执行模拟，因为输入保证行动合法。
中立颜色始终为初值，已占领格只由所有者数组判断。
对方的格不管原始数字是什么，始终禁止吞并。

正确性不变量是：每个列表恰为该方连通领土。初始搜索后成立。
每个新增格都是所选颜色的中立格，且邻接旧格或本次新增格，
因此其国家必须被吞并。反过来，队列会遍历所有相邻目标颜色国家
内部的路径，故没有遗漏。先标记再追加避免重复，所有者检查保护对手。
旧格从不删除，不变量在每次行动后保持。最终列表长度就是所求面积。

每次扩展最多扫描 nm 格及各自至多四个邻居，时间 O((l+1)nm)。
所有者、邻接表、领土列表用 O(nm) 空间；加上保存的行动序列共 O(nm+l)。

起点为左下和右上。必须取得整个初始国家。保留全部旧领土，
本次新增格也要在本次处理完。对角接触不算相邻，横向不能跨行。
原始颜色不能覆盖已有所有者。l 为奇数时不要多补一步。
测试生成的每一步都必须排除双方当前颜色。

## 各语言说明

零基坐标 (r,c) 编码为 r·m+c。C++、Go、Java、Rust 的游标以当前
增长后的列表长度为界；Python 列表迭代会在同一遍访问追加元素。
Java 使用两个容量足够的扁平数组，其他版本使用动态列表或向量。
所有遍历均为迭代，不使用递归。
