# 1979. Метки с одинаковыми суммами циклов на кубе

[Timus 1979](https://acm.timus.ru/problem.aspx?space=1&num=1979) · сложность 1360 · constructive

Автор оригинальной задачи — Денис Дублённых; XVII Открытый чемпионат Урала по спортивному программированию (май, 2013).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждая грань куба разбита на сетку `n×n`. Путь, попав в клетку через
сторону, обязан выйти через противоположную; через узлы сетки проходить
нельзя. Замкнутый путь посещает `4n` клеток. Расставьте все целые числа
от `1` до `6n²` по одному разу так, чтобы сумма за полный обход не
зависела от начальной клетки и направления.

Размер `1≤n≤100`. Ограничения: 1 секунда, 64 МБ.

## Входные данные

Одно целое число `n`.

## Выходные данные

Выведите Т-образную развёртку с указанными ниже именами граней. Первые
`n` строк содержат по `n` чисел грани `U`; следующие `n` строк — по `4n`
чисел граней `A,B,C,D`; последние `n` строк — по `n` чисел грани `V`.

```text
U
A B C D
V
```

## Проверка

Проверяющая программа сверяет строки и перестановку и проходит каждый
замкнутый путь по сложенному кубу; принимается любая подходящая
раскладка.

## Примеры

Ввод:

```
2
```

Вывод:

```
20 13
11 8
3 15 19 4 12 24 18 5
1 7 9 23 21 17 6 16
10 22
14 2
```

## Решение

Положим `a=n²`, `M=6a+1`. Заполним три грани нижней половиной чисел в
порядке строк. При индексах `r,c` от нуля получаем `A(r,c)=rn+c+1`,
`B(r,c)=a+rn+c+1`, `U(r,c)=2a+rn+c+1`.

Противоположные грани заполним дополнениями до `M`. У пар `A,C` и `B,D`
в этой развёртке обращены столбцы, а у `U,V` — строки. Поэтому
`C(r,c)=M−A(r,n−1−c)`, `D(r,c)=M−B(r,n−1−c)`, `V(r,c)=M−U(n−1−r,c)`.

Первые три грани содержат ровно `1,…,3a`, а дополнения — ровно
`3a+1,…,6a`. Значит, каждое требуемое число встречается один раз.

Рассмотрим физические координаты клетки. Переход через противоположные
стороны сохраняет одну касательную координату: путь идёт поясом через
четыре грани. На противоположных гранях пояс содержит соответствующие
полосы. Указанные обращения индексов сопоставляют клетки с одинаковыми
касательными координатами при отражении относительно средней плоскости
куба. Их метки дают `M` в каждой паре. В поясе `2n` пар, поэтому общая
сумма равна `2nM`. Доказательство работает при чётном и нечётном `n`,
включая единицу.

В примере `n=2`, и общая сумма равна `4·25=100`. Первый ряд средней
полосы образует цикл из восьми клеток с суммой 100; остальные
направления дают тот же итог.

Каждая метка непосредственно вычисляется по позиции вывода. Время —
`O(n²)`, что оптимально для печати `6n²` чисел; дополнительная память —
`O(n)` или меньше.

Подводные камни:

- Для противоположных граней нужны обращения индексов: столбцы у `A,C` и
  `B,D`, строки у `U,V`.
- Нужна симметрия относительно средней плоскости; центральная симметрия
  меняет фиксированную координату пояса.
- Средняя полоса содержит четыре грани в каждой строке, верхняя и нижняя — одну.
- Начальная клетка учитывается за полный цикл ровно один раз.

## Особенности языков

Во всех версиях используются прямые формулы. Python собирает одну
строку, Java пишет строку через буфер. C++, Go и Rust выводят метки
последовательно с буферизацией.
