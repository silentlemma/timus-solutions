# 1970. 拼接旋转且重叠的照片

[Timus 1970](https://acm.timus.ru/problem.aspx?space=1&num=1970) · difficulty 1254 · backtracking

原题出自 2013 年乌拉尔联邦大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

10×10 颜色矩阵被拍成九张 4×4 照片。旋转打乱前，各照片左上角坐标
是 {0,3,6} 的全部坐标对，所以相邻照片重叠一整行或列。每张可独立
旋转 90 度的整数倍，不可镜像。用全部九张照片各一次重建任意合法
10×10 矩阵。保证有解。限制：1 秒，64 MB。

## 输入

九个 4×4 整数矩阵，颜色范围为 0…99。相邻矩阵间有空行，其余空白
不影响读取。照片数量和尺寸固定。

## 输出

十行，每行十个空格分隔的颜色。指定的九个窗口能与全部照片旋转后
一一对应即可，答案不唯一。

## 评测方式

检查器从输出的矩阵中切出九块，并在允许旋转的情况下与输入的照片一一对应，每张照片恰用一次；任何合法的矩阵都被接受。

## 解法

预处理每张照片的四个旋转状态，状态包含照片身份和方向。同一照片
相同方向图案只保留一份，不同照片即使相同仍是独立资源。上下边从
左到右存，左右边从上到下存。两状态相邻当且仅当公共边的四个颜色
数组相等；无需再次倒序。

九个位置构成 3×3 网格，初始允许全部保留状态。递归选择候选状态
最少的空位，相同则选网格邻居更多的位置。尝试每个状态后，从全部
其他空位删除该照片所有方向，并将邻位候选与预处理的兼容掩码求交。
任何空位无候选则剪枝。每层复制九个小掩码，便于回退。

整个答案可以整体旋转，所以可要求第一张输入照片使用原方向，但
位置仍自由。这只消除整体旋转对称，不能把它强行放在角或中心。
至多 36 状态，64 位掩码足够。

### 正确性

每个状态都是允许的照片旋转。删除完整照片掩码避免重复使用。交集
只限制与已放邻居的相等边，不会剪去合法完成；位置启发式仅改变
枚举顺序。任何合法拼图均能整体旋转使首张照片方向为零，删除相同
方向也不改变图案，所以至少一个解保留。

完整赋值使所有水平、垂直公共边相等。四张照片相交处的角相等由
相邻公共边传递推出，无需额外对角检查。偏移 0、3、6 的 4×4 窗口
覆盖整个 10×10 矩阵，复制所有窗口即得一致且每张使用一次的答案。
完整枚举及存在性保证搜索成功。

设照片数 m、边长 s，保守时间界为 `O((4m)²s + m!·4^m·m²)`，空间
`O(m²+ms²)`，含递归中复制的候选。此题 m=9、s=4，约束传播大幅
减少分支；对可变规模问题并不声称多项式时间。

样例输出的行 0…3、列 0…3 正好是第一张输入照片，行 3…6、列
0…3 正好是第二张，共同行为 `9 1 1 9`。另外七个窗口同样各使用
一张剩余照片，合并为所列 10×10 图案。

步长为三而非四，存在重叠。不能镜像。公共边四个颜色须按相同坐标
方向比较。不能以重复使用一张照片代替另一张相同照片。整体旋转
仅允许固定方向，不允许固定位置。36 状态需要 64 位掩码。回退时
也要还原放置数组，复制候选掩码并未自动恢复它。

## 各语言说明

Python 使用任意精度整数和 bit_count；C++、Go 1.14、Java 8、Rust
1.75 使用 64 位掩码、置位计数和最低位操作。Java 每个输入创建新
Solver。所有版本递归深度至多九。
