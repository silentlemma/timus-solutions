# 1970. Сборка повёрнутых фотографий с перекрытием

[Timus 1970](https://acm.timus.ru/problem.aspx?space=1&num=1970) · difficulty 1254 · backtracking

Оригинальная задача: Открытое личное первенство УрФУ по программированию 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Матрица цветов 10×10 сфотографирована девятью фрагментами 4×4. До
независимых поворотов и перемешивания их левые верхние углы находились
во всех парах координат из {0,3,6}. Поэтому соседние снимки имеют общую
строку или столбец. Каждый снимок разрешено поворачивать на угол, кратный
90 градусам, но не отражать. Восстановите любую подходящую матрицу 10×10,
использовав каждый из девяти снимков ровно один раз. Решение существует.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

Девять целочисленных матриц 4×4, цвета от 0 до 99 включительно. Между
матрицами пустая строка; остальные пробелы несущественны. Число снимков
и размеры фиксированы.

## Выходные данные

Десять строк по десять цветов через пробел. Принимается любая матрица,
девять указанных окон которой соответствуют входным снимкам с поворотами.

## Проверка

Проверяющая программа вырезает девять кусков из напечатанной матрицы и
сопоставляет их с фотографиями с учётом поворотов, по одному разу
каждую; принимается любая подходящая матрица.

## Решение

Заранее получим четыре поворота каждого снимка. Состояние — номер снимка
и ориентация. Совпадающие ориентации одного снимка оставляем в одном
экземпляре; разные одинаковые снимки остаются разными ресурсами. Храним
верхнюю и нижнюю грани слева направо, левую и правую — сверху вниз.
Совместимость соседей означает равенство общих массивов из четырёх
цветов; дополнительно разворачивать грань не надо.

Позиции образуют сетку 3×3. Изначально каждая допускает все оставленные
состояния. Рекурсивно выбираем незаполненную позицию с наименьшим числом
вариантов; при равенстве — с большим числом соседей. Перебираем её
состояния. Убираем все ориентации выбранного снимка из остальных позиций,
а множества соседей пересекаем с заранее вычисленной совместимостью.
Пустое множество незаполненной позиции немедленно отвергает ветвь.
На каждом уровне копируем девять маленьких битовых масок для отката.

Весь ответ можно повернуть целиком. Поэтому первый входной снимок
разрешено оставить в исходной ориентации, где бы он ни оказался. Это
убирает только общий поворот и не фиксирует его место. Состояний не
больше 36, достаточно 64-битной маски.

### Корректность

Выбранные состояния являются допустимыми поворотами снимков. Удаление
полной маски снимка запрещает повторное использование. Пересечения
проверяют ровно условия с уже поставленными соседями и не отсекают
ни одного совместимого продолжения. Эвристика позиции меняет лишь
порядок поиска. Любую правильную сборку можно целиком повернуть, чтобы
первый снимок имел нулевую ориентацию; одинаковые ориентации неразличимы.
Таким образом, сокращения сохраняют хотя бы один ответ.

При полном заполнении все общие строки и столбцы совпадают. В точке
встречи четырёх снимков равенство углов следует по цепочке соседних
граней, отдельное диагональное условие не нужно. Окна 4×4 со смещениями
0,3,6 покрывают всю матрицу 10×10. Их копирование даёт согласованный
рисунок с каждым снимком ровно один раз. Полнота перебора и гарантия
существования обеспечивают нахождение ответа.

Для m снимков размера s консервативная граница времени —
`O(ms² + (4m)²s + m!·4^m·m²)`, памяти — `O(m²+ms²)`, включая копии множеств
в рекурсии. Здесь m=9, s=4, а распространение ограничений сильно
сокращает перебор. Для переменного размера это экспоненциальный поиск.
Слагаемое `O(ms²)` учитывает чтение, повороты, сравнение совпадающих
ориентаций и копирование пикселей снимков в ответ.

В примере окно строк 0…3 и столбцов 0…3 ответа в точности равно первому
снимку. Окно строк 3…6 и столбцов 0…3 равно второму. У них общая строка
`9 1 1 9`. Остальные семь окон аналогично используют все оставшиеся
снимки по одному; объединение даёт показанный рисунок 10×10.

Шаг равен трём, а не четырём: есть перекрытие. Разрешены повороты без
отражений. Сравнивайте все четыре цвета грани в согласованном порядке.
Одинаковые по цветам снимки нельзя использовать повторно вместо других.
Общий поворот позволяет фиксировать ориентацию, но не позицию. Для
36 состояний нужна 64-битная маска. При откате восстанавливайте также
массив размещения: копий множеств для этого недостаточно.

## Особенности языков

Python использует целые произвольной длины и bit_count. C++, Go 1.14,
Java 8 и Rust 1.75 — 64-битные маски и операции количества битов и
младшего установленного бита. Java создаёт новый Solver для входа.
Глубина рекурсии во всех версиях не превышает девяти.
