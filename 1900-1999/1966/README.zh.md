# 1966. 相交线段上的连通性

[Timus 1966](https://acm.timus.ru/problem.aspx?space=1&num=1966) · difficulty 682 · dsu, geometry

原题出自 2013 年乌拉尔联邦大学公开个人赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给出 n 个标记点以及连接其中点对的 m 条闭直线段。可以沿每条线段
双向移动，在任意公共点换到另一条线段，即使交点没有标记。位于线段
内部的标记点也能到达。判断从起始标记点能否到达所有标记点。无需
指定起点编号：该条件等价于所有标记点属于同一个几何连通分量。
时间限制 1 秒，内存限制 64 MB。

## 输入

n,m 满足 1≤m<n≤200。随后 n 个不同的整数坐标点 x,y，各坐标绝对值
不超过 30,000。再后 m 行，每行两个不同的 1 到 n 的编号，指定线段
端点。允许重复线段及端点逆序。

## 输出

所有标记点都可沿线段相互到达时输出 `YES`，否则输出 `NO`。

## 评测方式

按记号逐个比较输出。

## 样例

```
4 2
0 0
1 0
1 1
0 1
1 3
4 2
```

```
YES
```

```
4 3
0 0
1 0
1 1
0 1
1 2
2 1
3 4
```

```
NO
```

```
3 2
0 0
1 0
1 1
1 3
3 2
```

```
YES
```

## 解法

第一个样例中正方形两条对角线在中心相交，可以在那里换线，到达四个
端点，尽管只按端点建的图不连通。第二个样例把第一条线段反向重复，
并未连接上下两条边，所以输出 NO。第三个样例两段通过公共端点组成
一条链，三个标记点全部连通。

在 n 个标记点上维护并查集。先合并每条线段的两个端点；对每对相交
的闭线段，分别取一个端点合并；对每个落在线段上的标记点，将它与
该线段一个端点合并。最终所有标记点代表相同，当且仅当答案为 YES。

每次合并都对应真实路径：同一线段、经交点换线，或从线段内部标记
移动到端点。反过来，任意允许路径都沿着线段序列，只在公共点换线。
同一线段的端点已合并，所有换线都已合并，内部标记也全部附加，因此
任意真实可达关系都被并查集表示。不在任何线段上的标记保持孤立。
这证明判定条件与几何连通完全等价。

使用精确整数谓词。定义
cross(a,b,c)=(b_x−a_x)(c_y−a_y)−(b_y−a_y)(c_x−a_x)。
点在闭线段上，当且仅当叉积为零且两个坐标都落在端点坐标的闭区间内。

两闭线段相交，当且仅当 x、y 包围区间都重叠，并且每条线段的端点
位于另一条支撑直线的两侧或线上。区间检查排除共线但分离的线段，
非严格符号条件兼容公共端点、T 形接触及共线重叠。

时间 `O((nm+m²)·α(n))`，空间 `O(n+m)`，使用路径压缩和按大小合并。
有 nm 次点在线段检查及 m(m−1)/2 次线段对检查。α 为并查集复杂度中
的反 Ackermann 函数。

只按输入端点建图会漏掉交点及内部标记。即使 m=n−1 也不保证连通，
尤其存在重复线段时。接触也算相交，但仅共线不代表区间重叠。乘法前
将坐标放在有符号 64 位类型中：叉积可能超过有符号 32 位。即使 64 位
也不要直接乘两个叉积，3.6·10⁹ 的量级相乘会达到 1.296·10¹⁹，超出范围。
直接比较符号即可，无需 epsilon。

## 各语言说明

C++ 使用 int64_t，Go 1.14 使用 int64，Java 8 使用 long，Rust 1.75
使用 i64 进行几何运算。Python 3.12 使用精确整数。所有版本直接比较
符号，迭代压缩路径并按分量大小合并，不需要递归、平面图或浮点数。
