# 1966. Связность по пересекающимся отрезкам

[Timus 1966](https://acm.timus.ru/problem.aspx?space=1&num=1966) · difficulty 682 · dsu, geometry

Оригинальная задача: Открытое личное первенство УрФУ по программированию 2013.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны n отмеченных точек и m замкнутых прямолинейных отрезков между
некоторыми парами этих точек. По отрезкам можно перемещаться в обе стороны,
а в любой общей точке переходить с одного на другой, даже если отметки
там нет. Отмеченная точка внутри отрезка тоже доступна. Определить,
достижимы ли все отметки из начальной отмеченной точки. Её номер не нужен:
условие равносильно принадлежности всех отметок одной геометрической
компоненте. Ограничения: 1 секунда, 64 МБ.

## Входные данные

Числа n,m: 1≤m<n≤200. Затем n различных пар целых координат x,y,
модуль каждой не больше 30 000. Следующие m строк содержат два разных
номера от 1 до n — концы очередного отрезка. Повторяющиеся отрезки
и обратный порядок концов разрешены.

## Выходные данные

`YES`, если все отмеченные точки достижимы по отрезкам, иначе `NO`.

## Проверка

Ответы сравниваются по токенам.

## Решение

В первом примере диагонали квадрата пересекаются в центре. Переход через
центр объединяет все четыре конца, хотя граф только по концам несвязен.
Во втором первый отрезок повторён в обратном направлении: связи между
нижней и верхней сторонами это не создаёт, ответ NO. В третьем два
отрезка образуют цепь через общий конец, достигаются все три отметки.

Используем систему непересекающихся множеств на n отмеченных точках.
Объединим концы каждого отрезка. Для каждой пары пересекающихся замкнутых
отрезков объединим по одному концу из каждого. Для каждой точки,
лежащей на отрезке, объединим её с одним из его концов. Ответ YES
получается тогда и только тогда, когда все точки имеют одного представителя.

Каждое объединение соответствует настоящему пути: по одному отрезку,
через общую точку двух отрезков или от внутренней отметки к концу.
Обратно, любой допустимый маршрут проходит по цепочке отрезков, переходя
только в пересечениях. Концы одного отрезка уже объединены, каждый
возможный переход учтён, все лежащие на отрезках отметки присоединены.
Значит, любая физическая достижимость отражена в системе множеств.
Отметка вне всех отрезков остаётся изолированной. Это доказывает критерий.

Геометрию проверяем точно целыми числами. Ориентированная площадь
cross(a,b,c)=(b_x−a_x)(c_y−a_y)−(b_y−a_y)(c_x−a_x).
Точка лежит на замкнутом отрезке, когда площадь нулевая и обе её
координаты находятся между соответствующими координатами концов включительно.

Два отрезка пересекаются, если их диапазоны x и y перекрываются, а концы
каждого лежат по разные стороны прямой другого, с разрешённым нулём.
Проверка диапазонов исключает раздельные коллинеарные отрезки. Нестрогие
сравнения знаков учитывают общие концы, примыкания и наложения.

Время `O((nm+m²)·α(n))`, память `O(n+m)` при сжатии путей и объединении
по размеру. Проверяется nm пар «точка/отрезок» и m(m−1)/2 пар отрезков.
α — обратная функция Аккермана из оценки операций системы множеств.

Граф только по указанным концам пропускает пересечения и внутренние
отметки. Даже m=n−1 не гарантирует связность, особенно при повторах.
Касания считаются пересечениями, но одной коллинеарности недостаточно
для перекрытия. До умножения нужны знаковые 64-битные координаты: площадь
может не помещаться в 32 бита. Не перемножаем сами площади даже в 64 битах:
3,6·10⁹ по модулю даёт произведение 1,296·10¹⁹, превышающее диапазон.
Сравниваем знаки напрямую. Погрешности и epsilon не требуются.

## Особенности языков

C++ использует int64_t, Go 1.14 — int64, Java 8 — long, Rust 1.75 — i64
для геометрии. Python 3.12 считает точно целыми числами. Во всех версиях
непосредственные сравнения знаков, итеративное сжатие путей и объединение
по размеру компоненты. Рекурсия, построение плоского графа и float не нужны.
