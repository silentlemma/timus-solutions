# 1902. Meeting Times

[Timus 1902](https://acm.timus.ru/problem.aspx?space=1&num=1902) · difficulty 116 · math

Original problem by Denis Dublennykh, from Ural Championship 2012.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Один объект входит на отрезок в момент s. Ещё n объектов проходят тот же
отрезок навстречу ему, начиная в моменты sᵢ. Скорости всех объектов
постоянны и одинаковы; весь отрезок проходится за t единиц времени.
Найдите моменты встреч. Ограничения: 1 секунда и 64 МБ.

## Входные данные

Сначала n, t, s: 1 ≤ n ≤ 100, 1 ≤ t ≤ 100, 360 ≤ s ≤ 1200.
Далее n целых моментов входа в строгом порядке:
s−t < s₁ < … < sₙ < s+t. Вход удовлетворяет всем ограничениям одновременно.

## Выходные данные

n моментов встреч в порядке входа встречных объектов, через пробелы или
переводы строк. Допустимая абсолютная или относительная ошибка — 10⁻⁶.

## Проверка

Сравниваются n конечных чисел с абсолютной/относительной погрешностью
10⁻⁶. В тестах используется режим `float:1e-6`.

## Примеры

```
2 60 600
600 630
```

```
630.000000
645.000000
```

## Решение

Измерим расстояния в единицах пути за единицу времени. Тогда скорость
равна 1, а длина отрезка — t. К моменту встречи u первый объект прошёл
u−s, а встречный — u−sᵢ. Сумма этих расстояний равна длине:

`(u − s) + (u − sᵢ) = t`, поэтому `2u = s + sᵢ + t`.

Для каждого sᵢ выводим `(s + sᵢ + t) / 2`. Строгие ограничения дают
`max(s, sᵢ) < u < min(s+t, sᵢ+t)`: встреча происходит внутри обоих
маршрутов. Отбрасывать объекты или моделировать движение не требуется.

Равенство необходимо, поскольку объекты занимают одну точку. Суммарный
пройденный путь строго растёт со скоростью 2, значит решение единственно.
Оно лежит внутри обоих маршрутов, поэтому формула даёт нужную встречу.

Числитель целый, поэтому ответ целый или полуцелый. Выводим целое частное
и суффикс `.000000` для чётного числителя либо `.500000` для нечётного.
Это точное представление без погрешности округления и зависимости от
локали. Нельзя просто отбросить остаток при целочисленном делении.
Числитель меньше 2600, достаточно 32-битного типа.

В примере получаем `(600+600+60)/2=630` и `(600+630+60)/2=645`.

Время `O(n)`. На вычисление одной встречи нужна память `O(1)`;
с хранением токенов ввода или буфера вывода общая память равна `O(n)`.

## Особенности языков

Все пять версий форматируют частное и суффикс по чётности. Достаточно
буферизованного ввода/вывода; Python рассчитан на CPython 3.12.
Следует прочитать ровно n встречных стартов; t — длительность, а не
абсолютный момент времени.
