# 1902. Meeting Times

[Timus 1902](https://acm.timus.ru/problem.aspx?space=1&num=1902) · difficulty 116 · math

Original problem by Denis Dublennykh, from Ural Championship 2012.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个物体在时刻 s 进入线段，另有 n 个物体从另一端反向经过线段，
进入时刻依次为 sᵢ。所有物体速度相同且恒定，走完整段需要 t 个时间单位。
求每次相遇的时刻。时限 1 秒，内存限制 64 MB。

## 输入

首先给出 n、t、s，其中 1 ≤ n ≤ 100、1 ≤ t ≤ 100、360 ≤ s ≤ 1200。
接着给出 n 个严格递增的整数进入时刻：s−t < s₁ < … < sₙ < s+t。
所有限制同时满足，因此输入中的 n 和 t 也必须能容纳这些不同的整数。

## 输出

按输入顺序输出 n 个相遇时刻，用空格或换行分隔。
允许的绝对或相对误差不超过 10⁻⁶。

## 评测方式

检查恰好 n 个有限数值，绝对/相对容差为 10⁻⁶。
测试使用 `float:1e-6` 模式。

## 样例

```
2 60 600
600 630
```

```
630.000000
645.000000
```

## 解法

将单位距离设为物体单位时间走过的距离。速度变为 1，线段长度就是 t。
在相遇时刻 u，第一个物体走过 u−s，迎面物体走过 u−sᵢ，两者之和为 t：

`(u − s) + (u − sᵢ) = t`，所以 `2u = s + sᵢ + t`。

对每个进入时刻输出 `(s + sᵢ + t) / 2`。输入的严格不等式保证
`max(s, sᵢ) < u < min(s+t, sᵢ+t)`，即相遇发生在两段行程内部。
无需筛选或模拟事件。

物体占据同一点时，它们走过的距离之和必然等于线段长度。
该和以速度 2 严格增加，方程只有一个解；输入范围保证该解在两段行程内，
所以输出的是唯一正确的相遇时刻。

所有输入都是整数，答案只能是整数或半整数。保留整数分子：偶数时输出
整数商和 `.000000`，奇数时输出整数商和 `.500000`。
这种格式完全精确，也不受小数点地区设置影响。不能只做整数除法丢掉余数。
分子小于 2600，用 32 位整数即可。

示例得到 `(600+600+60)/2=630` 和 `(600+630+60)/2=645`。

时间 `O(n)`，每次计算只需 `O(1)` 状态。
保存输入词元或输出缓冲的实现，总空间为 `O(n)`。
