# 1920. 正方形网格中所有偶数长度的环

[Timus 1920](https://acm.timus.ru/problem.aspx?space=1&num=1920) · difficulty 728 · constructive

原题作者 Alexey Samsonov，Dmitry Ivankov 准备，出自 NEERC 2012 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在 n×n 正方形网格中构造恰含 L 个节点的简单环。相邻节点距离为 1，
最后一个节点与第一个节点也必须相邻。每个节点最多使用一次。
坐标为 1 到 n 的整数。输出任意合法环，或报告不存在。
限制：1 秒，64 MB。

## 输入

两个整数 n,L，满足 2≤n≤100，4≤L≤20,000。

## 输出

不存在时输出 `Unsuitable device`。否则先输出
`Overwhelming power of magic`，再按遍历顺序输出 L 对坐标，每行一对。
不要在末尾再次输出起点。任何合法环、起点和方向都可接受。

## 评测方式

专用检查器验证标题、坐标数量、整数范围、顶点互异，以及包括闭合边
在内的每条边的曼哈顿距离是否为 1。错误的“不存在”声明会被拒绝。
预期文件里的路径并非标准唯一路径，不按词元比较两条路径。

## 样例

```
2 6
```

```
Unsuitable device
```

```
3 6
```

```

1 1
2 1
3 1
```

## 解法

按 r+c 的奇偶性给节点 (r,c) 染色。每条边改变颜色，因此环长必须
为偶数。顶点互异还要求 L≤n²。下面构造从 4 到
M=n²−(n mod 2) 的每个偶数长度，证明这两个条件也充分。

从一个 2×2 正方形的四边环开始。每次将已有边 u—v 替换为
u—a—b—v，其中 a、b 是边另一侧两个相邻且未使用的节点。
这样恰增加两个顶点，仍保持单位边和一个简单环。

令 W=n−(n mod 2)，它是偶数。按固定顺序扩展：

1. 保持高度为 2，逐列扩展到宽 W。用经过新列两点的绕路替换右侧竖边。
2. 添加第 3 到第 n 行。每行处理列对 (1,2)、(3,4)、…、(W−1,W)，
   用经过新点对的绕路替换其正上方的横边。
3. 若 n 为奇数，在最后一列依次加入行对 (1,2)、(3,4)、…、(n−2,n−1)，
   使用这些点对左侧的竖边。

被替换的边始终存在。第一阶段保留完整下边界；第二阶段每次扩展
都会生成下一行所需的横向点对边，并保留右侧竖直边界。
第三阶段使用该边界上互不重叠的边。新点对总未被使用。
因此即使在一行中途停止，所得结果仍是简单环。

n 为偶数时，第二阶段覆盖 n² 个节点。n 为奇数时，第三阶段只留下
右下角未用，覆盖 n²−1 个节点。每次增加两个节点，所以在
(L−4)/2 次扩展后停止，就得到所有所需偶数长度。这同时证明构造
与判定不存在的条件正确。

将零基坐标编码为 r·n+c，用后继数组保存有向环边。若待替换边方向
相反，必须同时交换旧端点和新端点。修改三个后继链接即可完成扩展。
最后从左上角沿后继走恰好 L 步，输出转换为一基的坐标。

计入后继数组初始化和输出缓存，时间与空间均为 O(n²+L)。
每增加两个顶点只需 O(1) 次链接修改。不存在的输入可在 O(1) 时间拒绝。

奇数网格无法使用所有节点，但能使用 n²−1 个，而不只是 n(n−1) 个。
不要漏掉最后一列。反转边时两组端点都要交换。严格控制扩展次数，
允许最后一行未填满；检查闭合边，但不要重复输出起点。

## 各语言说明

索引与长度均可用普通整数。C++、Go、Java、Rust 使用扁平数组和显式循环。
Python 惰性生成相同的扩展序列。Java、Python、Rust 缓存输出，Go 使用
缓冲输入输出，C++ 关闭流同步。链接表示避免反复插入列表导致元素移动。
