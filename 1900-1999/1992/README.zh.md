# 1992. 共享不可变的学习与撤销历史

[Timus 1992](https://acm.timus.ru/problem.aspx?space=1&num=1992) · 难度 372 · trees, simulation

原题作者 Egor Shchelkonogov。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

初始对象 1 没有学过的程序，也没有撤销记录。处理 `n` 条命令，程序编号为 `1..m`。学习会追加程序并清空该对象的撤销记录。撤销移除最后学习的程序并记录它；恢复将最近撤销的程序放回。复制创建一个拥有两份当前历史的新对象。查询最后学习的程序，若没有则输出 `basic`。

限制 `1≤n,m≤500000`。所有命令合法：对象已经存在，新学程序尚未被该对象掌握，撤销时学习栈非空，恢复时撤销栈非空。被撤销的程序可以再次学习。时间限制 2 秒，内存限制 64 MB。

## 输入

第一行 `n m`，之后 `n` 条命令：

- `learn c p`：学习 `p`，`1≤p≤m`，并清空对象 `c` 的撤销记录。
- `rollback c`：撤销最后学习的程序。
- `relearn c`：恢复最近一次撤销。
- `clone c`：复制两份历史到下一个新对象。
- `check c`：查询最后学习的程序。

新对象按创建顺序编号，初始编号为 1。复制不改变原对象。

## 输出

按 `check` 顺序，每行输出程序编号或小写 `basic`。没有查询时输出为空。

## 评测方式

按记号逐个比较输出。

## 样例

输入：

```
9 10
learn 1 5
learn 1 7
rollback 1
check 1
clone 1
relearn 2
check 2
rollback 1
check 1
```

输出：

```
5
7
basic
```

第一次撤销后，对象 1 掌握程序 5，可以恢复 7。副本保留这两部分。对象 2 恢复 7，而对象 1 不变；最后撤销使对象 1 回到基础状态。

## 解法

每个对象保存两个栈顶：`A` 是学习栈，最近程序在顶；`R` 是撤销栈，最近撤销在顶。所有栈共享全局节点池。节点为 `(程序,前驱)`，创建后永不修改，编号 0 表示空栈。向栈顶 `h` 压入 `p` 就新建 `(p,h)`；弹出则读取前驱。

- 学习：`A=push(p,A)`，`R=0`。
- 撤销：先记 `t=A`，再令 `A=previous[t]`、`R=push(value[t],R)`。
- 恢复：先记 `t=R`，再令 `R=previous[t]`、`A=push(value[t],A)`。
- 复制：只复制两个整数栈顶。
- 查询：`A` 非零输出 `value[A]`，否则输出 `basic`。

清空撤销记录仅将栈顶设为零，不能删除共享节点，因为其他对象仍可能访问它们。副本共享不可变的后缀，未来修改只替换各自的栈顶。无需遍历、复制列表或保存已学程序集合；输入保证合法。

非零栈顶 `h` 表示 `value[h]` 后接 `previous[h]` 所表示的序列；零表示空序列。新节点恰好在原序列前加一个元素。已有节点永不改变，因此复制栈顶就永久保留整个序列，不受其他栈顶后续变化影响。

对命令归纳。初始两序列为空。学习压入指定程序并清空撤销序列；撤销准确地把学习栈顶移入撤销栈；恢复执行反向移动。复制保持两个序列，查询读取正确的学习栈顶。因此表示始终与题意相同，所有答案正确。

学习、撤销、恢复各创建一个节点，复制和查询不创建节点。最多 `n` 个节点、`n+1` 个对象。四个长度为 `n+2` 的数组保存值、前驱、两个栈顶表，均适合 32 位。最大元素存储为 `4·4·(500000+2)=8000032` 字节，约 7.63 MiB。

每条命令栈操作 `O(1)`，有界词长下总时间 `O(n)`，空间 `O(n)`。记输入为 `I` 字节、输出为 `B` 字节；Go、Rust 还保留输入，C++、Go、Python、Rust 缓存输出。Java 用缓冲流输出并复用数字字符数组，避免为每个数创建字符串。此格式下 `B≤7n`，总空间仍为线性。

Python 使用紧凑 `array('i')` 并逐行读取，逐节点元组或复制列表的开销过大。Go 用 32 位数组和兼容 1.14 的字节分词。Java 用 `int` 和字节缓冲。Rust 节点索引用 `u32`，访问向量时转换。若复制完整列表，大量复制深历史可能导致二次时间、空间。
