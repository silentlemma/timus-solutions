# 1918. 能够离开每个真前缀的映射

[Timus 1918](https://acm.timus.ru/problem.aspx?space=1&num=1918) · difficulty 937 · dp

原题作者 Denis Dublennykh，出自 NEERC 2012 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

选择映射 f:{1,…,n}→{1,…,n}，n 个控制器各有 n 种独立选择。
初始状态为 1，激活让 i 变为 f(i)，等待允许 i>1 时变为 i−1。
可在任意中间状态再次激活。统计能够到达 n 的映射。
限制：2 秒，64 MB。

## 输入

一个整数 n，2≤n≤5000。

## 输出

合适映射数模 M=1 000 000 007。

## 评测方式

精确比较一个整数词元。

## 样例

```
2
```

```
2
```

## 解法

可达状态必为前缀：能够到达某状态就能等待到所有更小正状态。
令 a[k] 为在 {1,…,k} 上能到达 k 的映射数，辅助初值 a[1]=1。

按最终可达前缀 {1,…,k} 分类全部 nⁿ 个映射。前 k 个映射值
必须留在此前缀内，且其限制映射能够到达 k，共 a[k] 种。
其余 n−k 个值可任取全部 n 个状态，共 n^(n−k) 种。
反之每种这样的组合恰有此前缀。前缀是固定集合，不需二项式系数。
因此

nⁿ = Σ(k=1..n) a[k]·n^(n−k)。

分离 a[n] 并提取 n，令 H=Σ(k=1..n−1) a[k]·n^(n−1−k)，得到

a[n] = n·(n^(n−1)−H) mod M。

按 k 递增用 Horner 求 H：从零开始，每步 H←(H·n+a[k]) mod M。
二进制模幂计算 n^(n−1)。定长整数语言先归一化减法。上述分类完备
且互斥，对 n 归纳即证明递推。

### Python 的循环

Python 每次处理两个系数：H←(H·n²+a[k]·n+a[k+1]) mod M，
恰为两步 Horner 合并一次取模。n−1 为奇数时单独处理最后系数。
共享迭代器 `zip` 可能消费未配对值却未处理，故尾项按下标重新读取。
其他语言使用单系数步。

时间 `O(n²)`，较小的模幂工作为 `O(n log n)`；空间 `O(n)`。
普通 Horner 乘积约小于 5·10¹²，模幂乘积小于 M²，64 位足够。
Python 双系数中间值约小于 2.501·10¹⁶，仍为精确整数。

n=2 时必须 f(1)=2，而 f(2) 两种皆可，故答案为 2。
n=1 仅作内部初值。

前缀外每个控制器有 n 种选择而非 n−k。注意 a[1]、每个最终前缀
只计一次、负减法归一化及奇数尾项。可达集合是前缀，不是任意连通
子集；不能用浮点幂。

## 各语言说明

C++/Go/Java/Rust 使用 64 位模运算。Python 使用精确整数、双系数
Horner 及线性额外切片。选择 CPython3.12，因为实测 PyPy 内存超过
64 MB 限制。每个程序计算前缀表，只输出第 n 项，不枚举全部映射。
