# 1918. Отображения, выходящие из любого собственного префикса

[Timus 1918](https://acm.timus.ru/problem.aspx?space=1&num=1918) · difficulty 936 · dp

Автор оригинальной задачи — Денис Дублённых; NEERC 2012, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Выберите отображение f множества {1,…,n} в себя: каждый из n регуляторов
независимо задаёт одно из n значений. Начальное состояние 1. Активация
переводит i в f(i), ожидание позволяет перейти из i в i−1 при i>1.
Активировать можно в любом промежуточном состоянии. Посчитайте настройки,
при которых достижимо n. Ограничения: 2 секунды, 64 МБ.

## Входные данные

Одно целое n, 2≤n≤5000.

## Выходные данные

Число подходящих отображений по модулю M=1 000 000 007.

## Проверка

Точное сравнение одного целого токена.

## Примеры

```
2
```

```
2
```

## Решение

Множество достижимых состояний — префикс: ожиданием из любого достижимого
состояния можно попасть во все меньшие положительные. Обозначим a[k]
число подходящих отображений на {1,…,k}, вспомогательная база a[1]=1.

Разобьём все nⁿ отображений по окончательному достижимому префиксу {1,…,k}.
Первые k значений должны оставаться внутри него, а ограничение отображения
должно позволять достичь k. Таких ограничений a[k]. Остальные n−k
значений произвольны и выбираются из всех n состояний, давая n^(n−k)
продолжений. Обратно, такая настройка имеет ровно этот достижимый префикс.
Биномиальный коэффициент не нужен: префикс фиксирован, это не произвольное
подмножество. Получаем

nⁿ = Σ(k=1..n) a[k]·n^(n−k).

Выделим a[n] и вынесем n. Если
H=Σ(k=1..n−1) a[k]·n^(n−1−k), то

a[n] = n·(n^(n−1)−H) mod M.

H считаем схемой Горнера по возрастающим k: начинаем с нуля и заменяем
H на (H·n+a[k]) mod M. Степень вычисляется двоичным возведением по модулю.
В языках фиксированной разрядности нормализуем разность перед умножением.
Разбиение исчерпывающее и непересекающееся, поэтому индукция доказывает динамику.

### Цикл Python

Python обрабатывает два коэффициента за шаг:
H←(H·n²+a[k]·n+a[k+1]) mod M. Это две точные операции Горнера с одним
взятием остатка. При нечётном количестве n−1 коэффициентов последний
обрабатывается отдельно. Общий итератор `zip` может прочитать непарный
элемент, не обработав его; остаток поэтому берётся по индексу.
Остальные версии используют обычный шаг по одному коэффициенту.

Время `O(n²)` модульных операций, включая меньшие `O(n log n)` на степени;
память `O(n)`. Обычные произведения Горнера меньше примерно 5·10¹²,
произведения для степени меньше M² — достаточно 64 бит. Парный промежуточный
результат Python меньше примерно 2,501·10¹⁶ и тоже вычисляется точно.

Для n=2 обязательно f(1)=2, а f(2) выбирается двумя способами, отсюда ответ 2.
n=1 используется только как внутренняя база динамики.

У регуляторов вне достижимого префикса n вариантов, не n−k.
Нужны база a[1], однократный учёт каждого конечного префикса,
нормализация отрицательной разности и непарный хвост Горнера.
Не заменяйте префикс произвольным связным подмножеством и не считайте степени вещественно.

C++/Go/Java/Rust используют 64-битную арифметику по модулю. Python —
точные целые, парную схему и временные срезы с линейной памятью.
