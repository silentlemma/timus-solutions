# 1956. 距离总和最小的直线

[Timus 1956](https://acm.timus.ru/problem.aspx?space=1&num=1956) · difficulty 2319 · geometry

Original problem from Ural FU contest. Kontur Cup. Petrozavodsk training camp. Winter 2013 | by Pavel Klimov (prepared by Olga Soboleva).

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把平面上的 n 个点移到同一条无限直线上，使欧几里得移动距离之和最小。
直线及终点位置均可自由选择，点可以重合。限制：1 秒、64 MB。

## 输入

先给 n，2≤n≤1000，再给 n 对整数坐标 x,y，各在闭区间 [−10⁶,10⁶] 内。

## 输出

一个实数，表示最小距离总和，绝对或相对误差不超过 10⁻⁶。程序输出十二位小数。

## 评测方式

答案按 10⁻⁶ 的绝对或相对误差比较。

## 样例

```
4
0 0
0 1
1 1
1 0
```

```
1.414214
```

## 解法

对固定直线，每个点移到正交投影最近。固定方向后，把输入点投影到单位
法向量上，绝对偏差之和在中位数处最小。因此该方向的一条最优直线经过
输入点 P；偶数个点时取中位区间的端点。

固定 P 并旋转直线。在指向其他不同位置的两个临界方向之间，各叉积符号
不变，总距离为 A cos θ+B sin θ≥0，二阶导数是它的负值。如果各点不共线，
该值为正且严格凹，区间最小值必在边界。因此有一条全局最优直线经过两个
不同输入位置。所有点都重合时答案为零。

逐对扫描所有点是 O(n³)。改为逐个固定支点 P，构造 v=Q−P，跳过零向量。
若 y<0 或 y=0 且 x<0，就取反，得到 y≥0 且包含正水平射线的半平面。
取反不改变叉积绝对值。

按 k=−x/(|x|+y) 排序，它随 [0,π) 内角度严格递增。令 R 初始为这些
规范向量之和。当前方向 d 之后的向量满足 cross(d,v)≥0，之前的满足 ≤0。
故 cross(d,R) 正好是绝对叉积之和，距离为 cross(d,R)/sqrt(d.x²+d.y²)。
每处理完 v 就从 R 减去 2v。同方向向量的叉积为零，无需分组相等键。
每对位置只在较小输入下标处计算。

Python 用 Counter 合并重合位置：重数 w 对 R 贡献 wv，经过事件后减 2wv。
其他语言显式保留重复点。两者均计入每个输入点，总时间 O(n² log n)，
工作空间 O(n)。

### 精确运算与注意事项

方向分量绝对值至多 2·10⁶，键的分母至多 4·10⁶。不同有理键间隔至少
1/(4·10⁶)²，远大于 [−1,1] 上 binary64 舍入误差；相等分数舍入相同。
因此排序无需 epsilon 或 atan2。

R 分量绝对值小于 2·10⁹，叉积每项小于 4·10¹⁵，差小于 8·10¹⁵。
原生版本用有符号 64 位整数。Python 特意使用取整数值的 binary64 向量：
乘积小于 2⁵²，整数差小于 2⁵³，故此处乘减均精确。平方范数至多
8·10¹²，也精确。仅开方和除法舍入，足以满足 10⁻⁶。
不能改成距离平方和，也不能漏掉重数、除以零向量或只试水平/竖直线。
全体共线时答案为零。

## 各语言说明

C++ 和 Rust 重用同一个向量，Go 1.14 使用 sort.Slice，Java 8 重用方向对象，而不是为每一对点新建对象。Python 使用 Counter、预先加倍的更新量和 itemgetter 作为排序键。它在 PyPy 下运行：在 CPython 3.12 下它在评测的第 49 个测试上超时，而在 PyPy 3.10 下以 0.843 秒通过。
