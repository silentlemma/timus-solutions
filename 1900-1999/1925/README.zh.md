# 1925. 补足总和的最后一个数

[Timus 1925](https://acm.timus.ru/problem.aspx?space=1&num=1925) · difficulty 70 · math

原题作者 Pavel Ageev，出自 2012 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

已知 n 轮历史。第 i 轮显示 bᵢ，理应输入 bᵢ−2，实际输入 gᵢ。
当前轮显示 k。只检查全部 n+1 轮的总和：实际输入之和必须等于
理应输入之和。求本轮应输入的非负整数，或报告无解。
历史各轮不要求单独正确。限制：1 秒，64 MB。

## 输入

n,k 满足 1≤n,k≤100，随后 n 对 bᵢ,gᵢ，各数均在 0..100。

## 输出

输出所需非负整数，零也合法。输出不受 100 的上界限制。
无解时精确输出 `Big Bang!`，保留空格、大小写和感叹号。

## 评测方式

精确比较空白分隔词元：一个整数，或 `Big` 与 `Bang!` 两词元。

## 样例

```
6 5
3 1
3 1
5 3
6 5
5 5
7 2
```

```
3
```

```
1 3
4 6
```

```
Big Bang!
```

## 解法

设 x 为今天的输入。检查比较的是全部 n + 1 轮的总和：
g₁ + … + gₙ + x = (b₁ − 2) + … + (bₙ − 2) + (k − 2)。因此
x = k − 2 + Σ(bᵢ − gᵢ − 2)；若它为负，任何输入都不行，答案是 `Big Bang!`。`O(n)`。

注意事项：

- 中途的累计值可能为负，最后却不为负，所以只能在最后判断；
- 零是合法答案；
- 每一轮（包括今天）都要减去 2。

## 优化解法

优化的 C++ 解法用 `scanf` 代替 `iostream` 读入各对数，读到就累加，不保存历史：
124 KB，而不是 428 KB。

优化的 Java 解法按 1 KB 分块读入并手工解析，而不是使用 `Scanner`，读数一读到就累
加，不保存：0.078 s，而不是 0.140 s；364 KB，而不是 1796 KB。
