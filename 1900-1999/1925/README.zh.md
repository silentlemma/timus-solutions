# 1925. 补足总和的最后一个数

[Timus 1925](https://acm.timus.ru/problem.aspx?space=1&num=1925) · difficulty 70 · math

原题作者 Pavel Ageev，出自 2012 年乌拉尔地区中学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

已知 n 轮历史。第 i 轮显示 bᵢ，理应输入 bᵢ−2，实际输入 gᵢ。
当前轮显示 k。只检查全部 n+1 轮的总和：实际输入之和必须等于
理应输入之和。求本轮应输入的非负整数，或报告无解。
历史各轮不要求单独正确。限制：1 秒，64 MB。

## 输入

n,k 满足 1≤n,k≤100，随后 n 对 bᵢ,gᵢ，各数均在 0..100。

## 输出

输出所需非负整数，零也合法。输出不受 100 的上界限制。
无解时精确输出 `Big Bang!`，保留空格、大小写和感叹号。

## 评测方式

精确比较空白分隔词元：一个整数，或 `Big` 与 `Bang!` 两词元。

3 1

## 解法

设本轮输入 x。总和检查要求

```text
sum(gᵢ) + x = sum(bᵢ−2) + (k−2)。
```

移项得 x=k−2+sum(bᵢ−gᵢ−2)。有符号余额初始为 k−2，每对历史
增加 bᵢ−gᵢ−2。必须读完全部历史后才检查符号：非负则输出余额，
否则输出失败短语。

x 的系数为一，因此候选值唯一。候选非负时代入即可满足总和。
候选为负时，不存在另一个非负整数满足同一等式，故判定充分且必要。

单轮理想输入或中间余额为负都允许，只看最终总和。
例如 k=100，历史为 (0,100),(100,0)，答案为 94，尽管第一对处理后
余额为负。k=1、历史 (3,0) 时，正确答案为零。

时间 O(n)。累计变量仅用 O(1) 工作空间；各实现存储历史或完整输入，
总空间为 O(n)。

总共 n+1 轮，当前轮也要减二。不能提前拒绝、逐轮验证历史、
把负的中间和截成零，或要求 k≥2。零是合法答案，结果可以大于
100。失败短语必须精确。

## 各语言说明

包括 Rust 在内均使用有符号整数。中间余额范围为 −10201..9898，
32 位有符号整数足够。最大值在 n=100,k=100、全为 (100,0) 时取得。
五版均先返回有符号余额，最后才选择失败格式。
Python 在输入缓存上惰性提供历史数对。
