# 1954. Пять палиндромов через чётность разбиения

[Timus 1954](https://acm.timus.ru/problem.aspx?space=1&num=1954) · difficulty 3575 · dp

Original problem from Ural FU contest. Kontur Cup. Petrozavodsk training camp. Winter 2013 | by Mikhail Rubinchik (prepared by Kirill Borozdin).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Разбейте всю строку ровно на пять непустых подряд идущих палиндромов,
сохраняя порядок символов. Палиндром совпадает со своим разворотом.
Подходит любое допустимое разбиение. Ограничения: 1 секунда, 64 МБ.

## Входные данные

Одна строка s из строчных латинских букв, 5≤n=|s|≤100000.

## Выходные данные

Если разбиения нет, `NO`. Иначе `YES` и пять палиндромов, каждый на
отдельной строке. Их конкатенация обязана точно совпадать с s.

## Проверка

Проверяющая программа убеждается, что ответ `YES` или `NO` верен, а для
`YES` — что пять напечатанных слов являются непустыми палиндромами и
составляют строку; принимается любое подходящее разбиение.

## Решение

Найдём минимальное НЕЧЁТНОЕ число частей r. Ответ существует тогда и
только тогда, когда r≤5. Необходимость очевидна. Для достаточности r
равно 1,3 или 5. Пока r<5, символов как минимум на два больше, чем частей.
Значит, либо есть часть длины не меньше трёх, либо две части длины два.
Первую заменяем первой буквой, непустой серединой и последней буквой:
все три части палиндромны. Во втором случае разбиваем оба двухбуквенных
палиндрома на буквы. Обе операции добавляют ровно две непустые части и
сохраняют строку. Хватает не более двух операций. Здесь существенно n≥5.

Для каждого префикса храним E[i],O[i] — минимальное чётное и нечётное
число палиндромов. E[0]=0, O[0]=∞. Для каждого палиндромного суффикса
s[j:i] обновляем O[i] значением E[j]+1, а E[i] значением O[j]+1; сохраняем
индекс j для восстановления. Добавление части меняет чётность. Последняя
часть любого разбиения является таким суффиксом, поэтому переходы точны.
Все значения больше пяти заменяем шестью: число частей дальше лишь растёт.
Обычный минимум без чётности недостаточен — другая чётность может иметь
иной минимум или быть невозможной.

Дерево палиндромов хранит узел для каждого различного палиндрома, ребро
по букве окружает его одинаковыми буквами, суффиксная ссылка ведёт к
длиннейшему собственному палиндромному суффиксу. Корни длин −1 и 0
обслуживают нечётные и чётные длины. При добавлении буквы идём по ссылкам
до суффикса, который можно окружить, переиспользуем или создаём узел и
его ссылку. Узлов не больше n+2. Для фиксированного алфавита держим 26
переходов на узел с детерминированным доступом.

Перебор всех суффиксных палиндромов квадратичен на одинаковых буквах.
Объединяем соседние суффиксы с одинаковой разностью длин
d[v]=len[v]−len[link[v]]; series[v] переходит к следующей группе. Для
ведущего v на позиции i новый предшественник
b=i−len[series[v]]−d[v]. Инициализируем две стоимости группы из E[b],O[b].
Если link[v] имеет ту же разность, покомпонентно берём минимум с его
сохранёнными стоимостями группы и соответствующие индексы предшественников.
Из группы обновляем E[i],O[i], добавляя единицу и меняя чётность.

Инвариант периодической серии: у прежней группы на i−d[v] те же позиции
предшественников, кроме новой b. Поэтому запомненный индекс даёт минимум
и настоящий палиндромный суффикс. Не очищаем кеш группы на каждом символе
и не прибавляем d[v] к сохранённому индексу. На префикс приходится
O(log n) ведущих групп. Стандартная лемма серий и конструкция приведены
в [статье о дереве палиндромов](https://arxiv.org/pdf/1506.04862), раздел 4.
Минимум применяется отдельно к двум компонентам чётности.

При O[n]>5 ответ NO. Иначе идём по предшественникам, меняя чётность,
восстанавливаем минимальное нечётное разбиение, разворачиваем список и
добавляем по две части доказанными операциями до пяти. Каждый шаг цепочки —
непустой палиндромный суффикс; начало в нулевом префиксе гарантирует полное
восстановление входа.

O(n log n) времени и O(26n)=O(n) памяти с переходами и предшественниками.
Построение дерева и финальное восстановление с печатью линейны для
фиксированного алфавита. Логарифм даёт число групп серий.

«Не больше пяти» не означает «ровно пять» без чётности. У чередующейся
строки чётной длины все палиндромы нечётные, пять частей невозможны.
Середина при разрезании обязана быть непустой: исходная часть длины ≥3.
Кешированный минимум должен сохранять свой индекс. Нужны два корня
сверх n узлов и состояния для нулевого префикса.

## Особенности языков

Только стандартные библиотеки. Python использует типизированные массивы
для переходов и индексов, bytearray для стоимостей, избегая словаря и
отдельных объектов чисел на каждый узел. Java использует плоские массивы
и BufferedReader. C++, Go, Rust сразу выделяют ёмкость дерева. Длины
корней знаковые. Суммарная длина пяти подстрок n, квадратичные цепочки
конкатенаций не нужны.
