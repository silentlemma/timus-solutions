# 1909. 不求平方根的首次接触

[Timus 1909](https://acm.timus.ru/problem.aspx?space=1&num=1909) · difficulty 3960 · geometry

原题作者 Pavel Atnashev，准备 Daniil Ayzenshteyn，比赛 Ural Championship 2012。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两个不同的点 A、B 以同一个非零恒定速度 v 移动。连接两点的线段可能碰到
一个固定实心球，球心 C、半径 R>0。初始整条线段与球无交集。线段首次接触
球时，两点立即停止。判断首次接触发生在端点、严格内部，还是永不接触。
相切也算接触；若端点与线段接触同时发生，归为端点碰撞。
时间限制 1 秒，内存限制 64 MB。

## 输入

四行依次为 Cx Cy Cz R；Ax Ay Az；Bx By Bz；vx vy vz。
全部 13 个数都是绝对值不超过 100 000 的整数。R>0、A≠B、v≠0。
初始线段连同两端点均不与球相交或相切。

## 输出

端点接触输出 `Crash`，首次接触严格在线段内部输出 `Warning`，没有接触
输出 `False alarm`。若内部接触已使两点停止，沿原轨迹继续前进才会发生的
端点碰撞不应算作实际碰撞。

## 评测方式

结果名称区分大小写，按标记精确比较。

## 解法

将球心平移到原点，使用点积和叉积：

```text
w0 = A-C, w1 = B-C, u = w1-w0, U = dot(u,u)
n = cross(u,v), j = cross(u,w0)
a = dot(n,n), b = dot(j,n), c = dot(j,j)-R²U
q(t) = at²+2bt+c
K = R²a-dot(w0,n)²
```

原点到移动支撑直线的距离平方减 R² 等于 q(t)/U。首次接触若严格在线段
内部，支撑直线必须首次从球外进入，所以需要 a>0、c>0、b<0 且判别量非负。
若直线初始已与球相交，但线段没有交点，则线段首次接触只能在端点发生。
若直线后来离开球时在线段内部才首次接触，连续性会推出更早已经相交，矛盾。
a=0 时运动沿支撑直线进行，首次接触也只能在端点。

不要用 128 位直接算 D=b²−ac。拉格朗日恒等式给出 D=U·K，故 K 的符号
即可判断是否有根，K=0 表示重根。满足 a>0,c>0,b<0,K≥0 时，直线首次
接触时间 t₀=(−b−√D)/a 为正。最近点严格在线段内部当且仅当
u·(w0+vt₀)<0 且 u·(w1+vt₀)>0。成立便输出 `Warning`，因为端点不可能
先于其支撑直线接触球。

无需真正求根即可计算 x+yt₀ 的符号，其中 x=u·w、y=u·v，w 为任一端点。
y=0 时直接用 sign(x)。否则令 z=−x/y=num/den，规范为 den>0，计算
H=a·num+b·den，它比较 z 与抛物线顶点 −b/a。H≥0 时 sign(t₀−z)=−1，
唯一例外 H=0,K=0 时为零。H<0 时 z 在顶点左侧，sign(t₀−z)=sign(q(z))。
在 z 时刻，该端点向量与 u 垂直，所以 q(z)y²/U 等于
E=||w·y−v·x||²−R²y²，直接计算 E 的符号即可。
最后 sign(x+yt₀)=sign(y)·sign(t₀−z)。边界等号意味着端点接触，因此
内部条件必须使用严格不等式。

没有内部首次接触时，检查两个端点的前向射线。对 w 令 p=w·v、V=v·v。
初始点在球外，射线相交或相切当且仅当 p<0 且 p²≥V(w·w−R²)。等号也算
碰撞。任一射线满足则输出 `Crash`，否则输出 `False alarm`。此时已排除
可能更早阻止这些射线继续运动的内部接触。

算术操作数与额外空间均为 O(1)。平移后坐标及 u 的分量至多 2·10⁵，速度
分量至多 10⁵，可估计 |H|≤1.152·10³³、|E|≤1.728·10³³。所有实际计算值
适合有符号 128 位；未计算的完整 D 却可能溢出，因此必须使用 K。

## 各语言说明

C++、Rust 的所有向量运算都使用有符号 128 位；先用 64 位相乘再转换并不
安全。Go 1.14 使用 math/big，Java 8 使用不可变 BigInteger，Python 3.12
使用精确整数。Go 运算为结果分配新值，防止共享引用修改输入。正式程序没有
平方根、除法、浮点数或误差容限。不能在判断提前停止之前先检查端点是否会
在原轨迹的将来碰撞。

在 6957 个测试上，答案与高精度搜索首次接触的结果一致，其中有 32 个精确构造的情形：相切、端点同时接触、偏移一个单位以及几乎平行的方向；另一份独立的已通过实现在另外 48 个测试上也一致。
