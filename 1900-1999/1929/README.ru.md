# 1929. Тройка с участником №1 и допустимый остаток

[Timus 1929](https://acm.timus.ru/problem.aspx?space=1&num=1929) · difficulty 385 · combinatorics

Original problem from Ural Regional School Programming Contest 2012 | by Olga Soboleva (prepared by Kirill Devyatkin).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Из n человек m являются специальными. Каждая команда состоит из трёх
человек и содержит хотя бы одного специального. Посчитать неупорядоченные
команды с участником №1, после выбора которых всех остальных можно
разбить на допустимые тройки. Каждая выбранная тройка учитывается один
раз, независимо от числа разбиений остатка. Лимиты: 1 секунда, 64 МБ.

## Входные данные

Первая строка: n и m, 6≤n≤999, n делится на 3, 1≤m≤n.
Во второй перечислены m различных номеров специальных участников
от 1 до n в произвольном порядке. Участник №1 может быть любым.

## Выходные данные

Одно целое число — количество допустимых команд с участником №1.

## Проверка

Точное сравнение одного целочисленного токена.

## Примеры

```
6 4
2 3 4 6
```

```
10
```

## Решение

Пусть h=1, если участник №1 специальный, иначе h=0. Среди остальных
есть S=m−h специальных и U=n−m−(1−h) обычных. Переберём r=0,1,2 —
число специальных среди двух партнёров. Удалится h+r специальных;
в выбранной тройке требуется h+r≥1. Останется t=n/3−1 команд,
которые можно составить тогда и только тогда, когда m−h−r≥t.

Необходимость: каждой оставшейся команде нужен отдельный специальный
участник. Для достаточности назначим по одному различному специальному
в каждую из t команд. Останется ровно 2t человек на 2t мест; заполним
их произвольно. Лишние специальные тоже могут занять эти места.
Других ограничений нет.

Для допустимого r получаем C(S,r)·C(U,2−r) вариантов. Невозможный
выбор даёт ноль; C(a,0)=1, C(a,1)=a, C(a,2)=a(a−1)/2.
Три случая не пересекаются и охватывают каждую неупорядоченную пару
ровно один раз. Поэтому сумма равна искомому количеству.

O(m) времени на чтение, O(1) вычислений. Потоковые C++, Go и Java
используют O(1) дополнительной памяти; Python и Rust хранят O(m) входа.

В выбранной тройке тоже нужен специальный участник. Не удаляйте №1
из неверной категории, не считайте порядок партнёров или распределение
ролей. В остальных тройках нужен хотя бы один специальный, а не ровно
один. При m<n/3 ответ ноль; при m=n/3 в каждой тройке ровно один,
что формула учитывает автоматически. C(0,0) равно 1.
Даже найдя №1, дочитайте оставшиеся идентификаторы.

## Особенности языков

Достаточно знаковых 32-битных целых: ответ не больше C(998,2)=497503,
промежуточное a(a−1) меньше миллиона. В Go используется int,
в Rust — i32 для количеств, в Python — целые. До умножения проверьте
доступность категории: обычных партнёров может не быть совсем.
Факториалы, модули, вещественные и длинные числа не требуются.
