# 1972. Самый длинный путь между двумя наборами опций

[Timus 1972](https://acm.timus.ru/problem.aspx?space=1&num=1972) · difficulty 3341 · constructive

Автор оригинальной задачи — Идея — Александр Ипатов; XVII Открытый чемпионат Урала по спортивному программированию (май, 2013).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Конфигурация — подмножество n независимо переключаемых опций. Нужно
начать с данного набора, закончить другим и на каждом шаге менять
ровно одну опцию. Ни одна конфигурация не повторяется. Максимизируйте
число посещённых конфигураций, включая оба конца, и выведите маршрут.
Концы различны, решение существует. Ограничения: 1 секунда, 64 МБ.

## Входные данные

n, 1≤n≤16. Следующие две строки задают концы: k и k включённых индексов,
где 0≤k≤n и 1≤a₁<…<aₖ≤n.

## Выходные данные

Максимальное число m, затем m конфигураций в порядке посещения: количество
и возрастающий список включённых индексов. Первая и последняя совпадают
с заданными. Принимается любой оптимальный маршрут.

## Проверка

Проверяющая программа убеждается, что каждый шаг меняет ровно одну
опцию, конфигурации не повторяются, а длина пути наибольшая возможная:
2ⁿ для концов разной чётности и 2ⁿ − 1 иначе. Принимается любой такой
путь.

## Примеры

```
2
0
2 1 2
```

```
3
0
1 2
2 1 2
```

## Решение

Представим набор n-битным числом. Конфигурации образуют булев куб:
ребро меняет один бит. Раскрасим вершины по чётности числа единиц.
Каждое ребро меняет цвет, в каждом классе 2ⁿ⁻¹ вершин. Поэтому путь
между разными цветами содержит не более 2ⁿ вершин, между одинаковыми —
не более 2ⁿ−1. Построим пути, достигающие обеих границ.

### Деление на два меньших куба

Подзадача хранит концы a,b и маску свободных координат; остальные биты
зафиксированы. Если свободна одна координата, возвращаем оба конца,
если они различны, иначе одну вершину. Равные концы нужны лишь в листе
рекурсии.

Иначе выбираем различающуюся координату d. Удалив её, получаем половину
с a и половину с b. Возьмём другую свободную координату e, положим
u=a XOR 2ᵉ, v=u XOR 2ᵈ. Строим путь a→u в первой половине, затем
v→b во второй. Переход u→v меняет ровно координату d.

Нужно исключение: если v=b, а свободных координат не меньше трёх,
выберем другое e. Равенство означает, что исходные концы различались
только в d и e, поэтому любая другая оставшаяся координата даст v≠b.
При двух свободных координатах равенство разрешаем: вторая половина
тогда даёт единственную конечную вершину.

### Полнота и оптимальность

a и u всегда разной чётности, поэтому по индукции первый путь проходит
все 2ⁿ⁻¹ вершин половины. Ещё одно изменение d даёт v той же чётности,
что a. Если a и b различной чётности, такими же являются v и b:
вторая половина проходится целиком, всего 2ⁿ вершин.

При одинаковой чётности a,b она одинакова у v,b. Правило исключения
оставляет их различными, если размерность половины не меньше двух.
По индукции во второй части 2ⁿ⁻¹−1 вершин. Для родительского квадрата
равные концы одномерного листа дают одну вершину, что согласуется с
формулой. Итого 2ⁿ−1. Половины не пересекаются, поэтому повторов нет.
Рекурсия меняет лишь свободные координаты, сохраняет концы и завершается.
Обе верхние границы достигнуты.

Построение масок требует `O(2^n)` времени и памяти, глубина — `O(n)`.
Форматирование списков занимает `O(n·2^n)` времени. С буфером текста
память может достигать `O(n·2^n)`; сам числовой путь требует `O(2^n)`.

В примере пустой набор и {1,2} имеют чётное число опций. Посетить между
ними все четыре состояния нельзя, но три можно: пустой → {2} → {1,2}.
Сначала меняется опция 2, затем 1. Длина три достигает границы.

Считаются состояния, а не переходы. Для одинаковой чётности нужен путь
2ⁿ−1, а не кратчайший. Не допускайте v=b в половине размерности не
меньше двух: одна вершина потеряет большую часть ответа. Равный
одномерный лист, напротив, необходим. Удаляйте разделяющий бит из
обеих рекурсивных масок. Индексы выводятся по возрастанию. Большие
ответы генерируйте, даже если вход состоит всего из нескольких чисел.

## Особенности языков

Все версии используют целые маски и младший установленный бит. Rust
применяет wrapping-отрицание беззнаковой маски, C++ — беззнаковые маски,
Go и Java — неотрицательные целые, Python — целые произвольной длины.
Java заранее выделяет массив пути. Глубина до 16 не требует изменения
лимита рекурсии.
