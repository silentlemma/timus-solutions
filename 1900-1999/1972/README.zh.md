# 1972. 两个位集合之间的最长不重复路径

[Timus 1972](https://acm.timus.ru/problem.aspx?space=1&num=1972) · difficulty 3339 · constructive

原题作者 Idea by Alexander Ipatov，出自 2013 年乌拉尔体育编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个配置是 n 个独立开关选项的子集。从给定集合开始，到另一个集合
结束，每步恰好改变一个选项，配置不能重复。最大化访问配置数，
包括两个端点，并输出相应序列。端点不同，保证有解。限制：1 秒，64 MB。

## 输入

n，1≤n≤16。后两行分别为起点、终点：k 后接 k 个已启用选项编号，
0≤k≤n，1≤a₁<…<aₖ≤n。

## 输出

先输出最大数量 m，再输出 m 个配置，格式均为数量及递增编号列表。
首尾等于输入端点。任意最优序列都可接受。

## 评测方式

检查器确认每一步恰好改变一个选项、没有重复的配置，并且路径长度达到最大：两端奇偶性不同时为 2ⁿ，否则为 2ⁿ − 1。任何这样的路径都被接受。

## 样例

```
2
0
2 1 2
```

```
3
0
1 2
2 1 2
```

## 解法

用 n 位整数表示集合，所有配置构成超立方体，边翻转一位。按置位数
奇偶染色，每边改变颜色，两色各有 2ⁿ⁻¹ 顶点。异色端点至多访问
2ⁿ 顶点，同色至多 2ⁿ−1。下面构造达到两种界的路径。

### 分成两个较小立方体

维护端点 a,b 和自由坐标掩码，其他位固定。若仅一自由坐标，端点
不同返回两个，相同只返回一个；相同情形只在递归叶子需要。

否则选 a,b 不同的一位 d。删除 d 后，两半分别含 a、b。另选自由
坐标 e，令 u=a XOR 2ᵉ，v=u XOR 2ᵈ。递归构造第一半 a→u，再接
第二半 v→b，连接 u→v 恰改变 d。

关键例外：若 v=b 且至少三位自由，就换另一个 e。相等说明原端点
只在 d、e 不同，换另一剩余坐标必使 v≠b。若只有两维则允许相等，
第二半只贡献终点一个顶点。

### 正确性与最优性

a、u 总是异奇偶，归纳可遍历第一半全部 2ⁿ⁻¹ 顶点。再翻 d 后，
v 与 a 同奇偶。若原端点异奇偶，v、b 也异奇偶，第二半全部遍历，
总长 2ⁿ。

若原端点同奇偶，v、b 也同奇偶。例外规则保证第二半维数至少二时
它们仍不同，归纳得 2ⁿ⁻¹−1 顶点。父问题仅二维时，一维相同端点
叶子贡献一，仍合公式。总长 2ⁿ−1。两半不相交，无重复；只改变
自由位，保留端点并最终终止，故两种上界均达到。

构造数值路径时间、空间均 `O(2^n)`，递归深度 `O(n)`。格式化各
启用编号列表时间 `O(n·2^n)`。缓冲输出文本时总空间可为 `O(n·2^n)`，
数值路径本身仍 `O(2^n)`。

样例空集与 {1,2} 均偶数置位，不能访问全部四个状态，但可访问
空集 → {2} → {1,2} 三个。依次翻选项 2、1，达到长度三的上界。

计数是配置数而非边数。同奇偶需最大 2ⁿ−1，不是最短路。第二半
维数至少二时不能 v=b，否则只输出一个顶点会浪费大量顶点；一维
同端点叶子则必要。两次递归都删除分割位。输出编号递增。即使输入
极小，大输出也应生成，不能作为大型静态测试答案保存。

## 各语言说明

五版均用整数掩码提取最低置位。Rust 对无符号值使用 wrapping
负号，C++ 用无符号掩码，Go、Java 用非负整数，Python 用任意精度
整数。Java 预分配路径数组。深度至多 16，无需调整递归限制。
