# 1994. 在夜间损失之间选择最优随机排除人数

[Timus 1994](https://acm.timus.ru/problem.aspx?space=1&num=1994) · 难度 1050 · dp, probability, combinatorics

原题作者 Denis Dublennykh（由 Eugene Kurpilyansky 整理）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`n` 个活跃成员中有 `k` 个敌对成员，其余为普通成员。每晚每个敌对成员可消除一个普通成员，安排总使消除数最大，所以损失为两种人数的较小值。每个随后的白天，选择一个正数作为排除人数，具体身份均匀随机。被排除者不再行动，也不计入最终人数。最优选择每日数量，使损失停止或普通成员全部消失时，仍活跃的普通人数期望最大。

初始是晚上，第一次夜间损失发生在首次排除之前。不能指定身份。`1≤k≤min(n,20)`、`n≤200`。时间限制 1 秒，内存限制 64 MB。

## 输入

两个整数 `n k`。

## 输出

一个实数：最终普通人数的最优期望，而非存活概率。

## 评测方式

数值按 10⁻⁶ 的绝对或相对误差比较。

## 样例

输入：

```
4 1
```

输出：

```
0.6666666667
```

第一晚将 `(4,1)` 变为白天的三人、一名敌对成员。排除一人有 `1/3` 概率保住两个普通成员，否则下一晚消除最后一个，期望为 `2/3`。

## 解法

### 白天状态动态规划

定义 `V(N,K)` 为白天排除前的最优期望，边界 `V(N,0)=N`、`V(N,N)=0`。虽然身份隐藏，人数足够描述决策：只要一晚后还有普通成员，死亡数就等于剩余敌对数；若普通成员全死，收益已为零，无须推断。

枚举保留人数 `t<N`。保留集合均匀随机，其中敌对数 `j` 服从超几何分布。`j=0` 时收益 `t`；`t≤2j` 时下一晚普通成员全灭；否则下一白天共有 `t−j` 人、其中 `j` 名敌对者。

`P(j)=C(K,j)·C(N−K,t−j)/C(N,t)`

`V(N,K)=max[1≤t<N] Σ[max(0,t−(N−K))≤j≤min(K,⌊(t−1)/2⌋)] P(j)·V(t−j,j)`

`j=0` 项使用 `V(t,0)=t`，省略项收益为零。保留零人也仅得零，可跳过。按 `N` 递增计算，因为 `t−j<N`。组合数用 Pascal 三角形；程序先累加带组合计数的分子，再对每个行动除一次公共 `C(N,t)`。

原问题在 `n≤2k` 时答案为零，否则为第一晚后的 `V(n−k,k)`。不能因为内部白天状态中敌对者占多数就置零：`V(2,1)=1/2`，随机排除有机会移除敌对者。也不能只排除一人；白天 `(5,2)` 保留三人得到 `0.6`，保留四人只有 `4/15`。

均匀保留给出所列概率，每种剩余组成都有上述夜间结果。更小状态已经包含最优未来期望，因此条件加权平均得到每个允许行动的价值。枚举全部正排除数取最大即为最优。按人口数归纳证明表格，再单独处理初始夜晚。随机选择行动数量也不会超过其确定行动价值的最大值。

令 `M=n−k`，只需计算至 `M`、敌对数至 `k`。时间 `O(M²k²)`，空间 `O(M²+Mk)`。初始零情况直接返回，最大输入只有数百万项。

200 以内组合数小于 `10⁶⁰`，分子和小于 `10⁶²`，double 不溢出。所有求和项非负。标准就近舍入下 Pascal 相对误差 `γ₂₀₀<2.3·10⁻¹⁴`；两个系数、至多 21 项及一次除法，使单行动相对数值误差保守地小于 `10⁻¹³`，另计已有表误差。期望的非负权重和不超过 1，最大运算是 1-Lipschitz。不到 200 次转移后绝对误差小于 `200((1+10⁻¹³)²⁰⁰−1)<5·10⁻⁹`。这些范围的正项不下溢。输出 12 位小数再增加至多 `5·10⁻¹³`。

## 各语言说明

五种版本使用相同递增人口 DP 和 double。Java 固定输出区域设置，Go 兼容 1.14。Python 将公共分母移出内循环。必须区分白天与首夜，允许一次排除多人；当保留数超过普通人数，`j` 下界为 `max(0,t−(N−K))`。
