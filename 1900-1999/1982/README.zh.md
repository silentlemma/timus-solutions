# 1982. 每个分量包含供给点的最小森林

[Timus 1982](https://acm.timus.ru/problem.aspx?space=1&num=1982) · 难度 128 · graphs, greedy

原题作者 Mikhail Rubinchik，出自 2013 年乌拉尔联邦大学公开团体锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 `n` 个顶点的完全无向图，其中 `k` 个顶点已经是供给点。选择总费用最小的边集，使每个顶点都能到达至少一个供给点。各供给点可以属于不同连通分量。

所有输入值均为整数，`1≤k≤n≤100`。费用矩阵对称，主对角线为零，其余元素为 1 到 `10⁵`。时间限制 0.5 秒，内存限制 64 MB。

## 输入

读入 `n k`、`k` 个互不相同且位于 1 到 `n` 的供给点编号，再读入 `n×n` 费用矩阵。

## 输出

一个整数，表示最小总费用。

## 评测方式

按记号逐个比较输出。

## 样例

输入:

```
4 2
1 4
0 2 4 3
2 0 5 2
4 5 0 1
3 2 1 0
```

输出:

```
3
```

## 解法

添加一个虚拟顶点，向所有供给点连费用为零的边。增广图的最小生成树即可给出答案。任何原图可行网络加上这些零边都会连通，因此增广生成树的费用不会更大。反过来，删除增广生成树中的虚拟顶点后，每个分量都含有一个供给点，且原有付费边总费用不变。因此两个问题的最优值相等。

无需显式建立虚拟顶点，直接使用稠密 Prim。所有供给点的初始键值设为零，其余设为无穷大，这恰好等于处理完虚拟顶点后的状态。每轮选择未使用顶点中键值最小者，把键值加入答案，再用对应矩阵行更新其余未使用顶点。

键值表示连接到已处理增广树部分的最便宜边。根据割性质，每次选择都是安全的。初始化包含全部供给点，所以所有现有供给都被正确计入。处理全部顶点后，累加值等于增广图最小生成树费用，也就是原问题最优值。

也可从有根森林理解：正费用环可以删除。若一个树含多个供给点，可删除两供给点路径上的一条边，使两部分各保留供给点。因此最优解可恰有 `k` 个分量与 `n−k` 条付费边；`k=n` 时费用为零。

样例选择费用为 2 的边 1–2 和费用为 1 的边 3–4，每个分量都有供给点，总费用为 3。

共进行 `n` 次最小键扫描和 `n` 次行更新，每次 `O(n)`，总时间 `O(n²)`。矩阵占 `O(n²)` 空间，键值和标记另占 `O(n)`。答案至多为 `(n−k)·10⁵≤9,900,000`。

注意事项：

- 所有供给点的初始键都应为零，与输入顺序无关。
- 未供给顶点不能提前获得零键值。
- 未供给顶点之间连边也可能降低总费用。
- 矩阵对角线的零不是不同顶点间的免费边。
- 全部顶点都是供给点时，不需要付费边。
