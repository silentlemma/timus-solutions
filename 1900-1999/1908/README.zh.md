# 1908. 动态剪枝选择树的点击代价

[Timus 1908](https://acm.timus.ru/problem.aspx?space=1&num=1908) · difficulty 2071 · dp, trees

原题作者 Denis Dublennykh，准备 Alexander Fetisov，比赛 Ural Championship 2012。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

每个字符串表示从树根到一个结局的选择序列。需要访问所有结局；到达结局后
免费回到树根。当某个子树的结局全部访问完，它对应的选项就会消失。
选择一条可用边花一次点击。另一个按钮也花一次点击，可沿当前唯一的路径
跳到最近的分支或结局；在分支上按此按钮没有效果。求最少总点击次数。
时间限制 1 秒，内存限制 64 MB。

## 输入

先给 n，1≤n≤100 000，再给出 n 个非空小写拉丁字母串。
没有字符串是另一个的前缀，总长度 S≤100 000。

## 输出

输出访问全部结局的最少点击次数。

## 评测方式

一个精确整数，按标记比较。

## 样例

```
3
aza
azc
b
```

```
4
```

## 解法

建立字典树。每个节点 v 记录叶子数 N[v]，以及两种代价：A[v] 每次正常
进入，B[v] 每次进入时已提供一次免费初始跳过，包括到达结局后的重新开始。
免费跳过只在进入时沿唯一链到当前第一个分支或结局，不会在后续选择后再次
提供。叶子上 N=1，A=B=0。

最优顺序可以逐个完成子树。取包含最终结局的孩子，把它的所有较早访问移到
其他孩子之后，同时保持各孩子内部的访问顺序。其他孩子仍然看到最后一个
选项可用，因此进入代价不增；被移动的访问只会更早获得唯一链跳过机会。
其余孩子也可以递归地分组。

访问非最后的孩子 c 时，本节点仍是分支，每个结局付一次选择，再付子树
正常代价，总计 N[c]+A[c]。最后的孩子在正常进入模式下，每个结局付一次
跳过，这也提供了孩子的初始跳过，总计 N[c]+B[c]；若进入时已经提供跳过，
则只需 B[c]。令 T=Σc(A[c]+N[c])，得到：

```text
N[v] = sum N[c]
A[v] = T - max (A[c] - B[c])
B[v] = T - max (N[c] + A[c] - B[c])
```

两个最大值必须独立选择。对于 aa,ab,ac,ad,bxa,bxb，根的 A=11、B=8，
对应的最后孩子不同。在所有串前添加 z 后，实际答案为 6+8=14。
相同公式适用于只有一个孩子的节点，可把任意长的唯一链合为一次跳过。
最终答案是根的 A。

新节点编号总大于父节点，故按编号逆序进行动态规划，无须递归，即使字符串
长达 100 000 也不会栈溢出。用兄弟链表保存孩子，每次查找至多检查 26 个
字母。固定字母表下，建树和动态规划均为 O(S) 时间，空间 O(S)。按原始路径
逐次点击也只需至多 S 次，因此所有计数和中间和均适合 32 位整数。

示例先选择 b，跳到剩余的 a/z 分支，再选择 c，最后一次跳过完成唯一剩余
路径，总计四次点击。

## 各语言说明

五种实现都使用迭代插入和逆序动态规划。C++、Go 1.14、Rust 1.75 使用
节点记录；Java 8 使用基本类型数组和缓冲输入。Python 3.12 使用紧凑整数
数组及字节标签，不为每个节点建立字典或长度为 26 的列表。输入字符串仅占
O(S) 空间，不使用深度随字符串长度增长的递归。

在 978 个测试上，答案与对界面状态做 BFS 的结果一致，其中包括所有长度不超过三的二进制无前缀串集合。
