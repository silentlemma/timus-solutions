# 1916. 指数长字符串中的短片段

[Timus 1916](https://acm.timus.ru/problem.aspx?space=1&num=1916) · difficulty 3024 · strings

原题作者 Ivan Burmistrov（由 Dmitry Ivankov 准备），出自 NEERC 2012 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n 种符号中，每种要么稳定，要么有唯一固定替换序列，按从底到顶排列。
不断替换不稳定符号，保证任意类型最终都只剩稳定符号。
可以从任意一个类型开始。统计所有最终字符串中长度恰好为 k 的
不同连续片段，重复出现只计一次。限制：1 秒，64 MB。

## 输入

n,k 都在 [2,100]。随后依次描述类型 1..n：稳定类型用 −1；
否则给出长度 1≤kᵢ≤100 与 kᵢ 个 [1,n] 中的类型编号，保持给定顺序。
全部替换长度之和 E≤100。

## 输出

不同长度 k 片段数量模 1 000 000 007。所有字符串都太短时输出零。

## 评测方式

精确比较一个整数词元。

## 样例

```
7 3
3 3 2 2
3 4 5 5
1 7
-1
-1
3 7 7 7
-1
```

```
5
```

## 解法

依赖图无环，否则非空替换循环永远无法终止。使用记忆化深搜，
每种类型只存至多 k−1 个符号的前缀和后缀。稳定类型对应自己的
单个符号。不要展开完整串：50 次倍增就能得到 2⁵⁰ 的长度。

按顺序拼接一个规则的孩子。把 B 接到当前累计串 A 后，构造
suffix(A,k−1)+prefix(B,k−1)，将此短窗口的全部长度 k 子串加入
全局集合。两半都短于 k，因此每个候选确实跨越这条边界。
新前缀取两个前缀拼接后的前 k−1 个符号；新后缀取两个后缀
拼接后的最后 k−1 个符号。更新后缀时必须使用孩子的后缀。

### 正确性

A+B 的长度 k 子串要么在 A 内、在 B 内，或跨越连接处。
前两类已在此前或递归处理中收集；跨界子串在两边各用至多 k−1
个符号，必在短窗口中。反之窗口里的长度 k 子串都是真实跨界片段。
前后缀更新保持摘要准确。对依赖图和孩子拼接顺序归纳即可证明
收集集合恰好正确。遍历全部类型包含所有起始选择，全局集合去重。

### 复杂度与表示

每个边界至多 k−1 个候选，总孩子连接次数≤E，故候选插入次数
≤E(k−1)≤9900。复制、哈希完整键需要 `O(k)`，所以期望时间
`O(Ek² + nk)`，空间 `O(Ek² + nk)`。这里计入键的实际长度。
给定限制下答案本来就小于模数，程序仍按要求取模。

类型编号≤100，可编码成单个字节。集合保存完整字节串或字符序列，
哈希碰撞仍会比较完整内容，不会把不同词混为一谈。记忆化处理
前向引用和共享后代。

样例的五种串为 777、455、745、554、545；455 的再次出现不增加答案。

统计不同词而非出现次数或推导路径，包含所有起始类型。
左摘要必须累计：片段可能跨越多个短孩子，而非仅相邻两个。
注意顺序、不同稳定编号、单孩子别名、过大的 k，以及孩子前后缀的区别。

## 各语言说明

Python 用 `bytes`，C++/Go 用字节串，Java 用字符字符串，Rust 用
字节向量，均使用精确集合。递归深度≤100。Go 的不可变键可能共享
短窗口存储，Rust 会复制键。没有版本展开指数长度的完整串，也不把
滚动哈希当作字符串身份。
