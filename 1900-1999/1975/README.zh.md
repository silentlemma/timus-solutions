# 1975. 标记球面点集的旋转计数

[Timus 1975](https://acm.timus.ru/problem.aspx?space=1&num=1975) · 难度 4177 · geometry

原题作者 Denis Dublennykh，出自 2013 年乌拉尔体育编程锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

以原点为中心的单位球面上有 n 个标记。统计绕球心的三维正旋转，
使每个标记的像与某个标记的欧氏距离不超过 10⁻⁶。恒等旋转也计入。
产生相同点排列的旋转只计一次；不允许反射。时间限制为 1 秒，内存为 64 MB。

## 输入

第一行为 n，3≤n≤200。接下来 n 行给出 x、y、z 坐标，每个数最多有九位小数。
点位于单位球面上，任意两个不同点的距离至少为 10⁻⁵。
计算距离时保留原坐标；归一化仅用于方向和正交基的构造。

## 输出

输出一个整数，表示能由合法旋转产生的不同排列数。

## 评测方式

按记号逐个比较输出。

## 样例

```
3
0 1 0
1 0 0
0 0 1
```

```
3
```

## 解法

### 枚举条件较好的基准点对

令 ε=10⁻⁶。取第一个单位方向 a，再选使 s=|a×b| 最大的方向 b。
至少三个互相分离的点保证 s>0，即使点几乎落在同一条轴上也是如此。
构造右手基 z=a、y=(a×b)/s、x=y×z，并将未归一化的原始点投影到该基。

枚举不同的目标点有序对 P,Q。设 e=ε/min|point|、η=2 asin(e/2)。
目标夹角 β 与源夹角 α 的差必须不超过 2η。先检查正弦、余弦的必要条件，
再检查角度；10⁻¹² 的余量只用于这些筛选，不用于接受旋转。

目标基确定一个正的标准旋转 R₀：它将 a 精确送至 P，并将 b 送至 Q 的方位角。
任何可行旋转可写成 T H R₀，其中 T 使 P 倾斜至多 η，H 绕 P 转 θ。
若 t=sin β，则 |sin(θ/2)|≤e/√(st)。由于所有源点相对 a 的横向半径至多为 s，
其标准像到真实目标的距离至多为 ε+rmax·e·(1+2√(s/t))。
最小点间距给出 s≥约 5·10⁻⁶，且 t≥s−2e；考虑九位小数的舍入后，该界仍小于 5ε。

因此 5ε 内最近的标记恰是真实目标：其他标记彼此至少相距 10ε。
采用边长 10ε 的空间哈希，将每个标记加入其周围 27 个桶。
每个标准像只查一个桶即可找到所有候选。若没有目标或目标重复，则丢弃该点对。
用集合保存已接受的排列，避免重复计数。

### 必须验证旋转可行性

标准旋转未必就是可行旋转。例如四点 (1,0,0)、(−δ,1,0)、(−1,0,0)、(δ,−1,0)，
在 δ=0.9ε 时允许四分之一周旋转，但精确对齐两点的标准旋转误差可达 1.8ε。
仅测试 R₀ 会漏解。最小二乘也不足以决定答案，因为平方和最小不等于最大误差最小。

先尝试一次三参数旋转修正，再进行加权最小二乘迭代。将轴向参数按 s 缩放，
可以改善极区点集的条件数。将所有修正合成为一个归一化四元数，始终作用于原始点。
只有当某个显式正旋转的所有误差不超过 ε 加舍入保护时才接受。

细分前保留累积权重：将各权重乘以 exp((dᵢ/max d−1)/2)，归一化后重新拟合。
这样能平衡最大的平方误差，避免独立重新赋权产生的振荡。
拒绝证书使用 ε² 加证书舍入余量；较大的见证保护仅用于接受。
测试 **02** 的陷阱是几乎互为对跖点的三点：容差边界上存在可行的半周旋转，
但最小二乘和独立赋权会导致过多细分。

迭代失败不能作为拒绝理由。可以用点对夹角的必要条件排除候选。
另一种证书采用非负权 wᵢ、当前像 pᵢ、目标 qᵢ：
F=Σwᵢ|pᵢ−qᵢ|²，g=Σwᵢ pᵢ×(qᵢ−pᵢ)，
H=Σwᵢ[(pᵢ·qᵢ)I−(pᵢqᵢᵀ+qᵢpᵢᵀ)/2]。
若 H 最小特征值的保守下界 λ>0，则任意旋转的加权误差至少为 F−|g|²/λ。
仅当此下界在保留舍入余量后仍超过 ε²Σwᵢ 时拒绝。Jacobi 旋转与 Gershgorin
圆盘下界共同产生 λ；λ 非正时跳过此证书。

### 对未决定的候选进行完整细分

在目标基中，以新轴方向 (u,v,1)/√(1+u²+v²) 参数化倾斜。
所有可行解均在 |u|,|v|≤tan η、|θ|≤2 asin(min(1,e/√(st))) 内。
先绕轴转 θ，得到 (x,y,z)，再令 c=1/√(1+u²+v²)、d=ux+vy、h=cz−c²d/(1+c)。
倾斜后的坐标是 (x+uh,y+vh,c(z−d))，仍由一个正旋转产生。

若参数盒的半宽为 hu、hv、hθ，点的模长为 r，横向半径为 ρ，则盒中任意像
到盒中心像的距离至多为 2r√(hu²+hv²)+ρhθ。如果某个中心误差减去此界仍大于
ε+10⁻¹⁶，则整个盒不可行。否则验证中心，或二分缩放后半宽最大的参数。
优先队列先访问误差下界最小的盒。没有节点数上限，也不会接受尚未判断的盒。
当移动界小于舍入保护的四分之一时，任何未被排除的中心都应通过显式验证，
因此边界不会导致无限细分，更不会把 5ε 候选半径当成最终容差。

每个合法排列都确定一个被枚举的基准像点对；5ε 界找回它的全部真实目标，
参数盒又包含对应旋转。每个接受的排列都有显式正旋转见证，而所有排除条件都是
必要条件或保守下界。由此得到完整性与正确性，但须保留前述 binary64 舍入带说明。

样例中，恒等排列和两个正坐标轴的循环排列都是正旋转。
其余三个排列改变空间定向，因此答案是 3。

若总共访问 B 个搜索盒，时间为 `O(n³+nB+B log(B+1))`：
至多 n(n−1) 个候选在细分前各用线性时间。若接受 A 个排列，同时存活 H 个盒，
空间为 `O(n²+nA+H)`。细分是自适应的，可能呈指数增长；这里不声称容差可行性
具有统一的多项式最坏时间界。

不要计入反射，也不要假设近似对称排列构成群。不能把精确基对齐失败或最小二乘
失败当成不可行。近乎平行时使用叉积建立基，距离检查使用原坐标。
最终见证的容差是 ε；快速迭代耗尽后必须继续带证书的搜索。

C++ 使用有序 map 和 set，因此时间界为
`O(n³ log(n+1)+nB+B log(B+1))`；其他版本保留上述时间界。

## 各语言说明

五个程序仅使用标准库，采用相同的完整搜索。所有修正均使用归一化四元数。
C++ 用 long double 累加证书项，Go、Java、Rust 用补偿求和，Python 用 math.fsum。
这些措施控制舍入误差，不改变 ε。
