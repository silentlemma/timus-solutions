# 1919. Прямоугольная заплата из цилиндра

[Timus 1919](https://acm.timus.ru/problem.aspx?space=1&num=1919) · difficulty 2068 · geometry

Автор оригинальной задачи — Дмитрий Иванков; NEERC 2012, четвертьфинал Восточного подрегиона.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть прямоугольное отверстие со сторонами w и h. Для каждого цилиндра
нужно определить, можно ли вырезать из боковой поверхности один связный
кусок, распрямить без растяжения и полностью закрыть отверстие.
Разрешён поворот; кусок может идти по спирали вокруг цилиндра.
Основания использовать нельзя. Цилиндр задан высотой H и длиной
окружности L, а не диаметром. Лимиты: 1 секунда, 64 МБ.

## Входные данные

В первой строке w,h, далее число n. Следующие n строк содержат H,L
соответствующего цилиндра именно в таком порядке. Все длины целые
от 1 до 1 000 000; 1≤n≤1000.

## Выходные данные

Для каждого цилиндра по порядку вывести `Block the hole`, если заплата
возможна, иначе `Too small`. Равенство допустимо: можно касаться
торцов и разрезанного шва.

## Проверка

Сравниваются токены с учётом регистра. Каждая фраза выводится
на отдельной строке.

## Примеры

```
314 314
4
314 314
314 313
600 500
234 3456
```

```
Block the hole
Too small
Block the hole
Too small
```

## Решение

Развернём цилиндр в плоскость с горизонтальным периодом L и вертикальной
полосой высоты H. Прямоугольник должен помещаться по высоте.
Каждое горизонтальное сечение должно быть не длиннее L: иначе две
внутренние точки на расстоянии L окажутся одним участком материала.
Обратно, при таком ограничении внутренние точки не склеиваются при
сворачивании; связный прямоугольник можно вырезать. Любой больший
покрывающий кусок разрешено обрезать до нужного прямоугольника.

Полная горизонтальная проекция может превышать L: разные высоты
используют разные витки. Например, отверстие 1×1000 закрывается
цилиндром H=11,L=100, хотя плоский лист 100×11 не подходит.

Пусть сторона w образует с горизонталью угол θ∈[0,π/2],
c=cos θ,s=sin θ. Высота равна Y=w s+h c. Самое длинное горизонтальное
сечение проходит через центр по симметрии и выпуклости; его длина
min(w/c,h/s), при нулевом знаменателе соответствующая граница бесконечна.
Значит, ограничение длины окружности имеет вид

```text
w ≤ L cos θ  ИЛИ  h ≤ L sin θ.
```

Каждая ветвь задаёт замкнутый интервал углов, прилегающий к 0 или π/2.
Функция Y вогнута: Y''=−Y<0. Минимум на каждом таком интервале достигается
на конце. Достаточно проверить осевые положения и углы, в которых
ограничение сечения обращается в равенство.

Проверим пары (A,B)=(w,h),(h,w). Ветвь A≤L cos θ существует лишь при
A≤L. Осевой конец подходит при B≤H. На другом конце cos θ=A/L,
а необходимая высота равна

```text
A (B + sqrt(L²−A²)) / L.
```

Обозначим T=HL−AB. После предыдущих проверок этот конец подходит
тогда и только тогда, когда T≥0 и T²≥A²(L²−A²). Проверка знака нужна
до возведения в квадрат. Все сравнения нестрогие и целочисленные.
Подходит хотя бы одна пара — ответ положительный. Аргумент о минимумах
на концах доказывает, что других полезных углов не осталось.

O(n) операций над ограниченными целыми и O(1) рабочей памяти геометрии.
При буферизации полного ввода или вывода общая память O(n).

Стороны отверстия менять местами можно, H и L — нельзя: роли различны.
L уже является длиной окружности. Площади недостаточно: 3×11 не
помещается при H=7,L=5. Проверка ограничивающего прямоугольника теряет
спиральные заплаты. Не теряйте знак T и допускайте равенство,
включая A=L с нулевым подкоренным выражением.

## Особенности языков

HL,AB,A²,L² помещаются в 64 бита, но итоговые произведения достигают
10²⁴. C++ расширяет тип до `__int128` перед умножением, Rust использует
`u128` с проверкой перед вычитанием. Go 1.14 получает старшее и младшее
слова через `math/bits.Mul64` и сравнивает их лексикографически.
В Java 8 финальные произведения вычисляются через `BigInteger`,
в Python целые имеют произвольную точность. Тригонометрии, корней
и допусков в программах нет.
