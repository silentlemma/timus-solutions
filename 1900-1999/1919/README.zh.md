# 1919. 从圆柱侧面裁出矩形补片

[Timus 1919](https://acm.timus.ru/problem.aspx?space=1&num=1919) · difficulty 2080 · geometry

原题作者 Dmitry Ivankov，出自 NEERC 2012 东部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有一个边长为 w、h 的矩形洞。对每个圆柱，判断能否从其侧面裁出
一块连通材料，不拉伸地展平，再旋转放置，使其完全覆盖洞。
裁切路径可以绕圆柱呈螺旋状，不能使用上下底面。
圆柱由高度 H 和圆周长 L 给出；L 不是直径。
限制为 1 秒、64 MB。

## 输入

第一行是 w,h，下一行是 n。随后 n 行各含 H,L，顺序不能交换。
所有长度均为 1 到 1,000,000 的整数，1≤n≤1000。

## 输出

按输入顺序逐个输出：可以覆盖时为 `Block the hole`，否则为
`Too small`。允许恰好相等，包括碰到圆柱端部或裁开的接缝。

## 评测方式

按空白分隔的词元比较，大小写必须一致，每个短语单独占一行。

## 样例

```
314 314
4
314 314
314 313
600 500
234 3456
```

```
Block the hole
Too small
Block the hole
Too small
```

## 解法

把圆柱展开为横向周期 L、纵向高度 H 的平面条带。
矩形的纵向跨度不能超过 H；任一水平截段不能长于 L，否则
同一高度上相距 L 的两个内部点会对应同一块材料。反过来，
若所有截段都不超过 L，卷回圆柱时内部点不重合，这个连通矩形
就能裁出。若原补片更大，可以再修剪成目标矩形。

整体水平投影可以超过 L，因为不同高度能使用不同圈。
例如 1×1000 的洞可由 H=11,L=100 的圆柱覆盖，普通的 100×11
平面板却不行。

令 w 边与水平夹角 θ∈[0,π/2]，c=cos θ,s=sin θ。
纵向跨度 Y=w s+h c。由中心对称性与凸性，最长水平截段经过中心，
长度为 min(w/c,h/s)；分母为零时视为无穷。因此圆周条件为

```text
w ≤ L cos θ  或  h ≤ L sin θ。
```

每个分支的可行角度都是贴着 0 或 π/2 的闭区间。
Y''=−Y<0，所以 Y 在每个区间上为凹函数，最小值在端点取得。
只需检查水平/竖直放置，以及一个截段限制恰好取等号的角度。

分别取 (A,B)=(w,h) 和 (h,w)。分支 A≤L cos θ 只有 A≤L 时存在。
轴对齐端点在 B≤H 时可行。另一端点满足 cos θ=A/L，所需高度为

```text
A (B + sqrt(L²−A²)) / L。
```

令 T=HL−AB。在前述检查之后，此端点可行恰好等价于
T≥0 且 T²≥A²(L²−A²)。必须先检查符号再平方。
全部使用含等号的整数比较。任一顺序可行就输出肯定结果。
区间端点的最小值论证保证，拒绝两个分支后不存在遗漏的旋转角度。

O(n) 次有界整数运算，几何判定的额外空间为 O(1)。
缓存全部输入或输出的版本总空间为 O(n)。

洞的两边可以交换，圆柱的 H、L 不能交换。L 已是圆周长。
面积足够不代表可行：3×11 在 H=7,L=5 时仍失败。
用整体包围盒判断会遗漏螺旋补片。平方前保留 T 的符号，
并允许等号，包括 A=L 时根号项为零的情况。

## 各语言说明

HL、AB、A²、L² 均可放入 64 位，但最终乘积可达 10²⁴。
C++ 在乘法前转换为 `__int128`；Rust 用 `u128` 并在减法前检查大小。
Go 1.14 用 `math/bits.Mul64` 分别取得高低字，先比较高字再比较低字。
Java 8 用 `BigInteger` 计算最后的乘积，Python 直接使用任意精度整数。
正式程序不计算浮点角度、平方根或误差容限。
