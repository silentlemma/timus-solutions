# 1928. 交替拨款与终止赠款

[Timus 1928](https://acm.timus.ru/problem.aspx?space=1&num=1928) · difficulty 769 · games, dp

Original problem: folklore, prepared by Maria Zyryanova; from Ural Regional School Programming Contest 2012.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两人轮流申请 1 到 k 之间的整数款项，第一人先行动，初始公共预算为 n。
预算为零时，在下一次申请之前终止。足额申请从预算支付；不足时，
当前申请者仅获得独立赠款 m，公共预算不支出，游戏立即结束。
每人首先最大化自己的总收入；若自己的收入相同，再最小化对方收入。
求双方最优行动后的两笔总收入。限制：1 秒，64 MB。

## 输入

一行 n m k：0≤n≤10000，0≤m≤1000，1≤k≤100。

## 输出

两个整数，依次为先手与后手的总收入。

## 评测方式

精确比较两个整数记号。

## 样例

```
12 30 10
```

```
31 10
```

## 解法

对剩余预算 b，令 F[b] 为当前行动者的未来收入，G[b] 为另一人的未来收入。
过去已获得的款项对于后续各个选择都是常量，不改变偏好次序。
b=0 时无下一回合，两者均为零。

若申请可支付，1≤x≤min(b,k)，预算变为 b−x，双方角色交换，
候选收入对为 (x+G[b−x], F[b−x])。只有 0<b<k 时能提出合法但不可支付
的申请，此类申请全部对应终止候选 (m,0)，不会支付 x 或剩余预算 b。
选择第一分量最大的候选，第一分量相同时选第二分量最小的。
依次计算 b=1..n，输出 F[n],G[n]。

用归纳证明：假设更小预算的状态均代表最优后续行动。每个合法行动
要么以赠款结束，要么进入预算更小、角色互换的状态，因此候选对
准确表示该行动的收入。按规定偏好挑选就是当前状态的最优选择。
结合零预算的基础情况，算法正确。

时间 O(nk)，空间 O(n)。使用两个数组，最大范围至多考虑 1,000,000
个可支付候选。提交程序不递归搜索完整博弈树。

最大化收入差不能替代首先最大化自身收入。第二偏好确实重要：
n=5,m=2,k=3 时结果为 (3,2)，忽略相同收入时的比较会改变结果。
初始预算为零时答案 (0,0)，即使赠款很大。b=k 时不存在合法的超额申请。
超额申请只支付 m，既不支付申请额也不支付剩余预算，并立即终止。
正常支付后必须交换双方角色。

## 各语言说明

收入非负，两人合计不超过 n+m≤11000，故有符号 32 位整数足够。
Go 使用 int；Rust 将 usize 索引与 i32 收入分开；C++ 和 Java 使用 int；
Python 使用普通列表。内部初值 −1 仅表示尚无候选，不会输出。
这个受限动态规划可使用 CPython。
