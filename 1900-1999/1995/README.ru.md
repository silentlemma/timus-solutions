# 1995. Минимальный суммарный вес при заданном числе оставленных предметов

[Timus 1995](https://acm.timus.ru/problem.aspx?space=1&num=1995) · сложность 615 · greedy, constructive

Автор оригинальной задачи — Денис Дублённых; подготовка — Олег Долгоруков.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Постройте последовательность из `n` положительных целых весов. Первый
предмет всегда отбрасывается. На каждой следующей позиции `i` с нулевой
нумерацией подсчитываются строго меньшие веса среди всех `i` предыдущих
предметов. Предмет оставляется тогда и только тогда, когда их не меньше
`p` процентов от `i`. Учитываются и отброшенные предметы, включая
первый; равные веса не считаются меньшими.

Найдите минимальную сумму весов, при которой оставляется ровно `k`
предметов, и любой достигающий её порядок. `1≤k<n≤100000`, `1≤p≤100`.
Решение гарантировано. Лимит времени — 1 секунда, памяти — 64 МБ.

## Входные данные

Первая строка — `n k`, вторая — `p`.

## Выходные данные

В первой строке минимальная сумма, во второй — `n` положительных целых
весов в порядке обработки. Подходит любой оптимум.

## Проверка

Проверяющая программа сверяет число и сумму весов, сравнивает итог с
оптимумом и моделирует каждое решение; принимается любая оптимальная
последовательность.

## Примеры

Ввод:

```
3 1
50
```

Вывод:

```
4
1 2 1
```

Вес 2 оставляется, последний вес 1 отбрасывается. Программа может
вывести `1 1 2`: сумма тоже 4, оставлен один предмет. Меньше `n+k=4`
невозможно: каждый вес хотя бы 1, оставленный — хотя бы 2.

## Решение

### Построение

Пусть `D=n−k`. Сначала запишем `D` единиц, которые будут отброшены,
затем `k` оставляемых весов. Они получатся неубывающими. Для позиции
`i=D..n−1` требуется `q=ceil(p·i/100)` предыдущих строго меньших весов.
В отсортированном префиксе наименьший допустимый целый вес на единицу
больше `q`-го элемента:

`a[i]=a[(p·i−1)//100]+1`, при `a[0..D−1]=1`.

Индекс равен `q−1` и лежит в `0..i−1`, поскольку `i≥1`, `1≤p≤100`. Он не
убывает с ростом `i`, поэтому по индукции весь префикс остаётся
отсортированным. Первые `q` значений строго меньше нового. Значит
оставляются ровно последние `k` предметов.

### Минимальность

В любой допустимой последовательности заменим все отброшенные веса
единицами. Они останутся отброшенными; уменьшение этих весов не может
сократить число меньших перед неизменённым оставленным предметом. Сумма
не увеличивается.

Обменяем соседние оставленный вес `x≥2` и следующую отброшенную единицу.
Если раньше перед `x` было `i` предметов, из них `L` меньших, то
`100L≥pi`. После обмена станет `i+1` предметов и `L+1` меньших. Условие
сохраняется, так как `100≥p`. Единица всё равно отбрасывается, множества
предыдущих весов для всех более поздних позиций не меняются. Такими
обменами перенесём все отброшенные единицы в начало. Значит оптимум
указанного вида существует.

Сравним жадную последовательность `a` с любым допустимым хвостом `b`
после `D` единиц. Пусть ранее все `a` не больше соответствующих `b`.
Тогда и `q`-я порядковая статистика префикса `a` не больше. Чтобы
оставить `b[i]`, `q`-й элемент его префикса должен быть не больше
`b[i]−1`. Жадное значение, на единицу больше своей статистики, потому не
превосходит `b[i]`. Индукция даёт покоординатную минимальность и
минимальную сумму, даже если конкурирующий хвост не отсортирован.

## Особенности языков

По одному обращению к массиву на предмет: `O(n)` арифметических
операций, `O(n)` памяти и текст вывода. Вес не больше `i+1≤n`. Сумма
достигает `n(n+1)/2=5000050000` при `n=100000`, `k=n−1`, `p=100`,
поэтому нужны 64-битные накопители. Произведение `p·i` помещается в 32
бита. В Python сумма целая неограниченная, остальные версии используют
широкий тип.

Нельзя включать текущий предмет в знаменатель, учитывать только ранее
оставленные, считать равные веса меньшими или менять процентное `≥` на
`>`. Дерево для подсчёта меньших весов нужно только проверяющей программе;
само построение линейное. Обмены доказывают вид оптимума, но программа их не
выполняет.
