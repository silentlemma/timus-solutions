# 1995. 指定保留数量时的最小总重量

[Timus 1995](https://acm.timus.ru/problem.aspx?space=1&num=1995) · 难度 614 · greedy, constructive

原题作者 Denis Dublennykh（由 Oleg Dolgorukov 整理）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

构造 `n` 个正整数重量。第一个物品总被丢弃。对之后的零基位置 `i`，数出全部 `i` 个先前重量中严格较小的个数；当且仅当至少占 `p` 百分比时保留当前物品。先前丢弃的物品和第一个也计算，相等不算较小。

要求恰保留 `k` 个，使总重量最小，输出任意最优顺序。`1≤k<n≤100000`，`1≤p≤100`，保证可行。时间限制 1 秒，内存限制 64 MB。

## 输入

第一行 `n k`，第二行 `p`。

## 输出

第一行最小总重量，第二行按处理顺序的 `n` 个正整数。任意最优解均可。

## 评测方式

检查器核对重量的个数与总和，将总和与最优值比较，并逐一模拟每个决定；任何最优序列都被接受。

## 样例

输入：

```
3 1
50
```

输出：

```
4
1 2 1
```

重量 2 被保留，最后的 1 丢弃。程序也可输出 `1 1 2`，总重同为 4，恰保留一个。每项至少 1、保留项至少 2，所以不可能低于 `n+k=4`。

## 解法

### 构造

令 `D=n−k`，先放 `D` 个会丢弃的 1，再构造 `k` 个保留项，重量保持非递减。位置 `i=D..n−1` 需要 `q=ceil(p·i/100)` 个严格更小的前项。在有序前缀中，最小合法整数恰为第 `q` 项加一：

`a[i]=a[(p·i−1)//100]+1`，初始 `a[0..D−1]=1`。

该下标为 `q−1`，由 `i≥1`、`1≤p≤100` 知位于 `0..i−1`。它随 `i` 非递减，故归纳可知前缀始终有序。前 `q` 项严格小于新重量，因此最后恰有 `k` 项保留。

### 最优性

把任意可行序列的全部丢弃项降为 1。它们仍被丢弃，且降低其他重量不会减少未变保留项之前的严格较小个数；总重不增加。

交换相邻的保留重量 `x≥2` 与随后丢弃的 1。若原来有 `i` 个前项、`L` 个较小项，满足 `100L≥pi`，交换后有 `i+1` 个前项和 `L+1` 个较小项。因为 `100≥p`，保留条件仍成立。1 仍丢弃，后续位置的前缀多重集合不变。反复交换可将所有丢弃的 1 移到前面，所以存在这种形式的最优解。

将贪心 `a` 与任意合法尾部 `b` 比较。若所有先前 `a` 不大于对应 `b`，则其第 `q` 顺序统计量也不大。`b[i]` 能保留意味着其前缀第 `q` 项至多 `b[i]−1`。贪心取自己的该项加一，因而不超过 `b[i]`。归纳得到逐坐标最小，总和最小，无需假设竞争尾部有序。

## 各语言说明

每项一次数组访问：`O(n)` 算术操作、`O(n)` 存储及输出文本。单重量不超过 `i+1≤n`。当 `n=100000`、`k=n−1`、`p=100` 时总和达 `n(n+1)/2=5000050000`，必须用 64 位累计值；`p·i` 仍适合 32 位。Python 整数直接支持，其余版本用宽类型。

分母不能包括当前项，不能只数先前保留项，也不能把相等当较小或将 `≥` 改成 `>`。统计较小重量所需的树只在检查器中使用，构造本身是线性的。交换是证明工具，程序直接生成结果。
