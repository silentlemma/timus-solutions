# 1946. 统计排序后的进球数表

[Timus 1946](https://acm.timus.ru/problem.aspx?space=1&num=1946) · difficulty 1832 · dp

Original problem from Open Ural FU Personal Contest 2012 | by Alexander Ipatov.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n人两两各比赛一次，每场共三球，比分为3:0、2:1、1:2、0:3之一。
汇总个人进球并按非增序排列，统计不同的最终列表。不计名字，
也不重复计算产生同一列表的不同比赛结果。时限1秒，内存64 MB。

## 输入

一个整数n，2≤n≤50。

## 输出

列表数模1000000007。

## 评测方式

按记号逐个比较输出。

## 样例

```
3
```

```
8
```

## 解法

改数反向的非降序a₁≤…≤a_n。设T=3n(n−1)/2，L(k)=3k(k−1)/2。
非负整数列表可行当且仅当总和T、每个长度k前缀和≥L(k)。
每个分数上界M=3(n−1)。必要性来自任意k人内部的k(k−1)/2场
比赛，其三球都留在集合内，外部比赛只添非负进球。

充分性用流：源到每场比赛容量3，比赛到两个参与者容量T+1，
参与者j到汇容量a_j。容量≤T的割中，令S为源侧参与者。
源侧比赛的两个端点必须都在S，否则割过T+1弧；固定S时最廉价
选择包含全部内部比赛，割容量为3·(C(n,2)−C(|S|,2))+Σ_{j∈S}a_j。
最小前缀条件保证它≥T，因此有整数流T。每场恰分三整数球，
每位得到指定总数，证明充分性。

dp_i[P][v]为i个非降分数前缀、和P、末值v且所有下界成立的数目，
dp₀[0][0]=1。前缀平均不能超过整体平均，只存
L(i)≤P≤U(i)=floor(Ti/n)。加入x时

dp_(i+1)[P+x][x] = Σ_{v≤x} dp_i[P][v]。

每个旧和按x递增维护累加前缀。新和与x唯一确定旧和，故赋值
而非与另一旧和累加。两层交替并清零，末值范围0..M。
精确扫描界为

first=max(0,L(i+1)−P,ceil(P/i)（i>0时）)，
last=min(M,U(i+1)−P,floor((T−P)/(n−i)))。

旧末值≥旧前缀平均，余下n−i个值（含x）都≥x，故只剔除不可能
完成的前缀。先累加小于first的位置，写入前再加dp_i[P][x]。
最终对dp_n[T]全部末值求和。每个排序列表恰走一条路径，不乘
名字排列数或比赛实现数。

时间O(n⁴)、空间O(n³)：n层、O(n²)种和、O(n)种末值。前缀和
避免再乘n。n=50最大938行和、148列，单层138824格。

统计列表，不是4^(场数)、带名字向量或仅总和分拆。前缀约束必需，
允许相同分数和零。正确整除floor/ceil、包含x=v、清零缓冲和
64位累加都不可漏。

## 各语言说明

原生版本重用两个平坦32位缓冲，每轮清空下一层；Python用列表。
原始前缀及最终行和需64位，最大148·(MOD−1)=148000000888。
写格时取模，Python整数不会溢出；全部下标乘积能放入32位。
