# 1900. Выбор железнодорожных перегонов

[Timus 1900](https://acm.timus.ru/problem.aspx?space=1&num=1900) · difficulty 527 · dp

Автор оригинальной задачи — Алексей Самсонов; подготовил Александр Фетисов. Чемпионат Урала 2012.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На прямой расположены станции 1,…,n. Вес w(i,j) — число пассажиров с
поездкой из i в j, i < j. Выберите ровно k разных перегонов между соседними
станциями. Пассажир учитывается один раз, если его маршрут пересекает хотя
бы один выбранный перегон. Максимизируйте сумму и восстановите выбор.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

Сначала n и k: 2 ≤ n ≤ 500, 1 ≤ k < n. Для i = 1,…,n−1 следующая строка
содержит w(i,i+1),…,w(i,n); каждый вес лежит от 0 до 100.

## Выходные данные

Максимальная сумма, затем k возрастающих номеров перегонов. Перегон i
соединяет станции i и i+1. Подходит любой оптимальный выбор.

## Проверка

Проверяются количество, диапазон и строгий порядок номеров. Покрытый вес
пересчитывается и должен совпадать с оптимумом; сами номера могут отличаться.

## Примеры

```
4 1
5 0 6
5 3
5
```

```
14
3
```

## Решение

Разрежем последовательность станций по выбранным перегонам: получатся
g = k+1 непустых групп. Неучтённый пассажир имеет оба конца в одной группе.
Поэтому минимизируем сумму весов поездок внутри групп.

C(l,r) — сумма w(i,j) для l ≤ i < j ≤ r. Вычислим её за `O(n²)`, перебирая
l по убыванию: C(l,r) = C(l+1,r) + Σ(j=l+1…r) w(l,j). Последняя сумма
накапливается при увеличении r.

D(t,r) — минимальный пропущенный вес при разбиении первых r станций на
t групп. D(1,r) = C(1,r), а D(t,r) = min[D(t−1,p) + C(p+1,r)] по
t−1 ≤ p < r. Запоминаем оптимальную границу p. Достаточно вычислять
t ≤ r ≤ n−g+t, оставляя по станции каждой будущей группе.

Неотрицательность даёт неравенство Монжа для a ≤ b ≤ c ≤ d:
C(a,c)+C(b,d) ≤ C(a,d)+C(b,c). Разность правой и левой частей равна
сумме w(i,j) для a ≤ i < b и c < j ≤ d. Добавление D(t−1,p) к строке
кандидатов сохраняет неравенство. Следовательно, самая левая оптимальная
граница не убывает с ростом r: пересекающиеся минимумы можно распрямить
по неравенству, а выбор самого левого исключает убывание при равенстве.

Слой считаем разделением пополам. Для среднего r находим лучший p в
допустимом диапазоне. Слева оставляем p не больше найденного, справа —
не меньше. При равенстве сохраняем первую границу. Слой требует `O(n log n)`.
Из состояния (g,n) восстанавливаем границы назад; они и есть перегоны.
Ответ — C(1,n) минус минимальный пропущенный вес.

Выбор перегонов и разбиение взаимно однозначны. Переход перебирает последнюю
группу и потому находит минимум; монотонная оптимизация сохраняет лучший
кандидат. Восстановленный выбор оптимален.

Время `O(n² + kn log n)`, память `O(n² + kn)` = `O(n²)`, поскольку k < n.
32-битных знаковых чисел хватает: общий вес не больше 12 475 000;
бесконечность равна 10⁹. В примере перегон 3 покрывает 6+3+5=14 пассажиров.

Подводные камни:

- учитывать поездку через несколько выбранных перегонов только один раз;
- оставлять каждую группу непустой;
- k выбранных перегонов создают k+1 групп.

## Особенности языков

Во всех пяти версиях одинаковый переход с выбором самой левой границы.
Python использует компактные целочисленные массивы, Java — буферизованный
ввод. Глубина рекурсии `O(log n)`.
