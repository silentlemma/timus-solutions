# 1900. 选择铁路区间

[Timus 1900](https://acm.timus.ru/problem.aspx?space=1&num=1900) · difficulty 527 · dp

原题作者 Alex Samsonov，由 Alexander Fetisov 准备，出自 Ural Championship 2012。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

直线上有编号 1 到 n 的车站。w(i,j) 表示从 i 到 j 的乘客数，i < j。
恰好选择 k 个不同的相邻车站区间。行程经过至少一个所选区间的乘客计入
答案，每人只计一次。求最大人数及达到最大值的区间集合。
时限 1 秒，内存限制 64 MB。

## 输入

首先给出 n 和 k，2 ≤ n ≤ 500，1 ≤ k < n。
对于 i = 1,…,n−1，下一行依次给出 w(i,i+1),…,w(i,n)，每个值为 0 到 100。

## 输出

先输出最大人数，再输出 k 个严格递增的区间编号。
区间 i 连接车站 i 和 i+1。可以输出任意最优集合。

## 评测方式

检查编号的数量、范围和递增性，重新计算覆盖人数，并与最优值比较。
无需与保存的答案选择相同的区间。

## 样例

```
4 1
5 0 6
5 3
5
```

```
14
3
```

## 解法

在所选区间处切开车站序列，得到 g = k+1 个非空连续组。
未覆盖的乘客恰好是两个端点位于同一组的乘客，因此最小化组内权值总和。

令 C(l,r) 为所有 l ≤ i < j ≤ r 的 w(i,j) 之和。按 l 递减计算：
C(l,r) = C(l+1,r) + Σ(j=l+1…r) w(l,j)。随 r 递增累加后一项，
即可在 `O(n²)` 时间内预处理。

D(t,r) 表示把前 r 个车站分成 t 组时最小的未覆盖权值。
D(1,r)=C(1,r)，转移为 D(t,r)=min[D(t−1,p)+C(p+1,r)]，
其中 t−1 ≤ p < r。保存最优 p 以便恢复。只需计算
t ≤ r ≤ n−g+t，为尚未建立的每组至少留下一个车站。

因为权值非负，对 a ≤ b ≤ c ≤ d 有 Monge 不等式：
C(a,c)+C(b,d) ≤ C(a,d)+C(b,c)。右边减左边恰好是
a ≤ i < b、c < j ≤ d 的 w(i,j) 之和。给每个候选行加上 D(t−1,p)
不会改变该不等式。因此，取最靠左的最优分割点时，它随 r 增大不会减小：
可用不等式消除交叉最优解，取最左者处理相等情况。

用分治计算每层：枚举中点 r 的允许分割点，得到最优 p；
左半部分只考虑不大于 p 的候选，右半部分只考虑不小于 p 的候选。
相等时保留较小的 p。每层 `O(n log n)`。从 (g,n) 反向追踪父状态，
得到的分割点就是区间编号，答案为 C(1,n) 减去未覆盖最优值。

每个区间集合唯一对应一个连续分组，反之亦然。转移枚举最后一组，
所以得到最小未覆盖权值；单调优化保留最优候选，恢复结果因而最优。

时间 `O(n² + kn log n)`，空间 `O(n² + kn)`=`O(n²)`，因为 k < n。
总权值最多 12,475,000，使用有符号 32 位整数即可，无穷大设为 10⁹。
示例选择区间 3，覆盖 6+3+5=14 人。

注意事项：

- 经过多个所选区间的乘客只能计数一次；
- 每组都必须非空；
- k 个所选区间形成 k+1 组。

## 各语言说明

五种实现使用相同的转移与最左平局规则。Python 用紧凑整数数组保存代价和
父状态，Java 使用缓冲输入。递归深度为 `O(log n)`。
