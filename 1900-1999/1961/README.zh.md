# 1961. 粤语

[Timus 1961](https://acm.timus.ru/problem.aspx?space=1&num=1961) · difficulty 875 · math

Original problem from Open Ural FU Personal Contest 2013 | by Alexander Ipatov.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 个对象中有未知整数 M 属于指定类别。均匀选取 n 个不同对象，恰有 m 个
属于该类。选择 0≤M≤N 使此观察的概率最大；若并列取最大的 M。抽样不放回。
限制：1 秒、64 MB。

## 输入

按顺序给三个整数 n,m,N：1≤n≤N≤10⁸，0≤m≤n。

## 输出

一个整数 M，即最大概率的最右取值。

## 评测方式

按记号逐个比较输出。

## 样例

```
10 1 200
```

```
20
```

## 解法

样例 m(N+1)=201，floor(201/10)=20，所以输出 20。

候选 M 的概率是 P(M)=C(M,m)·C(N−M,n−m)/C(N,n)，仅在
m≤M≤N−n+m 为正。分母与 M 无关，不必计算巨大组合数。比较相邻可行值：

P(M+1)/P(M) = (M+1)/(M+1−m) · (N−M−n+m)/(N−M)。

这些步骤分母均正。交叉乘积之差为 m(N+1)−n(M+1)，因此当且仅当
m(N+1)≥n(M+1) 时概率不减。概率先升，可能一对相邻值相等，再下降。
最大的最大值位置为

M = min(N, floor(m(N+1)/n))。

若 0<m<n 且 q=m(N+1)/n 为整数，则 q−1、q 同为最大，整数除法给所需较大值。
例如 n=2,m=1,N=3 时 M=1、2 概率均 2/3，输出 2。

m<n 时商至少 m，且 m(N+1)/n=(N+1)−(n−m)(N+1)/n<N−n+m+1，
取整后至多 N−n+m，故可行。m=n 时商为 N+1，用上界 N 修正；m=0 时为零。
n=N 是完整观察，答案必须恰为 m，公式同样满足。

时间 `O(1)`、空间 `O(1)`，仅乘法、整数除法及截断上界。

必须用 N+1，且并列取较大值，不能换成独立有放回抽样。中间乘积最大
10⁸(10⁸+1)=10,000,000,100,000,000，超过 int32 及 binary64 的精确整数
范围，但有符号 int64 足够。保持整数乘除。n=N=10⁸,m=99,999,999 时，
浮点舍入可能错误给 10⁸；完整观察显然要求 M=99,999,999。m=n 时必须取上界 N。

## 各语言说明

C++ 用 int64_t，Go 1.14 用 int64，Java 8 用 long，Rust 1.75 用 u64。
乘法前参数已是宽类型。Python 整数精确；Rust 仅用标准库。操作数非负，
普通整数除法即向下取整。
