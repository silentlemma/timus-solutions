# 1961. Кантонский язык

[Timus 1961](https://acm.timus.ru/problem.aspx?space=1&num=1961) · difficulty 875 · math

Original problem from Open Ural FU Personal Contest 2013 | by Alexander Ipatov.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В популяции N объектов неизвестное число M принадлежит заданному классу.
Равномерная выборка n различных объектов содержит ровно m представителей
класса. Найти целое M, 0≤M≤N, при котором вероятность наблюдения
максимальна; при равенстве взять наибольшее. Выборка без возвращения.
Ограничения: 1 с, 64 МБ.

## Входные данные

Три целых n,m,N именно в этом порядке: 1≤n≤N≤10⁸, 0≤m≤n.

## Выходные данные

Одно целое M — наибольшая точка максимума.

## Проверка

Ответы сравниваются по токенам.

## Примеры

```
10 1 200
```

```
20
```

## Решение

Для примера m(N+1)=201, floor(201/10)=20, поэтому ответ 20.

Вероятность для кандидата M:

P(M)=C(M,m)·C(N−M,n−m)/C(N,n).

Она положительна ровно при m≤M≤N−n+m. Знаменатель от M не зависит.
Вычислять огромные биномиальные коэффициенты не нужно: сравним соседние
допустимые значения:

P(M+1)/P(M) = (M+1)/(M+1−m) · (N−M−n+m)/(N−M).

Знаменатели такого шага положительны. Разность перекрёстных произведений
равна m(N+1)−n(M+1), поэтому вероятность не убывает на шаге ровно при
m(N+1)≥n(M+1). Значения сначала растут, могут иметь одну равную соседнюю
пару, затем убывают. Наибольший максимум:

M = min(N, floor(m(N+1)/n)).

При 0<m<n и целой дроби q=m(N+1)/n равны максимумы q−1 и q; целое
деление выбирает больший. Например, n=2,m=1,N=3 даёт вероятность 2/3
при M=1 и M=2, значит, нужен ответ 2.

При m<n частное не меньше m. С другой стороны,
m(N+1)/n=(N+1)−(n−m)(N+1)/n<N−n+m+1, поэтому его пол не больше
N−n+m. Ответ лежит в допустимой области. При m=n частное N+1 ограничиваем
сверху N; тогда вся выборка принадлежит классу. При m=0 получается ноль.
При n=N наблюдалась вся популяция, и результат ровно m, как и у формулы.

Время `O(1)`, память `O(1)`: умножение, целое деление и ограничение сверху.

Нужно N+1, а не N, и больший максимум при равенстве. Нельзя подменять
выборку независимыми попытками с возвращением. Произведение достигает
10⁸(10⁸+1)=10 000 000 100 000 000: больше int32 и точного целого диапазона
binary64, но помещается в знаковый int64. Умножение и деление должны
оставаться целыми. Для n=N=10⁸,m=99 999 999 округление float может дать
10⁸ вместо очевидного M=99 999 999 при полной переписи. Ограничение N
необходимо при m=n.

## Особенности языков

C++ использует int64_t, Go 1.14 — int64, Java 8 — long, Rust 1.75 — u64.
Аргументы широкие до умножения. Целые Python точные. Rust только со
стандартной библиотекой. Операнды неотрицательны, обычное целое деление
уже округляет вниз.
