# 1927. 两个无限条带的交集面积

[Timus 1927](https://acm.timus.ru/problem.aspx?space=1&num=1927) · difficulty 1062 · geometry

Original problem from Ural Regional School Programming Contest 2012 | by Artyom Averin.

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

两个非零线段各自给出一条无限条带的垂直横截面。经过线段每个点、
垂直于线段且向两个方向无限延伸的所有直线组成该条带。求两条带
交集的面积；面积无穷时输出 −1。限制：1 秒，64 MB。

## 输入

两行，每行四个整数 x1 y1 x2 y2，表示一个线段的两个端点。
坐标范围为 [−1000,1000]，每段的两个端点不同，端点次序任意。

## 输出

一个实数面积，或表示无穷面积的 −1。不相交或仅沿一条直线接触时
面积为零；接触直线本身无界不影响这个结论。

## 评测方式

一个数值记号；绝对误差或相对误差不超过 10^−6。

## 样例

```
0 0 2 0
0 0 0 2
```

```
4
```

## 解法

端点记作 A,B 和 C,D，法向量 v=B−A、w=D−C。第一条带的点 X 满足
v·X 位于 v·A 与 v·B 之间；第二条带类似，使用 w·C 与 w·D。
必要时将两个边界排序。

计算整数行列式 Δ=vx wy−vy wx。若 Δ≠0，可逆线性映射
X↦(v·X,w·X) 把交集变为矩形，两边长度分别为 v·(B−A)=|v|²
与 w·(D−C)=|w|²。映射将面积乘以 |Δ|，故原面积为
|v|²|w|²/|Δ|。这证明有限情况的公式，也说明平移线段不影响面积。

若 Δ=0，用共同法向量 v 投影两个线段。分别将 v·A,v·B 以及
v·C,v·D 排序。设 L 为较大的下界，R 为较小的上界。L<R 时，
正宽度交集沿条带方向无限延伸，面积无穷；L>R 时无交集；
L=R 时只有一条直线，面积为零。后两种都输出 0。
以上情况覆盖所有输入，因此算法正确。

时间与空间均为 O(1)，输入固定为八个整数。

条带向两个方向无限延伸，不是射线或半条带。平行判断不能使用
浮点误差阈值：行列式 ±1 仍对应很大的有限面积。无界接触直线
面积为零。平行情况必须用同一个向量投影两个线段；交换端点
不能改变结果。直接用长度平方，无需平方根或三角函数。

## 各语言说明

C++、Go、Java、Rust 在乘法之前使用有符号 64 位整数。
向量分量绝对值不超过 2000，长度平方不超过 8,000,000，
两者乘积不超过 64,000,000,000,000，小于 2^46，能被双精度数精确表示。
行列式绝对值不超过 8,000,000，非零时至少为 1。精确整数判断后
只进行一次浮点除法，输出十位小数即可满足误差要求。
Python 在除法前使用精确整数；Java 以 Locale.US 保证小数点格式。
