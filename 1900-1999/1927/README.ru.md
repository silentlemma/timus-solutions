# 1927. Площадь пересечения двух бесконечных полос

[Timus 1927](https://acm.timus.ru/problem.aspx?space=1&num=1927) · difficulty 1062 · geometry

Original problem from Ural Regional School Programming Contest 2012 | by Artyom Averin.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждый из двух ненулевых отрезков задаёт поперечное сечение бесконечной
полосы. Через каждую точку отрезка проходит прямая, перпендикулярная ему;
объединение этих полных прямых образует полосу. Требуется площадь общей
части двух полос; при бесконечной площади вывести −1.
Ограничения: 1 секунда, 64 МБ.

## Входные данные

Две строки по четыре координаты x1 y1 x2 y2 — концы соответствующего
отрезка. Все числа целые, от −1000 до 1000 включительно. Концы одного
отрезка различны; порядок концов произволен.

## Выходные данные

Одно вещественное число — площадь либо −1 при бесконечной площади.
У непересекающихся полос и при касании по прямой площадь равна нулю,
хотя сама прямая касания неограниченна.

## Проверка

Один числовой токен; абсолютная ИЛИ относительная ошибка не больше 10^−6.

## Примеры

```
0 0 2 0
0 0 0 2
```

```
4
```

## Решение

Обозначим концы A,B и C,D, нормали v=B−A и w=D−C. Первая полоса
задаётся условием: v·X находится между v·A и v·B. Для второй аналогично
используются w·C,w·D. При необходимости границы упорядочиваются.

Вычислим целый определитель Δ=vx wy−vy wx. Если Δ≠0, обратимое линейное
отображение X↦(v·X,w·X) переводит пересечение в прямоугольник со сторонами
v·(B−A)=|v|² и w·(D−C)=|w|². Площади при отображении умножаются на |Δ|,
поэтому искомая площадь |v|²|w|²/|Δ|. Это доказывает формулу конечной
площади и её независимость от переносов отрезков.

При Δ=0 проецируем ОБА отрезка на общую нормаль v. Упорядочиваем пары
v·A,v·B и v·C,v·D. Пусть L — максимум левых границ, R — минимум правых.
Если L<R, общая положительная ширина продолжается вдоль полос бесконечно:
ответ −1. Если L>R, пересечения нет. При L=R общей является только
прямая, её площадь нулевая. Последние два случая дают ответ 0.
Разобраны все возможности, поэтому алгоритм корректен.

O(1) времени и памяти: во входе всегда восемь целых чисел.

Нужны полные полосы, а не лучи или полуполосы. Параллельность проверяется
точно: определитель ±1 даёт большую, но конечную площадь. Неограниченность
линии касания не означает бесконечную площадь. При параллельности обе пары
концов проецируются на один и тот же вектор; порядок концов несущественен.
Квадратные корни и тригонометрия не нужны.

## Особенности языков

В C++, Go, Java и Rust все умножения заранее выполняются в знаковом
64-битном типе. Компоненты векторов по модулю не больше 2000, квадрат
длины — 8 000 000, произведение квадратов — 64 000 000 000 000.
Последнее меньше 2^46 и представимо в double точно. Модуль определителя
не больше 8 000 000, а ненулевой — не меньше 1. Точные проверки, одно
вещественное деление и десять знаков после точки обеспечивают допуск.
Python считает целые точно до деления; Java задаёт Locale.US для точки.
