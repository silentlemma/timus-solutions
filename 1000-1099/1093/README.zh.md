# 1093. 下落的飞镖能否穿过空间中的圆形靶

[Timus 1093](https://acm.timus.ru/problem.aspx?space=1&num=1093) · 难度 1996 · geometry

原题作者 Alexander Klepinin，出自 2001 年 3 月 USU Open Collegiate Programming Contest（Senior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

靶是一个圆盘，圆心 `C`，半径 `R`，法向量 `N`。飞镖从 `S` 以速度 `V`（水平分量不为零）出发，按
`S + V·t − (g/2)·t²·ẑ` 运动，`g = 10`。开始时它在靶外。如果飞镖在某一时刻从任一侧严格穿过圆盘内部，输出
`HIT`，否则输出 `MISSED`。所有 13 个数的绝对值都不超过 500，小数点后最多四位。

时间限制：1 秒。内存限制：64 MB。

## 输入

`Cx Cy Cz Nx Ny Nz R`，然后是 `Sx Sy Sz Vx Vy Vz`。

## 输出

`HIT` 或 `MISSED`。

## 评测方式

按记号逐个比较输出；多余的空白不影响结果。

## 样例

### 样例 1

输入：

```
47 0 -72 1 0 1 4.25
0 0 0 10 0 10
```

输出：

```
HIT
```

## 题解

设 `D = S − C`。飞镖到平面的距离乘以 `|N|` 等于 `N·(D + V t) − 5 Nz t²`，即二次式 `a t² + 2h t + c`，其中
`a = −5 Nz`，`h = N·V / 2`，`c = N·D`。飞镖只能在它的根 `t ≥ 0` 处碰到圆盘，在那里要检查到圆心距离的平方减去
`R²`，即 `Q(t) = |D + V t − 5t² ẑ|² − R²`，是否为负。

- `a ≠ 0`：至多两个根 `t = (−h ± √(h² − ac)) / a`；抛物线可能两次穿过平面，任何一次都可能是命中。
- `a = 0`，`h ≠ 0`（竖直平面）：一个根 `t = −c / 2h`。
- `a = h = 0`：轨迹与平面平行，或者就在平面内。两种情况下飞镖都不会从某一侧穿过圆盘，所以都算未命中：
  在靶面内滑行不算命中。

`O(1)`。

注意事项：

- 严格在内部：恰好落在边缘上的飞镖算未命中，所以比较时使用一个很小的负容差；
- 只有 `t ≥ 0` 的根才算，两个根都要检查，因为第一次穿过可能从圆盘旁边经过，第二次才穿过它；
- 当飞行的最高点恰好擦过平面时，判别式可能因舍入而略小于 0，所以要用一个很小的容差来比较，略小于零的根仍按
  `t = 0` 处理；
- `N` 没有归一化，这没关系，因为只用到平面方程的符号和根。

答案与用分数做的精确计算进行了核对：在二次式的根处，`Q` 化简为 `t` 的一次式，它在 `(−h ± √d) / a` 处的符号可以
不经舍入地确定。用这种方法比较了数百次瞄准靶边缘、误差在万分之一以内的随机投掷。早先的版本把位于平面内并穿过
圆盘的轨迹算作命中，在 Timus 第 56 个测试上被判错，所以现在这样的轨迹算未命中。
