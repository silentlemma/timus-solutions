# 1093. Пролетит ли падающий дротик сквозь круглую мишень в пространстве

[Timus 1093](https://acm.timus.ru/problem.aspx?space=1&num=1093) · сложность 1996 · geometry

Автор оригинальной задачи — Александр Клепинин; USU Open Collegiate Programming Contest, март 2001 года, Senior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Мишень — круг с центром `C`, радиусом `R` и вектором нормали `N`. Дротик
стартует из `S` со скоростью `V` (с ненулевой горизонтальной частью) и
движется как `S + V·t − (g/2)·t²·ẑ`, `g = 10`. Вначале он вне мишени.
Выведите `HIT`, если дротик когда-нибудь пройдёт строго внутри круга с
любой стороны, и `MISSED` иначе. Все 13 чисел по модулю не больше 500 и
имеют не больше четырёх знаков после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`Cx Cy Cz Nx Ny Nz R`, затем `Sx Sy Sz Vx Vy Vz`.

## Выходные данные

`HIT` или `MISSED`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
47 0 -72 1 0 1 4.25
0 0 0 10 0 10
```

Вывод:

```
HIT
```

## Решение

Пусть `D = S − C`. Расстояние дротика до плоскости, умноженное на `|N|`,
равно `N·(D + V t) − 5 Nz t²` — квадратному трёхчлену `a t² + 2h t + c`
с `a = −5 Nz`, `h = N·V / 2` и `c = N·D`. Дротик может коснуться круга
только в корне `t ≥ 0`, и там проверяется, отрицателен ли квадрат
расстояния до центра минус `R²`: `Q(t) = |D + V t − 5t² ẑ|² − R²`.

- `a ≠ 0`: до двух корней `t = (−h ± √(h² − ac)) / a`; парабола может
  пересечь плоскость дважды, и попаданием может оказаться любое
  пересечение.
- `a = 0`, `h ≠ 0` (вертикальная плоскость): один корень `t = −c / 2h`.
- `a = h = 0`: путь параллелен плоскости или лежит в ней. В обоих случаях
  дротик ни с какой стороны не проходит сквозь круг, так что это промах:
  скольжение в плоскости мишени попаданием не считается.

`O(1)`.

Подводные камни:

- строго внутри: дротик ровно на краю промахивается, поэтому сравнение
  идёт с небольшим отрицательным допуском;
- считаются только корни с `t ≥ 0`, и проверять нужно оба: первое
  пересечение может пройти мимо круга, а второе — сквозь него;
- дискриминант может оказаться чуть отрицательным из-за округления, когда
  верхняя точка полёта едва касается плоскости, поэтому он сравнивается с
  небольшим допуском, а корень чуть меньше нуля всё ещё считается
  `t = 0`;
- `N` не нормирован, но это не важно: используются только знак и корни
  уравнения плоскости.

Ответы сверены с точным вычислением в дробях: в корне квадратного
трёхчлена `Q` сводится к линейной форме от `t`, и её знак в
`(−h ± √d) / a` определяется без округлений. Так сравнены сотни случайных
бросков, нацеленных с точностью до десятитысячной на край мишени.
Прежняя версия считала попаданием путь, лежащий в плоскости и
пересекающий круг; Timus отверг её на тесте 56, так что теперь такой путь —
промах.

## Особенности языков

- Rust разбирает тринадцать чисел образцом среза.
- Java читает числа с `Locale.US`, поэтому десятичная точка принимается
  при любой системной локали.
