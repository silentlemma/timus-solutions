# 1036. 给定数字和的平衡票号

[Timus 1036](https://acm.timus.ru/problem.aspx?space=1&num=1036) · 难度 304 · dp

原题来自 Timus Online Judge 题库，未注明作者和出处。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

票号是由 `2N` 个十进制数字组成的字符串（`1 ≤ N ≤ 50`），允许有前导零。若前 `N` 位数字之和等于后 `N` 位数字
之和，则称票号是平衡的。给定 `S`（`0 ≤ S ≤ 1000`），求数字总和为 `S` 的平衡票号个数。

时间限制：2 秒。内存限制：64 MB。

## 输入

一行中给出 `N` 和 `S`。

## 输出

这种票号的个数（可能有大约一百位）。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
2 2
```

输出：

```
4
```

### 样例 2

输入：

```
3 6
```

输出：

```
100
```

## 题解

数字和为 `S` 的平衡票号，两半的数字和都是 `S / 2`，所以 `S` 为奇数时答案是 `0`，否则是 `W^2`，其中 `W` 是数字
和为 `S / 2` 的 `N` 位数字串的个数：两半可以独立选择。

`W` 用按位的动态规划求出：`ways[k][t]` 是数字和为 `t` 的 `k` 位数字串个数，`ways[k + 1][t]` 是对数字
`d = 0..9` 求 `ways[k][t − d]` 之和。只需要不超过 `S / 2` 的和；若 `S / 2 > 9N`，答案直接是 `0`。共
`O(N · S)` 次加法。

这些数放不进 64 位：`W` 可达约 `10^48`，答案可达约 `10^97`，所以动态规划和最后的平方都要用高精度整数。

注意事项：

- 数字和为奇数时没有平衡票号；
- 给定的和可能超过票号所能达到的最大值（最多 1000，而 `18N ≤ 900`）；
- 前导零也算：`0101` 是一个四位票号。

另一种做法是容斥原理给出的显式公式 `W = Σ (−1)^k C(N, k) C(S/2 − 10k + N − 1, N − 1)`；测试用它核对过。
