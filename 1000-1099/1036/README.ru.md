# 1036. Сбалансированные билеты с заданной суммой цифр

[Timus 1036](https://acm.timus.ru/problem.aspx?space=1&num=1036) · сложность 304 · dp

Оригинальная задача из архива Timus Online Judge; автор и источник не указаны.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Номер билета — строка из `2N` десятичных цифр (`1 ≤ N ≤ 50`); ведущие нули
допускаются. Билет сбалансирован, если суммы его первых `N` цифр и
последних `N` цифр равны. По заданному `S` (`0 ≤ S ≤ 1000`) посчитайте
сбалансированные билеты с суммой цифр `S`.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `S` в одной строке.

## Выходные данные

Число таких билетов (в нём может быть около сотни цифр).

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
2 2
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
3 6
```

Вывод:

```
100
```

## Решение

Обе половины сбалансированного билета с суммой цифр `S` имеют сумму
`S / 2`, поэтому при нечётном `S` ответ `0`, а иначе `W^2`, где `W` —
число строк из `N` цифр с суммой `S / 2`: половины выбираются независимо.

`W` считается динамикой по цифрам: `ways[k][t]` — число строк из `k` цифр
с суммой `t`, а `ways[k + 1][t]` — сумма `ways[k][t − d]` по цифрам
`d = 0..9`. Нужны только суммы до `S / 2`, а при `S / 2 > 9N` ответ сразу
`0`. Всего `O(N · S)` сложений.

Числа не помещаются в 64 бита: `W` доходит примерно до `10^48`, а ответ —
до `10^97`, поэтому и динамика, и итоговый квадрат считаются в длинной
арифметике.

Подводные камни:

- при нечётной сумме сбалансированных билетов нет;
- сумма может быть больше возможной для билета (до 1000 при
  `18N ≤ 900`);
- ведущие нули учитываются: `0101` — билет из четырёх цифр.

Альтернатива — явная формула по включениям-исключениям,
`W = Σ (−1)^k C(N, k) C(S/2 − 10k + N − 1, N − 1)`; тесты проверены ею.

## Особенности языков

- **C++**, **Rust**: небольшой тип длинных чисел по основанию `10^9` со
  сложением и умножением.
- **Go**: `math/big`; **Java**: `BigInteger`; **Python**: встроенные целые.
