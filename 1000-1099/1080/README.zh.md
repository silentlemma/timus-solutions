# 1080. 用两种颜色给地图着色

[Timus 1080](https://acm.timus.ru/problem.aspx?space=1&num=1080) · 难度 186 · bfs, graphs, dsu

原题作者 Emil Kelevedzhiev，出自 2001 年瓦尔纳冬季数学节信息学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

地图上有 `N` 个国家（`0 < N < 99`），从任何一个国家穿过若干边界都能到达其他任何国家。把国家涂成红色（0）和
蓝色（1），使相邻国家颜色总是不同，并且国家 1 是红色。把各国颜色输出成一串数字；如果做不到，输出 `-1`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行：第 `i` 行列出国家 `i` 的编号更大的邻国，并以 0 结尾。

## 输出

颜色串，或 `-1`。

## 评测方式

精确冻结的 Python 候选再次与独立 BFS 比较：所有至多六个顶点的
27,476 个连通带标号简单图，以及 701 个随机或极限连通图，含奇环和
98 顶点完全二分图。参考答案固定国家 1 为 0，比较唯一染色或 `-1`。
穷举小图不等于穷举所有 98 顶点地图。四份实际 DSU 程序还分别在 Docker 中
通过仓库 11 个输入，并有各自精确源码的 Accepted。28,177 个参考输入是
Python 执行次数，不是每个编译语言都执行了 28,177 次。

## 样例

### 样例 1

输入：

```
3
2 0
3 0
0
```

输出：

```
010
```

## 解法

合法染色就是无向边界图的二分。输入只在编号较小的端点列出每条边，
但保存邻接表时要加入两个方向。从国家 1、颜色 0 开始 BFS，每个新邻点取相反色。
一条冲突边意味着两条 BFS 路径与该边形成奇闭合游走，进而含奇环，故不可能染色。
若无冲突，每条边两端异色，结果合法。连通性保证访问所有国家，
固定首个颜色后答案唯一。

易读 BFS 的时间、空间均 `O(N + E)`，包括邻接表和队列，`E` 为边数。
五份原 Accepted 基线逐字节保留。输出连续数字，冲突则输出 `-1`。
仅含 `0` 的一行不新增输入边，`N = 1` 也合法。

## 优化解法

紧凑 BFS 保持相邻顶点异色的不变量，使用有界队列和紧凑颜色数组。另一个 Go 算法使用带奇偶信息的并查集，每条边要求两端奇偶性不同。路径压缩保持到代表元的奇偶值，矛盾边即检测出奇环。统一第一国家所在分量的颜色。边可流式处理，无需邻接表。
