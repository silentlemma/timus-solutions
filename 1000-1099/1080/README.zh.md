# 1080. 用两种颜色给地图着色

[Timus 1080](https://acm.timus.ru/problem.aspx?space=1&num=1080) · 难度 190 · bfs, graphs

原题作者 Emil Kelevedzhiev，出自 2001 年瓦尔纳冬季数学节信息学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

地图上有 `N` 个国家（`0 < N < 99`），从任何一个国家穿过若干边界都能到达其他任何国家。把国家涂成红色（0）和
蓝色（1），使相邻国家颜色总是不同，并且国家 1 是红色。把各国颜色输出成一串数字；如果做不到，输出 `-1`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行：第 `i` 行列出国家 `i` 的编号更大的邻国，并以 0 结尾。

## 输出

颜色串，或 `-1`。

## 评测方式

按记号逐个比较输出；多余的空白不影响结果。

## 样例

### 样例 1

输入：

```
3
2 0
3 0
0
```

输出：

```
010
```

## 题解

地图能这样着色，当且仅当边界构成的图是二分图。从国家 1 以颜色 0 开始做广度优先搜索，给每个新到达的国家涂上与
来源国家相反的颜色。如果某条边界连接了两个同色国家，就存在奇环，答案是 `-1`。地图是连通的，所以国家 1 的颜色
决定了其他所有国家的颜色，答案是唯一的。`O(N + M)`。

注意事项：

- 每行只列出编号更大的邻国，所以每条边界都要双向加入；
- 没有编号更大的邻国的国家，其所在行只有一个 0；
- 数字之间没有分隔符。

答案与一个记录到根路径奇偶性的并查集做了核对，这种方法根本不遍历地图。

## 各语言说明

- 各语言都逐个记号读取邻国，直到每行末尾的 0。
