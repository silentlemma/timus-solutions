# 1080. Раскраска карты в два цвета

[Timus 1080](https://acm.timus.ru/problem.aspx?space=1&num=1080) · сложность 190 · bfs, graphs

Автор оригинальной задачи — Emil Kelevedzhiev; турнир по информатике Зимнего математического фестиваля, Варна, 2001 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На карте `N` стран (`0 < N < 99`); из любой страны можно попасть в любую
другую, пересекая границы. Раскрасьте страны в красный (0) и синий (1)
цвета так, чтобы соседи всегда различались, а страна 1 была красной.
Выведите цвета одной строкой цифр или `-1`, если это невозможно.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк: строка `i` перечисляет соседей страны `i` с
большими номерами и заканчивается нулём.

## Выходные данные

Строка цветов или `-1`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
3
2 0
3 0
0
```

Вывод:

```
010
```

## Решение

Карту можно так раскрасить ровно тогда, когда граф границ двудольный.
Запускаем поиск в ширину от страны 1 с цветом 0 и даём каждой новой
достигнутой стране цвет, противоположный цвету страны, из которой в неё
пришли. Если какая-то граница соединяет две страны одного цвета, есть
нечётный цикл, и ответ `-1`. Карта связна, поэтому цвет страны 1
определяет все остальные, и ответ единственный. `O(N + M)`.

Подводные камни:

- каждая строка перечисляет только соседей с большими номерами, так что
  каждую границу нужно добавить в обе стороны;
- у страны без соседей с большими номерами строка состоит из одного 0;
- цифры выводятся без разделителей.

Ответы сверены с системой непересекающихся множеств, хранящей чётность
пути до корня, — способом, который вообще не обходит карту.

## Особенности языков

- Все языки читают соседей по одному токену до нуля, закрывающего каждую
  строку.
