# 1080. Раскраска карты в два цвета

[Timus 1080](https://acm.timus.ru/problem.aspx?space=1&num=1080) · сложность 186 · bfs, graphs, dsu

Автор оригинальной задачи — Emil Kelevedzhiev; турнир по информатике Зимнего математического фестиваля, Варна, 2001 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На карте `N` стран (`0 < N < 99`); из любой страны можно попасть в любую
другую, пересекая границы. Раскрасьте страны в красный (0) и синий (1)
цвета так, чтобы соседи всегда различались, а страна 1 была красной.
Выведите цвета одной строкой цифр или `-1`, если это невозможно.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк: строка `i` перечисляет соседей страны `i` с
большими номерами и заканчивается нулём.

## Выходные данные

Строка цветов или `-1`.

## Проверка

Точный замороженный кандидат Python повторно проверен независимым
BFS на всех 27 476 связных помеченных простых графах до шести вершин,
затем на 701 случайном и предельном связном графе. Есть нечётные циклы
и полный двудольный граф на 98 вершинах. Эталон фиксирует цвет страны 1
равным 0 и сравнивает единственный ответ либо `-1`. Исчерпывающая проверка
малых графов не означает перебор всех карт на 98 вершинах. Все четыре
реальные DSU-программы также прошли по 11 входов репозитория в Docker
и имеют собственные Accepted точных исходников. 28 177 эталонных входов
запускались на Python, а не по 28 177 раз на каждом компилируемом языке.

## Решение

Допустимая раскраска — это разбиение неориентированного графа границ
на две доли. Хотя вход перечисляет границу только у меньшего конца,
сохраняем её в обе стороны. Запускаем BFS из страны 1 с цветом 0
и красим каждого нового соседа противоположно. Конфликт на границе
доказывает невозможность: два пути BFS и эта граница дают нечётный
замкнутый маршрут, а значит, нечётный цикл. Без конфликтов на каждой
границе цвета различны, поэтому ответ корректен. Связность обеспечивает
обход всех стран, а фиксированный первый цвет определяет единственную
раскраску.

Понятные BFS-версии требуют `O(N + E)` времени и памяти со списками
смежности и очередью; `E` — число границ. Все пять исходных Accepted-баз
сохраняются побайтово. Выводим цифры без разделителей либо `-1` при
конфликте. Строка только с `0` не добавляет границ во входе; `N = 1`
тоже допустимо.

## Оптимизированные решения

Компактная BFS-версия сохраняет обычный инвариант разных цветов у соседей, используя ограниченную очередь и компактные цвета. Отдельная версия Go применяет DSU с паритетом: каждое ребро требует разных паритетов концов. Сжатие путей сохраняет паритет до представителя, противоречие выявляет нечётный цикл. Компонента первой страны нормализуется к требуемому цвету. Потоковая обработка рёбер исключает хранение списка смежности.
