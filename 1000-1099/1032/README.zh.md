# 1032. 选出和为 N 的倍数的若干数

[Timus 1032](https://acm.timus.ru/problem.aspx?space=1&num=1032) · 难度 302 · prefix_sums, math

原题出自 1999 年第三届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 `N` 个正整数（`1 ≤ N ≤ 10 000`，每个不超过 15 000，可以重复），从中选出一个或多个，使它们的和能被 `N`
整除。若无法做到，输出 0。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后每行一个共 `N` 个数。

## 输出

所选数的个数，然后每行一个所选的数，顺序任意；或者 0。

## 评测方式

接受任何正确的选法。检查器验证每个数的使用次数不超过给出的次数、至少选了一个数，且和是 `N` 的倍数。

## 样例

### 样例 1

输入：

```
4
3
8
6
1
```

输出：

```
1
8
```

### 样例 2

输入：

```
1
15000
```

输出：

```
1
15000
```

## 题解

**一定存在选法**，甚至可以是一段连续的数。考虑 `N + 1` 个前缀和 `S_0 = 0, S_1, ..., S_N` 对 `N` 取模。它们
至多有 `N` 种不同的值，由 **抽屉原理**，必有两个相等：`S_i ≡ S_j (mod N)`，`i < j`；于是
`a_{i+1} + ... + a_j = S_j - S_i` 是 `N` 的倍数。

依次遍历这些数，维护前缀和模 `N` 的值以及每个余数第一次出现的位置（余数 0 在位置 0）。第一个重复的余数
就给出了这一段。`O(N)`。

所以永远不需要输出 0。

注意事项：

- 余数 0 必须视为在位置 0 已出现，这样本身就是 `N` 的倍数的前缀也能被找到；
- 输出的是数值，而不是位置；
- `N = 1`：任意一个数都可以。

## 优化解法

`1032_prefix_sums_optimized.py`. Python 保留首个重复前缀余数算法。首次位置和已读数值均用 unsigned-short 数组：N<=10000、数值<=15000，偏移位置也可放入 16 位。零表示未出现，预先记录空前缀。相同余数给出和能被 N 整除的连续证据区间。输出长度，再以至多 512 项分块输出，限制临时拼接字符串，不构建完整证据字符串。在 main 内退出前刷新 stdout，此时两数组仍存活。时间 O(N)，存储 O(N) 加有界输出块。教学版不变。
