# 1032. Выбор чисел с суммой, кратной N

[Timus 1032](https://acm.timus.ru/problem.aspx?space=1&num=1032) · сложность 302 · prefix_sums, math

Оригинальная задача — III командный студенческий чемпионат Урала по программированию, 1999 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны `N` натуральных чисел (`1 ≤ N ≤ 10 000`, каждое не больше 15 000,
возможны повторы). Выберите одно или несколько из них так, чтобы их сумма
делилась на `N`. Если это невозможно, выведите 0.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` чисел по одному в строке.

## Выходные данные

Количество выбранных чисел, затем сами числа по одному в строке, в любом
порядке; или 0.

## Проверка

Принимается любой правильный выбор. Чекер проверяет, что каждое число
использовано не больше раз, чем оно дано, что выбрано хотя бы одно число и
что сумма кратна `N`.

## Примеры

### Пример 1

Ввод:

```
4
3
8
6
1
```

Вывод:

```
1
8
```

### Пример 2

Ввод:

```
1
15000
```

Вывод:

```
1
15000
```

## Решение

**Выбор существует всегда**, причём даже в виде отрезка подряд идущих
чисел. Рассмотрим `N + 1` префиксных сумм `S_0 = 0, S_1, ..., S_N` по модулю
`N`. Они принимают не больше `N` различных значений, значит, по **принципу
Дирихле** две из них равны: `S_i ≡ S_j (mod N)` при `i < j`; тогда
`a_{i+1} + ... + a_j = S_j - S_i` кратна `N`.

Идём по числам, поддерживая префиксную сумму по модулю `N` и первую
позицию, где встретился каждый остаток (остаток 0 — на позиции 0). Первый
повторившийся остаток даёт отрезок. `O(N)`.

Так что ответ 0 никогда не нужен.

Подводные камни:

- остаток 0 должен считаться «виденным» на позиции 0, чтобы находился
  префикс, который сам кратен `N`;
- в выводе — значения чисел, а не их позиции;
- `N = 1`: подходит любое одно число.

## Оптимизированные решения

`1032_prefix_sums_optimized.py`. Python сохраняет поиск первого повторного остатка префикса по модулю N. Первые позиции и прочитанные значения хранятся в массивах беззнаковых коротких целых: N<=10000, значения<=15000 и смещённые позиции помещаются в 16 бит. Ноль означает неизвестный остаток, пустой префикс записан заранее. Равные остатки дают непрерывный отрезок с суммой, кратной N. Длина и значения выводятся блоками не больше 512, без одной строки на весь ответ. Перед выходом внутри main stdout сбрасывается, оба массива ещё живы. Время O(N), память O(N) плюс ограниченный блок вывода. Учебная версия сохранена.

Accepted точного исходника Python 3.12 x64 №11327433: 0.078 с / 820 КБ. Сохранённое сравнение компиляторов от 2026-11-20: время 1/51, память 1/51. При памяти меньше 1024 КБ строгий допуск учитывает только время: первые десять мест или топ 15%, равенства делят место, процентный порог округляется вверх. Обе метрики на первом месте: отдельная цель языка также пройдена, звёздочка не нужна. Прежний документированный оптимизированный запуск №11310314 (Python 3.12 x64): 0.109 с / 1068 КБ; это отдельная историческая пара, не текущий замер данного исходника. Учебные версии сохранены без изменений.

- `1032_prefix_sums_optimized.py`: 0.078 s / 820 KB; сохранённая учебная база `1032_prefix_sums.py`: 0.093 s / 2608 KB.

Принятые базовые реализации [1032_prefix_sums.cpp](1032_prefix_sums.cpp), [1032_prefix_sums.go](1032_prefix_sums.go), [1032_prefix_sums.java](1032_prefix_sums.java), [1032_prefix_sums.rs](1032_prefix_sums.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.

`1032_prefix_sums_optimized.java`. Java обновляет остаток префиксной суммы по мере чтения. В массиве первых позиций ноль означает отсутствие, а настоящие позиции сдвинуты на единицу; пустой префикс заносится заранее. При первом повторе остатка нужные сохранённые значения выводятся напрямую через ограниченный буфер. Равные остатки обеспечивают делимость суммы отрезка на N. Убраны заполнение массива и построение всего ответа, время и память остаются O(N).

По сравнению с `1032_prefix_sums.java`: время 0.156 s → 0.109 s; память 944 KB → 592 KB.
