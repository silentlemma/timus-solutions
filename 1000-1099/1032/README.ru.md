# 1032. Выбор чисел с суммой, кратной N

[Timus 1032](https://acm.timus.ru/problem.aspx?space=1&num=1032) · сложность 301 · prefix_sums, math

Оригинальная задача — III командный студенческий чемпионат Урала по программированию, 1999 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны `N` натуральных чисел (`1 ≤ N ≤ 10 000`, каждое не больше 15 000,
возможны повторы). Выберите одно или несколько из них так, чтобы их сумма
делилась на `N`. Если это невозможно, выведите 0.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` чисел по одному в строке.

## Выходные данные

Количество выбранных чисел, затем сами числа по одному в строке, в любом
порядке; или 0.

## Проверка

Принимается любой правильный выбор. Чекер проверяет, что каждое число
использовано не больше раз, чем оно дано, что выбрано хотя бы одно число и
что сумма кратна `N`.

## Примеры

### Пример 1

Ввод:

```
4
3
8
6
1
```

Вывод:

```
1
8
```

### Пример 2

Ввод:

```
1
15000
```

Вывод:

```
1
15000
```

## Решение

**Выбор существует всегда**, причём даже в виде отрезка подряд идущих
чисел. Рассмотрим `N + 1` префиксных сумм `S_0 = 0, S_1, ..., S_N` по модулю
`N`. Они принимают не больше `N` различных значений, значит, по **принципу
Дирихле** две из них равны: `S_i ≡ S_j (mod N)` при `i < j`; тогда
`a_{i+1} + ... + a_j = S_j - S_i` кратна `N`.

Идём по числам, поддерживая префиксную сумму по модулю `N` и первую
позицию, где встретился каждый остаток (остаток 0 — на позиции 0). Первый
повторившийся остаток даёт отрезок. `O(N)`.

Так что ответ 0 никогда не нужен.

Подводные камни:

- остаток 0 должен считаться «виденным» на позиции 0, чтобы находился
  префикс, который сам кратен `N`;
- в выводе — значения чисел, а не их позиции;
- `N = 1`: подходит любое одно число.
