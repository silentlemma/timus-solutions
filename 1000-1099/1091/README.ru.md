# 1091. Подсчёт наборов чисел с общим делителем

[Timus 1091](https://acm.timus.ru/problem.aspx?space=1&num=1091) · сложность 526 · number_theory

Автор оригинальной задачи — Станислав Васильев; USU Open Collegiate Programming Contest, март 2001 года, Senior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Посчитайте наборы из `K` различных натуральных чисел, не больших `S`
(`2 ≤ K ≤ S ≤ 50`), наибольший общий делитель которых больше 1.
Выведите их количество или 10000, если оно больше.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`K` и `S`.

## Выходные данные

Число наборов, не больше 10000.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
3 10
```

Вывод:

```
11
```

## Решение

Наборов, все числа которых кратны `d`, ровно `C(⌊S/d⌋, K)`. У набора с
общим делителем больше 1 есть общий простой делитель, так что ответ —
размер объединения этих семейств по простым. Включения-исключения по
свободным от квадратов `d > 1` дают

`ответ = Σ −μ(d) · C(⌊S/d⌋, K)`,

где функция Мёбиуса `μ(d)` равна `(−1)^(число простых множителей)` для
свободных от квадратов `d` и 0 иначе: произведения нечётного числа
простых прибавляются, чётного — вычитаются. Небольшое решето вычисляет
`μ` до `S`, а биномиальные коэффициенты берутся из треугольника Паскаля.
`O(S²)`.

Подводные камни:

- настоящее количество может намного превышать 10000, например
  `C(25, 5)` наборов из одних чётных чисел при `K = 5`, поэтому
  ограничивается только итоговое значение, а суммы хранятся в 64 битах;
- набор, посчитанный для `d = 2` и для `d = 3`, посчитан и для `d = 6`,
  поэтому знаки чередуются;
- числа должны быть различными, так что `C(m, K)` равно 0 при `m < K`.

Ответы сверены для всех пар `K ≤ S ≤ 50` с количествами наборов с НОД
ровно `g`, найденными от наибольшего `g` вниз вычитанием количеств для
кратных `g`, а при `S ≤ 20` — с перебором всех наборов.

- Python использует `math.comb`; остальные языки заполняют таблицу
