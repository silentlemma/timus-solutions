# 1048. Сложение двух чисел из миллиона цифр

[Timus 1048](https://acm.timus.ru/problem.aspx?space=1&num=1048) · сложность 200 · implementation

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Два положительных целых числа имеют по `N` цифр (`1 ≤ N ≤ 10^6`, ведущие
нули допускаются), и их сумма тоже помещается в `N` цифр. Числа заданы
столбиком: в строке `i` записаны `i`-е цифры обоих чисел. Выведите сумму
ровно из `N` цифр.

Ограничение времени: 2 секунды. Ограничение памяти: 16 МБ.

## Входные данные

`N`, затем `N` строк с двумя цифрами через пробел.

## Выходные данные

`N` цифр суммы в одной строке.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4
0 4
4 2
6 8
3 7
```

Вывод:

```
4750
```

### Пример 2

Ввод:

```
3
0 0
4 5
5 5
```

Вывод:

```
100
```

## Решение

Сложение в столбик: храним суммы столбцов (от 0 до 18) в массиве байтов,
затем идём от последнего столбца к первому, добавляем перенос и оставляем
`t mod 10` с новым переносом `t div 10`. Тот же массив из `N` байтов
становится цифрами ответа. Время `O(N)`, память — `N` байтов.

Трудность только в размере: около 4 МБ ввода при ограничении памяти 16 МБ.
Читать нужно быстро и не хранить объекты или 4-байтовые целые на каждую
цифру.

Подводные камни:

- ведущие нули суммы печатаются: в выводе ровно `N` цифр;
- перенос может пройти через все миллион цифр (`0999…9 + 000…1`);
- переводить числа в тип длинных целых не нужно, а во многих языках это
  ещё и квадратично.

## Особенности языков

- **C++**, **Java**: буферизованное побайтовое чтение через `fread` /
  `DataInputStream`; **Go**: `bufio.Reader.ReadByte`; **Rust**: весь ввод
  в одном векторе байтов.
- **Python**: весь ввод — один объект `bytes`; `translate` удаляет
  пробельные символы, срезы с шагом 2 разделяют два числа, а цикл
  переносов пишет в `bytearray`. Перевод через `int()` был бы квадратичным
  (а Python 3.12 по умолчанию отказывается разбирать строки длиннее 4300
  цифр).
