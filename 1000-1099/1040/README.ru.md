# 1040. Нумерация рёбер с взаимно простыми номерами в каждой вершине

[Timus 1040](https://acm.timus.ru/problem.aspx?space=1&num=1040) · сложность 1001 · dfs, constructive

Автор оригинальной задачи — Дмитрий Филимоненков; Пятый командный чемпионат УрГУ по программированию, октябрь 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Связный неориентированный граф имеет `N` вершин (`2 ≤ N ≤ 50`) и `M` рёбер
(`1 ≤ M ≤ N(N − 1)/2`), без петель и кратных рёбер. Пронумеруйте рёбра
числами `1..M`, каждым по одному разу, так чтобы в каждой вершине с двумя
и более рёбрами наибольший общий делитель их номеров был равен 1. Выведите
`NO`, если это невозможно.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `M`, затем `M` строк с двумя концами каждого ребра.

## Выходные данные

`YES` и на следующей строке номера рёбер в порядке ввода; или `NO`.

## Проверка

Принимается любая подходящая нумерация. Проверяющая программа убеждается,
что ответ `YES`, что номера — перестановка `1..M` и что НОД в каждой
вершине хотя бы с двумя рёбрами равен 1.

## Примеры

### Пример 1

Ввод:

```
6 6
1 2
2 3
2 4
4 3
5 6
4 5
```

Вывод:

```
YES
1 2 4 3 6 5
```

### Пример 2

Ввод:

```
2 1
2 1
```

Вывод:

```
YES
1
```

## Решение

Ответ всегда `YES`, потому что два соседних числа взаимно просты.
Запустим поиск в глубину из любой вершины и будем давать каждому ребру
следующий номер счётчика, когда поиск впервые его рассматривает, — ведёт
ли оно в новую вершину или в уже посещённую:

```text
dfs(v):
    пометить v
    для каждого ребра e = (v, w):
        если у e нет номера:
            number[e] = ++counter
            если w не помечена: dfs(w)
```

Возьмём вершину `w`, в которую вошли по ребру с номером `k`. Ни одно другое
её ребро ещё не пронумеровано: ребро из более ранней вершины в `w` уже
привело бы поиск в `w`. Между присвоением `k` и вызовом `dfs(w)` ничего не
нумеруется, поэтому первое другое ребро `w` получает `k + 1`, а
`gcd(k, k + 1)` равен 1. Стартовая вершина получает номер 1 на первом
ребре. Вершине с одним ребром ничего не нужно. `O(N + M)`.

Подводные камни:

- рёбра в уже посещённые вершины нужно нумеровать в том же проходе: если
  нумеровать сначала только рёбра дерева, а остальные потом, рассуждение
  ломается;
- `NO` никогда не бывает ответом: граф связен;
- в ответе номера идут в порядке рёбер во входных данных.

## Особенности языков

- Во всех языках рекурсивный DFS; глубина не больше 50.
