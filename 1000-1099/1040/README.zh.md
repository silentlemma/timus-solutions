# 1040. 使每个顶点处编号互质的边编号

[Timus 1040](https://acm.timus.ru/problem.aspx?space=1&num=1040) · 难度 1001 · dfs, constructive

原题作者 Dmitry Filimonenkov，出自 2000 年 10 月第五届乌拉尔国立大学团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个连通无向图有 `N` 个顶点（`2 ≤ N ≤ 50`）和 `M` 条边（`1 ≤ M ≤ N(N − 1)/2`），没有自环和重边。用
`1..M` 给边编号，每个数用一次，使得每个至少有两条边的顶点处，这些边编号的最大公约数为 1。若做不到，输出
`NO`。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N` 和 `M`，然后 `M` 行，每行是一条边的两个端点。

## 输出

`YES`，下一行按输入顺序给出各边的编号；或者 `NO`。

## 评测方式

接受任意合法的编号。检查程序验证答案是 `YES`，编号是 `1..M` 的一个排列，并且每个至少有两条边的顶点处
最大公约数为 1。

## 样例

### 样例 1

输入：

```
6 6
1 2
2 3
2 4
4 3
5 6
4 5
```

输出：

```
YES
1 2 4 3 6 5
```

### 样例 2

输入：

```
2 1
2 1
```

输出：

```
YES
1
```

## 题解

答案总是 `YES`，因为相邻的两个整数互质。从任意顶点开始深度优先搜索，每条边在搜索第一次看到它时得到计数器
的下一个编号——无论它通向新顶点还是已访问的顶点：

```text
dfs(v):
    标记 v
    对每条边 e = (v, w):
        若 e 还没有编号:
            number[e] = ++counter
            若 w 未被标记: dfs(w)
```

设顶点 `w` 是经由编号为 `k` 的边进入的。它的其他边都还没有编号：如果有更早的顶点通向 `w` 的边，搜索早就
进入 `w` 了。在赋值 `k` 和调用 `dfs(w)` 之间没有给任何边编号，所以 `w` 的第一条其他边得到 `k + 1`，而
`gcd(k, k + 1)` 为 1。起点的第一条边编号为 1。只有一条边的顶点没有要求。`O(N + M)`。

注意事项：

- 通向已访问顶点的边必须在同一遍中编号；如果先只给树边编号、其余的边之后再编，上述论证就不成立；
- 答案永远不是 `NO`：图是连通的；
- 答案中的编号按输入中边的顺序给出。

- 各语言都用递归 DFS；深度不超过 50。
