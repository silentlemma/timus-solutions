# 1090. Шеренга новобранцев, которая прыгает больше всех: подсчёт инверсий

[Timus 1090](https://acm.timus.ru/problem.aspx?space=1&num=1090) · сложность 365 · fenwick, binary_search

Автор оригинальной задачи — Никита Шамгунов; USU Open Collegiate Programming Contest, март 2001 года, Senior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `K` шеренг (`1 ≤ K ≤ 20`) по `N` новобранцев (`2 ≤ N ≤ 10000`),
занумерованных по росту от 1 (самый высокий) до `N`; каждая шеренга —
перестановка чисел `1 … N`. Каждый новобранец подпрыгивает по разу за
каждого стоящего перед ним в шеренге с большим номером. Выведите
шеренгу с наибольшим общим числом прыжков, при равенстве — с наименьшим
номером.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `K`, затем `K` строк по `N` чисел.

## Выходные данные

Номер шеренги.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
3 3
1 2 3
2 1 3
3 2 1
```

Вывод:

```
3
```

## Решение

Общее число прыжков в шеренге — это число инверсий перестановки: пар
позиций `i < j` с `a[i] > a[j]`. При `N = 10000` двойной цикл слишком
медленный, поэтому считаем их по ходу чтения шеренги. Перед новобранцем
`x` на позиции `i` стоят `i` новобранцев, а число тех из них, у кого
номер меньше, — это префиксная сумма в дереве Фенвика по номерам
`1 … N`; прыжки `x` равны `i` минус эта сумма. Затем добавляем `x` в
дерево. `O(K · N log N)`.

Подводные камни:

- сумма по шеренге доходит до `N(N − 1)/2 ≈ 5 · 10^7`; она помещается в
  32 бита, но решения складывают в 64 битах;
- при равенстве побеждает первая шеренга, поэтому лучшую заменяет только
  строго большая сумма;
- дерево нужно очищать для каждой шеренги.

Ответы сверены с подсчётом инверсий сортировкой слиянием, а при
`N ≤ 300` — ещё и двойным циклом.

## Особенности языков

- Python хранит уже встреченные номера шеренги в отсортированном списке,
  находит количество через `bisect` и вставляет каждый номер через
  `list.insert`. Вставки сдвигают память, `O(N²)` в теории, но работают на
  C и обгоняют дерево Фенвика, написанное на Python, при `N = 10000`.
- Под CPython 3.12 решение на Python превышает ограничение времени на
  тесте 9 (0,515 с); тот же файл принимается на PyPy 3.10 за 0,437 с, так
  что решение на Python проходит только под PyPy.
