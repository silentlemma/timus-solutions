# 1081. 没有相邻 1 的第 K 个二进制串

[Timus 1081](https://acm.timus.ru/problem.aspx?space=1&num=1081) · 难度 269 · dp

原题作者 Emil Kelevedzhiev，出自 2001 年瓦尔纳冬季数学节信息学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

考虑所有长度为 `N`（`0 < N < 44`）、由 0 和 1 组成且没有两个相邻 1 的串，按字典序排列。输出其中第 `K` 个
（`0 < K < 10^9`）；如果不足 `K` 个，输出 `-1`。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N` 和 `K`。

## 输出

该串，或 `-1`。

## 评测方式

按记号逐个比较输出；多余的空白不影响结果。

## 样例

### 样例 1

输入：

```
3 1
```

输出：

```
000
```

## 题解

设 `count[r]` 为长度为 `r` 的合法串的个数：一个串要么以 0 开头再接任意合法的后续，要么以 `10` 开头再接任意
合法的后续，所以 `count[r] = count[r − 1] + count[r − 2]`，`count[0] = 1`，`count[1] = 2`，这就是斐波那契数。

从左到右构造答案。如果前一个字符是 1，这一位必须是 0。否则这一位为 0 的串在顺序中排在前面，共有
`count[rest]` 个，其中 `rest` 是这一位之后的位置数（0 不限制下一个字符）。若 `K ≤ count[rest]`，写 0；否则从
`K` 中减去 `count[rest]`，写 1。如果一开始就有 `K > count[N]`，输出 `-1`。`O(N)`。

注意事项：

- `count[43] = 1 134 903 170` 比任何 `K` 都大，所以 `N = 43` 时总有答案；计数仍然用 64 位整数保存；
- 1 之后的下一个字符是确定的，`K` 不变；
- 串从 `K = 1`（全零串）开始计数。

`N ≤ 20` 时答案与所有合法串排序后的列表做了核对；更长的串则用记忆化计数反过来求出答案的序号进行核对。

## 各语言说明

- Python 用 `append` 扩展 `count` 列表，直到长度达到 `N`。
