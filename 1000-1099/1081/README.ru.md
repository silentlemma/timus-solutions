# 1081. K-я двоичная строка без двух соседних единиц

## Задача

Рассмотрим все строки длины `N` (`0 < N < 44`) из 0 и 1 без двух соседних
единиц, упорядоченные лексикографически. Выведите `K`-ю из них
(`0 < K < 10^9`) или `-1`, если их меньше `K`.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `K`.

## Выходные данные

Строка или `-1`.

## Проверка

Сравнивается двоичная строка длины N либо -1 при недопустимом ранге. Новый точный исходник Python прошёл 15 тестов репозитория на PyPy 3.10. Также 239 исчерпывающих проверок коротких строк и рангов. Остальные сохранённые варианты имеют собственные проверки целевой среды и точные Accepted. Вывод сравнивается по правилам проверяющего модуля задачи.

## Примеры

### Пример 1

Ввод:

```
3 1
```

Вывод:

```
000
```

## Решение

Пусть `count[r]` — число допустимых строк длины `r`: строка начинается
либо с 0 и любого допустимого продолжения, либо с `10` и любого
допустимого продолжения, так что `count[r] = count[r − 1] + count[r − 2]`
при `count[0] = 1` и `count[1] = 2` — это числа Фибоначчи.

Строим ответ слева направо. Если предыдущий символ — 1, этот обязан быть
0. Иначе строки с 0 на этом месте идут в порядке первыми, и их
`count[rest]`, где `rest` — число позиций после текущей (0 не
ограничивает следующий символ). Если `K ≤ count[rest]`, пишем 0; иначе
вычитаем `count[rest]` из `K` и пишем 1. Если с самого начала
`K > count[N]`, выводим `-1`. `O(N)`.

Подводные камни:

- `count[43] = 1 134 903 170` больше любого `K`, так что при `N = 43`
  ответ есть всегда; количества всё равно хранятся в 64-битных целых;
- после 1 следующий символ вынужден, и `K` не меняется;
- строки считаются с `K = 1` — строки из одних нулей.

Ответы сверены с отсортированным списком всех допустимых строк при
`N ≤ 20`, а для более длинных строк — вычислением номера ответа обратно
через подсчёт с запоминанием.

## Оптимизированные решения

Понятная таблица количеств Фибоначчи сохранена. Компактные версии держат два соседних количества и при восстановлении обращают рекуррентное соотношение. Если остаточный ранг с нуля не меньше числа строк с нулевым префиксом, вычитается это число и выводится единица; иначе ноль. После единицы оставшийся интервал рангов меньше следующего количества с нулевым префиксом, поэтому следующий бит автоматически нулевой. Полное количество проверяет допустимость ранга. Python собирает ответ в одном целом и форматирует ровно N бит: сохраняется O(N)-битный ответ, а не таблица количеств.

- `1081_dp_optimized.java`: 0.078 s / 372 KB; база `1081_dp.java`: 0.125 s / 1640 KB; изменение относительно базы: время -37.6%, память -77.3%.
- `1081_dp_optimized.py`: 0.125 s / 284 KB; база `1081_dp.py`: 0.093 s / 476 KB; изменение относительно базы: время +34.4%, память -40.3%.
