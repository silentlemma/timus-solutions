# 1083. 带 k 个感叹号的阶乘

[Timus 1083](https://acm.timus.ru/problem.aspx?space=1&num=1083) · 难度 68 · math

原题作者 Oleg Kats，出自 2001 年 3 月 4 日斯维尔德洛夫斯克州第三届中学生团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

带 `k` 个感叹号的 `n!…!` 是乘积 `n(n − k)(n − 2k)…`，它在 `n mod k` 处结束；若 `k` 整除 `n`，则在 `k` 处结束。
例如 `10!!! = 10 · 7 · 4 · 1`。给定 `n`（`1 ≤ n ≤ 10`）和 `k` 个感叹号（`1 ≤ k ≤ 20`），输出它的值。

时间限制：1 秒。内存限制：64 MB。

## 输入

`n`，一个空格，然后是 `k` 个感叹号。

## 输出

`n!…!` 的值。

## 评测方式

按记号逐个比较输出；多余的空白不影响结果。

## 样例

### 样例 1

输入：

```
9 !!
```

输出：

```
945
```

## 题解

定义中的两种结尾都是数列 `n, n − k, n − 2k, …` 的最后一个正项，所以只要在项为正时一直相乘即可。`O(n/k)`。

注意事项：

- 输入中的 `k` 不是一个数，而是感叹号串的长度；
- 当 `k ≥ n` 时只有一个因数，就是 `n` 本身；
- 最大值 `10! = 3 628 800`，32 位整数放得下。

答案与直接按定义（两种结尾）计算的结果做了核对。

## 各语言说明

- C++、Go、Java 和 Rust 把感叹号作为一个记号读入并取其长度；Python 统计空格后的 `!` 字符个数。
