# 1083. Факториал с k восклицательными знаками

[Timus 1083](https://acm.timus.ru/problem.aspx?space=1&num=1083) · сложность 68 · math

Автор оригинальной задачи — Олег Кац; третье командное соревнование школьников Свердловской области по программированию, 4 марта 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

С `k` восклицательными знаками `n!…!` — это произведение
`n(n − k)(n − 2k)…`, которое заканчивается на `n mod k` или на `k`, если
`k` делит `n`. Например, `10!!! = 10 · 7 · 4 · 1`. По данным `n`
(`1 ≤ n ≤ 10`) и `k` (`1 ≤ k ≤ 20`) знакам выведите значение.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`n`, один пробел, затем `k` восклицательных знаков.

## Выходные данные

Значение `n!…!`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
9 !!
```

Вывод:

```
945
```

## Решение

Оба окончания в определении — это последний положительный член
последовательности `n, n − k, n − 2k, …`, поэтому перемножаем члены, пока
они положительны. `O(n/k)`.

Подводные камни:

- `k` во входных данных — не число, а длина строки из знаков;
- при `k ≥ n` множитель один — само `n`;
- наибольшее значение `10! = 3 628 800` помещается в 32-битные целые.

Ответы сверены с прямым прочтением определения с обоими окончаниями.

## Особенности языков

- C++, Go, Java и Rust читают знаки одним токеном и берут его длину;
  Python считает символы `!` после пробела.
