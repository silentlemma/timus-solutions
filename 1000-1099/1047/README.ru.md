# 1047. Первый неизвестный член рекуррентности второго порядка

[Timus 1047](https://acm.timus.ru/problem.aspx?space=1&num=1047) · сложность 305 · math

Автор оригинальной задачи — Дмитрий Филимоненков; студенческое соревнование по программированию УрГУ, 25 марта 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Последовательность `a0, a1, …, aN+1` (`1 ≤ N ≤ 3000`,
`−2000 ≤ ai ≤ 2000`) удовлетворяет `ai = (ai−1 + ai+1) / 2 − ci` для
каждого `i = 1 … N`. По `a0`, `aN+1` и `c1 … cN`, заданным с двумя знаками
после запятой, найдите `a1`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `a0`, затем `aN+1`, затем `c1 … cN`, по одному числу в строке.

## Выходные данные

`a1` с двумя знаками после запятой.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
1
50.50
25.50
10.15
```

Вывод:

```
27.85
```

### Пример 2

Ввод:

```
2
0.00
9.00
1.00
1.00
```

Вывод:

```
1.00
```

## Решение

Перепишем соотношение через разности `d[i] = a[i] − a[i−1]`:

```text
a[i+1] − 2·a[i] + a[i−1] = 2·c[i]   →   d[i+1] = d[i] + 2·c[i]
```

Значит, `d[k] = d[1] + 2·(c[1] + … + c[k−1])`, и в сумме всех разностей от
`d[1]` до `d[N+1]` каждое `c[i]` встречается `N + 1 − i` раз:

```text
a[N+1] − a[0] = (N + 1)·d[1] + 2 · Σ (N + 1 − i)·c[i]
a[1] = a[0] + d[1] = (N·a[0] + a[N+1] − 2 · Σ (N + 1 − i)·c[i]) / (N + 1)
```

`O(N)`. Чтобы не бороться с округлением, C++, Go, Java и Rust считают в
сотых: все входные числа становятся целыми, числитель остаётся меньше
примерно `10^12`, а результат деления на `N + 1` округляется до ближайшей
сотой.

Подводные камни:

- сумма 3000 вещественных слагаемых может «уплыть», а вывод должен
  содержать ровно два знака; целые числа в сотых избавляют от обоих
  проблем;
- отрицательный ответ между −1 и 0 должен печататься как `-0.35`, а не
  `0.35` или `-0.-35`.

## Оптимизированные решения

Go и Rust читают числа с двумя дробными знаками как знаковое целое количество сотых. Взвешенная сумма коэффициентов накапливается при чтении, затем выражение N·a₀ + aₙ₊₁ − 2Σ(N+1−i)cᵢ делится на N+1. Модуль округляется до ближайшей сотой, при равенстве — от нуля, после чего возвращается знак. Округлённый ноль выводится без минуса. Обе версии читают и формируют ответ в фиксированных байтовых буферах без преобразования строк.

Принятые базовые реализации [1047_math.cpp](1047_math.cpp), [1047_math.java](1047_math.java), [1047_math.py](1047_math.py) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
