# 1047. 二阶递推的第一个未知项

[Timus 1047](https://acm.timus.ru/problem.aspx?space=1&num=1047) · 难度 303 · math

原题作者 Dmitry Filimonenkov，出自 2000 年 3 月 25 日乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

序列 `a0, a1, …, aN+1`（`1 ≤ N ≤ 3000`，`−2000 ≤ ai ≤ 2000`）对每个 `i = 1 … N` 满足
`ai = (ai−1 + ai+1) / 2 − ci`。给定都带两位小数的 `a0`、`aN+1` 和 `c1 … cN`，求 `a1`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后是 `a0`、`aN+1`，再然后是 `c1 … cN`，每行一个数。

## 输出

带两位小数的 `a1`。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
1
50.50
25.50
10.15
```

输出：

```
27.85
```

### 样例 2

输入：

```
2
0.00
9.00
1.00
1.00
```

输出：

```
1.00
```

## 题解

用差分 `d[i] = a[i] − a[i−1]` 改写关系式：

```text
a[i+1] − 2·a[i] + a[i−1] = 2·c[i]   →   d[i+1] = d[i] + 2·c[i]
```

所以 `d[k] = d[1] + 2·(c[1] + … + c[k−1])`；把 `d[1]` 到 `d[N+1]` 的所有差分加起来，每个 `c[i]` 出现
`N + 1 − i` 次：

```text
a[N+1] − a[0] = (N + 1)·d[1] + 2 · Σ (N + 1 − i)·c[i]
a[1] = a[0] + d[1] = (N·a[0] + a[N+1] − 2 · Σ (N + 1 − i)·c[i]) / (N + 1)
```

`O(N)`。为避免舍入问题，解法以百分之一为单位计算：所有输入都变成整数，分子不超过约 `10^12`，对于一致的输入，
除以 `N + 1` 是整除（保险起见仍四舍五入到最近的百分之一）。

注意事项：

- 3000 个浮点数相加可能产生累积误差，而输出必须恰好两位小数；用以百分之一为单位的整数可以同时避免这两个问题；
- −1 到 0 之间的负数答案要输出为 `-0.35`，而不是 `0.35` 或 `-0.-35`。

## 各语言说明

- **C++**、**Go**、**Java**、**Rust**：以百分之一为单位的 64 位整数。
- **Python**：从十进制字符串解析出的精确 `Fraction`。
