# 1074. 把实数改写成小数点后恰好 N 位

[Timus 1074](https://acm.timus.ru/problem.aspx?space=1&num=1074) · 难度 2110 · parsing

原题作者 Alexander Klepinin，出自 2001 年 2 月 Ural State University Personal Contest Online（Students Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

实数由可选的符号、数字串（`digits`、`.digits` 或 `digits.digits`）以及可选的 `e` 或 `E` 加一个可带符号的
整数组成。输入由若干对行组成：一行最多 100 个字符、字符编码在 32–255 之间的 `S`，以及一个整数
`0 ≤ N ≤ 100`；单独一行 `#` 表示输入结束。对每一对，如果 `S` 不是实数，输出 `Not a floating point number`；
否则输出它的值，小数点后恰好 `N` 位，多余的位直接截去而不四舍五入，整数部分没有前导零（整数部分为零时写一个
`0`），也不带 `+` 号。保证答案不超过 200 个字符。

时间限制：1 秒。内存限制：64 MB。

## 输入

若干对行 `S` 和 `N`，最后是一行 `#`。

## 输出

每一对输出一行。

## 评测方式

按行比较输出；行内按记号逐个比较。测试以 UTF-8 保存这些行，以 latin-1 交给解法，32 到 255 之间的每个字符
对应一个字节。

## 样例

### 样例 1

输入：

```
10.23
0
.04
1
-0.051e0
1
1.1e30
10
-1.1E-30
1
2468097632.1358642324268913e-2
20
e23
3
1 e3
1
#
```

输出：

```
10
0.0
0.0
1100000000000000000000000000000.0000000000
0.0
24680976.32135864232426891300
Not a floating point number
Not a floating point number
```

## 题解

严格按照文法手工解析这一行：可选的符号，小数点前的数字，然后要么是小数点加至少一位数字，要么没有小数点但小数点
前至少有一位数字，然后是至少带一位数字的可选指数部分，此外不能有任何东西。任何其他字符，包括空格，都会使这一行
无效。

绝不要把数转换成浮点值。把小数点前后的数字拼成一个字符串 `D`；小数点位于它的第 `len(前) + 指数` 位之后，这个
位置可能是负数，也可能超出 `D` 的末尾。整数部分是 `D` 中这个位置之前的数字，右边不足时补零，去掉前导零（或为
`0`）；小数部分是接下来的 `N` 位数字，不足时补零。直接截掉多余的数字正是题目要求的截断。`O(|S| + N)`。

注意事项：

- 只有当输出的数字中有非零数字时才保留负号：`-0.051` 保留一位是 `0.0`，`-1.1E-30` 也是；
- `N = 0` 时完全没有小数点；
- `5.`、`.`、`e5`、`1e`、`1e+`、`1.e5` 以及空行都不是数，而 `.5`、`+.5` 和 `-0` 是；
- 指数可能有几十位：读取时把它的值限制在 1000 以内；更大的指数要么使答案为零（`D` 最多 100 位），要么被
  200 个字符的保证排除，除非所有数字都是零，而那时指数无关紧要；
- 编码大于 127 的字符不能被当作数字或空白：Python 的 `str.isdigit` 会接受 `²`，而按 UTF-8 读取输入遇到
  这样的字节会出错，所以按字节或 latin-1 读取输入，并用 `'0' ≤ c ≤ '9'` 判断数字；
- 每行只去掉末尾的回车符；空格是 `S` 的一部分。

答案在手工构造的行和数千条随机行上做了核对，核对方法是用正则表达式检查文法、用精确的分数运算计算数值。

## 各语言说明

- C++ 用 `std::getline` 读取行，它会保留每一个字节。
- Go 和 Rust 把整个输入当作字节读入，再按 `\n` 拆分。
- Java 读取字节并按 ISO-8859-1 解码，每个字节对应一个字符。
- Python 出于同样的原因把 `sys.stdin.buffer` 按 latin-1 解码。
