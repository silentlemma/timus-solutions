# 1074. Запись вещественного числа ровно с N знаками после точки

[Timus 1074](https://acm.timus.ru/problem.aspx?space=1&num=1074) · сложность 2110 · parsing

Автор оригинальной задачи — Александр Клепинин; Ural State University Personal Contest Online, февраль 2001 года, Students Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Вещественное число — это необязательный знак, затем цифры, `.цифры` или
`цифры.цифры`, затем необязательно `e` или `E` с целым числом, возможно
со знаком. Вход состоит из пар строк: строки `S` длиной до 100 символов с
кодами 32–255 и целого `0 ≤ N ≤ 100`; строка `#` завершает вход. Для
каждой пары выведите `Not a floating point number`, если `S` — не
вещественное число; иначе выведите его значение ровно с `N` знаками после
точки, отбросив остальные без округления, без ведущих нулей в целой части
(нулевая целая часть — один `0`) и без знака `+`. Гарантируется, что ответ
не длиннее 200 символов.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Пары строк `S` и `N`, затем строка `#`.

## Выходные данные

По одной строке на каждую пару.

## Проверка

Вывод сравнивается построчно; внутри строки — по токенам. Тесты хранят
строки в UTF-8 и передают их решениям в latin-1 — по одному байту на
каждый символ от 32 до 255.

## Примеры

### Пример 1

Ввод:

```
10.23
0
.04
1
-0.051e0
1
1.1e30
10
-1.1E-30
1
2468097632.1358642324268913e-2
20
e23
3
1 e3
1
#
```

Вывод:

```
10
0.0
0.0
1100000000000000000000000000000.0000000000
0.0
24680976.32135864232426891300
Not a floating point number
Not a floating point number
```

## Решение

Разбираем строку вручную, в точности по грамматике: необязательный знак,
цифры до точки, затем либо точка и хотя бы одна цифра после неё, либо без
точки, но тогда хотя бы одна цифра до неё, затем необязательная
экспонента хотя бы с одной цифрой — и больше ничего. Любой другой символ,
в том числе пробел, делает строку неверной.

Число нельзя превращать в значение с плавающей точкой. Склеиваем цифры до
и после точки в одну строку `D`; десятичная точка стоит после
`len(до) + экспонента` её цифр, и эта позиция может быть отрицательной
или лежать за концом `D`. Целая часть — цифры `D` до этой позиции,
дополненные справа нулями, без ведущих нулей (или `0`); дробная — следующие
`N` цифр, дополненные нулями. Отбрасывание цифр — это ровно требуемое
усечение. `O(|S| + N)`.

Подводные камни:

- минус остаётся, только если хотя бы одна выведенная цифра не ноль:
  `-0.051` с одним знаком — это `0.0`, как и `-1.1E-30`;
- при `N = 0` десятичной точки нет совсем;
- `5.`, `.`, `e5`, `1e`, `1e+`, `1.e5` и пустая строка — не числа, а
  `.5`, `+.5` и `-0` — числа;
- в экспоненте могут быть десятки цифр: при чтении её значение
  ограничивается 1000; большее значение либо делает ответ нулём (в `D` не
  больше 100 цифр), либо исключено гарантией про 200 символов, если только
  все цифры не нули, а тогда оно неважно;
- символы с кодами выше 127 не должны считаться цифрами или пробелами:
  `str.isdigit` в Python принимает `²`, а чтение входа как UTF-8 ломается
  на таких байтах, поэтому вход читается как байты или latin-1, а цифры
  проверяются как `'0' ≤ c ≤ '9'`;
- со строки удаляется только завершающий возврат каретки; пробелы — часть
  `S`.

Ответы сверены с регулярным выражением для грамматики и точной
арифметикой дробей для значения — на строках, составленных вручную, и на
тысячах случайных.

## Особенности языков

- C++ читает строки через `std::getline`, который сохраняет каждый байт.
- Go и Rust читают весь вход как байты и делят его по `\n`.
- Java читает байты и декодирует их как ISO-8859-1, где каждому байту
  соответствует один символ.
- Python по той же причине декодирует `sys.stdin.buffer` как latin-1.
