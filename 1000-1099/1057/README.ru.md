# 1057. Суммы K различных степеней B на отрезке

[Timus 1057](https://acm.timus.ru/problem.aspx?space=1&num=1057) · сложность 717 · combinatorics

Оригинальная задача — Рыбинская государственная авиационная академия.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Посчитайте целые числа на отрезке `[X, Y]` (`1 ≤ X ≤ Y ≤ 2^31 − 1`),
которые являются суммой ровно `K` различных степеней числа `B` с целыми
показателями (`1 ≤ K ≤ 20`, `2 ≤ B ≤ 10`).

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`X` и `Y`, затем `K`, затем `B`.

## Выходные данные

Количество таких чисел.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
15 20
2
2
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
1 100
1
10
```

Вывод:

```
3
```

## Решение

Различные отрицательные степени `B` в сумме дают меньше 1, поэтому целая
сумма использует только неотрицательные показатели. Такое число — ровно
то, у которого все цифры в системе по основанию `B` равны 0 или 1, а
единиц `K`. Посчитаем их на `[0, n]` функцией `f(n)`; ответ —
`f(Y) − f(X − 1)`.

Для `f(n)` запишем `n` по основанию `B` (не больше 31 цифры):

1. если какая-то цифра больше 1, то любая строка из 0 и 1, совпадающая с
   `n` выше этой цифры, меньше `n` независимо от продолжения, поэтому эту
   цифру и все младшие можно заменить на 1, не меняя ответа;
2. теперь все цифры 0 или 1: идём сверху, считая взятые единицы; на
   цифре 1 выбор 0 оставляет `i` младших позиций свободными, что даёт
   `C(i, K − ones)` чисел; выбор 1 продолжает проход;
3. в конце само `n` учитывается, если в нём ровно `K` единиц.

`O(log_B Y)` с небольшой таблицей биномиальных коэффициентов.

Подводные камни:

- цифры по основанию `B` должны быть 0 или 1; цифра 2 и больше — это уже
  не сумма *различных* степеней;
- `f(X − 1)` при `X = 1` — это `f(0) = 0`;
- при `B = 10` ниже `2^31` всего 10 позиций, поэтому `K > 10` даёт 0.
