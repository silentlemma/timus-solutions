# 1010. Самая крутая хорда над дискретной функцией

[Timus 1010](https://acm.timus.ru/problem.aspx?space=1&num=1010) · сложность 295 · math

Оригинальная задача — Third Open USTU Collegiate Programming Contest (PhysTech Cup), 2000.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Функция задана значениями `f(1), ..., f(N)` (`2 ≤ N ≤ 100 000`,
`-2^31 ≤ f(i) ≤ 2^31 - 1`). Пара точек `A = (a, f(a))` и `B = (b, f(b))`,
`a < b`, **допустима**, если каждая точка `(i, f(i))` с `a < i < b` лежит
строго ниже прямой `AB`. Среди допустимых пар найдите пару с наибольшим
модулем углового коэффициента `AB`; если таких несколько — с наименьшим `a`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` значений `f(1), ..., f(N)`, по одному в строке.

## Выходные данные

`a` и `b`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4
1
5
2
-4
```

Вывод:

```
3 4
```

### Пример 2

Ввод:

```
2
7
7
```

Вывод:

```
1 2
```

## Решение

Ответ — всегда пара соседей `(a, a + 1)`: первая с наибольшим
`|f(a + 1) - f(a)|`.

Почему: угловой коэффициент хорды от `a` до `b` — среднее коэффициентов
`b - a` единичных шагов под ней, поэтому по модулю он не больше наибольшего
модуля коэффициента шага. Соседние пары всегда допустимы (между ними ничего
нет), значит, максимум достигается на шаге. Более длинная хорда может
сравняться с ним, только если все её шаги имеют одинаковый коэффициент, — но
тогда промежуточные точки лежат на прямой, а не строго ниже, и хорда
недопустима. Итак, шаги с наибольшим `|разностью|` — ровно оптимальные пары, и
первый из них имеет наименьшее `a`.

Время `O(N)`, память `O(1)` (или `O(N)`, если хранить значения).

Подводные камни:

- разность двух значений достигает `2^32 - 1`: нужны 64-битные целые;
- равенство: оставляем первый максимум (строгое сравнение при проходе слева
  направо);
- условие допустимости наводит на мысль о выпуклой оболочке, но на ответ оно
  никогда не влияет.

## Оптимизированные решения

Максимальный модуль наклона достигается на соседних точках. Оптимизированный проход хранит только предыдущее значение и первый наибольший перепад, без полного массива значений или разностей. Обновление лишь при строгом улучшении сохраняет нужное равенство; перед модулем разность вычисляется в 64-битной арифметике. Буферизованный ввод в машинных языках и построчный ввод Python сокращают накладные расходы, не меняя доказательства.
