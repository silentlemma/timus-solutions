# 1010. 离散函数上方最陡的弦

[Timus 1010](https://acm.timus.ru/problem.aspx?space=1&num=1010) · 难度 295 · math

原题出自 2000 年 Third Open USTU Collegiate Programming Contest (PhysTech Cup)。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

函数由其取值 `f(1), ..., f(N)` 给出（`2 ≤ N ≤ 100 000`，`-2^31 ≤ f(i) ≤ 2^31 - 1`）。点对
`A = (a, f(a))` 与 `B = (b, f(b))`（`a < b`）称为 **合法**，当且仅当所有满足 `a < i < b` 的点
`(i, f(i))` 都严格位于直线 `AB` 下方。在所有合法点对中，求直线 `AB` 斜率绝对值最大的一对；若有多对，
取 `a` 最小的那一对。

时间限制：1 秒。内存限制：64 MB。

## 输入

先是 `N`，然后是 `N` 个值 `f(1), ..., f(N)`，每行一个。

## 输出

`a` 和 `b`。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
4
1
5
2
-4
```

输出：

```
3 4
```

### 样例 2

输入：

```
2
7
7
```

输出：

```
1 2
```

## 解法
答案总是一对相邻点 `(a, a + 1)`：第一个使 `|f(a + 1) - f(a)|` 最大的位置。

原因：从 `a` 到 `b` 的弦的斜率是其下方 `b - a` 个单位步长斜率的平均值，因此其绝对值不超过单步斜率
绝对值的最大值。相邻点对总是合法的（中间没有点），所以最大值在某一步上取到。更长的弦只有在所有步的
斜率都相同时才能与之相等——但这时中间的点都在直线上，而不是严格在下方，这条弦不合法。因此差值绝对值
最大的那些步恰好就是最优点对，其中第一个的 `a` 最小。

时间 `O(N)`，空间 `O(1)`（若存储所有值则为 `O(N)`）。

注意事项：

- 两个值的差可达 `2^32 - 1`：需使用 64 位整数；
- 相等情况：保留第一个最大值（从左到右扫描时用严格比较）；
- 合法性条件看起来需要凸包，但它从不影响答案。

## 优化解法

绝对斜率最大值可在相邻点取得。优化扫描只保存前一个值和最早的最大差，不保存全部函数值或差分数组。仅在严格变优时更新以保留最早答案；先用 64 位计算差，再取绝对值。原生语言的缓冲输入及 Python 的逐行输入降低开销，不改变证明。
