# 1088. 二叉树状道路中两个岔口之间的距离

[Timus 1088](https://acm.timus.ru/problem.aspx?space=1&num=1088) · 难度 751 · trees

原题作者 Oleg Kats，出自 2001 年 3 月 4 日斯维尔德洛夫斯克州第三届中学生团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

从第一块石头出发，道路每走一小时就分成左右两条，`F` 小时后每条支路都通到海边的一个码头。码头的编号规则是：
一直向右走到 1 号码头，只在最后一个岔口向左到 2 号码头，只在倒数第二个岔口向左到 3 号码头，依此类推。伊利亚
站在通往 `Ep` 号码头的路上、离海 `E` 小时的岔口；魔法石是通往 `Dp` 号码头的路上、离海 `D` 小时的岔口。他的马
最多能跑 `H` 小时，每段路一小时。伊利亚能到达魔法石吗？（`0 ≤ D, E, F, H ≤ 30`，`1 ≤ Dp, Ep ≤ 2^30`。）

时间限制：1 秒。内存限制：64 MB。

## 输入

`D`、`E`、`F`、`Dp`、`Ep` 和 `H`。

## 输出

`YES` 或 `NO`。

## 评测方式

按记号逐个比较输出；多余的空白不影响结果。

## 样例

### 样例 1

输入：

```
1 2 3 2 6 4
```

输出：

```
YES
```

## 题解

道路构成一棵深度为 `F` 的完全二叉树。编号规则说明，把 `p − 1` 写成 `F` 位二进制数就是通往码头 `p` 的路径：
最高位是第一个岔口，1 表示向左。通往码头 `p` 的路上离海 `k` 小时的岔口，就是同一条路径去掉最后 `k` 次转向，
即深度 `F − k` 处的数 `(p − 1) >> k`。

所以伊利亚是深度 `F − E` 处的结点 `a = (Ep − 1) >> E`，魔法石是深度 `F − D` 处的结点 `b = (Dp − 1) >> D`。
先用右移把较深的结点提升到另一个的深度，每次一小时；再同时提升两者，每步两小时，直到两个数相等：这就是它们
最近的公共岔口。把小时数与 `H` 比较。`O(F)`。

注意事项：

- 码头从 1 开始编号，所以路径是 `p − 1` 而不是 `p`；
- 两个岔口可能在不同深度，其中一个可能是另一个的祖先；
- 数值最大到 `2^30`，32 位有符号整数放得下，但解法用 64 位，让 `p − 1` 和移位都简单。

答案用另一种方法做了核对：把两条路径写成转向字符串，统计经过它们最长公共前缀的道路数。
