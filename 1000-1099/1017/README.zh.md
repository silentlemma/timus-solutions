# 1017. 统计阶梯数：拆分为互不相同的部分

[Timus 1017](https://acm.timus.ru/problem.aspx?space=1&num=1017) · 难度 158 · dp

原题出自 Ural State University Internal Contest '99 #2。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

用 `N` 个相同的小方块（`5 ≤ N ≤ 500`）搭成的阶梯，是由至少两列（台阶）组成的序列，各列高度严格递增、
每列至少 1，并用完全部 `N` 个方块。求不同阶梯的个数。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`。

## 输出

阶梯的个数。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
6
```

输出：

```
3
```

### 样例 2

输入：

```
11
```

输出：

```
11
```

## 题解

阶梯由台阶高度的集合决定：高度互不相同，顺序固定（递增）。所以答案就是把 `N` 写成 **互不相同** 的正整数
之和的方法数减一——只有一个高为 `N` 的台阶的“阶梯”不允许。

**0/1 背包计数。** `ways[s]` 表示和为 `s` 的互不相同大小的集合数。从 `ways[0] = 1` 开始，依次加入大小
`1, 2, ..., N`：对大小 `k`，让 `s` 从 `N` **向下** 到 `k` 执行 `ways[s] += ways[s - k]`，保证每个大小至多
使用一次（向上遍历会允许重复）。全部加入后答案为 `ways[N] - 1`。

时间复杂度为 `O(N^2)`，最多 125 250 次更新。数增长很快：`N = 500` 时答案约为 `7.3 · 10^14`，需要 64 位整数。

另一种方法：`f(n, k)` 表示把 `n` 拆成互不相同且都不小于 `k` 的部分的方法数，满足
`f(n, k) = f(n, k + 1) + f(n - k, k + 1)`，加记忆化可得到同样的数。

注意事项：

- 向上遍历 `s` 会统计含重复部分的拆分；
- 忘记减去只有一个部分的拆分；
- 有符号 32 位整数从 `N = 226` 起就会溢出。

## 优化解法

优化的 C++ 解法把表放在栈上一个固定大小、含 501 个 `long long` 的数组里，而不是
`vector`，因为 `N ≤ 500`，这样就不需要在堆上分配内存：{1017_dp_optimized.cpp}。

优化的 Java 解法用基于 `BufferedReader` 的 `StreamTokenizer` 读入唯一的数，而不
是 `Scanner`，后者的正则表达式机制加载起来既费时间又占内存：
{1017_dp_optimized.java}。
