# 1001. 逆序输出平方根

[Timus 1001](https://acm.timus.ru/problem.aspx?space=1&num=1001) · 难度 14 · math

原题由 Dmitry Kovalev 准备。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

输入是一列整数 `A1, A2, ..., An`，其中 `0 ≤ Ai ≤ 10^18`。按逆序输出它们的平方根：先输出
`√An`，最后输出 `√A1`。

数量 `n` 不会给出：数字一直到输入结束，输入总大小不超过 256 KB（因此 `n` 最多约为
131 000）。

时间限制：2 秒。内存限制：64 MB。

## 输入

整数 `Ai`，以任意数量的空格和换行（包括空行）分隔。

## 输出

`n` 行：`√An, √An-1, ..., √A1`，每行一个数，小数点后至少四位。

## 评测方式

每个输出的数与精确平方根的误差不得超过 `10^-4`（绝对误差，较大的值按相对误差）。

## 样例

### 样例 1

输入：

```
  16   2

 1000000000000000000   
0
```

输出：

```
0.0000
1000000000.0000
1.4142
4.0000
```

### 样例 2

输入：

```
7
```

输出：

```
2.6458
```

## 题解

把所有数读入数组直到输入结束，然后从后往前遍历，以四位小数输出 `sqrt(Ai)`。
时间和空间复杂度均为 `O(n)`。

双精度 `sqrt` 的精度足够：把不超过 `10^18` 的值转换为 double 时相对误差不超过
`2^-53`，因此平方根（不超过 `10^9`）的误差小于 `10^-6`，远小于允许的 `10^-4`。

注意事项：

- 数量没有给出，需要一直读到输入结束；
- 分隔符任意：多个空格、换行、空行；
- 数值超出 32 位范围，需要使用 64 位整数；
- 输出可能多达约 131 000 行，必须使用缓冲输出。

## 各语言说明

- **C++**：循环使用 `scanf("%llu")`，输出用 `printf("%.4f\n")`。
- **Go**：在 `bufio.Reader` 上按字节解析，用 `strconv.AppendFloat` 写入 `bufio.Writer`；
  每行调用一次 `fmt.Printf` 会很慢。
- **Python**：用 `sys.stdin.buffer.read().split()` 读入全部输入，拼好所有行后用一次
  `join` 输出。
- **Java**：从字节缓冲区解析数字，把输出收集到 `StringBuilder` 中；格式化时使用
  `Locale.US`，否则小数点可能变成逗号。
- **Rust**：把全部输入读入 `String`，解析为 `u64`，用 `{:.4}` 格式化到一个输出字符串中。
