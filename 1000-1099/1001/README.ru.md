# 1001. Квадратные корни в обратном порядке

[Timus 1001](https://acm.timus.ru/problem.aspx?space=1&num=1001) · сложность 14 · math

Оригинальную задачу подготовил Дмитрий Ковалёв.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На вход подаётся последовательность целых чисел `A1, A2, ..., An`, где
`0 ≤ Ai ≤ 10^18`. Выведите их квадратные корни в обратном порядке: сначала
`√An`, последним `√A1`.

Количество `n` не задаётся: числа идут до конца ввода, общий размер которого
не больше 256 КБ (значит, `n` не больше примерно 131 000).

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Целые числа `Ai`, разделённые любым количеством пробелов и переводов строки
(в том числе пустыми строками).

## Выходные данные

`n` строк: `√An, √An-1, ..., √A1`, по одному числу в строке, каждое не менее
чем с четырьмя знаками после десятичной точки.

## Проверка

Каждое выведенное число должно отличаться от точного квадратного корня не
более чем на `10^-4` (абсолютная погрешность или относительная для больших
значений).

## Примеры

### Пример 1

Ввод:

```
  16   2

 1000000000000000000   
0
```

Вывод:

```
0.0000
1000000000.0000
1.4142
4.0000
```

### Пример 2

Ввод:

```
7
```

Вывод:

```
2.6458
```

## Решение

Прочитать все числа до конца ввода в массив, затем пройти его с конца и
вывести `sqrt(Ai)` с четырьмя знаками. Время и память — `O(n)`.

Точности `sqrt` в двойной точности хватает: при переводе значения до `10^18` в
double относительная погрешность не больше `2^-53`, поэтому корень (не больше
`10^9`) отличается от точного меньше чем на `10^-6` — намного меньше
допустимых `10^-4`.

Подводные камни:

- количество чисел не задано, поэтому читать нужно до конца ввода;
- разделители произвольные: несколько пробелов, переводы строк, пустые строки;
- значения не помещаются в 32 бита: нужны 64-битные целые;
- до примерно 131 000 строк вывода: вывод нужно буферизовать.

## Особенности языков

- **C++**: `scanf("%llu")` в цикле, `printf("%.4f\n")`.
- **Go**: побайтовый разбор поверх `bufio.Reader` и `strconv.AppendFloat` в
  `bufio.Writer`; вызывать `fmt.Printf` для каждой строки медленно.
- **Python**: прочитать весь ввод через `sys.stdin.buffer.read().split()`,
  собрать все строки и вывести одним `join`.
- **Java**: разбирать числа из байтового буфера и собирать вывод в
  `StringBuilder`; форматировать с `Locale.US`, иначе разделителем дробной
  части может оказаться запятая.
- **Rust**: прочитать весь ввод в `String`, разобрать `u64`, форматировать
  через `{:.4}` в одну строку вывода.
