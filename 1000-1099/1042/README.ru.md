# 1042. Переключить каждый вентиль нечётное число раз

[Timus 1042](https://acm.timus.ru/problem.aspx?space=1&num=1042) · сложность 810 · math

Автор оригинальной задачи — Евгений Штыков; Пятый командный чемпионат УрГУ по программированию, октябрь 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `N` вентилей, все закрыты, и `N` техников (`1 ≤ N ≤ 250`). Каждый
техник отвечает за непустое множество вентилей и по вызову переключает
каждый вентиль этого множества (открыт ↔ закрыт). Множества независимы:
множество ни одного техника не является симметрической разностью множеств
каких-то других техников. Выберите техников так, чтобы после этого все
вентили были открыты. Выведите номера по возрастанию, самый короткий
список, если вариантов несколько, или `No solution`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк: строка `i` перечисляет вентили техника `i` и
заканчивается числом `-1`.

## Выходные данные

Номера выбранных техников по возрастанию или `No solution`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4
1 2 -1
2 3 4 -1
2 -1
4 -1
```

Вывод:

```
1 2 3
```

### Пример 2

Ввод:

```
3
2 3 -1
1 2 -1
3 -1
```

Вывод:

```
2 3
```

## Решение

Повторный вызов техника ничего не меняет, поэтому каждого техника
вызывают один раз или не вызывают вовсе: неизвестная `x_t` в GF(2).
Вентиль `v` окажется открытым, если его переключили нечётное число раз:

```text
сумма x_t по техникам t, у которых v есть в множестве, = 1 (mod 2), для каждого v
```

Это `N` линейных уравнений с `N` неизвестными над GF(2). Независимость
множеств означает, что матрица обратима: у системы ровно одно решение.
Значит, оно единственное и заодно самое короткое, а `No solution` при
корректном вводе не бывает (решения всё равно это проверяют).

Решаем методом Гаусса–Жордана, храня строки как битовые множества: для
каждого столбца находим строку с 1, поднимаем её и прибавляем (XOR) ко
всем остальным строкам с 1 в этом столбце. С 64-битными словами операция
со строкой — около 4 XOR, так что всё исключение занимает `O(N^3 / 64)`.

Подводные камни:

- все вентили сначала закрыты, поэтому правая часть — все единицы;
- уравнение вентиля собирает техников, которые им владеют: матрица —
  транспонированные входные списки;
- список техника заканчивается числом `-1`, а не концом строки.

## Особенности языков

- **C++**: `std::bitset`; **Go**, **Java**, **Rust**: массивы 64-битных
  слов.
- **Python**: каждое уравнение — одно целое число как битовая маска, так
  что операция со строкой — один `^`.
