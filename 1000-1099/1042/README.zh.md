# 1042. 让每个阀门被切换奇数次

[Timus 1042](https://acm.timus.ru/problem.aspx?space=1&num=1042) · 难度 810 · math

原题作者 Evgeny Shtykov，出自 2000 年 10 月第五届乌拉尔国立大学团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `N` 个阀门，全部关闭，还有 `N` 名技师（`1 ≤ N ≤ 250`）。每名技师负责一个非空的阀门集合，被叫到时会把集合
中的每个阀门切换一次（开 ↔ 关）。这些集合线性无关：任何一名技师的集合都不是其他某些技师集合的对称差。选出
一些技师，使得之后所有阀门都打开。按升序输出编号；若有多种方案，输出最短的那个；或者输出 `No solution`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行：第 `i` 行列出技师 `i` 负责的阀门，以 `-1` 结尾。

## 输出

按升序排列的选中技师编号，或者 `No solution`。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
4
1 2 -1
2 3 4 -1
2 -1
4 -1
```

输出：

```
1 2 3
```

### 样例 2

输入：

```
3
2 3 -1
1 2 -1
3 -1
```

输出：

```
2 3
```

## 题解

同一名技师叫两次等于没叫，所以每名技师要么叫一次、要么不叫：GF(2) 中的一个未知数 `x_t`。阀门 `v` 最终打开，
当且仅当它被切换了奇数次：

```text
对所有集合中含 v 的技师 t 求 x_t 之和 = 1 (mod 2)，对每个 v
```

这是 GF(2) 上 `N` 个未知数的 `N` 个线性方程。集合线性无关意味着矩阵可逆：方程组恰有一个解。所以它是唯一解，
也就是最短的；对于合法输入不会出现 `No solution`（解法仍然会检查）。

用高斯–若尔当消元求解，行用位集表示：对每一列找一个该列为 1 的行，换到上面，再把它异或到该列为 1 的所有
其他行。用 64 位字时一次行运算约 4 次异或，整个消元为 `O(N^3 / 64)`。

注意事项：

- 所有阀门开始都是关闭的，所以右端全是 1；
- 一个阀门的方程汇集拥有它的技师：矩阵是输入列表的转置；
- 技师的列表以 `-1` 结尾，而不是以行尾结尾。

## 各语言说明

- **C++**：`std::bitset`；**Go**、**Java**、**Rust**：64 位字的数组。
- **Python**：每个方程是一个用作位掩码的整数，所以一次行运算就是一次 `^`。
