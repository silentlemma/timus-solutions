# 1014. Наименьшее число с заданным произведением цифр

[Timus 1014](https://acm.timus.ru/problem.aspx?space=1&num=1014) · сложность 94 · greedy

Оригинальная задача — Ural State University Internal Contest '99 #2.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано `N` (`0 ≤ N ≤ 10^9`). Найдите наименьшее натуральное `Q`, произведение
десятичных цифр которого равно ровно `N`, или сообщите, что такого нет.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Целое число `N`.

## Выходные данные

`Q` или `-1`, если такого числа не существует.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
36
```

Вывод:

```
49
```

### Пример 2

Ввод:

```
0
```

Вывод:

```
10
```

## Решение

Сначала два особых случая:

- `N = 0`: произведение цифр равно 0 ровно тогда, когда в числе есть ноль,
  и наименьшее такое натуральное число — `10`;
- `N = 1`: ответ `1` (а не пустое число).

Иначе ни одна цифра не равна 0 или 1 (единица только удлиняет число), так
что `Q` состоит из цифр 2–9. Меньшее число короче, а среди чисел одной
длины наименьшее то, у которого цифры идут по возрастанию. Значит, задача —
записать `N` произведением наименьшего числа цифр.

**Жадность:** делим `N` на 9, пока делится, затем на 8, 7, ..., 2 и
собираем цифры. Если в остатке не 1, у `N` есть простой делитель больше 7, и
ответ `-1`. Выводим собранные цифры по возрастанию.

Почему сначала большие цифры: степени тройки выгоднее всего упаковать в
девятки (две тройки в одной цифре), степени двойки — в восьмёрки, а
оставшиеся тройка и двойка образуют шестёрку, а не две цифры; деление на 9,
8, ..., 2 в таком порядке даёт именно эту упаковку. `O(log N)` шагов.

Подводные камни:

- `N = 0` и `N = 1`;
- в ответе может быть 12 цифр (`10^9 = 2^9 · 5^9` даёт `555555555888`): не
  храните его в 32-битном целом — печатайте цифры строкой.

## Особенности языков

Во всех языках одна и та же жадность; цифры собираются в строку.
