# 1024. Порядок перестановки

[Timus 1024](https://acm.timus.ru/problem.aspx?space=1&num=1024) · сложность 323 · math

Автор оригинальной задачи — Никита Шамгунов; второе командное соревнование школьников Свердловской области по программированию, 7 октября 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Перестановка `P` множества `1..N` (`1 ≤ N ≤ 1000`) задана числами
`P(1), ..., P(N)`. Её степени: `P^1 = P` и `P^k(n) = P(P^(k-1)(n))`. Найдите
наименьшее `k ≥ 1`, при котором `P^k` — тождественная перестановка. Ответ не
превосходит `10^9`.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` чисел `P(1), ..., P(N)`.

## Выходные данные

Наименьшее такое `k`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
5
2 3 1 5 4
```

Вывод:

```
6
```

### Пример 2

Ввод:

```
1
1
```

Вывод:

```
1
```

## Решение

Любая перестановка распадается на непересекающиеся **циклы**: начинаем с
элемента и применяем `P`, пока не вернёмся. На цикле длины `c` перестановка
— это сдвиг, поэтому `P^k` тождественна на нём ровно тогда, когда `c` делит
`k`. `P^k` тождественна всюду, когда это верно для каждого цикла, и
наименьшее такое `k` — **наименьшее общее кратное** длин циклов.

Обходим циклы с массивом `seen` (каждый элемент посещается один раз,
`O(N)`) и сворачиваем длины через `lcm(a, b) = a / gcd(a, b) · b` — деление
вперёд держит промежуточное значение маленьким.

Подводные камни:

- произведение длин циклов — не ответ: длины 4 и 6 дают 12, а не 24;
- вычисление степеней `P` по одной может занять до `10^9` шагов;
- НОК по условию помещается в `10^9`, но `a · b` до деления может не
  поместиться в 32 бита — используйте 64-битные целые.

## Оптимизированные решения

Go хранит перестановку в фиксированном массиве 16-битных индексов. Посещённое значение заменяется нулём, которого в перестановке нет, поэтому отдельный массив посещений не нужен. Длины циклов объединяются через НОК с делением на НОД перед умножением. Ввод и вывод используют фиксированные байтовые буферы и прямой доступ к стандартным дескрипторам.

Принятые базовые реализации [1024_math.cpp](1024_math.cpp), [1024_math.java](1024_math.java), [1024_math.py](1024_math.py), [1024_math.rs](1024_math.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.

## Особенности языков

Эти замечания относятся к базовым реализациям.

Везде один и тот же обход циклов; в C++ (`std::lcm`) и Python (`math.lcm`)
НОК есть в стандартной библиотеке.
