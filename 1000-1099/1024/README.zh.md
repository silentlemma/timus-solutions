# 1024. 置换的阶

[Timus 1024](https://acm.timus.ru/problem.aspx?space=1&num=1024) · 难度 321 · math

原题作者 Nikita Shamgunov，出自 2000 年 10 月 7 日斯维尔德洛夫斯克州第二届中学生团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`1..N`（`1 ≤ N ≤ 1000`）上的置换 `P` 由 `P(1), ..., P(N)` 给出。其幂为 `P^1 = P`，
`P^k(n) = P(P^(k-1)(n))`。求使 `P^k` 为恒等置换的最小 `k ≥ 1`。答案不超过 `10^9`。

时间限制：2 秒。内存限制：64 MB。

## 输入

`N`，然后是 `N` 个数 `P(1), ..., P(N)`。

## 输出

最小的这样的 `k`。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
5
2 3 1 5 4
```

输出：

```
6
```

### 样例 2

输入：

```
1
1
```

输出：

```
1
```

## 题解

每个置换都可分解为互不相交的 **循环**：从某个元素出发不断应用 `P`，直到回到起点。在长度为 `c` 的循环上
置换就是一次轮转，所以 `P^k` 在其上为恒等当且仅当 `c` 整除 `k`。当所有循环都满足时 `P^k` 处处为恒等，
最小的这样的 `k` 就是各循环长度的 **最小公倍数**。

用 `seen` 数组遍历各循环（每个元素访问一次，`O(N)`），并用 `lcm(a, b) = a / gcd(a, b) · b` 累积长度——
先做除法可使中间值保持较小。

注意事项：

- 循环长度之积不是答案：长度 4 和 6 得 12，而不是 24；
- 逐次计算 `P` 的幂可能需要多达 `10^9` 步；
- 按题意最小公倍数不超过 `10^9`，但除法前的 `a · b` 可能超出 32 位——请用 64 位整数。

## 各语言说明

各语言使用同样的循环遍历；C++（`std::lcm`）和 Python（`math.lcm`）的标准库中有最小公倍数函数。
