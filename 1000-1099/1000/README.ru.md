# 1000. Сумма двух целых чисел

[Timus 1000](https://acm.timus.ru/problem.aspx?space=1&num=1000) · сложность 16 · math

Автор оригинальной задачи: Павел Атнашев.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны два целых числа `a` и `b`. Выведите их сумму `a + b`.

В оригинальной задаче ограничения на `a` и `b` не указаны; в решениях с
фиксированной разрядностью оба слагаемых и их сумма должны помещаться
в знаковое 64-битное целое.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Два целых числа `a` и `b`, разделённые пробельными символами (пробелом или
переводом строки).

## Выходные данные

Одно целое число: `a + b`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
2 3
```

Вывод:

```
5
```

### Пример 2

Ввод:

```
2000000000 2000000000
```

Вывод:

```
4000000000
```

## Решение

Считать два числа и вывести их сумму. Время и память — `O(1)`.

Подводные камни:

- сумма двух чисел, каждое из которых помещается в 32 бита, может в 32 бита не
  поместиться, поэтому для слагаемых и результата используется 64-битный тип;
- числа читаются как токены, разделённые пробельными символами, поэтому неважно,
  стоят они в одной строке или в двух.

## Оптимизированные решения

Оптимизированное решение на Java разбирает два числа побайтно из
`System.in` вместо `Scanner`: 0.046 с вместо 0.078 с и 336 КБ вместо
1548 КБ.

## Особенности языков

- **C++**: `long long` и `scanf("%lld %lld")`.
- **Go**: `int64` и `fmt.Scan`, который пропускает любые пробельные символы.
- **Python**: целые числа произвольной точности; чтение всех токенов через
  `sys.stdin.read().split()` работает при любом расположении по строкам.
- **Java**: простое решение использует `long` и `Scanner`.
- **Rust**: прочитать весь ввод в `String`, разбить по пробельным символам и
  разобрать `i64`.
