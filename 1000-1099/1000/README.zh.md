# 1000. 两个整数之和

[Timus 1000](https://acm.timus.ru/problem.aspx?space=1&num=1000) · 难度 16 · math

原题作者：Pavel Atnashev。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定两个整数 `a` 和 `b`，输出它们的和 `a + b`。

原题没有给出 `a` 和 `b` 的范围；使用定长整数的题解要求两个加数及其和
都能放进有符号 64 位整数。

时间限制：1 秒。内存限制：64 MB。

## 输入

两个整数 `a` 和 `b`，以空白字符（空格或换行）分隔。

## 输出

一个整数：`a + b`。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
2 3
```

输出：

```
5
```

### 样例 2

输入：

```
2000000000 2000000000
```

输出：

```
4000000000
```

## 题解

读入两个数并输出它们的和。时间和空间复杂度均为 `O(1)`。

注意事项：

- 两个都能放进 32 位的数，其和不一定能放进 32 位，因此加数和结果都使用 64 位类型；
- 按空白字符分隔的记号读入数字，所以两个数在同一行还是分两行都没有关系。

## 优化解法

优化的 Java 解法直接从 `System.in` 逐字节解析两个数，而不是使用 `Scanner`：
0.046 s，而不是 0.078 s；336 KB，而不是 1548 KB。

## 各语言说明

- **C++**：使用 `long long` 和 `scanf("%lld %lld")`。
- **Go**：使用 `int64` 和 `fmt.Scan`，它会跳过任意空白字符。
- **Python**：整数为任意精度；用 `sys.stdin.read().split()` 读入全部记号，适应任意换行方式。
- **Java**：简单解法使用 `long` 和 `Scanner`。
- **Rust**：把全部输入读入 `String`，按空白字符切分并解析为 `i64`。
