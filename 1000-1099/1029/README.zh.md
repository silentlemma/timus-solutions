# 1029. 在办公楼里向上走的最省路线

[Timus 1029](https://acm.timus.ru/problem.aspx?space=1&num=1029) · 难度 354 · dp, dijkstra

原题出自 1999 年第三届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一栋楼有 `M` 层（`1 ≤ M ≤ 100`），每层 `N` 个房间（`1 ≤ N ≤ 500`）；每个办公室收取一笔正的费用。路线从
第一层任意房间出发；每一步要么从同号房间上一层，要么走到同层相邻的房间。求一条结束于顶层、所经办公室
费用之和最小的路线。到达任何办公室的总费用都不超过 `10^9`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`M` 和 `N`，然后 `M` 行，每行 `N` 个费用：第 `i` 行是第 `i` 层。

## 输出

按路线顺序给出各办公室的房间号。接受任意一条最省路线。

## 评测方式

检查器根据房间号还原楼层——同一房间号再次出现表示上一层，相差 1 表示在同层移动——并验证路线从第一层
开始、在顶层结束，且费用恰好等于最小值。

## 样例

### 样例 1

输入：

```
3 3
5 1 9
9 1 1
1 9 1
```

输出：

```
2 2 3 3
```

### 样例 2

输入：

```
1 1
7
```

输出：

```
1
```

## 题解

**按楼层动态规划。** 设 `best[i][j]` 为结束于第 `i` 层第 `j` 个房间的最省路线。在同一层上，到达某个
办公室的最省路线要么来自下方，要么来自左邻，要么来自右邻——而且由于费用为正，最省路线在同一层上不会
折返。所以每一层做三遍：

1. 来自下方：`best[i][j] = fee[i][j] + best[i - 1][j]`（第一层就是 `fee[0][j]`）；
2. 从左到右：`best[i][j] = min(best[i][j], best[i][j - 1] + fee[i][j])`；
3. 从右到左：`best[i][j] = min(best[i][j], best[i][j + 1] + fee[i][j])`。

为每个办公室记录它的值来自三种情况中的哪一种；从顶层最省的办公室出发，沿这些选择回溯到第一层，再按相反
顺序输出房间号。`O(M·N)`。

**最短路。** 办公室加上向上、向左、向右的走法构成一个点权为正的图：从第一层所有办公室同时出发做 Dijkstra，
得到同样的答案，复杂度 `O(M·N log(M·N))`。

注意事项：

- 路线可能先在第一层走到最便宜的房间，所以第一层也要做横向两遍；
- 输出要列出所有经过的办公室，包括在同层的移动；
- 比较时费用之和可能超出 32 位：使用 64 位整数。
