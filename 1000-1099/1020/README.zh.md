# 1020. 绕在圆钉外的线长

[Timus 1020](https://acm.timus.ru/problem.aspx?space=1&num=1020) · 难度 100 · geometry

原题出自 2000 年 10 月 7 日斯维尔德洛夫斯克州第二届中学生团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N` 个半径同为 `R` 的圆形钉帽（`1 ≤ N ≤ 16`）位于一个凸多边形的顶点上，按绕多边形的顺序（顺时针或逆时针）
给出；钉帽互不重叠，坐标绝对值不超过 100。一根线绕所有钉帽拉紧。求线的长度，四舍五入到小数点后两位。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N` 和实数 `R`，然后 `N` 行，按多边形顺序给出各圆心的实数坐标。

## 输出

线的长度，保留两位小数。

## 评测方式

按记号逐一比较输出；数值最多可相差 0.01。

## 样例

### 样例 1

输入：

```
3 1
0 0
3 0
0 4
```

输出：

```
18.28
```

### 样例 2

输入：

```
1 2.5
1.5 -2.0
```

输出：

```
15.71
```

## 题解

线由直线段和圆弧组成。每条直线段在外侧与相邻两个钉帽相切，也就是两圆心间的边向外平移 `R`：其长度等于
多边形的边长。在每个钉子处，线沿半径为 `R` 的圆弧从一条边的方向转到下一条边的方向，转过的角度是多边形在
该顶点的外角。凸多边形外角之和为一整圈 `2π`，所以所有圆弧合起来是一个半径为 `R` 的整圆。

答案：多边形周长加 `2πR`，`O(N)`。

注意事项：

- `N = 1`：线就是圆 `2πR`；`N = 2`：“周长”是往返的距离；
- 多边形可能按顺时针给出——公式不受影响；
- 输出恰好两位小数。

## 各语言说明

各语言使用同样的公式。Java 用 `Locale.US` 读取和输出，使小数点为点号。
