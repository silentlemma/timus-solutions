# 1020. Длина нитки вокруг круглых гвоздей

[Timus 1020](https://acm.timus.ru/problem.aspx?space=1&num=1020) · сложность 100 · geometry

Оригинальная задача — второе командное соревнование школьников Свердловской области по программированию, 7 октября 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N` круглых шляпок гвоздей (`1 ≤ N ≤ 16`) одинакового радиуса `R` стоят в
вершинах выпуклого многоугольника и даны в порядке его обхода (по или
против часовой стрелки); шляпки не перекрываются, координаты по модулю не
больше 100. Вокруг всех шляпок туго натянута нитка. Найдите её длину,
округлённую до двух знаков после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N` и вещественное `R`, затем `N` строк с вещественными координатами
центров в порядке обхода многоугольника.

## Выходные данные

Длина нитки с двумя знаками после точки.

## Проверка

Вывод сравнивается по токенам; числа могут отличаться не больше чем на 0.01.

## Примеры

### Пример 1

Ввод:

```
3 1
0 0
3 0
0 4
```

Вывод:

```
18.28
```

### Пример 2

Ввод:

```
1 2.5
1.5 -2.0
```

Вывод:

```
15.71
```

## Решение

Нитка состоит из прямых отрезков и дуг. Каждый прямой отрезок касается двух
соседних шляпок с внешней стороны, то есть это сторона между их центрами,
сдвинутая наружу на `R`: его длина равна стороне многоугольника. У гвоздя
нитка поворачивает от направления одной стороны к направлению следующей по
дуге радиуса `R` на внешний угол многоугольника в этой вершине. Внешние углы
выпуклого многоугольника в сумме дают полный оборот, `2π`, так что все дуги
вместе составляют одну окружность радиуса `R`.

Ответ: периметр многоугольника плюс `2πR`, `O(N)`.

Подводные камни:

- `N = 1`: нитка — просто окружность `2πR`; `N = 2`: «периметр» — это
  расстояние туда и обратно;
- многоугольник может быть дан по часовой стрелке — формуле это не важно;
- выводите ровно два знака после точки.
