# 1035. 双面针脚图案所需的最少线数

[Timus 1035](https://acm.timus.ru/problem.aspx?space=1&num=1035) · 难度 1370 · graphs, dsu

原题作者 Pavel Zaletsky，出自 1999 年第三届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一张布上画有 `N × M` 个正方形格子（`1 ≤ N, M ≤ 200`）。一针覆盖某个格子的一条对角线，位于布的某一面——正面
或反面；每个格子的每条对角线在每一面最多有一针。一根线依次缝出若干针，相邻两针在格点处相连，并且同一根线
上相邻的两针总在不同的面（针在公共格点处穿过布）。给定两面的所有针脚，求缝出整个图案所需的最少线数。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N` 和 `M`（行数和列数），然后 `2N` 行，每行 `M` 个字符：前 `N` 行描述正面，后 `N` 行描述反面，反面与正面
方向相同。字符为 `.`（无针脚）、`/` 或 `\`（一条对角线）或 `X`（两条对角线）。

## 输出

最少的线数。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
4 5
.....
.\...
..\..
.....
.....
....\
.\X..
.....
```

输出：

```
4
```

### 样例 2

输入：

```
3 3
\..
.\.
..\
...
.\.
...
```

输出：

```
2
```

## 题解

把格点看作图的顶点，针脚看作按所在面着色的边。一根线就是一条颜色交替的迹，问题是把所有边分成尽量少的
这种迹。

考虑一个连通的针脚组，在每个顶点 `v` 处有 `f(v)` 个正面针脚端点和 `b(v)` 个反面针脚端点。迹在中间经过
一个顶点时用掉一个正面针脚和一个反面针脚，所以 `v` 处至少有 `|f(v) − b(v)|` 个迹的端点。每条迹有两个
端点，于是得到下界 `S / 2`，其中 `S` 是组内 `|f(v) − b(v)|` 之和；而且有针脚的组至少需要一根线。两个下界
都能达到：若 `S = 0`，所有顶点都平衡，颜色平衡的连通图存在经过所有边的交替闭迹（Kotzig 定理）。否则用
`S / 2` 条附加连接把缺少的端点配对，使组变得平衡；经过它的闭迹在这些连接处断开，恰好得到 `S / 2` 根线。

所以答案是各组 `max(1, S / 2)` 之和。在 `(N + 1)(M + 1)` 个顶点上用并查集找出各组，用数组记录
`f(v) − b(v)`。`O(N · M · α)`。

注意事项：

- 反面与正面方向相同：反面的 `\` 与正面的 `\` 连接相同的顶点；
- 同一面的针脚不能直接相连：一条由正面针脚组成的线段，每一针都需要单独一根线；
- 所有顶点都平衡的组仍需要一根线；没有针脚的顶点不构成组，没有针脚的图案需要 0 根线。
