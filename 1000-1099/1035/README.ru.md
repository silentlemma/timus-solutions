# 1035. Наименьшее число нитей для двустороннего узора

[Timus 1035](https://acm.timus.ru/problem.aspx?space=1&num=1035) · сложность 1370 · graphs, dsu

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На листе нанесена сетка из `N × M` квадратных клеток (`1 ≤ N, M ≤ 200`).
Стежок покрывает одну диагональ одной клетки и лежит на одной стороне
листа — лицевой или изнаночной; на каждой диагонали каждой клетки с каждой
стороны не больше одного стежка. Нить делает последовательность стежков,
соединённых в вершинах сетки, причём два соседних стежка одной нити всегда
лежат на разных сторонах (игла проходит сквозь лист в общей вершине). По
стежкам на обеих сторонах найдите наименьшее число нитей, которыми можно
выполнить весь узор.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `M` (строки и столбцы), затем `2N` строк по `M` символов: первые `N`
строк описывают лицевую сторону, следующие `N` — изнанку в той же
ориентации, что и лицевую. Символ — `.` (нет стежка), `/` или `\` (одна
диагональ) или `X` (обе диагонали).

## Выходные данные

Минимальное число нитей.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4 5
.....
.\...
..\..
.....
.....
....\
.\X..
.....
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
3 3
\..
.\.
..\
...
.\.
...
```

Вывод:

```
2
```

## Решение

Вершины сетки — вершины графа, стежки — рёбра, раскрашенные по сторонам.
Нить — это маршрут, цвета рёбер которого чередуются, и нужно разбить все
рёбра на наименьшее число таких маршрутов.

Рассмотрим одну связную группу стежков и в каждой вершине `v` число `f(v)`
лицевых и `b(v)` изнаночных концов стежков. Внутри маршрута вершина
проходится одним лицевым и одним изнаночным стежком, поэтому в `v` лежит
не меньше `|f(v) − b(v)|` концов маршрутов. У маршрута два конца, отсюда
нижняя оценка `S / 2`, где `S` — сумма `|f(v) − b(v)|` по группе, а группе
со стежками всегда нужна хотя бы одна нить. Обе оценки достигаются: если
`S = 0`, все вершины сбалансированы, а в связном графе со сбалансированными
цветами есть замкнутый чередующийся маршрут по всем рёбрам (теорема
Коцига). Иначе спарим недостающие концы `S / 2` дополнительными связками —
группа станет сбалансированной; замкнутый маршрут по ней, разрезанный в
связках, даёт ровно `S / 2` нитей.

Итак, ответ — сумма по группам величины `max(1, S / 2)`. Система
непересекающихся множеств на `(N + 1)(M + 1)` вершинах находит группы,
массив хранит `f(v) − b(v)`. `O(N · M · α)`.

Подводные камни:

- изнанка дана в той же ориентации, что и лицевая сторона: `\` на изнанке
  соединяет те же вершины, что и `\` на лицевой;
- стежки одной стороны напрямую не соединяются: линии из лицевых стежков
  нужна отдельная нить на каждый стежок;
- группе, где все вершины сбалансированы, всё равно нужна одна нить;
  пустые вершины группами не считаются, а узору без стежков нужно 0 нитей.

## Особенности языков

- Во всех языках одна и та же система непересекающихся множеств с
  сокращением путей; Java читает строки через `BufferedReader`: `StreamTokenizer`
  принял бы `/` за начало комментария.
