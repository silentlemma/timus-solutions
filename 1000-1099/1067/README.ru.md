# 1067. Дерево папок, восстановленное по полным путям

[Timus 1067](https://acm.timus.ru/problem.aspx?space=1&num=1067) · сложность 363 · trees, sorting

Оригинальная задача — полуфинал ACM ICPC Северо-Восточной Европы 2000–2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны `N` различных путей к папкам (`1 ≤ N ≤ 500`), каждый не длиннее 80
символов, имена папок разделены обратной косой чертой. Имя состоит из 1–8
символов: заглавных букв, цифр и специальных символов
``!#$%&'()-@^_`{}~``. Выведите дерево папок: каждая папка на своей строке
с отступом в один пробел на уровень, подпапки сразу после своей папки,
папки каждого уровня в лексикографическом порядке.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк с путями.

## Выходные данные

Дерево, по одной папке в строке.

## Проверка

Вывод должен совпадать с ожидаемым текстом; игнорируются только пробельные
символы в самом конце. Начальные пробелы — часть ответа.

## Примеры

### Пример 1

Ввод:

```
7
WINNT\SYSTEM32\CONFIG
GAMES
WINNT\DRIVERS
HOME
WIN\SOFT
GAMES\DRIVERS
WINNT\SYSTEM32\CERTSRV\CERTCO~1\X86
```

Вывод:

```
GAMES
 DRIVERS
HOME
WIN
 SOFT
WINNT
 DRIVERS
 SYSTEM32
  CERTSRV
   CERTCO~1
    X86
  CONFIG
```

## Решение

Каждый путь кладётся в дерево папок: идём от корня по именам пути и
создаём недостающие папки. Затем обход в глубину печатает каждую папку с
числом пробелов, равным её глубине, проходя подпапки в отсортированном
порядке. С упорядоченным словарём в каждой папке порядок получается сам.
`O(L log N)` для суммарной длины путей `L`.

Подводные камни:

- сортировки полных путей как строк недостаточно: обратная косая черта
  стоит в середине таблицы кодов, после заглавных букв и цифр, но перед
  `^`, `_`, `` ` ``, `{`, `}` и `~`, поэтому `A!` окажется между `A` и
  `A\X`; имена нужно сравнивать по уровням;
- папка в середине пути может ни разу не встретиться отдельно, а
  одинаковые имена у разных родителей — разные папки;
- в путях нет пробелов, поэтому их можно читать как токены, разделённые
  пробельными символами, и заодно не замечать возвраты каретки.

Ответы проверены сортировкой всех префиксов всех путей как кортежей имён:
тогда папка идёт сразу перед всем своим поддеревом.

## Особенности языков

- C++, Java и Rust хранят подпапки в упорядоченном словаре (`std::map`,
  `TreeMap`, `BTreeMap`); Go и Python хранят хеш-таблицу и сортируют её
  ключи при печати.
- Во всех языках имена сравниваются по кодам символов — именно такой
  порядок нужен задаче для этих символов.
- Java разбивает путь регулярным выражением `\\` — одной экранированной
  обратной косой чертой.
