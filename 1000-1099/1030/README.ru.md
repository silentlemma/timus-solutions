# 1030. Расстояние по большому кругу между кораблём и айсбергом

[Timus 1030](https://acm.timus.ru/problem.aspx?space=1&num=1030) · сложность 904 · geometry, parsing

Автор оригинальной задачи — Евгений Штыков; III командный студенческий чемпионат Урала по программированию, 1999 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Радиосообщение даёт координаты корабля и айсберга на идеальной сфере
диаметром 6875 миль. Выведите длину кратчайшего пути по сфере между ними с
двумя знаками после точки и добавьте строку `DANGER!`, если расстояние
до округления меньше 100.00 миль.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Сообщение всегда состоит ровно из таких строк (значения меняются):

```text
Message #<n>.
Received at <HH>:<MM>:<SS>.
Current ship's coordinates are
<X1>^<X2>'<X3>" <NL или SL>
and <Y1>^<Y2>'<Y3>" <EL или WL>.
An iceberg was noticed at
<X1>^<X2>'<X3>" <NL или SL>
and <Y1>^<Y2>'<Y3>" <EL или WL>.
===
```

`X1^X2'X3"` — X1 градусов, X2 минут и X3 секунд северной (`NL`) или южной
(`SL`) широты, от 0 до 90 градусов; `Y1^Y2'Y3"` — долгота, восточная (`EL`)
или западная (`WL`), от 0 до 180 градусов.

## Выходные данные

```text
The distance to the iceberg: <s> miles.
```

где `<s>` выведено с двумя знаками после точки, и затем строка `DANGER!`,
если `<s>` до округления меньше 100.00.

## Проверка

Вывод сравнивается по токенам; допуск для чисел —
`0.01 · max(1, |ожидаемое значение|)`.

## Примеры

### Пример 1

Ввод:

```
Message #100.
Received at 00:10:20.
Current ship's coordinates are
12^30'00" NL
and 40^10'00" WL.
An iceberg was noticed at
12^10'00" NL
and 41^00'00" WL.
===
```

Вывод:

```
The distance to the iceberg: 52.78 miles.
DANGER!
```

### Пример 2

Ввод:

```
Message #101.
Received at 01:11:21.
Current ship's coordinates are
55^45'20" NL
and 37^37'00" EL.
An iceberg was noticed at
59^56'30" NL
and 30^18'00" EL.
===
```

Вывод:

```
The distance to the iceberg: 342.61 miles.
```

## Решение

**Разбор.** Каждая координата — три целых числа, за которыми идёт `NL`,
`SL`, `EL` или `WL`. Заменяем символы `^`, `'` и `"` пробелами, разбиваем
текст на токены и у каждого токена с началом `?L`, где `?` — одна из `N S E W`,
берём три предыдущих токена как градусы, минуты и секунды. Значение —
`градусы + минуты / 60 + секунды / 3600`, со знаком минус для юга и запада.
Первые два значения — корабль, последние два — айсберг.

**Расстояние.** Для широт `φ1, φ2` и долгот `λ1, λ2` в радианах центральный
угол `θ` между точками даёт **формула гаверсинусов**

`hav θ = sin²((φ2 - φ1) / 2) + cos φ1 · cos φ2 · sin²((λ2 - λ1) / 2)`,

откуда `θ = 2 · asin(sqrt(hav θ))`, а расстояние — `R · θ` при
`R = 6875 / 2`. Сферическая теорема косинусов,
`cos θ = sin φ1 sin φ2 + cos φ1 cos φ2 cos(λ2 - λ1)`, даёт то же значение, но
теряет точность для близких точек, где `cos θ` очень близок к 1.

**Строка опасности.** По условию расстояние до округления должно быть строго
меньше 100.00. Код сначала округляет его до сотых, поэтому 99.996 мили
выводится как `100.00` без `DANGER!`.

Подводные камни:

- долготы по разные стороны 180-го меридиана (`179°59' E` и `179°59' W`
  отстоят на 2 минуты);
- ограничивайте `hav θ` единицей перед `sqrt`/`asin`: из-за округления для
  противоположных точек оно может превысить 1;
- строгий порог из условия применяется до округления.

## Особенности языков

Везде одна и та же формула; Python разбирает координаты регулярным
выражением, остальные — по токенам. Java печатает с `Locale.US`.
