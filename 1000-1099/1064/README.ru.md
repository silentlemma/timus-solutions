# 1064. Длины массивов, при которых двоичный поиск заканчивается на данном шаге

[Timus 1064](https://acm.timus.ru/problem.aspx?space=1&num=1064) · сложность 656 · simulation

Оригинальная задача — полуфинал ACM ICPC Северо-Восточной Европы 2000–2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Классический двоичный поиск по неубывающему массиву `A[0 … N−1]` хранит
границы `p = 0`, `q = N − 1`; пока `p ≤ q`, он смотрит на
`i = ⌊(p + q)/2⌋`, считает одно сравнение, останавливается, если
`A[i] = x`, а иначе сдвигает `q` в `i − 1` (при `x < A[i]`) или `p` в
`i + 1`. Он остановился на индексе `i` ровно после `L` сравнений
(`0 ≤ i ≤ 9999`, `1 ≤ L ≤ 14`). Найдите все длины `N` от 1 до 10000, при
которых это возможно, сгруппировав их в отрезки подряд идущих значений.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`i` и `L`.

## Выходные данные

Число `K` отрезков, затем `K` строк с первой и последней длиной каждого
отрезка по возрастанию; `0`, если их нет.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
9000 2
```

Вывод:

```
0
```

### Пример 2

Ввод:

```
10 3
```

Вывод:

```
4
12 12
17 18
29 30
87 94
```

## Решение

При фиксированной длине `N` сравнения зависят не от значений, а только от
того, куда идёт поиск. Чтобы закончить на индексе `i`, каждый
просмотренный элемент до `i` должен отправить поиск вправо, а после `i` —
влево, что обеспечивает массив с меньшими значениями до `i` и большими
после. Значит, путь поиска вынужден: начинаем с `[0, N − 1]`, берём
середину, останавливаемся, если это `i`, иначе оставляем половину,
содержащую `i`. Длина `N` подходит, если этот путь встречает `i` ровно на
`L`-м сравнении (и `i < N`).

Перебираем все `N`: не больше 14 шагов на каждую, `O(10000 · log 10000)`,
и объединяем подряд идущие подходящие длины в отрезки.

Подводные камни:

- `i` должен быть индексом массива: `N > i`;
- поиск может дойти до `i` раньше или позже `L`; подходит только ровно
  `L`;
- ответ может быть пустым: выведите только `0`.

## Особенности языков

- Во всех языках моделируется один и тот же путь для каждой длины.
