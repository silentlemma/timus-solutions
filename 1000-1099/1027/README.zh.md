# 1027. 检查玩具语言中的括号与注释

[Timus 1027](https://acm.timus.ru/problem.aspx?space=1&num=1027) · 难度 637 · parsing

原题作者 Leonid Volkov 与 Alexey Lysenko，出自 2000 年 10 月 7 日斯维尔德洛夫斯克州第二届中学生团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

长度不超过 10 000 个字符的文本，若能按如下方式分为普通文本、注释和算术表达式，就是正确的程序：

- **注释** 以 `(*` 开始，以随后最近的 `*)` 结束；可以包含任何内容，可出现在任何位置（包括表达式内部）；
  必须闭合；
- **算术表达式** 以 `(`（后面不是 `*`）开始，以与之匹配的 `)` 结束；其间只允许字符 `=+-*/0123456789`、
  括号和换行（不允许空格），且括号必须平衡；
- 其余的 **普通文本** 可以包含除 `(` 和 `)` 以外的任何字符。

若文本是正确的程序输出 `YES`，否则输出 `NO`。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

文本：拉丁字母、数字、括号、算术符号、空格和换行。

## 输出

`YES` 或 `NO`。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
Program text (1+2) more words (* a comment ) with a bracket *) end
```

输出：

```
YES
```

### 样例 2

输入：

```
just a) bracket
```

输出：

```
NO
```

## 题解

从左到右扫描一遍，只用一个计数器 `depth`——当前所在算术表达式的嵌套层数（普通文本中为 0）。

- 遇到 `(*` 时开始一个注释，无论当前在哪里：在开头这对字符 **之后** 查找第一个 `*)` 并跳过它；若找不到，
  答案为 `NO`。注释不改变 `depth`。
- `(` 开括号：`depth + 1`。
- `)` 闭括号：若 `depth` 为 0，说明括号位于普通文本中——`NO`；否则 `depth - 1`。
- 其他字符在普通文本中都可以；在表达式内部（`depth > 0`）必须是 `=+-*/0123456789` 之一或换行。

最后 `depth` 必须为 0。`O(长度)`。

注意事项：

- `(*)` **不是** 闭合的注释：查找 `*)` 从 `(*` 之后开始；
- 注释不能嵌套：在 `(* (*) *)` 中注释在第一个 `*)` 处结束，最后的 `)` 是多余的括号；
- `(*` 总是开始注释，所以表达式不能在括号后紧接着以 `*` 开头——但 `((*c*)*1)` 是正确的：注释位于 `(` 与
  `*` 之间；
- 表达式内部的空格使程序错误，换行则不会；
- 在 Windows 下换行可能是 `\r\n`：把 `\r` 当作 `\n` 处理。

## 各语言说明

各语言使用同样的扫描；文本按原始字节或整段字符串读入。
