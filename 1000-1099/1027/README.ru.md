# 1027. Проверка скобок и комментариев в игрушечном языке

[Timus 1027](https://acm.timus.ru/problem.aspx?space=1&num=1027) · сложность 637 · parsing

Авторы оригинальной задачи — Леонид Волков и Алексей Лысенко; второе командное соревнование школьников Свердловской области по программированию, 7 октября 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Текст длиной не больше 10 000 символов — правильная программа, если он
разбивается на обычный текст, комментарии и арифметические выражения так:

- **комментарий** начинается с `(*` и заканчивается ближайшим `*)`; он может
  содержать что угодно и стоять где угодно, в том числе внутри выражения;
  он обязан быть закрыт;
- **арифметическое выражение** начинается с `(` (без `*` следом) и
  заканчивается парной `)`; между ними допустимы только символы
  `=+-*/0123456789`, скобки и переводы строк (без пробелов), а скобки должны
  быть сбалансированы;
- оставшийся **обычный текст** может содержать любые символы, кроме `(` и
  `)`.

Выведите `YES`, если текст — правильная программа, иначе `NO`.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Текст: латинские буквы, цифры, скобки, знаки арифметических действий,
пробелы и переводы строк.

## Выходные данные

`YES` или `NO`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
Program text (1+2) more words (* a comment ) with a bracket *) end
```

Вывод:

```
YES
```

### Пример 2

Ввод:

```
just a) bracket
```

Вывод:

```
NO
```

## Решение

Один проход слева направо с единственным счётчиком `depth` — уровнем
вложенности арифметического выражения, в котором мы находимся (0 в обычном
тексте).

- На `(*` начинается комментарий, где бы мы ни были: ищем первое `*)`
  **после** открывающей пары и перепрыгиваем за него; если его нет — `NO`.
  Комментарии `depth` не меняют.
- `(` открывает скобку: `depth + 1`.
- `)` закрывает: если `depth` равно 0, скобка стоит в обычном тексте —
  `NO`; иначе `depth - 1`.
- Любой другой символ допустим в обычном тексте; внутри выражения
  (`depth > 0`) это должен быть один из `=+-*/0123456789` или перевод
  строки.

В конце `depth` должно быть 0. `O(длины)`.

Подводные камни:

- `(*)` — **не** закрытый комментарий: поиск `*)` начинается после `(*`;
- комментарии не вкладываются: в `(* (*) *)` комментарий заканчивается на
  первом `*)`, а последняя `)` — лишняя скобка;
- `(*` всегда начинает комментарий, поэтому выражение не может начинаться
  со `*` сразу после скобки — но `((*c*)*1)` правильно: комментарий стоит
  между `(` и `*`;
- пробел внутри выражения делает программу неправильной, перевод строки —
  нет;
- в Windows переводы строк могут быть `\r\n`: обрабатывайте `\r` как `\n`.

## Особенности языков

Во всех языках один и тот же проход; текст читается сырыми байтами или
целой строкой.
