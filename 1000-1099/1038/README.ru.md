# 1038. Подсчёт ошибок в заглавных буквах

[Timus 1038](https://acm.timus.ru/problem.aspx?space=1&num=1038) · сложность 487 · implementation

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Текст длиной не более 10000 символов состоит из латинских букв, цифр,
знаков препинания `. , ; : - ! ?` и пробельных символов. Слово — это
максимальная последовательность букв; любой другой символ, включая
перевод строки, его завершает. Предложение заканчивается на `.`, `?` или
`!`; начало текста тоже начинает предложение. Посчитайте ошибки двух
видов:

- первая буква предложения строчная;
- заглавная буква не является первой буквой своего слова (каждая такая
  буква — отдельная ошибка).

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Текст, возможно, на нескольких строках.

## Выходные данные

Число ошибок.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
This sentence iz correkt! -It Has,No mista;.Kes et oll.
But there are two BIG mistakes in this one!
and here is one more.
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
hello. World? yes!
OK, fine.
```

Вывод:

```
3
```

## Решение

Один проход по символам с двумя флагами:

- `new_sentence` — с начала текста или с последнего `.`, `?`, `!` ещё не
  было ни одной буквы;
- `in_word` — предыдущий символ был буквой.

Для буквы: если она строчная и `new_sentence` установлен — ошибка первого
вида; если заглавная и установлен `in_word` — ошибка второго вида. Затем
`new_sentence` сбрасывается, а `in_word` устанавливается. Любой другой
символ сбрасывает `in_word`, а конец предложения устанавливает
`new_sentence`. `O(L)` для текста длины `L`.

Подводные камни:

- первая буква предложения не обязана его начинать: перед ней могут быть
  цифры, пробелы или другие знаки (`2nd place.` — ошибка на `n`);
- цифра не буква, поэтому `3Rd` — это слово `Rd`, начинающееся с
  заглавной, ошибки нет;
- весь ввод — это текст: читайте его до конца вместе с переводами строк.

## Особенности языков

- Во всех языках ввод читается целиком (побайтово или одной строкой), и
  выполняется один и тот же проход с двумя флагами.
