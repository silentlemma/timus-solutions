# 1089. Исправление опечаток в одну букву по словарю

[Timus 1089](https://acm.timus.ru/problem.aspx?space=1&num=1089) · сложность 840 · strings

Автор оригинальной задачи — Антон Ботов; третье командное соревнование школьников Свердловской области по программированию, 4 марта 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Словарь из не более чем 100 слов в нижнем регистре (до 8 букв каждое)
заканчивается строкой `#`; за ним идёт текст до 1000 слов. Слово — это
максимальная последовательность букв `a`–`z`. Каждое слово текста,
которого нет в словаре, но которое отличается от словарного ровно одной
буквой (та же длина, одна позиция), нужно заменить этим словарным словом;
словарь таков, что вариант всегда не больше одного. Выведите исправленный
текст, сохранив всё остальное в точности, а затем число исправлений.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Словарь по слову в строке, строка `#`, затем текст.

## Выходные данные

Исправленный текст, затем число исправлений в отдельной строке.

## Проверка

Вывод должен совпадать с ожидаемым текстом; игнорируются только пробельные
символы в самом конце.

## Примеры

### Пример 1

Ввод:

```
country
occupies
surface
covers
russia
largest
europe
part
about
world
#
the rushia is the larjest cauntry in the vorld.
it ockupies abaut one-seventh of the earth's surfase.
it kovers the eastern park of yurope and the northern park of asia.
```

Вывод:

```
the russia is the largest country in the world.
it occupies about one-seventh of the earth's surface.
it covers the eastern part of europe and the northern part of asia.
11
```

## Решение

Идём по тексту символ за символом. Всё, что не буква, копируется как
есть; последовательность букв — это слово. Слово из словаря остаётся.
Иначе сравниваем его со всеми словарными словами той же длины, и если
одно из них отличается ровно в одной позиции, пишем его вместо слова и
считаем исправление. `O(T · W · L)` для `T` слов текста, `W` слов
словаря и длины `L ≤ 8`.

Подводные камни:

- исправима только заменённая буква: пропущенная или лишняя буква — нет,
  поэтому `aple` и `appple` остаются как есть;
- слово, которое уже есть в словаре, верно, даже если другое словарное
  слово отличается от него одной буквой;
- цифры, апострофы и дефисы разделяют слова: `one-seventh` — это два
  слова;
- пробелы, знаки препинания и пустые строки нужно сохранить в точности.

Ответы сверены с заменой по регулярному выражению на последовательностях
букв, которая проверяет единственность каждого исправления.

## Особенности языков

- Python использует `re.sub` с функцией, которая ведёт счётчик.
- C++ и Java читают текст построчно; Go, Python и Rust читают его целиком
  и делят по переводам строк, отбрасывая возвраты каретки.
