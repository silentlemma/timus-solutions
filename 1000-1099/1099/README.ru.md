# 1099. Пары ночных сторожей: максимальное паросочетание в произвольном графе

[Timus 1099](https://acm.timus.ru/problem.aspx?space=1&num=1099) · сложность 1144 · matching, graphs

Автор оригинальной задачи: Jivko Ganev.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `N ≤ 222` сторожей и список пар сторожей, которые могут работать
вместе (до конца ввода). Каждый сторож работает не больше чем с одним
напарником, и никто не работает один. Поставьте в смены как можно больше
сторожей: выведите их число и пары.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем пары `i j` до конца ввода.

## Выходные данные

Число поставленных сторожей `C`, затем `C/2` пар.

## Проверка

Подходит любой максимальный набор пар. Проверяющая программа убеждается,
что число равно максимальному и что каждая пара допустима и каждый
сторож использован не больше одного раза.

## Примеры

### Пример 1

Ввод:

```
3
1 2
2 3
1 3
```

Вывод:

```
2
1 2
```

## Решение

Это максимальное паросочетание в произвольном графе, в котором, в отличие
от двудольного, есть нечётные циклы, поэтому обычных увеличивающих путей
недостаточно. С ними справляется алгоритм сжатия цветков Эдмондса.
Начинаем с жадного паросочетания. Затем из каждого свободного сторожа
строим поиском в ширину чередующееся дерево: из внешней вершины `v`
свободный сосед `to` завершает увеличивающий путь, а занятый сосед входит
в дерево вместе со своим напарником. Когда `v` встречает другую внешнюю
вершину, два пути по дереву и ребро между ними образуют нечётный цикл
(цветок). Его вершины получают базу цветка (наименьшего общего предка),
становятся внешними и попадают в очередь, а ссылки на родителей по циклу
ставятся так, чтобы путь через цветок можно было пройти. Когда
увеличивающий путь найден, обмен занятых и свободных рёбер вдоль него
увеличивает паросочетание на одно ребро. `O(N³)`.

Подводные камни:

- число пар не задано, поэтому они читаются до конца ввода;
- пара может повторяться или идти в обоих порядках, а сторож в паре с
  самим собой работать не может, поэтому такие строки пропускаются;
- граф без пар даёт `0` и больше ничего.

Проверяющая программа опирается на ожидаемое число; числа проверены
рангом случайной матрицы Татта по модулю большого простого — он равен
удвоенному размеру максимального паросочетания — на всех тестах и на
сотнях случайных небольших графов.

## Особенности языков

- Rust хранит массивы поиска в структуре `Matcher`, потому что их меняют
  вспомогательные функции.
- Java и C++ строят упорядоченные списки смежности из множеств, что
  убирает повторяющиеся пары.
