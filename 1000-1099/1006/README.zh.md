# 1006. 还原重叠正方形框的绘制顺序

[Timus 1006](https://acm.timus.ru/problem.aspx?space=1&num=1006) · 难度 988 · greedy

原题出自 1997 年乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

文本屏幕有 50 列、20 行，初始全部为 `.`（字节 46）。左上角位于第 `x` 列、第 `y` 行、边长为 `a`
（`a ≥ 2`，框完全在屏幕内）的正方形框，通过在其边界上写入下列字节来绘制；后画的框会覆盖先画的框：

| 格子 | 字节（cp437） | 字符 |
|------|---------------|------|
| 左上角 | 218 | `┌` |
| 右上角 | 191 | `┐` |
| 左下角 | 192 | `└` |
| 右下角 | 217 | `┘` |
| 左右两边的其余格子 | 179 | `│` |
| 上下两边的其余格子 | 196 | `─` |

输入是画完 `N` 个框（`1 ≤ N ≤ 15`）之后的屏幕。求任意一个不超过 2000 个框的序列，使其在空屏幕上
按顺序绘制后恰好得到这幅图。该序列不必与原序列相同。

时间限制：2 秒。内存限制：64 MB。

## 输入

20 行，每行 50 个字节：自上而下的屏幕各行，使用单字节编码 cp437（不是 UTF-8）。解法应读取原始字节，
并同时接受 LF 和 CRLF 换行。

## 输出

框的个数 `K`，然后是 `K` 行 `x y a`：左上角的列号和行号（从 0 开始）以及边长，按绘制顺序给出。

## 评测方式

接受任何正确答案。检查器验证 `0 ≤ K ≤ 2000`，每个框满足 `a ≥ 2` 且位于屏幕内，并且在空屏幕上按给定
顺序绘制这些框恰好得到输入的图。

## 题解

从后往前撤销绘制。最后画的框完全可见。把它去掉后，它的格子在它被画之前可以是任何内容，因此这些格子
变成 *通配符*。一般地，若一个框边界上的每个格子要么是通配符，要么恰好显示该框会写入的字符，并且其中
至少有一个格子还不是通配符，则称这个框 **合适**。

反复扫描所有左上角和边长（`50 · 20` 个角，每个最多 19 种边长；先检查候选框的四个角，可立即排除大多数）；
每个合适的框都被记录下来，其边界变成通配符。当不再有非 `.` 的格子时停止。按相反顺序输出记录的框。

正确性：按该顺序绘制时，每个记录的框在其非通配符格子上写入正确字符，而它的通配符格子会被更早记录、
即更晚绘制的框覆盖。过程不会卡住：在仍覆盖某个非通配符格子的原始框中取最后画的那个；它没有显示出来的
每个格子都被更晚的原始框覆盖，而那些框的格子已全部是通配符，因此这个框是合适的。每个记录的框至少把
不超过 1000 个格子中的一个变成通配符，因此 `K ≤ 1000`。

一次扫描约有 `50 · 20 · 19` 个候选，大多在角上就被排除；扫描次数很少（每次至少去掉剩余原始框中最上面
的一个），所以运行时间可以忽略。

注意事项：

- 输入不是 UTF-8：按字节读取，并把 ≥ 128 的字节当作无符号数；
- `.` 格子绝不能被覆盖：它们不是通配符；
- 只由通配符组成的框没有用处，不予记录。

## 各语言说明

各语言使用相同的扫描。Python 在构造边界格子列表之前，先跳过左上格既不是 `┌` 也不是通配符的候选。
