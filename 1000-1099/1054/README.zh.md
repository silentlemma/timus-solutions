# 1054. 汉诺塔局面对应的步数

[Timus 1054](https://acm.timus.ru/problem.aspx?space=1&num=1054) · 难度 643 · math

原题出自雷宾斯克国立航空学院。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N` 个圆盘（`1 ≤ N ≤ 31`，圆盘 1 最小）开始时在柱 1 上，用经典的最优递归移到柱 2：

```text
Hanoi(n, from, to, via):
    若 n > 0:
        Hanoi(n − 1, from, via, to)
        把圆盘 n 从 `from` 移到 `to`
        Hanoi(n − 1, via, to, from)
```

调用方式为 `Hanoi(N, 1, 2, 3)`。一个局面给出每个圆盘所在的柱。求给定局面在第几步之后出现；若永远不出现，输出
`-1`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后依次是圆盘 `1 … N` 所在的柱 `D1 … DN`，每行一个。

## 输出

步数，或 `-1`。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
3
3
3
1
```

输出：

```
3
```

### 样例 2

输入：

```
1
3
```

输出：

```
-1
```

## 题解

从最大的圆盘开始沿递归往下看。当圆盘 `1 … k` 正从 `a` 经 `c` 移到 `b` 时，圆盘 `k` 恰好移动一次，发生在前
`2^(k−1) − 1` 步之后（这些步把圆盘 `1 … k − 1` 移到 `c`）。因此：

- 圆盘 `k` 仍在 `a` 上：处于前一半；继续考虑圆盘 `1 … k − 1` 从 `a` 经 `b` 移到 `c`；
- 圆盘 `k` 在 `b` 上：前一半和圆盘 `k` 的移动都已完成，共 `2^(k−1)` 步；继续考虑圆盘 `1 … k − 1` 从 `c` 经 `a`
  移到 `b`；
- 圆盘 `k` 在 `c` 上：这不可能发生，答案为 `-1`。

把所有位于目标柱上的圆盘对应的 `2^(k−1)` 加起来就是步数。`O(N)`。

注意事项：

- 每一层柱子的角色都会互换；最小的圆盘第一步移到柱 2 还是柱 3，取决于 `N` 的奇偶性；
- 31 个圆盘的终局要经过 `2^31 − 1` 步，需要 64 位（或无符号 32 位）整数；
- 只要有一个圆盘在“错误”的柱上，整个局面就不可达。
