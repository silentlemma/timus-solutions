# 1054. Номер хода позиции в Ханойской башне

[Timus 1054](https://acm.timus.ru/problem.aspx?space=1&num=1054) · сложность 643 · math

Оригинальная задача — Рыбинская государственная авиационная академия.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N` дисков (`1 ≤ N ≤ 31`, диск 1 — самый маленький) стоят на стержне 1 и
переносятся на стержень 2 классической оптимальной рекурсией

```text
Hanoi(n, from, to, via):
    если n > 0:
        Hanoi(n − 1, from, via, to)
        перенести диск n с `from` на `to`
        Hanoi(n − 1, via, to, from)
```

вызванной как `Hanoi(N, 1, 2, 3)`. Позиция задаёт стержень каждого диска.
Найдите, после скольких ходов появляется данная позиция, или `-1`, если
она не появляется никогда.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем стержни `D1 … DN` дисков `1 … N`, по одному в строке.

## Выходные данные

Число ходов или `-1`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
3
3
3
1
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
1
3
```

Вывод:

```
-1
```

## Решение

Пройдём рекурсию от самого большого диска вниз. Пока диски `1 … k`
переносятся с `a` на `b` через `c`, диск `k` перемещается ровно один раз —
после первых `2^(k−1) − 1` ходов (они переносят диски `1 … k − 1` на `c`).
Значит:

- диск `k` ещё на `a`: мы в первой половине; продолжаем с дисками
  `1 … k − 1`, которые переносятся с `a` на `c` через `b`;
- диск `k` на `b`: первая половина и ход диска `k` сделаны, это
  `2^(k−1)` ходов; продолжаем с дисками `1 … k − 1`, которые переносятся
  с `c` на `b` через `a`;
- диск `k` на `c`: так не бывает, ответ `-1`.

Сумма `2^(k−1)` по всем дискам, найденным на целевом стержне, и есть номер
хода. `O(N)`.

Подводные камни:

- стержни меняются ролями на каждом уровне; куда сначала идёт самый
  маленький диск — на стержень 2 или 3, — зависит от чётности `N`;
- конечная позиция 31 диска достигается за `2^31 − 1` ходов, нужны
  64-битные (или беззнаковые 32-битные) целые;
- хотя бы один диск «не на том» стержне делает всю позицию
  недостижимой.
