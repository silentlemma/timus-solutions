# 1016. Самая дешёвая прогулка катящегося кубика по шахматной доске

[Timus 1016](https://acm.timus.ru/problem.aspx?space=1&num=1016) · сложность 823 · dijkstra, graphs

Оригинальная задача — Ural State University Internal Contest '99 #2.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Кубик с числом от 0 до 1000 на каждой грани стоит на клетке шахматной доски
8×8; его ребро равно стороне клетки. Ход перекатывает кубик через ребро
нижней грани на соседнюю по стороне клетку. Стоимость прогулки — сумма чисел
на нижней грани по всем клеткам, на которых он стоял, включая первую и
последнюю (число учитывается каждый раз, когда его грань снизу). Найдите
прогулку минимальной стоимости между двумя заданными различными клетками.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Одна строка: начальная и конечная клетки в шахматной нотации (`a`–`h` и
`1`–`8`), затем числа на ближней, дальней, верхней, правой, нижней и левой
гранях в начале. «Ближняя» грань смотрит на первую горизонталь, «правая» —
на вертикаль `h`.

## Выходные данные

Одна строка: минимальная стоимость, затем клетки прогулки от начальной до
конечной через пробел.

## Проверка

Принимается любая оптимальная прогулка. Чекер прокатывает кубик по
выведенной прогулке: каждый шаг должен вести на соседнюю по стороне клетку
доски, прогулка должна начинаться и заканчиваться в заданных клетках, а её
стоимость — совпадать и с выведенной суммой, и с минимумом.

## Примеры

### Пример 1

Ввод:

```
b2 b3 0 9 1 3 1 1
```

Вывод:

```
5 b2 a2 a1 b1 b2 b3
```

### Пример 2

Ввод:

```
a1 h8 1 1 1 1 1 1
```

Вывод:

```
15 a1 a2 a3 a4 a5 a6 b6 b7 c7 c8 d8 e8 f8 g8 h8
```

## Решение

Стоимость следующей клетки зависит от того, какая грань окажется снизу,
поэтому одной клетки недостаточно: **состояние** — это клетка вместе с
ориентацией кубика. Ориентаций у кубика 24, значит, состояний
`64 · 24 = 1536`, из каждого не больше 4 ходов.

**Ориентации.** Храним для каждой позиции (ближняя, дальняя, верхняя,
правая, нижняя, левая) номер исходной грани, которая там находится.
Перекатывание — фиксированная перестановка позиций, например перекат в
сторону дальней грани переводит верх → дальнюю → низ → ближнюю → верх. Если
начать с тождественной ориентации и применять четыре переката, пока
появляется новое, получатся 24 ориентации и таблица переходов
`next[ориентация][направление]`.

**Кратчайший путь.** Вход в состояние стоит числа на его нижней грани, а
начальное состояние — своей нижней грани. Все стоимости неотрицательны,
поэтому алгоритм Дейкстры находит самую дешёвую прогулку; запоминаем
предка каждого состояния, в конце берём самое дешёвое из 24 состояний на
конечной клетке и идём по предкам назад. `O(S log S)` при `S = 1536` —
мгновенно.

Подводные камни:

- самая короткая по числу клеток прогулка часто не самая дешёвая: кубику
  бывает выгодно сделать петлю, чтобы опустить вниз дешёвую грань;
- одинаковые числа на разных гранях: отслеживайте грани по их позиции во
  входе, а не по значениям;
- нижняя грань на начальной клетке тоже входит в сумму.

## Особенности языков

Везде один и тот же Дейкстра со стандартной очередью с приоритетом
(`container/heap` в Go, `BinaryHeap` с `Reverse` в Rust).
