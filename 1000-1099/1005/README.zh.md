# 1005. 把重量分成两堆

[Timus 1005](https://acm.timus.ru/problem.aspx?space=1&num=1005) · 难度 78 · dp, bitmask, bruteforce

原题出自 1997 年乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 `n` 个正整数 `w1, ..., wn`（`1 ≤ n ≤ 20`，`1 ≤ wi ≤ 100 000`），把它们分成两组，使两组
之和的差尽可能小。输出这个差。某一组可以为空。

时间限制：1 秒。内存限制：64 MB。

## 输入

先是数 `n`，然后是 `n` 个重量，以空白字符分隔。

## 输出

一个整数：可能的最小差。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
5
5 8 13 27 14
```

输出：

```
3
```

### 样例 2

输入：

```
1
100000
```

输出：

```
100000
```

## 题解

若一组重 `s`，另一组重 `total - s`，差为 `|total - 2s|`。因此任务是找出最接近 `total / 2` 的
子集和 `s ≤ total / 2`。

**子集和（dp）。** `reach[s]` 表示能否恰好凑出 `s`；从 `reach[0]` 开始逐个加入重量，并从大到小
遍历 `s`，保证每个重量最多使用一次。只有不超过 `total / 2 ≤ 1 000 000` 的和有意义，因此最多
`20 · 10^6` 步，空间 `O(total)`。答案由最大的可达 `s ≤ total / 2` 给出。

**位集（dp, bitmask）。** 同样的表可以放进一个整数，其第 `s` 位就是 `reach[s]`：加入重量 `x`
即 `reach |= reach << x`。在 Python 中，借助任意精度整数，这一操作一次处理整个机器字，比按 `s`
循环快得多。

**枚举全部子集（bruteforce, bitmask）。** 由于 `n ≤ 20`，可以枚举全部 `2^20` 个子集。按格雷码
顺序，每个子集与前一个只差一个重量，因此和可以 `O(1)` 更新；最后一个重量可以固定留在第二组，
工作量减半。时间 `O(2^n)`。

注意事项：

- 总和最大为 `2 · 10^6`：`int` 足够，但对不超过 `total` 的所有和建表会浪费内存，只需
  `total / 2`；
- `n = 1`：答案就是那唯一的重量。

## 各语言说明

- **C++**、**Go**、**Java**、**Rust**：布尔子集和表，约 `2 · 10^7` 次简单操作。
- **C++** 另外提供按格雷码顺序枚举全部子集的解法。
- **Python**：大整数位集；普通的按重量和按和的双重循环会太慢。
