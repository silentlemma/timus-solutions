# 1059. Кратчайшая постфиксная программа для многочлена

[Timus 1059](https://acm.timus.ru/problem.aspx?space=1&num=1059) · сложность 677 · math

Оригинальная задача — Рыбинская государственная авиационная академия.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Запишите кратчайшее выражение в обратной польской записи, вычисляющее
многочлен `a0·x^N + a1·x^(N−1) + … + aN` при любых коэффициентах и любом
`x` (`1 ≤ N ≤ 1000`). Можно использовать операции `+` и `*`, букву `X` для
аргумента и число `i` для коэффициента `ai`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

Выражение, по одному элементу в строке.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
1
```

Вывод:

```
0
X
*
1
+
```

### Пример 2

Ввод:

```
3
```

Вывод:

```
0
X
*
1
+
X
*
2
+
X
*
3
+
```

## Решение

Схема Горнера `(((a0·x + a1)·x + a2)·x + …)·x + aN` в постфиксной записи —
это `0`, а затем `X * i +` для `i = 1 … N`: `4N + 1` элементов.

Короче не бывает. Каждый коэффициент должен встретиться, это `N + 1`
операндов. Скопировать значение нельзя, поэтому `X` должна встретиться не
меньше `N` раз: выражение с `k` вхождениями `X` имеет степень не больше
`k`. В постфиксном выражении с `m` операндами ровно `m − 1` бинарных
операций, значит, нужно не меньше `(2N + 1) + 2N = 4N + 1` элементов.
`O(N)`.

Подводные камни:

- коэффициент `ai` записывается числом `i`, а не `ai`;
- порядок элементов важен для проверки: схема начинается с `0 X *`, как
  в примере.

## Особенности языков

- Во всех языках печатаются одни и те же строки; при `N = 1000` их 4001,
  поэтому вывод буферизуется.
