# 1059. 计算多项式的最短后缀表达式

[Timus 1059](https://acm.timus.ru/problem.aspx?space=1&num=1059) · 难度 677 · math

原题出自雷宾斯克国立航空学院。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

写出最短的逆波兰表达式，使它对任意系数和任意 `x`（`1 ≤ N ≤ 1000`）都能计算多项式
`a0·x^N + a1·x^(N−1) + … + aN`。表达式可以使用运算 `+` 和 `*`、代表自变量的字母 `X`，以及代表系数 `ai` 的数字 `i`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`。

## 输出

表达式，每行一个元素。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
1
```

输出：

```
0
X
*
1
+
```

### 样例 2

输入：

```
3
```

输出：

```
0
X
*
1
+
X
*
2
+
X
*
3
+
```

## 题解

秦九韶（霍纳）算法 `(((a0·x + a1)·x + a2)·x + …)·x + aN` 写成后缀形式就是 `0`，然后对 `i = 1 … N` 依次写
`X * i +`：共 `4N + 1` 个元素。

不存在更短的写法。每个系数都必须出现，这就是 `N + 1` 个操作数。表达式无法复制一个值，所以 `X` 至少要出现 `N`
次：含 `k` 个 `X` 的表达式次数至多为 `k`。有 `m` 个操作数的后缀表达式恰有 `m − 1` 个二元运算，所以至少需要
`(2N + 1) + 2N = 4N + 1` 个元素。`O(N)`。

注意事项：

- 系数 `ai` 写成数字 `i`，而不是 `ai`；
- 元素的顺序对评测有影响：与样例一样，以 `0 X *` 开头。

## 各语言说明

- 各语言输出相同的行；`N = 1000` 时有 4001 行，所以使用带缓冲的输出。
