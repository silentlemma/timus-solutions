# 1073. Наименьшее число квадратных участков ценой ровно N

[Timus 1073](https://acm.timus.ru/problem.aspx?space=1&num=1073) · сложность 140 · number_theory

Автор оригинальной задачи — Станислав Васильев; Ural State University Personal Contest Online, февраль 2001 года, Students Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Квадратный участок со стороной `a` стоит `a²`. Нужно потратить ровно `N`
(`1 ≤ N ≤ 60000`) на как можно меньшее число участков, то есть записать
`N` как сумму наименьшего числа квадратов натуральных чисел. Выведите,
сколько участков для этого нужно.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

Наименьшее число квадратов.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
344
```

Вывод:

```
3
```

## Решение

Ответ никогда не больше 4: по теореме Лагранжа любое натуральное число —
сумма четырёх квадратов. Остальные случаи легко различить.

- 1, если `N` — точный квадрат.
- 2, если `N − a²` — точный квадрат при некотором `1 ≤ a < √N`; это не
  больше 244 проверок.
- 4, если `N = 4^a (8b + 7)`: по теореме Лежандра о трёх квадратах ровно
  эти числа не являются суммами трёх квадратов. Делим на 4, пока делится,
  и смотрим на остаток по модулю 8.
- 3 в остальных случаях.

`O(√N)`.

Динамика по всем суммам, `best[v] = 1 + min best[v − a²]`, за
`O(N√N)`, около 10 миллионов шагов, тоже укладывается в ограничения в
компилируемых языках, но медленна на Python, а теоремы делают её ненужной.

Подводные камни:

- множитель `4^a` важен: 28 = 4 · 7 тоже требует четырёх квадратов, так что
  проверки одного `N mod 8 = 7` недостаточно;
- квадратный корень в плавающей точке округляется перед возведением
  обратно в квадрат, чтобы результат вроде `6.9999…` не скрыл точный
  квадрат.

Формула сверена с динамикой для всех `N` до 60000.

## Особенности языков

- Python использует точный `math.isqrt`; остальные языки округляют
  вещественный квадратный корень, что для таких небольших чисел точно.
