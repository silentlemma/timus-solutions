# 1055. Число простых делителей биномиального коэффициента

[Timus 1055](https://acm.timus.ru/problem.aspx?space=1&num=1055) · сложность 422 · number_theory

Оригинальная задача — Рыбинская государственная авиационная академия.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны `1 ≤ M < N ≤ 50000`. Найдите, сколько различных простых чисел делят
биномиальный коэффициент `C(N, M) = N! / (M! · (N − M)!)`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `M`.

## Выходные данные

Число различных простых делителей `C(N, M)`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
5 3
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
10 5
```

Вывод:

```
3
```

## Решение

В `C(N, M)` десятки тысяч цифр, поэтому само число не вычисляется. Делить
его могут только простые до `N`, а показатель простого `p` в `x!` даёт
формула Лежандра:

```text
e_p(x!) = ⌊x/p⌋ + ⌊x/p²⌋ + ⌊x/p³⌋ + …
```

так что `p` делит `C(N, M)` ровно тогда, когда
`e_p(N!) − e_p(M!) − e_p((N − M)!) > 0`. Решето Эратосфена перечисляет
простые до `N`, и на каждое простое уходит `O(log N)` делений: всего
`O(N log log N)`.

Подводные камни:

- сами факториалы сразу переполняются: работаем только с показателями;
- проверять нужно все простые до `N`, включая большие `N / 2`;
- `M = N − 1` даёт `C = N`, и его простые делители — делители `N`.

Равносильная проверка — теорема Куммера: `p` делит `C(N, M)` ровно тогда,
когда сложение `M` и `N − M` в системе счисления по основанию `p` даёт
перенос. Тесты проверены ею и, при `N ≤ 3000`, разложением точного
коэффициента.
