# 1008. 连通像素图形的两种编码互相转换

[Timus 1008](https://acm.timus.ru/problem.aspx?space=1&num=1008) · 难度 367 · bfs

原题出自 2000 年 Third Open USTU Collegiate Programming Contest (PhysTech Cup)。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

图形是坐标满足 `1 ≤ x, y ≤ 10` 的非空黑色像素集合，且四连通（有公共边的像素互为邻居）。它有两种写法：

1. **列表**：先是像素个数，然后每个像素一行 `x y`，按 `x` 再按 `y` 排序。
2. **描述**：先是 *起始* 像素的一行 `x y`——`x` 最小者中 `y` 最小的那个——然后按从起点出发的广度
   优先顺序，每个像素一行。一个像素的行按 `R`（x+1）、`T`（y+1）、`L`（x-1）、`B`（y-1）的顺序列出
   它尚未被提到过的邻居；这些邻居也按此顺序加入队列。除最后一行外每行以 `,` 结尾，最后一行以 `.`
   结尾。

给出其中一种编码，输出另一种。

时间限制：2 秒。内存限制：64 MB。

## 输入

两种编码之一。行首行尾没有空格；`x` 与 `y` 之间恰好一个空格。

## 输出

另一种编码。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```

```

输出：

```
2 5
R,
B,
B,
R,
R,

```

### 样例 2

输入：

```
2 5
R,
```

## 题解

描述 *本身就是* 一次广度优先搜索，因此两个方向都是同一个搜索。

- **列表 → 描述**：在网格上标记像素，找到起点，执行 BFS；对每个出队的像素按 `R T L B` 顺序尝试四个
  方向，每个黑色且尚未见过的邻居被标记、入队并写出。
- **描述 → 列表**：重放搜索。队列从起点开始；第 `i` 行属于队列中的第 `i` 个像素，每个字母把该方向的
  邻居追加到队列。最后队列中就是全部像素；按 `(x, y)` 排序。

判断给出的是哪种编码：只有描述以 `.` 结尾，看最后一个记号即可。按空白分隔读取记号，也顺便处理了只有
`,` 的空行（它是一个记号）以及 CRLF 换行。

像素最多 100 个，一切都是 `O(100)`；带一圈空格子边框的网格（下标 `0..11`）省去了边界检查。

注意事项：

- 单个像素的描述是它的坐标加上一行只有 `.`；
- 起点是 *最左* 像素中最低的那个，而不是全局最低的像素；
- 每个邻居只写一次，由最先发现它的像素写出。

## 各语言说明

各语言使用相同的 BFS。Java 版本在重放描述时填充网格并按列输出，无需排序即得到有序结果。
