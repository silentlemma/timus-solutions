# 1011. Наименьшее население с долей строго между двумя процентами

[Timus 1011](https://acm.timus.ru/problem.aspx?space=1&num=1011) · сложность 248 · math, number_theory

Оригинальная задача — чемпионат Уральского государственного университета 1997 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны два процента `P` и `Q` (`0.01 ≤ P, Q ≤ 99.99`, не более двух знаков
после десятичной точки, `P < Q`). Найдите наименьшее натуральное `n`, при
котором найдётся целое `c` с `P% < c / n < Q%`, оба неравенства строгие.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`P` и `Q` через пробел или перевод строки. Они могут быть записаны целыми
(`13`) или с одним-двумя знаками после точки (`14.1`, `12.50`).

## Выходные данные

Наименьшее `n`.

## Проверка

Сравниваются точные токены ответа, пробельное оформление несущественно.

## Решение

Сначала уйдём от вещественных чисел. У обеих границ не больше двух знаков
после точки, поэтому `p = 100·P` и `q = 100·Q` — целые (сотые доли
процента), а условие превращается в `p·n < 10000·c < q·n`.

**Перебор n.** Для данного `n` наименьшее `c` выше нижней границы —
`c = ⌊p·n / 10000⌋ + 1`; `n` подходит ровно тогда, когда это `c` ещё ниже
верхней границы, `10000·c < q·n`. Пробуем `n = 1, 2, ...`. Ширина интервала
не меньше `1/10000`, поэтому всегда подходит какое-то `n ≤ 10000`
(наибольший ответ — 5001); перебор мгновенный.

**Дерево Штерна — Броко.** Ответ — наименьший знаменатель дроби строго
внутри `(p/10000, q/10000)`. Спускаемся по дереву Штерна — Броко от границ
`0/1` и `1/0`: берём медианту `(a + c)/(b + d)` текущих границ; если она не
выше интервала, она становится новой левой границей, если не ниже —
правой, иначе это ответ. Первая дробь дерева, попавшая в интервал, имеет
наименьший знаменатель.

Подводные камни:

- чтение границ как вещественных чисел: `14.1` не представимо точно в
  двоичной системе, и сравнение с `c / n` на границе может пойти в любую
  сторону;
- оба неравенства строгие: при `P = 12.5` дробь `1/8` не подходит;
- `n = 1` никогда не подходит, так как `0 < P` и `Q < 100`.

## Оптимизированные решения

Сохраняются перебор знаменателя и понятные одношаговые версии дерева Штерна–Броко. Быстрые версии держат соседние дроби a/b и c/d вне открытого процентного интервала. Их медианта — простейшая дробь между ними. Если она ещё снаружи, точное целочисленное частное пропускает максимальную серию медиант с этой стороны: все пропущенные дроби остаются снаружи. Поэтому первая внутренняя медианта имеет минимальный знаменатель. Проценты разбираются в целые сотые, сравниваются перекрёстные произведения при WHOLE=10000; равенство границе исключается. Переходы по частным соответствуют спуску по цепной дроби: O(log WHOLE) шагов и постоянное числовое состояние. Go использует переносимые ограниченные syscall-буферы, Python — существующие текстовые потоки и явно указанный PyPy.
