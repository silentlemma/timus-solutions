# 1085. 朋友们碰面花费最少的电车站

[Timus 1085](https://acm.timus.ru/problem.aspx?space=1&num=1085) · 难度 625 · bfs, graphs

原题作者 Alexander Somov，出自 2001 年 3 月 4 日斯维尔德洛夫斯克州第三届中学生团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

城市有 `N` 个车站和 `M` 条电车线路（`1 ≤ N, M ≤ 100`），每条线路是 2 到 100 个车站的列表。一张车票价格为 4，可沿
一条线路乘坐一次；每次换乘都要买新票。`K` 个朋友（`1 ≤ K ≤ 100`）各自从某个车站出发，每人最多有 1000 的钱，有些人
有月票，乘车全部免费。求所有朋友都能到达的车站（每人自己付钱），使总花费最少（相同时取编号最小的车站），输出
该车站和总花费；若不存在这样的车站，输出 `0`。

时间限制：2 秒。内存限制：64 MB。

## 输入

`N` 和 `M`；`M` 行，每行是线路的车站数和各个车站；`K`；`K` 行，每行是朋友的钱数、出发车站，以及有月票为 1、
否则为 0。

## 输出

车站和总花费，或 `0`。

## 评测方式

按记号逐个比较输出；多余的空白不影响结果。

## 样例

### 样例 1

输入：

```
4 3
2 1 2
2 2 3
2 3 4
3
27 1 0
15 4 0
45 4 0
```

输出：

```
4 12
```

## 题解

一次出行的花费是 4 乘以乘车次数，而一次乘车可以覆盖线路上的任意一段，所以关键是从出发点到每个车站的最少乘车
次数。广度优先搜索可以求出它：从一个车站出发，每条经过它且尚未使用的线路只打开一次，线路上所有尚未到达的车站
的乘车次数都加一。每条线路至多打开一次，所以一次搜索为 `O(N + ΣL)`。

从每个朋友的车站各做一次搜索。对每个车站 `t`，没有月票的朋友花费 `4 · 乘车次数`，不能超过他的钱；有月票的朋友
不花钱，但 `t` 仍须可达。把各朋友的花费相加，标记出有人到不了或付不起的车站，在剩下的车站中取花费最少、编号
最小的。`O(K · (N + ΣL))`。

注意事项：

- 月票让出行免费，但不能让到不了的车站变得可达；
- 朋友自己所在的车站不花钱，即使没有任何线路经过它；
- 朋友的钱可能不够买一张票，这时只能在他自己的车站碰面。

答案与在车站图上运行的 Floyd–Warshall 算法做了核对，在该图中同一线路上的两个车站相距一次乘车。
