# 1085. Самая дешёвая трамвайная остановка для встречи друзей

[Timus 1085](https://acm.timus.ru/problem.aspx?space=1&num=1085) · сложность 625 · bfs, graphs

Автор оригинальной задачи — Александр Сомов; третье командное соревнование школьников Свердловской области по программированию, 4 марта 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В городе `N` остановок и `M` трамвайных маршрутов (`1 ≤ N, M ≤ 100`),
каждый — список из 2–100 остановок. Билет стоит 4 и годится на одну
поездку по одному маршруту; каждая пересадка требует нового билета.
Каждый из `K` друзей (`1 ≤ K ≤ 100`) начинает на какой-то остановке и
имеет не больше 1000 денег, а у некоторых есть проездной, с которым все
поездки бесплатны. Найдите остановку, на которой могут встретиться все
друзья, если каждый платит за себя, с наименьшей суммарной стоимостью
(при равенстве — с наименьшим номером), и выведите её вместе со
стоимостью или `0`, если такой нет.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `M`; `M` строк с длиной маршрута и его остановками; `K`; `K` строк
с деньгами друга, его начальной остановкой и 1 при проездном или 0.

## Выходные данные

Остановка и суммарная стоимость или `0`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4 3
2 1 2
2 2 3
2 3 4
3
27 1 0
15 4 0
45 4 0
```

Вывод:

```
4 12
```

## Решение

Поездка стоит 4, умноженное на число поездок по маршрутам, а одна поездка
покрывает любую часть маршрута, поэтому важно наименьшее число поездок от
начала до каждой остановки. Его находит поиск в ширину: из остановки
каждый ещё не использованный маршрут через неё открывается один раз, и
все его недостигнутые остановки получают на одну поездку больше. Каждый
маршрут открывается не больше одного раза, так что один поиск занимает
`O(N + ΣL)`.

Запускаем поиск от остановки каждого друга. Для каждой остановки `t` друг
без проездного платит `4 · поездки`, и это не должно превышать его
денег; друг с проездным не платит ничего, но `t` всё равно должна быть
достижима. Суммируем стоимости по друзьям, отмечаем остановки, до которых
кто-то не может добраться или не может заплатить, и берём самую дешёвую
из оставшихся с наименьшим номером. `O(K · (N + ΣL))`.

Подводные камни:

- проездной делает поездку бесплатной, но не делает недостижимую
  остановку достижимой;
- собственная остановка друга ничего не стоит, даже если через неё не
  проходит ни один маршрут;
- у друга может быть меньше денег, чем стоит один билет, и тогда возможна
  только его собственная остановка.

Ответы сверены с алгоритмом Флойда — Уоршелла на графе остановок, где
две остановки общего маршрута находятся на расстоянии одной поездки.

## Особенности языков

- Все пять языков хранят для каждой остановки список проходящих через неё
  маршрутов и отмечают маршруты, уже открытые в каждом поиске.
