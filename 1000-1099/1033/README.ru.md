# 1033. Видимая площадь стен лабиринта

[Timus 1033](https://acm.timus.ru/problem.aspx?space=1&num=1033) · сложность 237 · bfs, dfs

Автор оригинальной задачи — Владимир Пинаев; III командный студенческий чемпионат Урала по программированию, 1999 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Лабиринт — сетка `N × N` (`3 ≤ N ≤ 33`) клеток 3 × 3 метра: `.` — пустая
клетка, `#` — сплошной блок. Лабиринт окружён внешней стеной, кроме левой
верхней и правой нижней клеток, которые служат входами (они всегда пустые).
Высота стен 3 метра. Посетитель ходит между пустыми клетками с общей
стороной; блоки, касающиеся углами, щели не оставляют. Найдите суммарную
площадь стен, которые посетитель может увидеть из частей лабиринта,
достижимых от входов.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк по `N` символов `.` и `#`.

## Выходные данные

Видимая площадь стен в квадратных метрах.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4
....
.##.
.#..
....
```

Вывод:

```
180
```

### Пример 2

Ввод:

```
3
...
...
...
```

Вывод:

```
72
```

## Решение

Стена видна ровно тогда, когда это сторона достижимой пустой клетки,
обращённая к блоку или к внешней стене. Каждая такая сторона — квадрат
3 × 3, поэтому ответ — `9 ·` (число таких сторон).

Запускаем обход в ширину (или в глубину) по пустым клеткам через общие
стороны, начиная сразу от **обоих** входов: они могут вести в разные части
лабиринта. Для каждой посещённой клетки смотрим на её четыре стороны:
сторона к `#` или за границу — видимая стена, сторона к пустой клетке —
переход дальше. В конце вычитаем 4 стороны-проёма: сверху и слева от левой
верхней клетки, снизу и справа от правой нижней. `O(N^2)`.

Подводные камни:

- учитываются только клетки, достижимые от входа; замкнутые комнаты не
  видны;
- начинайте от обоих входов: лабиринт может распадаться на две части;
- соседи по диагонали не соединены.

## Особенности языков

- **C++**, **Go**, **Java**, **Rust**: BFS с очередью.
- **Python**: тот же обход со стеком (DFS); порядок не важен.
