# 1033. 迷宫中可见墙面的面积

[Timus 1033](https://acm.timus.ru/problem.aspx?space=1&num=1033) · 难度 237 · bfs, bitmask, dfs, graphs

原题作者 Vladimir Pinaev，出自 1999 年第三届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

迷宫是一个 `N × N`（`3 ≤ N ≤ 33`）的网格，每格 3 × 3 米：`.` 表示空格，`#` 表示实心砖块。迷宫四周有外墙，
左上和右下两个格子除外，它们是两个入口（总是空的）。墙高 3 米。游客在有公共边的空格之间行走；以角相接的
砖块之间没有缝隙。求游客从入口可达的部分能看到的墙面总面积。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行，每行 `N` 个字符 `.` 或 `#`。

## 输出

可见墙面的面积（平方米）。

## 评测方式

比较一个整数词元。新Rust有569次原生执行，对照独立逐格BFS：全部128个自由入口3x3迷宫、随机图、31/32/33边长、入口同/异分量、空白/块边界及11个仓库输入。

## 解法

可见墙面恰是入口可达空格的一条边，另一侧为石块或外边界。从两个入口同时做
四邻接遍历，入队时标记，避免两个入口共用的分量重复遍历。每个到达格子向 `#`
或棋盘外的边计数，向另一空格的边不计。

这恰好枚举可见面：每面只有一个相邻空格，且该空格必须可达。同一石块的不同面
应分别计数；封闭房间不计。两入口角落的四条外边是开口，需减去四，再乘面宽
3 m、面高 3 m 得到的面积 9。

C++、Go、Java、Rust 基础版用格子队列，Python 用栈；顺序不影响可达集或面数。
每空格最多加入一次、检查四邻居，时间及空间均 `O(N²)`。只能穿过公共边，斜角
接触没有通路；两个入口可能属于不同分量。

## 优化解法

保留的 C++/Java/Python 行掩码把水平单元操作合为有界字操作；旧 Python 保存全部输入词元，仍有平方级存储。原始逐格 BFS/DFS 全部保留作教学版。

Rust 用不分配堆空间的行掩码遍历。从两个入口开始，在改变的行内沿空格做水平闭包，再把新增位传到相邻行。已入队行位集去重；固定环形队列配显式计数，允许 N 行同时在队中。每次调度及水平扩张均可计入一个新格，总共 `O(N²)` 字操作。N≤33，每行可装进 64 位。以位计数统计四向墙面，包含外边界，乘九前减去四个入口面；两个可达分量的并集只计一次。仅存掩码、行号及128字节输入。POSIX read/write 直接处理有界缓冲，不用 stdio 堆缓冲或格式器；输出数字转入固定字节数组。读取、移位、索引均遵守边长上界。
