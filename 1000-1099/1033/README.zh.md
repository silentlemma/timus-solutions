# 1033. 迷宫中可见墙面的面积

[Timus 1033](https://acm.timus.ru/problem.aspx?space=1&num=1033) · 难度 237 · bfs, dfs

原题作者 Vladimir Pinaev，出自 1999 年第三届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

迷宫是一个 `N × N`（`3 ≤ N ≤ 33`）的网格，每格 3 × 3 米：`.` 表示空格，`#` 表示实心砖块。迷宫四周有外墙，
左上和右下两个格子除外，它们是两个入口（总是空的）。墙高 3 米。游客在有公共边的空格之间行走；以角相接的
砖块之间没有缝隙。求游客从入口可达的部分能看到的墙面总面积。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行，每行 `N` 个字符 `.` 或 `#`。

## 输出

可见墙面的面积（平方米）。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
4
....
.##.
.#..
....
```

输出：

```
180
```

### 样例 2

输入：

```
3
...
...
...
```

输出：

```
72
```

## 题解

一面墙可见，当且仅当它是某个可达空格朝向砖块或外墙的一条边。每条这样的边是一个 3 × 3 的正方形，所以答案
是 `9 ·`（这种边的条数）。

从 **两个** 入口同时出发，在空格之间沿公共边做 BFS（或 DFS）——两个入口可能通向迷宫的不同部分。对每个
访问到的格子检查它的四条边：朝向 `#` 或越过边界的边是可见墙面，朝向空格的边则继续走。最后减去作为开口
的 4 条边：左上格子的上边和左边、右下格子的下边和右边。`O(N^2)`。

注意事项：

- 只计入从入口可达的格子；封闭的房间看不到；
- 要从两个入口出发：迷宫可能被分成两部分；
- 对角相邻的格子不连通。

## 各语言说明

- **C++**、**Go**、**Java**、**Rust**：用队列做 BFS。
- **Python**：用栈做同样的搜索（DFS）；顺序无关紧要。
