# 1076. 以最少搬运把垃圾分到各个容器

[Timus 1076](https://acm.timus.ru/problem.aspx?space=1&num=1076) · 难度 713 · matching

原题作者：Jivko Ganev。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `N` 个容器（`1 ≤ N ≤ 150`），容器 `i` 中装有 `N` 种垃圾中第 `j` 种的 `a[i][j]` 个单位
（`0 ≤ a[i][j] ≤ 100`）。要把垃圾分好类，使每种垃圾单独占一个容器。在两个不同容器之间搬运一个单位的代价是 1。
求最小的总代价。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行，每行 `N` 个数：第 `i` 行描述容器 `i`。

## 输出

最小的总代价。

## 评测方式

按记号逐个比较输出；多余的空白不影响结果。

## 样例

### 样例 1

输入：

```
4
62 41 86 94
73 58 11 12
69 93 89 88
81 40 69 13
```

输出：

```
650
```

## 题解

最终每种垃圾都有自己的容器，所以最终状态就是垃圾种类到容器的一一分配。如果第 `j` 种垃圾分到容器 `i`，那么
已经在那里的 `a[i][j]` 个单位不动，第 `j` 种的其余单位各搬一次。所以代价等于总量减去所选配对的 `a[i][j]`
之和，问题就是容器与垃圾种类之间的最大权完美匹配，即指派问题。

匈牙利算法可以在 `O(N^3)` 内解决它。这里用的是带行势 `u` 和列势 `v` 的版本：逐行加入，对每一行在约化代价下
逐列扩展一条最短增广路，每一步把势按最小的松弛量 `delta` 调整。代价取 `−a[i][j]` 时最小值是 `−v[0]`，答案是
总量加上这个最小值。

注意事项：

- 先取最大量的贪心是错误的：对于行 `10 9 0`、`9 0 0` 和 `0 0 1`，贪心只保留 11 个单位，最优分配保留 19 个；
- `N = 150` 时不可能枚举所有排列，而通用的最小费用流在 Python 中比需要的慢。

答案与用 SPFA 求最短路的最小费用流做了核对，`N ≤ 7` 时还与枚举所有分配的结果做了核对。

## 各语言说明

- 五种语言实现的是同一个匈牙利算法，势从 1 开始编号，并使用 `owner` 和 `way` 数组。
- Java 用 `StreamTokenizer` 读取矩阵，对 22 500 个数来说它比 `Scanner` 快得多。
