# 1076. Сортировка мусора по контейнерам с наименьшим перекладыванием

[Timus 1076](https://acm.timus.ru/problem.aspx?space=1&num=1076) · сложность 713 · matching

Автор оригинальной задачи: Jivko Ganev.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `N` контейнеров (`1 ≤ N ≤ 150`), и в контейнере `i` лежит `a[i][j]`
единиц (`0 ≤ a[i][j] ≤ 100`) каждого из `N` видов мусора `j`. Нужно
рассортировать мусор так, чтобы каждый вид оказался один в своём
контейнере. Перенос одной единицы между двумя разными контейнерами стоит
1. Найдите наименьшую суммарную стоимость.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк по `N` чисел: строка `i` описывает контейнер `i`.

## Выходные данные

Наименьшая суммарная стоимость.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4
62 41 86 94
73 58 11 12
69 93 89 88
81 40 69 13
```

Вывод:

```
650
```

## Решение

В конце у каждого вида свой контейнер, так что итог — взаимно однозначное
назначение видов контейнерам. Если вид `j` отправляется в контейнер `i`,
то `a[i][j]` единиц, уже лежащих там, остаются, а все остальные единицы
вида `j` переносятся по одному разу. Значит, стоимость равна общему
количеству минус сумма `a[i][j]` по выбранным парам, и задача — это
совершенное паросочетание максимального веса между контейнерами и видами,
то есть задача о назначениях.

Венгерский алгоритм решает её за `O(N^3)`. Здесь используется вариант с
потенциалами `u` для строк и `v` для столбцов: строки добавляются по
одной, и для каждой столбец за столбцом наращивается кратчайший
увеличивающий путь в приведённых стоимостях, а потенциалы на каждом шаге
сдвигаются на наименьший запас `delta`. При стоимостях `−a[i][j]` минимум
равен `−v[0]`, и ответ — общее количество плюс этот минимум.

Подводные камни:

- жадно брать сначала наибольшее количество неверно: при строках `10 9 0`,
  `9 0 0` и `0 0 1` жадный выбор оставляет на месте 11 единиц, а лучшее
  назначение — 19;
- перебор всех перестановок при `N = 150` невозможен, а общий поток
  минимальной стоимости на Python медленнее, чем нужно.

Ответы сверены с потоком минимальной стоимости с кратчайшими путями через
SPFA, а при `N ≤ 7` — с перебором всех назначений.

## Особенности языков

- Все пять языков реализуют один и тот же венгерский алгоритм с
  нумерацией потенциалов с единицы и массивами `owner` и `way`.
- Java читает матрицу через `StreamTokenizer`, который для 22 500 чисел
  намного быстрее `Scanner`.
