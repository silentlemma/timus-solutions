# 1058. 平分凸多边形面积的最短切线

[Timus 1058](https://acm.timus.ru/problem.aspx?space=1&num=1058) · 难度 2756 · geometry

原题出自雷宾斯克国立航空学院。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个有 `N` 个顶点的凸多边形（`4 ≤ N ≤ 50`，逆时针，坐标在 −100 到 100 之间，最多三位小数）被一条直线切成面积
相等的两部分。求切线的最小可能长度，误差不超过 `10^-4`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行顶点坐标。

## 输出

平分面积的切线的最小长度。

## 评测方式

数值按绝对或相对误差 `10^-4` 比较。

## 样例

### 样例 1

输入：

```
4
0 0
4 0
4 3
0 3
```

输出：

```
3.000000
```

### 样例 2

输入：

```
4
0 -5
5 0
0 5
-5 0
```

输出：

```
7.071068
```

## 题解

用切线在边界上的第一个端点 `P` 来描述它，把 `P` 写成位置 `u ∈ [0, N)`：`u = i + t` 表示第 `i` 条边上比例为
`t` 处的点。对每个 `P` 恰有一条经过它的平分切线，另一端 `Q` 由面积确定：

- 利用鞋带公式各项的前缀和，多边形 `P, V[i+1], …, V[j]` 面积的两倍可以 `O(1)` 求出；它随 `j` 递增，所以用
  二分查找找到 `Q` 所在的边 `j`；
- 在这条边上，面积随 `Q` 的位置线性增长，由此精确求出 `Q`。

于是切线长度 `L(u)` 可在 `O(log N)` 内算出。随着 `u` 移动，除了 `P` 或 `Q` 经过顶点的时刻以外，`L(u)` 都是
光滑的。断点是各个整数以及各顶点的配对点（配对关系是对称的），至多 `2N` 个。解法在每个光滑段上取 64 个采样点，
并对采样中的每个局部最小值（包括段的两端）用黄金分割搜索细化；找到的最小值就是答案。

这是数值搜索而不是公式：它依赖于在同一段内长度函数不会有两个比采样步长更近的极小值。它与一种完全不同的方法
（枚举切线方向，每个方向上用二分偏移量求平分直线）在约七十个随机、正则、细长和接近圆形的多边形上，
以及约一百个边上带有顶点、有重复顶点或按顺时针给出的随机多边形上做了比较，差距始终在 `10^-6` 以内。

注意事项：

- 切线不一定经过顶点，也不一定垂直于某条边；
- 很细的多边形切线很短；相对精度很重要；
- 沿边界的遍历需要逆时针顺序；解法根据面积的符号把顺时针的列表反转，而不是相信给定的顺序（相信顺序的第一版在评测机上没有通过）；
- 每条切线会从两端各找到一次，这没有影响。
