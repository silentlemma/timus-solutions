# 1086. n-е простое число

[Timus 1086](https://acm.timus.ru/problem.aspx?space=1&num=1086) · сложность 106 · number_theory

Оригинальная задача — фольклор; третье командное соревнование школьников Свердловской области по программированию, 4 марта 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для каждого из `k` чисел `n` (`1 ≤ n ≤ 15000`) выведите `n`-е по счёту
простое число. 1 не является простым.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`k`, затем `k` строк с `n`.

## Выходные данные

`n`-е простое для каждого `n`, по одному в строке.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4
3
2
5
7
```

Вывод:

```
5
3
11
17
```

## Решение

15000-е простое число — 163 841, поэтому одно решето Эратосфена до этого
числа даёт все простые, о которых могут спросить, а каждый запрос — это
индекс в списке. `O(L log log L)` на решето при `L = 163 842` и `O(1)` на
запрос.

Подводные камни:

- первое простое — 2, а не 1;
- граница решета должна захватывать само 15000-е простое; его можно один
  раз найти любым способом и вписать в программу;
- число запросов не ограничено, поэтому простые вычисляются один раз, а
  не для каждого запроса.

Ответы сверены с простыми, найденными по одному пробным делением.

## Особенности языков

- Python вычёркивает кратные присваиванием среза в `bytearray`.
- C++, Go, Java и Rust начинают вычёркивание с `p²`; C++ и Java считают
  его в 64 битах, чтобы не опасаться переполнения.
