# 1025. Наименьшее число сторонников для двухуровневого большинства

[Timus 1025](https://acm.timus.ru/problem.aspx?space=1&num=1025) · сложность 67 · greedy, sorting

Оригинальная задача — второе командное соревнование школьников Свердловской области по программированию, 7 октября 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Избиратели разделены на `K` групп (`K` нечётно, `1 ≤ K ≤ 101`), каждая
нечётного размера; всего не больше 9999 человек. Группа говорит «за», если
«за» голосует больше половины её членов, а решение принимается, если «за»
высказывается больше половины групп. Найдите наименьшее число сторонников,
которые при правильном распределении по группам проведут любое решение.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`K`, затем `K` размеров групп.

## Выходные данные

Наименьшее число сторонников.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
5
9 3 11 1 7
```

Вывод:

```
7
```

### Пример 2

Ввод:

```
1
9999
```

Вывод:

```
5000
```

## Решение

Чтобы провести решение, сторонники должны выиграть `K / 2 + 1` групп
(целочисленное деление, `K` нечётно), а чтобы выиграть группу из `s`
человек (`s` нечётно), нужно `s / 2 + 1` сторонников; лишние в этой группе
пропадают зря, как и сторонники в проигранных группах.

Значит, нужно выбрать `K / 2 + 1` групп с наименьшей суммарной стоимостью
`s / 2 + 1`. Стоимость растёт с размером, поэтому лучшие группы — просто
самые маленькие: сортируем размеры и складываем стоимости первых
`K / 2 + 1`. `O(K log K)`.

Подводные камни:

- большинство групп — это `K / 2 + 1`, а большинство в группе из `s` —
  `s / 2 + 1`, а не `s / 2`;
- во входе размеры не упорядочены.

## Особенности языков

Везде одни и те же сортировка и сумма.
