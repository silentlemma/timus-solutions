## Задача

Даны десять целых чисел `a1 … a10`, каждое от 1 до 10000. Найдите
последнюю цифру количества положительных делителей произведения
`a1 · … · a10`.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Десять целых чисел, по одному в строке.

## Выходные данные

Одна цифра — последняя цифра числа делителей.

## Проверка

## Решение

Если `P = p1^e1 · p2^e2 · … · pk^ek`, то делитель `P` выбирает каждый
показатель независимо от `0` до `ei`, поэтому у `P` ровно
`(e1 + 1)(e2 + 1)…(ek + 1)` делителей.

Само произведение может иметь 40 цифр, но оно и не нужно: раскладываем
каждое число пробным делением до его квадратного корня (не больше 100
шагов), складываем показатели одинаковых простых и перемножаем `(e + 1)`
по модулю 10. `O(10 · √10000)`.

Подводные камни:

- показатели нужно сложить по всем десяти числам до прибавления `1`:
  у `2 · 2` три делителя, а не `2 · 2`;
- простой множитель больше квадратного корня остаётся после пробного
  деления и тоже учитывается;
- последняя цифра может быть 0 (у 48 = `2^4 · 3` десять делителей).

## Оптимизированные решения

Формула числа делителей прежняя: раскладываем десять чисел, складываем степени одинаковых простых и перемножаем степень+1 по модулю десять. Степень двойки снимается целиком, далее проверяются нечётные делители; остаток больше единицы прост. Go использует байтовые степени и список затронутых простых, Java — беззнаковые 16-битные char вместо объектов в словаре. Максимальная степень 10*floor(log2(10000))=130 помещается в Go uint8, но не в знаковый Java byte. Произведение шести различных простых уже 30030, поэтому одно число добавляет не больше пяти. Индексные массивы требуют O(V) инициализации и памяти, десять разложений — O(C sqrt(V)). Python сохраняет небольшой словарь и битовые операции; обмен времени на память указан отдельно.
