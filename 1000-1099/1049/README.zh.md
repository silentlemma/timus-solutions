# 1049. 乘积的约数个数的末位数字

## 任务

给定十个整数 `a1 … a10`，每个都在 1 到 10000 之间。求乘积 `a1 · … · a10` 的正约数个数的末位数字。

时间限制：2 秒。内存限制：64 MB。

## 输入

十个整数，每行一个。

## 输出

一个数字：约数个数的末位。

## 解法
若 `P = p1^e1 · p2^e2 · … · pk^ek`，`P` 的约数对每个指数独立地在 `0` 到 `ei` 之间选取，所以 `P` 恰有
`(e1 + 1)(e2 + 1)…(ek + 1)` 个约数。

乘积本身可能有 40 位，但根本用不到它：对每个数用试除法分解到其平方根（最多 100 步），把相同素数的指数相加，
再把各个 `(e + 1)` 模 10 相乘。`O(10 · √10000)`。

注意事项：

- 必须先把十个数中的指数加起来，再加 `1`：`2 · 2` 有 3 个约数，而不是 `2 · 2` 个；
- 大于平方根的素因子在试除之后剩下来，也要计入；
- 末位可能是 0（48 = `2^4 · 3` 有 10 个约数）。

## 优化解法

`1049_number_theory_optimized.java`. 保存十个待分解余数。对每个试除因子，先从全部十个余数中除尽其幂，再将最终指数加一后模十相乘。同次扫描更新剩余最大值；下个因子的平方超过它时，大于一的余数必为素数，合并相同余数即可。较小素因子已除去，合数试除因子不会改变余数。完整扫描一个因子后若乘积模十为零，后续独立因子不能改变零，可立即结束；不能在某个输入的部分指数上提前退出。无需10001项指数表。C=10、初始最大值V≤10000时，时间O(C sqrt(V)+C²)、状态O(C)，余数变小会减少扫描次数。直接解析短输入，正常写出并flush两个答案字节。精确源码通过59个进程测试及11007个独立主函数检查，包含全部10000个单值及重复素数边界。保留教学分解和其他语言。
