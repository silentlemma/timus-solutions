# 1045. 在顶点会被烧毁的树上移动棋子

[Timus 1045](https://acm.timus.ru/problem.aspx?space=1&num=1045) · 难度 522 · games, trees

原题作者 Dmitry Filimonenkov，出自 2000 年 3 月 25 日乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一棵树有 `n` 个顶点（`n ≤ 1000`，每个顶点最多 20 个邻居）。棋子从顶点 `k` 出发。两名玩家轮流行动：一步把棋子
沿一条边移到相邻顶点，离开的顶点被永久摧毁。无法移动的一方输。判断双方都采取最优策略时谁获胜；若先手获胜，
给出获胜的第一步，若有多个则取编号最小的顶点。

时间限制：1 秒。内存限制：64 MB。

## 输入

`n` 和 `k`，然后 `n − 1` 行，每行一条边。

## 输出

`First player wins flying to airport L`（`L` 为第一步到达的顶点），或 `First player loses`。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
4 3
3 2
3 1
1 4
```

输出：

```
First player wins flying to airport 2
```

### 样例 2

输入：

```
3 1
1 2
2 3
```

输出：

```
First player loses
```

## 题解

所有被摧毁的顶点都在从 `k` 到棋子的路径上，所以棋子唯一不能去的邻居就是它刚离开的那个。每局游戏都是在以 `k`
为根的树上一路向下走，局面只取决于当前顶点。

于是这就是经典的胜负分析：若某个顶点至少有一个子节点是必败的，它对行动方就是必胜的；叶子是必败的。若 `k`
有必败的子节点，先手获胜，答案是这些子节点中编号最小的。

树可能是一条 1000 个顶点的路径，所以解法避免深递归：从 `k` 出发的广度优先顺序把父节点排在子节点之前，倒序
遍历时一旦发现必败的子节点，就把父节点标记为必胜。`O(n)`。

注意事项：

- 要的是编号最小的获胜走法，而不是输入中最先出现的；
- `n = 1`：没有边，也就无法移动，先手输；
- 先手只有走到*必败*的子节点才能获胜；对下一位玩家必胜的子节点是坏棋。

## 各语言说明

- 各语言都用同样的广度优先顺序代替递归。
