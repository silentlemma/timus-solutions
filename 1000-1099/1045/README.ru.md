# 1045. Игра с фишкой на дереве со сгорающими вершинами

[Timus 1045](https://acm.timus.ru/problem.aspx?space=1&num=1045) · сложность 522 · games, trees

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дерево имеет `n` вершин (`n ≤ 1000`, у каждой вершины не больше 20
соседей). Фишка стоит в вершине `k`. Два игрока ходят по очереди: ход
переводит фишку по ребру в соседнюю вершину, а покинутая вершина
уничтожается навсегда. Проигрывает тот, кто не может сделать ход.
Определите победителя при оптимальной игре; если выигрывает первый
игрок, укажите выигрывающий первый ход — наименьшую такую вершину, если
их несколько.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`n` и `k`, затем `n − 1` строк с рёбрами.

## Выходные данные

`First player wins flying to airport L` с вершиной `L` первого хода или
`First player loses`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4 3
3 2
3 1
1 4
```

Вывод:

```
First player wins flying to airport 2
```

### Пример 2

Ввод:

```
3 1
1 2
2 3
```

Вывод:

```
First player loses
```

## Решение

Все уничтоженные вершины лежат на пути от `k` до фишки, поэтому
единственный сосед, куда фишка пойти не может, — тот, откуда она пришла.
Любая партия — это спуск по дереву с корнем `k`, и позиция зависит только
от текущей вершины.

Значит, это классический анализ выигрышных и проигрышных позиций: вершина
выигрышна для ходящего, если хотя бы один её ребёнок проигрышный; лист
проигрышный. Первый игрок выигрывает, если у `k` есть проигрышный
ребёнок, и ответ — наименьший такой ребёнок.

Дерево может быть путём из 1000 вершин, поэтому решения обходятся без
глубокой рекурсии: порядок обхода в ширину от `k` ставит родителей раньше
детей, а проход по нему с конца помечает родителя выигрышным, как только
найден проигрышный ребёнок. `O(n)`.

Подводные камни:

- нужен наименьший выигрывающий ход, а не первый во входных данных;
- `n = 1`: нет рёбер и нет хода, первый игрок проигрывает;
- первый игрок выигрывает, только переходя в *проигрышного* ребёнка;
  ребёнок, выигрышный для следующего игрока, — плохой ход.

## Особенности языков

- Во всех языках один и тот же порядок обхода в ширину вместо рекурсии.
