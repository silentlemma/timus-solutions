# 1034. Перестановка трёх ферзей между мирными позициями

[Timus 1034](https://acm.timus.ru/problem.aspx?space=1&num=1034) · сложность 810 · bruteforce

Автор оригинальной задачи — Дмитрий Филимоненков; III командный студенческий чемпионат Урала по программированию, 1999 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N` ферзей (`4 ≤ N ≤ 50`) стоят на доске `N × N` в мирной позиции: ни
один ферзь не бьёт другого. Посчитайте мирные позиции, которые можно
получить из данной, переместив ровно трёх ферзей. Ферзи неразличимы:
позиция — это множество занятых клеток, поэтому перестановка ферзей по
занятым клеткам даёт ту же позицию.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк с координатами ферзей `X Y` (`1 ≤ X, Y ≤ N`).

## Выходные данные

Число мирных позиций, достижимых перемещением ровно трёх ферзей.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4
2 1
1 3
3 4
4 2
```

Вывод:

```
0
```

### Пример 2

Ввод:

```
9
2 5
3 8
7 1
8 7
9 4
6 6
1 3
5 9
4 2
```

Вывод:

```
4
```

## Решение

В мирной позиции в каждой строке и каждом столбце стоит ровно один ферзь,
так что позиция — это перестановка: строка `r` → столбец `col[r]`.
Переместить ровно трёх ферзей — значит получить позицию, отличающуюся от
исходной ровно в трёх клетках. Остальные `N − 3` ферзя остаются на своих
строках и столбцах, поэтому три перемещённых ферзя должны занять те же три
строки и те же три столбца, сопоставленные по-новому. Из 6 сопоставлений
трёх строк трём столбцам одно — исходная позиция, а три оставляют одного
ферзя на месте (двигаются только два); остаются два циклических сдвига
столбцов. Разные тройки или сдвиги дают разные позиции.

Итак: для каждой тройки строк `a < b < c` и обоих циклических сдвигов
ставим трёх ферзей в новые клетки и проверяем диагонали. Храним счётчики
ферзей на каждой диагонали `r + c` и `r − c`; убираем трёх старых ферзей,
после чего обе диагонали каждой новой клетки должны быть пусты (так
заодно ловится и случай, когда два новых ферзя бьют друг друга). Это
`2 · C(N, 3) ≈ 39 000` проверок за константу, всего `O(N^3)`.

Подводные камни:

- обмен двух ферзей — это перемещение двух ферзей, а не трёх, его не
  считаем;
- не считайте сдвиг дважды: два циклических сдвига тройки — две разные
  позиции, остальные четыре сопоставления не нужны;
- новый ферзь может бить другого нового ферзя, а не только оставшихся.

## Особенности языков

- **C++**, **Go**, **Java**, **Rust**: счётчики диагоналей меняются на
  месте и восстанавливаются после каждой проверки.
- **Python**: множества занятых диагоналей; для каждой тройки три старые
  диагонали удаляются из копии множеств.
