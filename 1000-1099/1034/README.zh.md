# 1034. 在和平局面之间移动三个皇后

[Timus 1034](https://acm.timus.ru/problem.aspx?space=1&num=1034) · 难度 810 · bruteforce

原题作者 Dmitry Filimonenkov，出自 1999 年第三届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N` 个皇后（`4 ≤ N ≤ 50`）以和平局面摆在 `N × N` 的棋盘上：没有皇后攻击另一个皇后。求从给定局面恰好移动
三个皇后能得到的和平局面个数。皇后之间不可区分：局面就是被占格子的集合，所以在已占格子之间交换皇后得到
的是同一个局面。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行，每行是一个皇后的坐标 `X Y`（`1 ≤ X, Y ≤ N`）。

## 输出

恰好移动三个皇后能得到的和平局面个数。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
4
2 1
1 3
3 4
4 2
```

输出：

```
0
```

### 样例 2

输入：

```
9
2 5
3 8
7 1
8 7
9 4
6 6
1 3
5 9
4 2
```

输出：

```
4
```

## 题解

和平局面中每行每列恰有一个皇后，所以局面就是一个排列：第 `r` 行 → 第 `col[r]` 列。恰好移动三个皇后，意味
着新局面与原局面恰有三个格子不同。其余 `N − 3` 个皇后不动，仍占着它们的行和列，所以被移动的三个皇后必须
落在原来的三行和原来的三列上，只是重新配对。三行与三列的 6 种配对中，一种是原局面，三种让一个皇后留在原
地（只移动了两个）；剩下的两种是列的循环移位。不同的三元组或移位得到不同的局面。

因此：对每个三行组 `a < b < c` 和两种循环移位，把三个皇后放到新格子上并检查对角线。维护每条对角线
`r + c` 和 `r − c` 上的皇后计数；先移除三个旧皇后，然后每个新格子的两条对角线都必须为空（这也顺带排除了
两个新皇后互相攻击的情况）。共 `2 · C(N, 3) ≈ 39 000` 次常数时间的检查，总计 `O(N^3)`。

注意事项：

- 只交换两个皇后算移动两个皇后，而不是三个，不能计入；
- 不要重复计数：一个三元组的两种循环移位是两个不同的局面，其余四种配对都不需要；
- 新皇后可能攻击另一个新皇后，而不只是留下的皇后。

## 各语言说明

- **C++**、**Go**、**Java**、**Rust**：原地修改对角线计数，每次检查后恢复。
- **Python**：用集合保存被占的对角线；对每个三元组，从集合的副本中删去三条旧对角线。
