# 1015. Группировка игральных костей с точностью до поворота

[Timus 1015](https://acm.timus.ru/problem.aspx?space=1&num=1015) · сложность 455 · hashing, implementation

Оригинальная задача — Ural State University Internal Contest '99 #2.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `N` игральных костей (`1 ≤ N ≤ 100 000`), пронумерованных с 1 в
порядке ввода. Кость задана числами на левой, правой, верхней, передней,
нижней и задней гранях в таком порядке — перестановкой `1..6`. Две кости
одного вида, если какой-то поворот одной даёт другую (зеркальное отражение
поворотом не считается). Разбейте кости по видам.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк по шесть чисел: левая, правая, верхняя, передняя,
нижняя, задняя грани.

## Выходные данные

Число видов `Q`, затем `Q` строк, по одной на вид: номера его костей по
возрастанию. Строки упорядочены по первому номеру, так что первая строка
начинается с 1.

## Проверка

Вывод сравнивается построчно, внутри строки — по токенам.

## Примеры

### Пример 1

Ввод:

```
4
1 6 2 3 5 4
2 5 6 3 1 4
1 6 2 4 5 3
3 4 1 2 6 5
```

Вывод:

```
2
1 2 4
3
```

### Пример 2

Ввод:

```
1
4 3 1 6 2 5
```

Вывод:

```
1
1
```

## Решение

**24 поворота.** Запишем поворот как перестановку шести позиций. Все они
порождаются двумя поворотами на четверть оборота: вокруг вертикальной оси
(лево ← перед ← право ← зад ← лево, верх и низ на месте) и вокруг оси
лево-право (верх ← зад ← низ ← перед ← верх). Если начать с тождественной
перестановки и применять оба поворота, пока появляется новое, получится
ровно 24 перестановки позиций. Получаются только повороты, не отражения,
так что кость и её зеркальное отражение остаются разными.

**Ключ каждой кости.** Применяем к кости все 24 поворота, читаем каждый
результат как 6-значное число (основания 7 хватает) и берём наименьшее:
кости одного вида получают один ключ, разных видов — разные. Видов всего
`720 / 24 = 30`.

**Группировка.** Идём по костям по порядку; хеш-таблица из ключа в группу
создаёт новую группу при первом появлении ключа и иначе добавляет кость в
существующую. Так группы создаются в порядке их наименьшей кости, а список
каждой группы возрастает — ровно требуемый вывод.

Время `O(24 · 6 · N)`. Можно и заранее посчитать ключ каждой из 720
возможных костей и искать его в таблице, как в версии на Python.

Подводные камни:

- отражения: шесть граней можно переставить 720 способами, но поворотов
  среди них только 24 — ключ только по набору противоположных пар склеит
  зеркальные кости;
- в выводе до `10^5` чисел: собирайте его в буфер.

## Особенности языков

- **C++**, **Go**, **Java**, **Rust**: 24 поворота на каждую кость.
- **Python**: таблица ключей всех 720 костей, затем один поиск в словаре на
  кость.
