# 1068. Сумма всех целых чисел между 1 и N

[Timus 1068](https://acm.timus.ru/problem.aspx?space=1&num=1068) · сложность 37 · math

Оригинальная задача — пробный тур полуфинала ACM ICPC Северо-Восточной Европы 2000–2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано целое число `N`, `|N| ≤ 10000`. Выведите сумму всех целых чисел
между 1 и `N` включительно.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

Сумма.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
-3
```

Вывод:

```
-5
```

## Решение

Числа между 1 и `N` образуют один отрезок из `|N − 1| + 1` чисел, по какую
бы сторону от 1 ни лежало `N`. Сумма отрезка равна его длине, умноженной
на среднее концов `(1 + N) / 2`. Произведение `(1 + N) · (|N − 1| + 1)`
всегда чётно: при `N ≤ 0` сумма двух сомножителей нечётна, а иначе они
равны `N + 1` и `N`, поэтому деление точное. `O(1)`.

Подводные камни:

- `N` может быть нулём или отрицательным: тогда отрезок идёт от `N` до 1,
  и `N(N + 1)/2` даёт неверный ответ, например 0 вместо 1 при `N = 0`;
- сумма доходит примерно до `5 · 10^7` по модулю и помещается в 32-битные
  целые; решения всё равно умножают в 64 битах (Python — в своих
  неограниченных целых).

Ответы сверены с поочерёдным сложением чисел.

## Особенности языков

- Python использует деление с округлением вниз `//`, которое здесь точное,
  потому что произведение чётно; остальные языки отбрасывают дробную
  часть, что точно по той же причине.
