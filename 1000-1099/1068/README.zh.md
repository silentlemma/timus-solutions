# 1068. 1 到 N 之间所有整数的和

[Timus 1068](https://acm.timus.ru/problem.aspx?space=1&num=1068) · 难度 37 · math

原题出自 2000–2001 年 ACM ICPC 东北欧区域赛的练习赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定整数 `N`，`|N| ≤ 10000`。输出 1 和 `N` 之间（含两端）所有整数的和。

时间限制：2 秒。内存限制：64 MB。

## 输入

`N`。

## 输出

和。

## 评测方式

按记号逐个比较输出；多余的空白不影响结果。

## 样例

### 样例 1

输入：

```
-3
```

输出：

```
-5
```

## 题解

无论 `N` 在 1 的哪一侧，1 和 `N` 之间的数都构成一个含 `|N − 1| + 1` 个数的区间。区间的和等于长度乘以两端的
平均值 `(1 + N) / 2`。乘积 `(1 + N) · (|N − 1| + 1)` 总是偶数：`N ≤ 0` 时两个因数之和为奇数，否则两个因数
是 `N + 1` 和 `N`，所以除法是精确的。`O(1)`。

注意事项：

- `N` 可以是零或负数：这时区间从 `N` 到 1，用 `N(N + 1)/2` 会得到错误答案，例如 `N = 0` 时得到 0 而不是 1；
- 和的绝对值最大约为 `5 · 10^7`，32 位整数放得下；解法仍然用 64 位做乘法（Python 用它的无界整数）。

答案与逐个相加的结果做了核对。

## 各语言说明

- Python 使用向下取整的除法 `//`，由于乘积是偶数，这里是精确的；其他语言截断小数部分，出于同样的原因也是精确的。
