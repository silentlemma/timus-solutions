# 1061. 最便宜的未锁定缓冲区窗口

[Timus 1061](https://acm.timus.ru/problem.aspx?space=1&num=1061) · 难度 670 · prefix_sums

原题出自 2000–2001 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `N` 个缓冲区（`1 ≤ N ≤ 100000`），每个要么被锁定（`*`），要么存有 0 到 9 的价值。选出 `K` 个连续的缓冲区
（`1 ≤ K ≤ 10000`），其中没有被锁定的，使总价值最小，输出第一个的编号 `L`；总价值相同时取最小的 `L`。若不存在
这样的窗口，输出 `0`。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N` 和 `K`，然后是 `N` 个状态，每行 80 个字符（最后一行可能更短）。

## 输出

`L`，或 `0`。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
100 53
2165745216091853477755800393859785807207523169954341**7363*9*94664808*4777717089
09825185827659480548
```

输出：

```
0
```

### 样例 2

输入：

```
100 10
2165745216091853477755800393859785807207523169954341**7363*9*94664808*4777717089
09825185827659480548
```

输出：

```
36
```

## 题解

对缓冲区做两个前缀和：前 `i` 个中的总价值和被锁定的个数。窗口 `[L, L + K − 1]` 合法当且仅当锁定个数在其中不
变，其价值是两个价值前缀和之差。从左到右检查全部 `N − K + 1` 个窗口，只在价值严格更小时才更新，就得到最便宜
窗口中最小的 `L`。`O(N)`。

注意事项：

- `K > N`：根本没有窗口，答案为 `0`；
- 价值相同时保留第一个窗口，所以只在严格更小时更新；
- 状态按每行 80 个字符分布在多行中：逐字符读取并跳过换行；
- 被锁定的缓冲区没有价值，只会使窗口不合法。

## 各语言说明

- **C++**、**Go**、**Java**：在读完两个数之后逐字符读取状态。
- **Python**、**Rust**：把全部输入按空白切分，再把各行拼接起来。

## 优化解法

Python 版本将输入分为连续的未锁定区间。在每个区间内滑动长度为 K 的窗口，减去离开窗口的值并加上进入窗口的值。只有总和严格减小时才更新答案，因此并列时保留最早的位置。时间复杂度为 O(N)，包含输入和区间的空间复杂度为 O(N)。提交 11317122 耗时 0.093 秒、使用 1048 KB；基础版为 0.125 秒和 9992 KB。

Go 版本流式读取状态，并用字节环形缓冲区保存最近 K 个值。遇到锁定缓冲区时清空窗口。时间复杂度为 O(N)，空间复杂度为 O(K)。提交 11317123 耗时 0.015 秒、使用 1088 KB；基础版为 0.031 秒和 2704 KB。

C++ 版本流式读取状态，并用字节环形缓冲区保存最近 K 个值。遇到锁定缓冲区时清空窗口。时间复杂度为 O(N)，空间复杂度为 O(K)。提交 11317125 耗时 0.015 秒、使用 184 KB；基础版为 0.015 秒和 1356 KB。
