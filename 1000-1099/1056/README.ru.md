# 1056. Центры дерева

[Timus 1056](https://acm.timus.ru/problem.aspx?space=1&num=1056) · сложность 551 · bfs, trees

Оригинальная задача — Рыбинская государственная авиационная академия.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дерево из `N` вершин (`2 ≤ N ≤ 10000`) строится добавлением вершин по
одной: вершина `i` (для `i = 2 … N`) соединяется с более ранней вершиной
`p_i`. Центр — вершина, у которой наибольшее расстояние (в рёбрах) до
остальных вершин минимально. Выведите все центры по возрастанию.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `p_2 … p_N`, по одному в строке.

## Выходные данные

Центры по возрастанию.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
5
1
1
2
2
```

Вывод:

```
1 2
```

### Пример 2

Ввод:

```
6
1
2
3
4
5
```

Вывод:

```
3 4
```

## Решение

У дерева один или два центра, и это середина любого самого длинного пути
(диаметра): наибольшее расстояние от вершины не меньше расстояния до
дальнего конца диаметра, а средняя вершина достаёт до любой вершины за
половину диаметра — иначе нашёлся бы путь длиннее.

Диаметр находится двумя обходами в ширину: вершина `u`, самая далёкая от
любого старта (вершины 1), — конец некоторого самого длинного пути, а
вершина `v`, самая далёкая от `u`, — его другой конец. Проход назад от `v`
по предкам обхода даёт путь длины `D`; его вершины с номерами `D / 2` и
`(D + 1) / 2` от `v` и есть центры — одна вершина при чётном `D`, две
соседние при нечётном. `O(N)`.

Подводные камни:

- если центров два, печатаются оба, по возрастанию;
- `N = 2`: обе вершины — центры;
- дерево может быть путём из 10000 вершин, так что рекурсивный обход
  может оказаться слишком глубоким; в обходе в ширину рекурсии нет.

Другой способ — обрывать все листья слой за слоем, пока не останется одна
или две вершины; тесты проверены им и, для маленьких деревьев,
расстояниями от каждой вершины.
