# 1056. 树的中心

[Timus 1056](https://acm.timus.ru/problem.aspx?space=1&num=1056) · 难度 552 · bfs, trees

原题出自雷宾斯克国立航空学院。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一棵 `N` 个顶点的树（`2 ≤ N ≤ 10000`）按顺序逐个加入顶点构成：顶点 `i`（`i = 2 … N`）连到更早的顶点 `p_i`。
中心是到其他顶点的最大距离（按边数）最小的顶点。按升序输出所有中心。

时间限制：2 秒。内存限制：64 MB。

## 输入

`N`，然后是 `p_2 … p_N`，每行一个。

## 输出

按升序排列的中心。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
5
1
1
2
2
```

输出：

```
1 2
```

### 样例 2

输入：

```
6
1
2
3
4
5
```

输出：

```
3 4
```

## 题解

树有一个或两个中心，它们就是任意一条最长路径（直径）的中点：一个顶点的最大距离不小于它到直径较远端点的距离，
而中间的顶点在直径一半向上取整的距离内就能到达所有顶点——否则就会有更长的路径。

直径用两次广度优先搜索求得：离任意起点（顶点 1）最远的顶点 `u` 是某条最长路径的一端，离 `u` 最远的顶点 `v` 是
另一端。从 `v` 沿 BFS 的前驱往回走得到长度为 `D` 的路径；其中从 `v` 数起第 `D / 2` 和第 `(D + 1) / 2` 个顶点就是
中心——`D` 为偶数时是一个顶点，为奇数时是两个相邻顶点。`O(N)`。

注意事项：

- 有两个中心时都要输出，并按升序；
- `N = 2`：两个顶点都是中心；
- 树可能是 10000 个顶点的路径，递归搜索可能太深；BFS 没有递归。

另一种方法是一层层剥去所有叶子，直到只剩一个或两个顶点；测试用它核对过，小树还用每个顶点出发的距离核对过。

## 优化解法

父结点的编号总是更小，因此可以按编号从大到小处理顶点。每个顶点保存最长向下分支的长度和端点。处理一个子结点时，将它的分支和此前最长的分支经父结点连接。所有这些路径中最长的一条就是直径。从较长分支的端点向父结点走直径长度的一半即可到达中心；若直径长度为奇数，中心还包括该顶点的父结点。时间和空间复杂度均为 O(N)。

任意路径的两条分支都在其最高节点相遇。处理较晚出现的分支时，算法将它与该节点此前最长的分支相接。直径中点位于较长的分支上或分叉处，因此从较长分支的端点沿父节点上溯即可。
