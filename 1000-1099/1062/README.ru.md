# 1062. Кто может выиграть триатлон при подходящих длинах этапов

[Timus 1062](https://acm.timus.ru/problem.aspx?space=1&num=1062) · сложность 1830 · geometry

Оригинальная задача — полуфинал ACM ICPC Северо-Восточной Европы 2000–2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Гонка состоит из трёх этапов. У `N` спортсменов (`1 ≤ N ≤ 100`) скорости
`Vi, Ui, Wi` (целые от 1 до 10000) на трёх этапах. Организаторы могут
выбрать любые положительные длины этапов. Для каждого спортсмена
определите, существуют ли длины, при которых только у него наименьшее
суммарное время.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк с `Vi Ui Wi`.

## Выходные данные

Для каждого спортсмена `Yes` или `No`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

Ввод:

## Решение

При длинах `(a, b, c)` время участника `j` равно `a/Vj + b/Uj + c/Wj`.
Участник `i` обгоняет `j`, когда

```text
(1/Vi − 1/Vj)·a + (1/Ui − 1/Uj)·b + (1/Wi − 1/Wj)·c < 0
```

Перемасштабируем длины для участника `i`: `u = (a/Vi, b/Ui, c/Wi)` — по-прежнему
любая положительная тройка, и после умножения на `Vj·Uj·Wj`
условие принимает вид `Σ (Sj − Si) · (две другие скорости j) · u < 0` по
трём этапам, с целыми коэффициентами меньше `10^12`. Важны только
отношения, поэтому `u` пробегает треугольник `x > 0, y > 0, x + y < 1`
(третья часть — `1 − x − y`), и каждый соперник отрезает от него открытую
полуплоскость. Участник `i` может выиграть, когда оставшаяся открытая
область не пуста.

Решать это в плавающей точке ненадёжно: область может быть полоской
крошечной, но положительной площади или отрезком нулевой площади, и
никакой допуск надёжно их не различает. Решения делают это точно. Каждое
ограничение ужесточается на одно и то же крошечное `ε > 0`; открытая
область не пуста ровно тогда, когда замкнутый ужесточённый многоугольник
не пуст при всех малых `ε`. Многоугольник хранится как список прямых в
порядке обхода границы, вершина — точка пересечения двух соседних прямых,
а сторона вершины относительно новой прямой — знак целого значения, а
затем его коэффициента при `ε`. Эти значения меньше `3 · 10^37` и
помещаются в 128 бит. Отсечение оставляет каждое ребро, часть которого
строго внутри, и вставляет новую прямую там, где граница выходит из
полуплоскости. `O(N)` на соперника, `O(N^3)` всего, не больше миллиона
шагов.

Тонкие места:

- одинаковые участники: ни один не может прийти первым в одиночку;
- участник, равный на двух этапах и медленнее на третьем, никогда не
  первый;
- область подходящих длин может быть отрезком или точкой, а этого мало:
  для строгой победы нужна открытая область;
- проверка площади в плавающей точке с фиксированным допуском (первая
  версия брала `10^-12`) не прошла на сервере; точной проверке допуск не
  нужен.

Ответы проверены точной реализацией на дробях (отсечение замкнутыми
полуплоскостями, затем положительная площадь) на нескольких сотнях
случайных входов, многие из которых полны равенств или почти равных
скоростей, и на тонкой полоске побед, построенной чуть ниже середины между
двумя соперниками.
