# 1062. 选择合适的赛段长度后谁能赢得铁人三项

[Timus 1062](https://acm.timus.ru/problem.aspx?space=1&num=1062) · 难度 1830 · geometry

原题出自 2000–2001 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一场比赛有三个赛段。`N` 名运动员（`1 ≤ N ≤ 100`）在三个赛段的速度为 `Vi, Ui, Wi`（1 到 10000 的整数）。组织者
可以任意选择各赛段的正长度。对每名运动员，判断是否存在某组长度，使得只有这名运动员的总用时最短。

时间限制：2 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行，每行 `Vi Ui Wi`。

## 输出

对每名运动员输出 `Yes` 或 `No`。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
9
10 2 6
10 7 3
5 6 7
3 2 7
6 2 6
3 5 7
8 4 6

```

输出：

```
Yes
Yes
Yes
No
No
No
Yes
No
Yes
```

### 样例 2

输入：

```
3
5 5 5
5 5 5
1 1 10
```

输出：

```
No
No
Yes
```

## 题解

当各段长度为 `(a, b, c)` 时，运动员 `j` 的用时是 `a/Vj + b/Uj + c/Wj`。运动员 `i` 胜过 `j` 当且仅当

```text
(1/Vi − 1/Vj)·a + (1/Ui − 1/Uj)·b + (1/Wi − 1/Wj)·c < 0
```

针对运动员 `i` 重新缩放长度：`u = (a/Vi, b/Ui, c/Wi)` 仍可取任意正三元组；乘以 `Vj·Uj·Wj` 后条件变为对三段求和
`Σ (Sj − Si) · (j 的另外两个速度) · u < 0`，系数都是小于 `10^12` 的整数。只有比例重要，所以 `u` 取遍三角形
`x > 0, y > 0, x + y < 1`（第三部分为 `1 − x − y`），每个对手都用一个开半平面去切它。剩下的开区域非空时，运动员 `i` 就能获胜。

用浮点数判断这一点并不可靠：区域可能是面积极小但为正的细条，也可能是面积为零的线段，任何容差都无法可靠地区分二者。解法精确地判断：把每个约束都收紧同一个极小的
`ε > 0`；开区域非空，当且仅当对所有足够小的 `ε`，收紧后的闭多边形非空。多边形按边界顺序保存为一列直线，顶点是相邻两条直线的交点，顶点相对新直线的位置由一个整数值的符号决定，若其为零再看
`ε` 系数的符号。这些值都小于 `3 · 10^37`，可放进 128 位整数。裁剪时保留严格位于内部的部分所在的每条边，并在边界离开半平面的地方插入新直线。每个对手
`O(N)`，总共 `O(N^3)`，至多一百万步。

注意事项：

- 完全相同的运动员：谁也不能单独第一；
- 在两段上相同、在第三段上更慢的运动员永远不会第一；
- 合适长度的区域可能只是一条线段或一个点，这不够：严格获胜需要开区域；
- 用固定容差的浮点面积判断（第一版用 `10^-12`）在评测机上没有通过；精确判断不需要容差。

答案经过验证：与一个用分数的精确实现（先用闭半平面裁剪，再看面积是否为正）比对，测试了数百组随机输入（其中许多充满相等或几乎相等的速度），以及一个在两个对手中点稍下方构造的细长获胜区域。
