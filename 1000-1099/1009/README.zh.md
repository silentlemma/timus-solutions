# 1009. 统计没有两个相邻零的 K 进制数

[Timus 1009](https://acm.timus.ru/problem.aspx?space=1&num=1009) · 难度 94 · dp, combinatorics

原题出自 1997 年乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

统计 `K` 进制下的 `N` 位数（首位不为零）中，数字里没有两个连续零的个数。`2 ≤ K ≤ 10`，`N ≥ 2`，
`N + K ≤ 18`。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N` 和 `K`，各占一行。

## 输出

个数。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
3
10
```

输出：

```
891
```

### 样例 2

输入：

```
2
2
```

输出：

```
2
```

## 题解

**动态规划。** 按最后一位统计合法前缀：`zero` 以 `0` 结尾，`other` 以非零数字结尾。一位时
`zero = 0`，`other = K - 1`。追加一位数字时：

- 零只能跟在非零数字后面：`zero' = other`；
- 非零数字可以跟在任何数字后面：`other' = (zero + other) · (K - 1)`。

`N` 位之后答案为 `zero + other`。时间 `O(N)`。

**组合计数。** 含 `z` 个零的数，这些零位于首位之后的 `N - 1` 个位置中且两两不相邻：共
`C(N - z, z)` 种；其余 `N - z` 位各取 `K - 1` 个非零值之一。答案为
`Σ C(N - z, z) · (K - 1)^(N - z)`，其中 `0 ≤ z ≤ N / 2`。

注意事项：

- 最大答案 `1 434 392 064`（`N = 11`，`K = 7`）接近 32 位整数上限，不小心写的公式中间值可能溢出：
  请使用 64 位整数；
- `K = 2` 时答案是斐波那契数，可用于检验。
