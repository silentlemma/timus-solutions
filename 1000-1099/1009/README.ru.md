# 1009. Подсчёт K-ичных чисел без двух нулей подряд

[Timus 1009](https://acm.timus.ru/problem.aspx?space=1&num=1009) · сложность 94 · dp, combinatorics

Оригинальная задача — чемпионат Уральского государственного университета 1997 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Посчитайте `N`-значные числа в системе счисления с основанием `K` (первая
цифра не ноль), в записи которых нет двух нулей подряд. `2 ≤ K ≤ 10`,
`N ≥ 2`, `N + K ≤ 18`.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `K`, каждое на своей строке.

## Выходные данные

Количество.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
3
10
```

Вывод:

```
891
```

### Пример 2

Ввод:

```
2
2
```

Вывод:

```
2
```

## Решение

**Динамическое программирование.** Считаем правильные префиксы по последней
цифре: `zero` оканчиваются на `0`, `other` — на ненулевую цифру. Для одной
цифры `zero = 0`, `other = K - 1`. При дописывании цифры:

- ноль может стоять только после ненулевой цифры: `zero' = other`;
- ненулевая цифра может стоять после чего угодно:
  `other' = (zero + other) · (K - 1)`.

После `N` цифр ответ — `zero + other`. Время `O(N)`.

**Комбинаторика.** У числа с `z` нулями они стоят среди `N - 1` позиций после
первой, никакие два не рядом: `C(N - z, z)` способов; каждая из остальных
`N - z` цифр принимает одно из `K - 1` значений. Ответ —
`Σ C(N - z, z) · (K - 1)^(N - z)` по `0 ≤ z ≤ N / 2`.

Подводные камни:

- наибольший ответ, `1 434 392 064` (`N = 11`, `K = 7`), близок к границе
  32-битных чисел, а промежуточные значения неаккуратной формулы могут
  переполниться: используйте 64-битные целые;
- при `K = 2` ответ — число Фибоначчи, удобная проверка.

## Особенности языков

- **C++**, **Go**, **Java**, **Rust**: ДП с двумя состояниями.
- **C++** и **Python** — ещё и через сумму; `math.comb` в Python считает
  биномиальные коэффициенты точно.
