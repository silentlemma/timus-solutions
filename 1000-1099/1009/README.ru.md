# 1009. Подсчёт K-ичных чисел без двух нулей подряд

[Timus 1009](https://acm.timus.ru/problem.aspx?space=1&num=1009) · сложность 95 · dp, combinatorics

Оригинальная задача — чемпионат Уральского государственного университета 1997 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Посчитайте `N`-значные числа в системе счисления с основанием `K` (первая
цифра не ноль), в записи которых нет двух нулей подряд. `2 ≤ K ≤ 10`,
`N ≥ 2`, `N + K ≤ 18`.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `K`, каждое на своей строке.

## Выходные данные

Количество.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
3
10
```

Вывод:

```
891
```

### Пример 2

Ввод:

```
2
2
```

Вывод:

```
2
```

## Решение

**Динамическое программирование.** Считаем правильные префиксы по последней
цифре: `zero` оканчиваются на `0`, `other` — на ненулевую цифру. Для одной
цифры `zero = 0`, `other = K - 1`. При дописывании цифры:

- ноль может стоять только после ненулевой цифры: `zero' = other`;
- ненулевая цифра может стоять после чего угодно:
  `other' = (zero + other) · (K - 1)`.

После `N` цифр ответ — `zero + other`. Время `O(N)`.

**Комбинаторика.** У числа с `z` нулями они стоят среди `N - 1` позиций после
первой, никакие два не рядом: `C(N - z, z)` способов; каждая из остальных
`N - z` цифр принимает одно из `K - 1` значений. Ответ —
`Σ C(N - z, z) · (K - 1)^(N - z)` по `0 ≤ z ≤ N / 2`.

Подводные камни:

- наибольший ответ, `1 434 392 064` (`N = 11`, `K = 7`), близок к границе
  32-битных чисел, а промежуточные значения неаккуратной формулы могут
  переполниться: используйте 64-битные целые;
- при `K = 2` ответ — число Фибоначчи, удобная проверка.

## Оптимизированные решения

`1009_math.py`. Рядом с DP цифр и комбинаторной учебной версией добавлен точный алгоритм производящей функции. Пусть q=K−1, B=2^36. Числа допустимых строк имеют функцию 1/(1−qx−qx²), поэтому коэффициент N извлекается как floor(B^(N+2)/(B²−qB−q)) mod B. Для всех допустимых N≥2,K≥2,N+K≤18 выполнены f_j≤K^j и оценка дробного хвоста K^(N+1)/(B−K)<1, исключающая перенос в извлекаемый разряд. Все 99 пар сверены с независимым биномиальным подсчётом на обоих рантаймах. Без float и готовых ответов. Одно деление O(N)-битных целых, числитель до 649 бит; для неограниченного N арифметика не константна. Текущая пара CPython 0.062 с/684 КБ отделена от сохранённой PyPy DP 0.109 с/196 КБ.

`1009_dp_optimized.go`. Go сохраняет динамику с двумя состояниями по последней цифре. Побайтовый переносимый ввод и фиксированный буфер вывода заменяют разбор и печать через fmt; хранятся только количества для предыдущего префикса. Получаем O(N) операций с целыми в пределах ограничений и O(1) дополнительной памяти.

По сравнению с `1009_dp.go`: время 0.031 s → 0.015 s; память 1104 KB → 796 KB.

`1009_dp.py`. Новый исходник Python использует динамику по цифрам вместо комбинаторной суммы. Пусть z и q — количества префиксов, заканчивающихся нулём и ненулевой цифрой. Начинаем с (z,q)=(0,K-1), исключая ведущий ноль, затем выполняем (z,q)=(q,(z+q)(K-1)). Ноль можно добавить лишь после ненулевой цифры, а ненулевых продолжений у каждого префикса K-1. Поэтому учитываются ровно допустимые строки за O(N) обновлений с O(1) ячейками для целых. Учебная комбинаторная версия остаётся отдельной.

По сравнению с `1009_combinatorics.py`: время 0.078 s → 0.109 s; память 404 KB → 196 KB.
