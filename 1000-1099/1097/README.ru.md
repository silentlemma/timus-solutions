# 1097. Квадратный парк, задевающий наименее влиятельных владельцев

[Timus 1097](https://acm.timus.ru/problem.aspx?space=1&num=1097) · сложность 1363 · bruteforce

Автор оригинальной задачи — Станислав Васильев; USU Open Collegiate Programming Contest, март 2001 года, Senior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Квадратная страна со стороной `L` имеет левый нижний угол в `(1, 1)`
(`1 ≤ A ≤ L ≤ 10000`). Заняты `M ≤ 100` квадратных участков с целыми
вершинами и сторонами, параллельными осям; они касаются друг друга не
больше чем по границе, и у каждого влиятельность от 2 до 100 или 255 для
участков жюри, которые занять нельзя. Разместите квадратный парк со
стороной `A` с целыми вершинами внутри страны так, чтобы наибольшая
влиятельность среди задетых им участков (с ненулевой площадью
пересечения) была как можно меньше. Выведите 1, если парк помещается на
свободной земле, иначе наименьшую возможную влиятельность или
`IMPOSSIBLE`, если любое место задевает участок жюри.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`L` и `A`, затем `M`, затем `M` строк с влиятельностью, стороной и левым
нижним углом участка.

## Выходные данные

1, наименьшая влиятельность или `IMPOSSIBLE`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
5 3
6
94 2 4 1
3 1 1 1
2 1 1 2
2 2 2 1
100 1 2 4
255 1 5 5
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
5 3
1
255 1 3 3
```

Вывод:

```
IMPOSSIBLE
```

## Решение

Парк с левым нижним углом `(px, py)` занимает `[px, px + A] × [py, py + A]`
и задевает участок `[x, x + s] × [y, y + s]` ровно тогда, когда
`px < x + s`, `x < px + A`, и то же выполнено для `y`.

Зафиксируем `py` и будем двигать парк слева направо. Множество задетых
участков меняется, только когда его левая сторона проходит правую
сторону участка (участок остаётся позади, при `px = x + s`) или его
правая сторона проходит левую сторону участка (участок задевается).
Задевание только добавляет участки, поэтому лучшие позиции — `px = 1`
или какое-то `x + s`. То же верно для `py` при фиксированном `x`, так что
`(px, py)` можно брать из не более чем 101 значения по каждой оси и
проверять каждую пару по всем участкам. `O(M³)`, около миллиона проверок.

Подводные камни:

- участки, касающиеся парка только по стороне, не считаются, поэтому все
  сравнения строгие;
- парк должен остаться внутри страны: `px + A − 1 ≤ L`, то есть
  `px ≤ L − A + 1`;
- 255 — не большая влиятельность, а запрещённый участок: место, которое
  его задевает, вообще недопустимо.

Ответы сверены с перебором всех положений парка в странах с `L ≤ 40`.

## Особенности языков

- Python сначала оставляет для каждого `px` участки этой вертикальной
  полосы, что сильно сокращает внутренний цикл.
