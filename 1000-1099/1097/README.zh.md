# 1097. 放置正方形公园，使受影响的业主尽量不重要

[Timus 1097](https://acm.timus.ru/problem.aspx?space=1&num=1097) · 难度 1363 · bruteforce

原题作者 Stanislav Vasiliev，出自 2001 年 3 月 USU Open Collegiate Programming Contest（Senior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

边长为 `L` 的正方形国家左下角在 `(1, 1)`（`1 ≤ A ≤ L ≤ 10000`）。有 `M ≤ 100` 块已被占用的正方形地块，顶点为整数，
边与坐标轴平行；它们之间至多在边界上接触，每块的影响力在 2 到 100 之间，或者为 255，表示评委的地块，不能征用。
在国家内放置一个边长为 `A`、顶点为整数的正方形公园，使它覆盖（相交面积为正）的地块中最大的影响力尽量小。若公园
能放在空地上，输出 1；否则输出最小可能的影响力；若每个位置都覆盖评委的地块，输出 `IMPOSSIBLE`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`L` 和 `A`，然后是 `M`，再然后 `M` 行，每行是一块地的影响力、边长和左下角坐标。

## 输出

1、最小的影响力，或 `IMPOSSIBLE`。

## 评测方式

按记号逐个比较输出；多余的空白不影响结果。

## 样例

### 样例 1

输入：

```
5 3
6
94 2 4 1
3 1 1 1
2 1 1 2
2 2 2 1
100 1 2 4
255 1 5 5
```

输出：

```
3
```

### 样例 2

输入：

```
5 3
1
255 1 3 3
```

输出：

```
IMPOSSIBLE
```

## 题解

左下角为 `(px, py)` 的公园占据 `[px, px + A] × [py, py + A]`，它与地块 `[x, x + s] × [y, y + s]` 相交，当且仅当
`px < x + s`、`x < px + A`，并且 `y` 方向也同样成立。

固定 `py`，让公园从左向右移动。只有当公园的左边越过某块地的右边（这块地被甩在后面，`px = x + s`），或者公园的
右边越过某块地的左边（这块地被覆盖）时，覆盖的地块集合才会改变。被覆盖只会增加地块，所以最好的位置是 `px = 1`
或某个 `x + s`。固定 `x` 时 `py` 也一样，因此 `(px, py)` 在每个坐标轴上最多取 101 个值，对每一对检查所有地块。
`O(M³)`，大约一百万次检查。

注意事项：

- 只在边上接触公园的地块不算，所以所有比较都是严格的；
- 公园必须在国家内：`px + A − 1 ≤ L`，即 `px ≤ L − A + 1`；
- 255 不是很大的影响力，而是禁止的地块：覆盖它的位置完全不允许。

答案与在 `L ≤ 40` 的国家中枚举公园所有位置的结果做了核对。

## 各语言说明

- Python 先为每个 `px` 保留该竖条内的地块，从而大大缩短内层循环。
