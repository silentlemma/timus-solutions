# 1069. Восстановление дерева по коду Прюфера

[Timus 1069](https://acm.timus.ru/problem.aspx?space=1&num=1069) · сложность 513 · trees

Автор оригинальной задачи — Магаз Асанов; Ural State University Personal Contest Online, февраль 2001 года, Students Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дерево на вершинах `1 … N` (`2 ≤ N ≤ 7500`) кодируется так: берём лист с
наименьшим номером, удаляем его и записываем его соседа; повторяем, пока
не останется одна вершина (это всегда `N`). Записанные `N − 1` чисел и есть
код. По коду выведите список смежности каждой вершины.

Ограничение времени: 0.25 секунды. Ограничение памяти: 8 МБ.

## Входные данные

Код: `N − 1` чисел, разделённых пробелами и переводами строк.

## Выходные данные

Для каждой вершины по возрастанию — строка `v: a b c …` с её соседями по
возрастанию.

## Проверка

Вывод сравнивается построчно; внутри строки — по токенам.

## Примеры

### Пример 1

Ввод:

```
2 1 6 2 6
```

Вывод:

```
1: 4 6
2: 3 5 6
3: 2
4: 1
5: 2
6: 1 2
```

## Решение

При кодировании вершина записывается по разу за каждого соседа, удалённого
раньше неё, и становится листом, когда у неё остаётся один сосед. Счётчик
`1 + (число вхождений v в код)` равен степени для `v != N` и степени плюс
один для `N`. Перед каждым шагом оставшиеся вершины со счётчиком 1 — это
ровно листья, кроме `N`.

Декодер повторяет кодирование шаг за шагом. Начинаем со счётчиков,
описанных выше, и минимальной кучи вершин со счётчиком 1. Для каждого числа `c`
кода наименьший лист — это удалённая вершина: соединяем её с `c` и
уменьшаем счётчик `c`; когда он становится равным 1, отправляем `c` в
кучу. Затем сортируем каждый список смежности.
`O(N log N)`.

Подводные камни:

- в этом коде `N − 1` чисел и он заканчивается на `N` — на одно больше,
  чем в обычном коде Прюфера, поэтому `N` — это количество чисел плюс один;
- вершина `N` не покинет кучу слишком рано: у дерева всегда не меньше двух
  листьев, так что лист с меньшим номером всегда найдётся;
- числа могут быть как угодно разбиты по строкам, поэтому они читаются как
  токены;
- ограничения жёсткие (0.25 секунды и 8 МБ), поэтому вывод
  буферизуется, а списки хранятся компактно.

Ответы проверены в обратную сторону: выведенное дерево, закодированное
заново по определению, даёт исходный ввод.

## Оптимизированные решения

Go убирает кучу листьев и сортировку смежности. Монотонный указатель ищет следующий номер без оставшихся вхождений в коде. После соединения листа с очередным номером кода сразу берём этот номер, если его последнее вхождение исчезло и он меньше указателя. Все меньшие номера уже удалены или ещё встречались в коде, а изменился только этот счётчик. Иначе двигаем указатель вперёд до минимального доступного листа. Сохраняем родителя каждого удалённого листа. Последний символ кода N, поэтому N остаётся корнем. Добавление номеров по убыванию в начало списков детей даёт возрастающие списки. При выводе сливаем их с одним родителем: сортированная смежность тоже строится линейно. Номера и счётчики при N≤7500 помещаются в uint16. Время и память O(N), ввод-вывод ограничен блоками. Учебные версии с кучей сохранены; остальные семейства используют подходящие базы.

Принятые базовые реализации [1069_trees.cpp](1069_trees.cpp), [1069_trees.java](1069_trees.java), [1069_trees.py](1069_trees.py), [1069_trees.rs](1069_trees.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.

## Особенности языков

C++/Rust сохраняют минимальные кучи, Java — PriorityQueue и размерные массивы смежности, Python — heapq. Исходный Go использует container/heap; новый Go — монотонный указатель листьев и слияние детей с родителем, uint16 для номеров/счётчиков и ограниченный ввод-вывод.
