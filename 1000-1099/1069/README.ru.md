# 1069. Восстановление дерева по коду Прюфера

[Timus 1069](https://acm.timus.ru/problem.aspx?space=1&num=1069) · сложность 517 · trees

Автор оригинальной задачи — Магаз Асанов; Ural State University Personal Contest Online, февраль 2001 года, Students Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дерево на вершинах `1 … N` (`2 ≤ N ≤ 7500`) кодируется так: берём лист с
наименьшим номером, удаляем его и записываем его соседа; повторяем, пока
не останется одна вершина (это всегда `N`). Записанные `N − 1` чисел и есть
код. По коду выведите список смежности каждой вершины.

Ограничение времени: 0.25 секунды. Ограничение памяти: 8 МБ.

## Входные данные

Код: `N − 1` чисел, разделённых пробелами и переводами строк.

## Выходные данные

Для каждой вершины по возрастанию — строка `v: a b c …` с её соседями по
возрастанию.

## Проверка

Вывод сравнивается построчно; внутри строки — по токенам.

## Примеры

### Пример 1

Ввод:

```
2 1 6 2 6
```

Вывод:

```
1: 4 6
2: 3 5 6
3: 2
4: 1
5: 2
6: 1 2
```

## Решение

При кодировании вершина записывается по разу за каждого соседа, удалённого
раньше неё, и становится листом, когда у неё остаётся один сосед. Поэтому
степень вершины `v` равна `1 + (число вхождений v в код)`, а на каждом шаге
текущие листья — это ровно те ещё не удалённые вершины, которых больше нет
в оставшейся части кода.

Декодер повторяет кодирование шаг за шагом. Начинаем со степеней,
описанных выше, и минимальной кучи вершин степени 1. Для каждого числа `c`
кода наименьший лист — это удалённая вершина: соединяем её с `c` и
уменьшаем степень `c`; когда она становится равной 1, `c` превратилась в
лист и отправляется в кучу. Затем сортируем каждый список смежности.
`O(N log N)`.

Подводные камни:

- в этом коде `N − 1` чисел и он заканчивается на `N` — на одно больше,
  чем в обычном коде Прюфера, поэтому `N` — это количество чисел плюс один;
- вершина `N` не покинет кучу слишком рано: у дерева всегда не меньше двух
  листьев, так что лист с меньшим номером всегда найдётся;
- числа могут быть как угодно разбиты по строкам, поэтому они читаются как
  токены;
- ограничения жёсткие (0.25 секунды и 8 МБ), поэтому вывод собирается в
  одном буфере, а списки хранятся компактно.

Ответы проверены в обратную сторону: выведенное дерево, закодированное
заново по определению, даёт исходный ввод.

## Особенности языков

- C++ превращает `std::priority_queue` в минимальную кучу с помощью
  `std::greater`; Rust делает то же через `Reverse` в `BinaryHeap`.
- Go использует `container/heap` с небольшим типом `[]int`.
- Java хранит каждый список смежности в массиве `int` размером со степень,
  а листья — в `PriorityQueue`.
- Python использует `heapq`.
