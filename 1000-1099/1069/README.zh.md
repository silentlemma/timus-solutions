# 1069. 由 Prüfer 编码重建树

[Timus 1069](https://acm.timus.ru/problem.aspx?space=1&num=1069) · 难度 513 · trees

原题作者 Magaz Asanov，出自 2001 年 2 月 Ural State University Personal Contest Online（Students Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

顶点为 `1 … N`（`2 ≤ N ≤ 7500`）的树这样编码：取编号最小的叶子，删去它并记下它的邻居；重复直到只剩一个顶点
（总是 `N`）。记下的 `N − 1` 个数就是编码。给定编码，输出每个顶点的邻接表。

时间限制：0.25 秒。内存限制：8 MB。

## 输入

编码：`N − 1` 个数，用空格和换行分隔。

## 输出

按编号递增，每个顶点一行 `v: a b c …`，邻居按递增顺序排列。

## 评测方式

按行比较输出；行内按记号逐个比较。

## 样例

### 样例 1

输入：

```
2 1 6 2 6
```

输出：

```
1: 4 6
2: 3 5 6
3: 2
4: 1
5: 2
6: 1 2
```

## 题解

编码时，一个顶点在它之前每删去一个邻居就被记下一次，当它只剩一个邻居时就成为叶子。计数器
`1 +（v 在编码中出现的次数）` 对 `v != N` 等于度数，对 `N` 则比度数大一。每一步开始前，尚未删除且计数器为 1
的顶点恰好是除 `N` 外的叶子。

解码器一步一步地重演编码过程。从上述计数器和由计数器为 1 的顶点组成的最小堆开始。对编码中的每个数 `c`，最小的
叶子就是被删去的顶点：把它与 `c` 相连，并把 `c` 的计数器减一；当计数器降到 1 时，把 `c` 放入堆中。最后
对每个邻接表排序。`O(N log N)`。

注意事项：

- 这里的编码有 `N − 1` 个数并以 `N` 结尾，比通常的 Prüfer 编码多一个，所以 `N` 等于数的个数加一；
- 顶点 `N` 不会过早出堆：树总是至少有两片叶子，所以总有编号更小的叶子；
- 数可能以任意方式分布在各行，所以按记号读取；
- 限制很紧（0.25 秒和 8 MB），所以输出使用缓冲，邻接表也保存得很紧凑。

答案反向做了核对：把输出的树按定义重新编码，得到的正是输入。

## 优化解法

Go 同时去掉叶堆与邻接排序。单调指针找剩余编码中不再出现的最小候选标签；连接当前叶后，若代码标签最后一次出现已消失且小于指针，立即取它。更小的标签此前要么已删除，要么仍在编码中出现，而本步只改了这一个计数。否则向前找最小可用叶。保存每个移除叶的父。编码最后一个符号为 N，因此 N 留作根。按顶点编号递减前插子链表，得到递增子列表；输出时与唯一父节点合并，邻接排序也为线性。N≤7500 时标签及计数适合 uint16。时间空间 O(N)，输入输出有界。保留堆教学版；其余四种语言复用达标基础版。
