# 1051. 无限网格上的跳棋独立钻石

[Timus 1051](https://acm.timus.ru/problem.aspx?space=1&num=1051) · 难度 534 · games, math

原题作者 Stanislav Vasiliev，出自 2000 年 3 月 25 日乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个 `M × N`（`1 ≤ M, N ≤ 10000`）的石子矩形放在无限网格的格点上。一步操作：一颗石子沿水平或竖直方向跳过相邻
的石子，落到其后的空格点上，被跳过的石子被移走。求最少能剩下多少颗石子。

时间限制：1 秒。内存限制：64 MB。

## 输入

`M` 和 `N`。

## 输出

最少剩余的石子数。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
3 4
```

输出：

```
2
```

### 样例 2

输入：

```
1 7
```

输出：

```
4
```

## 题解

答案只取决于形状：

```text
min(M, N) = 1                      ->  ceil(max(M, N) / 2)
否则，若 M 或 N 能被 3 整除         ->  2
否则                               ->  1
```

**为什么一边能被 3 整除时不能剩 1 颗。** 把格点 `(x, y)` 染成颜色 `(x + y) mod 3`。一行或一列中相邻的三个格点
颜色两两不同，一次跳跃清空其中两个、占据第三个：每种颜色的数量都变化 1，所以三种颜色数量的奇偶性同时翻转，
它们是否相等永远不会改变。一边能被 3 整除的矩形三种颜色数量相等（奇偶性相同）；一颗石子的数量是 `1, 0, 0`，
并不如此。所以至少剩两颗，而两颗是可以做到的。

**其余的二维情形。** 借助一颗相邻的石子，可以把一行中连续的三颗石子消去；这样矩形一条边一条边地缩小，直到
几种小情形，它们最后都只剩一颗石子。

**只有一行。** 一次跳跃用掉两颗相邻石子，并在直线上更远两格处留下一颗；在一条直线上石子无法再聚到一起，所以
每颗石子最多参与一次跳跃：至少剩下 `ceil(n / 2)` 颗，而从两端成对跳跃即可达到。

这个公式还对 `3 × 4`、`2 × 7`、`4 × 4` 以内的所有棋盘，用穷举所有局面（平移视为相同）验证过。`O(1)`。

注意事项：

- 一行的情形不同：`1 × 7` 剩 4 颗，而不是 1 颗；
- `2 × 3` 剩 2 颗，而 `2 × 4` 剩 1 颗；
- `M` 和 `N` 的顺序任意。
