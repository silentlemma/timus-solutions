# 1051. Пасьянс с прыжками на бесконечной сетке

## Задача

Прямоугольник `M × N` камней (`1 ≤ M, N ≤ 10000`) стоит в узлах
бесконечной сетки. Ход: камень перепрыгивает через соседа по горизонтали
или вертикали на пустой узел за ним, а перепрыгнутый камень убирается.
Найдите наименьшее число камней, которое может остаться.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`M` и `N`.

## Выходные данные

Наименьшее число оставшихся камней.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
3 4
```

Вывод:

```
2
```

### Пример 2

Ввод:

```
1 7
```

Вывод:

```
4
```

## Решение

Ответ зависит только от формы:

```text
min(M, N) = 1                      ->  ceil(max(M, N) / 2)
иначе, если M или N делится на 3   ->  2
иначе                              ->  1
```

**Почему не 1, если сторона делится на 3.** Раскрасим узел `(x, y)` в цвет
`(x + y) mod 3`. Три подряд идущих узла строки или столбца имеют три
разных цвета, а прыжок освобождает два из них и занимает третий: каждое
количество меняется на единицу, поэтому чётности всех трёх количеств
меняются одновременно, и то, равны они или нет, не меняется никогда. У
прямоугольника со стороной, кратной 3, количества трёх цветов равны (все
одной чётности); у одного камня количества `1, 0, 0` — нет. Значит,
останется хотя бы два камня, и два достижимы.

**Двумерный случай в остальном.** Камни можно убирать тройками подряд с
помощью соседнего камня; так прямоугольник уменьшается сторона за
стороной до нескольких маленьких случаев, и все они заканчиваются одним
камнем.

**Одна строка.** Прыжок берёт двух соседей и оставляет один камень на две
клетки дальше по линии, а на одной линии камни уже не собрать вместе,
поэтому каждый камень участвует не больше чем в одном прыжке: остаётся
хотя бы `ceil(n / 2)` камней, и прыжки парами с краёв этого достигают.

Формула также проверена полным перебором всех позиций (с точностью до
сдвига) для всех досок до `3 × 4`, `2 × 7` и `4 × 4`. `O(1)`.

Подводные камни:

- одна строка устроена иначе: `1 × 7` оставляет 4, а не 1;
- `2 × 3` оставляет 2, а `2 × 4` — 1;
- `M` и `N` могут идти в любом порядке.
