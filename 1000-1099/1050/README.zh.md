# 1050. 把直引号改成 TeX 引号

[Timus 1050](https://acm.timus.ru/problem.aspx?space=1&num=1050) · 难度 1442 · parsing

原题作者 Alexander Galperin，出自 2000 年 3 月 25 日乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一份 TeX 源文本最多 250 行（每行最多 80 个字符），以命令 `\endinput` 结尾。原样复制它，只有双引号 `"`
（编码 34）例外：

- 在一个段落内，引号依次替换为 ``` `` ```（开引号）和 `''`（闭引号）；
- 同一段落中没有闭引号与之配对的开引号被删除；
- `\"` 是变音符命令（如 `\"e`），保持不变。

段落在空行（一行或多行）处和命令 `\par` 处结束。命令以 `\` 开头，在第一个不是拉丁字母的字符处结束。文本可能
包含大于 127 的字节，最后一行可能没有换行符。

时间限制：1 秒。内存限制：64 MB。

## 输入

以 `\endinput` 结尾的文本。

## 输出

转换后的文本。

## 评测方式

输出必须与期望文本相同；只忽略末尾的空白字符。测试以 UTF-8 保存文本，以 cp1251（一种含西里尔字母的单字节
编码）交给解法。

## 样例

### 样例 1

输入：

```
There is no "q in this sentence. \par 
"Talk child," said the unicorn. 

She s\"aid, "\thinspace `Enough!', he said." 
\endinput
```

输出：

```
There is no q in this sentence. \par 
``Talk child,'' said the unicorn. 

She s\"aid, ``\thinspace `Enough!', he said.'' 
\endinput
```

### 样例 2

输入：

```
Он сказал: "Привет!" и ушёл, "не закрыв цитату.
   
"Новый абзац" с умлаутом \"o.
\endinput
```

输出：

```
Он сказал: ``Привет!'' и ушёл, не закрыв цитату.
   
``Новый абзац'' с умлаутом \"o.
\endinput
```

## 题解

对字节扫描一遍，记录当前段落中各引号的位置：

- `\` 后面是 `"` 时为变音符：跳过这两个字符。否则读取 `\` 之后的拉丁字母；若恰好是 `par`，段落结束（`\parbox`
  不结束段落）；
- `"` 加入本段落的列表；
- 遇到换行时看下一行：若它只含空格、制表符等空白字符，并且自身以换行结尾，则段落结束。

段落结束时，若引号个数为奇数，最后一个被标记删除，其余的交替作为开引号和闭引号。最后一个段落结束后，复制所有
字节，并替换被标记的引号。长度为 `L` 字节的文本 `O(L)`。

注意事项：

- 一个引号的处理方式要到其段落结束才能确定，所以在扫描结束后再输出；
- “空”行可能包含空格或制表符；
- `\par` 必须是完整的命令：`\parbox` 和 `\partial` 不结束段落，而 `\par"x` 会结束；
- 文本是字节而不是 UTF-8：大于 127 的字母原样通过，缺少的末尾换行也必须保持缺少；
- 测试中不会出现紧跟在 `"` 或字母之前的双反斜杠 `\\`，在那种情况下 TeX 与简单扫描的理解可能不同。

## 各语言说明

- 各语言都把全部输入当作字节读入并以字节输出：Java 不使用带字符集的 `Reader`，Python 使用 `sys.stdin.buffer`。
