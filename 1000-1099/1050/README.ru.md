# 1050. Превращение прямых кавычек в кавычки TeX

[Timus 1050](https://acm.timus.ru/problem.aspx?space=1&num=1050) · сложность 1442 · parsing

Автор оригинальной задачи — Александр Гальперин; студенческое соревнование по программированию УрГУ, 25 марта 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Исходный текст TeX из не более чем 250 строк (не длиннее 80 символов)
заканчивается командой `\endinput`. Скопируйте его в точности, кроме
двойных кавычек `"` (код 34):

- внутри абзаца кавычки по очереди заменяются на ``` `` ``` (открывающая)
  и `''` (закрывающая);
- открывающая кавычка без закрывающей в том же абзаце удаляется;
- `\"` — команда умлаута (как в `\"e`) и остаётся без изменений.

Абзац заканчивается пустой строкой (или несколькими) и командой `\par`.
Команды начинаются с `\` и заканчиваются на первом символе, который не
является латинской буквой. В тексте могут быть байты больше 127, а у
последней строки может не быть перевода строки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Текст, заканчивающийся на `\endinput`.

## Выходные данные

Преобразованный текст.

## Проверка

Вывод должен совпадать с ожидаемым текстом; игнорируются только пробельные
символы в самом конце. Тесты хранят текст в UTF-8 и передают его решениям
в cp1251 — однобайтовой кодировке с кириллицей.

## Примеры

### Пример 1

Ввод:

```
There is no "q in this sentence. \par 
"Talk child," said the unicorn. 

She s\"aid, "\thinspace `Enough!', he said." 
\endinput
```

Вывод:

```
There is no q in this sentence. \par 
``Talk child,'' said the unicorn. 

She s\"aid, ``\thinspace `Enough!', he said.'' 
\endinput
```

### Пример 2

Ввод:

```
Он сказал: "Привет!" и ушёл, "не закрыв цитату.
   
"Новый абзац" с умлаутом \"o.
\endinput
```

Вывод:

```
Он сказал: ``Привет!'' и ушёл, не закрыв цитату.
   
``Новый абзац'' с умлаутом \"o.
\endinput
```

## Решение

Один проход по байтам с запоминанием позиций кавычек текущего абзаца:

- `\`, за которым идёт `"`, — умлаут: пропускаем оба символа. Иначе
  читаем латинские буквы после `\`; если это ровно `par`, абзац
  заканчивается (`\parbox` его не заканчивает);
- `"` добавляется в список абзаца;
- на переводе строки смотрим на следующую строку: если в ней только
  пробелы, табуляции и другие пробельные символы и она сама заканчивается
  переводом строки, абзац заканчивается.

Когда абзац заканчивается, нечётная последняя кавычка помечается к
удалению, а остальные чередуются между открывающими и закрывающими. После
последнего абзаца байты копируются с заменой помеченных кавычек. `O(L)`
для текста из `L` байтов.

Подводные камни:

- судьба кавычки известна только в конце её абзаца, поэтому вывод
  пишется после прохода;
- «пустая» строка может содержать пробелы или табуляции;
- `\par` должен быть целой командой: `\parbox` и `\partial` не
  заканчивают абзац, а `\par"x` заканчивает;
- текст — это байты, а не UTF-8: буквы с кодами больше 127 проходят без
  изменений, а отсутствующий последний перевод строки должен остаться
  отсутствующим;
- тесты не содержат двойной обратной косой черты `\\` прямо перед `"` или
  перед буквами, где TeX и простой проход могут разойтись.

## Особенности языков

- Во всех языках ввод читается целиком как байты и выводится как байты:
  в Java нет `Reader` с кодировкой, в Python используется
  `sys.stdin.buffer`.
