# 1028. 统计每个点左下方的点数

[Timus 1028](https://acm.timus.ru/problem.aspx?space=1&num=1028) · 难度 264 · fenwick, segment_tree

原题出自 1999 年第三届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 `N` 个互不相同的点（`1 ≤ N ≤ 15 000`），整数坐标 `0 ≤ x, y ≤ 32 000`，按 `y` 递增给出，`y` 相同时按
`x` 递增。一个点的 **等级** 是满足 `x' ≤ x` 且 `y' ≤ y` 的其他点的个数。对 0 到 `N - 1` 的每个 `k`，输出
等级为 `k` 的点有多少个。

时间限制：0.25 秒。内存限制：64 MB。

## 输入

`N`，然后按上述顺序给出 `N` 行 `x y`。

## 输出

`N` 行：等级为 0、1、……、`N - 1` 的点的个数。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
6
2 0
6 0
0 2
4 2
4 4
1 6
```

输出：

```
2
2
1
1
0
0
```

### 样例 2

输入：

```
1
32000 32000
```

输出：

```
1
```

## 题解

输入的顺序已经完成了一半的工作。一个点到来时，所有 `y` 更小的点、以及 `y` 相同且 `x` 更小的点都已经到来；
而之后到来的点（除了它自己）都不会同时满足 `y' ≤ y` 和 `x' ≤ x`。所以一个点的等级就是 **已出现** 的点中
`x' ≤ x` 的个数。

这是带插入的 `x` 前缀计数：在坐标 `0..32 000` 上建一棵 **树状数组**（Fenwick 树），每次查询“已插入的值中
有多少 `≤ x`”和插入一个值都只需 `O(log C)`，`C` 为坐标范围。按顺序处理各点：查询、记录等级、插入。总计
`O(N log C)`。

在坐标上建线段树也可以，稍慢一些。

注意事项：

- `x` 可能为 0，而树状数组从 1 开始编号：整体加一；
- 对之前的点做平方级统计需要 `10^8` 次比较——在 0.25 秒内太慢；
- 输出有 `N` 个数：先在缓冲区中构造。

## 各语言说明

- **C++**：树状数组以及自底向上的线段树。
- **Go**、**Python**、**Java**、**Rust**：树状数组；Python 的循环尽量精简（只转换 `x` 坐标，向下用
  `j &= j - 1`）。
