# 1028. Подсчёт точек ниже и левее каждой точки

[Timus 1028](https://acm.timus.ru/problem.aspx?space=1&num=1028) · сложность 264 · fenwick, segment_tree

Оригинальная задача — III командный студенческий чемпионат Урала по программированию, 1999 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N` различных точек (`1 ≤ N ≤ 15 000`) с целыми координатами
`0 ≤ x, y ≤ 32 000` даны в порядке возрастания `y`, а при равных `y` — `x`.
**Уровень** точки — число других точек с `x' ≤ x` и `y' ≤ y`. Для каждого
`k` от 0 до `N - 1` выведите, сколько точек имеют уровень `k`.

Ограничение времени: 0.25 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк `x y` в описанном порядке.

## Выходные данные

`N` строк: количество точек уровня 0, 1, ..., `N - 1`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
6
2 0
6 0
0 2
4 2
4 4
1 6
```

Вывод:

```
2
2
1
1
0
0
```

### Пример 2

Ввод:

```
1
32000 32000
```

Вывод:

```
1
```

## Решение

Порядок входа делает половину работы. Когда приходит точка, все точки с
меньшим `y`, а также с тем же `y` и меньшим `x`, уже пришли — и ни у одной
более поздней точки нет одновременно `y' ≤ y` и `x' ≤ x`, если это не та же
точка. Значит, уровень точки — число **уже увиденных** точек с `x' ≤ x`.

Это подсчёт на префиксе по `x` со вставками: **дерево Фенвика** по
координатам `0..32 000` отвечает на «сколько вставленных значений `≤ x`» и
вставляет значение за `O(log C)` каждое, где `C` — диапазон координат.
Обрабатываем точки по порядку: запрос, учёт уровня, вставка. Всего
`O(N log C)`.

Дерево отрезков по координатам работает так же, чуть медленнее.

Подводные камни:

- `x` может быть 0, а дерево Фенвика нумеруется с 1: сдвигайте на единицу;
- квадратичный подсчёт предыдущих точек — это `10^8` сравнений, слишком
  медленно для 0.25 секунды;
- в выводе `N` чисел: собирайте его в буфер.

## Особенности языков

- **C++**: дерево Фенвика и дерево отрезков снизу вверх.
- **Go**, **Python**, **Java**, **Rust**: дерево Фенвика; в Python циклы
  максимально короткие (преобразуются только координаты `x`, спуск —
  `j &= j - 1`).
