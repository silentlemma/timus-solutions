# 1066. 下垂彩灯串最低的末端

[Timus 1066](https://acm.timus.ru/problem.aspx?space=1&num=1066) · 难度 580 · math

原题出自 2000–2001 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一串由 `N` 盏灯组成的彩灯（`3 ≤ N ≤ 1000`）两端悬挂。每盏中间的灯都比相邻两盏灯的平均高度低 1 毫米：
`H(i) = (H(i−1) + H(i+1)) / 2 − 1`。第一盏灯的高度为 `A`（`10 ≤ A ≤ 1000`，实数）。任何灯都不能低于地面，
但可以接触地面（`H(i) ≥ 0`）。求最后一盏灯可能的最小高度 `B`。

时间限制：2 秒。内存限制：64 MB。

## 输入

一行，包含 `N` 和 `A`。

## 输出

`B`，小数点后至少两位。

## 评测方式

数值按绝对误差 0.011 比较：答案以两位小数输出，最后一位可能相差 1。

## 样例

### 样例 1

输入：

```
8 15
```

输出：

```
9.75
```

### 样例 2

输入：

```
692 532.81
```

输出：

```
446113.34
```

## 题解

这条规则等价于 `H(i+1) = 2·H(i) − H(i−1) + 2`：高度的二阶差分恒为 2。因此第二盏灯的高度 `x` 决定了整串彩灯：

`H(i) = A + (i−1)·(x − A) + (i−1)·(i−2)`。

最后的高度随 `x` 增大而增大（系数 `N − 1` 为正），所以答案来自使所有灯都不低于 0 的最小 `x`。对第 `k + 1`
盏灯，条件 `H(k+1) ≥ 0` 即 `x ≥ A − A/k − (k − 1)`，`x` 取 `k = 1 … N−1` 上这些下界的最大值（`k = 1`
时的下界是 `x ≥ 0`）。然后 `B = H(N)`。`O(N)`。

注意事项：

- 接触地面的不一定是中间的灯：`A/k + k` 最小处下界最大，大约在 `k = √A`；如果这个位置超出了彩灯串的末端，
  接触地面的就是最后一盏灯本身，`B = 0`；
- `B` 按 `N^2` 增长，最大约为 `10^6`，`double` 完全能容纳；
- 对第二盏灯的高度二分查找也可行，但公式不需要迭代，也不需要容差。

答案用精确分数做了核对：从求出的第二个高度向前递推，所有灯都不低于 0，并且其中一盏恰好为 0。

## 各语言说明

- Python 用一次对生成器的 `max` 求出第二个高度。
- Java 用 `Locale.US` 读取 `A`，因此无论系统区域设置如何，都能接受小数点。
