# 1066. Самый низкий конец провисшей гирлянды

[Timus 1066](https://acm.timus.ru/problem.aspx?space=1&num=1066) · сложность 580 · math

Оригинальная задача — полуфинал ACM ICPC Северо-Восточной Европы 2000–2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Гирлянда из `N` ламп (`3 ≤ N ≤ 1000`) подвешена за концы. Каждая
внутренняя лампа висит на 1 миллиметр ниже средней высоты двух соседних:
`H(i) = (H(i−1) + H(i+1)) / 2 − 1`. Первая лампа висит на высоте `A`
(`10 ≤ A ≤ 1000`, вещественное число). Ни одна лампа не может оказаться
под землёй, хотя некоторые могут её касаться (`H(i) ≥ 0`). Найдите
наименьшую возможную высоту `B` последней лампы.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `A` в одной строке.

## Выходные данные

`B` не менее чем с двумя знаками после запятой.

## Проверка

Числа сравниваются с абсолютной погрешностью 0.011: ответы печатаются с
двумя знаками, поэтому последняя цифра может отличаться на единицу.

## Примеры

### Пример 1

Ввод:

```
8 15
```

Вывод:

```
9.75
```

### Пример 2

Ввод:

```
692 532.81
```

Вывод:

```
446113.34
```

## Решение

Правило равносильно `H(i+1) = 2·H(i) − H(i−1) + 2`: вторая разность высот
всегда равна 2. Значит, вторая высота `x` задаёт всю гирлянду:

`H(i) = A + (i−1)·(x − A) + (i−1)·(i−2)`.

Последняя высота растёт вместе с `x` (её коэффициент `N − 1`
положителен), поэтому ответ даёт наименьшее `x`, при котором все лампы
остаются на высоте 0 или выше. Для лампы `k + 1` условие `H(k+1) ≥ 0`
означает `x ≥ A − A/k − (k − 1)`, и `x` — наибольшая из этих границ по
`k = 1 … N−1` (граница для `k = 1` — это `x ≥ 0`). Затем `B = H(N)`.
`O(N)`.

Подводные камни:

- земли касается не обязательно средняя лампа: граница наибольшая там,
  где `A/k + k` наименьшее, около `k = √A`, а если это место за концом
  гирлянды, земли касается сама последняя лампа и `B = 0`;
- `B` растёт как `N^2` и доходит примерно до `10^6`, что `double` хранит с
  большим запасом;
- двоичный поиск по второй высоте тоже работает, но формуле не нужны ни
  итерации, ни допуск.

Ответы проверены точными дробями: рекуррентность, запущенная вперёд от
найденной второй высоты, оставляет все лампы на высоте 0 или выше, а одну
из них — ровно на 0.

## Особенности языков

- В Python вторая высота находится одним `max` по генератору.
- Java читает `A` с `Locale.US`, поэтому десятичная точка принимается при
  любой системной локали.
