# 1041. 从一组向量中选出最便宜的基

[Timus 1041](https://acm.timus.ru/problem.aspx?space=1&num=1041) · 难度 4654 · math, greedy

原题作者 Dmitry Filimonenkov，出自 2000 年 10 月第五届乌拉尔国立大学团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `M` 个 `N` 维整数向量（`3 ≤ N ≤ 50`，`N ≤ M ≤ 2000`，坐标绝对值不超过 2000），每个向量有 1 到 15000
的价格。选出 `N` 个线性无关的向量，使总价格最小。在所有最便宜的选法中，输出按升序排列的编号列表中字典序最小
的那个。如果任何 `N` 个向量都不线性无关，输出 `0`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`M` 和 `N`，然后 `M` 行向量坐标，再然后 `M` 行价格。

## 输出

最小总价格，然后按升序输出选中的 `N` 个向量编号，每行一个；或者 `0`。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
5 3
1 0 0
0 1 0
0 0 1
0 0 2
0 0 3
10
20
30
10
10
```

输出：

```
40
1
2
4
```

### 样例 2

输入：

```
4 3
1 2 3
2 4 6
0 1 1
1 3 4
1
1
1
1
```

输出：

```
0
```

## 题解

线性无关的向量集构成拟阵，而拟阵上贪心算法是最优的：从最便宜的向量开始依次考虑，若一个向量与已保留的向量
线性无关就保留它。价格相同时按编号从小到大。这样也得到字典序最小的列表。所有最便宜的基在每个价格等级 `c`
上都包含一组（在更便宜向量张成空间之上的）基。不同等级的选择互不影响，而在每个等级上按编号递增的贪心得到的
基，对每个 `k`，其第 `k` 小的编号都是可能的最小值。

线性无关的检验用高斯消元：保留的向量以阶梯形式存放（每行有一个等于 1 的主元坐标，且在之前各行的主元坐标处
为零）。用每一行约化候选向量；若还剩非零分量，它就线性无关，成为新的一行。共 `O(M · N^2)` 次运算。

精确运算很重要：用浮点数时，几乎平行的整数向量可能被误判。解法在素数 `2^31 − 1` 的模下计算。模素数线性无关
的集合在有理数上也线性无关（某个子式模该素数不为零，因而不为零）。反过来只有当该素数整除所有非零的 `N × N`
子式时才会出错，对这样的规模和数据实际上不可能。测试用精确分数核对过。

注意事项：

- 只按价格贪心不够：价格相同时必须按编号递增处理，列表才是最小的；
- 输出的向量编号按升序排列，而不是按选择的顺序；
- 如果全部 `M` 个向量张成的维数都不到 `N`，答案是 `0`。

## 各语言说明

- **C++**、**Go**、**Java**、**Rust**：64 位整数；两个小于 `2^31` 的剩余相乘绰绰有余。
- **Python**：基保持完全约化（每一行在其他各行的主元坐标处都是零）。这样候选向量在一个自由坐标上的余量就是
  与它的主元坐标的一次点积，用 `sum(map(mul, ...))` 计算，在 CPython 中足够快。
