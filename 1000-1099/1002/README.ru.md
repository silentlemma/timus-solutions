# 1002. Запись номера наименьшим числом слов

[Timus 1002](https://acm.timus.ru/problem.aspx?space=1&num=1002) · сложность 226 · dp, hashing

Оригинальная задача — Центральноевропейская олимпиада по информатике 1999 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждой строчной латинской букве соответствует одна цифра:

| Цифра | Буквы |
|-------|-------|
| 1 | i j |
| 2 | a b c |
| 3 | d e f |
| 4 | g h |
| 5 | k l |
| 6 | m n |
| 7 | p r s |
| 8 | t u v |
| 9 | w x y |
| 0 | o q z |

Слово записывает строку из цифр своих букв. Даны номер (строка не более чем
из 100 цифр) и словарь из `n ≤ 50 000` слов. Найдите последовательность слов
словаря с наименьшим числом слов, записи которых, склеенные подряд, дают номер.
Каждое слово можно использовать сколько угодно раз.

Во входных данных несколько таких тестов; общий размер ввода не больше 300 КБ.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Тесты идут друг за другом. Тест — это строка с номером, строка с `n` и `n`
строк по одному слову (от 1 до 50 строчных букв). Строка `-1` завершает ввод.

## Выходные данные

Для каждого теста — одна строка: слова кратчайшей последовательности через
одиночные пробелы или `No solution.`, если номер записать нельзя.

## Проверка

Принимается любая кратчайшая последовательность: чекер проверяет, что слова
есть в словаре, что они записывают номер и что более короткой
последовательности не существует.

## Примеры

### Пример 1

Ввод:

```
8733
3
use
e
tree
12
2
ab
cd
-1
```

Вывод:

```
tree
No solution.
```

### Пример 2

Ввод:

```
22
4
ac
ba
b
c
-1
```

Вывод:

```
ac
```

## Решение

Динамика по префиксам номера: `best[i]` — наименьшее число слов, записывающих
первые `i` цифр, `best[0] = 0`. Из каждой достижимой позиции `i` пробуем каждое
слово, запись которого совпадает с подстрокой, начинающейся в `i`, и
запоминаем последнее слово, чтобы восстановить ответ.

Перебор всех `n` слов в каждой позиции стоит `O(100 · n · 50)` на тест. Гораздо
быстрее положить словарь в хеш-таблицу «запись → слово»: слово не длиннее 50
букв, поэтому в каждой позиции достаточно поискать подстроки длиной от 1 до 50.
Это `O(100 · 50)` поисков на тест плюс `O(суммарная длина слов)` на построение
таблицы — быстро на любом языке.

Подводные камни:

- у нескольких слов может быть одинаковая запись: достаточно хранить любое;
- слово можно использовать много раз;
- при отсутствии ответа вывод должен быть ровно `No solution.`.

## Особенности языков

- **C++**: `std::unordered_map<std::string, int>`; чтение через `cin` после
  `sync_with_stdio(false)`.
- **Go**: `map[string]int`, а `phone[i:i+l]` — дешёвая подстрока.
- **Python**: таблица — `dict`, записи слов получаются через `str.translate`;
  версия с поиском в таблице быстрая, а сравнение каждого слова в каждой
  позиции было бы слишком медленным.
- **Java**: `HashMap<String, Integer>` с `putIfAbsent`; ввод через
  `BufferedReader` и `StringTokenizer`.
- **Rust**: `HashMap<Vec<u8>, usize>`, поиск по срезам байтов номера.
