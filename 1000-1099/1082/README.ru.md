# 1082. Входные данные, на которых быстрая сортировка делает заданное число шагов

[Timus 1082](https://acm.timus.ru/problem.aspx?space=1&num=1082) · сложность 126 · constructive

Автор оригинальной задачи — Никита Шамгунов; третье командное соревнование школьников Свердловской области по программированию, 4 марта 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Данная программа читает `N` целых чисел (`1 ≤ N ≤ 1000`) и сортирует их
быстрой сортировкой: опорный элемент — первый элемент отрезка, а два
индекса движутся навстречу друг другу, `j` справа, пока элементы больше
опорного, и `i` слева, пока они меньше, с обменом, пока индексы не
пересеклись (разбиение Хоара). Программа считает каждый отдельный сдвиг
`i` и `j` во всех вызовах и выигрывает, если сумма равна ровно
`(N² + 3N − 4)/2`. Выведите `N` целых чисел, по модулю не больше `10^9`,
на которых она выигрывает.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

`N` целых чисел через пробел.

## Проверка

Подходит любой подходящий набор чисел. Проверяющая программа выполняет то же
разбиение на выводе и сравнивает счётчик с `(N² + 3N − 4)/2`.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
1 2 3
```

## Решение

Выводим упорядоченные числа `1, 2, …, N`. На упорядоченном отрезке длины
`k` с опорным элементом на левом конце `j` проходит от правого конца до
самого опорного элемента — `k` сдвигов, — а `i` делает один сдвиг на
опорный элемент; индексы сразу встречаются, и отрезок делится на один
опорный элемент и остальные `k − 1` элементов, по-прежнему
упорядоченные. Счётчик равен `k + 1` для каждого `k` от `N` до 2:

`(N + 1) + N + … + 3 = (N² + 3N − 4)/2`,

а это ровно цель. `O(N)`.

Подводные камни:

- другие порядки дают другой счёт: для `3 2 1` программа насчитывает 8
  сдвигов вместо 7, потому что обмен меняет то, как делятся отрезки;
- при `N = 1` программа ничего не считает, и цель тоже равна 0.

Проверяющая программа моделирует разбиение с явным стеком и сравнивает
счётчик.

## Особенности языков

- Все языки выводят `1 … N` через пробел.
