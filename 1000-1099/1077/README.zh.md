# 1077. 每条都拥有一条专属道路的最多环游路线

[Timus 1077](https://acm.timus.ru/problem.aspx?space=1&num=1077) · 难度 395 · bfs, graphs

原题作者 Nguyen Xuan My（由 Dinh Quang Hiep 和 Tran Nam Trung 改编），出自越南国家大学河内自然科学大学数学与信息学系的第三场比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N` 个城市（`1 ≤ N ≤ 200`）由 `M` 条双向道路连接，两个城市之间最多一条道路。一条环游路线沿环经过 `K > 2` 个
不同的城市。要组织尽可能多的环游路线，使每条路线都有一条其他路线都不使用的道路。输出路线数 `T` 以及各条路线。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N` 和 `M`，然后 `M` 行，每行是一条道路的两个城市。

## 输出

`T`，然后 `T` 行，每行是 `K` 以及按顺序排列的路线上的 `K` 个城市。

## 评测方式

接受任何合法的路线集合。检查程序验证 `T` 是可能的最大值，每条路线都是由道路连接的、超过两个不同城市组成的环，
并且每条路线都有一条其他路线都不使用的道路。

## 样例

### 样例 1

输入：

```
5 7
1 2
1 3
1 4
2 4
2 3
3 4
5 4
```

输出：

```
3
3 2 1 4
3 2 1 3
3 3 1 4
```

## 题解

把路线看作 `GF(2)` 上的向量，每条道路对应一个坐标。拥有某条道路的路线是该坐标上唯一为 1 的路线，所以其他路线
的任何组合都得不到它：这些路线线性无关。环都在图的环空间中，对 `C` 个连通分量，环空间的维数是 `M − N + C`，
所以 `T ≤ M − N + C`。

生成森林的基本环可以达到这个上界。每条不在森林中的道路，加上森林中连接它两端的路径，构成一个环，而这条道路
不属于任何其他这样的环。这样的道路恰好有 `M − (N − C)` 条。用广度优先搜索建立的森林能让路径较短。要写出一个
环，先把较深的一端提升到另一端的深度，再同时提升两端直到相遇。`O(N + M + 输出总量)`。

注意事项：

- 图可能不连通，也可能有孤立的城市，所以要从每个尚未到达的城市出发扩展森林；
- 树或没有道路的图给出 `T = 0`，后面不再有任何行；
- 200 个城市之间全部 19 900 条道路时有 19 701 条路线，所以输出先拼在一个缓冲区里。

检查程序用并查集计算 `M − N + C`，并独立于解法检查每条路线。

## 各语言说明

- Python 一次读入所有数，用切片配成对：`zip(rest[0::2], rest[1::2])` 给出各条道路。
- Java 用 `StreamTokenizer` 读取，并把输出收集到 `StringBuilder` 中。
