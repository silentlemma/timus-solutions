# 1077. Наибольшее число туров, у каждого из которых есть своя дорога

[Timus 1077](https://acm.timus.ru/problem.aspx?space=1&num=1077) · сложность 395 · bfs, graphs

Автор оригинальной задачи — Nguyen Xuan My (адаптация Dinh Quang Hiep и Tran Nam Trung); третье соревнование факультета математики и информатики Колледжа естественных наук Вьетнамского национального университета, Ханой.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N` городов (`1 ≤ N ≤ 200`) соединены `M` двусторонними дорогами, между
двумя городами не больше одной дороги. Тур проходит по циклу через
`K > 2` различных городов. Составьте как можно больше туров так, чтобы у
каждого тура была дорога, которой не пользуется ни один другой тур.
Выведите их число `T` и сами туры.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `M`, затем `M` строк с двумя городами дороги.

## Выходные данные

`T`, затем `T` строк, в каждой `K` и `K` городов тура по порядку.

## Проверка

Подходит любой допустимый набор туров. Проверяющая программа убеждается,
что `T` наибольшее возможное, что каждый тур — цикл из более чем двух
различных городов, соединённых дорогами, и что у каждого тура есть
дорога, которой не пользуется ни один другой тур.

## Примеры

### Пример 1

Ввод:

```
5 7
1 2
1 3
1 4
2 4
2 3
3 4
5 4
```

Вывод:

```
3
3 2 1 4
3 2 1 3
3 3 1 4
```

## Решение

Будем считать туры векторами над `GF(2)` с координатой для каждой дороги.
Тур, владеющий дорогой, — единственный с единицей в этой координате,
поэтому никакая комбинация остальных его не даёт: туры линейно
независимы. Циклы лежат в пространстве циклов графа, размерность
которого `M − N + C` для `C` компонент связности, поэтому
`T ≤ M − N + C`.

Эта граница достигается фундаментальными циклами остовного леса. Каждая
дорога вне леса вместе с путём по лесу между её концами образует цикл, и
эта дорога не входит ни в один другой такой цикл. Таких дорог ровно
`M − (N − C)`. Лес поиска в ширину делает пути короткими. Чтобы выписать
цикл, поднимаем более глубокий конец до глубины другого, затем поднимаем
оба, пока они не встретятся. `O(N + M + размер вывода)`.

Подводные камни:

- граф может быть несвязным или иметь изолированные города, поэтому лес
  растится от каждого ещё не достигнутого города;
- дерево или граф без дорог дают `T = 0` и больше ни одной строки;
- при всех 19 900 дорогах между 200 городами получается 19 701 тур, поэтому
  вывод собирается в одном буфере.

Проверяющая программа вычисляет `M − N + C` через систему непересекающихся
множеств и проверяет каждый тур независимо от решений.

## Особенности языков

- Python читает все числа сразу и разбивает их на пары срезами:
  `zip(rest[0::2], rest[1::2])` даёт дороги.
- Java читает через `StreamTokenizer` и собирает вывод в
  `StringBuilder`.
