# 1043. Целочисленный ограничивающий прямоугольник дуги окружности

[Timus 1043](https://acm.timus.ru/problem.aspx?space=1&num=1043) · сложность 1626 · geometry

Автор оригинальной задачи — Александр Мироненко; Пятый командный чемпионат УрГУ по программированию, октябрь 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дуга окружности задана двумя концами `A`, `B` и ещё одной точкой дуги `C`;
у всех трёх точек целые координаты, по модулю не больше 1000, и они не
лежат на одной прямой. Центр окружности и вся дуга лежат в квадрате
`[-1000, 1000]^2`. Найдите наименьшую площадь прямоугольника со сторонами,
параллельными осям, и целыми вершинами, накрывающего дугу.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Три строки с координатами `A`, `B` и `C`.

## Выходные данные

Наименьшая площадь.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
476 612
487 615
478 616
```

Вывод:

```
66
```

### Пример 2

Ввод:

```
-5 0
5 0
0 5
```

Вывод:

```
50
```

## Решение

Ограничивающий прямоугольник дуги натянут на её концы и на те из четырёх
крайних точек окружности (`центр ± r` по каждой оси), которые лежат на
дуге. Затем нижние границы округляются вниз, а верхние — вверх.

Точка окружности лежит на дуге ровно тогда, когда это `A`, `B` или она
находится по ту же сторону прямой `AB`, что и `C`. Так что проверка —
знак векторного произведения.

Вся трудность в точности. Крайняя точка вроде `центр_x + r` может быть
ровно целой или промахиваться мимо целого на `10^-8`, и `ceil` в плавающей
точке легко даёт неверный ответ. Решения работают точно, в целых числах:

- центр равен `(ux / d, uy / d)` с целыми `ux`, `uy`, `d > 0` (правило
  Крамера), а `r · d = sqrt(rho2)` с целым `rho2`;
- `ceil(центр_x + r)` — наименьшее целое `k` с `k·d − ux ≥ 0` и
  `(k·d − ux)^2 ≥ rho2`; оценка в плавающей точке даёт старт, а точные
  сравнения сдвигают его на шаг-другой; `floor` симметричен;
- сторона крайней точки, умноженная на `d`, имеет вид
  `alpha − gamma · sqrt(rho2)` с целыми `alpha`, `gamma`, и её знак
  находится сравнением `alpha^2` с `gamma^2 · rho2` (после проверки знаков
  `alpha` и `gamma`).

Числа доходят примерно до `10^28`, нужны 128-битные целые. `O(1)`.

Подводные камни:

- крайняя точка ровно на линии сетки не должна отодвигать границу на
  единицу дальше, а точка чуть за линией — должна;
- крайняя точка, совпадающая с концом дуги, даёт сторону 0: она уже
  учтена как конец;
- центр может быть в полуцелой точке, так что целые крайние точки не
  требуют целого центра (тесты 13 и 14).
