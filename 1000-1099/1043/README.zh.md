# 1043. 圆弧的整点外接矩形

[Timus 1043](https://acm.timus.ru/problem.aspx?space=1&num=1043) · 难度 1626 · geometry

原题作者 Alexander Mironenko，出自 2000 年 10 月第五届乌拉尔国立大学团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一段圆弧由两个端点 `A`、`B` 和弧上另一点 `C` 给出；三点坐标都是绝对值不超过 1000 的整数，且不共线。圆心和
整段圆弧都在正方形 `[-1000, 1000]^2` 内。求覆盖这段圆弧、边与坐标轴平行且顶点为整点的矩形的最小面积。

时间限制：1 秒。内存限制：64 MB。

## 输入

三行，分别是 `A`、`B`、`C` 的坐标。

## 输出

最小面积。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
476 612
487 615
478 616
```

输出：

```
66
```

### 样例 2

输入：

```
-5 0
5 0
0 5
```

输出：

```
50
```

## 题解

圆弧的外接框由两个端点以及圆的四个极点（沿每个坐标轴的 `圆心 ± r`）中位于弧上的那些点张成。然后把下边界向下
取整，上边界向上取整。

圆上一点在弧上，当且仅当它是 `A`、`B`，或者与 `C` 位于直线 `AB` 的同一侧。所以判断就是看叉积的符号。

难点在于精度。像 `圆心_x + r` 这样的极值可能恰好是整数，也可能与整数只差 `10^-8`，这时浮点数的 `ceil` 很容易
出错。解法全部用整数精确计算：

- 圆心为 `(ux / d, uy / d)`，其中 `ux`、`uy`、`d > 0` 都是整数（克拉默法则），且 `r · d = sqrt(rho2)`，
  `rho2` 为整数；
- `ceil(圆心_x + r)` 是满足 `k·d − ux ≥ 0` 且 `(k·d − ux)^2 ≥ rho2` 的最小整数 `k`；用浮点估计作为起点，
  再用精确比较移动一两步；`floor` 对称处理；
- 极点所在的一侧乘以 `d` 形如 `alpha − gamma · sqrt(rho2)`，`alpha`、`gamma` 为整数；先看 `alpha` 和
  `gamma` 的符号，再比较 `alpha^2` 与 `gamma^2 · rho2`，即可得到它的符号。

数值可达约 `10^28`，需要 128 位整数。`O(1)`。

注意事项：

- 恰好落在网格线上的极点不应让边界再外移一格，而稍微越过网格线的必须外移；
- 与弧端点重合的极点所在侧为 0：它已经作为端点计入；
- 圆心可能在半整点上，所以极点为整数并不要求圆心为整点（测试 13 和 14）。
