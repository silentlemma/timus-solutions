# 1007. Исправление одной ошибки в кодовых словах с контрольной суммой

[Timus 1007](https://acm.timus.ru/problem.aspx?space=1&num=1007) · сложность 406 · math

Оригинальная задача — чемпионат Уральского государственного университета 1997 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждое отправленное слово — строка из `N` символов `0`/`1` (`4 ≤ N ≤ 1000`),
**вес** которой — сумма позиций единиц, считая с 1, — делится на `N + 1`
(вес 0 тоже подходит). По дороге с каждым словом происходит не более одного
из изменений:

- один `0` заменяется на `1`;
- один символ удаляется;
- один символ (`0` или `1`) вставляется в любое место.

По принятым словам выведите отправленные. Отправленное слово всегда
определяется однозначно.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем не более 2001 принятого слова, по одному в строке. Во входе могут
быть лишние пробелы и пустые строки.

## Выходные данные

Отправленные слова в порядке входа, по одному в строке.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
5
00000
10101
1011
111000
```

Вывод:

```
00000
10001
11011
11100
```

### Пример 2

Ввод:

```
6   

001100  
   10101


0100110 
110111

```

Вывод:

```
001100
101101
010010
110011
```

## Решение

Пусть `m = N + 1`, `w` — вес принятого слова, `L` — его длина.

- `L = N`: либо слово не изменилось (`w ≡ 0`), либо `0` на позиции `p` стал
  `1`, что прибавило ровно `p`; тогда `p = w mod m`, и символ на позиции `p`
  возвращается в `0`.
- `L = N - 1` (удаление): вставка цифры `d` на позицию `i` добавляет `d·i` и
  по единице за каждую `1` правее, потому что они сдвигаются на позицию
  дальше. Перебираем `i = L+1, L, ..., 1`, поддерживая число единиц справа, и
  берём первые `i` и `d`, для которых `w + ones_right + d·i ≡ 0 (mod m)`.
- `L = N + 1` (вставка): удаление символа `d` на позиции `i` вычитает `d·i` и
  по единице за каждую `1` правее. Тот же проход справа налево находит `i` с
  `w - ones_right - d·i ≡ 0 (mod m)`.

Это коды Варшамова–Тененгольца, исправляющие одно удаление или вставку (и
здесь — одну замену нуля единицей): разные отправленные слова не могут дать одно и
то же принятое, поэтому любая позиция, делающая вес правильным, даёт
отправленное слово. Каждое слово обрабатывается за `O(N)`, весь вход — за
`O(суммарной длины)`.

Подводные камни:

- слова разделены произвольными пробельными символами, читайте токены, а не
  строки;
- при удалении пропасть мог последний символ: позицию после конца тоже нужно
  проверить;
- перебор, который заново строит и взвешивает каждое слово-кандидат, — это
  `O(N^2)` на слово, до `4·10^9` шагов всего.

## Оптимизированные решения

Версии C++, Go и Rust переиспользуют один буфер для очередного слова и исправляют слово на месте. Остаток контрольной суммы по модулю N + 1 вычисляется один раз. При просмотре позиций справа налево переход через единицу меняет скорректированный остаток на единицу с переходом через границу модуля. Вместо повторного деления достаточно сравнения и прибавления или вычитания единицы. После выбора исправления сдвигаем хвост не более одного раза. Время линейно по длине входа, память O(N).

Принятые базовые реализации [1007_math.java](1007_math.java), [1007_math.py](1007_math.py) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
