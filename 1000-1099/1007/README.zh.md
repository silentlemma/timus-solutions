# 1007. 纠正带校验和码字中的一个错误

[Timus 1007](https://acm.timus.ru/problem.aspx?space=1&num=1007) · 难度 404 · math

原题出自 1997 年乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

每个发送的词是由 `N` 个字符 `0`/`1` 组成的串（`4 ≤ N ≤ 1000`），它的 **权重**——所有 `1` 的位置
（从 1 开始计数）之和——能被 `N + 1` 整除（权重为 0 也算）。传输途中每个词至多发生以下一种变化：

- 某一个 `0` 被替换成 `1`；
- 删除一个字符；
- 在任意位置插入一个字符（`0` 或 `1`）。

给出接收到的词，输出发送的词。发送的词总是唯一确定的。

时间限制：2 秒。内存限制：64 MB。

## 输入

先是 `N`，然后是至多 2001 个接收到的词，每行一个。输入中还可能有多余的空格和空行。

## 输出

按输入顺序输出发送的词，每行一个。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
5
00000
10101
1011
111000
```

输出：

```
00000
10001
11011
11100
```

### 样例 2

输入：

```
6   

001100  
   10101


0100110 
110111

```

输出：

```
001100
101101
010010
110011
```

## 题解

设 `m = N + 1`，`w` 为接收词的权重，`L` 为其长度。

- `L = N`：要么词没有变化（`w ≡ 0`），要么位置 `p` 上的 `0` 变成了 `1`，使权重恰好增加 `p`；
  此时 `p = w mod m`，把位置 `p` 的字符改回 `0`。
- `L = N - 1`（删除）：在位置 `i` 插入数字 `d` 会增加 `d·i`，并且其右侧每个 `1` 都后移一位、各加 1。
  依次尝试 `i = L+1, L, ..., 1`，同时维护右侧 `1` 的个数，取第一个满足
  `w + ones_right + d·i ≡ 0 (mod m)` 的 `i` 和 `d`。
- `L = N + 1`（插入）：删除位置 `i` 上的字符 `d` 会减去 `d·i`，并且右侧每个 `1` 各减 1。同样从右向左
  扫描，找到满足 `w - ones_right - d·i ≡ 0 (mod m)` 的 `i`。

这就是 Varshamov–Tenengolts 码，它能纠正一次删除或插入（在本题中还能纠正一个被置 1 的零）：不同的
发送词不可能变成同一个接收词，因此任何使权重正确的位置都给出发送的词。每个词 `O(N)`，整个输入
`O(总长度)`。

注意事项：

- 词之间由任意空白字符分隔，应按记号读取，而不是按行读取；
- 删除时丢失的可能是最后一个字符：末尾之后的位置也要尝试；
- 对每个候选词重新构造并计算权重的暴力做法每个词需要 `O(N^2)`，总计可达 `4·10^9` 步。

## 各语言说明

各语言都使用同样的线性扫描。Python 用字符串切片构造答案；每个词只需两次 `O(N)` 扫描，CPython 也足够快。
