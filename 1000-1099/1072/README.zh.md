# 1072. 经由 IP 子网的两台计算机之间的最短路由

[Timus 1072](https://acm.timus.ru/problem.aspx?space=1&num=1072) · 难度 502 · bfs, graphs

原题作者 Evgeny Kobzev，出自 2001 年 2 月 Ural State University Personal Contest Online（Students Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N` 台计算机（`2 ≤ N ≤ 90`）每台最多有 5 个网络接口；一个接口是一个 IP 地址和一个子网掩码（先是若干个 1，
后面全是 0）。当 `IP1 AND mask1` 等于 `IP2 AND mask2` 时，两个接口在同一子网中。共享子网的计算机之间直接传送
数据包；从一个子网到另一个子网只能经过在两个子网中都有接口的计算机。求两台给定计算机之间经过计算机数最少的
路径。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`；然后对每台计算机给出接口数 `K` 和 `K` 行点分形式的 IP 地址与掩码；最后是两台计算机的编号。

## 输出

`Yes` 以及按顺序排列的路径上的计算机；若没有路径则输出 `No`。

## 评测方式

接受任何一条最短路径。检查程序验证路径从第一台计算机通往第二台，路径上每两台相邻计算机共享一个子网，并且
计算机数目尽可能少。

## 题解

把每个接口化为数 `IP AND mask`。如果两台计算机的接口中有相等的数，就把它们相连；相连计算机之间的一跳正好是
一次直接传送，而路径中间的计算机在它两侧的子网中都有接口。所以问题就是这个计算机图上的最短路，从第一台计算机
出发的广度优先搜索就能找到它。从第二台计算机沿记录的前驱往回走，就得到路径。`O(N^2 · K^2)`。

注意事项：

- 子网判断使用每个接口自己的掩码：`10.0.0.77/255.0.0.0` 和 `10.0.0.5/255.255.255.0` 在同一子网中，因为
  两者都得到 `10.0.0.0`；而 `10.1.0.1/255.0.0.0` 和 `10.1.0.2/255.255.0.0` 不在同一子网中，尽管每个地址都
  落在对方的范围里；
- 掩码 `0.0.0.0` 和 `255.255.255.255` 都是允许的，不需要特殊处理；
- 地址是 32 位无符号数；只要只比较是否相等，有符号类型也可以。

路径长度与在同一张图上运行的 Floyd–Warshall 算法做了核对；那张图是另外构建的，并检查了掩码是“先 1 后 0”的
形式。

## 各语言说明

- C++ 用 `scanf("%u")` 和 `".%u"` 读取地址的四个部分；其他语言在点处拆分记号。
- Java 把地址存放在 `int` 中，较大的地址会溢出成负数，但这不影响 `AND` 和相等比较。
- Python 把一台计算机的子网存放在集合中，并用 `isdisjoint` 判断。
