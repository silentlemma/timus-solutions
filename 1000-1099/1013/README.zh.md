# 1013. 统计没有两个相邻零的 K 进制数（对 M 取模）

[Timus 1013](https://acm.timus.ru/problem.aspx?space=1&num=1013) · 难度 198 · matrix

## 任务

统计 `K` 进制下的 `N` 位数（首位不为零）中，数字里没有两个连续零的个数，对 `M` 取模。
`2 ≤ N, K, M ≤ 10^18`。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N`、`K` 和 `M`，各占一行。

## 输出

个数对 `M` 取模的结果。

## 评测方式

精确比较整数词元。新源码各有完整目标环境测试及自身Accepted；保留的已发布基础使用其自身Accepted，不借用旧存档测量。

## 解法
五份简单代码保留两状态矩阵算法。首位非零后
`(zero,other)=(0,K−1)`。添加一位得到 `zero'=other`、
`other'=(K−1)(zero+other)`：零只能接在非零后，而任一合法前缀都可接
`K−1` 个非零数字。因此令 `c=(K−1) mod M`，二进制计算
`A=[[0,1],[c,c]]` 的 `N−1` 次幂，作用于 `(0,c)`，最后两状态之和取模。
不使用模除法，复合模数也成立。

指数至多 60 位，故为 `O(log N)` 次矩阵步骤、常数个余数。
C++/Rust 用 128 位乘积，两个乘积之和小于 `2M²≤2·10³⁶<2¹²¹`。
Go 用 `bits.Mul64` 得高低字，再用 `bits.Div64` 求余；高字小于 `M`，
符合除法前提。Java/Python 使用大整数，运算成本依赖 `log M`；常数个
余数并非恒定比特数，输入及指数表示的存储也须另计。

仅简化 Rust 输入：从迭代器依次取三个 `u64`，去掉多余向量与索引。
矩阵计算和输出保持一致。此修改有独立精确源码 Accepted，采用新测量值，
不称为达到 30% 的优化。其余四份基础源码逐字节保留；旧 Rust 字节也有备份。

## 优化解法

保留五种教学矩阵算法，包括已接受的Rust输入简化。令c=(K-1)mod M，以aX+b表示模X²-cX-c的多项式。平方得a'=c*a²+2ab、b'=c*a²+b²，乘X得a'=ca+b、b'=ca。从1开始按N的高位到低位扫描得到X^N，答案a*c+b mod M，恰为首位非零的两状态递推。无模除法，合数M及公因子安全。Rust用128位乘积，未约简和<3M²<2^122。Python用大整数及整数位掩码，不构造二进制字符串。O(log N)模步骤、常量个O(log M)位余数。Rust有界C ABI I/O避免堆/启动开销。比较基准为当前已接受200 KB矩阵，不是旧220 KB测量。
