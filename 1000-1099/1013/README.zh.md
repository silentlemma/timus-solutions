# 1013. 统计没有两个相邻零的 K 进制数（对 M 取模）

[Timus 1013](https://acm.timus.ru/problem.aspx?space=1&num=1013) · 难度 196 · matrix

原题是[第 1009 题](../1009/README.zh.md)和[第 1012 题](../1012/README.zh.md)最难的版本。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

统计 `K` 进制下的 `N` 位数（首位不为零）中，数字里没有两个连续零的个数，对 `M` 取模。
`2 ≤ N, K, M ≤ 10^18`。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N`、`K` 和 `M`，各占一行。

## 输出

个数对 `M` 取模的结果。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
5
2
1000
```

输出：

```
8
```

### 样例 2

输入：

```
3
10
7
```

输出：

```
2
```

## 题解

[第 1009 题](../1009/README.zh.md)的递推按最后一位统计合法前缀：`zero' = other`，
`other' = (zero + other) · (K - 1)`，首位之后 `(zero, other) = (0, K - 1)`。这是这一对数的线性映射，
因此一步就是乘以矩阵

```text
A = | 0      1     |
    | K - 1  K - 1 |
```

`N` 位之后这一对数等于 `A^(N-1) · (0, K - 1)`。`N` 可达 `10^18`，不能一步一步算，但 `A^(N-1)` 可以用
**快速幂** 计算：对 `N - 1` 的每个为 1 的二进制位把当前矩阵乘进结果，并把矩阵平方，全部对 `M` 取模。
大约 60 次 2×2 矩阵平方，`O(log N)`。

答案为 `(A^(N-1)[0][1] + A^(N-1)[1][1]) · (K - 1) mod M`。

注意事项：

- `K - 1` 和 `M` 可达 `10^18`，两个余数之积可达 `10^36`，超出 64 位：需用 128 位乘法（`__int128`、
  `u128`、`bits.Mul64`）或大整数；
- 先把 `K - 1` 对 `M` 取模：它可能比 `M` 大。

## 各语言说明

- **C++**（`unsigned __int128`）和 **Rust**（`u128`）用 128 位乘法。
- **Go** 用 `bits.Mul64` 和 `bits.Div64` 求 128 位乘积及其余数。
- **Java** 8 没有 128 位乘法，因此使用 `BigInteger`；**Python** 的整数没有上限。
