# 1013. Подсчёт K-ичных чисел без двух нулей подряд по модулю M

[Timus 1013](https://acm.timus.ru/problem.aspx?space=1&num=1013) · сложность 196 · matrix

Оригинальная задача — самая сложная версия [задач 1009](../1009/README.ru.md) и [1012](../1012/README.ru.md).

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Посчитайте по модулю `M` количество `N`-значных чисел в системе счисления с
основанием `K` (первая цифра не ноль), в записи которых нет двух нулей
подряд. `2 ≤ N, K, M ≤ 10^18`.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, `K` и `M`, каждое на своей строке.

## Выходные данные

Количество по модулю `M`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
5
2
1000
```

Вывод:

```
8
```

### Пример 2

Ввод:

```
3
10
7
```

Вывод:

```
2
```

## Решение

Рекуррентность [задачи 1009](../1009/README.ru.md) считает правильные
префиксы по последней цифре: `zero' = other`,
`other' = (zero + other) · (K - 1)`, начиная с `(zero, other) = (0, K - 1)`
после первой цифры. Это линейное отображение пары, так что один шаг —
умножение на матрицу

```text
A = | 0      1     |
    | K - 1  K - 1 |
```

и после `N` цифр пара равна `A^(N-1) · (0, K - 1)`. При `N` до `10^18` шаги
нельзя делать по одному, но `A^(N-1)` считается **бинарным возведением в
степень**: возводим матрицу в квадрат и домножаем на неё результат для
каждого единичного бита `N - 1`, всё по модулю `M`. Это около 60 возведений
в квадрат матрицы 2×2, `O(log N)`.

Ответ — `(A^(N-1)[0][1] + A^(N-1)[1][1]) · (K - 1) mod M`.

Подводные камни:

- `K - 1` и `M` до `10^18`, поэтому произведение двух остатков доходит до
  `10^36` и не помещается в 64 бита: умножайте в 128 битах (`__int128`,
  `u128`, `bits.Mul64`) или в длинных целых;
- сначала возьмите `K - 1` по модулю `M`: оно может быть больше `M`.

## Особенности языков

- **C++** (`unsigned __int128`) и **Rust** (`u128`) умножают в 128 битах.
- **Go** использует `bits.Mul64` и `bits.Div64` для 128-битного произведения
  и остатка.
- В **Java** 8 нет 128-битного умножения, поэтому там `BigInteger`; целые
  в **Python** не ограничены.
