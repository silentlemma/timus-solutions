# 1063. 组成多米诺链所需的最便宜的附加骨牌

[Timus 1063](https://acm.timus.ru/problem.aspx?space=1&num=1063) · 难度 2206 · dijkstra

原题出自 2000–2001 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一套 `N` 张多米诺骨牌（`2 ≤ N ≤ 100`），每张两端的点数为 1 到 6。添加一些骨牌（可以不加），使点数总和最小，
并使所有骨牌能排成一条链，相邻两端点数相同。输出总和、添加的骨牌数和这些骨牌；任何一种最便宜的方案都可接受。

时间限制：2 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行，每行一张骨牌的两个点数。

## 输出

最小总和（不需要添加时为 `0`），添加的骨牌数，然后是这些骨牌。

## 评测方式

接受任何一种最便宜的方案。检查程序验证总和等于可能的最小值、等于所列骨牌之和，并且所有骨牌合起来能排成链。

## 样例

### 样例 1

输入：

```
6
6 1
1 5
5 5
5 2
2 4
4 2
```

输出：

```
0
0
```

### 样例 2

输入：

```
5
1 5
6 1
5 5
2 4
2 4
```

输出：

```
6
2
1 2
1 2
```

## 题解

把点数 1…6 看成顶点，骨牌看成边（对子是自环）。用上所有骨牌的链就是欧拉路径，它存在当且仅当用到的顶点连通，
且奇度顶点不超过两个。添加骨牌 `(a, b)` 的代价是 `a + b`，它合并 `a` 和 `b` 所在的连通组，并翻转两个点数的
奇偶性。

所有要紧的信息都装得进一个小状态：六个点数的连通分组、用到的点数集合，以及奇度点数集合。解法从给定的骨牌出发，
在这些状态上运行 Dijkstra 算法；可用的走法是 15 张两端不同的骨牌（对子从来没有用），第一个允许成链的状态给出
答案，沿路径回溯得到添加的骨牌。状态至多 `203 · 64 · 64` 个，实际到达的要少得多。

搜索能找到简单规则会漏掉的绕行方案。两个分开的对子 `5 5` 和 `6 6` 用一张 `5 6` 连起来（总和 11）。若不能改变
奇偶性，经过点数 1 的两张骨牌 `1 5` 和 `1 6`（总和 13）比同一张骨牌用两次更便宜。

注意事项：

- 对子使度数加 2，不改变奇偶性；
- 没有出现在任何骨牌上的点数不需要连通；
- 最便宜的修补可能用到套中根本没有的点数（通常是 1）。

答案与对至多七张附加骨牌的所有组合的穷举做了核对。
