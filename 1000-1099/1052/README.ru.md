# 1052. Больше всего точек на одной прямой

[Timus 1052](https://acm.timus.ru/problem.aspx?space=1&num=1052) · сложность 238 · geometry

## Задача

Даны `N` различных точек (`3 ≤ N ≤ 200`) с целыми координатами от −2000 до
2000. Найдите наибольшее число из них, лежащих на одной прямой.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк с `x` и `y`.

## Выходные данные

Наибольшее число точек на одной прямой.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
6
7 122
8 139
9 156
10 173
11 190
-100 1
```

Вывод:

```
5
```

### Пример 2

Ввод:

```
3
0 0
1 0
0 1
```

Вывод:

```
2
```

## Решение

Зафиксируем точку `i` и посмотрим на направления к точкам после неё. Точки
`j`, `k` лежат на одной прямой с `i` ровно тогда, когда векторы `i → j` и
`i → k` параллельны. Приведём каждый вектор к каноническому виду: разделим
`(dx, dy)` на `gcd(|dx|, |dy|)` и сменим знак так, чтобы `dx > 0` или
`dx = 0` и `dy > 0`. Тогда параллельные векторы совпадают, и подсчёт
одинаковых направлений в словаре даёт самую большую прямую через `i`
(плюс сама `i`). Достаточно брать `i` первой точкой каждой прямой в
порядке ввода, поэтому считаются только последующие точки.
`O(N^2 log C)`.

Целые числа делают сравнение точным; с наклонами в плавающей точке
вертикальные прямые и почти равные наклоны требуют осторожности.

Подводные камни:

- вертикальные (`dx = 0`) и горизонтальные (`dy = 0`) прямые;
- противоположные векторы задают одну прямую: нормализуйте знак;
- любые две точки лежат на прямой, поэтому ответ не меньше 2.

Альтернатива — проверка `O(N^3)` каждой пары с каждой точкой через
векторное произведение, тоже достаточно быстрая при `N = 200`; тесты
проверены ею.

## Особенности языков

- **C++**, **Go**, **Python**, **Rust**: словарь с ключом — парой
  компонент.
- **Java**: пара упакована в один ключ `long` (`dx · 8192 + dy`, так как
  `|dy| ≤ 4000`).
