# 1052. 一条直线上最多的点

[Timus 1052](https://acm.timus.ru/problem.aspx?space=1&num=1052) · 难度 238 · geometry

原题作者 Stanislav Vasiliev，出自 2000 年 3 月 25 日乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 `N` 个互不相同的点（`3 ≤ N ≤ 200`），坐标为 −2000 到 2000 的整数。求最多有多少个点位于同一条直线上。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行，每行 `x` 和 `y`。

## 输出

一条直线上最多的点数。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
6
7 122
8 139
9 156
10 173
11 190
-100 1
```

输出：

```
5
```

### 样例 2

输入：

```
3
0 0
1 0
0 1
```

输出：

```
2
```

## 题解

固定点 `i`，看它到后面各点的方向。点 `j`、`k` 与 `i` 共线，当且仅当向量 `i → j` 与 `i → k` 平行。把每个向量
化为标准形式：把 `(dx, dy)` 除以 `gcd(|dx|, |dy|)`，再调整符号使 `dx > 0`，或 `dx = 0` 且 `dy > 0`。这样平行
的向量就变得相同，用映射统计相同方向的个数，就得到经过 `i` 的最长直线（再加上 `i` 本身）。只要把 `i` 取作
每条直线上按输入顺序的第一个点就够了，所以只统计它之后的点。`O(N^2 log C)`。

整数保证比较精确；若用浮点数表示斜率，竖直线和几乎相等的斜率都需要小心处理。

注意事项：

- 竖直线（`dx = 0`）和水平线（`dy = 0`）；
- 相反的向量表示同一条直线：要统一符号；
- 任意两点都共线，所以答案至少为 2。

另一种做法是用叉积对每一对点和每个点做 `O(N^3)` 的检查，在 `N = 200` 时也足够快；测试用它核对过。

## 各语言说明

- **C++**、**Go**、**Python**、**Rust**：以分量对为键的映射。
- **Java**：把分量对压成一个 `long` 键（`dx · 8192 + dy`，因为 `|dy| ≤ 4000`）。
