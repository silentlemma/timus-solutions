# 1019. 直线多次重涂后最长的白色区间

[Timus 1019](https://acm.timus.ru/problem.aspx?space=1&num=1019) · 难度 464 · sorting, dsu

原题出自 Ural State University Internal Contest '99 #2。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

数轴上的线段 `[0, 10^9]` 为白色。随后依次进行 `N` 次重涂（`1 ≤ N ≤ 5000`）：第 `i` 次把从 `a_i` 到 `b_i`
（`0 < a_i < b_i < 10^9`，整数）的线段涂成白色或黑色。求结果中最长的白色区间；长度相同时取最左边的。

时间限制：2 秒。内存限制：64 MB。

## 输入

先是 `N`，然后 `N` 行 `a b c`，其中 `c` 为 `w`（白）或 `b`（黑）。

## 输出

最长白色区间的两端 `x y`（`x < y`）。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
4
2 999999998 b
100 500 w
500 900 w
300 310 b
```

输出：

```
310 900
```

### 样例 2

输入：

```
1
1 999999999 w
```

输出：

```
0 1000000000
```

## 题解

**坐标离散化。** 只有点 `0`、`10^9` 以及所有 `a_i`、`b_i` 才重要：在这个有序点集中相邻两点之间颜色不变。
它们把直线切成至多 `2N + 1` 段 `[x_k, x_{k+1})`，对 `[a, b]` 的重涂恰好覆盖从 `a` 的下标到 `b` 的下标
（不含）的各段。

**直接涂色。** 依次把每次重涂作用到各段上：至多 `5000 · 10 001 = 5 · 10^7` 次简单赋值，编译型语言足够快。

**用并查集倒序涂色。** 一段的颜色等于最后一次覆盖它的重涂的颜色。从最后一次重涂往前处理，只给尚未上色的
段涂色；用带路径压缩的“下一个未上色段”指针数组（直线上的并查集）跳过已上色的段。每段至多被涂一次：排序后
`O((N + M) α)`，`M` 为段数。没有被任何重涂覆盖的段保持白色。

**答案。** 从左到右扫描各段，把相邻的白段连成一串；串 `[x_i, x_j)` 的长度为 `x_j - x_i`。只在长度严格更大
时更新最优串，这样相同长度中保留最左的。白串总是存在：段 `[0, min a)` 从不被重涂。

注意事项：

- 相接的白色线段（如 `[10, 20]` 与 `[20, 30]`）构成同一个区间；
- 白色区间内部的黑色线段会把它切开；
- 端点 `0` 和 `10^9` 属于这条直线，即使没有重涂提到它们。

## 各语言说明

- **C++**、**Go**、**Java**、**Rust**：离散化后直接涂色。
- **C++** 和 **Python** 另有用并查集倒序涂色的解法，使 Python 版本保持线性。
