# 1019. Самый длинный белый интервал после перекрашиваний прямой

[Timus 1019](https://acm.timus.ru/problem.aspx?space=1&num=1019) · сложность 464 · sorting, dsu

Оригинальная задача — Ural State University Internal Contest '99 #2.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Отрезок `[0, 10^9]` числовой прямой белый. Затем по порядку выполняются `N`
перекрашиваний (`1 ≤ N ≤ 5000`): `i`-е красит отрезок от `a_i` до `b_i`
(`0 < a_i < b_i < 10^9`, целые) в белый или чёрный цвет. Найдите самый
длинный белый интервал результата; среди интервалов одной длины возьмите
самый левый.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк `a b c`, где `c` — `w` (белый) или `b` (чёрный).

## Выходные данные

Концы `x y` (`x < y`) самого длинного белого интервала.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4
2 999999998 b
100 500 w
500 900 w
300 310 b
```

Вывод:

```
310 900
```

### Пример 2

Ввод:

```
1
1 999999999 w
```

Вывод:

```
0 1000000000
```

## Решение

**Сжатие координат.** Важны только точки `0`, `10^9` и все `a_i`, `b_i`:
между двумя соседними точками этого упорядоченного множества цвет не
меняется. Они режут прямую не более чем на `2N + 1` кусков
`[x_k, x_{k+1})`, и перекрашивание `[a, b]` покрывает ровно куски от индекса
`a` до индекса `b`, не включая последний.

**Покраска.** Применяем перекрашивания к кускам по порядку: не больше
`5000 · 10 001 = 5 · 10^7` простых присваиваний — нормально для
компилируемых языков.

**Покраска с конца с DSU.** Цвет куска — цвет последнего покрывшего его
перекрашивания. Идём по перекрашиваниям с последнего и красим только ещё
не покрашенные куски; массив указателей «следующий непокрашенный кусок» со
сжатием путей (DSU на прямой) перепрыгивает через покрашенные. Каждый кусок
красится не больше одного раза: `O((N + M) α)` после сортировки, где `M` —
число кусков. Куски, до которых не дошло ни одно перекрашивание, остаются
белыми.

**Ответ.** Проходим куски слева направо, объединяя соседние белые в серии;
серия `[x_i, x_j)` имеет длину `x_j - x_i`. Обновляем лучшую серию только
при строго большей длине — так из равных остаётся самая левая. Белая серия
есть всегда: кусок `[0, min a)` никогда не перекрашивается.

Подводные камни:

- соприкасающиеся белые отрезки, например `[10, 20]` и `[20, 30]`, образуют
  один интервал;
- чёрный отрезок внутри белого разрезает его;
- концы `0` и `10^9` принадлежат прямой, даже если ни одно перекрашивание
  их не упоминает.

## Особенности языков

- **C++**, **Go**, **Java**, **Rust**: сжатие и прямая покраска.
- **C++** и **Python** — ещё и покраска с конца с DSU, благодаря которой
  версия на Python линейна.
