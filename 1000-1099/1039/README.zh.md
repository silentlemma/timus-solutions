# 1039. 不含直接上司的宾客名单

[Timus 1039](https://acm.timus.ru/problem.aspx?space=1&num=1039) · 难度 386 · dp, trees

原题作者 Marat Bakirov，出自 2000 年 10 月第五届乌拉尔国立大学团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N` 名员工（`1 ≤ N ≤ 6000`）构成一棵树：除根以外每人都有一个直接上司。每名员工有一个 −128 到 127 的评分。
选出一组员工，使得没有人和自己的直接上司同时被邀请，并使评分总和最大。这组人可以为空。

时间限制：0.5 秒。内存限制：8 MB。

## 输入

`N`，然后 `N` 行依次是员工 `1..N` 的评分，接着是若干行 `L K`，表示 `K` 是 `L` 的直接上司，以一行 `0 0`
结束。

## 输出

最大的评分总和。

## 评测方式

按记号逐一比较输出，多余的空白字符不影响结果。

## 样例

### 样例 1

输入：

```
7
1
1
1
1
1
1
1
1 3
2 3
6 4
7 4
4 5
3 5
0 0
```

输出：

```
5
```

### 样例 2

输入：

```
4
3
-5
4
2
1 2
3 2
2 4
0 0
```

输出：

```
9
```

## 题解

经典的树形动态规划。对每名员工 `v`，在 `v` 的子树上计算两个值：

- `take[v]`——邀请 `v` 时的最佳总和：`rating[v]` 加上所有下属 `c` 的 `skip[c]`；
- `skip[v]`——不邀请 `v` 时的最佳总和：对所有下属求 `max(take[c], skip[c])` 之和。

答案是 `max(take[root], skip[root])`。负的评分不会被强制计入：`skip` 总是允许不邀请该员工，所以评分全为负
时答案是 `0`。

树可能是一条 6000 层的链，所以解法不使用递归：从根出发的广度优先顺序把每个上司排在下属之前，倒序遍历时每棵
子树都在其根之前完成，并把两个值累加到上司身上。`O(N)`。

注意事项：

- 深度可达 6000：递归的 DFS 可能栈溢出；
- 评分可能为负：可以一个人都不邀请（总和为 0）；
- 根没有直接给出：它是没有上司的那名员工。

## 各语言说明

- **C++**、**Go**、**Java**、**Rust**：子节点用两个数组（`first`、`next`）组成的链表保存，适合 8 MB 的限制。
- **Python**：子节点列表；顺序列表在遍历过程中不断增长，从而得到广度优先顺序。
