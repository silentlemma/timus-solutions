# 1039. Список гостей без непосредственных начальников

[Timus 1039](https://acm.timus.ru/problem.aspx?space=1&num=1039) · сложность 386 · dp, trees

Автор оригинальной задачи — Марат Бакиров; Пятый командный чемпионат УрГУ по программированию, октябрь 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N` сотрудников (`1 ≤ N ≤ 6000`) образуют дерево: у каждого, кроме корня,
есть один непосредственный начальник. У каждого сотрудника есть рейтинг от
−128 до 127. Выберите множество сотрудников, в котором никто не приглашён
вместе со своим непосредственным начальником, с наибольшим суммарным
рейтингом. Множество может быть пустым.

Ограничение времени: 0,5 секунды. Ограничение памяти: 8 МБ.

## Входные данные

`N`, затем `N` строк с рейтингами сотрудников `1..N`, затем строки `L K`,
означающие, что `K` — непосредственный начальник `L`, и в конце строка
`0 0`.

## Выходные данные

Наибольший суммарный рейтинг.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

Ввод:

```
7
1
1
1
1
1
1
1
1 3
2 3
6 4
7 4
4 5
3 5
0 0
```

Вывод:

```

```

### Пример 2

Ввод:

```
4
3
-5
4
2
1 2
3 2
2 4
0 0
```

Вывод:

```
9
```

## Решение

Классическая динамика на дереве. Для каждого сотрудника `v` считаем два
значения по поддереву `v`:

- `take[v]` — лучшая сумма, если `v` приглашён: `rating[v]` плюс
  `skip[c]` по всем подчинённым `c`;
- `skip[v]` — лучшая сумма, если `v` не приглашён: сумма
  `max(take[c], skip[c])` по подчинённым.

Ответ — `max(take[root], skip[root])`. Отрицательный рейтинг никогда не
навязывается сумме: `skip` всегда позволяет не звать сотрудника, поэтому
при всех отрицательных рейтингах ответ `0`.

Дерево может быть цепочкой из 6000 уровней, поэтому решения обходятся без
рекурсии: порядок обхода в ширину от корня ставит каждого начальника
раньше подчинённых, а проход по нему с конца завершает каждое поддерево
раньше его корня и добавляет два значения начальнику. `O(N)`.

Подводные камни:

- глубина доходит до 6000: рекурсивный DFS может переполнить стек;
- отрицательные рейтинги: можно не пригласить никого (сумма 0);
- корень явно не задан: это сотрудник без начальника.

## Особенности языков

- **C++**, **Go**, **Java**, **Rust**: дети хранятся связными списками в
  двух массивах (`first`, `next`), что удобно при ограничении 8 МБ.
- **Python**: списки детей; список порядка растёт во время прохода по
  нему, что и даёт порядок обхода в ширину.
