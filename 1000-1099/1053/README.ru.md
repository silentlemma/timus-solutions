# 1053. Распил заготовок, пока не останется одна

[Timus 1053](https://acm.timus.ru/problem.aspx?space=1&num=1053) · сложность 343 · number_theory

Оригинальная задача — Рыбинская государственная авиационная академия.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `N` заготовок (`1 ≤ N ≤ 1000`) с целыми длинами от 1 до `2^31 − 1`.
Пока заготовок больше одной, берём любые две: если они равны, одну
выбрасываем; иначе отпиливаем от длинной кусок длиной в короткую и
выбрасываем его. Выведите длину последней заготовки или `IMPOSSIBLE`, если
она зависит от выбора.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` длин, по одной в строке.

## Выходные данные

Длина последней заготовки.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
3
2
3
4
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
4
12
18
30
42
```

Вывод:

```
6
```

## Решение

Оба шага сохраняют наибольший общий делитель всех длин:
`gcd(a, b) = gcd(a − b, b)`, а выбрасывание одной из двух равных заготовок
не меняет множества делителей. Процесс заканчивается одной заготовкой, а
НОД одного числа — само число, поэтому последняя заготовка всегда равна
НОД исходных длин, как бы мы ни выбирали. `IMPOSSIBLE` не бывает ответом
никогда. `O(N log L)`.

Это вычитательная форма алгоритма Евклида, запущенная сразу на многих
числах.

Подводные камни:

- длины доходят до `2^31 − 1`: читайте их в 64-битные целые или хотя бы в
  беззнаковые 32-битные;
- одна заготовка сама по себе и есть ответ;
- моделировать распилы по одному слишком долго для длин вроде
  `2^31 − 1` и 1.

## Особенности языков

- Во всех языках длины сворачиваются алгоритмом Евклида.
