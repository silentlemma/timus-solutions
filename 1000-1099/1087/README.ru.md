# 1087. Игра с камнями, где взявший последний камень проигрывает

[Timus 1087](https://acm.timus.ru/problem.aspx?space=1&num=1087) · сложность 277 · games

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В кучке `n` камней (`1 ≤ n ≤ 10000`). Два игрока по очереди берут
`k₁`, `k₂`, … или `kₘ` камней (`1 ≤ m ≤ 50`, `1 ≤ kᵢ ≤ n`); ход всегда
возможен. Тот, кто берёт последний камень, проигрывает. Выведите 1, если
при правильной игре выигрывает первый игрок, иначе 2.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`n` и `m`, затем `k₁ … kₘ`.

## Выходные данные

1 или 2.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
17 3
1 3 4
```

Вывод:

```
2
```

## Решение

Пусть `win[x]` означает, выигрывает ли игрок, делающий ход при `x`
оставшихся камнях. При 0 камней соперник только что взял последний
камень, так что `win[0]` истинно. При `x ≥ 1` игрок выигрывает, если
какой-то допустимый ход `k ≤ x` ведёт в проигрышную позицию:
`win[x] = ИЛИ по k от не win[x − k]`. Заполняем таблицу от 1 до `n`.
`O(n·m)`.

Подводные камни:

- это правило поддавков: опустошить кучку — проигрыш, поэтому ход,
  забирающий все оставшиеся камни, никогда не выигрышный, а `win[0]`
  истинно, а не ложно, как в обычной игре;
- размеры ходов могут повторяться, а ход больше кучки недопустим.

Ответы сверены с поиском по игре с запоминанием, который ведёт явный стек
от `n` вниз.

## Особенности языков

- Python убирает повторяющиеся размеры ходов через `set` перед циклом.
