# 1087. 拿走最后一颗石子者输的取石子游戏

[Timus 1087](https://acm.timus.ru/problem.aspx?space=1&num=1087) · 难度 277 · games

原题作者 Anton Botov，出自 2001 年 3 月 4 日斯维尔德洛夫斯克州第三届中学生团体程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一堆石子有 `n` 颗（`1 ≤ n ≤ 10000`）。两名玩家轮流拿走 `k₁`、`k₂`、… 或 `kₘ` 颗（`1 ≤ m ≤ 50`，`1 ≤ kᵢ ≤ n`）；
总是可以走一步。拿走最后一颗石子的玩家输。若双方都采取最优策略时先手获胜，输出 1，否则输出 2。

时间限制：1 秒。内存限制：64 MB。

## 输入

`n` 和 `m`，然后是 `k₁ … kₘ`。

## 输出

1 或 2。

## 评测方式

按记号逐个比较输出；多余的空白不影响结果。

## 样例

### 样例 1

输入：

```
17 3
1 3 4
```

输出：

```
2
```

## 题解

设 `win[x]` 表示剩下 `x` 颗石子时轮到走的玩家是否获胜。剩 0 颗时，对手刚刚拿走了最后一颗，所以 `win[0]` 为真。
`x ≥ 1` 时，如果某个允许的走法 `k ≤ x` 能走到必败局面，当前玩家获胜：`win[x] = 对所有 k 取 (not win[x − k]) 的或`。
从 1 到 `n` 填表即可。`O(n·m)`。

注意事项：

- 这是反常规则：取空石堆的人输，所以拿走全部剩余石子的走法永远不是必胜的走法，`win[0]` 为真，而不像普通游戏
  中那样为假；
- 走法的大小可能重复，大于石堆的走法不允许。

答案与一个用显式栈从 `n` 向下展开的记忆化博弈搜索做了核对。

## 各语言说明

- Python 在循环前用 `set` 去掉重复的走法大小。
