# 1098. Последний символ после вычёркивания каждого 1999-го

[Timus 1098](https://acm.timus.ru/problem.aspx?space=1&num=1098) · сложность 555 · math

Автор оригинальной задачи — Станислав Васильев; пробный тур III командного студенческого чемпионата Урала по программированию, 1999 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Вопрос — это весь ввод без переводов строк (от одного до 30000 символов;
пробелы и знаки препинания считаются). Начиная с первого символа,
отсчитываем `N − 1` символов и удаляем `N`-й, переходя к началу при
достижении конца; затем считаем снова с символа после удалённого, пока не
останется один символ, при `N = 1999`. Выведите `Yes`, если это `?`,
`No`, если это пробел, и `No comments` иначе.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Вопрос, возможно, на нескольких строках.

## Выходные данные

`Yes`, `No` или `No comments`.

## Проверка

Вывод сравнивается построчно; внутри строки — по токенам.

## Примеры

### Пример 1

Ввод:

```
Does the jury of this programming contest use the
algorithm described in this problem to answer my questions?
```

Вывод:

```
Yes
```

### Пример 2

Ввод:

```
At least, will anybody READ my question?
```

Вывод:

```
No
```

### Пример 3

Ввод:

```
This is
UNFAIR!
```

Вывод:

```
No comments
```

## Решение

Это задача Иосифа Флавия. Пусть `J(m)` — позиция, считая от начала
отсчёта, последнего оставшегося из `m` символов. После первого удаления
остаётся `m − 1` символ, а отсчёт начинается на `N` мест дальше, так что
`J(m) = (J(m − 1) + N) mod m` при `J(1) = 0`. Один проход до длины вопроса
даёт позицию, и важен только символ в ней. `O(L)`.

Удаление символов по одному из строки стоило бы `O(L²)` при `L = 30000`:
в компилируемом языке это достаточно быстро, но рекуррентность обходится
вообще без этого.

Подводные камни:

- считается каждый символ, кроме переводов строк, в том числе пробелы в
  концах строк и между словами, поэтому ввод читается как сырые байты и
  отбрасываются только `\n` и `\r`;
- вопрос может состоять из одного символа, и тогда ответ определяет он.

Ответы сверены с прямой моделью, удаляющей каждый 1999-й символ из
списка.

## Особенности языков

- Rust сворачивает рекуррентность по `2..=L`.
- Java и C++ читают ввод побайтно, что сохраняет каждый пробел.
