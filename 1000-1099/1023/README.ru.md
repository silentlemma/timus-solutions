# 1023. Выбор предела хода, при котором выигрывает второй игрок

[Timus 1023](https://acm.timus.ru/problem.aspx?space=1&num=1023) · сложность 218 · games, number_theory

Оригинальная задача — второе командное соревнование школьников Свердловской области по программированию, 7 октября 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Два игрока по очереди берут от 1 до `L` пуговиц из кучки в `K` пуговиц;
выигрывает тот, кто взял последнюю. Первый игрок выбрал `K`
(`3 ≤ K ≤ 10^8`), теперь второй выбирает `L` при `2 ≤ L < K`. Найдите
наименьшее `L`, при котором второй игрок выигрывает при любой игре первого,
или выведите 0, если такого нет.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`K`.

## Выходные данные

Наименьшее выигрышное `L` или 0.

## Решение

При ходах `1..L` проигрышные позиции для того, кто ходит, — ровно
кратные `L + 1`, включая пустую кучку. Из положительного кратного любой
разрешённый ход ведёт в некратное. Из некратного можно взять остаток
от деления на `L + 1` и оставить кратное; ход допустим и не превышает
размер кучки. Индукция доказывает утверждение. Второй игрок гарантирует
победу ровно тогда, когда `(L + 1)` делит `K`.

Ищем наименьший делитель `d ≥ 3`, ответ — `L = d − 1`. Делитель `d = K`
всегда допустим, поэтому на корректном входе ответ не бывает нулевым.
Простые версии проверяют по порядку все целые `3..sqrt(K)`. Если делителей
нет, меньший парный множитель делителя выше корня может быть только 1
или 2. Значит, остаётся `d = K/2`, если это целое не меньше 3, иначе
`d = K`. В частности, при `K = 4` нужен `d = 4`, а не 2. Первый найденный
делитель минимален, что доказывает ответ. Время — `O(sqrt(K))`,
дополнительная память — `O(1)`. Все пять исходных Accepted-баз сохранены
побайтово.

## Оптимизированные решения

Сохранено доказательство игры через наименьший допустимый делитель: ответ d-1, где d>=3 — минимальный делитель K. Сначала проверяются3,4и5. Остальные кандидаты взаимно просты с30, поэтому шаги колеса(4,2,4,2,4,6,2,6) перебирают все оставшиеся возможные малые делители. Если до sqrt(K) ничего нет, остаётся K/2для чётного K либо само K. Python проверяет четыре последовательных кандидата на один обратный переход цикла, сохраняя порядок поиска и точные условия остановки, уменьшая расходы горячего цикла/JIT без импорта управляющего модуля. Java оставляет компактный перебор нечётных делителей. Время O(sqrt(K)), состояние постоянно;1003дополнительных проверки, включая большие простые и составные у границы, сверены с независимым прямым поиском делителя.
