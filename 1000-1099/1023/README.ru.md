# 1023. Выбор предела хода, при котором выигрывает второй игрок

[Timus 1023](https://acm.timus.ru/problem.aspx?space=1&num=1023) · сложность 217 · games, number_theory

Оригинальная задача — второе командное соревнование школьников Свердловской области по программированию, 7 октября 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Два игрока по очереди берут от 1 до `L` пуговиц из кучки в `K` пуговиц;
выигрывает тот, кто взял последнюю. Первый игрок выбрал `K`
(`3 ≤ K ≤ 10^8`), теперь второй выбирает `L` при `2 ≤ L < K`. Найдите
наименьшее `L`, при котором второй игрок выигрывает при любой игре первого,
или выведите 0, если такого нет.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`K`.

## Выходные данные

Наименьшее выигрышное `L` или 0.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
8
```

Вывод:

```
3
```

### Пример 2

Ввод:

```
35
```

Вывод:

```
4
```

## Решение

**Игра.** При ходах от 1 до `L` пуговиц позиции, в которых ходящий
проигрывает, — ровно кратные `L + 1`: из такой кучки любой ход оставляет
некратное число, а из некратного ход, забирающий `n mod (L + 1)` пуговиц,
оставляет кратное. Значит, второй игрок выигрывает ровно тогда, когда
`L + 1` делит `K`.

**Выбор L.** Нужно наименьшее `L ≥ 2` с `L + 1 | K`, то есть наименьший
делитель `d ≥ 3` числа `K`, и `L = d - 1`; условие `L < K` означает
`d ≤ K`. Так как `d = K` подходит всегда (`K ≥ 3`), ответ никогда не 0.

**Быстрый поиск d.** Пробуем `d = 3, 4, ...`, пока `d^2 ≤ K`. Если ни одно
не делит `K`, наименьший делитель больше `sqrt(K)` равен `K / j` для
наибольшего делителя `j ≤ sqrt(K)`, а делителей до `sqrt(K)` осталось только
1 и 2. Значит, `d = K / 2`, если `K` чётно и `K / 2 ≥ 3`, иначе `d = K`. Не
больше `sqrt(10^8) = 10^4` шагов.

Подводные камни:

- `K = 4`: делитель 2 мал, `K / 2 = 2` тоже, поэтому `d = 4`, `L = 3`;
- `K = 2p` для простого `p`: делитель `p` больше `sqrt(K)`, его нельзя
  потерять;
- перебор всех `L` до `K` — это `10^8` шагов: на C++ укладывается, на
  Python слишком медленно.
