# 1096. 双面路线牌的最少交换次数

[Timus 1096](https://acm.timus.ru/problem.aspx?space=1&num=1096) · 难度 709 · bfs, graphs

原题作者 Stanislav Vasiliev，出自 2001 年 3 月 USU Open Collegiate Programming Contest（Senior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`K` 辆公交车（`1 ≤ K ≤ 1000`）中的每一辆跑路线 `rᵢ`，车上的牌子正面写 `rᵢ`，背面写另一个数 `bᵢ`（数在 1 到
2000 之间）。一辆新车要跑路线 `T`，却领到了写着 `S1` 和 `S2` 的牌子。如果新司机的牌子任一面写着某辆车的路线，
那辆车的司机就愿意和他交换牌子。求最少的交换次数，使新司机最后拿到写有 `T` 的牌子，并给出依次交换的车；若做不到，
输出 `IMPOSSIBLE`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`K`，然后 `K` 行，每行 `rᵢ` 和 `bᵢ`，最后是 `T`、`S1` 和 `S2`。

## 输出

交换次数 `M` 以及依次的 `M` 个车号，或 `IMPOSSIBLE`。

## 评测方式

接受任何一个最短的序列。检查程序重放这些交换，并把次数与最小可能值比较。

## 样例

### 样例 1

输入：

```
4
8 5
5 4
7 4
1 5
4 1 8
```

输出：

```
2
1
2
```

## 题解

关键在于新司机手里是哪块牌子：最初那块，或者某辆车 `j` 的牌子。拿着写有 `x` 和 `y` 的牌子，可以与任何跑路线 `x`
或 `y` 的车交换，得到那辆车的牌子。在这些状态上做广度优先搜索即可求出最少交换次数；每辆车只会被到达一次，所以
按路线把车分组，某条路线第一次出现时就把整组用完。搜索在第一块写有 `T` 的牌子处停止，记录的前驱给出依次交换的车。
`O(K)`。

为什么交换后牌子的变化不影响这一点：交换后车 `j` 拿着新司机之前的牌子。再与 `j` 交换只会把那块旧牌子换回来，所以
最短序列不会这样做，而其他车都没有变化。

注意事项：

- 输出的是车号，不是路线号；
- 答案至少有一次交换，因为最初那块牌子的两面都没有 `T`；
- `S1` 可能等于 `S2`，并且很多车可能跑同一条路线。

检查程序逐层求出最少交换次数，并在牌子易手的情况下重放所列的交换。

## 各语言说明

- 各语言在用过一条路线的车组后都把它从映射中删除（`pop`、`erase`、`delete`、`remove`），使任何车都不会两次
  进入队列。
