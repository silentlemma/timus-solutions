# 1095. Перестановка цифр, дающая число, кратное 7

[Timus 1095](https://acm.timus.ru/problem.aspx?space=1&num=1095) · сложность 580 · number_theory

Автор оригинальной задачи — Дмитрий Филимоненков; USU Open Collegiate Programming Contest, март 2001 года, Senior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждое из `N` натуральных чисел (`1 ≤ N ≤ 10000`, до 20 цифр) содержит
каждую из цифр 1, 2, 3 и 4. Переставьте цифры каждого числа так, чтобы
результат делился на 7, или выведите 0, если это невозможно.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` чисел, по одному в строке.

## Выходные данные

Кратное 7 из цифр каждого числа, по одному в строке.

## Проверка

Подходит любая подходящая перестановка. Проверяющая программа
убеждается, что каждый ответ состоит ровно из цифр своего числа, не
начинается с 0 и делится на 7.

## Примеры

### Пример 1

Ввод:

```
2
1234
531234
```

Вывод:

```
3241
531342
```

## Решение

Вынем из числа по одной цифре 1, 2, 3 и 4. Запишем сначала остальные
ненулевые цифры в любом порядке, затем четыре ключевые цифры в некотором
порядке, затем все нули. Нули в конце умножают число на степень 10, что
не меняет делимости на 7, и число не может начаться с нуля. Для начала с
остатком `r` по модулю 7 число равно `r · 10⁴ + p` по модулю 7 для
порядка `p` ключевых цифр, а 24 порядка цифр 1, 2, 3, 4 дают все семь
остатков по модулю 7 (`1234 ≡ 2`, `1243 ≡ 4`, `1324 ≡ 1`, `2134 ≡ 6`,
`2143 ≡ 1`, `3124 ≡ 2`, `3241 ≡ 0`, `4123 ≡ 0`, `1342 ≡ 5`, …). Значит,
какой-то из них всегда подходит, и 0 никогда не бывает ответом.
`O(N · L)` для `L` цифр.

Подводные камни:

- 20-значное число не помещается в 64-битные целые, поэтому остаток
  считается по цифрам (Python просто использует длинные целые);
- нули в начале могли бы оказаться первыми, если начало пусто, поэтому
  все нули уходят в конец;
- вынимается только по одному экземпляру каждой ключевой цифры, остальные
  остаются в начале.

Проверяющая программа проверяет цифры и делимость каждого ответа с
помощью длинных целых.

## Особенности языков

- C++ перебирает порядки через `std::next_permutation`; Go, Java и Rust
  строят их рекурсивно; Python использует `itertools.permutations`.
