# 1075. Кратчайшая нить вокруг закреплённого шара

[Timus 1075](https://acm.timus.ru/problem.aspx?space=1&num=1075) · сложность 1982 · geometry

Автор оригинальной задачи — Александр Мироненко; Ural State University Personal Contest Online, февраль 2001 года, Students Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Точки `A`, `B` и `C` в пространстве имеют целые координаты, по модулю не
больше 1000. Твёрдый шар целого радиуса `R` с центром в `C` закреплён, и
обе точки `A` и `B` дальше `R` от `C`. Найдите длину кратчайшей нити от
`A` до `B`, не заходящей внутрь шара, округлённую до двух знаков.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Координаты `A`, `B` и `C`, по точке в строке, затем `R`.

## Выходные данные

Длина нити.

## Проверка

Числа сравниваются с абсолютной погрешностью 0.011: ответы печатаются с
двумя знаками, поэтому последняя цифра может отличаться на единицу.

## Примеры

### Пример 1

Ввод:

```
0 0 12
12 0 0
10 0 10
10
```

Вывод:

```
19.71
```

## Решение

Кратчайшая нить лежит в плоскости, проходящей через `A`, `B` и `C`, так
что это кратчайший путь вокруг круга радиуса `R` в этой плоскости. Пусть
`a = |CA|`, `b = |CB|`, а `φ` — угол `ACB`. Если смотреть из `C`, точка
касания из `A` отстоит от направления на `A` на `α = arccos(R/a)`, а точка
касания из `B` — от направления на `B` на `β = arccos(R/b)`.

- Если `φ ≤ α + β`, отрезок `AB` не заходит в шар, и ответ — `|AB|`.
- Иначе нить идёт по касательной из `A`, по дуге с углом `φ − α − β` и
  по касательной к `B`: `√(a² − R²) + √(b² − R²) + R·(φ − α − β)`.

`O(1)`.

Подводные камни:

- `φ` через `arccos` нормированного скалярного произведения теряет
  точность около 0 и `π`; `atan2(|CA × CB|, CA · CB)` точен везде, а
  скалярное и векторное произведения — точные целые числа;
- когда `A`, `C` и `B` лежат на одной прямой и `C` посередине, плоскость
  не единственна, но `φ = π`, и формула по-прежнему верна;
- `A` может совпадать с `B`; тогда `φ = 0` и ответ 0.

Ответы проверены другим способом: плоскость раскладывается на чертёж,
отрезок проверяется на пересечение с кругом по расстоянию от `C`, а иначе
сравниваются все пути «касательная — дуга — касательная» по обеим точкам
касания каждого конца и обоим направлениям дуги.

## Особенности языков

- C++ хранит векторы в `long long`, чтобы произведения были точными до
  извлечения корней.
- Python считает длины через `math.hypot` с тремя аргументами.
