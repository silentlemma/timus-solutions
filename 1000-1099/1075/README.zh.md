# 1075. 绕过固定球体的最短细线

[Timus 1075](https://acm.timus.ru/problem.aspx?space=1&num=1075) · 难度 1982 · geometry

原题作者 Alexander Mironenko，出自 2001 年 2 月 Ural State University Personal Contest Online（Students Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

空间中的点 `A`、`B`、`C` 的坐标都是绝对值不超过 1000 的整数。一个半径为整数 `R`、球心在 `C` 的实心球被固定住，
`A` 和 `B` 到 `C` 的距离都大于 `R`。求从 `A` 到 `B`、不进入球内部的最短细线的长度，保留两位小数。

时间限制：1 秒。内存限制：64 MB。

## 输入

`A`、`B`、`C` 的坐标，每行一个点，然后是 `R`。

## 输出

细线的长度。

## 评测方式

数值按绝对误差 0.011 比较：答案以两位小数输出，最后一位可能相差 1。

## 样例

### 样例 1

输入：

```
0 0 12
12 0 0
10 0 10
10
```

输出：

```
19.71
```

## 题解

最短的细线位于经过 `A`、`B`、`C` 的平面内，所以问题就是在这个平面内绕过半径为 `R` 的圆的最短路径。设
`a = |CA|`，`b = |CB|`，`φ` 为角 `ACB`。从 `C` 看去，`A` 引出的切点与 `A` 的方向相差 `α = arccos(R/a)`，
`B` 引出的切点与 `B` 的方向相差 `β = arccos(R/b)`。

- 若 `φ ≤ α + β`，线段 `AB` 不进入球内，答案是 `|AB|`。
- 否则细线沿 `A` 的切线、角度为 `φ − α − β` 的圆弧和到 `B` 的切线走：
  `√(a² − R²) + √(b² − R²) + R·(φ − α − β)`。

`O(1)`。

注意事项：

- 用归一化点积的 `arccos` 求 `φ`，在 0 和 `π` 附近会损失精度；`atan2(|CA × CB|, CA · CB)` 处处精确，而且
  点积和叉积都是精确的整数；
- 当 `A`、`C`、`B` 共线且 `C` 在中间时，平面不唯一，但 `φ = π`，公式仍然成立；
- `A` 可能与 `B` 重合；此时 `φ = 0`，答案为 0。

答案用另一种方法做了核对：把平面展开，按到 `C` 的距离判断线段是否与圆相交，否则比较所有“切线—圆弧—切线”路径，
覆盖每个端点的两个切点以及圆弧的两个方向。

## 各语言说明

- C++ 用 `long long` 保存向量，使乘积在开平方之前是精确的。
- Python 用三个参数的 `math.hypot` 计算长度。
