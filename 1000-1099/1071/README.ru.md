# 1071. Наименьшее основание, в котором вычёркивание цифр превращает x в y

[Timus 1071](https://acm.timus.ru/problem.aspx?space=1&num=1071) · сложность 624 · math

Автор оригинальной задачи — Дмитрий Филимоненков; Ural State University Personal Contest Online, февраль 2001 года, Students Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны два целых числа `1 ≤ y < x ≤ 1 000 000`. Найдите наименьшее
основание `b ≥ 2`, в котором цифры `y` можно получить из цифр `x`,
вычеркнув часть из них, или выведите `No solution`, если такого основания
нет.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`x` и `y` в одной строке.

## Выходные данные

Основание или `No solution`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
127 16
```

Вывод:

```
3
```

## Решение

Разобьём основания на три диапазона.

- `b > x`: `x` — одна цифра, а `y` — другая, так что ничего не выйдет.
- `b² ≤ x`: не больше тысячи оснований. Записываем оба числа в системе
  `b` и жадно проверяем, что цифры `y` встречаются среди цифр `x` по
  порядку.
- `b² > x` и `b ≤ x`: у `x` ровно две цифры, `x div b` и `x mod b`, и
  `y < x` должно совпасть с одной из них.
  - `x div b = y` при `b` от `⌊x/(y+1)⌋ + 1` до `⌊x/y⌋`, так что
    наименьшее такое основание в этом диапазоне известно сразу.
  - `x mod b = y` значит, что `b` делит `x − y` и `b > y`, поэтому берём
    наименьший достаточно большой делитель `x − y`; делители перебираются
    парами до `√(x − y)`.

Малые основания проверяются первыми, поэтому первое совпадение там и есть
ответ; иначе ответ — меньший из двух кандидатов последнего диапазона.
`O(√x · log x)`.

Подводные камни:

- ответ может быть огромным, например 465379 для `932318 1560`, поэтому
  перебор, останавливающийся на основании 10 или 36, неверен;
- перебор всех оснований до `x` с полным переводом достаточно быстр в
  компилируемом языке, но почти все они попадают в двузначный диапазон, и
  его арифметическая обработка делает быстрым любой язык;
- цифра меньше основания: для младшей цифры это условие `b > y`, для
  старшей оно выполняется само, потому что `b² > x`.

Ответы сверены с перебором всех оснований с общей проверкой
подпоследовательности — для всех пар с `x < 700` и для случайных больших
пар.

## Особенности языков

- C++ и Java считают `b · b` в условии цикла в 64 битах; Go и Rust везде
  используют 64-битные целые.
- Python проверяет подпоследовательность идиомой `d in it` на одном
  итераторе, который движется вперёд по цифрам `x`.
