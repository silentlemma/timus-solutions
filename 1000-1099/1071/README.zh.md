# 1071. 划去数字能把 x 变成 y 的最小进制

[Timus 1071](https://acm.timus.ru/problem.aspx?space=1&num=1071) · 难度 624 · math

原题作者 Dmitry Filimonenkov，出自 2001 年 2 月 Ural State University Personal Contest Online（Students Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定两个整数 `1 ≤ y < x ≤ 1 000 000`。求最小的进制 `b ≥ 2`，使得在该进制下从 `x` 的各位数字中划去一部分后能
得到 `y` 的各位数字；如果不存在这样的进制，输出 `No solution`。

时间限制：1 秒。内存限制：64 MB。

## 输入

一行，包含 `x` 和 `y`。

## 输出

进制，或 `No solution`。

## 评测方式

按记号逐个比较输出；多余的空白不影响结果。

## 样例

### 样例 1

输入：

```
127 16
```

输出：

```
3
```

## 题解

把进制分成三段。

- `b > x`：`x` 是一位数字，`y` 是另一个数字，不可能。
- `b² ≤ x`：最多一千个进制。把两个数都写成 `b` 进制，贪心检查 `y` 的各位是否按顺序出现在 `x` 的各位中。
- `b² > x` 且 `b ≤ x`：`x` 恰有两位，`x div b` 和 `x mod b`，而 `y < x` 必须等于其中之一。
  - 当 `b` 在 `⌊x/(y+1)⌋ + 1` 到 `⌊x/y⌋` 之间时 `x div b = y`，所以这一段中最小的这种进制可以直接得到。
  - `x mod b = y` 意味着 `b` 整除 `x − y` 且 `b > y`，所以取 `x − y` 的足够大的最小因数；因数成对枚举到
    `√(x − y)`。

小进制先检查，所以那里的第一个匹配就是答案；否则答案是最后一段两个候选中较小的一个。`O(√x · log x)`。

注意事项：

- 答案可能非常大，例如 `932318 1560` 的答案是 465379，所以在 10 或 36 进制处停止的搜索是错误的；
- 在编译型语言中，把所有不超过 `x` 的进制都完整转换一遍也足够快，但几乎所有进制都落在两位数那一段，用算术
  处理这一段能让每种语言都很快；
- 每位数字都小于进制：对低位来说这就是条件 `b > y`，对高位来说因为 `b² > x` 自然成立。

答案与枚举所有进制、用通用子序列检查的暴力做了核对：覆盖 `x < 700` 的所有数对以及随机的大数对。

## 各语言说明

- C++ 和 Java 在循环条件中用 64 位计算 `b · b`；Go 和 Rust 全程使用 64 位整数。
- Python 用一个迭代器上的 `d in it` 写法检查子序列，迭代器沿着 `x` 的各位向前移动。
