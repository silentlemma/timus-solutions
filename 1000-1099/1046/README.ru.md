# 1046. Восстановление многоугольника по вершинам треугольников на сторонах

[Timus 1046](https://acm.timus.ru/problem.aspx?space=1&num=1046) · сложность 1887 · geometry

Автор оригинальной задачи — Дмитрий Филимоненков; студенческое соревнование по программированию УрГУ, 25 марта 2000 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У многоугольника `A1 A2 … AN` (`3 ≤ N ≤ 50`) вершины идут по часовой
стрелке. На каждой стороне `Ai Ai+1` (где `AN+1 = A1`) снаружи построен
равнобедренный треугольник `Ai Mi Ai+1` с `Mi Ai = Mi Ai+1` и углом `αi` при
вершине `Mi`. Никакое непустое подмножество углов не даёт в сумме число,
кратное 360°. По вершинам `Mi` и углам восстановите вершины многоугольника.

Все числа во вводе — вещественные, не больше двух знаков после запятой,
`|xi|, |yi| ≤ 100`. Ограничение времени: 0,5 секунды. Ограничение памяти:
64 МБ.

## Входные данные

`N`, затем `N` строк с координатами `M1 … MN`, затем `N` строк с углами
`α1 … αN` в градусах.

## Выходные данные

`N` строк с координатами `A1 … AN`, точными до двух знаков после запятой.

## Проверка

Числа сравниваются с абсолютной погрешностью 0.011: ответы печатаются с
двумя знаками, поэтому последняя цифра может отличаться на единицу.

## Примеры

### Пример 1

Ввод:

```
3
0 2
3 3
2 0
90
90
90
```

Вывод:

```
1.00 1.00
1.00 3.00
3.00 1.00
```

### Пример 2

Ввод:

```
4
-1.73 1.00
1.00 3.00
2.58 1.00
1.00 -2.41
60
90
120
45
```

Вывод:

```
0.00 -0.01
0.01 2.00
2.00 2.01
2.00 -0.01
```

## Решение

Будем считать точки комплексными числами. `Mi Ai = Mi Ai+1` с углом `αi`
при `Mi` означает, что `Ai+1` — это `Ai`, повёрнутая вокруг `Mi` на `αi`
(против часовой стрелки для многоугольника по часовой стрелке с внешними
треугольниками):

```text
A[i+1] = M[i] + w[i] · (A[i] − M[i]),     w[i] = e^(i·α[i])
```

Каждый шаг — отображение `z → w·z + (1 − w)·M`. Композиция всех `N` шагов
по порядку даёт `z → a·z + b` с `a = w1 · … · wN = e^(i·Σα)`, и `A1`
должна быть его неподвижной точкой, потому что обход возвращается в `A1`:

```text
A1 = a·A1 + b   →   A1 = b / (1 − a)
```

Углы никогда не дают в сумме кратное 360°, поэтому `a ≠ 1` и ответ
единственный. Остальные вершины получаются применением шагов по очереди.
`O(N)`.

Подводные камни:

- направление поворота: при вершинах по часовой стрелке и внешних
  треугольниках поворот от `Ai` к `Ai+1` вокруг `Mi` идёт против часовой
  стрелки;
- углы даны в градусах;
- вершины `Mi` во вводе округлены, поэтому восстановленный многоугольник
  близок к исходному, но не совпадает с ним; печатайте два знака и
  избегайте `-0.00`.
