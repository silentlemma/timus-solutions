# 1046. 由各边三角形的顶点还原多边形

[Timus 1046](https://acm.timus.ru/problem.aspx?space=1&num=1046) · 难度 1887 · geometry

原题作者 Dmitry Filimonenkov，出自 2000 年 3 月 25 日乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

多边形 `A1 A2 … AN`（`3 ≤ N ≤ 50`）的顶点按顺时针排列。在每条边 `Ai Ai+1`（其中 `AN+1 = A1`）的外侧作等腰
三角形 `Ai Mi Ai+1`，`Mi Ai = Mi Ai+1`，顶角 `αi` 在 `Mi` 处。任何非空的角度子集之和都不是 360° 的倍数。给定
顶点 `Mi` 和各角，还原多边形的顶点。

输入中的数都是最多两位小数的实数，`|xi|, |yi| ≤ 100`。时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行是 `M1 … MN` 的坐标，再然后 `N` 行是以度为单位的角 `α1 … αN`。

## 输出

`N` 行，`A1 … AN` 的坐标，精确到两位小数。

## 评测方式

数值按绝对误差 0.011 比较：答案以两位小数输出，最后一位可能相差 1。

## 题解

把点看成复数。`Mi Ai = Mi Ai+1` 且 `Mi` 处的角为 `αi`，意味着 `Ai+1` 是 `Ai` 绕 `Mi` 旋转 `αi` 得到的（对于
顺时针排列、三角形在外侧的多边形，旋转方向是逆时针）：

```text
A[i+1] = M[i] + w[i] · (A[i] − M[i]),     w[i] = e^(i·α[i])
```

每一步是映射 `z → w·z + (1 − w)·M`。按顺序复合全部 `N` 步得到 `z → a·z + b`，其中
`a = w1 · … · wN = e^(i·Σα)`；由于绕一圈回到 `A1`，`A1` 必须是它的不动点：

```text
A1 = a·A1 + b   →   A1 = b / (1 − a)
```

各角之和永远不是 360° 的倍数，所以 `a ≠ 1`，解唯一。其余顶点依次应用各步即可得到。`O(N)`。

注意事项：

- 旋转方向：顶点顺时针、三角形在外侧时，绕 `Mi` 从 `Ai` 转到 `Ai+1` 是逆时针方向；
- 角度以度为单位；
- 输入中的 `Mi` 是四舍五入过的，所以还原出的多边形与原多边形接近但不完全相同；输出两位小数，并避免出现
  `-0.00`。
