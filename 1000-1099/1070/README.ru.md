# 1070. Разница во времени двух аэропортов по полёту туда и обратно

[Timus 1070](https://acm.timus.ru/problem.aspx?space=1&num=1070) · сложность 662 · bruteforce

Авторы оригинальной задачи — Магаз Асанов и Станислав Васильев; Ural State University Personal Contest Online, февраль 2001 года, Students Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Самолёт летит из одного аэропорта в другой, а второй возвращается
обратно. Для каждого рейса даны время вылета и время прилёта по местному
времени того аэропорта, где это происходит. Часы двух аэропортов
отличаются на целое число часов, не больше 5; каждый полёт длится не
больше 6 часов, а длительности двух полётов отличаются не больше чем на
10 минут. Найдите разницу между часами.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Две строки, по одной на рейс, в каждой время вылета и прилёта в виде
`ЧЧ.ММ`.

## Выходные данные

Разница в часах — неотрицательное целое число.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
23.42 00.39
08.10 17.11
```

Вывод:

```
4
```

## Решение

Пусть часы второго аэропорта идут на `k` часов впереди. Тогда настоящая
длительность первого полёта — разность показаний часов минус `k` часов, а
второго — разность показаний плюс `k` часов, обе по модулю суток, ведь по
часам самолёт может приземлиться «раньше», чем вылетел. Перебираем `k` от
−5 до 5 и оставляем то, при котором обе длительности не больше 6 часов и
отличаются не больше чем на 10 минут. Выводим `|k|`. `O(1)`.

Подходит ровно одно `k`: шаг на один час меняет разность длительностей на
два часа, а при длительностях не больше 6 часов переход через сутки не
может дать второго совпадения.

Подводные камни:

- полёт может пересечь полночь, а со сдвигом самолёт может даже
  приземлиться по часам раньше, чем вылетел, поэтому длительности берутся
  по модулю 24 часов;
- `ЧЧ.ММ` — не десятичная дробь: часы и минуты читаются отдельно, а не
  как вещественное число.

Ответы проверены другим способом: перебором всех настоящих длительностей
первого полёта до шести часов, вычислением сдвига по ней и проверкой
обратного рейса; сдвиг при этом оказывается единственным.

## Особенности языков

- C++ читает каждое время через `scanf("%d.%d")`; остальные языки делят
  токен по точке.
- В Python, Java (`Math.floorMod`) и Rust (`rem_euclid`) остаток никогда
  не бывает отрицательным; C++ и Go прибавляют сутки перед вторым `%`.
