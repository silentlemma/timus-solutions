# 1079. Наибольший член последовательности Штерна до n

[Timus 1079](https://acm.timus.ru/problem.aspx?space=1&num=1079) · сложность 112 · dp

Автор оригинальной задачи — Emil Kelevedzhiev; турнир по информатике Зимнего математического фестиваля, Варна, 2001 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Последовательность задана так: `a₀ = 0`, `a₁ = 1`, `a₂ᵢ = aᵢ` и
`a₂ᵢ₊₁ = aᵢ + aᵢ₊₁` при `i ≥ 1`. Для каждого данного `n`
(`1 ≤ n ≤ 99 999`) выведите наибольшее из `a₀, a₁, …, aₙ`.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

До десяти строк с `n`, затем строка с 0.

## Выходные данные

Максимум для каждого `n`, по одному в строке.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
5
10
0
```

Вывод:

```
3
4
```

## Решение

Каждый член ссылается только на члены с меньшими номерами, поэтому один
проход от 2 до 99 999 заполняет всю таблицу, а бегущий максимум
`best[i] = max(best[i − 1], aᵢ)` сразу отвечает на все запросы. `O(N)`
на таблицу, `O(1)` на запрос.

Это двухатомная последовательность Штерна. Некоторые рекорды — числа Фибоначчи,
которые достигаются при целых `n = (2^k ± 1)/3`; наибольшее значение до
99 999 равно 2584, так что 32-битных целых хватает с запасом.

Подводные камни:

- запросы идут в любом порядке и заканчиваются нулём, который запросом не
  является;
- формула для нечётных номеров использует `aᵢ₊₁`, номер которого всё равно
  меньше `2i + 1`, так что порядок прохода правильный.

Ответы сверены с вычислением по определению рекурсией с запоминанием и
простым перебором для каждого запроса.

## Оптимизированные решения

`1079_number_theory.java`. Вместо DP размером с префикс используется двоичный поиск по префиксам последовательности Штерна. Соседние значения (a,b) переходят в (a,a+b) по нулю и (a+b,b) по единице. Для меньшей ветви префикса коэффициенты Фибоначчи дают максимум по оставшимся битам; точный конечный префикс также учитывается. Для 17 бит достаточно девятнадцати чисел Фибоначчи, это не таблица ответов. O(log N) арифметики на запрос, O(log Nmax) малой предобработки и ввод/вывод по 4096 байт. Старые DP-алгоритмы сохранены.

Точный исходник: Java 1.8 Accepted #11327743: 0.093 s / 408 KB. Сохранённые места в группе компилятора от 2026-11-20, время затем память: 17/298; 1/298. Строгий допуск учитывает только время при памяти меньше 1024 КБ: первые десять или топ 15%, равенства делят место, процентный порог округляется вверх. Звёздочка остаётся для отдельной цели языка — первого места по обеим метрикам. Сохранённый прежний вариант имеет собственную парную посылку #11304027 (Java 1.8): 0.109 s / 728 KB; замеры и рантаймы не смешиваются. Все учебные исходники сохранены без изменений.

- `1079_number_theory.java`: 0.093 s / 408 KB; сохранённая учебная база `1079_dp.java` (Java 1.8): 0.125 s / 2364 KB.

`1079_number_theory.py`. Отдельный алгоритм теории чисел находит максимум префикса Штерна за O(log n) без динамики на 100000 элементов. Вдоль двоичного префикса n храним соседнюю пару Штерна. При единичном бите меньшая нулевая ветвь становится свободной; её максимум — соответствующая комбинация соседей с весами Фибоначчи. В оставшейся единичной ветви a+=b, при нуле b+=a. После последнего бита учитывается точный конец. Для n<=99999 достаточно 19 чисел Фибоначчи, полученных рекуррентностью, не таблицей ответов. Ввод/вывод запросов хранится отдельно. Исходная DP и её упакованная оптимизация сохранены.

Accepted точного исходника CPython 3.12 №11326678: 0.062 с / 456 КБ. Сравнение, сохранённое 2026-11-20 для актуальных компиляторов семейства: место по времени 1/97, по памяти 1/97. При памяти меньше 1024 КБ строгий критерий учитывает только время.

- `1079_number_theory.py`: 0.062 s / 456 KB; сохранённая учебная база `1079_dp.py` (Python 3.12 x64): 0.125 s / 3280 KB; изменение времени -50.4%; изменение памяти -86.1%.
