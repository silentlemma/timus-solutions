# 1079. The largest term of Stern's sequence up to n

[Timus 1079](https://acm.timus.ru/problem.aspx?space=1&num=1079) · difficulty 112 · dp

Original problem by Emil Kelevedzhiev, from the Informatics Tournament of the Winter Mathematical Festival, Varna 2001.

**English** · [Русский](README.ru.md) · [中文](README.zh.md) · [Español](README.es.md)

## Task

The sequence is `a₀ = 0`, `a₁ = 1`, `a₂ᵢ = aᵢ` and
`a₂ᵢ₊₁ = aᵢ + aᵢ₊₁` for `i ≥ 1`. For each given `n`
(`1 ≤ n ≤ 99 999`) print the largest of `a₀, a₁, …, aₙ`.

Time limit: 2 seconds. Memory limit: 64 MB.

## Input

Up to ten lines with `n`, then a line with 0.

## Output

The maximum for each `n`, one per line.

## Checking

The output is compared token by token; extra whitespace does not matter.

## Examples

### Example 1

Input:

```
5
10
0
```

Output:

```
3
4
```

## Solution

Every term refers only to terms with smaller indices, so one pass from 2
to 99 999 fills the whole table, and a running maximum
`best[i] = max(best[i − 1], aᵢ)` answers every query at once. `O(N)` for
the table, `O(1)` per query.

This is Stern's diatomic sequence. Some records are Fibonacci numbers,
reached at integer indices `n = (2^k ± 1)/3`; the largest value up to 99 999 is 2584,
so 32-bit integers are plenty.

Pitfalls:

- the queries come in any order and end with 0, which is not a query;
- the recurrence for odd indices uses `aᵢ₊₁`, which is still smaller than
  `2i + 1`, so the order of the pass is right.

The answers were checked against the definition computed by a memoised
recursion and a plain scan for every query.

## Optimized solutions

`1079_number_theory.java`. Replace the prefix-sized DP by a binary-prefix search in Stern’s sequence. Track neighboring values (a,b): a zero bit maps to (a,a+b), a one bit to (a+b,b). At each smaller-prefix branch, precomputed Fibonacci coefficients bound the maximum over all remaining bits; include the exact final prefix. The 17-bit input bound needs only nineteen Fibonacci entries, not a table of answers. O(log N) arithmetic per query, O(log Nmax) small fixed precomputation and bounded 4096-byte I/O buffers. Preserve the old DP algorithms.

`1079_number_theory.py`. A separate number-theory algorithm computes each Stern prefix maximum in O(log n) without the 100000-entry DP. Track the adjacent Stern pair along the binary prefix of n. At each set bit, the smaller zero branch becomes unrestricted; its maximum is the appropriate Fibonacci-weighted combination of the adjacent pair. The remaining one branch updates a+=b; a zero updates b+=a. Include the exact endpoint after the final bit. Only a 19-entry Fibonacci list for n<=99999 is needed; it is generated by the recurrence, not an answer table. Query input/output storage is separate. Keep both the original DP and its packed optimized version.
