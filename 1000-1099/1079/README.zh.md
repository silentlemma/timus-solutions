# 1079. Stern 序列到 n 为止的最大项

[Timus 1079](https://acm.timus.ru/problem.aspx?space=1&num=1079) · 难度 112 · dp

原题作者 Emil Kelevedzhiev，出自 2001 年瓦尔纳冬季数学节信息学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

数列定义为 `a₀ = 0`，`a₁ = 1`，当 `i ≥ 1` 时 `a₂ᵢ = aᵢ`，`a₂ᵢ₊₁ = aᵢ + aᵢ₊₁`。对每个给定的 `n`
（`1 ≤ n ≤ 99 999`），输出 `a₀, a₁, …, aₙ` 中的最大值。

时间限制：2 秒。内存限制：64 MB。

## 输入

最多十行，每行一个 `n`，然后另有一行 0。

## 输出

每个 `n` 对应的最大值，每行一个。

## 评测方式

按记号逐个比较输出；多余的空白不影响结果。

## 样例

### 样例 1

输入：

```
5
10
0
```

输出：

```
3
4
```

## 题解

每一项只引用下标更小的项，所以从 2 到 99 999 扫一遍就能填满整张表，再用前缀最大值
`best[i] = max(best[i − 1], aᵢ)` 一次性回答所有询问。建表 `O(N)`，每次询问 `O(1)`。

这就是 Stern 双原子数列。部分纪录值是斐波那契数，出现在整数下标 `n = (2^k ± 1)/3` 处；99 999 以内的最大值是 2584，
所以 32 位整数绰绰有余。

注意事项：

- 询问的顺序是任意的，以 0 结束，而 0 不是询问；
- 奇数下标的递推式用到 `aᵢ₊₁`，它的下标仍然小于 `2i + 1`，所以扫描的顺序是正确的。

答案与按定义用记忆化递归计算、再对每个询问直接扫描的结果做了核对。

用到更靠后的项；项和前缀最大值都用 16 位整数存储，这就够了，因为 99 999 以内没有
超过 2584 的项：{1079_dp_optimized.cpp}。
