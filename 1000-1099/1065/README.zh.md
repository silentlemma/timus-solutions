# 1065. 把给定点保留在内部的最短子多边形

[Timus 1065](https://acm.timus.ru/problem.aspx?space=1&num=1065) · 难度 1413 · dp, geometry

原题出自 2000–2001 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定一个有 `N` 个顶点的凸多边形（`3 ≤ N ≤ 50`，顺时针，整数坐标绝对值不超过 10000；可能有几个顶点在同一条边上）
以及其内部的 `M` 个点（`0 ≤ M ≤ 1000`）。保持顺序选出一部分顶点，使它们构成面积非零、且所有 `M` 个点都严格在
其内部的多边形，并使周长最小。输出保留两位小数的周长。

时间限制：2 秒。内存限制：64 MB。

## 输入

`N` 和 `M`，然后 `N` 行按顺时针给出顶点，再然后 `M` 行给出各点。

## 输出

最小周长，小数点后至少两位。

## 评测方式

数值按绝对误差 0.011 比较：答案以两位小数输出，最后一位可能相差 1。

## 样例

### 样例 1

输入：

```
5 0
8 9
0 -7
-8 -7
-8 1
-8 9
```

输出：

```
27.31
```

### 样例 2

输入：

```
5 2
8 9
0 -7
-8 -7
-8 1
-8 9
-4 -3
-1 -5
```

输出：

```
51.78
```

## 题解

按原顺序取凸多边形的顶点，得到的总是凸多边形，所以唯一的问题是哪些边 `i → j` 可以使用。新多边形同样是顺时针的，
内部在每条边的右侧：若所有点都严格在一条边的右侧（叉积为负），这条边就可以用。这需要 `O(N^2 · M)`。

于是新边界就是沿可用边绕一圈的环。对每个起始顶点 `s`，按顺序对后面的顶点做动态规划，求出从 `s` 到每个顶点的
最短路，再用一条回到 `s` 的可用边闭合边界。`O(N^3)`。

没有点（`M = 0`）时所有边都可用，但边界不能退化：原多边形同一条边上的三个顶点没有面积。任何凸多边形都包含一个
由它自己的顶点构成、周长不更大的三角形，所以答案就是面积非零的最短顶点三角形。只要至少有一个点，边界就要包住
它，因此不会出现退化的边界。

注意事项：

- 点必须严格在内部：在边上的点不算；
- 原多边形中共线的顶点：由三个这样的顶点组成的“三角形”不是多边形；
- 坐标差可达 `2 · 10^4`，所以叉积可达 `8 · 10^8`：32 位整数勉强放得下，解法使用 64 位整数。

答案在 `N` 较小时与枚举所有顶点子集的结果做了核对。
