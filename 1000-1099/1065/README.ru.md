# 1065. Кратчайший подмногоугольник, сохраняющий заданные точки внутри

[Timus 1065](https://acm.timus.ru/problem.aspx?space=1&num=1065) · сложность 1413 · dp, geometry

Оригинальная задача — полуфинал ACM ICPC Северо-Восточной Европы 2000–2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны выпуклый многоугольник с `N` вершинами (`3 ≤ N ≤ 50`, по часовой
стрелке, целые координаты до 10000 по модулю; несколько вершин могут
лежать на одной стороне) и `M` точек внутри него (`0 ≤ M ≤ 1000`).
Выберите часть вершин, сохранив их порядок, так чтобы они образовали
многоугольник ненулевой площади, содержащий все `M` точек строго внутри, с
наименьшим периметром. Выведите периметр с двумя знаками после запятой.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `M`, затем `N` строк с вершинами по часовой стрелке, затем `M` строк
с точками.

## Выходные данные

Наименьший периметр не менее чем с двумя знаками после запятой.

## Проверка

Числа сравниваются с абсолютной погрешностью 0.011: ответы печатаются с
двумя знаками, поэтому последняя цифра может отличаться на единицу.

## Примеры

### Пример 1

Ввод:

```
5 0
8 9
0 -7
-8 -7
-8 1
-8 9
```

Вывод:

```
27.31
```

### Пример 2

Ввод:

```
5 2
8 9
0 -7
-8 -7
-8 1
-8 9
-4 -3
-1 -5
```

Вывод:

```
51.78
```

## Решение

Вершины выпуклого многоугольника, взятые по порядку, всегда образуют
выпуклый многоугольник, поэтому вопрос только в том, какие стороны
`i → j` можно использовать. Новый многоугольник тоже идёт по часовой
стрелке, поэтому его внутренность справа от каждой стороны: сторона
допустима, если каждая точка лежит строго справа от неё (отрицательное
векторное произведение). Это `O(N^2 · M)`.

Новая граница — цикл, обходящий многоугольник один раз по допустимым
сторонам. Для каждой первой вершины `s` динамика по следующим вершинам по
порядку даёт кратчайший путь от `s` до каждой из них, а допустимая сторона
обратно в `s` замыкает границу. `O(N^3)`.

Без точек (`M = 0`) допустима любая сторона, но граница не должна
вырождаться: три вершины на одной стороне исходного многоугольника не
дают площади. Любой выпуклый многоугольник содержит треугольник из своих
вершин с не большим периметром, поэтому ответ — кратчайший треугольник из
вершин с ненулевой площадью. Если есть хотя бы одна точка, граница её
охватывает, и вырожденная граница появиться не может.

Подводные камни:

- точки должны быть строго внутри: точка на стороне не годится;
- коллинеарные вершины исходного многоугольника: «треугольник» из трёх
  таких вершин — не многоугольник;
- разности координат доходят до `2 · 10^4`, поэтому векторное
  произведение доходит до `8 · 10^8`: в 32-битные целые оно помещается
  едва-едва, и решения используют 64-битные.

Ответы сверены с перебором всех подмножеств вершин при малых `N`.

## Особенности языков

- Во всех языках векторные произведения считаются точно в целых, а
  плавающая точка используется только для длин.
