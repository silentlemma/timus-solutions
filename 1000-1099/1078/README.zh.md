# 1078. 逐个嵌套的最长线段链

[Timus 1078](https://acm.timus.ru/problem.aspx?space=1&num=1078) · 难度 354 · dp

原题作者 Emil Kelevedzhiev，出自 2001 年瓦尔纳冬季数学节信息学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

直线上有 `N` 条线段（`0 < N < 500`），端点是 `[−10000, 10000]` 中的整数。如果一条线段包含在另一条之中，并且它的
端点都不与另一条的端点重合，就说它在另一条内部。求最长的线段序列，使每条线段都在下一条内部，输出它的长度以及
按从短到长顺序排列的线段编号。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行，每行是一条线段的左端点和右端点。

## 输出

序列的长度，然后是其中线段的编号。

## 评测方式

接受任何一个最长序列。检查程序验证其长度是可能的最大值，并且每条列出的线段都严格位于下一条内部。

## 样例

### 样例 1

输入：

```
4
-2 2
-1 1
-3 3
4 5
```

输出：

```
3
2 1 3
```

## 题解

“内部”意味着 `L₂ < L₁` 且 `R₁ < R₂`，所以在另一条内部的线段严格更短。按长度排序后的线段构成嵌套关系的一个拓扑
序，这个顺序上的最长路是一个简单的动态规划：`best[i] = 1 + max best[j]`，`j` 取所有位于 `i` 内部的更短线段，
`prev[i]` 记住选择。答案以 `best` 最大的线段结尾，沿 `prev` 走得到的是从外到内的链，所以要反过来输出。
`O(N^2)`。

注意事项：

- 端点重合不算：`[0, 1]` 不在 `[0, 3]` 内部，相等的线段也互不在对方内部；
- 长度为零的线段可以在另一条内部，但任何线段都不能在它内部；
- 顺序必须从最短的线段到最长的线段；
- 如果某条线段的端点以相反顺序给出，解法会交换它们，这表示的是同一条线段。

检查程序通过对所有线段的记忆化搜索求出最大长度，并检查输出的链。

## 各语言说明

- Python 用带步长的切片读取端点，并用 `min` 和 `max` 构造 `left` 和 `right`。
- Rust 用 `max_by_key` 选出最后一条线段。
