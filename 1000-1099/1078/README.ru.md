# 1078. Самая длинная цепочка отрезков, вложенных друг в друга

[Timus 1078](https://acm.timus.ru/problem.aspx?space=1&num=1078) · сложность 354 · dp

Автор оригинальной задачи — Emil Kelevedzhiev; турнир по информатике Зимнего математического фестиваля, Варна, 2001 год.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N` отрезков на прямой (`0 < N < 500`) имеют целые концы в
`[−10000, 10000]`. Отрезок лежит внутри другого, если он содержится в нём
и ни один его конец не совпадает с концом другого. Найдите самую длинную
последовательность отрезков, в которой каждый лежит внутри следующего, и
выведите её длину и номера её отрезков от самого короткого к самому
длинному.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк с левым и правым концами отрезка.

## Выходные данные

Длина последовательности, затем номера её отрезков.

## Проверка

Подходит любая самая длинная последовательность. Проверяющая программа
убеждается, что её длина наибольшая возможная и что каждый указанный
отрезок лежит строго внутри следующего.

## Примеры

### Пример 1

Ввод:

```
4
-2 2
-1 1
-3 3
4 5
```

Вывод:

```
3
2 1 3
```

## Решение

«Внутри» означает `L₂ < L₁` и `R₁ < R₂`, так что отрезок внутри другого
строго короче. Отсортированные по длине отрезки образуют топологический
порядок отношения вложенности, и самый длинный путь в этом порядке
находит простая динамика: `best[i] = 1 + max best[j]` по более коротким
отрезкам `j`, лежащим внутри `i`, а `prev[i]` запоминает выбор. Ответ
заканчивается на отрезке с наибольшим `best`, и проход по `prev` выдаёт
цепочку снаружи внутрь, поэтому она печатается в обратном порядке.
`O(N^2)`.

Подводные камни:

- общие концы не считаются: `[0, 1]` не лежит внутри `[0, 3]`, а равные
  отрезки не лежат друг в друге;
- отрезок нулевой длины может лежать внутри другого, а внутри него не
  может лежать ничего;
- порядок должен идти от самого короткого отрезка к самому длинному;
- если концы отрезка заданы в обратном порядке, решения меняют их местами
  — это тот же отрезок.

Проверяющая программа находит наибольшую длину поиском с запоминанием по
всем отрезкам и проверяет выведенную цепочку.

## Особенности языков

- Python читает концы срезами с шагом и строит `left` и `right` через
  `min` и `max`.
- Rust выбирает последний отрезок через `max_by_key`.
