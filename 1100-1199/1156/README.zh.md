# 1156. 把 2N 道题分成两轮，相似的题不放在同一轮

[Timus 1156](https://acm.timus.ru/problem.aspx?space=1&num=1156) · 难度 327 · graphs

原题作者 Evgeny Bryzgalov，出自 2001 年 4 月在彼尔姆举行的乌拉尔团体程序设计锦标赛英语轮。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

要把 `2N` 道题（`N ≤ 50`）分成两轮，每轮 `N` 道。有 `M ≤ 100` 对题目相似，
不能放在同一轮。输出两轮的题目，或者输出 `IMPOSSIBLE`。

时间限制：2 秒。内存限制：64 MB。

## 输入

`N` 和 `M`，然后是 `M` 对相似的题目。

## 输出

两行，每行一轮的 `N` 道题；或者 `IMPOSSIBLE`。

## 评测方式

任何合法的分法都被接受。检查程序验证两行各有 `N` 道题、合起来恰为 1 到
`2N` 的全部题目、没有相似的一对在同一轮，并且只有在确实无法划分时才输出
`IMPOSSIBLE`。

## 样例

### 样例 1

输入：

```
2 3
1 3
2 1
4 3
```

输出：

```
1 4
2 3
```

## 解法

把相似的题用边连起来。在一个连通分量内，一道题所在的轮次决定了其他所有题
的轮次：相邻的题交替。所以每个分量必须能二染色，出现奇环就无法划分。两个
颜色类大小为 `a` 和 `b` 的分量会给第一轮贡献 `a` 或 `b` 道题；没有相似题的
题目就是大小为 `(1, 0)` 的分量。

剩下的问题是为每个分量选择哪个颜色类进入第一轮，使第一轮恰好有 `N` 道题。
这是对分量做子集和：`reach[k]` 保存前 `k` 个分量能给出的数目，从 `N` 往回
走即可还原选择。分量最多 `2N = 100` 个，数目不超过 `N`，表非常小。

注意事项：

- 只染色还不够，颜色类的大小还必须凑成 `N`；
- 与自己相似的题会使划分不可能；
- 同一对可能给出两次；
- 每轮的题可以按任意顺序输出，这里按递增顺序。

答案已用检查程序在所有测试上验证；在 200 个最多 14 道题的随机输入上，是否
可分也与枚举所有 `N` 道题选法的结果比对过。

## 各语言说明

- 所有语言都用显式栈的深度优先搜索染色，并填写同样的子集和表；Python 把
  每一行存为集合。
