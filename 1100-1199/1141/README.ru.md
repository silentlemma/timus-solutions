# 1141. Расшифровка коротких сообщений RSA через разложение модуля

[Timus 1141](https://acm.timus.ru/problem.aspx?space=1&num=1141) · сложность 364 · number_theory

Автор оригинальной задачи: Михаил Медведев.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для `K ≤ 2000` запросов `e, n, c ≤ 32000`, где `n = p·q` для двух
различных нечётных простых, а `e < (p − 1)(q − 1)` взаимно просто с
`(p − 1)(q − 1)`, найти сообщение `m`, для которого `m^e ≡ c (mod n)`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`K`, затем `K` строк с `e`, `n` и `c`.

## Выходные данные

По одному `m` в строке.

## Примеры

### Пример 1

Ввод:

```
3
9 187 129
11 221 56
7 391 204
```

Вывод:

```
7
23
17
```

## Решение

Это RSA с крошечным модулем, так что его можно просто взломать. Перебор
нечётных делителей от 3 находит `p` не больше чем за `√n < 179` шагов, а
дальше `φ = (p − 1)(q − 1)`. Раз `e` взаимно просто с `φ`, у него есть
обратное `d` по модулю `φ`, которое даёт расширенный алгоритм Евклида.
Тогда `c^d = m^(e·d) ≡ m (mod n)`: по модулю каждого простого `r`,
делящего `n`, число `e·d = 1 + t·φ` равно `1` плюс кратное `r − 1`, так что
малая теорема Ферма даёт `m^(e·d) ≡ m (mod r)`, в том числе когда `r`
делит `m`, а китайская теорема об остатках соединяет оба простых. Значит,
`m = c^d mod n`, и его даёт быстрое возведение в степень.
`O(√n + log n)` на запрос.

Тонкие места:

- `c` может быть больше `n`; возведение в степень сначала его приводит;
- сообщение может иметь общий множитель с `n`; расшифровка всё равно
  работает, потому что `n` не делится на квадраты;
- обратное из расширенного алгоритма Евклида может получиться
  отрицательным, поэтому его приводят в `[0, φ)`;
- все произведения меньше `32000²` и помещаются в 64-битные целые.

Ответы сверены на всех тестах с перебором всех `m` от `0` до `n − 1`,
который заодно подтвердил, что ответ единственный.

## Особенности языков

- Во всех языках одинаковые разложение, обращение и возведение в
  степень; в Python обратное даёт встроенный `pow(e, -1, phi)`.
