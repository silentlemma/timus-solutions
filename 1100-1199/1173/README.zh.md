# 1173. 经过所有点且线段互不相交的闭合路线

[Timus 1173](https://acm.timus.ru/problem.aspx?space=1&num=1173) · 难度 1050 · geometry

原题作者 Mugurel Ionut Andreica，出自 2001 年 12 月的 Romanian Open Contest（罗马尼亚公开赛）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

Wally 的家和 `N ≤ 1000` 位朋友的家是平面上的点，任意三点不共线，坐标至多三位
小数。求一个顺序：Wally 从家出发，沿直线段恰好拜访每位朋友一次再回家，并且除了
相邻线段在公共端点相交外，任意两条线段都不相交。若不存在，输出 `-1`。

时间限制：1 秒。内存限制：64 MB。

## 输入

Wally 的坐标、`N`，然后 `N` 行，每行是一位朋友的坐标和 1 到 `N` 的编号。

## 输出

`0`、按拜访顺序排列的朋友编号，最后再一个 `0`，每行一个。

## 评测方式

只要顺序拜访每位朋友一次，并且闭合路线中任意两条不相邻的边都不相交，就被
接受；检查程序精确检查每一对边。由于路线总是存在，`-1` 永远是错的。

## 样例

### 样例 1

输入：

```
0 0
3
3 3 1
6 0 2
6 2 3
```

输出：

```
0
1
3
2
0
```

## 解法

把朋友按绕家的角度排序。在这个顺序中相邻的两位朋友从家看去张成一个角，只要
这个角小于半圈，它们之间的线段就落在这个角内。不同对的角互不重叠，所以这些线段
既不彼此相交，也不与沿角边界的两条从家出发的线段相交。

路线从家走到某位朋友，按角度顺序绕一圈再回家。它恰好跳过一个角，即最后一位和
第一位朋友之间的角。大于半圈的角至多一个，若存在，路线就从它之后开始；否则从
哪里开始都行。所以答案永远不是 `-1`。`O(N log N)`。

注意事项：

- 坐标有三位小数，所以换算成以千分之一为单位的整数，角度排序用精确的叉积，
  结果在 64 位之内；
- 家可能在朋友群的中间，这时随意选择起点会让某条线段横跨大于半圈的角；
- 只有两位朋友时只有两个角，恰好一个大于半圈。

所有测试上的每个输出都通过逐对检查所有边进行了验证，其中包括一千位朋友在家
周围、旁边以及远处的情形。

## 各语言说明

- 所有语言都用同样的精确比较排序：先比较方向所在的半平面，再看叉积的符号。
