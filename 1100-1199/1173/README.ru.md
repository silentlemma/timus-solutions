# 1173. Замкнутый обход всех точек без пересекающихся отрезков

[Timus 1173](https://acm.timus.ru/problem.aspx?space=1&num=1173) · сложность 1050 · geometry

Автор оригинальной задачи — Mugurel Ionut Andreica; Romanian Open Contest, декабрь 2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дом Уолли и дома `N ≤ 1000` друзей — точки на плоскости, никакие три не
лежат на одной прямой, координаты не более чем с тремя знаками после
запятой. Найти порядок, в котором Уолли выходит из дома, посещает каждого
друга по одному разу по прямым отрезкам и возвращается так, чтобы никакие
два отрезка не пересекались, кроме соседних в их общем конце. Если такого
нет, вывести `-1`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Координаты Уолли, `N`, затем `N` строк с координатами и номером друга от
1 до `N`.

## Выходные данные

`0`, номера друзей в порядке посещения и снова `0`, по одному в строке.

## Проверка

Принимается любой порядок, который посещает каждого друга один раз и в
котором никакие две несоседние стороны замкнутого пути не встречаются;
проверяющая программа точно проверяет каждую пару сторон. Поскольку обход
всегда существует, `-1` никогда не верен.

## Примеры

### Пример 1

Ввод:

```
0 0
3
3 3 1
6 0 2
6 2 3
```

Вывод:

```
0
1
3
2
0
```

## Решение

Отсортируем друзей по углу вокруг дома. Двое соседних в этом порядке
друзей задают угол, видимый из дома, и отрезок между ними остаётся внутри
этого угла, пока угол меньше половины оборота. Углы разных пар не
перекрываются, так что эти отрезки не пересекают ни друг друга, ни два
отрезка от дома, которые идут по границам углов.

Обход идёт от дома к какому-то другу, по угловому порядку и обратно. Он
пропускает ровно один угол — между последним и первым другом. Больше
половины оборота может быть не больше чем у одного угла, поэтому если
такой есть, обход начинается сразу после него; иначе начинать можно
откуда угодно. Значит, ответ никогда не `-1`. `O(N log N)`.

Тонкие места:

- у координат три знака после запятой, поэтому они переводятся в целые
  тысячные, а угловой порядок использует точные векторные произведения,
  которые помещаются в 64 бита;
- сам дом может стоять внутри толпы друзей, и тогда неудачное начало
  положит отрезок поперёк угла больше половины оборота;
- при двух друзьях угла всего два, и ровно один из них больше половины
  оборота.

Каждый вывод проверен перебором всех пар сторон на всех тестах, включая
тысячу друзей вокруг дома, сбоку от него и далеко от него.

## Особенности языков

- Во всех языках сортировка с одним и тем же точным сравнением: сначала
  полуплоскость направления, затем знак векторного произведения.
