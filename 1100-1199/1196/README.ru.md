# 1196. Сколько дат из списка студента есть у преподавателя

[Timus 1196](https://acm.timus.ru/problem.aspx?space=1&num=1196) · сложность 53 · binary_search

Оригинальная задача — фольклор; пятое командное первенство школьников по программированию, 2 марта 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У преподавателя отсортированный список из `N ≤ 15000` годов, а студент
выписывает `M ≤ 10⁶` годов в любом порядке; в обоих списках года могут
повторяться, все до `10⁹`. Посчитать записи из списка студента, которые
есть и в списке преподавателя.

Ограничение времени: 1.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N` и года преподавателя, по одному в строке, затем `M` и года студента.

## Выходные данные

Число совпадающих записей.

## Примеры

### Пример 1

Ввод:

```
2
1054
1492
4
1492
65536
1492
100
```

Вывод:

```
2
```

## Решение

Список преподавателя уже отсортирован, поэтому каждый год студента ищется
двоичным поиском; каждое совпадение засчитывается, включая повторы со
стороны студента, а повторы со стороны преподавателя ничего не меняют.
`O(M log N)`. При миллионе чисел на вход быстрое чтение важнее самих
поисков.

Тонкие места:

- год, записанный студентом дважды, засчитывается дважды;
- во входе до миллиона строк, так что медленное построчное чтение в
  некоторых языках может не уложиться во время.

Ответы сверены с отдельно написанным решением, использующим хеш-таблицу,
на всех тестах.

## Особенности языков

- Python складывает года преподавателя в множество; остальные языки
  ищут двоичным поиском в отсортированном массиве. Java читает ввод
  самописным побайтовым чтением.
- Python читает года студента по одной строке. Если разбить весь ввод
  сразу, в памяти одновременно окажется миллион маленьких строк, около
  62 МБ, и такая версия превысила лимит 64 МБ на тесте 8.
