# 1109. 覆盖二分图所有顶点的最少边数

[Timus 1109](https://acm.timus.ru/problem.aspx?space=1&num=1109) · 难度 250 · matching

原题出自保加利亚全国信息学奥林匹克竞赛第一天。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个二分图左侧有 `M` 个顶点，右侧有 `N` 个顶点（`M, N ≤ 1000`），共 `K` 条边，每条边连接一个左顶点和一个右顶点；每个顶点至少有一条边。求最少选多少条边，才能使每个顶点都是至少一条所选边的端点。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`M N K`，然后是 `K` 行 `a b`：左顶点 `a` 与右顶点 `b` 之间的一条边。边可能重复。

## 输出

最少的边数。

## 评测方式

输出按记号逐个比较；多余的空白字符无关紧要。

## 样例

### 样例 1

输入：

```
3 2 4
1 1
2 1
3 1
3 2
```

输出：

```
3
```

## 解法

这是最小边覆盖，它的大小等于 `M + N − ν`，其中 `ν` 是最大匹配的大小。有了最大匹配后，为每个未匹配的顶点任意加上它的一条边：共
`ν + (M + N − 2ν)` 条边。反过来，在最小边覆盖中每条边都有一个只被它覆盖的端点，所以覆盖由若干星形组成；从每个星形取一条边，得到大小为
`M + N − |覆盖|` 的匹配，因此不存在更小的覆盖。

最大匹配用 Hopcroft–Karp 算法求：从所有自由的左顶点做 BFS 把图分层，再沿着层用 DFS 在顶点不相交的最短增广路上增广，只要还有增广路就重复这一阶段。
`O(K √(M + N))`。

注意事项：

- 匹配本身不是答案：未匹配的顶点仍各需一条边；
- 贪心地取第一个空闲伙伴得到的匹配可能太小，阶梯形测试就是如此；
- 边数可达一百万而时限只有半秒，从每个顶点做朴素的增广路搜索可能太慢，慢速输入也是一样。

答案经过验证：在数百个小图上与枚举所有边子集的暴力比对，在大图上与 Kuhn 的简单增广路匹配比对。
