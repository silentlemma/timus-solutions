# 1109. Наименьшее число рёбер, касающихся всех вершин двудольного графа

[Timus 1109](https://acm.timus.ru/problem.aspx?space=1&num=1109) · сложность 250 · matching

Оригинальная задача — Болгарская национальная олимпиада по информатике, первый день.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Двудольный граф имеет `M` вершин слева и `N` справа (`M, N ≤ 1000`) и
`K` рёбер, каждое соединяет левую вершину с правой; у каждой вершины есть
хотя бы одно ребро. Найти наименьшее число рёбер, такое что каждая
вершина — конец хотя бы одного выбранного ребра.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`M N K`, затем `K` строк `a b`: ребро между левой вершиной `a` и правой
вершиной `b`. Рёбра могут повторяться.

## Выходные данные

Наименьшее число рёбер.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
3 2 4
1 1
2 1
3 1
3 2
```

Вывод:

```
3
```

## Решение

Это минимальное рёберное покрытие, и его размер равен `M + N − ν`, где
`ν` — размер наибольшего паросочетания. Имея наибольшее паросочетание,
добавим для каждой непокрытой им вершины любое её ребро: всего
`ν + (M + N − 2ν)` рёбер. В обратную сторону: в минимальном рёберном
покрытии у каждого ребра есть конец, покрытый только им, так что
покрытие — набор звёзд; взяв по ребру из каждой звезды, получим
паросочетание из `M + N − |покрытие|` рёбер, поэтому меньшего покрытия
не бывает.

Наибольшее паросочетание ищется алгоритмом Хопкрофта–Карпа: BFS из всех
свободных левых вершин делит граф на слои, затем DFS вдоль слоёв
увеличивает паросочетание по непересекающимся по вершинам кратчайшим
путям, и фазы повторяются, пока увеличивающий путь существует.
`O(K √(M + N))`.

Тонкие места:

- паросочетание само по себе — не ответ: непокрытым вершинам всё равно
  нужно по ребру;
- паросочетание, найденное жадно, взятием первого свободного партнёра,
  может оказаться слишком маленьким, как в тестах-лесенках;
- при миллионе рёбер и половине секунды простой поиск увеличивающего пути
  из каждой вершины может не успеть, как и медленный ввод.

Ответы проверены перебором всех подмножеств рёбер на сотнях маленьких
графов и простым паросочетанием Куна по увеличивающим путям на больших.
