# 1181. Разрезание трёхцветного многоугольника на разноцветные треугольники

[Timus 1181](https://acm.timus.ru/problem.aspx?space=1&num=1181) · сложность 455 · constructive

Автор оригинальной задачи — Дмитрий Филимоненков; третье личное первенство УрГУ по программированию, Екатеринбург, 16 февраля 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Вершины выпуклого многоугольника с `4 ≤ N ≤ 1000` вершинами окрашены в
R, G и B; все три цвета есть, и никакие две соседние вершины не одного
цвета. Разрезать многоугольник непересекающимися диагоналями на
треугольники, у каждого из которых есть вершина каждого цвета, или
вывести 0, если это невозможно.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем цвета в порядке обхода многоугольника.

## Выходные данные

Число диагоналей, затем диагонали парами номеров вершин.

## Проверка

Принимается любое разрезание, в котором `N − 3` различные диагонали не
пересекаются и каждый получившийся треугольник имеет все три цвета. Такое
разрезание всегда существует, так что `0` никогда не верен.

## Примеры

### Пример 1

Ввод:

```
7
RBGBRGB
```

Вывод:

```
4
1 3
3 7
5 7
5 3
```

## Решение

Если какой-то цвет встречается только один раз, проведём все диагонали из
этой вершины. В каждом треугольнике веера — она и две соседние вершины
остальной части, которые отличаются и друг от друга, и от неё.

Иначе каждый цвет встречается хотя бы дважды. Есть вершина, у которой
соседи разного цвета: если бы у каждой вершины соседи были одинаковы,
цвета повторялись бы с периодом два по всему многоугольнику, и цветов было
бы только два. Отрежем эту вершину диагональю между её соседями;
треугольник трёхцветный, у остатка по-прежнему все три цвета (цвет
удалённой вершины есть ещё где-то) и нет одинаковых соседей. Повторяем,
пока какой-то цвет не останется в одиночестве или не останется
треугольник. Значит, ответ всегда существует, и в нём `N − 3` диагонали.
`O(N²)` с простым удалением из списка.

Тонкие места:

- ответ никогда не 0, хотя задача его упоминает;
- после отрезания счётчики цветов меняются, так что цвет может стать
  одиночным позже — тогда работу заканчивает веер;
- нечётный многоугольник не может чередовать два цвета — ещё один способ
  увидеть, что поиск вершины с разными соседями всегда успешен.

Каждое выведенное разрезание прошло проверяющую программу на 200
случайных многоугольниках до 33 вершин и на всех тестах, включая
многоугольники из тысячи вершин.

## Особенности языков

- Во всех языках оставшиеся вершины хранятся в списке, из которого
  удаляется отрезанная.
