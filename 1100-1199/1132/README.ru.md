# 1132. Все квадратные корни из a по простому модулю n, до 100000 запросов

[Timus 1132](https://acm.timus.ru/problem.aspx?space=1&num=1132) · сложность 548 · number_theory

Автор оригинальной задачи: Михаил Медведев.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для `K ≤ 100000` запросов `a, n` с простым `n ≤ 32767` и `1 ≤ a ≤ 32767`,
не делящимся на `n`, вывести все `x` от `1` до `n − 1`, для которых
`x² ≡ a (mod n)`, по возрастанию, или `No root`, если таких нет.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`K`, затем `K` строк с `a` и `n`.

## Выходные данные

По строке на запрос: корни через пробел или `No root`.

## Примеры

### Пример 1

Ввод:

```
5
4 17
3 7
2 7
14 31
10007 20011
```

Вывод:

```
2 15
No root
3 4
13 18
5382 14629
```

## Решение

Берём `a` по модулю `n`. При `n = 2` единственный корень — `1`. Для
нечётного простого существование корня решает критерий Эйлера:
`a^((n−1)/2)` равно `1` для квадратичного вычета и `n − 1` иначе. Если
корень `r` есть, второй равен `n − r`, и они различны, потому что `n`
нечётно, а `a` не ноль.

Сам корень даёт алгоритм Тонелли — Шенкса. Запишем `n − 1 = q·2^s` с
нечётным `q` и возьмём любой невычет `z`. Начнём с `r = a^((q+1)/2)`,
`t = a^q` и `c = z^q`; тогда всегда `r² = a·t`. Пока `t ≠ 1`, находим
наименьшее `i` с `t^(2^i) = 1`, берём `b = c^(2^(s−i−1))` и обновляем
`r ← r·b`, `t ← t·b²`, `c ← b²`, `s ← i`. Каждый шаг уменьшает порядок
`t`, так что не больше чем за `s` шагов `t = 1` и `r² = a`. Наименьший
невычет каждого простого ищется один раз и запоминается. При
`n ≡ 3 (mod 4)` цикл не выполняется вовсе и `r = a^((n+1)/4)`.
`O(log² n)` на запрос.

Тонкие места:

- `a` может быть больше `n`, поэтому его сначала нужно привести;
- у `n = 2` один корень, `1`, и критерий Эйлера к нему не применяется;
- два корня выводятся начиная с меньшего;
- при 100000 запросов ввод и вывод буферизуются.

Ответы сверены на всех тестах с таблицей всех квадратов по модулю каждого
встретившегося простого.

## Особенности языков

- Во всех языках один и тот же алгоритм Тонелли — Шенкса и запоминание
