# 1135. 统计面对面的新兵转身次数，直到队列稳定

[Timus 1135](https://acm.timus.ru/problem.aspx?space=1&num=1135) · 难度 160 · math

原题出自 2001 年 10 月 17–18 日在雷宾斯克举行的俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N ≤ 30000` 名新兵站成一排，每人面向左（`<`）或面向右（`>`）。每一秒，
所有面对面的相邻两人（`><`）同时转身。统计直到队列不再变化时成对转身的
次数；若过程永不停止，输出 `NO`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后恰好 `N` 个字符 `<` 和 `>`，分布在长度不超过 255 的若干行中。

## 输出

成对转身的次数。

## 样例

### 样例 1

输入：

```
6
>><<><
```

输出：

```
7
```

## 解法

转身的一对 `><` 变成 `<>`：就朝向而言，这是两个相邻者的交换。每次这样的
交换恰好消除一对 `>` 在 `<` 之前的新兵（不一定相邻），并且不产生新的。
队列稳定当且仅当不再有 `><`，也就是所有 `<` 都在所有 `>` 之前，此时这样的
对一个也没有。因此过程总会停止，永远不会输出 `NO`，转身次数等于 `>` 在
`<` 之前的对数。一遍扫描即可统计：记录已经见过的 `>` 的个数，每遇到一个
`<` 就加上它。`O(N)`。

注意事项：

- 队列分布在多行中，可能有空行，所以要一直读字符，直到读满 `N` 个；
- 答案最大为 `15000² = 2.25·10⁸`，仍在 32 位范围内，但用 64 位计数器也
  没有代价；
- 同一秒内转身的先后顺序不影响计数。

答案已在 200 个最多 300 名新兵的随机队列上与逐秒模拟的结果比对。
