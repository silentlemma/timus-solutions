# 1135. Подсчёт поворотов новобранцев, стоящих лицом друг к другу, до стабилизации строя

[Timus 1135](https://acm.timus.ru/problem.aspx?space=1&num=1135) · сложность 160 · math

Оригинальная задача — четвертьфинал, центральный регион России, Рыбинск, 17–18 октября 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`1 ≤ N ≤ 30000` новобранцев стоят в ряд, каждый лицом влево (`<`) или
вправо (`>`). Каждую секунду все пары соседей, стоящих лицом друг к
другу (`><`), одновременно разворачиваются. Посчитать число поворотов
пар, пока строй не перестанет меняться, или вывести `NO`, если это не
кончается никогда.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем ровно `N` символов `<` и `>`, разбитых на строки длиной до 255
символов.

## Выходные данные

Число поворотов пар.

## Примеры

### Пример 1

Ввод:

```
6
>><<><
```

Вывод:

```
7
```

## Решение

Разворачивающаяся пара `><` превращается в `<>`: с точки зрения
направлений это обмен двух соседей. Каждый такой обмен убирает ровно одну
пару новобранцев (не обязательно соседних), где `>` стоит раньше `<`, и не
создаёт новых. Строй стабилен ровно тогда, когда `><` не осталось, то есть
когда все `<` стоят раньше всех `>`, а там таких пар нет вовсе. Значит,
процесс всегда кончается, `NO` не выводится никогда, а число поворотов
равно числу пар, где `>` раньше `<`. Их считает один проход: храним число
уже встреченных `>` и прибавляем его на каждом `<`. `O(N)`.

Тонкие места:

- считаем повороты пар, а не прошедшие секунды: в тесте `01` семь
  поворотов пар за четыре секунды;
- строй разбит на несколько строк, возможно с пустыми, так что символы
  читаются, пока не наберётся `N` штук;
- ответ доходит до `15000² = 2,25·10⁸`, это ещё помещается в 32 бита, но
  64-битные счётчики ничего не стоят;
- порядок поворотов внутри секунды на ответ не влияет.

Ответы сверены с посекундной симуляцией на 200 случайных строях до 300
новобранцев.

## Оптимизированные решения

Быстрая реализация Java сохраняет тот же подсчёт инверсий, но читает непосредственно через повторно используемый байтовый буфер 4 КБ вместо символьных читателей. Переводы строк пропускаются, учитываются ровно `N` направлений. Время остаётся `O(N)`, дополнительная память постоянна. Версия с символьным вводом остаётся базовой.

{1135_math_optimized.java}.

Accepted для соответствующих исходников: базовая версия 0.125 с / 532 КБ; эта версия 0.078 с / 364 КБ (посылка 11307457). В срезе от 2026-10-31 рейтинговая цель достигнута.
