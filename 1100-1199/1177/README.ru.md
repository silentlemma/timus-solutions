# 1177. Сопоставление строк с шаблонами SQL like

[Timus 1177](https://acm.timus.ru/problem.aspx?space=1&num=1177) · сложность 1249 · strings

Автор оригинальной задачи — Павел Атнашев; третье личное первенство УрГУ по программированию, Екатеринбург, 16 февраля 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Ответить на до 1000 вопросов вида `'строка' like 'шаблон'`. В шаблоне `%`
совпадает с любой последовательностью символов, `_` — с любым одним
символом, `[...]` — с любым одним символом из набора одиночных символов и
диапазонов `c1-c2`, а `[^...]` — с любым одним символом вне такого
набора; всё остальное совпадает само с собой. Строки и шаблоны длиной до
100 символов с кодами 32–255, кавычка внутри них записывается дважды.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк `'строка' like 'шаблон'`.

## Выходные данные

`YES` или `NO` для каждой строки.

## Примеры

### Пример 1

Ввод:

```
15
'abcde' like 'a'
'abcde' like 'a%'
'abcde' like '%a'
'abcde' like 'b'
'abcde' like 'b%'
'abcde' like '%b'
'25%' like '_5[%]'
'_52' like '[_]5%'
'ab' like 'a[a-cdf]'
'ad' like 'a[a-cdf]'
'ab' like 'a[-acdf]'
'a-' like 'a[-acdf]'
'[]' like '[[]]'
'''''' like '_'''
'U' like '[^a-zA-Z0-9]'
```

Вывод:

```
NO
YES
NO
NO
NO
NO
YES
YES
YES
YES
NO
YES
YES
YES
NO
```

## Решение

Читаем каждую строку как байты и убираем удвоение кавычек в обеих частях.
Затем идём по шаблону элемент за элементом, храня множество длин `i`,
таких что пройденная часть шаблона совпадает ровно с первыми `i` байтами
строки:

- байт или `_` переводит каждое `i` в `i + 1`, если следующий байт
  подходит;
- набор делает то же со своей проверкой принадлежности;
- `%` оставляет все длины, начиная с наименьшей в множестве.

Ответ — входит ли в множество полная длина в конце. `O(n·m)` на вопрос.

С синтаксисом набора нужна осторожность. После `[` необязательный `^`
обращает набор; дальше идут элементы до первой `]`. Элемент `a-b` —
диапазон, если третий символ есть и это не `]`, иначе `a` и `-` —
отдельные символы, так что в `[-acdf]` и `[a-]` есть дефис, а `[[]` —
набор из одной `[`. Скобка `[` без закрывающей `]` не совпадает ни с чем.

Тонкие места:

- символы с кодами больше 127 — одиночные байты, их нужно сравнивать и
  проверять в диапазонах как беззнаковые байты, а не декодировать как
  текст;
- пустой шаблон совпадает только с пустой строкой, и `%` тоже совпадает с
  ней;
- диапазон с концами в обратном порядке, например `[c-a]`, пуст.

Ответы сверены с отдельно написанным решением на 60 000 случайных
вопросов с кавычками, скобками, `^`, `-`, старшими байтами и
незакрытыми наборами.

## Особенности языков

- Python хранит множество длин как битовую маску в длинном целом с
  отдельной маской на каждый байт строки; остальные языки используют
  массив булевых значений на каждом шаге. Java читает ввод как Latin-1,
  чтобы каждый байт стал символом с тем же кодом.
