# 1105. Выбор отрезков, из которых ровно один покрывает две трети времени

[Timus 1105](https://acm.timus.ru/problem.aspx?space=1&num=1105) · сложность 824 · greedy

Автор оригинальной задачи — Дмитрий Филимоненков при участии Игоря Гольдберга; Tetrahedron Team Contest, май 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Промежуток времени `[T0, T1]` покрыт `N < 10 000` отрезками `[a_i, b_i]`,
`T0 ≤ a_i < b_i ≤ T1`: каждый момент промежутка лежит хотя бы в одном из
них. Выбрать набор отрезков так, чтобы суммарное время, покрытое ровно
одним выбранным отрезком, было не меньше `2/3 · (T1 − T0)`. Если такого
набора нет, вывести `0`. Все времена — вещественные числа.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`T0 T1`, затем `N`, затем `N` строк `a_i b_i`.

## Выходные данные

Количество выбранных отрезков, затем их номера (с 1), по одному в
строке, в любом порядке; либо одно число `0`.

## Проверка

Подходит любой правильный набор. Проверяющая программа проходит по концам
выбранных отрезков, измеряет время, покрытое ровно одним из них, и
сравнивает его с `2/3 · (T1 − T0)` с допуском `10^-6`.

## Примеры

### Пример 1

Ввод:

```
0.0 20.0
7
1.0 1.5
0.0 10.0
9.0 10.0
18.0 20.0
9.0 18.0
2.72 3.14
19.0 20.0
```

Вывод:

```
2
2
5
```

## Решение

Ответ существует всегда, так что `0` не выводится никогда. Сначала
сведём отрезки к цепочке классическим жадным покрытием: сортируем по
началу и от текущей точки каждый раз берём отрезок, который начинается
не позже неё и дотягивается дальше всех. В получившейся цепочке
`I_1, …, I_m` пересекаются только соседи: если бы `I_{k+2}` начинался
раньше конца `I_k`, жадность взяла бы его вместо `I_{k+1}`.

Тогда каждый момент промежутка лежит либо в одном отрезке цепочки, либо
в пересечении двух соседей. Уберём каждый третий отрезок цепочки, начиная
со сдвига 0, 1 или 2. Момент, покрытый одним отрезком, остаётся покрытым
один раз в двух сдвигах, сохраняющих этот отрезок; момент в пересечении
`I_k` и `I_{k+1}` покрыт один раз в двух сдвигах, убирающих один из них,
— оба они никогда не убираются. По трём сдвигам каждый момент учтён
дважды, поэтому лучший сдвиг сохраняет не меньше `2/3` промежутка. Его
время в одиночестве равно `Σ |I_k| − 2 Σ пересечений` по оставленным
отрезкам и оставленным парам соседей. `O(N log N)`.

Тонкие места:

- если выбрать все отрезки, можно не получить ничего: два одинаковых
  отрезка, покрывающих весь промежуток, никогда не бывают поодиночке;
- соседи в цепочке могут лишь касаться, с пересечением нулевой длины,
  что формула учитывает через `max(0, ·)`.

Ответы проверены перебором всех подмножеств с точными дробями на сотнях
маленьких случайных покрытий, который заодно подтвердил, что 2/3 всегда
достижимы, и проверяющей программой на всех тестах.

## Особенности языков

- Все пять решений читают времена как double; одинаковые строки во входе
  дают одинаковые значения, так что касающиеся концы везде сравниваются
  как равные.
