# 1105. 选出区间，使恰被一个区间覆盖的时间达到三分之二

[Timus 1105](https://acm.timus.ru/problem.aspx?space=1&num=1105) · 难度 824 · greedy

原题作者 Dmitry Filimonenkov，Igor Goldberg 参与，出自 2001 年 5 月 Tetrahedron Team Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

时间段 `[T0, T1]` 被 `N < 10 000` 个区间 `[a_i, b_i]` 覆盖，`T0 ≤ a_i < b_i ≤ T1`：时间段内的每一时刻至少落在其中一个区间里。选出一组区间，使恰好被一个所选区间覆盖的总时间不少于
`2/3 · (T1 − T0)`。如果不存在这样的一组，输出 `0`。所有时间都是实数。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`T0 T1`，然后是 `N`，然后是 `N` 行 `a_i b_i`。

## 输出

所选区间的个数，然后是它们的编号（从 1 开始），每行一个，顺序任意；或者只输出一个 `0`。

## 评测方式

接受任何一个正确的集合。检查程序扫描所选区间的端点，计算恰被其中一个区间覆盖的时间，并与 `2/3 · (T1 − T0)` 比较，容差为 `10^-6`。

## 样例

### 样例 1

输入：

```
0.0 20.0
7
1.0 1.5
0.0 10.0
9.0 10.0
18.0 20.0
9.0 18.0
2.72 3.14
19.0 20.0
```

输出：

```
2
2
5
```

## 解法

答案总是存在，所以从不输出 `0`。先用经典的贪心覆盖把区间化为一条链：按起点排序，从当前点出发，每次取起点不晚于它、延伸得最远的区间。得到的链
`I_1, …, I_m` 中只有相邻的区间相交：如果 `I_{k+2}` 在 `I_k` 结束之前开始，贪心就会选它而不是 `I_{k+1}`。

于是时间段内的每一时刻要么只在链上一个区间里，要么在两个相邻区间的交里。从链中每隔两个去掉一个区间，起始偏移取 0、1 或
2。只被一个区间覆盖的时刻，在保留该区间的两种偏移中仍只被覆盖一次；位于 `I_k` 与 `I_{k+1}`
交中的时刻，在去掉其中之一的两种偏移中只被覆盖一次，而两者永远不会同时被去掉。对三种偏移求和，每一时刻都被计了两次，所以最好的偏移至少保留时间段的
`2/3`。它的单独覆盖时间等于对保留的区间和保留的相邻对求 `Σ |I_k| − 2 Σ 交集长度`。`O(N log N)`。

注意事项：

- 把所有区间都选上可能一无所获：两个覆盖整个时间段的相同区间永远不会单独出现；
- 链上的相邻区间可能只是端点相接，交集长度为零，公式用 `max(0, ·)` 处理。

答案经过验证：在数百个随机的小覆盖上用精确分数枚举所有子集进行比对，这也确认了 2/3 总能达到；并在所有测试上用检查程序验证。

## 语言说明

- 五种解法都把时间读成 double；输入中相同的字符串得到相同的值，所以相接的端点在各处都按相等比较。
