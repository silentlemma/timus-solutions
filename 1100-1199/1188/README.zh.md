# 1188. 调整书架隔板以放下一本大书

[Timus 1188](https://acm.timus.ru/problem.aspx?space=1&num=1188) · 难度 2174 · geometry

原题作者 Elena Kryuchkova 和 Roman Elizarov，出自 2001–2002 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

宽 `XN`、高 `YN` 的壁龛里，在不同高度上有 `N ≤ 100` 块水平木板，每块架在两个
木钉上，木板中点位于两钉之间。一本宽 `XT`、高 `YT` 的大书必须完全立在某一块隔板
上，任何别的隔板或木钉都不能进入它的内部。每块隔板可以不动、平移、截短整数英寸、
把一个木钉挪到同一高度的另一处（同时可平移和截短），或者连同两个木钉一起拆除；
留下的每块隔板仍须在壁龛内正确地架在木钉上。先最小化挪动的木钉数（拆除算挪动
两个），再最小化截掉的英寸数（拆除算截掉整块木板）。

时间限制：1 秒。内存限制：64 MB。

## 输入

`XN YN XT YT`，`N`，然后对每块隔板给出高度、左端、长度以及两个木钉到左端的距离。
所有数都是不超过 1000 的整英寸。

## 输出

最少挪动的木钉数，然后是最少截掉的英寸数。

## 样例

### 样例 1

输入：

```
11 8 3 4
4
1 1 7 1 4
4 3 7 1 6
7 2 6 3 4
2 0 3 0 3
```

输出：

```
0 0
```

### 样例 2

输入：

```
11 8 4 6
4
1 1 7 1 4
4 3 7 1 6
7 2 6 3 4
2 0 3 0 3
```

输出：

```
1 3
```

## 解法

枚举放书的隔板 `i` 和每个整数位置 `x`。代价分成两部分：让隔板 `i` 托住书的代价，
以及严格位于书底与书顶之间的每块隔板离开条带 `(x, x + XT)` 的代价。这些部分互相
独立。

让隔板离开条带，就是把它的木板整个放进 `[0, x]` 或 `[x + XT, XN]`；记这个区域为
`[F, G]`。若不挪木钉，两个木钉 `a < b` 都必须在该区域内，而长为 `t` 的木板能架在
它们上面且中点在两钉之间，当且仅当 `b − a ≤ t ≤ min(2(b − F), G − F, 2(G − a))`。
所以截掉的长度是木板长度减去允许的最大 `t`（前提是它不小于 `b − a`）。若允许挪
一个木钉，新木钉总能让木板平衡，于是只需留下的那个木钉在区域内，截掉放不下的
部分即可：代价为一个木钉加 `max(0, 长度 − (G − F))`。拆除的代价是两个木钉和整块
木板的长度。三者中最优的就是这块隔板的代价。

托书的隔板永远不需要截短，因为更短的木板覆盖得更少。木钉不动时，木板可能的左端
构成一个区间，用加倍的坐标检查以保证中点是整数。否则只要木板长到能同时盖住书和
留下的木钉，挪一个木钉就可行。

每块隔板的清除代价只与 `x` 有关，所以把隔板按高度排序后，对隔板做前缀和即可一次
得到隔板 `i` 上方各板的总代价。代价存成“木钉数乘一百万加英寸数”，这样比较大小就
符合要求。`O(N·XN)`。

注意事项：

- 恰好与书顶同高或与书底同高的隔板可以碰到书，不需要代价；
- 移动后的木板必须仍在壁龛内，正是这一点迫使靠墙处截短；
- 与壁龛同宽的书在一侧不留任何空间，挡路的隔板只能去另一侧或被拆除。

答案已在 667 个随机书架和所有测试上与另一份独立编写的解答比对。

- 所有语言都使用同样的显式代价公式，以及对排序后隔板的同样前缀和。
