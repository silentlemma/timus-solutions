# 1134. 判断从写有 k − 1 和 k 的卡片上读出的数是否可能

[Timus 1134](https://acm.timus.ru/problem.aspx?space=1&num=1134) · 难度 197 · greedy

原题出自 2001 年 10 月 17–18 日在雷宾斯克举行的俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `n ≤ 1000` 张卡片；第 `k` 张卡片一面写着 `k − 1`，另一面写着 `k`。一个
孩子以某种顺序拿了 `m ≤ n` 张不同的卡片，每张读出一面。给出读出的 `m` 个
数，判断它们能否来自某种卡片与朝向的选择。

时间限制：1 秒。内存限制：64 MB。

## 输入

`n` 和 `m`，然后是 `m` 个数，每个在 `0` 到 `n` 之间。

## 输出

如果这样的读数可能，输出 `YES`，否则输出 `NO`。

## 样例

### 样例 1

输入：

```
5 4
2 0 1 2
```

输出：

```
NO
```

## 解法

问题在于能否给每个读数分配一张自己的卡片。数 `x` 出现在卡片 `x` 和
`x + 1` 上（`0` 只在卡片 1 上，`n` 只在卡片 `n` 上），所以每个读数可以使用
两张相邻卡片之一。统计每个数被读到的次数，从 `0` 往上处理。`x` 的读数先
占卡片 `x`，再占卡片 `x + 1`。先占较低的卡片是安全的：卡片 `x` 只写着
`x − 1` 和 `x`，而 `x − 1` 的所有读数都已安排好，后面再没有谁能用它。如果
`x` 的某个读数发现它的两张卡片都已被占，就不存在分配方案。`O(n + m)`。

注意事项：

- `0` 和 `n` 各自只出现在一张卡片上；
- 同一个数可能被读到多次，答案为 `YES` 时最多两次；
- 读数的顺序任意，只有各数的次数有关。

答案已在所有测试和 400 个随机情形上与 Kuhn 二分图匹配的结果比对。

- 所有语言都统计读数并做同样的一遍处理。
