# 1176. 一次环游铺设所有缺少的单向通道

[Timus 1176](https://acm.timus.ru/problem.aspx?space=1&num=1176) · 难度 335 · graphs

原题作者 Pavel Atnashev，出自 2002 年 2 月 16 日在叶卡捷琳堡举行的第三届乌拉尔国立大学个人程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N ≤ 1000` 个星球之间已有一些单向通道，以邻接矩阵给出。每一对有序的不同星球
之间都需要一条通道。铺设者从星球 `A` 出发，只能通过铺设新通道来移动，必须恰好
铺设所有缺少的通道并回到 `A`。缺少的通道不超过 32,000 条，且保证有解。按铺设
顺序输出通道。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N` 和 `A`，然后是 `N×N` 矩阵。

## 输出

铺设的通道，每行一对 `起点 终点`。

## 评测方式

只要顺序构成一条从 `A` 回到 `A`、恰好经过每条缺少的通道一次且不含其他通道的
路线，就被接受。

## 样例

### 样例 1

输入：

```
4 2
0 0 1 0
0 0 1 0
1 1 0 1
0 0 1 0
```

输出：

```
2 4
4 1
1 2
2 1
1 4
4 2
```

## 解法

铺设者的路线是一条恰好经过每条缺少通道一次的闭合路线，即缺少通道构成的图的
欧拉回路。题目保证有解，所以每个星球缺少的出通道和入通道一样多，并且有缺少通道
的星球都能从 `A` 到达。

Hierholzer 算法用显式栈构造回路。从栈顶星球沿未使用的通道继续走；当某星球没有
剩余通道时，把它弹出放进答案。弹出的星球按回路的逆序出现，每个支环都会被嵌入到
发现它的位置。`O(N² + M)`，主要时间花在读矩阵上。

注意事项：

- 矩阵有一百万个数，应当整体读入；
- 对角线不是缺少的通道；
- 如果什么都不缺，答案为空；
- 递归遍历可能深达 32,000 层，所以用显式栈。

每条输出的路线都已在 100 个随机小帝国以及有一千个星球、32,000 条缺少通道的生成
数据上与缺少的通道核对。

## 优化解法

C++、Go 和 Rust 版本为每个星球保存尚未建成的入向通道，在反向图上运行 Hierholzer 算法。出栈顺序反转了反向图上的回路，因此相邻出栈的星球已经给出所需方向的通道，可以直接输出。列表和栈中的星球编号只需 16 位。读取矩阵与构造路线的总时间仍为 O(N² + M)。

已通过评测的基础实现 [1176_graphs.java](1176_graphs.java), [1176_graphs.py](1176_graphs.py) 也满足快速版本的要求：在保存的比较快照中，时间和内存均符合前 15% 或前十名的排名收录规则。直接复用这些源文件，不创建相同副本。星号标记尚未达到该语言目标排名的版本。
