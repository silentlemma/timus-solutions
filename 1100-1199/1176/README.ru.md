# 1176. Проложить все недостающие односторонние каналы за один круговой маршрут

[Timus 1176](https://acm.timus.ru/problem.aspx?space=1&num=1176) · сложность 335 · graphs

Автор оригинальной задачи — Павел Атнашев; третье личное первенство УрГУ по программированию, Екатеринбург, 16 февраля 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Между `N ≤ 1000` планетами есть некоторые односторонние каналы, заданные
матрицей смежности. Канал нужен для каждой упорядоченной пары различных
планет. Прокладчик начинает у планеты `A`, перемещается только прокладывая
новый канал, должен проложить ровно недостающие и вернуться к `A`.
Недостающих каналов не больше 32 000, и решение гарантируется. Вывести
каналы в порядке прокладки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `A`, затем матрица `N×N`.

## Выходные данные

Проложенные каналы, по паре `откуда куда` в строке.

## Проверка

Принимается любой порядок, который образует путь от `A` обратно к `A`,
проходящий каждый недостающий канал ровно один раз и ничего больше.

## Примеры

### Пример 1

Ввод:

```
4 2
0 0 1 0
0 0 1 0
1 1 0 1
0 0 1 0
```

Вывод:

```
2 4
4 1
1 2
2 1
1 4
4 2
```

## Решение

Маршрут прокладчика — замкнутый путь по всем недостающим каналам, каждый
по разу: эйлеров цикл графа недостающих каналов. Решение обещано, так что у
каждой планеты недостающих каналов наружу столько же, сколько внутрь, а
планеты, у которых они есть, достижимы из `A`.

Алгоритм Хирхольцера строит цикл с явным стеком. С планеты на вершине
стека продолжаем идти по неиспользованным каналам. Когда у планеты их не
осталось, снимаем её в ответ. Снятые планеты выходят в обратном порядке
цикла, а каждая боковая петля вставляется туда, где её нашли.
`O(N² + M)`, основное время уходит на чтение матрицы.

Тонкие места:

- в матрице миллион чисел, поэтому ввод стоит читать целиком;
- диагональ — не недостающий канал;
- если ничего не недостаёт, ответ пустой;
- рекурсивный обход мог бы уйти на 32 000 уровней в глубину, отсюда явный
  стек.

Каждый выведенный маршрут сверен с недостающими каналами на 100 случайных
маленьких империях и на сгенерированных с тысячей планет и 32 000
недостающих каналов.

## Особенности языков

- C++ и Rust читают матрицу своими обычными средствами, Go — сканером
  слов, Java — самописным чтением байтов, а Python — одним разбиением
  всего ввода.
