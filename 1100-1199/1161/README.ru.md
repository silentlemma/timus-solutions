# 1161. Наименьший итог слияния существ по удвоенному среднему геометрическому

[Timus 1161](https://acm.timus.ru/problem.aspx?space=1&num=1161) · сложность 92 · greedy

Автор оригинальной задачи — Николай Дуров; северный подрегион полуфинала ACM ICPC Северо-Восточной Европы 2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У `N ≤ 100` существ целые веса до 10000. Два из них могут слиться в одно
весом `2·√(m₁·m₂)`, и слияния продолжаются, пока не останется одно.
Найти наименьший возможный итоговый вес с двумя знаками после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` весов.

## Выходные данные

Наименьший итоговый вес.

## Примеры

### Пример 1

Ввод:

```
2
72
50
```

Вывод:

```
120.00
```

### Пример 2

Ввод:

```
3
72
30
50
```

Вывод:

```
120.00
```

## Решение

Сначала сливаем два самых тяжёлых, затем результат со следующим по
тяжести и так далее до самого лёгкого. При любом порядке слияний каждый
вес оказывается внутри нескольких вложенных квадратных корней: вес,
слитый `k` раз, входит в результат как корень степени `2^k`, умноженный на
константы, зависящие только от формы слияний. Итоговый вес наименьший,
когда самые тяжёлые веса проходят через больше всего корней, и цепочка от
самого тяжёлого вниз делает именно это, отдавая самым большим весам
самые глубокие места. Сортировка и один проход: `O(N log N)`.

Тонкие места:

- при одном существе ответ — его вес;
- порядок важен: если сливать сначала лёгкие, результат тяжелее;
- вес никогда не превышает 40000, это далеко в пределах точности double.

Ответы сверены с перебором всех порядков слияний на 150 случайных
колониях до семи существ.
