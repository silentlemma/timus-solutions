# 1161. 按两倍几何平均合并生物后的最小结果

[Timus 1161](https://acm.timus.ru/problem.aspx?space=1&num=1161) · 难度 92 · greedy

原题作者 Nick Durov，出自 2001 年 ACM ICPC 东北欧区域赛北部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N ≤ 100` 个生物的重量是不超过 10000 的整数。两个生物可以合并成一个重量为
`2·√(m₁·m₂)` 的生物，合并一直进行到只剩一个。求最终重量的最小可能值，保留
两位小数。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后是 `N` 个重量。

## 输出

最小的最终重量。

## 样例

### 样例 1

输入：

```
2
72
50
```

输出：

```
120.00
```

### 样例 2

输入：

```
3
72
30
50
```

输出：

```
120.00
```

## 解法

先合并最重的两个，再把结果与次重的合并，依此类推直到最轻的。无论按什么顺序
合并，每个重量最后都处在若干层嵌套的平方根里：被合并 `k` 次的重量以它的
`2^k` 次方根进入结果，再乘以只与合并结构有关的常数。最重的重量被开方次数最多
时结果最小，而从最重往下的链恰好做到这一点，把最大的重量放在最深的位置。
排序加一遍扫描：`O(N log N)`。

注意事项：

- 只有一个生物时，答案就是它的重量；
- 顺序很重要：先合并轻的会得到更重的结果；
- 重量永远不超过 40000，远在双精度范围之内。

答案已在 150 个最多七个生物的随机群体上，与枚举所有合并顺序的结果比对。

## 各语言说明

- 所有语言以同样方式排序和折叠。
- Java 通过 `BigDecimal` 以“五成双”方式舍入结果，与 C 的 `printf` 一致。
