# 1182. 由互相认识的人组成、规模尽量相等的两个队

[Timus 1182](https://acm.timus.ru/problem.aspx?space=1&num=1182) · 难度 507 · graphs

原题作者 Vladimir Kotov 和 Roman Elizarov，出自 2001–2002 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`2 ≤ N ≤ 100` 个人各自列出认识的人；认识不一定是相互的。把所有人分成两个
非空的队，使每个队里每个人都认识队里其他每个人，并且两队人数尽量接近；或者
说明无法这样分。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后对每个人给出他认识的人的列表，以 0 结尾。

## 输出

`No solution`，或者两行，每行是一个队的人数和成员。

## 评测方式

只要两队都非空、覆盖所有人、都由互相认识的人组成，并且人数差尽可能小，就被
接受；最佳差值由检查程序从保存的答案中取得。

## 样例

### 样例 1

输入：

```
5
3 4 5 0
1 3 5 0
2 1 4 5 0
2 3 5 0
1 2 3 4 0
```

输出：

```
No solution
```

### 样例 2

输入：

```
5
2 3 5 0
1 4 5 3 0
1 2 5 0
1 2 3 0
4 3 2 1 0
```

输出：

```
3 1 3 5
2 2 4
```

## 解法

若两人中至少有一人不认识另一人，就称他们为陌生人。陌生人必须在不同的队，所以
陌生人图必须是二分图，可以用广度优先染色检查；出现奇环就是 `No solution`。
这个图的每个连通分量有两部分，它们必须分到不同的队，方向任选。不同分量中的人
都互相认识，所以各分量的选择可以任意组合。

剩下的是一个背包：`reach[k][s]` 表示前 `k` 个分量能否让第一队恰好有 `s` 人，并
记下所选的那部分。取最接近 `N/2` 的可达 `s`，倒推得到两个队。`O(N²)`。

注意事项：

- 输入中的认识是单向的，只有双方都列出对方才算互相认识；
- 只有一个人的分量可以去任一队，这正是能让人数持平的原因；
- 两队自动非空：含陌生人的分量两部分都非空，单独的人则由背包分配。

答案已在 300 组至多 41 人的随机数据（其中十二组无解）上与另一份独立编写的解答
比对，输出的每种分法都通过了检查程序。

## 优化解法

Go、Rust 保持不兼容补图二分与分量方向背包；必须双向认识才兼容。Go 每行两份 64 位字，Rust 一份 u128。BFS 与本色掩码相交查冲突，以末尾零计数只枚举未访问邻居。每分量保存两成员掩码和大小 a,b；可达大小更新 (old<<a)|(old<<b)，每层保留一个小历史掩码。交换队名可令第一队人数 s≤floor(N/2)。人数差为 N−2s，所以取最大的可达 s≥1。若不存在就无法分成两支非空队伍。查上一层历史恢复方向。N≤100 适合 128 位。时间 O(N²)，由输入及配对检查主导；掩码代替布尔与整数矩阵。保留简单版，其余三种语言复用达标基础版。

已通过评测的基础实现 [1182_graphs.cpp](1182_graphs.cpp), [1182_graphs.java](1182_graphs.java), [1182_graphs.py](1182_graphs.py) 也满足快速版本的要求：在保存的比较快照中，时间和内存均符合前 15% 或前十名的排名收录规则。直接复用这些源文件，不创建相同副本。星号标记尚未达到该语言目标排名的版本。
