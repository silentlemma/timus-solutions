# 1131. 用 K 根线把程序复制到 N 台电脑，每根线每小时复制一份

[Timus 1131](https://acm.timus.ru/problem.aspx?space=1&num=1131) · 难度 77 · math

原题作者 Stanislav Vasiliev 和 Alexander Mironenko，出自 2001 年 10 月 21 日第六届乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

程序在 `N` 台电脑中的一台上。一小时内，已有程序的电脑可以通过一根线把它
复制到另一台电脑上，一共有 `K` 根线。求所有 `N` 台电脑都有程序所需的最少
小时数，`1 ≤ N, K ≤ 10⁹`。

时间限制：0.25 秒。内存限制：64 MB。

## 输入

一行中的 `N` 和 `K`。

## 输出

最少的小时数。

## 样例

### 样例 1

输入：

```
8 3
```

输出：

```
4
```

## 解法

一小时内有 `min(have, K)` 台新电脑得到程序，其中 `have` 是已经有程序的
电脑数；每小时尽可能多地复制显然最优。当 `have < K` 时每台电脑都在复制，
数量翻倍；这最多约 30 小时。一旦 `have ≥ K`，每小时恰好增加 `K` 台，所以
剩下的 `N − have` 台还需要 `⌈(N − have) / K⌉` 小时。若 `have` 已经达到
`N`，翻倍阶段提前结束。`O(log min(N, K))`。

注意事项：

- `N = 1` 时不需要时间；
- `K = 1` 且 `N = 10⁹` 时答案接近 `10⁹`，所以翻倍之后的小时数必须用除法
  计算，不能逐小时累加；
- 翻倍过程中数量可能超过 `2³¹`，因此使用 64 位整数。

答案已在所有测试上与按小时数二分查找的结果比对，并对所有 `N < 200`、
`K < 70` 与逐小时模拟比对。
