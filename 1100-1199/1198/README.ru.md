# 1198. Какие сенаторы могут провести закон в одиночку

[Timus 1198](https://acm.timus.ru/problem.aspx?space=1&num=1198) · сложность 488 · graphs

Автор оригинальной задачи: Никита Рыбак.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У каждого из `N ≤ 2000` сенаторов есть компромат на некоторых других.
Сенатор, которому нужен закон, обзванивает всех, на кого хранит
компромат, и просит поддержать закон и сделать такие же звонки. Закон
проходит, если его поддержали все сенаторы. Найти всех сенаторов, которые
могут так провести закон в одиночку.

Ограничение времени: 1.5 секунды. Ограничение памяти: 96 МБ.

## Входные данные

`N`, затем по строке на сенатора со списком тех, на кого этот сенатор
хранит компромат, в конце `0`.

## Выходные данные

Номера таких сенаторов по возрастанию в одной строке, затем `0`; если их
нет — просто `0`.

## Примеры

### Пример 1

Ввод:

```
5
3 2 0
0
4 5 0
1 5 0
2 0
```

Вывод:

```
1 3 4 0
```

## Решение

Проведём ребро от каждого сенатора ко всем, на кого этот сенатор хранит
компромат; ответ — множество вершин, из которых достижимы все вершины.

Запускаем поиск из каждой ещё не отмеченной вершины, и каждый поиск
отмечает только неотмеченные вершины. Ничто отмеченное раньше не может
достичь корня более позднего поиска, иначе тот уже был бы отмечен, поэтому
корень последнего поиска лежит в компоненте сильной связности, в которую
не ведёт ни одна другая компонента. Если этот корень достигает не всех, то
не достигает всех никто: кто достигает всех, достигает и корня, а значит,
лежит в его компоненте. Если достигает, то ответ — ровно вершины, из
которых достижим корень; их находит ещё один поиск по обратным рёбрам.
`O(N + M)` для `M` записей компромата, до примерно `4·10⁶`.

Тонкие места:

- вход бывает почти 20 МБ, так что медленное чтение обходится дороже
  работы с графом;
- списки смежности из `4·10⁶` элементов нужно хранить компактно, 32-битными
  числами в плоских массивах, чтобы уложиться в память с запасом;
- сенатор может встретиться в собственном списке или дважды в одном
  списке;
- если подходящих нет, вывод — один `0`.

Ответы сверены с отдельно написанным решением на основе транзитивного
замыкания битсетами на 300 маленьких случайных графах и на всех тестах.

## Особенности языков

- C++, Go, Java и Rust хранят оба графа плоскими массивами со смещениями,
  обратный строится подсчётом.
- Python хранит список каждого сенатора как большое целое, по байту на
  сенатора, заполняя его через `bytearray`, так что вся работа по
  отдельным записям идёт во встроенных функциях; поиски стоят несколько
  операций над целыми множествами на сенатора, а обратный граф получается
  через `zip` по строкам. Вход читается целиком сразу — здесь это намного
  быстрее построчного чтения.
