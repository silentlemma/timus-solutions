# 1159. 用给定的砖块围出的最大面积

[Timus 1159](https://acm.timus.ru/problem.aspx?space=1&num=1159) · 难度 755 · geometry

原题作者 Nick Durov，出自 2001 年 ACM ICPC 东北欧区域赛北部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N` 块直的砖块（`3 ≤ N ≤ 100`），长度为不超过 100 的整数，必须全部首尾相接地
用作一道封闭围栏的边。求围栏能围出的最大面积，保留两位小数；若无法建成
围栏，输出 `0.00`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后是 `N` 个长度。

## 输出

最大面积，保留两位小数。

## 样例

### 样例 1

输入：

```
4
10
5
5
4
```

输出：

```
28.00
```

## 解法

给定边长的多边形存在，当且仅当最长边小于其余边之和。在所有具有这些边长的
多边形中，面积最大的是内接于圆的那个（经典结论；边的顺序不影响它的面积）。
所以任务就是找出这个圆。

半径为 `R` 的圆中，长为 `l` 的边从圆心看去的角为 `2·asin(l / 2R)`。若圆心在
多边形内部，所有边的角之和为 `2π`。若在外部，它位于最长边之外，该边的角等于
其余所有边的角之和。在最小可能的半径（最长边的一半）处，角之和不小于 `2π`
当且仅当圆心在内部；两种情况下相应方程关于 `R` 都只有一个根，用双精度二分
求出。面积是从圆心出发的各三角形 `R²·sin(角)/2` 之和；圆心在外部时要减去
最长边对应的三角形。

注意事项：

- 最长边等于其余边之和时围栏是扁的，面积为 `0.00`；
- 圆心在外部时，最长边的三角形要减去而不是加上；
- 因舍入误差，`asin` 的参数要截断到 1。

答案已在 300 个输入上分别与随机三角形的海伦公式、随机四边形的婆罗摩笈多
公式比对，等长砖块则与正多边形面积公式比对。

## 各语言说明

- 所有语言使用同样的二分。
- Java 通过 `BigDecimal` 以“五成双”方式舍入面积，与 C 的 `printf` 一致。
