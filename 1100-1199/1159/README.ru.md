# 1159. Наибольшая площадь, которую можно огородить забором из данных блоков

[Timus 1159](https://acm.timus.ru/problem.aspx?space=1&num=1159) · сложность 755 · geometry

Автор оригинальной задачи — Николай Дуров; северный подрегион полуфинала ACM ICPC Северо-Восточной Европы 2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N` прямых блоков, `3 ≤ N ≤ 100`, целой длины до 100, нужно все
использовать, ставя встык, как стороны замкнутого забора. Найти
наибольшую площадь, которую может огородить забор, с двумя знаками после
точки, или `0.00`, если забор построить нельзя.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` длин.

## Выходные данные

Наибольшая площадь с двумя знаками после точки.

## Примеры

### Пример 1

Ввод:

```
4
10
5
5
4
```

Вывод:

```
28.00
```

## Решение

Многоугольник с данными сторонами существует ровно тогда, когда самая
длинная сторона короче суммы остальных. Среди всех многоугольников с этими
сторонами наибольшую площадь имеет вписанный в окружность (классический
результат; порядок сторон на его площадь не влияет). Так что задача —
найти эту окружность.

Сторона длины `l` в окружности радиуса `R` видна из центра под углом
`2·asin(l / 2R)`. Если центр внутри многоугольника, углы всех сторон дают
в сумме `2π`. Если снаружи, то он за самой длинной стороной, и угол этой
стороны равен сумме углов всех остальных. При наименьшем возможном
радиусе, половине самой длинной стороны, углы дают в сумме не меньше
`2π` ровно тогда, когда центр внутри; в обоих случаях у нужного уравнения
один корень по `R`, и его находит бинарный поиск на double. Площадь —
сумма треугольников от центра, `R²·sin(угол)/2`, причём треугольник
самой длинной стороны вычитается, если центр снаружи.

Тонкие места:

- если самая длинная сторона равна сумме остальных, забор плоский и
  площадь `0.00`;
- при центре снаружи треугольник самой длинной стороны нужно вычесть, а
  не прибавить;
- аргумент `asin` обрезается до 1 из-за ошибок округления.

Ответы сверены с формулой Герона на случайных треугольниках и с формулой
Брахмагупты на случайных четырёхугольниках (300 входов), а равные блоки —
с формулой правильного многоугольника.

## Особенности языков

- Во всех языках один и тот же бинарный поиск.
- Java округляет площадь через `BigDecimal` с округлением половин к
  чётному, как `printf` в C.
