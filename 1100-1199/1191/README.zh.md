# 1191. 警察能否抓住不断换乘电车的小偷

[Timus 1191](https://acm.timus.ru/problem.aspx?space=1&num=1191) · 难度 248 · math

原题作者 Leonid Volkov，出自 2002 年 3 月 2 日第五届中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

小偷比警察领先 `L` 分钟，两人跑得一样快。在 `N` 个车站中的每一个，小偷都等一条
线路的电车（每 `Ki` 分钟一班，相位未知），坐到下一站；警察跟到同一站，坐同一线路
的下一班电车，若发现小偷还在等车就将其逮捕。所有电车速度相同。判断警察是否有
可能在 `N` 段乘车结束前抓住小偷。

时间限制：1 秒。内存限制：64 MB。

## 输入

`L` 和 `N`，然后是 `K1 … KN`，都是小于 100 的整数。

## 输出

若有可能抓住，输出 `YES`，否则输出 `NO`。

## 样例

### 样例 1

输入：

```
8 3
6 4 3
```

输出：

```
NO
```

### 样例 2

输入：

```
15 4
7 3 13 6
```

输出：

```
YES
```

## 解法

只有两人之间的时间差有意义，而它只在车站发生变化。若小偷到站时差为 `g` 分钟、
等了 `w` 分钟（`0 ≤ w < K`，取决于时刻表），警察在他之后 `g` 分钟到站。若
`w ≥ g`，小偷还在站上。否则警察坐他到站后的第一班车离开，比小偷那班晚整数个
间隔，所以新的时间差是 `K` 的倍数且不小于 `g − w`。取 `w = g mod K` 得到最小的
新时间差 `g − g mod K`。

时间差更小以后不会更差，因为 `g − g mod K` 随 `g` 单调不减。所以跟踪最幸运的
情况：每到一站把时间差换成 `g − g mod K`，当且仅当某站时间差变为 0（即小于该站
的间隔）时有可能抓住。`O(N)`。

注意事项：

- 时间差等于间隔时抓不到，只是保持不变；
- 1 分钟的间隔永远不改变时间差；
- 即使时间差是某个间隔的倍数，后面的车站仍可能把它缩小。

答案已在 300 次随机追逐和所有测试上与另一份独立编写的解答比对。
