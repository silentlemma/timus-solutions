# 1191. Может ли полицейский догнать вора, пересаживающегося с трамвая на трамвай

[Timus 1191](https://acm.timus.ru/problem.aspx?space=1&num=1191) · сложность 248 · math

Автор оригинальной задачи — Леонид Волков; пятое командное первенство школьников по программированию, 2 марта 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Вор опережает полицейского на `L` минут, бегут они с одной скоростью. На
каждой из `N` остановок вор ждёт трамвая маршрута, который ходит каждые
`Ki` минут с неизвестным сдвигом, и едет на нём до следующей остановки;
полицейский прибегает на ту же остановку и садится на следующий трамвай
того же маршрута, арестовывая вора, если застаёт его ещё ждущим. Все
трамваи едут с одной скоростью. Определить, может ли полицейский поймать
вора до того, как закончатся `N` поездок.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`L` и `N`, затем `K1 … KN`, все целые меньше 100.

## Выходные данные

`YES`, если поимка возможна, иначе `NO`.

## Примеры

### Пример 1

Ввод:

```
8 3
6 4 3
```

Вывод:

```
NO
```

### Пример 2

Ввод:

```
15 4
7 3 13 6
```

Вывод:

```
YES
```

## Решение

Важен только разрыв между ними, и меняется он только на остановках. Если
вор приходит на остановку с разрывом `g` минут и ждёт `w` минут
(`0 ≤ w < K`, в зависимости от расписания), полицейский приходит через
`g` минут после него. Если `w ≥ g`, вор ещё там. Иначе полицейский уезжает
на первом трамвае после своего прихода, через целое число интервалов
после трамвая вора, так что новый разрыв — кратное `K`, не меньшее
`g − w`. Выбор `w = g mod K` даёт наименьший возможный новый разрыв
`g − g mod K`.

Меньший разрыв дальше никогда не хуже, поскольку `g − g mod K` только
растёт с `g`. Значит, следим за самым удачным случаем: на каждой
остановке заменяем разрыв на `g − g mod K`, и поимка возможна ровно
тогда, когда разрыв на какой-то остановке становится 0, то есть когда он
меньше тамошнего интервала. `O(N)`.

Тонкие места:

- разрыв, равный интервалу, не даёт поимки, он просто сохраняется;
- интервалы в 1 минуту никогда не меняют разрыв;
- даже когда разрыв кратен интервалу, следующие остановки ещё могут его
  сократить.

Ответы сверены с отдельно написанным решением на 300 случайных погонях и
на всех тестах.
