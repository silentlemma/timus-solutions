# 1160. 连通所有集线器并使最长的电缆尽可能短

[Timus 1160](https://acm.timus.ru/problem.aspx?space=1&num=1160) · 难度 146 · dsu

原题作者 Andrew Stankevich，出自 2001 年 ACM ICPC 东北欧区域赛北部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N ≤ 1000` 个集线器可以用 `M ≤ 15000` 条给定长度的可选电缆相连。选出一些电缆，
使每个集线器都能直接或经由其他集线器连到其余所有集线器，并使所选电缆中最长
的那条尽可能短。输出这个长度，然后输出电缆数和这些电缆。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N` 和 `M`，然后 `M` 行，每行是两个集线器和一个长度。

## 输出

最长电缆的长度、电缆数 `P`，然后是 `P` 对集线器。

## 评测方式

只要方案用可选电缆连通所有集线器，且其最长电缆是可能的最小值，就被接受。
检查程序自己通过对长度二分并检查连通性求出这个最小长度，并验证输出的长度和
方案。

## 样例

### 样例 1

输入：

```
4 6
1 2 1
1 3 1
1 4 2
2 3 1
3 4 1
2 4 1
```

输出：

```
1
3
1 2
1 3
3 4
```

## 解法

Kruskal 算法从最短的电缆开始构造生成树，若电缆两端已经连通就跳过，用并查集来
判断。它构造的是最小生成树，而最小生成树同时使最长边最小：当 Kruskal 算法加入
最后一条、也是最长的边 `e` 时，比 `e` 短的电缆让集线器至少分成两组，所以任何
连通方案都需要一条不短于 `e` 的电缆。答案就是最后加入的边的长度，树的 `N − 1`
条电缆就是一个合法方案。`O(M log M)`。

注意事项：

- 方案不必是树，任何最长电缆最小的方案都被接受；
- 必须连到每个集线器，所以答案取 Kruskal 最后加入的边，而不是最后考察的边；
- 长度相等无需特殊处理。

答案已用检查程序在所有测试和 60 个随机网络上验证。
