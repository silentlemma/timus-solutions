# 1152. Наименьший урон от монстров на балкончиках вокруг зала

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N` балкончиков, `3 ≤ N ≤ 20`, стоят по кругу, на каждом от 1 до 100
монстров. Один залп уничтожает три соседних балкончика (`N`-й соседствует
с первым). После каждого залпа каждый оставшийся в живых монстр наносит
одну единицу урона. Залпы продолжаются, пока монстры не кончатся. Найти
наименьший общий урон.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем количества монстров на балкончиках.

## Выходные данные

Наименьший общий урон.

## Примеры

### Пример 1

Ввод:

```
7
3 4 2 2 1 4 1
```

Вывод:

```
9
```

## Решение

Состояние — множество ещё занятых балкончиков, маска из `N` битов. Из
состояния залп по балкончику `i` очищает `i − 1`, `i` и `i + 1` и
оставляет множество `rest`; он стоит количество монстров в `rest`, а
дальше следует лучшая игра из `rest`. Значит, при `damage(∅) = 0`

`damage(mask) = min по залпам, которые во что-то попадают, alive(rest) + damage(rest)`.

Важны только состояния, достижимые из полного круга: их очищенные части —
объединения отрезков из трёх соседей, и при `N = 20` их всего 15126.
Рекурсия с запоминанием посещает только их, по `N` залпов на каждое, а
глубина не больше `⌈N / 3⌉`. Залпы, не задевающие ни одного занятого
балкончика, пропускаются: они никогда не помогают.

Тонкие места:

- круг замкнут, так что залп по первому балкончику очищает и `N`-й;
- урон после последнего залпа равен нулю — никого не осталось;
- порядок залпов важен, потому что большие группы выгодно убирать рано.

Ответы сверены с таблицей снизу вверх по всем `2^N` подмножествам на 120
случайных входах до 13 балкончиков и на всех тестах с 20.
