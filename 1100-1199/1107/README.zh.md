# 1107. 把相差一个元素的多重集分开

[Timus 1107](https://acm.timus.ru/problem.aspx?space=1&num=1107) · 难度 424 · math

原题作者 Dmitry Filimonenkov，出自 2001 年 5 月 Tetrahedron Team Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `K ≤ 50 000` 个互不相同的多重集，元素是编号为 `1..N` 的物品，每个多重集有 1 到 100
个元素；元素的顺序无关紧要，重复则有意义。如果一个多重集删去一个元素、或把一个元素换成另一种物品后得到另一个，就称这两个多重集相似。给每个多重集分配
`M` 个组（`0 < N < M ≤ 100`）中的一个，使任意两个相似的多重集不在同一组；如果做不到，输出 `NO`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N K M`，然后是 `K` 行：多重集的大小及其元素，用单个空格分隔。

## 输出

`YES`，然后按输入顺序每行给出一个多重集的组号；或者 `NO`。

## 评测方式

接受任何一个正确的分配。检查程序把每个多重集哈希为其元素的随机 64 位权值之和：与另一个相差一次删除的多重集，或相差一次替换的两个多重集，都会共享某个去掉一个元素后的多重集的哈希值，这样的一对不能在同一组。

## 解法

答案总是 `YES`：把元素和为 `S` 的多重集放进第 `S mod (N + 1) + 1` 组，由于 `M ≥ N + 1`，这一组存在。删去一个元素使和改变它的值，即
`1..N`；把一种物品换成另一种使和改变一个介于 `−(N − 1)` 与 `N − 1` 之间的非零量。两种改变都不是 `N + 1`
的倍数，所以相似的多重集总是分到不同的组。`O(总大小)`。

注意事项：

- 输入最多有五百万个数，读入必须快：普通的 `scanf` 或为每个数建立记号列表，要么太慢，要么太占内存；
- 相同的多重集会落在同一组，但输入保证它们互不相同。

答案在所有测试上都用哈希检查程序验证过；检查程序本身在一百个小输入上，用正确的和随机的分配与逐对比较所有多重集的检查做过对照。

## 语言说明

- C++、Go 和 Java 用各自的缓冲数字读取器读取字节。
- Python 一次读入全部输入并按行切分；把五百万个数全部切成记号列表会超出 64 MB，而逐行读取要慢一倍。
