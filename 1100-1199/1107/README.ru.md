# 1107. Разделение мультимножеств, отличающихся одним элементом

[Timus 1107](https://acm.timus.ru/problem.aspx?space=1&num=1107) · сложность 424 · math

Автор оригинальной задачи — Дмитрий Филимоненков; Tetrahedron Team Contest, май 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `K ≤ 50 000` различных мультимножеств из предметов с номерами
`1..N`, в каждом от 1 до 100 элементов; порядок элементов не важен,
повторы важны. Два мультимножества похожи, если одно получается из
другого удалением одного элемента или заменой одного элемента на другой
предмет. Назначить каждому мультимножеству одну из `M` групп
(`0 < N < M ≤ 100`) так, чтобы никакие два похожих мультимножества не
оказались в одной группе, или вывести `NO`, если это невозможно.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N K M`, затем `K` строк: размер мультимножества и его элементы через
одиночные пробелы.

## Выходные данные

`YES`, затем группа каждого мультимножества, по одной в строке, в порядке
ввода; либо `NO`.

## Проверка

Подходит любое правильное распределение. Проверяющая программа хеширует
каждое мультимножество суммой случайных 64-битных весов его элементов:
мультимножество, отстоящее от другого на одно удаление, или два
мультимножества, отличающиеся одной заменой, тогда имеют общий хеш
мультимножества без одного элемента, и такая пара не должна попасть в
одну группу.

## Решение

Ответ всегда `YES`: мультимножество с суммой элементов `S` отправляем в
группу `S mod (N + 1) + 1`, которая существует, потому что `M ≥ N + 1`.
Удаление элемента меняет сумму на его значение, `1..N`; замена одного
предмета другим меняет её на ненулевую величину от `−(N − 1)` до
`N − 1`. Ни одно изменение не кратно `N + 1`, поэтому похожие
мультимножества всегда получают разные группы. `O(суммарный размер)`.

Тонкие места:

- во входе до пяти миллионов чисел, поэтому читать нужно быстро:
  обычный `scanf` или список токенов на каждое число слишком медленны или
  слишком велики;
- одинаковые мультимножества попали бы в одну группу, но вход гарантирует,
  что все они различны.

Ответы проверены хеширующей проверяющей программой на всех тестах; саму
её сравнили с попарной проверкой всех мультимножеств на сотне маленьких
входов, с правильными и случайными распределениями.

## Особенности языков

- C++, Go и Java читают байты своими буферизованными чтецами чисел.
- Python читает весь вход сразу и делит его на строки; список токенов из
  всех пяти миллионов чисел не поместился бы в 64 МБ, а чтение по строкам
  вдвое медленнее.
