# 1143. Кратчайший путь через все вершины выпуклого многоугольника

[Timus 1143](https://acm.timus.ru/problem.aspx?space=1&num=1143) · сложность 589 · dp

Оригинальная задача — отборочное соревнование в команду Вьетнама на IOI.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N ≤ 200` лагерей стоят в вершинах выпуклого многоугольника, заданных
против часовой стрелки вещественными координатами. Найти длину
кратчайшего пути, который начинается в любом лагере и проходит все
лагеря, и вывести её с тремя знаками после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк с координатами вершин.

## Выходные данные

Длина кратчайшего пути с тремя знаками после точки.

## Примеры

### Пример 1

Ввод:

```
4
50.0 1.0
5.0 1.0
0.0 0.0
45.0 0.0
```

Вывод:

```
50.211
```

## Решение

Кратчайший путь никогда не пересекает себя: если два его отрезка
пересекаются, разворот части между ними заменяет их двумя отрезками,
которые по неравенству треугольника вместе короче. Для точек в выпуклом
положении из этого следует сильное утверждение: в каждый момент
посещённые вершины образуют дугу многоугольника, а путь стоит на одном её
конце. Иначе пути пришлось бы перепрыгнуть через дугу на другую сторону,
и какой-то более поздний отрезок пересёк бы более ранний.

Поэтому состояние — дуга `(i, length)` и конец, где стоит путь. Дуга
растёт на одну вершину с любой стороны, из любого конца, что даёт четыре
перехода. Пусть `at[i]` и `at_end[i]` — кратчайшие пути по дуге,
начинающейся в вершине `i`, стоящие в её первой или последней вершине.
Начинаем со всех дуг длины 1 со стоимостью 0, растим их до длины `N` и
берём наименьшее значение. `O(N²)` по времени, `O(N)` памяти на длину.

Тонкие места:

- обход по кругу не всегда лучший: в длинном узком многоугольнике путь
  идёт зигзагом между двумя длинными сторонами;
- при `N = 1` ответ `0.000`;
- дуги переходят через конец списка вершин, поэтому индексы берутся по
  модулю `N`;
- ответ выводится ровно с тремя знаками после точки.

Ответы сверены с перебором Хелда — Карпа по всем подмножествам, который
не использует выпуклость, на 120 случайных многоугольниках до 11
вершин, в том числе на узких эллипсах и на вершинах, скученных на
короткой дуге.

## Особенности языков

- Во всех языках одна и та же динамика по дугам с двумя массивами на
  длину.
- Java форматирует ответ с `Locale.US`, чтобы разделителем была точка.
