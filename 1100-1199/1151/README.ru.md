# 1151. Определение положения радиомаяков по расстояниям в метрике максимума

[Timus 1151](https://acm.timus.ru/problem.aspx?space=1&num=1151) · сложность 1041 · geometry

Оригинальная задача — командный чемпионат Урала по программированию, Пермь, апрель 2001 года, английский тур.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Не больше 10 радиомаяков стоят в целых точках с координатами от 1 до
200. Из `M ≤ 20` контрольных точек с известными координатами измерены
расстояния до некоторых маяков, где расстояние между `A` и `B` равно
`max(|Ax − Bx|, |Ay − By|)`. Для каждого маяка в порядке возрастания его
идентификатора вывести его положение, если всем его измерениям
соответствует ровно одна точка поля, и `UNKNOWN` иначе. Измерения
непротиворечивы.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`M`, затем `M` строк вида `X,Y:ID-R,ID-R,…`: контрольная точка, затем
идентификаторы маяков с расстояниями.

## Выходные данные

По строке на маяк: `ID:x,y` или `ID:UNKNOWN`.

## Примеры

### Пример 1

Ввод:

```
2
15,15:16-7,5-3
10,10:5-2,16-2
```

Вывод:

```
5:12,12
16:UNKNOWN
```

## Решение

В метрике максимума точки на расстоянии ровно `r` от контрольной точки
образуют границу квадрата со стороной `2r` вокруг неё — не больше `8r`
клеток — или саму точку при `r = 0`. У каждого маяка есть хотя бы одно
измерение, так что кандидаты — клетки первого такого квадрата, лежащие в
поле; каждая остаётся, только если она на нужном расстоянии от всех
остальных точек, измерявших этот маяк. Если остался ровно один кандидат,
это ответ, иначе положение `UNKNOWN`. При не больше 1600 кандидатах и 20
измерениях на маяк это совсем немного.

В строках ввода перемешаны запятые, двоеточия и минусы; все они лишь
разделяют числа, поэтому строка читается как список её последовательностей
цифр: контрольная точка, затем пары из идентификатора и расстояния.

Тонкие места:

- граница поля обрезает квадрат, и часто именно это делает ответ
  единственным;
- маяк может измеряться из нескольких точек, а точка может измерять
  несколько маяков;
- маяки выводятся по возрастанию идентификатора, а не в порядке
  появления;
- расстояние `0` ставит маяк в контрольную точку.

Ответы сверены с проверкой каждой клетки поля на всех тестах и на 80
случайных входах.

## Особенности языков

- Во всех языках фильтруются одни и те же квадраты. C++, Go и Java
  выделяют последовательности цифр вручную, Python — регулярным
  выражением, а Rust разрезает строку по каждому нецифровому символу.
