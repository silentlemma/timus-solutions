# 1151. 由最大值度量下的距离确定无线电信标位置

[Timus 1151](https://acm.timus.ru/problem.aspx?space=1&num=1151) · 难度 1041 · geometry

原题出自 2001 年 4 月在彼尔姆举行的乌拉尔团体程序设计锦标赛英语轮。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

最多 10 个无线电信标位于坐标在 1 到 200 之间的整点上。从 `M ≤ 20` 个坐标已知的
控制点测量了到部分信标的距离，`A` 与 `B` 之间的距离为
`max(|Ax − Bx|, |Ay − By|)`。按标识符递增顺序，对每个信标：若场地上恰有一个点
满足它的所有测量，就输出该位置，否则输出 `UNKNOWN`。测量结果互不矛盾。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`M`，然后 `M` 行，格式为 `X,Y:ID-R,ID-R,…`：一个控制点，然后是信标标识符及其
距离。

## 输出

每个信标一行：`ID:x,y` 或 `ID:UNKNOWN`。

## 样例

### 样例 1

输入：

```
2
15,15:16-7,5-3
10,10:5-2,16-2
```

输出：

```
5:12,12
16:UNKNOWN
```

## 解法

在最大值度量下，与控制点距离恰为 `r` 的点构成以它为中心、边长 `2r` 的正方形的
边界——最多 `8r` 个格子——或在 `r = 0` 时就是该点本身。每个信标至少有一次
测量，所以候选点就是第一个这样的正方形上位于场地内的格子；只有与测过该信标
的所有其他点距离都正确的候选才保留。若恰好剩下一个候选，它就是答案，否则
位置为 `UNKNOWN`。每个信标最多 1600 个候选、20 次测量，计算量很小。

输入行中混有逗号、冒号和减号，它们都只是分隔数字，所以每行按其中的数字串
读取：先是控制点，然后是标识符与距离的配对。

注意事项：

- 场地边界会截断正方形，这往往正是答案唯一的原因；
- 一个信标可以被多个点测量，一个点也可以测量多个信标；
- 信标按标识符递增输出，而不是按出现顺序；
- 距离为 `0` 表示信标就在控制点上。

答案已在所有测试和 80 个随机输入上与逐格检查整个场地的结果比对。

## 各语言说明

- 所有语言都过滤同样的正方形。C++、Go 和 Java 手工提取每行中的数字串，Python
  用正则表达式，Rust 则在每个非数字字符处切分。
