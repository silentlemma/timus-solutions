# 1179. Система счисления, в которой в тексте больше всего чисел

[Timus 1179](https://acm.timus.ru/problem.aspx?space=1&num=1179) · сложность 295 · strings

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Текст до 1 МБ состоит из цифр, заглавных латинских букв, пробелов и
переводов строки; буквы — цифры от `A = 10` до `Z = 35`. В системе с
основанием `K` число — это максимальная последовательность символов,
являющихся цифрами этой системы. Найти основание `K` от 2 до 36, в котором
в тексте больше всего чисел (при равенстве наименьшее), и это количество.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Текст.

## Выходные данные

`K` и количество чисел.

## Примеры

### Пример 1

Ввод:

```
01234B56789
AZA
```

Вывод:

```
11 4
```

## Решение

Дадим каждому символу значение: значение цифры либо 36 для пробела или
перевода строки — это слишком много для цифры в любой системе. Такой же
разделитель поставим и перед текстом. В системе `K` число начинается на
каждом символе со значением меньше `K`, если значение перед ним не меньше
`K`. Значит, соседняя пара значений `(left, right)` с `right < left`
начинает по одному числу в каждой системе от `right + 1` до `left` (и не
меньше 2).

Посчитаем, сколько раз встречается каждая из 37 × 37 пар, затем разнесём
каждое количество на его диапазон оснований разностным массивом и выберем
лучшее основание. `O(L + 37²)` для текста длины `L`.

Тонкие места:

- первый символ тоже начинает число, об этом заботится разделитель в
  начале;
- пустой текст или текст без цифр даёт `2 0`;
- в системе 36 каждая буква, включая `Z`, — цифра.

Ответы сверены с отдельно написанным решением, которое следит за каждым
основанием посимвольно, на 200 случайных текстах и на всех тестах.

## Особенности языков

- Python обходится без цикла по мегабайту: он переводит текст в значения
  одним `translate` и считает каждую двухбайтовую пару через
  `bytes.count`. Пара из двух разных байтов не может перекрываться со своей
  копией, так что этот подсчёт точный. Остальные языки считают пары за один
  проход.
