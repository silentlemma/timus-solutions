# 1179. 文本中数最多的进制

[Timus 1179](https://acm.timus.ru/problem.aspx?space=1&num=1179) · 难度 295 · strings

原题作者 Pavel Atnashev，出自 2002 年 2 月 16 日在叶卡捷琳堡举行的第三届乌拉尔国立大学个人程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一段至多 1 MB 的文本由数字、大写拉丁字母、空格和换行组成；字母是从 `A = 10`
到 `Z = 35` 的数字。在 `K` 进制中，数是由该进制数字组成的极大连续段。求 2 到
36 之间使文本中数的个数最多的进制 `K`（并列时取最小的），以及这个个数。

时间限制：1 秒。内存限制：64 MB。

## 输入

文本。

## 输出

`K` 和数的个数。

## 样例

### 样例 1

输入：

```
01234B56789
AZA
```

输出：

```
11 4
```

## 解法

给每个字符一个值：数字的值，空格或换行则为 36——这个值在任何进制中都太大，不能
作为数字。在文本前面也放一个这样的分隔符。在 `K` 进制中，若某个字符的值小于
`K` 而它前面的值不小于 `K`，就从这里开始一个数。所以值为 `(left, right)` 且
`right < left` 的相邻对，在从 `right + 1` 到 `left`（且至少为 2）的每个进制中
各开始一个数。

统计 37 × 37 种相邻对各出现多少次，再用差分数组把每个次数分配到它对应的进制
区间上，最后选出最好的进制。长度为 `L` 的文本需要 `O(L + 37²)`。

注意事项：

- 第一个字符也会开始一个数，前面加的分隔符保证了这一点；
- 空文本或没有数字的文本，答案是 `2 0`；
- 在 36 进制中每个字母（包括 `Z`）都是数字。

答案已在 200 段随机文本和所有测试上，与另一份逐字符跟踪每种进制的独立解答比对。

## 各语言说明

- Python 不对一兆字节做循环：它用一次 `translate` 把文本变成值，再用
  `bytes.count` 统计每个双字节对。由两个不同字节组成的对不会与自身的另一份副本
  重叠，所以这种计数是精确的。其他语言一遍扫描统计相邻对。
