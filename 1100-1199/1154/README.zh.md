# 1154. 元素法师之战在一天中的最佳时刻

[Timus 1154](https://acm.timus.ru/problem.aspx?space=1&num=1154) · 难度 885 · math

原题作者 Evgeny Bryzgalov，出自 2001 年 4 月在彼尔姆举行的乌拉尔团体程序设计锦标赛英语轮。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

风、土、火、水四种元素的法师分别为光明与黑暗而战。每种元素在一天中有一个
力量时刻和一个虚弱时刻，各有对应的力量值；两者之间力量线性变化，并且每天
重复。一方的力量是其所有法师力量之和。选出一天中从 `00:00:00` 到 `23:59:59`
的某一秒，使光明对黑暗的优势最大，若有多个则取最早的，并输出该时刻和保留
两位小数的优势。若光明在任何时刻都不占优，输出 `We can't win!`。

时间限制：1 秒。内存限制：64 MB。

## 输入

四行 `代码 力量时刻 力量值 虚弱时刻 虚弱值`，然后是光明与黑暗的法师，用字母
`A`、`E`、`F`、`W` 组成的字符串表示，每方 1 到 1000 名。

## 输出

时刻和优势，或者 `We can't win!`。

## 样例

### 样例 1

输入：

```
A 10:00:00 130 18:00:00 40
E 14:00:00 150 21:30:00 25
F 06:00:00 105 18:00:00 70
W 23:00:00 140 02:00:00 20
A
WWW
```

输出：

```
02:00:00
25.00
```

### 样例 2

输入：

```
A 10:00:00 130 18:00:00 40
E 14:00:00 150 21:30:00 25
F 06:00:00 105 18:00:00 70
W 23:00:00 140 02:00:00 20
A
WWWF
```

输出：

```
We can't win!
```

## 解法

只有差值重要：对每种元素，令 `c` 为光明一方该元素法师数减去黑暗一方的数目。
时刻 `t` 的优势为 `Σ c·power(t)`。每种力量沿一天向前从力量时刻线性下降到
虚弱时刻，再线性回升；所以优势是分段线性的，只在八个时刻处转折。线性段的
最大值在端点取得，而一天本身在午夜被切开，所以最佳的一秒是八个时刻之一、
`00:00:00` 或 `23:59:59`。在这些点计算优势，取最大值，相等时取最早的时刻。
只有该值为正时光明才获胜。

注意事项：

- 若虚弱时刻在一天中早于力量时刻，从力量到虚弱的时间会跨过午夜，所以差值
  要对 86400 取模；
- 若优势在一整段区间上保持最大，该区间最早的一秒是某个时刻或午夜，已在
  候选之中；
- 优势恰为零不算获胜；
- 优势是小数，输出保留两位。

答案已在所有测试和 40 个随机输入上，与在一天全部 86400 秒用分数精确计算的
结果比对。

## 各语言说明

- Python 用精确分数计算候选点。
- C++、Go、Java 和 Rust 使用双精度浮点数，选择最早的最佳时刻时把相差在
  `10⁻⁹` 以内的值视为相等。
- Java 通过 `BigDecimal` 以“四舍六入五成双”方式舍入优势，与 C 的 `printf`
  一致，因为它自己的 `%.2f` 对十进制串采用“五入”，在恰好一半时可能不同。
