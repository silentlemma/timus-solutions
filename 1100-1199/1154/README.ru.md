# 1154. Лучший момент суток для сражения магов стихий

[Timus 1154](https://acm.timus.ru/problem.aspx?space=1&num=1154) · сложность 885 · math

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Маги четырёх стихий — Воздуха, Земли, Огня и Воды — сражаются за Свет и
за Тьму. У каждой стихии в течение суток есть момент силы и момент
слабости со своим могуществом; между ними могущество меняется линейно, а
сутки повторяются. Сила стороны — сумма могущества её магов. Нужно
выбрать секунду суток от `00:00:00` до `23:59:59`, когда перевес Света над
Тьмой наибольший, самую раннюю из равных, и вывести её и перевес с двумя
знаками после точки. Если Свет ни в какой момент не сильнее, вывести
`We can't win!`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Четыре строки `код время-силы могущество-силы время-слабости
могущество-слабости`, затем маги Света и Тьмы — строки из букв `A`, `E`,
`F`, `W`, по 1–1000 магов.

## Выходные данные

Время и перевес или `We can't win!`.

## Примеры

### Пример 1

Ввод:

```
A 10:00:00 130 18:00:00 40
E 14:00:00 150 21:30:00 25
F 06:00:00 105 18:00:00 70
W 23:00:00 140 02:00:00 20
A
WWW
```

Вывод:

```
02:00:00
25.00
```

### Пример 2

Ввод:

```
A 10:00:00 130 18:00:00 40
E 14:00:00 150 21:30:00 25
F 06:00:00 105 18:00:00 70
W 23:00:00 140 02:00:00 20
A
WWWF
```

Вывод:

```
We can't win!
```

## Решение

Важна только разность: для каждой стихии пусть `c` — число её магов на
стороне Света минус число на стороне Тьмы. Перевес в момент `t` равен
`Σ c·power(t)`. Каждое могущество линейно убывает от момента силы до
момента слабости, если идти по суткам вперёд, и линейно растёт обратно;
значит, перевес кусочно-линеен с изломами только в восьми моментах.
Линейный кусок достигает максимума на одном из концов, а сами сутки
разрезаны в полночь, так что лучшая секунда — один из восьми моментов,
`00:00:00` или `23:59:59`. Вычисляем перевес в них, берём наибольшее
значение и среди равных — самое раннее время. Свет побеждает, только если
это значение положительно.

Тонкие места:

- время от силы до слабости переходит через полночь, если слабость в
  сутках раньше силы, поэтому разности берутся по модулю 86400;
- если перевес держится на максимуме на целом отрезке, самая ранняя его
  секунда — момент или полночь, то есть один из кандидатов;
- перевес ровно ноль — не победа;
- перевес дробный и выводится с двумя знаками.

Ответы сверены на всех тестах и на 40 случайных входах с точным
вычислением в дробях во всех 86400 секундах суток.

## Особенности языков

- Python вычисляет кандидатов в точных дробях.
- C++, Go, Java и Rust используют double и считают значения в пределах
  `10⁻⁹` равными при выборе самого раннего лучшего момента.
- Java округляет перевес через `BigDecimal` с округлением половин к
  чётному, как `printf` в C, потому что её собственный `%.2f` округляет
  десятичную запись половиной вверх и мог бы разойтись на точных
  половинах.
