# 1183. Кратчайшая правильная скобочная последовательность, содержащая данную

[Timus 1183](https://acm.timus.ru/problem.aspx?space=1&num=1183) · сложность 197 · dp

Автор оригинальной задачи — Андрей Станкевич; полуфинал ACM ICPC Северо-Восточной Европы 2001–2002.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано до 100 символов из `(`, `)`, `[`, `]`; вывести кратчайшую правильную
скобочную последовательность, содержащую их как подпоследовательность.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Скобки в одной строке, возможно пустой.

## Выходные данные

Кратчайшая правильная последовательность, содержащая их.

## Проверка

Проверяются правильность типов скобок, вход как подпоследовательность и минимум вставок. Новый Java прошёл 507 запусков main с новым загрузчиком классов; независимый оракул максимизирует непересекающиеся пары, включая пустые строки и длину 100.

## Примеры

### Пример 1

Ввод:

```
([(]
```

Вывод:

```
()[()]
```

## Решение

Пусть `d[i][j]` — минимум вставок для правильной последовательности
из `s[i..j)`. Пустой отрезок стоит ноль, одна скобка — одну вставку.
Для более длинного отрезка проверяем обрамление `d[i+1][j−1]`, если крайние
скобки образуют открывающую/закрывающую пару, и все разбиения
`d[i][k]+d[k][j]`, `i<k<j`.

Полнота следует из непересечения пар правильной последовательности.
Оптимальному дополнению не нужна пара из двух вставленных скобок:
удаление такой согласованной пары сохраняет правильность и исходную
подпоследовательность. Если первая исходная скобка не спарена с другой
исходной, дополним её отдельно и разделим. Иначе её партнёр — последняя
исходная скобка (обрамление) либо более ранняя (разделение после партнёра).
Непересекающиеся пары оставляют подзадачи независимыми. Индукция по длине
доказывает рекуррентность; сохранённый переход восстанавливает оптимальную
правильную надпоследовательность без потери исходных символов.
Время `O(n³)`, память `O(n²)`, `n≤100`.

Читаем всю строку, включая пустую: для неё вывод тоже пустой.
Подходит любой кратчайший правильный ответ с исходной строкой как
подпоследовательностью. Пять прежних Accepted-версий хранят таблицу
выбранных переходов. Python восстанавливает явным стеком; другие языки —
рекурсией глубины не более `n`.

## Оптимизированные решения

Интервальная DP минимального числа вставок сохраняется. C++ хранит стоимости байтами, завершает перебор разбиений на нижней границе по чётности и восстанавливает оптимум без отдельной таблицы решений. Java хранит только полуинтервалы `i≤j`, включая пустые, в верхнем треугольнике. Индекс — `i(2N+1−i)/2+j`, размер `(N+1)(N+2)/2` байт вместо полного квадрата. Стоимости лежат от нуля до N≤100: знакового байта достаточно. Восстановление Java использует ограниченный явный стек: парные концы ставят внутренний отрезок и закрывающую скобку, разбиение — правый, затем левый отрезок. Вход остаётся подпоследовательностью, результат оптимален и содержит не более 2N скобок. Худшее время `O(N^3)`, память `O(N^2)`; экономятся представление и накладные расходы восстановления. Все понятные базы сохранены.

- `1183_dp_optimized.cpp`: 0.015 s / 80 KB; база `1183_dp.cpp`: 0.015 s / 460 KB; изменение относительно базы: время -0.0%, память -82.6%.
- `1183_dp_optimized.java`: 0.109 s / 416 KB; база `1183_dp.java`: 0.078 s / 616 KB; изменение относительно базы: время +39.7%, память -32.5%.
