# 1183. Кратчайшая правильная скобочная последовательность, содержащая данную

[Timus 1183](https://acm.timus.ru/problem.aspx?space=1&num=1183) · сложность 196 · dp

Автор оригинальной задачи — Андрей Станкевич; полуфинал ACM ICPC Северо-Восточной Европы 2001–2002.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано до 100 символов из `(`, `)`, `[`, `]`; вывести кратчайшую правильную
скобочную последовательность, содержащую их как подпоследовательность.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Скобки в одной строке, возможно пустой.

## Выходные данные

Кратчайшая правильная последовательность, содержащая их.

## Проверка

Принимается любая последовательность, которая правильна, содержит данные
скобки по порядку и не длиннее сохранённого ответа.

## Примеры

### Пример 1

Ввод:

```
([(]
```

Вывод:

```
()[()]
```

## Решение

Пусть `add[i][j]` — наименьшее число скобок, которое нужно добавить,
чтобы кусок `s[i..j)` стал правильным. Одиночной скобке нужна одна пара.
Более длинный кусок либо имеет на концах соответствующую пару, обёрнутую
вокруг лучшего исправления середины, либо делится на две части,
исправляемые отдельно:

`add[i][j] = min(add[i+1][j−1], если s[i] и s[j−1] — пара, min по k от add[i][k] + add[k][j])`.

Запоминая, какой вариант победил, последовательность можно восстановить:
одиночная скобка выводится со своей парой, обёрнутая пара — вокруг своей
середины, разбиение — двумя половинами. `O(n³)` при `n ≤ 100`.

Тонкие места:

- строка ввода может быть пустой, и тогда ответ — пустая строка;
- при равенстве вариантов всё равно нужно записать настоящий выбор, иначе
  восстановление примет длинный кусок за одиночную скобку;
- `([)]` требует ещё двух скобок, и `()[()]`, и `([])[]` — кратчайшие;
  принимается любой такой ответ.

Ответы сверены с отдельно написанным решением на 300 случайных строках до
100 скобок, и каждая выведенная последовательность прошла проверяющую
программу.

## Особенности языков

- Python восстанавливает ответ с явным стеком, остальные языки —
  рекурсией глубиной не больше 100.
