# 1183. 包含给定序列的最短合法括号序列

[Timus 1183](https://acm.timus.ru/problem.aspx?space=1&num=1183) · 难度 197 · dp

原题作者 Andrew Stankevich，出自 2001–2002 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定至多 100 个取自 `(`、`)`、`[`、`]` 的字符，输出一个以它们为子序列的最短
合法括号序列。

时间限制：1 秒。内存限制：64 MB。

## 输入

一行括号，可能为空。

## 输出

包含它们的最短合法序列。

## 评测方式

检查括号类型配平、输入子序列及最少新增长度。新Java以独立类加载器执行main共507次；独立预言机最大化非交叉匹配对，含空串及100字符输入。

## 样例

### 样例 1

输入：

```
([(]
```

输出：

```
()[()]
```

## 解法

令 `d[i][j]` 为将 `s[i..j)` 补成合法括号串的最少插入数。空区间为零，
单个括号为一。更长区间尝试两种转移：首尾为匹配的开闭括号时包住内部
`d[i+1][j−1]`；或枚举 `i<k<j`，取 `d[i][k]+d[k][j]`。

合法括号配对不交叉。最优补全不需要两个新插入括号彼此配对：删除这样的
匹配对仍合法，且保留原输入子序列。若第一个原括号不与其他原括号匹配，
可单独补全并分割；若匹配的是最后一个原括号，则包住内部；否则在其较早
的配对括号后分割。不交叉性保证两部分独立。按区间长度归纳证明转移完备，
记录最优选择即可恢复合法、保留全部原字符的最短上序列。
`n≤100`，时间 `O(n³)`，空间 `O(n²)`。

按整行读取，允许空行，其答案也是空行。任何包含输入为子序列的最短合法
答案均可。五份原 Accepted 基础版保存选择表；Python 显式栈恢复，其他语言
递归深度不超过 `n`。

## 优化解法

最少插入的区间 DP 不变。C++ 用字节存费用，在区间奇偶性下界停止枚举，并直接由费用恢复最优解，不存选择表。Java 只存 `i≤j` 的半开区间（含空区间），上三角索引为 `i(2N+1−i)/2+j`，共 `(N+1)(N+2)/2` 字节，代替完整方阵。费用在零到 N≤100 间，有符号字节足够。Java 用有界显式任务栈恢复：匹配端点安排内部区间与右括号，分割安排右区间再左区间。输入仍是输出子序列，结果最优且至多 2N 个括号。最坏时间 `O(N^3)`、空间 `O(N^2)`；改进在表示及恢复开销，清晰基础版全部保留。
