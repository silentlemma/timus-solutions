# 1183. 包含给定序列的最短合法括号序列

[Timus 1183](https://acm.timus.ru/problem.aspx?space=1&num=1183) · 难度 196 · dp

原题作者 Andrew Stankevich，出自 2001–2002 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定至多 100 个取自 `(`、`)`、`[`、`]` 的字符，输出一个以它们为子序列的最短
合法括号序列。

时间限制：1 秒。内存限制：64 MB。

## 输入

一行括号，可能为空。

## 输出

包含它们的最短合法序列。

## 评测方式

只要序列合法、按顺序包含给定的括号，并且与保存的答案一样短，就被接受。

## 样例

### 样例 1

输入：

```
([(]
```

输出：

```
()[()]
```

## 解法

设 `add[i][j]` 为使片段 `s[i..j)` 变得合法至少需要添加的括号数。单个括号需要
补一个配对。更长的片段要么两端是一对匹配的括号，包住中间部分的最优修补，要么
分成两部分分别修补：

`add[i][j] = min(add[i+1][j−1]（若 s[i] 与 s[j−1] 匹配）, min_k add[i][k] + add[k][j])`。

记录哪种选择最优，就能还原序列：单个括号连同它的配对输出，匹配对包住中间部分，
分割则输出两半。`n ≤ 100` 时 `O(n³)`。

注意事项：

- 输入行可能为空，此时答案是一个空行；
- 选择相同时也必须记录一个真实的选择，否则还原时会把长片段当成单个括号；
- `([)]` 需要再加两个括号，`()[()]` 和 `([])[]` 都是最短的；任何这样的答案都
  被接受。

答案已在 300 行至多 100 个括号的随机输入上与另一份独立编写的解答比对，输出的
每个序列都通过了检查程序。

## 各语言说明

- Python 用显式栈还原答案；其他语言用递归，深度不超过 100。
