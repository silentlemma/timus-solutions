# 1120. 和为给定值的最长连续正整数段

[Timus 1120](https://acm.timus.ru/problem.aspx?space=1&num=1120) · 难度 86 · math

原题作者 Leonid Volkov，出自 2001 年 10 月 USU Open Collegiate Programming Contest（Junior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 `1 ≤ S ≤ 10^9`，求正整数 `A` 和 `N`，使 `S = A + (A + 1) + … + (A + N − 1)`，且 `N` 尽可能大。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`S`。

## 输出

`A N`。

## 评测方式

输出按记号逐个比较；多余的空白字符无关紧要。

## 样例

### 样例 1

输入：

```
14
```

输出：

```
2 4
```

## 解法

这一段之和为 `N·A + N(N − 1)/2`，所以对给定的 `N`，起点 `A = (S − N(N − 1)/2) / N` 必须是正整数。`A ≥ 1` 意味着
`N(N + 1)/2 ≤ S`，所以 `N` 至多约为 `√(2S) ≈ 44721`。从这个上界开始向下尝试 `N`，遇到第一个能整除的就停止；`N = 1`
总是可行。`O(√S)`。

注意事项：

- 平方根可能向上取整：从 `⌊√(2S)⌋` 开始，在 `N(N + 1)/2 > S` 时减小 `N`；
- `N ≈ 44721` 时 `N(N + 1)/2` 约为 `10^9`，32 位放得下，但解法一律使用 64 位；
- 2 的幂没有奇因数，所以只有 `N = 1` 可行。

答案经过验证：对 `S ≤ 3000` 枚举所有起点和长度；对更大的 `S` 用因数的观点：长度为 `N` 的段存在，当且仅当 `N` 整除 `2S`，且
`2S/N − N + 1` 为正偶数。
