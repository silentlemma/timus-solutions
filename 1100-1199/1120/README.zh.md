# 1120. 和为给定值的最长连续正整数段

[Timus 1120](https://acm.timus.ru/problem.aspx?space=1&num=1120) · 难度 87 · math

原题作者 Leonid Volkov，出自 2001 年 10 月 USU Open Collegiate Programming Contest（Junior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 `1 ≤ S ≤ 10^9`，求正整数 `A` 和 `N`，使 `S = A + (A + 1) + … + (A + N − 1)`，且 `N` 尽可能大。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`S`。

## 输出

`A N`。

## 评测方式

输出按记号逐个比较；多余的空白字符无关紧要。

## 样例

### 样例 1

输入：

```
14
```

输出：

```
2 4
```

## 解法

这一段之和为 `N·A + N(N − 1)/2`，所以对给定的 `N`，起点 `A = (S − N(N − 1)/2) / N` 必须是正整数。`A ≥ 1` 意味着
`N(N + 1)/2 ≤ S`，所以 `N` 至多约为 `√(2S) ≈ 44721`。从这个上界开始向下尝试 `N`，遇到第一个能整除的就停止；`N = 1`
总是可行。`O(√S)`。

注意事项：

- 平方根可能向上取整：从 `⌊√(2S)⌋` 开始，在 `N(N + 1)/2 > S` 时减小 `N`；
- `N ≈ 44721` 时 `N(N + 1)/2` 约为 `10^9`，32 位放得下，但 C++、Go、Java 和 Rust 解法使用 64 位整数，Python 使用任意精度整数；
- 2 的幂没有大于 1 的奇因数，所以只有 `N = 1` 可行（测试 08）。

答案经过验证：对 `S ≤ 3000` 枚举所有起点和长度；对更大的 `S` 用因数的观点：长度为 `N` 的段存在，当且仅当 `N` 整除 `2S`，且
`2S/N − N + 1` 为正偶数。

## 优化解法

`1120_number_theory.py`. 分解 S 奇部并枚举约数，替代扫全部等差长度。每奇约数给 d 与2S/d 两长度，以 length(length+1)≤2S 保证正首项并取最大。去二后试奇因数、短递归约数生成、精确整数。短扫描关闭可选 PyPy JIT，刷新后退出。保守 O(√S+τ(S)) 算术工作、O(log S) 因数/递归状态，保留简单长度扫描。

与 `1120_math.py` 相比：时间 0.078 s → 0.109 s；内存 444 KB → 308 KB。

优化的 Java 解法直接从 `System.in` 逐字节解析这个数，而不是使用 `Scanner`，并在
O(1) 内更新下一个更短长度的余数：368 KB，而不是 1640 KB，时间不变。

`1120_math_optimized.rs`. 先用整数二分找出满足 N(N+1)/2<=S 的最大长度，再递减检查，直到 S-N(N-1)/2 能被 N 整除。去掉浮点平方根，保留降序搜索。S<=10^9 时二分中的乘积均可用 i64 表示。时间 O(log S+√S)=O(√S)，额外空间 O(1)。 Rust 版本通过 C 运行库读写，不保留解码后的输入 String，也不构造格式化的输出 String。保留简单版本及其 Accepted。

与 `1120_math.rs` 相比：时间 0.046 s → 0.031 s；内存 220 KB → 56 KB。
