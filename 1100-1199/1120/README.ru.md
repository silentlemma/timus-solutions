# 1120. Самая длинная серия последовательных натуральных чисел с данной суммой

[Timus 1120](https://acm.timus.ru/problem.aspx?space=1&num=1120) · сложность 86 · math

Автор оригинальной задачи — Леонид Волков; USU Open Collegiate Programming Contest, октябрь 2001 года, Junior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано `1 ≤ S ≤ 10^9`. Найти натуральные `A` и `N`, для которых
`S = A + (A + 1) + … + (A + N − 1)`, а `N` как можно больше.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`S`.

## Выходные данные

`A N`.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
14
```

Вывод:

```
2 4
```

## Решение

Сумма серии равна `N·A + N(N − 1)/2`, поэтому при данном `N` начало
`A = (S − N(N − 1)/2) / N` должно быть натуральным. `A ≥ 1` означает
`N(N + 1)/2 ≤ S`, так что `N` не больше примерно `√(2S) ≈ 44721`.
Перебираем `N` вниз от этой границы и останавливаемся на первом, при
котором деление нацело; `N = 1` подходит всегда. `O(√S)`.

Тонкие места:

- квадратный корень может округлиться вверх: начинать с `⌊√(2S)⌋` и
  уменьшать `N`, пока `N(N + 1)/2 > S`;
- `N(N + 1)/2` при `N ≈ 44721` около `10^9` и помещается в 32 бита, но
  решения всё равно считают в 64 битах;
- у степени двойки нет нечётных делителей, поэтому подходит только `N = 1`.

Ответы проверены перебором всех начал и длин для `S ≤ 3000`, а для
больших `S` — через делители: серия длины `N` существует ровно тогда,
когда `N` делит `2S`, а `2S/N − N + 1` положительно и чётно.
