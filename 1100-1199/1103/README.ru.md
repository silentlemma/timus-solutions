# 1103. Окружность через три карандаша, делящая остальные пополам

[Timus 1103](https://acm.timus.ru/problem.aspx?space=1&num=1103) · сложность 503 · geometry

Автор оригинальной задачи — Катя Овечкина; Tetrahedron Team Contest, май 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N` карандашей стоят в целых точках (`N` нечётно, `3 ≤ N ≤ 5000`,
координаты по модулю не больше `10^8`). Никакие три не лежат на одной
прямой, никакие четыре — на одной окружности. Нужно выбрать три
карандаша так, чтобы внутри окружности через них оказалось ровно
`(N − 3) / 2` остальных карандашей и столько же снаружи. Если такой
окружности нет, вывести `No solution`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк `x y`.

## Выходные данные

Координаты трёх карандашей, по одному карандашу в строке.

## Проверка

Подходит любая правильная окружность. Проверяющая программа убеждается,
что три точки — разные карандаши, и считает карандаши внутри и снаружи
окружности точным целочисленным определителем.

## Примеры

### Пример 1

Ввод:

```
7
0 0
1 0
2 -1
2 1
1 1
0 2
-3 -1
```

Вывод:

```
-3 -1
2 -1
1 1
```

## Решение

Решение есть всегда. Возьмём `A` — самый нижний карандаш (из самых
нижних самый левый) — и `B`, его соседа по выпуклой оболочке, выбранного
так, что все остальные карандаши лежат слева от прямой `AB`. Тогда любая
окружность через `A` и `B` делит эту полуплоскость одинаково: карандаш
`P` внутри окружности через `A`, `B` и `C` ровно тогда, когда он видит
отрезок `AB` под большим углом, чем `C`. Все углы `APB` меньше 180° и,
поскольку никакие четыре карандаша не лежат на одной окружности, все
различны. Отсортируем остальные `N − 2` карандаша по этому углу и
возьмём средний как `C`: `(N − 3) / 2` карандашей видят `AB` под большим
углом и лежат внутри, столько же — под меньшим и лежат снаружи.
`O(N log N)`.

Углы сравниваются без плавающей точки. Котангенс угла равен
`dot / cross`, где `dot = (A − P)·(B − P)`, а `cross` — ориентированная
площадь `P`, `A`, `B`, положительная для каждого `P`. У большего угла
котангенс меньше, поэтому `P` идёт раньше `Q`, когда
`dot_P · cross_Q > dot_Q · cross_P`.

Тонкие места:

- координаты доходят до `10^8`, поэтому `dot` и `cross` доходят примерно
  до `8 · 10^16`, а их произведения — до `6 · 10^33`, далеко за 64 бита;
- сравнивать углы через `atan2` рискованно: два далёких карандаша могут
  видеть `AB` под углами, разница которых меньше ошибки округления;
- `B` должен быть соседом `A` по оболочке; для произвольной второй точки
  карандаши по разные стороны от `AB` не упорядочиваются одним углом.

Ответы проверены точным определителем «точка в окружности» на всех
тестах, включая случайные наборы из тысяч карандашей на всём диапазоне
координат.

## Особенности языков

- C++ и Rust сравнивают произведения в 128-битных целых и выбирают
  средний элемент через `nth_element` и `select_nth_unstable_by`.
- В Go и Java этих версий нет 128-битного типа, и при сортировке
  произведения сравниваются как длинные целые.
