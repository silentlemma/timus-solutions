# 1103. 穿过三支铅笔、把其余铅笔平分的圆

[Timus 1103](https://acm.timus.ru/problem.aspx?space=1&num=1103) · 难度 503 · geometry

原题作者 Katya Ovechkina，出自 2001 年 5 月 Tetrahedron Team Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N` 支铅笔立在整点上（`N` 为奇数，`3 ≤ N ≤ 5000`，坐标绝对值不超过 `10^8`）。任意三支不共线，任意四支不共圆。选出三支铅笔，使经过它们的圆内恰有其余铅笔中的
`(N − 3) / 2` 支，圆外也是这么多。如果不存在这样的圆，输出 `No solution`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后是 `N` 行 `x y`。

## 输出

三支铅笔的坐标，每行一支。

## 评测方式

接受任何一个正确的圆。检查程序验证这三个点是不同的铅笔，并用精确的整数行列式统计圆内和圆外的铅笔数。

## 样例

### 样例 1

输入：

```
7
0 0
1 0
2 -1
2 1
1 1
0 2
-3 -1
```

输出：

```
-3 -1
2 -1
1 1
```

## 解法

解总是存在。取 `A` 为最低的铅笔（最低者中最左的），`B` 为它在凸包上的邻点，选法使其余所有铅笔都在直线 `AB`
的左侧。于是经过 `A` 和 `B` 的任何圆都以同样的方式切分这个半平面：铅笔 `P` 在经过 `A`、`B`、`C`
的圆内，当且仅当它看线段 `AB` 的视角大于 `C` 的视角。所有角 `APB` 都小于 180°，并且由于任意四支铅笔不共圆，它们互不相同。把其余
`N − 2` 支铅笔按这个角排序，取中间那支作为 `C`：有 `(N − 3) / 2`
支铅笔的视角更大，位于圆内；同样多的视角更小，位于圆外。`O(N log N)`。

角的比较不用浮点数。它的余切等于 `dot / cross`，其中 `dot = (A − P)·(B − P)`，`cross` 是 `P`、`A`、`B`
的有向面积，对每个 `P` 都为正。角越大余切越小，所以当 `dot_P · cross_Q > dot_Q · cross_P` 时 `P` 排在
`Q` 之前。

注意事项：

- 坐标可达 `10^8`，所以 `dot` 和 `cross` 可达约 `8 · 10^16`，它们的乘积可达约 `6 · 10^33`，远超 64 位；
- 用 `atan2` 比较角有风险：两支很远的铅笔看 `AB` 的视角之差可能小于舍入误差；
- `B` 必须是 `A` 在凸包上的邻点；对任意的第二个点，`AB` 两侧的铅笔无法用同一个角排序。

答案在所有测试上都用精确的“点在圆内”行列式检查过，包括在整个坐标范围内随机生成的数千支铅笔。

## 语言说明

- C++ 和 Rust 用 128 位整数比较乘积，并分别用 `nth_element` 和 `select_nth_unstable_by` 选出中间元素。
- 这些版本的 Go 和 Java 没有 128 位类型，排序时把乘积当作大整数比较。
