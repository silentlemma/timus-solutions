# 1124. 用最少的手部动作把彩色碎片放回各自的盒子

[Timus 1124](https://acm.timus.ru/problem.aspx?space=1&num=1124) · 难度 299 · dsu

原题作者 Stanislav Vasiliev，出自 2001 年 10 月 21 日第六届乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `M` 种颜色（`2 ≤ M ≤ 500`），每种 `N` 块碎片（`2 ≤ N ≤ 50`），还有 `M` 个盒子，盒子 `i` 用来装颜色 `i`；现在每个盒子里都有 `N`
块任意颜色的碎片。一次手部动作要么把一块碎片从手所在的盒子拿到另一个盒子（手随之停在那里），要么把空手移到另一个盒子。手可以免费从任意盒子开始。求让每块碎片都回到自己盒子的最少动作数。

时间限制：0.25 秒。内存限制：64 MB。

## 输入

`M N`，然后是 `M` 行，每行 `N` 个颜色：各盒子中的碎片。

## 输出

最少的手部动作数。

## 评测方式

输出按记号逐个比较；多余的空白字符无关紧要。

## 样例

### 样例 1

输入：

```
4 3
1 3 1
2 3 3
1 2 2
4 4 4
```

输出：

```
6
```

## 解法

对盒子 `b ≠ c` 中每块颜色为 `c` 的碎片，画一条从 `b` 指向 `c` 的有向边。每块放错的碎片至少需要一次搬运，每次搬运至多纠正一块碎片。每个盒子有
`N` 块碎片，最后也必须有 `N` 块，所以每个盒子的入边数等于出边数，每个连通的盒子组都有欧拉回路：手可以沿着它走，每条边搬一块碎片，每次搬运都结束在下一次开始的地方。两组之间手需要一次空移。所以若
`G` 个组中共有 `E` 块放错的碎片，答案就是 `E + G − 1`；若没有放错的则为 0。用并查集在盒子上求出各组。`O(M·N)`。

注意事项：

- 已经放对的盒子不构成组，不需要访问；
- 手的初始位置免费，所以有 `− 1`；
- 若没有放错的碎片，答案是 0，而不是 `−1`。

公式经过验证：在 150 个极小的局面上与对完整状态（所有盒子的内容和手的位置）做广度优先搜索的结果比对；手工测试取自该搜索，大测试则用单独计算的公式核对。
