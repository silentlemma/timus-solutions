# 1124. Раскладка цветных кусочков по коробкам за наименьшее число движений руки

[Timus 1124](https://acm.timus.ru/problem.aspx?space=1&num=1124) · сложность 297 · dsu

Автор оригинальной задачи — Станислав Васильев; VI студенческое соревнование по программированию УрГУ, 21 октября 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `M` цветов (`2 ≤ M ≤ 500`), по `N` кусочков каждого (`2 ≤ N ≤ 50`)
и `M` коробок, коробка `i` предназначена для цвета `i`; сейчас в каждой
коробке лежат `N` кусочков произвольных цветов. Одно движение руки либо
переносит один кусочек из коробки, у которой рука, в другую коробку (рука
оказывается там), либо переносит пустую руку к другой коробке. Начать
можно у любой коробки бесплатно. Найти наименьшее число движений, после
которых каждый кусочек лежит в своей коробке.

Ограничение времени: 0,25 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`M N`, затем `M` строк по `N` цветов: кусочки в каждой коробке.

## Выходные данные

Наименьшее число движений руки.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4 3
1 3 1
2 3 3
1 2 2
4 4 4
```

Вывод:

```
6
```

## Решение

Проведём ориентированное ребро из коробки `b` в коробку `c` для каждого
кусочка цвета `c`, лежащего в коробке `b ≠ c`. Каждый лежащий не на месте
кусочек требует хотя бы одного переноса, и каждый перенос исправляет не
больше одного кусочка. В каждой коробке `N` кусочков и в конце должно
быть `N`, поэтому у каждой коробки входящих рёбер столько же, сколько
исходящих, и в каждой связной группе коробок есть эйлеров цикл: рука
может пройти по нему, перенося по кусочку вдоль каждого ребра и
заканчивая каждый перенос там, где начинается следующий. Между двумя
группами руке нужно одно пустое движение. Значит, при `E` кусочках не на
месте в `G` группах ответ `E + G − 1`, и 0, если всё на месте. Группы
находит система непересекающихся множеств по коробкам. `O(M·N·log M)`.

Тонкие места:

- коробки, где всё уже на месте, не образуют группы, и к ним не нужно
  подходить;
- первая установка руки бесплатна, отсюда `− 1`;
- если всё на месте, ответ 0, а не `−1`.

Формула проверена поиском в ширину по полному состоянию (содержимое всех
коробок и положение руки) на 150 крошечных мозаиках; большие тесты
проверены отдельно вычисленной формулой.

## Оптимизированные решения

Go и Rust объединяют принадлежность компоненте, её размер и признак активности в одном 16-битном массиве. Ноль означает неиспользованную вершину, отрицательное значение — корень и размер компоненты, положительное — родителя. Объединение по размеру и сокращение пути поддерживают число активных компонент прямо при чтении неправильно лежащих шаров.

Принятая версия Rust 1.75 x64 заняла 0.046 с при 0.015 с у базовой и использовала 196 KB при 652 KB у базовой.

Принятые базовые реализации [1124_dsu.cpp](1124_dsu.cpp), [1124_dsu.java](1124_dsu.java), [1124_dsu.py](1124_dsu.py) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
