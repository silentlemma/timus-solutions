# 1147. Видимая площадь каждого цвета после наложения прямоугольников на лист

[Timus 1147](https://acm.timus.ru/problem.aspx?space=1&num=1147) · сложность 736 · dsu

Оригинальная задача с Timus; автор и источник не указаны.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N ≤ 1000` цветных прямоугольников со сторонами, параллельными осям,
кладутся один за другим на белый лист `A × B`, `A, B ≤ 10000`; лист имеет
цвет 1, а цвета доходят до 2500. Если смотреть сверху, вывести каждый
видимый цвет с его общей видимой площадью в порядке возрастания цвета.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`A`, `B` и `N`, затем `N` строк с нижним левым углом, верхним правым
углом и цветом прямоугольника, от нижнего к верхнему.

## Выходные данные

Видимые цвета с площадями, по одному в строке, по цвету.

## Примеры

### Пример 1

Ввод:

```
20 20 3
2 2 18 18 2
0 8 19 19 3
8 0 10 19 4
```

Вывод:

```
1 91
2 84
3 187
4 38
```

## Решение

Все углы делят лист не больше чем на `2001` вертикальную полосу и `2001`
горизонтальный пояс; внутри одной полосы и одного пояса видимый сверху
цвет постоянен. Берём полосы по одной. В полосе проходим прямоугольники,
которые её пересекают, от верхнего вниз: каждый закрашивает покрытые им
пояса, которые ещё не закрасил более высокий прямоугольник, и прибавляет
их высоту, умноженную на ширину полосы, к своему цвету. Всё, что осталось
незакрашенным, — белое.

Чтобы быстро находить незакрашенные пояса, `skip[j]` указывает от пояса
`j` на следующий пояс, который может быть ещё не закрашен, как в системе
непересекающихся множеств с сокращением путей; закраска пояса `j` ставит
`skip[j] = j + 1`. Каждый пояс закрашивается в полосе один раз, так что
полоса стоит `O(N + Y)`, а весь проход — `O(X·(N + Y))` при `X, Y ≤ 2001`.
Полоса заканчивается раньше, как только закрашена целиком.

Тонкие места:

- белый прямоугольник сверху виден белым, так что он прибавляет к цвету 1,
  как и непокрытый лист;
- цвета с нулевой видимой площадью не выводятся;
- площади доходят до `10⁸`, это ещё 32 бита, но суммы 64-битные.

Ответы сверены с закраской каждого единичного квадрата листа на 150
маленьких случайных входах.

## Особенности языков

- В C++, Go, Java и Rust для каждой полосы проверяется каждый
  прямоугольник.
- Python сначала строит список прямоугольников над каждой полосой и
  обходится без проверки; всё равно здесь он самый медленный из пяти. На
  самых больших тестах под CPython в наших запусках он работает около
  0,8 с, больше лимита в 0,5 с, поэтому решение на Python отправляется
  под PyPy 3.10, где Timus принимает его за 0,484 с, у самого лимита.
