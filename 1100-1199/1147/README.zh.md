# 1147. 在纸上叠放矩形后每种颜色的可见面积

[Timus 1147](https://acm.timus.ru/problem.aspx?space=1&num=1147) · 难度 736 · dsu

原题来自 Timus，未注明作者和出处。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N ≤ 1000` 个边与坐标轴平行的彩色矩形依次放在一张 `A × B`（`A, B ≤ 10000`）
的白纸上；白纸颜色为 1，颜色编号最大到 2500。从上往下看，按颜色递增顺序列出
每种可见颜色及其可见总面积。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`A`、`B` 和 `N`，然后 `N` 行，每行是一个矩形的左下角、右上角和颜色，从最底下
的开始。

## 输出

可见颜色及其面积，每行一个，按颜色排序。

## 样例

### 样例 1

输入：

```
20 20 3
2 2 18 18 2
0 8 19 19 3
8 0 10 19 4
```

输出：

```
1 91
2 84
3 187
4 38
```

## 解法

所有角点把纸分成至多 `2001` 条竖条和 `2001` 条横带；在同一竖条与同一横带的
交叉处，从上看到的颜色不变。逐条处理竖条。在一条竖条里，从最上面的矩形往下
依次处理与它相交的矩形：每个矩形把自己覆盖的、尚未被更高矩形涂过的横带涂上，
并把这些横带的高度乘以竖条宽度加到自己的颜色上。最后没被涂的部分是白色。

为了快速找到未涂的横带，`skip[j]` 从横带 `j` 指向下一个可能尚未涂色的横带，
就像带路径减半的并查集；涂上横带 `j` 时令 `skip[j] = j + 1`。每条横带在每条
竖条中只涂一次，所以一条竖条耗时 `O(N + Y)`，整个扫描为 `O(X·(N + Y))`，其中
`X, Y ≤ 2001`。竖条一旦被涂满就提前结束。

注意事项：

- 最上面的白色矩形显示为白色，所以和未被覆盖的纸一样计入颜色 1；
- 可见面积为零的颜色不输出；
- 面积可达 `10⁸`，仍在 32 位范围内，但求和用 64 位。

答案已在 150 个小型随机输入上与逐个单位方格涂色的结果比对。

## 各语言说明

- C++、Go、Java 和 Rust 对每条竖条检查每个矩形。
- Python 先为每条竖条建立覆盖它的矩形列表，从而省去检查；即便如此，它仍是
  这里五种语言中最慢的。在我们的运行中，最大的测试在 CPython 下约需 0.8 秒，
  超过 0.5 秒的限制，所以 Python 解法以 PyPy 3.10 提交，Timus 上用时 0.484 秒
  通过，接近限制。
