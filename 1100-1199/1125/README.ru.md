# 1125. Отмена перекрашиваний на целых расстояниях в сетке

[Timus 1125](https://acm.timus.ru/problem.aspx?space=1&num=1125) · сложность 236 · bitmask

Автор оригинальной задачи — Дмитрий Филимоненков; VI студенческое соревнование по программированию УрГУ, 21 октября 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Поле из `M × N` единичных клеток (`0 ≤ M, N ≤ 50`) раскрашено в чёрный
(`B`) и белый (`W`). Каждый раз, когда клетку посещают, все клетки, центры
которых находятся на целом расстоянии от её центра, меняют цвет, включая
саму посещённую клетку (расстояние 0). По конечным цветам и числу
посещений каждой клетки (до `2·10^9`) вывести начальные цвета.

Ограничение времени: 0,25 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`M N`, затем `M` строк конечных цветов, затем `M` строк по `N` чисел
посещений.

## Выходные данные

`M` строк начальных цветов.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
6 6
BWBBWW
BWBBWB
BBWWBW
BBBBBW
BBWWWW
BBWBBW
2 0 12 46 2 0
3 0 0 0 0 200
4 2 1 1 4 2
4 2 1 1 4 4
0 0 0 0 0 0
2 56 24 4 2 2
```

Вывод:

```
WWBBWW
WBWWBW
WBBBBW
WBWWBW
WBWWBW
WBWWBW
```

## Решение

Важна только чётность перекрашиваний, а значит, только чётность числа
посещений. Клетку `(r, c)` перекрашивает по разу каждая клетка с нечётным
числом посещений на смещении `(dr, dc)` целой длины, то есть с полным
квадратом `dr² + dc²`. В поле 50 × 50 таких смещений всего 405: сама
клетка, её строка и столбец и пифагоровы вроде `(3, 4)`.

Храним каждую строку нечётных посещений битовой маской. Клетки строки
`r`, которые перекрашивает смещение `(dr, dc)`, — это строка `r + dr`,
сдвинутая на `dc`, так что чётность перекрашиваний всей строки `r` —
XOR этих сдвинутых масок по всем смещениям. Перекрасив конечные цвета по
этой чётности, получаем начальные. `O(M · K)` операций с масками для
`K ≤ 405` смещений, около 20 000.

Тонкие места:

- посещённая клетка тоже перекрашивается: расстояние 0 целое;
- число посещений до `2·10^9` важно только по чётности;
- `M` или `N` может быть 0, и тогда выводить нечего.

Ответы проверены прямым вычислением по всем парам клеток с суммированием
посещений на целых расстояниях, на всех тестах и 30 случайных полях.

## Особенности языков

- C++, Go, Java и Rust хранят строки в 64-битных словах; Python —
  в своих целых. Java сдвигает через `>>>`.
