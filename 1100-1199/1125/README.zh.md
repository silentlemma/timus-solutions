# 1125. 撤销网格上整数距离处的颜色翻转

[Timus 1125](https://acm.timus.ru/problem.aspx?space=1&num=1125) · 难度 236 · bitmask

原题作者 Dmitry Filimonenkov，出自 2001 年 10 月 21 日第六届乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`M × N` 个单位格子（`0 ≤ M, N ≤ 50`）被涂成黑（`B`）或白（`W`）。每当一个格子被访问，所有中心与它的中心相距整数距离的格子都会变色，包括被访问的格子本身（距离为
0）。给定最终颜色以及每个格子被访问的次数（至多 `2·10^9`），输出初始颜色。

时间限制：0.25 秒。内存限制：64 MB。

## 输入

`M N`，然后是 `M` 行最终颜色，再是 `M` 行、每行 `N` 个访问次数。

## 输出

`M` 行初始颜色。

## 评测方式

输出按记号逐个比较；多余的空白字符无关紧要。

## 样例

### 样例 1

输入：

```
6 6
BWBBWW
BWBBWB
BBWWBW
BBBBBW
BBWWWW
BBWBBW
2 0 12 46 2 0
3 0 0 0 0 200
4 2 1 1 4 2
4 2 1 1 4 4
0 0 0 0 0 0
2 56 24 4 2 2
```

输出：

```
WWBBWW
WBWWBW
WBBBBW
WBWWBW
WBWWBW
WBWWBW
```

## 解法

只有翻转次数的奇偶性重要，所以只有访问次数的奇偶性重要。格子 `(r, c)` 会被每个访问次数为奇数、位于整数长度偏移 `(dr, dc)`（即 `dr² + dc²`
为完全平方数）处的格子各翻转一次。在 50 × 50 的场地内这样的偏移只有 405 个：格子本身、同行同列，以及像 `(3, 4)` 这样的勾股偏移。

把每一行的奇数次访问存成位掩码。偏移 `(dr, dc)` 翻转的第 `r` 行格子，就是第 `r + dr` 行平移 `dc` 位，所以整行 `r`
的翻转奇偶性就是这些平移后掩码对所有偏移的异或。按这个奇偶性翻转最终颜色即得初始颜色。对 `K ≤ 405` 个偏移为 `O(M · K)`
次掩码运算，约 20 000 次。

注意事项：

- 被访问的格子自己也会翻转：距离 0 是整数；
- 至多 `2·10^9` 的访问次数只有奇偶性有意义；
- `M` 或 `N` 可能为 0，这时没有格子需要输出。

答案经过验证：与一个对所有格子对直接计算、累加整数距离处访问次数的程序比对，覆盖所有测试和 30 个随机场地。
