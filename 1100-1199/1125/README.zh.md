# 1125. 撤销网格上整数距离处的颜色翻转

[Timus 1125](https://acm.timus.ru/problem.aspx?space=1&num=1125) · 难度 236 · bitmask

原题作者 Dmitry Filimonenkov，出自 2001 年 10 月 21 日第六届乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`M × N` 个单位格子（`0 ≤ M, N ≤ 50`）被涂成黑（`B`）或白（`W`）。每当一个格子被访问，所有中心与它的中心相距整数距离的格子都会变色，包括被访问的格子本身（距离为
0）。给定最终颜色以及每个格子被访问的次数（至多 `2·10^9`），输出初始颜色。

时间限制：0.25 秒。内存限制：64 MB。

## 输入

`M N`，然后是 `M` 行最终颜色，再是 `M` 行、每行 `N` 个访问次数。

## 输出

`M` 行初始颜色。

## 评测方式

按颜色行的 token 比较。直接模拟 Python 和新的掩码 Python 分别在 5748
个场地上与独立逐对格子枚举核对，精确判断整数距离，不使用掩码或轴分组。
包括 2×2、2×3 全部颜色/访问奇偶组合，3×3 全部奇偶配合两种均匀最终颜色，
以及空场地、窄场地、随机场地、50×50 奇数/偶数/随机访问和单格奇数访问。

八个新增程序（五个模拟和三个新掩码实现）分别通过 11 个仓库输入及 78
个额外 Docker 主程序输入，并取得精确源码各自的 Accepted。保存输出、返回码
重新与独立计算的逐对答案核对，并绑定源码 SHA。5748 是 Python 执行数，
并非每份原生程序执行数。四个 CPython 模拟压力输入最高 0.0687 秒 CPU、
17288 KB RSS，低于 0.25 秒/64 MB；评测机指标单独记录。

## 解法

首选教学算法直接模拟翻色。一次翻色是与一异或，两次抵消，顺序无关，
所以每个访问次数只保留奇偶。枚举场地范围内的全部有符号偏移 `(dr,dc)`，
要求平方长度是完全平方数，并包括 `(0,0)`。对每个奇数次访问的源格，
按这些偏移翻转所有未越界的目标格。

每个符合整数距离的源格–目标格恰好对应一个偏移，故贡献恰好一次。
翻色是自身的逆运算，对最终颜色应用同一组操作即可恢复初始颜色。
边长至多 50 时 `K≤405`。生成偏移需 `O((M+N)²)` 次基本检查，
模拟时间 `O(MNK)`，空间 `O(MN+K)`。五个新实现使用普通格子与坐标循环，
不使用行掩码移位，各自有自己的 Accepted。

距离零必须包括。访问数至多二十亿，仅取奇偶，输入可用有符号 32 位整数。
任一维为零时输出 `M` 个空行。所有以前的掩码实现均保留。

## 优化解法

翻色就是与一异或，两次翻色抵消，因此访问顺序无关，只需保存次数的奇偶。
令 `R[r]` 为第 `r` 行被访问奇数次的位掩码。对满足 `dr²+dc²` 为完全平方数
的所有偏移 `(dr,dc)`，把对应源行移位后异或，最后只保留低 `N` 位。
每个源格与目标格的组合恰好计入一次；翻色的逆操作仍是翻色，故把此奇偶
掩码作用于最终颜色即可恢复初始颜色。

五个原 Accepted 源码枚举包括 `(0,0)` 的所有有符号偏移。在 50×50 上共
405 个，小场地只需其子集。若有 `K` 个偏移，时间为 `O(MN+MK)` 次掩码操作，
含输入、输出及偏移生成。`N≤50` 时原生掩码在一个 64 位字中；Python 是大整数，
移位和异或的代价取决于其位块数。原生数据占 `O(MN+M+K)` 字或字符；原 Python
还保留全部输入 token 与访问整数，共 `O(MN+M+K)` 对象。五份原文件均保留。

距离零也必须计入。访问数至多二十亿，只需要最低位，输入计算可用有符号
32 位整数。任一维为零时输出 `M` 个空行，没有格子需要恢复。

新增三个实现保持同一个奇偶掩码算法，因此使用 `_optimized`。
把坐标轴与每个正偏移的四种符号合并。令 `C` 是所有 `R[r]` 的异或，`F` 的
低 `N` 位全为一。同一目标行内的源格贡献为 `F`（当 `popcount(R[r])` 为奇数），
同列贡献为 `C`。原点被计算了两次，需再异或 `R[r]`，恢复所需的一次贡献。

对每个整数长度的 `dr>0,dc>0`，取 `T = R[r−dr] XOR R[r+dr]`，越界行按零处理，
再异或 `(T<<dc) XOR (T>>dc)`。四种符号恰好各计一次，轴与原点不在这些项中。
最后保留场地列。正偏移至多 `P=52` 对，而非 405 个有符号偏移；时间为
`O(MN+MP)` 次掩码操作。保存颜色、行掩码与 `P` 对偏移。C++/Java 另有固定
5000 项平方表，Python 平方集合为 `O(M+N)` 项。Python 中间结果可达 `2N−1` 位，
不能视为一个机器字。原生移位均小于 64，丢弃的高位不影响低 `N` 位；Java 用 `>>>`。

## 各语言说明

五个新 `simulation` 是首选基础解。当前优化均与同语言模拟比较。
两个 Python 掩码版本均为 0.046 秒，模拟为 0.093 秒，时间减少 50.5%。
原版本内存 900/564 KB，增加 59.6%；分组版本 580/564 KB，增加 2.8%。
两者均按时间准入，明确内存代价。

分组 C++ 内存 132/136 KB，仅减少 2.9%；Java 424/536 KB，仅减少 20.9%，
各自时间相同，现列为 Accepted 替代实现。`_optimized` 文件名指向保留的
原掩码实现对，当时相对该掩码基础实现确有 71.1%、56.2% 内存改进。
这些是历史比较，不是相对当前模拟的百分比。未删除、改名或复制源码，
也不因文件名就认定当前优化准入。
