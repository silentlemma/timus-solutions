# 1180. Кто выиграет, если камни берут степенями двойки

[Timus 1180](https://acm.timus.ru/problem.aspx?space=1&num=1180) · сложность 89 · games

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В кучке `N ≤ 10²⁵⁰` камней. Двое по очереди берут из неё степень двойки
(1, 2, 4, 8, …) камней; кто взял последний камень, тот выиграл. Сказать,
кто выигрывает при правильной игре, а если первый — наименьшее число
камней, которое он может взять первым ходом, сохранив выигрыш.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, до 251 цифры.

## Выходные данные

`2` либо `1` и наименьший выигрывающий первый ход.

## Примеры

### Пример 1

Ввод:

```
8
```

Вывод:

```
1
2
```

## Решение

Ни одна степень двойки не делится на 3, поэтому из кучки, кратной 3,
любой ход оставляет некратную 3. Из любой другой кучки взятие 1 или 2
камней — остатка по модулю 3 — оставляет кратную 3. Ноль кратен 3, так что
игрок, всегда оставляющий кратную 3 кучку, берёт последний камень. Второй
выигрывает ровно тогда, когда `N` делится на 3; иначе выигрывает первый, а
наименьший выигрывающий ход — `N mod 3`, ведь никакой другой ход в 1 или 2
камня не оставляет кратную 3. `N mod 3` — это сумма цифр по модулю 3.
`O(цифр)`.

Тонкие места:

- в `N` до 251 цифры, так что как число его не прочитать;
- выигрывающий ход должен быть наименьшим, а 1 и 2 — степени двойки, так
  что это и есть сам остаток.

Ответы проверены прямым перебором игры для всех `N` до 399.
