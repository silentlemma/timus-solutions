# 1180. 每次取 2 的幂个石子时谁会获胜

[Timus 1180](https://acm.timus.ru/problem.aspx?space=1&num=1180) · 难度 89 · games

原题作者 Dmitry Filimonenkov，出自 2002 年 2 月 16 日在叶卡捷琳堡举行的第三届乌拉尔国立大学个人程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `N ≤ 10²⁵⁰` 个石子。两人轮流取走 2 的幂（1、2、4、8、……）个石子，取走最后
一个石子的人获胜。判断在最优策略下谁获胜；若先手获胜，还要给出先手第一步能保证
获胜的最少取石数。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，至多 251 位。

## 输出

`2`，或者 `1` 和先手获胜的最小第一步。

## 样例

### 样例 1

输入：

```
8
```

输出：

```
1
2
```

## 解法

2 的幂都不能被 3 整除，所以从 3 的倍数出发，任何一步都会留下不是 3 的倍数的石子
堆。从其他任何一堆出发，取走 1 或 2 个（即模 3 的余数）就留下 3 的倍数。0 是 3
的倍数，所以总是留下 3 的倍数的一方会取走最后一个石子。后手获胜当且仅当 `N` 能被
3 整除；否则先手获胜，最小的获胜步就是 `N mod 3`，因为其他 1 或 2 个的取法都不会
留下 3 的倍数。`N mod 3` 等于各位数字之和模 3。`O(位数)`。

注意事项：

- `N` 至多 251 位，64 位整数不够用；
- 获胜的一步必须是最小的，而 1 和 2 都是 2 的幂，所以余数本身就是答案。

答案已对 399 以内的每个 `N` 与直接的博弈搜索核对。

## 优化解法

优化解法（C++、Java）一边用 `getchar` 和 `System.in.read` 读取，一边逐位累加
数字，不把这个数存成字符串，并逐字节输出简短的答案。C++：88 KB，而不是
384 KB，时间不变。Java：0.093 s，而不是 0.125 s；328 KB，而不是 1568 KB。

- 所有语言都把数字当作文本读入，并对各位求和模 3。
