# 1110. Все вычеты, N-я степень которых даёт остаток Y

[Timus 1110](https://acm.timus.ru/problem.aspx?space=1&num=1110) · сложность 53 · bruteforce

Оригинальная задача — Болгарская национальная олимпиада по информатике, первый день.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны `N`, `M` и `Y` (`0 < N < 999`, `1 < M < 999`, `0 < Y < 999`). Найти
все целые `X` из `[0, M − 1]`, для которых `X^N mod M = Y`.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N M Y` в одной строке.

## Выходные данные

Все такие `X` по возрастанию через пробел или `-1`, если их нет.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
2 6 4
```

Вывод:

```
2 4
```

## Решение

Кандидатов меньше тысячи, поэтому перебираем каждый `X` и считаем
`X^N mod M` быстрым возведением в степень, беря остаток по `M` после
каждого умножения. `O(M log N)`.

Тонкие места:

- `Y` может быть равен `M` или больше; остаток таким не бывает, и тогда
  ответ `-1`;
- само `X^N` астрономически велико: остаток берётся на каждом шаге, а
  произведения остаются меньше `M²` и помещаются в 32 бита;
- при `N = 1` ответ — одно `Y`, если `Y < M`.

Ответы проверены простым повторным умножением, `N` умножений для каждого
`X`.

## Оптимизированные решения

Оптимизированное решение на C++ печатает каждый корень сразу, как только
он найден, а не собирает корни в вектор: 128 КБ вместо 196 КБ при том же
времени. Оптимизированное решение на Java читает три числа побайтно из
`System.in` вместо создания `Scanner`, который один стоит больше
мегабайта: 412 КБ вместо 1568 КБ при том же времени.

## Особенности языков

- Python использует встроенный `pow` с тремя аргументами; в остальных
  языках есть небольшая функция возведения в степень.
