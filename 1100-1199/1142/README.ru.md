# 1142. Число упорядочений N объектов с возможными равенствами

[Timus 1142](https://acm.timus.ru/problem.aspx?space=1&num=1142) · сложность 155 · combinatorics

Оригинальная задача с Timus; автор и источник не указаны.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Между любыми двумя из `N` сравнимых объектов выполняется одно из `a = b`,
`a < b`, `b < a`. Посчитать различные способы упорядочить `N` объектов в
этом смысле, с возможными равенствами: для трёх объектов их 13, от
`a = b = c` до `c < b < a`. Ответить для нескольких `N` от 2 до 10; ввод
заканчивается числом `-1`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Значения `N` по одному в строке, затем `-1`.

## Выходные данные

Количество для каждого `N`, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
2
3
-1
```

Вывод:

```
3
13
```

## Решение

Упорядочение с равенствами — это последовательность групп равных
объектов, строго возрастающих. Посмотрим на первую группу: это любое
непустое множество из `k` объектов, выбираемое `C(n, k)` способами, а
оставшиеся `n − k` объектов образуют своё упорядочение с равенствами.
Значит, при `a(0) = 1`

`a(n) = Σ_{k=1..n} C(n, k)·a(n − k)`.

Это упорядоченные числа Белла (числа Фубини) 1, 1, 3, 13, 75, 541, …;
наибольшее нужное `a(10) = 102247563` помещается в 32 бита. Таблица
строится один раз с треугольником Паскаля, а каждый запрос — просто
обращение к ней. `O(10²)` на построение.

Тонкие места:

- количества запросов во входе нет, читаем до `-1`;
- одно и то же `N` может спрашиваться несколько раз.

Значения сверены с независимой формулой `a(n) = Σ k!·S(n, k)` через
числа Стирлинга второго рода, а для `n ≤ 6` — с перечислением всех
упорядочений.
