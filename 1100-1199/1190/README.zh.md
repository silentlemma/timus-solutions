# 1190. 只标出部分含量的巧克力配料表能否诚实

[Timus 1190](https://acm.timus.ru/problem.aspx?space=1&num=1190) · 难度 339 · greedy

原题作者 Leonid Volkov，出自 2002 年 3 月 2 日第五届中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

配料表按含量不增的顺序列出 `N ≤ 5000` 种配料；其中一些标出了含量，单位是万分之
一（百分之一的百分之一）。每种配料的真实含量是 1 到 10000 之间的整数，且总和恰为
100%。判断是否存在与顺序和所有标出值都相符的真实含量。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后对每种配料给出名称、`0`，或者 `1` 及其含量。

## 输出

`YES` 或 `NO`。

## 样例

### 样例 1

输入：

```
4
Water 0
Cocoa-butter 0
Cocoa-powder 1 4000
Lecithin 0
```

输出：

```
NO
```

## 解法

由于含量沿列表向下不增，一个未标出含量的配料至少等于它下方最近的标出值（没有则
为 1），至多等于它上方最后一个标出值（没有则为 10000）。标出值是固定的。所有含量
都取最小值，得到总和最小的合法不增序列；都取最大值，得到总和最大的序列。

两者之间的每个总和也都能达到：从最小序列出发，把第一个含量逐一增加到它的最大值，
再增加第二个，依此类推；序列始终保持不增，每一步总和增加一。所以答案为 `YES`
当且仅当最小总和不超过 10000 且最大总和不小于 10000。`O(N)`。

注意事项：

- 未知含量也至少为 1，这可能使最小总和超过 100%；
- 若上方没有标出值，未知含量最多可以到 100%，而不只到第一个标出值；
- 完全没有标出值的配料表总是诚实的，因为 `N ≤ 5000` 个至少为 1 的含量放得进 10000。

答案已在 300 份随机配料表和所有测试上与另一份独立编写的解答比对。

## 各语言说明

- 所有语言都从两端各扫一遍，并记住最近的标出值。
