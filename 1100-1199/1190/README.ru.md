# 1190. Может ли надпись на шоколадке с несколькими долями быть честной

[Timus 1190](https://acm.timus.ru/problem.aspx?space=1&num=1190) · сложность 339 · greedy

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На обёртке перечислены `N ≤ 5000` продуктов в порядке невозрастания
долей; у некоторых доля указана, в сотых долях процента. Каждая настоящая
доля — целое число от 1 до 10000 сотых, и все они в сумме дают ровно
100%. Определить, существуют ли настоящие доли, согласные с порядком и со
всеми указанными значениями.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем для каждого продукта его название, `0` или `1` и доля.

## Выходные данные

`YES` или `NO`.

## Примеры

### Пример 1

Ввод:

```
4
Water 0
Cocoa-butter 0
Cocoa-powder 1 4000
Lecithin 0
```

Вывод:

```
NO
```

## Решение

Поскольку доли вниз по списку не растут, продукт без указанной доли не
меньше ближайшей указанной доли ниже него (или 1, если её нет) и не
больше последней указанной доли выше него (или 10000). Указанные доли
фиксированы. Если взять все доли наименьшими, получится допустимый
невозрастающий список с наименьшей суммой, а если наибольшими — с
наибольшей.

Достижима и любая сумма между ними: начиная с наименьшего списка,
поднимаем первую долю по единице до её максимума, затем вторую и так
далее; список всё время остаётся невозрастающим, а сумма растёт на единицу
за шаг. Значит, ответ `YES` ровно тогда, когда наименьшая сумма не больше
10000, а наибольшая не меньше 10000. `O(N)`.

Тонкие места:

- неизвестная доля всё равно не меньше 1, и это может вытолкнуть
  наименьшую сумму за 100%;
- если выше нет указанных долей, неизвестная доля может быть до 100%, а не
  только до первой указанной;
- надпись вообще без указанных долей всегда честна: `N ≤ 5000` долей по
  меньшей мере 1 помещаются в 10000.

Ответы сверены с отдельно написанным решением на 300 случайных надписях и
на всех тестах.

## Особенности языков

- Во всех языках два прохода, с каждого конца, с запоминанием ближайшей
  указанной доли.
