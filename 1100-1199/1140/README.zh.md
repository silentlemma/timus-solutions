# 1140. 漫步之后回到六边形网格中心的最短路线

[Timus 1140](https://acm.timus.ru/problem.aspx?space=1&num=1140) · 难度 383 · geometry

原题出自 2001 年 10 月 17–18 日在雷宾斯克举行的俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

沼泽被划分为六边形格子，相邻格子之间六个方向中的三个被命名为 `X`、`Y` 和
`Z`，其中 `Y` 位于 `X` 与 `Z` 之间。一名学生从中心格出发，走过最多 32000 段
直线，每段由方向和非零的带符号长度给出；长度为负表示反方向。学生离中心
从不超过 100 格。请用同样的格式给出一条经过格子最少的返回中心的路线。

时间限制：1 秒。内存限制：64 MB。

## 输入

`n`（`1 ≤ n ≤ 32000`），然后 `n` 行，每行是方向字母和带符号长度。

## 输出

返回路线的段数 `m ≥ 0`，然后是各段。

## 评测方式

任何最短路线都被接受。检查程序验证格式、路线终点是中心，以及总长度等于
最后一格到中心的六边形距离。

## 样例

### 样例 1

输入：

```
4
Z -2
Y 3
Z 3
X -1
```

输出：

```
2
Y -2
Z -2
```

## 解法

在六边形网格中，中间的方向是另外两个方向之和：沿 `Y` 走一步，与先沿 `X`
走一步再沿 `Z` 走一步到达同一格。因此按方向累加长度，把终点写成
`a·X + b·Z`，其中 `a = X + Y`，`b = Z + Y`。返回路线若沿 `Y` 走 `m` 步，
还需反向沿 `X` 走 `a − m` 步、沿 `Z` 走 `b − m` 步，共
`|a − m| + |m| + |b − m|` 步。`m` 到点 `a`、`0`、`b` 的距离之和在它们的中位数
处最小，所以取 `m` 为 `a`、`0`、`b` 的中位数，并输出 `X −(a − m)`、`Y −m`、
`Z −(b − m)` 中非零的部分。`O(n)`。

几何状态是三个总量及至多三个返程段候选，所有版本用 O(1)
个有界数值字，无递归。简单 C++/Go/Java 逐步读取，只保留有界
缓冲及该状态。简单 Python 保存完整输入和 split 记号，Rust
保存输入 String，另占 O(I) 字节。优化 Go/Rust 不保留完整输入；
Rust 因此有别于基础版。优化 Python 用 4096 字节块、split 片段
及未完成记号，最长记号 T 时为 O(4096+T)，而非 O(I)。读取
I 字节另加 O(I) 时间，几何更新为 O(n)。

注意事项：

- 当 `a` 与 `b` 同号时，部分路程沿 `Y` 走；异号时 `m = 0`，不用 `Y`；
- 不允许长度为零的段，所以要去掉它们，答案可能是 `0` 段；
- 即使路线终点在中心，输入也必须至少有一段（测试 03）；生成器在模式 1
  下若因请求规模过小而会生成空路线，就改用一对互相抵消的段；
- 最短路线可能不止一条，任何一条都被接受。

答案已用检查程序在所有测试和 1200 次随机漫步上验证；检查程序中的距离公式
已与对中心 100 格以内所有格子的广度优先搜索结果比对。

## 优化解法

两个原生优化版保留相同中位数公式。Go 将 map[string]int
换为三个整数数组、三数 sort.Ints 换为显式 clamp、fmt.Fscan
换为 Scanner/ScanWords 及 strconv.Atoi，fmt 格式行换为小字节
输出缓冲。基础版本来就只存三个总量。Rust 以 stdin.lock().bytes()
及直接有符号数读取替代 read_to_string 和通用 token 解析，
总量改为三个 i32 数组。其基础版本来就用 min/max 求中位数；
clamp 是相同常数规模操作，不是新几何算法。继续省略零长度，
两份简单源码均保留。

通过评测的 Rust 1.75 x64 版本耗时 0.031 秒，基础版为 0.015 秒，内存为 188 KB，基础版为 344 KB。

精确源码缓存确认复用 C++/Java 在低于 1 MiB 时仅按时间合格。
简单 Python 0.125 s/776 KB 未过小样本时间参考，由独立
0.062 s/828 KB 修订覆盖。简单 Go 通过小样本两项，优化 Go
仅比时间；两个 Rust 都通过低于 1 MiB 的普通时间名次。使用
统一[排名标准](../../RATING_CRITERIA.md)，教学源码不加星号，
不创建相同优化副本。
