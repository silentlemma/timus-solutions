# 1172. Число круговых маршрутов по трём островам только на кораблях

[Timus 1172](https://acm.timus.ru/problem.aspx?space=1&num=1172) · сложность 548 · combinatorics

Автор оригинальной задачи — Mugurel Ionut Andreica; Romanian Open Contest, декабрь 2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На трёх островах по `N ≤ 30` городов. Корабли ходят между любыми двумя
городами разных островов, а по острову перемещаться нельзя. Начиная с
заданного города, посчитать круговые маршруты, которые посещают каждый
другой город ровно один раз и возвращаются; маршрут и он же, прочитанный
в обратном порядке, считаются одним.

Ограничение времени: 1 секунда. Ограничение памяти: 16 МБ.

## Входные данные

`N`.

## Выходные данные

Число маршрутов; в нём до 121 цифры.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
16
```

## Решение

Разделим маршрут на узор островов и выбор городов. Узор — циклическая
последовательность из `3N` меток островов, начинающаяся с острова
туриста, по `N` меток каждого вида и без двух одинаковых соседей, включая
последнюю и первую. При фиксированном узоре остальные `N − 1` городов
родного острова заполняют его места `(N − 1)!` способами, а каждый другой
остров — `N!` способами. Маршрут, прочитанный назад, даёт другую
последовательность из того же начала (в маршруте не меньше трёх городов),
так что сумма делится пополам.

Узоры считает `ways[a][b][c][i]`: последовательности, которые начинаются
на острове 0, используют `a`, `b` и `c` мест трёх островов и кончаются на
острове `i`. Каждое значение — сумма двух значений с одним местом острова
`i` меньше, кончающихся на других островах. Ответ считает полные
последовательности, которые не кончаются на острове 0. Хранятся только две
плоскости с фиксированным `a`, так что длинных чисел немного. `O(N³)`
сложений длинных чисел.

Тонкие места:

- цикл запрещает и последнему городу быть на родном острове;
- начальный город фиксирован, поэтому родной остров даёт `(N − 1)!`, а не
  `N!`;
- полная таблица при `N = 30` содержала бы около 90 000 длинных чисел,
  а двум плоскостям нужно лишь около 6 000.

Ответы сверены с полным перебором всех порядков при `N ≤ 3` и с отдельно
написанным решением для всех `N` до 30.

Учебный Python строит последовательность островов по одной позиции. Словарь считает префиксы по трём использованным количествам городов и последнему острову. Для продолжения выбираем другой остров, где ещё есть свободное место, и прибавляем число способов в следующий слой. Храним только текущую и следующую длины. На полной длине отбрасываем варианты с последним городом на домашнем острове, расставляем города по местам и делим на два. На каждой длине O(N²) состояний, так как сумма трёх счётчиков равна длине. DP выполняет O(N³) сложений больших чисел и хранит O(N²) счётчиков.

## Оптимизированные решения

Go-версия сохраняет DP с двумя слоями, но хранит количества шаблонов в трёх разрядах по основанию 10⁹ вместо выделения math/big-объектов для каждой клетки. После фиксации начального острова у маршрута длины до 90 позиций не больше 2⁸⁹ островных слов. Это меньше 10²⁷, поэтому трёх разрядов хватает и промежуточным значениям. Два фиксированных слоя занимают 69192 байта разрядов. Для итоговых умножений на факториалы используются 14 разрядов: 126 цифр покрывают не более 122 цифр до деления пополам. Малый множитель не больше 30²·29, поэтому достаточно 64-битных произведений и переносов. Всё вычисляется, таблицы ответов нет. Время — O(N³) сложений фиксированной длины. Стандартные дескрипторы заменяют fmt; обычная база math/big и принятые версии остальных четырёх языков сохранены.

Принятые базовые реализации [1172_combinatorics.cpp](1172_combinatorics.cpp), [1172_combinatorics.java](1172_combinatorics.java), [1172_combinatorics.py](1172_combinatorics.py), [1172_combinatorics.rs](1172_combinatorics.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
