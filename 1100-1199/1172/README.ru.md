# 1172. Число круговых маршрутов по трём островам только на кораблях

[Timus 1172](https://acm.timus.ru/problem.aspx?space=1&num=1172) · сложность 549 · combinatorics

Автор оригинальной задачи — Mugurel Ionut Andreica; Romanian Open Contest, декабрь 2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На трёх островах по `N ≤ 30` городов. Корабли ходят между любыми двумя
городами разных островов, а по острову перемещаться нельзя. Начиная с
заданного города, посчитать круговые маршруты, которые посещают каждый
другой город ровно один раз и возвращаются; маршрут и он же, прочитанный
в обратном порядке, считаются одним.

Ограничение времени: 1 секунда. Ограничение памяти: 16 МБ.

## Входные данные

`N`.

## Выходные данные

Число маршрутов; при больших `N` в нём десятки цифр.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
16
```

## Решение

Разделим маршрут на узор островов и выбор городов. Узор — циклическая
последовательность из `3N` меток островов, начинающаяся с острова
туриста, по `N` меток каждого вида и без двух одинаковых соседей, включая
последнюю и первую. При фиксированном узоре остальные `N − 1` городов
родного острова заполняют его места `(N − 1)!` способами, а каждый другой
остров — `N!` способами. Маршрут, прочитанный назад, даёт другую
последовательность из того же начала (в маршруте не меньше трёх городов),
так что сумма делится пополам.

Узоры считает `ways[a][b][c][i]`: последовательности, которые начинаются
на острове 0, используют `a`, `b` и `c` мест трёх островов и кончаются на
острове `i`. Каждое значение — сумма двух значений с одним местом острова
`i` меньше, кончающихся на других островах. Ответ считает полные
последовательности, которые не кончаются на острове 0. Хранятся только две
плоскости с фиксированным `a`, так что длинных чисел немного. `O(N³)`
сложений длинных чисел.

Тонкие места:

- цикл запрещает и последнему городу быть на родном острове;
- начальный город фиксирован, поэтому родной остров даёт `(N − 1)!`, а не
  `N!`;
- полная таблица при `N = 30` содержала бы около 90 000 длинных чисел,
  а двум плоскостям нужно лишь около 6 000.

Ответы сверены с полным перебором всех порядков при `N ≤ 3` и с отдельно
написанным решением для всех `N` до 30.

- Python, Go и Java используют свои длинные целые; C++ и Rust хранят
