# 1128. 划分度数至多为三的图，使每个顶点在自己一侧至多有一个邻居

[Timus 1128](https://acm.timus.ru/problem.aspx?space=1&num=1128) · 难度 412 · greedy

原题作者 Dmitry Filimonenkov，出自 2001 年 10 月 21 日第六届乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `N ≤ 7163` 个孩子；每个孩子至多有三个对头，且敌对关系是相互的。把孩子们分成两组，使每个孩子在自己组里至多有一个对头。输出较小的一组（大小相同时输出含孩子
1 的那组）：先输出它的大小，再输出组内的孩子。若无法划分，输出 `NO SOLUTION`。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N`，然后是 `N` 行：一个孩子的对头数，接着是他们的编号。

## 输出

较小一组的大小，然后是该组的孩子（用空格分隔），或 `NO SOLUTION`。

## 评测方式

接受任何一个正确的划分。检查程序验证大小、所列的组是较小的一组（大小相同时包含孩子 1），并且每个孩子（无论是否在列）在自己一侧至多有一个对头。

## 样例

### 样例 1

输入：

```
8
3 2 3 7
3 1 3 7
3 1 2 7
1 6
0
2 4 8
3 1 2 3
1 6
```

输出：

```
3
3 6 7
```

## 解法

划分总是存在，简单的局部搜索就能找到。先把所有人放在同一组。只要某个孩子在自己组里有两个或更多对头，就把他移到另一组：他至多有三个对头，所以另一侧至多一个，同组的对头对数至少减少一。这个数一开始至多为
`3N/2`，所以移动至多进行这么多步就会停止，而停止时每个孩子在自己一侧至多有一个对头。用工作列表保存待检查的孩子，每次移动后只加入被移动的孩子和他的对头。`O(N)`。

注意事项：

- 答案永远不会是 `NO SOLUTION`：度数至多为三时总能划分；
- 输出的必须是划分中较小的一组，大小相同时输出包含孩子 1 的那组；
- 较小的一组可能为空，此时输出 `0` 和一个空行。

答案在所有测试以及 60 个随机图（包括四个孩子两两敌对的小组）上都用检查程序验证过。
