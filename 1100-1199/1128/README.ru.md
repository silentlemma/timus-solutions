# 1128. Разбиение графа степени три, при котором у каждой вершины не больше одного соседа в её части

[Timus 1128](https://acm.timus.ru/problem.aspx?space=1&num=1128) · сложность 412 · greedy

Автор оригинальной задачи — Дмитрий Филимоненков; VI студенческое соревнование по программированию УрГУ, 21 октября 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `N ≤ 7163` детей; у каждого ребёнка не больше трёх недругов, и
вражда взаимна. Разбить детей на две группы так, чтобы у каждого ребёнка
в его группе было не больше одного недруга. Вывести меньшую группу (при
равных размерах — ту, где ребёнок 1): её размер, затем её детей. Если
разбиения нет, вывести `NO SOLUTION`.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк: число недругов ребёнка, затем их номера.

## Выходные данные

Размер меньшей группы, затем её дети через пробел, или `NO SOLUTION`.

## Проверка

Подходит любое правильное разбиение. Проверяющая программа убеждается в
размере, в том, что указанная группа меньшая (или содержит ребёнка 1 при
равных размерах), и что у каждого ребёнка, указанного или нет, в его
части не больше одного недруга.

## Примеры

### Пример 1

Ввод:

```
8
3 2 3 7
3 1 3 7
3 1 2 7
1 6
0
2 4 8
3 1 2 3
1 6
```

Вывод:

```
3
3 6 7
```

## Решение

Разбиение существует всегда, и его находит простой локальный поиск.
Начнём со всех в одной группе. Пока у какого-то ребёнка в его группе два
или больше недругов, переводим его в другую группу: недругов у него не
больше трёх, значит, на другой стороне не больше одного, и число пар
недругов в одной группе уменьшается хотя бы на единицу. Вначале это число
не больше `3N/2`, так что переводы закончатся не позже чем за столько
шагов, а когда они закончатся, у каждого ребёнка в его части не больше
одного недруга. Список работы хранит детей для проверки, и после
перевода в него добавляются только переведённый ребёнок и его недруги.
`O(N)`.

Тонкие места:

- `NO SOLUTION` никогда не бывает ответом: степень не больше трёх всегда
  допускает разбиение;
- выводить нужно меньшую группу разбиения, а при равных размерах — ту, где
  ребёнок 1;
- меньшая группа может быть пустой: выводится `0` и пустая строка.

Ответы проверены проверяющей программой на всех тестах и 60 случайных
графах, в том числе с группами из четырёх детей, которые все враждуют.
