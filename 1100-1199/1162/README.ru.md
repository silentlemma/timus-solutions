# 1162. Можно ли цепочкой обменов валют с комиссиями увеличить капитал

[Timus 1162](https://acm.timus.ru/problem.aspx?space=1&num=1162) · сложность 197 · shortest_paths

Автор оригинальной задачи — Николай Дуров; северный подрегион полуфинала ACM ICPC Северо-Восточной Европы 2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `N ≤ 100` валют и `M ≤ 100` обменных пунктов, каждый работает между
двумя валютами в обе стороны со своими курсом и комиссией для каждого
направления: обмен суммы `x` даёт `(x − комиссия)·курс`, и сумма никогда не
может стать отрицательной. Имея `V` единиц валюты `S`, определить, есть ли
последовательность обменов, которая кончается в валюте `S` с суммой больше
`V`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, `M`, `S` и `V`, затем `M` строк с двумя валютами, курсом и комиссией
в каждую сторону.

## Выходные данные

`YES` или `NO`.

## Примеры

### Пример 1

Ввод:

```
3 2 1 10.0
1 2 1.0 1.0 1.0 1.0
2 3 1.1 1.0 1.1 1.0
```

Вывод:

```
NO
```

### Пример 2

Ввод:

```
3 2 1 20.0
1 2 1.0 1.0 1.0 1.0
2 3 1.1 1.0 1.1 1.0
```

Вывод:

```
YES
```

## Решение

Валюты — вершины, каждое направление обменного пункта — ребро. Пусть
`best[c]` — наибольшая сумма в валюте `c`, которую можно получить, начиная
с `best[S] = V`. Релаксация Беллмана — Форда
`best[b] = max(best[b], (best[a] − комиссия)·курс)`, допустимая только при
`best[a] ≥ комиссии`, улучшает эти суммы проход за проходом. Каждый шаг
возрастает по сумме, так что больше денег никогда не хуже.

Если выгодных циклов нет, наилучшие суммы достигаются простыми путями, в
которых не больше `N − 1` обменов, и к этому моменту проходы перестают
что-то менять. Поэтому если проход что-то меняет и после `N` проходов,
достижим выгодный цикл; если ходить по нему снова и снова, любая комиссия
становится пренебрежимой, а путь обратно в `S` есть, потому что каждый
пункт работает в обе стороны, так что ответ `YES`. Ответ `YES` и тогда,
когда `best[S]` превысило `V`. Иначе `NO`. `O(N·M)`.

Тонкие места:

- комиссия берётся сначала и в исходной валюте, а обмен суммы меньше
  комиссии невозможен;
- выгода может требовать крюка через цикл далеко от `S`;
- числа double сравниваются с небольшим допуском, чтобы шум округления не
  выглядел как выгода.

Ответы сверены на всех тестах и на 150 случайных входах с той же
релаксацией в точных дробях, выполненной в десять раз дольше.
