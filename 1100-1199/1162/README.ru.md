# 1162. Можно ли цепочкой обменов валют с комиссиями увеличить капитал

[Timus 1162](https://acm.timus.ru/problem.aspx?space=1&num=1162) · сложность 185 · shortest_paths

Автор оригинальной задачи — Николай Дуров; северный подрегион полуфинала ACM ICPC Северо-Восточной Европы 2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `N ≤ 100` валют и `M ≤ 100` обменных пунктов, каждый работает между
двумя валютами в обе стороны со своими курсом и комиссией для каждого
направления: обмен суммы `x` даёт `(x − комиссия)·курс`, и сумма никогда не
может стать отрицательной. Имея `V` единиц валюты `S`, определить, есть ли
последовательность обменов, которая кончается в валюте `S` с суммой больше
`V`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, `M`, `S` и `V`, затем `M` строк с двумя валютами, курсом и комиссией
в каждую сторону.

`1 ≤ S ≤ N ≤ 100`, `1 ≤ M ≤ 100`, `0 ≤ V ≤ 1000`.
Курсы лежат в `[0.01, 100]`, комиссии — в `[0, 100]`; они заданы не более
чем с двумя дробными цифрами. Число дробных цифр в `V` не ограничено.
Для любой последовательности, использующей каждый обменный пункт не
более одного раза, отношение конечной суммы к начальной меньше `10000`.

## Выходные данные

`YES` или `NO`.

## Примеры

### Пример 1

Ввод:

```
3 2 1 10.0
1 2 1.0 1.0 1.0 1.0
2 3 1.1 1.0 1.1 1.0
```

Вывод:

```
NO
```

### Пример 2

Ввод:

```
3 2 1 20.0
1 2 1.0 1.0 1.0 1.0
2 3 1.1 1.0 1.1 1.0
```

Вывод:

```
YES
```

## Решение

Валюты — вершины, каждое направление обмена — ребро. Применяем
Беллмана — Форда: `best[c]` — наибольшая достижимая сумма в валюте `c`.
Изначально достижима только `S` с суммой `V`. Каждый проход читает старый
массив и записывает новый: после прохода `k` учтены пути не длиннее `k`
обменов. Сначала вычитаем комиссию, затем умножаем на курс; недоступные
по сумме обмены пропускаем.

Вместо чисел с плавающей точкой используем точные целые. Пусть `P` —
максимум из двух и числа дробных цифр в `V`, а начальный общий знаменатель
`D = 10^P`. Курсы и комиссии храним умноженными на 100. Для числителя
суммы `x`, курса `R` и комиссии `C` новый числитель равен
`(x − C·(D/100))·R`, а знаменатель — `100·D`. Сохранённые суммы и начальную
сумму тоже умножаем на 100, затем обновляем `D`. Все сравнения точны,
включая проверку достаточности денег на комиссию.

Если достижимых выгодных циклов нет, удаление участка между повторными
посещениями вершины не уменьшает сумму. Поэтому достаточно простых путей
не длиннее `N − 1` обменов. Улучшение на проходе `N` доказывает достижимость
выгодного цикла. При положительных курсах и неотрицательных комиссиях его
множитель больше единицы, а повторение неограниченно увеличивает капитал.
Каждый пункт работает в обе стороны, поэтому со временем хватит денег
на обратный путь в `S`. Отвечаем `YES` при таком улучшении или сразу при
`best[S] > V`; если проход ничего не улучшил, отвечаем `NO`.

Выполняется `O(N·M)` релаксаций и копируется `O(N²)` элементов массивов.
Целые имеют `O(P+N)` цифр, поэтому точная арифметика требует
`O(N·(N+M)·(P+N))` времени и `O(N·(P+N)+M)` памяти.

Тонкие места:

- комиссия берётся сначала в исходной валюте; нулевая сумма допустима,
  а недостижимая валюта должна отличаться от нулевой суммы;
- для прибыли может понадобиться цикл далеко от `S`;
- в тесте **08** сумма `0.000000001` удваивается: абсолютный допуск
  скрывает прибыль, а его удаление при вычислениях с плавающей точкой
  может принять округление за прибыль. `V` нужно читать точно, без
  округления до двух дробных цифр.

Проверены все 8 сохранённых тестов, 101 вход генератора, 2500 случайных
входов с полным перебором простых путей и циклов в точных дробях и
600 случаев точного равенства и малых отклонений от порога прибыльности.
