# 1104. Наименьшее основание, в котором число делится на основание минус один

[Timus 1104](https://acm.timus.ru/problem.aspx?space=1&num=1104) · сложность 95 · number_theory

Автор оригинальной задачи — Игорь Гольдберг; Tetrahedron Team Contest, май 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Число записано цифрами `0`–`9` и буквами `A`–`Z` (`A` = 10, …, `Z` = 35),
их не больше `10^6`. Найти наименьшее основание `k`, `2 ≤ k ≤ 36`, в
котором эта строка — правильная запись числа, делящегося на `k − 1`.
Если такого нет, вывести `No solution.`

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Одна строка с цифрами.

## Выходные данные

`k` в десятичной записи или `No solution.`

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
A1A
```

Вывод:

```
22
```

## Решение

Так как `k ≡ 1 (mod k − 1)`, любая степень `k` даёт остаток 1 по модулю
`k − 1`, и число в системе с основанием `k` имеет тот же остаток, что и
сумма его цифр, — то же правило, что признак делимости на 9 в десятичной
системе. Поэтому один раз считаем сумму цифр `S` и наибольшую цифру `m`,
затем перебираем `k` от `max(m + 1, 2)` до 36 и выводим первое, для
которого `k − 1` делит `S`. `O(L)` для `L` цифр.

Тонкие места:

- основание должно быть больше любой цифры, поэтому перебор начинается с
  `m + 1`;
- в основании 2 всё делится на 1, так что у числа из нулей и единиц ответ
  всегда 2, в том числе у одиночного `0`;
- сумма цифр не больше `35 · 10^6` и помещается в 32 бита.

Ответы проверены переводом всей строки в каждое основание длинными целыми
Python и прямым взятием остатка.

## Особенности языков

- Python и Java читают каждую цифру как цифру по основанию 36 через
  `int(ch, 36)` и `Character.digit`; Rust — через `to_digit(36)`.
