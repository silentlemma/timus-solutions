# 1158. Подсчёт предложений длины M, не содержащих запрещённых слов

[Timus 1158](https://acm.timus.ru/problem.aspx?space=1&num=1158) · сложность 506 · strings

Автор оригинальной задачи — Николай Дуров; северный подрегион полуфинала ACM ICPC Северо-Восточной Европы 2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В алфавите `N ≤ 50` букв, а предложение — любая строка ровно из `M ≤ 50`
букв. Даны `P ≤ 10` запрещённых слов длиной до 10 букв; предложение
запрещено, если содержит одно из них как подстроку. Посчитать
незапрещённые предложения. Буквами могут быть любые символы с кодами
больше 32, в том числе больше 127.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, `M` и `P`, затем `N` букв одной строкой, затем `P` слов.

## Выходные данные

Число разрешённых предложений.

## Примеры

### Пример 1

Ввод:

```
3 3 3
QWE
QQ
WEE
Q
```

Вывод:

```
7
```

## Решение

Строим автомат Ахо — Корасик для запрещённых слов: бор с суффиксными
ссылками, дополненный так, что у каждого состояния есть переход по каждой
букве. Состояние соответствует самому длинному концу уже прочитанного
текста, который является префиксом какого-то слова; оно плохое, если в нём
заканчивается слово — само или через суффиксные ссылки. Предложение
разрешено ровно тогда, когда при его чтении автомат ни разу не попадает в
плохое состояние.

Значит, считаем пути: `ways[s]` — число разрешённых начал текущей длины,
заканчивающихся в состоянии `s`. Начинаем с одного пустого начала в корне
и делаем `M` шагов, каждый раз передавая `ways[s]` по всем `N` переходам,
которые не ведут в плохое состояние. Ответ — сумма по всем состояниям. В
автомате не больше 101 состояния, так что шаг — около 5000 сложений.

Тонкие места:

- число доходит до `50⁵⁰ ≈ 8,9·10⁸⁴`, так что нужна длинная арифметика;
- слово, содержащее другое слово, плохо уже на более коротком, и это
  переносят суффиксные ссылки;
- буквы — произвольные байты, возможно больше 127, поэтому ввод читается
  как байты, а не декодируется как текст;
- одно и то же слово может быть дано дважды.

Ответы сверены с перебором всех предложений на 200 маленьких случайных
входах; в тестах буквы больше 127 хранятся как символы Latin-1 в UTF-8, а
программа запуска передаёт их решениям одиночными байтами.

## Особенности языков

- Python, Go и Java используют свои длинные целые; C++ и Rust складывают
  числа, хранимые блоками по девять десятичных цифр, — для подсчёта
  больше ничего не нужно.
- Java читает весь ввод как байты и приводит каждый байт к `0..255`.
