# 1158. 统计不含任何禁词的长度为 M 的句子数

[Timus 1158](https://acm.timus.ru/problem.aspx?space=1&num=1158) · 难度 500 · strings

原题作者 Nick Durov，出自 2001 年 ACM ICPC 东北欧区域赛北部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

字母表有 `N ≤ 50` 个字母，句子是恰好 `M ≤ 50` 个字母组成的任意字符串。给出
`P ≤ 10` 个最多 10 个字母的禁词；句子只要以子串形式包含其中之一就被禁止。
求不被禁止的句子数。字母可以是编码大于 32 的任意字符，包括编码大于 127 的。

时间限制：2 秒。内存限制：64 MB。

## 输入

`N`、`M` 和 `P`，然后一行 `N` 个字母，然后是 `P` 个词。

## 输出

允许的句子数。

## 样例

### 样例 1

输入：

```
3 3 3
QWE
QQ
WEE
Q
```

输出：

```
7
```

## 解法

为禁词建立 Aho–Corasick 自动机：带失配指针的字典树，并补全为每个状态对每个
字母都有转移。状态表示已读文本中同时是某个词前缀的最长后缀；若有词在此结束
（直接结束或通过失配指针），该状态就是坏的。一个句子被允许，当且仅当读它时
从不进入坏状态。

于是数路径：`ways[s]` 是当前长度、停在状态 `s` 的允许前缀的数目。从根上的一个
空前缀开始，做 `M` 步，每一步把 `ways[s]` 沿所有不进入坏状态的 `N` 条转移
传下去。答案是所有状态之和。自动机有 `S ≤ 101` 个状态，计数需要 `O(M·S·N)` 次加法，每步约 5000 次。

注意事项：

- 计数可达 `50⁵⁰ ≈ 8.9·10⁸⁴`，需要大整数；
- 包含另一个词的词在较短的那个词处就已经是坏的，这由失配指针传递；
- 字母是任意字节，可能大于 127，所以输入按字节读取，不当作文本解码；
- 同一个词可能给出两次。

答案已在 200 个小型随机输入上与枚举所有句子的结果比对；测试中大于 127 的字母
以 Latin-1 字符的形式用 UTF-8 存储，运行程序会把它们以单字节交给解答。

Python 教学版直接用禁词的真前缀表示状态。添加一个字母后，若后缀为禁词，则丢弃该转移。否则选择存储的前缀中最长的后缀，空前缀也可选。任何可能补成禁词的更短前缀一定也是当前状态的后缀，所以直接检查与失配链接得到相同转移。设禁词数为 P、最大词长为 L，构建转移表耗时 O(SN(P+S)L)，计数需要 O(MSN) 次加法。

## 优化解法

Go、Rust 保留 Aho–Corasick 与精确计数。至多 101 个状态、50 个字母，转移 ID 用字节，BFS 队列定长。先传播禁后缀并补完全部失配转移，再将到相同安全状态的字母合并为带重数边。复用两层 DP，逐边加上计数乘重数。计数至多 50⁵⁰<10⁸⁵，十个 10⁹ 进制位足够精确；单段乘至多 50 适合 uint64。保留零计数与继承禁状态，大于 127 的字节按字母读取。设 W 为禁词总长度、S 为状态数、N 为字母数、E 为合并边数、D≤10 为数位数。每行扫描所有目标计数，建表与合并共耗时 O(W+S(S+N))。清空、检查和更新 DP 层共耗时 O(M(S+E)D)。空间为 O(SN+SD)，输入输出缓冲区定长。C++、Java、Python 复用达标基础版。
