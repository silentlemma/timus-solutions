# 1158. 统计不含任何禁词的长度为 M 的句子数

[Timus 1158](https://acm.timus.ru/problem.aspx?space=1&num=1158) · 难度 506 · strings

原题作者 Nick Durov，出自 2001 年 ACM ICPC 东北欧区域赛北部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

字母表有 `N ≤ 50` 个字母，句子是恰好 `M ≤ 50` 个字母组成的任意字符串。给出
`P ≤ 10` 个最多 10 个字母的禁词；句子只要以子串形式包含其中之一就被禁止。
求不被禁止的句子数。字母可以是编码大于 32 的任意字符，包括编码大于 127 的。

时间限制：2 秒。内存限制：64 MB。

## 输入

`N`、`M` 和 `P`，然后一行 `N` 个字母，然后是 `P` 个词。

## 输出

允许的句子数。

## 样例

### 样例 1

输入：

```
3 3 3
QWE
QQ
WEE
Q
```

输出：

```
7
```

## 解法

为禁词建立 Aho–Corasick 自动机：带失配指针的字典树，并补全为每个状态对每个
字母都有转移。状态表示已读文本中同时是某个词前缀的最长后缀；若有词在此结束
（直接结束或通过失配指针），该状态就是坏的。一个句子被允许，当且仅当读它时
从不进入坏状态。

于是数路径：`ways[s]` 是当前长度、停在状态 `s` 的允许前缀的数目。从根上的一个
空前缀开始，做 `M` 步，每一步把 `ways[s]` 沿所有不进入坏状态的 `N` 条转移
传下去。答案是所有状态之和。自动机最多 101 个状态，一步约 5000 次加法。

注意事项：

- 计数可达 `50⁵⁰ ≈ 8.9·10⁸⁴`，需要大整数；
- 包含另一个词的词在较短的那个词处就已经是坏的，这由失配指针传递；
- 字母是任意字节，可能大于 127，所以输入按字节读取，不当作文本解码；
- 同一个词可能给出两次。

答案已在 200 个小型随机输入上与枚举所有句子的结果比对；测试中大于 127 的字母
以 Latin-1 字符的形式用 UTF-8 存储，运行程序会把它们以单字节交给解答。

## 各语言说明

- Python、Go 和 Java 使用各自的大整数；C++ 和 Rust 对以九位十进制为一块存储的
  数做加法，计数只需要加法。
- Java 把整个输入读成字节，并把每个字节转换到 `0..255`。
