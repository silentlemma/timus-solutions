# 1111. Сортировка квадратов по расстоянию до точки

[Timus 1111](https://acm.timus.ru/problem.aspx?space=1&num=1111) · сложность 386 · geometry

Оригинальная задача с Timus; автор и источник не указаны.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны `n` закрашенных квадратов (`1 ≤ n ≤ 50`), каждый задан двумя
противоположными вершинами с целыми координатами из `(−9999, 9999)`;
квадраты могут быть повёрнуты под любым углом, а квадрат может
вырождаться в точку. Расстояние от точки `P` до квадрата — длина
кратчайшего отрезка от `P` до точки квадрата, так что оно равно 0, когда
`P` внутри. Вывести номера квадратов по возрастанию расстояния, при
равенстве — сначала меньший номер.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`n`, затем `n` строк `x1 y1 x2 y2` с двумя противоположными вершинами,
затем строка `x y` с точкой `P`.

## Выходные данные

Номера квадратов (с 1) в отсортированном порядке через пробел.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
2
0 0 1 1
0 3 1 4
0 0
```

Вывод:

```
1 2
```

## Решение

Посмотрим на каждый квадрат из его центра `C`, где
`D = (x2 − x1, y2 − y1)` — диагональ. Его стороны идут вдоль `D`,
повёрнутой на `±45°`, то есть вдоль `D ± D⊥`, где `D⊥` — `D`, повёрнутая
на `90°`. С удвоенным смещением `q = 2P − (x1 + x2, y1 + y2)`, целым,
проекции `q` на два направления сторон равны `s1 = |q · (D + D⊥)|` и
`s2 = |q · (D − D⊥)|`, и `P` внутри ровно тогда, когда обе не больше
`h = |D|²`. Снаружи избытки `a = max(0, s1 − h)` и `b = max(0, s2 − h)`
дают квадрат расстояния `(a² + b²) / (8h)`, а у квадрата-точки он равен
`|q|² / 4`.

Так каждый квадрат расстояния — точная дробь из целых, и два из них
сравниваются перекрёстным умножением; устойчивая сортировка сохраняет
порядок ввода у равных расстояний. `O(n log n)`.

Тонкие места:

- равенства часты — из-за симметричных квадратов и из-за `P` внутри
  нескольких из них, поэтому сравнение должно быть точным: в плавающей
  точке два равных расстояния могут упорядочиться как угодно;
- числители доходят примерно до `5 · 10^18`, а перекрёстные произведения
  — до `10^28`, больше 64 бит;
- заданные вершины противоположные, а не соседние, и любая диагональ в
  любом направлении описывает один и тот же квадрат.

Ответы проверены отдельным точным вычислением с дробями: четыре вершины
строятся явно, принадлежность проверяется векторными произведениями, а
расстояние — наименьшее до четырёх сторон как отрезков. Сотни случайных
наборов, многие с равенствами, совпали.

## Особенности языков

- C++ и Rust сравнивают в 128-битных целых, Go — через `bits.Mul64`, Java
  — через `BigInteger`, Python — собственными целыми.
