# 1114. Раскладка до A и B одинаковых шаров двух цветов по N коробкам

[Timus 1114](https://acm.timus.ru/problem.aspx?space=1&num=1114) · сложность 193 · combinatorics

Оригинальная задача — первое отборочное соревнование в болгарскую команду на IOI.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В ряд стоят `N` коробок (`1 ≤ N ≤ 20`), есть `A` одинаковых красных и
`B` одинаковых синих шаров (`0 ≤ A, B ≤ 15`). В каждую коробку можно
положить сколько угодно шаров любых цветов, коробки могут оставаться
пустыми, а шары — неиспользованными. Посчитать число различных раскладок.

Ограничение времени: 0,6 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N A B` в одной строке.

## Выходные данные

Число раскладок.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
2 1 1
```

Вывод:

```
9
```

## Решение

Цвета независимы, поэтому ответ — произведение количеств для каждого
цвета. Разложить не больше `A` одинаковых шаров по `N` коробкам — то же,
что разложить ровно `A` по `N + 1` коробкам, где лишняя коробка хранит
неиспользованные; по методу «шаров и перегородок» это `C(A + N, N)`.
Ответ `C(A + N, N) · C(B + N, N)` берётся из треугольника Паскаля.
`O((A + N)²)` на треугольник или `O(1)`, если таблица построена заранее.

Тонкие места:

- наибольший случай `N = 20, A = B = 15` даёт `C(35, 20)² ≈ 1,05 · 10^19`,
  что больше максимума знакового 64-битного `9,22 · 10^18`, но помещается
  в беззнаковое 64-битное целое;
- неиспользованные шары разрешены: если считать только раскладки всех
  `A` шаров, получится `C(A + N − 1, N − 1)`.

Ответы проверены динамикой по коробкам, которая считает заполнения с
каждым числом шаров и суммирует их до `A` и `B`.

## Особенности языков

- C++, Go и Rust умножают в беззнаковых 64-битных целых; в Java нет
  беззнаковых типов, поэтому она умножает `long`, чьи 64 бита верны по
  модулю `2^64`, и печатает их через `Long.toUnsignedString`; целые Python
  не переполняются.
