# 1146. 方阵中和最大的子矩形

[Timus 1146](https://acm.timus.ru/problem.aspx?space=1&num=1146) · 难度 79 · dp

原题来自 Timus，未注明作者和出处。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定一个 `N × N`（`N ≤ 100`）的整数数组，元素在 −127 到 127 之间。求子矩形
（至少 `1 × 1`、由相邻的行和列组成的块）的最大和。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N`，然后按行给出 `N²` 个数，以任意空白分隔。

## 输出

最大和。

## 样例

### 样例 1

输入：

```
4
0 -2 -7 0
9 2 -6 2
-4 1 -4 1
-1 8 0 -2
```

输出：

```
15
```

## 解法

固定矩形的上边那一行，把下边一行一行往下移，同时记录每一列在这两行之间的
元素和。对固定的一对行，最好的矩形就是这列和序列中最好的一段相邻列，用
Kadane 扫描一遍即可求出：记录以当前列结尾的一段的最大和，若之前的和为负就
从当前列重新开始。下一行的列和等于旧列和加上一行，所以每对行花 `O(N)`，
整个搜索 `O(N³)`，`N = 100` 时约五十万步。

注意事项：

- 矩形不能为空：所有数都为负时答案是其中最大的数，而不是 `0`，所以最优值
  从数组中的某个元素开始；
- 数字可能以任意方式分布在各行，所以按词流读取；
- 和不超过 `100² · 127`，在 32 位范围内。

答案已在 150 个不超过 `9 × 9` 的随机数组上，与借助前缀和表检查每个矩形的
结果比对。

## 优化解法

优化的 Python 解法按 4 KB 分块读入，每行存进字节 `array`（所有值都在 −127 到 127
之间），并用 `map` 而不是 Python 循环把一行加到列和上：632 KB，而不是 1372 KB，
时间不变。优化的 Rust 解法直接从 `stdin().lock()` 手工解析数字，把矩阵放在一个扁
平的 `i8` 向量里，并复用同一个列和向量：212 KB，而不是 372 KB，但时间从 0.015 s
增加到 0.046 s。
