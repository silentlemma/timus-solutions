# 1146. Подпрямоугольник с наибольшей суммой в квадратном массиве

[Timus 1146](https://acm.timus.ru/problem.aspx?space=1&num=1146) · сложность 79 · dp

Оригинальная задача с Timus; автор и источник не указаны.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дан массив `N × N`, `N ≤ 100`, целых чисел от −127 до 127. Найти
наибольшую сумму подпрямоугольника, то есть блока не меньше `1 × 1` из
соседних строк и столбцов.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N²` чисел по строкам, разделённых любыми пробельными
символами.

## Выходные данные

Наибольшая сумма.

## Примеры

### Пример 1

Ввод:

```
4
0 -2 -7 0
9 2 -6 2
-4 1 -4 1
-1 8 0 -2
```

Вывод:

```
15
```

## Решение

Зафиксируем верхнюю строку прямоугольника и будем опускать нижнюю по
одной строке, храня для каждого столбца сумму его клеток между этими
строками. Для фиксированной пары строк лучший прямоугольник — лучший
отрезок соседних столбцов в этом списке сумм, и его находит проход
Кадане: храним лучшую сумму отрезка, кончающегося в текущем столбце, и
начинаем заново с этого столбца, если сумма до него отрицательна. Суммы
столбцов для следующей нижней строки — старые плюс одна строка, так что
каждая пара строк стоит `O(N)`, а весь поиск — `O(N³)`, около полумиллиона
шагов при `N = 100`.

Тонкие места:

- прямоугольник не может быть пустым: если все числа отрицательны, ответ —
  наибольшее из них, а не `0`, поэтому лучшее значение начинается с клетки
  массива;
- числа могут быть разбиты по строкам как угодно, поэтому они читаются как
  поток токенов;
- суммы меньше `100² · 127` и помещаются в 32 бита.

Ответы сверены с перебором всех прямоугольников через таблицу
префиксных сумм на 150 случайных массивах до `9 × 9`.
