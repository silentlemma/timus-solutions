# 1113. Наименьший запас топлива для поездки в один конец со складами

[Timus 1113](https://acm.timus.ru/problem.aspx?space=1&num=1113) · сложность 265 · math

Оригинальная задача — Болгарская национальная олимпиада по информатике, второй день.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Машина должна проехать `N` км пустыни, тратя литр топлива на километр.
Она везёт не больше `M` литров, причём `M < N ≤ 5M` и `N < 32000`. В
начале пути топлива сколько угодно, и машина может оставлять любое
количество топлива в любой точке пути и забирать его позже. Найти
наименьшее общее количество топлива в литрах, нужное, чтобы доехать до
цели, округлённое вверх до целого.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N M` в одной строке.

## Выходные данные

Наименьшее количество топлива, округлённое вверх.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
1000 500
```

Вывод:

```
3837
```

## Решение

Это задача о джипе в одну сторону. Идём от цели назад. Последние `M` км
требуют одной полной загрузки. Чтобы доставить две загрузки к началу этого
участка, отрезок длиной `M/3` км перед ним проезжается трижды (туда,
обратно, туда), что стоит ровно одну лишнюю загрузку; вообще отрезок
`M/(2k − 1)` км доставляет `k` загрузок ценой ещё одной. Поэтому
добавляем отрезки `M, M/3, M/5, …`, пока они не дойдут до старта; если
нужно `k` загрузок, а отрезки перед последним покрывают `s` км, топлива
нужно `(k − 1)·M + (N − s)·(2k − 1)`. При `5M ≥ N` точный максимум —
`k = 3092`: для `H_j = Σ_{i=1}^j 1/(2i − 1)` выполняется
`H_3091 < 5 ≤ H_3092`. Итераций `O(k)`, но с учётом длинной арифметики
время составляет `O(kB)`, дополнительная память — `O(B)`, где `B` —
максимальная длина длинного целого в машинных словах. При данных
ограничениях второй операнд каждого умножения, деления или вычисления
gcd помещается в машинное слово, поэтому операция требует `O(B)`
операций над словами.

Тонкие места:

- округление вверх должно быть точным: топливо часто получается целым, а
  сумма `M/(2i − 1)` в плавающей точке чуть превышает его и добавляет
  лишний литр (например, `N = 59, M = 35` дают ровно 143, а вычисление в
  простом `double` печатает 144);
- отрезки убывают лишь как нечётный гармонический ряд, поэтому при
  `N = 5M` их 3092, а не максимум 3000 ([тест 08](tests/08.in): `5 1`);
  точная дробь вырастает до нескольких тысяч цифр, поэтому подсчёт
  одних итераций занижает стоимость арифметики.

Ответы проверены отдельной формулировкой на точных дробях: расстояние,
достижимое с `F` литрами, равно
`M · Σ_{i≤q} 1/(2i − 1) + (F − qM)/(2q + 1)` при `q = ⌊F/M⌋`, а
наименьшее целое `F`, дающее `N`, ищется двоичным поиском; 12 поездок,
составленных вручную, и 150 случайных, многие с вместимостью, кратной
`3 · 5 · 7 · 9`, совпали.

## Оптимизированные решения

Сохраняется построение запаса топлива назад через нечётные гармонические слагаемые. Нижняя и верхняя оценки с фиксированной точкой обычно определяют точный целый ответ без построения большой дроби после каждого слагаемого. Ширина интервала ограничена явно; только неоднозначность требует точной рациональной арифметики. Проверяются соседние возможные этапы и берётся больший необходимый запас. Здесь нет ни epsilon, ни таблицы ответов: округление не может признать недостаточный запас достаточным.

Здесь k — число этапов запаса топлива. Шаги точной арифметики не равны операциям с постоянной битовой стоимостью: редкий рациональный запасной путь зависит от длины числителя и знаменателя.
