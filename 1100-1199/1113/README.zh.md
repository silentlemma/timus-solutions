# 1113. 设置油料补给点的单程旅行所需最少燃料

[Timus 1113](https://acm.timus.ru/problem.aspx?space=1&num=1113) · 难度 265 · math

原题出自保加利亚全国信息学奥林匹克竞赛第二天。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一辆车要穿越 `N` 千米的沙漠，每千米消耗一升燃料。它最多携带 `M` 升，且 `M < N ≤ 5M`、`N < 32000`。起点的燃料无限，车可以在途中任意地点留下任意多的燃料，以后再取走。求到达终点所需的最少燃料总量（升），向上取整。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

一行 `N M`。

## 输出

最少的燃料量，向上取整。

## 评测方式

输出按记号逐个比较；多余的空白字符无关紧要。

## 样例

### 样例 1

输入：

```
1000 500
```

输出：

```
3837
```

## 解法

这是单程吉普车问题。从终点倒着考虑。最后 `M` 千米需要一整箱。要把两箱燃料运到这一段的起点，就要把它前面长 `M/3`
千米的一段走三遍（去、回、去），恰好多花一箱；一般地，长 `M/(2k − 1)` 千米的一段能以多一箱的代价运送 `k` 箱。于是依次加入长度为
`M, M/3, M/5, …` 的各段，直到到达起点；若需要 `k` 箱，而最后一段之前的各段共覆盖 `s` 千米，则燃料为
`(k − 1)·M + (N − s)·(2k − 1)`。由于 `5M ≥ N`，精确的最大段数为 `k = 3092`：令
`H_j = Σ_{i=1}^j 1/(2i − 1)`，则 `H_3091 < 5 ≤ H_3092`。循环有 `O(k)` 次迭代，但计入大整数运算后，
时间为 `O(kB)`，额外空间为 `O(B)`，其中 `B` 是大整数的最大机器字长度。在输入限制下，每次乘法、除法或 gcd
的另一个操作数都能放入一个机器字，因此每次运算需要 `O(B)` 次机器字操作。

注意事项：

- 向上取整必须精确：燃料量常常恰好是整数，而 `M/(2i − 1)` 的浮点和会略微超过它，多算一升（例如 `N = 59, M = 35` 恰好是
  143，而普通 `double` 计算输出 144）；
- 各段长度只像奇数调和级数那样减小，所以 `N = 5M` 时需要 3092 段，而非至多 3000 段（[测试 08](tests/08.in)：`5 1`）；
  精确分数会增长到几千位，因此只计算迭代次数会低估算术运算的成本。

答案经过验证：与另一种用精确分数的表述比对——用 `F` 升燃料能到达的距离为 `M · Σ_{i≤q} 1/(2i − 1) + (F − qM)/(2q + 1)`，其中
`q = ⌊F/M⌋`，再用二分搜索求出能到达 `N` 的最小整数 `F`；12 个手工构造的行程和 150 个随机行程（其中许多容量是 `3 · 5 · 7 · 9`
的倍数）结果一致。

## 优化解法

仍按奇数调和项反向构造燃料量。定点上下界通常能确定精确整数结果，而不用每一步都构造大有理数。区间宽度有明确上界，只有不能确定结果时才使用精确分数。检查相邻的可能阶段，取所需燃料最大值。算法既不依赖 epsilon，也不存答案表，不会因舍入而接受不足的燃料。

k 为燃料阶段数。精确算术步骤不是常数位代价，少见的分数回退取决于分子分母长度。
