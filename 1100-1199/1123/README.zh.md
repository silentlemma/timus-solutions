# 1123. 不小于一个长整数的最小回文数

[Timus 1123](https://acm.timus.ru/problem.aspx?space=1&num=1123) · 难度 122 · strings

原题作者 Leonid Volkov 和 Oleg Kats，出自 2001 年 10 月 USU Open Collegiate Programming Contest（Junior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定一个至多 2001 位的非负整数，输出大于或等于它的最小回文数（从两端读都相同的数）。

时间限制：1 秒。内存限制：64 MB。

## 输入

一行，这个数。

## 输出

该回文数。

## 评测方式

输出按记号逐个比较；多余的空白字符无关紧要。

## 样例

### 样例 1

输入：

```
12341321
```

输出：

```
12344321
```

## 解法

答案的位数相同：全由 9 组成的数就是回文数。这个长度的回文数由它的左半部分连同中间数字决定，左半部分越大，回文数越大。所以把左半部分倒序复制到右半部分；若结果不小于原数，它就是答案。否则把左半部分（连同中间数字）加一后再镜像：这是下一个可能的左半部分，也就是下一个回文数。加一不会溢出，因为全是
9 的左半部分镜像后是这个长度下最大的数，永远不会太小。等长的数字串按字典序比较与按数值比较一致，所以不需要大整数。`O(L)`。

注意事项：

- 加一的进位可能穿过一长串 9（1999 变成 2002）；
- 长度为奇数时，中间数字属于左半部分；
- 这个数至多有 2001 位，远超任何整数类型。

答案经过验证：对至多六位的数，向上逐个数到下一个回文数；对更长的数，用大整数构造左半部分 `p` 和 `p + 1`
对应的回文数，取其中不小于原数的较小者；400 个随机数以及带有穿过数百个 9 的进位的长测试结果一致。
