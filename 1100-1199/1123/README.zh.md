# 1123. 不小于一个长整数的最小回文数

[Timus 1123](https://acm.timus.ru/problem.aspx?space=1&num=1123) · 难度 122 · strings

原题作者 Leonid Volkov 和 Oleg Kats，出自 2001 年 10 月 USU Open Collegiate Programming Contest（Junior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定一个至多 2001 位的非负整数，输出大于或等于它的最小回文数（从两端读都相同的数）。

时间限制：1 秒。内存限制：64 MB。

## 输入

一行，这个数。

## 输出

该回文数。

## 评测方式

输出按记号逐个比较；多余的空白字符无关紧要。

## 样例

### 样例 1

输入：

```
12341321
```

输出：

```
12344321
```

## 解法

首先去掉前导零；如果所有数字都是零，则保留一个零。
答案的位数与去掉前导零后的数相同：全由 9 组成的数就是回文数。这个长度的回文数由它的左半部分连同中间数字决定，左半部分越大，回文数越大。所以把左半部分倒序复制到右半部分；若结果不小于原数，它就是答案。否则把左半部分（连同中间数字）加一后再镜像：这是下一个可能的左半部分，也就是下一个回文数。加一不会溢出，因为全是
9 的左半部分镜像后是这个长度下最大的数，永远不会太小。等长的数字串按字典序比较与按数值比较一致，所以不需要大整数。时间复杂度和额外空间复杂度均为 `O(L)`，其中 `L` 为输入长度。

注意事项：

- 加一的进位可能穿过一长串 9（1999 变成 2002）；
- 长度为奇数时，中间数字属于左半部分；
- 镜像前必须去掉前导零（`01` 应输出 `1`，测试 `11`）；全零输入应输出 `0`；
- 这个数至多有 2001 位，远超任何整数类型。

答案经过验证：对 0 至 9999 的所有整数及固定种子生成的 3000 个至多六位有效数字的随机输入（包括前导零），向上逐个数到下一个回文数。
更长的输入由独立的数位动态规划验证，该算法为对称位置赋值，并记录与输入的大小关系。
现有测试、生成器用例及长度至多 2001 位的边界用例（包括长进位）均一致。
