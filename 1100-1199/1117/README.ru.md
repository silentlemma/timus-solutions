# 1117. Путь по двоичному дереву, пронумерованному в симметричном порядке

[Timus 1117](https://acm.timus.ru/problem.aspx?space=1&num=1117) · сложность 279 · math

Автор оригинальной задачи — Александр Сомов; USU Open Collegiate Programming Contest, октябрь 2001 года, Junior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Узлы полного двоичного дерева пронумерованы `1, 2, 3, …` в симметричном
порядке: номер каждого внутреннего узла лежит между номерами двух его
детей, а все узлы одного поддерева — по одну сторону. Сообщение идёт от
номера `i` к номеру `j` через все номера между ними, по одному шагу; шаг
между `k` и `k ± 1` занимает столько дней, сколько узлов дерева лежит
строго между ними на пути в дереве (0 для родителя и ребёнка). Найти
общее число дней для `1 ≤ i, j ≤ 2^31 − 1`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`i j` в одной строке.

## Выходные данные

Число дней.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
1 5
```

Вывод:

```
2
```

## Решение

В полном дереве с симметричной нумерацией высота узла `x` над листьями
равна числу младших нулевых битов `tz(x)`: листья — нечётные числа, их
родители — числа `2 mod 4` и так далее. Из двух соседних чисел одно
нечётное, это лист, а чётное `e` — его предок на высоте `tz(e)`, поэтому
шаг стоит `tz(e) − 1` дней. Каждое чётное число строго между `i` и `j`
участвует в двух шагах, а чётный конец — в одном.

При `c(e) = tz(e) − 1 = tz(e/2)` сумма `c` по чётным числам до `n` равна
`Σ_{y ≤ n/2} tz(y) = m − popcount(m)` при `m = ⌊n/2⌋` (каждое `y` даёт
свои младшие нули, а `Σ_{t≥1} ⌊m/2^t⌋ = m − popcount(m)`). Поэтому при
`i < j` ответ равен `2·(G(j) − G(i − 1)) − c(i) − c(j)`, где `G` — эта
сумма, а `c` нечётного числа равно 0. `O(1)`.

Тонкие места:

- наибольший ответ, для `1` и `2^31 − 1`, равен `2147483586`, всего на
  61 меньше границы знаковых 32 бит; решения для надёжности считают в
  64 битах;
- порядок `i` и `j` не важен;
- размер дерева не дан, но он и не важен: симметричные номера и высоты
  одинаковы в любом полном дереве, достаточно большом для обоих чисел.

Ответы проверены обходом настоящего дерева (родитель `x` — это
`x ± 2^tz(x)`) с суммированием длин путей по шагам для 300 случайных пар
меньше 3000, а большие тесты — прямым циклом по всем шагам.

## Особенности языков

- Младшие нули и число единиц дают встроенные функции:
  `__builtin_ctzll` и `__builtin_popcountll`, `math/bits`,
  `Long.numberOfTrailingZeros` и `Long.bitCount`, `trailing_zeros` и
  `count_ones`; Python считает единицы в `bin(m)`.
