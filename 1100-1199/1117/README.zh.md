# 1117. 在按中序编号的二叉树上从一个编号走到另一个编号

[Timus 1117](https://acm.timus.ru/problem.aspx?space=1&num=1117) · 难度 281 · math

原题作者 Alexander Somov，出自 2001 年 10 月 USU Open Collegiate Programming Contest（Junior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一棵满二叉树的节点按中序编号为 `1, 2, 3, …`：每个内部节点的编号介于两个孩子之间，同一棵子树的节点都在同一侧。消息从编号 `i`
发往编号 `j`，逐个经过其间的每个编号；`k` 与 `k ± 1` 之间的一步所需天数等于树上它们之间路径上严格夹在中间的节点数（父子之间为
0）。对 `1 ≤ i, j ≤ 2^31 − 1` 求总天数。

时间限制：1 秒。内存限制：64 MB。

## 输入

一行 `i j`。

## 输出

天数。

## 评测方式

比较一个精确整数词元，忽略排版空白。 新Python精确源码在PyPy 3.10通过12个仓库测试。 其他保留原生版本各有保存的目标环境检查与精确Accepted。输出按本题检查器规则比较。

## 样例

### 样例 1

输入：

```
1 5
```

输出：

```
2
```

## 解法

在按中序编号的满二叉树中，节点 `x` 离叶子的高度等于其末尾零位的个数 `tz(x)`：叶子是奇数，它们的父节点是模 4 余 2
的数，依此类推。两个相邻的数中有一个是奇数，即叶子，而偶数 `e` 是它在高度 `tz(e)` 处的祖先，所以这一步需要 `tz(e) − 1` 天。严格位于
`i` 与 `j` 之间的每个偶数都被两步用到，偶数端点则只用到一次。

记 `c(e) = tz(e) − 1 = tz(e/2)`，则不超过 `n` 的偶数上 `c` 之和为 `Σ_{y ≤ n/2} tz(y) = m − popcount(m)`，其中
`m = ⌊n/2⌋`（每个 `y` 贡献它的末尾零，而 `Σ_{t≥1} ⌊m/2^t⌋ = m − popcount(m)`）。所以当 `i < j` 时答案为
`2·(G(j) − G(i − 1)) − c(i) − c(j)`，其中 `G` 就是这个和，奇数的 `c` 为 0。`O(1)`。

注意事项：

- 最大的答案（`1` 到 `2^31 − 1`）是 `2147483586`，只比有符号 32 位上限小 61；解法为稳妥起见用 64 位计算；
- `i` 与 `j` 的顺序无关紧要；
- 题目没给出树的大小，但这无关紧要：在任何足够容纳这两个编号的满二叉树中，中序编号和高度都相同。

答案经过验证：对 300 组小于 3000 的随机数对，与在真实树上行走（`x` 的父节点是 `x ± 2^tz(x)`）并逐步累加路径长度的程序比对；大测试则与逐步直接循环的程序比对。

## 优化解法
