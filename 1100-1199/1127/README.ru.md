# 1127. Самая высокая башня из кубиков с одноцветными боковыми гранями

[Timus 1127](https://acm.timus.ru/problem.aspx?space=1&num=1127) · сложность 322 · bruteforce

Автор оригинальной задачи — Екатерина Васильева; VI студенческое соревнование по программированию УрГУ, 21 октября 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `N` кубиков (`1 < N ≤ 1000`); у каждой грани кубика есть цвет (одна
из 10 букв), и все шесть граней кубика разного цвета. Грани даны в
порядке: передняя, правая, левая, задняя, верхняя, нижняя. Поставить друг
на друга как можно больше кубиков, повернув каждый как угодно, так чтобы
каждая из четырёх боковых сторон башни была одного цвета. Вывести высоту.

Ограничение времени: 0,4 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк по шесть букв-цветов.

## Выходные данные

Наибольшая высота.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
4
GYVABW
AOCGYV
CABVGO
OVYWGA
```

Вывод:

```
3
```

## Решение

Башня задаётся кольцом цветов своих боковых сторон: передняя, правая,
задняя, левая. Кубик подходит к кольцу, если одна из его 24 ориентаций
показывает ровно это кольцо. Так как его шесть цветов различны, каждое
кольцо кубик показывает не более чем в одной ориентации, поэтому подсчёт
для каждого кольца кубиков, которые могут его показать, даёт высоту
самой высокой башни с этим кольцом. 24 ориентации строятся один раз из
двух поворотов на четверть — вокруг вертикальной оси и вокруг оси
«лево-право» — как перестановки шести позиций граней. `O(24·N)`.

Тонкие места:

- повороты должны быть вращениями, а не отражениями: поворот на четверть
  переводит переднюю грань вправо, правую назад и так далее, сохраняя
  ориентацию;
- зеркальное отражение кубика всё равно подходит: перевёрнутое вокруг
  оси «перед-зад», оно показывает то же кольцо боковых граней, лишь верх
  и низ меняются местами, а они не важны;
- цвета верхней и нижней граней никогда не важны.

Ответы проверены отдельным построением 24 вращений как знаковых матриц
перестановок с определителем +1, действующих на нормали граней, на всех
тестах.

## Особенности языков

- Во всех языках ориентации строятся небольшим перебором двух поворотов,
  а кольца считаются в хеш-таблице.
