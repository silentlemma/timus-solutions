# 1127. 四个侧面各为单一颜色的最高立方体塔

[Timus 1127](https://acm.timus.ru/problem.aspx?space=1&num=1127) · 难度 322 · bruteforce

原题作者 Ekaterina Vasilyeva，出自 2001 年 10 月 21 日第六届乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 `N` 个立方体（`1 < N ≤ 1000`）；每个面有一种颜色（10 个字母之一），且同一立方体的六个面颜色互不相同。各面按前、右、左、后、上、下的顺序给出。把尽可能多的立方体以任意转向叠起来，使塔的四个侧面各自为单一颜色。输出高度。

时间限制：0.4 秒。内存限制：64 MB。

## 输入

`N`，然后是 `N` 行，每行六个颜色字母。

## 输出

最大高度。

## 评测方式

输出按记号逐个比较；多余的空白字符无关紧要。

## 样例

### 样例 1

输入：

```
4
GYVABW
AOCGYV
CABVGO
OVYWGA
```

输出：

```
3
```

## 解法

一座塔由它侧面的颜色环决定：前、右、后、左。若立方体的 24 种朝向之一恰好呈现这个环，它就适合这座塔。由于六种颜色互不相同，立方体至多以一种朝向呈现某个环，所以对每个环统计能呈现它的立方体数，就得到以该环为侧面的最高塔的高度。24
种朝向只需生成一次：用绕竖直轴和绕左右轴的两个四分之一转动，作为六个面位置的置换生成。`O(24·N)`。

注意事项：

- 转动必须是旋转而不是镜像：四分之一转动把前面转到右面，右面转到后面，依此类推，保持手性；
- 立方体的镜像仍然适合：绕前后轴翻转后，它呈现同样的侧面环，只是上下互换，而上下无关紧要；
- 上面和下面的颜色永远无关紧要。

答案经过验证：在所有测试上与另一种构造比对——把 24 种旋转构造成作用于面法向量、行列式为 +1 的带符号置换矩阵。

## 各语言说明

- 各语言都通过对两个转动的小规模搜索生成朝向，并用哈希表统计环。
