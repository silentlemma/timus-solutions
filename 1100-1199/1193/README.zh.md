# 1193. 口试要提前多久开始才能让所有人按时结束

[Timus 1193](https://acm.timus.ru/problem.aspx?space=1&num=1193) · 难度 181 · greedy

原题作者 Anatoly Uglov，出自 2002 年 3 月 2 日第五届中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N ≤ 40` 名学生在口试开始时拿到题目。学生 `i` 准备 `T1` 分钟（各不相同），然后
回答 `T2` 分钟；同一时间只能有一人回答，按准备完成的先后顺序进行，准备好时若有人
正在回答就排队等候。每名学生必须在计划开始时间之后 `T3` 分钟内结束。求口试至少
要提前多少分钟开始，才能让所有人按时结束。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N`，然后对每名学生给出 `T1 T2 T3`。

## 输出

分钟数；不需要提前时输出 0。

## 样例

### 样例 1

输入：

```
3
100 10 120
70 40 150
99 15 400
```

输出：

```
15
```

### 样例 2

输入：

```
2
100 10 110
80 15 100
```

输出：

```
0
```

## 解法

提前 `s` 分钟开始，会把一切都平移 `s`：排队顺序和每段等待都不变，只是相对于开始
时刻而言，截止时间都晚了 `s` 分钟。所以只需按 `T1` 的顺序模拟一次口试：每次回答
在学生准备好或上一位回答结束时开始，取两者中较晚者。答案就是最大的迟到量（结束
时间减去 `T3`），没人迟到则为 0。排序需要 `O(N log N)`。

注意事项：

- 队列按准备完成的时间排序，而不是按输入顺序；
- 学生准备好时若没人在回答就立即开始，所以学生之间老师可能空闲；
- 提前量不能为负：如果所有人都早有余裕，答案是 0。

答案已在 300 场随机口试和所有测试上与另一份用二分查找提前量的独立解答比对。

- 所有语言都按准备时间对学生排序，循环相同。
