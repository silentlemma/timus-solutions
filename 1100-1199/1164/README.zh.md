# 1164. 找出填字游戏中所有单词后剩下哪些字母

[Timus 1164](https://acm.timus.ru/problem.aspx?space=1&num=1164) · 难度 207 · strings

原题作者 Alex Selivanov，出自 2001 年 ACM ICPC 东北欧区域赛北部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个 `N×M` 的大写字母网格（`2 ≤ N, M ≤ 10`）中藏着 `P ≤ 100` 个单词。每个
单词占据一条由边相邻格子组成的路径，任何格子都不属于两个单词，也不会在同一个
单词中出现两次。合法的摆放方式总是存在。按字母顺序输出没有被任何单词使用的
格子里的字母。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`、`M` 和 `P`，然后是网格的 `N` 行，再然后是 `P` 个单词。

## 输出

排好序的剩余字母，占一行。

## 评测方式

精确比较剩余大写字母串；无剩余字母时允许空输出。 新Python精确源码在PyPy 3.10通过11个仓库测试。 其他保留原生版本各有保存的目标环境检查与精确Accepted。输出按本题检查器规则比较。

## 样例

### 样例 1

输入：

```
3 3 2
EBG
GEE
EGE
BEG
GEE
```

输出：

```
EEG
```

## 解法

不必搜索路径。对于字母 `c`，设 `G[c]` 为网格中该字母的格数，
`U[c]` 为所有给定单词中它的出现次数。任意合法放置恰好使用 `U[c]` 个
不同的 `c` 格：一条路径不能重复格子，不同单词也不能重叠。
因此无论几何位置如何，总剩 `G[c] − U[c]` 个 `c`。存在合法放置的保证
意味着所有差值非负。

统计网格字母，按重数减去单词字母，再依 `A..Z` 输出每个字母的剩余次数，
就得到排序后的准确剩余多重集。重复单词也分别消耗字母。若全部格子被占用，
输出空行。保证条件还给出总词长 `W ≤ N M ≤ 100`，故单词各自也至多 100 字符。

时间 `O(N M + W + 26)`。原生语言基线保存 26 个计数器，易读 Python 基线用
`Counter`。含存储的输入输出时，所有版本均可用 `O(N M + W)` 空间界；
流式版本保存的输入更少。五份原始 Accepted 源码均逐字节保留。

## 优化解法

所有放置消耗同一字母多重集。保留清晰计数版本和紧凑C++计数器。Python对固定26个大写字母分别统计网格及全部单词中的次数，按字母顺序输出正差值；常数大小字母表使总时间仍为线性。不导入Counter，也不为两个多重集另建字典，但保留输入字符串。使用现有文本流并直接写出结果，减少额外输入包装。实测仅内存改善，耗时增加如下明确列出。
