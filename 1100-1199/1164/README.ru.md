# 1164. Какие буквы останутся после поиска всех слов филворда

[Timus 1164](https://acm.timus.ru/problem.aspx?space=1&num=1164) · сложность 206 · strings

Автор оригинальной задачи — Alex Selivanov; северный подрегион полуфинала ACM ICPC Северо-Восточной Европы 2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В сетке `N×M` из заглавных букв (`2 ≤ N, M ≤ 10`) спрятаны `P ≤ 100`
слов. Каждое слово занимает путь из соседних по стороне клеток, и ни одна
клетка не принадлежит двум словам или дважды одному слову. Правильная
расстановка всегда существует. Вывести в алфавитном порядке буквы клеток,
не занятых ни одним словом.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, `M` и `P`, затем `N` строк сетки, затем `P` слов.

## Выходные данные

Оставшиеся буквы по порядку в одной строке.

## Примеры

### Пример 1

Ввод:

```
3 3 2
EBG
GEE
EGE
BEG
GEE
```

Вывод:

```
EEG
```

## Решение

Искать слова вообще не нужно. Любая расстановка использует каждую букву
каждого слова ровно в одной клетке, поэтому при любой расстановке в
оставшихся клетках лежат буквы сетки за вычетом букв слов с учётом
кратности. Посчитаем 26 букв по сетке, вычтем их количества по словам и
выведем каждую букву столько раз, сколько её осталось.
`O(N·M + суммарная длина слов)`.

Тонкие места:

- поиск кажется обязательным, но не нужен: расстановка может быть
  неоднозначной, как в примере, а мультимножество оставшихся букв — нет;
- если слова покрывают всю сетку, ответ — пустая строка.

## Особенности языков

- Во всех языках вход читается как токены через пробельные символы, так
  что переводы строк не важны.
