# 1130. Выбор направления каждого вектора, чтобы прогулка закончилась не дальше √2·L от начала

[Timus 1130](https://acm.timus.ru/problem.aspx?space=1&num=1130) · сложность 937 · geometry, greedy

Автор оригинальной задачи — Дмитрий Филимоненков; VI студенческое соревнование по программированию УрГУ, 21 октября 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Ребёнок по очереди бежит вдоль `N ≤ 10000` целочисленных векторов, каждый
не длиннее `L ≤ 100`, а воспитательница для каждого решает, бежать по
нему или против него. Нужно выбрать направления так, чтобы ребёнок
закончил не дальше `√2·L` от начала. Вывести `YES` и выбор строкой из `+`
и `-` или `WRONG ANSWER`, если ни один выбор не подходит.

Ограничение времени: 0,25 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `L`, затем `N` строк с двумя координатами вектора.

## Выходные данные

`YES` и строка из `N` знаков: `+` — бежать вдоль вектора, `-` — против
него; или `WRONG ANSWER`.

## Проверка

Принимается любой подходящий выбор. Проверяющая программа смотрит
строку знаков и точно сравнивает квадрат расстояния до конечной точки с
`2L²`.

## Примеры

### Пример 1

Ввод:

```
4
5
5 0
0 5
0 0
-3 4
```

Вывод:

```
YES
+--+
```

## Решение

Хороший выбор есть всегда, так что ответ всегда `YES`. Главный факт:
среди любых трёх векторов не длиннее `L` найдутся два, сумма или разность
которых не длиннее `L`. Три прямые, на которых они лежат, делят
полуоборот на три угла, поэтому две прямые расходятся не больше чем на
60°; если взять эти два вектора со знаками, при которых угол между ними
не больше 60°, квадрат длины разности равен
`a² + b² − 2ab·cos θ ≤ a² + b² − ab`, а это не больше `max(a, b)² ≤ L²`.

Поэтому держим не больше двух ещё свободных векторов. Когда приходит
третий, находим пару и знак, дающие вектор не длиннее `L`, и заменяем
пару этой комбинацией. В конце остаётся не больше двух векторов; выбираем
знак, при котором их скалярное произведение неположительно, и квадрат
длины результата не больше `2L²`. Каждая комбинация — узел леса, у детей
которого записан относительный знак; итоговый знак исходного вектора —
произведение относительных знаков на пути к корню. Каждый узел создаётся
после своих детей, так что один проход по узлам в обратном порядке
расставляет знаки. Вся арифметика целочисленная. `O(N)`.

Тонкие места:

- ответ `WRONG ANSWER` не бывает никогда;
- сравнение квадратов длин делает всё точным, корни не нужны;
- смена знака у комбинированного вектора меняет знаки всех векторов
  внутри него, и относительные знаки в лесу учитывают это, не трогая их;
- нулевые векторы и `L = 0` не требуют отдельной обработки.

Ответы проверены проверяющей программой на всех тестах и на 150
случайных наборах векторов, в том числе на векторах около трёх
направлений через 120°, где у шага слияния меньше всего запаса.
