# 1130. 为每个向量选择方向，使行走终点离起点不超过 √2·L

[Timus 1130](https://acm.timus.ru/problem.aspx?space=1&num=1130) · 难度 937 · geometry, greedy

原题作者 Dmitry Filimonenkov，出自 2001 年 10 月 21 日第六届乌拉尔国立大学大学生程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个孩子依次沿着 `N ≤ 10000` 个整数向量奔跑，每个向量长度不超过
`L ≤ 100`，老师为每个向量决定是顺着跑还是逆着跑。请选择方向，使孩子最后
离起点不超过 `√2·L`。输出 `YES` 和由 `+`、`-` 组成的一行表示选择；若任何
选择都不行，输出 `WRONG ANSWER`。

时间限制：0.25 秒。内存限制：64 MB。

## 输入

`N`，然后 `L`，然后 `N` 行，每行是一个向量的两个坐标。

## 输出

`YES` 和一行 `N` 个符号，`+` 表示顺着向量跑，`-` 表示逆着跑；或者输出
`WRONG ANSWER`。

## 评测方式

任何合法的选择都被接受。检查程序验证符号行，并把终点距离的平方与 `2L²`
精确比较。

## 样例

### 样例 1

输入：

```
4
5
5 0
0 5
0 0
-3 4
```

输出：

```
YES
+--+
```

## 解法

合适的选择总是存在，所以答案总是 `YES`。关键事实：任意三个长度不超过 `L`
的向量中，总有两个的和或差长度不超过 `L`。它们所在的三条直线把半圈分成
三个角，所以有两条直线的夹角不超过 60°；取这两个向量并选符号使它们夹角
不超过 60°，差的长度平方为 `a² + b² − 2ab·cos θ ≤ a² + b² − ab`，不超过
`max(a, b)² ≤ L²`。

因此最多保留两个尚未合并的向量。第三个到来时，找出一对向量和一个符号，
使组合后的向量长度不超过 `L`，并用这个组合替换这对向量。最后最多剩下两个
向量；选择使它们点积非正的符号，结果的长度平方不超过 `2L²`。每个组合是
森林中的一个节点，子节点记录相对符号；输入向量的最终符号是它到根的路径上
相对符号的乘积。每个节点都在其子节点之后创建，所以按逆序扫描一遍节点即可
确定所有符号。全部运算都是整数运算。`O(N)`。

注意事项：

- 答案永远不会是 `WRONG ANSWER`；
- 比较长度的平方可以保持完全精确，不需要开方；
- 翻转组合向量的符号会翻转其中所有向量的符号，森林里的相对符号无需逐个
  修改就能处理这一点；
- 零向量和 `L = 0` 不需要特殊处理。

答案已用检查程序在所有测试以及 150 组随机向量上验证，其中包括靠近三个
相隔 120° 方向的向量，这时合并步骤的余地最小。
