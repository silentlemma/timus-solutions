# 1133. Член последовательности фибоначчиевого типа по двум другим членам

[Timus 1133](https://acm.timus.ru/problem.aspx?space=1&num=1133) · сложность 224 · number_theory

Оригинальная задача — четвертьфинал, центральный регион России, Рыбинск, 17–18 октября 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Целочисленная последовательность, бесконечная в обе стороны, удовлетворяет
`F(k + 2) = F(k + 1) + F(k)` для всех `k`. По `F(i)` и `F(j)` при `i ≠ j`
найти `F(n)`. Все индексы лежат в `[−1000, 1000]`, и каждый член от
наименьшего до наибольшего из `i, j, n` не превосходит `2·10⁹` по модулю.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Пять целых чисел: `i`, `F(i)`, `j`, `F(j)`, `n`.

## Выходные данные

`F(n)`.

## Примеры

### Пример 1

Ввод:

```
3 5 -1 4 5
```

Вывод:

```
12
```

## Решение

Пусть `i < j` (иначе меняем пары местами). Каждый член — фиксированная
целочисленная комбинация `F(i)` и `F(i + 1)`:
`F(j) = A·F(i) + B·F(i + 1)`, где `A` и `B` — числа Фибоначчи, которые
получаются, если `j − i` раз шагнуть парой коэффициентов от `(1, 0)` и
`(0, 1)`. Значит, неизвестное `F(i + 1) = (F(j) − A·F(i)) / B`, а потом
последовательность проходится вперёд или назад от `i` до `n` по
`F(k − 1) = F(k + 1) − F(k)`.

Трудность в размере: `B` может быть 2000-м числом Фибоначчи, далеко за
пределами 64 бит, а ответ маленький. Поэтому всё считается по модулю
простого `P = 4294967291`. Оно больше `4·10⁹ + 1` возможных ответов, так
что вычет `F(n)` определяет его однозначно: вычет больше `P / 2` означает
отрицательное значение. Оно меньше `2³²`, так что произведение двух
вычетов помещается в беззнаковое 64-битное целое. Деление — это умножение
на `B^(P−2)`, и оно работает, потому что ни одно число Фибоначчи с
индексом от 1 до 2000 не делится на `P` (проверено напрямую). Линейно по
ширине `W` диапазона индексов: не больше 4000 шагов.

Тонкие места:

- промежуточные `A` и `B` огромны, хотя все входные числа и ответ малы;
  обычная 64-битная арифметика переполняется;
- `n` может лежать вне отрезка от `i` до `j`, с любой стороны;
- данные индексы могут идти в любом порядке;
- нулевая последовательность допускает индексы на расстоянии 2000, так
  что проход длится до 2000 шагов.

Ответы сверены с точным вычислением в длинных целых на всех тестах и на
200 случайных запросах; заодно проверено, что входные данные укладываются
в ограничение `2·10⁹`.

## Особенности языков

- Во всех языках один и тот же модуль и проход.
- В Java нет беззнакового 64-битного типа, но `Long.remainderUnsigned`
  правильно приводит переполнившееся произведение.
