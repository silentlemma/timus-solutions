# 1133. 由两项求类斐波那契数列的另一项

[Timus 1133](https://acm.timus.ru/problem.aspx?space=1&num=1133) · 难度 225 · number_theory

原题出自 2001 年 10 月 17–18 日在雷宾斯克举行的俄罗斯中部赛区四分之一决赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个向两端无限延伸的整数数列对所有 `k` 满足 `F(k + 2) = F(k + 1) + F(k)`。
已知 `F(i)` 和 `F(j)`（`i ≠ j`），求 `F(n)`。所有下标都在 `[−1000, 1000]`
内，并且从 `i, j, n` 中最小的到最大的下标之间每一项的绝对值都不超过
`2·10⁹`。

时间限制：1 秒。内存限制：64 MB。

## 输入

五个整数：`i`、`F(i)`、`j`、`F(j)`、`n`。

## 输出

`F(n)`。

## 评测方式

答案按一个整数 token 比较。实际新 Python 源码与独立正向、反向整数递推对照了 2500 个合法随机查询及 100 个零序列查询，包括反序、负下标、区间外查询和完整 2000 下标跨度。两个实际新程序分别通过 Docker 中仓库的全部 13 个输入，且有精确源码对应的 Accepted。2600 次差分检查是 Python 执行，不是 2600 次 Java 执行。

## 样例

### 样例 1

输入：

```
3 5 -1 4 5
```

输出：

```
12
```

## 解法

先交换已知项，使 `i < j`，记 `D=j−i`。令普通斐波那契数为 `H(0)=0,H(1)=1`。不断代入可得 `F(j)=H(D−1)·F(i)+H(D)·F(i+1)`。由于 `D≥1`，`H(D)>0`，用精确整数除法即可唯一求出下一项。之后用加法向前走，或按 `F(k−1)=F(k+1)−F(k)` 向后走到目标位置。这也证明在题目保证存在序列时，重建及答案唯一。

新 Python、Go、Java 的 `math` 文件直接使用任意精度整数，不需要挑选素数、模逆以及分母可逆性证明；它们是这三种语言首选的教学版本。令 `W=max(i,j,n)−min(i,j,n)`，需要 `O(W)` 次大整数运算，系数有 `O(W)` 位。在固定输入值范围下，保守的位时间上界为 `O(W²)`，同时存活的大整数额外占 `O(W)` 位。不能把大整数运算当成常数时间而直接称为机器整数的线性算法。

保留的 `number_theory` 实现在素数 `P=4294967291` 下计算同一表达式。它大于 `4·10⁹+1` 种可能答案的总数；大于 `P/2` 的余数代表负数。用精确递推验证了下标 1 到 2000 的所有斐波那契分母模 `P` 非零，所以可以用费马定理求逆。余数乘积适合无符号 64 位整数。这种方式是 `O(W)` 固定宽度运算和常量数值空间，C++、Rust 不需外部大整数库。

五个输入按空白 token 读取。下标可能倒序、为负、相邻，也可能在两个已知位置之外。即使相隔最远，零序列仍然合法。精确及模运算版本已与独立递推对照，包括长零区间和区间外查询。

## 优化解法

未修改的 Go 模运算实现相对首选直接大整数 Go 基础版，是另一种优化算法：1064 KB 对 1544 KB，节省 31.1% 内存。0.015 s 对 0.031 s 只差一个计时刻度，不宣称可靠加速。旧 Java/Python 模运算实现保留为已接受的数学替代方案，不称为优化版。

新的 Java/Python `math_optimized` 保留直接精确运算，只增加有证明的提前返回。若两个已知项均为零，由重建公式及 `H(D)>0`，相邻未知项也必须为零。向前相加、向后相减，推出整个双向无限序列为零。因此不必生成很大的斐波那契系数，就能直接返回零。其他输入的算法不变：保守位时间 `O(W²)`，同时存活的大整数占 `O(W)` 位；零序列的算术工作为常量。这是同一递推的特殊情况，不是预存答案表。

基准是首选 `math` 简单版，而不是旧模运算文件。Java Accepted 为 536 KB 对 828 KB，节省 35.3%；0.093 s 对 0.109 s 只差一个刻度，不能作为可靠加速证据。Python 明确使用 PyPy 3.10：256 KB 对 CPython 基础版的 436 KB，节省 41.3%，但 0.140 s 对 0.078 s，记录时间增加 79.5%。按约定在同一 Python 语言族中比较，包含解释器变化，不能独立归因于提前返回。两版都按评测报告的内存收益准入；教学用直接基础版全部保留。

## 各语言说明

Python 使用内置整数，Go 使用 `math/big`，Java 使用 `BigInteger`。C++、Rust 保留以标准无符号整数编写的 Accepted 模运算实现。Java 模运算替代版本用 `Long.remainderUnsigned` 处理回绕的 64 位乘积。Java token 读取器能精确表示这里所有输入值。

2026 年 11 月 2 日保存的筛选排名采用约定规则：C++ 两项同时进入前 15% 或前十名，其他语言族两项都第一。已准入但未达排名目标的版本加星号。Go/Rust 的竞争者样本为空，仅提供形式覆盖，不证明竞争优势。
