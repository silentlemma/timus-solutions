# 1149. Выписывание вложенного выражения из синусов

[Timus 1149](https://acm.timus.ru/problem.aspx?space=1&num=1149) · сложность 61 · strings

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Пусть `Aₙ = sin(1−sin(2+sin(3−…sin(n)…)))`, где знаки чередуются минус и
плюс, и `S_N = (…((A₁+N)A₂+N−1)A₃+…+2)A_N+1`. Для `1 ≤ N ≤ 200` вывести
текст `S_N` в точности как в примере, без пробелов.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

Выражение `S_N`.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
((sin(1)+3)sin(1-sin(2))+2)sin(1-sin(2+sin(3)))+1
```

## Решение

Нужен только текст, ничего не вычисляется. `Aₙ` — это `sin(1`, затем для
каждого следующего `k` знак (минус после нечётного числа, плюс после
чётного) и `sin(k`, и в конце `n` закрывающих скобок. `S_N` начинается с
`N − 1` открывающих скобок; затем для `i` от 1 до `N` в нём идут `Aᵢ`,
плюс, число `N − i + 1` и закрывающая скобка после каждой части, кроме
последней. В выводе около `4·N²` символов, 165 тысяч при `N = 200`, и он
собирается в одну строку. `O(N²)`.

Тонкие места:

- знак после `k` зависит от `k`, а не от глубины синуса;
- у последней части `A_N+1` нет закрывающей скобки;
- при `N = 1` ответ просто `sin(1)+1`;
- пробелов нет нигде.

Ответы сверены на всех тестах со вторым построением, которое оборачивает
выражение изнутри наружу, `(S)Aᵢ+…`, а `Aᵢ` строит рекурсией.
