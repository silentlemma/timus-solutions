# 1106. 划分图，使每个顶点在另一侧都有邻居

[Timus 1106](https://acm.timus.ru/problem.aspx?space=1&num=1106) · 难度 74 · bfs

原题作者 Dmitry Filimonenkov，出自 2001 年 5 月 Tetrahedron Team Contest。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个无向图有 `N ≤ 100` 个顶点，每个顶点至少有一个邻居。把顶点分成两组，使每个顶点在另一组中都有邻居。如果做不到，输出 `0`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后是 `N` 行：第 `i` 行列出顶点 `i` 的邻居，并以 `0` 结尾。邻接表是对称的。

## 输出

第一组的大小，然后在第二行给出它的顶点，用单个空格分隔。

## 评测方式

接受任何一个正确的划分。检查程序验证列出的顶点互不相同、个数与大小一致，并且每个顶点（无论是否在第一组）在另一侧都有邻居。

## 样例

### 样例 1

输入：

```
7
2 3 0
3 1 0
1 2 4 5 0
3 0
3 0
7 0
6 0
```

输出：

```
4
1 4 5 6
```

## 解法

划分总是存在，所以从不输出 `0`。从每个尚未到达的顶点出发做 BFS，按顶点在 BFS 树中深度的奇偶性把它分到相应的组。非根顶点与其父节点分在不同侧；根至少有一个邻居，而这个邻居就是它在树中深度为
1 的孩子。只有树边起作用，所以奇环没有影响。对 `M` 对朋友为 `O(N + M)`。

注意事项：

- 这不是二分图判定：三角形无法正常二染色，但可以很好地分成一个顶点对两个顶点；
- 图可能有多个连通分量，每个分量都需要自己的 BFS 根。

答案在所有测试上以及生成器四种形状的数百个随机图上都用检查程序验证过。

## 优化解法

优化解法（Go、Java）从缓冲区手工解析输入，把每个顶点的邻居存为字节（顶点最多 100
个），并用一个普通数组充当 BFS 的队列。顶点所属的队伍记为 1 或 2，0 表示尚未到达，
因此一个数组同时代替了“已访问”标记和颜色。Java 先把一个顶点的邻居收集到
`n` 字节的缓冲区，再复制到大小正好的数组：每行列出该顶点在其余 `n - 1`
个顶点中的邻居，每个只出现一次，因此少于 `n` 项。Go：948 KB，而不是
1480 KB，时间不变。Java：0.093 s，而不是 0.125 s；420 KB，而不是 748 KB。

优化的 Python 解法逐行解析输入，把邻接表和分组放在 `bytearray` 中（顶点最多 100
个），并把普通列表按顺序遍历当作队列：548 KB，而不是 964 KB，时间不变。
