# 1136. Перевод порядка «левое, правое, корень» дерева поиска в порядок «правое, левое, корень»

[Timus 1136](https://acm.timus.ru/problem.aspx?space=1&num=1136) · сложность 100 · trees

Оригинальная задача — четвертьфинал, центральный регион России, Рыбинск, 17–18 октября 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Члены парламента с различными положительными номерами рассаживаются как в
двоичном дереве поиска: первый — председатель, а каждый следующий идёт
влево, если его номер меньше номера текущего председателя, и вправо
иначе, пока не найдёт свободное кресло. На нечётных сессиях выступают в
порядке левое крыло, правое крыло, председатель, рекурсивно; на чётных —
правое крыло, левое крыло, председатель. По порядку нечётной сессии для
`N ≤ 3000` членов с номерами до 65535 вывести порядок чётной сессии.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` номеров в порядке нечётной сессии.

## Выходные данные

Номера в порядке чётной сессии, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
9
1
7
5
21
22
27
25
20
10
```

Вывод:

```
27
21
22
25
20
7
1
5
10
```

## Решение

Порядок нечётной сессии — обратный обход дерева поиска: левое крыло,
правое крыло, председатель. Если читать его с конца, каждый председатель
идёт раньше всех членов своих крыльев. Поэтому вставка номеров в пустое
двоичное дерево поиска в этом развёрнутом порядке ставит каждого члена
ровно на его место: его председатель к этому моменту уже на месте. Порядок
чётной сессии — рекурсивный обход: правое крыло, левое крыло, председатель.

Каждая вставка спускается от корня. На цепочке из 3000 членов это до 3000
шагов, всего около 4,5 миллиона: `O(N^2)`, но всё равно быстро.

Тонкие места:

- дерево может быть цепочкой глубины 3000, такой же глубины и рекурсия
  обхода; Python поднимает предел рекурсии;
- номера могут стоять по нескольку в строке, их читают как токены;
- для одного члена оба порядка совпадают.

Ответы обоих способов сверены на всех тестах и на 300 случайных
парламентах; заодно проверено, что каждый вход — правильный порядок
нечётной сессии.

## Оптимизированные решения

Оптимизированные решения восстанавливают дерево за один проход, `O(N)`.
Если читать порядок нечётной сессии с конца, он даёт каждого председателя,
затем всё правое крыло, затем всё левое. Держим стек председателей, к
которым ещё может прийти левое крыло:

- если следующий номер больше вершины стека, он правый ребёнок этой
  вершины;
- иначе снимаем всех председателей больше него; последний снятый — тот,
  чьё левое крыло он начинает, и он становится его левым ребёнком.

Каждый номер кладётся в стек один раз и снимается не больше одного раза.
Порядок чётной сессии — обычный порядок корень, левое, правое, прочитанный
с конца, и его даёт второй явный стек без рекурсии. Дети индексируются
позицией во вводе; Go к тому же разбирает ввод вручную. Решению на C++
нужно 188 КБ вместо 348 КБ, на Go — 1052 КБ вместо 2200 КБ, в обоих
случаях при том же времени; решению на Python — 0.078 с вместо 0.500 с
и 1028 КБ вместо 1508 КБ. Для Java и Rust есть только простые решения.

## Особенности языков

- Простые решения обходят дерево рекурсивно, до 3000 вызовов в глубину:
  ни одному языку для этого не нужен больший стек, Python лишь поднимает
  предел рекурсии.
