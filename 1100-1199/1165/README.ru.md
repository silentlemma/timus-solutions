# 1165. Где строка цифр впервые встречается в 123456789101112…

[Timus 1165](https://acm.timus.ru/problem.aspx?space=1&num=1165) · сложность 930 · strings

Автор оригинальной задачи — Никита Шамгунов; северный подрегион полуфинала ACM ICPC Северо-Восточной Европы 2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`S` — бесконечная строка из всех натуральных чисел, записанных подряд:
`1234567891011121314…`, нумерация с 1. Дана строка `A` не длиннее 200
цифр; найти наименьшее `k`, такое что `A` встречается в `S` с позиции `k`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Строка `A`.

## Выходные данные

Число `k`. В нём может быть около 200 цифр.

## Примеры

### Пример 1

Ввод:

```
101
```

Вывод:

```
10
```

## Решение

Первая цифра `d`-значного числа `x` стоит на позиции `d·x + 1 − R(d)`,
где `R(d)` — репьюнит `11…1` из `d` единиц: более короткие числа занимают
`(d − 1)·10^(d−1) − R(d − 1)` цифр, а `10^(d−1) + R(d − 1) = R(d)`.

Вхождение `A` накрывает несколько идущих подряд чисел. Бывает три вида:

1. Какое-то число `x` целиком лежит внутри `A`. Тогда `x` — подстрока `A`
   без ведущего нуля, и оно определяет всё остальное: пишем `x + 1`,
   `x + 2`, … вправо и `x − 1`, `x − 2`, … влево и сравниваем с `A`. Таких
   подстрок `O(n²)`.
2. `A` — конец `y − 1`, за которым идёт начало `y`, оба неполные, граница
   в позиции `i`. Начало `y` — это `A[i..]`. Последние `i` цифр `y` — это
   последние `i` цифр `y − 1` плюс один, то есть `A[..i] + 1`, обрезанное
   до `i` цифр, даже когда перенос превращает `99…9` в `100…0`. Самое
   короткое `y` как можно сильнее накладывает эти две известные части,
   поэтому перебираются все наложения с проверкой, как в первом случае.
3. `A` лежит внутри одного числа, но не с его начала. Самое короткое такое
   число — `1A`, так что `k` — позиция `1A` плюс один.

Ответ — наименьшая позиция среди всех кандидатов, прошедших проверку.
`O(n³)` операций с цифрами, `n ≤ 200`.

Тонкие места:

- `A` может начинаться с нулей или состоять из одних нулей: `0` впервые
  встречается внутри `10`, на позиции 11;
- ответ далеко выходит за 64 бита, так что для позиций нужна длинная
  арифметика;
- число перед степенью десяти на одну цифру короче;
- проход влево должен заканчиваться неудачей, если дошёл до нуля.

Ответы сверены с прямым поиском в `S` на всех строках до трёх цифр и на
случайных до пяти, всего 1 708 строк, и на 400 сгенерированных строках до
200 цифр с отдельно написанным решением.

## Особенности языков

- Python везде использует свои длинные целые.
- Go и Java идут по соседним числам в виде десятичных строк, а позиции
  считают через `big.Int` и `BigInteger`.
- C++ и Rust держат всё в десятичных строках, с небольшими функциями для
  прибавления единицы, вычитания единицы, умножения на длину и вычитания.
