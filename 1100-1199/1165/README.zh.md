# 1165. 一个数字串在 123456789101112… 中第一次出现的位置

[Timus 1165](https://acm.timus.ru/problem.aspx?space=1&num=1165) · 难度 930 · strings

原题作者 Nikita Shamgunov，出自 2001 年 ACM ICPC 东北欧区域赛北部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`S` 是把所有正整数依次写在一起得到的无限字符串：`1234567891011121314…`，
下标从 1 开始。给定一个不超过 200 位的数字串 `A`，求最小的 `k`，使 `A` 在 `S`
中从位置 `k` 开始出现。

时间限制：1 秒。内存限制：64 MB。

## 输入

字符串 `A`。

## 输出

数 `k`。它可能有约 200 位。

## 样例

### 样例 1

输入：

```
101
```

输出：

```
10
```

## 解法

`d` 位数 `x` 的第一位位于 `d·x + 1 − R(d)`，其中 `R(d)` 是由 `d` 个 1 组成的
循环单位数 `11…1`：更短的数共占 `(d − 1)·10^(d−1) − R(d − 1)` 位，而
`10^(d−1) + R(d − 1) = R(d)`。

`A` 的一次出现覆盖若干个连续的数。分三种情况：

1. 某个数 `x` 完全位于 `A` 之内。那么 `x` 是 `A` 的一个不带前导零的子串，它
   决定了其余一切：向右写出 `x + 1`、`x + 2`、…，向左写出 `x − 1`、`x − 2`、…，
   与 `A` 比较。这样的子串有 `O(n²)` 个。
2. `A` 是 `y − 1` 的结尾接上 `y` 的开头，两者都不完整，分界在位置 `i`。`y`
   的开头是 `A[i..]`。`y` 的最后 `i` 位等于 `y − 1` 的最后 `i` 位加一，即
   `A[..i] + 1` 截取到 `i` 位，即使进位把 `99…9` 变成 `100…0` 也成立。最短的
   `y` 让这两段已知部分尽可能重叠，所以尝试每种重叠并像情况 1 那样检查。
3. `A` 位于某一个数之内，但不在它的开头。最短的这样的数是 `1A`，所以 `k` 是
   `1A` 的位置加一。

答案是所有通过检查的候选位置中的最小值。`O(n³)` 次数字运算，`n ≤ 200`。

注意事项：

- `A` 可能以零开头，甚至全是零：`0` 第一次出现在 `10` 中，位置 11；
- 答案远超 64 位，所以位置需要高精度；
- 10 的幂前面的那个数少一位；
- 向左走如果走到了零，必须判定失败。

答案已在所有不超过三位的串和不超过五位的随机串（共 1,708 个）上与在 `S` 中的
直接查找比对，并在 400 个不超过 200 位的生成串上与另一份独立编写的解答比对。
