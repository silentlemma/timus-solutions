# 1150. 页码 1 到 N 中每个数字出现的次数

[Timus 1150](https://acm.timus.ru/problem.aspx?space=1&num=1150) · 难度 249 · math

原题作者 Evgeny Bryzgalov，出自 2001 年 4 月在彼尔姆举行的乌拉尔团体程序设计锦标赛英语轮。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

页码从 1 编到 `N`，`N < 10⁹`。统计 0 到 9 每个数字各写了多少次。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`。

## 输出

十行：0、1、…、9 的个数。

## 评测方式

按数字0..9顺序比较十个精确整数计数，忽略空白。 新Python精确源码在PyPy 3.10通过12个仓库测试。 其他保留原生版本各有保存的目标环境检查与精确Accepted。输出按本题检查器规则比较。

## 样例

### 样例 1

输入：

```
12
```

输出：

```
1
5
2
1
1
1
1
1
1
1
```

## 解法

每个十进制位分别统计。对权为 `p`（1、10、100、…）的位，把 `N` 分成它上面的
部分 `high = N / (10p)`、该位上的数字 `cur` 和下面的部分 `low = N mod p`。
按这一位上面的部分来看 1 到 `N` 的数：

- 上面部分从 `0` 到 `high − 1` 的每一种，后面都跟着全部 `10p` 种低位结尾，
  所以对其中每一种，每个数字在这一位上出现 `p` 次；
- 上面部分等于 `high` 时，数字 `d < cur` 再出现 `p` 次，`d = cur` 再出现
  `low + 1` 次（结尾从 `0` 到 `low`），更大的数字不出现。

零不一样：只有上面有非零数字时，这一位上的零才会被写出，所以上面部分为 `0`
的不算。于是从 1 开始的完整上面部分给出 `(high − 1)·p`，再加上与上面相同的
`p` 或 `low + 1`，而且这一切只在 `high > 0` 时成立。最多九个位。
`O(log N)`。

注意事项：

- 前导零不写出，所以零需要单独的规则；
- `N = 999999999` 时计数达到 `9·10⁸`，仍在 32 位范围内；
- `N` 本身也包括在内。

答案已与逐个写出所有数的结果比对（所有 `N ≤ 3000` 以及许多不超过 30000 的
`N`），并在所有测试上与按 `N` 的十进制写法逐位计数的结果比对。

## 优化解法

`1150_math_optimized.go`. 保留高位/当前位/低位计数及前导零修正。保护位权乘法，以 limit/place/radix 比较避免溢出。O(log N) 时间、常数额外空间，不枚举全部数字。 以 Go 1.14 syscall.Read/Write 使用有界 256 字节输入及 64 字节输出缓冲，重试 EINTR、部分写入并处理零字节 EOF，移除 fmt/bufio/os.File 初始化开销。Linux 测试和 Windows 交叉构建验证功能及构建；下列配对内存指标来自我们精确源在 Windows 评测的 Accepted。保留清晰教学源。

与 `1150_math.go` 相比：时间 0.031 s → 0.015 s；内存 1084 KB → 292 KB。

`1150_math_optimized.rs`. 保留 high/current/low 按位公式及去掉前导零的修正。直接数值输入与十行整数输出替代标准文本/格式化，固定十个计数及算法不变。题定整数范围下 O(log(N+1)) 时间、O(1) 辅助空间。保留清晰公式版及实测运行时更小的版本。

与 `1150_math.rs` 相比：时间 0.015 s → 0.046 s；内存 236 KB → 40 KB。

按数位计数算法不变：每个十进制位把N分成高位、当前位和低位。非零数字计算完整周期及部分周期，零则排除全前导零块。保留十个计数器，每步位权乘十。紧凑版本降低输入输出开销，并非采用另一计数公式。Python有自身PyPy Accepted，以更高实测耗时换取更少内存，所有清晰版本仍保留。

- `1150_math_optimized.java`: 0.078 s / 320 KB; 基础 `1150_math.java`: 0.109 s / 1568 KB; 相对变化: 时间 -28.4%, 内存 -79.6%.
- `1150_math_optimized.py`: 0.140 s / 316 KB; 基础 `1150_math.py`: 0.062 s / 460 KB; 相对变化: 时间 +125.8%, 内存 -31.3%.
