# 1150. Сколько раз каждая цифра встречается в номерах страниц от 1 до N

[Timus 1150](https://acm.timus.ru/problem.aspx?space=1&num=1150) · сложность 249 · math

## Задача

Страницы пронумерованы от 1 до `N`, `N < 10⁹`. Посчитать, сколько раз
пишется каждая цифра от 0 до 9.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

Десять строк: количество нулей, единиц, …, девяток.

## Проверка

Сравниваются десять точных целых количеств в порядке цифр 0..9; пробелы несущественны. Новый точный исходник Python прошёл 12 тестов репозитория на PyPy 3.10. Остальные сохранённые варианты имеют собственные проверки целевой среды и точные Accepted. Вывод сравнивается по правилам проверяющего модуля задачи.

## Решение

Каждый десятичный разряд считаем отдельно. Для разряда с весом `p` (1, 10,
100, …) разобьём `N` на часть выше него, `high = N / (10p)`, цифру `cur` в
нём и часть ниже, `low = N mod p`. Рассмотрим числа от 1 до `N` по их части
выше этого разряда:

- за каждой верхней частью от `0` до `high − 1` идут все `10p` нижних
  окончаний, так что для каждой из них каждая цифра встречается в этом
  разряде `p` раз;
- при верхней части, равной `high`, цифра `d < cur` встречается ещё `p`
  раз, `d = cur` — ещё `low + 1` раз (для окончаний от `0` до `low`), а
  большие цифры не встречаются вовсе.

С нулями иначе: ноль в этом разряде пишется, только если выше стоит
ненулевая цифра, так что верхняя часть `0` не считается. Это даёт
`(high − 1)·p` для полных верхних частей начиная с 1, а затем `p` или
`low + 1`, как выше, и всё это только при `high > 0`. Разрядов не больше
девяти. `O(log N)`.

Тонкие места:

- ведущие нули не пишутся, поэтому для нулей нужно отдельное правило;
- при `N = 999999999` количества доходят до `9·10⁸`, это ещё 32 бита;
- само `N` тоже входит.

Ответы сверены с выписыванием всех чисел для всех `N` до 3000 и многих
до 30000, а также с поразрядным подсчётом по десятичной записи `N` на всех
тестах.

## Оптимизированные решения

Позиционный подсчёт не изменён: для каждого десятичного разряда N делится на старшие цифры, текущую цифру и младшие цифры. Ненулевая цифра получает полные циклы и неполный остаток; у нуля исключается блок ведущих нулей. Хранятся десять счётчиков, вес разряда умножается на десять. Компактные файлы уменьшают накладные расходы ввода-вывода, а не вводят другую формулу подсчёта. У Python собственный Accepted на PyPy: более высокое время обменивается на меньшую память; понятные версии сохранены.

- `1150_math_optimized.java`: 0.078 s / 320 KB; база `1150_math.java`: 0.109 s / 1568 KB; изменение относительно базы: время -28.4%, память -79.6%.
- `1150_math_optimized.py`: 0.140 s / 316 KB; база `1150_math.py`: 0.062 s / 460 KB; изменение относительно базы: время +125.8%, память -31.3%.
