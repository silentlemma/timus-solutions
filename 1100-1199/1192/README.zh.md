# 1192. 梦中弹跳的球能飞多远

[Timus 1192](https://acm.timus.ru/problem.aspx?space=1&num=1192) · 难度 109 · math

原题作者 Igor Goldberg，出自 2002 年 3 月 2 日第五届中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在无限大的水平地面上，以与水平面成 `a` 度的角度、`V` 米/秒的速度抛出一个球；
重力加速度为 `10` 米/秒²，没有空气。球以相同角度反弹，每次撞击地面动能减小为
原来的 `1/K`（`K > 1`），圆周率取 `3.1415926535`。求球离抛出点最远能到多远，
保留两位小数。

时间限制：1 秒。内存限制：64 MB。

## 输入

`V`（至多 500000）、`a`（0 到 90）和 `K`。

## 输出

以米为单位的距离，四舍五入到两位小数。

## 样例

### 样例 1

输入：

```
5 15 2.50
```

输出：

```
2.08
```

## 解法

速度为 `v`、角度为 `a` 的一次飞行距离为 `v²·sin(2a)/g`。反弹时角度不变，动能也就
是 `v²` 除以 `K`。各次飞行构成公比为 `1/K` 的等比数列，其和为第一次飞行距离乘以
`K/(K − 1)`。`O(1)`。

注意事项：

- 圆周率必须用给定的 `3.1415926535`：用它计算时，以最大速度竖直上抛的球仍会
  偏出几米，预期答案包含了这一点；
- 当 `K` 接近 1 时结果可达约 `2.5·10¹⁴`，对两位小数而言仍在 double 的精度之内；
- `V = 0` 或 `a = 0` 时结果为 `0.00`。

答案已在所有测试上与另一份独立编写的解答比对。
