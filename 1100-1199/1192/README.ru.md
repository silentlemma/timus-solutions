# 1192. Как далеко улетит прыгающий мячик во сне

## Задача

С бесконечной горизонтальной плоскости бросают мячик под углом `a`
градусов к горизонту со скоростью `V` м/с; ускорение свободного падения
`10` м/с², воздуха нет. Мячик отскакивает под тем же углом, при каждом
ударе его кинетическая энергия уменьшается в `K > 1` раз, а число пи равно
`3.1415926535`. Найти, на какое расстояние от точки броска может улететь
мячик, с двумя знаками после запятой.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`V` (до 500000), `a` (от 0 до 90) и `K`.

## Выходные данные

Расстояние в метрах, округлённое до двух знаков.

## Примеры

### Пример 1

Ввод:

```
5 15 2.50
```

Вывод:

```
2.08
```

## Решение

Один полёт со скоростью `v` под углом `a` покрывает `v²·sin(2a)/g`.
Отскок сохраняет угол и делит кинетическую энергию, а значит и `v²`, на
`K`. Полёты образуют геометрическую прогрессию со знаменателем `1/K`, и её
сумма — первый полёт, умноженный на `K/(K − 1)`. `O(1)`.

Тонкие места:

- пи должно быть именно `3.1415926535`: с ним бросок прямо вверх при
  наибольшей скорости всё равно сносит на несколько метров, и ожидаемые
  ответы это учитывают;
- при `K`, близком к 1, результат доходит примерно до `2.5·10¹⁴`, что всё
  ещё укладывается в точность double для двух знаков;
- `V = 0` или `a = 0` дают `0.00`.

Ответы сверены с отдельно написанным решением на всех тестах.
