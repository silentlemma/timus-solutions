# 1189. Пары X + Y = N, где Y — это X с вычеркнутой цифрой

[Timus 1189](https://acm.timus.ru/problem.aspx?space=1&num=1189) · сложность 500 · math

Авторы оригинальной задачи — Владимир Лелюх и Роман Елизаров; полуфинал ACM ICPC Северо-Восточной Европы 2001–2002.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано `10 ≤ N ≤ 10⁹`; найти все пары `X + Y = N`, где у `X` не меньше двух
цифр и нет ведущего нуля, а `Y` — это `X` с одной вычеркнутой цифрой,
записанное на одну цифру короче `X` (поэтому может начинаться с нулей).
Вывести их число и сами пары по возрастанию `X`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

Число пар, затем строки `X + Y = N`.

## Примеры

### Пример 1

Ввод:

```
302
```

Вывод:

```
5
251 + 51 = 302
275 + 27 = 302
276 + 26 = 302
281 + 21 = 302
301 + 01 = 302
```

## Решение

Вычеркнем из `X` цифру `d` в разряде `k` (считая справа с 0). Запишем
`X = (10a + d)·10ᵏ + b`, где `b < 10ᵏ`; тогда `Y = a·10ᵏ + b` и

`X + Y = (11a + d)·10ᵏ + 2b = N`.

Значит, `2b` сравнимо с `N` по модулю `10ᵏ`. Поскольку `2b < 2·10ᵏ`, это
либо `N mod 10ᵏ`, либо оно же плюс `10ᵏ`, и оно должно быть чётным с
`b < 10ᵏ`. Остаток `(N − 2b)/10ᵏ` равен `11a + d`, что даёт `a` и `d`
делением на 11; остаток от деления должен быть настоящей цифрой, а не 10.
`X` подходит, если в нём не меньше двух цифр и он начинается не с нуля,
то есть `a > 0` или `d > 0`. Не больше двух кандидатов на разряд, всего
`O(log N)`.

Тонкие места:

- одна и та же пара может получиться вычёркиванием разных одинаковых
  цифр, как в `11 + 1 = 12`, поэтому кандидаты собираются в множество;
- `Y` печатается ровно на одну цифру короче `X`, с ведущими нулями, как в
  `301 + 01`;
- остаток `d` от деления на 11 может быть равен 10, а это не цифра.

Ответы сверены с прямым перебором всех `X` для каждого `N` до 1199 и для
150 случайных `N` до 200000, а также с отдельно написанным решением на
всех тестах.

## Особенности языков

- Во всех языках `Y` печатается с шириной по длине `X` и дополнением
  нулями.
