# 1189. 满足 X + Y = N 且 Y 是 X 删去一位数字的数对

[Timus 1189](https://acm.timus.ru/problem.aspx?space=1&num=1189) · 难度 500 · math

原题作者 Vladimir Lelyukh 和 Roman Elizarov，出自 2001–2002 年 ACM ICPC 东北欧区域赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定 `10 ≤ N ≤ 10⁹`，求所有满足 `X + Y = N` 的数对，其中 `X` 至少两位且无前导
零，`Y` 是 `X` 删去一位数字后得到的数，写成比 `X` 少一位的形式（因此可能以零
开头）。输出数对个数，并按 `X` 递增输出各数对。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`。

## 输出

数对个数，然后是若干行 `X + Y = N`。

## 样例

### 样例 1

输入：

```
302
```

输出：

```
5
251 + 51 = 302
275 + 27 = 302
276 + 26 = 302
281 + 21 = 302
301 + 01 = 302
```

## 解法

从 `X` 中删去第 `k` 位（从右往左、从 0 开始数）的数字 `d`。记
`X = (10a + d)·10ᵏ + b`，其中 `b < 10ᵏ`；于是 `Y = a·10ᵏ + b`，并且

`X + Y = (11a + d)·10ᵏ + 2b = N`。

所以 `2b` 与 `N` 模 `10ᵏ` 同余。由于 `2b < 2·10ᵏ`，它要么是 `N mod 10ᵏ`，要么是
它再加 `10ᵏ`，并且必须是偶数且 `b < 10ᵏ`。剩下的 `(N − 2b)/10ᵏ` 等于 `11a + d`，
除以 11 即得 `a` 和 `d`；余数必须是真正的数字，不能是 10。若 `X` 至少两位且首位
非零（即 `a > 0` 或 `d > 0`），就保留它。每一位至多两个候选，总共 `O(log N)`。

注意事项：

- 删去不同的相同数字可能得到同一个数对，例如 `11 + 1 = 12`，所以候选放进集合；
- `Y` 恰好比 `X` 少一位，带前导零输出，例如 `301 + 01`；
- 除以 11 的余数 `d` 可能是 10，它不是数字。

答案已在 1199 以内的每个 `N` 以及 150 个不超过 200000 的随机 `N` 上与枚举所有
`X` 的直接搜索比对，并在所有测试上与另一份独立编写的解答比对。

- 所有语言都按 `X` 的长度确定 `Y` 的宽度，并用零补齐。
