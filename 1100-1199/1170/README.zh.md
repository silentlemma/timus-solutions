# 1170. 穿过不同速度区域、长度为 L 的最快直线行走

[Timus 1170](https://acm.timus.ru/problem.aspx?space=1&num=1170) · 难度 1479 · geometry

原题作者 Mugurel Ionut Andreica，出自 2001 年 12 月的 Romanian Open Contest（罗马尼亚公开赛）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

从原点沿直线走 `L` 米，到达一个坐标为正的点。第一象限中有 `N ≤ 500` 个边平行于
坐标轴的矩形，各有延迟系数：在矩形内走长度 `d` 的一段耗时 `d·c`，在矩形外的
沙漠中耗时 `d·c0`。所有数都是不超过 32000 的正整数，且 `L` 超出所有矩形。求
最小总时间以及达到它的一个终点。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N`，然后 `N` 行 `x1 y1 x2 y2 c`，最后是 `c0` 和 `L`。

## 输出

最小时间，然后是终点，全部保留六位小数。

## 评测方式

只要终点到原点的距离为 `L`、坐标为正，并且给出最小时间，就被接受；检查程序
沿该方向逐个矩形重新计算时间。

## 样例

### 样例 1

输入：

```
1
1 1 2 2 1
2 3
```

输出：

```
4.585786
2.121320 2.121320
```

## 解法

以角度 `t` 行走时，经过 `a / cos t` 到达直线 `x = a`，经过 `b / sin t` 到达
直线 `y = b`。进入矩形的位置是 `x1 / cos t` 与 `y1 / sin t` 中较大者，离开的
位置是 `x2 / cos t` 与 `y2 / sin t` 中较小者。所以时间等于 `c0·L` 加上每个
矩形的 `(c − c0)` 乘以弦长，而走哪条边只在四个角的方向处切换。

因此在两个相邻的角方向之间，时间形如 `c0·L + p / cos t + q / sin t`，其中
`p`、`q` 是固定的整数。若 `p, q > 0`，它在整段上都大于 `c0·L`。否则它单调
（`p` 与 `q` 异号时）或是凹的（两者都为负），最小值都在段的端点。低于最低角
方向的方向不经过任何矩形，耗时恰为 `c0·L`。所以答案是 `c0·L` 与各角方向时间
中的最小值。

每个矩形贡献四项，每项在两个角方向处开启和关闭，所以按斜率排序扫描各方向即可
维护 `p` 和 `q`。斜率按分数比较，所以同一射线上的角合并为一个事件。
`O(N log N)`。

注意事项：

- 时间随方向连续变化，所以用角之前那一段的 `p` 和 `q` 计算该角是精确的；
- 同一射线上的两个角必须精确合并，否则它们之间极小的伪段可能给出一个任何方向
  都达不到的时间；
- 终点坐标必须为正，所以空方向取在最低角下方的中间，而不是沿坐标轴。

答案已在 400 组随机矩形（包括藏在慢速条带后面的快速区域）上与 20,000 个方向
的密集扫描比对，并在所有测试上与另一份独立编写的解答比对。

## 各语言说明

- C++ 和 Java 用有序映射保存事件，比较器按分数比较斜率；Python、Go 和 Rust
  把每个方向除以最大公约数后排序。
