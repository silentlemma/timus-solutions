# 1170. Самый быстрый прямой путь длины L через зоны с разной скоростью

[Timus 1170](https://acm.timus.ru/problem.aspx?space=1&num=1170) · сложность 1479 · geometry

Автор оригинальной задачи — Mugurel Ionut Andreica; Romanian Open Contest, декабрь 2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Из начала координат пройти `L` метров по прямой до точки с
положительными координатами. У `N ≤ 500` прямоугольников со сторонами
вдоль осей в первой четверти есть коэффициенты задержки: отрезок длины
`d` внутри прямоугольника стоит `d·c`, а вне их пустыня стоит `d·c0`. Все
числа — положительные целые до 32000, и `L` достаёт дальше любого
прямоугольника. Найти наименьшее общее время и точку, на которой оно
достигается.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк `x1 y1 x2 y2 c`, затем `c0` и `L`.

## Выходные данные

Наименьшее время, затем конечная точка, всё с шестью знаками после
запятой.

## Проверка

Принимается любая конечная точка на расстоянии `L` от начала, с
положительными координатами и с наименьшим временем; проверяющая
программа пересчитывает время вдоль её направления по всем
прямоугольникам.

## Примеры

### Пример 1

Ввод:

```
1
1 1 2 2 1
2 3
```

Вывод:

```
4.585786
2.121320 2.121320
```

## Решение

При движении под углом `t` прямая `x = a` достигается через `a / cos t`,
а прямая `y = b` — через `b / sin t`. В прямоугольник входим на большем
из `x1 / cos t` и `y1 / sin t`, а выходим на меньшем из `x2 / cos t` и
`y2 / sin t`. Значит, время — это `c0·L` плюс `(c − c0)`, умноженное на
хорду каждого прямоугольника, а то, через какую сторону идёт путь,
меняется только на направлениях четырёх углов.

Поэтому между двумя соседними угловыми направлениями время имеет вид
`c0·L + p / cos t + q / sin t` с постоянными целыми `p` и `q`. Если
`p, q > 0`, оно на всём куске больше `c0·L`. Иначе оно монотонно (когда у
`p` и `q` разные знаки) или вогнуто (оба отрицательны), так что
наименьшее значение — на конце куска. Направления ниже самого низкого
угла не задевают ни одного прямоугольника и стоят ровно `c0·L`. Значит,
ответ — лучшее из `c0·L` и времён на угловых направлениях.

Каждый прямоугольник добавляет четыре слагаемых, каждое включается и
выключается на двух угловых направлениях, так что проход по
направлениям, отсортированным по наклону, поддерживает `p` и `q`. Наклоны
сравниваются как дроби, поэтому углы на одном луче дают одно событие.
`O(N log N)`.

Тонкие места:

- время непрерывно по направлению, так что вычислять угол с `p` и `q`
  куска прямо перед ним точно;
- два угла на одном луче нужно объединять точно, иначе крошечный ложный
  кусок между ними может показать время, которого нет ни у какого
  направления;
- у конечной точки координаты должны быть положительными, поэтому пустое
  направление берётся посередине ниже самого низкого угла, а не вдоль
  оси.

Ответы сверены с плотным перебором 20 000 направлений на 400 случайных
наборах прямоугольников, включая быстрые зоны за медленными полосами, и с
отдельно написанным решением на всех тестах.

## Особенности языков

- C++ и Java хранят события в упорядоченном словаре, компаратор которого
  сравнивает наклоны как дроби; Python, Go и Rust сокращают каждое
  направление на НОД и сортируют.
