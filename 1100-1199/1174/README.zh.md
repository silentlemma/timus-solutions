# 1174. 排列在相邻交换顺序中的位置

[Timus 1174](https://acm.timus.ru/problem.aspx?space=1&num=1174) · 难度 716 · math

原题作者 Mugurel Ionut Andreica，出自 2001 年 12 月的 Romanian Open Contest（罗马尼亚公开赛）；题面中的生成程序基于 Frank Ruskey 的程序。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给定的程序列出 `1..N`（`N ≤ 100`）的全部 `N!` 个排列：从 `1 2 … N` 开始，每次
交换两个相邻元素。它是递归进行的：元素 `k` 一步步地穿过较小元素的排列，方向
交替，而在它的每两步之间，较大的元素完成它们的全部移动。给定一个排列，求它在
列表中的行号。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N`，然后是排列。

## 输出

从 1 开始计数的位置；可能超过 150 位。

## 样例

### 样例 1

输入：

```
4 
2 3 1 4
```

输出：

```
17
```

## 解法

只看元素 `1..k`，忽略较大的元素。它们的相对顺序只在 `k` 或更小的元素移动时
改变，所以这些顺序构成的列表正是 `k` 个元素时的列表。在其中，对 `1..k−1` 的
每一种顺序，元素 `k` 都在 `k` 个位置上走一趟，而且各趟交替：第一趟从右端走向
左边，下一趟从左向右，依此类推。

因此若 `rank(k−1)` 是 `1..k−1` 的顺序从 0 起的编号，那么 `1..k` 的顺序位于
第 `rank(k−1)` 趟中、偏移为 `s` 的位置，其中向右走的趟（奇数趟）里 `s` 是 `k`
左边较小元素的个数，向左走的趟（偶数趟）里是 `k − 1` 减去这个数。于是
`rank(k) = rank(k−1)·k + s`，答案是 `rank(N) + 1`。计数需要 `O(N²)`，另加
大整数运算。

注意事项：

- 方向取决于大整数 `rank(k−1)` 的奇偶性，但只需要它的最后一位；
- 程序开始时元素 `k` 在右端并向左移动，所以偶数趟是向左的；
- `100!` 有 158 位，64 位远远不够。

答案已在 `N ≤ 6` 时对每个排列与直接运行列表程序的结果核对，并在至多 100 个
元素的随机排列上与另一份独立编写的解答比对。
