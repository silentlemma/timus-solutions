# 1174. Номер перестановки в порядке обменов соседей

[Timus 1174](https://acm.timus.ru/problem.aspx?space=1&num=1174) · сложность 716 · math

Автор оригинальной задачи — Mugurel Ionut Andreica; Romanian Open Contest, декабрь 2001; программа из условия основана на программах Frank Ruskey.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Данная программа выписывает все `N!` перестановок `1..N` (`N ≤ 100`),
начиная с `1 2 … N` и каждый раз меняя местами двух соседей. Делает она
это рекурсивно: элемент `k` шаг за шагом проходит через расстановку
меньших элементов, чередуя направление, а между его шагами большие
элементы проделывают все свои ходы. По перестановке найти номер её строки
в этом списке.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем перестановка.

## Выходные данные

Номер, считая с 1; в нём может быть больше 150 цифр.

## Примеры

### Пример 1

Ввод:

```
4 
2 3 1 4
```

Вывод:

```
17
```

## Решение

Посмотрим только на элементы `1..k` и забудем о больших. Их взаимный
порядок меняется, только когда двигается `k` или меньший элемент, так что
список этих порядков — это тот же список для `k` элементов. В нём элемент
`k` делает один проход по `k` позициям на каждый порядок `1..k−1`, и
проходы чередуются: первый идёт с правого края влево, следующий слева
направо и так далее.

Значит, если `rank(k−1)` — номер порядка `1..k−1` с нуля, то порядок
`1..k` лежит в проходе номер `rank(k−1)` со сдвигом `s` внутри него, где
`s` — число меньших элементов слева от `k`, когда проход идёт вправо
(нечётные проходы), и `k − 1` минус это число, когда влево (чётные). Тогда
`rank(k) = rank(k−1)·k + s`, а ответ — `rank(N) + 1`. `O(N²)` на подсчёты
плюс шаги с длинными числами.

Тонкие места:

- направление зависит от чётности `rank(k−1)`, длинного числа, но нужна
  только его последняя цифра;
- программа начинает с элемента `k` у правого края, движущегося влево,
  поэтому влево идут чётные проходы;
- в `100!` 158 цифр, так что 64 бит далеко не хватает.

Ответы проверены прямым запуском выписывающей программы для каждой
перестановки при `N ≤ 6` и сверены с отдельно написанным решением на
случайных перестановках до 100 элементов.

## Особенности языков

- Python, Go и Java используют свои длинные целые; C++ и Rust хранят
  номер цифрами по основанию 10⁹ с одной операцией: умножить и прибавить
  небольшое число.
