# 1195. Кто выиграет недоигранную партию в крестики-нолики

[Timus 1195](https://acm.timus.ru/problem.aspx?space=1&num=1195) · сложность 260 · games

Авторы оригинальной задачи — Леонид Волков и Олег Кац; пятое командное первенство школьников по программированию, 2 марта 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На доске 3×3 для крестиков-ноликов ровно три крестика и три нолика, и ни
одна линия ещё не заполнена; крестики ходили первыми, значит, сейчас их
ход. Найти исход при наилучшей игре обеих сторон.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Три строки из `X`, `O` и `#` для пустой клетки.

## Выходные данные

`Crosses win`, `Ouths win` или `Draw`.

## Проверка

Сравниваются точные токены ответа, пробельное оформление несущественно.

## Решение

Свободны только три клетки, так что во всём дереве игры не больше
`3·2·1` вариантов. Его решает простой минимакс: ходящая сторона пробует
каждую пустую клетку; ход, заполняющий линию, выигрывает, иначе исход
противоположен лучшему исходу соперника из полученной позиции; полная
доска — ничья. `O(1)`.

Тонкие места:

- ходят всегда крестики, потому что обе стороны сделали по три хода;
- проверять заполненную линию нужно для только что поставленного знака, а
  не для обоих;
- ответ для ноликов пишется `Ouths win`.

Ответы сверены с отдельно написанным решением на всех 1372 досках с тремя
крестиками, тремя ноликами и без заполненной линии.

## Оптимизированные решения

Сохраняются полный минимакс и восемь выигрышных линий. В легальном вводе по три крестика и нолика без готовой победы, свободны только три клетки: таблица всех досок не нужна. Перебираем ход; если он завершил линию, сразу получаем победу, иначе меняем знак результата соперника и выбираем максимум. Полная доска даёт ничью. Нативные версии с изменяемой доской восстанавливают клетку перед каждым ранним выходом. Python держит две девятибитные маски и маску свободных клеток с тем же деревом игры. Прямой небольшой ввод-вывод убирает тяжёлые сканеры и потоки. Поиск глубины три имеет O(1); новый Python независимо проверен на всех1372легальных досках с шестью знаками.
