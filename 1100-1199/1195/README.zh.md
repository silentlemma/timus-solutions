# 1195. 一盘没下完的井字棋谁会赢

[Timus 1195](https://acm.timus.ru/problem.aspx?space=1&num=1195) · 难度 260 · games

原题作者 Leonid Volkov 和 Oleg Kats，出自 2002 年 3 月 2 日第五届中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

3×3 的井字棋盘上恰有三个叉和三个圈，还没有任何一条线被连满；叉先走，所以现在
轮到叉。求双方都下得最好时的结果。

胜利线指同一行、同一列或两条对角线之一上的三个相同符号。

时间限制：1 秒。内存限制：64 MB。

## 输入

三行，由 `X`、`O` 和表示空格的 `#` 组成。

## 输出

`Crosses win`、`Ouths win` 或 `Draw`。

## 评测方式

仓库检查器要求一行答案，比较该行内的词元。行内空格会归一化，把单词移到另一行则不等价。允许答案为 `Crosses win`、`Ouths win`、`Draw`。

- `1195_games_optimized.cpp` (G++ 13.2 x64): 15个仓库测试; 1372个额外精确源码比较.

- `1195_games_optimized.java` (Java 1.8): 15个仓库测试; 1372个额外精确源码比较.

- `1195_games_optimized.py` (PyPy 3.10 x64): 15个仓库测试; 1372个额外精确源码比较.

## 解法

只剩三个空格，所以整棵博弈树至多有 `3·2·1` 种走法。普通的极小极大搜索即可：
轮到的一方尝试每个空格；连成一线的走法获胜，否则结果是对手从该局面出发的最佳
结果的反面；棋盘下满则为和棋。`O(1)`。

注意事项：

- 轮到的总是叉，因为双方都已各走三步；
- 判断连线时只需检查刚放下的那种棋子，不必检查两种；
- 圈获胜的答案拼作 `Ouths win`。

答案已在全部 1372 个有三个叉、三个圈且没有连成一线的棋盘上与另一份独立编写的
解答比对。

## 优化解法

`1195_games_optimized.java`. Java 保留相同的精确三层负极大搜索。两个九位掩码表示双方棋子，行、列及对角线掩码判断胜负，获胜走法立即返回。输入恰有三个空格，无需记忆化表。64 字节输入缓冲区替代逐次流读取，三种输出字符串保持不变。固定棋盘上的时间及辅助空间均为 O(1)。全部 1372 个合法六子局面均与独立棋盘求解器比较。

精确源码 Java 1.8 Accepted #11327339 为 0.093 s / 372 KB；2026-11-20 保存比较为时间 3/25、内存 2/25。低于 1024 KB 按统一时间标准通过，无独立第一名目标或标记。较早 #11309258 是独立历史指标对 0.109 s / 352 KB，其内存不可替换当前 372 KB。

- `1195_games_optimized.java`: 0.093 s / 372 KB; 保留教学基础版 `1195_games.java`: 0.109 s / 1544 KB.

`1195_games_optimized.rs`. 保留给定六步井字棋局面的 negamax。用两个九位掩码替代可变棋盘向量，以八个胜线掩码替代逐三格比较，找到获胜走法立即返回。不引入记忆化或新规则。E 个空格下最坏搜索 O(E!)、栈 O(E)，固定 3×3 有界。字节输入输出保留 Crosses/Draw/Ouths 的精确消息。

与 `1195_games.rs` 相比：时间 0.046 s → 0.015 s；内存 212 KB → 56 KB。

保留完整极小极大与八条获胜线。合法输入恰有三个X、三个O且尚无胜者，只余三格，无需所有棋盘查表。尝试合法落子，若成线立即获胜，否则取对手结果的相反数并最大化；满盘为和。原生可变棋盘在任何提前返回前恢复格子。Python用两个九位掩码及空格掩码，游戏树相同。直接小型I/O省去扫描/流开销。固定三层搜索为O(1)；新Python源码独立验证了全部1372个合法六子棋盘。

- `1195_games_optimized.cpp`: 0.015 s / 100 KB; 基础 `1195_games.cpp`: 0.015 s / 352 KB; 相对变化: 时间 -0.0%, 内存 -71.6%.

- `1195_games_optimized.py`: 0.125 s / 280 KB; 基础 `1195_games.py`: 0.078 s / 528 KB; 相对变化: 时间 +60.3%, 内存 -47.0%.
