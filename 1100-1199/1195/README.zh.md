# 1195. 一盘没下完的井字棋谁会赢

[Timus 1195](https://acm.timus.ru/problem.aspx?space=1&num=1195) · 难度 260 · games

原题作者 Leonid Volkov 和 Oleg Kats，出自 2002 年 3 月 2 日第五届中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

3×3 的井字棋盘上恰有三个叉和三个圈，还没有任何一条线被连满；叉先走，所以现在
轮到叉。求双方都下得最好时的结果。

时间限制：1 秒。内存限制：64 MB。

## 输入

三行，由 `X`、`O` 和表示空格的 `#` 组成。

## 输出

`Crosses win`、`Ouths win` 或 `Draw`。

## 解法

只剩三个空格，所以整棵博弈树至多有 `3·2·1` 种走法。普通的极小极大搜索即可：
轮到的一方尝试每个空格；连成一线的走法获胜，否则结果是对手从该局面出发的最佳
结果的反面；棋盘下满则为和棋。`O(1)`。

注意事项：

- 轮到的总是叉，因为双方都已各走三步；
- 判断连线时只需检查刚放下的那种棋子，不必检查两种；
- 圈获胜的答案拼作 `Ouths win`。

答案已在全部 1372 个有三个叉、三个圈且没有连成一线的棋盘上与另一份独立编写的
解答比对。

## 优化解法

保留完整极小极大与八条获胜线。合法输入恰有三个X、三个O且尚无胜者，只余三格，无需所有棋盘查表。尝试合法落子，若成线立即获胜，否则取对手结果的相反数并最大化；满盘为和。原生可变棋盘在任何提前返回前恢复格子。Python用两个九位掩码及空格掩码，游戏树相同。直接小型I/O省去扫描/流开销。固定三层搜索为O(1)；新Python源码独立验证了全部1372个合法六子棋盘。
