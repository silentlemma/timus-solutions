# 1119. Кратчайший путь по сетке с несколькими диагональными срезками

[Timus 1119](https://acm.timus.ru/problem.aspx?space=1&num=1119) · сложность 70 · dp

Автор оригинальной задачи — Леонид Волков; USU Open Collegiate Programming Contest, октябрь 2001 года, Junior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Сетка состоит из `N × M` квадратных кварталов (`0 < N, M ≤ 1000`) со
стороной 100 метров. Путь идёт от юго-западного угла квартала `(1, 1)` к
северо-восточному углу квартала `(N, M)` по улицам, только на север или
восток; `K ≤ 100` данных кварталов можно также пересечь по диагонали с
юго-запада на северо-восток. Найти длину кратчайшего пути, округлённую до
метра.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N M`, затем `K`, затем `K` строк `x y` с кварталами, которые можно
пересечь.

## Выходные данные

Кратчайшая длина в метрах, округлённая.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
3 2
3
1 1
3 2
1 2
```

Вывод:

```
383
```

## Решение

Путь идёт только на север и восток, поэтому используемые им диагонали
образуют цепочку кварталов, строго возрастающих по обеим координатам, и
любую такую цепочку можно пройти. Каждая диагональ заменяет две стороны
(200 м) на `100√2` м, поэтому лучший путь использует самую длинную
цепочку. Сортируем кварталы и находим самую длинную цепочку квадратичной
динамикой для наибольшей возрастающей подпоследовательности; при `L`
диагоналях длина равна `100·(N + M − 2L) + 100√2·L`. `O(K²)`.

Тонкие места:

- два квартала в одной строке или столбце нельзя использовать оба:
  цепочка должна строго возрастать по обеим координатам;
- кварталы во входе могут повторяться;
- длина никогда не оказывается ровно посередине между целыми, потому что
  `100√2·L` иррационально при `L > 0`, так что обычное округление
  безопасно.

Ответы проверены динамикой по всем `(N + 1)(M + 1)` перекрёсткам сетки,
куда попадают с запада, с юга или по диагонали, на всех тестах и 60
случайных сетках.
