# 1184. Самые длинные равные куски, на которые можно разрезать кабели

[Timus 1184](https://acm.timus.ru/problem.aspx?space=1&num=1184) · сложность 244 · binary_search

Авторы оригинальной задачи — Владимир Пинаев и Роман Елизаров; полуфинал ACM ICPC Северо-Восточной Европы 2001–2002.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `N ≤ 10000` кабелей длиной от 1 м до 100 км, заданных с точностью до
сантиметра. Найти наибольшую длину в целых сантиметрах, при которой из
кабелей можно нарезать не меньше `K ≤ 10000` кусков этой длины.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `K`, затем длины в метрах ровно с двумя знаками после запятой.

## Выходные данные

Длина в метрах с двумя знаками, `0.00`, если не подходит даже 1 см.

## Примеры

### Пример 1

Ввод:

```
4 11
8.02
7.43
4.57
5.39
```

Вывод:

```
2.00
```

## Решение

Работаем в сантиметрах: у длин ровно два знака после точки, так что,
убрав точку, получаем точные целые. Кабель длины `c` даёт `⌊c/L⌋` кусков
длины `L`, и это число только убывает с ростом `L`. Поэтому двоичным
поиском ищем наибольшее `L` с `Σ ⌊c/L⌋ ≥ K` между 0 и самым длинным
кабелем; если не хватает даже `L = 1`, ответ остаётся 0. `O(N log C)`.

Тонкие места:

- чтение длин как вещественных чисел может превратить `8.02` в
  `801.99…` сантиметра; разбор как текста этого избегает;
- `K` может превышать суммарную длину в сантиметрах, и тогда нужно
  вывести `0.00`, а не упасть;
- в выводе нужны два знака, так что `2` печатается как `2.00`.

Ответы сверены с отдельно написанным решением на 300 случайных наборах и
на всех тестах.

## Особенности языков

- Python, Go, Java и Rust убирают из каждой длины точку; C++ читает
  целую и дробную части как два целых числа.
