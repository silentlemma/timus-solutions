# 1108. Единичные дроби, оставляющие наименьший положительный остаток

[Timus 1108](https://acm.timus.ru/problem.aspx?space=1&num=1108) · сложность 252 · math

Автор оригинальной задачи — Pavlin Peev.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Выбрать натуральные `a_1 ≤ a_2 ≤ … ≤ a_N` (`1 ≤ N ≤ 18`) так, чтобы
`1 − (1/a_1 + … + 1/a_N)` было положительным и как можно меньшим.
Вывести их в этом порядке, по одному в строке.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

`a_1`, …, `a_N`, каждое в отдельной строке.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
2
3
```

## Решение

Берём каждую дробь жадно: наибольшую единичную дробь, после которой ещё
что-то остаётся. Получается последовательность Сильвестра `a_1 = 2`,
`a_{k+1} = a_k (a_k − 1) + 1`, и по индукции остаток после `k` членов
равен ровно `1 / (a_{k+1} − 1)`, так что следующая наибольшая допустимая
дробь — `1/a_{k+1}`. То, что жадный выбор ещё и наилучший при любом `N`,
— классический результат о египетских дробях (Curtiss, 1922).

Члены возводятся в квадрат на каждом шаге: у `a_18` около 26 700 цифр, а
весь вывод — около 53 000 символов, поэтому нужна длинная арифметика.
Одного умножения на член, `O(D²)` школьным способом для `D` цифр,
вполне достаточно.

Тонкие места:

- 64-битные целые переполняются уже на `a_8`;
- Python по умолчанию отказывается переводить в текст целые длиннее 4300
  цифр, а `a_16` уже длиннее;
- знаменатели нужно выводить полностью, без экспоненциальной записи и
  округления.

Ответы проверены перебором всех неубывающих знаменателей с точными
дробями для `N ≤ 4`, а для каждого `N` — проверкой точными дробями, что
остаток равен `1 / (a_1 ⋯ a_N)`, как и даёт жадное рассуждение.

## Особенности языков

- Go и Java используют `math/big` и `BigInteger`; собственным целым
  Python перед выводом нужен `sys.set_int_max_str_digits(0)`.
- C++ и Rust хранят число цифрами по основанию `10^9` и считают
  `a · (a − 1) + 1` школьным умножением.
