# 1108. Единичные дроби, оставляющие наименьший положительный остаток

[Timus 1108](https://acm.timus.ru/problem.aspx?space=1&num=1108) · сложность 252 · math

Автор оригинальной задачи — Pavlin Peev.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Выбрать натуральные `a_1 ≤ a_2 ≤ … ≤ a_N` (`1 ≤ N ≤ 18`) так, чтобы
`1 − (1/a_1 + … + 1/a_N)` было положительным и как можно меньшим.
Вывести их в этом порядке, по одному в строке.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`.

## Выходные данные

`a_1`, …, `a_N`, каждое в отдельной строке.

## Проверка

Сравниваются точные токены ответа, пробельное оформление несущественно.

- `1108_math_optimized.java` (Java 1.8): 11 тестов репозитория; 18 дополнительных сравнений точного исходника.

- `1108_math_optimized.py` (Python 3.12 x64): 11 тестов репозитория; 18 дополнительных сравнений точного исходника.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
2
3
```

## Решение

Берём каждую дробь жадно: наибольшую единичную дробь, после которой ещё
что-то остаётся. Получается последовательность Сильвестра `a_1 = 2`,
`a_{k+1} = a_k (a_k − 1) + 1`, и по индукции остаток после `k` членов
равен ровно `1 / (a_{k+1} − 1)`, так что следующая наибольшая допустимая
дробь — `1/a_{k+1}`. То, что жадный выбор ещё и наилучший при любом `N`,
— классический результат о египетских дробях (Curtiss, 1922).

Члены возводятся в квадрат на каждом шаге: у `a_18` около 26 700 цифр, а
весь вывод — около 53 000 символов, поэтому нужна длинная арифметика.
Одного умножения на член, `O(D²)` школьным способом для `D` цифр,
вполне достаточно.

Тонкие места:

- 64-битные целые переполняются уже на `a_8`;
- Python по умолчанию отказывается переводить в текст целые длиннее 4300
  цифр, а `a_16` уже длиннее;
- знаменатели нужно выводить полностью, без экспоненциальной записи и
  округления.

Ответы проверены перебором всех неубывающих знаменателей с точными
дробями для `N ≤ 4`, а для каждого `N` — проверкой точными дробями, что
остаток равен `1 / (a_1 ⋯ a_N)`, как и даёт жадное рассуждение.

## Оптимизированные решения

Сохранены пять понятных реализаций последовательности Сильвестра. Быстрые версии считают те же a[1]=2,a[k+1]=a[k]^2-a[k]+1 и не строят ненужный член после последнего вывода. Java хранит int-цифры по основанию 10000, симметрично возводит их в квадрат в long-накопителях, затем точно вычитает прежнее значение и добавляет единицу с переносами. При N <= 18, a[18]<2^131072<10^40960, достаточно 11000 блоков; даже максимальный коэффициент свёртки помещается в long. Четырёхзначные блоки выводятся потоком. Python сохраняет длинные целые, но рекурсивно делит десятичный вывод на преобразования максимум 1000 цифр, ниже обычного ограничения. Рациональная верхняя оценка log10(2) и точное сравнение со степенью десяти определяют ширину без полной конвертации. Каждая цифра выводится один раз. Безопасная оценка O(D²) времени и O(D) рабочих цифр. Независимо проверены все 18 префиксов. У Python разница времени в один тик не служит допуском: собственная экономия памяти превышает 30%.

- `1108_math_optimized.java`: 0.125 s / 516 KB; база `1108_math.java`: 0.187 s / 6508 KB; изменение относительно базы: время -33.2%, память -92.1%.
- `1108_math_optimized.py`: 0.015 s / 788 KB; база `1108_math.py`: 0.031 s / 1144 KB; изменение относительно базы: время -51.6%, память -31.1%.
