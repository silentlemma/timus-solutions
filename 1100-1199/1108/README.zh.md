# 1108. 留下最小正余量的单位分数

[Timus 1108](https://acm.timus.ru/problem.aspx?space=1&num=1108) · 难度 252 · math

原题作者 Pavlin Peev。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

选出正整数 `a_1 ≤ a_2 ≤ … ≤ a_N`（`1 ≤ N ≤ 18`），使 `1 − (1/a_1 + … + 1/a_N)` 为正且尽可能小。按此顺序输出它们，每行一个。

时间限制：2 秒。内存限制：64 MB。

## 输入

`N`。

## 输出

`a_1`，…，`a_N`，每个单独一行。

## 评测方式

输出按记号逐个比较；多余的空白字符无关紧要。

## 样例

### 样例 1

输入：

```
2
```

输出：

```
2
3
```

## 解法

每个分数都贪心地取：仍能留下余量的最大单位分数。这就得到 Sylvester 数列 `a_1 = 2`，`a_{k+1} = a_k (a_k − 1) + 1`；由归纳法，取
`k` 项后的余量恰为 `1 / (a_{k+1} − 1)`，所以下一个可取的最大分数是 `1/a_{k+1}`。贪心选择对每个 `N`
也是最优的，这是埃及分数的一个经典结论（Curtiss，1922）。

各项每一步都会平方：`a_18` 约有 26 700 位，整个输出约 53 000 个字符，所以需要大整数。每项做一次乘法，对 `D` 位数用竖式乘法为
`O(D²)`，足够快。

注意事项：

- 64 位整数在 `a_8` 处就已溢出；
- Python 默认拒绝把超过 4300 位的整数转换为文本，而 `a_16` 已经超过；
- 分母必须完整输出，不能用科学计数法或四舍五入。

答案经过验证：对 `N ≤ 4` 用精确分数枚举所有不减的分母进行比对；对每个 `N` 用精确分数验证余量等于 `1 / (a_1 ⋯ a_N)`，即贪心论证给出的值。

## 语言说明

- Go 和 Java 使用 `math/big` 和 `BigInteger`；Python 自带的整数在输出前需要 `sys.set_int_max_str_digits(0)`。
- C++ 和 Rust 以 `10^9` 为基数按位存储，并用竖式乘法计算 `a · (a − 1) + 1`。
