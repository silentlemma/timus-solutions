# 1108. 留下最小正余量的单位分数

[Timus 1108](https://acm.timus.ru/problem.aspx?space=1&num=1108) · 难度 252 · math

原题作者 Pavlin Peev。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

选出正整数 `a_1 ≤ a_2 ≤ … ≤ a_N`（`1 ≤ N ≤ 18`），使 `1 − (1/a_1 + … + 1/a_N)` 为正且尽可能小。按此顺序输出它们，每行一个。

时间限制：2 秒。内存限制：64 MB。

## 输入

`N`。

## 输出

`a_1`，…，`a_N`，每个单独一行。

## 评测方式

精确比较答案词元，空白排版无关。

- `1108_math_optimized.java` (Java 1.8): 11个仓库测试; 18个额外精确源码比较.

- `1108_math_optimized.py` (Python 3.12 x64): 11个仓库测试; 18个额外精确源码比较.

## 样例

### 样例 1

输入：

```
2
```

输出：

```
2
3
```

## 解法

每个分数都贪心地取：仍能留下余量的最大单位分数。这就得到 Sylvester 数列 `a_1 = 2`，`a_{k+1} = a_k (a_k − 1) + 1`；由归纳法，取
`k` 项后的余量恰为 `1 / (a_{k+1} − 1)`，所以下一个可取的最大分数是 `1/a_{k+1}`。贪心选择对每个 `N`
也是最优的，这是埃及分数的一个经典结论（Curtiss，1922）。

各项每一步都会平方：`a_18` 约有 26 700 位，整个输出约 53 000 个字符，所以需要大整数。每项做一次乘法，对 `D` 位数用竖式乘法为
`O(D²)`，足够快。

注意事项：

- 64 位整数在 `a_8` 处就已溢出；
- Python 默认拒绝把超过 4300 位的整数转换为文本，而 `a_16` 已经超过；
- 分母必须完整输出，不能用科学计数法或四舍五入。

答案经过验证：对 `N ≤ 4` 用精确分数枚举所有不减的分母进行比对；对每个 `N` 用精确分数验证余量等于 `1 / (a_1 ⋯ a_N)`，即贪心论证给出的值。

## 优化解法

保留五种易读Sylvester递推。快速版仍算a[1]=2、a[k+1]=a[k]^2-a[k]+1，最后输出后不生成无用下一项。Java用基数10000的int数字，对称学校式平方累加到long，再精确减旧值加一并进位。N<=18时a[18]<2^131072<10^40960，11000块足够，最大卷积系数也适合long。逐四位块输出，避免巨大十进制字符串。Python保留原生大整数，但递归拆分输出，每次转换至多1000位，低于普通转换上限。log10(2)的有理上界结合精确十次幂比较给出宽度，无需转换整个数。每位恰输出一次。保守界为O(D²)时间、O(D)工作数字。全部18个前缀独立验证。Python仅差一个时间刻度，不作为准入依据，实际内存减少超过30%。
