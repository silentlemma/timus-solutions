# 1116. Вычитание из кусочно-постоянной функции области определения другой

[Timus 1116](https://acm.timus.ru/problem.aspx?space=1&num=1116) · сложность 333 · two_pointers

Автор оригинальной задачи — Олег Кац; USU Open Collegiate Programming Contest, октябрь 2001 года, Junior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Кусочно-постоянная функция — это список непересекающихся полуоткрытых
интервалов `[A, B)` со значением `Y` на каждом, упорядоченный по `A`; у
двух соприкасающихся интервалов значения никогда не совпадают. Даны две
такие функции `F1` и `F2` (в каждой `1 ≤ N ≤ 15000` интервалов,
`|A|, |B| < 32000`, `A < B`, `|Y| ≤ 100`). Построить `F`: она равна `F1`
там, где `F1` определена, а `F2` нет, и не определена во всех остальных
точках.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Две строки, по одной на функцию: `N`, затем `N` троек `A B Y`.

## Выходные данные

Одна строка в том же формате, описывающая `F`; одно число `0`, если `F`
нигде не определена.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
3 -1 1 2 1 3 4 4 6 3
2 -2 2 1 5 7 5
```

Вывод:

```
2 2 3 4 4 5 3
```

## Решение

Оба списка упорядочены, поэтому достаточно одного прохода двумя
указателями. Для каждого интервала `[A, B)` функции `F1` ведём курсор от
`A` до `B`: пропускаем интервалы `F2`, которые кончаются не правее
курсора; если следующий уже накрывает курсор, переносим курсор на его
конец; иначе выводим кусок от курсора до начала этого интервала (или до
`B`) со значением `Y`. Указатель в `F2` никогда не движется назад, так что
весь проход занимает `O(N1 + N2)`.

Куски не нужно склеивать: куски одного интервала разделены дырами, а
куски двух разных интервалов могут соприкасаться только там, где
соприкасались сами интервалы, а у них разные значения.

Тонкие места:

- интервалы полуоткрытые: `[0, 2)` и `[2, 4)` соприкасаются, но не
  пересекаются, поэтому интервал `F2`, кончающийся в `x`, не накрывает `x`;
- интервал `F2` может покрывать несколько интервалов `F1`, поэтому его
  указатель нельзя сдвигать только оттого, что интервал `F1` закончился;
- если ничего не осталось, ответ — одно число `0`.

Ответы проверены перебором, который вычисляет обе функции на каждой
единичной клетке диапазона координат и склеивает отрезки равных значений
обратно в интервалы, на всех тестах и 100 случайных парах.

## Оптимизированные решения

Версии C++ и Go хранят каждый интервал как три знаковых 16-битных числа. Первый список остаётся в памяти, а второй читается по мере надобности, и от него хранится только текущий вычитаемый интервал. Каждый вычитаемый интервал читается не более одного раза. Результат собирается в компактный массив, потому что сначала нужно вывести число интервалов. Время O(N1 + N2).

Принятая версия G++ 13.2 x64 заняла 0.062 с при 0.046 с у базовой и использовала 444 KB при 1880 KB у базовой.

Принятые базовые реализации [1116_two_pointers.java](1116_two_pointers.java), [1116_two_pointers.py](1116_two_pointers.py), [1116_two_pointers.rs](1116_two_pointers.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.

## Особенности языков

Эти замечания относятся к базовым реализациям.

- Во всех языках один и тот же проход; Go буферизует запись, остальные
  собирают строку вывода.
