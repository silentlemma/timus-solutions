# 1116. 从分段常数函数中去掉另一个函数的定义域

[Timus 1116](https://acm.timus.ru/problem.aspx?space=1&num=1116) · 难度 333 · two_pointers

原题作者 Oleg Kats，出自 2001 年 10 月 USU Open Collegiate Programming Contest（Junior Session）。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

分段常数函数是一列互不相交的半开区间 `[A, B)`，每个区间上取值 `Y`，按 `A` 排序；两个相接的区间取值从不相同。给定两个这样的函数 `F1` 和
`F2`（各有 `1 ≤ N ≤ 15000` 个区间，`|A|, |B| < 32000`，`A < B`，`|Y| ≤ 100`），构造 `F`：在 `F1` 有定义而
`F2` 无定义的地方它等于 `F1`，其余地方都无定义。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

两行，每行一个函数：`N`，然后是 `N` 个三元组 `A B Y`。

## 输出

用同样格式描述 `F` 的一行；若 `F` 处处无定义，只输出 `0`。

## 评测方式

输出按记号逐个比较；多余的空白字符无关紧要。

## 样例

### 样例 1

输入：

```
3 -1 1 2 1 3 4 4 6 3
2 -2 2 1 5 7 5
```

输出：

```
2 2 3 4 4 5 3
```

## 解法

两个列表都已排序，所以用双指针扫一遍就够了。对 `F1` 的每个区间 `[A, B)`，让游标从 `A` 走到 `B`：跳过 `F2`
中结束于游标处或之前的区间；如果下一个区间已经覆盖游标，就把游标移到它的终点；否则输出从游标到该区间起点（或到 `B`）的一段，取值为
`Y`。指向 `F2` 的指针从不后退，所以整个扫描是 `O(N1 + N2)`。

各段无需合并：同一区间切出的段之间隔着空洞，而两个不同区间切出的段只能在原区间相接处相接，而那些区间取值不同。

注意事项：

- 区间是半开的：`[0, 2)` 和 `[2, 4)` 相接但不重叠，所以结束于 `x` 的 `F2` 区间不覆盖 `x`；
- `F2` 的一个区间可能跨越 `F1` 的多个区间，所以不能仅因为 `F1` 的一个区间处理完就移动它的指针；
- 若什么都不剩，答案就是单独一个 `0`。

答案经过验证：与一个暴力程序比对，它在坐标范围内的每个单位格上计算两个函数，再把取值相同的连续格合并回区间；覆盖所有测试和 100 组随机数据。

## 优化解法

C++ 和 Go 版本用三个有符号 16 位整数表示每个区间。保存第一张列表，按需读取第二张列表，只保留当前用于扣除的区间。每个用于扣除的区间最多读取一次。由于必须先输出结果区间的个数，先把结果收集到紧凑的数组中。时间 O(N1 + N2)。

通过评测的 G++ 13.2 x64 版本耗时 0.062 秒，基础版为 0.046 秒，内存为 444 KB，基础版为 1880 KB。

已通过评测的基础实现 [1116_two_pointers.java](1116_two_pointers.java), [1116_two_pointers.py](1116_two_pointers.py), [1116_two_pointers.rs](1116_two_pointers.rs) 也满足快速版本的要求：在保存的比较快照中，时间和内存均符合前 15% 或前十名的排名收录规则。直接复用这些源文件，不创建相同副本。星号标记尚未达到该语言目标排名的版本。
