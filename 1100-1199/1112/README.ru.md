# 1112. Как можно больше отрезков без общих внутренних точек

[Timus 1112](https://acm.timus.ru/problem.aspx?space=1&num=1112) · сложность 165 · greedy

Оригинальная задача — Болгарская национальная олимпиада по информатике, второй день.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На прямой даны `N` отрезков (`1 ≤ N ≤ 99`), отрезок `i` — от `A_i` до
`B_i`, целые `−999 ≤ A_i < B_i ≤ 999`. Убрать как можно меньше отрезков
так, чтобы никакие два оставшихся не имели общей внутренней точки; концы
могут касаться. Вывести оставшиеся отрезки.

Ограничение времени: 0,5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` строк `A_i B_i`.

## Выходные данные

Число `P` оставленных отрезков, затем `P` строк `A B` по возрастанию левых
концов. Подходит любой оптимальный ответ.

## Проверка

Подходит любой оптимальный ответ. Проверяющая программа находит
наибольшее возможное число отрезков квадратичной динамикой и убеждается,
что вывод оставляет столько же, берёт их из входа, перечисляет по левым
концам и не содержит двух перекрывающихся.

## Примеры

### Пример 1

Ввод:

```
3
3 6
1 3
2 5
```

Вывод:

```
2
1 3
3 6
```

## Решение

Это задача о выборе заявок. Отсортируем отрезки по правым концам и будем
брать каждый, который начинается не раньше правого конца последнего
взятого. Отрезок, который кончается первым, всегда входит в какой-то
оптимальный ответ: в любом оптимальном наборе отрезок с самым левым
правым концом можно заменить на него, не создав перекрытия. Повторяя
рассуждение для остальных, получаем правильность жадного выбора.
Оставленные отрезки не пересекаются, поэтому их порядок по правым концам
совпадает с порядком по левым. `O(N log N)`.

Тонкие места:

- касающиеся отрезки (один кончается там, где начинается следующий) не
  имеют общей внутренней точки и могут остаться оба;
- сортировка по левому концу или по длине с жадным выбором даёт неверные
  ответы: длинный отрезок, начинающийся первым, может закрыть несколько
  коротких;
- отрезки могут повторяться; каждая копия — отдельный отрезок, но остаться
  может не больше одной.

Ответы проверены проверяющей программой на всех тестах и на 150 случайных
наборах, в том числе с цепочками касающихся, повторяющимися и вложенными
отрезками.
