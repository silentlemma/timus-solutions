# 1112. 保留尽可能多且没有公共内点的线段

[Timus 1112](https://acm.timus.ru/problem.aspx?space=1&num=1112) · 难度 165 · greedy

原题出自保加利亚全国信息学奥林匹克竞赛第二天。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

直线上有 `N` 条线段（`1 ≤ N ≤ 99`），第 `i` 条从 `A_i` 到 `B_i`，均为整数且 `−999 ≤ A_i < B_i ≤ 999`。删去尽可能少的线段，使剩下的任意两条都没有公共内点；端点可以相接。输出剩下的线段。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

`N`，然后是 `N` 行 `A_i B_i`。

## 输出

保留的线段数 `P`，然后按左端点递增顺序输出 `P` 行 `A B`。接受任何一个最优答案。

## 评测方式

接受任何一个最优答案。检查程序用平方复杂度的动态规划求出最多能保留的线段数，并验证输出保留了这么多条、都取自输入、按左端点排列，且没有两条重叠。

## 样例

### 样例 1

输入：

```
3
3 6
1 3
2 5
```

输出：

```
2
1 3
3 6
```

## 解法

这是活动选择问题。把线段按右端点排序，依次取每一条起点不早于上一条已取线段右端点的线段。最先结束的线段总在某个最优答案中：在任意最优集合里，右端点最靠左的那条线段可以换成它而不产生重叠。对其余线段重复这个论证，就证明了贪心的正确性。保留的线段互不重叠，所以按右端点的顺序也就是按左端点的顺序。
`O(N log N)`。

注意事项：

- 相接的线段（一条在另一条起点处结束）没有公共内点，可以同时保留；
- 按左端点或长度排序再贪心会得到错误答案：最先开始的长线段可能挡住好几条短线段；
- 线段可能重复；每个副本都是单独的线段，但最多只能保留其中一条。

答案在所有测试以及 150 组随机数据（包括相接的链、重复的和嵌套的线段）上都用检查程序验证过。
