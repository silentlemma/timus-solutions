# 1118. Число с наименьшей суммой собственных делителей на единицу

[Timus 1118](https://acm.timus.ru/problem.aspx?space=1&num=1118) · сложность 103 · number_theory

Автор оригинальной задачи — Леонид Волков; USU Open Collegiate Programming Contest, октябрь 2001 года, Junior Session.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Отношение натурального числа `N` — это сумма его собственных делителей
(меньших `N`), делённая на `N`. Для `1 ≤ I ≤ J ≤ 10^6` вывести число из
`[I, J]` с наименьшим отношением.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

`I J` в одной строке.

## Выходные данные

Число с наименьшим отношением.

## Проверка

Вывод сравнивается по токенам; лишние пробельные символы не важны.

## Примеры

### Пример 1

Ввод:

```
24 28
```

Вывод:

```
25
```

## Решение

У числа 1 нет собственных делителей, отношение 0, и оно побеждает при
`I = 1`. У простого `p` отношение `1/p`, поэтому среди простых лучше всех
наибольшее. Оно же обгоняет любое составное `n ≤ J` из диапазона: у
составного есть делитель `d ≥ √n` кроме 1, так что его отношение не меньше
`(1 + √n)/n`, а наибольшее простое не больше `J` превышает `J/2`
(постулат Бертрана), отчего `1/p` меньше. Значит, идём вниз от `J` и
останавливаемся на первом простом.

Сравнивать отношения нужно, только когда в диапазоне вовсе нет простых;
такой диапазон лежит внутри промежутка между простыми, не больше 113 чисел
до `10^6`. Каждая сумма делителей находится за `O(√n)` перебором, а два
отношения сравниваются точно как `σ(a)·b < σ(b)·a`, при равенстве
побеждает меньшее число. Всего `O(g · √J)` для наибольшего промежутка `g`.

Тонкие места:

- при `I = 1` ответ 1, а не наибольшее простое;
- в диапазоне без простых лучшее число не обязательно наибольшее и не
  обязательно квадрат: `[24, 28]` даёт 25, `[8, 10]` даёт 9;
- сравнивать отношения в плавающей точке незачем, перекрёстное
  произведение помещается в 64 бита.

Ответы проверены решетом сумм делителей всех чисел до `10^6` с точным
сравнением по всему диапазону — на всех тестах, на 200 случайных
диапазонах меньше 3000 и на самом длинном промежутке между простыми до
миллиона.
