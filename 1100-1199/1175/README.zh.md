# 1175. 二阶递推从何处开始重复及其周期

[Timus 1175](https://acm.timus.ru/problem.aspx?space=1&num=1175) · 难度 946 · math

原题作者 Alexander Klepinin，出自 2002 年 2 月 16 日在叶卡捷琳堡举行的第三届乌拉尔国立大学个人程序设计竞赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

数列以 `X1`、`X2` 开始，之后每一项是 `F(Xn−1, Xn)`：取
`H = A1·X·Y + A2·X + A3·Y + A4`，若 `H > B1`，则不断减去 `C` 直到 `H ≤ B2`。
所有 `H` 都在 `0..100000` 内。求最小的 `p` 和 `q`，使得对所有 `n ≥ 0` 有
`Xp+n = Xp+q+n`。

时间限制：1 秒。内存限制：2 MB。

## 输入

`A1 A2 A3 A4 B1 B2 C`，然后是 `X1 X2`。

## 输出

`p` 和 `q`。

## 样例

### 样例 1

输入：

```
0 0 2 3 20 5 7
0 1
```

输出：

```
2 3
```

## 解法

下一项只取决于前两项，所以数对 `(Xn, Xn+1)` 自行演化，而数列从 `p` 起以周期
`q` 重复当且仅当数对如此。数对在有限集合中行走，因此会进入一个环：`p` 是环上
第一个数对的下标，`q` 是环长。

内存只有 2 MB，无法保存数对，所以用 Brent 方法找环。慢指针停在 2 的幂次步处，
快指针向前走；当快指针遇到慢指针时，自上次跳跃以来走过的距离就是环长 `q`。
然后两个指针从头出发，其中一个先走 `q` 步，再一起前进；它们第一次相遇的位置就是
环的起点，由此得到 `p`。共 `O(p + q)` 步，`O(1)` 内存。

反复减法用一次除法代替：当 `H > B1` 且 `H > B2` 时，减去 `C` 乘以
`⌈(H − B2) / C⌉`。

注意事项：

- `p` 从 1 开始计数，是数对第一项的下标；
- 环可能很长，例如斐波那契数模 31250 的周期是 187,500，保存数对会超出内存
  限制；
- 若 `B1 < H ≤ B2`，什么也不减。

答案已在 300 组随机参数上与用字典保存数对的直接搜索比对，并在所有测试上与另一份
独立编写的解答比对。
