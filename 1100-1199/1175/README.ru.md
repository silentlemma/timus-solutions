# 1175. С какого места двучленная рекуррента начинает повторяться и её период

[Timus 1175](https://acm.timus.ru/problem.aspx?space=1&num=1175) · сложность 946 · math

Автор оригинальной задачи — Александр Клепинин; третье личное первенство УрГУ по программированию, Екатеринбург, 16 февраля 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Последовательность начинается с `X1`, `X2`, а каждый следующий член равен
`F(Xn−1, Xn)`: берётся `H = A1·X·Y + A2·X + A3·Y + A4`, и если `H > B1`,
из `H` вычитается `C`, пока не станет `H ≤ B2`. Все `H` лежат в
`0..100000`. Найти наименьшие `p` и `q`, при которых `Xp+n = Xp+q+n` для
всех `n ≥ 0`.

Ограничение времени: 1 секунда. Ограничение памяти: 2 МБ.

## Входные данные

`A1 A2 A3 A4 B1 B2 C`, затем `X1 X2`.

## Выходные данные

`p` и `q`.

## Примеры

### Пример 1

Ввод:

```
0 0 2 3 20 5 7
0 1
```

Вывод:

```
2 3
```

## Решение

Следующий член зависит от двух последних, так что пара `(Xn, Xn+1)`
меняется сама по себе, а члены повторяются с места `p` с периодом `q`
ровно тогда, когда повторяются пары. Пары гуляют по конечному множеству,
поэтому попадают в цикл: `p` — номер первой пары на нём, `q` — его длина.

При 2 МБ памяти пары хранить нельзя, поэтому цикл ищется методом Брента.
Медленный указатель ждёт на шаге, равном степени двойки, пока быстрый
уходит вперёд; когда быстрый его встречает, пройденное после последнего
прыжка расстояние и есть длина цикла `q`. Затем два указателя стартуют с
начала, один на `q` шагов впереди, и идут вместе; впервые они встречаются
в начале цикла, что даёт `p`. `O(p + q)` шагов и `O(1)` памяти.

Цикл вычитаний заменяется одним делением: при `H > B1` и `H > B2`
вычитаем `C`, умноженное на `⌈(H − B2) / C⌉`.

Тонкие места:

- `p` считается с 1 — это номер первого члена пары;
- цикл бывает длинным, например у чисел Фибоначчи по модулю 31250 период
  187 500, так что хранение пар нарушило бы ограничение памяти;
- если `B1 < H ≤ B2`, ничего не вычитается.

Ответы сверены с прямым поиском, хранящим пары в словаре, на 300
случайных наборах параметров и с отдельно написанным решением на всех
тестах.
