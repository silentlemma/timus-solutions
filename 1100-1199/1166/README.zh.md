# 1166. 一名玩家能否出完全部手牌而不让对手出牌

[Timus 1166](https://acm.timus.ru/problem.aspx?space=1&num=1166) · 难度 3552 · games

原题作者 Andrew Lopatine，出自 2001 年 ACM ICPC 东北欧区域赛北部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一种用 54 张牌（含两张王）进行的纸牌游戏只剩两名玩家。每张打出的牌都必须用
同花色或同点数的牌盖住；对于皇后，只认打出时宣布的花色。打出 6、7、A 或黑桃 K
之后，对手跳过这一轮，于是同一名玩家再次出牌，盖住自己的牌。王可以当作持有者
指定的任意一张牌打出。给定第一名玩家的手牌（他不能再摸牌）和桌上翻开的牌，判断
他能否一张接一张地打出全部手牌而让对手一次也出不了牌；若能，输出这样的顺序。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行是手牌，每张两个字符（`T` 表示 10，`*` 表示王），然后是翻开的牌；若是
皇后，后面跟着宣布的花色；若是王，后面跟着它所代表的牌。

## 输出

`YES` 和出牌顺序（每张打出的王后面跟它代表的牌，每张皇后后面跟宣布的花色），
或者 `NO`。

## 评测方式

只要顺序恰好打出全部手牌、每张牌都盖住前一张、除最后一张外每张牌都让对手跳过，
并且皇后和王都写完整，就被接受。`YES` 或 `NO` 以保存的答案为准。

## 样例

### 样例 1

输入：

```
6C QD 6S KS 7S *
*QHS
```

输出：

```
YES
7S KS 6S 6C *6D QDS
```

## 解法

除了十三张让对手跳过的牌（每种花色的 6、7、A 以及黑桃 K）以外，打出任何牌后
对手都会出牌。所以除最后一张外，每张牌都必须是这十三张之一，可以是真牌，也
可以是被指定为它们的王。手里有两张其他牌就直接是 `NO`，只有一张其他牌时它必须
最后打出。

剩下的就是一条从翻开的牌出发、经过全部手牌的路径，每张牌盖住前一张。状态是：
哪些真的跳过牌已经打出（至多 `2^13` 种集合）、用了几张王（王都一样，只有数量
有关）以及最上面的牌——十三张之一或翻开的牌。深度优先搜索记住失败过的状态，
所有牌打完时返回顺序。只剩一张牌时，检查它能否盖住顶牌：有其他牌时就是它，否则
是最后一张跳过牌；最后一张若是王，总可以指定为与顶牌同花色的 2。最坏
`O(2^13·3·14·26)`。

注意事项：

- 桌上的皇后只能用宣布的花色盖住，即使用另一张皇后也一样；
- 桌上的王按它被指定的牌计算；
- 8 或皇后会让对手出牌，所以只能放在最后；
- 打出的皇后在输出中必须带上宣布的花色，即使是最后一张。

答案已在 495 个随机牌局上与另一份独立编写的解答比对，输出的每个顺序都通过了
检查程序。
