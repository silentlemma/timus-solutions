# 1153. 由最多 600 位的和 1 + 2 + … + N 还原 N

[Timus 1153](https://acm.timus.ru/problem.aspx?space=1&num=1153) · 难度 336 · math

原题作者 Evgeny Bryzgalov，出自 2001 年 4 月在彼尔姆举行的乌拉尔团体程序设计锦标赛英语轮。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一台计算机把 1 到 `N`（`0 < N < 10³⁰⁰`）的整数相加并输出和 `S`，但 `N` 丢失
了。已知 `S`（它总是这样的和），求 `N`。

时间限制：1 秒。内存限制：64 MB。

## 输入

`S`。

## 输出

`N`。

## 样例

### 样例 1

输入：

```
28
```

输出：

```
7
```

## 解法

`S = N(N + 1)/2`，所以 `8S + 1 = 4N² + 4N + 1 = (2N + 1)²` 是完全平方数，
`N = (√(8S + 1) − 1) / 2`。唯一的困难在于规模：`S` 最多 600 位，开方需要
大整数。

学校里学的竖式开方逐位进行，只需要乘以小数、加法、比较和减法。把 `8S + 1`
从右往左每两位分成一组。记录已求出的根 `r` 和余数。对每一组，把它接到余数
后面（乘以 100 再加上），然后找出使 `(20r + x)·x` 不超过余数的最大数字 `x`，
减去这个乘积，并把 `x` 接到根后面。处理完最后一组后，根就是 `2N + 1`；减一
后从最高位开始除以 2。约 300 组、每组最多试九次、数字长 600 位，总共只有
几百万次数字运算。

注意事项：

- `S` 和 `N` 都放不进任何机器整数；
- `8S + 1` 的位数可能是奇数，前面补一个零就能对齐分组；
- `N = 1` 时 `S = 1`，`9` 的平方根是 `3`。

答案已在所有测试上用 Python 整数反算 `N(N + 1)/2` 验证。

## 各语言说明

- Python 对内置整数使用 `math.isqrt`，Go 使用 `big.Int.Sqrt`。
- Java 8 没有 `BigInteger.sqrt`，所以用牛顿法 `x ← (x + D/x)/2`，从大于根的
  2 的幂开始。
- C++ 和 Rust 的标准库没有大整数，因此对十进制数字做竖式开方。
