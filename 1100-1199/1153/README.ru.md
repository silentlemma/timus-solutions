# 1153. Восстановление N по сумме 1 + 2 + … + N длиной до 600 цифр

## Задача

Компьютер сложил целые числа от 1 до `N`, `0 < N < 10³⁰⁰`, и выдал сумму
`S`, но `N` потеряно. По `S`, которое всегда является такой суммой, найти
`N`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`S`.

## Выходные данные

`N`.

## Примеры

### Пример 1

Ввод:

```
28
```

Вывод:

```
7
```

## Решение

`S = N(N + 1)/2`, поэтому `8S + 1 = 4N² + 4N + 1 = (2N + 1)²` — точный
квадрат, и `N = (√(8S + 1) − 1) / 2`. Трудность только в размере: в `S`
до 600 цифр, так что корень требует длинной арифметики.

Школьный способ извлечения корня столбиком идёт цифра за цифрой и требует
только умножения на малые числа, сложения, сравнения и вычитания.
Разобьём `8S + 1` на пары цифр справа. Храним уже найденную часть корня
`r` и остаток. Для каждой следующей пары приписываем её к остатку
(умножаем на 100 и прибавляем), затем находим наибольшую цифру `x`, при
которой `(20r + x)·x` не больше остатка, вычитаем это произведение и
приписываем `x` к корню. После последней пары корень равен `2N + 1`;
вычитаем единицу и делим пополам, начиная со старшей цифры. При примерно
300 парах и не больше девяти попыток на каждую над числами из 600 цифр
это несколько миллионов действий с цифрами.

Тонкие места:

- ни `S`, ни `N` не помещаются ни в какое машинное целое;
- у `8S + 1` может быть нечётное число цифр; ведущий ноль выравнивает пары;
- `N = 1` даёт `S = 1`, а корень из `9` равен `3`.

Ответы проверены на всех тестах обратным вычислением `N(N + 1)/2` в целых
числах Python.

## Особенности языков

- Python использует `math.isqrt` на встроенных целых, а Go — `big.Int.Sqrt`.
- В Java 8 нет `BigInteger.sqrt`, поэтому там работает метод Ньютона,
  `x ← (x + D/x)/2`, начиная со степени двойки выше корня.
- В стандартных библиотеках C++ и Rust нет длинных целых, и там корень
  извлекается столбиком по десятичным цифрам.
