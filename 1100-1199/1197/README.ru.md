# 1197. Сколько клеток бьёт одинокий конь

[Timus 1197](https://acm.timus.ru/problem.aspx?space=1&num=1197) · сложность 28 · implementation

Оригинальная задача — фольклор; пятое командное первенство школьников по программированию, 2 марта 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На шахматной доске стоит один конь. Для каждой из `N ≤ 64` заданных
клеток посчитать, сколько клеток доски конь бьёт оттуда.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` клеток в шахматной записи: буква от `a` до `h` — вертикаль,
цифра от `1` до `8` — горизонталь.

## Выходные данные

Для каждой клетки — число клеток под боем, в отдельной строке.

## Примеры

### Пример 1

Ввод:

```
3
a1
d4
g6
```

Вывод:

```
2
8
6
```

## Решение

У коня восемь возможных прыжков: на две клетки в одну сторону и на одну
поперёк. Перебираем все восемь и считаем те, что остаются на доске.
`O(N)`.

Тонкие места:

- у края или в углу на доске остаётся только часть прыжков, поэтому у
  каждого прыжка проверяются обе координаты;
- буква — это столбец, а цифра — строка, но доска симметрична, так что
  перепутать их не страшно.

Ответы сверены с отдельно написанным решением на всех 64 клетках.

## Оптимизированные решения

`1197_implementation_optimized.java`. Java считает те же восемь ходов коня, вынося независимые варианты по осям. Пусть oneX/twoX — числа допустимых горизонтальных сдвигов на один/два поля, oneY/twoY определяются аналогично. Ответ oneX*twoY+twoX*oneY; две формы хода не пересекаются. Убраны цикл по ходам и двумерные массивы, таблицы ответов для доски нет. Координаты читаются напрямую из буфера на 256 байт. Ответ однозначный, поэтому массив вывода содержит ровно 2*N байт с переводами строк. Время O(N), хранение ответа O(N), остальное состояние фиксировано. Учебный перебор ходов сохранён.

Accepted точного исходника Java 1.8 №11327340: 0.078 с / 192 КБ. Сохранённое сравнение компиляторов от 2026-11-20: время 82/745, память 1/745. При памяти меньше 1024 КБ строгий допуск учитывает только время: первые десять мест или топ 15%, равенства делят место, процентный порог округляется вверх. Звёздочка остаётся для отдельной цели языка: первого места по обеим метрикам. Прежний документированный оптимизированный запуск №11303722: 0.109 с / 296 КБ; это отдельная историческая пара, не текущий замер данного исходника. Учебные версии сохранены без изменений.

- `1197_implementation_optimized.java`: 0.078 s / 192 KB; сохранённая учебная база `1197_implementation.java`: 0.093 s / 1576 KB.

Оптимизированное решение на C++ читает через `getchar` вместо `iostream`
и считает прыжки без таблицы. Прыжок сдвигает одну координату на 1, а
другую на 2, каждую в любую сторону, и выбор для двух координат
независим; поэтому ответ равен
`ways(x, 1) · ways(y, 2) + ways(x, 2) · ways(y, 1)`, где `ways(p, s)` —
сколько из `p - s` и `p + s` остаются на доске. Решению нужно 84 КБ
вместо 396 КБ при том же времени.

## Особенности языков

- В простых решениях восемь прыжков лежат в таблице, по которой идёт цикл.

Читаем каждую координату в двухбайтовый массив и выводим число ходов через буфер байтов. Принятая посылка 11301829 заняла 0,001 с и использовала 908 КБ. Простая версия заняла 0,015 с и использовала 1072 КБ.

Берём число ходов из таблицы фиксированной доски, которую 1197_math_table.py строит по допустимым прыжкам коня. Читаем входные байты напрямую и сбрасываем ответы перед os._exit(0), пропуская очистку интерпретатора. Принятая посылка 11324662 заняла 0,093 с и использовала 200 КБ. Простая версия заняла 0,046 с и использовала 328 КБ. Зафиксированное время выше, чем у простой версии.
