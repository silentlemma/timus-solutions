# 1197. Сколько клеток бьёт одинокий конь

[Timus 1197](https://acm.timus.ru/problem.aspx?space=1&num=1197) · сложность 28 · implementation

Оригинальная задача — фольклор; пятое командное первенство школьников по программированию, 2 марта 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На шахматной доске стоит один конь. Для каждой из `N ≤ 64` заданных
клеток посчитать, сколько клеток доски конь бьёт оттуда.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N`, затем `N` клеток в шахматной записи: буква от `a` до `h` — вертикаль,
цифра от `1` до `8` — горизонталь.

## Выходные данные

Для каждой клетки — число клеток под боем, в отдельной строке.

## Примеры

### Пример 1

Ввод:

```
3
a1
d4
g6
```

Вывод:

```
2
8
6
```

## Решение

У коня восемь возможных прыжков: на две клетки в одну сторону и на одну
поперёк. Перебираем все восемь и считаем те, что остаются на доске.
`O(N)`.

Тонкие места:

- у края или в углу на доске остаётся только часть прыжков, поэтому у
  каждого прыжка проверяются обе координаты;
- буква — это столбец, а цифра — строка, но доска симметрична, так что
  перепутать их не страшно.

Ответы сверены с отдельно написанным решением на всех 64 клетках.

## Оптимизированные решения

Оптимизированное решение на C++ читает через `getchar` вместо `iostream`
и считает прыжки без таблицы. Прыжок сдвигает одну координату на 1, а
другую на 2, каждую в любую сторону, и выбор для двух координат
независим; поэтому ответ равен
`ways(x, 1) · ways(y, 2) + ways(x, 2) · ways(y, 1)`, где `ways(p, s)` —
сколько из `p - s` и `p + s` остаются на доске. Решению нужно 84 КБ
вместо 396 КБ при том же времени.

Оптимизированное решение на Java читает числа и клетки побайтно из
`System.in` вместо `Scanner`, а поскольку каждый ответ — одна цифра,
пишет по два байта на клетку в один массив: 296 КБ вместо 1576 КБ при
том же времени.

## Особенности языков

- В простых решениях восемь прыжков лежат в таблице, по которой идёт цикл.
