# 1163. Кто победит в игре, где шашки щелчком сбивают с доски

[Timus 1163](https://acm.timus.ru/problem.aspx?space=1&num=1163) · сложность 3932 · games

Автор оригинальной задачи — Николай Дуров; северный подрегион полуфинала ACM ICPC Северо-Восточной Европы 2001.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Восемь красных и восемь белых шашек, кружков радиуса `0.4`, стоят на
доске `8×8`, не касаясь друг друга. Игроки ходят по очереди, первыми
красные. Ход — выбрать шашку своего цвета и щелчком пустить её в любом
направлении: она едет по прямой, пока не упадёт с доски, и все шашки,
которых она коснулась по пути, снимаются. Игрок, у которого к его ходу не
осталось шашек, проигрывает. Определить победителя при оптимальной игре.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Две строки по восемь пар координат: центры красных шашек, затем белых.

## Выходные данные

`RED` или `WHITE`.

## Примеры

### Пример 1

Ввод:

```
0.5 7.5 1.5 7.5 2.5 7.5 3.5 7.5 4.5 7.5 5.5 7.5 6.5 7.5 7.5 7.5
0.5 0.5 1.5 0.5 2.5 0.5 3.5 0.5 4.5 0.5 5.5 0.5 6.5 0.5 7.5 0.5
```

Вывод:

```
RED
```

## Решение

Движущаяся шашка заметает полосу: другая шашка сбита ровно тогда, когда
её центр впереди точки старта и не дальше `0.8`, двух радиусов, от линии
движения. Шашку позади старта задеть нельзя: шашки стоят дальше `0.8` друг
от друга, а расстояние только растёт.

При повороте направления шашка на расстоянии `d` сбивается внутри дуги
направлений, ограниченной двумя касательными углами
`atan2 ± asin(0.8/d)`. Значит, множество сбитых шашек меняется только на
этих углах. Если перебрать каждый касательный угол, где касание ещё
считается, и середину каждого промежутка между соседними углами, получатся
все возможные множества: не больше 60 на шашку, а после удаления повторов
меньше.

Состояние игры — множество оставшихся шашек и чей ход, всего `2^17`
состояний. Ход снимает саму движущуюся шашку и всё, что она сбила, так что
любая партия кончается за 16 ходов. Поиск с запоминанием считает
состояние выигрышным, если какой-то ход ведёт в проигрышное для соперника;
у стороны без шашек ходов нет, и она проигрывает. `O(2^16·16·60)` в
худшем случае.

Тонкие места:

- движущаяся шашка тоже уходит с доски, так что она всегда теряется;
- касание считается ударом, поэтому касательные направления нужно
  перебирать точно, с небольшим допуском на округление, а не только
  промежутки между ними;
- снять шашку своего цвета бывает выгодно, так что ходы не ограничиваются
  ударами по сопернику.

Ответы сверены на всех тестах и на 74 позициях, среди которых есть выигрышные
для белых, с отдельной программой, которая перебирает 200 000 направлений для
каждой шашки и решает все подмножества снизу вверх.

## Особенности языков

- Во всех языках одни и те же множества сбитых шашек строятся по одним и
  тем же углам.
- Python хранит результаты поиска в словаре, остальные языки — в массиве с
  ячейкой на каждое состояние.
