# 1163. 把棋子弹出棋盘的游戏中谁会获胜

[Timus 1163](https://acm.timus.ru/problem.aspx?space=1&num=1163) · 难度 3932 · games

原题作者 Nick Durov，出自 2001 年 ACM ICPC 东北欧区域赛北部分区赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`8×8` 的棋盘上有八枚红棋和八枚白棋，都是半径 `0.4` 的圆片，互不接触。双方轮流
行动，红方先手。一步棋是选一枚自己颜色的棋子，朝任意方向弹出：它沿直线滑行直到
掉出棋盘，途中碰到的每一枚棋子都被移走。轮到自己时已经没有棋子的一方判负。求双方
都采取最优策略时的胜者。

时间限制：1 秒。内存限制：64 MB。

## 输入

两行，每行八对坐标：先是红棋的圆心，然后是白棋的圆心。

## 输出

`RED` 或 `WHITE`。

## 样例

### 样例 1

输入：

```
0.5 7.5 1.5 7.5 2.5 7.5 3.5 7.5 4.5 7.5 5.5 7.5 6.5 7.5 7.5 7.5
0.5 0.5 1.5 0.5 2.5 0.5 3.5 0.5 4.5 0.5 5.5 0.5 6.5 0.5 7.5 0.5
```

输出：

```
RED
```

## 解法

运动的棋子扫过一条带状区域：另一枚棋子被击中，当且仅当它的圆心在起点前方，且到
运动直线的距离不超过 `0.8`（两个半径）。起点后方的棋子不可能被碰到，因为棋子之间
的距离都大于 `0.8`，而且这个距离只会增大。

方向转动时，距离为 `d` 的一枚棋子在一段方向弧内被击中，弧的两端是两条切线方向
`atan2 ± asin(0.8/d)`。所以被击中的棋子集合只在这些角度处变化。逐个尝试每个切线
角度本身（此时接触仍算击中）以及相邻角度之间每段空隙的中点，就能得到所有可能的
集合：每枚棋子最多 60 个，去重后更少。

游戏状态是仍在棋盘上的棋子集合加上轮到哪一方，总共 `2^17` 个状态。一步棋会移走
运动的棋子本身和它击中的一切，所以每局最多 16 步就结束。带记忆化的搜索中，若某步
棋能走到对手的必败状态，则当前状态为必胜；没有棋子的一方无棋可走，判负。最坏
`O(2^16·16·60)`。

注意事项：

- 运动的棋子自己也会离开棋盘，所以它总是被损失掉；
- 接触就算击中，所以切线方向必须精确地尝试（带一个很小的舍入容差），不能只试
  它们之间的空隙；
- 移走自己颜色的棋子有时是好棋，所以着法不只限于击打对手。

答案已在所有测试和 74 个局面（其中包括白方获胜的局面）上，与另一个程序比对：该程序对
每枚棋子采样 200,000 个方向，并自底向上求解所有子集。

## 各语言说明

- 所有语言都用同样的角度构造同样的击中集合。
- Python 用字典保存搜索结果，其他语言用每个状态一格的数组。
