# 1115. Разбиение длин по рядам заданной общей длины

[Timus 1115](https://acm.timus.ru/problem.aspx?space=1&num=1115) · сложность 415 · backtracking

Оригинальная задача — первое отборочное соревнование в болгарскую команду на IOI.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть `N < 100` предметов с целыми длинами от 1 до 100 и `M` рядов
(`1 < M < 10`) заданных длин. Разложить все предметы по рядам так, чтобы
длины в каждом ряду в сумме давали ровно длину ряда; в каждом ряду хотя
бы один предмет. Известно, что разбиение существует. Вывести любое.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N M`, затем `N` строк с длинами предметов, затем `M` строк с длинами
рядов.

## Выходные данные

Для каждого ряда в порядке ввода две строки: число предметов в нём и их
длины.

## Проверка

Подходит любое правильное разбиение. Проверяющая программа убеждается,
что каждый ряд в сумме даёт свою длину и что использованы ровно данные
предметы.

## Примеры

### Пример 1

Ввод:

```
5 2
4
10
2
5
3
11
13
```

Вывод:

```
3
5 4 2
2
10 3
```

## Решение

Это точное разбиение на несколько частей, в общем случае трудная задача,
поэтому решения ищут перебором с сильными отсечениями. Ряды заполняются
по одному, начиная с самого короткого: у коротких рядов меньше всего
заполнений; последний ряд просто забирает все оставшиеся предметы. Внутри
ряда предметы перебираются по убыванию длины, а равные длины пробуются на
каждом месте только один раз, ведь равные предметы взаимозаменяемы.

Главное отсечение — таблица сумм подмножеств. Перед заполнением ряда
битсет `reach[k]` хранит суммы, которые могут дать свободные предметы с
позиции `k` до конца (строится с конца:
`reach[k] = reach[k+1] | reach[k+1] << len`). Предмет берётся, только если
остаток ряда ещё можно добрать предметами после него, поэтому ряд никогда
не заводит в тупик; откат может понадобиться только из-за взаимодействия
рядов. На случайных наборах и на наборах почти равных длин, где частичных
заполнений много, каждый случай решается с большим запасом по времени.

Тонкие места:

- перебор равных предметов во всех порядках взрывается на наборах с
  многими одинаковыми длинами;
- без проверки сумм подмножеств ряд исследуется, даже когда его остаток
  уже недостижим;
- ряды нужно выводить в порядке ввода, хотя заполняются они в другом.

Ответы проверены проверяющей программой на всех тестах и на 120 случайных
наборах до 99 предметов в 9 рядах, в том числе с почти равными и в
основном одинаковыми длинами.

## Особенности языков

- C++ использует `std::bitset`; Go, Java и Rust хранят суммы в массивах
  64-битных слов с написанным вручную сдвигом с «или»; Python использует
  длинные целые как битсеты.
