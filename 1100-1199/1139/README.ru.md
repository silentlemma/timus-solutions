# 1139. Сколько кварталов пересекает полёт по диагонали над сеткой улиц

[Timus 1139](https://acm.timus.ru/problem.aspx?space=1&num=1139) · сложность 78 · number_theory

Оригинальная задача — четвертьфинал, центральный регион России, Рыбинск, 17–18 октября 2001 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N` авеню и `M` улиц, `1 < N, M < 32000`, делят город на квадратные
кварталы. Вертолёт летит по прямой из юго-западного угла в
северо-восточный. Посчитать кварталы, над которыми он пролетел; квартал —
открытая внутренность своего квадрата, так что касание угла не считается.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `M`.

## Выходные данные

Число кварталов.

## Примеры

### Пример 1

Ввод:

```
4 3
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
3 3
```

Вывод:

```
2
```

## Решение

Кварталы образуют сетку `a × b`, где `a = N − 1` и `b = M − 1`, а полёт —
её диагональ. Он начинается внутри первого квартала, и каждый раз, когда
пересекает линию сетки, попадает в новый квартал. Он пересекает `a − 1`
внутренних вертикальных и `b − 1` внутренних горизонтальных линий, но во
внутреннем углу сетки пересекает по одной линии каждого вида
одновременно и попадает только в один новый квартал. Диагональ проходит
через точки `(k·a/g, k·b/g)`, так что встречает ровно `g − 1` внутренних
углов, где `g = gcd(a, b)`. Всего
`1 + (a − 1) + (b − 1) − (g − 1) = a + b − gcd(a, b)`. `O(log min(a, b))`.

Тонкие места:

- во входе количества линий, а не кварталов: из каждого вычитается
  единица;
- в квадратной сетке диагональ проходит через все углы на своём пути и
  пересекает только `a` кварталов;
- при одном ряде или столбце полёт пересекает все его кварталы.

Ответы сверены с подсчётом кварталов под диагональю по столбцам, с точными
округлениями вниз и вверх, для всех `N, M ≤ 40` и на всех тестах.
