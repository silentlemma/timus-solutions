# 1194. 聚会结束后分头回家时的握手次数

[Timus 1194](https://acm.timus.ru/problem.aspx?space=1&num=1194) · 难度 83 · math

原题作者 Leonid Volkov，出自 2002 年 3 月 2 日第五届中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

`N ≤ 20000` 个霍比特人（其中有 `K` 对夫妻）一起离开聚会。在每个路口，一组人分成
若干更小的组，每个人都和即将分开的每个人握手。各组不断分开，直到每组只剩一个
霍比特人或一对夫妻。给出所有的分组过程，求握手的总次数。

时间限制：1 秒。内存限制：64 MB。

## 输入

`N` 和 `K`，然后对每次分组给出组号、新组数，以及每个新组的编号和人数。

## 输出

握手次数。

## 样例

### 样例 1

输入：

```
3 0
1 2 2 2 3 1
2 2 4 1 5 1
```

输出：

```
3
```

## 解法

任意两个霍比特人恰好握手一次：在他们第一次被分到不同组的那次分组时。唯一从不
分开的是一起回家的夫妻。所以答案是 `N·(N − 1)/2 − K`，分组的具体过程无关紧要。
除了读第一行，`O(1)`。

注意事项：

- 分组的各行可以完全不读，但逐次累加每次分开的人对数的解法也得到同样的结果；
- `N·(N − 1)/2` 约达 `2·10⁸`，仍在 32 位之内，不过这里用 64 位运算也毫无代价。

答案已在 200 次随机聚会和所有测试上与另一份逐次累加握手数的独立解答比对。
