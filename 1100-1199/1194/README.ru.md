# 1194. Сколько рукопожатий, когда компания расходится по домам

[Timus 1194](https://acm.timus.ru/problem.aspx?space=1&num=1194) · сложность 84 · math

Автор оригинальной задачи — Леонид Волков; пятое командное первенство школьников по программированию, 2 марта 2002 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

`N ≤ 20000` хоббитов, среди которых `K` супружеских пар, вместе уходят с
вечеринки. На каждом перекрёстке группа делится на меньшие, и каждый
пожимает руку каждому, с кем расстаётся. Группы делятся, пока каждая не
станет одним хоббитом или супружеской парой. Разбиения заданы; посчитать
все рукопожатия.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`N` и `K`, затем для каждого разбиения номер группы, число новых групп и
номер и численность каждой из них.

## Выходные данные

Число рукопожатий.

## Примеры

### Пример 1

Ввод:

```
3 0
1 2 2 2 3 1
2 2 4 1 5 1
```

Вывод:

```
3
```

## Решение

Любые два хоббита, кроме супругов, пожимают руки ровно один раз — на том
разбиении, где они впервые оказываются в разных группах. Не расстаются
только супружеские пары, которые уходят домой вместе. Значит, ответ —
`N·(N − 1)/2 − K`, а описание разбиений не важно. `O(1)`, не считая
чтения первой строки.

Тонкие места:

- строки с разбиениями можно вообще не читать, но решение, которое
  складывает разведённые пары по каждому разбиению, получает то же число;
- `N·(N − 1)/2` доходит примерно до `2·10⁸`, что ещё помещается в 32 бита,
  хотя 64-битная арифметика здесь ничего не стоит.

Ответы сверены с отдельно написанным решением, считающим рукопожатия по
разбиениям, на 200 случайных компаниях и на всех тестах.

## Оптимизированные решения

Оптимизированное решение на Java разбирает два числа вручную через
`System.in.read` вместо `Scanner`: 308 КБ вместо 1552 КБ при том же
времени. Формула та же.
