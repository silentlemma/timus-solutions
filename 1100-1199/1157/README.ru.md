# 1157. Наименьшее число плиток, дающее N прямоугольников, если на K плиток меньше давали M

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Мальчик выкладывает все свои квадратные плитки в прямоугольники. По `M`,
`N` и `K` (`M, N ≤ 50`, `K ≤ 9999`) найти наименьшее число плиток `L`,
такое что из `L` плиток можно сложить ровно `N` разных прямоугольников, а
из `L − K` плиток — ровно `M`. Если такого `L` не больше 10000 нет, вывести
`0`.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

`M`, `N` и `K`.

## Выходные данные

Наименьшее `L` или `0`.

## Примеры

### Пример 1

Ввод:

```
2 3 1
```

Вывод:

```
16
```

## Решение

Из `x` плиток получается по одному прямоугольнику `a × b` на каждое
представление `x = a·b` с `a ≤ b`, так что число прямоугольников — это
число делителей `x`, делённое пополам с округлением вверх (квадратный
корень, если он есть, в паре сам с собой). Решето по `d` от 1 до 10000
прибавляет единицу каждому кратному `d` и считает делители всех чисел до
10000 за `O(10000·log 10000)` шагов. Затем перебираем `L` от `K + 1` вверх
и останавливаемся на первом, у которого `N` прямоугольников, а у `L − K` —
`M`.

Тонкие места:

- `L − K` должно быть хотя бы одной плиткой, поэтому `L` начинается с
  `K + 1`;
- у точного квадрата нечётное число делителей, и его квадратный
  прямоугольник считается один раз;
- ни у одного числа до 10000 нет больше 64 делителей, так что при `N` или
  `M` больше 32 ответ всегда `0`.

Ответы сверены на всех тестах с прямым подсчётом прямоугольников перебором
делителей.
