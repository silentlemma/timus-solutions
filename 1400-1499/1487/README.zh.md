# 1487. 中国足球

[Timus 1487](https://acm.timus.ru/problem.aspx?space=1&num=1487) · 难度 1244 · graphs

原题作者 Sergey Pupyrev，出自 2006 年 10 月 7 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 支队伍（2 ≤ N ≤ 1000）进行了部分比赛，没有平局，结果以胜负表给出，且结果具有
传递性：若 A 胜 B、B 胜 C，则 A 也胜 C。若 A 胜过 B，或胜过某支比 B 强的队伍，则
A 比 B 强。若 A 不弱于任何比 B 强的队伍，则称 A 比 B 打得好。回答 Q ≤ 50000 个
"A 是否比 B 打得好？"的问题，答 "YES" 或 "No"。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，N × N 的 0/1 表，Q，然后是 Q 行 A B。

## 输出

对每个问题输出 "YES" 或 "No"。

## 样例

### 样例 1

输入:

```
3
011
000
000
2
2 3
1 3
```

输出:

```
No
YES
```

## 解法

"更强"就是沿胜负关系的可达性；由于结果具有传递性，胜负关系构成有向无环图。C 不
能到达 A 时，A 不弱于 C。所以当没有任何能到达 B 的队伍也能到达 A 时，A 比 B 打得
好：两者"更强队伍"的集合不相交。

这些集合用位集表示。按拓扑序（对胜负关系用 Kahn 算法）处理队伍，一支队伍的集合
就是战胜它的那些队伍的集合之并，再加上这些队伍本身。每场比赛做一次 N/64 个字的
位集并。每个问题就是一次求交。`O(N³/64 + Q·N/64)`。

注意事项：

- 答案是 "YES" 和 "No"，大小写不同（所有测试）；
- 任何队伍都比"没有队伍比它强"的队伍打得好，即使曾输给它（测试 02、03）；
- 两队之上有共同的胜者时，两个方向的答案都是 "No"（测试 04）。
