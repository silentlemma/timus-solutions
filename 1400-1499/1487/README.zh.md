# 1487. 中国足球

[Timus 1487](https://acm.timus.ru/problem.aspx?space=1&num=1487) · 难度 1241 · graphs

原题作者 Sergey Pupyrev，出自 2006 年 10 月 7 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 支队伍（2 ≤ N ≤ 1000）进行了部分比赛，没有平局，结果以胜负表给出，且结果具有
传递性：若 A 胜 B、B 胜 C，则 A 要么已经战胜 C，要么一定会战胜 C。若 A 胜过 B，或
胜过某支比 B 强的队伍，则 A 比 B 强。若 A 不弱于任何比 B 强的队伍，则称 A 比 B
打得好。回答 Q ≤ 50000 个
"A 是否比 B 打得好？"的问题，答 "YES" 或 "No"。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行是 N，接下来 N 行，每行恰有 N 个字符。第 i 行第 j 列为 1 表示队伍 i 已战胜
队伍 j，其余位置均为 0。每对队伍至多已赛一场。随后是 Q，再接 Q 行 A B，其中
1 ≤ A, B ≤ N 且 A ≠ B；队伍编号为 1 到 N。

## 输出

对每个问题输出 "YES" 或 "No"。

## 样例

### 样例 1

输入:

```
3
011
000
000
2
2 3
1 3
```

输出:

```
No
YES
```

## 解法

"更强"就是沿胜负关系的可达性；由于结果具有传递性，胜负关系构成有向无环图。C 不
能到达 A 时，A 不弱于 C。所以当没有任何能到达 B 的队伍也能到达 A 时，A 比 B 打得
好：两者"更强队伍"的集合不相交。

这些集合用位集表示。按拓扑序（对胜负关系用 Kahn 算法）处理队伍，一支队伍的集合
就是战胜它的那些队伍的集合之并，再加上这些队伍本身。每场比赛做一次位集并。
每个问题就是一次求交。设每个位集占 W 个存储字，则最坏时间复杂度为
`O(N²·W + Q·W)`。C++ 使用固定 1000 位的 `std::bitset`；Go、Java 和 Rust 使用
⌈N/64⌉ 个 64 位字。Python 使用任意精度整数掩码，因此其中 W 表示整数内部表示
所需的数位个数。

注意事项：

- 答案是 "YES" 和 "No"，大小写不同（所有测试）；
- 任何队伍都比"没有队伍比它强"的队伍打得好，即使曾输给它（测试 02、03）；
- 两队之上有共同的胜者时，两个方向的答案都是 "No"（测试 04）。
