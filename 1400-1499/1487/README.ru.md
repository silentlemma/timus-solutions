# 1487. Китайский футбол

[Timus 1487](https://acm.timus.ru/problem.aspx?space=1&num=1487) · сложность 1241 · graphs

## Задача

N команд (2 ≤ N ≤ 1000) сыграли часть матчей без ничьих, они заданы
таблицей побед, и результаты транзитивны: если A обыграла B, а B
обыграла C, то A либо уже обыграла C, либо обязательно её обыграет.
A сильнее B, если A обыграла B или обыграла команду, которая сильнее B.
A играет лучше B, если A не слабее
любой команды, которая сильнее B. Нужно ответить на Q ≤ 50000 вопросов
«играет ли A лучше B?» словами «YES» или «No».

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

В первой строке N, затем N строк ровно по N символов. Единица в строке i,
столбце j означает, что команда i обыграла j; все остальные элементы —
нули. Каждая пара сыграла не более одного раза. Далее Q и Q строк A B,
где 1 ≤ A, B ≤ N и A ≠ B; команды пронумерованы от 1 до N.

## Выходные данные

«YES» или «No» на каждый вопрос.

## Примеры

### Пример 1

Ввод:

```
3
011
000
000
2
2 3
1 3
```

Вывод:

```
No
YES
```

## Решение

«Сильнее» — это достижимость по победам, и победы образуют ациклический
граф, потому что результаты транзитивны. A не слабее C, когда C не
достигает A. Значит, A играет лучше B, когда ни одна команда, достигающая
B, не достигает A: два множества более сильных команд не пересекаются.

Эти множества — битовые множества. Если брать команды в
топологическом порядке (алгоритм Кана по победам), множество команды —
объединение множеств команд, которые её обыграли, вместе с ними самими.
Это одно объединение битовых множеств на матч. Каждый вопрос — одно
пересечение. Если множество занимает W машинных слов, время в худшем
случае — `O(N²·W + Q·W)`. C++ использует фиксированные 1000-битные
множества `std::bitset`; Go, Java и Rust — ⌈N/64⌉ 64-битных слов. Python
использует целочисленные маски произвольной точности, поэтому в нём W
считает разряды внутреннего представления целого числа.

Подводные камни:

- ответы — «YES» и «No», в разном регистре (все тесты);
- любая команда играет лучше команды, сильнее которой никого нет, даже
  если проиграла ей (тесты 02, 03);
- общий победитель над обеими командами даёт «No» в обе стороны
  (тест 04).
