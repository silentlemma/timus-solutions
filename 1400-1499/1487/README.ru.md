# 1487. Китайский футбол

## Задача

N команд (2 ≤ N ≤ 1000) сыграли часть матчей без ничьих, они заданы
таблицей побед, и результаты транзитивны: если A обыграла B, а B
обыграла C, то A обыгрывает и C. A сильнее B, если A обыграла B или
обыграла команду, которая сильнее B. A играет лучше B, если A не слабее
любой команды, которая сильнее B. Нужно ответить на Q ≤ 50000 вопросов
«играет ли A лучше B?» словами «YES» или «No».

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, таблица N × N из 0 и 1, Q, затем Q строк A B.

## Выходные данные

«YES» или «No» на каждый вопрос.

## Примеры

### Пример 1

Ввод:

```
3
011
000
000
2
2 3
1 3
```

Вывод:

```
No
YES
```

## Решение

«Сильнее» — это достижимость по победам, и победы образуют ациклический
граф, потому что результаты транзитивны. A не слабее C, когда C не
достигает A. Значит, A играет лучше B, когда ни одна команда, достигающая
B, не достигает A: два множества более сильных команд не пересекаются.

Эти множества — битовые множества. Если брать команды в
топологическом порядке (алгоритм Кана по победам), множество команды —
объединение множеств команд, которые её обыграли, вместе с ними самими.
Это одно объединение из N/64 слов на матч. Каждый вопрос — одно
пересечение. `O(N³/64 + Q·N/64)`.

Подводные камни:

- ответы — «YES» и «No», в разном регистре (все тесты);
- любая команда играет лучше команды, сильнее которой никого нет, даже
  если проиграла ей (тесты 02, 03);
- общий победитель над обеими командами даёт «No» в обе стороны
  (тест 04).
