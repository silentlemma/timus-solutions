# 1426. 矩形

[Timus 1426](https://acm.timus.ru/problem.aspx?space=1&num=1426) · 难度 4823 · geometry

原题作者 Nikita Rybak、Dmitry Kovalioff 与 Ilya Grebnov，出自 Timus Top Coders: First Challenge。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对 N 幅画（0 ≤ N ≤ 10 000）中的每一幅，给出四个整数坐标在 −5000 到 5000 之间的点，
可能有点重合。画一个任意朝向、没有重合顶点、位于 −10 000 到 10 000 的正方形之内
的矩形，使四个点都在它的某条边上。输出 "+" 和按环绕顺序排列的顶点（小数点后至少
六位），若不存在则输出 "-"；任何满足的矩形都可以。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后 N 行，每行八个数：四个点。

## 输出

每幅画一行。

## 样例

### 样例 1

输入:

```
2
1 0 0 1 3 2 1 2
0 1 0 -1 1 0 -1 0
```

输出:

```
+ 0.000000 0.000000 0.000000 2.000000 3.1234567890 2.000000 3.1234567890 0.000000
+ 0.000000 -1.000000 1.000000 0.000000 0.000000 1.000000 -1.000000 0.000000
```

## 解法

固定边的方向。四个点都必须在矩形内，而一个点只能位于与点集相接的边上，所以只需
考虑该方向下的包围盒：它可行当且仅当每个点在两个旋转坐标之一上取到极值。若所有
点在某个坐标上相同，包围盒退化，给它向一侧加宽 1，所有点仍在边上。

方向旋转时，可行方向的集合是闭集，它的每个端点都是两点在某个旋转坐标上相等的时
刻，也就是边平行或垂直于这两点连线的时刻。所以只需尝试至多六个点到点的方向（一
个方向同时代表它的垂直方向）。以方向 (dx, dy) 本身作为坐标系，旋转坐标
x·dx + y·dy 和 y·dx − x·dy 都是整数，检验是精确的；只有顶点用浮点计算。若所有点
重合，以该点为顶点的小正方形即可。

坐标在 ±5000 内的点的包围盒不会超出 ±10 000：这些点位于半径 5000·√2 的圆内，而
外切于该圆的任何正方形的顶点到中心的距离都不超过 10 000。`O(N)`。

注意事项：

- 位于其他三点构成的三角形内部的点永远不可能在边上（测试 03、06）；
- 共线或重合的点需要宽度为正的矩形（测试 02、04、07）；
- 包围盒可能恰好碰到画布边缘（测试 05）。
