# 1426. Прямоугольники

[Timus 1426](https://acm.timus.ru/problem.aspx?space=1&num=1426) · сложность 5158 · geometry

Авторы оригинальной задачи — Никита Рыбак, Дмитрий Ковалёв и Илья Гребнов; Timus Top Coders: First Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для каждой из N картин (N ≤ 10 000) даны четыре точки с целыми
координатами от −5000 до 5000; некоторые могут совпадать. Нужно
нарисовать прямоугольник, повёрнутый как угодно, без совпадающих
вершин, внутри квадрата от −10 000 до 10 000, так чтобы каждая из
четырёх точек лежала на одной из его сторон. Вывести «+» и вершины в
порядке обхода, не меньше шести знаков после точки, или «-», если
такого прямоугольника нет; подходит любой.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк по восемь чисел — четыре точки.

## Выходные данные

По строке на картину.

## Примеры

### Пример 1

Ввод:

```
2
1 0 0 1 3 2 1 2
0 1 0 -1 1 0 -1 0
```

Вывод:

```
+ 0.000000 0.000000 0.000000 2.000000 3.1234567890 2.000000 3.1234567890 0.000000
+ 0.000000 -1.000000 1.000000 0.000000 0.000000 1.000000 -1.000000 0.000000
```

## Решение

Зафиксируем направление сторон. Все четыре точки должны лежать в
прямоугольнике, а точка может оказаться только на стороне, касающейся
множества, поэтому достаточно рассмотреть ограничивающий прямоугольник
в этом направлении: он подходит ровно тогда, когда каждая точка
крайняя по одной из двух повёрнутых координат. Если у всех точек одна
координата совпадает, прямоугольник вырожден; ему добавляется ширина 1
с одной стороны, и все точки остаются на сторонах.

При повороте направления множество хороших направлений замкнуто, и
каждый его конец — момент, когда две точки сравниваются по повёрнутой
координате, то есть стороны параллельны или перпендикулярны отрезку
между ними. Поэтому достаточно перебрать не больше шести направлений от
точки к точке (одно направление заодно даёт и перпендикулярное). Если
взять само направление (dx, dy) за систему координат, повёрнутые
координаты x·dx + y·dy и y·dx − x·dy целые и проверка точна; только
вершины вычисляются в вещественных числах. Если все точки совпадают,
подходит маленький квадрат с вершиной в этой точке.

Прямоугольник для точек в пределах ±5000 не выходит за ±10 000: точки
лежат в круге радиуса 5000·√2, а у любого квадрата, описанного около
этого круга, вершины не дальше 10 000 от центра. `O(N)`.

Подводные камни:

- точка внутри треугольника остальных никогда не будет на стороне
  (тесты 03, 06);
- коллинеарным или совпадающим точкам нужен прямоугольник
  положительной ширины (тесты 02, 04, 07);
- прямоугольник может ровно касаться края картины (тест 05).
