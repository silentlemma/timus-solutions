# 1454. Прямоугольники 2

[Timus 1454](https://acm.timus.ru/problem.aspx?space=1&num=1454) · сложность 2530 · backtracking

Авторы оригинальной задачи — Никита Рыбак, Илья Гребнов и Дмитрий Ковалёв; Timus Top Coders: Second Challenge.

## Задача

Даны пять прямоугольников W[i] × H[i] (1 ≤ W[i], H[i] ≤ 1000). Нужно
выяснить, можно ли сложить из всех пяти, поворачивая их как угодно, без
наложений и разрезов, один большой прямоугольник.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Пять строк, в каждой W[i] и H[i].

## Выходные данные

«YES» или «NO».

## Примеры

### Пример 1

Ввод:

```
2 4
3 2
5 3
2 5
2 5
```

Вывод:

```
YES
```

## Решение

Площадь большого прямоугольника равна общей площади A, поэтому его
ширина w — делитель A, а по симметрии достаточно перебрать ширины с
w² ≤ A. При фиксированном размере куски кладутся заполнением по
«линии горизонта»: храним контур заполненной части как отрезки одного
уровня, берём самый низкий отрезок (самый левый среди низших) и кладём
в его левый угол какой-нибудь неиспользованный кусок в любой ориентации.
В любом разбиении самая нижняя левая свободная клетка — левый нижний
угол какого-то куска, и этот кусок не шире отрезка, так как оба
соседних отрезка выше; поэтому перебор находит любое разбиение.

Пять кусков дают не больше 5! · 2⁵ укладок на размер, и ограничения по
ширине и высоте отсекают большинство из них; кусок той же формы второй
раз в тот же угол не пробуется. У площади не больше нескольких сотен
делителей, так что весь перебор крошечный.

Подводные камни:

- «вертушка», где ни один кусок не тянется во всю сторону большого
  прямоугольника (тесты 02, 06, 14);
- простая общая площадь оставляет только полосы ширины 1 (тест 04);
- куски нужно пробовать в обеих ориентациях (тесты 02, 07, 11).
