# 1432. Двойное счастье

[Timus 1432](https://acm.timus.ru/problem.aspx?space=1&num=1432) · сложность 7793 · greedy

Автор оригинальной задачи — Евгений Крохалев; Седьмое открытое личное первенство УрГУ по спортивному программированию, 25 февраля 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Номера билетов состоят из 2N цифр (4 ≤ 2N ≤ 1500, возможны ведущие
нули) и идут до номера из одних девяток. Билет счастливый, если равны
суммы цифр двух половин или если равны суммы цифр на нечётных и чётных
местах. Начиная с данного билета, нужно найти первую пару соседних
билетов t, t + 1, оба из которых счастливые (данный билет может быть
t), или вывести «No solution».

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Текущий номер билета.

## Выходные данные

Два номера или «No solution».

## Примеры

### Пример 1

Ввод:

```
293087
```

Вывод:

```
293149 293150
```

## Решение

Запишем баланс билета как сумму цифр со знаками: правило половин берёт
первую половину с +, а вторую с −, правило мест чередует + и −; билет
счастливый, когда один из двух балансов равен 0. Выберем, какое
правило делает счастливым t и какое — t + 1: четыре сочетания, каждое
решается отдельно, и побеждает наименьший ответ.

Если t кончается девятками после цифры на позиции p, не большей 8, то у
t + 1 эта цифра на единицу больше, а после неё нули. Поэтому при
фиксированном p условия — два линейных уравнения на цифры до p, а
девятки после p лишь добавляют константы. А t ≥ s ровно тогда, когда
цифры t до p не меньше цифр s, так что для каждого p нужно найти
наименьшую строку цифр x ≥ s[0..p] с x_p ≤ 8, удовлетворяющую двум
уравнениям с весами ±1.

Можно ли ещё удовлетворить уравнениям — проверка на отрезках. Позиции
делятся на четыре класса по знакам их двух весов, сумма каждого класса
может быть любым целым между своими границами, и два уравнения
превращаются в условия на разность сумм классов «оба +» и «оба −» и на
разность двух смешанных, плюс проверка чётности. С префиксными
количествами по классам проверка занимает O(1). Наименьшее x сохраняет
самый длинный префикс s, поэтому для каждого p перебираем с конца
позицию, где x впервые больше s, берём там наименьшую подходящую цифру
и дальше жадно ставим наименьшие подходящие цифры. Кандидаты от разных
p и сочетаний сравниваются по месту первого превышения s и цифре там, а
целиком — только при равенстве. `O(L²)` для L = 2N.

Подводные камни:

- данный билет и следующий уже могут быть ответом (тест 08);
- у билета из одних девяток нет следующего, а у некоторых билетов пары
  нет вовсе (тесты 04, 05, 07, gen3);
- два билета могут быть счастливыми по разным правилам (тест 01);
- перенос через много девяток меняет оба баланса сразу (тесты 10, 12,
  gen2).
