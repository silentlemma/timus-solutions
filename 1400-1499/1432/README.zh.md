# 1432. 双重幸运

[Timus 1432](https://acm.timus.ru/problem.aspx?space=1&num=1432) · 难度 7793 · greedy

原题作者 Evgeny Krokhalev，出自 2006 年 2 月 25 日第七届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

车票号码有 2N 位（4 ≤ 2N ≤ 1500，可以有前导零），一直到全是 9 的号码。若两半的
数字和相等，或奇数位与偶数位上的数字和相等，车票就是幸运的。从给定的车票开始，
找出第一对相邻的车票 t、t + 1，使两张都是幸运的（给定的车票本身可以是 t）；若
不存在，输出 "No solution"。

时间限制：1 秒。内存限制：64 MB。

## 输入

当前的车票号码。

## 输出

两个号码，或 "No solution"。

## 样例

### 样例 1

输入:

```
293087
```

输出:

```
293149 293150
```

## 解法

把车票的平衡写成带符号的数字和：半数规则前一半取 +、后一半取 −，奇偶规则交替取
+ 和 −；某个平衡为 0 时车票是幸运的。选择让 t 幸运的规则和让 t + 1 幸运的规则：
共四种组合，各自独立求解，取最小的答案。

若 t 在位置 p 上的数字不超过 8、之后全是 9，那么 t + 1 在该位置上大一，之后全是
0。所以固定 p 后，条件是关于 p 之前（含 p）各位数字的两个线性方程，p 之后的 9
只贡献常数。又因为 t ≥ s 当且仅当 t 到 p 为止的数字不小于 s 的对应部分，所以对
每个 p，要找满足两个权为 ±1 的方程、x_p ≤ 8 且 x ≥ s[0..p] 的最小数字串 x。

能否满足方程是一个区间判定。按两个权的符号把位置分成四类，每类的和可以取其上下
界之间的任意整数，两个方程就变成对“两者都为 +”与“两者都为 −”两类之和的差、以及
两个混合类之和的差的条件，再加一个奇偶性检查。有了按类的前缀计数，判定只需
O(1)。最小的 x 保留尽量长的 s 的前缀，所以对每个 p，从末尾往前尝试 x 第一次超过
s 的位置，在那里取最小的可行数字，然后贪心地填入最小的可行数字。不同 p 和组合的
候选先按第一次超过 s 的位置及该处数字比较，只有相同时才比较整个串。对 L = 2N
为 `O(L²)`。

注意事项：

- 给定的车票和下一张可能已经就是答案（测试 08）；
- 全是 9 的车票没有下一张，有些车票根本没有这样的一对（测试 04、05、07、gen3）；
- 两张车票可能按不同的规则幸运（测试 01）；
- 跨过许多 9 的进位会同时改变两个平衡（测试 10、12、gen2）。
