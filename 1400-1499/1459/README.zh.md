# 1459. 弓箭手的旅行

[Timus 1459](https://acm.timus.ru/problem.aspx?space=1&num=1459) · 难度 1676 · dp

原题作者 Alexander Ipatov，由 Vladimir Yakovlev 准备，出自 2006 年 1 月彼得罗扎沃茨克冬季集训的乌拉尔国立大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

弓箭手是一种棋子，每步向前、后、左或右走一格。它站在 N × M 棋盘（2 ≤ N ≤ 5，
2 ≤ M ≤ 10⁹）的格子 (1, 1) 上，必须恰好经过每个格子一次并回到起点。求这样的巡游
数，对 10⁹ 取模。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 M。

## 输出

巡游数对 10⁹ 取模的结果。

## 样例

### 样例 1

输入:

```
2 3
```

输出:

```
2
```

## 解法

巡游就是网格的哈密顿回路沿两个方向之一走一遍，所以答案是回路数的两倍。按宽度为
N ≤ 5 的行用插头 DP 计数：两行之间，状态记录哪些竖边穿过边界，以及它们的端点如何
两两由路径相连，用括号表示。行内逐格处理，另带一个水平插头；没有插头的格子开始一
条新路径，有一个插头的格子把路径向下或向右延续，有两个插头的格子连接两条路径，
当两个左括号或两个右括号相遇时修正远端的括号。把同一条路径的两端连起来就闭合成
回路，这只允许在最后一个格子且没有其他插头时发生，因为回路必须覆盖所有格子。

宽度为 5 时只有 20 个状态，所以一行就成了一个小的转移矩阵。前 M − 1 行是它的幂，
从空状态出发用反复平方求出；最后一行不能再向下伸出插头，但可以闭合回路，在最后
单独施加。设 S 个状态，复杂度 `O(S³ log M)`。

注意事项：

- 格子数为奇数时没有巡游（测试 03、08、12）；
- 两行时无论多长都恰好只有一个回路（测试 01、07）；
- 矩阵乘法中对 10⁹ 取模需要 64 位中间值。
