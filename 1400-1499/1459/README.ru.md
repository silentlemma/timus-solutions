# 1459. Путешествие лучника

## Задача

Лучник — шахматная фигура, ходящая на одно поле вперёд, назад, влево
или вправо. Лучник стоит на поле (1, 1) доски N × M (2 ≤ N ≤ 5,
2 ≤ M ≤ 10⁹) и должен побывать на каждом поле ровно один раз и
вернуться в исходное. Нужно посчитать число таких обходов по модулю
10⁹.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M.

## Выходные данные

Число обходов по модулю 10⁹.

## Примеры

### Пример 1

Ввод:

```
2 3
```

Вывод:

```
2
```

## Решение

Обход — это гамильтонов цикл решётки, пройденный в одном из двух
направлений, так что ответ вдвое больше числа циклов. Циклы считаем по
строкам ширины N ≤ 5 динамикой по изломанному профилю: между двумя
строками состояние помнит, какие вертикальные рёбра пересекают границу и
как их концы попарно соединены путями, в виде скобок. Внутри строки
клетки обрабатываются по одной с одним дополнительным горизонтальным
выходом; клетка без выходов начинает новый путь, клетка с одним выходом
продолжает его вниз или вправо, а клетка с двумя соединяет два пути,
исправляя скобку дальнего конца, когда встречаются две открывающие или
две закрывающие. Соединение двух концов одного пути замыкает цикл, и это
разрешено только в самой последней клетке и без других выходов, ведь
цикл должен покрыть всё.

Для ширины 5 состояний всего 20, поэтому одна строка
превращается в небольшую матрицу перехода. Первые M − 1 строк — её
степень, найденная повторным возведением в квадрат, от пустого
состояния, а последняя строка, которая не может отдавать выходы ниже, но
может замкнуть цикл, применяется в конце. `O(S³ log M)` для S состояний.

Подводные камни:

- при нечётном числе полей обходов нет (тесты 03, 08, 12);
- у двух строк ровно один цикл при любой длине (тесты 01, 07);
- счёт по модулю 10⁹ в произведениях матриц требует 64-битных
  промежуточных значений.
