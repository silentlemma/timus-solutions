# 1461. 新年彩灯

[Timus 1461](https://acm.timus.ru/problem.aspx?space=1&num=1461) · 难度 988 · greedy

原题作者 Alexander Toropov，特别感谢 Dmitry Ivankov，出自 2006 年 1 月彼得罗扎沃茨克冬季集训的乌拉尔国立大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

长度为 N（2 ≤ N ≤ 100000）的彩灯是从 (0, 0) 到 (N, 0) 的折线，每段向右一个单位，
同时向上（u）、向下（d）或水平（h）。任何顶点都不能在 x 轴下方，也不能有两个相邻
顶点同时在 x 轴上。所有彩灯按字符串的字典序排列。给定一个彩灯，输出列表中的下一
个；若它是最后一个，输出 "No solution"。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是由 u、d、h 组成的彩灯字符串。

## 输出

下一个彩灯，或 "No solution"。

## 样例

### 样例 1

输入:

```
6
uhduhd
```

输出:

```
uhhdud
```

## 解法

轴上的水平段会让两个顶点连续落在轴上，所以规则是：不低于轴，轴上不能有 h。字母
顺序为 d < h < u。从高度 y 出发、剩 r 段时能否收尾很简单：在轴上下一段必须上升，
所以 r 为 0 或至少为 2；在轴上方，多余的长度都可以用水平段填充，所以 r ≥ y 即可。

和求字典序的下一个字符串一样，找最后一个可以把字母增大为 h 或 u 的位置，要求前缀
仍然合法，且仍能收尾；保留它之前的部分，其余部分每一步依次尝试 d、h、u，填入能保
证收尾的最小字母。若没有任何位置可以增大，这就是最后一个彩灯。`O(N)`。

注意事项：

- 轴上不允许 h，所以在轴上只能向上，增大字母后的剩余部分不一定能从低处开始（测试
  03、05）；
- 最后一个彩灯尽量上升，它没有后继（测试 02、04、06、gen2、gen3）；
- 长度为奇数时，必须在轴上方某处放一个水平段（测试 05、07、09）。
