# 1439. Поединок с И-Так-Понятно-Кем

## Задача

Комнаты Министерства Магии пронумерованы 1, 2, …, N (1 ≤ N ≤ 10⁹), и
нумерация всегда остаётся без пропусков: когда комнату уничтожают, все
комнаты с бо́льшими номерами сдвигаются на один номер вниз. По порядку
идут M ≤ 10⁵ событий, каждое «D x» (уничтожена комната, у которой
сейчас номер x) или «L x» (Гарри смотрит на дверь, где сейчас номер x).
Уничтожается не более 10⁴ комнат. Для каждого события «L» нужно вывести
номер, который эта комната имела в самом начале.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем M событий.

## Выходные данные

Исходные номера, по одному в строке.

## Примеры

### Пример 1

Ввод:

```
20 7
L 5
D 5
L 4
L 5
D 5
L 4
L 5
```

Вывод:

```
5
4
6
4
7
```

## Решение

Храним исходные номера уничтоженных комнат в отсортированном массиве g.
Комната с текущим номером x имеет исходный номер x + k, где k — число
уничтоженных комнат ниже неё. Если идти по массиву вверх, комната g[j]
лежит ниже ровно тогда, когда g[j] ≤ x + j, то есть g[j] − j ≤ x; а
g[j] − j не убывает, потому что номера в g различны, так что комнаты
ниже образуют префикс, и его длина k находится двоичным поиском.

Для «L» выводим x + k. Для «D» новый исходный номер x + k встаёт ровно
на позицию k массива: всё до неё меньше, всё после — больше, так что
вставка сохраняет порядок. `O(M log D + D²)` для D уничтоженных комнат,
где каждая вставка сдвигает не более 10⁴ чисел.

Подводные камни:

- один и тот же номер двери, уничтожаемый снова и снова, каждый раз
  скрывает новую комнату (тесты 03, 07, gen3);
- номера доходят до миллиарда, массив на каждую комнату не подходит
  (тесты 05, gen1).
