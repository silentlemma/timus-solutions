# 1453. 皇后

[Timus 1453](https://acm.timus.ru/problem.aspx?space=1&num=1453) · 难度 1201 · math

原题作者 Dmitry Kovalioff、Ilya Grebnov 与 Nikita Rybak，出自 Timus Top Coders: Second Challenge。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 维棋盘是 S × S × ... × S 个格子组成的立方体（1 ≤ N ≤ 10000，
2 ≤ S ≤ 100000）。车沿一个坐标移动任意非零格数；象同时沿全部 N 个坐标移动相同的
非零距离；皇后可以按两者之一走。皇后位于空棋盘的 (C[1], ..., C[N])。求它一步能到
达的格子数。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 S，然后是 N 个坐标。

## 输出

格子数，可能有上千位。

## 样例

### 样例 1

输入:

```
3 3
1 2 3
```

输出:

```
8
```

车可以走到 (2, 2, 3)、(3, 2, 3)、(1, 1, 3)、(1, 3, 3)、(1, 2, 1) 和 (1, 2, 2)，
象可以走到 (2, 3, 2) 和 (2, 1, 2)。

## 解法

车的走法给出 N (S − 1) 个格子。一维时象的走法与车完全相同，所以这就是全部答案。
N ≥ 2 时象改变所有坐标，车只改变一个，两者不重叠。

长度为 t 的象步在每个坐标上选一个方向，坐标 i 上方向 ± 可行，当且仅当该侧的余量
S − C[i] 或 C[i] − 1 不小于 t。两侧余量都有 t 的坐标有 2 种选择，只有一侧有的有
1 种，都没有则长度 t 不可行。因此对不超过 max(S − C[i], C[i] − 1) 最小值的长度
t，走法数是 2^k(t)，其中 k(t) 是满足 min(S − C[i], C[i] − 1) ≥ t 的坐标数。用这
些最小值的直方图一次求出所有 k(t)，答案 N (S − 1) + Σ 2^k(t) 可达约 3000 位：
统计每个 k 对应多少个 t，然后从最大的 k 往下用倍增构造和，使用九位十进制分段
（C++、Go、Rust）、`BigInteger`（Java）或 `int`（Python）。设有 D 段，复杂度 `O(N + S + N · D)`。

注意事项：

- 一维时象和车到达的是同一批格子（测试 02）；
- 答案超出定长整数类型（测试 06、gen1 到 gen3）；
- 坐标在边上时只剩一侧（测试 03、07、08）。
