# 1453. Ферзь

[Timus 1453](https://acm.timus.ru/problem.aspx?space=1&num=1453) · сложность 1201 · math

Авторы оригинальной задачи — Дмитрий Ковалёв, Илья Гребнов и Никита Рыбак; Timus Top Coders: Second Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N-мерная шахматная доска — куб из S × S × ... × S клеток
(1 ≤ N ≤ 10000, 2 ≤ S ≤ 100000). Ладья ходит на любое ненулевое число
клеток по одной координате; слон — по всем N координатам сразу на одно и
то же ненулевое расстояние; ферзь ходит как любой из них. Ферзь стоит в
клетке (C[1], ..., C[N]) на пустой доске. Нужно посчитать клетки, куда
ферзь может пойти одним ходом.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и S, затем N координат.

## Выходные данные

Число клеток, в котором могут быть тысячи цифр.

## Примеры

### Пример 1

Ввод:

```
3 3
1 2 3
```

Вывод:

```
8
```

Ходы ладьи ведут в (2, 2, 3), (3, 2, 3), (1, 1, 3), (1, 3, 3), (1, 2, 1)
и (1, 2, 2), ходы слона — в (2, 3, 2) и (2, 1, 2).

## Решение

Ходы ладьи дают N (S − 1) клеток. В одном измерении слон ходит в
точности как ладья, так что это весь ответ. При N ≥ 2 ход слона меняет
все координаты, а ход ладьи — только одну, поэтому множества не
пересекаются.

Ход слона длины t выбирает сторону в каждой координате, и сторона ± в
координате i возможна, когда запас с этой стороны, S − C[i] или
C[i] − 1, не меньше t. Координата, где запас t есть с обеих сторон,
даёт 2 варианта, где с одной — 1, а без запаса длина t невозможна.
Поэтому для длин t до наименьшего из max(S − C[i], C[i] − 1) число
ходов равно 2^k(t), где k(t) — число координат с
min(S − C[i], C[i] − 1) ≥ t. Гистограмма этих минимумов даёт все k(t)
за один проход, а ответ N (S − 1) + Σ 2^k(t) содержит до 3015 цифр:
считаем, сколько t приходится на каждое k, и строим сумму удвоениями от
большего k к меньшему в разрядах по девять цифр (C++, Go, Rust),
`BigInteger` (Java) или `int` (Python). `O(N + S + N · D)` для D разрядов.

Подводные камни:

- одно измерение, где ходы слона и ладьи — одни и те же клетки (тест
  02);
- ответ не помещается в целые типы фиксированной разрядности (тесты 06,
  gen1–gen3);
- координата на краю оставляет только одну сторону (тесты 03, 07, 08).
