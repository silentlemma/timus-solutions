# 1441. Из истории банка Гринготтс

## Задача

Гоблины прорыли M туннелей между N комнатами банка
(2 ≤ N ≤ 20000, 1 ≤ M ≤ 20000); ни один туннель не соединяет комнату с
ней самой, никакие два туннеля не соединяют одну и ту же пару комнат, и
все комнаты связаны. Каждый туннель прорыт гипервяком, и один гипервяк
может прорыть целую цепочку туннелей, где каждый следующий начинается в
комнате, где закончился предыдущий, но никогда не проходит по уже
существующему туннелю. Нужно найти наименьшее число гипервяков K,
которые могли прорыть все туннели, и маршрут каждого.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем M пар комнат, соединённых туннелями.

## Выходные данные

K, затем K строк, в каждой по порядку комнаты, через которые проходит
один гипервяк. Принимается любой правильный план.

## Примеры

### Пример 1

Ввод:

```
7 7
1 2
4 1
6 7
5 7
7 4
2 3
4 2
```

Вывод:

```
3
5 7 4 2 1 4
2 3
6 7
```

## Решение

Маршрут каждого гипервяка — цепь: путь, проходящий по каждому туннелю
не более одного раза. Комната с нечётным числом туннелей обязана быть
концом какой-то цепи, поэтому при 2k нечётных комнатах нужно не меньше
k цепей, и в любом случае хотя бы одна. Столько всегда и хватает:
добавим вспомогательную вершину, соединённую со всеми нечётными
комнатами, тогда все степени чётны и в связном графе есть эйлеров цикл.
Удаление k вспомогательных рёбер режет цикл на k цепей из настоящих
туннелей; если нечётных комнат нет, единственный маршрут — сам цикл.

Цикл строится алгоритмом Хирхольцера с явным стеком: из вершины на
вершине стека берём следующее неиспользованное ребро, а если их не
осталось, переносим вершину в цикл; указатель для каждой вершины
гарантирует, что каждое ребро просматривается один раз. Маршрут через
20000 комнат слишком глубок для рекурсии. `O(N + M)`.

Подводные камни:

- без нечётных комнат ответ — один замкнутый маршрут, а не ноль (тесты
  03, 07, gen2);
- в звезде почти все комнаты нечётные (тесты 04, gen3);
- маршрут может проходить через комнату несколько раз (тесты 05, 09).
