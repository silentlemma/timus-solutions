# 1408. 多项式乘法

[Timus 1408](https://acm.timus.ru/problem.aspx?space=1&num=1408) · 难度 1213 · parsing

原题作者 Vladimir Yakovlev，出自 2005 年 10 月 15 日第十二届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给出两个以 a 到 z 为变量的多项式，各占一行：各项用 + 和 - 连接，每项是一个可
选系数（不超过 100，可能有前导零，第一项可能为负）与形如 X 或 X^N 的因子之
积，任何地方都可能有空格。按固定格式输出它们的积：合并同类项和同类因子，不写
系数为零的项和零次因子，不写为 1 的系数和指数（项 "1" 和多项式 "0" 除外），
因子按字母顺序，各项按总次数降序，再按 a、b…… 的指数降序。

时间限制：1 秒。内存限制：64 MB。

## 输入

两个多项式。

## 输出

乘积，写在一行，空格如样例所示。

## 样例

### 样例 1

输入:

```
x*y*z + 4*x^2*y - 2*z*y*y^4 - 1
x + 7*z
```

输出:

```
-2*x*y^5*z - 14*y^5*z^2 + 4*x^3*y + 29*x^2*y*z + 7*x*y*z^2 - x - 7*z
```

## 解法

先去掉所有空格；这样多项式就是符号、项、符号、项……。项是用 * 连接的因子：数
字乘到系数上，字母（可带 ^ 和数字）加到该字母的指数上。把多项式存为从 26 个
指数到系数的映射，这样读入时同类项就已相加。把每对项相乘——指数相加、系数相
乘——去掉系数为零的项，再按总次数、然后按从 a 到 z 的指数排序，全部降序。第
一项为负时只带 "-"，之后的项用 " + " 或 " - "；系数不为 1 或项中没有变量时才
输出系数。对 T₁ 和 T₂ 项为 `O(T₁·T₂·26)`。

注意事项：

- 空格可能出现在数字内部以及 ^ 与指数之间（测试 07 和 12）；
- 积为零时输出 "0"，即使某个因子在相乘前就是 0（测试 03 和 11）；
- 零次方和零系数必须消失，一次方不写（测试 06 和 07）；
- 据论坛所说有一个测试的行长超过 100 个字符，所以按整行读入。

测试包括论坛中的例子，按精确比较判定。
