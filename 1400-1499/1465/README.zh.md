# 1465. 兵的游戏

[Timus 1465](https://acm.timus.ru/problem.aspx?space=1&num=1465) · 难度 489 · games

原题作者 Alexander Toropov，出自 2006 年 1 月彼得罗扎沃茨克冬季集训的乌拉尔国立大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在 3 × N（1 ≤ N ≤ 10⁹）的棋盘上，第一横排摆满白兵，第三横排摆满黑兵，中间一排为
空。兵按国际象棋规则走子和吃子，必须吃子，无法走子的一方输。白方先走。双方都采取
最优策略：若白方获胜输出 "White"，否则输出 "Black"。

时间限制：1 秒。内存限制：64 MB。

## 输入

N。

## 输出

"White" 或 "Black"。

3

```
White
```

4

### 样例 3

5
```

White
```

## 解法

这就是 Dawson 象棋。推到中间一排的兵会受到对方相邻直线上兵的攻击，随后必须进行
的吃子结束时，被推进的那一列及其相邻列都“死”了：那里再也没有兵能走。因此在 n 条
活列组成的一行中，在第 i 列走一步，会留下 i − 2 列和 n − i − 1 列两行独立的部
分；在边上走会使两列死掉，单独的一列自己死掉。这正是八进制游戏 0.137：只有整行
时才能取走一列，取走两列并至多留下一行，或取走三列并留下至多两行。

先手获胜当且仅当 n 的 Grundy 值不为零；一行的值是不在其各步走法值中的最小数，两
行的值用异或合并。用 O(200²) 求出不超过 200 的值。从 n = 52 起它们以 34 为周期重
复，而按八进制游戏的周期性定理，只需验证到 2 · 52 + 34 + 3 即可；因此更大的 N 被
折到 200 以下的最后一个周期中。每个答案 `O(1)`。

注意事项：

- N = 10⁹ 的棋盘无法模拟，只能折叠（测试 12 到 15）；
- 值从 n = 52 起才稳定：14 列与 48 列、34 列与 68 列的胜者不同（测试 07、08、17、18）；
- 在类 C 语言中负数取余为负，所以折叠时减法的顺序必须正确。
