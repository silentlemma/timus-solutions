# 1465. Игра в пешки

[Timus 1465](https://acm.timus.ru/problem.aspx?space=1&num=1465) · сложность 489 · games

Автор оригинальной задачи — Александр Торопов; контест УрГУ на Петрозаводских зимних сборах, январь 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На доске 3 × N (1 ≤ N ≤ 10⁹) первая горизонталь заполнена белыми
пешками, третья — чёрными, средняя пуста. Пешки ходят и бьют по
шахматным правилам, бить обязательно, и проигрывает тот, кто не может
сделать ход. Первыми ходят белые. Оба играют наилучшим образом: нужно
вывести «White», если выигрывают белые, и «Black» иначе.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

«White» или «Black».

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
White
```

### Пример 2

Ввод:

```
4
```

Вывод:

```
Black
```

### Пример 3

Ввод:

```
5
```

Вывод:

```
White
```

## Решение

Это шахматы Доусона. Пешка, выдвинутая на среднюю горизонталь,
оказывается под ударом пешек противника с соседних вертикалей, и
последующие обязательные взятия кончаются тем, что выдвинутая вертикаль
и её соседи мертвы: ни одна пешка там больше не сможет ходить. Поэтому
ход на вертикали i в ряду из n живых вертикалей оставляет два
независимых ряда из i − 2 и n − i − 1 вертикалей; ход у края убивает две
вертикали, а одиночная вертикаль умирает сама. Это октальная игра
0.137: взять одну вертикаль, только если это весь ряд, взять две,
оставив не больше одного ряда, или взять три, оставив до двух рядов.

Первый игрок выигрывает ровно тогда, когда значение Гранди для n не
ноль; значение ряда — наименьшее число, которого нет среди значений его
ходов, а два ряда объединяются через xor. Значения считаются до 200 за
O(200²). Начиная с n = 52 они повторяются с периодом 34, и по теореме о
периодичности октальных игр это достаточно проверить до
2 · 52 + 34 + 3; поэтому большее N сворачивается в последний период
ниже 200. `O(1)` на ответ.

Подводные камни:

- доску с N = 10⁹ не смоделировать, её можно только свернуть (тесты
  12–15);
- значения устанавливаются только с n = 52: у 14 и 48 вертикалей, как и
  у 34 и 68, победители разные (тесты 07, 08, 17, 18);
- в C-подобных языках остаток от отрицательного числа отрицателен,
  поэтому при сворачивании вычитать нужно в правильном порядке.
