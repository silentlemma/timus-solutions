# 1438. Time Limit Exceeded

[Timus 1438](https://acm.timus.ru/problem.aspx?space=1&num=1438) · сложность 2918 · simulation

Автор оригинальной задачи — Александр Клепинин; Седьмое открытое личное первенство УрГУ по спортивному программированию, 25 февраля 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно исполнить программу на маленьком языке длиной не более 2000
строк. В непустой строке стоит метка, команда или метка и за ней команда.
Команды: `end`, `print x`, присваивания `v = x`, `v = x op y`, где op —
одно из `+ - * / % or and xor`, `v = not x`, `goto label` и
`if x cmp y goto label` с шестью обычными сравнениями; x и y —
переменные или числа. В метках и ключевых словах регистр не важен, в
именах переменных важен. Значения — 32-битные целые без переполнений.

Нужно вывести то, что печатает программа. Если после десяти миллионов
команд она всё ещё работает, её надо остановить и добавить строку
«Program terminated. Variables state:», а за ней «имя: значение» для
каждой переменной, получившей значение, в порядке имён.

Ограничение времени: 1.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Программа; операнды разделяются пробелом. Лишние пробелы допустимы,
кроме места между меткой и её двоеточием.

## Выходные данные

Напечатанные значения, а затем отчёт, если программа была остановлена принудительно.

## Примеры

### Пример 1

Ввод:

```
X = 5
      Y = 1
loop: Y = Y * X
      X = X - 1
      if X >= 1 goto LOOP
      Print Y
      y = Y - 5
      Print y
      end
```

Вывод:

```
120
115
```

### Пример 2

Ввод:

```
value = 15
        value = not value
        value = value or 4
        print value
        value = 0
loop:   
        value = value - 1
        Value = value % 6
        ValueA = value % -6
        goto loop
```

Вывод:

```
-12
Program terminated. Variables state:
Value: 3
ValueA: 3
value: -2499999
```

## Решение

Сначала компиляция, потом запуск. Каждая строка делится на слова;
первое слово, оканчивающееся на «:», — метка, и она указывает на номер
следующей команды, так что строка с одной меткой, как и несколько таких
строк подряд, ведут к идущей за ними команде. Переменные получают
ячейки в таблице значений, а команды становятся записями, массивами
или перечислениями (в Python — замыканиями). Исполнение — простой
цикл по этим командам со счётчиком; во время работы ничего не ищется
по имени.

Команды различаются по форме: второе слово «=» означает присваивание, а
число слов после «=» отличает копирование, `not` и двуместную операцию.
Деление округляет к нулю, а остаток берётся как
`(a mod b + |b|) mod |b|` и никогда не отрицателен: во втором примере
`% 6` и `% -6` от отрицательного значения дают 3. Отчёт печатается,
когда выполнено ровно десять миллионов команд и последняя из них не
`end`, даже если эта команда стояла в последней строке. `O(L log L + K)`
для длины программы L и предела шагов K = 10⁷.

Подводные камни:

- метка одна в строке или две такие строки подряд (тест 03), а также
  метка с именем ключевого слова (тест 11);
- переменные, чьи имена начинаются с ключевого слова, например `ifi`
  (тест 10);
- пропущенное присваивание не попадает в отчёт (тест 04);
- `end` десятимиллионной командой — обычное завершение, любая другая
  команда на этом месте — нет (тесты 12, 13, 17);
- имена сортируются по кодам символов, поэтому заглавные идут первыми
  (тест 16).

## Особенности языков

- Python запускается в PyPy: самые длинные циклы занимают около 1,6 с в
  CPython и около 0,4 с в PyPy.
