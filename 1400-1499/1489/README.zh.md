# 1489. 长方体上的点

[Timus 1489](https://acm.timus.ru/problem.aspx?space=1&num=1489) · 难度 384 · geometry

原题作者 Vladislav Isenbaev 与 Alexander Toropov，出自 2006 年 10 月 14 日第十三届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个 A × B × C（1 ≤ A, B, C ≤ 1000）的盒子按十字形展开：一列宽为 A，位于 x 从 C
到 C + A，自下而上是高为 B、C、B、C 的面；第三个面的两侧各有一块 C × B 的侧翼。
展开图上标出两个不同的点，坐标带两位小数。求盒子折好后两点间的距离，误差不超过
10⁻⁶。

时间限制：1 秒。内存限制：64 MB。

## 输入

A、B 和 C，然后是两个点 x y。

## 输出

距离。

## 样例

### 样例 1

输入:

```
2 2 2
3.00 3.00
5.00 5.00
```

输出:

```
1.4142135623730950
```

## 解法

把这一列的第三个面放在地面上：它的角 (C, B + C) 对应原点，其上的点 (x, y) 对应
(x − C, y − B − C, 0)。其余各面沿公共边从它折起，所以点到该边的距离就成了它的高
度：

- 左翼得到 (0, y − B − C, C − x)，右翼得到 (A, y − B − C, x − C − A)；
- 地面下方的面得到 (x − C, 0, B + C − y)，上方的面得到 (x − C, B, y − 2B − C)；
- 这一列最下面的面成为盒盖：(x − C, B − y, C)。

公共边上的点从哪个面算都得到同一位置。答案是两个位置之间的直线距离。以百分之一
为单位读入坐标，面的划分就是精确的。`O(1)`。

注意事项：

- 距离是穿过盒子的直线距离，而不是沿表面的距离（测试 01、03）；
- 展开图上两个不同的点可能被粘成盒子上的同一点，此时答案为 0（测试 02、05）；
- 这一列和两侧翼的远端都会成为盒盖或侧面的边（测试 04、07）。
