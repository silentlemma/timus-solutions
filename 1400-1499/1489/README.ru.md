# 1489. Точки на параллелепипеде

[Timus 1489](https://acm.timus.ru/problem.aspx?space=1&num=1489) · сложность 384 · geometry

Авторы оригинальной задачи — Владислав Исенбаев и Александр Торопов; XIII командный чемпионат школьников Свердловской области по программированию, 14 октября 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Коробку A × B × C (1 ≤ A, B, C ≤ 1000) вырезали развёрткой в форме
креста: столбец ширины A при x от C до C + A, в котором снизу вверх
идут грани высотой B, C, B и C, и две створки C × B по бокам третьей
грани. На развёртке отмечены две разные точки с двумя знаками после
точки. Нужно найти расстояние между ними после сборки коробки с
точностью 10⁻⁶.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

A, B и C, затем две точки как x y.

## Выходные данные

Расстояние.

## Примеры

### Пример 1

Ввод:

```
2 2 2
3.00 3.00
5.00 5.00
```

Вывод:

```
1.4142135623730950
```

## Решение

Положим третью грань столбца на пол: её угол (C, B + C) переходит в
начало координат, а точка (x, y) — в (x − C, y − B − C, 0). Четыре боковые
грани поднимаются от неё вдоль общих рёбер, поэтому расстояние точки
до этого ребра становится её высотой:

- левая створка даёт (0, y − B − C, C − x), правая —
  (A, y − B − C, x − C − A);
- грань под полом даёт (x − C, 0, B + C − y), грань над ним —
  (x − C, B, y − 2B − C);
- нижняя грань столбца складывается через грань под полом и становится
  крышкой: (x − C, B − y, C).

Точки на общем ребре получают одно и то же положение с любой грани.
Ответ — расстояние по прямой между двумя положениями. Если читать
координаты в сотых, грани определяются точно. `O(1)`.

Подводные камни:

- расстояние берётся по прямой сквозь коробку, а не по поверхности
  (тесты 01, 03);
- две разные точки развёртки могут склеиться в одну точку коробки, и
  тогда ответ 0 (тесты 02, 05);
- дальние концы столбца и створок становятся рёбрами крышки или боковых
  граней (тесты 04, 05).

## Оптимизированные решения

Версия Go читает координаты сразу в целых сотых и применяет те же формулы граней. Выбор грани и квадрат расстояния вычисляются точно. Вещественная арифметика нужна только для квадратного корня. Результат округляется до восьми знаков после запятой в буфере фиксированного размера. syscall.Read и syscall.Write используют стандартные дескрипторы, повторяют прерванные вызовы и дописывают частичные записи.

Принятые базовые реализации [1489_geometry.cpp](1489_geometry.cpp), [1489_geometry.java](1489_geometry.java), [1489_geometry.py](1489_geometry.py), [1489_geometry.rs](1489_geometry.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
