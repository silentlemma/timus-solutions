# 1475. 母鸡里亚巴

[Timus 1475](https://acm.timus.ru/problem.aspx?space=1&num=1475) · 难度 3694 · math

原题作者 Alexander Ipatov（创意来自 Alexander Toropov），出自 2006 年 8 月彼得罗扎沃茨克夏季集训的乌拉尔国立大学与奥廖尔国立技术大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

屋顶的左坡从 (0, 0) 经过 (l, H) 上升，而 (l, H) 不是屋顶的最高点。蛋从 (l, H)
上方高 h 处落下，重力加速度 g = 10，在坡面上发生弹性反弹（入射角等于反射角，即使
在最低点也是如此），如此反复直到离开屋顶。对至多 1000 组测试
（1 ≤ H, l ≤ 10¹⁰⁰，1 ≤ h ≤ 10）求撞击次数。

时间限制：3 秒。内存限制：64 MB。

## 输入

测试组数，然后是若干行 H l h。

## 输出

每组测试的撞击次数。

## 样例

### 样例 1

输入:

```
2
1 2 1
1 2 10
```

输出:

```
1
1
```

## 解法

设坡面与地面夹角为 a，取沿坡向下和垂直于坡面的两个坐标轴，重力的分量分别为沿坡
g·sin a 和垂直 −g·cos a。蛋以速度 v = √(2gh) 竖直落下；反弹后以 v·cos a 离开坡
面，同时以 v·sin a 沿坡向下运动。每次反弹后垂直方向的运动都相同，所以每次飞行
历时 2v/g，而沿坡的速度每次飞行增加 2v·sin a。把各次飞行相加，第一次撞击之后的
第 k 次撞击位于沿坡向下 4h·sin a·k(k + 1) 处。

从 (l, H) 到坡底的长度为 L = √(l² + H²)，且 sin a = H / L，所以这次撞击发生的条
件是 4hH·k(k + 1) ≤ l² + H²。令 q = ⌊(l² + H²) / (4hH)⌋，满足条件的最大 k 满足
(2k + 1)² ≤ 4q + 1，即 k = (⌊√(4q + 1)⌋ − 1) / 2，算上第一次撞击，答案为 k + 1。
对 D 位数字，每组测试 `O(D²)`。

注意事项：

- H 和 l 可达 10¹⁰⁰，平方可达 10²⁰⁰，所以必须全程使用精确整数；浮点数会在边界
  上出错（测试 02、gen3）；
- 恰好撞在坡底最低点也算一次（测试 02）；
- 即使 h 很大而坡很短，答案也至少为 1（测试 01、03）。

## 语言说明

- C++ 和 Rust 没有内置大整数：解答用 32 位的分段存储数字，从高位起逐位确定 k，只
  用乘法检查 4hH·k(k + 1) ≤ l² + H²；每组测试 `O(D³)`，对 100 位数字仍然很快。
- Java 8 没有 `BigInteger.sqrt`，所以平方根用牛顿法计算。
