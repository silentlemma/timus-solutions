## Задача

Левый скат крыши поднимается из (0, 0) через (l, H), и эта точка — не
вершина. Яйцо считают материальной точкой и отпускают с высоты h над
(l, H); оно падает с g = 10,
упруго отскакивает от ската (угол падения равен углу отражения, даже в
самой нижней точке) и так далее, пока не покинет крышу. Нужно посчитать
удары для не более чем 1000 тестов с 1 ≤ H, l ≤ 10¹⁰⁰ и 1 ≤ h ≤ 10.

Ограничение времени: 3 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Число тестов, затем строки H l h.

## Выходные данные

Число ударов для каждого теста.

## Примеры

### Пример 1

Ввод:

```
2
1 2 1
1 2 10
```

Вывод:

```
1
1
```

## Решение

Пусть скат наклонён к земле под углом a; возьмём оси вдоль него, вниз
по склону, и поперёк. Тогда у силы тяжести составляющие g·sin a вдоль
и −g·cos a поперёк. Яйцо прилетает со скоростью v = √(2gh) вертикально
вниз; после удара оно удаляется от ската со скоростью v·cos a и
движется вниз по склону со скоростью v·sin a. Движение поперёк после
каждого удара одно и то же, поэтому каждый полёт длится 2v/g, а
скорость вдоль ската за полёт растёт на 2v·sin a. Складывая полёты,
получаем, что k-й удар после первого приходится на 4h·sin a·k(k + 1)
вниз по склону.

Скат от (l, H) до низа имеет длину L = √(l² + H²), и sin a = H / L,
поэтому этот удар происходит, когда 4hH·k(k + 1) ≤ l² + H². При
q = ⌊(l² + H²) / (4hH)⌋ наибольшее такое k удовлетворяет
(2k + 1)² ≤ 4q + 1, то есть k = ⌊(⌊√(4q + 1)⌋ − 1) / 2⌋, а ответ — k + 1
с учётом первого удара. Асимптотики даны для квадратичной арифметики
и D-значных входных чисел.

Подводные камни:

- H и l доходят до 10¹⁰⁰, а их квадраты — до 10²⁰⁰, поэтому всё должно
  считаться в точных целых; вещественные числа промахиваются на границе
  (тест 02, gen3);
- удар ровно в самом низу ската тоже считается (тест 02);
- ответ не меньше 1, даже когда h велико, а скат короток (тесты 01, 03).

## Особенности языков

- В C++ и Rust нет встроенных больших чисел: решения хранят числа
  32-битными разрядами и подбирают k по битам сверху, проверяя
  4hH·k(k + 1) ≤ l² + H² одними умножениями; это `O(D³)` на тест, но
  для 101 цифры всё равно быстро.
- В Java 8 нет `BigInteger.sqrt`, поэтому корень считается методом
  Ньютона.
