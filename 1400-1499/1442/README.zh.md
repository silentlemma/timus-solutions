# 1442. 飞路粉

[Timus 1442](https://acm.timus.ru/problem.aspx?space=1&num=1442) · 难度 3019 · geometry

原题作者 Anton Botov（作者）和 Stanislav Vasiliev（题面），出自 2006 年 3 月 24–25 日第十届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

飞路粉从盖子中央的小孔倒进一个长 1 米、宽 50 厘米、高 50 厘米的箱子，堆成半径
r、高 h 的正圆锥（1 ≤ r ≤ 25，1 ≤ h ≤ 50）。箱底有一条细直缝，距底面圆心为 d
（1 ≤ d ≤ 25）。底面与缝相交的地方粉会漏出去，沿缝留下与圆锥休止角相同的平坦斜
坡。求剩下多少立方厘米的粉，保留小数点后四位。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

r、d 和 h，每行一个，单位为厘米。

## 输出

剩余的体积。

## 样例

### 样例 1

输入:

```
10
5
2
```

输出:

```
151.704483
```

## 解法

把底面圆心放在原点，缝放在直线 x = d 上。设坡度 k = h / r，距圆心 ρ 处圆锥表面的
高度是 k (r − ρ)，沿缝的斜坡高度是 k |x − d|；剩下的粉在两者中较低者之下。若
d ≥ r，缝碰不到底面，答案就是整个圆锥 π r² h / 3。否则减去损失的体积，即
k ((r − ρ) − |x − d|) 在其为正处的积分。

沿缝的方向把底面切片。固定 x，令 a = r − |x − d|；损失在 ρ < a，即
|y| < Y = √(a² − x²) 时为正，对 y 的积分有闭式，所以这一片损失
k (a Y − x² ln((a + Y) / |x|))。只有 (d − r) / 2 < x < (d + r) / 2 时才有切片。
剩下对 x 的积分用自适应 Simpson 方法计算，在切片函数有折点的 x = 0 和 x = d 处
分段；端点处的平方根正是自适应步长的用武之地。实际上每个光滑段需要
`O(log(1/ε))` 步。

注意事项：

- 缝与底面相切或不相交时没有损失（测试 02、06、10）；
- 缝靠近圆心时损失最多（测试 03、09）；
- 要求四位准确小数，普通的几百步 Simpson 在端点附近不太够。
