# 1442. Дымолётный порошок

## Задача

Дымолётный порошок насыпали в сундук длиной 1 м, шириной 50 см и
высотой 50 см через отверстие в центре крышки, и он образовал прямой
круговой конус радиуса r и высоты h (1 ≤ r ≤ 25, 1 ≤ h ≤ 50). По дну
проходит тонкая прямая щель на расстоянии d от центра основания
(1 ≤ d ≤ 25). Там, где основание пересекает щель, порошок высыпается,
оставляя вдоль щели плоские склоны с тем же углом осыпания, что у
конуса. Нужно найти в кубических сантиметрах с четырьмя знаками после
точки, сколько порошка осталось.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

r, d и h по одному в строке, в сантиметрах.

## Выходные данные

Оставшийся объём.

## Примеры

### Пример 1

Ввод:

```
10
5
2
```

Вывод:

```
151.704483
```

## Решение

Поместим центр основания в начало координат, а щель — на прямую x = d.
При уклоне k = h / r поверхность конуса над точкой на расстоянии ρ от
центра имеет высоту k (r − ρ), а склоны вдоль щели — высоту k |x − d|;
оставшийся порошок лежит под меньшей из двух. Если d ≥ r, щель не
задевает основание, и ответ — весь конус π r² h / 3. Иначе вычитаем
потерянный объём — интеграл k ((r − ρ) − |x − d|) там, где это
положительно.

Разрежем основание вдоль щели. Для фиксированного x пусть
a = r − |x − d|; потеря положительна при ρ < a, то есть при
|y| < Y = √(a² − x²), а интеграл по y берётся в явном виде, так что
срез теряет k (a Y − x² ln((a + Y) / |x|)). Срезы есть только при
(d − r) / 2 < x < (d + r) / 2. Оставшийся интеграл по x считается
адаптивным методом Симпсона с разбиением в точках x = 0 и x = d, где у
функции среза изломы; именно квадратный корень на концах делает
адаптивный шаг полезным. На практике `O(log(1/ε))` шагов на гладкий
кусок.

Подводные камни:

- если щель касается основания или проходит мимо, ничего не теряется
  (тесты 02, 06, 10);
- щель рядом с центром уносит больше всего (тесты 03, 09);
- нужны четыре точных знака, поэтому простого метода Симпсона с
  несколькими сотнями шагов у концов не совсем хватает.
