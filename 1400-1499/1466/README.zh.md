# 1466. 魔方阵

[Timus 1466](https://acm.timus.ru/problem.aspx?space=1&num=1466) · 难度 3123 · backtracking

原题作者 Alexander Ipatov，出自 2006 年 1 月彼得罗扎沃茨克冬季集训的乌拉尔国立大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

n² × n² 的方阵（1 ≤ n ≤ 3）被分成 n² 个 n × n 的小块。若方阵中填入 0 到 n² − 1
的数，左上角为 0，任何数在一行、一列或一个小块中都不重复，并且交换任意两个有公共
边的小块后这些规则仍然成立，就称它为魔方阵。已有 k 个格子填好。判断能否把方阵补
成魔方阵。

时间限制：1 秒。内存限制：64 MB。

## 输入

n 和 k，然后是 k 个三元组 a、b、c：列 a、行 b 和数 c。

## 输出

"YES" 或 "NO"。

## 样例

### 样例 1

输入:

```
2 4
0 0 0
1 2 1
2 1 2
3 3 3
```

输出:

```
NO
```

### 样例 2

输入:

```
2 0
```

输出:

```
YES
```

## 解法

交换规则严格限定了结构。交换左右相邻的两个小块不影响行，而列仍然合法，当且仅当
在小块内的每个列偏移 c 上，两个小块在这一列中的数集相同：一个块列中这些数集划分
了全部的数，所以邻块的数集必须恰好填到对应的位置。因此在同一块行里，所有小块的
列数集相同；同理，由上下交换，在同一块列里所有小块的行数集相同。于是每个数 v 在
块列 J 的每个小块中都占同一个行偏移 π_v(J)，在块行 I 的每个小块中都占同一个列偏
移 σ_v(I)，而且 π_v、σ_v 都是排列，因为该数在整个方阵的每行每列各出现一次。方阵
合法当且仅当对每一对 (I, J)，各数恰好各占 n × n 个位置 (π_v(J), σ_v(I)) 一次；
反过来，任何这样的族都满足所有规则。

不计数的名字，这样的族就是 n² 对 (π, σ) 组成的集合，一次小搜索就能全部找到：
n ≤ 2 时只有一个，n = 3 时有 28 个。对每个族，已填格子 (a, b, c) 指定了落在该格
的唯一一对，于是数 c 必须对应这一对。方阵可以补全，当且仅当存在某个族，使得没有
数被指定到两对、也没有一对被指定给两个数；其余的数可以任意占据剩下的对。角上的
0 当作又一个已填格子。

注意事项：

- 普通的合法数独通常不是魔方阵（测试 09）；
- 0 必须在角上，而给出的角可能不对（测试 06、15）。
