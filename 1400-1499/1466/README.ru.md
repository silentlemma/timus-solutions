# 1466. Магический квадрат

[Timus 1466](https://acm.timus.ru/problem.aspx?space=1&num=1466) · сложность 3123 · backtracking

Автор оригинальной задачи — Александр Ипатов; контест УрГУ на Петрозаводских зимних сборах, январь 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Квадрат из n² × n² клеток (1 ≤ n ≤ 3) разделён на n² малых квадратов
n × n. Он магический, если в нём стоят числа от 0 до n² − 1, в левой
верхней клетке 0, никакое число не повторяется в строке, столбце и малом
квадрате, и эти правила сохраняются после перестановки любых двух малых
квадратов с общей стороной. k клеток уже заполнены. Нужно выяснить,
можно ли дополнить квадрат до магического.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n и k, затем k троек a, b, c: столбец a, строка b и число c.

## Выходные данные

«YES» или «NO».

## Примеры

### Пример 1

Ввод:

```
2 4
0 0 0
1 2 1
2 1 2
3 3 3
```

Вывод:

```
NO
```

### Пример 2

Ввод:

```
2 0
```

Вывод:

```
YES
```

## Решение

Правило перестановок жёстко задаёт структуру. Перестановка двух
соседних по горизонтали малых квадратов сохраняет строки, а столбцы
остаются правильными, только если на каждом смещении c внутри малого
квадрата оба квадрата содержат в этом столбце одно и то же множество
чисел: множества одного столбца малых квадратов делят все числа, так
что множество соседа должно точно лечь на место партнёра. Значит, в
одной строке малых квадратов все квадраты имеют общие множества по
столбцам, и так же, по вертикальным перестановкам, в одном столбце
малых квадратов — общие множества по строкам. Поэтому у каждого числа v
есть смещение по строке π_v(J), которое оно занимает в каждом квадрате
столбца J, и смещение по столбцу σ_v(I) в каждом квадрате строки I, и
π_v, σ_v — перестановки, ведь число встречается по разу в каждой строке
и столбце всего квадрата. Квадрат правилен ровно тогда, когда для каждой
пары (I, J) числа занимают n × n позиций (π_v(J), σ_v(I)) по одному
разу; и наоборот, любое такое семейство удовлетворяет всем правилам.

С точностью до имён чисел такое семейство — множество из n² пар
(π, σ), и короткий перебор находит их все: одно при n ≤ 2 и 28 при
n = 3. Для каждого из них заполненная клетка (a, b, c) указывает
единственную пару, попадающую в эту клетку, и число c обязано получить
эту пару. Квадрат можно дополнить ровно тогда, когда для какого-нибудь
семейства ни одно число не привязано к двум парам и ни одна пара — к
двум числам; свободные числа занимают оставшиеся пары в любом порядке.
Угол с 0 считается ещё одной заполненной клеткой.

Подводные камни:

- обычное правильное судоку, как правило, не магическое (тест 09);
- 0 должен стоять в углу, а угол может быть задан неверно (тесты 06,
  15).
