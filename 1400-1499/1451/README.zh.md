# 1451. 小酒馆的故事

[Timus 1451](https://acm.timus.ru/problem.aspx?space=1&num=1451) · 难度 995 · geometry

原题作者 Ilya Grebnov、Dmitry Kovalioff 与 Nikita Rybak，出自 Timus Top Coders: Second Challenge。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

三位程序员住在三个不同的点上，坐标为 −1000 到 1000 的实数，小数点后至多七位。为
啤酒摊找一个到三座房子距离之和最小的位置；该和须与最小值在小数点后六位一致，任
何这样的位置都被接受。

时间限制：0.25 秒。内存限制：64 MB。

## 输入

一行中的 X1、Y1、X2、Y2、X3、Y3。

## 输出

啤酒摊的坐标。

## 样例

### 样例 1

输入:

```
1.1 3.1 5.1 1.1 4.1 5.1
```

输出:

```
3.37423161 3.38281356
```

## 解法

这就是三角形的费马点。若三角形某个角不小于 120°，答案就是这座房子本身：离开它
不会更好，因为另外两座房子的拉力夹角不小于 120°，合力小于每走一步的单位代价。三
座房子共线也属于这种情况，中间那座房子处的角是 180°。

否则，从最优点看每条边的视角都是 120°。它的重心坐标为 a / sin(A + 60°)、
b / sin(B + 60°)、c / sin(C + 60°)，其中 a、b、c 是角 A、B、C 的对边；由于每个
角都小于 120°，三个权都是正的。角度用叉积与点积的 atan2 求出，对非常扁的三角形
也保持精确，所求点就是房子坐标的加权平均。`O(1)`。

注意事项：

- 三座房子共线（测试 02、12、13）；
- 角度略小于和略大于 120°（测试 05、10、11）；
- 针一样细的三角形，余弦会损失精度（测试 08、13）。
