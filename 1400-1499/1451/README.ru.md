# 1451. Басня о ларьке

[Timus 1451](https://acm.timus.ru/problem.aspx?space=1&num=1451) · сложность 994 · geometry

Авторы оригинальной задачи — Илья Гребнов, Дмитрий Ковалёв и Никита Рыбак; Timus Top Coders: Second Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Три программиста живут в трёх различных точках с вещественными
координатами от −1000 до 1000, заданными не более чем с семью знаками
после точки. Нужно найти место для пивного ларька с наименьшей суммой
расстояний до трёх домов; сумма должна совпадать с минимальной до шести
знаков, и принимается любое такое место.

Ограничение времени: 0.25 секунды. Ограничение памяти: 64 МБ.

## Входные данные

X1, Y1, X2, Y2, X3, Y3 в одной строке.

## Выходные данные

Координаты ларька.

## Примеры

### Пример 1

Ввод:

```
1.1 3.1 5.1 1.1 4.1 5.1
```

Вывод:

```
3.37423161 3.38281356
```

## Решение

Это точка Ферма треугольника. Если один из углов треугольника не меньше
120°, ответ — сам этот дом: уходить от него невыгодно, потому что два
других дома тянут под углом 120° или больше, и их тяга в сумме не больше
единичной цены шага. Три дома на одной прямой попадают в этот случай с
углом 180° у среднего дома.

Иначе из лучшей точки каждая сторона видна под углом 120°. Её
барицентрические координаты — a / sin(A + 60°), b / sin(B + 60°),
c / sin(C + 60°), где a, b, c — стороны против углов A, B, C; все три
веса положительны, так как каждый угол меньше 120°. Углы берутся через
atan2 от векторного и скалярного произведений, что остаётся точным и
для очень плоских треугольников, а точка — взвешенное среднее домов.
`O(1)`.

Подводные камни:

- три дома на одной прямой (тесты 02, 12);
- углы чуть меньше и чуть больше 120° (тесты 05, 10, 11);
- игольчато тонкий треугольник, где косинусы теряют точность (тесты 08,
  13).
