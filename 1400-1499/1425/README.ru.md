# 1425. Ферзь 2

[Timus 1425](https://acm.timus.ru/problem.aspx?space=1&num=1425) · сложность 1680 · hashing

Авторы оригинальной задачи — Никита Рыбак, Дмитрий Ковалёв и Илья Гребнов; Timus Top Coders: First Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Доска — N-мерный куб со стороной S клеток (1 ≤ N ≤ 5, 2 ≤ S ≤ 100).
Ладья ходит на любое ненулевое число клеток по одной координате; слон —
на одно и то же ненулевое число клеток по всем N координатам сразу, по
каждой в любую сторону; ферзь ходит как любая из них. Ферзь стоит на
пустой доске в клетке (C[1], …, C[N]). Нужно посчитать клетки, где он
может оказаться ровно через два хода.

Ограничение времени: 3 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N и S, затем N координат ферзя.

## Выходные данные

Число клеток.

## Примеры

### Пример 1

Ввод:

```
3 3
1 2 3
```

Вывод:

```
27
```

В примере первый ход может вести в (2, 2, 3), (3, 2, 3), (1, 1, 3),
(1, 3, 3), (1, 2, 1) или (1, 2, 2) как ладья либо в (2, 3, 2) или
(2, 1, 2) как слон.

## Решение

На доске может быть 10¹⁰ клеток, но ответ невелик: из центра самой
большой доски он равен 858 180. Поэтому клетки порождаются и считаются
в хеш-множестве. У ферзя 2N ладейных направлений и 2^N слоновых (в
одномерном случае это одни и те же). Клетки после первого хода — все
клетки вдоль каждого направления от начальной. Из каждой из них снова
идём по всем направлениям и добавляем в множество каждую клетку на
пути; сама клетка первого хода из своих лучей не добавляется, так что
она учитывается, только если её достигает другой первый ход.

Если нумеровать клетку как число с цифрами C[i] - 1 в системе
счисления по основанию S, каждый луч становится арифметической
прогрессией номеров, то есть целым диапазоном. Компилируемые решения
кладут номера в таблицу с открытой адресацией на 2²¹ ячеек; Python
добавляет в множество целые диапазоны. Порождается не больше примерно
4,3·10⁶ посещений клеток.

Подводные камни:

- ферзь может вернуться в свою клетку (тест 01);
- на линии из двух клеток за два хода достижима только начальная
  (тест 02);
- в одномерном случае ходы слона и ладьи совпадают (тесты 09, 13).

## Особенности языков

- Python добавляет каждый луч в множество одним `range`, так что цикл
  по клеткам идёт внутри кода множества. Все достижимые клетки вместе
  с сохранёнными лучами занимают больше 64 МБ, поэтому клетки считаются
  за восемь проходов, в каждом из которых остаются только клетки с
  заданным остатком первой координаты, отсчитываемой от нуля, по модулю 8:
  для каждого луча это снова один `range`. Тесты жюри занимают до 1,8 с
  и 33 МБ.
