# 1425. 皇后 2

[Timus 1425](https://acm.timus.ru/problem.aspx?space=1&num=1425) · 难度 1713 · hashing

原题作者 Nikita Rybak、Dmitry Kovalioff 与 Ilya Grebnov，出自 Timus Top Coders: First Challenge。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

棋盘是每边 S 格的 N 维立方体（1 ≤ N ≤ 5，2 ≤ S ≤ 100）。车沿一个坐标走任意非零
格；象在全部 N 个坐标上同时走相同的非零格数，每个坐标方向任意；皇后可以按两者之
一走。皇后位于空棋盘的 (C[1], …, C[N])。求恰好走两步后它可能所在的格子数。

时间限制：3 秒。内存限制：64 MB。

## 输入

N 和 S，然后是皇后的 N 个坐标。

## 输出

格子数。

## 样例

### 样例 1

输入:

```
3 3
1 2 3
```

输出:

```
27
```

样例中第一步可以作为车走到 (2, 2, 3)、(3, 2, 3)、(1, 1, 3)、(1, 3, 3)、
(1, 2, 1) 或 (1, 2, 2)，或作为象走到 (2, 3, 2) 或 (2, 1, 2)。

## 解法

棋盘可能有 10¹⁰ 个格子，但答案很小：在最大棋盘的中心为 858 180。所以把格子生成
出来，用哈希集合计数。皇后有 2N 个车的方向和 2^N 个象的方向（一维时两者相同）。
第一步后的格子是从起点沿各方向的所有格子。再从其中每一个格子出发沿所有方向走，
把途经的每个格子加入集合；第一步所在的格子不会从它自己的射线加入，所以只有当另
一个第一步能到达它时才被计入。

把格子编号为以 S 为基数、各坐标为数位的数，每条射线就成为编号的等差数列，即一个
完整的区间。编译型语言的解法把编号放入 2²¹ 个槽位的开放寻址表；Python 则把整个
区间加入集合。总共生成约 (2N + 2^N)² · S 个格子，最多约 4·10⁶。

注意事项：

- 皇后可以回到自己的格子（测试 01）；
- 在只有两格的直线上，两步只能回到起点（测试 02）；
- 一维时象和车的走法相同（测试 09、13）。

## 各语言说明

- Python 把每条射线作为一个 `range` 加入集合，因此按格子的循环在集合的代码内部进行。所有可达格子放进一个集合要超过 64 MB，所以分八遍计数，每遍只保留第一个坐标模 8 余数为给定值的格子：沿一条射线它们是每隔八个的格子，仍是一个 `range`。评测的测试最多用 1.8 秒和 33 MB。
