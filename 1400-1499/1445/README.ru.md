# 1445. Рождественские подарки

## Задача

Друзья Гарри образуют N компаний (1 ≤ N ≤ 500) размером от 1 до 500.
Гарри встречается с друзьями по одному, вручает каждому подарок и
получает подарок взамен. Другу можно вручить подарок, приготовленный
заранее, или полученный от участника другой компании, но не от своей.
Нужно найти наименьшее число подарков, которое придётся приготовить,
когда порядок встреч выбирает Гарри и когда порядок наихудший.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем размеры компаний.

## Выходные данные

Лучшее и худшее число приготовленных подарков.

## Примеры

### Пример 1

Ввод:

```
4
3 7 3 2
```

Вывод:

```
1 7
```

## Решение

Пусть m — размер самой большой компании, а S — число друзей. Каждый
обмен возвращает один подарок, поэтому у Гарри всегда столько подарков,
сколько было приготовлено. Участникам самой большой компании, а их m,
нужны подарки извне, а извне вообще приходит только S − m подарков,
так что приготовить нужно не меньше 2m − S, и в любом случае хотя бы
один. Этого хватает: при 2m > S сначала 2m − S участников самой большой
компании получают приготовленные подарки, а дальше чередуем её с
остальными. Иначе выбираем порядок без соседей из одной компании;
хватает одного подарка.

В худшем порядке первой идёт самая большая компания; её подарки внутри
неё бесполезны, поэтому нужно m подарков. Их и хватает: у Гарри m
подарков, из них от одной компании не больше, чем её участников уже
встречено, так что для каждого ещё ждущего участника найдётся подарок
извне. `O(N)`.

Подводные камни:

- для одной компании в обоих случаях все подарки приготовлены заранее
  (тесты 02, 03);
- одного подарка хватает, когда самая большая компания не больше
  остальных плюс один (тесты 05, 06, 08).
