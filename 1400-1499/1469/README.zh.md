# 1469. 禁止吸烟！

[Timus 1469](https://acm.timus.ru/problem.aspx?space=1&num=1469) · 难度 899 · geometry

原题作者 Ilya Shishkov，出自 2006 年 8 月彼得罗扎沃茨克夏季集训的乌拉尔国立大学与奥廖尔国立技术大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

桌上有 N 支香烟（1 ≤ N ≤ 50000），每支是长度非零、端点为 −10000 到 10000 之间整
数的线段。只能拿走与另一支接触或相交的香烟。输出 "YES" 和两支有公共点的香烟编
号；若不存在，输出 "NO"。

时间限制：1.5 秒。内存限制：64 MB。

## 输入

N，然后 N 行 x1 y1 x2 y2。

## 输出

"YES" 和两个编号，或 "NO"。任何相交的一对都被接受。

## 样例

### 样例 1

输入:

```
2
0 0 2 2
0 2 2 0
```

输出:

```
YES
1 2
```

### 样例 2

输入:

```
2
0 0 0 5
5 0 5 10
```

输出:

```
NO
```

## 解法

这是 Shamos–Hoey 扫描线。让一条竖直线从左向右移动，把它穿过的线段按高度有序地
保存在列表中。只要还没有两条线段相遇，这个顺序就不会改变，而最左边的相遇点总是
在列表中相邻的两条线段之间。所以只需在插入时把新线段与相邻线段比较，并在某条线
段离开时比较新成为相邻的两条。

退化情况需要小心。先用 x' = 20001 x + y 对平面做错切：不同整数端点的 x' 不同，所以
没有竖直线段，而接触与相交关系不变。在同一个 x' 上，先插入从这里开始的线段，再
删除在这里结束的线段，穿过同一点的线段按斜率排序。所有比较都用精确的整数叉积，
相遇判断包括端点接触和共线重叠。列表是一个有序数组：插入和删除可能移动 N 个元素。
共 `O(N log N)` 次比较，总时间为 `O(N^2)`。

注意事项：

- 接触也算：端点落在另一支香烟上、两个端点重合、共线重叠（测试 04、05、07、12）；
- 竖直的香烟由错切处理（测试 07、11）；
- 对 50000 支香烟检查所有线段对太慢。
