# 1469. Не курить!

[Timus 1469](https://acm.timus.ru/problem.aspx?space=1&num=1469) · сложность 902 · geometry

Автор оригинальной задачи — Илья Шишков; контест УрГУ и ОрёлГТУ на Петрозаводских летних сборах, август 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N сигарет (1 ≤ N ≤ 50000) лежат на столе отрезками ненулевой длины с
целыми концами от −10000 до 10000. Взять можно только сигарету, которая
касается другой или пересекает её. Нужно вывести «YES» и номера двух
сигарет с общей точкой или «NO», если таких нет.

Ограничение времени: 1.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк x1 y1 x2 y2.

## Выходные данные

«YES» и два номера или «NO». Принимается любая пересекающаяся пара.

## Примеры

### Пример 1

Ввод:

```
2
0 0 2 2
0 2 2 0
```

Вывод:

```
YES
1 2
```

### Пример 2

Ввод:

```
2
0 0 0 5
5 0 5 10
```

Вывод:

```
NO
```

## Решение

Это заметание Шеймоса — Хоя. Ведём вертикальную прямую слева направо и
храним пересекаемые ею отрезки в списке, упорядоченном по высоте. Пока
никакие два отрезка не встретились, этот порядок не меняется, а первая
слева точка встречи всегда лежит между двумя соседями в списке. Поэтому
достаточно проверять новый отрезок с соседями при вставке и два
отрезка, ставшие соседями, когда один уходит.

Вырожденные случаи требуют аккуратности. Сначала плоскость
сдвигается: x' = 20001 x + y; у каждой точки свой x', поэтому
вертикальных отрезков нет, а касания и пересечения сохраняются. При
одном x' отрезки, начинающиеся там, вставляются раньше, чем удаляются
заканчивающиеся, а отрезки через одну точку упорядочиваются по наклону.
Все сравнения используют точные целочисленные векторные произведения,
а проверка встречи учитывает касание концов и наложение на одной прямой.
Список — отсортированный массив: вставка в него — короткий сдвиг
памяти, достаточно быстрый для 50000 отрезков. `O(N log N)` сравнений.

Подводные камни:

- касание считается: конец на другой сигарете, два конца в одной точке,
  наложение на одной прямой (тесты 04, 05, 07, 12);
- вертикальные сигареты, с которыми справляется сдвиг (тесты 07, 11);
- перебор всех пар слишком медленный для 50000 сигарет.
