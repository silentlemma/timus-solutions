# 1495. Раз-два, раз-два 2

[Timus 1495](https://acm.timus.ru/problem.aspx?space=1&num=1495) · сложность 340 · bfs

Автор оригинальной задачи — Игорь Чевдарь; XIII командный чемпионат школьников Свердловской области по программированию, 14 октября 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно найти наименьшее число, записанное только цифрами 1 и 2, которое
делится на N (1 ≤ N ≤ 10⁶). Если такого нет или оно длиннее 30 цифр,
вывести «Impossible».

Ограничение времени: 2 секунды. Ограничение памяти: 256 МБ.

## Входные данные

N.

## Выходные данные

Число или «Impossible».

## Примеры

### Пример 1

Ввод:

```
5
```

Вывод:

```
Impossible
```

### Пример 2

Ввод:

```
8
```

Вывод:

```
112
```

## Решение

Для продолжения префикса важен только остаток по модулю N, поэтому ищем
в ширину по остаткам. Начинаем с чисел 1 и 2, а из числа с остатком r
идём в r·10 + 1, затем в r·10 + 2. Более короткие числа достигаются
раньше, а внутри одной длины очередь идёт в порядке возрастания, так что
первое число, пришедшее в остаток, — наименьшее с этим остатком; любое
следующее с ним, как и все его продолжения, было бы больше. Каждый из N
остатков хранится один раз с последней цифрой и родителем, и ответ
восстанавливается по родителям, как только появляется остаток 0. Числа
перестают расти на 30 цифрах. `O(N)`.

Подводные камни:

- число из 1 и 2 никогда не кончается на 0 или 5, так что кратные 5
  невозможны (тесты 01, 07, 09);
- ответ может быть ровно из 30 цифр, как для 999999, и это ещё
  допустимо (тест 05);
- r·10 + d остаётся меньше 10⁷, а сам ответ может выходить за диапазон
  64-битных целых типов; восстанавливайте его по цифрам (тесты 05, 08).

## Оптимизированные решения

`1495_bfs_optimized.py`. Сохраняются BFS по остаткам с порядком цифр 1, затем 2, упакованный 32-битный код предка/цифры и 32-битная очередь. Две дуги раскрыты явно: (10*r+1)%N считается один раз, остаток для цифры 2 получается прибавлением единицы с циклической поправкой. Границы слоёв ограничивают длину 30 цифрами; порядок посещения даёт кратчайший и затем лексикографически минимальный ответ. Кратность пяти остаётся точным признаком невозможности. Работа и память O(N) при данном ограничении длины. PyPy использует 11808 КБ вместо прежних 11404 КБ, время падает с 0.921 до 0.14 с; небольшой рост памяти указан явно. Учебный BFS сохранён. Упомянутый прежний запуск 0.921 с / 11404 КБ был на CPython 3.12, выбранный — на PyPy 3.10. Меняются код и интерпретатор, поэтому сравниваются парные запуски, а не изолированное влияние раскрытия дуг.

Accepted точного исходника PyPy 3.10 №11326708: 0.14 с / 11808 КБ. Сравнение, сохранённое 2026-11-20 для актуальных компиляторов семейства: место по времени 1/19, по памяти 1/19. Память не меньше 1024 КБ: требуются оба строгих рейтинга, оба пройдены.

- `1495_bfs_optimized.py`: 0.14 s / 11808 KB; сохранённая учебная база `1495_bfs.py` (Python 3.12 x64): 0.906 s / 62744 KB; изменение времени -84.5%; изменение памяти -81.2%.

Версии C++, Go и Python используют тот же поиск в ширину. На остаток приходится одна 32-битная ячейка. Ноль означает, что остаток ещё не посещён, иначе старшие биты хранят предшественника плюс один, а младший бит — цифру минус один. Очередь тоже хранит 32-битные числа. Длина определяется по границам слоёв, поэтому глубину для каждого остатка хранить не нужно.

Сохранённые принятые базы [1495_bfs.go](1495_bfs.go), [1495_bfs.java](1495_bfs.java), [1495_bfs.rs](1495_bfs.rs) также проходят строгий критерий первых десяти мест или топ 15% по требуемым метрикам в сохранённом сравнении. Они используются без одинаковых исходников. Остальные учебные версии сохранены; звёздочка означает отдельную рейтинговую цель языка.
