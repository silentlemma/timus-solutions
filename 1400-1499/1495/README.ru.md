# 1495. Раз-два, раз-два 2

[Timus 1495](https://acm.timus.ru/problem.aspx?space=1&num=1495) · сложность 340 · bfs

## Задача

Нужно найти наименьшее число, записанное только цифрами 1 и 2, которое
делится на N (1 ≤ N ≤ 10⁶). Если такого нет или оно длиннее 30 цифр,
вывести «Impossible».

Ограничение времени: 2 секунды. Ограничение памяти: 256 МБ.

## Входные данные

N.

## Выходные данные

Число или «Impossible».

## Примеры

### Пример 1

Ввод:

```
5
```

Вывод:

```
Impossible
```

### Пример 2

Ввод:

```
8
```

Вывод:

```
112
```

## Решение

Для продолжения префикса важен только остаток по модулю N, поэтому ищем
в ширину по остаткам. Начинаем с чисел 1 и 2, а из числа с остатком r
идём в r·10 + 1, затем в r·10 + 2. Более короткие числа достигаются
раньше, а внутри одной длины очередь идёт в порядке возрастания, так что
первое число, пришедшее в остаток, — наименьшее с этим остатком; любое
следующее с ним, как и все его продолжения, было бы больше. Каждый из N
остатков хранится один раз с последней цифрой и родителем, и ответ
восстанавливается по родителям, как только появляется остаток 0. Числа
перестают расти на 30 цифрах. `O(N)`.

Подводные камни:

- число из 1 и 2 никогда не кончается на 0 или 5, так что кратные 5
  невозможны (тесты 01, 07, 09);
- ответ может быть ровно из 30 цифр, как для 999999, и это ещё
  допустимо (тест 05);
- r·10 + d остаётся меньше 10⁷, а само число не помещается ни в какой
  целый тип (тесты 05, 08).
