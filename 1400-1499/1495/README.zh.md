# 1495. 一二，一二 2

## 任务

求只由数字 1 和 2 组成、能被 N（1 ≤ N ≤ 10⁶）整除的最小的数。若不存在或其长度超
过 30 位，输出 "Impossible"。

时间限制：2 秒。内存限制：256 MB。

## 输入

N。

## 输出

这个数，或 "Impossible"。

## 样例

### 样例 1

输入:

```
5
```

输出:

```
Impossible
```

### 样例 2

输入:

```
8
```

输出:

```
112
```

## 解法

对于一个前缀之后能接什么，只有它模 N 的余数有关，所以在余数上做广度优先搜索。从
1 和 2 出发，从余数为 r 的数走向 r·10 + 1，再走向 r·10 + 2。较短的数先被到达，同
一长度内队列保持数值顺序，因此第一个到达某余数的数就是具有该余数的最小数；之后再
到达它的数以及其所有延伸都更大。N 个余数各存一次，记下最后一位和父节点，一旦出现
余数 0 就沿父节点回溯得到答案。数字长度到 30 位就不再增长。`O(N)`。

注意事项：

- 由 1 和 2 组成的数末位不会是 0 或 5，所以 5 的倍数都不可能（测试 01、07、09）；
- 答案可以恰好 30 位，例如 999999，这仍然是允许的（测试 05）；
- r·10 + d 始终小于 10⁷，但这个数本身放不进任何整数类型（测试 05、08）。
