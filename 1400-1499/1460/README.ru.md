# 1460. Проводники

[Timus 1460](https://acm.timus.ru/problem.aspx?space=1&num=1460) · сложность 3931 · geometry

Автор оригинальной задачи — Дмитрий Иванков; контест УрГУ на Петрозаводских зимних сборах, январь 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Четыре вывода на плате с целыми координатами от −200 до 200 нужно
соединить прямыми отрезками провода; разрешено добавить где угодно до
трёх вспомогательных выводов. Для каждого из N наборов (1 ≤ N ≤ 100)
нужно найти наименьшую суммарную длину провода с не менее чем четырьмя
знаками после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N наборов из четырёх точек; пустые строки между наборами необязательны.

## Выходные данные

Наименьшая длина для каждого набора, по одной в строке.

## Примеры

### Пример 1

Ввод:

```
2
0 0
2 0
2 1
3 0

0 0
0 1
1 0
1 1
```

Вывод:

```
3.9093
2.7321
```

## Решение

Это евклидово дерево Штейнера для четырёх точек. В оптимальном дереве
каждый вспомогательный вывод соединяет ровно три провода под углами
120°, поэтому таких выводов не больше двух, и оптимальное дерево имеет
одну из трёх полных форм, возможно вырожденную: выводы {a, b} висят на одной
вспомогательной точке, {c, d} — на другой, а две вспомогательные точки
соединены. Для такой формы вспомогательные точки даёт построение
Мелзака: заменим a и b вершиной e равностороннего треугольника на ab;
тогда вторая точка — точка Ферма для e, c и d, а первая — точка Ферма
для a, b и второй (точки Ферма как в задаче 1451). Пробуются обе
стороны ab для вершины и оба порядка для каждого разбиения на пары.

Когда форма на самом деле не подходит, построение может дать странные
точки, поэтому учитывается всегда реальная длина дерева, построенного на
них, а не формула |e e'|; тогда каждый кандидат — настоящее дерево и
ни один не окажется меньше оптимума. Вырожденные формы добавляются
напрямую: минимальное остовное дерево и одна вспомогательная точка в
точке Ферма трёх выводов, а четвёртый вывод соединён с ближайшей из
четырёх точек. Ответ — наименьший кандидат. `O(1)` на набор.

Подводные камни:

- в оптимальном дереве может не быть вспомогательных точек (выводы на
  прямой), быть одна или две (тесты 01, 02);
- квадрату нужны две вспомогательные точки, а не диагонали (пример 1, набор 2);
- неприменимое построение не должно давать длину меньше настоящего
  оптимума, поэтому и измеряются реальные длины деревьев.
