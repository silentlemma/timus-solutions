# 1460. 导线

[Timus 1460](https://acm.timus.ru/problem.aspx?space=1&num=1460) · 难度 3928 · geometry

原题作者 Dmitry Ivankov，出自 2006 年 1 月彼得罗扎沃茨克冬季集训的乌拉尔国立大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

板上有四个引脚，坐标为 −200 到 200 的整数，要用直线段导线把它们全部连通；可以在
任意位置添加至多三个辅助引脚。对 N 组（1 ≤ N ≤ 100）中的每一组，求导线的最小总
长度，小数点后至少四位。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N 组，每组四个点，组之间用空行分隔。

## 输出

每组一行，输出最小长度。

## 样例

### 样例 1

输入:

```
2
0 0
2 0
2 1
3 0

0 0
0 1
1 0
1 1
```

输出:

```
3.9093
2.7321
```

## 解法

这是四点的欧几里得斯坦纳树。最优树中每个辅助点恰好以 120° 连接三段导线，所以辅
助点至多两个，而任何树都是三种完全形态之一的退化情形：引脚 {a, b} 挂在一个辅助
点上，{c, d} 挂在另一个上，两个辅助点相连。对这样的形态，Melzak 构造给出辅助
点：把 a 和 b 换成 ab 上等边三角形的顶点 e；第二个辅助点就是 e、c、d 的费马点，
第一个是 a、b 和第二个辅助点的费马点（费马点的求法同第 1451 题）。顶点取 ab 的两
侧都试，每种配对的两种方向也都试。

当这种形态并不真正适用时，构造可能给出奇怪的点，所以计算的总是用这些点实际搭成
的树的长度，而不是公式 |e e'|；这样每个候选都是真实的树，不会低于最优值。退化形
态直接加入：最小生成树，以及在三个引脚的费马点处放一个辅助点、第四个引脚连到四个
点中最近的一个。答案是最小的候选。每组 `O(1)`。

注意事项：

- 最优树可能没有辅助点（引脚共线），也可能有一个或两个（测试 01、02）；
- 正方形需要两个辅助点，而不是两条对角线（样例 2）；
- 不适用的构造绝不能给出低于真实最优值的长度，所以要测量真实的树长。
