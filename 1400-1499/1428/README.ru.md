# 1428. Джедайский ребус

[Timus 1428](https://acm.timus.ru/problem.aspx?space=1&num=1428) · сложность 498 · math

Авторы оригинальной задачи — Илья Гребнов, Дмитрий Ковалёв и Никита Рыбак; Timus Top Coders: First Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны A, B и C (1 ≤ A, B, C ≤ 32), причём C − 1 делится и на A, и на B.
Нужно найти целые X, Y и Z от 1 до 10⁵⁰, для которых X^A + Y^B = Z^C.
Подходит любая такая тройка.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

A, B и C.

## Выходные данные

X, Y и Z по одному в строке.

## Проверка

В репозитории используется проверяющая программа, принимающая любой вывод с указанными свойствами. Выводятся ровно три целых X,Y,Z из [1,10^50]; проверяется равенство X^A+Y^B=Z^C с точными целочисленными степенями.

## Примеры

### Пример 1

Ввод:

```
2 2 3
```

Вывод:

```
10
5
5
```

## Решение

Две равные половины дают целое: 2^(C−1) + 2^(C−1) = 2^C. Раз A и B
делят C − 1, возьмём X = 2^((C−1)/A) и Y = 2^((C−1)/B), тогда
X^A = Y^B = 2^(C−1), и Z = 2. Числа не больше 2³¹, далеко меньше 10⁵⁰,
и помещаются в 64 бита. `O(1)`.

Подводные камни:

- при C = 1 получаем X = Y = 1 и 1 + 1 = 2¹ (тесты 03, 08);
- в примере выведена другая тройка, поэтому тесты проверяет чекер с
  длинными числами (тест 01).

## Оптимизированные решения

Go использует те же степени двойки: X=2^((C−1)/A), Y=2^((C−1)/B), Z=2. Показатели от нуля до 31, поэтому хватает сдвигов uint64. Читаем три числа через стандартный дескриптор ввода и собираем три строки из десятичных цифр в буфере на 64 байта. Время и память O(1). Все 1537 допустимых троек проверены точным целочисленным возведением в степень. Для остальных четырёх языков подходят базовые версии.

Принятые базовые реализации [1428_math.cpp](1428_math.cpp), [1428_math.java](1428_math.java), [1428_math.py](1428_math.py), [1428_math.rs](1428_math.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.

`1428_math_optimized.java`. Java сохраняет алгоритм и структуры данных, описанные для простой версии. Фиксированный байтовый буфер и FastInput заменяют Scanner с его регулярными выражениями и обработкой локали. Целые числа разбираются напрямую; строки при необходимости по-прежнему декодируются из UTF-8, десятичные токены явно преобразуются в числа. Предварительный просмотр хранит токен только при необходимости. Алгоритм вывода не меняется. Убираются накладные расходы универсального разбора; в таблице указана работа алгоритма, а чтение линейно по числу байтов с ограниченным буфером.

По сравнению с `1428_math.java`: время 0.156 s → 0.109 s; память 1600 KB → 472 KB.
