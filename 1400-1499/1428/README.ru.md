# 1428. Джедайский ребус

[Timus 1428](https://acm.timus.ru/problem.aspx?space=1&num=1428) · сложность 499 · math

Авторы оригинальной задачи — Илья Гребнов, Дмитрий Ковалёв и Никита Рыбак; Timus Top Coders: First Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны A, B и C (1 ≤ A, B, C ≤ 32), причём C − 1 делится и на A, и на B.
Нужно найти целые X, Y и Z от 1 до 10⁵⁰, для которых X^A + Y^B = Z^C.
Подходит любая такая тройка.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

A, B и C.

## Выходные данные

X, Y и Z по одному в строке.

## Примеры

### Пример 1

Ввод:

```
2 2 3
```

Вывод:

```
10
5
5
```

## Решение

Две равные половины дают целое: 2^(C−1) + 2^(C−1) = 2^C. Раз A и B
делят C − 1, возьмём X = 2^((C−1)/A) и Y = 2^((C−1)/B), тогда
X^A = Y^B = 2^(C−1), и Z = 2. Числа не больше 2³¹, далеко меньше 10⁵⁰,
и помещаются в 64 бита. `O(1)`.

Подводные камни:

- при C = 1 получаем X = Y = 1 и 1 + 1 = 2¹ (тесты 03, 08);
- в примере выведена другая тройка, поэтому тесты проверяет чекер с
  длинными числами (тест 01).
