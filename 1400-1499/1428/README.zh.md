# 1428. 绝地之谜

[Timus 1428](https://acm.timus.ru/problem.aspx?space=1&num=1428) · 难度 498 · math

原题作者 Ilya Grebnov、Dmitry Kovalioff 与 Nikita Rybak，出自 Timus Top Coders: First Challenge。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给出 A、B、C（1 ≤ A, B, C ≤ 32），且 C − 1 能被 A 和 B 整除。求 1 到 10⁵⁰ 之间的
整数 X、Y、Z，使 X^A + Y^B = Z^C。任何这样的三元组都可以。

时间限制：1 秒。内存限制：64 MB。

## 输入

A、B 和 C。

## 输出

X、Y 和 Z，每行一个。

## 评测方式

仓库使用语义检查器，接受满足以下条件的任意输出。 输出恰好三个位于 [1,10^50] 的整数 X,Y,Z；检查器以精确整数幂验证 X^A+Y^B=Z^C。

## 样例

### 样例 1

输入:

```
2 2 3
```

输出:

```
10
5
5
```

## 解法

两个相等的一半合成一个整体：2^(C−1) + 2^(C−1) = 2^C。因为 A 和 B 整除 C − 1，取
X = 2^((C−1)/A)、Y = 2^((C−1)/B)，于是 X^A = Y^B = 2^(C−1)，再取 Z = 2。这些数不
超过 2³¹，远小于 10⁵⁰，放得进 64 位整数。`O(1)`。

注意事项：

- C = 1 时 X = Y = 1，且 1 + 1 = 2¹（测试 03、08）；
- 样例输出的是另一组三元组，所以测试使用带大整数的检查器（测试 01）。

## 优化解法

Go 保持 X=2^((C−1)/A)、Y=2^((C−1)/B)、Z=2。指数在 0…31，uint64 移位足够。通过标准输入句柄读取三个整数，将十进制数字写入 64 字节输出缓冲区。时间和空间均为 O(1)。全部 1537 个合法三元组均以精确整数幂验证。其余四种语言沿用符合条件的基础版。
