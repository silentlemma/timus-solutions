# 1483. Настольный футбол

## Задача

N команд (1 ≤ N ≤ 1000) играют круговой турнир: каждая пара встречается
один раз, за победу дают 3 очка, за ничью 1, за поражение 0. Команды с
равными очками делят место. Одна команда заняла первое место, другая —
последнее. Нужно найти наименьшее число очков у первой команды и
наибольшее — у последней.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

Два числа.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
1 1
```

## Решение

Каждый матч приносит не меньше 2 очков (ничья) и не больше 3 (победа).
Значит, всего у команд не меньше N(N − 1) очков, и у лидера не меньше
среднего N − 1; если все матчи сыграны вничью, у каждой команды ровно
N − 1.

Всего у команд не больше 3·N(N − 1)/2 очков, так что у последней не
больше ⌊3(N − 1)/2⌋. При нечётном N каждая команда может выиграть ровно
половину своих N − 1 матчей, и у всех будет 3(N − 1)/2. При чётном N
пусть команды сыграют вничью парами, по одной ничьей у каждой, а
остальные матчи разделятся так, чтобы каждая выиграла половину своих
N − 2 других: у всех будет 3(N − 2)/2 + 1 = ⌊3(N − 1)/2⌋. `O(1)`.

Подводные камни:

- при одной команде матчей нет: 0 и 0 (тест 02);
- при чётном N для оценки нужна одна ничья у каждой команды, ведь без
  ничьих очки кратны 3 (тест 04);
- оба ответа оптимизируются по отдельности, а не в одном турнире (тест 03).
