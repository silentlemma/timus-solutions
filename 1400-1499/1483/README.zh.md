# 1483. 桌上足球

[Timus 1483](https://acm.timus.ru/problem.aspx?space=1&num=1483) · 难度 384 · math

原题作者 Sergey Pupyrev，出自 2006 年 10 月 7 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 支队伍（1 ≤ N ≤ 1000）进行单循环赛：每两队交手一次，胜得 3 分，平得 1 分，负
得 0 分。积分相同的队伍名次并列。有一支队伍获得第一，另一支排名最后。求第一名可
能的最少积分，以及最后一名可能的最多积分。

时间限制：1 秒。内存限制：64 MB。

## 输入

N。

## 输出

两个数。

## 样例

### 样例 1

输入:

```
2
```

输出:

```
1 1
```

## 解法

每场比赛产生至少 2 分（平局）、至多 3 分（分出胜负）。所以各队总分至少为
N(N − 1)，第一名至少有平均值 N − 1；若所有比赛都是平局，每队恰好 N − 1 分。

各队总分至多为 3·N(N − 1)/2，所以最后一名至多有 ⌊3(N − 1)/2⌋ 分。N 为奇数时，每
队可以恰好赢下自己 N − 1 场中的一半，人人得 3(N − 1)/2 分。N 为偶数时，让各队两
两打平，每队一场平局，其余比赛分配成每队赢下其余 N − 2 场中的一半：人人得
3(N − 2)/2 + 1 = ⌊3(N − 1)/2⌋ 分。`O(1)`。

注意事项：

- 只有一支队伍时没有比赛：0 和 0（测试 02）；
- N 为偶数时需要每队一场平局，因为没有平局时积分都是 3 的倍数（测试 04）；
- 两个答案分别优化，而不是在同一届比赛中（测试 03）。

## 优化解法

Go 沿用 n−1 和 floor(3(n−1)/2) 两个公式，用小字节缓冲区读取队伍数，再复用该缓冲区格式化两个答案，避免通用格式化输入输出。通过 syscall.Read 和 syscall.Write 使用标准句柄，重试中断调用并完成部分写入。
