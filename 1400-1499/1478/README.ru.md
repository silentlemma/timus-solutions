# 1478. Спутники-шпионы

[Timus 1478](https://acm.timus.ru/problem.aspx?space=1&num=1478) · сложность 3899 · dsu

Автор оригинальной задачи — Дмитрий Иванков; контест УрГУ и ОрёлГТУ на Петрозаводских летних сборах, август 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N объектов лежат на плоскости в целых точках (координаты по модулю не
больше 10⁴). Их делят на базы так, чтобы внутри каждой базы любые два
объекта были строго ближе, чем любой объект этой базы к любому объекту
другой базы. Для каждого теста нужно вывести строку из N цифр, k-я из
которых равна 1, если есть разбиение ровно на k баз. Тесты заканчиваются
нулём; сумма N не больше 5000, N² — не больше 400 000, N³ — не больше
2,5·10⁸.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Тесты: N, затем N строк x y; тесты разделены пустыми строками; 0
завершает ввод.

## Выходные данные

Строка из N нулей и единиц на каждый тест.

## Примеры

### Пример 1

Ввод:

```
4
-1 -1
1 1
1 -1
-1 1

4
1 0
2 4
1 1
0 1

0
```

Вывод:

```
1001
1101
```

## Решение

Назовём множество C хорошим, если его диаметр меньше расстояния до
остальных; разбиение — это разбиение на хорошие множества. Два хороших
множества не пересекаются частично: если x лежит в обоих, a — только в
A, b — только в B, то d(x, b) > diam A ≥ d(x, a) и
d(x, a) > diam B ≥ d(x, b). Кроме того, если C хорошее, а t — его
расстояние до остальных, то C — компонента связности графа, соединяющего
объекты ближе t; и наоборот, такая компонента хорошая ровно тогда, когда
её диаметр меньше t. Значит, хорошие множества — узлы дерева
одиночной связи: запускаем Краскала по всем парам в порядке длины,
добавляя пары одинаковой длины вместе, и каждая компонента, появившаяся
после группы, — узел, дети которого — поглощённые ею компоненты. Узел
хороший, если его диаметр, обновляемый перекрёстными расстояниями при
каждом слиянии, меньше длины группы, которая потом его поглотит;
последний узел хороший всегда.

Любое собственное хорошее подмножество узла лежит внутри одного из его
детей, поэтому возможные количества для узла — {1}, если он хороший, и все
суммы, где от каждого ребёнка взято по одному возможному количеству.
Эти множества хранятся битовыми масками и складываются ребёнок за
ребёнком. В таблице w — число бит в слове или разряде длинного целого.

Подводные камни:

- пары одинаковой длины должны присоединяться одной группой: посреди
  ничьей компонента может не соответствовать ни одному порогу расстояния,
  поэтому сетка 25 × 25 допускает только 1 или 625 баз (gen4);
- неравенство строгое: три объекта с равными промежутками делятся
  только на 1 или 3 базы (тест 02);
- нехороший узел всё равно разбивается через детей: пять объектов
  (0, 0), (2, 0), (4, 0), (0, 1), (4, 1) допускают любое количество,
  кроме 2 (тест 02).
