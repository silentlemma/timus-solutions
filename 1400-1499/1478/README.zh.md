# 1478. 间谍卫星

[Timus 1478](https://acm.timus.ru/problem.aspx?space=1&num=1478) · 难度 3899 · dsu

原题作者 Dmitry Ivankov，出自 2006 年 8 月彼得罗扎沃茨克夏季集训的乌拉尔国立大学与奥廖尔国立技术大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

平面上 N 个目标位于整点（坐标绝对值不超过 10⁴）。把它们分成若干基地，使每个基
地内部任意两个目标的距离，严格小于该基地任一目标到其他基地任一目标的距离。对每
组测试输出一个 N 位的字符串，第 k 位为 1 表示存在恰好分成 k 个基地的分法。测试
以 0 结束；N 之和不超过 5000，N² 之和不超过 400 000，N³ 之和不超过 2.5·10⁸。

时间限制：2 秒。内存限制：64 MB。

## 输入

各组测试：N，然后是 N 行 x y；测试之间以空行分隔；0 表示输入结束。

## 输出

每组测试一个由 0 和 1 组成、长度为 N 的字符串。

## 样例

### 样例 1

输入:

```
4
-1 -1
1 1
1 -1
-1 1

4
1 0
2 4
1 1
0 1

0
```

输出:

```
1001
1101
```

## 解法

若集合 C 的直径小于它到其余目标的距离，就称 C 为好集合；一种分法就是把目标划分
成好集合。两个好集合不会交叉：若 x 同属两者，a 只属于 A，b 只属于 B，则
d(x, b) > diam A ≥ d(x, a) 且 d(x, a) > diam B ≥ d(x, b)。此外，若 C 是好集合，
t 是它到其余目标的距离，那么 C 是"距离小于 t 的目标相连"所得图的一个连通分量；反
之，这样的分量当且仅当直径小于 t 时是好集合。所以好集合都是单链接聚类树的节点：
按长度对所有点对运行 Kruskal，长度相同的点对一起加入，每组之后出现的分量就是一个
节点，它的子节点是它吞并的那些分量。若节点的直径（每次合并时用交叉距离更新）小于
之后吞并它的那组长度，它就是好的；最后一个节点总是好的。

节点的任何好真子集都位于某个子节点之内，所以一个节点可能的个数是：若它是好的
则有 {1}，再加上从每个子节点各取一个可能个数所得的全部和。这些集合用位掩码保存，
逐个子节点合并。表中 w 为机器字或大整数数位的位数。

注意事项：

- 长度相同的点对必须作为一组加入：在平局处理到一半时，分量可能不对应任何距离阈值，
  因此 25 × 25 的网格只能分成 1 或 625 个基地（gen4）；
- 不等式是严格的：间隔相等的三个目标只能分成 1 或 3 个基地（测试 02）；
- 不好的节点仍可通过子节点拆分：五个目标 (0, 0)、(2, 0)、(4, 0)、(0, 1)、(4, 1)
  可以分成除 2 以外的任何个数（测试 02）。
