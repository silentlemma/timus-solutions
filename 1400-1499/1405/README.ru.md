# 1405. Пусти козла в огород 5

[Timus 1405](https://acm.timus.ru/problem.aspx?space=1&num=1405) · сложность 709 · geometry

Автор оригинальной задачи — Владимир Яковлев; XII командный чемпионат школьников Свердловской области по программированию, 15 октября 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В огороде 2 ≤ N ≤ 1000 деревьев, заданных с точностью до сантиметра.
Двух козлов привязывают к двум разным деревьям. Козёл не должен доставать
до других деревьев, козлы не должны доставать друг до друга, а верёвка
должна быть не короче 1 и не длиннее 50 метров. Нужно найти наибольшую
суммарную площадь, доступную козлам, с точностью до 1 см². Допустимая
привязка гарантированно существует.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем координаты деревьев.

## Выходные данные

Наибольшая площадь в м² с четырьмя знаками после точки.

## Примеры

### Пример 1

Ввод:

```
8
1 1
-2 0
5 3
-2 3
8 3.10
-2 -1
-2 2
8 4.10
```

Вывод:

```
36.8060
```

## Решение

У дерева i верёвка не должна доставать до ближайшего другого дерева, так
что с ограничением в 50 метров она не длиннее topᵢ = min(50, расстояние
до ближайшего другого дерева). Для козлов у деревьев i и j на расстоянии
d нужно

1 ≤ a ≤ topᵢ, 1 ≤ b ≤ topⱼ, a + b ≤ d,

а площадь равна π(a² + b²). Это выпуклая функция на многоугольнике,
поэтому максимум в вершине: в углу прямоугольника или там, где прямая
a + b = d пересекает его сторону. Проверяем эти семь точек, оставляем
лежащие в области и берём лучшее по всем парам деревьев. `O(N²)`.
Решение на Python перебирает деревья по убыванию top и обрывает строку,
как только top² обоих деревьев вместе не может побить лучший ответ.

Подводные камни:

- ограничения в 1 и 50 метров легко пропустить: два дерева на расстоянии
  141 м дают 5000π, а не квадрат расстояния (тест 02);
- к дереву, у которого сосед ближе 1 м, козла привязать нельзя (тесты 03
  и 06);
- касания допустимы: верёвка ровно 1 м или две верёвки, в сумме ровно
  равные расстоянию (тест 05 и сгенерированный тест 4);
- в C++ на сервере нет M_PI, поэтому π — это acos(-1).

Перебор вершин сравнивался с мелкой сеткой по области на 3 000 случайных
случаях, а примеры с форума дают ожидаемые ответы.
