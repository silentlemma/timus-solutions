# 1482. Игра в треугольник

[Timus 1482](https://acm.timus.ru/problem.aspx?space=1&num=1482) · сложность 2928 · geometry

Автор оригинальной задачи — Александр Ипатов; чемпионат Уральского государственного университета, 7 октября 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На карте нарисован невырожденный треугольник и лежит треугольная
фишка (все координаты — целые числа, по модулю не больше 2000). За один
ход фишку можно перенести или повернуть, но не перевернуть. Можно ли
одним ходом совместить вершины фишки с нарисованными? Выведите 0, если
нельзя; 1 dx dy для переноса; иначе 2 x0 y0 A для поворота вокруг
(x0, y0) на A градусов против часовой стрелки, 0 ≤ A < 360, не меньше
чем с десятью знаками после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Вершины нарисованного треугольника, затем фишки, парами x y.

## Выходные данные

0, 1 dx dy или 2 x0 y0 A.

## Примеры

### Пример 1

Ввод:

```
0 0 10 0 0 -10
0 0 10 0 0 10
```

Вывод:

```
2 0.0000000000 0.0000000000 270.0000000000
```

## Решение

Вершины должны совпасть лишь как множества, поэтому перебираем все
шесть способов сопоставить вершины фишки с нарисованными. Сопоставление
осуществимо ходом ровно тогда, когда три стороны совпадают и оба
треугольника обходятся в одну сторону: ход не может отразить. Обе
проверки идут на целых квадратах длин и векторных произведениях, то
есть точны.

Если какое-то подходящее сопоставление сдвигает все три вершины на один
вектор, ответ — этот перенос. Иначе берём подходящее сопоставление.
Угол — между стороной фишки и её образом, через atan2 от их векторного
и скалярного произведений, приведённый в [0, 360). Центр — вершина,
которая остаётся на месте, если такая есть. Если нет, центр лежит на
серединном перпендикуляре каждой вершины и её образа:
2(t − s)·c = |t|² − |s|². Две такие прямые разных направлений
пересекаются в нём, и правило Крамера даёт центр точной дробью, которую
печатаем с десятью знаками. `O(1)`.

Подводные камни:

- вершины могут идти в любом порядке (тесты 08, gen1);
- отражение разностороннего треугольника сохраняет стороны, но
  недостижимо (тест 03);
- фишка, уже лежащая на месте, — перенос на (0, 0) (тест 02);
- у малого поворота возможен далёкий центр, около 2·10⁴ в тесте 05, поэтому
  центр лучше считать точно, а не через (I − R)⁻¹ в плавающей точке.

## Особенности языков

- C++ и Rust печатают точную дробь в целых числах: целую часть, затем
  остаток, умноженный на 10¹⁰ и делённый на знаменатель с округлением.
  Go использует `big.Rat`, Java — `BigDecimal`, Python — `Fraction`.
