# 1482. 三角形游戏

[Timus 1482](https://acm.timus.ru/problem.aspx?space=1&num=1482) · 难度 2928 · geometry

原题作者 Alexander Ipatov，出自 2006 年 10 月 7 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

地图上画着一个非退化三角形，并放着一块三角形棋子（所有坐标都是绝对值不超过 2000
的整数）。一步可以平移或旋转棋子，但不能把它翻过来。能否一步就让棋子的顶点与画
出的顶点完全重合？不能则输出 0；平移则输出 1 dx dy；否则输出 2 x0 y0 A，表示绕
(x0, y0) 逆时针旋转 A 度，0 ≤ A < 360，小数点后至少十位。

时间限制：1 秒。内存限制：64 MB。

## 输入

画出的三角形的顶点，然后是棋子的顶点，均为 x y 对。

## 输出

0、1 dx dy 或 2 x0 y0 A。

## 样例

### 样例 1

输入:

```
0 0 10 0 0 -10
0 0 10 0 0 10
```

输出:

```
2 0.0000000000 0.0000000000 270.0000000000
```

## 解法

顶点只需作为集合重合，所以枚举棋子顶点与画出顶点的全部六种对应。当且仅当三条边
长相等且两个三角形的绕向相同时（一步不能产生镜像），这种对应能由一步实现。两项
检查都用整数的边长平方和叉积，因此是精确的。

若某个可行的对应把三个顶点都平移同一个向量，答案就是这个平移。否则取一个可行的
对应。角度是棋子的一条边与其像之间的夹角，由它们叉积与点积的 atan2 得到，并归到
[0, 360)。若有顶点不动，中心就是它；否则中心位于每个顶点与其像的垂直平分线上：
2(t − s)·c = |t|² − |s|²。两条方向不同的这种直线交于中心，用克莱姆法则得到精确的
分数，再输出十位小数。`O(1)`。

注意事项：

- 顶点可能以任意顺序给出（测试 08、gen1）；
- 不等边三角形的镜像边长相同，但不可达（测试 03）；
- 棋子已经就位时，答案是平移 (0, 0)（测试 02）；
- 小角度旋转的中心可能很远，测试 05 中约在 2·10⁴ 处，所以中心最好精确计算，而不是用
  浮点数求 (I − R)⁻¹。

## 语言说明

- C++ 和 Rust 用整数运算输出精确的分数：先输出整数部分，再把余数乘以 10¹⁰ 除以分
  母并四舍五入。Go 用 `big.Rat`，Java 用 `BigDecimal`，Python 用 `Fraction`。
