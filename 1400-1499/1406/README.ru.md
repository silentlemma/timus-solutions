# 1406. Следующее число

[Timus 1406](https://acm.timus.ru/problem.aspx?space=1&num=1406) · сложность 344 · greedy

Автор оригинальной задачи — Александр Ипатов; XII командный чемпионат школьников Свердловской области по программированию, 15 октября 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дано K-значное число N, K ≤ 2000, возможно с ведущими нулями. Нужно
вывести наименьшее K-значное число больше N с той же суммой цифр, тоже
с ведущими нулями, или -1, если такого нет.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число N со всеми его K цифрами.

## Выходные данные

Следующее число или -1.

## Примеры

### Пример 1

Ввод:

```
113
```

Вывод:

```
122
```

### Пример 2

Ввод:

```
0050
```

Вывод:

```
0104
```

## Решение

Большее число с той же суммой совпадает с N до некоторой позиции, имеет
там большую цифру, а цифры после неё возвращают то, что эта цифра
взяла. Следующее число меняет как можно более позднюю позицию и
увеличивает её цифру ровно на единицу, поэтому ищем самую правую цифру
меньше 9 с положительной суммой после неё. Увеличиваем её на единицу и
собираем хвост с суммой на единицу меньше в наименьшем виде: сначала
нули, а сумма сдвинута к концу, девятки справа. Если такой цифры нет,
ответ -1. `O(K)`.

Подводные камни:

- ведущие нули — часть числа, их нужно сохранить (пример 2 и тест 09);
- у 0, 9 и чисел вроде 1000 следующего нет (тесты 05–07 и
  сгенерированный тест 3 — наибольшее число своей суммы);
- в числе до 2000 цифр, это далеко за пределами целых типов фиксированной
  разрядности; Python `int` поддерживает произвольную точность, но для
  ведущих нулей всё равно нужно сохранять длину (тест 09).

Ответы сравнивались с перебором чисел подряд на 2 000 случайных числах
до пяти цифр.
