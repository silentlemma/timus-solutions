# 1406. 下一个数

[Timus 1406](https://acm.timus.ru/problem.aspx?space=1&num=1406) · 难度 346 · greedy

原题作者 Alexander Ipatov，出自 2005 年 10 月 15 日第十二届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

给出一个 K 位数 N，K ≤ 2000，可能带前导零。输出比 N 大且数字和相同的最小 K
位数（同样保留前导零），若不存在则输出 -1。

时间限制：1 秒。内存限制：64 MB。

## 输入

带全部 K 位数字的 N。

## 输出

下一个数，或 -1。

## 样例

### 样例 1

输入:

```
113
```

输出:

```
122
```

### 样例 2

输入:

```
0050
```

输出:

```
0104
```

## 解法

数字和相同的更大数与 N 在某个位置之前相同，在该位置上数字更大，之后的各位把
这一位多拿的数还回来。下一个数要改动尽量靠后的位置，并且只把该位加一，所以找
最右边一个小于 9 且其后数字和为正的位置。把它加一，然后用减一后的和以最小的
形式重建后缀：前面是零，和都推到末尾，从右边起放 9。若找不到这样的位置，答案
是 -1。`O(K)`。

注意事项：

- 前导零是数的一部分，必须保留（样例 2 和测试 09）；
- 0、9 以及像 1000 这样的数没有下一个数（测试 05 到 07，以及生成测试 3，即
  其数字和下最大的数）；
- 数最多有 2000 位，远超任何整数类型。

在 2 000 个至多五位的随机数上与逐个往上数的方法做了比较。
