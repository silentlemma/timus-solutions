# 1430. Преступление и наказание

## Задача

Товары стоят A или B за штуку, каждого можно купить сколько угодно, а
потратить нужно не больше N (1 ≤ A, B, N ≤ 2·10⁹). Нужно найти x и y,
при которых x·A + y·B ≤ N и как можно больше; подходит любая лучшая
пара.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

A, B и N.

## Выходные данные

x и y.

## Примеры

### Пример 1

Ввод:

```
8 5 22
```

Вывод:

```
2 1
```

## Решение

Пусть A ≥ B (иначе меняем их местами и меняем ответ обратно). Если
x ≥ B, то B товаров по A можно обменять на A товаров по B с той же
суммой, так что у некоторого лучшего ответа x < B; а x·A ≤ N даёт
x ≤ N / A. Поэтому x пробегает от 0 до min(N / A, B − 1), и при каждом x
на остаток покупается y = (N − x·A) / B товаров по B. Раз A ≥ B, то либо
B ≤ √N, либо N / A < √N, так что значений x не больше примерно 44 722;
цикл к тому же останавливается, как только потрачено ровно N. `O(√N)`.

Подводные камни:

- произведения вроде x·A помещаются в 32-битное целое со знаком (тесты 03, 06);
- если обе цены больше N, ничего не покупается (тест 12);
- ответ не единственный, поэтому тесты проверяет чекер (тест 02).
