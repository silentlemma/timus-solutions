# 1420. 整系数复数除法

[Timus 1420](https://acm.timus.ru/problem.aspx?space=1&num=1420) · 难度 1771 · math

原题作者 Evgeny Krokhalev，出自 2005 年 10 月 29 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对于实部和虚部都是整数的复数，a 除以 b 的带余除法结果是满足 b·q + r = a 且
|r| < |b| 的任意一对这样的复数 (q, r)。给出 a 和 b（各部分绝对值不超过 10⁶），
求可能的结果个数。

时间限制：1 秒。内存限制：64 MB。

## 输入

第一行是 a 的实部和虚部，第二行是 b 的。

## 输出

结果的个数。

## 样例

### 样例 1

输入:

```
12 0
0 5
```

输出:

```
2
```

## 解法

余数由 q 决定，所以要数满足 |a − b·q| < |b| 的整系数复数 q。若 b = 0，没有东西
比 0 短，答案为 0。否则两边除以 |b| 得 |a / b − q| < 1：q 位于以 a / b 为中心的
开单位圆内，因此是 (⌊Re a/b⌋, ⌊Im a/b⌋) 周围 3 × 3 个点之一，最多有四个满足。

记 a / b = (x + y·i) / |b|²，其中 x = Re a·Re b + Im a·Im b，
y = Im a·Re b − Re a·Im b，向下取整的除法可以精确得到候选点网格的中心。
每个候选用 |a − b·q|² < |b|² 在 64 位整数（Python 中为任意精度整数）中检验：
余数的各部分不超过 |b| 的几倍，不会溢出，也不需要浮点数。`O(1)`。

注意事项：

- 除以零时根本没有结果（测试 04、05）；
- 距离恰好为 1 的商不算，所以 a / b 为整数时只有一个结果（测试 02、07）；
- 对负数部分，除法必须向负无穷取整（测试 10、11、12）。
