# 1420. Целочисленное комплексное деление

[Timus 1420](https://acm.timus.ru/problem.aspx?space=1&num=1420) · сложность 1809 · math

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для комплексных чисел с целыми составляющими делением a на b с
остатком называется любая пара (q, r) таких чисел, что b·q + r = a и
|r| < |b|. По a и b (все составляющие не больше 10⁶ по модулю) нужно
посчитать число возможных результатов.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Действительная и мнимая части a в первой строке, b — во второй.

## Выходные данные

Число результатов.

## Примеры

### Пример 1

Ввод:

```
12 0
0 5
```

Вывод:

```
2
```

## Решение

Остаток определяется по q, поэтому нужно посчитать целые комплексные q
с |a − b·q| < |b|. Если b = 0, ничего нет короче 0, и ответ 0. Иначе,
поделив на |b|, получаем |a / b − q| < 1: q лежит в открытом единичном
круге вокруг a / b, то есть это одна из 3 × 3 точек вокруг
(⌊Re a/b⌋, ⌊Im a/b⌋), и подойти могут не больше четырёх.

При a / b = (x + y·i) / |b|², где x = Re a·Re b + Im a·Im b и
y = Im a·Re b − Re a·Im b, деление с округлением вниз даёт центр
точно. Каждый кандидат проверяется как |a − b·q|² < |b|² в 64-битных
целых: части остатка не превосходят нескольких |b|, так что
переполнения нет и вещественные числа не нужны. `O(1)`.

Подводные камни:

- при делении на ноль результатов нет вовсе (тесты 04, 05);
- частное на расстоянии ровно 1 не считается, поэтому целое a / b даёт
  один результат (тесты 02, 07);
- деление должно округлять к минус бесконечности для отрицательных
  частей (тесты 10, 11, 12).
