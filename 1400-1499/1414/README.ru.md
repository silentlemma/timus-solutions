## Задача

База названий звёзд вначале содержит одно название «sun». Далее идут
до 10 000 операций, по одной в строке: «+name» добавляет название (его
могут добавить и повторно), «?prefix» запрашивает названия,
начинающиеся с префикса. Аргументы — от 1 до 20 строчных латинских
букв или цифр. На каждый запрос нужно вывести префикс, а затем
подходящие названия в лексикографическом порядке без повторов, каждое
с отступом в два пробела, не больше первых 20.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Операции.

## Выходные данные

Ответы на запросы.

## Примеры

### Пример 1

Ввод:

```
?e
+earth
+egg
?e
+eagle
+earth
?ea
```

Вывод:

```
e
e
  earth
  egg
ea
  eagle
  earth
```

## Решение

Храним названия в упорядоченном множестве. Названия с данным префиксом
образуют непрерывный отрезок в лексикографическом порядке, который
начинается там, куда встал бы сам префикс, поэтому каждый запрос
находит это место двоичным поиском и идёт вперёд, пока название
начинается с префикса и выведено меньше 20 названий. C++, Java и Rust
используют древовидные множества; Go и Python хранят отсортированный
массив и вставляют в него, сдвигая не больше 10 000 ссылок за
добавление. `O(Q log Q)` для древовидных множеств.

Подводные камни:

- «sun» есть в базе с самого начала (тест 02);
- повторные добавления не должны повторяться в ответе (тест 03);
- выводятся только первые 20 названий (тест 04);
- в названиях бывают цифры, они идут раньше букв (тест 12);
- в примере два пробела отступа показаны точками.
