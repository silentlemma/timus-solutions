# 1480. 餐券

[Timus 1480](https://acm.timus.ru/problem.aspx?space=1&num=1480) · 难度 471 · constructive

原题作者 Sergey Pupyrev，出自 2006 年 10 月 7 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

把 1 … N²（2 ≤ N ≤ 50）填入 N × N 的表格，使有公共边的两格之和的最大值尽可能小。
输出这个和以及达到它的表格；若按行依次填写，这个和是 2N² − 1。

时间限制：1 秒。内存限制：64 MB。

## 输入

N。

## 输出

可能的最小的最大和，然后是表格的 N 行。任何满足要求的表格都可以。

## 样例

### 样例 1

输入:

```
2
```

输出:

```
6
1 4
3 2
```

## 解法

设 V=N²，t=⌊N/2⌋。将表格按棋盘染色，按阅读顺序在偶色格填入
V,V−1,…，在奇色格填入1,2,…。两个计数器恰好划分1…V且没有重复，
每条边连接异色格。N为奇数时，直接代入下标可得水平和为V或V+1，
大数与其下方小数之和为V+(N+1)/2。N=2t时，水平和至多V+2，最大
竖直和为V+t+1。第0行第0列与第1行第0列恰好达到V+t+1，因此构造
的最大和正是该值。时间Θ(N²)是输出量所必需的；不计各语言输出缓冲，
两个计数器只占O(1)工作空间。

### 为什么不能更小

使用如下网格事实：若A只含一种棋盘颜色且|A|≤t²，则其开放邻域满足

|N(A)|−|A| ≥ ⌈√|A|⌉。

下文给出考虑边界的证明。假设所有边和至多V+t。最大的t²个标签占据
独立集S，因为其中任意两个标签的和已超过V+t。它们的邻点标签至多
t²+t−1，因而邻点数至多t²+t−1。按颜色将S分成A0、A1；两者邻域
颜色不同且不相交。上述事实给出
|N(S)|−|S|≥√|A0|+√|A1|≥√|S|=t，矛盾。因此下界为V+t+1，
构造达到下界，故最优。

### 网格事实的证明

无限方格中任意有限非空单色集X满足
[二分等周不等式](https://arxiv.org/html/1710.10232#S4.SS3)
|N(X)|−|X|≥⌈2√|X|⌉+1，见例4.7、式4.22。它不能直接用于有限表格
的边界；下面用反射和横穿路径处理缺失的邻点。

先假设A不接触某条水平边及某条竖直边。反射表格，使它们成为下边和右边。
记s=|A|、d=|N(A)|−s；a、b分别统计A、N(A)在上、左两轴上的点，
共同角点计两次，α、β表示角点是否属于相应集合。沿两轴反射并合并重复，
得到|X|=4s−2a+α，D=|N(X)|−|X|=4d+2(a−b)+β−α。
把A下移或右移，会单射到N(A)且避开相应轴，所以每条轴上的点数至多d。
无限网格不等式还给出d≥1。若α=1，则β=0、b≥a、a≤2d，故
4s−2a+1≤(2d−1)²，推出s≤d²。若α=0，设A接触两轴中的p条，
则b≥a+p、a≤pd、β≤1；p=0时β=0。代入后，p=0,1,2分别给出
s≤(d−1/4)²、s≤d²−d/2+1/4、s≤d²−d+1，均至多d²。
把有共同邻点的A点连为分量，不同分量的邻域不相交。若每个分量都满足
此条件，则累加sᵢ≤dᵢ²，同样得到s≤d²。

现在令B=N(A)，C为另一颜色中不在B的点。R=A∪B与Q=C∪N(C)互不相交。
若两者都有连接同一对对边的路径，则d≥t。转置到左右横穿的情形，取简单
不相交路径；它们有上下次序，可反射使R在Q上方。因此每列都有一个R点
位于某Q点上方。在交替颜色的列中，每段连续A色位置比所选点多一个
竖直邻点；若该段抵达A色端点则少一个。N为偶数时，每列净差非负；
有t列的A色端点在下方，若净差为0，R在该列必为底部后缀，与路径次序
矛盾，故这些列至少贡献1。N为奇数时，有t或t+1列的两端为另一颜色，
它们至少贡献1；其他列中Q阻止A段同时抵达两端，净差非负。水平邻点
只会增加B，故总计d≥t。

最后设|A|≤t²且某个分量横穿对边，但d<t。C非空，并有d_C≤d+ε，
ε是两色大小之差：N偶时为0，N奇时为±1。平面分离保证C的分量不能
垂直穿过A路径；若有平行横穿，则已得d≥t。否则C的各分量都可用反射
界，因而1≤d_C且|C|≤(d+ε)²。然而N=2t时，
|C|≥t²−t+1>(t−1)²；N=2t+1且A为多数颜色时，
|C|≥t²+t+1>t²；A为少数颜色时，|C|≥t²+t+2>(t−2)²。
若t−2<1，最后一种情形已与1≤d_C≤t−2矛盾。因此横穿的A也有
d≥t，s≤t²≤d²。事实对所有N成立，有限回归检查不代替此证明。

## 优化解法

C++、Go 以递增小数与递减大数两个计数器输出相同棋盘构造，用 8192 字节输出块代替逐数格式化。Go 通过标准句柄读写，用四字节数组转换数字。时间 Θ(N²) 已由输出量要求，额外工作空间 O(1)。保留全部原文件；Java、Python、Rust 复用达标版。一般最优性由上文考虑边界的反射及横穿路径证明；小网格穷举是独立回归证据。
