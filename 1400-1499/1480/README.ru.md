# 1480. Талоны

[Timus 1480](https://acm.timus.ru/problem.aspx?space=1&num=1480) · сложность 471 · constructive

Автор оригинальной задачи — Сергей Пупырев; чемпионат Уральского государственного университета, 7 октября 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно расставить числа 1 … N² (2 ≤ N ≤ 50) в таблице N × N так, чтобы
наибольшая сумма двух клеток с общей стороной была как можно меньше.
Выведите эту сумму и таблицу, на которой она достигается; если писать
числа подряд по строкам, сумма будет 2N² − 1.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

Наименьшая возможная наибольшая сумма, затем N строк таблицы. Подходит
любая верная таблица.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
6
1 4
3 2
```

## Решение

Пусть V=N², t=⌊N/2⌋. Раскрасим таблицу шахматно. В порядке чтения
запишем V,V−1,… на чётном цвете и 1,2,… на нечётном. Счётчики
разбивают 1…V без повторов, каждое ребро соединяет разные цвета.
При нечётном N прямые формулы индексов дают горизонтальные суммы
V или V+1, а сумму большого числа с малым под ним — V+(N+1)/2.
При N=2t горизонтальные суммы не превосходят V+2, наибольшая
вертикальная равна V+t+1. Пара (строка0,столбец0) и
(строка1,столбец0) достигает V+t+1 в обоих случаях. Значит,
максимум конструкции ровно такой. Время Θ(N²) необходимо для
вывода, два счётчика занимают O(1) рабочей памяти без учёта
зависящей от языка буферизации вывода.

### Почему лучше сделать нельзя

Используем факт о решётке: для множества A одного шахматного цвета,
|A|≤t², открытая окрестность удовлетворяет

|N(A)|−|A| ≥ ⌈√|A|⌉.

Ниже приведено доказательство с учётом границ. Предположим, что все
суммы не больше V+t. Наибольшие t² меток образуют независимое
множество S: уже сумма двух таких меток больше V+t. У соседей могут
быть только метки до t²+t−1, значит, соседей не больше t²+t−1.
Разобьём S на цвета A0,A1. Их окрестности имеют разные цвета и не
пересекаются. Указанный факт даёт
|N(S)|−|S|≥√|A0|+√|A1|≥√|S|=t — противоречие. Таким образом,
V+t+1 — нижняя оценка, и наша конструкция оптимальна.

### Доказательство факта о решётке

Для конечного непустого одноцветного X в бесконечной квадратной решётке
[двудольное изопериметрическое неравенство](https://arxiv.org/html/1710.10232#S4.SS3)
даёт |N(X)|−|X|≥⌈2√|X|⌉+1 (пример4.7, формула4.22).
К границе таблицы оно напрямую неприменимо; потерянные соседства
учитываются следующим отражением и рассуждением о пересекающих путях.

Сначала пусть A не касается одной горизонтальной и одной вертикальной
границы. Отразим таблицу так, чтобы это были нижняя и правая границы.
Обозначим s=|A|, d=|N(A)|−s. Числа a,b считают точки A,N(A) на
верхней и левой осях, общий угол считается дважды; α,β отмечают
принадлежность угла этим множествам. Отразим по обеим осям, удаляя
повторы. Получим |X|=4s−2a+α,
D=|N(X)|−|X|=4d+2(a−b)+β−α. Сдвиг вниз или вправо инъективно
отображает A в N(A), обходя соответствующую ось, поэтому число
точек на каждой оси не больше d. Бесконечное неравенство даёт d≥1.
При α=1 имеем β=0, b≥a, a≤2d, откуда
4s−2a+1≤(2d−1)² и s≤d². При α=0 пусть A касается p из двух осей.
Тогда b≥a+p, a≤pd, β≤1, а при p=0 ещё и β=0. Подстановка даёт
соответственно s≤(d−1/4)², s≤d²−d/2+1/4 или s≤d²−d+1
для p=0,1,2. Все оценки не больше d². Если этим свойством обладают
все компоненты, соединим точки A с общим соседом: окрестности разных
компонент не пересекаются. Суммируя sᵢ≤dᵢ², также получаем s≤d².

Теперь B=N(A), C — оставшиеся точки противоположного цвета. Области
R=A∪B и Q=C∪N(C) не пересекаются. Если в обеих есть пути между
одной парой противоположных границ, то d≥t. Транспонируем до путей
слева направо. Простые непересекающиеся пути упорядочены по вертикали;
отражением расположим R выше Q. В каждом столбце есть точка R выше
точки Q. В чередующемся столбце каждая серия точек A имеет на одного
вертикального соседа больше, кроме концов столбца цвета A, убирающих
по одному соседу. При чётном N вклад любого столбца неотрицателен;
в t столбцах с нижним концом цвета A нулевой вклад означал бы, что
R является нижним суффиксом, вопреки порядку путей. Там вклад хотя
бы1. При нечётном N в t или t+1 столбцах с концами другого цвета
вклад хотя бы1; в остальных Q не даёт серии дойти до обоих концов,
так что вклад неотрицателен. Горизонтальные соседи лишь увеличивают
B. Сумма в обоих случаях даёт d≥t.

Наконец, пусть |A|≤t² и некоторая компонента проходит между
противоположными границами, но d<t. Множество C непусто,
d_C≤d+ε, где ε — разность размеров цветовых классов: 0 для чётного
N и ±1 для нечётного. Компонента C не может пройти поперёк пути A
по планарности. Параллельное прохождение дало бы d≥t. Иначе все
компоненты C удовлетворяют оценке отражения, поэтому
1≤d_C и |C|≤(d+ε)². Но при N=2t
|C|≥t²−t+1>(t−1)²; при N=2t+1 и A большего цвета
|C|≥t²+t+1>t²; для меньшего цвета
|C|≥t²+t+2>(t−2)². Если t−2<1, последний случай уже противоречит
1≤d_C≤t−2. Значит, проходящее насквозь A имеет d≥t и
s≤t²≤d². Факт доказан для всех N; конечные проверки не заменяют
это доказательство.

## Оптимизированные решения

C++ и Go выводят ту же шахматную конструкцию двумя счётчиками: малый растёт, большой убывает. Блок вывода 8192 байта заменяет форматирование каждого числа; таблица и полная строка ответа не хранятся. Go читает и пишет через стандартные дескрипторы и записывает цифры каждого числа в массив из четырёх байтов. Время Θ(N²) необходимо для вывода, дополнительная рабочая память O(1). Исходные файлы сохранены; Java, Python и Rust используют подходящие базы. Общая оптимальность доказана выше отражением с учётом границ и пересекающими путями; перебор малых решёток служит отдельной регрессионной проверкой.

Принятые базовые реализации [1480_constructive.java](1480_constructive.java), [1480_constructive.py](1480_constructive.py), [1480_constructive.rs](1480_constructive.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
