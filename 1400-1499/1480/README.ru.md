# 1480. Талоны

[Timus 1480](https://acm.timus.ru/problem.aspx?space=1&num=1480) · сложность 471 · constructive

Автор оригинальной задачи — Сергей Пупырев; чемпионат Уральского государственного университета, 7 октября 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно расставить числа 1 … N² (2 ≤ N ≤ 50) в таблице N × N так, чтобы
наибольшая сумма двух клеток с общей стороной была как можно меньше.
Выведите эту сумму и таблицу, на которой она достигается; если писать
числа подряд по строкам, сумма будет 2N² − 1.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

Наименьшая возможная наибольшая сумма, затем N строк таблицы. Подходит
любая верная таблица.

## Примеры

### Пример 1

Ввод:

```
2
```

Вывод:

```
6
1 4
3 2
```

## Решение

Раскрасим таблицу как шахматную доску. Два больших числа не должны
соседствовать, поэтому N², N² − 1, … ставим на клетки одного цвета по
порядку чтения, а 1, 2, … — на клетки другого цвета, тоже по порядку
чтения. Тогда каждая сумма складывает маленькое число с большим, и
худшая пара — маленькое число с большим прямо над ним: между ними в
порядке чтения около N/2 клеток каждого цвета, и сумма выходит
N² + ⌊N/2⌋ + 1 (проверено для каждого N до 50).

Лучше не бывает. Полный перебор, который ставит числа от наибольшего и
даёт каждой клетке предел, оставленный уже поставленными соседями, не
находит таблицы с меньшей суммой ни для одного N до 9, и именно это
значение ожидает проверка. `O(N²)`.

Подводные камни:

- первая строка — сумма, а не N; таблица идёт следом (все тесты);
- раскраска одинаково работает для чётных и нечётных N, но ⌊N/2⌋
  округляется вниз (тесты 05, 06, 07);
- очевидная таблица по порядку чтения даёт 2N² − 1, как отмечено в
  условии, — далеко от оптимума.
