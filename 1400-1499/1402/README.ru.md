# 1402. Коктейли

[Timus 1402](https://acm.timus.ru/problem.aspx?space=1&num=1402) · сложность 130 · combinatorics

Автор оригинальной задачи — Сергей Пупырев; XII командный чемпионат школьников Свердловской области по программированию, 15 октября 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Коктейль — смесь двух или более из N ≤ 21 напитков, каждый не больше
одного раза, и порядок напитков важен. Нужно посчитать различные
коктейли.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Число N.

## Выходные данные

Количество коктейлей.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
12
```

## Решение

Коктейль из k напитков — упорядоченный выбор k различных напитков, и
таких N·(N − 1)·…·(N − k + 1). Складываем их для k от 2 до N, получая
каждое произведение из предыдущего. `O(N)`.

Подводные камни:

- с одним напитком коктейлей нет вовсе (тест 02);
- при N = 21 ответ около 1,4·10²⁰, больше 64 бит, поэтому решения
  используют 128-битные или длинные числа (тест 07).

Тесты проверяются точным сравнением.
