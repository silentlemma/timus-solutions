# 1422. Светлячки

[Timus 1422](https://acm.timus.ru/problem.aspx?space=1&num=1422) · сложность 851 · geometry

Авторы оригинальной задачи — Илья Гребнов, Дмитрий Ковалёв и Никита Рыбак; Timus Top Coders: First Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N мух (1 ≤ N ≤ 2000) неподвижно висят в целых точках с координатами до
10⁷ по модулю. Точечный файербол летит по любой прямой и превращает в
светлячка каждую муху на пути. Нужно найти наибольшее число мух,
которых может достать один файербол, то есть наибольшее число точек на
одной прямой.

Ограничение времени: 3 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк X Y Z.

## Выходные данные

Наибольшее число мух на одной прямой.

## Примеры

### Пример 1

Ввод:

```
6
-1 1 -1
0 1 2
0 0 -1
-2 -1 2
2 -1 -2
-1 0 2
```

Вывод:

```
3
```

## Решение

Берём по очереди каждую муху как первую на прямой и смотрим на
направления к мухам после неё. Две мухи лежат на одной прямой с первой
ровно тогда, когда их векторы разности кратны друг другу, поэтому
каждый вектор делится на наибольший общий делитель своих координат, а
знак выбирается так, чтобы первая ненулевая координата была
положительной. Равные приведённые векторы — одна прямая; их подсчёт
(хеш-таблицей или сортировкой) даёт лучшую прямую через эту муху. Мухи
в той же точке, что и первая, лежат на любой прямой через неё и
прибавляются к лучшему счёту. Ожидаемое время с хеш-таблицей —
`O(N² log C)`, с сортировкой — `O(N²(log C + log N))`
для C = 2·10⁷, с учётом НОД.

Подводные камни:

- несколько мух могут висеть в одной точке (тесты 03, 05, gen4);
- одна муха тоже даёт ответ 1 (тест 02);
- разности достигают 2·10⁷, что ещё помещается в 32 бита, а целые
  ключи избавляют направления от округлений (тесты 06, gen2).
