# 1477. Самолёты

[Timus 1477](https://acm.timus.ru/problem.aspx?space=1&num=1477) · сложность 2917 · geometry

Автор оригинальной задачи — Дмитрий Иванков; контест УрГУ и ОрёлГТУ на Петрозаводских летних сборах, август 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N самолётов (1 ≤ N ≤ 150) — точки на сфере с центром в начале
координат, заданные целыми направляющими векторами (X, Y, Z) с
координатами не больше 600 по модулю; направления у всех разные.
Издалека видна открытая полусфера. Нужно найти, сколько самолётов можно
увидеть одновременно.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк X Y Z.

## Выходные данные

Наибольшее число видимых самолётов.

## Примеры

### Пример 1

Ввод:

```
6
0 0 1
0 0 -1
0 1 0
0 -1 0
1 0 0
-1 0 0
```

Вывод:

```
3
```

## Решение

Открытая полусфера с полюсом d показывает точки p с d·p > 0. Возьмём
оптимальную и будем поворачивать d, пока она показывает те же точки; d
можно вести, пока граничная плоскость не пройдёт через два
непараллельных самолёта. Значит, достаточно перебрать все плоскости
через начало координат и два самолёта, с нормалью n = p × q,
сокращённой на НОД, чтобы каждая плоскость проверялась один раз.
Самолёты вне плоскости лежат по ту или другую сторону.

Самолёты на плоскости образуют окружность, и небольшой наклон полюса к
направлению u в плоскости показывает те, у которых u·p > 0, — это та же
задача на размерность ниже. Там край лучшей открытой полуокружности
можно повернуть, пока он не пройдёт через самолёт z: половина за краем
n × z, в ту или другую сторону, плюс сам z, которого добавляет ещё
небольшой поворот. Так каждая плоскость даёт max(сверху, снизу) +
лучшую половину своей окружности, а ответ — наибольшее из этих чисел,
но не меньше 1. Всего `O(N³)`, ведь пара самолётов лежит только на
одной плоскости.

Подводные камни:

- полусфера открыта: самолёты на её границе не видны, поэтому шесть
  направлений осей дают 3, а не 5 (тест 01);
- если все самолёты на одной прямой через начало координат, перебирать
  нечего, и ответ 1 (тесты 02, 03);
- многие самолёты на одной большой окружности требуют шага по
  окружности (тесты 04, 06, gen3);
- произведения доходят примерно до 1,6·10¹², больше 32 бит (gen1).
