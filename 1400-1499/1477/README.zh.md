# 1477. 飞机

[Timus 1477](https://acm.timus.ru/problem.aspx?space=1&num=1477) · 难度 2918 · geometry

原题作者 Dmitry Ivankov，出自 2006 年 8 月彼得罗扎沃茨克夏季集训的乌拉尔国立大学与奥廖尔国立技术大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 架飞机（1 ≤ N ≤ 150）是以原点为球心的球面上的点，由整数方向向量 (X, Y, Z) 给
出，坐标绝对值不超过 600，且方向各不相同。从远处可以看到一个开半球。求同时能看
到的飞机的最大数量。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N 行 X Y Z。

## 输出

能看到的飞机的最大数量。

## 样例

### 样例 1

输入:

```
6
0 0 1
0 0 -1
0 1 0
0 -1 0
1 0 0
-1 0 0
```

输出:

```
3
```

## 解法

以 d 为极点的开半球能看到满足 d·p > 0 的点 p。转动最优的 d，在到达极限之前
保持可见点不变；只要并非所有方向都共线，极限处的边界平面就可以经过两架方向不
平行的飞机。所以只需枚举所有经过原点和两架方向不平行的飞机的平面，法向量
n = p × q 按符号和最大公约数归一化，使每个平面只检查一次。不在平面上的飞机
分处平面两侧。

平面上的飞机构成一个圆，把极点向平面内的方向 u 稍稍倾斜，就能看到其中 u·p > 0 的
飞机，这是低一维的同一个问题。在圆上，最优开半圆的边缘可以趋近某架飞机 z：
以经过 z 的直径为界，取较多的一侧，再加上 z 本身——再稍转一点就能把它包含进来。
因此每个平面给出 max(上方, 下方) + 其圆上最好的半边，答案是这些值中的最大
者，且至少为 1。总计 `O(N³)`，因为每对不平行的方向唯一确定一个平面。

注意事项：

- 半球是开的：边界上的飞机看不到，所以六个坐标轴方向的答案是 3 而不是 5（测试
  01）；
- 如果所有飞机都在过原点的同一条直线上，就没有可枚举的平面，答案为 1（测试 02、
  03）；
- 许多飞机位于同一个大圆上时，需要在圆上再做一步（测试 04、06、gen3）；
- 点积可达约 7.3·10¹¹，超出 32 位（gen1）。
