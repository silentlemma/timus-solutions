# 1458. Военные учения

## Задача

На плацу N × N (N чётное, 2 ≤ N ≤ 1000) в каждой клетке стоит солдат в
одном из двух положений, W или B. По команде «клетка (i, j)» все солдаты
i-й горизонтали или j-й вертикали, всего 2N − 1 человек, меняют
положение на противоположное. Нужно найти самую короткую
последовательность команд, после которой все солдаты стоят одинаково,
всё равно как.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк из N букв W и B.

## Выходные данные

Число команд, затем клетки команд. Принимается любая самая короткая
последовательность.

## Примеры

### Пример 1

Ввод:

```
4
WBWB
BWWW
WWBW
WBWB
```

Вывод:

```
2
2 3
3 1
```

## Решение

Команды перестановочны, а повторная команда отменяет первую, так что
решение — это множество клеток. Если отдать все команды в горизонтали a
и в вертикали b, солдат в (a, b) сменит положение 2N − 1 раз, каждый
другой солдат этой горизонтали или вертикали — N раз, а все остальные —
дважды; при чётном N меняется только (a, b). Значит, любого солдата можно
переключить отдельно, и чтобы все стали W, переключить нужно стоящих в
B: складывая их «кресты», клетка (i, j) входит в ответ, когда в i-й
горизонтали, в j-й вертикали и в самой клетке вместе нечётное число B.
Раз каждого солдата можно переключить отдельно, 2^(N²) множеств клеток
дают все 2^(N²) расстановок, так что никакие два множества не действуют
одинаково, и это множество единственное для своей цели.

Чтобы все стали B, нужны в точности остальные клетки, ведь множество
всех клеток переключает всех. Поэтому берём меньшее из двух множеств: k
или N² − k команд. `O(N²)`.

Подводные камни:

- если все уже стоят одинаково, в любом из положений, команды не нужны
  (тесты 02, 03);
- один солдат, стоящий иначе, требует целого «креста» из 2N − 1 команд
  (тесты 07, gen2);
- до полумиллиона команд нужно выводить быстро (gen1, gen3, gen4).
