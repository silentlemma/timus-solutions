# 1447. Сеть портшлюзов

## Задача

У фирмы N филиалов (1 ≤ N ≤ 1000) и M возможных портшлюзов
(1 ≤ M ≤ 500000), каждый соединяет два разных филиала и имеет длину и
себестоимость — целые числа от 1 до 10⁶; никакая пара филиалов не
соединяется дважды. Сеть должна связывать все филиалы без лишних
портшлюзов, то есть быть остовным деревом, и такое дерево существует.
Фирма платит за метры, поэтому Люциус Малфой хочет дерево с наименьшим
отношением суммарной себестоимости к суммарной длине. Нужно вывести это
отношение с точностью 10⁻⁸.

Ограничение времени: 4 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, M, затем M строк: два филиала, длина и себестоимость портшлюза.

## Выходные данные

Наименьшая средняя стоимость метра.

## Примеры

### Пример 1

Ввод:

```
3
3
1 2 50 60
1 3 100 100
2 3 100 100
```

Вывод:

```
1
```

### Пример 2

Ввод:

```
3
3
1 2 1000 3000
1 3 1 5
2 3 1000 1997
```

Вывод:

```
2
```

## Решение

Дерево T имеет отношение не больше λ ровно тогда, когда сумма c − λ d по
его рёбрам не больше 0, поэтому вопрос «есть ли дерево с отношением
меньше λ» — это минимальное остовное дерево с весами c − λ d. Метод
Динкельбаха превращает это в быструю итерацию: берём любое дерево,
полагаем λ равным его отношению, находим минимальное дерево для весов
c − λ d, и если его вес отрицателен, то его собственное отношение
меньше, и оно становится новым λ; когда минимальный вес равен 0, ни одно
дерево не лучше λ. Отношение падает быстро, и на практике хватает
нескольких раундов.

Если хранить λ как дробь p / q, всё становится точным: веса c q − d p —
целые числа, помещающиеся в 64 бита, так что условие остановки не
зависит от округления. При 500000 рёбер на 1000 филиалов граф почти
полный, поэтому каждое дерево строится алгоритмом Прима по матрице
N × N за `O(N²)`, и весь расчёт занимает `O(N²)` на раунд.

Подводные камни:

- самое дешёвое дерево — не то, у которого лучшее отношение (пример 2);
- если сеть уже дерево, выбора нет (тесты 05, gen4);
- отношения бывают крошечными, поэтому нужна абсолютная точность, а не
  несколько значащих цифр (тесты 04, 07).
