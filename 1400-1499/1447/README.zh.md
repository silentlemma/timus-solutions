# 1447. 门钥匙网络

[Timus 1447](https://acm.timus.ru/problem.aspx?space=1&num=1447) · 难度 971 · graphs

原题作者 Den Raskovalov（作者）和 Stanislav Vasiliev（题面），出自 2006 年 3 月 24–25 日第十届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一家公司有 N 个分部（1 ≤ N ≤ 1000）和 M 条可能的门钥匙连接（1 ≤ M ≤ 500000），
每条连接两个不同的分部，有长度和成本，均为 1 到 10⁶ 的整数；任何一对分部至多有一
条连接。网络必须连通所有分部且没有多余的连接，也就是一棵生成树，并且这样的树一定
存在。公司按米付钱，所以卢修斯·马尔福想要总成本与总长度之比最小的树。以 10⁻⁸ 的
精度输出这个比值。

时间限制：4 秒。内存限制：64 MB。

## 输入

N、M，然后 M 行，每行是两个分部、连接的长度和成本。

## 输出

每米的最小平均成本。

## 样例

### 样例 1

输入:

```
3
3
1 2 50 60
1 3 100 100
2 3 100 100
```

输出:

```
1
```

### 样例 2

输入:

```
3
3
1 2 1000 3000
1 3 1 5
2 3 1000 1997
```

输出:

```
2
```

## 解法

树 T 的比值不超过 λ，当且仅当其各边 c − λ d 之和不超过 0，所以“是否存在比值小于
λ 的树”就是以 c − λ d 为权的最小生成树问题。Dinkelbach 方法把它变成快速的迭代：
任取一棵树，令 λ 等于它的比值，求权为 c − λ d 的最小生成树；若其权值为负，则它
自身的比值更小，成为新的 λ；当最小权值为 0 时，没有树能优于 λ。比值下降得很快，
实际上只需几轮。

把 λ 保存为分数 p / q 就能完全精确：权值 c q − d p 是 64 位以内的整数，所以停止
条件不受舍入影响。1000 个分部上最多 500000 条边，图可能接近完全图，所以每棵树都用
N × N 矩阵上的 Prim 算法在 `O(N²)` 内求出，每一轮 `O(N²)`。

注意事项：

- 最便宜的树不一定比值最好（样例 1）；
- 网络本身已是一棵树时没有选择余地（测试 05、gen4）；
- 比值可能非常小，所以要输出足够的小数位（测试 04、07）。

## 各语言说明

- Python 逐行读取连接，存进 `array` 组成的行：把五十万条连接拆成一个词表要占用超过 64 MB。在评测上它用 2.25 秒和 9 MB，在 4 秒限制之内。
