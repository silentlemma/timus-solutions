## Задача

В коридоре N светильников в ряд (1 ≤ N ≤ 10⁶), каждый горит в полную
силу или не горит. Аргус Филч хочет яркость b процентов (0 ≤ b ≤ 100),
распределённую как можно равномернее: нужно вывести ряд из N цифр 0 и 1
так, чтобы на любом отрезке из L подряд идущих светильников число
горящих отличалось от L b / 100 не больше чем на 2.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем b.

## Выходные данные

Ряд светильников. Принимается любой подходящий ряд.

## Примеры

### Пример 1

Ввод:

```
10
33
```

Вывод:

```
0100100100
```

## Решение

Светильник i (считая с 0) горит ровно тогда, когда ⌊(i + 1) b / 100⌋
больше ⌊i b / 100⌋. Тогда среди первых k горит ⌊k b / 100⌋
светильников, так что на отрезке от l до r их ⌊r b / 100⌋ − ⌊l b / 100⌋,
а это отличается от (r − l) b / 100 меньше чем на 1, с запасом в
пределах разрешённых 2. Узор повторяется каждые 100 светильников, ведь
прибавление 100 к i прибавляет ровно b к обоим округлениям вниз. `O(N)`.

Подводные камни:

- при b = 0 и b = 100 ряд из одинаковых цифр (тесты 02, 03, 05, gen1,
  gen2);
- буферизуйте вывод до миллиона цифр, чтобы избежать отдельного вызова
  на каждую (gen1–gen7);
- ряд из примера — лишь один из многих правильных ответов.
