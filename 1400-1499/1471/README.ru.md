# 1471. Расстояние в дереве

[Timus 1471](https://acm.timus.ru/problem.aspx?space=1&num=1471) · сложность 163 · trees

Автор оригинальной задачи — Дмитрий Жуков; контест УрГУ и ОрёлГТУ на Петрозаводских летних сборах, август 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В дереве n вершин (1 ≤ n ≤ 50000) с номерами от 0 до n − 1 и n − 1
взвешенных рёбер (веса от 0 до 1000). Для каждого из m вопросов
(1 ≤ m ≤ 75000) нужно вывести длину пути между двумя данными вершинами.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

n, затем рёбра в виде u v w, затем m и пары вершин.

## Выходные данные

По одному расстоянию в строке.

## Примеры

### Пример 1

Ввод:

```
3
1 0 1
2 0 1
3
0 1
0 2
1 2
```

Вывод:

```
1
1
2
```

## Решение

Подвесим дерево за вершину 0 и запомним расстояние от каждой вершины до
корня. Путь между a и b поднимается до их наименьшего общего предка,
поэтому его длина равна dist(a) + dist(b) − 2·dist(lca). Предка даёт
эйлеров обход: обход в глубину, который записывает вершину при входе в
неё и ещё раз после каждого потомка. Между первыми вхождениями a и b
обход проходит через их общего предка и не поднимается выше, так что
предок — самая неглубокая вершина на этом отрезке. Разреженная таблица
минимумов по отрезкам длины 2^k отвечает на это двумя перекрывающимися
обращениями. `O(n log n)` на построение, `O(1)` на вопрос.

Подводные камни:

- путь из 50000 вершин слишком глубок для рекурсии в большинстве языков,
  поэтому обход ведёт собственный стек (gen3);
- вершина 0 может быть листом, а рёбра даны в любом направлении
  (тест 03);
- у единственной вершины нет рёбер вовсе, а в вопросе одна и та же
  вершина может встретиться дважды (тест 02).

## Особенности языков

- Python складывает все числа входа и строки разреженной таблицы в
  плоские `array` и освобождает слова входа до построения таблиц: со
  списками питоновских целых он превышал лимит 64 МБ на тесте 14 жюри.
  Теперь решение тратит 0,67 с и 44 МБ.
