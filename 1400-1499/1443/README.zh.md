# 1443. 铁轨

[Timus 1443](https://acm.timus.ru/problem.aspx?space=1&num=1443) · 难度 676 · math

原题作者 Stanislav Vasiliev，出自 2006 年 3 月 24–25 日第十届乌拉尔大学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一条有 N 条线路（1 ≤ N ≤ 18）、每条长 S 米（1 ≤ S ≤ 10000）的魔法铁路，用长为 L
（10 ≤ L ≤ 10000）的铁轨铺设。铁轨可以切断，碎段可以连接，每次连接产生一个接
缝。接缝数必须尽量少，在此前提下用掉的铁轨数也要最少。长度精确到十分之一毫米。
输出这个铁轨数。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

N、S 和 L，每行一个。

## 输出

最少的铁轨数。

## 样例

### 样例 1

输入:

```
3
1005.6712
20.0001
```

输出:

```
151
```

## 解法

把长度精确地读成十分之一毫米的整数，因为浮点数会把“道路比铁轨长十分之一毫米”这
类情况弄模糊。记 S = q L + rest，0 ≤ rest < L。由 k 段组成的线路有 k − 1 个接
缝，并且需要 k L ≥ S，所以每条线路用 ⌈S / L⌉ 段时接缝最少。

若 rest = 0，每条线路是 q 根整轨，共 N q 根。否则每条线路用 q 根整轨和一段长为
rest 的短段，短段装进铁轨，每根装 ⌊L / rest⌋ 段，共
N q + ⌈N / ⌊L / rest⌋⌉ 根。把不足的长度分摊到线路的几段上并不能省下铁轨：线路的
每一段都不短于 rest，因为其余 q 段都不超过 L。`O(1)`。

注意事项：

- 长度的小数位可能少于四位，或者根本没有（测试 02、09、10）；
- 道路比铁轨略长或略短（测试 05、11）；
- 道路可能比一根铁轨还短（测试 03、08）；
- 五条线路、每根铁轨装两段短段时需要多用三根铁轨，而不是总长度暗示的两根（测
  试 07）。
