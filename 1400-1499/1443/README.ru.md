# 1443. Рельсы

## Задача

Волшебная N-колейная дорога (1 ≤ N ≤ 18) длиной S метров
(1 ≤ S ≤ 10000) укладывается из рельсов длины L (10 ≤ L ≤ 10000). Рельсы
можно резать, а куски — соединять, и каждое соединение даёт стык. Число
стыков должно быть наименьшим, а среди таких планов наименьшим должно
быть число потраченных рельсов. Длины заданы с точностью до десятых долей
миллиметра. Нужно вывести это число рельсов.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, S и L по одному в строке.

## Выходные данные

Наименьшее число рельсов.

## Примеры

### Пример 1

Ввод:

```
3
1005.6712
20.0001
```

Вывод:

```
151
```

## Решение

Читаем длины точно, как целые числа десятых долей миллиметра: числа с
плавающей точкой размыли бы случаи вроде дороги на десятую миллиметра
длиннее рельса. Запишем S = q L + rest, где 0 ≤ rest < L. Колея из k
кусков имеет k − 1 стык и требует k L ≥ S, поэтому меньше всего стыков
при ⌈S / L⌉ кусках в каждой колее.

Если rest = 0, каждая колея — это q целых рельсов, всего N q. Иначе
каждая колея берёт q целых рельсов и один короткий кусок длины rest, а
короткие куски укладываются в рельсы по ⌊L / rest⌋ штук, что даёт
N q + ⌈N / ⌊L / rest⌋⌉. Распределение недостачи по нескольким кускам
колеи рельса не экономит: каждый кусок колеи не короче rest, потому что
остальные q кусков не длиннее L. `O(1)`.

Подводные камни:

- у длин может быть меньше четырёх знаков после точки или не быть их
  вовсе (тесты 02, 09, 10);
- дорога чуть длиннее или чуть короче рельса (тесты 05, 11);
- дорога может быть короче одного рельса (тесты 03, 08);
- пяти колеям с двумя короткими кусками на рельс нужны три лишних
  рельса, а не два, как подсказывает общая длина (тест 07).
