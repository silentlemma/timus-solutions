# 1467. 幂和

[Timus 1467](https://acm.timus.ru/problem.aspx?space=1&num=1467) · 难度 1217 · math

原题作者 Alexander Ipatov，出自 2006 年 1 月彼得罗扎沃茨克冬季集训的乌拉尔国立大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对任意 k，和 1^k + 2^k + ... + N^k 是一个 k + 1 次、有理系数的多项式 P(N)；例如
1 + ... + N = N(N + 1)/2。给定 0 ≤ k ≤ 30，按次数从高到低输出它的 k + 2 个系数，
写成既约分数 "a/b" 或 "-a/b"（b ≥ 1），零写作 "0/1"。

时间限制：1 秒。内存限制：64 MB。

## 输入

k。

## 输出

P 的各个系数，用一个空格分隔。

## 样例

### 样例 1

输入:

```
1
```

输出:

```
1/2 1/2 0/1
```

## 解法

这是 Faulhaber 公式。取伯努利数的 B₁ = +1/2 约定，
P(N) = 1/(k + 1) · Σ C(k + 1, j) · B_j · N^(k + 1 − j)（j = 0..k），所以
N^(k + 1 − j) 的系数是 C(k + 1, j) B_j / (k + 1)，常数项为 0。伯努利数由恒等式
Σ C(m + 1, j) B_j = m + 1（j = 0..m）得到，在这个约定下它由前面的数给出 B_m：
B_m = (m + 1 − Σ_{j < m} C(m + 1, j) B_j) / (m + 1)。

所有运算都是精确的。约分后的系数不大，但 k 接近 30 时中间的和放不进 64 位：
Python 用 Fraction，Go 用 big.Rat，Java 用 BigInteger，C++ 和 Rust 用 128 位整数，
每个分数都用最大公约数约分。共 `O(k²)` 次分数运算。

注意事项：

- k ≥ 3 时 N^(k − 2)、N^(k − 4)、……的系数为零，但仍要输出 0/1（测试 04、10）；
- 和到 N 为止时 B₁ 必须取 +1/2（取 −1/2 时和只到 N − 1）；
- k 接近 30 时两个分数的乘积会超出 64 位（测试 09、10）。
