# 1467. Сумма степеней

[Timus 1467](https://acm.timus.ru/problem.aspx?space=1&num=1467) · сложность 1215 · math

Автор оригинальной задачи — Александр Ипатов; контест УрГУ на Петрозаводских зимних сборах, январь 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Для любого k сумма 1^k + 2^k + ... + N^k — многочлен P(N) степени k + 1
с рациональными коэффициентами; например, 1 + ... + N = N(N + 1)/2. По
0 ≤ k ≤ 30 нужно вывести его k + 2 коэффициента от старшей степени к
младшей несократимыми дробями «a/b» или «-a/b» с b ≥ 1, а ноль — как
«0/1».

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

k.

## Выходные данные

Коэффициенты P через пробел.

## Примеры

### Пример 1

Ввод:

```
1
```

Вывод:

```
1/2 1/2 0/1
```

## Решение

Это формула Фаульхабера. С числами Бернулли в соглашении B₁ = +1/2
P(N) = 1/(k + 1) · Σ C(k + 1, j) · B_j · N^(k + 1 − j) по j = 0..k,
так что коэффициент при N^(k + 1 − j) равен C(k + 1, j) B_j / (k + 1), а
свободный член равен 0. Числа Бернулли получаются из тождества
Σ C(m + 1, j) B_j = m + 1 по j = 0..m, которое в этом соглашении даёт
B_m через предыдущие: B_m = (m + 1 − Σ_{j < m} C(m + 1, j) B_j) / (m + 1).

Вся арифметика точная. Сокращённые коэффициенты невелики, но
промежуточные суммы при k около 30 не помещаются в 32 бита: Python
использует Fraction, Go — big.Rat, Java — BigInteger, а C++ и Rust —
128-битные целые, сокращая каждую дробь на наибольший общий делитель.
`O(k²)` операций с дробями; в Go — `O(k³)` арифметических операций
из-за повторного вычисления биномиальных коэффициентов.

Подводные камни:

- коэффициенты при N^(k − 2), N^(k − 4), ... равны нулю при k ≥ 3, но
  всё равно выводятся как 0/1 (тесты 04, 10);
- B₁ должно быть +1/2 для сумм до N (при −1/2 суммы шли бы до N − 1);
- промежуточные произведения при k около 30 не помещаются в 32 бита
  (тесты 09, 10).
