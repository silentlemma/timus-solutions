# 1497. Разрезание квадрата

[Timus 1497](https://acm.timus.ru/problem.aspx?space=1&num=1497) · сложность 304 · implementation

Автор оригинальной задачи — Александр Торопов; XIII командный чемпионат школьников Свердловской области по программированию, 14 октября 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Клетчатый лист N × N (3 ≤ N ≤ 1000) разрезан на чёрный кусок (клетки 1)
и белый кусок (клетки 0), оба связны по сторонам. Куски лежат вместе на
столе. Можно ли отодвинуть один из них далеко от другого, не отрывая
ни один от стола? Нужно вывести «Yes» или «No».

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк по N символов 0 и 1.

## Выходные данные

«Yes» или «No».

## Примеры

### Пример 1

Ввод:

```
5
10001
10001
10001
11111
11111
```

Вывод:

```
Yes
```

### Пример 2

Ввод:

```
5
11011
11011
10001
11111
11111
```

Вывод:

```
No
```

## Решение

Отодвинуть один кусок — то же, что отодвинуть другой в обратную
сторону, так что двигать нужно только чёрный кусок. Он может уехать
прямо вверх, когда ни в одном столбце нет белой клетки над чёрной, и
так же вниз, влево и вправо. Сдвиг по диагонали ничего не добавляет:
каждое ребро между кусками должно смотреть от направления движения, и
тогда свободны и оба осевых сдвига, из которых складывается диагональ.
Значит, достаточно проверить четыре направления, по одному проходу по
листу на каждое. `O(N²)`.

Подводные камни:

- кусок, окружённый другим, уйти не может никогда (тест 03, gen2);
- один крючок, даже в одну клетку, сцепляет куски (тесты 05, 07,
  gen4);
- лестничный разрез раздвигается вдоль оси, хотя его рёбра смотрят в
  две стороны (тест 04, gen1).

## Оптимизированные решения

C++ и Go проверяют четыре направления за один проход. На горизонтальной паре клеток разных цветов по этой оси допустимо только движение чёрной части от белой. Вертикальная пара так же ограничивает вторую ось. Храним четыре флага и прекращаем проверку, когда все сброшены. Достаточно предыдущей и текущей строк, поэтому память O(N).

Принятые базовые реализации [1497_implementation.java](1497_implementation.java), [1497_implementation.py](1497_implementation.py), [1497_implementation.rs](1497_implementation.rs) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
