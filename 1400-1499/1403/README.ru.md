# 1403. Курьер

[Timus 1403](https://acm.timus.ru/problem.aspx?space=1&num=1403) · сложность 350 · greedy

Автор оригинальной задачи — Никита Рыбак; XII командный чемпионат школьников Свердловской области по программированию, 15 октября 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Каждый из N ≤ 1000 заказов доставляется за один день, у него есть срок
и вознаграждение; просроченный заказ ничего не приносит, и доставлять
его нельзя. Нужно выбрать заказы и порядок доставки с наибольшим
суммарным вознаграждением.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем срок и вознаграждение каждого заказа.

## Выходные данные

Число доставленных заказов, затем их номера в порядке доставки.
Подходит любой лучший план.

## Примеры

### Пример 1

Ввод:

```
4
1 17
5 15
2 10
2 11
```

Вывод:

```
3
1 4 2
```

## Решение

Набор заказов можно доставить вовремя ровно тогда, когда после
сортировки по сроку k-й из них должен быть доставлен не раньше дня k.
Поэтому проходим заказы по сроку и держим выбранные в куче по
вознаграждению: добавляем каждый заказ, а когда в куче больше заказов,
чем позволяет его срок, выбрасываем самый дешёвый. Каждый шаг сохраняет
лучший допустимый набор из уже просмотренных заказов, потому что место
всегда уступает только наименьшее вознаграждение. Оставшиеся заказы,
отсортированные по сроку, и есть план. `O(N log N)`.

Подводные камни:

- сроки бывают больше 100 000 (на форуме об этом пишут про тест 9),
  поэтому ничего не рассчитано на этот предел (тест 06);
- если все заказы нужно доставить в первый день, доставляется только
  самый дорогой (тест 07).

Ответы сравнивались с перебором всех подмножеств на 400 случайных
маленьких наборах. Тесты проверяются программой, которая находит лучшую
сумму другим способом, ставя самые выгодные заказы на самые поздние
свободные дни.
