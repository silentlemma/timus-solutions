# 1450. 俄罗斯输气管道

[Timus 1450](https://acm.timus.ru/problem.aspx?space=1&num=1450) · 难度 149 · dp

原题作者 Dmitry Kovalioff、Ilya Grebnov 与 Nikita Rybak，出自 Timus Top Coders: Second Challenge。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

输气网络有 N 个站（2 ≤ N ≤ 500）和 M 条单向管道（0 ≤ M ≤ 124750），每条从 A 到
B，收益为 C（1 ≤ C ≤ 10000）；每对站之间至多一条管道，且网络中没有环：若气体能
从 X 流到 Y，就不能流回去。求从站 S 到站 F 收益最大的路线，路线的收益是其所含管
道的收益之和；若无法到达 F，输出 "No solution"。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

第一行是 N 和 M，然后 M 行 A、B、C，其中 1 ≤ A, B ≤ N；最后一行是 S 和 F，
其中 1 ≤ S, F ≤ N 且 S ≠ F。

## 输出

最大收益，或 "No solution"。

## 样例

### 样例 1

输入:

```
6 7
6 5 10
1 4 11
1 2 4
3 1 5
2 4 5
6 3 1
6 1 3
6 4
```

输出:

```
17
```

样例中最好的路线是 6、3、1、4。

## 解法

没有环时，最长路就是简单的动态规划。用 Kahn 方法对站做拓扑排序：从没有入管道的
站开始，一个站的所有入管道都处理过后才放出该站。按这个顺序，每个站在其出管道被
使用之前就已确定，所以对管道 v → w 有 best[w] = max(best[v] + C)，best[S] = 0，
从 S 不可达的站保持为空。答案是 best[F]。`O(N + M)`。

注意事项：

- F 不可达，包括管道从 F 通向 S 的情况（测试 02、03、06）；
- 收益最大的路线可能比直达管道经过更多管道（测试 07）；
- 从 S 不可达的站不能把收益传下去，但仍然要参与排序。

## 优化解法

优化的 C++ 解法从 4 KB 缓冲区中手工解析数字，而不是用 `scanf`，并把管网存成
16 位 `uint16_t` 收益的矩阵，`N = 500` 时约 490 KB，而不是由 pair 组成的
`vector` 嵌套 `vector`。收益至少为 1，且每对站之间至多一条管道，所以值为零的单元
表示没有管道；从队列取出的站扫描自己的整行，总共 `O(N²)`。最佳收益用 `int` 而不
是 `long long`：一条路线至多 499 条管道，收益至多 4 990 000：
{1450_dp_optimized.cpp}。

优化的 Go 解法从 `bufio.Reader` 中逐字节解析数字，而不是用 `fmt.Fscan`，并把管网
存成 `uint16` 收益的矩阵，`N = 500` 时约 490 KB，而不是由含两个 `int` 字段的结构
体组成的切片。收益至少为 1，且每对站之间至多一条管道，所以值为零的单元表示没有管
道；从队列取出的站扫描自己的整行，总共 `O(N²)`：{1450_dp_optimized.go}。

优化的 Java 解法从 4 KB 缓冲区中手工解析数字，而不是用 `StreamTokenizer`，并把管
网存成 `short` 收益的矩阵（足以容纳不超过 10 000 的值），而不是三个存管道的
`int` 数组加上按站分组的数组。收益至少为 1，且每对站之间至多一条管道，所以值为零
的单元表示没有管道；从队列取出的站扫描自己的整行，总共 `O(N²)`。最佳收益用 `int`
而不是 `long`：一条路线至多 499 条管道，收益至多 4 990 000：
{1450_dp_optimized.java}。

优化的 Python 解法利用输入按行排列这一点，逐行读入，而不是把整个输入切分成列表。
管网按站存成每站一行的 `array("H")`，元素是无符号 16 位收益，而不是元组列表；收
益至少为 1，且每对站之间至多一条管道，所以值为零的单元表示没有管道，从队列取出的
站用 `enumerate` 扫描自己的整行：{1450_dp_optimized.py}。

优化的 Rust 解法从 4 KB 缓冲区中手工解析数字，而不是把整个输入读进 `String`，并
把管网存成 `u16` 收益的矩阵，`N = 500` 时约 490 KB，而不是 `(usize, i64)` 对的向
量。收益至少为 1，且每对站之间至多一条管道，所以值为零的单元表示没有管道；从队列
取出的站扫描自己的整行，总共 `O(N²)`。最佳收益用普通的 `i32`，不可达记为 -1，而
不是 `Option<i64>`：一条路线至多 499 条管道，收益至多 4 990 000：
{1450_dp_optimized.rs}。
