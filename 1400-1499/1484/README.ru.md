# 1484. Кинорейтинг

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Рейтинг фильма — среднее целых оценок от 1 до 10, округлённое до одного
знака с округлением половины вверх (7.55 показывается как 7.6). Сейчас
он показывает X после N оценок (1 ≤ X, Y ≤ 10 с одним знаком,
1 ≤ N ≤ 10⁶). Нужно найти наименьшее число новых оценок, после которых
рейтинг покажет не больше Y, какими бы ни были прежние оценки, или
вывести «Impossible».

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

X, Y и N.

## Выходные данные

Число оценок или «Impossible».

## Примеры

### Пример 1

Ввод:

```
9.5 2.0 12
```

Вывод:

```
86
```

## Решение

Работаем в десятых: x = 10X и y = 10Y. Сумма S из N оценок показывает x
ровно тогда, когда (2x − 1)N ≤ 20S < (2x + 1)N, а оценки допускают
N ≤ S ≤ 10N. Если никакое целое S не подходит под оба условия, никакой
набор оценок не показывает X, и ответ — «Impossible»: например, одна
оценка никогда не покажет 7.1.

Новые оценки стоит ставить единицами, а худший случай — наибольшее
подходящее S. После k таких оценок рейтинг покажет не больше y, когда
20(S + k) < (2y + 1)(N + k), то есть (2y − 19)·k > 20S − (2y + 1)N.
Так как Y ≥ 1, число 2y − 19 положительно, поэтому наименьшее k равно 0,
если правая часть уже отрицательна, и (20S − (2y + 1)N) div (2y − 19) + 1
иначе. `O(1)`.

Подводные камни:

- рейтинг, который N оценок показать не могут, — это «Impossible», даже
  если цель была бы лёгкой (тесты 02, 09);
- 7.55 округляется вверх до 7.6, поэтому границы полуоткрытые, и их
  лучше держать в целых числах (тест 07);
- ответ доходит до 179 000 001, когда миллион десяток опускают до 1.0
  (тест 04).
