# 1484. 电影评分

[Timus 1484](https://acm.timus.ru/problem.aspx?space=1&num=1484) · 难度 629 · math

原题作者 Vladimir Yakovlev，出自 2006 年 10 月 7 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

电影评分是 1 到 10 之间整数投票的平均值，保留一位小数，0.05 向上进位（7.55 显示
为 7.6）。现在已有 N 票，评分显示为 X（1 ≤ X, Y ≤ 10，一位小数，1 ≤ N ≤ 10⁶）。
求最少再投几票，才能无论之前的票是什么，评分都显示不超过 Y；若做不到，输出
"Impossible"。

时间限制：1 秒。内存限制：64 MB。

## 输入

X、Y 和 N。

## 输出

票数，或 "Impossible"。

## 样例

### 样例 1

输入:

```
9.5 2.0 12
```

输出:

```
86
```

## 解法

以十分之一为单位：x = 10X，y = 10Y。N 票的总和 S 显示为 x，当且仅当
(2x − 1)N ≤ 20S < (2x + 1)N，而票数本身要求 N ≤ S ≤ 10N。若没有同时满足两者的整
数 S，就没有任何投票能显示 X，答案为 "Impossible"：例如一票永远不会显示 7.1。

新投的票都应是 1，最坏情况是满足条件的最大 S。投 k 张这样的票后，评分显示不超
过 y 的条件是 20(S + k) < (2y + 1)(N + k)，即 (2y − 19)·k > 20S − (2y + 1)N。由于
Y ≥ 1，2y − 19 为正，所以若右边已经为负，最小的 k 为 0，否则为
(20S − (2y + 1)N) div (2y − 19) + 1。`O(1)`。

注意事项：

- N 票不可能显示的评分要输出 "Impossible"，即使目标本身很容易（测试 02、09）；
- 7.55 向上进位为 7.6，所以边界是半开的，最好用整数处理（测试 07）；
- 一百万张 10 分降到 1.0 时，答案可达 179 000 001（测试 04）。
