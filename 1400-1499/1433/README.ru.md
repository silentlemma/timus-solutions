# 1433. Тетраэдры

[Timus 1433](https://acm.timus.ru/problem.aspx?space=1&num=1433) · сложность 264 · bruteforce, math

## Задача

У двух правильных тетраэдров одного размера каждая грань покрашена в R,
G, B или Y. Цвета перечислены в одном порядке для обоих: основание,
левая передняя грань, правая передняя грань и задняя. Нужно вывести
«equal», если один тетраэдр можно повернуть так, чтобы он выглядел
точно как другой, и «different» иначе.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Две строки по четыре буквы.

## Выходные данные

«equal» или «different».

## Проверка

Точно сравнивается строчный токен equal либо different. Новый точный исходник Python прошёл 12 тестов репозитория на PyPy 3.10. Также 1600 пар раскрасок с независимой группой вращений. Остальные сохранённые варианты имеют собственные проверки целевой среды и точные Accepted. Вывод сравнивается по правилам проверяющего модуля задачи.

## Примеры

### Пример 1

Ввод:

```
RGRB
GRRB
```

Вывод:

```
equal
```

## Решение

Поворот тетраэдра переставляет четыре грани, и повороты дают ровно 12
чётных перестановок: поворот вокруг оси через вершину сдвигает три
грани по циклу, поворот на пол-оборота вокруг оси через середины двух
противоположных рёбер меняет местами две пары, а нечётная перестановка,
например одна транспозиция, была бы зеркальным отражением. Поэтому
перебираем все 24 порядка граней, оставляем те, у которых чётное число
инверсий, и проверяем, превращает ли один из них первую раскраску во
вторую. `O(1)`.

Подводные камни:

- зеркальные отражения различны: при четырёх разных цветах обмен двух
  граней — не поворот (тесты 03, 11);
- при повторяющемся цвете любые расстановки одних и тех же цветов
  равны, ведь обмен двух одинаковых граней исправляет чётность (тесты
  05, 07, 08, 12).

## Оптимизированные решения

Учебные версии по-прежнему перебирают двенадцать правильных вращений тетраэдра. Новые математические варианты сначала сравнивают мультимножества цветов. При повторяющемся цвете перестановка двух неразличимых граней меняет чётность, сохраняя раскраску: чётный представитель существует всегда. Иначе четыре различных цвета однозначно задают перестановку; правильному вращению соответствует ровно чётная перестановка, что проверяется числом инверсий. Все повёрнутые раскраски строить не нужно. Граней постоянно четыре, сравнения точные. Python также использует существующие текстовые потоки.
