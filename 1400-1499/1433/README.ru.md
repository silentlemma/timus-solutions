# 1433. Тетраэдры

## Задача

У двух правильных тетраэдров одного размера каждая грань покрашена в R,
G, B или Y. Цвета перечислены в одном порядке для обоих: основание,
левая передняя грань, правая передняя грань и задняя. Нужно вывести
«equal», если один тетраэдр можно повернуть так, чтобы он выглядел
точно как другой, и «different» иначе.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Две строки по четыре буквы.

## Выходные данные

«equal» или «different».

## Примеры

### Пример 1

Ввод:

```
RGRB
GRRB
```

Вывод:

```
equal
```

## Решение

Поворот тетраэдра переставляет четыре грани, и повороты дают ровно 12
чётных перестановок: поворот вокруг оси через вершину сдвигает три
грани по циклу, поворот на пол-оборота вокруг оси через середины двух
противоположных рёбер меняет местами две пары, а нечётная перестановка,
например одна транспозиция, была бы зеркальным отражением. Поэтому
перебираем все 24 порядка граней, оставляем те, у которых чётное число
инверсий, и проверяем, превращает ли один из них первую раскраску во
вторую. `O(1)`.

Подводные камни:

- зеркальные отражения различны: при четырёх разных цветах обмен двух
  граней — не поворот (тесты 03, 11);
- при повторяющемся цвете любые расстановки одних и тех же цветов
  равны, ведь обмен двух одинаковых граней исправляет чётность (тесты
  05, 07, 08, 12).
