# 1496. Спамер

[Timus 1496](https://acm.timus.ru/problem.aspx?space=1&num=1496) · сложность 49 · implementation

Автор оригинальной задачи — Сергей Пупырев; XIII командный чемпионат школьников Свердловской области по программированию, 14 октября 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

За последние 10 минут контеста пришло N посылок (0 ≤ N ≤ 100), каждая
от команды с названием до 30 строчных латинских букв и цифр. Нужно
вывести все команды, сдавшие больше одной посылки, в любом порядке.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N названий команд.

## Выходные данные

Команды больше чем с одной посылкой, по одной в строке.

## Примеры

### Пример 1

Ввод:

```
11
naucoder
iceman
abikbaev
abikbaev
petr
abikbaev
abikbaev
x
abikbaev
acrush
x
```

Вывод:

```
x
abikbaev
```

## Решение

Считаем посылки каждой команды в словаре и выводим команды, у которых
счётчик больше единицы, каждую один раз. Сохранять порядок первого
появления не обязательно, но так вывод получается устойчивым.
C++: `O(N log N)`; остальные: `O(N)` в среднем.

Подводные камни:

- команда, сдавшая много раз, всё равно выводится один раз (тест 01);
- названия — это текст, так что «0» и «00» — разные команды (тест 04);
- если ни одна команда не повторяется, вывод пустой (тесты 02, 03, 05).
