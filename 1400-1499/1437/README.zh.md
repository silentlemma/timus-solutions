# 1437. 加油站

[Timus 1437](https://acm.timus.ru/problem.aspx?space=1&num=1437) · 难度 493 · bfs

原题作者 Alexey Lakhtin，出自 2006 年 2 月 25 日第七届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

三个油桶的容量各为 0 到 255 升。加油泵只能把一个油桶加满，汽油可以从一个桶倒入另
一个桶，直到前者倒空或后者装满，不能洒出。只有在所有倒油操作结束后，才把其中一
些桶倒进油箱。油箱能得到多少种不同的正体积？

时间限制：1 秒。内存限制：64 MB。

## 输入

三个容量，每行一个。

## 输出

体积的种数。

## 样例

### 样例 1

输入:

```
0
3
4
```

输出:

```
6
```

## 解法

从三桶皆空开始搜索所有状态 (x, y, z)：三种加满一桶的操作和六种把一桶倒入另一桶的
操作。任何操作之后总有某个桶是空的或满的，所以 256³ 个状态中至多约 3·2·256² 个可达。每个
可达状态的各个非空桶子集之和都是油箱可得的体积；统计不同的正值。对容量 a、b、c，
令 P=(a+1)(b+1)(c+1)、V=a+b+c+1，S 为已到达的状态数。计入标记初始化后，平均时间
为 `O(P)`；C++ 使用有序集合，时间为 `O(P + S log V)`。

注意事项：

- 零升不算（测试 01、03）；
- 已经满的桶不能再倒入，所以样例中得不到 5 升（测试 01）；
- 三个容量相等的桶总是空的或满的（测试 05）。
