## Задача

Три канистры вмещают от 0 до 255 литров каждая. Колонка может только
наполнить канистру доверху, бензин можно переливать из одной канистры в
другую, пока первая не опустеет или вторая не наполнится, а проливать
нельзя. Только после всех переливаний некоторые канистры выливаются в
бак. Сколько различных положительных объёмов можно получить в баке?

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Три ёмкости, по одной в строке.

## Выходные данные

Количество объёмов.

## Примеры

### Пример 1

Ввод:

```
0
3
4
```

Вывод:

```
6
```

## Решение

Перебираем все состояния (x, y, z) канистр начиная с пустых: три хода
наполнить канистру и шесть ходов перелить одну канистру в другую. После
любого хода какая-то канистра пуста или полна, поэтому достижимы
не более примерно 3·2·256² из 256³ состояний. Каждое достигнутое
состояние даёт суммы своих непустых подмножеств канистр как объёмы для
бака; считаем различные положительные. Для ёмкостей a, b, c обозначим
P=(a+1)(b+1)(c+1), V=a+b+c+1, S — число достигнутых состояний. С учётом
инициализации флагов время в среднем `O(P)`, а в C++ с упорядоченным
множеством — `O(P + S log V)`.

Подводные камни:

- ноль литров не считается (тесты 01, 03);
- уже полная канистра больше не принимает, поэтому в примере 5 литров
  не получить (тест 01);
- три равные канистры всегда пусты или полны (тест 05).
