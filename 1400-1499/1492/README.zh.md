# 1492. 瓦夏的爸爸 2

## 任务

一个分段线性函数由 N 个顶点给出（2 ≤ N ≤ 30000，整数坐标绝对值不超过 15000），x
递增，x_1 = −x_N，且没有三个相邻顶点共线。它能否写成一个偶的和一个奇的分段线性
函数之和？若能，输出 "Yes"，然后是偶部分的顶点，再是奇部分的顶点，小数点后至少四
位；否则输出 "No"。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N 行 x y。

## 输出

"Yes" 和两组顶点，或 "No"。

## 样例

### 样例 1

输入:

```
2
-1 0
1 0
```

输出:

```
Yes
-1.0000 0.0000
1.0000 0.0000
-1.0000 0.0000
1.0000 0.0000
```

## 解法

[−a, a] 上的任何函数都只有一种分解方式：E(x) = (f(x) + f(−x))/2 是偶函数，
O(x) = (f(x) − f(−x))/2 是奇函数，两者之和为 f。所以答案总是 "Yes"，两部分也是唯
一确定的。

两部分在 f 的各点及其镜像点之间都是线性的，所以把这些 x 排序去重后就是候选顶点；
函数值由 f 插值得到。内部候选点只有在该部分真正弯折时才保留，因为不能有三个相邻顶
点共线。E 在两个候选点之间的斜率是 (a/b − c/d)/2，其中 a/b 是 f 在那里的斜率，
c/d 是 f 在镜像段上的斜率；O 用加号。两个这样的分数交叉相乘比较是精确的，所有因子
都小于 2·10⁹，所以 64 位足够。`O(N log N)`。

注意事项：

- 答案永远不会是 "No"（所有测试）；
- 镜像点常常不是某一部分的弯折点，若保留它，就会有三个顶点共线（测试 05、07、
  gen3、gen4）；
- 输入为偶函数或奇函数时，另一部分是只有两个顶点的直线 0（测试 01、02、03、05、07）；
- 必须用精确的斜率判断弯折，而不是用浮点比较插值结果（gen5、测试 07）。
