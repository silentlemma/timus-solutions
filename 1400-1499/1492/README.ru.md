# 1492. Папа у Васи 2

[Timus 1492](https://acm.timus.ru/problem.aspx?space=1&num=1492) · сложность 1989 · math

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Кусочно-линейная функция задана N вершинами (2 ≤ N ≤ 30000, целые
координаты по модулю не больше 15000) с возрастающими x, x_1 = −x_N и
без трёх последовательных вершин на одной прямой. Можно ли представить
её суммой чётной и нечётной кусочно-линейных функций? Нужно вывести
«Yes» и вершины чётной части, затем нечётной, не меньше чем с четырьмя
знаками после точки, или «No».

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк x y.

## Выходные данные

«Yes» и два списка вершин или «No».

## Примеры

### Пример 1

Ввод:

```
2
-1 0
1 0
```

Вывод:

```
Yes
-1.0000 0.0000
1.0000 0.0000
-1.0000 0.0000
1.0000 0.0000
```

## Решение

Любая функция на [−a, a] раскладывается ровно одним способом:
E(x) = (f(x) + f(−x))/2 чётна, O(x) = (f(x) − f(−x))/2 нечётна, и их
сумма равна f. Значит, ответ всегда «Yes», и обе части определены
однозначно.

Обе части линейны между точками f и их зеркальными отражениями, поэтому
эти x, упорядоченные и без повторов, — кандидаты в вершины; значения
берутся из f интерполяцией. Внутренний кандидат остаётся только там, где часть
действительно изгибается, ведь три последовательные вершины не могут
лежать на одной прямой. Наклон E между двумя кандидатами равен
(a/b − c/d)/2, где a/b — наклон f там, а c/d — наклон f на отражённом
куске; у O знак плюс. Сравнение двух таких дробей перекрёстным
умножением точно, и все множители меньше 2·10⁹, так что хватает 64 бит.
`O(N log N)`.

Подводные камни:

- ответ «No» не бывает никогда (все тесты);
- отражённая точка часто не является изгибом одной из частей, и если её
  оставить, три вершины окажутся на одной прямой (тесты 05, 07, gen3,
  gen4);
- чётный или нечётный вход оставляет другую часть прямым нулём всего из
  двух вершин (тесты 01, 02, 03, 05, 07);
- изгибы нужно находить по точным наклонам, а не сравнивая
  интерполированные значения в плавающей точке (gen5, тест 07).
