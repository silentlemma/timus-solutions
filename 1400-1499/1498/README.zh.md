# 1498. 助跑一击

[Timus 1498](https://acm.timus.ru/problem.aspx?space=1&num=1498) · 难度 881 · bfs

原题作者 Alex Samsonov，出自 2006 年 10 月 14 日第十三届斯维尔德洛夫斯克州中学生团体程序设计锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

骑士站在 N × M 的场地上（N, M ≤ 100），至多走 L 步（L ≤ 1000）到相邻格，不能离开
场地，也不能进入恶魔所在的格子。之后骑士从恶魔旁边的格子出手一次，力量为 K + 1，
其中 K 是出手前紧接着走过的直线段长度。求最大可能的力量；若根本无法走到恶魔旁边，
输出 0。

时间限制：1 秒。内存限制：64 MB。

## 输入

N、M 和 L，然后是骑士的格子，再是恶魔的格子。

## 输出

最大的力量。

## 样例

### 样例 1

输入:

```
3 4 4
1 1
3 4
```

输出:

```
4
```

## 解法

出手的位置是恶魔旁边至多四个格子中的一个 A，之前沿四个方向之一走了 k 步直线，所以
直线段从 S = A − k·d 开始，段上所有格子都必须在场地内且不是恶魔的格子。在直线段之
前，骑士只需走到 S，所需步数就是封住恶魔格后从起点出发的广度优先距离。当这个距离
加上 k 不超过 L 时方案可行。枚举所有 A、所有方向和所有 k，直到直线段离开场地，取
最大的 k + 1。如果骑士到达 S 时已经在沿该方向移动，真正的直线段只会更长，而这条更
长的线段也会被枚举到。`O(NM)`。

注意事项：

- 最后一段不必指向恶魔：样例中骑士沿一行跑动，然后向下出手；
- 恶魔既挡路也挡助跑，所以有时要借用相邻的行或列来助跑（测试 08）；
- 若恶魔旁边的格子都到不了，答案为 0；骑士一开始就在旁边时，力量至少为 1（测试
  02、03、05）。
