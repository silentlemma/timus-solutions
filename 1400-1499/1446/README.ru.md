# 1446. Волшебная шляпа

[Timus 1446](https://acm.timus.ru/problem.aspx?space=1&num=1446) · сложность 91 · implementation

Автор оригинальной задачи — Станислав Васильев; Десятый командный чемпионат Урала по спортивному программированию, 24–25 марта 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N первокурсников (1 ≤ N ≤ 1000) распределены по факультетам; для
каждого в порядке церемонии одна строка содержит имя (латинские буквы,
пробелы и дефисы, не больше 200 символов), а следующая — факультет.
Нужно вывести списки Слизерина, Хаффлпаффа, Гриффиндора и Рейвенкло в
этом порядке: название факультета с двоеточием, затем его ученики по
одному в строке в порядке церемонии, с пустой строкой между списками. На
каждый факультет попадает хотя бы один ученик.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем 2N строк: имя и факультет каждого ученика.

## Выходные данные

Четыре списка.

## Примеры

### Пример 1

Ввод:

```
7
Ivan Ivanov
Gryffindor
Mac Go Nagolo
Hufflepuff
Zlobeus Zlei
Slytherin
Um Bridge
Slytherin
Tatiana Henrihovna Grotter
Ravenclaw
Garry Potnyj
Gryffindor
Herr Mionag-Ranger
Gryffindor
```

Вывод:

```
Slytherin:
Zlobeus Zlei
Um Bridge

Hufflepuff:
Mac Go Nagolo

Gryffindor:
Ivan Ivanov
Garry Potnyj
Herr Mionag-Ranger

Ravenclaw:
Tatiana Henrihovna Grotter
```

## Решение

Читаем вход построчно, потому что в именах есть пробелы, и добавляем
каждое имя в список нужного факультета; затем выводим списки в нужном
порядке. Из имени убирается только перевод строки, так что пробелы
внутри остаются как есть. `O(N)` строк.

Подводные камни:

- чтение по словам разрывает имена (тесты 01, 03, 04);
- ученика могут звать так же, как факультет (тест 03);
- порядок факультетов в выводе не алфавитный.

## Оптимизированные решения

`1446_implementation_optimized.py`. Сохраняются отдельный bytearray факультета и исходный порядок имён внутри него. Кэшируется связанный метод бинарного readline; внутренние пробелы имени сохраняются удалением лишь CR/LF, ввод остаётся построчным. Готовая группировка сбрасывается перед прямым выходом интерпретатора. Время O(I+O) по байтам ввода/вывода, хранимые имена O(I); читаемая версия сохранена.

Accepted точного исходника CPython 3.12 №11327052: 0.062 с / 812 КБ. Сравнение, сохранённое 2026-11-20 для актуальных компиляторов семейства: место по времени 6/107, по памяти 27/107. При памяти меньше 1024 КБ строгий критерий учитывает только время.

- `1446_implementation_optimized.py`: 0.062 s / 812 KB; сохранённая учебная база `1446_implementation.py` (Python 3.12 x64): 0.062 s / 1520 KB; изменение времени +0.0%; изменение памяти -46.6%.

Оптимизированное решение на Rust обходится без словаря по названиям
факультетов. Оно читает ввод построчно, а не целиком, находит факультет
в списке из четырёх и дописывает каждое имя прямо в байтовый буфер
своего факультета: 492 КБ вместо 980 КБ при том же времени.

Сохранённая `1446_implementation_optimized.java` читает блоки по 4 КБ, узнаёт факультет по отличающейся первой букве и копирует имена байтами в отдельный поток без String. Её замер прежний: 0.062 с / 1180 КБ против Java-базы 0.125 с / 2324 КБ. Текущая Python-группировка и её отдельные метрики описаны выше.

Храним имена в массивах символов фиксированного размера и группируем указатели по факультетам. Принятая посылка 11303747 заняла 0,001 с и использовала 416 КБ. Простая версия заняла 0,031 с и использовала 520 КБ.
