# 1400. Сотовые символы

## Задача

N ≤ 256 дополнительных символов телефона стоят в таблице из M
столбцов, заполненной по строкам; последняя строка может быть короче.
Курсор ходит влево, вправо, вверх и вниз; влево и вправо он также
переходит на предыдущую или следующую строку и с одного конца таблицы на
другой, а вверх из первой строки или вниз на отсутствующую клетку
остаётся на месте. Нужно выбрать начальную клетку с наименьшим средним
числом нажатий до символа и вывести это среднее и число нажатий для
каждого символа.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и M.

## Выходные данные

«Mean = X» с двумя знаками после точки, затем N чисел нажатий, по M в
строке. Подходит любая лучшая начальная клетка.

## Примеры

### Пример 1

Ввод:

```
5 3
```

Вывод:

```
Mean = 1.00
1 0 1
2 1
```

## Решение

Пронумеруем клетки 0 … N − 1 по строкам. Тогда влево и вправо — это
i − 1 и i + 1 по модулю N, вверх — i − M, если такая клетка есть, вниз —
i + M, если она есть; иначе курсор стоит. Поиск в ширину из каждой
начальной клетки даёт все расстояния, и побеждает начало с наименьшей
суммой. `O(N²)`.

Подводные камни:

- для одного символа ответ — Mean = 0.00 и один 0 (тест 02);
- среднее вроде 13/8 = 1.625 — точная середина во втором знаке; решения
  выводят то же, что printf в C, то есть 1.62, поэтому Java округляет
  точное значение double через BigDecimal, а не String.format (тест 07);
- по сообщениям форума есть тесты за пределами условия, например с 46
  столбцами, поэтому ничего не рассчитано на эти пределы (тест 06).

Тесты проверяются программой, которая требует наименьшее среднее и
расстояния от какой-то начальной клетки с этим средним.
