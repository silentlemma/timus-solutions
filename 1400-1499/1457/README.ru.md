# 1457. Теплотрасса

## Задача

Прямая теплотрасса проходит под N пунктами (1 ≤ N ≤ 1000) в точках P[i]
(0 ≤ P[i] ≤ 10⁶). Усилия на преодоление расстояния пропорциональны его
квадрату. Нужно найти точку теплотрассы, для которой среднее усилие на
путь до пунктов наименьшее, с не менее чем шестью знаками после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N положений.

## Выходные данные

Лучшая точка.

## Примеры

### Пример 1

Ввод:

```
3
7 4 5
```

Вывод:

```
5.333333
```

## Решение

Среднее (x − P[i])² — парабола по x, производная которой 2 (x − среднее)
обращается в ноль в среднем арифметическом положений, так что ответ —
сумма, делённая на N. Сумма не превосходит 10⁹ и помещается в любой
целый тип. `O(N)`.

Подводные камни:

- округление до шести знаков может различаться в разных языках, когда
  среднее оканчивается ровно на пятёрку, как 1/128 (тест 05); принимается
  любой ответ с требуемой точностью.
