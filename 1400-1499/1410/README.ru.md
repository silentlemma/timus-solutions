## Задача

Дана фраза: слова — это отрезки из латинских букв, все остальные
символы их разделяют; слова не повторяются без учёта регистра. Артур
отвечает той же фразой, вычеркнув несколько слов и сохранив порядок.
Слово можно произносить не больше секунд, чем в нём букв, и никакие
два слова, стоявшие во фразе рядом, не могут остаться оба. Сколько
секунд может длиться ответ?

До 10 000 слов длиной до 100 букв, вход не больше 512 КБ.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Фраза.

## Выходные данные

Наибольшая длительность ответа в секундах.

## Примеры

### Пример 1

Ввод:

```
You have come a long way
```

Вывод:

```
11
```

В примере ответ — «You come long».

## Решение

Два слова образуют в ответе запрещённую пару ровно тогда, когда во
фразе они стояли рядом, так что нужно выбрать слова без соседних пар
с наибольшей суммарной длиной. Идём по словам и храним два числа:
лучшую сумму, если последнее слово оставлено, и если вычеркнуто.
Новое слово длины w даёт kept' = dropped + w и
dropped' = max(kept, dropped). C++ и Java выделяют слова при чтении;
Go и Rust сначала читают весь вход, а Python также хранит список слов.
Во всех версиях ДП хранит две суммы. Время `O(L)`, где L — размер входа.

Подводные камни:

- слова должны быть различны без учёта регистра во всей фразе, в том
  числе в сгенерированных входах (gen3, seed 6);
- фраза может занимать несколько строк (тест 02);
- любой символ, кроме буквы, разделяет слова, включая апострофы, цифры
  и `=`, а несколько разделителей подряд не дают пустых слов (тесты 04,
  05, gen4);
- во входе может не быть ни одного слова, тогда ответ 0 (тесты 03 и
  06);
- брать сначала самое длинное слово неверно: в «tiny Enormous small»
  выигрывают два коротких (тест 08).
