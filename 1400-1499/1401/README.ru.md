# 1401. Игроки

[Timus 1401](https://acm.timus.ru/problem.aspx?space=1&num=1401) · сложность 168 · constructive

Автор оригинальной задачи — Алексей Самсонов; XII командный чемпионат школьников Свердловской области по программированию, 15 октября 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно замостить доску 2ⁿ × 2ⁿ, n ≤ 9, без одной клетки уголками из трёх
клеток. Вывести доску с 0 на выбитой клетке и номером фигуры на каждой
остальной, фигуры пронумерованы от 1 до (4ⁿ − 1) / 3, или -1, если
замостить нельзя.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

n, затем строка и столбец выбитой клетки.

## Выходные данные

2ⁿ строк по 2ⁿ чисел. Подходит любое замощение.

## Примеры

### Пример 1

Ввод:

```
2
1 1
```

Вывод:

```
0 1 3 3
1 1 4 3
2 4 4 5
2 2 5 5
```

## Решение

Замощение всегда существует, делением пополам. Разобьём доску на четыре
четверти; выбитая клетка лежит в одной из них. Положим уголок на три
клетки у середины доски, принадлежащие трём другим четвертям. Теперь
каждая четверть — доска 2ⁿ⁻¹ × 2ⁿ⁻¹ ровно с одной занятой клеткой, то
есть та же задача, а доска 1 × 1 ничего не требует. Решения держат ещё
не замощённые квадраты в стеке вместо рекурсии, каждый со своей занятой
клеткой, и нумеруют фигуры в порядке укладки. `O(4ⁿ)`.

Подводные камни:

- ответ никогда не равен -1;
- доска 512 × 512 — это 262 144 числа, поэтому вывод собирается в один
  буфер (сгенерированные тесты).

Тесты проверяются программой, которая требует 0 только на выбитой
клетке и каждое число от 1 до (4ⁿ − 1) / 3 ровно на трёх клетках,
образующих уголок внутри квадрата 2 × 2.
