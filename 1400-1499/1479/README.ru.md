# 1479. Контроль по расписанию

[Timus 1479](https://acm.timus.ru/problem.aspx?space=1&num=1479) · сложность 3958 · bitmask

Автор оригинальной задачи — Александр Ипатов; контест УрГУ и ОрёлГТУ на Петрозаводских летних сборах, август 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В простом графе N остановок (3 ≤ N ≤ 14) и M дорог. Фирма запускает
как можно больше маршрутов, каждый — кольцо не меньше чем через три
разные остановки без повторов, причём любые два маршрута отличаются хотя
бы одной дорогой. Расписание — это таблица: строки — моменты времени,
столбцы — маршруты, а в клетке стоит остановка, где маршрутку этого
маршрута проверяют в этот момент. Каждую маршрутку проверяют по одному
разу на каждой остановке её маршрута, на одной остановке не проверяют
две маршрутки сразу, и маршрутка не бывает на двух остановках сразу.
Нужно найти наименьшее возможное число строк.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем M строк с двумя остановками дороги.

## Выходные данные

Наименьшее число строк.

## Примеры

### Пример 1

Ввод:

```
4 4
1 2
2 3
1 3
1 4
```

Вывод:

```
3
```

## Решение

Два разных простых цикла всегда отличаются какой-то дорогой, так что
маршруты — это все простые циклы графа. Соединим каждый маршрут с
каждой его остановкой: расписание должно покрыть каждую такую пару один
раз, а строка — это набор пар без общих маршрутов и остановок, то есть
паросочетание. Покрытие рёбер двудольного графа паросочетаниями — это
рёберная раскраска, и по теореме Кёнига хватает наибольшей степени.
Значит, ответ — большее из длины самого длинного маршрута (числа его
остановок) и наибольшего числа маршрутов через одну остановку, или 0,
если циклов нет.

Циклы считаются по множествам остановок. Для каждого множества S
считаем простые пути, которые начинаются в наименьшей остановке S,
проходят всё S и кончаются в v; те, у которых v соседняя с началом,
замыкаются в циклы с множеством остановок S, и каждый цикл учтён по
разу на направление. Путь растёт только через остановки больше своего
начала, поэтому каждый цикл виден только из своей наименьшей остановки.
Прибавив циклы каждого S к каждой остановке S, получаем числа по
остановкам. `O(2^N·N²)`.

Подводные камни:

- если циклов нет, нет ни маршрутов, ни строк (тесты 02, 03);
- когда соединены все 14 остановок, через каждую проходит около
  8,5·10⁹ маршрутов, и нужны 64 бита (тест 06);
- у одиночного кольца через каждую остановку идёт один маршрут, так что
  решает его длина (тест 04), а у двух треугольников с общей остановкой
  через неё идут два маршрута, но строк всё равно нужно 3 (тест 07).
