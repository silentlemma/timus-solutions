# 1479. 按时检查

[Timus 1479](https://acm.timus.ru/problem.aspx?space=1&num=1479) · 难度 3929 · bitmask

原题作者 Alexander Ipatov，出自 2006 年 8 月彼得罗扎沃茨克夏季集训的乌拉尔国立大学与奥廖尔国立技术大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个无向简单图有 N 个站点（3 ≤ N ≤ 14）和 M 条道路。公司开设尽可能多的线路，每条线
路是经过至少三个不同站点、不重复站点的环，并且任意两条线路至少有一条道路不同。
时刻表是一张表格：行是时刻，列是线路，格子里写的是该线路的车在该时刻接受检查的
站点。每辆车在其线路的每个站点各接受一次检查，同一站点同一时刻不能检查两辆车，
一辆车也不能同时在两个站点。求表格的最少行数。

时间限制：2 秒。内存限制：64 MB。

## 输入

N 和 M，然后是 M 行，每行是一条道路连接的两个站点。

## 输出

最少的行数。

## 样例

### 样例 1

输入:

```
4 4
1 2
2 3
1 3
1 4
```

输出:

```
3
```

## 解法

两个不同的简单环总有某条道路不同，所以线路就是图中所有的简单环。把每条线路与它
的每个站点相连：时刻表必须把每个这样的配对恰好覆盖一次，而一行就是一组既不共用
线路也不共用站点的配对，即一个匹配。用匹配覆盖二分图的边就是边染色，由 König
定理，最大度数就够了。所以答案是最长线路的站点数与经过同一站点的最多线路数中的
较大者；若没有环则为 0。

按站点集合来数环。对每个集合 S，统计从 S 中最小站点出发、经过 S 的全部站点、终
止于 v 的简单路径；其中 v 与起点相邻的路径可以闭合成站点集合为 S 的环，每个环按
两个方向各计一次。路径只经过比起点大的站点，所以每个环只会从它的最小站点被看
到。把每个 S 的环数加到 S 的每个站点上，就得到每个站点的线路数。`O(2^N·N²)`。

注意事项：

- 没有环时既没有线路也没有行（测试 02、03）；
- 14 个站点两两相连时，每个站点约有 8.5·10⁹ 条线路经过，需要 64 位（测试 06）；
- 单独一个环时每个站点只有一条线路经过，所以由环的长度决定（测试 04）；两个共
  用一个站点的三角形在该站点有两条线路，但仍需要 3 行（测试 07）。
