# 1412. Осенняя пора

[Timus 1412](https://acm.timus.ru/problem.aspx?space=1&num=1412) · сложность 1530 · geometry

Автор оригинальной задачи — Павел Егоров; чемпионат Уральского государственного университета, 29 октября 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Дождь падает отвесно, 1 мм в минуту, на прямоугольное поле с углами
(0, 0), (0, W), (L, 0) и (L, W) (1 ≤ W, L ≤ 10 000). N человек
(N ≤ 1000) стоят в заданных точках (|X|, |Y| ≤ 10 000), каждый под
зонтом в форме верхней полусферы радиуса 1 м. Вода на зонте стекает
по кратчайшему пути по полусфере и падает с края. Зонты не
перекрываются, а высокие столбы в углах поля не дают зонту накрыть
угол. Нужно вывести количество дождя, попадающего на поле за минуту, с
3 знаками после точки.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

W и L, затем N, затем N строк с X и Y.

## Выходные данные

Количество дождя на поле.

## Примеры

### Пример 1

Ввод:

```
10 10
2
0.5 2
2 10.1
```

Вывод:

```
99.666
```

## Решение

Кратчайший путь от точки полусферы до края идёт по меридиану, поэтому
дождь, упавший на круг зонта под углом θ, стекает с края под тем же
углом θ: пойманные зонтом π единиц распределяются по краю равномерно.
Без зонтов поле получает W·L, а каждый зонт меняет это на π, умноженное
на долю края над полем, минус площадь круга над полем.

Площадь единичного круга внутри прямоугольника — сумма по четырём
сторонам знаковой площади круга внутри треугольника от центра до
стороны: сторона режется в точках пересечения с окружностью, кусок
внутри круга добавляет свой треугольник, а кусок снаружи — свой
сектор. Доля края получается разрезанием окружности в углах, где она
встречает четыре граничные прямые, и проверкой середины каждой дуги.
`O(N)`.

Подводные камни:

- несмотря на слово «среднее» в условии, ожидается суммарное
  количество на всё поле, W·L, если ничто не мешает (тесты 01, 05);
- X идёт вдоль L, второго числа, а Y — вдоль W; один случай с форума
  согласуется только с таким прочтением (тесты 02, 10);
- край или сторона, лишь касающиеся окружности, не должны засчитывать
  внутрь целую дугу или хорду, поэтому точки касания разрезают дуги, а
  проверка круга строгая (тесты 11, 12);
- зонт вне поля всё равно может ронять воду на него (тест 08).
