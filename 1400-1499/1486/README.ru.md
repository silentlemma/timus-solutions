# 1486. Одинаковые квадраты

[Timus 1486](https://acm.timus.ru/problem.aspx?space=1&num=1486) · сложность 621 · hashing

Автор оригинальной задачи — Владимир Яковлев; чемпионат Уральского государственного университета, 7 октября 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В матрице N × M из строчных латинских букв (1 ≤ N, M ≤ 500) нужно найти
наибольшее K, при котором два разных квадрата K × K (они могут
пересекаться, но не совпадать) одинаковы, и вывести K и их левые
верхние клетки, или 0, если одинаковых клеток нет.

Ограничение времени: 2 секунды. Ограничение памяти: 128 МБ.

## Входные данные

N и M, затем N строк по M букв.

## Выходные данные

K, затем две клетки как строка и столбец, или только 0. Подходит любая
пара.

## Примеры

### Пример 1

Ввод:

```
5 10
ljkfghdfas
isdfjksiye
pgljkijlgp
eyisdafdsi
lnpglkfkjl
```

Вывод:

```
3
1 1
3 3
```

## Решение

Два разных одинаковых квадрата K × K содержат два разных одинаковых
квадрата (K − 1) × (K − 1) — свои левые верхние части. Значит,
существование пары размера K монотонно по K, и двоичный поиск находит
наибольшее K примерно за девять проверок.

Проверка хеширует все квадраты K × K за `O(NM)`: скользящий хеш по
каждой строке даёт хеш каждого окна из K букв, а второй скользящий хеш
с другим основанием идёт вниз по каждому столбцу этих строковых хешей.
У одинаковых квадратов одинаковые хеши. Повторившийся хеш
подтверждается побуквенным сравнением квадратов, так что коллизия может
стоить лишь времени, но не неверного ответа.
`O(NM log min(N, M))`.

Подводные камни:

- квадраты могут пересекаться, как на шахматной доске, где лучшие
  квадраты сдвинуты на одну клетку (тест 07);
- если ни одна буква не повторяется, ответ — один 0 (тесты 02, 03, 05);
- квадратная матрица из одной буквы допускает только K = N − 1, ведь два
  квадрата N × N совпали бы; вытянутая допускает min(N, M) (gen4,
  тест 06).

## Особенности языков

- Остальные языки упаковывают два хеша по модулям 10⁹ + 7 и 998244353 в
  один 64-битный ключ.

- Python не хеширует квадраты, а нумерует их точно. Каждый квадрат 2 × 2
  получает номер своего класса, квадрат стороны 2s — класс своих четырёх
  угловых квадратов стороны s, а квадраты, чей класс состоит из одного
  элемента, отбрасываются: никакой больший повторяющийся квадрат не
  имеет их углом. После наибольшей стороны p = 2ʲ с повтором двоичный
  поиск между p и 2p нумерует каждый квадрат K × K по четырём его углам
  стороны p, которые перекрываются и покрывают его. Классы хранятся в
  таблицах с открытой адресацией на плоских массивах, сравнивающих все
  четыре номера, так что коллизия не может дать неверный ответ. Решение
  запускается под PyPy, у судьи 0,41 с и 21 МБ; прежние версии со
  скользящими хешами превышали лимит 2 с на тестах 10 и 23 жюри, а
  версия со словарём на каждую группу — лимит 128 МБ на тесте 23.
