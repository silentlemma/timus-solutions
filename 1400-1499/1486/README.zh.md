# 1486. 相同的正方形

[Timus 1486](https://acm.timus.ru/problem.aspx?space=1&num=1486) · 难度 620 · hashing

原题作者 Vladimir Yakovlev，出自 2006 年 10 月 7 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

在由小写字母组成的 N × M 矩阵（1 ≤ N, M ≤ 500）中，找出最大的 K，使得存在两个不
同的 K × K 正方形（可以重叠，但不能重合）完全相同，输出 K 和它们的左上角；若没有
两个相同的格子，输出 0。

时间限制：2 秒。内存限制：128 MB。

## 输入

N 和 M，然后是 N 行，每行 M 个字母。

## 输出

K，然后是两个左上角的行号和列号；或者只输出 0。任意一对都可以。

## 样例

### 样例 1

输入:

```
5 10
ljkfghdfas
isdfjksiye
pgljkijlgp
eyisdafdsi
lnpglkfkjl
```

输出:

```
3
1 1
3 3
```

## 解法

两个不同的相同 K × K 正方形，它们左上方的 (K − 1) × (K − 1) 部分也是两个不同的相
同正方形。所以"存在大小为 K 的一对"关于 K 单调，二分查找大约九次检查即可找到最
大的 K。

一次检查用 `O(NM)` 算出所有 K × K 正方形的哈希：在每一行上做滚动哈希，得到每个长
为 K 的窗口的哈希；再用另一个底数沿每一列对这些行哈希做第二次滚动哈希。相同的正
方形哈希相同。将哈希排序后，对键相同的候选逐字母比较。这不会误认不同的正方形，
但哈希冲突可能掩盖一对相同的正方形。无冲突时，`O(NM log(NM) log min(N, M))`。

注意事项：

- 两个正方形可以重叠，比如棋盘图案中最佳正方形只相差一步（测试 07）；
- 若没有重复的字母，答案只有一个 0（测试 02、03、05）；
- 全是同一字母的方阵只能取 K = N − 1，因为两个 N × N 正方形会重合；非方阵则可取
  min(N, M)（gen4、测试 06）。

## 优化解法

Go 与 Python 一样用四个角的类别为正方形分类。开放寻址表会比较全部四个标签，因此哈希冲突不会合并不同类别。提交 11317159 耗时 0.062 秒，使用 6296 KB；基础版耗时 0.734 秒，使用 27468 KB。

## 语言说明

- 其他语言把模 10⁹ + 7 和 998244353 的两个哈希打包成一个 64 位键。

- Python 不对正方形做哈希，而是精确编号。每个 2 × 2 正方形得到其等价类的编号，边长 2s 的正方形取其四个边长为 s 的角上正方形的类；类中只有一个成员的正方形被丢弃，因为没有更大的重复正方形以它为角。在有重复的最大边长 p = 2ʲ 之后，在 p 与 2p 之间二分，用边长为 p 的四个互相重叠、覆盖整体的角给每个 K × K 正方形编号。等价类存放在基于扁平数组的开放寻址表中，比较全部四个编号，因此冲突不会导致错误答案。它在 PyPy 下运行，评测用时 0.41 秒、内存 21 MB；使用滚动哈希的早期版本在评测第 10 和第 23 个测试上超过 2 秒的限制，每组一个字典的版本在第 23 个测试上超过 128 MB。
