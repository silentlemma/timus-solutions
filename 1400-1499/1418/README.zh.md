# 1418. 军旅故事

[Timus 1418](https://acm.timus.ru/problem.aspx?space=1&num=1418) · 难度 1491 · geometry

原题作者 Alexey Lakhtin，出自 2005 年 10 月 29 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 根互不相同的柱子立在整点上（3 ≤ N ≤ 4000，坐标在 0 到 10 000 之间）。围栏是
以柱子为顶点、面积非零的简单多边形；围栏之间不能相接或相交，并且每个都必须位于
下一个之内。求围栏的最大数目。

时间限制：2 秒。内存限制：64 MB。

## 输入

N，然后 N 行坐标。

## 输出

围栏的最大数目。

## 样例

### 样例 1

输入:

```
4
100 100
200 100
100 200
300 300
```

输出:

```
1
```

## 解法

位于凸包边界上的柱子（无论在顶点还是在边的中间）都不可能严格位于以柱子为顶点
的多边形内部，因为这样的多边形在凸包之内。所以只有最外层围栏能使用这些柱子，
所有内层围栏只用严格位于凸包内部的柱子；归纳可知，围栏数不超过凸包层数：去掉
整个凸包边界，再去掉剩余点凸包的边界，依此类推，直到剩下的柱子面积为零。这些
凸包本身就达到这个上界，每个都严格位于前一个之内。

柱子只需排序一次；之后每一层用 Andrew 单调链在线性时间内求出，只在严格右转时
弹栈，使边上的柱子留在链中。当剩下不足三根柱子或全部共线时停止。最坏情况（N /
3 个嵌套三角形）为 `O(N²)`。

注意事项：

- 凸包边中间的柱子属于外层（测试 09）；
- 剩下的共线柱子，或剩下的一两根柱子，都不能构成围栏（测试 02、07、08、gen4）；
- 稠密网格的每条凸包边上都有很多柱子（测试 06、07、gen3）。
