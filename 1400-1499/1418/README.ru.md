# 1418. Армейская история

## Задача

N различных столбов стоят в целых точках (3 ≤ N ≤ 4000, координаты от
0 до 10 000). Заборы — простые многоугольники ненулевой площади с
углами в столбах; они не должны касаться или пересекаться, и каждый
должен лежать внутри следующего. Нужно найти наибольшее число заборов.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк с координатами.

## Выходные данные

Наибольшее число заборов.

## Примеры

### Пример 1

Ввод:

```
4
100 100
200 100
100 200
300 300
```

Вывод:

```
1
```

## Решение

Столб на границе выпуклой оболочки — в вершине или в середине
стороны — никогда не окажется строго внутри многоугольника с углами в
столбах, ведь такой многоугольник лежит внутри оболочки. Значит, эти
столбы может использовать только внешний забор, все внутренние заборы
используют лишь столбы строго внутри оболочки, и по индукции заборов не
больше, чем слоёв оболочек: убираем всю границу оболочки, затем границу
оболочки остатка и так далее, пока оставшиеся столбы имеют
положительную площадь. Сами оболочки достигают этой границы, каждая
строго внутри предыдущей.

Столбы сортируются один раз; каждый слой затем находится монотонной
цепочкой Эндрю за линейное время, причём выталкиваем только при строгом
правом повороте, чтобы столбы на сторонах оставались в цепочке.
Очистка останавливается, когда осталось меньше трёх столбов или все
они лежат на одной прямой. `O(N²)` в худшем случае — N / 3 вложенных
треугольников.

Подводные камни:

- столбы в серединах сторон оболочки принадлежат внешнему слою
  (тест 09);
- оставшиеся на одной прямой столбы, как и один-два оставшихся, забора
  не дают (тесты 02, 07, 08, gen4);
- на плотной сетке на каждой стороне оболочки много столбов (тесты 06,
  07, gen3).
