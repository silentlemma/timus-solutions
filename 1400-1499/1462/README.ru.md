# 1462. Золото дядюшки Скруджа

[Timus 1462](https://acm.timus.ru/problem.aspx?space=1&num=1462) · сложность 847 · math

Автор оригинальной задачи — Александр Ипатов; контест УрГУ на Петрозаводских зимних сборах, январь 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

У дядюшки Скруджа есть по одному золотому слитку на каждую строку из 0 и
1 длины 2N − 2 без двух нулей подряд и по одному сейфу на каждую такую
строку длины N − 2 (3 ≤ N ≤ 70000). В каждый сейф кладётся одинаковое
число слитков, а остаток, меньший числа сейфов, идёт на
благотворительность. Нужно найти, сколько слитков лежит в каждом сейфе.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

Число слитков в каждом сейфе.

## Примеры

### Пример 1

Ввод:

```
3
```

Вывод:

```
4
```

## Решение

Строки длины k без двух нулей подряд считаются числами Фибоначчи:
строка оканчивается на 1 после любой более короткой или на 10 после
строки на две буквы короче, так что их F(k + 2) при F(1) = F(2) = 1.
Слитков F(2N), сейфов F(N), и тождество F(2N) = F(N) · L(N) с числами
Люка L(0) = 2, L(1) = 1, L(k + 1) = L(k) + L(k − 1) показывает, что
слитки делятся нацело: ответ — L(N), и на благотворительность ничего не
остаётся.

В L(70000) 14630 цифр, поэтому число строится повторным сложением
длинных чисел: в Python и Java есть длинная арифметика, в Go — math/big,
а в C++ и Rust числа хранятся разрядами по 18 десятичных цифр.
Всего `O(N²)` операций с цифрами, несколько десятков миллионов.

Подводные камни:

- ответ не помещается в знаковые 64 бита уже при N = 92, а в
  беззнаковые — при N = 93 (тесты 06, 07);
- Python 3.12 отказывается печатать целые длиннее 4300 цифр, пока это
  ограничение не снято (тесты 09, 10).
