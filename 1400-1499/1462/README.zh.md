# 1462. 史高治叔叔的金子

[Timus 1462](https://acm.timus.ru/problem.aspx?space=1&num=1462) · 难度 847 · math

原题作者 Alexander Ipatov，出自 2006 年 1 月彼得罗扎沃茨克冬季集训的乌拉尔国立大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

史高治叔叔为每个长度为 2N − 2、不含两个连续 0 的 01 串准备了一根金条，又为每个长
度为 N − 2 的这种串准备了一个保险箱（3 ≤ N ≤ 70000）。每个保险箱放入同样多的金
条，剩下的金条（少于保险箱数）捐给慈善机构。求每个保险箱里有多少根金条。

时间限制：1 秒。内存限制：64 MB。

## 输入

N。

## 输出

每个保险箱中的金条数。

## 样例

### 样例 1

输入:

```
3
```

输出:

```
4
```

## 解法

长度为 k、不含两个连续 0 的串的个数是斐波那契数：串要么在任意更短的串后接 1，要
么在短两位的串后接 10，所以共有 F(k + 2) 个，其中 F(1) = F(2) = 1。金条有 F(2N)
根，保险箱有 F(N) 个，而恒等式 F(2N) = F(N) · L(N)（卢卡斯数 L(0) = 2，
L(1) = 1，L(k + 1) = L(k) + L(k − 1)）说明金条恰好能整除：答案是 L(N)，没有剩余
捐出。

L(70000) 有 14630 位，所以用大数反复相加求出：Python 和 Java 自带大整数，Go 有
math/big，C++ 和 Rust 则把数按 18 位十进制分段存放。总共 `O(N²)` 次数位运算，约
几千万次。

注意事项：

- N = 92 时答案超出有符号 64 位整数，N = 93 时超出无符号 64 位整数（测试 06、07）；
- Python 3.12 默认拒绝打印超过 4300 位的整数，需要解除限制（测试 09、10）。
