# 1427. SMS

[Timus 1427](https://acm.timus.ru/problem.aspx?space=1&num=1427) · сложность 364 · greedy

Авторы оригинальной задачи — Дмитрий Ковалёв, Никита Рыбак и Илья Гребнов; Timus Top Coders: First Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Текст длиной до 100 000 символов (латинские буквы, пробелы, цифры и
знаки . , ; : ! ? - ") разбивается на последовательные SMS. Сообщение
только из букв и пробелов может иметь длину до M символов, любое
другое — только до N (1 ≤ N ≤ M ≤ 10 000). Нужно найти наименьшее
число сообщений.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N и M, затем текст отдельной строкой.

## Выходные данные

Наименьшее число сообщений.

## Примеры

### Пример 1

Ввод:

```
10 15
On the 11-th of February, 2006 the contest "Timus Top Coders: First Challenge" is held!
```

Вывод:

```
8
```

## Решение

Пусть run(i) — число букв и пробелов подряд, начиная с позиции i.
Сообщение, начатое в i, может закончиться где угодно до
i + max(N, min(M, run(i))). Этот самый дальний конец не отступает
назад с ростом i (и i + N, и конец отрезка букв только растут), а при
такой монотонной досягаемости жадность, всегда отправляющая самое
длинное сообщение, оптимальна: любой другой план на каждом шаге
продвигается не дальше. Отрезки букв считаются с конца текста. `O(L)`.

Подводные камни:

- текст может начинаться с пробелов, поэтому вторую строку нужно
  читать целиком, а не после пропуска пробелов (тест 04);
- цифры не считаются буквами (тесты 03, 06);
- сообщение из букв всё равно может быть короче N; длинная форма
  помогает, только когда отрезок букв длиннее N (тест 05).
