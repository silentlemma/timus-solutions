# 1463. 给人们带来欢乐！

[Timus 1463](https://acm.timus.ru/problem.aspx?space=1&num=1463) · 难度 598 · dp

原题作者 Alexander Toropov，特别感谢 Alexander Ipatov，出自 2006 年 1 月彼得罗扎沃茨克冬季集训的乌拉尔国立大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 N 座城市（1 ≤ N ≤ 50000），访问城市 i 带来欢乐 A[i]；有 K 条城市间的航线，沿
航线飞行带来欢乐 c；所有值都是不超过 10000 的非负整数。任意两座城市之间至多一条
路线，所以航线构成森林。求一条经过不同城市、可从任意城市出发的路线，使城市与航
线的欢乐总和最大。

时间限制：1 秒。内存限制：64 MB。

## 输入

N 和 K，然后是 A[i]，再是 K 行 a、b、c。

## 输出

最大欢乐值、路线上的城市数以及路线。任何最优路线都被接受。

## 样例

### 样例 1

输入:

```
2 1
1 1
1 2 1
```

输出:

```
3
2
1 2
```

### 样例 2

输入:

```
8 7
1 5 4 6 10 1 2 2
1 2 1
2 3 10
2 4 1
4 5 1
4 6 2
6 7 2
6 8 3
```

输出:

```
37
4
5 4 2 3
```

## 解法

森林中的路线就是某棵树里的一条路径，把树挂在根上后，每条路径都有一个最高的城
市。把每棵树任意定根，从叶子向上处理城市。对每座城市 v 记录从 v 出发向下的最优路
线 down[v] = A[v] 加上各子节点 w 的 c + down[w] 中的最大值，并记下给出该值的子节
点。以 v 为最高城市的最优路线把子节点中最好的两个值接到 A[v] 上；所有值都非负，
所以取两个子节点（或一个，或零个）都不会更差。沿保存的子节点向下遍历两条选定的分支即可重建
路线。

树的深度可达 50000，所以遍历用显式栈而不是递归。`O(N + K)`。

注意事项：

- 可能完全没有航线，最优路线也可能只有一座城市（测试 03、04、07、gen5）；
- 长链会让递归溢出（gen2）；
- 欢乐值全为零时，任何路线都是最优的（测试 05）。

## 优化解法

C++ 版本不断移除叶子。对每个城市记录当前度数、剩余邻居编号的异或值和剩余航线欢乐值的异或值。对叶子，这两个异或值直接给出唯一剩余航线。保留已移除的两条最优分支即可计算并还原经过该城市的最优路线。时间复杂度为 O(N + K)，额外空间为 O(N)。评测数据来自提交 11317012。

Python 版本同样逐个移除叶子。每次移除一条分支时，先把它与父节点已有的最优分支合并，再更新父节点的最优分支。保存两条选中分支的起点即可还原最优路线。时间复杂度为 O(N + K)，额外空间为 O(N)。评测数据来自提交 11317010。

Go 版本使用紧凑的城市记录数组逐个移除叶子。异或运算可在无需邻接表的情况下找出剩余邻居和边权。提交 11317154 耗时 0.078 秒，使用 1976 KB；基础版耗时 0.125 秒，使用 11580 KB。

Rust 版本用紧凑记录保存城市数据并移除叶子，通过异或运算找出剩余邻居和边权。提交 11317155 耗时 0.015 秒，使用 980 KB；基础版耗时 0.031 秒，使用 10112 KB。

Java 版本逐个移除叶子，并用异或运算找出剩余邻居和边权。提交 11317156 耗时 0.140 秒，使用 1276 KB；基础版耗时 0.156 秒，使用 3896 KB。
