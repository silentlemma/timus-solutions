# 1463. Радость населению!

[Timus 1463](https://acm.timus.ru/problem.aspx?space=1&num=1463) · сложность 598 · dp

Автор оригинальной задачи — Александр Торопов, особая благодарность Александру Ипатову; контест УрГУ на Петрозаводских зимних сборах, январь 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть N городов (1 ≤ N ≤ 50000) с радостью A[i] за посещение и K
связей между парами городов с радостью c за перелёт по ним; все значения
— неотрицательные целые до 10000. Между любыми двумя городами не больше
одного маршрута, поэтому связи образуют лес. Нужно найти маршрут по
различным городам, начинающийся где угодно, с наибольшей суммарной
радостью городов и перелётов.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N и K, затем радости A[i], затем K строк a, b, c.

## Выходные данные

Наибольшая радость, число городов маршрута и сам маршрут. Принимается
любой лучший маршрут.

## Примеры

### Пример 1

Ввод:

```
2 1
1 1
1 2 1
```

Вывод:

```
3
2
1 2
```

### Пример 2

Ввод:

```
8 7
1 5 4 6 10 1 2 2
1 2 1
2 3 10
2 4 1
4 5 1
4 6 2
6 7 2
6 8 3
```

Вывод:

```
37
4
5 4 2 3
```

## Решение

Маршрут в лесу — это путь в одном дереве, и у каждого пути есть самый
верхний город, если подвесить дерево за корень. Подвесим каждое дерево
за любой город и пройдём города от листьев вверх. Для каждого города v
храним лучший маршрут, начинающийся в v и идущий вниз:
down[v] = A[v] плюс лучшее значение c + down[w] по детям w, вместе с
ребёнком, который его даёт. Лучший маршрут с верхним городом v
соединяет с A[v] два лучших таких значения детей; все значения
неотрицательны, поэтому взять двух детей (или одного, или ни одного)
никогда не вредно. Маршрут восстанавливается спуском по сохранённым
детям вдоль двух выбранных ветвей.

Деревья бывают глубиной в 50000 городов, поэтому обход использует явный
стек вместо рекурсии. `O(N + K)`.

Подводные камни:

- связей может не быть вовсе, а лучший маршрут — один город (тесты 03,
  04, 07, gen5);
- длинная цепь переполняет рекурсию (gen2);
- при нулевых радостях лучший любой маршрут (тест 05).
