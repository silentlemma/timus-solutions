## Задача

Двум игрокам сдают по три карты. Дима может незаметно заменить одну или
две сданные карты двумя картами из рукава, но не достаёт карту, равную
одной из карт Саши, и не оставляет себе двух одинаковых карт.
Комбинации от старшей: три тройки, стрит-флэш, тройка, стрит, флэш,
пара, старшая карта. Одинаковые комбинации или руки без пары
сравниваются по достоинствам от старшего; у пары сначала сравнивается
пара, потом непарная карта. Туз старший, а 2-3-туз и король-туз-2 не
стриты. Для каждой игры нужно вывести «Dima», если Дима может выиграть,
«Artyom» (дилер, которому достаётся ничья), если можно лишь сыграть
вничью, и «Sasha» иначе.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Игры через пустую строку: три карты Саши, три карты Димы и две карты в
рукаве, записанные как 10H или QS.

## Выходные данные

По имени на каждую игру.

## Примеры

### Пример 1

Ввод:

```
4C AC 2C
4S KD 6H
5C KH

JS 8H JC
8C 8D 10H
8H 10H

10D 8D 9D
3D 3C 3H
AH AS

2C 3D 4H
2D 3H 4S
AH AH
```

Вывод:

```
Dima
Sasha
Dima
Artyom
```

## Решение

У Димы не больше десяти рук на выбор: сданная, каждая из трёх карт,
заменённая любой картой из рукава, и обе карты из рукава вместе с одной
сданной. Сначала отбрасываются карты из рукава, равные картам Саши, а
руки с двумя одинаковыми картами пропускаются.

Каждой руке сопоставляется ключ, который упорядочен так же, как руки:
номер комбинации, затем достоинства для разрешения ничьих. Достоинства
идут от старшего; у пары — достоинство пары, затем непарной карты. Трём
тройкам больше ничего не нужно. Дима выигрывает, если какой-то ключ
старше ключа Саши, играет вничью, если какой-то ключ равен ему, и
проигрывает иначе. `O(1)` на игру.

Подводные камни:

- 2-3-туз и король-туз-2 не стриты, а дама-король-туз — стрит (тест 02);
- в рукаве может оказаться карта Саши, копия собственной карты Димы или
  две одинаковые карты, и ни одну нельзя использовать запрещённым
  образом (тесты 01, 02, gen3);
- три тройки старше даже лучшего стрит-флэша (тесты 01, 02);
- равные ключи означают ничью даже при разных мастях (тест 02, gen2).
