# 1409. Два бандита

[Timus 1409](https://acm.timus.ru/problem.aspx?space=1&num=1409) · сложность 15 · math

Автор оригинальной задачи — Ден Расковалов; XII командный чемпионат школьников Свердловской области по программированию, 15 октября 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В ряд стоят не больше 10 банок. Гарри стреляет по ним по очереди
слева, Ларри — справа, и последнюю банку оба поражают одновременно.
По числу банок, простреленных каждым, нужно найти, сколько банок не
прострелил Гарри и сколько не прострелил Ларри.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Числа банок, простреленных Гарри и Ларри.

## Выходные данные

Числа банок, не простреленных Гарри и Ларри.

## Примеры

### Пример 1

Ввод:

```
4 7
```

Вывод:

```
6 3
```

## Решение

Общая банка учтена в обоих числах, поэтому банок было H + L − 1.
Гарри не прострелил остальные L − 1 банок Ларри, а Ларри — H − 1,
так что ответ — L − 1 и H − 1. `O(1)`.

Подводные камни:

- ответ для Гарри берётся из числа Ларри и наоборот, порядок легко
  перепутать (тест 03);
- одна банка даёт 0 0 (тест 02).

## Оптимизированные решения

Оптимизированное решение на C++ читает и пишет через `scanf` и
`printf` вместо `iostream`, что требует меньше памяти: 124 КБ вместо
400 КБ при том же времени.

Оптимизированное решение на Java разбирает два числа побайтно из
`System.in` вместо `Scanner`: 336 КБ вместо 1560 КБ при том же времени.
