# 1449. Кредитные операции 2

[Timus 1449](https://acm.timus.ru/problem.aspx?space=1&num=1449) · сложность 1464 · matching

Авторы оригинальной задачи — Илья Гребнов, Никита Рыбак и Дмитрий Ковалёв; Timus Top Coders: Second Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N предприятий (2 ≤ N ≤ 100) взяли кредиты в N банках; A[i, j] — кредит
предприятия i в банке j (0 ≤ A[i, j] ≤ 10⁶). Нужно выбрать
неотрицательные целые взятки BR[i] для предприятий и BC[j] для банков
так, чтобы каждый кредит удовлетворял A[i, j] ≤ BR[i] + BC[j], а сумма
всех взяток была как можно меньше. Вывести любой оптимальный вариант.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем кредитная матрица N × N.

## Выходные данные

BR в первой строке, BC во второй.

## Примеры

### Пример 1

Ввод:

```
4
5 8 4 3
3 6 2 1
4 6 4 1
4 3 5 4
```

Вывод:

```
2 0 1 2
3 6 3 2
```

## Решение

Это двойственная задача линейного программирования к задаче о
назначениях. Для любой перестановки σ взятки покрывают кредиты
A[i, σ(i)], так что сумма не меньше веса самого тяжёлого совершенного
паросочетания; венгерский алгоритм даёт потенциалы, достигающие ровно
этого веса. Запустим его на стоимостях −A: в конце выполняется
u[i] + v[j] ≤ −A[i, j] с равенством на найденном паросочетании, так что
BR = −u и BC = −v покрывают все кредиты и в сумме дают вес самого
тяжёлого паросочетания, а потенциалы остаются целыми.

Потенциалы бывают отрицательными, но прибавление t ко всем BR и
вычитание из всех BC не меняет ни общую сумму, ни суммы BR[i] + BC[j].
Сдвинем так, чтобы наименьшее BR стало 0. Тогда ни одно BC не
отрицательно: если бы BC[j] было отрицательным, все
BR[i] ≥ A[i, j] − BC[j] были бы положительными, включая нулевое.
`O(N³)`.

Подводные камни:

- для нулевой матрицы ответ всё равно нужен — все нули (тест 02);
- если все кредиты выдал один банк, достаточно, чтобы платил этот банк
  (тест 07);
- потенциалы — не взятки: перед сдвигом нужно поменять их знаки.
