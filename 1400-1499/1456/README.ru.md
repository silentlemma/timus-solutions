# 1456. Джедайский ребус 2

Авторы оригинальной задачи — Илья Гребнов, Дмитрий Ковалёв и Никита Рыбак; Timus Top Coders: Second Challenge.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Даны A и N (2 ≤ A < N ≤ 10⁹); по очереди вычисляются остатки
Z[1] = A mod N, Z[i + 1] = Z[i] · A mod N. Нужно найти наименьшее
положительное X, при котором Z[X] = 1, то есть наименьшее X с
A^X ≡ 1 (mod N), или вывести 0, если его нет.

Ограничение времени: 0.25 секунды. Ограничение памяти: 64 МБ.

## Входные данные

A и N.

## Выходные данные

X или 0.

## Примеры

### Пример 1

Ввод:

```
7 20
```

Вывод:

```
4
```

Остатки равны 7, 9, 3 и 1.

## Решение

Если у A и N есть общий делитель, каждый остаток его сохраняет и никогда
не становится 1, так что ответ 0. Иначе X — порядок A по модулю N, и по
теореме Эйлера он делит φ(N). Разложим N пробным делением до √N, чтобы
получить φ(N), так же разложим φ(N) и начнём с x = φ(N): для каждого
простого p из φ(N) делим x на p, пока A^(x / p) по-прежнему равно 1 по
модулю N. Остаток и есть порядок, ведь степень, равная 1, остаётся
кратной порядку. Все произведения меньше 10¹⁸, так что хватает 64-битной
арифметики с быстрым возведением в степень. `O(√N + log² N)`.

Подводные камни:

- общий делитель A и N, в том числе чётные A и N (тесты 02, 08, 11);
- моделировать остатки по одному слишком медленно, когда порядок близок
  к N (тест 13);
- у A = N − 1 порядок 2 (тесты 04, 10).
