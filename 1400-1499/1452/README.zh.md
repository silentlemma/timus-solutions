## 任务

一个序列有 N 个元素（2 ≤ N ≤ 2000），都是 0 到 10⁹ 的整数。选出尽可能多的值互不
相同的元素，使它们构成某个递增等差数列的连续项；它们在序列中的顺序无关紧要。输
出个数，以及按任意顺序排列的所选元素编号。

时间限制：0.25 秒。内存限制：16 MB。

## 输入

N，然后是 N 个元素。

## 输出

个数，然后是元素编号。任何一个最长的数列都被接受。

## 样例

### 样例 1

输入:

```
6
7 3 2 3 5 9
```

输出:

```
4
4 5 1 6
```

## 解法

只有值的集合重要，所以把每个值在哈希表中存一次，并记下持有它的某个元素的编号，
再对不同的值排序。任何至少两项的数列都由前两项 x < y 和公差 d = y − x 确定。只
从数列真正的起点出发，即 x − d 不存在时：然后沿着 y + d、y + 2d、……一直走，直
到不在表中为止。

极大数列中每一对相邻项恰好落在一次行走中，而每对 (x, y) 只需一次查表来检查起
点，所以对 m 个不同的值，整个搜索共 O(m²) 次查表，而且不需要成对的表：内存保持
O(m)，正是 16 MB 限制所要求的。只有一个不同的值时答案是一个元素。期望时间
`O(m²)`。

注意事项：

- 重复的值只算一次（测试 02、04、07、gen4）；
- 贯穿所有值的数列是行走最慢的情况（gen3）；
- 像通常 O(N²) 动态规划那样存所有对的表，在大多数语言中会超出内存限制。
