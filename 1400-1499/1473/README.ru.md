# 1473. Ферма 2

[Timus 1473](https://acm.timus.ru/problem.aspx?space=1&num=1473) · сложность 5038 · geometry

Автор оригинальной задачи — Александр Ипатов; контест УрГУ и ОрёлГТУ на Петрозаводских летних сборах, август 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Эксперт выбирает целые a_i, b_i (|a_i|, |b_i| ≤ 2·10⁹) и называет
животное с параметрами (A, B) верблюдом, если a_i·A + b_i·B > 0,
бараном, если это < 0, и молчит, если 0. Комиссия из K экспертов
признаёт животное верблюдом (бараном), если так говорят строго больше
половины экспертов. Даны N известных животных (1 ≤ N ≤ 10000,
0 ≤ A, B ≤ 10000, вид 1 — верблюд, 2 — баран); нужно найти наименьшее K
и числа экспертов, при которых каждое животное определено верно, или
вывести −1, если это невозможно.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк A B вид.

## Выходные данные

−1 или K и K строк a_i b_i. Подходят любые верные эксперты.

## Примеры

### Пример 1

Ввод:

```
2
10 0 1
0 10 2
```

Вывод:

```
1
1 -1
```

## Решение

Мнение эксперта зависит только от направления (A, B): за животное в
начале координат не голосует никто, а два животных на одном луче из
начала координат получают одинаковые голоса, так что в любом из этих
случаев при разных видах на луче ответ −1. Сократим каждую точку на НОД
и отсортируем лучи по углу; все они лежат в первой четверти, на дуге
короче π, поэтому эксперт меняет мнение вдоль неё не больше одного
раза. Пусть r — число отрезков одного вида.

Посчитаем экспертов, говорящих «верблюд». При нечётном K это число на
каждой границе отрезков должно перейти с больше K / 2 на меньше, для
чего там должен смениться хотя бы один эксперт; при чётном K оно должно
упасть с K/2 + 1 и выше до K/2 − 1 и ниже, а это два эксперта. Значит,
K ≥ r − 1 для нечётного K и K ≥ 2(r − 1) для чётного, и наименьшее K
равно r − 1, если это нечётно, и r иначе (в том числе K = 1 для одного
отрезка). Оно достижимо: на каждой границе между лучами p и q прямая
через начало координат вдоль p + q проходит строго между ними, а
эксперт, перпендикулярный ей, голосует до неё за прежний вид, а после —
за другой. Если таких экспертов чётное число, ещё один эксперт, (1, 1)
или (−1, −1), везде голосует за первый вид; тогда перевес голосов
чередуется между +1 и −1 по отрезкам. Все числа меньше 20001.
`O(N log N)`.

Подводные камни:

- животное в начале координат определить нельзя (тест 02);
- точки на одном луче, как (2, 4) и (1, 2), — одно направление: разные
  виды на нём означают −1, а одинаковые — один отрезок (тесты 03, 05,
  gen3, gen5);
- нечётному числу отрезков нужен лишний эксперт, потому что чётной
  комиссии нужны две смены на каждой границе (тесты 06, 08);
- лучи, близкие, как (9999, 9998) и (10000, 9999), различаются только
  точными целочисленными векторными произведениями (тест 07).
