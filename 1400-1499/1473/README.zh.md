# 1473. 农场 2

[Timus 1473](https://acm.timus.ru/problem.aspx?space=1&num=1473) · 难度 5041 · geometry

原题作者 Alexander Ipatov，出自 2006 年 8 月彼得罗扎沃茨克夏季集训的乌拉尔国立大学与奥廖尔国立技术大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一位专家选择整数 a_i、b_i（|a_i|, |b_i| ≤ 2·10⁹）：参数为 (A, B) 的动物，若
a_i·A + b_i·B > 0 则判为骆驼，< 0 判为绵羊，等于 0 则不表态。K 位专家组成的委员
会在严格多于半数的专家这样判断时，才认定动物是骆驼（绵羊）。给定 N 只已知动物
（1 ≤ N ≤ 10000，0 ≤ A, B ≤ 10000，种类 1 为骆驼、2 为绵羊），求最小的 K 以及
能把每只动物都判对的专家参数；若不存在这样的委员会，输出 −1。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N 行 A B 种类。

## 输出

−1，或者 K 以及 K 行 a_i b_i。任何满足要求的专家都可以。

## 样例

### 样例 1

输入:

```
2
10 0 1
0 10 2
```

输出:

```
1
1 -1
```

## 解法

专家的判断只取决于 (A, B) 的方向：原点处的动物得不到任何人的投票，而从原点出发
的同一条射线上的两只动物得到的投票完全相同，所以只要出现原点处的动物，或同一射
线上有不同种类，答案就是 −1。把每个点除以最大公约数，再按角度给射线排序；它们
都在第一象限，即一段短于 π 的弧上，所以每位专家至多切换一次投票种类，期间可能
弃权。设 r 为同种类连续段的个数。

数一数说"骆驼"的专家。K 为奇数时，这个数在每个段边界都要跨过 K / 2，因此那里
至少要有一位专家改变判断；K 为偶数时，它要在 K/2 + 1 及以上与 K/2 − 1 及以下
之间变化，需要两位。所以奇数 K ≥ r − 1，
偶数 K ≥ 2(r − 1)，最小的 K 在 r − 1 为奇数时等于 r − 1，否则等于 r（只有一段时
K = 1）。这是可以达到的：在射线 p 与 q 的每个边界处，过原点沿 p + q 方向的直线
严格位于两者之间，与它垂直的专家在它之前投给前一种类，之后投给另一种类。若这样
的专家有偶数个，再加一位专家 (1, 1) 或 (−1, −1)，处处投给第一种类；这样票数差
在各段之间交替为 +1 和 −1。所有数都小于 20001。`O(N log N)`。

注意事项：

- 原点处的动物永远无法判定（测试 02）；
- 同一射线上的点，如 (2, 4) 和 (1, 2)，是同一方向：种类不同则为 −1，种类相同则
  属于同一段（测试 03、05、gen3、gen5）；
- 段数为奇数时需要多一位专家，因为偶数人的委员会在每个边界需要两次改变（测试
  06、12）；
- 用精确的整数叉积对像 (9999, 9998) 与 (10000, 9999) 这样接近的射线排序（测试
  07）。
