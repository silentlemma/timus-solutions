# 1440. Расписание тренировок

[Timus 1440](https://acm.timus.ru/problem.aspx?space=1&num=1440) · сложность 669 · bruteforce

## Задача

Команда Гриффиндора по квиддичу тренируется в определённые дни недели,
например каждую пятницу и воскресенье. Тренироваться можно со второго
сентября до дня перед первым матчем, а матч проходит между вторым
сентября и 24 декабря. Тренировок должно быть от A до B
(1 ≤ A ≤ B ≤ 200). По дню недели первого сентября и дате матча нужно
выбрать набор дней недели, дающий такое число тренировок, или сообщить,
что его нет.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

День недели первого сентября по-английски, дата матча в виде
«Month Day», затем A и B.

## Выходные данные

«Impossible» или число выбранных дней недели, а за ним их названия по
одному в строке в любом порядке. Принимается любой подходящий набор.

## Примеры

### Пример 1

Ввод:

```
Thursday
September 10
9 20
```

Вывод:

```
Impossible
```

### Пример 2

Ввод:

```
Tuesday
October 7
12 14
```

Вывод:

```
Impossible
```

### Пример 3

Ввод:

```
Friday
October 4
12 14
```

Вывод:

```
3
Monday
Wednesday
Saturday
```

## Решение

Посчитаем, сколько дней тренировок приходится на каждый день недели:
пройдём по дням со второго сентября до кануна матча, их не больше 113,
добавляя единицу дню недели каждого из них. Набор дней недели даёт
сумму своих счётчиков, а непустых наборов всего 127, так что
перебираем их все и выводим первый, чья сумма лежит между A и B.
`O(D + 2⁷ · 7)` для D дней до матча.

Подводные камни:

- матч второго сентября не оставляет ни одного дня для тренировок
  (тест 04);
- 200 тренировок никогда не помещаются до Рождества (тест 05);
- иногда подходит только один набор или нужны все семь дней (тесты 06,
  09, 10, 13);
- месяцы разной длины: 30 сентября и 1 октября — соседние дни (тесты
  11, 12).
