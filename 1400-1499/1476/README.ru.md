# 1476. Лунокод

[Timus 1476](https://acm.timus.ru/problem.aspx?space=1&num=1476) · сложность 1263 · dp

Автор оригинальной задачи — Александр Ипатов (идея — Александр Торопов); контест УрГУ и ОрёлГТУ на Петрозаводских летних сборах, август 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Нужно посчитать матрицы M × N из нулей и единиц (1 ≤ M, N ≤ 40), в
которых для каждой пары соседних столбцов i и i + 1 не больше K строк
(0 ≤ K ≤ M) имеют 0 в столбце i и 1 в столбце i + 1.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

M, N и K.

## Выходные данные

Число таких матриц.

## Примеры

### Пример 1

Ввод:

```
2 1 0
```

Вывод:

```
4
```

### Пример 2

Ввод:

```
2 2 1
```

Вывод:

```
15
```

## Решение

Заполняем матрицу по столбцам. Допустимость следующего столбца зависит
от того, в каких строках текущего стоят нули, но число способов
продолжить зависит только от того, сколько в столбце единиц. Из столбца
с c единицами следующий столбец с d единицами получается, если
превратить t ≤ K из M − c нулей в единицы и оставить s = d − t из
c единиц: step(c, d) = Σ C(M − c, t)·C(c, d − t) по t ≤ K. Эти числа не
больше 2⁴⁰. Первый столбец с c единицами выбирается C(M, c) способами;
каждый следующий столбец умножает вектор количеств на таблицу step, а
ответ — сумма после N столбцов. `O(M²(K + N))` арифметических операций
над числами длиной до M·N + 1 бит.

Подводные камни:

- при K = M подходит любая матрица, и для 2¹⁶⁰⁰ нужны большие числа
  (тест 03);
- одна строка при K = 0 означает, что строка никогда не переходит от 0
  к 1: N + 1 матриц (тест 05);
- у одного столбца нет пар для проверки: 2^M матриц (тесты 01, 06).
