# 1415. Мобильная жизнь

[Timus 1415](https://acm.timus.ru/problem.aspx?space=1&num=1415) · сложность 8920 · geometry, simulation

Автор оригинальной задачи — Евгений Крохалев; чемпионат Уральского государственного университета, 29 октября 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N базовых станций (N ≤ 100) стоят в целых точках; у станции c есть
пороговое расстояние R_c и название. Мощность сигнала обратно
пропорциональна расстоянию, а индикатор телефона фиолетовый внутри
R_c и опускается на один цвет (синий, голубой, зелёный, жёлтый,
оранжевый, красный) на каждые 2 дБ потерянной мощности, дальше
оставаясь красным. Телефон несут по ломаной из M ≤ 1000 отрезков. При
включении он выбирает самую мощную станцию, при равенстве — с меньшим
названием; остаётся с ней, пока индикатор не станет красным, а пока он
красный, переключается на самую мощную станцию с не красным сигналом,
как только такая появляется. Нужно вывести журнал включения, смен соты
и смен цвета; строка о красном цвете пишется, даже если телефон тут же
переключается.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N строк X Y R название, затем M, затем M отрезков X1 Y1 X2 Y2.

## Выходные данные

Журнал.

## Решение

Мощность пропорциональна R / d, так что потеря равна 10·log₁₀(d / R)
дБ, и цвет меняется на окружностях радиуса R·10^(k/5) для k = 0..5:
фиолетовый внутри первой, красный снаружи последней, радиуса 10·R.

На отрезке p(t) = s + t·(e − s) моменты, когда расстояние до станции
равно радиусу, — корни квадратного уравнения по t. Важны только два
вида моментов: текущая станция пересекает любую из своих шести
окружностей, и любая станция пересекает свою красную окружность (лишь
тогда какая-то станция перестаёт или начинает быть красной). Сортируем
эти моменты, объединяем отстоящие меньше чем на 10⁻⁹ и смотрим на
состояние сразу после каждой группы — в середине до следующего
момента:

- если телефон не красный, записывается новый цвет текущей станции;
  если теперь он красный, кандидаты — все станции, не красные в этой
  точке;
- если телефон был красным, кандидаты — станции этой группы, которые
  перестали быть красными.

Среди кандидатов побеждает самая мощная, сравнение R / d — в сам
момент и с относительным допуском, чтобы станции, одновременно
достигшие красных окружностей, считались равными и решало меньшее
название. Если победила текущая станция, пишется только цвет; иначе —
смена соты, её цвет берётся сразу после момента до её собственной
следующей окружности, и моменты перестраиваются для новой станции.
`O(M·N·log N)`.

Подводные камни:

- телефон остаётся со слабой станцией, пока она не красная, даже рядом
  с гораздо более мощной (тесты 04, 10);
- возвращение текущей станции из красного — смена цвета, а не соты
  (тесты 02, 03);
- несколько станций могут достичь красных окружностей в один момент;
  при равной мощности выбирается меньшее название при побайтовом
  сравнении (тесты 04, 08, 09, gen3);
- телефон может включиться красным без станций в зоне, а отрезки
  бывают нулевой длины (тесты 06, 07);
- на форуме приводят входы, где события отличаются примерно на 10⁻¹³ и
  их не упорядочить даже в long double; тесты системы их избегают.
