# 1431. 证书

[Timus 1431](https://acm.timus.ru/problem.aspx?space=1&num=1431) · 难度 362 · greedy

原题作者 Stanislav Vasiliev，出自 2006 年 2 月 25 日第七届乌拉尔国立大学个人公开赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

有 N 种证书（N ≤ 18），每种 1 到 30 张。同一种的证书挂在同一排。一排只挂一种，
或者挂严格交替的两种，并且每一排都必须关于墙的中心对称。求最少的排数。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是每种证书的张数。

## 输出

最少的排数。

## 样例

### 样例 1

输入:

```
6
8 15 13 8 14 8
```

输出:

```
5
```

## 解法

只挂一种的排总是可以的。两种严格交替形成 ABAB…，这样的排只有在首尾是同一种时
（A B A … B A）才是回文的，也就是张数恰好相差一。答案是 N 减去张数相差一的、互
不相交的种类对的最大数目。

这些对连接链 1, 2, …, 30 上相邻的值。沿链往上走时，张数为 c 且尚未配对的种类此
后只能与张数 c + 1 的配对，所以立即尽量多地配对绝不会更差。`O(N + 30)`。

注意事项：

- 张数相同的两种不能挂在同一排：长度为偶数的交替排不对称（测试 06）；
- 在 1、2、3、4 中应配成 1–2 和 3–4，而不是 2–3（测试 07）；
- 多种证书可能张数相同（测试 08、12）。

## 优化解法

Go 和 Rust 用字节数组统计数量一至 30 的类型频次。处理每个数量时，尽可能与前一数量尚未配对的类型配对，每配一对就少需一行。只将未配对的余量传给下一步，无需排序列表或匹配图。两个版本均用固定字节缓冲区进行输入和十进制输出。Go 直接访问标准输入和输出句柄，Rust 通过 C 运行库读写。

通过评测的 Rust 1.75 x64 版本耗时 0.031 秒，基础版为 0.015 秒，内存为 56 KB，基础版为 220 KB。
