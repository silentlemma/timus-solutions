# 1431. Сертификаты

[Timus 1431](https://acm.timus.ru/problem.aspx?space=1&num=1431) · сложность 362 · greedy

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Есть N типов дипломов (N ≤ 18), каждого от 1 до 30 штук. Все дипломы
одного типа висят в одном ряду. В ряду висит один тип или два типа,
строго чередующихся, и каждый ряд должен быть симметричен относительно
центра стены. Нужно найти наименьшее число рядов.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем количество дипломов каждого типа.

## Выходные данные

Наименьшее число рядов.

## Примеры

### Пример 1

Ввод:

```
6
8 15 13 8 14 8
```

Вывод:

```
5
```

## Решение

Ряд из одного типа годится всегда. Два строго чередующихся типа дают
ABAB…, и такой ряд читается одинаково в обе стороны, только если
начинается и кончается одним типом: A B A … B A, то есть количества
отличаются ровно на единицу. Ответ — N минус наибольшее число
непересекающихся пар типов, количества которых отличаются на единицу.

Пары соединяют соседние значения цепочки 1, 2, …, 30. Если идти вверх по
цепочке, ещё не спаренные типы с количеством c теперь могут
спариться только с количеством c + 1, поэтому спарить их сразу как можно
больше никогда не хуже. `O(N + 30)`.

Подводные камни:

- равные количества не могут делить ряд: чередующийся ряд чётной длины
  не симметричен (тест 06);
- в 1, 2, 3, 4 пары — 1–2 и 3–4, а не 2–3 (тест 07);
- у нескольких типов может быть одинаковое количество (тесты 08, 12).

## Оптимизированные решения

Go и Rust хранят частоты количеств от одного до 30 в байтовых массивах. На каждом количестве составляется максимум пар с оставшимися типами предыдущего количества. Каждая пара уменьшает ответ на одну строку. Дальше передаётся только остаток без пары, поэтому не нужны отсортированный список или граф паросочетания. Обе версии используют фиксированные байтовые буферы для ввода и десятичного вывода. Go обращается напрямую к дескрипторам стандартного ввода и вывода, Rust использует библиотеку времени исполнения C.

Принятая версия Rust 1.75 x64 заняла 0.031 с при 0.015 с у базовой и использовала 56 KB при 220 KB у базовой.

Принятые базовые реализации [1431_greedy.cpp](1431_greedy.cpp), [1431_greedy.java](1431_greedy.java), [1431_greedy.py](1431_greedy.py) также закрывают быстрый набор: в сохранённом срезе сравнения они уже удовлетворяют рейтинговому критерию включения — топ 15% или первые десять мест одновременно по времени и памяти. Используются те же исходники без одинаковых копий. Звёздочка отмечает версию, которая пока не достигла целевого рейтинга своего языка.
