# 1468. 分数

[Timus 1468](https://acm.timus.ru/problem.aspx?space=1&num=1468) · 难度 836 · math

原题作者 Dmitry Zhukov，出自 2006 年 8 月彼得罗扎沃茨克夏季集训的乌拉尔国立大学与奥廖尔国立技术大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

对至多 100 组 a、b、k（1 ≤ a, b ≤ 10000，2 ≤ k ≤ 36），用 0–9 和 A–Z 作数字，把
a / b 写成 k 进制：先写整数部分；若不是整数，再写小数点和小数部分，循环节放在括
号里。不能有多余的零。输入以 "0 0" 结束。

时间限制：0.4 秒。内存限制：64 MB。

## 输入

若干行 a b k，然后是 "0 0"。

## 输出

每组一行。

## 样例

### 样例 1

输入:

```
10 5 2
1 2 8
8780 1 29
2794 6083 23
157 7 19
1 12 10
0 0
```

输出:

```
10
0.4
ACM
0.(ACM)
13.(82DAG5)
0.08(3)
```

## 解法

整数部分 a div b 照常写成 k 进制。小数部分就是长除法：余数乘以 k，除以 b 的商是
下一位数字，余下的是新余数。余数共有 b 种，所以要么某个余数变成 0（小数结束），
要么某个余数再次出现。记录每个余数第一次出现的位置，就能准确得到循环节：从该位
置起的数字无限重复；而且余数决定了之后的一切，所以这是最短的循环节，并且开始得
尽可能早。每组 `O(b)`。

注意事项：

- 结果为整数时完全不输出小数点（测试 01、02）；
- 循环节可能在若干不循环的数字之后才开始，如 0.08(3)（测试 01）；
- 循环节可长达近 10000 位（测试 03、gen2）。
