# 1474. Про лягушек

[Timus 1474](https://acm.timus.ru/problem.aspx?space=1&num=1474) · сложность 725 · constructive

Автор оригинальной задачи — Александр Ипатов; контест УрГУ и ОрёлГТУ на Петрозаводских летних сборах, август 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

На кочках 0 … 2N (1 ≤ N ≤ 499) сидят N белых лягушек на 0 … N − 1,
кочка N пуста, а N чёрных лягушек сидят на N + 1 … 2N. Белая лягушка
переходит вправо на пустую соседнюю кочку или прыгает вправо через одну
чёрную лягушку на пустую кочку; чёрная делает то же влево. Ходы идут в
любом порядке. Нужно поменять цвета местами не больше чем за миллион
ходов, выведя число ходов и кочку, с которой начинается каждый ход, или
−1, если это невозможно.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N.

## Выходные данные

K, затем K начальных кочек. Подходит любая верная последовательность.

## Примеры

### Пример 1

Ввод:

```
1
```

Вывод:

```
3
2 0 1
```

## Решение

Лягушки движутся только вперёд, поэтому каждая белая лягушка ровно один
раз обходит каждую чёрную, а обойти лягушку можно только прыжком: N²
прыжков. Все лягушки вместе проходят 2N(N + 1) кочек, по две за прыжок
и по одной за шаг, значит, шагов 2N. Поэтому любая удачная игра длится
N² + 2N ходов, 249 999 при N = 499, и ответ никогда не −1; опасен лишь
тупик, когда две лягушки одного цвета загораживают друг друга.

Ходы идут сериями по 1, 2, …, N, затем ещё раз N, затем N, …, 1,
чёрные и белые чередуются, чёрные первыми. Внутри серии выполняется
прыжок на пустую кочку, если он возможен, а иначе шаг. Такой порядок
позволяет избежать тупиков, так что ход всегда есть; повторение
ходов подтверждает обмен для каждого N от 1 до 499. `O(N²)`.

Подводные камни:

- порядок важен: жадные ходы без схемы серий могут запереть двух
  лягушек одного цвета друг за другом (02, проверка повторяет
  каждый ход);
- ответ −1 не бывает никогда (все тесты);
- при N = 499 выводится 249 999 номеров исходных кочек, их стоит
  собирать в один буфер (gen4).
