# 1435. Финансовая ошибка

[Timus 1435](https://acm.timus.ru/problem.aspx?space=1&num=1435) · сложность 994 · math

## Задача

N чисел (N ≤ 200 000, каждое не больше 2³¹ − 1) переписаны из отчёта, и
их сумма не совпала с итогом отчёта (не больше 10¹⁶). Ошибка при
переписывании — две соседние цифры одного числа поменялись местами; ни
у копии, ни у настоящего числа нет ведущих нулей. Нужно вывести «Input
has no error.», если суммы совпадают, «Error in record #L. Correct
number is: K.» для записи, которую объясняет такая перестановка, или
«Unrecoverable error.».

Ограничение времени: 0.4 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, N переписанных чисел, затем итог отчёта.

## Выходные данные

Одна из трёх строк.

## Примеры

### Пример 1

Ввод:

```
3
12
26
45
119
```

Вывод:

```
Error in record #2. Correct number is: 62.
```

## Решение

Перестановка цифр a при 10^(i+1) и b при 10^i меняет число на
(b − a)·10^(i+1) + (a − b)·10^i = 9·(b − a)·10^i. Значит, разность D
между итогом и суммой должна быть 9·c·10^i с 1 ≤ |c| ≤ 9: делим D на 9,
отбрасываем множители 10 и получаем i, а остаток — это c. Затем
просматриваем записи как строки и ищем ту, у которой цифры при
10^(i+1) и 10^i отличаются ровно на c, пропуская перестановку, которая
вывела бы ноль вперёд, и выводим первую такую запись с цифрами,
переставленными обратно. `O(N)`.

Подводные камни:

- настоящее число может выйти за 32 бита, как 9100000000 вместо
  1900000000 (тест 04);
- 90 не может быть копией 09, а 10 — копией 01 (тесты 02, 06);
- сам итог переписан без ошибки (тест 07);
- чтобы прочитать 200 000 чисел за 0,4 секунды, нужен быстрый ввод;
  решения читают всё сразу.
