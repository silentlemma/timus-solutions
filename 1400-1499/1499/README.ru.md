# 1499. Треуголки

[Timus 1499](https://acm.timus.ru/problem.aspx?space=1&num=1499) · сложность 1475 · constructive

Автор оригинальной задачи — Алексей Самсонов; XIII командный чемпионат школьников Свердловской области по программированию, 14 октября 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В правильном многоугольнике с вершинами 1 … N (3 ≤ N ≤ 50000) уже
сделаны K непересекающихся разрезов по диагоналям (0 ≤ K ≤ N − 3).
Нужно добавить разрезы по диагоналям, не пересекающие остальные, пока
многоугольник не распадётся на треугольники, и вывести новые разрезы.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, K, затем K строк с двумя вершинами разреза.

## Выходные данные

Число новых разрезов, затем сами разрезы парами вершин. Подходит любая
триангуляция.

## Примеры

### Пример 1

Ввод:

```
5
1
1 4
```

Вывод:

```
1
3 1
```

## Решение

В любой триангуляции N-угольника N − 3 диагонали, так что не хватает
ровно N − 3 − K разрезов. Данные разрезы делят многоугольник на
выпуклые грани, а любую грань можно разбить веером диагоналей из одной
её вершины.

Грани находятся стеком при обходе вершин 1 … N по порядку. Кладём
каждую вершину v; затем для каждого данного разреза u–v с u < v, от
ближайшего u к самому дальнему, участок стека от u до v образует одну
грань: снимаем вершины до u, оставляя u в стеке, разбиваем грань веером
из u и кладём v обратно. После обхода в стеке остаётся грань со стороной
N–1, её тоже разбиваем веером. Всего добавлений N + K, а снятий не больше,
так что обход линеен, не считая сортировки разрезов в каждой вершине.
`O(N log N)`.

Подводные камни:

- разрез может быть задан с большей вершиной первой (тест 06);
- в одной вершине может кончаться несколько разрезов, и их грани надо
  закрывать изнутри наружу (тесты 05, 12);
- если даны все N − 3 разреза или N = 3, ответ 0 (тесты 02, 03, gen3).
