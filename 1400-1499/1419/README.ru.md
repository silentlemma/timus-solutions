# 1419. Карта мира 40 островов

[Timus 1419](https://acm.timus.ru/problem.aspx?space=1&num=1419) · сложность 1208 · graphs

Автор оригинальной задачи — Александр Клепинин; чемпионат Уральского государственного университета, 29 октября 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

В изображении из M × N символов (оба числа нечётные, от 1 до 99) на
каждой позиции с нечётными номерами строки и столбца (считая с 1) стоит
`O`, а в остальных — `-`, `|`, `/`, `\` или пробел. Это настоящая карта
островного мира, если символы — мосты между соседними островами, у
каждого острова ровно три моста и острова остаются связными после
разрушения любого одного моста. Нужно вывести «Island world» или «Just
a picture».

Это проверка, стоящая за [задачей 1411](../1411/README.ru.md).

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

M и N, затем N строк по M символов.

## Выходные данные

«Island world» или «Just a picture».

## Примеры

### Пример 1

Ввод:

```
15 9
O-O-O-O-O-O O-O
|\| |  \|/|/|/|
O-O O-O O O O O
 \ / /|  /  |/|
O-O O-O-O-O O-O
|\  |    / \  |
O-O O O-O-O O-O
|/ /| |\  |\ \|
O-O-O-O-O-O-O-O
```

Вывод:

```
Island world
```

### Пример 2

Ввод:

```
5 3
O-O-O
|   |
O-O-O
```

Вывод:

```
Just a picture
```

## Решение

Строки читаются как есть, ведь они могут начинаться с пробелов. Каждый
символ моста должен подходить своему промежутку: `-` между двумя островами
строки, `|` между двумя островами столбца, `\` или `/` в середине
четырёх островов; любой другой символ моста означает, что это не карта.
Каждый мост добавляет ребро между соединяемыми островами. Затем у
каждого острова должна быть степень три, а один поиск в глубину
вычисляет времена входа и low-значения: граф связен, если поиск
достиг всех островов, и в нём нет мостов, если ни для какого ребра
дерева в вершину v не выполнено low(v) > tin(родителя). Поиск ведёт
свой стек, потому что путь из 2500 островов слишком глубок для
стека вызовов в некоторых языках. `O(MN)`.

Подводные камни:

- символ не в том промежутке, например `-` там, где может стоять только
  `|`, — не мост (тест 06);
- карта, где у всех островов степень три, может распадаться на две
  части или держаться на одном мосту (тесты 03, 07);
- у единственного острова мостов нет вовсе (тест 05).
