# 1419. 岛屿世界地图

[Timus 1419](https://acm.timus.ru/problem.aspx?space=1&num=1419) · 难度 1212 · graphs

原题作者 Alexander Klepinin，出自 2005 年 10 月 29 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一张 M × N 个字符的图（两者均为 1 到 99 的奇数）在每个行号和列号都为奇数（从 1
开始计）的位置上是 `O`，其余位置是 `-`、`|`、`/`、`\` 或空格。如果这些符号是相
邻岛屿之间的桥，每个岛恰好有三座桥，并且拆掉任意一座桥后岛屿仍然连通，那么它就
是一张真正的岛屿世界地图。输出 "Island world" 或 "Just a picture"。

这正是[第 1411 题](../1411/README.zh.md)背后的检查。

时间限制：1 秒。内存限制：64 MB。

## 输入

M 和 N，然后 N 行，每行 M 个字符。

## 输出

"Island world" 或 "Just a picture"。

## 样例

### 样例 1

输入:

```
15 9
O-O-O-O-O-O O-O
|\| |  \|/|/|/|
O-O O-O O O O O
 \ / /|  /  |/|
O-O O-O-O-O O-O
|\  |    / \  |
O-O O O-O-O O-O
|/ /| |\  |\ \|
O-O-O-O-O-O-O-O
```

输出:

```
Island world
```

### 样例 2

输入:

```
5 3
O-O-O
|   |
O-O-O
```

输出:

```
Just a picture
```

## 解法

按原样读入各行，因为行首可能有空格。每个符号必须与它所在的空隙相符：`-` 在同一
行两个岛之间，`|` 在同一列两个岛之间，`\` 或 `/` 在四个岛的中间；其他符号都说明
这不是地图。每个符号在它连接的两个岛之间加一条边。然后每个岛的度数必须为三，再用
一次深度优先搜索求出时间戳和 low 值：若搜索到达所有岛则图连通；若没有指向顶点 v
的树边满足 low(v) > tin(父节点)，则没有桥。搜索使用自己的栈，因为 2500 个岛的路
径对某些语言的调用栈来说太深。`O(MN)`。

注意事项：

- 放错空隙的符号，例如只能放 `|` 的地方出现 `-`，不算桥（测试 06）；
- 所有岛度数都为三的地图仍可能分成两块，或只靠一座桥相连（测试 03、07）；
- 只有一个岛时根本没有桥（测试 05）。
