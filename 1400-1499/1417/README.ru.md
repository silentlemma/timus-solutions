# 1417. Космическая распальцовка

[Timus 1417](https://acm.timus.ru/problem.aspx?space=1&num=1417) · сложность 1928 · math

Автор оригинальной задачи — Станислав Васильев; чемпионат Уральского государственного университета, 29 октября 2005 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

Игрок и крупье показывают от 1 до N пальцев (1 < N ≤ 100). Таблица
N × N задаёт выигрыш игрока для каждой пары: 1000 на диагонали, где
числа совпали, и целое от 0 до 10 в остальных клетках. Нужно найти
вероятности, с которыми крупье показывает каждое число, чтобы
ожидаемый выигрыш игрока не зависел от показанного им числа, и вывести
их с 5 знаками после точки.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, затем таблица: строка i — число пальцев игрока i, столбец j — число
пальцев крупье j.

## Выходные данные

N вероятностей, по одной в строке.

## Примеры

### Пример 1

Ввод:

```
3
1000 10 10
0 1000 1
5 3 1000
```

Вывод:

```
0.32986
0.33623
0.33391
```

## Решение

При вероятностях p игрок, показавший i, ожидает Σⱼ A[i][j]·pⱼ, и все
эти величины должны быть равны одному v. Решаем A·x = (1, …, 1)
методом Гаусса с выбором главного элемента; тогда p = x / Σx и
v = 1 / Σx.

Диагональ 1000 перевешивает остаток строки (не больше 99 · 10 = 990),
так что A невырождена, а решение положительно: из записи
xᵢ = (1 − Σⱼ≠ᵢ A[i][j]·xⱼ) / 1000 следует, что каждое xᵢ лежит между
10⁻⁵ и 10⁻³. Значит, ответ всегда существует и отрицательных
вероятностей нет. `O(N³)`.

Подводные камни:

- строки относятся к игроку, а столбцы — к крупье, поэтому система
  A·p = v·1, а не транспонированная (тесты 03, 05);
- одинаковые выигрыши везде дают равные вероятности (тесты 02, 04).
