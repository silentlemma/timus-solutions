# 1417. 太空猜拳

[Timus 1417](https://acm.timus.ru/problem.aspx?space=1&num=1417) · 难度 1884 · math

原题作者 Stanislav Vasiliev，出自 2005 年 10 月 29 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

玩家和荷官各伸出 1 到 N 根手指（1 < N ≤ 100）。一张 N × N 的表给出每种组合下玩
家的奖金：对角线（数目相同）上是 1000，其余格子是 0 到 10 的整数。玩家每轮支付
20，赌场要在玩家采用最优策略时最大化期望利润。求荷官伸出各个数目的概率，使玩家
的期望奖金与玩家伸出的数目无关，保留小数点后 5 位输出。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

N，然后是表：第 i 行对应玩家伸出 i 根，第 j 列对应荷官伸出 j 根。

## 输出

N 个概率，每行一个。

## 样例

### 样例 1

输入:

```
3
1000 10 10
0 1000 1
5 3 1000
```

输出:

```
0.32986
0.33623
0.33391
```

## 解法

在概率 p 下，伸出 i 的玩家期望得到 Σⱼ A[i][j]·pⱼ，这些值必须都等于同一个 v。用
带部分主元的高斯消元解 A·x = (1, …, 1)；则 p = x / Σx，v = 1 / Σx。

对角线上的 1000 大于该行其余元素之和（至多 99 · 10 = 990），所以 A 非奇异。
映射 Fᵢ(x) = (1 − Σⱼ≠ᵢ A[i][j]·xⱼ) / 1000 将 [10⁻⁵, 10⁻³]ᴺ 映射到自身，
且以至多 0.99 的系数压缩，因此其不动点 x 为正。故答案总是存在，且概率均为正。
`O(N³)`。

注意事项：

- 行属于玩家，列属于荷官，所以方程组是 A·p = v·1，而不是它的转置（测试 03、
  05）；
- 处处安慰奖相同时概率相等（测试 02、04）。
