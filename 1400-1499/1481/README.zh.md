# 1481. 获胜的机会

[Timus 1481](https://acm.timus.ru/problem.aspx?space=1&num=1481) · 难度 2273 · greedy

原题作者 Sergey Pupyrev，出自 2006 年 10 月 7 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 个重量各不相同的砝码（1 ≤ N ≤ 50，不超过 1000 的正整数）逐个放到天平上，每个
放在左盘或右盘。每放一个砝码就用 L 或 R 记下较重的一侧；天平从未平衡过。给定砝
码和记录，输出能产生这份记录的砝码顺序及所在的盘；若不存在，输出
"I'm too stupid to solve this problem"。

时间限制：0.5 秒。内存限制：64 MB。

## 输入

N，各砝码的重量，然后是 N 个字母的记录。

## 输出

N 行：按放置顺序给出砝码重量及其所在的盘。

## 样例

### 样例 1

输入:

```
3
10 20 30
LRL
```

输出:

```
10 L
20 R
30 L
```

## 解法

顺序总是存在的。把砝码排序，并让已用的砝码始终构成排序后列表中的一个连续段，段
中相邻的砝码位于不同的盘上。这样放有最重砝码的盘一定严格更重：从最重的开始两两
配对，(a_k − a_(k−1)) + (a_(k−2) − a_(k−3)) + … 为正。

设 c 为记录中字母变化的次数。先放恰好有 c 个更重砝码的那个砝码，放在第一个字母
对应的盘上。每遇到一次变化，就把下一个更重的砝码放在当前最重砝码的对面——它就成
了新的较重一侧。每遇到一次重复，就把下一个更轻的砝码放在当前最轻砝码的对面；最
重的砝码不变，较重的一侧也就不变。c 次变化恰好用完 c 个更重的砝码，重复则用更轻
的砝码。`O(N log N)`。

注意事项：

- 那条消息永远不会输出：任何记录都能实现（所有测试）；
- 按重量递减的顺序总是往较轻的盘上加砝码，对于接近的重量会失败：7、6、5 得到
  LLR 而非 LLL（测试 05）；
- 在这个构造中，每次变化都用更重的砝码，所以起始砝码之上必须恰好留有足够多
  更重的砝码（测试 04、gen2）。
