# 1481. Шансы на победу

[Timus 1481](https://acm.timus.ru/problem.aspx?space=1&num=1481) · сложность 2273 · greedy

Автор оригинальной задачи — Сергей Пупырев; чемпионат Уральского государственного университета, 7 октября 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N разных гирь (1 ≤ N ≤ 50, положительные целые до 1000) ставят по
одной на чашечные весы, каждую на левую или правую чашку. После каждой
гири записывали перевесившую чашку буквой L или R; равновесия не было
ни разу. По гирям и записи нужно вывести порядок гирь с их чашками,
дающий эту запись, или «I'm too stupid to solve this problem», если
такого нет.

Ограничение времени: 0.5 секунды. Ограничение памяти: 64 МБ.

## Входные данные

N, веса гирь, затем запись из N букв.

## Выходные данные

N строк: вес гири и её чашка в порядке установки.

## Примеры

### Пример 1

Ввод:

```
3
10 20 30
LRL
```

Вывод:

```
10 L
20 R
30 L
```

## Решение

Порядок существует всегда. Отсортируем гири и будем держать
использованные непрерывным отрезком отсортированного списка, в котором
соседи стоят на разных чашках. Тогда чашка с самой тяжёлой гирей строго
перевешивает: если разбить гири на пары сверху, (a_k − a_(k−1)) +
(a_(k−2) − a_(k−3)) + … положительно.

Пусть c — число смен буквы в записи. Начинаем с гири, тяжелее которой
ровно c гирь, на чашке первой буквы. При каждой смене добавляем
следующую более тяжёлую гирю на чашку, противоположную текущей самой
тяжёлой, — она и становится перевешивающей. При каждом повторе
добавляем следующую более лёгкую гирю на чашку, противоположную текущей
самой лёгкой; самая тяжёлая гиря, а значит и перевешивающая чашка, не
меняется. c смен расходуют ровно c более тяжёлых гирь, а повторы —
более лёгкие. `O(N log N)`.

Подводные камни:

- сообщение не выводится никогда: любую запись можно получить (все
  тесты);
- если идти по убыванию веса и всегда нагружать более лёгкую чашку,
  близкие гири подводят: 7, 6, 5 дают LLR вместо LLL (тест 05);
- здесь при каждой смене берём более тяжёлую гирю, так что начать
  нужно с гири, тяжелее которой ровно столько гирь (тест 04, gen2).
