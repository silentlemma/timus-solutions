# 1464. Освещение

[Timus 1464](https://acm.timus.ru/problem.aspx?space=1&num=1464) · сложность 2748 · geometry

Автор оригинальной задачи — Дмитрий Иванков (идея — Александр Ипатов); контест УрГУ на Петрозаводских зимних сборах, январь 2006 года.

## Задача

Комната — простой многоугольник из N вершин (3 ≤ N ≤ 50000), заданных
против часовой стрелки, с координатами от 0 до 1000 и не более чем
четырьмя знаками после точки. Люстра висит в точке строго внутри.
Нужно найти площадь освещённой части комнаты, то есть площадь,
видимую из люстры, с двумя знаками.

Ограничение времени: 3 секунды. Ограничение памяти: 64 МБ.

## Входные данные

Люстра, N, затем N вершин.

## Выходные данные

Освещённая площадь.

## Примеры

### Пример 1

Ввод:

```
1.0 1.0
6
0 0
3 0
3 2
2 2
2 3
0 3
```

Вывод:

```
8.00
```

## Решение

Посмотрим на комнату из люстры. Отсортируем вершины по направлению и
объединим одинаковые направления; так как люстра внутри, соседние
направления отстоят меньше чем на пол-оборота. Между двумя соседними
направлениями ни одной вершины не видно, поэтому в таком промежутке
освещённая область упирается в одно ребро — ближайшее из пересекающих
промежуток, и промежуток даёт треугольник между люстрой и этим ребром,
отрезанный двумя лучами.

Ребро, видимое из люстры, покрывает подряд идущие промежутки (ребро,
видимое с торца, не покрывает ни одного и ничего не заслоняет). Положим
промежутки в дерево отрезков и добавим каждое ребро в O(log N) вершин,
из которых складывается его отрезок. Каждая вершина хранит только
ближайшее из своих рёбер: два ребра, покрывающие одни и те же
промежутки, не пересекаются, поэтому одно сравнение вдоль луча через
первый промежуток вершины решает для всех её промежутков. Ближайшее
ребро для каждого промежутка — среди вершин на его пути к корню.
`O(N log N)`.

Все координаты читаются точно как целые в единицах 10⁻⁴, поэтому
слияние направлений и ориентация рёбер решаются без округлений; числа с
плавающей точкой нужны только для расстояний вдоль лучей.

Подводные камни:

- вершины на одной прямой с люстрой и рёбра, направленные прямо на неё
  (тесты 05, 07, gen3);
- глубокие ниши и «гребёнки», где большая часть комнаты в тени (тесты
  04, gen2);
- квадратичный перебор рёбер для каждого промежутка слишком медленный
  для 50000 вершин.
