# 1464. 照明

[Timus 1464](https://acm.timus.ru/problem.aspx?space=1&num=1464) · 难度 2748 · geometry

原题作者 Dmitry Ivankov（构思来自 Alexander Ipatov），出自 2006 年 1 月彼得罗扎沃茨克冬季集训的乌拉尔国立大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

房间是一个有 N 个顶点（3 ≤ N ≤ 50000）的简单多边形，顶点按逆时针给出，坐标在 0
到 1000 之间，小数点后至多四位。吊灯挂在房间内部严格的某一点。求房间被照亮部分的
面积，也就是从吊灯能看到的面积，保留两位小数。

时间限制：3 秒。内存限制：64 MB。

## 输入

吊灯位置、N，然后是 N 个顶点。

## 输出

被照亮的面积。

## 样例

### 样例 1

输入:

```
1.0 1.0
6
0 0
3 0
3 2
2 2
2 3
0 3
```

输出:

```
8.00
```

## 解法

从吊灯看房间。把顶点按方向排序并合并相同方向；由于吊灯在内部，相邻方向的夹角小
于半圈。在两个相邻方向之间看不到任何顶点，所以在这个间隙里被照亮的区域止于一条
边——穿过该间隙的最近的边，这个间隙贡献吊灯与这条边之间、被两条射线截出的三角
形。

从吊灯看，一条边覆盖连续的若干间隙（侧面朝向吊灯的边不覆盖任何间隙，也不遮挡任
何东西）。把间隙放进线段树，把每条边加入构成其区间的 O(log N) 个节点。每个节点只
保留它的边中最近的一条：覆盖同样间隙的两条边不会相交，所以沿着穿过节点第一个间隙
的射线比较一次，就对节点的所有间隙都成立。每个间隙最近的边就在它到根的路径上的节
点中。`O(N log N)`。

所有坐标都精确地读成以 10⁻⁴ 为单位的整数，所以方向的合并和边的定向都没有舍入误
差；浮点数只用于沿射线的距离。

注意事项：

- 与吊灯共线的顶点，以及正对吊灯的边（测试 05、07、gen3）；
- 深的凹槽和梳子形房间，大部分区域处在阴影中（测试 04、gen2）；
- 对每个间隙都扫描所有边的平方算法，对 50000 个顶点太慢。
