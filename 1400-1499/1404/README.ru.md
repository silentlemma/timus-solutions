# 1404. Легко взломать!

## Задача

Слово не длиннее 100 строчных латинских букв шифруется так: буквы
заменяются числами от 0 до 25, к первому числу прибавляется 5, к каждому
следующему — новое значение предыдущего, затем все значения берутся по
модулю 26 и снова заменяются буквами. По зашифрованному слову нужно
восстановить исходное.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

Зашифрованное слово.

## Выходные данные

Исходное слово.

## Примеры

### Пример 1

Ввод:

```
xbduyr
```

Вывод:

```
secret
```

## Решение

k-е зашифрованное значение — это (k − 1)-е плюс k-я буква, и переход к
модулю 26 это соотношение не портит. Поэтому каждая буква — разность её
кода и предыдущего кода по модулю 26, а перед первым кодом стоит 5.
`O(n)`.

Подводные камни:

- разность может быть отрицательной, её нужно вернуть в 0 … 25 (тест 03,
  где z превращается в e и обратно);
- суммы при шифровании выходят за 25 до взятия остатка, но коды во
  входных данных уже приведены, и этого достаточно.

Тесты получены шифрованием слов и проверяются точным сравнением.

## Оптимизированные решения

Оптимизированные решения (C++, Java) расшифровывают буквы по одной по
мере чтения через `getchar` и `System.in.read` вместо `iostream` и
`Scanner`, не сохраняя слово строкой: C++ сразу печатает каждую букву
через `putchar`, Java собирает их в массив из 101 байта и выводит его
одним вызовом. Разность по модулю 26 берётся как
`(code − previous + 26) % 26`, она никогда не отрицательна. C++ занимает
84 КБ вместо 360 КБ, Java — 328 КБ вместо 1612 КБ, в обоих случаях при
том же времени.
