# 1472. 火星军队

[Timus 1472](https://acm.timus.ru/problem.aspx?space=1&num=1472) · 难度 1037 · dp

原题作者 Alexander Ipatov，出自 2006 年 8 月彼得罗扎沃茨克夏季集训的乌拉尔国立大学与奥廖尔国立技术大学比赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

N 名军人（2 ≤ N ≤ 100000）构成一棵树：军人 i > 1 的直属指挥官是 K_i < i，这条
连接每兆字节收费 C_i（0 ≤ C_i ≤ 1000）。每名军人有一个实数可靠度 A_i：将军（1
号）为 1，列兵（没有下属的军人）为 0，其余未知。账单上军人 i 那条连接的流量由军
人自己填写，可以是不小于 max(0, A_K_i − A_i) 的任意值。求运营商能确保得到的最
小金额，保留恰好两位小数。

时间限制：1 秒。内存限制：64 MB。

## 输入

N，然后是 N − 1 行 K_i C_i，对应 i = 2 … N。

## 输出

确保能得到的金额。

## 样例

### 样例 1

输入:

```
7
1 10
2 5
2 3
3 1
3 2
3 3
```

输出:

```
8.00
```

## 解法

军人们只填最小值，并选择未知的可靠度来最小化 Σ C_i·max(0, A_K_i − A_i)。把所有
A 截断到 [0, 1] 不会让任何一项变大。然后在 0 到 1 之间的每个高度 t 切一刀：A ≥ t
的军人包含将军而不含任何列兵，从这些军人连向 t 以下军人的连接就是一个把将军与所有列
兵分开的割。账单等于这些割的价格对 t 的积分，因此不小于最便宜的割；而在该割上方
取 A = 1、下方取 0 就能达到它。答案就是最便宜的这种割，并且一定是整数。

在树上这是自底向上的最小值：cut(v) 表示把 v 与其下方所有列兵分开的最小代价，等
于对所有下属 u 求 min(C_u, cut(u)) 之和；列兵无法与自己分开，只能提供自己的那条
连接。指挥官的编号小于下属，所以从 N 倒序处理到 2，每名军人都会在其指挥官之前处
理完。答案是 cut(1)。`O(N)`。

注意事项：

- 可靠度是实数，但最优值是整数，输出时带 ".00"（所有测试）；
- 深处一条便宜的连接可能胜过上方昂贵的连接，价格为 0 的连接会让整个分支免费（测
  试 03、04）；
- 列兵只能提供通往其指挥官的连接（测试 02）；
- 100000 名军人的链对递归来说太深，而编号顺序让我们不必递归（gen2）。
