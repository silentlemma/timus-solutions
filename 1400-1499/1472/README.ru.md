# 1472. Марсианская армия

[Timus 1472](https://acm.timus.ru/problem.aspx?space=1&num=1472) · сложность 1035 · dp

Автор оригинальной задачи — Александр Ипатов; контест УрГУ и ОрёлГТУ на Петрозаводских летних сборах, август 2006 года.

[English](README.md) · **Русский** · [中文](README.zh.md) · [Español](README.es.md)

## Задача

N военных (2 ≤ N ≤ 100000) образуют дерево: военный i > 1 подчиняется
командиру K_i < i, а связь стоит C_i (0 ≤ C_i ≤ 1000) за мегабайт.
У каждого есть действительная надёжность A_i: у генерала (номер 1) она
равна 1, у рядовых (тех, у кого нет подчинённых) — 0, у остальных
неизвестна. Трафик по связи военного i в счёте — любое число не меньше
max(0, A_K_i − A_i), его выбирают сами военные. Нужно найти наименьшую
сумму, которую провайдер может себе гарантировать, ровно с двумя знаками
после точки.

Ограничение времени: 1 секунда. Ограничение памяти: 64 МБ.

## Входные данные

N, затем N − 1 строк K_i C_i для i = 2 … N.

## Выходные данные

Гарантированная сумма.

## Примеры

### Пример 1

Ввод:

```
7
1 10
2 5
2 3
3 1
3 2
3 3
```

Вывод:

```
8.00
```

## Решение

Военные вписывают минимум и выбирают неизвестные надёжности так, чтобы
минимизировать Σ C_i·max(0, A_K_i − A_i). Если обрезать все A до
отрезка [0, 1], ни одно слагаемое не вырастет. Разрежем теперь на
каждом уровне t от 0 до 1: военные с A ≥ t включают генерала и ни
одного рядового, а связи от них к военным ниже t образуют разрез,
отделяющий генерала от всех рядовых. Сумма в счёте — интеграл цен этих
разрезов по t, поэтому она не меньше самого дешёвого разреза, а если
поставить A = 1 выше этого разреза и 0 ниже, она его достигает. Ответ —
самый дешёвый такой разрез, и он всегда целый.

В дереве это минимум снизу вверх: cut(v), самый дешёвый способ отделить
v от всех рядовых под v, равен сумме по подчинённым u величин
min(C_u, cut(u)), причём рядового нельзя отделить от самого себя, и
рядовой предлагает только свою связь. Номера командиров меньше номеров
подчинённых, поэтому проход от N вниз до 2 заканчивает каждого военного
раньше командира. Ответ — cut(1). `O(N)`.

Подводные камни:

- надёжности действительные, но оптимум целый и выводится с «.00» (все
  тесты);
- дешёвая связь глубоко внизу может быть выгоднее дорогой сверху, а
  связи ценой 0 делают целую ветку бесплатной (тесты 03, 04);
- рядовой предлагает только связь с командиром (тест 02);
- цепочка из 100000 военных слишком глубока для рекурсии, а нумерация
  позволяет без неё обойтись (gen2).
