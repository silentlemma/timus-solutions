## Задача

Связный граф имеет n вершин (2 ≤ n ≤ 500) и m рёбер стоимостью от 0
до 1000, между двумя вершинами не больше одного ребра. Нужно вывести
стоимость минимального остовного дерева и стоимость следующего по
стоимости остовного дерева (она может совпадать с первой) или −1, если
другого остовного дерева нет.

Ограничение времени: 2 секунды. Ограничение памяти: 64 МБ.

## Входные данные

n и m, затем m строк a b w.

## Выходные данные

«Cost: » и первая стоимость, затем «Cost: » и вторая.

## Примеры

### Пример 1

Ввод:

```
4 6
1 2 2
2 3 2
3 4 2
4 1 2
1 3 1
2 4 1
```

Вывод:

```
Cost: 4
Cost: 4
```

### Пример 2

Ввод:

```
3 2
1 2 2
2 3 2
```

Вывод:

```
Cost: 4
Cost: -1
```

## Решение

Второе по стоимости остовное дерево отличается от некоторого
минимального ровно одним ребром: входит ребро не из дерева и уходит
самое тяжёлое ребро на пути по дереву между его концами. Поэтому
вторая стоимость — минимальная плюс наименьшее w − (самое тяжёлое ребро
на пути) по рёбрам вне дерева, и −1, если все рёбра в дереве.

При не более 500 вершинах алгоритм Прима на матрице стоимостей работает
за O(n²). Самые тяжёлые рёбра на всех путях по дереву получаются
попутно: когда вершина v присоединяется через родителя p ребром
стоимости c, для каждой уже добавленной вершины u
heaviest(u, v) = max(heaviest(u, p), c). `O(n² + m)`.

Подводные камни:

- второе дерево может стоить столько же, сколько первое (тест 01);
- если граф сам является деревом, второго дерева нет (тесты 02, 03,
  gen2);
- стоимости бывают нулевыми (тесты 04, 06).
