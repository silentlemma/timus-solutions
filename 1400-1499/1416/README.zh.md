# 1416. 机密

[Timus 1416](https://acm.timus.ru/problem.aspx?space=1&num=1416) · 难度 385 · graphs

原题作者 Den Raskovalov，出自 2005 年 10 月 29 日乌拉尔国立大学锦标赛。

[English](README.md) · [Русский](README.ru.md) · **中文** · [Español](README.es.md)

## 任务

一个连通图有 n 个顶点（2 ≤ n ≤ 500）和 m 条边，边权为 0 到 1000，任意两点之间
至多一条边。输出最小生成树的权值，以及按权值排序的下一棵生成树的权值（可以与第
一个相等）；若不存在其他生成树，输出 −1。

时间限制：2 秒。内存限制：64 MB。

## 输入

首行给出 n 个顶点、m 条无向边，2≤n≤500，1≤m≤n(n−1)/2。随后 m 行给出端点 a,b（1..n）及代价 w（0..1000）。无自环、无重边，图连通。

## 输出

"Cost: " 和第一个权值，然后 "Cost: " 和第二个权值。

## 检查

仓库仅去掉完整输出末尾空白后精确比较：两行分别为 Cost: 及第一、第二棵树的代价。大小写、冒号、后面的空格及内部换行均重要。第二代价可等于第一；仅无另一组生成树边时输出 -1。

## 样例

### 样例 1

输入:

```
4 6
1 2 2
2 3 2
3 4 2
4 1 2
1 3 1
2 4 1
```

输出:

```
Cost: 4
Cost: 4
```

### 样例 2

输入:

```
3 2
1 2 2
2 3 2
```

输出:

```
Cost: 4
Cost: -1
```

## 解法

次小生成树与某棵最小生成树恰好相差一条边：一条树外的边加入，它两端之间树上路
径中最重的边移出。因此第二个权值等于最小权值加上所有树外边上 w − (路径上最重
边) 的最小值；若所有边都在树中，则为 −1。

顶点数不超过 500，在权值矩阵上运行 Prim 算法为 O(n²)。树上所有路径的最重边可
以顺便求出：当顶点 v 通过父节点 p 以权值 c 的边加入时，对每个已在树中的顶点 u，
heaviest(u, v) = max(heaviest(u, p), c)。`O(n² + m)`。

注意事项：

- 第二棵树的权值可以与第一棵相同（测试 01）；
- 如果图本身就是一棵树，就没有第二棵树（测试 02、03、gen2）；
- 边权可以为 0（测试 04、06）。

## 优化解法

紧凑的 C++ 版本沿用 Prim 的递推，两张矩阵均使用 16 位条目。边加入生成树后就在权重矩阵中标记为不存在。由于两个端点都已加入，这不会影响后续更新。最后只需扫描树外的边，找到增量为零的边即可停止。
